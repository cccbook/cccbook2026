# Linux 的獨創基因：從 epoll、容器到 eBPF 與雲原生系統

> **副標題**：內核原語、隔離抽象與現代分散式基礎設施的演進

Linux 不只是一個作業系統內核，而是現代伺服器、雲端與分散式系統的「共同底座」。
本書聚焦於 Linux 生態中那些改變系統架構與雲端基礎設施的關鍵原語與創見——從早期的 I/O 多工與隔離原語，到容器與叢集編排，再到現代內核可程式化與可觀測性引擎 eBPF，以及雲原生系統的演進。

全書的核心論點只有一句：**Linux 的獨創性不在於「一次想好所有答案」，而在於提供可演進的底層原語。**

每一章都在回答同一個問題：**Linux 提供了什麼樣的原語，使得上層的抽象層可以長出來？** 而每一章也都會指出：上層抽象層的需求，又如何反過來逼迫 Linux 演化出新的原語。

## 撰寫原則

1. **事實優先**：所有年份、版本號、人物與事件皆經查證，爭議性數據明確標示為估算或引述來源。
2. **因果鏈**：每個原語都要說明「前因」（上一個抽象層暴露的瓶頸）與「後果」（催生了哪個新抽象層）。
3. **可實作**：每一章盡量給出可讀的 C 片段、核心設定檔或真實設定檔，讓原語從抽象變成具體。
4. **理論連線**：在必要處引入排隊論、Amdahl 法則、快取局部性等量化模型，說明「為什麼這樣設計」。
