# AI 時代的異質編譯器

> 副標題：從確定性翻譯的鬆動、MLIR 多層降階，到神經生成與硬體合成的網狀管線

一本關於 **編譯器在 AI 與異質算力雙重壓力下如何重構** 的技術教科書，與《AI 時代的異質作業系統》互為表裡。
它不談單一工具的使用手冊，也不預測某個框架的生死；每一節都在回答同一個問題：**「這個延續了七十年的編譯假設，究竟是為了誰、在什麼條件下成立，而這個條件現在還成立嗎？」**

如果《AI 時代的異質作業系統》負責 **執行期的安全驗證、統一記憶體與跨晶片調度**，那麼本書處理的是它之前的那一步：
**在執行前，把人類與 LLM 的意圖，透過多層 IR 拆解、搜尋、驗證，精準降階為 CPU 指令、GPU Kernel、NPU 排程與 FPGA 邏輯閘。**

全書圍繞四條主線展開：

* **編譯定義的鬆動**——「同一份輸入永遠產出語義等價輸出」的黃金律，如何在 LLM 介入生成後被鬆動；以及為什麼機率性生成越強，確定性驗證就越值錢。
* **異質硬體的物理現實**——CPU 的微架構、GPU 的 SIMT、NPU 的靜態排程、FPGA 的時序與資源，四種算力形態如何各自逼出不同的編譯策略。
* **多層 IR 帝國**——單一 IR 的語意抹除危機，如何催生 MLIR 的方言與漸進式降階，並把線性流水線改寫成網狀編譯管線。
* **AI 賦能與終極形態**——LLM 在編譯器工程、Kernel 生成與代價模型上的三條前線，以及編譯器、作業系統與硬體設計的邊界最終如何融合。

全書的核心命題是：

> 現代異質編譯器不再只是「語言翻譯機」，而是 **融合多層抽象降階、機率性搜尋、形式化守門與軟硬體協同的網狀轉化系統**。

## 本書的閱讀線索

第 1 部（第 1–2 章）是「定義的鬆動」：先把編譯器七十年來的確定性黃金律攤開，說明 LLM 介入後為什麼會鬆動，以及為什麼鬆動反而抬高了驗證的價值。

第 2 部（第 3–5 章）是「物理的現實」：把四種算力形態——CPU、GPU、NPU/TPU、FPGA——的硬體限制擺上桌，說明每一種形態如何逼出不同的編譯策略。讀者若只熟 CPU，第 3 章可快速掠過，重點放在第 4、5 章。

第 3 部（第 6–8 章）是「抽象的重建」：從單一 IR 為何崩壞講到 MLIR 的方言與漸進式降階，最後把線性流水線改寫成網狀編譯管線。這是全書的技術核心，建議與《MLIR 多層中間表示法》對讀。

第 4 部（第 9–10 章）是「未來的形狀」：LLM 在三條前線上的實際用法，以及編譯器與作業系統、硬體設計最終的融合。

## 與姊妹作的關係

| 問題 | 《AI 時代的異質作業系統》 | 《AI 時代的異質編譯器》 |
|---|---|---|
| 何時發生 | 執行期（runtime） | 執行前（compile time） |
| 核心職責 | 驗證、記憶體、調度 | 降階、搜尋、守門 |
| 主要產物 | 執行計畫與安全邊界 | 指令、Kernel、排程、位元流 |
| 交接介面 | IR 執行介面 | 高階 IR 與驗證器 |

兩本書共用同一個假設：**AI 寫 Code 讓「意圖」成為新的程式來源，而多層 IR 是意圖與硬體之間的標準介面。**
