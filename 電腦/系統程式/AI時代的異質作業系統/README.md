# AI 時代的異質作業系統

> 副標題：當 LLM 重寫軟體生產方式，MLIR、eBPF 與異質算力如何重構系統底層

一本關於 **作業系統在 AI 與異質算力雙重壓力下如何重構** 的技術教科書。
它不談單一 API，也不預測某個產品的生死；每一節都在回答同一個問題：**「這個延續了半世紀的抽象層，究竟是為了誰、在什麼假設下被發明，而這個假設現在還成立嗎？」**

全書圍繞四條主線展開：

* **舊世界抽象層的崩壞**——為什麼 1970 年代為「同質 CPU + 被動外設 + 人類程式」設計的驅動、行程、檔案系統模型，在異質算力與 AI 生成程式雙重夾殺下失效。
* **AI 寫 Code 帶來的範式轉移**——一次性軟體、意圖驅動執行、IR 成為系統介面、載入前驗證取代權限硬隔離。
* **AI 時代異質作業系統的新原語**——全域統一記憶體、跨晶片計算圖排程器、極小化可信核心。
* **演化與革命兩條路線**——從 Linux 長出新器官（eBPF / io_uring / VFIO / Unikernel）的漸進策略，與白紙重構的 Clean-Slate OS 藍圖。

全書的核心命題是：

> 下一代作業系統不是「對 AI 友好的 Linux」，而是 **融合編譯器、形式驗證與異質算力調度的極薄執行底座**。

## 本書的閱讀線索

第 1 部（第 1–3 章）是「診斷」：先把舊世界抽象層的假設一條條攤開，說明它們為何在異質算力面前失效。
第 2 部（第 4–6 章）是「外力」：AI 寫 Code 如何改變軟體的生產方式，並逼著作業系統改變它的介面與安全模型。
第 3 部（第 7–9 章）是「處方」：新作業系統需要的三個核心原語。
第 4 部（第 10–12 章）是「路線」：演化與革命的兩種現實策略，以及它們可能的交匯點。

閱讀時可以把它當成一場接力：每一章都在拆掉上一章還默認存在的東西，直到最後只剩下一層「連接意圖、驗證與物理算力」的薄膜。

## 環境與術語說明

文中涉及的系統與規格，以 2024–2026 年的公開資訊為基準。幾個貫穿全書的術語先在此定義：

* **IR（Intermediate Representation，中間表示）**：介於人類意圖與機器執行之間的程式表示，本書特別指 MLIR 家族的多層 IR。
* **異質算力**：CPU、GPU、NPU、TPU、FPGA 等架構互異、記憶體層級與執行模型不同的計算單元。
* **一次性軟體（Ephemeral Software）**：由 AI 針對單次任務即時生成、驗證、執行後即銷毀、不進入長期維護的程式。
* **載入前驗證（Load-time Verification）**：在程式或 IR 進入執行前，以靜態分析或形式化證明確認其安全性與資源預算。
