# 網站安全與防駭

本書從攻擊者的視角與防禦者的工程兩個方向，系統性講解網站安全。閱讀主線沿用本系列的精神：**每一種攻擊的誕生都有其技術前因，每一種防禦都是對攻擊的結構性回答**。理解因果，才能在新的攻擊出現時自己推導出防禦，而不是背誦檢查清單。

建議先讀完《網站設計基礎知識》（HTTP/HTML/JS/WebSocket），本書大量引用其章節。
