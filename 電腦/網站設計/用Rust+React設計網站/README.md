# 用 Rust + React 建構網站：axum + expo 全端開發

本書以「理論驅動實務」的方式，講解如何使用 **Rust (axum)** 作為後端、**React (Expo)** 作為前端，建構現代化的全端網站與行動應用。書中特別著重技術背後的理論基礎與歷史脈絡 —— 每一項技術的出現，都是為了解決前一代技術的某些缺陷，理解這些「前因後果」，才能真正掌握系統設計的精髓。
