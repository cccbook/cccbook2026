# 網站設計基礎知識

本書涵蓋網站設計的完整基礎知識鏈：從網路的物理層（TCP/IP、Socket）到傳輸層（HTTP、TLS、CDN、WebSocket），再到三大前端基石（HTML/CSS/JavaScript），最後整合成一個即時聊天室全端實戰。

閱讀主線：**一個網頁從你按下 Enter 到出現在螢幕上，經歷了什麼？** 每一章都是這段旅程的一站，並說明每項技術為何存在、解決了前一代的什麼問題。
