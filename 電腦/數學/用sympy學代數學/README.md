# 用 SymPy 學代數學

本書以 SymPy 為工具，帶領讀者從多項式與群的定義出發，一路走到 Galois 理論、表示論與同調代數的入門。每一節都包含：數學理論、歷史脈絡（驅動理論發展的問題）、以及 SymPy 程式實作，展示「技術需求驅動理論、理論反過來支持技術」的前因後果。

```python
pip install sympy
```
