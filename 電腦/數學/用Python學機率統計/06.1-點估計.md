# 6.1 點估計

## 本節目標

- 搞清楚「估計量」到底在估什麼：母體參數 $`\theta`$ 是一個固定的數字，而估計量 $`\hat{\theta}`$ 是資料的函數，因此**會搖擺**
- 用**偏誤（bias）**與**變異數（variance）**兩把尺衡量一個估計量好不好
- 理解 **MSE = 變異數 + 偏誤平方**，這是「不偏但變異大」與「微偏但集中」取捨的完整答案
- 驗證兩個必背結果： $`\bar{X}`$ 是不偏的；樣本變異數要**除以 $`n-1`$ ** 才是對 $`\sigma^2`$ 的不偏估計（呼應 1.3 與 5.4）
- 體會「好估計量」的取捨：對稱常態用平均數、右偏資料用中位數

## 問題：抽到一袋樣本之後，「母體平均是多少」要怎麼講？

第 1 章我們把資料拿來算「集中趨勢」，那一章的結論是：平均數、中位數、眾數這些數字可以**描述**手上的資料。但統計推論要回答的是另一個問題：

> 母體的参数 $`\mu`$ 是一個**未知但固定**的數字。我們抽到 $`n`$ 個樣本 $`X_1, X_2, \ldots, X_n`$ ，能不能用這批資料造一個數字，來「猜」 $`\mu`$ ？

這個猜測值就叫**估計量（estimator）** $`\hat{\theta}`$ ，而它對應的參數真值 $`\theta`$ 叫真值。

關鍵在於： $`\hat{\theta}`$ 是**樣本的函數**。同一個母體，抽樣抽 100 次就得到 100 個不同的 $`\hat{\theta}`$ 。所以我們不能問「它對不對」，只能問兩個統計上的問題：

1. **中心有沒有對準？** 平均而言，它會不會系統性地偏高或偏低？——這是**偏誤**。
2. **它會晃多厲害？** 反覆抽樣時估計量的散布程度有多大？——這是**變異數**。

這兩把尺就是本章的全部內容。

### 歷史：1900—1930 年代，費歇（Ronald Fisher）把「猜測」變成一門數學

在 Fisher 之前，統計學家常把估計量叫做「最接近的近似值」，討論靠的是經驗法則。Fisher 在 1922 年的論文〈On the Mathematical Foundations of the Theory of Statistics〉裡，把問題重新定義成「**決策的風險**」：既然估計量會搖擺，那就用一個可以計算的函數來衡量它的表現，並且把「對準」與「晃動」拆成兩個可以分別設計的部件。

這個拆解是整個現代統計的骨架：後來的最小變異量無偏估計量（MVUE）、 Neyman–Pearson 檢定、最大似然估計，全都是這兩把尺的後代。

## 理論：偏誤、變異數、MSE

### 定義

對估計量 $`T = T(X_1, \ldots, X_n)`$ 估計參數 $`\theta`$ ：

- **偏誤（bias）**： $`\operatorname{Bias}(T) = E[T] - \theta`$ 

- **變異數**： $`\operatorname{Var}(T) = E\left[(T - E[T])^2\right]`$ 

- **均方誤差（MSE, mean squared error）**： $`\operatorname{MSE}(T) = E[(T-\theta)^2] = \operatorname{Var}(T) + \operatorname{Bias}(T)^2`$ 

最後那個等式是本章最重要的公式：**MSE = 變異數 + 偏誤平方**。它把「兩個缺點」加總成一個可以比較的數字。

注意兩個關鍵詞：

- **不偏（unbiased）** 指 $`E[T] = \theta`$ ，此時偏誤為 0。**不偏不等於好估計**——一個估計量可以完全不偏但散布得離譜。
- 變異數越小越好，因為它直接是「猜錯多遠」的平方的平均（ $`\operatorname{Var}(T) = E[(T-\theta)^2] - \operatorname{Bias}(T)^2`$ ，不偏時兩者相等）。

### 必背結果一： $`\bar{X}`$ 是不偏的

 $`E[\bar{X}] = E\left[\frac{1}{n}\sum_{i=1}^n X_i\right] = \frac{1}{n}\sum_{i=1}^n E[X_i] = \mu`$ 

這一步只用到期望值的線性性，**完全不需要常態假設**。變異數則是：

 $`\operatorname{Var}(\bar{X}) = \frac{\sigma^2}{n}`$ 

也就是 5.2 節中央極限定理說的那件事：樣本越大，平均數越集中在真值附近。

### 必背結果二：樣本變異數為什麼要除 $`n-1`$ ？

1.3 節我們定義過樣本變異數 $`S^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2`$ 。現在知道那個 $`n-1`$ 從哪來了：它讓 $`S^2`$ 成為 $`\sigma^2`$ 的**不偏估計**。

理由可以用自由度數一遍： $`\sum_{i=1}^n (X_i - \bar{X})^2`$ 這個平方和裡， $`n`$ 個偏差受到約束 $`\sum_i (X_i - \bar{X}) = 0`$ ，只有 $`n-1`$ 個方向能自由動（5.4 節）。而 5.4 節我們已經驗證過：

 $`\frac{(n-1)S^2}{\sigma^2} \sim \chi^2_{n-1}`$ 

取期望值， $`E[\chi^2_{n-1}] = n-1`$ ，所以：

 $`E\left[\frac{(n-1)S^2}{\sigma^2}\right] = n-1 \;\Longrightarrow\; E[S^2] = \sigma^2`$ 

**除以 $`n-1`$ 剛好抵掉自由度少了一個的事實。** 若改除以 $`n`$ （有些教科書叫 $`S_n^2`$ ），就會系統性低估： $`E[S_n^2] = \frac{n-1}{n}\sigma^2`$ ，偏誤是 $`-\sigma^2/n`$ 。

## 動手（一）：親眼看見 $`\bar{X}`$ 的抽樣分布

母體取 $`N(50, 12^2)`$ ，重複抽樣 20000 次，每次抽 $`n`$ 個，看 $`\bar{X}`$ 的分布怎麼隨 $`n`$ 收斂。

```python
import math
import rstatistics as r


def ascii_hist(x, nb=20, width=60):
    lo, hi = min(x), max(x)
    step = (hi - lo) / nb
    counts = [0] * nb
    for v in x:
        counts[min(nb - 1, int((v - lo) / step))] += 1
    mx = max(counts)
    for i, c in enumerate(counts):
        if c == 0:
            continue
        m = lo + (i + 0.5) * step
        bar = "#" * max(1, round(width * c / mx))
        print(f"{m:8.2f} |{bar} {c}")


B = 20000
mu, sigma = 50.0, 12.0

print("=== 母體 N(50, 12^2)：重複抽樣，看 x-bar 的抽樣分布如何隨 n 收斂 ===")
print(f"{'n':>4} {'mean(x-bar)':>12} {'bias':>10} {'sd(x-bar)':>10} {'sd/sigma':>9} {'RMSE':>8}")
for n in (1, 2, 5, 10, 25, 100):
    g = r.set_seed(100 + n)
    means = [r.mean(g.rnorm(n, mean=mu, sd=sigma)) for _ in range(B)]
    bias = r.mean(means) - mu
    sd = r.sd(means)
    rmse = math.sqrt(r.mean([(v - mu) ** 2 for v in means]))
    print(f"{n:>4} {r.mean(means):>12.4f} {bias:>10.4f} {sd:>10.4f} {sd/sigma:>9.4f} {rmse:>8.4f}")
print(f"理論：sd(x-bar) = sigma/sqrt(n)；n=1 時 {sigma/math.sqrt(1):.4f}，n=25 時 {sigma/math.sqrt(25):.4f}")
```

讀法：

- **偏誤那一欄永遠在 0 附近跳動**（最大 0.0557，只有 sigma 的 0.5%）。這就是「 $`\bar{X}`$ 不偏」的實證：20000 次抽樣的平均值幾乎都在 50。
- **sd 那一欄才會隨 n 系統性下降**，而且精確地遵守 $`\sigma/\sqrt{n}`$ ：n=1 時 11.92（≈12），n=25 時 2.39（≈2.4），n=100 時 1.21（≈1.2）。

**這兩件事要分開看**：偏誤不隨 n 改善（本來就是 0），但變異會隨 n 以 $`1/\sqrt{n}`$ 的速度改善。這正是 6.2 節信賴區間寬度的來源。

## 動手（二）：為什麼要除 $`n-1`$ —— 用數字說話

```python
print()
print("=== 樣本變異數為什麼要除 n-1？（呼應 1.3 / 5.4）===")
g = r.set_seed(7)
s2n = []
s2m1 = []
for _ in range(B):
    s = g.rnorm(20, mean=mu, sd=sigma)
    m = r.mean(s)
    ss = sum((v - m) ** 2 for v in s)
    s2n.append(ss / 20)
    s2m1.append(ss / 19)
print(f"母體 sigma^2 = {sigma**2}")
print(f"  S2_n   (除以 n=20)  : mean = {r.mean(s2n):8.4f}  bias = {r.mean(s2n)-sigma**2:8.4f}  MSE = {r.mean([(v-sigma**2)**2 for v in s2n]):9.4f}")
print(f"  S2_(n-1)(除以 n-1=19): mean = {r.mean(s2m1):8.4f}  bias = {r.mean(s2m1)-sigma**2:8.4f}  MSE = {r.mean([(v-sigma**2)**2 for v in s2m1]):9.4f}")

print("  → 除以 n-1 才是對 sigma^2 的不偏估計（偏差剛好抵掉 1/(n-1) 的修正）")

```

**有趣的一個細節**： $`S^2_{n-1}`$ 的 MSE（2222）反而比 $`S^2_n`$ 的 MSE（2051）稍大。這不是 $`n-1`$ 比較差，而是「不偏」和「MSE 小」本來就是兩回事——這正好引出下一節的取捨。

## 動手（三）：好估計量的取捨

### 取捨一：不偏但變異大 vs 微偏但集中

**情境 (a)**：母體是對稱常態 $`N(50, 12^2)`$ ，估 $`\mu`$ 。比較兩個候選：

- $`\bar{X}`$ ：不偏，變異小。
- 樣本中位數：對常態母體也幾乎不偏，但變異**大約多 25%**。

```python
print()
print("=== 取捨一：不偏但變異大 vs 微偏但集中 ===")
print("(a) 對稱常態母體估 mu：x-bar（不偏）vs 中位數（也幾乎不偏，但變異較大）")
n = 25
g = r.set_seed(31)
em = []
ed = []
for _ in range(B):
    s = g.rnorm(n, mean=mu, sd=sigma)
    em.append(r.mean(s))
    ed.append(r.median(s))
print(f"  n = {n}, 母體 N({mu}, {sigma}^2)")
print(f"    x-bar  : bias = {r.mean(em)-mu:>8.4f}  sd = {r.sd(em):>7.4f}  RMSE = {math.sqrt(r.mean([(v-mu)**2 for v in em])):>7.4f}")
print(f"    median : bias = {r.mean(ed)-mu:>8.4f}  sd = {r.sd(ed):>7.4f}  RMSE = {math.sqrt(r.mean([(v-mu)**2 for v in ed])):>7.4f}")
print(f"    理論 sd(median) = 1.2533*sigma/sqrt(n) = {1.2533*sigma/math.sqrt(n):.4f}")
```

兩者偏誤都是 0（模擬誤差），但中位數的 sd 是 2.99 vs 平均數的 2.40，理論比值 $`1.2533`$ 也對上了（3.0079 vs 2.9856）。**在對稱母體上，平均數比較有效（efficient）**。

**情境 (b)**：這個對比其實上一段已經出現過了——估 $`\sigma^2`$ 時， $`S^2_n`$ （除以 $`n`$ ）是**有偏**的，但它的 MSE 卻比不偏的 $`S^2_{n-1}`$ **更小**。我們把它推廣到不同的 $`n`$ 看：

```python
print("(b) 微偏但更集中：估 sigma^2 用 S2_n（除以 n）還是 S2_(n-1)（除以 n-1）？")
print("    n = 20，S2_n 的偏誤是 -sigma^2/n，但 MSE 反而比較小")
for nn in (5, 10, 20, 50):
    g = r.set_seed(60 + nn)
    a = []
    b = []
    for _ in range(B):
        s = g.rnorm(nn, mean=mu, sd=sigma)
        m = r.mean(s)
        ss = sum((v - m) ** 2 for v in s)
        a.append(ss / nn)
        b.append(ss / (nn - 1))
    mse_a = r.mean([(v - sigma**2) ** 2 for v in a])
    mse_b = r.mean([(v - sigma**2) ** 2 for v in b])
    print(f"    n = {nn:>3}: S2_n   bias = {r.mean(a)-sigma**2:>8.4f}  MSE = {mse_a:>10.4f}")
    print(f"           S2_(n-1) bias = {r.mean(b)-sigma**2:>8.4f}  MSE = {mse_b:>10.4f}   (MSE 較小的是 S2_n: {mse_a < mse_b})")
print("    理論：MSE(S2_(n-1)) = 2*sigma^4/(n-1)，MSE(S2_n) = sigma^4*(2n-1)/n^2")
print(f"          n=20 時分別是 {2*sigma**4/19:.4f} 與 {sigma**4*39/400:.4f} → S2_n 的 MSE 比較小")
```

**這是本章最值得學會的一個判斷**：

- $`S^2_{n-1}`$ ：偏誤 ≈ 0（不偏），MSE = $`2\sigma^4/(n-1)`$ 。
- $`S^2_n`$ ：偏誤 = $`-\sigma^2/n`$ （有偏），MSE = $`\sigma^4(2n-1)/n^2`$ 。

比較兩者： $`\frac{2}{n-1} - \frac{2n-1}{n^2} = \frac{2n^2 - (2n-1)(n-1)}{n^2(n-1)} = \frac{3n-1}{n^2(n-1)} > 0`$ ，所以 ** $`S^2_n`$ 的 MSE 永遠比較小**（雖然差距很小）。這就是「微偏但集中」的乾淨例子。

為什麼？因為偏誤只有 $`O(1/n)`$ 而變異是 $`O(1/n)`$ ，**偏誤平方是 $`O(1/n^2)`$ **，量級小於變異的改善量。

同一個思想的更高級版本是 **James–Stein 估計量**（James & Stein, 1961）：同時估計很多個參數時，把每個估計值往整體平均「收縮」，用一點點偏誤換到大幅度的變異下降。Fisher 在 1930 年代就提過類似想法，但當時沒有被推廣。

**但要記住**：MSE 只是很多種判準之一。**在統計推論裡，「不偏」常常是刻意保留的性質**，因為不偏讓我們能寫出「覆蓋率恰好是 95%」這種保證；MSE 較小但覆蓋率不對的估計量，會讓 6.2 節的信賴區間失去意義。

### 取捨二：平均數 vs 中位數，關鍵在於「你要估什麼」

右偏母體（指數分布，平均 20）上，估**平均**和估**中位數**是兩件不同的事。

```python
print()
print("=== 取捨二：右偏母體上，平均數 vs 中位數誰更有效？ ===")
g = r.set_seed(11)
xs = g.rexp(20000, rate=1.0 / 20.0)
true_med = 20.0 * math.log(2)
print(f"母體（指數，平均 20）：mean = {r.mean(xs):.3f}，median = {r.median(xs):.3f}，真中位數 = {true_med:.4f}")
for n in (10, 30):
    g = r.set_seed(300 + n)
    est_mean = []
    est_med = []
    for _ in range(B):
        s = g.rexp(n, rate=1.0 / 20.0)
        est_mean.append(r.mean(s))
        est_med.append(r.median(s))
    print(f"  n = {n}:")
    print(f"    x-bar  (目標 20.0000): bias = {r.mean(est_mean)-20.0:>8.4f}  sd = {r.sd(est_mean):>7.4f}  RMSE = {math.sqrt(r.mean([(v-20.0)**2 for v in est_mean])):>7.4f}")
    print(f"    median (目標 {true_med:.4f}): bias = {r.mean(est_med)-true_med:>8.4f}  sd = {r.sd(est_med):>7.4f}  RMSE = {math.sqrt(r.mean([(v-true_med)**2 for v in est_med])):>7.4f}")
print("  → 估『平均』用 x-bar 有效（不偏且 sd 小）；估『中位數』用樣本中位數（不偏但 O(1/n) 微偏、sd 略大）")
print("  → 真正在意的是目標參數是什麼：想估平均就別用中位數去湊")
```

看兩件事：

1. **樣本中位數估中位數時有 $`O(1/n)`$ 的微偏**（n=10 偏 0.99，n=30 偏 0.32，比例大約是 1:3，正好符合 $`1/n`$ ）。這是估計中位數的固有困難（要反推分位位置），但 n 大時可以忽略。
2. **用中位數去湊一個右偏母體的平均，會系統性地低估**——這是「估錯目標」的典型災難。

**結論**：平均數 vs 中位數之爭不是「誰比較好」，而是「你的參數是什麼」。想估平均就用平均數（不偏、有效）；想估中位數就用中位數；資料嚴重右偏又只關心「典型值」時，中位數更穩健（不受極端值影響）。

## 小結

1. **估計量是樣本的函數，會搖擺**；估計量的品質用**偏誤**與**變異數**衡量，合成 **MSE = 變異數 + 偏誤平方**。
2. $`\bar{X}`$ 是 $`\mu`$ 的不偏估計量， $`\operatorname{Var}(\bar{X}) = \sigma^2/n`$ ——偏誤不隨 n 改善，但變異以 $`1/\sqrt{n}`$ 改善。
3. **樣本變異數除以 $`n-1`$ ** 才是對 $`\sigma^2`$ 的不偏估計，這個 $`n-1`$ 就是自由度少了一個（1.3 / 5.4）。
4. 「不偏」不是唯一目標：MSE 有時由微偏的估計量達成（本章的 $`S^2_n`$ 就是例子；多參數情形則有 James–Stein 收縮）。
5. **平均數 vs 中位數之爭的答案是「你的目標參數是什麼」**：估平均用平均數，估中位數用中位數。

## 練習

1. 用模擬證明：**樣本眾數（mode）不是母體眾數的不偏估計量**。取一個雙峰常態混合母體，估計母體眾數位置，看重複抽樣時估計量的平均落在哪裡、偏誤多大。
   （提示：先在密度上做數值搜尋找母體眾數，再用網格上的最大密度點作為樣本眾數的估計。）
2. 驗證 $`E[S^2_n] = \frac{n-1}{n}\sigma^2`$ ：對不同的 $`n = 5, 10, 20, 50`$ 各模擬 5000 次，畫「 $`S^2_n`$ 的平均 vs $`\frac{n-1}{n}\sigma^2`$ 」的對照表。
3. 把本節情境 (b) 推廣：對不同的 $`n = 5, 10, 20, 50`$ ，算出 $`S^2_n`$ 與 $`S^2_{n-1}`$ 的**理論 MSE**（ $`2\sigma^4/(n-1)`$ 與 $`\sigma^4(2n-1)/n^2`$ ），與模擬值對照，並算出兩者的**相對差距** $`\frac{MSE(S^2_{n-1}) - MSE(S^2_n)}{MSE(S^2_{n-1})}`$ 。**看 n 越大，相對差距越小**。
   （提示：n=5 時差距約 28%，n=50 時約 3%。）
4. 找一個「高偏誤但低變異」的估計量：對 $`N(\mu, \sigma^2)`$ 估 $`\sigma`$ ，比較 $`\sqrt{S^2}`$ 與「把 $`S^2`$ 開根號後再除上一個小於 1 的修正係數」的版本，看哪個 MSE 小。
   （提示： $`\sqrt{\cdot}`$ 這一步會製造 $`O(1/n)`$ 的偏誤。）
5. 討論題：若目標參數是母體的**中位數**，而母體是對稱常態，則中位數與平均數都是不偏估計量。哪一個**更有效**？用 20000 次模擬比較兩者的 sd，並用理論說明為什麼。
   （提示：對稱常態的樣本中位數的漸近效率是 $`2/\pi \approx 0.637`$ 倍於平均數。）
