# 用 Python 學機率統計：從擲骰子到資料科學

本書是一本 **用 Python 親手模擬與計算來學機率統計** 的書。

機率統計是最適合「做實驗」的數學：你可以在電腦上擲一萬次骰子、模擬一萬次抽樣、畫出一萬次實驗的直方圖 —— 讓「大數法則」與「中央極限定理」從課本上的口號，變成你 **親眼看見** 的現象。這種「模擬驗證理論」的學習方式，正是現代資料科學家的工作方法。

本書路線：**機率直覺（擲骰、排組）→ 隨機變數與分布 → 抽樣與推論（估計、檢定）→ 迴歸與實務**。前半用 Python 標準庫與 SymPy 做精確計算與蒙地卡羅模擬；後半進入 NumPy、pandas、SciPy、Matplotlib 的資料科學工作流，處理真實資料。

讀完本書，你將具備閱讀任何統計學教科書的直覺基礎，以及分析真實世界資料的動手能力。

## 本書特色

- **模擬先行**：每個理論定理都先用蒙地卡羅模擬「看見」，再講數學證明
- **雙工具對照**：精確計算（SymPy/數學推導）與模擬驗證（NumPy 蒙地卡羅）並行
- **真實資料**：後半章使用真實資料集（含台灣資料）演練完整的統計分析流程
- **常見陷阱**：每章點破機率統計最常見的直覺謬誤（賭徒謬誤、辛普森悖論、p 值誤用）
- **零統計背景**：只需高中數學；第 1 章把需要的 Python 基礎補齊

## 閱讀方式

- **模擬優先**：每個定理先跑模擬「看見現象」，再讀數學 —— 直覺先於公式
- **邊讀邊跑**：所有程式碼建議在 Jupyter Notebook 中執行並改參數
- **章節依賴**：第 1–6 章是機率統計主線，第 7–8 章是工具，第 9 章整合，第 10 章展望
- 趕時間的讀者：1 → 3.4 → 4.3 → 5 → 6.1 → 9 這條主軸可快速建立推論統計核心
