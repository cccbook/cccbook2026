# 用 SymPy 學數學：讓 Python 當你的數學助理

本書是一本 **用 SymPy（Python 的符號計算函式庫）親手運算來學數學** 的書。

《用 Lean 學數學》教你「證明」；本書教你「**計算與探索**」。數學家的工作不只有寫證明 —— 更多時間花在 **做實驗**：展開多項式、解方程、畫函數圖形、算極限、驗證猜測。SymPy 讓你在瀏覽器與終端機裡完成這一切，而且 **每一步都保留符號形式**（不像計算機只能給你 $`0.6666\cdots`$ ，SymPy 告訴你答案是 $`\frac{2}{3}`$ ）。

本書每章對應一門標準數學課程：代數運算、方程、函數圖形、微積分、線性代數、級數、機率統計。讀完本書，你將擁有一套 **用程式探索數學** 的完整工具箱 —— 這是資料科學、機器學習與所有理工科研究的基本功。

## 本書特色

- **符號優先**：全書堅持用符號運算訓練數學直覺，避免過早退化成數值計算
- **對照表**：每個概念同時給出「手算過程」與「SymPy 程式碼」的對照，程式碼就是標準答案
- **探索導向**：每節都有「動手實驗」，讓你改參數、看圖形、找規律、猜定理
- **接軌實務**：最後一章銜接 NumPy/Matplotlib/Jupyter 的科學計算工作流
- **零背景入門**：只需高中數學與一點 Python 基礎，第一章就帶你裝好環境

## 閱讀方式

- **邊讀邊打**：所有程式碼都建議在 Jupyter Notebook 中實際執行，並 **改參數做實驗**
- **先手算後驗證**：每個例子先自己算，再用 SymPy 檢查 —— 程式是助理不是代打
- **動手實驗**：每節的「實驗」單元是本書精華，別跳過
- 章節有依賴性，建議按順序讀；趕時間者可先讀 1、2、5 三章建立核心能力

## 需要的背景知識

- 高中數學（函數、多項式、基本微積分概念會在第 5 章重新教）
- 一點 Python 基礎（變數、函數呼叫）；第 1 章會補齊所需的一切
- 不需要安裝付費軟體：全部使用免費開源工具
