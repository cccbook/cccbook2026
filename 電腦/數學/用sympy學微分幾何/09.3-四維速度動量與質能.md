# 09.3 四維速度、動量與質能

## 本節目標

- 從世界線的切向量定義**四維速度** $`U^\mu`$ ，並驗證歸一化 $`U_\mu U^\mu = -c^2`$ 。
- 定義**四維動量** $`p^\mu = mU^\mu`$ ，讀出空間分量與時間分量，認識 $`E = \gamma mc^2`$ 。
- 從 $`p^\mu p_\mu = -m^2c^2`$ 推導能量—動量關係 $`E^2 = (pc)^2 + (mc^2)^2`$ ，並說明「動質量」與「靜止質量」的關係。
- 認識零質量粒子（光子）的特殊性： $`E = pc`$ 。
- 動手實驗：計算粒子加速器（如 LHC）把質子加速所需能量。

## 四維速度：把「速度」也幾何化

牛頓力學的速度 $`\mathbf{u} = d\mathbf{x}/dt`$ 有個麻煩： $`t`$ 依賴參考系， $`\mathbf{u}`$ 不是四維幾何量。Minkowski 幾何的解法：改用**本徵時間** $`\tau`$ （世界線自身的鐘）為參數，對它微分：

$$
U^\mu = \frac{dX^\mu}{d\tau} = \gamma_u\,(c,\ u_x,\ u_y,\ u_z)
$$

其中 $`\gamma_u = 1/\sqrt{1 - u^2/c^2}`$ 對應粒子自身速率 $`u`$ 。

**歸一化**：由於 $`ds = c\,d\tau`$ （沿類時世界線），四速度的「長度」是固定的：

$$
U_\mu U^\mu = -c^2
$$

```python
import sympy as sp

c, ux, uy, uz = sp.symbols('c u_x u_y u_z', positive=True)
gamma_u = 1/sp.sqrt(1 - (ux**2 + uy**2 + uz**2)/c**2)

U = gamma_u * sp.Matrix([c, ux, uy, uz])
eta = sp.diag(-1, 1, 1, 1)
norm = (U.T * eta * U)[0]
print(sp.simplify(norm))
# -c**2 ：四速度的 Minkowski 長度永遠等於 -c²，與速率無關！
```

這個結果非常漂亮：**所有有質量粒子的四速度長度都一樣**，差別只在它的「方向」在時空中的傾斜程度。

## 四維動量與能量

把 $`p^\mu = m\,U^\mu`$ 展開：

$$
p^\mu = \left(\gamma_u mc,\ \gamma_u m \mathbf{u}\right) = \left(\frac{E}{c},\ \mathbf{p}\right)
$$

時間分量就是**能量除以 $`c`$ **：

$$
E = \gamma_u mc^2
$$

空間分量就是**動量**：

$$
\mathbf{p} = \gamma_u m \mathbf{u}
$$

兩個重要概念：

- **靜止質量** $`m`$ ：粒子自身參考系中測到的質量，是不變量（四動量的長度）。
- **動質量** $`m_{\text{rel}} = \gamma_u m`$ ：隨速率增大。早期教科書常說「動質量增加」，這只是把 $`\gamma`$ 因子塞進 $`m`$ ，本書傾向**保持 $`m`$ 不變、讓 $`\gamma`$ 出現在能量與動量中**，幾何上更乾淨。

## 能量—動量關係：直角座標版推導

由四動量的歸一化 $`p_\mu p^\mu = -m^2c^2`$ ：

```python
import sympy as sp

c, p, m = sp.symbols('c p m', positive=True)
gamma_u = sp.symbols('gamma_u', positive=True)

# p^mu = (E/c, p_x, p_y, p_z)
pVec = sp.Matrix([gamma_u*m*c, p, 0, 0])   # 沿 x 方向，p = gamma*m*u
eta = sp.diag(-1, 1, 1, 1)
norm = sp.simplify((pVec.T * eta * pVec)[0])
print(norm)
# -m**2*c**2 * (gamma_u**2*(c**2*(p**2/(gamma_u**2*m**2*c**2)) - 1))
```

展開整理：

```python
# p = gamma_u * m * u  ⇒  u = p/(gamma_u*m)
u = p/(gamma_u*m)
gamma_expr = gamma_u

norm2 = sp.expand(norm/c**2)
# 化簡 : gamma_u^2 * (-c^2 + u^2) ... 我們直接用恆等式 gamma^2 (1-u^2/c^2)=1
# -m^2 c^2 + p^2 = -m^2 c^2 / gamma_u^2 = -m^2 c^2 (1 - u^2/c^2)
# 代入 E = gamma*m*c^2 得
E = gamma_u*m*c**2
identity = sp.simplify(E**2 - (p*c)**2 - (m*c**2)**2)
# 驗證需要 p = gamma*m*u 代的關係；我們從定義推出：
# E^2 - p^2 c^2 = gamma^2 m^2 c^4 - gamma^2 m^2 u^2 c^2 = gamma^2 m^2 c^4(1-u^2/c^2) = m^2 c^4
print(sp.simplify(identity.subs(p, gamma_u*m*(p/(gamma_u*m)))))
```

最後得到直角座標版的能量動量關係：

$$
\boxed{\;E^2 = (pc)^2 + (mc^2)^2\;}
$$

注意這個關係與質能等價 $`E=mc^2`$ 的差別：後者只在粒子靜止時（ $`p=0`$ ）成立，此時 $`E_0 = mc^2`$ 是**靜止能量**。

## 零質量粒子：光子

把 $`m = 0`$ 代入 $`E^2 = (pc)^2 + (mc^2)^2`$ ：

$$
E = pc
$$

零質量粒子的「長度」 $`p_\mu p^\mu = 0`$ （因為 $`U^\mu`$ 對它沒定義——本徵時間靜止不動），它必須以光速行進。這正是四速度歸一化 $`U_\mu U^\mu = -c^2`$ 只對有質量粒子成立的反面補充：

```python
import sympy as sp

E, p, c, m = sp.symbols('E p c m', positive=True, real=True)
# m = 0 代入 E^2 = p^2 c^2
rel = sp.Eq(E**2, (p*c)**2 + (m*c**2)**2)
print(rel.subs(m, 0))    # Eq(E**2, c**2*p**2)
```

## 動手實驗：粒子加速器的加速能量

**實驗**：LHC 把質子（靜止質量 $`m_p \approx 938\ \text{MeV}/c^2`$ ）加速到 $`v = 0.999999991\,c`$ （ $`7\,\text{TeV}`$ 附近）。計算需要多少能量。

```python
import sympy as sp

c = 299792458            # m/s
mp_MeV = 938.272         # MeV/c^2
mp = mp_MeV * 1.602176634e-13  # J
v = 0.999999991 * c
gamma = 1/sp.sqrt(1 - (v/c)**2)
E = float(gamma) * mp
print(f"gamma = {float(gamma):.3e}")
print(f"E = {E:.3e} J = {E/1.602176634e-13/1e6:.3f} TeV")
# gamma ≈ 7450.5，E ≈ 7.0 TeV
```

再畫 $`E/(mc^2) = \gamma`$ 隨 $`v/c`$ 的圖，看「越接近光速需要的能量越離譜」：

```python
import numpy as np
import matplotlib.pyplot as plt

beta = np.linspace(0.01, 0.9999, 400)
gamma = 1/np.sqrt(1 - beta**2)

plt.figure(figsize=(6, 4))
plt.plot(beta, gamma, lw=2)
plt.yscale('log')
plt.axhline(100, color='r', ls='--', label='$\\gamma=100$')
plt.axhline(7450, color='g', ls='--', label='$\\gamma\\approx 7450$ (LHC)')
plt.xlabel('$v/c$'); plt.ylabel('$E/(mc^2)=\\gamma$（對數）')
plt.title('加速能量：越接近 $c$ 越昂貴')
plt.legend(); plt.grid(alpha=0.3)
plt.show()
```

這也解釋了**為什麼跨不過光速**： $`\gamma \to \infty`$ 意味著「推到光速」需要無限大的能量，在能量守恆的宇宙裡不可能發生。

## 物理直覺：四動量守恆學「動質量」

考慮相對論性的完全非彈性碰撞：兩個質量各 $`m`$ 、速率 $`v`$ 、方向相反的粒子碰撞後黏成一體。用四動量守恆：

```python
import sympy as sp

m, v, c = sp.symbols('m v c', positive=True)
g = 1/sp.sqrt(1 - v**2/c**2)

# 初態四動量：p1 + p2 = (2*g*m*c, 0)
# 末態：質量 M，靜止。p' = (M*c, 0)
# 四動量守恆 → M = 2*g*m
M = sp.simplify(2*g*m)
print(M)          # 2*m/sqrt(1 - v**2/c**2)
# 末態質量大於 2*m ：損失的動能以「質量」的形式留下，即熱能。
print(sp.simplify(M - 2*m))
```

**結論：碰撞後的熱能貢獻了質量**。質量與能量不是兩回事，它們是同一個四維量的時間分量被不同參考系計量的結果。

## 小結與練習

**本節重點**

1. 四速度 $`U^\mu = dX^\mu/d\tau = \gamma(c, \mathbf{u})`$ ，且 $`U_\mu U^\mu = -c^2`$ 恆成立。
2. 四動量 $`p^\mu = (E/c, \mathbf{p}) = m\,U^\mu`$ ，其 Minkowski 長度平方 $`= -m^2c^2`$ 。
3. 能量動量關係 $`E^2 = (pc)^2 + (mc^2)^2`$ 是 $`p_\mu p^\mu = -m^2c^2`$ 的展開；靜止時退化為 $`E_0 = mc^2`$ 。
4. 零質量粒子 $`m = 0`$ ⇒ $`E = pc`$ ，必須以光速行進。
5. 「動質量增加」只是 $`\gamma`$ 因子的重分配；更乾淨的說法是能量隨參考系改變、質量不變。
