# 用 SymPy 學微分幾何：從向量微積分到廣義相對論

本書是一本 **用 SymPy 親手計算來學微分幾何** 的書。

微分幾何是描述「彎曲」的數學 —— 曲線的曲率、曲面的高斯曲率、時空的愛因斯坦方程。傳統課程充滿冗長的指標運算，一個 Christoffel symbol 算錯一個下標就全盤皆輸。SymPy 的 `sympy.diffgeom`、`sympy.vector` 與 EinsteinPy 生態讓這些計算 **變成程式**：你可以宣告座標系、算度量張量、求 Christoffel symbols、驗證 Bianchi 恆等式 —— 電腦代勞繁瑣，你專注幾何直覺。

路線一氣呵成：**曲線與曲面（微分幾何入門）→ 向量微積分（梯度、散度、旋度）→ 廣義斯托克斯定理（微分形式與外微分）→ 曲率與張量 → 廣義相對論（史瓦西解）**。讀完本書，你將能看懂 《Nature》上的黑洞論文在算什麼，也能用 SymPy 驗證你自己的每一個計算。

## 本書特色

- **電腦代勞指標地獄**：Christoffel symbols、Riemann 張量全部由程式計算，杜絕手算錯誤
- **雙軌對照**：每個量都同時給出「幾何直覺圖解」與「SymPy 程式碼」
- **一條龍故事線**：從平面曲線的曲率一路推到愛因斯坦場方程，每章都是下一章的工具
- **真實驗證**：重算史瓦西解、驗證時空的 $`R_{\mu\nu}=0`$ ，親手確認 1915 年的計算
- **零背景入門**：只需微積分（多元）基礎；向量微積分在第 3 章重新完整教過

## 閱讀方式

- **程式即草稿紙**：所有 Christoffel symbols、曲率張量的計算都建議用 SymPy 重跑
- **圖形先行**：1–4 章大量依賴 Matplotlib 3D 圖，請務必跑出來看
- **章節依賴**：第 1–2 章是微分幾何入門，第 3–5 章是向量微積分與形式（皆為第 7–8 章的預備），第 9–10 章是相對論應用
- 趕時間的讀者：2 → 3 → 5.4 → 7 → 8 → 10.3 這條主軸可直達史瓦西解

## 需要的背景知識

- 一元微積分（紮實程度）與基本的多元微積分概念
- 線性代數基礎（矩陣、行列式）—— 第 6–8 章會用到張量的矩陣語言
- 不需要拓樸或流形先驗知識 —— 第 6 章會從直覺教起
- 程式只需要 Python/SymPy 基礎（本系列《用 SymPy 學數學》第 1–5 章程度）
