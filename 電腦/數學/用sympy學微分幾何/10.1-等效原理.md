## 電梯思想實驗

1907 年，Einstein 在專利局上班時，自稱想起「一生中最快樂的想法」：

> 一個從屋頂自由落下的人，在下落過程中不會感覺到自己的重量。

想像兩個封閉的「艙」：

- **艙 A** 在地球表面的火箭發射台上靜止，艙內一切物體受到向下的力 $`mg`$ ，以 $`g = 9.8\,\mathrm{m/s^2}`$ 加速下落。
- **艙 B** 是深空中以 $`a = 9.8\,\mathrm{m/s^2}`$ 向上加速的火箭，艙內物體相對火箭以同樣的加速度「落向地板」。

艙內的觀察者（看不到外面）無論做任何實驗，都**無法區分**自己是在重力場中靜止，還是在加速度中。這就是等效原理的原始形式：

$$
g \;=\; a
$$

把這個思想反過來：如果你在一部斷纜的電梯裡自由下落，電梯內所有物體都以相同的加速度下落——相對於你，**重力消失了**。你在電梯內扔一支筆，它就靜靜浮在眼前。這就是「局部慣性系」：沿著自由落體的世界線，重力可以在一點鄰域內被「消掉」。

在幾何語言（第 8 章）中，這正是：

$$
\Gamma^\mu_{\alpha\beta} \xrightarrow{\ \text{選自由落體座標}\ } 0 \quad \text{在一點上}
$$

我們在第 2 章學過：Christoffel 記號不是張量，總能選座標在一點使它們全部為零——但曲率 $`R^\rho{}_{\sigma\mu\nu}`$ 是張量，消不掉。**重力可以局部消除，潮汐力（曲率）不能。** 這一句話就是廣義相對論的種子。

## 重力質量 = 慣性質量

等效原理之所以成立，依賴一個實驗事實：

$$
m_g = m_i
$$

其中 $`m_g`$ 是出現在 $`F = m_g g`$ 中的重力荷， $`m_i`$ 是出現在 $`F = m_i a`$ 中的慣性。在本悼斥力學（第 0 章）裡這兩個量定義完全不同，卻在實驗中精確相等：

| 實驗 | 年代 | 精度 $`\Delta(m_g/m_i)`$ |
|---|---|---|
| Newton 擺 | 1687 | $`\sim 10^{-3}`$ |
| Bessel 擺 | 1832 | $`\sim 10^{-5}`$ |
| **Eötvös 扭秤** | 1889 | $`\sim 10^{-9}`$ |
| Dicke–Roll–Krotkov | 1964 | $`\sim 10^{-11}`$ |
| Eöt-Wash 扭秤 | 2008 | $`\sim 10^{-13}`$ |
| MICROSCOPE 衛星 | 2022 | $`\sim 10^{-15}`$ |

Eötvös 的巧思：若 $`m_g/m_i`$ 因材料不同而異，地球自轉產生的離心力與重力的比值會因材料而不同，懸掛的扭秤就會受到一個指向東西方向的扭矩。實驗結果：**沒有觀測到任何差異**。

這個「巧合」在 Newton 力學裡無法解釋，Einstein 把它升格為原理：重力與慣性是同一件事的兩面——彎曲時空中自由運動的表現。

## 重心一擊：重力使光彎曲

等效原理的第一個可觀測推論：**光也會「下落」**。

設想加速火箭中的一道光從左牆射向右牆。光穿越艙需要時間 $`\Delta t = L/c`$ ，這段時間內火箭上升了 $`\Delta y = \frac{1}{2} a (\Delta t)^2`$ 。在艙內觀察者看來，光的軌跡向下彎了一個拋物線：

$$
\Delta y = \frac{1}{2} g \left(\frac{L}{c}\right)^2
$$

由等效原理，同樣的事必發生在靜止於重力場中的艙。所以**重力場中的光會向下彎**。

1915 年 Einstein 用完整廣義相對論計算太陽附近光的偏折角（一半來自等效原理的「時間彎曲」，一半來自「空間彎曲」）：

$$
\Delta\theta = \frac{4GM}{c^2 R_\odot} \approx 1.75''
$$

1919 年 5 月 29 日日全食，Eddington 率隊遠赴普林西比島與 Sobral 觀測，太陽背面的恆星視位置偏了約 $`1.75''`$ ——紐約時報頭版寫著「牛頓已被推翻」。那是 Einstein 的一夜成名。

**動手算**：沒有廣義相對論也行，等效原理+牛頓近似會給出一半的值：

```python
import sympy as sp

G, M, c, R = sp.symbols('G M c R', positive=True)
# Newton 近似：光子以「等效質量」m_E = E/c^2 通過太陽邊緣
# 動量改變的橫向分量積分 => 偏折角
delta_half = 2*sp.G*M/(c**2*R)      # 半徑處的光速拋物線近似的一半
delta_full = 4*sp.G*M/(c**2*R)      # 廣義相對論完整值
Ms, Rs = 1.989e30, 6.957e8          # 太陽質量、半徑 (SI)
Gv, cv = 6.674e-11, 2.998e8
angle = delta_full.subs({M: Ms, R: Rs, c: cv, G: Gv}) * 206265  # 轉角秒
print(angle)                        # ≈ 1.75 角秒
```

## 重力紅移：等效原理的另一個推論

再看一個思想實驗：在加速火箭中，底部（ $`z=0`$ ）的燈每 $`T`$ 秒發一個光脈衝，頂部（ $`z=h`$ ）的接收器。因為火箭在加速，光在飛行時間 $`h/c`$ 內速度又增加了 $`gh/c`$ ，頂部相對底部有微小速度差，由 Doppler 效應：

$$
\frac{\Delta \lambda}{\lambda} = \frac{v}{c} = \frac{gh}{c^2}
$$

由等效原理，靜止在地球重力場中的同樣配置（頂端為「上」，底端為「下」）也會觀測到：**光爬出重力場時被拉長（紅移），掉入重力場時被壓縮（藍移）**——這就是重力紅移，等效原理就能推出，不需要任何新數學：

$$
\boxed{\ \frac{\Delta\lambda}{\lambda} = \frac{gh}{c^2}\ }
$$

用 SymPy 正式重算一遍（把火箭加速度問題 Uncle 兩次內插精確化）：

```python
import sympy as sp

g, h, c, v = sp.symbols('g h c v', positive=True)

# 火箭底部發光時其速度 v0，光到達頂部時火箭速度增加了 gh/c
v0 = v
v1 = v + g*h/c           # 相對論低階近似下的速度差（一階）
# Doppler：Δλ/λ ≈ Δv / c （一階非相對論）
doppler = (v1 - v0)/c
print(sp.simplify(doppler))          # g*h/c**2
```

結果正是 $`\frac{gh}{c^2}`$ 。1959 年 Pound–Rebka 在哈佛大學 22.5 m 高塔中用 Mössbauer 效應實測驗證：

```python
g_, h_, c_ = 9.8, 22.5, 2.998e8
print(f"Δλ/λ = {g_*h_/c_:.3e}")   # 约 2.45e-15
```

$`2.45\times 10^{-15}`$ ——這麼小的效應居然被測到了，而且與理論吻合到 10% 以內（後續實驗更佳）。等效原理不再是思想實驗，而是精密計量的對象。

## 動手實驗：GPS 時間修正的簡算

GPS 衛星在 $`h \approx 20{,}200`$ km 高空繞行，一天繞兩圈。狹義相對論（衛星速度 $`v\approx 3.87`$ km/s）使衛星鐘**變慢**；等效原理（從衛星到地面是「順著重力下落」）使衛星鐘（較高空，重力較弱）**變快**。兩者淨效應：

```python
import sympy as sp

G, M, c, h, R, v = sp.symbols('G M c h R v', positive=True)

# 重力效應（等效原理版）：Δf/f ≈ gh/c²（h 遠小於地球半徑時成立，
# 這裡直接用位能差：Δ(Φ)/c²，Φ = -GM/r）
dPhi_grav = G*M*(1/R - 1/(R+h))      # 位能差 per unit mass（正：高處位能高）

# 狹義相對論：Δf/f = -v²/(2c²)
sr = -v**2/(2*c**2)

net = (dPhi_grav/c**2 + sr)

# 代入地球參數
vals = {G: 6.674e-11, M: 5.972e24, R: 6.3781e6, h: 2.02e7,
        v: 3874.0, c: 2.998e8}
net_v = net.subs(vals)
print(f"淨效應 Δf/f = {float(net_v):.3e}")

# 一天的累積誤差
sec_per_day = 86400
drift = float(net_v)*sec_per_day*1e6   # 微秒
print(f"一天累積 ≈ {drift:.1f} μs")
```

粗算結果：重力效應每天使衛星鐘**快約 45.7 μs**，狹義效應**慢約 7.2 μs**，淨**快約 38.5 μs/天**；光速 30 cm/ns，一天 38 μs 對應約 11 km 的定位誤差。若沒有相對論修正，GPS 幾小時後就會飄掉——日常科技驗證了等效原理。

## 小結與練習

本節要點：

- 等效原理：局部（一點）上重力可以複歸為加速度，也可被自由落體座標消去；不可消去的是曲率（潮汐力）。
- 重力質量 = 慣性質量，精度已達 $`10^{-15}`$ （MICROSCOPE 衛星）。
- 可觀測推論：光偏折（1919 Eddington）、重力紅移 $`\Delta\lambda/\lambda = gh/c^2`$ （Pound–Rebka）。
- GPS 每天 38 μs 的鐘差是相對論在日常科技的印證。
