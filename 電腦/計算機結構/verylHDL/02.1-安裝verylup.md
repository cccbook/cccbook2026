# 安裝 verylup

要開始使用 Veryl，第一件事不是安裝 Veryl 本身，而是安裝它的版本管理器 verylup。這個順序本身就有故事：Veryl 從 Rust 生態學來的第一課，就是工具鏈必須可版本化管理。

## 為什麼需要版本管理器

回想 Rust 生態的 rustup：Rust 語言每年釋出新版本，不同專案可能依賴不同版本，團隊成員與 CI 機器的編譯器版本必須完全一致，否則同一份程式碼可能出現不同的編譯結果。rustup 用「toolchain」的概念解決這個問題：全域有預設 toolchain，每個專案可以用設定檔釘選特定版本，`rustup` 負責下載、安裝、切換。

Veryl 面對完全相同的問題。Veryl 的語言與工具仍在活躍演化中，不同版本對同一份原始碼的轉譯輸出可能有差異；團隊如果各裝各的版本，就會出現「我這裡編譯會過、你那裡會錯」的經典爭執；CI 若不釘版本，昨天綠的 pipeline 今天可能就紅了。verylup 因此照著 rustup 的模式設計：它管理 veryl 的多個 toolchain，提供 stable 與 nightly 兩種通道，讓團隊可以用最少的設定保證每台機器上的 veryl 完全一致。這是版本管理器存在的根本理由：可重現性（reproducibility）不是奢侈品，而是工程協作的基礎設施。

## 安裝 verylup

在類 Unix 系統（Linux、macOS）上，官方推薦的一行安裝指令是：

```console
$ curl -L https://veryl-lang.org/install | sh
```

這個 script 會下載 verylup 的執行檔並安裝到使用者的工具目錄中，安裝完成後把對應的 `bin` 目錄放進 `PATH`（大多數環境會自動處理，必要時重新登入或修改 shell 設定）。如果你是 Rust 開發者、機器上已有 cargo，也可以直接從 crates.io 編譯安裝：

```console
$ cargo install verylup
```

兩種方式的結果相同：系統裡多了一個 `verylup` 指令。Windows 使用者可從 GitHub releases 下載安裝程式，這裡不展開。

## 安裝 veryl toolchain

verylup 裝好之後，安裝 veryl 本體只需要一條指令：

```console
$ verylup install
```

這會下載目前 stable 通道的最新 veryl 並設為預設。想嘗試開發中的新功能，可以安裝 nightly：

```console
$ verylup install nightly
$ verylup use nightly
```

`verylup use` 切換預設 toolchain，概念與 rustup 完全相同。之後你敲的每一個 `veryl` 指令，實際上都由 verylup 代為分派到目前選定的 toolchain——這也是為什麼 verylup 必須先裝：它是所有 `veryl` 指令的入口。

安裝完成後驗證一下：

```console
$ veryl --version
```

能看到版本號輸出，代表 veryl 已就緒。

## 專案層級的版本釘選

verylup 支援在專案中釘選 toolchain，機制與 rustup 的 `rust-toolchain` 檔案類似：在專案根目錄放置對應的設定檔、寫入如 `stable` 或特定版本號，之後在該目錄下執行 veryl 指令就會自動使用釘選的版本。把這個檔案提交進版本控制，團隊所有人與 CI 就自動得到同一個版本的 veryl——這是「工具鏈即程式碼」的最小實踐。具體檔名與語法隨 veryl 版本可能有異動，使用時以官方文件為準。

## 更新與解除

日常維護只需要少數幾條指令：`verylup update` 更新目前 toolchain 到最新；`verylup show` 查看已安裝的 toolchain 列表。整個工具的設計哲學就是 rustup 的鏡像，熟悉 Rust 的讀者不需要重新學習。

## 本章小結

- verylup 是 veryl 的版本管理器，模仿 rustup 的 toolchain 模型，提供 stable/nightly 通道。
- 安裝：`curl -L https://veryl-lang.org/install | sh`，或 `cargo install verylup`。
- `verylup install` 安裝 veryl，`verylup use` 切換版本。
- 專案可釘選 toolchain，保證團隊與 CI 的版本一致性與可重現性。
- 版本管理器解決的是工程協作的基礎問題，而非單純的安裝便利性。
