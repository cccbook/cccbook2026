# 計算機結構入門

一本強調「技術與理論前因後果、互相驅動關係」的計算機結構教科書。全書以歷史脈絡串起軟硬體介面的核心概念：從圖靈機的可計算性，到馮紐曼架構、指令集設計之爭、流水線微架構、記憶體階層，直到多核心、GPU 與領域特定架構的現代發展。
