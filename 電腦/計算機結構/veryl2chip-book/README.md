# 從 HDL 到晶片：EDA 原理與 veryl2chip 實作

一本講解 EDA（電子設計自動化）核心原理的書，並以本專案 veryl2chip 的 Rust 原始碼作為貫穿全書的實作案例。
本書不是使用手冊（使用手冊見 `manual/`），而是深入「為什麼這樣做、演算法怎麼寫、資料結構長什麼樣」。

全書分六篇：

* **第 1 章** 導論：EDA 在做什麼、veryl2chip 的整體架構。
* **第 2 章** 前端：解析與模擬（veryl-sim 的世界）。
* **第 3 章** 中端：綜合（veryl-eda 的核心：符號執行 → 閘級網表 → 最佳化）。
* **第 4 章** FPGA 後端：iCE40 / ECP5 映射、佈局繞線、位元流。
* **第 5 章** ASIC 後端：標準單元、實體設計、SKY130 PDK、GDS。
* **第 6 章** 進階主題：RISC-V SoC 與 C 編譯器、虛擬麵包板、Web/WASM。
