# 6.3 多重曝光：LELE、SADP 與 SAQP 的顏色分配問題

微影是半導體的畫筆，而這支畫筆的解析度有一道物理天花板。光學微影能印出的最小特徵大致受瑞利準則 $`CD = k_1 \dfrac{\lambda}{NA}`$ 支配：波長 $`\lambda`$ 越短、數值孔徑 $`NA`$ 越大，可解析的線寬越細。1990 年代末，業界以 193nm ArF 準分子雷射為主力光源，本以為接下來會跳到 157nm F2 雷射，但 157nm 的材料問題（氟化鈣透鏡、光阻）遲遲無解，加上解析度增強技術（浸潤式微影、off-axis illumination、OPC）不斷榨出餘裕，業界做出關鍵決定：留在 193nm，把 NA 推到浸潤式的水橋極限約 1.35，然後——把同一層印兩次甚至四次。這就是多重曝光（multi-patterning）。

最直觀的形式是 LELE（litho-etch-litho-etch）：第一道光印出一組圖形並蝕刻進硬質遮罩，第二道光對準後印出另外一組，兩組交錯合成最終圖形。它把「畫不出的細線」拆成「畫得出、錯得開」的兩組線。但 LELE 對套疊精度（overlay）極為敏感：兩次曝光之間的錯位直接造成線寬變異與橋接。更精緻的解法是 SADP（self-aligned double patterning，自我對準雙重圖形）：先用第一道光印出心軸（mandrel），在心軸兩側以沉積加回蝕的方式長出間隔層（spacer），去掉心軸後，spacer 本身成為光罩，一次製程就得到間距減半的圖形。因為 spacer 是從既有圖形「長」出來的，它天生對準，避開了 overlay 問題；代價是圖形拓撲受限——SADP 擅長規律的線陣列，處理線端與切斷需要額外的 cut/block mask。把 SADP 再做一輪，就是 SAQP，可達四倍壓縮。

20nm 世代，金屬層普遍採用 LELE 或 SADP；16/14nm 的 fin 與閘極層走上 SADP；10nm 世代的閘極與部分金屬層進入 SAQP。整個 2010 年代，先進晶片就是在 193nm 浸潤式機台的多重曝光之上蓋出來的，直到 2019 年前後 EUV（13.5nm）在 7nm 以下量產，single-exposure 才部分回歸。這段歷史裡 EUV 的姍姍來遲（原訂 2009 年前後導入，實際晚了近十年）正是 multi-patterning 存在的原因：經濟上，多買幾道光罩與多跑幾次機台，比等待不成熟的新光源便宜。

而多重曝光把一個新的計算問題丟給了設計端：coloring（著色）。以 LELE 為例，所有在同一層的圖形必須被分配到兩道光罩之一，分配的約束是「靠得太近的兩個圖形不能同色」——否則它們會在光阻上成為相連或過度接近的圖形，無法分開蝕刻。這在數學上是一張衝突圖（conflict graph）的 2-coloring 問題：節點是版圖圖形，若兩圖形間距小於 single-exposure 可解析的下限則連一條邊；若衝突圖不能二著色，就產生 conflict（無解），必須靠 stitch（在同一圖形上切一刀，讓它分屬兩個 color 並在製程中接合）來救，而 stitch 又引入新的 edge placement error 風險。SADP 更苛刻：它本質上把圖形約束成柵欄結構，任意方向的 T 形與橋接都可能不可分解，還要分配 cut mask 的位置，使 colorable 問題變成多光罩的組合最佳化。

EDA 的回應是一整條 tool chain：litho checking（辨識違反 single-exposure 間距的 edge）、layout decomposition（把 layout 分解成各道光罩，求解 coloring，必要時插入 stitch）、分解後的 mask-level OPC、以及分解結果與 DRC 的整合簽核。coloring 是 NP-hard 級的組合問題，商業工具靠圖分割、整數規劃與啟發式策略在數億個圖形上求近似解。但更有效的介入點在更上游：coloring-aware routing。既然繞線工具知道「相鄰平行線段必須異色」，它就能在布線時直接避開衝突，例如把同層相鄰的線段在適當位置跳層或錯開線端，讓後段的 decomposition 幾乎不需要 stitch。Cadence、Synopsys 與 Siemens 在 20nm 世代都把 multi-patterning 的約束內建進 router 與 DRC，使 colorless DRC（不考慮分解的設計規則）過關的版圖仍然可能在分解時失敗，因此業界發展出 MPT-compliant 的規則檔與檢查流程。

多重曝光的經濟後果同樣深遠。每多一道曝光，就多一張光罩（LELE 兩張、SAQP 加 cut 可達五、六張），光罩費用從 28nm 的百萬美元量級漲到 10nm 的八位數；晶圓的機台時間也成倍增加，直接推高了先進節點的 wafer cost。這是摩爾定律的經濟學第一次被「畫圖」而非「做元件」的成本反噬，也構成了 7nm 以下轉向 EUV 的財務動機。對台灣產業而言，這段時期正是台積電以浸潤式多重曝光在 16nm 打下根基、並在 7nm 前後與 EUV 無縫接軌的關鍵窗口。教育與人才結構也隨之改變：懂得 litho 物理的版圖工程師、寫得動 coloring 演算法的 EDA 工程師，成為兩個原本不相干的行業裡同時搶人的稀缺資源。顏色分配這個聽來童話的問題，實際上是二十一世紀第二個十年裡，決定一顆晶片能不能量產、要花多少錢的核心難題。
