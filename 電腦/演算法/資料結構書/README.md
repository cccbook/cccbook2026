## 學習建議

1. 全書範例皆可獨立執行（Python 3.8+），請邊讀邊跑。
2. 每章末的練習題建議全數完成，多數答案即為程式碼修改。
3. 建議按章節順序閱讀：第2~4章為基礎，第5~7章為核心，第8~9章為進階應用，第10章總結設計思維。
