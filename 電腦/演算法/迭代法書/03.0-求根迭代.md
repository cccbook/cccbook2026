# 第3章 求根迭代

## 章前言

解方程 $f(x) = 0$ 是科學計算最古老也最普遍的任務：電路的穩態、化學平衡濃度、軌道力學、金融隱含波動率，最後都落到「找根」。多項式有公式解，但五次以上沒有；大多數真實模型的 $f$ 連解析反函數都不存在——此時迭代法是唯一選擇。

本章介紹三種經典求根法，構成一條清晰的權衡光譜。**二分法**（3.1）最保守：只要求 $f$ 連續且兩端異號，線性收斂但絕對可靠，是所有穩健求根器的最後防線。**牛頓法**（3.2）最快：利用切線外推，平方收斂，數步內榨乾浮點精度，但需要導數、且可能發散或跳到別的根。**割線法**（3.3）居中：用兩點割線取代切線，免導數、收斂階 1.618；我們還會介紹把牛頓法的速度與二分法的保證合在一起的**Dekker/Brent 混合策略**——這正是 Python `scipy.optimize.brentq` 背後的演算法。

學完本章，你應能針對問題回答：導數好求嗎？有沒有可靠夾根區間？要多少精度？——並據此選出合適的方法。
