# 第 1 章 電腦與數學

數學是人類最古老的抽象學問，而電腦則是最年輕的計算工具。當這兩者相遇，誕生了「數學演算法」這門兼具理論之美與實用價值的領域。本章是全書的地基：我們將先認識電腦「眼中的」數學世界——它如何表示數、如何執行四則運算、又會在哪裡遭遇人類直覺想像不到的陷阱。

本章分三節。1.1 節從最根本的問題出發：電腦如何做數學？我們會看到電腦的一切計算最終都化約為位元運算，並介紹演算法思維如何把數學問題轉成明確的計算步驟。1.2 節探討浮點數與捨入誤差——這是每個寫程式的人都踩過的坑，例如 `0.1 + 0.2 != 0.3`。理解 IEEE 754 的表示方式與誤差傳播，是寫出可靠數值程式的第一步。1.3 節則介紹大整數與精確計算：Python 的整數沒有溢位問題，`decimal` 模組能做精確十進位運算，而模運算技巧更是處理巨大數字的關鍵武器。

讀完本章，你將建立一個核心觀念：電腦做數學時，必須時時區分「數學上的精確答案」與「計算上的近似答案」。後續章節的每一個演算法，都會在這條光譜上找到自己的位置——有些演算法追求完全精確（如大數運算、精確消去），有些則在誤差可控的前提下換取速度（如牛頓法、蒙地卡羅法）。帶著這個眼光，你才能真正讀懂每一章背後的取捨。
