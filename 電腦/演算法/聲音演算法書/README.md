# 聲音演算法

本書以繁體中文系統性地介紹聲音（音訊）處理的核心演算法，從數位訊號基礎、時域與頻域分析、濾波器設計，一路走到特徵提取、音訊壓縮、語音處理、音樂資訊檢索、音效處理，最後談到現代聲音 AI。每節均包含概念說明、演算法步驟、可執行的 Python 範例（numpy）、複雜度分析與練習題，適合大學課程與自學者使用。
