# 第3章 頻域分析

時域告訴我們聲音「何時」發生，頻域則告訴我們聲音「由哪些頻率組成」。把訊號從時間軸搬到頻率軸的鑰匙，就是傅立葉轉換。可以說，現代音訊處理的九成應用——從 MP3 壓縮、等化器、語音辨識到聲源分離——都建立在頻域分析之上。

本章由三個層次遞進。首先從傅立葉級數的直覺出發，導出離散傅立葉轉換（DFT）的定義與其對稱、線性、摺積等重要性質，理解「頻譜」到底是什麼。接著進入演算法的重頭戲：快速傅立葉轉換（FFT）。我們將推導 Cooley–Tukey 分治法，展示 O(N²) 如何奇蹟般降到 O(N log N)，甚至親手寫一個遞迴式的 FFT 與 numpy 的實作對照。最後介紹短時距傅立葉轉換（STFT）與窗函數，學會處理「頻率會隨時間變化」的真實聲音，並以文字頻譜圖視覺化一段掃頻訊號與語音式的合成訊號。

掌握本章之後，「看見聲音」對你而言就不再是比喻，而是一張張可以計算、比較、加工的矩陣。
