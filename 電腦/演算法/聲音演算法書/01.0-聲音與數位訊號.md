# 第1章 聲音與數位訊號

聲音是空氣壓力的波動，是自然界最普遍的資訊載體之一。當我們把聲音送進電腦，第一個面對的問題就是：如何把連續的物理波形變成離散的數字？這個問題的答案構成了整本書的地基——取樣（sampling）與量化（quantization）。

本章從聲音的物理性質談起，說明頻率、振幅與波形如何對應到人耳聽到的音調、音量與音色；接著介紹類比數位轉換（ADC）與數位類比轉換（DAC）的原理，並嚴謹地推導奈奎斯特取樣定理，說明為什麼取樣率不足會產生「混疊」這種不可逆的失真。最後我們討論量化的數學：位元深度如何決定動態範圍與訊噪比，dither 又如何用加一點雜訊來換取更好的聽感。

學完本章，你將能夠用 numpy 從零合成一個純音、檢驗混疊現象、並計算不同位元深度下的量化雜訊。這些看似簡單的練習，其實是後面所有章節——從 FFT 到神經網路聲學模型——共同依賴的基本功。
