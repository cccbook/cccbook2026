# 蒙地卡羅法：原理、數值技術與跨領域應用

> 本書以「為什麼需要這個技術 → 它如何解決前一方法的缺陷 → 它又引發什麼新問題」為主軸，
> 從蒙地卡羅法的歷史起源出發，一路貫穿基本概念、隨機數生成、積分法、變換抽樣、平行與 GPU 加速、
> 隨機過程模擬、物理與金融應用、誤差分析，到機器學習與未來展望。
