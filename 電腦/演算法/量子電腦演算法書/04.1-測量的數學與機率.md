# 4.1 測量的數學與機率

## 概念說明

**Born 規則**：量子態 $|\psi\rangle$ 對基底 $\{|i\rangle\}$ 測量，得到結果 $i$ 的機率為

$$P(i) = |\langle i|\psi\rangle|^2 = |\psi_i|^2$$

測量後狀態**塌縮**為 $|i\rangle$ 。對一般可觀測量（Hermitian 算子 $M$ ，本徵態 $\{|i\rangle\}$ 、本徵值 $\lambda_i$ ），期望值為

$$\langle M\rangle = \langle\psi|M|\psi\rangle = \sum_i |\psi_i|^2 \lambda_i$$

**部分測量**：對 $n$ 位元系統只量第 $k$ 位。設振幅 $a_x = a_{x,0}$ （第 $k$ 位為 0）與 $a_{x,1}$ （第 $k$ 位為 1），則

$$P(0) = \sum_x |a_{x,0}|^2, \qquad P(1) = \sum_x |a_{x,1}|^2$$

量得 0 後，其餘位元的狀態變成（重新正規化的）條件態： $\psi'_{x,0} = a_{x,0}/\sqrt{P(0)}$ 。這就是「測量一個位元會影響與它糾纏的其他位元」的數學表現。

**干涉的來源**：機率不是直接相加—— $\left|\sum_i \psi_i\right|^2$ 有交叉項，正是振幅之間的干涉。量子演算法設計的核心就是控制這些交叉項的正負。

## 演算法步驟（模擬部分測量）

1. 由振幅計算目標位元的 $P(0)$ 、 $P(1)$ 。
2. 依機率抽樣決定測量結果。
3. 依結果把狀態向量投影並重新正規化。

## Python 範例

```python
import numpy as np

def partial_measure(state, n, k, result=None, rng=None):
    """測量第 k 位（0=最低位），回傳 (結果, 新狀態)"""
    rng = rng or np.random.default_rng()
    idx0 = np.array([i for i in range(2**n) if (i >> k) & 1 == 0])
    idx1 = np.array([i for i in range(2**n) if (i >> k) & 1 == 1])
    p0 = np.sum(np.abs(state[idx0])**2)
    if result is None:
        result = int(rng.random() > p0)
    target = idx0 if result == 0 else idx1
    new = np.zeros_like(state)
    new[target] = state[target] / np.sqrt(p0 if result == 0 else 1 - p0)
    return result, new

# 範例 1：|+> 的測量
plus = np.array([1, 1], dtype=complex) / np.sqrt(2)
r, collapsed = partial_measure(plus, 1, 0, result=0, rng=np.random.default_rng(0))
print("量得", r, "塌縮為", collapsed)   # |0>

# 範例 2：Bell 態的部分測量
bell = np.zeros(4, dtype=complex); bell[0] = bell[3] = 1/np.sqrt(2)
r, new = partial_measure(bell, 2, 1, result=1, rng=np.random.default_rng(0))
print("量第一個位元得 1 後，狀態 =", new)   # 恰是 |11>：另一位元被決定為 1

# 範例 3：期望值 <Z>
Z = np.diag([1, -1]).astype(complex)
psi = np.array([1, 1], dtype=complex) / np.sqrt(2)
print("<Z> =", psi.conj() @ Z @ psi)     # 0：|+> 沒有確定的 z 值
```

## 複雜度分析

部分測量需掃描全部振幅計算 $P(0)$ ： $O(2^n)$ ；投影與正規化亦 $O(2^n)$ 。對整個系統測量則只是按 $|\psi_i|^2$ 抽樣， $O(2^n)$ 建表、每次抽樣 $O(\log 2^n)$ 。 $S$ 次重複實驗（shot）總成本 $O((m+S)\,2^n)$ 。

## 練習

1. 對 GHZ 態 $\frac{|000\rangle+|111\rangle}{\sqrt2}$ 測量第一個位元得 0，寫出其餘兩位元的塌縮狀態。
2. 計算 $|\psi\rangle = \frac{\sqrt3}{2}|0\rangle + \frac{1}{2}|1\rangle$ 的 $\langle Z\rangle$ 與 $\langle X\rangle$ （ $X$ 的本徵向量為 $|\pm\rangle$ ）。
3. （程式）用 `partial_measure` 對 Bell 態分別量第一位元與第二位元，驗證兩者結果永遠相同；再對 $\frac{|00\rangle+|11\rangle}{\sqrt2}$ 與均勻混合分佈 $[0.5,0,0,0.5]$ 比較，說明為什麼「經典相關」與「糾纏」不同。
