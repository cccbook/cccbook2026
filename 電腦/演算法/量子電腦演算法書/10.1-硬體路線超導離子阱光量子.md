# 10.1 硬體路線：超導、離子阱、光量子

## 概念說明

量子位元的候選物理載體很多，本節比較三條主流路線與兩條新興路線。

**1. 超導量子位元**（IBM、Google、Intel）

- 原理：約瑟夫森結（Josephson junction）構成的非線性 LC 振盪電路，在毫開爾文低溫下有兩個能階可當量子位元；用微波脈衝操作。
- 優勢：閘速度快（~20-50 ns）、與半導體製程相容、易於大規模平面佈局。IBM 已達 1000+ 位元（Condor）。
- 劣勢：需要稀釋冷凍機（ $T \approx 10$ mK）；位元間連線受限（近鄰耦合）； $T_1 \sim 100\,\mu s$ 相對短；每位元都要一條控制線，接線是工程瓶頸。

**2. 離子阱**（IonQ、Quantinuum、Oxford Ionics）

- 原理：電磁阱囚禁帶電原子（如 $\mathrm{^{171}Yb^+}$ ），用雷射做閘；量子資訊存在離子的電子能階。
- 優勢：保真度最高（雙位元閘 >99.9%）、 $T_1/T_2$ 長（分鐘級）、全連接（任何兩個離子都能糾纏）。
- 劣勢：閘慢（~100 µs–ms）、離子鏈長度受限（需 ion shuttling 或模組化）、真空與雷射系統複雜。Quantinuum H2 曾創下量子體積（quantum volume）紀錄。

**3. 光量子**（Xanadu、PsiQuantum）

- 原理：單光子的路徑/偏振/壓縮態做量子位元，線性光學＋測量誘導糾纏（cluster state）。
- 優勢：室溫運作（偵測器除外）、天然適合通訊與網路、製程可借力光電產業。
- 劣勢：光子不易相互作用（雙位元閘要靠測量與機率性資源）、單光子源與探測器的效率/損耗是關鍵。

**新興路線**：

- **中性原子**（QuEra、Pasqal）：光鑷陣列囚禁里德堡原子，可程式化的任意拓撲、快速擴展（已達千位元級），2023 年實現 48 邏輯位元糾錯。
- **矽自旋**（Intel、QuTech）：與 CMOS 完全相容，位元極小（~50 nm），但雜訊與均勻性仍在改進。

**比較指標**：保真度、連接性、速度、可擴展性、運行環境（溫度/真空）。沒有單一贏家——業界共識是「容錯時代可能由多種平台混合」。

## Python 範例：畫出平台特性雷達圖資料

```python
import numpy as np

platforms = {
    "超導":    dict(保真度=3, 速度=5, 連接性=2, 擴展性=4, 環境難度=2),
    "離子阱":  dict(保真度=5, 速度=2, 連接性=5, 擴展性=2, 環境難度=3),
    "光量子":  dict(保真度=3, 速度=4, 連接性=2, 擴展性=4, 環境難度=4),
    "中性原子": dict(保真度=4, 速度=3, 連接性=3, 擴展性=5, 環境難度=4),
    "矽自旋":  dict(保真度=3, 速度=4, 連接性=2, 擴展性=5, 環境難度=3),
}
print(f"{'平台':<6}" + "".join(f"{k:<8}" for k in next(iter(platforms.values()))))
for name, scores in platforms.items():
    print(f"{name:<6}" + "".join(f"{v:<8}" for v in scores.values()))
# 說明：1~5 分。沒有平台在所有維度都高——這是硬體「路線之爭」的本質。

# 閘速度與 T1 的數量級比較
data = [("超導", 50e-9, 100e-6), ("離子阱", 200e-6, 1e3),
        ("中性原子", 1e-6, 10e0), ("矽自旋", 100e-9, 1e-3)]
print("\n平台       雙閘時間     T1/T2")
for name, tg, t1 in data:
    print(f"{name:<8}  {tg:>8.1e} s   {t1:>8.1e} s")
print("\n超導 1 秒可做 ~2 萬個閘，但 T1 只有 0.1 ms —— 趕在退相干前算完是主要挑戰")
```

## 複雜度分析

工程上的「可擴展性」量化：要跑 Shor（2048 位元 RSA）需要約 $2\times10^7$ 物理位元與 $10^{11}$ 個容錯閘。以超導的 20 ns 閘速， $10^{11}$ 閘約需 35 分鐘（理想並行下）；離子阱的 100 µs 則需 4 個月——**閘速度直接決定大型演算法的可行性**，這解釋了為何各路線都在往更快、更並行發展。
