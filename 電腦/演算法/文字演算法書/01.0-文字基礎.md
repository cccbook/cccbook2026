# 第1章 文字基礎

文字是電腦最早處理、也是最普遍的資料形式之一：從原始程式碼、網頁內容、電子郵件，到社群貼文與對話訊息，幾乎所有資訊都以文字承載。要有效處理文字，必須先理解文字在電腦中「如何被表示」——也就是字元、字串與編碼的原理。本章建立全書的基礎。

1.1 節介紹字串的表示方式與 ASCII、UTF-8 等編碼的原理，說明為什麼「長度」與「位元組數」不是同一件事；1.2 節聚焦中文處理的特殊議題，包括繁簡轉換、異體字、全半形與正規化；1.3 節介紹正規表示式這套強大的文字模式語言，它是後續許多演算法實作時不可或缺的工具。

學完本章，讀者應能正確處理中英混合文字、避免常見的編碼錯誤，並能用正規表示式進行搜尋與替換，為第2章以後的字串演算法鋪路。
