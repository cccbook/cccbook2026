# 第1章 密碼學導論

歡迎來到密碼學的世界。這一章不會教你任何具體的加密演算法，但會建立貫穿全書的觀念框架：密碼學到底在解決什麼問題？一個保密系統由哪些部分組成？什麼樣的系統才算「安全」？

我們將從人類幾千年的保密歷史說起——從凱薩的戰場密令到二次大戰的 Enigma，再到今日保護你每一次上購物網站的 TLS。歷史不只是故事，它一再重複同一個教訓：依賴「敵人想不到」的設計遲早被破解，唯有依賴公開、經過檢驗的數學難題的設計才能長久。

接著我們定義密碼學的基本模型（明文、密文、金鑰、加解密）與攻擊者模型，最後說明現代密碼學的憲法——Kerckhoffs 原則——以及計算安全、無條件安全、完美保密等安全觀念。這些觀念將幫助你在後續章節判斷：一個演算法是「真的安全」還是只是「看起來安全」。

學完本章，你應該能回答三個問題：密碼學的四個核心目標是什麼？為什麼要把加密方法公開？「計算上不可行」是什麼意思？
