# 第2章 古典密碼

在電腦問世之前，人類用紙筆與機械保護訊息長達兩千年。這一章我們親手實作三個代表性的古典密碼：凱薩移位密碼、多表替代的維吉尼亞密碼，並以程式重現「頻率分析」這個讓古典密碼全面崩潰的破密技術。

古典密碼最大的價值不是拿來使用（它們早已全數不安全），而是作為學習密碼分析的**最佳教具**：它們規模小、可以用人工驗證，能讓你完整走過「觀察統計特徵 → 形成假設 → 驗證 → 破解」的破密流程。這套思路正是現代密碼分析的原型。

我們也會介紹 Enigma——機械時代的巅峰之作，它把古典多表替代推到極致，卻仍敗在「金鑰使用的程序錯誤」與「可預測的訊息格式」上，再次印證第 1 章的教訓：安全取決於整個系統，而不只是演算法本身。
