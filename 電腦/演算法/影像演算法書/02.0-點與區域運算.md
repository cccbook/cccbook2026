# 第2章 點與區域運算

點運算是影像處理中最簡單也最常用的一類操作：輸出像素的值只由「同一位置」的輸入像素決定，與鄰居無關。亮度、對比、反相、gamma 校正都屬於這一類，它們的共同數學形式是對映函式 s = T(r)。由於每個像素獨立處理，點運算的複雜度永遠是線性的 O(N)，而且天然適合平行化。

本章從最直覺的亮度與對比調整出發，引入直方圖這個強大的統計工具——它是影像的「簽名」，能一眼看出曝光與對比問題。接著把直方圖推到極致：直方圖等化利用累積分布函數，自動把對比不足的影像拉伸到滿動態範圍，這是「用機率觀點設計演算法」的經典範例。最後介紹二值化：把灰階影像壓成黑白兩色是文件處理、物件分割的第一步，而 Otsu 法示範了如何用類間變異數自動找出最佳門檻值，不需要人工調參。

這三節環環相扣：直方圖是語言，等化與 Otsu 是用它寫出的兩個漂亮演算法。學會本章，你對「影像即分布」的直覺就成形了。
