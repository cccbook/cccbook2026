# 神經網路與深度學習

本書是「人工智慧系列」四本書中的第一本（另三本為《智慧模型》、《強化學習》、《Agent 技術》）。

全書沿著 1943 年至今的神經網路演化史展開：**每一次突破都是為了解決前一代架構做不到的事**——感知器解不了 XOR，所以有多層網路；多層網路訓不動，所以有反向傳播；深層網路梯度消失，所以有殘差與正則化；RNN 記不住長程依賴，所以有 Attention；算力與框架成熟，才讓一切理論得以兌現。
