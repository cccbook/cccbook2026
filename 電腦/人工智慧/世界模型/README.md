# 世界模型：理解空間、物理與通用智慧架構

*World Models: Understanding Space, Physics, and Architectures for General Intelligence*

本書是「人工智慧系列」的第九本。前八本處理的是文字與聲音——**人類已經寫下來的符號**。但人類智慧真正依賴的，從來不是文字本身，而是**對世界的內部模型**：預測球落地後會彈多高、預判伸手能否握住杯子、在腦中排練尚未發生的動作。本書要處理的就是這個被 LLM 時代長期忽略、卻決定通用智慧上限的課題。

全書的主線是**一條貫穿的因果鏈**：

- **狀態是什麼？** → 從 MDP 到 POMDP，再到 Dreamer 的循環潛在狀態（第 1 章）→ 沒有可模擬的狀態，就沒有可規劃的世界
- **狀態必須有幾何** → 2D 像素不足以承載遮擋與持久性（第 2 章）→ 物體中心的槽位表徵是幾何一致性的前提
- **狀態必須遵守物理** → 直覺物理學先驗、碰撞與交互（第 3 章）→ 從相關性走向結構因果與反事實
- **如何生成未來？** → 三條架構範式的分岔：**自迴歸**（第 4 章）、**擴散**（第 5 章）、**JEPA 特徵預測**（第 6 章）→ 三者分別對應「像真的」、「不確定性」與「只要有用」
- **如何讓未來服從我的動作？** → 動作條件化、前後向動力學與多感官（第 7 章）→ 這是被動觀察永遠學不到的因果結構
- **如何在腦中排練？** → 測試時計算、MCTS 與 MPC（第 8 章）→ 把算力從訓練期搬到決策期
- **如何落地到軀體？** → VLA、數位孿生與 Sim-to-Real（第 9 章）
- **還差多少？** → 複合誤差、物理幻覺與通用世界模型的藍圖（第 10 章）
