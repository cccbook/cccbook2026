# 智慧模型：語言、影音與世界模型

本書是「人工智慧系列」四本書中的第二本（另三本為《神經網路與深度學習》、《強化學習》、《Agent 技術》）。

第一本書講「**器官**」——神經網路如何從感知器演化到 Transformer；本書講「**心智**」——用這些器官造出的各種智慧模型：語言模型、生成模型、影音模型、世界模型，以及它們之間互相驅動的歷史邏輯。

全書主線：**每一次模型範式的躍遷，都是為了解決上一代模型做不到的事**——n-gram 遇到稀疏性，所以有神經語言模型；神經語言模型遇到長程依賴，所以有 Attention；生成模型遇到模式崩塌，所以有擴散模型；純生成遇到物理幻覺，所以有世界模型；預訓練縮放遇到能力天花板，所以有推理模型。
