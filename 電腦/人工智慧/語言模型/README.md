# 語言模型的演化：從生成語法到超大語言模型、對齊、世界模型與智慧體協作

*The Evolution of Language Models: From Generative Grammar to LLMs, Alignment, World Models and Agent Collaboration*

本書是「人工智慧系列」的第八本。前幾本處理的是神經網路的算子、強化學習的演算法、博弈的搜尋、聲音的訊號表示；**語言模型是把這些零件組裝成「能思考、能推理、能行動」的完整系統的載體**，因此本書刻意走一條更長的時間軸：七十年。

全書的因果主線是**「記憶的存放位置」不斷遷移**：

- 語法規則存在於**人的心智**中（1957 生成語法）→ 機器只學會判斷句子是否合法，卻不會生成
- 機率存在於**計數表**中（n-gram）→ 稀疏性逼出平滑，逼出對稱性，逼出向量
- 意義存在於**分散式向量**中（Word2Vec）→ 靜態向量無法處理多義，序列模型登場
- 上下文存在於**注意力矩陣**中（Transformer）→ 讓「記憶」變成可微、可查詢的運算
- 能力存在於**權重**中（預訓練）→ 但權重不能學會「聽指令」與「拒絕有害」
- 意圖存在於**人類偏好**中（RLHF、DPO）→ 對齊帶來可控，也帶來代價
- 知識存在於**模型之外**（RAG、工具呼叫）→ 避免幻覺，也帶來檢索與延遲成本
- 推理發生於**測試時**（思維鏈、形式化證明）→ 把算力從訓練期搬到推論期
- 世界存在於**模型的內部狀態**中（世界模型）→ 讓「想像」成為可規劃的對象
- 行動存在於**迴圈**中（智慧體、多智慧體協作）→ 語言模型成為大腦，周圍長出感官與手腳
