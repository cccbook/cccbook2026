# 聲波的迴響：從傳統 DSP、語音辨識到生成式語音與多模態 AI 的聲音革命（深度技術版）

*Echoes of Sound: The Voice Revolution from Classical DSP and ASR to Generative Speech and Multimodal AI*

本書是「人工智慧系列」的第七本。聲音是繼文字之後第二個被深度學習徹底改寫的模態，而且它比影像更早面對「資料是連續的、序列極長、人類感知高度非線性」這三重難題。本書以數學嚴謹的方式，沿著一條因果鏈走完聲音 AI 的完整革命：

- **連續波形的數位化**（取樣、量化、壓擴）→ 它決定了後續一切模型能看見的資料形態
- **DFT/FFT 與 STFT** → 把波形變成機器可學習的時頻矩陣，以及 Gabor 極限下時間與頻率解析度的永恆取捨
- **聽覺刻度（Bark/ERB/Mel）** → 人耳的非線性感知被寫進濾波器組，MFCC 成為長達 40 年的特徵標準
- **貝氏決策 + HMM-GMM + Viterbi** → 1980-2010 年代的機率圖模型黃金期，以及它的瓶頸（人手工設計的特徵與狀態）
- **DNN-HMM 混血 → CTC → seq2seq → Whisper** → 對齊難題的三種解法（外狀態對齊、邊際化、注意力）
- **WaveNet 的自迴歸生成** → 1-bit 排序的精確但緩慢 → 逼出 FastSpeech 的非自迴歸革命 → VITS/HiFi-GAN 的對抗與流
- **神經音訊編解碼器與 RVQ** → 連續音訊離散化成 Token，聲音正式可用語言建模來生成（VALL-E、MusicGen）
- **串聯式 vs 原生全模態** → 延遲、情感與錯誤傳遞三痛點，如何被 Omni 模型一次解決

全書核心命題：**聲音 AI 的每一次躍升，都是「先解决特徵表示，再解决對齊，再解决生成效率，最後將離散化讓渡給語言模型」的循環**。
