# 解碼生命之形：蛋白質摺疊、AlphaFold 與人工智慧生物學革命

*Decoding the Shape of Life: Protein Folding, AlphaFold, and the AI Biology Revolution*

本書是「人工智慧系列」的第五本。前四本（《神經網路》、《智慧模型》、《強化學習》、《Agent 技術》）處理的是**認知的軟體面**；本書轉向**生命科學的物理面**，但使用的是同一套方法論：當一個領域的經典方法在 50 年內無法突破時，往往會出現一種新的資料表示與新的學習架構，把「不可能的搜尋空間」壓縮成「可解的推斷問題」。

全書的核心敘事是一條因果鏈：

- 蛋白質摺疊是列文索爾悖論（1969）揭示的**組合爆炸**問題 → 需要新的搜尋策略
- 摺疊漏斗（1995  formalized）與演化資訊提供**物理與資訊的雙重約束**
- 實驗技術（X 光 1912、NMR 1946、冷凍電子顯微鏡 1986/2013）長期無法跟上序列爆炸 → 需要**代理模型**
- AlphaFold 1（2018）證明深度網路可行但精度不足 → 關鍵在**輸入表示**
- Evoformer（2020）讓 MSA 表示與配對表示跨維度對話 → 演化資訊可以被深度挖掘
- 結構模組與 IPA（2020）讓網路直接操作**三維剛體幾何**，繞開了「先預測距離再轉座標」的瓶頸
- AlphaFold 3（2024）用擴散模型直接生成**原子坐標**，涵蓋蛋白質、核酸、配體、藥物
- 後 AlphaFold 時代：從「看見形狀」走向「預測動態與生命」
