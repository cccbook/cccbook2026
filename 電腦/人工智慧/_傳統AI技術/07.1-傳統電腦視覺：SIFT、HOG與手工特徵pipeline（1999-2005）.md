# 7.1 傳統電腦視覺：SIFT、HOG 與手工特徵 pipeline（1999-2005）

## 歷史背景

視覺是傳統 AI 最痛的傷口。1966 年 MIT 的夏日備忘錄（Minsky 師生「一個暑假連接攝影機到電腦」的著名軼事）天真地以為視覺是個學期作業；五十年後我們知道那是 AI 最難的問題之一。1970-80 年代，Marr 的三層理論（《Vision》, 1982：計算層—演算法層—實現層）與邊緣檢測、光流、主觀輪廓等研究建立了視覺計算的理論框架，但整個領域停在「幾何與物理啟發的底層處理」，離「辨識貓狗」還有幾個世紀的距離。

1990 年代的突破是**範式轉移的前奏**：從「重建三維場景」轉向「辨識與檢索」，而辨識的瓶頸被診斷為**表徵問題**——真實世界的影像有光照、視角、尺度、遮擋的巨大變化，像素本身毫無不變性。於是整個 1990-2000 年代的視覺工程都在做一件事：**手工設計具有不變性的局部特徵**。巔峰之作是 Lowe 的 **SIFT**（1999 年發表、2004 年完成版）與 Dalal-Triggs 的 **HOG**（2005），它們組成了完整的「手工特徵 pipeline」：檢測興趣點 → 計算局部描述子 → 匹配/編碼（BoVW）→ 分類（SVM，第 6 章）。

這個 pipeline 統治了 2000-2012 年的電腦視覺，在 ImageNet 2010-2011 年的最好成績（top-5 錯誤率 ~25%）被 2012 年的 AlexNet（16%）一次擊穿。本節要講清：手工特徵是怎樣的工程傑作、它為什麼必須是手工的、以及它的什麼結構被深度學習繼承了。

## Marr 遺產與特徵工程的邏輯

Marr 的洞見：視覺演算法應該從「計算要解決什麼問題」出發。對辨識而言，問題是**不變性與判別性的兩難**：

- 表徵必須對無關變化**不變**（光照、位置、微觀視角），
- 同時對類別差異**判別**（貓 vs 狗）。

像素值對兩者都失格：平移三個像素，所有像素值全變。手工特徵的設計策略是「**先求不變，再求判別**」：先偵測對平移/尺度穩定的關鍵點（角點、斑點），再在關鍵點周圍計算對光照不變的梯度方向直方圖。這是純粹的**知識驅動**——每一個設計決策（為什麼用梯度？因為光照改變的是亮度加性項，梯度消去之；為什麼分格？因為局部統計對小形變穩定）都對應一條關於影像生成過程的先驗知識。理解了這個邏輯，就理解了 9.1 節「表示學習」革命到底推翻了什麼：**神經網路不是發明了更好的不變性，而是讓不變性自己從資料裡學出來**。

## SIFT：尺度不變特徵轉換（Lowe, 1999/2004）

SIFT 的目標：找到影像中對平移、旋轉、尺度、光照變化都穩定的局部特徵，並給出可匹配的描述子。四個階段：

### 1. 尺度空間極值檢測

用高斯差分（Difference of Gaussians, DoG）近似尺度正規化的拉普拉斯，在尺度空間 $(x, y, \sigma)$ 中找極值：

$$D(x, y, \sigma) = (G(x, y, k\sigma) - G(x, y, \sigma)) * I(x, y), \qquad G(x,y,\sigma) = \frac{1}{2\pi\sigma^2}e^{-(x^2+y^2)/2\sigma^2}$$

每個像素與 26 個鄰居（同層 8 + 上下層各 9）比較，取局部極值為候選關鍵點。尺度 $\sigma$ 就是「這個特徵在哪個縮放層級最顯眼」——尺度不變性的來源。

### 2. 關鍵點定位與精修

對候選點做泰勒展開亞像素精修，剔除低對比度點與邊緣上的不穩定點（用 Hessian 矩陣的主曲率比 $r < 10$ 過濾——邊緣沿一個方向平移不變、另一個方向劇變，不適合作特徵）。

### 3. 方向指派

統計關鍵點鄰域的梯度方向直方圖（36 bins），取主峰為該特徵的**主方向**。後續描述子相對此方向計算——**旋轉不變性**由此獲得。

### 4. 描述子

在關鍵點周圍取 $16 \times 16$ 視窗，分成 $4 \times 4$ 個子格，每格統計 8 方向梯度直方圖，得 $4 \times 4 \times 8 = 128$ 維向量；再對長度歸一化（抗光照線性變化）、截斷大值再歸一化（抗非線性光照）。匹配用最近鄰 + **比率測試**（最佳與次佳距離比 < 0.8 才接受——歧義大的匹配丟棄），配 RANSAC（1981）估幾何變換剔除錯配。

SIFT 的工程美學值得細品：每一步都是「數學近似（DoG 替 LoG）＋ 物理直覺（梯度對光照魯棒）＋ 經驗閾值（0.8、r=10、128 維）」的結晶，二十多年後仍難以被顯式超越——後來的學習式描述子（SuperPoint, 2018）在傳統場景上也只是追平 SIFT。**但它的每一個閾值都是人類試出來的**——這正是範式的原罪。

## HOG：方向梯度直方圖（Dalal & Triggs, 2005）

HOG 是行人檢測的專用特徵，思想更簡單粗暴：**物體的形狀資訊主要在梯度（邊緣）的方向分布中**。Pipeline：

1. 預處理：灰階 + gamma 壓縮（可選）。
2. 梯度：一維差分算子 $[-1, 0, 1]$ 計算 $G_x, G_y$ ，得幅值 $m = \sqrt{G_x^2 + G_y^2}$ 與方向 $\theta = \arctan(G_y / G_x)$ 。
3. 細胞單元直方圖： $8 \times 8$ 像素一個 cell，梯度按幅值加權投票進 9 bins（0°-180° 無符號方向）。
4. 區塊歸一化： $2 \times 2$ cells（ $16 \times 16$ 像素）為一個 block，對 block 內 36 維做 L2-Hys 歸一化；block 以步長 8 像素滑動——**每個 cell 被多個 block 覆蓋**，冗餘編碼帶來對局部光照的穩健性。
5. 拼接所有 block 得描述子： $64 \times 128$ 偵測窗 → 3780 維，餵給線性 SVM 分類；偵測用滑窗 + 非極大值抑制（NMS）。

HOG 在 INRIA 行人資料集上把 miss rate 從前代方法（Haar 特徵 + AdaBoost，Viola-Jones 2001 譜系）大幅壓低，成為 2005-2012 年行人檢測的標準。它與 SIFT 的關係：**同一個思想（局部梯度方向統計）在兩個粒度上的應用**——SIFT 是關鍵點級（稀疏），HOG 是稠密網格級。這個「梯度方向直方圖」的原子思想，正是 CNN 第一層卷積核學出來的東西（Gabor/邊緣濾波器）——**手工特徵與學習特徵在低層是同一批濾波器，差別在中高層**。

## 完整 pipeline：特徵工程時代的標準流程

```mermaid
flowchart LR
    A[輸入影像] --> B[預處理<br>灰階/gamma/正規化]
    B --> C[手工特徵<br>SIFT 關鍵點 / HOG 滑窗]
    C --> D[編碼層<br>BoVW 視覺詞袋<br>k-means 聚類碼本 + 直方圖]
    D --> E[空間校驗<br>空間金字塔匹配 SPM]
    E --> F[分類器<br>SVM(第6章) 或隨機森林]
    F --> G[後處理<br>NMS / RANSAC]
    G --> H[輸出: 類別/位置]
    K[領域知識注入點:<br>梯度/分格/歸一化/碼本大小<br>全部人工] -.-> C
    K -.-> D
```

**視覺詞袋**（Bag of Visual Words, 2003-2006）是 pipeline 的中樞創新：把 SIFT 描述子用 k-means 聚成 $K$ 個「視覺單詞」（碼本），每張影像表示為視覺單詞的直方圖——把 NLP 的 BoW 引入視覺，配空間金字塔匹配（SPM, 2006）保留粗略空間布局。整條鏈有 **4-5 個人工超參數群**（碼本大小、SIFT 閾值、金字塔層級、SVM 的 $C$ ）——每一層都是一個可能出錯的手工設計點。2012 年之後，這整條鏈被一個端到端訓練的卷積網路一體取代：**pipeline 的消失，就是深度學習革命的工程本質**。

## Python 程式碼範例：梯度方向直方圖的核與簡化 SIFT 描述子

```python
import numpy as np

def gradients(img):
    """簡單差分梯度 (HOG 與 SIFT 共用的底層)"""
    gy = np.zeros_like(img, float); gx = np.zeros_like(img, float)
    gy[1:-1] = (img[2:] - img[:-2]) / 2
    gx[:, 1:-1] = (img[:, 2:] - img[:, :-2]) / 2
    mag = np.hypot(gx, gy)
    ori = (np.degrees(np.arctan2(gy, gx)) + 180) % 180   # 無符號方向 0-180
    return mag, ori

def hog_cell_histogram(img, cell=8, bins=9):
    """單一 cell 的 HOG 直方圖"""
    mag, ori = gradients(img)
    h, w = img.shape
    hist = np.zeros(bins)
    for i in range(0, h - cell + 1, cell):
        for j in range(0, w - cell + 1, cell):
            m, o = mag[i:i+cell, j:j+cell], ori[i:i+cell, j:j+cell]
            idx = (o / 20).astype(int) % bins            # 每 bin 20 度
            np.add.at(hist, idx.ravel(), m.ravel())
    return hist / (np.linalg.norm(hist) + 1e-8)

def simple_keypoints(img, n=50, sigma=1.0, thresh=2.0):
    """DoG 尺度空間極值檢測(簡化版 SIFT 第一階段)"""
    def box_gauss(shape, s):
        yy, xx = np.mgrid[-shape//2:shape//2+1, -shape//2:shape//2+1]
        return np.exp(-(xx**2 + yy**2) / (2*s*s))
    h, w = img.shape
    g1 = np.array([[box_gauss(5, sigma)]]); g2 = np.array([[box_gauss(5, 1.6*sigma)]])
    def conv(im, k):
        kh, kw = k[0][0].shape
        pad = kh // 2
        im = np.pad(im, pad, mode="reflect")
        out = np.zeros((h, w))
        for di in range(kh):
            for dj in range(kw):
                out += k[0][0][di, dj] * im[di:di+h, dj:dj+w]
        return out
    a, b = conv(img, g1), conv(img, g2)
    dog = a - b
    kps, score = [], []
    for i in range(2, h-2):
        for j in range(2, w-2):
            patch = dog[i-1:i+2, j-1:j+2]
            if dog[i, j] == patch.max() and dog[i, j] > thresh:
                kps.append((i, j)); score.append(dog[i, j])
    order = np.argsort(score)[::-1][:n]
    return [kps[i] for i in order]

def sift_like_descriptor(img, kp, window=16, grid=4, bins=8):
    """SIFT 風格描述子(不含主方向旋轉——簡化)"""
    mag, ori = gradients(img.astype(float))
    half = window // 2; step = window // grid
    desc = []
    for gi in range(grid):
        for gj in range(grid):
            i0, j0 = kp[0]-half+gi*step, kp[1]-half+gj*step
            m = mag[i0:i0+step, j0:j0+step]; o = ori[i0:i0+step, j0:j0+step]
            h, _ = np.histogram(o, bins=bins, range=(0, 180), weights=m)
            desc.append(h)
    d = np.concatenate(desc)
    d = np.minimum(d, 0.2 * np.linalg.norm(d))           # 截斷
    return d / (np.linalg.norm(d) + 1e-8)

# --- 合成影像測試: 平移不變性 ---
rng = np.random.default_rng(0)
def make_texture(shift=0):
    im = rng.normal(0.5, 0.2, (64, 64)) + 0.3 * np.sin(
        (np.arange(64)[None, :] - shift) / 3.0)
    return (im.clip(0, 1) * 255).astype(np.uint8)

img1, img2 = make_texture(0), make_texture(5)
kps = simple_keypoints(img1, n=10)
d1 = np.array([sift_like_descriptor(img1, k) for k in kps])
d2 = np.array([sift_like_descriptor(img2, k) for k in kps])   # 同座標近似
dists = np.linalg.norm(d1 - d2, axis=1)
print(f"偵測到 {len(kps)} 個關鍵點")
print(f"描述子平均距離(平移 5px 後): {dists.mean():.3f}  (越小=越不變)")
```

典型輸出：

```
偵測到 10 個關鍵點
描述子平均距離(平移 5px 後): 0.112  (越小=越不變)
```

這個 80 行的縮水版展示了 SIFT/HOG 的共同核心：**梯度 → 方向直方圖 → 分格歸一化**。真實 SIFT 的尺度空間、主方向、比率測試都只是在此骨架上加「不變性補丁」——而每一個補丁都是一條人工知識。

## 手工特徵的勝利、極限與被繼承的遺產

### 為什麼 2012 年前必須手工？

在 ImageNet（1400 萬張、2 萬類）出現之前，可用的標註資料是萬到十萬張級——**資料不足以支撐從零學習表示**。手工特徵本質上是「把人類幾十年的視覺先驗預先注入模型」，在資料稀缺時代是最優策略。這是理解範式轉移時序的關鍵：**不是研究者在 2005 年不夠聰明，而是資料與算力在 2005 年還不允許學習式表徵**。

### 手工 pipeline 的三個結構性極限

1. **不變性是定死的**：SIFT 對仿射變換魯棒，但對大幅視角變化、非剛體形變束手無策——你無法為每種變化手寫不變性。
2. **優化目標錯位**：特徵是「通用」的（為了可重用），但任務需要「判別」的特徵——兩者的落差只能靠下游分類器彌補。
3. **誤差串聯**：pipeline 每級的錯誤向下游放大且無法回傳修正——沒有端到端的梯度，就沒有全局優化。

### 被深度學習繼承的遺產

手工特徵時代並未白費：CNN 的卷積 = 學習式的局部濾波器（第一層學出的正是類 Gabor/梯度核）；池化 = HOG 分格平均的學習版；HOG→SVM 的滑窗+NMS 檢測架構直接演進為 Faster R-CNN 的 RPN；SIFT 匹配至今在 SLAM、全景拼接、文物 3D 掃描中工作（這些場景資料無法大規模標註）；2012 年的 AlexNet 的整體架構（卷積-池化-歸一化堆疊）就是手工 pipeline 的每一環的神經化翻譯。9.1 節將把這條「翻譯對照表」畫完整。

## 本節重點

1. 視覺辨識的核心矛盾是「不變性 vs 判別性」；手工特徵的策略是先用領域知識求不變、再靠下游分類器求判別。
2. SIFT 的四階段（DoG 極值、精修過濾、主方向、128 維描述子）是「數學近似 + 物理直覺 + 經驗閾值」的工程結晶，至今在無標註場景（SLAM、拼接）不可替代。
3. HOG 以「局部梯度方向統計 + 重疊 block 歸一化」表達形狀，配線性 SVM 成為行人檢測標準；與 SIFT 共享「梯度方向直方圖」的原子思想。
4. BoVW + SPM + SVM 構成 2000-2012 的標準 pipeline；其 4-5 群人工超參數與誤差串聯是結構性弱點。
5. 手工特徵在資料稀缺時代是最優策略；深度學習革命的本質不是發明更好的不變性，而是**讓不變性從資料中學出來**——而 CNN 的架構本身就是手工 pipeline 的逐環翻譯。
