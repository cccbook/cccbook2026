# 棋盤上的神經元：從古典搜尋到 AlphaGo、AlphaZero 的博弈 AI 革命

*Neurons on the Board: From Classical Search to the Game-Playing AI Revolution of AlphaGo and AlphaZero*

本書是「人工智慧系列」的第六本。前五本（《神經網路》、《智慧模型》、《強化學習》、《Agent 技術》、《AlphaFold 蛋白質摺疊》）處理的是模型與演算法本身；本書把它們放進**一個可以被量化勝負的世界**裡，用一條六十年、可被黑白對錯驗證的因果鏈，檢視這些技術究竟是真智慧，還是更精密的算力包裝。

全書的核心敘事：

- 西洋跳棋是**有限、確定、回合制、零隨機**的完美資訊遊戲 → 成為 AI 的試驗場
- 塞繆爾（1952-1959）證明機器可以「學」一個評估函數 → 機器學習的第一個里程碑
- 極小化極大與阿爾法貝塔剪枝（1956-1959）建立了搜尋的效率典範 → 但它們是**人寫的知識**
- 深藍（1997）靠專用晶片與窮舉擊敗卡斯帕羅夫 → 「暴力美學的極致」，卻也暴露硬體偏食的盲點
- 圍棋的狀態空間約 $`10^{170}`$ 、博弈樹約 $`10^{360}`$ → 古典搜尋徹底失效，**評估函數的弱點**被放大成致命傷
- 蒙地卡羅樹搜尋（MCTS）把「無限窮舉」換成「有偏抽樣」 → 為 2016 年的突破鋪路
- AlphaGo（2016）把 CNN、強化學習、價值網路與 MCTS 縫合成一個系統 → 第三局、第四局、第五局
- AlphaGo Zero（2017）與 AlphaZero（2017）證明**規則與人類棋譜都可以丟掉** → 通用演算法的誕生
- MuZero（2019）連環境模型都不要求正確，只要求**對決策有用** → 從棋盤走向真實世界
- 硬體（TPU、分散式訓練）不是配角，而是 AlphaZero 能夠「一天學完西洋棋」的物理前提
- 終局：博弈 AI 教會我們的不是「機器很強」，而是人類直覺的侷限、創造力的重新定義，以及從遊戲到科學的同源迁移
