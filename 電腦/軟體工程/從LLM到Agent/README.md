# 《從 LLM API 到 Agent：建構自主智慧體的工程指南》

> 一本從「呼叫模型」一路走到「可驗證自主智慧體」的工程教科書。
> 全書以「前因後果」與「技術—理論的互相驅動」為主軸，串連 API、工具、記憶、規劃、多 Agent、可觀測性、生產治理，直到多模態、世界模型、具身智慧與形式化數學。

## 如何使用本書

- 每個小節是一個獨立 `.md` 檔，對應 GitHub 友善的標準 Markdown。
- 數學以 `$`...`$` 行內公式與 `$$`...`$$` 區塊公式撰寫，均可於 GitHub 正確渲染。
- 架構圖以 [Mermaid](https://mermaid.js.org/) 撰寫。
- 建議閱讀順序：第 1–3 章打地基，第 4–6 章接上外部世界，第 7–9 章進入核心引擎，第 10–12 章規模化，第 13–16 章面向前沿。
