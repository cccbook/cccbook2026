# 4.2 工具整合：內建 MCP 與 Codemode 沙箱

## 從一個問題開始

你的 agent 需要 Jira、GitHub、檔案系統等外部工具。Pi 內建 **MCP（Model Context Protocol）** 支援，再加上獨門武器 **Codemode**：讓 agent 在 JavaScript 沙箱中組合工具鏈。

## MCP 快速上手

三步：加入伺服器、檢查連線、啟動 Pi。

```bash
pi mcp add filesystem -- npx -y @modelcontextprotocol/server-filesystem .
pi mcp list
pi
```

遠端伺服器：

```bash
pi mcp add docs --url https://example.com/mcp --bearer-token-env-var DOCS_TOKEN
```

互動模式內用 `/mcp` 檢視連線、登入、重連、改 exposure、啟用/停用。

## mcp.json 設定

`~/.pi/agent/mcp.json`（全域）或 `.pi/mcp.json`（專案，需 trust），格式與其他 MCP 客戶端相容：

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "."]
    },
    "docs": {
      "url": "https://example.com/mcp",
      "headers": { "Authorization": "Bearer ${DOCS_TOKEN}" }
    }
  }
}
```

- stdio 伺服器：`command` + `args` + `env` + `cwd`
- HTTP 伺服器：`url` + `headers` + `oauth`
- `env`/`headers` 值可用 `${NAME}` 環境變數或 `!command`
- 專案同名條目**取代**全域條目
- **從別的客戶端遷移**：Claude Code / Cursor 直接複製 `mcpServers`；OpenCode 把 `"type": "local"` 轉成 stdio、`command` 陣列拆成 `command` + `args`、`environment` 改名 `env`

## 工具曝光：Codemode 是預設

伺服器工具註冊為 `mcp__<server>__<tool>`，`exposure` 決定模型怎麼碰到它：

| exposure | 行為 | 適用 |
|---|---|---|
| `codemode`（**預設**） | 只能從 codemode 腳本呼叫，不宣告給模型 | 一般 MCP 伺服器，腳本可組合/過濾呼叫 |
| `deferred` | `tool_search` 找到才宣告給模型 | 大型伺服器，找到後直接呼叫 |
| `direct` | 像內建工具一樣宣告給模型 | 小型、常用工具組 |
| `hidden` | 已註冊但不可達 | 暫時停用 |

- 伺服器接上後，Pi 自動啟用 `codemode`（codemode exposure 時）或 `tool_search`（deferred exposure 時）
- `toolExposure` 可對個別工具覆蓋：`"get_*": "codemode"`、`"delete_*": "hidden"`
- OAuth 伺服器（如 Sentry）不需在 json 放憑證：`pi mcp login sentry` 即可

## Codemode：JavaScript 沙箱組合工具

Codemode 讓 agent **寫 JavaScript 腳本**呼叫其他工具，跑在 **QuickJS 沙箱**裡——只有腳本的輸出會進 context。

啟用（settings.json）：

```json
{ "defaultTools": ["+codemode"] }
```

一次呼叫時：

```bash
pi --tools read,bash,edit,write,codemode
```

腳本透過 `tools.<name>(args)` 呼叫工具。典型用途：

```js
// 平行執行多個工具呼叫
const results = await Promise.allSettled([
  tools.read({ path: "package.json" }),
  tools.read({ path: "README.md" }),
]);
// 過濾大輸出，只有處理後的結果進 context
```

Codemode 即使沒有 MCP 也有用：

1. **平行呼叫**：`Promise.allSettled` 同時跑多個工具
2. **過濾輸出**：讀大檔案、處理後只回摘要給模型
3. **呼叫分類器模型**：`models.classify()`（如 TypeSafe 的 Jev）對 JSON 狀態回答 yes/no、選項或分數
4. **生成圖片**：`models.generateImages()`（如 OpenRouter 的 Gemini 圖像模型）

```js
// 用分類器模型判斷「使用者是否同意」
const jev = await models.getModelOfType("classifier", "typesafe", "jev-latest");
const result = await models.classify(jev, {
  state: { message: "The change works, thanks." },
  questions: {
    approved: {
      type: "bool",
      instructions: "Does the user approve of the result?",
      criteria: { true: "Approval", false: "No approval" },
    },
  },
});
return result.answers;
```

> 打比方：一般的 MCP 是「每個工具都擺上桌面給模型看」——桌面越來越擠，context 越來越大。Codemode 是「工具收在抽屜裡，模型寫一張便條（JS 腳本）叫抽屜開」——context 只放最後結果。

## 20 KB 截斷與資源

- 文字結果超過 20 KB：模型收到中段移除的版本（`…N chars truncated…`），完整文字存到暫存檔；codemode 腳本收到的永遠是完整結果
- 支援 MCP resources：`list_mcp_resources`、`read_mcp_resource` 等工具

## 從 Extension 加 MCP 伺服器

```typescript
pi.registerMcpServer("jira", { url: "https://mcp.example.com/jira", exposure: "codemode" });
pi.unregisterMcpServer("jira");
```

- 註冊不持久化，每次載入要重新註冊
- `mcp.json` 同名條目優先
- 完全替換內建 MCP 支援：註冊 `/mcp` 指令的擴充（如 `pi-mcp-adapter`）會接管

## 疑難排解

```bash
pi mcp list    # 連線到每個啟用的伺服器，印出狀態、工具與錯誤（退出碼 1 = 有問題）
```

- 設定錯誤與連線失敗會在啟動後報告一次
- 伺服器 log 在 `~/.pi/agent/mcp.log`（超過 5 MB 輪替）
- HTTP 暫時性錯誤（408、429、5xx）自動重試兩次
