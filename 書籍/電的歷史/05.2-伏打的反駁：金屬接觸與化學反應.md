# 第五章　動電的誕生：從青蛙腿到電池

## 第 2 節 亞歷山德羅·伏打（Alessandro Volta）的反駁：金屬接觸與化學反應

### 一、「無需動物，也能產生電」

伏打（Alessandro Volta, 1745–1827）是帕維亞大學的實驗物理教授，早年以發明起電盤（electrophorus）聞名，是歐洲靜電學的頂尖專家。重複伽伐尼實驗時，他抓住了一個伽伐尼忽略的變因：**金屬的種類**。他設計了決定性的實驗——完全拿掉動物組織：把兩種不同的金屬片（例如銅與鋅）接在一起，再用舌頭同時輕觸兩片金屬，舌尖立刻感到明顯的酸麻與微酸味。沒有青蛙、沒有肌肉、沒有神經，只有兩種金屬與一個（活體的）感測器。

伏特的結論石破天驚：電的來源不是動物，而是**兩種不同金屬的接觸**。他提出「金屬接觸電位」理論：任何兩種不同的導體相接觸，交界處就會產生電動勢；動物組織（舌頭、蛙腿）只不過是靈敏的「驗電器」，而非電源。1792 年起，他在一系列論文與通信中系統地重述伽伐尼的全部實驗，逐一用接觸理論重新解釋。他用濕紙板或食鹽水取代蛙腿夾在金屬之間，發現效果依然存在——「濕的導電中介物」這個要素，已經悄悄指向電池的構造。

（有趣的是，以今日的電化學知識回看：伏特的「接觸電位」確實存在，但它無法持續供電；真正維持電流的是金屬—電解液界面的化學反應。伏特打贏了論戰，論證的核心卻只對了一半——科學史上，打倒舊理論的新理論往往自身也藏著缺陷。）

### 二、義大利科學界的兩極分化：一場制度性的論戰

「動物電 vs 接觸電」迅速撕裂了義大利學界。波隆那（伽伐尼陣營）與帕維亞（伏特陣營）兩所大學各執一端；義大利的科學期刊、學院通訊、私人通信網絡全部動員起來。物理學家傾向伏特，解剖學家與醫學家傾向伽伐尼——學科立場決定理論立場，這在科學爭論史上屢見不鮮：人們總是傾向保護自己學科的解釋權。

這場論戰是研究「學術爭議制度史」的經典案例。當時的科學傳播依賴通信、期刊與學會報告，論戰以公開發表的實驗報告為武器；雙方都逼自己不斷改進實驗設計以壓倒對方。例如伽伐尼陣營設計出「無金屬電流」實驗（蛙神經直接搭在肌肉上仍可引起抽搐），企圖證明動物電無需金屬；伏特則以遞增的實驗證明任何兩種異質導體的組合都能產生效應。論戰的制度意義在於：**沒有仲裁者，只有實驗與出版**。爭議沒有被權威裁決，而是被更好的實驗「稀釋」——最終由伏特的電池提供了一個讓兩派都能繼續工作的平台（日後的生物電研究也證明伽伐尼並未全錯）。

### 三、通信之爭：兩位紳士的優雅交鋒

伏特與伽伐尼的論戰主要透過書面通信與論文進行，兩人從未當面公開辯論，甚至保持著某種禮貌的距離。伏特的通信對象遍及全歐——他善於把實驗結果寫成清晰的信件寄給外國學者，借助國際聲望向義大利國內施壓。這種「以國際輿論支撐本土論戰」的策略，顯示十八世紀末的科學已是跨國公共領域：一個理論能否生存，取決於巴黎、倫敦的同行是否買帳。伽伐尼陣營的回擊則較為內向，隨著 1798 年伽伐尼去世，波隆那陣營失去了靈魂人物，論戰的天平全面倒向伏特。

### 四、拿破崙的封賞：政治贊助科學的極致

1800 年，伏特發明電堆（下節詳述），並致信倫敦皇家學會發表。消息傳開，全歐矚目。1801 年，伏特應邀前往巴黎，在法國科學院當眾演示電堆——第一排坐著的是第一執政拿破崙。拿破崙親自觀看實驗、下令表彰，授予伏特金質獎章，隨後封他為伯爵、義大利王國參議員，並提供年金。拿破崙甚至提議設立「伽伐尼電學獎」，懸賞十年一度、獎勵「對電與動物電研究有貢獻者」——鼓勵的對象包括他的論敵伽伐尼一方的後繼者。

這是「政治贊助科學」的教科書場景：法國正與奧地利爭奪北義大利，拿破崙需要一個象徵義大利科學榮光的和平之人，來為其統治增添正當性；伏特則獲得金錢、頭銜與安逸的晚年。科學聲望成為政治資本，政治恩庇成為科研資源——這種交換在拿破崙時代被制度化（他的名言「科學的進步是法蘭西的光榮」），也延續到今日各國的科學獎章與國家實驗室體制。當然，贊助是有代價的：伏特晚年謹言慎行，在政治上幾乎不表態，科學家的獨立性與國家恩寵之間的張力，自此成為科學社會學的永恆課題。

### 因果鏈條

> 伏特重複伽伐尼實驗 → 察覺電流強度取決於金屬種類 → 「無動物」的決定性實驗（舌頭測試）→ 金屬接觸電位理論 → 義大利學界兩極分化（物理學家 vs 醫學家）、以期刊與通信公開論戰 → 伏特借重國際聲望取勝 → 1800 年電堆問世 → 巴黎演示、拿破崙觀禮 → 封爵與年金 → 政治贊助科學制度化 → 電堆開啟動電時代（下節）。
