# 第 3 章／第 2 節 補全拼圖：週期表上「故意留白」的空格（還缺哪些元素？如類鋁、類矽）

## 表不只整理過去，更命令未來

門得列夫 1869 年的初表已經留下空格，但真正震動化學界的，是他 1871 年的長篇論文〈元素的週期律與化學親和力〉。在這篇論文裡，他做了一件此前沒有任何分類學者敢做的事：**在表上留下空格，並為空格裡「還不存在的元素」寫出詳細履歷**。

這是一場方法論革命。在他之前，所有的元素分類（三素組、八音律）都是**回顧性**的：把已知的東西排整齊。門得列夫的表卻是**前瞻性**的：它像一張拼圖的底板，明確告訴世人哪幾塊還缺、缺的形狀是什麼。表從此不只是倉庫的貨架，而是對未來的命令——「去，把這些找出來。」

## 三個預言：類硼、類鋁、類矽

門得列夫挑出三個空格，分別位於鋁、矽、硼的正下方，並依週期表左右鄰居的性質「內插」，給出驚人精確的預言：

| 性質 | 類鋁（eka-Al） | 類矽（eka-Si） |
|---|---|---|
| 原子量 | 約 68 | 約 72 |
| 密度 | 約 5.9 g/cm³ | 約 5.5 g/cm³ |
| 熔點 | 低（易熔） | 高 |
| 氧化物 | $E_2O_3$ | $EO_2$ |
| 氯化物 | $ECl_3$（揮發性） | $ECl_4$（液體，沸點略低於 100°C） |

（第三個是「類硼」eka-B，位於鈧的位置，原子量約 44。）

預言的細節令人咋舌：他連類矽的氯化物「密度比水大、可蒸餾、不易分解」都寫了；連類鋁「將由光譜分析法發現」都指出了方法。這些數字不是憑空而來——它們是週期表幾何結構的必然推論：一個元素在其水平鄰居與垂直鄰居的性質之間，必然占據內插的位置。週期表第一次展現出**數學般的結構強制力**。

## 半信半疑的化學界

為什麼當時多數化學家將信將疑？因為**週期律沒有理論**。門得列夫只能說「性質是原子量的週期函數」，卻答不出「為什麼」。在當時的原子論框架下，元素被視為不可分割的終極實體——碳就是碳，鉛就是鉛，彼此之間不該有任何「家族血緣」。若元素之間真有週期性，那暗示著元素背後還有更深的結構，而那個結構沒有人看得見。一個沒有機制的經驗定律，憑什麼讓人相信它對未知世界的預言？門得列夫的空格，在多數人眼裡不過是漂亮的推測。英國化學界反應尤其冷淡，連門得列夫的老師輩人物也不以為然。要等到一個實物落網，疑雲才會散去——那是下一節的故事。

## 意外插入的整族：稀有氣體的考驗

就在化學界遲疑之際，一場更嚴峻的考驗先來了——**整整一族元素，事先不在表上，突然插了進來**。

第一個徵兆來自天上。1868 年日食觀測中，法國天文學家讓桑與英國的洛克耶在太陽色球光譜裡看到一條任何地球元素都對不上的黃線（波長 587.6 nm），洛克耶據此宣布太陽上有一種新元素，以希臘的赫利俄斯（Helios）命名為**氦**（Helium）。一個只在太陽光譜中存在的元素，當時被許多化學家視為天方夜譚。

第二個徵兆來自地上。1894 年，倫敦的瑞利男爵發現從空氣中除去的氮，密度竟比化學方法製得的氮略重千分之一——這個微小的「誤差」被拉姆塞與瑞利追查到底，結果從空氣裡榨出一種全新的、極端惰性的氣體，命名為**氬**（Argon，希臘語「懶惰」）。1895 年拉姆塞又在釔鈾礦加熱的氣體中發現了地球上的氦。此後數年，氖、氪、氙相繼從液態空氣的分餾中現身。

一整族、五、六種元素，集體缺席於週期表——這對任何分類系統都是災難。門得列夫起初甚至質疑氬是否真是新元素。但他很快做出教科書式的反應：既然這些氣體化學性質極端惰性（價數為零），它們就應該構成**一個全新的「零族」**，插在鹵素與鹼金屬之間——而這一插，恰好把每個週期的長度完美接合，原子量也嚴絲合縫。1898 年後，門得列夫甚至預言零族還應有原子量約 20 與 22 的成員（後來的氖）。稀有氣體的「突然插入」非但沒有摧毀週期表，反而像在拼圖上硬生生補出一整排，卻發現邊緣完全吻合——表的結構強度接受了最嚴苛的實戰檢驗。

## 因果鏈條

教科書式的分類需求 → 門得列夫把空格與預言寫進週期表（1871）→ 表從回顧工具變成對未來的命令 → 缺乏理論基礎使化學界半信半疑 → 太陽光譜（1868 氦）與空氣密度誤差（1894 氬）帶來整族意外元素 → 門得列夫以「零族」化解危機並強化結構 → 週期表的預言威信大增，等待鎵與鍺的最終驗證。
