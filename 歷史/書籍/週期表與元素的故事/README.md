### 本書三條主線

1. **規律的尋找總是先於解釋**：從經驗分類（三元素組、八音律）到量子理論（電子殼層、核殼層模型），規律先被「看見」，再被「理解」。
2. **「留白」是最強的方法論**：門得列夫的空格、莫斯利的缺口清點、穩定島的預言——科學由預言驅動的探索推向未知。
3. **儀器決定邊界**：光譜儀、X 射線譜、核反應堆、粒子加速器——每一次儀器革命，都改寫了元素清單。
