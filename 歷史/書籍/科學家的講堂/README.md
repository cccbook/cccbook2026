## 閱讀說明

本書各章環繞一位科學家的「教室」——可能是講堂、實驗室、咖啡館或茶室。每章三節：

1. **前因**：這位科學家如何養成其教學思想（時代、制度、文化的驅動）；
2. **課堂**：教室裏發生了什麼（風格、方法、經典瞬間）；
3. **後果**：這些課堂如何改變科學、教育與世界。

書中穿插 `mermaid` 圖表與 $\LaTeX$ 公式，方便對照理解。
