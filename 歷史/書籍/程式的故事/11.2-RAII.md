# 11.2 RAII（資源獲取即初始化）：C++ 獨創的資源管理哲學

## 資源管理的三種時代答案

到 1980s，「資源問題」已不止記憶體：檔案句柄、socket、資料庫連線、鎖——**一切需要「取得後必須歸還」的東西**。三種管理範式相繼登場：

| 範式 | 策略 | 問題 |
|------|------|------|
| **手動配對**（C） | `open()` … `close()` | 錯誤路徑漏歸還 → 資源洩漏 |
| **垃圾回收**（Lisp/Java） | 系統回收**記憶體** | **只管記憶體！**檔案、鎖、連線不受管 |
| **RAII**（C++） | 資源生命週期綁定物件生命週期 | 需要確定的解構時機——**GC 語言做不到** |

## RAII 的核心思想：把「清理」交給作用域

> **資源在物件建構時取得，在物件解構時釋放。而 C++ 的解構時機是確定的：離開作用域的瞬間。**

```cpp
void process() {
    File f("data.txt");        // 建構子：open()
    Lock guard(mutex_);        // 建構子：lock()
    // ... 使用資源，包括任何 early return、例外 ...
}   // 作用域結束：解構子自動 unlock() → close()
```

**無論函數怎麼離開**（正常返回、多處 return、拋出例外），解構子**必定執行**——清理邏輯從「程式員的記憶」變成「語言的機制」。**正確性靠結構而非紀律**——Dijkstra 精神（8.3）在資源管理上的重現。

## RAII 的深層意涵：確定性解構是 C++ 的分水嶺

| | GC 語言 | C++（RAII） |
|---|---------|------------|
| 記憶體釋放時機 | 不確定（GC 選擇） | 確定（離開作用域） |
| 非記憶體資源 | 需手動 close | 自動 |
| 釋放成本 | 集中（GC 暫停） | 分攤（逐作用域） |
| 心智模型 | 「誰還引用我？」 | 「誰擁有我？」 |

**「所有權（ownership）」一詞在此誕生**：每個資源恰好一個擁有者，擁有者死亡則資源釋放。這個 1980s 的 C++ 慣例，在三十年後被 Rust 提煉成**型別系統**（15.2）——RAII 是從「編碼慣例」到「語言機制」的完整演化鏈起點。

## RAII 的工程普及：智慧指標與 STL

- **STL（Stepanov，1994）**：容器本身是 RAII——`std::vector` 的解構子釋放內部記憶體。**容器+RAII 使 C++ 程式員絕大多數情況下不再手動 new/delete**
- **智慧指標**：`unique_ptr`/`shared_ptr`（2011）——把「指標的擁有權語義」顯式化。`shared_ptr` 本質是**引用計數 GC（7.3）**的 RAII 化
- **例外安全**：RAII 是 C++ 例外安全程式設計的基石

## 歷史對照：各語言如何「補」RAII

| 語言 | 補丁 | 年代 |
|------|------|------|
| Python | `with` 語句（上下文管理器） | 2005 |
| C# | `using` 語句 | 2005 |
| Java | try-with-resources | 2011 |
| Go | `defer` | 2009 |
| Rust | **Drop trait + 所有權**（RAII 成為語言核心） | 2015 |

**規律**：GC 語言無法直接做 RAII（解構時機不確定），只能發明**詞法作用域化的清理原語**——本質是 RAII 的受限版。Rust 則證明：**把「確定解構」與「唯一所有權」寫進型別系統，可以同時擁有安全、零成本與確定性。**

## RAII 的教學與文化意義

RAII 體現了一種**「讓正確成為容易」**的設計倫理：

- 傳統 C 的態度：「程式員應該記得 close」——靠紀律
- RAII 的態度：「忘了 close 在結構上不可能」——靠機制

這條倫理可以追溯到 Dijkstra 的結構化運動（8.3），並在 Rust 的借用檢查器達到頂峰。**軟體工程史的主旋律之一：把「人的紀律需求」轉化為「結構的機制保證」。**

## 小結

| 概念 | 內容 | 後繼者 |
|------|------|--------|
| RAII | 資源生命週期 = 物件生命週期 | Rust Drop、Go defer |
| 確定性解構 | 離開作用域即釋放 | with/using 語句 |
| 所有權觀念 | 一個資源一個主人 | Rust borrow checker |
| 智慧指標 | 擁有權顯式化 | unique_ptr/shared_ptr |
