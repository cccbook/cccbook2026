### 本書三條主線

1. **儀器先於理論，理論先於工程，工程先於文明變革**：驗電器→庫侖定律→發電機→城市照明，每一環都有數十年的「錯位時差」。
2. **資本與戰爭反覆扮演加速器**：電報帝國、電流戰爭、軍方採購啟動積體電路——科學突破從不孤立存在。
3. **「統一」是反覆出現的主題**：電與磁（奧斯特、法拉第）、光與波（麥克斯韋）、經典與量子（電晶體）——以及最終的核融合，把恆星的火種握在人類手中。
