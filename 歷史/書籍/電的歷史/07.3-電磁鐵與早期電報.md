# 第 7 章 電與磁的會合

## 第 3 節 電磁鐵的發明與早期電報（Telegraph）的誕生

奧斯特證明電能生磁之後，下一個問題自然是：能否把這種磁放大到有用？1825 年，英國電工威廉·斯特金（William Sturgeon）給出第一個答案：他把導線繞在絕緣的軟鐵蹄鐵上，通電後這塊鐵竟能舉起約四公斤的鐵器；斷電，吸力消失。軟鐵在電流消失後立即退磁——這正是電磁鐵優於天然磁石之處：磁力可以隨電流開關，等於人類首次擁有「可遙控的力」。

### 亨利：美國學院科學的強力電磁鐵

斯特金的電磁鐵受限於當時的電池與設計，但真正把它推上實用之路的是美國科學家約瑟夫·亨利（Joseph Henry）。在奧爾巴尼學院任教時，亨利悟出關鍵區分：若要舉重物，應該用少數幾匝粗導線與強電池組；若要透過長導線遙遠控制——例如遠距離電報——則該用多層細導線密繞數千匝，靠微弱電流驅動。1831 年他在耶魯大學展示的巨型電磁鐵能舉起超過一噸的重物，震驚學界；後來普林斯頓的大磁鐵更成為美國學院科學的象徵。這些成就表明：科學重鎮不必只在歐洲，美國新建的學院體系透過教師、示範儀器與少量資助，同樣能做出世界級工作。而亨利的「多匝細線」原理，正是遠距電報的物理基礎——訊號經過長導線衰減後，仍足以驅動高靈敏電磁鐵。

### 電報競賽：莫斯—維爾與庫克—惠斯通

有了電磁鐵，電報從概念變成工程。英國方面，威廉·庫克（William Cooke）與查爾斯·惠斯通（Charles Wheatstone）於 1837 年取得專利，並抓住一個制度性機遇：鐵路。鐵路公司急需協調雙線軌道上的列車與信號，庫克—惠斯通的針式電報沿鐵路沿線鋪設，1850 年代已遍及英國路網。鐵路與電報自此結為共生經濟：鐵路提供路權、電桿與維修人力，電報提供調度安全與調度效率，兩者互相放大彼此的商業價值。

美國方面，畫家出身的薩繆爾·莫斯（Samuel Morse）與機械師阿爾弗雷德·維爾（Alfred Vail）於 1838 年前後發展出點劃碼（後稱摩斯電碼），以最少的訊息狀態編碼字母——這是資訊編碼思想的先聲。1844 年，華盛頓至巴爾的摩的電報線以「What hath God wrought」訊息開通。莫斯的成功一半來自專利與法律：他透過專利訴訟與授權建立起商業帝國模式，也確立了「發明即資本」的美式遊戲規則——西方聯盟電報公司日後壟斷全美電報網，正是這套制度的產物。

### 跨越大西洋：資本、保險與失敗學

1858 年，第一條跨大西洋海底電纜在大西洋電報公司（由實業家菲爾德 Cyrus Field 奔走集資）支持下敷設成功，維多利亞女王與布坎南總統互致賀電——數週後電纜即因過高電壓損毀。這場失敗迫使工程界直面新問題：訊號在長電纜中的延遲與畸變（後由開爾文以理論解決，催生「反射計」式的工程科學），以及深海電纜的機械強度。1866 年，「大東方號」（Great Eastern）成功敷設永久性電纜。背後是倫敦金融市場的資本動員與保險制度的風險分擔——大東電纜公司此後數十年壟斷全球海底電纜網。電報工程因此成為「現代大型工程專案」的範本：資本、保險、科學理論與工程失敗學（從失敗中提煉設計準則）缺一不可。

### 新聞、金融與戰爭的重塑

電報一出，資訊的物理限制被打破：訊息傳遞速度首度超越馬車、火車與輪船。路透社等通訊社應運而生，新聞從「事件發生數日後」變成「數小時內」；金融市場上，倫敦與紐約的匯率與股價得以同步套利，全球資本市場的雛形出現；軍事上，克里米亞戰爭（1853–56）成為第一場「被電報即時報導並遙控指揮」的戰爭，政治中心第一次能直接干預遠方戰場——電報因此重塑了戰爭的權力結構，也埋下日後無線電與密碼戰的伏筆。

### 因果鏈條

奧斯特「電生磁」→ 斯特金電磁鐵（可開關的磁力）→ 亨利多層繞組與強力電磁鐵（美國學院科學）→ 遠距訊號成為可能 → 英國：庫克—惠斯通電報 × 鐵路共生經濟；美國：莫斯—維爾點劃碼 × 專利商業化 → 跨大西洋電纜：資本＋保險＋工程失敗學 → 資訊超越運輸速度 → 新聞通訊社、全球金融同步、戰爭遙控指揮 → 奠定現代資訊社會的物質基礎。
