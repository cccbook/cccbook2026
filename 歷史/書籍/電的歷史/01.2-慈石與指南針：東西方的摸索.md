# 第 2 節 慈石（磁鐵礦）與指南針：東西方對磁現象的摸索與應用

## 從「慈石」到司南：中國的發現與應用

中國人稱磁鐵礦為「慈石」，取其「慈愛地吸引鐵子」之意——《呂氏春秋》已載「慈石召鐵，或引之也」。戰國末期，工匠以天然磁石琢磨成勺狀，置於光滑的「地盤」上，勺柄自然指南，是為**司南**。《韓非子》已有「先王立司南以端朝夕」的記載。值得注意的是，司南最初多用於占卜與堪輿——「定向」的能力，首先服務於禮制與風水，而非航海。

技術的轉向發生在宋代。北宋沈括（1031–1095）在《夢溪筆談》中記載了四種裝置磁針的方法（碗唇旋定、指甲旋定、縷懸、水浮），並記下兩個至關重要的觀察：

> 「方家以磁石磨針鋒，則能指南，然常微偏東，不全南也。」

這是**磁偏角**（磁北與真北的夾角）在世界上最早的明確記載——比歐洲哥倫布在大西洋上的同類發現早了約四百年。沈括還注意到磁針「常指南，亦有指北者」，暗示他已觸及磁極的同異相斥相吸。

朱彧《萍洲可談》（1119年）則留下了航海應用的實錄：「舟師識地理，夜則觀星，晝則觀日，陰晦觀指南針。」到南宋，**指南針已成為遠洋商船的標準配備**，配合「針路」（羅盤航線記錄）與水羅盤，中國商船得以遠航印度洋。

## 絲路與阿拉伯世界的傳播

指南針沿著海陸貿易網絡西傳。十二至十三世紀，阿拉伯航海文獻中出現了磁性浮針的記載，波斯語稱之為「魚」。阿拉伯商人在印度洋與紅海的航線上使用羅盤，並可能將這項技術連同中國的海圖知識傳入地中海世界。**貿易網絡不僅運送商品，也運送著能擴張貿易本身的技術**——這是技術傳播史上反覆出現的正回饋。

## 歐洲：亞歷山大·涅克姆的記載與航海羅盤

歐洲最早的文字記錄出自英國修士**亞歷山大·涅克姆（Alexander Neckam，1157–1217）**。約1190年，他在《論事物的本性》（De naturis rerum）中描述：船上備有一枚磁化鐵針，以樞軸支撐，轉動後即指向北方，供水手在陰天辨向使用。此後不出百年，乾式樞軸羅盤與刻度盤「風玫瑰」在義大利完成整合，成為地中海商船的標準儀器。

## 羅盤如何重塑經濟史

```mermaid
flowchart LR
    A[磁石: 中國戰國] --> B[司南: 占卜/堪輿]
    B --> C[宋代指南針+針路]
    C --> D[遠洋航運常態化]
    D --> E[絲路海路傳播]
    E --> F[阿拉伯航海羅盤]
    F --> G[歐洲乾式羅盤 13世紀]
    G --> H[漢薩同盟/地中海貿易]
    H --> I[遠洋貿易革命]
```

磁羅盤的意義，遠不止「多一件儀器」。它改變了航海的**經濟結構**：

1. **風險成本下降**：陰天、霧夜不再意味著迷航與船難。保險費率、貨損率隨之降低，遠距貿易的預期報酬率上升。
2. **冬季航行成為可能**：過去地中海貿易在冬季「海禁」，羅盤使全年航運漸趨常態化，資本週轉加快。
3. **航線記錄化**：「針路」與波特蘭海圖（portolan chart）讓航線成為可累積、可傳承的知識資產——這是資訊資本主義的遠古雛形。
4. **商業組織升級**：北海與波羅的海的**漢薩同盟**、威尼斯與熱那亞的地中海網絡，都以可靠航線為基礎進行分工：貨棧、匯兌、保險、複式簿記相繼成熟。

換言之，**一撮磁化的鐵針，參與催生了現代商業制度的全套配備。** 而當歐洲船隊在十五世紀駛入大西洋、繞過非洲、橫渡印度洋時，羅盤正是帝國擴張的無聲引擎。哥倫布在1492年橫渡大西洋途中注意到磁偏角隨地點變化——這個「異常」日後將成為科學的問號。

## 知其用而不知其理

但整個中世紀，無論東西方，磁現象始終停留在「術」的層次：工匠會用，占卜師會說，哲學家（如馬里古的皮埃爾在《論磁石的信》）也只是堆疊荒誕假說——磁石怕洋蔥、能治療頭痛、被「天球」吸引。**應用走在了理論前面四百年，理論的債務終須有人償還。**

**因果鏈條**：磁針推動了貿易，貿易催生了疑問——為什麼針總是指向北方？磁偏角為何隨地而變？這些由商船與帝國帶來的實際難題，正等著一位兼具宮廷地位與實驗精神的學者。而在他登場之前，我們還須回望人類對天空中那道更大「放電」的漫長恐懼。下一節，雷電的神話。
