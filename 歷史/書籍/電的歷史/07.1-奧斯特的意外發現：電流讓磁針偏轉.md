# 第 7 章 電與磁的會合

## 第 1 節 漢斯·奧斯特（Hans Christian Ørsted）的意外發現：電流造成磁針偏轉

1820 年春天，哥本哈根大學的一間教室裡，四十三歲的物理學教授漢斯·奧斯特正在為一堂課做準備。他手邊有一組伏打電堆、一根白金導線，以及一具指南針。當導線接通電流、恰好橫越在磁針上方時，他注意到一件旁人可能視而不見的事：磁針輕輕晃動，然後停在一個不再指向南北的位置。

這不是純然的運氣。奧斯特尋找電與磁的關聯已經超過十年。他深受康德哲學與德國自然哲學（Naturphilosophie）熏陶，堅信自然界的各種「力」——電、磁、光、熱、化學親和力——並非彼此孤立，而是同一根本力量的不同顯現。這種「自然力統一」的先驗信念，在當時法國主流的量化實驗傳統看來近乎形上學空談，卻驅使奧斯特年復一年地在講台與實驗桌上試探電流對磁石的作用。這是科學史上罕見的「思想先行於實驗」的案例：不是觀察引導理論，而是一個哲學信念讓他在意外降臨時認得出它的意義。

### 垂直性：違反直覺的幾何

更耐人尋味的是，他的實驗為何遲遲不成功。早期研究者多半預期電流對磁針的作用應沿著導線方向「拉」或「推」磁極——即作用力沿兩者連線。奧斯特起初的實驗也把導線與磁針擺成直角，因而一無所獲。直到那堂課上導線與磁針平行放置，效應才顯現。而且作用力的方向既不沿導線、也不沿磁針，而是垂直於兩者構成的平面：把右手拇指沿電流方向，四指環繞的方向就是磁場環繞的方向。這種「環繞性」（後來稱為右手定則）徹底背離了牛頓式「力沿連線作用」的直覺，等於宣告自然界存在一種全新的幾何。難怪當年七月他以拉丁文短文《關於電流衝突對磁針效應的實驗》寄發歐洲各科學院時，許多一流學者起初難以置信。

### 歐洲的迅速回響

信件所到之處，迴響快得驚人。在日內瓦，阿拉戈（Arago，當時同行的另有其人，阿拉戈則在巴黎）於數週內獲悉並向法國科學院報告；安培在幾星期內完成系列實驗並提出電動力學理論；阿喇戈（Dominique Arago）則演示了電流使鐵屑附著於載流導線，通往電磁鐵的路由此打開。巴黎的數學物理傳統迅速把這個粗糙的演示轉化為精密的定量科學。一位丹麥教授的課堂片刻，在數個月內重組了歐洲物理學的地圖。

### 小國的科學

奧斯特的處境也值得深思。丹麥當時是人口不過百餘萬的北歐小國，科學資源遠不如巴黎、倫敦。哥本哈根大學教授同時肩負繁重教學，奧斯特還是出色的科普講者與教育家——他後來創立了推廣自然科學的學會，丹麥今天的「奧斯特獎章」即以他為名。小國的制度處境有弊亦有利：教學負擔讓他長期在講台上重複演示，反而增加了偶然碰上現象的機率；而丹麥大學「自然哲學」課程未完全臣服於法國式專業分工，使康德式思辨與實驗得以並存於一人之身。電磁學的誕生，因此不只是個人故事，更是教育制度與哲學氛圍交織的產物。

### 因果鏈條

康德／自然哲學的「自然力統一」信念 → 驅動奧斯特十年持續試驗 → 課堂演示的偶然條件（導線與磁針平行）→ 觀察到垂直性偏轉 → 拉丁文快信傳遍歐洲 → 巴黎（安培、阿喇戈）迅速數學化與實驗擴充 → 電磁學成為新學科 → 小國教育制度與哲學氛圍孕育重大突破的範例 → 直接通往安培電動力學與電磁鐵。
