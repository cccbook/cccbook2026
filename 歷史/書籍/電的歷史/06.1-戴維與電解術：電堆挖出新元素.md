# 第六章　電化學與電路：動電時代的科學與工程

## 第 1 節 漢弗里·戴維（Humphry Davy）與電解術：利用電堆發現鈉、鉀等新元素

### 一、巨型電池組：用功率轟開化學的邊界

伏打電堆傳到英國後，最先意識到其化學潛力的，是倫敦皇家研究院（Royal Institution）年輕的化學教授漢弗里·戴維（Humphry Davy, 1778–1829）。他說服研究院的董事們斥巨資建造史無前例的巨型電池組——數百對銅鋅極板、占滿整個地下室的規模。功率，成為戴維的武器。

1807 年，戴維做了一個前人不敢想的實驗：不用水溶液，而是把苛性鹼（氫氧化鉀）加熱熔融成液態，再通以強電流。熔融鹼中沒有水干擾，電流直接奪取化合物中的金屬——陰極上凝結出閃著金屬光澤的小珠，接觸水便猛烈爆燃。這是**鉀**；數日後用同法從蘇打得到**鈉**。1808 年他再接再厲，以電解配合石灰汞齊等方法，接連分離出**鈣、鍶、鋇、鎂**。兩年之間，元素表憑空多出一整列金屬——此前人類只用火、炭與酸提煉元素，如今「電」成為威力空前的化學試劑。

戴維的電解術不僅是發現，更確立了一條新的認識論路徑：**物質的親和力就是電性的傾向**。他提出化學親和力與電吸引的同源性思想，這是後來電化學價鍵理論（貝齊利烏斯乃至更遠）的思想起點。拉瓦錫說氧是酸之本，戴維用電解證明鹽酸不含氧、氯是元素——電化學直接改寫了化學的基本概念。

### 二、皇家研究院：貴族贊助與科普講座的制度創新

戴維的舞台本身也是一項制度發明。1799 年成立的皇家研究院，靠貴族與地主階層捐款運作，其章程明定雙重任務：為農業與製造業改進技術，並向公眾傳播科學。它發明了兩樣影響深遠的東西：**應用研究實驗室**與**面向付費公眾的定期科普講座**。上流社會的女士與紳士買票入場，觀看化學演示與電學實驗，成為攝政時期倫敦的時髦社交。

這個「知識娛樂化、科學資產化」的模式，解決了純科學的經費來源問題：貴族的贊助動機（時尚、聲望、以及農業改良的實際利益）供養了前沿研究；講座收入與捐助又反哺儀器（如戴維的巨型電池）。科學、貴族經濟與都市消費文化在此形成三角驅動。戴維正是這套制度打造的第一位科學明星。

### 三、講台上的明星與煤礦裡的安全燈

戴維的講座魅力是傳說級的：俊美、雄辯、演示驚人，聽眾為擠進講堂而阻塞街道。他證明了一件事——**科學家可以成為公共人物，科學傳播本身可以是職業**。這種「科普明星」現象塑造了此後兩世紀的科學公關文化，從法拉第的聖誕講座、到當代的科普直播，血脈相承。

戴維也有扎實的工程貢獻。1815 年前後，英國煤礦頻繁發生沼氣（甲烷）爆炸，礦工死傷慘重——煤礦是當時英國經濟的動脈，供應家庭取暖、冶鐵與新興蒸汽機。戴維受煤礦業主委託研究爆炸原理，以細金屬網罩住火焰製成**安全礦燈**（Davy lamp，1815–16）：網目導熱使火焰溫度低於甲烷燃點，燈罩內外氣體互不引爆。安全燈立刻普及，被礦工視為救命物，戴維獲得隆姆福德獎章與國家感謝。這是「基礎物理原理（熱傳導與燃點）→ 工程設計 → 拯救生命 → 支撐能源產業擴張」的完整鏈條，也預示了煤—蒸汽—礦燈—電氣化之間即將到來的能源史交響。

### 四、法拉第：裝訂工學徒走進地下室

1812 年，一位曾在書店當裝訂學徒的青年邁克爾·法拉第，聽了戴維的講座，把筆記裝訂成冊寄給戴維，請求一份差事。1813 年，戴維聘他為實驗室助手。此後法拉第隨戴維出訪歐陸、參與電解研究，從洗瓶子、製作電池，逐步成長為史上最偉大的實驗物理學家。

這段師承關係有雙重意義。制度上，它展示了皇家研究院「學徒制科研培養」的可行性——正規大學之外，實驗室本身就是一所學校（英國當時的大學幾乎不教實驗科學）。人事上，它留下戲劇性的伏筆：戴維晚年據說在被問及一生最大發現時回答「法拉第」。然而戴維也曾因嫉妒而阻撓法拉第進入皇家學會。天才的發現者與被發現的天才之間的張力，正是科學社群內部競爭與傳承的縮影。下一節將看到，把電學再往前推一大步的，另有其人——一位德國中學教師。

### 因果鏈條

> 伏打電堆問世 → 戴維說服皇家研究院建造巨型電池組（貴族贊助制度供資）→ 1807–08 年電解熔融鹼 → 鉀、鈉、鈣、鍶、鋇、鎂相繼問世 → 電化學確立「電—化學親和力同源」思想 → 皇家研究院科普講座打造科學明星文化 → 煤礦爆炸事故與煤礦經濟需求 → 戴維安全礦燈（基礎科學→工程救生→產業支撐）→ 裝訂工法拉第入實驗室為助手 → 學徒制科研培養 → 師承伏筆連向第八章的場論革命。
