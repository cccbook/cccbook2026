# 台灣電子產業史——無資源小島為何成為全球電子中心

## 總序：一樁歷史懸案的偵查

一個沒有天然資源、被殖民與戒嚴反覆塑造、直到 1960 年代還在靠蔗糖與紡織換外匯的小島，六十年後卻掌握了全球先進晶圓代工九成以上的產能，成為美中兩強都不能不搶的「護國神山」。這件事本身不稀奇——技術會擴散、資本會流動。真正令史家著迷的是案發現場的幾個反常細節：

第一，台灣的每個「優勢」拆開來看，都不是台灣的發明：加工出口區是借來的制度，IC 技術是 RCA 賣的，晶圓代工的客戶是美國的，設備是荷蘭與日本的。台灣像是把別人的零件重新組裝，卻組出了一台別人都開不動的機器。

第二，同樣的政策工具（科技園區、技術移轉、國家研發），世界上幾十個國家都模仿過，大多失敗。韓國走的是財閥自研的大規模路線，台灣走的卻是「國家先賭、賭完放手」的小規模路線——兩條路最後在半導體相遇。

第三，每次產業升級，風險都先由國家承擔（工研院研發、開發基金入股），再遞移給市場（衍生公司、上市、訂單淘汰）。這條「風險遞移鏈」是台灣模式的核心機制。

本書的偵查立場由此確立：**不問「台灣為何會強」（那是人人都會強的問題），而問「為何偏偏是台灣」**。答案是一條連乘的因果鏈——任何一項為零，積便為零：

$$
\text{台灣模式}=\underbrace{\text{地理與人才}}_{\text{留美工程師回流}}\times\underbrace{\text{政策設計}}_{\text{加工出口區}\cdot\text{工研院}\cdot\text{科學園區}}\times\underbrace{\text{技術移轉}}_{\text{RCA計畫}}\times\underbrace{\text{垂直分工}}_{\text{專業代工}\cdot\text{風險遞移鏈}}\times\underbrace{\text{摩爾定律}}_{\text{贏者全拿}}
$$
