# 8.1 薛丁格方程：複數（Complex Numbers）與波函數

## 背景：一場由燈泡公司資助的理論危機

1900 年 12 月 14 日，柏林。普朗克（Max Planck）報告黑體輻射譜的理論，被迫假設能量以離散份額（量子 $E = h\nu$）發射。歷史背景：**德國電氣工業（西門子等）需要精確的輻射標準來製造更亮更省的燈泡**——「標準燭光」的黑體測量是柏林國家物理技術研究院（PTR，1887 成立，世界首個國家計量院）的核心任務。**量子理論的第一個資助者是電燈產業。**

之後的連鎖：

- 1905 愛因斯坦：光電效應——光是粒子（光子）
- 1913 波耳：氫原子模型，電子軌道量子化（解釋了氫光譜線——巴耳末 1885 年的經驗公式）
- 1922–26 德布羅意：物質波 $\lambda = h/p$（他的博士論文，委員會拿不定主意，寄給愛因斯坦——愛因斯坦說「掀開了大幕的一角」）
- 1925 海森堡：矩陣力學（見 8.2）

## 1926 年初：薛丁格的「聖誕奇蹟」

薛丁格（Erwin Schrödinger）當時 38 歲，蘇黎世大學教授，原本研究的是統計力學與色之理論（他還寫詩）。1925 年底他讀到德布羅意的論文，德拜在蘇黎世研討會上說：「你的波在哪裡？波應該有波動方程！」——薛丁格聖誕假期到山間別墅（阿爾卑斯，註明「與一位舊情人」），回來時帶著波動力學。

**薛丁格方程**（含時）：

$$i\hbar\frac{\partial\Psi}{\partial t} = \hat{H}\Psi = \left(-\frac{\hbar^2}{2m}\nabla^2 + V\right)\Psi$$

最令人不安的特徵：$\Psi$ 是**複數**。薛丁格本人為此苦惱——他想找「實數」的波，但找不到自洽的版本。

## 複數的前史：又一次「數學搶跑」

| 年代 | 事件 |
|------|------|
| 1545 | 卡爾達諾《大術》第一次在解三次方程時被迫用 $\sqrt{-1}$（「精神折磨式的細微事物」） |
| 1572 | 邦貝利給出虛數運算規則 |
| 1637 | 笛卡兒創「虛」（imaginary）一詞——貶義 |
| 1748 | 歐拉公式 $e^{i\theta} = \cos\theta + i\sin\theta$ |
| 1799/1831 | 高斯確立複數平面，賦予幾何意義，並說服數學界接納 |
| 1926 | 薛丁格方程：複數成為物理實在的描述語言 |

**三次大規模的複數應用**：交流電工程（史坦梅茨 1890s 把複數變成電機工程的日常工具——通用電氣的培訓教科書）、相對論的四維時空（$ict$ 記號）、量子力學。每次都是「不可能存在的數」先在代數中被迫出現，再被幾何/物理收編。**數學的邏輯一致性，比人類的直覺更可靠。**

## 為什麼必須是複數？三個理由

**1. 波的「二維性」**。波需要兩個實數描述：振幅與相位。複數 $re^{i\theta}$ 把兩者打包成一個數；時間演化是相位旋轉。實數波函數無法正確表達干涉的相位結構。

**2. 用「頻率」編碼能量**。定態解 $\Psi(t) = \psi e^{-iEt/\hbar}$：能量 $E$ 以**旋轉速率**的方式存在於相位中。對時間求導：

$$i\hbar\frac{\partial\Psi}{\partial t} = E\Psi$$

「對時間微分 = 乘上 $E/(i\hbar)$」——能量算符由此而來。

**3. 機率流守恆**。機率密度 $\rho = |\Psi|^2$ 的守恆方程（連續性方程）：

$$\frac{\partial \rho}{\partial t} + \nabla\cdot\vec{j} = 0$$

其中機率流 $\vec{j} = \frac{\hbar}{m}\,\text{Im}(\Psi^*\nabla\Psi)$ **用到了虛部**——實波函數的機率流為零，無法描述散射與電流。

## 解一個原子：氫原子與化學的數學基礎

薛丁格方程套上庫侖位能 $V = -e^2/4\pi\varepsilon_0 r$，解出的能級**精確重現氫光譜**（巴耳末公式），且給出三個量子數 $n, l, m$。再加上自旋與包利不相容原理：

> **門捷列夫週期表（1869，化學經驗規律）被重寫為「薛丁格方程 + 包利原理」的推論。**

化學鍵、原子半徑、元素性質——全部從一個偏微分方程長出來。這是還原論最輝煌的勝利，也直接服務了二十世紀的材料工業（半導體！）——沒有能帶理論（薛丁格方程在晶體週期位能中的解，布洛赫 1928），就沒有電晶體（1947 貝爾實驗室）與整個電子產業。

## 詮釋之戰：波函數「是」什麼？

- **玻恩**（1926）：$|\Psi|^2$ 是機率密度——波函數是「機率幅」，疊加時**先加振幅、再平方**，這正是干涉的來源（與費馬原理的量子解釋相呼應，見 5.1）
- **哥本哈根詮釋**（玻爾、海森堡）：測量前談「粒子在哪裡」無意義
- **薛丁格的抗議**：1935 年他提出著名的**貓**思想實驗，諷刺「疊加到宏觀」的荒謬——他沒想到這隻貓成了量子科普的永久吉祥物
- 今天的戰場：多世界詮釋、退相管理論、量子資訊（資訊派）——戰爭未結束，但**數學（線性疊加 + 機率詮釋）已無人質疑**

## 歷史與制度的註腳

- 1920s 量子革命的搖籃是**哥廷根—哥本哈根—慕尼黑三角**，德國大學（教師自治 + 助教階層 + 玻恩/索末菲的研討班制度）提供了人才密度。**研討班制度（seminar）**——師生平等互詰的教學形式——是德國教育的發明，量子力學是它的最大收穫
- 1933 年納粹上台，這個三角瞬間瓦解：玻恩流亡（愛丁堡）、愛因斯坦流亡（普林斯頓）、費米流亡（芝加哥，他妻子是猶太裔）……**美國的科學霸權，一半是德國親手輸送出去的**
- 薛丁格方程今日也活在工程師的電腦裡：半導體設計（TCAD）、量子化學軟體、量子電腦模擬器，本質上都在數值求解它
