# 7.2 布朗運動與隨機過程（Stochastic Process）

## 1827 年：植物學家看到的一團亂

布朗（Robert Brown）用顯微鏡觀察花粉粒懸浮在水中，發現微粒永不停歇地做無規則運動。他排除了「生命現象」（用一百年前的炭粉也一樣），但無法解釋。此後八十年，這個現象成為原子論的懸案：**如果水是連續介質，微粒為何亂動？如果水由分子組成，撞擊為什麼不平均掉？**

## 愛因斯坦 1905：用統計終結爭論

1905 年的「奇蹟年」，愛因斯坦同時發表了三項工作：狹義相對論、光電效應（光量子的證據）、以及**布朗運動理論**。後者看似最不起眼，卻是**原子實在性的判決書**。

他的論證分三步：

**1. 擴散方程**。懸浮粒子的密度 $n(x, t)$ 滿足：

$$\frac{\partial n}{\partial t} = D\frac{\partial^2 n}{\partial x^2}$$

**2. 微觀推導**。假設每 $\tau$ 時間粒子隨機跳動一步（位移 $\Delta$），密度演化給出擴散係數：

$$D = \frac{\Delta^2}{2\tau}$$

**3. 與熱力學掛鉤**。用滲透壓 + 膠體粒子在重力下的平衡分布（分子動力學 + 阿伏伽德羅常數），得：

$$D = \frac{kT}{6\pi\eta a}$$

其中 $\eta$ 是液體黏度，$a$ 是粒子半徑。**全部是可測量**：給定溫度、黏度、粒徑，就能預測擴散速率；反過來，測擴散就能算出**亞佛加厥常數**——也就是「一摩尔裡有多少個原子」。

1908–09 年，佩蘭（Jean Perrin）的實驗（顯微鏡逐粒追蹤膠體）完全證實愛因斯坦公式，測得 $N_A$。**原子論獲得實驗判決**，佩蘭獲 1926 年諾貝爾獎。奧斯特瓦爾德（唯能論領袖）隨即承認原子實在——玻茲曼若能看到這一天……

## 隨機過程：把「亂走」變成數學對象

愛因斯坦—斯莫魯霍夫斯基的布朗運動理論，在 1920s 被數學家（維納 Norbert Wiener）公理化為**維納過程** $W_t$：

- $W_0 = 0$
- 增量獨立：$W_t - W_s$ 與過去無關
- 增量是常態分布：$W_t - W_s \sim N(0, t - s)$
- 軌跡**連續但處處不可微**——與魏爾斯特拉斯的病態函數呼應，但這次它描述的是**物理實在**

粒子位置滿足**朗之萬方程**（Langevin, 1908）：

$$m\frac{dv}{dt} = -\gamma v + \xi(t)$$

其中 $\xi(t)$ 是隨機力（分子撞擊）。這是**隨機微分方程**（SDE）的起點：微分方程 + 噪聲項。伊藤清（Kiyosi Itô, 1940s）建立了 SDE 的嚴格微積分（伊藤引理）——注意：這位日本數學家的工作誕生於二戰期間相對隔絕的東京，戰後經由貝爾實驗室（用於電路噪聲）進入主流，最終成為**金融數學的官方語言**。

## 黑—斯科爾斯：熵的遠房子孫如何統治華爾街

1973 年 Black–Scholes 選擇權定價公式，數學骨架完全來自布朗運動：

$$dS = \mu S\,dt + \sigma S\,dW_t \qquad(\text{股價 = 漂移 + 幾何布朗噪聲})$$

$$C = S N(d_1) - K e^{-rT} N(d_2)$$

這條公式開創了衍生性金融商品市場（選擇權交易量爆炸）→ 1997 年諾貝爾經濟學獎 → 1998 年 LTCM 長期資本管理公司崩盤（用同類模型槓桿豪賭，聯準會出面協調救助）→ 2008 年金融海嘯的爭議背景（信用商品定價同樣依賴高斯隨機假設）。

**數學模型的政治經濟學教訓**：當一條公式成為整個產業的定價標準，它對「現實偏差」的盲點會被槓桿放大成系統性風險。**布朗運動假設了漲跌互相獨立，而金融恐慌是高度相關的**——這正是模型的社會生命週期中，人們忘記假設條件的時刻。

## 隨機過程的現代版圖

| 應用 | 模型 |
|------|------|
| 物理化學 | 擴散、反應動力學 |
| 生物學 | 神經元放電（Leaky Integrate-and-Fire）、族群遺傳漂變（Wright–Fisher） |
| 疫情 | 隨機 SIR、超級傳播者事件 |
| 機器學習 | **隨機梯度下降（SGD）**——訓練神經網路的核心演算法就是離散化的朗之萬動力學；擴散模型（Stable Diffusion、Midjourney 背後的圖像生成）= 學習逆轉一個布朗運動 |
| 蒙地卡羅方法 | 曼哈頓計畫（von Neumann、Ulam）為中子擴散而發明，今日是金融風控與圖形渲染（光線追蹤）的基礎 |

**擴散模型的直覺**：往圖片上加噪聲就像讓墨滴擴散（熵增、可預測）；AI 生成圖像就是學會「熵減的方向」——從噪聲一步步反推回清晰影像。**克勞修斯的熵與你的 AI 繪圖，是一條數學血脈的兩端。**

## 小結

- 布朗運動：物理懸案（原子是否存在）→ 統計論證（愛因斯坦 1905）→ 實驗判決（佩蘭）
- 數學成果：維納過程、伊藤積分——「隨機性」成為可計算的對象
- 應用鏈：原子論 → 電路噪聲 → 選擇權定價 → SGD 與擴散模型
- 一貫主題：**微觀的混亂，在統計上產生宏觀的規律；而寫下這個規律的語言，就是機率與微積分的合體**
