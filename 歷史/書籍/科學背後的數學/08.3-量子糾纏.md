# 8.3 量子糾纏：線性代數中的張量積與態疊加

## 態疊加：量子力學的語法

量子態是希爾伯特空間中的向量（狄拉克記號 $|\psi\rangle$）。兩個態可以相加：

$$|\psi\rangle = \alpha|0\rangle + \beta|1\rangle, \qquad |\alpha|^2 + |\beta|^2 = 1$$

這是**線性代數**的直接應用：疊加 = 向量相加；測量 = 投影；機率 = 分量平方。量子計算的一切花樣，都建立在此語法上。

## 張量積：兩個系統如何「合起來」

兩個粒子合成的系統，態空間不是相加而是**張量積**（維度相乘）：

$$\mathcal{H}_A \otimes \mathcal{H}_B, \qquad \dim = n_A \times n_B$$

若 $|0\rangle, |1\rangle$ 是單量子位基態，兩量子位空間由四個基張成：$|00\rangle, |01\rangle, |10\rangle, |11\rangle$。

**關鍵問題**：哪些兩粒子態可以拆成「各自單獨的描述」？

- 可分離態：$|\psi\rangle = |\psi_A\rangle \otimes |\psi_B\rangle$——各自描述即可
- **糾纏態**：**不可**寫成張量積的態，例如

$$|\Phi^+\rangle = \frac{1}{\sqrt{2}}\left(|00\rangle + |11\rangle\right)$$

嘗試分離：需要 $\alpha|0\rangle \otimes \gamma|0\rangle + \alpha\gamma|0\rangle\otimes|1\rangle$ 型項出現 $|01\rangle$ 與 $|10\rangle$ 係數——但它們在 $|\Phi^+\rangle$ 中為零。代數卡死：**這個態不可分解**。你無法說「第一個粒子是什麼狀態」——整體有確定性質，部分沒有。

**張量積的維度爆炸**是量子計算力量的來源：$n$ 個量子位的態空間是 $2^n$ 維。描述 300 個量子位需要 $2^{300}$ 個係數——超過可觀測宇宙的原子數。**量子電腦不是「更快的電腦」，而是活在不同維度空間裡的電腦。**

## EPR 之爭（1935）：一場由論戰催生的科學

1935 年，愛因斯坦與波多爾斯基、羅森發表 EPR 論文，指出糾纏態意味著：測量 A 粒子，**瞬間**確定遠方 B 粒子的狀態。愛因斯坦稱之「幽靈般的超距作用」，認為這證明量子力學不完備——應有「隱變數」決定一切。

薛丁格同年回應，創造「糾纏」（Verschränkung）一詞，並說這「不是量子力學的特色之一，而是它的全部特色」。

注意歷史情境：1935 年正是愛因斯坦抵達普林斯頓的第一年、納粹德國的第四年。這場論戰的兩位主角（玻爾在哥本哈根、愛因斯坦在普林斯頓）來自同一個崩解的歐洲科學共同體。**學術論戰的發生，需要雙方都還在場；戰後的世界，愛因斯坦的追問被冷落了三十年**——「哲學問題」，物理系學生被如此教導。

## 貝爾定理（1964）：把哲學變成實驗

北愛爾蘭的物理學家約翰·貝爾（John Bell，在 CERN 做加速器本職工作，糾纏是他的「業餘愛好」）證明：

> 任何「定域隱變數」理論都必須滿足一個不等式（貝爾不等式）；而量子力學的預測**違反**它。

貝爾不等式的一種形式（CHSH）：

$$|S| \leq 2, \qquad S = E(a,b) + E(a,b') + E(a',b) - E(a',b')$$

量子力學（與實驗）給出最大 $|S| = 2\sqrt{2} \approx 2.83 > 2$。

**實驗裁決**：
- 1972–82：弗里德曼、克勞澤、阿斯佩（Aspect）的光子糾纏實驗——量子獲勝
- 2015：「無漏洞」實驗（荷蘭 Delft、維也納、NIST）同時封堵定域性漏洞與偵測漏洞
- 2022：Aspect、Clauser、Zeilinger 獲諾貝爾物理獎

**思想史意義**：貝爾定理是哲學史上罕見的時刻——**一個形上學爭論（世界是否獨立於觀察而確定）被轉化為實驗可判定的數學不等式，並且被判定**。數學又一次充當了不同世界觀之間的仲裁者。

## 應用：糾纏從哲學變成資源

| 技術 | 糾纏的角色 | 狀態 |
|------|-----------|------|
| 量子密鑰分發（QKD） | 竊聽必然擾動糾纏 → 可偵測 | 中國「墨子號」衛星（2016）、商用系統 |
| 量子計算 | 糾纏 + 疊加 = 指數級狀態空間 | Google「懸鈴木」2019 量子霸權實驗 |
| 量子隱形傳態 | 傳輸量子態（非物質） | 1997 起多次演示，衛星間 1200 km |
| 量子感測 | 糾纏突破標準量子極限 | 原子鐘、重力測量（LIGO 已用量子擠壓光） |

產業與地緣政治：量子科技已成為國家戰略（美國《國家量子倡議法案》2018、中國十四五規劃、歐盟量子旗艦計畫）——**基礎線性代數進入了大國競爭的預算表**。這是本書反覆出現的模式在 2020s 的重演：1940s 的核物理、1960s 的太空數學、2020s 的量子資訊。

## 給讀者的線性代數練習

驗證 $|\Phi^+\rangle$ 不可分離：假設 $\frac{1}{\sqrt2}(|00\rangle+|11\rangle) = (a|0\rangle + b|1\rangle)\otimes(c|0\rangle + d|1\rangle)$。展開比較係數：$ac = 1/\sqrt2$，$bd = 1/\sqrt2$，$ad = 0$，$bc = 0$。若 $a \neq 0$ 則 $d = 0$，與 $bd = 1/\sqrt2$ 矛盾；若 $a = 0$ 則 $ac = 0$，矛盾。∎

一個小時的線性代數，就能「證明」大自然不允許的世界觀。**這就是數學的力量：它讓不可見的結構成為可爭辯、可檢驗的對象。**
