# 1.2 面積與時間的對話：開普勒第二定律與微積分的前身

## 一個奇怪的發現：行星的速度忽快忽慢

開普勒在 1602 年前後注意到：行星靠近太陽時跑得快（近日點），遠離時跑得慢（遠日點）。如果軌道是橢圓，這是必然的——但他想找的不是「現象」，而是「規律」。

他嘗試了無數種速度與距離的關係（多數是錯的，包括他自己一度相信的「速度與距離成反比」），最後發現了一個意想不到的不變量：

**開普勒第二定律（面積定律）**：太陽與行星的連線，在相等時間內掃過相等面積。

$$\frac{dA}{dt} = \text{常數}$$

## 為什麼「面積」是關鍵？——微積分的前身

這裡有一個深刻的方法論轉變。希臘數學處理的是**靜態形狀**；開普勒處理的是**連續變化的量**——他必須把橢圓切成無數個小扇形，把時間切成無數個小段，然後問：「當小段趨近於零，總和是什麼？」

這正是**積分**的思想，比牛頓和萊布尼茨早了六十年。開普勒用同樣的方法計算了酒桶的體積（《測量酒桶體積的新科學》，1615）——這本書的緣起很有市場經濟味道：他在奧地利的酒商賣酒時用不準的容量估算，他認為交易不公，乾脆寫書解決。**數學革命有時始於一筆不愉快的買賣。**

## 幾何證明：面積定律等價於角動量守恆

```mermaid
flowchart LR
    G[引力沿連線方向<br>徑向力] --> N[對太陽力矩為零]
    N --> L[角動量 L 守恆]
    L --> A[掃面積速率 dA/dt 恆定]
```

把極短時間 $dt$ 內行星的位移想成一條小弦。掃過的小三角形面積：

$$dA = \tfrac{1}{2} |\vec{r} \times d\vec{r}| = \tfrac{1}{2} |\vec{r} \times \vec{v}|\, dt = \frac{L}{2m}\, dt$$

其中 $\vec{L} = m\,\vec{r} \times \vec{v}$ 是角動量。因為引力 $F \propto 1/r^2$ **永遠沿著連線方向**（徑向），它對力矩 $\vec{\tau} = \vec{r} \times \vec{F}$ 的貢獻為零，所以 $L$ 守恆，於是 $dA/dt = L/2m$ 是常數。

**注意邏輯的精妙**：開普勒是從數據「歸納」出面積定律（1609）；八十年後牛頓「演繹」出它只是角動量守恆的幾何化身。歸納發現規律，演繹解釋規律——這是科學方法的雙引擎。

## 開普勒的朋友與敵人：時代如何對待新數學

- 開普勒的母親在 1615 年被指控為女巫，他親自為母親辯護了一年多。這不是軼聞的邊角料——它提醒我們，在「理性時代」的黎明，**數學革命與獵巫運動是同時發生的**。科學並非在啟蒙的溫室中生長，而是在迷信與戰爭的泥濘中硬擠出來。
- 三十年戰爭（1618–1648）中，開普勒為華倫斯坦的軍營做占星算命謀生。諷刺的是：**真正的天文學收入微薄，占星才是當時的「數據科學產業」**。資助結構決定了科學的形態。

## 連結：為什麼這條定律通往無窮小

面積定律本質是一個**微分方程的首次積分**：$\frac{dA}{dt} = \frac{L}{2m}$。開普勒寫下了它，卻沒有系統的方法解出 $\vec{r}(t)$——因為還缺兩樣工具：

1. 極座標下的微分技巧（牛頓才補上）
2. 「力」的精確概念（牛頓的 $F = ma$）

六十年後，這些拼圖將由一個在瘟疫年被迫離開大學的年輕人拼合。
