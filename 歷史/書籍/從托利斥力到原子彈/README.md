### 本書三個核心看點

1. **非線性卻必然的技術演進**：沒有玻璃密封與真空泵的工藝積累，就沒有 CRT 管；沒有 CRT 管就發現不了電子，更談不上中子與核反應。
2. **「資金與權力」的暗線穿梭**：從美第奇家族的宮廷贊助到美國政府的數十億美元，科學突破從不孤立存在。
3. **引人入勝的人物群像**：托里拆利、蓋斯勒、湯姆孫、查德威克、邁特納、奧本海默——跨越 300 年的知識火炬傳遞。
