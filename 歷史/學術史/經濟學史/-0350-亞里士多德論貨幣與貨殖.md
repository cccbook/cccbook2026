# -0350-亞里士多德論貨幣與貨殖：錢生錢的第一場訴訟

## 案件摘要

西元前 350 年前後，亞里士多德（Aristotle！柏拉圖學院出身！亞歷山大大帝的老師！）在《政治學》第一卷對「貨殖」（χρηματιστική！chrematistike！聚財之術！）提出人類史上最著名的經濟起訴——**核心證詞：貨幣的本職是交換的媒介，不是增殖的種子**（！）——「以錢生錢」（利息！tokos！本義「子息」！）是最違反自然的賺錢法（！因為錢不會生育！）——他區分「家計管理」（oikonomia！滿足需要的自然聚財！）與「無限貨殖」（！為累積而累積！）——**財富的目的被正式寫進哲學**（！）——這樁案件是「**給市場文明先立一條道德界線**」（！）——**此後兩千年的反高利貸傳統由此授權**（→中世紀教會禁令！→馬克思也引用他！）。

## 前因 -- 多因素的局勢

- **城邦經濟的成熟**：雅典商業（！）＋海外貿易（！）＋貨幣經濟滲透（！）——**錢第一次成為日常主角**（！）。
- **哲學傳統**：蘇格拉底—柏拉圖（！）對「善的生活」的追問（！）——**經濟問題一登場就是倫理問題**（！）。
- **奴隸制城邦**：自由人鄙視勞動（！）——**「值得做的經濟活動」預設了階級**（！）。
- **放貸者現象**：雅典已有專業金融（！）海事貸款、兌換商（！）——**利率現象需要解釋**（！）。

## 線索與推理 -- 因素咬合

### 線索一：用途 vs 交換——「鞋子的雙重生命」

亞氏的經典分析：一隻鞋（！）「可以穿、也可以換」（！）——**直接使用是第一用途，交換是衍生用途**（→用對的方式使用即是正義！）：

$$\text{物} = \text{（使用價值！）} + \text{（交換價值！）} \Rightarrow \text{為換而換（！）＝脫軌}$$

**馬克思的公式 $C-M-C$ vs $M-C-M'$ 正是這組對比的形式化**（！見 [1867-馬克思資本論.md](1867-馬克思資本論.md)）——**亞氏是商品拜物教批判的祖師**（！）。

### 線索二：錢不會生錢——「自然 vs 人為的增殖」

| 增殖方式 | 亞氏判決 |
|----------|----------|
| 農耕、畜牧 | 自然（！大地生養！） |
| 交換生活必需 | 準自然（！） |
| 零售貿易 | 界線模糊（！） |
| **放貸收息** | **最不自然**（！錢生出錢！） |

（→推理核心：增殖應來自「被培育之物的本性」——**貨幣的本性只是計量單位，硬要它生育是違反名分**！）——**這個「名分論證」統治歐洲利息倫理一千八百年**（！）。

### 線索三：無限的恐懼——「需要的自然尺度」

家計有自然的終點（！生活夠了！），貨殖沒有終點（！）——**亞氏真正的恐懼：無限性**（→「只為活著而活著」被他視為可恥！→累積為累積，把手段變目的！）——**目的論經濟學的原廠設定**（！）。

## 破案時刻

- -367：入柏拉圖學院（！）。
- -356 前後：遊歷、觀察各城邦憲制（！）。
- -350 前後：《政治學》成書（！第一卷、第一至十一章論家計與貨殖！）。
- -334：呂克昂學園創立（！）。
- 中世紀：經院學者全量繼承（！）。
- 1905：英國「亞里士多德式」社會主義者的援引（！）——韋伯夫婦、吉爾森皆回頭引用（！）。

## 後果 -- 改變了什麼

- **中世紀利息禁令**：阿奎那體系的法源之一（！見 [1282-阿奎那與正義價格.md](1282-阿奎那與正義價格.md)）——**高利貸成為重罪**（！）。
- **「自然價格」傳統**：經院—古典學派的價值理論血統（→斯密的「自然價格」用語直接是經院遺產！）。
- **馬克思的引用**：《資本論》第四篇開頭即引亞氏區分 $C-M-C$ 與 $M-C-M'$ （！）——**兩千年後的起訴書引用同一條法條**（！）。
- **倫理經濟學的伏筆**：當代金融倫理、共益經濟（！）仍以「目的」對抗「無限增殖」（！）。

## 因素影響筆記

```
城邦貨幣經濟 ──→ 亞氏的觀察 ──→ 貨殖 vs 家計的區分（-350！）
「錢不生錢」判決 ──→ 教會高利貸禁令 ──→ 阿奎那體系（1282！）
使用 vs 交換 ──→ C-M-C vs M-C-M' ──→ 馬克思拜物教批判（1867！）
「無限累積」的恐懼 ──→ 目的論經濟學 ──→ 當代金融倫理（→持續回響！）
```

**偵探結語**：亞里士多德不是經濟學家（！當時沒有這門學科！），卻替經濟學設立了第一條偵辦規則：**審問一切賺錢手段的「目的」**。他的判決在今天看來有兩處「誤判」——錢確實能透過投資再生產（！他把生產性資本當成了單純的金屬計量！），而貿易也能創造真實價值（！比較利益要到 1817 年才出庭，見 [1817-李嘉圖比較利益.md](1817-李嘉圖比較利益.md)）。但他的直覺驚人地長壽：**手段蛻變成目的，是他診斷出的經濟活動的原罪**——今天批評金融化、批評為股東價值而股東價值的人（！），用的仍是他的原始證詞。偵辦史的第一頁，寫的不是「財富是什麼」，而是「財富為了什麼」——這一問，兩千年沒有結案。
