# 1282-阿奎那與正義價格：市場的第一次道德審查

## 案件摘要

1270 年代，托馬斯·阿奎那（Thomas Aquinas！道明會士！天使博士！）在《神學大全》中系統處理經濟問題（！）——**核心判詞：賣方以高於「物品價值」的價格出售即犯欺詐罪**（！正義價格！iustum pretium！）——高利貸被正式定罪（！「錢生錢」雙重收費！）——**但他同時承認價格會隨時地浮動**（！考慮勞動成本、賣方處境、效用！）——這樁案件是「**在商業興起的歐洲替市場立法**」（！）——**阿奎那死於 1274；1260–1290 年代正值行會城市與貿易復興**（！）——**經院經濟學（Scholastics！）不是經濟學的恥辱期，是第一個分析性傳統**（→熊彼得在《經濟分析史》裡為他平反！）。

## 前因 -- 多因素的局勢

- **商業復興**：香檳市集（！）＋義大利銀行業（！）＋漢薩同盟萌芽（！）——**貨幣經濟重返歐洲**（！）。
- **教會的反高利貸立法**：1179 第三次拉特朗公會議（！）譴責放貸者；1236 里昂公會議（！）——**禁令已經執行，需要理論**（！）。
- **亞里士多德重臨**：12 世紀翻譯運動（！）→「哲學家」的權威與基督教神學的整合工程（！）——**異教智慧需要收編**（！見 [-0350-亞里士多德論貨幣與貨殖.md](-0350-亞里士多德論貨幣與貨殖.md)）。
- **行會制度**：城市手工業的價格與品質管制（！）——**「公正價格」有制度土壤**（！）。
- **大學誕生**：巴黎大學（！）——**神學家的講壇成為經濟法庭**（！）。

## 線索與推理 -- 因素咬合

### 線索一：正義價格——「不是一個數字，是一個區間」

謎題（！）：正義價格到底是多少？阿奎那的答案出人意外地寬（！）：

$$\text{正義價格} \approx \text{（通行市價！）} \pm \text{（勞動成本）} \pm \text{（風險）} \pm \text{（時地差）}$$

| 情境 | 判決 |
|------|------|
| 市場競爭下自願成交 | 大致正義（！） |
| 以次充好、缺斤短兩 | 欺詐（！罪！） |
| 賣方急需、買方趁機壓價 | 不義（！） |
| 運貨入饑荒區加價 | 可容許（！風險與運費！） |

（→**他其實承認了市場價格的正當性**——現代解讀兩極：一派說他是成本論者，一派說他是效用論先驅——**兩派都能找到引文**（！）——這正是文本的豐富）。

### 線索二：高利貸之辯——「時間屬於誰？」

阿氏繼承亞里士多德（！）並加上神學論證（！）：

- **所有權論證**：利息是出售「尚未屬於你的東西」（！時間是上帝的！）——**「賣時間」= 賣不屬於自己的物**（！）。
- **消費品 vs 生產品**：貨幣是消費品（！用掉即不存！），借用必須歸還本體——**收息即雙重出售**（！）。
- **但漏洞已開**：合夥共擔風險可收利潤（！）＋賠償性收入（interesse！達默羅達損失！）——**現代金融由此裂縫生長**（→後來的「盧克薩三合約」把利息合法包裝！）。

### 線索三：私有財產的收編

阿氏與教父傳統分道（！奧古斯丁視私有為墮落！）：**私有財產合乎自然法**（！因人類對自己之物更用心照管！）——**但使用上有社會義務**（！急需者取用不算偷竊！）——**「產權在己、使用在義」的公式**（→後世社會市場經濟的思想遠祖！）。

## 後果 -- 改變了什麼

- **正義價格的長壽**：直到 16 世紀仍在神學家筆下活躍（！）——**薩拉曼卡學派把它推向主觀價值論**（→邊際革命的遠祖！見 [1871-邊際革命三傑.md](1871-邊際革命三傑.md)）。
- **禁令的日常運作**：猶太人與倫巴第人的放貸豁免（！）——**經濟歧視的制度化**（！）——**也倒逼了銀行技術創新**（匯票繞道！）。
- **熊彼得的致敬**：《經濟分析史》稱經院學者為「被誤解的偉大分析家」（！）——**二十世紀對中世紀的平反**（！）。
- **當代回響**：公平貿易、價格管制辯論（！）——**「價格可以不義」的命題至今未結案**（！）。

**偵探結語**：阿奎那的案件是「**一個不碰錢的人替碰錢的人立法**」——他的偉大在於誠實的兩難：他見到市集上真實的成交與真實的欺詐（！），於是拒絕給出魔法數字，改給出一個**情境化的正義區間**。這其實比後來的純市場論更接近現實：價格確實同時承載成本、效用與權力（！）。高利貸判決則是典型的「立法超前於金融工程」——禁令沒有消滅借貸（！），只是把利息趕進合夥、匯票與賠償金的衣櫃（！）——**經濟規律打不過，就換一件法律外衣**。偵探的結論：中世紀不是經濟學史的黑夜（！），是第一個認真審問「價格的良心」的法庭——而這個審問，2008 年之後又被提上日程（！見 [2008-金融危機與總體經濟學反思.md](2008-金融危機與總體經濟學反思.md)）。
