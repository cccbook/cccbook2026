# 2019-隨機對照試驗與發展經濟學：把貧窮問題送進實驗室

## 案件摘要

2019 年 10 月，諾貝爾經濟學獎頒給阿比吉特·班納吉（Abhijit Banerjee！麻省理工！加爾各答出身！）與埃絲特·迪弗洛（Esther Duflo！麻省理工！史上最年輕的經濟學諾獎得主、46 歲！）與麥可·克雷默（Michael Kremer！哈佛！）——**表彰「以實驗方法緩解全球貧窮」**（！）——**核心方法：隨機對照試驗（RCT！）搬進發展經濟學**（！）——**把「援助有沒有用」的大哉問，拆成幾百個可實驗的小問題**（！蚊帳免費還是收費？教師激勵？小額信貸？）——**2003 J-PAL 實驗室創立**（！）——**2011《貧窮的本質》成為現象級教材**（！）——**這樁案件是「發展經濟學的實驗科學化」**（！）——**同時點燃史上最烈的方法論論戰**（！）。

## 前因 -- 多因素的局勢

- **發展經濟學的巨論疲勞**：薩克斯「終結貧窮」的千禧村計畫（！）vs 伊斯特利「白人的負擔」的批判（！）——**大爭論沒有證據可判**（！）。
- **援助有效性的黑箱**：數十億美元流入，效果無法歸因（！）——**因果推斷的荒地**（！）。
- **勞動經濟學的方法革命**：自然實驗（！）＋安斯基的工具變數復興（！）＋人力資本評估（！）——**可信度革命（credibility revolution！）**（！）。
- **醫學 RCT 的模板**：隨機分組是因果的金標準（！）——**為何發展政策不學**（！）。
- **1990s 肯亞的蠕蟲實驗**：克雷默的學校分組隨機化（！）——**發展 RCT 的原型案**（！）。

## 線索與推理 -- 因素咬合

### 線索一：分解策略——「把貧窮拆成一千個可答的問題」

RCT 方法論（！）：

$$Y_i = \alpha + \beta T_i + \varepsilon_i, \quad T_i \text{（隨機分派！）} \Rightarrow E[\varepsilon|T]=0$$

（→**隨機分組讓處理組與對照組可比**（！）——**因果的乾淨識別**（！）——**犧牲：只能回答「此地此案」**（！）——**策略：用數量換深度**（！））。

### 線索二：蠕蟲案例——「一個實驗改寫一個產業」

克雷默 2004 肯亞驅蟲實驗（！）：

| 發現 | 結論 |
|------|------|
| 驅蟲藥降低缺課率（！） | 健康干預＝教育干預（！） |
| 外部性（傳染下降！） | 免費發放優於收費（！） |

（→**2007–08 世界衛生組織與億萬兒童覆蓋（Deworm the World！）**（！）——**實證→政策的直通管**（！）——**同時 Givewell 等有效利他組織以 RCT 為評級基準**（！））。

### 線索三：心理學的貧窮理論——「稀缺佔用頻寬」

班納吉—迪弗洛的綜合（！）：

- 農民只在施肥上「低估成本」的行為模式（！）。
- 教師缺勤的相機監督實驗（！印度！相機打卡讓缺勤率腰斬！）。
- 小額信貸的 RCT：**有幫助但非革命**（！）——**神話的降級**（！）。
- 疫苗接種：給一小袋扁豆，完成率從 6% 升到 38%（！）——**小誘因大效果**（！）。

（→**貧窮不僅是缺錢，是決策環境的全面劣化**（！）——**與 [2002-卡尼曼行為經濟學.md](2002-卡尼曼行為經濟學.md) 的行為洞見合流**（！））。

## 破案時刻

- 1994–97：克雷默肯亞蠕蟲研究啟動（！）。
- 2003：J-PAL 創立（MIT！）。
- 2004–07：驅蟲、免疫、教育系列 RCT（！）。
- 2010：迪頓陣營的公開批評（！）。
- 2011：《貧窮的本質》（！）。
- 2015：迪弗洛任世界銀行首席經濟學家呼聲與影響力（！）。
- 2019.10.14：三人共獲諾獎（！）。

## 後果 -- 改變了什麼

- **發展實務的證據化**：政府與 NGO 設立評估單位（！）——**「先試點、先隨機、再推廣」**（！）。
- **有效利他運動的基石**：捐款評級（！）——**慈善的經濟學化**（！）。
- **方法論論戰的制度化**：外部效度、測量偏誤、實驗者效應的檢查清單（！）——**RCT 的自我修正**（！）。
- **學科人才的遷徙**：頂校博士進入田野（！）——**發展經濟學成為最有活力分支之一**（！）。


**偵探結語**：RCT 運動的案件是「**兩個年輕人把貧窮這頭巨獸，拆成一千隻可以逐隻擊破的小獸**」——他們的方法論誓言（！）與配第一脈相承（！見 [1664-配第政治算術.md](1664-配第政治算術.md)）：**「只訴諸數字與感官，拒絕宏大敘事」**——三百年後的武器升級為隨機分組（！）——**「這裡有用」比「應該有用」值錢**（！）。但要完整結案，必須並排記錄反方卷宗（！見 [2015-迪頓與貧窮經濟學.md](2015-迪頓與貧窮經濟學.md)）：其一，**RCT 擅長回答「這個政策有效嗎」，不擅長「該選哪個制度」**（！宏觀結構問題——產權、國家能力、貿易——不在實驗室射程，見 [1990-諾斯制度變遷理論.md](1990-諾斯制度變遷理論.md)！）；其二，**最有力的問題常無法隨機**（！你不可能隨機分配一場內戰！）；其三，**政策推廣的土壤差異**（！同一劑蚊帳，在肯亞與海地的效果可以完全不同！）。偵探的終審意見（！）：**RCT 是偉大的顯微鏡，不是望遠鏡**——顯微鏡找病菌，望遠鏡定航向——**發展經濟學需要兩架，而 J-PAL 教會了世界怎麼用第一架**（！）。
