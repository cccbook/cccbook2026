# 1798-馬爾薩斯人口論：幾何與算術的凶案

## 案件摘要

1798 年，托馬斯·馬爾薩斯（Thomas Malthus！英格蘭教會牧師！劍橋耶穌學院研究員！史上第一位政治經濟學教授——1805 年起在東印度公司學院任職！）匿名出版《人口論》第一版（Essay on the Principle of Population！4 萬字小冊！）——**核心定律：人口在無阻礙時按幾何級數（1, 2, 4, 8…）增長，生活資料按算術級數（1, 2, 3, 4…）增長**（！）——因此必然有「積極抑制」（！饑荒、瘟疫、戰爭！）與「預防抑制」（！道德抑制＝晚婚！）——**這樁案件是「烏托邦的第一份驗屍報告」**（！）——直接起訴對象：戈德溫與孔多塞（！人類可臻完善的樂觀論！）——**史上第一個被「數學化」的社會科學模型**（→達爾文讀到它才悟出自然選擇！）。

## 前因 -- 多因素的局勢

- **法國革命的論戰**：戈德溫《政治正義論》（1793！預言廢除財產與政府後人類完善！）＋孔多塞《人類精神進步史表綱要》（！）——**無限進步的樂觀主義**（！）。
- **英國貧困問題**：濟貧法（！）＋圈地後的農村失序（！）——**貧窮是懶惰還是結構？**（！）。
- **人口恐慌**：英格蘭人口回升（！）＋歐洲戰亂饑荒記憶（！）——**人口數字首次成為公共焦點**（！）。
- **牧師的職業視角**：教區濟貧的日常經驗（！）——**他在底層看到生育與飢餓的賽跑**（！）。

## 線索與推理 -- 因素咬合

### 線索一：兩條級數——「悲劇的算術」

$$\text{人口：} 1, 2, 4, 8, 16 \quad\quad \text{糧食：} 1, 2, 3, 4, 5$$

（→「土地的報酬遞減」是隱含前提（！）——好地有限、次地遞補（！）——**李嘉圖把這一步正式化為地租理論**（！見 [1817-李嘉圖比較利益.md](1817-李嘉圖比較利益.md)）——**馬爾薩斯邏輯為李嘉圖的農業經濟學提供了引擎**（！））。

### 線索二：抑制的分類——「天譴與自救」

| 抑制 | 機制 | 馬氏立場 |
|------|------|----------|
| 積極抑制 | 饑荒、瘟疫、戰爭 | 被動的屠刀（！） |
| 預防抑制（非道德） | 婚齡延後外的墮胎、節育 | 貶為「惡習」（！） |
| 道德抑制 | 晚婚＋克制 | **唯一救法**（！） |

（→第二版（1803！）起「道德抑制」比重增加（！）——**牧師身分與理論的一致性辯論**（！）——**人口轉型的事實後來證明：人均所得上升反而生育率下降**（！）——**他的機制搞對了壓力，搞錯了方向**（！））。

### 線索三：對濟貧法的控訴

馬氏主張逐步廢除濟貧法（！）——理由（！）：扶養窮人→刺激生育→擴大貧困（！）——**現代「福利養懶人」論的祖源**（！）——**但這個推理忽略了貧困的結構成因**（！）——**其政策影響：1834 新濟貧法的嚴酷**（！）。

## 破案時刻

- 1766：生於薩里（！休謨與盧梭是他父親的摯友！）。
- 1784：入劍橋耶穌學院（！）。
- 1798：第一版匿名出版（！）。
- 1803：第二版大幅擴寫（！4 倍長！署名！）。
- 1805：東印度公司學院教授（！）。
- 1815：地租論；1820：《政治經濟學原理》（！）。
- 1834：去世（！）——同年新濟貧法通過（！）。

## 後果 -- 改變了什麼

- **古典經濟學的悲觀底色**：「工資鐵律」（！）——工資趨向維生水準（！）——**「沉悶的科學」綽號由此而來**（！）。
- **達爾文的引爆**：1838 達爾文讀馬氏（！）「為生存而掙扎」→自然選擇（！）——**經濟學的思想餵了生物學**（！）。
- **凱因斯的致敬**：凱因斯稱他為劍橋經濟學之源（！）——馬氏的有效需求不足論（！1820《原理》！）被凱因斯復活（！見 [1936-凱因斯一般理論.md](1936-凱因斯一般理論.md)）——**他同時是悲觀定律與需求理論的作者**（！）。
- **現代的翻案**：綠色革命與避孕技術（！）擊潰兩條級數的必然性（！）——**但氣候與生態經濟學又請他回來**（！行星邊界＝新的人口約束！）。

## 因素影響筆記

```

「道德抑制」 ──→ 1834 新濟貧法（！）──→ 福利辯論的長期模板
人口壓力邏輯 ──→ 達爾文（1838！）──→ 自然選擇（跨界外溢！）
```

**偵探結語**：馬爾薩斯的案件是「**一個牧師用算術擊碎天堂**」——他最狠的一擊（！）是承認樂觀主義的前提卻推出絕望的結論：**就算人人理性勤勉，人口的鐘擺仍會碾壓生活資料**。他錯了兩件大事（！）：技術會移動糧食曲線（！綠色革命！），而且生育率會隨繁榮下降（！人口轉型！）——**他假設人性不變，但繁榮本身就是最強的避孕藥**。可是他又對了一件事（！）：**資源的約束不會消失，只會轉移戰場**——從糧食換成碳預算、換成漁場與地下水（！）。偵探的判決：馬爾薩斯不是先知（！），是第一個用方程式寫悲劇的人——而悲劇的寫法，兩百年後仍在生態經濟學與氣候模型裡逐字重演（！）。
