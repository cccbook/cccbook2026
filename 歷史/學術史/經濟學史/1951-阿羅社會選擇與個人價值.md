# 1951-阿羅社會選擇與個人價值：民主的數學陷阱

## 案件摘要

1951 年，肯尼斯·阿羅（Kenneth Arrow！紐約市立學院學士！23 歲的哥倫比亞博士生！）出版《社會選擇與個人價值》（Social Choice and Individual Values！）——**核心炸彈：不可能定理**（！）——**在 3 個以上選項、3 個以上選民時，不存在同時滿足四個合理性條件的社會決策規則**（！）——**條件：無限制域、帕累托原則、無關選項獨立性、非獨裁**（！）——**「完美的投票制度」在邏輯上不存在**（！）——**這樁案件是「福利經濟學的地震儀：集體理性從公理上被炸塌」**（！）——**阿羅後來又與德布魯完成一般均衡的存在性證明（1954！）**（！）——**一人同時炸毀與重建經濟學的兩座神殿**（！）。

## 前因 -- 多因素的局勢

- **福利經濟學的困境**：柏格森—薩繆森社會福利函數（！）——**社會排序從哪來？**（！）——**需要基礎檢查**（！）。
- **孔多塞投票悖論的出土**：1785 年的老謎題（！）——兩兩多數決可以循環（！A>B、B>C、C>A！）——**兩百年無人當回事**（！）。
- **蘭格—勒納的市場社會主義**：福利經濟學被用作計劃的理論武器（！）——**阿羅的博士論文就出自蘭格門下的氛圍**（！）。
- **1948 年選舉之夜**：阿羅在蘭德公司看民調翻盤（！）——**投票方法的謎團第一次擊中他**（！）。
- **數理邏輯的工具箱**：關係、公理、映射（！）——**證明的技術已備**（！）。

## 線索與推理 -- 因素咬合

### 線索一：孔多塞循環——「多數決的迴旋鏢」

三位選民、三個選項（！）：

| 選民 | 排序 |
|------|------|
| 甲 | A > B > C |
| 乙 | B > C > A |
| 丙 | C > A > B |

$$\text{多數決：} A > B > C > A \Rightarrow \text{（循環！沒有社會偏好！）}$$

（→**多數意見可以自我矛盾**（！）——**議事日程操縱者可以製造任何結果**（！）——**委員會政治的暗數學**（！））。

### 線索二：四條件的不可能——「民主的工程學極限」

阿羅定理的結構（！）：

| 條件 | 內容 |
|------|------|
| 無限制域 | 一切偏好組合都允許 |
| 帕累托 | 人人同意則社會同意 |
| IIA | 只與兩個選項間的個人排序有關 |
| 非獨裁 | 無人一票定江山 |

（→**四者不可兼得**（！）——**放棄哪一條？每個現實制度都在偷放一條**（！）——**多數決犧牲 IIA 的精神（！操縱議程！），市場犧牲無限制域（！初始分配決定一切！）**（！））。

### 線索三：一般均衡的重建——「炸完之後蓋回來」

1954 阿羅—德布魯論文（！）：用不動點定理證明競爭均衡存在（！）——**第一福利定理**：均衡即帕累托有效（！）——**市場的數學神殿重新落成**（！）——**但第二福利定理需要轉移支付**（！）——**效率與分配的分離是政策藝術**（！）——**兩座神殿的張力構成戰後福利經濟學的全部日程**（！）。

## 後果 -- 改變了什麼

- **社會選擇理論的誕生**：森（Sen！）的自由悖論（！）＋吉巴德—薩特斯維特定理（！策略操縱不可免！）——**政治經濟學的數學化**（！）。
- **投票制度工程**：排序複選制、Borda 計分的復活（！）——**選舉改革的學理依據**（！）。
- **資訊經濟學與醫療經濟學**：1963 論文是阿克洛夫檸檬市場（1970！）的先聲（！）——**保險、健康、遴選**（！）。
- **福利經濟學的謙卑**：社會福利函數的價值前提被攤在桌上（！）——**規範經濟學的誠實化**（！）。
