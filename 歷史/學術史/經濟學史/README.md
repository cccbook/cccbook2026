# 經濟學史 -- AI 偵探風格

以「推理探案」的方式，追查經濟學的重大轉折：亞里士多德的貨殖、阿奎那的正義價格、配第的政治算術、斯密的國富論、馬爾薩斯的人口、李嘉圖的比較利益、穆勒的綜合、馬克思的資本、邊際革命三傑、馬歇爾的原理、費雪的資本、凱因斯的一般理論、寇斯的企業、馮諾依曼的賽局、海耶克的知識、阿羅的不可能、菲利普曲線、寇斯的社會成本、傅利曼的自由、貝克爾的人類行為、諾斯的制度、卡尼曼的偏誤、金融危機、席勒的敘事、迪頓的貧窮、隨機對照試驗、注意力經濟——
前因是什麼？線索在哪裡？推理如何展開？後果又如何改寫了「財富」的定義？

本卷的核心命題只有一句話：**經濟學史是「財富如何被解釋」的偵辦史。**
每一樁案件都是一次「換掉被告」的革命：貨殖（錢生錢有罪！）、正義價格（市場有道德底線！）、政治算術（財富可以測量！）、看不見的手（利己可以公益！）、剩餘價值（利潤是剝削！）、邊際效用（價值在人心！）、一般理論（市場會失靈！）、賽局（他人會算計！）、制度與行為（人不理性、規則不中性！）。
解釋的框架變了，「財富」的定義就重寫了。每個重大轉折都是一樁「多因懸案」：偵探的工作，就是把因素鏈一環一環還原出來。

（涵蓋：亞里士多德、阿奎那、配第、斯密、馬爾薩斯、李嘉圖、穆勒、馬克思、傑文斯—門格爾—瓦拉斯、馬歇爾、費雪、凱因斯、寇斯、馮諾依曼與摩根斯坦、海耶克、阿羅、菲利普斯、傅利曼、貝克爾、諾斯、卡尼曼、席勒、迪頓、班納吉與迪弗洛、平台經濟）

## 偵辦的回饋迴路

```
              ┌────（時代病：戰爭—蕭條—通膨—貧窮—危機）────┐
              ↓                                      ↓
   現象 ──→ 測量 ──→ 理論 ──→ 政策 ──→ 新現象 ──→ 反思
    │                ↑        ↑                   │
    │                │        │                   ↓
    └──→ 意識形態之戰 ←── 諾獎 ←── 模型化 ←── 數學化
              ↑                        ↑
              └── 冷戰—危機 ←──（資助與政治）┘

   正向迴路（加速）：危機→理論→教科書→政策→更多數據
   正向迴路（加速）：數學化→諾貝爾獎→學科地位
   負向迴路（抑制）：模型太美→忽略現實（→2008 爆炸！）
   經濟學迴路（本卷特有）：道德→測量→市場→失靈→制度→行為→道德

**偵探的訣竅**：找到「誰測量、誰建模、誰開藥方、誰翻案」，把鏈條畫出來；再問一句——**這個理論把「財富」照成了什麼（黃金？勞動？效用？預期？制度？注意力？）**——案件的因果鏈就浮現了。

## 案件卷宗（歷史年表）

### 一、道德法庭：財富的原審（-0350–1664）

- -0350：亞里士多德論貨幣與貨殖——錢生錢違反自然；用途與交換的區分；兩千年「利息禁令」的思想原廠。［[-0350-亞里士多德論貨幣與貨殖.md](-0350-亞里士多德論貨幣與貨殖.md)］
- 1282：阿奎那與正義價格——價格有道德底線；高利貸之辯；經院經濟學的黃金時代。［[1282-阿奎那與正義價格.md](1282-阿奎那與正義價格.md)］
- 1664：配第《政治算術》——用數字治國；勞動是財富之父；統計經濟學的出生證。［[1664-配第政治算術.md](1664-配第政治算術.md)］
- 1758：魁奈《經濟表》——重農主義；淨產品的血液循環；第一張宏觀迴路圖。［[1758-魁奈經濟表.md](1758-魁奈經濟表.md)］

### 二、古典學派：市場的辯護與翻供（1776–1867）

- 1776：亞當·斯密《國富論》——分工與看不見的手；利己通向公益；政治經濟學的獨立宣言。［[1776-亞當斯密國富論.md](1776-亞當斯密國富論.md)］
- 1798：馬爾薩斯《人口論》——幾何對算術；人口壓力的悲觀定律；第一個經濟模型。［[1798-馬爾薩斯人口論.md](1798-馬爾薩斯人口論.md)］
- 1817：李嘉圖《政治經濟學及賦稅原理》——比較利益；地租與分配；模型化經濟學的開端。［[1817-李嘉圖比較利益.md](1817-李嘉圖比較利益.md)］
- 1848：穆勒《政治經濟學原理》——古典學派的綜合；生產法則 vs 分配法則；靜態與改革的調和。［[1848-穆勒政治經濟學原理.md](1848-穆勒政治經濟學原理.md)］
- 1867：馬克思《資本論》——剩餘價值；用敵人的公式起訴敵人；資本主義的解剖學。［[1867-馬克思資本論.md](1867-馬克思資本論.md)］

### 三、邊際革命：價值搬進人心（1871–1906）

- 1871：邊際革命三傑——傑文斯、門格爾、瓦拉斯同時换掉勞動價值論；效用邊際遞減；新古典的地基。［[1871-邊際革命三傑.md](1871-邊際革命三傑.md)］
- 1890：馬歇爾《經濟學原理》——供需剪刀；局部均衡；「經濟學」取代「政治經濟學」。［[1890-馬歇爾經濟學原理.md](1890-馬歇爾經濟學原理.md)］
- 1906：費雪《資本與收入的性質》——資本是存量、收入是流量；利率即耐心的價格；貨幣數量論的底座。［[1906-費雪資本與收入的性質.md](1906-費雪資本與收入的性質.md)］

### 四、大危機的翻案：凱因斯與社會科學化（1936–1951）

- 1936：凱因斯《一般理論》——有效需求不足；節儉的悖論；總體經濟學誕生。［[1936-凱因斯一般理論.md](1936-凱因斯一般理論.md)］
- 1937：寇斯《企業的性質》——交易成本；企業為何存在；新制度經濟學的第一塊磚。［[1937-寇斯企業的性質.md](1937-寇斯企業的性質.md)］
- 1944：馮諾依曼與摩根斯坦《賽局理論與經濟行為》——期望效用；極大化極小；把「他人」裝進模型。［[1944-馮諾依曼與摩根斯坦賽局理論.md](1944-馮諾依曼與摩根斯坦賽局理論.md)］
- 1945：海耶克《知識的使用》——知識分散在價格裡；社會主義計算辯論的判詞；自發秩序。［[1945-海耶克知識的使用.md](1945-海耶克知識的使用.md)］
- 1951：阿羅《社會選擇與個人價值》——不可能定理；投票的邏輯陷阱；福利經濟學的地動儀。［[1951-阿羅社會選擇與個人價值.md](1951-阿羅社會選擇與個人價值.md)］

### 五、黃金時代的機器與反叛（1958–1976）

- 1958：菲利普斯曲線——通膨與失業的取捨；政策選單的誕生；其後被理性預期摧毀。［[1958-菲利普曲線.md](1958-菲利普曲線.md)］
- 1960：寇斯《社會成本問題》——社會成本與外部性；寇斯定理；產權取代政府管制。［[1960-寇斯社會成本問題.md](1960-寇斯社會成本問題.md)］
- 1962：傅利曼《資本主義與自由》——貨幣主義；負所得稅；把「自由」裝回經濟學的政策宣言。［[1962-傅利曼資本主義與自由.md](1962-傅利曼資本主義與自由.md)］
- 1971：施蒂格勒〈資訊經濟學〉——搜尋有成本；資訊不是免費的；資訊經濟學開山。［[1971-施蒂格勒訊息經濟學.md](1971-施蒂格勒訊息經濟學.md)］

### 六、制度、行為與危機（1990–2021）

## 偵探的結案陳詞

兩千三百多年的經濟學史，可以壓縮成三條因果鏈：

1. **價值鏈**：道德（貨殖有罪！）→ 生產（勞動創造財富！）→ 主觀（價值在人心！）→ 預期（未來決定現在！）→ 制度（規則決定結果！）→ 注意力（稀缺轉移了！）——**每一次換掉價值的定義，就換一次經濟學**。
2. **人物鏈**：哲學家（亞里士多德！）→ 神學家（阿奎那！）→ 測量員（配第！）→ 立法者（斯密李嘉圖！）→ 解剖者（馬克思！）→ 工程師（馬歇爾費雪！）→ 醫生（凱因斯！）→ 律師（寇斯！）→ 心理學家（卡尼曼！）——**先問該不該，再問是多少，最後問人到底怎麼想**。
3. **危機鏈**：蕭條（1873！1929！）→ 戰爭（1914！1939！）→ 通膨（1970s！）→ 金融海嘯（2008！）→ 疫情與平台（2020s！）——**教科書的每一版修訂，都是危機的傷口結痂**。

三條鏈咬合在一起，就是本卷二十七樁案件的全部真相：**經濟學不是關於錢的學問，是關於「人如何一起活得好」的偵辦記錄——而嫌犯至今仍在換人。**
