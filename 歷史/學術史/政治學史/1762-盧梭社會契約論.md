# 1762-盧梭《社會契約論》：公意與合法性的換軌

## 案件摘要

1762 年，日內瓦公民**盧梭**（Rousseau！鐘錶匠之子！棄嬰五個！被日內瓦通緝！書被焚燒！）出版《社會契約論》（Du contrat social！開篇即政治學最著名的起訴書：「**人生而自由，卻無往不在枷鎖之中**」！）。核心證詞：合法的政治秩序只有一個來源——**公意**（volonté générale！指向共同善的全體意志！≠眾意的加總！）；社會契約的公式：「**每人把自己與全部權力交給共同體**，受公意指導」（→每個人交出給全體、同時從全體拿回同樣的份額＝等價交換！）；主權屬於**人民**、不可讓渡、不可分割、不可代表（！對代議制的判決：「英國人自以為自由，大錯特錯——只在選議員時自由」！）。這樁案件是**人民主權論的成典之作**。

## 前因 -- 多因素的局勢

- **啟蒙的分裂**：伏爾泰的精英啟蒙 vs 盧梭的平民啟蒙（！1750 論文獲獎：科學與藝術敗壞風俗！一夜成名！）。
- **日內瓦的政治**：小共和國內市民與貴族的鬥爭（！《社會契約論》被日內瓦與巴黎同時查禁——兩邊都看懂了！）。
- **文明批判**：《論科學與藝術》（1750！）、《論不平等》（1755！「第一個圈地者」＝私有制之惡！）——**理論前置**。
- **《新愛洛漪絲》與《愛彌兒》同年出版**：1762 三書齊發（！情感政治＋教育政治＋契約政治的套裝！）。
- **熱那亞科西嘉事務**：為科西嘉起草憲法建議（→小國直接民主的實驗興趣！）。

## 線索與推理 -- 因素咬合

### 線索一：不平等 × 合法性危機

私有制造成依賴與欺騙（！富人發明國家保護贓物——1755 的指控！），但退回自然狀態不可行（！霍布斯式無政府更糟！）：

$$\text{問題} = \text{（找到一種結合形式！）} : \text{每人服從權威卻仍只服從自己}$$

（→「服從自己」＝自由的保全方案！）

### 線索二：公意 vs 眾意——意志的過濾器

| 概念 | 定義 | 後果 |
|------|------|------|
| 眾意（volonté de tous） | 個別利益加總 | 利益集團政治（！派系！） |
| 公意（générale） | 剝除特殊利益的共同善 | 立法的對象（！永遠正確？！） |
| 意志 vs 意見 | 公意總是正的，判斷會錯 | 需要啟蒙的立法者（！外來賢人立憲！） |

（→危險在此：「公意正確」＋「少數被迫自由」（il faudra le forcer d'être libre！）——被讀成極權許可證（→雅各賓恐怖的理論資源！））

### 線索三：小國、參與、公民宗教

公意運轉需要**小規模**（！日內瓦級！）、直接參與、節儉平等、**公民宗教**（！第四卷：不寬容的宗教不可入法——但他自己也主張處死不守公民信仰者——矛盾成謎！）：

$$\text{自由} = \text{（參與！）} \times \text{（小國！）} + \text{（公民美德！）}$$

## 破案時刻

- 1750：第戎學院論文獲獎——批判路線啟動。
- 1755：《論不平等》——「圈地者」段落（私有制起訴書！）。
- 1761–1762：《新愛洛漪絲》《社會契約論》《愛彌兒》接連出版。
- 1762-6：《愛彌兒》被巴黎議會焚毀、逮捕令發出（！盧梭夜逃！）。
- 1766：流亡英國、與休謨決裂（！被迫害妄想症發作！）。
- 1789–1794：法國大革命——盧梭遺骸 1794 入先賢祠（！羅伯斯比爾自稱其門徒！）。

## 後果 -- 改變了什麼

- **人民主權**：主權從君主（博丹［[1576-博丹主權論.md]］）轉移到人民的理論完成式（→1793 法國憲法直接引述公意！）。
- **代議制的批判傳統**：參與民主、公民大會（！愛爾蘭審議式抽籤！）、激進民主的血統。
- **危險遺產**：「公意」＋「被迫自由」被極權主義研究者列為病灶（！塔爾蒙「極權民主」的譜系起點！）。
- **社會科學**：合意（consensus）與強制（coercion）的張力成為政治學永恆主題（→達爾［[1961-達爾多元政體.md]］的多元主義正是對「統一公意」的降維！）

## 因素影響筆記

```
私有制批判（1755！圈地者！）──→ 合法性危機（枷鎖何來？）
日內瓦小共和國經驗 ──→ 小國＋直接參與的想像（！）
公意≠眾意（過濾器！）──→ 人民主權（！）──→ 法國大革命（雅各賓引經！）
「被迫自由」（！）──→ 極權民主的病灶（！）──→ 20世紀的百年論戰
```

**偵探結語**：盧梭的案子是政治學史上**最光的火把與最深的陰影**在同一處燃燒：他證明了合法性只能來自被治理者，卻又允許「整體意志」高於個人判斷。他的偵探技巧在於翻轉問句——別人問「如何服從」，他問「**如何服從而仍是自由**」。這個問句規定了之後兩百五十年的左翼政治想像：參與、平等、社群。而「被迫自由」這四個字提醒每個讀者：當抽象的「人民」被允許壓倒具體的人，人民的統治就會吃掉它本要保護的自由。
