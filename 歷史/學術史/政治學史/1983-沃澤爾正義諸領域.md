# 1983-沃澤爾《正義諸領域》：複雜平等與多元正義

## 案件摘要

1983 年，普林斯頓政治學家**麥克·沃澤爾**（Michael Walzer！曾是羅爾斯［[1971-羅爾斯正義論.md]］的同事！）出版《正義諸領域》（Spheres of Justice）。核心證詞：不存在單一的正義原則——**不同的社會物品（social goods）服從不同的分配邏輯**：愛按親密分配、醫療按需要、官職按資格、金錢按市場（!而後者必須被圍欄！）。正義的核心不是「人人分得一樣」，而是**複雜平等**（complex equality）：**沒有一種物品能越境兌換**——金錢買不到官職、榮譽、愛與司法判決（!一旦金錢可以兌換其他物品，就出現**支配性物品**（dominant good！），寡頭誕生！）。這樁案件是**社群主義對分配正義的正案起訴**（→「正義的意義取決於共享的意義」——多元社會正義的地圖！）

## 前因 -- 多因素的局勢

- **羅爾斯—諾齊克壟斷辯論**：1971–74 後分配正義被「單一原則」框架壟斷（!差異原則 vs 自我所有權——兩端都不對!）——**靶子**。
- **1960s–70s 的社會變革**：平權法案（affirmative action！）、配額、教育分配——**現實爭議**（!「誰該進大學？」的哲學問題！）
- **市場社會的擴張**：1970s 起商業邏輯滲透（!代孕、賣血、買官——後世桑德爾《錢買不到的東西》接棒！）——**越境兌換的警覺**。
- **猶太政治思想傳統**：出埃及記、先知傳統＋社群經驗——**思想底盤**（!沃澤爾：正義先在猶太傳統中呈多元形態！）。
- **羅爾斯的「無拘自我」批評**：桑德爾 1982《自由主義與正義的局限》——**社群主義集結號**。

## 線索與推理 -- 因素咬合

### 線索一：物品的意義決定分配

$$\text{正義} = \text{（各領域內！按照物品的社會意義分配！）} \neq \text{（單一原則！)}$$

| 物品 | 分配原則 | 領域 |
|------|----------|------|
| 愛與恩惠 | 親密關係 | 家庭 |
| 醫療 | 需要 | 健康 |
| 官職與工作 | 資格＋成就 | 職場 |
| 金錢 | 自由交易（!但被圍欄！） | 市場 |
| 榮譽 | 功績 | 公共生活 |
| 成員資格 | 社群自決（!他承認社群有權篩選移民！） | 政治共同體 |

（→每個領域有自己的「邊界守衛」——**界限的守衛就是正義本身**！）

### 線索二：支配性物品與寡頭的誕生

歷史上的支配物：封建時代是**土地與血統**、現代是**金錢**——一旦金錢可兌換一切（!官職、教育、司法、影響力！），「形式平等」淪為寡頭統治：

$$\text{寡頭} = \text{（金錢的越境兌換！）} \Rightarrow \text{正義的解藥} = \text{（圍欄！各領域自治！）}$$

（→「複雜平等」：即使每人財富不同，只要金錢買不到其他領域的地位，**沒有人能統治一切領域**——達爾多元主義的正義版升級！［[1961-達爾多元政體.md]］）

### 線索三：反對「一元論」的哲學

「哲學家的錯誤在於以為正義有**一個**答案」——他主張「**詮釋而非發明**」（!正義的原則從共享意義中**讀出**，不是從無知之幕後**推出**！→與羅爾斯的認識論分野！）。

## 破案時刻

- 1970：〈不服從義務〉——公民抗命理論出道。
- 1977：《正義與不義之戰》——戰爭倫理（!先於正義諸領域的權利觀！）
- 1982：桑德爾《自由主義與正義的局限》——社群主義集結。
- 1983：《正義諸領域》出版。
- 1990s：桑德爾《民主的不滿》、麥金泰爾的傳統論——社群主義浪潮。
- 2012：《錢買不到的東西》——越境兌換論的暢銷版。

## 後果 -- 改變了什麼

- **正義理論的多元化**：從「單一原則」競賽轉向「多領域」地圖（!阿瑪蒂亞·森《正義的理念》承認多元、承認不完美制度也可評價！）
- **市場邊界辯論**：代孕、器官、買賣入學——20 世紀末到 21 世紀的倫理戰場（!桑德爾正直接延續沃澤爾！）
- **移民與成員資格**：社群有權自決的論證（!入籍條件、庇護政策的哲學基礎之一——也成為民族主義者的引文！）
- **批判**：領域邊界由「共享意義」決定——但共享意義本身就可能是**不義的**（!種族隔離時代的「共享意義」！羅爾斯陣營的經典反擊！）

## 因素影響筆記

```
羅爾斯—諾齊克單一原則壟斷（！）──→ 沃澤爾的多元起訴（！）
平權法案＋市場擴張（！）──→ 「金錢能買什麼」的現實爭議（！）
支配性物品（金錢！）──→ 越境兌換（！）──→ 寡頭（！）
複雜平等（！）──→ 市場邊界辯論＋多元正義（！）
```

**偵探結語**：沃澤爾的偵探手法是**跟蹤每一件物品的去向**：愛到了哪裡、錢到了哪裡、官職到了誰的手上——他發現正義的兇案現場不在抽象原則裡，而在**領域之間的邊界**。他的洞見至今鋒利：當一種東西（錢）可以兌換其他一切，平等就會被收購。複雜平等不求人人一樣，只求**沒有人能買下整個社會**。這是社群主義對自由主義最有力的正面出擊，也是 21 世紀「平台資本主義」時代最該重讀的一樁舊案。
