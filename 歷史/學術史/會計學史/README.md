# 會計學史 -- AI 偵探風格

以「推理探案」的方式，追查人類如何一步步把「看不見的財產與責任」從口頭承諾、繩結泥板、私人帳本，變成可以查帳、可以審計、可以課責的數字體系——
前因是什麼？線索在哪裡？推理如何展開？後果又如何改變了「誰能信任誰的錢」這個問題？

本卷的核心命題只有一句話：**會計的歷史，就是「信任如何被數字化」的歷史。**
每個重大事件都是一樁「多因懸案」：商業形式（貿易、合夥、股份、跨國公司）、技術（算術、印刷、試算表、資料庫）、政治（稅務、審查、證券管制、舞弊醜聞）、信任機制（審計、準則、罰則）——這些因素互相咬合。偵探的工作，就是把「數字為何在此時此地被賦予如此權威」的因素鏈一環一環還原出來，同時追查每個數字如何被製造、又如何被濫用。

（涵蓋：兩河流域泥板帳目、秦簡倉律、伊斯蘭稅務會計、佛羅倫斯與熱那亞複式簿記、帕喬利、荷蘭東印度公司、南海泡沫、工廠成本會計、愛丁堡會計師公會、紐約 CPA 法、科學管理與標準成本、證券法與 SEC、麥克森-羅賓斯案、FASB 與 IASC、電子試算表、恩隆與安達信、沙賓法案、公允價值論戰、IFRS 趨同、區塊鏈與三式簿記、生成式 AI）

## 本卷的破案框架：六條主軸

| 主軸 | 問題 | 關鍵轉折 |
|------|------|----------|
| **記帳技術** | 如何讓數字互相牽制 | 泥板清點 → 單式流水帳 → 複式簿記（借貸平衡）→ 試算表 → 資料庫與 AI |
| **商業形式** | 什麼樣的生意需要什麼樣的帳 | 神廟倉庫 → 合夥貿易 → 股份公司 → 跨國集團 → 平台經濟 |
| **審計制度** | 誰來查帳、查帳者聽誰的 | 官府倉律稽核 → 股東委託 → 特許會計師 → 法定審計 → 內控稽核 |
| **成本與管理** | 帳簿如何讓工廠賺錢 | 工場粗估 → 標準成本 → 管理會計 → 作業基礎成本 |
| **準則與舞弊** | 數字被濫用後如何補網 | 泡沫法案 → 證券法 → 審計程序改革 → GAAP/IFRS → SOX |
| **數位化** | 機器接管了什麼 | 打孔卡片 → 試算表 → ERP → 持續審計 → 生成式 AI |

## 案件卷宗（歷史年表）

### 一、前複式時代：清點、稽核與信任的最早技術（前3500–1200）

- 約前3300：兩河流域的陶籌與封球——第一批「數字憑證」。
- 約前3000：烏魯克神廟泥板——倉庫收支被壓進楔形文字，會計與文字同時誕生。
- 約前2100：烏爾第三王朝的年度清點與「多餘/短缺」追責——官廳審計的原型。
- 約前700：亞述與巴比倫的商站帳簿、收據與封印——商業會計的童年。［[-0700-泥板與兩河流域的帳目.md](-0700-泥板與兩河流域的帳目.md)］
- 約前600：雅典公共財政的審計官（logistai）——卸任官員必須查帳，查不過要上法庭。

### 二、帝國的稽核：東方的倉律與西方的莊園（前300–1400）

- 約前350：秦簡〈倉律〉、〈效律〉——官倉物資的定量核銷與「計校」追責，中國官廳審計成文法化。［[-0300-秦簡倉律與官府審計.md](-0300-秦簡倉律與官府審計.md)］
- 漢唐：上計制度與比部郎中——中央對地方收支的年度勾稽。
- 約800：阿拔斯王朝的稅務總帳與 ziyadat（增補分錄）——伊斯蘭財政行政的記帳體系，日後被爭論為「複式簿記的東方前身」。［[0800-阿拔斯王朝的稅務會計.md](0800-阿拔斯王朝的稅務會計.md)］
- 1086：英格蘭《末日審判書》——王國規模的資產清查，一次政治性的總審計。
- 1202：斐波那契《計算之書》把印度—阿拉伯數字帶進義大利商界——複式簿記的算術地基。

### 三、複式簿記的誕生與傳播（1211–1720）

- 1211：佛羅倫斯最早複式簿記殘卷——一位匿名商人的往來帳，出現「一筆兩記」。［[1211-佛羅倫斯複式簿記殘卷.md](1211-佛羅倫斯複式簿記殘卷.md)］
- 1340：熱那亞 Massari 帳簿——公共收支的複式記錄，官方版的「借貸必等」。［[1340-熱那亞Massari帳簿.md](1340-熱那亞Massari帳簿.md)］
- 1494：帕喬利《算術、幾何、比與比例概要》出版——複式簿記第一次被印刷、被教學、被教義化。［[1494-帕喬利與複式簿記.md](1494-帕喬利與複式簿記.md)］
- 1602：荷蘭東印度公司成立——股份公司讓「所有權與經營分離」，帳簿第一次要向陌生人交代。［[1602-荷蘭東印度公司與股份公司會計.md](1602-荷蘭東印度公司與股份公司會計.md)］
- 1720：南海泡沫與英國《泡沫法案》——第一場系統性的會計信任危機，也是審計觀念的政治起點。［[1720-南海泡沫與泡沫法案.md](1720-南海泡沫與泡沫法案.md)］

### 四、工業、職業與國家（1771–1934）

- 約1800：博爾頓與瓦特的 Soho 工廠成本制度——工業革命逼出「一件東西成本多少」的問題。［[1800-博爾頓瓦特與成本會計.md](1800-博爾頓瓦特與成本會計.md)］
- 1844/1856：英國公司法先後要求帳簿稽核；專業查帳被寫進法律。
- 1854：愛丁堡會計師公會獲皇家特許——「註冊會計師」成為職業。［[1854-愛丁堡會計師公會.md](1854-愛丁堡會計師公會.md)］
- 1896：紐約州 CPA 執照法——美國把查帳變成國家發照的專業。［[1896-紐約州CPA法.md](1896-紐約州CPA法.md)］
- 1911：泰勒《科學管理原理》——工時與成本被拆解成標準，標準成本會計登場。［[1911-科學管理與標準成本.md](1911-科學管理與標準成本.md)］
- 1929–1934：大蕭條、美國《證券法》與《證券交易法》——公開發行公司強制揭露，SEC 誕生。［[1934-證券法與SEC.md](1934-證券法與SEC.md)］

### 五、程序革命與準則政治（1938–2002）

- 1938：麥克森-羅賓斯舞弊案——查帳員沒看存貨、沒函證客戶，全美審計程序翻新。［[1938-麥克森-羅賓斯舞弊案.md](1938-麥克森-羅賓斯舞弊案.md)］
- 1973：FASB 成立；同年 IASC 在倫敦成立——準則制定的職業政治與國際化的起點。［[1973-FASB與IASC.md](1973-FASB與IASC.md)］
- 1979–1985：VisiCalc 到 Excel——電子試算表把簿記工作整個改寫；儲貸危機暴露監理會計的失靈。［[1985-電子試算表革命.md](1985-電子試算表革命.md)］
- 2001：恩隆（Enron）破產、安達信解體——審計獨立的終審判決。［[2001-恩隆與安達信.md](2001-恩隆與安達信.md)］
- 2002：《沙賓法案》（SOX）——內部控制、審計監理、課責的新憲法。［[2002-沙賓法案.md](2002-沙賓法案.md)］

### 六、全球化與演算法時代（2008–2026）

- 2008：金融危機與公允價值會計論戰——「市值」究竟是真相還是放大器？［[2008-金融危機與公允價值論戰.md](2008-金融危機與公允價值論戰.md)］
- 2015：IFRS 全球趨同——一百多個司法轄區採用國際準則，準則制定成為地緣政治。［[2015-IFRS全球趨同.md](2015-IFRS全球趨同.md)］
- 2018：區塊鏈與「三式簿記」的夢想——不可竄改的總帳能否取代審計？［[2018-區塊鏈與三式簿記.md](2018-區塊鏈與三式簿記.md)］
- 2020：疫情下的遠距審計與 ERP 雲端化——查帳員進不了倉庫。
- 2022–2026：生成式 AI 進入會計——自動對帳、草擬底稿、讀契約的「帶著提示詞的查帳員」。［[2022-生成式AI與會計自動化.md](2022-生成式AI與會計自動化.md)］
