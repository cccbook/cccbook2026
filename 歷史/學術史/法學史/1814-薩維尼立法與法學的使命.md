# 1814-薩維尼立法與法學的使命：法是長出來的，不是造出來的

## 案件摘要

1814 年，柏林大學法學教授薩維尼（Friedrich Carl von Savigny！）發表小冊《**立法與法學的使命**》（Vom Beruf unserer Zeit für Gesetzgebung und Rechtswissenschaft！）——回應海德堡教授蒂鮑（Thibaut！）的呼籲（！「普魯士應制定一部像法國那樣的統一民法典」！）——薩維尼反對：**法不是立法者的任意造物，而是「民族精神」（Volksgeist！）的顯現**（！）——法像語言一樣**隨民族有機生長**（！習俗→學說→法典！），**當下時機未熟**（！德意志分裂、法學未成！）——主張**從羅馬法與德意志法的歷史研究中淬鍊共同法**（！）——**歷史法學派成立宣言**（！）。（→後果！1815 創辦《歷史法學雜誌》；普魯士 1818 維持 1794 普通邦法；德國民法典延宕至 1900 年生效（！八十五年！）；羅馬法在德國的繼受繼續深化；潘德克頓學派與溫德沙伊德《潘德克頓教科書》（→德國民法典五編結構！）——**反對法典化的人，最終寫出了最好的法典**（！悖論！）。）這樁案件是「**立法全能主義的第一次系統反擊**」：**法有身世，不可以無中生有**（！）。

## 前因 -- 多因素的局勢

- **拿破崙法典的陰影**：萊茵區已適用法典（！）——**法國法長驅直入德意志**（！）——民族反彈（！）。
- **德意志政治碎片**：39 個邦（！）——**沒有立法中央權威**（！）。
- **浪漫主義思潮**：赫爾德的民族精神論（！）＋語言學與民謠採集（！）——**「民族有機體」的時代哲學**（！）。
- **德國羅馬法繼受深厚**：普通法（ius commune！）在帝國法院實務運行（！）——**學術法的存量資產**（！）。
- **蒂鮑的愛國提案**：1814《論制定一部德國普通民法典的必要》——**統一誘惑**（！）。

## 線索與推理 -- 因素咬合

### 線索一：Volksgeist——「法像語言一樣生長」

$$\text{法} = \text{（民族共同意識！）} \Rightarrow \text{習俗（！）→ 學說（！）→ 立法（！）三階段}$$

**立法是果實不是種子**（！）——**時機未熟就立法＝強摘果子**（！）。

### 線索二：法學家的角色——「法者是民族的代言人」

| 階段 | 主角 |
|------|------|
| 習俗法 | 全民族（政治因素！） |
| 學術法 | 法學家（雙重生活：民族＋專業！） |
| 法典 | 立法者（！） |

**法學家是法文化的器官**（！）——**當下德意志法學不成熟，法典只會凍結粗糙**（！）。

### 線索三：歷史研究即法學——「回到羅馬」

薩維尼《中世紀羅馬法史》（1815–31！六卷！）＋《當代羅馬法體系》（1840–49！八卷！）——**用語文學方法（！歷史語法！）重建法概念**（！）——**歷史＋體系雙引擎**（！）——**法學從立法附庸變成獨立科學**（！）。

## 破案時刻

- 1794：普魯士《普通邦法》頒行（！）——法典化的先行樣本。
- 1804：法國民法典頒布——外來壓力源。
- 1814：蒂鮑提案＋薩維尼小冊應戰——論戰爆發。
- 1815：《歷史法學雜誌》創刊＋柏林大學任教——學派建制化。
- 1837：《論當代羅馬法體系》方法論綱領式言說。
- 1840–49：《當代羅馬法體系》八卷——體系工程。
- 1848：德意志革命（！）——統一議題政治化。
- 1900.1.1：德國民法典生效——薩維尼死後 109 年，法典來了。

## 後果 -- 改變了什麼

- **歷史法學派**：薩維尼→普赫塔→耶林（後叛出！）——**法學的歷史轉向**（！）。
- **德國民法典的形狀**：潘德克頓五編（總則＋債＋物＋家＋繼！）、總則與抽象概念技術（！）——**反對者的學派造出法典**（！）。
- **法律多元論**：法不止國家立法一種源頭（→[1907-艾利希活的法律.md](1907-艾利希活的法律.md)直接受其啟發！）。
- **反面**：Volksgeist 的民族主義濫用（！）——**「民族法」可以滑向排外與專制**（！）。

**偵探結語**：薩維尼的案件中藏著法學史最漂亮的悖論：**他反對法典化，是為了讓德國終有一天擁有更好的法典**（！）——他把法典化從政治速度賽改造成學術馬拉松（！八十五年！），用歷史語文學把羅馬法淬鍊成概念精密的潘德克頓體系（！），而德國民法典恰恰是這場「慢」的獎品（！）。他的教訓有兩面：**法不是立法者的任意，這句話永遠成立**（！立法要有土壤！）；但「民族精神」這個詞也被二十世紀最壞的力量撿去用過（！）——偵探的判語：**有機生長論是對的，民族有機體論是危險的**——把兩者分開，是讀薩維尼的必修作業（！）。
