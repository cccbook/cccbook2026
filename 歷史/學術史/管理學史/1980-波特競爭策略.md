# 1980-波特競爭策略：五力分析佔領管理學院

## 案件摘要

1980 年，邁克爾·波特（Porter！普林斯頓工程學士！哈佛MBA＋經濟學博士！空軍軍官出身！）出版《競爭策略》（Competitive Strategy！）——**把產業組織經濟學（IO經濟學！）整包搬進管理學院**（！）——核心武器：**五力分析**（！現有競爭者！新進入者！替代品！供應商議價力！買方議價力！）——**三種通用戰略**（！成本領導！差異化！專一化——夾在中間者死！）——**進入障礙、移動障礙、戰略群組**（！）——這樁案件是「**管理學的經濟學化**」（！）——**戰略分析第一次擁有經濟學的正統血統**（→安索夫的表格被升級成產業地圖，見 [1965-安索夫公司戰略.md](1965-安索夫公司戰略.md)）。

## 前因 -- 多因素的局勢

- **戰後美國產業的停滯陰影**：1970s滯脹＋日本競爭（！）——**企業急需「如何打」的理論**（！）。
- **哈佛的跨學科位置**：波特同時修完MBA與經濟學博士（！）——**兩個世界的翻譯者**（！）。
- **IO經濟學的成熟**：SCP範式（結構—行為—績效！）（！）——**產業結構決定利潤的學說**（！）。
- **顧問業的需求**：麥肯錫BCG的工具太經驗主義（！）——**需要學術背書的框架**（！）。
- **反托拉斯的實務**：監管需要產業分析工具（！）——**五力後來成為壟斷案的通用語**（！）。

## 線索與推理 -- 因素咬合

### 線索一：五力——把行業畫成一張受力圖

| 力 | 問的問題 | 武器 |
|------|------|------|
| 現有競爭 | 打得有多狠？ | 市占率、集中度 |
| 新進入者 | 城牆夠高嗎？ | 進入障礙！ |
| 替代品 | 誰在隔壁搶客？ | 性價比曲線 |
| 供應商 | 上游掐你多緊？ | 集中度與轉換成本 |
| 買方 | 下游壓你多低？ | 買方集中度 |

$$\text{產業吸引力} = f(\text{五力的合力！}) \quad \text{（！）先選行業，再談經營！}$$

**這是戰略學的哥白尼轉向**（！）——**企業的位置（position！）比企業的內功更重要**（！）——（→安索夫問「往哪長」，波特問「在哪站」——問題的等級下降了！）

### 線索二：三種通用戰略——夾在中間的死刑

成本領導（！）差異化（！）專一化（！）——**試圖同時便宜又獨特者，兩頭落空**（！）——（→「stuck in the middle」成為管理學最有名的死刑判決——**而後來的豐田證明：品質與成本可以兼得，反例的殺傷力比理論更長壽**！見 [1978-大野耐一豐田生產方式.md](1978-大野耐一豐田生產方式.md)）

### 線索三：定位學派的登基——戰略的經濟學正統

波特由此建立**定位學派**（！）——**戰略＝在產業裡選一個可防禦的位置**（！）——（→明茲伯格的批判隨之而來：**定位學派假設環境穩定、情報完備——實際上企業常在霧中作戰**！而三十年後金偉燦直接說：**別在紅海裡選位置，去造一片海**！見 [2005-金偉燦藍海策略.md](2005-金偉燦藍海策略.md)）

## 破案時刻

- 1947：生於密西根（！）——軍人家庭（！）。
- 1969：普林斯頓工程學士（！）。
- 1971：哈佛MBA＋經濟學博士（！）——史上最年輕的終身教授候選人之一（！）。
- 1980：《競爭策略》出版（！）——即成經典（！）。
- 1983：Monitor顧問公司創立（！）。
- 1985：《競爭優勢》（！）——價值鏈登場（！）。
- 1990：《國家競爭優勢》（！）——鑽石模型（！）。
- 2000s：Monitor倒閉（2012！）——理論大師也逃不過自己的五力（！）。

## 後果 -- 改變了什麼

- **MBA課表的核彈級影響**：五力成為必修必修必修（！）——**戰略課程的全球標準**（！）。
- **顧問業的學術化**：價值鏈、五力（！）——**諮詢報價單的語言**（！）。
- **反壟斷的應用**：美國司法部合併指南採用（！）——**經濟學與法律的橋樑**（！）。
- **反擊的陣營**：資源基礎觀（RBV！核心能力！藍海！）（！）——**由內而外 vs 由外而內的百年之辭**（！）——（→平台經濟更是把「行業」這個分析單位本身炸掉了：**亞馬遜的行業是什麼？**見 [2015-平台經濟與零工管理.md](2015-平台經濟與零工管理.md)）

## 因素影響筆記

```
滯脹＋日本競爭 ──→ 企業的焦慮 ──→ 1980 五力登場
IO經濟學＋MBA訓練 ──→ 跨界翻譯 ──→ 戰略學的經濟學化
五力＋三戰略 ──→ 定位學派登基 ──→ MBA課表標準（→顧問業語言！）
「夾在中間」判決 ──→ 豐田反例 ──→ 理論的邊界暴露（1978！）
行業作為分析單位 ──→ 平台時代瓦解 ──→ 藍海與平台經濟的改寫（2005！2015！）
```

**偵探結語**：波特五力的案件是「**管理學史上最成功的一次理論出口**」：他證明經濟學可以賣給CEO（！）——**而且賣出了課堂、董事會、司法部三個市場**（！）偵探的判詞：五力的前提是「產業」這個容器（！）——**當亞馬遜同時是零售商、雲計算商、物流商與演算法公司時，五力圖上連坐標軸都畫不出來**（！）這不是波特錯了，是時代換了考卷（！）——他的真正遺產是那個姿勢：**經營企業前，先冷靜地畫出你所在力量的地圖**（！）——這個姿勢，藍海策略與精實創業都得繼承（→見 [2005-金偉燦藍海策略.md](2005-金偉燦藍海策略.md)）——**只是她們把地圖畫到了波特沒畫過的地方**。
