# 1916-法約爾工業管理與一般管理：管理的五职能憲法

## 案件摘要

1916 年，亨利·法約爾（Fayol！法國礦業工程師！科芒特里—富爾尚博公司三十年總經理！）出版《工業管理與一般管理》（Administration industrielle et générale！）——**與泰勒同時而路線相反**（！）——泰勒管車間（！）——法約爾管**整個公司**（！）——他提出：**管理是一般職能**（！）——**計畫、組織、指揮、協調、控制**五大職能（！）——**十四條管理原則**（！分工！權責一致！統一指揮！統一領導！集權！等級鏈！秩序！公平！人員穩定！首創精神！團結精神！等）——**管理可以被教、可以從學校學**（！）——這樁案件是「**管理學的憲法被起草**」（！）——**每一本管理教科書的第一章都是他的遺產**（→而明茲伯格五十七年後將實證顛覆它，見 [1973-明茲伯格管理工作的本質.md](1973-明茲伯格管理工作的本質.md)）。

## 前因 -- 多因素的局勢

- **法約爾的實戰身分**：他不是顧問而是總經理（！）——**從瀕臨破產的公司把工業帝國救起來**（！）。
- **泰勒的車間偏光**：科學管理聚焦作業層（！）——**高層管理的理論仍是空白**（！）。
- **法國工程師傳統**：中央理工學院！（！）——**系統化、原則化的思維風格**（！）。
- **企業規模擴大**：多工廠、多職能（！）——**協調成為頭號問題**（！）。
- **管理教育的需求**：法國商學與工程教育（！）——**需要可以傳授的框架**（！）。

## 線索與推理 -- 因素咬合

### 線索一：五職能——管理被切成可教的方塊

| 職能 | 內容 | 問的問題 |
|------|------|------|
| 計畫 | 預見未來、擬定行動路線 | 去哪裡？ |
| 組織 | 建構機構、配置資源 | 誰做什麼？ |
| 指揮 | 讓人員發揮作用 | 怎麼帶？ |
| 協調 | 對齊各部門節奏 | 怎麼合拍？ |
| 控制 | 核對實際與計畫 | 有沒有走偏？ |

$$\text{管理} = \sum \text{（可命名的職能！）} \quad \text{（！）可命名→可教→可考→可授學位！}$$

**這是管理學成為學科的操作性定義**（！）——（→安索夫的戰略、波特的策略，都是在「計畫」這一格裡開疆拓土！見 [1965-安索夫公司戰略.md](1965-安索夫公司戰略.md)）

### 線索二：十四原則——經驗的法典化

統一指揮（一人一個上司！）、等級鏈（！）＋**「跳板法」**（！同層級可直接橫向溝通，不必逐級上報——法約爾自己的聰明折衷！）、人員穩定（！）——**這些原則來自三十年實務（！）而非書齋推理**（！）——（→與韋伯的科層制理想型同時成形——官僚制的法國版實務說明書！）

### 線索三：與泰勒的和解——管理的上下兩半

法約爾公開承認並推崇泰勒（！）——**「泰勒管作業，我管管理」**（！）——兩人在晚年互認（！）——（→管理學的兩大源頭就此合流：車間的科學＋高層的原則——此後的教科書結構即此合流的產物！）

## 破案時刻

- 1841：生於伊斯坦堡（！）——法國工程師家庭（！）。
- 1860：礦業學院畢業（！）——入科芒特里公司（！）。
- 1888：任總經理（！）——公司瀕臨倒閉（！）。
- 1888–1918：三十年重建（！）——冶金帝國復興（！）。
- 1916：《工業管理與一般管理》出版（！）——時值一戰（！）。
- 1925：死（！）——法國管理運動的中心人物（！）。
- 1930s–40s：經林德爾·厄威克等人引介入英美（！）——成為教科書正典（！）。

## 後果 -- 改變了什麼

- **管理教科書的骨架**：五職能＋原則（！）——**至今所有入門書的第一章**（！）。
- **管理教育的正當性**：商學院可以教管理（！）——**MBA 的理論祖先**（！）。
- **跳板法與組織設計**：橫向溝通的先聲（！）——**矩陣組織與跨部門協作的遠祖**（！）。
- **被實證挑戰的宿命**：明茲伯格的秒錶追蹤（！）——**真實管理不是五職能的優雅排列**（！見 [1973-明茲伯格管理工作的本質.md](1973-明茲伯格管理工作的本質.md)）。

## 因素影響筆記

```
總經理實戰三十年 ──→ 原則的法典化 ──→ 1916 憲法問世
泰勒車間偏光 ──→ 高層理論空白 ──→ 法約爾補上上半身
五職能可命名 ──→ 可教可考 ──→ 商學院正當性（→MBA帝國！）
十四原則＋跳板法 ──→ 科層實務說明書 ──→ 組織設計傳統
優雅的職能圖 ──→ 與真實管理的落差 ──→ 明茲伯格的顯微鏡（1973！）
```

**偵探結語**：法約爾的案件是「**管理的憲法起草人**」：泰勒發明了手術刀（！），法約爾寫了操典（！）——他最深的貢獻不是哪一條原則，而是那個斷言：**管理是一門可以命名、可以傳授的普遍學問，與你管的是礦場還是醫院無關**（！）這個斷言撐起了整個管理教育產業（！）偵探的保留意見：憲法寫得越優雅，離現場就越遠（！）五十七年後，一位加拿大教授拿著秒錶坐在 CEO 辦公室裡，發現真實的管理根本不是五個方塊的合唱，而是一場被打斷一百次的即興演出（→見 [1973-明茲伯格管理工作的本質.md](1973-明茲伯格管理工作的本質.md)）——**但沒有法約爾的憲法，就沒有值得明茲伯格去顛覆的教科書**。
