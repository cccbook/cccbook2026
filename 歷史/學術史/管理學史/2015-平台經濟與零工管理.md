# 2015-平台經濟與零工管理：把「公司」拆成演算法的偵查

## 案件摘要

2010s 中葉（本案以 2015 年為偵查中點！），平臺經濟學（Rochet 與 Tirole 的雙邊市場理論 2003 起奠基！Tirole 獲 2014 諾貝爾經濟學獎！）與零工經濟（Gig Economy！）成為管理學的核心案卷——**Uber、Airbnb、Upwork 等：用演算法取代經理人、用評分取代監督、用 App 取代人力資源部**（！）——**錢德勒的「看得見的手」被改裝成「看不見的演算法」**（→ [1962-錢德勒看得見的手.md](1962-錢德勒看得見的手.md)）（！）——**管理學被迫回答三個新問題**：當勞動者不叫員工而叫「夥伴」，管理是什麼？（！）當監督由演算法執行，泰勒制回來了嗎？（！）當「公司」的邊界液化，組織理論還剩下什麼？（→ [2023-AI與管理的自動化.md](2023-AI與管理的自動化.md)）（！）。

## 前因 -- 多因素的局勢

- **雙邊市場經濟學**：Rochet-Tirole 證明平台定價的交叉補貼邏輯——**規模→網路效應→贏者通吃**（！）。
- **智慧手機＋GPS＋行動支付**：2007–2013 的基礎設施齊備——**即時調度億萬次勞動的技術條件**（！）。
- **2008 金融危機的就業缺口**：失業與債務使「彈性接案」從被迫變成話術（！）。
- **「零工經濟」的命名與傳播**：2015 年前後進入主流媒體與政府報告（！）。
- **雲端與行動通訊**：企業可以把「工作」拆成 API 般的任務包——**巴貝奇技能拆解的極致版**（→ [1832-巴貝奇論機器與製造業的經濟.md](1832-巴貝奇論機器與製造業的經濟.md)）（！）。

## 線索與推理 -- 因素咬合

### 線索一：演算法管理（Algorithmic Management）——泰勒的數位復活

| 傳統經理人 | 平台演算法 |
|------|------|
| 派工與排程 | 即時派單（！接單率懲罰！） |
| 績效面談 | 星級評分＋動態降權（！） |
| 培訓 | 彈窗與推送（！） |
| 解僱面談 | 帳號停權（！） |

**工人從未見過「雇主」，卻被最細粒度地管理**（！）——**「控制力的黃金時代回來了，只是老闆看不見」**（→ [1911-泰勒科學管理原理.md](1911-泰勒科學管理原理.md)、[1960-麥格雷戈X理論Y理論.md](1960-麥格雷戈X理論Y理論.md)）（！）。

### 線索二：僱傭關係的液化——「夥伴」的法律煉金術

**平台自稱「科技公司」而非運輸/僱傭公司**——**成本轉嫁（車！保險！社保！）＋責任切割**（！）——**加州 AB5 法案（2019！）與 Prop 22 大戰、英國最高法院 2021 判 Uber 司機為 worker**（！）——**管理學史與勞動法史的合流**（！）——**平台話語的「彈性」vs 工人的體感「不穩定」**（！）。

### 線索三：公司的邊界液化——錢德勒判例的重新審理

$$\text{科斯之問：為何有公司？(交易成本！)} \quad \xrightarrow{\text{平台把交易成本壓到趨零！}} \quad \text{公司為何還存在？}$$

**組織理論的新議題**：平台不是市場也不是層級，是**「有界的市場」**（！）——**新型混合組織：內部創業＋外部接單＋眾包補位**（！）——**德魯克「員工是社會公民」的對立面出現：勞動者成為「用戶」**（→ [1945-德魯克公司的概念.md](1945-德魯克公司的概念.md)）（！）。

## 破案時刻

- 2003：Rochet-Tirole 雙邊市場理論（！）。
- 2009–2013：Uber、Airbnb 等成立並指數擴張（！）。
- 2014：Tirole 獲諾貝爾獎；「分享經濟」一詞流行（！）。
- 2015：零工經濟成為政策與學術熱點；平臺工作研究爆發（！）。
- 2016：倫敦、紐約司機罷工——**演算法管理的第一次集體抗議**（！）。
- 2019–2021：AB5／Prop 22（！）＋英國最高法院判決（！）——**法律對「夥伴」煉金術的反擊**（！）。
- 結案：公司沒有消失，但「管理」被拆成了數億次演算法決策——偵查仍在進行（！）。

## 後果 -- 改變了什麼

- **人力資源管理的分裂**：一部分人類 HR，一部分演算法 HR——**勞動過程理論的數位復興**（！）。
- **零工福利的制度實驗**：平臺社保、可攜式福利、第三類身分（worker！）——**二十世紀勞動體系的修補**（！）。
- **對「管理」的反身性提問**：如果調度可以自動化，經理人的存在理由被縮減——**通往 AI 管理的預審**（→ [2023-AI與管理的自動化.md](2023-AI與管理的自動化.md)）（！）。
- **社會學的匯流**：平台勞動研究與數位社會學（→ [2018-演算法社會與數位社會學.md](../社會學史/2018-演算法社會與數位社會學.md)）合流（！）。

**偵探結語**：平台經濟案是管理學史上最徹底的一次「角色重排」——**公司說自己是科技公司，勞動者被登記為夥伴，經理人被替換成演算法，而顧客的評分成了新的工頭**（！）——泰勒若復活，會認出每一個零件：派單是派工，評分是計件，停權是解僱；只是整座工廠被裝進了口袋，**沒有牆，沒有鐘聲，也沒有人回答你的申訴**（！）——阿克萊特的鐘聲（→ [1771-阿克萊特工廠與最早的管理.md](1771-阿克萊特工廠與最早的管理.md)）變成了接單倒數（！）。但偵探也記錄了抵抗的證據：司機的罷工、法院的判決、司機自建的通訊群——**兩百五十年來，管理的每一次升級都同步生產著抵抗的新語法**（！）。本案未結：**當演算法不僅管理零工、還開始管理白領時，錢德勒的帝國將面對真正的終審**（→ [2023-AI與管理的自動化.md](2023-AI與管理的自動化.md)）。
