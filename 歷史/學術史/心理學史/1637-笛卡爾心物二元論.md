# 1637-笛卡爾心物二元論：把心靈搬出肉體的世紀搬遷

## 案件摘要

1637 年，笛卡爾出版《方法論》，提出「我思故我在」；1650 年他去世時，留下了一個尚未解決、卻決定此後三百年心理學走向的懸案：**心靈與身體是兩種不同的實體嗎？**這樁案件的兇手是「機械論的世界觀」：笛卡爾把身體完全交給力學（動物是機器），卻把心靈留在機器之外——這個「搬遷」一方面讓生理學得以解放（身體不需要靈魂來解釋），另一方面製造了「心如何推動身」的世紀難題。

## 前因 -- 多因素的局勢

- **宗教**：宗教戰爭（1618–1648）——歐洲被信仰撕裂，笛卡爾要找一個任何教派都無法否認的起點。
- **科技**：機械鐘錶與自動玩偶的流行——「機器可以做到什麼程度」成為時代話題。
- **前輩線索**：伽利略用數學描述運動成功——自然書寫的語言是數學；亞里斯多德的目的論物理正在崩塌。
- **個人線索**：笛卡爾的夢境疑案——夢中經驗如此逼真，如何確定「清醒」？懷疑方法由此而來。

## 線索與推理 -- 因素咬合

### 線索一：懷疑方法 = 系統性刪除

笛卡爾的推理是「刪除法」：感官會騙人 → 刪；數學也可能被惡魔欺騙 → 刪；最後剩下的：

$$\text{我在懷疑} \Rightarrow \text{我在思考} \Rightarrow \text{我（思考實體）存在}$$

**唯一刪不掉的是思考本身**——心靈因此被證明為「與廣延物體不同的實體」。這是思辨上的漂亮一擊，但也埋下地雷。

### 線索二：二元論的「交易」

| 給予 | 換取 |
|------|------|
| 把身體完全交給機械論（生理學可以無神論式研究） | 教會不再追究身體研究 |
| 把心靈劃為教會轄區（靈魂不滅得以保留） | 心靈研究失去生理學工具 |

這是一樁「政教分離式」的交易——**心理學未來三百年的困境，就是這樁交易的遺產**：身體可以量測，心靈只能內省。

### 線索三：松果腺的失敗嘗試

心身如何互動？笛卡爾選了腦中的松果腺作為交會點——這是第一個「心智的神經定位」嘗試。定位錯了，但**問題問對了**：兩百年後布羅卡（[1861-布羅卡失語症.md](1861-布羅卡失語症.md)）正是沿著「心靈功能能否在腦中定位」這條線索破案。

### 線索四：反射的概念

笛卡爾描述了「反射」：刺激 → 神經中的「動物精氣」 → 肌肉反應，不需要心靈參與。這是**行為主義的技術原型**——巴夫洛夫（[1904-巴夫洛夫條件反射.md](1904-巴夫洛夫條件反射.md)）與史金納（[1938-史金納操作性制約.md](1938-史金納操作性制約.md)）的反射弧，直接繼承此處。

## 破案時刻

- 1637：《方法論》——「我思故我在」公開。
- 1641：《沈思錄》——二元論的完整論證。
- 1649：《論靈魂的激情》——情緒的機械生理學，最後一部作品。
- 1650：客死瑞典；遺體與頭顱此後分離流轉，彷彿二元論的黑色寓言。

## 後果 -- 改變了什麼

- **哲學**：心物問題成為近代哲學第一懸案——斯賓諾莎、萊布尼茲、休謨都從這裡出發。
- **生理心理學**：反射概念 → 謝林頓的神經生理學 → 行為主義。
- **認知科學**：心靈可以離開「肉體細節」被形式化——電腦心智的哲學前提（[1950-圖靈測試.md](1950-圖靈測試.md)）。
- **負面遺產**：心理學長期糾結「意識能否科學研究」——華生的行為主義（[1913-華生行為主義宣言.md](1913-華生行為主義宣言.md)）某種意義上是「刪除二元論的那一半」。

## 因素影響筆記

1. **宗教衝突 → 懷疑方法**：信仰崩解的年代逼出最激進的懷疑。
2. **科技（機器）→ 心身模型的隱喻**：每個時代的技術決定心靈的隱喻——機器、電報、電腦、神經網路。
3. **長期迴路**：二元論 → 定位論的提問 → 顱相學的錯誤答案 → 布羅卡的正確答案 → fMRI（[1990-fMRI與認知神經科學.md](1990-fMRI與認知神經科學.md)）。
