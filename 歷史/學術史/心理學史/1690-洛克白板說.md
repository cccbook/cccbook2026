# 1690-洛克白板說：心靈的內容從經驗來

## 案件摘要

1690 年，洛克出版《人類理解論》。他不問「心靈是什麼」，改問「**心靈裡有什麼、它們從哪裡來**」——答案是：一張白板（tabula rasa），所有觀念都來自經驗（感覺與反省）。這樁案件的兇手是「經驗論的知識觀」：如果觀念來自經驗，那麼心靈就**可以被追蹤、被分析、被教育**——心理學從此從「靈魂的形上學」轉向「觀念的會計學」。

## 前因 -- 多因素的局勢

- **政治**：英國內戰與光榮革命——洛克是革命理論家，對「天賦權威」的一切版本都有敵意（國王不是天授，觀念也不是天賦）。
- **宗教**：清教徒的寬容爭論——洛克主張宗教寬容，「天賦觀念」會變成強制信仰的藉口。
- **前輩線索**：笛卡爾的天賦觀念（[1637-笛卡爾心物二元論.md](1637-笛卡爾心物二元論.md)）是要攻擊的靶子；霍布斯的唯物論已把「思想」降格為「感覺的連鎖」。
- **經濟與社會**：商業社會的實用精神——知識要能被檢驗、被累積，而不是被玄談。

## 線索與推理 -- 因素咬合

### 線索一：攻擊「天賦觀念」= 政治論證的認識論版本

洛克的推理鏈：如果天賦觀念存在，兒童與愚人應該也懂邏輯與道德公理——但他們不懂。因此：

$$\text{心靈} = \text{白板} + \sum(\text{感覺經驗}) + \sum(\text{反省經驗})$$

注意政治暗流：**如果觀念是天賦的，權威就有籍口說「你天生該服從」；如果觀念來自經驗，教育與環境就是改造人的槓桿**——認識論與政治學在這裡是同一案。

### 線索二：簡單觀念 → 複雜觀念 = 心理的原子論

洛克把心靈內容拆成「原子」（簡單觀念），複雜觀念由原子組合而成——這是**心靈的化學模型**。一百年後，英國聯想主義（哈特萊、彌爾父子）沿此發展成「心理學的原子論」；再一百年後，行為主義的「刺激—反應聯結」（[1898-桑代克效果律.md](1898-桑代克效果律.md)）是同一套原子論的操作化版本。

### 線索三：第一性質 vs 第二性質的留白

洛克承認「第二性質」（顏色、味道）是心靈的加工——**這等於承認心靈有「主動加工」的成分**，與白板說有張力。這道裂縫被康德炸開（[1781-康德的心靈地圖.md](1781-康德的心靈地圖.md)）：加工不是偶發的，而是成套的先天結構。

### 線索四：教育即工程

《教育漫話》：「九成的善惡由教育決定。」白板說的直接應用——**人是可以被設計的**。樂觀的一面是普及教育的正當性；陰暗的一面是行為主義的「行為工程」（[1938-史金納操作性制約.md](1938-史金納操作性制約.md)）與極權宣傳的理論空間。

## 破案時刻

- 1690：《人類理解論》出版。
- 1693：《教育漫話》。
- 結案：心靈的研究對象從「靈魂」變成「觀念的來源與組合」。

## 後果 -- 改變了什麼

- **哲學**：英國經驗論的起點——柏克萊、休謨接力，休謨把因果都降格為「習慣的聯想」。
- **心理學**：聯想主義成為心理學前科學期的主流理論。
- **教育**：環境決定論 → 現代教育學與「早期介入」政策的哲學根基。
- **政治**：白板 + 天賦人權（人有理性，故平等）→ 啟蒙與革命時代的意識形態。

## 因素影響筆記

1. **政治革命 → 認識論革命**：推翻王權的邏輯同時用來推翻天賦觀念。
2. **經驗論 → 教育工程 → 行為主義**：一條從 1690 直通 1938 的線索。
3. **張力線索**：白板說自己埋下了康德的反案——「被經驗填滿的白板」仍需要先天的框架才能經驗。
