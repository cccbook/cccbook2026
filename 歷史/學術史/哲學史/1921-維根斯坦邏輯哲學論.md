# 1921 · 維根斯坦邏輯哲學論：戰壕手稿案

## 案件摘要
1921 年，《自然科學年鑑》刊出維根斯坦（1889–1951）的《邏輯哲學論》（拉丁文題辭：「凡是能夠說的事情，都能夠說清楚；凡是不能談論的事情，就應當保持沉默」）。（!七十五頁、編號命題七層樓的書，作者宣稱它解決了全部哲學問題——然後宣布自己不再做哲學家！）

## 前因 -- 多因素的局勢
1. **維也納的三重遺產**：鋼鐵帝國維根斯坦家族（其兄保羅是獨臂鋼琴家、家中常客有馬勒與克里姆特）；三兄自殺的家族陰影；維也納學派末期的科學世界觀——（!巨富+死亡+科學主義，此案的成長檔案極端沉重！）
2. **劍橋-羅素收編（1911–1914）**：兩年時間維根斯坦從「學生」變成「導師」——羅素承認「他是我所見的最完美的激情典範」，並說維氏教他「邏輯之外還有重要的事」。
3. **一戰志願兵**：奧匈炮兵觀測員，屢獲勳章，在戰壕與戰俘營（1918–19 卡薩諾）完成定稿——手稿隨身、戰壕讀托爾斯泰《福音書摘要》——（!《邏輯哲學論》一半是邏輯，一半是宗教急救包！）
4. **弗雷格-羅素邏輯革命**：弗雷格對胡塞爾的心理主義批判、羅素悖論與類型論——「把哲學變成邏輯」的工廠已經建成。
5. **叔本華-克爾凱郭爾-托爾斯泰的暗流**：倫理、意志、世界意義的問題被正式開除出可說領域——但沒有被取消。

## 線索與推理 -- 因素咬合
### 線索一：圖像論——命題如何工作
命題是事態的**邏輯圖像**：結構同構即描畫。「世界的意義必定在世界之外」（6.41）；世界=事實的總和（1.1），不是物的總和。（→ 把「世界」從名詞倉庫改成事實清單，這一步讓傳統形上學的存貨瞬間滯銷！）

### 線索二：可說與不可說的邊界偵查
| 層 | 內容 | 身分 |
|---|---|---|
| 可說 | 自然科學命題 | 有真假 |
| 不可說 | 倫理、美學、世界意義 | 只能顯示（zeigen） |
| 本書自身 | 哲學命題 | 6.54：爬完梯子後扔掉 |

「我的命題是這樣起闡明作用的：理解我的人，最終會認出它們是無意義的——他必須爬上梯子之後把梯子扔掉。」（6.54）
（!邏輯哲學論自認為梯子——這是哲學史上最徹底的自我取消，也是書籍版的自殺炸彈！）

### 線索三：實踐上的自棄
1920 年代維根斯坦真的照做：放棄遺產、當小學教師（奧特塔爾，1920–26，因體罰醜聞辭職）、修道院園丁、為姊姊設計現代主義宅邸——（!哲學史上唯一按自己理論執行「退出哲學」的案例！）
但同期維也納學圈把此書讀成實證主義憲章（石里克 1924 來信、1927 會面）——維根斯坦私下抗議：「他們不理解我」。

### 線索四：回鍋與二審預告
1929 年維根斯坦重返劍橋（以《邏輯哲學論》獲博士學位，主考人羅素與摩爾），開始批判自己：「圖像論無法解釋語言的實際用法」——《藍皮書》《棕皮書》（1933–35）→《哲學研究》（見 [1953-維根斯坦哲學研究.md](1953-維根斯坦哲學研究.md)）——（!同一作者完成哲學史上最大的一次自我起訴！）

## 破案時刻
- 1908：曼徹斯特航空工程（風箏與螺旋槳）。
- 1911-10：劍橋見羅素。
- 1914–18：一戰奧匈軍服役，戰壕中多次修改手稿。
- 1918-8：意大利戰俘營完成定稿。
- 1921：《邏輯哲學論》刊於《自然科學年鑑》（奧斯特瓦爾德主編，維根斯坦自費換得版面）——（!巨富之子居然要貼錢發表，因為出版社都退稿！）
- 1922：英語雙語版（Ogden 譯，C. K. Ogden & 弗蘭克·拉姆齊協作）。
- 1924–27：與石里克通信；維也納學圈集體閱讀（拉姆齊、魏斯曼記錄）。
- 1929：重返劍橋；1939 接摩爾任教授；1947 辭職；1951-4-29 卒於劍橋（醫生家樓上）。
- 遺言：「告訴他們，我度過了美好的一生。」

## 後果 -- 改變了什麼
1. 維也納學圈的「聖經」：《宣言》(1929) 的「通過邏輯分析清除形上學」綱領以此書為上游（見 [1929-維也納學圈宣言.md](1929-維也納學圈宣言.md)）——作者本人卻站在對面。
2. 哲學的「治療」概念：哲學問題=語言誤用症——日常語言學派（賴爾、奧斯汀）與後期維根斯坦「語言遊戲」皆承此病歷。
3. 邏輯實證主義的「可證實性」判準：是《邏輯哲學論》「不可說」邊界的世俗化版本——石里克主義讀走了梯子，忘了梯子原本是扔的。
4. 「沉默」的美學與倫理輻射：塞蘭的詩、卡爾維諾、維特根斯坦在文學與建築中的引用——「對不可說者保持沉默」成為現代主義的口號。


**偵探結語**：這樁案件最震撼的物證不是書，是書的用法：一個在戰壕裡讀福音書的炮兵寫了邏輯的墓誌銘，然後真的去鄉下教小學生拼單詞。維也納學圈把梯子搬回家當聖物，作者回頭說那是用完就扔的東西。此案揭示的權力結構百年不變：體制需要教條，天才寫的是自由——最後連「保持沉默」都會被收編成口號。維根斯坦一生都在對抗自己被盜版。
