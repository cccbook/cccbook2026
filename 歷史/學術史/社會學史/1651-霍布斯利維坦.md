# 1651-霍布斯利維坦：從戰爭泥沼裡撈出的巨獸

## 案件摘要

1651 年，托馬斯·霍布斯（Hobbes！1588 生於西葡無敵艦隊逼近之年——母親的驚嚇產下早產的他，他自嘲「恐懼與我是雙胞胎」！）在巴黎出版《利維坦》（Leviathan！聖經中的海中巨獸！）——**人造的國家之神**（！）——全書從「自然狀態」推演出絕對主權：在沒有公共權力的地方，人人對人人開戰（！war of all against all！），人生「孤獨、貧窮、齷齪、野蠻而短暫」（！名句！）——所以理性的人用契約把權利讓渡給一個巨大的人造體（→利維坦！）——**社會契約論的開山＋社會學「秩序問題」的原始碼**（！）。這樁案件是「**從內戰的血泊裡推導出國家**」：霍布斯不是在寫哲學，他是在替一個燒起來的世界寫滅火器說明書（！）。

## 前因 -- 多因素的局勢

- **英國內戰**：1642–1648（！議會軍 vs 王軍！）＋查理一世 1649 斷頭台（！）——**親眼目睹國家解體**（→霍布斯 1640 早逃巴黎！）。
- **三十年戰爭**：1618–48（！德意志死三分之一人口！）——**整個歐洲的自然狀態樣本**（→「戰爭不是例外是常態」！）。
- **科學革命**：伽利略（！1636 霍布斯親訪！）、哈維（！血液循環、霍布斯好友！）——**把人看成機器**（→機械論身體觀！）。
- **人文傳統**：修昔底德（！霍布斯譯《伯羅奔尼撒戰爭史》！）——**人性和政體的觀察標本**（！）。
- **宗教內戰**：教派相殘（！）——**「誰掌真理誰掌刀」**（→利維坦要壟斷裁判權！）。

## 線索與推理 -- 因素咬合

### 線索一：自然狀態——「沒有政府的實驗室」

霍布斯做了一個思想實驗（！把國家抽掉會怎樣？）：人天生平等（！都能殺人！）＋資源相對匱乏＋利己＋恐懼＋榮譽心——結果：

$$\text{自然狀態} = \text{（平等！）} + \text{（匱乏！）} + \text{（利己！）} \Rightarrow \text{一切人對一切人的戰爭}$$

**沒有警察的世界**（→沒有農耕！沒有航海！沒有建築！沒有藝術！）——**社會學的「秩序問題」第一次被公式化**（！這是霍布斯問題：社會性合作為何可能？）。

### 線索二：契約與主權——「人造神的組裝圖」

第二卷（！）：眾人互相訂約，把自然權利**讓渡給第三人（或多數）**——主權者（！Sovereign！）在契約之外（！他不是簽約方，你無法違約告他！）——**絕對不可分割**：

$$\text{利維坦} = \sum(\text{個體權利讓渡}) \Rightarrow \text{單一主權（不可退貨！）}$$

**「國家是人造的人」**（！封面巨人：身體由小市民組成！手持劍與杖！）——**機械論的政治學**（→哈維的血液循環＝主權的命令系統！）。

### 線索三：宗教與思想——「第七章審判權」

第三、四卷（！）：《聖經》詮釋權（！誰解經誰掌權！）＋「王國之內只有一个最高立法者」——霍布斯本人被保王黨恨（！克倫威爾聽了舒服！）、又被革命黨忌（！）——**書回到英國反而獲准出版**（→他伺機回國！1651！）——**太誠實的政治科學，兩邊都怕**（！）。

## 破案時刻

- 1588：出生（！無敵艦隊恐慌！）——恐懼是雙胞胎。
- 1629–1636：譯修昔底德（！）＋訪伽利略（！）——方法成型。
- 1640：《法律要義》（！）——內戰爆發前夜逃亡巴黎（！）。
- 1642–51：《論公民》（！）→《利維坦》（！）——破案。
- 1651：回英國（！）——向克倫威爾政權（！主權已立！）低頭。
- 1666：倫敦大火與瘟疫後，國會還想以「無神論」審他（！）——利維坦被焚（！）。

## 後果 -- 改變了什麼

- **社會契約傳統**：洛克（！有限政府！）→盧梭（！公意！見 [1755-盧梭論不平等.md](1755-盧梭論不平等.md)）——**全部從霍布斯的問題出發**（！）。
- **社會學秩序問題**：涂爾幹（！反對契約論，「契約需要非契約基礎」！）——**每個社會學家都在回答或改寫霍布斯**（見 [1893-涂爾幹社會分工論.md](1893-涂爾幹社會分工論.md)）。
- **現代國家理論**：主權（！韋伯「壟斷合法暴力」的祖先！）——**國家是個人製造的怪獸**（！）。
- **人性觀**：經濟人原型（！亞當·斯密的利己假設陰影！見 [1776-亞當斯密國富論.md](1776-亞當斯密國富論.md)）——**冷冷的起點**（！）。

## 因素影響筆記

```
英國內戰（1649斷頭台！）──→ 目睹無政府之惡 ──→ 自然狀態假說
伽利略＋哈維（機械論！）──→ 人＝機器／國家＝人造人 ──→ 利維坦組裝圖
恐懼（1588胎記！）──→ 「安全的」絕對主權 ──→ 契約論傳統（洛克→盧梭！）
秩序問題 ──→ 社會學原始碼 ──→ 涂爾幹／韋伯（改寫霍布斯！）
```

**偵探結語**：霍布斯的案件是「**用最壞的人性推導最強的政府**」：他不是極權主義者（！那詞還沒發明！），他是**一個被內戰嚇破膽的聰明人把膽量換成了邏輯**——利維坦的每一寸肌肉都是恐懼澆鑄的（！）。真相：**社會學的起源不在烏托邦，而在災難**（！莫爾有羊吃人、霍布斯有斷頭台！）。最深的諷刺：他筆下的主權者（！不可反抗！）在 1660 年的現實裡是——被殺國王的兒子復辟（！權力靠血統不靠契約！）——**霍布斯用契約論證明的，是復辟**。但問題留下了，一百年、三百年、四百年（！）都沒人逃得掉：**如果人人自私，秩序從哪裡來？**——今天每一場關於警力、死刑、軍隊、平台的辯論（！），都是 1651 年那頭巨獸的迴聲。
