# 2018-演算法社會與數位社會學：推薦系統成為新的社會工程師

## 案件摘要

2010s（！本檔案以 2018 為標誌年：劍橋分析事件＋《監控資本主義時代》出版！）——**演算法成為社會的基礎設施**（！）——**祖博夫（Zuboff！）的「監控資本主義（surveillance capitalism！）」**（！）——**演算法社會（algorithmic society！）**：**推薦系統＋演算法治理＋資料殖民**（！）——**數位社會學（digital sociology！）**作為新次領域**（！）——**平台（platform！）、演算法、大數據、AI**（！）——**這是社會學史的最新案件**（！）——**每一個按讚、每一次滑動、每一個推薦，都是社會學的實驗室**（！）——這樁案件是「**一個看不見的工程師，正在重新設計人類的社會行為**」（！）。

## 線索與推理 -- 因素咬合

### 線索一：監控資本主義——「你的行為是商品」

祖博夫（Zuboff！）的診斷（！）：

$$\text{行為剩餘（behavioral surplus！）} = \text{（資料提取！）} \Rightarrow \text{（預測商品！）} \Rightarrow \text{（利潤！）}$$

**免費服務的代價**（！）——**行為剩餘**（！你以為你在用，其實你在被收割！）——**「資料殖民」**（！data colonialism！）——**「你是產品」**（！）——**這是馬克思剩餘價值理論的數位版**（！見 [1867-馬克思資本論.md](1867-馬克思資本論.md)）。

### 線索二：演算法治理——「看不見的行政」

演算法的社會角色（！）：

| 領域 | 演算法的功能 |
|------|--------------|
| 資訊 | 推薦系統（！你在看什麼！） |
| 評價 | 信用評分＋評價系統（！） |
| 治理 | 預測警務（！）＋風險評估 |
| 勞動 | 零工經濟的派單（！） |

$$\text{演算法} = \text{（新科層！）} + \text{（新文化工業！）} + \text{（新監控！）}$$

**韋伯的鐵籠升級為演算法的籠子**（！）——**但鐵籠看不見**（！）——**「演算法不歧視」是新的種族主義**（！）——**演算法偏見（！algorithmic bias！）**（！）。

**社會學的新工具**（！）——**數位民族誌＋計算社會學**（！）——**跨學科的競爭與合作**（！）。
