# 1966-伯格與盧克曼現實的社會建構：常識本身就是社會學案發現場

## 案件摘要

1966 年，彼得·伯格（Berger！奧地利裔美國人！）與托馬斯·盧克曼（Luckmann！德裔斯洛維尼亞人！）出版《現實的社會建構》（The Social Construction of Reality！）——**副題：知識社會學論文集**（！）——核心：**我們所謂「現實」不是給定的，是由社會過程建造的**（！）——**外在化（externalization！）→ 客觀化（objectivation！）→ 內化（internalization！）**——**制度化的三階段**（！）——**「常識」是社會學最大的案發現場**（！）——**「現實不是一成不變的，是有人持續施工的」**（！）——這樁案件是「**兩個歐洲移民在美國郊區，給整個常識世界驗明出身**」（！）——**社會建構論的旗艦＋後現代思想的社會學源頭**（！）。

## 前因 -- 多因素的局勢

- **涂爾幹＋舒茲**：集體表象（！）＋現象學（！）——**兩條理論線的合流**（見 [1912-涂爾幹宗教生活的基本形式.md](1912-涂爾幹宗教生活的基本形式.md)）。
- **韋伯的理解社會學**：意義的建構（！）——**主觀的社會學**（！）。
- **馬克思的異化概念**：意識形態（！）——**「意識是社會的產物」**（！）。
- **美國實用主義**：米德（！）——**符號互動**（！）。
- **知識社會學**：舍勒＋曼海姆（！）——**知識的社會根源**（！）。

## 線索與推理 -- 因素咬合

### 線索一：外在化—客觀化—內化——「現實的施工流程」

伯格與盧克曼的循環（！）：

$$\text{外在化（人創造社會！）} \to \text{客觀化（社會變成「物」！）} \to \text{內化（人被社會塑造！）}$$

**「社會是人的產物；社會是客觀現實；人是社會的產物」**（！）——**三句話的循環**（！）——**制度化的三階段**（！）：

| 階段 | 例子 |
|------|------|
| 習慣化（habitualization！） | 「我們總是這樣做」 |
| 類型化（typification！） | 「丈夫」「妻子」「老師」 |
| 傳承（！） | 「下一代覺得理所當然」 |

**「第二代人不知道第一代人是怎麼開始的」**（！）——**制度一旦客觀化，就獲得「非人」的力量**（！）。

### 線索二：日常生活的現實——「常識的顯微鏡」

現象學的方法（！）：

- **日常生活是「最高現實」**（！）——**常識的獨斷性**（！）。
- **語言是「知識的儲存庫」**（！）——**符號創造現實**（！）。
- **合法化（legitimation！）**：**制度需要解釋為什麼合理**（！）——**從神話到理論的四層合法化**（！）。

$$\text{現實} = \text{（日常的建構！）} \times \text{（語言的合法化！）} \Rightarrow \text{（「理所當然」的世界！）}$$

### 線索三：身份認同的社會生產——「我是誰？」

人格的社會建構（！）：

- **身份是「社會分配的」**（！）。
- **「我是誰」由社會的鏡子回答**（！）——**與杜波依斯的雙重意識共振**（見 [1903-杜波依斯黑人的靈魂.md](1903-杜波依斯黑人的靈魂.md)）。
- **「對話是身份的工地」**（！）。

**自我不是心理事實，是社會成就**（！）——**比戈夫曼更根本**（！）。

## 破案時刻

- 1954：伯格與盧克曼在新學院（！）——同窗（！）。
- 1963：伯格《天堂的預感》（invitation to sociology！）（！）。
- 1966：《現實的社會建構》（！）。
- 1967：伯格《神聖的帷幕》（！）——**宗教社會學的建構論**（！）。

- 1970s：建構論進入科學社會學（！SSK！）＋性別研究（！）。

## 後果 -- 改變了什麼

- **知識社會學**：常識的研究正當化（！）——**社會學的擴展**（！）。
- **科學社會學**：SSK（！）——**科學知識的社會建構**（！）。
- **性別研究**：West 與 Zimmerman「做性別」（！）——**「性別是社會建構」的理論依據**（！）。
- **醫療社會學＋宗教社會學**：疾病！神聖！（）——**各領域的建構轉向**（！）。

```

外在化→客觀化→內化 ──→ 制度化 ──→ 「理所當然」的生產（→常識批判！）

建構論 ──→ SSK＋科學社會學 ──→ 後現代思想的社會學源頭
```

**偵探結語**：伯格與盧克曼的案件是「**把整個常識世界當作一樁尚未結案的施工工程**」：他們的偉大（！）是——**證明「現實」有出生證明**——**每一件「理所當然」的事（！性別！階級！宗教！道德！），都曾經是某一代人的發明**（！）——**「你以為你發現了世界，其實你被世界安裝」**（！）——**這是社會學最徹底的祛魅**（！）。最深的諷刺：兩位寫盡建構的人（！）——**一個（伯格）晚年回到宗教，一個（盧克曼）從未離開**——**他們證明了建構，卻沒有否定意義**（！）——**這是社會學的溫柔之處：它拆掉牆，是為了讓你知道牆可以再砌**（！）。而今天（！）——**「性別是流動的」、「國族是發明的」、「金錢是集體的想像」**——**每一句「XX 是社會建構」都是 1966 年那本書的迴聲**（！）——**建構論的問題從來不是「它是不是建構的」，而是「誰在建構、誰在受益」**（！）。
