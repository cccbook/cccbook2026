# 1951-帕森斯社會系統：給整個社會學畫一張總設計圖

## 案件摘要

1951 年，塔爾科特·帕森斯（Parsons！哈佛！）出版《社會系統》（The Social System！）——**將 1937《社會行動的結構》的「意志論行動理論」發展成完整的「結構功能論」**（！）——核心：**社會系統是一個「模式化互動」的秩序**（！）——**模式變項（pattern variables！）**＋**AGIL 功能系統**（adaptation! goal attainment! integration! latency!）——**制度化（institutionalization！）**：價值內化為人格與角色（！）——**這是社會學史上最宏大的綜合嘗試**（！）——**歐陸（韋伯、涂爾幹、帕累托、馬歇爾）＋美國（實用主義、精神分析）的熔爐**——這樁案件是「**一個哈佛工程師型學者，想替整個人類社會畫一張總設計圖**」（！）——**戰後美國社會學的霸權與爭議的源頭**（！）。

## 前因 -- 多因素的局勢

- **戰後美國的自信**：經濟霸權（！）＋社會學的學科膨脹（！）——**「美國生活方式」的理論需求**（！）。
- **《社會行動的結構》（1937！）**：歐洲四位大師的綜合（！）——**理論的先期工程**（！）。
- **哈佛社會關係系**：1946 成立（！）——**社會學＋心理＋人類的合併實驗**（！）。
- **韋伯與涂爾幹的翻譯工程**：帕森斯是推手（！）——**德法理論的英語化**（！）。
- **冷戰意識形態**：西方的「成功模式」需要理論護航（！）——**現代化理論的溫床**（！）。

## 線索與推理 -- 因素咬合

### 線索一：模式變項——「行動者的選擇菜單」

五組二分（！）：

| 變項 | 兩端 |
|------|------|
| 普遍主義 vs 個殊主義 | 規則 vs 特殊關係 |
| 成就 vs 先賦 | 表現 vs 出身 |
| 情感中立 vs 情感 | 冷靜 vs 投入 |
| 專門性 vs 擴散性 | 限定 vs 全面 |
| 自我取向 vs 集體取向 | 個人 vs 團體 |

**醫生與病人的角色**（！）：專門性＋情感中立＋普遍主義＋成就＋集體取向（！）——**角色是系統的螺絲釘**（！）。

### 線索二：AGIL——「社會的四台引擎」

帕森斯的總體框架（！）：

| 功能 | 系統 | 對應制度 |
|------|------|----------|
| A 適應（adaptation！） | 經濟系統 | 市場、生產 |
| G 目標達成（goal attainment！） | 政治系統 | 政府、權力 |
| I 整合（integration！） | 社會共同體 | 法律、規範 |
| L 潛在維持（latency！） | 文化系統 | 家庭、宗教、教育 |

$$\text{社會系統} = \text{（A！）} + \text{（G！）} + \text{（I！）} + \text{（L！）}$$

**系統的功能要求決定結構**（！）——**這是「工程學的社會學」**（！）——**同一套框架還應用於人格系統、文化系統、行為有機體（AGIL 的四次方！）**（！）。

### 線索三：秩序問題的重新回答——「涂爾幹＋弗洛伊德」

帕森斯的秩序理論（！）：

$$\text{秩序} = \text{（規範內化（涂爾幹！））} + \text{（超我（弗洛伊德！））} \Rightarrow \text{制度化}$$

**價值經由社會化內化為人格**（！）——**犯罪是「社會化的失敗」**（！）——**反對霍布斯式的強制（！）**——**帕森斯是「涂爾幹主義者＋韋伯主義者」的美國版**（！）。

## 破案時刻

- 1902：生於科羅拉多（！）。
- 1927：哈佛經濟學講師（！）。
- 1937：《社會行動的結構》（！）。
- 1942：〈麥卡錫時代〉（！）——先知式的警告（！）。
- 1946：哈佛社會關係系（！）。
- 1951：《社會系統》＋〈工作日〉（！）。
- 1953：《經濟與社會》（與斯梅爾瑟！）。
- 1970s：結構功能論的「死亡」（！）——**理論的退潮**（！）。
- 1979：死（！）——臨終前仍在寫作（！）。

## 後果 -- 改變了什麼

- **結構功能論的霸權**：默頓（！）＋斯梅爾瑟（！）——**戰後社會學的主流**（！）。
- **現代化理論**：Rostow！（！）——**發展研究的理論基礎**（！）。
- **六○年代的反叛**：衝突論（！達倫多夫！）＋互動論（！布魯默！）＋批判理論（！）——**「反帕森斯」成為一代人的旗幟**（！）。
- **理論綜合的教訓**：宏大系統的失敗（！）——**社會學轉向「中程」與「批判」**（！）。

**偵探結語**：帕森斯的案件是「**一個想把宇宙裝進四個格子的哈佛學者**」：《社會系統》的野心（！）是——**用 AGIL 四個功能，解釋一切社會**（！）——**醫院、家庭、公司、教會、國家**（！）——**這是社會學的「萬有理論」嘗試**。最深的諷刺：他寫作最抽象的理論，卻在 1942 年寫出了對麥卡錫主義最精準的預言（！）——**理論的高度與政治的敏銳，在帕森斯身上是同一種能力**（！）——但六○年代的反叛（！）證明：**系統論解釋了社會如何運作，卻解釋不了社會為何要革命**（！）——**功能論的沉默，成為六○年代的燃料**。而今天（！）——**當我們討論「系統整合」、「制度功能」、「社會治理」**——**每一個詞都是 1951 年的迴聲**（！）——**帕森斯輸掉了六○年代，卻贏回了所有後來試圖綜合的人**（！）。
