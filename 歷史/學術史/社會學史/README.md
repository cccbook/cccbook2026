前因是什麼？線索在哪裡？推理如何展開？後果又如何改寫了「何為社會」？

本卷的核心命題只有一句話：**社會學史是「社會的自我發現史」。**
每一樁案件都是一次「社會照鏡子」的革命：烏托邦（社會可以設計！）、契約（社會如何組成！）、法的精神（社會有結構！）、不平等（社會有病灶！）、分工（社會是實在！）、貨幣與城市（現代性登場！）、方法（怎麼研究社會！）、系統（社會如何整合！）、互動（社會在臉上！）、風險與演算法（社會進入行星規模！）。
看的方法變了，「社會」的定義就重寫了。每個重大轉折都是一樁「多因懸案」：偵探的工作，就是把因素鏈一環一環還原出來。

## 鏡子的回饋迴路

```
              ┌────（時代病：革命—工業化—都市化—戰爭—危機）────┐
              ↓                                          ↓
   病灶 ──→ 診斷 ──→ 設計烏托邦 ──→ 科學化 ──→ 專業化 ──→ 反思
    │                  ↑        ↑                     │
    │                  │        │                     ↓
    └──→ 意識形態之戰 ←── 學院 ←── 教科書 ──→ 公共社會學
              ↑                            ↑
              └── 冷戰—市場化 ←──（經費與政治）┘

   正向迴路（加速）：方法→證據→學系→期刊→更多研究
   正向迴路（加速）：危機→理論→再解釋歷史
   負向迴路（抑制）：意識形態審查→延遲診斷（法蘭克福流亡！）
   社會學迴路（本卷特有）：病灶→命名→方法→系統→互動→風險→病灶

**偵探的訣竅**：找到「誰診斷、誰命名、誰立方法、誰照鏡子」，把鏈條畫出來；再問一句——**這面鏡子把「社會」照成了什麼（機器？有機體？舞台？戰場？風險？）？**案件的因果鏈就浮現了。

- 1755：盧梭《論人類不平等的起源》——私有制是病灶；進步的辯證；社會批判的原型。［[1755-盧梭論不平等.md](1755-盧梭論不平等.md)］

## 偵探的結案陳詞

五百多年的社會學史，可以壓縮成三條因果鏈：

1. **鏡子鏈**：設計（社會可以更好！）→ 契約（社會如何可能！）→ 結構（社會有網！）→ 病灶（社會會病！）→ 實證（社會可測！）→ 系統（社會會整合！）→ 互動（社會在臉上！）→ 風險（社會在全球化！）——**每一面新鏡子，重照一次社會**。
2. **人物鏈**：空想家（莫爾！）→ 契約家（霍布斯！）→ 比較者（孟德斯鳩！）→ 命名者（孔德！）→ 立法者（涂爾幹！）→ 解剖者（韋伯馬克思！）→ 田野者（帕克恩格斯！）→ 反思者（米爾斯布迪厄！）——**先設計，再診斷，再立方法，再回頭看自己**。
3. **政治鏈**：革命（法國！工業！俄國！）→ 意識形態之戰（馬克思 vs 韋伯！）→ 冷戰經費（拉扎斯菲爾德！帕森斯！）→ 五月風暴與反叛（米爾斯！）→ 新自由與風險（貝克皮凱提！）——**教科書底下是政治**。

三條鏈咬合在一起，就是本卷四十一樁案件的全部真相。
