# 人類學史 -- AI 偵探風格

以「推理探案」的方式，追查人類學的重大轉折：瓦利亞多利德辯論、林奈命名、布魯門巴赫五大族、泰勒摩爾根、博厄斯、托雷斯海峽、馬林諾夫斯基、米德、本尼迪克特、努爾人、列維-斯特勞斯、駱駝項目、薩林斯、格爾茨、東方主義、沃爾夫、斯科特、寫作文化、全球流、債務、人類世、數位田野——
前因是什麼？線索在哪裡？推理如何展開？後果又如何改寫了「何為人類」？

本卷的核心命題只有一句話：**人類學史是「他者的發明史與平反史」。**
每一樁案件都是一次「看陌生人的方法」的革命：辯論（他是人嗎？）、分類（他排在哪？）、進化（他在哪一站？）、田野（他怎麼生活？）、結構（他怎麼思考？）、權力（誰在看他？）、反思（我是誰？）。看的方法變了，人類的定義就重寫了。每個重大轉折都是一樁「多因懸案」：偵探的工作，就是把因素鏈一環一環還原出來。

（涵蓋：瓦利亞多利德、林奈、布魯門巴赫、泰勒、摩爾根、博厄斯、托雷斯海峽、馬林諾夫斯基、米德、本尼迪克特、努爾人、列維-斯特勞斯、駱駝項目、薩林斯、格爾茨、薩義德、沃爾夫、斯科特、寫作文化、阿帕杜萊、格雷伯、人類世、數位民族誌）

## 人類學的看人革命：八種目光如何改寫人類

| 目光 | 機制 | 經典案例 |
|------|---------------------|----------|
| **辯論** | 他是人嗎？法律與良心對質 | 拉斯卡薩斯 vs 塞普爾維達 |
| **分類** | 林奈式格子，人也是物種 | Homo sapiens；五大族 |
| **進化** | 殘存—比較—單線階梯 | 泰勒；摩爾根蒙昧野蠻文明 |
| **田野** | 參與觀察住進去學語言 | 馬林諾夫斯基帳篷；托雷斯海峽 |
| **文化** | 相對論：每種文化自成標準 | 博厄斯；米德；本尼迪克特 |
| **結構** | 深層心智與交換邏輯 | 親屬基本結構；生食熟食 |
| **權力** | 誰在看他？誰付錢？誰書寫？ | 駱駝項目；東方主義；寫作文化 |
| **數位** | 演算法、平台與多物種田野 | 人類世；臉書民族誌 |

## 目光的回饋迴路

```
              ┌────（偶然相遇：船難—傳教—殖民—軍方）────┐
              ↓                                          ↓
   他者 ──→ 遇見 ──→ 傳教士—旅人 ──→ 學院 ──→ 田野法 ──→ 新他者
    │                  ↑        ↑                     │
    │                  │        │                     ↓
    └──→ 殖民—帝國 ←── 博物館 ←── 教科書 ──→ 反思倫理
              ↑                            ↑
              └── 戰爭—冷戰 ←──（應用與罪責）┘

   正向迴路（加速）：田野→民族誌→系所→經費→更多田野
   正向迴路（加速）：理論→再讀舊材料→重寫歷史
   負向迴路（抑制）：種族科學霸權→延遲平反（博厄斯對決）
   人類學迴路（本卷特有）：遇見→分類→田野→權力→反思→遇見
```

**偵探的訣竅**：找到「誰遇見、誰分類、誰下田野、誰反思」，把鏈條畫出來；再問一句——**這種目光把「他」看成了什麼（野人？兄弟？系統？受害者？）？**案件的因果鏈就浮現了。

## 案件卷宗（歷史年表）

### 一、遇見他者：辯論與分類（1550–1795）

- 1550：瓦利亞多利德大辯論——拉斯卡薩斯 vs 塞普爾維達；印地安人是不是人；帝國的良心審判。［[1550-瓦利亞多利德大辯論.md](1550-瓦利亞多利德大辯論.md)］
- 1735：林奈《自然系統》——Homo sapiens 命名；人進入生物格子；四膚色亞種的後遺症。［[1735-林奈與智人命名.md](1735-林奈與智人命名.md)］
- 1795：布魯門巴赫五大族——頭骨測量開端；高加索人種命名；科學種族主義的雙面基因。［[1795-布魯門巴赫與五大族.md](1795-布魯門巴赫與五大族.md)］

### 二、進化論人類學：階梯與殘存（1861–1898）

- 1861：巴霍芬《母權論》——母系先於父系；摩爾根易洛魁作證；家族史誕生。［[1861-巴霍芬母權論.md](1861-巴霍芬母權論.md)］
- 1871：泰勒《原始文化》＋摩爾根——殘存法；單線進化；人類學學科化。［[1871-泰勒與摩爾根進化論.md](1871-泰勒與摩爾根進化論.md)］
- 1883：博厄斯巴芬島——地理學家下北極；文化相對論萌芽；美國人類學之父起點。［[1883-博厄斯巴芬島.md](1883-博厄斯巴芬島.md)］
- 1898：劍橋托雷斯海峽探險——第一支專業田野隊；儀器＋語言＋長住；田野訓練誕生。［[1898-托雷斯海峽探險.md](1898-托雷斯海峽探險.md)］

### 三、田野革命：博厄斯學派與功能論（1911–1949）

- 1911：博厄斯《原始人的心智》——頭型可塑實驗；種族＝政治迷思；移民委員會翻案。［[1911-博厄斯反種族主義.md](1911-博厄斯反種族主義.md)］
- 1922：馬林諾夫斯基《西太平洋上的航海者》——庫拉圈；參與觀察宣言；帳篷裡的孤獨（日記之謎）。［[1922-馬林諾夫斯基與參與觀察.md](1922-馬林諾夫斯基與參與觀察.md)］
- 1928：米德《薩摩亞人的成年》——青春期是文化問題；弗里曼三十年後反撲；先天後天大案。［[1928-米德薩摩亞.md](1928-米德薩摩亞.md)］
- 1934：本尼迪克特《文化模式》——祖尼多布誇瓦壽限；文化是放大的性格；國民性研究延伸。［[1934-本尼迪克特文化模式.md](1934-本尼迪克特文化模式.md)］
- 1940：埃文斯-普里查德《努爾人》——無國家的秩序；血償與牛；非洲政治制度會議。［[1940-努爾人與非洲政治制度.md](1940-努爾人與非洲政治制度.md)］
- 1949：列維-斯特勞斯《親屬的基本結構》——交換女人；亂倫禁忌是文化起點；結構主義登場。［[1949-親屬的基本結構.md](1949-親屬的基本結構.md)］

### 四、理論風暴：結構、冷戰與經濟（1962–1978）

- 1962：列維-斯特勞斯《野性的思維》——圖騰分類即心智；生食熟食神話素；薩特的對決。［[1962-野性的思維與結構主義.md](1962-野性的思維與結構主義.md)］

- 1973：格爾茨《文化的詮釋》——濃描；巴厘鬥雞；文化不是力量而是脈絡。［[1973-格爾茨文化的詮釋.md](1973-格爾茨文化的詮釋.md)］
- 1978：薩義德《東方主義》——東方是發明；人類學的鏡子；後殖民轉向前奏。［[1978-薩義德東方主義.md](1978-薩義德東方主義.md)］

### 五、反思轉向：世界體系與書寫（1982–1996）

- 1982：沃爾夫《歐洲與沒有歷史的人民》——沒有孤立部落；資本主義製造了「原始」；政治經濟學轉向。［[1982-沃爾夫與沒有歷史的人民.md](1982-沃爾夫與沒有歷史的人民.md)］

## 偵探的結案陳詞

四百七十多年的人類學史，可以壓縮成三條因果鏈：

1. **目光鏈**：辯論（他是人？）→ 分類（他排哪？）→ 進化（他在哪站？）→ 田野（他怎麼活？）→ 結構（他怎麼想？）→ 權力（誰在看？）→ 反思（我是誰？）——**每一種新目光，重寫一次人類**。
2. **人物鏈**：傳教士（拉斯卡薩斯！）→ 分類學家（林奈！）→ 搖椅學者（泰勒！）→ 田野者（馬林諾夫斯基！）→ 反思者（寫作文化！）——**先遇見，再分類，再住進去，再回頭看自己**。
3. **政治鏈**：帝國（辯論為殖民服務！）→ 科學種族主義（五大族！）→ 冷戰（駱駝項目！）→ 後殖民（東方主義！）→ 倫理守則與返還——**帳篷底下是政治**。

三條鏈咬合在一起，就是本卷二十三樁案件的全部真相。
