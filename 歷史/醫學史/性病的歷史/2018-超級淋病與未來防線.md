## 2018 - 超級淋病與未來防線（當抗生素的賽跑輸給細菌的演化，我們還剩什麼牌）

## 案件摘要

**本案的兇手是一個演化速度驚人的細菌，而人類手中的武器正在一支支折斷。**

2018 年 3 月，英國公共衛生部（Public Health England）通報全球首例**無法治癒的「超級淋病」**：一名英國男性在東南亞旅遊時感染淋病，對一線藥物 azithromycin 與二線 ceftriaxone **同時呈抗藥性**，最終靠靜脈注射 ertapenem（碳青黴烯類，通常保留給最後手段）才治好。這不是孤例，而是 80 年軍備競賽的終點預告：淋球菌自 1930 年代以來，**對每一種投入臨床的抗生素都演化出抗藥性**——磺胺、青黴素、四環素、macrolides、fluoroquinolones、頭孢菌素，無一倖免。2017 年 WHO 把淋球菌列入「高優先病原體」名單，明言「淋病或將無藥可醫」。本案追查的是：一場抗生素與演化論的賽跑，以及賽跑終點之外的新防線。

## 前因 -- 為什麼會有這個案子

- **淋病是抗生素的鏡像**：它不是病毒，沒有疫苗（至今無正式上市者）、無長期免疫（感染後可重複感染），唯一的武器就是抗生素——而它偏偏是**基因水平轉移（HGT）能力最強**的人類病原體之一。
- **80 年的抗藥編年史**：

| 年代 | 藥物 | 抗藥性出現 | 機制 |
|---|---|---|---|
| 1930s | 磺胺類 | 1940s 初 | 靶點基因突變（DHPS） |
| 1943 | 青黴素 | 1950s–70s | β-lactamase 質體 + penA 突變 |
| 1950s | 四環素 | 1980s | tetM 質體水平轉移 |
| 1980s | fluoroquinolones | 1990s–2000s | gyrA / parC 突變累積 |
| 2007 | CDC 停用 fluoroquinolones | — | 抗藥率 > 15% |
| 2000s | 頭孢菌素（口服 cefixime） | 2010s | penA mosaic 基因 |
| 2010s | ceftriaxone + azithromycin（雙藥） | 2018 英國首例雙抗藥 | penA + 23S rRNA 突變 |

- **咽喉是抗藥性的孵化器**：咽部同時存在多種 Neisseria（包括腦膜炎雙球菌與口腔共生菌），淋球菌在這裡**與其他細菌交換基因盒**、且藥物濃度低——是突變與重組的溫床。WHO 2017 年警告：咽部感染多無症狀、難根除，是抗藥性菌株的儲存庫。
- **疫情的規模**：WHO 估計全球每年新增淋病約 8,200 萬例（2016 年數據），是最常見的細菌性性病之一；美國 CDC 年報告病例自 2009 年以來持續攀升，2018 年突破 58 萬例。

## 線索與推理 -- 數學式、程式、理論

**線索一：抗藥性的選擇壓力方程。** 經典的單間宿主—單藥模型（Crow & Kimura、Blower 等）：

$$ \frac{dR}{dt} = \beta (1 - \epsilon) \, \frac{S\,R}{N} + \mu \beta \frac{S\,I}{N} - \gamma R $$

其中 $R$ 為抗藥株、$I$ 為野生株、$\epsilon$ 為治療覆蓋率、$\mu$ 為突變率、$\gamma$ 為清除率。**當治療覆蓋率高、劑量不足或療程中斷時，$R$ 相對於 $I$ 的增長率上升**——治療本身就是選擇壓力。

**線索二：水平基因轉移使抗藥性「跳躍」而非「爬行」。**

```python
# 淋球菌抗藥性的兩條演化路徑
# 路徑 A：點突變累積（緩慢、可預測）——如 gyrA/parC 對 fluoroquinolone
p_single_mutation = 1e-8   # 每次複製每個鹼基
# 路徑 B：水平基因轉移（HGT）——如 penA mosaic 基因從口腔共生菌跳入淋球菌
# mosaic 基因是「整段重寫」，不是一個一個突變疊加 → 跨越式抗藥

def time_to_resistance(path, n_steps):
    if path == "point_mutation":
        return n_steps * 1e8      # 每步需 ~1e8 複製世代
    if path == "HGT_mosaic":
        return "一次轉化 + 重組 → 一步到位"

# 淋球菌自然轉化能力極強（有 pili、有 competence）
# 這就是為什麼 80 年內它可以對每一種新藥「重新開機」
print(time_to_resistance("HGT_mosaic", None))
```

淋球菌可以從環境游離 DNA 直接攝取並整合基因（自然勝任能力），這讓它不像其他細菌那樣需要「慢慢突變」——它可以直接**借別人的抗藥基因**用。

**線索三：意外的疫苗線索。** 2017 年，《Lancet》發表紐西蘭的回溯性病例對照研究（Petousis-Harris 等）：2004–2008 年間接種過**外膜囊腫（OMV）腦膜炎雙球菌疫苗 MeNZB** 的青少年，日後感染淋病的風險**下降 31%**（校正後 OR 0.69）。機制推測：腦膜炎雙球菌與淋球菌是同屬近親，**外膜蛋白（如 PorA、Factor H binding protein）共享表位**，引發交叉免疫。這是史上第一支對淋病顯示保護力的疫苗線索——而且是**從防疫腦膜炎的意外副作用中撿到的**。

**線索四：檢測與追蹤的新工具。** 2010 年代末，快篩（包括居家 self-test）、PCR 面板同時偵測淋球菌+披衣菌+滴蟲，以及匿名伴侶通知 App（如 2018 年推出的 TellYourPartner、CDC 支援的 partner notification 系統）使接觸者追蹤繞過羞恥感；Grindr/Tinder 時代的數位流行病學則用匿名化網路資料預測傳播熱點。

**線索五：為什麼淋病沒有疫苗——免疫學的解釋。** 淋球菌有兩套絕活：**抗原變異**（pilE 基因的家族重組使其菌毛抗原幾乎無限變化，感染一次不產生對下次的免疫）與**表象掩護**（sialylation 使外膜看似宿主細胞、並招募補體抑制因子 Factor H）。這使傳統「滅毒—記憶免疫」路線失效。這也是為什麼 MeNZB 的 OMV 路線（不含易變抗原、針對保守外膜蛋白）特別有價值——它瞄準的是細菌「捨不得變」的部分。

**線索六：貧窮與抗藥性的地理學。** 抗藥菌株的擴散路徑高度對應**旅行與性觀光**路線：東南亞（泰國、菲律賓）、東亞（日本 FC428 克隆）→ 歐洲 → 美洲。WHO 西太平洋區域長期是 ceftriaxone 敏感性下降的震央。而資源有限地區的診斷常缺乏培養與藥敏試驗（只用症狀治療）——**看不見抗藥性，不等於抗藥性不在**；這正是 WHO 推動 Gonococcal Antimicrobial Surveillance Programme（GASP）全球化的原因。

## 結案 -- 後果與影響

- **治療指引的節節後退**：CDC 2010 年停用 cefixime 口服單藥，2012 年建議 ceftriaxone+azithromycin 雙藥，2020 年因 azithromycin 抗藥性又改回 **ceftriaxone 單藥高劑量（500 mg）**。每一輪修改都是在為「最後一道防線」延長壽命——碳青黴烯類已是僅存的備胎。
- **雙抗藥個案的意義**：2018 英國首例後，澳洲、法國、日本也陸續通報對 ceftriaxone 敏感性下降的菌株（FC428 克隆）。若 ceftriaxone 失效，常規門診將**失去門診治療能力**——淋病可能重新變成「必須住院靜脈注射」的疾病。
- **疫苗研發的新熱潮**：MeNZB 的意外發現催生 4CMenB（Bexsero，含 OMV 成分）對淋病交叉保護的研究（後續研究顯示保護力約 30–40%）；NIH 與多國啟動專門的淋病疫苗計畫。**即使只有 40% 保護力，模型顯示也足以扭轉流行曲線**——因為淋病的 $ R_0 $ 高、世代時間短，疫苗阻斷的複利效應極大。
- **CRISPR 與潛伏庫**：對 HIV 側，基因編輯（CRISPR/Cas9、鹼基編輯）被研究用於攻擊病毒儲存庫或敲除 CCR5（見 `2009-柏林病人HIV根治.md`）；對淋病側，噬菌體療法與抗毒力策略（阻斷 pili/OPA 介導的黏附）在動物模型中嶄露頭角——「不殺菌，只解除它的武器」是後抗生素時代的新哲學。
- **2030 終結的賽跑**：UNAIDS 2030 年目標（90-90-90 達成後新增感染降至流行病學終結門檻）與 WHO 的性病消滅策略（STI 2030）都在倒數。淋病告訴我們：**當演化站在敵人那邊，任何單一武器都會失效**；真正的防線是「疫苗 + 快篩 + 數位追蹤 + 行為/生物醫學預防（`2012-Truvada PrEP.md`）+ 治療即預防（`2016-U=U共識宣言.md`）」的組合拳——不是一支神藥，而是一張網。
