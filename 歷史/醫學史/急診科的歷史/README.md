# 急診科的歷史：從戰場擔架、黃金一小時到檢傷數學與生存鏈

> 本書以「推理探案」的體例，為急診醫學（Emergency Medicine）史上的每個關鍵事件寫一篇 wiki：
> 謎題是什麼（黃金一小時從何而來？time is brain 的 4.5 小時怎麼算出來的？）？偵探是誰（Larrey、Safar、Cowley、NINDS 團隊）？線索與推理是什麼？
> 每篇檔名以年份開頭（4 位數，西元前以 `-` 開頭）。

| 線 | 演變 |
|---|---|

## 本書的三個核心理論（在多篇 wiki 反覆出現）

1. **黃金一小時（Golden Hour）**：重傷病患的預後由最初一小時的處置決定。其科學基礎是出血性休克的生理曲線（見 `1973-馬里蘭創傷系統與黃金一小時.md`）——死亡風險隨未控制時間呈指數上升。
2. **檢傷的數學（Triage）**：資源少於需求時，目標函數從「救每一個人」變成「極大化總存活數」（見 `1983-START檢傷與大批傷患.md`）。
3. **生存鏈與時間窗**：CPR、溶栓、門球、敗血症 bundle 的共同結構是——每個環節都有指數衰減的效益，延遲越多，救回越少（見 `1991-生存鏈與公共AED.md`、`1986-GISSI與心梗溶栓革命.md`）。
