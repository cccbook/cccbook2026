## 1912 - 庫欣創立神經外科（大腦——外科的最後禁區，被數據與器械打開）

## 案件摘要

- 時間：1912 年，美國波士頓，哈佛醫學院與 Peter Bent Brigham 醫院。
- 嫌疑對象：顱內——活人腦組織，一壓就壞、一血腫就死的外科禁區。
- 侦探：Harvey Cushing（1869–1939），Halsted 的嫡傳弟子。
- 兇器與裝備：血壓計、銀夾（silver clips）、電燒刀、腦壓管理技術，以及一套 2,000+ 病例的卡片檔案系統。
- 結局：三千餘例腦瘤手術、手術死亡率從約 50% 降到約 7%；神經外科從「偶爾有人敢開顱」變成有制度、有數據、有教科書的獨立專科。

## 前因 -- 為什麼會有這個案子

19 世紀末，開顱手術的三大死因：

1. **感染**——已被 Lister（`1865-李斯特石炭酸無菌革命.md`）與 Halsted（`1889-哈爾斯特德橡膠手套.md`）大致解決。
2. **定位失敗**——不知道腫瘤在哪裡，只能靠神經學症狀猜，開錯地方。
3. **出血與腦壓**——腦組織血管豐富、不容許積血；術中血壓驟降或顱內壓飆升都致命。

Cushing 1896 年自耶魯入 Hopkins 外科，在 Halsted 的住院醫師金字塔中受訓十年（Halsted 訓練以嚴酷漫長著稱）。1900–01 年他赴歐洲遊學：在伯恩向 Kocher 學習，並在 Pavia 见識 Scipione Riva-Rocci（1896）發明的袖帶血壓計。這趟旅程埋下兩顆種子：**術中血壓監測**與**顱內壓的系統研究**。

## 線索與推理 -- 數學式、程式、理論

**1. 血壓監測的推理**：Cushing 觀察到顱內壓升高時出現血壓上升、心跳變慢的代償反應——即後來的 **Cushing 反射**：

$$
\text{ICP} \uparrow \;\Rightarrow\; \text{腦灌注壓} = \text{MAP} - \text{ICP} \;\downarrow \;\Rightarrow\; \text{代償性} \; \text{MAP} \uparrow, \; \text{HR} \downarrow
$$

沒有血壓數據，這條救命曲線根本不可見。1901 年起他把 Riva-Rocci 血壓計引進美國手術室，麻醉監測從「摸脈搏、看臉色」升級為量化工程——麻醉學的誕生點之一。

**2. 腦瘤定位**：結合顱骨 X 光（1895 Röntgen）、神經學局灶症狀（運動皮質定位圖，Fritsch–Hitzig 1870）、以及術中電刺激——Cushing 把「猜腫瘤」變成「三角定位」：

```python
def localize_tumor(patient):
    evidence = {}
    evidence['神經學'] = patient.focal_deficits()      # 偏癱→對側運動皮質區
    evidence['X光'] = patient.skull_xray()            # 鈣化、蝶鞍擴大、顱壓指痕
    evidence['視野'] = patient.visual_field()          # 腦垂體瘤→雙顳側偏盲
    site = triangulate(evidence)                      # → 開顱骨窗位置
    intraop = electrical_stimulation(site)            # 術中皮質圖譜
    return site, intraop
```

**3. 術中監測與止血的器械鏈**：

| 年份 | 發明／技術 | 解決的問題 |
|---|---|---|
| 1901 | 術中血壓監測（Riva-Rocci 血壓計） | 麻醉與腦壓的即時量化 |
| 1904 | 生理鹽水灌注、腦壓管理 | 腦水腫與出血控制 |
| 1909– | 銀夾（silver clips）封閉血管 | 腦表面細小血管止血 |
| 1926 | Bovie 電燒刀（與物理學家 William Bovie 合作） | 高頻電流切割＋凝固，深部止血革命 |
| 1920s | 腦室造影（ventriculography，Dandy 1918 之改良應用） | 定位深部腫瘤 |

**4. 數據管理的「外科＝數據科學」**：Cushing 與長期助手 Regina Kelly 建立每例病人一張的標準化紀錄卡，累積 2,000+ 張顱內腫瘤檔案，附組織切片與手術繪圖。這是外科史上最早的專科病例登記庫之一，讓「死亡率 50%→7%」不是印象，而是可查表的結論。

## 結案 -- 後果與影響

1. **專科的誕生**：1912 年 Cushing 任 Harvard/Brigham 外科教授（Moseley Professor），1917 年一戰中在法國前線處理顱腦槍傷，累積戰傷外科經驗；1921 年創立神經外科學會的先聲、1932 年出版經典《Intracranial Tumors》。
2. **Cushing 病／症候群（1932）**：他描述腎上腺皮質功能亢進（垂體嗜鹼細胞腺瘤所致）的臨床像——滿月臉、向心性肥胖、高血壓——內分泌學與神經外科的跨界經典。
3. **死亡率曲線**：Cushing 抵達 Brigham 時腦瘤手術死亡率約 30–50%；其後期系列（1932 統計逾 2,000 例）降至約 7%——專科化與數據回饋的直接紅利。
4. **人才譜系**：Walter Dandy（腦室造影、腦積水手術）、Percival Bailey（腦瘤病理分類）、Wilder Penfield（蒙特婁神經學研究所）皆出其門下或受其影響。
5. **手術室的未來鋪路**：Bovie 電燒刀至今仍是手術室標配；術中血壓監測演化為現代麻醉監護——一路鋪向 `1953-吉本人工心肺機.md` 的體外循環時代。
