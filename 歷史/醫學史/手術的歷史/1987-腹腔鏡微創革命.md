## 1987 - 腹腔鏡微創革命（三個小孔，終結了「大切口大醫生」的百年信條）

## 案件摘要

1987 年 3 月，法國里昂的婦科醫師 Philippe Mouret 在為一位患者做腹腔鏡手術時，順手用腹腔鏡技術切除了她的膽囊——史上第一例腹腔鏡膽囊切除術，就這樣「順便」發生了，甚至沒有先聲張。這台手術起初被外科主流斥為旁門左道，卻在五年內席捲全球：膽囊切除術的住院天數從約 7 天縮到 1 天，90 % 以上的膽囊切除改由腹腔鏡完成。外科史上從來沒有一項技術以這種速度被患者「用腳投票」。

患者不懂什麼是凱氏三角，但他們懂什麼是少挨一刀、少痛三天、週一開刀週五上班。

## 前因 -- 為什麼會有這個案子

腹腔鏡膽囊切除不是靈光一閃，而是三條技術線的匯流：

1. **診斷性腹腔鏡（1901–1930s）**：1901 年德國 Kelling 以膀胱鏡觀察狗的腹腔，1910 年瑞典 Jacobaeus 首度用於人體。此後半世紀，腹腔鏡主要是婦科與內科的診斷工具，因為一個致命限制：**影像昏暗、視野極小**。
2. **冷光源與柱狀透鏡（1950s–60s）**：倫敦的物理學家 Harold Hopkins 發明光纖導光束（冷光源，讓光「送進去」而不在路徑上發熱）與柱狀透鏡系統（rod-lens endoscope，空氣間隙從透鏡間消失，透光量與解析度提升數十倍）。1960 年代由 Storz 量產。沒有 Hopkins，腹腔裡永遠是一團模糊的黃光。
3. **電視影像（1980s）**：CCD 攝影機小型化後接上內視鏡，手術影像從「只有主刀一人貼著目鏡看」變成「整個團隊盯著螢幕看」。這看似小事，實則是手術社會學的顛覆：助手第一次真正能幫上忙，教學第一次可以看著螢幕進行。

Mouret 本來就是婦科腹腔鏡高手。1987 年 3 月那台手術，他先做婦科操作，再以膽囊切除術的標準完成膽囊剝離。影片傳開後，巴黎的 Dubois、波爾多的 Périssat 迅速跟進並發表，1988 年美國的 McKernan 與 Saye 以雷射技術推廣，1989 年起美國外科界從抗拒（「這是瘋子的手術」）轉為搶購（不會腹腔鏡就丟掉膽囊手術的病人）。

## 線索與推理 -- 數學式、程式、理論

**微創背後的理論：手術創傷的「劑量—反應」關係。** 切口與撐開器不只是通路的代價，它們本身就是應激源。外科應激反應大致與組織損傷量成比例：

$$
S \;\propto\; k_1 A_{\text{切口}} + k_2 V_{\text{組織操作}} + k_3 t_{\text{麻醉}}
$$

其中 $S$ 為全身應激反應（CRP、皮質醇、IL-6 上升），$A$ 為切開的面積。腹腔鏡把 $A$ 從數十平方公分壓到數平方公分，應激曲線隨之塌陷——這就是術後疼痛輕、腸麻痺短、下床早的機制。可量化為：

| 指標 | 傳統開腹膽囊切除 | 腹腔鏡膽囊切除 |
|---|---|---|
| 切口 | 右肋下 10–15 cm | 3–4 個孔（0.5–1 cm） |
| 住院天數 | ~7 天 | ~1 天 |
| 恢复正常活動 | 4–6 週 | 7–10 天 |
| 膽管損傷率（早期） | ~0.1–0.2 % | 學習曲線期一度 >0.5 % |

```python
def 術後恢復天數(切口面積_cm2, 術中出血_ml):
    # 簡化模型：恢復期主要隨切口面積增長
    return round(3 + 0.3 * 切口面積_cm2 + 0.002 * 術中出血_ml, 1)

print(術後恢復天數(切口面積_cm2=150, 術中出血_ml=200))  # ~49 天量級（開腹）
print(術後恢復天數(切口面積_cm2=3,   術中出血_ml=50))    # ~4 天量級（腹腔鏡）
```

**視覺取代觸覺的代價。** 外科醫師的手是高解析度觸覺感測器；腹腔鏡手術中，觸診歸零，醫師只能靠 2D 影像重建 3D 空間。資訊論的觀點：

$$
\text{手部觸覺頻寬} \gg \text{2D 螢幕視覺頻寬}
$$

這個「感測器降級」解釋了為何膽管損傷率在革命初期不降反升，也解釋了為何外科需要下一個進化：3D 立體視野與腕狀器械（見 `2000-達文西機器人手臂.md`）。

**革命的路徑依賴**可用 mermaid 呈現：


## 結案 -- 後果與影響

- **外科訓練體系重寫**。1990 年代初，一代開腹外科醫師被迫「重當住院醫師」學習螢幕手術；模擬器與訓練課程（如後來的 FLS 認證）應運而生。
- **流行病學的即時檢驗**：膽囊切除總量在腹腔鏡普及後不減反增——門檻降低，適應症放寬，這是所有微創技術的共同宿命。
- **醫院經濟學重算**：住院天數縮短使床位周轉加快，微創器械成本上升由住院費節省抵銷，微創從此成為醫院行銷標語。
- **後續演化**：1990s 末 NOTES（經口、經陰道等自然孔道手術，2000 年代 Apollo 小組首例）與單孔腹腔鏡相繼出現，但因器械張力與縫合困難未成主流，反而把需求導向機器人系統。
- **尚未解決的問題**：CO₂ 氣腹的生理干擾（高碳酸血症、靜脈回流下降）、2D 深度感喪失、觸覺回饋歸零——每一步微創，都是用某一種代價換另一種收益。
