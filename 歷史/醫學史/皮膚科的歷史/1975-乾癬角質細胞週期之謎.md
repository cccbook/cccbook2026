## 1975 - 乾癬角質細胞週期之謎（表皮快轉三倍的測量）

## 案件摘要

**乾癬的斑塊裡藏著一個計時器的故障，1970 年代，有人終於把錶拆開看了。**

1975 年前後，Weinstein 與 Van Scott 以放射線標記（${}^3$H-胸腺嘧啶）測量乾癬表皮的細胞動力學，發現驚人數字：正常角質細胞從基底層到脫落約需 **26 天**，乾癬皮損裡卻只要 **3–4 天**——表皮快轉約八倍。角質細胞來不及成熟就被推上表面，於是核沒消失（角化不全）、角質層鬆散成銀屑、血管增生供應失控的增殖。乾癬第一次有了定量病理：「增殖失控病」。

## 前因 -- 為什麼會有這個案子

- **形態學的天花板**：自 Hebra（1841 分家，`1841-乾癬與癬的分家.md`）以來，乾癬的形態描述已臻完備，但「表皮為何這樣長」沒有數字。
- **細胞動力學工具就位**：1950s-60s，放射標記胸腺嘧啶摻入分裂期 DNA 的技術使「測量細胞週期」成為可能（先用於腫瘤，如結腸隱窩）。
- **乾癬的臨床悖論**：有的治療（蒽林、焦油＋光）有效但機制不明；「表皮增殖」假說已有組織學旁證（棘層增厚、有絲分裂像增多）——只欠定量。
- **Grenz 區與微血管**：皮損真皮乳頭迂曲擴張的微血管（Auspitz 徵出血的來源）暗示血管增生與增殖同步。

## 線索與推理 -- 數學式、程式、理論

表皮的穩態可用一條產出—脫落平衡式表示：

$$ \text{表皮厚度恆定}: \quad \underbrace{T_{\text{週期}}}_{\text{正常 } \approx 26 \text{ 天}} \times \underbrace{N_{\text{基底細胞}}}_{\text{增殖池}} = \text{恆定產出} $$

$$ \text{乾癬}: \quad T_{\text{週期}} \approx 3\text{–}4 \text{ 天} \;\wedge\; \text{增殖池擴大} \Rightarrow \text{產出暴增} \Rightarrow \text{銀屑堆積} $$

```python
def epidermal_turnover(cycle_days, shedding_days):
    if cycle_days < shedding_days:
        backlog = shedding_days / cycle_days
        return f"生產快於脫落 {backlog:.0f} 倍 → 角質層堆積=看得見的鱗屑"
    return "穩態"

print(epidermal_turnover(cycle_days=3.5, shedding_days=26))
```

本案最大的偵查轉折在二十年後：增殖失控被降級為**下游現象**。1980s–90s 發現皮損中 T 細胞浸潤、環孢素（一種免疫抑制劑）對乾癬驚人的療效（1986 報告），指向「免疫細胞分泌細胞激素驅動角質細胞增殖」；2004 年後 IL-23/IL-17 軸確立（`2014-生物製劑與乾癬免疫革命.md`）——Th17 細胞的訊號才是計時器被撥快的手。角質細胞是受害者兼共犯，不是主謀。

## 結案 -- 後果與影響

- **治療學的指針**：抗增殖藥（蒽林、維 A 酸、維生素 D3 衍生物 calcipotriene 1991、methotrexate）的設計目標從「去鱗屑」明確為「校正週期」。
- **從皮膚病到系統病**：增殖—炎症—血管軸的量化，為後來「乾癬是系統性炎症、合併代謝症候群與心血管風險」的認知鋪路。
- **模型辯證的教科書案例**：1975 的「表皮模型」與 2014 的「免疫模型」不是對錯替換，而是層級關係——本案示範了醫學理論如何「套娃式」修正。
- **一句話結案**：測量把比喻變成病理（「快轉的表皮」），而更深的測量又把病理變成症狀（「被撥快的計時器」）——乾癬的卷宗，每三十年就要重寫一次案情摘要。
