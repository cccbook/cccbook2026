# 皮膚科的歷史

**皮膚是身體最大的器官，也是最誠實的證人。** 內臟的秘密、免疫的戰況、環境的傷害，全都寫在這層不到 2 平方公尺的表面上。皮膚科史，就是一部「從表面讀出深處」的推理史：疹子是誰的筆跡？為什麼同樣的紅斑，有人說是體液失衡，有人說是免疫失調，有人說是 Th17 路徑的細胞激素風暴？本書以「推理探案」的方式，追蹤人類如何一層層剝開皮膚之謎——從紙草處方到體液論、從 Willan 的圖譜分類到生物製劑的細胞激素地圖。

## 主題線索

- **分類學線**：Willan → Bateman → Hebra → Virchow —— 皮膚病如何從「一片雜亂的紅斑」變成有名字、有邊界、有病理的實體。
- **病原體線**：Gruby → Sabouraud →（真菌）；痲瘋桿菌（1873 Hansen）→（細菌）——「癬是活的」的發現史。
- **免疫線**：Jadassohn 斑貼試驗 → Pirquet 變態反應 → 組織胺 → 類固醇 → Th1/Th17 生物製劑。
- **光線**：Finsen 光療 → 維生素 D → 雷射 → 紫外線致突變與黑色素瘤。
- **污名線**：癩病的鈴鐺（見姊妹書 `../性病的歷史/1350-麻風鈴鐺與罪惡身體.md`）到乾癬患者的就業歧視——皮膚病是「看得見的病」，因此也是被看得最重的病。
