## 1882 - 心靈研究學會（以科學方法調查通靈：懷疑論作為偵探）

## 案件摘要

1882 年 2 月 20 日，劍橋學者 Henry Sidgwick、Frederic Myers 等人在倫敦創立心靈研究學會（Society for Psychical Research, SPR），宗旨莊嚴得近乎天真：以科學方法調查「心靈現象」——通靈、靈媒、念力、瀕死異象。他們大多不是騙子也不是狂熱者，而是認真相信「若真有超自然，就該能被實驗證實」。結果調查了一百年，靈媒倒了一個又一個，學會卻意外催生了現代心理學的幾個分支，並訓練出史上最鋒利的一批「打假偵探」。本案追查：**認真的輕信，如何意外生產了嚴謹的懷疑論？**

## 前因 -- 為什麼會有這個案子

- **唯靈論的蔓延**：1848 年紐約 Fox 姊妹的「敲擊靈魂」事件引爆全球唯靈論熱潮，靈媒產業席捲歐美（見 [-0400-阿斯克勒庇俄斯神廟](-0400-阿斯克勒庇俄斯神廟.md)——還願碑經濟的維多利亞版）。
- **科學的危機感**：達爾文主義、熱力學擴張了科學版圖，也讓部分知識分子焦慮：靈魂、來世是否會被科學整個否決？SPR 想給靈魂「留一個實驗席位」。
- **修會工具的成熟**：統計學、心理生理學剛剛成型，使「調查靈異」首次具備方法論工具箱。
- **本案兇手**：**「魔術師的專業知識」是兇手**——最能拆穿靈媒的人不是科學家，而是懂手法（sleight of hand）的表演者。

## 線索與推理 -- 數學式、程式、理論

### Fox 姊妹事件的餘波（本案的直接前案）

1848 年紐約州，Fox 姊妹宣稱聽見「靈魂敲擊」，掀開唯靈論熱潮。四十年後（1888），妹妹 Margaret 公開示範敲擊是掰動腳趾關節所為——但產業早已不需要真實的靈媒。SPR 的創立者們正是看著這個「被自己人拆穿卻照樣繁榮」的市場，決定「至少要有一個有紀錄的調查機構」。Fox 事件的教訓被完整帶入本案：**證據的死亡無法殺死市場，只有制度化的查核可以壓縮它的空間。**

### SPR 的三大調查遺產

| 調查項目 | 代表人物 | 結果 |
|----------|----------|------|
| 靈媒查核 | Eleanor Sidgwick、後期 Houdini 協作網絡 | Palladino 等名靈媒被多次抓到造假 |
| 念寫（thoughtography） | 各分會 | 無一通過嚴格控制 |
| 心靈感應實驗（ganzfeld 之前身） | 卡劍橋統計調查 | 數據無法與「機率+選擇偏差」區分 |

### 統計與選擇偏差：SPR 意外成為偏差偵測學的先驅

SPR 學者在查核靈異證據時，系統性地發展了「替代解釋清單」——這份清單後來成為整個超心理學批評的方法論基礎：

$$ P(\text{命中} \mid \text{無靈異}) = P(\text{機率}） + P(\text{選擇性報告}） + P(\text{ sensory leakage}） + P(\text{紀錄缺陷}） $$

```python
def evaluate_psi_claim(result, controls):
    alternatives = {
        "chance":            controls.randomized,        # 隨機化是否確實
        "selective_report":  controls.pre_registered,    # 失敗案例是否有紀錄
        "sensory_leakage":   controls.blinded,           # 是否可能偷看
        "subject_fraud":     controls.magician_present,  # 有無魔術師在場
    }
    if all(alternatives.values()) and result.p < 0.001:
        return "值得進一步調查"   # SPR 一百年來幾乎沒送出過這個結論
    return "未通過替代解釋檢驗"
```

### William James 的參與：另一條支線

哈佛心理學家 William James 於 1890 年代加入 SPR（曾任主席），調查著名靈媒 Leonora Piper——他結論曖昧（「我認為有真實的通靈成分，但無法證明」），但他的參與有兩個重要後果：(1) 心理學正視「變異意識狀態」為研究對象（其《宗教經驗之種種》）；(2) 「確定性的謙遜」成為調查倫理：**既不輕信，也不輕否**。

### 魔術師戰爭（1920s）

Harry Houdini 加入調查陣線，親自喬裝混入降神會，抓出靈媒的舞台手法；他與柯南·道爾（SPR 名人、堅信唯靈論）的決裂是本案最具戲劇性的註腳——偵探小說的創造者，被真正的魔術師在真實案件中打臉。Houdini 的遺言式名言：與其燒掉靈媒，不如教會大眾「他們是怎麼騙的」。此精神直接延續到 James Randi 與 20 世紀的打假傳統（第 15 篇）。

## 結案 -- 後果與影響

- **超心理學的制度化與持續的零成果**：SPR 及其美國分會存在至今，百餘年間未產出一個經得起重複驗證的心靈現象——但它因此成為「負結果科學」的博物館。
- **心理學的意外收穫**：催眠研究、潛意識概念（Myers 的「subliminal self」）、變異意識研究——多條現代心理學支線是從靈異調查的廢墟中挖出的工具。
- **懷疑論作為偵探職業的確立**：SPR 建立了「調查者必須懂對方的騙術」的原則；魔術師+統計學家+心理學家的三人組合，預演了 20 世紀所有科學打假行動的方法配置。
- **方法論的清單化**：SPR 時代留下的「替代解釋清單」（機率、選擇偏差、感官洩漏、造假、紀錄缺陷）在今日仍有直接傳人——臨床試驗的預先登記制度、偏差風險評級工具，本質上是同一份清單的現代格式。**這份清單比 SPR 任何一個「陽性發現」都更有價值。**
- **治療敘事線的註記**：靈媒降神會本質上是「為哀傷者提供的儀式治療」——亡夫亡妻在靈界「報平安」的信息，是維多利亞時代的哀傷輔導。SPR 調查的是通靈的真偽，卻也順手記錄了「儀式性哀傷服務」的市場結構：訪客付費、關係持久化、服務客製化。今日的「寵物溝通師」「通靈諮詢 App」（第 16 篇）延續的正是這個市場，只是收款方式變成了訂閱制。

### SPR 保留至今的遺產清單

- **調查程序檔案**：數十年靈媒查核的原始紀錄，成為「如何（不）設計觀察研究」的教科書級負面教材；
- **統計先行**：SPR 早期成員促成「異常宣稱需先做統計替代解釋檢驗」的習慣——比 p 值革命早了半個世紀；
- **調查倫理**：Sidgwick 對自己調查失敗的公開承認，樹立「誠實的負結果」典範；
- **跨學科配置**：哲學家+物理學家+心理學家+魔術師的調查小組編制，成為日後所有科學委員會（包括 1784 型審查的現代版）的模板；
- **失敗的價值**：SPR 證明了一件事——**即使調查一百年都得到否定結果，這件事本身就是知識**：「心靈現象至今無一通過嚴格檢驗」是一個可以寫進教科書的事實。
- **與本書主軸的呼應**：本案證明治療敘事線與權力鬥爭線在 19 世紀末的交匯——靈媒產業販賣的是「與死者溝通的治療」（哀傷輔導的商業化），而科學界首次有組織地介入市場查核。
- **本案的內在張力（誠實記錄）**：SPR 並非純粹的打假機構——Sidgwick 終生盼望靈魂不滅被證實，臨終仍囑託同人在其死後以暗號驗證（他死後傳回的「暗號訊息」從未對上）。**調查者本人可能是信徒，這既是弱點也是動力**；對照第 15 篇 Emily Rosa（外行孩子、無利益糾葛），可以看清：查核者的獨立性，比查核者的聰明更決定結論的可信度。
