## 1487 - 女巫之錘（獵巫手冊與「醫學的性別清洗」假說）

## 案件摘要

1484 年 12 月，教宗 Innocent VIII 發出諭令（Summis desiderantes affectibus），承認德意志地區巫術橫行並授權多明我會士 Heinrich Kramer 與 Jakob Sprenger 追查。1487 年，Kramer 出版《女巫之錘》（Malleus Maleficarum）——一本從神學、法學到「臨床細節」俱全的獵巫手冊，教法官如何偵訊、如何逼供、如何認定女巫。此書隨印刷術流通全歐，成為此後兩百年獵巫的標準作業程序。本案是全書權力鬥爭線的核心：**為什麼獵巫的主要受害者是女性，其中又為何包括大量草藥師、助產士等民間治療者？**

## 前因 -- 為什麼會有這個案子

- **魔鬼學的完成**：15 世紀教會神學確立「巫術=與魔鬼締約」的框架（見 [0030-驅魔與早期基督教治癒](0030-驅魔與早期基督教治癒.md)），把從前的民間巫術從「犯傻」升級為「重罪」。
- **醫學的背書**：《女巫之錘》引用醫學權威討論「女性體液易受魔影響」——蓋倫醫學的性別理論為獵巫提供「科學」依據。
- **社會壓力**：黑死病後的社會創傷（[1350-鞭笞派與代罪羔羊](1350-鞭笞派與代罪羔羊.md)）、氣候惡化、經濟動盪，提供了恐慌燃料。
- **本案兇手**：**「醫學性別論+司法機器」是兇手**——缺一不可：只有神學沒有法學程序，獵巫無法規模化；只有司法沒有「女性易染魔」的醫學論述，受害者名單不會如此性別化。

## 線索與推理 -- 數學式、程式、理論

### 《女巫之錘》的三部結構

| 卷 | 內容 | 功能 |
|----|------|------|
| 卷一 | 駁斥「不相信巫術」的懷疑論 | 認知封鎖：否認巫術本身就是證據（魔鬼迷惑你） |
| 卷二 | 巫術的行為與危害，含墮胎、陽痿、殺嬰指控 | 把民間治療（避孕、助產、草藥）定義為巫術 |
| 卷三 | 司法程序：檢舉、偵訊、酷刑、驗巫針、水刑 | 執行手冊 |

注意卷二的指控清單：墮胎、調經、催情、止痛——**這正是傳統女性治療者的日常業務**。當這些業務被重新命名為「巫術」，治療者就成為嫌疑人。

### 「醫學的性別清洗」假說及其爭議

Ehrenreich 與 English 在《Witches, Midwives and Nurses》（1973）提出著名論點：獵巫是男性專業醫學（大學制、行會制）消滅女性民間醫療的歷史過程——女巫被燒，醫學被「清洗」成男性職業。此說的證據與爭議：

| 支持證據 | 反駁/修正 |
|----------|-----------|
| 指控清單與助產、草藥業務高度重疊 | 多數受害婦女並非治療者；鄰里糾紛、財產、性格才是常見導火線 |
| 醫學論述持續貶低女性行醫 | 教會法庭常「拆穿」巫術指控（奇蹟查核傳統，[1173-貝克特朝聖治癒](1173-貝克特朝聖治癒.md)），獵巫主力是世俗法庭 |
| 獵巫後專業醫學確實男性化 | 男巫也受審（占 20–25%），動機不能用性別單一解釋 |
| 部分地區助產士被要求舉報女巫 | 修正派：獵巫更接近「社區恐慌的司法化」而非「行業清洗的陰謀」 |

折衷結論：性別清洗不是精心策劃的陰謀，但**結果**具有強烈的性別選擇性——用一個機制模型表達：

```python
def witchcraft_suspect(person):
    risk = 0
    if person.gender == "female":   risk += 30   # 醫學性別論的基準加權
    if person.job in ["midwife", "herbalist", "healer"]: risk += 25
    if person.age >= 50:            risk += 20   # 更年期、獨居、無男性保護人
    if person.has_property:         risk += 15   # 財產糾紛是常見檢舉動機
    if person.has_quarrel:          risk += 25   # 鄰里衝突後的報復性檢舉
    return risk > threshold(judicial_climate)
# 恐慌氣候決定 threshold：恐慌高時 threshold 低 → 檢舉即定罪
```

### 獵巫的終結（17 世紀末）

獵巫退場不是因為「科學戰勝迷信」這麼簡單，而是三股力量的合流：(1) 司法程序要求（酷刑逼供的供詞被判定不可靠，且上訴成本高）；(2) 啟蒙理性對「魔鬼締約可實證」的否定（如 Christian Thomasius 1701 年的批判）；(3) 醫學對「鬼附」症狀的接管——被稱為女巫的症狀（幻視、痙攣）開始被稱為疾病。**「巫婆」變成「病人」，是本書治療敘事線的關鍵轉折。**

### 獵巫手冊的「臨床」內容樣本

《女巫之錘》的駭人之處在於其「專業細節」——它像醫學手冊一樣描述「巫術病理學」：

- **陽痿巫術**：男人失去性能力是因被女巫「封住」——此說讓私密的婚姻失敗變成可舉報的罪行，也讓被拒絕的求愛者獲得報復工具。
- **墮胎與嬰兒夭折**：產褥熱、新生兒死亡（當時極常見）被重新歸因為女巫的毒手——醫學無能為力的嬰幼兒死亡，成為獵巫最大的「案源」。
- **幻化的動物**：貓、蟾蜍、蒼蠅皆可能是女巫的化身——為日常動物的異常行為（家畜暴斃）提供檢舉理由。

每一條都是把「**生活中的壞事**」翻譯成「**某個具名婦女的罪行**」的翻譯機。司法機器則負責讓翻譯具有法律效力。

### 酷刑與供詞的自我實現

| 程序 | 效果 | 結構問題 |
|------|------|----------|
| 剝衣剃毛（搜「魔鬼印記」） | 羞辱、去人化 | 任何疤痕皆可定罪 |
| 驗巫針 | 「不痛不出血」者為巫 | 鈍針本身就不會造成劇痛出血 |
| 水刑／拉肢 | 劇痛下招供 | 供詞必然包含「指控他人」→ 案件自我增殖 |

關鍵的系統性缺陷：刑求得來的供詞被要求供出「同夥」，於是一個嫌疑人自動製造出多個新嫌疑人——**這是一台正反饋的指控製造機**，也解釋了為何獵巫在部分地區呈爆發式蔓延，而在司法程序嚴格（需上級核准、禁止連坐）的地區幾乎沒有案件。

## 結案 -- 後果與影響

- **受害者規模**：現代史學估計約 5–6 萬人被處死（修正早年的百萬級誇估），約 75–80% 為女性，集中於 1560–1630 年的神聖羅馬帝國。
- **民間醫療的寒蟬效應**：草藥與助產知識的傳承鏈在部分地區中斷；18 世紀起助產士被國家發照管理——治理取代了火刑，但接管是一樣的。
- **醫學權威的擴張**：獵巫時代確立了一個危險先例：**醫學理論可以成為迫害的技術依據**（「女性體質」論證）。20 世紀的精神醫學濫用（如對異議者的診斷）是此先例的現代回聲。
- **方法論遺產（正面）**：對獵巫檔案的量化研究（地區差異、司法氣候、經濟變量）催生了歷史學的統計方法；第 12 篇的心靈研究學會與第 15 篇的 Emily Rosa 實驗，是「用方法拆穿權威」傳統的另一端。
- **本案與「醫療多元主義」的關係**：獵巫不是「科學對抗迷信」，而是「**一種醫學（蓋倫性別論）+一種神學（魔鬼契約）聯手清除另一種醫學（民間女性治療）**」。它提醒我們：多元主義最危險的敵人，從來不是無知，而是被體制授權的確定性。
