## 1955 - 比徹安慰劑效應（巫醫效力的現代解釋框架）

## 案件摘要

1955 年，哈佛麻醉學教授 Henry K. Beecher 在《美國醫學會雜誌》（JAMA）發表《The Powerful Placebo》：彙整 15 項研究、共 1,082 名病人的對照數據，發現安慰劑組平均有 35% 的症狀「顯著改善」。這篇論文把醫學界一個模糊的常識——「病人吃了糖丸也會好轉」——變成了一個有名有姓、可以量化的科學對象：**安慰劑效應（placebo effect）**。本案是全書的謎底：兩千年前神廟還願碑上那些治癒見證（[-0400-阿斯克勒庇俄斯神廟](-0400-阿斯克勒庇俄斯神廟.md)），第一次獲得了系統性的、可測量的解釋。

## 前因 -- 為什麼會有這個案子

- **二戰的戰地線索**：Beecher 作為戰地軍醫，在嗎啡用盡時以鹽水注射液替代止痛，發現同樣有效——這成為他終生研究的種子。
- **1950 年代的藥效亂象**：市場充斥未經對照檢驗的「特效藥」，醫學界需要一個標準來區分「藥效」與「病人本來就會好轉」。
- **比徹的方法自覺**：他同時是《實驗醫學的倫理》作者（後催生 1966 年研究倫理規範），兼具方法論與倫理學的雙重敏感。
- **本案兇手**：**「對照組的分母」是兇手**——沒有安慰劑組，任何療效都無法與「自然病程+期望效應」區分。巫醫兩千年來的「驗證」，缺的正是這個分母。

## 線索與推理 -- 數學式、程式、理論

### Beecher 的彙整數據

| 研究情境 | 安慰劑組改善率 |
|----------|----------------|
| 術後傷口疼痛 | ~39% |
| 暈船 | ~58% |
| 咳嗽、感冒症狀 | ~35–40% |
| 心絞痛 | ~38%（部分研究還有器質變化報告） |
| **合計平均** | **35.2% ± 2.2%** |

$$ \text{真實藥效} = \text{觀察總效應} - \text{安慰劑效應} - \text{自然病程} $$

### 「安慰劑」一詞的考古

- **字源**：拉丁文 placebo =「我將取悅」；中世紀晚課（Vespers）的第一首聖詠《Placebo Domino》——受雇哭喪者唱的正是此曲，故 placebo 在 14 世紀英語中已有「討好者的諂媚」之意。
- **1811 年首個醫學定義**：Hooper 醫學詞典：「安慰劑：一種比作為藥物更為取悅病人的藥」——**從誕生之初就帶著輕蔑**。
- **Beecher 的翻轉**：他把這個「騙人的甜丸」升格為需要被嚴肅量測的生理力量——一個詞的社會地位史，等於治療敘事線的微縮史。

### 後續修正：效應量之謎

Beecher 的 35% 是粗略彙整，後續研究做出重要修正：

```python
def meta_analysis(placebo_effect, no_treatment_arm):
    # Kirsch 等人 (2002, 2008) 的關鍵拆解：
    # 1. 未治療組（no treatment）也會改善 → 自然病程
    # 2. 安慰劑組改善 - 未治療組改善 = 真正的「安慰劑效應」
    # 3. 抗憂鬱藥試驗中：藥效 - 安慰劑 ≈ 2 分（HDRS 量表），輕中度病人臨床意義存疑
    return {
        "natural_course": no_treatment_arm.improvement,
        "placebo_proper": placebo_effect - no_treatment_arm.improvement,
        "drug_specific":  drug_effect - placebo_effect,
    }
# 教訓：連「安慰劑效應」本身都需要一個對照組來純化
```

- **Kirsch（2008）**：抗憂鬱藥對輕中度憂鬱的效果與安慰劑差距臨床意義有限，僅重度患者藥效顯著——引發持續至今的爭論。
- **開放標籤安慰劑（open-label placebo, 2010s–2020s）**：告訴病人「這是安慰劑」，症狀仍改善（腸躁症、慢性腰痛試驗）——暗示效應不必然依賴「欺騙」，儀式與條件化本身就有效。這是對巫醫最友善的科學發現：**巫醫從不欺騙的部分，可能是最有效的部分。**

### RCT 成為金標準的制度化

| 年份 | 事件 | 意義 |
|------|------|------|
| 1948 | 英國醫學研究理事會鏈黴素試驗 | 公認第一個現代 RCT |
| 1955 | Beecher 論文 | 安慰劑效應被命名與量化 |
| 1962 | Kefauver-Harris 修正案 | 美國法律要求新藥證明「有效性」（不只是安全性），須有對照試驗 |
| 1970s– | 雙盲隨機對照成為國際規範 | 「證據等級」概念的制度基礎 |

比徹框架的深層意義：**它為巫醫的「效力」提供了第一個誠實的解剖學**——巫醫治療 = 自然病程 + 安慰劑/期望 + 儀式與社會支持 + （偶爾）真實藥理。前兩項是「真」的，但屬於普遍心理機制；只有最後一項才是特定療法的專利。

## 結案 -- 後果與影響

- **對照試驗成為醫學的憲法**：任何療法（包括「另類療法」）若要主張效力，必須通過安慰劑對照——這把第 5、7 篇那種「見證式驗證」永久降級為廣告。
- **安慰劑研究成為正經科學**：期望、條件化、醫病關係（情境效應）被神經科學具體化——安慰劑止痛的鴉片類機制（Levine 1978）、前額葉—腦幹迴路成像，證明「想像力」有生理學。
- **對巫醫史的再評價**：全書治療敘事線至此閉合——薩滿的鼓聲、神廟的睡眠、梅斯梅爾的磁桶，效力核心都是同一組心理—生理機制的不同時代包裝。巫醫是「期望效應的工程師」，這不是侮辱，而是定位。
- **倫理的平行遺產**：Beecher 1955 年論文與其 1966 年倫理論文出自同一人之手——量測安慰劑與保護受試者，是同一場方法論革命的兩面。
- **全書謎底正式歸檔**：以此篇為分水嶺，前面各案的「神奇治癒」都可以放入同一個解剖表——Epidauros 碑文 = 自然病程+期望；貝克特奇蹟 = 同上+朝聖儀式；梅斯梅爾 = 期望+群體傳染；觸療 = 純期望且無感知能力。**巫醫不是被科學打倒的，而是被科學「翻譯」了：它的效力被承認，但被重新命名。**
