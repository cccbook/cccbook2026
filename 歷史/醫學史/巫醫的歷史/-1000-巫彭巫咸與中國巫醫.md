## -1000 - 巫彭巫咸與中國巫醫（巫醫分家前後的千年拉鋸）

## 案件摘要

《山海經·海內西經》記載一座「群巫上下」的靈山，其中巫彭、巫咸等六巫「皆操不死之藥以距之」——中國最早的醫療神話裡，掌管不死藥的是「巫」，不是「醫」。到了周代，「巫醫」兩字乾脆連用成一個詞；《論語·子路》說「人而無恆，不可以作巫醫」。但同樣在這片土地上，春秋戰國之際扁鵲提出「六不治」，最後一條正是「信巫不信醫」。本案追查中國醫學史上持續兩千年的案件：**巫與醫，如何分家？分了之後，巫去哪裡了？**

## 前因 -- 為什麼會有這個案子

- **醫巫同源**：甲骨文的「醫」字古文作「毉」，下半是「巫」——字形本身就是證據：最早的治病者就是巫。
- **《山海經》的巫系譜**：巫彭、巫咸、巫抵、巫陽等群巫往來靈山採藥，說明「採藥、掌藥」本是巫的核心職能。
- **周代體制化**：周官系統中巫與醫分屬不同職司，但民間「巫醫」仍連稱；孔子引「人無恆不可作巫醫」的南人諺語，可見其社會存在感。
- **本案兇手**：**「官僚制理性」是兇手**——戰國以降，國家需要可考核、可傳習的醫學，於是醫進入體制，巫被推向邊緣與地下。

## 線索與推理 -- 數學式、程式、理論

### 扁鵲六不治（約前 4 世紀，《史記·扁鵲倉公列傳》）

| 六不治 | 白話 | 現代對照 |
|--------|------|----------|
| 驕恣不論於理 | 蠻橫不講理 | 醫病關係破裂 |
| 輕身重財 | 要命不要錢 | 治療依從性 |
| 衣食不能適 | 生活習慣失控 | 慢性病管理 |
| 陰陽并，藏氣不定 | 病機紊亂 | 預後極差 |
| 形羸不能服藥 | 身體無法承受藥物 | 禁忌症 |
| **信巫不信醫** | 寧信巫師不信醫生 | 治療選擇衝突 |

第六條是中國醫學史上最著名的一道分界線：醫生第一次以「職業倫理」之名，宣告不接巫醫病人的責任歸屬——「有此一者，死可治也」（死了也別怪我）。

### 但巫沒有消失：祝由科的千年存續

| 朝代 | 體制位置 | 證據 |
|------|----------|------|
| 唐 | 太醫署設「禁咒」為一科 | 《唐六典》醫學四科含咒禁 |
| 宋 | 書載祝由符水仍行於民間與軍中 | 《聖濟總錄》論符禁 |
| 元 | 太醫院十三科之一即「祝由科」 | 《聖濟總錄》科目沿革 |
| 明清 | 祝由逐科遞減，轉入民間 | 醫籍屢有「刪去祝由」之議 |

「祝由」之名出《黃帝內經·素問》：「古之治病，惟其移精變氣，可祝由而已。」——連正統醫典也承認：上古治病靠祝禱移轉精神即可。這是官方醫學為巫術留下的「祖產條款」。

### 字形學與文本層位的雙重線索

- **「毉」→「醫」**：漢字下半部從「巫」換成「酉」（酒器），約在秦漢之際完成——藥酒取代巫祝，成為治療的標誌物。一個字的內部，封存了醫巫分家的全程。
- **《左傳》的醫和**：前 6 世紀秦國醫和為晉侯診病，提出「六氣致病說」（陰陽風雨晦明），明言「疾不可為也」與「鬼神致病」無關——這是中國醫學第一次以自然病因論對抗鬼神解釋，與扁鵲六不治構成戰國醫學「去巫化」的兩個波次。
- **《黃帝內經》的立場**：全書幾乎不談巫術，僅在《素問》留下一句祝由的「祖產條款」——正統醫學經典以「沉默」完成對巫的邊緣化。
- **文獻層位提醒**：《山海經》成書跨度大（戰國至漢），其巫彭巫咸記載反映的是**追想中的上古巫醫**，而非周代實況；「醫巫同源」的圖景越古老的文本越濃，正是層位效應。

用一句話總結本案結構：

$$ \text{字形（毉→醫）} + \text{經典（內經的沉默）} + \text{倫理（六不治）} = \text{醫巫分職的三重證據} $$

### 醫療多元主義的結構模型

用現代 medical pluralism 的框架分析中國民間就醫行為：

```python
def choose_healer(patient, symptoms, budget, belief):
    options = {
        "正統醫(儒醫/太醫)": cost=high, legitimacy=high,
        "祝由/符水/巫婆":   cost=low,  legitimacy=varies,
        "自療/偏方/香火":   cost=low,  legitimacy=community,
    }
    # 千年不變的行為模式：先試便宜的、 familiar 的；無效才升級
    # 「信巫不信醫」其實是經濟學問題 + 認知問題，不只是愚昧問題
    return sequential_search(options, by=budget, filter=belief)
```

人類學的儀式效力理論（見 [-5000-薩滿與逐靈儀式](-5000-薩滿與逐靈儀式.md)）在此完全適用：祝由的核心機制是「移精變氣」——以言語儀式重整病人的注意力與期望，正是現代所說的期望效應與情緒調節。

## 結案 -- 後果與影響

- **醫巫分職完成，但多元醫療市場永久存在**：從扁鵲到清代，中國社會從未真正壟斷化——儒醫、祝由、佛道療法、民間偏方長期並存。這是本書「醫療多元主義」主軸最重要的東方案例。
- **祝由科成為官方醫學的「合法巫術」**：唐代太醫署到元代太醫院，巫術治療以「科」的名義在國家體制內活了一千多年，之後才退入民間成為「走陰」「收驚」「符水」傳統。
- **與西方對照**：西方在獵巫時代（第 9 篇）以暴力清除民間治療者；中國以行政分科的方式「體制化邊緣化」——同一目標，兩種手段，暴力程度截然不同。
- **現代回聲**：今日廟宇收驚、符水、改運與中醫、西醫並行的就醫序列，正是本案結構的延續。
