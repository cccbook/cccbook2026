## -0400 - 阿斯克勒庇俄斯神廟（還願碑：史上最早的倖存者偏差偵查）

## 案件摘要

公元前 4 世紀的希臘，病人在 Epidauros、Kos 等地的 Asclepion（阿斯克勒庇俄斯神廟）過夜，等待醫神在夢中顯現治病，醒來後若有好轉，便刻一塊還願碑（votive tablet）立在神廟裡。Epidauros 的碑文記載了一個甚至能讓現代讀者發笑的案例：一位名叫 Agamede 的瞎子夢見神掀開她的眼皮塗上藥膏，醒來後重見光明。本案要拆穿的正是這些「治癒見證」——它們是史上最早、也最經典的**倖存者偏差**資料庫。

## 前因 -- 為什麼會有這個案子

- **Asclepius 崇拜的擴張**：前 5–4 世紀，這位醫神的聖所遍布希臘世界，Epidauros 是總部，Kos 的神廟則與醫學派比鄰而居。
- **incubation 制度**：沿用埃及與近東的神廟睡眠傳統（見 [-2650-印何闐神醫神格化](-2650-印何闐神醫神格化.md)），希臘版更系統化：禁食、沐浴、獻祭、入寢「男士病房」（abaton）。
- **神廟的商業模式**：還願碑+入場費+祭品，是神廟的營收與廣告。
- **本案兇手**：**「見證檔案的篩選機制」是兇手**——神廟只展示好轉者的證詞；失敗者既不會立碑，也不被記錄。

## 線索與推理 -- 數學式、程式、理論

### 為什麼神廟「看起來」有效

假設某病自癒率為 $p$（多數常見病都會自癒或波動好轉），神廟只記錄好轉者。則：

$$ P(\text{碑上可見} \mid \text{痊癒}) = 1, \qquad P(\text{碑上可見} \mid \text{未癒}) \approx 0 $$

碑上的「治癒率」恆近 100%——不是神有效，而是**資料產生過程有系統性篩選**。這就是倖存者偏差（survivorship bias）最古老的實例。

```python
import random

def asclepion_outcome(p_self_heal, n_patients):
    outcomes = [random.random() < p_self_heal for _ in range(n_patients)]
    tablets  = [o for o in outcomes if o]      # 只立碑的案例
    return len(tablets) / len(tablets)          # 碑上「治癒率」恆為 100%
# 教訓：分母裡缺席的病人，比任何藥方都更能製造奇蹟
```

### 還願碑病種分布（Epidauros 碑文內容分類）

| 病種 | 碑文案例性質 | 現代解讀 |
|------|--------------|----------|
| 失明、失聲 | 主觀感官症狀 | 心因性或功能性障礙，暗示敏感 |
| 跛行、腫瘤切開 | 有「手術」敘事 | 部分可能有小型外科（見《手術的歷史》之古代外科諸篇） |
| 不孕 | 期望驅動、病程長 | 儀式壓力緩解可能有真實生理影響 |
| 寄生蟲排出 | 吸吮式「取病灶」表演 | 與薩滿吐骨技法同構（[-5000-薩滿與逐靈儀式](-5000-薩滿與逐靈儀式.md)） |

### 理性醫學與神廟的共存

關鍵疑點：Kos 島上既有醫神聖所，又是希波克拉底醫學派的據點——兩者**沒有互相消滅**。希波克拉底《論聖病》（On the Sacred Disease）明言癲癇「不比其他病更神聖，有自然原因」，但同時代的病人照樣湧向神廟。用現代話說：這是**醫療多元主義**的古典版本，理性醫學與儀式醫學各有客群、各有價位。

- **客群分化**：有錢的城邦公民找遊方醫生（technitai），窮人與重症家屬進神廟；許多家庭「兩邊都試」——先請醫生，無效再許願，或反過來。
- **互不否認的默契**：希波克拉底文集攻擊的是「把病神聖化」的解釋，而非神廟本身；神廟碑文也從不貶低醫生。競爭存在，但沒有獵巫式的消滅企圖——與兩千年後的獵巫（第 9 篇）相比，希臘的多元是相對和平的。
- **神廟也做「實證改良」**：部分聖所逐步加入實際醫療設施（浴場、運動場、病房規則），顯示儀式系統會主動吸收醫學元素以維持競爭力——傳統醫學的「現代化壓力」古今皆然。

### Asclepion 的一天：儀式流程重建

以 Epidauros 為例，一位病人的標準療程大致如下：

1. **淨化**：在聖泉沐浴、禁食特定食物（如某些豆類）；
2. **獻祭**：向神奉獻餅與牲禮（脂肪焚燒、參與者分食）；
3. **頌歌**：吟唱 Paean（讚美詩）進入聖所——音樂的催眠前導功能；
4. **入寢**：在 abaton 的長凳上過夜，羊皮上睡臥（與神「同睡」）；
5. **夢診**：神現身診治，或給出指令；
6. **解夢與處方**：祭司解讀夢境，給出飲食、運動或二次入寢的建議；
7. **還願**：痊癒者立碑、塑像、捐出病患部位的模型（大理石的眼、腿、乳房）。

這七步與現代住院流程（入院、評估、治療、醫囑、回診）的映射度驚人地高——**神廟是一座以儀式語言運作的醫院**，其「出院標準」由病人自己的身體感覺判定。

### 還願碑的三則原文樣本（現代譯意）

- **失明復明**：「一位叫 Agamede 的女士，兩眼已看不見。她日夜守候在聖所，夢中醫神前來，掀開她的眼瞼塗入藥膏。翌日她走出聖所，看見眾人。」
- **膿腫取出**：「Kleodemos 眼上長了膿瘡。他在夢中見神切開患處，取出一支矛尖，將其獻於神廟。」——醒來後病人手裡「真的」拿著矛尖，這類「夢中取出的實物」顯示廟方（或病人）會製造信物。
- **發燒退燒**：「Andragoras 發燒。夢中神命他從三個指頭的重量取肉獻祭，他依言行之，三場燒退了。」

### 神廟「品管」與守門人

碑文中還混有**失敗與戲弄案例**：有人進入 abaton 卻只夢見普通事物，被記為「不得醫治，因不潔／時機未至」；Epidauros 亦留有病人違規（如女性誤入男病房）被記錄的條目。這些條目顯示神廟有一套「為什麼沒效」的備援解釋系統——與現代騙術的「免責條款」結構完全相同：**成功歸神，失敗歸病人。**

## 結案 -- 後果與影響

- **還願碑 = 古代的見證行銷**：神廟模式證明「病人見證」自古就是最強的醫療廣告——直到今天，見證式行銷仍是另類療法產業的核心引擎（第 14、16 篇）。
- **倖存者偏差意識的缺席與遲來**：古代無人系統質疑還願碑的篩選；要等到 1784 年法國王家委員會（第 11 篇）才出現第一次「對照式」療法審查。本案因此是醫學方法論史的負片：**證據很多，證據等級很差**。
- **incubation 的遺產**：神廟睡眠演變為中世紀聖徒祠堂過夜求癒（第 7 篇貝克特朝聖），結構一模一樣。
- **醫神崇拜延續千年**：Asclepius 的蛇杖至今仍是醫學符號之一；「醫生神格化」的社會心理（第 3 篇）從未失效。
- **本案的「偵探教訓」**：判斷一個古代療法是否有效，正確問題不是「有沒有治癒記錄」，而是「**沒有被治癒的人留下了什麼記錄**」。分母的沉默，永遠比分子的喧嘩更有資訊量——這條原則將在第 13 篇以統計學的形式正式歸隊。
- **與薩滿傳統的連續性**：吸吮取蟲、夢中取物、神授醫囑——Epidauros 的技術棧與新石器薩滿（[-5000-薩滿與逐靈儀式](-5000-薩滿與逐靈儀式.md)）幾乎同構，只是把「靈界」換成了「神的宮廷」。這提醒我們：**希臘不是奇蹟，只是薩滿儀式的都會版本**；真正的新事物不是儀式，而是隔壁那個宣稱「癲癇有自然原因」的醫學派。

## 關鍵人物與文獻

- **Asclepius**：希臘醫神，傳為太陽神阿波羅之子，因醫術高明（甚至起死回生）觸怒宙斯被雷斃——神話本身就是「醫生越界」的寓言。
- **Epidauros 聖所**：全希臘最重要的療癒聖地，其還願碑文（iamata）存留約 70 則治癒記錄。
- **希波克拉底**：Kos 出身，《論聖病》作者，理性醫學的旗手，與神廟系統並立而非對決。
