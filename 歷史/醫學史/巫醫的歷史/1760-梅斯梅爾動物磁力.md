## 1760 - 梅斯梅爾動物磁力（史上第一次療法科學審查）

## 案件摘要

1770 年代的巴黎，維也納醫生 Franz Anton Mesmer 的沙龍門庭若市：病人圍坐一個裝滿「磁化」水與鐵屑的橡木桶（baquet），手握從桶中伸出的鐵棒，Mesmer 身著紫綢長袍、手持玻璃琴杖穿梭其間，以目光與手勢「傳導動物磁力」。不少病人陷入痙攣、大笑、大哭——時人稱「極樂危機」（crisis）。治癒見證堆積如山（見 [-0400-阿斯克勒庇俄斯神廟](-0400-阿斯克勒庇俄斯神廟.md)：見證行銷的巴黎版）。1784 年，路易十六下令成立王家委員會調查，成員包括美國大使富蘭克林與斷頭台的發明者 Guillotin 醫生。本案是醫學史上第一次以實驗方法審查一個流行療法——結論：「效果來自想像力」。

## 前因 -- 為什麼會有這個案子

- **啟蒙時代的療法真空**：正統醫學仍是放血與催吐，病人尋求「不痛的治療」；梅斯梅爾的溫柔儀式正是市場空缺的答案。
- **牛頓力學的殘響**：「看不見的力」（重力、磁、電）接連被科學證實，使「動物磁力」聽起來像下一個待發現的自然力——偽科學搭科學的順風車，此案是經典。
- **維也納醜聞的轉場**：Mesmer 在維也納因治療盲少女爭議（病人疑似未真正復明）名譽受損，1778 年轉進巴黎重開張。
- **本案兇手**：**「暗示與社會傳染」是兇手**——委員會將拆解出：療效真實存在，但其來源不是磁力，而是想像力。

## 線索與推理 -- 數學式、程式、理論

### 1784 年委員會的實驗設計

委員會在富蘭克林的宅邸與花園進行一系列「分離測試」——這是醫學史上最早的系統性單盲／偽治療對照：

| 實驗 | 操作 | 結果 |
|------|------|------|
| 樹的「磁化」 | 磁化其中一棵杏樹，病人被蒙眼隨機引至各樹 | 病人在**未被磁化**的樹前同樣發作 |
| 磁化的水杯 | 給病人正常水杯卻宣稱已磁化 | 發作出現 |
| 已磁化的水杯 | 給磁化水但宣稱未磁化 | 無反應 |
| 蒙眼觸碰 | 病人不知誰在旁邊「施術」 | 無感 |

結論寫得冷酷而清楚：**動作、想像與信念足以產生痙攣與「療效」；「動物磁力」無實驗證據。** 用現代語言：

$$ \text{觀察到的改善} = \text{安慰劑效應} + \text{暗示} + \text{社會傳染} + \underbrace{\varepsilon}_{\text{磁力} \approx 0} $$

```python
def mesmer_test(patient, claimed_magnetized, actually_magnetized):
    # 1784 年設計的核心變量分離
    if claimed_magnetized:   # 病人「被告知」是唯一有效變量
        return crisis()
    return calm()
# 富蘭克林們在沒有「安慰劑效應」這個詞的時代，
# 已經量測到了它——這是方法論先於理論的範例
```

### 本案的雙重後代：催眠與心理治療

委員會的報告雖殺死了「動物磁力」，卻催生了三個學科：

1. **催眠**：英國醫生 James Braid（1843）以「神經催眠學」重新解釋——不再需要磁力，凝視與專注即可誘導。名詞 hypnotism 從此剝離 Mesmer 的形上學。
2. **暗示理論**：法國 Nancy 學派（Bernheim、Liébeault）確立「暗示可治症狀」，直接影響心理治療的誕生。
3. **歇斯底里的劇場化**：夏可在巴黎 Salpêtrière 重演「梅斯梅爾式危機」，並以醫院舞台展示——詳情參閱《心理諮商的歷史》之夏可歇斯底里劇場篇；而佛洛伊德正是夏可的學生。

一條隱蔽的直線：**梅斯梅爾沙龍 → 富蘭克林報告 → 催眠 → Nancy 暗示 → 心理治療**。巫術被科學審查拆穿後，其有效成分（暗示、期望、儀式）被科學重新收編。

### baquet（磁化木桶）的設計圖解

| 部件 | 設計 | 功能推測 |
|------|------|----------|
| 橡木桶 | 內裝磁化水、碎玻璃與鐵屑 | 神秘感 + 洗禮意象 |
| 彎鐵棒 | 從桶蓋伸出、可移動指向病人 | 「能量出口」的可操作道具 |
| 繩索 | 病人圍桶、彼此以繩相連 | 群體連結的物理化——社會傳染的催化劑 |
| 鋼琴（玻璃琴） | Mesmer 以樂器「調頻」 | 聽覺儀式 + 藝人魅力 |

單看這張表，與第 5 篇薩滿的鼓、面具、社群圍坐，是同一套技術棧的不同時代包裝——**儀式治療的工程學兩百年來沒有實質進化，只是材料從木與鼓換成了木桶與琴。**

### 危機（crisis）作為「療效證明」的循環

梅斯梅爾體系有一個精巧的封閉迴路：病人不發作=磁力未傳導；病人發作=磁力有效。**無論何種結果都證實理論**——這正是波普爾意義上的「不可否證結構」。1784 年委員會的歷史意義因此更清楚：他們不是「更聰明」，而是第一次**把可否證性**帶進了治療現場（蒙眼、錯置、對照）。

## 結案 -- 後果與影響

- **審查的勝利與事業的失敗**：報告公布後梅斯梅爾聲譽崩潰，離開巴黎；但磁力療法以「追隨者」形式又流行了數十年——**拆穿理論容易，拆穿市場很難**（參見第 15 篇觸療實驗：兩百年後市場同樣不死）。
- **方法論的誕生**：蒙眼、對照、變量分離——1784 年委員會的設計是 RCT 的直系祖先；比徹 1955 年（[1955-比徹安慰劑效應](1955-比徹安慰劑效應.md)）量化的「安慰劑效應」，正是富蘭克林們當年看到的「想像力」的正式命名。
- **權力鬥爭線的轉折**：這是國家首次以實證審查介入醫療市場，確立「療法須受檢驗」的原則——但同時也示範了審查的另一面：委員會否定了療效機制，卻對儀式本身的心理價值視而不見，理性也有它的傲慢。
- **文化後座**： mesmerize 一詞進入日常語言；莫扎特的《魔笛》與當代小說中的「催眠師」形象，皆源於本案的社會記憶。
- **本案留給全書的問題**：委員會證明了「磁力不存在」，但沒有回答「為什麼病人真的好了」。這個被擱置的問題，直到 1955 年比徹（第 13 篇）才獲得正式的科學身份。**拆穿一個假解釋很容易，為真現象找到好解釋則需要兩百年**——這是治療敘事線最漫長的一段等待。

## 關鍵人物與文獻

- **Franz Anton Mesmer**（1734–1815）：動物磁力學說提出者，博士論文即以此為題（受 Paracelsus 與天文潮汐影響）。
- **Benjamin Franklin**：委員會實際主持人，花園樹木實驗的設計者。
- **Joseph-Ignace Guillotin**：委員會成員，後以「斷頭台」留名；當年的身份是醫學改革者。
- **Jean-Baptiste de La Condamine、Antoine Lavoisier**：委員會成員，化學家拉瓦錫並做了磁力對「發情貓」的無效測試。
- 文獻：*Rapport des commissaires chargés par le roi de l'examen du magnétisme animal*（1784）；Braid, *Neurypnology*（1843）。
