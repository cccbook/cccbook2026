## 1895 - 博爾代發現補體（血清裡的熱敏感幫兇）

## 案件摘要

**本案偵破的是：免疫血清不是單獨作戰——血清裡另有一個「非特異性幫兇」，加熱會使它失效。**

1895 年，比利時年輕人 Jules Bordet 在 Pasteur 研究所發表關鍵實驗：把免疫過霍亂的家兔血清加熱到 55 °C，殺菌能力消失；但只要**補回一滴新鮮（未免疫）的正常血清**，殺菌力立即恢復。結論：免疫血清裡至少有兩種成分——(1) 熱穩定的「特異性成分」（後稱抗體，Bordet 稱 sensibilisateur，致敏物）；(2) **熱不穩定的非特異性成分**，無免疫專一性，任何血清都有，德國人 Paul Ehrlich 命名為「補體」（Komplement）。補體是免疫學第一個被發現的「非特異性免疫系統」，也成就了 1919 年的諾貝爾獎。

## 前因 -- 為什麼會有這個案子

- **Nuttall 的前哨（1888）**。Hermann Nuttall 發現正常動物血清本身就有微弱殺菌力——「血清殺菌性」不是免疫動物專利。
- **Buchner 的命名（1889–1890）**。Hans Buchner 證明血清加熱 55 °C 後殺菌力喪失，稱此熱敏感成分為 *alexin*（防衛素）——他已摸到補體的邊，但沒有把「特異 vs 非特異」拆開。
- **Metchnikoff 的招募**。吞噬細胞學說（1883）的旗手 Elie Metchnikoff 在巴黎 Pasteur 研究所急需實驗利器來對抗德國的血清學派；他看中了 23 歲的 Bordet，1894 年邀他到巴黎。
- **學派戰爭的背景**。Behring 血清療法的成功（見 `1890-貝林白喉抗毒素.md`）使「血清裡的特異物質」成為顯學；「非特異性防衛」則是 Metchnikoff 陣營的立場證明。

## 線索與推理 -- 數學式、程式、理論

**線索一：加熱—回補的雙重排除實驗。** Bordet 的實驗設計堪稱偵探教範：

| 條件 | 結果 | 推論 |
|---|---|---|
| 免疫血清（新鮮） | 殺死霍亂弧菌 | 有殺菌物 |
| 免疫血清＋55 °C 加熱 | 失效 | 有熱敏感成分 |
| 加熱免疫血清＋新鮮正常血清 | **恢復殺菌** | 正常血清含非特異成分 |
| 正常血清單獨 | 不殺 | 非特異成分需特異成分引導 |

**線索二：功能分工的邏輯式。**

$$ \text{殺菌} \;=\; \underbrace{S(\text{特異, 熱穩定})}_{\text{抗體}} \;\times\; \underbrace{C(\text{非特異, 熱敏感})}_{\text{補體}} $$

兩者相乘而非相加——**抗體負責「指認」，補體負責「處決」**；任何一項為零，功能歸零。這個乘法結構是免疫學第一次明確的「系統分工」模型。

**線索三：補體結合試驗的誕生。** Bordet 與 Gengou（1901）發現：抗原抗體結合會「用掉」補體——於是可以用**指示系統**（紅血球＋溶血素）偵測補體是否被消耗：

```python
# 補體結合試驗（Bordet–Gengou, 1901）邏輯
def complement_fixation(patient_serum, antigen):
    mix(patient_serum, antigen, known_complement)
    add_sheep_rbc_and_hemolysin()
    if not hemolysis:
        return "補體被消耗 → 病人血清含特異抗體（陽性）"
    return "補體剩餘 → 溶血（陰性）"
```

這個「間接偵測」的設計，1906 年由 Wassermann 改造為梅毒血清診斷（*Wassermann test*，性病史 `../性病的歷史/1905-紹丁發現蒼白密螺旋體.md` 有詳述），是**醫學史上第一個廣泛使用的免疫診斷**——補體從發現到臨床只用了 10 年。

**線索四：吞噬學說 vs 血清學的和解伏筆。** Bordet 的發現表面上是替 Metchnikoff 鬥爭（證明血清裡有非特異性防衛），實際上**調和**了兩派：抗體指認＋補體處決＝血清路線；吞噬細胞吞掉被補體/抗體標記的靶標＝細胞路線。兩條線在 20 世紀被統一為「調理作用」（opsonization，Wright 與 Douglas 1903 年提出）。

## 結案 -- 後果與影響

- **先天免疫系統首次亮相**。補體系統是免疫學發現的第一套非特異性防衛；20 世紀陸續釐清其 30 餘種蛋白、經典/凝集素/替代三條活化路徑、MAC 攻膜複合物——補體缺陷的臨床意義（反覆感染、SLE）在 20 世紀後半定型。
- **免疫診斷技術的萬用底盤**。補體結合試驗統治血清診斷半世紀（梅毒、腦炎、黴漿菌），直到 1970s 被 ELISA 取代；「指示系統＋間接推論」的偵探結構被所有免疫分析法繼承。
- **1919 年諾貝爾獎**。Bordet 因免疫與血清學發現（補體為主）獨得；他後來創建比利時 Pasteur 研究所，並發現百日咳桿菌（*Bordetella* 以他命名）。
- **陰影面**。補體也是雙面刃：過度活化造成缺血再灌注損傷、超急性移植排斥（見 `1943-梅達沃與移植排斥的發現.md`）、及藥物性溶血——補體抑制劑（eculizumab，2007）最終成為另一條治療產業線。
- **一句話結案**：Bordet 用一支加熱的試管證明——**免疫不是孤膽英雄，而是「特異指認者」與「非特異執行者」的雙人舞**；免疫系統第一次顯示出它的「系統性」。
