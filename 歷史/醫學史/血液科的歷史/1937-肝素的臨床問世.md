## 1937 - 肝素的臨床問世（從狗肝提取物到第一支注射抗凝藥）

## 案件摘要

**本案偵破的是凝血治療的另一半謎題：檸檬酸鹽只能在「體外」防凝固，進入人體後，如何在血液循環中安全地阻止血栓？**

1916 年，約翰霍普金斯的醫學生 Jay McLean 在 Howell 實驗室從犬肝與心中分離出一種強力抗凝磷脂物質，後由 Howell 命名為 heparin（肝素）。經過近二十年純化與毒性爭議，1935–1937 年瑞典胸外科醫生 Clarence Crafoord 與多倫多的 Charles Best 團隊完成臨床化：純化配方穩定、劑量可監測、靜脈輸注即可全身抗凝。**血栓病治療第一次有了「體內武器」**——之後所有抗凝治療（華法林、LMWH、DOAC）都以它為起點。

## 前因 -- 為什麼會有這個案子

- **體內血栓無藥可醫**：檸檬酸鹽（見 `1914-血庫與檸檬酸鹽抗凝.md`）只能在採血管與血庫裡螯合鈣離子——若注入人體會引發致命低鈣血症。**手術後肺栓塞、心肌梗塞、深部靜脈血栓，全是沒有武器的戰場。**
- **凝血機制的拼圖**：1900 年代已知凝血酶原—凝血酶—纖維蛋白主鏈（完整瀑布要到 1964 年，見 `1964-凝血瀑布學說.md`），但「在體內溫和地按住這條鏈」需要一個分子能干擾酶而病人不出血——**治療指數（therapeutic index）的懸賞**。
- **意外的新手運氣**：1916 年 McLean 本想研究「促凝物質」，卻在犬肝提取物中測出反常的強力抗凝活性——兇手的指紋出現在不是在找它的實驗裡。
- **純化是二十年的苦役**：早期肝素製劑不純、效價不穩、發熱與過敏頻傳——「發現」與「可用」之間隔著一整座山。

## 線索與推理 -- 數學式、程式、理論

**線索一：肝素的分子本質——帶負電的多糖鏈。** Howell 1920 年代確認肝素是硫酸化黏多糖（glycosaminoglycan）；1960s 進一步確認其五糖序列可與抗凝血酶 III（ATIII）高親和結合。機制在 1968 年被精確偵破（Rosenberg 與 Damus）：

$$ \text{Heparin} + \text{ATIII} \rightarrow \text{複合物，凝血酶抑制速率} \times 1000 $$

肝素本身不直接溶解血栓——它**武裝了血液自帶的剎車系統**（ATIII），把生理抑制劑的速率常數提高三個數量級。這是「催化性抑制」的教科書案例：藥物是變速箱，不是燃料。

**線索二：劑量—監測—安全的三件套。** 肝素治療指數窄，Crafoord 1935 年起在肺栓塞手術前後使用「定時停藥＋臨床觀察」；1939 年 Best 實驗室學生改良出效價單位化（後演進為 *USP* 單位），配合 1950s 的凝血時間監測（今日 aPTT 前身）——**可滴定的抗凝**誕生：

```python
# 治療窗概念的雛形：抗凝強度 vs 出血/血栓風險
def heparin_dose_response(dose):
    # 簡化模型：血栓風險隨劑量下降，出血風險隨劑量上升
    thrombosis = 1.0 / (1 + dose)          # 劑量越高越不易血栓
    bleeding   = dose ** 2 / (dose ** 2 + 4)  # 二階上升
    return thrombosis + bleeding           # 總風險：U 型曲線

for d in [0.5, 1, 2, 4]:
    print(f"dose={d}, total risk={heparin_dose_response(d):.2f}")
# 輸出最低點即「治療窗」——現代 TDM（治療藥物監測）的祖先
```

**線索三：外科是第一個客戶。** Crafoord 用肝素於動脈栓塞取栓術與血管吻合——「讓血在人造環境下不凝固」的需求與血庫同源（見 `1914-血庫與檸檬酸鹽抗凝.md`），並直接鋪路給 1953 年人工心肺機的體外循環（見 `../手術的歷史/1953-吉本人工心肺機.md`）。

## 結案 -- 後果與影響

- **抗凝治療的雙軌成型**：1940s 華法林補上「口服」那一半（見 `1954-華法林從鼠藥到抗凝藥.md`）——肝素（靜脈、即效、可逆、需監測）＋華法林（口服、慢效、長期）構成此後六十年的抗凝雙人舞。
- **體外循環與透析的前提**：人工心肺機、血液透析、導管沖洗都依賴肝素化——沒有肝素，心臟直視手術（`../手術的歷史/1953-吉本人工心肺機.md`）與洗腎都無法成立。
- **LMWH 與 DOAC 的系譜樹**：1980s 低分子量肝素（依諾肝素）把「可監測」變成「固定劑量」；2010s 直接口服抗凝劑（見 `2008-直接口服抗凝劑DOAC.md`）終結監測時代——每一代都在回答肝素案留下的小問題。
- **一句話結案**：肝素案的真相是——**發現只要一個下午，可用要花二十年；把提取物變成藥物的不是靈感，是純化、單位化與劑量學**。

## 關鍵人物與文獻

- **Jay McLean（1890–1957）**——醫學生時期於 1916 年發現肝提取物抗凝物質；優先權之後與 Howell 團隊有百年爭議（現代史學傾向還他一個共同發現者位置）。
- **William Henry Howell（1860–1945）**——約翰霍普金斯生理學家，命名 heparin 並完成早期定性。
- **Charles Best（1899–1978）**——胰島素共同發現者；1930s 帶領多倫多團隊純化肝素並推動臨床試驗。
- **Clarence Crafoord（1899–1984）**——瑞典胸外科先驅，1935–37 首批臨床常規使用肝素於血管手術與肺栓塞。
