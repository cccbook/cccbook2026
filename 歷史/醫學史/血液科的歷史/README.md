# 血液科的歷史：從放血刀、血型指紋、凝血瀑布到基因編輯的造血偵查史

> 本書以「推理探案」的體例，為人類血液學史上的每個關鍵事件寫一篇 wiki：
> 謎題是什麼（血為何是生命？為什麼輸血時靈時不靈？復發的白血病藏在哪裡？），
> 偵探是誰（解剖學家、染料化學家、病毒獵人、細胞工程師）？線索與推理是什麼？
> 每篇檔名以年份開頭（4 位數，負年以 `-` 開頭）。

## 雙線主軸

| 線 | 演變 |
|---|---|
| **認知線** | 血是體液之潮 → 血是循環資源 → 血是細胞的集合 → 血是可計數、可染色、可分型的取證對象 → 血是分子（血紅素、凝血因子、抗體）→ 血是可改造的細胞與基因（移植、CAR-T、基因編輯） |
| **技術—制度線** | 放血刀 → 顯微鏡與計數板 → 血庫與篩檢 → 因子濃縮劑與血品安全 → 生物工程藥物（EPO、DOAC、IMiD）→ 活體細胞藥物與基因治療 |

## 貫穿全書的偵查母題

1. **劑量即案情**——warfarin（毒牛的藥 vs 救人的藥）、EPO（救腎 vs 禁藥）、放血（蓋倫的萬用刀 vs 真性紅血球增多症的特異療法）：同一分子/同一手段，兇手或偵探，由劑量與適應症決定。
2. **看不見的敵人**——骨髓的 MRD（總體治療）、血漿中的抗體（血漿置換）、B12 的 pM 級濃度、免疫記憶（抗 D 預防）：血液學的勝利幾乎都來自「把偵測靈敏度推進一個對數級」。
3. **天然缺陷病人是最完美的實驗**——血友病之於瀑布學說、XII 缺乏不出血之於修正模型、XI 缺乏之於下一代抗凝藥：罕見病人自帶「單變數實驗」的證據力。
4. **制度與倫理也是取證對象**——Denis 案的禁令、血品 HIV 汙染、沙利竇邁的 iPLEDGE：技術案卷的背面，永遠寫著制度案卷。
5. **從「補充」到「改造」**——缺鐵給鐵、缺 B12 給 B12（補充）→ 給 VIII 因子、給 EPO（替代）→ 骨髓移植（更換工廠）→ CAR-T（武裝免疫細胞）→ 基因編輯（改寫圖紙）：血液科完整走過了醫學干預強度的全部階梯。
