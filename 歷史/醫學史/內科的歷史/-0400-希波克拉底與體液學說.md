## -0400 - 希波克拉底與體液學說（醫學脫離神廟，床邊偵探術開張）

## 案件摘要

**本案偵破的是「疾病從哪裡來、該由誰來看」。**

約西元前 400 年，希臘科斯島的希波克拉底學派寫下《預後》《流行病論》《空氣、水與地方》等六十餘篇文獻，做出兩件劃時代的事：第一，疾病不再被解釋為神罰，而是自然現象，可以觀察、記錄、預測；第二，醫生的核心工作從神廟的祭儀轉移到病人床邊——看臉色、摸脈搏、聞尿味、以耳貼胸聽呼吸。本案的真相是：希波克拉底留給後世的最大遺產不是體液學說（它後來反而成了兩千年的枷鎖），而是一套**「觀察→記錄→預後→再觀察」的偵探方法**。

## 前因 -- 為什麼會有這個案子

- **神廟醫學的壟斷**。古希臘疾病歸 Asclepius 神廟管：病人在聖所過夜（incubation），夢中得神諭，由祭司解夢開方——病因是觸怒神明，治療是獻祭與淨化。
- **自然哲學家的挑戰**。恩培多克勒提出四元素（土水氣火）；阿爾克邁翁主張健康是「力的均衡」。把哲學的元素論移植到醫學，只差一步。
- **瘟疫的教訓**。前 430 年雅典大瘟疫，修昔底德記錄了醫生「以身試病」的死亡——觀察流行、記錄病程，開始被視為專業。
- **愛奧尼亞沿海的醫者行會**。科斯與尼多斯兩大學派競爭：尼多斯派按症狀分病（已有「內科分科」的雛形），科斯派重整體病程與環境。

## 線索與推理 -- 數學式、程式、理論

**線索一：體液論的邏輯結構。** 四體液對應四元素、四季、四質（熱冷濕燥）：

| 體液 | 元素 | 季節 | 質 | 過量之病 |
|---|---|---|---|---|
| 血液 | 氣 | 春 | 熱＋濕 | 發炎、多血質 |
| 黏液 | 水 | 冬 | 冷＋濕 | 痰咳、水腫 |
| 黃膽汁 | 火 | 夏 | 熱＋燥 | 發燒、嘔吐 |
| 黑膽汁 | 土 | 秋 | 冷＋燥 | 憂鬱（melancholia） |

健康可以寫成化學式的「平衡」：

$$ \text{健康} \iff \sum_{i} \text{體液}_i \text{ 均衡} \quad;\quad \text{疾病} = \Delta(\text{失衡}) $$

治療因此是「疏導」：放血、催吐、瀉下、發汗——把過量的體液排出去。這套算式在邏輯上自洽，但在**可否證性**上為零：任何病程都可事後歸給某種失衡，這正是它能統治兩千年的原因。

**線索二：預後學的偵探規則。** 《預後》教醫生在問診前先「看」：Acute illness 危相日（critical days）的體溫變化、面容（Hippocratic facies——鼻尖削、眼下凹、冷汗＝將死之相）。可還原成一段判斷流程：

```python
# 《預後》的床邊掃描（前 400 年復原）
def prognosis(patient):
    signs = observe(patient, ["臉色", "呼吸", "脈象", "尿沉渣", "汗"])
    if "Hippocratic facies" in signs:
        return "死亡將至, 告知家屬"          # 預後宣告
    if is_critical_day(patient.day) and fever_dropped(patient):
        return "危相已過, 預後佳"            # 尿沉渣變清、出汗即「轉相」
    return "每日複查, 記錄病程"
```

**線索三：流行病學的原始雛形。** 《空氣、水與地方》要求醫生到新城先調查當地風向、水質、季節與居民體型——《流行病論》逐日記錄病人病程（「第 X 日，尿變稠，發燒……」）而不急於解釋。這是**描述性流行病學＋病程記錄**的第一次系統化。

**線索四：倫理的架構。** 《誓言》把醫病關係定為契約與保密義務；「不傷害」原則（後世 primum non nocere）與「有時治癒，常常緩解，總是安慰」一同構成內科的職業倫理底座。

## 結案 -- 後果與影響

- **醫學的自然化**。疾病從神罰變成自然事件——此後所有內科進步（蓋倫脈搏、叩診、細菌學）都在這條「可以偵辦」的前提下才有可能。
- **體液論的雙面遺產**。它統一了病理解釋（好處），也以權威姿態封鎖了質疑（壞處）：放血療法因此流行近兩千年，直到 19 世紀才被統計證據處死。
- **「acute/chronic」「epidemic/endemic」「relapse/crisis」**等術語至今仍是內科日常語言。
- **希波克拉底式的自省**。《古代醫學》篇明言：「我記下許多無效的治療與我們的失敗，以免羞恥被掩蓋」——這種「記錄失敗」的態度，正是 1948 年 RCT（見 `1948-鏈黴素RCT.md`）與 1972 年科克倫（見 `1972-科克倫效能與效率.md`）的精神遠祖。
- **一句話結案**：希波克拉底沒有治好多少人，但他立下了偵探守則——**先看證據，再下判斷，並且誠實記錄辦不到的事**。

## 關鍵人物與文獻

- **Hippocrates（約前 460–前 370）**——科斯島醫者，Corpus Hippocraticum 約 60 篇文獻的象徵性作者；柏拉圖與亞里士多德稱其為 Asclepiad 一派宗師。
- **《空氣、水與地方》《預後》《古代醫學》**——方法論三支柱；Hippocratic facies 的原始描述出自《預後》第 2 節。
- 東方對照——同時期中國的《黃帝內經》（約前 2 世紀成書）同樣以整體平衡（陰陽五行）解釋疾病；平衡病理學是全球古文明的共同答案。
- 現代註腳——2016 年《預後》描述的面容特徵被以臉部辨識演算法在唐氏症診斷上復活；床邊的「看臉色」，兩千五百年後變成了 convolutional neural network。
