本書與《性病的歷史》（`../性病的歷史/`）互為姊妹篇：性病書聚焦「以人傳人」的慢性社會病，本書則涵蓋大瘟疫、蟲媒病、空氣傳播、抗藥性與全球防疫制度。

## 貫穿全書的理論主線

1. **瘴氣說 vs 接觸傳染論**：從古典時代到 1880 年代，兩派爭了兩千年。瘴氣說雖然押錯了「元兇」，卻意外催生了公共衛生工程（下水道、通風、淨水）；接觸傳染論則等待顯微鏡與 Koch 法則的平反。
2. **Koch 法則**：從病體分離病原 → 純培養 → 接種健康動物重現疾病 → 再分離。這四步是「誰是兇手」的法定證據標準。
3. **流行病學方法**：Snow 的地圖、Semmelweis 的對照組、 Doll 的病例對照——在病原體缺席時，統計就是指紋。
4. **傳染病數學**：$ R_0 = \beta \cdot c \cdot d $，群體免疫門檻 $ 1 - \frac{1}{R_0} $。麻疹要 95%、天花 80%、流感 60%——每一場疫苗運動都是一道算式。
5. **抗藥性選擇壓力**：Fleming 1945 年的預言。抗生素用得越多，選擇壓力越大，噬菌體、抗菌肽與抗生素管理（stewardship）成為二十一世紀的反擊。
6. **全球防疫制度**：從威尼斯的 40 天隔離，到 1951 年《國際衛生條例》、2005 年修訂、2007 年 PHEIC（國際關注公共衛生緊急事件）機制——SARS 之後的世界，把傳染病偵查寫進了國際法。
