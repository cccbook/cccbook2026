## -0430 - 雅典大瘟疫（史上第一份瘟疫臨床紀錄，也是第一樁無名命案）

## 案件摘要

**本案的特殊之處：兇手至今未被起訴，但被害人的病歷完整保存了兩千四百年。**

公元前 430 年，伯羅奔尼撒戰爭開打第二年，一場瘟疫降臨雅典。據修昔底德記載，它在三年內奪走雅典約三分之一人口，包括主政者伯里克利（Pericles）；斯巴達軍隊兵臨城下卻不敢入城。這是西方文明史上第一場有目擊者詳細記錄臨床病程的大流行——而修昔底德本人染病倖存，以「痊癒者」身分寫下觀察報告。兇手是誰？迄今有天花、麻疹、傷寒、鼠疫、伊波拉樣出血熱等十餘種假說，2006 年雅典古墓 DNA 分析指向傷寒沙門氏菌（*Salmonella enterica* typhoid），但爭議未歇。

## 前因 -- 為什麼會有這個案子

- **戰爭製造的完美培養基**：伯里克利的戰略是放棄鄉村、全體退守雅典城牆內。阿提卡半島的農民連人帶牲畜湧入一座約 10 萬人口的城市，瞬間變成 30 萬人以上的擁擠難民營——沒有下水道、沒有隔離概念、井水共用。
- **戰略與疫情的致命互動**：瘟疫爆發後雅典人再度湧出城牆外避疫，又被斯巴達軍隊趕回去。人口密度是這場瘟疫的第一共犯。
- **修昔底德的動機**：他在《伯羅奔尼撒戰爭史》第二卷專章記錄瘟疫，因為他預見「醫生將需要這份資料」。他記錄了症狀序列、接觸傳染的觀察（照顧者最易死亡）、以及倖存者免疫現象——**「病人最悲慘的是陷入抑鬱，而看護者死亡最多」是史上第一條接觸傳播的流行病學觀察**。
- **社會崩解的紀錄**：修昔底德同時記錄了道德秩序的瓦解——及時行樂、神殿裡堆滿屍體、法律失效。此後每一場大瘟疫的敘事模板（薄伽丘、笛福、卡繆）都回到了這個原型。

## 線索與推理 -- 數學式、程式、理論

修昔底德的「病歷」是本案的核心物證。症狀序列：突發高燒、眼睛發炎、喉舌出血、打噴嚏、聲音沙啞、胸痛咳嗽、胃痛嘔吐、第七至九天死亡或開始恢復、倖存者四肢潰爛失明、部分失憶。

**發燒、皮疹（潰瘍）、高傳染性、單次感染獲得免疫、死亡率高**——這個症狀群讓現代學者提出多個候選：

```python
# 病原體偵查：症狀矩陣比對（歷代假說）
suspects = {
    "天花":   {"疹": 2, "發燒": 2, "胃腸症狀": 0, "死亡率": 2, "古DNA支持": False},
    "傷寒":   {"疹": 1, "發燒": 2, "胃腸症狀": 2, "死亡率": 1, "古DNA支持": True},
    "麻疹":   {"疹": 2, "發燒": 2, "胃腸症狀": 1, "死亡率": 1, "古DNA支持": False},
    "鼠疫":   {"疹": 0, "發燒": 2, "胃腸症狀": 1, "死亡率": 2, "古DNA支持": False},
}
# 2006 年 Papagrigorakis 團隊從雅典 Kerameikos 古墓牙髓
# PCR 擴增出 Salmonella enterica serovar Typhi DNA
best = max(suspects, key=lambda k: sum(suspects[k].values()))
print(best)  # 傷寒（但樣本僅 3 具、PCR 污染爭議未決）
```

**天花派的反駁**：傷寒不會造成四肢潰爛失明；**傷寒派反駁**：天花沒有修昔底德描述的劇烈胃痛嘔吐。**麻疹派**指出另一個數學難題——麻疹需要約 25 萬至 50 萬人的易感人口池才能持續流行（見 $R_0$ 論證），雅典 30 萬人恰好勉強在門檻上，但一次流行後病毒應消失，與「三年反覆」矛盾。

用現代傳播數學倒推本案：

$$ R_0 \approx \frac{\text{爆發規模}}{\text{易感人口}} \Rightarrow \text{三年內感染} \tfrac{1}{3} \text{人口，} R_0 \text{ 約在 } 2 \text{ 至 } 4 \text{ 之間} $$

修昔底德觀察到的「照顧病人者最先倒下」，正是今天我們說的 **household secondary attack rate 極高**——在沒有醫院、沒有隔離的時代，家庭就是傳播的主戰場。

## 結案 -- 後果與影響

- **軍事與政治**：伯里克利本人死於瘟疫（-0429），雅典失去最具威望的領導者；此後的政治走向激進化與寡頭政變。瘟疫被修昔底德視為雅典戰敗（-0404）的隱形原因之一。
- **醫學史的起點**：修昔底德的紀錄確立了一個傳統——**瘟疫必須被觀察、記錄、分析**。這個傳統經過蓋倫、伊本·西那、Sydenham，一路延伸到 John Snow 的地圖與 CDC 的 MMWR。
- **倖存者免疫概念的最早紀錄**：修昔底德寫道「同樣的疾病不會第二次襲擊同一人」——這是人類文獻中第一次寫下「病後免疫」，是一千三百年後詹納牛痘實驗的概念祖先。
- **戰爭與瘟疫的宿命糾纏**：本案開啟了「戰爭製造瘟疫」的歷史母題——直到 1918 年流感（`1918-西班牙流感.md`）與 COVID-19，人口擁擠與軍隊調動仍是疫情放大器。
- **一句話結案**：本案永遠無法定讞——兇手的 DNA 沉睡在古墓牙髓裡，而唯一目擊證人的證詞，寫滿了症狀卻沒寫下名字。
