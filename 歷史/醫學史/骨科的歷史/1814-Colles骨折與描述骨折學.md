## 1814 - Colles 骨折與描述骨折學（一張 1814 年的描述，至今每天被診斷數萬次）

## 案件摘要

**本案的謎題：一個 63 歲老太太滑倒撐地，腕部畸形如「餐叉」——骨頭究竟斷在哪？**

1814 年，都柏林 Abraham Colles 發表《On the Fracture of the Carpal Extremity of the Radius》，描述「距腕關節約 2.5 公分處、遠端橈骨向背側移位」的骨折。他沒有 X 光（要等 81 年，`1895-侖琴發現X光.md`），全憑觸診與解剖推理，並大膽主張：**即使復位不完美，石膏固定 3 週後，功能多能良好**。這一描述至今仍是全世界最常見的骨折之一——治療超過兩世紀，爭論也超過兩世紀。

## 前因 -- 為什麼會有這個案子

- **橈骨遠端骨折的兩千年誤案**：從蓋倫到 18 世紀，這類骨折被誤認為「腕關節脫位」——因為畸形位置太靠近腕部。C. F. Desault 與其學生略早質疑，但 Colles 的描述最完整、最有說服力。
- **愛爾蘭解剖學黃金期**：Colles 就讀的 Dublin 學派（並曾師從 Astley Cooper）以屍體解剖著稱，可親手驗證骨折型態。
- **老年人骨質疏鬆的隱形存在**：絕經後女性是最常見患者群——當時無人知道這是骨量流失（要等 20 世紀骨質疏鬆學，`1995-Alendronate與骨質疏鬆.md`），但流行病學形態已經寫在 Colles 的病例年齡分布裡。
- **滑倒的生物力學**：城市鋪石路面＋結冰 → 前伸撐地（FOOSH, fall on outstretched hand）是最常見致傷機轉。

## 線索與推理 -- 背後的理論

Colles 的推理三步：

1. **解剖定位**：畸形尖端在腕橫紋上 5 公分處、可觸到移位的骨端——若為脫位，月骨脫位應在腕中央觸到；觸診位置否定了「脫位說」。
2. **機轉分析**：跌倒時腕背伸、前臂旋前，軸向壓縮經橈骨遠端松質骨傳導——松質骨是弱點。
3. **治療決策**：旋轉牽引復位後，以夾板固定於掌屈尺偏位，**固定期短、允許指腕活動**。

```python
# FOOSH 機轉的簡化力學
def colles_fracture(fall_energy, bone_strength):
    axial_load = fall_energy * 0.6          # 經腕的軸向負荷
    distal_radius = bone_strength * 0.35    # 骨質疏鬆後遠端橈骨強度
    return axial_load > distal_radius       # 斷！

print(colles_fracture(fall_energy=400, bone_strength=800))  # True
```

生物力學：遠端橈骨的張力側在掌側、壓縮側在背側；跌倒時背伸位使背側皮質承受壓縮坍塌、掌側張開——這解釋了「餐叉畸形」的向量，也解釋了為何復位需「掌屈＋尺偏＋牽引」三向同時作用。

Colles 還提出具預見性的**癒合生物學主張**：即使背側塌陷輕度殘留（背傾角<10°），腕功能仍可接受——「功能優於解剖」的保守派宣言，這句話將在 200 年後被 AO 學派（`1958-AO學派與內固定原則.md`）挑戰、再被現代微創理念部分平反。

## 結案 -- 後果與影響

- **骨折診斷的觸診範式**：X 光問世後發現，Colles 以純觸診描述的型態與影像學高度吻合——臨床推理能力的極致展示，也是醫學教育裡「觸診到底還要不要教」的永恆教材。
- **命名的國際化**：與 Pott（`1768-Pott骨折與描述性骨科.md`）一脈相承，19 世紀骨折命名學爆發；Colles 的論文只有短短 8 頁，卻成為被引用最久的骨科文獻之一。
- **骨質疏鬆流行病學的史前史**：遠端橈骨、髖部、椎體三大骨折點的年齡分布，20 世紀末被重新解讀為「骨量流失的流行病學指紋」——Colles 病例簿是骨質疏鬆學的史前證據。
- **治療爭論至今未決**：石膏 vs 鋼針 vs 掌側鎖定鋼板；每一代技術都宣稱打敗 Colles 的保守路線，但大規模試驗反覆顯示「多數老年人功能差異不大」——兩百年的論戰，本質是「解剖復位」與「功能結果」的哲學對決。
