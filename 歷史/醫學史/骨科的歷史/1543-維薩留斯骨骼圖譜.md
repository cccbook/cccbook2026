## 1543 - 維薩留斯骨骼圖譜（骨科的解剖學地基）

## 案件摘要

**本案的證物，是一冊印著骨骼站在墓碑旁擺姿勢的巨書。**

1543 年 6 月，29 歲的 Padua 教授 Andreas Vesalius 出版《人體構造七卷》（*De humani corporis fabrica*），附 200 餘幅精美木刻。其中第 1 卷全部獻給骨骼——骨骸被畫成倚著墓碑沉思、吊掛於絞架的姿態，解剖細節精確到鉤骨的鉤與蝶骨的翼。他拆穿了蓋倫 1300 年的錯誤（蓋倫的解剖來自動物），為骨科提供了第一張精確的「地圖」。**沒有正確的地圖，就沒有正確的復位。**

## 前因 -- 為什麼會有這個案子

- **蓋倫的千年統治**：蓋倫解剖以豬、猴為主，人體解剖在中世紀被宗教禁令限制，錯誤層層累積——例如把人骨與猴骨混寫、胸骨數目錯誤、下頜骨被寫成兩塊。
- **Padua 的解剖劇場**：威尼斯共和國寬容，屍體供應相對充足；Vesalius 主持公開解剖時親自執刀（以往教授坐高椅讀蓋倫、由理髮匠動刀）。
- **文藝復興版畫技術**：Titian 工作室（或其近郊畫坊）水準的木刻，使解剖圖首次「像照片一樣可信」並可大量複製。
- **骨的保存傳統**：備製乾燥骨骼標本供教學的方法（煮、曬、浸油）在當時已成熟，讓「骨學」成為解剖中最易標準化的分支。

## 線索與推理 -- 背後的理論

Vesalius 的方法論是一場「證偽」：他不引經據典，而說「我的眼睛與雙手」。以骨骼為例，他數出人類胸骨 3 塊（蓋倫寫 7 塊，因猴骨）、下頜骨 1 塊（蓋倫寫 2 塊）。這種對抗權威的態度，是日後一切骨科分類學（Pott、Colles）的認識論前提：**描述必須來自觀察，而非文本**。

骨骼的生物學意義也在圖譜中浮現：骨膜、骨骺線、骨小樑的走向被一一描繪——雖然當時不知骨細胞，但「骨有結構、結構適應功能」的形態線索已鋪好，直通 Wolff 定律（`1892-Wolff定律.md`）。

```python
# 解剖學證偽的演算法（Vesalius 方法）
def correct_galen(claim, observation):
    if observation.contradicts(claim):
        return f"蓋倫說錯了：{observation} 優於文本"
    return "沿用"

print(correct_galen("下頜骨為兩塊", "一具人屍的下頜是一整塊"))
```

## 結案 -- 後果與影響

- **解剖學成為外科的必修語言**：此後外科醫師必須具備學院解剖知識，理髮匠外科的「經驗派」地位衰落——手術開始有「科學」資格。
- **骨學標準化**：後繼者（如 Falloppio、Eustachius、16 世紀末的骨學專著與骨骼標本教具）把骨骼命名系統化，今日拉丁骨名多承其統。
- **對蓋倫主義的宣戰**：Vesalius 遭蓋倫學派圍剿，但 17 世紀 Harvey 以實驗生理學繼起，文本權威時代終結。
- **骨科的直接受益**：骨折復位、脫臼分類、截肢平面判斷，自 17 世紀起全部以真實解剖為據——為 1741 年「骨科學」的正式誕生（`1741-André創立骨科學.md`）備好知識本體。
