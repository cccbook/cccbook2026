## 1870 - 運動皮質電刺激（在狗腦上通微電流：定位論從猜測變成實驗）

## 案件摘要

1870 年春天，柏林的 Gustav Theodor Fritsch（生理學家）與 Eduard Hitzig（精神病科醫生）在自家兩位家庭成員的裁縫桌上——不是正式實驗室——用微弱電流刺激狗的暴露腦面。當電極觸到**額葉前部皮質**時，**對側肢體抽動**。這是史上第一次以電刺激在哺乳類皮質上劃出「運動區」。這樁案件的意義是方法論的：**定位論不必再等待死於意外的病人；實驗者可以主動「審訊」活體大腦**。

## 前因 -- 為什麼會有這個案子

- **電的資產**：Galvani 的蛙腿實驗（[生理醫學史：Galvani蛙腿放電](../生理醫學史/1791-Galvani蛙腿放電.md)）確立神經—電的連結；du Bois-Reymond 的動作電流研究讓「以電探神經」成為標準工具。
- **Hitzig 的意外線索**：他在治療病人時用電流刺激頭皮，觀察到肌肉反應——靈光一閃：**電或許能直接作用於皮質**。但需要開顱的動物實驗來驗證。
- **Fritsch 的加入**：傷兵照護的經驗讓他對「腦傷—對側癱瘓」的對應關係印象深刻；他帶來電生理的操作技術。
- **理論僵局的推力**：Broca 剛以屍檢證明語言定位（[1861-布洛卡失語症](1861-布洛卡失語症.md)），但屍檢法又慢又不能重複。**如果能「問」大腦——刺激它、看它回答什麼——定位論就有了可重複的實驗基礎。**

## 線索與推理 -- 數學式、程式、理論

Fritsch 與 Hitzig 的實驗設計，用現代語言描述：

```python
# 1870 年實驗的邏輯（現代復盤）
for 電極位置 in 狗腦暴露面_網格掃描:
    電流 = 弱強直刺激(短脈衝)          # 約 1–4 伏特、短時程
    response = 觀察(肌肉抽動的部位與方向)
    if response 對側且具體:
        運動區地圖[對應點] = (刺激點 → 肢體部位)

# 關鍵發現：
# 1. 只有刺激額葉前部特定帶狀區才引發運動 → 皮質「電可興奮區」有界線
# 2. 地圖呈由上而下的身體排序 → 「小矮人」(motor homunculus) 的雛形
# 3. 切除此區 → 對側運動障礙 → 刺激(正向)與切除(負向)互為驗證
```

**David Ferrier（1873）的擴大戰果**：他在倫敦以猴子為對象，用更精細的刺激，劃出運動、視覺、聽覺等多個皮質區，繪出第一張系統性的**皮質功能圖**。同一時代的 Hitzig 也持續擴充狗的地圖。兩人的爭論（刺激參數、區界）反而讓方法標準化——**爭議成為質量管理**。

| 研究者 | 年份 | 物種 | 主要貢獻 |
|---|---|---|---|
| Fritsch & Hitzig | 1870 | 狗 | 首證皮質電可興奮區；運動帶與體位排序 |
| Ferrier | 1873–75 | 猴 | 多功能區皮質圖；運動／視覺／聽覺定位 |
| Hitzig | 後續 | 狗 | 生理學教科書式整理；刺激—切除雙驗證 |

**Sherrington 的接力**：Ferrier 的猴實驗與運動圖為 Sherrington 的脊髓反射與交互神經支配研究（[1897-謝靈頓突觸](1897-謝靈頓突觸.md)）鋪路——從「哪裡出招」進一步到「如何整合」。

## 結案 -- 後果與影響

- **神經外科的導航圖**：皮質功能圖讓外科醫生首次知道「切這裡會癱、留那裡保語言」。Cushing 在手術中直接以電刺激皮質定位運動與感覺帶（[手術的歷史：庫欣創立神經外科](../手術的歷史/1912-庫欣創立神經外科.md)），Penfield 於 1930–50 年代在清醒開顱病人上畫出傳世的人體皮質地圖——**血統可直溯 1870 年的裁縫桌**。
- **定位論的實驗化**：繼 Broca 的屍檢路線之後，「刺激—反應」路線確立；此後一百年，皮質電刺激從科研工具變成臨床定位、癲癇術前評估的常規（連結 [1929-伯格腦電圖](1929-伯格腦電圖.md)的癲癇定位）。
- **倫理與爭議**：Ferrier 的動物實驗引發反活體解剖運動的訴訟；**動物實驗的正當性與界線**自此成為神經科學的長期議題。
- **方法論遺產**：「以刺激審訊大腦」至今仍是核心手段——從深部腦刺激（[1997-深部腦刺激](1997-深部腦刺激.md)）到皮質內電極腦機介面（[2024-腦機介面人體植入](2024-腦機介面人體植入.md)），本質都是 1870 年問題的續集：**電流能否指揮神經系統？**

## 延伸證物 -- 細節與爭點

- **「裁縫桌實驗室」的傳奇**：兩人最初缺乏正式實驗室，在 Hitzig 家中裁縫桌上完成關鍵實驗——條件極克儉，設計極嚴謹；他們先以自己的頭皮測試電流強度確保不會灼傷腦組織，這個安全步驟日後成為皮質刺激的倫理原型。
- **Fritsch 與 Hitzig 的分工**：Fritsch 掌握電生理操作（受 du Bois-Reymond 學派訓練），Hitzig 帶來臨床觀察與狗隻照護——臨床醫生與生理學家的組合，正是 Willis 案件「臨床+解剖」組合的電學版本。
- **Ferrier 的司法風波**：1876 年英國反活體解剖者以《維多利亞街法案》控告 Ferrier 未持實驗執照，法庭辯論把動物實驗的科學價值推向公共議題；Ferrier 最終免責，此案促成 1876 年《Cruelty to Animals Act》執行細則的確立——神經科學與動物倫理的第一次正面交鋒。
- **Homunculus 的百年迭代**：狗腦地圖（1870）→ 猴腦地圖（1873–75）→ 清醒人腦地圖（Penfield 1930s–50s）→ 人類連體組學的地圖（2000s–）；「小矮人」愈畫愈細，但 1870 年發現的「由上而下體位排序」從未改版。
- **為什麼電刺激能「審訊」**：神經元的語言是放電，電流直接以放電的母語說話——這就是為什麼一百年後的深部腦刺激（[1997-深部腦刺激](1997-深部腦刺激.md)）與腦機介面（[2024-腦機介面人體植入](2024-腦機介面人體植入.md)）仍以電為共同語言。

## 偵查筆記 -- 案件年表

| 年代 | 事件 | 意義 |
|---|---|---|
| 1791 | Galvani 蛙腿放電 | 神經—電連結成立 |
| 1870 | Fritsch & Hitzig 狗腦刺激 | 運動皮質首度實驗定位 |
| 1873–75 | Ferrier 猴腦地圖 | 多功能區系統化 |
| 1876 | Ferrier 訴訟與動物法案 | 動物實驗倫理首役 |
| 1909 | Brodmann 分區圖 | 細胞建構的皮質地圖補完 |
| 1930s–50s | Penfield 清醒開顱地圖 | 人類皮質功能圖定稿 |
| 1990s | 術中皮質定位常規化 | 電刺激成為手術標配 |

- **刺激參數的現代標準**：術中皮質定位多用 60 Hz、1–4 mA 雙極刺激；1870 年 Fritsch–Hitzig 用的「微弱電流」今日看來參數粗糙，但「低於致癇閾值、可重複引發」的原則完全一致。
- **狗腦地圖的原始座標**：兩人報告刺激額葉外側面即引起對側前肢與後肢運動，上肢區偏外側——與今日靈長類運動帶的體位排序方向一致；第一版地圖的方向沒有畫反。
- **Hitzig 的孤獨後半場**：Fritsch 轉向人類學與殖民地研究，Hitzig 獨自擴充狗實驗並與反對者論戰；「共同發現者分道揚鑣」在神經科學史上與 Golgi–Cajal 案遙相呼應。
- **Ferrier 地圖的臨床誤區**：Ferrier 把視覺區畫在頂葉（猴實驗判讀失誤），後被 Munk 等修正——即使是劃時代地圖也會有錯誤座標，需要同業覆核。
- **從審訊到對話**：單細胞記錄（[1962-休伯爾與維澤爾視覺皮質](1962-休伯爾與維澤爾視覺皮質.md)）讓研究者從「問問題（刺激）」升級為「聽自述（記錄）」；刺激與記錄兩種偵查術的合流，最終長成腦機介面的讀與寫（[2024-腦機介面人體植入](2024-腦機介面人體植入.md)）。
