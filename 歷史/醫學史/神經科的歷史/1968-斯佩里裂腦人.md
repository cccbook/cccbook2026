## 1968 - 斯佩里裂腦人（切斷胼胝體之後：一顆頭顱，兩個意識？）

## 案件摘要

1960 年代，加州理工學院的 Roger Sperry 與年輕的 Michael Gazzaniga 對一組特殊病人展開研究：為控制頑固癲癇，外科醫生切斷了他們的**胼胝體**——連接左右半球約兩億根神經纖維的總幹。癲癇不再越境蔓延，病人日常看似正常；但在精確設計的實驗裡，**左半球與右半球像兩個分開的資訊系統各自運作**：左手不認得右半球「看到」的字、卻能用觸摸挑出對應物件。Sperry 據此提出「每個半球可能是一個意識系統」，1981 年獲諾貝爾獎。這樁案件至今仍是意識哲學與神經科學交界的深水區。

## 前因 -- 為什麼會有這個案子

- **臨床來源——連合切除術**：1940 年代 Rochester 的 Van Wagenen 與 Herren 首先為重度癲癇病人切斷胼胝體；當時的臨床報告稱「後果輕微」。1960s，洛杉磯的 Joseph Bogen 與 Philip Vogel 以較年輕病人重行此術，並主動邀請 Sperry 做認知測試——**臨床需求與基礎科學就此合流**。
- **Sperry 的動物先備研究**：1950–60 年代他以貓與猴做「分裂腦」實驗（切斷視交叉與胼胝體，讓兩半球各看一半世界），早已證明每個半球能獨立學習、且互不共享記憶。人類病人是這套方法的自然延伸。
- **方法論的關鍵——視野半側投射**：人類視覺系統的解剖決定了**左視野→右半球、右視野→左半球**。只要在中央注視點兩側快速（<150 ms）閃現刺激，就能把資訊單獨餵給某一個半球；再配合觸覺（左手→右半球）。
- **時代的懸案**：語言定位已百年（[1861-布洛卡失語症](1861-布洛卡失語症.md)），但**「無語言的右半球」究竟有沒有心智**？此前無法在人類身上檢驗——裂腦病人是唯一的自然窗口。

## 線索與推理 -- 數學式、程式、理論

標準實驗與結果的對照表（本案的指紋鑑識）：

| 實驗操作 | 病人的反應 | 推論 |
|---|---|---|
| 右視野閃現「鑰匙」→ 病人能**說出**「鑰匙」 | 資訊到了左半球（語言半球） | 左半球掌口語 |
| 左視野閃現「鑰匙」→ 病人說「什麼都沒看到」，**左手**卻能從一堆物件摸出鑰匙 | 右半球知道，但不能說 | 右半球有豐富知覺與認知，只是無口語 |
| 左手觸摸物件後**不能用左手**叫出名字，右卻可以 | 觸覺投射同樣偏側 | 兩半球各自成系統 |
| 讓病人對左視野圖像選擇對應工具 | 右手（左半球）常選錯、左手選對 | 功能偏側不是語言專利 |
| Gazzaniga 後續：某些病人右半球具有限詞彙理解 | 右半球的語言能力因人而異 | 偏側化是程度問題 |

**「兩個意識」的哲學難題**：Sperry 主張切斷後「顱內存在兩個各自的心理系統」。若意識依賴半球間整合，那麼**沒有胼胝體的人有一個意識還是兩個**？用推理式復盤：

```python
# 裂腦意識難題的邏輯結構
前提1 = "意識經驗需要跨腦區的即時整合"
前提2 = "裂腦病人的跨半球整合被物理切斷"
觀察  = "兩半球各自能感知、決策、（右半球受限地）回應"
推論A = "病人有兩個並行的意識經驗"      # Sperry 的立場
推論B = "仍是一個意識，只是內容異常"     # 反對派（如 Puccetti 的反論）
未決  = "意識的判準本身沒有共識 → 案件維持未結"
# 提醒：右半球非語言 ≠ 右半球無心智——這是本案最重要的除魅
```

## 結案 -- 後果與影響

- **1981 年諾貝爾獎**：Sperry 與 Hubel、Wiesel 共享（後者見 [1962-休伯爾與維澤爾視覺皮質](1962-休伯爾與維澤爾視覺皮質.md)）。
- **大眾文化的簡化與修正**：「左腦理性、右腦感性」的流行說法把結果推向偽科學的「左腦人／右腦人」測驗；科學的修正版是：**功能偏側存在且真實，但多數日常功能是雙側網路協作，個體差異遠大於口號**。
- **臨床遺產**：連合切除成為難治癲癇的選項之一；「半球間失聯」症候群（異手症等）成為神經症狀學的教科書章節。
- **意識研究的長期座標**：裂腦研究為整合資訊理論（IIT）等現代意識學說提供了核心案例——**意識與資訊整合的關聯**至今仍是活躍的假說戰場。

## 延伸證物 -- 細節與爭點

- **實驗設計的解剖學依據**：人類視覺纖維在視交叉半交叉，左視野投射右半球；運動控制與體感覺皆對側支配——「左眼看到的字，右手摸不出來」這些看似靈異的現象，其實是解剖學的必然結果。
- **異手症（alien hand syndrome）**：少數裂腦病人報告左手「自行行動、不聽指揮」——右半球有自己的意圖，且能驅動行動；這是「兩個決策系統」最戲劇性的臨床展示，也成為意識哲學的重要案例。
- **Sperry 的動物前期工作**：1940s–50s 他以蟾蜍、魚、貓研究神經纖維的特異性生長（chemoaffinity hypothesis），分裂腦實驗原是發育問題的工具——一個發育生物學問題意外長出意識哲學的答案。
- **Gazzaniga 的分岔與詮釋之爭**：Gazzaniga 後來提出「解釋器（interpreter）」理論——左半球會為右半球的行為即席編造理由；裂腦研究由「兩個意識」的驚悚問題，轉為「自我敘事的建構性」的科學問題，與認知偏差研究接軌。
- **大眾迷思的清理**：「右腦人更有創意」無科學根據：創作涉及全腦網路，個體差異遠大於半球差異；裂腦病人日常生活的近乎正常，本身就是對誇大版本最有力的反駁。

## 偵查筆記 -- 案件年表

| 年代 | 事件 | 意義 |
|---|---|---|
| 1940 | Van Wagenen 連合切除報告 | 臨床手術先例 |
| 1950s | Sperry 動物分裂腦實驗 | 各半球獨立學習的證據 |
| 1962–64 | Bogen 與 Vogel 手術、病人轉介 | 人類研究啟動 |
| 1968 | Sperry 系列研究報告 | 「兩個意識」假說成形 |
| 1970 | Gazzaniga《The Bisected Brain》 | 解釋器理論萌芽 |
| 1981 | Sperry 諾貝爾獎 | 研究加冕 |
| 2000s | 整合資訊理論等再討論 | 案件維持未結 |

- **胼胝體的解剖規格**：約兩億條纖維、連接兩半球對應皮質——切斷它等於關掉腦內最寬的資料匯流排；而病人聊天、購物、開車幾乎正常，日常神經的可冗餘度令科學家驚訝。
- **經典的「雙手打架」展示**：一位病人右手繫鞋帶時左手同時解開——兩半球的目標衝突以最直觀的方式呈現；這些影像成為神經科學最著名的教學素材。
- **右半球的語言程度之爭**：早期認為右半球「無語言」；Gazzaniga 的個案（P.S.、J.W.）顯示部分病人右半球有詞彙理解甚至有限發聲——「偏側化」是統計傾向而非絕對規則。
- **哲學戰場的現況**：整合資訊理論（IIT）、全局工作空間理論都引用裂腦資料；爭點在「意識需要什麼程度的整合」——本案五十年未結，是意識科學的常青懸案。
- **與大眾文化的和解**：Gazzaniga 晚年親自清理「左腦理性右腦創意」的迷思，指出偏側化是「處理風格傾向」——裂腦研究的公眾形象，花了半個世紀才從迷思回到科學。

- **Sperry 的鷹派實驗哲學**：他主張「先切開再看」的還原策略，也因此捲入動物權爭議；他晚年轉向意識的價值論（意識是因果力，不是副現象）——從冷實驗到熱哲學的罕見弧線。
- **手術的現代定位**：連合切除在 1960–70s 高峰期有百餘例；藥物進步後大幅減少，如今保留給最頑固的跌倒型發作——本案的「病人供給」本身就隨醫學進步而萎縮。
- **裂腦病人的日常能力**：多數病人能雙手合作完成熟悉任務（抄寫、拉鋸），因為小腦與皮質下通路未被切斷——「意識分離」不等於「功能分離」，這是誤讀本案最常見的陷阱。
- **與 BCI 時代的照面**：若未來可讀取兩半球的訊號並分別解碼，「兩個意識」的問題將從思想實驗變成工程問題——裂腦案卷因此成為 neurorights 討論的重要引用（[2024-腦機介面人體植入](2024-腦機介面人體植入.md)）。
