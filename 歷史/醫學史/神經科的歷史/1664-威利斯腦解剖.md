## 1664 - 威利斯腦解剖（神經病學在牛津誕生：臨床觀察與解剖刀的第一次合流）

## 案件摘要

1664 年，牛津出版了一本拉丁文巨著《Cerebri anatome》（腦的解剖）。作者 Thomas Willis 以系統的屍檢、精緻的圖版與病人生前的症狀記錄相互對照，把「腦」從蓋倫式的腦室精氣學說中解放出來。這樁案件的突破點有二：**Willis 環**——腦底動脈環，讓腦的供血擁有冗餘備援；以及「神經科學之父」的方法論——**用同一批病人的生前症狀與死後解剖互為證據**。神經病學（neurology）這個詞，正是他創造的。

## 前因 -- 為什麼會有這個案子

- **蓋倫體系的桎梏**：一千五百年來，腦功能被安置在「腦室」裡——想像腦室中流動著動物精氣（animal spirits），感覺與運動是精氣在中空神經裡的進出。腦實質本身被視為次要。
- **維薩里之後的解剖學復興**：1543 年《人體的構造》（[手術的歷史：維薩里人體的構造](../手術的歷史/1543-維薩里人體的構造.md)）已經示範了「親眼所見」對抗權威的力量，但腦因質地脆弱、難以保存，仍是解剖學的死角。
- **牛津團隊的組成——這是一個偵探團**：
  - **Thomas Willis**（1621–1675）：Sedleian 自然哲學教授，同時是有大量臨床病人的醫生，亦是皇家學會創始成員。
  - **Thomas Millington**：解剖學同事，負責屍檢台上的協作。
  - **Richard Lower**：執行解剖操作的高手，後來以輸血實驗聞名。
  - **Christopher Wren**：後來設計聖保羅大教堂的建築師，為本書繪製了舉世聞名的腦底動脈環圖版——科學史上最著名的「跨界作圖」之一。
- **社會背景**：內戰後的牛津是實驗哲學的重鎮；Willis 在倫敦大疫期間仍堅持看診，積累了神經系統疾病的臨床樣本。**他手上有病人，也有屍體**——這是破案的關鍵配置。

## 線索與推理 -- 數學式、程式、理論

Willis 的偵查流程，用現代術語說就是「臨床—解剖相關研究」：

```python
# Willis 方法論的現代復盤
for patient in 牛津臨床病人:
    生前症狀 = 記錄(patient)          # 癱瘓、失語、頭痛、抽搐
    死後腦解剖 = 逐區檢查(patient)     # 腦實質、腦神經、血管
    若 症狀與病灶位置反覆對應:
        腦區功能假說 += (位置 → 功能)

# 與蓋倫方法的差異：
# 蓋倫: 從哲學目的論推出功能，再找解剖支持
# Willis: 從反覆共現的症狀—病灶推出功能，允許假說被推翻
```

本書的主要發現，可列成一份「起訴書」：

| 發現 | 內容 | 意義 |
|---|---|---|
| Willis 環 | 腦底前後循環吻合成環狀吻合網 | 腦供血的冗餘設計；一側阻塞未必致命；今日神經外科與介入放射的基本地標 |
| 腦神經分類 | 將腦神經整理編號與分組 | 取代蓋倫的七對分類；現代腦神經解剖的雛形 |
| 腦實質的功能地位 | 主張腦「物質」本身（而非腦室）承擔功能 | 把功能從「精氣容器」搬進腦組織 |
| 神經病學 | 創詞 neurologie：關於神經的學說 | 醫學分科誕生 |
| 臨床—解剖結合 | 同一病人的生前症狀＋死後解剖 | 現代神經病理學的方法範本 |

Willis 對「動物精氣」的處理值得細看：他沒有一舉廢除精氣，而是把它「物質化」——精氣變成神經實質中的一種含硫含硝的易燃微粒，藉血液供應而產生。這是一個**過渡理論**：它錯在細節，卻把腦功能拉回了可用觀察與實驗檢驗的物理世界。一百年後 Galvani 的蛙腿放電（[生理醫學史：Galvani蛙腿放電](../生理醫學史/1791-Galvani蛙腿放電.md)）將把「神經的燃料」正式換成電。

## 結案 -- 後果與影響

- **神經病學誕生**：Willis 之後，腦不再是哲學推想的容器，而是有地圖、有血管、有神經編號的**可檢驗器官**。他在《De anima brutorum》（1672）中更討論了動物的本能與睡眠，開啟比較神經學。
- **直接後裔**：他對症狀—病灶對應的重視，經 19 世紀 Broca（[1861-布洛卡失語症](1861-布洛卡失語症.md)）與電刺激實驗（[1870-運動皮質電刺激](1870-運動皮質電刺激.md)）發揚光大，最終支撐起神經外科（[手術的歷史：庫欣創立神經外科](../手術的歷史/1912-庫欣創立神經外科.md)）。
- **命名永存**：Willis 環至今是神經解剖、腦血管造影與動脈瘤手術的必備常識；「Circle of Willis」是醫學中以人名命名地標的典範。
- **未竟之業**：Willis 仍相信腦室與「精氣」在部分功能中扮演角色，對皮質功能分區的理解要等 19 世紀的定位論戰爭才真正展開。

## 延伸證物 -- 細節與爭點

- **Willis 環的臨床身價**：環狀吻合讓一側頸內動脈阻塞時對側血流可繞道補償——這就是為什麼有些病人單側血管全堵卻無症狀，有些人環不完整則中風劇烈。介入放射科醫師評估動脈瘤時，第一步就是讀 Willis 環的完整性。
- **Wren 圖版的現代評價**：Christopher Wren 繪製的腦底血管圖精確到可以被現代神經外科教科書直接引用；藝術與科學在 17 世紀尚無分科——同一位天才既能畫腦環又能設計大教堂。
- **「neurologie」的原意爭議**：Willis 的用詞指「關於神經的學說」，涵蓋解剖與病理，與今日偏臨床的「神經病學」有落差；但作為分科命名，優先權無爭議。
- **動物精氣的硫硝模型**：Willis 把精氣設想為含硫（可燃）含硝（助燃）的微粒，靠血液補充——這是化學語言取代液壓語言的第一步；雖然錯誤，卻把問題轉譯成「神經靠什麼物質與能量運作」，為兩百年後的電生理預留了正確的提問格式。
- **與心理諮商史的交界**：Willis 也討論「歇斯底里」與情緒障礙的腦基礎，是「精神症狀=腦功能」路線的早期宣示——這條線日後分流為神經學與精神醫學，在 20 世紀末又重新合流（參見 [心理諮商的歷史](../心理諮商的歷史/)）。

## 關鍵人物與文獻

- **蓋倫**：被超越的對手——腦室精氣學說的代表。
