## -7000 - 梅赫爾格爾史前鑽牙（新石器時代的牙科手術室）

## 案件摘要

**九顆牙齒，十一個完美的圓孔，破案日期：約公元前 7000 年。**

2001 年，考古學家 Andrea Cucina 在巴基斯坦俾路支省的梅赫爾格爾（Mehrgarh）新石器時代墓葬中，檢視一批約 9000 年前的成人牙齒時，發現多顆臼齒的咬合面上有邊緣銳利、直徑約 1–3 mm 的規則圓形凹洞——至少 11 個孔，分布在 9 顆牙上。沒有金屬、沒有麻醉、沒有文獻，卻有手術的痕跡。這是迄今人類最早的牙科介入證據：**在文字發明之前五千年，已經有人對著牙痛動手。**

## 前因 -- 為什麼會有這個案子

- **梅赫爾格爾是南亞農業革命的現場**。約前 7000 年起，這裡的居民開始種植大麥小麥、馴養牛羊——飲食中碳水化合物比例急升，正是齲齒流行的完美溫床（碳水化合物＋口腔細菌＝產酸，見 `1890-Miller化學寄生說.md`）。
- **同遺址已有高度發達的工藝**：燧石細器（microliths）、串珠鑽孔技術成熟——他們有能力在貝殼與玉珠上鑽出小孔，也就有能力在牙上鑽孔。
- **為什麼嫌疑指向「治療」而非「裝飾」？** 考古學上的兩難：牙上的孔是儀式性鑲嵌（如瑪雅寶石鑲牙），還是醫療操作？必須靠孔的形態與位置推理。

## 線索與推理 -- 數學式、程式、理論

**線索一：孔的位置。** 鑽孔集中在**咬合面齲壞處或其正下方**，而非美觀區（門齒唇面）。裝飾性鑲牙會選別人看得見的牙面；只有「為了止痛」才會鑽在最裡面、最難操作的臼齒窩洞上。

**線索二：孔的幾何。** 掃描電鏡下，孔壁有同心圓狀細微刮痕，孔緣銳利無癒合痕跡——表示施術對象多在死前不久，且工具為**旋轉運動**的燧石鑽頭。在實驗考古中，以燧石尖器配合弓鑽在琺瑯質上復現出幾何一致的孔：

```python
# 復原實驗：燧石鑽 + 弓鑽 vs 牙齒硬度
def drilling_feasibility():
    enamel_hardness = 5          # Mohs 硬度（比骨骼硬得多）
    flint_hardness = 6.5-7       # 燧石略勝琺瑯質
    rotation_speed = "弓鑽每分鐘數百轉"
    time_needed = "數分鐘至十餘分鐘可鑽穿琺瑯質"
    return flint_hardness > enamel_hardness  # True: 技術上完全可行

print(drilling_feasibility())
# 結果: True → 新石器工具包足以完成手術
```

**線索三：磨耗梯度。** 孔的深度不一，最深的已穿透琺瑯質進入牙本質——正好是齲壞最痛的深度。鑽得「恰到好處」而非穿髓，顯示操作者對牙齒結構有經驗性掌握。

**線索四：統計的巧合檢驗。** 若是齲齒隨機分佈，孔出現在多個個體、多位於齲壞或其附近的比例如此之高，屬隨機的概率極低——

$$ P(\text{11 孔皆於咬合面且多伴齲壞} \mid \text{隨機裝飾}) \approx 0 $$

## 結案 -- 後果與影響

- **牙科史起點被前推至新石器時代**。此前最早的公認牙科證據是約前 3000 年埃及；梅赫爾格爾把「外科行為」的起點推早了四千年。
- **是否貫通至今日牙科？** 這條技術線在中斷後沒有直接傳承記錄，但它揭示了一個普世事實：**牙痛夠痛時，任何文明都會發明鑽頭。**
- **與農業的綁定**。齲齒流行率隨農業革命上升——本案等於把「牙痛是文明的代價」這一命題寫進了考古地層。
- **一句話結案**：九千年前的鑽孔不是巫術，而是史上第一位匿名牙醫在沒有教科書、沒有麻醉的條件下，憑一把燧石和病人慘叫聲中的回饋完成的清創手術。

## 關鍵人物與文獻

- **Andrea Cucina**——羅馬第一大學人類學家，2001 年於 *Current Anthropology* 發表梅赫爾格爾牙齒研究。
- **Coppa et al., *Nature*, 2006**——後續團隊以 SEM 與實驗考古確認旋轉鑽孔技術，確立「新石器時代牙科」的國際共識。
- **梅赫爾格爾遺址**——位於巴基斯坦博蘭山口，1974 年起由法國考古隊發掘，是南亞前哈拉帕文明最重要遺址。
- 現代註腳——2015 年起，分子考古學在古代牙結石中檢出變形鏈球菌 DNA，顯示農業革命確實重塑了口腔菌群——本案偵探們推測的「飲食—齲齒」鏈條，獲得基因組層面的補強。
