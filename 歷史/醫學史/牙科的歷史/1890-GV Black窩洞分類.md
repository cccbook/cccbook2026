## 1890 - GV Black 窩洞分類（補牙的幾何聖經）

## 案件摘要

**補一顆牙，需要幾個步驟？鑽多大？鑽什麼形狀？在 G.V. Black 之前，每個牙醫憑手感各答各的；1890 年之後，全世界用同一套幾何語言回答。**

Greene Vardiman Black（1836–1915）——自學成才、沒有上過一天牙科學校的美國牙醫——於 1890 年出版《牙體操作學》（*Operative Dentistry*，1897 年定稿八卷），提出沿用至今的**窩洞分類（Class I–V）**與「**擴展預防（extension for prevention）**」原則，並系統化窩洞預備的六步驟。他被尊為「現代補牙學之父」，也是把牙科從手藝改造成**工程學科**的人。

## 前因 -- 為什麼會有這個案子

- **十九世紀末的補牙亂象**：汞合金戰爭（見 `1833-汞合金戰爭.md`）後，汞合金已是主流材料，但**填多大、留多少、洞壁什麼角度**毫無標準——同一位病人找十位牙醫會得到十種洞形。
- **材料決定幾何**：汞合金脆弱處在邊緣與厚度不足處，無黏著性、靠機械固位——這意味著窩洞形狀必須服從材料的力學。
- **Black 的自學軌跡**：農家子弟、跟哥哥學醫、在西部小鎮行醫二十年，晚年任教西北大學——他代表了一種新模式：牙科的知識權威可以由**實驗與著述**而非出身產生。

## 線索與推理 -- 數學式、程式、理論

**線索一：分類的幾何邏輯。** Black 以**齲齒好發位置**為分類軸——這是流行病學觀察向手術規範的轉譯：

| 分類 | 位置 | 邏輯 |
|---|---|---|
| Class I | 咬合面窩溝裂隙 | 發育溝裂是菌膜庇護所 |
| Class II | 後牙鄰接面 | 鄰面清潔死角 |
| Class III | 前牙鄰接面（未損切緣） | 同上，美觀要求更高 |
| Class IV | 前牙鄰接面（含切緣缺損） | 需恢復切緣強度 |
| Class V | 頰/唇面頸 1/3 | 齦緣菌膜帶 |

**線索二：擴展預防（extension for prevention）。** 核心命題：「**齲壞的好發位置要一併納入洞形**」——鄰面洞的咬合端要沿窩溝擴展，把未來可能蛀的溝裂一起封死。這是 19 世紀預防哲學被寫進鑽頭的角度，其代價是**大量犧牲健康齒質**：

$$ V_{cavity}^{Black} \gg V_{lesion} \quad (\text{為預防而多磨}) $$

（這一原則統治 70 年，直到黏著牙科證明「可以少磨」——見 `1955-Buonocore酸蝕技術.md` 的「預防性擴展的終結」。）

**線索三：窩洞五要素。** Black 定義窩洞的抵抗形（resistance form）、固位形（retention form）、便利形（convenience form）等要素——本質是把汞合金補綴問題化為**結構力學**：

```python
def black_cavity_design(material="amalgam"):
    design = {
        "resistance": "洞底平、洞壁垂直→咬合力沿壁軸向傳遞, 避免劈裂",
        "retention": "倒凹與鴉尾（dovetail）→ 無黏著材料的機械鎖結",
        "marginal": "洞緣角 ~90° → 避免薄邊崩裂與微滲漏",
        "extension": "鄰面洞沿窩溝擴展 = 預防性犧牲",
    }
    return design
# 全部假設都源自一個材料性質: 汞合金沒有黏著力
```

**線索四：全書的實驗方法**。Black 以體外牙齒的抗壓試驗、邊緣滲漏觀察支持每條規則——牙體操作學第一次以**量測**而非師傅口訣立論。

## 結案 -- 後果與影響

- **Class I–V 沿用逾 130 年**，至今仍是全球牙科教育與病歷書寫的通用語言（現代雖新增 Class VI，主幹未變）。
- **牙科的「工程化」範式**：Black 把「補牙」變成「在生物組織上按力學規範施工」——這一範式後來延伸到嵌體（見 `1907-Taggart精密鑄造.md`）與補綴學。
- **被自己的範式超越**：黏著材料問世後，「預防性擴展」被「**最小侵入（minimally invasive）**」取代——今日的補牙哲學是「只移除壞的、保留好的」，恰是 Black 幾何學的反面。Black 若在世，大概會第一個承認：他所有的規則都建立在「材料沒有黏著力」這個當時為真、如今為假的前提上。
- **一句話結案**：Black 沒有發現新病、也沒有發明新材料，他做的是把牙鑽變成幾何儀——用一套分類與五個要素，把全世界牙醫的手感統一成工程圖紙；而他最偉大之處，是留下一套日後可以被推翻的明確規則。

## 關鍵人物與文獻

- **G.V. Black（1836–1915）**——*Operative Dentistry*（八卷，1897 定稿）；另著 *Descriptive Anatomy of the Human Teeth*；1895 年提出汞合金標準配方（見 `1833-汞合金戰爭.md`）。
- **西北大學牙學院**——Black 晚年執教處，其實驗室開創牙科材料測試傳統。
- **現代修訂**——1998 年起全球採用 ICDAS 齲齒分級與微創預備；Black 分類從「手術規範」降格為「病灶位置描述」——但它仍是病歷上最常出現的 19 世紀遺產。
