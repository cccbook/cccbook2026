## 1989 - EMDR 創傷治療（公園散步時的眼球，如何變成創傷治療的實證明星）

## 案件摘要

1987 年，心理師 Francine Shapiro 在加州公園散步時注意到：痛苦的念頭浮現時，她的眼球不自覺地快速來回移動，而念頭的痛苦隨之下降。她隨後系統化這個觀察，1989 年在《Journal of Behavior Therapy and Experimental Psychiatry》發表 EMD（Eye Movement Desensitization）的首篇對照研究。治療後來擴充為八階段的 EMDR（Eye Movement Desensitization and Reprocessing），成為與延長暴露（PE）並列的 PTSD 第一線實證治療——但它「眼動是否為活性成分」的爭議持續至今。本篇是一場「療效包裝 vs 活性成分」的方法論探案。

## 前因 -- 為什麼會有這個案子

- **PTSD 的診斷剛剛誕生是兇手**：1980 年 DSM-III 收入 PTSD（見《1980 - DSM-III診斷革命》），大批越戰退伍軍人與性侵倖存者湧入臨床，但有效治療稀缺且痛苦（早期暴露治療脫落率高）。臨床對「更溫和、更快」的創傷治療有巨大飢渴。
- **既有工具的缺口**：系統減敏（見《1958 - 沃爾普系統減敏》）需要放鬆與階層，對侵入性畫面（flashback）效果有限；藥物只能壓症狀。創傷記憶的處理技術是一片空地。
- ** Shapiro 的個人條件**：她是文學背景轉行的心理學研究生（1988 年才取得博士），不在任何主流學派內——既是弱點（初期不被學界接納），也是優勢（不被教義束縛，敢於以單一觀察開案）。
- **時代的方法論水位**：RCT 已是臨床心理學的新憲法（Beck 範式，見《1976 - 貝克認知治療》），任何新療法都必須過試驗的關。

## 線索與推理 -- 數學式、程式、理論

EMDR 的八階段結構：

| 階段 | 名稱 | 內容 |
|---|---|---|
| 1 | 病史與治療計畫 | 找出目標記憶網絡 |
| 2 | 準備 | 穩定化、安全地練習、解釋程序 |
| 3 | 評估 | 選定畫面、負面認知、正認知、情緒與身體感覺（SUD、VOC 評分） |
| 4 | 減敏感 | 回想目標＋雙側刺激（眼動／交替拍擊／聲音），重複至 SUD 下降 |
| 5 | 安裝 | 以正向認知取代（VOC 達標） |
| 6 | 身體掃描 | 清除殘餘身體緊繃 |
| 7 | 結束 | 穩定、意象強化 |
| 8 | 再評估 | 下次會談檢驗療效持續 |

它的理論主張是**適應性資訊處理（AIP）**：創傷記憶因過載而以「未消化」的狀態儲存，雙側刺激模擬 REM 睡眠的記憶加工狀態，使記憶重新納入聯結網絡。用程式描述兩種治療哲學的差異：

```python
memory = {"畫面": "爆炸瞬間", "情緒強度": 9, "加工狀態": "封存、易閃回"}

def prolonged_exposure(m):
    m["情緒強度"] -= 4          # 反覆面對 → 習慣化＋預期否證
    m["加工狀態"] = "重新編碼"
    return m

def emdr(m):
    # 短暫接觸＋雙側刺激，號稱直接恢復「加工」而非重歷「暴露」
    m["情緒強度"] -= 5
    m["加工狀態"] = "納入自傳體網絡"
    return m

print(prolonged_exposure(dict(memory)))
print(emdr(dict(memory)))
# 兩條路都通向記憶更新——爭議在於：活性成分是誰？
```

科學爭議的清單，本身就是一堂方法論課：

| 爭議點 | 正方（EMDR 陣營） | 反方（成分拆解陣營） |
|---|---|---|
| 眼動是否必要 | 有元件拆解研究顯示眼動增強記憶聯想與工作記憶負載效應 | 多項拆解試驗顯示眼動組與固定注視組療效無差異 |
| 治療理論 | AIP 模型 | 無額外解釋力：暴露＋認知重構即可涵蓋 |
| 療效證據 | 多份臨床指引（APA、WHO）列為 PTSD 一線治療 | 與 PE 等效；等效≠機制正確 |

這裡的關鍵判準是 **dismantling design（成分拆解設計）**：把療法拆成零件，逐一移除，看誰在開火。EMDR 的尷尬在於：整體療效穩定（對 PTSD 的效果量與其他一線療法相當，$ d $ 普遍在 0.8 以上），但被指控為活性成分的部分（眼動）經拆解後常常不出血。心理治療史上罕見如此純粹的案例：**一個療法可能「有效但名不副實」**——包裝（儀式、命名、八階段）與成分（暴露＋認知）的利潤歸屬之爭。


### 深挖：Shapiro 案的方法學時間線

- **1987**：公園觀察（n=1，自我實驗）。
- **1988**：修畢臨床心理學博士；隨後系統化流程。
- **1989**：首篇 EMD 對照研究（n=22，創傷記憶，單次療程後對照）——樣本小、指標粗，但通過了第一關。
- **1991**：EMDR 正式命名（加入 Reprocessing），八階段成形。
- **1995–2010s**：多項 RCT 與後設分析確立 PTSD 療效；成分拆解研究與眼動必要性之爭並行。

### 「療效包裝 vs 活性成分」的對照組：其他案件的判決

| 案件 | 療效 | 活性成分拆解的結果 |
|---|---|---|
| 系統減敏（見《1958 - 沃爾普系統減敏》） | 有效 | 放鬆非必要，暴露是核心 |
| 眼動減敏（EMDR） | 有效 | 眼動成分爭議未決；暴露＋認知為主要候選 |
| 正念減壓（見《1979 - 卡巴金正念減壓》） | 中等有效 | 「去中心化」等特定機制被部分驗證 |
| 精神分析（見《1900 - 夢的解析》） | 整體效應存在 | 機制與理論幾乎不可拆解 |

EMDR 在此表中的特殊位置：它是**療效證據最強、成分證據最曖昧**的案例。這個組合使它成為心理治療研究法教科書的必收案例，也解釋了為什麼臨床指引（講療效）與學術批評（講機制）可以長期對它下不同判決。

### 雙側刺激的最後防線

支持眼動的工作記憶理論（van den Hout & Engelhard, 2012）：回想創傷影像的同時做眼動，工作記憶被佔用，影像的生動性與情緒性**即時**下降——這個效應在實驗室可複製。若此理論成立，眼動是一種「工作記憶稅」，使記憶在重新儲存時變得不那麼痛。這不是 Shapiro 原本的 AIP 理論，卻是唯一有實驗微觀證據的版本。本案的終審可能落在：**眼動有效，但它是止痛劑，不是鑰匙。**

## 結案 -- 後果與影響

- **臨床地位的確立**：EMDR 與 PE、認知處理治療（CPT）同列 PTSD 指引推薦；退伍軍人部門（VA）、NICE 等納入常規，全球治療師認證體系成形。
- **方法論的遺產**：EMDR 案迫使學界把「療效證據」與「機制證據」分帳——療效試驗證明「有用」，拆解試驗檢驗「為什麼有用」；兩者可以背離。這對整個第三波（見《1993 - 林納翰辯證行為治療》《1979 - 卡巴金正念減壓》）都是有效的檢驗模板。
- **對暴露陣營的良性刺激**：EMDR 的「短暫暴露」主張逼 PE 陣營精煉自己的劑量理論，兩者競爭的淨結果是 PTSD 治療選項的擴大與療程的改良。
- **未結之案**：雙側刺激的工作記憶理論（回想的同時執行眼動會佔用工作記憶，使記憶影像「變鈍」）是目前最有實證支持的成分解釋——若成立，眼動確有作用，但功能是**即時減痛**而非「加工創傷」，與 Shapiro 的原始理論並不相同。判決仍在上訴中。


### 結案之後：本案的終審預備庭

- **指引的共識面**：APA（2017）、WHO（2013）、NICE（2018）皆列 EMDR 為 PTSD 一線治療，與 PE、CPT 並列。臨床層級的爭議基本結案。
- **理論層級的懸案**：AIP 模型仍缺獨立證據；工作記憶理論是目前最好的候選——眼動是「減痛劑」而非「加工鍵」的假說，等待關鍵實驗。
- **行業啟示**：EMDR 的成功證明：在心理治療界，**有效的包裝也是資產**——八階段儀式給治療師結構感、給病人可預期性，這些非特異成分本身有療效價值。科學家批評它名不副實；臨床家使用它如魚得水。兩種評價都對，因為它們測的是不同的東西。
