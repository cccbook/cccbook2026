## 1980 - DSM-III 診斷革命（症狀條列取代臨床直覺，信度戰勝了效度）

## 案件摘要

1980 年，美國精神醫學會出版 DSM-III。主編 Robert Spitzer 帶領團隊做了一件冒天下之大不韙的事：把精神診斷改寫成**可操作的症狀條列**——要診斷憂鬱症，需符合清單上的 N 條症狀、持續 M 週、且排除其他原因。多軸系統、明確排除條款、上百個新診斷類別同時登場，PTSD 首次入典。信度奇蹟般上升，效度的哲學爭論則被延後三十年。本篇追查：這場革命的推力從何而來？Feighner 標準鋪了什麼路？以及「診斷革命」如何同時改寫測驗、藥物與病人權利的版圖？

## 前因 -- 為什麼會有這個案子

- **「信度崩盤」是兇手**：1970 年代的跨國診斷一致性研究（US-UK Diagnostic Project、Cooper 等）顯示，英美醫師對同一病人的診斷一致率低得驚人——紐約診斷的「精神分裂症」很多在倫敦被診為躁鬱。在藥物試驗與保險給付都需要穩定診斷的時代，這是體制的火災警報。
- **精神分析解釋系統的壟斷**：DSM-I（1952）與 DSM-II（1968）夾帶大量精神分析式的病因描述（如「焦慮神經症源於對衝動的壓抑」），既無實證基礎，也阻斷了非分析取向的臨床與研究。
- **Feighner 標準（1972）**：華盛頓大學的 Feighner、Robins 與 Guze 發表 16 個疾病的操作性研究用診斷標準，並附上「信度—效度—生物標記」的研究綱領（新肯珀主義 Neo-Kraepelinism：回到 Kraepelin 的描述性分類傳統）。DSM-III 就是這套標準的臨床化擴編。
- **外部壓力的總和**：ICD-9 的國際接軌需求、藥廠對精準適應症的商業需求、反精神醫學批判（Szasz、1975 年 Rosenhan 實驗「假病人事件」）對診斷任意性的羞辱——每一路壓力都指向同一個出口：把診斷變成清單。

## 線索與推理 -- 數學式、程式、理論

DSM-III 的核心工程是診斷規則的形式化：

$$ \text{診斷 D} \iff (\text{症狀集} \supseteq \text{必要條款}) \wedge (\text{持續時間} \geq T) \wedge (\text{排除條款均不成立}) $$

用程式看一個（簡化的）重性憂鬱診斷引擎：

```python
symptoms = ["低落情緒", "失眠", "無價值感", "食欲下降", "疲累", "注意力差"]
required_count = 4          # 九條中至少四條（含低落情緒）
duration_weeks = 2
present = ["低落情緒", "失眠", "無價值感", "食欲下降", "疲累"]
exclusions = ["甲狀腺功能異常", "物質使用"]   # 先排除器質與物質原因

def diagnose(present, exclusions):
    if exclusions: return "先處理器質性／物質性原因"
    core = "低落情緒" in present
    return "重性憂鬱症" if core and len(present) >= required_count else "不符合診斷"

print(diagnose(present, exclusions))  # 先處理器質性／物質性原因
print(diagnose(present, []))          # 重性憂鬱症
```

多軸系統把評估拆成五個座標：臨床症候群、人格與智能障礙、一般醫學狀況、心理社會壓力源、整體功能評估（GAF）——一個病人不再只是「一個診斷」，而是五個維度的剖面。革命性的取捨在於**放棄病因、只描述症狀**：這換來了信度（不同醫師對同一病人得出同一診斷，kappa 大幅提升），但把效度（診斷是否對應真實疾病實體）作為未兌現的支票。Robins 與 Guze 的「外科手術式」效度驗證綱領（家族研究、病程、治療反應、生物標記）成為未來三十年的研究議程。


### 深挖：DSM-III 的政治史

- **誰被排除**：DSM-III 把同性戀已在 DSM-II（1973 年表決移除、1980 完全除名）排除於疾病清單之外——診斷手冊的每次修訂都是一次政治人類學事件：社會的哪些痛苦被醫療化、哪些被除罪化。
- **Spitzer 的方法**：他召集工作小組、以數據與表決決定診斷去留（包括著名的「經前緊張症」爭議的折衷——GMT/PMDD 條目），開啟了「診斷是委員會產品」的時代。
- **與 ICD 的張力**：DSM 是美國手冊、ICD 是世界分類；兩者的編碼相容但理論不同——DSM-III 的症狀條列最終反向殖民了 ICD-10 的精神科章節，美國範式成為全球範式。

### 信度 vs 效度：一場未終結的交易

DSM-III 用**描述性主義**（只說症狀、不談病因）買到了信度，代價是共病爆炸（同一病人常同時符合多個診斷，暗示類目切得太細）、異質診斷（同一名下病人可能只有一條共同症狀）、以及 RDoC（2010s，NIMH）對「類目體系與神經科學脫節」的反叛。三十年後的裁判傾向：操作性診斷是**優秀的研究與溝通協議、不完美的疾病本體論**。這個判決也重新定價了臨床判斷：當清單窮盡之處，正是治療關係與個案概念化（見《1942 - 羅傑斯當事人中心》《1976 - 貝克認知治療》）回場的時刻。

## 結案 -- 後果與影響

- **PTSD 入典的偵探細節**：越戰退伍軍人運動（Vietnam Veterans Against the War 的rap groups、Chaim Shatan 與 Robert Lifton 的倡議）把「戰爭創傷後的遲發症候群」推進 DSM-III——這是診斷手冊史上第一次由**病人團體的政治行動**創造診斷類別（參見《1908 - 心理衛生運動》的病人發聲傳統），也直接塑造了創傷治療的實證陣營（見《1989 - EMDR創傷治療》）。
- **測驗地圖的改寫**：操作性診斷削弱了羅夏等直覺式評估（見《1921 - 羅夏墨跡測驗》）的臨床正當性；MMPI 的實證鍵與結構化會談（SCID）成為新標準（見《1943 - 明尼蘇達多相人格測驗》）。
- **藥物時代的合流**：穩定診斷讓藥廠試驗有了精準目標人群，精神藥理學黃金年代與診斷革命互相加速（見《藥物的歷史》）；同時「症狀清單」的診斷也使適應症不斷擴張——兒童的 ADHD（首列於 DSM-III 作 ADD）等新類別伴隨爭議而生。
- **哲學帳單**：疾病實在論（精神疾病是真實的自然類別）vs 建構論（診斷是社會協商的產物）的爭論貫穿 DSM-IV 與 DSM-5（2013）：DSM-5 研究上的維度化嘗試（RDoC）正是對類目體系效度危機的回應。Spitzer 本人晚年也承認：信度是買得到的，效度還沒。
- **病人權利的迴響**：診斷標準的透明化使「我是否符合診斷」第一次可以被病人自己查證——診斷從專業黑箱變成可討論的公共文本，為知情同意與自我倡議提供了彈藥。


### 結案之後：清單時代的三十七年

- **DSM-IV（1994）**：文獻驅動的保守修訂，信度制度化。
- **DSM-5（2013）**：維度評估入門、自閉症譜系合併、哀傷排除條款的放寬爭議——革命者成為被批判的體制。
- **RDoC（2010s）**：NIMH 宣布不再以 DSM 類目資助研究，改以神經行為維度——描述性主義的支票正式到期。
- **ICD-11（2019）**：世界分類跟進操作性化，也加入遊戲障礙等新條目，顯示診斷的政治性一如 DSM-III 的 PTSD 時代。
Spitzer 的遺產是雙面的：他終結了解釋的暴政，也建立了清單的暴政。心理治療各流派如今都在清單上討生活——包括反對清單的那些。

### 結案之後：一場革命的回聲清單

- **信度買到了**：結構化會談（SCID）的 kappa 達 0.7 以上——跨醫師、跨國家的診斷終於可比。
- **效度仍欠著**：共病率、異質性、維度—類目錯配，三十年未解；RDoC 與 Hierarchical Taxonomy of Psychopathology（HiTOP）是兩種還債方案。
- **政治性被公開**：每次修訂都成為公共事件（哀傷要不要算憂鬱？自閉譜系怎麼切？）——診斷從專業技術問題變成公民議題，這本身就是 DSM-III 的革命遺產：它把瘋狂的定義權放上了檯面，再也收不回去。
