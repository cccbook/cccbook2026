## 1921 - 羅夏墨跡測驗（十張墨跡如何讀出一個人，又如何在科學面前敗退）

## 案件摘要

1921 年，瑞士精神病學家 Hermann Rorschach 出版《心理診斷學》（Psychodiagnostiks），附上十張精心調製的墨跡圖：命受測者說出「你看到什麼」。他相信，人在面對曖昧刺激時的知覺組織方式，會洩漏其性格結構。這是投射測驗的誕生。戰後它被美國軍方與臨床界奉為 X 光級的心理顯影技術，1970 年代卻遭遇信效度危機，1974 年 John Exner 以統一計分系統救亡。本篇追查：投射假說的機制是什麼？一張墨跡憑什麼診斷人格？以及科學的反噬為何既毀了它、又救了它。

## 前因 -- 為什麼會有這個案子

- **「不請自來的答案是兇手」**：直接問卷測人格，病人會給社會期許的答案。臨床需要一種受測者不知道「正確答案」的工具。曖昧刺激——既不像什麼、又可能像什麼——強迫受測者自己組織知覺，組織方式即人格的指紋。
- **投射假說的系統化**：此說可上溯到 19 世紀的「墨跡聯想」遊戲（Justinus Kerner 的墨跡詩集）與 Binet 的建議；Rorschach 的突破在於把它變成有計分、有常模初步的診斷工具。
- **時代需求**：一次大戰後，大批退伍軍人需要心理篩選與分類；瑞士精神病學（Bleuler 的門下，Jung 的同門）正積極為診斷找客觀指標（見《1913 - 榮格與佛洛伊德決裂》的同門背景）。
- **墨跡的工藝門檻**：Rorschach 淘汰了數千張樣品，最終定版的十張（5 張黑白、2 張黑白加紅、3 張彩色）是為對稱性、輪廓與情緒誘發力調校過的「儀器」。

## 線索與推理 -- 數學式、程式、理論

Rorschach 系統的推理核心：**知覺 = 輸入刺激 × 內在結構**。當輸入極度曖昧，輸出便主要由內在結構決定：

$$ \text{反應} = f(\text{刺激的模糊性}) \times \text{人格結構} $$

他的計分是三軸的：

| 計分軸 | 問什麼 | 推理 |
|---|---|---|
| 定位（Location） | 全體 W、局部 D、細節 d | 整體 vs 細節取向＝思考組織風格 |
| 決定因子（Determinant） | 形狀 F、運動 M、色彩 C | M 高＝內在生活豐富；純 C＝情緒外放 |
| 內容（Content） | 人、動物、性、解剖 | 聯想的主題偏好 |

加上反應總數 R、對時間與拒答數，構成一張「心理剖面」。用程式看兩個極端受測者的輪廓：

```python
def profile(name, W, M, C, R):
    style = []
    if W > 6: style.append("整體掃描、抽象取向")
    if M > C: style.append("內控、想像主導")
    if C > M: style.append("情緒外放、衝動性")
    if R < 15: style.append("反應保守，可能防衛或遲滯")
    print(name, "->", "; ".join(style) or "常態範圍")

profile("受測者A", W=9, M=6, C=1, R=28)
profile("受測者B", W=2, M=1, C=6, R=12)
# A：豐富的內在生活與整體組織；B：低反應量、情緒色主導
```

投射假說的家族很快擴張：TAT 主題統覺測驗（Murray & Morgan, 1935）、畫人測驗、語句完成——整個「投射技術」黃金年代由羅夏開路。二戰與戰後，美軍對數十萬人施測，羅夏成為臨床心理師的看家本領。


### 深挖：羅夏測驗的一場法學插曲

- **1970 年代的「偽科學審判」氣氛**：心理計量學者（如 Paul Meehl 的學生輩）把羅夏與占星並列批判的場合時有所聞；但也有司法系統仍大量採信羅夏作鑑定——科學審計與法庭實務長期脫節。
- **常模災難**：Exner 的綜合系統常模曾被發現有嚴重問題（1999 年前後，Schretlen 等發現 CS 常模使大量正常人被判為「思覺失調指標陽性」），一度引發「羅夏讓人們看起來都瘋了」的公關危機——這是常模管理失敗的經典教材。
- **倫理的代價**：受測者對墨跡的回答會被引申出性、攻擊、精神病態的推論，且難以反駁。1950 年代被指測驗使用於就業篩選的爭議，是心理測驗隱私議題的先聲（見《1943 - 明尼蘇達多相人格測驗》的延伸爭論）。

### 投射測驗為何值得記住？

即使證據不足，「曖昧刺激 → 內在結構」的邏輯並沒有死：它以新名義存活在內隱聯想測驗（IAT）、注意偏誤作業（dot-probe）、以及心理病理的「訊息處理偏誤」實驗傳統中。差別只在：舊投射測驗要求詮釋者的天才，新範式要求反應時間的毫秒。羅夏的墓誌銘或許是：**他問對了問題，但找錯了儀器。**

## 結案 -- 後果與影響

- **黃金年代**：1950 年代，超過八成的美國臨床心理師使用羅夏；它塑造了「臨床心理師＝測驗詮釋者」的職業形象（此形象後被見《1942 - 羅傑斯當事人中心》的談話治療職業形象取代）。
- **信效度危機是兇手的反噬**：1960–70 年代的心理計量學審計發現：不同計分系統互不相容、評分者間信度參差、對常態族群的常模失真、增量效度存疑。羅夏從「心理 X 光」跌落為科學批判的標靶，與 DSM-III 的操作性診斷革命（見《1980 - DSM-III診斷革命》）前後呼應。
- **Exner 的救亡（1974）**：綜合系統（Comprehensive System）統一計分、重建常模、規範施測程序，使羅夏勉強續命；但科學界的共識是：它可用於人格描述與治療假說生成，不宜單獨作為診斷依據。2013 年前後對 CS 常模與信度的再批評（見 Mihura 等 2013 的 meta-analysis）使其地位進一步收縮。
- **方法論遺產**：羅夏案是心理學史上「直覺詮釋 vs 心理計量標準」的標準案例。它教會這門學科：**一個工具的浪漫，不等於它的效度**——這條教訓直接餵養了 MMPI 的實證鍵路線（見《1943 - 明尼蘇達多相人格測驗》）。


### 結案之後：墨跡的餘生

- **臨床現況**：羅夏仍在部分國家（德語區、南美、荷蘭）作為輔助評估使用；北美臨床心理師的使用率已從八成跌到少數。它的角色從「診斷儀器」降級為「人格對話的起點」。
- **法庭上的教訓**：Daubert 標準（1993）要求專家證據具有可檢驗性與已知誤差率——羅夏在美國法庭的採信度大幅下降。心理測驗的司法命運，如今由統計而非臨床魅力決定。
- **文化後備**：墨跡成為大眾文化的密碼（安迪・沃荷、心理驚悚片、心理測驗 App）——它作為「深不可測的心」的視覺符號比作為工具活得更久。一項技術最好的身後事，往往是變成隱喻。

### 結案之後：十張卡片的最後清點

- **設計的倖存**：Rorschach 1922 年病逝（闌尾炎併發症），未及修訂；原版十張墨跡由出版社持續印製，版權爭議（2020 年前後 Wikipedia 公開全部墨跡影像）反而引爆「常模是否被污染」的新爭論——一件心理工具竟能同時踩中智慧財產與測驗安全兩個現代議題。
- **測驗者的美德**：羅夏案最持久的教學價值在於定義了「什麼是好測驗」的反面清單：主觀計分、常模失修、機制不明、增量效度存疑。之後每一個新測驗（含神經心理與數位測驗）都在這份清單的陰影下受審。

## 關鍵人物與文獻

- **Hermann Rorschach**（1884–1922）：瑞士精神病學家；《Psychodiagnostiks》（1921），出版翌年即病逝，未及見證自己的測驗席捲世界。
- **Samuel Beck、Bruno Klopfer、Marguerite Hertz**：美國三大計分學派創建者（彼此不相容——危機根源之一）。
- **John E. Exner Jr.**：《The Rorschach: A Comprehensive System》（1974）。
