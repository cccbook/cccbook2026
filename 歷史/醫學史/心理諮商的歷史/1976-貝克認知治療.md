## 1976 - 貝克認知治療（治好病人之前，先讓病人的想法上法庭）

## 案件摘要

1976 年，Aaron T. Beck 出版《Cognitive Therapy and the Emotional Disorders》，為他自 1960 年代起在賓州大學發展的認知治療（CT）提出完整理論：憂鬱的核心不是無意識的性衝突，而是**負面認知三角**——對自己、世界、未來的系統性負面信念。治療的任務是把自動化思考當作假設，以蘇格拉底式提問與行為實驗加以檢驗。本篇追查：一個精神分析師如何用實驗「否證」了精神分析？認知三角的機制是什麼？以及 CBT 如何成為 21 世紀實證支持最強的治療體系？

## 前因 -- 為什麼會有這個案子

- **精神分析預測的失敗是兇手**：Beck 是受過完整訓練的精神分析師，最初設計實驗是想驗證「憂鬱是轉向自身的憤怒」。結果資料不合作：憂鬱者的夢比對照組**更少**敵意主題——假說被自己的實驗否證。
- **正面資料的反常**：他進一步發現憂鬱病人並非「痛苦被壓抑」，而是有一條持續運作的負面濾器：同一場會議，病人只記得自己講錯的那句話。這條「選擇性抽象」是認知模型的實驗室起點。
- **時代的方法論氣候**：1960 年代行為治療崛起（見《1958 - 沃爾普系統減敏》）、Meehl 的統計預測論（見《1943 - 明尼蘇達多相人格測驗》）與 DSM 的計量化轉向，都在懲罰不可檢驗的理論。Beck 選擇把「想法」變成可測量、可檢驗的變項。
- **臨床需求的縫隙**：精神分析太慢、行為治療對憂鬱無力、藥物（三環與 MAOI，見《藥物的歷史》）有副作用與復發問題——中間留著一塊無人認領的空地。

## 線索與推理 -- 數學式、程式、理論

認知模型的核心方程式：

$$ \text{情緒 C} = f(\text{對事件的解釋 B})，\quad \text{而非 } f(\text{事件本身}) $$

**認知三角**：憂鬱病人對三個對象持有系統性負面信念——自己（我沒價值）、世界（處處受挫）、未來（不會變好）。三者的交互鎖定構成憂鬱的認知迴路：

```python
def depression_loop(core_belief="我一無是處"):
    thoughts = {
        "自己": f"{core_belief}，這次失誤又證明了",
        "世界": "所有人都看得出我不行",
        "未來": "努力也沒用，不會好轉",
    }
    behavior = "退縮、放棄活動"
    consequence = "缺乏正向經驗 → 負面信念獲得更多「證據」"
    return thoughts, behavior, consequence

t, b, c = depression_loop()
for k, v in t.items(): print(f"{k}: {v}")
print("行為:", b); print("後果:", c)
# 負向信念 → 退縮行為 → 經驗匱乏 → 信念強化：自我封閉的迴路
```

治療就是把迴路剪開的兩把剪刀：

| 技術 | 操作 | 目標 |
|---|---|---|
| 蘇格拉底式提問 | 「這個想法的證據？有沒有相反證據？最壞會怎樣？」 | 鬆動自動化思考 |
| 行為實驗 | 預測「打電話一定被拒絕」→ 真的去打 → 記錄結果 | 以否證更新信念 |
| 活動排程與監控 | 記錄情緒與活動、排入可完成的任務 | 打破退縮迴路、累積反例 |
| 概念化層級 | 自動化思考 → 中間信念 → 核心信念（圖式） | 由表及裡，分層處理 |

分層結構：表層是瞬間冒出的**自動化思考**（「他一定覺得我很蠢」），中層是**假設／規則**（「如果我不完美，別人就會嫌棄我」），底層是早年形成的**核心信念／圖式**（「我不可愛」）。這讓 CT 既保留精神分析對深層結構的關注，又以可檢驗的方式處理它——Ellis 的哲學駁斥（見《1955 - 艾利斯理情療法》）在此被改造為實證假設檢驗，兩人並稱認知革命雙先鋒，卻長期隔空較勁。


### 深挖：Beck 的實驗室如何運作

- **憂鬱夢境實驗（1960s）**：Beck 與同事比對憂鬱病人與對照組的夢的敵意主題，發現憂鬱組**較少**——精神分析「憂鬱是內轉的憤怒」被否證。他在自傳中稱這是「我此生最誠實的時刻」：讓資料殺死自己深信的假說。
- **DAS 量表的誕生**：功能失調態度量表（Dysfunctional Attitudes Scale）把「規則／假設」層的信念變成可測量題目；與自動化思考紀錄表（DTR）配合，認知層級三層都有了量測儀器——理論的可檢驗性由工具保證。
- **手冊的誕生（1979）**：《Cognitive Therapy of Depression》逐次會談給出流程——這本書成為所有心理治療手冊的參考原型，也讓「治療師忠誠度」成為可稽核的變項。

### CBT 的效果量帳本

| 適應症 | CBT 對照組效果量（後設分析概略） | 備註 |
|---|---|---|
| 憂鬱症 | $ d \approx 0.7 $ | 與藥物相當，復發率較低 |
| 廣泛性焦慮 | $ d \approx 0.8{-}1.0 $ | 認知＋放鬆組合 |
| 恐慌症 | $ d \approx 0.9{-}1.2 $ | 內感性暴露是關鍵成分 |
| 強迫症 | ERP（暴露＋反應防止）為金標準 | 屬行為傳統 |
| 精神分裂症（CBTp） | $ d \approx 0.3{-}0.4 $ | 輔助性，非取代藥物 |

帳本的同時也要記下：效果量隨對照組強度下降（弱對照組膨脹效果量）、發表偏誤影響估計——CBT 的證據帝國同樣接受過審計，而它通過審計的方式（預註冊、對照組升級）正是 Beck 方法論遺產的延伸。

## 結案 -- 後果與影響

- **實證傳統的建立**：1977 年 Beck 團隊發表憂鬱症 CT 的對照試驗，1979 年《Cognitive Therapy of Depression》出版治療手冊——心理治療第一次擁有「手冊化＋RCT」的完整範式。其後數十年的後設分析把 CBT 對憂鬱與焦慮症的療效穩定落在 Cohen's $ d \approx 0.7{-}1.0 $ 的量級，CBT 成為實證支持最廣的治療品牌。
- **手冊化與指引制度**：Beck 範式催生了治療手冊、治療師忠誠度檢核與臨床指引——心理治療進入「證據等級」時代，也引發「手工藝 vs 標準化」的長期論戰。
- **與藥物的長期賽局**：CBT 的療效與藥物相當，而**復發率較低**（停藥後防護持續）——這成為認知模型正確性的間接證據，也改寫了憂鬱症治療的流程圖（見《藥物的歷史》）。
- **譜系的延續**：認知治療與行為技術合流為 CBT；1990 年代第三波（正念、ACT、DBT）把「改變信念」擴充為「改變與信念的關係」（見《1979 - 卡巴金正念減壓》《1993 - 林納翰辯證行為治療》）。Beck 的女兒 Judith Beck 接掌貝克認知行為治療研究所，使範式跨世代制度化。


### 結案之後：CBT 帝國的管理學

- **手冊化與忠誠度**：Beck 範式使心理治療第一次可以「品管」——手冊、治療師訓練、錄音評分（CBTS）。這套品管學被各國 NHS 與保險制度採用，CBT 因此成為制度最愛的治療：可稽核、可外包、可量產。
- **IAPT 的規模實驗**：英國 2008 年起的 IAPT（現 Talking Therapies）以 CBT 為主力，年服務逾百萬人次——史上最大規模的心理治療公共工程，結果：約一半病人「可靠改善」，也暴露了治療師倦怠與個別化的侷限。
- **Beck 家的長期主義**：Aaron Beck 活到 100 歲（2021 年辭世），晚年仍參與研究；Judith Beck 的教材與貝克研究所的訓練認證，使這個範式擁有心理治療界少見的傳承機構。理論會老，制度讓它不散架。
