# 醫療儀器的歷史：從兩片鏡片到達文西機器人——一部「看不見的身體如何被看見、聽見、量到、替代」的偵查史

> 本書以「推理探案」的體例，為醫療儀器史上的每個關鍵事件寫一篇 wiki：
> 當時醫生**看不到、聽不到、測不到、替代不了**什麼（謎題）？前因是什麼（背景與理論限制）？
> 發明如何發生（往往來自其他領域的跨界靈感：眼鏡工業、潛艦聲納、染料化學、唱片公司、國防科技）？
> 後果影響是什麼？背後的科學理論（光學、聲學、電生理、流體力學、X 光繞射、核磁共振、遙操作）是什麼？
> 每篇檔名以年份開頭（4 位數，負年以 `-` 開頭，西元前如 `-1590`）。

## 雙線主軸

| 線 | 演變 |
|---|---|
| **感知線（診斷儀器）** | 肉眼＋觸診 → 光學放大（顯微鏡）→ 聽與量（聽診器、體溫計、血壓計）→ 電生理（心電圖）→ 穿透與切片（X 光、CT）→ 磁與聲（MRI、超音波） |
| **介入與替代線（治療儀器）** | 伸進孔道（內視鏡）→ 進入心臟（心導管）→ 停跳與替代（人工心肺、人工腎臟、鐵肺、人工心臟）→ 縮小醫生的手（雷射、手術機器人） |

## 貫穿全書的偵查方法論（儀器史的六條規律）

1. **儀器先於問題而存在**。楊森父子造顯微鏡時沒有「微生物」這個問題；雷文霍克看見的東西要等 200 年才變成知識（見 `-1590`、`1676` 兩案）。
2. **跨界是常態**：眼鏡工坊→顯微鏡；吞劍師→胃鏡；潛艦聲納與鍋爐探傷→超音波；唱片公司→CT；軍事雷達→多種儀器；國防遙操作→手術機器人。
3. **瓶頸常是材料與光源，不是概念**：Bozzini 的光路 1806 年就對了，等的是電燈與光纖；Kolff 的透析原理 1913 年就知道了，等的是賽璐玢與肝素。
4. **每件偵查武器都有附帶傷害**：X 光技師的灼傷、CT 的劑量、人工心臟的血栓與感染、達文西的高費用——儀器的倫理審計與儀器本身同步成長。
5. **先驅常被制度碾壓**：Bozzini 遭醜聞打壓、福斯曼被譏為小丑、Damadian 錯失諾獎、Mary Gibbon 幾乎被隱名——功勞切分與制度承認是儀器史最難的終審。
6. **「正常值」是儀器的函數**：37 °C 的腋下基準、Hounsfield 標尺、Korotkoff 五階段——儀器不只看見身體，儀器定義了身體的「正常」。
