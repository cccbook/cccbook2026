## 1818 - 聽診器聽見胎心（兩千年來第一次「知道胎兒還活著」）

## 案件摘要

**本案偵破的是：在超音波誕生前 140 年，醫師如何解決一個比「看不見」更折磨人的問題——**聽不見**胎兒是否還活著。**

1818 年，法國里昂醫師凱爾加拉德克（Jacques-Alexandre Lejumeau de Kergaradec）在產婦腹部放上 Laennec 發明不久的木製聽筒，聽見了規則而快速的胎兒心跳、臍帶雜音與胎動音。他隨即寫信給 Laennec：「這是一個新世界。」1821/1822 年他在巴黎醫學院報告並出版《論以聽診器研究懷孕的脈搏》（Mémoire sur l'auscultation appliquée à l'étude de la grossesse）。本案的謎題：為什麼這麼明顯的方法——把聽筒貼上孕肚——此前兩千年無人想到？

## 前因 -- 為什麼會有這個案子

- **胎兒生死的判斷困境**。古代以來，判斷胎兒存活只有間接徵象：母親自覺胎動（16–20 週後才有）、腹圍增減、乳房變化。滯產時「胎兒已死」的誤判常導致放棄或提早碎胎——**誤殺活胎**。索拉努斯（見 `0100-索拉努斯論產婦疾病.md`）到斯梅利（見 `1751-斯梅利與產科手術化.md`）都只能以觸診與經驗賭生死。
- **法律困境**。胎兒死產/活產涉及繼承與殺嬰罪：活產證明（肺漂浮試驗）需屍檢，生前則無客觀證據。
- **1816 年 Laennec 的發明**。木製單耳聽筒（monaural stethoscope）在巴黎問世，1819 年出版《間接聽診法》，主要用於心肺疾病。
- **凱爾加拉德克與 Laennec 的私交**。他正是 Laennec 的同門好友，拿到聽筒後自然地「什麼都想聽」——包括孕婦的肚子（他先想聽胎兒的心音來估算孕周）。

## 線索與推理 -- 數學式、程式、理論

**線索一：心率的判別力。** 成人安靜心率約 60–80 bpm；胎兒心音約 120–160 bpm：

$$ f_{\text{胎兒}} \approx 2 \times f_{\text{母親}} \quad \Rightarrow \quad \text{腹部規則音源可被唯一歸屬於胎兒} $$

頻率與母親脈搏的倍差，使「聽見」即可判死活——這是判別式，不需要更多理論。

**線索二：三種音的鑑識清單。** 凱爾加拉德克區分：(1) 胎心音（快速、如懷錶滴答）；(2) 臍帶雜音（umbilical souffle，與胎心同步的吹風音）；(3) 子宮胎盤雜音（與母親脈搏同步）。**同步對象**是歸屬音源的鑰識：與母脈同步＝母方血流；與胎心同步＝胎方。

**線索三：臨床決策樹的翻轉。**

```python
def delivery_decision(fetal_heart_audible, obstructed_labour):
    if fetal_heart_audible:
        return "胎兒存活 → 嘗試旋轉/產鉗/等待, 禁止碎胎"
    else:
        return "持續聽不到 >30 分鐘 → 才考慮放棄性介入"
# 1818 之前: 無法聽診 → 依『胎動消失+腹痛史』猜測 → 活胎被碎胎的冤案
# 1818 之後: 聽診成為否決權: 只要聽得見, 就不准放棄
```

**線索四：孕周估算的新標尺。** 胎心首次聽見的平均孕周（約 18–20 週）成為核對經期記憶的獨立證據——「懷孕第幾週」第一次有了生理計時器（後由超音波接棒，見 `1958-超音波首窺胎兒.md`）。

## 結案 -- 後果與影響

- **碎胎術的倫理崩塌**。1818 年後，「聽不到胎心」成為碎胎的前置證明；活胎誤殺率大幅下降——一件 2.5 公分的木筒改寫了產科倫理。
- **胎心監護的長鏈起點**。1821 凱爾加拉德克聽診 → 1893 Winkel 校準胎心正常值 → 1958 Edward Hon 超音波多普勒胎心監護 → 1960s CTG 產時連續監護：一條 140 年的技術鏈，源頭是這一次偶然的聆聽。
- **「胎兒是病人」的哲學起點**。當胎兒擁有可被監測的自主生理訊號，「母—子雙病人」的產科框架誕生；胎兒治療學（宮內輸血、胎兒手術）皆以此為前提。
- **陰影面**。聽診靈敏度有限（肥胖、羊水多、胎位背側皆易漏聽）；20 世紀 CTG 的過度判讀又造成剖腹產潮——「聽見」帶來的干預衝動，是每一代監測技術都要重付的學費。
- **一句話結案**：婦產科史上第一次感官革命不是「看見」而是「聽見」——**活著的證明，比長什麼樣更先到達**。
