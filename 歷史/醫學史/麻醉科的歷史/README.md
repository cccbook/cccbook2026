# 麻醉科的歷史：從曼陀羅與麻沸散、乙醚日、氯仿論戰、箭毒革命，到無創監測與意識科學

> 本書以「推理探案」的體例，為麻醉史上的每個關鍵事件寫一篇 wiki：
> 謎題是什麼（手術之痛如何被馴服）？偵探是誰（草藥師、化學家、牙醫、麻醉醫生、工程師）？
> 線索與推理是什麼（分子結構、離子通道、閘門學說、分配係數、腦電）？
> 每篇檔名以年份開頭（4 位數，負年以 `-` 開頭，西元前年份補零如 `-0157`）。

## 雙線主軸

| 線 | 演變 |
|---|---|
| **藥理技術線** | 草藥（鴉片/曼陀羅）→ 氣體（笑氣/乙醚/氯仿）→ 局部麻醉（可卡因/普魯卡因）→ 靜脈藥（巴比妥/丙泊酚）→ 肌鬆劑 → 鹵化吸入藥 → 全靜脈與靶控輸注 |
| **安全監測線** | 手感與讀表（格德爾分期）→ 無菌與死亡率稽核 → 無創監測（SpO₂/EtCO₂）→ 麻醉深度腦電（BIS）→ 閉環麻醉與意識科學 |
