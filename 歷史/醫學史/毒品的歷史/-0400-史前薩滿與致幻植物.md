## -0400 - 史前薩滿與致幻植物（藥與毒的第一筆帳）

## 案件摘要

**本案的兇手不在人間，而在一朵蘑菇裡。**

人類使用改變心智物質的歷史，遠早於文字。考古證據顯示：北非 Tassili n'Ajjer 岩畫（約前 7000–前 4000）描繪持蘑菇的舞者；秘魯的 San Pedro 仙人掌殘骸可溯至前 6000 年；西伯利亞遺址中的毒蠅鵝膏菌與馴鹿尿祭祀；希臘厄琉息斯秘儀的「Kykeon」聖飲（可能含麥角生物鹼）。到前 400 年前後，《奧義書》中的蘇摩、《波斯古經》中的 Haoma、斯基泰人的大麻蒸氣帳（希羅多德親筆記載），已把「致幻物＝通往神界的門票」寫成制度。本案要偵查的是：為什麼幾乎所有早期文明，都獨立發現並神聖化了同一批植物？

## 前因 -- 為什麼會有這個案子

- **覓食風險的自然篩選**。人類祖先在森林草原間遷徙，辨認可食植物是生死問題。誤食毒物致幻、致死的經驗，必然累積成口傳知識；而「小劑量致幻、大劑量致死」的物質（鵝膏菌、曼陀羅、仙人掌鹼）會被特別記住——因為效果太戲劇化。
- **薩滿的職業需求**。早期社會需要有人「去別的世界出差」：求雨、問病、尋找獵物、安撫亡魂。致幻植物是薩滿的工具，也是其權威的來源——能控制稀有體驗的人，就控制了解釋世界的權力。
- **疼痛與疲勞的實用面**。古柯葉在安地斯、檳榔在東南亞、卡特葉在東非，都是勞動者的高地藥：抑制食慾、抗疲勞、耐寒。這些「工作藥物」與「宗教藥物」的分界，從一開始就模糊。
- **文字前的證據鏈**：考古學靠三種物證——植物殘骸（種子、花粉）、藝術描繪（岩畫、陶器紋樣）、人骨殘留（牙結石中的生物鹼分子）。三者相互印證，才能拼出史前的用藥地圖。

## 線索與推理 -- 數學式、程式、理論

為什麼人腦會被這些植物「擊中」？現代神經科學給出的答案是**分子擬態**（molecular mimicry）：植物鹼與哺乳動物自身的神經傳導物質結構相似，能直接打開腦中的鎖。

| 植物鹼 | 類似的內源性物質 | 作用的受體 |
|---|---|---|
| 嗎啡（鴉片） | 腦內啡（endorphin） | μ-鴉片受體 |
| 古柯鹼 | 無直接對應（阻斷回收） | 多巴胺/血清素轉運體 |
| 裸蓋菇素 | 血清素（5-HT） | 5-HT2A 受體 |
| 麥角酸（LSD 前身） | 血清素 | 5-HT2A 受體 |
| 大麻素 | anandamide（內生大麻素） | CB1 受體 |
| 菸鹼 | 乙醯膽鹼 | nACh 受體 |

換句話說，腦裡本來就有一整套「快樂與感知的鎖」，植物的鑰匙只是恰好相容。演化上這不是巧合——植物合成生物鹼本是防蟲武器，而人類神經系統的受體保守性讓這些武器意外地對我們也有效。

```python
# 薩滿社會的「稀有體驗壟斷」模型
class Shaman:
    def __init__(self):
        self.knowledge = 1.0   # 對植物劑量與風險的知識
        self.authority = 0.2
    def ritual(self, dose, tribe):
        if dose < self.lethal_threshold * self.knowledge:
            tribe.awe += 0.5
            self.authority += 0.1   # 成功的儀式累積權威
        else:
            self.authority = 0      # 出人命則權威歸零
```

這個玩具模型點出歷史的關鍵：**劑量知識本身就是權力**。薩滿之所以能世代壟斷致幻植物，靠的是代代相傳的「安全窗」數據——多少劑量產生幻覺、多少致死。希羅多德記載斯基泰人在小帳棚中把大麻籽撒在燒紅的石頭上吸入蒸氣「歡呼雀躍」，這正是劑量工程：透過蒸氣（而非口服）控制攝取速度。

$ \text{到達腦中速率} = \frac{\text{吸收面積} \times \text{濃度梯度}}{\text{血腦障壁阻力}} $

吸食與蒸氣吸入繞過肝臟首過代謝，血中濃度數秒內達峰——這也是為什麼後來的菸草、古柯鹼（鼻吸）、芬太尼（靜脈）都選擇「加速路徑」：**藥物越快進腦，主觀衝擊越大，成癮潛力越高**（見 `1805-嗎啡分離與注射時代.md`）。

## 結案 -- 後果與影響

- **神聖化與污名化的雙生**。致幻植物既是神賜（蘇摩、Pejote、Teonanácatl），也是異端的印記——這條「神聖/邪惡」的雙重標準，將貫穿整本書：中世紀的巫術藥膏（`1486-巫術藥膏與顛茄.md`）、1960 年代的迷藥恐慌（`1967-愛之夏與迷藥文化.md`）、到今天的迷幻藥醫療復興（`2018-迷幻藥醫療復興.md`）。
- **貿易網的史前原型**。前 2000 年起，乳香、沒藥、鴉片的遠距貿易已出現在美索不達米亞—埃及航線；鴉片在賽普勒斯青銅器時代陶器中被檢出。毒品貿易是人類最古老的長程貿易之一。
- **藥食同源的知識體系**。前 1550 年的《埃伯斯紙草》已記載鴉片鎮咳止痛；前 1 世紀的《神農本草經》列大麻為上品藥。藥與毒的界線，從第一頁就由「劑量」而非「本質」決定——Paracelsus 在 1500 年後說「萬物皆毒，無毒之物不存在，劑量決定毒與藥」，只是把史前的默會知識說出了口。
- **一句話結案**：人類不是「發明」了毒品，而是被植物的化學武器射中了腦中已有的鎖；此後五千年的歷史，就是各文明不斷重新劃定「這把鑰匙歸誰用、何時用、以何名義用」的鬥爭史。
