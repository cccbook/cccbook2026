## 1964 - 美沙酮維持療法（把「戒斷」改成「維持」的醫學革命）

## 案件摘要

**本案的兇手，是一個反直覺的治療觀念：不戒，才是治療。**

1964 年，洛克斐勒大學的 Vincent Dole 與 Marie Nyswander 在紐約展開實驗：給長期海洛因成癮者每日口服合成鴉片美沙酮（methadone），維持穩定血中濃度，不追求「戒斷」。結果驚人：受試者的非法用藥、犯罪、失業率大幅下降，社會功能恢復——這是史上第一次以嚴格研究證明「鴉片成癮可以像糖尿病一樣以維持治療管理」。此療法至今是全球鴉片類成癮治療的支柱之一（與丁丙諾啡並列），但爭議從第一天持續到今天：「以毒攻毒」還是「合法上癮」？

## 前因 -- 為什麼會有這個案子

- **成癮的臨床絕望**。哈里森法案後 50 年，美國對海洛因成癮沒有任何有效治療：Lexington 的短期戒斷復發率高達 90% 以上——「戒斷了又回去」是規則，不是例外。
- **戰後海洛因流行**。1950 年代紐約黑市海洛因氾濫，青少年成癮與犯罪問題使政策圈絕望，也在尋找「醫學解方」的政治動力。
- **Dole 的轉向**。內科代謝學家 Dole 原本研究肥胖，被 Lexington 的一位病人（成癮研究者之友）說服：「成癮是代謝疾病，需要像糖尿病一樣長期管理」——這個類比成為美沙酮的理論基礎。
- **Nyswander 的臨床視角**。精神科醫師 Nyswander 已為成癮者看診多年，堅持「成癮者不是道德失敗者，是需要醫療的病人」——她提供了臨床場域與倫理堅持。

## 線索與推理 -- 數學式、程式、理論

美沙酮為何「維持」有效？答案在**藥物動力學的形狀**：

| 參數 | 海洛因 | 美沙酮 |
|---|---|---|
| 半衰期 | 3–8 分鐘（母體）→ 嗎啡 2–3 小時 | 24–36 小時 |
| 給藥 | 靜脈/鼻吸（峰值劇烈） | 口服，每日一次 |
| 血中濃度 | 峰谷劇烈 | 穩定平台 |
| 主觀效應 | 強烈欣快 | 「正常感」，無欣快 |

$ \text{渴求強度} \propto \text{血中濃度的谷值落差} \quad \text{(峰谷落差越大, 強迫性補藥越強)} $

```python
def methadone_logic():
    # 穩定濃度 → μ受體持續部分占據
    # 1. 阻斷海洛因帶來的「額外高峰」(交叉耐受)
    # 2. 消除戒斷 → 消除「為了不難受而用」的動機
    # 3. 消除峰值 → 消除「為了爽而用」的動機
    # 4. 口服+門診監督 → 給藥路徑回到「慢速」
    return "把成癮的生理引擎從峰值模式調成怠速模式"
```

第二層推理是**行為經濟學**：成癮的核心是「即時小酬賞壓倒延遲大酬賞」（延遲折扣）。美沙酮不提供高峰，但提供「每天穩定、免費、不用犯罪」的確定性——這讓病人第一次有足夠的認知頻寬去工作、治療、重建關係。**維持治療不是給快樂，是移除痛苦，從而把選擇權還給病人。**

Dole 與 Nyswander 的原始論文（*JAMA*, 1966）追蹤 6 個月以上，非法用藥率從近 100% 降至個位數——這在當時的成癮治療文獻中無可匹敵。

## 結案 -- 後果與影響

- **全球制度化**。1970 年代起美、港、澳、歐陸推廣；WHO 認可為基本治療；香港的美沙酮門診（1972 年起）是亞洲減害的先聲。
- **持續的文化抵抗**。「把政府變成毒販」的批評使美沙酮門診在美國長期供不應求（排隊數月）、地理上遠離貧民區——治療的瓶頸從來不是科學，是政治。
- **第二代維持藥物**。丁丙諾啡（buprenorphine，部分激動劑，2002 年 FDA 批准門診處方）降低過量風險，把維持治療從專門門診帶進基層診所——本篇理論的直接延伸。
- **模型之爭的仲裁**。美沙酮的成效成為「疾病模型」最強的實證證據之一（見 `1935-成癮醫學誕生.md`）——如果成癮是意志問題，維持治療不可能有效。
- **一句話結案**：Dole 與 Nyswander 的洞見是：成癮的敵人不是鴉片，而是「峰谷劇烈的鴉片濃度曲線」——把曲線拉平，人就能活。
