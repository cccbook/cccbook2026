## -0150 - 鴉片：從神藥到萬靈丹的古代醫療（罌粟汁的第一筆處方）

## 案件摘要

**本案的兇器，是一朵罌粟花割開後流出的白色淚水。**

鴉片是最早被系統性用作藥物的成癮物質。前 3400 年的蘇美泥板稱罌粟為 Hul Gil（「快樂植物」）；前 1550 年《埃伯斯紙草》把鴉片列為小兒鎮靜劑；希臘醫學把它編入正典——蓋倫稱其為「最強的鎮痛藥」，並坦承皇帝馬可·奧勒留每日服用鴉片蜜酒（theriac）。到前 2–1 世紀，《神農本草經》尚未收錄鴉片，但印度阿育吠陀文獻已把鴉片列入；托勒密時代的賽普勒斯「罌粟室」（opium rooms）被考古發掘。本案追蹤：一種止痛聖藥，如何在兩千年前就被記錄下「依賴」的陰影？

## 前因 -- 為什麼會有這個案子

- **前現代醫學的鎮痛真空**。在人類史上的絕大多數時間，疼痛沒有任何有效治療。外傷、結石、牙痛、末期病痛——醫生能做的只有忍耐或祈禱。鴉片是唯一的例外，這決定了它的地位：**不是因為它完美，而是因為它是唯一的**。
- **theriac（底野迦）傳統**。源自 Mithridates VI 國王的「萬毒解藥」配方，經 Nero 的御醫 Andromachus 改良，含數十種成分、鴉片為主力。羅馬官方以國家規模生產 theriac，配發軍隊與官員——這是史上第一個「國家級鴉片配給制度」。
- **小兒鎮靜劑的黑暗常規**。古代至 20 世紀初，「soothing syrups」（含鴉片的嬰兒糖漿）讓哭鬧嬰兒安睡，家長視為恩物——鴉片嬰兒猝死的紀錄層出不窮，但没人把死因歸給糖漿。
- **蓋倫的坦白**。蓋倫記錄馬可·奧勒留服用 theriac「蛇毒解藥」每晚飲用，並辯稱此為防止毒殺之必需——皇帝本人也曾在信中抱怨睡眠需賴藥物。古代醫學家並非沒有察覺依賴現象，只是沒有概念工具去命名它。

## 線索與推理 -- 數學式、程式、理論

鴉片為何止痛如此有效？答案是身體自有一套「內建鎮痛系統」，而鴉片直接劫持它。

1970 年代，Candace Pert 與 Solomon Snyder 發現鴉片受體（μ、δ、κ），隨後 John Hughes 與 Hans Kosterlitz 找到腦內的內源性配體——腦內啡（endorphin）。這解釋了兩千年之謎：

$ \text{嗎啡} + \mu\text{-受體} \rightarrow \text{抑制 } \mathrm{Ca}^{2+} \text{ 內流} \rightarrow \text{脊髓背角痛覺訊號衰減} $

```python
# 為何止痛藥會「上癮」：同一把鎖的兩個房間
def morphine_effect(mu_receptors):
    analgesia = mu_receptors.periaqueductal_gray   # 導水管周灰質: 鎮痛
    euphoria   = mu_receptors.ventral_tegmentum    # 腹側被蓋區: 愉悅(多巴胺↑)
    breathing  = mu_receptors.medulla              # 延髓: 呼吸抑制(致命)
    return analgesia, euphoria, breathing
# 三種效應共用同一受體 → 想要止痛就必須接受愉悅與呼吸風險
```

古代醫者觀察到的臨床事實（今日語言）：鎮痛、欣快、便祕、瞳孔縮小、呼吸抑制、耐受性（越用越多）、戒斷（腹瀉、雞皮疙瘩、骨痛）。羅馬文獻已描述「非 theriac 不可者」——這是**依賴**的臨床描述，但古代醫學把它理解為體質問題或意志問題，而非藥理學現象。

$ \text{耐受性: } ED_{50}(t) = ED_{50}(0) \cdot e^{k \cdot n} $

其中 $n$ 為用藥次數。受體脫敏（磷酸化、內吞）與代償性上行（腺苷酸環化酶反彈）使得同樣劑量效果遞減——這就是蓋倫時代「有人越喝越多」的機制，只是要到 1800 年後才被寫成方程式。

## 結案 -- 後果與影響

- **醫學正典化**。鴉片從薩滿的私有知識，變成蓋倫醫學的標準處方，隨阿拉伯醫學（Avicenna《醫典》專章論鴉片）傳遍伊斯蘭世界與歐洲。「罌粟是上帝的恩賜」成為醫學格言一千五百年。
- **貿易與帝國**。小亞細亞、波斯、埃及成為鴉片產區；阿拉伯商人把鴉片帶到印度、中國（唐代經絲路傳入，宋代有「罌粟粥」食俗）。這條貿易線是後來 19 世紀鴉片戰爭（`1839-鴉片戰爭.md`）的物流基礎。
- **未解的陰影**。古代醫學對鴉片依賴的紀錄零星且邊緣化——直到工業化時代，嗎啡分離（`1805-嗎啡分離與注射時代.md`）與皮下注射器讓依賴問題以千倍速度放大，「藥物成癮」才被逼成一門科學。
- **一句話結案**：鴉片在人類醫學中站穩腳跟，靠的是一個殘酷事實——在兩千年的時間裡，它是唯一能止痛的東西；成癮的代價，古代世界選擇了不看。
