## 1984 - 納曲酮上市（把「欣快」上鎖的分子）

## 案件摘要

**本案的兇手，是一個「佔了位子卻不給快樂」的分子。**

1984 年，FDA 批准納曲酮（naltrexone）用於鴉片類依賴的預防復發——這是第一個「拮抗劑」型戒毒藥：它與 μ-受體結合極強，卻幾乎不激活受體（低內在活性），等於把鎖孔堵死。使用者若再使用海洛因，感覺不到欣快——分子層面的「封鎖」。1994 年再被批准用於酒精依賴（口服）、2010 年長效注射劑（Vivitrol）問世。本案偵查：為什麼一個藥理上近乎完美的設計，臨床採用率卻長期低迷？

## 前因 -- 為什麼會有這個案子

- **受體理論的成熟**。1973 年 Pert 與 Snyder 發現鴉片受體後，藥廠第一次可以「設計」受體配體，而不是從罌粟裡碰運氣。
- **納洛酮的前身**。1961 年合成的納洛酮（naloxone）是短效純拮抗劑，用於急救逆轉過量——它的長效版本就是納曲酮（1963 年合成，Endo Labs，Blumberg 研究）。
- **維持療法爭議的產物**。美沙酮「以鴉片治鴉片」的政治爭議（見 `1964-美沙酮維持療法.md`）創造了市場需求：「一種讓人完全不碰鴉片的藥」在政治上無懈可擊。
- **動物模型的支撐**。自給藥實驗顯示：預先給拮抗劑，動物不再自給鴉片——受體阻斷假說獲得操作性行為的驗證。

## 線索與推理 -- 數學式、程式、理論

$ \text{納曲酮} + \mu\text{-受體} \xrightarrow{K_i \approx 0.1\,nM} \text{長期占據, 內在活性} \approx 0 $

$ \text{海洛因到腦} \rightarrow \text{無空位可占} \rightarrow \text{無欣快} \rightarrow \text{強化學習被切斷} $

```python
# 納曲酮的悖論: 藥理完美, 臨床冷清
def naltrexone_paradox():
    strengths = ["半衰期長(口服約4-13h, 注射劑30天)",
                 "無濫用潛力", "無生理戒斷", "政治上完美"]
    failures = {
        "留置率": "口服劑型3個月留置率常<20%",
        "原因1": "啟動需先戒斷7-10天(否則誘發劇烈戒斷)",
        "原因2": "無法給快樂 → 病人沒有『服藥動機』",
        "原因3": "渴求與環境觸發不因受體封鎖而消失",
    }
    return strengths, failures
# 對照: 美沙酮/丁丙諾啡留置率常 >60% —— 給「正常感」的藥留得住人
```

關鍵推理：**治療黏著度由「病人主觀獲得什麼」決定，而非藥理優雅度**。納曲酮是「阻斷型」：它的效果是負向的（吸了也沒用），病人必須先熬過戒斷、再忍受無酬賞的日常——這對動機已耗竭的成癮者門檻極高。美沙酮是「替代型」：每天給「正常」，病人有理由來。兩者並非優劣，而是匹配不同病人（住院後的高動機者 vs 門診的長期維持者）——2010 年代的比較研究（NEJM 等）正是這場「激動劑 vs 拮抗劑」之爭的收網。

1994 年的酒精適應症則另有機理：納曲酮阻斷飲酒的內源性腦內啡酬賞，使「一杯的快感」下降——臨床上最有效的用法是 Sinclair 法（喝前服藥，逐步「藥理消退」飲酒動機）——同一受體邏輯，應用在不同酬賞通路。

## 結案 -- 後果與影響

- **戒毒藥物的三角格局確立**。美沙酮（完全激動劑）、丁丙諾啡（部分激動劑）、納曲酮（拮抗劑）——今日鴉片類成癮治療的三大支柱在 1984–2002 年間全部到位。
- **過量逆轉的基礎**。納洛酮（納曲酮的短效表親）在 2010 年代芬太尼危機（`2016-芬太尼危機.md`）中成為救命的公共衛生工具，非醫療人員配發合法化——拮抗劑從「戒毒藥」變成「急救藥」。
- **政治化的治療選擇**。美國部分司法系統強制 Vivitrol（拒絕美沙酮的「無濫用」選項）——藥理學被道德偏好扭曲成處方政治。
- **一句話結案**：納曲酮證明了毒理學能設計出「不快樂的鎖」，也證明了：成癮治療的成敗不在分子鎖得多牢，而在病人是否願意每天回來。
