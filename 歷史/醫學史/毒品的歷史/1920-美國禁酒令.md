## 1920 - 美國禁酒令（史上最大規模的物質管制實驗）

## 案件摘要

**本案的兇器，是憲法第 18 修正案——人類唯一一次把一種日常物質寫進憲法禁止。**

1920 年 1 月 17 日，美國全國禁酒（Volstead Act 執行第 18 修正案）：製造、販售、運輸酒類聯邦級非法。13 年後的 1933 年，第 21 修正案把它廢除——這是憲法史上唯一一次修正案廢除修正案。期間：私酒（bootlegging）、地下酒吧（speakeasy）、有組織犯罪（Capone 的芝加哥帝國年入數千萬美元）、工業酒精中毒死亡（僅 1927 年紐約就有約 700 人死於變性酒精）、執法腐敗。本案偵查：禁酒令「失敗」了嗎？它教給毒品政策的是什麼？

## 前因 -- 為什麼會有這個案子

- **人均消費的歷史高峰**。19 世紀美國人均純酒精消費量約 7 加侖/年（今日約 2.3），酗酒、家暴、工傷是社會危機。
- **百年運動的積累**。WCTU（1874）、Anti-Saloon League（1893）把禁酒從道德運動做成政治機器；一次大戰「節約穀物」成為臨門一腳。
- **啤酒的族群政治**。德裔啤酒商與愛爾蘭、義大利工人階級的酒館文化，被新教中產視為「他者的罪惡」——禁酒也有種族與階級的潛台詞。
- **婦女參政的聯盟**。婦女是酗酒暴力的直接受害者，參政權（1920）與禁酒互為犄角。

## 線索與推理 -- 數學式、程式、理論

本案提供了**毒品政策數學**的第一手數據：

$ \text{傷害總量} = \underbrace{(\text{消費量} \times \text{單位傷害})}_{\text{藥物傷害}} + \underbrace{(\text{管制強度} \times \text{黑市成本})}_{\text{管制傷害}} $

```python
# 禁酒令的損益表
def prohibition_scorecard():
    wins = {
        "人均酒精消費": "下降約 50-70% (戰前 7 加侖 → 1930s 約 1.5-2)",
        "肝硬化死亡率": "下降約 40%",
        "精神病院酒精中毒入院": "大幅下降",
    }
    losses = {
        "有組織犯罪": "從地方幫派升級為跨州企業",
        "執法腐敗": "警局、海關、司法系統被滲透",
        "酒精毒性": "私酒(甲醇、工業變性酒精)致死上升",
        "稅收": "聯邦年損失約 5 億美元(當時天文數字)",
    }
    return wins, losses
```

關鍵推理：**禁令對「重度飲酒」有效、對「社交飲酒」失效**。飲酒文化深植的社會，禁令把市場推向黑市；黑市沒有品質管制（甲醇混酒）、沒有年齡限制（青少年更好買）、沒有爭議解決機制（暴力取代法律）。但數據同時顯示：肝硬化死亡率確實在禁酒期下降——**禁令不是零效果，而是「效果與副作用」同時巨大**。

這套損益邏輯直接套用到今日的毒品政策辯論：鴉片類（`1839-鴉片戰爭.md`）、大麻（`2012-大麻合法化.md`）、乃至芬太尼時代的處方藥管制，都在計算同一條曲線的兩端。

## 結案 -- 後果與影響

- **「可管制，不可根除」的教訓**。禁酒令的失敗不等於「物質管制無用」——它證明的是：當消費文化夠深，刑法供給側管制會催生黑市經濟，而黑市的傷害可能超過原物質。
- **有組織犯罪的資本累積**。Capone 等私酒帝國為戰後毒品走私（海洛因、古柯鹼）提供了網路、資金與人才——美國毒品黑市的組織架構是禁酒令的直接遺產。
- **酒稅制度的重生**。1933 年廢除後，美國以「管制＋課稅＋年齡限制」取代全面禁止——這個「合法化後的規制工具箱」是 21 世紀大麻合法化的藍本。
- **AA 的誕生土壤**。禁酒時代的酗酒者私下互助小組，是 1935 年嗜酒者互誡協會（AA）的前身——物質管制實驗的失敗，意外催生了成癮康復運動（見 `1935-成癮醫學誕生.md`）。
- **一句話結案**：禁酒令證明刑法可以壓低消費、卻無法消滅需求——而黑市是不會簽署品質保證書的供應商。
