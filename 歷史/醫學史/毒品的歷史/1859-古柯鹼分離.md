## 1859 - 古柯鹼分離（安地斯的葉子，被提煉成白粉）

## 案件摘要

**本案的兇手，是一位博士候選人的論文實驗。**

1859 年，Göttingen 大學博士生 Albert Niemann 在 Friedrich Wöhler 實驗室從古柯葉中分離出生物鹼，撰寫博士論文《Über Coca》並首次描述其「使舌頭麻木」的特性——古柯鹼（cocaine）正式問世。1863 年 Angelo Mariani 推出「Vin Mariani」（古柯紅酒）風靡歐洲；1886 年 John Pemberton 調出可口可樂（含古柯鹼至 1903 年）。從安地斯原住民嚼了數千年的葉子，到 19 世紀末的歐美專利藥物，古柯鹼只用了三十年就完成「純化→商品化→濫用」的全程。本案偵查：為什麼提純會把一種溫和的傳統植物，變成一種危險毒品？

## 前因 -- 為什麼會有這個案子

- **古柯葉的傳統角色**。安地斯農民與礦工嚼古柯葉（混石灰）以抗高海拔、抑制飢餓；釋放速度慢、劑量低（約 30–50 mg 古柯鹼/小時），社會上被儀式與集體規範約束——這是一個「低劑量、慢吸收、有文化框架」的系統。
- **純化改變了一切**。每片葉只含約 0.25–1% 古柯鹼；提純把 100 片葉子濃縮成幾百毫克白粉，可鼻吸、可注射——血藥濃度上升斜率從「小時級」變成「分鐘級」。
- **19 世紀的醫學時尚**。古柯鹼被試用於嗎啡戒斷（Freud 是推手之一）、酒精中毒、憂鬱、疲勞——當時醫界正苦於嗎啡癮流行（見 `1805-嗎啡分離與注射時代.md`），古柯鹼以「解藥」身份登場。
- **麻醉學的意外收穫**。1884 年 Carl Koller 證明古柯鹼是局部麻醉劑，眼科手術從此革命——這是古柯鹼真正的醫學遺產（後來由普魯卡因、利多卡因等合成替代品繼承）。

## 線索與推理 -- 數學式、程式、理論

古柯鹼的藥理是**單胺轉運體阻斷**——它堵塞多巴胺、正腎上腺素、血清素的回收幫浦（DAT、NET、SERT）：

$ \text{古柯鹼} + \text{DAT} \rightarrow \text{回收受阻} \rightarrow \text{突觸間隙多巴胺濃度} \uparrow\uparrow $

```python
# 為何古柯鹼的成癮潛力遠超古柯葉
def coca_vs_cocaine(absorption_minutes, dose_mg):
    peak_speed = 1 / absorption_minutes
    return peak_speed * dose_mg
print(coca_vs_cocaine(45, 40))   # 嚼葉: 慢、低 → 溫和提神
print(coca_vs_cocaine(3,  100))  # 鼻吸: 快、高 → 強化藥物
# 同一分子, 血藥動力學差一個數量級 → 文化約束瞬間失效
```

關鍵推理：嚼古柯葉時，多巴胺系統接收的是「緩慢滴灌」；鼻吸純古柯鹼是「洪水衝擊」。VTA–伏隔核的多巴胺酬賞通路被快速灌滿，大腦的學習系統把「這個動作→這種感覺」寫成最高優先級記憶（**敏化, sensitization**）——此後該線索（白粉、吸管、特定朋友）足以引爆渴求。安地斯的文化規範能約束慢速系統，卻對快速系統毫無辦法——**文化只對它演習過的劑量節奏有效**。

## 結案 -- 後果與影響

- **專利藥物時代的爆款**。Vin Mariani 被教宗、愛迪生、柯南·道爾代言；可口可樂（1886）至 1903 年去除古柯鹼——古柯鹼是第一個靠大眾行銷走紅的純化毒品。
- **Freud 的教訓**。1884 年佛洛伊德發表《Über Coca》讚譽其為萬靈藥，並推薦給摯友 Fleischl-Marxow 戒嗎啡——後者以古柯鹼取代嗎啡，劑量失控而亡。佛洛伊德迅速撤回推薦，此案成為醫學史上「以新藥解舊藥」反覆失敗的經典（見 `1884-佛洛伊德與可卡因.md`）。
- **1914 年後的定罪**。美國《哈里森法案》把古柯鹼列為管制物質；1910 年代媒體把古柯鹼與「南方黑人男性犯罪」的種族恐慌連結，加速立法——毒品管制的政治，從一開始就混合了公共衛生與種族偏見。
- **現代走私經濟**。1980 年代起哥倫比亞可卡因集團（Medellín、Cali）、快克可卡因（crack, 1980s）、以及今天的全球可卡因市場——純化的白粉成為跨國犯罪經濟的支柱，監獄人口與暴力犯罪的结构性驅動。
- **一句話結案**：古柯葉裝在葉子裡是文化，裝在瓶子裡是商品，裝在鼻子裡是流行病——改變的不是分子，是濃縮程度與給藥速度。
