## 1884 - 佛洛伊德與可卡因（一位天才的處方錯誤）

## 案件摘要

**本案的兇手，是一篇熱情過頭的藥理評論。**

1884 年，28 歲的維也納神經學家 Sigmund Freud 讀到美軍軍醫 W. H. Bentley 對古柯鹼的報告後，自服並發表《Über Coca》（論古柯），稱之為「神奇物質」：可治憂鬱、消化不良、嗎啡癮、酒精中毒。他寄古柯鹼給好友 Ernst von Fleischl-Marxow——一位因截肢感染而嗎啡成癮的生理學家。結果 Fleischl 把嗎啡癮換成了古柯鹼癮，劑量失控（每日約 1 克），一年後死亡。佛洛伊德迅速停止公開推薦，此案成為他一生最尷尬的科學錯誤，也成為醫學倫理與成癮藥理的教科書案例。

## 前因 -- 為什麼會有這個案子

- **嗎啡癮的時代焦慮**。1853 年注射器問世後，歐美醫界苦於「嗎啡病」流行（見 `1805-嗎啡分離與注射時代.md`），急切尋找「不成癮的替代」——這種迫切讓醫學判斷力降低。
- **Bentley 的軍醫報告**。1876–1880 年 Bentley 報告用古柯鹼治療「菸草癮」與工兵疲勞，宣稱效果良好且無成癮——個案觀察被誤讀為系統證據。
- **Freud 的個人處境**。年輕、經濟困窘、渴望學術名聲、未婚妻分隔兩地——他自己每天服用古柯鹼提神、寫信給未婚妻「親愛的可卡小姐」。他的熱情不是純科學，也掺雜了個人經驗與事業焦慮。
- **Koller 的搶先**。1884 年 Freud 的同事 Carl Koller 聽了他的描述後，證明古柯鹼為局部麻醉劑，一夕成名——「古柯鹼之父」的名聲旁落，加重了 Freud 的失落（也間接推動他轉向心理學）。

## 線索與推理 -- 數學式、程式、理論

本案的推理核心：**為什麼「替代療法」在成癮上會失敗？**

古柯鹼與嗎啡作用於不同系統（DAT 阻斷 vs μ-受體激動），生理依賴性質不同——但兩者都直接衝擊多巴胺酬賞通路。把病人從一種強效酬賞藥換到另一種，等於讓大腦的酬賞學習系統繼續高速運轉：

$ \text{戒斷}(\text{藥A}) + \text{強化}(\text{藥B}) \neq \text{康復} \quad \Rightarrow \quad \text{只產生雙重依賴} $

```python
def substitution_without_maintenance(patient, new_drug):
    # 成功的替代治療(如美沙酮)需要: 長半衰期+穩定血藥濃度+口服+醫療監督
    # 古柯鹼恰恰相反: 短半衰期+峰谷劇烈+鼻吸/注射+無監督
    risks = []
    if new_drug.half_life < 2:  risks.append("峰谷劇烈→強迫性補藥")
    if new_drug.route == "IV/nasal": risks.append("快速到腦→敏化")
    if not new_drug.medical_supervision: risks.append("劑量無上限")
    return risks
print(substitution_without_maintenance("Fleischl", "cocaine"))
# ['峰谷劇烈→強迫性補藥', '快速到腦→敏化', '劑量無上限'] → 災難
```

當代藥理還補了一刀：古柯鹼與酒精併用時，肝臟會合成 **cocaethylene**（古柯乙鹼），心臟毒性高於任一單獨成分——Fleischl 同時飲酒與用古柯鹼（維也納社交文化），這個藥物交互作用在 1884 年無人知曉，今日仍每年造成猝死。

**成癮的疾病模型 vs 道德模型**（見 `1935-成癮醫學誕生.md`）在此案初次交鋒：佛洛伊德把 Fleischl 的失控歸咎於「其人體質與意志薄弱」（道德語言），而今日回望，是給藥方式（注射＋短半衰期＋無監督）註定的藥理結果（疾病語言）。偵探的判決：兩種模型都對了一半——特質影響易感性，但給藥動力學決定下限。

## 結案 -- 後果與影響

- **佛洛伊德的轉向**。古柯鹼事件後，他放棄神經藥理，轉向精神分析——一場處方錯誤，間接把人類思想史推向另一個方向。
- **醫學的教訓制度化**。「替代治療需要維持型藥物（長半衰期、口服、可控）」這一原則，要到 1964 年美沙酮維持療法（`1964-美沙酮維持療法.md`）才被正確實現——距離 Fleischl 之死八十年。
- **古柯鹼的醫學遺產仍在**。局部麻醉（Koller 的貢獻）成為眼科與耳鼻喉科的基石，衍生出普魯卡因、利多卡因家族——「從毒品中提煉出醫學」的雙面模式。
- **一句話結案**：佛洛伊德不是庸醫，他只是用「對的分子」做「錯的工程」——成癮治療的成敗，不在於分子是否神奇，而在於血藥濃度曲線的形狀。
