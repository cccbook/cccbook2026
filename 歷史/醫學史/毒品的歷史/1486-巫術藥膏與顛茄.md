## 1486 - 巫術藥膏與顛茄（被燒死的女巫，與被誤讀的麻醉）

## 案件摘要

**本案的兇器，是一本獵巫手冊和一罐含有阿托品的豬油。**

1486 年，多明我會修士 Heinrich Kramer 出版《錘煉女巫》（*Malleus Maleficarum*），其中描述女巫塗抹「飛行藥膏」參加巫魔會。今日藥理學告訴我們：這些藥膏的主要成分——顛茄（belladonna）、曼陀羅、天仙子——含有莨菪鹼（hyoscyamine）、阿托品與東莨菪鹼，是強效的抗膽鹼致譫妄劑，經皮膚吸收可產生飛行幻覺、口齒不清、對時間感知扭曲。數百年間，數以萬計的人因「與魔鬼交合、飛上天空」的指控被處死，而真正的「兇手」可能是藥膏本身的藥理作用，以及醫學對女性疼痛（助產、經痛）用藥需求的污名化。

## 前因 -- 為什麼會有這個案子

- **莨菪鹼植物的醫療常規**。中世紀外科的「睡眠海綿」（spongia somnifera）——浸泡顛茄、天仙子、曼陀羅的海綿，吸食後用於手術麻醉——是藥典正式療法。這些植物同時是民間助產與墮胎的常用藥。
- **教會的妖魔化工程**。14–15 世紀，教會把民間的魔法實踐（助產士、草藥師、占卜者）逐步定義為異端。《錘煉女巫》是這場定義戰的技術手冊：提供訊問流程、刑求標準與「證據」清單。
- **女性知識的結構性地位**。掌握避孕、墮胎、止痛知識的助產士與草藥婦女，在教會視角下正是「干預上帝旨意」的嫌疑人。藥膏、藥草與女性身體的連結，成了獵巫的敘事骨架。
- **致譫妄劑的知覺效應**。抗膽鹼藥物不同於血清素致幻劑：它產生的是清醒夢境式的譫妄、真實感極強的幻覺、事後遺忘——「飛行」是典型的主觀報告。

## 線索與推理 -- 數學式、程式、理論

莨菪鹼的藥理機制是**競爭性拮抗毒蕈鹼受體**（muscarinic acetylcholine receptor）：

$ \text{東莨菪鹼} + mAChR \rightarrow \text{阻斷副交感神經} \rightarrow \text{心跳↑、口乾、瞳孔放大、記憶編碼失效} $

中樞效應：皮層與海馬的膽鹼通路被關閉，意識從「感知真實」滑向「夢境與真實無法區分」——這就是譫妄（delirium），也是「飛行」敘事的生理基礎。

```python
# 為何「飛行藥膏」的幻覺被當成真實犯罪
def transdermal_deliriant(dose_mg, application_area):
    absorbed = dose_mg * 0.1 * application_area  # 經皮吸收率低但持續
    if absorbed > 1.0:
        return "譫妄: 飛行、變形、巫魔會幻覺(醒後可部分記憶)"
    return "輕微口乾與心率上升"

# 經皮給藥的巧妙之處: 繞過腸胃, 避免大部分噁心與過量嘔吐
# → 使用者「看見了什麼」而非「吐了什麼」
```

一個常被引用的線索：藥膏需要透過黏膜（會陰、腋下）吸收才能達到有效血中濃度，民間傳說中的「騎掃帚」可能是給藥器械的隱喻——這個假說由藥理學史家 Gustav Schelenz 等學者反覆討論，仍屬推論而非定論，但它顯示：**若把「女巫自述」當作藥物動力學數據來讀，整個巫魔會敘事可以翻譯成一張中毒症狀表**。

$ \text{血中濃度}(t) = \frac{D \cdot k_a}{V_d (k_a - k_e)} (e^{-k_e t} - e^{-k_a t}) $

經皮吸收的 $k_a$（吸收速率常數）遠小於口服，故血中濃度曲線平緩——「飛行」體驗可持續數小時，且無消化道警訊，正是最危險的給藥方式。

## 結案 -- 後果與影響

- **獵巫運動的藥理基礎被忽略**。15–17 世紀歐洲估計有 4–6 萬人因巫術處死（多為女性）；藥膏的致幻效應被當成「魔鬼證據」，而非藥物作用。
- **助產與女性醫學的打壓**。獵巫之後，女性醫療知識被系統性排擠出正規醫學——18 世紀產科被男性醫師「接管」，女性助產士地位千年未復。這段歷史是「毒品管制＝對知識的管制」的第一個大型案例。
- **顛茄的雙面名字**。*belladonna*（美女草）來自義大利貴婦用其滴眼液放大瞳孔以增美貌——同一株植物，既是美容品、麻醉藥、毒藥，也是巫術的罪證。
- **現代的回聲**。東莨菪鹼至今仍是手術前用藥（止吐、鎮靜）與暈車藥；「scopolamine 麻醉犯罪」（哥倫比亞的「魔鬼呼吸」）則是本案藥理的現代犯罪版。
- **一句話結案**：當一種物質能讓人看見「不可能的事」，社會選擇相信「看見」的人是惡魔，而不是「物質」在作用——這個選擇的代價是數萬條人命，也預告了 20 世紀迷藥恐慌的劇本。
