# 傳染病的歷史

> 從法老木乃伊上的痘痕，到武漢實驗室裡 48 小時內定序完成的病毒基因組——一部以「推理探案」體寫成的傳染病偵查史。

本書採用**雙線主軸**：

| 主軸 | 一句話 | 代表案件 |
|---|---|---|
| **病原線**：兇手現形 | 瘴氣 → 細菌 → 病毒 → 病原體基因組，人類一步步「看見」兇手的臉 | 1883 霍亂弧菌、2003 SARS-CoV、2020 SARS-CoV-2 |
| **戰役線**：人類反擊 | 人痘 → 牛痘 → 疫苗與抗生素 → 根除與監測，防禦體系的演化 | 1796 牛痘、1944 鏈黴素、1980 天花根除 |
