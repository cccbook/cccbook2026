# 醫學美容的歷史 —— 一部以「偵查」書寫的美麗工程史

> 本書把五千年的醫學美容史拆解成一樁樁「案件」：每一篇 wiki 都是一次推理——謎題是什麼、前因是什麼、線索如何指向理論、結局改變了什麼。因為醫美史的真相是：**人類一直在做同一件事——用當代最先進的工程，賭注自己的身體。**

## 全書核心問題

1. **美麗能否被工程化？**——從鉛白研磨到雷射方程式，答案越來越接近「能」，但每次工程化都附帶新的風險結構。
2. **副作用謎團如何破解？**——石蠟瘤、矽膠肉芽腫、UV 燈突變特徵：醫美史的一半是流行病學偵探史。
3. **誰決定「美」的標準？**——階級（羅馬白粉）、宗教（塔利亞科齊的圍剿）、戰爭（吉萊斯）、媒體（卡戴珊）、演算法（濾鏡）。

## 貫穿全書的五條暗線

1. **可逆戰勝永久**：石蠟 → 矽膠 → Zyderm → 玻尿酸——填充劑史就是「後悔藥」的發明史。
2. **經驗有效、理論缺失的長夜**：愛提烏斯到 Q-switched 雷射的 1453 年，證明沒有理論的改良會撞天花板。
3. **延遲性災難的因果難題**：慢性、低劑量、分布式的傷害最難被看見——從鉛白到 UV 燈，偵查工具一直在升級。
4. **制度決定技術存亡**：塔利亞科齊的技術失傳、Gillies 的專科建制、FDA 的核准效應——醫學知識的存活靠制度而非天才。
5. **需求產生機制的外包**：階級 → 宗教 → 戰爭 → 好萊塢 → 演算法——「美」的定義權每一次轉移，都重寫了醫美產業的形態。
