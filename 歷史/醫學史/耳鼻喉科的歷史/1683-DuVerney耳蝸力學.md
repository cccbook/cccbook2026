## 1683 - 杜韋爾內的耳蝸力學（把耳朵從「靈氣樂器」改造成「聲學機器」）

## 案件摘要

**本案的謎題延續兩千年：聲音到底是什麼？耳朵又如何接收它？**

1683 年，巴黎王家科學院解剖學家約瑟夫·蓋雄·杜韋爾內（Joseph Guichard Du Verney）發表《耳的器官與聽覺》（*Traité de l'organe de l'ouie*），以實驗與幾何論證提出：聲音是空氣的**振動**，耳蝸的功能是**分辨振動的頻率高低**——不同部位感受不同音高。這是史上第一份「音調—部位對應」的系統學說（部位論的雛形），聽覺生理學從此告別「耳朵裡住著共鳴的靈氣」的古典敘事。

## 前因 -- 為什麼會有這個案子

- 17 世紀物理學革命：伽利略與 Mersenne 已確立音高與振動頻率的對應；Boyle 與 Hooke（1660s）證明「沒有空氣就沒有聲音」（真空鐘實驗）。耳朵被排除在物理之外，已不合時宜。
- 解剖學補給：Coiter（1573）已描述耳蝸螺旋；Casserio（1609）的耳解剖圖譜完整。Du Verney 手中第一次有足夠的形態學資料來「賦予功能」。
- 巴黎王家科學院（1666 年成立）的風氣是**以實驗裁決爭論**——正是聽覺生理學需要的法庭。
- 舊學說的弱點一目瞭然：蓋倫—Fernel 系統說「靈氣在耳內共鳴」，無法解釋為什麼音高不同、為什麼高音低音聽感分明。

## 線索與推理 -- 數學式、程式、理論

Du Verney 的核心論證是幾何式的：耳蝸底圈寬、頂圈窄，**基底部的纖維短而硬、頂部長而柔軟**——恰似一系列長短不同的琴弦或管風琴管：

$$ f \propto \frac{1}{L} \quad (\text{弦長與頻率成反比}) $$

```python
# Du Verney 式的「耳蝸弦列」模型
def cochlea_strings(n=20):
    tones = []
    for i in range(n):
        L = 1.0 - 0.9*i/(n-1)          # 底圈短、頂圈長
        tones.append(round(1/L, 2))     # 頻率與長度成反比
    return tones

print(cochlea_strings())
# [1.0, 1.047, 1.105, ... 10.0] → 一排由高到低的頻率偵測器
```

他的實驗證據同樣現代：用火漆封閉聽小骨之一、切斷聽神經、以鼓膜振動觀察等「干預—觀察」操作，確認**振動傳導路徑**。當然他的學說有大錯：他以為耳蝸的骨性螺旋板纖維直接「聽」聲音，真正的感音結構（Corti 器）要到 1851 年才被 Alfonso Corti 發現；行波學說（`1961-貝凱西行波學說諾獎.md`）則要再等 250 年。但**「音高由部位編碼」這個框架本身，一立就沒有倒過**。

## 結案 -- 後果與影響

- 部位論成為聽覺生理學的長期主軸：Cotugno（1760）證明內耳充滿液體而非空氣；Helmholtz（`1863-黑姆霍茲共振學說.md`）以物理學重鑄部位論；Békésy 的行波學說是它的實驗定讞。
- Du Verney 首度把「耳聾分類」的種子埋下：傳導路徑上的問題（鼓膜、聽小骨）與感音器官的問題，在學理上可以分開——19 世紀 Rinne（1855）與 Weber（1834）的音叉試驗將其變成臨床常規（氣骨導差）。
- 他對王家科學院的影響延續至其繼子與學生；法國耳科學派由此起步。
- 頻率—部位思想的最終實用果實之一，是現代人工耳蝸的「頻率—電極位置」設計（`1978-克拉克多通道人工耳蝸.md`）與助聽器的多頻道處理。
- 一句話結案：第一位聽覺生理學家的功績，是把「聽見」從靈魂的神秘活動，改寫成一部可以被拆解的機器。
