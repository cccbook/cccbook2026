# 1975 Allen Newell & Herbert Simon —— 物理符號系統假說的審判

> 「兩位學者宣稱：**智慧就是符號操作**。這個假說如何被提出、
> 如何被驗證、又如何在半世紀後被深度學習動搖？」

## 案件檔案

| 項目 | 內容 |
|---|---|
| 得主 | Allen Newell (1927–1992)、Herbert A. Simon (1916–2001) |
| 得獎理由 | 人類問題求解與決策過程的研究，共同創立 AI 領域 |
| 關鍵詞 | 邏輯理論家、GPS、物理符號系統假說 |

## 前因

1955 年，經濟學家 Simon 在蘭德公司遇到工程師 Newell。
當時電腦只會算數。兩人的謎題：**下棋、證明定理這些「思考」
能否化為計算？** 他們不是先談哲學，而是**直接造出會思考的程式**。

## 線索與推理

### 線索一：邏輯理論家 Logic Theorist（1956）

模仿人類證明 Whitehead & Russell《數學原理》中的定理。策略：
**手段–目的分析（means-ends analysis）**：

```
1. 比較目標與現況，找出「差異」
2. 選擇能縮小差異的操作
3. 若子目標出現，遞迴求解
```

它獨立重證了 38 條定理，甚至找出一條比原書更優雅的證明——
**機器第一次在數學上達到人類水準**。

### 線索二：GPS（General Problem Solver, 1957–59）

把手段–目的分析抽出為通用架構。謊稱「通用」是詐欺嗎？
其價值在揭示：**不同領域的問題求解共享同一套控制結構**——
這是認知架構（cognitive architecture）思想的起點，後繼者為
SOAR（Newell）。

### 線索三：物理符號系統假說（1976 圖靈獎演講）

> 「物理符號系統具有產生智慧行動的必要且充分手段。」

```
符號系統 = 實體記號集合 + 對記號產生、組合、比較的操作
主張：這樣的系統 ⟺ 能表現智慧
「必要」：任何智慧皆需符號；「充分」：符號即可產生智慧
```

### 線索四：人類問題求解（1972，與 Newell）

用「問題空間 + 狀態 + 算子 + 評估」模擬人類解謎（如河內塔）
的實測行為，開創**計算認知科學**。Simon 亦以此思路獲 1978 年
諾貝爾經濟學獎（有限理性 bounded rationality：人非最佳化者，
而是「夠用即止」的滿意化 satisficer）。

## 理論評析

本案的核心爭議即假說的「必要性」半邊。批評線索：

- Dreyfus《電腦不能做什麼》：常識與身體性無法符號化
- Searle 中文房間（1980）：句法操作不產生語義
- 2010s 深度學習（2018 案）：以連續向量而非離散符號達成智慧行為

判決至今未定。當代的折衷（neuro-symbolic AI）正是兩條線索的合流。

## 後果

- 符號 AI 的整個譜系：專家系統（1994 案）、知識圖譜、
  自動規劃。
- Simon 的啟發式搜尋經濟學影響行為經濟學（Kahneman 一系）。
