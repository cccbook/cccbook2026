# 2004 Vint Cerf & Bob Kahn —— 網際網路的共同父親

> 「兩位研究者接到一個無聊的任務：把幾台不同廠牌的電腦
> 連起來。他們的解法——『網路之上再疊一層網路』——成為
> 人類史上最大機器的施工圖。」

## 案件檔案

| 項目 | 內容 |
|---|---|
| 得主 | Vinton G. Cerf (1943–)、Robert E. Kahn (1938–) |
| 得獎理由 | TCP/IP 協定與網際網路架構的先驅貢獻 |
| 關鍵詞 | TCP/IP、封包交換、端到端原則 |

## 前因

1969 年 ARPANET 以 NCP 協定運轉，但它是**單一網路**：
只連 IMP 交換機、只管自家終端。1972 年 Kahn 到 ARPA 接
封包無線電（PRNET）、衛星網（SATNET）專案——謎題：
**異質網路（有線/無線/衛星，各自封包大小、可靠性、
速度皆不同）如何互連？**

## 線索與推理

### 線索一：關鍵設計決策（1973–74）

Cerf 與 Kahn 在火車上與會議中的數月討論，定下原則：

| 決策 | 內容 | 為何正確 |
|---|---|---|
| 閘道器（gateway） | 網路間只轉發，不做智慧 | 網路保持笨（Lampson 1992 案端到端精神） |
| best-effort | 核心網不保證送達 | 可靠性交給端點，交換機簡單可擴展 |
| 全域位址 | 每台主機唯一 IP | 定址獨立於任何底層網路 |
| 分層 | TCP（可靠）與 IP（轉發）分家 | 各層獨立演化 |

### 線索二：TCP/IP 的數學骨架

```
滑動視窗 + ACK + 重傳 + 指數退避 → 擁塞控制在 1988
（Van Jacobson）補齊：AIMD
  cwnd ← cwnd/2（遇擁塞）；cwnd ← cwnd+1/RTT（每 RTT）
證明目標：多流收斂到公平共享（比例公平）
```

封包交換 vs 電路交換的效率論證：統計多工讓利用率從
電路交換的 <50% 提升到接近飽和——**排隊論的 M/G/1
模型**即其理論底座。

### 線索三：1983 年 1 月 1 日——旗艦日（Flag Day）

ARPANET 全網一天之內從 NCP 切換到 TCP/IP。之後開放
免費授權（BSD Unix 內建，1983 案的UNIX 生態載體），
1989 年 Cerf 推動商業化、1991 年 WWW（2016 案）登場
——**架構的開放性決定了一切**。

## 理論評析

網際網路成功的偵探學：**把智慧放在端點**。

```
笨網路 + 聰明端點 > 聰明網路（電話網 PSTN 的教訓）
可擴展性來自「不認識應用」：IP 不解碼內容，
  因此任何未來應用皆可運行（neutral design）
```

這正是 Saltzer–Reed–Clark 端到端論證（1981/1984）的
歷史實踐。

## 後果

- 全球經濟的傳輸層；物聯網、雲端是同架構的尺度放大。
- IPv4 位址枯竭→IPv6 遷移持續中；網路中立性辯論
  直接圍繞本案的「笨網路」原則。
