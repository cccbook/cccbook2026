# 圖靈獎歷史年表（1966–2024）—— AI 偵探風格

以「推理探案」的方式，追查 ACM 圖靈獎自 1966 年頒發以來的每一屆：
謎題是什麼？線索在哪裡？背後的理論（公式、定理、方法論）如何破案？
後果又如何改變了計算的世界？

## 案件間的暗線（全書主軸）

```
1. 複雜性之戰：Wilkes→Dijkstra→Wirth→Brooks→Hoare/Liskov(2021)
   「簡單性是工程的前提」的反覆偵破
2. 難度與秘密：Hartmanis–Stearns→Cook→Karp→Blum→Yao→Goldwasser–Micali→Wigderson
   「計算資源是一種可交易的貨幣」
3. 知識的來源：Newell–Simon(符號)→Feigenbaum(規則)→Pearl(因果)→Barto–Sutton(獎勵)
   「知識=規則→圖→資料→經驗」的四段演化
4. 抽象的層層堆疊：Wilkes(微碼)→Perlis(編譯器)→Codd(資料模型)→Cerf–Kahn(協定)→Berners-Lee(應用)
   「每一層只做自己不可替代的事」
```

## 統計小檔案

- 第一屆：1966（Perlis）；截至 2024 年共 **59 屆**、**82 位**得主
- 兩度得主：僅 2021 年（Hoare 1980+2021、Liskov 2008+2021）
- 女性得主：Frances Allen（2006，首位）、Barbara Liskov（2008、2021）、Shafi Goldwasser（2012）
- 華人得主：姚期智（2000）
- 失蹤得主：Jim Gray（1998 得主，2007 年海上失蹤）
- 最年輕／最年長：Tarjan 獲獎時 38 歲；Brooks 獲獎時 68 歲
