# 2011 Judea Pearl —— 因果革命：把「為什麼」寫進數學

> 「機器學習只會回答『相關』，人類卻渴望『因果』。吸菸
> 導致肺癌，還是體質使人又想吸菸又易得癌？Pearl 為這個
> 差別發明了數學。」

## 案件檔案

| 項目 | 內容 |
|---|---|
| 得主 | Judea Pearl (1936–) |
| 得獎理由 | 因果推理的機率與代數方法：貝葉斯網路與因果演算 |
| 關鍵詞 | 貝葉斯網路、do-演算、因果階梯 |

## 前因

1980s 的困境：古典統計只會條件機率 P(Y|X)，但
**P(Y|X) ≠ P(Y|do(X))**——觀察與干預的鴻溝無法用
現有數學表達。醫學、經濟學在相關性與因果間反覆踩坑
（辛普森悖論即典型案例）。

## 線索與推理

### 線索一：貝葉斯網路（1985/1988）

用**有向無環圖（DAG）**分解聯合機率：

```
P(X₁,...,Xₙ) = Π P(Xᵢ | Parents(Xᵢ))

d-分離準則：判斷圖上兩節點何時條件獨立
  鏈 A→B→C：B 為中介；分叉 A←B→C：B 為共因；
  碰撞 A→B←C：B 是 collider（控制它反而打開通路）
```

**以圖的拓撲承載知識結構，以機率承載不確定性**——
專家系統的知識獲取瓶頸（1994 案）部分解鎖：專家容易
回答「誰影響誰」（畫圖），難以直接給聯合機率表。

### 線索二：do-演算（1995）

Pearl 引入干預算子 do(T=t)，切斷 T 的所有入邊：

```
P(Y | do(T=t)) = Σ_z P(Y | T, Z=z, confounders) P(Z=z)
  ——後門調整公式（backdoor adjustment）

do-演算三大規則：在圖上機械化地判斷
  「觀察資料能否推出因果效應」→ 可識別性判定演算法
```

辛普森悖論的破解示範：

```
整體：新藥痊癒率 78% < 舊藥 83%   （看似新藥差）
分性別：男 93%>87%、女 73%>69%   （明明新藥好！）
真相：性別是混淆因子（男多分到新藥組）。
後門調整（以性別為 Z 分層合併）→ 正確因果效應
```

### 線索三：因果階梯

| 層級 | 問題 | 需要的數學 |
|---|---|---|
| 1. 關聯 | 看見 X，Y 會如何？ | P(Y\|X) |
| 2. 干預 | 若我**做** X 呢？ | P(Y\|do(X)) |
| 3. 反事實 | 當初若沒做 X，會如何？ | 反事實結構方程 |

機器學習（2018 案）只活在第 1 層——Pearl 的著名批評。
結構因果模型（SCM）的方程組解釋反事實：**同一組
結構方程，三層問題全解**。

## 理論評析

Pearl 的偵探學：**因果是一種數學對象，不是哲學姿態**。
他堅持：因果假設無法只從資料推出（圖的邊是人的
判斷），但一旦畫出圖，其餘推導可完全機械化——
「假設的明示化」是科學誠信的工程化。

## 後果

- 隨機對照試驗（RCT）之外的觀察性因果推斷成為醫學/
  經濟學主流工具（經濟學 2021 諾獎的因果工具箱同源）。
- 反事實在推薦系統、可解釋 AI、政策評估落地。
