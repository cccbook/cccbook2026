# 1689 洛克《論寬容》：國家憑什麼容忍「錯誤」的信仰？

## 案發現場

1689 年，流亡荷蘭的約翰·洛克（John Locke）以拉丁文在豪達出版《論寬容》（Epistola de Tolerantia）。背景是英國的宗教內戰：清教徒革命與內戰（1640s，以宗教為旗）、復辟後的《克拉倫登法典》迫害不信國教者；洛克本人因政治與宗教立場流亡。同年，英國《寬容法》（Toleration Act 1689）通過——但只容忍**三位一體的新教徒**：天主教徒與無神論者仍然排除。

> **各國打了上百年的宗教戰爭，每方都相信自己是對的——「寬容」聽起來像放棄真理。那麼，國家憑什麼容忍錯誤的信仰？洛克的論證是什麼結構，它如何把「容忍錯誤」變成「保護自由」？**

## 偵查過程

**線索一：第一論證——強迫不能產生信仰。** 洛克的核心論證：**信仰是意志不能支配的**。你不能「決定」相信一件事——信念隨證據而來；刀劍能製造表面順從（去教堂、行禮儀），不能製造真正的信念。結論：**以強迫「拯救靈魂」在邏輯上無效**——靈魂不是強制的對象。這是把「寬容」從道德讓步轉成**邏輯必然**：既然強迫無效，強迫就只是暴力。

**線索二：第二論證——教會是志願結社。** 洛克定義教會：**信徒自由結合的志願社團**——以共同崇拜為目的。志願結社的屬性：入會靠同意、退會靠自由——**沒有人生來就在教會裡**（這對國家教會是顛覆性的）。既為志願結社，教會無權動用國家強制；國家無權介入結社內部。

**線索三：分球法——國家與靈魂是兩個場域。** 洛克的憲法工程：**國家的職責是世俗之善**（生命、自由、財產——civil goods）；**教會的職責是靈魂**。兩個場域各有職權、互不越界：

$$\text{國家} \Rightarrow \text{世俗之善（生命/自由/財產）} \qquad \text{教會} \Rightarrow \text{靈魂之善（崇拜/良心）}$$

越界即濫權：國家強迫信仰=濫權；教會動用刀劍=濫權。

**線索四：洛克自己的例外（本案的內部矛盾）。** 洛克排除了兩類人：**無神論者**（無神則誓言無效，社會信任崩塌）與**天主教徒**（效忠外國元首——教宗）。這兩個例外暴露了理論的邊界：寬容以「共同公民忠誠」為底線——**理論自身的矛盾，成為後世不斷擴大寬容範圍的推力**。

**線索五：先例與後果。** 先例：羅傑·威廉斯的羅德島（1636，政教分離的首個殖民地實驗）、賓的賓夕法尼亞（1681，多宗教並存）。後果：**1791 年美國憲法第一修正案**——「國會不得制定設立國教的法，不得禁止信仰自由」（建立條款+自由行使條款）——洛克的理論被**制度化**；傑弗遜的《弗吉尼亞宗教自由法》（1786）與 1802 年「政教分離之牆」書信，把牆砌成制度。

## 結案報告

1. **信仰自由成為法理**：洛克把寬容從「君王的恩典」轉成「邏輯與結社的必然」——宗教自由成為法理原則，延續到《世界人權宣言》第 18 條（1948）。
2. **世俗國家=中立容器**：國家的中立性（不裁定教義）成為現代憲政的基石——西發里亞解決國際戰場（[1648-西發里亞和約.md](1648-西發里亞和約.md)），洛克解決國內場域。
3. **理論矛盾的推進力**：洛克排除的無神論者與天主教徒，先後被各國寬容法收納——**理論的邊界不斷被其邏輯本身突破**（若強迫無效是普遍真理，就無法止於某些例外）。
4. **偵探教訓**：寬容的基礎不是「對方可能也是對的」（這是相對主義），而是「**強迫在結構上無效 + 教會是志願結社 + 國家職責在世俗之善**」——三個論證環環相扣，寬容從恩典變成法理。

## 證據與工具

**洛克論證的結構（本案的核心推理）：**

```
論證一：信念非自願（隨證據而來） → 強迫不能產生信仰
        ↓
論證二：教會 = 志願結社（入會靠同意） → 教會無權用強制
        ↓
論證三：國家職責 = 世俗之善；教會職責 = 靈魂之善
        ↓
結論：政教互不越界——寬容是結構的必然，不是君王的恩典
```

**寬容 vs 自由的差異（概念偵查）：**

| 項目 | 寬容（toleration） | 宗教自由（liberty） |
|------|--------------------|---------------------|
| 邏輯 | 掌權者容忍異見 | 權利為人人所有 |
| 主體 | 國家施予 | 公民持有 |
| 1689 英國 | 有（三位一體新教徒） | 尚未 |
| 1791 美國 | — | **制度化**（第一修正案） |

**時間表：**

| 年份 | 事件 |
|------|------|
| 1636 | 威廉斯創羅德島（政教分離實驗） |
| 1681 | 賓夕法尼亞多宗教並存 |
| 1689 | 洛克《論寬容》；英國寬容法（有條件） |
| 1786 | 弗吉尼亞宗教自由法 |
| 1791 | 美國第一修正案（建立條款+自由行使） |
| 1802 | 傑弗遜「分離之牆」書信 |

**結論：** 1689 年的破案把「寬容」從君王的恩典變成了法理的必然：**信念非自願（強迫無效）、教會是志願結社、國家只管世俗之善**——三個論證把宗教自由從道德姿態升級為憲法結構。它自身的例外（無神論者、天主教徒）則成為後世擴大寬容的推力：**理論的邏輯，最終突破了理論制定者的邊界。**
