# 1959 - 舞踏誕生

## 案件摘要
1959 年 5 月，東京，土方巽（Tatsumi Hijikata）首演《禁色》（Kinjiki），改編三島由紀夫的同名小說：半裸的年輕舞者、同性情慾的暗示、雞的慘叫聲——觀眾席騷動，三島由紀夫本人就在場。這一夜被視為日本**舞踏（Butoh）**的誕生。這樁案子的謎題是：**一種「既反芭蕾、也反現代舞」的身體，為什麼會在戰後的東京誕生，又為什麼在三十年後反過來征服歐美的劇場？** 答案藏在廢墟、佔領與一具「死體」的慢動作裡。

## 前因 -- 為什麼會有這個案子
戰後的日本是廢墟：東京被燒夷彈燒平，美軍佔領（1945–52）帶來的文化衝擊——爵士樂、好萊塢、現代化的身體（見 `1984-街舞全球化.md` 的全球脈絡的反面）。日本的現代舞追隨**德國表現主義**（見 `1928-表現主義現代舞.md` 的脈絡）——日德蘭學派出身的舞者模仿瑪麗·魏格曼（Mary Wigman）的姿態，但那是歐洲的靈魂、歐洲的身體。土方巽的問題意識：**日本人的身體記憶在哪裡？**

同時，前衛藝術運動在日本爆發：具體派（Gutai，1954 起）在關西用身體作畫，激浪派（Fluxus）的實驗在日本與紐約同時發生——行為藝術的土壤已經鬆動。

## 線索與推理 -- 死體、白妝、農民身體

### 為什麼「反芭蕾也反現代舞」？
芭蕾的語彙是延伸、上提、反重力——歐洲宮廷與劇場的垂直性。現代舞（Graham 系，見 `1926-Graham現代舞.md`）雖然落到地面，但仍以「表現」為目的。土方巽的第三條路：**「死體」**——屍體般的身體、龜裂般的慢動作、蜷縮的內縮性。他的推理：死亡與衰敗是日本戰後最真實的經驗，跳「美」是逃避，跳「死」才是誠實。

### 《禁色》的證物
- 半裸的男舞者（大野一雄之子大野慶人飾演）在暗中追逐、撫摸另一具身體——同性情慾直接挑戰日本舞台的禁忌
- 雞被帶上舞台——叫聲成為「身體的叫聲」
- 觀眾的反應：憤怒、騷動、退場——**爭議本身就是作品的完成**

### 土方巽的方法論
| 概念 | 內容 |
|------|------|
| 舞踏譜（Butoh-fu） | 以文字意象（「一隻被折斷翅膀的鳥」「霧中的屍體」）引導動作——不記舞步，記身體狀態 |
| 身體的陰性 | 對抗陽剛的直立，讓身體內縮、歪斜、龜裂 |
| 農民身體記憶 | 土方巽出身秋田的農家——彎腰、負重、雪中的姿態成為語彙的來源 |
| 白妝 | 抹去日常的身體，成為「非人」的存在 |

### 組織的偵破
1960 年代，土方巽在東京開設舞踏工作坊（Asbestos 館），與**大野一雄**合作——大野的抒情與土方的暗黑成為舞踏的兩極。學生來自前衛藝術圈：畫家、詩人、劇場人。三島由紀夫的贊助與書寫（他為土方寫《太陽的鐵》）提供了知識界的正當性——**文學界為舞踏背書**。

## 結案 -- 後果與影響
1970 年代起，舞踏出國：**天兒牛大**的 Sankai Juku（1975 起）在巴黎、紐約演出——懸吊於大樓外牆的儀式成為傳奇。結案的定論：

- **舞踏成為日本輸出的獨特身體藝術**——20 世紀唯一由非西方世界反向輸出的舞蹈形式
- 影響歐美的**後現代舞**（見 `1962-Judson後現代舞.md`）與**行為藝術**——日常、緩慢、非奇觀的身體
- 白妝、慢動作、地面性成為全球當代舞的通用語彙
- 日本國內：舞踏與傳統能劇、現代舞並存，成為國際藝術節的常客
