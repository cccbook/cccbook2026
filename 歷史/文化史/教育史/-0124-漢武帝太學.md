# -0124-漢武帝太學：官學制度化的誕生

## 案件摘要

前 136 年漢武帝採董仲舒議「罷黜百家，表章六經」、置五經博士；前 124 年採公孫弘之議設太學、招博士弟子五十人——**中國官學制度化的起點**。博士弟子歲課「通一藝者」補文學掌故、高第為郎官——「通經入仕」把教育與官制直接綁定。到東漢，太學生膨脹至三萬人。本案偵破的問題是：一個五十人的班，如何成為統治兩千年的「士人政治」的生產線？

## 前因 -- 為什麼會有這個案子

- 秦的教訓：「以吏為師」（前213 焚書、以法律文書為教材）——純技術官僚的帝國二世而亡。
- 漢初黃老無為 → 武帝的轉型需求：帝國需要統一意識形態與文治官僚。
- 董仲舒天人三策（前134）：「養士之大者，莫大乎太學」——**辦學校是治國方案的核心條款**。
- 蜀郡太守文翁（景帝時）辦郡學的成功先例——地方辦學可行。

## 線索與推理 -- 太學的制度設計

### 線索一：「以吏為師」vs「以經為師」——秦漢的制度分岔

| 對比 | 秦（以吏為師） | 漢（以經為師） |
|------|----------------|----------------|
| 教材 | 法律文書、行政文書 | 五經（詩書禮易春秋） |
| 師資 | 官吏 | 博士（學者） |
| 出路 | 軍功與吏員升遷 | 通經補官 |
| 帝國壽命 | 二世而亡 | 四百年（含新莽） |

**選哪種教材，就是選哪種統治**：秦選技術，漢選意識形態——太學是漢帝國「意識形態統治」的基礎設施。

### 線索二：通經入仕——考試與官制的最早綁定

制度流程：

```
博士弟子五十人 → 歲課（一年一考）
→ 「能通一藝以上」補文學掌故缺
→ 「高第可以為郎中」——直接進入中央官僚序列
```

**教育與仕途直接綁定**——「學而優則仕」從思想變成制度。這是兩千三百年後「後沖效應（washback）」的最早國家級案例：**考什麼，全國就教什麼**——五經成為全國統一課綱，與一千三百年後的科舉（[0605-科舉的誕生.md](0605-科舉的誕生.md)）同一邏輯。

### 線索三：規模膨脹的動力學

太學規模的成長曲線：

| 年代 | 博士弟子人數 |
|------|--------------|
| 前124 | 50 |
| 前51 | 100→200（增置） |
| 前33 左右 | 1,000 |
| 王莽時（前後） | 10,800＋ |
| 東漢質帝（145） | **30,000** |

$$N(t) \text{ 指數成長} \quad \Rightarrow \quad \text{官位需求} \ll \text{畢業生供給}$$

畢業生供給指數成長，官位線性有限——**規模超過官僚消化能力，士人失業與政治不穩定同時到來**：東漢「黨錮之禍」（166、169）中太學生正是政治運動的主力。**教育擴張的政治代價**——這條規律在千年後的科舉廢除（[1905-廢科舉與新學.md](1905-廢科舉與新學.md)）與現代大學擴張中反覆重演。

### 線索四：官學與私學的雙軌

太學（中央官學）只是頂端；漢代同時存在：

| 層級 | 機構 | 功能 |
|------|------|------|
| 中央 | 太學、四姓小侯學 | 培養官僚頂層 |
| 地方 | 郡國學（文翁模式） | 官吏預備 |
| 民間 | 書館（蒙學：識字）、經師私學 | 識字＋經學預備 |

**雙軌制的誕生**：官方認證 + 民間基礎教育——這個結構成為此後兩千年的中國教育骨架。

### 線索五：制度成效表

| 指標 | 成效 |
|------|------|
| 意識形態統一 | 罷黜百家——儒學成為國家教學大綱 |
| 官僚供給 | 「通經入仕」兩百年——文治官僚取代軍功貴族 |
| 政治代價 | 太學生三萬人 → 黨錮之禍——教育擴張的政治副作用 |
| 制度遺產 | 通經入仕 → 科舉（605）的前身；郡國學 → 地方官學網 |

## 破案時刻

董仲舒對策的一句話：「養士之大者，莫大乎太學；太學者，賢士之所關也，教化之本原也。」——**辦學校被寫進治國方案**。前 124 年的五十人班，是史上第一次「國家以教育作為統治工程的基礎設施」。

## 後果 -- 改變了什麼

- 「通經入仕」確立：教育與官制綁定的兩千年傳統——漢代太學 → 隋唐科舉（[0605-科舉的誕生.md](0605-科舉的誕生.md)）一脈相承。
- 儒學成為官方教學大綱：諸子學退入民間——中國學術版圖被教育制度重寫。
- 官學＋私學雙軌結構：太學與書館並存——中國教育的基本形態確立。
- 士人政治的誕生：太學生成為此後兩千年中國政治的主要行動者（東林、清流、黨爭）。

## 教育演進筆記

1. **教育是意識形態工程**：漢代太學證明——辦學校是治國方案，不是福利。
2. **考試與官制綁定＝後沖效應的誕生**：通經入仕讓「考什麼」直接決定「全國教什麼」。
3. **教育擴張有政治代價**：畢業生供給超過官位需求，士人轉為政治不穩定力量——規模膨脹的動力學警告。
4. **雙軌制是穩定結構**：中央官學認證 + 民間蒙學打底——任何現代學制的骨架。
