# -0550-孔子私學與有教無類：教育的平民化革命

## 案件摘要

前 551–479 年，孔子在魯國設私學，弟子三千、賢者七十二，「自行束脩以上，吾未嘗無誨焉」——**史上第一次把教育門檻從血統降到一束肉乾**。「有教無類」「因材施教」「學而不思則罔，思而不學則殆」——孔子的私學把教育從「貴族職業培訓」重寫為「人格養成」，並產生了持續兩千五百年的士人階層。本案偵破的問題是：官學崩壞的亂世，為什麼反而誕生了最成功的平民教育？

## 前因 -- 為什麼會有這個案子

- 西周官學（辟雍、泮宮）與六藝課綱：教育專屬貴族，「學在官府」。
- 春秋亂局：王室衰微、「天子失官，學在四夷」——官吏流散民間，官學體系崩塌。
- 士階層興起：各國爭霸需要人才，**流動的知識人成為稀缺資源**。
- 竹簡的普及：知識載體從青銅銘文轉向竹簡——**抄寫與攜帶成本下降，私人藏書成為可能**。

## 線索與推理 -- 私學的教學法與制度設計

### 線索一：有教無類——教育門檻的社會學

| 對比 | 西周官學 | 孔子私學 |
|------|----------|----------|
| 入學資格 | 血統（貴族子弟） | 束脩（十條肉乾的象徵性學費） |
| 課程 | 六藝（禮樂射御書數） | 六藝＋詩書禮易春秋（經典化） |
| 目的 | 世襲官職的預備 | 成人（君子）＋出仕 |
| 師生關係 | 官吏對世子 | 「三人行必有我師」——對等對話 |

**門檻從血統降到束脩**：教育的輸入端被重寫——平民第一次可以透過學習改變階層。孔子弟子原憲貧、子路野、顏回居陋巷——「賢者七十二」來自各階層。

### 線索二：因材施教——最早的個別化教學記錄

《論語·先進》的經典案例：子路與冉有同問「聞斯行諸」（聽到就去做嗎？），孔子給了**相反**的答案：「求也退，故進之；由也兼人，故退之。」——同一問題、不同答案，因為診斷不同。**先診斷、後教學**——這是最早的個別化教學記錄，也是兩千三百年後「最近發展區」（[1934-維果茨基最近發展區.md](1934-維果茨基最近發展區.md)）與今日「自適應學習」的哲學先聲。

### 線索三：學與思的認知理論

「學而不思則罔，思而不學則殆」——**輸入（學）與整理（思）的雙通道模型**：只輸入不整理，是資訊過載的罔；只整理不輸入，是過擬合的殆。用現代認知科學的語言：**編碼與提取必須配對**——孔子在兩千五百年前就寫下了學習科學的第一條定律。

### 線索四：制度成效表

| 指標 | 成效 |
|------|------|
| 規模 | 弟子三千、賢者七十二——戰國最大私學 |
| 產出 | 弟子遍列諸國從政——子貢相魯衛、冉有仕季氏 |
| 模式擴散 | 戰國諸子全數採用私學模式（墨家、孟子、荀子） |
| 長期效應 | 士人階層制度化 → 漢代經學 → 科舉（[0605-科舉的誕生.md](0605-科舉的誕生.md)） |

### 線索五：語錄體——《論語》作為教學媒體

《論語》不是孔子寫的，是弟子記錄的對話——**「教學對話」被媒體化為文本**。語錄體的可複製性，讓孔子的教學突破了「師在場」的時間限制——**教學媒體化**的第一步（兩千年後印刷術把同樣的邏輯推到極致：[1445-古騰堡印刷術.md](1445-古騰堡印刷術.md)；慕課則把「對話」再次媒體化：[2008-慕課革命.md](2008-慕課革命.md)）。

## 破案時刻

「自行束脩以上，吾未嘗無誨焉」——一句話把教育門檻降到象徵性水平；「有教無類」四個字，重寫了「誰能上學」——**史上第一次教育平權宣言**。亂世官學崩壞，反而騰出了私學的空間——**制度的崩壞是創新的前提**。

## 後果 -- 改變了什麼

- 士人階層誕生：「學而優則仕」成為兩千五百年的社會流動通道，最終制度化為科舉（[0605-科舉的誕生.md](0605-科舉的誕生.md)）。
- 私學模式成為中國教育的主流形態：戰國諸子、漢代經師、宋代書院（白鹿洞、岳麓）都是孔子的直系子孫。
- 東亞教育文化圈：儒家的「師道」與「學思並重」影響朝鮮、日本、越南至今。
- 「教育＝人格養成」進入教育思想史：與希臘的智者學派（[-0450-希臘智者學派.md](-0450-希臘智者學派.md)）同時代、兩相對照——軸心時代的雙子星。

## 教育演進筆記

1. **制度崩壞是創新前提**：官學崩了，私學才有空間——教育改革的機會窗口常在舊制度失效時。
2. **門檻設計決定誰能上學**：從血統到束脩——入學資格的一次修改，重寫了一個階層的命運。
3. **因材施教＝先診斷後教學**：個別化教學的最早記錄，比 ZPD 早兩千三百年。
4. **教學媒體化**：對話被記錄為文本，教學就突破了師生同在的時間限制——從《論語》到慕課的同一條線。
