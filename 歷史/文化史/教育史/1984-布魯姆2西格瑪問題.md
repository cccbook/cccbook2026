# 1984-布魯姆2西格瑪問題：一對一輔導的兩個標準差

## 案件摘要

1984 年，教育心理學家本傑明·布魯姆（Benjamin Bloom）發表著名的「2σ 問題」：一對一輔導（tutoring）的學生，平均成績比傳統班級教學**高出兩個標準差**——從中位數躍升到前 2%。班級教學只達到一對一效果的一小部分。布魯姆提出的問題是：**能否找到方法，讓多數學生在一對一效果下學習？** 這一問在四十年後（2022 起）由生成式 AI 接手兌現。本案偵破的問題是：兩個標準差是什麼概念？為什麼四十年無人兌現？

## 前因 -- 為什麼會有這個案子

- 1968 布魯姆「掌握學習」（mastery learning）：給足時間與反饋，多數學生可掌握——「能力分布」部分是教學產物。
- 1956 布魯姆教育目標分類學：認知目標分層——測量與教學設計的工程學。
- 芝加哥大學的教學實驗：布魯姆團隊比較一對一輔導、掌握學習與傳統班級。
- 美國教育改革的恐慌期（1983《國家在危機中》）：尋找「有效的教學」成為政策議題。

## 線索與推理 -- 兩個標準差的意義

### 線索一：2σ 是什麼概念

常態分布下的成績位置：

```
        ┌─────── 常態分布 ───────┐
   -2σ    -1σ    μ(均值)    +1σ    +2σ
   2%    16%     50%        84%    98%
                ↑
        班級教學：中位數附近
        一對一輔導：+2σ（約前 2%）
```

**兩個標準差**：從中位數（第 50 百分位）躍升到第 98 百分位——相當於把普通學生變成資優生，或說：**班級教學的 1,000 小時 ≈ 一對一的 500 小時**（效率翻倍的量級）。

### 線索二：為什麼一對一有效

一對一輔導的機制（布魯姆的歸因）：

| 機制 | 班級教學 | 一對一輔導 |
|------|----------|------------|
| 反饋 | 延遲（作業批改） | **即時** |
| 節奏 | 統一（中位數校準） | **個人化（ZPD 校準）** |
| 錯誤 | 累積（不懂繼續教） | **即時修正** |
| 動機 | 匿名 | 一對一關係 |

即時反饋＋個人化節奏——正是蒙台梭利教具的「自我糾錯」（[1907-蒙台梭利兒童之家.md](1907-蒙台梭利兒童之家.md)）與維果茨基的 ZPD（[1934-維果茨基最近發展區.md](1934-維果茨基最近發展區.md)）的組合：**2σ 不是奇蹟，是即時反饋＋最適難度的疊加**。

### 線索三：掌握學習——班級內的 1σ 嘗試

布魯姆的「掌握學習」在班級內追求部分效果：

```
單元教學 → 形成性測驗 → 未達標者補救 → 再測 → 進入下一單元
```

成效：約 **1σ**（比班級教學高一個標準差）——掌握學習拿到一對一效果的一半；剩下的 1σ 需要真正的個人化——**班級制度能擠出 1σ，剩下的 1σ 卡在「一人對多人」的結構限制**。

### 線索四：成本函數——為什麼四十年無人兌現

教學成本函數：

$$C = \frac{\text{教師成本} \times \text{學時}}{\text{學生數}}$$

一對一輔導的單位成本是班級教學的數十倍——**2σ 的效果卡在成本函數上**：師資規模、薪資結構、學時分配——一九八零年代沒有任何經濟結構能負擔「全民一對一」。**效果已證明、成本無法負擔**——這是布魯姆的問題成為「問題」的原因。

### 線索五：制度成效表

| 指標 | 成效 |
|------|------|
| 理論地位 | 教育研究的經典效應量——「2σ 問題」成為教育科技的終極靶子 |
| 1980s 嘗試 | 電腦輔助教學（CAI）、智能導師系統（ITS）——效果有限（0.3–0.5σ） |
| 2000s | 自適學習平台、可汗學院——規模化起步 |
| 2022– | 生成式 AI 導師——首次接近「對話式個人化」的形態（[2022-生成式AI進入教育.md](2022-生成式AI進入教育.md)） |

## 破案時刻

布魯姆 1984 年的原文問題：「一對一輔導的兩個標準差，能否在（或多數）學生身上以群體（班級）程序實現？」——**這一問定義了此後四十年教育科技的使命**。答案的形態在四十年後才出現：能「即時反饋＋個人化節奏」的 AI 導師——**理論（1984）→ 兌現（2022+）——三十八年**。

## 後果 -- 改變了什麼

- 「2σ」成為教育科技（EdTech）的北極星：所有自適應學習與 AI 導師的目標函數。
- 掌握學習與形成性評量的普及：班級內的 1σ 嘗試——形成性評估成為標準做法。
- 教育科技的標準：任何「教育 AI」的成效宣稱都被拿來與 2σ 比對——評價的基準線。
- 個人化 vs 規模化的終局之問：班級制度四百年的取捨（規模 vs 個人化），第一次出現「同時取得」的可能形態。

## 教育演進筆記

1. **2σ ＝ 即時反饋＋最適難度**：一對一的效果不是神秘，是兩項機制的疊加——蒙氏教具與 ZPD 的組合效應。
2. **掌握學習擠出 1σ**：班級制度內的個人化極限——剩下的 1σ 卡在結構。
3. **成本函數是兌現的瓶頸**：效果已證明、成本無法負擔——教育的推廣問題是經濟學問題。
4. **理論的靶子作用**：布魯姆的一問，定義了四十年後的教育科技——好問題比答案活得久。
