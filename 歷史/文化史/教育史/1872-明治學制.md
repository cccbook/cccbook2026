# 1872-明治學制：東亞的現代學制工程

## 案件摘要

1872 年，明治政府頒布《學制》（Gakusei）——日本第一套現代學制：全國分八學區、大學-中學-小學三級、仿法國學區制與美國課程。序文宣示「**邑無不學之戶，家無不學之人**」。1877 年東京大學成立；1886 年森有禮的《學校令》轉向普魯士模式；到 1905 年小學就學率超過 95%——與清廷廢科舉（[1905-廢科舉與新學.md](1905-廢科舉與新學.md)）同年。本案偵破的問題是：日本如何在三十三年間把就學率從 28% 拉到 95%？

## 前因 -- 為什麼會有這個案子

- 明治維新（1868）：「文明開化」——富國強兵的國家戰略，教育是基礎設施。
- 江戶時代的教育基礎：寺子屋（terakoya，幕末約 1.5–5 萬所）——男子識字率約 40%，亞洲最高；藩校與蘭學私塾（杉田玄白《解體新書》1774——西方知識的民間吸收）。
- 岩倉使節團（1871–73）：考察歐美十二國——**教育是被最認真考察的項目之一**。
- 制度震動：1853 黑船來航——「落後就捱打」的緊迫感。

## 線索與推理 -- 混合工程的設計與執行

### 線索一：既有基礎＋外來制度的混合工程

《學制》不是從零開始：

| 組成 | 來源 | 作用 |
|------|------|------|
| 寺子屋與藩校 | 江戶傳統 | **識字底子**（男 40%）——學生與家長已接受「上學」的概念 |
| 學區制 | 法國 | 八大學區、分級學校——行政骨架 |
| 小學課程 | 美國 | 讀寫算＋知識課 |
| 師範與軍操 | 普魯士（1880s 森有禮轉向） | 師資與紀律 |

**混合工程**：本土底子＋法國骨架＋美國血肉＋普魯士紀律——日本的學制是「選配」而非「全套進口」——制度移植的可調性是速度的來源。

### 線索二：「邑無不學之戶」——義務教育的國家敘事

《學制》序文的宣言：教育不是個人選擇，是國民義務——**「國民」這個概念本身靠學校製造**：統一教材、統一課程、統一時間表——民族國家的「國民製造機」（與賀拉斯·曼的公立學校 [1852-美國公立學校運動.md](1852-美國公立學校運動.md) 同構、更集權）。

### 線索三：就學率的 S 曲線

| 年份 | 小學就學率 |
|------|------------|
| 1873 | 約 28% |
| 1880 | 約 41% |
| 1890 | 約 49% |
| 1900 | 約 90% |
| 1905 | **約 95%** |

$$S\text{-曲線}：1880\text{s 後加速——免費化（1900）與就學義務嚴格化是拐點}$$

三十三年 28%→95%：**制度擴散的 S 曲線在強制＋免費＋檢核三管齊下時陡升**——經費工程（1886 學校令、1900 免費化）是關鍵拐點。

### 線索四：1877 東京大學——頂端先行

東京大學（1877）：四學部（法理文醫）、外籍教師授課——**先建頂端、再鋪底層**的倒金字塔：先有大學與官僚培養，小學網隨後跟進——與美國「先小學後大學」的路徑相反——**國家需求決定建設順序**（明治需要立即的官僚與技術者）。

### 線索五：制度成效表

| 指標 | 成效 |
|------|------|
| 就學率 | 1873 約 28% → 1905 約 95%——33 年的 S 曲線 |
| 大學 | 1877 東京大學——亞洲第一所現代大學 |
| 師資 | 師範學校網＋普魯士式操練——教師的軍官化 |
| 意識形態 | 1890《教育敕語》——忠孝意識形態入校（陰影） |
| 擴散 | 中國癸卯學制（1904）抄日本；朝鮮、台灣殖民地學制跟進 |

## 破案時刻

「邑無不學之戶，家無不學之人」——《學制》序文把教育宣告為國民義務；三十三年後（1905）就學率 95%——**史上最快的義務教育覆蓋**。同年清廷廢科舉：**東亞兩大教育變革同時發生，日本領先三十年**——制度轉型的速度差決定了兩國的百年國運。

## 後果 -- 改變了什麼

- 東亞現代學制圈：中國癸卯學制（1904）、朝鮮與台灣學制——日本模式擴散。
- 高速現代化的教育基礎：識字率與技術官僚——甲午戰爭（1895）與日俄戰爭（1905）勝利的基礎設施。
- 軍國主義教育的陰影：1890《教育敕語》與森有禮的軍操——1945 年前的意識形態教育，1948 廢止。
- 「先大學後小學」的倒金字塔路徑：後發國家的建設順序模板（中國 1898 京師大學堂同款）。

## 教育演進筆記

1. **混合工程勝過全套進口**：本土底子（寺子屋）＋外來骨架（法國）＋選配血肉（美國、普魯士）——制度移植的可調性是速度來源。
2. **國民靠學校製造**：統一教材與課程——民族國家的「國民製造機」。
3. **強制＋免費＋檢核＝S 曲線陡升**：經費工程（免費化）是就學率拐點——制度的執行端決定覆蓋速度。
4. **先大學後小學的倒金字塔**：國家需求決定建設順序——後發國家的路徑選擇。
