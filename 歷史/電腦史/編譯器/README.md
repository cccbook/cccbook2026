## 破案主線一覽

1. **可行性之戰**（1943–1957）：從紙上語言到「效率逼近手寫」的 FORTRAN，證明高階語言值得用。
2. **理論化**（1958–1965）：Chomsky 層級 → BNF → LR(k)，把「翻譯」變成可判定的數學問題。
3. **工程化**（1970–1977）：自舉、可攜、parser generator，編譯器從手工藝變成工程。
4. **協同設計**（1980–1991）：RISC 與圖著色，證明硬體與編譯器必須一起設計；SSA 統一優化理論。
5. **動態化**（1995–2000）：JIT 融合直譯器與編譯器——「先觀察、再投機、錯了退回」。
6. **基礎設施化**（2000–至今）：LLVM 樂高化、WebAssembly 通用執行環境、MLIR 多層級 IR，最後 AI 上場找更快的代碼。
