# 歷史 -- 歷史書籍系列

本目錄依五大類收錄歷史書籍，各分類資料夾為入口，底下每個子資料夾才是書籍。

分類  | 說明
-------------|-----------
[世界史]  | 各地區與時代的世界歷史，共 30+ 本
[學術史]  | 各學門的發展史，共 12 本
[文化史]  | 藝術、音樂、宗教等文化史，共 6 本
[書籍]  | 大歷史提問式的專書，共 7 本
[科技史]  | 科技與學科技術發展史，共 50 本
[年表] | 年表，12篇
