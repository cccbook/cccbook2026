# 1954 · 鮑林化學鍵：把量子力學變成化學家的工具箱

> 1954 諾貝爾化學獎：林納斯·鮑林（Linus Pauling），表彰化學鍵本質之研究及應用於複雜物質結構的闡明（1962 再獲和平獎——唯一科學諾獎+和平獎得主）

## 案情提要

1927 年起，量子力學對 H₂ 分子的處理（海特勒-倫敦，1927）大獲成功——但那套波函數積分只有理論物理學家算得動，對有 20 個原子的分子完全無能為力。化學家手上有一百年累積的鍵長鍵角資料，卻沒有一個**能用的理論**。鮑林要做的，是把量子力學「翻譯」成化學家可操作的半經驗規則。

## 前因

| 年份 | 事件 |
|---|---|
| 1916 | 路易斯提出共用電子對（共價鍵）概念——沒有解釋「為何共用就穩定」 |
| 1927 | 海特勒-倫敦精確處理 H₂：兩個電子自旋反平行、軌域重疊 → 鍵能 4.7 eV |
| 1929 | 穆利肯（1966 諾獎）分子軌域理論並行發展（兩派論戰三十年，最後由計算化學統一） |
| 1913 | 維爾納配位理論（[1913-維爾納配位理論](1913-維爾納配位理論.md)）等待量子詮釋 |

## 調查：鮑林的四大法寶

### 1. 雜化軌域

甲烷的四個鍵完全等價、夾角 109.5°——但碳的價電子是 2s²2p²，2s 與 2p 軌域形狀全然不同，怎麼會等價？鮑林把軌域「線性重組」：

- `sp³ = (s + p_x + p_y + p_z)/2` → 四個等價的正四面體指向（[1904-鈍氣的發現](1904-鈍氣的發現.md) 案中凡特荷夫 1874 年的幾何直覺，獲得量子身份證）
- `sp²` → 平面三角（乙烯），`sp` → 直線（乙炔）——一組公式覆蓋全部碳化學幾何。

### 2. 共振論

苯的六個 C–C 鍵等長（1.39 Å，介於單鍵 1.54 與雙鍵 1.34 之間）。鮑林說：真實分子是幾個經典結構的量子疊加：

`Ψ(苯) = c₁Ψ(凱庫勒) + c₂Ψ(另一凱庫勒) + c₃Ψ(杜瓦) + …`

- 共振使能量降低（共振能約 150 kJ/mol）——苯的異常穩定性有了定量語言。
- 酮-烯醇、羧酸、臭氧……整個有機化學的「中間態」獲得統一表述。（在蘇聯，共振論一度被批為「唯心主義」，化學政治史的著名公案。）

### 3. 電負度標尺

鮑林用鍵解離能定義電負度 χ：

`Δ(A–B) = D(A–B) − ½[D(A–A) + D(B–B)] ∝ (χ_A − χ_B)²`

以 F = 4.0 為錨點，一張表格預測**任何兩元素的鍵極性**——化學家从此可定量估計鍵的離子/共價成分：`離子性% = 1 − e^{−(Δχ)²/4}`。

### 4. 半經驗鍵長-鍵級公式

`d(n) = d(1) − 0.71 log n`——由鍵長反推鍵級，晶體結構資料變成結構偵探的指紋庫。

## 實戰破案

- 1930s 系統解出數十種礦物與合金結構。
- **血紅蛋白的折疊**：用同樣的鍵幾何思考蛋白質，1951 年與柯里提出 α-螺旋（每圈 3.6 個殘基、氫鍵螺距 5.4 Å）——與 X 光數據吻合，直通 DNA 雙螺旋與蛋白質結構學（1962 諾獎）。1953 年他幾乎解出 DNA 結構，因錯誤的三螺旋模型（且未看羅莎琳·富蘭克林的 B 型照片）敗給華生-克里克——本案最著名的敗訴。

## 後果

| 層面 | 影響 |
|---|---|
| 教育 | 《化學鍵的本質》（1939）被譽為「二十世紀最重要的化學教科書」 |
| 生物 | α-螺旋 → 二級結構 → 分子生物學的幾何語言 |
| 醫學 | 鮑林晚年提倡維生素 C 大劑量治感冒/抗癌，科學界多次檢驗多為否定——偉大偵探的晚年誤判案例 |
| 政治 | 反核彈試爆運動，1962 和平獎；因左派立場一度被拒發護照、險些錯過 1954 領獎 |
| 判例 | 「結構決定性質」從此成為化學的第一公理 |
