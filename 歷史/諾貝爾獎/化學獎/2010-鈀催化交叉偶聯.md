# 2010 · 鈀催化交叉偶聯：把碳原子像積木一樣拼起來

> 2010 諾貝爾化學獎：理查德·赫克（Richard Heck）、根岸英一（Ei-ichi Negishi）、鈴木章（Akira Suzuki），表彰鈀催化交叉偶聯反應

## 案情提要

藥物與天然物的主幹是碳骨架，而碳-碳鍵的形成是合成化學的「承重牆」。傳統方法（格氏試劑+鹵化物的偶聯、Diels-Alder 等）各有死角：官能基耐受性差、區域選擇性不可控。世紀懸案：**能否讓兩個「不活潑」的碳碎片，在溫和條件下精準相連？**——並且要能容忍藥物分子常見的胺基、羰基、酯基通通不動。

## 前因

| 年份 | 事件 |
|---|---|
| 1912 | 格林尼亞試劑（Grignard，當年諾獎）：有機鎂作親核試劑——猛烈但無選擇性 |
| 1960s | 錯合物化學成熟（[1913-維爾納配位理論](1913-維爾納配位理論.md) 的現代版）；有機鈀化學萌芽 |
| 1968–72 | 赫克（Hercules 公司）發現芳基/烯基鹵化物與烯烴在 Pd(0) 催化下「直接」相連——**Heck 反應** |

## 調查：鈀的四步舞

所有鈀催化偶聯共享同一套「作案流程」（以 Suzuki 反應為例，1979）：

1. **氧化加成**（oxidative addition）：Pd(0) 插入 Ar–X 鍵 → `Ar–Pd(II)–X`
2. **轉金屬**（transmetalation）：有機硼/鋅/錫試劑把 R 基團「轉交」給鈀 → `Ar–Pd(II)–R`
3. **還原消除**（reductive elimination）：Ar 與 R 相連成 C–C 鍵，釋出 `Pd(0)`，**催化劑回生**
4. 循環往復：每微摩爾鈀可完成上千次循環

`Ar–X + R–B(OH)₂ + 總鹼 → Ar–R + XB(OH)₂`

各獲獎方法的差異只在「第二把碳刀」：

| 方法 | 試劑 | 特色 |
|---|---|---|
| Heck（1968–72） | 烯烴 | 烯烴官能化，生成取代烯烴 |
| Negishi（1977） | 有機鋅 | 溫和、高官能基耐受 |
| Suzuki（1979） | 有機硼酸 | **無毒、易操作、水相可用**——工業首選 |

 Suzuki 的深意：有機硼試劑「溫馴」到可以放進水裡——鹼（OH⁻/OAc⁻）先與鈀交換形成 Pd–OH，再與硼酸形成硼酸鈀酯，四員環過渡態完成轉金屬。**溫和性來自「鈀先做人情（與鹼配位）」的精妙機理**，由 X 光與動力學聯合鑑識。

## 理論裁決

- Pd 的魔力在**可逆的 0 ↔ II 價切換**（金屬的氧化還原緩衝），把「電子給受體難以匹配」的兩個碳碎片暫時收押、配對、然後同時釋放——這是過渡金屬化學（18 電子規則，見 [1913-維爾納配位理論](1913-維爾納配位理論.md)）最壯觀的工業應用。
- 立體化學：烯烴幾何在全程**保留**（E/Z 不變）——鈀像「戴著白手套」搬運分子，不碰亂立體。

## 後果

| 層面 | 影響 |
|---|---|
| 藥物 | 數百種上市藥的關鍵步驟（如抗癌藥拉帕替尼、抗真菌藥、GLP-1 藥物片段） |
| 材料 | OLED 發光材料、有機導體（[2000 導電聚合物](README.md)的延伸） |
| 自然界 | 2008 年起發現天然「基因」編碼鈀酶的疑雲多次被否證——生物界確有酶促偶聯，但鈀催化仍屬純人工奇蹟 |
| 綠色化學 | 鈀用量降至 ppm 級（再循環/微波/水流相） |
| 教訓 | 赫克退休後隱居佛羅里達；鈴木章 83 歲接獲通知，感謝「一生只做一件事」的師道（其導師布朗 1979 諾獎，[1979 有機硼化學](README.md)）——三代師徒的接力偵查 |
