# 1903 · 阿瑞尼士電離學說：十年前被評為三等的異端

> 1903 諾貝爾化學獎：斯凡特·阿瑞尼士（Svante Arrhenius），表彰電離學說

## 案情提要

1884 年，23 歲的阿瑞尼士提交博士論文：鹽溶於水會**自發分解成帶電的離子**。烏普薩拉大學評審給的成績是「三等（非commended）」，僅容他勉強畢業。主因：化學家無法接受——氯化鈉在水裡「自己拆成 Na⁺ 和 Cl⁻」？電離明明需要通電，怎麼會「自己電離」？這是概念上的雞生蛋誤解：他們把「電解」與「電離」混為一談。

## 前因

| 年份 | 事件 |
|---|---|
| 1800 | 伏打電堆問世；尼科爾森與卡萊爾首次電解水 |
| 1833–34 | 法拉第電解定律；「離子」（ion）一詞由法拉第創用——**意指通電後的產物** |
| 1857 | 克勞修斯計算鹽水中離子導電，認為只有「極小部分」解離 |
| 1882 | 凡特荷夫的滲透壓數據出爐：電解質的 π 「異常偏大」，修正因子 i 無人能解 |

## 調查：三條獨立證據鏈匯合

阿瑞尼士的關鍵推理：法拉第的「離子靠電產生」與他主張的「離子**先於**電而存在」是兩回事。鑑證手法是把三條互不相干的測量擺在同一張桌上：

1. **滲透壓**：NaCl 溶液的 π 超標 1.87 倍 → 溶液中粒子數近乎加倍 → **鹽已拆成兩份**（i ≈ 2）。
2. **凝固點下降**：同樣呈現倍數異常——獨立方法，同一結論。
3. **導電度**：溶液導電度隨稀釋而「每分子當量電導」增大——若離子是通電才產生，此現象無解；若離子本就存在，只是更難相互阻擋，完全吻合。

他還導出稀釋定律：

`K = Λ² / (Λ₀(Λ₀ − Λ))`

濃度、電導、離子數三者的定量鎖鏈。法拉第意義上的「電解」只是離子（已在場）在電極上的收尾動作。

## 理論裁決：為何「電」非必需

- 水的介電常數 ε ≈ 78，庫侖力 `F ∝ 1/ε` 被削弱近 80 倍，加上水合作用釋放能量——足夠補償拆開晶格的代價。**「為什麼在水裡會自發電離」的微觀解釋**要到波恩循環（1919–20）與熱力學才算嚴密，但宏觀證據鏈 1884 年已閉合。
- 酸鹼定義隨之翻新：酸 = 產生 H⁺ 的物質（阿瑞尼士酸鹼定義，後被布朗斯特-勞里、路易斯接力擴充）。
- 阿瑞尼士活化能理論 `k = A e^{−Ea/RT}`（1889）是本案的副產品，至今仍是化學動力學第一公式。

## 戲劇性結局：從三等到金獎

- 1884 年的論文答辯由克列夫等老一輩嚴厲批判；克列夫後來成為提名他諾獎的主要推手。
- 諾委會討論時仍激烈分裂（「他的理論可能是錯的，獎要追回怎麼辦」），最終 1903 年頒獎。阿瑞尼士成為首位獲諾獎的瑞典人——評審體系親手把當年打三等的論文加冕為年度最佳。
- 副產品：阿瑞尼士 1896 年首度定量計算 CO₂ 濃度對地表溫度的影響——**溫室效應的定量先驅**；他亦提出生命可由孢子星際傳播（泛種論）。一生橫跨電化學、動力學、宇宙學。

## 後果

| 層面 | 影響 |
|---|---|
| 理論 | 電化學、酸鹼化學、膠體化學全面重寫；溶液不再是「分子湯」而是「離子海」 |
| 工業 | 電解工業（氯鹼、鋁冶煉 Hall–Héroult）獲得理論地基 |
| 教訓 | 評審的「常識」可能是最強的偏見——1903 案成為科學社會學的教科書案例 |
