# 1972 · Arrow 不可能性定理：民主可能嗎？

> 1972 費爾茲獎層級的經濟學獎（與 Hicks 共享）：Kenneth J. Arrow，表彰一般均衡與福利理論；其 1951 年的**不可能性定理**是本案最鋒利的證物

## 案情提要

18 世紀啟蒙時代以來，社會選擇的聖杯：**能否設計一個完美的投票規則，把每個人的偏好「公正地」匯總成社會偏好？** Borda（1770）、Condorcet（1785）已見到投票的悖論（多數循環：A > B > C > A）。Arrow 1951 年證明：**不存在**。這不是「現有投票制不好」，而是**任何**投票制都必然違反至少一條最基本的公平條件。

## 前因

| 年份 | 事件 |

| 1785 | Condorcet 悖論：三選項多數決可出現循環 |
| 1938 | Bergson 社會福利函數概念 |

| 1951 | 《Social Choice and Individual Values》出版 |

## 調查：四條基本條件與一個矛盾

Arrow 要求社會福利函數 F（把偏好組合映射為社會排序）滿足：

| 條件 | 內容 |
|---|---|
| **無限制域**（U） | 任何偏好組合皆允許 |
| **Pareto 原則**（P） | 若人人偏好 x 勝 y，則社會偏好 x 勝 y |
| **無關方案獨立性**（IIA） | 兩方案的社會排序只取決於個體對這兩方案的排序（與第三方案無關） |
| **非獨裁**（D） | 沒有一個人的偏好可單獨決定社會排序 |

**Arrow 定理**：當候選方案 ≥ 3，**同時滿足 U + P + IIA + D 的社會福利函數不存在**。

證明核心（「** pivotal voter**」推理）：在任意偏好組合下，總能找到一個「關鍵投票者」——他單獨改變立場即可翻轉社會排序；再以 Pareto 原則證明他可以強加**與自己無關的**方案排序於社會之上，即成為**獨裁者**。

**四條看似無害的條件，邏輯上互相矛盾。**

## 理論裁決

- **一般均衡的正面戰果**（與本定理同年代）：Arrow 與 Debreu（1983 費爾茲獎）1954 年證明 **競爭均衡的存在性**（以 Brouwer/Kakutani 不動點定理），1959 年的《競爭經濟的存在性》把 Walras 的百年猜想變成定理。
- 不可能性定理的實務意義：**不存在完美的民主**——任何投票制都有被操縱的可能（Gibbard–Satterthwaite 定理 1973 是其延伸：任何非獨裁規則皆可被策略性投票操縱）。

## 後果

| 層面 | 影響 |
|---|---|
| 政治學 | 投票制度設計（IRV、Borda、Condorcet 投票）的理論基礎；Rank-Choice 爭議的學理根源 |
| 賽局 | 機制設計（[2007 Hurwicz–Maskin–Myerson](README.md)）是「放棄完美、尋找可實現」的務實後代 |
| 市場設計 | 2012 Roth–Shapley 的匹配理論，「機制」取代「規則」成為工程學 |
| 哲學 | 「集體理性」概念被證明有限——民主的正當性來自程序而非邏輯必然 |
