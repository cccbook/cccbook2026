# 1970 · Samuelson 數學化革命：把整個經濟學寫成一組方程式

> 1970 費爾茲獎層級的經濟學獎：Paul A. Samuelson（MIT），表彰「以科學方法提升經濟分析的靜態與動態理論」——獲獎理由涵蓋幾乎所有經濟學次領域

## 案情提要

1947 年前，經濟學主要靠文字論證與圖解：供需曲線畫一畫、口語推論推一推——同一命題常有不同結論。Samuelson 的博士論文《經濟學分析基礎》提出一個近乎狂妄的方案：**把經濟學的全部理論寫成有可比較靜態性質的數學結構**。懸案：**經濟學能不能像力學一樣，從幾條基本原理推出所有定理？**

## 前因

| 年份 | 事件 |
|---|---|
| 1932 | Samuelson 入芝加哥大學（時值大蕭條，經濟學的社會地位暴跌） |
| 1936–37 | Keynes《通論》出版；Hicks 的 IS-LM 翻譯 |
| 1938 | Samuelson 的「顯示偏好」論文 |
| 1941 | 博士論文完成（哈佛，導師 Schumpeter 稱之「天才之作」） |
| 1948 | 《經濟學》教科書出版，全球銷量逾 400 萬冊，影響三代學生 |

## 調查：Samuelson 的五大法寶

### 1. 對應原理（Correspondence principle）

比較靜態的良態性（比較靜態導數的正負號）與動態穩定性**同源**：一個均衡在動態上穩定，其比較靜態才有明確方向——把靜態與動態焊接在同一組微分方程上。

### 2. 顯示偏好理論（1938）

不需假設效用函數，只需觀察消費者的選擇即可推得需求性質：

`若 x 在預算集 B₁ 中被選，而 y 也在 B₁ 中，則 y 從不被選擇於 B₂ ⊂ {x 可得的集合}`

——**從行為反推偏好**，這是「用最少假設解釋最多現象」的範式。

### 3. 因素均等化定理（1948，Heckscher–Ohlin–Samuelson）

兩國貿易可使**要素價格完全均等**（不須移民）——全球化分配效應的第一個嚴格定理，也是當代貿易政治經濟學（[2024-制度與繁榮](2024-制度與繁榮.md) 的分配面）的源頭。

### 4. 乘數-加速數模型（1939）

投資的加速原理 × 消費的乘數 = **內生的經濟波動**——不須外部衝擊，市場自己會震盪（Frisch 案 [1969-首屆與計量經濟學](1969-首屆與計量經濟學.md) 的具體化）。

### 5. 公共支出理論（1954）

公共財的最優條件（Samuelson 條件）：

`Σ_i MRS_i = MRT`（所有人邊際替代率之和 = 邊際轉換率）

——與私人財的 `MRS = MRT` 對比，揭示市場為何**無法**自發提供公共財（[2009-Ostrom與公地治理](2009-Ostrom與公地治理.md) 的理論對面）。

## 理論裁決

- Samuelson 的綜合方案被稱為「**新古典綜合**」（Neo-classical synthesis）：以微觀最優化為基礎 + Keynes 有效的總量理論，成為 1950–1970 年代西方主流。
- 《經濟學分析基礎》的寫法成為現代經濟學論文的**標準格式**：定義 → 引理 → 定理 → 證明 → 應用。

## 後果

| 層面 | 影響 |
|---|---|
| 教育界 | 《經濟學》統一全球教材；「經濟學=數學社會科學」的自我形象 |
| 實證 | 其學生（如 Solow 1987、Mundell 1999）延續 MIT 學派 |
| 批評 | 1970s 之後被 Lucas 批判（[1995-Lucas批判](1995-Lucas批判.md)）質疑其微觀基礎不足——新古典綜合的「動態最優化」重寫 |
| 判例 | 一人榮獲「涵蓋所有次領域」的獎——諾獎史上唯一 |
