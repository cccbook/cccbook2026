# 1969 · 首屆經濟學獎：一個「紀念」獎的身分證

> 1969 瑞典央行紀念諾貝爾經濟學獎首屆：Ragnar Frisch（挪威）、Jan Tinbergen（荷蘭），表彰計量經濟學之開創

## 案情提要

1968 年，瑞典央行行長 Asbrink 提議為建行 300 週年設立一個「跟諾貝爾獎同級」的經濟學獎。諾貝爾基金會的反應是**反對**：遺囑白紙黑字只有五獎，加設新獎違反捐贈人意志。懸案：**如何在不傷害遺囑權威的前提下，給經濟學一張「諾貝爾級」的身分證？** 結果是法律技術的傑作：**改名 + 修法**。

## 前因

| 年份 | 事件 |
|---|---|
| 1895 | 諾貝爾遺囑僅五獎 |
| 1900 | 諾貝爾基金會章程通過（皇家科學院受託物理、化學、經濟） |
| 1930–60s | 經濟學「數學化」成熟（Samuelson 1947、Frisch 的術語系統），社會地位高漲 |
| 1967 | 瑞典議會通過《中央銀行紀念獎法》，獎金由央行全額捐助、程序全依諾獎規則 |
| 1969-12-10 | 首屆頒獎——刻意低調，避免「搶諾獎風頭」的批評 |

## 調查：Frisch 的三項「立案」貢獻

### 1. 給學科命名（1926–1933）

Frisch 創造了「**Econometrics**」（計量經濟學）一詞，並創立**計量經濟學會（Econometric Society, 1930）**與《Econometrica》期刊——把數理經濟、統計與經濟理論焊接成一個獨立學科。

### 2. Tinbergen 的第一個「可檢驗模型」

Tinbergen（荷蘭中央統計局）1936 年為荷蘭、1939 年為美國（1919–1932）建立**第一個完整宏觀經濟計量模型**，用統計估計參數、預測經濟波動。他是「**目標-工具**」（Tinbergen Rule）的提出者：要達成 n 個政策目標，至少需要 n 個獨立政策工具——今日貨幣與財政分工的數學根源。

### 3. 方法論的宣言

Frisch 主張：經濟理論若不可檢驗、經驗若無理論框架，皆無意義。他的「**衝擊-傳播機制**」（propagation mechanism）模型把經濟週期視為隨機衝擊經由結構性滯後放大——**Slutsky、Frisch、Kalecki 路線**成為後來 RBC 理論（[2004 Kydland–Prescott](README.md)）的直系祖先。

## 理論裁決

- 本獎的合法化結構：

`瑞典央行出錢 + 皇家科學院評選 + 諾貝爾基金會掛名 + 立法背書 = 「紀念獎」`

- **自律條款**：首屆刻意低調（Frisch 的領獎演說題為「從烏托邦理論到實際應用」），以緩解「非諾貝爾」的質疑。
- 1986 年起每年仍有科學家聯名要求廢除——「**經濟學是否夠格稱科學**」的哲學爭議成為本獎的持續二審（1986 Krebs、2016 Ferguson 等聯名）。

## 後果

| 層面 | 影響 |
|---|---|
| 學科 | 「經濟學=可檢驗的科學」的定位自此被制度化（1970 Samuelson、1989 Haavelmo 接力） |
| 政策 | Tinbergen 模型 → 1970s 世界大型計量模型（Klein, 1980）、國際貨幣基金/世銀的預測框架 |
| 制度 | 「紀念獎」名稱正式化：官方文件從不寫「諾貝爾經濟學獎」 |
| 判例 | 以「捐設人以外的組織」擴充獎項——純粹派至今仍視此為違憲先例 |
