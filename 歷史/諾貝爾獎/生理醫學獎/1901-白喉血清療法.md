# 1901 · 白喉血清療法：從「死神的童謠」到抗體的誕生

> 1901 首屆諾貝爾生理學或醫學獎：埃米爾·馮·貝林（Emil von Behring），表彰白喉血清療法

## 案情提要

十九世紀末，白喉（Diphtherie）是兒童頭號殺手：喉部的偽膜堵塞氣管，死亡率在幼兒高達 40–50%。柏林一年奪走五萬名兒童。病原體白喉桿菌 1883 年已被發現——**但知道兇手是誰，不會救人**。懸案是：細菌本身並不進入血液，為何全身中毒？兇器在哪裡？

## 前因

| 年份 | 事件 |
|---|---|
| 1883 | 克勒布（Klebs）發現白喉桿菌；呂弗勒（Löffler）純培養 |
| 1884 | 科霍法則確立（見 [1905-科霍與結核桿菌](1905-科霍與結核桿菌.md)） |
| 1888 | 魯（Roux）與耶爾辛（Yersin）證明：細菌培養液的**無細胞濾液**即可殺死豚鼠——**兇器是外毒素**，一種可溶蛋白 |
| 1890 | 貝林與北里柴三郎登場：追問「毒素能否被中和」 |

## 調查：免疫血清的發明

貝林（軍醫出身的科霍門生）與北里在科霍實驗室做了一系列關鍵實驗：

1. 以亞致死量白喉毒素多次免疫山羊/天竺鼠 → 動物存活並「記得」毒。
2. 取其**血清**注射給健康動物 → 再注射致死量毒素仍存活。
3. 結論：中和能力存在於**血清（無細胞部分）**，不在細胞裡——他們稱之「抗毒素」（antitoxin）。

**「血清療法」誕生**：免疫動物的血清即可被動轉移免疫力。這是史上第一次「把免疫力裝瓶出售」。

1894 年臨床試驗（柏林、巴黎）結果：白喉死亡率從約 48% 降至約 15%——19 世紀兒科醫學最壯觀的數字逆轉。1895 年起德國藥廠量產馬血清，白喉由絕症變成可治療病。

## 理論裁決

- 貝林的實驗成功早於理論。免疫學的「為什麼」要等埃利希（1908 同案得主）的**側鏈理論**（side-chain theory）：細胞表面有與毒素互補的受體（側鏈），過量產生並釋放至血液即為抗體——史上第一個抗體形成學說，雖然細節後被推翻，但「**受體-配體互補**」的框架沿用至今。
- 量化的語言：埃利希以「免疫單位」標準化抗毒素效價——**生物製劑的標準化**（單位/劑量）自此成為藥政管理的基礎（今日疫苗效價單位的遠祖）。
- 1894–96 年間，補體（波爾德特，1919 諾獎）的發現補足了免疫的第二條路徑——補體結合反應成為梅毒診斷（瓦瑟曼反應，1906）的基礎。

## 後果

| 層面 | 影響 |
|---|---|
| 兒科 | 白喉死亡率驟降；抗毒素+類毒素疫苗（1923 拉蒙）最終在已開發國家幾乎消滅白喉 |
| 免疫學 | 體液免疫 vs 細胞免疫（梅契尼科夫，1908）兩大傳統並立，1960s 才由 T/B 細胞統一 |
| 產業 | 血清療法是第一個「生物製藥」——馬血清農場、標準化效價、冷鏈 |
| 諾獎判例 | 1901 年以「直接救命」為首要判準——此後百年，醫學獎始終在「基礎發現」與「臨床療效」間擺盪 |
| 貝林本人 | 獲貴族頭銜「von」；製造結核血清失敗（結核的免疫謎團直到 1970s 才部分解開）；1914 年建立 Behringwerke，成為今日 CSL Behring |
