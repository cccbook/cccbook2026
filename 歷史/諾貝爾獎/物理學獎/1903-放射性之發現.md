# 1903 · 放射性之發現：鈾礦裡的恆定火苗

> 1903 諾貝爾物理學獎：貝克勒（一半）、皮耶·居禮與瑪麗·居禮（共享另一半）

## 案情提要

1896 年 2 月，巴黎的貝克勒想追查「螢光物質是否也會發出 X 射線」。天不配合——巴黎連日陰天，他把包著黑紙、壓著鈾鹽的底片收進抽屜。幾天後沖洗，**底片照樣曝光**。不需要陽光、不需要通電，鈾自己就是光源。這是純粹的意外，但貝克勒沒有把底片當瑕疵丟棄。

## 前因

- 1895 倫琴發現 X 射線（見 [1901-倫琴與X射線](1901-倫琴與X射線.md)），全歐掀起「什麼物質會發射射線」的淘金熱。
- 貝克勒家族三代研究螢光與磷光，手邊現成的「陳年樣本」正是硫酸鉀鈾醯。

## 調查過程

貝克勒逐步排除嫌疑人：

1. 陰天 → 底片仍曝光 → **排除「日光激發」假說**。
2. 換用不發螢光的鈾鹽 → 仍有效應 → **排除「螢光」假說**。
3. 鈾金屬（非化合物）→ 效應更強 → **鎖定元素「鈾」本身**。

結論：這是一種**自發的、持續的、與化學狀態無關**的「鈾射線」。

瑪麗·居禮 1897 年以此為博士論文題目，用皮耶發明的壓電靜電計精密測量射線的電離電流：

- 各種鈾化合物 → 電離度只與**鈾含量**成正比 → 放射性是**原子性質**，不是分子性質（當時的革命性論斷）。
- 瀝青鈾礦的放射性强於純鈾 → **礦石裡藏著未知元素**。
- 夫婦二人以噸計處理礦渣，1898 年 7 月發現**釙**（紀念波蘭）、12 月發現**鐳**。

## 理論裁決

放射性背後的理論要等到量子力學與核物理才完備：

- 1902 盧瑟福與索迪提出**蛻變理論**：原子衰變是指數過程
  
  `N(t) = N₀ · e^(−λt)`，半衰期 `t½ = ln2 / λ`

- 這是「元素會轉變」自中世紀鍊金術以來首次有定量證據——化學的公理被物理改寫。
- 能量來源之謎：鐳持續發熱 100 kcal/h/g，遠超任何化學反應。愛因斯坦 1905 年的質能關係 `E = mc²` 給出答案：質量虧損轉為能量。

## 後果

| 層面 | 影響 |
|---|---|
| 科學 | 開啟原子核物理；同位素概念（索迪 1913，1921 化學獎） |
| 醫學 | 鐳療法治癌；居禮基金會成立 |
| 社會 | 鐳「發光手錶」狂熱 → 1920s 鐳姑娘訴訟案 → 勞工輻射防護立法 |
| 代價 | 皮耶 1906 年死於馬車車禍（可能受衰弱體質影響）；瑪麗 1934 死於再生不良性貧血 |
| 榮耀 | 瑪麗·居禮 1911 年再獲化學獎，至今唯一「兩科學門、雙諾獎」者 |
