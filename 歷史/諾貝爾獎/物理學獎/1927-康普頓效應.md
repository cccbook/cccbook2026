# 1927 · 康普頓效應：光子撞球的目擊證詞

> 1927 諾貝爾物理學獎（一半）：亞瑟·康普頓（Arthur Compton），表彰康普頓效應之發現；另一半頒給雲霧室發明者威爾森

## 案情提要

1922–1923 年，康普頓用 X 射線（λ ≈ 0.07 nm）照射石墨，發現散射光中除了原波長，還出現**波長變長**的成分（λ′ > λ）。經典電磁理論無法解釋——湯姆森散射中，電子只是「隨波振盪」再輻射，波長不該改變。散射光為何「變紅」？

## 前因

- 1905 愛因斯坦光子假說（[1921-愛因斯坦光電效應](1921-愛因斯坦光電效應.md)）解釋了「光的能量是顆粒狀」，但光電效應只涉及**能量**，未涉及**動量**——它不能排除「光子只是能量包裹，仍寄居在波裡」的折衷說。
- 要定讞光子是**完整粒子**（同時具有能量與動量），需要看到它像撞球一樣**交換動量**。

## 推理：相對論性撞球

康普頓把 X 光光子與（近似自由的）外層電子視為兩顆撞球，用狹義相對論的能量-動量守恆聯立求解：

- 能量守恆：`hν + m₀c² = hν′ + γm₀c²`
- 動量守恆（向量）：`ħk = ħk′ + γm₀v`

兩式聯立消去電子變數，得到驚人的乾淨結果：

**康普頓公式**：

`Δλ = λ′ − λ = (h / m₀ c)(1 − cos θ)`

- `h/m₀c ≈ 0.00243 nm`，即**電子的康普頓波長**——只與電子質量有關，與入射波長、材料無關。
- 預言：散射角 θ = 90° 時 Δλ ≈ 0.00243 nm。實驗測得完全吻合。

## 鑑識細節

- 波長變長 = 光子把**動能與動量**交給電子 → 光子必須是攜帶動量 `p = h/λ` 的實體粒子。
- 散射電子確實被「彈飛」（後由威爾森雲霧室拍到電子徑跡，與理論軌道一致——兩位得主在同一案件中互為人證物證）。
- 低頻光（可見光）Δλ/λ 太小、電子又被原子緊縛（等效質量趨近原子質量），故效應不顯——這完美解釋了為何「案子拖到 X 光時代才破」。

## 理論裁決與後果

- 康普頓效應是**波粒二象性的最終實錘**：光既是波（干涉、繞射），又是粒子（動量交換）。
- 反向案例：戴維森與 G.P. 湯姆森 1927 年發現**電子**繞射（1937 諾獎）——物質也有波性，`λ = h/p`。波粒二象性成為普適規律，最終由德布羅意（1929 諾獎）與量子力學統一。

`E² = (pc)² + (m₀c²)²`，`λ = h/p` —— 光與物質在相對論性量子論中合流。

- 技術後果：康普頓成像（核醫學）、輻射防護計算、宇宙射線研究。
