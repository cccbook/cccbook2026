# 1901 · 倫琴與 X 射線：一道穿牆的光

> 諾貝爾物理學獎第一屆（1901）得主：威廉·倫琴（Wilhelm Conrad Röntgen）

## 案情提要

1895 年 11 月 8 日晚，德國符茲堡大學的倫琴在暗室中做陰極射線實驗，發現一米外鍍有鉑氰化鋇的螢幕竟發出微光。陰極射線在空氣中最多飛行數公分，是什麼穿透了距離？

## 前因（線索鏈）

| 年份 | 線索 |
|---|---|
| 1858 | 普呂克爾觀察到陰極射線使管壁螢光 |
| 1869 | 希托夫證明射線沿直線前進並能投下陰影 |
| 1876 | 戈德斯坦命名「陰極射線」（Kathodenstrahlen） |
| 1880s | 克魯克斯管普及；多次有人拍到不明霧狀底片（被當成瑕疵丟棄） |

## 調查過程

倫琴連續七週閉門實驗，逐一排除變數：

1. **不是陰極射線本身**：用黑紙完全包住玻璃管，螢光仍在。
2. **穿透力驚人**：能穿透書本、木板、甚至薄金屬片；鉛則幾乎完全阻擋。
3. **不帶電、不磁偏轉**：排除了帶電粒子的身分。
4. **不能反射、折射**：光是「直線」傳播的陌生波或粒子。
5. **著名證據**：為妻子安娜拍下第一張「透視」照——手上骨骼與戒指清晰可見。

倫琴因不明其本質，以數學上代表未知的字母命名：**X 射線**。

## 理論裁決

X 射線本質之謎直到 1912 年勞厄繞射實驗（1914 諾獎）才裁決：它是一種波長極短（約 0.01–10 nm）的電磁波。

- 電磁波譜：`λ_X-ray ≈ 10⁻¹² ~ 10⁻⁸ m`
- 產生機制：高能電子撞擊金屬靶，急速減速時輻射**制動輻射**（Bremsstrahlung），並疊加靶材特徵譜線。
- 倫琴定律：連續譜最短波長與加速電壓成反比：
  
  `λ_min = hc / eV`

## 判決後的餘波（後果）

- 醫學影像革命：1896 年即出現第一批骨折 X 光診斷；一戰中居禮夫人的「小居禮」流動 X 光車拯救大量傷兵。
- 倫琴拒絕申請專利（「發現應屬於全人類」），只領取諾貝爾獎金。諾貝爾基金會明文規定獎項「不得申請專利」，倫琴立下典範。
- 代價：早期研究者與技術員大量罹患輻射傷害，促成 1920s 輻射防護學誕生——這條線索最終引向放射線醫學與 1903 年的居禮家族案件。
