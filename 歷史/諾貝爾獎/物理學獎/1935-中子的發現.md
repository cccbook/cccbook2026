# 1935 · 中子的發現：原子核失踪質量案的破案關鍵

> 1935 諾貝爾物理學獎：詹姆斯·查兌克（James Chadwick），表彰 1932 年中子之發現

## 案情提要

1920 年代，原子核有一樁「失蹤案」：氦核質量 ≈ 4 個質子，但電荷只有 +2e；氮核質量 14、電荷 +7。若核內只有質子，**質量與電荷對不上帳**。當時的假說「質子+電子混在核裡」雖能湊帳，卻違反量子力學：氮-14 的自旋實測為整數，質子+電子模型（14+7 個自旋 ½ 粒子）必給半整數。

## 前因：三條線索

| 年份 | 線索 | 結局 |
|---|---|---|
| 1920 | 盧瑟福在貝克講座提出核內可能有「中性粒子」 | 理論預言，苦無證據 |
| 1930 | 波特與貝克爾用 α 粒子轟擊鈹，測得一種穿透力極強的輻射 | 誤判為「高能 γ 射線」 |
| 1931 | 約里奧-居禮夫婦發現此輻射能把石蠟中的質子打出，且質子能量高達 5 MeV | 距真相一步之遙——仍用 γ 射線的康普頓散射解釋，算出的 γ 能量與動量守恆矛盾，他們沒有追問 |

約里奧-居禮的計算陷阱：若輻射是光子，要打動 5 MeV 的質子，光子需約 50 MeV——但上游 α 轟擊鈹的總能量根本不夠。**帳對不上，卻沒人重算**。卡文迪許實驗室的查兌克讀到法國同行報告的當晚，意識到：這不是 γ 射線，是**質量與質子相當的中性粒子**。

## 調查過程

查兌克兩週內完成一系列鑑識實驗：

1. 用鈹射線轟擊氫、氦、氮，測出各反衝核的最大動能。
2. 由動能反推入射粒子質量：`m ∝ 1/(E_recoil)` 給出質量 ≈ 1.15 m_p（約質子質量）。
3. γ 射線（無質量）不可能造成如此重核的反衝——數量級就差十倍以上。
4. 對帳成功：**電荷為零、質量近似質子的粒子**——中子。

核反應帳目：`⁹Be + ⁴He → ¹²C + ¹n + 5.7 MeV`，收支平衡。

## 理論裁決

- 中子的存在使「質量數 A、電荷數 Z」的核組成帳目完全理順：`原子核 = Z 個質子 + (A−Z) 個中子`。
- 自旋懸案解決：中子自旋 ½，偶數個核子 → 整數自旋，氮-14（7p+7n）自旋 1，吻合。
- 更深層：中子並非質子+電子的複合物（那個模型連帳都湊不平——結合能與 β 衰變電子譜矛盾），而是基本粒子。1933 年費米提出 β 衰變理論：`n → p + e⁻ + ν̄`。

## 後果：從鑰匙到蘑菇雲

| 年份 | 事件 |
|---|---|
| 1934 | 費米用慢中子誘發各元素人工放射性（1938 諾獎） |
| 1938-12 | 中子轟擊鈾 → 哈恩與斯特拉斯曼發現核分裂 |
| 1939-01 | 邁特納與弗里施解釋分裂：`E = mc²` 釋放約 200 MeV／分裂 |
| 1942 | 費米建成首座自持反應堆 |
| 1945-07-16 | Trinity 核試——中子這把鑰匙打開了潘朵拉之盒 |

諷刺的註腳：約里奧-居禮夫婦三度與諾獎「擦肩中的近距離接觸」（1932 中子、1933 正電子、1938 分裂），1935 年終以人工放射性獲化學獎。錯過中子的原因不是儀器，而是**沒有重算那筆對不上的帳**——科學史上最貴的一次心算失誤。
