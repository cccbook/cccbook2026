# 諾貝爾物理學獎 歷史年表（詳細版）

> 本年表以「事件」為單位，收錄 1895 年起至 2024 年的重要節點。
> 詳細的「推理探案式」wiki 請見本目錄下以年份開頭的各篇檔案。

## 序幕：獎項的誕生（1833–1900）

| 年份 | 事件 |
|---|---|
| 1833 | 阿爾弗雷德·諾貝爾（Alfred Nobel）出生於斯德哥爾摩 |
| 1867 | 諾貝爾取得硝化甘油炸藥（Dynamite）專利，累積巨額財富 |
| 1888 | 誤讀自己訃聞（哥哥過世被誤報），自省「發明殺人武器者不應死無葬身之地」 |
| 1895-11-27 | 諾貝爾簽署遺囑，捐出遺產 3100 萬瑞典克朗設立五項大獎（物理、化學、生理醫學、文學、和平） |
| 1896-12-10 | 諾貝爾逝世，此日後來成為每年頒獎日 |
| 1897–1900 | 遺囑爭議與法律程序；1900 年諾貝爾基金會成立，瑞典皇家科學院受託頒發物理獎 |
| 1901-12-10 | 第一屆頒獎，倫琴獲物理學獎 |
