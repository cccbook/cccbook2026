# 1998：金盾工程與防火長城（GFW） — 「牆內市場」的誕生

## 案情

1998 年，公安部啟動「金盾工程」，建設全國公安資訊系統；同年，「防火長城」（Great Firewall, GFW）開始建設，對境外網站與資訊流進行過濾、封鎖。此後 25 年，「牆」成為中國網路產業最重要的結構性變數。

## 前因

- 1994 中國接入網際網路（見 1994 檔案）。
- 1997–1998 年網路快速普及，境外資訊（新聞、BBS）湧入。
- 1999 年法輪功事件——管控從「嘗試」轉為「系統工程」。

## 線索與推理

**GFW 的技術結構**：

| 層 | 技術 | 功能 |
|----|------|------|
| DNS 層 | 污染 | 網域名解析到錯誤 IP |
| IP 層 | 黑名單 | 封鎖特定位址 |
| 內容層 | 關鍵字過濾 | 深度封包檢測（DPI） |
| 自我審查 | 平台責任 | **把審查外包給公司** |

**最精妙的設計是最後一層**——「自我審查外包」：

$$
C_{審查總成本} = C_{國家設備} + \sum_{平台} C_{平台自查}
$$

國家只建「管道」，內容責任壓給平台——**審查成為每家公司的營運成本**（微信、微博、抖音的內容審核團隊數以萬計）。

**「牆」的產業後果——溫室效應**：

$$
V_{中國網路巨頭} = V_{全球同類} \times (\text{無國際競爭者} + \text{14億市場})
$$

Google 退出（2010）後百度獨占搜尋；Facebook 進不來 → 騰訊/微博/抖音瓜分社交；Amazon 敗退 → 阿里京東壟斷。**牆造就了全球市值最高的網路公司群**。

## 理論：受保護市場的「內卷創新」

| 效應 | 機制 |
|------|------|
| 溫室紅利 | 無國際競爭 → 巨頭快速長大 |
| **內卷烈度** | 市場封閉但本土競爭者多 → 產品迭代極致 |
| 出海悖論 | 牆內練出的能力（推薦算法、超級 App）反向全球擴張（TikTok） |

## 後果

- 百度、阿里、騰訊（BAT）、字節跳動在「牆內」成長為全球級公司。
- Google 2010 年退出（見 2010 檔案）——地緣化的轉折。
- TikTok 的全球成功反向觸發美國「**要不要建自己的牆**」的辯論（2020–2024 美國 TikTok 禁令）——**「牆」的技術與理念被反向輸出**。
- 長期成本：開源/學術隔絕、人才流動受限——基礎創新的隱形債。

## 冷案檔案

- 時間：1998 年起
- 案由：管控技術如何成為產業結構本身
- 教訓：**牆既是政治工具，也是產業邊界——它同時製造了巨頭與天花板**。
