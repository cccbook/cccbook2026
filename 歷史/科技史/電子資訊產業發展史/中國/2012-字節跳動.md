# 2012：字節跳動與推薦算法 — 「算法即入口」的新帝國

## 案情

2012 年 3 月，張一鳴在北京創立字節跳動，第一款產品「今日頭條」不做編輯、不用社交鏈，**只用推薦算法決定你看什麼**。十年後，字節成為全球用戶量最大的內容公司（抖音+TikTok 合計 20 億+用戶），營收超過騰訊——**「算法分發」打敗「社交分發」與「編輯分發」**。

## 前因

- 2010 年代初，內容分發的三種模式並存：編輯（門戶）、社交（微博）、搜索（百度）。
- 張一鳴的判斷：「**技術不是工具，是分發的本身**」。
- 智慧手機普及（2012 智慧機出貨爆發）→ 個人化數據第一次可規模收集。

## 線索與推理

**推薦算法的冷啟動勝利**：

$$P_{點擊} = f(\text{用戶畫像}, \text{內容特徵}, \text{上下文}) \quad \text{（協同過濾 + 深度模型）}$$

- 微信的分發靠「朋友讀過」→ 依賴社交密度。
- 頭條的分發靠「你點過什麼」→ **零社交依賴，冷啟動即可運轉**。
- 結果：頭條日活超微博只用了 2 年。

**抖音的極端化**（2016）：全螢幕、單條、演算法直投——

$$\text{沉浸度} \propto \frac{\text{單位決策成本}^{-1}}{\text{內容切換頻率}}$$

用戶不需要選擇（算法替你選）→ 決策成本為零 → **使用時長的物理極限**。抖音日均在線超過 100 分鐘——人類媒體史上最高。

**TikTok 的出海**（2017）：**字節是「牆內公司」中唯一成功全球化的**——因為推薦算法不需要「牆」（不依賴 GMS、不依賴微信關係鏈、不需要本地支付），**算法能力本身就是通用護照**。

## 理論：分發權的歷史遷移

```
編輯分發（1990s 門戶）→ 搜索分發（2000s 百度）→ 社交分發（2010 微博/微信）
→ **算法分發（2012 字節）**
```

每一次遷移都重新分配「**注意力經濟**」的租金。算法分發的爭議也最大：

| 爭議 | 本質 |
|------|------|
| 成癮設計 | 注意力最大化 vs 用戶福祉 |
| 資訊繭房 | 個人化的副作用 |
| 數據主權 | TikTok 在美國的國安指控（見「牆」的雙面推理） |

## 後果

- 2020 年代：字節營收超騰訊，成為中國第一大（未上市）科技公司。
- TikTok 在美國遭遇禁令戰（2020 川普、2024 立法）——**算法出海觸發地緣反彈**。
- 淘寶、百度、美團全部「抖音化」——**算法分發成為全行業的標準答案**。
- 2021 年後中國加強「算法監管」（《互聯網信息服務算法推薦管理規定》）——**帝國被牆內的規則反噬**。

## 冷案檔案

- 時間：2012 年
- 案由：分發權從「關係」與「編輯」轉移到「算法」手中
- 教訓：**誰掌握分發，誰掌握注意力——注意力是網路時代唯一的主權貨幣**。
