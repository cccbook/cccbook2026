# 1997：軟體產業為何輸給硬體那麼多 — 台灣資訊業的「結構性病例」

## 案情

2020 年代，台灣硬體產業：台積電市值逾 8,000 億美元、IC 產值 5 兆台幣、筆電代工全球 70%。台灣軟體產業：無一家市值破 100 億美元的上市軟體公司（趨勢科技約 70 億）、軟體產值占 GDP 不到 1%、人均產值不到硬體的 1/5。**同一批人、同一個島、同一個時期——為什麼軟體輸了 20 年？**

本篇為「偵探總結報告」：綜合 1979、1986、1988、1995 四份現場證據，提出七項結構性病因。

## 證據清單（先看事實）

| 指標 | 台灣硬體 | 台灣軟體 |
|------|---------|---------|
| 全球地位 | 晶圓代工 90%+、封測 50%+、筆電 70%+ | 幾乎無全球要角 |
| 龍頭市值 | 台積電 ~8,000 億美元 | 趨勢科技 ~70 億美元 |
| 資本市場支持 | 半導體占台股 1/3 | 軟體股占比 <1% |
| 人才流向 | 竹科工程師年薪 150–300 萬 | 軟體工程師常須外流（美/中）才有機會 |
| 成功樣本 | 台積電、聯發科、大立光、鴻海 | **趨勢科技（n=1）** |

## 病因一：內需市場太小（需求側）

$$
V_{軟體公司} = V_{產品} \times N_{用戶}
$$

軟體的邊際成本近零，但**固定成本（研發）需要用戶規模攤提**：

- 美國：4 億人口 + 全球英語市場 + 企業 IT 預算 = 天然放大器。
- 中國：14 億人的封閉市場 = 溫室。
- **台灣：2,300 萬人 + 無語言壁壘保護**——內銷天花板太低，產品一出生就該外銷，但外銷需要的資本與渠道又是台灣最缺的。

**對照**：硬體的攤提靠「全球客戶的代工訂單」——台灣硬體公司不需要「本國市場」就能長大；軟體需要「本國市場練兵」再出海——**台灣剛好缺這塊跳板**。

## 病因二：盜版文化摧毀了第一批賣斷型軟體（1986 倚天案）

1980–2000 年台灣 PC 軟體盜版率 90%+。當「付費買軟體」的社會契約不存在，第一代軟體公司的收入模型（賣斷）全數死亡。**硬體不怕盜版（抄不走晶圓廠），軟體最怕（複製零成本）**——同一個法律環境，對兩個產業的殺傷力完全不同。

## 病因三：政府專案依賴症（1979 資策會案）

台灣軟體公司的主要收入來源長期是**政府標案**（戶政、稅務、國防）：

| 標案邏輯 | 產品邏輯 |
|---------|---------|
| 最低標取勝 → 殺價 | 價值定價 |
| 客戶唯一（政府） | 客戶分散 |
| 交件即結案（無維運文化） | 持續迭代 |
| 勝負在「關係與規格綁標」 | 勝負在「產品力」 |

$$
\text{標案公司} \neq \text{產品公司} \quad (\text{兩者的能力樹完全不同})
$$

最會投標的公司活下來、最會做產品的餓死——**逆向淘汰**。資策會的專案模式把整個產業的基因鎖在「代工/專案」。

## 病因四：資本市場的「硬體偏見」（定價機制）

台灣資本市場為硬體而生：

| | 硬體公司 | 軟體公司 |
|--|---------|---------|
| 估值邏輯 | 本益比（看獲利） | **PSR（看營收成長）** |
| 早期投資 | 少但存在（竹科天使） | **幾乎不存在**（創投要求「有廠、有設備、有抵押」） |
| 上市門檻 | 獲利即可 | SaaS 前期虧損 → 上不了 |

$$
V_{台股軟體} = \text{本益比} \times EPS \approx 10\text{倍} \quad vs \quad V_{美股SaaS} = 10\times \text{營收}
$$

**同一家公司，在台灣估值是在美國的 1/10**——台灣軟體公司只能去美國上市（趨勢、Gogoro、Appier），或長不大。資本的「重資產偏見」讓軟體新創在第一關就斷糧。

## 病因五：人才被硬體虹吸（機會成本結構）

台灣最強的理工人才去了哪裡？

$$
\text{人才選擇} = \max(\text{薪資}, \text{前景}, \text{地位})
$$

- 竹科硬體：股票分紅（1990 年代起）+ 全球產業地位。
- 軟體：薪資只有硬體的 1/2–1/3、無「台灣軟體巨頭」可以榮耀加入。

**因果迴路（惡性）**：

```
沒有軟體巨頭 → 人才不去軟體 → 軟體公司長不大 → 沒有軟體巨頭
```

同時，硬體的「輪班 + 製程紀律」文化訓練的人才，其技能與「產品直覺、用戶體驗、開源社群」的軟體文化**不互換**——人才池不但小，連型狀都不對。

## 病因六：沒有平台與生態位（戰略位階）

軟體業的贏家都「站在平台上」：

| 贏家 | 站在誰之上 |
|------|-----------|
| Microsoft | IBM PC 相容機 |
| Google/百度 | 開放網路 |
| 騰訊/字節 | Android + 牆內市場 |
| Salesforce | 雲 + 企業數位化 |

台灣的軟體公司沒有自己的平台（無 OS、無市場規模做入口、無雲帝國），只能「**在別人的平台上找縫**」——縫會被平台吸收（1986 倚天案）。

**對照**：趨勢科技成功，因為「資安」是平台**吸不走**的垂直剛需——證明台灣軟體的出路是「垂直深耕」，而非「平台爭奪」。

## 病因七：政策的「重硬輕軟」（制度路徑依賴）

政府的工具箱全是為硬體設計的：

| 政策工具 | 對硬體 | 對軟體 |
|---------|--------|--------|
| 園區（土地、宿舍） | ✓ 有效 | △（軟體需要的是城市與生活） |
| 設備折舊抵減 | ✓ | ✗（軟體無設備） |
| 研發補助（以專利計） | ✓ | ✗（軟體的資產是程式碼與用戶，非專利） |
| 上市條件（獲利制） | ✓ | ✗（見病因四） |

**軟體產業需要的工具**（政府採購開放給新創、數位公共基礎建設、開放資料、教育改革）——**一項都沒有系統性建立**。「軟體五年計畫」多次提出、多次無疾而終。

## 綜合診斷：一個自我強化的「反軟體系統」

$$
\text{軟體弱} = \underbrace{\text{市場小}}_{需求} \times \underbrace{\text{盜版}}_{歷史} \times \underbrace{\text{標案文化}}_{供給} \times \underbrace{\text{資本偏見}}_{資本} \times \underbrace{\text{人才虹吸}}_{人才} \times \underbrace{\text{政策錯配}}_{制度}
$$

六個變數**相互鎖定**——任一單獨修復都會被其他五個拉回。這就是為什麼「開一間好軟體公司」在台灣難度是全球最高級別：**不是工程師不行，是整個系統不發行軟體公司的股票（比喻：系統性的生存條件缺失）**。

## 破局的可能（2020 年代的新變數）

| 新變數 | 為何可能改變遊戲 |
|--------|----------------|
| SaaS 訂閱制 | 收入可驗證 → 台股已有 psyche 支持（Appier、iKala、91APP 赴美/上櫃） |
| 硬體的 AI 轉型 | 資安、邊緣 AI、工業軟體與硬體綁定——**台灣終於有「硬體帶軟體」的槓桿** |
| 工程師薪資追上 | 硬體高薪擠壓 → AI 世代軟體人才議價力回升 |
| 美中脫鉤 | 「**非紅供應鏈軟體**」（資安、企業 IT）出現地緣需求 |
| 雲端原生世代 | 不需要本地市場練兵，直接全球（Golden Ticket：英語市場 + 遠端工作） |

**偵探結論**：台灣軟體的失敗不是單一原因，是一個「六角鎖」。趨勢科技證明鎖可以被繞過（選對戰場），2020 年代的 AI 週期則可能是「鎖被整體替換」的第一個機會——因為 AI 的產業形態（軟硬整合、邊緣運算、訂閱服務）恰好是台灣現有能力的延伸，而非對抗。

## 冷案檔案

- 時間：1980–2025（本案跨度最長）
- 案由：同一教育體系與人才庫下，硬體霸權與軟體荒漠的並存之謎
- 終局推理：**硬體贏在「可路徑化的製造知識 + 全球代工需求」；軟體輸在「六個變數的惡性鎖定」——破局只能靠外部變數（AI、地緣）重設遊戲，而非內部修補**。
