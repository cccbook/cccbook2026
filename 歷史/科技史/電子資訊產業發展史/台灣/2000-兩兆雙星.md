# 2000：網路泡沫與「兩兆雙星」 — 用國家資源押注半導體＋面板

## 案情

2000 年網路泡沫破裂，台灣股市從萬點跌到三千。政府推出「兩兆雙星」計畫：半導體與顯示器產業產值各達一兆元，另以數位內容與生物科技為「雙星」。這是台灣最後一次大規模的「國家挑選產業」實驗。

## 前因

- 1990 年代台灣 IC 與筆電的成功，讓政府相信「挑產業」有效。
- 網路泡沫使美國科技股崩盤，台股跟跌，政府需要新故事。
- 韓國三星在面板與記憶體的政府補貼模式（對台）形成競爭壓力。

## 線索與推理

**「兩兆」的成績單**：

| 產業 | 結果 | 原因 |
|------|------|------|
| 半導體 | ✓ 成功（產值破兆） | 台積電代工模式已自成一體，政府只是推波助瀾 |
| 顯示器（面板） | △ 一度破兆，2010 年代衰退 | 資本密集、與韓陸競爭、無差異化 |
| 數位內容（雙星之一） | ✗ 失敗 | 文化與政策工具不匹配 |
| 生物科技（雙星之一） | ✗ 尚未突破 | 缺臨床/法規生態 |

**為什麼半導體成功、面板失敗？** 決定性差異是「**產業結構**」：

$$
\text{產業勝負} = f(\text{差異化能力}, \text{進入障礙}, \text{客戶黏著度})
$$

- 晶圓代工：差異化高（製程+服務）、障礙極高、黏著度高 → 贏者可持續。
- 面板：**商品化**（同尺寸同規格）、障礙中、無黏著 → 價格戰絞肉機。
- 台灣政府用同一套「資本+園區+租稅」工具支援兩者，結果天差地遠——**工具本身不決定成敗，產業結構才決定**。

## 理論：Porter 鑽石模型的台灣驗證

Porter 鑽石四要素：

```
1. 要素條件：人才、資本、土地（台灣：好）
2. 需求條件：本地市場（台灣：無，依賴外銷）✗
3. 相關支援產業：供應鏈（台灣：極好）✓
4. 企業策略與競爭：同質競爭激烈（台灣：過度）
+ 政府、機遇（輔助變數）
```

台灣模式的弱點：第 2 項（本地需求）長期缺失 → 產業必須「出口導向」→ 對全球景氣極敏感。

## 後果

- 2002 年友達併購達碁/廣輝、奇美電合併（見 2004 檔案）——「面板雙虎」成形。
- 2008 年 DRAM 與面板同時崩盤——「雙 D 慘案」。
- 政府此後不再大規模「挑產業」，改為較中性的「5+2、6 大核心戰略」。
- 歷史定位：兩兆雙星是「發展型國家」模式的最後一次高峰。

## 冷案檔案

- 時間：2000 年
- 案由：同一套政策工具，為何在兩個產業有相反結果
- 教訓：政策成功的關鍵變數不是「投入多少」，而是「產業結構是否適合此工具」。
