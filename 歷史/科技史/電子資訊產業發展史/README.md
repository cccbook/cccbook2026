# 電子資訊產業發展史 -- 總覽

以「推理探案」的方式，分四卷追查電子資訊產業的全球版圖如何形成：
**全球（原始卷宗）→ 日本（第一帝國）→ 台灣（分工革命）→ 中國（規模豪賭）**。

## 卷宗結構

| 卷 | 資料夾 | 主題 | 偵探謎題 |
|----|--------|------|---------|
| 1 | [全球/](全球/README.md) | 從電學起源到電晶體、個人電腦、網路與 AI——產業的「物理與架構」基礎 | 為什麼電子產業每隔 20 年就重新洗牌？ |
| 2 | [日本/](日本/README.md) | 家電帝國的崛起與解體，材料設備的隱形冠軍轉身 | 為什麼贏了製造的帝國，輸給了架構？ |
| 3 | [台灣/](台灣/README.md) | 組裝→IC→晶圓代工→AI 供應鏈；硬體霸權與軟體荒漠的並存之謎 | 同一批人，為什麼軟體輸給硬體那麼多？ |
| 4 | [中國/](中國/README.md) | 世界工廠、網路巨頭、大基金與制裁下的自主豪賭 | 規模換時間的貸款，什麼時候到期？ |

## 四卷的推理主線（時間軸）

```
1950s ──── 全球：電晶體/積體電路誕生（美國主場）
1955–1980  日本：收音機→家電→品質帝國（第一次移轉：美→日）
1976–1985  日本：VLSI 計畫，DRAM 占全球 80%（頂點）
1980–1987  台灣：園區+RCA 技術移轉（第二次移轉：美/日→台）
1987       台灣：台積電發明專業代工（產業架構革命）
1986–1995  日本：泡沫破裂、Wintel 標準化擊潰封閉帝國
1995–2005  中國：特區→入世→世界工廠（第三次移轉：台/日→中國）
2000s      四地分工成形：美（設計/標準）—台（代工/設計）—日（材料/設備）—韓（IDM）—中（製造/市場）
2013–2025  中國：大基金、制裁與自主豪賭；台積電成為地緣樞紐
```

## 三次產業轉移的共同公式

$$\text{轉移} = \text{成本差} + \text{技術可得性} + \text{政治允許度}$$

| 轉移 | 成本差 | 技術可得性 | 政治允許度 |
|------|--------|-----------|-----------|
| 美→日（1950s） | ✓ | ✓（授權） | ✓（冷戰同盟） |
| 日→台/韓（1980s） | ✓ | ✓（移轉/代工） | ✓（圍堵中國） |
| 台→中（1990s–2000s） | ✓✓ | ✓（台商西進） | ✓（接觸政策） |
| **中→回（2018–）** | ✗（成本已高） | ✗（管制） | ✗（脫鉤） |

**2020 年代的特殊之處**：第四次轉移（中國→印越/回流）是史上第一次「**由政治啟動、而非由成本啟動**」的轉移——這是四卷共同指向的當代結局。

## 閱讀建議

1. 先讀 **全球/**——理解產業的物理基礎與架構變遷（電→電子→數位→網路→AI）。
2. 再讀 **日本/**——第一次看到「製造帝國」的完整生命週期（崛起→頂點→解體→轉身）。
3. 然後 **台灣/**——看「架構創新」（代工模式）如何擊敗「製造霸權」。
4. 最後 **中國/**——看「規模+國家資本」如何在全球化中長成，又如何在制裁下重新下注。

每一卷的 README 都有完整年表與各篇 wiki 的連結；每篇 wiki 都是獨立的「案發現場」，可單獨閱讀。
