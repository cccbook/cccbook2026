# 1990：泡沫破裂 — 資產負債表的十年沉重

## 案情

1990 年起，日經指數從 38,957 點跌到 2003 年的 7,600 點；地價從峰值跌 70%。日本電子企業背上「**資產負債表衰退**」（Koo 理財：資產縮水 → 被迫還債 → 不投資 → 需求更萎縮）的沉重枷鎖。

## 前因

- 廣場協議後貨幣寬鬆 + 廣場資產泡沫（1989 檔案）。
- 1989 年三重野康上任日本銀行總裁，連續升息刺破泡沫。
- 1990 年地價開始下跌，1992 年股市見底。

## 線索與推理

**資產負債表衰退的機制**：

$$
\text{企業目標函數從} \max \pi \to \min \text{債務}
$$

- 企業資產（土地、股票）暴跌，負債名目不變。
- 即使利率為零，企業仍優先還債而非投資——**利率失效**。
- 結果：投資不足 → 需求不足 → 物價下跌 → 通縮螺旋。

**對電子業的具體傷害**：
1. **研發縮減**：投資決策保守，錯過 1990 年代的數位化浪潮（數位相機、PDA、MP3、智慧手機）。
2. **組織凍結**：終身雇用制讓「裁員」成為禁忌——**過剩人力只能「窗邊族」**（發呆的員工）。
3. **資本成本上升**：銀行壞帳，融資困難。

## 理論：Koo 資產負債表衰退 vs Keynes 流動性陷阱

| | Keynes 流動性陷阱 | Koo 資產負債表衰退 |
|--|-----------------|-------------------|
| 原因 | 需求不足 | **資產縮水 + 債務過重** |
| 企業行為 | 持有現金 | **主動還債** |
| 貨幣政策 | 無效 | **無效** |
| 財政政策 | 有效 | **有效**（政府代行借貸） |

日本的解法：政府大規模財政支出 + 銀行壞帳拖延——代價是「**失去的二十年**」。

## 後果

- 1990–2005：日本電子業研發投資成長率從 10% 降到 2%。
- 新創企業幾乎消失（日本的創投占 GDP 比重不到美國 1/10）。
- 日本錯過的清單：PC 標準化、網路、行動通訊、數位音樂、社交、雲端——**每一次數位革命，日本都在旁邊**。
- 2000 年後的「**日本材料/設備霸權**」正是這段「保守投資」的意外產物——精密化學與製造 know-how 是「不需要新創」的累積型能力（見 2020 檔案）。

## 冷案檔案

- 時間：1990 年起
- 案由：資產負債表衰退如何凍結一個產業帝國的轉型
- 教訓：**危機的真正代價不是當期虧損，而是「錯過下一場革命」**。
