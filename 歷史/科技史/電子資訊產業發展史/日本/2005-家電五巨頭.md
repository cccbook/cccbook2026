# 2005：家電五巨頭全虧損 — 家電帝國的終局開始

## 案情

2005 年前後，日本家電五巨頭（松下、索尼、日立、東芝、三洋）的家電業務開始全面陷入虧損或低利潤。傳統的「**電視 + 冰箱 + 洗衣機 + 空調**」四件套，在韓台與中國廠商的低價攻勢下成為無利可圖的業務。

## 前因

- 1980 年代日本家電全球市占 50%+。
- 1990 年代韓國（三星、LG）崛起。
- 2000 年代中國（海爾、海信、TCL）+ 台灣（鴻海）加入。
- 商品化 + 模組化 + 標準化 → 家電利潤被壓縮到 3–5%。

## 線索與推理

**日本家電為什麼輸？** 五個結構因素：

1. **成本結構**：日本國內工廠的工資 + 終身雇用 → 成本高於亞洲競爭者 30%。
2. **垂直整合包袱**：自製面板、自製壓縮機、自製電機——在「全球採購」時代成為劣勢。
3. **組織慣性**：「家電是帝國的根本」——沒有人敢提出「退出家電」。
4. **產品同質化**：模組化時代，日本家電的「品質優勢」對消費者不再可感知。
5. **匯率**：日圓 2000 年代相對強勢。

$$
\text{家電利潤} = P_{市場} - C_{日本製造} \approx 0 \text{ 或 } < 0
$$

**結構性的矛盾**：日企無法「裁員 + 外移 + 退出」——因為終身雇用 + 供應商網絡 + 企業文化。

## 理論：僵屍企業與資本錯置

|  | 美國模式 | 日本模式 |
|--|---------|---------|
| 虧損業務 | 立即裁撤 | 慢慢流血 |
| 資源 | 流動到新業務 | 鎖死在舊業務 |
| 結果 | 快速轉型 | **僵屍化** |

## 後果

- 2008–2012：日本家電五巨頭合計虧損超過 3 兆日圓。
- 2010 年代：日立的 TV 出售、東芝 TV 賣給海信、三洋被松下收購再賣給海爾。
- **日本的「家電帝國」正式解體**——只剩松下（轉型 B2B）與 Sony（轉型娛樂+CIS）。
- **台灣與韓國成為家電製造的主要承接者**。

## 冷案檔案

- 時間：2005 年起
- 案由：終身雇用 + 垂直整合 + 匯率 = 無法退出的虧損業務
- 教訓：**退出的能力（exit capability）是企業最重要的戰略能力之一**。
