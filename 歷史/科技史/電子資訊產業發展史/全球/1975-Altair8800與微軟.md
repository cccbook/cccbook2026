# 1975：Altair 8800 與微軟 — 一本雜誌封面如何創造一個產業

## 案情
1975 年 1 月，《Popular Electronics》封面刊出 MITS 公司的 Altair 8800：以 Intel 8080 為核心的組裝套件，售價 439 美元。哈佛大學學生 Bill Gates 與 Paul Allen 讀到報導後，聯繫 MITS 創辦人 Ed Roberts，宣稱已為其開發出 BASIC 直譯器——事實上他們一行程式都還沒寫。八週後，兩人在新墨西哥州 Albuquerque 展示成品，MITS 授權販售；同年 7 月，兩人正式創立 Microsoft。

## 前因
- 1974 年 Intel 8080 上市：8 位元、2 MHz、完整指令集，價格從 360 美元快速跌到約 75 美元，首次讓「整台電腦」變得平民可負擔。
- Ed Roberts 的計算機公司在德州儀器價格戰下瀕臨破產，決定賭一台 8080 電腦套件來出清庫存。
- Gates 與 Allen 在中學時期就摸過 PDP-10，在湖濱中學與華盛頓大學的機器上寫 BASIC；Allen 訂閱電子雜誌，第一時間看到 Altair 報導。
- 當時 hobbyist 圈的道德慣例是共享軟體，沒人認為軟體可以賣錢。

## 線索與推理
偵探指出，本案有三處精彩的決策推理。

第一處：Allen 的偵查。他先打電話給 MITS 謊稱有 BASIC——這是「先承諾、後交付」的賭注式談判，逼自己進入不可退的狀態。接著在 PDP-10 上以演算法模擬 8080（他先寫了模擬器），使 BASIC 開發不必等硬體。這正是模擬器技術在商業史上的第一次決定性應用。

第二處：Roberts 的盲點。他要的是讓套件暢銷的配件軟體，把 BASIC 視為 20 美元的授權品；Gates 卻堅持「軟體本身是產品」，授權費按機器台數計算。MITS 的合約允許 Microsoft 把 BASIC 授權給其他廠商——條款上的疏漏成為微軟日後的搖錢樹。

第三處：1976 年的「公開信事件」。Altair BASIC 被愛好者大量盜拷，Gates 在 Homebrew Computer Club 通訊發表〈給業餘愛好者的公開信〉，控訴盜版行為。這封信在當時被罵翻，但它確立了微軟此後二十年的基本商業命題：軟體是財產，必須付費。

偵探的結論：Altair 8800 本身銷量僅數千台，是個小案子；真正的贓物是「軟體授權費」這個商業模式，由兩個 20 歲上下的年輕人在談判桌上偷走。

## 理論
BASIC 直譯器的結構：逐行讀入、剖析、立即執行，不需編譯連結。核心迴圈可用虛擬碼表達：

```
while true:
    line = input()
    if line has 行號: 存入程式區
    else: 執行 parse(line)
```

1975 年 4K 版 Altair BASIC 在 4 KB 記憶體內塞入剖析器、算術常式與運行時函式庫，是極致的空間最佳化。其商業模型可寫成：

$$R = p \cdot N_{machines} \cdot s$$

其中 R 為總授權收入、p 為每台機器權利金、N 為裝機量、s 為市占機型覆蓋率。微軟的策略是最大化 s——讓每一種相容機都付費。

Altair 8800 規格：Intel 8080 @ 2 MHz、256 bytes RAM 標準、前面板撥桿開關輸入、S-100 匯流排擴充。

## 後果
- 微軟依合約從 MITS 獨立，1980 年代成為各種微電腦 BASIC 的標準供應商（TRS-80、Apple、Commodore 均曾採用）。
- S-100 匯流排催生 CP/M 與相容機生態，為 1981 年 IBM PC 鋪路。
- 「授權軟體」模式確立，與 Apple 的「軟硬一體」形成兩條路線，其爭執貫穿至今（開源 vs. 專有）。
- Roberts 後來離開產業行醫；Altair 進博物館，微軟進歷史。

## 冷案檔案
- 時間：1975-01 雜誌上市；1975-07-01 微軟正式成立
- 案由：個人電腦套件引爆市場，軟體授權商業模式在合約縫隙中誕生
- 歷史定位：PC 產業的「創世紀事件」——第一名客戶很小，第一名員工（後來的商業模式）很大。
