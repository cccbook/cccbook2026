# 1999：大宇集團解體 — 「擴張型財閥」的死亡

## 案情

1999 年 8 月，韓國第二大財閥大宇集團（Daewoo）解體——負債 800 億美元，是**當時史上最大的破產案**。創辦人金宇中流亡海外。與三星同年虧損、同樣高槓桿，為什麼大宇死了、三星活了？

## 前因

- 金宇中的哲學：「**用別人的錢、買全世界的工廠**」——1980–1990 年代大宇收購了數百家公司（汽車、造船、家電、建築、通信），橫跨 110 國。
- IMF 危機（1997）後，政府要求財閥「**大交易**」（互換子公司）——大宇拒絕瘦身，反而繼續收購。
- 1998 年大宇負債率 3,000%+。

## 線索與推理

**大宇 vs 三星的解剖**：

| | 大宇 | 三星 |
|--|------|------|
| 擴張邏輯 | **收購 = 成長**（規模幻覺） | 投資 = 能力（DRAM/品牌） |
| 核心能力 | 貿易、談判、政府關係 | **製造、技術、品牌** |
| 現金流 | 弱（各事業互不產生綜效） | **DRAM 現金流（帝國的血液）** |
| 1997 後的選擇 | 繼續擴張 | 瘦身（賣汽車） |

$$
P_{存活} \propto \frac{\text{核心業務的現金流}}{\text{債務利息}}
$$

- 三星：DRAM 市占第一 → 現金流強 → 利息可付。
- 大宇：收購來的工廠普遍低效 → 現金流弱 → **債務利滾利 → 斷鏈**。

**根本差異**：大宇是「**貿易商心態的製造集團**」——擅長「買與賣」，不擅長「**把工廠經營好**」。財閥的規模沒有轉化成能力。

## 理論：規模 ≠ 能力（M&A 的吸收瓶頸）

$$
\text{有效規模} = \min(\text{帳面規模}, \text{管理吸收能力})
$$

大宇的管理吸收能力遠低於其收購速度——**帳面帝國是紙做的**。

## 後果

- 大宇汽車賣給通用（GM Daewoo）、造船賣給現代——帝國被拍賣。
- 金宇中 2006 年回韓服刑（緩刑）。
- 韓國財閥的「大宇教訓」：**IMF 後所有財閥都學會「現金流 > 規模」**——三星的李健熙早一步（新經營 1993）。
- 對照台灣：同時期宏碁的品牌全球化挫敗（1987 檔案）、鴻海的穩健擴張——**「擴張的速度必須 ≤ 能力成長的速度」是跨越國界的鐵律**。

## 冷案檔案

- 時間：1999 年
- 案由：用債務購買規模、卻沒有能力消化規模的死亡
- 教訓：**擴張的財務上限由管理能力決定，不由融資市場決定**。
