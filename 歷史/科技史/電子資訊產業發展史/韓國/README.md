# 韓國電子資訊產業史 -- AI 偵探風格

以「推理探案」的方式，追查韓國電子資訊產業從三星電子創立、DRAM 賭局、IMF 危機、到 Galaxy 帝國與 HBM 霸權的每一步：
前因是什麼？線索在哪裡？推理如何展開？後果又如何改寫東亞科技版圖？

核心謎題只有一個：**一個 1950 年代還是世界最窮的國家之一，為什麼能在記憶體、面板、手機三個「資本密集＋規模決勝」的產業全部登頂？**
推理的答案是：**財閥資本的無限耐心 + 逆週期投資的軍事化執行 + 國家與財閥的共生**——韓國把「熬得比對手久」變成了國家戰略。

$$
\text{韓國模式}： \text{財閥資本} \times \text{逆週期投資} \times \text{集中壓倒} \xrightarrow{\text{每個週期}} \text{對手出清} \xrightarrow{} \text{贏者全拿}
$$

韓國模式的本質是一場「**賭局的軍事化**」：用財閥集團的資本把 DRAM/面板/手機的景氣週期武器化——別人看週期是風險，三星看週期是「**清除競爭者的機會**」。

## 為什麼是韓國？（偵探的最終推理）

| 變數 | 韓國 | 日本 | 台灣 | 中國 |
|------|------|------|------|------|
| 資本主體 | **財閥（無限耐心）** | 獨立企業 | 散戶+法人 | 國家基金 |
| 投資節奏 | **逆週期** | 順週期 | 順週期 | 政策週期 |
| 決策速度 | 極快（集權） | 慢（共識） | 快 | 中 |
| 品質紀律 | 軍事化 | 匠人化 | 精實化 | 規模化 |
| 結果 | 商品化產業之王 | 品牌退位 | 分工之王 | 追趕者 |

韓國的答案：**在「規模與資本決定勝負」的產業（DRAM、面板、手機、HBM），財閥的資本耐心是唯一無法被模仿的武器**——但同樣的體系，在「需要創新與軟體」的產業上從未證明自己（韓國軟體業同樣弱小，與台灣同病）。

每一篇 wiki 都是這個「軍事化賭局」的現場。
