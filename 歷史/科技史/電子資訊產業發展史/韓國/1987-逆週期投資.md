# 1987：逆週期投資 — 把景氣週期武器化

## 案情

1985–1987 年，DRAM 價格暴跌 80%（日本傾銷戰 + 需求衰退），全行業虧損。三星與現代電子做出震驚全球的決策：**在虧損最深的谷底，加倍擴產**。1992 年，三星成為 DRAM 世界第一。

## 前因

- 1984–1985 DRAM 崩盤：日本廠商傾銷、美國廠商退出（Intel 1985 退 DRAM）。
- 三星 1985 年虧損 1.5 億美元，債務激增——內部「撤出 DRAM」的聲音強烈。
- 李健熙的判斷：「**現在是別人停下來的時候——正是我們超車的時候**」。

## 線索與推理

**逆週期投資的數學**：

$$
\text{市占變化} = \frac{\text{我的新增產能}}{\text{全行業新增產能}}
$$

- 順週期（大家都擴產）：市占不變，大家一起在高峰虧損。
- **逆週期（只有我擴產）**：市占暴增——且是在**對手財務最脆弱、融資最難**的時刻。

**三重殺傷機制**：

1. **成本殺**：新廠 = 新製程 = 成本更低 → 價格戰中我仍有毛利。
2. **現金流殺**：對手虧損 → 融資斷鏈 → 被迫退出（Intel 退 DRAM 的直接原因之一）。
3. **客戶殺**：對手退出 → 客戶轉單 → 我市占固化。

$$
\text{三星的優勢} = \underbrace{V_{集團資本}}_{\text{隨時可注資}} \times \underbrace{D_{決策速度}}_{\text{會長一句話}} \times \underbrace{T_{耐心}}_{\text{十年不算久}}
$$

**為什麼只有三星做得到？** Intel、TI 有季度財報壓力；日本大廠有「全員共識」的決策惰性；台灣 DRAM 廠靠銀行聯貸（每輪擴產都要重新說服銀行）。**只有財閥資本能「無限續杯」**。

## 理論：掠奪性投資的博弈論

```
三星：擴產（承諾可信——集團資本作抵押）
對手：預期三星會繼續擴 → 退出是理性 → 退出
三星：等對手退出 → 漲價 → 收割
```

這是一個「**可信承諾（credible commitment）**」的賽局——三星用集團資產為「繼續燒錢」做抵押，使威脅可信，對手理性認輸。

## 後果

- 1992 年三星 DRAM 市占世界第一（見 1992 檔案）。
- 1996–1998、2001、2008–2009：三星每次都在週期谷底擴產——**同一武器用了五次，每次都有效**。
- 對手的宿命：Intel（退 DRAM）、日本廠（合併、破產）、台灣（雙 D 慘案）、奇夢達（破產）。
- 2008 金融海嘯：三星逆週期投資面板與 DRAM——把日本面板與台灣 DRAM 一起清場（見台灣篇 2009、日本篇 2008 檔案）。

## 冷案檔案

- 時間：1985–1992（首次完整演練）
- 案由：財閥資本 + 景氣週期 = 掠奪性投資的完美武器
- 教訓：**週期不是風險，是武器——但只有資本無限的人拿得動這把武器**。
