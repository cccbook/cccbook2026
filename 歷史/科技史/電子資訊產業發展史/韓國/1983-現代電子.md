# 1983：現代電子成立 — 財閥全線進入 DRAM

## 案情

1983 年，現代集團成立現代電子（Hyundai Electronics，後 Hynix），LG 的金星（GoldStar）也在同期進入半導體——**韓國四大財閥（三星、現代、LG、大宇）在 1980 年代全部押注 DRAM**。這不是企業決策，是「**國家級軍備競賽**」。

## 前因

- 1983 東京宣言（三星）示範了「DRAM 可行」。
- 全斗煥政府推動「**半導體產業育成政策**」：低利融資、租稅減免、電力與用水的優先供給。
- 財閥間的「**同業競爭文化**」——三星做了，其他財閥不能不做（面子+政治）。

## 線索與推理

**為什麼四家財閥同時進入一個「全球只容得下 3–5 個玩家」的產業？** 推理：

| 動機 | 說明 |
|------|------|
| 政治正確 | 全斗煥政府視半導體為「國家戰略」——不做 = 不愛國 |
| 財閥面子 | 三星做了，現代/LG 不做 = 承認次等 |
| 內部邏輯 | 家電/汽車需要晶片，垂直整合的誘惑 |
| 政府補貼 | 融資成本低於市場——**補貼把「理性計算」扭曲為「都值得做」** |

$$\text{參與者數量} \propto \text{補貼規模} \times \text{財閥競爭文化} \gg \text{市場可容納數量}$$

**結局（先揭曉）**：全球 DRAM 業在 1980–2000 年經歷五次洗牌——
- 美國（Intel、TI、Mostek）1985 年前後退出。
- 日本（NEC、東芝、日立、三菱）1999 年合併為 Elpida、2012 破產。
- 德國奇夢達 2009 破產。
- 台灣（力晶、茂德、華亞科）2008–2016 全線重整。
- **倖存者：三星、SK 海力士（現代電子的繼承者）、美光**——恰好是韓國兩家 + 一家。

**四家進入、兩家存活——存活率 50%，但倖存者拿走了整個市場**。這是「**財閥過度進入的理性**」：政府與集團資本承擔了試錯成本，存活者的壟斷利潤歸財閥。

## 理論：過度進入的「補貼經濟學」

$$\text{私人期望利潤} = \pi_{市場} + \text{補貼} \quad \text{vs} \quad \text{社會期望利潤} = \pi_{市場} - \text{補貼成本}$$

補貼使私人（財閥）的期望利潤為正——即使社會總利潤為負（過度進入）。韓國的賭法：**接受過度進入的浪費，換取至少一家登頂的確定性**。

## 後果

- 現代電子 1996 年更名現代微電子，1999 年與 LG 半導體合併（LG 因 IMF 危機退出），2001 年更名 Hynix。
- Hynix 2001–2002 瀕臨破產，債權銀行接管——2012 年被 SK 集團收購（見 2012 檔案）。
- LG 退出半導體，專攻家電與面板。
- **大宇 1999 年解體**（見 1999 檔案）——擴張型財閥的極端案例。

## 冷案檔案

- 時間：1983 年
- 案由：財閥全線進入的「過度進入的理性」
- 教訓：**補貼扭曲進入決策，但倖存者的壟斷利潤能償還全體試錯成本——前提是至少一家活下來**。
