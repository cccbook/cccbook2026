# 1947 - 電晶體（從真空管到半導體的跳躍）

## 案件摘要
1947 年 12 月 16 日，Bell Labs 的 **John Bardeen、Walter Brattain、William Shockley**
發明了**電晶體（Transistor）**——第一個半導體放大與開關裝置（點接觸式電晶體）：
$$\text{真空管（三極管）} \quad \xrightarrow{\quad \text{材料革命} \quad} \quad \text{電晶體（半導體 PN 接面）}.$$
體積：1/1000、功耗：1/100、壽命：1/10^6（理論級）、速度快 10–100 倍、**無真空、無燈絲、無易損零件**。
這是 20 世紀最偉大的發明之一——**直接造就了蘋果、Intel、台灣晶圓、整個矽谷經濟體**。

## 前因 -- 為什麼會有這個案子
- **真空管的三大缺陷（1940s）**：
  1. **體積龐大**：ENIAC 18000 顆管，30 噸（見「1946-ENIAC電子計算機.md」）。
  2. **功耗驚人**：150 kW，需強冷。
  3. **壽命短、易壞**：平均壽命數百至數千小時（燈絲燒斷最常見）——
     電腦要 24/7 運作，維護是災難。
- **固態放大器的追尋（1920s–1945）**：Crystal detector（礦石收音機，1906）、Lilienfeld 的場效電晶體專利（1925、1933）——
  理論早有，但**材料純度（半導體雜質控制）達不到要求**。
- **第二次世界大戰的推動**：雷達（1940–1945）需要高頻固態檢波器，促進了對**鍺（Ge）、矽（Si）**半導體的研究（MIT Rad Lab）。
- **Shockley 的偵探直覺（理論 + 實驗）**：
  Shockley 提出「場效應」理論（1945），但實驗一直失敗（表面態問題）。
  Bardeen（固體物理理論家）與 Brattain（實驗天才）採用**不同的實驗路線（point contact）**，而非 Shockley 的平面場效應——
  **實驗路線的分歧，意外造就了發明**。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：PN 接面與載流子（半導體物理）
半導體（矽 $Si$，4 價）摻雜：
- **n 型**（donor）：摻磷 $P$（5 價）→ 多自由電子 $e^-$。
- **p 型**（acceptor）：摻硼 $B$（3 價）→ 多電洞 $h^+$。
**PN 接面**：p 與 n 相接，形成**空乏區（depletion region）**：
$$J_D = J_0\!\left(e^{qV/kT} - 1\right) \quad \text{（Shockley 二極管方程）}.$$
- 正向偏壓 $V>0$：導通；反向偏壓：截止。
電晶體 = **三端元件**，能**控制大電流（集極-射極）用小電流（基極）**——**電流放大 + 開關**。

### 第二條線索：電晶體的三種工作區（開關 = 數位邏輯）
雙極性電晶體（BJT，Bipolar Junction Transistor）：
$$I_C = \beta\, I_B + (1+\beta)I_{CBO}, \qquad \beta \approx 50\text{–}500.$$
工作區：
- **截止區（Cutoff）**：$I_B=0 \to I_C \approx 0$ → **開關 OFF（邏輯 0）**
- **飽和區（Saturation）**：基極充分驅動 → 集極-射極飽和導通 → **開關 ON（邏輯 1）**
- **主動區（Active）**：線性放大（類比放大器）

**關鍵轉折**：1947 年的點接觸電晶體（point-contact）證明了**電流放大**，1951 年 Shockley 的 **BJT（平面型）**與 1960 年 **MOSFET（金屬氧化物半導體場效電晶體）**才成為主流。
**MOSFET（1959，Atalla/Kahng，Bell Labs）**是今日 CPU/GPU 的絕對主流（>99% 晶片）。

### 第三條線索：材料革命（矽 vs 鍺）
早期電晶體用**鍺（Ge）**（1947–1960s），但鍺的**能隙小（0.66 eV）**、溫度穩定差。
**矽（Si）**：能隙 1.12 eV、氧化性好（可形成 $SiO_2$ 絕緣層）——
這是 **Fairchild（1957）** 與 **Intel（1968）** 選擇矽的關鍵。今日 99.9% 的晶片用矽。
$$\text{SiO}_2 + \text{平面光刻} \quad \Longrightarrow \quad \text{積體電路（IC，1958，見下篇）}.$$

### Python：電晶體開關（邏輯閘）與 NOT 閘模擬

```python
# MOSFET 開關模型（簡化）：Vgs 決定導通/截止
def nmos_on(Vgs, Vth=0.7):  # nMOS：Vgs > Vth 導通
    return Vgs > Vth

def pmos_on(Vgs, Vth=0.7):  # pMOS：Vgs < -Vth（或 |Vgs|>Vth，低電壓導通）
    return Vgs < -Vth

# CMOS NOT 閘（反相器）
def cmos_not(Vin, Vdd=1.0, Vth=0.7):
    """Vin=0 → Vout=Vdd（1），Vin=Vdd → Vout=0"""
    # pMOS 上拉（pull-up），nMOS 下拉（pull-down）
    p_on = pmos_on(Vin - Vdd, Vth)  # Vgs_p = Vin - Vdd
    n_on = nmos_on(Vin - 0, Vth)     # Vgs_n = Vin
    # CMOS：互補，任何時刻只一個導通
    if not n_on and p_on:   return Vdd
    if n_on and not p_on:   return 0.0
    # 過渡區（模擬用）
    return Vdd/2

# 測試反相器（NOT 閘）
for Vin in [0.0, 0.2, 0.8, 1.0]:
    print(f"NOT({Vin:.1f}) = {cmos_not(Vin):.1f}")
```
輸出：
```
NOT(0.0) = 1.0
NOT(0.2) = 1.0
NOT(0.8) = 0.0
NOT(1.0) = 0.0
```
（CMOS 反相器：只用 2 顆電晶體（1 nMOS + 1 pMOS）完成 NOT 閘——
1959 年 MOSFET 啟發了 CMOS（互補式金屬氧化物半導體），今日 99% 數位晶片都用 CMOS，
功耗低（靜態幾乎零，只有切換耗電）——這是大規模積體電路（LSI/VLSI）能做到十億級電晶體的關鍵。）

## 結案 -- 後果與影響
- **1947–1954 點接觸式 → 平面型**：Shockley 於 1951 年發明 **BJT**（junction transistor），可批量生產，穩定性大幅提升。
- **MOSFET 革命（1959）**：Mohamed Atalla 與 Dawon Kahng（Bell Labs）發明 **MOSFET**——
  **閘極絕緣層（SiO₂）是關鍵突破**。MOSFET 體積更小、功耗更低、易於積體化。
- **矽谷的起源（1957）**：八個 Shockley 實驗室工程師（Traitorous Eight）離開，成立 **Fairchild Semiconductor**（1957）——
  發明平面製程（planar process, Jean Hoerni, 1959），直接孕育 Intel（1968，Moore/Noyce/Grove）。
- **消費電子革命**：電晶體收音機（1954，Sony TR-55）、電視、晶體管計算機（1950s 終端）、1960s 微型電子產品。
- **計算機時代的跨越**：真空管（1946 ENIAC）→ 電晶體（1954 TRADIC, MIT）→ 積體電路（1958，見「1958-積體電路.md」）→ VLSI。
- **諾貝爾物理獎（1956）**：Bardeen、Brattain、Shockley 獲獎。
  （Bardeen 是唯一兩次諾貝爾物理獎得主：1956 電晶體 + 1972 超導 BCS 理論）
- 歷史定位：電晶體是「**原子尺度的開關**」（半導體能帶控制載流子）——把計算從「真空管的發熱燈泡」變成「固態晶片」。
