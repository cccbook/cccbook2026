# 作業系統史 -- AI 偵探風格

以「推理探案」的方式，追查作業系統從批處理到容器與雲端的每一步：
前因是什麼？線索在哪裡？推理如何展開？後果又如何改變了整個電腦科學與數位世界？
核心謎題只有一個：**如何讓一顆 CPU、一份記憶體，同時服務多個互不信任的程式？**
