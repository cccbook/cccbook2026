# 1982 - Lam Research AutoEtch（單片式蝕刻：良率與均勻性的勝利）

## 案件摘要
1980 年，**Roger Bonham 與 David Brandly**（皆前 Applied Materials 工程師）
成立 **Lam Research**；1982 年出貨 **AutoEtch**——**單片式（single-wafer）
電漿蝕刻機**，專攻**多晶矽閘極蝕刻**：
$$\text{批次式（batch，一次數十片）} \xrightarrow{\text{單片式（一片一片）}} \text{均勻性 ±3\% 以內}$$
「**批次 → 單片**」是 1980s 設備業最重要的轉折——
良率與均勻性打敗了產能與成本。Lam 成為**蝕刻之王**（2024 年全球第三大設備商）。

## 前因 -- 為什麼會有這個案子
- **批次蝕刻的缺陷**（1980s 主流是批次式 barrel/hexode）：晶圓在批次內位置不同 →
  **晶圓對晶圓均勻性 ±10%**、等離子體不均勻、交叉污染。
- **閘極蝕刻的極端要求**：MOSFET 的閘極線寬（CD）直接決定電流——
  閘極 CD 均勻性 < ±3%，**批次式做不到**。
- **創辦人的嗅覺**：Bonham/Brandly 看到「單片式雖然慢，但**每片都一樣**」——
  良率價值 > 產能損失。
- **經濟學前提**：單片式要有**足夠的產能**才划算——1980s 晶圓尺寸
  從 100→125→150 mm，自動化機械手臂讓單片式變得可行。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：批次 vs 單片（設備哲學的分水嶺）
| 特性 | 批次式（barrel/hexode） | 單片式（single-wafer） |
|------|------------------------|------------------------|
| 產能 | 高（一次 25–100 片） | 低（一次 1 片） |
| 晶圓間均勻性 | ±10%（位置相依） | **±1–3%** |
| 片內均勻性 | 中 | 高 |
| 過程控制 | 難（無法中途調整） | 易（每片可回饋） |
| 單片成本 | 低 | 高 |
| 結果 | 量產初期 | **先進製程全面勝出** |

**偵推**：先進製程的 CD 要求讓**均勻性 > 產能**——
「單片化」從蝕刻蔓延到 CVD、CMP、清洗、ALD——**1980s 設備業的總路線**。

### 第二條線索：CD 控制的數學（閘極蝕刻為何致命）
MOSFET 飽和電流：
$$I_{D,sat} \propto \frac{W}{L} \quad (L = \text{閘極長度 = 蝕刻後的 CD})$$
- 閘極 CD 變化 ±10% → 電流變化 ±10% → **Vt 與速度的飄移** → 良率崩盤；
- 蝕刻的 CD 控制 = 微影 CD + 蝕刻 bias（各半）——
  **蝕刻機是 CD 的「第二支筆」**。

### 第三條線索：成本模型（CoO——設備業的通用語言）
$$\text{CoO} = \frac{\text{設備折舊} + \text{人力} + \text{耗材} + \text{電力/氣體}}{\text{產能} \times \text{良率} \times \text{稼動率}}$$
- 單片式的產能劣勢要靠**自動化、真空傳送、多腔體**補回——
  這正是 1991 年群集設備（見 `1991-Endura群集設備.md`）誕生的伏筆。
- **偵推**：設備業的辯論永遠是「**產能 vs 良率**」——
  每次先進製程轉折，良率都贏。

### 第四條線索：Lam 的技術演進
| 年份 | 產品 | 意義 |
|------|------|------|
| 1982 | AutoEtch | 單片式多晶矽蝕刻 |
| 1984 | EPIC | 多晶矽/金屬蝕刻主力 |
| 1988–91 | TCP（變壓器耦合電漿）| 介電層高深寬比蝕刻 |
| 1994 | 9400 TCP | DRAM 接觸窗蝕刻 |
| 2000s | 2300 Flex | 12 吋多功能蝕刻平台 |
| 2013 | 併 Novellus | 蝕刻 + CVD（見 `1994-HDPCVD.md`）|

## 結案 -- 後果與影響
- **單片化成為總路線**：蝕刻（1982）→ CVD（1980s 末）→ CMP（1995）
  → ALD（2000s）——**先進製程的一切都是單片式**。
- **Lam 的霸權**：蝕刻市占第一（~45%）、2024 年全球第三大設備商
  （營收 ~$17B）；**客戶服務群（CSBG）** 佔營收 20%+——
  「設備 + 服務」的雙引擎。
- **蝕刻成為「化學廚房」**：先進蝕刻涉及 5–10 種氣體、等離子體化學、
  聚合物鈍化——**蝕刻工程師是 fab 裡最難取代的職位**。
- **偵探教訓**：1980s 的「批次 vs 單片」之辯是設備業的**範式之爭**——
  結論：**在良率壓力下，單片式永遠勝出**（每一次轉折都重演一次）。
