# 1994 - HDP-CVD 高密度電漿 CVD（填滿 0.25μm 的洞）

## 案件摘要
1994 年，**Novellus**（Richard Hill，1984 年創立）出貨 **SPEED**——
**高密度電漿 CVD（High-Density Plasma CVD, HDP-CVD）**：
**沉積 + 濺鍍同時進行**，把高深寬比（>4:1）的洞填滿不留空洞：
$$\text{PECVD（覆蓋不均、留空洞）} \xrightarrow{\text{HDP：沉積+濺鍍同時}} \text{底部向上填滿}$$
解決 0.25 μm 世代的**STI、接觸窗、金屬間介電層（IMD）填充**——
Novellus 成為 **CVD 之王**（2013 年被 Lam 併購，見 `1982-LamResearch蝕刻.md`）。

## 前因 -- 為什麼會有這個案子
- **0.35→0.25 μm 的形貌危機**：線寬縮小，洞與溝的**深寬比暴增**（>4:1）——
  傳統 PECVD 的覆蓋率：孔口快、底部慢——**封口留洞（void）**；
- **回流的死刑**：金屬層之後不能高溫（Al 熔點 660°C、low-k 更脆弱）——
  **BPSG 回流不可用**；
- **ECR-CVD 的失敗**：1980s 電子迴旋共振（ECR）電漿——真空度要求高、
  產能低——**商業化失敗**；
- **Novellus 的洞察**：**沉積與濺鍍同時進行**——邊長邊削，底部補上。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：HDP 的物理（離子密度 ×100）
電感耦合電漿（ICP）：
- 離子密度 $n_i \approx 10^{11}\text{–}10^{12}$ cm⁻³（PECVD 的 10–100 倍）；
- **密度與能量解耦**：感應線圈控制密度（低偏壓）、基板 RF 控制離子能量——
  **兩個旋鈕獨立**——ICP 對 ECR 的架構優勢；
- **同時濺鍍**：Ar⁺ 削掉孔口多餘沉積 → 底部追上 → **「底部向上」填滿**。

### 第二條線索：填充的形貌演化（為什麼會有空洞）
PECVD 沉積的等向性：孔口兩側都沉積 → 孔口閉合 → 底部留洞：
$$\text{空洞條件：} \frac{\text{孔口沉積速率}}{\text{底部沉積速率}} \gg 1$$
- HDP：濺鍍削平孔口 + 底部補充 → 比例接近 1 → **無洞填充**；
- **偵推**：這是「**生長與刻蝕的動態平衡**」——
  蝕刻（1974）與沉積的物理合流在同一台機器裡。

### 第三條線索：PECVD vs HDP-CVD 對照
| 特性 | PECVD（1978） | HDP-CVD（1994） |
|------|---------------|------------------|
| 離子密度 | 10⁹–10¹⁰ cm⁻³ | 10¹¹–10¹² |
| 覆蓋 | 台階覆蓋（有縮頸）| 近填充（填洞） |
| 深寬比能力 | <2:1 | >4:1 |
| 用途 | 鈍化層、淺溝 | STI、IMD、接觸窗 |

### 第四條線索：電荷損傷（新的缺陷種類）
高密度電漿的副作用——**天線效應**（antenna effect）：
- 晶圓上大面積導體在電漿中充電 → 擊穿閘極氧化層；
- **對策**：跳線設計（EDA 規則）、製程順序——
  **設備的新缺陷種類**催生新的設計規則——
  設備史與 EDA 史第一次直接耦合。

## 結案 -- 後果與影響
- **1990s HDP = 標準**：STI、IMD、接觸窗的填充主力——
  0.25 μm 世代的救星。
- **2000s 被替代**：flowable CVD（液相填洞）、ALD、旋塗介電——
  **技術的階層性更替**（見 `2007-HighK與ALD.md`）。
- **Novellus 的興衰**：CVD 之王 → 2013 年被 **Lam 併購（$33 億）**——
  蝕刻 + CVD 同廠——**「整合供應商」的邏輯**（客戶要一站式）。
- **偵探教訓**：HDP-CVD 證明了「**沉積與蝕刻的合流**」——
  設備的分類（沉積機/蝕刻機）是暫時的，**物理的組合才是永恆**。
