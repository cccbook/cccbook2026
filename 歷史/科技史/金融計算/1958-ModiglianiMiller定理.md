# 1958 -- Modigliani–Miller 定理：套利論證成為金融學的基石

## 案件描述

1958 年 6 月，Franco Modigliani 與 Merton Miller 在《American Economic Review》發表《資本成本、公司財務與投資理論》。論文的核心主張震驚了整個金融學界：

> **在完美市場中，公司的價值與它的資本結構（負債 vs 股權的比例）無關。**

這個「無關性定理」（irrelevance theorem）看似荒謬——負債越多風險越大，怎麼會無關？——但它背後的推理方式（**套利論證**）成為之後所有金融定價理論的引擎，包括 Black–Scholes。

## 前因：資本結構之謎

- 1950 年代的主流觀點（「傳統觀點」）：公司有一個「最佳負債比例」，偏離它會增加資本成本。
- 投資銀行與財務顧問靠「設計最佳資本結構」收費——如果 MM 定理為真，這門生意就沒有理論基礎。
- **線索**：Modigliani（凱因斯主義總體經濟學家）與 Miller（原先是勞動經濟學家）在卡內基理工學院（後來的 CMU）合作教公司財務課程。他們發現教科書的傳統觀點**邏輯上自相矛盾**，於是動手清理這團混亂。

## 推理過程

### 線索一：一價定律的邏輯力量

MM 的推理武器不是實證資料，而是**純邏輯**：兩個在所有狀態下給付完全相同的現金流的資產，必須有相同的價格——否則就存在無風險套利。

### 線索二：複製論證

設公司 $U$（ unlevered，無負債）與公司 $L$（levered，有負債），營運現金流相同。

- 買下公司 $L$ 的全部股權 + 全部債權 = 擁有公司 $U$ 的全部股權 → 兩者價值必須相等：

$$V_L = V_U$$

- 個人投資者可以**自製槓桿**（home-made leverage）：借錢買公司 $U$ 的股權，可以完全複製公司 $L$ 股權的報酬。如果 $V_L > V_U$，套利者賣 $L$ 買自製槓桿的 $U$，無風險獲利——套利壓力迫使 $V_L = V_U$。

### 線索三：股權成本隨槓桿上升

MM 並非說「負債沒有影響」——負債會讓**股權**變得更風險、要求更高的報酬。以現代記號：

$$r_E = r_A + \frac{D}{E}(r_A - r_D)$$

其中 $r_A$ 是資產（公司整體）的報酬率。槓桿 $D/E$ 上升時，$r_E$ 線性上升，正好抵銷便宜負債帶來的好處——**加權平均資本成本（WACC）不變**：

$$r_{WACC} = \frac{E}{D+E} r_E + \frac{D}{D+E} r_D = r_A$$

### 假設的代價

MM 定理在以下假設下成立：無稅、無交易成本、無破產成本、個人與公司借款利率相同。**1963 年** MM 自己加入公司稅修正（負債的稅盾 $t_c D$ 有價值），後續學者再加入破產成本，得到「權衡理論」（trade-off theory）。

## 現代程式驗證：自製槓桿複製

```python
def mm_check(E, D, rA, rD):
    """驗證 WACC 不隨槓桿改變"""
    rE = rA + (D / E) * (rA - rD)          # MM 命題 II
    wacc = (E / (D + E)) * rE + (D / (D + E)) * rD
    return rE, wacc

for D in [0, 25, 50, 75]:
    rE, wacc = mm_check(E=100, D=D, rA=0.10, rD=0.05)
    print(f"D={D:>3}  rE={rE:.4f}  WACC={wacc:.4f}")
# 輸出：WACC 恆為 0.10，不隨 D 改變；rE 隨 D 線性上升
```

## 後果

- **套利論證成為金融學的統一方法論**：Black–Scholes（1973）的動態避險、HJM 利率模型、無套利定價（APT），全部是 MM 式「複製 + 一價定律」的延伸。
- **公司財務成為一門科學**：MM 定理是「基準」（benchmark）——實際世界偏離 MM 的每一處（稅、破產成本、資訊不對稱、代理成本），都是一個可以研究的題目。現代資本結構理論本質上是「MM + 修正項」的清單。
- Modigliani 獲 **1985 年**諾貝爾獎，Miller 獲 **1990 年**諾貝爾獎。
- Miller 後來說：MM 定理就像說「牛奶的味道與牛的擠奶方式無關」——它的價值不在於描述現實，而在於**指出需要解釋的偏離**。

## 偵探筆記

- 動機：教科書傳統觀點的邏輯矛盾
- 工具：套利論證（複製 + 一價定律）
- 遺產：無套利定價範式、現代公司財務的基準模型
- 盲點：完美市場假設——但正是這個盲點，讓「偏離 MM 的原因」成為之後半世紀的研究綱領
