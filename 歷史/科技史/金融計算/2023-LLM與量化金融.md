# 2023 -- LLM 與量化金融：大型語言模型進入金融

## 案件描述

2022 年 11 月 ChatGPT 發布後，大型語言模型（LLM）在 2023 年迅速進入金融業的每個角落：

> **研究報告生成、財報情感分析、程式碼生成（金融計算的程式碼！）、法規合規、客戶服務——甚至投資決策本身。**

這是金融計算史上第一次，「語言」本身成為可計算的物件——而金融恰恰是資訊密度最高的行業。

## 前因：NLP 在金融的二十年鋪路

- **情感分析的早期**：Tetlock（2007）發現《華爾街日報》專欄的悲觀情緒可以預測短期市場下行——「語言可以預測市場」的第一個實證。
- **FinBERT 時代**（2019）：金融領域微調的 BERT 模型，情感分析準確率達 80%+。
- **文本作為資料**：2000 年代起，量化基金開始消化新聞、財報、法說會逐字稿——「另類資料」（alternative data）產業誕生。
- **線索**：LLM 的能力（上下文理解、推理、程式碼生成）遠超以往的 NLP——它不只是「情感分析器」，而是「可以做金融研究的助手」。

## 推理過程

### 線索一：LLM 在金融的四種角色

1. **研究助手**：閱讀財報、生成摘要、回答金融問題——研究員的效率倍增器。
2. **情感與事件分析**：從新聞、財報、法說會逐字稿中抽取「市場訊號」：

   $$\text{訊號}_t = f_{\text{LLM}}(\text{文本}_t) \rightarrow \text{交易決策}$$

   實證（Loughran–McDonald 2011 的金融情感字典 + LLM）：財報語氣的變化有微弱的預測力。
3. **程式碼生成**：**這是對金融計算最直接的衝擊**——「寫一個 Black-Scholes 定價器」「寫一個 GARCH 估計程式」「用 LSM 為美式選擇權定價」——LLM 可以直接生成可執行的程式碼，把本書前 22 篇的每一個演算法變成一句話的事。
4. **合規與風控**：法規文件分析、交易審查、洗錢偵測。

### 線索二：LLM 的「市場預測」能力之謎

2023 年的實證研究（Lopez-Lira & Tang 2023）發現一個驚人的結果：

> **ChatGPT 對新聞標題的情感判斷，可以顯著預測次日的股票報酬。**

**推理**：為什麼「已經公開」的新聞還能預測報酬？因為：
- 新聞量太大，市場來不及全部消化（注意力是稀缺資源）
- LLM 可以同時處理所有新聞，把「資訊 → 價格」的映射提前完成
- **這是有效市場假說（1965，見 [1965-Fama有效市場假說.md](1965-Fama有效市場假說.md)）的有趣回響**：EMH 說「價格反映一切可得資訊」——LLM 讓「可得資訊的消化速度」大幅提升，市場效率的上限被推高。

### 線索三：LLM 作為金融計算的「編譯器」

本書的主線：金融計算的每一次革命都伴隨計算方法的革命。

| 時代 | 計算方法 | 誰能使用 |
|------|------|------|
| 1973 | 手算 + 計算機 | 少數學者 |
| 1979–1994 | C 語言、試算表 | 交易台 |
| 2000–2017 | Python、GPU | 量化基金 |
| 2023– | **自然語言 → LLM → 程式碼** | **任何人** |

LLM 把「寫程式」這個門檻降到「說一句話」——**金融計算的民主化**。這也是本書用 AI 偵探風格寫作的原因：LLM 時代，知識的生產方式本身改變了。

### 線索四：風險與盲點

- **幻覺（hallucination）**：LLM 會自信地編造數字與引用——金融計算要求數值精確，幻覺是致命的。
- **市場同質化**：如果所有基金都用 LLM 分析同樣的新聞，訊號會同質化——2008 年（見 [2008-金融海嘯與CDO.md](2008-金融海嘯與CDO.md)）的教訓重演：**所有人都用同一個模型，本身就是風險。**
- **法規**：SEC 對 AI 使用於投資建議的監管開始收緊。
- **算力與成本**：LLM 推理成本高，即時交易場景仍受限。

## 現代程式重現：LLM 情感訊號的回測框架

```python
import numpy as np

def llm_sentiment_signal(headlines, llm_scorer):
    """用 LLM 對新聞標題評分（-1 到 1），生成交易訊號"""
    return np.array([llm_scorer(h) for h in headlines])

def backtest(signals, next_day_returns, threshold=0.3):
    """訊號 > 0.3 買、< -0.3 賣，其餘觀望"""
    longs = signals > threshold
    shorts = signals < -threshold
    ret = next_day_returns[longs].mean() - next_day_returns[shorts].mean()
    return ret

# Lopez-Lira & Tang (2023): ChatGPT 情感訊號的次日預測力顯著
# 這挑戰了「公開資訊不可預測」的半強式 EMH — 因為注意力是稀缺的
```

## 後果

- **金融業的 LLM 化**：BloombergGPT（2023，Bloomberg 的金融專用 LLM）、各大券商的 AI 研究助手、Robo-advisor 的升級。
- **量化基金的 LLM 策略**：另類資料 + LLM 的訊號挖掘成為新的阿爾法來源。
- **教育的改變**：金融計算的教學從「教寫程式」轉向「教審核 LLM 生成的程式」——理解演算法本質（本書的目標）比記住實作細節更重要。
- **理論的回響**：LLM 把「資訊→價格」的映射加速，市場效率的上限推高——但也可能讓訊號同質化、放大系統性風險。
- **本書的終點與起點**：從 Bachelier（1900）的「價格是隨機的」到 LLM（2023）的「語言是可計算的」——金融計算的歷史，就是**把不確定性變成可計算物件**的歷史。下一章會是什麼？可能是「把整個市場變成可模擬的世界模型」。
