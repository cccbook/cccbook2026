# 1905 - Einstein 光電效應

## 案件摘要
1905 年（奇蹟之年），Einstein 把 Planck 的 $h\nu$ 從數學手段升級為實體粒子——光量子（光子），一舉解釋了光電效應的全部謎團，並因此獲 1921 年諾貝爾獎。

## 前因 -- 為什麼會有這個案子
- **1887 年 Hertz** 在驗證電磁波的實驗中意外發現：紫外光照在電極上更容易產生火花——光電效應首次現身。
- **1902 年 Lenard** 精確測量發現：出射電子能量與光**強度無關**，只與**頻率**有關。
- 經典波動理論（光是連續電磁波）預測完全相反，三大矛盾無法調和。

## 線索與推理 -- 數學式、程式、理論

### 線索：實驗現象與經典理論的三個矛盾

| 實驗事實 | 經典波動理論預測 | 矛盾 |
|---|---|---|
| (1) 電子動能只依賴頻率 $\nu$ | 動能應依賴光強度 | 強度換不到能量 |
| (2) 存在截止頻率 $\nu_0$，$\nu < \nu_0$ 時無論多強都無電子 | 任何頻率，只要時間夠久、強度夠大，能量累積足以打出電子 | 不存在「蓄能量」機制 |
| (3) 電子發射**無時間延遲**（$< 10^{-9}$ s） | 弱光下能量累積需數小時 | 立即發射無法解釋 |

### 推理一：光量子假說
Einstein 的關鍵洞察：Planck 的量子化不只適用於腔壁振子，**光本身就是量子化的**。一束光是一顆顆能量為

$$
E = h\nu
$$

的光量子。一顆光子**一次性**把全部能量交給一顆電子——所以沒有時間延遲、強度只決定光子數目（電子數目），與單顆電子能量無關。矛盾 (1)(2)(3) 全部一次解決。

### 推理二：Einstein 光電方程
電子脫離金屬需付出能量代價 $\phi$（功函數，work function）。能量守恆給出：

$$
K_{max} = h\nu - \phi
$$

由 **截止頻率** 定義：

$$
\nu_0 = \frac{\phi}{h}
$$

- $\nu > \nu_0$：有電子，$K_{max}$ 隨 $\nu$ 線性增加，斜率為 $h$。
- $\nu < \nu_0$：無電子，與強度無關。
- $h\nu = \phi$（臨界）：$K_{max} = 0$。

實驗上以**遏止電壓** $V_s$ 測量：$e V_s = K_{max} = h\nu - \phi$，即

$$
V_s = \frac{h}{e}\nu - \frac{\phi}{e}
$$

$V_s$–$\nu$ 圖是一條直線，**斜率 = $h/e$**——這是測量 $h$ 最乾淨的方法。

各金屬功函數（eV）：銫 2.1、鈉 2.3、鋅 4.3、銅 4.7、鉑 6.35。可見光（1.6–3.3 eV）只能打出低功函數金屬的電子，紫外線（> 3.3 eV）則幾乎都能。

### 推理三：光子的動量
1909 年 Einstein 進一步指出光子也帶動量；1916–1923 由 Compton 效應完全證實。由相對論能量動量關係 $E^2 = (pc)^2 + (m c^2)^2$ 與 $m = 0$：

$$
p = \frac{E}{c} = \frac{h\nu}{c} = \frac{h}{\lambda}
$$

這是德布羅意物質波 $\lambda = h/p$ 的先聲。

### 程式驗證：Millikan 實驗模擬

```python
import numpy as np
import matplotlib.pyplot as plt

h = 6.626e-34; e = 1.602e-19
phi = 4.3 * e          # 鋅的功函數 (J)
nu0 = phi / h          # 截止頻率

nu = np.linspace(0.5e15, 1.5e15, 200)
Vs = np.where(nu >= nu0, (h*nu - phi)/e, 0)   # 遏止電壓

plt.figure(figsize=(7,5))
plt.plot(nu*1e-15, Vs, lw=2)
plt.axvline(nu0*1e-15, ls='--', c='r', label=f'cutoff $\\nu_0$ = {nu0*1e-15:.2f} PHz')
plt.xlabel(r'$\nu$ ($10^{15}$ Hz)'); plt.ylabel(r'$V_s$ (V)')
plt.title('Stopping voltage vs frequency (slope = h/e)')
plt.legend(); plt.show()

# 由斜率反推 h
nu_pts = np.linspace(1.2e15, 1.5e15, 10)
Vs_pts = (h*nu_pts - phi)/e
slope = np.polyfit(nu_pts, Vs_pts, 1)[0]
print(f"推得 h = {slope*e:.3e} J·s  (真值 6.626e-34)")
```

執行結果：$\nu < \nu_0$ 時 $V_s = 0$，之後線性上升；由斜率反推 $h$ 與真值一致。

## 結案 -- 後果與影響
- **Millikan（1916）** 十年實驗企圖推翻 Einstein 方程，結果反而精確證實之：斜率給出 $h$，誤差 < 1%。Millikan 自己得 1923 諾貝爾獎。
- **Einstein 得 1921 年諾貝爾獎**——不是因相對論，而是「發現光電效應定律」。
- 光子概念孕育了 Compton 效應（1923）、德布羅意物質波（1924）、量子電動力學（1927–）。
- 技術遺產：光電倍增管、太陽能電池、數位相機感光元件（CMOS/CCD）皆基於光電效應。
- 波粒二象性從此成為量子力學的核心思想：光既是波（干涉、繞射）也是粒子（光電、Compton）。
