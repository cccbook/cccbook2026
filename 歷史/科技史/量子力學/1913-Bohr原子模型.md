# 1913 - Bohr 原子模型

## 案件摘要
1913 年，Bohr 把 Planck 的量子化嫁接到 Rutherford 的核式原子上，提出半經典模型，一舉解釋氫原子光譜與「原子為何不會塌縮」兩大懸案。

## 前因 -- 為什麼會有這個案子
- **Rutherford 模型（1911）** 的致命難題：繞核加速的電子依 Larmor 公式輻射能量，$\sim 10^{-11}$ 秒內墜入原子核——但原子明明穩定存在。
- **氫原子光譜**（Balmer 1885 發現可見光譜系）呈現神秘的分立譜線，符合 Rydberg 經驗公式，但無人能解釋。
- 經典物理給出的是**連續**光譜與**塌縮**的原子——兩個大矛盾。

## 線索與推理 -- 數學式、程式、理論

### 線索一：Rydberg 公式（1888）
氫原子譜線波數的經驗公式：

$$
\frac{1}{\lambda} = R\left(\frac{1}{n_1^2} - \frac{1}{n_2^2}\right), \quad R = 1.0968\times 10^7\,\text{m}^{-1}
$$

譜線系列：
- **Lyman 系列**（1906）：$n_1 = 1$，紫外區，$n_2 = 2, 3, 4, \dots$
- **Balmer 系列**（1885）：$n_1 = 2$，可見區，$n_2 = 3, 4, 5, \dots$（Hα = 656.3 nm、Hβ = 486.1 nm、Hγ = 434.0 nm）
- **Paschen 系列**（1908）：$n_1 = 3$，紅外區。

### 推理一：兩大假設
Bohr 的推理極為大膽，直接放棄經典力學的兩條法則：

1. **角動量量子化（定態假設）**：電子只能在特定「定態」軌道運行，不輻射能量。軌道角動量取離散值：

$$
L = m v r = n\hbar = n\frac{h}{2\pi}, \quad n = 1, 2, 3, \dots
$$

2. **頻率條件（躍遷假設）**：電子從能階 $E_{n_2}$ 躍遷到 $E_{n_1}$ 時，發射（或吸收）一顆光子：

$$
h\nu = E_{n_2} - E_{n_1}
$$

### 推理二：推導能階與軌道半徑
對氫原子（核固定），庫侖力提供向心力：

$$
\frac{e^2}{4\pi\epsilon_0 r^2} = \frac{m v^2}{r}
\;\Rightarrow\; m v^2 r = \frac{e^2}{4\pi\epsilon_0}
$$

與量子化條件 $m v r = n\hbar$ 聯立：

$$
r_n = \frac{4\pi\epsilon_0 \hbar^2}{m e^2}\, n^2 = a_0\, n^2
$$

其中**波爾半徑** $a_0 = 0.529\,\text{Å} = 5.29\times 10^{-11}\,\text{m}$——與已知原子尺寸 $10^{-10}$ m 完全一致（量子理論「算出」了原子的大小！）。

動能 $K = \frac{1}{2}m v^2 = \frac{e^2}{8\pi\epsilon_0 r}$，位能 $U = -\frac{e^2}{4\pi\epsilon_0 r}$，總能量：

$$
E_n = -\frac{m e^4}{2(4\pi\epsilon_0)^2 \hbar^2}\, \frac{1}{n^2} = -\frac{13.6\,\text{eV}}{n^2}
$$

- $E_1 = -13.6$ eV（基態，游離能），$E_2 = -3.4$ eV，$E_3 = -1.51$ eV，$E_\infty = 0$。
- 能階**不均勻**：$n$ 越大越密集，收斂於 0。

### 推理三：推出 Rydberg 公式
由頻率條件：

$$
\frac{1}{\lambda} = \frac{E_{n_2} - E_{n_1}}{hc} = \frac{m e^4}{8\epsilon_0^2 h^3 c}\left(\frac{1}{n_1^2} - \frac{1}{n_2^2}\right) = R_H\left(\frac{1}{n_1^2} - \frac{1}{n_2^2}\right)
$$

理論 Rydberg 常數 $R_H = 1.0968\times 10^7\,\text{m}^{-1}$——**與實驗值吻合到 5 位有效數字**！這是量子理論第一次做出如此精確的定量預測，Balmer 的經驗公式從此有了物理根源。

### 程式驗證：能階圖與光譜

```python
import numpy as np
import matplotlib.pyplot as plt

E1 = -13.6  # eV
n = np.arange(1, 7)
En = E1 / n**2

# 能階圖
plt.figure(figsize=(6,7))
for i, e_ in enumerate(En, 1):
    plt.hlines(e_, 0, 1, lw=2)
    plt.text(1.05, e_, f'n={i}: {e_:.2f} eV', va='center')
plt.annotate('ionization (E=0)', (0, 0), (0, 0.7),
             arrowprops=dict(arrowstyle='->'))
plt.xlim(0, 2); plt.ylim(-15, 1.5)
plt.ylabel('Energy (eV)'); plt.title('Hydrogen energy levels (Bohr)')
plt.xticks([]); plt.show()

# Rydberg 公式：計算 Balmer 系列波長
R = 1.0968e7
lam = 1 / (R * (1/2**2 - 1/np.arange(3, 7)**2))
print("Balmer series (nm):", np.round(lam*1e9, 1))
# 656.3 486.1 434.0 410.2 -- 與實驗完全一致
```

執行結果：能階圖顯示 $-13.6/n^2$ 的階梯逐漸收斂至 0；Balmer 系列波長 656.3、486.1、434.0、410.2 nm 與實驗譜線完全吻合。

### 推理四：對應原理
Bohr 提出**對應原理（correspondence principle）**：當量子數很大（$n \to \infty$）時，量子結果必須趨近經典結果。檢查：

- 軌道頻率 $f_{orb} = \frac{v}{2\pi r} \propto \frac{1}{n^3}$。
- 躍遷頻率 $\nu_{n \to n-1} = \frac{E_n - E_{n-1}}{h} \approx \frac{27.2\,\text{eV}}{h n^3} \propto \frac{1}{n^3}$。

兩者在 $n$ 大時一致——量子躍遷頻率在高 $n$ 極限回歸經典輻射頻率。這成為日後建立完整量子力學（矩陣力學）的指導原則。

### 結案推理：原子穩定性
定態假設直接切斷「加速電子必輻射」的經典法則：電子在 $n = 1$ 定態上不輻射、不塌縮。原子穩定性結案。

## 結案 -- 後果與影響
- 氫光譜與原子穩定性結案；Bohr 得 1922 年諾貝爾獎。
- **模型的缺陷**（引出新案）：
  1. **只對氫有效**：對氦（$\text{He}^+$ 只差 $Z^2$ 修正勉強可算）、鹼金屬與多電子原子完全失靈——電子間交互作用無法處理。
  2. **無法解釋譜線強度與精細結構**：譜線為何有亮有暗？磁場下的 Zeeman 分裂為何偏離預測？
  3. 軌道概念本身含糊：定態的「軌道」無法被實驗觀測。
- 1925 年 Heisenberg 矩陣力學、Schrödinger 波動力學徹底重建量子力學（由 Bohr 的哥本哈根研究所主導）；Sommerfeld 橢圓軌道修正部分解釋精細結構。
- 技術遺產：能階概念成為雷射、原子鐘、化學鍵理論的基礎。
