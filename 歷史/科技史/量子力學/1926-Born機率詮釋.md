# 1926 — Born 機率詮釋

## 案件摘要
1926 年，Max Born 在一篇僅兩頁的短註中提出：波函數的模方 $|\psi|^2$ 不是物質的密度，而是**找到粒子在該處的機率密度**。這一詮釋把機率放進物理定律的核心，引爆了 Einstein 與量子陣營長達三十年的決定論之爭，並讓 Born 在 28 年後獲得諾貝爾獎。

## 前因 -- 為什麼會有這個案子
- 1926 年 Schrödinger 波動力學問世，但 $\psi$ 的**物理意義不明**：Schrödinger 自己認為 $e\psi^2$ 是電荷的實際空間分佈（連續物質波）。
- Born 研究電子對原子的**散射實驗**：實驗測到的是螢幕上「一顆一顆」的電子亮點與總體散射角分佈，而非連續波。
- 碰撞後波以各方向擴散，但偵測器每次只在一處記錄到**整顆**電子——連續波如何變成顆粒？這是詮釋難題的案發現場。

## 線索與推理 -- 數學式、程式、理論

### 線索一：散射實驗的詮釋難題
入射平面波 $\psi_{in} = e^{ikz}$ 撞上原子後變成散射波：

$$\psi_{sc}(r) \sim f(\theta)\,\frac{e^{ikr}}{r}$$

若 $\psi$ 是電荷密度，電子應「碎裂」成球面波灑向四面八方——但實驗中**從未**看到半顆電子。Born 的結論：$f(\theta)$ 決定的是散射**機率**，不是物質分佈。

### 線索二：機率詮釋與歸一化
**Born 規則**：

$$P(x) = |\psi(x)|^2 = \psi^*(x)\psi(x)$$

$\psi$ 本身是複數、不可觀測；只有模方是實數機率密度。波函數必須**歸一化**：

$$\int_{-\infty}^{\infty} |\psi(x)|^2\, dx = 1$$

物理意義：粒子一定會在**某處**被找到，全空間機率總和為 1。

### 線索三：期望值
任意可觀測量 $\hat{A}$ 的期望值由機率幅積分給出：

$$\langle A\rangle = \int_{-\infty}^{\infty} \psi^*\, \hat{A}\, \psi\, dx$$

例如位置期望值 $\langle x\rangle = \int x|\psi|^2 dx$、動量 $\langle p\rangle = \int \psi^*(-i\hbar\frac{d}{dx})\psi\, dx$。Schrödinger 方程保證 $\langle A\rangle$ 隨時間演化的規律（Ehrenfest 定理），與經典力學對應原理一致。

### 線索四：決定論 vs 機率論之爭
- Schrödinger 方程本身是**完全決定論**的：$\psi$ 的演化毫無隨機。
- 但「測量得到哪個位置」是**本質隨機**的——機率不是無知造成的（非經典機率），而是自然定律的一部分。
- Einstein 的抗議：「**God does not play dice with the universe**」（上帝不擲骰子），他在 1926 年 12 月致 Born 的信中寫下此語。
- Born 的回應立場：量子力學完備，機率詮釋是物理的一部分。這場辯論延伸出 1935 年 EPR 悖論與 1964 年 Bell 不等式——實驗最終（Aspect 1982 等）支持量子機率。

### 程式碼範例：Python Monte Carlo 模擬雙縫干涉機率分佈
```python
import numpy as np
import matplotlib.pyplot as plt

# 雙縫波函數的機率幅（遠場 Fraunhofer 近似）
d, lam, Lscr = 1e-6, 500e-9, 1.0   # 縫距、波長、屏距
X = np.linspace(-3e-3, 3e-3, 2000)
k = 2 * np.pi / lam
amp = np.cos(k * d * X / (2 * Lscr))                 # 干涉因子
env = np.sinc(X / (Lscr * 1e-6))                     # 單縫繞射包絡
psi = amp * env                                      # 機率幅
P = np.abs(psi)**2                                   # Born 規則
P /= P.sum()                                         # 歸一化 ∫|ψ|²=1

# Monte Carlo：抽樣 5000 顆電子的落點
rng = np.random.default_rng(42)
hits = rng.choice(X, size=5000, p=P)

fig, axes = plt.subplots(2, 1, figsize=(8, 6), sharex=True)
axes[0].hist(hits, bins=200, density=True, color="steelblue")
axes[0].set_ylabel("偵測到的電子數（顆）")
axes[1].plot(X, P, "r-"); axes[1].set_ylabel("$|\\psi|^2$")
axes[1].set_xlabel("螢幕位置 x (m)")
plt.tight_layout(); plt.show()
```

直方圖（顆粒、隨機）與 $|\psi|^2$ 曲線（平滑、確定）的對比，正是量子機率詮釋的核心畫面：單次事件隨機，大量事件服從 Born 規則。

## 結案 -- 後果與影響
- 機率詮釋被大多數物理學家接受，成為哥本哈根詮釋的支柱之一（見 1927 Solvay 會議）。
- Schrödinger 對此深表遺憾，1926 年底說：「若我早知如此，當初就不會發明這個方程。」
- 測量問題就此誕生：塌縮（collapse）機制是什麼？引出多世界、導航波、客觀塌縮等競爭詮釋。
- 1954 年 Born 以「對波函數機率詮釋的統計研究」獲**諾貝爾物理獎**——距提出已 28 年，反映此觀念當年被接受的艱難。
- 影響至今：量子資訊的機率幅計算、量子測量的統計模型，全部建立在 Born 規則上。
