# 1997-量子隱形傳態

## 案件摘要
1997 年，Anton Zeilinger 領導的因斯布魯克團隊（以及稍後的義大利 Rome 團隊 De Martini 等）首次在實驗上完成「量子隱形傳態」：一個未知量子態跨越實驗室消失，又在另一端重現。偵探追查發現，真正的方案早在 1993 年就由 Bennett 等 6 人寫成論文——本案件是「理論先行、實驗收網」的典範。

## 前因 -- 為什麼會有這個案子
- 直接「複製」量子態是被禁止的：Wootters–Zurek（1982）證明 **no-cloning theorem**。因此無法「掃描然後重建」一個未知態。
- 直接「測量再傳」也不行：量測會破壞疊加，只能得到有限資訊（1 個 qubit 只能量出 1 bit）。
- 但 1993 年 Bennett、Brassard、Crépeau、Jozsa、Peres、Wootters 發現一條漏洞：若雙方共享 **糾纏**（EPR 對）並輔以 **古典通信**，未知態可以在不出現「複製」的情況下轉移——原處的態被測量摧毀，新處的態被重現，符合量子力學一切限制。
- 問題：這個方案需要同時具備高品質 EPR 對產生、Bell 態辨識、快速古典通信——1990 年代中期的量子光學實驗室恰好剛好湊齊。

## 線索與推理 -- 數學式、程式、理論
### 完整推導
Alice 持有未知態

$$|\psi\rangle_1 = \alpha|0\rangle + \beta|1\rangle,\quad |\alpha|^2+|\beta|^2=1$$

Alice 與 Bob 共享 Bell 對：

$$|\Phi^+\rangle_{23} = \frac{1}{\sqrt{2}}\big(|00\rangle + |11\rangle\big)$$

三粒子總態：

$$|\psi\rangle_1|\Phi^+\rangle_{23} = \frac{1}{2}\Big[|\Phi^+\rangle_{12}(\alpha|0\rangle+\beta|1\rangle)_3 + |\Phi^-\rangle_{12}(\alpha|0\rangle-\beta|1\rangle)_3$$
$$+ |\Psi^+\rangle_{12}(\beta|0\rangle+\alpha|1\rangle)_3 + |\Psi^-\rangle_{12}(\beta|0\rangle-\alpha|1\rangle)_3\Big]$$

三步驟：
1. **Bell 測量**：Alice 對粒子 1、2 做 Bell 基測量（Hadamard + CNOT + 量測），結果等機率為 4 個 Bell 態之一，並通知 Bob 2 個古典位元。
2. **古典通信**：Bob 根據收到的位元選擇修正操作：

| Alice 測得 | Bob 的修正 |
|---|---|
| $\Phi^+$ (00) | $I$ |
| $\Phi^-$ (01) | $Z$ |
| $\Psi^+$ (10) | $X$ |
| $\Psi^-$ (11) | $XZ$ |

3. **重建**：修正後 Bob 的粒子 3 恰為 $|\psi\rangle_3 = \alpha|0\rangle+\beta|1\rangle$。

注意：原粒子 1 的態已因測量而坍縮——傳送的是「態」，不是「物質」，也沒有複製；且古典通信保證不超光速。

### No-cloning 與 $\sqrt{\mathrm{NOT}}$ 的不可能
若存在複製機 $U|0\rangle|e\rangle = |0\rangle|0\rangle$、$U|1\rangle|e\rangle=|1\rangle|1\rangle$，由線性：

$$U(\alpha|0\rangle+\beta|1\rangle)|e\rangle = \alpha|00\rangle + \beta|11\rangle \ne (\alpha|0\rangle+\beta|1\rangle)^{\otimes 2}$$

（前者是糾纏態，後者是可分離態），矛盾。同理，一個酉算符 $U$ 若把 $|0\rangle$ 映到 $|+\rangle$、$|1\rangle$ 映到 $|-\rangle$，則 $U^2=I$ 而非 $U^2=\sqrt{\mathrm{NOT}}$——不存在能對任意態「部分複製」的酉機；完美複製與完美測量都是量子世界的不可能任務，傳態是繞道而行的唯一解。

### 1997 年實驗
Zeilinger 團隊（Innsbruck）用參數下轉換（SPDC）產生 EPR 光子對，透過偏振分析完成 Bell 態測量，將任意偏振態 $|\psi\rangle$ 傳送到 4 個光子外。實驗以 Bell 態保真度約 0.80 驗證（經典極限 2/3），確認量子傳態成功。

### Python 模擬
```python
from qiskit import QuantumCircuit, transpile
from qiskit_aer import AerSimulator
from qiskit.quantum_info import Statevector, partial_trace
import numpy as np

alpha, beta = np.sqrt(0.7), np.sqrt(0.3)
qc = QuantumCircuit(3, 2)

qc.ry(2*np.arctan2(beta, alpha), 0)   # 準備 |psi> on q0
qc.h(1); qc.cx(1, 2)                  # EPR 對 on q1,q2
qc.cx(0, 1); qc.h(0)                  # Bell 測量前置
qc.measure(0, 0); qc.measure(1, 1)

sim = AerSimulator()
r = sim.run(transpile(qc, sim), shots=1024).result()
counts = r.get_counts()

# 帶條件修正後驗證 Bob 的態（以 00 結果為例驗證 I 修正）
qc2 = QuantumCircuit(3, 2)
qc2.ry(2*np.arctan2(beta, alpha), 0)
qc2.h(1); qc2.cx(1, 2); qc2.cx(0, 1); qc2.h(0)
sv = Statevector(qc2)
bob = partial_trace(sv, [0, 1])       # 約化密度矩陣
print(counts)
print(np.real(bob.data[0,0]), np.real(bob.data[1,1]))  # 0.7, 0.3
```

## 結案 -- 後果與影響
- 傳態成為**量子資訊科學的基本原語**：量子中繼器（quantum repeater）、量子網路、模組化量子電腦之間的態轉移都以傳態為核心。
- **量子中繼器**：Briegel–Dür–Cirac–Zoller（1998）提出利用傳態 + 糾纏純化串接節點，突破光纖中距離限制，是未來量子網際網路的藍圖。
- **gate teleportation**：Gottesman–Chuang（1999）指出傳態也可「傳送量子門」，成為容錯量子計算的重要技巧。
- 深遠影響：2017 年中國「墨子號」衛星完成 1400 km 的地星傳態；量子網際網路成為 2020 年代的國家級戰略目標。
