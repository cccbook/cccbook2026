# 1936-波導與雷達

## 案件摘要
1936 年，Bell Labs 的 George Southworth 與 W. L. Barrow 各自獨立證實：金屬空心管可以低損耗地傳送微波。這個「管中電磁波」的發現，讓雷達在二戰中成為決勝武器，並開啟了整個微波工程學科。

## 前因 -- 為什麼會有這個案子
- 1930 年代，無線電已進入公尺波段，但傳統雙導線傳輸線在高頻下輻射損耗與集膚效應急遽惡化。
- 光學中「中空導管導光」的想法（Wheeler、Rayleigh 早已提出理論端倪）暗示：金屬管或許能導電磁波。
- Southworth 在 Bell Labs 想找一種能把厘米波從振盪器送到天線而不漏光的「導管」；Barrow 在 MIT 則從波動方程出發研究管內模式。
- 戰雲密佈的歐洲，英國急需「看見」來襲轟炸機的技術——雷達應運而生，波導正是雷達的血管。

## 線索與推理 -- 數學式、程式、理論
### 1. 波導為什麼能傳波？
在理想導體圍成的矩形波導（寬 $a$、高 $b$）內，Maxwell 方程加上邊界條件 $E_\parallel = 0$，解出可傳播的模式 TE 與 TM。以 $\mathrm{TE}_{10}$ 模為例：

$$E_y = E_0 \sin\!\left(\frac{\pi x}{a}\right) e^{j(\omega t - \beta z)}$$

其中傳播常數：

$$\beta = \sqrt{\left(\frac{\omega}{c}\right)^2 - \left(\frac{\pi}{a}\right)^2}$$

當 $\omega < \pi c/a$ 時 $\beta$ 變為虛數，波不是傳播而是「消散（evanescent）」——這就是**截止頻率**：

$$f_c = \frac{c}{2a}$$

只有頻率高於 $f_c$ 的波才能在管中前進。波導因此像一個「高通濾波器 + 導管」。

### 2. 群速與相速
波導內相速超過光速、群速低於光速：

$$v_p = \frac{c}{\sqrt{1-(f_c/f)^2}}, \qquad v_g = c\sqrt{1-(f_c/f)^2}, \qquad v_p v_g = c^2$$

這不違反相對論——能量（資訊）由群速攜帶。

### 3. 腔式磁控管（Boot & Randall, 1940）
伯明罕大學的 John Randall 與 Harry Boot 為了雷達需要高功率微波源，發明了**腔式磁控管**（cavity magnetron）：
- 電子在外加磁場 $B$ 中繞圓軌道運動，迴旋頻率 $\omega = eB/m$。
- 電子在多個共振腔（諧振器陣列）間形成「輻條狀」電子雲，把直流功率轉為微波，效率可達 70%。
- 1940 年 Tizard 使團把一枚磁控管帶到美國，直接催生了 MIT 輻射實驗室（Radiation Laboratory）。

### 4. Chain Home 雷達鏈（1938）
英國在 1938 年起沿東海岸架設 Chain Home 高頻雷達網（工作頻率約 20–30 MHz），配合隨後的厘米波雷達（波導 + 磁控管），在不列顛空戰中使皇家空軍能預先攔截。

### 5. Python 模擬：波導截止頻率與傳播

```python
import numpy as np
import matplotlib.pyplot as plt

c = 3e8  # 光速 m/s

def fc_rect(a, m=1, n=0):
    """矩形波導 TE_mn 模截止頻率"""
    return c/2 * np.sqrt((m/a)**2) if n == 0 else c/2*np.sqrt((m/a)**2+(n/(a/2))**2)

def beta(f, a):
    l = c/f
    fc = c/(2*a)
    if f <= fc:
        return np.nan
    return 2*np.pi*np.sqrt(1/f**2 - 1/(4*a**2)*np.ones_like(f)) if hasattr(f,'__len__') \
           else 2*np.pi*np.sqrt(1/f**2 - 1/(4*a**2))

# WR-90 波導：a = 22.86 mm（X band）
a = 22.86e-3
fc = c/(2*a)
print(f"WR-90 截止頻率 f_c = {fc/1e9:.2f} GHz（X band 8.2–12.4 GHz 可用）")

f = np.linspace(2e9, 20e9, 500)
vg = c*np.sqrt(np.clip(1-(fc/f)**2, 0, 1))
vp = c**2/np.where(vg==0, np.nan, vg)

plt.figure(figsize=(8,5))
plt.plot(f/1e9, vg/1e8, label='群速 $v_g$')
plt.plot(f/1e9, vp/1e8, label='相速 $v_p$')
plt.axvline(fc/1e9, ls='--', color='r', label=f'截止 $f_c$={fc/1e9:.2f} GHz')
plt.xlabel('頻率 (GHz)'); plt.ylabel('速度 ($\\times 10^8$ m/s)')
plt.title('波導傳播：$v_p v_g = c^2$')
plt.legend(); plt.grid(True); plt.show()
```

執行結果：WR-90 截止頻率約 **6.56 GHz**；低於截止時波消散，高於截止時 $v_p > c > v_g$。

## 結案 -- 後果與影響
- 二戰雷達（Chain Home、機載 H2S、艦載雷達）倚賴波導與磁控管，被史學家視為盟軍勝利的關鍵科技之一。
- 戰後 MIT 輻射實驗室出版 28 卷《Radiation Laboratory Series》，奠定了**微波工程**學科：波導元件、諧振腔、阻抗匹配、微波網路分析。
- 磁控管至今仍是家用微波爐的心臟。
- 波導理論直接通向 1960 年代的波導光學與後來的光纖——「管中傳波」的思路從厘米延伸到微米。
