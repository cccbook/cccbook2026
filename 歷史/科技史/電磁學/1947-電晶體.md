# 1947-電晶體

## 案件摘要
1947 年 12 月 23 日，Bell Labs 的 Bardeen 與 Brattain 以鍺晶體上的金屬針做出「點接觸電晶體」，首次實現固態放大。1948 年 Shockley 提出接面電晶體理論，固態電子學正式取代真空管時代。

## 前因 -- 為什麼會有這個案子
- 1940 年代，電話交換機與雷達大量使用真空管：耗電、易燒、體積大、需預熱。Bell Labs 的主管 Mervin Kelly 下令：「用固態元件取代真空管。」
- 量子力學在 1920–30 年代已給出半導體理論工具：能帶論、Fermi 統計、載流子概念。
- 戰前肖特基與 Mott 已解釋金屬-半導體整流；戰時 Bell Labs 的矽/鍺檢波器研究累積了材料純化技術。
- 1945 年 Bell Labs 成立固態物理小組，Shockley 提出「場效應」構想：用垂直電場調控半導體表面導電——這是本案的最初線索，卻以失敗開場。

## 線索與推理 -- 數學式、程式、理論
### 1. Shockley 場效構想的失敗（推理的起點）
Shockley 預測外加電場 $V_g$ 應能調變表面載流子濃度 $\Delta n = C_g V_g/(e t)$，但實驗觀測到的調變**比理論小幾個數量級**。

Bardeen 的推理：**表面態（surface states）**——半導體表面的懸鍵把感應電荷「卡」在表面，電場到不了晶體內部。這個失敗的解釋反而成為破案關鍵：既然表面這麼敏感，何不直接**利用**表面？

### 2. 點接觸電晶體（1947.12.23）
Bardeen 與 Brattain 在 N 型鍺上放兩根間距約 50 μm 的金針（發射極 emitter、集極 collector），底部接基極：
- 發射極注入電洞（少數載流子）進入鍺薄層。
- 電洞未復合即被反向偏壓的集極吸走——**少數載流子注入與收集**，這就是電晶體作用。
- 觀測到功率增益約 4.5 dB，頻率可達 10 kHz 量級。

### 3. 雙載子接面電晶體（BJT）原理
Shockley 1948 年提出的結構更對稱、可量產：NPN 三層。放大關係：

$$I_C = \beta I_B, \qquad \beta = \frac{\alpha}{1-\alpha}, \qquad I_C = \alpha I_E$$

其中 $\alpha$ 是集極效率（典型 0.98–0.998），$\beta$ 是電流增益（典型 50–300）。Ebers–Moll 模型把 BJT 描述為兩個背靠背的二極體加電流源：

$$I_C = \alpha_F I_{ES}\!\left(e^{V_{BE}/V_T}-1\right) - I_{CS}\!\left(e^{V_{CB}/V_T}-1\right), \qquad V_T = \frac{kT}{e} \approx 26\,\text{mV}$$

### 4. 半導體能帶與 pn 接面
- **摻雜**：N 型摻磷（施主，$E_D$ 貼近導帶），P 型摻硼（受主）。
- **pn 接面**：內建電位 $V_{bi} = V_T \ln\!\left(\dfrac{N_A N_D}{n_i^2}\right)$；二極體定律 $I = I_S\!\left(e^{V/V_T}-1\right)$。
- 空乏區寬度 $W = \sqrt{\dfrac{2\varepsilon}{q}\dfrac{N_A+N_D}{N_A N_D}(V_{bi}-V)}$。

### 5. Python：BJT 輸出特性曲線（簡化 Ebers–Moll）

```python
import numpy as np
import matplotlib.pyplot as plt

kT = 0.02585          # V_T = kT/e (300K)
Is = 1e-14            # 飽和電流
alpha_F, alpha_R = 0.99, 0.5
Ies = Is/alpha_F; Ics = Is/alpha_R

def ic_bjt(vbe, vce):
    """簡化 BJT：主動區以指數注入為主"""
    vbc = vbe - vce
    return alpha_F*Ies*(np.exp(vbe/kT)-1) - Ics*(np.exp(vbc/kT)-1)

vce = np.linspace(0, 10, 300)
plt.figure(figsize=(7,5))
for vbe in [0.6, 0.65, 0.7, 0.7, 0.72, 0.74][::2]:
    ic = ic_bjt(vbe, vce)
    plt.plot(vce, ic*1e3, label=f'$V_{{BE}}$={vbe:.2f} V')
plt.xlabel('$V_{CE}$ (V)'); plt.ylabel('$I_C$ (mA)')
plt.title('BJT 輸出特性：$I_C \\approx \\alpha_F I_{ES} e^{V_{BE}/V_T}$（主動區平直）')
plt.legend(); plt.grid(True); plt.show()
```

結果顯示典型的輸出特性族：在主動區 $I_C$ 幾乎不隨 $V_{CE}$ 變化，只由 $V_{BE}$（即 $I_B$）決定——這就是電流放大與「恆流源」特性的由來。

## 結案 -- 後果與影響
- **1956 年諾貝爾物理獎**頒給 Shockley、Bardeen、Brattain三人（Bardeen 後於 1972 年再得超導理論獎，兩屆得主第一人）。
- 1950 年代 Teal 與 Little 製出單晶矽、結面電晶體量產；真空管在電腦（ENIAC 的 17,000 根管子）與電話交換機中被淘汰。
- Shockley 到加州創立公司，孕育出「八叛逆」與 Fairchild Semiconductor——1958 年 IC 的直接前奏。
- 今天單顆晶片上有數百億顆電晶體；本案件是人類史上影響最深遠的單一發明之一。
