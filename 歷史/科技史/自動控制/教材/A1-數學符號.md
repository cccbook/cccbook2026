# A1 數學符號

## 常用符號表

| 符號 | 意義 |
|------|------|
| $u(t)$ | 控制輸入（controller output） |
| $y(t)$ | 系統輸出（measured output） |
| $r(t)$ | 參考命令（reference / setpoint） |
| $e(t) = r(t) - y(t)$ | 誤差 |
| $d(t)$ | 擾動（disturbance） |
| $G(s)$ | 受控體的轉移函數 |
| $K(s)$ | 控制器的轉移函數 |
| $L(s) = K(s)G(s)$ | 迴路轉移函數（open-loop transfer function） |
| $T(s) = \dfrac{L}{1+L}$ | 閉迴路（補敏度）轉移函數 |
| $S(s) = \dfrac{1}{1+L}$ | 敏感度函數 |
| $x(t),\ \dot x(t)$ | 狀態向量及其導數 |
| $A, B, C, D$ | 狀態空間矩陣：$\dot x = Ax + Bu,\ y = Cx + Du$ |
| $\Phi(t) = e^{At}$ | 狀態轉移矩陣 |
| $\Re(s),\ \Im(s)$ | $s$ 的實部與虛部 |
| $\|G\|_\infty$ | $H_\infty$ 範數：最壞情況頻率增益 |
| $V(x)$ | Lyapunov 函數（類能量函數） |
| $J$ | 代價函數（cost functional） |
| $\lambda$ | Riccati/特徵值問題中的未知量 |

## Laplace 變換常用對照

| $f(t)$ | $F(s)$ |
|--------|--------|
| $\delta(t)$ | $1$ |
| $1$ | $\dfrac{1}{s}$ |
| $t$ | $\dfrac{1}{s^2}$ |
| $e^{-at}$ | $\dfrac{1}{s+a}$ |
| $\sin \omega t$ | $\dfrac{\omega}{s^2+\omega^2}$ |
| $\cos \omega t$ | $\dfrac{s}{s^2+\omega^2}$ |
| $e^{-at}\sin \omega t$ | $\dfrac{\omega}{(s+a)^2+\omega^2}$ |

## 三大判據一覽

| 判據 | 域 | 工具 | 適用 |
|------|----|------|------|
| Routh–Hurwitz | $s$ 域 | Routh 表 | 多項式極點位置 |
| Lyapunov | 時域 | 能量函數 $V(x)$ | 非線性系統 |
| Nyquist | 頻域 | 迴路頻率響應圖 | 回饋系統、含延遲 |
