# 03.1 Routh–Hurwitz 判據

## 本章導讀

「這個回饋系統穩不穩？」——最直接的答案是解特徵方程的根，
但高次多項式沒有根式解（Abel 定理）。
Routh 的妙招：**不必解根，只看係數就能判斷極點是否全在左半平面**。

## 淺顯說明

穩定性像「推不倒翁」：推一下會晃，但會回到原位。
數學上，這就是所有自然響應 $e^{p_i t}$ 都會衰減——即所有極點 $\Re(p_i) < 0$。

Routh 表像體檢報告：把多項式係數排成表格，第一欄有沒有變號，就是穩不穩的判準。

## 正規理論

### 穩定性的定義（連續時間線性系統）

線性系統 $\dot x = Ax$ 穩定（漸近穩定）若且唯若：

$$
\text{所有特徵值 } \lambda_i \text{ 滿足 } \Re(\lambda_i) < 0
$$

對轉移函數 $G(s)$，即特徵多項式的根全在左半平面。

### 特徵多項式

$$
a_ns^n + a_{n-1}s^{n-1} + \cdots + a_1 s + a_0 = 0, \qquad a_n > 0
$$

### Routh 表的構造

第一列：$a_n,\ a_{n-2},\ a_{n-4},\dots$；第二列：$a_{n-1},\ a_{n-3},\dots$。
之後每列由前兩列交叉相乘：

$$
b_1 = \frac{a_{n-1}a_{n-2} - a_na_{n-3}}{a_{n-1}}, \qquad
b_2 = \frac{a_{n-1}a_{n-4} - a_na_{n-5}}{a_{n-1}}, \quad \dots
$$

### Routh 判據

> 多項式的右半平面根的個數 = Routh 表第一欄的變號次數。
> **第一欄全同號（無變號）⇔ 系統穩定。**

必要條件（先檢查）：所有係數 $a_i > 0$。有負係數直接不穩，不必建表。

## 簡易範例：三階系統

$$
s^3 + 2s^2 + 4s + 8 = 0
$$

Routh 表：

| $s^3$ | 1 | 4 |
|-------|---|---|
| $s^2$ | 2 | 8 |
| $s^1$ | $\dfrac{2\cdot 4 - 1\cdot 8}{2} = 0$ | |
| $s^0$ | 8 | |

$s^1$ 列為 **0**——臨界情形！事實上 $s^3+2s^2+4s+8 = (s+2)(s^2+4)$，
極點 $s = \pm 2j$ 在虛軸上，系統持續振盪（Watt 調速器的「獵振」正是這種）。

### 回饋增益的穩定範圍

$G = \dfrac{1}{s(s+1)(s+2)}$，$K = k$，特徵方程：

$$
s^3 + 3s^2 + 2s + k = 0
$$

Routh 表 $s^1$ 列元素：$\dfrac{3\cdot 2 - k}{3} = \dfrac{6-k}{3}$。

穩定條件：$6 - k > 0$，即 $k < 6$。

**$k \ge 6$ 時系統不穩**——這說明回饋增益不是越大越好：
增益太大，極點被推過虛軸，系統振盪發散。

## 歷史典故

- 1877 年 Routh 提出穩定性判據，見 [1877-Routh穩定性判據.md](../1877-Routh穩定性判據.md)——
  為了回答 Adams 關於飛球調速器穩定性的疑問。
- 1893 年 Hurwitz 獨立完成矩陣形式，見（卷宗）——今日教科書的 Routh–Hurwitz 判據是兩人工作的合體。
- 1868 年 Maxwell 的〈論調速器〉已用特徵方程，但只處理低階，見
  [1868-Maxwell論調速器.md](../1868-Maxwell論調速器.md)。
