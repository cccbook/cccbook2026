# 自動控制 -- 教材

以淺顯的方式，搭配簡易範例與正規 TeX 數學推導，說明自動控制的理論。
每一節都引用 [../](../README.md) 資料夾的歷史卷宗作為典故，讓理論與歷史並行。

自動控制的核心，是「回饋」（feedback）取代「開環操作」成為主角：

- **古代**：浮子調節、恆溫裝置——直覺式的機械回饋。
- **經典控制**：轉移函數、頻域分析、根軌跡——以 Laplace 變換為語言的 SISO 時代。
- **現代控制**：狀態空間、Kalman 濾波、最佳控制——以矩陣與泛函為語言的多變數時代。
- **當代**：$H_\infty$ 魯棒控制、模型預測控制、學習控制——在不確定性中求穩與求優。

## 學習路徑建議

1. **入門**：01.1 → 01.2 → 02.2 → 02.3（回饋概念與轉移函數，動手算一階/二階系統）。
2. **經典控制**：03.1 → 04.1 → 04.2（穩定性與 PID/Bode 設計，工程實務核心）。
3. **理論加深**：02.1 → 03.3 → 04.3（建模、Nyquist、根軌跡）。
4. **現代控制**：05.1 → 05.2 → 05.3 → 06.2（狀態空間一條線，LQR 是最佳控制的門票）。
5. **前瞻**：06.1 → 07.1 → 07.2 → 07.3（最佳控制、魯棒、學習，接回歷史卷宗的當代篇）。
