# 自動控制史 -- AI 偵探風格

以「推理探案」的方式，追查自動控制從古希臘水鐘到今日魯棒控制與智慧控制的每一步：
前因是什麼？線索在哪裡？推理如何展開？後果又如何改變了整個工程與數學？

自動控制的核心，是「回饋」（feedback）取代「開環操作」成為主角：

- **古代**：浮子調節、恆溫裝置——直覺式的機械回饋。
- **經典控制**：轉移函數、頻域分析、根軌跡——以拉普拉斯變換為語言的單輸入單輸出時代。
- **現代控制**：狀態空間、Kalman 濾波、最佳控制——以矩陣與泛函為語言的多變數時代。
- **當代**：魯棒控制 $H_\infty$、模型預測控制、學習控制——在「不確定性」中求穩與求優。

三者等價又互補：經典控制最適合設計與直觀，現代控制最能顯露結構，當代控制處理真實世界的模型誤差。

## 主線結案陳詞

回饋是「用結果修正行為」的通用原理：從 Ktesibios 的浮子到 Watt 的飛球，
從 Black 的放大器到 Kalman 的濾波器，再到今日的 $H_\infty$ 與學習控制——
每一次躍升，都是「不確定性」被更深的數學馴服。控制理論的歷史，
就是工程師與數學家合力把「穩定」從手藝變成科學的歷史。
