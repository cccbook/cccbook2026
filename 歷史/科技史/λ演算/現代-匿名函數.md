# 現代 — 匿名函數進入主流

## 案件摘要
λ 演算發明近一甲子後，匿名函數終於滲透進每一個主流語言：Python（1991）、C#（2007）、Java 8（2014）、JavaScript ES6（2015）、Rust。從「邏輯學的玩具」到「雲端運算的基礎」，λ 演算百年完成了從純理論到全民武器的旅程。

## 前因 -- 為什麼會有這個案子
- **Lisp 的先聲（1958）**：McCarthy 的 Lisp 直接實作 λ 演算的 `lambda`，但主流（C、Pascal、Fortran）長期拒絕匿名函數——「函數必須有名字」。
- **ML 與 Miranda 的推廣**：ML 的 `fn x => x*2`、Miranda 的 `\x -> x*2` 證明匿名函數可以自然融入靜態型別語言。
- **多核心與雲端的壓力**：2000 年代多核心 CPU 與雲端運算興起，「迴圈 + 共享狀態」的命令式寫法在平行化時問題重重，函數式風格（無副作用、higher-order function）成為解藥。
- **MapReduce（2004）**：Google 的 MapReduce 論文直接以函數式概念命名——`map` 與 `reduce` 是 Lisp/函數式語言的基本操作，大規模分散式計算被建構在兩個 λ 演算基本運算子上！

## 線索與推理 -- 數學式、程式、理論

### 各語言 lambda 語法對照表
| 語言 | 年份 | 匿名函數語法 | 備註 |
|---|---|---|---|
| Lisp | 1958 | `(lambda (x) (* x 2))` | 直接實作 λ 演算 |
| ML | 1978 | `fn x => x * 2` | 靜態型別、Hindley–Milner 推論 |
| Miranda | 1985 | `\x -> x * 2` | 惰性求值 |
| Haskell | 1990 | `\x -> x * 2` | `\` 就是 λ 的 ASCII 形式 |
| Python | 1991 | `lambda x: x * 2` | 單表達式限制 |
| C# | 2007 | `x => x * 2`（LINQ） | 表達式樹可被序列化 |
| Java | 2014 | `x -> x * 2`（Java 8） | 需搭配函數式介面（Functional Interface） |
| JavaScript | 2015 | `x => x * 2`（ES6） | 箭頭函數，詞法 this |
| Rust | 2015 | `\|x\| x * 2` | 閉包以 trait（Fn/FnMut/FnOnce）型別化 |
| C++ | 2011 | `[](int x) { return x*2; }` | C++11 lambda |
| Swift | 2014 | `{ x in x * 2 }` | 尾隨閉包 |

### 閉包（Closure）語義
λ 演算的「自由變數」$\mathsf{FV}(\lambda x.\,x\,y) = \{y\}$——匿名函數捕捉外層的變數，這就是**閉包**：

$$(\lambda x.\,x\,y) \text{ 捕捉 } y \Rightarrow \text{閉包} = (\lambda x.\,M, \; \text{環境} \{y \mapsto v\})$$

```python
# Python：閉包捕捉外層變數
def make_adder(n):
    return lambda x: x + n      # 捕捉 n（自由變數）

add5 = make_adder(5)
add5(10)   # 15
```

各語言閉包語義的差異（捕捉「值」還是「變數」）：
- **Python**：閉包捕捉**變數綁定**（cell），`nonlocal` 才能修改。
- **JavaScript**：捕捉變數（let 之前的 var 有經典陷阱）。
- **Rust**：閉包以 **trait** 型別化——`Fn`（借用）、`FnMut`（可變借用）、`FnOnce`（奪走所有權），借用檢查器強制正確性。
- **C++**：捕捉值（`[=]`）或引用（`[&]`）由程式設計師指定。

```rust
// Rust：閉包與 trait
let n = 5;
let add5 = |x: i32| x + n;    // 閉包捕捉 n 的引用（Fn）
assert_eq!(add5(10), 15);
```

### Higher-order function（map / filter / reduce）
λ 演算的核心能力——**函數是第一等公民**（first-class），可以作為參數與回傳值：

$$(\text{map } f\,)[x_1, \ldots, x_n] = [f\,x_1, \ldots, f\,x_n]$$

```python
# Python：三劍客
xs = [1, 2, 3, 4, 5]
list(map(lambda x: x * 2, xs))           # [2, 4, 6, 8, 10]
list(filter(lambda x: x % 2 == 0, xs))   # [2, 4]
from functools import reduce
reduce(lambda acc, x: acc + x, xs, 0)    # 15
```

```javascript
// JavaScript ES6：箭頭函數
[1,2,3,4,5].map(x => x * 2)      // [2,4,6,8,10]
  .filter(x => x > 4)            // [6,8,10]
  .reduce((acc, x) => acc + x, 0);  // 24
```

### MapReduce 與雲端運算
Google 2004 年的 MapReduce 論文將「map + reduce」推廣到數千台機器：

```text
map    : (k1, v1) → list(k2, v2)     -- 每台機器對資料做 map
reduce : (k2, list(v2)) → list(v2)   -- 彙整中間結果
```

理論上，這就是 λ 演算的 catamorphism（摺疊）與 anamorphism（展開）在分散式系統的體現：

$$\mathsf{MapReduce}(f, g) = \mathsf{reduce}\,g\,(\mathsf{concat}\,(\mathsf{map}\,f\,\text{data}))$$

**後續**：Hadoop（2006）、Spark（2010）、以及 **AWS Lambda（2014）**——連「雲端無伺服器運算」都以 λ 命名！MapReduce 的函數式風格成為雲端運算的標準：**無副作用的純函數，才能被安全地平行化與重試**。

### λ 演算百年歷史的總結
```text
1928-1932  Church 發明 λ 演算（邏輯基礎的候選）
1936       Church–Rosser 合流性、Turing 機器（等價性）
1958-1969  Curry–Howard 對應、Lisp
1970s      Scott domain theory、ML、System F
1980s      Martin-Löf 依賴型別、Barendregt 聖經與 Lambda Cube
1989       Coq（Curry–Howard 的實作）
1990       Haskell（λ 演算的實戰語言）
1991-2015  Python/C#/Java/JavaScript/Rust 的匿名函數
2004+      MapReduce、雲端運算、AWS Lambda
2005+      四色定理、CompCert、Lean、HoTT
```

**百年結案陳詞**：λ 演算從「Frege-Russell 邏輯基礎危機的解藥之一」，經過 Church 的孤獨堅持、Turing 的等價性證明、Curry–Howard 的神秘對應、Scott 的語義模型、Martin-Löf 的依賴型別、Barendregt 的聖經整理，最終成為**每一個主流程式語言都內建的能力**。函數是第一等公民、匿名函數、閉包、higher-order function、monad——這些「現代常識」，每一個都源自 1928 年 Church 在普林斯頓的那支筆。**λ 演算是程式設計理論中最長壽、最深遠的單一發明**。
