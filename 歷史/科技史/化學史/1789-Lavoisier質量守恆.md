# 1789 Lavoisier 質量守恆

## 案發現場

1789 年的巴黎，是舊世界崩塌的一年——巴士底監獄在 7 月 14 日被攻陷，法國大革命爆發。但在化學的世界裡，這一年卻是新世界的誕生之年：**安東尼·拉瓦節（Antoine Lavoisier, 1743–1794）**出版了《化學基礎論（Traité élémentaire de chimie）》，化學史上第一部真正的「教科書」。

在這之前，拉瓦節已用氧化說推翻了燃素說（見 [1777-Lavoisier氧化說.md](1777-Lavoisier氧化說.md)），但化學仍缺少兩樣東西：**一條支配一切化學變化的基本定律**，以及**一張確定的元素表**。當時化學家各自為政：有人仍信四元素，有人自創分類，測量數據互相矛盾，命名混亂（同一種物質在不同實驗室有不同名字）。化學像一個沒有憲法、沒有戶籍制度的國家。

誰來制定憲法與戶籍？拉瓦節。他與妻子瑪麗-安妮在軍火庫實驗室工作了十幾年，累積了大量密閉系統的定量數據。這樁案件的重要性在於：《化學基礎論》確立了**質量守恆定律** $m_{\text{反應物}} = m_{\text{生成物}}$、列出**33 種元素表**、開創**化學方程式平衡**之始——現代化學的憲法，在斷頭台的陰影下誕生。

## 偵查過程

**第一步：把「物質不滅」從推理變成定律。** 拉瓦節在書中寫下化學史上最著名的方法論宣言之一：

> 「由於無中生有是不可能的，我們可以假設一個先驗命題：一切人工與自然操作中，物質既不產生也不消滅；反應前後物質的總量相等，只是發生了組合的變化與替代。」

用現代數學語言，質量守恆定律可寫成：

$$\sum_{i} m_{\text{反應物}, i} \;=\; \sum_{j} m_{\text{生成物}, j}$$

對密閉系統中的任何化學反應，參與反應各物質的總質量恆等於生成各物質的總質量。這不是一個「發現」於單一實驗的定律，而是從無數密閉系統對帳實驗中歸納出來、並被拉瓦節宣告為「化學的第一原理」。例如水的合成與分解（見 [1766-Cavendish氫氣.md](1766-Cavendish氫氣.md)）：

$$\mathrm{2H_2 + O_2 \rightarrow 2H_2O}$$

莫耳質量驗證：$2 \times 2.016 + 32.00 = 36.03$ g；$2 \times 18.02 = 36.03$ g。兩邊質量完全相等——方程式兩端平衡，正是質量守恆的表達形式。

**第二步：化學方程式平衡之始。** 拉瓦節首創用「方程式」表達化學變化：把反應物與生成物寫成代數等式，用質量守恆檢驗係數。他甚至用圖表（當時的「flamme式記法」）記錄物質的質量進出。雖然他的符號系統後來被貝托雷與道耳頓時代的現代記法取代，但「**化學反應 = 可以用代數平衡的方程式**」這個思想是他確立的。用現代符號表示，若反應 $\mathrm{a A + b B \rightarrow c C + d D}$，則對每一種元素 $X$：

$$a \cdot n_X(A) + b \cdot n_X(B) = c \cdot n_X(C) + d \cdot n_X(D)$$

其中 $n_X(M)$ 為一個分子 $M$ 中元素 $X$ 的原子數。這組線性方程組的解，就是化學計量係數——今天高中化學的「平衡方程式」練習，邏輯上正是拉瓦節質量守恆的直接推論。

**第三步：33 種元素表——化學的戶籍制度。** 《化學基礎論》的附錄是一張分類表，列出拉瓦節認定的 33 種「簡單物質」，分為四類：

1. **氧、氮、氫**等氣體元素（當時認為光與熱也是元素——這是最著名的誤判）；
2. **可氧化與成酸的非金屬**：硫、磷、碳、鹽酸基、氟酸基、硼酸基；
3. **可氧化成鹼的金屬**：銻、銀、砷、鉍、鈷、銅、錫、鐵、錳、汞、鉬、鎳、金、鉑、鉛、鎢、鋅；
4. **可鹽化的土類**：石灰、苦土、重土、礬土、矽土。

判斷標準正是波以耳的操作型定義：「能用一切方法都不能分解者」（見 [1661-Boyle元素概念.md](1661-Boyle元素概念.md)）。這張表有幾個誤判（光、熱、「土類」其實是氧化物——要等戴維 1807–1808 年用電解分離鉀、鈉、鈣後才修正），但它有兩個革命性的特點：**第一，它是第一張以實驗分解為判準、而非哲學傳統為判準的元素表**；**第二，它允許被修正**——此後每當有人分解出一種「元素」，元素表就更新一次，直到門得列夫週期表（1869）與現代 118 種元素。

**第四步：定量數據的品質標準。** 拉瓦節對測量精度的要求近乎偏執：他使用當時最精良的天平（感量達毫克級），堅持密閉系統、重複測量、誤差分析。他的水的合成實驗、糖發酵實驗（糖 + 水 → 酒精 + 二氧化碳的質量對帳）、動物呼吸實驗（呼吸是緩慢氧化）全部符合質量守恆。這些數據的品質讓氧化說與質量守恆無可辯駁。

## 結案報告

《化學基礎論》的遺產構成了現代化學的地基。

**第一，質量守恆定律**成為化學的第一原理：一切化學計量、化學方程式平衡、工業化學的物料計算，邏輯上都立足於 $\sum m_{\text{反應物}} = \sum m_{\text{生成物}}$。愛因斯坦的質能等價 $E = mc^2$ 後來補充了它的精確形式（化學反應中質量變化小到無法測量，所以守恆定律在化學尺度上依然成立）。

**第二，元素表**開啟了「元素戶籍」的傳統：戴維的電解（1807）分離出鉀、鈉、鈣、鎂，修正了「土類」；道耳頓的原子說（[1803-Dalton原子說.md](1803-Dalton原子說.md)）給元素以原子基礎；門得列夫的週期表（1869）把元素排序；今天我們有 118 種元素。一切始於拉瓦節的 33 種。

**第三，化學方程式與命名法**：系統命名法（1787）與《化學基礎論》的記法傳統，讓化學有了統一的語言。

**第四，教科書的典範**：《化學基礎論》是第一本用新理論體系組織、以定量數據支撐、附有元素表的化學教科書，此後所有化學教科書都是它的後裔。

悲劇：1794 年 5 月 8 日，拉瓦節因稅務總局股東的身分被革命法庭判處死刑，當日送上斷頭台。他的妻子瑪麗-安妮倖存，此後編輯出版了他的遺稿。拉格朗日的哀悼成為科學史的名言：「砍下這顆頭顱只要一瞬間，但要再長出這樣一顆頭，一百年也不夠。」質量守恆——物質不滅——的最終反諷是：拉瓦節的物質化為塵土，他的思想卻從未滅亡。

## 證據與工具

用 Python 實作化學方程式平衡（質量守恆的直接應用）：

```python
# 質量守恆驗證：2H2 + O2 -> 2H2O
M = {"H2": 2.016, "O2": 32.00, "H2O": 18.02}

def mass_balance(coeff_reactants, coeff_products, M):
    """檢驗化學方程式是否符合質量守恆"""
    left  = sum(c * M[s] for s, c in coeff_reactants.items())
    right = sum(c * M[s] for s, c in coeff_products.items())
    return left, right

# 拉瓦節的經典反應：水的合成
left, right = mass_balance({"H2": 2, "O2": 1}, {"H2O": 2}, M)
print(f"2H2 + O2 -> 2H2O")
print(f"反應物總質量 = {left:.3f} g，生成物總質量 = {right:.3f} g")
print(f"質量守恆成立：{abs(left - right) < 1e-6}")
```

```python
# 化學方程式平衡求解：以質量守恆（各元素原子數守恆）解線性方程組
# 範例：燃燒丙烷 C3H8 + O2 -> CO2 + H2O，求係數 a, b, c, d

from fractions import Fraction

def balance_reaction(elements, reactants, products):
    """以原子數守恆解 a*R1 + b*R2 -> c*P1 + d*P1 的係數"""
    # 建立係數矩陣：每一列對應一種元素的守恆式
    # a*nX(R1) + b*nX(R2) - c*nX(P1) - d*nX(P2) = 0
    import itertools
    for a, b, c, d in itertools.product(range(1, 30), repeat=4):
        if all(a*reactants[X][0] + b*reactants[X][1]
               == c*products[X][0] + d*products[X][1]
               for X in elements):
            return a, b, c, d

# C3H8 + 5O2 -> 3CO2 + 4H2O（正確平衡）
coeffs = balance_reaction(
    elements=["C", "H", "O"],
    reactants={"C": (3, 0), "H": (8, 0), "O": (0, 2)},
    products={"C": (1, 1), "H": (0, 0), "O": (2, 1)},
)
a, b, c, d = coeffs
print(f"平衡結果：{a} C3H8 + {b} O2 -> {c} CO2 + {d} H2O")

# 質量守恆驗證
M_C3H8, M_O2, M_CO2, M_H2O = 44.10, 32.00, 44.01, 18.02
left  = a*M_C3H8 + b*M_O2
right = c*M_CO2 + d*M_H2O
print(f"反應物 {left:.2f} g = 生成物 {right:.2f} g ✓（拉瓦節的第一原理）")
```
