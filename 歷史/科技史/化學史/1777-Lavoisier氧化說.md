# 1777 Lavoisier 氧化說

## 案發現場

1770 年代的巴黎，一位嚴謹到近乎苛刻的化學家正盯著化學界最大的懸案：**燃素說的矛盾**。

燃素說（見 [1774-Priestley氧氣.md](1774-Priestley氧氣.md)）已統治化學近百年，卻陷入無法自拔的困境：金屬煅燒後變成灰渣，質量**增加**了；如果燃燒是燃素逸出，質量應該減少。支持者被迫發明「負重量燃素」，一個允許負質量的理論已經失去科學的資格。同時，布萊克用天平抓到了固定空氣（[1754-Black二氧化碳.md](1754-Black二氧化碳.md)），證明看不見的氣體可以定量研究；卡文迪西測出了氫氣的精確密度（[1766-Cavendish氫氣.md](1766-Cavendish氫氣.md)）；普利斯特里加熱氧化汞得到了讓蠟燭燃燒更旺的「脫燃素空氣」。證據已經齊備，但沒有人把它們拼成真相。

誰接手這樁案件？**安東尼·拉瓦節（Antoine Lavoisier, 1743–1794）**，法國稅務總局的股東、軍火庫化學實驗室的主人、以及擁有當時歐洲最精良天平的定量化學家。他的妻子瑪麗-安妮擔任他的實驗記錄員與翻譯（她把英國化學文獻譯成法文，包括普利斯特里的論文）。1774 年 10 月普利斯特里訪巴黎的演示，點燃了拉瓦節的偵查靈感。這樁案件的重要性在於：拉瓦節以氧化說推翻了燃素說，並確立「物質不滅」的推理原則，是化學史上最徹底的一次理論革命。

## 偵查過程

拉瓦節的偵查手法可歸納為三條原則：**只信天平、封閉系統、質量對帳。**

**第一步：重做錫的煅燒實驗（1772 年）。** 拉瓦節先從質量矛盾下手。他重做金屬煅燒實驗，發現錫在密閉容器中加熱後，灰渣確實更重，但**容器與內容物的總質量不變**。這是關鍵線索：如果燃素逸出到空氣中，總質量應該減少；總質量不變，說明根本沒有東西逸出——相反，灰渣的增重來自**容器內空氣的某種成分被吸收了**。

我們用現代符號重述這個對帳：

$$m_{\text{錫}} + m_{\text{空氣}} = m_{\text{灰渣}} + m_{\text{剩餘空氣}}$$

密閉系統中總質量守恆，因此灰渣的增重 $\Delta m$ 必然等於空氣的減重。拉瓦節測得灰渣增重與空氣減重確實相等——物質不滅的推理第一次在燃燒問題上發揮威力。

**第二步：識破「脫燃素空氣」的真身。** 1774 年普利斯特里的演示給了拉瓦節最後一塊拼圖。他立刻重做氧化汞實驗，並把實驗倒過來做：加熱氧化汞得氧氣；再把汞與氧氣密閉加熱，**重新生成氧化汞，且質量分毫不差**：

$$\mathrm{2Hg + O_2 \rightarrow 2HgO}, \qquad \mathrm{2HgO \rightarrow 2Hg + O_2}$$

這個可逆的定量實驗證明：煅燒不是燃素逸出，而是**金屬與空氣中那個「助燃成分」的結合**。灰渣 = 金屬 + 氧。用現代摩爾質量驗證汞的氧化物：$\mathrm{HgO}$ 中 $\mathrm{O}$ 佔 $16.00/216.59 \approx 7.4\%$，與拉瓦節的實測相符。

**第三步：命名「氧」，提出氧化說（1777 年）。** 拉瓦節把這種助燃成分命名為「氧（oxygène，意為成酸者）」，因為他發現非金屬燃燒後的產物溶於水呈酸性（硫→硫酸、磷→磷酸；這個「成酸」的命名後來被證明以偏概全——鹽酸、後來發現的氫氯酸並不含氧——但氧化說的骨架是正確的）。1777 年他向巴黎科學院提交《燃燒通論》，正式提出**氧化說**：

> 燃燒不是燃素的逸出，而是物質與氧化合的過程；金屬煅燒產生的灰渣是金屬氧化物；空氣不是單一元素，而是氧氣與其他成分的混合物；呼吸是緩慢的燃燒（氧化）。

這一理論一舉解釋了所有舊謎團：金屬煅燒增重（與氧結合）、蠟燭在氧氣中更旺（氧濃度高）、呼吸（緩慢氧化）、石灰石分解（釋出氧的化合物 $\mathrm{CO_2}$）。一個假說，解釋所有證據，且不需要「負質量」——偵探破案的標誌。

**第四步：定量實驗方法的制度化。** 拉瓦節的真正武器不是任何單一實驗，而是方法論。他規定：化學實驗必須在**密閉系統**中進行，必須用**精確天平**稱量反應前後所有物質，必須進行**質量對帳**（總質量進出相等）。他用這套方法重做了布萊克、普利斯特里、卡文迪西的實驗，證明它們全部可以在氧化說框架下統一。這套方法後來成為質量守恆定律（見 [1789-Lavoisier質量守恆.md](1789-Lavoisier質量守恆.md)）的實驗基礎，也是所有化學計量的祖師。

**第五步：與燃素說的決戰。** 1780 年代，拉瓦節與燃素說的支持者（包括普利斯特里本人）展開激烈辯論。1783 年，卡文迪西與拉瓦節合作完成水的合成實驗（見 [1766-Cavendish氫氣.md](1766-Cavendish氫氣.md)），證明水是氫與氧的化合物——燃素說最後的堡壘（水＝氫的燃素化合物）崩塌。拉瓦節戲言：「我燒掉了燃素這個幽靈。」1789 年《化學基礎論》出版，氧化說成為正統。

## 結案報告

氧化說的遺產是化學史上最深厚的。

**第一，燃燒的正確解釋**，成為一切現代化學的基礎。今天的每一本化學教科書、「氧化反應」的概念（從生鏽到呼吸到電池）都源自拉瓦節。燃素說成為科學哲學中「被徹底推翻的舊範式」的標準案例（孔恩《科學革命的結構》多次引用）。

**第二，質量守恆的推理原則**：拉瓦節的密閉系統實驗直接導出質量守恆定律，成為化學方程式平衡的邏輯基礎（見 [1789-Lavoisier質量守恆.md](1789-Lavoisier質量守恆.md)）。

**第三，定量方法的制度化**：天平、密閉系統、質量對帳成為化學家的標準作業程序，供養了此後整個定量革命——普魯斯特的定比定律（[1799-Proust定比定律.md](1799-Proust定比定律.md)）、道耳頓的原子說（[1803-Dalton原子說.md](1803-Dalton原子說.md)）都站在拉瓦節的方法之上。

**第四，化學命名法的改革**：1787 年拉瓦節與同行推出系統命名法（氧化汞、硫酸、碳酸鈉……），取代煉金術的模糊術語，今天的化學命名仍沿用其精神。

悲劇的尾聲：拉瓦節身兼稅務總局股東，在法國大革命中被視為舊體制的象徵。1794 年 5 月 8 日，他與其他 27 名稅務官員一起被送上斷頭台。數學家拉格朗日痛惜地說：「砍下這顆頭顱只要一瞬間，但要再長出這樣一顆頭，一百年也不夠。」這位用天平稱量物質不滅的偵探，最終被時代的瘋狂稱量了生命——但他的方法，稱量著此後所有化學的真相。

## 證據與工具

用 Python 重現拉瓦節的密閉系統質量對帳：

```python
# 拉瓦節 1772 年錫的煅燒實驗：密閉系統質量對帳
# Sn + O2 -> SnO2（簡化為二氧化錫模型）

M_Sn  = 118.71
M_O2  = 32.00
M_SnO2 = 150.71

def calcination_mass_balance(mass_Sn, mass_air_available):
    """密閉容器煅燒：回傳 (灰渣質量, 消耗氧質量, 剩餘空氣質量)"""
    n_needed = mass_Sn / M_Sn           # 需要的氧莫耳數（1:1，簡化模型）
    m_O2_needed = n_needed * M_O2
    m_O2_used = min(m_O2_needed, mass_air_available * 0.21)  # 空氣僅含 21% 氧
    m_residue = mass_Sn + m_O2_used     # 灰渣 = 錫 + 氧
    m_air_left = mass_air_available - m_O2_used
    return m_residue, m_O2_used, m_air_left

m_Sn, m_air = 10.0, 100.0
residue, used, left = calcination_mass_balance(m_Sn, m_air)
print(f"錫 {m_Sn} g + 空氣 {m_air} g（密閉系統）")
print(f"煅燒後：灰渣 {residue:.2f} g（增重 {used:.2f} g），剩餘空氣 {left:.2f} g（減重 {used:.2f} g）")
total_before, total_after = m_Sn + m_air, residue + left
print(f"總質量對帳：前 {total_before:.2f} g = 後 {total_after:.2f} g  ✓")
```

```python
# 拉瓦節氧化汞可逆實驗：2Hg + O2 <=> 2HgO
M_Hg, M_O2, M_HgO = 200.59, 32.00, 216.59

def synthesize_HgO(mass_Hg, mass_O2):
    """汞與氧密閉加熱重新生成氧化汞，回傳 (HgO 質量, 剩餘 Hg, 剩餘 O2)"""
    n_Hg, n_O2 = mass_Hg / M_Hg, mass_O2 / M_O2
    n_product = min(n_Hg, 2 * n_O2)     # 2Hg : 1O2
    m_HgO = n_product * M_HgO
    return m_HgO, mass_Hg - n_product * M_Hg, mass_O2 - n_product * M_O2 / 2

m_HgO, hg_left, o2_left = synthesize_HgO(10.0, 1.0)
print(f"Hg 10.0 g + O2 1.0 g -> 生成 HgO {m_HgO:.2f} g，剩餘 Hg {hg_left:.2f} g、O2 {o2_left:.3f} g")
print(f"質量檢驗：{m_HgO:.2f} + {hg_left:.2f} + {o2_left:.3f} = "
      f"{m_HgO + hg_left + o2_left:.2f} g（= 原始 11.0 g）✓")

# 氧化汞中氧的百分比（拉瓦節的定量依據）
print(f"\nHgO 中氧佔 {M_O2/M_HgO*100:.2f}%，與拉瓦節的實測相符")
```
