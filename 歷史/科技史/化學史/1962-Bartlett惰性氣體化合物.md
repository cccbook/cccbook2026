# 1962 Bartlett 惰性氣體化合物

## 案發現場

自從 1890 年代 Ramsay 與 Rayleigh 發現氦、氖、氬、氪、氙這一族氣體以來，化學界就建立了一個近乎宗教式的信仰：**惰性氣體（貴氣體）不會與任何物質反應**。這個信念有理論支撐——這些元素的價殼層是填滿的 $ns^2np^6$ 組態，八隅體全滿，沒有形成化學鍵的動機。1916 年 Lewis 提出八隅體規則時，更是以惰性氣體的「穩定」作為整個理論的出發點；Pauling 的價鍵理論也同樣把它們排除在化學反應之外。

因此當 1933 年 Pauling 本人根據電離能的粗略估算，推測氙應該可以與氟反應、並促使學生嘗試混合氙與氟時，實驗全部失敗。此後三十年，無數嘗試都以失敗告終，「惰性」這個名字本身就成了判決書。教科書、教科書圖表、元素週期表上的這一族被寫成「零價、零反應」，好像它們是化學世界的旁觀者。

1962 年初，加拿大英屬哥倫比亞大學的尼爾·巴特列特（Neil Bartlett）正在研究一個與惰性氣體完全無關的課題：鉑與氟的化學。他合成了一種深紅色的神奇化合物——六氟化鉑（$\mathrm{PtF_6}$），發現它是一種「氧化性強到不可思議」的物質。一次尋常的實驗操作中，$\mathrm{PtF_6}$ 蒸氣意外接觸到空氣，竟然把玻璃容器中的氧氣給氧化了，生成紅色的固體 $[\mathrm{O_2}]^+[\mathrm{PtF_6}]^-$。

巴特列特停下來想了一個所有人都不曾想過的問題：**連氧氣都能被氧化，那電離能與氧相近的氙，是不是也能被氧化？** 這個問題即將推翻一個六十六年的信仰。

## 偵查過程

巴特列特的推理是化學史上最優雅的「類比推理」之一。他手上有兩個關鍵數據：

- 氧氣（$\mathrm{O_2}$）的第一電離能（移走一個電子所需的能量）：$I_1(\mathrm{O_2}) = 1175\ \mathrm{kJ/mol}$
- 氙（$\mathrm{Xe}$）的第一電離能：$I_1(\mathrm{Xe}) = 1170\ \mathrm{kJ/mol}$

兩者幾乎完全相同——氙甚至比氧還**稍微容易被電離**！既然 $\mathrm{PtF_6}$ 強到可以把 $\mathrm{O_2}$ 氧化成 $\mathrm{O_2^+}$，那從熱力學與氧化還原電位的角度，它沒有理由不能把氙氧化成 $\mathrm{Xe^+}$。巴特列特的形式化推理如下：

氧化還原反應的自發性由自由能變化決定。對於 $\mathrm{PtF_6}$ 氧化受體 $\mathrm{A}$ 生成離子對的反應：

$$\mathrm{A} + \mathrm{PtF_6} \rightarrow [\mathrm{A}]^+[\mathrm{PtF_6}]^-$$

其自由能可分解為：

$$\Delta G \approx I_1(\mathrm{A}) + \mathrm{EA}(\mathrm{PtF_6}) + U_{\text{晶格}}$$

其中 $I_1$ 是電離能（正值，要花費能量），$\mathrm{EA}$ 是 $\mathrm{PtF_6}$ 的電子親和能（負值，放能，$\mathrm{PtF_6}$ 的 EA 極大，約 $-700\ \mathrm{kJ/mol}$ 以上），$U_{\text{晶格}}$ 是離子對的晶格能（負值，放能）。由於 $\mathrm{PtF_6}$ 的 EA 與晶格能合計遠超過 $1175\ \mathrm{kJ/mol}$，所以它連 $\mathrm{O_2}$ 都能氧化。而 $\mathrm{Xe}$ 的 $I_1 = 1170\ \mathrm{kJ/mol}$ 與 $\mathrm{O_2}$ 相同，因此：

$$\Delta G(\mathrm{Xe}) - \Delta G(\mathrm{O_2}) \approx I_1(\mathrm{Xe}) - I_1(\mathrm{O_2}) = 1170 - 1175 = -5\ \mathrm{kJ/mol} < 0$$

氙甚至應該比氧「更容易」被氧化。巴特列特立刻在筆記本上寫下這個推論，並決定驗證。

1962 年 3 月 23 日，他把 $\mathrm{PtF_6}$ 蒸氣與氙氣在玻璃容器中混合（甚至在室溫、無催化劑的條件下），兩種氣體一接觸就**立刻反應**，生成橘黃色固體。這是化學史上第一次合成出惰性氣體化合物。巴特列特最初把它寫為 $\mathrm{Xe^+[PtF_6]^-}$，後續研究（包括他自己與 Sladky 等人）發現產物實際上是更複雜的 $[\mathrm{XeF}]^+[\mathrm{PtF_6}]^-$ 與 $[\mathrm{XeF}]^+[\mathrm{Pt_2F_{11}}]^-$ 的混合物——氙-氟鍵是真實存在的化學鍵。

同年稍後，Argonne 國家實驗室的科學家用更簡單的方法合成了四氟化氙（$\mathrm{XeF_4}$）：把氙與氟直接加熱加壓即可。1962 年因此成為「惰性氣體化學元年」：$\mathrm{XeF_2}$、$\mathrm{XeF_4}$、$\mathrm{XeF_6}$、$\mathrm{XeO_3}$、$\mathrm{XeO_4}$ 逐一問世，氙甚至能形成含 Xe–C 鍵、Xe–N 鍵的化合物。

## 結案報告

巴特列特的發現震撼了整個化學界——他在 1962 年 6 月《Nature》發表的論文只有一頁，卻終結了一個六十六年的教條。遺產包括：

1. **「惰性氣體」更名「貴氣體」**：教科書刪改了「零反應」的教條，這一族被改名為 noble gases（貴氣體）——「貴」是「不輕易反應」而非「不反應」。週期表上的教條被實驗推翻，這是科學自我修正的最佳示範。
2. **化學鍵理論的深化**：氙化物的存在迫使化學家重新思考八隅體規則的適用範圍——氙可以擴展價殼層（如 $\mathrm{XeF_6}$ 的形式上超價結構），推動了現代價鍵理論與分子軌域理論（含 3c-4e 三中心四電子鍵模型）的發展。
3. **強氧化劑化學**：$\mathrm{PtF_6}$、$\mathrm{XeF_2}$ 等成為極強的氟化劑與氧化劑，在有機氟化學與無機合成中成為重要工具；氙化合物的高密度能量特性甚至被研究用於推進劑。
4. **類比推理的範式**：巴特列特的推理方式——「比較關鍵物理量（電離能），做出跨物種的類比，再實驗驗證」——成為理論指導實驗的教科書範例，也影響了理論化學（如 [1931-Huckel分子軌域法.md](1931-Huckel分子軌域法.md) 所代表的量子化學）在無機化學中的應用。
5. **後續地外與超重元素化學**：電離能數據比較的方法，後來用於預測超重元素（如 Og）的化學性質，顯示相對論效應可能使其不像惰性氣體。

一個深紅色的意外，加上兩個數字的比較（$1175$ vs $1170\ \mathrm{kJ/mol}$），推翻了一整族元素的「死刑判決」。巴特列特證明：在化學中，沒有教條是不可動搖的——只有還沒找到合適的氧化劑。

## 證據與工具

以下用 Python 比較惰性氣體與相鄰元素的第一電離能，並以類比巴特列特的邏輯做出「氙應該能被氧化」的定量推論。

```python
import numpy as np
import matplotlib.pyplot as plt

# --- 惰性氣體與相鄰元素的第一電離能 (kJ/mol) ---
elements = ['H', 'He', 'Ne', 'Ar', 'Kr', 'Xe', 'Rn', 'O2', 'F2']
ionization = [1312, 2372, 2081, 1521, 1351, 1170, 1037, 1175, 1515]

plt.figure(figsize=(9, 5))
colors = ['#888' if e in ('H','O2','F2') else '#4C9BE8' for e in elements]
bars = plt.bar(elements, ionization, color=colors)
plt.ylabel('第一電離能 (kJ/mol)')
plt.title('惰性氣體(藍) vs 分子(灰)：電離能比較')
# 標註巴特列特的關鍵比較
plt.annotate('$I_1(O_2)=1175$', xy=(7, 1175), xytext=(6.2, 1900),
             arrowprops=dict(arrowstyle='->'))
plt.annotate('$I_1(Xe)=1170$', xy=(5, 1170), xytext=(4.2, 1600),
             arrowprops=dict(arrowstyle='->'))
plt.show()

# --- 巴特列特式推理：比較電離能 ---
dI = 1170 - 1175
print(f"ΔI = I₁(Xe) − I₁(O₂) = {dI} kJ/mol")
print("→ 氙比氧更容易被電離，PtF₆ 能氧化 O₂ 就沒有理由不能氧化 Xe")

# --- 簡化熱力學估算：氧化反應自發性 ---
# ΔG ≈ I₁(受體) + EA(PtF₆) + U(晶格能)
EA_ptf6 = -700        # PtF₆ 電子親和能(示意值, 極強電子受體)
U_lattice = -550      # 離子對晶格能(示意值)
for name, I1 in [('O₂', 1175), ('Xe', 1170)]:
    dG = I1 + EA_ptf6 + U_lattice
    print(f"{name}: ΔG ≈ {dG:+.0f} kJ/mol → "
          + ("可被氧化 ✓" if dG < 0 else "不可氧化 ✗"))

# --- 電離能隨原子序的趨勢 ---
noble = ['He', 'Ne', 'Ar', 'Kr', 'Xe', 'Rn']
Z = [2, 10, 18, 36, 54, 86]
I_noble = [2372, 2081, 1521, 1351, 1170, 1037]
print("\n電離能隨原子序增大而遞減：Xe、Rn 已低於許多活潑元素")
print("→ 「滿殼層 = 不反應」是錯誤推論，反應性由氧化還原電位決定")
```
