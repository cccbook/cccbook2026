# 1927 Heitler-London 氫分子

## 案發現場

1925–26 年，量子力學誕生：海森堡的矩陣力學、薛丁格的波動力學相繼問世。薛丁格方程精確解出了氫原子（見 [1913-Bohr原子模型.md](1913-Bohr原子模型.md)），物理學家歡欣鼓舞。但化學家在旁邊焦急地問：**那氫分子呢？** 兩個氫原子為什麼會結合成 $\mathrm{H_2}$？路易斯 1916 年說「共享一對電子」（見 [1916-Lewis共價鍵.md](1916-Lewis共價鍵.md)），化學家用了十年，但沒有人能從量子力學導出這個結論。薛丁格方程對多電子系統（連氦原子都含兩個電子）無法精確求解——電子之間的互相排斥讓方程變成不可解的多體問題。

這不是小問題，而是化學的存在的根基：**如果量子力學解釋不了化學鍵，那化學與物理之間就有一道無法跨越的鴻溝**。1927 年，兩位年輕人——德國的海特勒（Walter Heitler, 1904–1981）與倫敦（Fritz London, 1900–1954）——在蘇黎世接下這個案子，只花了幾個月，就用量子力學寫出了量子化學的第一頁。

## 偵查過程

海特勒與倫敦的靈感來自薛丁格本人在蘇黎世的演講，以及一個關鍵的物理思想：**波函數的對稱性與不可分辨性**。

**第一步：寫出近似波函數。** 對 $\mathrm{H_2}$，兩個電子分別受兩個質子吸引。最粗略的近似是：電子 1 在 A 原子、電子 2 在 B 原子，波函數為兩個氫原子波函數的乘積：

$$\psi_{(1)} = \psi_A(1)\,\psi_B(2)$$

但電子不可分辨，電子 1 也可能在 B、電子 2 在 A：

$$\psi_{(2)} = \psi_A(2)\,\psi_B(1)$$

**第二步：對稱與反對稱組合。** 電子是費米子，總波函數必須對交換反對稱。若自旋部分為反對稱（自旋單重態，兩電子自旋相反），空間部分必須對稱；反之亦然。於是有兩種組合：

$$\psi_+ = \psi_A(1)\psi_B(2) + \psi_A(2)\psi_B(1) \quad (\text{對稱，配對自旋})$$

$$\psi_- = \psi_A(1)\psi_B(2) - \psi_A(2)\psi_B(1) \quad (\text{反對稱，平行自旋})$$

**第三步：變分法求能量（破案關鍵）。** 用變分原理 $E = \frac{\langle\psi | \hat{H} | \psi\rangle}{\langle\psi|\psi\rangle}$ 計算兩種組合的能量。結果出現兩個新項：庫侖積分 $J$ 與**交換積分** $K$：

$$E_{\pm} = 2E_H + \frac{J \pm K}{1 \pm S^2}$$

其中 $S = \int \psi_A \psi_B\, d\tau$ 是重疊積分。**交換積分 $K$ 是純量子效應**——它沒有古典對應，來自兩個電子「互換位置」的干涉。計算表明：對稱態 $\psi_+$ 的 $K$ 為負、能量在核間距 $R \approx 0.87$ Å 處出現極小值，深度約 $3.14\ \mathrm{eV}$（實驗值 $4.75\ \mathrm{eV}$，定量尚不完美但定性完全正確）；反對稱態 $\psi_-$ 能量則隨 $R$ 減小而飆升——兩電子自旋平行時互相排斥，不能成鍵。

**結論石破天驚：共價鍵的本質是自旋配對引發的交換效應。** 兩個電子自旋相反（成對）時，波函數空間部分對稱、電子密度在兩核之間堆積，把兩個質子「黏」在一起；自旋平行時電子密度在兩核間被排空，無鍵形成。路易斯的「共享電子對」得到了量子力學的完整解釋——而且解釋了為什麼必須「成對」。

## 結案報告

1927 年 4 月，Heitler 與 London 的論文《原子與分子的量子力學相互作用》（*Wechselwirkung ferner Atome im quantenmechanischen Prinzip*）發表，這一天被公認為**量子化學誕生日**。遺產包括：

1. **價鍵理論（VB）**：Heitler-London 的電子對方法被 Pauling 發展成價鍵理論，雜化軌域、電負度相繼登場（見 [1931-Pauling價鍵理論.md](1931-Pauling價鍵理論.md)）。
2. **分子軌道理論（MO）**：Hund 與 Mulliken 把同樣的思路推廣成「電子在整個分子中離域」的分子軌道理論，最終成為計算化學的主流（見 [1964-密度泛函理論.md](1964-密度泛函理論.md)）。
3. **化學與物理的統一**：化學鍵從「神祕親和力」變成可以計算的量子力學問題，化學正式成為「應用量子力學」。
4. **泡利原理的化學意義**：自旋配對、電子對成鍵，全部源自泡利不相容原理——費米子的不可分辨性決定了化學世界的樣貌。

## 證據與工具

```python
# 用 Heitler-London 的對稱/反對稱波函數概念計算 H2 能量曲線（簡化模型）
import numpy as np
import matplotlib.pyplot as plt

# 簡化變分模型：E± = 2E_H + (J ± K)/(1 ± S²)
# 用 Slater 型 1s 軌域 ψ = (ζ³/π)^(1/2) e^(-ζr)（原子單位），ζ=1.24（最佳化值）
zeta = 1.24
E_H = -0.5 * zeta**2        # 氫原子能量（原子單位）

def overlap(R):
    """兩個 1s 軌域的重疊積分 S"""
    Rz = zeta * R
    return np.exp(-Rz) * (1 + Rz + Rz**2/3)

def J_int(R):
    """庫侖積分（含核吸引與排斥的近似式）"""
    Rz = zeta * R
    return np.exp(-2*Rz) * (1 + 1/R) - zeta * np.exp(-Rz) * (1 + Rz)

def K_int(R):
    """交換積分（近似式）"""
    Rz = zeta * R
    return -zeta * np.exp(-Rz) * (1 + Rz) + np.exp(-2*Rz) * (2.625 - 1/R)

R = np.linspace(0.5, 6, 300)
S = overlap(R)
E_plus  = 2*E_H + (J_int(R) + K_int(R)) / (1 + S**2)    # 對稱態（成鍵）
E_minus = 2*E_H + (J_int(R) - K_int(R)) / (1 - S**2)    # 反對稱態（反鍵）

plt.plot(R, E_plus, label=r"對稱態 $\psi_+$（成鍵，自旋配對）")
plt.plot(R, E_minus, "--", label=r"反對稱態 $\psi_-$（反鍵）")
plt.axhline(2*E_H, color="gray", ls=":", label="2×氫原子能量")
plt.xlabel("核間距 R (a₀)"); plt.ylabel("能量 (Hartree)")
plt.title("Heitler-London：H₂ 的成鍵與反鍵能量曲線")
plt.ylim(-1.3, 0.3); plt.legend(); plt.show()

Re = R[np.argmin(E_plus)]
print(f"對稱態在 R ≈ {Re:.2f} a₀ 處有極小值 → H₂ 分子穩定")
print("→ 共價鍵本質：自旋配對引發的交換積分（純量子效應）")
```
