# 1774 Scheele 氯氣

## 案發現場

十八世紀中葉，化學界仍被「燃素說」籠罩：人們相信一切可燃物與金屬都含有一種看不見的「燃素」，燃燒就是燃素的釋放。當時礦物學家與漂白工匠都知道一個奇怪的現象：軟錳礦（二氧化錳，$\mathrm{MnO_2}$）加入鹽酸後，會冒出一種黃綠色、有強烈刺激味的氣體，它能讓染了色的布褪色，卻沒有人知道這氣體究竟是什麼。有人認為它是「脫燃素的鹽酸空氣」——也就是失去了燃素的鹽酸蒸汽。

遇到這個謎題的人，是瑞典舍勒（Karl Wilhelm Scheele, 1742–1786）。他出身貧寒，是波美拉尼亞的藥劑師學徒，一生在簡陋的藥房後室做實驗，用藥罐、曲頸瓶與自己的鼻子當儀器。他先後發現了氧、氮、氯、錳、鋇、氟、氫氟酸、氰化氫、檸檬酸、乳酸、甘油等數十種物質，卻因為貧窮與遠離學術中心，許多榮耀都被他人拿走。氯氣之謎之所以重要，是因為它牽涉兩個大問題：第一，它挑戰了燃素說對「空氣」的解釋；第二，它關係到當時歐洲紡織業最迫切的需求——如何快速又便宜地漂白布匹。誰能馴服這黃綠色的氣體，誰就掌握了漂白工業的鑰匙。

## 偵查過程

舍勒的思路是典型的「分解—比較—歸納」。他觀察到幾個關鍵事實：

1. $\mathrm{MnO_2}$ 與鹽酸共熱，產生黃綠色氣體；
2. 這氣體溶於水後，水能漂白蔬菜的顏色、能使石蕊試紙變白；
3. 這氣體與金屬作用，似乎「奪走」金屬中的燃素；
4. 加熱時鹽酸蒸汽並不會產生此氣體，必須有 $\mathrm{MnO_2}$ 參與。

由此他推理：鹽酸本身是「鹽酸＋燃素」的複合物，$\mathrm{MnO_2}$ 則扮演「吸走燃素」的角色，把燃素抽走後剩下的，就是他命名的「脫燃素鹽酸空氣」（dephlogisticated marine acid air）。用化學方程式（以今天的寫法）表示，其反應為：

$$\mathrm{MnO_2 + 4HCl \to MnCl_2 + Cl_2\uparrow + 2H_2O}$$

從現代觀點看，這是一個氧化還原反應：$\mathrm{MnO_2}$ 中的 $\mathrm{Mn}^{+4}$ 被還原為 $\mathrm{Mn}^{+2}$，而氯離子 $\mathrm{Cl^-}$ 被氧化為氯氣 $\mathrm{Cl_2}$。電子轉移的半反應為：

$$\mathrm{MnO_2 + 4H^+ + 2e^- \to Mn^{2+} + 2H_2O} \qquad \mathrm{2Cl^- \to Cl_2 + 2e^-}$$

舍勒的實驗數據完全正確，但他被燃素說的框架困住了：他把一個「元素」解釋成「鹽酸減去燃素」，方向剛好相反。這個本質之謎懸宕了三十六年——氯究竟是元素還是化合物？法國的貝托萊（Berthollet）認為它是鹽酸與氧的化合物；直到 1810 年，英國的戴維（Humphry Davy）用電池電解與熱分解等一連串實驗，證明無論用什麼方法都無法把氯分解成更簡單的物質，才斷言氯是**化學元素**，並命名為 chlorine（希臘文 chloros，黃綠色）。這段推理的教訓是：**數據可以正確，解釋卻可能完全錯誤——理論框架會決定你「看見」什麼。**

## 結案報告

舍勒本人並未從氯氣獲得財富。他於 1786 年死於傷寒，年僅四十三歲，據說死前幾天還在掙扎著完成實驗紀錄。但他的發現改變了世界：

- **漂白工業革命**：1785 年貝托萊發現氯水的漂白力，1789 年蘇格蘭的坦南特（Tennant）發明漂白粉（氯化石灰 $\mathrm{Ca(ClO)_2}$），使漂白從數天的日曬草灰法縮短到數小時，英國紡織業產能暴增，成為工業革命的引擎之一。
- **元素概念的鞏固**：戴維 1810 年確認氯為元素，也連帶確立了「電解是分解物質的終極手段」，間接鋪路給 [1800-Volta電池](1800-Volta電池.md) 與後來的週期律。
- **公共衛生**：氯及其衍生物後來成為自來水消毒的基礎，拯救了無數生命。

貧窮藥劑師舍勒的故事成為科學史的經典教材：他發現了氧卻被拉瓦錫搶走理論詮釋權（見 [1777-Lavoisier氧化說.md](1777-Lavoisier氧化說.md)），發現了氯卻被戴維摘走命名權。科學的榮耀往往屬於「說對故事的人」，而基礎的功勞屬於「拿到數據的人」。

## 證據與工具

以下 Python 程式碼示範：以簡單化學計量模擬舍勒的氯氣製備，並繪出氯氣產量與鹽酸用量的關係。

```python
# 舍勒氯氣製備的化學計量模擬
# 反應式: MnO2 + 4HCl -> MnCl2 + Cl2 + 2H2O
MOL_MASS = {"MnO2": 86.94, "HCl": 36.46, "Cl2": 70.90}

def chlorine_yield(mass_MnO2, mass_HCl):
    """給定 MnO2 與 HCl 的質量(克)，依限制試劑計算 Cl2 產量(克)"""
    n_MnO2 = mass_MnO2 / MOL_MASS["MnO2"]   # MnO2 莫耳數
    n_HCl  = mass_HCl  / MOL_MASS["HCl"]    # HCl 莫耳數
    n_from_MnO2 = n_MnO2                    # 1 mol MnO2 -> 1 mol Cl2
    n_from_HCl  = n_HCl / 4                 # 4 mol HCl  -> 1 mol Cl2
    n_Cl2 = min(n_from_MnO2, n_from_HCl)    # 限制試劑決定產量
    limiting = "MnO2" if n_from_MnO2 < n_from_HCl else "HCl"
    return n_Cl2 * MOL_MASS["Cl2"], limiting

# 情境一：舍勒的典型實驗 — 10 克軟錳礦 + 過量鹽酸
mass, lim = chlorine_yield(10.0, 200.0)
print(f"10 g MnO2 + 200 g HCl -> {mass:.2f} g Cl2 (限制試劑: {lim})")

# 情境二：掃描不同 MnO2 用量，找出轉折點
print("\nMnO2(g)  Cl2(g)   限制試劑")
for m in range(0, 31, 5):
    y, lim = chlorine_yield(m, 30.0)  # 固定 30 g HCl
    print(f"{m:5d}    {y:6.2f}   {lim}")
```

執行後可看到：鹽酸固定時，氯氣產量隨軟錳礦用量線性上升，直到鹽酸耗盡為止——「限制試劑」的觀念，正是從舍勒這一代化學家的定量實驗中逐漸誕生的。
