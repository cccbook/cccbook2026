# -3300 青銅：第一種「設計出來」的合金

## 案發現場

約公元前 5000 年，安納托利亞與伊朗的陶工遇到一件怪事：窯裡某些帶著綠色孔雀石（malachite）的「石頭」，在高溫木炭堆裡會滲出紅色的小金屬珠——**銅**。人類第一次煉出金屬，銅器時代開始。

但喜悅很快被冷水澆熄：**純銅太軟了**。退火態純銅的布氏硬度只有約 35 HB，做把刀，切幾下就捲刃；當武器，一擊就彎。石斧都比銅刀耐用。當時的冶金師面對一個世紀之謎：

> **有沒有辦法讓金屬又硬、又能鑄出鋒利的形狀，而且鑄造溫度別那麼折磨人？**

偶然的線索出現在「髒」礦石裡：某些銅礦混有砷，煉出的銅明顯更硬（砷銅，砷青銅）。這證明「摻雜質」能改變性質——但砷有毒，砷銅脆且冶金師常被毒死。真正的解答要等到工匠學會**刻意**加入另一種金屬：錫。

約公元前 3300 年，西亞（兩河流域與安納托利亞交界地帶）出現了刻意配製的**銅錫合金——青銅**。

## 偵查過程

青銅的發明沒有留下論文，但可以用冶金化學完整重建它的「偵查邏輯」：

**線索一：熔點下降。** 純銅熔點 1085 °C，古代爐子逼近極限。加入約 10% 的錫後，合金的液相線降到 **約 1000 °C**，鑄造變得從容。用今天的 Cu–Sn 相圖回看：錫原子融入銅晶格，擾亂了原子排列，熔點隨之下降（相圖的液相線效應）。

**線索二：硬度躍升。** 這是最關鍵的「案情」。錫原子比銅原子大，嵌入銅晶格造成畸變，**位錯（dislocation）在畸變場中難以滑移**——金屬變形依賴位錯運動，堵住位錯就堵住了變形。再加上鑄造快冷形成的硬脆 $\delta$ 相（$\mathrm{Cu_{41}Sn_{11}}$ 金屬間化合物），硬度可達純銅的 **3–5 倍**。

**線索三：流動性。** 青銅熔液比銅液流動性好，能澆滿複雜陶范——這是為何青銅時代鑄出的是精緻兵器與禮器，而非粗糙銅塊。

冶煉本身的化學是兩步還原。孔雀石先分解，再被木炭還原：

$$\mathrm{Cu_2CO_3(OH)_2 \xrightarrow{\Delta} 2\,CuO + CO_2\uparrow + H_2O\uparrow}$$

$$\mathrm{2\,CuO + C \rightarrow 2\,Cu + CO_2\uparrow}$$

錫則來自錫石（cassiterite）：

$$\mathrm{SnO_2 + 2\,C \rightarrow Sn + 2\,CO_2\uparrow}$$

最後按比例熔合。這套流程用 Gibbs 相則（[1876-Gibbs化學熱力學.md](1876-Gibbs化學熱力學.md)，四千多年後才問世）才能完整描述：在凝固的合金系統中，$F = C - P + 1$（定壓簡化式），正是相圖告訴冶金師在哪個溫度、哪個成分能拿到想要的相。

**偵探式的代價：** 錫礦稀少且產地遙遠——近東的錫要從阿富汗（中亞錫礦）或遙遠的康沃爾運來。公元前 14 世紀的烏魯布倫（Uluburun）沉船載著約 10 噸銅錠與 1 噸錫錠，見證了人類第一條為「材料配方」而建的國際貿易線。**青銅不只發明了一種合金，還發明了全球化。**

## 結案報告

1. **合金設計原理誕生**：「在 A 裡加少量 B，性質大變」從此成為材料科學的第一原理——後來的黃銅（Cu–Zn）、碳鋼（Fe–C，青銅時代晚期鐵器取代青銅）、乃至鎳基高溫合金，都是同一偵探劇的重演。
2. **國家與技術壟斷**：冶鑄青銅需要礦源、貿易、專業工匠，催生了最早的「軍工複合體」與技術官僚。
3. **約前 1200 年青銅時代崩潰**：貿易網瓦解、錫源斷絕，各地轉向技術門檻更低（不需遠程錫礦）的鐵器——一種材料的供應鏈問題，改寫了文明史。
4. **硬度之謎的科學後續**：位錯理論（1930 年代）與相圖學最終解釋了青銅為何硬；今日所有結構合金的開發流程（相圖 + 位錯工程）仍是青銅工匠那套「摻雜—試煉」的科學化版本。

## 證據與工具

**還原冶煉的總反應（孔雀石路線）：**

$$\mathrm{Cu_2CO_3(OH)_2 + 2\,C \rightarrow 2\,Cu + 2\,CO_2\uparrow + H_2O\uparrow}$$

**硬度對照表**（布氏硬度 HB，約值）——合金化的威力一目了然：

| 材料 | 成分 | 硬度 (HB) | 備註 |
|------|------|-----------|------|
| 退火純銅 | Cu | 約 35 | 太軟，難做工具 |
| 加工硬化純銅 | Cu | 約 90 | 敲打可增硬，但會再變軟 |
| 砷銅 | Cu–As（1–2%） | 約 70 | 較硬，但砷毒、脆 |
| **鑄造青銅** | Cu–10% Sn | **約 110–160** | 硬、鑄造性好 |
| 熟鐵（對照） | Fe–低 C | 約 70–100 | 青銅時代後期的替代者 |
| 碳鋼（對照） | Fe–0.8% C（淬火） | 200+ | 鐵器時代的最終答案 |

**相則（Gibbs phase rule，定壓）：**

$$F = C - P + 1$$

$C$ 為組元數、$P$ 為相數、$F$ 為自由度。Cu–Sn 二元系中，這條規則畫出的相圖正是冶金師「配方→溫度→組織」的全部地圖——古代工匠用一輩子的試錯，現代冶金師用一張相圖讀完。

**結論：** 青銅的發明把材料從「撿到什麼用什麼」變成「按目標性質設計成分」——這是人類第一次對物質進行工程設計，比 Lavoisier 的定量革命早了五千年，卻 already 用上了「成分—組織—性質」的現代邏輯。
