# Lean 程式與證明 -- 教材

以淺顯的方式，搭配簡易範例與正規 TeX 數學推導，說明 Lean（依賴型別證明器／函數式程式語言）背後的理論與實作。
每一節都引用 [../](../README.md) 資料夾的歷史卷宗作為典故，讓理論與歷史並行。

Lean 的核心，是「證明」與「程式」合而為一：

- **判斷**： $\Gamma \vdash e : \alpha$ ，在上下文 $\Gamma$ 中項 $e$ 具型別 $\alpha$ 。
- **命題即型別**： $Proof(p) \simeq p$ ，證明就是住在命題型別裡的程式。
- **依賴函數**： $\Pi (x : A), B(x)$ ，值域可依賴參數，謂詞與全稱量詞的本體。
- **歸納**： $Nat = zero \mid succ(Nat)$ ，遞迴定義與歸納證明同一枚硬幣。
- **重寫**： $rw[h] : Goal[a] \to Goal[b]$ ，等式是最常用的證明變換。
- **tactic 狀態**： $Goals \xrightarrow{tactic} Goals'$ ，互動證明的每一步都是目標轉換。

## 核心概念地圖

```
                        ┌─────────────────────────────────────────┐
                        │           核心判斷                      │
                        │   Γ ⊢ e : α （項 e 住在型別 α 裡）      │
                        └───────────────────┬─────────────────────┘
                                            │
          ┌─────────────────────────────────┼─────────────────────────────────┐
          ▼                                 ▼                                 ▼
   【邏輯即規則】                    【資料即歸納】                    【自動化即程式】
   • → : intro / apply              • Nat / List / Tree              • rw / simp 重寫
   • ∧∨ : cases / constructor       • 構造子 / match                  • ring / omega 判定
   • ¬ : → False / 反證法           • 結構歸納 / 終止遞迴            • macro / elab 自寫 tactic
   • ∀∃ : Π / Σ                     • ΠΣ 即量詞本體                  • AI 錘子 / AlphaProof
```

## 學習路徑建議

1. **入門**：01.1 → 01.2 → 02.1（先跑起第一個證明，讀懂證明狀態與宇宙）。
2. **邏輯基礎**：02.2 → 02.3 → 03.1 → 03.2（命題與量詞，Gentzen 規則在 Lean 的化身）。
3. **證明基本功**：04.1 → 04.2 → 05.1（重寫、歸納、歸納型別，日常證明八成靠這三招）。
4. **理論加深**：05.2 → 06.1 → 06.2（遞迴、Curry–Howard、宇宙與公理，連回歷史卷宗的理論篇）。
