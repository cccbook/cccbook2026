# 1822 傅立葉熱傳導

> 環節標註：**理論⇒數學⇒技術**——熱傳導問題逼出傅立葉級數，百年後成為訊號處理的引擎。

## 案發現場

十九世紀初，熱是物理學最熱的題目：蒸汽機正在改造世界（見 [1769-瓦特冷凝器.md](1769-瓦特冷凝器.md)），但**熱如何在一個物體內部流動**，卻沒有人能寫出定量理論。

約瑟夫·傅立葉（Joseph Fourier, 1768–1830）在擔任法國伊澤爾省省長之餘，多年研究一個非常具體的問題：一根金屬棒一端加熱，溫度沿棒如何分佈？一塊平板一面保溫，內部溫度場如何演化？這不是玄想——它關係到炮管的冷卻、建築的保溫，是一個徹底務實的物理問題（技術需求倒逼理論的又一次上演）。

1807 年他提交論文，1822 年出版《熱的解析理論》（Théorie analytique de la chaleur），寫出了熱傳導偏微分方程：

$$\frac{\partial T}{\partial t} = \alpha \nabla^2 T$$

方程寫出來了，但要解它，傅立葉需要一個當時不存在的數學工具——於是他自己造了一個，並引爆了數學史上最著名的爭議之一。

## 偵查過程

傅立葉的破案手法，是把「熱流」這個連續問題**拆成簡單波動的疊加**。

**第一層：分離變數。** 對兩端固定的金屬棒，他猜測解可以寫成空間函數與時間函數的乘積，而空間部分恰好是正弦波 $\sin(n\pi x/L)$——每個正弦波都是方程的解，且邊界條件自動滿足。

**第二層：驚人的斷言。** 關鍵一步：任何初始溫度分佈——哪怕是一個有尖角的、完全不「圓滑」的分佈——都可以寫成**無窮多個正弦波的疊加**：

$$f(x) = \sum_{n=1}^{\infty} b_n \sin\left(\frac{n\pi x}{L}\right), \quad b_n = \frac{2}{L}\int_0^L f(x)\sin\left(\frac{n\pi x}{L}\right)dx$$

這就是**傅立葉級數**。熱方程是線性的，所以各個正弦分量各自演化、再疊加回去——難解的偏微分方程就此化為無窮多個易解的常微分方程。

**第三層：權威的反對。** 拉格朗日（Lagrange）當場質疑：函數是解析表達式，怎麼可能等於一堆正弦波之和？一個有尖角的函數，每個點的行為都不同，正弦波那麼光滑，疊加怎麼可能拼出尖角？這在當時看來近乎荒謬。這場爭議意外地有生產力：為了說清楚「什麼才算函數」「級數收斂到什麼」，數學家（狄利克雷、黎曼、柯西）被迫重新定義極限、積分與函數概念——**一個物理問題倒逼出嚴格分析**（黎曼的積分理論正是為研究傅立葉級數而生，見 [1854-黎曼幾何.md](1854-黎曼幾何.md) 的同一位作者）。而答案是：傅立葉是對的——尖角確實能被無窮多個光滑波拼出來（只是在不連續點會有約 9% 的過衝，即 Gibbs 現象）。

## 結案報告

傅立葉自己大概只預見了這個工具對熱學與數學分析的價值；他沒能預見的是，百年之後這個級數會成為**整個資訊時代的引擎**：

1. **FFT（1965，Cooley–Tukey）**——把傅立葉變換的計算量從 $O(N^2)$ 降到 $O(N\log N)$，數學配上演算法，分析從可行變成即時。
2. **JPEG 與 MP3**——圖像與聲音被拆成頻率分量，人耳眼看不敏感的高頻直接丟棄：壓縮的原理就是傅立葉。
3. **通訊調變**——Wi-Fi、4G/5G 的 OFDM 調變，把資料裝載到一束正交的正弦波上。
4. **MRI 與光譜學**——磁振造影的原始訊號本身就是空間頻率的傅立葉域，影像是逆變換「還原」出來的（見 [1953-DNA雙螺旋.md](1953-DNA雙螺旋.md) 中 X 光繞射的頻域解譜同源）。

拉格朗日質疑「荒謬」的級數，最終住進了每一台手機、相機與醫院裡的 MRI 機器。

## 促進鏈分析

- **理論⇒數學**：熱傳導方程這個物理問題逼出傅立葉級數；為替它辯護，數學被迫發明嚴格的極限、積分與函數定義（理論⇒數學的經典案例，與量子力學逼出泛函分析同構）。
- **數學⇒技術**：傅立葉分析成為訊號處理的引擎——FFT、JPEG、MP3、OFDM 通訊、MRI，數學直接物化為技術（見 [1948-夏農資訊論.md](1948-夏農資訊論.md) 的頻域基礎）。
- **技術⇒數學**：1965 年 FFT 演算法反哺計算數學——演算法複雜度成為數學研究的對象，「快速演算法」的尋找從此成為數值分析的核心課題。
- **數學⇒理論**：傅立葉級數成為解一切線性偏微分方程（波動、擴散、電磁、量子）的標準武器，是 [1865-麥克斯韋方程組.md](1865-麥克斯韋方程組.md) 與 [1926-薛丁格方程.md](1926-薛丁格方程.md) 背後的通用工具。

## 證據與工具

```python
# 重演傅立葉案件：用正弦波疊加逼近方波——拉格朗日說「不可能」，我們來驗證

import math

# --- 第一部分：目標函數——一個有尖角的方波 ---
# 方波：x in (0, pi) 時為 +1，x in (pi, 2pi) 時為 -1
def square_wave(x):
    return 1.0 if (x % (2 * math.pi)) < math.pi else -1.0

# --- 第二部分：傅立葉級數（1822 年的核心公式）---
# 方波的傅立葉級數：只含奇次諧波，係數 4/(n*pi)
# f(x) = 4/pi * [ sin(x) + sin(3x)/3 + sin(5x)/5 + ... ]
def fourier_partial_sum(x, N):
    s = 0.0
    for n in range(1, N + 1, 2):  # 只取奇數項
        s += math.sin(n * x) / n
    return 4.0 / math.pi * s

# --- 第三部分：部分和逐項逼近，觀察「尖角被拼出來」---
print("--- 部分和逼近方波（在 x = pi/2，方波值 = 1）---")
for N in [1, 3, 11, 51, 101, 999]:
    approx = fourier_partial_sum(math.pi / 2, N)
    print(f"N = {N:4d} 項：逼近值 = {approx:.6f}")
print("=> 項數越多，光滑正弦波真的疊出了方波：傅立葉是對的")

# --- 第四部分：Gibbs 現象——尖角附近的 9% 過衝 ---
print("\n--- Gibbs 現象（x = pi - 0.01，間斷點左側）---")
for N in [11, 51, 101, 999]:
    approx = fourier_partial_sum(math.pi - 0.01, N)
    overshoot = (approx - 1.0) / 1.0 * 100  # 理論極限約 8.95%
    print(f"N = {N:4d} 項：逼近值 = {approx:.4f}，過衝 = {overshoot:+.2f}%")
print("=> 無論加多少項，間斷點旁始終有約 9% 的過衝——")
print("   收斂的極限仍是『會過衝的』：19 世紀數學嚴格化的標本")

# --- 第五部分：頻譜思想——現代訊號處理的種子 ---
print("\n--- 頻譜（JPEG/MP3 壓縮的原理）---")
print("方波的傅立葉係數：1次 = 4/π ≈ 1.273（能量最大）")
for n in [1, 3, 5, 9, 101]:
    print(f"第 {n:3d} 次諧波係數 = {4.0/(n*math.pi):.5f}")
print("=> 高頻分量能量極小 → 丟棄高頻、只留低頻，即壓縮")
print("   這正是 JPEG（影像）與 MP3（聲音）每天的日常。")
```
