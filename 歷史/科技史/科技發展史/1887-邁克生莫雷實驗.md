# 1887 邁克生-莫雷實驗

## 案發現場

十九世紀末，物理學的地基上立著一根無人懷疑的柱子——**以太（ether）**。光既然是波（見 [1865-麥克斯韋方程組.md](1865-麥克斯韋方程組.md)），就必須有介質來振動；而這個介質應該瀰漫全宇宙、靜止不動，地球穿行其中，就像潛艇穿行海水。那麼，地球上應該能測出一股「以太風」——光順風走與逆風走，速度必然不同，年差至少該在 $v^2/c^2 \approx 10^{-8}$ 的量級上留下痕跡。

問題是：$10^{-8}$ 的效應，相當於測量一隻螞蟻爬過地球赤道時地球直徑的變化。誰的儀器測得出來？

答案是美國海軍學院出身的**邁克生（Albert Michelson）**。他不是理論家，而是偏埧的精密測量工匠——他一生都在造儀器，而 1881 年起他與化學家**莫雷（Edward Morley）**在克里夫蘭合力造出的，是當時人類史上最精密的光學儀器：**邁克生干涉儀**。

## 偵查過程

干涉儀的巧思在於**不比光速，比相位**。一束光被半鍍銀鏡分成兩路：一路沿地球運動方向（順逆以太風），一路垂直於它；兩路各走 11 米（往返 22 米），再會合疊加。若以太風存在，兩路的有效光速不同，抵達時相位就錯開——轉動整台儀器 90 度，兩路角色互換，干涉條紋應該**平移**。

預期位移量可以用一筆簡單的帳算出來（見「證據與工具」）：以 $v = 30\ \mathrm{km/s}$（地球公轉速度）、$c = 3\times10^8\ \mathrm{m/s}$、光波長 $\lambda \approx 500\ \mathrm{nm}$ 計算，條紋應平移約 0.4 個條紋。這個量以干涉術之精，綽綽有餘可測——儀器靈敏度達預期效應的 1/40。

為了消除震動，整台儀器浮在水銀池上；為了消除溫差，實驗室門窗封閉，莫雷甚至先在室內坐半小時才讀數。1887 年 7 月，兩人在四天內於六個時段、全天各方位反覆轉動儀器，讀了數百組數據。

結果是物理學史上最著名的**零結果**：條紋位移小於 0.01 個條紋——不到預期的四十分之一。以太風，不存在。

這個零結果像一具屍體擺上桌面，理論家們慌了。愛爾蘭物理學家**勞倫茲（FitzGerald）**與**勞倫茲（Lorentz）**先後提出補救假說：也許物體沿運動方向會**收縮** $\sqrt{1-v^2/c^2}$ 倍，恰好抵消光程差——但「為什麼會收縮」無人能答，這是打補丁，不是理論。真正的結案，要等 1905 年一個伯恩專利局的三級技術員（見 [1905-狹義相對論.md](1905-狹義相對論.md)）：愛因斯坦直接宣布光速對一切慣性觀察者不變、以太是多餘的假設——零結果不是異常，而是新物理的第一條公理的必然推論。

## 結案報告

邁克生-莫雷實驗的遺產有三層：

1. **實驗⇒理論的極致樣板**——一次精密測量的「什麼都沒測到」，推翻了兩百年的以太宇宙觀，逼出二十世紀物理的新時空觀。
2. **技術遺產**——邁克生因干涉儀獲 1907 年諾貝爾獎（美國第一位）；這台儀器的後代包括邁克生-皮斯干涉儀，以及 2015 年偵測重力波的 LIGO（見 [2015-LIGO重力波.md](2015-LIGO重力波.md)）——同樣的干涉原理，臂長從 11 米放大到 4 公里，測量精度從 $10^{-8}$ 推到 $10^{-21}$。
3. **方法論的教訓**——「零結果」不是失敗。實驗的價值不在於證實預期，而在於以受控手段把矛盾逼上桌面。

## 促進鏈分析

本篇是**技術⇒實驗⇒理論**完整鏈的經典案例，涉及九通道中的三條：

- **技術⇒實驗**：邁克生干涉儀（技術）讓原本不可能的 $v^2/c^2$ 量級測量得以進行，產出零結果（實驗）。若無干涉術，以太假說根本無法被檢驗，只能停留在哲學爭論。
- **實驗⇒理論**：零結果（實驗）先逼出勞倫茲收縮假說（半成品理論），最終逼出狹義相對論（理論）。README 九通道表中「邁克生-莫雷零結果⇒狹義相對論」即此條。
- **實驗⇒實驗**：干涉儀的方法被 LIGO 繼承——同一張設計圖，128 年後再次震動物理學。
- **反向通道（理論⇒技術）的伏筆**：相對論確立後，GPS 衛星鐘修正（見 [1995-GPS.md](1995-GPS.md)）成為這條鏈的下游物化。

## 證據與工具

```python
# 用 Python 驗證邁克生-莫雷實驗的預期條紋位移量（v^2/c^2 量級）

import math

c = 299_792_458.0        # 光速 m/s
v = 29_800.0             # 地球公轉速度 m/s
L = 11.0                 # 每臂單程長度 m（1887 年實驗）
lam = 500e-9             # 鈉黃光附近波長 m
N = 2 * L / lam          # 兩臂總條紋數

# 以太風理論下的雙程時間差（二階近似）：
# 平行臂 t_par = 2L/c * 1/(1 - v^2/c^2)；垂直臂 t_perp = 2L/c * 1/sqrt(1 - v^2/c^2)
beta2 = (v / c) ** 2
dt = (2 * L / c) * (1 / (1 - beta2) - 1 / math.sqrt(1 - beta2))
shift = 2 * c * dt / lam   # 轉動 90 度，兩臂角色互換，位移再加倍

print(f"v^2/c^2 = {beta2:.3e}")
print(f"光行單臂時間 ≈ {L/c*1e9:.1f} ns，時間差 ≈ {dt*1e17:.4f} ×10^-17 s")
print(f"預期條紋位移 = {shift:.3f} 條")
print(f"1887 年實測：|位移| < 0.01 條（儀器可辨 0.01 條）—— 零結果！")
print(f"若臂長放大到 LIGO 的 4 km 且用雷射，靈敏度倍率 = {4000/L:.0f} ×")

# 對照：若以太風效應真實存在，轉 90 度應看到約 0.4 條平移
# 零結果意謂：光速不隨方向變化 => 相對論第二公設的直接實驗前身
```
