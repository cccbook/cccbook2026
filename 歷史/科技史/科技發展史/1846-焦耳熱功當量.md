# 1846 焦耳熱功當量

## 案發現場

1840 年代的歐洲，「熱是什麼」仍是懸案。熱素說雖經 [1789-拉瓦錫定量革命.md](1789-拉瓦錫定量革命.md) 重創，卻陰魂不散：如果熱是一種流體，它應當「守恆地流動」，摩擦生熱就很難解釋（摩擦把什麼「流體」變出來了？）。倫福德伯爵 1798 年鑽炮膛的實驗已暗示熱是運動，但他只給了定性結論。要讓「熱即能量」成為物理學的基石，缺一個定量答案：**1 卡的熱，等於多少焦耳的功？** 這個數字——熱功當量——是能量守恆定律的最後一塊拼圖。

本案的「偵探」出人意料：不是學院教授，而是一位啤酒廠少爺——詹姆斯·焦耳（James Prescott Joule, 1818–1889）。他在曼徹斯特經營家傳啤酒廠，白天釀酒、夜裡在自家地下室做實驗。他的正式科學訓練幾乎為零（只短期受過道耳頓的指導），卻擁有史上罕見的**測溫精度**：他能測出千分之一度（0.001°F）的溫差——這在當時的專業實驗室都做不到。

## 偵查過程

**第一步：從啤酒廠的問題出發。** 焦耳最初關心的是實際問題：用新發明的電動機取代蒸汽機，划不划算？他測量電動機做功與發熱的關係（1841 年發表焦耳定律：$Q = I^2Rt$），發現電流產生的熱與「功」之間存在嚴格的比例。他由此產生一個大膽假設：**熱不是流體，而是運動——而且熱與功可以互相轉換，比例恆定。**

**第二步：一連串「笨拙」的實驗。** 焦耳的偵查手法是把一個簡單問題測到底。他做過：把水通過細管摩擦生熱；用槳葉攪拌水；壓縮空氣測其溫升；甚至去瀑布邊測量瀑布頂底的水溫差（計算重力勢能轉成的熱）。其中最經典的是槳葉實驗（1845–1849）：下落的重物通過細繩帶動水中的槳葉輪旋轉攪水，水溫微升。精確測量下落高度（做功）與溫升（生熱），就能算出熱功當量。

他用的器材樸實得驚人：銅製水槽、自製槳輪、校準過的溫度計。但測量結果的穩定性震驚學界：**多次實驗得到的熱功當量都在 4.15–4.24 焦耳/卡之間**——與現代值 4.186 驚人地接近。

**第三步：學界的抗拒與開爾文的轉變。** 1847 年，焦耳在英國科學促進會上宣讀結果，反應冷淡。23 歲的威廉·湯姆生（後來的開爾文勳爵）原打算發言反駁，卻在會後被焦耳攔住深談，發現這位「業餘爱好者」的數據無懈可擊。他寫道：

> 「焦耳用最令人信服的方式證明：熱與機械功之間存在嚴格的當量關係……我立刻成為他的信徒。」

開爾文的加入至關重要：他把焦耳的實驗事實與 [1824-卡諾熱機理論.md](1824-卡諾熱機理論.md) 的理論框架合流，熱力學兩大定律就此成形（第一定律：能量守恆；第二定律經 [1850-克勞修斯第二定律.md](1850-克勞修斯第二定律.md) 完成）。

## 結案報告

焦耳熱功當量是**能量守恆定律的實驗基石**。用金觀濤的框架說，本案屬於**實驗**環節，它對迴路的推動在於：

1. **熱力學第一定律落地**——能量既不能創生也不能消滅，只能轉換：整個物理學的「能量帳本」從此有了一條鐵律，摩擦、化學反應、電流全部入帳。
2. **統一力的世界觀**——熱、功、電、化學能全部統一在「能量」之下：這是繼牛頓統一天上與地上的力之後的又一次大統一。
3. **業餘實驗家的勝利**——啤酒廠地下室勝過學院實驗室：金觀濤所說「迴路的組織形式不斷升級」的另一面是，迴路的精神（受控實驗＋定量表達）可以出現在任何地方。
4. **工程回報**——熱功當量是熱機工程師的「匯率表」：能量轉換效率的計算全部以此為基準，直接支撐 [1876-奧托四衝程.md](1876-奧托四衝程.md) 等動力機械的設計。

## 證據與工具

```python
# 焦耳槳葉實驗：熱功當量的計算
# 下落重物做功 W = mgh → 攪水生熱 Q = mcΔT → 熱功當量 J = W/Q

m_weight = 20.0      # 重物質量 kg
h = 1.5              # 下落高度 m
m_water = 5.0        # 水質量 kg
c = 4186             # 水的比熱 J/(kg·K)
delta_T = 0.014      # 實測溫升 K（焦耳能測出千分之一度！）

W = m_weight * 9.8 * h               # 做功 J
Q = m_water * c * delta_T            # 生熱 J
J = W / Q                            # 熱功當量（焦耳/卡 ≈ J/cal，此處直接比值）
print(f"重物做功 W = mgh = {W:.1f} J")
print(f"攪水生熱 Q = mcΔT = {Q:.1f} J")
print(f"實測轉換效率 W/Q = {J:.3f}")
print("焦耳多次實驗得到的熱功當量約 4.15–4.24 J/cal，")
print("與現代值 4.186 J/cal 惊人接近。")

# 能量守恆：瀑布頂底的溫差（焦耳蜜月時也不忘測量！）
H = 50       # 瀑布高度 m
dT = 9.8 * H / c * 1000 / 1000  # 全部勢能轉熱時的溫差（K）
print(f"\n50 m 瀑布全部勢能轉為熱，水溫應升高約 {dT:.3f} K")
print("=> 『能量不會消失，只會換帳本』——熱力學第一定律的直觀版。")
```
