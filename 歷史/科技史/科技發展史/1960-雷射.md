# 1960 雷射

## 案發現場

1960 年 5 月 16 日，加州馬利布，休斯飛機公司實驗室。37 歲的西奧多·梅曼（Theodore Maiman, 1927–2007）——一位被公司主管認為「項目太小、恐遭撤資」的年輕工程師——用一根手指粗的合成紅寶石柱，兩端鍍銀反射膜，纏上螺旋狀閃光燈。他把閃光燈通電，紅寶石柱射出一束**紅色的相干光**——人類歷史上第一台**雷射（laser）**。

「案發現場」的理論基礎可以追溯到 1917 年：愛因斯坦在推導黑體輻射定律時，從理論上指出除了自發輻射與吸收，還必須存在第三種過程——**受激輻射（stimulated emission）**：一個光子經過激發態原子時，可以「誘導」它釋出一個**完全相同**的光子（同頻率、同相位、同方向）——光子增殖，光被放大。理論跑在前面**四十三年**，只等工程把它物化。

## 偵查過程

**線索一：愛因斯坦 1917 年的理論預言。** 受激輻射的關鍵特性：光子不是隨機生成，而是**複製**——一變二、二變四，指數增殖。這與核裂變的鏈式反應（[1938-核裂變.md](1938-核裂變.md)）同構：一個是中子增殖，一個是光子增殖。但理論上還有一道難關：熱平衡下基態原子遠多於激發態，光子只會被吸收——要放大，必須「**粒子數反轉（population inversion）**」：讓激發態原子多於基態。

**線索二：微波激射器的先聲。** 1954 年，湯斯（Charles Townes, 1915–2015）與哥倫比亞大學團隊造出「**邁射（maser）**」——用氨分子實現微波段的受激輻射放大，證明粒子數反轉可行。1958 年湯斯與蕭洛（Arthur Schawlow）發表〈光學邁射〉論文，給出光波段的設計方案：用兩面平行反射鏡構成「共振腔」，讓光子來回穿過增益介質、指數放大，一部分從半透膜端射出。理論到實驗的等待時間——從 maser 的兩年——已縮短到歷史新低。

**線索三：梅曼的工程裁決。** 蕭洛與湯斯的方案建議用氣體介質；梅曼反其道而行，選用**紅寶石**（含鉻離子的氧化鋁晶體）：他算出紅寶石的螢光量子效率高，且用高功率氙燈閃光可以瞬間打出粒子數反轉——「脈衝式」破解「連續泵浦功率不足」的難題。休斯公司高層一度要求他中止（「太小的項目」），他自費購買紅寶石與閃光燈完成實驗。第一束雷射的峰值功率約 1 千瓦——遠超當時任何光源。

**線索四：競賽與命名。** 1960 年下半年起，氦氖雷射（連續輸出）、半導體雷射（1962，直接通往 [1958-積體電路.md](1958-積體電路.md) 的平面製程）接連問世。哥倫比亞大學研究生古爾德（Gordon Gould）的專利申請因漏填「光泵浦」一詞而失敗，纏訟三十年才勝訴——科技史上最漫長的專利戰之一。名稱「laser」是縮寫：**L**ight **A**mplification by **S**timulated **E**mission of **R**adiation——與 maser 的「受激輻射微波放大」一脈相承。

## 結案報告

雷射屬於迴路的**理論→技術**合體環節——愛因斯坦 1917 年的受激輻射理論，四十三年後被完全物化。其深遠遺產：

1. **相干光成為工具**——光學從觀測（望遠鏡，[1609-伽利略望遠鏡.md](1609-伽利略望遠鏡.md)）變成製造：切割、焊接、手術、測距、讀寫光碟。
2. **資訊路的光學化**——雷射與 [1970-光纖.md](1970-光纖.md) 結合成光通訊，[1989-全球資訊網.md](1989-全球資訊網.md) 時代資訊高速公路的物理載體。
3. **理論等待時間的持續縮短**——從哥白尼 60 年、麥克斯韋 23 年、愛因斯坦（引力波）近百年，到受激輻射 43 年、maser 2 年：迴路轉速一目了然。
4. **鏈式反應的光學版**——光子增殖與中子增殖同構，顯示「理論—實驗—技術」迴路的方法論（指數增殖、臨界條件）跨領域通用。

## 證據與工具

```python
# 偵查證物一：受激輻射的光子增殖 — 鏈式反應的光學版
import math

gain_per_pass = 1.05   # 每穿過增益介質一次，光放大 5%（粒子數反轉）
passes = 100           # 共振腔內來回 100 次
I = 1.05**passes
print(f"光子增殖：增益 {gain_per_pass}，{passes} 次往返 → I = {I:.1f} 倍（指數放大）")

# 偵查證物二：粒子數反轉的波茲曼裁決 — 為什麼需要「反轉」
kT = 0.026  # 室溫熱能 (eV)
deltaE = 1.79  # 紅寶石鉻離子激發能階 (eV)
ratio_normal = math.exp(-deltaE/kT)   # 熱平衡：激發態/基態
print(f"\n熱平衡：激發態/基態 = exp(-ΔE/kT) = {ratio_normal:.1e} → 光只被吸收")
print("粒子數反轉（泵浦後）→ 比值 > 1 → 光被放大")

# 偵查證物三：雷射的單色性 — 波長與相干性
lam = 694.3  # 紅寶石雷射波長 (nm)
f = 2.998e8/(lam*1e-9)/1e14
print(f"\n紅寶石雷射：λ = {lam} nm，頻率 {f:.2f}×10^14 Hz（紅光）")
print("受激輻射 → 同頻率、同相位、同方向 → 相干光（普通光源無法比擬）")
```
