# 1905 狹義相對論

## 案發現場

1905 年，伯恩專利局。二十六歲的三級技術員愛因斯坦（Albert Einstein）在審查電磁同步專利的閒暇，寫下了〈論動體的電動力學〉。這篇後來被稱為「狹義相對論」的論文，沒有引用任何實驗數據、沒有做任何實驗——它是一場**純理論的重構**：兩條公設，推翻兩百年的牛頓時空。

這樁案件的特殊之處在於：它是九通道中「**理論⇒理論**」的極致樣板——理論不必等實驗、不必等技術，它可以踩在危機與前代理論的肩上，直接改寫物理學的憲法。

## 偵查過程

到 1905 年，物理學面臨的僵局是：**麥克斯韋方程組與牛頓力學，在伽利略變換下不相容。** 麥克斯韋預言光速 $c$ 是方程組的常數——對誰都是 $c$？但伽利略變換說：你在火車上向前跑，地面觀察者量到的速度是兩者相加。兩者只能活一個。

主流的搶救方案是保住伽利略變換：光速 $c$ 是相對於「以太」而言的。但 1887 年邁克生-莫雷實驗的零結果（見 [1887-邁克生莫雷實驗.md](1887-邁克生莫雷實驗.md)）測不到任何以太風；勞倫茲（Lorentz）與斐茲傑惹只好發明補丁——物體沿運動方向收縮 $\sqrt{1-v^2/c^2}$ 倍、時間也有「局域時」——補丁越打越多，以太卻越來越像一個從未被抓住的幽靈。

愛因斯坦的刀法截然不同：**不補，直接換地基。** 他提出兩條公設：

1. **相對性原理**：一切慣性參考系中，物理定律形式相同——不存在特殊的「以太參考系」；
2. **光速不變原理**：真空中光速對一切慣性觀察者都是 $c$，與光源運動無關。

這兩條合在一起，立刻推出：**同時性是相對的**——兩事件在甲看來同時，在乙看來可以不同時。從「同時的相對性」出發，勞倫茲變換不再是補丁，而是公理的必然推論；而時間膨脹與長度收縮，成為新時空的幾何性質：

$$\Delta t = \frac{\Delta t_0}{\sqrt{1-v^2/c^2}}, \qquad L = L_0\sqrt{1-v^2/c^2}$$

這也順手消解了邁克生-莫雷零結果：既然垂直與平行兩臂都按同一規則收縮（或說：光速本來就不變），零結果不是異常，而是**新物理的必然**——不需要以太。

理論⇒理論的鏈條在此清晰可見：愛因斯坦的重構踩在兩個肩膀上——**麥克斯韋電磁理論**（提供了光速不變的線索，光速 $c = 1/\sqrt{\mu_0\epsilon_0}$ 是方程組的結構常數）與**勞倫茲電子論**（提供了勞倫茲變換的數學形式，只是勞倫茲自己不知道它的真正意義）。愛因斯坦做的事，是把這些碎片**重構成一套自洽的時空理論**。

十年後，同一把刀繼續砍向加速度與引力，成為廣義相對論（見 [1915-廣義相對論.md](1915-廣義相對論.md)）——而那次的數學骨架是黎曼幾何（見 [1854-黎曼幾何.md](1854-黎曼幾何.md)）。

## 結案報告

狹義相對論的遺產：

1. **以太之死**——光傳播不需要介質，「絕對靜止參考系」從物理學中除名。
2. **牛頓絕對時空的終結**——時間與空間不再是獨立舞台，而是合為四維時空，且隨觀察者而變；牛頓力學成為 $v \ll c$ 時的近似。
3. **質能關係** $E = mc^2$——同一年（1905）的後續論文給出；四十年後核裂變與核反應堆（見 [1938-核裂變.md](1938-核裂變.md)、[1942-費米核反應堆.md](1942-費米核反應堆.md)）把它物化為毀滅與發電的力量。
4. **理論領先實驗的樣板**——這次是理論不等實驗、自己重構時空；但實驗很快追上：μ 子壽命、粒子加速器（見 [1932-粒子加速器.md](1932-粒子加速器.md)）、GPS 鐘修正（見 [1995-GPS.md](1995-GPS.md)）一一蓋章。

## 促進鏈分析

本篇是「**理論⇒理論**」通道的核心案例，並含反向的實驗⇒理論伏筆：

- **理論⇒理論（主鏈）**：麥克斯韋電磁理論 + 勞倫茲電子論（理論）成為狹義相對論（理論）的數學素材；狹義相對論又成為廣義相對論（1915）與量子場論的基礎工具。README 九通道表中「邁克生-莫雷的以太危機⇒狹義相對論重構時空」即此條。
- **實驗⇒理論（上游伏筆）**：邁克生-莫雷零結果（實驗）是逼出這次重構的危機來源；本篇的結案是這條通道的下游。
- **理論⇒技術（下游物化）**：時間膨脹公式成為 GPS 衛星鐘每日 38 微秒修正的設計依據——純理論在九十年後變成公共基礎設施。
- **實驗⇒實驗（驗證繼承）**：μ 子壽命實驗（1941）繼承了「檢驗時間膨脹」的方法傳統，此後每台加速器都是相對論的日常驗證。

## 證據與工具

```python
# 用 Python 驗證狹義相對論：時間膨脹與 μ 子壽命

import math

c = 299_792_458.0   # 光速 m/s

def gamma(v):
    """勞倫茲因子 γ = 1/sqrt(1 - v^2/c^2)"""
    beta2 = (v / c) ** 2
    return 1 / math.sqrt(1 - beta2)

# --- μ 子壽命：宇宙線 μ 子為何能到達地面？ ---
tau0 = 2.197e-6     # μ 子靜止壽命 s
v = 0.995 * c       # 宇宙線 μ 子典型速度
h = 10_000.0        # 產生高度 m

g = gamma(v)
tau_lab = g * tau0                    # 實驗室系壽命（時間膨脹）
dist_cl = v * tau0                    # 無相對論：最多能走多遠
dist_sr = v * tau_lab                 # 有相對論：能走多遠

print(f"γ = {g:.2f}")
print(f"μ 子靜止壽命 {tau0*1e6:.2f} μs，膨脹後 {tau_lab*1e6:.2f} μs")
print(f"無相對論最多走 {dist_cl:.0f} m（在 10 km 高處早該衰變殆盡）")
print(f"有相對論可走 {dist_sr/1000:.1f} km —— 到得了地面！")
print("實驗事實：海平面確實偵測到大量 μ 子 => 時間膨脹被蓋章")

# --- 長度收縮：μ 子眼中的地球 ---
L_mu = h / g
print(f"\nμ 子參考系中，10 km 大氣收縮為 {L_mu/1000*1000:.0f} m")
print("兩種描述等價 => 相對性原理的自洽")

# --- 加速器時代的 γ 值 ---
print("\n--- γ 值速查表 ---")
for label, vv in [("0.1c", 0.1), ("0.5c", 0.5), ("0.9c", 0.9),
                  ("0.99c", 0.99), ("0.999c", 0.999)]:
    print(f"v = {label:7s}  γ = {gamma(vv*c):8.2f}")
print("=> 速度越接近光速，γ 發散；光速是不可逾越的極限")
```
