# 1895 倫琴X光

## 案發現場

1895 年 11 月 8 日，德國維爾茨堡大學的實驗室裡，一位 50 歲的物理學家正在做陰極射線實驗。**威廉·倫琴（Wilhelm Röntgen, 1845–1923）**注意到一件怪事：一米之外、用黑紙板蓋著的螢光屏，竟在陰極射線管放電時微微發光。

案發現場的背景是：陰極射線管（真空管）是當年最熱門的實驗工具——克魯克斯管已普及到各大實驗室，全歐洲的物理學家都在研究陰極射線。**「會發光的螢光屏」這個現象，理論上任何做過放電實驗的人都有機會看到**——此前至少有數十人注意到底片變黑、螢光屏異常，卻都當成儀器故障或疏忽丟到一邊。哥白尼等了六十年、麥克斯韋等了二十三年，而這個新窗，其實已經開了十幾年——只等一個對異常夠敏感的人。

## 偵查過程

**第一步：不放過異常。** 倫琴的偵查風格是「不放過任何異常」：他立刻關閉實驗室窗簾、蓋住射線管，重複實驗——螢光屏依然發光。他很快確認：這種射線**來自陰極射線管，卻不是陰極射線本身**——它穿過黑紙板（陰極射線做不到）、穿透書本與木板、甚至能拍出抽屜裡的底片。

**第二步：七個星期的祕密偵查。** 倫琴接下來的七週，把自己關在實驗室裡，連妻子也不知情。他系統地測量這種未知射線的一切性質，並在筆記中用「X」（數學上「未知數」的符號）稱呼它——**X 光由此得名**。他的偵查結論：

1. **穿透力**：能穿透木材、厚紙、肌肉，卻被厚金屬明顯阻擋——鉛板幾乎完全不透；
2. **直線傳播**：不會被磁場或電場偏折（陰極射線是帶電粒子，會偏折）——所以 X 光不是粒子束；
3. **使螢光物質發光、使底片感光**：可見、可記錄；
4. **不反射、不折射、不干涉**：當時未測出這些波動特徵（後來 1912 年勞厄用晶體繞射才證明它是波）。

**第三步：史上第一張 X 光片。** 倫琴把妻子的手放在底片前曝光十五分鐘——沖洗出的照片上，**骨骼、戒指清晰可見**。他看著照片說：

> 「我終於看到了自己將來死後的樣子。」（戲言；他隨即意識到醫學價值。）

**第四步：極速的公布與應用。** 1895 年 12 月 28 日，倫琴發表〈一種新射線〉，附上 X 光片。1896 年 1 月，消息席捲全球報紙——**理論與應用之間的等待時間被壓縮到幾天**：1 月下旬，醫院已用 X 光定位斷骨與取出子彈；數月內 X 光機已商用化。倫琴拒絕申請專利，留下那句名言：

> 「我的發現屬於全人類。」

1901 年，第一屆諾貝爾物理學獎授予倫琴。

## 結案報告

倫琴X光是**理論儀器（真空管）開出的意外新窗**。用金觀濤的框架說，本案屬於**實驗**環節，它開啟第六幕「科學的工業化」：

1. **實驗儀器的意外回報**——真空管本來是研究陰極射線的工具（[1831-法拉第電磁感應.md](1831-法拉第電磁感應.md) 與麥克斯韋理論的實驗遺產），卻開出了無人預言的新窗：**工具改變實驗的邊界，實驗改變理論的邊界**。
2. **醫學的革命**——外科醫生第一次「看見」體內：斷骨定位、異物取出、肺結核追蹤，醫學診斷從此有眼睛。
3. **理論的裂縫**——X 光不偏折卻有穿透力，「波還是粒子」的謎題成為量子革命的引線：[1897-湯姆生電子.md](1897-湯姆生電子.md) 拆開原子，1912 年勞厄證明它是波，[1913-玻爾原子模型.md](1913-玻爾原子模型.md) 的量子世界由此開門。
4. **科學的工業化**——X 光機數月內商用化、醫院標配：理論與應用之間的等待被壓縮到幾天，這正是「科學的工業化」的速度指標。

## 證據與工具

```python
# X 光的穿透力：為何能穿透肌肉卻擋在骨頭與金屬？
# 衰減定律：I = I0 · e^(-μx)，μ 為線衰減係數

import math

def transmitted(I0, mu, x):
    return I0 * math.exp(-mu * x)

I0 = 100.0   # 初始強度
# 線衰減係數（近似，單位 cm^-1）
tissues = [("軟組織（肌肉）", 0.2), ("骨骼", 0.6), ("鉛板", 30.0)]
print("--- X 光穿透各物質 1 cm ---")
for name, mu in tissues:
    I = transmitted(I0, mu, 1.0)
    print(f"{name}: 透過 {I:.2f}%")
print("=> 肌肉幾乎全透、骨骼明顯阻擋、鉛板完全擋住：")
print("   這就是 X 光片上骨骼清晰可見的原因（密度與原子序決定 μ）。")

# 醫學應用：底片對比度
print("\n--- 為何骨骼在片子上清晰？ ---")
soft = transmitted(I0, 0.2, 5)   # 穿透 5 cm 軟組織
bone_in_soft = transmitted(I0, 0.2, 4) * transmitted(I0, 0.6, 1)  # 4 cm 肌肉 + 1 cm 骨
print(f"5 cm 肌肉：{soft:.1f}% vs 4 cm 肌肉 + 1 cm 骨：{bone_in_soft:.1f}%")
print(f"對比度差異：{soft - bone_in_soft:.1f}%——足夠讓底片顯影出骨骼輪廓。")

# 理論與應用的等待時間（倫琴案的驚人速度）
print("\n--- 等待時間帳 ---")
for name, days in [("發現（11.8）→ 論文發表（12.28）", 50),
                   ("論文 → 醫院首次應用", 30),
                   ("論文 → 全球報紙頭條", 14)]:
    print(f"{name}：約 {days} 天")
print("=> 麥克斯韋等了 23 年，倫琴只等了幾十天：科學的工業化在加速。")
```
