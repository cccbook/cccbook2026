# 1903 N 射線

## 案發現場

1895 年倫琴發現 X 光（見 [../1895-倫琴X光.md](../1895-倫琴X光.md)），榮耀歸了德國。法國科學界——曾擁有貝克勒與居禮的放射性榮光——處處想奪回「射線之王」的桂冠。

1903 年，法國 Nancy 大學的物理學家勒內·布隆洛（René Blondlot）宣稱：他發現了一種比 X 光更強的新射線，命名為「N 射線」（以 Nancy 之 N 為名）。他說這種射線能增強螢光屏的亮度、被鋁稜鏡折射、甚至從人體發射。

消息一出，法國科學院與物理界爭相跟進。兩年之內，法國人發表了**三百多篇** N 射線論文；索邦的頂尖實驗室宣布「複製成功」，甚至有人宣稱在月光下測到了 N 射線。法國科學院還頒給布隆洛二萬法郎的勒孔特獎。

謎團不在「N 射線為什麼存在」，而在「**為什麼三百多人都看得見一種不存在的東西**」。

## 偵查過程

N 射線有個致命的特徵：它**只能用人的眼睛觀察**。X 光能拍出底片、讓氣體導電、穿透血肉留下骨骼的影子——每一項都能用儀器記錄。而 N 射線的效果，全靠觀察者盯著一塊忽明忽暗的螢光屏說「變亮了」。德國、英國的實驗室照著論文逐一重做，**全部失敗**——劍橋的實驗室甚至當場回信「看不到任何效應」。

1904 年，《Nature》派美國物理學家羅伯特·伍德（Robert Wood）前往 Nancy 拜訪布隆洛。伍德在暗室裡親眼看了布隆洛示範 N 射線增亮螢光屏，然後悄悄動了手腳：

> 他**拔掉了儀器中的鋁稜鏡**。布隆洛毫無察覺，繼續對著沒有稜鏡、射線根本不可能折射的裝置，一本正經地報告「折射的亮帶在哪裡」。
>
> 伍德又把一片玻璃透鏡偷偷放進光路——玻璃會吸收 X 光，N 射線理應被擋住；布隆洛照樣宣稱「看見」N 射線通過了。

「實驗已經證明我不需要繼續做了，」伍德在報告中寫道，「這些現象純粹是**主觀的**——眼睛的錯覺。」論文發表在《Nature》上，N 射線的根基一夜之間崩塌。法國物理界隨後集體沉默；只有布隆洛本人至死仍堅信 N 射線存在，臨終前還在書房裡測量。

## 結案報告

N 射線事件是科學史上**觀察者效應／期望偏差**的經典案例：觀察者的期望會真實地改變他「看見」的東西——螢光屏的亮度本就隨疲勞、暗適應、對比而波動，一顆想看見榮耀的心，會把噪聲讀成訊號。

事件的教訓至今仍是實驗科學的鐵律：

1. **不可用單一觀察者的主觀判讀作為唯一證據**——效應必須能被儀器記錄（底片、電表、電腦），或至少能被雙盲測試確認。
2. **榮耀焦慮會形成社會性的免疫缺口**——法國科學界集體跟進，不是因為證據強，而是因為「法國也該有自己的射線」的心理期待。權威的複製報告成了假象的保護殼。
3. **外來者與異見者的價值**——德英實驗室的重複失敗早已敲響警鐘，但只有伍德親手做的那個「拔稜鏡當場測試」才讓法國人無話可說。**糾錯不需要道德，只需要一個夠簡單的對照實驗。**

N 射線死後，真正能改變世界的射線技術照樣由迴路孕育出來——雷射（[../1960-雷射.md](../1960-雷射.md)）在 1960 年誕生，走的是理論—實驗—技術的正路。

## 糾錯分析

**誰拆穿**：美國物理學家 Robert Wood（外來者、受《Nature》委託）。
**用什麼工具**：一塊被拔掉的稜鏡——即**對照實驗／控制變因**這個方法論工具。
**如何拆穿**：把儀器中理應不可或缺的關鍵元件偷偷移除，若「效應」依舊出現，證明效應不在儀器裡，而在觀察者的腦子裡。這是雙盲測試的先聲。

連回金觀濤的迴路論：N 射線案件展示的是迴路**自我糾錯的最小成本形態**——不需要新儀器、新理論，只需要嚴格執行迴路既有的檢驗程序（複製→控制變因）。假象能存活兩年，是因為三百多篇論文互相引用、構成封閉的法國學術圈；一旦加入獨立複製這個環節，謊言立即死亡。**「複製與檢驗」正是科學區別於一切信仰體系的根本機制。**

## 證據與工具

**期望偏差的數學本質：為何無儀器記錄時，人眼判讀不可靠。** N 射線不存在，螢光屏的亮度本是純隨機噪聲（效應強度為 0）。但布隆洛「想看見 N 射線」，判讀規則是不對稱的：噪聲恰好上升就記為「增亮」（N 射線效應）；下降則歸因於疲勞、暗適應——每次都有藉口。對任何長度 $n$ 的隨機序列，相鄰兩點上升的機率恰為一半：

$$P(\text{上升}) = \frac{1}{2} \;\Rightarrow\; \text{任何噪聲序列都有約一半的「增亮」段}$$

觀察者只要對「上升」敏感、對「下降」找理由，任何序列都能被讀出「效應」——30 次連續判讀中，「增亮」約出現一半的次數，於是「N 射線」被「看見」了數百次。

**對照組：伍德的雙盲測試。** 伍德的解法是把「有無稜鏡」隨機化並隱瞞觀察者：拔掉稜鏡後，「效應」依舊——證明亮度變化與稜鏡無關，純屬主觀判讀。無對照實驗時，主觀判讀的假陽性率接近 50%；這就是為什麼伍德只需拔掉一塊稜鏡，就能拆穿 300 篇論文。
