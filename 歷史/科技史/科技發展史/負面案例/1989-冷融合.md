# 1989 冷融合

## 案發現場

1989 年 3 月 23 日，美國猶他大學的化學家弗萊許曼（Martin Fleischmann）與龐斯（Stanley Pons）召開了一場載入史冊的記者發布會：他們宣稱在**桌面上的電解槽**——一支鈀電極浸泡重水（D₂O）通電電解——測得「過量熱」，並推論這是**室溫核融合**。沒有先送同行審查，沒有先發論文，先開記者會。

若真，這是比任何發明都大的能源革命：海水中的氘取之不盡，核融合在桌面上發生，世界從此不再需要石油與核電廠。猶他大學急著搶在隔壁德州農工大學之前申請專利，州議會火速撥款五百萬美元——**新聞壓力與專利競爭讓假象免於被檢驗**。發布會次日，《紐約時報》頭版、全球媒體轉播，「冷融合」一詞誕生。

## 偵查過程

謎團立刻有兩層：

**第一層：過量熱是真的嗎？** 量熱學容易有系統性誤差（重組合熱、攪拌不均、電極化學反應）。弗萊許曼與龐斯宣稱的「過量熱」大到足以熔化電極——卻沒有人被熔死、也沒有核融合應有的伴隨產物。

**第二層（關鍵）：核融合的物理證據呢？** 真正的 D-D 融合會放出中子、氚與伽瑪射線，劑量足以致命；他們宣稱有融合卻測不到足量的中子。當時就有人引用伽莫夫的庫倫位障理論（見 [../1932-粒子加速器.md](../1932-粒子加速器.md)）指出：兩個氘核要靠熱運動穿隧融合，需要太陽核心等級的能量條件；鈀晶格裡氘核的間距（約 0.9 Å）遠大於融合所需的距離，室溫下穿隧機率小到宇宙尺度都可忽略。

此後數月，全球數百個實驗室、數億美元投入重複實驗——**絕大多數系統性失敗**：沒有過量熱、沒有中子。5 月，麻省理工學院與加州理工公開宣布重複失敗；加州理工的 Lewis 當場演示鈀的吸氘化學反應就能解釋「過量熱」。物理學界的否認聲浪席捲而來，兩位化學家在美國物理學會年會上被當眾圍剿——這正是 N 射線案中 Wood 拔稜鏡（[1903-N射線.md](1903-N射線.md)）的當代翻版，只是這次的「測試」是幾百個實驗室的量熱計與中子偵測器。

## 結案報告

美國能源部兩次評估（1989、2004），結論一致：**無法確認過量熱的存在，更無法用核融合解釋**；核融合的伴隨產物（中子、氚）與宣稱的熱量相差數十億倍。冷融合被主流科學淘汰，期刊拒收，經費斷絕。少數人仍繼續研究，改名「低能量核反應（LENR）」，至今仍無可重複的決定性證據。

深遠遺產：

1. **同行審查不可繞過**——記者會先於論文，成為科學傳播史的反面教材；此後學界對「媒體先行」的重大宣稱保持高度戒心。
2. **複製實驗是科學自我糾錯的核心機制**——冷融合沒有造假者可抓（這與皮爾當人 [1912-皮爾當人.md](1912-皮爾當人.md)、Schön 案 [2002-Schon造假.md](2002-Schon造假.md) 的「造假案」不同），它是**錯誤解釋被複製失敗自然淘汰**的純粹案例。
3. **正面教材對照**：真正馴服核融合的路徑是高溫與鏈式控制——裂變反應堆（[../1942-費米核反應堆.md](../1942-費米核反應堆.md)）與加速器穿隧（[../1932-粒子加速器.md](../1932-粒子加速器.md)），迴路把資源導向了物理允許的方向。

## 糾錯分析

**誰、用什麼工具、如何拆穿**：全球數百個獨立實驗室，用**量熱計與中子偵測器**進行複製實驗，系統性失敗；理論物理學家用**伽莫夫庫倫位障計算**證明室溫 D-D 融合機率趨近於零；美國能源部兩度正式評估定案。這是科學自我糾錯最乾淨的示範：不需要抓出說謊者，**只要複製實驗做不出來，理論就死**。

**為何假象能席捲全球**：（1）誘因太大——能源革命＋專利暴利；（2）新聞壓力——記者會先於審查，媒體造勢讓質疑顯得「反進步」；（3）最初數週連猶他州議會都押注撥款，承認失敗等於政治自打耳光；（4）檢驗成本看似低（一個電解槽而已）但隱藏的系統誤差高，導致初期有幾個實驗室「看似」部分重複成功，延長了混亂。**假象的壽命與檢驗成本成正比——當複製成本夠低、全球一起做，它只活了幾個月**，這正是它比皮爾當人（四十年）短命的原因。糾錯工具（量熱學、中子物理、穿隧理論）全部來自理論—實驗—技術迴路本身。

## 證據與工具

```python
# 為什麼室溫核融合理論上不可能？
# (1) 鈀晶格的氘密度 vs 太陽核心條件
# (2) 庫倫位障下的穿隧機率（伽莫夫因子）

import math

# --- 第一部分：鈀晶格能容納的氘密度 ---
a = 3.89e-10            # 鈀 fcc 晶格常數 (m)
r_dd_lattice = a / math.sqrt(2)   # 最近鄰距離約 0.9 Å
n_lattice = 6.8e28      # 鈀原子數密度 (m^-3)，近飽和時氘密度同量級
print("--- 氘密度比較 ---")
print(f"鈀晶格氘核最近鄰距離：{r_dd_lattice*1e10:.2f} Å")
print(f"鈀中氘密度：約 {n_lattice:.1e} m^-3")

# 太陽核心：密度 ~150 g/cm^3，溫度 1.5e7 K
T_sun = 1.5e7
k_B = 1.381e-23
E_sun = k_B * T_sun
print(f"太陽核心溫度：{T_sun:.1e} K，平均動能 {E_sun*6.242e18:.2f} keV")

# --- 第二部分：庫倫位障與穿隧機率（伽莫夫因子）---
e = 1.602e-19
eps0 = 8.854e-12
hbar = 1.055e-34
m_D = 3.344e-27         # 氘核質量

def coulomb_barrier(r):
    # 兩個氘核相距 r 時的庫倫位能
    return e**2 / (4*math.pi*eps0*r)

r_lattice = 0.9e-10
V_lattice = coulomb_barrier(r_lattice)
print("\n--- 庫倫位障（見 ../1932-粒子加速器.md 的伽莫夫理論）---")
print(f"0.9 Å 處的庫倫位障：{V_lattice*6.242e18:.0f} keV")
print(f"室溫熱運動能量（kT @ 300K）：{k_B*300*6.242e18*1000:.4f} eV")
print(f"位障/室溫能量 ≈ {V_lattice/(k_B*300):.1e} 倍")

# 伽莫夫穿隧因子 exp(-2πZ1Z2 e²/(ħv))，用 WKB 近似估數量級
def gamoff_factor(T):
    # 特徵速度取 kT 對應動能
    v = math.sqrt(2*k_B*T/m_D)
    # 伽莫夫能量 G ≈ 2π * sqrt(2m / E) * (e²/4πε0) （單位簡化估計）
    G = 2*math.pi * math.sqrt(2*m_D/(k_B*T)) * (e**2/(4*math.pi*eps0*hbar))
    return math.exp(-G)

P_room = gamoff_factor(300)
P_sun  = gamoff_factor(T_sun)
print("\n--- D-D 融合穿隧機率（每對氘核每次「碰撞」）---")
print(f"室溫 300 K：約 {P_room:.0e}")
print(f"太陽核心 1.5e7 K：約 {P_sun:.0e}")

# 估算：即使鈀中每個氘核每秒振動 1e13 次，室溫下多久才融合一次？
nu = 1e13
t_one_pair = 1/(nu*P_room)
age_universe = 4.35e17   # 秒
print(f"\n即使每秒振動 {nu:.0e} 次，一對氘核平均 {t_one_pair:.1e} 秒才融合")
print(f"宇宙年齡約 {age_universe:.1e} 秒 → 比值 {t_one_pair/age_universe:.1e}")
print("結論：室溫下穿隧機率小到宇宙尺度都可忽略——")
print("冷融合若要成真，必須有繞過庫倫位障的新物理，而鈀晶格沒有提供。")
```
