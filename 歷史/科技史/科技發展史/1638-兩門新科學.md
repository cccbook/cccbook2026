# 1638 兩門新科學

## 案發現場

1638 年，荷蘭萊頓。雙目失明的伽利略·伽利雷（Galileo Galilei, 1564–1642）在軟禁中出版《兩門新科學的對話與數學證明》（Discorsi e Dimostrazioni Matematiche）——他畢生力學研究的總結，也是**近代物理學誕生的標誌**。

案發現場的知識處境：亞里士多德的運動學統治兩千年——重物下落更快（速度與重量成正比）、運動需要持續的推動力（力是速度的原因）。這些「常識」從未被系統地檢驗。同時，望遠鏡已證明天界不完美（[1609-伽利略望遠鏡.md](1609-伽利略望遠鏡.md)），天上的問題解決了，**地上的運動呢？**

謎團：**落體到底怎麼落下？拋體為什麼走那條曲線？力與運動究竟是什麼關係？**

## 偵查過程

《兩門新科學》以三人對話（薩爾維亞蒂代表伽利略、沙格列陀的開明貴族、辛普利邱的亞里士多德派）展開偵查，兩門「新科學」是：

**第一門：均勻加速運動的材料學（自由落體）**

1. **歸謬證偽**：伽利略先以邏輯反駁亞里士多德——若重物比輕物落得快，把重輕二物綁在一起，輕物應拖慢重物，則整體應比重物慢；但整體更重，又應更快——**矛盾**。因此兩物必以同速下落。**邏輯的武器被用於檢驗物理假說**。
2. **斜面實驗——受控實驗的典範**：自由落體太快（數秒即畢），無法測量。伽利略的絕妙設計是**稀釋重力**：讓青銅球沿刻槽的斜面滾下，把「落體」放慢到可計時的程度。他用水鐘（水流計量時間）與自製脈搏反覆測量，發現：

$$s \propto t^2 \quad\text{（下落距離與時間平方成正比）}$$

   不同傾角、不同質量的球，規律不變——**「控制變數、重複測量、數學表達」**，這是近代實驗方法的完整誕生。
3. **拋物線的合成**：拋體運動 = 水平等速運動 + 垂直加速運動的**疊加**，軌跡是拋物線。他用溝槽與桌面做實驗驗證——**運動的獨立性原理**第一次被明確提出。這條拋物線正是火砲彈道（[1044-火藥.md](1044-火藥.md)）與開普勒天體幾何（[1609-開普勒行星定律.md](1609-開普勒行星定律.md)）的合流。

**第二門：材料強度**

伽利略分析了樑的承重與斷裂——靜力學（[-0250-阿基米德與機械.md](-0250-阿基米德與機械.md)）的復活與工程力學的起點。

4. **慣性的萌芽**：對話中提出「斜面論證」——小球從斜面滾下再滾上另一斜面，若無摩擦將回到原高；若第二斜面放平，球將**永遠滾下去**——**運動不需要力來維持，力是改變運動的原因**。這是慣性定律的直接前身，通往牛頓第一定律（[1687-牛頓原理.md](1687-牛頓原理.md)）。

## 結案報告

《兩門新科學》是「實驗＋理論」合體的典範，近代物理學在此誕生：

1. **亞里士多德運動學的終結**：落體定律與慣性觀念摧毀了「力維持速度」「重物速落」的千年教條。愛因斯坦稱伽利略為「近代科學之父」——因為他示範了**受控實驗 + 數學表達**的完整方法。
2. **實驗方法的完整誕生**：斜面實驗具備了近代實驗的一切要素——問題定義、假說、控制變數、量測儀器、數學規律、可重複性。培根的方法論（[1620-培根新工具.md](1620-培根新工具.md)）在伽利略手中得到最佳實踐。
3. **迴路的閉合**：伽利略用自製的鐘錶與斜面（技術⚙）做實驗（實驗），得出數學定律（理論），理論又預言彈道與擺的行為、反哺工程——**理論—實驗—技術的迴圈第一次完整轉動**。牛頓接棒：把伽利略的地上力學與開普勒的天上力學統一於萬有引力（[1687-牛頓原理.md](1687-牛頓原理.md)）；惠更斯用單擺定律造出擺鐘（[1656-惠更斯擺鐘.md](1656-惠更斯擺鐘.md)）。
4. **孤行的對照**：斜面實驗的思路，其實需要的是精確計時——中國的水運儀象台（[1090-水運儀象台.md](1090-水運儀象台.md)）早已掌握擒縱技術，但沒有「用機器做實驗」的觀念；歐洲則有機械鐘（[1280-機械鐘.md](1280-機械鐘.md)）與印刷術（[1450-古騰堡印刷術.md](1450-古騰堡印刷術.md)）把這一切連成迴圈。**工具到處有，迴圈只此一家**——這就是金觀濤之問的答案。

## 證據與工具

```python
# 用 Python 驗證伽利略的兩大發現：落體定律 s ∝ t² 與拋物線軌跡

import math

# --- 第一部分：斜面實驗的數據（伽利略的手稿數據量級）---
# 傾角約 1.7°（槽長 2 m，一端墊高 6 cm），「稀釋重力」使運動變慢可測
g, L, h = 9.8, 2.0, 0.06
g_eff = g * h / L          # 沿斜面的有效加速度
print(f"斜面長 {L} m，墊高 {h} m → 有效加速度 {g_eff:.3f} m/s²（重力被稀釋 {L/h:.0f} 倍）")

print("\n時間t(s)   距離s(m)   s/t²（伽利略：此值應為常數！）")
for t in [1, 2, 3, 4, 5]:
    s = 0.5 * g_eff * t**2
    print(f"  {t}        {s:6.2f}     {s/t**2:.3f}")
print("→ s/t² 為常數：s ∝ t²，與質量無關（亞里士多德被否決）")

# --- 第二部分：拋物線軌跡（水平等速 + 垂直加速的疊加）---
v0 = 10.0       # 水平初速 m/s
print(f"\n--- 拋體軌跡（v₀ = {v0} m/s 水平）---")
print("時間t    水平x    垂直y")
for t in [0.5, 1.0, 1.5, 2.0]:
    x, y = v0*t, 0.5*g*t**2
    print(f"  {t}      {x:6.1f}   {y:6.1f}")
print("→ 軌跡 y = g·x²/(2v₀²)：標準拋物線（火砲彈道的理論）")

# --- 第三部分：慣性論證（斜面對稱性）---
# 無摩擦斜面：滾下再滾上，回到原高 → 水平面上永遠滾下去
print("\n--- 慣性論證 ---")
print("斜面A（滾下）→ 斜面B（滾上）：無摩擦時回到原高 h")
print("B 放平 → 小球永遠滾下去：運動不需要力來維持！")
print("力是『改變』運動的原因 → 牛頓第一定律的前身。")

# 驗證：等高約束 v1² = v2² + 2g·h（能量守恆的先聲）
v_top = math.sqrt(2 * g * h)
print(f"\n斜面底端速度 = √(2gh) = {v_top:.2f} m/s（與路徑形狀無關——能量守恆）")
```
