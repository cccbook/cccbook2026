# 2015 LIGO 重力波：理論⇒技術⇒實驗的百年閉合

## 案發現場

2015 年 9 月 14 日凌晨 5 點 51 分（美東時間），路易斯安那州利文斯頓與華盛頓州漢福德。兩台相距 3,000 公里的雷射干涉儀，在 7 毫秒內先後記錄到同一個信號：鏡面之間的距離發生了約 $10^{-18}$ 公尺的變化——比質子直徑還小一千倍。

信號的波形與理論預言的「雙黑洞併合」一模一樣：兩個分別為 36 與 29 個太陽質量的黑洞，以半倍光速互相繞轉、併合，釋放出 3 個太陽質量的能量——**全部以重力波的形式輻射出去**。這是人類第一次直接聽見時空本身的震動。愛因斯坦 1916 年的預言，等了九十九年，終於被實驗蓋章。

## 偵查過程

**理論先行（1916）。** 1915 年底，愛因斯坦在黎曼幾何上完成廣義相對論（[1915-廣義相對論.md](1915-廣義相對論.md)、[1854-黎曼幾何.md](1854-黎曼幾何.md)）。場方程是非線性的，但把時空在小擾動下線性化後，愛因斯坦發現：方程允許一種以光速傳播的時空漣漪——**重力波**。他一度懷疑這只是數學的座標假象（連他自己都與此糾纏了二十年），直到 1950 年代，物理學界才用「正能量攜帶」的計算確認：重力波是真實的物理實體，會攜帶能量。

理論⇒實驗的通道在此打開：預言指定了該測什麼——但測量難度是天文數字級的。

**技術的百年接力（1887→2015）。** 偵測重力波的儀器，是**邁克生干涉儀的巨大化**。1887 年，邁克生與莫雷用邁克生干涉儀測以太風，得到零結果，逼出相對論（[1887-邁克生莫雷實驗.md](1887-邁克生莫雷實驗.md)）。實驗⇒實驗的通道在此清晰可見：同一台干涉儀的原理，被繼承、放大了十萬倍——4 公里長的臂、法布里-珀羅鏡腔把光往返 300 次、相位壓縮、懸吊隔震——LIGO 的應變靈敏度達到 $10^{-21}$ 級。

**實驗蓋章（2015）。** LIGO 的設計精度來自一個理論估算：雙黑洞併合在 1 億光年外，應變約 $10^{-21}$——臂長 4 公里對應的變化約 $4 \times 10^{-18}$ 公尺。2015 年 9 月 14 日的信號，臂長變化實測約 $10^{-18}$ 公尺，波形（叫啾頻 chirp：頻率與振幅隨併合逼近而升高）與數值相對論的模板完全吻合。理論的預言被實驗蓋章——而且被兩台儀器同時蓋章，排除了本地噪聲。

## 結案報告

LIGO 三位關鍵人物（韋斯、巴里什、索恩）於 2017 年獲諾貝爾物理學獎。這樁案件是「理論⇒技術⇒實驗」百年閉合的極限案例：

1. **重力波天文學誕生**——人類獲得了一種全新的感官：不再只用光看宇宙，還能聽時空的震動。多信使天文學（重力波+電磁波聯合觀測）隨之展開。
2. **干涉儀譜系的最終形態**——邁克生（1887）→ 邁克生-莫雷 → 邁克生-皮斯 → LIGO：同一個實驗方法的繼承與放大，跨越一百三十年（實驗⇒實驗）。
3. **工程極限的典範**——$10^{-21}$ 應變的測量，要求把 4 公里臂長的變化測到千分之一質子直徑；這需要雷射（[1960-雷射.md](1960-雷射.md)）、超低噪聲電子學（[1940-雷達.md](1940-雷達.md) 孵化的微波技術）、數值相對論（超級電腦的大規模計算，[2012-深度學習革命.md](2012-深度學習革命.md) 同源的算力）。
4. **等待時間的哲學**——愛因斯坦等了九十九年：理論可以領先一百年，但只要被記錄與傳播，它就在迴路中待命。

## 促進鏈分析

- **理論⇒實驗（主通道）**：廣義相對論預言重力波（1916）⇒ LIGO 干涉儀偵測（2015）——理論預言該測什麼、理論估算決定了儀器需要的靈敏度（$10^{-21}$ 應變）。
- **實驗⇒實驗（關鍵支線）**：邁克生干涉儀（1887）⇒ 邁克生-莫雷實驗 ⇒ LIGO（2015）——干涉儀的原理與方法被繼承、放大了十萬倍。
- **理論⇒技術（支援鏈）**：受激輻射理論 ⇒ 雷射（1960）⇒ LIGO 的光源——沒有雷射就沒有干涉儀的靈敏度。
- **技術⇒實驗（支援鏈）**：雷達微波技術孵化的低噪聲電子學、真空與隔震技術 ⇒ LIGO 的可運轉性——軍事技術讓原本不可能的實驗得以進行。
- **理論⇒理論（底層骨架）**：黎曼幾何（1854）⇒ 廣義相對論（1915）⇒ 數值相對論波形模板（2005）——理論的自我促進貫穿全程，波形模板本身就是理論為實驗準備的「答案卷」。
- **實驗⇒理論（回饋）**：GW150914 的實測波形 ⇒ 強場重力理論被證實、雙黑洞系統的存在被確認——理論的預言被實驗蓋章。

本篇九通道主通道：**理論⇒技術⇒實驗**。特色：百年閉合——理論領先九十九年，靠實驗方法的繼承（邁克生干涉儀）、理論的自我促進（黎曼幾何→廣義相對論→數值相對論）與技術的多線支援（雷射、微波電子學）共同完成閉合。

## 證據與工具

```python
# 用 Python 計算：重力波應變、臂長變化，與雙黑洞併合的質能釋放
import numpy as np

c = 3.0e8        # 光速 (m/s)
M_sun = 1.989e30 # 太陽質量 (kg)

# --- 1. 應變 h = 10^-21 對應的臂長變化 ---
h = 1e-21        # LIGO 的應變靈敏度（無因次：ΔL/L）
L = 4000.0       # LIGO 臂長（公里→公尺：4 km）
dL = h * L
print("--- 應變與臂長變化 ---")
print(f"應變 h = {h}，臂長 L = {L/1000:.0f} km = {L:.0f} m")
print(f"臂長變化 ΔL = h×L = {dL:.1e} m = {dL*1e12:.2f} 皮米（pm）")
d_proton = 1.7e-15  # 質子直徑（米）
print(f"質子直徑約 {d_proton:.1e} m")
print(f"ΔL 是質子直徑的 {dL/d_proton*1000:.0f} 分之一！")
print("→ LIGO 要把 4 公里測到千分之一質子直徑的精度")

# --- 2. 雙黑洞併合的質能釋放（E = mc²）---
m1, m2 = 36 * M_sun, 29 * M_sun   # GW150914 的兩個黑洞
m_final = 62 * M_sun               # 併合後的黑洞
m_radiated = m1 + m2 - m_final     # 以重力波輻射掉的質量
E = m_radiated * c**2
print("\n--- GW150914 的質能帳本（E=mc²）---")
print(f"黑洞 1 = {36} 太陽質量，黑洞 2 = {29} 太陽質量")
print(f"併合後 = {62} 太陽質量 → 輻射掉 {m_radiated/M_sun:.0f} 太陽質量")
print(f"釋放能量 E = Δm·c² = {E:.2e} 焦耳")
# 對照：太陽全程的核融合輸出
E_sun_life = 1e44  # 太陽一生核融合總輸出約 10^44 J
print(f"太陽一生核融合輸出 ≈ {E_sun_life:.0e} J")
print(f"GW150914 釋放的能量 ≈ 太陽一生的 {E/E_sun_life:.1f} 倍")
print("→ 而且 0.2 秒內全部釋放！峰值功率超過可觀測宇宙所有恆星的總和")

# --- 3. 併合尾聲的重力波頻率（叫啾頻 chirp）---
# 頻率 ≈ 軌道頻率的 2 倍；最內穩定圓軌道頻率 ~ c³/(6^1.5 π G M)
G = 6.674e-11
M_total = m1 + m2
f_isco = c**3 / (6**1.5 * np.pi * G * M_total)
print(f"\n--- 併合前的最高頻率（ISCO）---")
print(f"總質量 = {M_total/M_sun:.0f} 太陽質量")
print(f"最內穩定圓軌道的重力波頻率 ≈ {f_isco:.0f} Hz")
print("→ 在人耳聽域（數十~數百 Hz）！這就是『聽見』黑洞併合的原因")
print(f"→ 波形從 ~35 Hz 升頻到 ~250 Hz，與數值相對論模板完全吻合")

# --- 4. 距離與信號強度（GW150914 距地球約 1.3 億光年）---
D = 1.3e9 * 9.461e15  # 1.3 億光年（米）
h_est = (G * m1 * m2) / (c**4 * D)  # 數量級估算
print(f"\n--- 距離估算 ---")
print(f"距離 1.3 億光年，理論應變量級 ≈ {h_est:.1e}")
print(f"→ 與 LIGO 靈敏度 {h} 同數量級 → 只有現在的技術測得到")
print("→ 愛因斯坦 1916 預言、2015 蓋章：理論⇒技術⇒實驗的百年閉合")
```
