# 1698 紐科門蒸汽機

## 案發現場

案發地點是英國的煤礦井底。十七世紀末，英國煤炭需求暴增，礦井越挖越深，**積水成了礦場的頭號殺手**。傳統的馬匹拉水車、鏈式水泵昂貴而低效——一個大礦場要養五十匹馬日夜拉泵，馬匹費用吞掉了利潤。

科學那邊，理論早已備好武器：托里拆利（[1643-托里拆利大氣壓.md](1643-托里拆利大氣壓.md)）證明了**大氣壓是有重量的海洋**，波以耳（[1662-波以耳定律.md](1662-波以耳定律.md)）證明了**氣體壓力與體積的定量關係**，「真空具有可怕力量」已是全歐知識分子的常識——馬德堡半球的十六匹馬就是證人。**問題只剩下一個：怎麼把「真空的力量」變成一台能日夜幹活的機器？**

解決者是英國鐵匠**托馬斯·紐科門（Thomas Newcomen, 1664–1729）**——一位達特茅斯的五金工匠，與皇家學會素無往來。但他的機器，每一寸都建立在四十年的科學案卷上。

## 偵查過程

紐科門的偵查是「科學→技術」的教科書式轉譯，他的機器原理分四步，每一步都是一條已驗證的科學定律：

1. **造真空**：把蒸汽通入汽缸，填滿活塞下的空間（利用波以耳定律中「氣體可膨脹填滿容器」的性質）；
2. **冷凝造真空**：向汽缸外壁**潑冷水**，蒸汽遇冷凝結成水——體積驟縮近一千七百倍，汽缸內瞬間形成近似真空（托里拆利與馬德堡半球證明的外界大氣壓即將發威）；
3. **大氣壓做功**：活塞上方的**大氣壓力**把活塞壓下，拉動泵桿——這就是為什麼它叫「**大氣式蒸汽機（atmospheric engine）**」；
4. **循環往復**：閥門自動切換，蒸汽再入、冷水再潑，機器日夜不歇。

1698 年第一台機器在康沃爾礦場運轉，到 1712 年斯塔福德郡的機器已能**一天二十四小時持續抽水**，一台機器頂替五十匹馬——馬匹費用驟降九成以上。礦井得以越挖越深，煤價暴跌，煤又餵養更多蒸汽機——**正反饋迴路在大工業尺度上首次點火**。

有趣的是，紐科門本人可能並未讀過《原理》（[1687-牛頓原理.md](1687-牛頓原理.md)）——但知識是經由工匠社群、酒館與師徒制滲透到他那裡的。這正是迴路制度化的另一面：科學知識一旦公共化，即使不識字的工匠也能用它造出改變世界的機器。

## 結案報告

1. **科學知識第一次驅動大工業**——真空的理論（托里拆利、波以耳）物化為日夜運轉的機器，這是「理論→技術」環節在工業尺度上的處女作。
2. **正反饋迴路點火**——蒸汽機抽水→挖更深的礦→產更多煤→餵更多蒸汽機→再挖更深的礦。工業革命的動力迴路由此起動。
3. **技術反哺理論的伏筆**——紐科門機效率極低（熱量大多浪費在每次重新加熱整個汽缸），這個缺陷將成為布萊克潛熱理論（[1761-布萊克潛熱.md](1761-布萊克潛熱.md)）與瓦特冷凝器（[1769-瓦特冷凝器.md](1769-瓦特冷凝器.md)的待破之案。**蒸汽機賺的錢，將養出下一代的實驗室。**
4. **迴路的社會擴散**——知識從學會滲入工匠社群，證明迴路一旦制度化，就能在學院之外自我複製。

## 證據與工具

```python
# 紐科門蒸汽機的「功的帳本」
P_atm = 101325.0  # 大氣壓 Pa
cyl_d = 0.5       # 汽缸直徑 m（典型紐科門機約 0.5 m）
stroke = 2.4      # 活塞行程 m
r = cyl_d / 2
A = 3.14159 * r**2

# 大氣壓做功：W = P * A * stroke
W = P_atm * A * stroke
print(f"活塞面積 = {A:.3f} m^2")
print(f"每次下行大氣壓做功 W = P*A*s = {W:,.0f} J\n")

# 馬匹對比：一台機器一天的工作量
work_per_day = W * 12  # 每分鐘一次循環，一天約 12 小時運轉
horse_power_per_day = 746 * 86400  # 一匹馬一天的功率輸出
print(f"一天做功 ≈ {work_per_day:,.0f} J")
print(f"相當於 {work_per_day/horse_power_per_day:.1f} 匹馬日夜工作")

# 蒸汽冷凝的體積驟縮（造真空的原理）
water_density, steam_density = 1000.0, 0.6  # 100°C 蒸汽 kg/m^3
shrink = water_density / steam_density
print(f"\n蒸汽凝結成水，體積驟縮約 {shrink:,.0f} 倍")
print("=> 汽缸內瞬間近似真空，大氣壓把活塞壓下")

# 熱效率：紐科門機僅約 0.5%
W_total = W * 1000
Q_in = W_total / 0.005
print(f"\n紐科門機熱效率約 0.5%：輸入 {Q_in:,.0f} J 熱量，只輸出 {W_total:,.0f} J")
print("=> 大量熱浪費在重新加熱汽缸 —— 這是留給瓦特的待破之案")
```
