# 1932 粒子加速器：高壓技術讓量子穿隧預言被實驗蓋章

## 案發現場

1932 年 4 月 14 日，劍橋卡文迪許實驗室。約翰·考克饒夫（John Cockcroft）與愛爾蘭人歐內斯特·瓦爾頓（Ernest Walton）盯著一片硫化鋅螢光屏——它被 α 粒子轟擊後會閃爍。他們用自己造的高壓倍加器，把質子加速到約 70 萬伏特的能量，打向鋰金屬靶。

螢光屏上出現了閃爍——但不是質子的閃爍。反應室裡，鋰原子核被質子擊中後分裂成兩個 α 粒子，這是人類歷史上**第一次用人工加速的粒子拆開原子核**：

$$^7\mathrm{Li} + \mathrm{p} \longrightarrow 2\,^4\mathrm{He}$$

盧瑟福實驗室主任當時感嘆：這是「用高壓電拆開原子」。但更深刻的意義在理論一側——三年前，伽莫夫已經用純理論算出了這個反應何時該發生。

## 偵查過程

**理論先行（1928）。** 喬治·伽莫夫（George Gamow）研究 α 衰變時發現怪事：α 粒子的能量遠低於經典物理認為要逃出原子核所需的能量，卻偏偏能逃出來。他用量子力學的**穿隧效應**解釋：粒子有一定的機率「穿過」經典物理認為不可逾越的位障。伽莫夫的公式給出了庫倫位障的穿透機率——它強烈依賴入射粒子能量：能量越高，穿透越容易。伽莫夫甚至預言：只要能把質子加速到幾十萬伏特，就應該能打進輕元素的核。

理論⇒實驗的通道在此打開：伽莫夫的計算不僅解釋了舊實驗，還**預言了該做什麼實驗**。

**技術造出實驗（1929–1932）。** 問題是：當時沒有儀器能產生幾十萬伏特的穩定高壓。實驗室裡的變壓器整流器大而危險。考克饒夫與瓦爾頓採用了更聰明的路線——**高壓倍加電路**：用一組電容與二極管整流器逐級充電，把幾十萬伏特的電壓「倍加」出來（這個電路本由格雷納赫發明，他們把它工程化為粒子加速電源）。加上高真空技術，粒子加速器誕生——技術⇒實驗：新工具讓原本不可能的實驗得以進行。

**實驗蓋章（1932）。** 他們先用質子轟擊鋰，測得反應產生的 α 粒子能量約 8.5 MeV（各 8.5 MeV 的總動能），與伽莫夫穿隧計算的預言能量範圍吻合。理論的預言被實驗蓋章——而且他們接著按伽莫夫的預言轟擊其他輕元素（鈹、硼等），逐一驗證。

值得一提的是：伽莫夫本人當時在哥本哈根，他與考克饒夫從未謀面；他的理論是透過論文與書信傳入卡文迪許的。知識的印刷傳播，讓理論與實驗在兩座城市之間完成了這次接力。

## 結案報告

考克饒夫-瓦爾頓實驗是「技術⇒實驗⇒理論」鏈的示範：技術（高壓倍加器）讓實驗（分裂鋰）得以進行，實驗又反過來驗證了理論（量子穿隧）。1932 年被稱為「加速器時代元年」，兩人於 1951 年獲諾貝爾物理學獎——第一個完全由加速器實驗產生的諾貝爾獎。

遺產極為深遠：

1. **加速器成為核物理與粒子物理的核心工具**——迴旋加速器（1932 勞倫斯）、同步加速器、大型強子對撞機（LHC），全部始於這台高壓倍加器（技術⇒技術：加速器自我複製升級）。
2. **量子穿隧從解釋工具變成實證事實**——今日閃存、掃描穿隧顯微鏡（[1931-電子顯微鏡.md](1931-電子顯微鏡.md) 的後裔之一）、核融合太陽能源，全部踩在穿隧效應上。
3. **核反應 Q 值成為標準計算**——本實驗測得的能量釋放，直接通往 [1938-核裂變.md](1938-核裂變.md) 與 [1942-費米核反應堆.md](1942-費米核反應堆.md) 的能量計算。
4. **「小實驗室也能做出大科學」的信心**——考克饒夫與瓦爾頓的預算極小，卻打開了整個時代。

## 促進鏈分析

- **技術⇒實驗（主通道之一）**：高壓倍加電路 + 高真空技術（1932）⇒ 考克饒夫-瓦爾頓質子分裂鋰實驗——新工具讓原本不可能的實驗得以進行。
- **理論⇒實驗（主通道之二）**：伽莫夫量子穿隧位障計算（1928）⇒ 加速器實驗——理論不僅預言「質子能量達幾十萬伏特可打進核」，還指明該轟擊哪些元素。
- **實驗⇒理論（回饋蓋章）**：α 粒子能量的實測值 ⇒ 穿隧理論與核反應 Q 值計算被證實——理論的預言被實驗蓋章。
- **技術⇒技術（後續）**：高壓倍加器 ⇒ 迴旋加速器（1932）⇒ 同步加速器 ⇒ LHC——加速器時代的自我複製與升級。
- **實驗⇒技術（遠期）**：人工核反應的成功 ⇒ 核能工業的構想（1942–）。

本篇九通道主通道：**技術⇒實驗⇒理論**。特色：技術造出實驗、實驗檢驗理論，理論的預言反過來指導實驗設計——三環在一間小實驗室裡同時扣合。

## 證據與工具

```python
# 用 Python 計算：鋰-7 + 質子反應的 Q 值，與伽莫夫位障估算
import numpy as np

# --- 1. 反應 Q 值（質量帳本）---
# 7Li + p -> 2 He-4
m_Li7 = 7.016003   # u（原子質量單位）
m_p   = 1.007276   # u
m_He4 = 4.002603   # u
u_to_MeV = 931.494  # 1 u = 931.494 MeV/c^2

Q = (m_Li7 + m_p - 2*m_He4) * u_to_MeV
print("--- 鋰-7 + 質子反應的 Q 值 ---")
print(f"質量差 = ({m_Li7} + {m_p} - 2×{m_He4}) u = "
      f"{m_Li7 + m_p - 2*m_He4:.6f} u")
print(f"Q = {Q:.2f} MeV（放熱反應）")
# 動量守恆：兩個 α 粒子反向射出，各得 Q/2 動能（質子動能小，近似）
print(f"兩個 α 粒子各得約 {Q/2:.2f} MeV（實測約 8.5 MeV，吻合！）")

# --- 2. 伽莫夫庫倫位障估算 ---
# 兩個原子核接觸時的庫倫位能：V = k·Z1·Z2·e^2 / r
k_e2 = 1.44  # MeV·fm（庫倫常數×e^2）
Z_Li, Z_p = 3, 1
r = 1.2 * (7**(1/3) + 1**(1/3))  # 核半徑之和（fm），r ≈ 1.2·A^(1/3)
V_barrier = k_e2 * Z_Li * Z_p / r
print(f"\n--- 庫倫位障（經典物理的牆）---")
print(f"核半徑之和 ≈ {r:.1f} fm")
print(f"經典位障高度 ≈ {V_barrier:.2f} MeV")
print(f"→ 經典物理：質子需 > {V_barrier:.0f} MeV 才能碰到核")

# --- 3. 穿隧：為何 0.3 MeV 就夠？---
E_proton = 0.3  # MeV（加速到約 30 萬伏特）
print(f"\n--- 量子穿隧（伽莫夫 1928）---")
print(f"實際質子能量僅 {E_proton} MeV << 位障 {V_barrier:.1f} MeV")
# 簡化的伽莫夫因子（穿透機率 ~ exp(-2π Z1 Z2 e^2 / (hbar v))）
# 用方阱位障近似：T ≈ exp(-2 G)，G ≈ (sqrt(2m(V-E))·a)/hbar
hbar_c = 197.3   # MeV·fm
m_p_MeV = 938.3
a = r  # 位障寬度近似
G = np.sqrt(2 * m_p_MeV * (V_barrier - E_proton)) * a / hbar_c
T = np.exp(-2 * G)
print(f"方阱近似穿透機率 T ≈ {T:.2e}（很小但非零！）")
print(f"→ 量子力學：只要不是零，轟夠多質子就能看到穿隧")
print(f"→ 這正是伽莫夫預言、1932 年被蓋章的理論")
```
