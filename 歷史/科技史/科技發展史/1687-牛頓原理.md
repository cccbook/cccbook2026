# 1687 牛頓原理

## 案發現場

1687 年之前，科學革命的「案卷」已經堆積了四十年：開普勒的橢圓軌道（[1609-開普勒行星定律.md](1609-開普勒行星定律.md)）、伽利略的落體與慣性（[1638-兩門新科學.md](1638-兩門新科學.md)）、惠更斯的擺與離心力（[1656-惠更斯擺鐘.md](1656-惠更斯擺鐘.md)）、波以耳的氣體定律（[1662-波以耳定律.md](1662-波以耳定律.md)）——每一件證物都指向同一個方向，卻沒有一條定律把它們**全部**扣在一起。天上是開普勒的橢圓，地上是伽利略的拋物線，兩者為何不同？天與地是否服從同一套定律？

懸案的終結者是**牛頓（Isaac Newton, 1643–1727）**。1665–66 年大瘟疫期間，他從劍橋回到家鄉伍爾斯索普，在兩年內奠定了微積分、光學分解與萬有引力的基礎——史稱「奇異年」。但真正的偵查，要到二十二年後、在好友哈雷（Edmond Halley）的催促與資助下才完成。

## 偵查過程

**第一條關鍵推理：月球是一個掉落的蘋果。** 牛頓的傳奇性洞見是：讓蘋果落地的力與拉住月球的力**是同一種力**。他用月球做檢驗：地表重力加速度 $g \approx 9.8\ \mathrm{m/s^2}$；若重力隨距離平方反比，月球軌道處（約 60 倍地球半徑）的重力應只有 $1/3600$。用離心力公式算月球每秒「落向」地球的距離，結果與預測吻合——**天地定律統一**。

**第二條：把四十年案卷全部重新偵訊。** 牛頓用他自己發明的微積分，從三大運動定律＋萬有引力出發：
- 推出開普勒橢圓定律（案卷一，1684 年哈雷親訪後三個月內完成，震驚皇家學會）；
- 推出伽利略的落體與拋物線（案卷二）；
- 推出惠更斯的離心力公式（案卷三）；
- 解釋潮汐、歲差、彗星軌道（案卷四——哈雷彗星由此得名）。

**第三條：寫成《原理》。** 1687 年，《自然哲學的數學原理》出版，哈雷自掏腰包資助印行。這本書的方法論宣言，是科學史上最著名的一句話：

> 「如果我能看得更遠，是因為我站在巨人的肩膀上。」

這不是客套——開普勒、伽利略、惠更斯的名字就寫在案卷裡。《原理》的副標題「數學原理」同樣關鍵：它宣告自然規律不僅可以被觀察、被描述，還可以被**數學化地推演**——太陽系從此成為一台可計算的機器。

## 結案報告

1. **天與地的統一**——亞里士多德「天上高貴、地上卑賤」的兩千年底盤被一舉掀翻，一個宇宙、一套定律。
2. **數學化理論的完成式**——牛頓模式「定律→數學推演→預測→實驗/觀測檢驗」成為此後一切物理學的標準作業程序。
3. **理論—實驗—技術迴路首次完整閉合**——第三幕從托里拆利（實驗）→ 惠更斯（理論→技術）→ 波以耳（實驗逼理論）→ 牛頓（理論統一），再反哺紐科門蒸汽機（[1698-紐科門蒸汽機.md](1698-紐科門蒸汽機.md)）用真空驅動大工業。皇家學會（1660）把這個迴路制度化——發表、公開驗證、院士制度，迴路不再依賴天才個體。
4. **迴路的加速證據**——哥白尼等了六十年才有實驗來審，牛頓只等了幾十年，而牛頓理論的預言（哈雷彗星回歸、海王星）在他身後被一一蓋章。

## 證據與工具

```python
import math

# 牛頓的第一條推理：月球是一個掉落的蘋果
g = 9.81          # 地表重力加速度 m/s^2
R_earth = 6371e3  # 地球半徑 m
r_moon = 384400e3 # 月球軌道半徑 m
ratio = r_moon / R_earth
print(f"月球軌道 = 地球半徑的 {ratio:.1f} 倍")

# 平方反比預測：月球處重力 = g / r^2
g_moon_pred = g / ratio**2
print(f"預測月球處重力加速度 = {g_moon_pred*1000:.4f} mm/s^2")

# 月球每秒「落向」地球的距離：a = v^2/r = 2*d/t^2 => d = a*t^2/2
T_moon = 27.32 * 86400           # 月球公轉週期 s
v = 2*math.pi*r_moon / T_moon    # 月球軌道速度
d_fall = g_moon_pred * 1**2 / 2  # 每秒下落距離
print(f"月球軌道速度 = {v:.0f} m/s")
print(f"月球每秒向地球下落 ≈ {d_fall*1000:.4f} mm（與平方反比預測吻合！）\n")

# 萬有引力：F = G*m1*m2/r^2
G = 6.674e-11
F = G * 5.972e24 * 7.348e22 / r_moon**2  # 地-月引力
print(f"地月引力 F ≈ {F:.2e} N")

# 開普勒第三定律從萬有引力推出：T^2 = 4*pi^2*r^3/(G*M)
T_calc = math.sqrt(4*math.pi**2 * r_moon**3 / (G*5.972e24))
print(f"由牛頓理論算出月球週期 = {T_calc/86400:.2f} 天（實測 27.32 天）")
```
