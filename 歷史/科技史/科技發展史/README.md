# 科技發展的歷史年表（科學史）

> 思想家金觀濤在剖析近代科學起源時提出一個核心論斷：**科學革命的本質，是「理論—實驗—技術」三者形成一個相互促進、自我完成的循環結構**。
>
> - **理論**提出有待驗證的假設（為什麼會這樣？）；
> - **實驗**以受控手段檢驗假設（到底是不是這樣？）；
> - **技術**把得到驗證的知識物化為工具（能拿來做什麼？），而新工具又反過來造出更精的儀器、開出新的實驗、逼出新的理論。
>
> 更進一步，這個結構的精髓是：**三者之中，任兩者之間都存在相互促進的通道——甚至同一類內部也會自我促進**。以 $x, y, z$ 代表理論、實驗、技術，則促進關係是完整的有向圖：$a \Rightarrow b$，其中 $a, b \in \{x, y, z\}$，共九條通道：
>
> - **理論⇒實驗**：理論預言該測什麼（麥克斯韋預言電磁波→赫茲去測）；
> - **理論⇒技術**：理論直接物化為發明（量子力學→電晶體）；
> - **理論⇒理論**：一個理論成為另一個理論的數學工具（黎曼幾何→廣義相對論）；
> - **實驗⇒理論**：異常數據逼出新理論（黑體輻射→量子假說）；
> - **實驗⇒技術**：實驗發現變成產業（赫茲實驗→無線電）；
> - **實驗⇒實驗**：一個實驗的儀器與方法被另一個實驗繼承（真空泵實驗→一切低壓實驗）；
> - **技術⇒實驗**：新工具讓原本不可能的實驗得以進行（電子顯微鏡→看到分子）；
> - **技術⇒理論**：技術需求倒逼理論更新（蒸汽機極限→熱力學）；
> - **技術⇒技術**：製造機器的機器，技術自我複製（車床→機床工業）。
>
> 還有第四個要素貫穿這張圖的每一條通道：**數學**。數學是理論的語言、實驗數據的分析工具、技術設計的計算引擎——它與三環之間同樣構成雙向促進：
>
> - **數學⇒理論**：公理化方法、幾何與微積分成為理論的骨架（歐幾里得→牛頓；黎曼幾何→廣義相對論）；
> - **數學⇒實驗**：最小平方法、誤差理論讓數據變成證據（高斯→穀神星軌道→一切數據分析）；
> - **數學⇒技術**：傅立葉分析、圖論、資訊論成為技術設計的引擎（FFT→JPEG/MRI；圖論→網路與晶片佈線）；
> - **理論⇒數學**：物理問題逼出新的數學（熱傳導逼出傅立葉級數；量子力學逼出泛函分析）；
> - **實驗⇒數學**：實際問題與異常數據催生新數學（賭局問題催生機率論；哥尼斯堡七橋催生圖論）；
> - **技術⇒數學**：計算技術反哺數學本身（納皮爾對數；電腦催生數值分析與可計算性理論）。
>
> 本書的每一篇 wiki 都會明確標註它體現了哪條通道。
>
> 古代文明有技術（青銅、火藥、水車）、有理論（亞里士多德）、也有觀測，但三者各自孤立、不成循環，所以技術只能緩慢累積，理論千年不變。近代科學之所以在十六、十七世紀的歐洲起飛，正是因為印刷術、望遠鏡、顯微鏡、真空泵、機械鐘把三個環節第一次扣成了一個**不斷加速的正反饋迴路**。
>
> 本年表即以此「循環結構」為主軸：每一幕都是這個迴路的一次升級，每一個事件都標註它主要屬於哪個環節（理論🔬→**實驗**→**技術**⚙），以及它如何推動整個迴路。
>
> 本書以「推理探案」的方式，為每個歷史事件寫一篇 wiki，包含前因後果、數學式、理論與程式。每篇檔名以年份開頭。
>
> 另有子書 **[負面案例](負面案例/README.md)**：實驗造假與錯誤理論如何讓科學瞎忙，以及迴路如何自我糾錯（N 射線、皮爾當人、Schon 造假、黃禹錫、冷融合）。

## 尾聲：循環結構的哲學

回顧九幕，可以看到「理論—實驗—技術」迴路演化的幾條規律：

1. **古代的困境不是沒有知識，而是沒有迴路**——中國有火藥與水運儀象台，希臘有阿基米德，但技術與理論互不往來，進步只能線性累積。
2. **迴路的每次升級都由新工具點火**——印刷術、望遠鏡、真空泵、電堆、電晶體、電腦：工具改變了實驗的邊界，實驗改變了理論的邊界。
3. **促進是任兩環之間的完整通道，同類內部也自我促進**——理論⇒理論（黎曼幾何餵養廣義相對論）、實驗⇒實驗（托里拆利真空實驗繼承給一切低壓實驗）、技術⇒技術（車床製造車床）：九條通道全部打通之日，就是循環無法停下之時。
4. **理論可以領先，但不能離線太久**——哥白尼等了六十年，麥克斯韋等了二十三年，廣義相對論只等了四年；等待時間的縮短本身就是迴路加速的證據。
5. **迴路的組織形式不斷升級**——個人（伽利略、列文虎克）→ 學會（皇家學會）→ 工業實驗室（愛迪生、拜耳）→ 國家計畫（曼哈頓、阿波羅）→ 全球開源網絡（WWW、深度學習）。
6. **迴路在擴散中加速**——從少數精英到億萬終端使用者，每一次「知識複製成本」的暴跌（印刷術、WWW）都讓循環的參與者數量級躍升。

金觀濤的洞見在此得到歷史驗證：**近代科學不是一堆發現的清單，而是一個自我完成的組織結構。理解了這個結構，就理解了為什麼科學革命發生在那裡、那時，以及為什麼它再也停不下來。**
