# 1911-泰勒科學管理

## 案件摘要

1911 年，Frederick Winslow Taylor 出版《科學管理原理》（The Principles of Scientific Management），把「管理」從經驗與直覺變成一門以數據、測量與標準化為基礎的科學。這樁案件的主角不是機器，而是一種「把人當機器來測量」的方法論：時間動作研究（time-and-motion study）。它引發了工人、工會與管理階層之間長達數十年的論戰，也直接催生了 1913 年福特流水線——嫌犯足跡遍布每一座現代工廠。

## 前因 -- 為什麼會有這個案子

- 19 世紀末美國工廠普遍存在「系統性磨洋工」（systematic soldiering）：工人集體放慢速度，因為計件工資制度下多做反而導致單價被砍。
- Taylor 1878 年進入米德維爾鋼鐵公司（Midvale Steel Company），從車間工人做到總工程師，親眼目睹生產效率的巨大浪費。
- 當時管理知識全靠師徒口傳，「科學」只存在於實驗室，不存在於車間。
- Taylor 相信：每項工作都存在「一個最好的方法」（one best way），可以靠測量找出來。

## 線索與推理 -- 數學式、程式、理論

### 理論一：時間研究的標準工時公式

Taylor 把一項作業分解成基本動作元素，逐一用碼錶測量，再計入寬放（rest allowance）得到標準工時：

$$T_{\text{標準}} = T_{\text{正常}} \times (1 + A)$$

其中 $T_{\text{正常}}$ 是受過訓練工人以正常速度作業的觀測時間，$A$ 是疲勞與不可避免的延遲寬放係數（通常 10%–20%）。有了標準工時，就能計算每日產量定額與差別計件工資。

### 理論二：生鐵搬運的疲勞物理

Taylor 最著名的實驗：在伯利恆鋼鐵公司（Bethlehem Steel, 1898 年起）研究生鐵搬運工。搬運 92 磅（約 42 公斤）生鐵，工人每日步行往返，他發現實際「負荷時間」只占工時的 42%：

$$t_{\text{負荷}} \le 0.42 \times T_{\text{工時}}$$

這背後是疲勞累積的生理學：肌肉作功受限於氧債（oxygen debt）累積速率，重負荷必須穿插休息。Taylor 用此公式把搬運量從每人每日 12.5 噸提升到 47 噸，並將日薪從 1.15 美元提高到 1.85 美元。

### 理論三：差別計件工資的激勵結構

Taylor 設計「差別計件率」：達到定額者以高單價 $p_1$ 計酬，未達標者以低單價 $p_2$（$p_2 < p_1$，甚至低於成本線）計酬：

$$W = \begin{cases} p_1 q & q \ge q^* \\ p_2 q & q < q^* \end{cases}$$

合理設計 $p_1, p_2$ 使偷懶的期望報酬嚴格低於全力工作的報酬，從經濟學角度消滅磨洋工的動機。

### 理論四：動作研究的後繼者

Taylor 的搭檔 Frank Gilbreth 與 Lillian Gilbreth 夫婦把動作分解到 17 個基本「動素」（therbligs，如伸手、抓取、搬運），用電影攝影機與微計時器分析砌磚作業，把砌一塊磚的動作從 18 個減到 4.5 個，產量提升近三倍。

### Python 驗證：標準工時與差別計件工資

```python
def std_time(observed, allowance=0.15):
    return observed * (1 + allowance)

def wage(q, q_star, p1, p2):
    return p1*q if q >= q_star else p2*q

# 觀測 2.0 分鐘，寬放 15%
t = std_time(2.0)
print("標準工時 =", t, "分鐘")          # 2.3
print("每日定額(480分) =", int(480/t), "件")  # 208 件

# 差別計件：定額 200，高價 0.30，低價 0.18
print("做 180 件工資 =", wage(180, 200, 0.30, 0.18))  # 32.4
print("做 210 件工資 =", wage(210, 200, 0.30, 0.18))  # 63.0
```

## 破案時刻

1911 年《科學管理原理》出版，Taylor 在書中宣稱「過去人是第一，未來系統是第一」。同年國會針對泰勒制在政府軍工廠的實施展開聽證，1915 年國會甚至立法禁止在陸軍兵工廠使用碼錶研究——爭議之大可見一斑。Taylor 於 1915 年去世，但他的方法已被 Henry Ford（1913 年流水線）與法國的 Henri Fayol（一般管理理論）吸收，成為工業工程（Industrial Engineering）學科的開端。

## 後果 -- 改變了什麼

- 生產力數據化：工時、定額、成本首次成為可測量、可比較、可改善的管理變數。
- 標準化作業（SOP）成為現代工廠與服務業的通用語言，也是後來豐田生產方式與六標準差的遠祖。
- 工業工程與作業研究（Operations Research）從此獨立成學科。
- 負面爭議：把工人簡化為「手」的觀點引發工會激烈抵制，1911 年沃特敦兵工廠罷工即因泰勒制而起。
- 人性化管理反思：Elton Mayo 的霍桑實驗（1924–1932）部分正是對泰勒制的回應，開啟了行為科學管理學派。
