# 1876 貝爾電話

## 案件摘要

1876 年 3 月 10 日，亞歷山大・格拉漢姆・貝爾（Alexander Graham Bell, 1847–1922）在波士頓的實驗室裡對著送話器說出那句著名的話：「Mr. Watson, come here, I want to see you.」隔壁房的助手湯瑪斯・華生（Thomas Watson）清楚聽見了──這是人類史上第一次用電線傳送可懂的人聲。本案要追查的是：聲音如何變成電流、又如何變回聲音？以及為什麼同一天提交專利的還有一個叫 Elisha Gray 的人？

## 前因 -- 為什麼會有這個案子

- 電報已經營運數十年（Morse 1844），但只能傳送斷續的碼，無法傳送連續的聲波。
- 和諧電報（harmonic telegraph）研究盛行：用不同頻率的音叉調變電流，試圖在一條線上傳多路電報。貝爾正是從這個思路切入──既然電流可以「帶著」頻率，為什麼不能帶著整個語音頻譜？
- 貝爾的家族背景是聲學與聾啞教育（他的母親與妻子皆失聰），他對人耳、鼓膜、共振的理解遠超一般發明家。
- 德國的 Philipp Reis（1861）曾造出「Reis 電話」，但它的接觸點設計只能勉強傳送音調、無法傳送語音──這是一樁懸案的前科紀錄。

## 線索與推理 -- 數學式、程式、理論

### 理論一：換能原理 -- 聲壓驅動的電磁感應

貝爾的關鍵洞察是模仿人耳鼓膜：一片薄鐵膜（diaphragm）隨聲波振動，改變它與電磁鐵極靴之間的氣隙，從而改變磁路的磁阻，使線圈中的磁通量隨聲音變化，依法拉第定律感應出電動勢：

$$\mathcal{E} = -\frac{d\Phi}{dt} \approx -\frac{d\Phi}{dg}\frac{dg}{dt}$$

其中氣隙 $g$ 的變化量只有微米級，但變化速率就是聲波頻率（語音約 300–3400 Hz）。接收端則反過來：變化的電流通過電磁鐵，對金屬膜產生隨時間變化的吸力：

$$F(t) = \frac{1}{2} I(t)^2 \frac{dL}{dg}$$

這是一個平方律器件──由於 $I^2$ 對正負電流都產生吸引力，膜片會被拉向一側並產生倍頻失真，但對早期的語音可懂度而言已足夠。

### 理論二：磁阻與氣隙的靈敏度

磁性回路中，氣隙的磁阻遠大於鐵心（因空氣的磁導率 $\mu_0$ 只有鐵的數千分之一）：

$$\mathcal{R}_{total} = \frac{l_{iron}}{\mu A} + \frac{g}{\mu_0 A} \approx \frac{g}{\mu_0 A} \quad (g \ll l_{iron})$$

所以膜片的微小位移 $dg$ 幾乎線性且強烈地調變整個磁阻──這解釋了為什麼氣隙式換能器如此靈敏，也解釋了為什麼 Reis 用「接觸點」而非「氣隙」的設計會失敗：金屬接觸對壓力變化是非線性且不穩定的。

### 理論三：感應線圈（變壓器的前身）

貝爾與華生在長線路實驗中使用了感應線圈（induction coil）提升送話端的電壓以克服線路電阻損耗。依變壓器原理：

$$\frac{V_2}{V_1} = \frac{N_2}{N_1}, \qquad V_{line} = I R_{line}$$

把電流變小、電壓變大，線路上的歐姆損耗 $I^2 R$ 就隨之下降。這個小技巧正是日後整個交流輸電時代的理論種子。

### 驗證小程式

```python
import numpy as np

# 平方律接收器：I(t) = cos(wt)，輸出力 F ∝ I²
t = np.linspace(0, 1, 10000)
I = np.cos(2*np.pi*440*t)          # 440 Hz 送話
F = 0.5 * I**2                      # 吸力，非負
# 倍頻失真：F = 0.25(1 + cos(2wt))，含 880 Hz 分量
spectrum = np.abs(np.fft.rfft(F - F.mean()))
peak = np.fft.rfftfreq(len(t), t[1]-t[0])[spectrum.argmax()]
print(f"主要輸出頻率 ≈ {peak:.0f} Hz（輸入的兩倍，示平方律失真）")
```

## 破案時刻

1876 年 2 月 14 日，貝爾的律師與 Gray 的律師在同一天先後向華盛頓的專利局遞件；貝爾的申請被裁定優先，同年 3 月 7 日獲頒美國專利第 174,465 號──史上最有價值的專利之一。爭議焦點在於貝爾專利中「可變電阻送話器」的構想是否來自 Gray 的水銀送話器設計（橋接電阻式），兩人用的是幾乎相同的「liquid transmitter」概念完成了 3 月 10 日的首次通話。官司纏訟多年，貝爾電話公司最終在最高法院（1888 年）守住專利，但 Gray 與其支持者的疑雲至今仍是史學辯論題。判決依據的關鍵是：貝爾有完整的連續波理論構想與實驗紀錄，而 Gray 只把它當作電報的附屬品。

## 後果 -- 改變了什麼

- 1877 年貝爾電話公司（後來的 AT&T 前身）成立，電話以驚人速度普及：到 1880 年代，美國已有數萬台電話。
- 換能器成為獨立的工程學科：碳粒送話器（carbon microphone，Edison 與 Berliner 改良）以電阻調變取代感應式，靈敏度大增，支配了整個 20 世紀的電話機。
- 感應線圈的思路長成變壓器，為交流輸電（1880–1890 年代）鋪路。
- 電話網路催生了交換技術、長途通訊工程，甚至催生了日後的貝爾實驗室──20 世紀資訊科學的搖籃（電晶體、資訊理論皆出自於此）。
