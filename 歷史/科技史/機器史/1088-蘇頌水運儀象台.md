# 1088-蘇頌水運儀象台

## 案件摘要

北宋元祐年間（1086–1092建造，1088年落成於開封），官員與天文學家蘇頌（1020–1101）率領吏部官員韓公廉等人，建造了一座高約十二米（三丈五尺餘）的巨型水力天文鐘——水運儀象台。它集渾儀（觀測）、渾象（演示）、報時機構於一身，以水輪驅動、用擒縱器（escapement）把水流切成等時脈衝，帶動精密齒輪系自動報時。這是中國機械史的巔峰之作，其擒縱機構比歐洲機械鐘的關鍵發明早了約兩百年。

## 前因 -- 為什麼會有這個案子

- 宋代天文觀測與曆法修訂是國家大事：曆法不準即「失政」，朝廷需要持續、可靠的天象記錄。
- 唐代一行禪師與梁令瓚（723年）的水運渾象已用「水輪擒縱」概念，但其機構失傳，宋代需要復原並超越。
- 蘇頌奉詔檢驗太史局的渾儀，發現舊儀器殘缺、觀測失準，於是提出建造一台「三合一」的天文鐘。
- 他找到精通算學與機械的吏部守當官韓公廉，以《九章算術》與張衡、一行的文獻為據，先製作木樣模型驗證——這是嚴謹的「先建模、後建造」流程。

## 線索與推理 -- 數學式、程式、理論

### 理論一：擒縱器——把連續水流變成等時脈衝

水運儀象台的核心是「天衡」擒縱機構：水流入恒定水位的樞輪受水壺（類似漏刻的恒水位原理，流量 $Q$ 由水位差控制），水壺注滿後重量觸發槓桿系統放開樞輪一格，樞輪轉過一壺，天關、天條、天鎖等槓桿再把它鎖住。每格轉動時間約為：

$$T = \frac{V_{壺}}{Q}$$

樞輪共三十六個受水壺，一天轉動若干周而帶動全天齒輪系。擒縱器的本質是「能量調節器」：水源提供連續功率 $P_{in} = \rho g Q h$，擒縱器把它切成脈衝，使周期 $T$ 只取決於 $V_{壺}$ 與 $Q$ 的穩定性——這正是機械鐘錶計時的普適原理，歐洲要到十三世紀末的機械鐘才獨立發展出類似機構。

### 理論二：齒輪傳動比——讓樞輪「變速」推動渾儀

天球每恒星日（約 23 小時 56 分）轉一周，而報時系統依太陽日（24 小時）運作。蘇頌以五層齒輪系把樞輪的轉動減速/變速傳到渾儀與木人報時塔。設樞輪角速度 $\omega_1$、齒數 $z_1$，輸出軸齒數 $z_2$，則：

$$\omega_2 = \omega_1 \cdot \frac{z_1}{z_2}, \qquad i = \prod_k \frac{z_{1,k}}{z_{2,k}}$$

《新儀象法要》記載了精密的齒數配置（如天輪、晝夜機輪等），使渾儀與天象同步、每日誤差極小。齒輪系的總傳動比 $i$ 是多級比值的乘積——這是機械運動學的標準結果，宋代工匠以實測校準達成。

### 理論三：恒水位漏刻——流量穩定性的流體力學

計時的準確性取決於流量 $Q$ 的穩定。依 Torricelli 定律（宋代當然以經驗掌握），小孔流量與水位差 $\Delta h$ 的關係為：

$$Q = C_d\, A\, \sqrt{2 g \Delta h}$$

若直接從大水池放水，$\Delta h$ 隨水位下降而減小，$Q$ 越來越慢。解法是多級補償水櫃（恒水位裝置）：用溢流保持供水櫃水位不變，使 $\Delta h$ 恒定、$Q$ 恒定。這是水運儀象台計時精度的物理基礎。

```python
# 驗證：恒水位 vs. 簡單漏刻的流量穩定性
import math
Cd, A, g = 0.62, 1e-4, 9.8
for dh in [0.10, 0.09, 0.08]:
    Q = Cd * A * math.sqrt(2 * g * dh)
    print(f"水位差 {dh} m：流量 {Q*1e6:.2f} cm³/s （無補償時逐漸變慢）")
print("恒水位裝置使 dh 恒定 → Q 恒定 → 計時穩定")
```

## 破案時刻

1092年，水運儀象台在開封建成運轉：晝夜機輪驅動五層木閣中的木人，按時辰、刻、更、籌自動出來擊鼓、搖鈴、敲鉦、舉牌報時；頂部渾儀以水力緩慢轉動，隨天球同步運行，觀測者透過窥管對準天體。蘇頌為整台機器撰寫了完整的技術圖紙與說明——《新儀象法要》（1094–1096成書），附星圖與每一層機構圖，留下人類中世紀最完整的機械文獻。破案時刻的驗證：台成後「 徧儀象皆自動」，朝廷視為盛事，蘇頌升官，機器運行至北宋末年。

## 後果 -- 改變了什麼

- 水運儀象台代表十一世紀世界機械工程與天文儀器的最高水準，其擒縱機構是機械計時史上的關鍵節點。
- 《新儀象法要》是罕見的完整工程文檔，使後世（含二十世紀學者如李約瑟 Needham、王振鐸的復原研究）得以重建這座巨鐘，1958年後中國與英國均製作復原模型。
- 金兵攻陷開封（1127年）後，儀象台被拆運北上而損毀，南宋屢次嘗試復原未果——象徵機械知識傳承的脆弱。
- 概念上，擒縱器 + 齒輪系 + 報時機構的三件組，正是後來歐洲機械鐘（十四世紀）與工業革命精密製造（古騰堡壓床、紐科門與瓦特蒸汽機的調速器）的同一條技術血脈。
