# 1913-福特流水線

## 案件摘要

1913 年 4 月，Henry Ford 與他的工程團隊在密西根州 Highland Park 工廠，讓一台 Model T 的底盤被鏈條拖著以固定速度在地面上移動，工人站在原地安裝零件——世界史上第一條移動式汽車組裝流水線正式啟動。這樁案件的「兇手」是一條不斷移動的輸送帶：它把造一台車的工時從 12.5 小時砍到 93 分鐘，把 Model T 的售價從 850 美元壓到 260 美元，把汽車從富豪玩具變成大眾商品。

## 前因 -- 為什麼會有這個案子

- 泰勒科學管理（1911）已證明標準化與測量能大幅提升效率，但工人在車間間走動取料仍浪費大量時間。
- Ford 早已在零件端實施「互換性生產」（interchangeable parts）與單一車型策略：Model T 只有一種黑色車身、極少變化，這是流水線的前提。
- 靈感來源之一是芝加哥屠宰場的「拆解線」（disassembly line）：豬屍掛在吊軌上移動，工人依序切割——Ford 的團隊把它反轉成「組裝線」。
- 目標明確：讓汽車價格低到「任何靠薪水過活的人」都買得起。

## 線索與推理 -- 數學式、程式、理論

### 理論一：節拍時間（Takt Time）

流水線的靈魂是節拍：若每日需求量為 $D$、每日可用工時為 $T$，則

$$\text{Takt} = \frac{T}{D}$$

Ford 的目標是年產 25 萬輛、單班每日可用工時約 480 分鐘，則節拍約

$$\frac{8 \text{ 小時}}{1000 \text{ 輛/日}} \approx 0.5 \text{ 分/輛}$$

整條線的每個工位必須在節拍內完成自己的動作，否則整線停擺——這是把泰勒的「個人標準工時」升級為「全線同步節奏」。

### 理論二：工時的指數級壓縮

Model T 底盤組裝工時的演進：1913 年 4 月約 12.5 小時（750 分鐘），1914 年 4 月降至 93 分鐘。若拆成 $n$ 個工位、每工位節拍 $c$，則

$$T_{\text{總}} \approx n \cdot c + T_{\text{瓶頸損失}}$$

拆解成 84 個工位、配合鏈條速度約 6 英呎/分鐘的移動節拍，總工時從 750 分降到 93 分，壓縮比約 8 倍。工時下降直接轉換為單位人工成本下降。

### 理論三：成本曲線與規模經濟

學習曲線（Wright's learning curve，1936 年正式提出，但現象早已被 Ford 實踐）描述累積產量加倍時單位工時以固定比例下降：

$$T_n = T_1 \cdot n^{\log_2 b}, \quad b < 1$$

Model T 售價從 1909 年的 850 美元降到 1925 年的 260 美元，年銷量從 1.8 萬輛升到 200 萬輛——產量每翻倍，成本下降約 15%–20%，這使 Ford 能在降價的同時維持利潤，靠規模取勝。

### 理論四：瓶頸理論的前身

流水線效率受限於最慢的工位：

$$\text{產出率} = \frac{1}{\max_i t_i}$$

Ford 團隊為此不斷拆解與重組工序：磁電機發電機組裝率先實驗（工時從 20 分鐘降到 5 分鐘），再逐步推廣到引擎、車軸與最終總裝——「找出瓶頸、拆解瓶頸」正是日後豐田生產方式與 Theory of Constraints 的思想源頭。

### Python 驗證：學習曲線與售價下降

```python
def unit_time(n, T1, b):
    return T1 * n ** ( __import__('math').log2(b) )

# 首件 750 分，學習率 85%
print("累積第 100 萬輛單位工時 ≈",
      round(unit_time(1_000_000, 750, 0.85), 1), "分")  # ≈ 105 分

# 售價 850 -> 260
print("降幅 =", round((1 - 260/850)*100, 1), "%")  # 69.4%
```

## 破案時刻

1913 年 4 月 1 日，Highland Park 工廠的磁電機組裝線率先以飛輪式輸送帶運轉；同年秋天，底盤總裝線以鏈條與絞盤驅動啟動，底盤沿 150 英呎長的軌道移動。1914 年 1 月，Ford 宣布「5 美元日薪」（當時業界約 2.3 美元），把工人變成消費者——流水線 + 高工資 + 低售價構成福特主義（Fordism）的鐵三角。1927 年最後一台 Model T 下線時，累計產量超過 1,500 萬輛。

## 後果 -- 改變了什麼

- 製造業全面流水線化：從汽車、家電到飛機（1940 年代 B-24 轟炸機廠），節拍時間成為工業工程的通用概念。
- 大眾消費社會誕生：汽車普及重塑了城市、道路與郊區的地貌。
- 5 美元日薪引發勞資關係革命，也埋下日後汽車工人聯合工會（UAW, 1935/1937）壯大的種子。
- 單一化生產的副作用：Model T 的「只有黑色」成為缺乏多樣性的代名詞，1920 年代末被通用汽車（GM）的多車型策略反超，Ford 被迫停產 Model T 重新設計。
- 流水線的單調重複勞動成為現代社會學批評的對象：卓別林《摩登時代》（1936）是這場批判的經典影像。
