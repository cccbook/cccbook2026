# 1902 開利空調

## 案件摘要

1902 年 7 月 17 日，25 歲的年輕工程師威利斯・開利（Willis Carrier, 1876–1950）在紐約布魯克林的 Buffalo Forge 公司畫出了一張改變世界的設計圖：為布魯克林一家印刷廠（Sackett-Wilhelms Lithographing and Publishing Company）設計一套除濕系統，解決夏季潮濕使紙張伸縮、套色印刷對位失準的問題。這套系統後來被稱為世界第一台現代空調機。本案追查：一台「除濕機」為什麼是空調的起點？濕空氣學（psychrometrics）藏著什麼數學？

## 前因 -- 為什麼會有這個案子

- 1902 年的難題是工業性的：印刷廠的紙張隨濕度吸濕膨脹，同一頁紙上多色油墨無法對位，報社印刷品大量報廢。
- 蒸汽機時代的工廠已用暖氣控制冬季溫度，但夏季的「熱+濕」無解；早期的降溫方法（冰塊、水噴淋）只降溫不控濕，甚至越噴越濕。
- 熱力學基礎已就位：飽和蒸氣壓、露點、焓濕圖的理論框架在 19 世紀末已經成形（Regnault 的蒸氣壓測量、Mollier 的焓濕圖前身）。
- 開利 1901 年畢業於康乃爾大學機械工程系，在 Buffalo Forge 負責暖氣系統設計──他對濕度的敏感度來自工程實務。

## 線索與推理 -- 數學式、程式、理論

### 理論一：濕空氣學 -- 濕度比的含水量數學

濕空氣的含水量以濕度比（humidity ratio）表示：

$$W = \frac{m_{water}}{m_{dry\ air}} = 0.622\,\frac{p_v}{p - p_v}$$

其中 $p_v$ 是水蒸氣分壓、$p$ 是大氣壓，0.622 是水與空氣分子量之比（$18/29 \approx 0.622$）。印刷紙張的平衡含水量與相對濕度直接相關──控制 $W$ 才能控制紙張尺寸，這是「除濕機」成為空調起點的工程原因：開利的第一目標從頭到尾都是濕度，溫度只是副產品。

### 理論二：露點與冷凝除濕

空氣冷卻到露點溫度 $T_{dew}$ 時，水蒸氣分壓達到飽和蒸氣壓 $p_{sat}(T_{dew})$，繼續冷卻即冷凝出水：

$$p_v = p_{sat}(T_{dew}), \qquad \text{Clausius–Clapeyron:}\ \frac{dp_{sat}}{dT} = \frac{L\, p_{sat}}{R_v T^2}$$

其中 $L \approx 2.26\times10^6\,\mathrm{J/kg}$ 是水的汽化熱，$R_v \approx 461.5\,\mathrm{J/(kg\,K)}$。開利的方案：把空氣冷卻到露點以下使水在冷卻盤管上凝結排出，再（必要時）把乾燥過的冷空氣回熱──「冷凝除濕 + 回熱」至今仍是空調除濕的基本架構。

### 理論三：焓濕圖 -- 開利的發明工具

1904–1911 年間，開利系統性地發展出焓濕圖（psychrometric chart）：以濕度比 $W$ 為縱軸、乾球溫度為橫軸，畫出等相對濕度線、等焓線、等比容線，使任何濕空氣過程（加熱、冷卻、加濕、除濕、混合）變成圖上的向量運算：

$$h = c_p T + W\,(h_{fg} + c_{pv} T)$$

其中 $h_{fg} \approx 2,501\,\mathrm{kJ/kg}$。焓濕圖是史上少數由「工程師為工程師發明的理論工具」，把 Clausius–Clapeyron 的抽象熱力學變成可以畫在圖紙上量角器的實務科學。

### 驗證小程式

```python
import math

# Clausius–Clapeyron 近似：飽和蒸氣壓 (Magnus 公式)
def p_sat(T):  # T in °C
    return 611.2*math.exp(17.62*T/(243.12+T))  # Pa

# 30°C、相對濕度 70% 的空氣，求露點
p, RH, T = 101325.0, 0.70, 30.0
pv = RH*p_sat(T)
W = 0.622*pv/(p-pv)
Tdew = 243.12*math.log(pv/611.2)/(17.62-math.log(pv/611.2))
print(f"濕度比 W = {W*1000:.1f} g/kg 乾空氣，露點 ≈ {Tdew:.1f} °C")
# 盤管需冷到露點以下才會凝水除濕
```

## 破案時刻

1902 年 7 月 17 日，開利畫出系統設計圖；同年夏天，印刷廠的除濕系統安裝完成，紙張對位問題解決。1906 年開利獲得「空氣處理裝置」（Apparatus for Treating Air）專利。1906 年 Stuart Cramer 在北卡羅萊納紡織廠的論文中創造了「air conditioning」一詞（原指加濕），開利則把這個詞變成了「溫濕皆控」的完整技術。1911 年開利在 ASME 發表《Rational Psychrometric Formulae》，奠定濕空氣學的工程標準──理論破案時刻。

## 後果 -- 改變了什麼

- 1915 年開利與同仁創立 Carrier Engineering Corporation，空調從工業製程（印刷、紡織、製藥）走向劇院（1920 年代）與建築舒適。
- 1920 年代起，有空調的電影院引領夏季娛樂革命；1939 年首輛有空調的汽車問世；戰後住宅空調普及。
- 濕空氣學成為 HVAC（暖通空調）工程的標準學科，ASHRAE 的濕空氣學表至今仍是業界聖經。
- 空調重塑了地理與社會：美國南方、新加坡、海灣國家的大城市繁榮皆有空調作為基礎建設；「把熱帶變成宜居」是這台除濕機最意想不到的後果。
