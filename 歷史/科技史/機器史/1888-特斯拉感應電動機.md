# 1888 特斯拉感應電動機

## 案件摘要

1888 年 5 月，塞爾維亞裔發明家尼古拉・特斯拉（Nikola Tesla, 1856–1943）向美國電氣工程師協會（AIEE）發表論文，並向專利局申請多項專利，展示了一種前所未有的電動機：不需要電刷、不需要換向器、轉子完全靠「旋轉磁場」感應驅動。喬治・西屋（George Westinghouse）當場買下專利，開啟了交流電對抗愛迪生直流電的「電流戰爭」（War of Currents）。本案追查：一個沒有接觸任何導體的轉子，為什麼會轉？

## 前因 -- 為什麼會有這個案子

- 直流電動機（Gramme 電動機等）依賴電刷與換向器（commutator）：高速磨損、打火花、需持續維護，是電力系統最脆弱的環節。
- 直流輸電無法升壓降壓，限制了發電廠的供電半徑；但工程師們不敢全面轉向交流，正是因為當時「沒有一台能用的交流電動機」──交流電只能點燈、不能驅動機器，這是電流戰爭的勝負關鍵。
- 特斯拉 1882 年在布達佩斯散步時（讀著歌德《浮士德》）想通了旋轉磁場的概念；1884 年抵美後曾在愛迪生公司工作，因理念不合離去。
- Galileo Ferraris 在義大利幾乎同時獨立推導出旋轉磁場原理（1885–1888），並發表了與特斯拉殊途同歸的成果──這是本案的平行偵探。

## 線索與推理 -- 數學式、程式、理論

### 理論一：旋轉磁場 -- 兩相繞組的魔術

特斯拉的關鍵洞察：把兩組線圈在空間上互成 90° 放置，通以相位差 90° 的兩相電流，合成磁場就是一個以固定大小、勻速旋轉的向量。設兩繞組磁場分別為 $B_x = B_0\cos(\omega t)$、$B_y = B_0\sin(\omega t)$，合成：

$$\vec{B}(t) = B_0\cos(\omega t)\,\hat{x} + B_0\sin(\omega t)\,\hat{y}, \qquad |\vec{B}| = B_0\ \text{（常數）}$$

磁場向量以角速度 $\omega$ 勻速旋轉──空間的 90° 位移配上時間的 90° 相移，兩個「閃爍」的磁場合成一個「旋轉」的磁場。推廣到 $m$ 相、空間間隔 $2\pi/m$ 的繞組同樣成立，這就是多相系統的理論基礎。

### 理論二：轉子的感應驅動 -- 法拉第定律的反向應用

旋轉磁場掠過導電的鼠籠轉子（squirrel-cage rotor，由端環短接的導條構成），在導條中感應出電動勢與電流：

$$\mathcal{E} = B_0\, l\, v_{slip}, \qquad v_{slip} = \omega_s r - \omega_r r\ \text{（轉差速度）}$$

感應電流在磁場中受力（勞倫茲力 $F = I l \times B$）驅動轉子旋轉。轉子會加速直到「轉差率」$s = (\omega_s - \omega_r)/\omega_s$ 縮小到感應電流足以提供負載轉矩為止──轉子永遠追不上磁場（若同步則無相對運動、無感應、無轉矩），這個「永遠差一點」的物理正是感應電動機的名字由來。轉矩-轉差關係近似為：

$$T \propto \frac{s\, E_0^2\, R_2}{R_2^2 + (s X_2)^2}$$

### 理論三：免維護的工程優勢

無電刷意味著：無摩擦磨損、無火花（可防爆）、無換向損耗。同步轉速由電源頻率與極數直接決定：

$$n_s = \frac{120 f}{P}\ \mathrm{rpm}$$

50 Hz、四極電機即 1,500 rpm──速度由發電廠的頻率「遠端控制」，這是整個交流電力系統標準化的理論基石。

### 驗證小程式

```python
import numpy as np

# 兩相繞組合成磁場：驗證 |B| 為常數、相位勻速旋轉
t = np.linspace(0, 1, 10000)
Bx, By = np.cos(2*np.pi*50*t), np.sin(2*np.pi*50*t)
B = np.hypot(Bx, By)
print(f"|B| 標準差 = {B.std():.2e}（≈0，恆定旋轉磁場成立）")
# 轉差率與轉矩曲線
R2, X2, s = 1.0, 4.0, np.linspace(0.001, 1, 500)
T = s*R2/(R2**2 + (s*X2)**2)
print(f"最大轉矩於 s ≈ {s[T.argmax()]:.2f}，啟動後運轉於小轉差區")
```

## 破案時刻

1887 年 10 月至 1888 年 5 月，特斯拉連續獲得多項基礎專利（含美國專利 381,968「Electro-Magnetic Motor」、382,280 等），1888 年 5 月 16 日在 AIEE 發表演講《A New System of Alternating Current Motors and Transformers》。西屋聽聞後立即赴紐約買斷專利（傳聞約數萬美元加每馬力權利金），並聘請特斯拉到匹茲堡指導工程化。1893 年芝加哥哥倫布世界博覽會，西屋以交流系統點亮全場 20 萬盞燈並驅動全部展示機器──電流戰爭的民意戰獲勝。

## 後果 -- 改變了什麼

- 感應電動機至今仍是工業動力的主力：全球絕大多數電動機是三相感應式，無刷、免維護、壽命以數十年計。
- 多相系統（三相）成為電力標準：發電、輸電、用電全部以三相交流架構運行至今。
- 電流戰爭由交流勝出：配合變壓器與三相輸電（1891 年勞芬–法蘭克福），愛迪生的直流系統在長距離市場全面潰敗。
- 特斯拉的專利組合奠定了西屋公司的電力王國，也奠定了「交流電頻率即國家標準」的現代電網概念。
