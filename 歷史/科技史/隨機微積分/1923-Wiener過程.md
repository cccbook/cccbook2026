# 1923 年數學鋼印案：Wiener 過程的嚴格誕生

> 花粉跳了一百年，股市跳了二十三年，物理學家都說那是布朗運動，數學家卻問：它到底是什麼函數。MIT 的 Norbert Wiener 在 1923 年給出答案：它是連續但處處不可微的怪物，二次變差等於時間。這枚鋼印一蓋，隨機微積分才有了地基。

| 欄位 | 內容 |
|------|------|
| 發生時間 | 1923 年，Differential Space 論文；1924 至 1933 年 Paley–Wiener–Zygmund 補強 |
| 地點 | 麻省理工學院數學系；構造橫跨測度論、Fourier 分析與 Brown、Einstein 的物理遺產 |
| 報案人 | 數學嚴格性本身：布朗運動缺乏函數定義，微分與積分無從談起 |
| 偵探 | Norbert Wiener（1894–1964），神童出身，控制論之父，調和分析高手 |
| 兇器 | 標準布朗運動 $W_0 = 0$ ，獨立增量 $N(0, t-s)$ ，連續不可微，二次變差 $[W]_t = t$ |
| 結論 | 布朗運動成為嚴格隨機過程，處處不可微得證，Itô 積分與 SDE 地基落成 |

## 案發現場

1923 年的數學界，布朗運動是個黑戶。

物理學家用 $dS = \\sigma dW$ ，Einstein 用擴散方程，Langevin 直接寫白噪聲 $\\xi$ 。但數學家追問： $W(t)$ 究竟是哪個函數空間的元素。它的軌跡可微嗎，可積嗎，測度何在。若答不上來，Itô 積分、Feynman–Kac、Black–Scholes 全是空中樓閣。

案發現場有三具「數學屍體」。

第一具是白噪聲。Langevin 的 $\\xi(t)$ 處處獨立、方差無窮，不是函數，不能逐點定義。物理直覺對，數學身份不明。

第二具是 Einstein 的基本解。高斯核 $(4 \\pi D t)^{-1/2} \\exp(-x^2 / 4 D t)$ 描述的是分佈，不是軌跡。它說一群粒子的統計，不說一顆粒子的路徑。

第三具是 Bachelier 的反射原理。論證漂亮，但建立在增量常態的假設上，沒有證明存在一個具有連續軌跡的過程同時滿足所有有限維分佈。

Wiener 的任務就是給黑戶上戶口：在連續函數空間上構造一個機率測度，使其有限維分佈恰為高斯增量，且幾乎所有軌跡連續。這就是 Wiener 測度。

## 偵查過程

Wiener 的偵查武器是 Fourier 級數與測度論，手法堪稱鑑識藝術。

### 第一步：寫下要證明的身份

標準 Wiener 過程（數學布朗運動）定義為滿足四條的隨機過程 $W_t$ 。

第一，初值 $W_0 = 0$ ，幾乎必然成立。

第二，獨立增量：不交區間的增量互相獨立。

第三，增量分佈為常態，即對 $t > s$ 有

$$
W_t - W_s \\sim N(0, t - s)
$$

均值零，變異數為時間差。這是 Einstein 均方位移的嚴格版。

第四，軌跡連續： $t \\mapsto W_t$ 幾乎必然連續。這是最難的一條，也是 Wiener 的主戰場。

前三條決定有限維分佈，第四條決定軌跡正則性。四條齊備，戶口成立。

### 第二步：Fourier 構造與連續性

Wiener 用隨機 Fourier 級數構造軌跡。取獨立標準常態係數 $Z_n$ ，以三角基展開布朗橋，再修正端點，得到 $[0,1]$ 上的候選過程。其形如隨機級數疊加，每一項連續，但無窮疊加是否連續並不明顯。

Wiener 證明級數一致收斂，從而極限連續。這一步用了精細的尾部估計，是調和分析功力的展現。Lévy 後來給出更直觀的二進插值構造，Ciesielski 用 Haar 小波重寫，但原創榮譽屬 Wiener。

構造完成後，有限維分佈驗證為高斯增量，連續性由一致收斂保證。Wiener 測度就此誕生：連續函數空間 $C_0$ 上的 Borel 機率測度，支撐在起於零的連續路徑上。

### 第三步：處處不可微的怪物現形

連續不代表可微。Wiener 猜測布朗軌跡處處不可微，1933 年 Paley、Wiener、Zygmund 聯手證明：幾乎所有軌跡在每一點都不可微。

直觀理由是尺度律。增量 $W_{t+h} - W_t$ 的典型大小為 $\\sqrt{h}$ ，故差商量級為

$$
\\lvert W_{t+h} - W_t \\rvert / h \\sim h^{-1/2}
$$

當 $h \\to 0$ 時爆發至無窮。軌跡抖動太劇烈，任何切線都被甩開。形式化的 PWZ 定理說，對幾乎所有軌跡，每一點的上導數為 $+\\infty$ 、下導數為 $-\\infty$ 。

| 性質 | 布朗軌跡 | 光滑函數對照 |
|------|----------|--------------|
| 連續性 | 處處連續 | 處處連續 |
| 可微性 | 處處不可微 | 分段可微 |
| 變差 | 任意區間無窮變差 | 有界變差可積 |
| 二次變差 | $[W]_t = t$ 有限非零 | 光滑函數二次變差為零 |
| Hölder 指數 | 小於 $1/2$ 成立，大於 $1/2$ 失敗 | 一階可微即 $1$ 階 Hölder |

### 第四步：二次變差等於時間

不可微的函數如何積分。答案藏在二次變差裡。對劃分 $0 = t_0 < t_1 < \\dots < t_n = t$ ，定義平方和

$$
Q_n = \\sum_{k} (W_{t_k} - W_{t_{k-1}})^2
$$

Wiener 與 Lévy 證明，當網格趨於零時， $Q_n$ 依機率收斂至 $t$ ，即

$$
[W]_t = t
$$

這是隨機微積分的基石。普通光滑函數的二次變差為零，布朗運動的二次變差為時間本身。這多出來的一份變差，正是 Itô 公式中二階項的來源。

換句話說， $dW^2 = dt$ 。這條乘法表寫於 1923 年的構造之中，1940 年代被 Itô 讀出來，1951 年寫成公式，1973 年被 Black–Scholes 拿去定價。

## 結案報告

1923 年案件的判決是：布朗運動從物理現象升格為數學對象。

直接遺產有三。第一，隨機過程理論有了第一個非平凡範例，Kolmogorov 的相容性定理與 Wiener 的構造互相印證，Doob、Lévy、Feller 在此地基上蓋樓。第二，PWZ 不可微定理終結了「軌跡逐點微分」的幻想，逼出 Itô 的新積分：不能對 $dW$ 逐點微分，只能對它做等距積分。第三，二次變差 $[W]_t = t$ 成為鞅論的分類器，連續鞅皆為時間變換的布朗運動，這是 Dubins–Schwarz 的深刻回聲。

Wiener 本人轉向了控制論與濾波，Wiener 濾波與後來的 Kalman 濾波同源。但他 1923 年的鋼印，至今蓋在每一條 SDE、每一個選擇權公式、每一個擴散生成模型的出生證明上。

第一幕至此落幕。從 1827 年 Brown 的花粉，到 1923 年 Wiener 的測度，抖動被看見、被定價、被定量、被鏈化、被寫成方程、被實驗稱量，最後被數學收編。第二幕的 Kolmogorov 與 Itô，將在這枚鋼印上繼續偵查。

## 證據與工具

| 證物 | 數學形式 | 偵查意義 |
|------|----------|----------|
| 初值 | $W_0 = 0$ | 軌跡起點固定，測度支撐在 $C_0$ |
| 獨立增量 | 不交區間增量獨立 | 無記憶的連續版，Markov 性的源頭 |
| 常態增量 | $W_t - W_s \\sim N(0, t-s)$ | Einstein 均方位移的嚴格化 |
| 連續軌跡 | $t \\mapsto W_t$ 連續 | Wiener 構造的核心，一致收斂保證 |

### 讀者實驗

將 $N$ 由 20000 加密至 80000 後重跑，觀察 $QV$ 標準差是否隨劃分加密而縮小。

完整程式如下：

```python
# 對應 wiki：1923 年 Wiener 過程（二次變差 [W]_T = T、Levy 模數連續性）
# 說明：T=1 切 N=20000 等分，h=T/N；每條路徑 QV = sum(dW^2)，理論均值 T；
# 200 條平均驗證誤差 < 3%。另驗 max|dW| ~ sqrt(2h log(1/h)) 量級（比值落於 [0.5, 2)）。
# 僅用 numpy，固定種子，不畫圖只印數字。
import numpy as np

SEED = 1923
T = 1.0
N = 20_000
M = 200

rng = np.random.default_rng(SEED)
h = T / N
sd = float(np.sqrt(h))
dW = rng.normal(0.0, sd, size=(M, N))
qv = np.sum(dW ** 2, axis=1)
qv_mean = float(qv.mean())
qv_std = float(qv.std(ddof=1))
rel_err = abs(qv_mean - T) / T

mx = np.max(np.abs(dW), axis=1)
mx_mean = float(mx.mean())
scale = float(np.sqrt(2.0 * h * np.log(1.0 / h)))
ratio = mx_mean / scale

print(f"T={T} N={N} M={M} h={h:.8f}")
print(f"QV_mean={qv_mean:.6f} QV_std={qv_std:.6f} target={T:.6f} rel_err={rel_err:.6f} (tol 0.03)")
print(f"max|dW|_mean={mx_mean:.6f} scale=sqrt(2h log(1/h))={scale:.6f} ratio={ratio:.4f} (tol [0.5,2.0])")

assert rel_err < 0.03, f"Wiener QV rel_err {rel_err} >= 3%"
assert 0.5 < ratio < 2.0, f"max|dW| ratio {ratio} not order-one"
print(f"VERIFY 1923-wiener_qv PASS qv={qv_mean:.4f} target={T:.4f} ratio={ratio:.3f}")
```
