# 隨機微積分的歷史年表（科學史）

> 隨機微積分是「會抖動的微積分」：當布朗運動的花粉、股市的價格、神經元的訊號都走上不規則之路，牛頓與萊布尼茲的鏈鎖律就失效了。從 Brown 的花粉、 Bachelier 的投機、Einstein 的擴散、Langevin 的阻尼，到 Wiener 的嚴格構造、Kolmogorov 的公理、Itô 的積分與公式，再到 Black–Scholes、鞅定價、BSDE、粒子濾波、粗糙路徑、Hairer 的正則結構，直到深度 BSDE、神經 SDE 與擴散生成模型——這部歷史就是人類追問「隨機性能否微分」的兩百年探案史。
>
> 本書以「推理探案」的方式，為每個歷史事件寫一篇 wiki，包含前因後果、理論與公式。每篇檔名以年份開頭。

## 寫作方式說明

每篇 wiki 採「推理探案」結構：

1. **案發現場（前因）**：當時的未解之謎是什麼？誰遇到的？為何重要？
2. **偵查過程（推理）**：主角如何思考？關鍵靈感為何？核心技術（方程、測度變換、數值格式）如何推導，含數學式與表格。
3. **結案報告（後果）**：謎題如何解？留下什麼遺產？影響了哪些後續事件？
4. **證據與工具**：關鍵公式、演算法虛擬碼或 Python 模擬程式、參數表（非必要不硬寫程式，優先講清理論）。
5. **補充：程式實作**：對應 `_code/` 可執行程式的連結、理論呼應、執行方式、實測輸出、讀者實驗，以及完整程式碼。
