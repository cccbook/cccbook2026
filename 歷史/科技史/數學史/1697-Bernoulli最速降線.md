# 1697 - 伯努利最速降線

## 案件摘要
1696 年 6 月，Johann Bernoulli 在《教師學報》（Acta Eruditorum）公開徵答：**最速降線問題**（brachistochrone）——重力下，從 A 點滑到更低 B 點，什麼形狀的軌道最快？**不是直線**！答案：**擺線（cycloid）**——倒轉的擺輪軌跡。牛頓（匿名，一天內解出）、萊布尼茨、雅各布·伯努利、洛必達全都解出——而雅各布的解法（比較相鄰路徑）催生了**變分法**（calculus of variations）——**從「求函數值」到「求函數本身」**的數學革命。**力學（歐拉–拉格朗日方程）與場論（廣義相對論）的數學基礎**。

## 前因 -- 為什麼會有這個案子
**1690 年代的挑戰**：微積分（1665，見 `1665-Newton微積分.md`）剛誕生，能求「函數的極值」（最大最小值）——**但最速降線問的不是「哪個點」，是「哪條曲線」**：

$$\text{給定函數空間（所有軌道），找最優的函數}$$

——**極值問題的升維**：從 $\mathbb{R}$ 到函數空間！微積分無力（它只會對參數求導，不會對「函數」求導）。

**Johann Bernoulli 的動機**：與哥哥**雅各布**（Jacob）的競爭（兄弟鬩牆——數學史上最激烈的家務戰爭）、挑戰牛頓與歐陸學派。**公開徵答**：「看看誰是幾何學的天才」。

## 線索與推理 -- 數學式、程式、理論

### 最速降線的數學
**問題**：軌道 $y(x)$，從 $(0, 0)$ 到 $(L, H)$，重力加速度 $g$。滑行時間（能量守恆：$v = \sqrt{2gy}$）：

$$T[y] = \int_0^L \frac{\sqrt{1 + (y')^2}}{\sqrt{2gy}}\, dx$$

**求「使 $T$ 最小的函數 $y$」**——**泛函極值**（functional extremum）！

**答案：擺線（cycloid）**：

$$x = a(t - \sin t), \quad y = a(1 - \cos t)$$

（滾輪上一點的軌跡——倒轉。）

### 雅各布的解法：變分法的前身
**Johann 的解法**（費馬原理式的光學類比）：把軌道切成薄片，每片用**斯涅爾定律**（折射）——$v/\sin\theta = $ 常數——**光走最快的路**（費馬原理 1662），所以最速降線是「光在介質中的路徑」——擺線。

**雅各布的解法（更深刻）**：**比較相鄰路徑**——最優軌道 $y$ 與鄰近軌道 $y + \epsilon\eta$ 的時間差：

$$T[y + \epsilon\eta] - T[y] \ge 0 \quad \forall \eta$$

**一次變分為零**：

$$\delta T = 0 \quad \text{（對函數的「導數」）}$$

——**變分法的誕生**：對「函數」求極值的數學。

### 歐拉–拉格朗日方程
**歐拉與拉格朗日的形式化**（1730s–1750s）：泛函

$$J[y] = \int_a^b F(x, y, y')\, dx$$

的極值條件：

$$\frac{\partial F}{\partial y} - \frac{d}{dx}\frac{\partial F}{\partial y'} = 0 \quad \text{（歐拉–拉格朗日方程）}$$

**最速降線的驗證**：$F = \sqrt{1+y'^2}/\sqrt{2gy}$——代入歐拉–拉格朗日方程，解得擺線。$\blacksquare$

**力學的 revolution（歐拉–拉格朗日、Hamilton 1833，見 `1843-Hamilton四元數.md`）**：力學的方程不是 $F = ma$ 的「牛頓式」，而是**最小作用量原理**：

$$\delta \int L\, dt = 0 \quad \text{（作用量 S = ∫ L dt 的極值）}$$

——**變分法是力學的語言**：從最速降線到場論（廣義相對論的愛因斯坦–希爾伯特作用量、量子場論的最小作用量）——**變分法是現代物理的基礎設施**。

### 程式碼：最速降線 vs 直線

```python
import math, random

def slide_time(y_fn, L, H, n=10000):
    """軌道 y_fn 的滑行時間（能量守恆 v = sqrt(2gy)）"""
    T = 0.0
    for i in range(n):
        x = i * L / n
        y = y_fn(x)
        if y <= 0: continue
        # 弧長微元 / 速度
        y2 = y_fn(x + L/n)
        ds = math.sqrt((L/n)**2 + (y2-y)**2)
        T += ds / math.sqrt(2 * max(y, 1e-12))
    return T

# 直線軌道
straight = lambda x: H * x / L
# 擺線軌道（最速降線）：x = a(t - sin t), y = a(1 - cos t)
def cycloid(L, H):
    """解擺線參數 a 使 y(L) = H"""
    # 近似：a = H/2 時 y = a(1 - cos(t)), x = a(t - sin t)
    a = H / 2
    return lambda x: max(a * (1 - math.cos((x/a) + math.sin(x/a))), 0.01)

H, L = 1.0, 2.0
T_straight = slide_time(straight, L, H)
T_cycloid = slide_time(cycloid(L, H), L, H)
print(f"直線滑行時間 = {T_straight:.4f}")
print(f"擺線滑行時間 = {T_cycloid:.4f}")
print(f"擺線比直線快 {(1 - T_cycloid/T_straight)*100:.1f}% ✓")
# 擺線更快——「不是直線」的經典

# 歐拉–拉格朗日方程的概念
print("\n歐拉–拉格朗日方程：∂F/∂y - d/dx(∂F/∂y') = 0")
print("變分法：對『函數』求極值——從求值到求函數的革命")
```

### 兄弟鬩牆與牛頓的匿名
**雅各布 vs Johann**：哥哥雅各布的解法（變分法）**比 Johann 的更深刻**——Johann 憤怒（哥哥搶了他的榮耀）。**數學史上最激烈的家務戰爭**（兄弟、兒子（丹尼爾 vs 父親 Johann）、師生（歐拉 vs 約翰））。

**牛頓的匿名解**：1697 年 1 月，牛頓收到徵答，**一天內**解出（匿名寄回）——Johann 讀後說「**從爪子認出獅子**」（ex ungue leonem）——**大師的指紋**。牛頓當時是鑄幣廠廠長（公务），數學是業餘——**大師的餘威**。

**偵探筆記**：最速降線的推理是「**升維**」——從「求點的極值」到「求函數的極值」。**微積分的無力**（只會對參數求導）催生變分法——與 Galois 群論（1832，見 `1832-Galois群論.md`，從方程到群）、Cantor 集合論（1874，見 `1874-Cantor集合論.md`，從數到集合）同源：**數學的革命常是「問題空間的升維」**。

## 結案 -- 後果與影響
- **變分法的誕生**：對函數求極值——歐拉–拉格朗日方程、力學的語言。
- **力學的 revolution**：最小作用量原理——拉格朗日力學、Hamilton 力學、場論（廣義相對論、量子場論）的基礎（見 `1854-Riemann幾何.md`）。
- **光學的類比**：費馬原理（最短時間）——變分法與光學的統一（斯涅爾定律的深刻解釋）。
- **兄弟鬩牆的教訓**：雅各布的解法更深刻——**競爭催生進步，但傷害合作**（伯努利家族的內耗）。
- **牛頓的指紋**：一天內的匿名解——「從爪子認出獅子」——大師的餘威。
- **現代物理的基礎設施**：最小作用量貫穿古典力學、量子力學（費曼路徑積分 1948）、場論——**變分法是物理的統一語言**。
