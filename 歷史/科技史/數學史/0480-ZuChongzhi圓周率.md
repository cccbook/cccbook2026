# 480 - 祖沖之圓周率

## 案件摘要
480 年前後，南北朝數學家祖沖之把割圓術（劉徽，263，見 `0263-LiuHui割圓術.md`）推到極致：

$$3.1415926 < \pi < 3.1415927 \quad \text{（約 12288 邊形）}$$

並給出**密率** $\pi \approx \frac{355}{113}$——**這個精度統治世界近千年**（歐洲 15 世紀才超越，1585 年才重新發現 355/113）。祖沖之與其子祖暅還用**祖暅原理**求出球體積——**Cavalieri 原理（1635）的 1300 年前身**。**一位被傳統遺忘的天才**：他的《綴術》失傳（唐代後失傳，宋代全佚），成就靠《隋書》的記載流傳。

## 前因 -- 為什麼會有這個案子
**劉徽的遺產**（263）：割圓術至 192 邊形，$\pi \approx 3.1416$——**還不夠**（誤差 $10^{-4}$）。祖沖之的問題：**割圓到極致，π 能到多少位？**

**計算的挑戰**：12288 邊形——每步勾股定理兩次、開方數百次——**用算籌（計數棍）手算**，與其子祖暅協助。**沒有阿拉伯數字、沒有計算機**——純算籌運算達到 8 位精度。

## 線索與推理 -- 數學式、程式、理論

### 割圓術的極致
**邊長的遞推**（劉徽的公式）：內接正 $n$ 邊形邊長 $a_n$、半徑 $r$：

$$a_{2n} = \sqrt{\left(\frac{a_n}{2}\right)^2 + \left(r - \sqrt{r^2 - \left(\frac{a_n}{2}\right)^2}\right)^2}$$

**周長逼近**：$n$ 邊形周長 $P_n = n \cdot a_n$，$P_n / 2r \to \pi$。

**誤差階**（現代分析）：$P_n/2r = \pi - \frac{\pi^3}{6n^2} + O(1/n^4)$——$n = 12288$ 時誤差 $\approx 1.6 \times 10^{-9}$——**祖沖之的 8 位精度正是 12288 邊形的能力極限**。

### 密率：355/113
**密率**：$\pi \approx \frac{355}{113}$：

$$\frac{355}{113} = 3.14159292\ldots \quad \text{（誤差 } 2.7 \times 10^{-7}\text{）}$$

**為什麼 355/113 是最佳**：**連分數理論**——$\pi$ 的連分數展開：

$$\pi = [3; 7, 15, 1, 292, \dots] \implies \text{漸近分數：} \frac{22}{7}, \frac{333}{106}, \frac{355}{113}, \dots$$

**355/113 是「最佳有理近似」**（下一個更好的漸近分數是 $103993/33102$——分子大 293 倍）。**祖沖之憑什麼找到 355/113？**——謎（綴術失傳）：可能是「調日法」的改良或窮舉。

**對照**：

| 分數 | 誤差 | 發現者 |
|------|------|--------|
| 22/7（約率） | $4 \times 10^{-3}$ | Archimedes 前 250 |
| 333/106 | $2.7 \times 10^{-5}$ | Adriaan Anthonisz 1585 |
| **355/113（密率）** | $2.7 \times 10^{-7}$ | **祖沖之 480** |
| 103993/33102 | $5.8 \times 10^{-10}$ | 15 世紀印度 Madhava |

**千年精度**——歐洲直到 1585 年（Anthonisz）才重新發現 355/113，15 世紀 Madhava 超越。

### 祖暅原理：體積的秘訣
**祖沖之之子祖暅**：「冪勢既同，則積不容異」——**等高處截面積相等 ⟹ 體積相等**：

$$V = \int_0^h A(y)\, dy \quad \text{（現代語言——體積是截面積的積分）}$$

**球體積的推導**：球與「外切圓柱挖去圓錐」在每個高度的截面積相等——**不用窮竭法**，直接比較：

$$V_{球} = \frac{2}{3} V_{柱} = \frac{4}{3}\pi r^3$$

**Cavalieri 原理（1635）**——**祖暅原理的 1300 年前身**。積分思想的東方先聲（牛頓積分 1665 的兩千年譜系，見 `1665-Newton微積分.md`）。

### 程式碼：密率與祖暅原理

```python
import math

# 祖沖之的割圓術極致：12288 邊形
def liuhui_pi(sides, r=1.0):
    a, n = r, 6
    while n < sides:
        half = a / 2
        arrow = r - math.sqrt(r*r - half*half)
        a = math.sqrt(half*half + arrow*arrow)
        n *= 2
    return a * n / (2 * r)

for n in [6, 96, 12288]:
    p = liuhui_pi(n)
    print(f"{n:6d} 邊形：π ≈ {p:.10f}（誤差 {abs(p - math.pi):.2e}）")
# 12288 邊形誤差 ≈ 1.6e-9——祖沖之的 8 位精度

# 密率 355/113：連分數的最佳近似
def cf_pi(terms=5):
    """π 的連分數 [3; 7, 15, 1, 292, ...] → 漸近分數"""
    cf = [3, 7, 15, 1, 292]
    p, q = cf[terms-1], 1
    for c in reversed(cf[:terms-1]):
        p, q = c * p + q, p
    return p, q

for k in [1, 2, 3]:
    p, q = cf_pi(k)
    print(f"漸近分數 {k}: {p}/{q} = {p/q:.10f}（誤差 {abs(p/q - math.pi):.2e}）")
# 355/113 是連分數的最佳有理近似——祖沖之的成就

# 祖暅原理：球體積
R = 1.0
V_ball = 4/3 * math.pi * R**3
V_cyl = 2 * math.pi * R**3
print(f"\n球體積 = {V_ball:.4f}，外切圓柱 = {V_cyl:.4f}，比值 = {V_ball/V_cyl:.4f} = 2/3 ✓")
print("祖暅原理（冪勢既同，積不容異）= Cavalieri 原理的 1300 年前身")
```

### 《綴術》的失傳
**悲劇**：祖沖之的《綴術》（含 π 的方法與天文曆法）被譽為「學官莫能究其深奥」——唐代列為算學教科書（學習年限最長），**宋代後失傳**——**祖沖之的方法成謎**（割圓到 12288？調日法？），只有《隋書》記載了結果。

**偵探筆記**：與 Galois 遺稿（見 `1832-Galois群論.md`）、Bletchley Park（見 `../密碼學/1939-BletchleyPark.md`）同源的主題——**知識的傳播與遺失**。祖沖之的結果流傳、方法失傳——**數學史的最大懸案之一**。

## 結案 -- 後果與影響
- **千年的精度**：355/113 統治世界近千年——中國數學的巔峰成就。
- **連分數的最佳近似**：355/113 是 π 連分數的漸近分數——**連分數理論**（Brouncker 1657、Lagrange 1798）的先聲。
- **祖暅原理**：Cavalieri 原理的 1300 年前身——積分思想的東方先聲。
- **《綴術》的失傳**：知識傳播的悲劇——數學史的懸案（方法成謎）。
- **數學的多元起源**：與希臘（證明）、伊斯蘭（代數）並列——**中國（算法與極限）是數學的第三大源頭**。
