# 820 - 花拉子米《代數學》

## 案件摘要
約 820 年，波斯學者花拉子米（al-Khwārizmī）在巴格達的智慧宮（House of Wisdom）完成《代數學》（al-Kitāb al-mukhtaṣar fī ḥisāb al-jabr wal-muqābala）：系統化「移項與合併」解方程的方法——**al-jabr（還原）就是 algebra 一詞的來源**。他的另一本書《印度數字算術》傳播了印度-阿拉伯數字系統，拉丁化他的名字（Algoritmi）成為 **algorithm（演算法）**一詞的來源。**一個人給了兩個詞：algebra 與 algorithm**——現代數學與電腦科學的名字都源自他。

## 前因 -- 為什麼會有這個案子
8 世紀的巴格達：阿拔斯王朝的黃金年代，智慧宮集結各地的學術遺產——希臘的幾何（歐幾里得譯本）、印度的數字與天文、波斯的算術。花拉子米的任務：**把實用算術（遺產分割、商業計算）系統化**。

**希臘數學的盲點**：幾何式思維——所有量都是線段與面積，方程是幾何關係（如《幾何原本》的命題 II）。**實用的代數**（已知面積求邊長）零散無系統。

**花拉子米的問題**：能否把「解方程」從幾何直覺變成**機械的步驟**？

## 線索與推理 -- 數學式、程式、理論

### 代數的方法：移項與還原
花拉子米的分類：方程的三種基本型（用文字）——

- 根（$x$）、平方（$x^2$）、數（常數）

**兩個基本操作**：

1. **al-jabr（還原/restoration）**：把負項移到等號另一邊：

$$x^2 + 5 = 8x - 3 \implies x^2 + 8 = 8x \quad \text{（-3 還原為 +8）}$$

2. **al-muqābala（對比/合併）**：合併同類項：

$$3x + 4x = 8x - 3 \implies 7x + 3 = 8x$$

**algebra = al-jabr**——「還原」這個操作的名字成為整個學科的名字。

### 二次方程的解法
花拉子米給出二次方程 $x^2 + bx = c$ 的解法（用文字描述，現代記號為）：

$$x = \sqrt{\left(\frac{b}{2}\right)^2 + c} - \frac{b}{2}$$

**配方（completing the square）**：兩邊加 $(b/2)^2$：

$$x^2 + bx + \frac{b^2}{4} = c + \frac{b^2}{4} \implies \left(x + \frac{b}{2}\right)^2 = c + \frac{b^2}{4}$$

——**幾何證明**（正方形補全圖形）+ 機械步驟。負根與複數根**不承認**（只取正實根）——這個限制要到 1545 年 Cardano（見 `1545-Cardano三次方程.md`）才被打破。

### 「演算法」的命名
花拉子米的《印度數字算術》（On the Calculation with Hindu Numerals，約 825）傳播 0–9 的位值系統與四則運算的**步驟化方法**。

12 世紀拉丁譯本把他的名字拉丁化：**Algoritmi** → **algorithm**——「演算法」原意就是「花拉子米式的計算方法」。

**演算法的定義**（現代）：

$$\text{演算法} = \text{有限步驟、確定性的計算程序}$$

——從花拉子米的「機械步驟」到 Turing 機（1936，見 `../計算理論/1936-Turing機與停機問題.md`）的「理想化計算者」，1200 年的譜系。

### 配方的數值實例
**花拉子米的公式** $x = \sqrt{(b/2)^2 + c} - b/2$ 與現代求根公式 $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$ 的對照：

| 方程 | 花拉子米（只取正根） | 現代（含負根/複數根） |
|------|----------------------|------------------------|
| $x^2 + 4x = 21$ | $x = \sqrt{4 + 21} - 2 = 3$ | $x = 3$ 或 $x = -7$ |
| $x^2 + 4x = -21$ | 無解（不承認） | $x = -2 \pm \sqrt{17}i$（複數） |
| $x^2 + 1 = 0$ | 無解（不承認） | $x = \pm i$（虛數，1545 Cardano 才接受） |

**驗證**：$x = 3$ 代入 $x^2 + 4x = 9 + 12 = 21$ ✓——配方的幾何證明保證機械步驟的正確性。

### 智慧宮的傳承
**偵探筆記**：花拉子米的推理是「系統化」——把零散的實用知識（遺產分割、方程、商業計算）組織成**分類 + 機械步驟**。這個方法與歐幾里得的公理化（見 `-0300-Euclid幾何原本.md`）不同：**不追求從公理演繹，追求「照著做就對」的步驟**——這正是「演算法」的本質，也是電腦科學的靈魂。

## 結案 -- 後果與影響
- **代數學的誕生**：al-jabr 的移項方法成為整個學科——從二次方程到五次方程（1545 Cardano）到群論（1832 Galois）。
- **位值系統的傳播**：印度-阿拉伯數字傳入歐洲（1202 年 Fibonacci 的《計算之書》，見 `1202-Fibonacci斐波那契.md`）——計算的革命。
- **演算法一詞**：Algoritmi → algorithm——電腦科學的核心概念以他命名。
- **數學的兩條腿**：代數（運算）與幾何（形狀）——1637 年 Descartes 的解析幾何（見 `1637-Descartes解析幾何.md`）統一兩者。
- **翻譯運動**：智慧宮的希臘-印度-波斯遺產翻譯——伊斯蘭黃金年代保存並發展了古典學術（沒有它，歐洲文藝復興無從谈起）。
