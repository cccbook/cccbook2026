# 1799 - 高斯代數基本定理

## 案件摘要
1799 年，22 歲的 Carl Friedrich Gauss 在博士論文中證明**代數基本定理**（Fundamental Theorem of Algebra）：$n$ 次多項式在**複數域**中必有一個根（等價地：恰有 $n$ 個根，計重數）——**複數域是代數封閉的**。Cardano 的虛數怪物（1545，見 `1545-Cardano三次方程.md`）從此有了「更大的家」：虛數不是技巧，是**必須的**。高斯一生給了 4 種證明，被稱為「數學王子」（Princeps mathematicorum）——他的博士論文開啟了 19 世紀數學的黃金年代。

## 前因 -- 為什麼會有這個案子
17–18 世紀代數的困惑：**實係數多項式的根在哪裡？**

- $x^2 + 1 = 0$：沒有實根（虛數根 $\pm i$）
- $x^3 - 15x - 4 = 0$：三個實根，但根式中間必經虛數（casus irreducibilis，見 `1545-Cardano三次方程.md`）
- **複數的尷尬**：有運算規則（Bombelli 1572）、有用（歐拉公式 1748，見 `1748-Euler公式.md`），但**「真的存在嗎？」**——哲學上的疑慮

**待解的問題**：任何多項式（實或複係數）是否**必然**有複數根？——若有，複數域就是「完整的」（代數封閉），虛數的地位從此穩固。

**高斯的環境**：不倫瑞克（Braunschweig）貧困家庭的神童——Gauss 的算術天賦（3 歲修正父親的帳目傳說、10 歲快速算 $1+2+\dots+100$）被不倫瑞克公爵資助，1795 年入 Göttingen 大學。1796 年（19 歲）發現正 17 邊形的尺規作圖——**2000 年無人解的幾何問題**，Gauss 決定投身數學。1799 年博士論文證明代數基本定理。

## 線索與推理 -- 數學式、程式、理論

### 定理的陳述
**代數基本定理**：非常數複係數多項式

$$p(z) = a_n z^n + \dots + a_1 z + a_0$$

必有複數根 $z_0$ 使 $p(z_0) = 0$。等價地：$p(z) = a_n(z - z_1)\cdots(z - z_n)$（恰 $n$ 個根，計重數）——**複數域代數封閉**。

### 為什麼以前的方法失效
**純代數的方法**：17–18 世紀的嘗試（d'Alembert 1746、Euler、Lagrange）都假設了**未證明的拓撲/分析事實**（如多項式的連續性、根的存在性）——**代數問題需要分析工具**。

**高斯的洞察（第一個證明，1799）**：多項式 $p(z) = u(x,y) + iv(x,y)$（$z = x + iy$），考慮兩條曲線：

$$u(x, y) = 0 \quad \text{與} \quad v(x, y) = 0$$

**推理**：$|z| \to \infty$ 時，$u, v$ 的曲線的**拓撲行為**（走向、包圍）保證它們**必相交**——交點就是根。**這是拓撲論證**（雖然 1799 年還沒有拓撲學——Gauss 的論證有漏洞，後來補完）。

**高斯的四個證明**（1799、1816、1816、1849）：每個都用分析/拓撲——**純代數證明不可能**（這個事實後來由 Artin–Schreier 1927 形式化：代數封閉性是「有序域」的性質，需要拓撲/序結構）。

### 為什麼重要：複數的穩固地位
**證明的意義**：

1. **虛數不是技巧，是必須**：實係數多項式（如 $x^2+1$）的根**必然**在複數域——虛數是實數的**擴張的必然**，不是發明的技巧
2. **casus irreducibilis 的解釋**：三次方程的實根「必經虛數」（見 `1545-Cardano三次方程.md`）——因為複數域是**完整**的，實數域是**殘缺**的
3. **因式分解的完整性**：任何多項式完全分解——代數的機械化（求根公式的譜系：二次（花拉子米）、三次（Cardano）、四次（Ferrari）、**五次無根式**（Abel 1824，見 `1824-Abel五次方程.md`）但**複數根必存在**）

**n 次根的譜系**：

| 次數 | 根式解 | 複數根必存在 |
|------|--------|--------------|
| 2 | ✓ 花拉子米 | ✓ |
| 3 | ✓ Cardano | ✓ |
| 4 | ✓ Ferrari | ✓ |
| 5+ | ✗ Abel–Galois | ✓（代數基本定理）|

### 程式碼：多項式的複數根

```python
import cmath, math

def polynomial_roots(coeffs):
    """複係數多項式求根（數值方法：Newton 迭代的複數版）"""
    def p(z):
        return sum(c * z**i for i, c in enumerate(reversed(coeffs)))
    def p_prime(z):
        return sum(i * c * z**(i-1) for i, c in enumerate(reversed(coeffs)) if i > 0)
    roots = []
    for seed in [cmath.exp(2j * math.pi * k / 7) * 2 for k in range(7)]:
        z = seed
        for _ in range(100):
            if abs(p_prime(z)) < 1e-12: break
            z = z - p(z) / p_prime(z)
        if all(abs(z - r) > 1e-6 for r in roots):
            roots.append(z)
    return roots

# x^4 - 1 = 0：四個複數根（含虛數 ±i）
roots = polynomial_roots([1, 0, 0, 0, -1])
print(f"x^4 - 1 的根：{[f'{r.real:.3f}{r.imag:+.3f}i' for r in sorted(roots, key=lambda z: (z.real, z.imag))]}")
# ±1, ±i：複數域完整——實數域缺 ±i

# x^2 + 1 = 0：實數域無根，複數域有
print(f"x² + 1 的根 = ±i（虛數是必須的，不是技巧）")

# 5 次方程：無根式解（Abel 1824），但複數根必存在（Gauss 1799）
print("x^5 - x + 1 = 0：5 個複數根必存在（代數基本定理），但無根式解（Abel–Ruffini）")
```

### 高斯的帝國
**「數學王子」的貢獻**：
- **數論**：《算術研究》（Disquisitiones Arithmeticae，1801）——同餘、二次互反律、正 17 邊形
- **非歐幾何**（1820s，未發表）：否定第五公設的自洽幾何（見 `1854-Riemann幾何.md`）
- **最小平方法**（1795/1809）：高斯分佈、誤差理論（見 `../機率統計/README.md`）
- **複分析**：Cauchy–Riemann 方程、複積分
- **磁學**：CGS 單位、地磁測量

**偵探筆記**：Gauss 的推理是「**代數問題用拓撲解**」——根的存在性不是純代數的（Artin–Schreier 1927 形式化了這個事實），需要分析/拓撲的連續性論證。這個「跨領域」的風格與歐拉（見 `1734-Euler巴塞爾問題.md`）、阿基米德（見 `-0250-Archimedes圓周率.md`）同源：**數學的統一性——代數、幾何、分析是一體的**。

## 結案 -- 後果與影響
- **複數域的穩固**：代數封閉性證明後，虛數的地位從此無可動搖——從怪物到「更大的家」。
- **代數的完整性**：任何多項式完全分解——代數機械化的理論保證。
- **五次方程的伏筆**：根**存在**但**無根式解**（Abel–Galois）——存在性與可解性的分離。
- **高斯的帝國**：數論（1801）、非歐幾何、最小平方法——19 世紀數學的領路人。
- **拓撲的誕生伏筆**：Gauss 的第一個證明的拓撲論證——拓撲學（Poincaré 1895，見 `2003-Perelman龐加萊猜想.md`）的先聲。
- **現代代數**：域的擴張、Galois 理論（見 `1832-Galois群論.md`）——代數基本定理是起點。
