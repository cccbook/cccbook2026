# 1859 - 黎曼假設

## 案件摘要
1859 年，33 歲的 Bernhard Riemann 在柏林科學院發表《論小於給定值的素數個數》（On the Number of Primes Less Than a Given Magnitude）：引入**ζ 函數的解析延拓**，提出**黎曼假設**——ζ 函數的所有非平凡零點都在直線 $\Re(s) = \frac{1}{2}$ 上。這是**數論的中心懸案**（167 年未解）、**千禧年大獎（見 `2000-千禧年大獎.md`）的明珠**、Hilbert 23 問題的第 8 題（見 `../計算理論/1900-Hilbert23問題.md`）。**素數分佈的精確鑰匙**——若成立，素數定理的誤差界立即收緊。**一篇 8 頁的論文改寫了數論**。

## 前因 -- 為什麼會有這個案子
**歐拉的遺產**（1737，見 `1734-Euler巴塞爾問題.md`）：ζ 函數的歐拉乘積：

$$\zeta(s) = \sum_{n=1}^{\infty} \frac{1}{n^s} = \prod_{p \text{ 素數}} \frac{1}{1 - p^{-s}}$$

——**素數與分析的橋樑**（$s = 2$ 時 $\zeta(2) = \pi^2/6$，巴塞爾問題）。

**素數的困惑**：素數有多少？**素數定理的猜想**（Gauss 1792 的猜測、Legendre 1798）：$\pi(x) \approx x/\ln x$——但**誤差**多大？

**Riemann 的問題**：ζ 函數在 $\Re(s) \le 1$ **發散**（級數不收斂）——**如何研究素數與 ζ 的關係**？答案：**解析延拓**——把 ζ 擴張到複數平面（除 $s = 1$），研究零點。

## 線索與推理 -- 數學式、程式、理論

### ζ 函數的解析延拓
**Riemann 的擴張**（通過積分表示）：

$$\zeta(s) = \frac{1}{\Gamma(s)} \int_0^\infty \frac{x^{s-1}}{e^x - 1}\, dx \quad \text{（} \Re(s) > 1\text{）}$$

**解析延拓**到整個複數平面（除 $s = 1$ 的單極點）。**函數方程**（對稱性）：

$$\zeta(s) = 2^s \pi^{s-1} \sin\frac{\pi s}{2} \Gamma(1-s) \zeta(1-s)$$

**零點的結構**：
- **平凡零點**：$s = -2, -4, -6, \dots$（來自 $\sin$ 因子）
- **非平凡零點**：$0 < \Re(s) < 1$ 的零點——**素數分佈的鑰匙**

### 黎曼假設
**陳述**：ζ 函數的所有非平凡零點都在**臨界線**上：

$$\zeta(s) = 0 \text{ 且 } 0 < \Re(s) < 1 \implies \Re(s) = \frac{1}{2}$$

（前幾個零點：$\frac{1}{2} \pm 14.1347i$、$\frac{1}{2} \pm 21.0220i$、……）

### 素數定理的鑰匙
**顯式公式（Riemann 的推導，von Mangoldt 1895 嚴格化）**：

$$\psi(x) = x - \sum_{\rho} \frac{x^{\rho}}{\rho} - \ln 4\pi - \dots$$

（$\psi(x)$ 是素數冪的計數、$\rho$ 遍歷非平凡零點——**素數分佈由零點的「波動」決定**。）

**推理**：若黎曼假設成立（$\Re(\rho) = 1/2$），則誤差項 $O(x^{1/2} \ln^2 x)$——**素數定理的誤差立即收緊**：

$$\pi(x) = \mathrm{Li}(x) + O(\sqrt{x} \ln x)$$

**「素數的分佈像隨機的擲骰子，但擲骰子的偏度由零點決定」**——與蒙地卡羅（見 `../隨機算法/1946-Ulam蒙地卡羅.md`）的隨機性同源的視角。

### 程式碼：ζ 函數與零點

```python
import cmath, math

# ζ 函數（Dirichlet eta 變換實現收斂）
def zeta(s, terms=100000):
    """ζ(s) = η(s) / (1 - 2^{1-s})——eta 級數收斂更廣"""
    eta = sum((-1)**(n+1) / n**s for n in range(1, terms))
    return eta / (1 - 2**(1-s))

# 驗證已知值
print(f"ζ(2) = {zeta(2):.6f}（π²/6 = {math.pi**2/6:.6f}）✓")
print(f"ζ(4) = {zeta(4):.6f}（π⁴/90 = {math.pi**4/90:.6f}）✓")

# 非平凡零點的驗證（前幾個已知零點都在臨界線）
zeros_t = [14.1347, 21.0220, 25.0109, 30.4249, 32.9351]
print("\n前幾個非平凡零點（都在 Re(s) = 1/2）：")
for t in zeros_t:
    s = 0.5 + 1j * t
    z = zeta(s, terms=50000)
    print(f"  s = 0.5 + {t:.4f}i，|ζ(s)| = {abs(z):.2e} ≈ 0 ✓")

# 臨界線之外的測試（假設失敗處 |ζ| 不小）
s_off = 0.6 + 1j * 14.1347
print(f"\n偏離臨界線 s = 0.6 + 14.1347i：|ζ| = {abs(zeta(s_off, 50000)):.3f}（不小 → 不是零點）")
print("黎曼假設（1859）：所有非平凡零點在 Re(s) = 1/2——167 年懸案")
```

### Hilbert–Pólya 的譜理論
**猜測（1914/1982）**：ζ 的零點是某個**自伴算子**的特徵值（譜）——**若找到這個算子，黎曼假設立即成立**（自伴算子的特徵值是實數——對應 $\Re(s) = 1/2$ 的對稱）。

**攻擊的譜系**：
- **計算驗證**：$10^{13}$ 個零點全在臨界線（Odlyzko 的計算）——**證據大量，證明為零**
- **Montgomery 對關聯（1973）**：零點的間距分佈 = **隨機矩陣（GUE）的特徵值間距**——**與量子混沌的意外連結**（Berry–Keating 1999）
- **素數的譜**：與隨機矩陣理論（見 `../隨機算法/README.md` 的 JL 引理同源）的深層連結

**偵探筆記**：Riemann 的推理是「**解析延拓 + 函數方程**」——把發散的級數擴張到複平面，用零點的結構研究素數。**8 頁論文**含 3 個定理、2 個猜想——**密度最高的數學論文之一**。與 Euler 的 ζ 乘積（見 `1734-Euler巴塞爾問題.md`）、Gauss 的素數猜測同源：**素數分佈是數論與分析的交匯點**。

## 結案 -- 後果與影響
- **數論的中心懸案**：167 年未解——千禧年大獎（2000，見 `2000-千禧年大獎.md`）、Hilbert 第 8 題。
- **素數定理的路徑**：Riemann 的顯式公式 → Hadamard–de la Vallée Poussin（1896）的證明（不用黎曼假設）——**素數定理的誕生**。
- **隨機矩陣的連結**：Montgomery 對關聯與 GUE——**數論與量子混沌的意外橋樑**（Wigner 的隨機矩陣，見 `../量子力學/README.md`）。
- **Hilbert–Pólya 譜理論**：若找到算子，假設立即成立——**數論的「物理化」**（Berry–Keating 的 Hamiltonian）。
- **密碼學的間接連結**：素數分佈影響 RSA 的金鑰安全性分析（見 `../密碼學/1977-RSA.md`）——但密碼學不依賴黎曼假設。
- **黎曼的雙棲**：幾何（1854，見 `1854-Riemann幾何.md`）與數論（1859）——**40 歲早夭的雙棲天才**。
