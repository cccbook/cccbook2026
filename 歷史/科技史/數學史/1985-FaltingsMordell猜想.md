# 1985 - Faltings Mordell 猜想

## 案件摘要
1983 年，31 歲的德國數學家 Gerd Faltings 證明 **Mordell 猜想**（1922）：虧格 $\ge 2$ 的代數曲線上**只有有限多個有理點**——「有限性」的證明（不是找全部點，是證明「沒有無窮多」）。**數論的世紀突破**——Wiles 費馬定理（1995，見 `1994-Wiles費馬定理.md`）的重要前奏（費馬曲線 $x^n + y^n = z^n$ 虧格 > 1——**有限性暗示 Fermat 的方向**）。**Faltings 獲 Fields 1986**——**用 Arakelov 幾何與 Galois 上同調的深水**。

## 前因 -- 為什麼會有這個案子
**有理點的譜系**：

- **虧格 0**（直線、圓）：有理點**無窮或無**（圓 $x^2+y^2=1$ 有無窮多——參數化）
- **虛格 1**（橢圓曲線 $y^2 = x^3 + ax + b$）：有理點形成**群**——**有限生成**（Mordell 1922 證明）但**可能無窮多**（秩 $> 0$）
- **虛格 $\ge 2$**：**Mordell 猜想**——**只有有限多個有理點**

**Mordell 的猜想（1922）**：虧格 $\ge 2$ 的曲線只有**有限多**有理點——**直覺**：曲線越「彎」，有理點越少。

**65 年的攻擊**（1922–1983）：
- **Weil（1928）**：函數域版本（有限域上的曲線）——**有限域的對應先解決**
- **Tate（1960s）**：Galois 上同調的視角——**Tate 模組**
- **Arakelov（1974）**：**Arakelov 幾何**——把數論曲線「幾何化」（加上無窮遠的度量）——**Faltings 的工具**

**Faltings 的問題**：數論曲線（整數上的曲線）的有理點有限性——**答案：是**。

## 線索與推理 -- 數學式、程式、理論

### 有理點與虧格
**三種曲線的對照**：

| 虧格 | 曲線 | 有理點 |
|------|------|--------|
| 0 | 直線、圓 | 無窮（參數化）或無 |
| 1 | 橢圓曲線 | 有限生成的群（Mordell 1922） |
| $\ge 2$ | 一般曲線 | **有限多**（Faltings 1983） |

**直覺**：曲線越彎（虧格越高），有理點越稀——**「彎曲排斥有理數」**。

**與 Fermat 的連結**：費馬曲線 $x^n + y^n = z^n$（$n \ge 4$）虧格 $> 1$——**Faltings 的有限性**：費馬方程只有**有限多**本原解——**離「無解」（Fermat 定理）更近一步**（有限性不是無解，但**方向正確**——Wiles 1995 終結）。

### Faltings 的證明
**證明骨架**（Arakelov 幾何 + Galois 上同調）：

1. **反證**：假設有理點無窮多——**無窮多次「新的」有理點**
2. **Height（高度）**：有理點的「複雜度」（分子分母的大小）——**高度無界增長**
3. **Galois 表示**：每個有理點給出一個 Galois 表示（Tate 模組）——**表示的集合有限**（Weil 的定理）
4. **矛盾**：無窮多有理點 ⟹ 無窮多高度 ⟹ 與**表示的有限性**矛盾——**有限性**。$\blacksquare$

**深遠之處**：**「無窮多 ⟹ 某種重複」**——**與 Cantor 對角線、Pigeonhole（Ramsey）同源**：**無窮與有限的張力**——數論的「有限性」證明與組合的「必然規律」是同一哲學。

### 程式碼：有理點與高度

```python
from math import gcd

def rational_points_ellipse(N=50):
    """單位圓 x²+y²=1 的有理點（虧格 0：無窮多，參數化）"""
    points = []
    for t in range(1, N):
        # 參數化：x = (1-t²)/(1+t²), y = 2t/(1+t²)
        x, y = (1-t*t)/(1+t*t), 2*t/(1+t*t)
        points.append((x, y))
    return points

def height(p, q):
    """有理數 p/q 的高度：max(|p|, |q|)"""
    g = gcd(abs(p), abs(q))
    return max(abs(p)//g, abs(q)//g)

# 虧格 0：無窮多有理點（參數化）
pts = rational_points_ellipse()
print(f"單位圓（虧格 0）的有理點：{pts[:3]}... 無窮多 ✓")

# 虧格 ≥ 2：有限多（Faltings 1983）
print("\n費馬曲線 x⁴+y⁴=z⁴（虧格 2）：有限多有理點（Faltings 1983）")
print("——離『無解』（Fermat 定理 1995）更近一步")

# 高度的直覺：分子分母的複雜度
for p, q in [(1, 2), (3, 7), (355, 113)]:
    print(f"{p}/{q} 的高度 = {height(p, q)}")
# 高度增長快於有理點的數量——有限性的直覺

print("\nFaltings 1983：虧格 ≥ 2 的曲線只有有限多有理點")
print("Fields 1986——Arakelov 幾何與 Galois 上同調的深水")
```

### 譜系與影響
**Wiles 的前奏**：
- **Faltings（1983）**：虧格 ≥ 2 的有限性——**費馬的方向**
- **Frey–Ribet（1985–86）**：Frey 曲線——**費馬 ⟹ 谷山–志村**
- **Wiles（1995）**：**費馬定理的終結**——**Langlands 的 n=2**（見 `1967-Langlands綱領.md`）

**偵探筆記**：Faltings 的推理是「**有限性的哲學**」——不是找點，而是證明「無窮多 ⟹ 重複 ⟹ 矛盾」。**與 Cantor 對角線（見 `1874-Cantor集合論.md`）、Ramsey 定理（見 `1930-Ramsey理論.md`）同源的「無窮與有限」張力**：**數論的有限性證明**——不找全部解，證明解有限。

## 結案 -- 後果與影響
- **數論的世紀突破**：虧格 ≥ 2 的有限性——**有理點理論的里程碑**。
- **Wiles 的前奏**：費馬曲線的有限性——**離 Fermat 定理更近**（見 `1994-Wiles費馬定理.md`）。
- **Arakelov 幾何的誕生**：數論曲線的「幾何化」——**數論與幾何的橋樑**（與 Langlands 綱領的幾何化同源，見 `1967-Langlands綱領.md`）。
- **Fields 1986**：Faltings——**德國數論的復興**（Gauss、Riemann 的傳統）。
- **BSD 猜想的視角**：橢圓曲線（虧格 1）的有理點群——**千禧年大獎的姊妹題**（見 `2000-千禧年大獎.md`）。
- **有限性的哲學**：無窮 ⟹ 重複的矛盾——**數論證明的標準模式**。
