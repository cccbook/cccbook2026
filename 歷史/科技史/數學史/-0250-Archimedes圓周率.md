# 前 250 - 阿基米德圓周率

## 案件摘要
約西元前 250 年，敘拉古的阿基米德（Archimedes）用**窮竭法**測量圓周率：內接與外切正多邊形（96 邊形），夾逼出

$$3\frac{10}{71} < \pi < 3\frac{1}{7}$$

（即 $3.1408 < \pi < 3.1429$）——人類第一次給 π 一個**嚴格的誤差界**。他還發現球體積與圓柱體積的關係（$V_{球} = \frac{2}{3}V_{柱}$，墓碑上刻的就是這個）、浮力原理、槓桿原理——**古代最偉大的數學家與物理學家**，窮竭法是微積分（1665，見 `1665-Newton微積分.md`）的兩千年前身。

## 前因 -- 為什麼會有這個案子
古代對圓的困惑：圓周率是多少？巴比倫用 $3\frac{1}{8}$、埃及用 $\frac{256}{81} \approx 3.16$——**經驗值，沒有誤差界**。問題：π 是無理數（1882 年 Lindemann 才證明），小數無限不循環——**如何「測量」一個無窮的量？**

阿基米德的環境：敘拉古（西西里），希臘化時代的學術中心。他師承歐多克索斯（Eudoxus）的窮竭法傳統（《幾何原本》第 V 卷，見 `-0300-Euclid幾何原本.md`）——**用有限的步驟夾逼無窮的量**。

## 線索與推理 -- 數學式、程式、理論

### 窮竭法：內接與外切多邊形
**夾逼**：圓的周長被內接與外切正多邊形夾住：

$$P_{內接} < C < P_{外切}$$

從正六邊形開始（$P_{內接} = 6r$，即 $\pi > 3$），**邊數倍增**：12、24、48、96 邊形。每倍增一次，多邊形更貼近圓——**誤差每次約縮小 4 倍**（$O(1/n^2)$ 收斂）。

**阿基米德的計算**：96 邊形時（$n = 96$）：

$$3\frac{10}{71} < \pi < 3\frac{1}{7}$$

誤差界 $0.002$——**沒有計算機，用分數手算**，每一步都嚴格（不用近似小數）。

### 夾逼的數學
$n$ 邊形內接的周長：

$$P_n = 2nr \sin\frac{\pi}{n} \approx 2nr\left(\frac{\pi}{n} - \frac{\pi^3}{6n^3}\right)$$

誤差 $O(1/n^2)$——**每倍增邊數，誤差縮 4 倍**。這個「誤差階」的分析是 2200 年後的語言，但阿基米德實際做的是**嚴格的不等式**（窮竭法不用極限，用歸謬）：

$$\text{假設 } C > P_{外切} \implies \text{存在多邊形夾在圓與外切多邊形之間} \implies \text{矛盾}$$

——**窮竭法的證明不用「無窮」，用反證**。這是希臘數學對「無窮」的恐懼（芝諾悖論）的回應：**不用無窮，也能處理無窮的量**。

### 球體積：墓碑上的定理
阿基米德最自豪的發現（墓碑刻的）：**球體積 = 外接圓柱的 2/3**：

$$V_{球} = \frac{4}{3}\pi r^3 = \frac{2}{3} \cdot (2\pi r^2 \cdot 2r) \cdot \frac{1}{2} \cdot \ldots \quad \text{更精確：} V_{柱} = 2\pi r^3, \quad V_{球} = \frac{2}{3} V_{柱}$$

**證明方法**：把球與圓柱切片，用**槓桿平衡**（物理方法！）——每片的重心距離不同，槓桿原理給出體積關係。**用物理證明數學**——阿基米德的《方法論》（1906 年才被發現的羊皮書）記載了這個「非嚴格但天才」的方法。

### 程式碼：窮竭法逼近 π

```python
import math

def archimedes_pi(sides=96):
    """阿基米德窮竭法：內接與外切多邊形夾逼"""
    # 內接多邊形周長 / 直徑
    p_in = sides * math.sin(math.pi / sides)
    # 外切多邊形周長 / 直徑
    p_out = sides * math.tan(math.pi / sides)
    return p_in, p_out

for n in [6, 12, 24, 48, 96]:
    lo, hi = archimedes_pi(n)
    print(f"{n:3d} 邊形：{lo:.5f} < π < {hi:.5f}（誤差 < {hi-lo:.5f}）")
# 96 邊形：3.1410 < π < 3.1427——阿基米德的精度
# 邊數倍增，誤差約縮 4 倍：O(1/n^2) 收斂

# 驗證誤差階
print(f"\n誤差比（6→12）：{(archimedes_pi(12)[1]-archimedes_pi(12)[0]) / (archimedes_pi(6)[1]-archimedes_pi(6)[0]):.2f}")
print(f"誤差比（48→96）：{(archimedes_pi(96)[1]-archimedes_pi(96)[0]) / (archimedes_pi(48)[1]-archimedes_pi(48)[0]):.2f}")
# ≈ 4：平方收斂的指紋
```

### 阿基米德之死（前 212）
第二次布匿戰爭，羅馬圍攻敘拉古。阿基米德設計守城武器（槓桿投石機、聚焦鏡燒船——後者存疑）。城破時，羅馬士兵殺了他——他正在沙地上畫幾何圖形，說「別踩壞我的圓」（Noli turbare circulos meos）。**數學至死的典範**。

## 結案 -- 後果與影響
- **窮竭法 → 微積分**：阿基米德的夾逼是牛頓極限（1665，見 `1665-Newton微積分.md`）與積分（面積）的兩千年前身——牛頓自認站在阿基米德肩上。
- **π 的譜系**：阿基米德（96 邊形）→ 劉徽（263 年，割圓術）→ 祖沖之（480 年，$3.1415926 < \pi < 3.1415927$）→ Machin（1706，分析式）→ 電腦（蒙地卡羅，見 `../隨機算法/1777-Buffon針實驗.md`）。
- **物理與數學的統一**：阿基米德用槓桿證明體積——物理直覺作為數學證明的嚮導（嚴格證明再補）。
- **「不用無窮處理無窮」**：窮竭法對芝諾悖論的回應——極限概念的前身。
- **π 是無理數**：1882 年 Lindemann 證明 π 是超越數——尺規不可能化圓為方（阿基米德時代無法知道的答案）。
