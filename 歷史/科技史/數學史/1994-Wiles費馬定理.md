# 1994 - Wiles 費馬定理

## 案件摘要
1994 年 9 月 19 日，Andrew Wiles 在 8 年秘密研究的絕望時刻，突然看到最後的線索——**橢圓曲線的岩澤理論補完變換**。1995 年發表：**費馬最後定理**成立——$n \ge 3$ 時 $x^n + y^n = z^n$ 無正整數解。這個 1637 年 Fermat 在書頁邊寫下「我有一個絕妙的證明，可惜這裡空白太小寫不下」的註記，358 年懸案終結。**Wiles 的證明不只解決費馬，還證明了谷山–志村猜想的一半**——橢圓曲線與模形式的統一，數論的世紀勝利。

## 前因 -- 為什麼會有這個案子
**1637 年**，Fermat 在 Diophantus《算術》的書頁邊寫下：

$$x^n + y^n = z^n \text{ 無正整數解（} n \ge 3\text{）} \quad \text{「我有一個絕妙的證明，此處空白太小」}$$

**358 年的攻擊**：
- **Fermat 自己**：$n = 4$（無窮下降法）
- **Euler（1770）**：$n = 3$——證明有漏洞（後補）
- **Dirichlet / Legendre（1825）**：$n = 5$
- **Lamé / Kummer（1847）**：一般攻擊——**Kummer 的理想數**（代數數論的誕生！）證明一類素指數（正則素數）
- **Goro Shimura / Yutaka Taniyama（1955–57）**：**谷山–志村猜想**——每個橢圓曲線都是模形式
- **1985 年 Frey 的轉折**：Fermat 反例 → 構造「奇怪的橢圓曲線」——**若谷山–志村猜想成立，則 Fermat 成立**（Frey 曲線不是模形式）

**Wiles 的路徑**：證明谷山–志村猜想的**半穩定**情況 → Fermat 成立。

**Wiles 的秘密研究**：1986 年起（35 歲，Princeton 教授），**7 年完全秘密**（連學生都不知道）——在閣樓工作、用假論文做掩護。1993 年 6 月劍橋演講宣稱證明——**1993 年秋發現漏洞**（岩澤理論不夠）——絕望 14 個月。

## 線索與推理 -- 數學式、程式、理論

### Frey 曲線的轉折
**推理（Frey 1985）**：假設 $x^n + y^n = z^n$ 有正整數解（$n \ge 4$），構造橢圓曲線：

$$E_{a,b}: y^2 = x(x - a^n)(x + b^n)$$

**Frey 曲線的奇怪性質**：判別式 $= (ab)^{2n}(a^n + b^n)^2 = (abz)^{2n}$——**完美得不可能**（一般橢圓曲線的判別式雜亂）。

**Ribet 的定理（1986）**：Frey 曲線**不是模形式**——**若谷山–志村猜想成立（每個橢圓曲線都是模形式），則 Fermat 反例不可能存在**：

$$\text{Fermat 反例} \implies \text{Frey 曲線} \implies \text{非模形式} \implies \text{違反谷山–志村}$$

**橋樑**：費馬問題化為**橢圓曲線與模形式的統一**——數論的中心問題。

### 谷山–志村猜想與橢圓曲線
**橢圓曲線**：$y^2 = x^3 + ax + b$（見 `../密碼學/2005-橢圓曲線密碼學.md` 的群運算）——**每條曲線有一個「L-函數」**（算術的指紋）。

**模形式**：上半平面的高度對稱函數 $f(z)$（$f(\frac{az+b}{cz+d}) = (cz+d)^k f(z)$）——**傅立葉係數** $a_n$ 編碼數論資訊。

**谷山–志村猜想**：每個（有理）橢圓曲線的 L-函數 = 某模形式的傅立葉級數——**算術與分析的統一**（與歐拉 ζ 函數的傳統同源，見 `1734-Euler巴塞爾問題.md`）。

**Wiles 的證明（1994–95）**：半穩定橢圓曲線都是模形式——用**岩澤理論**（Iwasawa theory，$p$-進的上升方法）+ **Kolyvagin–Flach** 方法 + **橫截變換**（1934 年 Euler 式的「最後一步補丁」，見 `1734-Euler巴塞爾問題.md`）。

**1994 年 9 月 19 日**：Wiles 與學生 Taylor 檢視 Kolyvagin–Flach 的失效處，突然看到：**岩澤理論的補完可以替代**——「難以描述的解脫時刻」（indescribable moment）。1995 年兩篇論文發表（《Annals of Mathematics》）。

### 程式碼：費馬方程的檢驗

```python
import math

# 費馬最後定理：n >= 3 時 x^n + y^n = z^n 無正整數解
def fermat_search(n, limit=100):
    """搜尋反例（不會找到——定理保證）"""
    for x in range(1, limit):
        for y in range(x, limit):
            z = (x**n + y**n) ** (1/n)
            if abs(z - round(z)) < 1e-9 and round(z) > 0:
                return (x, y, round(z))
    return None

# n = 2（畢氏定理）：有解！
print(f"n=2：{fermat_search(2, 50)}")        # (3, 4, 5)——畢氏三元組

# n = 3, 4, 5：無解（費馬最後定理）
for n in [3, 4, 5]:
    print(f"n={n}：{fermat_search(n, 50)}")  # None

# 畢氏三元組的生成（n=2 的完整理論）
def pythagorean_triples(m, k):
    """x = k(m²-n²), y = 2kmn, z = k(m²+n²)"""
    a, b = m*m - k*k, 2*m*k
    return a, b, m*m + k*k

print(f"\n畢氏三元組（m=2,k=1）：{pythagorean_triples(2, 1)}")   # (3, 4, 5)
print("n=2 有無窮多解（畢氏定理）；n≥3 無解（費馬最後定理 1995）")
```

### 358 年的譜系
**攻擊者的貢獻**（每個失敗都產生新數學）：
- **Euler（1770）**：$n=3$——複數的早期使用
- **Kummer（1847）**：理想數——**代數數論的誕生**（環論的先聲）
- **Frey–Ribet（1985–86）**：Frey 曲線——橢圓曲線的轉折
- **Wiles（1995）**：谷山–志村的半穩定情況——**橢圓曲線理論的世紀勝利**

**Fermat 的註記是真的嗎？**——現代共識：**Fermat 大概沒有完整證明**（他用的無窮下降法不夠），可能是**錯誤的證明**或僅對 $n=4$。**書頁邊的自信與 358 年的空白**——數學史上最大的「空白太小」之謎。

## 結案 -- 後果與影響
- **358 年懸案終結**：費馬最後定理成立——數學史上最多人攻擊的問題之一。
- **谷山–志村猜想的勝利**：橢圓曲線與模形式的統一——**數論的中心橋樑**（全猜想在 2001 年由 Breuil–Conrad–Diamond–Taylor 證明）。
- **新數學的果實**：Kummer 的理想數（代數數論）、Frey 曲線（橢圓曲線）、岩澤理論——**每個失敗都產生新數學**。
- **Langlands 綱領**：谷山–志村是 Langlands 大統一（數論與表示論）的一角——21 世紀數學的中心。
- **秘密研究的範式**：Wiles 的 7 年秘密——數學的「深潛」文化（與現代的開放科學對照）。
- **Fermat 的正名**：書頁邊的註記大概是錯的——但**問題本身改寫了數論**。
