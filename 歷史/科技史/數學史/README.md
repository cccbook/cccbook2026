# 數學史 -- AI 偵探風格

以「推理探案」的方式，追查數學從歐幾里得的《幾何原本》到佩雷爾曼的龐加萊猜想的每一步：
前因是什麼？線索在哪裡？推理如何展開？後果又如何改變了整個人類文明？

數學史的核心脈絡是：**從「算」到「證」到「抽象」**——從計數與測量，到公理化證明，到集合論與結構的抽象——每一步都是對「什麼是數學」的重新定義。
