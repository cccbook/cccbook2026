# 前 250 年 — Archimedes 窮竭法

## 案件摘要
約公元前 250 年，敘拉古的 Archimedes 在〈拋物線弓形求積〉〈論圓的測量〉等著作中，用「窮竭法」（method of exhaustion）配合幾何級數求和，證明了拋物線弓形面積等於內接三角形面積的 $4/3$ 倍，並以 96 邊形逼近把圓周率夾在 $3\frac{10}{71}$ 與 $3\frac{1}{7}$ 之間。這是人類史上第一次系統地「用無限逼近去計算面積」——積分思想的遠古原型。

## 前因 -- 為什麼會有這個案子
- 公元前 5 世紀，Pythagoras 學派發現正方形的對角線與邊**不可公度**（比值不是兩個整數之比，即 $\sqrt{2}$ 是無理數），希臘數學陷入「量危機」：長度可以是無理數，那麼面積、體積的計算還能信任嗎？
- 公元前 4 世紀，Eudoxus 建立了嚴格的「窮竭法」：不直接說「無限多個小片加起來」，而是用雙重歸謬法——給定任意小的餘量 $\varepsilon$，證明「不多於」且「不少於」，從而面積只能等於那個值。
- 拋物線弓形的面積恰好是 Euclid《幾何原本》沒有處理的問題，而 Archimedes 曾在致 Dositheus 的信中宣稱這是他的發現（其實是他自己說，此前 Democritus 曾「無嚴格證明地」知道某些曲面體積）。
- 案件的動機：希臘人不能用「無窮過程」作為證明工具，卻又想算出曲線圍出的面積——Archimedes 必須在**有限的邏輯框架內**駕馭無限的逼近。

## 線索與推理 -- 數學式、程式、理論

### 線索一：拋物線弓形與內接三角形
考慮拋物線 $y = x^2$ 上弦為 $AB$ 的弓形。取 $AB$ 中點正上方的頂點 $C$ 作內接三角形 $ABC$。Archimedes 證明：$C$ 恰好「填滿」弓形的中間部分，而剩餘的兩個小弓形又可以在 $AC$、$BC$ 上各補一個三角形，每一層的面積都是上一層的 $1/4$。

設第一個三角形面積為 $A_1$，則

$$S = A_1 + \frac{A_1}{4} + \frac{A_1}{16} + \frac{A_1}{64} + \cdots$$

這是一個公比 $r = \frac{1}{4}$ 的幾何級數，和為

$$S = \frac{A_1}{1 - \frac{1}{4}} = \frac{4}{3}A_1$$

Archimedes 的做法是：令部分和為 $S_n$，先證明 $S_n + \frac{1}{3}A_1 > S$ 恆成立（每次補上的三角形恰好是剩餘的 $2/3$ 再多一點），再用雙重歸謬法排除了「弓形面積大於 $S$」和「小於 $S$」兩種可能——窮竭而不窮盡，邏輯滴水不漏。

### 線索二：以現代語言重寫
用現代積分語言，取弦端點在 $x = -1$ 與 $x = 1$，弓形面積為

$$S = \int_{-1}^{1} (1 - x^2)\,dx = \left[x - \frac{x^3}{3}\right]_{-1}^{1} = \frac{4}{3}$$

而內接三角形 $ABC$ 的底為 $2$、高為 $1$，面積 $A_1 = 1$。故 $S = \frac{4}{3}A_1$，與 Archimedes 的結果完全一致。換句話說，Archimedes 在兩千多年前就算出了 $\int_{-1}^{1}(1-x^2)\,dx = \frac{4}{3}$。

### 線索三：圓周率的多邊形逼近
Archimedes 用內接與外切正多邊形夾逼圓：半徑 $r$ 的圓，內接正 $n$ 邊形周長 $P_{\text{in}} = 2nr\sin(\pi/n)$，外切正 $n$ 邊形周長 $P_{\text{out}} = 2nr\tan(\pi/n)$。從正六邊形開始，每次邊數加倍，他只用倒數關係遞推（不顯式使用三角函數）：

$$\cot(\theta/2) = \cot\theta + \csc\theta, \qquad \sec\text{ 亦同理遞推}$$

推到 96 邊形時得到

$$3\frac{10}{71} < \pi < 3\frac{1}{7}$$

同時他在〈論圓的測量〉命題 2 證明：圓面積等於以半徑為股、周長為勾的直角三角形面積，即 $A = \frac{1}{2}r \cdot (2\pi r) = \pi r^2$——同樣用窮竭法證成。

### 線索四：靜力平衡的「力學方法」
Archimedes 另有一件祕密武器：在《方法》（The Method，1906 年才被 Heiberg 在君士坦丁堡發現的重寫本中尋回）中，他把面積切成無限多條線段，掛在槓桿兩端，用**靜力平衡**「秤出」面積。例如球體積 $\frac{4}{3}\pi r^3$ 就是這樣被「秤」出來的。他自己也承認：力學方法只是發現工具，最終仍需幾何證明背書。

### 程式碼範例：窮竭法多邊形逼近 π 與幾何級數驗證
```python
import numpy as np

# (1) Archimedes 96 邊形逼近 pi
def archimedes_pi(n):          # n: 邊數（從 6 開始倍增）
    # 內接正 n 邊形邊長遞推：從六邊形邊長 = 半徑開始
    s = 1.0                    # 半徑 r=1，正六邊形邊長
    m = 6
    while m < n:
        s = np.sqrt(2 - 2*np.sqrt(1 - (s/2)**2))  # 倍邊公式
        m *= 2
    return 2 * m * s / 2 / 2   # 周長/2 = pi 近似（r=1: P/2=pi）

for n in [6, 12, 24, 48, 96]:
    print(f"內接{n}邊形: pi ≈ {2*n*np.sin(np.pi/n):.6f}")

# (2) 拋物線弓形 = 4/3 * 三角形：幾何級數部分和收斂
A1 = 1.0
S, term = 0.0, A1
for k in range(1, 25):
    S += term
    term /= 4
print(f"級數和 S = {S:.10f}, 4/3 = {4/3:.10f}")

# (3) 數值積分驗證 ∫_{-1}^{1}(1-x^2)dx
x = np.linspace(-1, 1, 100000)
print("數值積分 =", np.trapz(1 - x**2, x), "（理論 4/3）")
```

程式輸出顯示：內接 96 邊形給出 $\pi \approx 3.14103$，落在 Archimedes 的區間內；幾何級數部分和收斂到 $4/3$；數值積分 $\int_{-1}^{1}(1-x^2)\,dx = 1.3333\ldots$，正是弓形面積。

### 線索五：為何是 4/3 而不是更複雜的數
值得注意：拋物線弓形給出的答案是 $\frac{4}{3}$ 這樣的**有理數**——但這純屬巧合嗎？不是。Archimedes 還證明了螺旋線第一圈與圓的面積之比為 $1:3$、球與其外切圓柱的體積之比為 $2:3$（他甚至要求把圓柱嵌球的圖刻在他的墓碑上）。這些簡潔的比值顯示：曲線圍出的面積可以被**有理比**精確捕捉，前提是你要有正確的逼近程序。窮竭法的威力正在於此——它證明的不是近似值，而是精確的等式。

## 結案 -- 後果與影響
- 窮竭法成為希臘數學處理曲面積/體積的**標準工具**，但雙重歸謬法繁瑣，每個問題都要個別設計。
- Archimedes 的〈拋物線弓形求積〉與《方法》手抄本流傳千年，成為 Cavalieri、Fermat、Wallis 等人重新發現積分的起點。
- $\frac{4}{3}$ 的幾何級數、多邊形逼近 $\pi$，是「無限過程可以有有限答案」最早的可信案例。
- 212 BC，Archimedes 在第二次布匿戰爭中死於羅馬士兵之手，據 Plutarch 記載他臨死前仍在沙盤上畫幾何圖。
- 手抄本經 Byzantium 的 Eutocius 註釋、9 世紀阿拉伯譯本、16 世紀拉丁譯本（Tartaglia 1543、Commandino 1558）層層流轉，最終在文藝復興的歐洲重見天日——積分的火種穿越了 1800 年。
- 案件的影響：窮竭法的精神（用有限邏輯駕馭無限逼近）在 19 世紀 Weierstrass 的 $\varepsilon$-$\delta$ 語言中重生——Archimedes 的作案手法跨越兩千年仍是標準。
