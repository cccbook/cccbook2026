# 中等-彈簧振子的相空間與能量守恆

## 題目
一個質量 m = 1 kg 的物體掛在彈簧上（彈力常數 k = 4 N/m），在光滑水平面上振動。
1. 寫出哈密頓量。
2. 畫出相空間（x-p 平面）軌道的形狀。
3. 證明哈密頓量沿著軌道保持不變。

## 解說

### 第 1 步：哈密頓量

$$H = \frac{p^2}{2m} + \frac{1}{2}kx^2 = \frac{p^2}{2} + 2x^2$$

### 第 2 步：正則方程

$$\dot{x} = \frac{\partial H}{\partial p} = \frac{p}{m} = p$$
$$\dot{p} = -\frac{\partial H}{\partial x} = -kx = -4x$$

直觀解讀：
- 第一條：「動量就是位置的前進方向和快慢」
- 第二條：「彈簧把動量往中間拉」（x 在右邊時 p 變負，往左推）

### 第 3 步：相空間軌道

把能量固定為 E，則軌道滿足：

$$\frac{p^2}{2} + 2x^2 = E$$

這是一個**橢圓**！例如 E = 8 時：

$$\frac{x^2}{4} + \frac{p^2}{16} = 1$$

- x 方向半軸 = 2（最大位移 2 m）
- p 方向半軸 = 4（最大動量 4 kg·m/s）

**相空間圖**（想像一個點在橢圓上逆時針跑圈圈）：

```
        p
        ↑
      4 |   ● ● ●
        | ●       ●
   ─────●────●────●───→ x
   -2   |         2
        | ●       ●
     -4 |   ● ● ●
```

物體在最右邊時（x = 2, p = 0）動能為零、位能最大；
衝過中間時（x = 0）動能最大；就這樣週而復始。

### 第 4 步：證明能量守恆

對 H 求時間導數（用鏈鎖法則）：

$$\frac{dH}{dt} = \frac{\partial H}{\partial x}\dot{x} + \frac{\partial H}{\partial p}\dot{p}$$

代入正則方程 $\dot{x} = \partial H/\partial p$ 和 $\dot{p} = -\partial H/\partial x$：

$$\frac{dH}{dt} = \frac{\partial H}{\partial x}\cdot\frac{\partial H}{\partial p} + \frac{\partial H}{\partial p}\cdot\left(-\frac{\partial H}{\partial x}\right) = 0$$

兩項正好**互相抵消**！這不是巧合，而是哈密頓方程結構的美妙之處：
**只要 H 不直接依賴時間，能量就自動守恆。**

### 數值驗算
取 x = 1, p = 2（此時在軌道上嗎？）：H = 2²/2 + 2(1)² = 2 + 2 = 4 ≠ 8，
不在 E = 8 的軌道上。改取 x = 0, p = 4：H = 16/2 = 8 ✓

半秒後（用方程積分）：x(t) = 2sin(2t)，在 t = π/4 時 x = √2, p = 2√2·cos(2t)...

驗證：H = (2√2·cos(π/2))²/2 + 2(2sin(π/4))² = 0 + 2·2·(1/2) = ... 

直接驗證一般解 x = 2sin(2t), p = 4cos(2t)：
H = 16cos²(2t)/2 + 2·4sin²(2t) = 8cos²(2t) + 8sin²(2t) = 8 ✓ 永遠等於 8！

## 重點整理
1. 調和振子的相空間軌道是橢圓
2. dH/dt = ∂H/∂x·∂H/∂p - ∂H/∂p·∂H/∂x = 0（自動抵消）
3. 每一個橢圓對應一個固定的能量值
