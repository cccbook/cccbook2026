# 中等-拋體運動的最小作用量原理

## 題目
一顆球從原點 (0, 0) 以初速 v₀ = 10 m/s、仰角 45° 拋出（g = 10 m/s²）。
1. 用牛頓力學算出軌道和射程。
2. 說明「最小作用量原理」如何「一口氣」決定這條軌道。

## 解說

### 第 1 步：牛頓力學解法（複習）

水平方向不受力：x(t) = v₀cos45°·t = 10·(√2/2)·t ≈ 7.07t
鉛直方向受重力：y(t) = v₀sin45°·t - ½gt² = 7.07t - 5t²

落地時 y = 0：5t² = 7.07t → t = 1.414 秒

射程 = 7.07 × 1.414 ≈ **10 公尺**

（順帶一提：45° 時射程 v₀²/g = 100/10 = 10，正是最大射程的角度！）

### 第 2 步：拉格朗日量與作用量

哈密頓力學的思想源頭是**最小作用量原理**（Maupertuis, 1744）：

> 大自然會選擇讓「作用量」S 最小的那條路徑。

作用量的定義（拉格朗日版本）：

$$S = \int_{0}^{T} L \, dt, \qquad L = K - V = \frac{1}{2}m(\dot{x}^2+\dot{y}^2) - mgy$$

注意：L 是「動能**減**位能」，跟哈密頓量 H = K + V 的加號不同！

### 第 3 步：變分法的直觀理解

想像把球可能走的路徑畫出來，每一條都算一個 S 分數：

- 走得太平：位能項貢獻小，但為了準時到達必須速度快，動能項爆增
- 走得太高：位能項 mgy 累積太多
- 走拋物線：剛剛好，S 最小！

數學上，令 S 最小的條件是「尤拉-拉格朗日方程」：

$$\frac{d}{dt}\frac{\partial L}{\partial \dot{y}} - \frac{\partial L}{\partial y} = 0$$

代入計算：
- ∂L/∂ẏ = mẏ → d/dt(mẏ) = mÿ
- ∂L/∂y = -mg

所以 mÿ - (-mg) = 0 → **ÿ = -g**，正是重力！

x 方向同理可得 ẍ = 0。

### 第 4 步：比較兩種方法

| | 牛頓力學 | 最小作用量原理 |
|---|---|---|
| 出發點 | 力與加速度 | 能量與整條路徑 |
| 解法 | 逐步積分 | 一次變分決定全程 |
| 觀點 | 「現在」推「下一刻」 | 「起點」與「終點」之間挑最佳路徑 |
| 哲學 | 因果式 | 目的式（像大自然已先看完整局） |

費曼（Feynman, 1948）把這個思想帶進量子力學：粒子其實**同時走所有路徑**，
只是作用量小的路徑貢獻最大。拋體運動的拋物線，就是所有路徑「合作」的結果。

## 重點整理
1. L = K − V（減），H = K + V（加），千萬別搞混
2. 45° 拋射射程最大：R = v₀²/g
3. 最小作用量原理 ⟺ 尤拉-拉格朗日方程 ⟺ 牛頓定律，三種講法同一件事
