# 1788 - Lagrange《分析力學》(Mécanique analytique)

## 案件摘要
1788 年（巴黎大革命前夕），Lagrange 出版《分析力學》。
全書**沒有一張圖**——Lagrange 在序言中自豪地說：「書中找不到任何圖形；我使用的方法既不需要作圖，也不需要幾何或力學的論證，只需要代數運算。」
牛頓以來 120 年的向量式力學，被重寫為純解析的架構。**Euler–Lagrange 方程**正式定名，
廣義座標 $q_i$、廣義力、虛功原理成為標準術語。這是「力 → 能量」革命章節的正式結案。

## 前因
- **變分法的一般方法（1755）**：Lagrange 手上已有發動機，缺的是完整成品。
- **虛功原理**：D'Alembert（1743）已把靜力學虛功與動力學合併（d'Alembert 原理），
  $$\sum_i (\vec F_i - m_i \vec a_i)\cdot \delta \vec r_i = 0$$
  但表述繁瑣、未系統化。
- **約束系統的痛點**：單擺的張力、剛體的內力——牛頓形式必須顯式算出每個約束力，才能解出運動。
- **Lagrange 的野心**：寫一本「一次講完所有力學」的書，讓約束自動消失。

## 線索與推理

### 第一步：虛功原理的解析化
設系統有 $n$ 個廣義座標 $q_1,\dots,q_n$（$N$ 質點、$k$ 個約束，$n = 3N - k$），位置 $\vec r_i(q, t)$。
虛位移 $\delta\vec r_i = \sum_j \dfrac{\partial \vec r_i}{\partial q_j}\delta q_j$，理想約束（約束力不做虛功）⇒

$$\sum_j \left( Q_j - \sum_i m_i \vec a_i \cdot \frac{\partial \vec r_i}{\partial q_j} \right)\delta q_j = 0$$

### 第二步：Lagrange 的恆等式（d'Alembert 原理的化簡）
Lagrange 證明兩條恆等式（今日教科書標配）：
$$\frac{\partial \dot{\vec r}_i}{\partial \dot q_j} = \frac{\partial \vec r_i}{\partial q_j}, \qquad
\frac{d}{dt}\frac{\partial \vec r_i}{\partial q_j} = \frac{\partial \dot{\vec r}_i}{\partial q_j}$$
代入後定義廣義動量 $p_j = \dfrac{\partial T}{\partial \dot q_j}$、廣義力 $Q_j = \sum_i \vec F_i \cdot \dfrac{\partial \vec r_i}{\partial q_j}$，
得**拉格朗日方程**：
$$\boxed{\ \frac{d}{dt}\frac{\partial T}{\partial \dot q_j} - \frac{\partial T}{\partial q_j} = Q_j \ }$$
若力有位能 $V(q)$（$Q_j = -\partial V/\partial q_j$），則化為：
$$\frac{d}{dt}\frac{\partial L}{\partial \dot q_j} - \frac{\partial L}{\partial q_j} = 0, \qquad L = T - V$$

### 範例：單擺的「解放」
直角座標 + 張力（牛頓法）：兩個方程 + 一個未知約束力 $T_{ension}$，要消元。
廣義座標 $\theta$（拉格朗日法）：
$$L = \tfrac{1}{2}m\ell^2\dot\theta^2 - mg\ell(1-\cos\theta)
\;\Rightarrow\; \ddot\theta + \frac{g}{\ell}\sin\theta = 0$$
一個方程、一個變數、無約束力——**約束被結構性地藏起來**。

### 隱藏的伏筆：守恆量與循環座標
$L$ 不含某座標 $q_j$（「循環座標」）⇒ $\dfrac{d}{dt}\dfrac{\partial L}{\partial \dot q_j} = 0$ ⇒ 廣義動量 $p_j$ 守恆。
「對稱性 ⇒ 守恆量」的具體樣本——這個模式的一般性要到 Noether（1918）才完全揭曉（見 [1918-Noether定理.md](1918-Noether定理.md)）。

## 結案
- 解析力學成為 19 世紀力學的正統；「牛頓 vs 拉格朗日」的教科書之爭以「兩者等價、拉氏更強大」收場。
- 但 Lagrange 形式仍是「二階 + 配置空間」觀點；下一案的動機：**降到一階、換成相空間**——Hamilton 正則方程（見 [1834-Hamilton正則方程.md](1834-Hamilton正則方程.md)）。
- 歷史註腳：此書出版於 1788 年，正是法國大革命前一年；Lagrange 本人在革命中安然無恙，還主持了米制的制定。
