# 1959-平面製程

## 案件摘要
IC 發明後仍有一道未解難題：鍺與合金電晶體的接面暴露在外，一受污染即劣化。1959 年，Fairchild 八叛逆之一的 Jean Hoerni 用 SiO2 當「鈍化保鏢」並結合光微影，發明平面製程——所有接面藏於氧化層之下、元件全部在平面完成，IC 量產的大門自此開啟。

## 前因 -- 為什麼會有這個案子
- **接面裸露之禍**：點接觸與早期合金接面電晶體的表面暴露於空氣，水氣與離子沾污造成表面漏電、漂移，元件參數隨時間劣化。
- **Noyce 的需求**：IC 需要「元件間互不干擾」且可從上方佈線，欠缺一個能同時保護接面與定義圖案的製程。
- **前案累積**：柴氏矽單晶（1952）提供乾淨基板；矽天然生成穩定 SiO2——這是鍺沒有的天賦，成為本案關鍵線索。
- **背景人物**：1957 年 Shockley 半導體實驗室的八位青年集體出走創立 Fairchild 半導體，人稱**八叛逆（traitorous eight）**：Noyce、Moore、Hoerni、Kleiner、Last、Roberts、Blank、Grinich。這場「叛變」本身就是矽谷創業文化的起源案件。

## 線索與推理 -- 數學式、程式、理論

### 線索一：SiO2 鈍化層的保護作用
Hoerni 的關鍵洞察（1959.3 提出備忘錄）：SiO2 既絕緣又能**隔絕外界沾污**。若先長氧化層、再在氧化層上「開窗」進行擴散，接面側壁自然被 SiO2 覆蓋——接面藏在地下，表面污染無從下手。

氧化層生長服從 Deal–Grove 模型：

$$x_{ox}^2 + A\, x_{ox} = B\, t \quad \Rightarrow \quad x_{ox}(t) = \frac{A}{2}\left[\sqrt{1 + \frac{4Bt}{A^2}} - 1\right]$$

乾氧（$B$ 小）品質緻密、濕氧（$B$ 大）速度快；薄層用乾氧、厚場氧化用濕氧。

### 線索二：光微影（photolithography）流程
在 SiO2 上定義圖案的四步：

1. **塗佈**：晶圓旋轉塗上光阻（photoresist，~1 μm）。
2. **曝光**：透過光罩（mask）以紫外光照射；光阻可為正型（曝光處可溶）或負型。
3. **顯影**：顯影液溶去曝光（正型）或未曝光（負型）區域，圖案浮現。
4. **蝕刻**：以 HF 或電漿蝕刻掉無光阻保護的 SiO2，開出窗口；去膠後即得圖案化氧化層。

解析度受光的繞射極限限制，約：

$$R \approx 0.5\,\frac{\lambda}{NA}$$

從早期 contact print 到今日 EUV（$\lambda = 13.5\,\mathrm{nm}$），持續縮小——摩爾定律的每一節台階都踩在光微影上。

### 線索三：摻雜擴散與離子佈植
**擴散（1950–70 年代主流）**：高溫下雜質從表面往內擴散，濃度分佈：

- 恒定表面源（預沉積）：$C(x,t) = C_s\, \mathrm{erfc}\!\left(\dfrac{x}{2\sqrt{Dt}}\right)$
- 有限劑量（再驅入，高斯分佈）：$C(x,t) = \dfrac{Q}{\sqrt{\pi D t}}\, e^{-x^2/4Dt}$

**離子佈植（1970 年代起）**：雜質離子加速至 keV 級打入晶圓，劑量精準可控，入射深度近似高斯：

$$C(x) = \frac{\phi}{\sqrt{2\pi}\,\Delta R_p}\, \exp\!\left[-\frac{(x - R_p)^2}{2\Delta R_p^2}\right]$$

其中 $\phi$ 為劑量（ions/cm²），$R_p$ 為投影射程，$\Delta R_p$ 為標準差。佈植後經退火修復晶格損傷。

### 線索四：Noyce 平面 IC 與量產化
Noyce 採納 Hoerni 的平面製程，提出完整 IC 製作：氧化 → 開窗擴散形成電晶體與電阻 → 再氧化絕緣 → 蒸鍍鋁互連。全部元件與互連在**同一平面**完成，且所有 pn 接面受 SiO2 保護——這正是 1959 專利的核心，也是今日所有晶片的祖先。

### 製程流程圖

```
矽晶圓 ──┬─[熱氧化]──> SiO2 層
         │
         ├─[塗光阻]──[曝光(光罩)]──[顯影]──[蝕刻開窗]──[去膠]
         │
         ├─[擴散/離子佈植]──> 摻雜區（藏在窗下）
         │
         ├─[再氧化絕緣]──[開接觸窗]
         │
         └─[蒸鍍鋁互連]──[光微影定義金屬線]──> 平面 IC 完成
```

### Python 模擬：光微影曝光圖案（高斯光斑捲積）

```python
import numpy as np
import matplotlib.pyplot as plt

# 模擬光微影：光罩圖案與高斯光斑捲積 → 晶圓上的曝光劑量分佈
N = 400
x = np.linspace(0, 4, N)
# 光罩：兩條線（亮區=1）
mask = np.zeros(N)
mask[(x > 1.0) & (x < 1.3)] = 1
mask[(x > 2.5) & (x < 2.8)] = 1

def gaussian_kernel(sigma, n=100):
    k = np.linspace(-3*sigma, 3*sigma, n)
    return np.exp(-k**2 / (2*sigma**2)); 

dose = np.convolve(mask, gaussian_kernel(0.06), mode="same")
dose /= dose.max()

threshold = 0.5
pattern = (dose > threshold).astype(float)

fig, ax = plt.subplots(3, 1, sharex=True, figsize=(8, 6))
ax[0].plot(x, mask);  ax[0].set_ylabel("Mask")
ax[1].plot(x, dose);  ax[1].axhline(threshold, color="r", ls="--")
ax[1].set_ylabel("Dose")
ax[2].plot(x, pattern); ax[2].set_ylabel("Resist (post-dev)")
ax[2].set_xlabel("Position (μm)")
fig.suptitle("Photolithography: Mask ⊛ Gaussian Spot → Pattern")
plt.tight_layout()
plt.show()
```

模擬顯示：銳利的光罩圖案經高斯光斑（繞射/擴散）模糊後，以閾值顯影仍可還原兩條線，但邊角變圓、線寬略變——這就是光微影解析度極限的直觀成因。

## 結案 -- 後果與影響
- **量產化**：平面製程使元件可批量大規模、重複製作，良率與可靠度飛躍——IC 從 Kilby 的手工原型變成可年產數百萬顆的工業產品。
- 1960 年 Fairchild 用平面製程做出第一顆可量產 IC；1961 年 Noyce、Moore 離開創立 Intel，1971 年推出 4004 微處理器——全拜平面製程之賜。
- 八叛逆的「叛變」樹立矽谷範式：技術人員離開母公司創業、風險投資接力——Fairchild 子公司輩出，矽谷自稱「Fairchildren」。
- 平面製程與光微影構成至今所有半導體製造的骨架；60 餘年來結構未變，只有解析度持續縮小。
