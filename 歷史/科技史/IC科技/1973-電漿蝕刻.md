# 1973 - 電漿蝕刻：把圖案轉移從藥水槽搬進電漿腔

## 案件摘要
1970 年代，濕式蝕刻的罩門——各向同性鑽蝕（undercut）、廢液污染、難以控制線寬——讓次微米圖案轉移止步。
電漿蝕刻以 RF 電場游離氣體，用自由基與離子「邊化學啃、邊物理轟」，方向性可調。
1973 年前後商業化電漿蝕刻機問世，RIE 成為圖案轉移標準——今日 FinFET/GAA 的每道深溝，都是電漿刻出來的。

## 前因 -- 為什麼會有這個案子
- **濕式蝕刻的罩門**：HF、KOH 等藥液在所有方向等速啃蝕（isotropic），蝕 1 μm 深也同時橫向鑽 1 μm，圖案底部被掏空：

$$
\underbrace{CD_{\text{film}} = CD_{\text{mask}} - 2 \times \text{undercut}}_{\text{濕式：undercut = depth}} \quad\Rightarrow\quad \text{CD 隨蝕刻深度失控}
$$

- **廢液污染之禍**：大量 HF/鉻酸廢液處理成本高、污染環境，且藥液壽命漂移、批與批之間重現性差。
- **小幾何時代的剛需**：平面製程讓線寬一路縮小，當 $CD \lesssim 3\,\mu\mathrm{m}$，濕式的橫向鑽蝕就把電晶體通道與接觸窗吃壞。
- **關鍵推理**：若把蝕刻從「藥水槽的等向漫蝕」改成「電漿腔中的定向轟擊」，則化學反應選材料、離子轟擊定方向：

$$
\text{蝕刻} = \underbrace{\text{化學（自由基）}}_{\text{高選擇比}} \times \underbrace{\text{物理（離子轟擊）}}_{\text{方向性}} \quad\Longrightarrow\quad A_f \gg 1
$$

1960 年代 Bell Labs 實驗驗證電漿去膠與 Si/氮化矽蝕刻；1973 年前後商用機上市，乾式蝕刻自此改寫圖案轉移。

## 線索與推理 -- 數學式、程式、理論

### 線索一：電漿解剖——RF 電場裡的自由基與離子

$$\text{氣體 (CF}_4/\text{Cl}_2/\text{HBr)} \xrightarrow{\text{RF 電場游離}} \text{電漿} \left\{ \begin{array}{l} \text{電子} \\ \text{離子（受鞘層電場加速，垂直打向晶圓）} \\ \text{自由基（中性、四面八方擴散，負責化學蝕刻）} \end{array} \right.$$

1. **游離**：RF（13.56 MHz）電場把電子加熱，撞擊氣體分子產生離子與自由基。
2. **自由基化學蝕刻**：如 F 自由基與 Si 反應生成揮發性 SiF₄，等向性、高選擇比。
3. **離子物理轟擊**：鞘層電場把離子加速垂直轟擊表面，打破鈍化層、打出方向性。
4. **化學＋物理協同（ion-enhanced etching）**：離子轟擊揭露新鮮表面讓自由基反應，方向性與選擇比同時到手——這正是 RIE 的本質。

### 線索二：各向異性度 $A_f$ 與 undercut 公式

蝕刻方向性以縱向與橫向速率之比定義：

$$
A_f = \frac{\text{vertical rate}}{\text{lateral rate}}
$$

- 濕式蝕刻：$A_f \approx 1$（isotropic），蝕深 $d$ 則 undercut $\approx d$；
- RIE：$A_f = 10\text{–}100$（anisotropic），undercut 幾乎歸零。

最終 CD（critical dimension）：

$$
CD_{\text{film}} = CD_{\text{mask}} - 2 \times \text{undercut}, \qquad \text{undercut} = \frac{\text{lateral rate}}{\text{vertical rate}} \times d = \frac{d}{A_f}
$$

$A_f$ 越大，圖案越忠實轉移——**方向性就是 CD 的旋鈕**，旋鈕由腔體壓力、RF 功率與氣體化學共同控制。

### 線索三：蝕刻選擇比 $S$

蝕刻速率比：對下層（或光罩）要慢、對目標膜要快：

$$
S = \frac{\text{film rate}}{\text{mask rate}} \quad\text{或}\quad S = \frac{\text{film rate}}{\text{substrate rate}}
$$

- 選擇比低 → 光罩被啃掉（CD 失控）或下層被挖傷；
- 高選擇比靠氣體化學：CF₄/CHF₃ 對 SiO₂ 選擇、Cl₂/HBr 對多晶矽選擇，皆由自由基種類與離子能量調控。
- 過蝕容許度：若需 20% 過蝕，選擇比須滿足 $S \times 0.2 \times (\text{film thickness ratio}) \ll 1$——選擇比是良率的命脈。

### 線索四：RIE、平行板與 ICP

- **圓桶式電漿蝕刻（barrel）**：純化學、等向性，適合去膠。
- **平行板 RIE（1970s 主力）**：晶圓接陰極，自偏壓 $V_{dc}$ 把離子加速垂直轟擊——化學與物理兼備，方向性蝕刻的標準機型。
- **ICP（inductively coupled plasma, 1990s）**：獨立線圈高密度游離（離子密度高 10–100 倍），基板偏壓另控——**游離與轟擊解耦**，高密度＋低損傷＋高方向性，深次微米與高深寬比蝕刻的主力。
- **氣體化學分線**：CF₄/O₂、CHF₃ 蝕 SiO₂/Si₃N₄；Cl₂、HBr、BCl₃ 蝕矽/鋁；氟系各向同性、氯/溴系易得方向性——氣體就是蝕刻的「配方」。

### 線索五：蝕刻輪廓的空間視角

沿垂直剖面看圖案轉移：光罩開口 $W$、蝕深 $d$、橫向速率 $v_l$、縱向速率 $v_v$：

```
光罩 ████████        ████████
     ────────┐        ┌────────
film      │  ← v_l │   v_v ↓
          └────────┘
          └─ CD ───┘  (CD = W − 2·v_l·t, d = v_v·t)
```

- **t = d/v_v** 時到達目標深度，此時 undercut = $v_l d / v_v = d/A_f$；
- 濕式（$A_f=1$）undercut = d，圖案呈半圓底；RIE（$A_f\gg1$）側壁垂直、底部平坦；
- 側壁鈍化（polymer passivation）是 RIE 拿高 $A_f$ 的手法：副產物聚合物沉積在側壁擋住橫向蝕刻，讓離子只能往下打。

### Python 實作：蝕刻輪廓與 CD 模擬

```python
def etch_profile(cd_mask, depth, Af, selectivity, mask_loss=0.0):
    """簡化 1D：給定縱深、各向異性度、選擇比，算 CD 與 undercut
       Af = vertical/lateral rate；selectivity = film/mask rate
       過蝕比例 over = 額外蝕刻時間 / 目標蝕刻時間"""
    undercut = depth / Af                                  # 橫向鑽蝕 (um)
    cd = cd_mask - 2 * undercut                            # 最終 CD (um)
    mask_consumed = depth / selectivity                    # 光罩被啃掉量 (um)
    cd_actual = cd + 2 * mask_loss                         # 光罩側縮回補回一點 CD
    return cd_actual, undercut, mask_consumed

cases = [
    # (名稱, cd_mask, depth, Af, S)
    ("wet (isotropic)", 1.0, 0.5, 1.0, 10),
    ("RIE 1970s",       1.0, 0.5, 10.0, 10),
    ("ICP 1990s",       1.0, 0.5, 100.0, 100),
]
for name, cm, d, af, s in cases:
    cd, uc, mc = etch_profile(cm, d, af, s)
    print(f"{name:18s}: CD = {cd:.3f} um, undercut = {uc:.3f} um, mask loss = {mc:.3f} um")
# wet (isotropic)  : CD = 0.000 um, undercut = 0.500 um, mask loss = 0.050 um
# RIE 1970s        : CD = 0.900 um, undercut = 0.050 um, mask loss = 0.050 um
# ICP 1990s        : CD = 0.990 um, undercut = 0.005 um, mask loss = 0.005 um
```

模擬顯示：同樣蝕 0.5 μm 深，濕式把 1 μm 的窗吃成 0（完全掏空），RIE 只鑽 0.05 μm，ICP 幾乎忠實轉移——**$A_f$ 就是 CD 的旋鈕**，這正是乾式蝕刻取代濕式的數學本質。

### 線索六：偵辦對照表——濕式 vs RIE vs ICP

| 項目 | 濕式 | RIE（1970s） | ICP（1990s） |
|------|------|--------------|--------------|
| $A_f$ | $\approx 1$ | 10–100 | 50–300 |
| 選擇比 | 高但漂移 | 中高 | 高且可調 |
| 損傷 | 無 | 中（$V_{dc}$ 高） | 低（偏壓解耦） |
| 深寬比 | $\lesssim 1$ | 5–10 | 20–30+ |
| 廢液 | 大量 HF | 無 | 無 |
| 重現性 | 藥液壽命漂移 | 良好 | 極佳（診斷閉環） |

## 結案 -- 後果與影響
- **乾式取代濕式**：1970 年代末 RIE 成為圖案轉移標準，濕式退居清洗與少數體矽蝕刻場合。
- **次微米圖案轉移必備**：CD 控制進入次微米後，沒有方向性蝕刻就做不出 DRAM 電容孔與邏輯閘。
- **為 FinFET/GAA 鋪路**：FinFET 的 fin 切割、GAA 的奈米片釋放，皆為高深寬比電漿蝕刻——深寬比 30:1 以上已是家常便飯。
- **電漿診斷與 ALE**：OES/RGA 電漿診斷、腔體建模，乃至 ALE（atomic layer etching）——一層一層剝，把蝕刻推到原子級精度，源頭都在 1970 年代這條線上。
- **綠色製程**：乾式蝕刻大幅削減 HF/鉻酸廢液，製造業的環境足跡自此改寫。
