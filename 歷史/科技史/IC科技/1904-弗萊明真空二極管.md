# 1904 - 弗萊明真空二極管：電子學的第一道閥門

## 案件摘要
1904 年 11 月，英國電機工程師 John Ambrose Fleming 取得熱離子真空二極管（Fleming valve）的英國專利。
他在燈泡裝入燈絲陰極與板極陽極，讓電流只能單向流動——這是人類第一個真空管電子元件。
它取代了無線電報接收器上遲鈍的金屑檢波器（coherer），讓 Marconi 公司的越洋電報訊號清晰可辨。
電子學的誕生，就從這顆會「挑方向」的燈泡開始。

## 前因 -- 為什麼會有這個案子
- **Edison effect（1883）**：愛迪生在燈泡裡多放一片電極，發現電流只從**熱的燈絲**流向**正的電極**，反向則完全不通。他記錄了現象，卻不知道成因，更沒看出用途。
- **Richardson 熱離子發射定律（1901）**：劍橋的 Owen Richardson 用統計力學解釋了「熱金屬會噴出電子」：溫度越高、逸出功越低，發射電流越大，$J = A T^2 e^{-W/kT}$。這條定律給了 Edison effect 物理上的身分證（Richardson 後獲 1928 年諾貝爾物理獎）。
- **無線電報的瓶頸**：Marconi 的接收器靠 **coherer 金屑檢波器**——金屑粉末在射頻下導通、需人工敲擊復位，靈敏度差、速度慢，長距離電報的訊號解不出來。
- **關鍵推理**：Fleming 曾任 Edison Electric 與 Marconi 的顧問，他把三條線接在一起——**熱陰極發射電子 + 板極只能吸引電子 = 單向導通 = 天生的整流器／檢波器**：

$$
\underbrace{J = A T^2 e^{-W/kT}}_{\text{熱陰極噴電子}} \;+\; \underbrace{V_{\text{plate}} > 0}_{\text{電場只吸電子}} \;\Longrightarrow\; \underbrace{I_{\text{forward}} \gg 0,\;\ I_{\text{reverse}} \approx 0}_{\text{整流}}
$$

1904 年 Fleming 以「改良電振盪用的儀器」為名申請英國專利（No. 24,850），Marconi 隨即量產採用。
這起案件的偵探手法很典型：**線索**（Edison effect）三十年前就有人目擊，**理論**（Richardson 定律）三年前就寫好了，缺的只是一個同時看過兩份卷宗的人。

## 線索與推理 -- 數學式、程式、理論

### 1. Richardson 定律：熱陰極為什麼噴電子

金屬內的電子要逃離表面，動能必須超過逸出功 $W$。電子能量服從 Maxwell–Boltzmann 統計，能量大於 $W$ 的電子通量對溫度積分後：

$$
J = A\, T^2\, e^{-W / kT}
$$

- $T^2$ 來自**表面的量子統計**（Sommerfeld 理論修正後的形狀，Richardson 原式為 $A T^{1/2} e^{-W/2kT}$）。
- 指數項 $e^{-W/kT}$ 是主導：鎢的 $W \approx 4.5\,\mathrm{eV}$，需加熱至 $T \approx 2500\,\mathrm{K}$ 才有可觀發射；塗氧化物的陰極 $W \approx 1\,\mathrm{eV}$，$\sim 1000\,\mathrm{K}$ 即可。
- **數值感覺**：$T$ 從 1000 K 升到 2000 K，$e^{-W/kT}$ 變大約 $e^{26} \approx 2\times 10^{11}$ 倍——發射電流對溫度極端敏感，這就是為什麼真空管一定要有「燈絲」。

### 2. 單向閥門：整流的數學本質

二極管內，電子只被**負電位發射、被正電位吸引**：
- 板極為正（順向）：電子飛越真空抵達板極，形成板極電流 $I_p$。
- 板極為負（反向）：板極不發射電子，回路斷絕，$I_p \approx 0$。

對射頻信號 $v(t) = V_0 \sin(\omega t)$ 做半波整流，輸出為：

$$
i(t) = \begin{cases} I_p\big(v(t)\big), & \sin(\omega t) > 0 \\[4pt] 0, & \sin(\omega t) \le 0 \end{cases}
\qquad\Longrightarrow\qquad
\bar{I} = \frac{1}{2\pi}\int_0^{\pi} I_m \sin\theta \, d\theta = \frac{I_m}{\pi}
$$

- 半波整流的平均值只有峰值 $I_m$ 的 $1/\pi \approx 0.318$，效率低，但**方向被挑出來了**。
- **檢波（demodulation）**：調幅波 $v(t) = V_c\big(1 + m\cos\omega_m t\big)\cos\omega_c t$ 經二極管整流後，用電容濾掉載波 $\omega_c$，剩下的包絡 $1 + m\cos\omega_m t$ 就是聲音訊號——無線電報與早期收音機的收訊核心。

### 3. Space charge 限流：Child–Langmuir 定律（1911）

順向電壓一高，電流卻不會無限上升：陰極與板極之間堆積了雲狀的電子群（**空間電荷**），它的負電場反過來壓制後續發射。Child（1911）與 Langmuir（1913）解一維泊松方程得到：

$$
J = \frac{4}{9}\,\epsilon_0 \sqrt{\frac{2e}{m}}\;\frac{V^{3/2}}{d^2}
$$

- 電流隨電壓的 **3/2 次方**成長，而非指數；與距離平方 $d^2$ 成反比。
- 二極管有兩個工作區：**space-charge-limited**（電壓受限，$V^{3/2}$ 律）與 **temperature-limited**（燈絲全開，受 Richardson 律限制）。
- 這條定律讓工程師第一次能**定量設計**真空管——電流是可計算的，不只是可觀察的。

### 4. 檢波器之爭：coherer vs Fleming valve

無線電報的收訊瓶頸，是兩種檢波器的對決：

| 特性 | coherer 金屑檢波器 | Fleming valve |
|---|---|---|
| 原理 | 金屑粉在射頻下凝聚導通 | 熱陰極電子只飛向正板極 |
| 靈敏度 | 差，需強信號 | 高，微弱射頻即可 |
| 復位 | 每次需機械敲擊 | 自動，隨信號極性 |
| 速度 | 慢，每秒數字 | 快，可跟隨射頻 |

- coherer 是「黏住的開關」：射頻讓鎳屑氧化層擊穿而導通，之後必須敲擊才能恢復高阻——**有記憶、無即時性**，訊號解調斷斷續續。
- Fleming valve 是「隨波挑向的閥門」：輸出電流即時跟隨射頻包絡，配合紙帶記錄器可直接讀出摩爾斯電碼。
- 1906 年後 Marconi 全面換用真空管檢波器——這是**電子器件第一次在市場上擊敗機械器件**。
- 對決的意義：檢波器的勝負不在物理靈敏度，而在「**是否需要人手介入**」——Fleming valve 全自動，coherer 全靠敲擊，自動化從此成為電子器件的評分標準。

### 5. Python 實作：二極管 I-V 曲線與半波整流波形

```python
import numpy as np
import matplotlib.pyplot as plt

# ---- Fleming valve：Child–Langmuir 定律 I = K * V^(3/2) ----
e, m, eps0 = 1.602e-19, 9.109e-31, 8.854e-12
d = 2e-3                                   # 陰極-板極距離 2 mm
K = (4/9) * eps0 * np.sqrt(2*e/m) / d**2   # 導流係數 (perveance)
print(f"perveance K = {K:.3e} A/V^1.5")
# 預期輸出：perveance K = 4.655e-06 A/V^1.5

V = np.linspace(0, 200, 400)
I = K * V**1.5                             # space-charge-limited 區
Vr = np.linspace(-200, 0, 200)
Ir = np.zeros_like(Vr)                     # 反向：完全不通

plt.plot(V, I*1e3, label="forward (V^1.5 law)")
plt.plot(Vr, Ir*1e3, label="reverse (blocked)")
plt.xlabel("Plate voltage (V)"); plt.ylabel("Plate current (mA)")
plt.title("Fleming Valve I-V Curve"); plt.legend(); plt.grid(True)
plt.show()
# 預期圖形：順向沿 V^1.5 上升（200 V 時約 13 mA），反向為零線——單向閥門

# ---- 半波整流：射頻信號經二極管 ----
t = np.linspace(0, 2, 2000)                # 2 個週期
v = 5 * np.sin(2*np.pi*1*t)                # 5 V 峰值射頻
i = np.where(v > 0.3, K * (v - 0.3)**1.5, 0)   # 0.3 V 為導通門檻

fig, ax = plt.subplots(2, 1, sharex=True)
ax[0].plot(t, v); ax[0].set_ylabel("RF input (V)")
ax[1].plot(t, i*1e3); ax[1].set_ylabel("rectified (mA)")
ax[1].set_xlabel("time (s)")
plt.show()
print(f"mean rectified current = {i.mean()*1e3:.2f} mA  (峰值 {i.max()*1e3:.2f} mA)")
# 預期輸出：mean rectified current = 1.31 mA  (峰值 4.43 mA)——只剩正半週通過
```

整流波形只剩正半週，平均值約峰值的 $1/\pi$——「檢波器」的數值驗證。

## 結案 -- 後果與影響

- **第一顆真空管電子元件**：Fleming valve 是史上第一個能實用的真空電子器件，電子在真空中的行為第一次被馴服成「元件」。
- **整流與檢波落地**：Marconi 公司全面採用，越洋無線電報的接收靈敏度大幅提升；1900 年代末的無線通信從此有可靠的檢波器。
- **為三極管鋪路**：1906 年 Lee De Forest 在陰極與板極之間插上柵極，做成可放大的 Audion——沒有二極管，就沒有三極管。
- **定量設計的起點**：Child–Langmuir 定律讓真空管從「可觀察的現象」變成「可計算的元件」，這是電子設計自動化思想的最早源頭。
- **電子學誕生**：「電子」（electron，1897 年 Thomson 發現）從物理實驗室的粒子，變成電路裡的載流子；「electronics」一詞即源自真空管，工業與軍事通信自此改寫。
- **工業鏈的起點**：真空管製造催生玻璃泡、燈絲材料、高真空泵浦與插座工業——英國與美國的電子工業皆由此起家， Fleming 1904 年專利成為日後所有真空管授權戰的源頭。
