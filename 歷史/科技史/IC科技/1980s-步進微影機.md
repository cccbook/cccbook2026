# 1980s - 光學步進微影機：die-by-die 的曝光革命

## 案件摘要
1980 年，GCA 推出 4800 DSW——史上第一台量產用 wafer stepper，把晶圓曝光從「整片一次印」
改成「一格一格步進重複」。此後 Nikon、Canon 相繼加入，ASML（1984）從小廠起步，
步進機成為半導體微影的標準設備——「微影是半導體引擎」這句話，正是由它執行了四十年。

## 前因 -- 為什麼會有這個案子
- **接觸式微影的罩罩門**：最早的接觸式微影要把 mask 緊貼光阻，每曝光一次 mask 就磨損一次、
  光阻也被刮傷，良率與 mask 壽命都是災難；接近式（proximity）拉開距離後繞射又讓解析度崩壞。
- **1:1 projection 的妥協**：Perkin-Elmer **Micralign**（1973）用反射鏡掃描式投影，
  mask 與晶圓 1:1 等倍成像，解決了磨損問題，一度稱霸 1970 年代。
  但 1:1 意味著 mask 上的圖形必須和晶圓一樣小——mask 製作困難、缺陷密度高、難以檢修。
- **關鍵推理**：把 mask 做大 4x～5x、投影時再縮小回來，mask 上每條線都變粗、
  缺陷相對變小、製作與修復都容易——**reduction stepper** 的商業邏輯：

$$
\text{mask 圖形尺寸} = 4\,\text{CD} \quad\Longrightarrow\quad \text{mask 容忍 } 4\times \text{ 的缺陷與誤差}
$$

- **die-by-die 對齐**：晶圓受熱與機械應力會翹曲，整片 1:1 印的套準誤差隨晶圓半徑放大；
  stepper 每曝光一格就重新對焦對位一次，把誤差「逐格消化」。

## 線索與推理 -- 數學式、程式、理論

### 1. Rayleigh 公式：微影的物理天花板

成像解析度與景深由 Rayleigh 準則決定：

$$
\text{CD} = k_1\frac{\lambda}{\text{NA}}, \qquad
\text{DOF} = k_2\frac{\lambda}{\text{NA}^2}
$$

- $\lambda$：光源波長；$\text{NA} = n\sin\theta$：鏡頭數值孔徑（空氣中 $n=1$，上限 1.0）。
- **核心矛盾**：縮小 CD 有兩條路——縮短波長或加大 NA，但 $\text{DOF} \propto 1/\text{NA}^2$，
  NA 每加大一點，景深就平方級崩塌，焦距誤差數十奈米就報廢一片晶圓。
- 1980 年代初 g-line（436nm）+ NA 0.35 時，$\text{CD} \approx 1.2\,\mu m$，恰好夠 1μm 製程。

### 2. 波長縮短史：g-line → i-line → KrF

$$
\text{g-line } 436\,\text{nm} \xrightarrow{\;\text{Hg 燈譜線}\;} \text{i-line } 365\,\text{nm}
\xrightarrow{\;\text{化學放大光阻}\;} \text{KrF } 248\,\text{nm}
$$

- **g-line（436nm）**：高壓汞燈的直接譜線，1980 年代前半主力，對應 1μm～0.8μm 製程。
- **i-line（365nm）**：同一顆汞燈的另一條譜線，只需換鏡頭玻璃材料（i-line 用 fused silica
  替代普通光學玻璃）與更高 NA，1980 年代末撐到 0.5μm 製程。
- **KrF（248nm）**：ArF/KrF 準分子雷射取代汞燈，1990 年代初進入 0.35μm；
  搭配 **化學放大光阻（CAR, Ito 1982）** 解決 248nm 光源功率不足的問題。
- **推理**：每換一次波長，光源、鏡頭、光阻、量測全部重來——這是十年一次的燒錢換代，
  也是設備廠洗牌的窗口。

### 3. Overlay：套準誤差的 $1/3$ 法則

多層圖形必須疊準，業界經驗法則：

$$
\text{overlay} < \frac{1}{3}\,\text{CD}
$$

CD 0.8μm 時 overlay 要小於 270nm；stepper 靠雷射干涉儀量測平台位移（精度數奈米）、
逐格自動對位（wafer alignment marks）、以及機台間的 match-up 校正達成。
**推理**：步進機賣的不是解析度而已——overlay 與產能（wafer/hour）才是客戶換機的真正帳單。

### 4. k1 下降：繞射理論的邊界推進

Rayleigh 公式中的 $k_1$ 理論極限約 0.25–0.3（接近完全相干極限）。1980 年代 k1 ≈ 0.8，
此後靠解析度增強技術（RET）一路壓低：

- **離軸照明（OAI, 1990s）**：光源傾斜入射，把斜射光變成可用訊號，提升小 pitch 的對比；
- **相移 mask（PSM, Levenson 1982 提出、1990s 量產）**：相鄰開口相位差 $\pi$，
  繞射場在暗線處相消，邊緣對比大幅提升：

$$
E_{\text{edge}} = E_0 - E_0\,e^{i\pi} = 2E_0 \quad\Longrightarrow\quad \text{對比加倍}
$$

**推理**：波長換代太貴，k1 優化相對便宜——$k_1: 0.8 \to 0.3$ 等於免費把解析度提升近三倍，
這條線一直延伸到後來的 immersion 與 EUV 時代。

### 5. Python 實作：Rayleigh 公式計算器（各代微影的極限）

```python
def rayleigh(lmbda, NA, k1=0.8, k2=0.5):
    """給定波長(nm)、數值孔徑、k1/k2，回傳 (CD, DOF)，單位 nm"""
    cd  = k1 * lmbda / NA
    dof = k2 * lmbda / NA**2
    return cd, dof

generations = [
    ("g-line 436nm  NA=0.35", 436, 0.35),
    ("g-line 436nm  NA=0.54", 436, 0.54),
    ("i-line 365nm  NA=0.60", 365, 0.60),
    ("i-line 365nm  NA=0.65 (PSM, k1=0.5)", 365, 0.65),
    ("KrF    248nm  NA=0.80", 248, 0.80),
]

for name, lam, na in generations:
    k1 = 0.5 if "PSM" in name else 0.8
    cd, dof = rayleigh(lam, na, k1=k1)
    print(f"{name}:  CD = {cd*1000:.0f} nm,  DOF = {dof/1000:.2f} um")
# g-line 436nm  NA=0.35:  CD = 997 nm,  DOF = 0.89 um
# g-line 436nm  NA=0.54:  CD = 646 nm,  DOF = 0.37 um
# i-line 365nm  NA=0.60:  CD = 487 nm,  DOF = 0.25 um
# i-line 365nm  NA=0.65 (PSM, k1=0.5):  CD = 281 nm,  DOF = 0.22 um
# KrF    248nm  NA=0.80:  CD = 155 nm,  DOF = 0.10 um

print(f"\nk1 理論極限 (0.27, i-line NA=0.65): "
      f"CD = {rayleigh(365, 0.65, k1=0.27)[0]:.0f} nm")
# k1 理論極限 (0.27, i-line NA=0.65): CD = 152 nm
print(f"overlay 上限 (CD=281nm): {281/3:.0f} nm")
# overlay 上限 (CD=281nm): 94 nm
```

執行結果顯示：g-line 到 KrF 的十年間，CD 從 1μm 壓到 155nm；但 DOF 從 0.89μm 崩到
0.10μm——這正是後來浸潤式微影（拉高 NA 卻保住 DOF）登場的伏筆。

## 結案 -- 後果與影響
- **stepper 成為微影標準設備**：die-by-die step-and-repeat 從 1μm 製程一路用到今天，
  掃描式（step-and-scan, 1990s）只是它的演化型，架構基因未變。
- **GCA 的教訓**：發明者 GCA 因產能交付延誤與服務品質問題在 1980 年代末崩盤——
  **設備業的勝負不在發明，而在量產、交機與服務**。
- **三強成形**：Nikon（1980 年代市占第一）、Canon（g/i-line 大廠）、ASML（1984 年成立、
  從 PAS 2500 起步）——ASML 從小廠變霸主的起點就在這個年代。
- **k1 優化延續**：離軸照明、相移 mask、後來的 off-axis + immersion，k1 從 0.8 壓到 0.27，
  讓 193nm 乾式撐到 90nm 節點，為 2002 年浸潤式微影鋪路。
- **「微影是半導體引擎」的執行者**：晶片製程節點的推進，本質上就是 stepper 的推進——
  設備從配角變成主角，從此定義了摩爾定律的節奏。
