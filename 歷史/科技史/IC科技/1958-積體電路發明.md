# 1958-積體電路發明

## 案件摘要
1958 年 9 月，TI 的 Jack Kilby 在一塊鍺上做出相移振盪器；半年後，Fairchild 的 Robert Noyce 用矽與金屬互連做出更完整的 IC。兩人獨立破案，引發十年專利纏訟，最終和解共分市場——「把整個電路做進一塊晶體」從此改寫人類文明。

## 前因 -- 為什麼會有這個案子
- **數字的暴政（tyranny of numbers）**：電晶體雖小，但每個仍需焊接引線、封裝、互連。電路越複雜，零件數呈指數成長：
  $$N_{\text{connections}} \sim N_{\text{components}}, \qquad \text{可靠度} \propto \frac{1}{N_{\text{components}}}$$
  軍方系統（如民兵飛彈）需要數十萬元件，互連焊接點的失效成為系統不可靠的元兇——元件越來越小，系統卻越來越不可行，這就是「數字的暴政」。
- **軍方資金**：美國空軍與國防部大力資助微型化研究（Micromodule 計畫等），但多半走「把零件做小再組裝」的路，Kilby 認為此路不通。
- **材料齊備**：區域提純（1950）與柴氏單晶已提供 9N 級半導體基板，作案條件成熟。

## 線索與推理 -- 數學式、程式、理論

### Kilby 的推理：何不讓零件「長在一起」？
1958 年夏天 Kilby 新進 TI，尚無休假資格，獨自留在實驗室。他的推理：電阻、電容、電晶體都可用**同一塊半導體**的不同區域實現——何必分開做再組裝？

1958 年 9 月 12 日，他在一塊鍺上以金屬焊接做出**相移振盪器**原型（一個電晶體 + 電阻 + 電容），示波器上出現正弦波——積體電路誕生。

### RC 相移振盪器的數學
Kilby 原型與後續 IC 驗證的振盪原理：三節 RC 高通網路各提供 $60°$ 相移，環路總相移 $180°$ 加上放大器反相構成 $360°$ 振盪條件（Barkhausen 準則）：

$$\beta A = 1, \qquad \angle \beta + \angle A = 360°$$

三節 RC 網路的轉移函數：

$$H(s) = \left(\frac{sRC}{1 + sRC}\right)^3, \qquad \omega_{osc} = \frac{1}{RC\sqrt{6}}$$

振盪頻率 $f = \dfrac{1}{2\pi RC\sqrt{6}}$，起振條件為放大倍率 $A > 29$。

### Noyce 的推理：用矽 + 平面互連
Noyce（Fairchild 八叛逆之一）得知 Kilby 成果後推理：Kilby 用鍺、靠焊接互連，仍非真正可量產。他提出：
1. 用**矽**（有 SiO2 絕緣層，見 1959 平面製程）。
2. 元件間互連用**蒸鍍金屬（鋁）走線**，直接在氧化層上佈線。
3. 電阻、電容與電晶體全部以平面製程做在同一晶片上。

1959 年 Noyce 申請專利：「Semiconductor device-and-lead structure」——這是現代 IC 的藍圖。

### 兩案對照
| | Kilby (TI, 1958) | Noyce (Fairchild, 1959) |
|---|---|---|
| 材料 | 鍺 | 矽 |
| 互連 | 金線焊接 | 蒸鍍鋁金屬走線 |
| 製程 | 手工組裝 | 平面製程（可量產） |
| 意義 | 概念首創 | 工程實現 |

### Python 模擬：RC 相移振盪器

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.signal import bode, lsim, TransferFunction

# 三節 RC 高通網路 H(s) = (sRC/(1+sRC))^3, Barkhausen 條件驗證
R, C = 1e3, 100e-9
num = np.polymul([R*C, 0], np.polymul([R*C, 0], [R*C, 0]))   # (sRC)^3
den = np.polymul([R*C, 1], np.polymul([R*C, 1], [R*C, 1]))   # (1+sRC)^3
H3 = TransferFunction(num, den)

w, mag, phase = bode(H3, np.logspace(2, 6, 500))
f_osc = 1 / (2 * np.pi * R * C * np.sqrt(6))
print(f"理論振盪頻率: {f_osc:.1f} Hz")

fig, ax = plt.subplots(2, 1, sharex=True)
ax[0].semilogx(w, mag); ax[0].set_ylabel("|H| (dB)")
ax[1].semilogx(w, phase); ax[1].set_ylabel("Phase (deg)")
ax[1].axhline(-180, color="r", ls="--")
ax[1].set_xlabel("Frequency (rad/s)")
fig.suptitle("3-Stage RC Phase-Shift Network (Kilby Oscillator)")
plt.show()
```

波特圖顯示：相位在理論頻率處穿越 $-180°$，配合增益條件 $A>29$ 即可起振——Kilby 振盪器的數學得到驗證。

## 結案 -- 後果與影響
- **專利之爭**：TI（Kilby, 1959.2 提出專利）與 Fairchild（Noyce, 1959.7）纏訟十年；1969 年美國海關法院與關稅專利上訴法院裁定：Kilby 是 IC 概念先驅，Noyce 的互連結構才是可量產的工業標準。兩家公司最終**交叉授權和解**。
- **2000 年諾貝爾獎**：Kilby 獲**諾貝爾物理學獎**（「對發明積體電路的貢獻」）；Noyce 已於 1990 年去世，諾貝爾獎不追授，成為遺憾。
- **革命意義**：IC 使電路複雜度不再受焊接點數限制，摩爾定律（1965）應運而生；單晶片電晶體數從 4 個（1962）到數百億（今日），價格反而指數下降。
- 太空競賽（阿波羅登月的導航電腦）與軍方採購成為 IC 最早的大客戶，撐起早期量產曲線。
