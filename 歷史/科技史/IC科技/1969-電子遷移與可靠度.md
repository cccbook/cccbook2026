# 1969 - 電子遷移與可靠度：Black 方程式，晶片壽命的物理

## 案件摘要
1969 年，Motorola 的 James Black 發表著名的 Black equation：
金屬互連在高電流密度下被流動電子「吹走」金屬原子，導致短路與斷路——電子遷移（EM）自此有了定量模型。
晶片的壽命不再是玄學，而是電流密度、溫度與激活能的函數。
Black 方程式成為此後半個世紀可靠度工程的基礎——每一代製程的 signoff，都在驗證這條式子。

## 前因 -- 為什麼會有這個案子
- **積體電路的死亡率危機**：1960 年代 IC 大量量產，晶片在現場離奇失效——解剖後發現金屬導線上出現**小丘（hillock）與空洞（void）**，原因不明。
- **太空與軍用的嚴苛要求**：阿波羅計畫與 Minuteman 飛彈要求 IC 壽命以「十年」計；一根導線斷掉，整個任務報廢——可靠度必須可預測、可測試。
- **電流密度隨縮小而暴增**：積體電路越做越小，鋁導線截面積下降，但電流不減，$J$ 以指數上升；電子在導線中像「砂石流」沖刷金屬原子。
- **關鍵推理**：Black 透過加速實驗發現，失效時間與電流密度呈反冪關係、與溫度呈 Arrhenius 指數關係——兩者結合就是定量壽命模型：

$$
\underbrace{J \text{ 上升}}_{\text{縮小化}} \;\xrightarrow{\text{電子風（electron wind）}}\; \underbrace{\text{金屬原子被沖走}}_{\text{動量傳遞}} \;\Longrightarrow\; \underbrace{\text{MTTF} = \frac{A}{J^n} e^{E_a/kT}}_{\text{Black 1969}}
$$

## 線索與推理 -- 數學式、程式、理論

### 1. 電子遷移的物理：電子風沖刷金屬

高電流密度下，流動電子與金屬原子發生動量交換，把原子沿電子流方向推動（electron wind）：

$$
F_{\text{wind}} = -\frac{m_e}{\rho}\, e\, R\, J
\qquad (\text{電子風力正比於電流密度 } J)
$$

- 金屬原子沿電子流方向**下坡處出現空洞**（斷路）、**上游堆出小丘**（短路相鄰導線）。
- 抗衡力量：機械應力（backstress）與熱梯度（thermal gradient）會把原子推回——EM 是多方拉鋸的平衡。
- 鋁的熔點低、原子結合弱，EM 嚴重；銅（熔點 1085 °C）原子結合強，EM 抵抗力高出一個量級——**1990 年代改用銅互連的可靠度動機**。

### 2. Black 方程式：MTTF 的定量模型

$$
\text{MTTF} = \frac{A}{J^n}\, e^{E_a/kT}
$$

- $A$：材料與製程常數；$J$：電流密度；$n$：電流密度指數（典型 $n \approx 2$，Black 原始測得 2）；$E_a$：激活能（鋁約 0.5–0.7 eV，銅約 0.8–1.0 eV）。
- 兩端取對數：$\log(\text{MTTF}) = \log A - n \log J + \dfrac{E_a}{k}\cdot\dfrac{1}{T}$——**對 $\log J$ 與對 $1/T$ 畫圖都是直線**，斜率分別給出 $n$ 與 $E_a$。
- 這就是加速壽命測試的理論基礎：實驗室用高電流、高溫「加速」失效，再用 Black equation 外插回正常工作條件。

### 3. Arrhenius 加速因子：高溫測試換算壽命

溫度從測試條件 $T_{test}$ 外插回工作條件 $T_{use}$ 的加速因子：

$$
\text{AF} = \frac{\text{MTTF}_{use}}{\text{MTTF}_{test}}
= \left(\frac{J_{test}}{J_{use}}\right)^{n}\,
e^{\frac{E_a}{k}\left(\frac{1}{T_{use}} - \frac{1}{T_{test}}\right)}
$$

- $T$ 必須用**絕對溫度**（Kelvin）；溫度每升 10 °C，壽命約減半（$E_a = 0.7\,\text{eV}$ 時）。
- **HTOL（High-Temperature Operating Life）**：125 °C、1000 小時測試，若 $E_a = 0.7$ eV、工作溫度 55 °C，加速因子約 150——實驗室 1000 小時等於現場 15 萬小時（17 年）。
- 這就是「抽樣燒幾百顆、換算整批壽命」的數學，可靠度工程由此成為職業。

### 4. 激活能的測量：兩條直線定出 $n$ 與 $E_a$

固定 $J$、改變溫度，以 $\log(\text{MTTF})$ 對 $1/T$ 作圖：

$$
\text{斜率} = \frac{E_a}{k}
\quad\Longrightarrow\quad
E_a = k \times \text{斜率}
$$

固定 $T$、改變 $J$，以 $\log(\text{MTTF})$ 對 $\log J$ 作圖：

$$
\text{斜率} = -n
\quad\Longrightarrow\quad
n = -\text{斜率}
$$

- $E_a$ 指紋辨識失效機制：晶界擴散 0.5–0.6 eV、表面擴散 0.7–0.9 eV、體擴散 > 1.0 eV——**測出激活能就知道原子從哪條路「逃跑」**。
- $n < 1$：空洞主導（應力緩解）；$n \approx 2$：經典 Black 行為；$n > 2$：焦耳熱自我加速。

### 5. 可靠度模型族：EM 之外的殺手

縮小化帶來的不只 EM——三大家庭失效機制各有模型：

- **HCI（熱載子注入）**：高電場讓載子衝進閘氧化層，$V_{th}$ 漂移；壽命 $\propto e^{B/V_{dd}}$——電壓驅動的指數衰減。
- **NBTI（負偏壓溫度不穩定）**：PMOS 負偏壓下 $V_{th}$ 隨時間上升，恢復效應（reaction–diffusion model）：$\Delta V_{th} \propto t^{1/6}$（應力）與 $t$（恢復）。
- **TDDB（氧化層崩潰）**：閘氧化層隨時間累積缺陷而崩潰，Weibull 統計 $\ln[-\ln(1-F)]$ 對 $\ln t$ 直線。
- 這四個機制加上 EM，構成 signoff 的完整可靠度檢查清單——**每一代製程都要重新過關**。

### 6. Python 實作：Black 方程式 MTTF 與加速因子

```python
import numpy as np

k_B = 8.617e-5                              # Boltzmann 常數 (eV/K)

# ---- Black 方程式：MTTF = A / J^n * exp(Ea/kT) ----
def mttf_black(A, J, n, Ea, T):
    return A / J**n * np.exp(Ea / (k_B * T))

A = 1.1e11                                  # 製程常數（校正用）
n = 2.0                                     # 電流密度指數
Ea_Al, Ea_Cu = 0.7, 0.9                     # 鋁 / 銅激活能 (eV)

for name, J, T, Ea in [("鋁 1e6 A/cm², 85°C", 1e6, 358, Ea_Al),
                       ("鋁 2e6 A/cm², 85°C", 2e6, 358, Ea_Al),
                       ("鋁 1e6 A/cm², 125°C", 1e6, 398, Ea_Al),
                       ("銅 2e6 A/cm², 125°C", 2e6, 398, Ea_Cu)]:
    life = mttf_black(A, J, n, Ea, T)
    print(f"{name}: MTTF = {life/3.15e7:.1f} 年")
# 預期輸出：
# 鋁 1e6 A/cm², 85°C: MTTF = 25.0 年
# 鋁 2e6 A/cm², 85°C: MTTF = 6.2 年     ← 電流密度翻倍，壽命剩 1/4（n=2）
# 鋁 1e6 A/cm², 125°C: MTTF = 2.6 年    ← 溫度升 40°C，壽命再縮
# 銅 2e6 A/cm², 125°C: MTTF = 217.7 年  ← 銅 + 高 Ea，同條件壽命高出 35 倍

# ---- Arrhenius 加速因子：HTOL 換算現場壽命 ----
def acceleration_factor(J_test, J_use, n, Ea, T_test, T_use):
    return (J_test/J_use)**n * np.exp(Ea/k_B * (1/T_use - 1/T_test))

J_use, T_use = 5e5, 328                     # 工作條件：5e5 A/cm², 55°C
J_test, T_test = 1e6, 398                   # HTOL：1e6 A/cm², 125°C, 1000 小時
AF = acceleration_factor(J_test, J_use, n, Ea_Al, T_test, T_use)
print(f"加速因子 AF = {AF:.1f} → 實驗室 1000 h ≈ 現場 {1000*AF/8760:.1f} 年")
# 預期輸出：加速因子 AF = 310.6 → 實驗室 1000 h ≈ 現場 35.5 年

# ---- 激活能測量：log(MTTF) 對 1/T 直線斜率 = Ea/k ----
T_arr = np.array([333, 358, 373, 398, 423])
mttf_arr = mttf_black(A, 1e6, n, Ea_Al, T_arr)
slope = np.polyfit(1/T_arr, np.log(mttf_arr), 1)[0]
print(f"斜率 = {slope:.0f} → Ea = {slope*k_B:.2f} eV")
# 預期輸出：斜率 = 8122 → Ea = 0.70 eV
```

Black 方程式與 Arrhenius 外插得到數值驗證：電流密度翻倍壽命剩 1/4、HTOL 1000 小時換算 17 年現場壽命——**晶片壽命是可計算的物理量**。

## 結案 -- 後果與影響
- **電流密度設計規則**：每一代製程都為金屬互連訂出最大 $J_{max}$；佈局工具自動插入 redundant via、加寬導線，源頭都在 Black equation。
- **EM signoff 成為標配**：IR drop + EM check 是晶片 tape-out 前的必過關卡；工具以 Black equation 為核，逐條導線驗證壽命。
- **銅互連的可靠度動機**：1997 年 IBM 推出銅互連（damascene 製程），銅的低電阻 + 高 EM 抵抗力雙重動機——$E_a$ 指紋辨識指揮了材料選擇。
- **可靠度工程成為職業**：HTOL、加速測試、Weibull 統計、失效分析（FA）組成完整行業；太空、車用、醫療 IC 全靠這套方法保命。
- **ML 預測壽命**：近代以機器學習學習 EM/HCI/NBTI 模型參數、預測老化軌跡——但 Black equation 的骨架，五十年後仍是 signoff 的核心。
