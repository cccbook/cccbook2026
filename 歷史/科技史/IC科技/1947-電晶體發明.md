# 1947-電晶體發明

## 案件摘要
1947 年 12 月，Bell Labs 的 Bardeen、Brattain 與 Shockley 在鍺晶體上做出第一個「點接觸電晶體」，以固體取代真空管放大訊號。這起案件揭開了固態電子的序幕，也埋下了日後積體電路的種子。

## 前因 -- 為什麼會有這個案子
- **真空管的三大暴政**：
  - 體積龐大：一枚真空管如拇指大小，ENIAC 用了 17,468 枚，佔地 167 平方公尺。
  - 功耗驚人：燈絲需加熱至發射電子，ENIAC 功耗約 150 kW。
  - 壽命短促：燈絲燒毀、真空漏氣，平均壽命僅數千小時，故障頻繁。
- **固體的可能性**：1930 年代已有半導體整流器（貓鬚檢波器、氧化銅整流器），但缺乏理論解釋。
- **理論突破**：1931 年 Wilson 提出半導體能帶理論；二戰期間雷達用的鍺與矽檢波器研究累積大量實驗數據。戰後 Bell Labs 組成固態物理小組，目標明確：找一個固體放大器。

## 線索與推理 -- 數學式、程式、理論

### 能帶理論：罪案的第一條線索
固體中電子的能量只能落在特定「能帶」中：

- **價帶（valence band）**：被價電子填滿的能帶。
- **導帶（conduction band）**：電子可自由移動的能帶。
- **能隙 $E_g$**：兩帶之間的禁區。金屬 $E_g = 0$；絕緣體 $E_g > 4\,\mathrm{eV}$；半導體居中（矽 $E_g \approx 1.12\,\mathrm{eV}$，鍺 $E_g \approx 0.67\,\mathrm{eV}$）。

載子濃度與能隙的關係（本質半導體）：

$$n_i = \sqrt{N_c N_v}\, e^{-E_g / 2kT}$$

其中 $N_c, N_v$ 為導帶與價帶的有效狀態密度。能隙越小、溫度越高，載子越多。

- **本質半導體**：純淨晶體，電子與電洞成對產生，$n = p = n_i$。
- **摻雜半導體**：
  - n 型：摻 V 族元素（磷、砷），提供電子，$n \approx N_D$。
  - p 型：摻 III 族元素（硼），提供電洞，$p \approx N_A$。

質量作用定律 $np = n_i^2$ 是摻雜設計的核心：

$$n = \frac{N_D - N_A + \sqrt{(N_D-N_A)^2 + 4n_i^2}}{2}$$

### pn 接面：整流之謎
p 型與 n 型相接時，載子擴散形成空乏區與內建電位 $V_{bi}$：

$$V_{bi} = \frac{kT}{q} \ln\!\frac{N_A N_D}{n_i^2}$$

Shockley 二極體方程描述其整流特性：

$$I = I_S\left(e^{V / nV_T} - 1\right), \qquad V_T = \frac{kT}{q} \approx 26\,\mathrm{mV} \ (300\,\mathrm{K})$$

順偏時電流指數上升，逆偏時只剩微小飽和電流 $I_S$ —— 這種非對稱性就是「檢波/整流」的數學本質。

### 破案時刻：點接觸電晶體
1947 年 12 月 23 日，Bardeen 與 Brattain 在 n 型鍺片上放置兩根相距約 50 μm 的金觸針（發射極與收集極），底部為基極。發射極注入電洞（少數載子），擴散至收集極被收集——輸入小電流即可控制輸出大電流，實現放大。

Shockley 不甘只在旁觀，一個月後閉關推導出更穩健的**接面電晶體（BJT）**：夾心結構 p-n-p 或 n-p-n，中央基極極薄，少數載子穿越基極的傳輸效率 $\alpha$ 接近 1。

電流增益的定義：

$$\beta = \frac{I_C}{I_B} = \frac{\alpha}{1 - \alpha}$$

當 $\alpha = 0.99$ 時 $\beta = 99$，小基極電流撬動大集極電流——這就是「電晶體」（transfer + resistor）的物理。

### Python 驗證：pn 接面 I-V 特性曲線

```python
import numpy as np
import matplotlib.pyplot as plt

# Shockley 二極體方程 I = IS * (exp(V/(n*VT)) - 1)
q, k, T = 1.602e-19, 1.381e-23, 300.0
VT = k * T / q          # 熱電壓 ~ 25.85 mV
IS, n = 1e-12, 1.0      # 飽和電流、理想因子

V = np.linspace(-0.4, 0.8, 500)
I = IS * (np.exp(np.clip(V / (n * VT), -50, 50)) - 1)

plt.plot(V, I * 1e3)
plt.xlabel("Voltage V (V)")
plt.ylabel("Current I (mA)")
plt.title("pn Junction I-V (Shockley Diode Equation)")
plt.grid(True)
plt.show()
```

曲線在 $V \approx 0.6\,\mathrm{V}$ 附近急遽上升，逆偏則近乎水平——「單向閥門」得到數值驗證。

## 結案 -- 後果與影響
- 1956 年，Bardeen、Brattain、Shockley 三人獲**諾貝爾物理學獎**，是史上極少數由同一實驗室團隊共享的案例。
- Shockley 後赴 Palo Alto 創辦半導體實驗室，間接催生「八叛逆」與 Fairchild、進而催生 Intel——電晶體發明案直接點燃了矽谷。
- 電晶體尺寸從毫米級縮小到奈米級，單晶片電晶體數從個位數成長到數百億，摩爾定律自此啟航。
- 真空管三大暴政（體積、功耗、壽命）被徹底推翻：現代電晶體開關能耗僅皮焦耳級，壽命以十年計。
