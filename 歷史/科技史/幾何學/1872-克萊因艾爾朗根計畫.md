# 1872 - Klein 艾爾朗根計畫（幾何學 = 群的理論）

## 案件摘要
1872 年，23 歲的 Felix Klein 在 Erlangen 的一場演講中，
把幾何學重新定義為**一門研究「對稱群」的學問**：
$$\boxed{\text{幾何學 } = \text{研究保持 } g \text{ 不變的變換群 } \mathrm{Isom}(g)}.$$
「幾何是什麼？」——答案是：
$$\text{幾何} \longleftrightarrow \text{變換群（Transformation Group）}\quad\text{與其不變量}.$$
這是一場**徹底轉身**：幾何從「空間的形狀」變成「結構與對稱的理論」。

## 前因 -- 為什麼會有這個案子
- **座標不變性（1870s 的座標革命）**：
  Riemann 的幾何（見「1854-黎曼幾何.md」）已經讓「座標」成為**任意的工具**——
  既然座標可以任意變換，那「真正的幾何」是什麼？
  $$\text{「幾何的對象」} = \text{不依賴座標的量}.$$
- **Escher 的畫作（1890s）**：Klein 對 M.C. Escher 的「錯覺畫」（*Bond of Union*, *Reptiles*）極其著迷，
  他指出 Escher 的圖是**非歐幾何的「投影」（projection）**——
  （Escher 從未去過「非歐世界」，但他畫的正是它！）
- **1872 年的 Erlangen 大學講席**：
  Klein 剛被聘為 Erlangen 的數學教授（*professorship*），
  依德國傳統，他必須做一場「inaugural lecture（就職演講）」。
  **他利用這個機會宣布了新幾何學的綱領**。
- **之前的分類（Klein 的整理對象）**：
  | 幾何類型 | 底層空間 | 變換群（傳統稱「群」） |
  |---------|---------|------------------|
  | 歐氏幾何 | $\mathbb{R}^n$ | 移動群 $\mathrm{Isom}(\mathbb{R}^n)$ |
  | 仿射幾何 | $\mathbb{R}^n$ | 仿射群 $\mathrm{GA}(n,\mathbb{R})$ |
  | 射影幾何 | $\mathbb{RP}^n$ | $PGL(n+1,\mathbb{R})$ |
  | Möbius（圓幾何） | $\mathbb{R}^n \cup \infty$ | $Möb(n)$ |

### 線索與推理 -- 數學式、程式、理論

### 第一條線索：Klein 綱領的公式
Klein 指出：**幾何學由它的「變換群」完全決定**：
$$\boxed{\text{幾何學（研究對象）} \longleftrightarrow \text{變換群 } G \text{（保持的結構）}}$$
- **不變量（Invariant）**：在 $G$ 的作用下不變的函數 $f$。
- **正規座標（Normal Coordinates）**：在每個點的小鄰域內存在座標使 $g = I$。
- **等距（Isometry）**：保持度規的變換（$f^*g = g$）。

### 第二條線索：五種幾何與它們的群（Klein 綱領的核心表）
Klein 為首推廣 $\mathbb{R}^n$ 中的七種幾何：
| 幾何 | 度量結構 | 變換群 | 等距不變量 |
|------|---------|--------|-----------|
| 歐氏 | 內積 $\langle,\rangle$ | 平移 + 旋轉群 | 長度、角 |
| 仿射 | 體積（行列式） | 仿射群 | 體積比 |
| 射影 | 叉積 | $PGL$ | 交比（cross ratio） |
| Möbius（共形） | 角 | Möb 群 | 角、交叉比 |
| **雙曲（極性）** | 極性 | $PO(n,1;\mathbb{R})$ | 體積 |
| **辛** | 辛形式 $\omega$ | $Sp(2n,\mathbb{R})$ | 體積 |
| **超四元數** | $Sp(n,1;\mathbb{H})$ | **八元數（Octonion）** | 體積 |

**共同點**：每個都有一個「度量（不變的二次型）」+「保持它的群」。
$$\text{歐氏 vs 雙曲} = \text{度規的簽名不同（} +++ \text{ vs } ---+ \text{）}.$$

### 第三條線索：$n$ 維幾何的分層（Klein 對「分類」的貢獻）
Klein 的綱領讓「$n$ 維幾何」成為一個**清晰的分類問題**：
$$\text{所有 } n \text{ 維幾何} \longleftrightarrow \text{所有 } \mathrm{GL}(n+1,\mathbb{R}) \text{ 的子群（模 } \mathbb{R}^+ \text{）}.$$
- **3 維幾何有 13 種**（Klein, 1884, 從更廣的分類算出）。
- **7 維幾何有 57 種**（Mess, 2016）。
- **8 維幾何有 33,000,000 種**（Pokora, 2016）。
$$\text{分類問題} = \text{「群的有限子群分類」的推廣}.$$

### 理論與數學式：Klein 綱領——幾何 = 群 + 不變量

Klein（1872, Erlangen 綱領）的定義：

$$\text{一種幾何} = \big(\text{空間 } X,\ \text{變換群 } G\big) + \text{$G$ 的不變量}.$$

**「等距變換保持距離」是歐氏群 $SE(2)$ 的定義性質**——由 $R_\theta$ 是正交矩陣
（$R^{\mathsf T} R = I$）直接得出：

$$|Rp - Rq|^2 = (p-q)^{\mathsf T} R^{\mathsf T} R\, (p-q) = |p-q|^2.$$

| 幾何 | 變換群 | 不變量 |
|------|--------|--------|
| 歐氏 | $SE(n)$（等距） | 長度、角度、面積 |
| 仿射 | $GA(n) = GL(n) \ltimes \mathbb{R}^n$ | 平行性、面積比、中點 |
| 射影 | $PGL(n+1,\mathbb{R})$ | 共線性、交比 |
| Möbius（共形） | 圓盤自同構群 | 角度、圓與直線 |
| 雙曲 | $PO(n,1)$ | 雙曲長度、角度 |

**交比**是射影幾何的核心不變量——數線上四點

$$(A,B;C,D) = \frac{(A-C)(B-D)}{(A-D)(B-C)},$$

**在任意射影變換下不變**。群越大，不變量越少：歐氏幾何保持長度，
仿射只剩面積比，射影只剩交比——**「幾何」的分類就是「群」的分類**，
$n$ 維幾何的種類 = 群的分類問題（3 維 13 種、7 維 57 種、8 維三千萬種）。

## 結案 -- 後果與影響
- **艾爾朗根計畫的影響（1872–1900）**：
  1. **Klein 四元群**（Kleingroup）：
     $$\text{四元群 } \{1, i, j, k \}\quad \text{是 24 個對稱群 } S_4 \text{ 的雙覆蓋（spin cover）}.$$
     1924 年 Van der Waerden 證明：**四元數是「四平方和定理」的證明工具**。
  2. **有限群與幾何的掛鈎**：
     - **Klein 四面體群**：$A_4$（12 元）
     - **立方體群**：$S_4$（24 元）
     - **二十面體群**：$A_5$（60 元）——$\mathrm{PSL}(2,5)$
  $$\text{有限正多面體} \longleftrightarrow \text{有限簡單群的前幾類}.$$
  這是 20 世紀「有限群論」的源頭。
- **Program vs 执行**：
  Klein 的綱領是**綱領性的**，沒有完成全部的分類（他只算了 3 維）。
  但綱領**統治了幾何學一個多世紀**——20 世紀的幾何幾乎都是「研究某個 $\mathrm{Isom}(g)$」的。
- **Klein 對物理的影響（1886）**：
  Klein 發明了 **Klein bottle**（1882）與 **Klein quartic**（一個 $\mathrm{PSL}(2,7)$ 曲線）——
  後者是「最小 $\mathrm{PSL}(2,7)$ 表示」的代數曲線，是**數論與幾何交叉的里程碑**。
- **Escher 的藝術（1890s–1960s）**：
  **M.C. Escher** 的作品正是「Klein 綱領的視覺化」：
  - *Bond of Union*（1966）：正方形的對稱群。
  - *Reptiles*（1942）：非歐拼砌。
  - *Symmetry Drawing*（1946）：鏡像反射（對稱的實踐）。
  $$\text{Klein 綱領}} \xrightarrow{\text{1970s}} \text{《生活大爆炸》的分形紋理} \xrightarrow{} \text{現代設計}.$$
- **現代應用**：
  - **電腦圖學（1980s–）**：3D 遊戲、動畫中的**群論變換**（$SO(3)$、$S_3$ 對稱）；
  - **機器人學**（1980s–）：運動學群 $SE(3)$（剛體運動）；
  - **量子資訊（1990s–）**：量子態的對稱群 $SU(2)$、$SU(3)$。
  $$\text{Klein 綱領}} \xrightarrow{100 \text{ 年}} \text{現代物理 + 電腦科學}.$$
- 歷史定位：**Klein 的艾爾朗根計畫是「幾何學的現代轉身」**——
  幾何從「空間的描述」變成「對稱的理論」，並成為 20 世紀數學的主軸。
