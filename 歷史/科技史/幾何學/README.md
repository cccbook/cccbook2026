# 幾何學 -- AI 偵探風格

以「推理探案」的方式，追查幾何學三千年的每一場危機與轉身：
前因是什麼？線索在哪裡？推理如何展開？後果又如何改變了整個數學與物理？

核心謎題只有一個：**「形狀」與「空間」到底是什麼？它們是物件，還是我們思維的產物？**

## 三大歷史脈絡

1. **公理化（Euclid → Hilbert）**：幾何從「測量技藝」變成「形式系統」。
2. **座標化與代數化（Descartes → 幾何代數）**：形狀變成方程式，圖形變成可計算物件。
3. **抽象化與拓樸化（Klein → Perelman）**：幾何不再問「多長」，而問「在何種變換下保持不變」。

## 非歐與黎曼幾何的專線

非歐幾何與黎曼幾何是本卷最長的一條主線，貫穿三千年：

$$\text{內在幾何（1827）} \to \text{公理革命（1829/1832）} \to \text{曲率即幾何（1854）} \to \text{模型實現（1868）} \to \text{物理現實（1908/1916）} \to \text{規範場（1918）} \to \text{大統一（1926）} \to \text{嵌入（1936/1954）} \to \text{幾何化（1982）} \to \text{Ricci 流（2003）}$$

- **內在幾何**：Gauss 絕妙定理——曲率是內在量，曲面上的居民不需要離開曲面。
- **公理革命**：Lobachevsky、Bolyai——平行公設可以「不成立」而幾何依然自洽。
- **曲率即幾何**：Riemann——度規決定空間的一切內在性質。
- **模型實現**：Beltrami 偽球面、Poincaré 圓盤——雙曲幾何「可以被畫出來」。
- **物理現實**：Minkowski 時空、Einstein 廣義相對論——重力 = 時空曲率。
- **規範場**：Weyl——對稱決定相互作用；規範場 = 纖維叢上的聯絡。
- **大統一**：Cartan——活動標架、微分形式、聯絡與曲率的現代語言。
- **嵌入**：Whitney（$\mathbb{R}^{2n}$）、Nash（等距）——抽象流形 = 歐氏空間的子流形。
- **幾何化**：Thurston——三維空間是八種幾何的有限組合；Mostow 剛性；Gromov 雙曲群。
- **Ricci 流**：Perelman——幾何化猜想與龐加萊猜想的最終證明。
