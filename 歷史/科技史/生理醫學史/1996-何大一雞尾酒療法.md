# 1996 - 何大一的雞尾酒療法（HIV 從絕症到慢性病）

## 案件摘要
1996 年，美國艾伦戴蒙德愛滋研究中心的**何大一 (David Ho)** 在《Nature》發表
**雞尾酒療法 (HAART, 高效抗反轉錄病毒治療)**——
**三種藥物同時聯合**（兩種反轉錄酶抑制劑 + 一種蛋白酶抑制劑），
**病毒量降到檢測不到、CD4 回升、AIDS 從絕症變成慢性病**。
**「先發制人、多重打擊」**——**HIV 的高突變率被三重打擊壓制**——
**AIDS 的死亡率暴跌 80%+**。**何大一獲 1996 年《時代》年度風雲人物**——
**瘟疫的偵破者成為時代的面孔。**

## 前因 -- 為什麼會有這個案子
- **AZT 的單藥困境**：1987 年的 AZT（第一個抗 HIV 藥）**單獨使用**——
  初期有效、**數月後抗藥性出現**——HIV 的**突變率極高**
  （反轉錄酶無校正功能：**每天產生 ~10^9 個新病毒、每個基因組 ~1 個突變**）——
  **單一藥物 = 天擇的單一選壓 = 抗藥株迅速放大**（Fleming 1945 的警告）。
- **HIV 的動力學偵破（1995）**：何大一與 Perelson 用**數學建模**偵破 HIV 的動力學——
  **病毒不是「潛伏」，是「爆發性生產 + 快速清除」**：
  $$\text{每天生產 } 10^{10} \text{ 個病毒}， \qquad \text{病毒半衰期 } \sim 0.5 \text{ 天}.$$
  **血漿病毒的半衰期只有半天**——**病毒在「瘋狂生產」**——
  **這推翻了「潛伏」的常識**，並推論：**打擊要早、要多、要狠**——
  **「先發制人 (hit early, hit hard)」的誕生。**
- **蛋白酶抑制劑的線索（1995）**：HIV 的**蛋白酶**（切割病毒蛋白的酶）被
  結晶（1990s）——**蛋白酶抑制劑**（saquinavir 1995）問世——
  **靶點的第三個**（反轉錄酶 x2 + 蛋白酶）——**三藥聯合成為可能。**

## 線索與推理 -- 數學式、程式、理論

### 核心推理：HIV 的病毒動力學
何大一與 Perelson 的數學模型（1995）：
$$\frac{dV}{dt} = P(t) - cV， \qquad P(t) = \text{生產率}， \quad c = \text{清除率}.$$
- 用藥前：穩態 $V_0 = P_0/c$（生產與清除平衡——表面「潛伏」）
- **用藥後**：生產被抑制（$P \to 0$）→ 病毒指數衰減 $V = V_0 e^{-ct}$
- **實測衰減率**：$c \approx 0.5$/天 → **病毒半衰期 ~1.4 天、產量 $10^{10}$/天**

$$\text{衰減曲線的實測} \Longrightarrow \text{生產率 } 10^{10}\text{/天} \Longrightarrow \text{病毒在「瘋狂生產」}.$$
**數學偵破的意義**：**「潛伏」的常識被衰減曲線推翻**——
**病毒量高 = 生產快 = 突變多 = 抗藥快**——**單藥必失敗的數學必然**：
$$P(\text{抗藥突變}) \propto \text{病毒量} \times \text{突變率} \approx 10^{10} \times 10^{-4} = 10^6 \text{ 個/天}.$$
**每天 100 萬個抗藥突變**——**任何單藥都會被迅速繞過**——
**多重打擊的數學**：三藥聯合需要**同時突變三個靶點**——
$$P(\text{三重抗藥}) \approx 10^{6 \times 3} = \text{天文數字} \to 0.$$
**三藥 = 抗藥性的關閉**——**這是雞尾酒療法的數學核心。**

### 核心推理二：三藥聯合的臨床偵破
1996 年的臨床結果（AIDS 的翻案）：
| 指標 | 單藥（AZT） | **雞尾酒（HAART）** |
|------|------------|---------------------|
| 病毒量 | 數月後回升 | **檢測不到（<50 copies/mL）** |
| CD4 | 緩慢下降 | **回升** |
| AIDS 死亡率 | 高 | **暴跌 80%+** |
| 治療定位 | 暫時延命 | **終身慢性病** |

**AIDS 從絕症變成慢性病**——**1996 年的翻案**：美國 AIDS 死亡率
在 1996–1997 年暴跌 80%——**瘟疫的偵破一戰成功。**

### 雞尾酒的三味藥
| 藥物類別 | 靶點 | 例子 |
|---------|------|------|
| NRTI（核苷類反轉錄酶抑制劑） | 反轉錄酶 | AZT、3TC |
| **PI（蛋白酶抑制劑）** | 蛋白酶 | saquinavir、ritonavir |
| NNRTI（非核苷類） | 反轉錄酶（變構位） | nevirapine |
| **整合酶抑制劑（2007+）** | 整合酶 | raltegravir |

## 結案 -- 後果與影響
- **AIDS 的翻案**：死亡率暴跌 80%、壽命接近正常——
  **HIV 從死刑判決變成終身慢性病**——**數千萬人的性命被救回**。
- **病毒動力學的誕生**：數學建模（生產/清除/突變）= 感染病治療的工程語言——
  **B 型肝炎、C 型肝炎的治療全部沿用**（DAAs 2014 根治 C 型肝炎）。
- **抗藥性的策略**：多重打擊 = 抗藥性的關閉——
  **結核（MDR-TB）、C 型肝炎、癌症的聯合治療**——
  **Fleming 1945 的警告被何大一的數學回答**。
- **先發制人的策略**：早治療 = 病毒庫小 = 易控制——
  **HIV 的早期治療準則**（START 試驗 2015）——**發病前治療**。
- **何大一的定位**：1996 年《時代》年度風雲人物——**亞裔科學家的里程碑**——
  **偵破者成為時代的面孔**（Salk 1955 的迴響）。
