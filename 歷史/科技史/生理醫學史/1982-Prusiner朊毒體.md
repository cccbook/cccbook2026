# 1982 - Prusiner 的朊毒體（只有蛋白質的傳染兇手）

## 案件摘要
1982 年，加州大學舊金山分校的 Stanley Prusiner 在《Science》發表：
**羊搔癢症的傳染因子不含核酸——只有蛋白質**——他命名為
**朊毒體 (prion, proteinaceous infectious particle)**。
**中心法則（核酸是遺傳物質）的第二次地震**：**沒有核酸也能傳染**——
**蛋白質構象的改變本身就是「遺傳」**（正常 PrP^C → 病態 PrP^Sc → 誘導更多 PrP^Sc）。
**庫賈氏症、狂牛症、羊搔癢症的兇手現形**——**這是生物學最異端的偵破。**
（1997 年諾貝爾生理醫學獎。）

## 前因 -- 為什麼會有這個案子
- **羊搔癢的懸案**：1930 年代起，羊搔癢症 (scrapie) 的傳染因子**無法被偵破**——
  **紫外線、輻射（破壞核酸的武器）殺不死它**——**但它會傳染**！
  **Koch 法則失效：無法培養、無法看到核酸**——**兇手的身份是懸案。**
- **庫賈氏症的怪異**：人類的庫賈氏症 (CJD)——**散發性（無傳染途徑）**、
  **家族性（遺傳）**、**醫源性（手術器械傳染）**——**三種模式、一個病因**——
  **1970 年代的解釋（慢病毒）說不通。**
- **Prusiner 的偵探執著**：1972 年他的病人死於 CJD——他決定研究——
  **十年、逐步提純**：把傳染因子提純到極致，測量它的化學成分——
  **含氮、不含磷、抗核酸武器、被蛋白酶部分消化**——**只有蛋白質！**
- **命名（1982）**：prion = **pr**oteinaceous **i**nfectious **o**n——
  **「蛋白質傳染顆粒」**——**核酸中心的教條被直接挑戰。**

## 線索與推理 -- 數學式、程式、理論

### 核心推理：構象 = 遺傳（核酸的缺席）
Prusiner 的偵破（成分確認 + 機制假說）：
$$\text{傳染因子} = \text{抗紫外} + \text{抗輻射} + \text{抗 DNase/RNase} + \text{含蛋白質} \Longrightarrow \text{只有蛋白質}.$$
**機制的偵破**（Griffith 1967 年的理論預言 + Prusiner 的實驗確認）——
**構象的模板複製**：
$$\text{PrP}^{C}（\text{正常構象}） + \text{PrP}^{Sc}（\text{病態構象}） \to 2\,\text{PrP}^{Sc} \to 4\,\text{PrP}^{Sc} \to \cdots$$
- **PrP^C**：正常的膜蛋白（α 螺旋為主，無害）
- **PrP^Sc**：病態構象（**β 摺板**為主，聚集、不可溶、致神經死亡）
- **PrP^Sc 誘導 PrP^C 轉換構象**——**指數級的構象擴散**——**這就是「遺傳」**

**構象 = 遺傳資訊的載體**——**沒有核酸、沒有序列，只有形狀的傳播**——
**中心法則的第二次修正**（Temin 1970 的第一次修正的再延伸）：
$$\text{DNA} \rightleftarrows \text{RNA} \to \text{蛋白質}， \qquad \text{蛋白質構象} \to \text{蛋白質構象}（\text{旁支}）.$$

### 核心推理二：三種模式的統一
庫賈氏症的三種模式被同一機制統一：
| 模式 | 傳播途徑 |
|------|---------|
| 散發性 | PrP^C **自發突變**成 PrP^Sc（機率 ~百萬分之一） |
| 家族性 | **PrP 基因突變**（易變成病態構象）——**遺傳** |
| 醫源性 | 外源 PrP^Sc 感染（器械、腦膜移植物）——**傳染** |
| 狂牛症 | 牛飼料含病牛的肉骨粉 → **種間傳播** → 變種 CJD（vCJD） |

**狂牛症的地震（1996）**：英國的狂牛症（BSE）→ 人類變種 CJD（vCJD，吃了病牛肉）——
**種間屏障被跨越**——**185 萬頭牛被撲殺、170 人死於 vCJD**——
**朊毒體的公共衛生地震**。

## 結案 -- 後果與影響
- **中心法則的旁支**：蛋白質構象的傳播 = **表觀遺傳的極端形式**——
  **酵母的朊毒體**（真核生物的「有益」朊毒體，功能性的構象遺傳）——
  **構象遺傳成為生物學的新維度**。
- **公共衛生的地震**：狂牛症 → vCJD——**食物鏈的朊毒體傳播**——
  **肉骨粉禁令、血液捐贈限制**（朊毒體在血中傳播）——
  **食品安全的新戒律**。
- **藥物的懸案**：朊毒體疾病**無藥可治**（不可逆的構象轉換）——
  抗朊毒體藥物至今是懸案（小分子穩定 PrP^C 的嘗試）。
- **異端的公道**：Prusiner 的理論被嘲笑十年（**「只有蛋白質？不可能！」**）——
  **1997 年諾獎**——**異端的堅持 → 偵破 → 封聖**（Temin 1970、Semmelweis 1847 的迴響）。
- **蛋白質摺疊的橋樑**：PrP^C → PrP^Sc = **錯誤摺疊的疾病**——
  阿茲海默（類澱粉蛋白）、帕金森（α-突觸核蛋白）、亨廷頓——
  **錯誤摺疊疾病的大家族**——**朊毒體是第一個被偵破的成員**，
  也為 AlphaFold（2022）的蛋白質結構偵查鋪路。
