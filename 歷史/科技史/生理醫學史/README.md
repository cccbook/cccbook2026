# 生理醫學史（含生物學）-- AI 偵探風格

以「推理探案」的方式，追查生理醫學與生物學從血液循環之謎到 mRNA 疫苗的每一步：
前因是什麼？線索在哪裡？推理如何展開？後果又如何改變了整個醫學、生物學與人類世界？
核心謎題只有一個：**生命這台機器，到底能不能被觀察、量化、讀寫、甚至改寫？**
