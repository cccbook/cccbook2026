# 1928 - Fleming 青黴素（一個污染的培養皿開啟抗生素時代）

## 案件摘要
1928 年 9 月，倫敦 St Mary's 醫院的 Alexander Fleming 度假回來，發現一個
**被黴菌污染的葡萄球菌培養皿**——黴菌周圍出現一圈**無菌環**。
他辨認出黴菌是青黴菌 (Penicillium)，其分泌物能殺死細菌，命名為**青黴素 (penicillin)**。
**這是醫學史上最著名的意外偵破**——但意外只提供了線索，
藥物化與量產要等 Florey 與 Chain（1940–1943），二戰救活了千百萬人。

## 前因 -- 為什麼會有這個案子
- **細菌感染的不治之症**：1920 年代，一個劃傷就可能死於敗血症、產褥熱、肺炎。
  李斯特的消毒術（1865）只能**預防**，不能**治療**——**殺菌藥物是懸案。**
- **前人的殘缺線索**：Ehrlich 的「魔法子彈」606（1909，治梅毒）證明**選擇性毒殺**可能；
  Domagk 的磺胺（1932）證明染料能殺菌——但都有毒副作用或抗藥性問題。
- **Fleming 的偵探素養**：他長期研究溶菌酶 (lysozyme, 1922)——天然抗菌物質。
  他的實驗室**故意不追求太乾淨**，喜歡保留舊培養皿觀察變化。
  **當意外發生時，只有有準備的眼睛看得見線索。**（Pasteur：「機遇偏愛有準備的頭腦。」）

## 線索與推理 -- 數學式、程式、理論

### 核心推理：無菌環 = 擴散 + 選擇性毒殺
Fleming 的推理：
1. 黴菌周圍出現無菌環 → 黴菌分泌**可擴散的抗菌物質**
2. 無菌環只殺死葡萄球菌、不傷白血球 → **選擇性毒殺**（Ehrlich 魔法子彈的實現）
3. 對革蘭氏陽性菌有效、陰性菌無效 → 抗菌譜有限，但**已足夠救命**

**選擇性毒殺的原理（現代解釋）**：青黴素抑制**肽聚糖合成**（細胞壁的交聯）——
細菌有細胞壁、人的細胞沒有，所以**毒性是選擇性的**：
$$\text{青黴素} + \text{轉肽酶 (PBP)} \to \text{交聯被抑制} \to \text{細菌裂解}.$$
人體細胞無細胞壁 → 無此靶點 → 低毒性。**這是抗生素的通用偵探公式：找細菌有、人沒有的靶點。**

### 劑量與藥效的數學：藥動學
青黴素在體內的濃度衰減（一階動力學）：
$$C(t) = C_0 e^{-kt}, \qquad t_{1/2} = \frac{\ln 2}{k} \approx 0.5 \text{ 小時（天然青黴素）}.$$
**半衰期太短是量產化之前最大的工程難題**——這解釋了為什麼 Fleming 放棄了提純
（他不是化學家），而 Florey 團隊改用**多次注射**維持濃度。

### Python：殺菌動力學與抗藥性的偵查

```python
import numpy as np

def kill_dynamics(C0, k, MIC, t_max=6, dt=0.1):
    # MIC：最低抑菌濃度。濃度高於 MIC 的時間 = 有效殺菌時間
    t = np.arange(0, t_max, dt)
    C = C0 * np.exp(-k*t)
    T_above_MIC = (C > MIC).sum() * dt
    return t, C, T_above_MIC

k = np.log(2) / 0.5                                  # 半衰期 0.5 小時
t, C, T = kill_dynamics(C0=100, k=k, MIC=1)
print(f"半衰期 = {np.log(2)/k:.1f} 小時")
print(f"有效殺菌時間（C > MIC）= {T:.1f} 小時 / 6 小時 → 需多次注射")

# 抗藥性 = 天擇的現場直播（見 Darwin 案）
def resistance(p0, w_res, w_sens, generations=10):
    p = p0                                            # 抗藥菌頻率
    for _ in range(generations):
        p = p * w_res / (p * w_res + (1-p) * w_sens)  # 用藥期間的天擇
    return p
for gens in [0, 5, 10, 20]:
    print(f"用藥 {gens} 代後，抗藥菌頻率 = {resistance(0.001, 1.0, 0.8, gens):.3f}")
```
輸出：
```
半衰期 = 0.5 小時
有效殺菌時間（C > MIC）= 3.4 小時 / 6 小時 → 需多次注射
用藥 0 代後，抗藥菌頻率 = 0.001
用藥 5 代後，抗藥菌頻率 = 0.003
用藥 10 代後，抗藥菌頻率 = 0.009
用藥 20 代後，抗藥菌頻率 = 0.080
```
**抗生素就是選壓，抗藥基因就是被選中的性狀**——Fleming 1945 年的諾獎演說中
親自警告：濫用青黴素會製造抗藥菌。**這個預言今天正在應驗（超級細菌）。**

## 結案 -- 後果與影響
- **抗生素時代**：青黴素之後，鏈黴素 (1943)、四環素 (1948)……
  幾十種抗生素改寫了醫學——**細菌感染從絕症變成藥方可治**。
- **人類壽命躍升**：20 世紀人類平均壽命從 ~45 歲升至 ~75 歲，
  抗生素 + 疫苗是最大的貢獻者——**一個污染的培養皿，延長了數十億人的生命。**
- **意外發現的方法論**：青黴素證明「意外 + 有準備的頭腦」可以偵破懸案——
  但它也警示：Fleming 放棄提純的 12 年，讓藥物晚了 12 年問世。
  **意外給線索，工程給答案。**
- **抗藥性的現場直播**：抗生素的選壓讓抗藥基因逐代放大——
  這是 Darwin 天擇（`1859-Darwin物種起源.md`）最快的實驗室驗證，
  也是今天的公共衛生懸案（超級細菌 MRSA）。
- **靶點偵探公式**：找「細菌有、人沒有」的靶點（細胞壁、核糖體 70S）——
  這成為所有抗生素研發的通用方法。
