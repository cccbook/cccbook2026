# 1859 - Darwin 物種起源（天擇解釋一切物種）

## 案件摘要
1859 年 11 月，Charles Darwin 出版《物種起源》(On the Origin of Species)。
他以**天擇 (natural selection)** 一個機制解釋千萬種物種的起源：
$$\text{變異} + \text{遺傳} + \text{繁殖差異} \xrightarrow{\text{天擇}} \text{新物種}.$$
這是生物學史上最大的翻案——物種從「神創的固定類型」變成「演化的動態結果」。
**所有生命共用一個家譜樹，人類也在樹上。**

## 前因 -- 為什麼會有這個案子
- **小獵犬號的五年**：1831–1836 年，Darwin 以博物學家身分環球航行。
  加拉巴哥群島的雀鳥（每島鳥喙形狀不同）、南美的化石（大地懶與現存犰狳相似）——
  **物種隨地理變化**，這是固定類型論解釋不了的。**觀察是線索，類型論是兇手。**
- **類型論的絕望**：神創論說每個物種都是被個別創造的固定類型。
  但化石紀錄顯示物種會**出現與消失**，地理分佈顯示物種會**隨環境變化**。
  幾百萬個物種 = 幾百萬次個別創造？**不可否證、無解釋力。**
- **Malthus 的關鍵線索**：1838 年 Darwin 讀到 Malthus 的《人口論》：
  「人口以幾何級數增長，資源以算術級數增長——**必然有生存競爭**。」
  Darwin 電光石火：繁殖過剩 + 變異 + 遺傳 = **天擇**！
- **Wallace 的雙重偵破**：1858 年，Alfred Russel Wallace 在馬來群島瘧疾發燒中
  獨立想出同樣的機制，寄信給 Darwin——**兩人同時偵破，Linean 學會聯合發表 (1858)。**

## 線索與推理 -- 數學式、程式、理論

### 核心推理：天擇的三前提
Darwin 的推理只有三步（觀察 + Malthus 的數學）：
1. **繁殖過剩**：任何物種的後代數量呈指數增長
   $$N(t) = N_0 \cdot R^t, \quad R > 1.$$
   一對大象（最慢繁殖的動物）400 年後也能有 $1.9\times10^7$ 後代——但世界沒被大象塞滿。
2. **必然的淘汰**：資源有限 → 群體大小大致穩定 → **大多數後代活不到繁殖年齡**。
3. **差異化的存活**：後代有變異，**適應環境的變異更容易存活與繁殖**——
   這些變異被遺傳，逐代累積 = **天擇**。

$$\boxed{p_{t+1}(a) = \frac{p_t(a)\, w(a)}{\sum_{a'} p_t(a')\, w(a')}}$$
其中 $p_t(a)$ 是性狀 $a$ 的頻率、$w(a)$ 是適應度 (fitness)。**這是天擇的數學核心**：
適應度高的性狀頻率逐代上升。Fisher 1930 年證明：**適應度增加率 = 性狀的遺傳變異數**
（天擇基本定理）——演化必有方向，只要變異存在。

### Python：天擇的模擬（加拉巴哥雀鳥的鳥喙）

```python
import numpy as np

def natural_selection(p0, w, generations=50):
    # p0: 性狀頻率, w: 適應度
    p = np.array(p0, float)
    hist = [p.copy()]
    for _ in range(generations):
        p = p * w / (p * w).sum()          # 天擇更新
        hist.append(p.copy())
    return np.array(hist)

# 加拉巴哥：乾旱 → 大種子 → 喙大的雀適應度高
p0 = [0.9, 0.1]                            # 小喙 90%、大喙 10%
w  = [1.0, 1.6]                            # 大喙適應度 1.6 倍
hist = natural_selection(p0, w)
print("第 0 代 :", hist[0].round(3))
print("第 10 代:", hist[10].round(3))
print("第 50 代:", hist[-1].round(3))
```
輸出：
```
第 0 代 : [0.9 0.1]
第 10 代: [0.076 0.924]
第 50 代: [0. 1.]
```
50 代之後，大喙從 10% 幾乎完全取代小喙——**乾旱就是選壓，天擇就是引擎**。
（真實案例：Grant 夫婦 1977 年的乾旱實測，喙尺寸在一代之內增大 4–5%。）

### 遺傳的懸案
Darwin 的最大漏洞：**變異怎麼遺傳？** 他提出的「泛生論 (pangenesis)」是錯的。
答案要等 Mendel（1865，遺傳因子）與 Watson–Crick（1953，DNA）——
**遺傳機制的偵破，比天擇晚了近一世紀。**

## 結案 -- 後果與影響
- **生物學的統一**：天擇讓分類學、解剖學、胚胎學、地理學有了共同解釋——
  物種從固定類型變成演化樹上的節點，**所有生命有共同祖先**。
- **人類地位的翻案**：《物種的由來》(1871) 把人類放進演化樹——
  人從「神的形象」變成「與猿共祖」——維多利亞社會的地震。
- **孟德爾的接力**：1900 年 Mendel 被再發現，遺傳學與演化論合流為
  **現代綜合論** (modern synthesis, 1930s–1940s, Fisher/Wright/Haldane)。
- **工程的伏筆**：天擇 = 「變異 + 選擇 + 遺傳」的演算法——
  這是遺傳演算法 (Holland, 1975) 與演化計算的直接藍圖，
  也是強化學習中「變異選擇」思想的源頭（Turing 1950）。
- **醫學的後果**：抗藥性細菌 = 天擇的現場直播（見 `1928-Fleming青黴素.md`）——
  抗生素的選壓讓抗藥基因逐代放大。**天擇不只發生在加拉巴哥，也發生在你的藥盒裡。**
