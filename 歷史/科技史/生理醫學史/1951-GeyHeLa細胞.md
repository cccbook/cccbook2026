# 1951 - Gey 的 HeLa 細胞（第一株不死細胞系）

## 案件摘要
1951 年 2 月，約翰霍普金斯醫院的 George Gey 從**子宮頸癌病人 Henrietta Lacks**
的腫瘤組織取樣培養——細胞**不會死**，每 20 小時分裂一次、無限增殖。
他命名為 **HeLa**（Henrietta Lacks 的縮寫）——**人類第一株不死細胞系**。
**癌症 = 失控增殖的細胞**（Virchow 1855）的活體現形——
HeLa 之後，脊髓灰質炎疫苗、基因組定序、癌症研究、COVID 疫苗研發
**全部用過它**。**一個病人的腫瘤，餵養了七十年的醫學。**

## 前因 -- 為什麼會有這個案子
- **細胞培養的瓶頸**：1940 年代，人類細胞的體外培養**幾乎全數失敗**——
  細胞分裂幾十次就死亡（**Hayflick 極限**的先聲：正常細胞只能分裂 ~50 次）。
  **死亡是兇手：正常細胞的有限壽命讓長期實驗不可能。**
- **Lacks 的腫瘤**：Henrietta Lacks（31 歲，5 個孩子的母親）患子宮頸癌——
  她的腫瘤是**HPV-18 病毒感染**誘發的（1980s 偵破），
  表達**端粒酶 (telomerase)**——端粒不縮短，細胞不死。
- **Gey 的偵探直覺**：他培養人類細胞 20 年、失敗幾百次——
  他有**系統性的取樣策略**（每位子宮頸癌病人的組織都試），
  並用**滾筒培養法**（roller culture）讓細胞接觸更多營養。
  **第 1 次（其他人從沒成功過）就成功了**——運氣 + 準備 + 癌細胞的特性。

## 線索與推理 -- 數學式、程式、理論

### 核心推理：不死的兩把鑰匙
HeLa 為什麼不死（1980s–1990s 偵破）：
1. **HPV 病毒的癌蛋白**（E6、E7）：E7 失活視網膜母細胞瘤蛋白 (pRb)——
   **細胞週期的剎車被拆**；E6 失活 p53——**監控與凋亡的剎車被拆**
$$\text{pRb（剎車 1）} \xrightarrow{E7} \text{失活}， \quad \text{p53（剎車 2）} \xrightarrow{E6} \text{失活}.$$
2. **端粒酶**：癌細胞表達端粒酶——染色體末端的端粒**不隨分裂縮短**——
   **Hayflick 極限被繞過**（正常細胞每次分裂丟 50–100 bp，50 次後停止分裂）

$$\text{不死} = \text{剎車全拆（E6/E7）} + \text{端粒不縮（端粒酶）}.$$
**這是癌症的共同公式**——90% 的人類癌症都走這條路（剎車 + 端粒酶）。
**HeLa 是這個公式的第一個活體樣本。**

### 核心推理二：Hayflick 極限（後續偵破）
1961 年，Leonard Hayflick 發現正常細胞**只能分裂 50 次左右**——
**細胞的壽命是內建的**（端粒縮短）。HeLa 是這個極限的**反例**——
反例偵破了「細胞可以無限分裂」的誤解（Carrel 1912 的雞心臟培養神話），
也開啟了**衰老生物學**（端粒、端粒酶，Greider 與 Blackburn 1985 發現，2009 諾獎）。

### HeLa 的增殖偵查
| 項目 | 數值 |
|------|------|
| 倍增時間 | ~20 小時 |
| 70 年總量 | 估計 **5 萬公噸**（質量與 100 座帝國大廈相當） |
| 分布 | 全球 100+ 國家的實驗室 |
| 貢獻 | 脊髓灰質炎疫苗（1954）、基因組定序、COVID 疫苗 |

## 結案 -- 後果與影響
- **疫苗的救命鏈**：HeLa 是 Salk 小兒麻痺疫苗（1954）的**測試平臺**——
  Enders 的細胞培養 + HeLa 的增殖 = 疫苗量產的基礎（見 `1954-Salk小兒麻痺疫苗.md`）。
- **癌症生物學的模型**：E6/E7 + 端粒酶 = 癌症的共同公式——
  HeLa 是這個公式的第一個樣本，之後的幾千株癌細胞系（HeLa、MCF-7、A549……）
  成為癌症研究與藥物篩選的標準工具。
- **倫理的地震**：Lacks 家人**不知情**（組織被取走、細胞被商用）——
  1970 年代家人發現 HeLa 的存在，引發**知情同意與生物標本權利**的辯論——
  現代 IRB（倫理審查）規範的催化劑。**偵破的證據可以是偷來的——但代價要還。**
- **1951 年的性別與種族暗面**：Lacks 是 1950 年代種族隔離醫院的病人——
  她被葬在無名墓（直到 2020 年才立墓碑）。**HeLa 的功勞與 Lacks 的沉默並存七十年。**
- **端粒酶的諾獎**：Greider 與 Blackburn（1985）發現端粒酶——2009 年諾獎——
  **HeLa 的不死之謎，35 年後被分子生物學偵破。**
