# 1972 - Berg 的重組 DNA（基因可以「拼接」）

## 案件摘要
1972 年，史丹佛的 Paul Berg 完成**人類史上第一次重組 DNA**——
把**不同來源的 DNA**（病毒 SV40 與細菌噬菌體 λ）用限制酶剪開、
用連接酶接上，造出**雜種 DNA 分子**。
**基因可以像剪貼簿一樣被拼接**——基因工程的誕生。
Berg 因此獲 1980 年諾貝爾化學獎（與 Sanger、Gilbert 同獲）——
**Sanger 讓基因可讀（1977）、Berg 讓基因可寫（1972）、Cohen–Boyer 讓基因可種（1973）。**

## 前因 -- 為什麼會有這個案子
- **剪刀的線索（1970–71）**：限制酶——HindII（Smith 與 Wilcox, 1970）在特定序列切斷 DNA、
  EcoRI（1971）留下**黏性末端**（sticky ends，單鏈互補的尾巴）——
  **黏性末端 = 兩段 DNA 可以互相咬合的魔鬼氈**。**剪刀有了，缺的是膠水與程序。**
- **膠水的線索**：DNA 連接酶（1967, Gellert 等多實驗室）能把 DNA 片段的
  磷酸雙酯鍵**接合**——**天然的膠水一直存在**。
- **Berg 的偵探直覺**：他是病毒學家（研究 SV40 腫瘤病毒），
  他反問：**如果用 EcoRI 剪兩段不同來源的 DNA，黏性末端互補、連接酶接合——
  不就得到一個雜種分子？** 他與研究生 Jackson、Symons 用 SV40 + λ 噬菌體完成實驗——
  **生物學與化學的邊界在此消失：DNA 是可以剪貼的材料。**

## 線索與推理 -- 數學式、程式、理論

### 核心推理：黏性末端 = 拼接的魔鬼氈
EcoRI 的切割：
$$5'\text{-G A A T T C-}3' \xrightarrow{EcoRI} 
\begin{cases}
5'\text{-G} \quad \text{AATTC-}3' \\
3'\text{-CTTAA} \quad \text{G-}5'
\end{cases}$$
切口留下 **AATT 單鏈尾巴**（黏性末端）。兩段用 EcoRI 剪的 DNA，
尾巴**互補咬合**、連接酶封口：
$$\text{DNA}_1 + \text{DNA}_2 \xrightarrow{EcoRI + \text{連接酶}} \text{重組 DNA}.$$
**特異性的數學**：EcoRI 認 6 bp 序列——$4^6 = 4096$ bp 隨機出現一次——
**4 kb 的基因組有 ~1000 個切點、30 億的人類基因組有 ~73 萬個**——
剪刀的特異性讓拼接**可程式化**（CRISPR 2012 的先聲：剪刀 + 序列 = 可程式化編輯）。

### 核心推理二：質體 = 基因的運輸車（Cohen–Boyer, 1973）
Berg 的雜種 DNA **不能複製**（沒有複製起點）。1973 年，Cohen 與 Boyer 偵破了
最後一環：把外源基因拼進**質體 (plasmid)**——細菌的環狀小染色體（有自己的複製起點），
轉型（Avery 1944 偵破的機制！）送進大腸桿菌——
**細胞自己複製外源基因**：
$$\text{外源基因} + \text{質體} \xrightarrow{EcoRI + \text{連接酶}} \text{重組質體} \xrightarrow{\text{轉型}} \text{大腸桿菌} \to \text{基因量產}.$$
**基因可以種進細胞、讓細胞當工廠**——1978 年合成人類胰島素（Genentech，1982 年獲批——
第一個基因工程藥物，見 `1921-BantingBest胰島素.md` 的接力）、
1980 年代的生技產業全部由此誕生。

### 重組 DNA 的工具箱
| 工具 | 功能 | 偵破年 |
|------|------|--------|
| 限制酶（EcoRI、HindII） | 剪刀（特定序列） | 1970–71 |
| DNA 連接酶 | 膠水（磷酸雙酯鍵） | 1967 |
| 質體 | 運輸車（複製起點） | 1973 |
| 大腸桿菌轉型 | 生產工廠 | 1944（Avery） |
| Sanger 定序 | 品管（讀出驗證） | 1977 |

## 結案 -- 後果與影響
- **基因工程的誕生**：讀（Sanger）+ 寫（Berg）+ 種（Cohen–Boyer）——
  基因從抽象因子變成**可操作的工業材料**——生技產業（Genentech 1976、
  Amgen 1980）與轉基因生物的起點。
- **第一個基因工程藥物**：1982 年人類胰島素獲批（Humulin）——
  從狗的胰腺萃取（1921）到細菌工廠量產（1982）——**61 年的接力**。
- **Asilomar 會議（1975）的先聲**：Berg 在完成實驗後**主動暫停**——
  他召集全球專家訂出**重組 DNA 的安全準則**（生物安全的誕生）——
  **偵破者先於社會自我設限**（賀建奎 2018 的反面教材——倫理的兩種結局）。
- **CRISPR 的伏筆**：剪刀 + 序列特異性 = 可程式化——
  Berg 的限制酶是「蛋白質剪刀」，CRISPR（2012）是「RNA 嚮導的剪刀」——
  **同樣的偵破模式，更強的程式化**。
- **1980 年諾獎**：Berg（化學獎，重組 DNA）與 Sanger（第二次諾獎，定序）同屆——
  **讀與寫的偵探同台領獎**。
