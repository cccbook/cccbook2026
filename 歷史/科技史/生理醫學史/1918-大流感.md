# 1918 - 大流感（西班牙流感：史上最致命的瘟疫）

## 案件摘要
1918–1920 年的**大流感**（Spanish flu, H1N1）感染全球 5 億人（1/3 人口）、
死亡 **5,000 萬–1 億人**——**比一戰死亡人數還多、比黑死病更快的殺人兇手**。
它有三波疫情（1918 春、1918 秋、1919 冬），第二波**最致命**（死亡率最高），
且**專殺 20–40 歲的健康年輕人**（細胞激素風暴）——
**與一般流感相反的死亡年齡分佈**——這個特徵讓它成為流行病學的世紀懸案。
**兇手的完整身份（H1N1 病毒）要到 2005 年才被從凍土屍體中復原偵破——87 年。**

## 前因 -- 為什麼會有這個案子
- **一戰的完美風暴**：戰壕（擁擠）、運兵列車（跨國散播）、營養不良（免疫低下）——
  **一戰的軍事後勤 = 病毒的傳播網絡**。美國堪薩斯的軍營（1918/3 首例報告）
  → 東海岸 → 歐洲戰場 → 全球。
- **當年的無知**：1918 年**沒有人知道流感是病毒**（病毒 1898 年才被發現、
  流感病毒 1933 年才分離）——當年主流認為是**細菌**（「菲佛氏桿菌」被誤認為兇手）——
  **細菌理論的成功反而掩護了病毒**（Koch 法則的盲區）。
- **「西班牙流感」的冤案**：疫情**不是**起源於西班牙——西班牙（一戰中立國）
  的媒體自由報導疫情，**背了黑鍋**。**媒體自由 = 冤案的原因。**

## 線索與推理 -- 數學式、程式、理論

### 核心推理：W 型的死亡年齡分佈
一般流感的死亡分佈是 **U 型**（小孩與老人死）；
1918 大流感是 **W 型**——**20–40 歲的健康年輕人死得最多**！
$$\text{一般流感}： \text{U 型}（\text{免疫弱者死}） \qquad \text{1918}： \text{W 型}（\text{免疫強者也死}）。$$
**2005–2007 年的偵破**：1918 病毒引發**細胞激素風暴 (cytokine storm)**——
**免疫系統過度反應**（IL-6、TNF-α 飆升）→ 肺部的免疫殺傷 → 急性呼吸窘迫（ARDS）——
**免疫越強、風暴越大、死得越快**——**年輕人的強免疫 = 死因**。
**這推翻了「免疫弱者死」的常識**：兇手不是病毒本身的毒殺，是**宿主自己的免疫反應**。

### 核心推理二：三波疫情的動力學
1918 大流感的三波：
| 波次 | 時間 | 致命性 |
|------|------|--------|
| 第一波 | 1918 春 | 溫和（死亡率低） |
| **第二波** | **1918 秋** | **最致命（費城 6 週死 1.2 萬）** |
| 第三波 | 1919 冬 | 中等 |

**第二波的恐怖**：第一波的倖存者**有免疫**（波次之間有抗原變異但部分保護）；
**沒被第一波感染的年輕人**在第二波全數暴露——**波次的數學 = 抗原漂移 + 人群免疫的動態**。

### 復原與偵破（2005）
| 年份 | 偵破 |
|------|------|
| 1951 | Hultin 赴阿拉斯加凍土掘屍（失敗——樣本無法復原） |
| 1997 | Taubenberger 從福馬林固定的屍檢組織**定序出 H1N1 的部分基因** |
| 2005 | Hultin 再赴凍土（1997 年的 Lucy 屍體）——**完整復原 1918 病毒**（Tumpey 重建活病毒） |
| 2006–2007 | **細胞激素風暴**的確認（小鼠與靈長類實驗） |

**87 年的偵破**：1918 → 2005——**凍土屍體 = 未讀完的書**（古 DNA 的迴響）。

## 結案 -- 後果與影響
- **細胞激素風暴的偵破**：免疫過度反應 = 死因——
  **COVID-19（2020）的重症機制與 1918 相同**（ARDS、細胞激素風暴）——
  **87 年前的兇手手法，2020 年重演**——重症治療（類固醇、抗細胞激素）的依據。
- **疫苗與監測的誕生**：流感疫苗（1940s）、全球流感監測網（WHO, 1952）——
  **每年的疫苗更新 = 與抗原漂移的軍備競賽**。
- **公共衛生的教訓**：1918 年的封城、隔離、口罩令（舊金山 1918）——
  **非藥物干預（NPI）的有效性被確認**——COVID 2020 的封城政策的歷史依據。
- **西班牙的冤案**：命名之冤證明「疾病命名 = 政治」——
  COVID 的「武漢病毒」命名爭議是同一個教訓。**WHO 2015 年的命名準則**
  （不用地名）源自 1918 的冤案。
- **大流行的世代記憶**：1918 的世紀教訓（低估、遲緩、散播）——
  **2019 年的「Disease X」準備清單**、2020 年的 COVID 應對——
  **瘟疫的記憶每百年被重新學一次。**
