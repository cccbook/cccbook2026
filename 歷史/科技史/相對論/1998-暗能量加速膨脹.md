# 1998-暗能量加速膨脹

## 案件摘要
1998 年，Perlmutter/Schmidt/Riess 領導的兩個團隊用 Ia 型超新星測距，發現遠方超新星比預期**更暗**——宇宙膨脹正在加速。
神祕的「暗能量」佔宇宙 68%，Einstein 的 $\Lambda$ 以新身分復活，2011 年諾貝爾獎為此結案。

## 前因 -- 為什麼會有這個案子
- 1929 年 Hubble 發現宇宙膨脹；理論上，若宇宙只含物質，重力會使膨脹**減速**。
- 1990 年代標準假設：$\Omega_m < 1$ 的物質主導宇宙，減速參數 $q_0 = \frac{\Omega_m}{2} > 0$（減速）。
- 疑點一：物質密度測量遠低於臨界密度（$\Omega_m \approx 0.3$），宇宙「缺質量」。
- 疑點二：年齡問題——$\Omega_m = 1$ 的模型給出宇宙年齡小於最老的恆星，矛盾。
- **線索疑點（核心）**：要測膨脹是減速還是加速，需要看到紅移 $z \sim 0.5$ 以上的「過去」——需要極亮的標準燭光。
- Ia 型超新星（白矮星吸積到 Chandrasekhar 極限 $1.44\,M_\odot$ 爆發）亮度均勻，正是完美燭光。

## 線索與推理 -- 數學式、程式、理論

### 1. Ia 型超新星：標準燭光
- Phillips 關係（1993）：Ia 超新星光變曲線越寬，峰值越亮，可校準為「可校正的標準燭光」。
- 亮度均一性來自爆發機制：白矮星接近 Chandrasekhar 極限 $M_{Ch} \approx 1.44\,M_\odot$ 時碳爆燃，質量幾乎固定 → 峰值光度固定：

  $$L_{Ia} \approx 10^{10} L_\odot \approx 4\times 10^{35}\,\text{W}$$

  峰值絕對星等 $M_B \approx -19.3$，足以在宇宙學距離（數十億光年）被看到。

### 2. 關鍵線索：遠方超新星比預期暗
兩團隊（Perlmutter 的 SCP；Schmidt、Riess、Filippenko 的 High-Z Team）各自測得：
- 紅移 $z \approx 0.4\text{--}0.7$ 的 Ia 超新星，比「減速宇宙」模型預測的**暗約 20–25%**。
- 推理：更暗 = 更遠 = 膨脹歷史比減速模型**更快** = 加速膨脹。
- 消光（灰塵）與演化效應被逐一排除：灰塵會同時使顏色變紅，觀測未見系統性紅化。

### 3. 加速膨脹的數學：加速度方程
Friedmann 加速度方程：

$$\frac{\ddot{a}}{a} = -\frac{4\pi G}{3}\left(\rho + \frac{3p}{c^2}\right) + \frac{\Lambda c^2}{3}$$

**推理核心**：要使 $\ddot{a} > 0$（加速），必須有壓強為負的成分：

$$\rho + \frac{3p}{c^2} < 0 \quad\Rightarrow\quad p < -\frac{\rho c^2}{3}$$

宇宙學常數正是 $p_\Lambda = -\rho_\Lambda c^2$（狀態方程 $w = p/(\rho c^2) = -1$），強烈違反直覺——**負壓強**是本案最詭異的線索。
等僫地，含 $\Lambda$ 的 Friedmann 方程：

$$H^2 = \frac{8\pi G}{3}\rho_m + \frac{\Lambda c^2}{3} - \frac{kc^2}{a^2}$$

### 4. 暗能量與宇宙組成
- 暗能量密度：$\rho_\Lambda = \frac{\Lambda c^2}{8\pi G}$，宇宙學常數改寫為能量成分。
- Planck 2018 給出的宇宙組成：
  $$\Omega_\Lambda \approx 0.68\ (\text{暗能量 68\%}),\quad \Omega_{CDM} \approx 0.27\ (\text{暗物質 27\%}),\quad \Omega_b \approx 0.05\ (\text{普通物質 5\%})$$
- 我們熟悉的星辰，只佔宇宙的 5%——這是本案最震撼的結案陳詞。
- 年齡矛盾同步化解：$\Lambda$CDM 給 $t_0 \approx 138$ 億年，大於最老恆星年齡（約 132 億年）。

### 5. 2011 諾貝爾獎
- 2011 年諾貝爾物理獎授予 Saul Perlmutter、Brian Schmidt、Adam Riess，「透過遙遠超新星的觀測，發現宇宙加速膨脹」。
- Filippenko 等其他貢獻者因諾獎最多三人的限制而未獲獎。

### 6. Python 模擬 $\Lambda$CDM 的 $a(t)$

```python
import numpy as np
from scipy.integrate import odeint
import matplotlib.pyplot as plt

# Friedmann 方程 (ΛCDM, flat): (dadt/a)^2 = H0^2 (Ωm/a^3 + ΩΛ)
H0, Om, OL = 1.0, 0.3, 0.7     # 以 H0 為單位，Ωm+ΩΛ=1

def rhs(a, t):
    return a * np.sqrt(Om/a**3 + OL)

t = np.linspace(0.01, 3.0, 400)
a0 = 0.01
a_lcdm = odeint(rhs, a0, t).ravel()

# 對照：純物質宇宙 (Ωm=1)
a_mat = odeint(lambda a, t: a/np.sqrt(a**3), a0, t).ravel()

# 減速參數 q(z) = 0.5*Ωm/a^3 - ΩΛ
q = 0.5*Om/a_lcdm**3 - OL
print(f"今日減速參數 q0 = {q[-1]:.3f} (負值 = 加速膨脹)")

plt.figure(figsize=(9,5))
plt.plot(t, a_lcdm, 'b-', lw=2, label='ΛCDM (Ωm=0.3, ΩΛ=0.7) 加速')
plt.plot(t, a_mat, 'r--', lw=2, label='純物質 (Ωm=1) 減速')
plt.xlabel('時間 (H0^-1 為單位)'); plt.ylabel('尺度因子 a(t)')
plt.title('ΛCDM vs 純物質宇宙的膨脹歷史')
plt.legend(); plt.grid(alpha=0.3); plt.show()

# 距離模數差：遠方超新星更暗
z = np.linspace(0.01, 1.0, 200)
c = 299792.458
# 光度距離 (小 z 近似 + 積分 E(z))
E = np.sqrt(Om*(1+z)**3 + OL)
Dc = c/H0 * np.array([np.trapezoid(1/E[:i+1], z[:i+1]) for i in range(len(z))])
Dl_mat = Dc*(1+z)                       # 純物質（粗糙對照）
plt.figure(figsize=(8,5))
plt.plot(z, 5*np.log10(Dl_mat) + 25, label='ΛCDM 距離模數')
plt.plot(z, 5*np.log10(Dc/H0*np.ones_like(z)*(1+z)*0.85) + 25, 'r--', label='減速模型（超新星更亮/近）')
plt.xlabel('紅移 z'); plt.ylabel('距離模數 m-M'); plt.title('遠方 Ia 超新星比預期暗')
plt.legend(); plt.grid(alpha=0.3); plt.show()
```

$q_0 \approx -0.55$（負值）證實加速；距離模數圖顯示遠方超新星落在「更遠、更暗」的位置——1998 年的兩份觀測報告正是這條曲線上的散點。

## 結案 -- 後果與影響
- **結案**：宇宙膨脹正在加速，主導者是壓強為負的暗能量。Einstein 的 $\Lambda$ 從「最大錯誤」變成「最大的謎」。
- 2011 年諾貝爾獎結案。此後 DESI（暗能量光譜儀）、Euclid、Roman 望遠鏡繼續追查暗能量的本質。
- 深遠影響一：宇宙終極命運改寫——若 $w = -1$ 恆定，宇宙將走向永遠加速的「大凍結（Big Freeze）」，甚至遙遠未來的「大撕裂（Big Rip）」（$w < -1$）。
- 深遠影響二：量子場論計算的真空能量與觀測值差 $10^{120}$ 倍——「宇宙學常數問題」成為理論物理最深的懸案。
- 深遠影響三：暗能量 68% + 暗物質 27%，人類認識的物質只佔 5%——「普通」反而是宇宙的例外。
