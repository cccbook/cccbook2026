# 1824-Abel 五次方程無根式解

## 案件摘要
1824 年，22 歲的挪威青年 Abel 自費出版小冊子，證明：
**次數 $\ge 5$ 的一般代數方程不存在根式解**。
困擾數學界近三百年的謎團——為何三次、四次都有公式，五次卻找不到——就此結案。

## 前因 -- 為什麼會有這個案子
- **1545 年 Cardano/Ferrari**：三次方程 $x^3 + px + q = 0$ 有 Cardano 公式
  $$x = \sqrt[3]{-\frac q2 + \sqrt{\frac{q^2}{4} + \frac{p^3}{27}}} + \sqrt[3]{-\frac q2 - \sqrt{\frac{q^2}{4} + \frac{p^3}{27}}}$$
  四次方程也有 Ferrari 的降次解法。
- **兩百年謎團**：此後 Euler、Tschirnhaus 等人前仆後繼尋找五次公式，全部失敗。
  沒有人懷疑「公式根本不存在」——這是偵探學上最典型的盲點：**大家都在錯的現場找兇手**。
- **Ruffini（1799）**：義大利醫生 Ruffini 發表 300 頁證明，核心想法正確
  （根式解會強迫根的置換群具有某種「可解鏈」結構），但證明中缺少關鍵引理
  （關於置換乘積的組合性質，即後來 Jordan 補足的「 Jordan 引理」），
  且未證明輔助根式可用有理函數表示。數學界雖存疑但無法指出確切漏洞。
- 案件問題：**證明「不存在」需要什麼樣的武器？**

## 線索與推理 -- 數學式、程式、理論

### 線索一：根式解的結構學（Abel 的關鍵引理）
Abel 證明（現代表述）：
> 若一般 $n$ 次方程 $x^n + a_1 x^{n-1} + \cdots + a_n = 0$（係數為獨立變元）有根式解，
> 則其根域 $K$ 可由一列擴張搭起：
> $$\mathbb{Q}(a_1,\dots,a_n) = F_0 \subset F_1 \subset \cdots \subset F_m \ni \text{全部根}$$
> 其中每一步 $F_{i+1} = F_i(\sqrt[p_i]{\,u_i\,})$，且每個 $\text{Gal}(F_{i+1}/F_i)$ 是質數階循環群（阿貝爾群）。
> 根的置換群必須擁有這條「可解鏈」——**每個質因數層都只能是交換群**。

### 線索二：$S_5$ 沒有可解鏈
一般五次方程的根置換群是 $S_5$，$|S_5| = 5! = 120 = 2^3 \cdot 3 \cdot 5$。
若可解，需有一列正規子群
$$S_5 = G_0 \triangleright G_1 \triangleright \cdots \triangleright G_m = \{e\},\quad G_i/G_{i+1} \text{ 為交換群}$$
但 $A_5$（120/2 = 60 階的交錯群）是**單群**：它的正規子群只有 $\{e\}$ 與 $A_5$ 自身，
而 $A_5/\{e\} \cong A_5$ 不是交換群（例如 $(1\,2\,3)$ 與 $(1\,2\,4)$ 不可交換）。斷鏈，無解。$\blacksquare$

### 線索三：Abel 的證明路線與「Abel 函數」前驅
Abel 的原始證明（1824 小冊子、1826 修訂版《Démonstration de l'impossibilité...》發表於 Crelle's Journal 創刊號）
不使用群論名詞，而是自創「以根的置換為變元的函數論」：
- 他證明根式解中每個根式都可以表示成**已有根的有理函數**（Ruffini 缺失的那一環）。
- 他進一步研究橢圓積分的反函數——**Abel 函數**——開啟了雙週期函數理論，
  成為後來 Riemann 面與現代代數幾何的前驅。
- 同時期他還證明了二項級數的收斂性（Abel 判別法、Abel 定理），
  把「嚴格性」帶進分析學。

### Python 實作：數值方法顯示五次方程根無法用根式表達

```python
import numpy as np
from itertools import combinations

# 一般五次方程 x^5 + a1 x^4 + a2 x^3 + a3 x^2 + a4 x + a5 = 0
rng = np.random.default_rng(2026)
coeffs = [1.0] + list(rng.uniform(-5, 5, 5))
roots = np.roots(coeffs)
print("五次方程數值根：")
for r in sorted(roots, key=lambda z: (round(z.real, 6), z.imag)):
    print(f"  {r:.6f}")

# 反例：絕大多數五次方程的根是「超越表達」——
# 任何根式嵌套組合 r = f(c1,...,c5)（f 為根式塔）都無法窮舉。
# 我們可以驗證 Galois 對稱性：根的判別式是否為完全平方數
# （完全平方 <=> Galois 群落在 A5 內，仍不可解，但結構不同）
def disc_sign_test(coeffs):
    D = np.prod([(r_i - r_j) for r_i, r_j in combinations(roots, 2)]) ** 2
    # 一般五次方程判別式落在係數有理函數域，這裡只做數值示意
    return abs(D)

print("判別式（數值）：", disc_sign_test(coeffs))

# 對照組：x^5 - 2 = 0 有根式解 x = 2^(1/5)（Galois 群 F20，可解）
r2 = np.roots([1, 0, 0, 0, 0, -2])
print("x^5 - 2 的根（其一為 2^(1/5) ≈", 2 ** 0.2, "）：")
print(r2)
```

### 理論定義
> **定義（根式解）**：方程的根可由係數經加減乘除與開 $n$ 次方（$n$ 為正整數）之有限組合表出。
> **Abel–Ruffini 定理**：一般 $n$ 次方程（$n \ge 5$）無根式解。

## 結案 -- 後果與影響
- 結案陳詞：**不是數學家不夠聰明，而是武器不存在**——五次方程的對稱群 $S_5$ 太「硬」了。
- Abel 27 歲（1829 年 4 月 6 日）死於肺結核，貧困潦倒，死前兩天才收到柏林大學的教授聘書。
  他的手稿 1841 年才由 Crelle 整理出版。
- **Abel 獎（2003）**：挪威政府為紀念 Abel 設立，金額比照諾貝爾獎（約 750 萬挪威克朗），
  補上數學界沒有諾貝爾獎的遺憾。
- 1832 年 Galois 用群論給出**完整且可操作的判準**（可解性 ⟺ 群可解），
  並指出「哪些特定五次方程可解」——Abel 說的是「一般情況不存在」，
  Galois 回答的是「具體方程怎麼判」。
- 結案餘波：超越方程、橢圓函數、Abel 範疇（交換群以 Abel 命名）皆由此案衍生。
