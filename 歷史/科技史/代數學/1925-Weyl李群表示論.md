# 1925-Weyl 李群表示論

## 案件摘要
1925–1926 年，Hermann Weyl 在 Peter 的啟發下，用「最大權理論 + Weyl 特徵標公式」完整解決了半單李代數的不可約表示分類問題。連續對稱性的離散密碼被破譯，表示論從此成為數學與物理的共同語言。

## 前因 -- 為什麼會有這個案子
- 1870 年代 Jordan 奠定有限群論基礎（參照 [1870-Jordan群論](1870-Jordan群論.md)），但那是**離散**的對稱。
- Sophus Lie（1870–1890）研究**連續變換群**，產生李群 $G$ 與其切空間上的李代數 $\mathfrak{g}$：微分方程的對稱性理論。
- Killing（1888）與 Cartan（1894）完成半單李代數的**分類**：$A_n, B_n, C_n, D_n$ 與例外型 $E_6, E_7, E_8, F_4, G_2$。
- 1900 年代初，Cartan、Hurwitz 等已求出部分表示（如 $\mathfrak{sl}_2$），但「一般半單李代數的所有不可約表示是什麼？」仍是懸案。
- 1925 年：量子力學誕生（Heisenberg、Schrödinger），物理迫切需要一套處理連續對稱性的數學——Weyl 應聲出手。

## 線索與推理 -- 數學式、程式、理論

### 線索一：李群與李代數
李群 $G$ 的李代數定義為單位元處的切空間，配上換位括號：

$$\mathfrak{g} = T_e G, \qquad [X, Y] = XY - YX$$

例如 $SU(2)$ 的李代數 $\mathfrak{su}(2)$ 由反 Hermitian 無跡矩陣生成，常用基為：

$$\sigma_1 = \begin{pmatrix} 0 & i \\ i & 0 \end{pmatrix},\quad \sigma_2 = \begin{pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix},\quad \sigma_3 = \begin{pmatrix} i & 0 \\ 0 & -i \end{pmatrix}$$

滿足 $[\sigma_1, \sigma_2] = 2\sigma_2 \cdot (-1)\cdots$（即著名對易關係 $[J_1,J_2]=J_3$ 型）。李群非交換，但李代數把問題「線性化」——這是破案的顯微鏡。

### 線索二：根系、Weyl 群與權格
取 Cartan 子代數 $\mathfrak{h}$（極大交換），在其對偶 $\mathfrak{h}^*$ 上：
- **根系** $\Phi$：使 $\mathfrak{g}$ 的伴隨分解中出現特徵空間 $\mathfrak{g}_\alpha$ 的非零權 $\alpha$。
- **Weyl 群** $W$：由各 $\alpha$ 的反射 $s_\alpha(\lambda) = \lambda - 2\frac{(\lambda,\alpha)}{(\alpha,\alpha)}\alpha$ 生成的有限反射群。
- **權格** $P \subset \mathfrak{h}^*$：$W$ 不變的整格；**支配權** $\lambda$ 滿足 $(\lambda, \alpha^\vee) \ge 0$（對所有單根 $\alpha$）。

**最高權定理**：半單 $\mathfrak{g}$ 的每個有限維不可約表示都有唯一最高權 $\lambda$，且 $\lambda$ 是支配整權；反之每個支配整權給出唯一 $V_\lambda$。分類問題化為格點計數！

### 線索三：Weyl 特徵標公式
表示的特徵標 $\chi_\lambda(g) = \mathrm{tr}(g|V_\lambda)$ 完全決定表示。Weyl 證明（在 maximal torus $T$ 上）：

$$\chi_\lambda = \frac{\sum_{w \in W} \epsilon(w)\, e^{w(\lambda+\rho)}}{\sum_{w \in W} \epsilon(w)\, e^{w\rho}}, \qquad \rho = \frac{1}{2}\sum_{\alpha \in \Phi^+} \alpha$$

其中 $\epsilon(w) = \det(w) = (-1)^{\ell(w)}$ 是 Weyl 群元素的符號。分子是「反對稱化」，分母是 Weyl 分母恆等式。取 $\lambda = 0$ 即得 $|T|$ 的體積公式（Weyl 積分公式之源）。

**檢驗**：$\mathfrak{sl}_2$ 時 $W = \{1, s\}$，公式給出 $\chi_n = e^{n\alpha} + e^{(n-2)\alpha} + \cdots + e^{-n\alpha}$——正是 $n+1$ 維不可約表示的特徵標，與角動量理論 $j = 0, \tfrac12, 1, \ldots$ 完全吻合。

### 程式碼：Python numpy 實作 $\mathfrak{su}(2)$ 的表示矩陣與特徵標

```python
import numpy as np

# su(2) 的角動量生成元：自旋 j 表示（維度 2j+1）
def spin_rep(j):
    n = int(round(2 * j)) + 1          # 維度
    m = np.arange(j, -j - 1, -1)       # m = j, j-1, ..., -j
    Jz = np.diag(m).astype(complex)
    # J+ 上升算子：J+|j,m> = sqrt(j(j+1)-m(m+1)) |j,m+1>
    Jp = np.zeros((n, n), dtype=complex)
    for k in range(n - 1):
        Jp[k, k + 1] = np.sqrt(j * (j + 1) - m[k + 1] * (m[k] + 1))
    Jm = Jp.conj().T
    Jx = (Jp + Jm) / 2
    Jy = (Jp - Jm) / (2j)
    return Jx, Jy, Jz

# 驗證對易關係 [Jx, Jy] = i Jz
Jx, Jy, Jz = spin_rep(1.5)
print(np.allclose(Jx @ Jy - Jy @ Jx, 1j * Jz))   # True

# 特徵標：沿 maximal torus（即 exp(theta Jz)）求跡
def character(j, theta):
    n = int(round(2 * j)) + 1
    m = np.arange(j, -j - 1, -1)
    return sum(np.exp(1j * theta * mi) for m_i in m for mi in [m_i])

# Weyl 公式預測：chi_j(theta) = sin((2j+1)theta/2) / sin(theta/2)
import math
theta = 0.7
print(character(1.5, theta),
      math.sin(2 * theta) / math.sin(theta / 2))   # 相同（2j+1=4）
```

這段程式正是物理課本裡的角動量矩陣——數學的「權」就是物理的「磁量子數 $m$」。

## 結案 -- 後果與影響
- 半單李代數表示論**完全解決**：分類（最高權）+ 個數（特徵標公式）+ 生成（Verma 模，後由 Bernstein–Gelfand–Gelfand 發揚）。
- Weyl 1928 年出版《群論與量子力學》（*Gruppentheorie und Quantenmechanik*），把對稱性變成物理的組織原理：角動量 = $SO(3)$ 表示、同位旋、週期表的殼層結構。
- Weyl 積分公式、Peter–Weyl 定理成為緊群調和分析的基石。
- 表示論向無限維（單位表示、Langlands 綱領）與量子群（Drinfeld 1990 菲爾茲獎）擴張，至今仍是數學最活躍的交叉地帶。
