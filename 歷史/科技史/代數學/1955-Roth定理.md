# 1955-Roth 定理（Thue–Siegel–Roth 定理）

## 案件摘要
1955 年，Klaus Roth 證明：代數數 $\alpha$ 不可能被有理數「太準確」地逼近——不等式 $\left|\alpha - \frac{p}{q}\right| < \frac{1}{q^{2+\epsilon}}$ 對任意 $\epsilon > 0$ 只有有限多個有理解。這件案子終結了 Thue–Siegel 以來半世紀的追緝，並使 Roth 獲 1958 年菲爾茲獎。

## 前因 -- 為什麼會有這個案子
- **Dirichlet 逼近（1842）**：對任何實數 $\alpha$，存在無窮多個 $\frac{p}{q}$ 使
  $$\left|\alpha - \frac{p}{q}\right| < \frac{1}{q^2}$$
  指數 $2$ 是「人人可達」的下限；連分數理論給出構造性證明。
- **Liouville 定理（1844）**：若 $\alpha$ 是 $n$ 次代數數，則存在 $c(\alpha) > 0$ 使
  $$\left|\alpha - \frac{p}{q}\right| > \frac{c(\alpha)}{q^n}$$
  由此 Liouville 立刻造出第一批**超越數**（可被任意高次冪逼近的數）。
- **缺口**：Liouville 的指數 $n$ 很粗。Thue（1909）證明可改為 $n/2+1$，Siegel（1921）改為 $2\sqrt{n}$，Dyson（1947）改為 $\sqrt{2n}$。指數一步步逼近 $2$，但無人能跨越鴻溝。
- **懸案**：$2+\epsilon$ 的有限性是否成立？這是代數數逼近的「終極底線」。

## 線索與推理 -- 數學式、程式、理論

### 線索一：定理內容
> **Thue–Siegel–Roth 定理**（Roth, 1955）：設 $\alpha$ 是無理代數數，$\epsilon > 0$ 任意。則不等式
> $$\left|\alpha - \frac{p}{q}\right| < \frac{1}{q^{2+\epsilon}}, \qquad (p, q) = 1,\ q \geq 1$$
> 只有**有限多**個有理解 $\frac{p}{q}$。

等價說法：對代數數 $\alpha$，存在常數 $c(\alpha, \epsilon) > 0$，使
$$\left|\alpha - \frac{p}{q}\right| > \frac{c(\alpha,\epsilon)}{q^{2+\epsilon}} \quad \text{對所有 } \frac{p}{q} \in \mathbb{Q}.$$

**關鍵對比**：對**超越數**（如 Liouville 數 $\sum 10^{-n!}$）此結論不真；「指数 $2+\epsilon$ 的不可突破性」正是代數數的指紋。

### 線索二：超越數論的判別工具
Roth 定理反過來成為**證明超越性的利器**：
- 若某實數 $\alpha$ 能被 $q^{-2-\epsilon}$ 級的有理數無窮次逼近（對某 $\epsilon>0$），則 $\alpha$ **必是超越數**。
- 例：設 $\alpha = \sum_{k\geq 1} 10^{-k!}$，取部分和 $\frac{p_n}{q_n}$，$q_n = 10^{n!}$，則
  $$0 < \alpha - \frac{p_n}{q_n} < 2 \cdot 10^{-(n+1)!} = \frac{2}{q_n^{\,n+1}} \leq \frac{1}{q_n^{\,2+\epsilon}}\ (\text{當 } n \text{ 大})$$
  故 $\alpha$ 超越（這其實連 Liouville 就夠了，但 Roth 能處理更精細的逼近級）。

### 線索三：證明的思想（ auxiliary polynomial / 輔助多項式）
Roth 沿 Thue–Siegel 路線但引進革命性的工具（後被 Lang、Bombieri 發展成 Schmidt 子空間定理等）：
1. 造**輔助多項式** $P(x, y) \in \mathbb{Z}[x,y]$，在 $(\alpha, \alpha)$ 處有多重高階零點（指數高度的零點）。
2. 反設有無窮多解 $\frac{p_i}{q_i}$ 滿足 $q^{-2-\epsilon}$ 逼近，代入 $P$ 得整數值極小卻不為零的矛盾候選。
3. 用 **Roth 引理**（Wronskian 式的行列式論證）證明：$P$ 在 $(\frac{p_i}{q_i}, \frac{p_i}{q_i})$ 處不可能「各階導數都太小」——歸結為丟番圖逼近與多項式虧格的角力。
4. 技術核心是指數參數的精細簿記：恰好允許 $\epsilon$ 出現，且證明對 $\epsilon$「無法去掉」（後來 Schmidt 證明某種意義上 $2+\epsilon$ 不能換成 $2$）。

### 線索四：Python 實作連分數逼近 $\sqrt{2}$ 並驗證 Roth 界
$\sqrt{2} = [1; 2, 2, 2, \dots]$，連分數收斂子 $\frac{p_k}{q_k}$ 滿足 $\left|\sqrt{2} - \frac{p_k}{q_k}\right| \approx \frac{1}{2\sqrt{2}\, q_k^2}$——恰好貼著指數 $2$，永遠進不去 $2+\epsilon$。

```python
from fractions import Fraction
import math

def convergents_sqrt2(n):
    """sqrt2 = [1;2,2,2,...] 的前 n 個收斂子（精確分數）"""
    a = [1] + [2] * (n - 1)
    p_nm2, p_nm1 = 0, 1   # p_{-1}=1? 標準遞迴: p_{-2}=0, p_{-1}=1
    q_nm2, q_nm1 = 1, 0
    out = []
    for k in range(n):
        p = a[k] * p_nm1 + p_nm2
        q = a[k] * q_nm1 + q_nm2
        out.append(Fraction(p, q))
        p_nm2, p_nm1 = p_nm1, p
        q_nm2, q_nm1 = q_nm1, q
    return out

alpha = math.sqrt(2)
eps = 0.01
print(f"{'p/q':<22}{'q':>10}{'|alpha-p/q|':>16}{'1/q^(2+eps)':>14}{'roth_ok':>10}")
solutions = 0
for r in convergents_sqrt2(15):
    err = abs(alpha - float(r))
    bound = 1.0 / r.denominator ** (2 + eps)
    ok = err < bound                      # 是否落入 Roth 區間
    solutions += ok
    print(f"{str(r):<22}{r.denominator:>10}{err:>16.3e}{bound:>14.3e}{str(ok):>10}")
print("落入 2+eps 區間的收斂子個數:", solutions, "（Roth: 只能有限多）")
```

執行可見：誤差 $\approx c/q^2$，而界 $1/q^{2.01}$ 下降更快，僅極少數（小 $q$）收斂子落入區間——與「有限多解」一致。

### 線索五：與丟番圖方程的關聯
Thue 原本的目的：定理蘊含**不可約二元齊次方程** $F(x, y) = m$（$F$ 為 $\geq 3$ 次整係數）只有有限多個整數解。Roth 定理強化了這一點，是丟番圖方程有限性的基石（後續 Faltings 定理 1983 處理曲線上的有理點）。

## 結案 -- 後果與影響
- **1958 菲爾茲獎**：Roth 因本定理於愛丁堡國際數學家大會獲菲爾茲獎。
- **指數 $2$ 的最終定位**：逼近論中「$2+\epsilon$ 可達、$2$ 不可達」的二分法成立；Bombieri 與 Schmidt（1967–70）推廣到聯立逼近與子空間定理的前身。
- **超越數判別標準化**：Roth 條件成為教科書級的超越性判準（如對 $\sum 2^{-2^n}$ 型數）。
- **深遠影響**：定理被 Lang、Vojta 納入大綱預言（Vojta 猜想中 Diophantine 逼近與 Nevanlinna 理論的統一）；Schmidt 的 Subspace Theorem（1980）是其高維推廣，至今仍是丟番圖逼近最強工具之一。
