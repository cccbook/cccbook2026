# 1986-量子群（Quantum Group）

## 案件摘要
1986 年，Drinfeld 與 Jimbo 各自獨立提出「量子群」：Hopf 代數的非平凡形變。
它解開了 Yang–Baxter 方程與紐結不變量之間的謎題，讓統計力學、李代數與拓撲學合流。

## 前因 -- 為什麼會有這個案子
- **Yang–Baxter 方程**：統計力學中的可積模型（如六頂點模型、Baxter 1972）依賴矩陣 $R$ 滿足
  $$R_{12}R_{13}R_{23} = R_{23}R_{13}R_{12}$$
  這是「三體散射可交換次序」的代數化身，但長期缺乏系統性的解來源。
- **紐結多項式**：Jones 1984 年發現多項式紐結不變量 $V_K(t)$，其 skein 關係看起來像某種「變形的李代數表示」。拓撲學家不知道這個代數從何而來。
- **Hopf 代數**：1960 年代 Milnor–Moore 等人已建立 Hopf 代數理論（見 [1960s-Hopf代數](1960s-Hopf代數.md)），
  但當時認為泛包絡代數 $U(\mathfrak{g})$ 的形變是平凡的。
- 線索匯合處：$R$ 矩陣正是某個 Hopf 代數的「萬有 R 元素」，而 Jones 多項式來自 $U_q(\mathfrak{sl}_2)$。

## 線索與推理 -- 數學式、程式、理論

### 定義（Hopf 代數）
Hopf 代數是具有乘法 $m$、餘乘法 $\Delta$、 counit $\varepsilon$、antipode $S$ 的代數：
$$\Delta(ab) = \Delta(a)\Delta(b), \qquad m(S \otimes \mathrm{id})\Delta = \varepsilon \cdot \mathrm{id}$$

### q-形變
對李代數 $\mathfrak{sl}_2$ 的對易關係 $[x,y] = xy - yx = 1$，定義 q-對易子：
$$[x,y]_q = xy - q\,yx$$
當 $q \to 1$ 時退化回經典情況。由此得到 **Drinfeld–Jimbo 量子群** $U_q(\mathfrak{sl}_2)$：
生成元 $E, F, K, K^{-1}$ 滿足
$$KEK^{-1} = q^2 E, \quad KFK^{-1} = q^{-2} F, \quad [E,F] = \frac{K - K^{-1}}{q - q^{-1}}$$
並帶有餘乘法 $\Delta(E) = E \otimes 1 + K \otimes E$，使其成為 Hopf 代數。

### q-數
q-類比的自然數：
$$[n]_q = \frac{q^n - q^{-n}}{q - q^{-1}} = q^{-(n-1)} + q^{-(n-3)} + \cdots + q^{n-1}$$
滿足 $[m]_q [n]_q$ 的變形二項式定理，$q \to 1$ 時 $[n]_q \to n$。

### 萬有 R 矩陣與紐結
$U_q(\mathfrak{sl}_2)$ 有萬有 R 元素 $\mathcal{R} \in U_q \otimes U_q$ 滿足 Yang–Baxter 方程。
從 $U_q(\mathfrak{sl}_2)$ 的二維表示與 $\mathcal{R}$ 出發，經 Turaev–Reshetikhin 構造可得到
**Jones 多項式**（在 $t = q^2$ 處）：
$$V_{\text{unknot}}(t) = 1, \qquad V_{\text{trefoil}}(t) = t + t^3 - t^4 \ (\text{右三葉結})$$

### Python 實作：q-數與 Jones 多項式

```python
from fractions import Fraction

def q_num(n, q):
    """q-數 [n]_q = (q^n - q^{-n}) / (q - q^{-1})"""
    q = Fraction(q)
    return (q**n - q**(-n)) / (q - q**(-1))

# 驗證 q -> 1 時退化為 n
for n in range(1, 6):
    print(f"[{n}]_q (q=2) = {q_num(n, 2)},  極限 = {n}")

# Jones 多項式：用字典 {次冪: 係數} 表示
def poly_add(p, r):
    out = dict(p)
    for k, v in r.items():
        out[k] = out.get(k, 0) + v
    return {k: v for k, v in out.items() if v != 0}

def poly_mul(p, r):
    out = {}
    for i, a in p.items():
        for j, b in r.items():
            out[i + j] = out.get(i + j, 0) + a * b
    return {k: v for k, v in out.items() if v != 0}

def skein(crossing):
    """Jones skein 關係: t^{-1} V(L+) - t V(L-) = (t^{1/2} - t^{-1/2}) V(L0)"""
    # 簡化版：對 trefoil 逐步展開（此處直接給出已知結果驗證結構）
    return {1: 1, 3: 1, 4: -1}   # 右手三葉結 V(t) = t + t^3 - t^4

trefoil = skein("R")
print("右三葉結 Jones 多項式:", trefoil)
# 在 t = 1 處求值：1 + 1 - 1 = 1（不變量正規化檢查）
print("V(1) =", sum(trefoil.values()))
```

### 推理鏈整理
統計力學 $R$ 矩陣 $\Rightarrow$ Yang–Baxter 方程 $\Rightarrow$ 需要 Hopf 代數的形變
$\Rightarrow U_q(\mathfrak{sl}_2)$ $\Rightarrow$ 萬有 $\mathcal{R}$ $\Rightarrow$ 紐結不變量（Jones 多項式）。
三個看似無關的領域被同一個代數結構貫穿——這就是量子群的破案關鍵。

## 結案 -- 後果與影響
- **Drinfeld 獲 1990 年菲爾茲獎**（Jimbo 與 Miwa 亦因相關工作獲多項殊榮）。
- 量子群成為表示論、可積系統、共形場論、鏡像對稱的標準工具。
- 紐結理論獲得代數化基礎，催生 Khovanov 同調等更強的不變量。
- 觸發「形變思想」的普及：數學結構可透過參數 $q$ 家族化地理解（亦與非交換幾何呼應，見 [1960s-Hopf代數](1960s-Hopf代數.md)）。
