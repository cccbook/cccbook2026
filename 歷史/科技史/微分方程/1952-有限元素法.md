# 1952 有限元素法

## 案發現場

1940 年代，戰爭與工程的雙重壓力下，工程師與數學家共同面對一個巨大的難題：**飛機機翼、水壩、橋樑的結構分析**。這些問題的數學本質是偏微分方程——彈性力學的 Navier 方程、位勢理論的 Laplace 方程——但這些方程只有少數對稱完美幾何（圓、矩形）才有解析解。真實的機翼有不規則的邊界、不均勻的材料、複雜的受力，解析方法完全無能為力。

當時工程師靠的是兩條粗糙的路線：

1. **有限差分法**：把區域切成規則網格。問題：不規則邊界（斜坡、曲線）必須用階梯近似，誤差大且處理繁瑣。
2. **Rayleigh–Ritz 法**（1908 年 Ritz 系統化）：把解近似為全域基函數的線性組合 $\sum c_i \phi_i$，用變分原理（最小位能）決定係數。問題：全域基函數（多項式、三角級數）在不規則區域上收斂極慢，且要選「好的」基函數全憑經驗。

而在數學界，Hilbert 第 19 問（見 [1900-Hilbert與微分方程問題.md](1900-Hilbert與微分方程問題.md)）催生的變分直接法與 Sobolev 空間理論正在成熟，但尚未與工程實務連結。偵探 Richard Courant（1888–1972）——Göttingen 學派的傳人、紐約大學 Courant 研究所的創立者——在 1943 年寫下了一篇將兩個世界連結起來的論文。

此謎題之所以重要：戰後的核反應器、噴射機、太空船的設計，全部依賴 PDE 的數值解。誰能找到一種既靈活（處理任意幾何）又嚴格（有數學收斂保證）的方法，誰就掌握了工程計算的鑰匙。

## 偵查過程

### 關鍵靈感一：變分形式取代微分形式

Courant 的第一步推理：**不要直接解微分方程，改解它的變分等價形式**。以 Poisson 方程為例：

$$
-\Delta u = f \quad \text{在 } \Omega \text{ 內}, \qquad u = 0 \quad \text{在 } \partial\Omega \text{ 上}
$$

這個方程等價於最小化 Dirichlet 能量（Hilbert 1900 年直接法的核心）：

$$
J[u] = \int_\Omega \left(\frac{1}{2}|\nabla u|^2 - f\,u\right) dx
$$

**證明等價性（偵查的關鍵一步）**：設 $u$ 是極小化解，考慮擾動 $u + \varepsilon v$（$v$ 在邊界上為零），令

$$
\frac{d}{d\varepsilon} J[u + \varepsilon v]\Big|_{\varepsilon=0} = \int_\Omega \left(\nabla u \cdot \nabla v - f v\right) dx = 0
$$

對第一項做分部積分（Green 恆等式）：

$$
\int_\Omega \nabla u \cdot \nabla v\, dx = -\int_\Omega (\Delta u)\, v\, dx + \int_{\partial\Omega} \frac{\partial u}{\partial n} v\, ds
$$

邊界項因 $v|_{\partial\Omega} = 0$ 而消失，故得

$$
\int_\Omega (-\Delta u - f)\, v\, dx = 0 \quad \forall v
$$

由 $v$ 的任意性，得 $-\Delta u = f$。這條路線的深意：**變分形式（弱形式）比微分形式（強形式）要求的正則性更低**——強形式要求 $u$ 二次可微，弱形式只要求 $u \in H^1(\Omega)$（一階弱可微）。這正是 Sobolev 空間理論的用武之地，也解釋了為什麼弱形式能處理材料不連續、邊界有折角的真實工程問題。

### 關鍵靈感二：分片多項式取代全域基函數

第二步是 Courant 1943 年論文的核心靈感：**把區域切成小三角形，在每個小三角形上用最簡單的多項式**。以一維為例，把 $[a, b]$ 切成節點 $a = x_0 < x_1 < \dots < x_n = b$，基函數取「帽形函數」：

$$
\phi_i(x) = \begin{cases} \dfrac{x - x_{i-1}}{x_i - x_{i-1}} & x_{i-1} \le x \le x_i \\[2mm] \dfrac{x_{i+1} - x}{x_{i+1} - x_i} & x_i \le x \le x_{i+1} \\[2mm] 0 & \text{其他} \end{cases}
$$

這些函數的性質完美：$\phi_i(x_j) = \delta_{ij}$（局部支撐），且任意線性組合 $\sum u_j \phi_j$ 是分片線性函數，係數 $u_j$ 恰好就是節點值。近似解為

$$
u_h(x) = \sum_{j=1}^{n-1} u_j\, \phi_j(x)
$$

代入變分形式，令殘差對每個基函數正交（Galerkin 條件）：

$$
\int_a^b \left(u_h' \phi_i' - f \phi_i\right) dx = 0, \qquad i = 1, \dots, n-1
$$

這給出一個線性系統 $\mathbf{K}\,\mathbf{u} = \mathbf{f}$，其中剛度矩陣 $\mathbf{K}_{ij} = \int_a^b \phi_i' \phi_j'\, dx$。由於帽形函數只有局部支撐（$\phi_i$ 只與 $\phi_{i\pm1}$ 重疊），$\mathbf{K}$ 是**三對角矩陣**——可以用 Thomas 演算法以 $O(n)$ 快速求解。

**逐步計算一維例子**：考慮 $-u'' = 1$（均勻負載的弦），等間距 $h$。對內部節點 $i$：

$$
\int_{x_{i-1}}^{x_{i+1}} \phi_i' \phi_i'\, dx = \frac{2}{h}, \qquad \int_{x_{i-1}}^{x_{i+1}} \phi_{i-1}' \phi_i'\, dx = \int \phi_i' \phi_{i+1}'\, dx = -\frac{1}{h}
$$

$$
\int \phi_i\, dx = h
$$

故線性系統為

$$
\frac{1}{h}\left(-u_{i-1} + 2u_i - u_{i+1}\right) = h \quad\Longrightarrow\quad -u_{i-1} + 2u_i - u_{i+1} = h^2
$$

配合邊界 $u_0 = u_n = 0$，解得 $u_i = \dfrac{h^2}{2}\, i\,(n - i)$——與解析解 $u(x) = \frac{x(b-x)}{2}$ 在節點上的值**完全一致**（此例中分片線性 FEM 在節點上精確，是超收斂現象的簡單示例）。

### 關鍵靈感三：從數學論文到工程革命

Courant 1943 年的論文是在戰時條件下發表在一本不太起眼的刊物上，當時並未引起轟動。真正的爆發在 1950 年代：波音公司的工程師 Turner、Clough、Martin 與 Topp 在 1956 年發表了三角彈性元素的系統方法，Clough 在 1960 年首次使用「finite element」這個名詞。1960 年代，Zienkiewicz 寫出第一本教科書，Argyris、Babuska、Brezzi 等人建立了完整的收斂理論（Lax–Milgram 定理、Babuska–Brezzi inf-sup 條件），有限元素法正式成為一門既有工程實用性又有數學嚴格性的學科。

## 結案報告

Courant 的偵破路線：

1. **變分形式**（Hilbert 直接法 + Sobolev 空間）取代微分形式 → 降低正則性要求；
2. **分片多項式**（三角形元素、帽形函數）取代全域基函數 → 任意幾何 + 局部支撐 + 稀疏矩陣；
3. **Galerkin 正交條件** → 化為線性代數問題；
4. **工程實務**（波音 1956、Clough 1960）→ 命名與推廣。

其遺產：

- **工程計算的革命**：今天幾乎所有結構分析、熱傳、流固耦合、電磁模擬軟體（ANSYS、ABAQUS、COMSOL）都以 FEM 為核心。汽車碰撞測試、飛機疲勞分析、晶片散熱設計，背後都是數百萬個三角形元素。
- **數學**：Sobolev 空間、弱解、Lax–Milgram 定理、Céa 引理、自適應網格加密（a posteriori error estimation）——計算數學成為獨立學科。
- **與 Hilbert 問題的呼應**：第 19 問的變分直接法是 FEM 的數學根，第 6 問的公理化精神體現在 FEM 的收斂理論中。
- **數值 PDE 的全面勝利**：FEM 與譜方法、有限體積法並列，把 PDE 的求解從少數數學家的手工絕技，變成每個工程師電腦上的日常——這條大眾化之路最終通向 [1975-數值解與SciPy.md](1975-數值解與SciPy.md) 的開源軟體時代。
- **與定性理論的對照**：FEM 處理的是線性橢圓問題的「靜態」解；而非線性動態系統的「混沌」解（[1963-Lorenz混沌與蝴蝶效應.md](1963-Lorenz混沌與蝴蝶效應.md)）則展示了計算時代的另一面——電腦不只是算得快，還能發現人類看不到的現象。

## 證據與工具

以下程式實作最簡單的一維線性 FEM，求解 $-u'' = f$，並與解析解比較收斂率：

```python
import numpy as np
import matplotlib.pyplot as plt

# 一維線性 FEM 求解 -u'' = f, u(0)=u(1)=0
# 步驟：
#   1. 把 [0,1] 切成 n 個元素，節點 x_i = i/n
#   2. 基函數 = 帽形函數（分片線性，局部支撐）
#   3. 組裝剛度矩陣 K 與載荷向量 f
#   4. 解 K u = f

def fem_1d(n, f):
    h = 1.0 / n
    x = np.linspace(0, 1, n+1)
    # 剛度矩陣（三對角）：K = (1/h) * tridiag(-1, 2, -1)
    K = (1.0/h) * (2*np.eye(n-1) - np.eye(n-1, k=1) - np.eye(n-1, k=-1))
    # 載荷向量：f_i = ∫ phi_i * f dx ≈ h * f(x_i)（梯形法的中點近似）
    F = np.array([f(x[i]) * h for i in range(1, n)])
    # 解三對角系統（scipy 的稀疏求解器更快，這裡用稠密以示簡潔）
    u = np.zeros(n+1)
    u[1:n] = np.linalg.solve(K, F)
    return x, u

# 測試問題：-u'' = 2, 解析解 u(x) = x*(1-x)
f = lambda x: 2.0
u_exact = lambda x: x * (1 - x)

# 收斂性實驗：網格加密時誤差應按 O(h^2) 下降（L2 範數）
print("網格加密收斂實驗（理論誤差率 O(h^2)）:")
prev_err = None
for n in [4, 8, 16, 32, 64]:
    x, u = fem_1d(n, f)
    err = np.sqrt(np.trapezoid((u - u_exact(x))**2, x))  # L2 誤差
    rate = np.log2(prev_err/err) if prev_err else None
    print(f"  n={n:3d}: h={1/n:.4f}, L2誤差={err:.2e}",
          f"收斂率={rate:.2f}" if rate else "")
    prev_err = err

# 可視化：n=8 時的分片線性解 vs 解析解
x, u = fem_1d(8, f)
xx = np.linspace(0, 1, 200)
plt.figure(figsize=(9, 5))
plt.plot(xx, u_exact(xx), 'k-', lw=1.5, label='解析解 u = x(1-x)')
plt.plot(x, u, 'bo--', lw=1.2, ms=5, label='FEM 分片線性解 (n=8)')
plt.xlabel('x'); plt.ylabel('u')
plt.title('一維線性有限元素法：帽形函數 + 分片多項式')
plt.legend(); plt.grid(alpha=0.3)
plt.tight_layout()
plt.savefig("fem_1d.png", dpi=120)
plt.show()

# 延伸：此例中 FEM 在節點上完全精確（超收斂）
x16, u16 = fem_1d(16, f)
print("節點誤差（應為機器精度級）:", np.max(np.abs(u16 - u_exact(x16))))
```

程式展示了偵查的全部證據：帽形函數的分片線性結構、三對角剛度矩陣的組裝、$O(h^2)$ 的收斂率。這個只有三十行的程式，是波音公司 1956 年之後席捲工程界的技術之根。今天的 FEM 軟體把同樣的思想推廣到三維四面體、高階元素、非線性材料與百萬自由度的平行計算——但核心邏輯與 Courant 1943 年的論文完全一致：**變分形式 + 分片多項式 + 線性代數**。
