# 1982 · 丘成桐與卡拉比猜想：幾何分析學派的加冕

> 1982 費爾茲獎（華沙 ICM，因波蘭戒嚴延至 1983 頒發）：Shing-Tung Yau（丘成桐），表彰偏微分方程方法於幾何學之應用——首位華人得主

## 案情提要

1954 年，年輕的意大利幾何學家 Eugenio Calabi 提出一個看似單純的問題：**給定一個緊 Kähler 流形的第一陳類 c₁ < 0（或 0），其上是否存在一個指定的 Ricci 曲率形式？** 換成人話：能否在複幾何的世界裡，**按圖索驥地製造出曲率剛好符合規格的度量**？Calabi 自己給了必要條件並證明唯一性，但存在性 25 年無人能破。1976 年，27 歲的丘成桐用一組非線性 PDE 證明存在——**並在 1980 年代用它收穫了整個數學物理與代數幾何**。

## 前因

| 年份 | 事件 |
|---|---|
| 1954 | Calabi 提出猜想；當時連「如何下手」都不明確 |
| 1960s–70s | 幾何分析（Harmonic maps、極小曲面）在 Nirenberg、Aubin 等推動下成形 |
| 1976 | Yau 證明 Calabi 猜想（三個月內；此前他 1973 年曾**公開給出錯誤證明**，被 Calabi 當場指出——隨後苦讀三個月再戰） |
| 1978 | Yau 與孫理察（R. Schoen）解決正質量猜想（廣義相對論中的質量非負性） |

## 調查：把幾何問題變成 Monge–Ampère 方程

Calabi 猜想的翻譯：在緊 Kähler 流形 (M, ω) 上，是否存在 Kähler 度量使其 **Ricci 形式等於任一指定的代表**？以複座標寫出，這等價於求解一個**複 Monge–Ampère 方程**：

`det(ω + i∂∂̄φ) = e^{F(φ)} · det(ω)`（給定 F，求 φ）

- 具體證明以**連續性方法**（continuity method）完成：
  1. 對參數 t 定義方程族，t = 0 有平凡解。
  2. 證明 t ∈ [0, t₀] 的解集**既開且閉** → 對所有 t 有解。
  3. 「閉」的部分需要**先驗估計**（C²、C³ 估計）——這是真正的硬骨頭，丘成桐以逐項 PDE 估計攻克。

**先驗估計**是幾何分析的通用偵查術：不等式把「解是否存在」轉成「解是否被控制」。

## 理論裁決：一證多收

Calabi 猜想不是一個問題的答案，而是**一整批懸案的鑰匙**：

| 推論 | 內容 |
|---|---|
| **Calabi–Yau 流形** | Ricci 平坦的緊 Kähler 流形——1985 年 Candelas 等提出弦論六維緊化空間（[1990-Witten與拓撲量子場論](1990-Witten與拓撲量子場論.md) 的物理連結） |
| **Severi 猜想** | 複射影平面上不存在非常數負曲率 Kähler 度量——Calabi 猜想的直接推論 |
| **Miyaoka–Yau 不等式** | c₁² ≤ 3c₂（代數曲面不等式），代數幾何的分類工具 |
| **正質量猜想** | 廣義相對論的數學基礎（Schoen–Yau 1979–80，用極小曲面法） |
| **Donaldson 極小曲面技術**、**Perelman 熵技術** | 都屬「幾何分析」傳統的後代——[2006-Perelman與龐加萊猜想](2006-Perelman與龐加萊猜想.md) 的 Ricci 流正需要 Monge–Ampère 類估計 |

## 後果

- 「幾何分析」自此成為獨立學派：Harvard/UCSD/中研院的接力（Schoen、劉克峰、田剛……）。
- 著名公案：1980s 與劍橋 PDE 學派關於三維正質量猜想的優先權之爭（Hamilton vs Yau 派）；2000s 「丘-田之爭」成為中文數學界最著名的論戰——**偉大學派內部的張力**。
- 丘成桐 2003–04 年推動清華大學數學科學中心，提出「中國數學需有自己學派」——本案的東亞延伸。
