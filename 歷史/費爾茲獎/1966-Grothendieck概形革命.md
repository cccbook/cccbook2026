# 1966 · Grothendieck 概形革命：把幾何徹底代數化

> 1966 費爾茲獎（莫斯科 ICM）：Alexander Grothendieck——**本人缺席**，抗議蘇聯拘捕異議人士，把獎章託赴會者轉交給當時被監禁的越南數學家的家屬

## 案情提要

1950 年代末的代數幾何是「手工時代」：意大利學派的直觀、Weil 的抽象、Serre 的層論各據一方，許多經典結果（如 Riemann 假說的函數域版本）的推廣屢屢失敗。Grothendieck 在 1957–1970 年間（十餘年、上萬頁《EGA/SGA》）提出：**不是改良現有工具，而是把「空間」的定義整個換掉**。這是二十世紀數學最徹底的一次「換地基」。

## 前因

| 年份 | 事件 |
|---|---|
| 1928 | Grothendieck 生於柏林；父母為無政府主義者，母親俄籍猶太裔；父親死於奧斯維辛——他本人少年時在法國為無國籍難民 |
| 1940s | 難民營中自學；戰後在巴黎被 Cartan 發現「把一般拓撲的完備化問題全解了」 |
| 1946–57 | 泛函分析（核空間、張量積）成名後**突然轉行**代數幾何——「從最抽象走到更抽象」 |
| 1957 | 開始 IHÉS 時期；1958 與 Dieudonné 開寫《EGA》 |

## 調查：四大發明

### 1. 概形（scheme）

把空間定義為**環的對偶**：仿射概形 = Spec(R)（環的素譜），一般概形由其黏合而成。代數幾何從此**完全由交換代數生成**——任何交換代數的定理即刻是幾何定理。

### 2. 層論與 Grothendieck 拓撲

- **不換點，換「覆蓋」**：topology 重新定義為「容許覆蓋」的範疇論結構（Grothendieck topology）——étale topology、fppf topology 等應運而生。
- 由此得到 **étale 上同調**（1960 前後與 Artin、Verdier）：終於在特徵 p 世界造出與複數上同調性質相同的 **Weil 上同調**——攻擊 Weil 猜想的攻城錘。

### 3. 相對觀點（relative viewpoint）

「相對於一個基底 S 的族」：把「所有曲線的集合」本身當作空間（**模空間**；[2014-Mirzakhani與模空間動力學](2014-Mirzakhani與模空間動力學.md) 的直接源頭）。數學家開始研究「空間的空間」。

### 4. motive 計畫

提出一個萬用的「上同調母體」，使所有上同調理論成為其投影——至今未完成的「母案」。

## 理論裁決

- **Weil 猜想的完全證明**由學生 Deligne 於 1973 年完成（1978 費爾茲獎）——Riemann 假說的有限域版本落網。這是 Grothendieck 機器第一次「殺人成功」。
- 1970 年 Grothendieck 因 IHÉS 接受軍方資金而**辭職**，此後漸離數學主流，1980s 起隱居法比利牛斯山村，1991 年完全失聯，2014 年逝世——「數學的聖人與遁世者」。
- 「Grothendieck 素數」軼事（他自述數學時總以 0 代替具體數字），形象化其風格：**從不使用具體例子**——抽象不是逃避，而是「讓所有例子同時成立」的手段。

## 後果

| 層面 | 影響 |
|---|---|
| 學科 | 代數幾何成為現代數論（[1998-懷爾斯與費馬最後定理](1998-懷爾斯與費馬最後定理.md) 的全套語言）、表示論、物理（[1990-Witten與拓撲量子場論](1990-Witten與拓撲量子場論.md)）的通用語法 |
| 制度 | 「現代數學必讀 EGA/SGA」的恐懼與迷思；2020 年代 Stacks Project 將其數位化民主化 |
| 量級 | 以一人之筆改寫一個學科的地基——費爾茲獎史上「影響力/獲獎工作比」最高的案例 |
