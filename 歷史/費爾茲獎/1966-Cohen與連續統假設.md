# 1966 · Cohen 與連續統假設：證明「證不出來」

> 1966 費爾茲獎（莫斯科 ICM）：Paul Cohen，表彰連續統假設與選擇公理的獨立性——**唯一的邏輯學費爾茲獎**

## 案情提要

1878 年 Cantor 提出：實數的個數（連續統 c）與自然數的個數（ℵ₀）之間，有沒有中間大小的無窮？Cantor 猜測沒有——**連續統假設（CH）**：`2^ℵ₀ = ℵ₁`。1940 年 Gödel 已證明：若 ZF 集合論一致，則加入 CH 也不矛盾（CH 不可被否證）。剩下另一半：**CH 可以被證明嗎？** Cohen 1963 年證明：也不能。懸案就此「永久懸案化」——但懸案本身就是裁決。

## 前因

| 年份 | 事件 |
|---|---|
| 1878 | Cantor 連續統假說提出（他本人至死苦無證明，被視為其人生之痛） |
| 1900 | Hilbert 首屆 23 問題的**第 1 題** |
| 1908 | Zermelo 公理化集合論 |
| 1938–40 | Gödel 可構造宇宙 L：`V = L ⇒ CH 成立`——相對一致性完成 |
| 1963 | Cohen 史丹福 |

## 調查：力迫法（Forcing）

Cohen 的發明是**力迫法**：不證明某命題，而是**手工打造一個讓它失敗的宇宙**。

1. 從一個 ZFC 的模型 M 出發。
2. 加入一個「一般元素」G（general filter，泛型濾子），把 M 擴張成更大的模型 M[G]。
3. 用「**力迫關係** p ⊩ φ」在 M 內部**遞歸地**控制 M[G] 中哪些命題為真——不需要真造 G，只需在 M 內證明「G 可使 ¬CH 成立」。
4. 結果：可以加入 ℵ₂ 個實數而保持基數不塌，使 `2^ℵ₀ > ℵ₁`——**¬CH 與 ZFC 一致**。

與 Gödel 的 L 結果合併：CH 對 ZFC **既不可證、也不可否證**——**獨立**。Cantor 問題就此成為「數學公理選擇」問題：CH 真不真，取決於你住哪個宇宙。

## 理論裁決

- 力迫法自此成為集合論的**通用工具箱**（後由 Solovay、Shelah 系統化）：連續統可以是 ℵ₁、ℵ₂、ℵ₃……甚至 `2^ℵ₀ = ℵ_{17}`； Martin's axiom、Solovay 模型（「所有集合勒貝格可測」）皆為力迫的產物。
- 哲學餘波：**Platonism vs Formalism** 的百年辯論獲得實質武器——若 CH 無真值，數學真理的「唯一宇宙」觀受到衝擊。當代回應（Woodin 的 Ultimate-L 計畫、多宇宙論 multiverse view）仍是進行中的「二審」。
- Cohen 是少數「以邏輯學家身分得費爾茲獎」者；此前他已以分析學（Littlewood 問題）成名——跨界偵探。

## 後果

| 層面 | 影響 |
|---|---|
| 集合論 | 大基數公理、inner model 理論、Shelah 的 pcf 理論——力迫的生態系 |
| 電腦科學 | 可計算性與「相對一致性」思想影響複雜性理論的 oracle 相對化方法 |
| 哲學 | 「CH 是否應有真值」至今是數學哲學的核心案例 |
| 判例意義 | 費爾茲獎可以頒給「證明問題不可解」的人——**懸案本身也是科學貢獻** |
