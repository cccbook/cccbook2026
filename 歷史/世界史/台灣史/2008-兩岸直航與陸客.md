# 2008 兩岸直航：陸客與ECFA前夜

## 案發現場

2008 年，兩岸直航（三通：7 月週末包機、12 月平日包機+直航+通郵）+開放陸客（7 月首發團 700 人）+金融海嘯（9 月）——此前：2000 輪替（參見 [2000-政黨輪替.md](2000-政黨輪替.md)）後八年凍結（戒急用忍→積極開放未果、一邊一國、連戰破冰 2005）；此後：2010 ECFA、2014 太陽花（參見 [2014-太陽花學運.md](2014-太陽花學運.md)）。**包機載的是觀光客，還是生產鏈？當夜市出現簡體字菜單，兩岸是更近還是更怕？**

> **直航縮短的是航程，還是薪資？當團客擠爆日月潭，本土派看到的是錢還是統戰？**

## 偵查過程

**線索一：為何此時通（馬英九的窗口）。** 2008 馬英九當選（58%、「九二共識、一中各表」+「不統不獨不武」）+北京（胡溫、奧運年、胡六點軟化）+海基海協復談（江丙坤—陳雲林 6 月簽包機陸客）——**三窗齊開**（台北換黨、北京要奧運面子、華盛頓樂見緩和）。偵查結論：這是**選舉開出的支票**：$直航 = 馬票_{58\%} + 京奧_{面子} + 美默許$。此前 2000–08（民進黨執政：戒急用忍名亡實存、包機需繞港澳：李登輝「戒急用忍」，參見 1996 戒急用忍案）——**繞了八年的路（經港澳），2008 拉直**（省 2 小時、省千億物流，一說）。此案接 2001 入WTO（兩岸先後入世：中 2001、台 2002）——**入世七年才直航**：世貿的貨先通，人的腿後通（貨比人自由）。

**線索二：陸客的經濟學（夜市的兩面賬）。** 陸客（2008 年 30 萬→2015 年 418 萬高峰，一說）：團費低價（零團費、購物回扣：珠寶茶葉鳳梨酥）、夜市攤商笑（士林逢甲）、景點擠（日月潭阿里山）、飯店炒（兩岸直航概念股）。偵查結論：這是**觀光的分配政治**：$收益 = 團社_{中資低價} + 購物店_{回扣} + 夜市_{散客}$——**大錢（購物回扣）回流中資一條龍，小錢（滷肉飯）留夜市**。此案接 1987 台積電（參見 [1987-台積電成立.md](1987-台積電成立.md)）+1980 竹科（參見 [1980-新竹科學園區.md](1980-新竹科學園區.md)）對照：**科技島賺的是美日單（高毛利），觀光島賺的是陸客單（低毛利+高波動）**——兩張單，一張穩、一張險。2016 陸客急凍（民進黨再輪替）證明：**靠團客的夜市，遙控器在北京**。

**線索三：生產鏈的直航（ECFA的跑道）。** 直航真正主角不是客機，是貨：兩岸供應鏈（筆電：研發台灣、組裝蘇州崑山）此前經港轉（成本+時間），直航後（貨運包機、海運直航：高雄—廈門）成本降——2010 ECFA（早收清單：石化、工具機、汽車零組件）水到渠成。偵查結論：這是**生產網絡的收尾**（東亞史 2001 入世案的台灣章）：$ECFA = 直航_{物流} + 投資保障_{制度} + 早收_{讓利}$。瞿宛文「三角貿易」：台灣接單—大陸生產—美國市場——**直航把三角形的台灣—大陸邊拉直**（邊越短，綁越緊）。2014 太陽花擋的服貿，正是這條直線的延長線——**2008 拉直的線，2014 有人想剪**（怕綁太緊：黑箱+分配+主權三憂）。

**線索四：海嘯的緩衝（四萬億的台灣份）。** 2008.9 金融海嘯：台灣出口崩（Q4 −20%，一說）、馬政府（三挺：挺銀行、挺企業、挺就業+消費券 3600）+大陸四萬億（基建拉動：台灣工具機、面板搭順風）。偵查結論：這是**危機的兩岸連動**：$台灣復甦 = 美蘋果單（2010 iPhone） + 陸基建單（工具機） + 陸客單$——三單齊下，2009–10 V 型反彈。與 1973 石油危機（參見 [1973-十大建設與石油危機.md](1973-十大建設與石油危機.md)：逆週期十大建設）對照：**1973 靠政府投資撐，2008 靠對岸投資撐**——撐的手從自家變成對家。**直航通了，海嘯的浪也通了**（好處通、壞處也通：2015 紅色供應鏈殺價，台灣 panels 嘗到）。

## 結案報告

1. **三窗論**：馬票+京奧+美許——繞八年的路一次拉直。
2. **兩面賬論**：大錢回流、小錢留攤——遙控器在北京。
3. **拉直論**：直航是 ECFA 跑道——三角邊越短綁越緊，太陽花來剪。
4. **連動論**：1973 靠自家手、2008 靠對家手——浪也通了。

**直航公式（示意）：**

```
整合度 ＝ （物流省 ＋ 觀光錢 ＋ 供應鏈綁）÷ 主權憂。
2008：分子大÷分母小（馬58%）→ 通。2014：分母（黑箱憂）↑ → 擋（太陽花）。
$Integration = \frac{Logistics + Tourists + Chain}{Sovereignty\_anxiety}$，分母是選票函數。
```

**結論：** 直航案是「拉直的兩面」的完整樣本：三窗齊開、夜市兩賬、三角拉直、海嘯連動——**拉直的航線，繫緊的結**。2000 輪替的凍（參見前案）2008 解，2014 太陽花的擋（參見後案）正是解的反作用——**解鈴還須繫鈴人，繫鈴人坐著包機來**。包機的轟鳴裡，一半是商機，一半是心跳（怕）——台灣的耳朵，兩種聲音都聽見了。
