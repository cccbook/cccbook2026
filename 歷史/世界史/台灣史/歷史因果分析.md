# 台灣史歷史因果分析

## 案件摘要

台灣史是一樁「**地理位置决定论**」的長篇案件：一座位於東亞航道交會點的島嶼，每一波世界體系的潮水——大航海、貿易帝國、移民墾殖、帝國殖民、冷戰、全球化晶片供應鏈——都先沖刷它的位置，再塑造它的制度與人群。島上沒有單一主謀，凶手是「位置 × 移民 × 貿易 × 強權」的四重奏。因果鏈公式：

$$\text{海道位置} \Rightarrow \text{外部強權進出} \Rightarrow \text{移民與貿易社會形成} \Rightarrow \text{在地主體性萌芽} \Rightarrow \text{強權再洗牌} \Rightarrow \text{在地承擔後果並升級}$$

## 主要驅動力

| 驅動力 | 機制 | 證據案件 |
|---|---|---|
| 地理位置航道化 | 台灣海峽 = 東亞貿易咽喉 | `1544-福爾摩沙與大航海時代.md`、`1624-荷蘭東印度公司入台.md` |
| 海洋貿易誘因 | 鹿皮、蔗糖、樟腦、晶片輪流上場 | `1662-鄭氏屯墾與貿易王國.md`、`1868-樟腦戰爭.md`、`2021-晶片荒與台積電.md` |
| 移民社會張力 | 漢人墾殖 ↔ 原住民 ↔ 官府三角 | `1684-渡台禁令與移墾社會.md`、`1796-分類械鬥與土牛溝.md`、`1930-霧社事件.md` |
| 帝國治理實驗 | 荷、鄭、清、日、國府五套體制接力 | `1898-兒玉後藤體制與保甲制度.md`、`1953-耕者有其田與土地改革.md` |
| 冷戰與地緣保險 | 美國安全傘 ↔ 經濟起飛 ↔ 民主化 | `1951-美援與麵粉.md`、`1958-八二三炮戰與共同防禦.md`、`1979-中美斷交與美麗島事件.md` |

## 因果鏈與回饋環

### 回饋環一：貿易財富 → 治理投資 → 更多財富（正環）

荷蘭人以 `1624-荷蘭東印度公司入台.md` 把台灣編入全球貿易網，`1636-新港文書.md` 是治理工具化的證據；`1662-鄭氏屯墾與貿易王國.md` 接手後，同一套海洋貿易邏輯換了旗幟繼續跑。清帝國雖設 `1684-渡台禁令與移墾社會.md` 想踩煞車，移民經濟的自發力量卻不斷突破禁令，直到 `1858-開港通商.md` 把島嶼重新推回世界市場——**禁令擋不住航道位置**。

### 回饋環二：移民壓力 → 械鬥 → 國家介入 → 制度化（負回饋）

$$\text{移民湧入} \Rightarrow \text{水源土地爭奪} \Rightarrow \text{分類械鬥} \Rightarrow \text{官府建土牛溝劃界} \Rightarrow \text{張力制度化但未消解}$$

`1796-分類械鬥與土牛溝.md` 之前，`1721-朱一貴事件.md` 與 `1786-林爽文事件.md` 已兩度證明民變結構；日本殖民者用 `1898-兒玉後藤體制與保甲制度.md` 的保甲＋警察制度把同樣的社會一次性收編——**同樣的社會張力，不同政權給出不同制度解。**

### 回饋環三：殖民現代化 → 戰後接收斷裂 → 二二八（悲劇環）

```mermaid
flowchart LR
  A[日治制度化<br/>糖業/教育/戶口] --> B[1945接收<br/>語言/行政斷裂]
  B --> C[治理摩擦累積]
  C --> D[1947二二八]
  D --> E[戒嚴與白色恐怖]
  E --> F[本土精英斷層]
  F --> G[日後政治動能]
```

`1919-糖業帝國與總督府.md` 與 `1935-始政四十周年博覽會.md` 展示殖民現代化的表裡；`1945-終戰與接收.md` 的治理落差點燃 `1947-二二八事件.md`，再鎖進 `1949-戒嚴與白色恐怖.md`。**治理斷裂的代價以數十年計。**

### 回饋環四：美援 → 土改 → 加工出口 → 民主化（發展環）

`1949-三七五減租與耕地官僚.md` 與 `1953-耕者有其田與土地改革.md` 以美援為後盾拆掉地主經濟 → `1966-加工出口區與經濟起飛.md` 釋放勞動力 → `1968-九年國民義務教育.md` 養出工程師世代 → `1980-新竹科學園區.md` 與 `1987-台積電成立.md` 接棒 → 經濟精英壯大 → `1986-民進黨成立.md`、`1987-解嚴與開放探親.md`、`1990-野百合學運.md`、`1992-國會全面改選.md`、`1996-首次總統直選.md` 完成政治升級——**土地改革是本島二十世紀最強的單點因果源**。

## 關鍵轉折點

- **1661–1662 年**：`1661-鄭成功攻台.md` 與 `1662-熱蘭遮圍城與荷蘭退出.md`——一場明朝遺將的求生遠征，讓台灣從貿易站變成漢人政權基地，此後四百年的人口結構由此定調。
- **1895 年**：`1895-馬關條約與乙未戰爭.md`——甲午戰敗的副產品，島嶼被當作談判籌碼割讓；結構上，台灣的命運屢次由外部戰爭的結果決定（1945 年 `1944-美軍轟炸台灣與制空權.md` 之後的重返亦然）。
- **1950 年**：韓戰使美國第七艦隊巡防台海，`1958-八二三炮戰與共同防禦.md` 確認安全傘——沒有這道保險，就沒有後續一切發展。
- **1987 年**：`1987-解嚴與開放探親.md`——壓力累積多年後的體制讓步，與 `1979-中美斷交與美麗島事件.md` 的衝擊互為因果。
- **2020 年代**：`2020-疫情防疫與晶片地緣政治.md` 與 `2021-晶片荒與台積電.md`——矽盾從隱喻變成硬地緣，位置因素以晶片形態回歸。

## 反事實推演

- **若無鄭成功攻台**：荷蘭據台若延續，漢人墾殖仍會因貿易誘因南下，但速度與規模將大減，清代移墾社會的張力形態會完全不同。
- **若台灣未被割讓**：清廷繼續治理，`1885-台灣建省與自強運動.md` 的劉銘傳路線或許是另一種現代化——但乙未證明：台灣的前途長期由大陸政權的成敗外溢決定。
- **若無土地改革**：地主階級延續，工業化資本與人力都將受阻，`1987-台積電成立.md` 的工程師紅利未必存在。
- **若無 1979 斷交衝擊**：威權鬆綁可能更慢——危機是民主化的加速器。

## 偵探教訓

1. **先看地圖，再看檔案**——從 `1624-荷蘭東印度公司入台.md` 到 `2021-晶片荒與台積電.md`，四百年不變的常數是海峽的位置。
2. **誰統治不重要，誰來犁田才重要**——`1953-耕者有其田與土地改革.md` 對後世的影響超過任何一次政權更替。
3. **外部戰爭的結算單常寄到島上**——1895、1945、1971（`1971-退出聯合國.md`）、1979 皆是。
4. **社會張力不會消失，只會換制度包裝**——從土牛溝到保甲到選舉，每一代都用新容器裝舊張力。
