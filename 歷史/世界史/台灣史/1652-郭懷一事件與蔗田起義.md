# 1652 郭懷一事件：蔗田裡的第一次漢人起義

## 案發現場

1652 年 9 月，郭懷一（鄭芝龍舊部、 sugar 承包商）率漢人農民（傳 4000–5000 人，一說）起義：攻赤崁（普羅民遮城外）、圍熱蘭遮未果，荷蘭（揆一）聯合原住民（新港社）鎮壓：斬首千餘（一說三四千）、全台大搜捕。此前：荷蘭引入漢人種蔗（1640s 漢人逾 2 萬）、人頭稅+贌社壓榨；此後：荷蘭放寬漢人管制、鄭成功 9 年後攻台（參見 [1661-鄭成功攻台.md](1661-鄭成功攻台.md)）時漢人內應。**種蔗的人為何砍起甘蔗刀？荷蘭的帳本與漢人的鋤頭，哪個先動手？**

> **當稅單比甘蔗長，農民的鐮刀會先割蔗還是先割官？一場失敗的起義，為何是成功的預告？**

## 偵查過程

**線索一：人頭稅的絞索（荷蘭的財政機器）。** 荷蘭東印度公司（參見 [1624-荷蘭東印度公司入台.md](1624-荷蘭東印度公司入台.md)）治台邏輯：轉口+蔗糖（台灣糖輸日本波斯）——漢人是「進口勞力」（按人頭收稅：人頭稅、贌金、什一），原住民是「贌社對象」（鹿皮）。1650s 糖價跌+稅不降：農民（多漳泉佃戶，欠承包商郭懷一等預借）雙重盤剝（公司稅+包商利）。偵查結論：這是**殖民財政的轉嫁鏈**：$公司利潤 = 稅_{漢} + 贌_{番} - 管治費$，管治費省（兵僅數百），稅只能加——**阿姆斯特丹的股息，台灣農民的人頭稅裡出**。郭懷一本人即承包商（收蔗包商）：**剝削鏈的中間人反水**（收不上蔗→交不出包金→橫豎是死，不如反）——起義領袖不是最苦的，是**帳算得最清的**。

**線索二：漢番的裂縫（荷蘭的分而治之）。** 鎮壓主力是新港社原住民（荷蘭教化+新港文書，參見 [1636-新港文書.md](1636-新港文書.md)：傳教士聲望+火繩槍配給）——漢人起義，原住民助荷。偵查結論：這是**族群統治術**：荷蘭（數百人）以番制漢（教化番社為盟軍）——**人少者的槓桿**。與 1786 林爽文（參見 [1786-林爽文事件.md](1786-林爽文事件.md)：閩客+漢番互鬥）對照：**台灣民變的永恆劇本——統治者永遠找得到另一群人來鎮壓這群人**。郭懷一之敗，敗在**漢人沒聯合番**（攻赤崁時掠番社，番更助荷）——**起義的算術：漢 − 番 < 荷 + 番**。

**線索三：失敗的成功（鄭成功的接收）。** 起義雖敗，後果三重：荷蘭減稅（人頭稅緩、贌金降，1653–60 安撫）、漢人武裝經驗（鄉勇、結社）、鄭氏情報（鄭芝龍舊部網絡：郭懷一部眾餘黨通鄭）。1661 鄭成功攻台（參見 [1661-鄭成功攻台.md](1661-鄭成功攻台.md)）時漢人紛應（「簞食壺漿」一說誇張，但引路、運糧屬實）。偵查結論：這是**失敗的路測**：$1661 成功 = 1652 失敗 + 鄭氏水師（變量）$——1652 證明荷蘭（稜堡+盟番）野戰可破、圍城需水師（郭無船，鄭有船）。此案給 [1662-鄭氏屯墾與貿易王國.md](1662-鄭氏屯墾與貿易王國.md)遞因：**鄭氏屯墾的佃戶，正是郭懷一的工友**（同批蔗農，換個老闆）——人還是那些人，地還是那些地，老闆從公司變延平王。

**線索四：被遺忘的記憶（為何課本跳過）。** 郭懷一在荷蘭檔案（熱蘭遮城日誌、揆一報告）大書，在漢文志書（《台灣外記》寥寥）幾無——國民史（鄭成功民族英雄）不愛「漢人先被荷蘭殺、再迎鄭氏」的複雜。偵查結論：這是**記憶的政治**（參見 [1675-被遺誤的台灣與荷蘭檔案.md](1675-被遺誤的台灣與荷蘭檔案.md)：同一檔案庫）：**成功者（鄭）吸走記憶，失敗者（郭）還給檔案**。人類學詹姆斯·斯科特「弱者的武器」：郭懷一是蔗農弱者武器的極限（鐮刀轉刀）——**日常抵抗（逃稅、匿報）無效，才有起義**。台灣史第一課：**先有郭懷一的鐮刀，才有鄭成功的刀**——鐮刀先舉，刀後到。

## 結案報告

1. **轉嫁鏈論**：股息→人頭稅→包商→佃戶——中間人先算清先反。
2. **以番制漢論**：人少者槓桿——漢減番小於荷加番即敗。
3. **路測論**：1652 是 1661 的彩排——缺的只是水師變量。
4. **記憶政治論**：成功者吸記憶——檔案還給失敗者。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 起義工程 | 跨域效應 |
|------|----------|----------|
| 財政 | 人頭稅+贌社 | 轉嫁鏈爆 |
| 族群 | 新港社助荷 | 以番制漢樣本 |
| 軍事 | 圍城無水師 | 鄭氏補變量 |
| 糖業 | 蔗價跌稅不降 | 經濟導火 |
| 記憶 | 荷檔詳漢志略 | 成功者吸記憶 |

**兩次漢人起義（對照）：**

| 項 | 1652 郭懷一 | 1721 朱一貴 |
|----|-------------|-------------|
| 對手 | 荷蘭公司 | 清帝國 |
| 幫手 | 無（番助官） | 無（閩客互鬥） |
| 結果 | 斬千餘 | 稱帝旬日敗 |
| 遺產 | 鄭氏內應 | 渡台禁弛 |

**起義公式（示意）：**

```
起義爆發 ＝ 盤剝（稅+利）÷ 出路（逃/告）。出路→0（搜捕+欠債）→爆。
勝算 ＝ 漢團結 × 水師 ÷ （官軍 + 盟番）。1652：水師0 → 0；1661：水師1 → 勝。
$R = \frac{Tax+Debt}{Exit}$，$Exit \to 0 \Rightarrow R \to \infty$。
```

**結論：** 郭懷一案是「蔗田起義」的完整樣本：稅絞索、番裂縫、路測成功、記憶被吸——**甘蔗刀先舉，延平刀後到**。1624 公司的帳本（參見前案）寫得出股息，寫不出人頭；1661 鄭成功的船（參見後案）裝得下兵，裝不下 1652 的屍——**屍在田裡，肥了蔗**（來年糖更甜）。台灣漢人社會的第一課不在課本，在蔗田。
