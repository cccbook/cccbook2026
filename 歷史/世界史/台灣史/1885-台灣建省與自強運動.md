# 1885-台灣建省與自強運動：劉銘傳的標準化統治實驗

## 案件摘要

1885 年，清廷宣布台灣建省，劉銘傳任首任巡撫（1885–1891 在任）。他不只完成行政升格，更在六年間推動一整套「自強運動」工程：**鐵路（基隆—台北—新竹）、電報線（含海底電纜通福建）、新式郵政（郵政總局與郵票）、西式學堂、開山撫番、清賦丈田、招商興礦**。這樁案件的本質是：**把秦式的「標準化統治」搬到清代邊陲島嶼**——用現代基建與行政工具，把台灣從「邊疆」變成「可管理的省份」。它是清帝國最激進的一次地方現代化實驗，也是 1895 年之前台灣唯一的官方現代化窗口。

## 前因 -- 多因素的局勢

- **政治**：中法戰爭（[1884-中法戰爭.md](1884-中法戰爭.md)）暴露台灣海防空虛——「台灣為南洋門戶」成為朝野共識。
- **時代**：清帝國的自強運動（1861 起）——「師夷長技以制夷」的洋務風潮，台灣是最後一批實驗場之一。
- **經濟**：台灣開港（1860 淡水、基隆）後茶、糖、樟腦出口激增——財政基礎已備。
- **行政**：台灣原屬福建省，隔海治理的成本極高——行政半徑超出帝國的管理效率。
- **人物**：劉銘傳——淮軍實戰出身，重視技術與實效，作風強勢專斷。

## 線索與推理 -- 因素咬合

### 線索一：建省 = 行政半徑的修正

隔海治理的問題：福州的政令到台灣要渡海、傳遞慢、反應遲。建省的邏輯是「讓決策靠近現場」：

$$\text{治理效率} \propto \frac{\text{決策品質}}{\text{資訊傳遞距離} + \text{資源調度成本}}$$

建省縮短了決策鏈——這與秦代郡縣制「讓官員靠近現場」是同一原理：**行政區劃是治理半徑的工具**。

### 線索二：基建三件套 = 資訊、運輸、財政的整合

劉銘傳的工程本質是降低三種成本：

| 工程 | 降何種成本 | 時間點 |
|---|------|------|
| 鐵路（台北—基隆 1891 通車，後延至新竹） | 運輸與兵力調度成本 | 1887 動工 |
| 電報線與福州—川石山海底電纜 | 資訊傳遞成本 | 1887 完工 |
| 新式郵政（中國現代郵政的先驅之一） | 通訊與商業成本 | 1888 設立 |

**基建 = 治理與市場的共同基礎設施**——與羅馬的道路、秦的馳道同一工程邏輯：統治半徑與市場半徑同步擴大。

### 線索三：清賦丈田 = 財政基礎工程

劉銘傳實施「清賦」——全面丈量田地，把隱田納入稅基。這是所有現代國家的第一步：**丈量（測量學）→ 登記（檔案）→ 徵稅（財政）**。歷史學家所謂「現代國家的可視性」（legibility）——看不見的土地收不到稅，丈量讓台灣「可見」。此舉觸動大租戶與地主的利益，阻力與弊端叢生，是劉銘傳政策中最吃力的一環。

### 線索四：開山撫番與新式學堂 = 治理的兩面

- **開山撫番**：打通東西橫貫道路，設「撫墾局」——以軍事與懷柔並用將原住民領域納入國家治理；這是殖民式的整合，埋下原漢衝突的伏線。
- **西學堂、電報學堂**（1887 起）：培養本地的技術人才——人力資本的自製化，減少對外籍技師的依賴。

### 線索五：制度的脆弱（負向迴路）

劉銘傳的改革觸動既得利益（地主、士紳、官場），財政高度依賴茶糖出口與清賦收入；1891 年他因財政糾紛與政敵攻擊去職，多數新政隨後停擺或萎縮。**改革依賴強人，強人離場則改革斷裂**——這是「人治式現代化」的內建風險：制度未被制度化，改革只是個人的工程。

## 破案時刻

- 1885 年：台灣建省，劉銘傳任巡撫。
- 1887 年：鐵路動工、電報線完工、西學堂設立。
- 1888 年：新式郵政設立；清賦全面推動。
- 1891 年：台北—基隆鐵路通車；劉銘傳去職，改革動能衰退。

## 後果 -- 改變了什麼

- **行政**：台灣成為一省——三府一州的格局，邊陲完成行政整合。
- **基建**：鐵路、電報、郵政成為 1895 年後日本殖民政府接手的現成基礎——清治的現代化遺產被殖民者繼承。
- **財政**：清賦擴大稅基——地籍資料沿用至日治。
- **人才**：西學堂培育的技術人員——台灣最早的一批現代工程人力。
- **反面**：多數改革隨劉去職而停滯——1895 年割讓時，台灣的現代化只是「半成品」（見 [1895-馬關條約與乙未戰爭.md](1895-馬關條約與乙未戰爭.md)）。

## 因素影響筆記

本案件的因素因果鏈：

1. **戰爭壓力（中法戰爭）→ 行政升格（建省）**：威脅是改革的催化劑。
2. **基建投資 → 治理與市場半徑擴大**：運輸、資訊、財政三成本同降。
3. **丈量與登記 → 國家可視性**：現代財政國家的第一步。
4. **強人改革 → 制度脆弱**：改革未制度化，人走政息——「半成品現代化」的教訓。
