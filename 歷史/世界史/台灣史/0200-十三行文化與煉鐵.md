# 0200-十三行文化與煉鐵：鐵器時代的貿易之島

## 案件摘要

約西元 200 年起，台灣淡水河口的十三行遺址出土了大量的鐵器、煉鐵渣與玻璃珠——這是台灣進入「金屬器時代」的標誌。案件的疑點：**台灣本土沒有像樣的鐵礦，十三行人卻能煉鐵；遺址又出土中國錢幣、玻璃器與金銀器——這座小聚落為何同時是「工廠」與「貿易站」？** 兇手是「比較利益＋貿易網路」：十三行人用進口鐵料或鐵器，經營起台灣西北岸的貿易節點，把原住民社會接上東亞的海洋經濟圈。

## 前因 -- 多因素的局勢

- **考古**：十三行文化（約 200–1800 年，亦有說法延伸至漢人入墾）——番社、貝塚、干欄式建築、煉鐵作坊。
- **技術**：東亞冶鐵技術早已成熟（中國戰國已量產鐵器）——技術沿著航路外溢。
- **地理**：淡水河口——台灣西北部最大的河港，是內陸原住民部落與海上航路的介面。
- **資源**：台灣本地缺乏鐵礦，但有豐富的砂鐵（磁鐵礦砂，來自溪流與海灘沖積）。
- **貿易**：漢人、東南亞商船在台灣海峽活動——唐代以後中國海洋貿易興起。

## 線索與推理 -- 因素咬合

### 線索一：煉鐵渣 = 本土工坊的證據

十三行遺址出土大量煉鐵渣（slag）與坩堝殘片——**渣是冶煉的副產品，有渣就有工坊**。煉鐵的核心化學反應：用碳在高溫下把鐵礦石中的氧奪走（還原反應）：

$$\text{Fe}_2\text{O}_3 + 3\text{CO} \rightarrow 2\text{Fe} + 3\text{CO}_2 \quad (T \gtrsim 1000^\circ\text{C})$$

還原劑 CO 由木炭燃燒產生（$\text{C} + \frac{1}{2}\text{O}_2 \rightarrow \text{CO}$）。十三行人以砂鐵或進口鐵料為原料、木炭為燃料——**煉渣證明他們掌握冶煉，而不只是用磨製進口鐵器**。這是台灣最早的本土冶金業。

### 線索二：貿易品 = 節點位置的證據

遺址同時出土：中國銅錢（唐代開元通寶等）、玻璃手環與珠子（可能來自中國或東南亞）、金銀器（如著名的金碗殘件）、大量魚骨與貝殼。一個只有數十戶的聚落，為何有跨國商品？比較利益的邏輯：

| | 十三行人 | 外來商船 |
|---|---|---|
| 有比較利益的事 | 鐵器加工、砂鐵、採硫、鹿皮與山產 | 遠航、布匹、玻璃、錢幣 |
| 機會成本高的 | 遠洋航運 | 深入內陸蒐集山產 |

$$\text{貿易收益} = \text{交換價差} - \text{運輸成本} - \text{交易成本}$$

淡水河口正好把「運輸成本」壓到最低：商船不必深入內陸，部落不必出海——**節點坐地收差價**。這是後來大航海時代（[1544-福爾摩沙與大航海時代.md](1544-福爾摩沙與大航海時代.md)）與荷蘭人選在台灣設站（[1624-荷蘭東印度公司入台.md](1624-荷蘭東印度公司入台.md)）的地理前史。

### 線索三：貝塚與干欄屋 = 生計與社會

貝塚顯示海洋資源在飲食中的比重；干欄式建築（高架房屋）適應濕熱與淹水；陪葬品（玻璃珠、金器）隨墓葬規格分化——**社會階層已經出現**，而階層的來源很可能是控制貿易的家族：誰掌握與商船交易的權利，誰就累積財富。

## 破案時刻

- 約 200 年：十三行文化開始——台灣進入金屬器時代。
- 約 600–1000：遺址中出現唐代錢幣與外來玻璃器——貿易網成形。
- 十三世紀起：漢人、琉球與東南亞船隻往來台灣海峽的紀錄漸增——節點持續運作。
- 1800 年前後：文化層下限——逐漸融入漢人開墾後的社會。

## 後果 -- 改變了什麼

- **技術**：台灣從石器時代直接躍入鐵器時代（本土未經青銅器主導期）——技術跳躍。
- **經濟**：台灣第一次成為東亞海洋貿易網的節點——「貿易之島」的雛形。
- **社會**：原住民部落出現財富與權力的分化——貿易 chieftain 的興起。
- **世界史**：證明大航海時代之前，台灣並非孤立孤島，而是早被接上東亞海洋經濟圈。

## 因素影響筆記

本案件的因素因果鏈：

1. **航路技術外溢 → 本土冶金**：技術沿著人的接觸傳播——鐵器不是孤立發明，是網路中的學習。
2. **地理節點（河口）→ 貿易收益**：位置就是資本——節點坐收差價。
3. **比較利益 → 專業分工**：島民加工、商船運輸——各做機會成本最低的事。
4. **貿易財富 → 社會階層**：誰控制節點，誰掌握權力——經濟因素轉化為組織因素。
