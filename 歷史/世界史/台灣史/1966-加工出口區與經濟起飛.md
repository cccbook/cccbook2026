# 1966-加工出口區與經濟起飛：出口導向工業化的實驗室

## 案件摘要

1966 年 12 月，全球第一個專為出口設置的加工出口區在高雄落成——一片圍籬起來的特區，外資進駐、原料免稅進口、成品全部出口。此後楠梓、台中相繼設立，台灣從「進口替代」轉向「出口導向工業化」，經濟成長率連年超過 10%，締造「台灣奇蹟」。本案要追查：一個小島如何在十年內從農業社會變成出口機器？

## 前因 -- 多因素的局勢

- **經濟**：1950 年代進口替代（自行生產消費品）遭遇內需市場太小的天花板——台灣市場只有一千多萬人。
- **土改紅利**：農村剩餘勞力充沛（見 [1953-耕者有其田與土地改革.md](1953-耕者有其田與土地改革.md)），工資低廉。
- **政治**：威權體制的執行力——政府說一不二，特區法規與基建的推動速度快於民主國家。
- **國際**：1960 年代全球景氣、跨國企業尋找廉價生產基地；美援轉型為貸款與技術協助。
- **地緣**：位居東亞航運要道，高雄港的港口條件優越。

## 線索與推理 -- 因素咬合

### 線索一：雁行理論 = 台灣在隊伍的哪個位置

赤松要的雁行理論：東亞產業如雁群飛行——日本率先工業化，產業升級後把勞力密集產業（紡織、成衣、電子組裝）讓給後進國：

$$\text{後進國的起飛} = \text{（領頭雁的產業讓渡）} \times \text{（自身勞力成本優勢）}$$

台灣 1960 年代正是雁群第二位——**承接日本的技術與訂單，以更低的工資接棒**。韓國緊跟其後。這是區域分工的接力賽，台灣跑對了棒次。

### 線索二：特區設計 = 交易成本的極小化

加工出口區的核心是「一站式服務」：設廠核准、外匯結算、通關、稅務全部在區內完成——把官僚摩擦壓到最低：

| | 一般設廠 | 加工出口區 |
|---|------|------|
| 行政流程 | 數月、多機關 | 數週、一站式 |
| 進口關稅 | 課徵 | 免稅（原料） |
| 外匯管制 | 限制 | 自由結匯 |
| 交易成本 | 高 | 極低 |

**特區 = 制度套利的小實驗室**——國家把「新制度」先圈在圍籬裡試驗，成功再擴散。這與 1978 年後中國的經濟特區（深圳）是同一邏輯，台灣先行了十二年。

### 線索三：低工資 + 高紀律 = 比較優勢的實現

出口導向的核心競爭力是廉價、勤奮、高教育水準的勞工（九年國教自 1968 年啟動，見 [1968-九年國民義務教育.md](1968-九年國民義務教育.md)）。農村女性大量進入電子與紡織工廠——**二元經濟的勞動轉移**（劉易斯模型）：農村剩餘勞力供給工業，工資長期壓低，出口競爭力維持。

### 線索四：成長的複利 = 出口導向的乘數

1960–1970 年代，台灣出口年均成長約 20%，經濟成長率常達 10% 以上，外匯存底快速累積：

$$\text{GDP 成長} \approx \text{出口成長} \times \text{出口佔 GDP 的比例變化}$$

出口從 GDP 的一成多升至五成以上——**小島的規模限制被世界市場解鎖**。進口替代的天花板，被出口導向推倒了。

## 破案時刻

- 1965：高雄加工出口區條例通過、動工。
- 1966.12：高雄加工出口區正式營運，首批外資（電子、成衣）進駐。
- 1971：楠梓、台中加工出口區相繼設立。

## 後果 -- 改變了什麼

- **經濟**：台灣成為世界電子與紡織代工重鎮；外匯存底累積，1970 年代轉向重工業（十大建設）。
- **社會**：農村人口大規模移入都市，中產階級興起；女性大量進入勞動市場。
- **政治**：經濟成為威權政體的正當性來源（「表現型正當性」）——但中產階級的興起也埋下民主化的種子。
- **世界史**：全球第一個加工出口區成為開發中國家的制度模板（中國、東南亞、中南美紛紛仿效）。

## 因素影響筆記

1. **市場天花板 → 出口轉向**：內需不足是轉型的推力。
2. **雁行接力 → 產業承接**：區域分工的時機與位置決定成敗。
3. **特區制度 → 交易成本極小化**：制度是競爭力，圍籬內的實驗室是改革的技術。
4. **本案件的總教訓**：小經濟體的出路在於把世界市場當作自己的市場——制度（特區）＋要素（勞力）＋時機（雁行）三者的咬合，就是奇蹟的配方。
