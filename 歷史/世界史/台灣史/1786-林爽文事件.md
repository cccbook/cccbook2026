# 1786-林爽文事件：天地會起義與帝國的十年武功

## 案件摘要

1786 年 11 月，彰化天地會首領林爽文起事，攻陷彰化、諸羅，圍困府城；南部莊大田響應，全台幾乎易手。清軍屢戰屢敗，乾隆派陝甘總督福康安率精銳渡台，1788 年初方才平定。這是清代台灣規模最大的民變，也被乾隆列入「十全武功」之一。案件的謎題：一個內陸縣衙的會黨起事，為何要動用帝國最精銳的部隊？兇手是**會黨網絡與分類結構的複合**——起事者用分類動員，平定者也用分類平定。

## 前因 -- 多因素的局勢

- **組織**：天地會自福建傳入台灣——異姓結拜、互保互助的秘密會黨。
- **社會**：漳泉分類械鬥頻仍——1782 年彰化漳泉大械鬥的餘波。
- **政治**：官府查禁天地會、逮捕會眾——逼迫會黨提前起事。
- **軍事**：台灣綠營兵力薄弱——府城與諸羅之間的防務空洞。
- **經濟**：土地開發的利益分配（大租戶、小租戶、佃農）——階層矛盾的背景。

## 線索與推理 -- 因素咬合

### 線索一：天地會 = 互助需求生出的秘密組織

天地會的功能首先是互助（喪葬濟助、糾紛仲裁、防身），其次才是反清。羅漢腳社會的需求結構：

$$\text{會黨規模} \propto \text{（無產人口的互助需求）} \times \text{（官方治理的空缺）}$$

禁令社會造出需求，薄弱治理讓出空間——天地會在台灣的發展速度遠超福建原鄉。官府的查禁則適得其反：查禁提高了會員的忠誠（退會的成本變成死刑），並迫使會眾團結——**鎮壓式的治理是秘密組織最好的招募廣告**。

### 線索二：分類的雙刃 = 起事與平定的同一邏輯

林爽文（漳州人）起事後，泉州人與客家莊拒絕響應，組成「義民」助清——分類意識同時削弱了起事者、增強了平定者：

| | 林爽文（漳） | 義民（泉、客） |
|---|------------|---------------|
| 動員基礎 | 漳州社群 | 泉州＋客家社群 |
| 訴求 | 反清 | 保障莊社（助清） |
| 結局 | 內部分類裂痕 | 義民成為清代台灣的軍事傳統 |

福康安的策略正是利用這條斷層線：以義民為嚮導與補給，以精銳兵力直搗大里杙根據地。**起事者與平定者用的是同一套分類邏輯**——清代台灣的政治動員從未跳出分類框架。

### 線索三：十全武功 = 帝國的自我敘事

乾隆將林爽文之役列入「十全武功」，是十全中唯一在帝國領土內的平亂。這暴露了結構性的矛盾：帝國把「內部民變」敘事為「對外武功」，以維持征服的正當性敘事。但軍事上的事實是：台灣綠營無力平亂，需由大陸調兵渡海——治理半徑跨海的成本極高：

$$\text{跨海治理成本} = \text{駐軍維持費} + \text{動亂平定費（每數十年一次）}$$

清代官員對「治台成本」的反覆計算，一直要到 1874 年牡丹社事件後才真正得出結論（轉向積極治台）。

## 破案時刻

- 1786 年 11 月：林爽文攻陷彰化、諸羅；莊大田南部響應。
- 1787：清軍屢敗；諸羅守城（乾隆改名「嘉義」以獎守城軍民）。
- 1788 年初：福康安渡台，解諸羅之圍，擒林爽文；莊大田旋亦被擒。

## 後果 -- 改變了什麼

- **政治**：乾隆加派兵力、增設行政區——但治理半徑問題依舊。
- **社會**：客家義民的傳統確立（新竹、苗栗義民廟信仰的源頭）——分類結構的再固化。
- **軍事**：清廷在台增設營汛，卻未改變「防內重於防外」的邏輯。
- **世界史**：帝國對海島統治成本的計算——六十年後同樣的問題由日本以殖民統治的方式回答。

## 因素影響筆記

1. **禁令社會 → 會黨需求**：互助需求是秘密組織的溫床。
2. **查禁 → 忠誠強化**：鎮壓提高了退出成本——治理的適得其反。
3. **分類意識 → 義民傳統**：斷層線同時是起事的動員與平定的槓桿。
4. **跨海治理成本 → 消極統治**：成本計算決定了帝國對台灣的投資意願——這個問題的答案要到 1874 年才改變。
