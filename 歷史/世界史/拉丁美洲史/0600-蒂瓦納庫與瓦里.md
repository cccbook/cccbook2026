# 0600 蒂瓦納庫與瓦里：沒有文字的安地斯雙帝國

## 案發現場

西元 600 年前後，安地斯高原同時升起兩個太陽：南方的蒂瓦納庫（Tiwanaku），踞的的喀喀湖畔海拔近四千公尺；北方的瓦里（Wari），踞中部高原阿亞庫ucho盆地。兩者都築城、修路、屯田、駐軍，勢力各覆蓋數十萬平方公里——規模堪比同時代的唐與拜占庭的地方總督區，卻**沒有留下任何文字**。

約西元 1000 年，雙帝國又在百年之內相繼崩塌：城市被棄，梯田荒蕪，高原陷入分裂。此後四百年，安地斯再無帝國，直到印加。是巧合，還是同一兇手？

> **沒有文字的帝國如何統治數十萬平方公里？兩個同時崛起、同時死亡的帝國，背後是同一個氣候兇手嗎？**

## 偵查過程

**線索一：高原農業的三件套（梯田、馬鈴薯、駱馬）。** 的的喀喀湖畔寒冷缺氧，蒂瓦納庫發明高畦農法（chinampa 的高原親戚：waru waru Raised Beds）——抬高田床、環水調溫，霜凍之夜仍可保住馬鈴薯與藜麥；馴化羊駝與駱馬提供馱運、毛料與肉食。瓦里則在山坡大修梯田與灌溉渠，把玉米種上原本種不了的高度。偵查：**農業工程是帝國的地基**——多養一個人，就多一份稅與一個兵。技術（technology）→剩餘糧食（economy）→帝國動員（politics）。

**線索二：無文字的統治技術（結繩、倉儲與複製）。** 兩帝國皆無文字，卻有標準化手段：遍佈各地的**國營倉儲群**（盈餘集中再分配）、制式陶器與紡織紋樣（帝國認證的器物）、四通八達的驛道與驛站、以及後來印加沿用的**結繩記事（quipu）**前身。瓦里更以「複製首府」著稱——在征服地照抄瓦里式行政中心與神廟格局。偵查：文字缺席之處，**倉庫、道路與制式器物就是公文**：看得見的糧堆與穿得出的紋樣，比詔書更有效。制度（institution）→可視的權力（legibility）。

**線索三：雙帝國的分工與對峙（南北 squeeze）。** 蒂瓦納庫主控南方高原、湖區與南下智利的商路，以宗教朝聖（太陽門、卡拉薩薩亞神廟）與湖區物產立國；瓦里主控中部高原與南下海岸通道，以軍事屯墾與行政複製擴張。兩者勢力在南方海岸與高原南部犬牙交錯，既貿易又對峙。偵查：雙帝國把整個安地斯編成一張**糧倉—道路—神廟網**，地方菁英被收編為倉儲官與祭司。網絡（network）→依附（dependency）→帝國秩序。

**線索四：約 1000 年的同步死亡（旱災假說）。** 湖芯沉積與冰芯顯示，約 1000–1100 年安地斯高原遭遇長期嚴重乾旱：的的喀喀湖水位大降，waru waru 高畦失去環水調溫之效，梯田灌溉無水可引。蒂瓦納庫城與瓦里各省會先後被棄，倉儲體系斷糧。偵查：**靠精密農業工程撐起的帝國，也死於工程前提的消失**——水位一下降，再嚴密的倉儲與道路都無糧可運。氣候（climate）→農業崩潰（economy）→行政解體（politics），一條筆直的兇器鏈。

**線索五：留給印加的遺產（帝國的草稿）。** 雙帝國死後，梯田、驛道、倉儲、結繩、太陽神崇拜與行政複製術，全被印加繼承並放大。印加自稱太陽後裔、定都庫斯科（接近瓦里故地）、重建全國倉儲路網——等於照著雙帝國的草稿重抄一遍。偵查：蒂瓦納庫與瓦里是**安地斯帝國的第一次彩排**，印加是正式演出。制度遺產（institution）→路徑依賴（path dependence）。

## 結案報告

1. **高原也能養帝國**：高畦田、梯田、馬鈴薯藜麥與駱馬馱運，把四千公尺的「不毛高原」變成糧倉——農業工程改寫了帝國的海拔上限。
2. **無文字統治術**：倉儲、驛道、制式器物與結繩記事，足以管理大帝國——文字不是國家能力的必要條件，可視的糧食與道路才是。
3. **氣候是共同兇手**：約 1000 年的長期旱災同時拔掉雙帝國的農業插頭——工程型帝國最強之處（精密水利），正是其最脆弱之處。
4. **偵探教訓**：帝國死亡現場先別只找入侵者，先查**湖芯與冰芯**——氣候帳本裡的旱線，往往比戰場上的刀痕更早寫下結局。

**旱災致死的因果鏈：**

```
長期旱災（湖芯冰芯證據，約 1000–1100）
   ↓ 湖水位下降、渠道斷流
高畦失溫＋梯田無水 → 馬鈴薯藜麥歉收
   ↓ 倉儲見底、驛道無糧可運
駐軍斷餉 → 地方菁英脫鉤
   ↓
雙城被棄 → 高原分裂四百年 → 印加接棒
```

**結論：** 蒂瓦納庫與瓦里證明兩件事：高原農業工程能托起無文字的大帝國；而托起帝國的水，也能在一場百年旱災中把帝國放下。**帝國的草稿寫在梯田與倉庫裡，驗收者卻是氣候——印加後來把這份草稿抄成了正稿。**
