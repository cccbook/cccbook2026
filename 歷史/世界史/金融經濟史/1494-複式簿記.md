# 1494 - 複式簿記（資本主義的會計引擎）

## 案件摘要
1494 年，**Luca Pacioli** 在威尼斯出版《算術、幾何、比與比例概要》（Summa），
系統化**複式簿記（double-entry bookkeeping）**——
每筆交易**記兩次**（借方 = 貸方），帳本**自我校驗**：
$$\text{資產} = \text{負債} + \text{權益} \quad (A = L + E)$$
這不是數學發明（威尼斯商人已用 200 年），而是**標準化與出版**——
讓「可驗證的帳本」從商人祕技變成**資本主義的基礎設施**：
**沒有複式簿記，就沒有大企業、沒有審計、沒有股份有限公司**。

## 前因 -- 為什麼會有這個案子
- **單式帳本的致命缺陷**：只記「我付了什麼、收了什麼」——**無法發現錯誤與舞弊**；
- **威尼斯商業的複雜度**：遠洋貿易、合夥、匯兌、佣金——**單式記不完了**；
- **15 世紀義大利的積累**：佛羅倫斯/威尼斯商人已用複式記帳（1300s）——
  **Pacioli 的工作是「整理 + 出版」**；
- **印刷術的推力**：古騰堡（1450s）→ 教科書可以**大量傳播**——
  **知識的規模化**（與 1961 年 Kasper 把對準機商品化同理：
  **把私門知識變成公開標準**）。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：會計恆等式（自我校驗的數學）
每筆交易同時記錄兩個方向：
$$\text{借方（Debit）} = \text{貸方（Credit）} \quad \Longrightarrow \quad A = L + E$$
- **總和恆等**：任何錯誤都會讓借貸不等——**錯誤可被偵測**——
  **這是「用冗餘偵測錯誤」的資訊學原理**（同位元檢查、
  半導體檢測的 die-to-die 比對——見 `科學史/半導體設備史/1976-KLA檢測設備.md`）；
- **偵推**：複式簿記 = **會計的「同位元檢查」**——
  一個加法校驗，就讓 100 萬筆交易近乎不可舞弊（不被輕易掩蓋）。

### 第二條線索：範例帳本（借貸記帳）
| 交易 | 借方 | 貸方 | 金額 |
|------|------|------|------|
| 收到股本 1,000 ducat | 現金 | 資本 | 1,000 |
| 買貨 600 ducat | 存貨 | 現金 | 600 |
| 賒賣 800 ducat | 應收帳款 | 銷貨 | 800 |
| 合計 | 2,400 | 2,400 | ✓ 平衡 |

- **每一行都是兩個故事**：資源的來與去——**資本主義的「敘事規範」**。

### 第三條線索：理論回望——複式簿記為什麼是「資本主義的引擎」
- **Sombart（1902）的命題**：複式簿記是資本主義的精神前提——
  **把財富變成「可計算、可比較、可累積」的抽象量**；
- **Weber 的理性化**：可計算性（calculability）是理性資本主義的特徵；
- **企業的存續**：複式簿記讓企業**獨立於老闆的生命**（帳本比人活得久）——
  **永續經營體（going concern）的誕生**——
  與 1602 年 VOC 的**永續資本**（見 `1602-荷蘭東印度公司.md`）互為因果。

### 第四條線索：複式簿記的延伸（從帳本到審計到財務報表）
| 年代 | 發明 | 意義 |
|------|------|------|
| 1300s | 義大利商人複式記帳 | 私門技術 |
| 1494 | Pacioli 出版 | 標準化 |
| 1600s | 年度結帳、損益表 | 績效可衡量 |
| 1800s | 審計師職業 | 第三方驗證 |
| 1900s | GAAP/IFRS | 全球的會計語言 |
| 2000s | 公允價值、衍生品會計 | 市值化的極端（2008 的伏筆）|

## 結案 -- 後果與影響
- **股份公司的前提**：可審計的帳本 → 股東信任 → **外部資本**——
  VOC（1602）的永續資本建立在帳本上；
- **審計與信任的機器**：現代資本市場的**揭露制度**（disclosure）——
  SEC（1934）的全部邏輯就是「**強制公開可驗證的帳本**」；
- **會計的身分**：Pacioli 的方法讓「**利潤**」成為可計算的科學量——
  **資本主義的核心指標（ROI、EPS）是會計的發明**；
- **偵探教訓**：1494 年證明了——**文明的跳躍常常不是新發明，
  而是把已有的好方法「標準化 + 出版」**（與複式簿記同構的：
  Paxioli 之於簿記 = Kasper 之於對準機 = ASML 之於微影）。
