# 1845 - 英國鐵路狂熱（鐵路股泡沫：實體革命與金融泡沫的雙面案件）

## 案件摘要
1845–1847 年，英國國會收到**上千件鐵路法案**，鐵路股價在兩年內翻倍再翻倍，
全民——公爵到女傭——排隊認購。1847 年 10 月，泡沫連同穀物歉收的貨幣衝擊一起爆破，
銀行利率升到 10%，**1844 年皮爾銀行法被迫暫停**：
$$\text{真實革命（鐵路）} + \text{金融泡沫（股份認購）} \to \text{同一場危機的兩張臉}$$
本案是金融史上最弔詭的案件：**泡沫破裂了，鐵路卻留了下來**。

## 前因 -- 為什麼會有這個案子
- **1825 年斯托克頓–達靈頓鐵路成功**（見 `1825-鐵路時代開啟.md`）+ 1830 年利物浦–曼徹斯特線的**股息實績**——投資人第一次「看得見的複利」；
- **倫敦證交所的角色**（見 `1801-倫敦證交所.md`）：鐵路股成為主板主力，流動性使「認購即轉售」成為玩法；
- **1844 年公司法鬆綁**：註冊公司免特許——**供給側打開了新股發行的閘門**；
- **低利率環境**：3% 的公債殖利率讓 5% 保證股息的鐵路股像免費午餐；
- **保證金制度**：認購只需付 5–10% 押金——**用槓桿買未來的鐵路**（風航交易的鐵路版）。

## 線索與推理

### 第一條線索：泡沫的財務結構（分期認購的槓桿）
鐵路股採「認購—分期繳款」制：
$$\text{投入 5\%} \to \text{股價漲 20\%} \to \text{報酬率 400\%}$$
- 押金 5 英鎊、面額 100 英鎊的認購權，本身就是一張**深價內選擇權**；
- 需要催繳（calls）時賣股補錢 → 股價跌 → 更多催繳 → **正回饋下墜**。

### 第二條線索：Python——催繳螺旋
```python
equity, calls_due, price = 1000, 0, 100.0
for week in range(1, 25):
    price *= (0.88 if week > 12 else 1.05)      # 前漲後跌
    calls_due += 80                              # 鐵路公司持續催繳
    equity += 0  # 賣股繳款
    if price < 70:
        equity -= calls_due * (100 - price) / 100
        print(f"week {week}: 股價 {price:.0f}，累積催繳 {calls_due}，淨值 {equity:.0f}")
    if equity <= 0:
        print(f"week {week}: 破產——催繳螺旋完成")
        break
```
（**泡沫不是崩在「沒人買」，而是崩在「錢繳不出來」**——1847 年的真實機制。）

### 第三條線索：真實經濟與泡沫的辯證（Schumpeter 命題）
| 兩張臉 | 證據 |
|--------|------|
| 泡沫面 | 1/3 的法案從未動工；股價與里程嚴重背離 |
| 實體面 | 1840s 末英國鐵路里程從 2,400 英里 → 6,600 英里；運費、旅行時間實質崩跌 |
- Schumpeter：**泡沫是創新的融資載體**——大工程需要超額動員，
  泡沫的「浪費」是給未來路網的預付款；
- Kindleberger 的 Minsky 階段：欺騙（manipulation）階段的樣本——
  George Hudson 等鐵路大王的做帳醜聞在 1848–49 年連環爆發。

### 第四條線索：貨幣制度的擠壓
1844 年皮爾銀行法規定發行部以 100% 黃金背書發鈔：
- 1846–47 年馬鈴薯歉收 → 黃金外流買糧 → $M$ 被動緊縮；
- 同時鐵路催繳抽乾存款 → **貨幣需求↑而供給↓**；
- 10 月恐慌，銀行法**暫停施行**——政府親手承認「規則在危機中會讓位給最後貸款人」
  （Bagehot 在 `1873-巴吉特最後貸款人.md` 把這一課寫成教義）。

## 結案 -- 後果與影響
- **1873 的預演**：鐵路超建 + 金融槓桿的配方，20 年後在美國重演（見 `1873-巴吉特最後貸款人.md`）；
- **公司法修正（1856）**：泡沫讓「股份公司」名譽掃地，卻也讓有限責任改革加速——
  制度補丁在崩潰之後到貨（本卷 `1855-有限責任法.md` 的直接背景）；
- **會計與審計**：Hudson 做帳案催生鐵路帳目公開要求——審計職業的需求端；
- **鐵路時代照樣來臨**：1848 年後完工的路網讓英國運費再跌一半——
  **偵探教訓：判斷泡沫，先問「崩了以後留什麼」**——留路網的叫過度投資，留帳篷的才是龐氏。

## 因果鏈總表
$$\text{股息實績} + \text{證交所流動性} + \text{5\%保證金} + \text{低利率} \to \text{認購狂熱} \to \begin{cases} \text{1847 催繳危機 + 銀行法暫停} \\ \text{Hudson 做帳醜聞} \\ \text{6,600 英里路網留下} \\ \text{Bagehot 教義的伏筆} \end{cases}$$
