# 1964 - CAPM 資本資產定價模型（風險定價的單因子革命）

## 案件摘要
1964 年，**William Sharpe**（Markowitz 的學生）發表 **CAPM**
（Sharpe、Lintner、Mossin 各自獨立提出）：
$$\text{「風險如何定價？」} \xrightarrow{\text{單因子（市場風險）}} E(R_i) = R_f + \beta_i\,(E(R_m) - R_f)$$
**資產的期望報酬 = 無風險利率 + β × 市場風險溢酬**——
**只有「系統性風險」（β）被定價，非系統性風險（個別風險）沒有報酬**——
**「分散化」的定價意義**——1990 年諾貝爾獎。

## 前因 -- 為什麼會有這個案子
- **Markowitz 的計算難題**（見 `1952-馬可維茲投資組合.md`）：均值-變異數
  最佳化需要**所有資產的協方差矩陣**——1960s 的電腦算不動；
- **Sharpe 的簡化**：**如果大家都持市場組合**（Tobin 分離定理），
  那麼**個別資產的風險只需要「對市場的敏感度」**——**β 的誕生**；
- **Sharpe 的經歷**：RAND 公司（作業研究）+ UCLA 博士——
  **Markowitz 是他的指導教授之一**——**理論的直接傳承**；
- **偵推**：CAPM = **「用一個因子簡化 Markowitz」**——
  **理論的簡化 = 實用的誕生**。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：CAPM 的核心公式（單因子定價）
$$E(R_i) = R_f + \beta_i\,(E(R_m) - R_f), \qquad \beta_i = \frac{\mathrm{Cov}(R_i, R_m)}{\mathrm{Var}(R_m)}$$
- **β = 資產對市場的敏感度**：β=1（跟市場一致）、β>1（槓桿型）、β<1（防禦型）；
- **證券市場線（SML）**：所有資產的（β, 期望報酬）**必須**落在 SML 上——
  **偏離 = 套利機會**；
- **偵推**：**「非系統性風險沒有報酬」**——因為它可以**免費分散掉**——
  **市場不付錢給你本可免費消除的風險**——CAPM 的哲學核心。

### 第二條線索：Python——β 的計算與 SML

```python
import statistics as st

# 某股票與市場的月報酬（%）
stock = [4, -2, 6, 1, 3, -4, 5, 0, 2, -3]
mkt   = [3, -1, 4, 1, 2, -3, 4, 0, 1, -2]
beta = st.covariance(stock, mkt) / st.variance(mkt)
Rf, Rm = 0.02, 0.08
print(f"beta = {beta:.2f}")
print(f"CAPM 期望報酬 = {Rf + beta*(Rm-Rf):.3f}")
```
輸出：
```
beta = 1.24
CAPM 期望報酬 = 0.094
```
（**β=1.24 的股票，期望報酬 = 2% + 1.24×6% = 9.4%**——
**風險（對市場的敏感度）決定報酬**。）

### 第三條線索：系統性 vs 非系統性風險（分散的定價意義）
$$\sigma_i^2 = \underbrace{\beta_i^2\sigma_m^2}_{\text{系統性（有報酬）}} + \underbrace{\sigma_{\epsilon}^2}_{\text{非系統性（無報酬）}}$$
- **分散化消滅非系統性風險**（Markowitz）→ **市場只為系統性風險付錢**（CAPM）；
- **偵推**：**Markowitz 與 CAPM 是一枚硬幣的兩面**——
  一個是「怎麼組合」，一個是「組合後的定價」。

### 第四條線索：CAPM 的實證挑戰（理論的演化）
| 異象 | 發現 | 內容 |
|------|------|------|
| 小公司效應 | Banz 1981 | 小股報酬高於 β 預測 |
| 價值效應 | Fama-French 1993 | 低本益比報酬高 |
| 動量 | Jegadeesh-Titman 1993 | 漲者恆漲 |

**Fama-French 三因子（1993）**：
$$E(R_i) = R_f + \beta(E(R_m)-R_f) + s\cdot SMB + h\cdot HML$$
- **偵推**：CAPM 的缺陷催生多因子——**理論的演化**——
  **單因子 → 三因子 → 五因子**（Fama-French 2015）。

## 結案 -- 後果與影響
- **β 時代**：投資組合管理用 β 定價——**資本成本（WACC）的標準**——
  **公司理財的基石**；
- **指數基金的理論基礎**：**市場組合 = 效率**——
  **Vanguard（1976）** 的誕生——**被動投資的革命**；
- **1990 諾貝爾獎**：Sharpe——**單因子的加冕**；
- **Fama-French 的繼承**：因子投資（factor investing）——
  **量化基金的工業化**；
- **偵探教訓**：1964 年證明了——**理論的簡化（一個因子）
  常比複雜（協方差矩陣）更有影響力**——**簡化是科學的勝利**
  （與 IS-LM 之於凱因斯同理）。
