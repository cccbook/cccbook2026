# 1972-紅杉資本與創投制度：2/20 公式如何量產矽谷

## 案件摘要
1972 年，唐·瓦倫丁（Don Valentine）在沙丘路創辦紅杉資本（Sequoia Capital）；同年 KPCB 成立，有限合夥＋2/20 收費＋ERISA 鬆綁預期，三者合流，「矽谷創投體制」定型。兇手不是單一的伯樂眼光，而是 ARD（1946）證明封閉基金可行、仙童系出走潮提供案源、有限合夥解決 GP/LP 誘因、1979 年 ERISA 澄清允許退休金入場四者咬合。創投從「富豪副業」變成「制度化量產獨角獸的機器」——蘋果（1978 紅杉投資）、甲骨文、思科、Google、Airbnb 皆出此門。

## 前因 -- 為什麼會有這個案子
- **先驅**：1946 年多里奧創 ARD，投資 DEC 賺 500 倍，證明「陪跑＋重倉」可行，但封閉公司制募資艱難。
- **案源**：1968 英特爾、1969 AMD，仙童系每年裂變數家新創——沙丘路旁即是礦脈，缺的是採礦機。
- **組織**：1958 年小企業投資法催生 SBIC，但官僚僵化；德雷珀（Draper）等試驗有限合夥雛形，GP 出 1% 操盤、LP 出 99% 資金。
- **資金**：1970 年那斯達克前身議論、IPO 通道漸開；1979 年勞工部澄清 ERISA「謹慎人」規則，退休金可投創投，資金水庫開閘。
- **人物**：瓦倫丁（仙童、國家半導體銷售出身）深信「投人不投術」；KPCB 的 Perkins、Kleiner 則是技術派——兩派同年開張，互為鏡像。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：2/20 的誘因相容
有限合夥標準條款：2% 管理費＋20% 績效分成（carry），GP 跟投 1%：
$$\text{GP 報酬} = 2\% \times AUM + 20\% \times \max(0, \text{利潤} - \text{門檻})$$
偵推：管理費養團隊、carry 賭上行、跟投綁風險——委託-代理問題的制度解。SBIC 拿死薪水故官僚，2/20 讓 GP 與 LP 同坐一條船。

### 第二條線索：冪律——創投的數學骨架
創投回報服從冪律，一檔基金中約一成案子賺回整檔：
| 分位 | 佔比 | 貢獻回報 |
|---|---|---|
| 明星（>10x） | ~10% | ~70–80% |
| 平庸（1–3x） | ~30% | ~20% |
| 歸零 | ~60% | 0（虧損） |

$$\text{基金回報} \approx \sum p_i r_i,\quad \text{尾部主導一切}$$
偵推：創投不是「少犯錯」，而是「不錯過尾部」——重倉＋陪跑＋快速止損，皆由此式導出。紅杉敢在蘋果、Google 最貴時加碼，正是冪律思維。

### 第三條線索：Python——為什麼必須投出 10 倍

```python
# 一檔 10 個案子的簡化基金：9 個歸零/平庸，1 個明星
returns = [0, 0, 0, 0, 0, 1.5, 2.0, 2.5, 3.0, 20.0]
moic = sum(returns) / len(returns)
print(f"組合 MOIC = {moic:.2f}x")  # 2.90x
# 若錯過 20x 明星：MOIC = 0.90x（虧錢）
print(f"錯過明星 MOIC = {sum(returns[:-1])/len(returns):.2f}x")
```

（錯過尾部即虧損——創投是「尾部狩獵業」。）

### 第四條線索：退出迴路——那斯達克＋IPO
1971 年那斯達克電子報價（見 1971 案）給成長股 IPO 通道，創投才有退出。迴路：
$$\text{創投投資} \to \text{成長} \to \text{IPO 退出} \to \text{LP 獲利} \to \text{再募資} \to \text{更多投資}$$
1978 年蘋果 60 萬美元投資、1980 年 IPO 賺 100 倍以上——迴路第一次完整轉動，矽谷機器點火。

## 結案 -- 後果與影響
- **矽谷量產化**：紅杉＋KPCB 模板（2/20、董事會陪跑、對賭、分期注資）被全球複製，沙丘路成為制度地標。
- **科技史**：沒有 1972 體制，就沒有蘋果、思科、Google 的超速成長——技術天才需要尾部資本。
- **金融史**：ERISA 鬆綁後退休金湧入，創投管理規模從 1970 年代數億美元膨脹到 2021 年逾千億——另類資產的先鋒。
- **泡沫一體兩面**：同一體制在 2000 年燒出網路泡沫（見 2000 案）——冪律狩獵必然附帶過度狩獵。
- **偵探教訓**：創投的發明不是「看人眼光」，而是「誘因＋冪律＋退出」的三件套制度。
