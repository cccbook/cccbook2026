# 前214-秦置南海郡與百越海洋先民：漁村神話的考古反證

## 案件摘要

前 214 年，秦始皇平定嶺南、置**南海郡**（郡治番禺，今廣州），香港所在的珠江口從此納入中原帝國的行政版圖。但在帝國登記之前，這片海域早已住滿人：新石器的**大灣文化**聚落（西貢滘西洲、馬灣東灣仔北）、百越先民的**採珠與製鹽**產業、漢代李鄭屋古墓、唐代的**屯門鎮**——香港在兩千年裡始終是嶺南海洋網絡的常設節點。這樁案件要偵破的是一個流行誤解：**「香港開埠前是小漁村」**。證據顯示：不是漁村，是海上絲路的中繼站。

## 前因 -- 多因素的局勢

- **地理**：珠江口東側的深水良港＋鹹淡水交界的河口灣——產珠、產鹽、可停泊，三種資源一次到位。
- **族群**：百越（南越）先民的海洋傳統——善舟習水、以海為田，與中原的農耕文明是兩套技術樹。
- **帝國**：前 221 秦統一後南擴——前 214 平嶺南、置南海／桂林／象三郡，移民五十萬實邊。
- **貿易**：南海—印度洋航線逐步成形——香料、珠璣、犀角的長程貿易需要中繼港。

## 線索與推理 -- 因素咬合

### 線索一：考古地層——「先民比帝國早到三千年」

| 遺址 | 年代 | 證據 |
|---|---|---|
| 西貢滘西洲 | 新石器中期（約前 4000） | 石器、聚落遺跡 |
| 馬灣東灣仔北 | 新石器至青銅 | 墓葬、陶器序列 |
| 大灣文化（南丫島等） | 約前 3500–2500 | 彩陶圈足盤——跨域風格 |

大灣文化的彩陶與長江流域（如崧澤文化）風格呼應——**石器時代的香港已在長程交換網絡之內**。「海隅小村」的地層裡，埋的是跨海貿易的風格傳播。

### 線索二：珠與鹽——「資源的帝國會計」

百越先民的採珠（合浦珠池、大澳一帶海域）與煮鹽，被帝國快速收編為官營資源。漢武帝設**鹽鐵官**，番禺的鹽官管轄含香港在內的沿海場區：

$$\text{帝國對邊陲的興趣} = \text{（資源產出）} \times \text{（運輸成本的可控性）}$$

**帝國不是為了領土而來，是為了會計科目而來**——珠、鹽、香料把這片「蠻荒海隅」記進了中央的收支簿。前 111 年漢平南越、嶺南入漢版圖；李鄭屋漢墓（東漢）墓磚刻「**大治曆**」——邊陲的工匠已在用帝國的紀年。

### 線索三：屯門鎮——「海絲航線的原始碼」

唐代設**屯門鎮**（防海）、屯門為番舶入廣州前的等候泊點——外海船隻候風、候引水、候關檢：

$$\text{中繼港價值} = \text{（主港廣州吞吐量）} - \text{（屯門到廣州的航程與風險）}$$

**香港的命運公式在唐代已寫好：它是廣州的外港**。深水良港＋珠江口位置，等一個貿易體系升級的那一天——這份地理原始碼，要到 1841 年才被重新編譯（參見[1839-鴉片戰爭.md](1839-鴉片戰爭.md)）。

## 破案時刻

- 約前 4000：滘西洲、東灣仔北聚落——新石器先民定居。
- 約前 3500–2500：大灣文化彩陶——跨域交換網絡成形。
- 前 214：秦平嶺南、置南海郡（番禺）——帝國行政到達珠江口。
- 前 111：漢武帝平南越——嶺南正式入漢版圖、設鹽鐵官。
- 東漢：李鄭屋古墓——墓磚「大治曆」銘文。
- 唐：設屯門鎮——海上絲路的常設泊點與海防節點。

## 後果 -- 改變了什麼

- **政治**：嶺南納入郡縣制——此後兩千年，珠江口始終在「廣州—中央」的行政軸上，未曾自成體系。
- **經濟**：珠、鹽、番舶貿易的資源組合——香港的「可利用性」早在帝國帳簿上立案。
- **社會**：百越海洋傳統與中原移民的混合——嶺南「面向海洋」的文化基因。
- **國際**：屯門成為域外航海者的已知地標——歐洲人東來前的數百年，波斯、阿拉伯、東南亞船隻已在此候泊（[1513-歐人東來與屯門海戰.md](1513-歐人東來與屯門海戰.md)）。

## 因素影響筆記

```
深水良港＋珠江口（地理）──┬──→ 珠、鹽資源（帝國會計）──→ 前214 置郡
                            └──→ 泊點功能（航線需求）──→ 唐屯門鎮
百越海洋傳統（族群）──────→ 長程交換網絡（大灣文化）
                                        ↓
                    「漁村」神話被考古與文獻雙重否定
```

**偵探結語**：本案證明：**「漁村」是結果，不是起點**——香港不是 1841 年從零開埠，而是兩千年海洋網絡的節點被重新定價。帝國為珠與鹽而來，航線為候風而停；地理的原始碼一旦寫好，等的不過是下一次編譯。
