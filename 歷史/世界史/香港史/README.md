# 香港史 -- AI 偵探風格

以「推理探案」的方式，追查香港從百越海洋節點到明文時代的每一次結構變遷：
秦置南海、宋末二王、屯門海戰、一口通商、鴉片戰爭、開埠、割九龍、租新界、革命基地、省港罷工、淪陷、重光、難民工業化、六七、廉政、聯合聲明、回歸、雨傘、反修例——
前因是什麼？線索在哪裡？推理如何展開？後果又如何改變了這座深水良港？

本卷的核心命題只有一句話：**香港史是「縫隙的槓桿」的兩千年變奏。**
嶺南海洋網絡的常設節點、帝國夾縫裡的轉口港、冷戰邊境的生產線、兩制之間的模糊地帶——香港的每一次躍升，都不是自己選的，而是**大國博弈留出的縫隙被華人社會的網絡填滿**；而縫隙一旦被明文關閉，槓桿就換了支點。每個重大事件都是一樁「多因懸案」：偵探的工作，就是把因素鏈一環一環還原出來。

（涵蓋：百越海洋先民、秦置南海、宋末二王、屯門海戰、十三行、鴉片戰爭、開埠、割九龍、租新界、革命基地、省港大罷工、三年零八個月、重光、難民工業化、六七暴動、廉政公署、中英聯合聲明、回歸、雨傘、反修例與國安法）

## 歷史因素：各自如何影響其他因素

| 因素 | 影響其他因素的機制 | 香港史經典案例 |
|------|---------------------|---------------|
| **地理** | 深水良港＋珠江口位置＝門戶的原始碼 | 屯門泊點；維多利亞港；九龍的幾何補全 |
| **貿易** | 貿易結構的不平衡生成衝突與轉型 | 白銀漏損→鴉片；禁運→工業化；轉口→服務業 |
| **帝國** | 主權的表格決定城市的命運 | 南京條約；99 年租約；聯合聲明 |
| **法治** | 制度移植是轉口港的信任基礎 | 英式司法＋自由港；廉政公署的系統修復 |
| **縫隙** | 治外法權與模糊地帶養出反體制者 | 興中會基地；冷戰夾縫；一國兩制的張力 |
| **人口** | 難民潮是資本與勞動的雙重輸入 | 1949 難民工業化；石硤尾→徙置區 |
| **心理** | 信心危機直接改寫資本流動 | 1983 港元危機→聯繫匯率；移民潮兩波 |
| **武器** | 火力差距決定帝國進出 | 屯門海戰；醉酒灣防線；催淚彈的政治學 |
| **疾病** | 外生衝擊重置經濟結構 | 沙士→自由行；疫後向北生活圈 |
| **資訊** | 報刊與電訊是門戶的神经系統 | 中國日報；海底電纜；禁運下的訊息港 |
| **冷戰** | 意識形態邊界把城市變成前哨 | 省港罷工；六七暴動；難民工業化 |

## 因素的回饋迴路

```
    地理（良港）──→ 貿易 ──→ 帝國（主權表格）──→ 法治／制度
       │             ↑              │                 │
       │             │              ↓                 ↓
       └──→ 縫隙（夾縫地帶）←── 冷戰／博弈 ──→ 人口（難民與資本）
                          │                        │
                          ↓                        ↓
                    心理（信心）←── 資訊（報刊・匯率）←── 經濟

    正向迴路（加速）：縫隙→轉口→財富→制度升級→更可信的門戶
    負向迴路（抑制）：政治收縮→信心流失→資本與人遷出→門戶折舊
    移植迴路（香港特有）：帝國表格→華人網絡填縫→變異（工業化・廉政）→再輸出
```

**偵探的訣竅**：先問「大國的表格這次寫了什麼」（割讓、租借、禁運、聲明、明文），再問「誰的網絡填了縫隙」（洋行、難民、資本、世代）——案件的因果鏈就浮現了。

### 一、古代：海洋節點與帝國邊陲（前214–1757）

- 約前 4000–前 214：百越海洋先民——滘西洲、東灣仔、大灣文化；採珠與鹽業。［[-0214-秦置南海郡與百越海洋先民.md](-0214-秦置南海郡與百越海洋先民.md)］
- 前 214：秦平嶺南置南海郡——香港入版圖；漢代李鄭屋墓、唐代屯門鎮——海上絲路常設節點。［[-0214-秦置南海郡與百越海洋先民.md](-0214-秦置南海郡與百越海洋先民.md)］
- 1277–1279：宋末二王駐蹕九龍（宋王臺）→ 崖山滅國——帝國末日把小港灣寫進史冊。［[1279-宋末二王與九龍.md](1279-宋末二王與九龍.md)］
- 1513：葡萄牙人歐維士抵屯門——歐人首次登陸中國；1521 屯門海戰。［[1513-歐人東來與屯門海戰.md](1513-歐人東來與屯門海戰.md)］
- 1757：一口通商——廣州十三行、白銀漏損與鴉片走私的生成。［[1757-一口通商與廣州十三行.md](1757-一口通商與廣州十三行.md)］

### 二、殖民前史：鴉片與三次割讓（1839–1898）

- 1839：虎門銷煙、九龍之戰——鴉片戰爭第一槍在香港水域。［[1839-鴉片戰爭.md](1839-鴉片戰爭.md)］
- 1842：南京條約割讓香港島、開埠——自由港三決策（零關稅＋英式司法＋華人自由）。［[1842-香港開埠.md](1842-香港開埠.md)］
- 1860：北京條約割讓九龍——軍事邏輯補幾何邏輯；蘇伊士運河後的轉口黃金期。［[1860-割讓九龍.md](1860-割讓九龍.md)］
- 1895：興中會總部設港——革命境外基地（籌款、軍火、報刊、避難）。［[1895-革命基地香港.md](1895-革命基地香港.md)］
- 1898：展拓香港界址專條——租借新界 99 年；1899 新界六日戰。［[1898-新界租借九十九年.md](1898-新界租借九十九年.md)］

### 三、轉型：工運、戰火與難民（1925–1974）

- 1925–26：省港大罷工——16 個月癱瘓、香港左翼的源頭。［[1925-省港大罷工.md](1925-省港大罷工.md)］
- 1941.12.8–12.25：香港淪陷——18 日戰役、三年零八個月（歸鄉、軍票、憲兵）。［[1941-香港淪陷與三年零八個月.md](1941-香港淪陷與三年零八個月.md)］
- 1945：重光——夏愨軍政府、英國重佔的博弈確認；楊慕琦計畫流產。［[1945-重光與轉口港復甦.md](1945-重光與轉口港復甦.md)］
- 1949–51：冷戰邊境——承認新中國但封關；韓戰禁運殺死轉口港。［[1949-冷戰邊境與難民工業化.md](1949-冷戰邊境與難民工業化.md)］
- 1950s–60s：難民工業化——紡織塑膠成衣、徙置屋邨；石硤尾大火（1953）。
- 1967：六七暴動——文革外溢、炸彈浪潮；港英治理的升級轉折。［[1967-六七暴動.md](1967-六七暴動.md)］
- 1973–74：葛柏潛逃→廉政公署成立——從貪污之都到廉潔經濟體。［[1974-廉政公署.md](1974-廉政公署.md)］

### 四、過渡與特區：談判、回歸與明文時代（1984–）

- 1983：港元危機→聯繫匯率 7.8；1984.12 中英聯合聲明——一國兩制、50 年不變。［[1984-中英聯合聲明.md](1984-中英聯合聲明.md)］
- 1985–90：基本法起草；信心危機與第一波移民潮。
- 1997.7.1：回歸；亞洲金融風暴同年襲港、聯繫匯率保衛戰。［[1997-回歸與一國兩制.md](1997-回歸與一國兩制.md)］
- 2003：沙士＋七一大遊行（23 條擱置）→ 自由行與 CEPA——經濟融合的雙刃。
- 2012：反國教；2014.6 白皮書＋8.31 決定。
- 2014.9–12：雨傘運動——87 枚催淚彈、79 天佔領、雨傘世代。［[2014-雨傘運動.md](2014-雨傘運動.md)］
- 2019：反修例運動——百萬人、五大訴求、理大圍城、區選大勝。［[2019-反修例運動與國安法.md](2019-反修例運動與國安法.md)］
- 2020.6.30：港區國安法——明文時代開幕：選制改革、47 人案、BNO 移民潮、人口遷出。
- 2023–：北上消費與門戶重定位——「縫隙」的故事仍在續寫。

## 偵探的結案陳詞

兩千年的香港史，可以壓縮成三條因果鏈：

1. **門戶鏈**：屯門泊點 → 十三行 → 自由港 → 轉口港 → 訊息港——**位置是常數，網絡是變數，制度是轉換器**。
2. **表格鏈**：南京條約 → 北京條約 → 展拓專條 → 聯合聲明 → 國安法——**城市的命運由主權的表格決定，而表格由武力與談判的力學書寫**。
3. **填縫鏈**：華商網絡 → 革命者 → 難民與資本 → 傘後世代——**每一次帝國留出的縫隙，都被華人社會的網絡填滿並變異**。

三條鏈咬合在一起，就是本卷十九樁案件的全部真相：**香港不是自己選擇成為香港——但每一次，都是香港人把別人給的局勢打成自己的籌碼。**
