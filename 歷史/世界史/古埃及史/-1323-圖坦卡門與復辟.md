# -1323-圖坦卡門與復辟：少年法老、阿蒙祭司與記憶抹除的多因案件

## 案件摘要
圖坦卡門（約前1341–前1323，在位約前1332–前1323）是最有名的法老，也是最無為的法老：9歲登基、19歲早逝，政績幾乎是零，卻因小墓KV62未被盜掘、1922年被卡特完整發現而名垂千古。本案無單一兇手，真兇是阿肯那頓宗教革命的反噬、祭司與軍人的復辟交易、以及少年早死帶來的考古運氣三因咬合。

## 前因 -- 多因素的局勢
- **宗教**：阿肯那頓（約前1353–前1336）推行阿頓一神改革，關閉阿蒙神廟、沒收地產、遷都阿瑪納，得罪整個祭司集團。
- **政治**：阿瑪納末期王位混亂——斯門卡拉、娜芙蒂蒂（？）曇花一現，中央權威真空，地方與軍隊離心。
- **經濟**：神廟經濟停擺＋對外朝貢體系鬆弛（阿瑪納書信顯示迦南城邦求援無門），王室財政失血。
- **軍事**：大將霍朗赫布掌握實權，軍隊成為復辟的最大股東，要求恢復舊秩序以重啟敘利亞戰事。
- **地理**：阿瑪納孤立於中埃及沙漠，遷回孟菲斯—底比斯雙中心是恢復統治半徑的必然。
- **意識形態**：法老合法性繫於瑪阿特（maat，宇宙秩序），阿頓改革被宣傳為「混亂（isfet）」，復辟即恢復瑪阿特。

## 線索與推理 -- 因素咬合
### 線索1：改名即政變——從圖坦卡頓到圖坦卡門
登基原名圖坦卡頓（Tutankhaten，阿頓的活像），數年後改為圖坦卡門（Tutankhamun，阿蒙的活像），並迎娶安赫森娜蒙（原名安赫森帕頓）。改名不是家務事，是復辟宣言：
$$\text{祭司支持} \to \text{改名＋還都} \to \text{合法性回流} \to \text{神廟地產歸還}$$
「復辟石碑」（現藏開羅博物館）明載：神廟荒廢、神不應驗，少年法老重修一切——實為攝政阿伊與霍朗赫布借少年之手與阿蒙祭司簽約。

### 線索2：小墓為何沒被盜？——邊緣性的運氣
| 因素 | 說明 |
|------|------|
| 王墓規格小 | KV62原為大臣墓規格，繼任者阿伊沿用，来不及擴建 |
| 位置低窪 | 位於帝王谷谷底，後被拉美西斯六世（KV9）碎石掩埋，盜墓賊找不到入口 |
| 兩次小盜即封 | 古代曾兩度被盜，祭司官僚迅速重新封印，保留了95%以上隨葬品 |
| 早死紅利 | 在位僅約9年，無暇建大墓，反成保存條件 |

理論：考古學「保存偏差（preservation bias）」——最有名的法老恰恰是最不重要的法老，名氣是抽樣誤差的產物。

### 線索3：抹除記憶——Damnatio Memoriae 的宣傳戰
霍朗赫布與塞提一世的王表跳過阿肯那頓、斯門卡拉、圖坦卡門、阿伊四代，直接從阿蒙霍特普三世跳到霍朗赫布。圖坦卡門主持了復辟，卻仍被清算：
$$\text{復辟不徹底} \to \text{軍人政權需徹底切割阿瑪納} \to \text{連復辟者一併抹除}$$
這正是「記憶政治」：合法性不靠延續，而靠選擇性遺忘。

### 線索4：死因之謎——謀殺還是體弱？
木乃伊顯示左腿骨折未癒、瘧疾（鐮刀菌 DNA）、鐮刀型貧血家族病史、近親通婚（父母為兄妹）。CT 掃描否定早年「頭部受擊謀殺說」。推理：無需陰謀，近親繁殖＋感染＋骨折併發症足以致19歲少年於死。早死＋無子（兩具夭折胎兒葬於墓中）→ 第十八王朝絕嗣 → 軍人霍朗赫布奪權的結構條件。

## 破案時刻
- 約前1332：9歲圖坦卡頓登基，攝政為阿伊（Ay），監國為霍朗赫布。
- 約前1330：改名圖坦卡門，頒布復辟法令，遷廷回孟菲斯，恢復阿蒙祭祀。
- 約前1327：王后誕下兩死胎，第十八王朝血脈斷絕的前兆。
- 前1323（約數）：圖坦卡門猝死（一說狩獵墜車骨折感染），葬入KV62。
- 前1323–前1319：老臣阿伊繼位，娶寡后以續法統。
- 前1319–前1292：霍朗赫布登基，頒布大法令反腐，系統抹除阿瑪納諸王。
- 1922年11月4日：霍華德·卡特在卡納馮勳爵資助下發現KV62階梯，26日窺見「到處都是金子」。

## 後果 -- 改變了什麼
- **政治**：第十八王朝絕嗣，軍人王朝（霍朗赫布→拉美西斯一系）上台，埃及轉向軍事帝國主義。
- **宗教**：阿蒙祭司全面復權，神廟地產膨脹，為日後祭司架空王權埋下遠因。
- **世界**：KV62的5000件文物＋黃金面具成為古埃及的全球符號，1920年代掀起「圖坦熱」（裝飾藝術、時尚、詛咒傳說）。
- **學術**：帝王谷考古標準化，X光、DNA、CT 等科技埃及學由此發端。
- **教訓**：名氣≠功績——歷史記憶由「保存＋發現＋媒體」三環決定，而非當事人的作為。

## 因素影響筆記
1. 宗教革命得罪祭司 → 祭司＋軍人結盟 → 少年法老被推為復辟招牌。
2. 對外收縮＋財政失血 → 軍方不滿達到閾值 → 復辟成為軍隊重返敘利亞的前提。
3. 近親通婚 → 體弱＋無嗣 → 早死 → 王朝斷絕 → 軍人奪權合法化。
4. 小墓＋低窪＋後代碎石掩埋 → 逃過系統性盜掘 → 三千年後完整出土。
5. 記憶抹除 → 圖坦卡門被王表除名 → 反因無人盜掘（不知名即安全）→ 1922年以最完整之姿重返人間，弔詭閉環。
