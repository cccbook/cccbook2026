# -1177-海上民族與青銅崩潰：拉美西斯三世、系統崩解與埃及倖存的多因案件

## 案件摘要
約前1200–前1150年間，邁錫尼、赫梯、烏加里特等青銅時代宮殿國家一夕傾覆，唯獨埃及在拉美西斯三世（約前1186–前1155）手下於前1177年前後擊退「海上民族」，刻下梅迪內特哈布（Medinet Habu）凱旋浮雕。本案兇手不是一支艦隊，而是氣候乾旱、貿易斷鏈、宮殿體制僵化與移民潮共振的系統崩潰；埃及倖存亦非武功獨高，而是地理與體制的韌性差。

## 前因 -- 多因素的局勢
- **氣候**：地中海東部約前1250–前1100持續乾旱（孢粉＋同位素證據），糧食減產→饑荒→流民化，烏加里特信札直呼「糧船未至」。
- **經濟**：青銅體系依賴長鏈貿易（塞浦路斯銅＋阿富汗錫＋波羅的海琥珀），一環斷即全軍無兵器，宮殿再分配體制毫無彈性。
- **政治**：宮殿王權高度集中，官僚只會記帳不會救災；附庸趁機叛亂，中央兩線作戰。
- **軍事**：戰車貴族兵不適應海上民族的輕裝＋標槍＋長劍群戰，烏加里特、阿穆魯的戰車軍團被步兵海淹沒。
- **地理**：埃及有尼羅河糧倉＋西奈沙漠緩衝＋三角洲水網，海上民族只能從海陸兩路硬攻，無迂迴空間。
- **技術**：鐵器前夜——零星鐵器出現但未普及，青銅斷供的一方先死，埃及靠努比亞黃金換糧續命。

## 線索與推理 -- 因素咬合
### 線索1：梅迪內特哈布浮雕——埃及版的「最後一戰」宣傳
拉美西斯三世第八年（約前1177）銘文：「諸國一時俱滅——赫梯、科德（奇里乞亞）、迦底墀、烏加里特……無人能擋」。浮雕分海戰（三角洲）與陸戰（迦南扎希 Djahi）兩幕，埃及以岸上弓箭＋接舷戰大勝：
$$\text{三角洲水網} \to \text{敵艦機動受限} \to \text{埃及弓箭集火} \to \ تخصص{殲滅戰}$$
但銘文誇大：部分「海上民族」（佩萊塞特 Peleset，即後之非利士人）實被安置為迦南雇傭邊防軍——勝利的另一面是招安。理論：帝國收縮（imperial retrenchment）——以空間換時間。

### 線索2：烏加里特的最後一封信——系統論的屍檢報告
烏加里特王宮末代文書（RS 94.2530 等）：糧食告急、艦隊調往南方、敵人已在城外，而王還在等赫梯宗主的回信。城市焚毀層與未發出的信同坑出土，堪稱青銅崩潰的龐貝時刻：
$$\text{乾旱} \to \text{饑荒} \to \text{附庸叛亂} \to \text{貿易斷鏈} \to \text{宮殿無稅} \to \text{軍隊解體} \to \text{移民補刀}$$
學術理論：一般系統崩潰論（Joseph Tainter 複雜性邊際報酬遞減＋Eric Cline《1177 B.C.》多因共振）——無單一病因，死因是併發症。

關鍵推理：舍爾登人早在麥倫普塔五年（約前1208）入侵失敗後即被埃及收編為禁衛軍——「敵人」與「雇傭兵」是同一批人的兩副面孔。這是雇傭兵制度的濫觴。

### 線索4：埃及為何倖存？——韌性的三根樑柱
```
# 倖存條件 pseudocode
if 粮倉(尼羅河氾濫尚穩) and 緩衝(沙漠＋海) and 中央(拉美西斯三世集權):
    埃及 = 慘勝 + 收縮
else:
    埃及 = 第二個烏加里特
```
但慘勝代價巨大：迦南帝國丟失大半、神廟地產膨脹（哈里斯大紙草載阿蒙神廟占全國土地近1/3）、物價飛漲。倖存只是把崩潰推遲了五十年——第二十王朝末即陷入祭司架空、工匠罷工、物價革命。

## 破案時刻
- 約前1213–前1208：麥倫普塔擊退利比亞＋舍爾登聯軍，「以色列石碑」紀功。
- 約前1190–前1180：烏加里特、哈圖沙、邁錫尼宮殿相繼焚毀，赫梯帝國滅亡。
- 約前1177（拉美西斯三世八年，約數）：扎希陸戰＋三角洲海戰，擊退海上民族主力。
- 約前1175–前1170：佩萊塞特人定居迦南海岸（非利士人興起），埃及退守西奈—迦南要塞線。
- 前1155：拉美西斯三世遇刺（後宮陰謀，木乃伊頸部刀痕＋司法紙草佐證），埃及盛世終結。
- 前1070：新王國崩解，第三中間期開始——遲到的崩潰。

## 後果 -- 改變了什麼
- **政治**：近東從宮殿帝國時代進入城邦—部族時代（以色列、腓尼基城邦、亞蘭諸國填補真空）。
- **軍事**：戰車貴族沒落，步兵＋海軍＋雇傭兵崛起，鐵器時代軍事革命的前夜。
- **宗教**：埃及神廟地產畸膨，阿蒙祭司坐大，為第三中間期祭司王分治鋪路。
- **世界**：希臘進入黑暗時代（前1100–前800），線性文字B失傳；腓尼基字母乘虛而起，文明載體換代。
- **教訓**：複雜系統死於併發症而非單一外傷；地理韌性能救命，但救不了體制。

## 因素影響筆記
1. 長期乾旱 → 糧食危機 → 流民潮 → 海上民族南下（推力）。
2. 長鏈貿易斷裂 → 青銅斷供 → 宮殿軍隊癱瘓 → 堅城不堪一擊。
3. 宮殿體制僵化 → 無法分權救災 → 小亂變大崩（脆弱性放大器）。
4. 埃及尼羅河糧倉＋三角洲地形 → 以逸待勞殲滅戰 → 倖存但帝國收縮。
5. 招安海上民族為雇傭兵 → 短期止血 → 長期雇傭兵傳統 → 利比亞—努比亞—希臘雇傭兵輪流坐莊的千年伏筆。
