# 前2055年-曼圖霍特普再統一：底比斯、中王國與新集權術的多因案件

## 案件摘要
第一中間期分裂約一個半世紀後，上埃及底比斯（Thebes）的曼圖霍特普二世（Mentuhotep II，約前2061–前2010年在位）滅掉北方赫拉克雷奧波利斯，约前2055 年再統一埃及，中王國開幕。勝利不是一仗打贏的，而是底比斯糧倉、奧西里斯新信仰、地方制衡術三因咬合：他用古王國的屍體做教材，發明了更耐旱、更彈性的國家。

## 前因 -- 多因素的局勢
- **地理**：底比斯居上埃及中段，控尼羅河峽谷段與東部沙漠—紅海商路、西部綠洲糧道，進可攻退可守；北方赫拉克雷奧波利斯困於三角洲門戶，外有亞洲移民壓力。
- **氣候**：4.2ka 事件尾聲，尼羅河水位逐步恢復；誰先恢復徵收—賑濟循環，誰就贏得「瑪阿特恢復者」名號。
- **經濟**：底比斯十一王朝數代經營（因提夫一世至三世）積累糧倉與努比亞黃金、貿易稅；北方連年內耗，稅基疲敝。
- **政治**：南北對峙約百年，北方十王朝宮廷內鬥；底比斯以「上埃及聯盟盟主」整合諸諾姆長，統一戰線大於赫拉克雷奧波利斯的孤家寡人。
- **宗教**：奧西里斯（Osiris）信仰普及＋底比斯守護神蒙圖（Montu，戰神）加持，出師有神名；統一後尊阿蒙（Amun）為主神，收編全國祭司。
- **軍事**：底比斯發展出努比亞弓箭雇傭兵＋上埃及艦隊，機動性勝過北方民兵；代爾埃爾巴哈里（Deir el-Bahari）六十武士墓證明常備軍存在。
- **人物**：曼圖霍特普二世——即位名 Nebhepetre，在位約 51 年，前 39 年統一戰爭，後 12 年制度重建，耐心即戰略。

## 線索與推理 -- 因素咬合

### 線索1：五十年戰爭——持久戰拖垮北方
都靈王表與哈特努布（Hatnub）採石銘文顯示：曼圖霍特普二世第 14、25、39 年仍有戰事記載。戰略學解讀：底比斯採「農村包圍城市」——先併吞阿拜多斯以南諸諾姆，斷北方糧道，再決戰赫拉克雷奧波利斯。北方以一城之稅養全國之戰，財政先崩。

$$\text{底比斯糧倉} + \text{努比亞黃金} \to \text{持久戰能力} > \text{北方} \to \text{封鎖 → 決戰 → 統一}$$

| 階段 | 年次（在位年） | 動作 |
|------|---------------|------|
| 積累 | 1–14 年 | 併吞上埃及諸諾姆，取阿拜多斯聖城 |
| 相持 | 14–30 年 | 與赫拉克雷奧波利斯拉鋸，兼併中埃及 |
| 決戰 | 約 39 年（前2055） | 攻陷赫拉克雷奧波利斯，改元「統一兩國者」 |

### 線索2：新集權術——不再相信諾姆長
古王國教訓是世襲掏空中央，曼圖霍特普的解法是「分而治之＋中央巡按」：保留諾姆制但拆大諾姆、派王室總督（vizier 上下埃及分設前身）、以「王室清查」重奪稅權；書吏直接向底比斯匯報。政治學稱「間接統治 2.0」：承認地方，但錢袋歸中央。

```pseudocode
for 每個大諾姆:
    拆分(大諾姆 → 小轄區, 防止坐大)
    任命(忠誠派諾姆長, 任期制 + 清查考核)
    派駐(王室書吏, 直報底比斯糧倉)
```

### 線索3：神學統一戰線——蒙圖＋阿蒙＋奧西里斯
軍事靠蒙圖（戰神），合法性靠奧西里斯（死而復國之王，隱喻埃及復活），長遠靠阿蒙（後升為帝國主神）。代爾埃爾巴哈里祭葬廟（階梯＋柱廊＋山體鑿墓）融合金字塔與岩墓，既告慰上埃及傳統，又向北方宣告新美學。宗教社會學：三神分工覆蓋軍隊、民眾、祭司三個受眾。

$$\text{蒙圖（軍隊認同）} + \text{奧西里斯（民眾來世）} + \text{阿蒙（祭司同盟）} \to \text{統一合法性全覆蓋}$$

### 線索4：文學治國——《薩努赫》之前的警告書
統一後中王國文學（《對兒子美里卡拉的教諭》《能言善辯的農夫》）實為政治教材：教新王「善待諾姆長、慎用武力、勤於聽訟」。話語即制度：中王國用文學把古王國崩潰的教訓寫成官僚手冊，這是埃及史上第一次「以史為鑑」治國。

## 破案時刻
- 約前2119年：底比斯因提夫三世自稱「上下埃及之王」，南北正統之爭公開化。
- 約前2061年：曼圖霍特普二世即位，繼承上埃及聯盟與努比亞雇傭兵。
- 約前2055年（在位第 39 年）：攻陷赫拉克雷奧波利斯，再統一完成，中王國開始（年代為學界約數，今從 Shaw《牛津古埃及史》說）。
- 約前2055–前2010年：遷都底比斯、建代爾埃爾巴哈里廟、重開努比亞商路，第十二王朝阿蒙涅姆赫特一世遷都利什特（Itjtawy）承其制度。
- 後世：第十二王朝塞索斯特里斯三世的中央集權，皆是曼圖霍特普 2.0 的升級版。

## 後果 -- 改變了什麼
- **政治**：中王國建立——強中央＋受控地方的新平衡，地方豪強墓誌仍存但稅權上收。
- **經濟**：全國徵收—賑濟循環重建，努比亞黃金與紅海—龐特貿易重開，王室糧倉再滿。
- **宗教**：阿蒙崛起為主神（底比斯祭司集團登上歷史舞台，為新王國阿蒙帝國鋪路）；奧西里斯信仰全民化。
- **技術**：岩鑿墓＋階梯廟建築新範式（代爾埃爾巴哈里→哈特謝普蘇特廟的譜系）；文學行政（教諭文學）成熟。
- **教訓**：統一不是回到古王國，而是「記住崩潰、重寫代碼」——最好的復辟是改革。

## 因素影響筆記
1. 氣候恢復＋底比斯糧倉 → 持久戰資本 → 拖垮北方財政。
2. 上埃及聯盟＋努比亞雇傭兵 → 軍事優勢 → 39 年三階段統一戰爭獲勝。
3. 古王國世襲教訓 → 拆分諾姆＋王室清查 → 新集權術防止重蹈覆轍。
4. 蒙圖＋奧西里斯＋阿蒙 → 軍隊、民眾、祭司全覆蓋 → 統一合法性速成。
5. 崩潰文學 → 官僚教材 → 中王國「以史治國」傳統 → 第十二王朝古典時代。
