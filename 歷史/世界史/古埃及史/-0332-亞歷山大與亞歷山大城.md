# 公元前332年-亞歷山大與亞歷山大城：神諭、選址與港口城市網絡的多因案件

## 案件摘要
公元前332年冬，馬其頓王亞歷山大大帝（Alexander III，約公元前356–323年）兵不血刃入主埃及，親赴錫瓦（Siwa）綠洲求阿蒙神諭，隨即在尼羅河三角洲西緣奠基亞歷山大城。本案兇手不是一人一劍，而是宗教加冕、地理選址與城市規劃三重佈局的咬合：一座為帝國海權而生的城市，如何取代孟菲斯與推羅，成為地中海世界的心臟長達千年？

## 前因 -- 多因素的局勢
- **地理**：埃及舊都孟菲斯位尼羅河谷頂端，距海遙遠；三角洲東部 Pelusium 沙洲淤淺，唯有西部拉科提斯（Rhakotis）漁村外有法羅斯島可作天然防波堤。
- **經濟**：推羅圍城（公元前332年）後，東地中海商路需新樞紐；埃及穀物亟需深水港直運希臘。
- **政治**：波斯總督馬扎塞斯（Mazaces）獻城投降，埃及祭司痛恨波斯稅政，歡迎解放者；亞歷山大需埃及糧倉支持東征。
- **宗教**：錫瓦阿蒙神諭宣布亞歷山大為「阿蒙之子」，等同埃及法老神統；孟菲斯阿匹斯（Apis）祭祀加冕完成雙重合法性。
- **軍事**：埃及無險可守，亞歷山大留總督與駐軍，並以海港—艦隊—燈塔體系鎖住制海權。
- **技術**：建築師德諾克拉特斯（Dinocrates）以希波丹姆式棋盤規劃設計七體育場（stade）長街，堤道（Heptastadion）連接本島與法羅斯島。
- **外交**：亞歷山大以「希臘解放者＋埃及法老」雙面孔示人，安撫希臘傭兵、馬其頓老兵與埃及祭司三方。
- **資訊**：普魯塔克、阿里安與斯特拉波各記建城夢（荷馬顯靈指點法羅斯）與大麥粉劃線築城，神話即政治宣傳。

## 線索與推理 -- 因素咬合
### 線索1：為何選在拉科提斯？一張港口比較表
斯特拉波稱此地兼得海港與湖港之利：北有地中海深水，南有馬雷奧蒂斯湖（Lake Mareotis）通尼羅河。

| 候選地 | 優點 | 缺點 |
|--------|------|------|
| 孟菲斯 | 舊都、祭司中心 | 內陸，無海港 |
| Pelusium | 近西奈要道 | 泥沙淤淺，波斯易攻 |
| 拉科提斯／法羅斯 | 島鏈避風、石灰岩地基、湖海雙港 | 需新建、淡水靠運河 |

$$\text{法羅斯島防波} + \text{湖港轉運} + \text{石灰岩地基} \to \text{地中海罕見深水良港} \to \text{千年不墜}$$

適用「港口城市網絡（port-city network）」理論：亞歷山大城卡住穀物—香料—知識三流交匯點。

### 線索2：錫瓦神諭——沙漠三百公里為何非去不可？
亞歷山大冒冬雨橫越沙漠赴錫瓦，祭司以希臘語稱其為「宙斯—阿蒙之子」。此舉一石三鳥：

$$\text{神諭認證} \to \text{法老合法性} \to \text{免於埃及叛亂} \to \text{東征無後顧之憂}$$

同時向希臘世界宣告自己超越凡人，為日後要求神化 proskynesis 鋪路。這是典型的「宗教資本轉換為政治資本」。

### 線索3：七體育場長街與 Heptastadion——城市即機器
全城以東西大道（Canopic Way）為脊，寬逾30公尺、長約7 stade（約1.3公里一說；全城逾5公里），南北棋盤分割希臘區、埃及區、猶太區與王宮區。七斯塔德堤道將法羅斯島連成本土，創造東西雙港（大港＋Eunostos 港）。

```pseudocode
城市 = 王宮區(布魯奇姆) + 穆塞昂/圖書館 + 劇場/體育館 + 埃及神廟(Serapeum)
港口 = 大港(軍商兩用) + 外港 + 馬雷奧蒂斯湖港(尼羅河駁船)
防禦 = 城牆 + 法羅斯島 + 堤道閘門
# 輸出：可養活百萬人的地中海最大都市
```

### 線索4：不流血入主——波斯為何棄守埃及？
公元前334年伊蘇斯之戰後，波斯海軍瓦解，埃及總督孤立無援。埃及人視馬其頓為解放者而非征服者，支點在賦稅：

$$\text{波斯重稅＋神廟掠奪記憶} \to \text{祭司倒戈} \to \text{總督投降} \to \text{零傷亡佔領}$$

## 破案時刻
- **公元前334年**：伊蘇斯之戰，波斯主力潰敗；推羅圍城開始。
- **公元前332年夏—秋**：推羅陷落，加薩陷落；埃及門戶洞開。
- **公元前332年冬**：亞歷山大入孟菲斯，獻祭阿匹斯，加冕為法老。
- **公元前332年冬—331年初**：赴錫瓦綠洲求神諭，獲「阿蒙之子」稱號。
- **公元前331年4月（傳統系年）**：於拉科提斯奠基亞歷山大城，大麥粉劃線傳說即此時。
- **公元前331年夏**：離埃東征，此後再未返回；建城工程交克里奧米尼斯續辦。

## 後果 -- 改變了什麼
- **政治**：埃及中心由孟菲斯北移至亞歷山大城，托勒密王朝定都於此，羅馬、拜占庭皆沿用，凡千年。
- **經濟**：大港＋湖港體系使埃及穀物直供羅馬（帝國時期年運約2000萬 modii），香料之路西端鎖定於此。
- **文化**：棋盤城市成為希臘化建城範本（安條克、塞琉西亞皆仿效）；多族群分區共存預演 cosmopolis。
- **世界**：亞歷山大城證明「人造樞紐可重寫地理」——選址即國運。
- **教訓**：合法性比軍隊便宜：一次神諭＋一次祭祀，換來埃及六年無叛亂。

## 因素影響筆記
1. 地理良港（法羅斯島鏈） → 選址拉科提斯 → 千年海權基地。
2. 宗教加冕（錫瓦＋阿匹斯） → 法老合法性 → 不流血統治。
3. 經濟動機（穀物＋商路） → 湖海雙港設計 → 地中海貿易心臟。
4. 技術規劃（希波丹姆棋盤＋堤道） → 軍商分區＋雙港 → 百萬人口大城。
5. 外交雙面（希臘解放者／埃及法老） → 三方精英各取所需 → 托勒密體制藍本。
