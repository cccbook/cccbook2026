# 公元前518年-大流士運河：帝國治理、法典與蘇伊士前身的多因案件

## 案件摘要
波斯阿契美尼德王朝的大流士一世（Darius I，約公元前522–486年在位）在征服埃及（公元前525年由岡比西斯完成）後，完成尼科二世未竟的尼羅河—紅海運河，並立碑誇耀「我令船從埃及直航波斯」。本案無單一英雄：水利工程、帝國行政與法律整合三力咬合，使一條運河成為世界第一條洲際運河，也是波斯治理埃及的縮影。

## 前因 -- 多因素的局勢
- **地理**：埃及為波斯第二十七王朝（第一埃及總督轄區），尼羅河三角洲經苦湖通紅海的窪地仍在，舊渠淤塞待疏。
- **經濟**：波斯需打通埃及穀物—紅海—波斯灣—印度航線，對接大流士同時開拓的印度洋探險（斯基拉克斯航行）。
- **政治**：岡比西斯征服手段殘酷，埃及祭司懷恨；大流士改行懷柔，需一項惠及神廟與商人的政績工程。
- **宗教**：埃及神廟經濟占耕地約三分之一，大流士自稱「埃及法老式統治者」，修廟、編法典以換取祭司合作。
- **技術**：波斯動員埃及勞役與工程師，疏浚布巴斯提斯（Bubastis）—派吞（Pithom）—苦湖—蘇伊士段，全長約200公里。
- **軍事**：運河可速調艦隊鎮壓埃及叛亂，並將地中海艦隊與紅海艦隊連結，具戰略機動價值。
- **外交**：運河碑用古波斯文、埃蘭文、巴比倫文與埃及象形文字四語書寫，向全帝國宣告統治合法性。
- **資訊**：運河石碑（今蘇伊士一帶出土多塊）與希羅多德卷二158節互證，是少數有考古實物的波斯運河記載。

## 線索與推理 -- 因素咬合
### 線索1：運河到底多長？碑文與地理的對質
大流士碑文稱「從尼羅河開渠至紅海」，希羅多德稱需四天航程、寬可容雙槳船。現代測量布巴斯提斯—紅海古河道約180–200公里，苦湖為天然蓄水段。

$$\text{尼羅河水位} \to \text{季節性通航} \to \text{苦湖調節} \to \text{紅海潮汐銜接} \to \text{洲際航運}$$

| 河段 | 功能 | 證據 |
|------|------|------|
| 布巴斯提斯—派吞 | 尼羅河引水段 | 大流士碑、托勒密地理志 |
| 苦湖 | 天然湖泊蓄水 | 地質鑽探含尼羅河淤泥 |
| 苦湖—紅海 | 人工渠＋舊河道 | 蘇伊士出土碑文殘塊 |

### 線索2：帝國知識政治——為何用四種文字立碑？
碑文並列帝國三官方語言加埃及文，適用「帝國知識政治（imperial knowledge politics）」理論：文字即統治技術。

$$\text{多語碑文} \to \text{多族群可讀} \to \text{法老＋萬王之王雙重正當性} \to \text{埃及祭司默許統治}$$

這與後來羅塞塔石碑的三語法令同構：征服者都必須學會用被征服者的神聖文字說話。

### 線索3：法典與運河——硬體與軟體的配套
大流士命編纂《埃及法典》（傳集埃及智者成書，以通俗體文字記錄），同時改革賦稅與度量衡。運河是硬體，法典是軟體：

```pseudocode
function 統治埃及():
    修神廟 + 編法典  # 收買祭司與官僚
    開運河 + 統一度量衡  # 降低交易成本
    設總督 + 駐軍  # 壟斷暴力
    return 穀物與稅收穩定流入波斯波利斯
```

### 線索4：蘇伊士前身為何屢開屢廢？
從尼科到大流士到托勒密再到圖拉真，此渠反覆淤塞。關鍵在尼羅河泥沙與紅海鹽度差，缺乏船閘技術，只能季節性使用。

$$\text{泥沙淤積} \to \text{維護成本高昂} \to \text{中央衰弱即廢} \to \text{強權復起再開} \to \text{運河即帝國晴雨表}$$

## 破案時刻
- **公元前525年**：岡比西斯征服埃及，建立第二十七王朝。
- **約公元前522–518年**：大流士平定帝國叛亂，派希臘人斯基拉克斯探索印度洋—紅海航線。
- **約公元前518–515年**：疏浚尼羅河—紅海運河完工，豎立花崗岩紀念碑群。
- **約公元前516年**：大流士巡視埃及，修復神廟，編纂埃及法典。
- **希羅多德追記（約公元前450年）**：親見運河仍在使用，留下四日航程的記錄。

## 後果 -- 改變了什麼
- **政治**：埃及成為波斯最富總督區，年貢穀物與白銀支撐波斯戰爭機器；埃及祭司獲得自治，換取不叛。
- **經濟**：埃及—波斯灣直航開通，印度商品經紅海入地中海，亞歷山大城日後的香料貿易預演於此。
- **文化**：四語碑開創多語統治文書傳統，影響托勒密雙語法令與羅馬三語碑。
- **世界**：人類第一條連接地中海水系與印度洋水系的人工水道，比蘇伊士運河（1869年）早約2380年。
- **教訓**：沒有制度配套的運河只是溝渠；大流士以法典養運河，以運河養帝國。

## 因素影響筆記
1. 地理窪地＋舊渠基礎 → 工程成本可負擔 → 波斯選擇續建而非新建。
2. 經濟動機（印度洋貿易） → 運河與斯基拉克斯探險配套 → 紅海航線成形。
3. 政治懷柔（修廟＋法典） → 祭司合作 → 運河勞役與稅收得以徵發。
4. 技術侷限（無船閘、泥沙） → 季節性通航 → 運河命運繫於中央維護能力。
5. 資訊宣傳（四語碑） → 帝國正當性展示 → 後世王朝競相仿效多語政治。
