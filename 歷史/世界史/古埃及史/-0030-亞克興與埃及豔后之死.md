# 公元前30年-亞克興與埃及豔后之死：同盟、誤算與帝國吞併的多因案件

## 案件摘要
克麗奧佩脫拉七世（Cleopatra VII，約公元前51–30年在位）先後結盟凱撒與安東尼，圖以羅馬內戰為槓桿保住托勒密埃及；卻在公元前31年亞克興（Actium）海戰慘敗，翌年與安東尼相繼自殺，屋大維（後之奧古斯都）將埃及併為羅馬行省。本案沒有單一兇手：王朝財政、同盟賽局與羅馬內戰三力絞合，法老三千年的文明就此落幕。

## 前因 -- 多因素的局勢
- **地理**：埃及為東地中海糧倉，尼羅河豐歉牽動羅馬糧價；亞歷山大城雙港與沙漠要塞使強攻成本高昂，羅馬更願扶植傀儡。
- **經濟**：托勒密末期王室壟斷紙草、香料與銀行，克麗奧佩脫拉以重稅與貨幣貶值維持艦隊，民怨與祭司離心日增。
- **政治**：托勒密王朝兄妹共治、弒親成習，克麗奧佩脫拉先後除去弟夫托勒密十三世、十四世，合法性全繫於羅馬強人背書。
- **宗教**：女王自塑為伊西斯化身（Nea Isis），與安東尼以狄俄倪索斯—俄西里斯配對遊行，爭取埃及祭司與東方希臘城邦認同。
- **技術**：安東尼—埃及聯合艦隊船大樓高（含十列槳巨艦），機動卻遜於屋大維部將阿格里帕（Agrippa）的輕快利布尼亞戰船＋鉤艦戰術。
- **軍事**：安東尼帕提亞遠征（公元前36年）慘敗失血，軍團老兵思歸；屋大維掌握義大利本土徵兵與補給線。
- **外交**：前32年安東尼「亞歷山大獻禮」分封東方予克麗奧佩脫拉子女，屋大維宣讀其遺囑，煽動羅馬反東方情緒，元老院對克麗奧佩脫拉宣戰。
- **資訊**：屋大維的宣傳機器（詩人維吉爾、賀拉斯）將戰爭塑為「羅馬vs東方妖后」，掩蓋其為羅馬內戰的本質。

## 線索與推理 -- 因素咬合
### 線索1：亞克興海戰——大船為何輸給小船？
公元前31年9月2日，安東尼約500艘戰船困於安布拉基亞灣，疫病與叛逃不斷；阿格里帕以輕船切斷補給，誘其出灣決戰。克麗奧佩脫拉分艦突圍揚帆而去，安東尼棄艦隊追隨，軍心崩潰。

$$\text{巨艦笨重} + \text{補給斷絕} + \text{疫病叛逃} \to \text{突圍變潰逃} \to \text{陸軍不戰而降}$$

| 雙方 | 兵力 | 戰術 |
|------|------|------|
| 安東尼—埃及 | 約500艦、19 legions | 巨艦正面衝撞，女王艦隊殿後載財寶 |
| 屋大維—阿格里帕 | 約400艦、16 legions | 輕艦迂迴、鉤斷槳櫓、斷糧圍困 |

適用「軍事革命不對稱」理論：機動＋後勤勝過噸位。

### 線索2：凱撒—安東尼同盟——理性豪賭還是自殺賽局？
克麗奧佩脫拉先以凱撒之子凱撒里昂（Caesarion）為繼承人，再與安東尼生三子，押注「東方帝國共治」。以「依附與同盟賽局」分析：

```pseudocode
埃及.選項 = [中立(必被勝者吞併), 押安東尼(勝則共治東方)]
# 中立期望值 < 豪賭期望值，故理性選擇豪賭
if 安東尼勝: 埃及 = 東方共主
else: 埃及 = 行省  # 歷史執行了此分支
```

豪賭理性但方差極大，一旦押錯即亡國。

### 線索3：屋大維的宣傳戰——妖后是如何煉成的？
屋大維避免對安東尼（羅馬公民）宣戰，而對克麗奧佩脫拉宣戰，將內戰包裝為文明衝突：

$$\text{遺囑曝光} \to \text{獻禮醜聞} \to \text{詩人動員} \to \text{義大利全民效忠宣誓} \to \text{師出有名}$$

這是古代「資訊戰（information warfare）」的典範：誰定義敵人，誰就贏得動員。

### 線索4：豔后之死——蛇咬還是政治自殺？
普魯塔克稱其以無花果籃藏眼鏡蛇自盡， modern 醫學多疑蛇毒不可控，更可能是服毒或針刺。死法之謎不掩其政治計算：

$$\text{被俘遊街} \to \text{王朝尊嚴掃地} \to \text{主動赴死} \to \text{保住子女活命＋伊西斯神格}$$

屋大維果然赦免其子女（後分養於屋大維婭），埃及祭司則為其舉行法老式葬禮。

## 破案時刻
- **公元前51年**：克麗奧佩脫拉七世與弟共治；公元前48年凱撒入埃及，亞歷山大港之戰，托勒密十三世溺死。
- **公元前44–41年**：凱撒遇刺；克麗奧佩脫拉會安東尼於塔爾蘇斯，結盟。
- **公元前36年**：安東尼遠征帕提亞慘敗；公元前34年亞歷山大獻禮，觸怒羅馬。
- **公元前32年**：羅馬對克麗奧佩脫拉宣戰；安東尼部將多叛逃屋大維。
- **公元前31年9月2日**：亞克興海戰，安東尼—埃及艦隊覆滅。
- **公元前30年8月**：安東尼自刎（約8月1日）；克麗奧佩脫拉自殺（約8月10–12日）；屋大維處死凱撒里昂，埃及改為羅馬行省。

## 後果 -- 改變了什麼
- **政治**：托勒密王朝滅亡，法老制度終結（共約三千年）；埃及成為羅馬皇帝直轄糧倉，總督皆騎士階級以防割據。
- **經濟**：埃及穀物直供羅馬城，香料稅充實國庫，支撐奧古斯都和平的麵包供給。
- **文化**：亞歷山大圖書館漸衰，埃及宗教（伊西斯、塞拉皮斯）反向輸入羅馬，成為帝國普世信仰之一。
- **世界**：地中海成為羅馬內湖（Mare Nostrum）；亞克興勝利日成為奧古斯都紀元神話起點。
- **教訓**：小國在大國內戰中選邊，勝則續命、敗則滅國；中立雖難，卻是期望損失最小的策略。

## 因素影響筆記
1. 經濟糧倉地位 → 羅馬必欲吞併 → 埃及無真正中立空間。
2. 政治王朝內鬥 → 合法性繫於羅馬強人 → 被迫捲入內戰選邊。
3. 軍事巨艦＋補給斷鏈 → 亞克興潰敗 → 陸軍瓦解，亞歷山大不守。
4. 外交獻禮＋遺囑戰 → 屋大維動員成功 → 戰爭合法性一面倒。
5. 資訊妖后敘事 → 內戰包裝為文明戰爭 → 屋大維獨攬勝利果實，法老文明落幕。
