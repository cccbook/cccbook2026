# 0850-火藥的誕生：從煉丹爐到攻城炮的八百年

## 案件摘要

西元 850 年前後，唐代煉丹家在追求「長生不老藥」的實驗中，留下了史上最早的火藥配方警告（火藥易燃、燒手、焚屋）；1044 年《武經總要》記載了三種軍用配方。此後八百年，火藥沿「火攻 → 爆炸 → 投射」的路線演化：火器（火箭、火炮）、鐵火炮（震天雷）、1259 年突火槍（最早管形火器）；十三世紀經蒙古西征傳入伊斯蘭世界與歐洲——1453 年君士坦丁堡的巨炮（[1453-君士坦丁堡陷落.md](1453-君士坦丁堡陷落.md)）與 1503 年切里尼亞奧拉的火繩槍（[1503-切里尼亞奧拉與火繩槍.md](1503-切里尼亞奧拉與火繩槍.md)），都是這樁案件的遠期後果。

## 前因 -- 為什麼會有這個案子

- 唐代煉丹術以「長生不老」為目標，硝石（氧化劑）＋硫＋炭的組合在實驗中反覆起火。
- 中國的圍城戰傳統（城牆密集）提供了「軍事需求」：火攻、爆炸、投射都有戰場出口。
- 硝石礦（硝土）在中國廣泛分布——量產的物質條件。

## 線索與推理 -- 化學與物理

### 線索一：火藥的化學

黑火藥的理想配比約 **硝石 75%、硫 10%、炭 15%**：

$$2KNO_3 + S + 3C \rightarrow K_2S + N_2 \uparrow + 3CO_2 \uparrow$$

硝石是氧化劑（自帶氧），使燃燒**不需要空氣**——這是火藥能在封閉炮膛內做功的根本。燃燒瞬間產生大量氣體，壓力做功推動彈丸。

### 線索二：黑火藥的物理極限

黑火藥是**爆燃**（deflagration，亞音速燃燒波），氣體膨脹速度有限，因此彈丸初速上限約 400–600 m/s：

$$v_{\text{彈丸}} < v_{\text{氣體膨脹}}$$

這條極限定義了黑火藥時代的一切：火炮射程有限、彈道彎曲（直瞄困難）、精度差——**「面殺傷＋攻城」成為黑火藥時代的主戰法，直瞄精確射擊要等無煙火藥（1884，硝化纖維）**。這條線索直通馬克沁機槍（[1884-馬克沁機槍.md](1884-馬克沁機槍.md)）：無煙火藥的高燃速＋無煙，才使「自動武器」在技術上可能。

### 線索三：演化的三階段

| 階段 | 年代（約） | 武器 | 戰法 |
|------|------------|------|------|
| 火攻 | 900s | 火箭、火油罐 | 延燒、恐慌 |
| 爆炸 | 1200s | 鐵火炮（震天雷） | 攻城破壞、心理戰 |
| 投射 | 1259–1320s | 突火槍→歐洲火炮 | 攻城火力、野戰火力 |

**「火→爆→射」的順序不是偶然**：它反映的是「把化學能轉為殺傷」的工程難度遞增——火最容易、爆炸次之、「受控的投射」最難。1259 年的突火槍（竹管＋彈丸）是「管形投射」概念的起點——**槍械的祖先**。

### 線索四：擴散的傳播律

火藥沒有「祕密材料」（硝石隨處可製、配方可用簡單比例描述），因此擴散速度極快：十三世紀蒙古西征（攻城時徵用中原工匠，[1206-蒙古軍事體系.md](1206-蒙古軍事體系.md)）把火藥帶到中東與歐洲；1320 年代歐洲已有火炮記載。**技術擴散的速度 ∝ 配方的「可描述性」**——這與戰車（[-1650-喜克索斯與戰車帝國.md](-1650-喜克索斯與戰車帝國.md) 線索二）同一規律。

## 破案時刻

- 1044《武經總要》記載三種軍用配方——火藥正式軍事化。
- 1232 開封保衛戰：金軍以「震天雷」與「飛火槍」對抗蒙古——黑火藥的實戰驗證。
- 1259 突火槍：管形火器的誕生。
- 1320s 歐洲火炮登場；1453 君士坦丁堡：巨炮攻城革命——火藥改寫世界史。

## 後果 -- 改變了什麼

- 攻城革命與棱堡（[1453-君士坦丁堡陷落.md](1453-君士坦丁堡陷落.md)）：城牆的設計假設失效，戰爭變成工程競賽。
- 火藥帝國（鄂圖曼、薩法維、蒙兀兒）：炮兵＋職業軍隊統治陸權。
- 騎士時代的終結：火器的穿透力終結「以厚度對抗」（[1503-切里尼亞奧拉與火繩槍.md](1503-切里尼亞奧拉與火繩槍.md) 線索一）。
- 化學與戰爭的綁定：黑火藥 → 無煙火藥 → 硝化甘油/TNT → 毒氣（[1915-毒氣戰.md](1915-毒氣戰.md)）——**化學工業從此成為戰爭的基礎設施**。

## 戰法演進筆記

火藥的戰法遺產：

1. **自帶氧化劑 = 不需空氣的燃燒**：化學能的受控釋放是所有「投射武器」的物理基礎。
2. **爆燃的極限定義戰法**：黑火藥時代以「面殺傷＋攻城」為主；直瞄精確要等無煙火藥。
3. **火→爆→射的工程難度階梯**：每一階都重寫一次戰場。
4. **可描述的技術擴散極快**：祕密不長久，**掌握量產與組織者獲勝**——火藥帝國的統治邏輯。
