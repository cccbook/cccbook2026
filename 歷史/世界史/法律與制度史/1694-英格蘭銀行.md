# 1694 - 英格蘭銀行（財政-軍事國家的信用革命）

## 案件摘要
1694 年，**William Paterson** 提案、英國議會通過——**英格蘭銀行**成立：
$$\text{政府需要打仗的錢} \xrightarrow{\text{特許狀 + 國債 + 永久資本}} \text{國家的信用就是制度的信用}$$
1,200 位股東集資 **£120 萬**借給政府（年息 8%），換取**特許狀**與**存款、貼現、
發鈔**的權利——**銀行與國家的共生契約**：
英國從此以 3% 的利率打仗，法國要 6%+——**制度就是融資成本，融資成本就是國家能力**。

## 前因 -- 為什麼會有這個案子
- **九年戰爭（1688–97）的財政缺口**：威廉三世戰費 £300 萬以上——
  金匠銀行家（goldsmith bankers）的短期貸款已到極限——
  **1672 年查理二世的停兌（Stop of the Exchequer）** 讓私人對王室的信用崩壞；
- **1689 權利法案的制度基礎**（見 `1689-權利法案與議會主權.md`）：
  **未經議會同意不得徵稅**——**議會批准的債務 = 全國稅收擔保**——
  **國王的債變成國家的債**（違約風險驟降）；
- **荷蘭的榜樣**：Paterson 是蘇格蘭人，見過阿姆斯特丹的公債與銀行機器
  （見 `1602-荷蘭東印度公司與股份制.md`、`1609-阿姆斯特丹銀行.md`）；
- **威尼斯的先例**：1262 起的**強制公債（monti）**——
  **有議會擔保的城邦，利率遠低於專斷的國王**——**制度差異的利率顯示**。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：特許狀的法律設計（銀行與國家的契約）
| 特許狀條款 | 內容 | 現代對應 |
|-----------|------|----------|
| 放款 £120 萬給政府 | 年息 8% + 每年 £4,000 管理費 | 國債的主承銷商 |
| 發鈔權 | 銀行券 = 準備的收據 | 中央銀行發鈔 |
| 存款與貼現 | 政府存款 + 商業貼現 | 央行的流動性提供 |
| 有限責任 + 法人 | 獨立法律人格 | 現代公司制度（見 `1602-荷蘭東印度公司與股份制.md`）|

**偵推**：英格蘭銀行不是「發明中央銀行」——它是**把「政府融資」與「貨幣發行」
打包成一個機構**——這個打包用了 250 年才演變成現代央行
（1946 國有化、1997 獨立）——**制度的功能比制度的名稱先到**。

### 第二條線索：議會主權的可信承諾（North & Weingast, 1989）
$$\text{違約風險貼水} = f\left(P(\text{國王單方面賴帳})\right) \xrightarrow{\text{議會控制錢袋}} 0$$
- 革命前：國王**可以**賴帳（1672 年就賴了）——貼水高達 6-7%；
- 革命後：**還款需要議會通過** = 債權人是**議會的對手方**——
  **賴帳 = 議會賴自己的帳**——**制度上不可能**；
- **偵推**：這是**時間不一致問題（time inconsistency）的制度解**——
  Kydland & Prescott（1977）的形式化：**承諾技術（commitment technology）**——
  英格蘭銀行就是**第一個國家級承諾技術**。

### 第三條線索：利率下降的數據（財政革命的實證）
| 時期 | 英國長期公債利率 | 對照：法國 |
|------|-----------------|-----------|
| 1690s | ~8% | ~6-7%（但違約頻繁）|
| 1710s | ~6%（整合為 consol 的前身）| 反覆部分違約 |
| 1730s | **~3%**（3% 年金 consol）| 5-6%+ |
| 1750s–1815 | 3-4% | 高且不穩 |

$$\text{戰爭融資成本} = \text{本金} \times r \times t \quad \Rightarrow \quad r: 8\% \to 3\% = \text{同樣戰費，利息省 } 62.5\%$$
- **偵推**：英法戰爭（1689–1815）中，英國用**更低的利率借更多的錢**——
  **融資能力 = 軍事能力**——這是 Brewer「財政-軍事國家」的核心論證——
  **勝負在戰場之外：在債券市場**。

### 第四條線索：社會契約視角——銀行是「納稅人與債權人的契約」
- 英格蘭銀行的本質：**納稅人（未來的）向債權人（現在的）出具的期票**——
  **議會作為中介**：
$$\text{納稅人（未來）} \xrightarrow{\text{議會批准}} \text{國債} \xrightarrow{\text{英格蘭銀行}} \text{債權人（現在）}$$
- **偵推**：這是**代際契約**的金融形式——盧梭的社會契約是同代人間的，
  英格蘭銀行把契約**延伸到未世代**——**公債是對未世代的抵押**——
  **這也是公債批評的起點**（Hume、後來的 Buchanan 公共選擇學派）。

### 第五條線索：公共選擇學派的警示（Buchanan / Wagner）
- 公共選擇的問題：**支出受益與納稅負擔分離**——
  政客有動機**今天支出、明天舉債**——公債是**「財政幻覺」**；
- 但英格蘭銀行的制度反而**抑制**了這個動機——因為**議會的兩院制 + 財產權選民**
  讓「舉債過度」有制度成本——**制度設計對政治人的誘因設下約束**；
- **偵推**：這是**mechanism design 的早期應用**——
  英格蘭銀行不是「聰明的銀行家發明的」——是**「議會要限制國王的誘因」**而設計的——
  **制度 = 誘因的重新配置**。

## 結案 -- 後果與影響
- **英國的百年勝利**：西班牙王位繼承戰爭、七年戰爭、拿破崙戰爭——
  **低利率的英國打贏高利率的法國**——**融資能力決定帝國勝負**；
- **金融革命的擴散**：美國 First Bank（1791，Hamilton 學英格蘭銀行）、
  法蘭西銀行（1800）——**央行成為現代國家標配**；
- **貨幣與國債的融合**：英鎊的「本位」是**國債的可兌換性**——
  **法幣的信用 = 國家財政的信用**——現代貨幣制度的原點；
- **陰暗面**：財政-軍事國家的效率也餵養了**帝國擴張**（見 `1602-荷蘭東印度公司與股份制.md`）——
  **低成本的戰爭 = 更多戰爭**；
- **偵探教訓**：1694 年證明了——**國家的信用就是制度的信用**。
  不是「國王人品好」而是「制度讓賴帳不可能」——
  **可信承諾是制度經濟學的第一命題**，利率是它的實證指標。
