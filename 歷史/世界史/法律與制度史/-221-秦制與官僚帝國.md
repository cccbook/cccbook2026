# -221 - 秦制與官僚帝國（上計、連坐與委託-代理的帝國解法）

## 案件摘要
前 221 年，秦王政統一六國。本書系「法律與制度史」的偵探焦點不是郡縣制
的社會結構（見 `../社會結構史/-221-秦郡縣制與官僚帝國.md`），而是**法律、
會計與考核制度**：商鞅變法（前 356–338）建立的**上計制度**——郡縣每年
把戶口、墾田、錢穀出入編成計簿上報中央，由丞相**年度稽核**——這是
**國家會計與政績考核**的第一次全國化；**睡虎地秦簡**（1975 年出土，
前 217 年墓主「喜」的藏書）揭露了秦律的精密：**《效律》**（核驗帳目
與庫存的專門法律——**審計法**！）、**連坐法**（什伍連坐、官吏連坐）、
**文書行政**（簡牘、封泥、郵驛）：
$$\text{帝國} = \text{文書} + \text{上計} + \text{連坐} \quad (\text{委託-代理的三件套})$$
秦證明：**帝國的統治能力 = 帝國的記帳與考核能力**——韋伯所說的
「家產官僚制」（patrimonial bureaucracy）在此達到古代的極致精度。

## 前因 -- 為什麼會有這個案子
- **戰國的財政競賽**：七國競爭是**財政-動員的競賽**——誰能把資源
  從土地上抽出來誰就贏——秦的答案是**會計 + 律令**；
- **商鞅的設計**（前 356–338）：《商君書》的核心命題——
  「治國能摶民力而務用之」——**把民力變成可計算、可徵集的量**；
  縣制的會計化：前 350 年秦設 41 縣，**縣就是一個會計單位**；
- **文書技術就緒**：竹簡、封泥、筆墨已成熟——戰國各國已有計簿
  行政——秦的工作是**全國化與法律化**（把上計寫進律）；
- **統一的規模跳躍**：前 221 年疆域擴大 2 倍以上——**委託-代理鏈
  急速拉長**——代理問題成為帝國的第一號難題——上計與連坐是
  秦的系統性答案。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：上計——年度政績稽核的會計結構
上計的流程與帳簿結構（據秦簡、漢初張家山漢簡與睡虎地律令重構）：

| 環節 | 主事者 | 內容 |
|------|--------|------|
| 基層登記 | 鄉里、縣曹 | 戶口、田畝、牲畜、勞役 |
| 縣級彙編 | 縣令/丞 | 計簿（年度預算+決算）|
| 上報 | 郡守 | 秋計上達中央 |
| 稽核 | 丞相/御史 | **課殿最**（分出優劣等第）|
| 問責 | 皇帝 | 升遷、罰俸、免官、刑 |

- **偵推**：上計是**政府會計 + 績效考核**的合一——計簿的本質是
  **預算 + 決算**的年度對照——與烏爾第三王朝的「平衡帳」
  （`-3000-泥板會計與神廟制度.md`）同構，但**規模大了兩個數量級**；
- **《效律》——最早的審計法**：睡虎地秦簡《效律》規定——倉庫物資、
  金錢帳目必須**定期核驗**，帳實不符（差值）按**比例罰金**：
  $$\text{罰} = f(\text{帳實差額} / \text{總額}) \quad (\text{差一甲、二甲，罰有等差})$$
  例如《效律》：倉存糧誤差超過一定比例，**縣嗇夫罰一甲**、佐史罰盾——
  **審計罰則被量化、分級**——這是**內部控制（internal control）**
  的最早成文法典。

### 第二條線索：委託-代理模型——秦的制度數學
帝國治理的核心是**委託-代理問題**（principal-agent problem）：
皇帝（委託人）與郡縣官（代理人）的目標不一致 + 資訊不對稱：

$$\text{代理人效用} = \text{俸祿} + \text{自利行為} - \text{被察覺的處罰} \cdot p$$

- **激勵相容（incentive compatibility）**：制度的設計目標是讓
  代理人的**最優策略 = 委託人想要的策略**——秦的三件套：

| 工具 | 針對的問題 | 現代對應 |
|------|-----------|----------|
| 上計（年度稽核）| 資訊不對稱 | 績效審計、預算制度 |
| 連坐（官吏連坐、什伍連坐）| 監督成本 | 同儕監控、集體問責 |
| 御史（監察官）| 逆向選擇 | 稽核/監察體系 |

- **連坐的數學**：一人犯罪，同僚/鄰里同罰——**把監督外包給利益
  相關者**——每個人都成了「監工」，監督成本 $c$ 被攤平：
  $$\text{總監督成本} = \frac{c}{\text{連坐人數}} \quad (\text{監控被稀釋到每一個人})$$
  代價是**激勵扭曲**：連坐使人不敢舉報自己的失誤 → 隱瞞與串通
  ——秦二世而亡的制度伏筆之一；
- **韋伯的家產官僚制**：韋伯區分**家產制**（官員是君主的私人家臣）
  與**法理型官僚制**（官員服務於非人格化規則）——秦制是**家產制
  與官僚制的高壓混合**：考核與文書是官僚制的（理性化極致），
  但**權力來源純屬君主個人**（皇帝可任意誅殺）——
  $$\text{秦制} = \text{官僚技術（理性化）} + \text{家產權力（非理性化風險）}$$
  韋伯的診斷：中國官僚帝國兩千年的困境正是**技術理性化了、
  正當性沒有制度化**——官吏對皇帝負責而非對法負責。

### 第三條線索：文書行政——帝國的作業系統
睡虎地秦簡《內史雜》《行書律》規範文書流程：
- **文書格式**：發文機關、日期、簽名（**畫押**）、收文記錄——
  **可追責鏈**（audit trail）的成文化；
- **行書律**：文書傳遞的時限（急書晝夜兼程）——**帝國的延遲預算**：
  $$\text{統治半徑} \leq \frac{\text{文書時限}}{2} \times \text{驛傳速度}$$
- **封泥**：竹簡以繩捆紮、泥封加印——**防篡改技術**——與烏爾的
  封球（`-3000-泥板會計與神廟制度.md`）同構：**重要文件必須
  完整性驗證**——這是「用冗餘偵測篡改」的最早行政實踐；
- **偵推**：秦的行政本質是**文書驅動的狀態機**——每一份簡牘都是
  一次狀態轉移（命令下達/執行回報）——**檔案即統治**。

### 第四條線索：商鞅的會計命題——《商君書》的「數」
《商君書·去強》：**「治國者，摶力以殺力……國好力，日以難攻；
國好言，日以易攻」**——更直接的命題在《商君書·弱民》與《去強》的
「十三數」：竟內倉口之數、壯男壯女之數、老弱之數、官士之數、
馬牛芻藁之數……
$$\text{治國} = \text{掌握十三數} \quad (\text{「強國知十三數」})$$
- **偵推**：商鞅明言——**不知道數字就不能治國**——這是**統計國家
  （statisticians' state）**的最早綱領——「statistics」詞源即「國家的
  科學」——秦比歐洲的統計革命（17 世紀政治算術 Petty）早了
  整整兩千年。

## 結案 -- 後果與影響
- **漢承秦制**：上計（漢代的計簿與「課殿最」）、御史監察、戶籍、
  律令體系全盤繼承——**兩千年帝國的會計-考核制度**是秦的迭代——
  唐的勾檢制、宋的審計院（諸軍諸司專勾司）、明清的奏銷制度
  都是上計的後裔；
- **審計與監察的譜系**：《效律》→ 漢代上計簿的「遣吏實核」→
  唐比部勾覆 → 宋審計司 → 明都察院——**中國的審計傳統始於秦律**；
- **連坐的教訓**：連坐法把監督成本降到極致，但代價是**資訊的
  隱瞞與系統的脆弱**——陳勝吳廣（「失期當斬」——但新出土
  湖南益陽兔子山秦簡顯示「失期，罰而不斬」——歷史敘事與律法
  的張力本身是線索）——**過度威嚇的制度會在第一個衝擊下
  系統性崩潰**——秦二世而亡是激勵設計的反面教材；
- **偵探教訓**：秦制證明了**帝國 = 會計 + 法律 + 文書**——統治的
  極限是核算與考核的極限；但同時證明：**激勵設計失敗的帝國
  會被自己的制度反噬**——委託-代理問題沒有純技術解，
  正當性與激勵必須一起設計。
