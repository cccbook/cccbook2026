# 1876 江華島條約：雲揚號的炮聲與開港

## 案發現場

1875 年，日本軍艦雲揚號在江華島海域挑釁（測量+登陸），與朝鮮炮台交火。次年日本以此為藉口派黑田清隆率軍艦壓境，簽訂《江華島條約》——朝鮮開港（釜山、元山、仁川）、日本享領事裁判權。朝鮮兩百年鎖國（參見丙子後的大報壇體制，本書 [1636-丙子胡亂.md](1636-丙子胡亂.md)）被炮聲終結。

> **日本為何複製黑船劇本？同樣的炮艦外交，為何在日本成功、在朝鮮只開了一道門縫？**

## 偵查過程

**線索一：黑船劇本的朝鮮版（學生超過老師）。** 明治日本把佩里的劇本（參見 [../亞洲史/1853-黑船來航.md](../亞洲史/1853-黑船來航.md)）完整複製：軍艦示威→製造事件（雲揚號故意挑釁）→壓境簽約。偵查結論：**被炮艦開國的國家，學會用炮艦開別人的國**——日本用了八年（1868 維新→1876 條約）。劇本相同的背後是實力差：佩里的美國是工業國，黑田的日本是維新八年的後發國——但對朝鮮已足夠。**炮艦外交的有效性只看相對差距**：日本vs朝鮮的代差，足夠複製美國vs日本的效果。

**線索二：大院君的鎖國（止痛藥的毒性發作）。** 興宣大院君當政（1863–73）——斥邪（焚毀天主堂、丙寅邪獄）、攘夷（辛未洋擾擊退美軍）。偵查結論：丙子後的尊明攘夷（大報壇體制）在此登峰造極——**兩百年的心理補償變成國策**：斥邪（反天主教）+攘夷（反一切外國）。短期凝聚人心，長期自廢武功（拒絕洋務、拒絕開化）。雲揚號來時，朝鮮的岸防炮是百年前的古董——**鎖國鎖住的不是外國，是自己升級的機會**。與德川鎖國（參見 [../亞洲史/1639-日本鎖國.md](../亞洲史/1639-日本鎖國.md)）對照：日本鎖國留了蘭學窗口，朝鮮鎖國連窗口都釘死——**管制的密度決定開國的慘度**。

**線索三：條約的門縫（只開一道縫的後果）。** 江華島條約開三港、給領事裁判權——但朝鮮朝廷（閔妃集團）採「以夷制夷」（引清、俄、美牽制日本），先後與美（1882）、英、德、俄簽約。偵查結論：這是**用多邊牽制對沖單邊壓迫**——小國的經典手法（高句麗多面結盟的現代版，參見本書 [-0037-高句麗建國.md](-0037-高句麗建國.md)）。短期有效（日本獨吞受阻），長期失效——**牽制的前提是牽制者互相制衡**；甲午戰爭（1894）日本打敗清朝，門縫變大門（參見本書 [1894-甲午改革.md](1894-甲午改革.md)）。以夷制夷的保質期=列強均勢的保質期。

**線索四：開港的經濟衝擊（米穀流出的憤怒）。** 開港後日本商人收購朝鮮米穀出口，米價飛漲——1882 年壬午兵變（士兵欠餉+米價騰貴）即其後果。偵查結論：開港的分配效應——**出口商賺錢，全民付通膨**（與日本開國時同，參見 [../亞洲史/1853-黑船來航.md](../亞洲史/1853-黑船來航.md)）。米穀流出=糧食主權流失，農民與士兵最先受害——東學農民軍（1894）的火藥裡，有一半是米價。**貿易自由化的第一張帳單，永遠寄給最窮的人**。

## 結案報告

1. **劇本複製**：被開國者學會開別國——炮艦外交的有效性只看相對代差。
2. **鎖國的毒性**：大報壇體制兩百年→岸防古董化——管制越密，開國越慘。
3. **牽制的保質期**：以夷制夷有效直到列強均勢破裂——甲午一戰，門縫變大門。
4. **窮人付帳**：米穀流出→米價飛漲→兵變農民起義——自由化的第一張帳單寄給最窮者。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 開港工程 | 跨域效應 |
|------|----------|----------|
| 法律 | 領事裁判權、開港條款 | 主權切片第一刀 |
| 經濟 | 米穀出口、米價飛漲 | 出口商賺、全民付 |
| 科技 | 雲揚號vs古董岸防炮 | 代差視覺化 |
| 政治 | 以夷制夷、多邊簽約 | 牽制日本獨吞 |
| 文化 | 斥邪攘夷總清算 | 鎖國意識形態破產 |

**德川鎖國 vs 朝鮮鎖國（對照）：**

| 項目 | 日本鎖國 | 朝鮮鎖國 |
|------|----------|----------|
| 資訊閥 | 出島+風說書 | 無（全面斥邪） |
| 洩漏物 | 蘭學 | 無（壬午才驚醒） |
| 開國劇本 | 被演（黑船） | 被演（雲揚號） |
| 後續 | 學會演別人 | 繼續被演（甲午、乙巳） |

**開國連鎖（示意）：**

```
雲揚號挑釁 → 江華島條約（門縫）→ 米穀流出 → 米價漲
  → 壬午兵變 → 以夷制夷 → 甲午戰敗（清）→ 大門洞開。
```

**結論：** 江華島案是「炮艦開國」的朝鮮版本：同樣的劇本（軍艦+事件+條約），不同的後續（日本學會演別人，朝鮮繼續被演）。**差別不在劇本，在開國後的回應速度**——日本八年從學生變老師，朝鮮三十年從門縫到亡國。回應速度，才是開國衝擊的真正考題。
