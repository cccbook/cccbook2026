# 0612 薩水之戰：乙支文德的水淹三十萬

## 案發現場

612 年，隋煬帝發兵逾百萬征高句麗——陸軍圍遼東城不下，海軍別部直趨平壤。乙支文德以「七戰七敗」誘隋軍深入，待其糧盡南返，決開薩水（清川江）上游堤壩，水淹隋軍。三十萬大軍生還僅數千。此戰直接動搖隋朝統治，間接催生唐朝。

> **小國軍隊如何正面殲滅十倍之敵？乙支文德的「詐敗」與隋煬帝的「必勝」，中間隔著什麼樣的後勤數學？**

## 偵查過程

**線索一：誘敵深入（把戰場搬到敵人後勤的盡頭）。** 乙支文德連敗七陣，每日遣使請降——隋軍將領宇文述輕敵冒進，直抵平壤城下三十里。偵查結論：詐敗的本質是**用空間換敵人的補給線長度**——隋軍每前進一步，糧道就長一分、民夫逃亡就多一分。抵達平壤時，隋軍已是**後勤曲線末端的強弩之末**。乙支文德給隋將的五言詩（「神策究天文，妙算窮地理，戰勝功既高，知足願云止」）是心理戰的巔峰——**捧殺驕將，驕將必冒進**。

**線索二：後勤絞殺（百萬大軍的胃）。** 百萬人每日耗糧以萬石計，遼東至平壤千里轉運，民夫逃亡、糧車被劫。偵查結論：隋軍的真正敵人不是高句麗兵，是**自己的胃**——

```
戰力 ＝ 紙面兵力 × 補給係數。
補給係數 ＝ 隨距離遞減 → 平壤城下趨近於零。
```

薩水決戰時隋軍已斷糧數日——**餓兵無戰力**，水淹只是給崩潰一個形式。這是尼布楚「後勤等高線」邏輯（參見 [../亞洲史/1689-尼布楚條約.md](../亞洲史/1689-尼布楚條約.md)）的戰場版：**遠征的終點是戰力的谷底**，乙支文德算準了谷底的位置。

**線索三：水攻（地形的武器化）。** 高句麗軍上游築壩蓄水，待隋軍半渡而擊、決壩放水。偵查結論：水攻的精髓不在水，在**時機**——半渡時陣形割裂、前後不能相救，此時放水=把一支軍隊切成兩段再淹掉一段。地形是免費的盟軍：**善戰者先算地形，再算兵力**。薩水、赤壁、淝水——東亞戰史的水戰勝利全是同一公式：誘敵至水邊→半渡而擊。

**線索四：戰略外溢（打贏一仗，改寫兩個帝國）。** 隋煬帝三征高句麗（612、613、614）皆敗，府庫空虛、民變蜂起——隋亡（618）；唐太宗親征（645）亦敗於安市城，在高句麗碰得頭破血流。偵查結論：薩水之戰的真正戰果不在戰場，在**歷史走向**——它證明中原王朝無法速勝半島強權，迫使唐改用「聯合新羅」的間接路線（參見本書 [0676-新羅統一.md](0676-新羅統一.md)）。**一場戰役的失敗，改寫了帝國的戰略選項**——直接征服此路不通，才有借師助剿的迂迴。

## 結案報告

1. **空間換補給**：詐敗的本質是拉長敵人糧道——戰場應選在敵人後勤的盡頭。
2. **胃即戰力**：百萬大軍敗於自己的消耗——後勤係數歸零時，紙面兵力只是數字。
3. **時機即武器**：半渡而擊+決壩——地形免費，時機無價，水戰公式千年不變。
4. **戰役改寫戰略**：薩水證明直接征服不通——唐被迫改走聯合新羅路線，半島命運就此轉向。

| 項目 | 隋軍 | 高句麗軍 |
|------|------|----------|
| 兵力 | 百萬（紙面） | 數萬（實際） |
| 補給線 | 千里（遞減） | 本土（滿血） |
| 情報 | 輕敵冒進 | 知己知彼 |

**殲滅公式（示意）：**

```
殲滅 ＝ 誘敵至補給盡頭 × 斷糧（戰力歸零）× 半渡而擊（陣形割裂）。
乙支文德的三步：請降（驕敵）→ 誘深（耗糧）→ 決水（收割）。
```

**結論：** 薩水案是「以小搏大」的完整教案：不拚兵力拚後勤，不決戰決補給——把敵人請進自家後院，餓瘦了再用水送走。**遠征軍的墳墓永遠挖在補給線的盡頭**——這條公式從薩水到拿破崙征俄到對馬海戰（參見 [../亞洲史/1905-日俄戰爭.md](../亞洲史/1905-日俄戰爭.md)），從未失手。
