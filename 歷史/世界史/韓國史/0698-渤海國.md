# 0698 渤海國：被遺忘的海東盛國

## 案發現場

698 年，高句麗遺將大祚榮率靺鞨與高句麗遺民，在東牟山建渤海（初號震國）。鼎盛時疆域跨今中朝俄三國交界，設五京十五府，與唐、日本、新羅並立——唐人稱「海東盛國」。926 年被契丹所滅，存在 228 年。這個國家為何在韓國史與中國史之間「無處安放」？

> **渤海是高句麗的繼承者、靺鞨的帝國，還是唐朝的羈縻州？一個國家的歸屬爭議，為何成為東北工程的核心戰場？**

## 偵查過程

**線索一：遺民帝國（亡國之後的重建）。** 大祚榮本是高句麗遺將，部眾是高句麗遺民+靺鞨部落——國家機器（官制、文字、佛教）承自高句麗，兵源人口來自靺鞨。偵查結論：渤海是**亡國精英+地方部落的合資重建**——精英提供制度模板（上京仿長安、官制仿唐），部落提供人口與武力。這種「借殼上市」模式此後反覆出現（高麗王建亦用新羅遺民+豪族）。**亡國不是終點，是資產重組的起點**——只要精英與模板還在，國家可以換殼重生。

**線索二：海東盛國（五京制的貿易帝國）。** 渤海設上京（東京）等五京，日本海貿易興盛——與日本通使 34 次（渤日貿易：毛皮人參換絲綢水銀），與唐朝貢貿易，與新羅有事（雙方築長城對峙）。偵查結論：渤海的繁榮靠**中轉貿易**——處於唐、日本、新羅的十字路口，位置本身就是財富。

**線索三：南北國時代（兩個韓國的第一次）。** 新羅統一南部、渤海雄踞北部——韓國史學界稱「南北國時代」，主張渤海是韓國史的一部分。偵查結論：這是**統一敘事的回溯建構**——用「南北國」把渤海納入民族史，對抗「新羅統一=正統」的單線史觀。功能與檀君神話同（參見本書 [-2333-檀君古朝鮮.md](-2333-檀君古朝鮮.md)）：**史學分期本身就是政治**——叫「南北國」還是叫「新羅—渤海並立」，決定了渤海姓韓還是姓唐。

**線索四：歸屬爭議（東北工程的風暴眼）。** 中國主張渤海是唐朝羈縻州（曾受唐冊封「渤海郡王」）、是中國地方政權；韓國主張其主體是高句麗遺民、是韓國史。偵查結論：雙方各執一端——**冊封是事實（外交名分），主體是遺民也是事實（人口基本盤）**。爭議的本質是現代主權的古代投射：渤海故地（今延邊）的主權歸屬已定（中國），爭的是**敘事主權**。與好太王碑之爭（參見本書 [0391-廣開土大王.md](0391-廣開土大王.md)）同構：**領土既定，歷史未定——敘事是最後的戰場**。

## 結案報告

1. **借殼重生**：遺民精英+靺鞨部落——亡國是資產重組，模板在即可換殼上市。
2. **貿易立國**：五京=關稅站網絡——十字路口的位置本身就是財富。
3. **分期即政治**：「南北國」之名決定渤海姓誰——史學分期是主權的文化工事。
4. **敘事是最後戰場**：領土既定、歷史未定——冊封與主體各執一端，爭的是話語權。

**重建公式（示意）：**

```
亡國遺產（精英＋制度模板）＋ 地方部落（人口＋武力）
  × 十字路口（貿易）＝ 遺民帝國（渤海 228 年）。
```

**結論：** 渤海案是「亡國重建」與「敘事爭奪」的雙重樣本：大祚榮用遺民加部落換殼上市，後人用分期與冊封爭奪歸屬。**國家會滅亡兩次——一次在戰場，一次在史書**；渤海在戰場亡於契丹，在史書仍在開戰——而這場戰爭，才是它真正的「海東盛國」遗产：讓三國史學家為它打了三十年。
