# 1592 壬辰衛國戰爭：李舜臣與全民戰爭

## 案發現場

1592 年，豐臣秀吉發兵十六萬侵朝（文祿之役），三週陷漢城，宣祖逃往義州。朝鮮正規軍（水陸）相繼崩潰——然後戰局逆轉：李舜臣閑山島大捷斷日軍糧道、各地義兵蜂起、明軍參戰，1598 年露梁海戰李舜臣陣亡、日軍撤退。七年戰爭，朝鮮本土打爛，但國家得保。

> **正規軍崩潰後，誰在打仗？龜船、義兵與李舜臣——七年戰爭的逆轉方程式是什麼？**

## 偵查過程

**線索一：正規軍為何崩潰（黨爭誤國）。** 戰前朝鮮重文輕武、黨爭（東人西人）互相傾軋，武將李鎰臨陣脫逃、申砬輕敵覆滅。偵查結論：崩潰的不是軍隊，是**人事系統**——能打的李舜臣此前被貶為庶民（丁酉再亂前又遭誣陷下獄），庸將因黨派上位。**官僚政治的用人邏輯（派系）與戰爭的用人邏輯（能力）衝突時，戰爭替官僚付帳**。三週失國土，是黨爭二十年的總帳單。這是甲午北洋（參見 [../亞洲史/1894-甲午戰爭.md](../亞洲史/1894-甲午戰爭.md)）的朝鮮預演：**同樣的船（制度），同樣的沉法**。

**線索二：李舜臣與制海權（斷糧道即斷命脈）。** 李舜臣以全羅左水使守住南部海域——玉浦、閑山島（「閑山島月夜」閑山大捷）、釜山浦，二十三戰全勝。偵查結論：戰略核心是**制海權=日軍糧道**：日軍十六萬在朝鮮作戰，糧食靠海運（對馬—釜山—漢城）；李舜臣不斷糧道，日軍即斷命脈。龜船（鐵甲+火炮+撞角）是戰術奇兵，但真正的武器是**李舜臣的情報與時機**（鳴梁大捷以十二艘對三百餘艘，靠的是鳴梁海峽的激流——地形武器化，參見本書 [0612-薩水之戰.md](0612-薩水之戰.md)）。**海戰打的是後勤，不是船數**。

**線索三：義兵（全民戰爭的原型）。** 郭再祐（紅衣將軍）、金千鎰、高敬命等儒生起義兵——截糧道、襲據點，與正規軍配合。偵查結論：義兵的本質是**國家失能時的社會自救**：中央崩潰，地方士紳用宗族+書院網絡組織武裝。儒生能打仗，因為**書院即動員節點**（同學、同門、師生=現成的指揮鏈）。這是半島「全民動員」傳統的起點（後續：抗日義兵、三一運動、光州——參見本書 [1919-三一運動.md](1919-三一運動.md)、[1980-光州事件.md](1980-光州事件.md)）。**國家會崩潰，社會不會——只要動員節點還在**。

**線索四：明軍參戰（宗主國的帳單）。** 萬曆三大征之援朝——李如松、麻貴率軍入朝，平壤大捷、碧蹄館受挫，最終和談破裂再戰。偵查結論：明軍是**雙面刃**：沒有明軍，朝鮮必亡；有了明軍，朝鮮國庫被吃空（軍費攤派）、戰後對明依賴加深。宗主國出兵從來不是免費的——**保護費的帳單在戰後寄到**（參見丙子胡亂後對清的歲幣，見本書 [1636-丙子胡亂.md](1636-丙子胡亂.md)）。壬辰戰爭確立了此後三百年的東亞秩序：**朝鮮=明的屬國、日本鎖國、女真崛起於戰後真空**（努爾哈赤1583起兵正在戰時）。

## 結案報告

1. **黨爭付帳**：庸將上位、良將下獄——三週失國是人事系統崩潰的總帳單。
2. **制海即制命**：斷糧道不斷船——海戰打後勤，李舜臣二十三戰全勝靠情報時機地形。
3. **社會自救**：書院即動員節點——國家崩潰時，社會用現成網絡組織義兵，全民戰爭原型。
4. **宗主帳單**：明軍救國也吃空國庫——保護從來不是免費，戰後秩序重寫三國命運。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 戰爭工程 | 跨域效應 |
|------|----------|----------|
| 法律 | 軍功賞罰、義兵合法性 | 戰時動員法理 |
| 經濟 | 軍費攤派、糧道戰 | 國庫吃空、民生塗炭 |
| 科技 | 龜船、火炮、時節情報 | 地形武器化 |
| 政治 | 黨爭誤國、明軍參戰 | 屬國體制鞏固 |
| 文化 | 李舜臣神話、亂中日記 | 全民戰爭記憶 |

**崩潰 vs 逆轉（對照）：**

| 階段 | 主體 | 結果 |
|------|------|------|
| 開戰三週 | 正規軍（黨爭庸將） | 失漢城、國王逃義州 |
| 中期 | 李舜臣（制海）+義兵 | 斷糧道、日軍困守 |
| 後期 | 明軍+朝鮮聯軍 | 平壤收復、相持 |
| 終局 | 露梁（李舜臣陣亡） | 日軍撤退、國保民殘 |

**逆轉方程式（示意）：**

```
逆轉 ＝ 制海斷糧（李舜臣）＋ 社會自救（義兵）＋ 宗主參戰（明軍）。
三者缺一即亡國：無制海則日軍南糧北運暢通，
無義兵則佔領區穩固，無明軍則陸戰無主力。
```

**結論：** 壬辰案是「國家崩潰後的戰爭」的完整樣本：正規軍先垮，社會與良將接棒——制海斷命、義兵遍地、宗主兜底。**國家的韌性不在朝廷，在社會的動員節點**——書院、宗族、水軍，只要節點還在，亡國只是暫時的。
