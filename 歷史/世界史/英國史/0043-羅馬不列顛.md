# 0043-羅馬不列顛：帝國邊疆的三百六十年

## 案件摘要

西元 43 年，克勞狄烏斯（Claudius）派四個軍團登陸不列顛——**羅馬征服開始**；122 年哈德良長城（Hadrian's Wall）、43–410 年羅馬統治近四百年；410 年霍諾里烏斯撤軍令（「自己保衛自己」！）——羅馬不列顛終結。這樁案件是「帝國邊疆的成本效益」：**不列顛從缺人問津的蠻荒，變成要塞化邊疆，再變成帝國丟不起也養不起的包袱**。

## 前因 -- 多因素的局勢

- **羅馬**：凱撒兩次試探（前 55、前 54！）未佔領；克勞狄烏斯需要軍事榮耀（跛足皇帝的合法性！）——征服的個人動機。
- **本地**：貝爾蓋（Belgae）等部落王國分裂（卡塔庫斯—卡拉塔庫斯抵抗！、布狄卡 Boudica 60–61 大起義焚倫敦！）——分而治之的機會。
- **經濟**：鉛—銀礦（門迪普 Mendips！）、穀物（後期「帝國糧倉」之一！）、奴隸—獵犬出口——邊疆的自給潜力。
- **戰略**：北方喀裡多尼亞（蘇格蘭）無法征服 → 哈德良長城（122！）→ **帝國從擴張轉守成的象徵**。

## 線索與推理 -- 因素咬合

### 線索一：布狄卡起義——「羅馬化的代價」

60–61 年：羅馬沒收 Icenian 王產—鞭打布狄卡—凌辱其女 → 起義（焚 Camulodunum、Londinium、Verulamium，死 7–8 萬！）→ 保利努斯鎮壓（Watling Street！）：

$$\text{起義} = \text{（財產沒收）} \times \text{（人格侮辱）} \div \text{（羅馬駐軍空虛：保利努斯在安格爾西！）}$$

**羅馬學到教訓**：此後懷柔（給部落貴族公民權—別墅！）——不列顛南部羅馬化（別墅 500＋、浴場—馬賽克！），北方保持部落。**懷柔與屠殺的交替是邊疆統治的標準作業**。

### 線索二：哈德良長城——「帝國的資產負債表」

122 年：橫貫英格蘭北部 117 公里石牆（軍團—輔助軍 1 萬＋駐守！）：

$$\text{長城} = \text{（征服喀裡多尼亞成本} > \text{收益）} \Rightarrow \text{守成}$$

**長城是羅馬擴張的止損線**——帝國承認：有些土地不值得。安東尼長城（142，前推蘇格蘭！）曇花一現即退回——**止損線的確認**。不列顛從此是「要塞省」（三個軍團＋艦隊！高於多數行省！）——**邊疆的軍事化＝財政的黑洞化**。

### 線索三：410 撤軍——「自己保衛自己」的訃告

3 世紀危機（高盧帝國 260–74！不列顛首府！、卡勞修斯 286 僭位！）→ 4 世紀蠻族（皮克特—蘇格蘭—撒克遜！）海陸夾擊 → 407 君士坦丁三世抽走最後野戰軍 → 410 霍諾里烏斯回信（Zosimus 記載！真偽爭議！）：

$$\text{撤軍} = \text{（高盧—義大利吃緊）} \times \text{（不列顛稅收} < \text{駐軍成本）}$$

**帝國的邊疆按 ROI 排序拋售**——不列顛第一個被放棄（富裕的高盧—西班牙更晚！）。羅馬別墅迅速荒廢（410–450 城市—貨幣—陶器崩潰！）——**文明的斷電**（→[0597-七國時代.md](0597-七國時代與基督教化.md)盎格魯—撒克遜的黑暗時代！）。

## 破案時刻

- 前 55、前 54：凱撒試探——未佔領。
- 43：克勞狄烏斯四軍團登陸（Aulus Plautius！）——征服開始。
- 60–61：布狄卡起義—鎮壓——懷柔轉向。
- 122：哈德良長城——擴張止損。
- 286–296：卡勞修斯—阿萊克圖斯僭位（不列顛帝國！）——邊疆的離心。
- 407：抽走野戰軍；410：撤軍令——羅馬不列顛終結。

## 後果 -- 改變了什麼

- **城市**：倫敦（Londinium！）、約克（Eboracum！）、巴斯（Aquae Sulis！）——羅馬城市網的起點（倫敦至今首都！）。
- **道路**：Watling Street、Ermine Street、Fosse Way——**羅馬大道用兩千年**（A1—A5 國道的走向！）。
- **語言**：拉丁語底層（chester—caster—coln 地名！Manchester、Doncaster！）＋基督教種子（聖奧爾本斯殉道！→597 再傳！）。
- **神話**：亞瑟王傳說（5–6 世紀抵抗撒克遜的 Romano-British 領袖？！）——帝國撤退的文學補償。
