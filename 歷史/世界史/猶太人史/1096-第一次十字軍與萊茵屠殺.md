# 1096-第一次十字軍與萊茵屠殺：反猶的組織化起點

## 案件摘要

1096 年春，教宗烏爾班二世號召的十字軍（1095 宣講， 目標奪回耶路撒冷）尚未與穆斯林交鋒，就在歐洲腹地先屠殺了猶太人。自封統帥的沃爾姆斯伯爵埃米希與「窮人十字軍」傳教士（隱修士彼得等人）率眾沿萊茵河而下，先後攻擊施派爾、沃爾姆斯、美因茨、科隆、特里爾、雷根斯堡的猶太社群。5 月美因茨大屠殺最烈：主教庇護失效，約八百至一千猶太人被殺，許多人在集體自殺中殉道（史稱 kiddush ha-Shem，聖化神名）。數月間萊茵蘭社群近半被毀。這樁案件的真相是：**十字軍提供了一個新的組織模板——以宗教熱情動員、以暴力清除「內部異教徒」**——反猶暴力從此有了可複製的劇本。

## 前因 -- 多因素的局勢

- **十字軍宣講**：烏爾班二世的口號「上帝願意」（Deus vult）把殺敵赦罪的贖罪機制向全民開放——原本屬於騎士的聖戰特權大眾化。
- **邏輯的滑移**：耶路撒冷在萬里之外，猶太人就在隔壁——「先肅清身邊的基督之敵」成為即時可執行的版本。
- **債務結構**：萊茵蘭主教與貴族、商販普遍欠猶太錢莊債務；殺死債主、焚毀債契＝債務銷毀——參與者有直接的財務誘因。
- **主教庇護制的斷裂**：數世紀來猶太人是帝國「王家僕役」（servi camerae regis 雛形），由主教直轄保護；十字軍的群眾暴力壓過了庇護武力。
- **殉道神學的回應**：猶太社群面對「受洗或死」的選擇，多數選死——中世紀猶太殉道文學（如《美因茨哀歌》）由此成形。

## 線索與推理 -- 因素咬合

### 線索一：赦罪機制的暴力外溢

十字軍的核心發明是**暴力的宗教會計**：參戰＝赦罪＝得救。一旦「殺敵」可以記入救贖帳戶，敵人的定義就會向下滲透：

$$\text{救贖報酬} \propto \text{「聖戰」行為} \quad\Rightarrow\quad \text{最廉價的聖戰} = \text{殺最近、最無抵抗力的「敵人」}$$

攻打耶路撒冷需要數月行軍與軍事技能；攻擊同城猶太區需要一個下午。**當暴力的宗教收益相同而成本懸殊，理性（或半理性）的暴力就流向低成本目標**——這是制度設計（赦罪）未曾預料、卻結構性注定的外溢。

### 線索二：債務銷毀的財政邏輯

萊茵蘭猶太人的核心經濟功能是信貸（主教們自己常是最大債務人）。屠殺的會計效果：

| 行為 | 對債務的效果 |
|---|------|
| 殺債主 | 債權人消失 |
| 焚債契（常隨屠殺發生） | 證據消失 |
| 沒收遺產 | 本金回流兇手 |

美因茨大主教本人在圍城時庇護猶太人，城破後暴徒喊的是「看啊，這就是靠猶太錢致富者的下場」。此後歷代驅逐（[1290-英國驅逐猶太人.md](1290-英國驅逐猶太人.md)）把這個邏輯國家化——**債主消失等於債務消失**，成為王公財政的誘惑公式。

### 線索三：庇護體系的失敗

主教們（施派爾、沃爾姆斯、美因茨、科隆）大多盡力庇護——把猶太人藏進主教堡壘、雇兵守衛。但庇護的算式失敗了：

$$\text{庇護存活} = \text{主教武力} + P(\text{主教不被推翻或嚇退})$$

在群眾狂熱面前，主教或逃（特里爾）、或被暴徒壓垮（美因茨，主教親兵倒戈）。更深的教訓：**猶太人的安全建立在「個別統治者的私人保護」上，而非「可執行的普遍權利」上**——庇護是可以被撤回的資產。

### 線索四：殉道選擇——社群的自我定義

面對「受洗保命」，萊茵蘭社群出現大規模集體殉道：父母殺子女再自殺。中世紀猶太史家（如亞伯拉罕·本·大衛的編年）與哀歌把此詮釋為比 70 年、135 年更純粹的「聖化神名」。功能上看：**殉道敘事重建了社群邊界**——受洗的誘惑（保命）是最強的同化壓力，殉道傳說把「不改宗」變成社群的最高榮譽。暴力反而固化了身分（也埋下日後阿什肯納茲猶太性的剛性底色）。

## 破案時刻

- 1095.11：克萊蒙會議，烏爾班二世宣講十字軍。
- 1096.4–5：埃米希與群眾軍沿萊茵河南下；施派爾（主教保住多數）、沃爾姆斯（800 死）、美因茨（1014 死，最烈）。
- 1096.5–6：科隆居民藏匿猶太人於周邊村莊，多數被搜出殺害。
- 1096.6–7：特里爾、雷根斯堡（強制受洗）；埃米希軍後在匈牙利被殲——「內部聖戰」的執行者自己也未走到聖地。

## 後果 -- 改變了什麼

- **人口**：萊茵蘭猶太社群近半消滅；倖存者遷向東方（波希米亞、波蘭）——東歐猶太中心的起點之一。
- **宗教**：阿什肯納茲殉道文學與哀歌傳統確立；社群對外界的根本不信任成形。
- **政治**：教會官方（主教會議、個別教宗）多次譴責強迫受洗與屠殺——但**組織模板已經存在**：群眾＋赦罪話語＋財務誘因，此後每個危機（黑死病 1348–49 的血祭誣陷大屠殺是它的大爆發）都會重演。
- **世界史**：反猶暴力從偶發的騷亂變成「可組織、有劇本、有收益」的行動——它是 20 世紀集體暴力的遠祖之一。

## 因素影響筆記

1. **赦罪機制 → 暴力外溢**：把暴力記入救贖帳戶的制度，注定流向成本最低的目標——制度設計必須計算外溢。
2. **債務結構 → 財務誘因**：債主成為債務人的清除目標——信貸關係在缺乏法治保護下變成死亡風險。
3. **私人庇護 → 脆弱**：安全若繫於個別主教的善意而非普遍規則，狂熱時刻即告失效——權利的可執行性高於庇護的恩惠。
4. **殉道 → 身分固化**：極端暴力反而強化社群的自我定義與內聚力——迫害的社會心理悖論。
