# 2007-智慧手機與平台零工經濟

## 案件摘要
2007 年 1 月，Jobs 發布 iPhone；6 月開賣——智慧手機把網路裝進口袋（App Store 2008）。這樁「口袋裡的電腦」案件是組織與勞動的重構：**平台**（Uber 2009、滴滴 2012、外送、Airbnb 2008）以雙邊市場（Rochet-Tirole 2003）的網路效應重構中介——計程車行、仲介、旅行社被平台取代；**零工經濟**：僱傭關係拆解為「按單接案」——**演算法管理**（algorithmic management）：派單、評分、定價都由演算法執行——泰勒的科學管理（1908 案）以演算法復活，且這次**沒有人情、沒有工會的緩衝**。組織從「公司」變「平台」，勞動從「職業」變「任務」。

## 前因 -- 為什麼會有這個案子
- **手機的技術條件**：GPS + 行動網路 + 智慧手機——即時定位與下單的硬體就緒。
- **閒置資源與信任問題**：私家車、空房、閒置時間——「共享」的供給存在，缺的是**信任與配對機制**（評分系統解決）。
- **公司內部的閒置**：科層企業的閒置人力與低效——「按需勞動」的供給。
- **資本與演算法**：創投（2008 後的低利率熱錢）+ 雲端（AWS 2006）——平台的資本與基礎設施就緒。

## 線索與推理 -- 數學式、理論、表格

### 線索一：雙邊市場的網路效應
Rochet-Tirole（2003）的雙邊市場理論：平台連接兩側（司機-乘客、房東-旅客），價值隨兩側用戶數超線性增長：

$$\text{平台價值} \propto n_{\text{側一}} \times n_{\text{側二}} \quad (\text{網路效應})$$

**推理**：網路效應 → 贏者通吃（最先達到臨界質量的平台獨占）——平台的「自然壟斷」結構；定價的不對稱（補貼一側、收費另一側——用戶補貼司機、廣告補貼內容）。這是「市場的中介」從人工（仲介行）變演算法（平台）的組織革命。

### 線索二：演算法管理 = 科學管理的復活
泰勒（1911）的科學管理（時間動作研究、計件）以演算法形式復活：

| | 泰勒工廠（1908）| 平台演算法管理（2009-）|
|---|----------------|----------------------|
| 計量 | 秒錶測時 | GPS + 派單演算法 |
| 定價 | 計件工資 | 動態定價（surge pricing）|
| 監督 | 領班 | 評分（5 星）+ 申訴 |
| 組織 | 僱傭（有工會法）| 承包（勞動法外）|

**推理**：演算法管理把「監督、定價、懲罰」全部演算法化——**效率升級 + 責任外移**（平台自稱科技公司非僱主——勞動法的外套被脫掉）。評分系統是「非人格的監工」——勞動的控制結構重構（Lee et al. 2015 的演算法管理研究）。

### 線索三：僱傭 → 任務的拆解
零工經濟把「職業」拆成「任務」：

$$\text{僱傭（職業 + 福利 + 階梯）} \to \text{按單接案（任務 + 無福利 + 無階梯）}$$

**推理**：就業的「組織依附」被拆解——彈性（可自選時間）的代價是保障的消失（無保險、無退休、收入波動）——「彈性 vs 安全」的取捨（Kalleberg 2009 的不穩定工作；Standing 2011 的「不穩定無產階級」precariat）；英國 Uber 案（2021 判決司機為工人）與加州 AB5——法律正在追趕組織。

### 線索四：平台的企業邏輯
平台 = 雙邊市場 + 演算法管理 + 資產輕（不擁有車與房）→ 估值邏輯（網路效應 → 獨占預期 → 高估值）；監管的滯後（antitrust 的重新討論——「平台是否自然壟斷」）——「平台資本主義」（Srnicek 2017）的政治經濟學。

## 結案 -- 後果與影響
- **組織的形態變遷**：公司 → 平台——中介的演算法化；傳統中介（計程車行、旅行社、仲介）的衰落。
- **勞動的任務化**：零工、按需經濟——保障與彈性的制度辯論（勞動法的重新設計）。
- **消費的即時化**：外送、叫車的「即時滿足」——城市生活的節奏重構。
- **信任的演算法化**：評分系統取代機構認證——「信任」從機構（執照、品牌）變成數據（評分）——2008 案的演算法信任主題的社會版。
- **演算法治理的議題**：派單不透明、評分歧視、動態定價——「演算法的公共責任」成為新治理課題。
