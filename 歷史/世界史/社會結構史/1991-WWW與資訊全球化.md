# 1991-WWW與資訊全球化

## 案件摘要
1989-91 年，CERN 的 Tim Berners-Lee 提出並上線 WWW（HTTP/HTML/URL）——網路從軍事與學術（ARPANET 1969、TCP/IP 1983）走向公共。同年 12 月，蘇聯解體——「計算的失敗」（1917 案）與「網路的誕生」同年。這樁「超連結」案件是信息結構與組織的雙重重構：**信息與通訊成本的暴跌**（Coase 1937 的應用：交易成本下降 → 企業邊界縮小——外包、全球供應鏈、WTO 1995）+ **信息的高速流動**——全球化 2.0 的十年（1990s-2000s）。Castells 的「網路社會」：組織從科層金字塔變成網路。

## 前因 -- 為什麼會有這個案子
- **網路的基礎設施**：ARPANET（1969）→ TCP/IP（1983）→ 學術網路（NSFNET）——「封包交換 + 通用協議」的技術已就緒。
- **PC 的普及**（1971 案）：個人計算 → 數百萬台可上網的終端。
- **CERN 的需求**：科學文獻與數據的共享——「超連結」的想法（Nelson 的 hypertext 1965）待實現。
- **蘇聯解體的同期**：計畫經濟的信息瓶頸（1917 案）——「分散計算（市場/網路）」勝過「集中計算（計畫）」的世紀判決同年落筆。

## 線索與推理 -- 數學式、理論、表格

### 線索一：WWW 的三件套
Berners-Lee 的發明是**協議的極簡主義**：

| 發明 | 內容 | 效果 |
|------|------|------|
| URL | 資源的統一地址 | 任何東西可被引用 |
| HTTP | 無狀態的簡單協議 | 部署門檻極低 |
| HTML | 超文本標記 | 文檔互相連結 |

**推理**：極簡 + 開放 → 網路效應的爆發（Metcalfe 定律：網路價值 $\propto n^2$）——1993 Mosaic 瀏覽器 → 1995 電子商務（Amazon/eBay）→ 2000 年全球網站千萬級。「協議的開放性」是網路的制度基因（無人擁有網路）。

### 線索二：科斯定理的網路應用——企業邊界的縮小
Coase（1937）：企業的存在是為了節省**市場的交易成本**（搜尋、談判、履約）。網路讓交易成本暴跌：

$$\text{企業邊界} \propto \frac{\text{內部組織成本}}{\text{市場交易成本}} \quad \xrightarrow{\text{交易成本} \downarrow} \quad \text{企業邊界縮小}$$

**推理**：信息成本暴跌 → 外包、全球供應鏈、眾包——「大而全」的垂直整合讓位於「網路化的專業分工」——Nike（無工廠的品牌）與富士康（純代工）同時誕生。**通訊技術重畫企業邊界**——Coase 定理的歷史驗證（Malone 2004）。

### 線索三：全球供應鏈與 WTO
WTO（1995）+ 網路 + 集裝箱（1956 的技術，此時制度化）→ 全球供應鏈：設計在美國、零件在台日韓、組裝在中國、銷售全球——「微笑曲線」的全球分工：

| 環節 | 附加價值 | 實例 |
|------|---------|------|
| 設計/品牌 | 高 | 美國 |
| 關鍵零件 | 中高 | 台韓日 |
| 組裝 | 低 | 中國東南亞 |

**推理**：信息技術讓「跨國協調」的成本低於「本地整合」——供應鏈的地理重構 → 中國崛起（1990s-2010s 的世界工廠）——全球化的地理與階層重構。

### 線索四：蘇聯解體的同構判決
同年（1991）蘇聯解體——1917 案的「計畫計算」輸給「市場 + 價格」（哈耶克的信息論證）+ WWW 的「分散網路」誕生——**集中計算的失敗與分散網路的勝利同年**。歷史的註腳：組織的未來是網路（Castells 1996《網路社會的崛起》）：科層金字塔 → 平面網路——企業、媒體、政治的組織形態都朝網路演化。

## 結案 -- 後果與影響
- **全球化 2.0**：供應鏈、外包、WTO——全球經濟的網絡化；中國崛起為世界工廠。
- **企業邊界的縮小**：虛擬企業、平台（2007 案）——組織形態的網路化。
- **信息的民主化與過載**：信息接近免費 → 注意力稀缺（2004 案）——「信息的豐富造成注意力的稀缺」（Simon 1971）。
- **數位鴻溝**：上網與不上網的階層線——新的不平等軸。
- **組織的網路化**：科層 → 網路——開源軟體（Linux）、跨國團隊——「網路社會」的組織學。
