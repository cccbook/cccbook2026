# 476-西羅馬崩潰與封建莊園

## 案件摘要
476年，日耳曼將領奧多亞克廢黜西羅馬末帝——西羅馬帝國正式落幕。偵辦這樁「文明倒退」案件會發現：崩潰的關鍵是**經濟網路的解體**——貿易萎縮、貨幣消失、城市衰退，長距離交換的交易成本重新超過自給的收益。社會組織隨之「縱向化」：市場（非人格交換）讓位於莊園（人身依附）——農民以自由換保護，領主以土地換效忠。封建制不是野蠻倒退，而是「交易成本上升後的組織重構」——波蘭尼筆下市場從社會中「脫出」的鏡像案例。

## 前因 -- 為什麼會有這個案子
- **財政-軍事的螺旋**：三世紀危機（貨幣貶值、邊防軍費暴增、稅收崩潰）→ 貶值鑄幣 → 通膨 → 貴金屬外流 → 更重的稅 → 小農棄地投靠大莊園。
- **貿易網的萎縮**：帝國安全動盪 + 海盜 + 關卡林立，地中海貿易量下降——羅馬的城市糧食供應（埃及麥子）斷鏈。
- **城市衰退**：羅馬城從百萬人口跌到數萬；公共建築（浴場、劇場、道路）失修——城市是貿易與行政的載體，貿易死則城市死。
- **軍事外包的結構病**：日耳曼傭兵取代羅馬公民兵，軍權落入蠻族將領——476 只是「組織已被掏空」的追認。

## 線索與推理 -- 數學式、理論、表格

### 線索一：交易成本 = 組織形態的決定變數
科斯（1937）的原理可以反過來解釋崩潰：當**市場的交易成本**（運輸、安全、契約執行）上升到超過**內部組織的成本**，經濟活動就從市場移入自給組織：

$$\text{市場交易成本} > \text{自給組織成本} \implies \text{市場讓位於莊園}$$

羅馬的統治提供低交易成本（道路、法律、貨幣、和平）——崩潰後交易成本暴增，莊園自給是「理性回應」而非野蠻倒退。

### 線索二：封建契約 = 安全的買賣
封建制的核心交換：

| 給出 | 換得 |
|------|------|
| 農民：勞役 + 收成的部分 | 領主的保護 + 土地耕作權 |
| 附庸：軍事效忠 | 領主：采邑（fief）土地 |
| 領主：效忠國王 | 國王：封地 + 豁免 |

**推理**：當公共安全（國家提供）消失，安全變成私人財貨——「保護」成為可交易的服務，封建制是安全市場的人身化組織。韋伯：封建 = 武裝的契約依附；馬克思：封建 = 人身依附的生產關係——兩者都指向「國家失能後的組織重構」。

### 線索三：莊園的自給數學
莊園盡量自給：糧食、布匹、工具、鹽、鐵都在莊園內解決。理由：外部採購的「運輸+劫掠風險+無契約執行」成本高於內部生產。剩餘被窖藏（金銀不流通）而非投資——貨幣經濟退化為實物經濟，市場半徑縮到村落周邊的集市。

### 線索四：與中國崩潰的對照
同時代的西晉崩潰（316）與五胡亂華，中國經歷類似的莊園化（塢堡、部曲、門閥），但**文書行政與官僚傳統**未斷（北魏均田制、隋唐科舉重建），故能復歸官僚帝國；西羅馬的行政傳統斷裂（拉丁文書吏文化由教會勉強保存），重建花了五百年——**制度技術的可保存性**決定復原速度。

## 結案 -- 後果與影響
- **封建世界的三百年**（476-1000）：莊園、采邑、人身依附——歐洲的「權力碎片化」時代，王權徒有其名。
- **教會接管行政與文化**：修道院保存文字、法律與農業技術（本篤會）——「文明的火種」由宗教組織保管，教會成為最大的「封建領主」。
- **市場的蟄伏與反攻**：950 農業革命與 1100 商業革命（城市、行會、複式記帳）是本案的鏡像續集——當交易成本重新下降，市場與城市反攻，封建逐步瓦解。
- **理論的鏡像**：波蘭尼《大轉型》描述市場「脫嵌」於社會；本案是其反面——社會「吞回」市場。兩案合看，交易成本是擺鐘的軸。
