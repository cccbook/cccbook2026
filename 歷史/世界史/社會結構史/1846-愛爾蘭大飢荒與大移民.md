# 1846-愛爾蘭大飢荒與大移民

## 案件摘要
1845-1849 年，馬鈴薯晚疫病（Phytophthora infestans）襲擊愛爾蘭——人口從 850 萬降到 655 萬（百萬餓死、百萬移民），1841-1900 年移民總數逾 400 萬。這樁「單一作物」案件是社會結構的跨洋重構：愛爾蘭農民靠一英畝馬鈴薯過活（1550 案的人口爆炸）——單一化的脆弱結構 + 英國政策的自由放任（穀物法 1846 同年廢除——糧食出口未禁止）= 史上最慘飢荒之一。移民改寫了美國的社會結構：波士頓、紐約的愛爾蘭勞工、天主教堂網、政治機器（Tammany Hall）——**移民是社會結構的出口閥與輸入管**：愛爾蘭失去人口，美國得到城市工人階級與天主教少數。

## 前因 -- 為什麼會有這個案子
- **馬鈴薯的單一化**（1550 案）：愛爾蘭農民（土地被地主持有）只靠 lumpers 品種 + 一英畝——熱量全依賴馬鈴薯（人均日食 4-6 公斤）。
- **晚疫病的入侵**：1845 病原從美洲（墨西哥）經比利時傳入——單一品種無抗性——遺傳多樣性的零緩衝。
- **政策的失靈**：英國的自由放任（Peel 的玉米救濟 1846 止、Russell 的市場路線）+ 穀物法廢除（1846/6）——「市場 vs 救濟」的意識形態災難（Sen 1981 的權利分析：糧食在，交換權利不在）。
- **地主的系統**：外地地主（absentee landlords）+ 佃農——土地結構的掠奪性（飢荒中仍強制遷出欠租佃戶）。

## 線索與推理 -- 數學式、理論、表格

### 線索一：單一化的脆弱結構
愛爾蘭農民的熱量結構（1845 前）：

| 來源 | 占熱量比 |
|------|---------|
| 馬鈴薯 | 80%+ |
| 燕麥/牛奶 | 少量 |

**推理**：單一品種（lumpers）× 單一作物（馬鈴薯）= 零冗餘系統——病原入侵（Phytophthora）→ 系統全崩（1550 案「單一化 = 脆弱化」的實證——與 2020 案供應鏈單一化的同構）：

$$\text{系統脆弱性} \propto \frac{1}{\text{品種與作物多樣性}}$$

### 線索二：Sen 的權利分析——飢荒是分配問題
Sen（1981）：飢荒的關鍵不是糧食總量，而是**交換權利**（entitlement）——

$$\text{飢餓} = f(\text{交換權利失效})，\ \text{非} f(\text{糧食總量})$$

**推理**：飢荒期間愛爾蘭仍**出口糧食**（小麥燕麥）——糧食在，但農民無錢買（失業 + 物價漲）→ 交換權利失效 → 餓死。英國政策的自由放任（不干預市場）讓「分配機制」失靈——飢荒是社會結構（誰有權利取得食物）的災難，不只是天災。

### 線索三：大移民——社會結構的出口閥
1841-1900 移民 400 萬+（美國為主，加拿大、澳洲）——

| | 愛爾蘭 | 美國 |
|---|--------|------|
| 人口 | 850 萬 → 655 萬（-23%）| 愛爾蘭裔 1900 年達 400 萬+ |
| 城市 | 人口崩潰 | 波士頓、紐約的愛爾蘭區（Fives Points）|

**推理**：移民是「人口過剩與災難的出口閥」——愛爾蘭的社會結構被掏空（農村凋敝、晚婚與獨身文化——移民壓力下的低生育傳統）；美國得到城市工人階級——**移民 = 社會結構的跨洋重構**（兩岸同時改寫）。

### 線索四：美國的愛爾蘭社會
- 天主教堂網（1840s-50s 教區爆炸——移民的社會骨架）；
- 政治機器（Tammany Hall——愛爾蘭選票 → 城市政治機器）→ 美國城市政治的民主黨基礎；
- 勞動市場：鐵路、運河、女傭——底層勞動；排斥（「No Irish Need Apply」）→ 逐步上移（警察、消防、政治）——移民的階層爬升軌跡（三代：勞工 → 公務 → 專業）。

**推理**：移民的社會結構 = 教堂（社群骨架）+ 政治機器（權力通道）+ 勞動階層（經濟起步）——移民融入的「三件套」，成為後續移民（義大利、猶太、拉丁）的重演模板。

## 結案 -- 後果與影響
- **愛爾蘭的百年人口萎縮**：850 萬 → 20 世紀末 400 萬（含北愛）——史上少見的人口長期下滑——社會結構的深層改寫（家庭、語言、宗教）。
- **美國的天主教少數**：愛爾蘭天主教 → 美國天主教會的骨幹——新教美國的宗教結構重構。
- **城市政治機器**：Tammany 模式 → 移民政治的標準模板——美國城市民主的結構。
- **政策的教訓**：Sen 的權利分析 → 發展經濟學與災害治理——「分配重於總量」的飢荒理論。
- **移民的全球化**：1846-1924 歐洲移民潮（6000 萬人）的先聲——「移民 = 社會結構的出口閥」的世紀（大西洋移民系統）。
