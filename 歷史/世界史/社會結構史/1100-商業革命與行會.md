# 1100-商業革命與行會

## 案件摘要
1050-1300 年，歐洲爆發商業革命：自治城市（「城市的空氣使人自由」）、行會、香檳集市、銀行與**複式記帳**——中世紀的市場從村落集市長成國際網絡。偵辦此案的核心線索是**記錄技術**：複式記帳（每一筆交易記兩次：借與貸）讓商業第一次「可以計算」——企業的損益、資產與負債可以核對。桑巴特稱複式記帳為「資本主義的計算精神」，韋伯視之為理性化的標誌。這是從「人情商業」到「計算商業」的組織革命，股份公司（1602 案）與金融革命（1688 案）都在其上。

## 前因 -- 為什麼會有這個案子
- **農業剩餘已就緒**（950 案）：人口倍增、城市復興——貿易的貨物與人力基礎。
- **安全改善**：封建秩序局部穩定，君主與城市提供武裝護送——長途貿易的「安全成本」下降。
- **法律創新**：商法（lex mercatoria）與集市法庭讓商人糾紛快速裁決——契約執行的司法硬體。
- **記錄的瓶頸**：單式記帳（流水帳）無法核對盈虧、無法查錯——合夥貿易（多人出資、跨季遠航）需要可計算的帳目。

## 線索與推理 -- 數學式、理論、表格

### 線索一：複式記帳 = 商業的計算機
複式記帳的核心：每筆交易記錄兩個帳戶（借方 debit / 貸方 credit），恆等式：

$$\text{資產} = \text{負債} + \text{資本} \quad (\text{借方總和} = \text{貸方總和})$$

**為什麼重要**：
1. **可核對**：兩邊不相等 → 必有錯誤——帳目自帶校驗碼；
2. **可計算盈虧**：期末結帳可算出損益——商業第一次可以「量化管理」；
3. **可委託**：帳目可稽核 → 股東可委託經理人——所有權與經營權分離的前提。

這是「企業」作為計算對象的誕生：複式記帳之前，「企業」是模糊的人情集合；之後，它是一個可以計算損益的帳戶集合。

### 線索二：自治城市 = 契約的島嶼
「城市的空氣使人自由」（Stadtluft macht frei）——農奴住滿一年零一天即自由。城市向領主買下自治權（特許狀），自設法庭、自選市長：

| 制度 | 功能 | 經濟效應 |
|------|------|---------|
| 特許狀 charter | 自治的法律依據 | 財產權保護 |
| 市政法庭 | 快速商業裁決 | 契約執行成本低 |
| 自由身份 | 人身自由 | 勞動力流動 |

**推理**（Greif、North 的制度經濟學）：城市是「契約執行」的技術島——在王權無力保護財產的碎片化封建世界，城市用自治特許創造了**可信的商業環境**。

### 線索三：行會 = 技能的組織化
行會（guild）：同業工匠的壟斷組織——學徒（7 年）→ 伙計 → 師傅（masterpiece 之作）。功能：品質管制（拒收劣品）、定價（禁止削價）、訓練（技能傳承）、互助（喪葬救濟）。
**推理**：在沒有專利法與職業學校的世界，行會是**技能的知識產權 + 保險 + 工會**三合一組織——人力資本的制度載體。代價：壟斷與創新抑制（拒絕新技術的記錄屢見）。

### 線索四：金融技術的萌芽
- **匯票**（bill of exchange, 13 世紀義大利）：避免攜帶現金——異地兌付的信用工具；
- **合夥**（commenda）：一方出資不出力、一方出力不出資，利潤分帳——風險資本與人力資本的契約結合；
- **美第奇銀行**（1397）：分行制 + 複式記帳——跨國銀行的組織原型。

## 結案 -- 後果與影響
- **資本主義的計算精神**：桑巴特（1902）、韋伯（1905）視複式記帳為理性化與資本主義精神的標誌——「可以計算」是資本主義的認知前提。
- **股份公司的路徑**：複式記帳 + commenda 合夥 → 1602 東印度公司（股份制 + 證交所）——本案是現代公司的史前史。
- **大學與知識階層**：城市剩餘養活大學（波隆那 1088）——知識職業從修道院走向城市。
- **勞動力的分化**：行會工匠 vs 雇工 vs 農民——城市社會的三層結構，與鄉村封建階層並行——階級的「城市變體」誕生。
