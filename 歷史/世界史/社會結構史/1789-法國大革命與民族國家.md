# 1789-法國大革命與民族國家

## 案件摘要
1789 年 7 月 14 日，巴黎民眾攻陷巴士底獄。這樁「革命」案件是現代政治的誕生：**公眾輿論**（印刷沙龍、報紙、咖啡館——哈伯瑪斯的公共領域）第一次成為政治力量；**徵兵制**（levée en masse，1793）把全體人民變成戰爭主體——民族（nation）取代王朝成為政治共同體；**人權宣言**（8 月 26 日）把正當性從君權神授改寫為人民主權。拿破崙法典（1804）與行政中央集權把革命成果制度化——現代民族國家的作業系統自此安裝，並隨拿破崙戰爭輸出全歐。

## 前因 -- 為什麼會有這個案子
- **財政破產**：七年戰爭與援助美國獨立的債務——王室財政崩潰，三級會議（1789/5）被逼召開——「錢袋危機」引爆政治危機。
- **階層的僵固**：第一、二等級（教士、貴族）免稅特權 vs 第三等級（平民）承擔稅負——特權社會的正當性危機。
- **公眾輿論已成形**：印刷術（1440 案）+ 沙龍、咖啡館、《百科全書》（1751-72）——啟蒙思想與輿論空間就緒（哈伯瑪斯的公共領域）。
- **美國獨立的示範**：1776 獨立宣言 + 1787 憲法——「人民主權 + 成文憲法」的可行性已驗證。

## 線索與推理 -- 數學式、理論、表格

### 線索一：公眾輿論 = 新的政治主體
哈伯瑪斯（1962）的「公共領域」理論：沙龍、報紙、咖啡館形成**介於國家與私人之間的輿論空間**——政治討論第一次不依賴宮廷。

$$\text{印刷媒體（1440 案）} + \text{識字擴張} \implies \text{公眾輿論} \implies \text{政治動員能力}$$

**推理**：輿論讓「民意」成為正當性的來源——巴士底獄之後，「人民」取代「王」成為主權主體。這是媒體 → 政治的結構性鏈條（1517 案的宗教版 → 本案的政治版 → 2004 案的數位版）。

### 線索二：徵兵制 = 民族的動員
1793 年 levée en masse（全民徵召）：兩年內動員 60 萬+ 大軍（歐洲史上最大）。

| | 王朝軍隊 | 民族軍隊 |
|---|---------|---------|
| 來源 | 傭兵 + 貴族軍官 | 全民義務 |
| 忠誠 | 領餉/效忠王 | 為民族而戰 |
| 規模 | 數萬-十萬 | 數十萬-百萬 |
| 政治共同體 | 王朝（dynasty）| 民族（nation） |

**推理**（安德森）：為「民族」而戰需要**民族**的想像——印刷資本主義（1440 案）的方言共同體 → 民族認同 → 民族軍隊 → 民族國家。徵兵制是「民族」的政治-軍事硬體。

### 線索三：人權宣言 = 正當性的改寫
《人權與公民權宣言》（1789/8/26）：「人生而自由平等」——正當性從**君權神授**改寫為**人民主權 + 自然權利**。

$$\text{正當性}：\text{神授（傳統）} \to \text{人民主權（法理 + 民意）}$$

推理：這是漢摩拉比案（正當性 = 神授 + 條文）之後，正當性結構的最大改寫——「人民」成為規範性概念的源頭（民主、民族自決、人權）。

### 線索四：拿破崙的制度化輸出
拿破崙法典（1804）：法律面前人人平等、財產權、世俗婚姻——革命成果的條文化；行政中央集權（省長制）、大學與高中制度——現代國家的行政骨架。拿破崙戰爭（1803-15）把法典與行政模式輸出全歐——**現代國家的作業系統被強制安裝**到被征服各國。

## 結案 -- 後果與影響
- **民族國家的世紀**：民族主義 → 1848 革命、德義統一、殖民帝國——「民族」成為 19-20 世紀政治的基本單位（1618 案的主權體系 + 本案的民族動員）。
- **平民的政治化**：普選的漸進擴張（1848、1871、1918）——大眾政治的起點。
- **革命譜系**：法國革命 → 1848、巴黎公社（1871）、俄國革命（1917 案）——「革命」成為政治變遷的模式。
- **國家能力的升級**：徵兵、稅收、戶口（拿破崙時期的統計）——「現代國家」的行政能力（Weber 的理性國家）。
- **媒體與革命的鏡像**：印刷輿論（本案）→ 電報新聞（1844 案）→ 社交媒體革命（2004 案阿拉伯之春）——媒體速度決定動員規模。
