# -0480 薩拉米斯海戰：窄水裡的數學題

## 案發現場

-480 年，薛西斯傾波斯帝國之力水陸並進（陸軍號稱數百萬、實約二十萬上下；艦隊一千二百餘艘）。溫泉關三百斯巴達勇士與其盟軍死守隘口三日後全滅，雅典棄城，波斯進入阿提卡。雅典人已按地米斯托克利（Themistocles）的計畫全體遷往薩拉米斯島與艦上，聯軍艦隊（約三百七十艘）泊於薩拉米斯與本土之間的窄海峽。波斯艦隊入峽合圍，一夜對峙後，次日（9 月末）決戰：波斯的數量優勢在窄水裡無法展開，希臘三列槳艦撞角戰術收割，波斯潰敗、艦隊折損過半，薛西斯主力撤回亞洲。次年普拉提亞陸戰，希臘全勝——波斯入侵希臘徹底失敗。

> **希臘人是被逼到絕路，還是地米斯托克利把絕路設計成了陷阱？——數量優勢為什麼會在窄水裡反過來殺死自己？**

## 偵查過程

**線索一：溫泉關的戰略意義（三百人換十個月）。** -480 年夏，斯巴達王列奧尼達率三百親衛（另有數千盟軍）守溫泉關隘口：地形一夫當關，波斯正面攻擊連日無效，最後由當地人引小路迂迴包抄，守軍腹背受敵、除殿後者外撤離，三百勇士死戰殉關。偵查結論：隘口戰的價值是**遲滯＋信息＋士氣**三重——陸軍被拖住數日（艦隊同時在阿提密西翁消耗戰），希臘各邦獲得動員時間；「以寡擊眾」的敘事成為希臘全境的士氣資產；波斯也知道了：希臘人會死戰，勸降窗口關閉。三百人的軍事損失可忽略，其戰略產出極高——**遲滯作戰的交換比不在屍體上，在時間表上**。

**線索二：地米斯托克利的騙術（假情報逼戰）。** 聯軍會議上多數將領（尤其伯羅奔尼撒諸邦）主張退守科林斯地峽——放棄阿提卡。地米斯托克利無力說服，於是派家僕潛往波斯營中帶話：希臘艦隊要趁夜逃走，波斯若封峽口可全殲。薛西斯下令入峽合圍、封鎖出口——退路斷絕後，希臘人想走也走不了，聯軍被迫留在窄水決戰。偵查結論：這是**用敵人的手實施軍事紀律**——聯軍的分歧（撤退派與決戰派）由波斯替地米斯托克利裁決；封峽的波斯自己堵死了自己的機動空間。對照馬拉松（參見 [../希臘史/-0490-馬拉松戰役.md](../希臘史/-0490-馬拉松戰役.md)）：那一戰雅典賭的是「敵人等不及」，這一戰賭的是「敵人一定會追」——兩次都靠讀懂帝國的決策函數。

**線索三：三列槳戰艦與窄水的物理學。** 三列槳戰艦（trireme）長約三十七米、槳手一百七十人三層坐槳、輕殼高速，武器是船首撞角——戰術靠機動：切入敵舷撞擊或掠過折斷敵槳，使敵艦癱瘓。波斯艦隊更大更舊（含被征服的腓尼基、埃及、愛奧尼亞分隊），人數多但水道窄（薩拉米斯海峽寬不足兩公里），展開後前後自擠、命令難達；希臘艦熟悉潮汐與風向（狄俄斯庫里風清晨從峽內吹出，攪亂波斯隊形），以逸待勞。偵查結論：**數量優勢是展開係數的函數**——開闊海域，艦多即戰力多；窄水裡，同時能接戰的艦數有上限，後排不僅無用，還在前排潰退時自相撞擊。戰場寬度 W 決定同時交戰數 n，n 之外的都是負資產：

```
實際戰力 ≈ min(艦隊總數, 戰場寬度允許的展開數) × 單艦素質。
薩拉米斯：波斯 1200 × 低展開 × 低熟悉度 < 希臘 370 × 滿展開 × 高熟悉度。
地形把數量優勢項清零——帝國的規模，在幾何面前無效。
```

**線索四：海權論的希臘章（勞民傷財的艦隊從哪來）。** 雅典原本無大艦隊；-483 年勞里昂銀礦新礦脈開採，國庫進帳一百塔蘭特，多數議員主張分紅，地米斯托克利力排眾議：**全數投入建艦**（約二百艘三列槳艦）——「為對付埃伊納建艦」是其政治包裝，實際防的是波斯。棄城入海（阿提卡人口全遷）則是「海權城市」的徹底化：雅典的城就是船。偵查結論：這是**一次改變政體命運的財政決策**——艦隊由最下層公民（thetes）划槳，海權反過來擴大了這個階級的政治分量（參見 [../世界簡史/-0508-雅典民主與海權.md](../世界簡史/-0508-雅典民主與海權.md)）：划槳手是水兵也是選民。薩拉米斯之戰後，雅典海權與雅典民主互為因果——勞里昂的銀子買下的不是船，是一種政體的未來。

## 結案報告

1. **遲滯的價值**：溫泉關三百人換的不是傷亡比，是時間與士氣——隘口戰的產出寫在時間表上。
2. **借敵之手**：假情報讓波斯替聯軍做出「留下決戰」的決定——紀律外包給敵人，是說服術的極致。
3. **幾何殺死規模**：窄水展開上限把一千二百艘清成一線——數量優勢是戰場寬度的函數。
4. **海權的財政根源**：銀礦不紅利而建艦——一次預算決策決定政體（海權民主）與帝國（雅典帝國）的雙重未來。

**戰力公式（code block）：**

```
有效戰力 F ＝ min(平台數 N, 戰場寬度 W 允許展開數 n) × 單位素質 q。
開闊海：N 大者勝；窄水：q 高且熟悉 W 者勝。
波斯 N=1200、q 混成；希臘 N=370、q 高、W 熟悉。
F波斯 ≈ n × q混 < F希臘 ≈ 370 × q高。
```

**結論：** 薩拉米斯案的本質是把馬拉松的戰術原理搬到戰略層級：希臘輸不起消耗（帝國體量百倍），所以把決戰設計成**一次性的幾何陷阱**——窄海峽是刪掉波斯數量優勢的除數，假情報是讓敵人自願入局的鑰匙，勞里昂銀礦是十年前就付清的學費。薛西斯敗退時大概仍不解：為什麼一千二百艘會輸給三百七十艘。答案不在船，在制度：划槳的是選民，選民守的是自己的城（雖然那城此刻就是船）。帝國的規模撞上城邦的密度，愛琴海的故事就此改寫——而雅典海權的帝國化陰影（參見 [../希臘史/-0478-提洛同盟.md](../希臘史/-0478-提洛同盟.md)），也從這場大勝里同時出發。
