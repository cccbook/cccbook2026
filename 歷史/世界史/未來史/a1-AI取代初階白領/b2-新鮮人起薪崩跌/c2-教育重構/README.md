# c2-教育重構

> 樹葉節點：[a1/b2-新鮮人起薪崩跌](../../) 的終點——**如果教育重構發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 教育 | 課程的重寫：判斷力、實作、倫理取代可編碼技能；「個別化學習」（AI 家教）常態 |
| 經濟 | 大學的產業重構（招生崩塌、合併與轉型）；微學位與證照的興起 |
| 組織 | 「學習與工作」的界線消失——企業成為「帶薪學習」的主要場域（反向恢復學徒制） |
| 心理 | 「為什麼要讀書」的答案重寫——從「文憑」到「判斷力與意義」 |
| 政治 | 教育補貼的轉向（從大學到終身學習）——與 [a2/b1/c1-可相容性工程](../../../a2-少子化的引擎/b1-女性高學歷與機會成本/c1-可相容性工程與生育率回升/) 交叉 |

## 上游（傳導回顧）

起薪崩跌（b2）→文憑雙重貶值→教育的市場壓力→「重寫或關閉」的分流——教育重構是「重寫」的枝。

## 觀察指標

- 大學的合併/關閉數與科系收起。
- 企業內訓與「帶薪學徒」的規模（反向恢復的訊號）。
- 微學位與證照的認可度（雇主的採用）。

## 不確定性

- 教育的重構速度慢於勞動市場——「錯配期」（課程教舊技能）可能是長期常態。
- 「判斷力教育」的可規模化存疑（師資與成本）——重構可能只服務精英。
