# c1-世代政治引爆

> 樹葉節點：[a1/b2-新鮮人起薪崩跌](../../) 的終點——**如果世代政治引爆發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 政治 | 「世代政黨」的誕生（青年聯盟 vs 老年選民）；選舉權年齡與「世代代表」的修憲討論 |
| 財政 | 學貸免除、青年住房、就業補貼的政策戰場——與 [a7/b2/c1-年金擠壓](../../../a7-壽命革命與老齡化/b2-老齡化加深/c1-年金擠壓投資與財政死結/) 的老齡支出正面對撞 |
| 經濟 | 「世代轉移」的政策化（遺產稅、房產稅）——與 [a7/b1/c2-繼承延後](../../../a7-壽命革命與老齡化/b1-健康年限延長/c2-繼承延後與青年財富階梯斷裂/) 交叉 |
| 社會 | 世代對立的敘事（「被偷走的一代」vs「不放手的世代」） |
| 心理 | 「等待繼承」與「躺平」的混合——時間偏好的世代重構 |

## 上游（傳導回顧）

起薪崩跌（b2）→「讀書改變階級」契約撕毀→世代政治的燃料：**青年的「階梯斷裂」（職業+財富）是政治地震的地質條件**。

## 觀察指標

- 世代政黨/青年運動的組織與得票。
- 「世代條款」立法（遺產稅、住房）的進度。
- 世代間的房產與財富持有差距統計。

## 不確定性

- 世代政治可能被其他分裂（階級、族群）覆蓋——歷史上「世代」很少是主戰場（1960s 例外）。
- 政策的讓步（學貸免除等）可能化解——引爆不必然。
