# c1-資深人才斷供與組織空心化

> 樹葉節點：[a1/b1-學徒階梯斷裂](../../) 的終點——**如果資深人才斷供與組織空心化發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 組織 | 中層空洞化；組織依賴「老將＋AI」雙層結構——單點失效風險（老將離職=組織斷電） |
| 經濟 | 資深判斷力的工資暴漲；「經驗」成為稀缺資本 |
| 教育 | 大學的價值重估：判斷力、實作與倫理的課程暴漲 |
| 政治 | 「人才斷供=國安」論述→學徒制的政策化（補貼初階職位保留） |
| 心理 | 「入行無門」的世代焦慮 |

## 上游（傳導回顧）

AI 取代初階（a1）→學徒階梯斷裂（b1）→十年尺度：老將折舊、無人補位——組織只剩頂端與 AI 工具。

## 觀察指標

- 組織的「老將依賴度」（單點失效的關鍵職缺數）。
- 資深人才的獵頭溢價與「顧問化」（退休返聘）。
- 學徒制政策的立法（補貼初階職位）。

## 不確定性

- 「AI 監督學徒」的反向設計可能重築階梯——空心化不必然持續。
