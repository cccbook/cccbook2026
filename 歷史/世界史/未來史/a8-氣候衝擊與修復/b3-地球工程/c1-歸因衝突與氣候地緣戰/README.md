# c1-歸因衝突與氣候地緣戰

> 樹葉節點：[a8/b3-地球工程](../../) 的終點——**如果歸因衝突與氣候地緣戰發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 地緣 | 氣候從「公共危機」變「地緣武器嫌疑」：受損方與動用方的對峙；反制工程（各自的 SRM 互相干擾） |
| 社會 | 天氣歸因的日常化；陰謀論的爆發——與 [a3/b1/c2-資訊封建化](../../../a3-AI治理與法律/b1-生成內容爆炸/c2-資訊的封建化/) 咬合（真實性稀缺使歸因更不可能） |
| 法律 | SRM 條約的缺位（治理真空的氣候版）——與 [a3/b2](../../../a3-AI治理與法律/b2-治理真空擴大/) 咬合 |
| 科學 | 副作用科學（環流、降水的區域效應）成為地緣知識 |
| 心理 | 「天氣被操縱」的集體焦慮 |

## 上游（傳導回顧）

地球工程（b3）的單方動用→「是不是他們幹的」的歸因戰場（與 [武器與戰法/2007-震網](../../../武器與戰法/2007-震網與網路戰.md) 的「誰攻擊了我」同構）——**氣候的地緣對峙**。

## 觀察指標

- 極端災害後的「氣候武器」言論頻率。
- 各國 SRM 監測與反制計畫的成立。
- 歸因科學的法庭與外交應用。

## 不確定性

- 歸因科學的成熟可能化解部分衝突——本節點最弱的一環。
- 「反制工程」的升級（各自 SRM 的互相干擾）可能失控——與核門檻鏈的混沌同構。
