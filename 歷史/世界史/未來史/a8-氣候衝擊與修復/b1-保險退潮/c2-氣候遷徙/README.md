# c2-氣候遷徙

> 樹葉節點：[a8/b1-保險退潮](../../) 的終點——**如果氣候遷徙規模化發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 人口 | 內部與跨國遷徙的規模化（農業帶移動+不可保地帶）——遷徙的政治 |
| 政治 | 「氣候難民」的法律地位（國際法無此類別）——與 [a3/b2-治理真空](../../../a3-AI治理與法律/b2-治理真空擴大/) 咬合 |
| 經濟 | 遷徙的成本與「接收區」的壓力（住房、就業）——與 [a2-少子化](../../../a2-少子化的引擎/) 的勞動互補（老齡國需要人） |
| 社會 | 遷徙的社會張力（民粹的反彈 vs 勞動需求）——與 [2042/2044 的移民] 交叉 |
| 心理 | 「失去家園」的世代創傷 |

## 上游（傳導回顧）

保險退潮（b1）→不可保地帶（c1）→農業帶移動+被棄地帶→遷徙的規模化——**外生衝擊重置人口的空間結構**。

## 觀察指標

- 氣候相關的內部移民統計（美國的縣際遷徙資料）。
- 「氣候難民」的國際法討論進度。
- 接收區的住房與勞動市場壓力。

## 不確定性

- 遷徙的政治反應（接收 vs 排斥）是本節點的分水嶺——與民粹的興衰連動。
- 「氣候遷徙」與「經濟遷徙」的界線模糊——統計與法律都難定義。
