# c1-軍隊無人化

> 樹葉節點：[a6/b1-兵源稀缺與無人機量產](../../) 的終點——**如果軍隊無人化發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 軍事 | 軍制重寫：兵役（人→技術員）、軍階（階級→技能）、後勤（彈藥→電池與頻寬）——「誰養得起決勝力量」的答案從「兵源」變「工業與算力」 |
| 科技 | 無人機產業的國防化；AI 末端制導與蜂群演算法 |
| 經濟 | 國防工業的量產化轉型；「作坊式戰爭」的軍隊版 |
| 社會 | 兵役契約的終結；「上戰場」的人群從青年變技術員——兵役的社會契約重寫 |
| 法律 | 自主武器的責任真空——與 [a6/b2-自主武器擴散](../../) 咬合 |

## 上游（傳導回顧）

兵源稀缺（b1）→機器的相對價格下降→量產與迭代→軍制的全面無人化——**「誰養得起決勝力量，誰定義政治」**（[武器與戰法/1884] 的成本-階級規律）的答案重寫。

## 觀察指標

- 軍隊的無人系統與人力比（軍制的重寫實證）。
- 兵役制的存廢討論（社會契約的重寫訊號）。
- 後勤結構（電池、頻寬、演算法）的預算占比。

## 不確定性

- 「機海對機海」的消耗可能使「便宜」失去意義（雙方都量產）——成本交換比的對稱化。
- 兵役制的社會契約可能被「技術員志願役」重寫而非終結。
