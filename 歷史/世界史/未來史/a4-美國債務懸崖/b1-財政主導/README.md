# b1-財政主導

> [a4-美國債務懸崖](../) 的下游節點——**如果美國走向財政主導發生**，下游分岔：[c1-通膨稀釋債務](c1-通膨稀釋債務/)、[c2-美元儲備地位動搖](c2-美元儲備地位動搖/)。

## 這個節點（如果發生）是什麼

債務大到利率政策服從財政需求：央行受壓維持實質負利率，通膨目標「彈性化」（容許 3–4%）——「以時間換債」成為唯一路徑。政治先動（緊縮與加稅都無選票），市場被動跟隨。

## 傳導與理論

$$\text{央行獨立性} \propto \frac{1}{\text{（債務/GDP）}}$$

金融抑制的歷史先驗（1945–1980 的戰後債務稀釋）：實質利率為負、儲戶與債券持有人承擔隱形稅——**「通膨是無淚的稅」**（由最沒有議價力的人支付）。

## 下游分岔（若…否則…）

| 環節 | 若 | 否則 |
|------|-----|------|
| 通膨的錨 | 3–4% 彈性錨→緩慢稀釋（c1） | 失錨→通膨預期失控→不僅稀釋、還有衰退 |
| 債權人的反應 | 緩慢配置轉移（黃金、實物）→動搖是斜坡（c2） | 一次事件觸發快速轉移→動搖是斷崖 |
| 政治的出口 | 一次財政危機使「痛苦換緊縮」→→[a4/b2-殖利率失控](../b2-殖利率失控/) | 財政主導持續 |

## 觀察指標

- 實質利率（名目減通膨預期）持續為負=財政主導進行中。
- 通膨目標「彈性化」的官方言論與章程修改討論。
- 央行獨立性的政治壓力事件頻率。

## 不確定性

- 「彈性錨」與「失錨」的邊界：通膨預期的臨界無法從現有資料確定——本節點最弱的一環。
- AI 紅利（[a1] 的 A1）若兌現，「增長消化」可能取代財政主導——分岔的相依性。
