# c1-通膨稀釋債務

> 樹葉節點：[a4/b1-財政主導](../../) 的終點——**如果通膨稀釋債務發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 經濟 | 實質負利率的常態；儲蓄行為重構（實物資產、黃金、比特幣↑） |
| 財政 | 「隱形違約」成為大國財政工具：通膨 3–4% 持續十年，債務比可降 20–30 個百分點 |
| 社會 | 固定收入者（退休者、債券持有人）承擔隱形稅——「通膨世代」的政治反彈 |
| 法律 | 央行獨立性的章程修改壓力——與 [a3-AI治理與法律](../../a3-AI治理與法律/) 的法律因素交叉 |
| 跨鏈 | 稀釋的「失信」是去美元化的動力——→[a4/b1/c2-美元儲備地位動搖](./c2-美元儲備地位動搖/) |

## 上游（傳導回顧）

財政主導（b1）→實質負利率→債務被通膨緩慢稀釋——「1945–1980 的金融抑制」的當代重演。

## 觀察指標

- 債務/GDP 比的年度變化（通膨項的貢獻）。
- 儲蓄結構的轉移（黃金、實物、加密的配置）。
- 「通膨預期」的調查統計（失錨的監測）。

## 不確定性

- 「彈性錨」的維持：通膨預期一旦失控，稀釋變成危機——本節點的臨界無法確定。
- 政治的反彈（通膨世代的選票）可能使政策反轉。
