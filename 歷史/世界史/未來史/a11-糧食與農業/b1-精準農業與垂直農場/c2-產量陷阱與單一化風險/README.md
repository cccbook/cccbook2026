# c2-產量陷阱與單一化風險

> 樹葉節點：[a11/b1-精準農業與垂直農場](../../) 的終點——**如果產量陷阱與單一化風險發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 生態 | 高產品種全球單一化→病原體的「單一大目標」；愛爾蘭大饑荒（馬鈴薯晚疫病）的規模化重演風險 |
| 經濟 | 種子與育種專利集中——卡路里的「晶片化」：少數公司控制全球主糧基因 |
| 政治 | 種子主權運動；種質庫（斯瓦爾巴末日種子庫）成為戰略資產 |
| 保險 | 系統性相關風險（一次病原體=全球同發）→不可保化 |

## 上游（傳導回顧）

技術平價（a11）→規模化催生經濟學的單一化壓力（最優品種贏者全拿）（b1）→多樣性被效率換掉→系統脆弱性累積。

## 理論

多樣性—穩定性的生態律：系統產出方差與品種多樣性負相關；單一化把「年年小損失」換成「低機率大崩潰」——塔勒布的**碎裂風險集中**，與金融的系統性風險同構。

## 觀察指標

- 全球主糧前五品種的種植面積集中度（HHI）。
- 商業種質庫與公共種質庫的基因多樣性指標。
- 植物病原新變種的跨洲傳播速度。

## 不確定性

- 精準育種也可以反向操作：快速導入抗病基因的多樣化（技術是雙刃——它製造單一化壓力，也提供多樣化的速度）。
