# b1-精準農業與垂直農場

> [a11-糧食與農業](../) 的下游節點——**如果精準農業與垂直農場跨過平價門檻發生**，下游分岔：[c1-農業脫土化與耕地地租崩跌](c1-農業脫土化與耕地地租崩跌/)、[c2-產量陷阱與單一化風險](c2-產量陷阱與單一化風險/)。

## 這個節點（如果發生）是什麼

農業的輸入從「土地＋天氣」變成「資本＋能源＋數據」：衛星與感測器逐株施肥（精準農業）、LED 全光譜補光與閉環水循環讓產量脫離緯度與季節（垂直農場）。荷蘭案例已證明：單位水用量的番茄產量可達傳統的十倍以上——**不是能不能，是貴不貴**。

## 傳導與理論

單位產量的成本結構改寫：

$$\text{每卡路里成本} = \frac{\text{資本折舊} + \text{能源} + \text{勞動}}{\text{產量}}$$

當「能源項」被太陽能＋電池壓到接近零、自動化吃掉「勞動項」，成本只剩資本折舊——農業變成**製造業**，而製造業的規模經濟與學習曲線（萊特定律：產量倍增、成本降固定比例）開始適用。

## 下游分岔（若…否則…）

| 環節 | 若 | 否則 |
|------|-----|------|
| 電力平價 | 植物工廠電力成本降到露天農業等值 → 脫土化（c1） | 只在高電價／缺水地區利基 |
| 生態管理 | 病蟲害多樣化防治成熟 → 可控 | 單一品種大規模化 → 系統性風險（c2） |

## 觀察指標

- 植物工廠的每公斤電力成本曲線（對照 LED 學習曲線）。
- 農業用地交易的價格／收益率變化（地租重估的前兆）。
- 大型農業科技公司對「設施農業」的資本支出。

## 不確定性

- 穀類（小麥、稻米）的光合效率使垂直化困難——先突破的是高值蔬果與蛋白（培養肉），主糧脫土可能晚二十年。
