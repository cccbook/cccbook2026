# b2-糧食地緣與出口禁運

> [a11-糧食與農業](../) 的下游節點——**如果糧食出口禁運常態化發生**，下游分岔：[c1-糧食自給軍備競賽](c1-糧食自給軍備競賽/)、[c2-綠色禁運與糧食人權](c2-綠色禁運與糧食人權/)。

## 這個節點（如果發生）是什麼

極端氣候連年減產＋地緣衝突（黑海穀物走廊的先例），使「糧食出口禁運」從偶發貿易事件變成常態化地緣工具。歷史劇本早已寫好：1980 年美國對蘇聯穀物禁運（失敗——蘇聯改從阿根廷買）、2008 與 2010 年糧價危機中二十餘國相繼禁出口——**禁運的第一受害者是禁運者自己的信譽**。

## 傳導與理論

糧食的政治數學：糧價漲幅與政局動盪的相關（2008、2011 阿拉伯之春前的糧價峰值）——

$$\text{政權穩定度} \propto \frac{1}{(\text{主糧價格相對基期})^{\alpha}}$$

購買力愈低（以恩格爾係數衡量）的國家，α 愈大：同樣漲三成，在恩格爾係數 0.5 的國家是政治事件，在 0.1 的國家是通膨數據。

## 下游分岔（若…否則…）

| 環節 | 若 | 否則 |
|------|-----|------|
| 禁運成效 | 主要出口國協調（如 OPEC 式糧食卡達爾）→ 禁運有牙齒（c1 加速） | 禁運被第三方轉口套利瓦解 → 工具失效 |
| 技術替代 | 進口國加速自給（b1 鏈）→ 籌碼貶值 | 替代緩慢 → 禁運反覆成功（c2 惡化） |

## 觀察指標

- 全球糧食出口限制措施計數（IFPRI 追蹤的現成指標）。
- 主要進口國的戰略儲備目標上修幅度。
- 糧食期貨的波動率與政治事件溢價。

## 不確定性

- 禁運常態化反而催生「糧食不結盟運動」與多邊儲備池——武器化的歷史結局常是制度化的反制。
