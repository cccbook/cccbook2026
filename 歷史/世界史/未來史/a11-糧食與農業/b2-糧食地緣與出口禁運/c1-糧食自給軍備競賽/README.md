# c1-糧食自給軍備競賽

> 樹葉節點：[a11/b2-糧食地緣與出口禁運](../../) 的終點——**如果糧食自給軍備競賽發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 貿易 | 自給率從經濟指標變國安指標：進口多元化＋海外農地收購（「買地不如買產量」）＋戰略儲備擴張 |
| 技術 | 缺地國家重押 b1 鏈（垂直農場、培養蛋白）——技術路線由國安預算補貼 |
| 金融 | 農地與農業基礎設施成為主權基金標的；「糧食安全溢價」進入資產定價 |
| 外交 | 與化肥、種子的供應鏈外交；肥料出口國（俄、中東）獲得新籌碼——**化肥是糧食的上游武器** |

## 上游（傳導回顧）

禁運常態化（b2）→各國把糧食當國防→自給率軍備競賽→低效但安全的本地產能擴張（糧食版「晶片補貼」）。

## 觀察指標

- 各國戰略糧食儲備天數的立法目標。
- 海外農地投資協議數量（土地掠奪資料庫）。
- 肥料與種子的出口管制措施。

## 不確定性

- 自給軍備競賽與 b1 技術平價互相餵養：競賽給了脫土化技術最初的補貼市場——武器化反而加速了去武器化。
