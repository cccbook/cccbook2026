# a9-核融合商業化

> 樹根節點（起火點：能源與工業）——**如果核融合發電跨過商業門檻發生**，下游分岔：b1-聚變電力平價、b2-聚變地緣重洗。

## 案件摘要

2022 年 NIF 點火增益首破 1（Q>1）；2024 年私人聚變融資累計破百億美元，CFS、Helion、TAE 相繼立下「幾年內供電」的軍令狀。聚變若商業化，不只多一種發電——它是**第一種「燃料成本趨近於零、選址不受地理限制」的基載電力**：海水裡的氘夠用億年，電廠可建在任何工業中心旁邊。本案的結論：**能源從「搶來的地租」變成「造出來的工業品」**——化石地緣政治的地基被抽掉，電價歸零邊際的分岔決定它是天堂還是電網災難。

## 起火點 -- 現況證據與觸發條件

- **證據**：NIF 科學增益達標（雖是慣性約束、非發電路徑）；高溫超導磁體（REBCO）把托卡馬克縮小到可融資尺寸；AI 電力需求（資料中心）給出第一個「不在乎貴、只在乎有電」的大客戶。
- **觸發條件**：工程增益（wall-plug Q>1、連續運轉）＋度電成本進入可融資區間＋首個併網 PPA 簽約。

## 下游分岔樹

```
a9-核融合商業化
├─ b1-聚變電力平價
│   ├─ c1-電力過剩與後稀缺工業
│   └─ c2-電網重構與棄光式浪費
└─ b2-聚變地緣重洗
    ├─ c1-化石政治的終結
    └─ c2-聚變供應鏈的新卡脖子
```

## 傳導與理論

勞森判據（點火的物理門檻）：

$$n \tau_E T > 3 \times 10^{21} \ \text{keV}\cdot\text{s}\cdot\text{m}^{-3} \quad \text{（密度×約束時間×溫度）}$$

物理達標≠商業達標，商業的算式是學習曲線：

$$C_n = C_0 \cdot n^{-b} \quad \text{（累計裝機翻倍，成本降固定比例）}$$

裂變的首堆昂貴、第十堆便宜——聚變若走模組化小堆路線， $b$ 值決定它是「下一個裂變」（越建越貴）還是「下一個光伏」（越造越便宜）。**分岔點不在物理，在製造路線**。

## 分岔的條件（若…否則…）

| 環節 | 若 | 否則 |
|------|-----|------|
| 製造路線 | 模組化量產→成本沿學習曲線下墜（b1） | 巨型一體堆→重演裂變的成本詛咒 |
| 電網跟進 | 儲能＋特高壓同步擴張→過剩變紅利 | 電網鎖定→棄電與負電價常態化（b1/c2） |
| 燃料與材料 | 氚增殖＋抗輻照材料過關→真・無限 | 卡在氚自持→「示範堆林立、商用堆缺席」 |
| 地緣反應 | 產油國提前轉型→軟著陸 | 財政斷崖→輸出動盪（b2/c1 的背面） |

## 交叉

- 與 [a8/b2-碳移除平價](../a8-氣候衝擊與修復/b2-碳移除平價/) 是**修復路的兩條腿**（過剩電力＋碳移除＝大氣修復的工程閉環）。
- 與 [a4-美國債務懸崖](../a4-美國債務懸崖/) 交叉（能源獨立改善貿易與財政；但聚變投資本身是財政下注）。
- 與 [a5-台海封鎖](../a5-台海封鎖/) 交叉（聚變若成，封鎖的「能源窒息」籌碼縮水——b2 的邏輯）。

## 觀察指標

- wall-plug 增益與連續運轉時數（商業化的物理訊號）。
- 首個併網 PPA 的度電價與融資結構（商業化的市場訊號）。
- 私人融資 vs 政府投入比（路線是模組化還是巨型堆）。
- 產油國主權基金的轉型持倉（地緣是否提前定價）。

## 不確定性

- 「幾年內供電」的承諾歷史上跳票成常態——本樹的時間表不可信，只給條件。
- 氚自持與材料壽命是兩個可能卡十年的暗礁——鏈條可能長期停在「示範堆」階段。
