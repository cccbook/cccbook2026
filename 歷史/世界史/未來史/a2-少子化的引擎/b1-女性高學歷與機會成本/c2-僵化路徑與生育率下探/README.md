# c2-僵化路徑與生育率下探

> 樹葉節點：[a2/b1-女性高學歷與機會成本](../../) 的終點——**如果僵化路徑與生育率下探發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 人口 | TFR 繼續下探（0.8 以下的新常態）；「人口動量耗盡」（世代縮小→適婚人口↓→出生數崩） |
| 經濟 | 勞動力稀缺的加速（→[a6/b1-兵源稀缺](../../../a6-戰爭形態的重寫/b1-兵源稀缺與無人機量產/)）；solo economy 的擴張 |
| 財政 | 年金與健保的算式惡化（→[a7/b2/c1-年金擠壓](../../../a7-壽命革命與老齡化/b2-老齡化加深/c1-年金擠壓投資與財政死結/)） |
| 社會 | 「不婚不生」的世代規範化；單人戶主流化（→[a7/b2/c2-照護真空](../../../a7-壽命革命與老齡化/b2-老齡化加深/c2-單人戶與照護真空/)） |
| 心理 | 「TFR 0.8 的世代認為 0.8 是正常」——規範的下移 |

## 上游（傳導回顧）

機會成本（b1）→可相容性工程失敗（托育不足、家務不分擔、職場歧視）→生育的相對價格繼續上升→下探。

## 觀察指標

- TFR 跌破 0.8 的國家數與「世代規模」的萎縮速度。
- 一人戶占比（破四成五=下探的確認）。
- 生育政策的「現金津貼」慣性（工具化轉向的缺席=僵化持續）。

## 不確定性

- 規範的反轉（嬰兒潮先例）可能截斷下探——需要「事件+意義」的組合，等價事件未知。
- 下探的「地板」未知：人類史上沒有 TFR 0.7 以下的世代存續樣本——**地板在哪裡是全書最大的未解之一**。
