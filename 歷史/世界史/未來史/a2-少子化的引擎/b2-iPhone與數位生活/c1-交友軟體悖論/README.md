## 上游（傳導回顧）

選擇悖論：選擇越多→承諾成本越高→「瀏覽而不承諾」的均衡——**市場的「高流量、低轉化」**。

## 觀察指標

- 交友軟體的「配對→承諾」轉化率（下降=悖論加深）。
- 「承諾型」平台（付費高門檻、審核制）的崛起。
- 初婚率的持續下降與「非婚同居」的比例。

## 不確定性

- 撮合的科學化（AI 配對優化）可能逆轉悖論——**選擇悖論是「設計問題」不是「技術宿命」**。
- 規範的重構（非婚生育的開放）可能使「承諾」與「生育」脫鉤——悖論對人口的影響減弱。
