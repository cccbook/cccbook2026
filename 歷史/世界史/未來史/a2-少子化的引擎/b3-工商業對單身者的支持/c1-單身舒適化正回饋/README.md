# c1-單身舒適化正回饋

> 樹葉節點：[a2/b3-工商業對單身者的支持](../../) 的終點——**如果單身舒適化正回饋持續發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 經濟 | solo economy 從利基變主幹：一人份供應鏈（餐飲、住宅、旅遊、保險）的全面化 |
| 社會 | 「單身」從過渡狀態變成「舒適的完整生活」——solo 的去污名化完成 |
| 人口 | 單人戶主流化（→[a7/b2/c2-照護真空](../../../a7-壽命革命與老齡化/b2-老齡化加深/c2-單人戶與照護真空/)）；婚育的前置動機再降 |
| 心理 | 「單身但有陪伴」（寵物、AI、朋友網）的生活設計——親密的多元化 |
| 跨鏈 | 與 [a7/b2-老齡化加深](../../../a7-壽命革命與老齡化/b2-老齡化加深/) 的年金與照護問題疊加 |

## 上游（傳導回顧）

正回饋迴路：越多人單身→市場越大→產品越精緻→越舒適→越少結婚——**迴路不會自行停止**，除非遇到「天花板」（育兒成本的下降、規範的反轉）。

## 觀察指標

- 一人戶占比（破四成五=回饋的成熟期）。
- solo 產業的市場規模與「單身者生活滿意度」。
- 寵物與 AI 陪伴的「替代性家庭」份額。

## 不確定性

- 迴路的天花板：育兒成本下降（a2/b4/c2）與規範反轉可能打破回饋——**單身舒適化與育兒可負擔化的賽跑**。
