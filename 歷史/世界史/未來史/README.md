# 未來史 -- AI 偵探風格

> 未來無法用年份標記——**時間無法確定，因果可以推理。**
> 本書是一棵**因果樹**：資料夾的層級就是因果的層級。
> - 第一層（a1、a2…）：**起火點**——「如果某件事情發生」；
> - 第二層（a1/b1、a1/b2…）：它造成的第一步後果（分岔）；
> - 第三層（a1/b1/c1、a1/b1/c2…）：後果的後果（再分岔）。
>
> 每個節點都是一篇「推理探案」：從現況證據出發，推演「如果這件事發生，整個世界會有什麼變化」，並在每一步標注「若…否則…」的分岔——**因果鏈從來不是單線，是樹；而這本書本身就是那棵樹。**

（涵蓋：AI 與勞動、少子化的引擎（iPhone、女性高學歷、單人經濟）、AI 陪伴、AI 治理與法律、美國債務、台海與晶片、戰爭形態、壽命與老齡化、氣候、核融合商業化、後量子密碼遷移、糧食與農業、太空資源）

## 方法論

1. **不武斷**：不寫「X 年會發生 Y」；只寫「如果 A 發生」＋觸發條件＋觀察指標。
2. **不單線**：每個節點都有分岔（子資料夾）；互斥的枝幹並列（例如「AI 陪伴→少子化加深」與「AI 育兒輔助→生育率回升」）。
3. **不孤立**：節點之間以「交叉」連結——因果樹是網路。
4. **理論優先**：每個節點寫出背後的理論（數學式、學術理論、表格），必要時才用範例——不硬寫程式。

## 樹枝之間的交叉（樹是網路）

- 「a2/b4-AI陪伴」餵養「a6/b1-兵源稀缺」（少子化→兵源）與「a7/b2-老齡化加深」（少子化→年金）。
- 「a4/b2-殖利率失控」與「a5-台海封鎖」互相放大（財政危機中的封鎖承受力更低）。
- 「a3/b1-生成內容爆炸」使「a3/b2-治理真空」更難修復（法律的執行依賴證據與共識）。
- 「a1/b1-學徒階梯斷裂」與「a7/b1/c2-繼承延後」是**同一條「青年階梯斷裂」**的兩個來源（職業階梯＋財富階梯）。
- 「a8/b2-碳移除平價」與「a8/b3-地球工程」是修復的兩條路（慢而穩 vs 快而險）。
- 「a9/b1-聚變電力平價」是修復路的第三條腿（過剩電力＋碳移除＝大氣修復的工程閉環）；「a9/b2-聚變地緣重洗」與「a5-台海封鎖」的能源窒息籌碼對沖。
- 「a10/b1-金融信任遷移」是「a3/b1-生成內容爆炸」的金融版（信任崩潰從資訊蔓延到結算）；「a10/b2-密碼主權爭奪」餵養「a6-戰爭形態的重寫」（軍令鏈路失明）。
- 「a11/b2-出口禁運」是「a5-台海封鎖」的糧食版（窒息戰的兩種窒息：晶片與卡路里）；「a11/b1-精準農業」的電力平價依賴「a9/b1-聚變電力平價」——電力是農業脫土化的上游；「a11/b2/c1-自給軍備競賽」給了「a11/b1」最初的補貼市場（武器化加速去武器化）。
- 「a12/b1/c2-太空自持經濟」與「a9/b1-電力過剩」是電力的兩條外溢路（軌道太陽能 vs 聚變）；「a12/b2/c1-太空軍備」餵養「a6-戰爭形態的重寫」（戰場立體化的終點）；「a12/b2/c2-軌道資源公用化」與「a3/b3-算力條約」同構——稀缺新場域的治理賽局；「a12/b1/c1-稀缺金屬反轉」對沖「a5/b1-晶片斷鏈」中的上游礦產籌碼。
- 「2030-CBDC」加速「a4-財政主導」（定向發錢的技術載體）；「2032-數位稅」緩解「a7/b2-年金死結」（新增財源）；「2031-平台拆分」與「2033-算法審計」是「a3-治理真空」的兩條收斂路；「2034-社保算法化」是「a7-老齡化」的公式化解方。
- 「2036-真實性基礎設施」是「a3/b1-生成內容爆炸」的補完（把信任變成簽章基礎設施）；「2038-自主武器條約」收束「a6/b2/b3」（保留人的扳機與核紅線）；「2041-氣候遷徙條約」接住「a8/b1-保險退潮」的人口後果；「2044-第二幕制度」重排「a7/b1-健康年限延長」的人生契約；「2052-人口下行總帳」結算「2048-人口峰值」，並與 a1（AI 紅利=年金繳款人）、a2（少子化引擎）、a4（債務懸崖）、a8（氣候遷徙補位）全部交叉。
- 「2037-電力配給」是「a9-聚變平價」到來前的過渡制度（窗口期有多長，配給就有多緊），並給「a3/b3-算力條約」提供談判起點（管電＋管晶片）；「2039-水糧配給」先於「2041-遷徙條約」（配得住就不必走，配不住才遷徙），並與「a5-封鎖窒息戰」互相抵押（晶片與卡路里是同一種戰爭的兩種彈藥）；「2040-照護機器人」接住「2034-社保算法化」沒解決的人手問題，並與「2044-第二幕制度」咬合（獨居可行年齡上移）；「2045-全齡教育」是「2044-第二幕制度」的施工圖（學費與文憑誰來認），供給側接住「a1/b1/c2-判斷力工資暴漲」的需求；「2050-財政清算」是「2052-總帳」的動工（先換規則與稅基，再算總帳），財源側靠「2032-數位稅」升級與「2037-算力配額」的新稀缺稅基。

## 閱讀方式

- 從任一樹根（a 節點）往下讀：每個節點是「如果這件事發生」的推理探案——現況證據→傳導與理論→分岔（若…否則…）→觀察指標→不確定性。
- 樹葉（c 節點）是鏈條的終點：寫的是「這個終點發生後，整個世界的變化總帳」。
- 用各節點的**觀察指標**追蹤現實：未來不是等來的，是查出來的。

本書與 [世界史]（多因咬合的過去）、[武器與戰法]（武器→戰法）、[科技發展史]（金觀濤的理論—實驗—技術循環）互補：**過去看迴路，未來推迴路**——過去的迴路自我完成，未來的迴路正在分岔；讀懂哪條迴路被點火，就讀懂了樹往哪邊長。
