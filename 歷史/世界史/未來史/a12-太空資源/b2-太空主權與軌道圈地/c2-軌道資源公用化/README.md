# c2-軌道資源公用化

> 樹葉節點：[a12/b2-太空主權與軌道圈地](../../) 的終點——**如果軌道資源公用化發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 制度 | 「太空版的國際海底管理局」：資源收益共享＋軌道槽位與著陸區的國際登記制 |
| 發展 | 深空基礎設施的公共財化：導航中繼、推進劑站對所有國家開放——太空的「公地良好管理」實驗 |
| 氣候 | 在軌太陽能納入全球脫碳組合；與 a8/b3-地球工程的協調治理共用同一套國際機制 |
| 商業 | 「許可證＋特許費」模式——圈地衝動被租約替代，先發優勢轉為先發特許 |

## 上游（傳導回顧）

圈地衝動（b2）→大國算出「軍備成本 > 收益共享成本」→重談成功→公用化制度。

## 觀察指標

- 收益共享條款的談判文本出現。
- 國際登記制的覆蓋率（著陸、採礦、軌道槽位）。
- 深空基礎設施的多邊出資結構。

## 不確定性

- 公用化的代價是效率：特許制可能拖慢開採，使整個 a12 鏈（含 b1）延後一個世代——**治理速度與技術速度的永恆賽局**（對照 a3/b3-c1）。
