# c2-太空自持經濟

> 樹葉節點：[a12/b1-小行星採礦與太空製造](../../) 的終點——**如果太空自持經濟發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 能源 | 在軌太陽能電站＋微波傳輸的示範（Caltech 2023 已完成首次在軌驗證）→ 地面電網的外生競爭者；與 a9-核融合的電力過剩劇本互為對沖 |
| 工業 | 推進劑補給站→深空航運網→「地球軌道＝港口城市」；微重力製造的獨家產品（特殊合金、蛋白藥物晶體） |
| 人口 | 常駐太空勞工階層出現；太空定居點的「母國」關係=公司城 vs 主權的百年之問 |
| 軍事 | 軌道工業設施成為戰略目標——與 a6-戰爭形態交叉：戰場的立體化終點 |

## 上游（傳導回顧）

商業迴路閉合（a12）→「太空用於太空」的內部迴路先閉合（b1）→推進劑、結構、能源不再從地球運→太空經濟自持→地球經濟的離岸化。

## 觀察指標

- 在軌製造與服務業的總營收佔太空經濟比重。
- 推進劑補給站的在軌數量。
- 微重力專利與「太空製造」產品的商品化清單。

## 不確定性

- 自持經濟可能是「小而肥」的利基（服務少數衛星與科學站），而非「大而廣」的文明分支——規模取決於發射成本下降的下限。
