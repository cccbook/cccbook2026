# 2034-社保算法化：長壽社會的給付重寫

## 案件摘要

**如果年金給付與長壽、物價、扶養比自動掛鉤（ Prosperity-indexed pension）並輔以全民基本收入底層，就會造成「政治不再能開空頭支票」，進而造成「代際契約從投票博弈變成公式治理」**——退休年齡與給付隨壽命自動漂移，政客的手被公式綁住。這條鏈與 [a_b_c/老齡化加深_年金擠壓投資_財政死結.md](a_b_c/老齡化加深_年金擠壓投資_財政死結.md)（財政死結鏈）互為解方：死結的鑰匙是自動穩定器。

## 起火點 -- 如果給付公式化發生

- **現況證據**：瑞典 NDC（名義確定提撥）、德國永續因子、日本宏觀經濟滑動機制——皆已是半自動掛鉤；2025–26 多國啟動基本收入地方試點。
- **觸發條件**：一次年金瀕臨斷付危機＋跨黨派「甩鍋給公式」的共識（政客樂於綁住自己的手）。

## 連鎖推演 -- A→B→C

### 第一步：給付自動掛鉤（人口⇒財政）

- 瑞典 NDC 機制：個人帳戶＋隨預期壽命調整年金除數——活得越久、每月越少（總額不變）：

$$\text{月給付} = \frac{\text{終身提撥累積} \times (1+r)}{\text{預期餘命除數}(e_x)} \times \text{平衡比}$$

- 平衡比（資產/負債）低於 1 自動砍給付——**政治承諾變成會計恆等式**（Samuelson 現收現付報酬 $n+g$ 的自動執行版）。

### 第二步：UBI 底層補網（財政⇒社會）

- 年金公式化只保「不破產」，不保「夠生活」——底層由部分基本收入（老年底層津貼）補足，財源來自數位稅與碳稅（見 [2032-全球數位稅.md](2032-全球數位稅.md)）。
- 給付兩層化：公式層（精算中性）＋底層（稅收支應）——**效率與兜底分開定價**。

### 第三步：代際契約公式化（社會⇒政治）

- 退休年齡與壽命掛鉤（丹麥模式：每多活一年、多做 8 個月）——「白髮抗議」的標的從政府變成數學。
- 選舉不再能承諾加給付（公式鎖死）——**民粹的提款機被關掉**，政治競爭轉向稅率與底層額度。

## 分岔 -- 每一步的「若…否則…」

| 環節 | 若 | 否則 |
|------|-----|------|
| 自動機制 | 觸發即執行（無裁量）→可信 | 國會保留否決→危機時照樣放水 |
| UBI 財源 | 數位碳稅落袋→底層可持續 | 財源落空→底層縮水、老年貧困 |
| 壽命分化 | 按階級差異除數→公平 | 統一除數→窮人補貼富人（短命補長命） |

## 整個世界的變化

| 領域 | 變化 |
|------|------|
| 財政 | 年金自動平衡；政治透支終結 |
| 社會 | 退休年齡漂移常態化；百年人生（見健康年限鏈）制度化 |
| 政治 | 加給付承諾絕跡；競爭轉向稅與底層 |
| 經濟 | 長壽風險定價進保費；私營養老第三支柱膨脹 |
| 倫理 | 壽命階級化（富人活更久領更多）的再分配爭議 |

## 觀察指標

- 各國年金平衡比與自動削減的觸發次數。
- 退休年齡與預期壽命掛鉤立法的國家數。
- 老年貧困率 vs 年金支出占 GDP 的剪刀差。
- UBI/底層津貼試點的財政評估報告。

## 不確定性

- 壽命階級差（高收入多活 5–10 年）使統一公式實質累退——公平性設計尚無共識。
- 政客在危機中「暫停公式」的前科（一暫停即永停）是本鏈最大風險。
