# b1-健康年限延長

> [a7-壽命革命與老齡化](../) 的下游節點——**如果健康年限延長（壓縮疾病率）發生**，下游分岔：[c1-退休契約重寫與百年人生](c1-退休契約重寫與百年人生/)、[c2-繼承延後與青年財富階梯斷裂](c2-繼承延後與青年財富階梯斷裂/)。

## 這個節點（如果發生）是什麼

壽命↑且「帶病年數」被壓縮（疾病擠到生命末端）——「70 歲的新 50 歲」：勞動能力的存量重估；「退休」的定義失效；繼承的時點延後。

## 傳導與理論

$$\text{健康年限} = \text{壽命} - \text{帶病年數} \quad \text{（壓縮疾病率 vs 延長帶病期——社會帳完全不同）}$$

「壓縮疾病率」兌現（GLP-1 外溢、senolytics、重編程）→健康的老年=勞動與消費的雙重紅利。

## 下游分岔（若…否則…）

| 環節 | 若 | 否則 |
|------|-----|------|
| 制度跟進 | 退休與年金的立法重寫→百年人生（c1） | 制度鎖定→「健康的沒工作」的錯配 |
| 財富的釋放 | 生前贈與的規範化→階梯部分修復 | 死後繼承為主→繼承延後（c2） |
| 分配 | 延長機會均勻→紅利 | 只有精英延長→**壽命的階級**（→[a7/b3-階級化壽命](../b3-階級化壽命/)） |

## 觀察指標

- 「60+ 健康工作年」的統計趨勢（壓縮疾病率的實證）。
- 退休年齡立法的進度與政治烈度。
- 繼承時點統計與「生前贈與」占比。

## 不確定性

- 「壓縮疾病率」的兌現是生醫前沿——本節點可能長期不滿足（帶病延年更可能→[a7/b2-老齡化加深](../b2-老齡化加深/)）。
