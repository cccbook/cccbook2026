# c1-退休契約重寫與百年人生

> 樹葉節點：[a7/b1-健康年限延長](../../) 的終點——**如果退休契約重寫與百年人生社會發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 法律 | 年金與退休契約的立法重寫（領取年數與繳費的再平衡）；年齡歧視法的重寫——與 [a3-法律因素](../../../a3-AI治理與法律/) 咬合 |
| 經濟 | 勞動供給的存量重估：「高齡經濟」的崛起；「一生兩三個職業」的多段式 |
| 教育 | 中年重返教育的常態（與 [a1/b2/c2-教育重構](../../../a1-AI取代初階白領/b2-新鮮人起薪崩跌/c2-教育重構/) 咬合） |
| 心理 | 百年人生的時間觀：儲蓄與風險的長期規劃回歸；「意義」的重新規劃 |
| 人口 | 生育時間窗延後——少子化的新變數（與 [a2-少子化的引擎](../../../a2-少子化的引擎/) 交叉） |

## 上游（傳導回顧）

健康年限延長（b1）→「退休」的定義失效→三段式人生（教育-工作-退休）重寫為多段式——**人生的節奏全面重構**。

## 觀察指標

- 退休年齡立法的重寫與「高齡雇用」的比例。
- 中年重返教育的註冊統計。
- 「多段式職涯」的調查（一生的事業數）。

## 不確定性

- 制度跟進的速度慢於健康年限——「錯配期」（健康的沒工作）可能是常態過渡。
- 「多段式」的機會可能只屬於精英——與 [a7/b3-階級化壽命](../../b3-階級化壽命/) 的分岔。
