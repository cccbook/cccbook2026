# 自主武器誤判_核門檻跨越_嚇阻體系重構

## 案件摘要

**如果自主武器的誤判引發核門檻跨越發生，就會造成「嚇阻體系的重構」**——核指揮體系的 AI 化使「誤判→核」的時間壓縮；一次「差點開戰」或「小規模跨越」的先例，改寫七十年的嚇阻均衡。這條鏈的終點是：核秩序的重新談判——或世界的重置。

## 起火點 -- 如果自主武器的誤判引發核門檻跨越發生

- **現況證據**：核預警與決策系統的 AI 化進行中；新飛彈（高超音速）壓縮決策時間（數分鐘內）；軍控條約真空（新 START 後無條約）。
- **觸發條件**：決策時間壓縮到「人類無法審核 AI 建議」＋誤判（演習/故障/干擾被讀為攻擊）＋「先發優勢」的誘惑（第一次打擊的論述）。

## 連鎖推演 -- A→B→C

### 第一步：自主武器誤判（戰爭⇒科技）

誤判的機率與速度：

$$\text{核風險} \propto \text{（AI 參與決策的比例）} \times \frac{1}{\text{（人的否決層）}} \times \text{（決策時間的壓縮倍數）}$$

與 [武器與戰法/1962-相互保證毀滅與博弈論](../武器與戰法/1962-相互保證毀滅與博弈論.md) 的「潛艇指揮官授權過大」同構——**授權與否決的設計**是核安全的新戰場。

### 第二步：核門檻跨越（戰爭⇒政治）

- 情境一（險釀）：誤判逼近、人類最後一層否決生效——**「差點開戰」的教訓**（古巴危機先驗的當代版）。
- 情境二（跨越）：小規模戰術核武的使用——**七十年禁忌的首次破裂**（[武器與戰法/1945-廣島與核時代](../武器與戰法/1945-廣島與核時代.md) 的核禁忌）。

### 第三步：嚇阻體系重構（政治⇒法律⇒全球）

- 情境一的後果：熱線與否決層的國際制度化（「人的否決」成為條約義務）——**嚇阻的升級**。
- 情境二的後果：核禁忌破裂→小規模核使用的「先例」→**擴散與使用的常態化風險**（與 [武器與戰法/1915-毒氣戰](../武器與戰法/1915-毒氣戰.md) 的「從使用到禁忌」反向：從禁忌到使用）——全球的重置（與 [1945] 的戰後秩序重建同構）。

## 分岔 -- 每一步的「若…否則…」

| 環節 | 若 | 否則 |
|------|-----|------|
| 誤判的結局 | 險釀（否決層生效）→教訓與重構 | 跨越（小規模使用）→禁忌破裂 |
| 跨越的規模 | 戰術核武、單點→國際制壓與談判 | 戰略核武、多點→全球重置 |
| 大國的反應 | 「不對稱升級」的克制（與 [武器與戰法/1962] 的古巴結局同構） | 對稱升級→互毀的邊緣 |

## 整個世界的變化

| 領域 | 變化 |
|------|------|
| 政治 | 嚇阻的重構：「人的否決層」條約化；核禁忌的破裂或強化 |
| 法律 | 核與 AI 的「責任」真空（誰下達、誰執行、誰負責）——與 [2046] 咬合 |
| 軍事 | 決策時間的壓縮與「預授權」的爭議；高超音速與防禦的競賽 |
| 全球 | 情境二：全球的重置（市場、聯盟、核擴散的連鎖）——與 [1945] 的戰後重建同構 |
| 心理 | 核焦慮的世代回歸；「末日鐘」的心理學 |

## 觀察指標

- 核指揮體系「AI 化」的公開程度（預授權的辯論）。
- 高超音速與預警時間的壓縮（誤判窗口的縮小）。
- 「人的否決層」的條約化進展（情境一的重構訊號）。
- 演習與故障的「險釀」通報（誤判的統計基數）。

## 不確定性

- 「險釀 vs 跨越」的機率無法推演（單一決策的混沌）——本卷不確定性之最。
- 跨越後的世界無歷史先驗（核禁忌破裂的後果鏈無法從 1945 推演——唯一的「樣本」不存在）。
