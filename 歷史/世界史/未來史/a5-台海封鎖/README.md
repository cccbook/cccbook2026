# a5-台海封鎖

> 樹根節點（起火點：戰爭與地緣）——**如果台海封鎖發生**，下游分岔：[b1-晶片斷鏈](b1-晶片斷鏈/)、[b2-窒息戰](b2-窒息戰/)。

## 案件摘要

先進製程約九成在台灣——晶片=新錫貿易（[武器與戰法/-3000] 的供應鏈短板規律）。封鎖是「可否認的戰爭」（以「檢疫」名義的海空封鎖，與 [武器與戰法/1943-大西洋狼群](../武器與戰法/1943-大西洋狼群與反潛.md) 的噸位戰同構）：不必登陸，只要斷流。如果封鎖發生，全球經濟進入「無聲的衰退」。

## 起火點 -- 現況證據與觸發條件

- **證據**：「檢疫式演練」與灰色地帶操作常態化；封鎖討論從沙盤推演變成公開論述；海外先進產能（美日德）在建但占比仍低。
- **觸發條件**：政治事件升級＋「可否認」的封鎖形式＋「封鎖比登陸便宜」的成本核算。

## 傳導與理論

供應鏈的短板規律：先進製程斷供=AI、手機、車用、國防的上游全停——**「錫斷供→兵器停擺」的當代版**。

封鎖的戰略算式：封鎖的成本（無人機與艦隊）≪ 登陸的成本；但封鎖的「可否認性」使國際反應的門檻模糊——**升級與否是政治判斷，無法推演**。

## 分岔的條件（若…否則…）

| 環節 | 若 | 否則 |
|------|-----|------|
| 封鎖的型態 | 灰色（檢疫式、可否認）→斷鏈緩慢累積 | 公開宣戰→直接衝突（→a6 的核門檻風險） |
| 全球庫存 | 高庫存產業撐一年→緩衝 | 即時化產業數週即斷 |
| 決戰的走向 | 封鎖長期化→窒息戰消耗（b2） | 快速攤牌→軍事衝突 |

## 交叉

- 與 [a4-美國債務懸崖](../a4-美國債務懸崖/) 交叉：財政危機中的封鎖承受力與防衛負擔。
- 與 [a6/b1-兵源稀缺與無人機量產](../a6-戰爭形態的重寫/b1-兵源稀缺與無人機量產/) 交叉：封鎖與反封鎖的無人機戰。
- 與 [a3/b3-算力條約](../a3-AI治理與法律/b3-算力條約/) 交叉：斷鏈可能加速「算力治理」的談判。

## 觀察指標

- 「檢疫式演練」的頻率與持續時間（封鎖的路徑累積）。
- 海外先進產能的落地比例（緩衝的大小）。
- 戰爭風險保險費率與貨櫃運費的跳升。
- 全球科技業「庫存天數」的回歸。

## 不確定性

- 「何時何地」不可預測——本樹只給條件與指標，不給日期。
- 海外產能的緩衝隨時間變化（越晚發生、緩衝越大）——後果依時點而異。
