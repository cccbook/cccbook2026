# c1-同盟承諾打折

> 樹葉節點：[a5/b2-窒息戰](../../) 的終點——**如果同盟承諾打折發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 地緣 | 同盟的「可信度」受疑：條約不必然兌現——**威懾的再定義**（自助的回歸） |
| 軍事 | 各國的軍備擴張（不依賴同盟的自主防衛）——核門檻討論的回歸（與 [a6/b3-核指揮](../../../a6-戰爭形態的重寫/b3-核指揮的AI化/) 咬合） |
| 經濟 | 「安全自給」的投資（防衛、供應鏈、能源）；中立化的壓力 |
| 政治 | 同盟體系的重新談判；「去美國化」與「去風險」的並行 |
| 財政 | 各國防衛支出的跳升——與 [a4-美國債務懸崖](../../../a4-美國債務懸崖/) 的擠壓交叉 |

## 上游（傳導回顧）

窒息戰（b2）→同盟的猶豫或分裂→承諾的可信度受疑——**「同盟=威懾」的邏輯受損**（與 1930s 的集體安全失敗同構）。

## 觀察指標

- 各國防衛支出占 GDP 的跳升（自主防衛的轉向）。
- 同盟條約的重新談判與「戰略模糊」的增多。
- 核議題（自有核武）的公開討論回歸。

## 不確定性

- 同盟的「可信度」可能因一次果斷行動回復——打折不必然永久。
- 「自助」的軍備擴張可能帶來新的穩定（均勢）或新的危險（擴散）——兩條歷史路徑。
