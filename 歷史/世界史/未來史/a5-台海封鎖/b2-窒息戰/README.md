# b2-窒息戰

> [a5-台海封鎖](../) 的下游節點——**如果封鎖長期化為窒息戰發生**，下游分岔：[c1-同盟承諾打折](c1-同盟承諾打折/)。

## 這個節點（如果發生）是什麼

封鎖不快速攤牌、轉為長期消耗：封鎖方以「檢疫」維持斷流、被斷方與盟友以護航與繞道反制——**窒息戰的消耗賽**（與 [武器與戰法/1943-大西洋狼群與反潛](../../../武器與戰法/1943-大西洋狼群與反潛.md) 的大西洋戰同構：史上最長的貓鼠博弈的當代版）。

## 傳導與理論

消耗戰的算式（與 [武器與戰法/1943] 的「噸位戰」同構）：

$$\text{窒息的效果} \propto \text{（封鎖的完整度）} \times \text{（持續時間）} \quad \text{vs} \quad \text{（被斷方的庫存與替代）}$$

## 下游分岔（若…否則…）

| 環節 | 若 | 否則 |
|------|-----|------|
| 同盟的參與 | 護航與制裁的團結→封鎖的鈍化 | 同盟分裂或猶豫→封鎖的深化（c1） |
| 消耗的終局 | 談判（成本核算）→收束 | 攤牌（登陸或誤判）→與 [a6/b3-核門檻](../../a6-戰爭形態的重寫/b3-核指揮的AI化/) 交叉 |

## 觀察指標

- 封鎖的「完整度」統計（通行的船舶數）。
- 同盟的護航與制裁團結度（聲明與行動的一致）。
- 談判管道的開閉。

## 不確定性

- 窒息戰的「終局」無法推演（談判、攤牌、僵持的三岔）——政治的混沌。
