# b1-晶片斷鏈

> [a5-台海封鎖](../) 的下游節點——**如果晶片斷鏈發生**，下游分岔：[c1-全球算力配給](c1-全球算力配給/)、[c2-即時化終結](c2-即時化終結/)。

## 這個節點（如果發生）是什麼

先進製程（≤7nm）的斷供=AI、手機、車用、國防的一切上游停擺——**「晶片=新錫貿易」**（[武器與戰法/-3000] 的供應鏈短板規律：錫斷供→兵器停擺的當代版）。晶圓、封測、設備、材料的連鎖缺料——「庫存天數」成為全球企業的生死線。

## 傳導與理論

供應鏈的短板規律：

$$\text{產出} = \min(\text{上游供給}) \quad \text{（短板系統：最稀缺的環節定義產出）}$$

即時化（JIT）的脆弱：庫存天數低=緩衝小——與 [武器與戰法/1943-大西洋狼群與反潛](../../../武器與戰法/1943-大西洋狼群與反潛.md) 的噸位戰同構：**不必登陸，只要斷流**。

## 下游分岔（若…否則…）

| 環節 | 若 | 否則 |
|------|-----|------|
| 全球庫存 | 高庫存（車用）撐一年→緩衝 | 即時化（AI 資料中心）數週即斷 |
| 替代產能 | 海外先進產能（已分散 10–20%）＋成熟製程頂上→配給而非全斷 | 無替代→全面衰退 |
| 算力的分配 | 市場自動配給（價格暴漲）vs 國家優先序→配給時代（c1） | 快速恢復（談判成功）→短暫衝擊 |

## 觀察指標

- 先進製程的替代產能落地比例（緩衝的大小）。
- 全球科技業「庫存天數」的回歸（即時化的反向）。
- 晶片價格與交期（lead time）的跳升。

## 不確定性

- 替代產能的緩衝隨「發生時點」變化——越晚發生、緩衝越大。
- 斷鏈的「恢復速度」取決於談判與外交——政治判斷，無法推演。
