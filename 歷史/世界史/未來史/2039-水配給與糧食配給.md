# 2039-水配給與糧食配給：卡路里與立方米的戰時帳本

## 案件摘要

**如果極端乾旱＋出口禁運同時打中糧食主產區，就會逼出「水—糧配給制」（灌溉配額＋主糧儲備投放＋禁運協調），進而造成「糧食從商品變成戰略物資」**——水權定價糧價，糧食自給率變成國防指標。這條鏈是 [2041-氣候遷徙條約.md](2041-氣候遷徙條約.md)（管人）之前的一步：先配給水與糧，配給不住才輪到遷徙；也是 a11-糧食與農業中 b2-出口禁運的制度收尾。

## 起火點 -- 如果配給發生

- **現況證據**：2022–25 年印度小麥出口禁令、黑海糧食走廊中斷、歐美多地含水層枯竭；主糧庫存消費比多次逼近警戒線。
- **觸發條件**：同一年度兩大主產區歉收（例如黑海＋北美），且主要出口國同步收緊出口——國際糧價單季翻倍。

## 連鎖推演 -- A→B→C

### 第一步：水權定價糧食（氣候⇒農業）

- 灌溉配額按含水層可持續開採量核定，水權可交易——**每公斤糧食的水足跡第一次有了價格**：

$$\text{糧價} = \text{生產成本} + P_{\text{水權}} \times \text{水足跡} + P_{\text{風險}}$$

- 精準農業（a11/b1）的節水技術從「加分項」變成「准入證」：滴灌、耐旱品種、垂直農場的補貼在此兌現（禁運給了去禁運技術最初的市場）。

### 第二步：主糧儲備與投放（農業⇒財政）

- 國家儲備從「豐歉調節」升級為「禁運戰備」（儲備量從 3 個月消費量提到 6–9 個月），投放規則公式化（糧價觸發線＋自動拋儲）——儲備的財政成本由碳稅與數位稅（見 [2032-全球數位稅.md](2032-全球數位稅.md)）分攤。
- 儲備即威懾：有儲備的國家在禁運談判中有叫價權——**糧食儲備＝糧食時代的核威懾**（不用，但必須有）。

### 第三步：禁運協調機制（財政⇒地緣）

- 出口禁運引入通報＋配額＋人道豁免（WTO 糧食安全盒的升級版），違規禁運面臨集體反制——從「各國自保」走向「有規則的自保」。
- 與台海封鎖（a5）的窒息戰同構：**晶片窒息與卡路里窒息是同一種戰爭的兩種彈藥**，談判桌上互相抵押。

## 分岔 -- 每一步的「若…否則…」

| 環節 | 若 | 否則 |
|------|-----|------|
| 水權定價 | 水權可交易→節水技術爆發 | 水權行政配→尋租與黑市 |
| 儲備戰備 | 自動投放→預期穩定 | 相機投放→囤積與恐慌搶購 |
| 禁運協調 | 有規則自保→人道豁免守住 | 無規則自保→窮國先斷糧 |

## 整個世界的變化

| 領域 | 變化 |
|------|------|
| 農業 | 節水技術准入化；垂直農場加速 |
| 財政 | 儲備成本常態化；稅收支應 |
| 地緣 | 禁運有規則；糧食—晶片互相抵押 |
| 社會 | 主糧配給預案；食物階層（誰吃什麼）顯性化 |
| 倫理 | 綠色禁運（a11/b2/c2）與人道豁免的拉扯 |

## 觀察指標

- 主糧庫存消費比與出口限制措施數。
- 灌溉水權價格與含水層水位。
- 儲備投放觸發次數與糧價波動率。
- 人道豁免通道的實際通行量。

## 不確定性

- 兩大產區同年歉收是小機率大衝擊事件——儲備规模的政治意願平時不足，災時不夠。
- 水權交易的公平性：大農場買斷水權、小農出局的階級化風險。
