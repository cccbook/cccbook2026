# a10-後量子密碼遷移

> 樹根節點（起火點：資訊與金融）——**如果容錯量子電腦破解現行公鑰體系發生**，下游分岔：b1-金融信任遷移、b2-密碼主權爭奪。

## 案件摘要

RSA 與橢圓曲線密碼保護著全球銀行轉帳、區塊鏈、軍令鏈路——其安全性建立在「古典電腦解不動大數分解」上。Shor 演算法（1994）早已證明量子電腦解得動，只缺夠大的機器；對手更已開始「先囤後解」（harvest now, decrypt later）：今天截獲的加密電文，等量子機成熟再解。本案的結論：**密碼遷移不是「量子機問世那天」才開始，而是「囤積開始那天」就已經開賽**——遷移速度 vs 量子速度的賽跑，輸的一方失去的不只是秘密，是整個金融與指揮體系的信任根。

## 起火點 -- 現況證據與觸發條件

- **證據**：NIST 後量子密碼標準（2024 Dilithium/Kyber 定稿）；美 NSA 要求國安系統 2030 年代初完成遷移；「先囤後解」被各國情報界公開承認為進行式。
- **觸發條件**：邏輯量子位元跨過破解 RSA-2048 的門檻（約數千邏輯位元＋糾錯）**或**一次公開的「量子解密演示」引爆信任恐慌——後者可能比前者先到。

## 下游分岔樹

```
a10-後量子密碼遷移
├─ b1-金融信任遷移
│   ├─ c1-有序遷移與雙軌期
│   └─ c2-信任閃崩與結算凍結
└─ b2-密碼主權爭奪
    ├─ c1-標準分裂與密碼鐵幕
    └─ c2-量子後門與不對稱透明
```

## 傳導與理論

Shor 演算法的複雜度斷崖（ $N$ 為密鑰位元數）：

$$T_{\text{古典}} \approx e^{O(N^{1/3})} \quad \text{vs} \quad T_{\text{量子}} \approx O(N^3)$$

2048 位元 RSA：古典需宇宙年齡量級，量子理論上數小時。遷移的算式則是另一條：

$$\text{遷移完成度} = \frac{\text{已升級系統}}{\text{全部依賴公鑰的系統}} \quad \text{（長尾以十年計）}$$

歷史先驗：SHA-1 退役拖了十年、IPv6 遷移拖了二十年——**密碼基建的長尾永遠比預期長**，而囤積的密文不會等人。

| 資產 | 量子風險 | 遷移難度 |
|---|---|---|
| 銀行即時結算 | 高（長期保密需求） | 中（系統集中） |
| 區塊鏈舊地址 | 極高（公鑰裸奔） | 高（去中心化，無人可強制升級） |
| 軍令與外交密電 | 最高（囤後解的首選） | 中（可空運升級，但量大） |
| 物聯網嵌入設備 | 中 | 極高（算力跑不動後量子簽名） |

## 分岔的條件（若…否則…）

| 環節 | 若 | 否則 |
|------|-----|------|
| 遷移速度 | 金融軍工先行完成→有序雙軌（b1/c1） | 長尾拖後→信任閃崩（b1/c2） |
| 標準 | 全球單一標準→互通 | 中美各立標準→密碼鐵幕（b2/c1） |
| 首破者 | 公開演示→全體恐慌性遷移 | 秘密首破→單方不對稱透明（b2/c2） |
| 區塊鏈 | 成功凍結/遷移舊幣→減震 | 舊地址被掃→加密資產信任崩盤 |

## 交叉

- 與 [a3-AI治理與法律](../a3-AI治理與法律/) 交叉（治理速度的考驗：密碼遷移是「制度速度 vs 物理速度」的期中考）。

- 與 [a6-戰爭形態的重寫](../a6-戰爭形態的重寫/) 交叉（軍令鏈路的信任根一斷，無人化軍隊即失明——b2 的戰場版）。

## 觀察指標

- 邏輯量子位元數與糾錯閾值進展（量子速度）。
- 銀行與支付系統的 PQC 遷移公告比例（遷移速度）。
- NIST 標準在中美歐的採納分歧（鐵幕訊號）。
- 舊式區塊鏈地址的異常歸集（掃幣前兆）。

## 不確定性

- 容錯量子機可能比預期晚十年——但「囤後解」使等待本身就有成本，鏈條已經啟動。
- 後量子演算法自身可能被古典新方法攻破（SIKE 前車）——遷移的目的地也可能搬家。
