# 1347 蒙兀兒斯坦分裂：察合台的兩半人生

## 案發現場

1347 年，哈扎爾（合札爾）擁立禿黑魯帖木兒，東察合台（蒙兀兒斯坦：天山南北＋七河）與西察合台（河中）正式分裂——**察合台汗國（參見 [1227-察合台汗國.md](1227-察合台汗國.md)）的死亡證明書**，也是帖木兒（參見 [1370-帖木兒.md](1370-帖木兒.md)）二十三年後崛起的舞台說明書。

> **一個汗國為何裂成遊牧東部與定居西部？帖木兒撿到的河中，是誰切下來送他的？**

## 偵查過程

**線索一：遊牧—定居斷層（社會偵查）。** 東部（蒙兀兒斯坦）堅持遊牧、蒙古語、部落制；西部（河中）突厥化、伊斯蘭化、城市商稅化。1330 年代海都—篤哇改革紅利耗盡，東西稅基已無法兼容：**遊牧要草場免稅，城市要商稅養軍**。偵查結論：

$$\text{分裂} = \text{（東：遊牧稅基）} \parallel \text{（西：城市稅基）} \Rightarrow \text{一國兩稅、無解}$$

平行線硬綁在一起八十年，1347 只是簽字儀式。

**線索二：黑死病與權力真空（偶然偵查）。** 1338–1346 黑死病沿絲路橫掃中亞（訛答剌、撒馬爾罕墓碑激增）、汗位十年九換（1327–1347 九汗被殺）。偵查結論：**瘟疫是最好的分裂催化劑**：商稅暴跌→汗庭發不出餉→部落各找各的汗。學術理論：麥克尼爾「瘟疫與帝國收縮」——**疾病先打稅收，再打合法性**。

**線索三：河中的軍閥化（政治偵查）。** 西部實權落入部落埃米爾（哈扎爾、後來的帖木兒之主侯賽因）之手，汗成橡皮圖章（「傀儡汗」時代）；東部禿黑魯帖木兒皈依伊斯蘭（1354）試圖縫合，但為時已晚。對照：

| 東部蒙兀兒斯坦 | 西部河中 |
|---|---|
| 遊牧部落聯盟 | 城市＋突厥軍閥 |
| 汗有實權（短期） | 汗是圖章 |
| 伊斯蘭化晚（1354） | 伊斯蘭化早 |
| 後裔：葉爾羌、準噶爾前身土壤 | 後裔：帖木兒帝國 |

## 結案報告

1. **兩稅不容論**：遊牧稅基與城市稅基無法共用一個汗。
2. **瘟疫催化論**：黑死病打崩商稅即打崩汗權。
3. **圖章化論**：西部汗先變圖章，帖木兒才有位置可坐。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 1347 分裂 | 跨域效應 |
|------|----------|----------|
| 經濟 | 商稅崩＋兩稅分離 | 東西各過各的 |
| 疾病 | 黑死病墓碑層 | 人口—稅收雙殺 |
| 政治 | 傀儡汗時代 | 帖木兒崛起的空位 |
| 宗教 | 東部1354皈依 | 全中亞伊斯蘭化收官 |

**分裂公式（示意）：**

```
察合台 ＝ 東（遊牧＋部落）＋ 西（城市＋商稅）。
黑死病 × 汗位九換 → 膠水失效 → 1347 簽字 → 1370 帖木兒撿走西半。
```

**結論：** 蒙兀兒斯坦案填補 1227 與 1370 之間一百四十三年的黑洞：**帖木兒不是橫空出世，是分裂的接盤俠**——東半繼續遊牧（後來養出準噶爾，參見 [1757-準噶爾的終結.md](1757-準噶爾的終結.md)），西半城市化（被帖木兒打包成撒馬爾罕的琉璃瓦）。1347 的那一刀，切出了此後三百年的中亞地圖。
