# 1599 三汗國並立：河中的黃昏與大航海的陰影

## 案發現場

1599 年，昔班尼王朝的阿卜杜拉汗二世死去，烏茲別克諸烏魯斯分立；十七世紀初，中亞定格為三個汗國：布哈拉汗國（河中）、希瓦汗國（花剌子模綠洲）、浩罕汗國（費爾干納，十八世紀成型）。三國互相攻伐、內訌不斷——同時，歐洲商船已經完全繞開了陸上的絲路。

> **帖木兒的繼承人為何守不住撒馬爾罕？當海運取代駝隊，中亞的通道命運如何一夜改寫？**

## 偵查過程

**線索一：分封的詛咒（體制的內建崩解）。** 昔班尼王朝照搬蒙古—突厥傳統：帝國是黃金家族的家族財產，諸子分封烏魯斯，長子為宗主。阿卜杜拉汗二世一度接近統一，但他死後，汗位在親族間輪轉，阿斯特拉罕王朝（1599–1747）取而代之也同樣碎片化。偵查結論：這是**繼承制＝財產制**的老病（參見 [1227-察合台汗國.md](1227-察合台汗國.md) 的東西分裂）：帝國越大，分得越碎；分得越碎，越打不過任何外來的統一力量。三汗國不是被誰拆開的，是自己長成三塊的。

**線索二：海運的降維打擊（經濟偵查：絲路為何斷流）。** 十六世紀葡萄牙人控扼馬六甲與印度洋航線（參見 [../亞洲史/1511-馬六甲陷落.md](../亞洲史/1511-馬六甲陷落.md)），荷英商船隨後直航。一艘大帆船的載量等於數百峰駱駝，海運成本只有駝隊的一小部分。偵查結論：絲路斷流不是戰亂使然（戰亂只是加速），是**運輸技術的降維**——

$$\text{陸運單位成本} \approx \text{（護衛＋消耗＋關稅層層加碼）} \gg \text{海運單位成本}$$

中亞的財富公式是「通道租金」：商流過境即抽稅。當商流改道海洋，租金歸零——三汗國失去的不是商隊，是**存在的經濟理由**。十七世紀布哈拉使節屢屢出訪莫斯科與印度求通商，恰是通道帝國斷糧後的自救。

**線索三：奴隸貿易的替代產業（綠洲的畸形轉型）。** 商路斷了，三汗國改行：搶鄰居。希瓦與布哈拉的騎兵劫掠波斯邊境、哈薩克草原與俄國商隊，把俘虜賣為奴隸——布哈拉的奴隸市場（波斯人、俄羅斯人、哈薩克人）臭名昭著，希瓦的土庫曼騎兵以襲奴為業。偵查結論：這是**通道經濟的病理轉化**——當正經的過境貿易利潤消失，唯一還值錢的「商品」是人。劫奴經濟又反過來嚇跑殘餘商旅，形成自毀迴路：越搶越窮，越窮越搶。

**線索四：知識線的斷流（文化偵查）。** 對照八百年：布哈拉曾出阿維森納（參見 [0875-薩曼王朝.md](0875-薩曼王朝.md)），撒馬爾罕曾出兀魯伯星表（參見 [1409-兀魯伯與撒馬爾罕天文台.md](1409-兀魯伯與撒馬爾罕天文台.md)）；十七世紀的三汗國，學術幾乎留白，宮廷詩歌平庸，天文台無人重建。偵查結論：學術繁榮的兩個燃料——**商業剩餘**與**跨國人才流動**——同時熄火。中亞不是被某場戰爭打斷了文明，是被海運釜底抽薪。這就是為何 1865 年俄國人來時（參見 [1865-塔什干陷落.md](1865-塔什干陷落.md)），面對的是技術與組織都停滯了兩百年的對手。

## 結案報告

1. **分封詛咒論**：帝國當遺產分，必然碎成汗國群。
2. **降維打擊論**：海運對駝隊的成本碾壓——絲路斷流是技術性死亡。
3. **劫奴迴路**：通道租金歸零後，人成為商品——越搶越窮的自毀螺旋。
4. **雙燃料熄火論**：商業剩餘與人才流動同滅——中亞學術中斷的經濟病因。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 三汗國現象 | 跨域效應 |
|------|----------|----------|
| 經濟 | 絲路斷流 | 通道租金歸零、經濟內卷 |
| 政治 | 分封內訌 | 無力抵抗後來的殖民 |
| 社會 | 奴隸貿易 | 與波斯、俄國結成死仇 |
| 文化 | 學術留白 | 兩百年知識斷層 |
| 地緣 | 三國割據 | 為俄羅斯各個擊破預留縫隙 |

**通道經濟的斷糧曲線（示意）：**

```
大航海繞行 → 商流改海 → 過境稅歸零
  → 汗國財政萎縮 → 劫掠與奴隸貿易 → 商旅絕跡 → 更窮
中亞不是被征服打斷，是先被海運斷糧，後被征服收割。
```

**結論：** 三汗國案是「通道文明的大停滯」：碎於分封、窮於改道、毒於劫奴、啞於斷學——四個病灶互相餵養。它填補的正是本卷 1500 昔班尼與 1757 準噶爾終結之間的主題空白：這兩百年中亞不是沒有事件，而是事件全部向內塌縮。**依賴通道租金的文明，最怕的不是強敵，是繞路**——大航海時代畫出的每一條新航線，都是中亞帳本上的一筆壞帳。
