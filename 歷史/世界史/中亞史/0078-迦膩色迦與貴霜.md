# 0078 迦膩色迦與貴霜：佛像、會議與關稅

## 案發現場

約公元 78 年（諸說 78/120/144 年，取傳統說），貴霜王迦膩色迦即位。貴霜（大月氏五翕侯之一丘就卻統一）疆域從中亞到印度西北——絲路中段、印度洋季風貿易北端。任內：召開第四次佛教結集（迦濕彌羅）、犍陀羅佛像大盛、與漢（班超）、安息、羅馬並立（「四帝」說）。一個游牧後代，如何同時當佛教護法與關稅老闆？

> **弘法與收稅矛盾嗎？佛教會議、希臘式佛像、絲路商隊——迦膩色迦的三筆生意用的是同一本賬嗎？**

## 偵查過程

**線索一：大月氏的西遷鏈（被趕出來的帝國）。** 大月氏本居甘肅，被匈奴冒頓擊敗（前 174 年）西遷伊犁，後被烏孫擠往大夏，征服當地，丘就卻統一五翕侯建貴霜。偵查結論：這是**游牧多米諾**：匈奴推大月氏，大月氏推塞種，大夏希臘王國（參見本書 [-0256-大夏希臘王國.md](-0256-大夏希臘王國.md)）倒霉——**草原的每一次碰撞，都在下游製造一個帝國**。貴霜是碰撞的第三站產物：匈奴（推）→大月氏（走）→大夏（亡）→貴霜（立）。**中亞史是檯球史**：白球（匈奴）一桿，彩球滿盤跑，洞裡掉出個貴霜。

**線索二：第四次結集（弘法的政治學）。** 迦膩色迦召集 500 比丘於迦濕彌羅（克什米爾），結集三藏、注釋（《大毘婆沙論》），確立大乘正統（一說）。偵查結論：這是**阿育王的翻版**（參見 [../亞洲史/-0261-阿育王.md](../亞洲史/-0261-阿育王.md)）：用佛教會議統一信仰、用法統包裝王權。游牧出身的王朝缺合法性（中原視為胡、印度視為蠻）——**佛教是現成的普世合法性**：護法之王，不分族裔。會議的副產品：大乘佛教定型，沿絲路東傳（參見 [../亞洲史/0067-白馬寺與佛教入華.md](../亞洲史/0067-白馬寺與佛教入華.md)）——**迦膩色迦無意中當了佛教全球化的董事長**。

**線索三：犍陀羅佛像（希臘鑿子的豐收）。** 希臘式衣紋、捲髮、高鼻的佛菩薩像大盛——工匠是大夏遺留的希臘後裔（參見本書 [-0256-大夏希臘王國.md](-0256-大夏希臘王國.md)），題材是大乘所需的佛像（此前無像）。偵查結論：**供需相遇**：大乘要佛像（供信徒瞻仰）+希臘工匠會刻（人體寫實）=犍陀羅藝術。貴霜王室下訂單（塔、寺、像），僧團驗收——**國家訂單孵化藝術流派**。佛像隨商隊東傳：于闐、敦煌、雲岡、龍門——**今日東亞的每一尊佛，都帶著一點希臘血統**。迦膩色迦的錢包，付的是全亞洲美學的定金。

**線索四：絲路關稅（帝國的現金流）。** 貴霜控絲路中段（瓦罕—喀什）+印度洋出海口（巴里加薩），收過路費+轉口稅；金幣（仿羅馬奧里斯）行銷，羅馬為絲綢逆差頭疼（老普林尼抱怨）。偵查結論：貴霜的本質是**通道帝國**（參見本書核心命題）：不事生產（游牧+收稅），專收通道費。佛教護法+佛像訂單，全是通道利潤的再投資——**弘法是關稅的廣告**：商隊信佛，商路暢通（寺院兼客棧、錢莊）。與渤海（參見 [../韓國史/0698-渤海國.md](../韓國史/0698-渤海國.md)）同構：**中轉+關稅=立國之本**，差別只在貴霜還附贈了世界宗教。

## 結案報告

1. **檯球理論**：匈奴一桿，滿盤跑，掉出貴霜——草原碰撞在下游製造帝國。
2. **護法即合法**：結集統一信仰——游牧王朝買普世合法性，無意中董事長了佛教全球化。
3. **訂單孵藝術**：大乘需求+希臘工匠——國家訂單孵出犍陀羅，東亞佛像帶希臘血。
4. **關稅即國本**：通道費養一切——弘法是關稅的廣告，寺院兼客棧錢莊。

**弘法賬本（示意）：**

```
收入：關稅（絲路）＋ 轉口（印度洋）。
支出：結集（合法性）＋ 佛像（廣告）＋ 寺院（基建）。
淨值：佛教全球化 ＋ 帝國美名 —— 一本賬，兩份利。
```

**結論：** 迦膩色迦案是「通道帝國」的完整樣本：匈奴的球撞出王朝，關稅的錢買來合法性，合法性的會開出全球化，全球化的佛像帶著希臘血。**一本賬，三筆生意（稅、法、像），筆筆賺**——中亞通道老闆的最高境界：收錢收到被做成菩薩（迦膩色迦像即近菩薩）。
