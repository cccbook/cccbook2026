# 商業貿易史歷史因果分析

## 案件摘要

本卷自西元前 1900 年的亞述商網一路追到 2020 年的供應鏈重構，縱貫四千年。核心謎題只有一個：**是什麼決定了商品走哪條路、財富積在哪個港**。破案後發現，兇手從來不是某個商人，而是三股力量的合力：運輸成本（技術與地理）、交易成本（制度與安全）、以及兩者夾縫中的套利者。每一代霸權本質上都是「在當時技術下把運輸＋交易成本降到最低的路徑」的具象化：波斯御道、絲路、威尼斯、里斯本、阿姆斯特丹、倫敦、集裝箱港口，皆是同一公式在不同時代的解。

$$\text{貿易流量} \propto \frac{(\text{兩地價差} - \text{運輸成本} - \text{關稅與風險成本})}{\text{路程不確定性}}$$

誰能系統性壓低分母，誰就拿到時代的租金。

## 因果鏈與回饋環

### 環一：開放 → 繁榮 → 分配衝突 → 關閉 → 衰落（長週期震盪）

```mermaid
flowchart LR
    A[貿易開放] --> B[港口繁榮]
    B --> C[分配不均與失血恐懼]
    C --> D[關稅／海禁／法案]
    D --> E[貿易萎縮]
    E --> F[財政與供給危機]
    F --> A
```

同構案例層出不窮：明朝海禁造就走私與雙嶼港；英國航海法案打擊荷蘭卻孕育自己的航運帝國；斯姆特霍利關稅把蕭條推向全球（`1914-全球化中斷.md`、`2008-貿易大衰退.md`）；美中貿易戰催生供應鏈重構（`2020-疫情與供應鏈重構.md`）。**偵推：貿易政治學的第一定律——開放是共識的預設值，保護是衝突的應答聲**。凡遇繁榮，先找它的分配裂縫。

### 環二：中間商的宿命——被繞過（負回饋，殘酷收斂）

$$\text{中間層加價} \to \text{繞路誘因} \to \text{直航成功} \to \text{中間層歸零}$$

君士坦丁堡陷落（`1453-君士坦丁堡陷落.md`）之於威尼斯，馬木路克香料壟斷（`1291-馬木路克香料壟斷.md`）之於里斯本，蘇伊士開通（`1869-蘇伊士運河.md`）之於開普敦補給站——同一劇本重演四次。**凡靠「剛好站在路上」賺的錢，都會因路改道而歸零**。只有把中間地位轉成制度與金融能力者（威尼斯的保險與匯兌、阿姆斯特丹的倉庫與信用）才能穿越航線更迭。

### 環三：貿易 → 專業化 → 規模 → 更深貿易（正回饋，現代成長引擎）

亞當·斯密的分工受市場規模限制：集裝箱把市場半徑推到全球，出口導向工業化（`1965-出口導向工業化.md`）讓四小龍得以用世界市場替代狹窄內需，中國入世（`2001-中國入世.md`）把三十億勞動力接入同一網絡，WTO（`1995-WTO成立.md`）則是這個正回饋環的制度保險。改革開放（`1978-改革開放.md`）之所以是二十世紀最大貧困削減案，本質是「把國家接入正回饋環」。

### 環四：三角貿易——暴力嵌入供應鏈

三角貿易（`1663-三角貿易.md`）與蔗糖、棉花構成大西洋奴隸經濟：低成本的源頭供給（奴役）壓低終端價格，養出歐洲的消費市場與英國的工業資本。**這提醒偵探：貿易數據的每一格便宜，都必須查帳——成本被記在誰的身上**。

## 反事實推演

- **若 1433 年下西洋未終止**：明艦隊與葡萄牙將在印度洋相遇。以朝貢邏輯（要朋友不要租金）對上炮艦邏輯（要執照與稅），明朝多半仍會退出——財政成本與內部政治使其不可持續。**偶發事件的背後是結構性的成本核算**。
- **若沒有蘇伊士運河**：倫敦—孟買航程多六千公里，英屬印度的統治成本劇增，帝國可能早衰；開普敦與新加坡的戰略地位將完全不同。
- **若沒有集裝箱**：出口導向工業化失去物理基礎，四小龍與沿海中國難以嵌入全球分工，亞洲奇蹟將延後且縮小。**最不起眼的技術（一個鐵箱子）往往是最大案件的真兇**。
- **若 1995 年沒有 WTO**：貿易擴張照舊（關稅已因 GATT 與單邊自由化而降），但爭端解決機制缺席，2000 年代的美中摩擦會提早以叢林法則登場。制度的作用不是加速，而是延緩退潮。

## 偵探教訓

1. **先查路，再查人**。貨往哪裡走，由價差與成本決定；商人只是方程式的解。凡見巨富，先還原他站在哪條路上。
2. **中間地位不可靠，制度地位才可靠**。航線會改道，但保險、匯兌、信用評級與規則制定權不會。問一個城市「除了過路還提供什麼」，就知道它能不能穿越霸權更替。
3. **開放與保護是同一枚硬幣**。每次全球化的盛極而衰，都始於分配而非貿易本身。偵探的目光要從港口移向內陸的輸家。
4. **帳要查三方**。便宜的終端價格，其成本可能記在奴工、殖民地或未來的環境上。貿易史的完整帳本從來不只有買賣兩欄。
5. **技術的階梯效應大於政策的口號**。運河、鐵路、蘇伊士、集裝箱對貿易的影響，遠大於任何條約。追蹤長期因果時，把工程師放在外交官前面。
