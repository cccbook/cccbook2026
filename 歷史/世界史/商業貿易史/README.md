# 商業貿易史 -- AI 偵探風格

以「推理探案」的方式，追查人類貿易從美索不達米亞的商隊到全球供應鏈、貿易戰的每一步：
前因是什麼？線索在哪裡？推理如何展開？後果又如何重塑了世界經濟？

核心謎題只有一句話：**貿易如何不斷降低「距離的成本」——又如何被權力反覆截斷？**

$$\text{需求差} \to \text{商路} \to \text{中間商利潤} \to \text{權力競逐} \to \text{繞道／壟斷} \to \text{新商路} \to \dots$$

每一次貿易革命，都是「運輸成本、資訊成本、制度成本」三項之中至少一項的斷崖式下降；
每一次貿易戰爭與封鎖，都是有人想**截取中間利潤**——而結果幾乎總是催生**繞道的技術**。
帝國起於商路，也亡於商路改道。

## 三條偵探法則（本卷的分析框架）

1. **成本三角**：任何貿易事件，先問「運輸、資訊、制度」三種成本哪一個先動了。
2. **中間商定律**：兩端需求越大、中間環節越多，中間商越富、越有動機壟斷——
   而壟斷利潤正是別人繞道的資本（威尼斯→好望角；陸上絲路→海路；轉口→直航）。
3. **路徑依賴的報酬**：誰控制節點（海峽、港口、運河、清算系統），誰收租——
   但收租的舒適會延遲創新，讓下一位挑戰者得手（西班牙、葡萄牙、清朝的教訓）。

## 貫穿全卷的因果迴路

```
   地理 ──→ 商路成本 ──→ 節點城市財富 ──→ 帝國／霸權
     ↑            │              │              │
     │            ↓              ↓              ↓
   技術      中間商利潤      金融制度        軍事保護
 （船、運河、   （壟斷誘因）  （匯兌、保險、  （炮艦、要塞、
  集裝箱）                     公司特許）      貿易特權）
     │                                          │
     └──← 繞道創新 ←── 截租／封鎖 ←── 壟斷租金 ←┘

   正向迴路：貿易→財富→制度→更低成本→更多貿易
   負向迴路：壟斷→高價→繞道→中間商衰落（威尼斯、君士坦丁堡、廣州）
```

**偵探教訓**：貿易史的每一頁都在重複同一個案子——
**有人靠位置收租，就有人想辦法搬走位置。**
