# 1643-哥薩克東進黑龍江：波雅爾科夫與哈巴羅夫的偵查戰

## 案件摘要

1643 年 6 月，雅庫茨克總督戈洛文派出哥薩克瓦西里·波雅爾科夫（132 人！）溯勒拿河、越外興安嶺進入黑龍江上游——探險隊冬糧盡絕，吃土著屍體度日（→達斡爾人稱他們「吃人的羅剎」！）；三年後回報：黑龍江流域毛皮豐饒、耕作成熟、無需向沙皇要補給。前因：1632 雅庫茨克建城（勒拿河據點！）、皮毛財政（yasak 貢皮制！→西伯利亞收入佔俄國國庫三分之一！）；續章：1649–1653 哈巴羅夫率「志願者」再進黑龍江（炮艦＋火繩槍！雅克薩築城！）、1658 沙俄建尼布楚；後果：達斡爾人南撤（清廷堅壁清野！）、1660s 康熙與沙俄在黑龍江的直接對峙（→1685–86 雅克薩之戰、1689 尼布楚條約！）——**哥薩克的偵查報告，寫出了兩大帝國的第一張邊界草圖**。

## 前因 -- 多因素的局勢

- **毛皮財政**：沙俄國庫對西伯利亞皮毛的依賴（→「軟黃金」！）——發現新獵場＝發現新收入（→激勵總督不斷東派！）。
- **雅庫茨克**：1632 建城的極東據點（→補給線末端、總督需要戰功！）。
- **黑龍江土著**：達斡爾（農耕＋城堡！）、鄂倫春——向清廷納貢（→「這是有人管的地」的誤判空間！）。
- **清廷**：忙於入關（1644！）與南方——**東北防務真空期**。

## 線索與推理 -- 因素咬合

### 線索一：擴張的動力學——「皮毛驅動的帝國」

$$\text{東進速度} \propto \text{（皮毛利潤率！）} - \text{（運輸與駐軍成本！）}$$

明斯克商人計算：西伯利亞松鼠皮轉手歐洲市場利潤率 1000%+（→成本可忽略！）——**利潤率即擴張半徑**（→西班牙找銀、俄國找貂：殖民主義的兩種計算器！）。

### 線索二：以戰養偵——「140 人與一座帝國」

波雅爾科夫—哈巴羅夫模式：小隊＋船＋火器＋築寨（ostrog！）：

| 要素 | 功能 |
|------|------|
| 木寨 ostrog | 補給節點＋鏈條（→一年推進一環！） |
| yasak 貢皮 | 當地人變財源（＋人質！） |
| 火繩槍／炮 | 對木城與箭的技術碾壓 |
| 「志願者」契約 | 國家零成本、私人冒險家分贓（→特許狀式殖民主義！） |

**國家把擴張外包給冒險家**（→葉爾馬克 1581 的模式複製！）。

### 線索三：清朝的遲到與反應——「情報的時間差」

清廷 1652 才派寧古塔章京海色迎擊（敗！）、1658 沙爾虎達截擊哈巴羅夫繼任者（勝！）——**情報到達北京的時間＝反應的延遲**：

$$\text{帝國邊界} = f(\text{雙方兵力投送成本交點})$$

俄方投送成本極高（→雅克薩補給走水路千里！），清方投送成本因「柳條邊＋驛站」較低——交點停在黑龍江北岸（→1689 劃界的物理邏輯！）。

## 破案時刻

- 1632：雅庫茨克建城——跳板。
- 1643–46：波雅爾科夫偵查（吃人報告！）——黑龍江入檔。
- 1649–53：哈巴羅夫遠征（雅克薩！阿槍斯克之戰 1652！）——殖民化。
- 1658：清軍截擊、尼布楚建城——對峙成型。
- 1685–89：雅克薩之戰→尼布楚條約——結案。

## 後果 -- 改變了什麼

- **地緣**：兩大帝國首次正式接觸（→1689 平等條約！1860 反轉的遠因！）。
- **黑龍江社會**：達斡爾南遷、部族編入八旗（→「新滿洲」！）。
- **俄國財政**：皮毛收入曲線東移（→堪察加、白令海的下一步！）。
- **清廷**：東北封禁與柳條邊強化（→人口空白帶，為 19 世紀璦琿悲劇埋線！）。

## 因素影響筆記

```
皮毛利潤率（1000%！）──→ 雅庫茨克總督派隊（1643）
ostrog鏈×yasak ──→ 以戰養偵的擴張（波雅爾科夫→哈巴羅夫！）
清廷情報延遲 ──→ 1650s 被動迎擊 ──→ 雅克薩（1685）→ 尼布楚（1689）
```

**偵探結語**：1643 年案的真相是「偵查即征服」：波雅爾科夫 132 人用三年換來一張流域情報圖，哈巴羅夫照圖施工——**殖民是情報的複利**。清廷的反擊雖在雅克薩扳回，卻留下更深的隱患：堅壁清野把黑龍江變成無人緩衝帶（→兩百年後俄國人沿同一條水路回來，帶的是炮艦與移民，1858 璦琿條約收走了北岸）。
