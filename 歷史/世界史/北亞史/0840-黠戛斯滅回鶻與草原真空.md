# 0840 黠戛斯滅回鶻：草原真空的三個冬天

## 案發現場

840 年，回鶻汗國被黠戛斯攻破（殺㕎馺可汗、焚斡耳朵八里），部眾西遷（甘州、龜茲、西州）——**突厥（參見 [0552-突厥汗國與草原新主.md](0552-突厥汗國與草原新主.md)）與契丹（參見 [0907-契丹遼朝與燕雲.md](0907-契丹遼朝與燕雲.md)）之間一百六十七年的真空**。回鶻曾是摩尼國教、絹馬貿易之王（參見 [0744-回鶻汗國與摩尼之國.md](0744-回鶻汗國與摩尼之國.md)），怎麼三年就亡了？

> **大雪、內鬥與唐朝斷供，哪一個先動手？草原帝國為何總在冬天死亡？**

## 偵查過程

**線索一：大雪與疫病（氣候偵查）。** 839 年嚴冬（牛羊凍死、糧絕）、時疫並行——遊牧經濟一年即斷糧。偵查結論：這是**外生衝擊先動**（呼應本卷因素迴路：大雪／火山是外生箭頭）：

$$\text{回鶻崩潰} = \text{（大雪} \times \text{疫病）} \times \text{（內鬥} \uparrow\text{）} \Rightarrow \text{汗權清零}$$

氣候不殺帝國，**氣候殺掉帝國的糧倉，再由內鬥完成處決**。

**線索二：絹馬斷供（經濟偵查）。** 回鶻財政靠唐朝絹馬貿易（以馬易絹、歲幣變相），安史後唐自顧不暇、甘露之變（835）後宦官索賄無度——**朝貢intosh 斷流**。偵查結論：草原帝國的公式（本卷經濟：草原需中原穀鐵）反轉——**中原一斷供，草原先餓死**。對照後來遼的澶淵歲幣：**誰給誰輸血，決定誰是宗主**。

**線索三：三路西遷（人口偵查）。** 回鶻三分：甘州回鶻（河西）、龜茲回鶻、車師西州回鶻（高昌）——由遊牧轉綠洲農商（建高昌城、改信佛教、創回鶻文）。偵查結論：**滅亡即轉型**：西州回鶻後來富甲西域（高昌稅關）、甘州回鶻扼河西（宋夏遼金都要買路）——草原帝國死了，**綠洲商國活了兩百年**。契丹 907 年崛起時面對的，正是這個「無汗的草原＋三個富綠洲」的格局。

## 結案報告

1. **外生先動論**：大雪先斷糧，內鬥再處決。
2. **斷供論**：絹馬一停，汗庭先破產。
3. **轉型論**：遊牧死、綠洲生——西州高昌是回鶻的第二條命。

**草原死亡公式（示意）：**

```
死亡 ＝ 外生衝擊（雪／疫）× 財政斷供（朝貢停）× 內鬥（殺汗）。
轉生 ＝ 西遷綠洲 × 改信佛教 × 收商稅。
840 是死亡，907 契丹接的是轉生後的盤。
```

**附記：黠戛斯為何沒能當第二個回鶻。** 黠戛斯破回鶻後自稱可汗、遣使入唐求冊封，但既無絹馬貿易可繼（唐已無力輸血）、又無商路組織可接（粟特商團隨回鶻西遷），二十年即退回葉尼塞——**殺死帝國容易，繼承稅卡難**。偵探的判語：草原的王位不是打下來的，是**中原的歲幣＋粟特的帳本**兩件套襯起來的；黠戛斯只有刀，沒有帳本，所以王冠戴了二十年就滑落了。

**結論：** 黠戛斯案填補 744 與 907 之間的真空：**契丹不是在草原帝國的屍體上建國，是在三個富綠洲的夾縫裡建國**——回鶻把草原讓出來、把商路留下來，阿保機撿走的正是這份遺產。
