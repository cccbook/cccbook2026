# 1727-恰克圖條約與萬里茶道：邊界畫出來的財富

## 案件摘要

1727 年（雍正五年），中俄簽《布連斯奇界約》、次年《恰克圖條約》：劃定蒙古與西伯利亞的邊界，並指定恰克圖為官方互市點——一座木柵欄小城從此成為「沙漠裡的芝加哥」。此前 1689 尼布楚只定了東段（→[1689-尼布楚條約](1689-尼布楚條約與中俄邊界.md)），中段懸而未決四十年；此後萬里茶道全線貫通：武夷山—張家口—庫倫—恰克圖—莫斯科。**茶葉成了北亞資源鏈上繼紫貂之後的第二張王牌**——本卷 1755 準噶爾之亡與 1896 中東鐵路之間的百年，恰克圖是主角。

## 前因 -- 多因素的局勢

- **尼布楚的留白**：東段已定、中段未劃（→喀爾喀歸附後，[1691-多倫會盟](1691-多倫會盟與喀爾喀歸附.md)，邊界必須重談！）。
- **噶爾丹的教訓**：準噶爾還在打（→[1755-準噶爾之亡](1755-準噶爾之亡與新疆建置.md)未到！）——**清朝需要東線安穩、單線作戰**（→外交動機！）。
- **俄國的需求**：彼得大帝要中國茶、絲、綢（→宮廷與歐洲轉售市場！），俄毛皮在西伯利亞存量下降（→yasak 收入見頂！）。
- **蒙古的處境**：喀爾喀已歸附（→盟旗格子！），但邊界不清則逃人、盜馬、越境不斷（→執法成本！）。

## 線索與推理 -- 因素咬合

### 線索一：劃界為何雙贏——「邊界即執法裝置」

條約核心條款：中段邊界（→鄂爾渾圖勒測繪！五十四個界牌！）＋逃人遣返＋盜竊追償＋定點互市：

$$\text{邊界} = \text{（主權線！）} + \text{（執法半徑！）} \Rightarrow \text{貿易成本下降} \Rightarrow \text{雙方財政收入上升}$$

**與尼布楚一脈相承**（→條約外交在亞洲的第二次實踐！）——兩帝國用墨水取代哨兵（→暫時的！）。偵探結語：**邊界不是把人隔開，是把生意裝進格子**——有了格子，才有秩序；有了秩序，才有流量。

### 線索二：恰克圖的會計學——「茶換皮毛的剪刀差」

貿易結構：俄出毛皮（海獺、狐、灰鼠！）＋呢絨，中出茶、綢、大黃、瓷器——**茶葉是硬通貨**（俄國全境飲茶！西伯利亞人以磚茶充貨幣！）：

| 項目 | 南端（武夷—張家口！） | 北端（恰克圖—莫斯科！） |
|---|---|---|
| 商隊 | 晉商駝隊（數萬峰！） | 俄商車隊 |
| 抽稅 | 厘金＋關稅 | 伊爾庫茨克關稅 |
| 硬貨 | 磚茶！ | 毛皮＋金銀 |

**萬里茶道的三段抽水**（→晉商常氏、榆次車輞常家發家！伊爾庫茨克崛起為西伯利亞首府！）——與 yasak 的差別：**皮毛是狩獵的餘額，茶是種植的流量**（→資源鏈從「賣大自然」升級到「賣勞動」！）。

### 線索三：關閉的武器——「三次閉市」

恰克圖互市三度關閉（1764、1778、1792！起因：越境、逃犯、關稅糾紛！）——每次閉市，俄國毛皮滯銷、財政受損，最終 1792《恰克圖市約》復市並細化章程：

$$\text{貿易依賴} = \frac{\text{對方在你市場的收入}}{\text{你的替代選項}} \Rightarrow \text{閉市權} = \text{清朝的經濟武器}$$

**斷市比斷交疼**（→清朝在軍事上已無優勢的年代，恰克圖是最後一根經濟槓桿！）——與[1689-尼布楚](1689-尼布楚條約與中俄邊界.md)對照：**1689 靠炮，1792 靠市場**（→帝國間的槓桿在換手！）。

### 線索四：蒙古的帳本——「通道穿過誰的牧場」

茶道經張家口—庫倫—恰克圖（→喀爾喀盟旗境內！）——驛站、馱夫、草場出租、喇嘛廟的商棧（→蒙古貴族與寺院的貿易分成！）＋晉商的高利貸（→「印票」債務！牧民以畜抵債！）——**通道的繁榮同時是依附的加深**（→日後 1911 外蒙獨立的經濟怨恨之一，見 [1911-外蒙古獨立](1911-外蒙古獨立與博克多汗.md)！）。偵探結語：**貿易線從不免費穿過——過路費收的不是錢，是主權的分量**。

## 破案時刻

- 1689：尼布楚（東段定！中段懸！）——留白。
- 1727：布連斯奇界約（五十四界牌！）——劃界。
- 1728：恰克圖條約（互市＋逃人條款！）——建市。
- 1764/1778：兩度閉市（糾紛！）——試武器。
- 1792：恰克圖市約（章程細化！）——復市。
- 19 世紀中：茶道鼎盛（年入茶數十萬箱！）——高峰。

## 後果 -- 改變了什麼

- **中俄**：百年邊界和平（→單線對準噶爾！1755 收官！）——**外交與貿易互為槓桿**。
- **晉商**：萬里茶道的商業帝國（→匯通天下的票號前身！）——**金融隨商路而生**。
- **西伯利亞**：伊爾庫茨克、恰克圖城市帶（→西伯利亞不再只是流放地！）。
- **蒙古**：驛站＋債務＋寺院經濟（→依附加深！）——**繁榮的苦果 1911 才發酵**。
- **資源鏈**：紫貂 → 茶葉 →（後續）→ 鐵路 → 石油（→見結案陳詞！）——**北亞永遠在賣東西，貨單一直在換**。

## 因素影響筆記

```
尼布楚留白（中段！）＋噶爾丹壓力（單線作戰！）──→ 1727 劃界（執法裝置！）
劃界（秩序！）──→ 恰克圖互市（流量！）──→ 萬里茶道（晉商＋俄商！）
茶換皮毛（剪刀差！）──→ 依賴不對稱（清朝握閉市權！）──→ 1792 市約（經濟槓桿！）
茶道穿蒙（驛站＋印票債！）──→ 依附加深（→1911 的經濟伏筆！）
```

**偵探結語**：恰克圖案是「邊界生財」的判例：兩個帝國在 1727 年同時想通了一件事——**把無主的草原變成有格子的帳本，格子裡的每筆生意都有稅**。茶葉沿著界牌北上，毛皮南下，晉商的駝鈴與俄國的關稅冊在木柵欄兩側對帳一百年。這條資源鏈接續了 yasak 的皮毛（大自然的餘額），預告了中東路的鋼軌（工業的動脈）——**北亞從賣紫貂，到賣茶葉，到賣石油：貨在換，通道的命題從未變**。而那筆記在蒙古牧民帳上的印票債，將在 1911 年的庫倫連本帶利地收回。
