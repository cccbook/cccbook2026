# 1930 古拉格：勞改即經濟制度

## 案發現場

1930 年，蘇聯設勞改營管理總局（古拉格），此後二十年：白海—波羅的海運河（1933，10 萬人死亡，一說）、莫斯科—伏爾加運河、科雷馬金礦、沃爾庫塔煤礦、貝阿鐵路前身——數百萬囚犯（政治犯+刑事犯+「社會異己」）無償勞動。索爾仁尼琴《古拉格群島》（1973）揭開全貌。勞改營是懲罰，還是生意？

> **免費勞力划算嗎？當國家擁有數百萬奴工，運河、金礦、鐵路的賬怎麼算——古拉格是古拉格經濟學，還是純粹的恐怖？**

## 偵查過程

**線索一：白海運河的賬（人命換工程）。** 1931–33 年，十餘萬囚犯（多數無機械，鎬鍬手挖）建成 227 公里運河（水深不足，大船難行，實用價值低）。死亡逾十萬（一說）。偵查結論：這是**面子工程的人命會計**：運河為史達林生日獻禮（1933 通航），實用性次要（水淺+結冰期長）。**成本收益比**：收益（運河，低價值）÷成本（十萬命+糧食）→負數——市場經濟絕不會建。但計劃經濟的賬不同：**囚犯是免費投入（糧食配給低于成本？不，配給即成本，但政治上免費）+工程是政治獻禮（無價）**——賬算得平（政治上）。古拉格經濟學第一定律：**免費勞力的工程，只問政治，不問經濟**。

**線索二：科雷馬金礦（勞改的現金流）。** 達爾斯特羅伊（遠北建設總局）：科雷馬金礦（-50℃，囚犯採金，一說年產百噸級）、沃爾庫塔煤、諾里爾斯克鎳——支撐工業化外匯（買機器）。偵查結論：這是**古拉格的盈利部門**：與白海運河（面子）不同，金礦是真錢（黃金出口換設備，五年計劃的外匯）。**勞改的雙軌**：面子工程（運河，虧）+現金牛（金礦，賺）——後者補貼前者。囚犯死亡率（科雷馬年均逾一成，一說）=**折舊**：人是耗材，死了再抓（1937–38 大清洗補貨，參見 [../俄羅斯史/1936-大清洗.md](../俄羅斯史/1936-大清洗.md)）。**人口即礦產**：富農（1929–30，數百萬流放）、清洗（1937–38）、戰俘（1940s）——三次進貨，保證勞力不斷。這是奴隸制的工業版：**供應鏈（抓人）+生產（挖礦）+折舊（死亡）**全齊。

**線索三：貝阿鐵路與凍土（未完成的白骨路）。** 貝阿鐵路（貝加爾—阿穆爾，第二條西伯利亞幹線）1930s 古拉格修築（死傷慘重，停工），1970s 勃列日涅夫重啟（共青團+志願者+高薪），1984 通車。偵查結論：這是**古拉格的爛尾+重建**：1930s 用命修（凍土+嚴寒+無機械，死亡率高），修不通（戰爭打斷）；1970s 用錢修（高薪+志願者+日本貸款換石油？一說）修通。**同一條路，兩種修法**：命修法（便宜，快，死人）vs 錢修法（貴，慢，活人）——蘇聯兩種都試了。貝阿的教訓：**凍土不認政治，只認物理**（路基融沉）——1930s 的人命填不平凍土（技術不夠），1970s 的錢+技術才填平。**自然規律面前，古拉格和盧布一律平等**（都不管用，得靠技術）。

**線索四：索爾仁尼琴的賬本（記憶的清算）。** 1973 年《古拉格群島》西方出版（手稿偷運），1974 年索氏被驅逐；1989 年蘇聯國內出版，千萬人讀。戈巴契夫平反（1987–91，數百萬）。偵查結論：這是**記憶的遲到正義**：官方檔案（1990s 部分開放：死亡170 萬，一說，爭議）+文學見證（索氏+沙拉莫夫《科雷馬故事》）=拼圖。**數字的戰爭**：170 萬（一說檔案）vs 數千萬（一說誇大）——真相在中間（學界共識千萬級經歷，死亡百萬級）。數字的政治：俄羅斯官方（淡化：紀念+和解，避免追責）vs 自由派（追責）vs 共產黨（否認/辯護）——**古拉格的賬，俄羅斯至今沒結清**（無全國性和解程序，一說）。此案與納粹（紐倫堡審判，參見 [../國家滅亡史/1945-納粹德國.md](../國家滅亡史/1945-納粹德國.md)）對照：**德國審了，俄羅斯沒審**——沒審的賬，利息是遺忘與重演風險。

## 結案報告

1. **面子會計**：免費勞力只問政治——白海運河人命獻禮，經濟負數。
2. **現金牛定律**：金礦補貼運河——人口即礦產，三次進貨不斷供。
3. **凍土平等**：命填不平物理——1930s 人命，1970s 錢加技術。
4. **未結之賬**：德國審了俄沒審——記憶的利息是遺忘與重演。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 勞改工程 | 跨域效應 |
|------|----------|----------|
| 法律 | 刑法58條、勞改法令 | 罪名批發 |
| 經濟 | 金礦外匯、運河面子 | 雙軌（一賺一虧） |
| 科技 | 凍土工程、手挖 | 技術不夠人命湊 |
| 政治 | 大清洗供貨 | 恐怖供生產 |
| 文化 | 索氏群島、沙拉莫夫 | 記憶文學 |

**面子 vs 現金（對照）：**

| 項目 | 白海運河 | 科雷馬金礦 |
|------|----------|------------|
| 目的 | 獻禮（政治） | 外匯（經濟） |
| 工具 | 鎬鍬+人命 | 鎬鍬+人命+嚴寒 |
| 產出 | 低價值運河 | 真黃金 |
| 死亡 | 十萬級 | 年均逾一成 |

**勞改方程（示意）：**

```
古拉格產出 ＝ 免費勞力（抓）× 政治意願（獻禮/外匯）− 死亡（折舊）。
補貨：富農（29–30）＋清洗（37–38）＋戰俘（40s）。
人口是耗材——死了再抓，賬永遠平（政治上）。
```

**結論：** 古拉格案是「奴隸制工業版」的完整樣本：面子運河、現金金礦、凍土白骨、未結之賬——數百萬人，二十年，人命換工程。**免費的勞力最貴**：貴在死亡（折舊）、貴在技術停滯（人命替代機械）、貴在記憶（至今未結）。索爾仁尼琴的書名是隱喻：群島——散在北海的島，連起來就是古拉格；散在歷史的命，連起來就是質問：誰來結賬？
