# 0380-狄奧多西敕令：宗教壟斷的成本

## 案件摘要

西元 380 年，皇帝狄奧多西一世頒布《薩洛尼卡敕令》，宣告「我們所有人」都應信奉三位一體的基督教——尼西亞正統（見 [0325-尼西亞信經](0325-尼西亞信經.md)）從「合法」升級為「國教」；異端教派被剝奪聚會權，異教祭祀逐步查禁，392 年更明令全面禁止獻祭與占卜。這樁案件的兇手是**意識形態的國家壟斷**：帝國決定不再中立於諸神之上，而是指定唯一供應商。統一的信仰帶來黏著劑，也帶來後世難以估計的社會成本。

## 前因 -- 多因素的局勢

- **政治**：361–363 尤利安皇帝試圖復興異教失敗——「倒車檔」已掛不上。
- **組織**：基督教會經數十年整合，主教的網絡與紀律勝過殘存的異教祭司團。
- **神學**：亞流之爭延燒——狄奧多西本人受正統主教影響，也需要教義統一穩住東方。
- **社會**：城市裡異教神廟仍是社群核心；帝國要用法律重畫公共空間的界線。

## 線索與推理 -- 因素咬合

### 線索一：從「自由市場」到「指定供應商」

米蘭敕令（313）是宗教自由市場；380 敕令是牌照壟斷——

| | 313 米蘭敕令 | 380 薩洛尼卡敕令 |
|---|---|---|
| 政策 | 宗教自由 | 正統獨尊 |
| 教會角色 | 合法結社 | 國家意識形態機器 |
| 異端 | 無此概念 | 法律上的非法組織 |

**壟斷的動機**：單一信仰＝單一忠誠座標。帝國要的是「同一本書、同一信經、同一教會」的低協調成本。

### 線索二：黏著劑的收益模型

設帝國凝聚力為 $\sum (\text{各地忠誠})$，若各地信仰不同，忠誠分散；若統一——

$$\text{凝聚力} = \text{教義統一度} \times \text{教會組織滲透率} \times \text{國家背書強度}$$

狄奧多西的三項都拉滿：信經已定（尼西亞）、主教網絡現成、皇帝強制執行。這是羅馬史上最強的意識形態整合工程。

### 線索三：壟斷的社會成本

- **391–392**：關閉神廟、禁止獻祭與占卜——數百年的文化資本（圖書館、祭典、神廟經濟）被折舊清零。
- 391 年亞歷山大里亞塞拉皮斯神廟被毀——異教知識圈的重創。
- 奧林匹克祭賽停辦（傳統繫於祭祀）——文化縱深的斷裂。
- **異端與異教成為同一類罪犯**：國家從此要 policing 民眾的內心——治理成本轉入新戰場。

### 線索四：壟斷的反噬——教會反過來監督皇帝

390 年，狄奧多西在薩洛尼卡屠殺平民，米蘭主教安波羅修禁止他領聖餐，皇帝當眾懺悔——**壟斷者被自己的供應商節制**。政教結盟的博弈從此互有籌碼：皇帝給教會法律，教會給皇帝（或收回）合法性。

## 破案時刻

- 379：狄奧多西即位，受洗為基督徒。
- 380：薩洛尼卡敕令——三位一體為國教。
- 381：君士坦丁堡大公會議，補充尼西亞信經。
- 392：全面禁止獻祭——異教在法律上終結。

## 後果 -- 改變了什麼

- **政治**：羅馬國家的合法性基礎由「諸神護佑」轉為「正統信仰的保護者」。
- **文化**：異教經典與廟宇文化式微，教會成為古典知識的儲存庫（也是過濾器）。
- **社會**：宗教裁判的先例建立——歐洲此後千年在「正統—異端」的軸線上內耗與整合並行。
- **反向**：被壓的異教資源（人才、財產）流向教會——帝國完成意識形態的資產重組。

## 因素影響筆記

1. **教義標準化（325）→ 國教化（380）**：先有規格，再有強制——制度工程的兩步。
2. **黏著劑收益 vs 壟斷成本**：統一降低協調成本，但消滅文化多元、製造異端衝突。
3. **政教博弈 → 互相節制**：皇帝與主教的囚徒困境長期化——安波羅修事件是第一個反例警示。
4. **392 全面禁祭 → 古典世界的法律終點**：意識形態國家化的極限，也是中世紀的起點。
