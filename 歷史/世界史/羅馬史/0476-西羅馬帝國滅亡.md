# 0476-西羅馬帝國滅亡：崩潰還是轉型

## 案件摘要

西元 476 年，日耳曼雇傭軍首領奧多亞克廢黜西羅馬末帝——年少的羅慕路斯·奧古斯都路斯，把帝國徽記送往君士坦丁堡，並表示西方不再需要皇帝。史書把這一年定為西羅馬帝國的終點。這樁案件的有趣之處在於：**現場幾乎沒有暴力，也沒有改朝換代的宣告**——行政機器照舊運轉。真正的問題是：這是「崩潰」的時刻，還是「轉型」完成的最後簽收？今天的史學共識是：**慢性財政與軍事的制度失效，累積了一個世紀；476 年只是把早已發生的事實，寫進公文**。

## 前因 -- 多因素的局勢

- **財政**：西方稅基在五世紀連續失血——北非（439 年被汪達爾奪走）、高盧、西班牙的失地使軍費無著。
- **軍事**：軍隊「蠻族化」——士兵與將領多為日耳曼出身；帝國實質上依賴要價越來越高的武裝承包商。
- **政治**：自 455 年瓦倫丁尼安三世被弒後，皇帝如走馬燈；實權在蠻族出身的軍頭（里西梅爾一系）手中。
- **外敵**：汪達爾的海上劫掠掐住義大利糧道；468 年東西聯合遠征北非慘敗——最後的翻盤機會燒掉了數十年財政積蓄。

## 線索與推理 -- 因素咬合

### 線索一：財政崩壞的負向迴路

失地→稅收減→雇不到兵→更多失地：

$$\text{軍力} = f(\text{稅收})，\quad \text{稅收} = f(\text{領土})，\quad \frac{d\,\text{領土}}{dt} < 0 \;\Rightarrow\; \text{軍力}\downarrow\downarrow$$

439 年失去北非是臨界點：那裡是穀倉與最富的稅省。468 年遠征失敗後，西方財政已無法維持國家機器——**476 年之前，帝國就已資不抵債**。

### 線索二：軍頭政治的終局邏輯

五世紀西方的實際統治者是軍事權臣，皇帝是他們的「合法性執照」。但奧多亞克的部下提出了更便宜的制度：**何必養一個羅馬皇帝來蓋章？**他們向東部皇帝芝諾要求義大利的實地封賞——被拒後，兵變、殺權臣歐瑞斯特斯、廢其子羅慕路斯。這不是民族起義，是**薪資談判的極端形式**。

### 線索三：行政的連續性——轉型派的證據

| 制度 | 476 年前 | 476 年後 |
|---|---|---|
| 元老院 | 存在 | 照常開會，簽署公文 |
| 執政官 | 年任 | 繼續任命，東西共認 |
| 稅務與法律 | 羅馬法 | 奧多亞克仍用羅馬官員與法律 |
| 教會 | 羅馬主教 | 角色不變，還更吃重 |

奧多亞克自號「意大利統領」而非皇帝，鑄幣仍用東帝名義——**他把義大利掛回了君士坦丁堡的名義主權之下**。末帝被廢後甚至領年金退隱坎帕尼亞——史上最溫和的亡國。

### 線索四：崩潰派的反擊

轉型論不能掩蓋的斷裂：帝國不再能徵稅與徵兵（統治者變為地租集團）、城市規模萎縮、長程貿易衰退、識字率下降。**「行政連續」是表層，「汲取能力喪失」是裡層**——中世紀的分權封建結構，正是帝國汲取體系解體後的重組。

## 破案時刻

- 439：汪達爾奪迦太基——財政臨界點。
- 468：遠征北非慘敗——最後的翻盤機會消失。
- 475：歐瑞斯特斯兵變，立其子羅慕路斯為帝。
- 476：奧多亞克兵變、廢帝、送徽記至君士坦丁堡。

## 後果 -- 改變了什麼

- **西方**：帝國官僚制讓位於王國並立——法蘭克、西哥特、東哥特等「羅馬式蠻族王國」。
- **東方**：名義上的帝國統一（直到查士丁尼西征），東羅馬續存千年。
- **教會**：羅馬主教填補權力真空，成為西方的道德與行政參照。
- **史學**：吉本以降的「崩潰論」與二十世紀的「轉型論」（如 Peter Brown 的「晚期古代」）持續辯論——答案很可能是：**制度汲取能力崩潰，而文化與宗教組織轉型**。

## 因素影響筆記

1. **稅基喪失 → 軍事外包 → 主權讓渡**：西部的死亡迴路是財政問題，不是蠻族戰力問題。
2. **名義主權的廉價出售**：奧多亞克送徽記，是「無成本的合法性租借」——制度巧思。
3. **行政連續 vs 汲取斷裂**：判斷崩潰或轉型，關鍵在於國家的「汲取與動員能力」是否延續。
4. **476 的象徵性**：日期是史學家的便利貼——真實的終結是 439–468 之間完成的財政破產。
