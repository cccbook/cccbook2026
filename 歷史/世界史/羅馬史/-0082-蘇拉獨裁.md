# -0082-蘇拉獨裁：政治暴力常態化與承諾問題

## 案件摘要

西元前 82 年，盧基烏斯・科爾內利烏斯・蘇拉（Lucius Cornelius Sulla）在內戰中擊敗馬略派，進入羅馬，被元老院授予**「獨裁官」頭銜——但沒有六個月期限**。這是羅馬史上第一次（也是最後一次，直到凱撒）憲政獨裁的永久化。他立即執行「公敵宣告」（proscriptio）：公開張貼名單，名單上的人可被任何人殺死、財產充公——第一份名單約 80 人，累計逾千人，包括元老與騎士，其中不乏「單純因為房子或妻子被看中」的死者。完成憲法改造後，前 79 年，蘇拉做了一件出人意料的事：**主動辭職，以平民身分退休**。這樁案件的謎題是：一個屠殺了千人的獨裁者，為何自願交出權力？答案藏在承諾問題（commitment problem）裡——蘇拉的制度設計沒有解決任何結構問題，只是證明了「暴力可以改寫憲法」。**他的辭職不是美德的證明，而是制度的死刑判決**。

## 前因 -- 多因素的局勢

- **軍隊私有化的成熟**：馬略改革後（參見 [-0107-馬略軍制改革.md](-0107-馬略軍制改革.md)），軍團效忠統帥——蘇拉是第一個把這個結構「兌現」的人。
- **米特里達梯戰爭指揮權之爭（前 88）**：東方本都國王米特里達梯屠殺羅馬僑民，羅馬需遠征——指揮權在蘇拉（元老院）與馬略（護民官蘇爾皮基烏斯以平民大會改授馬略）之間被政治撕扯。
- **第一次「軍隊進攻羅馬」**：前 88 年，蘇拉率六個軍團攻入羅馬城——軍隊首次對母城開火，馬略逃亡，蘇爾皮基烏斯的法律被廢除。**憲政的第一道防線（軍隊不對內）被徹底打破**。
- **內戰的雙向暴力**：蘇拉東征期間（前 87–84），馬略派掌權並屠殺蘇拉派（馬略本人前 86 年第七任執政官任上死亡）；前 83 年蘇拉帶勝利之師返義，內戰第二輪，前 82 年科林門（Colline Gate）會戰定局。
- **社會戰爭的餘燼**：前 91–88 的同盟戰爭使意大利半島剛獲公民權，公民權的政治分配未定——新公民的選票分配是政爭的核心。

## 線索與推理 -- 因素咬合

### 線索一：公敵宣告 = 暴力的「制度化」與「私有化」

公敵宣告的法律設計：

1. **名單公開張貼於廣場**——被害者不再有法律人格：任何人可以殺死他而不受追訴，**殺人甚至有賞**。
2. **窩藏者連坐**——把恐懼滲透進親子與鄰里。
3. **財產充公拍賣**——暴力有了直接的分贓機制：支持蘇拉的追隨者以低價購得死者的房產田地。

$$\text{暴力的期望報酬} = \text{殺人賞金} + \text{掠得財產} - \text{（法律風險} \approx 0\text{）}$$

這是「殺人市場」的建立：**暴力從政治手段變成可交易的資產**。參加公敵宣告的年輕人裡，有一個名叫克拉蘇（Crassus，未來三巨頭）——他透過低價收購死者的財產成為羅馬首富；另一個名叫凱撒（年輕的凱撒因親屬關係被列入名單，行賄與逃亡才倖免）。**蘇拉名單上的每一次殺戮，都在為下一個獨裁者編寫教材**。

### 線索二：憲法改造——舊制度的「防獨裁零件」被逐一拆解

蘇拉以獨裁官身分推動「憲政改革」（leges Corneliae），目標是「恢復元老院權威」：

| 改革 | 內容 | 拆解了什麼 |
|------|------|------------|
| 護民官閹割 | 護民官不得再競選更高官職、否決權受限 | 格拉古以來「人民路線」的制度通道被關閉 |
| 元老院擴編 | 300 → 600 人，由蘇拉親自任命補充 | 元老院的「權威」建立在獨裁者的私授上 |
| 法院歸還元老 | 陪審權從騎士收回 | 格拉古的司法改革逆轉 |
| 行政官年齡與晉升秩序 | 執政官之間設十年間隔、強制晉升序列（cursus honorum） | 針對馬略式連任的防禦 |
| 意大利公民票權分散 | 新公民選票分配到偏遠部落 | 削弱城市無產者的動員力 |

**但每項改革的效力都取決於「不使用暴力的人遵守它」**——而蘇拉自己剛用暴力證明了憲法可以被軍隊改寫。這是制度設計的根本矛盾：**用暴力的成果來重建防暴力的制度，等於在沙上築堤**。

### 線索三：辭職之謎——承諾問題的解讀

前 79 年蘇拉辭職，傳說他在廣場演說時放下權杖，甚至被民眾丟擲石塊（他安然走過），一年後病逝，葬禮是羅馬史上最盛大之一。為何辭職？三種解釋：

1. **身體**：長期酗酒與寄生蟲病，自認來日無多。
2. **制度的自欺**：他真心相信自己的憲法改革已「治好」共和國——獨裁是手段，不是目的。
3. **承諾問題的深層邏輯**：蘇拉面臨的困境是——若他終身掌權，他必須時刻防範下一次政變（他自己就是靠政變上位的模板）；若他交出權力並「示範」獨裁可以退場，他反而希望自己的制度設計能被信任地執行。

**承諾問題的核心**：制度的可信度需要「獨裁者會退場」的證明——但這個證明本身無法防止下一個獨裁者不退場。蘇拉以自身退場，試圖為「獨裁有終點」建立先例；歷史的回應是：三十七年後，凱撒成為**終身**獨裁官（前 44），隨即被刺殺——蘇拉的「溫和先例」沒有兌現，倒是「獨裁會招致刺殺」的先例兌現了。

### 線索四：蘇拉遺產的「雙重效果」

蘇拉死後十年內，他的憲法幾乎被全部拆除：前 70 年龐培與克拉蘇任執政官，恢復護民官全部權力。**但拆除「蘇拉憲法」的手段，恰恰是蘇拉示範的「軍隊＋個人權威」**——龐培與克拉蘇的執政官資格來自兵權與金錢。蘇拉真正留下的遺產不是那套被廢除的法律，而是三個先例：

1. **軍隊可以進攻羅馬城**（前 88）。
2. **公敵名單是有效的政治清洗工具**（前 82）。
3. **獨裁權力可以取得，也可以放棄**（前 79）——第三條被前兩條壓倒。

## 破案時刻

- 前 88：蘇拉首次進攻羅馬 → 東征。
- 前 87–84：馬略派掌權與清洗。
- 前 83–82：蘇拉返義 → 科林門會戰 → 進入羅馬 → 獨裁官（無限期）。
- 前 82–81：公敵宣告、憲法改造、大赦與殖民安置（老兵被安置在意大利各地——軍隊私有化的空間化）。
- 前 79：辭職；前 78：死亡。

## 後果 -- 改變了什麼

- **政治暴力完全常態化**：此後每一次權力更迭（龐培、凱撒、三巨頭、屋大維）都以軍隊為後盾——「憲政外解決」成為標準操作。
- **獨裁官頭銜的污染**：蘇拉之後，「獨裁官」不再是緊急備援制度，而是奪權的階梯——凱撒的終身獨裁直接死於這個頭銜。
- **老兵殖民體系**：退役軍人被安置在全意大利的殖民城，成為將軍們的「私兵地盤」——內戰的物質網絡。
- **屋大維的教訓**：前 27 年建立元首制時，屋大維刻意**不用**「獨裁官」頭銜、不搞公敵名單（只對安東尼派做有限清洗），以「共和國恢復者」的包裝取得實質王權——蘇拉的失敗，教會了帝國的第一位皇帝如何成功。

## 因素影響筆記

1. **軍隊私有化（馬略）→ 蘇拉的兌現 → 憲法暴力化**：前 88 年的第一次，是所有後來者的許可證。
2. **公敵宣告 → 暴力可交易 → 分贓機制**：當殺人有賞、掠奪合法，政治競爭的底線即消失。
3. **暴力重建的憲法 → 不可信的制度 → 被下一代暴力拆除**：以暴力獲得的和平，需要持續的暴力維持。
4. **蘇拉辭職 → 承諾問題的未解**：個人可以退場，但無法擔保制度——蘇拉用一生證明了獨裁可行，卻無法證明獨裁可控。
