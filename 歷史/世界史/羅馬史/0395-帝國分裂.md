# 0395-帝國分裂：分治的制度邏輯

## 案件摘要

西元 395 年，狄奧多西一世去世，帝國分給兩個兒子：長子阿卡狄烏斯得東半部（都君士坦丁堡），次子霍諾留得西半部（都米蘭，後遷拉文納）。從此羅馬帝國在制度上正式分為二，再未重新統一。這樁案件的兇手不是兄弟鬩牆，而是**治理半徑**：帝國太大、戰線太長、行政太慢——分治是早從戴克里先就開始的「試行方案」在 395 年的永久化。

## 前因 -- 多因素的局勢

- **組織**：戴克里先（285 起）已開四帝共治；君士坦丁與其繼任者反覆分治——「東西兩頭管理」是數十年的慣例。
- **軍事**：萊茵河—多瑙河防線對蠻族、幼發拉底對波斯——兩大戰區相距三千公里，指揮無法集中。
- **經濟**：東方富、西方窮——稅基已嚴重不對稱（見 [0476-西羅馬帝國滅亡](0476-西羅馬帝國滅亡.md)）。
- **首都**：330 年遷都後，東重心已固定於博斯普魯斯（見 [0330-遷都君士坦丁堡](0330-遷都君士坦丁堡.md)）。

## 線索與推理 -- 因素咬合

### 線索一：治理半徑的極限

帝國的行政依靠文書、驛道與官員——通訊與執行速度決定了有效統治半徑：

$$\text{有效治理半徑} = v_{\text{資訊}} \times t_{\text{決策容忍延遲}}$$

邊境蠻族入侵的決策容忍延遲以「日」計，而君士坦丁堡到萊茵河的資訊要走上數週——**半徑超限，指揮失靈**。解法只有一個：拆分戰區、分設朝廷。

### 線索二：兩個戰區 = 兩套國家

| | 東半部 | 西半部 |
|---|---|---|
| 主要威脅 | 薩珊波斯、多瑙河下游 | 萊茵河、不列顛、西哥特 |
| 稅基 | 埃及、敘利亞、小亞 | 高盧、義大利、北非 |
| 首都 | 君士坦丁堡 | 米蘭→拉文納 |
| 命運 | 存續至 1453 | 476 年終結 |

分治不是把帝國切兩半的「離婚」，而是把兩個戰區各自的「軍財政系統」制度化。

### 線索三：兄弟分產的繼承邏輯

兩位繼承人皆未成年（約 18 與 10 歲），實權在權臣之手（東：魯菲努斯；西：斯提里科）——**分治讓權臣有了各自的舞台**，宮廷政治從帝國級降為半帝國級。斯提里科主張自己有權兼管東西（以狄奧多西遺命為據），被東方朝廷拒絕——395 年的分界線，就是這次權力談判劃下的。

### 線索四：分治後的「囚徒困境」

東西本可合作對付共同威脅（如 401 年西哥特入侵時），但兩朝廷互疑：西要東的援軍，東要西不越界。**共同威脅＋分離決策＝協調失靈**——西哥特人阿拉里克正是利用兩政府的互相推諉，在巴爾幹與義大利之間反覆套利。

## 破案時刻

- 285 起：戴克里先的分治試驗——制度原型。
- 330：遷都君士坦丁堡——東重心確立。
- 394：狄奧多西最後一次統一（於冷河戰役擊敗西部僭主）。
- 395：狄奧多西死，二子分治——永久化的起點。

## 後果 -- 改變了什麼

- **政治**：東西兩國並行——西部 81 年後滅亡，東部續存逾千年。
- **軍事**：西部失去東方財政與人力支援，防禦逐漸外包給蠻族盟軍。
- **宗教**：兩宮廷分別介入教會事務，政教格局東西分化。
- **文化**：希臘語東方與拉丁語西方漸行漸遠——中世紀歐洲與拜占庭的分野自此定型。

## 因素影響筆記

1. **通訊速度 → 治理半徑**：帝國的裂痕首先是技術性的——資訊傳播跟不上戰爭節奏。
2. **戰區分離 → 財政分離**：軍事需求決定資源配置，資源配置決定政治單位。
3. **幼主繼承 → 權臣政治**：分治降低了權臣割據的成本。
4. **協調失靈 → 西部孤懸**：395 年不是終點，而是西部慢性失血的開始。
