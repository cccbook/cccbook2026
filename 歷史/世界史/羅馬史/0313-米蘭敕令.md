# 0313-米蘭敕令：國家與宗教的結盟邏輯

## 案件摘要

西元 313 年，君士坦丁與李錫尼在米蘭會晤，聯名頒布敕令：**帝國境內一切宗教自由，歸還教會被没收的財產**。基督教從被迫害的非法結社，一夕成為帝國座上賓。這樁案件的兇手不是虔誠，而是**政治計算**：三世紀危機後，帝國需要一種跨地域、有組織、能動員人心的網絡——而基督教恰好是帝國境內唯一的「現成組織」。國家與宗教的結盟，是一次降低統治交易成本的合併案。

## 前因 -- 多因素的局勢

- **宗教**：三世紀大迫害（250 德西烏斯、303 戴克里先）失敗——基督徒越抓越多，鎮押成本高於收益。
- **組織**：教會已具備主教制、跨省通訊網、慈善體系——帝國境內最有效率的橫向組織。
- **政治**：四帝共治崩潰後的內戰（306–312）——君士坦丁需要一切可用的忠誠來源。
- **軍事**：312 年米爾維安橋之役，君士坦丁以較少兵力擊敗馬克森提烏斯；戰前「拉布蘭旗」（Chi-Rho 符號）的傳說，無論真假，戰後他確實押注基督教。
- **東方**：李錫尼 313 年擊敗馬克西米努斯·達亞——兩人各控一方，需要共同的政治綱領。

## 線索與推理 -- 因素咬合

### 線索一：迫害是虧本生意

戴克里先的「大迫害」（303）命令拆教堂、燒經書、逼官員獻祭。結果：信徒多到殺不完，行刑的公開反而成為教會的廣告——

$$\text{鎮壓成本} \uparrow \quad \text{改宗率} \uparrow \quad \Rightarrow \quad \text{迫害的邊際收益} < 0$$

組織經濟學的結論：**無法消滅的網絡，就該收編**。米蘭敕令是把「打擊對象」轉為「治理工具」的停損點。

### 線索二：教會 = 現成的治理網絡

| 治理需求 | 羅馬官僚系統 | 教會 |
|---|---|---|
| 跨省聯絡 | 驛道＋公文，慢 | 主教通信網，快 |
| 基層動員 | 稅吏（惹人怨） | 主教（施粥濟貧） |
| 社會福利 | 幾乎沒有 | 賑濟孤寡病患 |

**皇帝不花一兵一卒，就得到一張深入基層的網**——這是史上著名的「低成本外包」。

### 線索三：歸還財產 = 購買忠誠

敕令要求歸還 303 年後充公的教堂財產，「買主可向國庫求償」——帝國自掏腰包為迫害善後。這是**沉沒成本的官方了結**：用一筆賠償，換取教會未來數百年的合作。

### 線索四：李錫尼的下場（反向驗證）

313 敕令的聯署人李錫尼，324 年被君士坦丁擊敗。君士坦丁臨終受洗（337）——但真正穩固結盟的是繼任者：**帝國與教會從此互為籌碼**，教義糾紛要皇帝開會仲裁（見 [0325-尼西亞信經](0325-尼西亞信經.md)），皇帝的合法性要教會背書。

## 破案時刻

- 303–311：大迫害失敗，鎮壓成本失控。
- 312：米爾維安橋之役，君士坦丁勝。
- 313：米蘭敕令——宗教自由＋財產歸還。
- 324：李錫尼敗亡，結盟轉為壟斷的前奏。

## 後果 -- 改變了什麼

- **政治**：基督教由非法而合法，帝國獲得新的意識形態基礎。
- **組織**：主教會議、教階制度成為帝國的平行行政系統。
- **思想**：政教關係成為此後千餘年西方史的主軸。
- **反向**：異教的廟宇雖未立即拆，資源與人才開始流向教會。

## 因素影響筆記

1. **鎮壓失敗 → 收編**：當組織網絡無法消滅，轉為合作是交易成本最低的解。
2. **米爾維安橋 → 合法性敘事**：勝利被敘事化為神助——軍事與意識形態的互鎖。
3. **教會組織力 → 治理外包**：帝國用最小成本取得最大動員——結盟的經濟學。
4. **兩帝聯署 → 帝國級政策**：宗教政策首次成為全帝國的統一制度工程。
