# -0073-斯巴達克斯起義：奴隸經濟的系統性風險

## 案件摘要

西元前 73 年，卡普亞角鬥士學校的約七十名角鬥士持廚房刀具逃亡，推舉色雷斯人斯巴達克斯為首領。這場原本是「越獄事件」的反抗，滾雪球成七萬至十二萬人的大起義，縱橫義大利半島兩年多，屢敗羅馬軍團。最後由最富有的元老克拉蘇自掏腰包組軍，加上龐培自西班牙回師合擊，於前 71 年鎮壓。六千名俘虜被釘死在阿庇亞大道沿線的十字架上——羅馬用最殘酷的展示，向整個奴隸經濟體系發出系統風險警告。

## 前因 -- 多因素的局勢

- **經濟**：羅馬的征服戰爭帶來海量奴隸（前 167 年伊庇魯斯一役十五萬人淪奴），大莊園（latifundia）以奴隸勞動取代自由小農。
- **社會**：奴隸占義大利人口約三分之一；角鬥士是「被訓練成武器的奴隸」——羅馬親手武裝了自己的風險。
- **政治**：蘇拉獨裁後的老兵殖民與土地兼併，製造大量失地流民——起義的兵源後備。
- **地理**：義大利半島無常備警力，鎮壓依賴野戰軍團——反應時間以月計。
- **心理**：角鬥士學校的極端壓迫——「沒什麼可失去」者是博弈中最危險的參與者。

## 線索與推理 -- 因素咬合

### 線索一：奴隸經濟是「高槓桿」體系

奴隸是會流血的資本：不折舊於帳面，卻折舊於肉體，且**會反抗**。奴隸莊園的利潤率極高，但系統性風險被外部化：

$$\text{莊園利潤} = \text{產出} - (\text{監工成本} + \text{鎮壓期望成本})$$

平時鎮壓期望成本趨近於零，莊園主便無限擴張奴隸存量——直到起義讓期望成本一次兌現。這是典型的**風險外部性**：個體的理性擴張，累積成系統的脆弱。

### 線索二：鎮壓為何如此昂貴與羞恥

前 72 年起義軍兩度擊敗執政官率領的正規軍，穿越整個義大利南來北往。羅馬的體制尷尬暴露無遺：

| 項目 | 現實 |
|---|---|
| 常備警察 | 無 |
| 軍團駐地 | 遠在邊境 |
| 動員速度 | 數月 |
| 國內防禦 | 靠幸運 |

最後是克拉蘇動用**私人財富**（傳說中他財產的十分之一）自費招募六個軍團——國家安全由私人買單，這件事本身就是共和國失能的證據（此失能將在[-0049-渡過盧比孔河.md]( -0049-渡過盧比孔河.md)中由軍閥收割）。

### 線索三：起義軍為何失敗——沒有出口的博弈

斯巴達克斯多次擊敗羅馬軍，卻始終無法為七萬人找到政治出口：渡海去西西里被海盜出賣、北上翻越阿爾卑斯的選項被部眾的劫掠慾望否決。這是一場**無法談判的博弈**——奴隸起義者若放下武器就是釘十字架，羅馬若妥協則奴隸制度瓦解，雙方都沒有「退出選項」：

$$\text{起義者的困境}：\text{戰鬥的期望值} > \text{投降的確定報酬（死亡）}$$

所以起義軍戰至最後。而克拉蘇以重金懸賞與十一抽殺律（戰敗部隊每十人處死一人）重塑己方激勵——**雙方都在用制度設計打仗**。

## 破案時刻

- 前 73：卡普亞逃亡，起義爆發。
- 前 72：連敗執政官軍，起義軍內部分裂（克力克斯部被殲）。
- 前 71：克拉蘇在盧卡尼亞決戰圍殲，斯巴達克斯戰死；龐培回師收割殘部，並因此分走政治榮光。
- 事後：六千具十字架沿阿庇亞大道綿延，成為「展示性暴力」的極致。

## 後果 -- 改變了什麼

- **政治**：克拉蘇與龐培因鎮壓而聲勢大漲，聯手當選前 70 年執政官——通往[-0060-前三頭同盟.md](-0060-前三頭同盟.md)的第一步。
- **經濟**：奴隸貿易照舊，但莊園主開始在意奴隸來源的多樣化（避免同族同鄉集中）；奴隸制未改革，風險繼續累積。
- **制度**：羅馬並未建立國內治安體系——答案被推給強人。
- **記憶**：這場失敗的起義成為兩千年後反抗壓迫的象徵符號。

## 因素影響筆記

1. **奴隸經濟（經濟）→ 系統性風險（社會）**：高利潤、高外部性的體系，危機是延遲兌現的帳單。
2. **國家失能（政治）→ 私人軍隊（組織）**：鎮壓依賴克拉蘇的錢包——公共安全的私有化是強人政治的前奏。
3. **無退出選項（博弈）→ 血戰到底**：制度的殘酷決定了戰爭的烈度。
4. **展示性暴力（心理）→ 威懾**：六千十字架是發給整個奴隸階級的「風險公告」——但公告不解決風險本身。
