# 1405-鄭和下西洋：世界最大艦隊為何消失

## 案件摘要

1405 年，明成祖朱棣命宦官鄭和率 62 艘巨艦、2 萬餘人自劉家港啟程。此後至 1433 年，七下西洋，遍及東南亞、南亞、波斯灣與東非，寶船長逾百公尺，是當時世界最大的木船艦隊。他不建殖民地，而是冊封國王、擒海盜陳祖義、帶回長頸鹿（麒麟），以厚往薄來的朝貢貿易宣示天威。然而 1433 年鄭和死於歸途後，遠洋戛然而止。這樁案件的兇手是「成本效益不對稱」：一場只賺威望、不賺財政的工程，一旦皇帝意志消失、文官接管預算，注定被裁撤。

## 前因 -- 多因素的局勢

- **政治**：靖難之役（1399–1402）奪位，朱棣合法性不足，急需萬國來朝證明天命；兼傳聞搜尋建文帝下落。
- **經濟**：洪武海禁之下，朝貢是官方壟斷外貿的唯一合法通道。
- **組織**：宦官（鄭和）對文官——皇帝繞開官僚體系的私人代理人。
- **科技**：指南針、水密隔艙、帆裝與《鄭和航海圖》的針路體系成熟。
- **地緣**：帖木兒帝國威脅西陲，須安撫南洋、牽制西亞。

## 線索與推理 -- 因素咬合

### 線索一：朝貢貿易 = 賠本賺吆喝

朝貢規則是厚往薄來——藩國進薄禮、明廷回厚賜，加上沿途賞賜與軍費：

$$\text{淨收益} = \text{政治威望} - (\text{造船} + \text{軍餉} + \text{賞賜} - \text{貢物變現})$$

威望無法入國庫，支出卻是真金白銀。戶部算的是錢，皇帝算的是臉——**兩本帳，注定衝突**。

### 線索二：文官 vs 宦官的委託代理之爭

| | 宦官集團（鄭和） | 文官集團（戶部、翰林） |
|---|---|---|
| 權力來源 | 皇帝私人信任 | 科舉與制度 |
| 對下西洋態度 | 支持（權力與經費） | 反對（靡費、重本抑末） |
| 財政觀 | 威望即收益 | 量入為出、重農 |

宣德以後國庫吃緊（安南戰爭、營建北京），文官以「祖制海禁」為武器收回預算——**下西洋是皇權的私房錢工程，不是國家的生意**。

### 線索三：與葡萄牙的對照

鄭和船隊是朝廷消費品，達伽馬船隊是上市公司：前者的 KPI 是來朝國數，後者是胡椒利潤。一個花錢，一個賺錢——**激勵不同，壽命不同**。

## 破案時刻

- 1405–1433：七下西洋，最遠抵東非麻林迪。
- 1433：鄭和卒於古里返航途中。
- 1436、1500 年代：兵部郎中劉大夏藏匿航海檔案、海禁加嚴，遠洋能力自我銷毀。

## 後果 -- 改變了什麼

- **中國**：重返內陸帝國與海禁，走私與倭寇問題反而惡化。
- **南洋**：華人移民網絡（下南洋）失去官方保護傘。
- **世界史**：最大的反事實——若明朝轉向貿易帝國，大航海主角可能易主。

## 因素影響筆記

1. **合法性需求 → 威望工程**：政治因素啟動遠洋。
2. **厚往薄來 → 財政赤字**：經濟上不可持續。
3. **皇權私器 → 制度無根**：組織上隨皇帝死亡而終結。
