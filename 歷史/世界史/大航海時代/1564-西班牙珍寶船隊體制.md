# 1564-西班牙珍寶船隊體制：用時刻表打敗海盜的白銀 конвей帶

## 案件摘要

1564 年起，西班牙王室立法固定「印度船隊」（Flota de Indias）：每年兩支護航船隊——新西班牙船隊赴韋拉克魯斯、加萊恩船隊赴南美，哈瓦那集結後返航塞維亞，全程武裝蓋倫護航、商船編隊同行。此案的兇手是「時刻表＋編隊＋護航」：西班牙以軍事物流把加勒比海盜時代終結了半個世紀——白銀變成按班次發車的國家快遞。

## 前因 -- 多因素的局勢

- **經濟**：波托西、薩卡特卡斯白銀噴發（[1545-波托西銀礦與價格革命.md](1545-波托西銀礦與價格革命.md)），單船白銀價值連城——海盜的獎盃越來越大。
- **軍事**：法國、英國私掠猖獗（德雷克即將登場，見[1580-德雷克環球與私掠.md](1580-德雷克環球與私掠.md)），單船航行等於送貨上門。
- **行政**：卡薩契約之家（[1503-卡薩契約之家.md](1503-卡薩契約之家.md)）已能審批登記，缺的是海上執行——衙門管得到港口，管不到大洋。
- **技術**：蓋倫船（galleon）火炮甲板成熟，可兼商兼戰；哈瓦那、聖胡安要塞化——護航有了硬體。
- **金融**：海事保險（[1523-海事保險與共同海損.md](1523-海事保險與共同海損.md)）使編隊延誤成本可計算——晚開船三個月 vs 被劫整船，帳算得過來。
- **氣象**：信風、灣流、颶風季已被掌握——時刻表可寫（七月離港、八月集結、避開九月颶風）。

## 線索與推理 -- 因素咬合

### 線索一：編隊的數學

單船被劫機率 $p$ ，護航編隊以火力把 $p$ 壓到 $p'$ ，代價是全隊等最慢的船：

| | 單船散航 | 船隊編隊 |
|---|---|---|
| 被劫機率 | 高（ $p \approx 0.15$ ） | 低（ $p' \approx 0.02$ ） |
| 平均航時 | 短 | 長 30–50 天 |
| 保費 | 12–15% | 6–8%（減半） |
| 王室稅收 | 易流失（走私） | 集中查驗，quinto 足額 |

期望成本比較：

$$E_{convoy} = \text{延誤成本} + p'V < pV = E_{solo}$$

只要貨值 $V$ 夠大（白銀！），編隊永遠划算——白銀的價值密度養活了整個護航體系。

### 線索二：時刻表即權力

船隊每年固定班次：春季塞維亞出發、夏季抵韋拉克魯斯交易市集（feria）、冬季前返航。美洲殖民地經濟被調成西班牙時間——市集、稅收、官員輪換全跟船隊走。偵查結論：**物流時刻製造了帝國節律**——利馬、墨西哥城的物價隨船隊到港而波動，馬尼拉大帆船（[1571-馬尼拉大帆船.md](1571-馬尼拉大帆船.md)）亦須與之銜接——太平洋與大西洋共用一本時刻表。

### 線索三：僵化的代價

船隊制保護了白銀，也凍結了競爭：商船須等護航、須走指定港口、須用指定船型——運力永遠短缺，運費高企，殖民地工業品全賴進口。英國、荷蘭以「 BOT 式走私＋私掠」蠶食邊緣（牙買加、背風群島），船隊護不住每一處海岸。偵查結論：此即「保護的詛咒」：**最安全的體制，培養出最脆弱的產業**——十八世紀波旁改革想拆船隊，已拆不動既得利益。

### 線索四：範例——1715 年寶藏艦隊

1715 年颶風吞掉整支返航船隊（佛羅里達外海，千萬比索沉底），王室一年軍費泡湯——編隊把風險從「被劫」換成「共沉」。現代打撈公司至今仍在撈這批銀幣——船隊制的遺產變成海底遺產。

## 破案時刻

- 1564：船隊條例成文化，雙船隊制確立。
- 1571–1580：哈瓦那集結制成熟，私掠損失驟降。
- 1588：無敵艦隊覆滅後護航一度吃緊，但船隊制不墜。
- 1739–1748：詹金斯耳朵戰爭中船隊屢遭截擊，體制開始鬆動；1790 年代廢止。

## 後果 -- 改變了什麼

- **物流**：發明了國家級定期護航班輪——軍事物流的海洋原版。
- **財政**：quinto 穩定二百年，西班牙帝國的現金流壓艙石。
- **經濟**：運力壟斷＋高運費→殖民地產業空心化，走私經濟與之共生。
- **世界史**：證明「安全可以制度化生產」——也證明過度保護即慢性自殺。

## 因素影響筆記

本案件的因素因果鏈：

1. **白銀高貨值（經濟）→ 編隊護航划算（軍事）**：價值密度決定物流形態。
2. **卡薩審批＋保險定價（制度）→ 時刻表可行**：衙門＋保單養出班次。
3. **時刻表（物流）→ 殖民地經濟節律化**：帝國時間即船隊時間。
4. **保護（安全）→ 壟斷僵化 → 走私＋衰落**：安全的長期負迴路。
