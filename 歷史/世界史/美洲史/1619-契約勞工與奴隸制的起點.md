# 1619 契約勞工與奴隸制的起點：一紙紀錄與一部法典

## 案發現場

1619 年 8 月，「胡獅號」（White Lion）與「財寶號」（Treasurer）兩艘私掠船把約 20 餘名非洲人帶抵維吉尼亞的點康福特（Point Comfort）——他們原是被葡萄牙奴隸船運往墨西哥途中、被英荷私掠船劫走的貨物。維吉尼亞的紀錄只寫著他們被「以口糧換得」（bought for victualle）——這是英屬北美非洲勞動史的最早一頁。

此後數十年，「非洲人在殖民地的法律身分」從曖昧走向定型：1660 年代，維吉尼亞與馬里蘭先後立法——**改宗基督教不得免於奴役、奴隸身分世襲、黑白通婚入罪**——種族奴隸制的法典成形。

> **為什麼 1619 年的「曖昧身分」會在四十年後凝固成世襲的種族奴隸制？是法律的演進、勞動市場的短缺，還是契約勞工制度本身的演化把社會推向了種族奴隸制？**

## 偵查過程

**線索一：1619 年的曖昧——初期並非法定的奴隸制。** 1619 年抵達的非洲人，身分處於**契約勞工與奴隸之間的灰區**：安東尼與瑪麗·約翰遜（Anthony and Mary Johnson）夫婦服完年限後取得土地、擁有僕人，甚至打贏了官司——十七世紀 20–40 年代，部分非洲人以契約身分獲釋。偵查：英格蘭普通法**沒有奴隸制的成文傳統**（無羅馬法基礎），初期殖民地只能借用契約勞工的框架處理非洲勞工——**法律真空**是本案的起點，而真空終將被「需求」填補。

**線索二：勞動經濟學——菸草與勞力短缺。** 菸草是勞動密集作物（參見 [1607-詹姆斯鎮](1607-詹姆斯鎮.md)），地力耗竭需要不斷擴張；殖民地面對**勞動短缺**：歐洲移民不夠、工資市場不存在。契約勞工（indentured servants）成為主流：簽四至七年契約換船票與解放時的「自由費」。偵查：1670 年代起，英格蘭本土經濟好轉、契約勞工供給下滑、菸草價格下跌——**勞動成本上升與菸草利潤下滑的剪刀差**，讓「更便宜的終身勞動」成為殖民者階級的理性選擇。經濟壓力是本案的推手。

**線索三：法律演進——從個案到法典。** 1640 年，僕人約翰·潘奇（John Punch）因逃亡被判**終身服侍**——非洲人被刻上終身奴役的第一筆紀錄；1662 年維吉尼亞立法：**子女身分隨母親**（partus sequitur ventrem）——奴隸身分世襲化，且奴役主人之子成為「收益」；1667 年立法：**改宗洗禮不得免役**——宗教藉口被法律封死；1691 年立法：**黑白通婚驅逐**。偵查：法律不是一步到位，而是**逐案補洞**——每一條都堵住上一條的漏洞（改宗免役、通婚、世襲的繞道），最終拼成完整的**種族奴隸法典**。法律的演進方向，由勞動需求的引力決定。

**線索四：契約勞工→種族奴隸制的制度演化。** 偵查：契約勞工制度本身提供了奴隸制的**模板**——買賣契約、拍賣、人身控制、逃亡追緝法（1640s 起已有專對黑人僕人的罰則）——奴隸制是把契約的「年限」拿掉、把「身分」烙成遺傳的簡化版。同時，1676 年**培根叛亂**（Bacon's Rebellion）：契約勞工與非洲人**聯手**燒了詹姆斯鎮——統治階級警覺：跨種族的底層聯盟是威脅；此後轉向以**膚色劃線**的制度，把歐洲裔窮人收編進「自由白人」的特權圈，黑人則整體打入終身奴役。**分化底層，是種族奴隸制的政治功能。**

**線索五：與加勒比及葡語世界的比較。** 巴西與加勒比的糖業奴隸制早於北美（1530s 起），法典與規模也更極端；北美的菸草奴隸制是**移植**（1660 年代起巴巴多斯的奴隸法典成為模板）而非發明。偵查：**種植園經濟＋勞力短缺＋法典移植**三者的組合，在蔗糖與菸草的殖民地上重複出現——奴隸制不是英國的發明，是種植園經濟學的通用解。

## 結案報告

1. **法律真空被需求填補**：1619 年的曖昧身分，在勞動短缺與菸草利潤下滑的壓力下，被逐條立法凝固為世襲種族奴隸制——法律的演進方向由勞動市場的引力決定。
2. **契約制度是奴隸制的模板**：買賣、拍賣、追緝法皆承自契約勞工制；奴隸制是契約制的「終身化＋世襲化」簡化版。
3. **政治功能是分化底層**：培根叛亂後以膚色劃線，收編歐裔窮人、整體奴役非裔——種族界線是統治術的產物，不是自然的分類。
4. **偵探教訓**：追蹤奴隸制的起源，先看**勞動經濟學**（成本剪刀差）與**逐條立法的補洞順序**——制度不是宣布出來的，是在漏洞上一格格補出來的。

## 證據與工具

**法律演進時間表：**

| 年份 | 法律／事件 | 效果 |
|------|-----------|------|
| 1619 | 約 20 餘名非洲人抵維吉尼亞 | 身分曖昧（灰區） |
| 1640 | 潘奇被判終身服侍 | 終身奴役首例 |
| 1662 | 子女身分隨母 | 奴隸身分世襲化 |
| 1667 | 洗禮不得免役 | 封死宗教藉口 |
| 1676 | 培根叛亂 | 底層跨種族聯盟的警訊 |
| 1691 | 黑白通婚驅逐 | 種族界線法律化 |

**勞動經濟學分析：**

```
菸草勞動密集 ⇒ 需求:勞動↑
契約勞工供給↓（1670s 英格蘭景氣）＋菸草價↓
   ↓ 成本-收益剪刀差
終身勞動（奴隸）的單位成本 < 契約勞工
   ↓
法律補洞：世襲＋洗禮失效＋通婚入罪
   ↓
種族奴隸法典（1660s–1690s 定型）
```

**因果鏈：**

```
菸草經濟擴張 → 勞力短缺
   ↓
契約勞工為主流（1630s–60s）
   ↓ 供給下滑＋培根叛亂
轉向種族奴隸制＋分化底層
   ↓
1660s–1690s 奴隸法典定型
```

**結論：** 1619 案的證據鏈：法律真空→勞動短缺→逐條補洞→種族法典。奴隸制不是一紙宣言，而是四十年間在經濟壓力與政治算計下，一條條立法補出來的制度。**制度的惡，往往是漏洞被需求一格格填滿的結果。**
