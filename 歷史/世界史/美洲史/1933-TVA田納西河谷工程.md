# 1933 TVA田納西河谷工程：以水壩偵辦大蕭條的技術新政

## 案發現場

1933 年 5 月 18 日，羅斯福簽署《田納西河流域管理局法》（TVA Act），在美國東南部七州設立聯邦直營的流域開發公司：防洪、發電、化肥、航運、植樹一次打包。十餘年間建成水壩二十餘座（如諾里斯、水牛灘、肯塔基大壩），把全美最貧困的河谷變成廉價電力的輸出地，原子彈計畫的鈾濃縮廠（橡樹嶺）後來直接插上 TVA 的插頭。

與同年其他新政立法（參見 [1933-羅斯福新政.md](1933-羅斯福新政.md)）不同，TVA 不是救濟支票，而是一台「用混凝土寫的電腦」——輸入是河水與預算，輸出是電力、就業與區域規劃。

> **為什麼治一條河要動用聯邦公司？水壩擋住的究竟是洪水，還是市場失靈？廉價電力的真正客戶是誰？**

## 偵查過程

**線索一：河谷的病理報告。** 偵查先看現場：田納西河谷 1930 年代人均所得不到全美一半，水土流失、瘧疾、洪水年年來；私營電力公司嫌農戶分散無利可圖，九成農家無電可用。**市場在這裡缺席**——不是壟斷，而是「無利可圖所以不來」。TVA 的診斷：貧困是系統性的（洪水沖走表土 → 產量下降 → 更砍樹燒柴 → 更多水土流失），單點救濟無效，必須流域整體下藥。

**線索二：多目標水庫的運籌學。** 一座 TVA 水壩同時要裝五種功能：

| 功能 | 手段 | 受益者 |
|------|------|--------|
| 防洪 | 汛期預留庫容 | 下游城鎮 |
| 發電 | 水輪機＋輸電網 | 農戶＋工業 |
| 航運 | 船閘（9 英尺航道直通俄亥俄河） | 內陸貨運 |
| 肥料 | 肌肉灘硝酸鹽廠轉產磷肥 | 缺磷農田 |
| 生態 | 植樹＋瘧疾防治（滅蚊） | 公共衛生 |

偵查關鍵：五個目標互相打架（防洪要空庫，發電要滿庫），TVA 的成就是發明了「水庫調度規則曲線」——**把政治妥協寫成水位公式**。工程師的曲線圖，就是七州利益的停戰協定。

**線索三：公營電力的違憲官司。** 私營電力公司與共和黨指控 TVA 是「社會主義楔子」，官司一路打到最高法院（1936、1939 年 TVA 勝訴）。偵查發現真正的戰場是電價：TVA 家用電價約為私營的一半，逼得周邊私營公司被迫降價——**聯邦用一條河谷當「電價錨」**，全美電費因此被拽下來。所謂意識形態之爭，賬本上是每度電幾分錢之爭。

**線索四：從農田到原子彈。** 二戰改寫 TVA 的客戶名單：鋁（飛機）、磷（炸藥）、電力（橡樹嶺鈾濃縮耗電占全美約一成）。戰時 TVA 發電量九成供應軍工——**治河的水壩變成兵工廠的插座**。戰後廉價電力又孵出橡樹嶺國家實驗室與南方工業帶。偵查結論：基礎設施的「真正用途」從不在可行性報告裡，而在下一場戰爭裡。

## 結案報告

1. **整體下藥**：流域級貧困只能流域級治理，單點救濟會被系統吞掉。
2. **公式即契約**：水庫調度曲線把七州矛盾翻譯成水位，技術規則替代政治吵架。
3. **電價錨效應**：一處公營低價即全網比價壓力，壟斷最怕的不是禁令而是隔壁的低價。
4. **偵探教訓**：看大壩別只看發電量，看它的「第二客戶」——**基礎設施的結案報告由戰爭書寫**。

## 證據與工具

**水庫多目標權衡公式：**

```
Max Σ（防洪效益＋發電收益＋航運＋肥料＋衛生）
s.t. 汛限水位 ≤ 蓄水位 ≤ 壩頂；出力 ≥ 軍工需求（戰時）
調度規則曲線 = 約束條件的圖形化停戰協定
```

**跨領域影響矩陣：**

| 領域 | 變化 | 機制 |
|------|------|------|
| 經濟 | 電價腰斬＋工業化 | 公營錨＋輸電網 |
| 環境 | 水土保持＋瘧疾下降 | 植樹＋水位管理滅蚊 |
| 法律 | 聯邦經營合憲 | 最高法院兩勝 |
| 軍事 | 橡樹嶺＋鋁磷供應 | 廉價大電力 |
| 區域 | 南方工業帶前身 | 電力招商 |

**因果鏈：**

```
河谷系統性貧困 → TVA 法（1933）：聯邦公司＋多目標水壩
   ↓ 調度曲線＋電價錨 ↓ 違憲訴訟敗（私營）
二戰軍工插座（橡樹嶺）→ 戰後南方工業化＋大壩外交模板（輸出各國）
```

**結論：** TVA 案同時是工程案（多目標調度）、法律案（公營合憲）、戰爭案（原子彈的插頭）。**偵辦大蕭條的技術面，水壩就是證物**——混凝土裡封著電價、 mosquitoes 與鈾濃縮機的嗡鳴。
