# 美洲史歷史因果分析

## 案件摘要

美洲史的案卷要從兩端同時讀：北端是一條從 `-11500-克洛維斯矛頭與最早美洲人.md` 經 `-5000-玉米馴化.md` 到 `1964-民權法案.md` 的長卷；南端與中部則是 `1532-卡哈馬卡與五重碾壓.md`（見拉丁美洲卷宗）與 `1519-科爾特斯征服阿茲特克.md` 的征服現場。把整座大陸的證據攤開，因果主軸浮現：**白令陸橋的移民起點決定了生態與技術起始條件，1492 年的接觸重設了整個大陸的命運參數，此後每一次制度選擇（奴隸制、聯邦制、疆域擴張、金融創新）都在放大或修正那個初始斷層**。

$$\text{美洲的走向} = \text{初始生態條件} \times \text{1492 接觸斷層} \times \text{制度選擇的複利}$$

## 因果鏈與回饋環

### 鏈一：接觸斷層→勞動力需求→奴隸制的全球化

瘟疫消滅了美洲原住勞動力（`1521-特諾奇蒂特蘭陷落與文明摘心.md`），殖民者轉向非洲補充；巴巴多斯糖業把種植園模式打磨成「效率機器」（`1640-巴巴多斯糖業革命.md`），再輸出到加勒比與北美南部（`1619-契約勞工與奴隸制的起點.md`、`1739-斯托諾起義與黑人法典.md`）。這條鏈的餘波貫穿整個案卷：`1861-南北戰爭.md` 是它的武裝清算，`1877-重建終結與吉姆克勞.md` 是它的變相復辟，`1964-民權法案.md` 才是第二輪結案——而結案報告至今仍在補寫。

### 鏈二：廉價土地→民主擴張的雙面回饋

```mermaid
flowchart LR
    A[土地取得/購地/戰爭] --> B[小農民主擴大]
    B --> C[政治壓力繼續西進]
    C --> D[原住民族被遷移/戰爭]
    D --> A
```

`1803-路易斯安那購地.md` 與 `1848-美墨戰爭.md` 供應了土地，`1862-宅地法.md` 分配了土地，`1830-印第安遷移法與血淚之路.md` 與 `1890-傷膝河與邊疆關閉.md` 記錄了原住民族的代價。**美國民主的廣度與原住民族的損失是同一筆帳的兩欄**。

### 鏈三：規模化生產→大眾消費→金融化

福特的大量生產（`1903-福特T型車與大量生產.md`）創造了高工資大眾消費社會；`1929-華爾街股災與大蕭條.md` 暴露其金融脆弱性；`1933-羅斯福新政.md` 與 `1933-TVA田納西河谷工程.md` 重建了國家與市場的契約；戰後 `1944-布雷頓森林體系.md` 把美國配方輸出全球；最後 `1978-401k退休金融化.md` 把風險從國家轉回家庭——**同一體系百年內完成「製造—福利—金融」三次換檔**。

### 鏈四：移民作為系統的進料口

`1620-五月花號公約.md` 設定了自治與宗教容忍的初始碼；`1849-加州淘金潮.md`、`1916-大遷徙與黑人北遷.md`、`1965-移民與國籍法.md` 顯示每一次勞動力缺口都會修改移民規則；而 `1969-阿爾卡特拉斯佔領與紅權運動.md` 提醒：系統的原始債權人（原住民族）從未在帳本上被註銷。

## 反事實推演

- **若巴巴多斯糖業未成功**：種植園模式可能停留在試驗階段，北美南部的奴隸制或以較小規模存在，南北戰爭的地質構造將大幅改變——但美洲對強制勞動的需求仍會尋找其他出口。
- **若 1803 年購地未成**：法國資金需求遲早出售路易斯安那（或英國取得），美國西進不會停止，但跨大陸擴張的法制路徑（購地 vs 戰爭）比例會不同。
- **若新政未發生**：大蕭條的政治後果可能是更激進的民粹或更保守的撙節；布雷頓森林體系的「嵌入式自由主義」未必出現，戰後世界秩序的地基將改用其他材料。
- **若 1965 年移民法未開放**：美國的人口紅利與亞洲、拉美的勞動力外流壓力同時受阻，`1994-北美自由貿易協定.md` 之後的移民議題形態將完全不同——人口流動是結構需求，法律只是閥門。

## 偵探教訓

1. **從起始條件算複利**：馴化動植物、接觸斷層、制憲妥協——早期的微小差異經百年複利成為巨大分岔。
2. **同一筆帳的兩欄**：繁榮的貸方幾乎總有一個對應的借方（奴隸、原住民族、勞工），偵探要同時讀兩欄。
3. **制度是回饋環的節流閥**：同樣的土地擴張，法制化的購地與暴力的遷移可以在同一部憲法下並存——問「規則為誰改寫」。
4. **偶發與必然**：福特個人、仙童八叛將是偶發；規模化生產與技術動員的需求是必然。歷史的槍聲由個人扣發，彈道由結構決定。
