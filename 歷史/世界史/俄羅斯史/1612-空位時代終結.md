# 1612 空位時代：米寧與波扎爾斯基的國民軍

## 案發現場

1598 年伊凡之子費奧多爾死（絕嗣，參見本書 [1547-伊凡四世.md](1547-伊凡四世.md)），留里克王朝斷絕。鮑里斯·戈東諾夫、偽德米特里一世二世輪番登台，波蘭佔領莫斯科（1610–12），瑞典佔諾夫哥羅德。1612 年，下諾夫哥羅德商人米寧募款、波扎爾斯基率國民軍光復莫斯科；1613 年縉紳會議選米哈伊爾·羅曼諾夫為沙皇。十五年空位時代終結。

> **王朝斷絕時，誰來救國？商人募款、屠夫捐錢、貴族帶兵——國民軍的錢從哪裡來，合法性從哪裡來？**

## 偵查過程

**線索一：絕嗣的連鎖（一個鐵杖的代價）。** 伊凡誤殺太子（1581），次子費奧多爾低能，幼子德米特里離奇死亡（烏格里奇事件，1591）——1598 年斷嗣。偵查結論：空位時代的**第一因是生育事故**：專制體制下，王位繼承=國家存續，太子之死=定時炸彈。鮑里斯（攝政上位）缺合法性→偽德米特里（真假難辨）有機可乘→波蘭干預→全面內戰。**繼承制度是專制國家的單點故障**——沒有備份（兄弟、議會），一點即全盤崩。這是秦二世而亡的羅斯版：**制度不備份，血緣一斷就當機**。

**線索二：偽德米特里的市場（冒名者的供需）。** 先後出現三個偽德米特里（自稱烏格里奇逃生的皇子），波蘭、哥薩克輪番支持。偵查結論：冒名者是**合法性真空中的套利**：只要有人相信（或假裝相信），名字就能換軍隊。波蘭支持偽德米特里=用一個名字入侵俄羅斯——**信息不對稱時代的低成本戰爭**（沒人能驗血緣）。各地擁偽與反偽，實為地方勢力**選邊下注**：賭對了封官，賭錯了掉頭。空位時代的本質是**全國性的賭場**，賭注是王位。

**線索三：米寧的募款（商人救國的眾籌）。** 下諾夫哥羅德屠夫出身的米寧號召捐獻（「不惜妻子兒女，拯救祖國」），商人捐錢、市民捐物，雇波扎爾斯基（貴族將領）帶兵。偵查結論：這是**戰爭眾籌**：國家失能時，社會用市場方式組織軍隊——出錢的（商人）+出力的（市民）+懂行的（貴族將領）三方合資。與壬辰義兵（參見 [../韓國史/1592-壬辰衛國戰爭.md](../韓國史/1592-壬辰衛國戰爭.md)）同構：**國家崩潰時，社會用現成網絡（商會、宗族）自救**。米寧的特殊性：他是**職業經理人**——不管打仗（交給波扎爾斯基），只管錢和糧——**分工即戰力**。

**線索四：縉紳會議選沙皇（選舉的君主制）。** 1613 年縉紳會議（教士、貴族、市民代表）選舉米哈伊爾（16 歲，羅曼諾夫家族，與留里克有姻親）。偵查結論：這是**俄羅斯唯一的選王時刻**：各等級用選票終結賭場。選米哈伊爾的邏輯——年輕（好控制）、有血緣（不斷統）、非波蘭（愛國）。諷刺的是：**用選舉產生的專制，迅速取消選舉**（羅曼諾夫此後三百年再無縉紳會議）——選舉是手段，不是信念。但1613 年的先例長存：**主權在民的種子（哪怕是等級的民）一旦播下，總會發芽**——1917 年二月革命的杜馬，遠親正是縉紳會議。

## 結案報告

1. **單點故障**：太子之死=國家當機——專制無備份，血緣一斷即崩。
2. **名字即軍隊**：偽德米特里的套利——信息不對稱時代，名字可換軍隊。
3. **眾籌救國**：商人出錢+市民出力+貴族帶兵——社會自救的分工公式。
4. **選舉的專制**：縉紳會議選沙皇——手段非信念，但種子長存，1917 年發芽。

**跨領域影響矩陣：**

| 領域 | 終結工程 | 跨域效應 |

| 經濟 | 米寧募款、商人捐獻 | 戰爭眾籌 |
| 科技 | 火器國民軍 | 市民武裝 |
| 政治 | 驅逐波蘭、羅曼諾夫 | 三百年王朝開張 |
| 文化 | 11 月 4 日民族團結日 | 記憶的年度充值 |

**崩潰 vs 重建（對照）：**

| 階段 | 主體 | 機制 |
|------|------|------|
| 1598–1605 | 鮑里斯（無合法性） | 攝政 |
| 1605–10 | 偽德米特里（套利） | 賭場 |
| 1610–12 | 波蘭佔領 | 外國託管 |
| 1612 | 國民軍（眾籌） | 社會自救 |
| 1613 | 縉紳會議 | 選舉終結 |

**重建公式（示意）：**

```
重建 ＝ 錢（米寧眾籌）＋ 槍（波扎爾斯基）＋ 章（縉紳會議選舉）。
國家失能時，社會用市場＋選舉重建國家。
```

**結論：** 空位案是「國家重啟」的完整樣本：血緣斷線→賭場開張→外國託管→眾籌救國→選舉終結。**專制的單點故障由社會的三方合資修復**——商人的錢、貴族的槍、會議的章。羅曼諾夫的三百年，開張於一場眾籌和一次選舉——專制王朝最諷刺的身世。
