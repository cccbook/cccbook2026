# 1762 葉卡捷琳娜二世：開明專制的兩面

## 案發現場

1762 年，德國公主索菲亞（改宗後名葉卡捷琳娜）發動政變，丈夫彼得三世被廢殺，自己加冕女皇。在位 34 年：致函伏爾泰談啟蒙、頒貴族特許狀（1785）、三次瓜分波蘭（1772、1793、1795）、南下黑海；同時鎮壓普加喬夫起義（1773–75，殺百萬級人口波及）、強化農奴制（農奴可被買賣如物）。開明與專制，啟蒙與農奴——同一個女皇的兩張臉。

> **給伏爾泰寫信的人，為何把農奴釘得更死？開明專制是理想、是偽裝，還是統治的精密計算？**

## 偵查過程

**線索一：政變上位（合法性的先天不足）。** 德國人、靠政變（近衛軍）上位、丈夫死因不明——三重原罪。偵查結論：葉卡捷琳娜的開明姿態首先是**合法性公關**：致函伏爾泰（歐洲輿論）、召開立法會議（1767，雖無果）、談論孟德斯鳩——**用啟蒙的語言包裝政變的出身**。啟蒙是口紅，政變是底色。但口紅也有用：歐洲承認她是「哲學家女皇」，俄羅斯的國際地位上升——**合法性可以進口**，伏爾泰的讚美信就是進口單據。

**線索二：普加喬夫起義（農奴的總爆發）。** 頓河哥薩克普加喬夫自稱彼得三世（未死），揭竿，席捲伏爾加—烏拉爾，農奴、工廠農民、少數民族響應，號稱百萬之眾。偵查結論：起義的根在**農奴制的強化**——葉卡捷琳娜為酬謝貴族（政變功臣），把國有農民賞給貴族、私營工廠農民處境惡化。起義是**賬單到期**：開明的口紅下，農奴的負擔加重了。鎮壓（蘇沃洛夫）後，女皇反而**進一步收緊**（農奴主可流放農奴去西伯利亞）——**起義的教訓不是放鬆，是貴族更需要沙皇保護**：恐懼把貴族與皇權綁得更緊。鎮壓的意外效果：**專制的同盟更牢固了**。

**線索三：瓜分波蘭（三次切蛋糕）。** 俄普奧三次瓜分波蘭立陶宛（1772、1793、1795），波蘭亡國，俄羅斯西進數百公里，得烏克蘭、白俄羅斯大部。偵查結論：這是**無本萬利的擴張**：波蘭貴族民主制（自由否決權，一人可否決全國）已癱瘓，鄰國切蛋糕如切黃油。葉卡捷琳娜的算盤——**不費一槍一彈（相對）拿下半個東歐**。但附帶一個百年包袱：境內多了數百萬波蘭人、天主教徒、猶太人（定居區）——**擴張的領土好消化，擴張的人口不好消化**。波蘭復國主義、猶太人問題，此後一百五十年都是俄羅斯的病灶。**切蛋糕容易，消化蛋糕難**。

**線索四：貴族特許狀（專制的包養合同）。** 1785 年特許狀：貴族免服役、免體罰、財產不可侵犯、組貴族會議。偵查結論：這是**用特權買忠誠**：彼得的服役貴族（參見本書 [1682-彼得大帝.md](1682-彼得大帝.md)）在此變成食利貴族——不當官也是貴族。皇權與貴族的契約：**你不管我專制，我不管你剝削農奴**。開明專制的真相：**開明是給歐洲看的，專制是給貴族分的，農奴付賬**。這份合同維持到 1861 年（參見本書 [1861-農奴解放.md](1861-農奴解放.md)）——農奴為貴族的特權付了七十年地租。

## 結案報告

1. **口紅理論**：啟蒙是政變的合法性公關——合法性可以進口，伏爾泰是供應商。
2. **賬單理論**：普加喬夫是強化農奴的賬單——鎮壓反而綁緊皇權貴族同盟。
3. **蛋糕理論**：瓜分波蘭無本萬利——但人口難消化，病灶一百五十年。
4. **包養合同**：特許狀分特權買忠誠——開明給歐洲看，專制給貴族分，農奴付賬。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 女皇工程 | 跨域效應 |
|------|----------|----------|
| 法律 | 貴族特許狀、城市章程 | 特權法制化 |
| 經濟 | 賞國有農民、農奴強化 | 財政靠人頭 |
| 科技 | 斯莫爾尼學院、科学院 | 啟蒙裝潢 |
| 政治 | 瓜分波蘭、黑海擴張 | 帝國西進南下 |
| 文化 | 致函伏爾泰、冬宮收藏 | 哲學家女皇人設 |

**兩張臉（對照）：**

| 面向歐洲 | 面向俄羅斯 |
|----------|------------|
| 致函伏爾泰 | 鎮壓普加喬夫 |
| 立法會議 | 貴族特許狀 |
| 啟蒙話語 | 農奴可買賣 |
| 冬宮藝術 | 西伯利亞流放 |

**開明專制公式（示意）：**

```
開明專制 ＝ 啟蒙話語（出口）＋ 貴族特權（分贓）＋ 農奴負擔（買單）。
三者缺一即不穩：無話語則無合法性，
無分贓則貴族反，無買單則財政崩。
```

**結論：** 葉卡捷琳娜案是「開明專制」的完整樣本：口紅（啟蒙）、分贓（貴族）、買單（農奴）、蛋糕（波蘭）——四件套運轉三十四年，俄羅斯成為歐洲強權。**開明的真偽不重要，重要的是它有用**——對女皇有用（合法性），對貴族有用（特權），對農奴無用（負擔加重）。有用即真實，政治的唯一標準。
