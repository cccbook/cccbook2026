# 1936 大清洗：革命吞噬自己的兒女

## 案發現場

1934 年列寧格勒市委書記基洛夫遇刺（兇手尼古拉耶夫，背景至今成謎）——史達林以此為藉口，發動大清洗（1936–38）：三次莫斯科公審（季諾維也夫、加米涅夫、布哈林、李可夫認罪伏法），軍隊清洗（圖哈切夫斯基等 3 元帥、1.5 萬軍官），內務部兩任首腦（雅戈達、葉若夫）也被處決。受害者逾百萬（處決 70 萬+，勞改數百萬）。革命的締造者，幾乎被殺光。

> **為何先殺自己人？公審的認罪是真是假——恐怖的真正目標是敵人，還是恐懼本身？**

## 偵查過程

**線索一：基洛夫之死（藉口的製造）。** 1934.12 基洛夫在走廊被槍殺——警衛恰好缺席、兇手此前被捕又釋放，疑點重重（史達林下令？至今無定論）。偵查結論：**真相不重要，用途重要**：史達林立即推出「反革命恐怖」敘事，頒特別程序（十天結案、不許上訴、立即執行）。基洛夫之死=**國會縱火案式的授權事件**：一次暗殺，換來清洗一切的許可證。基洛夫生前是溫和派（十七大「代表」傳聞）——**潛在的替代者必須先變成死者，再變成藉口**。一石二鳥：除掉威脅，拿到授權。

**線索二：公審的認罪（劇本的動機）。** 季諾維也夫等老布爾什維克在公審中「認罪」（間諜、暗殺、破壞），證據多為拼湊。偵查結論：認罪的動機是**交易+絕望**：以認罪換家人平安（多未兌現）、以配合換速死（免受刑）。維辛斯基的公訴詞是劇本，法庭是劇場——**審判的功能不是查明真相，是廣播恐怖**：連列寧的戰友都是叛徒，人人自危。認罪的政治效果：**反對派的歷史合法性被註銷**——十月革命變成史達林一人的功業（照片修掉托洛茨基）。**歷史在此被重寫，底片用血洗**。

**線索三：清洗軍隊（自廢武功）。** 1937–38 年處決圖哈切夫斯基（機械化戰爭理論家）等大批軍官——紅軍指揮層斷代。1941 年德軍入侵初期的慘敗（參見本書 [1941-衛國戰爭.md](1941-衛國戰爭.md)），部分源於此（師級指揮員多是速成提拔）。偵查結論：這是**恐怖的反噬**：史達林怕軍隊政變（圖哈切夫斯基與德國軍方有往來+威望高），先下手為強——**用國防換安全**。獨裁者的困境：能打仗的將軍也能政變（參見袁世凱，[../亞洲史/1911-辛亥革命.md](../亞洲史/1911-辛亥革命.md)）——**忠誠與能力不可兼得時，獨裁者選忠誠**。1941 年的學費：三百萬戰俘、丟掉半壁江山——清洗的帳單，德國人幫忙寄到。

**線索四：恐怖的均衡（人人告密的社會）。** 清洗波及全社會：工廠完不成計劃=破壞、說錯話=反革命、親屬連坐。告密成風（帕夫利克·莫羅佐夫舉報父親成模範）。偵查結論：恐怖的目標不是消滅敵人（敵人早沒了），是**製造服從**：當任何人可能因任何事被捕，**自我審查代替警察**——社會自我馴化。這是成本最低的統治：**警察只處理抽查，恐懼處理日常**。與秦「以法為教」（參見 [../世界發展史/-0221-秦統一.md](../世界發展史/-0221-秦統一.md)）對照：秦用法條明碼標價，史達林用**不確定性**定價——不知道什麼會被捕，所以什麼都不敢做。**確定的恐怖是法律，不確定的恐怖是馴化**。

## 結案報告

1. **藉口理論**：基洛夫之死=授權事件——真相不重要，許可證重要。
2. **劇場理論**：公審廣播恐怖+註銷反對派歷史——底片用血洗。
3. **忠誠陷阱**：清洗軍隊用國防換安全——1941 年帳單寄到。
4. **馴化理論**：不確定的恐怖最便宜——自我審查代替警察，恐懼處理日常。

**恐怖經濟學（示意）：**

```
統治成本 ＝ 警察（抽查）＋ 恐懼（日常）。
確定的法：人人算得清代價→敢鑽空子。
不確定的恐怖：算不清→什麼都不敢→自我馴化。
史達林選後者——最便宜，也最貴（1941 年結算）。
```

**結論：** 大清洗案是「恐怖統治」的完整樣本：藉口（基洛夫）、劇場（公審）、忠誠陷阱（殺將軍）、馴化（不確定性）——四件套運轉三年，革命者殺光，社會馴服。**恐怖的邏輯終點是自我吞噬**：劊子手輪流上斷頭台，無人安全——包括史達林自己（1953 年死於無人敢救的中風，傳說）。馴化了他人的，最終也被馴化。
