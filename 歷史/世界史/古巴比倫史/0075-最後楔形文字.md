# 0075 最後楔形文字：天文日記的黃昏

## 案發現場

公元 75 年（一說前後），巴比倫埃薩吉拉神廟祭司刻下最後一塊楔形文字泥板（天文日記：某月某日，木星在某某座，物價若干）——此後，楔形文字退出歷史（希臘化、帕提亞、羅馬，改用阿拉姆語、希臘語）。從 -3200 年烏魯克第一筆賬（參見本書 [-3200-烏魯克與楔形文字.md](-3200-烏魯克與楔形文字.md)）到公元 75 年，泥板寫了 3275 年。**最後一筆，寫的是星星——開頭是羊，結尾是星，中間是什麼？**

> **文字會死嗎？當最後一個會寫楔形字的人放下蘆葦筆，他知不知道自己在關一扇三千年的門？**

## 偵查過程

**線索一：天文日記（祭司的最後工作）。** 塞琉古時代至帕提亞時代，巴比倫祭司堅持記天文日記（每晚：行星位置、月相、物價、河水位、事件）——連續數百年（一說最長連續觀測記錄）。偵查結論：這是**傳統的慣性**：城空了（政治遷走，參見本書 [-0305-塞琉西亞.md](-0305-塞琉西亞.md)）、廟窮了（香火少）、星照看（習慣）——**沒人付錢還觀星**：俸祿（廟產縮水）不夠，傳統不夠嗎？夠——**習慣比工資長壽**。天文日記的科學價值（現代天文學家用它定古代地球自轉減速，一說）——**祭司隨手記的，科學家當寶**。最後一塊泥板（75 年，木星+物價）平平無奇——**偉大的謝幕往往無聲**（沒有「永別了楔形文字」的跋，只有例行的星和價）。**傳統死於某個週二的黃昏**（例行公事，做到一半，人沒了/不做了）。

**線索二：阿拉姆語的取代（通用語的換代）。** 波斯帝國（-539 起）行阿拉姆語（帝國通用語，字母文字，好學），希臘化（希臘語，行政），帕提亞（帕拉維語）——楔形文字退守神廟（祭司內部用）。偵查結論：這是**書寫的達爾文主義**：字母（二十幾個符號，三天學會）vs 楔形（幾百個符號，十年學會）——**好學的贏**（參見訓民正音，[../韓國史/1443-訓民正音.md](../韓國史/1443-訓民正音.md)：表音贏表意，同款）。楔形文字的死因：**難學（十年）+載體重（泥板）+用戶少（祭司）**——三重劣勢，神仙難救。阿拉姆語（耶穌說的語言，一說）的勝利：**帝國推廣（波斯）+商人使用（絲路）+宗教採用（猶太教部分經典）**——三重優勢。**文字的進化不看美醜（楔形很美），看學費**——學費貴的死，學費便宜的活。此案給簡化字（1956）：**同樣的賬**（難學→簡化→普及）——三千年，同一道題。

**線索三：最後書記（無名氏的謝幕）。** 最後泥板無署名（一說有名字但殘缺）——不知其名，不知其貌，只知他那晚看了木星、記了物價。偵查結論：這是**歷史的匿名性**：開頭（烏魯克）無名（第一個書記是誰？不知道），結尾（75 年）也無名——**三千年，頭尾都不知姓甚名誰**，中間倒是名垂了幾個（辛萊基溫寧尼，參見本書 [-1200-吉爾伽美什史詩.md](-1200-吉爾伽美什史詩.md)）。**書記階級的宿命：記錄一切，留下自己最少**（史官傳統：記事不記己，參見司馬遷自序是例外）。最後書記放下筆時（75 年某夜，巴比倫，埃薩吉拉神廟，燈油將盡，一說文學想象）——他不知道這是最後一筆（以為明天還寫）——**所有的「最後」都是事後追認的**（當時人只覺得是平常一天）。**平常心的偉大**：認真記完最後一筆星和價，然後回家——**謝幕不需要觀眾**。

**線索四：3275 年的賬（從羊到星）。** -3200 年第一筆：羊三頭（一說）；75 年最後一筆：木星在某某座、大麥一升銀若干——**開頭是賬（羊），結尾也是賬（星+價）**，中間三千年：法典、史詩、書信、星表——**全是賬的變體**（法律是行為賬，史詩是記憶賬，書信是外交賬，星表是時間賬）。偵查結論：這是**文字的功能守恆**：生於記賬（烏魯克），死於記賬（天文日記的物價欄）——**有始有終，賬賬相連**。楔形文字的一生：會計（-3200）→文學（-1200）→科學（-500 天文）→遺物（75 年後）——**工具的生命週期**：趁手（壟斷）→過時（字母來了）→情懷（祭司堅守）→化石（博物館）。**化石的價值**：19 世紀 decipher（釋讀，羅林森貝希斯敦銘文，1835–47）——**死文字復活**（今人人可學，年輕人拿它當紋身，一說）。**死亡不是終點，被遺忘才是**——楔形文字死於 75 年，活於 1835 年（釋讀），火於表情包時代（楔形文字符號？一說）。

## 結案報告

1. **慣性定律**：沒錢還觀星——習慣比工資長壽，謝幕無聲。
2. **學費定律**：文字進化看學費——難學的死，便宜的活。
3. **匿名定律**：頭尾無名——書記記錄一切，留下自己最少。
4. **守恆定律**：生於賬死於賬——工具生命週期，死亡非終點。

**跨領域影響矩陣：**

**文字公式（示意）：**

```
文字壽命 ＝ 壟斷期（官方用）＋ 情懷期（祭司守）− 學費（難學）。
楔形：官方三千年 ＋ 祭司三百年 − 學費貴 → 3275 年。
學費是唯一的死因——其他都是併發症。
```

**結論：** 最後楔形文字案是「文字之死」的完整樣本：慣性觀星、學費致死、匿名謝幕、賬賬相連——3275 年，一筆星收尾。**開頭是羊（三頭），結尾是星（木星），中間是三千年的人間**——法典、史詩、書信、星表，全是賬。這是本書的最後一案，也是第一案（-3200 篇）的回聲：**泥板開於賬，終於賬**。75 年那晚，巴比倫的祭司放下蘆葦筆，吹熄燈，走出埃薩吉拉——他不知道，自己關了一扇三千年的門。門外是阿拉姆語、希臘語、阿拉伯語的喧譁——**新文字吵吵嚷嚷，老文字安靜退場**。1835 年，羅林森在貝希斯敦崖壁下抄波斯楔形，門又開了一條縫——**死亡不是終點，被遺忘才是**。楔形文字沒被遺忘（博物館+紋身+表情包），所以它沒死——**它只是換了種活法：從工具，變成化石，變成潮物**。三千年，不虧。
