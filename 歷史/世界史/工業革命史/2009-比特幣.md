# 2009-比特幣：白皮書、創世區塊與去中心化信任的多因案件

## 案件摘要
2009 年 1 月 3 日創世區塊挖出，兇手不是某個天才的靈光，而是 2008 金融海嘯摧毀銀行信任、密碼龐克二十年鋪路、工作量證明點燃引線的三重咬合；比特幣以降「信任中介成本」為武器，證明沒有銀行也能轉帳。

## 前因 -- 多因素的局勢
- **經濟**：2008 雷曼倒閉、各國印鈔救市，法幣濫發恐懼＋「銀行大到不能倒卻能作惡」激起另類貨幣渴求。
- **政治**：密碼龐克（cypherpunk）無政府自由意志傳統——1990 年代 DigiCash、E-gold 被政府掐死，教訓是「中心化必被拔插頭」。
- **法律**：創世區塊留言「Chancellor on brink of second bailout for banks」（2009-01-03《泰晤士報》），把對銀行紓困的憤怒鑄進鏈上，政治宣言即出生紙。
- **金融**：雙花問題（double-spending）是數位現金三十年死結：無中介則一幣多花，有中介則重回銀行。
- **技術**：Hashcash（Adam Back 1997）＋b-money（Wei Dai）＋Bit Gold（Szabo）＋Merkle 樹＋P2P，零件早已躺在桌上，只差組裝圖。
- **心理**：金融海嘯後的虛無與極客浪漫——與其上街，不如寫 code 另起爐灶。

## 線索與推理 -- 因素咬合

### 線索1：白皮書——八頁紙的組裝圖
2008-10-31 中本聰（Satoshi Nakamoto）貼出《Bitcoin: A Peer-to-Peer Electronic Cash System》，定義：交易打包成區塊、節點比算力投票、作惡成本高於誠實收益。因果鏈：
$$\text{交易廣播} \to \text{節點打包＋解 PoW} \to \text{最長鏈即真相} \to \text{雙花需重寫全鏈} \to \text{作惡不划算}$$
```pseudocode
# 拜占庭將軍問題的算力解
while True:
  block = collect(tx_pool) + prev_hash + nonce
  if sha256(sha256(block)) < target:  # 工作量證明
    broadcast(block); break
  nonce += 1
# 誠實鏈最長最重，叛將要追上需燒掉同等電力
```

### 線索2：工作量證明 vs 拜占庭將軍問題
分散式系統經典難題：互不信任的將軍如何約定同一進攻時間？中本聰答案：用電力投票、機率終局。學術對照：
| 傳統 BFT（PBFT） | 比特幣 PoW |
|---|---|
| 需已知節點名單、2/3 誠實 | 匿名可進出，靠算力權重 |
| 即時確定性 | 機率確定性（6 確認≈不可逆） |
| 高效但中心化傾向 | 耗能但抗審查、抗關停 |
推理：PoW 把「信任的成本」從牌照＋法庭轉成電費——貴，但誰也關不掉。

### 線索3：信任的成本理論——兇手是中介費
Coase 交易成本＋銀行學：每筆轉帳要付清算費、詐欺準備金、監管合規費與「銀行會不會倒」的風險溢價。比特幣的出價：
$$\text{去中介} \to \text{跨境匯款費 6%→<1%} \to \text{無銀行帳戶者可持幣} \to \text{信任外包給數學＋賽局}$$
代價是波動性與私鑰自負——銀行偷走你的錢 vs 自己弄丟私鑰，兩種恐懼二選一。

### 線索4：創世區塊——50 枚挖不出來的神話
2009-01-03 中本聰挖出 block 0（獎勵 50 BTC 永不可花，因寫死在程式），六天後 Hal Finney 收到第一筆轉帳（block 170，10 BTC）。鏈式公式：
$$\text{創世區塊＋報紙標題} \to \text{時間戳不可偽造} \to \text{公平啟動神話} \to \text{社群信仰鑄成}$$
沒有預挖、沒有公司，公平性本身就是估值引擎。

## 破案時刻
- 2008-10-31：中本聰發布比特幣白皮書（metzdowd 密碼學郵件組）。
- 2009-01-03：創世區塊誕生，內嵌紓困標題。
- 2009-01-09：Bitcoin v0.1 開源釋出；12 日 Finney 收首筆轉帳。
- 2010-05-22：披薩日（10,000 BTC 買兩披薩），首次定價。
- 2011–2013：Mt.Gox 竄起又崩、絲路暗網案，投機＋惡名雙至。
- 2015 起：區塊鏈（blockchain）一詞出圈，以太坊把帳本變電腦。

## 後果 -- 改變了什麼
- **制度**：DeFi、穩定幣、央行數位貨幣（CBDC）全被逼應戰，「貨幣非國家專利」重回檯面。
- **經濟**：總量 2100 萬枚＋四年減半，數位稀缺＋通縮敘事吸納黃金派資金，波動卻十倍於黃金。
- **技術**：區塊鏈＋智能合約＋零知識證明開枝散葉，PoS 等綠色共識試圖洗掉耗能原罪（劍橋估比特幣年耗電逾百 TWh）。
- **世界**：薩爾瓦多 2021 列為法幣、中美洲匯款走廊實測，制裁規避與洗錢疑慮並存。
- **教訓**：去中心化不是免費午餐——省下銀行費，付給礦機電費與波動稅；中本聰 2011 年消失，更留下「無主系統誰負責」的永恆考題。

## 因素影響筆記
1. 2008 海嘯＋印鈔救市 → 銀行信任崩盤，另類貨幣需求爆棚。
2. 密碼龐克三十年零件（Hashcash＋Merkle＋P2P） → 只差組裝，中本聰補上最後一塊。
3. PoW 解拜占庭難題 → 匿名共識可行，雙花死結打開。
4. 信任成本轉嫁（中介費→電費） → 抗審查誕生，代價是耗能與波動。
5. 創世區塊＋公平啟動神話 → 無主信仰成護城河，鏈上宗教就此開宗。
