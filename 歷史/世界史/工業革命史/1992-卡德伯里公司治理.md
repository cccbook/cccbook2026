# 1992-卡德伯里報告：董事會如何被關進籠子

## 案件摘要
1992 年，英國 **Cadbury Report** 在 BCCI、Maxwell、Polly Peck 連環醜聞後開出藥方：董事會要有獨立非執行董事、審計委員會、董事長與 CEO 分設、「遵守或解釋」（comply-or-explain）。此後「公司治理」（corporate governance）從學術詞變成全球上市規則。本案追查：幾頁軟法如何馴服大股東與經理人？

$$\text{醜聞＋掏空} \to \text{治理守則} \to \text{董事會制衡} \to \text{醜聞成本} \uparrow \to \text{權益成本} \downarrow$$

## 前因 -- 多因素的局勢
- **醜聞**：Maxwell 挪用養老金 4.4 億鎊後墜海、BCCI 洗錢倒閉、Polly Peck 憑空蒸發——董事會橡皮圖章是共犯。
- **經濟**：1986 金融大爆炸（見 `1986-倫敦金融大爆炸.md`）後機構投資人持股過半，有動機也有選票逼宮。
- **法律**：普通法董事信義義務抽象，執法靠事後訴訟；守則以「上市規則＋市場壓力」補成文法之不足。
- **思想**：Berle–Means 所有權經營分離、Jensen–Meckling 代理成本、Fama 有效市場——理論等了 60 年等到實務爆點。
- **國際**：美國已有審計委員會（1977 NYSE 強制），英國需追上以保住 City 競爭力。

## 線索與推理 -- 因素咬合

### 線索1：代理成本的數學 -- 治理折價
設 firm value $V = V^* - A$ ， $A$ 為代理成本（在職消費＋帝國擴張＋掏空）。投資人對治理差的公司打折：
$$P = \frac{E[CF] - E[A \mid \text{治理}]}{r}$$
獨立董事＋審計委員會＋分權（董事長/CEO 分設）即壓低 $E[A]$ 的三把鎖。實證：Gompers–Ishii–Metrick（2003）治理指數每差一檔，年報酬差 8.5%。

### 線索2：守則的三把鎖
| 鎖 | 條款 | 針對 |
|------|------|------|
| 獨立非執行董事 ≥3 人 | 挑戰經理人、定薪酬 | 內部人控制 |
| 審計委員會（全獨董） | 審財報、聘審計師 | 財報舞弊（Maxwell 式） |
| 董事長/CEO 分設＋遵守或解釋 | 不硬性立法，以揭露逼表態 | 一言堂＋規避 |

「遵守或解釋」是英國式智慧：硬法易被規避，軟法＋機構投資人投票（見 ISS、Glass Lewis 興起）反而咬人。

### 線索3：從倫敦到世界 -- 治理的傳染
| 年份 | 擴散 |
|------|------|
| 1995 Greenbury（薪酬）、1998 Hampel 合併為 Combined Code | 董事薪酬揭露 |
| 2002 美國 SOX（硬法版） | 審計獨立＋內控（見 `2002` 案） |
| OECD 1999/2004 治理原則 | 新興市場上市條件 |
| 台灣 2002、中國 2002、印度 Clause 49 | 獨董＋審計委員會移植 |

La Porta「法律與金融」學派：投資人保護越強，股權越分散、資本市場越大——治理是金融深化的因。

### 線索4： limits -- 治理擋不住什麼
2008 年北岩、海嘯中治理評分高的銀行照樣倒（風險模型集體失靈）；獨董「獨立而無知」是結構性困境。治理馴服的是**掏空與舞弊**，不是**集體誤判**——後者要靠總體審慎監理。

## 破案時刻
- **1991-05**：Cadbury 委員會成立（倫敦證交所＋FRC＋英格蘭銀行合召）。
- **1992-12-01**：報告出版，19 條守則＋遵守或解釋。
- **1993-06**：倫敦上市規則納入，揭露不遵守須解釋。
- **1998**：Hampel 合併為 Combined Code，FRC 逐版加嚴（至 UK Corporate Governance Code）。

## 後果 -- 改變了什麼
- **制度**：獨董＋審計＋薪酬委員會成全球上市標配；OECD 治理原則、ISS 投票政策皆源於此。
- **經濟**：英國機構投資人積極主義興起，敵意併購、股東提案有章可循；權益成本實證下降。
- **工業**：國企民營化（BT、British Gas）敢賣給散戶，因治理承諾散戶不被掏空——私有化浪潮的信任地基。
- **世界**：新興市場移植時水土不服（家族企業＋國家股），催生「關係治理 vs 契約治理」之爭。

## 因素影響筆記
1. 連環掏空 → 軟法守則 → 董事會制衡可操作化。
2. 遵守或解釋 → 市場執法 → 硬法規避難。
3. 代理成本可定價 → 治理折價 → 好治理融資便宜。
4. 英美模板輸出 → OECD＋新興市場移植 → 上市全球化。
5. 治理馴服舞弊、馴服不了誤判 → 總體審慎補位。
