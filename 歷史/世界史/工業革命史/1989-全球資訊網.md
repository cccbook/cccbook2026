# 1989-全球資訊網：伯納斯-李的免費贈與與資訊成本歸零案

## 案件摘要
1989 年 3 月，歐洲核子研究組織（CERN）工程師提姆・伯納斯-李（Tim Berners-Lee）提交一份備忘錄《資訊管理：一個提案》，設想用超文本連結散落各處的物理學家文件。1990 年底首個瀏覽器與伺服器上線，1991 年 8 月對外開放，1993 年 CERN 宣布 Web 技術永久免費。本案的奇點在於：與電話、電報皆由壟斷資本經營相反，資訊時代最關鍵的基礎設施是一份放棄專利的贈與——資訊成本自此趨近於零，平台帝國與網路泡沫都是它的後代。

## 前因 -- 多因素的局勢
- **技術**：ARPANET（1969）、TCP/IP（1983）、DNS（1985）已鋪好路；缺的是普通人可用的文件層。超文本理論（Bush 1945、Nelson 1965）等了四十年等到圖形顯示與個人電腦。
- **組織**：CERN 上萬名流動物理學家，文件格式混亂、人員來去，資訊遺失是日常之痛——需求來自科研協作，不是商業計畫。
- **制度**：CERN 作為跨國公共實驗室，無營利壓力，容許工程師把時間花在「無用」的資訊系統上；美國 1990 年代解禁網路商用，時機咬合。
- **競爭**：Gopher（明尼蘇達大學收費）、CompuServe、Minitel 各據一方，封閉系統林立，開放免費成為差異化武器。
- **資本**：工作站與 PC 降價，數據機普及，撥接上網的前夜。

## 線索與推理 -- 因素咬合
### 線索1：三位一體的極簡設計
伯納斯-李只定義三件事，多一事都不做：

| 元件 | 內容 | 作用 |
|---|---|---|
| URL | 統一資源定位符 | 全球每份文件一個地址 |
| HTTP | 超文本傳輸協定 | 無狀態、極簡、可擴展 |
| HTML | 超文本標記語言 | 結構＋連結，容錯渲染 |

$$C_{發布} \to 0, \quad C_{檢索} \to 0 \implies 梅特卡夫定律 \ V \propto n^2$$

節點每增一個，全網價值平方增長——開放免費讓 $n$ 爆炸，這是 Gopher 收費模式被瞬間淘汰的數學原因。

### 線索2：免費的經濟學
CERN 1993 年放棄專利，等於把消費者剩餘放到無窮大：

$$\text{專利收費} \to \text{採用摩擦} \to n \ {\rm 小} \to V \ {\rm 小}$$

$$\text{免費開放} \to n \ {\rm 爆炸} \to \text{互補市場（伺服器、瀏覽器、電商）} \to \text{整體剩餘最大}$$

NCSA Mosaic（1993）、網景（1994）站在免費地基上爆發；若 Web 如貝爾電話般壟斷經營，網路股時代晚十年、規模小一個數量級。開放是最高明的產業政策。

### 線索3：從文件網到平台網
三階段演化，每階段成本崩跌養出新物種：

```pseudocode
1991-1998 靜態文件網: 報紙上網, 入口網站 (Yahoo)
1998-2007 動態交易網: LAMP + 寬頻, 電商搜索 (Google, Amazon, eBay)
2007-     社交行動網: iPhone + 社群圖譜, 平台 + 演算法 (Facebook, App)
每階段: 頻寬成本↓ -> 互動形式升級 -> 協調半徑放大 -> 組織重寫
```

資訊成本歸零的另一面是注意力稀缺——搜尋引擎、社群推薦、廣告拍賣，都是為過剩資訊配對稀缺注意力的機制。

## 破案時刻
- 1989-03：伯納斯-李提案；主管批註「含糊但令人興奮」。
- 1990-12：首台 Web 伺服器（NeXT 電腦）與瀏覽器在 CERN 上線。
- 1991-08-06：Usenet 公告對外開放；首批海外鏡像出現。
- 1993-04-30：CERN 宣布 Web 免費；同年 Mosaic 圖形瀏覽器點燃大眾。
- 1994–1995：網景成立、Yahoo 上線，瀏覽器大戰與網路股時代開幕。

## 後果 -- 改變了什麼
- **經濟**：交易成本（搜尋、議價、履約）系統性崩跌，長尾市場、全球供應鏈協同、零邊際成本商品（軟體、串流）誕生。
- **組織**：科斯的企業邊界重畫——外包、平台、零工、開源協作，市場規模再放大一輪，斯密定理的網路版。
- **社會**：1995 年瀏覽器大戰、2000 年網路泡沫、2004 年社群媒體、2007 年行動革命，全部是本案的續集。
- **世界**：免費開放戰勝封閉收費，成為數位時代的範式判決；但免費的代價是監控資本主義——廣告與數據成為新的稅。
- **教訓**：通用技術的贏法不是收過路費，而是把路修到所有人家門口，再從路邊的城鎮收稅。

## 因素影響筆記
1. CERN 協作痛點 → 超文本需求 → URL/HTTP/HTML 三位一體。
2. TCP/IP＋PC＋數據機 → 承載層就緒 → 文件層只欠臨門一腳。
3. 免費開放 vs Gopher 收費 → 網路效應碾壓 → 標準一統天下。
4. 資訊成本歸零 → 注意力稀缺浮現 → 搜索＋社群＋廣告新三位一體。
5. 平台續集（泡沫、社群、行動、AI）→ 迴路仍在轉，源頭是 1989 年那份備忘錄。
