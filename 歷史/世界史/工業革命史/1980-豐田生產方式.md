# 1980-豐田生產方式：JIT、看板與精實革命的多因案件

## 案件摘要
1980 年前後，底特律終於發現油耗醜、毛病多的日本小車搶走了美國市場，兇手不是廉價勞工，而是豐田的大野耐一（Taiichi Ohno）用二十年磨出的生產方式：以看板拉動的 JIT、內建品質的自働化（jidoka），把福特「以量取勝」的邏輯整個翻面——不靠規模，靠消滅浪費取勝。

## 前因 -- 多因素的局勢
- **經濟**：日本國內市場狹小、資金短缺，豐田買不起福特式巨型沖壓線與大庫存，只能「小批量、多品種、低庫存」求生。
- **政治**：戰後財閥解體、勞工運動激進，1950 年豐田大罷工後承諾終身僱用，裁員式增產此路不通，只能向效率要人。
- **技術**：美國超市（1956 年大野訪美所見貨架補貨）＋福特生產手冊＋統計品管（戴明、朱蘭 1950 年代赴日授課）三者拼出靈感。
- **組織**：豐田喜一郎「Just-in-Time」祖訓、豐田佐吉「自働化」（機器異常即停）家學，加上協力廠（keiretsu）緊密網絡，拉動式生產有人接得住。
- **能源**：1973、1979 兩次石油危機重創美國大車，省油、耐用的日本車需求暴漲，TPS 的品質＋成本優勢被世界看見。
- **資訊**：MIT 國際汽車計畫（IMVP）1980 年代實地測量，發現豐田裝配工時與缺陷率皆約為美國廠一半，數據鐵證如山。

## 線索與推理 -- 因素咬合

### 線索1：看板——用紙牌取代電腦的拉動革命
後工序憑「看板」（kanban）向前工序領料，有牌才生產、無牌即停線，庫存被壓到以小時計。因果鏈：
$$\text{後工序拉動} \to \text{在製品↓} \to \text{不良品無處藏身} \to \text{品質↑} \to \text{返工與庫存成本↓}$$
```pseudocode
# 推動式（福特）：不管需不需要，照計畫往前推
push(parts, forecast)  # 庫存堆積掩蓋問題
# 拉動式（豐田）：後工序要了才做
while True:
  if kanban_received(part): produce(part, qty=1)
  else: stop_and_improve()  # 停線即改善機會
```
推理：庫存是「問題的麻醉劑」，JIT 拔掉麻醉，逼全員止痛治病。

### 線索2：自働化與防呆——品質是做出來的，不是檢出來的
豐田織機時代的「斷線停車」基因被大野注入汽車線：異常即停（andon 拉繩）、防呆（poka-yoke）、全員品管圈。七大浪費（muda：過量生產、等待、搬運、加工過度、庫存、動作、不良）即通緝名單：
| 福特大量生產 | 豐田精實生產 |
|--------------|--------------|
| 經濟批量大、換模慢 | 快速換模（SMED，單分鐘換模）、小批量 |
| 尾端檢驗、返修區大 | 源頭品管、停線修、一次做對 |
| 庫存是資產 | 庫存是浪費 |
| 工人是手的延伸 | 工人是改善的主體 |

### 線索3：協力體——JIT 的廠外一半
豐田把供應商綁成命運共同體：長期訂單＋駐廠指導＋均勻化排程（heijunka），貨車一天多趟小批量送貨。鏈式公式：
$$\text{平準化排程} \to \text{供應商可預測} \to \text{小批量高頻配送可行} \to \text{全鏈庫存↓}$$
沒有這種信任密度的供應網，看板只是廢紙——這正是美國廠 1980 年代抄 JIT 屢敗的主因。

### 線索4：石油危機＋MIT 背書——世界終於看見
1973 年後 Corolla、Civic 在美銷量翻倍；1980 年日本汽車產量（1100 萬輛）首超美國；1990 年《改變世界的機器》（The Machine That Changed the World）把 TPS 正名為「精實生產」（lean），全球車廠競相導入。外部衝擊＋學術認證合力，把廠內 know-how 變成世界標準。

## 破案時刻
- 1937：豐田汽車獨立；豐田喜一郎提出 JIT 構想。
- 1945–1955：大野耐一在機械、引擎、總裝工場試驗同步化與看板。
- 1950：豐田大罷工→終身僱用制；大野訪美考察福特與超市。
- 1960–1970 年代：看板體系覆蓋全社與一級協力廠；快速換模（新鄉重夫協助）成熟。
- 1973–1979：石油危機，日本省油車橫掃歐美市場。
- 1980：日本汽車產量超越美國；福特、GM 派團赴日取經。
- 1990：MIT《改變世界的機器》出版，「lean production」定名全球。

## 後果 -- 改變了什麼
- **技術**：JIT、看板、TQM、持續改善（kaizen）成為製造業世界語，從汽車擴散到電子、醫療、軟體（看板方法、敏捷）。
- **經濟**：庫存周轉率與一次良率成為競爭新維度，成本戰從規模轉向速度與品質。
- **社會**：終身僱用＋品管圈重塑勞資關係想像，但高壓改善與供應鏈轉嫁成本也引發過勞爭議。
- **世界**：日本模式輸出全球（NUMMI 合資、 transplant 工廠），後發國家學會「不靠大市場也能贏」；2000 年後又與數位化合流為工業 4.0。
- **教訓**：TPS 證明組織技術與機器同等重要——買得到機器人，買不到「停線文化」；精實是整套社會契約，不是幾張看板。

## 因素影響筆記
1. 狹小市場＋資金短缺 → 大規模路線走不通，小批量求生倒逼創新。
2. 終身僱用承諾 → 不能靠裁員增產，只能靠消滅浪費與培育多能工。
3. 超市補貨＋戴明品管＋福特手冊拼合 → 拉動＋品質兩翼在大野手中合流。
4. 協力廠命運共同體 → 廠外 JIT 成立，全鏈庫存同步下降。
5. 石油危機＋MIT 實證 → 外部需求與學術背書把廠內方法推成世界標準。
