# 1868-朱拉隆功改革：暹羅的避險現代化

## 案件摘要

1868–1910 年，**朱拉隆功**（Chulalongkorn，拉瑪五世）推行暹羅現代化：廢奴隸—徭役（sakdina 制解體）、中央集權（Monthons 圈制取代半自治土侯）、新式陸軍—海軍、鐵路—電報、朱拉隆功大學前身、1892 內閣制——**東南亞唯一未被殖民的國家**，代價是割地（1893 寮國、1904–07 柬北—馬來四邦、1909 吉打—吉蘭丹等歸英）。這樁案件是「以空間換時間」：**割邊緣、保核心、買現代化時間**。

## 前因 -- 多因素的局勢

- **外部**：英法夾擊（緬甸已滅 [1824-英緬戰爭.md](1824-英緬戰爭.md)、法國據交趾 [1862-法國殖民交趾支那.md](1862-法國殖民交趾支那.md)、1893 Paknam 炮艦）——「不改革即瓜分」的壓力。
- **內部**：四世王蒙固（Mongkut，1851–68，出家 27 年、通英文—拉丁—科學！）的開明預熱＋昭披耶・是・素里亞翁（Si Suriyawong）攝政。
- **財政**：關稅（不平等條約 Bowring 1855：3% 關稅上限！）＋鴉片稅＋包稅制——改革的錢包。
- **人力**：王族留歐（子弟留英—法—俄—德）＋歐洲顧問（比利時 Rolin-Jaequemyns 起草法典！）——移植的人力。

## 線索與推理 -- 因素咬合

### 線索一：割地買時間——「邊緣 vs 核心」的計算

| 年份 | 割讓 | 換得 |
|---|---|---|
| 1893 | 湄公河東（寮國）歸法 | 法國退兵＋承認暹羅獨立 |
| 1904–07 | หลวงพระบาง？不——馬德望—暹粒歸法柬 | 治外法權廢除＋關稅自主部分恢復 |
| 1909 | 吉打—吉蘭丹—登嘉樓—玻璃市歸英 | 英廢治外法權＋鐵路借款 |

$$\text{獨立} = \text{（核心：昭拍耶—曼谷）} - \sum\text{（邊緣：寮、柬、馬來邦）}$$

**每一次割地都買回主權 прогрессивно（治外法權、關稅）**——這是「朝貢避險」（素可泰—阿瑜陀耶傳統）的現代版：**以前納貢品，現在納土地**。曼谷王朝三世—五世的外交一脈相承：竹子隨風（[1238-素可泰與泰族南下.md](1238-素可泰與泰族南下.md)的國技）。

### 線索二：Monthons 圈制——「中央集權的移植」

1892–99：全國劃 Monthons（圈）、Changwat（府）——派曼谷王族任圈尹（thesaphiban）——**半自治土侯（chao muang）→ 中央官僚**：

$$\text{集權} = \text{（圈尹：王族—官僚）} \times \text{（電報—鐵路：控制技術）} \times \text{（新式軍：鎮壓）}$$

1902 帕塔尼（北大年）「七頭城」收權、南部馬來穆斯林不滿——**集權的副作用：北大年問題（至今！）**。廢奴（1905 廢奴隸買賣）＋徭役貨幣化——**人身支配→財政稅收的現代轉型**（與日本版籍奉還—廢藩同構，只是慢二十年）。

### 線索三：為何暹羅能、緬甸越南不能？——「緩衝國的賽局」

$$\text{暹羅獨立} = \text{（英法均勢：英要緩衝、法要制衡）} \times \text{（主動改革：無藉口）} \times \text{（運氣：1896英法宣言保證湄南河流域）}$$

- 緬甸：只鄰英國（無均勢可玩）＋錫袍僵化 → 滅。
- 越南：只鄰法國（中國自顧不暇）＋嗣德僵化 → 亡。
- 暹羅：英法對峙＋主動改革（無「保護傳教士」藉口）＋1896 緩衝保證 → 存。

**獨立是賽局，不是美德**——暹羅的三項乘數全中。這也是泰國民族主義史學的盲點（「英明君主」敘事掩蓋結構運氣）。

## 破案時刻

- 1851–68：蒙固四世預熱（通科學—英文、Bowring 條約 1855）。
- 1868–73：朱拉隆功親政（攝政期後）；1873 第一次訪新—爪—印（考察殖民行政！）。
- 1890–97：第一次訪歐（學制度）；1892：內閣—圈制改革。
- 1893.7：Paknam 事件——法艦封鎖曼谷、割寮國（改革的最大推力）。
- 1897–1907：第二次訪歐、法典編纂、鐵路（曼谷—呵叻 1900 通車）。
- 1905：廢奴；1909：英暹條約（割馬來四邦、廢治外法權）。
- 1910：朱拉隆功駕崩——改革大體完成（→1932 立憲革命的舞台）。

## 後果 -- 改變了什麼

- **主權**：唯一未被殖民＋治外法權廢除（1907–09 英法美）——「獨立」的代價是半壁邊緣。
- **國家**：中央集權官僚制＋新式軍（→1932 軍人政變的工具！）＋國民教育（→民族主義）。
- **副作用**：北大年馬來穆斯林問題（1902 收權的遺產、至今分離主義）；華人國籍—同化政策（拉瑪六世「東方猶太人」論的遠源）。
- **敘事**：「偉大 beloved 國王」崇拜——五世王像（周二？不——十月二十三朱拉隆功紀念日）至今泰國王權崇拜的核心。

## 因素影響筆記

```
英法夾擊（外壓）×蒙固預熱（內備）──→ 1868改革
割邊緣（寮柬馬來）──→ 買主權（治外法權廢＋關稅回）──→ 獨立保全
圈制集權＋廢奴＋新軍 ──→ 現代國家 ──┬──→ 1932立憲（新軍政變工具）
                                      └──→ 北大年問題（集權副作用）
```

**偵探結語**：朱拉隆功案件是避險的藝術：**以前的暹羅王納貢品，朱拉隆功納土地**——每塊邊緣都明碼標價，買回主權的進度條。而獨立的三項乘數（英法均勢×主動改革×運氣）缺一不可——緬甸越南各缺一項，各亡一國。曼谷的王座保住了，帳單是半壁江山與一個至今未解的北大年。
