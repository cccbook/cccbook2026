# 1238-素可泰與泰族南下：蘭甘亨的字母革命

## 案件摘要

1238 年，坤邦克朗陶（Pho Khun Bang Klang Thao，即室利膺陀羅提）驅逐吳哥總督、建**素可泰**（Sukhothai，「幸福曙光」）——泰族第一個獨立王國。其子**蘭甘亨**（Ramkhamhaeng，約 1279–1298 在位）立碑（1292 蘭甘亨碑）：創泰文、行上座部佛教、結盟元朝（1282、1294 遣使）、「鑄鐘鳴冤」（子民敲鐘直訴大王）。這樁案件是「邊緣的建國學」：**吳哥衰落的權力真空＋泰族南下的移民潮＋漢字的反面教材＝泰文**。

## 前因 -- 多因素的局勢

- **人口**：泰族（Tai）自廣西—雲南南下（南詔—大理壓力＋蒙古入侵雲南 1253 的推力）——移民潮。
- **政治**：吳哥晚期控制力衰退（[0802-吳哥帝國.md](0802-吳哥帝國.md)）——邊緣總督自立的窗口。
- **宗教**：斯里蘭卡系上座部經緬甸—孟族傳入——素可泰的國教（與吳哥神王觀的對比）。
- **外部**：元朝的羈縻（要求朝貢）——蘭甘亨兩次遣使（1282、1294），換取「不被打＋貿易」。

## 線索與推理 -- 因素咬合

### 線索一：泰文的發明——「拼音化的政治」

蘭甘亨碑（1292）：以高棉文＋巴利文為原料，創**泰文（44 輔音的音節文字）**：

$$\text{泰文} = \text{（高棉字母形）} \oplus \text{（漢語系聲調標記）} \oplus \text{（巴利拼寫）}$$

對比：越南用漢字（後來自創喃字）、爪哇用帕拉瓦系——**泰文是「為泰語量身訂做」的拼音化**。政治效果：文書行政的本地化（脫離高棉文書壟斷）＋佛教經典的泰語化——**文字即主權**。蘭甘亨碑本身（「誰有冤敲鐘」）就是識字政治的宣言。

### 線索二：父政（paternal kingship）——與神王的對比

碑文：大王如父、子民如子——**pho khun（父君）制** vs 吳哥 devaraja（神王）：

| | 吳哥神王 | 素可泰父君 |
|---|---|---|
| 王—民關係 | 神—人（距離） | 父—子（親近） |
| 合法性 | 宇宙模型 | 道德＋功德 |
| 宗教 | 婆羅門—大乘 | 上座部（功德佛教） |

$$\text{小國合法性} = \text{（道德親近）} > \text{（宇宙規模）}$$

**小國玩不起吳哥的規模遊戲，改玩道德遊戲**——上座部功德＋父君親民，是邊緣小國的最優解。阿瑜陀耶（[1350-阿瑜陀耶王國.md](1350-阿瑜陀耶王國.md)）後來融合兩者（神王儀式＋上座部）。

### 線索三：朝貢元朝——「小國的避險」

兩次遣使大都（1282 忽必烈、1294 成宗）——**用朝貢買安全＋買陶瓷貿易**（宋元青瓷經素可泰—暹羅灣轉口）：

$$\text{小國生存} = \text{（朝貢成本）} < \text{（被征服損失）} \quad \text{且朝貢附帶貿易利潤}$$

**朝貢是理性的保險單**——素可泰、阿瑜陀耶、馬六甲（[1405-馬六甲海峽帝國.md](1405-馬六甲海峽帝國.md)）都買同一家保險（明朝）。蘭甘亨與元朝的「朋友關係」，是泰國外交「竹子隨風」（bending with the wind）的最早版本。

## 破案時刻

- 1238：驅逐吳哥總督、建素可泰——泰族建國。
- 約 1279–1298：蘭甘亨在位——碑文、泰文、上座部、遣元。
- 1292：蘭甘亨碑——泰文的最早自證。
- 1350：阿瑜陀耶興起（[1350-阿瑜陀耶王國.md](1350-阿瑜陀耶王國.md)）；1378 素可泰淪為附庸——小國被大國吸收。
- 1438：素可泰併入阿瑜陀耶——但「父君＋泰文＋上座部」遺產被繼承。

## 後果 -- 改變了什麼

- **文字**：泰文——至今泰國、寮國（寮文變體）的書寫系統；識字政治的起點。
- **政治**：父君傳統——泰國王權「親民道德」的深層原型（九世王蒲美蓬的「發展之王」形象正是父君制的現代版）。
- **宗教**：上座部國教化——泰國至今（僧王、守夏節、功德政治）。
- **外交**：朝貢避險＋竹子外交——泰國「從不被殖民」的長期策略源頭（[1868-朱拉隆功改革.md](1868-朱拉隆功改革.md)）。

## 因素影響筆記

```
泰族南下（人口）×吳哥衰退（窗口）──→ 1238素可泰
                                              ↓
泰文發明（主權）＋父君制（道德合法性）＋遣元（避險）──→ 小國最優解
                                              ↓
                              1378附庸化 ──→ 遺產被阿瑜陀耶繼承
```

**偵探結語**：素可泰案件是邊緣的智慧：**玩不起規模，就玩道德；打不贏帝國，就買保險**。蘭甘亨用一塊石碑（文字）、一個稱號（父君）、兩次朝貢（避險），為泰族買下八百年的入場券——而「竹子隨風」的外交，從此成為泰國的國技。
