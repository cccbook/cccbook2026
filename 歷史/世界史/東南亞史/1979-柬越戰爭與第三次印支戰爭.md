# 1979-柬越戰爭與第三次印支戰爭：同志的坦克

## 案件摘要

1978.12.25，越軍15萬＋韓桑林柬救國陣線閃擊金邊，1979.1.7滅赤棉（見 [1975-赤色高棉.md](1975-赤色高棉.md)），扶韓桑林政權——**共產黨打共產黨，越南打柬埔寨、中國打越南（1979.2對越自衛反擊）**。前案越南統一（見 [1975-越南統一.md](1975-越南統一.md)）講南北和，後案革新開放（1986）講向錢看，中間獨缺：**同志為何相殘？一場戰爭如何拖出十年制裁＋1986革新？**本案補冷戰最黑的一頁。

## 前因 -- 多因素的局勢

- **柬**：波爾布特零年（城市清空、越裔屠殺、1977–78Ba Chúc越境屠3000）＋清洗親越派（符寧、韓桑林出逃）——意識形態（毛—反越民族主義）雙引擎。
- **越**：統一後糧荒＋船民潮＋蘇越同盟（1978.11）——需東邊安全＋蘇經援（反華代價）。
- **中蘇**：中美建交（1979.1）—鄧訪美戴牛仔帽、蘇古巴—金蘭灣——柬是蘇南下支點、中是美制蘇新友——小國卒子化。
- **東協**：泰（邊境赤棉庇護）＋新馬（反越）——民柬保住聯合國席位至1991，越陷外交孤島。

## 線索與推理 -- 因素咬合

### 線索一：Ba Chúc到金邊——「屠殺請來的坦克」

| 時點 | 赤棉動作 | 越南反應 |
|---|---|---|
| 1977–78 | 越境屠Ba Chúc等村 | 外交抗議＋邊境戰 |
| 1978.6 | 大清洗親越東部軍區 | 韓桑林出逃越南 |
| 1978.12 | 拒談判 | 15萬閃擊 |
| 1979.1.7 | 波爾布特退豆蔻山 | 金邊易幟 |

$$\text{開戰} = \text{（越境屠殺：人道藉口）} \times \text{（清洗親越派：代理人現成）} \times \text{（蘇約：後盾）}$$

偵探結論：**波爾布特替河內寫好了出兵令**——沒有Ba Chúc，越軍仍是侵略；有了Ba Chúc，越軍是「自衛反擊＋人道干預」二合一。1979.1金邊萬人空巷（赤棉已清空城市）迎越軍——**被屠殺者解放屠殺之都**，冷戰最諷刺的入城式。

### 線索二：1979.2中國打越南——「懲罰的懲罰」

鄧小平「教訓越南」（20萬邊境戰、諒山—高平、28天回撤）：

$$\text{中方收益} = \text{（援柬姿態：保波爾布特殘部）} + \text{（對美投名狀：制蘇）} - \text{（軍事慘勝：傷亡比不利、暴露解放軍鏽蝕）}$$

學術理論（Chen Jian「可控戰爭」）：北京要的不是勝，是**流血信號**——告訴蘇（不敢南下救越）、美（敢反蘇）、越（兩線透支）。越軍精銳陷柬（十年佔領、年耗10億美元＋蘇援）、北線民兵抗中——**越南贏了兩場戰爭，輸了十年發展**（1980s糧票、1985通脹700%）。

### 線索三：十年佔領—1991巴黎協定——「流血換革新」

越佔柬十年（1979–89，韓桑林—洪森政權＋越顧問），美中泰經泰邊境養赤棉（民柬聯合政府1982：赤棉＋西哈努克＋宋雙）：

$$\text{撤軍} = \text{（蘇援斷：戈巴契夫1986符拉迪沃斯托克講話）} + \text{（越財政崩：革新前夜）} + \text{（中越鬆動）}$$

1986阮文靈革新開放（本卷1986案）**正是被柬戰爭逼出來的**：再不向錢看，連佔領費都付不起。1989越撤、1991巴黎協定、1993UNTAC大選——洪森（韓桑林外長出身）笑到最後。**赤棉1998波爾布特死、1999投降**——中美泰養了二十年的鬼，終於自己散了。

## 破案時刻

- 1978.4：Ba Chúc屠殺——開戰藉口。
- 1978.12.25：越閃擊——第三次印支戰爭開幕。
- 1979.1.7：金邊陷——赤棉退山。
- 1979.2.17–3.16：中越邊境戰——懲罰。
- 1979–89：十年佔領＋聯大席位戰（民柬保席）。
- 1986：越南革新——戰爭逼出的改革。
- 1991.10：巴黎協定——終局。

## 後果 -- 改變了什麼

- **柬**：止殺（200萬死終止）＋越式黨國（洪森1985–2023）——救命者變長期房東，感恩與怨恨雙軌至今。
- **越**：十年失血→革新（見1986革新案）——「打贏戰爭、打輸經濟」的教科書，2010電子代工（見 [2010-越南電子代工崛起.md](2010-越南電子代工崛起.md)）的起點是1989撤軍。
- **中**：暴露軍鏽→百萬裁軍＋對美蜜月（1980s）——1979是解放軍現代化的恥辱動員令。
- **東協**：反越擴員（文萊84—越95—寮緬97—柬99）——敵人變會員，弱連結的勝利（見 [1967-東協成立.md](1967-東協成立.md)）。

## 因素影響筆記

```
Ba Chúc＋清洗 ──→ 1979.1金邊易幟 ──┬──→ 十年佔領（蘇援輸血）
中蘇爭＋中美和 ──→ 1979.2懲越 ──┘        ↓
                              財政崩 ──→ 1986革新 ──→ 1991巴黎協定
```

**偵探結語**：1979年三個共產黨打成一團——**柬用屠刀請坦克，越用坦克請制裁，中用制裁請蜜月**。唯一的贏家是豆蔻山上的波爾布特（多活二十年）和金蘭灣的蘇聯艦隊（多停十年）。和平在1991年到達時，穿的是越南革新（向錢看）的拖鞋。
