# 1619-巴達維亞：VOC 公司國家的誕生

## 案件摘要

1619 年，簡·科恩（Jan Pieterszoon Coen）夷平查雅加達、建巴達維亞城——**荷蘭東印度公司（VOC，1602，[1602-VOC與巴達維亞.md](1602-VOC與巴達維亞.md)）從商館升級為領土國家**：築城、鑄幣、簽條約、發動戰爭、壟斷香料（班達肉豆蔻、安汶丁香）。這是人類第一家股份公司第一次證明：**資產負債表可以長出軍隊，股東大會可以宣戰**。重商主義（mercantilism）的東南亞實驗場，由此開張。

## 前因 -- 多因素的局勢

- **經濟**：1602 年六家商館合併為 VOC——永久資本（4.5 萬股東）＋十年壟斷特許狀；阿姆斯特丹股價需要香料壟斷利潤支撐。
- **武器**：葡萄牙 cartaz 體系（[1511-葡萄牙攻陷馬六甲.md](1511-葡萄牙攻陷馬六甲.md)）已證明「稅卡靠艦砲」；科恩帶來「要塞＋艦隊＋條約」三件套。
- **地理**：巽他海峽—爪哇北岸是香料（摩鹿加）—胡椒（萬丹）—糧食（爪哇）三流交會點；巴達維亞卡住咽喉。
- **組織**：十七人董事會（Heeren XVII）授總督「先斬後奏」全權——公司即主權（quasi-sovereignty）的法理創新。

## 線索與推理 -- 因素咬合

### 線索一：公司即國家——VOC 的主權工具箱

| 國家職能 | VOC 版本 |
|---|---|
| 宣戰媾和 | 與萬丹、馬打蘭簽條約；1621 班達征服 |
| 鑄幣徵稅 | 巴達維亞鑄幣、通行稅、人頭稅 |
| 司法行政 | 市政廳＋法院＋奴隸法典 |
| 軍隊警察 | 僱傭軍（歐日非裔混編）＋城牆艦隊 |
| 貿易壟斷 | 香料定點交售、Extirpatie（剷除他島香料樹） |

$$\text{壟斷利潤} = \text{（歐洲售價 } \approx 10\times\text{收購價）} \times \text{（交售落實率）} - \text{（要塞＋艦隊成本）}$$

推理：公式前半靠暴力（剷除＋屠殺）維持，後半（軍事成本）只升不降——18 世紀 VOC 帳面富貴、現金枯竭，1799 破產即此式崩解。**用軍隊維持的壟斷，軍隊即成本黑洞**。

### 線索二：班達 1621——壟斷的原罪

1621 年科恩率軍攻班達群島，屠殺、驅逐、奴役約 1.5 萬原住民，代之以奴隸種植園（perken）。肉豆蔻歐洲價格維持百倍剪刀差一個世紀。

$$\text{重商體制} = \text{（產地滅絕式壟斷）} + \text{（消費地飢餓營銷）} + \text{（中間商死刑）}$$

格勞秀斯《海洋自由論》（1609，為 VOC 背書卻反被其踐踏）的諷刺：公司用自由貿易理論拿特許，用壟斷暴力關市場。**自由的旗，壟斷的刀**——此後三百年殖民公司的標準劇本（英東印度、英緬 [1824-英緬戰爭.md](1824-英緬戰爭.md)同理）。

### 線索三：學術理論——主權公司（company-state）

斯特恩（Philip Stern）「公司國家」論：VOC 不是「有軍隊的公司」，而是「有股東的國家」——早期現代主權可分割、可特許。巴達維亞證明：威斯特伐利亞之前，主權即商品（特許狀可買）。

$$\text{公司國家壽命} = \frac{\text{（壟斷租金）}}{\text{（代理成本＋戰爭成本）}}$$

總督（巴達維亞）—董事會（阿姆斯特丹）相隔萬里、信息半年一往返，代理人貪腐（私貿）蛀空租金；英法戰爭成本疊加——分母在 1780 年代超過分子，**第一家股份公司死於第一個委託—代理難題**。

## 破案時刻

- 1602：VOC 成立——永久資本＋特許狀。
- 1619.5：科恩陷查雅加達——巴達維亞建城（Fatahillah 忌日即雅加達市慶）。
- 1621：班達征服——壟斷完成。
- 1641：奪馬六甲（聯柔佛）——葡稅卡易主。
- 1684：萬丹屈服——爪哇西半鎖定。
- 1799：VOC 破產解散——公司國家移交巴達維亞共和國（荷蘭國家殖民開幕）。

## 後果 -- 改變了什麼

- **政治**：公司國家範式確立——英、法東印度公司照抄；印尼「殖民國家」的行政（攝政—縣制）即 VOC 遗产。
- **經濟**：強迫交售制（Priangan 咖啡）→ 強迫種植制（[1830-強迫種植制.md](1830-強迫種植制.md)）的直系祖先；爪哇貨幣—稅收經濟啟動。
- **人口**：奴隸＋華人甲必丹（kapitan）＋歐亞混血——巴達維亞多元社會的起點，也是排華 LIKE 1740 紅溪慘案的溫床。
- **理論**：股份制＋主權特許的結合——現代跨國公司（稅卡—避稅港）的遙遠祖先。

## 因素影響筆記

```
特許狀（法律）＋股本（金融）──→ VOC ──→ 1619 巴達維亞（要塞國家）
                                        ↓
班達暴力（壟斷租金）──→ 百倍利潤 ──→ 代理＋戰爭成本 ──→ 1799 破產
```

**偵探結語**：巴達維亞案是資本主義的出生側寫：第一家上市公司，第一件事是屠城。股價與刀，同時上市。此後四百年，每當有人說「公司只管賺錢」，偵探都該回頭看看 1619——**公司一旦有了軍隊，賺錢只是順便，收稅才是本業**。
