# 1767-阿瑜陀耶陷落與曼谷王朝：四百年古都的葬禮

## 案件摘要

1767.4.7，緬甸貢榜王朝謝苗—芒結大軍破阿瑜陀耶，屠城焚宮，417年王朝（見 [1350-阿瑜陀耶王國.md](1350-阿瑜陀耶王國.md)）滅亡——**東南亞史上最慘烈的首都陷落**。前案只講長壽，後案直跳朱拉隆功（見 [1868-朱拉隆功改革.md](1868-朱拉隆功改革.md)），中間獨缺：**長壽者為何驟死？吞武里—曼谷如何在一年內復國？**本案收尾大陸王國線。

## 前因 -- 多因素的局勢

- **緬甸**：雍籍牙統一（1752–60）—貢榜擴張機（孟族滅、曼尼普爾掠、暹羅為糧倉）→ 1765兩路（北路經南邦、南路經丹那沙林）夾擊。
- **暹羅**：烏通末代王埃甲他空信占星輕備戰， corvée（徭役）制崩（華人包稅+逃役），火器靠荷蘭舊銃 vs 緬法式炮手（俘虜改造）。
- **外部**：英法七年戰爭餘波（無暇干預）、華人移民潮（鄭信之父為澄海稅吏）——救國者恰是混血。
- **地理**：雨季圍城（緬軍反常不退，學會暹式水戰＋圍田種稻）——天時紅利被沒收。

## 線索與推理 -- 因素咬合

### 線索一：為何守了一年四個月卻亡？——「圍城種稻」的降維打擊

| 項目 | 暹軍 | 緬軍 |
|---|---|---|
| 戰略 | 待雨季（緬例退） | 反例不退、圍城種稻 |
| 兵力 | 約6萬（逃亡中） | 約4–5萬（分贓激勵） |
| 火器 | 舊銃＋僱傭葡炮手殘部 | 法俘炮手＋繳獲暹炮 |
| 城防 | 三重城牆＋護城河 | 築對壘＋水柵封江 |

$$\text{陷落} = \text{（緬學會水戰）} \times \text{（雨季紅利} \to 0\text{）} \times \text{（逃役掏空）}$$

1766雨季緬不退反種稻——**把圍城變成屯田**，阿瑜陀耶的護城河從屏障變魚塘（緬的）。1767.4城破、萬佛寺鎔金、典籍焚——**417年檔案一夕成灰**，泰史料斷層之痛至今。

### 線索二：鄭信一年復國——「華人網絡＋港口現金」

廣東混血鄭信（達信）1767.1突圍羅勇—尖竹汶，聚華人私兵—潮州帆船—鹽魚稅，11月水師入湄南、殺緬留守、建吞武里：

$$\text{復國速度} = \frac{\text{（華商資本：船＋米＋槍）} \times \text{（緬主力北歸戰清：1767清緬戰爭）}}{\text{（舊貴族真空：死光）}}$$

分母歸零反而是紅利——無門閥掣肘，新人（華裔、北碧豪族）直上。學術理論（Skinner「華人與泰國」）：**吞武里是華人資本建國**，鄭信—拉瑪一世皆半華血統，曼谷王朝即「潮州—暹羅合資公司」。1770平各地割據、1769–79暹緬拉鋸（芒結死、清緬和）——**緬被清拖住，暹得喘息**，地緣的慈悲。

### 線索三：1782曼谷遷都——「新瓶裝舊酒＋新酒」

鄭信後期自稱須陀洹（未來佛）失心、通鑾（拉瑪一世）1782政變建曼谷（卻克里）：三藏結集、玉佛寺、薩克迪納（田制）重編＋華人包稅擴大：

$$\text{曼谷} = \text{（阿瑜陀耶法統：三印法典重頒）} + \text{（吞武里資本：華人稅吏）} + \text{（拉達那哥欣島：易守）}$$

卻克里法典（1805）自稱恢復舊制，實為**中央集權2.0**（蒙空—朱拉改革之母，見朱拉案）。緬1785–86再伐（九軍之戰）被新制府兵＋華勇擊退——**葬禮一年後，復仇已備**。

## 破案時刻

- 1765：緬兩路入侵——包圍網。
- 1766：雨季不退、圍城種稻——轉折。
- 1767.1：鄭信突圍東南——復國種子。
- 1767.4.7：阿瑜陀耶陷、屠焚——417年終結。
- 1767.11：吞武里光復——一年復國。
- 1782：拉瑪一世建曼谷——卻克里開幕（→1868朱拉）。

## 後果 -- 改變了什麼

- **泰國**：阿瑜陀耶彈性外交（見1350案）終結，代之以曼谷集權＋華人財政——近代泰國的底稿。
- **緬甸**：勝暹敗清（1765–69清緬戰爭慘勝）——兩線透支，貢榜盛極轉衰（→1824英緬戰爭見 [1824-英緬戰爭.md](1824-英緬戰爭.md)）。
- **華人**：潮州幫自此為泰國稅務—米業—王室三棲——今日正大—盤谷銀行的遠祖上岸。
- **史學**：典籍焚毀→拉瑪史官重構（《阿瑜陀耶編年史》多版互歧）——泰國史的「焚書坑儒」記憶。

## 因素影響筆記

```
貢榜擴張＋暹備戰廢 ──→ 1766種稻圍城 ──→ 1767.4陷落焚城
                                              ↓
鄭信華人資本＋緬北歸戰清 ──→ 吞武里復國 ──→ 1782曼谷集權2.0
```

**偵探結語**：阿瑜陀耶活了417年，死於把雨季當保險——**緬甸人把保險單撕了，在城外種起稻來**。而復國者是稅吏的兒子（半個中國人）——古都的葬禮上，抬棺的是新移民。曼谷此後兩百年沒再遷都，因為新棺材用潮州木打的，結實。
