# 1532 印加帝國：內戰、天花與卡哈馬卡的 168 人

## 案發現場

1532 年 11 月，卡哈馬卡廣場，皮薩羅以 168 名西班牙人突襲，擒獲印加皇帝阿塔瓦爾帕（其數千衛隊被屠）。皇帝出贖金（一屋黃金一屋白銀，史上最大贖金），仍被處死（1533）。此前：天花流行（皇帝瓦伊納·卡帕克死於天花，1527）、兄弟內戰（阿塔瓦爾帕 vs 瓦斯卡爾，1529–32）。帝國（安第斯山脈，千萬人口）亡於 168 人。

> **168 人擒一國之君後為何無人反抗？內戰、天花、馬匹、文字——印加的死因裡，哪個是第一推手？**

## 偵查過程

**線索一：兄弟內戰（帝國的左右互搏）。** 瓦伊納·卡帕克死於天花（1527，先於西班牙人到達——天花比軍隊跑得快），兩子分南北（基多 vs 庫斯科）內戰三年，阿塔瓦爾帕剛獲勝（1532，瓦斯卡爾被俘）。皮薩羅到時，帝國是**剛打完內戰的疲憊之師**：軍隊傷亡、地方離心（瓦斯卡爾派）、皇帝立足未穩。偵查結論：**內戰是第一推手**：沒有內戰，阿塔瓦爾帕不會輕敵（帶數千衛隊赴會，以為是外交場合）；沒有內戰，瓦斯卡爾派不會暗助西班牙人（敵人的敵人）。**鷸蚌相爭，漁翁只需要 168 人**——內戰把帝國的防禦歸零，皮薩羅撿了現成的。與阿茲特克（參見本書 [1521-阿茲特克.md](1521-阿茲特克.md)）對照：阿茲特克死於外恨（花戰），印加死於內耗（兄弟）——**外恨養叛軍，內耗降防禦**，兩種死法同一公式：團結歸零。

**線索二：天花先行（病毒的外交使團）。** 天花（1520s 從中美洲傳入，比皮薩羅早到五年）殺死皇帝+繼承人（瓦伊納·卡帕克+太子），引發繼承真空→內戰。偵查結論：天花是**內戰的助產士**：沒有天花，無繼承危機；沒有危機，無內戰；沒有內戰，無卡哈馬卡。**因果鏈**：病毒→皇帝死→內戰→防禦零→168 人擒王。皮薩羅的真正先鋒是看不見的——**微生物比帆船快五年**。印加的人口損失（估計高達九成，一說） vs 阿茲特克同款（參見本書 [1521-阿茲特克.md](1521-阿茲特克.md)）——**哥倫布大交換的死亡面**：舊大陸輸出疾病，新大陸輸出白銀土豆——**不對等的交換，拿命換銀**。

**線索三：卡哈馬卡的突襲（斬首的標準動作）。** 皮薩羅設伏（廣場埋伏火槍大砲騎兵），印加衛隊無甲（儀仗性質），鳴炮+衝鋒+擒王，一個下午死傷數千（一說）。偵查結論：這是**斬首戰術的教科書**：擒王（太陽之子，神）→全軍宕機（士兵不敢動——動=瀆神，參見蒙特祖瑪，[本書 1521 篇](1521-阿茲特克.md)）。**神權君主的單點故障**：皇帝=太陽化身，被擒=太陽被抓——宇宙觀崩塌比軍隊崩塌更快。贖金（一屋金）交了仍被殺（莫須有：叛亂罪）——**贖金買的是時間（皮薩羅等人到齊），不是命**。阿塔瓦爾帕到死學會西班牙語（要求洗禮改名胡安）——**求生欲戰勝了太陽神**，晚了。卡哈馬卡證明：**神王制下，擒王=亡國**——不需要打贏軍隊，只需要抓住一個人。

**線索四：馬匹鋼鐵文字（技術三件套）。** 西班牙人：馬（機動+心理震懾：印加人沒見過騎兵）、鋼劍甲（青銅/石器對鋼）、文字（協調+欺詐：契約、聖經、假情報）。偵查結論：賈雷德·戴蒙德的「槍炮病菌鋼鐵」在此全齊——**三件套缺一即不同結局**：無馬（追不上）、無鋼（砍不動）、無文字（騙不了+協調不了 168 人）。但三件套是**放大器**，不是本因：沒有內戰天花，168 人再強也只是騷擾（曼科二世 1536 年圍攻庫斯科，差點翻盤——證明印加會打仗，只是沒機會）。**技術決定下限（168 人敢動手），團結決定上限（帝國會不會垮）**——下限夠了（敢），上限沒了（內戰），結局注定。

## 結案報告

1. **內戰即歸零**：兄弟三年互搏——鷸蚌相爭，168 人撿現成。
2. **病毒即助產士**：天花殺皇帝→繼承真空→內戰——微生物比帆船快五年。
3. **神王即單點**：擒王=亡國——贖金買時間不買命，求生輸給太陽神太晚。
4. **技術即放大器**：馬鋼文字三件套——決定下限（敢動手），不決定上限。

**因果鏈（示意）：**

```
天花（1527，皇帝死）→ 繼承真空 → 內戰（1529–32）
  → 防禦歸零 → 卡哈馬卡（168 人擒王）→ 贖金→處死。
病毒是第一塊骨牌——推倒皇帝，再推倒帝國。
```

**結論：** 印加案是「內爆外擒」的標準樣本：天花殺皇帝、兄弟殺團結、168 人殺皇帝（二度）——三殺疊加，千萬人口帝國歸零。**最少的征服者（168 人）打最大的帝國（千萬人），靠的不是強，是對手先把自己打殘**。皮薩羅的墓誌銘應該寫：感謝天花，感謝內戰——我只是來收屍的，順便收了一屋黃金。
