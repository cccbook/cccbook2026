# 0316 西晉：八王之亂與永嘉之禍——自己拆自己的防線

## 案發現場

316 年，匈奴漢趙政權的劉曜攻破長安，晉愍帝出降——西晉滅亡。距武帝司馬炎 280 年滅吳統一天下，僅三十六年；距爆發內戰的「八王之亂」（291 年起），僅二十五年。中間還有 299 年起的大飢荒、氐羌流民起義（李特、流民入蜀）、以及 311 年的永嘉之禍——洛陽陷落、數萬官民被殺、晉懷帝被擄。**一個繼承了曹魏精兵與東吳資源的統一王朝，怎麼能在一代人之內把首都輸兩次？**

> **西晉的滅亡是「分封諸王」制度的錯，還是「門閥清談」文化的錯？為什麼最終接住中原的不是任何漢人政權，而是內附的匈奴？**

## 偵查過程

**線索一：制度設計的原始缺陷——矯枉過正的分封。** 司馬家族的政權來自宮廷政變（高平陵之變）而非軍功集團的立國戰爭，它對「權臣代魏」的路徑瞭如指掌——因為自己就是這條路的走完者。於是武帝大封宗室諸王、授予都督軍權與封國兵，理由是「屏藩皇室、防止外姓權臣」。但設計者忽略了一件事：**防止權臣的手段，是製造一群潛在權臣**。武帝一死（290），惠帝弱智、賈后干政，都督州的宗王們發現中央可以奪——八王之亂的開關就裝在制度裡。

**線索二：內戰的軍事自殘。** 八王之亂的本質是洛陽中央與都督諸王（鄴、關中、許昌三大軍區）的循環火併：諸王互相調用防禦胡人的邊軍、放縱鮮卑烏桓突騎參與內戰（王浚引段部鮮卑屠掠鄴城與河北）、把帝國最精銳的部隊消耗在洛陽城下的拉鋸。統計：三十年內中原的野戰軍幾乎全滅於自己人之手。偵查結論：**胡人不是打進來的，是看著防線自己拆完才進來的**。

**線索三：內附胡族的結構性位置。** 曹操與晉廷把降附的匈奴五部安置於并州（今山西）內地，「以防塞外」——數十萬戶遊牧武裝 living 在帝國腹地與農業區交界。八王之亂中，成都王司馬穎把匈奴五部都督劉淵當傭兵資源拉攏；劉淵趁機於 304 年回到左國城自立，國號「漢」（以漢室外甥自居，政治包裝極精）。**內附部族的軍事動員成本低於任何中原勢力**：他們的騎兵體系完好，而晉的野戰軍已在內戰中燒光。

**線索四：士族文化的治理失能。** 門閥政治的另一面：清談玄學成為精英身份的通行證，州郡武備被裁撤（罷州郡兵，天下一統後的「和平紅利」幻想）、公卿以服散清言為榮而避實務。這不是「亡國因為喝酒清談」的道德故事，而是**精英的激勵結構**：選官看門第（九品中正制的固化），能力與責任脫鉤，政權在危機來臨時找不到能執行的官僚。財政上，占田蔭客制把人口與賦稅讓渡給士族——**國家連普查與徵兵的底層資料都交給了私人**。

**線索五：天災的壓力測試。** 299 年起的關中大旱與饑荒把關中流民推向漢中、益州（李特流民起義，成漢政權的起源）；山西、河南的飢荒使內附胡族與漢民同時失所。晉廷的賑濟與遷徙政策失靈——**任何帝國的危機處理能力，等於其基層行政與糧倉體系的健康度**，而西晉兩者皆已禮讓給門閥與諸王。

## 結案報告

1. **政變起家的政權，用「防止政變」的制度自殺**：分封宗王的設計把防禦工事變成了內戰軍火庫。
2. **內戰是外患的前置工程**：八王之亂不是背景，是主兇——它完成了所有外敵需要的「防線拆解」。
3. **內附與遷徙是雙刃**：把武裝人口引入腹地可以省軍費，但前提是中央有駕馭它的野戰軍——西晉沒有。
4. **精英脫鉤於治理**：門第選官＋蔭客免稅＝國家失去動員能力——文化興盛（清談、文學、書法）與國家能力是兩回事。
5. **偵探教訓**：問「帝國為何亡」，先問「帝國的暴力與賦稅基礎被誰 privatize 了」——西晉把軍權給了宗王、人口給了士族、騎兵資源給了內附部族，**三個 privatization 就是三份遺囑**。

## 證據與工具

**滅亡時序與主因維度：**

| 年份 | 事件 | 主因 |
|------|------|------|
| 265–280 | 司馬代魏、滅吳統一 | 制度起點：政變政權 |
| 290 | 武帝死、賈后干政 | 繼承危機 |
| 291–306 | 八王之亂 | 政治（分封自毀） |
| 299– | 關中大飢、流民入蜀 | 環境＋社會 |
| 304 | 劉淵自立、成漢建國 | 軍事（內附部族崛起） |
| 311 | 永嘉之禍：洛陽陷落 | 軍事＋政治 |
| 316 | 長安陷落、愍帝降 | 終局 |

**自毀鏈（本案核心模型）：**

```
政變建國 → 恐懼權臣 → 大封宗王＋都督軍權
   → 繼承弱主 → 宗王奪權 → 內戰消耗野戰軍
   → 邊備撤空 ＋ 內附部族武裝完好
   → 胡族自立 → 兩京陷落 → 南渡（東晉）
```

**與同類案例對照：**

| 案件 | 軍權私有化的對象 | 結局 |
|------|------------------|------|
| 西晉（0316） | 宗王＋內附胡族 | 內戰引狼入室 |
| 東漢→三國 | 州牧與豪族部曲 | 割據 |
| 唐（0907） | 藩鎮 | 節度使取代朝廷 |

**結論：** 西晉案是「防禦性制度設計」反噬的教科書：**用來防止上一種死法的制度，往往就是下一種死法**。三十六年統一、二十五年內戰、兩京相繼陷落——中原三百年的大分裂，開關是司馬炎親手按下的一份分封詔書。
