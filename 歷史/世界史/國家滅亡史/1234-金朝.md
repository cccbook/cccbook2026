# 1234 金朝：交鈔變廢紙與蔡州之圍

## 案發現場

1234 年，蒙宋聯軍攻破蔡州，金哀宗自縊，末帝被殺，金朝滅亡（120 年）。此前：野狐嶺慘敗（1211，45 萬號稱，一戰崩）、三峰山覆滅（1232，完顏合達移剌蒲阿二十萬覆沒）、汴京陷落（1233，崔立獻城）。金末：交鈔貶值萬倍（一說）、军心渙散、黃河改道水患。紙幣先死，國家後死。

> **交鈔是怎麼變成廢紙的？當財政先於防線崩潰，蔡州的三萬殘兵為何還能守三個月——金朝的最後一戰在證明什麼？**

## 偵查過程

**線索一：交鈔的濫發（無準備金的印刷機）。** 金末軍費浩大（抗蒙+防宋），稅收（北方殘破+黃河水患）銳減——朝廷濫發交鈔（紙幣）+大錢（銅錢貶值），無金銀準備、無發行上限。貞祐年間（1213–17）交鈔貶值百倍，正大末年（1230s）萬倍（一貫買一餅，一說）。偵查結論：這是**財政的飲鴆止渴**：印鈔解燃眉（發餉），通膨殺長遠（物價飛漲→市場退回以物易物→稅收更收不上→再印）。**惡性通膨的死亡螺旋**（參見西羅馬，[本書 0476 篇](0476-西羅馬帝國.md)：銀幣版；此處紙幣版）——**幣制先亡，軍心後亡**：士兵拿廢紙當餉，不如回家種地（逃亡）——野狐嶺、三峰山的潰敗，一半是戰術（蒙古強），一半是**餉銀是紙**（沒人為廢紙拼命）。蔡州守軍（三萬）是特例（哀宗親在+絕境），證明**餉銀正常時金軍能打**——交鈔殺死了正常。

**線索二：野狐嶺與三峰山（兩場殲滅戰）。** 1211 野狐嶺：金軍號稱 45 萬，被蒙古十萬擊潰（胡沙虎臨陣脫逃+指揮混亂）；1232 三峰山：金最後野戰軍（完顏合達、移剌蒲阿）被拖雷迂迴+雪夜圍殲。偵查結論：兩戰的共同點——**以多輸少**：人數佔優，組織完敗。野狐嶺輸在**臨陣換將+脫逃**（胡沙虎殺主帥獨吉千家奴），三峰山輸在**飢寒+被圍**（鄧州雪夜，斷糧三日）。**金軍的病：將不知兵（女真勳貴腐化）+兵無鬥志（餉是廢紙）**。與北宋（參見本書 [1127-北宋.md](1127-北宋.md)）對照：同樣紙面大軍、同樣一觸即潰——**重文輕武（宋）與勳貴腐化（金）殊途同歸**：平時不練兵，戰時現配命。蒙古的十進制（參見 [../亞洲史/1206-成吉思汗.md](../亞洲史/1206-成吉思汗.md)）打紙面大軍，如刀切豆腐——**組織度差兩級，人數差十倍也沒用**。

**線索三：聯蒙滅金？不，是聯宋（南宋的短視）。** 1233 年，南宋（孟珙）與蒙古約：夾攻蔡州，滅金後河南歸宋。1234 年蔡州破，金亡。三十年後（1270s），蒙古（忽必烈）南下滅宋（參見本書 [1279-南宋.md](1279-南宋.md)）。偵查結論：這是**海上之盟的翻版**（參見本書 [1127-北宋.md](1127-北宋.md)）：宋再一次拆屏障（金）引強盜（蒙）——**同樣的錯，犯兩次**（1120 聯金滅遼，1233 聯蒙滅金）。南宋的算盤（收復河南） vs 代價（直面蒙古）——**算盤珠子打錯了**：河南三城（蔡州分得）守不住（無險可守），蒙古大軍守不住（無人可擋）。**短視的連續性**：從徽宗到理宗，宋的外交DNA不變——**聯強滅弱，弱滅強大，強再滅宋**。金亡（1234）→宋亡（1279），間隔 45 年——**給自己挖的墳，四十五年後準時下葬**。

**線索四：蔡州三個月（末日的尊嚴）。** 蔡州被圍（蒙宋十萬圍三萬），哀宗分發宮藏（布帛）、與士卒同苦，城破前傳位（末帝，百官皆哭）、自縊（幽蘭軒）。蒙古史官亦記金忠臣（完顏承暉、完顏陳和尚）。偵查結論：蔡州證明**金朝不是不能打，是平時不打**：絕境+明君（哀宗，正大之治，算中興之主）+無路可退=戰力拉滿（三個月，蒙宋死傷慘重）。**迴光返照定律**：滅亡前的精英（哀宗、陳和尚）總是最好的——因為**選拔機制恢復正常**（絕境無人情，唯才是舉）。蔡州的尊嚴屬於個人（哀宗、守軍），不屬於體制（體制早死於交鈔+腐化）——**個人的英勇救不了系統的死亡，只能給墓誌銘加分**。末帝在位不足一日（一說半日）——**史上最短命的皇帝，史上最長的葬禮（三個月圍城）**。

## 結案報告

1. **幣制先亡**：交鈔萬倍貶值——士兵不為廢紙拼命，潰敗一半是餉銀的錯。
2. **組織差兩級**：紙面大軍對十進制——人數差十倍也沒用，刀切豆腐。
3. **短視犯兩次**：聯蒙滅金翻版海上之盟——拆屏障引強盜，墳四十五年後用。
4. **迴光定律**：蔡州三個月——絕境恢復選拔，個人英勇只給墓誌銘加分。

**通膨—潰敗鏈（示意）：**

```
濫發交鈔 → 萬倍貶值 → 餉銀成紙 → 逃亡 → 野狐嶺/三峰山潰
  → 蔡州（哀宗自掏腰包，迴光）→ 城破。
幣制死在前，防線死在後——財政是防線的爹。
```

**結論：** 金案是「財政先亡」的標準樣本：交鈔變紙、逃亡成風、兩場殲滅、蔡州迴光——120 年女真帝國，死於印刷機和短視的鄰居。**防線的爹是財政**：餉銀正常，金軍能守三個月（蔡州）；餉銀成紙，百萬大軍一觸即潰（野狐嶺）。而南宋在旁邊鼓掌——四十五年後，掌聲變成哭聲。挖墳的人，終將躺進去。
