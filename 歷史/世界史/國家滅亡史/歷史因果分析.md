# 國家滅亡史歷史因果分析

## 案件摘要

本案卷宗厚達五千年，死者近百，兇手卻始終是同一夥人輪流值班：**財政失血、軍事代差、合法性崩塌、精英內鬥、結構剛性**。沒有一個國家死於單一兇器——法醫報告上永遠是多處傷口，且多數傷口在死亡前十到一百年就已造成。因果總公式：

$$\text{滅亡} = (\text{財政失血} + \text{軍事代差}) \times \text{合法性赤字} \xrightarrow{\text{危機催化}} \text{結構解體}$$

一句話結案：**滅亡不是事件，是過程；亡國之君往往只是法醫，不是兇手**——拜占庭死於 1354 年鄂圖曼登陸歐洲，1453 年只是行刑；清朝死於 1850 年代的內亂與財政失控，1912 年只是簽字。

## 因果鏈與回饋環

### 鏈一：失血—代差—行刑的標準時序

大多數滅亡遵循同一時間線：**失血（數十年到數百年）→ 死刑判決（結構性劣勢確立）→ 行刑（表面上的滅亡事件）**。拜占庭的帳單：1071 曼齊刻特失血、1204 截肢、1354 死刑、1453 行刑（`1453-拜占庭帝國.md`）。南宋的版本：聯蒙滅金自毀緩衝（`1234-金朝.md`、`1279-南宋.md`），襄陽失守後財政軍事同時見底。西晉則示範了「精英自殺」的加速版：八王之亂把帝國軍力燒光，永嘉之禍只是收屍（`0316-西晉.md`）。偵推：**閱讀滅亡案卷時，把焦點從亡國之日往前挪五十年，兇手通常已經在場**。

### 鏈二：財政死因的兩種變體

| 變體 | 機制 | 案件 |
|------|------|------|
| 美洲白銀型 | 靠掠奪性現金流掩蓋結構空洞 | `1557-西班牙破產.md`、`1485-大利馬與穆塔帕.md` |
| 石油與外援型 | 單一收入中斷即窒息 | `1991-蘇聯解體.md`、`2011-利比亞格達費政權.md` |
| 債務滾雪球型 | 軍費＋借債＋通膨螺旋 | `1918-德意志帝國.md`、`1983-阿根廷債務與惡性通膨.md`、`2009-希臘債務危機.md` |

規律：**錢好賺的時候不改，錢斷流的時候改不動**——資源詛咒的帝國版與共和國版共用同一劇本。

### 鏈三：合法性—動員—替代秩序

合法性不是裝飾，是徵稅與徵兵的潤滑劑。法國波旁王朝死於財政破產＋三級會議的合法性重構（`1789-法國波旁王朝.md`）；魏瑪死於戰敗恥辱與經濟恐慌的雙重打擊（`1933-魏瑪共和國.md`）；東德死於績效與理念的雙重破產，柏林牆一開，國家即無（`1990-東德.md`）；阿富汗共和國則證明**沒有忠誠的軍隊，任何政權的存活時間以天計**（`2021-阿富汗共和國.md`）。回饋環：

```mermaid
flowchart LR
    A[政績/理念承諾] --> B[財政或軍事挫敗]
    B --> C[合法性赤字]
    C --> D[徵稅徵兵成本上升]
    D --> E[更多橫徵暴斂]
    E --> F[民眾與精英離心]
    F --> B
```

### 鏈四：多民族結構的散夥預製件

奧匈在戰敗時按民族斷面整齊裂開（`1918-奧匈帝國.md`）；南斯拉夫在強人死後與經濟崩潰中沿同一斷面撕裂（`1992-南斯拉夫.md`）；蘇聯憲法預埋的退出權在公開化時變成消防斧（`1991-蘇聯解體.md`）。**聯邦結構平時是裝飾，危機時是切割線**——共用的臨界條件永遠是：中央財政失能＋鎮壓意志瓦解。

## 關鍵轉折點

1. **-2193 年阿卡德滅亡**：史上第一份帝國死亡證明，單一糧源＋氣候衝擊的脆弱性原型（`-2193-阿卡德帝國.md`）。
2. **476 年西羅馬落幕**：軍隊蠻族化＋稅基萎縮的慢性病終末期，皇帝之位已成雞肋（`0476-西羅馬帝國.md`）。
3. **1204 年君士坦丁堡洗劫**：外力截肢讓帝國永久失去復原能力（`1204-君士坦丁堡洗劫.md`）。
4. **1795 年波蘭被瓜分**：貴族否決制（liberum veto）讓國家在鄰國擴張前自我癱瘓——**制度設計缺陷直接賣掉地圖**（`1795-波蘭立陶宛.md`）。
5. **1991 年蘇聯解體**：超級大國在無外敵入侵、無大規模內戰下和平散夥，證明結構性死亡可以不流血（`1991-蘇聯解體.md`）。

## 反事實推演

- **若拜占庭保住小亞細亞**：兵源與稅基在，烏爾班巨砲只能轟出一場普通圍城，1453 年或成為另一次擊退鄂圖曼的勝仗——帝國續命未必，但不至於孤城待斃。
- **若明朝未裁撤驛站、未壓縮邊軍餉銀**：李自成可能仍是驛卒，流寇與後金兩線壓力減半，1644 年的北京或能撐到勤王兵到（`1644-明朝.md`）。
- **若蘇聯 1986 年油價不崩**：硬通貨續流，改革壓力延後，但計畫僵化只會加深——解體或遲到十年，且可能以更激烈的方式到來。
- **若奧匈戰勝或體面議和**：民族矛盾仍在，但「戰敗即解體」的觸發器不啟動，帝國可能如英國般以緩慢分權改造存續——戰爭結果比民族矛盾本身更具決定性。

## 偵探教訓

1. **滅亡是慢性病，不是意外**：把案發日往前推五十年，看稅基、軍力與合法性三張體檢報告，死因早就在化驗單上。
2. **錢比軍隊先死**：幾乎所有政權在失去戰場之前先失去財政——查帳本比查地圖更能預測亡國。
3. **代差殺死的不只是軍隊，還有信心**：城牆保質期等於進攻技術迭代周期，神話一旦破，士氣先於城牆崩塌。
4. **結構剛性是最隱形的兇手**：能改革時不改革（既得利益阻撓），想改革時已無資源——「改革窗口」是滅亡案卷中最常缺席的證物。
5. **多民族與過度集權是同一枚硬幣**：集權壓住矛盾時天下太平，財政一斷，壓力沿著預製的斷面整齊裂開。
