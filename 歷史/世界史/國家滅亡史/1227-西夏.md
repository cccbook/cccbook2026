# 1227 西夏：軍國財政榨乾黨項王國

## 案發現場

1227 年，成吉思汗遺命圍攻中興府（今銀川），末帝李睍出降，蒙古屠城，西夏（1038–1227，近 190 年）滅亡。此前：與北宋、遼、金三方和戰（歲幣外交），與蒙古六次大戰（1205–26），末期地震、瘟疫、內訌（得敬塞骨之亂）疊加。**黨項以區區數州之地三面稱帝近兩百年，為何最後十年像被抽掉骨頭一樣垮掉？**

> **小國軍國化的代價是什麼？當全民皆兵，誰來種地、誰來交稅？**

## 偵查過程

**線索一：全民皆兵的財政（兵民合一的賬本）。** 西夏戶口約 300 萬，最高動員 50 萬（正軍 15 萬+擒生軍 10 萬+民兵），動員率逾 15%——前現代社會的極限（對照：北宋動員率約 2%）。偵查結論：**每六個黨項人養一個兵**，平時為農戰時為兵→農時誤（青壯抽走）→糧食減→加稅（賦斂苛重，李元昊鑄禮法、括田畝）→逃戶（蕃漢流亡宋金）→稅基縮→再加稅。**動員率→逃戶→稅基萎縮的死亡螺旋**：對蒙戰爭前已轉十圈。

**線索二：歲幣外交的斷奶（ external subsidy 歸零）。** 西夏歲入三支柱：歲幣（宋歲賜銀絹+茶葉，遼、金歲幣）+榷場互市（青鹽、馬匹）+農牧稅。金朝衰落（蒙金戰爭）後金幣斷付，南宋榷場因戰時禁運，**外部輸血停掉的同時軍費翻倍**（抗蒙）。財政方程進入絕境：

```
歲入（歲幣↓+互市↓+農稅↓）− 軍費（↑↑）= 赤字 → 括田、和糴、鑄惡錢
```

末期鑄「天慶寶錢」惡錢、強行和糴（低價徵糧），漢人地主倒戈（以城降蒙者眾）——**財政先叛變，城池才投降**。

**線索三：官僚蕃漢二元的撕裂。** 西夏官制蕃（樞密、蕃學）漢（中書、門下）並立，末期外戚（沒藏、梁氏故事重演）與權臣得敬家族專權，末帝誅得敬卻失蕃將心、漢官早已離心。偵查結論：**認同分裂先於城牆破裂**：中興府被圍時城內蕃漢互疑、開門獻城者即漢官——與元昊立國時蕃漢一體恰成鏡像。**制度老化：開國的包容官僚，亡國時變成兩套互相告密的系統**。

**線索四：外交誤判（聯金拒蒙的時機錯）。** 1219 年成吉思汗邀夏攻金，西夏拒絕且對金若即若離；1224 年聯金（金夏議和）已太晚——蒙古既定先滅夏再攻金（去唇亡齒）。小國在大國夾縫的生存術（平衡、納幣、聯弱抗強）需要精準時機，西夏末期**同時得罪蒙金宋**（拒蒙、叛金、擾宋），三面無援。**地緣孤立+財政枯竭+認同撕裂**——1227 年屠城只是簽收單。

## 結案報告

1. **軍國化榨乾稅基**：15% 動員率→逃戶→加稅→再逃戶，螺旋十圈即亡。
2. **歲幣即氧氣**：外部輸血一停，軍費一漲，惡錢和糴接踵而至。
3. **二元官僚反噬**：開國包容變亡國互疑，城門從內部打開。
4. **小國時機定律**：夾縫生存靠精準站隊，同時得罪三家等於自殺。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 滅亡工程 | 跨域效應 |
|------|----------|----------|
| 經濟 | 歲幣斷+惡錢+和糴 | 漢人地主倒戈獻城 |
| 軍事 | 六次抗蒙耗盡青壯 | 中興府無兵可守 |
| 政治 | 外戚權臣專權內訌 | 蕃漢官僚互疑 |
| 外交 | 拒蒙叛金擾宋 | 三面無援被圍屠 |

**財政死亡螺旋（示意）：**

```
高動員 → 誤農時 → 糧減 → 加稅 → 逃戶 → 稅基縮 → 再加稅 → 惡錢和糴 → 倒戈
```

**動員—稅基模型：**

$$
\frac{dB}{dt} = -\alpha M + \beta S,\quad M\uparrow\uparrow,\ S\ (\text{歲幣})\to 0 \Rightarrow B \to 0
$$

（$B$ 稅基，$M$ 動員強度，$S$ 外部輸血）

**結論：** 西夏案是「小國軍國化」的標準樣本：以三州之地養五十萬兵近兩百年已是奇蹟，奇蹟的燃料是歲幣與互市。當蒙古把燃料抽掉、把戰爭強度調高，黨項王國不是被攻破的，是被自己的動員率壓垮的——**全民皆兵的終點，是全民皆逃**。
