# 1739 莫臥兒帝國與納迪爾沙入侵：孔雀寶座上的死亡通知書

## 案發現場

1739 年二月，波斯阿夫沙爾王朝的納迪爾沙在卡爾納爾（Karnal，德里西北）以優勢騎兵與野戰炮擊潰莫臥兒皇帝穆罕默德·沙的大軍，隨後進入德里；傳言的暴亂遭致波斯軍屠城，莫臥兒被迫割讓印度河西全部省份（今巴基斯坦與阿富汗一帶），並獻上**孔雀寶座、光之山與光之海**等皇冠珠寶——估計掠走相當於帝國歲入數倍的財富。戰後納迪爾沙揚長而去，未占領土核心；但莫臥兒名義上繼續存在百年。為何一場「打完就走」的掠奪性入侵，被史家視為帝國的死亡通知書？

> **入侵者不占領、不遷都、不換朝——他只是搬走了寶座上的珠寶，帝國為何就此信用破產？**

## 偵查過程

**線索一：德干戰爭的二十六年放血（1681–1707）。** 奧朗則布晚年親率大軍南下征伐馬拉塔與德干諸蘇丹國，前後二十六年（1681–1707）耗在馬拉塔游擊的泥沼中：軍費長期超收、賈吉爾（采邑）枯竭、柴明達爾欠稅蔓延，北方的軍政精英與財政盡數南調。偵查結論：這是**帝國的自我放血**——奧朗則布贏了幾乎每一場戰役，卻輸掉了財政與時間。德干戰爭把帝國從「中央調節的財政機器」變成「地方自求多福的承包體系」：**皇帝還在德里，但帝國的毛細血管已經各自斷電**。馬拉塔戰爭同時鍛造出敵人（參見線索三）——放血療法放的是自己，練的是對手。

**線索二：帝國信用——莫臥兒真正的貨幣。** 莫臥兒體制依靠三種信用運轉：曼薩布達爾（軍階貴族）相信「效忠有回報」、賈吉爾達爾相信「采邑有收益」、各省納瓦布相信「中央有能力保護與制裁」。1739 年穆罕默德·沙御駕親征即崩、皇帝本人被俘、寶座與雙鑽被搬走——三種信用**在同一天兌付失敗**。偵查結論：這是掠奪性入侵的精妙之處：納迪爾沙不需要占領，**他只需當眾證明皇帝的保險單是廢紙**。此後孟加拉、奧德、海得拉巴的納瓦布加速自治（納瓦布的效忠對象變成自己），旁遮普的錫克人與馬拉塔騎兵填補真空。1750 年代納迪爾沙死後其將領艾哈邁德沙·阿布達里（杜蘭尼）照方抓藥、屢次南掠（1757 劫德里）——**破產的保險公司會被反覆擠兌**。

**線索三：鄰國的崛起——馬拉塔與波斯的一體兩面。** 內部有馬拉塔：西瓦吉開創的游擊政權在德干戰爭中越打越大，1730 年代巴吉·拉奧一世已兵臨德里城郊（1737），帝國實際上已對馬拉塔割地求和（1738 年前後）。外部有波斯：1722 年薩法維王朝被阿富汗人傾覆（參見 [0651-薩珊波斯.md](0651-薩珊波斯.md) 的波斯案互見脈絡），納迪爾沙以復國者身分崛起，平阿富汗、擊鄂圖曼、收呼羅珊——**薩法維滅亡造成的權力真空，被軍事天才填充並外溢**。偵查結論：這是權力轉移理論的雙向夾擊：內部崛起者（馬拉塔）吸走稅基與軍功，外部崛起者（納迪爾沙）吸走寶藏與邊省。修昔底德式的恐懼在莫臥兒朝堂上表現為癱瘓——**被兩個方向的崛起者同時追上，守成者連押注哪一邊都來不及**。

**線索四：卡爾納爾的軍事學判決書。** 卡爾納爾之戰：莫臥兒約三十萬大軍（含大量儀仗與非戰鬥人員）對納迪爾沙約八至十二萬精兵；波斯軍以機動騎兵、野戰炮與偵察優勢合圍，莫臥兒指揮體系一觸即潰，皇帝親赴敵營求和。偵查結論：這是**組織度的閱兵式審判**——德干二十六年沒有鍛鍊出任何新軍制，北方禁軍徒有其表；波斯軍卻是連續十餘年實戰選拔出的戰爭機器。戰場之外，波斯人早已透過商旅與叛逃者掌握莫臥兒的布防與虛實——**帝國的機密在市場上流通，而皇帝的軍報還停在三十年的光榮記憶裡**。此戰不是亡國的起點，是對早已發生的死亡的公證。

## 結案報告

1. **自我放血**：德干 26 年戰爭掏空財政與中央權威——贏了戰役，輸掉帝國的血管。
2. **信用破產日**：1739 年皇帝被俘、寶座被搬——曼薩布、賈吉爾、納瓦布三重信用同日兌付失敗。
3. **雙向夾擊**：馬拉塔（內）與納迪爾沙（外）先後崛起，薩法維滅亡的真空直接傳導到德里。
4. **不占領的致命性**：掠奪性入侵只拆信用不接管領土——帝國繼續存在，但已無人相信它。

**掠奪性入侵公式（示意）：**

```
帝國壽命 ＝（軍事信用 × 財政信用 × 政治信用）。
德干戰爭：財政信用 ↓。
卡爾納爾（1739）：軍事信用歸零；
皇帝被俘當日，政治信用跟進。
三者其一歸零，帝國只剩名號——
不占領的入侵，是最好的死亡通知書。
```

**結論：** 莫臥兒案的偵查重點在於：1739 年不是死亡，是**訃告**。殺死帝國的三因素早已到位：**奧朗則布的德干戰爭**（自殘）、**馬拉塔的崛起**（內部權力轉移）、**納迪爾沙與薩法維滅亡後的真空傳導**（外部權力轉移）——卡爾納爾只是當眾宣讀了體檢報告。孔雀寶座被搬去馬什哈德，是帝國信用破產的實物證據；此後英國東印度公司（參見 [../亞洲史/1757-普拉西之戰.md](../亞洲史/1757-普拉西之戰.md)）與馬拉塔在同一片信用廢墟上競標——**沒人再相信德里的保單，帝國便只剩被接管的命運**。
