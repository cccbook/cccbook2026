# 1795 波蘭立陶宛：自由否決權與三次瓜分

## 案發現場

1795 年，俄普奧第三次瓜分波蘭——波蘭立陶宛聯邦（1569–1795，鼎盛時歐洲最大國之一）從地圖上消失（123 年，直到 1918 年復國）。此前：第一次瓜分（1772）、《五三憲法》（1791，歐洲第一部成文憲法，廢否決權）、第二次瓜分（1793，俄普回應改革）。**一個有憲法、有啟蒙、有軍隊的國家，為何三次被切？**

> **自由否決權如何癱瘓一個大國？當一名議員能否決全國，議會是民主的殿堂，還是自殺的機器？**

## 偵查過程

**線索一：自由否決權（一人否決全國）。** 波蘭議會（瑟姆）慣例：任何一名議員（貴族）可喊「我反對」（自由否決），議案作廢，議會解散。1652–1764 年，半數議會被否決解散——稅收、軍費、改革全過不了。偵查結論：這是**全票通過制的自殺**：設計初衷（防王權+保貴族自由）→異化為鄰國工具（俄普收買一名議員即癱瘓波蘭）——**否決權成了外國的遙控器**。與聯合國安理會（五常否決）對照：同樣一人否決，安理會癱瘓的是決議（可繞行），波蘭癱瘓的是國家（稅收軍隊全停）。**否決權的毒性=被否決事項的重要性**：否決宣戰（波蘭）即自殺，否決譴責（安理會）只是吵架。波蘭用兩百年證明：**全體一致是最高級的癱瘓**。

**線索二：三次瓜分（強鄰的切蛋糕）。** 1772（俄普奧第一次：各取邊疆，波蘭丟三成）、1793（俄普第二次：回應五三憲法）、1795（第三次：全分）。偵查結論：瓜分的**時機選擇**：第一次（波蘭巴爾聯盟內戰+奧斯曼分心）、第二次（法國大革命，歐洲無人管）、第三次（柯斯丘什科起義失敗）。**強鄰切蛋糕的條件：受害者內亂+國際無人管**——波蘭兩樣全佔（否決權內耗+法國自顧不暇）。普魯士（腓特烈大帝）的算盤：**與其和奧俄爭，不如三家分**——分贓協議（彼得堡）比戰爭便宜。瓜分的合法性包裝（「恢復秩序」「保護信徒」）——**強權的藉口永遠是為你好**。波蘭的教訓：**地緣位置（夾在三強之間）+制度癱瘓=待切蛋糕**，缺一即不亡（有制度可抗，有位置可逃）。

**線索三：五三憲法（改革來得太晚）。** 1791 年，四年議會（繞開否決：秘密結盟+趁親俄派缺席）通過憲法：廢否決權、世襲王位、市民權、農民保護——歐洲第一部。俄羅斯以「保衛自由」為名入侵（1792，塔戈維查叛國貴族帶路），憲法黨敗，第二次瓜分。偵查結論：**改革的時機悲劇**：改得對（廢否決），改得晚（鄰國已嘗到甜頭，不許你改）——**觸動既得利益（俄普：癱瘓的波蘭最好）即招打**。與明治（參見 [../亞洲史/1868-明治維新.md](../亞洲史/1868-明治維新.md)）對照：同樣自上而下改革，明治成功（島國+列強忙+廢藩徹底），波蘭失敗（陸上三強包圍+改革不徹底（農奴未解放）+外援零）。**改革的成功=內容×時機×地緣**——波蘭內容對，時機晚，地緣死。五三憲法的墓誌銘：**正確的答案，交卷時考場已關門**。

**線索四：123 年亡國（沒有國家的民族）。** 1795–1918，波蘭語、文學（密茨凱維奇）、天主教保存民族——一月起義（1830）、一月起義（1863）皆敗，但民族不死。一戰（德奧俄互毆）→1918 年畢蘇斯基復國。偵查結論：這是**文化亡國論的反例**：國家亡了（123 年），民族活了（語言文學教會）——**認同不需要國家機器**（對比亞述，[本書 -0612 篇](-0612-亞述帝國.md)：亞述無認同故無復國；波蘭有認同故復國）。復國的時機（一戰三強互毆）證明：**亡國的解藥是耐心+強鄰互掐**——123 年等一戰，值了。滅亡史的安慰獎：**地圖上消失不可怕，可怕的是心裡消失**——波蘭心裡沒消失，所以回來了。此案給所有亡國者：**保存語言一百年，強鄰自會打起來**。

## 結案報告

1. **否決即自殺**：一人否決全國——否決權毒性=事項重要性，全票通過是最高癱瘓。
2. **蛋糕定律**：內亂+國際無人管——強鄰切蛋糕，藉口永遠為你好。
3. **交卷關門**：改革對但晚——內容×時機×地緣，缺一即亡。
4. **心不死即不死**：123 年無國有族——保存語言等強鄰互掐，值了。

|------|----------|----------|

| 科技 | 軍事落後（騎兵對火炮） | 代差 |
| 政治 | 三次瓜分 | 地圖抹去 |
| 文化 | 語言文學教會保存 | 123 年後復國 |

**否決權兩案（對照）：**

| 項目 | 波蘭瑟姆 | 安理會 |
|------|----------|--------|
| 規則 | 一人否決 | 五常否決 |
| 標的 | 稅收軍隊（命脈） | 決議（面子） |
| 結果 | 國家癱瘓被分 | 吵架但存活 |
| 定律 | 否決毒性=事項重要性 | 同 |

**瓜分時間表（23 年）：**

```
1772（一瓜，丟三成）→ 1791（憲法，改革）→ 1792（俄入侵）
  → 1793（二瓜）→ 1794（起義敗）→ 1795（三瓜，歸零）。
改革插在兩瓜之間——交卷時考場關門。
```

**結論：** 波蘭案是「制度自殺」的標準樣本：一人否決兩百年、三次被切二十三年、亡國一百二十三年——然後回來了。**否決權的墓誌銘：自由的極致是癱瘓，癱瘓的極致是被分**；而復國的墓誌銘：心不死，地圖遲早重畫。波蘭用123 年證明：**國家可以亡，民族只要不停地說母語，總有一天強鄰會自己打起來**。
