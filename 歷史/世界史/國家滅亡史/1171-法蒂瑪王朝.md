# 1171 法蒂瑪王朝：包稅制掏空與薩拉丁廢黜

## 案發現場

1171 年，埃及維齊爾薩拉丁（庫爾德人，初為贊吉部將）廢黜末代法蒂瑪哈里發阿迪德，改奉阿拔斯，自立阿尤布王朝。法蒂瑪（909–1171，什葉派哈里發，建開羅）享國 262 年，末期：哈里發幼主（嬰兒即位）、維齊爾專權（謝沃爾、希爾庫赫輪替，宮廷請外援引狼）、軍隊欠餉譁變（黑人軍 vs 突厥軍火併）。薩拉丁幾乎沒流血就接管了埃及——因為國庫是空的，軍隊是散的。

> **包稅制如何掏空一個王朝？當稅收被拍賣，中央與地方誰在賺錢——薩拉丁撿的是一個國家，還是一個空殼？**

## 偵查過程

**線索一：包稅制（稅收的拍賣）。** 法蒂瑪晚期行伊克塔（包稅制）：把一地稅收權「封」給將領（換軍役），將領轉包、層層加碼。偵查結論：這是**稅收的批發轉零售**：中央拿固定數（封額），包稅人吃差價（多徵的歸己）——**徵得越多，包稅人越富，中央越窮（封額不變）**。農民被三茬收割（中央稅+包稅人+轉包人）→逃亡→荒地→稅基縮→中央再加封額→惡性循環。**包稅制是財政的興奮劑**：當下有錢（封額到手），長期失血（稅基逃光）。與明三餉（參見本書 [1644-明朝.md](1644-明朝.md)）對照：同樣竭澤而漁——明是中央親自加派（得罪農民），法蒂瑪是外包加派（得罪農民+養肥軍閥）——**外包的比親征的更壞：錢軍閥拿了，罵名中央背了**。

**線索二：軍隊欠餉（黑與突的火併）。** 法蒂瑪軍：黑人步兵（蘇丹奴隸兵）vs 突厥騎兵（東方雇傭）——欠餉時互搶（1060s–70s 內戰，開羅街頭火併，哈里發被迫賣宮藏寶物發餉）。偵查結論：**欠餉的軍隊即土匪**：不發餉，軍隊自己找飯吃（搶首都）。黑突火併（街頭戰爭）摧毀開羅繁華——**首都的軍隊比敵人先動手**。此後哈里發請外援（贊吉的將軍希爾庫赫，含其侄薩拉丁）平亂——**請雇傭兵平雇傭兵**，飲鴆止渴。希爾庫赫死後薩拉丁繼任維齊爾（1169）——**請來的保安，兩年變業主**。法蒂瑪的滅亡程序：欠餉→火併→請外援→被奪權——**每一步都是上一歩的利息**。

**線索三：幼主與權臣（法統的空心化）。** 末代數任哈里發皆幼主（阿迪德 11 歲即位，病弱）——實權在維齊爾（謝沃爾引十字軍、希爾庫赫引贊吉，輪流賣國）。偵查結論：**幼主即印章**：誰控制哈里發，誰的命令合法——謝沃爾、希爾庫赫、薩拉丁輪流蓋章。法統（什葉派哈里發，對抗巴格達遜尼）只剩符號價值——薩拉丁 1171 年改奉阿拔斯（遜尼），**換個招牌，無人抗議**（連什葉派都不反抗，因為哈里發早是傀儡）。**法統的死亡先於肉體**：1171 年廢黜的只是一具法統木乃伊。與清末（溥儀，參見 [../亞洲史/1911-辛亥革命.md](../亞洲史/1911-辛亥革命.md)）對照：**末代幼主+權臣當國=改朝的標準前戲**，古今同款。

**線索四：薩拉丁的接收（無痛接管）。** 1171 年，阿迪德病死（一說被薩拉丁悶死），薩拉丁宣布改宗遜尼、奉阿拔斯——埃及官僚、軍隊、商人照常上班（換個老闆）。偵查結論：這是**企業併購**：法蒂瑪（資不抵債：國庫空、軍隊散、法統死）→薩拉丁（有兵、有錢（敘利亞後方）、有合法性（贊吉授權+阿拔斯認證））**善意收購**（無惡意，無抵抗）。**國家滅亡的最低成本形態：無人反抗**——因為舊政權的既得利益者（官僚、商人）早算過：換老闆比保舊主划算（薩拉丁減稅、整軍、抗十字軍，確實更好）。滅亡史的冷知識：**多數王朝更替無人流血**——流血的是開國（打天下），不是亡國（交接班）。法蒂瑪交接班的平滑度：滿分。

## 結案報告

1. **包稅即失血**：批發轉零售——中央拿固定數，軍閥吃差價，農民被三茬。
2. **欠餉即土匪**：黑突火併→請外援→被奪權——每步都是上一步的利息。
3. **幼主即印章**：法統先死於肉體——廢黜的只是木乃伊。
4. **併購即滅亡**：無人反抗的交接——舊既得利益者算過，換老闆更划算。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 滅亡工程 | 跨域效應 |
|------|----------|----------|
| 法律 | 伊克塔封授 | 稅收批發化 |
| 經濟 | 三茬收割、稅基逃亡 | 財政失血 |
| 科技 | 尼羅河灌溉（荒廢） | 農業退化 |
| 政治 | 幼主+維齊爾輪替 | 法統空心 |
| 文化 | 愛資哈爾（留存） | 機構比王朝長壽 |

**包稅制兩案（對照）：**

| 項目 | 法蒂瑪伊克塔 | 明三餉 |
|------|--------------|--------|
| 執行 | 外包（軍閥） | 中央（官僚） |
| 錢誰拿 | 軍閥 | 中央（部分） |
| 罵名誰背 | 中央 | 中央 |
| 結果 | 養肥奪權者 | 逼反李自成 |

**失血公式（示意）：**

```
中央收入 ＝ 封額（固定）− 逃亡（遞增）。
包稅人收入 ＝ 實徵 − 封額（遞增）。
農民：被三茬 → 逃亡 → 稅基縮 → 封額加 → 更逃。
薩拉丁：等血流乾，進場收購。
```

**結論：** 法蒂瑪案是「財政失血亡國」的標準樣本：包稅外包、欠餉火併、幼主蓋章、併購收場——262 年王朝，無痛交接。**最便宜的滅亡是不用打仗的滅亡**——薩拉丁一分錢軍費沒花（用的還是法蒂瑪的國庫），就換了招牌。包稅制的墓誌銘：把稅收外包出去的人，最後連國家一起被外包了。
