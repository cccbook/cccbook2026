# 0067 白馬寺與佛教入華：一場跨越語言的譯經工程

## 案發現場

公元 67 年，漢明帝夜夢金人，遣使西行求法。使者在西域遇到印度僧侶**攝摩騰、竺法蘭**，兩人以白馬馱佛像經典抵達洛陽——朝廷建寺安置，即**白馬寺**（中國第一座官辦佛寺），並在寺中譯出《四十二章經》。

朝廷面對的核心難題：一個來自印度、有完整哲學體系與跨國僧團組織的宗教，要進入一個由儒家官僚與道家信仰構成的帝國——**語言不通、概念不對應、制度格格不入**。這不是翻譯一本書，是安裝一套外來作業系統。

> **一個外來宗教如何被翻譯成本地產品？用道家詞彙講佛理，會失真還是獲勝？當跨國僧團遇上官僚帝國，摩擦如何解決？**

## 偵查過程

**線索一：語言轉換的資訊成本。** 譯經是古代最大規模的**跨語言資訊工程**：梵文佛典的概念（空、業、輪迴、涅槃）在漢語中沒有對應詞。早期譯經靠外國僧侶口述、漢人筆受——中間每一層轉換都損耗資訊。用經濟學語言：**翻譯=降低跨文化交易的資訊成本，但翻譯本身有成本**；譯得越多，體系越完整，接收成本越低——這是一筆巨大的前置投資，回報在數百年後（鳩摩羅什、玄奘的成熟譯場）。

**線索二：格義（本案的關鍵手法）。** 早期譯經用**道家詞彙翻譯佛教概念**：以「無為」譯「涅槃」、以「道」譯「菩提」、以「本無」譯「空」——即「格義」。這是失真與獲勝的兩面刃：

```
梵文概念 ──(格義：借道家詞彙)──> 漢語理解
   失真：概念被誤讀為玄學
   獲勝：陌生概念獲得本地接口，得以存活
```

偵查結論：**外來思想的存活策略是先搭本地概念的便車**——先進門，再慢慢修正。佛教借道家的「殼」登陸，數百年後反過來影響道家（六朝玄學佛化），這是一場成功的本地化策略。

**線索三：宗教的市場分析（佛道儒三方競合）。** 把漢代思想界看作一個市場：儒家壟斷官學（考試與做官的通道），道家佔據民間信仰與養生，佛教是**新進入者**，尋找市場空隙。它的差異化產品：儒家不管**死後**（「未知生，焉知死」），道家修仙貴己，佛教提供了完整的**輪迴、因果、報應體系**——個體命運的解釋權。三方競合的結果：佛教填補了「生死解釋」的空白市場，同時借儒家的倫理（孝、報恩）與道家的語言降低敵意。

**線索四：僧團=跨國組織的制度摩擦。** 佛教僧團是一個**跨國的、出世間的組織**：剃度出家（脫離家族）、不事生產（靠布施）、不拜皇帝（「沙門不敬王者」）——每一條都與官僚帝國的邏輯衝突：戶籍要人、賦稅要丁、忠孝要禮。摩擦的解法是長期談判：朝廷控制度牒（出家許可證=人頭管制）、寺廟納入管理、僧人也講「護國」。用組織理論：**外來制度要進入帝國，必須交出部分主權換取生存空間**。

**線索五：路徑的偵查（佛教為何能進來）。** 白馬寺的兩位僧侶能抵洛陽，前提是絲路已通——張騫鑿空（[-0126-張騫鑿空.md](-0126-張騫鑿空.md)）開的路，一百年後開始搭載思想。貿易網的第一批「非商品貨物」就是宗教。而佛教在華的完整哲學基礎，遠溯至釋迦牟尼的原始教義（參見 [../../宗教史/-0563-釋迦牟尼佛教.md](../../宗教史/-0563-釋迦牟尼佛教.md)）。

## 結案報告

1. **譯經=資訊工程**：語言轉換有真實成本，格義是「先進門再修正」的本地化策略——外來思想的存活靠搭本地概念的便車。
2. **市場空隙策略**：佛教以「生死解釋權」切入儒道不管的地帶，用差異化產品而非正面競爭打開市場。
3. **制度摩擦的解法**：跨國僧團與官僚帝國的衝突，以「交出部分控制權（度牒、護國）換生存空間」長期化解。
4. **偵探教訓**：外來文化進入一個帝國，看三件事——翻譯接口、市場空隙、與官僚體系的談判籌碼；三者齊備才能生根。

| 項目 | 儒家 | 道家 | 佛教（新進入者） |

**格義示意（借殼登陸）：**

```
涅槃 ──譯作──> 無為（道家詞）
菩提 ──譯作──> 道
空   ──譯作──> 本無
     ↓ 數百年後
譯場成熟（鳩摩羅什/玄奘）──> 概念歸位、體系完整
```

**結論：** 白馬寺案證明：**外來思想的移植=翻譯接口+市場空隙+制度談判**三件套。佛教先用道家的詞登陸、再用品質（哲學體系）站穩、最後與帝國達成共存協議——這條路線，兩百年後的基督教在羅馬走過，六百年後伊斯蘭在中亞也將走過。
