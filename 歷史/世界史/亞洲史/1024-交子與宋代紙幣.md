# 1024 交子問世：世界最早的紙幣為何誕生在四川

## 案發現場

1024 年（北宋天聖元年），益州（成都）設「益州交子務」，官辦交子正式發行——這是人類第一次由政府發行流通紙幣。此時距吳哥王朝建立（參見本書 [0802-吳哥王朝.md](0802-吳哥王朝.md)）兩百年，距鎌倉幕府（1192）還有一百七十年——這段長期空檔裡，亞洲真正的革命發生在宋代的市場與印鈔機上。

> **鐵錢重到要車載，逼出了紙幣——但為何政府一接手，紙幣就開始貶值？交子是金融發明，還是財政毒品？**

## 偵查過程

**線索一：鐵錢的重量（貨幣的物理學瓶頸）。** 四川行鐵錢：買一匹布要付兩萬文，重約百斤，商人交易「以車載錢」。偵查結論：貨幣的形態由**交易成本**決定——當錢本身重到妨礙交易，市場就會自己發明替代品。十六家富商聯合發行私交子：存鐵錢換交子，憑票兌現，票面蓋印、隱記題號。這是市場自發的**信用憑證**，類似後世的銀行券。

**線索二：兌付危機與國有化（私營的失敗與收編）。** 私交子很快出事：富商挪用準備金、偽鈔出現、兌付糾紛引發訴訟。1023 年官府收編：設交子務，交子改為官發，分界發行（兩年一界）、定額（每界 125 萬餘緡）、備本錢（準備金約 28 萬緡，準備率約 22%）。偵查結論：私營貨幣的死亡原因是**沒有監管的信用**——發鈔者同時是資金的使用者，擠兌必然發生。官辦方案抓住了三件事：分界（定期回收）、定額（限量）、備本（準備金）——這就是現代央行三大工具的雛形。

**線索三：準備率的滑落（財政的誘惑）。** 起初守規矩，但西北用兵（對西夏）、財政吃緊，朝廷開始超發：無本錢空券進入流通，「界以濫惡，人不受用」。至南宋，四川錢引（交子改稱）發行額膨脹至面額的數十倍，貶值一瀉千里。偵查結論：這是一條經典的**通脹因果鏈**——

$$\text{戰爭支出} \uparrow \Rightarrow \text{超發交子} \Rightarrow \text{貶值} \Rightarrow \text{稅收實值下降} \Rightarrow \text{更需要超發}$$

政府既是貨幣的發行者又是最大的支出者，**裁判下場踢球**——交子的悲劇不是技術失敗，是治理失敗。六百年後蒙古人發行交鈔（參見本書 [1260-蒙古驛站與交鈔.md](1260-蒙古驛站與交鈔.md)），把同樣的劇本重演得更猛。

**線索四：為何是四川、為何是宋代（環境偵查）。** 三個條件同時成立：四川用鐵錢（重！改革壓力最大）；雕版印刷成熟（偽鈔防偽與批量印製可行）；宋代商業革命（市坊制瓦解、契約發達、信用觀念普及）。偵查結論：紙幣不是靈光一閃，是**印刷術 × 商業密度 × 貨幣痛點**三因素的交點。此後宋代還有會子、關子——一個帝國同時運行銅錢、鐵錢、紙幣的多軌系統，正是商業深度超前於金屬供給的證據。

## 結案報告

1. **交易成本論**：錢太重，市場自會造票——私交子是商人的自救。
2. **三大工具的雛形**：分界、定額、備本——1024 年的官辦方案就是央行制度的草稿。
3. **裁判下場論**：發鈔者同時是支出者，超發必然——紙幣之死死在財政，不死在技術。
4. **三因素交點**：印刷術 × 商業密度 × 貨幣痛點——發明落地的必要條件清單。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 交子工程 | 跨域效應 |
|------|----------|----------|
| 經濟 | 紙幣流通、信用票據 | 商業半徑擴大、鹽茶鈔引制度 |
| 科技 | 雕版印刷防偽 | 印刷術的貨幣應用 |
| 財政 | 超發救戰費 | 通脹—貶值—更超發的迴路 |
| 法律 | 偽鈔律、分界法規 | 貨幣法的最早實踐 |
| 世界史 | 交鈔—馬可波羅記述 | 歐洲紙幣觀念的遠因 |

**交子興衰時間軸（示意）：**

```
私鋪交子（信用票）→ 兌付危機 → 1024 官辦（分界·定額·備本）
  → 西北用兵 → 超發 → 貶值 → 更超發 → 錢引濫惡
制度草稿是對的，執行它的政府不守稿。
```

**結論：** 交子案是「制度發明早於治理能力」的教科書：人類在 1024 年就寫出了央行三大工具，卻在每一次戰爭帳單面前親手作廢。它填補的正是 0802 與 1192 之間的時代空檔——這兩百年亞洲最深刻的變化不在戰場，在帳房。**紙幣考驗的不是印鈔機，是政府的自制力**——這道考題，此後每個發鈔政權都要重考，且多數不及格。
