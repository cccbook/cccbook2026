# -0221 秦始皇統一：把戰國裝進一個盒子

## 案件摘要

前 221 年，秦王嬴政滅齊，完成十年統一戰爭（韓前 230、趙前 228、魏前 225、楚前 223、燕前 222、齊前 221）——**中國第一次政治統一**。此前：阿育王前 261 羯陵伽（參見 [-0261-阿育王.md](-0261-阿育王.md)）用佛教縫合印度；此後：前 126 張騫鑿空（參見 [-0126-張騫鑿空.md](-0126-張騫鑿空.md)）的漢帝國，直接繼承的正是秦的郡縣、馳道與文字。這樁案件要回答：**為何是秦？統一的盒子裡裝了什麼，讓漢接得住、後世拆不掉？**

## 前因 -- 多因素的局勢

- **商鞅**：耕戰體系（編戶、軍功爵、連坐）——**動員機器的發明**（→秦卒源源不絕）。
- **地緣**：關中盆地（崤函之固）＋巴蜀糧倉（都江堰前 256）——**進可攻退可守的根據地**。
- **六國**：合縱屢敗（各懷鬼胎、搭便車）——**集體行動的失敗**。
- **技術**：鐵器＋弩（標準化量產）——**武器代差的量產化**。

## 線索與推理 -- 因素咬合

### 線索一：耕戰機器——「把農民變成士兵」

商鞅變法（前 356）把人口編戶齊民、按軍功授田授爵：

$$\text{秦軍力} = \text{（編戶人口基數）} \times \text{（軍功激勵係數）} - \text{（貴族分肥損耗）}$$

六國貴族分封吃掉剩餘，秦把剩餘全部變成箭頭。**統一不是嬴政的天才，是商鞅的複利**——一百三十年的制度複利，一次兌現。

### 線索二：遠交近攻——「一個一個吃」

范雎獻策遠交近攻，秦逐一滅國、每次消化一塊（設郡、徙豪）：

| 滅國順序 | 年份 | 手法 |
|---|---|---|
| 韓 | 前 230 | 誘捕韓王安 |
| 趙 | 前 228 | 反間殺李牧 |
| 魏 | 前 225 | 水灌大梁 |
| 楚 | 前 223 | 王翦六十萬眾 |
| 燕齊 | 前 222–221 | 傳檄而定 |

$$\text{統一} = \text{（各個擊破）} \times \text{（即滅即郡縣化）} \Rightarrow \text{無復國據點}$$

### 線索三：盒子的三件套——「書同文、車同軌、行同倫」

統一後三年（前 221–前 219）：郡縣制（36 郡）、馳道、統一度量衡、焚書（李斯議）——**資訊標準化工程**（呼應本卷 [-1754-漢摩拉比法典.md](-1754-漢摩拉比法典.md)的公開法邏輯）：

$$\text{大一統} = \text{（郡縣：人事直達）} \times \text{（文字：資訊直達）} \times \text{（馳道：軍隊直達）}$$

## 破案時刻

- 前 230–前 221：十一年六滅國——動員＋外交的兌現。
- 前 221：稱皇帝（朕、詔、璽）——**新權力語法的發明**。
- 前 220–前 214：馳道、直道、長城、靈渠——**帝國的硬體布線**。
- 前 210：始皇死、沙丘之變——**繼承制的定時炸彈**（二世而亡的伏筆）。

## 後果 -- 改變了什麼

- **制度**：郡縣＋皇帝成為兩千年標配（→漢承秦制、張騫的西域都護府才有中央可回報）。
- **文化**：小篆統一文字——**僧團譯經（參見 [0067-白馬寺與佛教入華.md](0067-白馬寺與佛教入華.md)）兩百年後能全國流通的前提**。
- **代價**：焚書坑儒、嚴刑峻法——**第一個「發明者落後」樣本**（速統速亡）。
- **世界**：與阿育王印度、羅馬共和國並立——**歐亞三大統一實驗的東方案**。

## 因素影響筆記

```
商鞅編戶（動員！）×關中巴蜀（糧！）──→ 十年滅六國
遠交近攻（外交！）×即滅即郡（消化！）──→ 無復國
書同文＋車同軌＋郡縣（標準化！）──→ 漢接得住的大一統
```

**偵探結語**：秦案是「複利兌現案」：**商鞅存錢，嬴政取錢**——取出來不是金銀，是郡縣、馳道與統一文字的三件套。盒子裝好了，漢（前 202）直接拎走；裝得太滿太緊，秦自己被勒死。**統一最難的不是打下來，是讓下一代拆不掉**——秦做到了，所以它是始皇帝。
