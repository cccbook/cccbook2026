# 亞洲史的歷史年表（推理探案）

> 亞洲史是各文明互相塑造的偵探史：漢摩拉比為何要把法律刻在石柱上？秦的資訊系統如何接上絲路的商業網絡？一位法師的隨葬佛經如何讓佛教穿越中亞進入中國？一場安史之亂如何同時改寫中國、中亞與東南亞的命運？蒙古的驛站為何是帝國的作業系統？鐵炮與黑船如何逼出明治維新？印巴分治的悲劇為何寫在「兩岸制度分岔」的密碼裡？
>
> 本書以「推理探案」的方式，為每個歷史事件寫一篇 wiki，包含前因後果、學術理論與跨領域影響矩陣。每篇檔名以年份開頭（西元前以負號表示，四碼不足補零）。
>
> 本書的核心命題：**亞洲各文明不是平行條列，而是由資訊、商路、宗教與帝國機器互相驅動的系統**——每篇 wiki 都以「跨領域影響矩陣」拆解政治、經濟、科技、文化與法律的互動。

## 閱讀路線（偵探式提問）

- **資訊與制度線**：漢摩拉比石柱（-1754）→ 周封建（-1046）→ 張騫鑿空（-0126）→ 大化改新（0646）→ 尼布楚條約（1689）——統治的成敗寫在資訊基礎設施裡。
- **商路線**：絲路（-0126）→ 怛羅斯（0751）→ 君士坦丁堡（1453）→ 鄭和（1405）→ 普拉西（1757）→ RCEP（2020）——貿易路線的每一次改道都改寫帝國的命運。
- **技術轉移線**：造紙西傳（0751）→ 鐵炮傳入（1543）→ 黑船（1853）——技術的擴散速度決定權力的重新分配。
- **宗教網絡線**：佛陀（-0563）→ 阿育王（-0261）→ 白馬寺（0067）→ 玄奘西行（0629）——僧團是古代最強的跨國資訊網絡。
- **現代化對決線**：明治維新（1868）→ 甲午（1894）→ 日俄（1905）→ 辛亥（1911）——同樣的衝擊，不同的制度回應，不同的結局。
- **戰爭與去殖民線**：普拉西（1757）→ 馬戛爾尼（1793）→ 盧溝橋（1937）→ 太平洋戰爭終結（1945）→ 印巴分治（1947）——帝國的擴張、失敗與關門是一條完整的帳本。
