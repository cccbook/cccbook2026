# 1793-馬戛爾尼使節：兩套世界觀的一次照面

## 案件摘要

1793 年，英國派出馬戛爾尼勳爵率 700 人使團訪華，攜天文儀器、蒸汽機模型與毛瑟槍，請求開放口岸、設使館、減免關稅。乾隆以「天朝物產豐盈，無所不有」回絕全部請求。本案追查：這次「禮儀衝突」為何被史家視為兩個世界體系的錯身——以及五十年後鴉片戰爭（1839）的預告片？

## 前因

- **經濟**：英中貿易嚴重逆差——英國年進口茶葉 1,800 萬磅，白銀源源東流；唯一能換的合法商品是有限的毛織品。東印度公司（1600 案）急需「以物易銀」之外的解法。
- **政治**：英國在 1784《緩解法案》後由政府接管印度——需要一個新市場平衡殖民虧損；使團副手斯當東正是廣州商館的老手。
- **制度**：清廷的朝貢體系只有「藩屬入貢」一種外交格式，不存在對等使節的檔案欄位。
- **心理**：乾隆朝的盛世自信（人口破三億、十全武功）；英國則剛經歷工業革命的產能焦慮——兩國各自理性，各自錯位。

## 線索與推理

### 線索一：禮儀不是禮儀，是主權的介面

$$\text{外交格式} = \text{政治體系的介面規格}$$

磕頭（koutou）之爭的實質：朝貢體系以儀式確認等級（天下觀），西發利亞體系以對等主權確認平級（條約觀）。馬戛爾尼拒絕行三跪九叩，乾隆把他降格為「貢使」——**不是雙方傲慢，而是兩套介面無法握手**。協議告吹的成本當時趨近於零：茶照買、銀照付。問題在於介面不相容會累積技術債。

### 線索二：技術展示為何被讀成「貢品」

使團刻意展示天文儀器與武器模型以證明英國先進；清方檔案卻將其登記為「貢物」，最大的塑膠地球儀得「恭設殿中」。情報轉譯失敗的三層：語言（傳譯迴避敏感詞）、制度（無常駐使館→無資訊管道）、心理（盛世濾鏡）。對照：55 年後黑船來航（1853 案）時，日本蘭學者能讀懂蒸汽艦的意義——**資訊基礎設施的差異決定了危機的反應速度**。

### 線索三：使節的「報告書」如何反過來塑造侵略

馬戛爾尼返程後的判斷：「中華帝國是一艘破舊的頭等戰艦」；副手斯當東（小斯當東，當年唯一會中文的隨員）1839 年在英國下議院力主開戰。線索鏈：

| 年份 | 事件 | 作用 |
|---|---|---|
| 1793 | 使節失敗 | 建立對清的實地情報 |
| 1816 | 阿美士德使團再敗 | 確認介面不相容 |
| 1834 | 律勞卑事件 | 貿易體系衝突升高 |
| 1839 | 鴉片戰爭 | 用炮艦重寫介面 |

**和平的介面談判失敗 → 戰爭成為「翻譯」手段**——這是砲艦外交的制度成因。

## 破案時刻

破案點在使團離開時交換的兩份文書：乾隆致喬治三世的敕諭（「毋庸遠勞心計」）與馬戛爾尼報告書（「破船」比喻）。兩份檔案各自成立、互相矛盾——**真相是兩國各自正確地執行了各自的體系邏輯**。歷史的悲劇不在誤解，在於兩個都自洽的系統不共軛。

## 後果

- **貿易**：白銀逆差未解 → 東印度公司以鴉片平衡帳目 → 白銀外流倒灌中國（1839 案的直接前因）。
- **情報**：英國對華作戰評估基本沿用使團報告——「領航員與測量」成為鴉片戰爭的軍事底圖。
- **清朝**：盛世敘事未受挑戰，內部腐化（和珅案 1799）繼續積累——錯過的是「預警」而非「戰敗」。
- **觀念史**：這次錯身成為「衝擊—回應」論與加州學派（彭慕蘭《大分流》）爭論的標本：是外衝擊打斷了清朝，還是內生路徑本就不同？

## 因素影響筆記

- 介面不相容 → 1839 鴉片戰爭 → 1858 條約體系（對等使節終於以武力取得）。
- 情報差異對照：清（無翻譯機構）vs 日本（蘭學 1774、北學派 1780）→ 1868 明治維新 vs 清朝自強運動的成敗分岔。
- 白銀與鴉片 → 1581 一條鞭法的白銀依賴被反噬——全球經濟早已串聯的證據。
