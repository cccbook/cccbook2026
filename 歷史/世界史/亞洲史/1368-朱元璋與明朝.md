# 1368 朱元璋與明朝：從乞丐到皇帝的組織重建

## 案發現場

1368 年，出身貧農、當過乞丐與和尚的朱元璋稱帝建明，定都南京。他接手的是一個被蒙古統治近百年、官僚體系斷裂的中國。他面對的難題：**如何從零重建一台統治機器的硬體（軍隊、戶籍、稅收），同時確保這台機器永遠不再失控？**

> **一個沒有官僚背景的皇帝，如何設計制度？衛所、里甲、廢丞相與海禁——朱元璋的每一項設計都在防範什麼？**

## 偵查過程

**線索一：衛所軍戶制（自給自足軍隊的財政實驗）。** 朱元璋設衛所，軍戶世襲、屯田自給——理論上軍隊不花國庫一文錢。偵查結論：這是**把國防成本轉嫁給軍戶家庭**的設計——用身份世襲制鎖定兵源，用屯田鎖定給養。短期有效（明初軍隊龐大而廉價），長期腐蝕（軍官侵占屯田→逃亡→戰鬥力崩壞，土木堡之變即其後果）。**免費的軍隊最貴——代價是戰鬥力**。

**線索二：里甲與黃冊（戶籍資訊系統的重建）。** 朱元璋編黃冊（戶口）、魚鱗圖冊（土地），行里甲制（110 戶一里，輪流當差）。偵查結論：這是秦「上計」的明代版本（參見 [../世界發展史/-0221-秦統一.md](../世界發展史/-0221-秦統一.md)）——**國家直接掌握每一戶的人口與土地資訊**，賦役徵發直達基層。代價是把農民釘死在土地上（路引管制流動）——**資訊完備性以犧牲流動性為代價**。

**線索三：廢丞相（代理問題的極端解法）。** 胡惟庸案後廢丞相，六部直屬皇帝——朱元璋每天親批奏章。偵查結論：這是對「權臣篡位」風險的**過度修正**——把代理層整個砍掉，皇帝直連六部。短期集權，長期透支（後世皇帝不得不靠宦官與內閣——新的代理人）。**砍掉代理層不會消滅代理問題，只會把它轉移到更暗處**（宦官專權、廠衛）。

**線索四：海禁（貿易管制的第一次全國實驗）。** 朱元璋禁私人海貿，僅許朝貢貿易。動機：防倭寇、防張士誠餘黨勾結海外。偵查結論：**管制的初衷是安全，後果是走私產業化**——合法貿易歸零，需求仍在，走私集團武裝化（後期的「倭寇」多為中國海商），緝私成本飆升。海禁證明了**禁令經濟學**：需求不滅，禁止只會把利潤讓給黑市。鄭和下西洋（參見本書 [1405-鄭和下西洋.md](1405-鄭和下西洋.md)）恰是同一邏輯的反面——國家壟斷海洋。

## 結案報告

1. **重建的三件套**：衛所（暴力）+里甲黃冊（資訊）+廢丞相（集權）——朱元璋用身份鎖定與資訊直達重建了帝國機器。
2. **過度修正的代價**：廢丞相防權臣，卻養出宦官；海禁防倭寇，卻養出走私——**防範措施常常製造它要防範的東西**。
3. **體制的壽命**：明清兩代沿用這套架構近五百年——**低流動性+高控制=超長待機，但以犧牲適應力為代價**。
4. **偵探教訓**：讀朱元璋的制度，先問「他在怕什麼」——**每條制度都是恐懼的形狀**：怕軍閥（衛所）、怕流民（里甲）、怕權臣（廢相）、怕海盜（海禁）。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 帝國工程 | 跨域效應 |
|------|----------|----------|
| 法律 | 《大明律》、廢丞相 | 皇權直達、代理轉暗 |
| 經濟 | 里甲賦役、海禁 | 農民釘死、走私產業化 |
| 科技 | 黃冊魚鱗冊、屯田 | 戶籍資訊完備 |
| 政治 | 衛所、廠衛 | 軍戶腐蝕、特務政治 |
| 文化 | 八股取士、程朱理學定一尊 | 思想控制配套 |

**明初設計 vs 長期後果（對照）：**

| 設計 | 初衷 | 長期後果 |
|------|------|----------|
| 衛所屯田 | 軍隊免費 | 軍戶逃亡、戰力崩壞 |
| 里甲黃冊 | 資訊直達 | 釘死流動、里甲崩壞 |
| 廢丞相 | 防權臣 | 宦官內閣填補真空 |
| 海禁 | 防倭防奸 | 走私武裝化 |

**恐懼—制度映射（示意）：**

```
怕軍閥 ──> 衛所（兵源鎖定）
怕流民 ──> 里甲+路引（流動鎖定）
怕權臣 ──> 廢丞相（代理層刪除）
怕海盜 ──> 海禁（海洋關閉）
每條制度 = 一種恐懼的工程化。
```

**結論：** 朱元璋案是「從零重建帝國」的完整實驗：用身份與資訊把社會釘住，用集權把代理風險歸零——代價是適應力。**控制力與適應力不可兼得**——明朝選了前者，撐了五百年，也為鴉片戰爭（參見本書 [1839-鴉片戰爭.md](1839-鴉片戰爭.md)）時的僵硬埋下伏筆。
