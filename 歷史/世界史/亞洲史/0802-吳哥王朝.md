# 0802 吳哥王朝：水利帝國的興衰

## 案發現場

802 年，闍耶跋摩二世在荔枝山宣布獨立於爪哇，自稱「宇宙之王」（devaraja），高棉帝國開場。此後六百年，吳哥城崛起為世界最大城市之一（鼎盛期人口或達百萬），留下吳哥窟——人類史上最大的宗教建築群。1431 年暹羅攻陷吳哥，帝國落幕。

> **沒有大河、沒有鐵器優勢的高棉，如何養活百萬人口的都城？支撐吳哥的水利機器，又為何最終反噬了自己？**

## 偵查過程

**線索一：洞里薩湖（自然的水庫）。** 洞里薩湖隨湄公河季節漲落——雨季面積膨脹數倍，帶來魚群與淤泥。吳哥工程師的解法：在湖畔與都城間修建**巨型水庫（baray）與運河網**，把季節性的水存起來、按需分配。偵查結論：這是**把自然波動熨平的工程**——水庫=電池，運河=電網，稻田=用電戶。一年三熟的水稻養活了百萬人口與龐大的營建勞力——**水利即國力**。

**線索二：神王信仰（動員的軟體）。** 國王自稱宇宙之王，吳哥窟即宇宙的微縮模型（須彌山+乳海）。偵查結論：大型水利工程需要**跨越村社的集體動員**——誰有權徵發數萬勞力挖水庫？神王信仰把勞役包裝成宇宙秩序的一部分，**把稅收成本轉化為宗教義務**。與阿育王的「法」（參見本書 [-0261-阿育王.md](-0261-阿育王.md)）同理：**意識形態是大型工程的潤滑劑**。

**線索三：海上絲路的紅利。** 吳哥的興起恰逢陸上絲路衰落、海上貿易興起（參見本書 [0755-安史之亂.md](0755-安史之亂.md)）——扶南、真臘、室利佛逝相繼在這條商路上收過路費。偵查結論：吳哥的財富不只來自稻米，還來自**港口與中轉貿易的關稅**。水利養活人口，貿易養活王室——**雙引擎結構**，缺一即跛。

**線索四：系統的脆弱性（氣候與維護）。** 近年樹輪與沉積物研究指向 14–15 世紀的**長期乾旱與極端季風交替**——水庫淤積、運河失效；同時泰族南下、貿易路線改道。偵查結論：水利帝國的致命弱點是**固定成本剛性**——水庫與寺廟要持續維護，一旦財政（貿易+農業）下滑，維護中斷→系統退化→產出再降，形成**死亡螺旋**。吳哥不是被一場戰爭打垮的，是被**維護不起自己的基礎設施**拖垮的。

## 結案報告

1. **水利=國力公式**：水庫+運河把季節波動變成穩定產出——**控制水的人控制人口，控制人口的人控制帝國**。
2. **神王的動員術**：宇宙之王信仰=大型工程的合法性外包——意識形態降低徵發成本。
3. **雙引擎結構**：稻米（內）+海貿關稅（外）——任一引擎熄火，帝國即進入死亡螺旋。
4. **基礎設施的詛咒**：最強大的系統往往維護成本最高——**建得起、養不起，是所有巨型工程的共同墓誌銘**；吳哥窟留存至今，恰因石頭不需要維護預算。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 帝國工程 | 跨域效應 |
|------|----------|----------|
| 法律 | 神王制、勞役動員 | 徵發成本宗教化 |
| 經濟 | 三熟稻+海貿關稅 | 雙引擎財政 |
| 科技 | baray 水庫、運河網 | 波動熨平、產出穩定 |
| 政治 | 高棉帝國、中南半島霸權 | 泰族興起後易位 |
| 文化 | 吳哥窟、印度教→佛教 | 石造宇宙模型 |

**興起 vs 衰落（系統狀態對照）：**

| 項目 | 鼎盛期（12 世紀） | 衰落期（14–15 世紀） |
|------|------------------|----------------------|
| 氣候 | 季風穩定 | 久旱+暴雨交替 |
| 水利 | 擴建+維護 | 淤積+失效 |
| 貿易 | 海路紅利 | 路線改道 |
| 鄰國 | 高棉霸權 | 泰族崛起、暹羅攻陷 |
| 維護 | 財政充裕 | 死亡螺旋 |

**死亡螺旋（示意）：**

```
氣候異常 → 產出降 → 財政緊 → 維護停 → 水利退化 → 產出再降 → …
              ↑                                              │
              └──────────── 惡性循環 ─────────────────────────┘
```

**結論：** 吳哥案是「水利帝國」的完整生命週期：用水庫馴服季風、用神王動員勞力、用海貿補貼王室——再因氣候波動與維護剛性墜入死亡螺旋。**帝國的壽命=基礎設施可維護的年限**——這條公式從吳哥的水庫到今日的每一座大壩都適用。
