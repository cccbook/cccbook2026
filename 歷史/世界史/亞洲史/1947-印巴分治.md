# 1947 印巴分治：一條拉德克利夫線的悲劇

## 案發現場

1947 年 8 月，英屬印度一分為二——印度與巴基斯坦（東西兩翼）。邊界由拉德克利夫在六週內劃定，公布時兩國已獨立。隨後約 1,400 萬人跨境遷徙，數十萬至百萬人死於教派屠殺。人類史上最大規模的人口遷移，伴隨著最慘烈的分娩陣痛。

> **為何獨立非要分治？一條六週劃出的線，如何製造了千萬人的流離——是宗教的必然，還是政治的計算？**

## 偵查過程

**線索一：兩國論（宗教=民族=國家的命題）。** 真納主張穆斯林與印度教徒是兩個民族，需各自建國；國大黨主張統一世俗印度。偵查結論：這場爭論的核心是**身份的政治化**——英屬印度的人口普查（參見本書 [1858-英屬印度.md](1858-英屬印度.md)）早已把宗教變成官方分類，選舉的教派保留席次讓宗教成為選票單位。**殖民統計先製造了類別，政客再把類別變成國家**——兩國論是九十年分類治理的邏輯終點，不是伊斯蘭教的內在要求（多數穆斯林此前並未要求分治）。

**線索二：拉德克利夫線（資訊不足下的隨機性）。** 從未到過印度的律師拉德克利夫，用過時地圖與人口數據，六週劃完邊界——旁遮普與孟加拉被攔腰切斷，村莊、農田、運河一分為二。偵查結論：這是**劃界的信息災難**——決策所需的資訊（村級宗教混居圖、水利系統、交通線）根本不存在，劃線者只能按縣級粗數據切割。**邊界的精度=資訊的精度**，資訊為零時，邊界即隨機——而隨機的線穿過的是活生生的人。克什米爾（土邦王公印度教、百姓穆斯林）的懸置，正是這場隨機的餘波，至今引發三次戰爭。

**線索三：人口大遷徙（恐懼的自我實現）。** 邊界一公布，少數教派社群恐慌性遷移——火車載滿屍體抵達車站（「血色列車」）。偵查結論：遷徙的驅動力不是邊界本身，是**對未來的預期**——每個人都預期「留下來會被殺」，於是逃跑；大規模逃跑掏空混居社區，留下的人更脆弱，暴力升級，預期自我實現。這是**恐慌級聯**（information cascade）的教科書案例：**不需要真的危險，只需要人人都相信危險**。

**線索四：制度分岔的代價（統一 vs 分治的成本）。** 分治後印巴三次戰爭、軍備競賽、克什米爾凍結；東巴 1971 年再獨立為孟加拉——兩國論連穆斯林內部都統一不了。偵查結論：分治解決了「誰統治」的問題，製造了「如何共存」的永久問題。對照統一多族群國家的成本（協商、聯邦、保留席）——**分治是把內部矛盾外部化**：國內的教派衝突變成國與國的戰爭。外部化的矛盾更貴（軍隊對峙七十年），因為**國家間沒有憲法法院，只有邊境部隊**。

## 結案報告

1. **分類先於分裂**：殖民普查製造宗教類別，選舉將其變成選票——兩國論是分類治理的終點，不是宗教的必然。
2. **無資訊的劃界即隨機**：六週、過時地圖、粗數據——邊界的精度等於資訊的精度，隨機的線切開活人的生活。
3. **恐慌自我實現**：血色列車源於預期而非現實——級聯恐慌不需要真危險，只需要共同相信。
4. **分治是最貴的解法**：內部矛盾外部化→三次戰爭→七十年對峙——**把問題推出國界，代價是問題穿上軍裝**。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 分治工程 | 跨域效應 |
|------|----------|----------|
| 法律 | 印度獨立法、拉德克利夫線 | 主權切割、土邦歸屬難題 |
| 經濟 | 運河鐵路切斷、難民潮 | 旁遮普水利爭端、安置成本 |
| 科技 | 粗糙地圖、人口數據 | 劃界精度災難 |
| 政治 | 兩國論、國大黨—穆盟對立 | 三次戰爭、克什米爾凍結 |
| 文化 | 教派身份固化 | 混居傳統斷裂 |

**統一 vs 分治（成本對照）：**

| 項目 | 統一聯邦方案 | 分治方案 |
|------|--------------|----------|
| 矛盾位置 | 國內（憲法處理） | 國界（軍隊處理） |
| 解決機制 | 法院、選舉、協商 | 戰爭、對峙 |
| 難民 | 無 | 1,400 萬 |
| 長期成本 | 政治摩擦 | 軍備競賽七十年 |
| 完整性 | 旁遮普孟加拉完整 | 攔腰切斷 |

**恐慌級聯（示意）：**

```
邊界公布 → 少數群體預期危險 → 先行者逃離
  → 混居社區掏空 → 留守者更脆弱 → 暴力事件
  → 驗證預期 → 更大規模逃離 → 血色列車。
```

**結論：** 分治案是「分類—劃界—恐慌」的三級災難：殖民統計製造類別，六週劃界製造隨機，預期級聯製造屍體。**最貴的分手費不是財產，是把鄰居變成敵國**——拉德克利夫用六週畫的線，南亞用了七十年還沒走出來。
