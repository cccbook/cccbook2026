# -0321 孔雀帝國：印度的第一次政治統一

## 案發現場

約公元前 321 年，旃陀羅笈多推翻難陀王朝，在華氏城建都，之後擊退塞琉古帝國，將印度次大陸大部納入同一個政權——**印度史上第一次政治統一**。他背後的謀士考底利亞留下《政事論》，一本比馬基維利早一千八百年的「治國手冊」。

> **一個幅員相當於歐洲的次大陸，如何用一台中央機器統治？間諜、稅收與官僚——《政事論》裡藏著什麼樣的統治工程？**

## 偵查過程

**線索一：曼陀羅理論（鄰國皆潛在敵人）。** 《政事論》的外交模型叫「曼陀羅」（mandala，同心圓）：**你的鄰國是天生的敵人，鄰國的鄰國是天生的朋友**。偵查結論：這是一套**同盟的數學**——結盟對象不看感情，看地理位置的函數。王的外交只有六種動作（和、戰、中立、遠征、求援、雙重），像一台有限狀態機。這套理論解釋了旃陀羅笈多為何先聯姻塞琉古、再穩定西北邊境：**把敵人變成邊界，把邊界變成稅收線**。

**線索二：間諜系統（國家的眼睛）。** 《政事論》用大篇幅講間諜：偽裝成僧人、商人、農夫的密探遍布全國，互相監視、直接向王報告。偵查結論：這是**資訊不對稱的武器化**——在沒有電報的時代，統治大帝國的瓶頸是「中央不知道地方在幹什麼」。孔雀王朝的解法與秦的上計制度異曲同工（參見 [../世界發展史/-0221-秦統一.md](../世界發展史/-0221-秦統一.md)）：**用人力情報網代替資訊基礎設施**，代價是維持成本極高。

**線索三：稅務國家（國營經濟）。** 孔雀帝國的財政：土地稅（收成的 1/6 到 1/4）、國營礦山、國營鹽業、關稅、森林與工坊的壟斷收入。國王同時是**最大地主、最大礦主、最大商人**。偵查結論：這是「榨取型國家」的完整形態——**國庫的豐厚度=常備軍的規模=帝國的半徑**。希臘使節麥加斯梯尼記載華氏城有市政委員會管商業、管度量衡——標準化工程與秦的「車同軌」遙相呼應。

**線索四：常備軍與戰象（暴力的規模化）。** 傳說孔雀軍有 60 萬步兵、3 萬騎兵、9 千戰象。數字或許誇大，但方向正確：**把部落武裝變成國家發薪的常備軍**。戰象是古代的「坦克」——衝擊力、威懾力、後勤負擔三者兼具。偵查結論：統一的真正基礎不是理念，是**壟斷暴力的規模**——誰養得起最大的軍隊，誰就定義邊界。

## 結案報告

1. **統一的工程模板**：間諜（資訊）+稅務（財政）+常備軍（暴力）——孔雀帝國證明了次大陸量級的統一需要三件套同時到位。
2. **《政事論》的現實主義**：比《君主論》早一千八百年，把治國寫成可操作的規則書——**政治學可以先於政治學之名而存在**。
3. **與秦的對照**：同時代的東方（秦）與印度（孔雀）各自獨立發明了官僚帝國——**大帝國的治理難題是普世的，解法會趨同**。
4. **為阿育王鋪路**：旃陀羅笈多留下的是機器的硬體（軍隊、稅收、官僚）；他的孫子阿育王將為這台機器裝上軟體——佛教（參見本書 [-0261-阿育王.md](-0261-阿育王.md)）。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 帝國工程 | 跨域效應 |
|------|----------|----------|
| 法律 | 《政事論》成文治國規則 | 官僚行為可預期、可考核 |
| 經濟 | 土地稅+國營壟斷+關稅 | 國庫=軍隊規模的函數 |
| 科技 | 戰象部隊、華氏城木柵防禦 | 暴力規模化、首都工程 |
| 政治 | 曼陀羅外交、行省總督 | 邊界由同盟數學定義 |
| 文化 | 希臘使節往來、阿育王前傳 | 東西資訊開始對流 |

**孔雀 vs 秦（同時代的帝國對照）：**

| 項目 | 孔雀帝國 | 秦帝國 |
|------|----------|--------|
| 資訊系統 | 間諜人力網 | 上計+馳道文書網 |
| 財政 | 土地稅+國營壟斷 | 田租+口賦+徭役 |
| 暴力 | 常備軍+戰象 | 常備軍+弩與長城 |
| 統治哲學 | 《政事論》現實主義 | 法家賞罰標準 |
| 繼任升級 | 阿育王+佛教軟體 | 漢朝+黃老放鬆 |

**帝國三件套（示意）：**

```
資訊（間諜網）──> 中央知道地方在幹什麼
財政（稅+壟斷）──> 中央養得起軍隊與官僚
暴力（常備軍）──> 中央壟斷最終裁決權
三者互為前提，缺一即分裂回列國。
```

**結論：** 孔雀案是「次大陸統一」的第一次完整工程：曼陀羅算清敵友、間諜看清地方、稅收養活機器。**帝國的半徑=資訊半徑與財政半徑的交集**——這條公式在兩千年後的每一個大帝國身上依然成立。
