# 1946-伊朗危機與冷戰走廊：北緯三十度的第一場冷戰

## 案件摘要

1946 年 3 月 2 日，盟軍協議的撤軍期限已過——蘇軍仍駐伊朗西北（阿塞拜疆！），並扶植 1945.12 成立的「阿塞拜疆人民政府」（大不里士！）與「庫爾德共和國」（馬哈巴德！）——**冷戰的第一場代理危機**。伊朗總理卡瓦姆兩手出擊：請聯合國安理會首次正式控訴（1946.1！蘇聯代表葛羅米柯的第一次否決威脅！）＋親赴莫斯科談判、以「阿塞拜疆自治＋北方石油特許權」換承諾撤軍（4 月協議！）；蘇軍 5 月撤離（斯大林在美英壓力與伊朗頑抗下止步！）；12 月伊朗政府軍進大不里士、兩個共和國覆滅、卡瓦姆隨後讓議會否決石油特許權（→斯大林白忙一場！）——**「以文件換時間、以時間收回一切」的經典操作**。後果：杜魯門主義的心理燃料（1947.3！）、北層防禦體系（巴格達公約 1955！）、石油民族主義怒火（1951 摩薩台國有化！）——冷戰的地緣模板在此打版。

## 前因 -- 多因素的局勢

- **1941 佔領**：英蘇以「德國間諜活動」分區佔領伊朗（→南方補給走廊：波斯走廊運送盟軍物資 500 萬噸！）、禮薩汗退位（→21 歲巴列維即位！）。
- **1942 三國同盟條約**：戰後六個月內撤軍（→1946.3.2 期限！）。
- **蘇聯目標**：北方石油（1944 巴里尼基使團被拒→懷恨！）＋高加索屏障＋阿塞拜疆民族的「統一」誘惑（→大不里士與巴庫一水之隔！）。
- **美國轉向**：1945 底羅斯福去世、1946.2 凱南長電報（→「遏制」理論出爐！）——伊朗成為理論的第一個應用題。

## 線索與推理 -- 因素咬合

### 線索一：撤軍談判的博弈樹——「卡瓦姆的雙面交易」

$$\text{蘇聯撤軍條件} = \text{（石油特許權 51\%！）} + \text{（阿塞拜疆「和平解決」的表面承諾）}$$

卡瓦姆的騙局結構：**對莫斯科給支票（未來收益）、對議會留後門（批准權在德黑蘭！）**——議會（被他重組！）1947.10 以 102:2 否決特許權：

| 步驟 | 表面動作 | 實際效果 |
|------|----------|----------|
| 1946.1 告上安理會 | 國際化！ | 蘇聯首次面對多邊壓力（→危機「凍結」！） |
| 1946.2 莫斯科之行 | 融姿態 | 換 4 月撤軍協議 |
| 1946.8 吸收卡什凱部族入閣 | 拆南方內亂 | 穩定後方 |
| 1946.12 軍事進大不里士 | 「平叛」 | 代理政權覆滅（無流血——蘇軍袖手！） |
| 1947 議會否決石油案 | 程序正義 | 蘇聯收穫歸零 |

**弱國的勝利公式：把強國的每一步都寫進程序，再用程序反殺**。

### 線索二：代理政權的脆弱性——「三分鐘的民族主義」

阿塞拜疆人民政府（皮謝瓦里！）與庫爾德共和國（卡齊·穆罕默德！）缺三樣：軍隊自主、經濟基盤、城市中產支持（→土地改革被地主抵制、蘇式徵購反而激起反蘇！）——蘇軍一撤，政權存續天數可數：

$$\text{代理政權壽命} \propto \text{（外軍駐留天數）} \times \text{（本地合法性）} \quad \text{後者 ≈ 0}$$

### 線索三：華盛頓的解讀——「第一塊骨牌」

1946.3.21 杜魯門親自質問斯大林（外交史罕見：總統直線施壓！）；貝爾納斯國務卿的「蘇聯測試論」——伊朗是蘇聯對戰後秩序的第一次「測試」——直接餵養了凱南—杜魯門主義：

$$\text{遏制理論} = \text{伊朗經驗（多邊施壓有效！）} + \text{希臘土耳其援助案（1947！）}$$

## 破案時刻

- 1945.11–12：阿塞拜疆、庫爾德政權成立（蘇軍封鎖德黑蘭通路！）。
- 1946.1.19：伊朗告上安理會（聯合國首案之一！）。
- 1946.3.2：撤軍逾期——危機峰值（杜魯門攤牌！）。
- 1946.5：蘇軍撤出（雙線：談判＋國際壓力！）。
- 1946.12：政府軍收復大不里士、馬哈巴德（卡齊·穆罕默德絞刑！）。
- 1947.10：議會否決石油特許權——反殺收官。

## 後果 -- 改變了什麼

- **冷戰理論**：遏制戰略的第一個成功案例（→杜魯門主義、馬歇爾計劃的邏輯前置！）。
- **伊朗**：北層防禦體系核心（→1955 巴格達公約！1979 之前的反蘇樞紐！）。
- **石油政治**：蘇聯石油要求的破產反證「資源外交須配合軍事存在」（→1951 摩薩台國有化的民族主義燃料反而來自英國！）。
- **民族問題**：阿塞拜疆、庫爾德問題被冷戰框架吸收（→1991 中亞獨立時的同名復活！）。

## 因素影響筆記

```
波斯走廊（1941-45！）──→ 蘇軍駐留藉口 ──→ 1946 危機
安理會控訴×總統直線施壓 ──→ 撤軍（多邊制衡的早期樣本！）
卡瓦姆：支票給蘇聯、程序留後門 ──→ 議會反殺（1947！）
危機解讀 ──→ 凱南電報→杜魯門主義 ──→ 冷戰體制成型
```

**偵探結語**：伊朗危機案的真相有兩層：表層是斯大林的試探被頂回（蘇聯在 1946 年的實力並不足以在遠離鐵路網的地方維持軍事存在——後勤的坦白！）；裡層是卡瓦姆的「程序反殺」——弱國最強的武器不是軍隊，而是**讓強國簽下自己無法執行的文件**。這一課，冷戰雙方都沒有真正學會（→1953 美英政變摩薩台：同款手法，反向使用）。
