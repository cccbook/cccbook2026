# 1852 廈門苦力貿易：豬仔館與海上抗暴

## 案發現場

1840s–70s，廈門（五口之一）成為苦力貿易（豬仔）中心：豬仔館（洋行+買辦+會黨）、苦力船（汕頭廈門出發，死亡率高），目的地古巴、秘魯、美國。一說高峰年出洋數萬。反抗：苦力暴動（船上奪船：一說「新金山」號等）、廈門小刀會（1853，參見 [本書 1853 篇](1853-廈門小刀會.md)：反清兼反洋？一說複雜）、清政府查禁（沈葆楨，1860s）。**開埠的廈門，為何變成人市？**

> **通商口岸如何變成人口市場？當洋行的招牌下掛著豬仔館的牌子，開埠的光環照的是誰？**

## 偵查過程

**線索一：廈門的區位（苦力的產地直銷）。** 廈門背靠閩南（泉漳：人多地少+械鬥頻繁+災荒）——**苦力的貨源地**：械鬥俘虜（被賣）、災民（自賣）、拐騙（被賣）。洋行（英美德）+買辦（華商中介）+會黨（小刀會餘部？一說+哥老會）——**三方合資的人市**。偵查結論：這是**產地直銷的人口貿易**：貨源（閩南）+港口（廈門）+船（洋行）——**零公里供應鏈**（拐來即裝船）。與廣州（十三行舊體制）對照：廈門新口岸（1842 開埠，無舊規矩）——**新口岸無舊道德**：廣州有行商體制（雖腐敗但有規矩），廈門是叢林（誰狠誰賺）。**開埠的陰影**：通商（茶、糖）+販人（豬仔）——同一個碼頭，兩種貨物（一種喝的，一種喘氣的）。廈門的繁榮（1840s–，參見 [本書 1842 篇](1842-廈門開埠.md)）——**一半茶葉，一半人血**。

**線索二：豬仔館的日常（人間地獄的標準程序）。** 館內：關押（數百人一間，烙號，一說）、驗身（脫衣，如牲口）、畫押（按手印，不識字）、裝船（底艙，死亡率逾一成，一說）。偵查結論：這是**販賣的標準作業**：標準程序（拐→關→驗→押→裝）——**每一環都有價目表**（拐費、館費、船費、拍賣價）。苦力的「自願」（畫押）=**槍口下的自願**（不畫押接著關，打到畫為止，一說）。與黑奴（參見 [../大航海時代/1518-伊斯帕尼奧拉天花.md](../大航海時代/1518-伊斯帕尼奧拉天花.md)：非洲—美洲）對照：**同一條販賣鏈，換了貨源（非洲→華南）**——廢奴（1833）後，販奴船換招牌（苦力船），繼續開。**招牌換了，標準程序 沒換**：關、驗、押、裝——四步，一步不少。廈門豬仔館的特殊：**華人賣華人**（買辦+會黨）——販賣鏈的本土化（洋人不髒手，華人髒手）——**殖民的聰明：讓本地人管本地人的販賣**。

**線索三：船上的抗暴（奪船的勇氣）。** 苦力船暴動：1852 年「羅伯特·鮑恩」號（一說）、「新金山」號等——苦力破艙奪船（殺船員，回航或漂流）。偵查結論：這是**絕境的反抗**：底艙（缺氧+疾病+虐待）→橫豎是死→奪船（萬一活）——**死亡率倒逼勇氣**（不反抗死九成？一說誇張，但方向對：反抗有一線）。奪船的結局多悲慘（缺航海知識，漂流餓死或被鎮壓）——**勇氣彌補不了技術**（不會開船）。但意義在國際（瑪耶西號 1872，參見 [../亞洲史/1842-三合會與苦力貿易.md](../亞洲史/1842-三合會與苦力貿易.md)：日本扣船仲裁）——**每一次奪船，都是一次國際曝光**（報紙報導：豬仔真相）。**反抗的函數**：壓迫（死亡率）× 絕望（無活路）=奪船——廈門出發的船，奪船率最高（一說），因為**閩南人悍**（械鬥傳統：上船前打過架，上船接著打）。

**線索四：沈葆楨的查禁（晚清的作為）。** 1860s，沈葆楨（閩浙總督，船政大臣）查禁豬仔館（封館、拿辦買辦）+李鴻章交涉（1874 古巴調查，陳蘭彬）——苦力貿易 1870s 後轉地下/漸息。偵查結論：這是**晚清少有的作為**：地方大員（沈葆楨）頂住洋人壓力（領事抗議）查禁——**主權的微光**（不平等條約下，華官管洋館，難）。查禁的局限：治標（封廈門的館，館移到汕頭香港）+治不了本（需求在：古巴秘魯還要人）——**打地鼠式執法**。但意義：**第一次官民合力**（士紳控訴+官員查禁+苦力反抗）——三流匯成壓力，逼出 1874 年交涉。廈門的教訓：**開埠的城市，藏污納垢是常態**（租界、洋行、會黨三不管）——**治得了豬仔館，治不了開埠本身**（開埠即開放+失控）。

## 結案報告

1. **直銷定律**：貨源港口零公里——新口岸無舊道德，繁榮一半人血。
2. **標準程序 定律**：招牌換標準程序不換——華人賣華人，殖民本土化。
3. **奪船定律**：死亡率倒逼勇氣——勇氣補不了技術，曝光補得了正義。
4. **微光定律**：打地鼠式查禁——治標不治本，官民合力第一次。

**人市公式（示意）：**

```
苦力貿易 ＝ 貨源（閩南亂）× 港口（廈門新）＋ 需求（古巴秘魯）− 查禁（沈葆楨）。
開埠＋亂世＋需求−微光＝百萬豬仔。
```

**結論：** 廈門苦力案是「開埠陰影」的完整樣本：產地直銷、標準程序販賣、船上奪船、微光查禁——一個口岸，兩種貨物（茶和人）。**通商的光環下，總有人市的陰影**——廈門的繁榮，一半寫在茶葉提單上，一半寫在豬仔的烙號裡（烙在身上，一說）。奪船的苦力不會開船，但他們會開歷史的門——門後是瑪耶西號的仲裁、陳蘭彬的調查、豬仔館的封條。**不會開船的人，開了正義的門**——門開處，1874 年的光照進來，豬仔館關門了（大半）。
