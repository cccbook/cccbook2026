# 1628-鄭芝龍與海上帝國：收買路錢的海盜王

## 案件摘要

明天啟末至崇禎元年（1628 年），縱橫東亞的海盜頭子鄭芝龍（一官）接受明朝招撫，由盜轉官，旋即以官軍之名行壟斷之實：凡經台灣海峽的商船，不掛鄭家令旗、不繳「買路錢」者，奪船殺人。全盛時擁船逾千、眾數萬，年入以百萬兩計，連荷蘭東印度公司都要向他買通關。這樁案件的兇手是「壟斷」：鄭芝龍把嘉靖以來的走私黑市，整合成一家有艦隊、有稅收、有外交的「海上公司＋政府」。金廈（浯島與嘉禾）正是這帝國的總部與收費站。

## 前因 -- 多因素的局勢

- **時代**：明末海禁名存實亡，月港合法化後私貿暴增，中日絲銀貿易＋歐人東來，東亞海面白銀滾滾。
- **個人**：鄭芝龍泉州南安人，少時赴澳門習葡語、赴日本娶田川氏（鄭成功母），入李旦、顏思齊海盜集團，1625 年自立「一官黨」。
- **競爭**：海上群雄並立——劉香、李魁奇、荷蘭人、西班牙人、明官軍，互相劫殺。
- **明廷**：遼東用兵、餉糧告急，對東南「以盜制盜、以海養海」樂見其成，福建巡撫熊文燦主撫。
- **基地**：金門、廈門港深水闊、島嶼可守，又近月港、漳泉貨源，天然總部。

## 線索與推理 -- 因素咬合

### 線索一：買路錢 = 保護費經濟學

鄭氏收費不是亂搶，而是一套定價系統：按船大小、航線、貨值收「稅」，給旗、給護航、給賠償（被搶包賠）。經濟學上這叫** stationary bandit（定居強盜）**：流寇只搶一次，定居者要養肥了再收。用公式表示：

$$R = t \times Q(t) - C_{艦隊}$$

$t$ 為稅率，$Q$ 為過往船數（隨稅率遞減），$C$ 為艦隊成本。鄭芝龍把 $t$ 定在商人「付得起、比被搶划算」的甜蜜點（約貨值 10–20%），$Q$ 反而大增——壟斷的稅收遠大於海盜的一次性搶劫。難怪商人寧繳錢掛旗：鄭旗所至，荷蘭人也不敢動。這就是**黑道變政府**的瞬間——收稅者即統治者。

### 線索二：一官黨 = 海上股份公司

鄭集團不是一人之匪幫，而是聯號制：十八芝（結拜兄弟）各擁船隊，鄭為盟主；設帳房、定股份、按出資與功勞分紅；兼營運輸、貿易、移民（招漳泉饑民渡台開墾，每人收銀三兩、給牛具）。組織表如下：

| 部門 | 功能 | 陸上類比 |
|------|------|----------|
| 戰船隊 | 護航＋劫殺對手 | 海軍 |
| 旗稅館（金廈） | 發旗收稅 | 稅務局 |
| 貿易號 | 絲銀瓷糖交易 | 外貿公司 |
| 移民船 | 載客渡台 | 航運＋仲介 |

這比同時代荷蘭 VOC 更靈活：VOC 靠股東＋國家特許，鄭靠兄弟＋拳頭。但邏輯相同——**暴力是海上最好的商業模式**。

### 線索三：為何接受招撫？洗白的數學

1628 年受撫，鄭由盜得官（遊擊、副總兵），看似投降，實是併購：

$$\text{受撫收益} = \text{合法性} + \text{官軍補給} + \text{剿滅對手的尚方寶劍}$$

受撫後他以官軍名義，三年內滅李魁奇（1630）、滅劉香（1635），荷蘭人亦不敢輕動。朝廷給的官銜、餉銀只是零頭，真正的紅利是「合法壟斷」。明廷以為收了一條狗，實是請了一位王——東南海面從此姓鄭。這招後來鄭成功反用（以明朝忠臣之名行割據之實），父子同一套路。

### 線索四：金廈為何是心臟？

鄭以安平（今安海）為老巢，以金門、廈門為前進基地：金門料羅灣泊戰船，廈門（嘉禾）中左所收稅發旗。金廈有三好：水深可泊大船、島險可守、近大陸貨源又與台灣、日本成三角。用地緣公式：

$$\text{基地價值} = \text{航道交會} \times \text{易守難攻} \times \text{補給距離}^{-1}$$

金廈三項全滿分。此後三十年，誰得金廈誰得海權——1633 年料羅灣海戰（[1633-料羅灣海戰.md](1633-料羅灣海戰.md)）與 1650 年代鄭成功基地（[1646-鄭成功與金廈基地.md](1646-鄭成功與金廈基地.md)），都是這顆心臟的跳動。

## 破案時刻

- 1625：一官黨自立，劫掠漳泉，荷蘭人稱之為 Iquan。
- 1628：熊文燦招撫鄭芝龍，授遊擊，鄭以官軍剿同行。
- 1630–1635：滅李魁奇、劉香，壟斷台灣海峽，荷蘭人被迫繳稅通關，海上帝國成形。

## 後果 -- 改變了什麼

- **經濟**：東亞貿易秩序由鄭家定價，白銀—生絲—蔗糖鏈條經金廈轉運，閩南暴富。
- **政治**：明廷東南防務外包給鄭家，養虎成患，為後來鄭成功抗清留下本錢。
- **台灣**：鄭招數萬人渡台墾殖，台灣漢人社會自此大規模展開。
- **金廈**：由衛所邊城變為帝國商都的前身——沒有鄭芝龍的稅旗，就沒有後來廈門的商埠。

## 因素影響筆記

本案件的因素因果鏈：

1. **白銀貿易 → 海上利潤池**：全球化製造海盜的獵場。
2. **壟斷暴力（買路錢）→ 超額利潤**：定居強盜勝過流寇。
3. **招撫（合法性）→ 兼併對手**：以官滅盜的洗白術。
4. **金廈基地 → 海權心臟**：地理兌現為權力。
