# 1852-苦力貿易與豬仔館：僑鄉線的黑暗起點

## 案件摘要

咸豐二年（1852 年）三月，廈門爆發反苦力貿易暴動：民眾攻擊擄掠華工的「豬仔館」與美國商船「羅伯特·布朗號」（Robert Bowne），英軍開槍鎮壓，死傷十餘人，廈門商人罷市聲援。英國領事被迫調查，揭開「契約華工」（coolie trade）的黑暗內幕：廈門自 1845 年起成為西印度、南美種植園的人力獵場，賣身者多為閩南破產農民，簽的是八年契約，領的常是殺豬般的待遇——「豬仔」之名由此而來。本案是本書僑鄉線（[1904-僑匯與僑批.md](1904-僑匯與僑批.md)、[1921-廈門大學與陳嘉庚.md](1921-廈門大學與陳嘉庚.md)）的**黑暗起點**：海外華人社會的第一代，很多不是移民，是貨物。

## 前因 -- 多因素的局勢

- **經濟**：鴉片戰後閩南農村破產（白銀外流、鴉片內耗），出海謀生成為宗族集體決策。
- **需求**：1833 英屬殖民地廢奴、1848 美加淘金潮，種植園與礦場人力真空，全球都在找人。
- **制度**：廈門開埠（[1842-廈門開埠.md](1842-廈門開埠.md)）後領事裁判權在握，洋行招工無王法可管。
- **中介**：閩南「客頭」（豬仔頭）以預支安家費、賭債綁架等手法在鄉間網羅人力。

## 線索與推理 -- 因素咬合

### 線索一：契約的自由外衣

豬仔貿易的法律包裝是「自願契約移民」：簽八年契約、船資由雇主墊付、工資償還。但實際運作是債務奴役：

$$\text{實際束縛年數} = \frac{\text{船資} + \text{利息} + \text{扣款} + \text{物價虛高}}{\text{名目工資} - \text{克扣}} \gg 8$$

在古巴與秘魯鳥糞島，契約華工死亡率高達一至三成，自殺成風。**契約是為了讓奴隸制在廢奴時代合法存活**——這與夏威夷大分封（參見姊妹書國家滅亡史 1893 案）同一邏輯：法律形式先於實質正義。

### 線索二：1852 暴動的訊號——社會的免疫反應

「羅伯特·布朗號」水手在船上虐殺華工，激起廈門公憤；民眾圍攻豬仔館、拒絕與洋行交易，罷市持續數日。這是中國近代最早的大規模反對人口販運運動之一。值得注意的參與者：本地商人（罷市）、宗族（阻止子弟被擄）、祕密會黨（組織動員）——**反洋的社會動員第一次以「保護自己人」而非「保衛朝廷」為主軸**，這條動員技術後來出現在小刀會（[1853-廈門小刀會.md](1853-廈門小刀會.md)）。

### 線索三：從豬仔到僑批的體質轉換

1850s 之後，列強輿論與清廷壓力使苦力貿易形式上收斂；廈門的出洋轉向「自由移民＋親友引薦」模式：先到的同鄉（水客）寄回銀信、帶出新客，形成自我增長的移民鏈。人類學所謂 chain migration（鏈式移民）——**每一封信就是下一批移民的廣告**。南洋的錫礦、橡膠園、碼頭、商號，於是由閩南宗族的「過番」網絡填滿。

### 線索四：數字的帳本

1850–1875 年間從廈門出洋者近百萬人次，主要目的地：新加坡、檳城、馬尼拉、爪哇、檀香山。這些人在 1904 年的僑批網絡（月匯百萬銀元級）、1910s 的辛亥捐款、1921 年的廈大（陳嘉庚是新加坡橡膠大王）、1939 年的南僑機工（後續案件）——**本案那些被當貨物運走的人，是此後九十年閩南現代化的第一推動力**。

## 破案時刻

- 1845：首批契約華工自廈門出洋。
- 1852.03：羅伯特·布朗號事件，廈門暴動與罷市。
- 1860s：英屬海峽殖民地設「華民護衛司」，苦力貿易轉入地下。
- 1874：葡萄牙澳門苦力貿易被禁，全球契約工制進入衰退。

## 後果 -- 改變了什麼

- **人口**：閩南（含金門）成為華僑輸出重鎮，僑匯成為二十世紀閩南家庭的命脈。
- **社會**：出洋取代科舉成為底層流動的主要通道，「過番」敘事進入歌謠與族譜。
- **法律**：反苦力暴動迫使領事與洋行收斂，催生華工保護的早期國際規範。
- **金門**：下南洋的金門人回鄉起洋樓（1930s 達到高峰），金門地表景觀由此定形。
- **史鑑**：移民的悲劇起點，可以長出偉大的僑鄉網絡——歷史的利息常常記在不同的帳戶上。

## 因素影響筆記

1. **農村破產 → 出洋供給**；殖民地人力真空 → 出洋需求：價差即市場。
2. **契約形式 → 債務奴役實質**：法律外衣是奴隸制的續命裝置。
3. **暴動（1852）→ 社會免疫 → 貿易轉型**：從「擄人」到「引親」的體質轉換。
4. **鏈式移民 → 僑批網絡 → 教育投資（廈大）**：本書僑鄉線的第一塊基石。
