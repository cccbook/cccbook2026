# 0803-陳淵牧馬浯洲：十二姓開啟的島嶼史

## 案件摘要

唐德宗貞元十九年（803 年），河南光州人陳淵，率李、吳、蔡、張、黃等十二姓人家渡海入浯洲（金門舊稱浯洲、浯島），牧馬、煮鹽、墾荒。後人尊為「開浯恩主」，金門各姓族譜皆以此為開端。這樁案件的兇手是「馬」：唐帝國在安史之亂後馬政崩壞，急需南方牧地養戰馬，陳淵的屯墾團恰逢其會。一群中原移民牽著馬、挑著鹽，在無人問津的海島上，寫下金門第一頁有名字的歷史。

## 前因 -- 多因素的局勢

- **政治**：安史之亂後藩鎮割據，朝廷馬源（河西、隴右）斷絕，設群牧監四處求馬。
- **軍事**：福建觀察使柳冕奏請於泉州置牧馬區，陳淵以別駕銜主持其事。
- **經濟**：浯洲空曠、草豐、少稅，兼有鹽場之利——馬＋鹽＋墾，三業並舉可自給。
- **人群**：中原經永嘉、安史兩次南渡，泉州一帶已有南來漢人，十二姓多為光州、潁川舊族旁支。
- **地理**：浯洲與廈門（時稱嘉禾嶼，屬同安一隅）隔海相望，颱風、缺水卻少瘴癘，宜牧不宜耕。

## 線索與推理 -- 因素咬合

### 線索一：牧馬 = 邊疆屯墾模式

陳淵帶來的不只是人，而是一套「屯墾套餐」：官給旗號（牧馬監）、兵給秩序、民給勞力、馬給資本。公式如下：

$$\text{屯墾成功率} = \frac{官府背書 \times 自衛能力 \times 多元生業}{天災 + 土著衝突 + 賦稅}$$

單一種田在金門必死（土薄水鹹、颱風一來全滅），但馬＋鹽＋漁＋墾的組合把風險分散了。馬是官物、銷路有保證；鹽是硬通貨，走私都好賣；墾田種地瓜小米餬口。這種**複合生業**是此後千年金門的生存模板——金門人從不靠一種飯吃飯。

### 線索二：十二姓 = 宗族社會的種子

十二姓同舟而來，登島後按血緣分地：陳氏居後浦、蔡氏居瓊林前身……每姓建祠、修譜、共井、共墓。這是組織行為學的經典：**在無政府邊疆，血緣是最便宜的契約**。

| 邊疆難題 | 宗族解法 |
|----------|----------|
| 防盜禦倭 | 丁壯聯防、銃樓團練 |
| 水源分配 | 祖訓定份、族長仲裁 |
| 貧富救濟 | 祭田、義倉、渡台盤纏 |
| 糾紛 | 家法先於王法 |

自此金門成為宗族之島：聚落即血緣、宮廟即議會。後來下南洋、遷台灣，金門人照樣先建宗祠再建屋——803 年的十二姓，是所有海外金門會館的源代碼。

### 線索三：為何是浯洲，不是嘉禾？

當時廈門本島（嘉禾）更大、水更多，為何選金門？答案是**產權真空**：嘉禾近同安縣治，已有土著與稅戶，插不進腳；浯洲孤懸海外，無官無稅，整島可圈為牧區。陳淵以「牧馬」之名拿到整島開發權——馬是幌子，地才是本。這招叫「以官業包民墾」：後世鄭成功以軍屯包商屯、國軍以戰地包農地，都是同一邏輯。

### 線索四：恩主的製造——記憶的政治學

陳淵在史書中僅一筆，族譜卻把他捧為神明（開浯恩主廟遍布金門）。為何？因為十二姓需要一個**共同祖先以上的祖先**：各姓血緣不同，若無超血緣的象徵，聯盟必散。陳淵（官＋漢＋開拓者）恰好充當最大公約數。每年祭祀，即重申一次「我們是浯洲人」。**恩主不是歷史人物，而是島嶼認同的黏合劑**。

## 破案時刻

- 803 年：陳淵率十二姓入浯洲，置牧馬監，分地屯墾。
- 805–820 年：鹽場、渡口漸成，浯洲納入泉州版圖，始有編戶。
- 後世：牧馬廢而農漁村存，十二姓繁衍為金門百餘聚落之祖。

## 後果 -- 改變了什麼

- **人群**：金門由越人漁島變為漢人宗族島，閩南話、族譜、風獅爺自此生根。
- **經濟**：馬鹽墾複合模式確立，金門納入海上絲路的鹽糧供應鏈。
- **認同**：浯洲之名與開浯記憶，成為金門人「我群」的起點，與嘉禾（廈門）分途。
- **對照**：廈門此時仍是嘉禾荒嶼，要到宋元泉州興、明清展界後才超車——金門先跑了八百年。

## 因素影響筆記

本案件的因素因果鏈：

1. **帝國馬政危機 → 邊疆授權（牧馬監）**：國防需求打開移民閘門。
2. **島嶼貧瘠 → 複合生業（馬鹽漁墾）**：環境逼出多元經濟。
3. **無政府邊疆 → 宗族組織**：血緣是最便宜的治理。
4. **多元姓氏 → 共同象徵（恩主）**：記憶製造認同。
