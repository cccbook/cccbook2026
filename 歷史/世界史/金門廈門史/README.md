> 金門與廈門隔海相望（最窄處僅約 2 公里），同屬閩南，卻走過截然不同的路：金門是「固若金湯」的海上堡壘與冷戰前線，廈門是五口通商的國際商埠與僑鄉門戶。兩城一體兩面，是理解明清海防、國共內戰與兩岸關係的鑰匙。
