# -4000-復國墩遺址與史前金門：貝塚裡的六千年

## 案件摘要

金門島東南角的復國墩，是一座不起眼的小漁村。1970 年代考古學家在此發現：厚達數公尺的貝殼堆積層，夾著陶片、石器與魚骨——一座新石器時代的「貝塚」。定年約距今 6000–4000 年，陶器以粗砂繩紋陶與幾何印紋陶為主，與福建曇石山文化、大陸東南沿海同屬一個文化圈。這樁案件的兇手是「海」：在文字出現的三千年前，浯島（金門舊稱浯洲、浯島）已是南島語族與百越先民交會的漁獵前哨。貝殼不會說謊——它們是史前金門人的餐桌帳本，也是第一份「金門經濟史」。

## 前因 -- 多因素的局勢

- **地理**：冰期後海平面上升，金門由丘陵變為島嶼，潮間帶發達——牡蠣、文蛤、泥蚶取之不盡。
- **氣候**：全新世大暖期，亞熱帶海洋資源豐盛，支持定居而不必完全依賴農業。
- **技術**：磨製石器、夾砂陶（露天燒製約 700–900℃）、獨木舟與近海漁撈。
- **文化**：曇石山—金門—台灣北部的印紋陶圈，暗示沿海族群的遷徙與交換網。
- **人口**：採集漁撈的承載力低，一處貝塚聚落約數十至百人，不斷遷移、重疊堆積。

## 線索與推理 -- 因素咬合

### 線索一：地層學 = 時間的三明治

考古地層學第一定律——疊壓定律：下層早於上層。復國墩剖面自上而下：表土耕土層、近代墓葬擾亂層、貝殼密集層、黃土生土層。每一層都是一張時間切片：

| 層位 | 內涵 | 推論 |
|------|------|------|
| 上層貝殼稀疏、夾瓷片 | 明清漁民活動 | 晚期季節性利用 |
| 中層貝殼密集、幾何印紋陶 | 新石器鼎盛期 | 長期定居聚落 |
| 下層貝殼稀少、夾粗繩紋陶 | 早期試探性移住 | 小群體間歇登島 |

**地層不說故事，地層就是故事本身**——挖土即讀時間。

### 線索二：貝塚 = 生業經濟的資產負債表

一枚牡蠣殼是蛋白質的收據。生態考古學用公式估算：

$$E_{net} = \sum(卡路里收益) - \sum(採集 + 搬運 + 開殼成本)$$

潮間帶貝類單位成本極低、風險極小、且婦孺皆可採集——是「低風險、低報酬」的 staple（主食）。魚骨中的鯛科、石首魚科則是「高風險、高報酬」的蛋白質。復國墩先民的組合是典型的**廣譜採集（broad-spectrum）策略**：不把雞蛋放在同一個籃子裡。以貝類保底、以漁獵加菜、以少量旱作（小米？）補充——這正是島嶼環境的最優解。

範例：以今日金門潮間帶實測，一小時可採蚵約 2–3 公斤（去殼約 300 克肉，約 200 大卡），恰足一人半日所需。聚落百人，每日需出動二三十人採集——社會分工就此誕生。

### 線索三：幾何印紋陶 = 身分證與社交網

復國墩陶器胎土取自島上花崗風化土，紋飾以拍印的曲折紋、雲雷紋、方格紋為主。重點不在美觀，而在**資訊**：紋飾母題與曇石山下層、漳州浮宮高度相似，距離超過 100 公里海路。這意味著：

$$\text{紋飾相似度} \propto \text{通婚與交換頻率}$$

陶器是族群的「方言」——會做同一種紋路的人，就是「自己人」。史前浯島不是孤島，而是閩台黑水溝兩岸的踏腳石，後來南島語族向台灣與東南亞擴散，很可能踩過這塊石頭。

### 線索四：為何消失？承載力的天花板

約距今 4000 年後，復國墩文化層驟然變薄。兇手可能是海平面小幅上升淹沒灘塗，或土壤鹽化、貝場枯竭——小島承載力公式：

$$\text{人口上限} = \frac{\text{潮間帶面積} \times \text{單位產量}}{\text{人均需求}}$$

島嶼生態脆弱，一旦過度採集，聚落只能 fission（分裂遷出）。金門此後近三千年幾無大型遺址——直到唐宋才再興。這是島嶼史的第一次循環：**來得早、長不大、海一變臉就得走**。

## 破案時刻

- 約前 5000–前 4000：先民季節性登島，留下稀疏繩紋陶。
- 約前 4000–前 3000：定居高峰，厚貝塚＋幾何印紋陶形成。
- 約前 3000 以後：海退場、聚落萎縮，浯島重歸寂靜，等待漢唐的下一批移民。

## 後果 -- 改變了什麼

- **人群**：證實金門有人史早於中原信史三千年，且屬海洋百越—南島世界，而非中原農耕世界。
- **經濟**：貝塚生業模式成為此後漁村的原型——靠海吃海、貝蚵不離桌。
- **文化**：印紋陶圈把金門寫進「海洋中國」的起點，而非邊陲。
- **史觀**：金門史不從 803 年陳淵開始，而從貝殼開始——島史比國史老得多。

## 因素影響筆記

本案件的因素因果鏈：

1. **地理（島嶼潮間帶）→ 生業（貝塚經濟）**：環境決定菜單。
2. **技術（陶＋舟）→ 社會網（印紋陶圈）**：器物即社交。
3. **生態承載力 → 聚落興衰**：小島的硬天花板。
4. **海平面變動 → 文化斷層**：氣候寫下第一頁金門史。
