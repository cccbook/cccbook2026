# 1684-展界與廈門興起：港口洗牌的那隻看不見的手

## 案件摘要

1683 年施琅澎湖大捷、鄭克塽降清，台灣入版圖。1684 年康熙下令「展界」（復界）：廢止 1661 年遷界令的封鎖線，准沿海居民回遷出海，並開海設關（閩海關正口在廈門）。此後二十年，**廈門取代金門，成為福建對台貿易的正口與閩南第一大港**。本案的兇手是「區位＋政策」：深水避風的廈門港被政策選中，商人、船工、錢莊隨之聚集，金門則因水淺、腹地小而邊緣化——一旦路徑形成，後來者再難翻盤。

## 前因 -- 多因素的局勢

- **政治**：1661 年遷界令（遷海三十里，焚屋、築界牆），閩粵沿海數十萬人流離，金廈成為「界外鄭界」。
- **軍事**：1683 年六月施琅澎湖海戰擊潰劉國軒，鄭克塽降，海上戰爭結束，封鎖失去理由。
- **經濟**：閩南人下海謀生需求強烈；台灣米、糖需經廈門轉運內地，內地布、器需經廈門運台。
- **地理**：廈門島有深水港（嵩嶼、鼓浪嶼屏障）、腹地連漳泉；金門島小、水淺、多礁，宜屯兵而不宜聚商。
- **制度**：1684 年設閩、粵、江、浙四海關，閩海關駐廈門——官方稅收與管理向廈門傾斜。

## 線索與推理 -- 因素咬合

### 線索一：展界 = 解開封印

遷界是「堅壁清野」的成本：朝廷以沿海民生為代價餓死鄭氏。平台之後，康熙算的是另一筆帳：

$$財政收益 = 海關稅收 + 沿海安定 - 駐軍軍費$$

展界復界讓流民回鄉、海商納稅，軍費下降。這是政策的理性轉向：**戰時封鎖，戰後開海**。1684 年展界詔下，漳泉百姓「扶老攜幼歸」，廈門街市一年而復。

### 線索二：港口區位——為什麼是廈門不是金門？

比較兩港的「港口生產函數」：

| 條件 | 廈門 | 金門 |
|---|---|---|
| 水深與避風 | 九龍江口、鼓浪嶼屏障，深水良港 | 沿岸多礁、水淺，大船難泊 |
| 腹地 | 連漳州、泉州平原，米糧手工業腹地大 | 島小田瘠，腹地幾無 |
| 制度加持 | 閩海關正口、對台正口 | 僅設協鎮、巡檢，軍事前哨 |
| 商人網絡 | 漳泉海商、郊商雲集 | 戰後人口凋敝，網絡斷裂 |

商船選擇港口只看一句話：**哪裡裝卸快、稅低、好賒帳，就去哪裡**。廈門三者兼得。

### 線索三：路徑依賴——贏者通吃的港口經濟

經濟學的路徑依賴（Path Dependence）：港口一旦聚集，就自我強化——

$$商船數_{t+1} = f(商船數_t, 錢莊數_t, 修船廠_t)$$

船多 → 錢莊、牙行、修船廠聚集 → 成本更低 → 船更多。廈門在 1684–1720 年代完成這個正向迴路：郊商（貿易公會）、錢莊、米市、船廠齊聚；金門錯過窗口，此後三百年再未翻盤。這就是諾斯（Douglass North）說的制度變遷：「**小事件＋正反饋＝不可逆的路徑**」。

### 範例說明

如同高鐵設站：站設在哪，哪裡就長出商圈。康熙把「海關站」設在廈門，商人自然用腳投票。金門像被繞過的老車站，風光留給了廈門。

## 破案時刻

- 1683 年 8 月：鄭克塽降，台灣平定。
- 1684 年：康熙展界、開海，設閩海關，廈門為對台正口。
- 1727 年：清廷定廈門為台灣、澎湖往來正口，金門徹底淪為配角。

## 後果 -- 改變了什麼

- **經濟**：廈門成為閩南貿易中心，米、糖、布、茶經此集散，郊商崛起。
- **社會**：漳泉移民經廈門出海下南洋，廈門成為僑鄉門戶。
- **金門**：由軍政中心降為防汛小島，人口外流、僑匯經濟的種子悄悄埋下。
- **兩岸**：廈—台航線固定化，「一水之隔」的經貿臍帶形成，延續至今。

## 因素影響筆記

1. **戰爭結束 → 政策轉向**：平台消除了遷界的理由，展界水到渠成。
2. **地理區位 → 政策選址**：深水＋腹地使廈門被選為海關正口。
3. **制度加持 → 聚集經濟**：海關、郊商、錢莊形成正向迴路。
4. **路徑依賴 → 長期分化**：廈門鎖定勝局，金門鎖定邊緣。
