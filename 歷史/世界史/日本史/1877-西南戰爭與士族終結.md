# 1877-西南戰爭與士族終結：武士階級的訃告

## 案件摘要

1877.2–9，西鄉隆盛率薩摩士族約3萬舉兵，圍熊本、戰田原坂，9.24城山自刃——**日本最後一場內戰，政府動員6萬徵兵＋軍艦鐵道，耗費4200萬圓（年財政七成）**。前案維新（見 [1868-明治維新.md](1868-明治維新.md)）講了開國，後案憲法（見 [1889-大日本帝國憲法.md](1889-大日本帝國憲法.md)）講了立憲，中間獨缺：**拿刀推翻幕府的武士，為何九年後被自己建的徵兵軍隊消滅？**本案是維新後果的收尾。

## 前因 -- 多因素的局勢

- **財政**：秩祿（士族俸祿）占歲出三成 → 1873徵兵令＋1876秩祿處分（金祿公債一刀兩斷）→ 士族由「領薪階級」變「公債食利＋失業」。
- **政治**：1873征韓論分裂（西鄉下野歸鹿兒島辦私學校）→ 1874佐賀之亂、1876神風連—秋月—萩之亂連敗 → 不滿總爆發。
- **軍事**：政府軍：徵兵農民兵＋斯潘塞—村田步槍＋鐵道海運；薩軍：士族白刃突擊＋舊式槍炮——代差一世代。
- **思想**：士道（戰死美學）vs 國民軍（消耗數學）——兩種戰爭觀的對決。

## 線索與推理 -- 因素咬合

### 線索一：熊本為何攻不下？——城與鐵道的數學

| 項目 | 薩摩軍 | 政府軍 |
|---|---|---|
| 兵力峰值 | 約30000（遞減） | 約60000（遞增） |
| 補給 | 鹿兒島—熊本陸路牛馬 | 長崎—博多海運＋鐵道 |
| 火力 | 舊式前裝槍＋奪取炮 | 後裝槍＋野炮＋軍艦炮 |
| 增援速度 | 步行10日 | 輪船3日 |

$$\text{勝率} = \frac{\text{（火力} \times \text{補給持續）}}{\text{（士氣} \times \text{白刃突擊）}} = \frac{\text{工業量}}{\text{精神量}}$$

田原坂17日血戰（雙方死傷7000）：薩軍拔刀隊夜襲屢勝戰術、屢敗戰略——政府軍打完一排再來一排（徵兵池深），薩軍死一個少一個。**熊本城（加藤清正築）的石垣擋了52天，擋住的其實是時代**。

### 線索二：4200萬圓的帳單——內戰即財政改革加速器

戰費靠公債＋增稅（地租改正後貨幣稅顯威，見 [1873-地租改正.md](1873-地租改正.md)）：

$$\text{戰後財政} = \text{（秩祿廢除省下的} 1200\text{萬）} - \text{（戰費} 4200\text{萬公債）} + \text{（地稅穩定流入）}$$

短期巨虧，長期摘掉士族包袱——松方正義1880s緊縮（見 [1882-日本銀行.md](1882-日本銀行.md)）的前提正是士族帳清零。學術理論（大久保利謙「維新官僚論」）：**西南戰爭是維新的第二次結帳**——第一次（廢藩）收大名的權，第二次收武士的錢。

### 線索三：西鄉之死——輸家贏得神社

城山之戰西鄉股傷、別府晉介介錯，大久保1878被刺（紀尾井坂）：

$$\text{記憶政治} = \text{（政府勝：制度）} \times \text{（西鄉死：道德）} \to \text{南洲神社＋靖國並立}$$

政府1879年特赦西鄉（復大將位，1889赦）、鹿兒島南洲墓成聖地——**贏了戰爭、輸了敘事，只好合資建神**。徵兵農民兵證明「百姓能戰」，士族神話破產；西鄉神格化證明「武士能死」，精神遺產轉包給陸軍（乃木—二二六，見 [1936-二二六事件.md](1936-二二六事件.md)）。

## 破案時刻

- 1876.3：秩祿處分、廢刀令——導火索。
- 1877.1：政府運炮艦襲鹿兒島火藥庫——開戰。
- 1877.2–4：熊本圍城52天不下——轉折。
- 1877.3：田原坂血戰——薩軍精銳耗盡。
- 1877.8：可愛岳突圍失敗——敗局定。
- 1877.9.24：城山自刃——內戰終結；1878.5大久保被刺。

## 後果 -- 改變了什麼

- **軍事**：徵兵制確立——甲午（見 [1894-甲午戰爭.md](1894-甲午戰爭.md)）、日俄（見 [1904-日俄戰爭.md](1904-日俄戰爭.md)）的農民兵團前身在此驗收。
- **財政**：士族包袱出清——地稅＋公債的近代財政輕裝上陣。
- **政治**：自由民權運動接棒不滿（板垣「士族之亂轉為言論之戰」）→ 國會開設請願（1881）→ 憲法路線。
- **文化**：西鄉隆盛銅像（上野，穿平民服、牽狗）——唯一沒穿軍服的陸軍大將，敗者的溫柔復仇。

## 因素影響筆記

```
秩祿處分＋廢刀（財政斷奶）──→ 私學校黨薩軍 ──→ 熊本田原坂消耗
                                                      ↓
徵兵＋鐵道海運（工業量）──→ 城山勝利 ──┬──→ 士族終結＋徵兵確立
                                         └──→ 西鄉神格化（記憶合資）
```

**偵探結語**：維新是下級武士用刀搶來的，西南戰爭是新政府用槍把刀收走的——**革命者親手沒收革命資格**。城山那聲槍響（介錯），是武士時代一千年的句號，也是徵兵時代六十八年的冒號。
