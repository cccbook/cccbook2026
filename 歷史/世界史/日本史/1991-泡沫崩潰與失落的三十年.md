# 1991-泡沫崩潰與失落的三十年：資產負債表的長期衰退

## 案件摘要

1991 年地價下跌開始——**泡沫崩潰**：日經從 38,915 跌至 14,000（1992）、土地跌七成（六大都市）；不良債權（1998 估 100 兆日圓級）→ 1997 三洋證券、北海道拓殖銀行、山一證券倒閉；此後三十年（1991–2020s）：零成長、通縮、零利率、就職冰河期、少子高齡化——**失落的三十年**。這樁案件是「資產負債表衰退」（辜朝明）的教科書：**全民還債不花錢，貨幣政策失效**。

## 前因 -- 多因素的局勢

- **直接**：泡沫（[1985-廣場協議與泡沫.md](1985-廣場協議與泡沫.md)）的崩潰——加息＋總量規制（1990 大藏省土地融資限制）。
- **結構**：後發紅利吃完（追上前沿）＋人口紅利反轉（1974 出生率跌破 2.1、2008 人口見頂）。
- **制度**：護送船團（銀行不倒神話）→ 殭屍企業＋不良債權的延命——「先送り」的十年。
- **外部**：中國崛起（2001 WTO）——製造業的競爭＋供應鏈轉移；IT 革命的落後（Galápagos 化）。

## 線索與推理 -- 因素咬合

### 線索一：資產負債表衰退——「全民還債的合成謬誤」

辜朝明的理論：泡沫崩潰後，企業資產＜負債——**理性行為從「利潤最大化」變「負債最小化」**：

$$\text{經濟} = C + I + G + NX \quad \text{而 } I \to 0\text{（企業還債不投資）}$$

零利率也無人借錢——**流動性陷阱**。個人理性（還債）＋合成謬誤（全民還債＝需求消失）——**政府必須舉債填補（財政赤字→國債 200% GDP）**。日本證明：**財政刺激能止血，不能治癒**（需求回來需要資產負債表修復＋結構改革）。

### 線索二：失落的十年處方——「先送り的成本」

| 時期 | 處置 | 結果 |
|---|---|---|
| 1992–97 | 財政刺激＋低利率、銀行延命 | 不良債權膨脹 |
| 1997–98 | 金融危機（三洋、拓銀、山一） | 公共資金注入（30 兆框架） |
| 1999–2006 | 零利率、量化寬鬆（2001）、竹中改革（不良債權處理） | 不良債權見頂回落 |
| 2013– | 安倍經濟學（三支箭） | 通縮緩解、但成長未返 |

$$\text{延命成本} = \text{（殭屍企業的資源佔用）} \times \text{（年數）}$$

**1990s 的「先送り」把十年變成三十年**——1977–98 住專處理的拖延是縮影。竹中改革（2002–06）證明：**不良債權能處理，但失去的時間不回來**。

### 線索三：人口＋技術的雙重逆風——「結構的三十年」

- 人口：2008 人口見頂、高齡化率世界第一（28%＋）——**需求與供給的雙重收縮**。
- 技術：IT 革命落後（功能手機的 Galápagos、半導體的日美摩擦後遺症）——**前沿的缺席**。
- 分配：就職冰河期（1993–2005 畢業）→ 非正規化（40%）→ 少子化加速——**世代的惡性迴路**：

$$\text{少子化} \leftarrow \text{（非正規＋低薪）} \leftarrow \text{（冰河期）} \leftarrow \text{（泡沫崩潰）}$$

**泡沫崩潰的代價由一整個世代支付**——而這個世代的不婚不育，決定下一個三十年的人口。

## 破案時刻

- 1991：地價下跌——崩潰開幕；1992：日經 14,000。
- 1993：1955 體制崩壞（細川連立）——政治的連動。
- 1995：阪神大地震＋地下鐵沙林——「災害與恐怖的同時」。
- 1997–98：金融危機（三洋、拓銀、山一）——護送船團的終結。
- 1999–2006：零利率、QE、竹中改革——處置與延命的並存。
- 2011：三一一（[2011-三一一大地震.md](2011-三一一大地震.md)）——複合災害。
- 2013：安倍經濟學——通縮對策的總動員。

## 後果 -- 改變了什麼

- **經濟**：通縮＋零利率的常態化——貨幣政策的邊界實驗（QQE、負利率）；國債 200% GDP。
- **社會**：冰河期世代＋非正規化＋少子高齡——人口結構的不可逆（2100 人口或腰斬的預測）。
- **政治**：政權輪替（2009 民主黨）＋再輪替（2012 自民）——「失落」的政治擺盪；修憲、安保法制（2015）的爭議。
- **國際**：中國 GDP 超日（2010）——東亞第一的交棒；日本的「課題先進國」（少子高齡的全球先行）。

## 因素影響筆記

```
泡沫崩潰（1991）──→ 資產負債表衰退（全民還債）──→ 需求消失＋通縮
      ＋                    ↓
人口反轉（結構）──→ 先送り（延命十年）──→ 1997 金融危機 ──→ 竹中處置
      ＋                    ↓
技術落後（IT）──→ 冰河期世代（分配）──→ 少子化加速 ──→ 下一個三十年
```

**偵探結語**：失落案件沒有單一兇手——**是三重謀殺：資產負債表的崩潰（循環）、人口的反轉（結構）、技術的落後（前沿）**。1990年代的先送り把十年變成三十年；而冰河期世代證明：泡沫的帳單，最終由沒見過泡沫的人支付。
