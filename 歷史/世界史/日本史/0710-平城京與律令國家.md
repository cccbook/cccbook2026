# 0710-平城京與律令國家：長安的縮小複製品

## 案件摘要

710 年，元明天皇遷都**平城京**（奈良）——一座以唐長安城為範本、面積約其四分之一的棋盤式都城。奈良時代（710–794）是日本律令國家的「安裝完成期」：大寶律令（701）與養老律令（757）、全國戶籍與班田、正倉院與東大寺大佛（752 開眼）——**一個「唐式帝國」在群島上全速運轉**。但這樁案件的核心線索藏在反方向：**運轉的同時，體系已開始失靈**——班田制的人口極限、寺院經濟的失控、藤原氏的權力壟斷，都是平安時代的伏筆。

## 前因 -- 多因素的局勢

- **政治**：大化革新（[0645-大化革新.md](0645-大化革新.md)）確立律令軌道；大寶律令（701）是安裝完成的宣告。
- **資訊**：遣唐使持續輸入——長安城、佛教、曆法、醫學、貨幣的全套技術。
- **宗教**：佛教成為「國家宗教」——東大寺大佛是國家動員力的展示工程。
- **經濟**：班田收授與租庸調——稻作剩餘的系統性壟斷，財政的物質基礎。

## 線索與推理 -- 因素咬合

### 線索一：平城京是「長安的縮小複製品」

| | 長安 | 平城京 |
|---|---|---|
| 面積 | 約 84 平方公里 | 約 25 平方公里（北端建設區） |
| 布局 | 棋盤格＋中軸線（朱雀大路） | 同構複製 |
| 城牆 | 有城牆 | 無城牆（島國無外敵） |

$$\text{移植制度} = \text{原版} \times \frac{\text{本國需求}}{\text{原版需求}}$$

**無城牆的長安**——這是移植的關鍵細節：日本取其行政與象徵功能，捨去其防衛功能。**移植從來不是照抄，而是按需求的取捨**——此後一切日本式移植（明治維新亦然）皆然。

### 線索二：正倉院——帝國的「資料庫」

正倉院（東大寺旁）保存至今 9,000 件 8 世紀文物——絲綢、樂器、藥品、文書、地圖。這是**班田制與朝貢貿易的資料庫**：從戶籍文書到納稅記錄。偵探的判斷：**正倉院的文物本身就是律令帝國的「運行日誌」**——寫真行文書（戶籍、計帳）顯示班田制的實際運作與衰退曲線。

### 線索三：律令制的「內建缺陷」

班田收授的數學：口分田按人口分配、六年一班——但人口成長與土地集中使其必然失靈：

$$\text{可班田面積} < \text{應班田需求} \Rightarrow \text{班田延遲} \Rightarrow \text{農民逃亡} \Rightarrow \text{稅基萎縮}$$

- 8 世紀中期：班田已難按期執行；逃亡農民投靠豪族與寺院——**「莊園」的萌芽**。
- 寺院與神社獲「不輸不入」特權（免稅、免檢查）——**財政黑洞的制度化**。
- 藤原四家（尤其北家）壟斷攝政、內覽——權力世襲化的起點（[0858-攝關政治與藤原氏.md](0858-攝關政治與藤原氏.md)）。

**律令帝國的天才與詛咒同源：過於精密的制度，遇到人口與經濟的現實，比粗放制度崩得更快**。

## 破案時刻

- 710：遷都平城京——唐式都城的安裝。
- 712–720：《古事記》《日本書紀》——「國史」的編纂，王權的敘事工程。
- 743：墾田永年私財法——允許開墾田私有，**莊園制的法律起點**。
- 749–752：聖武天皇出家、東大寺大佛開眼——佛教國家化的頂點（也是財政極限的展示）。
- 757：藤原仲麻呂之亂（757 計畫、764 惠美押勝之亂）——中央權力的首次軍事震盪。
- 784：遷都長岡京——平城京的放棄（藤原種繼事件、佛教勢力糾纏）。

## 後果 -- 改變了什麼

- **政治**：律令制表面存續、實質空心化——攝關政治（[0858-攝關政治與藤原氏.md](0858-攝關政治與藤原氏.md)）接手實權。
- **經濟**：莊園制的萌芽——「私有領地」將在此後五百年瓦解律令帝國。
- **文化**：天平文化（正倉院、東大寺）——移植期文化的頂峰與日本美學的萌芽。
- **宗教**：佛教的國家化 → 反彈（桓武排抑佛教、遷都）——平安新佛教（最澄、空海）的起點。

## 因素影響筆記

```
大化革新 ──→ 大寶律令（701）──→ 平城京（710）＝長安縮小複製品
                                     ↓
班田制內建缺陷 ──→ 班田延遲 ──→ 逃亡→莊園萌芽（743 法令）
寺院特權 ──────→ 財政黑洞          ↓
藤原壟斷 ──────→ 權力空心化 ──→ 794 平安遷都
```

**偵探結語**：平城京是移植制度的傑作，也是移植制度的病歷表——**精密的帝國在外省落地，第一代人輝煌，第二代人失靈**。奈良時代的正倉院保存的不是榮光，而是一條衰退曲線的日誌；讀懂它，就讀懂了平安時代的到來。
