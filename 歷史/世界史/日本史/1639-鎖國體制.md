# 1639-鎖國體制：主權的兩百年實驗

## 案件摘要

1639 年，幕府驅逐葡萄牙船——**鎖國體制完成**：此後至 1854（黑船），日本僅保留長崎（荷蘭＋中國）、對馬（朝鮮）、薩摩（琉球）、松前（蝦夷）四個窗口——**貿易與外交的幕府壟斷**。這樁案件常被誤讀為「閉關自守」——真相是**主權的精密工程**：在禁教（[1549-天主教傳來.md](1549-天主教傳來.md)）與島原之亂（1637–38）的教訓上，幕府選擇「可控的開放」——**不是關門，是只開一扇自己守的門**。

## 前因 -- 多因素的局勢

- **宗教**：禁教令（1614）＋島原之亂（1637–38）——「信仰動員」的危險證明。
- **政治**：幕藩體制（[1603-江戶幕府.md](1603-江戶幕府.md)）的完成——對外壟斷是主權的最後一塊拼圖。
- **經濟**：生絲—銀貿易的暴利——幕府要壟斷（糸割符、相庭商人），不容大名分潤。
- **外部**：西班牙—葡萄牙的殖民擴張（菲律賓、澳門）——「殖民的前奏是傳教」的警覺。

## 線索與推理 -- 因素咬合

### 線索一：鎖國不是閉關——「四個窗口」的設計

| 窗口 | 對象 | 功能 |
|---|---|---|
| 長崎（出島） | 荷蘭＋中國 | 貿易（生絲、藥材、書籍）＋情報（風說書） |
| 對馬（宗氏） | 朝鮮 | 外交（朝鮮通信使）＋貿易 |
| 薩摩 | 琉球 | 間接的中國貿易 |
| 松前 | 蝦夷（阿伊努） | 北方物資＋邊防 |

$$\text{鎖國} = \text{（禁教）} \times \text{（貿易壟斷）} \times \text{（情報收集）}$$

**荷蘭商館長的「風說書」（世界情報報告）是幕府的 CIA**——鎖國日本對世界的了解，比多數人想像的深。蘭學（天文、醫學、軍事）經長崎輸入——**鎖國是「過濾器」，不是牆**。

### 線索二：島原之亂——鎖國的最後一根稻草

1637–38：天草四郎率 3.7 萬天主教徒＋飢荒農民起義——幕府動員 12 萬鎮壓（荷蘭船砲擊支援！）：

$$\text{鎖國決心} = \text{（島原的動員規模）} \times \text{（外國支援的諷刺）}$$

**用荷蘭大砲打天主教徒**——幕府看穿：外國勢力是可替換的工具，主權不可分。1639 驅逐葡萄牙——**只留新教荷蘭（無傳教熱情）＋中國**——「無傳教的貿易夥伴」的篩選邏輯。

### 線索三：鎖國的兩百年紅利與代價

- 紅利：和平的延續（無外國—大名勾結）、國內市場的深化（參勤交代＋貨幣經濟）、文化的內生演化（元祿、化政文化）。
- 代價：**軍事技術的代差**——1825 異國船打拂令時，日本大砲 vs 西洋艦砲已差兩個世代；**黑船（1853）的衝擊是兩百年複利的兌現**（[1853-黑船來航.md](1853-黑船來航.md)）。

$$\text{鎖國總帳} = \text{（和平紅利} \times 200\text{年）} - \text{（技術代差} \times \text{指數增長）}$$

**和平的複利是線性的，技術的複利是指數的**——鎖國的數學註定在工業革命面前破產。

## 破案時刻

- 1614：禁教令——迫害的體制化。
- 1616–1635：西班牙船限制、奉書船制、參勤交代——窗口的收窄。
- 1637–38：島原之亂——3.7 萬起義、12 萬鎮壓。
- 1639：葡萄牙船驅逐——鎖國完成。
- 1641：荷蘭商館移出島——四窗口體制定型。
- 1792–1808：拉克斯曼、列札諾夫、費頓號事件——俄英的叩關（鎖國的鬆動前兆）。

## 後果 -- 改變了什麼

- **政治**：主權完整＋和平延續——幕藩體制的外部保障。
- **經濟**：國內市場的深化——貨幣經濟、堂島期貨、飛腳網（鎖國的意外紅利）。
- **學術**：蘭學——荷蘭窗口的知識輸入（解體新書 1774、前野良澤、杉田玄白）；幕末開國的思想準備。
- **軍事**：技術代差的累積——黑船衝擊（1853）的結構性原因。

## 因素影響筆記

```
禁教（1614）＋島原（1637）──→ 外國—大名直連的危險確認
                                      ↓
1639 鎖國 ──┬──→ 四窗口（可控開放）──→ 蘭學＋風說書（過濾器）
            ├──→ 國內市場深化（紅利）
            └──→ 軍事代差累積（代價）──→ 1853 黑船
```

**偵探結語**：鎖國案件的真相是：**日本從未閉關，只是把對外關係國有化**。四個窗口是幕府的海關、情報站與提款機——兩百年的和平紅利是真的，技術代差的指數複利也是真的。當黑船帶著工業革命叩關，鎖國的總帳一次結清。
