# 1603-江戶幕府：二百六十年的和平工程

## 案件摘要

1603 年，德川家康任征夷大將軍、開設**江戶幕府**——此後至 1868（十五代），日本進入**二百六十年的和平**（Pax Tokugawa）。幕藩體制：幕府直轄（天領約 400 萬石）＋約 260 藩（大名領）——**中央—地方的封建聯邦**；士農工商身份制、參勤交代、寺請制——**全套社會控制工程**。這樁案件是「和平的組織技術」：如何用制度讓武士不打仗、讓大名不造反、讓社會不流動——二百六十年。

## 前因 -- 多因素的局勢

- **政治**：關原（[1600-關原之戰.md](1600-關原之戰.md)）的領地洗牌——親藩譜代外樣的地緣配置。
- **軍事**：大坂之陣（1614–15）滅豐臣——**最後的內戰**；此後無大規模戰爭。
- **經濟**：石高制＋檢地（秀吉遺產）——米本位的財政基礎。
- **思想**：朱子學（林羅山）官學化——「忠孝」的意識形態工程。

## 線索與推理 -- 因素咬合

### 線索一：參勤交代——「人質的經濟學」

1635 年武家諸法度確立**參勤交代**：大名隔年赴江戶、妻子留江戶為人質——表面是忠誠儀式，實質是**財政消耗工程**：

$$\text{大名的反叛能力} = \text{（領地財政）} - \text{（參勤成本）} - \text{（江戶邸宅成本）}$$

參勤的行列（數百至數千人）＋江戶屋敷的維持——**消耗大名財政的 50–70%**——造反的錢包先被掏空。附帶效果：五街道（東海道等）的整備、全國物資流動、江戶百萬人口消費都市的誕生——**控制工程意外催生全國市場**。

### 線索二：士農工商——「身份的凍結與和平的代價」

| 身份 | 職能 | 凍結機制 |
|---|---|---|
| 士（武士） | 統治、官僚 | 苗字帶刀、俸祿（知行／藏米） |
| 農 | 納稅（年貢） | 本百姓＋五人組連坐 |
| 工、商 | 生產流通 | 株仲間（公會） |

**武士官僚化**：無仗可打的武士變成藩的行政官——俸祿固定（藏米制）→ 通膨下實質所得下降 → **下級武士的貧困化**（幕末倒幕派的社會基礎）。身份凍結買了和平，**代價是二百年後的階級流動壓力鍋**。

### 線索三：寺請制與思想統制——「全民的思想戶籍」

寺請制（人人須屬一寺、領受寺請證文）——表面是禁教（[1549-天主教傳來.md](1549-天主教傳來.md)）的延續，實質是**全民戶籍＋思想審查**：

$$\text{統制密度} = \text{（寺請戶籍）} \times \text{（五人組連坐）} \times \text{（朱子學官學）} \times \text{（出版審查）}$$

**江戶日本是前近代組織密度最高的社會之一**——這套密度在和平時期維持秩序，在危機時期（幕末）成為動員的現成網絡（尊王攘夷的傳播走的正是寺子屋＋藩校網）。

## 破案時刻

- 1603：家康征夷大將軍——幕府開設。
- 1614–15：大坂冬夏之陣——豐臣滅亡（最後內戰）。
- 1615：武家諸法度（一國一城令）——大名的法制化。
- 1635：參勤交代制度化——和平工程的完成。
- 1639：鎖國完成（[1639-鎖國體制.md](1639-鎖國體制.md)）——對外窗口的壟斷。
- 1651：慶安之變（由井正雪）——浪人的不滿爆炸（和平的陰影）。

## 後果 -- 改變了什麼

- **政治**：二百六十年和平——前近代最長的內部和平之一；幕藩體制（聯邦式封建）。
- **經濟**：參勤交代 → 全國市場＋貨幣經濟——大坂堂島米市（世界最早的期貨市場）、飛腳（物流網）。
- **社會**：身份凍結 → 武士貧困化＋商人崛起（「金勝於刀」）——幕末的階級火藥。
- **文化**：元祿文化（[1688-元祿文化.md](1688-元祿文化.md)）、町人文化——和平的紅利；寺子屋識字率（世界最高之一）。

## 因素影響筆記

```
關原洗牌＋大坂滅豐臣 ──→ 1603 幕府 ──┬──→ 參勤交代（財政消耗）──→ 大名無力造反
                                      ├──→ 士農工商（身份凍結）──→ 和平＋貧困化
                                      ├──→ 寺請制（思想戶籍）──→ 統制密度
                                      └──→ 鎖國（1639）──→ 對外壟斷
```

**偵探結語**：江戶案件證明：**和平不是自然狀態，是昂貴的工程**——參勤交代掏空大名的錢包、身份制凍結社會的流動、寺請制登記每個人的思想。二百六十年的和平，是二百六十年的控制；而控制的每一條鋼索，都在幕末變成引信。
