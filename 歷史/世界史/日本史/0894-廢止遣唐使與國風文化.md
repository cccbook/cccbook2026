# 0894-廢止遣唐使：文化獨立的宣告與「移植休止符」

## 案件摘要

894 年，菅原道真以「唐國內亂、海路凶險」為由上奏**停派遣唐使**，朝廷准奏——持續約二百六十年的對唐制度採購正式終止。但偵探要指出：這不是文化閉關，而是**移植階段的完成宣言**。最後一批遣唐使（838）以來日本已「學滿畢業」；停止輸入後，貴族文化沒有枯萎，反而開出假名文學與國風文化的花——**移植→消化→變異**迴路（本卷核心命題）在此第一次完整走完。

## 前因 -- 多因素的局勢

- **政治（外部）**：唐自黃巢之亂（875–）與藩鎮割據走向崩解——「原始碼倉庫」本身著火，採購的動機消失。
- **財政**：遣唐使耗費巨大（造船、饋贈、隨行人員數百），而律令財政已因班田制鬆動而吃緊——每次出航都是一次財政冒險（838 年最後一批曾有溺死與漂流）。
- **制度**：大寶令（701）以降，官制、都城、律、曆、佛已安裝完畢——**邊際學習收益遞減**。
- **心理**：平等意識抬頭——桑原、高丘等請益僧記錄「唐土禮崩樂壞」的見聞，先進國濾鏡破裂。

## 線索與推理 -- 因素咬合

### 線索一：真正的殺手不是道真的奏章，是「學費的邊際效用」

用本卷的移植模型來看：

$$\text{繼續派遣的淨收益} = \underbrace{\text{新知識增量}}_{\downarrow \text{已學滿}} - \underbrace{\text{使節成本}}_{\uparrow \text{財政吃緊}} - \underbrace{\text{海難風險}}_{\uparrow \text{航路凶險}} < 0$$

菅原道真只是把這條不等式寫成奏章。**偵探的推論**：廢止不是「鎖國」的先聲，而是移植曲線的飽和點——唐代制度的「本地編譯」已經完成，繼續輸入原始碼反而會干擾本地版本。

### 線索二：停輸入之後為何反而開花？——假名的「在地編譯」

停止輸入後的三十年內，輸出反而爆炸：

| 年代 | 成果 | 「本地編譯」在哪裡 |
|---|---|---|
| 905 | 《古今和歌集》 | 漢詩的格律 → 假名五七調 |
| 約935 | 《土佐日記》 | 男用漢文 → 女性假名日記 |
| 約1008 | 《源氏物語》 | 唐傳奇 → 平安宮廷心理小說 |
| 928– | 假名書法成熟 | 楷書 → 假名「女手」美學 |

**因果鏈**：輸入漢字 → 貴族女性被排除在漢文教育外 → 她們用假名寫作 → **被排除者成為創新者**。移植的技術（假名脫胎於漢字草書）經過「制度外的手」變異，長出原創文化——這與戰國鐵炮（[1543-鐵炮傳來.md](1543-鐵炮傳來.md)，一年國產化）是同一條變異鏈的古代版。

### 線索三：894 與 1543 的鏡像——「停止採購」何時是自信、何時是災難？

對照本卷另一樁「停輸入」案：1639 鎖國（[1639-鎖國體制.md](1639-鎖國體制.md)）。三次停輸入的判決：

| 事件 | 停止什麼 | 判決 | 條件 |
|---|---|---|---|
| 894 廢遣唐使 | 制度輸入 | 自信的畢業 | 已有替代動能（假名、莊園經濟） |
| 1549→1587 禁天主教 | 宗教輸入 | 防禦的取捨 | 保留荷蘭書籍管道（蘭學） |
| 1639 鎖國 | 全面輸入 | 混合：穩定＋欠債 | 代差在兩百年後兌現（黑船） |

**規律**：停輸入是好是壞，取決於**內部是否還有消化與變異的引擎**。894 有引擎（學問僧與貴族的在地創作），故為佳話；1639 的引擎仍在轉（蘭學）但代差已開始累積。

## 破案時刻

- 838：最後一批正式遣唐使出航，沿途海難與漂流。
- 875–：黃巢之亂，唐帝國崩解進行式。
- 894.9：菅原道真奏請停派遣唐使；朝廷准。
- 905：《古今和歌集》敕撰——國風文化在「斷奶」後開花。
- 901：道真失勢左遷大宰權帥（昌泰之變）——停航與政爭同時代的註腳。

## 後果 -- 改變了什麼

- **文化**：國風文化全速展開——假名文學、和樣建築、浄土美術——「移植休止符」變成原創的起跑線。
- **政治**：與大陸政權的正常外交斷線，東亞冊封網中的日本位置懸空——直到 1404 足利義滿受明冊封才恢復。
- **資訊**：留學生管道關閉後，知識老化與斷層出現（宋錢、宋禪後來以民間商路補課）——埋下鐮倉新佛教「自我更新」的伏筆。
- **模式**：「移植→消化→變異→再輸出」迴路首次完整驗證，成為本卷解讀明治（[1868-明治維新.md](1868-明治維新.md)）與戰後（[1955-戰後經濟奇蹟.md](1955-戰後經濟奇蹟.md)）的原始模板。
