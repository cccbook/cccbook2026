# 1839-鴉片戰爭與朝貢體系崩解

## 案件摘要
1839 年林則徐虎門銷煙 → 1840-42 鴉片戰爭 → 1842《南京條約》：五口通商、割香港、賠款 2100 萬銀元、協定關稅——東亞秩序的「條約化」開始。這樁「條約」案件的偵辦重點：**朝貢體系 vs 條約體系**的結構較量（濱下武志：兩種國際秩序的碰撞）；費正清的「衝擊-回應」模式與柯文（Paul Cohen）《在中國發現歷史》的批判——「西方衝擊」的敘事 vs 東亞內部的動能。南京條約的連鎖：日本（1853 案黑船）、朝鮮（1876 案江華島）、越南（1883-84 法國）——**條約體系的東亞擴散**——朝貢體系的千年終局。

## 前因 -- 為什麼會有這個案子
- **鴉片貿易的結構**：英國的貿易逆差（茶葉絲綢）→ 鴉片東運（孟加拉）——「貿易失衡的白銀外流」（1545 案的英國版：白銀外流的方向反轉）。
- **禁煙的政治**：1839 虎門銷煙（林則徐）——「主權 vs 貿易」的衝突。
- **軍事的代差**：英軍的蒸汽船（復仇女神號）+ 步槍炮 vs 清的水師——「軍事革命」（1543 案的英國版）的代差。
- **朝貢體系的結構**：天朝的「不平等對等」（朝貢 = 華夷）vs 西方的條約平等（對英國而言）——「秩序結構的衝突」。

## 線索與推理 -- 數學式、理論、表格

### 線索一：朝貢體系 vs 條約體系
濱下武志的兩種秩序結構：

| | 朝貢體系 | 條約體系 |
|---|---------|---------|
| 原則 | 華夷（垂直）| 主權平等（水平，名義上）|
| 關係 | 冊封 + 朝貢 + 受市 | 條約 + 最惠國 + 領事裁判 |
| 經濟 | 朝貢貿易（執照制）| 通商條約（口岸制）|
| 正當性 | 王位認證（外購）| 條約的互認 |

**推理**：南京條約 = 「條約體系」對「朝貢體系」的取代——「協定關稅 + 領事裁判 + 最惠國」的條約三件套——**東亞國際秩序的結構轉換**——1895 案甲午（朝貢的最後一角：朝鮮宗主權的終結）——千年華夷秩序的終局。

### 線索二：費正清 vs 柯文的史學辯論
| | 費正清（1954）衝擊-回應 | 柯文（1984）中國中心觀 |
|---|------------------------|------------------------|
| 敘事 | 西方衝擊 → 中國回應 | 中國內部的動能 |
| 框架 | 傳統 vs 現代 | 內部演化 + 外部衝擊的互動 |
| 批判 | 西方中心（現代化理論）| 「衝擊-回應」的低估內部 |

**推理**：鴉片戰爭的兩種史學框架——「衝擊-回應」（西方現代化的單向擴散）vs「中國中心」（內部演化 + 外部的局部影響）——**史學框架 = 解釋的選擇**——本書採「東亞網絡」的中間立場（內部動能 + 外部衝擊 + 域內互動）——東亞史的方法論辯論。

### 線索三：白銀外流的反向
1840s 的白銀外流（鴉片貿易）：

$$\text{茶絲出口} < \text{鴉片進口} \implies \text{白銀外流} \implies \text{銀貴銅賤} \implies \text{農民稅負加重}$$

**推理**：白銀外流（1545 案波托西的流入 → 1840s 的流出——白銀流向的反轉）→ 銀貴錢賤 → 農民以銅錢繳稅的實際負擔加重——「貨幣流動 = 社會負擔」——鴉片戰爭前的社會危機（太平天國 1851 的經濟土壤）。

### 線索四：條約體系的東亞擴散
南京條約的連鎖：

| 年份 | 事件 | 條約體系的擴散 |
|------|------|----------------|
| 1842 | 南京條約（清）| 五口、領事裁判 |
| 1854 | 日美和親（日）| 開港（1853 案）|
| 1858 | 天津條約、安政五國 | 開港的擴大 |
| 1876 | 江華島條約（日-朝鮮）| **日本 = 條約體系的執行者** |
| 1883-84 | 順化條約（法-越）| 法屬印度支那 |

**推理**：條約體系的東亞擴散——日本（1868 案後）成為條約體系的「執行者」——「被條約者 → 締條約者」的翻轉（1876 江華島是日本對朝鮮的第一個不平等條約）——**帝國主義的亞洲化**的開始。

## 結案 -- 後果與影響
- **朝貢體系的條約化**：華夷 → 主權條約——千年秩序的結構轉換——1895 案甲午的終局。
- **內部重構的壓力**：太平天國（1851-64）、洋務運動（1861-）——「戰敗的內部重構」。
- **日本的覺醒**：鴉片戰爭的消息（1842 魏源《海國圖志》傳日）——「他人的失敗 = 自己的教材」——1853 案黑船的「前車之鑑」。
- **帝國主義亞洲化的開始**：日本 1876 案對朝鮮的條約——「被條約者 → 締條約者」——1905 案日俄戰爭的帝國化。
- **史學的框架辯論**：衝擊-回應 vs 中國中心觀——東亞史的方法論（本書的「網絡視角」的來源）。
