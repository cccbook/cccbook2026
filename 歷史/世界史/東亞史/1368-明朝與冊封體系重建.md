# 1368-明朝與冊封體系重建

## 案件摘要
1368 年明朝建立，洪武帝重建冊封體系：朝鮮（1392 李朝）、日本（1404 勘合貿易）、琉球、占城、暹羅——「海禁 + 勘合」的組合：民間海貿被禁，朝貢（勘合符）成為**貿易執照**。1405-1433 鄭和七下西洋——海權的頂點與撤退。這樁「勘合」案件的偵辦重點：濱下武志的**朝貢貿易體系**理論——朝貢不只是儀式，而是「貿易的執照制度」：勘合符 = 貿易許可證——東亞的國際經濟秩序以冊封為殼、貿易為實。琉球的「萬國津梁」（1428 鐘銘）是這張網絡的中轉節點——近世東亞秩序（貿易網 + 冊封）的重心。

## 前因 -- 為什麼會有這個案子
- **元末的秩序真空**：蒙古和平（1274 案）的崩解——倭寇（14 世紀的前期倭寇：高麗沿岸）+ 群雄割據——「海上的無秩序」。
- **朱元璋的設計**：海禁（1371 禁瀕海民私通外國）+ 冊封——「以秩序換控制」——「祖訓」的定位（15 不征之國）。
- **倭寇的壓力**：14 世紀前期倭寇（高麗、山東沿岸）——「海禁 = 防倭」的軍事動機。
- **足利義滿的轉向**：1392 統一南北朝（南北朝合一）→ 1404 接受勘合（「日本國王」冊封）——「稱臣換貿易」的政治決斷。

## 線索與推理 -- 數學式、理論、表格

### 線索一：勘合 = 貿易執照
濱下武志的「朝貢貿易體系」：朝貢的實質是**貿易的許可制度**：

| 層面 | 制度 | 實質 |
|------|------|------|
| 形式 | 冊封、朝貢、表文 | 政治儀式 |
| 實質 | 勘合符、貢期、貢道、回賜 | 貿易的配額與許可 |
| 經濟 | 貢物+回賜的差額、隨貢貿易 | 利潤的官方壟斷 |

**推理**：勘合符 = 貿易執照——「入貢的權利」是稀缺資源（貢期、船數、人數都受限）——朝貢 = 官方壟斷的貿易（民間被禁）——**冊封體系 = 貿易執照制度**（濱下的核心：東亞的國際秩序以朝貢為殼、貿易為實）——對照西方條約體系（1839 案）的結構差異。

### 線索二：琉球 = 萬國津梁的中轉
1428 年琉球鐘銘「萬國津梁」（四海的橋樑）——琉球的中轉貿易：

$$\text{琉球} = \text{明（勘合）} + \text{日本（薩摩 1609 後兩屬）} + \text{東南亞（暹羅、爪哇）}$$

**推理**：小國的「中轉貿易」策略——琉球以「明冊封 + 東南亞轉口」維持繁榮（15 世紀的中轉帝國）——1609 薩摩入侵（兩屬的開始）——**小國的生存技術：多重冊封與中轉**——冊封體系內的「節點國家」。

### 線索三：鄭和下西洋的頂點與撤退
1405-1433 鄭和七下西洋（寶船、朝貢擴大）：

| 面向 | 內容 |
|------|------|
| 規模 | 240+ 船、2.7 萬人（寶船的官方海軍）|
| 目的 | 冊封擴大、朝貢網、威懾 |
| 撤退 | 1433 後停止——財政與文官的反對 |

**推理**：鄭和的撤退 = 「朝貢的擴張極限」——海軍的維持成本 > 朝貢的收益（朝貢是「政治經濟」非「利潤經濟」）——**帝國的海洋撤退**（對照同期葡萄牙的東進——「利潤經濟」的海權）——東亞與歐洲海洋史的「分岔」（1498 案達伽馬的對照：利潤驅動 vs 政治驅動）。

### 線索四：海禁的結構病
海禁的「結構病」：民間海貿被禁 → 走私（倭寇的商業面——嘉靖倭寇 16 世紀：中國海商為主體的「倭寇」）——「禁令製造走私」：

$$\text{海禁} \to \text{貿易需求不滅} \to \text{走私（倭寇化）} \to \text{武力鎮壓} \to \text{更深的走私}$$

**推理**：海禁是「需求不滅下的禁令」——嘉靖大倭寇（1547-1565，王直等中國海商為主體）是海禁的結構產物——1567 隆慶開關（月港開放）——「禁令 → 走私 → 開放」的循環（1603 案江戶鎖國的對照：日本選擇「四口壟斷」而非全面封閉）。

## 結案 -- 後果與影響
- **近世東亞秩序的重心**：明中心 + 勘合貿易——「朝貢 = 貿易執照」的秩序（濱下武志）——清繼承（1644-1895）——直到 1839 案鴉片戰爭的條約化。
- **琉球的兩屬與繁榮**：中轉貿易（萬國津梁）→ 1609 薩摩入侵的兩屬——「小國的多重冊封」。
- **倭寇的結構產物**：海禁 → 走私（王直）——「禁令製造海盜」的循環——1592 案壬辰倭亂的海上背景。
- **海洋的分岔**：鄭和撤退（政治驅動）vs 葡萄牙東進（利潤驅動）——東亞與歐洲海洋史的「分岔點」——1498 案的世界體系之門。
- **冊封的地圖**：朝鮮、琉球、占城、暹羅、日本（1404-1547）——「冊封圈」的近世地圖——1868 案日本脫離的伏筆。
