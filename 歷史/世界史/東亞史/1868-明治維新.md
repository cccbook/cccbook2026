# 1868-明治維新

## 案件摘要
1868 年王政復古與戊辰戰爭 → 1871 廢藩置縣 → 1872 學制 → 1873 徵兵令與地租改正——日本的「國家改造」：廢藩置縣（-221 案秦郡縣制的日本版）、學制、徵兵、地租——制度套裝的整體移植（645 案大化改新的第二次展演——這次從唐換成西洋）。這樁「維新」案件的偵辦重點：**制度套裝移植的第二次展演**（大化改新 645 案的千年前例——「套裝移植 + 吸收調整 + 法典化」）；**發展型國家的誕生**（Chalmers Johnson 1982《通產省》——國家主導的產業化）；岩倉使節團（1871-73）的實地考察——「移植的實地驗證」。福澤諭吉「脫亞論」（1885）——東亞秩序的日本翻轉。

## 前因 -- 為什麼會有這個案子
- **幕末的外壓**（1853 案）：黑船 → 條約 → 攘夷的失敗實證（薩英、下關）——「開國 + 討幕」的轉向。
- **藩的財政疲弊**：參勤交代（1603 案）的財政壓縮 + 天保飢荒——「藩制的破產」。
- **蘭學的人才儲備**（1774 案）：蘭學塾的技術官僚候補（適塾的福澤諭吉）——「人才庫」。
- **薩長的軍事優勢**：薩英（1863）、下關（1864）的「敗者學習」——薩長的西洋軍制（常備軍 + 采買）。

## 線索與推理 -- 數學式、理論、表格

### 線索一：制度套裝的移植清單（第二次）
明治維新的「制度套裝」（對照 645 案大化改新）：

| 領域 | 1871-73 的移植 | 模板 |
|------|----------------|------|
| 中央 | 廢藩置縣（廢 261 藩 → 3 府 72 縣）| 郡縣制（-221 案秦）|
| 軍事 | 徵兵令（1873）——全民皆兵 | 法國/普魯士軍制 |
| 教育 | 學制（1872）——全民義務教育 | 法國學制 |
| 稅制 | 地租改正（1873）——地價 3% 貨幣稅 | 近代財政 |
| 官制 | 太政官制 → 內閣制（1885）| 西洋官僚制 |

**推理**：制度套裝移植的第二次展演——大化改新（645，唐化）→ 明治維新（1868，西化）——「套裝移植 + 吸收調整 + 法典化」（大日本帝國憲法 1889——普魯士憲法的調整版）——**日本模式的元結構**：「敗者/後進者的套裝移植」。

### 線索二：發展型國家的誕生
Chalmers Johnson（1982）《通產省》的「發展型國家」：

| 要素 | 內容 |
|------|------|
| 國家主導 | 通產省的產業政策（殖產興業）|
| 官僚主導 | 官僚的經濟計畫（不是市場也不是計畫）|
| 出口導向 | 貿易立國 |
| 教育 | 義務教育（學制 1872）的先投資 |

**推理**：發展型國家 = 「官僚主導的市場經濟」（-1917 案計畫經濟的中間解）——「國家主導 + 市場機制 + 出口導向」——明治的「殖產興業」（官營工廠 → 民間出售——政府做種子）——**發展型國家的原型**（韓國漢江、台灣奇蹟的模板——1965 案）。

### 線索三：岩倉使節團——移植的實地驗證
1871-73 岩倉使節團（48 人、22 個月、美歐）：

| 觀察 | 結論 |
|------|------|
| 美歐的工業 | 「富國強兵 = 產業 + 軍事」 |
| 憲政 | 憲法的選型（普魯士 → 1889 憲法）|
| 教育 | 義務教育的效應 |
| 軍制 | 陸軍普魯士、海軍英國 |

**推理**：岩倉使節 = 「移植的實地驗證」——制度的「選型」（不是全面英式，而是混合選型：普魯士憲法、法國民法、英國海軍、美國教育）——**移植 = 選型 + 調整**（不是照抄，是工程選型）——制度移植的方法論。

### 線索四：脫亞論與民族構建
福澤諭吉「脫亞論」（1885《時事新報》）：

$$\text{「文明開化」} = \text{西洋的標準} \implies \text{「脫亞」} = \text{離開「劣等」的東亞} \implies \text{帝國的路線}$$

**推理**：脫亞論 = 「文明的等級」的接受（西方中心 + 自我改造）——安德森的民族構建（想像的共同體的日本版：天皇中心）——**「文明 = 西洋」的等級接受 → 帝國的路線**——1895 案甲午、1910 案合併的意識形態基礎——「脫亞 → 入帝」的路線。

## 結案 -- 後果與影響
- **條約改正**：1894 日英通商航海條約（領事裁判權廢除）——主權的回復——東亞第一個「條約體系內的成功者」。
- **東亞的知識重心轉移**：留學日本（梁啟超、金玉均後繼者）——「勝者學習」的東亞化——1895 案後的留日潮。
- **發展型國家的模板**：通產省 → 韓國漢江、台灣奇蹟（1965 案）——「國家主導的出口導向」的東亞模式。
- **帝國的路線**：脫亞 → 入帝（1895、1905、1910 案）——「文明的等級 → 帝國主義」的意識形態鏈。
- **-221 案的日本對照**：廢藩置縣 = 郡縣制的日本版——「去封建化」的東亞兩次（秦 221、明治 1871）——中央集權的東亞公式。
