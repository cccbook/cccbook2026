# 1997-亞洲金融風暴

## 案件摘要
1985 廣場協議（日圓升值 2 倍）→ 日本泡沫（1986-90 地產股價暴漲）→ 泡沫破裂（1990-，「失落的十年」）；1997/7/2 泰銖崩潰 → 亞洲金融風暴（韓國 IMF 584 億美元、印尼、泰國）——「漢江奇蹟的急剎車」。這樁「危機」案件的偵辦重點：**雁行的極限**（1965 案的轉折）；**金融自由化的風險**（短期外債 + 釘住匯率的結構病）；**IMF 的結構調整**——「危機 = 模式的再評價」——東亞模式（1965 案）的轉型：韓國的 IT 轉型（三星）、金融改革、清邁倡議（2000，東亞金融合作）。

## 前因 -- 為什麼會有這個案子
- **廣場協議**（1985）：日圓升值（240 → 120）——「匯率的協調升值」——日本的泡沫動機（出口受挫 → 內需與地產的放水）。
- **日本泡沫**（1986-90）：低利率 + 地產與股票暴漲（日經 38915）——「泡沫的結構」——1990- 的破裂（「失落的十年」）。
- **短資的流入**（1990s）：東亞的短期外債（外資銀行的短資）+ 釘住美元的匯率——「雙重錯配」（短借長投 + 匯率錯配）。
- **泰銖的防衛**：1997/5-7 的外匯防衛失敗——「崩潰的導火線」。

## 線索與推理 -- 數學式、理論、表格

### 線索一：雙重錯配的結構
1997 的「雙重錯配」：

$$\text{短借（外資的短期外債）} + \text{長投（國內的固定投資）} + \text{釘住匯率} = \text{危機的結構}$$

**推理**：「雙重錯配」（期限錯配 + 匯率錯配）——短期外資的抽逃 → 匯率崩潰 → 銀行的外債惡化 → 企業破產——「金融自由化的結構病」——Kruger? 不——Krugman（1998）的「亞洲神話」批判：投入驅動（非 TFP）的增長——**雁行的極限**（1965 案模式的轉折）。

### 線索二：廣場協議 → 泡沫 → 失落的十年
日本的鏈條：

| 階段 | 事件 | 效果 |
|------|------|------|
| 1985 | 廣場協議（日圓升值 2 倍）| 出口的受挫 → 內需的放水 |
| 1986-90 | 低利率 + 地產股價暴漲 | 泡沫（日經 38915）|
| 1990- | 利率回升 → 泡沫破裂 | 「失落的十年」（地產與銀行的壞帳）|

**推理**：廣場協議 → 泡沫 → 失落——「匯率協調的意外後果」——「升值 → 放水 → 泡沫」——**匯率政策的結構風險**——「失落的十年」——「奇蹟的終局」（1965 案的轉折）。

### 線索三：IMF 的結構調整與模式的轉型
IMF（584 億美元）的條件與韓國的轉型：

| 面向 | IMF 條件 | 韓國的轉型 |
|------|---------|-----------|
| 金融 | 銀行的重整與開放 | 金融改革 + 外資 |
| 財閥 | 大宇的解體（1999）| 財閥的重組（三星的集中）|
| 匯率 | 浮動匯率 | 彈性匯率 |
| 結果 | 「IMF 時代」的陣痛 | IT 轉型（2000s 三星的世界頂點）|

**推理**：IMF = 「外部強制的改革」（1868 案明治的「外力版」金融版）——「危機 → 改革」的結構——**模式的轉型**（官治金融 → 市場金融 + IT）——「危機 = 轉型的催化」（三星的 IT 頂點——漢江奇蹟的第二幕）。

### 線索四：東亞金融合作的誕生
清邁倡議（2000）：

$$\text{1997 危機} \implies \text{「亞洲貨幣基金」的構想（失敗）} \to \text{清邁倡議（雙邊換匯 → 2010 多邊化）}$$

**推理**：危機 → 金融合作（清邁倡議的多邊化 2010——2400 億美元的換匯網）——「東亞金融合作的誕生」——「區域 = 金融防衛」（IMF 之外的區域安全網）——**東亞的「共同體」化**（金融的合作——東亞共同體的經濟基礎之一）。

## 結案 -- 後果與影響
- **雁行的轉折**：短資與錯配的結構病——「模式的再評價」——1965 案東亞模式的轉型。
- **日本的失落的十年**：泡沫 → 壞帳 → 通縮——「匯率協調的意外後果」——「安倍經濟學」（2012）的伏筆。
- **韓國的 IT 轉型**：IMF → 改革 → 三星的頂點——「危機 = 轉型的催化」——漢江奇蹟的第二幕。
- **東亞金融合作**：清邁倡議 → 多邊化——「區域 = 金融防衛」——東亞共同體的經濟基礎。
- **「亞洲神話」的辯論**：Krugman 的批判（投入驅動 vs TFP）——「東亞模式的辯論」——模式的再評價。
