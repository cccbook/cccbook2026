# 1969 ARPANET

## 案發現場

1969 年 10 月 29 日晚，加州大學洛杉磯分校（UCLA）。研究生克萊恩羅克（Leonard Kleinrock）的團隊把一台「介面訊息處理器（IMP）」——第一台 ARPANET 節點交換機——連上終端，向六百公里外史丹佛研究所（SRI）的第二台節點傳輸第一則訊息。他們想輸入「LOGIN」：打出 L、O 兩個字母後，**系統當機**。第一次傳輸只送出了兩個字元——史上第一則網路訊息，是「LO」。

兩個月內四個節點（UCLA、SRI、猶他大學、UCSB）互聯。**ARPANET**——網際網路的前身——誕生了。

它的母體是冷戰：1958 年史潑尼克危機（[1957-史潑尼克.md](1957-史潑尼克.md)）後，美國國防部成立 ARPA（高級研究計畫署）。1960 年代 ARPA 的利克萊德（J.C.R. Licklider）提出「星際網路（Intergalactic Network）」構想：把全國的電腦連成網路，讓研究者共享運算力。**電腦開始互聯，網絡化的迴路起點。**

## 偵查過程

**線索一：理論——封包交換。** 當時的通訊用「電路交換」（電話模式）：通話前建立專用線路，頻寬被獨佔。兩位研究者獨立提出「**封包交換（packet switching）**」：把訊息切成小封包，每個封包自帶地址、獨立路由、可走不同路徑——線路被共享、效率暴增、部分節點損毀網路仍存活。蘭德公司的巴倫（Paul Baran）從核戰生存的通訊需求出發（1964）；英國 NPL 的戴維斯（Donald Davies）從分時系統的需求出發——兩條路線匯合，與 [1926-薛丁格方程.md](1926-薛丁格方程.md) 的雙路線偵破同型。

**線索二：IMP 與第一代路由。** ARPA 把封包交換物化為硬體：每個節點放一台 IMP（由 BBN 公司建造，用 Honeywell 小型機改裝），主機電腦只管產生訊息，IMP 負責路由——**功能分層**的設計成為網路架構的模板。

**線索三：TCP/IP 的統一。** ARPANET 的早期協議（NCP）只能連 ARPANET 自己。瑟夫（Vint Cerf）與康恩（Bob Kahn）1974 年發表 TCP/IP：讓**不同網路互聯**（internetworking）——「網際網路（Internet）」之名由此而來。1983 年 1 月 1 日 ARPANET 全面切換到 TCP/IP，成為網際網路的真正生日。

**線索四：從軍用迴路到公共迴路。** ARPANET 初期只有四個節點、服務軍方資助的研究者；1980 年代大學全面接入；1989 年蒂姆·伯納斯-李（Tim Berners-Lee）發明 [1989-全球資訊網.md](1989-全球資訊網.md)，1991 年 ARPANET 正式退役——軍用迴路的副產品，成為全球公共知識迴路。與 [1946-ENIAC.md](1946-ENIAC.md)、[1940-雷達.md](1940-雷達.md) 一樣：**戰爭與冷戰催生的技術，戰後流向民間，成為下一幕的燃料。**

## 結案報告

ARPANET 屬於迴路的**技術⚙**環節——電腦開始互聯，網絡化的迴路起點。其深遠遺產：

1. **迴路的網絡化**——第九幕的起點：每個節點既是使用者也是貢獻者，「理論—實驗—技術」循環從精英機構擴散為全球網絡。
2. **封包交換成為通訊的通用語言**——電話網、電視網逐步被 IP 網吞併，[1970-光纖.md](1970-光纖.md) 提供物理載體，[1948-夏農資訊論.md](1948-夏農資訊論.md) 提供理論極限。
3. **冷戰技術的民間擴散**——ARPA 模式（高風險、長週期、資助基礎研究）成為科技政策的模板。
4. **「LO」的方法論教訓**——第一次傳輸當機，網路卻從故障中長出來：容錯設計（部分節點損毀仍存活）不僅是工程特性，也是迴路本身的特性。

## 證據與工具

```python
# 偵查證物一：封包交換 vs 電路交換 — 頻寬的帳本
bandwidth_Mbps = 10
# 電路交換：通話獨佔線路
calls_simultaneous = bandwidth_Mbps / 0.064   # 每通話 64 kbps
# 封包交換：訊息切包、統計復用（利用率約 90%）
packets_capacity = bandwidth_Mbps / 0.064 * 0.9
print("--- 頻寬帳本 ---")
print(f"電路交換：{calls_simultaneous:.0f} 路通話（獨佔線路）")
print(f"封包交換：{packets_capacity:.0f} 路等效流量（統計復用）")

# 偵查證物二：網路成長 — 從 4 個節點到全球
import math
nodes = {1969: 4, 1971: 23, 1973: 40, 1981: 213, 1989: 100000, 2020: 5e9}
print("\n--- ARPANET/網際網路節點數 ---")
for y, n in nodes.items():
    print(f"{y}: {n:.0e} 台主機/裝置")
print("從 4 個節點到 50 億台裝置 —— 網絡化迴路的指數曲線")

# 偵查證物三：容錯 — 部分節點損毀仍存活
alive_ratio = 0.7   # 假設 30% 節點損毀
print(f"\n核戰生存設計：{alive_ratio*100:.0f}% 節點存活 → 網路仍可路由（封包繞道）")
print("「LO」當機的教訓：容錯不僅是工程特性，也是迴路本身的特性")
```
