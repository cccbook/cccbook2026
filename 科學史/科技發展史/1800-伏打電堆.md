# 1800 伏打電堆

## 案發現場

萊頓瓶（[1745-萊頓瓶.md](1745-萊頓瓶.md)）讓電學實驗可以儲存，但它有兩個致命缺陷：**用完要重新摩擦充電**，而且**放電是瞬間的**——電流像閃電，一閃而過。要研究「電流」這種連續現象（電解、連續導電、穩定磁場），萊頓瓶力不從心。**電學實驗的邊界，再次被技術卡死。**

線索來自一場著名的學術爭論：1791 年，波隆那的解剖學家伽伐尼（Luigi Galvani）發現，用銅鉤掛著蛙腿、接上鐵欄杆時，蛙腿會抽搐。他宣布這是「動物電」——生物體內自帶電。物理學家**伏打（Alessandro Volta, 1745–1827）**起初讚嘆，隨即起疑：**蛙腿為什麼總在兩種不同金屬之間抽搐？**

## 偵查過程

**第一步：受控對照實驗。** 伏打用系統的對照實驗偵訊伽伐尼的證詞：同樣的蛙腿，只用一種金屬——不抽搐；用兩種不同金屬接觸——抽搐；換不同金屬配對——抽搐強度不同。他推出結論：**電不是來自蛙腿，而是來自兩種不同金屬的接觸**——蛙腿只是最敏感的「驗電器」。1794 年起他公開反駁伽伐尼：

> 「金屬接觸生電，蛙腿只不過是把電顯示出來的靈敏儀器。」

**第二步：甩掉動物。** 為了徹底驗證，伏打做了決定性的一步：**完全不用動物**。他發現用濕紙板代替蛙腿、金屬配對照樣生電——「動物電」被處決，電的來源是純粹的物理接觸。

**第三步：物化為電堆。** 1800 年，伏打把推理推向極致：一對金屬生電太弱，那就**疊很多對**。他把鋅片、銅片（或銀片）與浸鹽水的紙板**交替疊成塔狀**——這就是「**伏打電堆（voltaic pile）**」，人類第一個**穩定、連續的電源**。他在給皇家學會主席的信中寫下這套裝置的宣言：

> 「這個裝置不需要任何動物，也不需要摩擦起電——它會源源不絕地供電，像電的蓄水池。」

**迴路的點火。** 電堆公布後數週內，尼科爾森與卡萊斯爾（1800）用它**電解水**，分解出氫與氧——人類第一次用電分解物質，直接驗證了拉瓦錫（[1789-拉瓦錫定量革命.md](1789-拉瓦錫定量革命.md)）的水成分理論；戴維（1807–08）用它電解出鉀、鈉、鈣等**六種新元素**；奧斯特（1820）用它發現電流使磁針偏轉——**電生磁**，通往法拉第（[1831-法拉第電磁感應.md](1831-法拉第電磁感應.md)）與電磁大循環。伏打的電壓單位（伏特）以他命名。

## 結案報告

1. **第一個穩定電源**——電學實驗從「瞬間放電」變成「連續電流」，電解、電磁學、電化學全部由此起跑。
2. **「動物電」被處決**——受控對照實驗再次戰勝神秘主義；電的來源是物理的，不是生物的。
3. **迴路意義（第五幕的點火器）**——技術（電堆）→ 實驗（電解水、電解出元素、電生磁）→ 新理論（電化學、電磁學）→ 新技術（電鍍、電報、電機）——這是金觀濤所說迴路「升級」的典範：工具改變實驗邊界，實驗改變理論邊界。
4. **爭論的生產力**——伽伐尼與伏打的論戰不是內耗，而是迴路：解剖學的觀察（實驗）逼出物理學的新理論，理論再物化為電堆。**學科之間的爭論，正是迴路加速的另一種形式。**

## 證據與工具

```python
# 伏打電堆的「電壓帳本」：疊加的威力

# 單一電對的電動勢（接觸電位差，近似值）
E_Zn_Cu = 0.9   # 鋅-銅對約 0.9 V（鹽水電解液中）
E_Zn_Ag = 1.0   # 鋅-銀對約 1.0 V

print("--- 伏打的原偵查：對照實驗邏輯 ---")
tests = [("蛙腿 + 一種金屬", "不抽搐"),
         ("蛙腿 + 兩種不同金屬", "抽搐"),
         ("濕紙板 + 兩種不同金屬（無動物）", "照樣生電")]
for cond, result in tests:
    print(f"{cond:30s} -> {result}")
print("=> 電來自金屬接觸，不是動物：『動物電』被處決\n")

# 電堆：N 對金屬疊加，電壓相加
print("--- 電堆的疊加 ---")
for n in [1, 10, 30, 60]:
    print(f"{n:2d} 對鋅-銅：總電壓 {n*E_Zn_Cu:.1f} V")

# 尼科爾森與卡萊斯爾的電解水：電流分解物質
# 2H2O -> 2H2 + O2（陰極出氫，陽極出氧，體積比 2:1）
print("\n--- 電解水（1800，電堆的第一次實驗）---")
charge = 96500  # 1 法拉第電量 C
moles_H2 = charge / (2*96500)  # 電解 1 F 電量得 0.5 mol 氫
moles_O2 = charge / (4*96500)  # 得 0.25 mol 氧
print(f"通 {charge:.0f} C 電量：得氫 {moles_H2:.2f} mol、氧 {moles_O2:.2f} mol")
print(f"體積比 H2:O2 = {moles_H2/moles_O2:.0f}:1")
print("=> 電流首次分解物質，驗證拉瓦錫的水成分理論")
print("=> 電堆讓實驗從『瞬間』變成『連續』：第五幕電磁大循環的點火器")
```
