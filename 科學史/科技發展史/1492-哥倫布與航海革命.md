# 1492 哥倫布與航海革命

## 案發現場

1492 年 8 月 3 日，克里斯多福·哥倫布（Christopher Columbus, 1451–1506）率三艘帆船從西班牙帕洛斯港出發，向西橫渡大西洋。10 月 12 日凌晨，巴哈馬群島的陸地出現在月光下。

案發現場的知識處境是一場**理論與現實的衝突**。當時的歐洲地理學（基於托勒密《地理學》與教會的世界觀）認為：歐亞大陸以西是浩瀚大洋，直達亞洲則路途遙不可及；哥倫布卻根據《馬可波羅遊記》與托斯卡內利的信件，主張西航到日本與中國只要幾週。

謎團的核心：**雙方都引用「理論」，誰對誰錯，如何裁決？**答案出人意料——不是學院辯論，而是**實際航行**。而且雙方都算錯了地球的周長：哥倫布低估了近三分之一，幸而中途撞上了美洲。

## 偵查過程

哥倫布的「偵查」是一次技術與理論的正面交鋒：

1. **理論的推算**：哥倫布採納的地球周長約 28,000 公里（比真值 40,000 公里小得多），並高估了亞洲向東延伸的距離。據此算出西航日本僅約 4,400 公里——一個「紙上可達」的距離。
2. **技術的支撐**：十五世紀葡萄牙發展出的**卡拉維爾帆船**（caravel）——三角帆與橫帆混裝，可逆風行駛（搶風調向）；**羅盤**（磁針指向，原理見 [1600-吉爾伯特磁學.md](1600-吉爾伯特磁學.md)）；**象限儀與星盤**測量緯度；**航位推算法**（dead reckoning）估算航程。沒有這些，任何理論都是空談。
3. **航行即實驗**：哥倫布的航海日誌詳錄每日航向、航速、風向、海況——這是一次系統的、有紀錄的「自然檢驗」。途中他遇到羅盤磁偏角（磁北偏離真北）的異常，船員恐慌，他卻記錄並調整——**對異常數據的敏感**，正是實驗態度的萌芽。
4. **理論被航行「部分證偽」**：西航的距離遠超估算——若非美洲擋路，船隊必將全滅於大洋。但哥倫布至死堅稱所到之處是亞洲邊緣——**理論可以被實驗否定，但人不一定接受**。這一課，要等第二幕的科學社群（印刷術傳播的公共辯論）才學會。

## 結案報告

哥倫布西航的深遠影響：

1. **地理學革命**：美洲大陸的發現摧毀了托勒密的世界圖像——古希臘的「權威地理學」第一次被實測徹底推翻。此後亞美利哥·維斯普奇的航行確認這是「新大陸」，1507 年瓦爾德澤米勒地圖即以他命名。**技術需求倒逼理論更新**——這是金觀濤迴路的第一個明確案例。
2. **新問題的量產**：遠洋航海暴露出一連串舊理論無法處理的問題——經度如何測定（需要精確計時，見 [1280-機械鐘.md](1280-機械鐘.md) 與 [1656-惠更斯擺鐘.md](1656-惠更斯擺鐘.md)）、磁偏角為何隨地而異（[1600-吉爾伯特磁學.md](1600-吉爾伯特磁學.md)）、曆法與太陽年不符（需要天文觀測，見 [1576-第谷天文台.md](1576-第谷天文台.md)）。**每個問題都是新實驗、新理論的種子**。
3. **知識的加速傳播**：哥倫布的手記經印刷術（[1450-古騰堡印刷術.md](1450-古騰堡印刷術.md)）在數月內傳遍歐洲——知識複製的速度第一次趕上了探索的速度。同時代的中國鄭和下西洋（早於此 87 年）規模更大，但航海檔案被朝廷銷毀，未成公共知識——**同一事件，有無印刷迴路，結局天壤之別**。
4. **心理革命**：舊權威的地圖可以錯，那麼舊權威的天文學呢？（[1543-哥白尼日心說.md](1543-哥白尼日心說.md)）——哥倫布撕開的裂縫，哥白尼、伽利略將繼續擴大。

# 用 Python 驗證哥倫布案的關鍵疑點：地球周長的估算誤差

import math

R_true = 6371.0                 # 地球真實半徑（km）
C_true = 2 * math.pi * R_true   # 真實周長

# 哥倫布採用的推算（綜合托勒密縮小的地球與馬可波羅拉長的亞洲）
C_columbus = 28000.0            # km
dist_to_japan_columbus = 4400.0 # 他估計西航到日本的距離

print(f"地球真實周長 ≈ {C_true:,.0f} km")
print(f"哥倫布採用的周長 ≈ {C_columbus:,.0f} km（低估 {100*(1-C_columbus/C_true):.0f}%）")
print(f"他估計西航日本需 {dist_to_japan_columbus:,.0f} km")

# 15世紀帆船實際日航程約 110 km（信風帶可達更快）
speed = 110
days_est = dist_to_japan_columbus / speed
print(f"按他的估算：{days_est:.0f} 天可達（紙上可達）")

# 真實情況：到美洲約 5,500 km，若直航日本則需約 19,000 km
dist_to_america = 5500
dist_to_japan_true = 19000
print(f"\n實際到美洲 {dist_to_america:,.0f} km = {dist_to_america/speed:.0f} 天（剛好在補給極限）")
print(f"若直航日本：{dist_to_japan_true/speed:.0f} 天 —— 遠超補給極限，必將全滅")
print("\n結論：雙方都算錯了，是美洲救了船隊——")
print("『理論可以被航行否定，但人不一定接受』：哥倫布至死堅稱那是亞洲。")

# 緯度測量：象限儀測北極星高度 = 緯度（誤差約 1°，即 111 km）
lat_err = 1.0

print("經度更是無解（需精確鐘錶）→ 技術需求倒逼理論與儀器更新。")
