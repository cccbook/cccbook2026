# 1897 湯姆生電子

## 案發現場

1897 年 4 月 30 日，倫敦皇家研究院的演講廳裡，**約瑟夫·約翰·湯姆生（J. J. Thomson, 1856–1940）**宣布了一個令人震驚的結論：陰極射線——那束在真空管中從陰極飛向陽極的射線——**不是光波，不是以太波，而是一種帶負電的粒子流，質量比最小的原子（氫）還小一千倍以上**。

案發現場的背景是：道耳頓 1803 年以來的原子論共識是——**原子是物質的最小單位，不可再分**（見 [1789-拉瓦錫定量革命.md](1789-拉瓦錫定量革命.md) 奠定的化學原子基礎）。陰極射線的性質自 [1895-倫琴X光.md](1895-倫琴X光.md) 之類的真空管實驗熱潮以來爭論不休：「波派」（德國多數）與「粒子派」（英國）相持不下。這條「原子不可分割」的禁令，即將被一根真空管打破。

## 偵查過程

湯姆生在卡文迪什實驗室的偵查，是電磁理論與實驗技術合體的教科書：

**第一步：用電磁場審問射線。** 湯姆生的關鍵武器是 [1865-麥克斯韋方程組.md](1865-麥克斯韋方程組.md) 的實驗兌現——他能用電場與磁場**精確地偏折和控制**陰極射線。第一步判決：射線在電場與磁場中都會偏折，方向對應負電荷——**它是帶電粒子，不是波**。（X 光恰好相反：不偏折——所以 X 光與陰極射線是兩回事。）

**第二步：測出荷質比。** 第二步是定量偵查：湯姆生設計了一套精巧的平衡實驗——電場使粒子向下偏折，磁場使粒子向上偏折；調節兩場強度使偏折抵消，粒子走直線。由力平衡方程：

$$qE = qvB \quad\Rightarrow\quad v = \frac{E}{B}$$

先測出速度 v；再用磁場單獨偏折的位移，解出荷質比：

$$\frac{q}{m} = \frac{v}{B r}$$

結果震驚學界：**陰極射線粒子的荷質比，約是氫離子的一千倍以上**。兩種可能：電荷極大，或質量極小。湯姆生判斷後者——這種粒子的質量約為氫原子的 1/1800。

**第三步：證明普適性。** 第三步是「結案」的關鍵：湯姆生改變陰極材料（鋁、鉛、鉑）、改變管中殘餘氣體（空氣、氫、二氧化碳）——**荷質比完全不變**。粒子與陰極材料、氣體無關：它存在於**一切物質之中**。結論水到渠成：

> 「這些粒子是物質的組成單位……原子不是不可分割的，原子本身是由更小的粒子構成的。」

他稱之為「微粒」（corpuscles），後世依 1891 年斯通尼提出的名稱，稱之為**電子（electron）**。他還提出「葡萄乾布丁模型」：原子是帶正電的布丁，電子如葡萄乾嵌在其中（此模型 1911 年被盧瑟福的實驗推翻，[1913-玻爾原子模型.md](1913-玻爾原子模型.md) 的量子世界由此開門）。

**第四步：迴路的回報。** 電子的發現直接孵化了真空管技術的升級：弗萊明 1904 年的真空二極管、德福雷斯特 1906 年的真空三極管（可放大信號）——電子學由此誕生，無線電（[1895-馬可尼無線電.md](1895-馬可尼無線電.md)）的商用化由此提速。

## 結案報告

湯姆生電子是**真空管＋電磁理論，原子被拆開**的時刻。用金觀濤的框架說，本案屬於**實驗＋理論**環節，它對「科學的工業化」的推動在於：

1. **原子論的裂縫**——原子被拆開：化學原子論（[1789-拉瓦錫定量革命.md](1789-拉瓦錫定量革命.md)）的「不可分割」禁令破產，微觀物理學開門。
2. **電磁理論的實驗兌現**——麥克斯韋方程組的場概念，經湯姆生的電磁偏折實驗成為拆原子的工具：理論—實驗迴路再次互促。
3. **電子學的誕生**——真空管、電晶體（1947）、積體電路（1958）：整個資訊時代的元件，都始於這個「質量是氫 1/1800 的粒子」。
4. **科學的工業化**——卡文迪什實驗室（麥克斯韋創辦、湯姆生主持）成為常設研究機構：工業實驗室（愛迪生）與學院實驗室（卡文迪什）並行，第六幕的組織形態全面成型。

## 證據與工具

```python
# 湯姆生的平衡實驗：測電子的荷質比
# 力平衡：qE = qvB → v = E/B；再由磁偏折半徑 r：q/m = v/(B·r)

E, B = 3000.0, 0.001   # 電場 V/m（板間約 3000 V/m）、磁場 T
v = E / B
r = 0.05               # 磁場單獨作用下的偏折半徑 m
qm = v / (B * r)       # 荷質比 C/kg
print(f"平衡法測得速度：v = E/B = {v:.2e} m/s")
print(f"荷質比 q/m = v/(Br) = {qm:.2e} C/kg")

# 對比氫離子
m_h = 1.67e-27         # 氫原子質量 kg
q_e = 1.602e-19        # 基本電荷 C
qm_h = q_e / m_h
print(f"\n氫離子荷質比：{qm_h:.2e} C/kg")
print(f"比值（電子/氫離子）≈ {qm/qm_h:.0f} 倍")
print(f"=> 電子質量 ≈ 氫原子的 {1/(qm/qm_h):.2e}（約 1/1800）")
print("=> 原子不是最小單位：原子被拆開了！")

# 普適性：改陰極材料、改氣體，荷質比不變
print("\n--- 湯姆生的普適性檢驗 ---")
for cathode, gas in [("鋁", "空氣"), ("鉛", "氫"), ("鉑", "二氧化碳")]:
    print(f"陰極 {cathode}、氣體 {gas}：q/m = {qm:.2e} C/kg（不變）")
print("=> 粒子存在於一切物質之中：電子是物質的普遍組成單位。")
```
