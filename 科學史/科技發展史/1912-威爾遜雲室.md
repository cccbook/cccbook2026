# 1912 威爾遜雲室

## 案發現場

十九世紀末，微觀物理學有一個根本的窘境：帶電粒子——電子、α 粒子、β 粒子——的一切證據都是**間接的**。你數得到閃光（蓋格的螢幕）、量得到電流，卻**從來沒有看見過任何一顆粒子**。粒子長什麼樣、走什麼路線、在哪裡拐彎——全部只能猜。

1894–1895 年，卡文迪許實驗室的威爾遜（Charles T. R. Wilson）在蘇格蘭本尼維斯山頂觀察雲霧時，被一個現象迷住：**過飽和的水蒸氣，需要「核」才能凝結**——塵埃、離子，都可以是核。他回到實驗室，花費十幾年打磨一套裝置：一個可以膨脹的密閉室，裡面充著過飽和蒸氣。

1911 年，他成功了：讓帶電粒子穿過這個密閉室——粒子沿途撞出的離子成為凝結核，蒸氣在徑跡上凝成一串**肉眼可見的小水珠**——一條白色的霧線，就是粒子的腳印。**人類第一次親眼看見了帶電粒子的徑跡。**

## 偵查過程

雲室的原理是一道漂亮的物理習題：濕空氣驟然膨脹，按絕熱膨脹降溫（$T V^{\gamma-1} =$ 常數），若膨脹比恰到好處，蒸氣便進入**過飽和**狀態——按理該凝結，卻因為沒有凝結核而撐著。此時若有帶電粒子穿過，它電離空氣分子留下的一串離子，立刻成為凝結核——霧線現形，再用閃光燈拍照。

威爾遜的關鍵偵查有兩步：

1. **沒有粒子的對照組**：1910 年前後他先證明，用 X 光照射密閉室（製造離子），霧就凝在離子上——離子確實是核。這是受控對照，不是運氣。
2. **有粒子的實驗組**：1911 年他用鐳源與宇宙線反覆測試，拍出了清晰的 α 粒子短粗徑跡與 β 粒子細長徑跡——**不同粒子、不同徑跡**。徑跡的粗細、長短、彎曲程度，成為粒子的「指紋」。

這是九通道中「**技術⇒實驗**」的極致樣板：威爾遜把過飽和蒸氣（一個氣象學觀察的副產品）**物化為粒子徑跡照相機**，讓原本不可能的實驗——「直接看見粒子」——成為可能。而徑跡一現形，實驗⇒理論的通道立刻打開：粒子走什麼路線，就是理論的判決書。

雲室此後成為微觀物理學的萬能偵查工具，一連串發現都靠它：

- **宇宙線（1911–12）**：維克托·赫斯把雲室與電離計量帶上氣球，在五千公尺高空測到更強的電離——宇宙線被確認（1936 年諾貝爾獎）；
- **正電子（1932）**：安德森（Carl Anderson）用雲室拍下宇宙線中一條「向上彎曲、質量如電子」的徑跡——反物質的第一份照片（見 [1926-薛丁格方程.md](1926-薛丁格方程.md) 的狄拉克理論被蓋章）；
- **人工核蛻變（1919）**：拉塞福用 α 粒子轟擊氮氣，靠雲室觀測到氫核的反衝徑跡——人類第一次人工改變原子核（見 [1909-拉塞福原子核.md](1909-拉塞福原子核.md) 的核模型的下游）。

## 結案報告

威爾遜因雲室獲 1927 年諾貝爾物理學獎。本案的遺產：

1. **粒子「現形」的技術**——微觀物理學從間接計數進入直接成像時代；徑跡就是證據，照片就是判決書。
2. **實驗⇒實驗的方法繼承**——雲室的方法被整個粒子物理繼承：膨脹雲室、擴散雲室、氣泡室（1952，格拉澤，同樣的「過熱液體成核」思路）、火花室——一脈相承的「徑跡照相機」家族。
3. **一張照片蓋章一個理論**——正電子的照片蓋章了狄拉克的反物質預言；理論⇒實驗的通道，靠雲室這項技術才能通車。
4. **方法論的教訓**——重大技術未必來自重大計畫；雲室始於一次山頂看雲的好奇心。

## 促進鏈分析

本篇是「**技術⇒實驗**」通道的核心案例，並含實驗⇒實驗的繼承鏈，涉及九通道中的四條：

- **技術⇒實驗（主鏈）**：雲室（技術）讓「直接看見粒子徑跡」的實驗得以進行；README 表中「威爾遜雲室（技術，1912）⇒拉塞福人工核蛻變觀測（1919）」即此條的下游。
- **實驗⇒理論**：徑跡照片（實驗）成為新粒子與新理論的判決書——正電子徑跡（1932）蓋章狄拉克理論，核蛻變徑跡（1919）蓋章核結構理論。
- **實驗⇒實驗（方法繼承）**：雲室的「凝結核成像」方法被宇宙線實驗、正電子實驗、中子實驗（見 [1932-中子的發現.md](1932-中子的發現.md)）與氣泡室繼承；README 表中「威爾遜雲室（1912）⇒宇宙線、正電子、中子的一切徑跡實驗」即此條。
- **技術⇒技術（伏筆）**：雲室的「過飽和成核」思路在 1952 年被氣泡室繼承——把凝結核換成沸騰核，同樣的原理，靈敏度再升級。

## 證據與工具

```python
# 用 Python 模擬過飽和度與凝結條件：雲室何時「開眼」

import numpy as np

# --- 絕熱膨脹降溫：T V^(γ-1) = 常數 ---
gamma = 1.4        # 空氣的比熱比
T0 = 293.0         # 初始溫度 K（20°C）
V_ratio = np.linspace(1.0, 1.5, 200)   # 膨脹比 V/V0

T = T0 * V_ratio**(1 - gamma)          # 膨脹後溫度

# --- 飽和水蒸氣壓（克勞修斯-克拉佩龍近似）---
L = 2.45e6         # 水的汽化熱 J/kg
Rv = 461.5         # 水蒸氣氣體常數 J/(kg·K)
e0 = 2339.0        # 20°C 飽和蒸氣壓 Pa
e_sat = e0 * np.exp(-L / Rv * (1 / T - 1 / T0))

# 膨脹後實際蒸氣壓（絕熱：p ∝ T^(γ/(γ-1))，蒸氣分壓隨總壓同步稀釋）
e_actual = e0 * (T / T0)**(gamma / (1 - gamma))
supersaturation = e_actual / e_sat     # 過飽和度 S

# 雲室的關鍵區間：S > 1（該凝結而未凝結），且要夠高離子才能成核
# 實驗：無塵埃時，離子成核需 S ≳ 4~6；有塵埃時 S ≳ 1 即凝
cond_clean = np.argmax(supersaturation > 4)
cond_on = np.argmax(supersaturation > 1)

print("--- 絕熱膨脹與過飽和度 ---")
print(f"{'膨脹比':>6s} {'溫度(°C)':>8s} {'過飽和度S':>10s}")
for i in range(0, 200, 25):
    print(f"{V_ratio[i]:6.2f} {T[i]-273.15:8.1f} {supersaturation[i]:10.2f}")

print(f"\n膨脹比 ≈ {V_ratio[cond_on]:.2f} 時 S = 1（蒸氣飽和，有塵埃即凝）")
print(f"膨脹比 ≈ {V_ratio[cond_clean]:.2f} 時 S = 4（純淨空氣中，離子成核生效！）")
print("=> 威爾遜的訣竅：除塵 + 控制膨脹比，讓『只有離子』成為凝結核")
print("=> 帶電粒子穿過 => 沿途離子 => 霧線現形 => 粒子徑跡被拍下")

# --- 徑跡差異：α 粒子 vs β 粒子（電離本領與射程）---
print("\n--- 徑跡指紋 ---")
print("α 粒子：電荷 2e、質量大 => 電離本領強 => 徑跡粗、短（空氣中 ~3 cm）")
print("β 粒子：電荷 e、質量小 => 電離本領弱 => 徑跡細、長，易被磁場彎曲")
print("=> 1932 年安德森靠『細徑跡 + 磁場彎曲方向』認出正電子")
```
