# 1965 宇宙微波背景：大爆炸的預言被兩位工程師的喇叭天線偶然捕獲

## 案發現場

1965 年 5 月，紐澤西州霍姆德爾，貝爾實驗室的克勞福德山研究站。阿諾·彭齊亞斯（Arno Penzias）與羅伯特·威爾遜（Robert Wilson）正在調校一台 6 公尺的喇叭形天線——它原本是為了軍事通訊衛星 Echo 號的實驗而建造的。

他們想測量銀河系邊緣的 21 公分氫線輻射，但無論天線指向何方——天上、地下、任何方向——都收到一個穩定的噪聲：等效溫度約 3.5 K。他們清理了天線裡的鴿子糞（著名的「白色介電質」事件），檢查了每一個接頭、每一級放大器，噪聲依然存在，而且**不隨方向、季節、時間變化**。它來自四面八方，來自宇宙本身。

## 偵查過程

**理論先行（1948）。** 十七年前，喬治·伽莫夫、拉爾夫·阿爾菲（Ralph Alpher）與羅伯特·赫爾曼（Robert Herman）研究大爆炸核合成時提出：宇宙誕生之初是高溫高密度的輻射海洋，隨著膨脹冷卻，這片輻射的溫度會不斷下降，但**永遠不會消失**。他們計算出：今日這片殘餘輻射的溫度應約為 5 K——一片充滿整個宇宙、波長在微波段的「背景輝光」。

這個預言發表後被遺忘了十餘年。伽莫夫團隊的論文以 αβγ 的幽默署名聞名（Alpher-Bethe-Gamow，伽莫夫未經同意把物理學家貝特的名字加了上去以湊成希臘前三字母），但論文的預言卻無人追測——理論⇒實驗的通道竟停滯了十七年。

**軍事技術造出實驗（1960s）。** 為什麼最後是貝爾實驗室的工程師測到了它？因為冷戰。1957 年蘇聯發射史潑尼克衛星後，美國急需衛星通訊技術；貝爾實驗室為 Echo 號通訊衛星計畫建造了這台超低噪聲喇叭天線——**軍事通訊技術（技術）⇒實驗**。彭齊亞斯與威爾遜用這台為衛星通訊打造的儀器，去做純粹的射電天文觀測。

**接線（1965）。** 彭齊亞斯與威爾遜無法解釋自己的噪聲。某次通話中，彭齊亞斯向麻省理工學院的伯克提起困擾，伯克想起普林斯頓大學羅伯特·狄克（Robert Dicke）團隊正在建造儀器搜尋「大爆炸的殘餘輻射」。狄克接到電話後對團隊說出了物理學史上最著名的認輸之一：「各位，我們被搶先了（Boys, we've been scooped）。」

兩個團隊很快確認：3.5 K 噪聲正是 1948 年預言的宇宙微波背景（CMB）。兩篇論文並排發表在 1965 年《天文物理期刊》：一篇是實驗發現，一篇是理論解讀。

## 結案報告

彭齊亞斯與威爾遜於 1978 年獲諾貝爾物理學獎。CMB 的發現是「理論⇒實驗」通道的示範，而實驗發現反過來重塑了理論：

1. **大爆炸宇宙學確立**——CMB 是大爆炸留下的「餘燼」，穩恆態宇宙學（霍伊爾等人的主張）被淘汰，宇宙有了開端。
2. **宇宙成為可測量的實驗室**——CMB 的各向異性測量（COBE 1992、WMAP、普朗克衛星）把宇宙學從哲學爭論變成精密科學：宇宙年齡、組成、幾何全部可從這片輝光讀出（幾何即 [1854-黎曼幾何.md](1854-黎曼幾何.md) 的彎曲空間）。
3. **核合成的驗證**——CMB 溫度與氦豐度互相印證，伽莫夫團隊 1948 年的整個理論框架被蓋章。
4. **偶然性與技術的教訓**——這個發現屬於「手裡有對的儀器的人」：喇叭天線為通訊而造，卻撞見了宇宙的誕生。

## 促進鏈分析

- **理論⇒實驗（主通道）**：伽莫夫-阿爾菲-赫爾曼預言殘餘輻射約 5 K（1948）⇒ 彭齊亞斯-威爾遜喇叭天線發現 CMB（1965）——理論預言該測什麼（雖然被遺忘十七年，最後由對話與偶然完成接線）。
- **技術⇒實驗（關鍵支線）**：冷戰衛星通訊技術 ⇒ 超低噪聲喇叭天線 ⇒ 射電天文觀測——軍事技術讓原本不可能的實驗得以進行。
- **實驗⇒理論（回饋）**：CMB 的發現 ⇒ 大爆炸宇宙學確立、穩恆態理論淘汰——異常噪聲（對整個舊理論框架而言）反過來裁決了理論之爭。
- **實驗⇒實驗（繼承）**：喇叭天線觀測 ⇒ COBE、WMAP、普朗克衛星的全天 CMB 測量——儀器與方法的層層升級。
- **理論⇒理論（骨架）**：CMB 精密測量所需的宇宙幾何分析 ⇒ 踩在黎曼幾何與廣義相對論上（[1915-廣義相對論.md](1915-廣義相對論.md)）。

本篇九通道主通道：**理論⇒實驗**。特色：理論領先十七年、被遺忘、被偶然接線——理論可以離線，但只要被記錄與傳播，它就在迴路中待命。

## 證據與工具

```python
# 用 Python 計算：CMB 溫度與光譜峰值波長（維恩定律）
import numpy as np

T_CMB = 2.725  # 今日 CMB 溫度 (K)，COBE 衛星 1992 精確值
b_wien = 2.898e-3  # 維恩位移常數 (m·K)

# --- 1. 維恩定律：峰值波長 ---
lam_peak = b_wien / T_CMB
print("--- CMB 的光譜峰值（維恩定律）---")
print(f"T = {T_CMB} K → 峰值波長 = {lam_peak*1e3:.2f} 毫米（微波段）")
print(f"對應頻率 ≈ {3e8/lam_peak/1e9:.1f} GHz")
print("→ 彭齊亞斯與威爾遜的 7.35 cm 天線測到的正是這片輻射的尾端")

# --- 2. 宇宙膨脹：溫度隨尺度因子下降 ---
# T ∝ 1/a（絕熱膨脹），紅移 z 時 T = T_CMB (1+z)
print("\n--- CMB 溫度隨宇宙膨脹演化 ---")
for z, era in [(0, "今日"), (1, "半徑一半"), (1100, "CMB 最後散射面")]:
    T = T_CMB * (1 + z)
    lam = b_wien / T
    print(f"z = {z:>5}（{era}）：T = {T:>8.1f} K，峰值 = {lam*1e9:>8.0f} 奈米")
print("→ 1948 年預言：宇宙誕生時是輻射海洋，膨脹冷卻至今日 5 K 左右")
print("   （實測 2.725 K，與預言同數量級）")

# --- 3. 彭齊亞斯與威爾遜的噪聲帳本 ---
print("\n--- 1965 年的噪聲帳本（等效天線溫度）---")
print(f"總噪聲（ zenith 測得）        ≈ 6.7 K")
print(f"大氣吸收（扣除）              ≈ 2.3 K")
print(f"天線與放大器本身（扣除）      ≈ 0.9 K")
noise_left = 6.7 - 2.3 - 0.9
print(f"剩餘、無法解釋的噪聲          ≈ {noise_left:.1f} K")
print("→ 扣完帳後剩下的 ~3.5 K 噪聲，不隨方向變化")
print("→ 狄克團隊指出：這正是 1948 年預言的 CMB（我們被搶先了）")

# --- 4. 普朗克光譜的形狀驗證（黑體輻射）---
h = 6.626e-34
k_B = 1.381e-23
c = 3e8
nu = np.linspace(1e9, 1000e9, 500)  # 1-1000 GHz
B_nu = 2*h*nu**3/c**2 / (np.exp(h*nu/(k_B*T_CMB)) - 1)
print(f"\n普朗克黑體譜在 CMB 溫度下的峰值頻率 ≈ "
      f"{nu[np.argmax(B_nu)]/1e9:.0f} GHz（~160 GHz，微波段）")
print("→ CMB 是已知宇宙中最完美的黑體光譜 → 大爆炸的餘燼鐵證")
```
