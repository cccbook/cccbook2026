# 1789 拉瓦錫定量革命

## 案發現場

1789 年之前，化學是歐洲科學中最混亂的領域。統治一百年的官方理論是**燃素說（phlogiston theory）**：燃燒是物質釋放「燃素」的過程，木頭燒完變輕，正是燃素逃走了。但這套理論有一個致命的帳目漏洞——**金屬煅燒（燒成灰）之後反而變重了**！燃素明明應該逃走，天平上卻多出了重量。燃素說者辯稱燃素有「負重量」，這種解釋已經近乎神學。

與此同時，技術那邊的案卷堆積如山：波以耳定律（[1662-波以耳定律.md](1662-波以耳定律.md)）讓氣體可以定量處理、布萊克（[1761-布萊克潛熱.md](1761-布萊克潛熱.md)）的量熱學讓熱可以記帳、普利斯特里（1774）剛分離出一種「助燃的空氣」——證物齊備，只差有人把它們全部偵訊一遍。

接手的是巴黎的收稅官、實驗家**拉瓦錫（Antoine Lavoisier, 1743–1794）**。他手上握著化學家們輕視的武器：**一台精確的天平**。

## 偵查過程

拉瓦錫的偵查是「定量」的教科書：他堅信**質量不會說謊**，一切解釋必須先過天平這一關。

**第一件證物：密封容器的煅燒實驗。** 拉瓦錫把錫放入密封玻璃瓶中煅燒，**連瓶帶物一起稱重——總質量不變**；開瓶瞬間空氣湧入，質量才增加。他推出結論：**煅燒變重不是因為釋放了負重量燃素，而是因為吸收了空氣中的某種成分**。

**第二件證物：氧的命名與燃素說之死。** 拉瓦錫重複普利斯特里的實驗：加熱氧化汞（HgO），分解出一種氣體——它助燃、能讓動物更活躍、能與多種物質結合。1777 年他命名為**氧（oxygène，成酸者）**，並宣布：**燃燒不是釋放燃素，而是與氧結合**。他寫下這場革命的宣言：

> 「如果『燃素』一詞意味著什麼，那它什麼都不意味著——這是一個應該被化學驅逐的幽靈。」

**第三件證物：質量守恆定律。** 1789 年，拉瓦錫出版《化學基礎論》（Traité élémentaire de chimie），宣布化學的第一定律：**在化學反應中，物質的總質量守恆**——「無中生有」與「有變成無」都不存在。這是化學的「帳本原則」：一切反應都必須記平帳。同書還列出了第一張**元素表**（33 種元素），化學從此有了自己的「元素名單」與命名法（氧化汞、硫酸、碳酸鈣——名稱即組成）。

**技術反哺理論。** 拉瓦錫的定量方法，直接受益於此前的技術工具（天平、氣體量測裝置、量熱計——他與拉普拉斯合作的冰量熱計）。而他清算燃素說所用的氧，正是紐科門蒸汽機時代（[1698-紐科門蒸汽機.md](1698-紐科門蒸汽機.md)）「燃燒=氧化」的工業常識在理論上的倒逼。**技術的常識反哺了理論的清算**——第四幕迴路的又一次閉合。

## 結案報告

1. **燃素說被處決**——化學史上統治最久的錯誤理論被天平終結；「負重量」的辯護成為科學史上拒不認錯的經典反面教材。
2. **質量守恆定律**——化學成為「必須記平帳」的定量實驗科學，元素表與命名法讓化學有了公共語言；通往道耳頓原子論（1803）與現代化學。
3. **迴路意義**——技術（天平與量熱計）→ 實驗（密封煅燒）→ 理論（氧說＋質量守恆）→ 技術（定量化的化學工業，如 [1856-貝塞麥轉爐.md](1856-貝塞麥轉爐.md)）——金觀濤迴路在化學中的完整標本。
4. **代價與遺產**——拉瓦錫是收稅官，1794 年死於法國大革命的斷頭台。拉格朗日哀悼：「砍下這顆頭顱只要一瞬，再長出一顆卻要一百年。」

# 拉瓦錫的「質量帳本」：燃素說 vs 氧說的對決

# 密封煅燒實驗：總質量守恆
m_tin = 100.0      # 錫 g
m_air_O2 = 21.3    # 密封瓶中參與反應的氧 g（示意）
m_ash = m_tin + m_air_O2  # 煅燒灰（氧化錫）
m_sealed = m_tin + m_air_O2  # 密封系統總質量
print("--- 密封煅燒實驗 ---")
print(f"錫 {m_tin} g + 密封瓶中氧 {m_air_O2} g")
print(f"煅燒後灰 {m_ash} g，密封系統總質量 {m_sealed} g（不變！）")
print("開瓶瞬間空氣湧入，總質量才增 => 煅燒是『吸收』而非『釋放』\n")

# 燃素說的窘境：金屬煅燒變重
print("燃素說預測：釋放燃素 => 應變輕")
print(f"實測：變重了 {m_air_O2} g => 燃素說的帳對不上！\n")

# 氧化汞分解：氧的來源
M_HgO, M_Hg, M_O = 216.59, 200.59, 16.00
m_HgO = 10.0
print("--- 氧化汞分解（拉瓦錫 1777）---")
print(f"HgO {m_HgO} g -> 汞 {m_HgO*M_Hg/M_HgO:.2f} g + 氧 {m_HgO*M_O/M_HgO:.2f} g")
print("助燃氣體 = 氧：燃燒是與氧結合，不是釋放燃素\n")

# 質量守恆定律的帳本驗證：氫氣燃燒成水
print("--- 質量守恆：2H2 + O2 -> 2H2O ---")
print(f"氫 {2*2.016:.2f} g + 氧 {2*16.00:.2f} g -> 水 {2*18.016:.2f} g")
print(f"左邊 {2*2.016+2*16.00:.2f} g = 右邊 {2*18.016:.2f} g（帳平了！）")
print("=> 『無中生有』不存在：化學的第一定律")
