# 科技發展的歷史年表（科學史）

> 思想家金觀濤在剖析近代科學起源時提出一個核心論斷：**科學革命的本質，是「理論—實驗—技術」三者形成一個相互促進、自我完成的循環結構**。
>
> - **理論**提出有待驗證的假設（為什麼會這樣？）；
> - **實驗**以受控手段檢驗假設（到底是不是這樣？）；
> - **技術**把得到驗證的知識物化為工具（能拿來做什麼？），而新工具又反過來造出更精的儀器、開出新的實驗、逼出新的理論。
>
> 古代文明有技術（青銅、火藥、水車）、有理論（亞里士多德）、也有觀測，但三者各自孤立、不成循環，所以技術只能緩慢累積，理論千年不變。近代科學之所以在十六、十七世紀的歐洲起飛，正是因為印刷術、望遠鏡、顯微鏡、真空泵、機械鐘把三個環節第一次扣成了一個**不斷加速的正反饋迴路**。
>
> 本年表即以此「循環結構」為主軸：每一幕都是這個迴路的一次升級，每一個事件都標註它主要屬於哪個環節（理論🔬→**實驗**→**技術**⚙），以及它如何推動整個迴路。
>
> 本書以「推理探案」的方式，為每個歷史事件寫一篇 wiki，包含前因後果、數學式、理論與程式。每篇檔名以年份開頭。

## 尾聲：循環結構的哲學

回顧九幕，可以看到「理論—實驗—技術」迴路演化的幾條規律：

1. **古代的困境不是沒有知識，而是沒有迴路**——中國有火藥與水運儀象台，希臘有阿基米德，但技術與理論互不往來，進步只能線性累積。
2. **迴路的每次升級都由新工具點火**——印刷術、望遠鏡、真空泵、電堆、電晶體、電腦：工具改變了實驗的邊界，實驗改變了理論的邊界。
3. **理論可以領先，但不能離線太久**——哥白尼等了六十年，麥克斯韋等了二十三年，廣義相對論只等了四年；等待時間的縮短本身就是迴路加速的證據。
4. **迴路的組織形式不斷升級**——個人（伽利略、列文虎克）→ 學會（皇家學會）→ 工業實驗室（愛迪生、拜耳）→ 國家計畫（曼哈頓、阿波羅）→ 全球開源網絡（WWW、深度學習）。
5. **迴路在擴散中加速**——從少數精英到億萬終端使用者，每一次「知識複製成本」的暴跌（印刷術、WWW）都讓循環的參與者數量級躍升。

金觀濤的洞見在此得到歷史驗證：**近代科學不是一堆發現的清單，而是一個自我完成的組織結構。理解了這個結構，就理解了為什麼科學革命發生在那裡、那時，以及為什麼它再也停不下來。**
