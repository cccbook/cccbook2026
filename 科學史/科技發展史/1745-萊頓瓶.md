# 1745 萊頓瓶

## 案發現場

案發地點是荷蘭萊頓大學。十八世紀上半葉，靜電學已經累積了半個世紀：吉爾伯特《論磁》（[1600-吉爾伯特磁學.md](1600-吉爾伯特磁學.md)）分清了電與磁，摩擦起電機越造越大——但電學實驗有個致命瓶頸：**電存不住**。摩擦機一轉就有電，一停就沒了；電荷像水流過篩子，抓到多少漏掉多少。實驗只能在「起電的瞬間」進行，無法重複、無法儲存、無法量產。

轉機來自兩位幾乎同時撞見它的人：1745 年 10 月，萊頓大學的教授**馬森布羅克（Pieter van Musschenbroek, 1692–1761）**與德國波美拉尼亞的教士**馮·克萊斯特（Ewald Georg von Kleist）**。兩人都在做同一件事——想辦法把電荷「存進瓶子裡」。

## 偵查過程

馮·克萊斯特先發現（1745 年 10 月）：把帶電的釘子插進裝水的玻璃瓶，取出釘子後用手碰瓶口，手臂被狠狠一擊。馬森布羅克在萊頓獨立重做了實驗，被電得當場寫下科學史上最著名的「被害人陳述」：

> 「我剛剛遭到一次新的、但可怕的實驗打擊，我奉勸你千萬不要拿自己的性命去重複它。」

但他隨即意識到：這一擊不是災難，而是**儲電成功的證據**。

**關鍵推理：水不是關鍵，玻璃與「兩面」才是。** 馬森布羅克系統改變實驗條件：水可以換成金屬箔；帶電體與導體必須**隔著玻璃**分居兩側；兩側同時用「手」與「帶電體」接觸，儲電量最大。他推出結論：玻璃不是導體而是**介質**，電荷以某種「束縛」狀態存在於玻璃兩側——現代術語稱之為**電容（capacitance）**，這個人類第一個電容器就是「**萊頓瓶**」。

**技術的成熟與量產。** 萊頓瓶迅速標準化：玻璃瓶內外貼金屬箔，瓶口金屬棒作電極，可串聯成「電池組」蓄積驚人的電荷。1746 年諾萊特（Nollet）在巴黎讓 180 名手拉手的士兵同時被電——人體成為導電迴路的公開演示。**電學實驗第一次可以儲存、重複、批量進行**，瓶中的電成為可支配的實驗資源。

## 結案報告

1. **電的儲存技術誕生**——電學實驗從「瞬間」變成「連續」，實驗邊界被技術重新劃定。
2. **電容概念之始**——「電荷束縛於介質兩側」的直覺，通往卡文迪什與庫侖的定量電學，最終由法拉第（[1831-法拉第電磁感應.md](1831-法拉第電磁感應.md)）發展為場論。
3. **迴路意義（第四幕的點火器）**——技術（萊頓瓶）造出新實驗（批量放電）→ 新實驗逼出新理論（富蘭克林 [1752-富蘭克林風箏.md](1752-富蘭克林風箏.md) 用萊頓瓶統一電閃與電火花）→ 新理論再催生新技術（伏打電堆 [1800-伏打電堆.md](1800-伏打電堆.md) 解決萊頓瓶「用完要重充」的缺陷）。**工具改變了實驗的邊界，實驗改變了理論的邊界**——金觀濤的迴路規律在此乾淨上演。
4. **公共實驗的濫觴**——士兵手拉手被電的演示，讓科學實驗成為大眾娛樂與公共事件，科學的社會參與者數量級躍升。

## 證據與工具

```python
# 萊頓瓶的「電容帳本」：人類第一個電容器

# 平行導體電容：C = eps0 * eps_r * A / d
eps0 = 8.854e-12    # 真空介電常數 F/m
eps_r = 5.0         # 玻璃相對介電常數約 5
A = 0.05            # 瓶壁金屬箔面積 m^2（約 0.05 m^2）
d = 0.003           # 玻璃厚度 3 mm
C = eps0 * eps_r * A / d
print(f"萊頓瓶電容 C = eps0*eps_r*A/d ≈ {C*1e9:.2f} nF")

# 儲電量：Q = C * V
V = 50000  # 摩擦起電機電壓約 5 萬伏
Q = C * V
E = 0.5 * C * V**2
print(f"充電至 {V:,} V：儲電荷 Q ≈ {Q*1e6:.2f} μC，能量 E ≈ {E:.3f} J")

# 一擊的能量對比：萊頓瓶 vs 摩擦起電機瞬間
print(f"\n萊頓瓶一擊能量 ≈ {E:.2f} J（足以讓 180 名士兵同時有感）")
print("摩擦機瞬間輸出能量 < 0.01 J 且無法儲存")
print("=> 儲存是關鍵：實驗從『瞬間』變成『連續』")

# 串聯「電池組」：電壓相加，能量相加
n = 5
V_total = n * V
E_total = n * 0.5 * C * V**2
print(f"\n{n} 個萊頓瓶串聯：總電壓 {V_total:,} V，總能量 {E_total:.2f} J")
```
