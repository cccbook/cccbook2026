# 1752 富蘭克林風箏

## 案發現場

萊頓瓶（[1745-萊頓瓶.md](1745-萊頓瓶.md)）讓電學實驗可以量產之後，一個古老謎團重新上了桌面：**天上的閃電是什麼？**

古人的答案是神怒與雷神；十八世紀的學院派則大多認為閃電是「空氣中的爆炸」——但沒有人能檢驗。與此同時，實驗室裡的電已經被研究得相當透徹：電火花有藍光、有爆裂聲、能電死動物、能沿導體傳導。**電火花的性質與閃電的描述，像得可疑**——但兩者之間橫著一道無法跨越的高度：沒有人能「把閃電請下來」檢驗。

接手的人不是任何學院的院士，而是費城的一位印刷商、政治家、業餘科學愛好者——**富蘭克林（Benjamin Franklin, 1706–1790）**。他自 1746 年起迷上萊頓瓶，靠自學與通信（他從未發表過正式論文，只寫信給倫敦的皇家學會會員）研究電學。1752 年，他提出了一個大膽到近乎瘋狂的假設，並設計了一個大膽到送命的實驗。

## 偵查過程

**第一步：理論預測。** 富蘭克林在 1749 年的筆記中，逐條比對電火花與閃電的性質：都發光、顏色相近、都有曲折的軌跡、都有爆裂聲、都能殺死動物、都能熔化金屬、都沿導體走。他推出假設：**閃電就是大尺度的電火花**——天上的雲是起電機，大地與雨是導體。他寫下：

> 「電流體與閃電是同一種東西。」

**第二步：設計決定性實驗。** 要檢驗，就必須「把天上的電與地上的電接通」。富蘭克林原提出用高塔尖端收集雲電（1752 年 5 月，法國達利巴爾已用鐵桿先行完成，證實雲帶電）。但富蘭克林要更徹底的檢驗：**直接捕捉雷雨雲的電**。1752 年 6 月，他在費城放出一隻**風箏**——風箏頂端綁尖鐵絲，麻繩末端繫一把銅鑰匙與一枚萊頓瓶。

**第三步：結案。** 雷雨中，麻繩被雨打濕成導體。富蘭克林觀察到**麻繩纖維直立豎起**（帶電的證據），伸手靠近鑰匙——**電火花跳出**，與萊頓瓶的火花一模一樣。他隨即用鑰匙為萊頓瓶充電，再用瓶中的電做了所有熟悉的電學實驗（電死火雞、點燃酒精）——**閃電的電與實驗室的電完全相同**。

這是「統一推理」的教科書：兩種看似不同的現象（天上的閃電、瓶中的火花），被證明是**同一種實體的不同尺度**。同時他由尖端放電現象發明**避雷針**——理論直接物化為拯救生命的技術。

## 結案報告

1. **閃電被「除魅」**——神怒與雷神退場，閃電成為可研究、可防禦的物理現象。避雷針是科學理論第一次大規模拯救人命。
2. **業餘愛好者的勝利**——富蘭克林無學位、無實驗室、不懂微積分，憑受控實驗與系統比對統一了天與地的電；皇家學會授予他科普利獎章，證明迴路的門檻是方法而非身分。
3. **迴路意義**——技術（萊頓瓶）→ 實驗（風箏）→ 理論（電單一流體說）→ 技術（避雷針）——第四幕「技術反哺理論」的乾淨標本。
4. **未竟之志**——電的本質仍是謎，要等到伏打電堆（[1800-伏打電堆.md](1800-伏打電堆.md)）提供穩定電源、法拉第（[1831-法拉第電磁感應.md](1831-法拉第電磁感應.md)）用實驗逼出場論，電學的大循環才真正轉動。

## 證據與工具

```python
# 富蘭克林的「統一推理」帳本：逐條比對電火花與閃電

props = ["發光", "顏色偏藍白", "曲折軌跡", "爆裂聲",
         "殺死動物", "熔化金屬", "沿導體傳導"]
print("--- 電火花 vs 閃電 性質比對 ---")
print(f"{'性質':10s} 電火花  閃電")
for p in props:
    print(f"{p:10s}   ✓      ✓")
print("=> 七條性質全部吻合，推出假設：閃電 = 大尺度電火花\n")

# 避雷針的原理：尖端放電（場強在尖端集中）
# 球形導體表面場強 E = V/r；尖端曲率半徑極小 => E 極大
V = 100e6  # 雷雨雲與地間電壓可達 1 億伏
for r in [5.0, 0.01, 0.0001]:  # 建築、金屬球、針尖
    print(f"曲率半徑 {r} m：表面場強 ~ {V/r:.1e} V/m")

print("\n針尖場強是平頂建築的 5 萬倍 => 尖端優先放電，把雲電導入大地")
print("=> 理論直接物化為避雷針：科學第一次大規模拯救人命")

# 閃電的能量帳本
I = 30000      # 閃電電流約 3 萬安培
t = 30e-6      # 持續約 30 微秒
V_flash = 100e6
E_flash = V_flash * I * t
print(f"\n一道閃電能量 ≈ {E_flash/1e6:.1f} MJ（{E_flash/4.184e3/1000:.0f} 千克 TNT 當量）")
print("=> 為什麼富蘭克林是拿命做實驗：這不是萊頓瓶的小一擊")
```
