# 1609 伽利略望遠鏡

## 案發現場

1608 年，荷蘭米德爾堡的眼鏡匠漢斯·李伯希（Hans Lippershey）申請「遠見鏡」專利——兩片透鏡組合，能把遠物拉近。消息在 1609 年春傳到威尼斯。此時帕多瓦大學的數學教授伽利略·伽利雷（Galileo Galilei, 1564–1642）做了一件改寫歷史的事：**他沒有等荷蘭人的成品，而是用幾何光學自己推算並造出了放大 20 倍的望遠鏡。**

案發現場的知識處境：天文學正在哥白尼假說（[1543-哥白尼日心說.md](1543-哥白尼日心說.md)）與第谷數據（[1576-第谷天文台.md](1576-第谷天文台.md)）之間僵持——**理論之爭無法裁決，因為肉眼已到極限**。亞里士多德宇宙論斷言：天界完美無瑕，月界與天界性質迥異。

謎團：一個荷蘭玩具，能審判千年宇宙論嗎？

## 偵查過程

伽利略的「偵查」是**技術造出新實驗**的教科書案例：

1. **理論先行，三天造鏡**：伽利略從「荷蘭望遠鏡」的傳聞推算出原理——**凸透鏡（物鏡）會聚平行光成實像，凹透鏡（目鏡）放大虛像**。他沒有樣品可抄，靠折射幾何親手磨鏡：8 月完成 3 倍鏡，8 月下旬完成 8 倍，10 月完成 20 倍。他把 20 倍鏡呈給威尼斯元老院，薪水加倍——**技術直接換來資源**。
2. **把鏡指向天空（1609 年冬–1610 年初）**，五個決定性發現接連轟炸亞里士多德宇宙論：
   - **月球有山有谷**：明暗界線上的光點與陰影證明月面崎嶇——天界不完美，且月球與地球**同質**。
   - **木星有四顆衛星**（1610 年 1 月）：四顆小星夜夜繞木星轉動——**存在不以地球為中心的運動**。他命名為「美第奇星」，把發現獻給托斯卡納大公換得終身職位。
   - **金星有完整相位**：金星呈現從新月到滿月的全部盈虧——這**只在日心體系下可能**（托勒密體系下金星永遠呈新月形）。哥白尼 67 年前的預言被望遠鏡蓋章。
   - **太陽有黑子**：日面黑斑移動，證明太陽自轉且不完美。
   - **銀河由無數恆星組成**：肉眼可見的雲霧原來是千萬顆星——宇宙尺度暴增。
3. **出版與辯論**：1610 年 3 月，伽利略以《星際信使》（Sidereus Nuncius）出版發現，印行 550 册，數週內售罄，傳遍歐洲（[1450-古騰堡印刷術.md](1450-古騰堡印刷術.md)）。開普勒立即以《與星際信使的對話》聲援，並證實了木星衛星——**發現經印刷成為公共財，經複製驗證成為共同知識**。質疑者（如部分亞里士多德派學者）拒絕看鏡中世界，但拒絕者被歷史淘汰——**「親眼看見」成為新的知識標準**。

## 結案報告

伽利略望遠鏡是「技術⚙→實驗→理論」迴路的一次典範運轉：

1. **亞里士多德宇宙論的崩塌**：天界完美論、月天分界、地球中心——五個發現同時轟擊，千年宇宙論的地基被移走。
2. **理論獲得裁判**：金星相位是哥白尼體系的決定性證據；木星衛星消解了「如果地球在動，月亮為什麼不掉隊」的反駁（既然木星在動也帶著衛星）。日心說從「數學假說」升格為「被證據支援的理論」，通往開普勒（[1609-開普勒行星定律.md](1609-開普勒行星定律.md)）與牛頓（[1687-牛頓原理.md](1687-牛頓原理.md)）。
3. **迴路的運轉**：荷蘭鏡匠的技術（工藝）→伽利略的光學理論與自製望遠鏡（理論→技術）→新天文發現（實驗）→日心說受審（理論）→更精的望遠鏡與更多發現。**古代望遠鏡不存在，因為古代沒有這個迴圈**——荷蘭與義大利的眼鏡業是幾百年磨鏡工藝的累積，而只有印刷術時代的知識流通才讓伽利略「聽說」荷蘭發現並立即跟上。
4. **望遠鏡之後**：顯微鏡（[1665-虎克顯微圖譜.md](1665-虎克顯微圖譜.md)）同源而生，人類感官的延伸成為科學的常規裝備——「儀器造出新實驗」從此不再是例外，而是規則。

## 證據與工具

```python
# 用 Python 計算伽利略望遠鏡的放大率與金星相位的判決力

import math

# 折射望遠鏡：放大率 = 物鏡焦距 / 目鏡焦距
# 伽利略的 20 倍鏡：物鏡焦距約 1.3 m，目鏡為凹透鏡
f_obj, f_eye = 1.3, 0.065     # 米
M = f_obj / f_eye
print(f"物鏡焦距 {f_obj} m / 目鏡焦距 {f_eye} m → 放大率 {M:.0f} 倍")

# 肉眼分辨極限約 2 角分；20 倍鏡分辨極限 = 2/20 角分
eye_limit = 2.0
scope_limit = eye_limit / M
print(f"肉眼分辨極限 {eye_limit} 角分 → 望遠鏡 {scope_limit:.2f} 角分")
print(f"木星衛星視角約 0.5~2 角分：肉眼不可見，望遠鏡可見 ✓")

# 金星相位判決：兩種宇宙論對金星視角（相位的軌道位置）的不同預言
# 托勒密體系：金星本輪始終在日地連線上 → 永遠呈「新月形」
# 哥白尼體系：金星繞日 → 有完整相位（新月~滿月）
print("\n--- 金星相位的判決 ---")
print("托勒密：金星永遠在太陽附近、永遠呈新月 → 只能見『部分』相位")
print("哥白尼：金星繞日，可運行到太陽背面 → 可見『滿月』相位")
# 伽利略 1610 年 12 月觀測到金星呈半圓甚至近滿月相位
print("伽利略觀測：金星呈近滿圓相位 → 托勒密被否決，哥白尼獲勝！")

# 簡化的軌道驗證：金星軌道半徑 0.723 AU（內行星）
R_v, R_e = 0.723, 1.0
# 金星最大離角（大距）= arcsin(R_v/R_e) ≈ 46°——與觀測相符
elong = math.degrees(math.asin(R_v / R_e))
print(f"\n金星大距理論值 = arcsin(0.723) ≈ {elong:.0f}°（與觀測的 45–47° 相符）")
print("→ 角度、相位、週期全部吻合日心幾何：技術造的新實驗審判了舊理論。")
```
