# 1865 麥克斯韋方程組

## 案發現場

1865 年的倫敦，電磁學的實驗拼圖已經齊備：[1600-吉爾伯特磁學.md](1600-吉爾伯特磁學.md) 的定性觀察、[1800-伏打電堆.md](1800-伏打電堆.md) 的穩定電源、奧斯特 1820 年的電生磁、安培的電流磁力定律、[1831-法拉第電磁感應.md](1831-法拉第電磁感應.md) 的磁生電。但拼圖散落一地：**沒有人把它們拼成一套統一的數學理論**。法拉第本人不會微積分——他的「力線」圖像語言，在學院數學家眼中只是不嚴謹的比喻。電、磁、光三者之間的關係，更是無人能答。

本案的「偵探」是一位蘇格蘭貴族出身的數學天才——詹姆斯·克拉克·麥克斯韋（James Clerk Maxwell, 1831–1879）。他 15 歲發表第一篇數學論文，劍橋數學榮譽學位考試第二名。而他的破案使命，正是**把法拉第的圖像翻譯成數學**。

## 偵查過程

**第一步：翻譯法拉第。** 1855–1862 年間，麥克斯韋系列論文《論法拉第的力線》《論物理力線》《電磁場的動力理論》逐步完成翻譯工作。他的天才之處不是把法拉第硬套進當時流行的超距作用數學，而是**把力線變成真實的物理對象**——電磁場本身是載有能量與動量的連續介質。

**第二步：補上缺環——位移電流。** 麥克斯韋發現拼圖有一道缺口：安培定律 $\nabla\times\mathbf{B} = \mu_0\mathbf{J}$ 在電容器情形下自相矛盾（極板間沒有電流，磁場卻要「連續」）。麥克斯韋的天才補丁：**變化的電場也等效於電流**——他稱之為「位移電流」：

$$\mathbf{J}_D = \varepsilon_0\frac{\partial\mathbf{E}}{\partial t}$$

這個補丁在當時沒有任何實驗依據，純粹為了數學自洽。但它成為整個理論最革命的一步：**變化的電場生磁，正如變化的磁場生電（法拉第）**——於是電場與磁場可以互相激發、自我維持，在空間中以波的形式傳播。

**第三步：預言電磁波，算出光速。** 1865 年，麥克斯韋把四條定律整理成方程組（現代形式的四個向量方程是他死後由亥維賽簡化的）：

$$\nabla\cdot\mathbf{E} = \frac{\rho}{\varepsilon_0},\quad \nabla\cdot\mathbf{B} = 0,\quad \nabla\times\mathbf{E} = -\frac{\partial\mathbf{B}}{\partial t},\quad \nabla\times\mathbf{B} = \mu_0\mathbf{J} + \varepsilon_0\frac{\partial\mathbf{E}}{\partial t}$$

從中推出電磁波的傳播速度：

$$c = \frac{1}{\sqrt{\varepsilon_0\mu_0}}$$

代入實驗測得的電磁常數，得到約 $3.1\times10^8$ m/s——與斐索、傅科測得的光速**驚人吻合**。麥克斯韋寫下了物理學史上最偉大的推論之一：

> 「我們幾乎無法避免這個推論：光本身就是電磁擾動，以波的形式在電磁場中傳播。」

**電、磁、光——三個看似無關的現象，被四個方程統一。** 這是牛頓《原理》（[1687-牛頓原理.md](1687-牛頓原理.md)）之後物理學的第二次大統一。

**第四步：等待實驗蓋章。** 理論領先了實驗二十三年：麥克斯韋 1879 年去世，未能親眼看到 [1888-赫茲電磁波.md](1888-赫茲電磁波.md) 的實驗捕獲他預言的波。等待時間雖長，卻比哥白尼等日心說的六十年短得多——迴路在加速。

## 結案報告

麥克斯韋方程組是**實驗定律的數學大一統，光即電磁波**。用金觀濤的框架說，本案屬於**理論**環節，它對「雙迴路大加速」的推動是電這條線的頂點：

1. **法拉第的實驗被理論收編**——四個方程把六十年實驗（奧斯特、安培、法拉第）全部入帳，電磁學成為一門成熟的數學科學。
2. **光學與電磁學合流**——光即電磁波：光學從此成為電磁學的分支，光譜學、光通信全部改寫。
3. **相對論的伏筆**——方程組在伽利略變換下不協變，這道裂縫最終逼出愛因斯坦的狹義相對論（1905）。
4. **技術的孵化清單**——無線電（[1895-馬可尼無線電.md](1895-馬可尼無線電.md)）、雷達、廣播、光纖——整個資訊時代的電磁技術，都是這四個方程的物化。

## 證據與工具

```python
import math

# 麥克斯韋的偉大推論：c = 1/sqrt(ε0·μ0)
epsilon_0 = 8.854187817e-12   # 真空介電常數 F/m（電學實驗測得）
mu_0 = 1.25663706e-6          # 真空磁導率 H/m（磁學實驗測得）

c_maxwell = 1 / math.sqrt(epsilon_0 * mu_0)
c_light = 2.99792458e8        # 光速實測值 m/s

print(f"麥克斯韋算出的電磁波速：{c_maxwell:.4e} m/s")
print(f"光速實測值：            {c_light:.4e} m/s")
print(f"相對誤差：{abs(c_maxwell-c_light)/c_light*100:.2f}%")
print("=> 電磁波以光速傳播：光即電磁波！")

# 電磁波譜：麥克斯韋預言的波，遠不止可見光
bands = [("無線電", 3e6, 3e9), ("微波", 3e9, 3e12), ("紅外", 3e12, 4.3e14),
         ("可見光", 4.3e14, 7.5e14), ("紫外", 7.5e14, 3e16), ("X光", 3e16, 3e19)]
for name, f1, f2 in bands:
    l1, l2 = c_light/f2, c_light/f1
    print(f"{name}: 波長 {l1:.2e} – {l2:.2e} m")
print("=> 電磁譜從無線電到 X 光，全部由同一組方程統治。")
```
