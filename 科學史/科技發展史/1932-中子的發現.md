# 1932 中子的發現：異常實驗數據的十年追查

## 案發現場

1932 年 2 月，劍橋卡文迪許實驗室。詹姆斯·查德威克（James Chadwick）發表了一篇僅兩頁的短文〈論中子存在的可能性〉。文中他用最古典的武器——能量守恆與動量守恆——證明了一個驚人的結論：一年來困擾歐洲物理學界的「鈹輻射」，不是 γ 射線，而是一種**質量與質子相當、卻不帶電的新粒子**——中子。

這個發現補全了原子核的最後一塊拼圖：原子核由質子與中子組成。但案件的前奏，是一對法國夫婦與一個錯誤的判斷。

## 偵查過程

**異常數據（1931）。** 1930 年，德國物理學家博特（Bothe）與貝克爾發現：用 α 粒子轟擊鈹，會產生一種穿透力極強的輻射。1931 年，約里奧-居禮夫婦（Frédéric 與 Irène Joliot-Curie）接手研究，發現這種輻射能把石蠟中的氫核（質子）打出來，而且打出的質子能量高達 5 MeV。

約里奧-居禮夫婦依循當時的常識，把這種輻射判定為 γ 射線。這個判斷有一個致命漏洞：γ 光子要把質子撞到 5 MeV，按能量與動量守恆計算，γ 光子本身必須擁有約 50 MeV 的能量——遠高於 α+鈹反應所能提供的能量。**數據與「γ 射線」的解釋之間出現了一道鴻溝**。夫婦倆看到了異常，卻沒有抓住它——他們在論文中只說「這需要進一步研究」。

**十年追問（1920–1932）。** 查德威克的優勢是他腦中裝著一個老問題。1920 年，他的老師盧瑟福在貝克講座中提出過一個假說：原子核裡可能存在一種「質量與質子相近、電荷為零」的粒子——他暫稱之為 neutron。此後十二年，查德威克一直在尋找它。所以當他讀到約里奧-居禮夫婦的論文時，反應完全不同：他立刻意識到——**這可能就是中子！**

**守恆律的反推（1932）。** 查德威克重做了實驗，用鈹輻射分別打氫、氮、鋰等輕核，測量被打出的反衝核能量，然後做了一件約里奧-居禮夫婦沒做的事：**用守恆律反推入射粒子的質量**。結果：無論撞哪種核，反推質量都約等於質子質量；而 γ 光子（零質量）不可能同時符合所有碰撞數據。中子存在，鐵證如山。

查德威克後來回憶，約里奧-居禮夫婦的失誤在於「沒讀過盧瑟福 1920 年的講座」——他們腦中沒有中子假說，所以看見了數據卻看不見答案。理論（假說）⇒實驗（設計）的通道在此清晰可見。

## 結案報告

查德威克於 1935 年獲諾貝爾物理學獎。中子的發現是「實驗⇒理論」與「理論⇒實驗」雙向通道的示範：

1. **原子核被補全**——質子-中子模型取代質子-電子模型，解決了核自旋與統計性的矛盾。
2. **核物理的新彈藥**——中子不帶電、不受庫倫位障阻擋（對照 [1932-粒子加速器.md](1932-粒子加速器.md) 中質子面對的位障），是轟擊原子核的理想炮彈，直接通往 [1938-核裂變.md](1938-核裂變.md) 與 [1942-費米核反應堆.md](1942-費米核反應堆.md)。
3. **方法論的教訓**——重大發現常屬於「腦中有問題的人」：異常數據人人可見，但只有裝著正確假說的頭腦能抓住它。約里奧-居禮夫婦同年（1932）用類似方法發現正電子，錯失中子後他們學到了教訓——1934 年發現人工放射性，終於獲得諾貝爾化學獎（1935）。
4. **守恆律的勝利**——能量與動量守恆這兩條最古典的定律，成為拆解微觀世界最鋒利的手術刀。

## 促進鏈分析

- **實驗⇒理論（主通道之一）**：約里奧-居禮夫婦的異常數據（質子反衝能量 5 MeV 與 γ 解釋矛盾，1931）⇒ 查德威克證明中子存在（1932）——異常數據逼出新粒子。
- **理論⇒實驗（主通道之二）**：盧瑟福的中子假說（1920）⇒ 查德威克的實驗設計——十二年來「尋找中子」的問題意識，決定了查德威克會重做哪些實驗、反推哪些質量。
- **理論⇒實驗（交叉）**：α+鈹反應的核物理知識 ⇒ 博特、貝克爾、約里奧-居禮、查德威克的連續實驗——前人的核反應理論指定了後人該轟擊什麼。
- **實驗⇒實驗（繼承）**：博特的計數器實驗 ⇒ 約里奧-居禮的雲室/電離實驗 ⇒ 查德威克的反衝核測量——儀器與方法層層繼承。
- **實驗⇒技術（遠期）**：中子成為炮彈 ⇒ 核反應堆（1942）、中子繞射分析材料結構。

本篇九通道主通道：**實驗⇒理論**。特色：一個實驗的異常數據，配上另一個理論的預先假說，才能逼出新粒子——單靠實驗或單靠假說都不夠。

## 證據與工具

```python
# 用 Python 重做查德威克的計算：用守恆律反推鈹輻射粒子的質量
import numpy as np

# --- 1. 情境 A：假設鈹輻射是 γ 光子（約里奧-居禮夫婦的判斷）---
# 光子撞靜止質子（正面碰撞），質子獲得動能 Ep
# 能量守恆：E_gamma = Ep + E_gamma'
# 動量守恆：E_gamma/c = p_p + E_gamma'/c
# 聯立可得：Ep = 2 E_gamma^2 / (E_gamma + m_p c^2) → 解出 E_gamma
c2 = 938.272   # 質子靜質能 (MeV)
Ep_obs = 5.0   # 實測反衝質子動能 (MeV)

# Ep = 2E^2/(E + m_p c^2) → 2E^2 - Ep·E - Ep·m_p c^2 = 0
a_, b_, c_ = 2, -Ep_obs, -Ep_obs * c2
E_gamma = (-b_ + np.sqrt(b_**2 - 4*a_*c_)) / (2*a_)
print("--- 情境 A：鈹輻射 = γ 光子？ ---")
print(f"要撞出 {Ep_obs} MeV 的質子，γ 光子需 E ≈ {E_gamma:.1f} MeV")
# α+鈹反應最多能提供多少能量？
m_Be9, m_alpha, m_C13 = 9.012183, 4.002603, 13.003355
Q_Be = (m_Be9 + m_alpha - m_C13) * 931.494
print(f"但 α+鈹→碳-13 反應的 Q 值僅 ≈ {Q_Be:.1f} MeV")
print(f"矛盾！γ 需 {E_gamma:.0f} MeV，反應只提供 {Q_Be:.0f} MeV")
print("→ γ 光子解釋破產（約里奧-居禮夫婦的鴻溝）")

# --- 2. 情境 B：鈹輻射 = 中子（查德威克的假說）---
# 中子（質量 m_n）撞靜止質子，正面碰撞時質子動能：
#   Ep = 4 m_n m_p / (m_n + m_p)^2 × En（類彈性散射）
m_p = 1.007276   # 質子質量 (u)
m_n_guess = m_p  # 假說：m_n ≈ m_p
En_needed = Ep_obs * (m_n_guess + m_p)**2 / (4 * m_n_guess * m_p)
print(f"\n--- 情境 B：鈹輻射 = 中子（m_n ≈ m_p）---")
print(f"撞出 {Ep_obs} MeV 質子，只需中子動能 ≈ {En_needed:.1f} MeV")
print(f"遠小於 Q 值 {Q_Be:.0f} MeV + α 粒子動能 → 完全合理！")

# --- 3. 用不同靶核反推質量（查德威克的關鍵手法）---
# 正面碰撞：反衝核動能 Er = 4 m_n m_t/(m_n+m_t)^2 × En
# 比值公式：Ep/Er = m_p(m_n+m_N)^2 / (m_N(m_n+m_p)^2)，由此解 m_n
m_N = 14.007  # 氮核（查德威克也測了氮）
Er_N_obs = 1.2  # 實測氮反衝核動能 ≈ 1.2 MeV
def f(mn):
    return m_p*(mn + m_N)**2 / (m_N*(mn + m_p)**2) - Ep_obs/Er_N_obs
lo, hi = 0.1, 20.0  # 二分法求根
for _ in range(100):
    mid = (lo + hi) / 2
    if f(lo) * f(mid) < 0:
        hi = mid
    else:
        lo = mid
print(f"\n--- 守恆律反推質量（氫/氮雙靶比值法）---")
print(f"由氫與氮的反衝動能反推：m_n ≈ {mid:.2f} u（質子質量 ≈ {m_p} u）")
print("→ 無論撞哪種核，反推質量都 ≈ 質子質量")
print("→ 中子存在！鐵證如山（查德威克 1932）")
```
