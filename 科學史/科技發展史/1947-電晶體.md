# 1947 電晶體

## 案發現場

1947 年 12 月 23 日，美國紐澤西州默里丘（Murray Hill），貝爾實驗室。三位物理學家——巴丁（John Bardeen）、布拉頓（Walter Brattain）、蕭克利（William Shockley）——圍著一台简陋的實驗裝置：一塊鍺晶片、一支彎成三角形的彈簧與金箔觸點、一個耳機。他們把輸入訊號接上，輸出端出現**放大的訊號**——耳機裡傳出清晰的聲音。布拉頓在筆記本上記下這一天；這是人類歷史上第一支**電晶體（transistor）**。

迴路的載體，從此要從能量換成資訊。

「案發現場」的理論基礎是量子力學（[1926-薛丁格方程.md](1926-薛丁格方程.md)）：能帶理論說明固體為何有導體、半導體、絕緣體之別；1931 年威爾遜（Wilson）的能帶理論、摻雜半導體的載流子理論——理論早已指出「用電場控制半導體中電流」的可能，只等一雙實驗的手把它做出來。這是「理論→技術」的最直接物化。

## 偵查過程

**線索一：理論的預言。** 貝爾實驗室戰後成立固態物理小組，蕭克利主張用「場效應」原理——以電場調控半導體表面載流子濃度——造出固態放大器，取代體積大、易碎、耗電的真空管。理論計算看似無懈可擊，但蕭克利的場效應實驗**屢屢失敗**。

**線索二：巴丁的表面態理論。** 巴丁（量子力學訓練出身）找出失敗原因：半導體表面存在「表面態」——表面懸鍵捕捉電子，形成屏蔽層，電場根本調控不到內部載流子。這一解讀改變偵查方向：既然表面效應這麼強，**那就直接利用表面效應**。

**線索三：布拉頓的實驗。** 12 月的實驗中，布拉頓把金箔觸點壓在氧化層被刻意沖洗掉的鍺表面，兩個觸點相距極近（幾十微米）——輸入端的電流改變表面載流子濃度，輸出端出現**電壓增益**。這就是「點接觸電晶體」。巴丁與布拉頓的專利申請避開了蕭克利——蕭克利不甘，一個月內閉關寫出更好的設計：**接面電晶體（junction transistor）**，以三層半導體（N-P-N）夾出可精確控制的放大結構，才是日後量產的版本。1956 年三人共享諾貝爾物理獎；而蕭克利後來西遷矽谷創業，其下屬八人出走創辦快捷半導體（Fairchild），再孵化英特爾——「八叛逆」直接通往 [1958-積體電路.md](1958-積體電路.md) 與 [1971-微處理器.md](1971-微處理器.md)。

**線索四：命名。** 貝爾實驗室徵名時，貝爾實驗室的物理學家皮爾斯（Pierce）提出「transistor」——trans-（跨接）+ resistor（電阻）：**一個「跨接的電阻」**，把小訊號放大。

## 結案報告

電晶體屬於迴路的**理論→技術**合體環節——量子力學的能帶理論直接孵化出取代真空管的元件，是「理論物化為技術」的最純粹樣板。其深遠遺產：

1. **迴路載體從能量換成資訊**——第八幕的開端：繼能量迴路（蒸汽、電力、核能）之後，「資訊迴路」開始跑——電腦（[1946-ENIAC.md](1946-ENIAC.md)）從真空管走向固態，[1948-夏農資訊論.md](1948-夏農資訊論.md) 提供理論，電晶體提供技術。
2. **量子力學的工程化**——從 [1926-薛丁格方程.md](1926-薛丁格方程.md) 到電晶體只等二十一年，理論到應用的等待時間進入歷史新低。
3. **矽路線的起點**——1950 年代矽取代鍺（耐高溫、二氧化鈍化層），通往 [1958-積體電路.md](1958-積體電路.md)、[1965-摩爾定律.md](1965-摩爾定律.md)、[1971-微處理器.md](1971-微處理器.md)，再到 [2007-智慧型手機.md](2007-智慧型手機.md) 的整條摩爾定律之路。
4. **組織形式的又一次升級**——企業實驗室（貝爾）取代戰時國家計畫，成為迴路的常設載體；而「八叛逆」出走則示範了迴路如何靠人才流動自我複製。

## 證據與工具

```python
# 偵查證物一：電晶體的放大 — 貝塔（β）電流增益
I_base  = 1.0e-6   # 基極電流 1 μA
I_collector = 200e-6  # 集極電流 200 μA
beta = I_collector / I_base
print(f"電流增益 β = I_C / I_B = {beta:.0f}（小電流控制大電流 → 放大器）")

# 偵查證物二：能帶理論 — 為什麼是「半導體」
Eg_Si, Eg_Ge, Eg_dia = 1.12, 0.66, 5.47   # 能隙 (eV)
print("\n--- 能隙對比（量子力學能帶理論）---")
print(f"鑽石（絕緣體）: {Eg_dia} eV — 太寬，電子跳不過去")
print(f"矽（半導體）: {Eg_Si} eV — 恰好：室溫少數電子可跳越、可控")
print(f"鍺（半導體）: {Eg_Ge} eV — 更窄，但耐溫差 → 矽勝出")

# 溫度帳本：室溫下有多少電子能跳越能隙（波茲曼因子）
import math
kT = 0.026  # 室溫熱能 (eV)
for name, Eg in [("矽", Eg_Si), ("鑽石", Eg_dia)]:
    f = math.exp(-Eg/kT)
    print(f"{name}: 越障因子 exp(-Eg/kT) = {f:.2e}（矽可控、鑽石為零）")
```
