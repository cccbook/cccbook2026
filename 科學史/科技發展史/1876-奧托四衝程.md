# 1876 奧托四衝程

## 案發現場

1876 年的德國，動力機械被蒸汽機壟斷：鍋爐、煤倉、冷凝器、煙囪——一個小型工坊根本供養不起。蒸汽機太重、太大、啟動太慢，小型機械（車床、印刷機、未來的汽車）只能靠人力、水力或皮帶從中央蒸汽機「分功率」。要讓動力小型化，需要一種**燒液體燃料、不要鍋爐**的機器——內燃機的構想已有百年（勒努瓦 1860 年的煤氣機已商用，但效率僅 4%、壓縮比為零），缺的是理論與工程的合體。

本案的「偵探」是一位德國自學成才的推銷員——尼古勞斯·奧托（Nikolaus Otto, 1832–1891）。他原本是雜貨推銷員，被勒努瓦煤氣機的廣告打動後自費研究內燃機。而他的破案關鍵，是一個反直覺的工程洞見：**先壓縮、再點火**。

## 偵查過程

**第一步：認清勒努瓦的死因。** 奧托研究勒努瓦煤氣機（1860）的失敗，得出關鍵診斷：勒努瓦的機器**不壓縮混合氣**，活塞直接在常壓混合氣中點火膨脹——一半的行程浪費在「吸氣」上，膨脹比極小，熱效率僅 4%。而理論（[1824-卡諾熱機理論.md](1824-卡諾熱機理論.md) 與 [1850-克勞修斯第二定律.md](1850-克勞修斯第二定律.md)）早已指出：**提高效率的路是提高壓縮比、提高燃燒溫度**。奧托是第一個把熱力學公式當真、設計實機的工程師。

**第二步：四衝程循環。** 1876 年，奧托造出史上第一台四衝程內燃機，把工作循環分解成活塞的四個行程：

1. **進氣**：活塞下行，吸入煤氣與空氣的混合氣；
2. **壓縮**：活塞上行，把混合氣壓縮到原體積的數分之一；
3. **動力**：火花點火，混合氣爆燃膨脹，推動活塞下行做功；
4. **排氣**：活塞上行，排出廢氣。

關鍵在第二步：壓縮使混合氣溫度與密度大增，點火後的膨脹比遠大於勒努瓦機——理論效率從 4% 躍升至 14% 以上（實測值，同期蒸汽機僅 6–8%）。奧托的機器安靜、輕巧、啟動快，一台 3 馬力機重不過數百公斤——蒸汽機的十分之一。

**第三步：理論的追認。** 有趣的是，奧托本人並非先有理論再設計——他靠直覺與試錯造出機器，**理論是後來被工程師與學者追認的**。德國工程師們很快證明：奧托循環的效率上限可用等容加熱循環的公式表達，壓縮比越高、效率越高。理論與實踐在此互相追認、互相促進——這正是「理論—實驗—技術」迴路的教科書式運轉。

**第四步：資本的孵化。** 1872 年，奧托與工程師蘭根（Eugen Langen）創辦 DEUTZ 發動機廠，四衝程專利帶來豐厚利潤。1886 年專利到期後，德國工程師戴姆勒（提高轉速、用汽油）與狄塞爾（更高壓縮比、壓燃）迅速在此基礎上開出新分支——[1885-賓士汽車.md](1885-賓士汽車.md) 的汽車與後來的柴油機，全部是奧托循環的子孫。

## 結案報告

奧托四衝程是**熱力學落地為輕型動力**的勝利。用金觀濤的框架說，本案屬於**技術⚙環節**，它對「雙迴路大加速」的推動在於：

1. **動力小型化**——動力第一次可以裝進任何工坊、車輛、船艇：蒸汽機的「中央分功率」時代結束，分散式動力時代開始。
2. **熱力學理論的工程兌現**——卡諾與克勞修斯指出的「提高壓縮比」之路，由奧托實機兌現：理論—技術迴路在內燃機領域閉合。
3. **液體燃料的時代**——汽油、柴油比煤氣便於攜帶：交通運輸（汽車、飛機如 [1903-萊特兄弟飛機.md](1903-萊特兄弟飛機.md)）的能源基礎由此奠定。
4. **迴路的加速**——奧托→戴姆勒→狄塞爾：技術分支的繁殖速度遠快於蒸汽機時代，內燃機迴路轉速暴增。

## 證據與工具

```python
# 奧托循環（等容加熱循環）的理論效率
# η = 1 - 1/r^(γ-1)，r 為壓縮比，γ 為比熱比（空氣約 1.4）

def otto_efficiency(r, gamma=1.4):
    return 1 - 1 / r**(gamma - 1)

print("--- 壓縮比與效率：熱力學的鐵律 ---")
cases = [("勒努瓦煤氣機（不壓縮，r≈1）", 1.0),
         ("早期奧托機（r≈2.5）", 2.5),
         ("現代汽油機（r≈10）", 10.0),
         ("現代柴油机（r≈18）", 18.0)]
for name, r in cases:
    if r <= 1:
        print(f"{name}: η ≈ 0%（壓縮比為零，無膨脹可言）")
    else:
        print(f"{name}: η = {otto_efficiency(r)*100:.1f}%")
print("=> 壓縮比越高效率越高：這就是奧托『先壓縮、再點火』的理論依據。")

# 對比：1876 年實測
print("\n--- 1876 年實測對比 ---")
print(f"奧托四衝程實測效率：約 14%（蒸汽機同期僅 6–8%）")
print(f"奧托機 3 馬力重約 500 kg，同功率蒸汽機重約 5000 kg")
print("=> 輕、靜、快：動力小型化的勝利。")

# 四衝程示意
print("\n--- 四衝程循環 ---")
for s in ["①進氣：活塞下行，吸入混合氣",
          "②壓縮：活塞上行，壓縮至 1/r 體積",
          "③動力：點火爆燃，膨脹做功",
          "④排氣：活塞上行，排出廢氣"]:
    print(s)
```
