# 1953 DNA 雙螺旋

## 案發現場

1953 年 2 月 28 日，英國劍橋，卡文迪許實驗室（[1687-牛頓原理.md](1687-牛頓原理.md) 時代以降英國物理學的大本營）。一位 25 歲的美國後博士研究生華生（James Watson, 1928–）與一位 36 歲的英國物理學家克里克（Francis Crick, 1916–2004），在鷹吧（Eagle Pub）的午餐桌上宣告：**我們找到了生命的秘密**——DNA 的分子結構是**雙螺旋**。

在此之前，基因的「載體」懸而未決：孟德爾的遺傳因子（1860 年代）、染色體學說（1900 年代初）、艾弗里 1944 年證明「轉型因子」是 DNA——但 DNA **如何儲存遺傳資訊、如何複製**，無人能答。這是一樁證據分散在各實驗室、卻沒有統一模型的懸案。

## 偵查過程

這樁案件的偵查手法，是「X 光繞射實驗數據＋模型建構」的雙線合流：

**線索一：倫敦的 X 光繞射數據。** 倫敦國王學院的羅莎琳·富蘭克林（Rosalind Franklin, 1920–1958）以精湛的 X 光繞射技術，拍出 DNA 纖維的「照片 51」——繞射圖案呈清晰的 X 形交叉，表明螺旋結構；富蘭克林還測出關鍵參數：螺旋直徑約 2 奈米、每圈 10 個鹼基、節距 3.4 奈米，以及「骨架在外、鹼基在內」的判斷。她的技術屬於迴路的**實驗**環節——而 X 光繞射技術本身，正是 [1895-倫琴X光.md](1895-倫琴X光.md) 與 [1913-玻爾原子模型.md](1913-玻爾原子模型.md) 時代布萊格父子開創的晶體學傳統（卡文迪許實驗室主持人正是小布萊格）。

**線索二：查加夫法則。** 哥倫比亞大學的查加夫（Erwin Chargaff）1950 年的化學分析顯示：DNA 中 A 與 T 的數量相同、G 與 C 的數量相同——**A=T、G=C**。這個「法則」當時無人能解釋，卻是破解配對的關鍵線索。

**線索三：模型的偵探戰。** 華生與克里克的手法是**模型建構**：用金屬片拼出分子的三維模型，逐一檢驗與所有證據的相容性。第一次嘗試（三螺旋、骨架在內）被富蘭克林的數據否定；關鍵突破來自兩件事：華生看到「照片 51」（富蘭克林與威爾金斯在未充分知會的情況下提供的資料，成為科學史上最著名的資料倫理爭議之一）；以及化學家多諾休（Donohue）指出華生抄錯了鹼基的互變異構形式——修正後，A-T 以兩個氫鍵、G-C 以三個氫鍵精準配對，**兩條骨架自然反向平行纏繞成雙螺旋**，直徑與節距與富蘭克林的數據完美吻合。

克里克意識到配對的深意：**「互補配對意味著複製機制」**——兩條鏈分開，各自作為模板，就能複製出兩份相同的 DNA。遺傳資訊的儲存與複製，一次破解。

1953 年 4 月 25 日，《自然》期刊發表了那篇九百多字、一張圖的論文——克里克與華生寫下那句著名結語：

> 「我們並未忽略，我們所設想的配對機制，直接暗示了遺傳物質的一種可能的複製方式。」

## 結案報告

DNA 雙螺旋屬於迴路的**實驗+理論**合體環節——X 光繞射數據（富蘭克林）＋查加夫法則（化學實驗）＋模型建構（理論偵探戰），三線合流。其深遠遺產：

1. **遺傳學獲得分子基礎**——基因從抽象因子變成可讀寫的分子序列；1958 年梅塞爾森—斯塔爾實驗證實半保留複製。
2. **資訊迴路進入生命科學**——DNA 是儲存遺傳**資訊**的分子：第八幕「迴路載體從能量換成資訊」的主題在此擴展到生命本身，通往基因工程與 [1996-桃莉羊.md](1996-桃莉羊.md)。
3. **資料倫理的教訓**——富蘭克林 1958 年死於癌症，未能分享 1962 年諾貝爾獎（已故者不授獎）；「照片 51」的資料使用爭議成為科學倫理的經典案例。
4. **實驗與理論的合流新樣板**——與 [1938-核裂變.md](1938-核裂變.md) 同型：化學實驗提供證物，理論偵探完成解讀，迴路的雙環節缺一不可。

## 證據與工具

```python
# 偵查證物一：查加夫法則 — A=T、G=C 的化學帳本
from collections import Counter

# 人類 DNA 的鹼基組成（實測約值）
human_dna = {"A": 30.9, "T": 29.4, "G": 19.9, "C": 19.8}  # 百分比
print("--- 查加夫法則：A≈T、G≈C ---")
print(f"A = {human_dna['A']}%  vs  T = {human_dna['T']}%")
print(f"G = {human_dna['G']}%  vs  C = {human_dna['C']}%")
print("→ 嘌呤與嘧啶一一配對，組成相等（差為實驗誤差）")

# 偵查證物二：雙螺旋的幾何 — 富蘭克林測出的參數
import math
diameter = 2.0     # 奈米
bp_per_turn = 10   # 每圈 10 個鹼基
rise = 0.34        # 每鹼基上升 0.34 奈米
print(f"\n--- B 型 DNA 幾何 ---")
print(f"直徑 {diameter} nm，每圈 {bp_per_turn} 個鹼基，節距 {bp_per_turn*rise:.1f} nm")
print(f"每圈旋轉 360°，相鄰鹼基夾角 {360/bp_per_turn:.0f}°")

# 偵查證物三：氫鍵的互補配對 — 為什麼是 A-T、G-C
pairs = {"A-T": 2, "G-C": 3}   # 氫鍵數
print("\n--- 互補配對（氫鍵數）---")
for p, n in pairs.items():
    print(f"{p}: {n} 個氫鍵")
print("A（嘌呤，雙環）只能配 T（嘧啶，單環）→ 直徑恆定 2 nm")
print("互補配對 → 兩鏈分開各作模板 → 複製機制自動成立")
```
