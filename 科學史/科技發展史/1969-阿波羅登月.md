# 1969 阿波羅登月

## 案發現場

1969 年 7 月 20 日 20 時 17 分（UTC），月球靜海（Sea of Tranquility）。阿波羅 11 號登月艇「老鷹號（Eagle）」著陸，杭思朗（Neil Armstrong, 1930–2012）踩上月面，留下那句刻在人類記憶裡的話：

> 「這是我個人的一小步，卻是人類的一大步。」

四天之後，兩人安全濺落太平洋。阿波羅計畫（1961–1972）動員約 40 萬人、兩萬家企業與大學、耗資約 250 億美元（今日約 2,500 億），是人類歷史上最大規模的和平時期工程總動員。

「案發現場」的點火來自冷戰：[1957-史潑尼克.md](1957-史潑尼克.md) 的「嗶嗶」聲震動美國，1961 年蘇聯加加林（Gagarin）成為第一個上太空的人，甘迺迪總統當年 5 月在國會宣布：「在這十年結束之前，把人送上月球並安全帶回。」**理論早已就緒（牛頓軌道力學），技術大致齊備（火箭、電腦），只等國家意志灌進迴路。**

## 偵查過程

阿波羅的「偵查」是一場國家級總動員的迴路運轉：

**線索一：火箭——農神五號。** 登月需要的推進力遠超史潑尼克的 R-7：農神五號（Saturn V）高 111 米、重 3,000 噸、三級、起飛推力 3,400 萬牛頓——至今仍是史上最大的火箭。其設計師馮·布朗（Wernher von Braun）正是 V-2 飛彈（1944）的總工程師：戰時技術（[1945-原子彈.md](1945-原子彈.md) 時代的戰時動員）流向太空計畫，迴路的載體跨計畫流動。

**線索二：導航——阿波羅導航電腦（AGC）。** 登月艇需要即時軌道計算，而當時的電腦是整個房間的 ENIAC（[1946-ENIAC.md](1946-ENIAC.md)）級怪物。MIT 儀器實驗室把整台電腦縮進一台 32 公斤的機器：用 [1958-積體電路.md](1958-積體電路.md)（晶片）——**阿波羅消化了當時全球六成的積體電路產量**，把 IC 價格拉下量產曲線，直接餵養 [1965-摩爾定律.md](1965-摩爾定律.md) 與 [1971-微處理器.md](1971-微處理器.md)。

**線索三：著陸的現場推理。** 老鷹號下降時電腦發出「1202 警報」（運算超載），杭思朗手動接管，在剩餘燃料約 25 秒的狀態下找到安全著陸點——人類判斷與機器運算的合體。這是迴路的現場縮影：**理論（軌道力學）→ 技術（電腦、火箭）→ 人的決斷**。

**線索四：總動員的迴路組織。** 與曼哈頓計畫（[1945-原子彈.md](1945-原子彈.md)）同型：國家計畫、系統工程、數十萬人同步——但目的從毀滅轉向探索。NASA 的「系統工程」方法（把百萬零件的可靠性用機率管理）成為戰後大科學的模板。

## 結案報告

阿波羅登月屬於迴路的**技術⚙**環節——國家總動員的工程極限，理論與實驗環節基本就緒、由國家意志灌滿迴路。其深遠遺產：

1. **迴路組織形式的頂點**——個人（伽利略）→ 學會（皇家學會）→ 工業實驗室（愛迪生）→ 國家計畫（曼哈頓）→ **和平時期國家工程（阿波羅）**→ 全球開源網絡（[1989-全球資訊網.md](1989-全球資訊網.md)）。
2. **積體電路的拉量產者**——阿波羅與民兵飛彈消化早期 IC，把 [1965-摩爾定律.md](1965-摩爾定律.md) 的曲線啟動。
3. **地球的視角**——從月球拍回的「地球升起」照片成為環保運動的圖騰：太空迴路反過來改變人類對地球的認知。
4. **大科學的兩面性**——阿波羅證明迴路可以做到任何事，也證明迴路的轉速由「政治意志」決定：1972 年阿波羅終止後，人類至今未再踏足月球——迴路可以加速，也可以停擺。

## 證據與工具

```python
# 偵查證物一：地月軌道 — 牛頓力學的裁決
import math
G, M_earth, M_moon = 6.674e-11, 5.972e24, 7.348e22
d_earth_moon = 3.844e8    # 地月距離 (m)

# 地月之間的重力平衡點（拉格朗日 L1，近似）
r = d_earth_moon / (1 + math.sqrt(M_moon/M_earth))  # 粗略估算
print(f"地月距離：{d_earth_moon/1000:.0f} km")
print(f"重力平衡點距地球約：{r/1000:.0f} km（登月軌道規劃的理論基礎）")

# 偵查證物二：逃逸速度 — 為什麼需要農神五號
v_escape = math.sqrt(2*G*M_earth/6.371e6)
v_orbit = math.sqrt(G*M_earth/6.371e6)
print(f"\n地球軌道速度：{v_orbit/1000:.2f} km/s（史潑尼克）")
print(f"地球逃逸速度：{v_escape/1000:.2f} km/s（登月所需）")

# 偵查證物三：AGC 的運算力帳本 — 積體電路的拉量產
agc_ops = 40000          # 阿波羅導航電腦每秒約 4 萬次運算
eniac_ops = 5000         # ENIAC（[1946-ENIAC.md]）
modern_ops = 1e12
print(f"\nAGC 運算力：{agc_ops} 次/秒（ENIAC 的 {agc_ops/eniac_ops:.0f} 倍，重 32 kg）")
print(f"現代手機：{modern_ops:.0e} 次/秒 —— 阿波羅消化六成 IC 產量，啟動摩爾定律")
```
