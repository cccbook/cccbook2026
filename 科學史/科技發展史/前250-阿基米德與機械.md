# 前250 阿基米德與機械

## 案發現場

公元前 250 年前後，希臘化世界的敘拉古（Syracuse）。工匠們使用槓桿、滑輪、絞盤已有數千年（見 [前3000-青銅與輪子.md](前3000-青銅與輪子.md)），人人知道「長臂省力」，卻無人能說出**為什麼**、**省多少**。

當時的知識版圖有一道奇特的裂縫：古希臘自然哲學（柏拉圖、亞里士多德）關心天體與「完美的自然」，鄙視工匠器物為「卑賤的手藝」；而工匠只有經驗，沒有幾何。**理論與技術兩不相往來**——這正是古代技術無法自我加速的根源。

謎團：有沒有人能讓理論「俯身」下來，用幾何證明機械的原理？

## 偵查過程

敘拉古的阿基米德（Archimedes, 約前 287–前 212）做到了。他是幾何學家，卻不恥於研究槓桿——他做了一件整個古代世界幾乎無人做的事：**用公理化的歐氏幾何，證明槓桿定律**。

他的推理路徑在《論平面圖形的平衡》中清晰可見：

1. **設公理**：離支點等距的等重物體處於平衡（對稱性，無可爭議）。
2. **歸約**：把任意重物分割成小塊，證明重心的槓桿等效原理——一個物體對槓桿的作用，等同於其全部重量掛在重心上。
3. **證得**：由這幾條自明公理，嚴格推出一般情況：

$$F_1 \cdot L_1 = F_2 \cdot L_2$$

這是**第一條用數學證明的物理定律**——不是經驗規則，而是從公理演繹出的必然結論。理論第一次直接解釋了技術。

阿基米德隨即把理論「物化」回技術。據普魯塔克記載，他對敘拉古國王希倫說出了那句名言：

> 「給我一個支點，我可以移動地球。」

國王要他兌現：一艘擱淺的大船。阿基米德設計了一套複合滑輪組，獨自一人（一說只用少量助手）將滿載的船緩緩拉動上岸——眾人驚為神蹟。他還發明了**阿基米德螺旋提水器**：螺旋管在圓筒中旋轉，把水連續提升到高處，至今仍在埃及與荷蘭使用。

前 212 年羅馬圍攻敘拉古，他設計的投石機與起重鐵爪（把羅馬戰艦吊起掀翻）讓羅馬軍隊久攻不下。羅馬主將馬塞勒斯下令：活捉此人。可惜城破時，一位士兵殺死了正在沙地上畫幾何圖形的老人——阿基米德最後的話是：

> 「別踩壞我的圓！」

## 結案報告

阿基米德證明了「理論可以解釋並改進技術」，這條路線如果持續下去，科學革命也許能提前一千八百年。但悲劇正在於：**他是孤例，沒有形成迴路**。

1. **後繼無人**——羅馬人重工程輕理論，希臘化科學隨政治衰亡；槓桿定律被寫下後，一千年間無人用它造出新儀器、做出新實驗。
2. **缺少實驗環節**——阿基米德靠幾何演繹而非受控實驗；沒有實驗檢驗與量產數據，理論無法滾雪球。
3. **靜力學的天花板**——他達到了古代力學的頂峰（《方法》一書甚至預演了積分思想），但沒有機械鐘（[1280-機械鐘.md](1280-機械鐘.md)）那樣的精確計時技術，動力學（運動的原因）無從研究，直到伽利略（[1638-兩門新科學.md](1638-兩門新科學.md)）與牛頓（[1687-牛頓原理.md](1687-牛頓原理.md)）才接續。

阿基米德之死象徵著古代「理論—技術」單線的斷裂：羅馬士兵殺死的不只是一位老人，而是一個可能的世界線。

## 證據與工具

```python
# 用 Python 驗證阿基米德槓桿定律：F1*L1 = F2*L2
# 情境：把擱淺大船（約 50 公噸）用支點槓桿撬動，人手能施力 60 kgf

W = 50_000        # 船重，單位 kgf
F = 60            # 一人的力量，kgf

# 所需的力臂比
ratio = W / F
print(f"船重 {W} kgf，人力 {F} kgf")
print(f"力臂比 L_人力 / L_船 = {ratio:.1f} 倍")

# 若短臂（船側）取 0.5 m，長臂需要多長？
L_short = 0.5
L_long = L_short * ratio
print(f"短臂 {L_short} m → 長臂需 {L_long:.0f} m（≒阿基米德說的『給我支點』）")

# 複合滑輪組：n 段繩索分擔重量，省力 n 倍（忽略摩擦）
for n in [5, 10, 20]:
    need = W / n
    print(f"{n:>3} 段滑輪組：僅需拉力 {need:.0f} kgf"
          f"{' ← 一人可拉動！' if need <= F else ''}")

# 檢驗槓桿平衡：左右兩邊「力 × 力臂」是否相等
F1, L1 = 60, L_long
F2, L2 = W, L_short
print(f"\n驗證：F1×L1 = {F1*L1:.0f}，F2×L2 = {F2*L2:.0f}")
print("相等 → 槓桿定律成立。阿基米德用幾何證明的，這裡用數字驗證。")
```
