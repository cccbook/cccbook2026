# 1895 馬可尼無線電

## 案發現場

1895 年的義大利博洛尼亞郊外，一位 21 歲的富家子弟正在自家莊園的閣樓與花園之間架設天線與金屬粉屑檢波器——他要讓一個七年前被發現、卻被發現者本人認定「大概沒什麼用」的電磁波（見 [1888-赫茲電磁波.md](1888-赫茲電磁波.md)），變成跨越空間的通信工具。

案發現場的背景是：電報（[1844-莫斯電報.md](1844-莫斯電報.md)）已經鋪滿陸地與海底，但鋪線的成本高昂——跨越大西洋的電纜費時數年、耗資數百萬美元；船隻、偏遠地區、戰場根本無線可鋪。**「無線的電報」**的構想顯然成立，可是歐洲學院物理學界的共識是：電磁波沿直線傳播，**繞不過地球的弧面，傳不了幾公里**——理論上「不可能」的事情。

本案的「偵探」是一位沒上過大學的義大利人——古列爾莫·馬可尼（Guglielmo Marconi, 1874–1937）。他申請博洛尼亞大學被拒，靠家庭教師補習物理。而他的破案關鍵，不是新理論，而是**工程上不講理的堅持：把天線架高、把功率加大、把距離推到理論說不可能的地方。**

## 偵查過程

**第一步：從赫茲到馬可尼。** 1894 年，馬可尼讀到赫茲訃聞中的實驗描述，立刻動手復現：火花隙發射器＋金屬粉屑檢波器（coherer，法國人布蘭利發明的元件——金屬屑在電磁波作用下導電率突變，可當接收開關）。1895 年，他在莊園裡把通信距離從幾米推到 1.5 公里以上，發現兩個關鍵：**把天線與地線相接（接地天線）、把天線架高**，傳輸距離大幅增長。

**第二步：推翻「直線傳播」的共識。** 學院共識認為電磁波走直線，繞不過地弧。馬可尼不懂高深的波動理論，只會一句話：**那就試試看。** 他發現波能沿地表與大氣繞射、折射傳播（後來物理學證明：地表波與 1902 年發現的電離層反射是真正原因——電離層像一面天然的天鏡，把無線電波反射回地面，遠距離通信由此可能）。實驗再次推翻理論空談——這是金觀濤所說「技術逼出真知」的又一案例。

**第三步：跨越英吉利海峽與大西洋。** 1896 年馬可尼赴英國申請專利，獲英國郵政總局支持；1897 年成立無線電報與信號公司（後來的馬可尼公司）；1899 年跨越英吉利海峽（45 公里）。1901 年 12 月 12 日，他在紐芬蘭聖約翰斯的山丘上，用風箏吊起的天線接收到**來自英國康沃爾 2900 公里外的摩斯電碼信號「S」**——橫渡大西洋的無線通信宣告成功。當時的理論家（包括一些物理學教授）公開宣稱「地球弧面使此不可能」——實驗再次勝利。

**第四步：船與海的生意。** 馬可尼的商業眼光極準：他先抓住**海上船隻**這個無線可鋪的市場。1900 年代起，遠洋郵輪紛紛裝上馬可尼電報機；1909 年，「共和國號」郵輪遇險時靠無線電報求救，全船獲救——無線電第一次證明自己能救命。1909 年馬可尼獲諾貝爾物理學獎（與布勞恩共享）。

## 結案報告

馬可尼無線電是**赫茲的實驗變成跨越海洋的生意**。用金觀濤的框架說，本案屬於**實驗→技術⚙**環節，它對迴路的推動在於：

1. **理論→預言→實驗→技術的全迴路**——法拉第（[1831-法拉第電磁感應.md](1831-法拉第電磁感應.md)）逼出麥克斯韋（[1865-麥克斯韋方程組.md](1865-麥克斯韋方程組.md)），赫茲捕獲電磁波（[1888-赫茲電磁波.md](1888-赫茲電磁波.md)），馬可尼把它變成生意：電磁這條迴路完整走完全程。
2. **資訊傳播的第三次飛躍**——從印刷術（複製成本暴跌）到電報（傳播脫離交通）到無線電（傳播脫離線路）：資訊從此無線可達。
3. **電離層的發現**——馬可尼的遠距離通信逼出電離層理論（1902）：技術需求反哺大氣物理學。
4. **科學的工業化**——馬可尼公司是最早的技術創業公司之一：個人發明家＋專利＋資本＋海運市場，第六幕「科學的工業化」的商業形態成型。

## 證據與工具

```python
# 馬可尼的工程帳：為何天線要高、接地要深？

import math

# 接地天線（馬可尼的天線）：電容加高、輻射效率提升
# 輻射功率近似 ∝ (h/λ)²（h 為天線高度）
lam = 300        # 波長 m（早期長波）
for h in [1, 10, 50]:   # 天線高度 m
    rel = (h / lam)**2
    print(f"天線高 {h:2d} m：相對輻射效率 {rel:.4f}")
print("=> 天線越高、輻射越強：馬可尼『把天線架高』的工程直覺。")

# 視距 vs 實際距離：為何「繞不過地弧」是錯的？
R_earth = 6371e3   # 地球半徑 m
antenna_h = 50     # 天線高 50 m
d_horizon = math.sqrt(2 * R_earth * antenna_h)
print(f"\n50 m 天線的視距（直線傳播極限）：{d_horizon/1000:.1f} km")
print("1901 年馬可尼實際跨越：2900 km —— 視距的 40 倍！")
print("=> 地表波繞射 + 電離層反射：理論共識被實驗推翻。")

# 摩斯電碼跨越海洋
MORSE_S = "..."
print(f"\n1901.12.12 跨大西洋信號：'S' = {MORSE_S}")
print("距離 2900 km，從英國康沃爾到紐芬蘭——資訊第一次無線跨洋。")

# 理論與應用的等待時間
print("\n--- 迴路時間帳 ---")
for name, years in [("赫茲實驗 → 馬可尼首航", 7),
                    ("馬可尼首航 → 跨英吉利海峽", 4),
                    ("跨海峽 → 跨大西洋", 2)]:
    print(f"{name}：{years} 年")
print("=> 迴路轉速暴增：從 23 年（麥克斯韋）到 2 年。")
```
