# 1919 愛丁頓日食觀測

## 案發現場

1919 年 5 月 29 日，兩個英國遠征隊分別守在地球的兩端：西非外海的普林西比島（Príncipe）與巴西的索布拉爾（Sobral）。他們的目標只有一件——趁日全食月影遮日的短短幾分鐘，拍下太陽背後星空的照片，量測星光**是否被太陽引力彎曲**。

這是一次為理論蓋章的遠征實驗。被檢驗的假設來自四年前的柏林：愛因斯坦的廣義相對論（[1915-廣義相對論.md](1915-廣義相對論.md)）預言，光線經過太陽邊緣時會偏折 **1.75 角秒**——正好是牛頓「光微粒說」計算值（0.87 角秒）的兩倍。兩個數字都小，但足以裁決誰對誰錯。

更戲劇性的是背景：英國與德國正在打完一場死了千萬人的大戰。一位英國天文學家（愛丁頓，Arthur Eddington, 1882–1944），作為貴格會反戰者，用國家經費去驗證一個**敵國科學家**的理論——這本身就是科學作為超越戰爭的國際迴路的證明。

## 偵查過程

愛丁頓的偵查邏輯清晰得像偵探小說：

**線索一：為什麼必須等日食？** 平時太陽太亮，背景星光完全被淹沒。只有全食時月亮擋住太陽，才能拍到太陽附近的星場。方法：先拍同一片星空在太陽**不在場**時的照片（夜間），再拍太陽**在場**時（日食），比對星點位置的偏移。

**線索二：偏折角從哪裡來？** 等效原理要求引力場中時間變慢，光經過時波前傾斜——愛因斯坦 1911 年就算出 0.87 角秒；1915 年完整的廣義相對論加上空間彎曲的貢獻，總量翻倍到 1.75 角秒。**「時間彎曲」與「空間彎曲」各貢獻一半**——這是裁決的關鍵分水嶺：牛頓式答案與愛因斯坦式答案差一倍，沒有模糊地帶。

**線索三：戰場上的數據本身就有爭議。** 索布拉爾的兩台望遠鏡中，主鏡（4 吋）因日曬失焦，數據偏向牛頓值；後備鏡（7 吋 astrograph）數據乾淨，支持 1.75 角秒。愛丁頓以統計判斷捨棄失焦數據——這個取捨後來被質疑「是否裁判偏心」，但 1970 年代起無數更精確的實驗（無線電干涉、 VLBI）反覆確認了 1.75 角秒無誤。

普林西比島當天多雲，愛丁頓在回憶錄中寫道，他在雲縫間拍了十幾張底片，一度以為全毀。數日後他當場用望遠鏡做了初步量測，對同僚說出那句著名的話：

> 「麥喀松（Cottingham）先生，你不會介意全世界知道你不瘋狂、我瘋狂吧？——因為結果顯示星光確實彎了，而我獨自一人在島上就知道這一點。」

11 月 6 日，皇家學會與皇家天文學會聯合會議宣布結果：偏折角約 **1.61–1.98 角秒**（合併誤差範圍），與愛因斯坦的 1.75 吻合，排除牛頓值。次日《泰晤士報》頭版：〈科學革命——新的宇宙理論〉。愛因斯坦一夜之間成為全球名人。

## 結案報告

愛丁頓日食觀測屬於迴路的**實驗**環節——它沒有發明新理論，而是把一個純理論推演的假設，用受控的遠征觀測蓋章確認。它的深遠意義：

1. **理論與實驗的迴路轉速**——從哥白尼等 60 年、麥克斯韋等 23 年，到愛因斯坦只等 **4 年**。遠洋交通（[1825-史蒂芬遜鐵路.md](1825-史蒂芬遜鐵路.md) 時代以降的交通革命）、攝影術、國際科學組織（皇家學會，[1687-牛頓原理.md](1687-牛頓原理.md) 的制度化傳統）把實驗端武裝到位。
2. **科學的國際性**——英國科學家驗證德國理論，證明「理論—實驗—技術」迴路超越國界與戰爭。
3. **相對論進入工程視野**——星光偏折確認後，引力透鏡、黑洞、宇宙學全部開張；七十多年後引力時間膨脹成為 [1995-GPS.md](1995-GPS.md) 的日常修正項。
4. **實驗數據取捨的方法論教訓**——愛丁頓捨棄失焦底片的判斷，引出「先驗期望是否污染裁判」的永恆問題；此後科學界發展出盲分析（blind analysis）等制度來防範。

## 證據與工具

```python
# 偵查證物：太陽邊緣星光偏折角 —— 裁決牛頓 vs 愛因斯坦

import math

G, M, R, c = 6.674e-11, 1.989e30, 6.957e8, 2.998e8
# 牛頓「光微粒」值（1911 年愛因斯坦也算出此值）
theta_newton = 2*G*M/(R*c**2)
# 廣義相對論值（時間彎曲 + 空間彎曲，總量翻倍）
theta_gr = 4*G*M/(R*c**2)

arcsec = 180*3600/math.pi
print(f"牛頓式預言：{theta_newton*arcsec:.2f} 角秒")
print(f"愛因斯坦預言：{theta_gr*arcsec:.2f} 角秒")
print(f"1919 年愛丁頓實測：約 1.6–1.98 角秒 → 蓋章愛因斯坦")

# 兩個預言差一倍，沒有模糊地帶 —— 這是偵探案的關鍵分水嶺
print(f"倍率 = {theta_gr/theta_newton:.0f}（時間彎曲 0.87 + 空間彎曲 0.87）")
```
