# 1620 培根新工具

## 案發現場

1620 年，英格蘭大法官法蘭西斯·培根（Francis Bacon, 1561–1626）出版《新工具》（Novum Organum）——書名對抗亞里士多德的《工具論》（Organon）：千年邏輯學的權威，正受到挑戰。

案發現場的知識處境：1610–1620 年代，哥白尼（[1543-哥白尼日心說.md](1543-哥白尼日心說.md)）、第谷（[1576-第谷天文台.md](1576-第谷天文台.md)）、伽利略（[1609-伽利略望遠鏡.md](1609-伽利略望遠鏡.md)）、吉爾伯特（[1600-吉爾伯特磁學.md](1600-吉爾伯特磁學.md)）的成果已經問世——**新知識正在湧現，但「如何獲得知識」的方法論仍然缺失**。經院哲學以亞里士多德邏輯（演繹三段論）從權威文本推導結論；真相的來源是「古人說了什麼」，而不是「自然說了什麼」。

謎團：如果自然是一本案卷，應該怎樣「讀」它？

## 偵查過程

培根的推理是一部方法論宣言，核心論點可以重建如下：

1. **診斷——四種偶像（idols）**：培根首先清算阻礙知識的四種心理與制度障礙：**種族偶像**（人類共有的偏見，如以目的論解釋自然）、**洞穴偶像**（個人偏好與成見）、**市場偶像**（語言的含混，詞語空轉）、**劇場偶像**（哲學體系的教條，如亞里士多德主義）。**錯誤的來源被系統地命名了**。
2. **宣言——知識就是力量**：培根寫下那句名言：
   > 「人類的知識與人類的力量是同一回事；因為不知道原因，就不能產生結果。」（Knowledge is power）
   知識的目的是**控制與應用**——這是對「為知識而知識」的經院傳統的反轉，也是對技術與理論應當合流的宣言。
3. **方法——歸納法與三表**：培根提出替代三段論的方法：從**觀察事例**出發，以「三表」整理證據——**肯定表**（現象出現的事例）、**否定表**（現象不出現的事例）、**比較表**（現象按程度變化的事例），再歸納出「形式」（規律）。他以「熱」為示範案例：比較太陽光、火焰、摩擦、石灰遇水等數十種事例，歸納出**熱是運動**的假說（方向正確，雖然他錯誤地否認哥白尼日心說）。
4. **方法——受控實驗**：培根強調觀察必須輔以**人為干预的實驗**——「扭轉獅子」（vex nature）逼自然吐露祕密。他為「實驗」立法：受控、可重複、系統記錄。這是對伽利略與吉爾伯特實際做法的理論化。
5. **制度——所羅門之宮**：培根在未竟的《新亞特蘭提斯》（1627）中描繪了一座國家資助的研究機構「所羅門之宮」，分工研究、系統實驗、共享成果——**1660 年倫敦皇家學會的直接藍本**。

## 結案報告

《新工具》是「為實驗立法」的方法論宣言，是金觀濤迴路中「實驗環節」的正式命名者：

1. **方法論的轉向**：知識的來源從權威文本轉向自然本身；「觀察→歸納→驗證」取代「演繹→引經據典」。此後牛頓在《原理》結尾自述方法為「從現象歸納出概括」（[1687-牛頓原理.md](1687-牛頓原理.md)）——培根的方法已成為科學的自我意識。
2. **科學的制度化**：所羅門之宮的藍圖在 1660 年兌現為皇家學會，格言正是培根的「Nullius in verba」（不隨他人之言，與吉爾伯特扉頁警告遙相呼應）。**迴路的組織形式升級：個人→學會**。
3. **知識就是力量**：培根把知識的目的定為「應用」——這為「理論→技術」的環節提供了哲學動機；蒸汽機時代（[1698-紐科門蒸汽機.md](1698-紐科門蒸汽機.md)）「科學造福工業」的格局，在此已埋下種子。
4. **歷史的公正**：培根本人不是實驗家（他死於雪地中試驗「雪能否防腐雞肉」的感冒），他的歸納法也不完備（休謨後來指出歸納的邏輯漏洞；現代科學實際上兼用歸納與假設演繹）。但他的功績在於：**把「實驗」從零散的手藝提升為方法論與制度**——古代中國有火藥與水運儀象台（[1044-火藥.md](1044-火藥.md)、[1090-水運儀象台.md](1090-水運儀象台.md)）卻無此立法，技術因此孤行。

## 證據與工具

```python
# 用 Python 重演培根的「三表」歸納法：以「熱」為案例
# 肯定表（熱出現的事例）、否定表、比較表 → 歸納出「熱是運動」

# --- 肯定表：熱出現的事例及其伴隨條件 ---
affirmative = [
    ("太陽光",       {"運動": True,  "摩擦": False, "化學反應": False}),
    ("火焰",         {"運動": True,  "摩擦": False, "化學反應": True}),
    ("摩擦木塊",     {"運動": True,  "摩擦": True,  "化學反應": False}),
    ("敲打鐵塊",     {"運動": True,  "摩擦": True,  "化學反應": False}),
    ("石灰遇水",     {"運動": True,  "摩擦": False, "化學反應": True}),
    ("壓縮氣體",     {"運動": True,  "摩擦": False, "化學反應": False}),
]

# --- 否定表：無熱的事例（月光、靜止的水、陰影）---
negative = [
    ("月光",   {"運動": False, "摩擦": False, "化學反應": False}),
    ("靜止水", {"運動": False, "摩擦": False, "化學反應": False}),
    ("陰影",   {"運動": False, "摩擦": False, "化學反應": False}),
]

# --- 歸納：所有「熱」事例的共同條件 ---
common = set.intersection(*(set(k for k, v in cond.items() if v)
                            for _, cond in affirmative))
absent_in_negative = set.union(*(set(k for k, v in cond.items() if v)
                                 for _, cond in negative))
print("--- 肯定表 ---")
for name, cond in affirmative:
    keys = [k for k, v in cond.items() if v]
    print(f"  {name}: {', '.join(keys)}")
print(f"\n所有熱事例的共同點：{', '.join(common)}")
print(f"否定表中均無：{', '.join(absent_in_negative)}（或運動）")

print("\n培根的歸納結論：『熱是運動，是物體微粒的擴張運動』——方向正確！")

# --- 比較表的現代版：溫度與分子平均動能的定量關係 ---
# 熱的本質 = 分子運動：T ∝ 平均動能（E = 3/2 k_B T）
kB = 1.381e-23
print("\n--- 比較表（定量驗證：熱是運動）---")
for T_c in [0, 25, 100]:
    T = T_c + 273.15
    E = 1.5 * kB * T
    print(f"  {T_c:>4}°C → 分子平均動能 = {E:.3e} J（溫度越高，動能越大）")
print("\n培根的定性歸納 → 19世紀的定量證明：熱是運動。")
print("『知識就是力量』：歸納法為實驗立法，迴路的方法論宣言。")
```
