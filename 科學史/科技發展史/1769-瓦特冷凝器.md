# 1769 瓦特冷凝器

## 案發現場

紐科門蒸汽機（[1698-紐科門蒸汽機.md](1698-紐科門蒸汽機.md)）已經運轉了七十年，英國礦場裡有上百台它在日夜抽水——但礦場主們在賠錢。**它的熱效率只有約 0.5%**：每次循環，都要先用蒸汽把整個冷汽缸從室溫加熱到 100°C，然後再潑冷水把它打回室溫。**一熱一冷之間，四分之三的煤燒得毫無意義**——錢在燃燒，卻沒有人知道燒到了哪裡。

接手的是格拉斯哥大學的儀器工匠**詹姆斯·瓦特（James Watt, 1736–1819）**。1763 年，大學把一台紐科門機模型送來修理。這個「修理任務」成為工業革命的轉捩點——因為瓦特手上握著一件別的工匠沒有的武器：布萊克教授的**潛熱與比熱理論**（[1761-布萊克潛熱.md](1761-布萊克潛熱.md)）。

## 偵查過程

**第一步：用理論記帳。** 瓦特不是瞎修——他系統實驗，逐一量測：汽缸升溫要多少蒸汽？冷水潑下要多少蒸汽重新補熱？他把每一筆帳加起來，得出結論：**每個循環損耗的熱量中，絕大部分用在把冷汽缸重新加熱**——汽缸是鐵做的，鐵的比熱不小，加上冷凝水升溫，每次循環都像把一大鍋冷水重新燒開。瓦特寫下他偵查的核心：

> 「我的汽缸必須像煮沸的蒸汽一樣熱，蒸汽卻必須在別處冷凝。」

**第二步：設計解決方案。** 布萊克的潛熱理論指出：蒸汽冷凝時會釋放巨量潛熱，凝結是「熱的收支大戶」。瓦特的推理由此反轉：**冷凝不能省，但可以「搬家」**——把冷凝移出汽缸，放進一個永遠保持低溫的小容器。1765 年 5 月，他在格拉斯哥綠地散步時想通了這一點，造出**分離冷凝器（separate condenser）**：汽缸永遠保持熱（省去重新加熱），蒸汽做完工後經閥門進入隔壁的冷凝器凝結（汽缸內依然形成真空，大氣壓照常做功）。

**第三步：物化為工業。** 1769 年瓦特取得專利，1776 年起與礦場主博爾頓（Matthew Boulton）合作量產。瓦特機的煤耗只有紐科門機的**四分之一**——效率提升近四倍。博爾頓的宣言寫盡了迴路的野心：

> 「我賣的是全世界的動力（power），先生們，全世界都想買。」

**迴路的合體。** 瓦特機不再只會抽水：加上行星齒輪與飛輪，它輸出旋轉動力——紡織廠（[1764-珍妮紡紗機.md](1764-珍妮紡紗機.md)）、磨坊、鐵廠全部改用蒸汽驅動。**蒸汽機賺的錢反哺實驗室**（瓦特晚年資助熱學與化學研究），而熱學理論又回頭改良蒸汽機——第四幕的「技術反哺理論」迴路在格拉斯哥與伯明罕之間完全閉合。

## 結案報告

1. **蒸汽機效率提升近四倍**——煤耗驟降，蒸汽動力從礦場走向全工業，工業革命的動力基礎就此定型。
2. **「熱學理論＋工匠工藝」的合體**——瓦特模式的精髓：用科學理論記帳，用工匠手藝實現。這是第一幕（理論與技術互不往來）的反面，也是金觀濤迴路論最完整的單點標本。
3. **技術反哺理論**——博爾頓—瓦特工廠的利潤養出實驗室與儀器（瓦特的量熱計、複製機），理論再回頭升級技術；通往卡諾的熱機理論（[1824-卡諾熱機理論.md](1824-卡諾熱機理論.md)）與焦耳的熱功當量（[1846-焦耳熱功當量.md](1846-焦耳熱功當量.md)）。
4. **旋轉動力的誕生**——從往復到旋轉，蒸汽機成為「萬能動力機」，一切工廠的定位由此改寫。

## 證據與工具

```python
# 瓦特冷凝器的「效率帳本」：分離冷凝器省下了什麼

c_iron, c_water = 450, 4186
L_vapor = 2260e3
m_cyl = 15.0   # 汽缸等效鐵質量 kg
dT = 80.0      # 室溫到 100°C 的溫差

# 紐科門機：每循環重新加熱汽缸的浪費
Q_reheat = c_iron * m_cyl * dT
print(f"重新加熱汽缸耗熱 Q = c*m*dT = {Q_reheat:,.0f} J（每循環）")

# 瓦特機：汽缸保持高溫，此項浪費歸零
print(f"分離冷凝器：汽缸保持高溫，浪費 = {0} J\n")

# 效率對比：紐科門約 0.5%，瓦特約 2%（約 4 倍）
Q_total = 1e6
eta_newcomen, eta_watt = 0.005, 0.02
print(f"紐科門機效率 {eta_newcomen*100:.1f}% -> 瓦特機 {eta_watt*100:.1f}%"
      f"（提升 {eta_watt/eta_newcomen:.0f} 倍）")

# 煤耗對比：同樣做功，瓦特機煤耗 1/4
work = Q_total * eta_newcomen
coal_newcomen = work / eta_newcomen
coal_watt = work / eta_watt
print(f"同樣輸出 {work:,.0f} J：瓦特機煤耗為紐科門機的 {coal_watt/coal_newcomen:.0%}\n")

# 理想熱機的上限（卡諾效率，第五幕的伏筆）
T_hot, T_cold = 373.0, 293.0  # 蒸汽 100°C / 冷凝器 20°C
eta_carnot = 1 - T_cold / T_hot
print(f"卡諾上限（100°C/20°C）：{eta_carnot*100:.1f}%")
print(f"=> 瓦特機的 {eta_watt*100:.1f}% 距離理論上限還有 {eta_carnot-eta_watt:.1%} 的空間")
print("=> 這個差距，是留給卡諾的待破之案")
```
