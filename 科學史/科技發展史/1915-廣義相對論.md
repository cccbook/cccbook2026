# 1915 廣義相對論

## 案發現場

1915 年 11 月，柏林，第一次世界大戰的炮火正轟擊西線。普魯士科學院的會議室裡，愛因斯坦（Albert Einstein, 1879–1955）連續四個星期四登台報告，逐步公開一套顛覆兩百年牛頓引力理論的新學說。11 月 25 日，他提交最終論文〈廣義相對論的場方程〉——人類歷史上第一次，有理論家僅憑**純粹的數學推演**，就重寫了時間、空間與引力的定義。

這樁案件的「案發現場」其實在十年前就埋下：1907 年，愛因斯坦在專利局坐辦公室時，突然想到一個他稱之為「一生中最幸福的念頭」——**自由落體的人感覺不到自己的重量**。這個「等效原理」說：引力與加速度在局域上不可區分。既然加速度可以彎曲運動軌跡，引力就應該能彎曲**時空本身**。

## 偵查過程

愛因斯坦的偵查手法，是科學史上罕見的「純推理辦案」：幾乎沒有新實驗數據，只有兩條公理與數學。

**線索一：等效原理。** 電梯思想實驗——在自由落體的電梯裡，引力「消失」了；在太空中加速的火箭裡，一個「偽引力」出現了。引力不是一種「力」，而是時空彎曲的幾何效應。

**線索二：廣義協變性。** 物理定律必須對所有座標系（不論加速與否）成立。這迫使愛因斯坦去學習他當年幾乎不及格的黎曼幾何與張量分析——好友格羅斯曼（Marcel Grossmann）在 1912 年警告他：「你必須補修數學，否則理論做不下去。」

偵查中最驚險的一幕，是 1915 年 11 月的水星近日點進動計算。水星軌道每百年偏轉 5600 角秒，用牛頓理論扣除行星攝動後仍有 43 角秒**無法解釋**——這個懸案已懸了半世紀（勒維耶 1859 年甚至以為存在一顆「火神星」）。當愛因斯坦用新場方程算出恰好 43.03 角秒時，他回憶自己「心臟都停了一拍」，激動了好幾天。

最終的場方程只有一行（含十個分量方程）：

$$G_{\mu\nu} + \Lambda g_{\mu\nu} = \frac{8\pi G}{c^4} T_{\mu\nu}$$

左邊是時空的幾何（曲率），右邊是物質與能量。物理學家惠勒（Wheeler）後來用一句話總結：「**物質告訴時空如何彎曲，時空告訴物質如何運動。**」

但理論跑得太快了——1915 年，全世界能檢驗它的實驗幾乎為零。這正是金觀濤所說「理論可以領先，但不能離線太久」的典型案例：廣義相對論只離線了**四年**，就被 [1919-愛丁頓日食.md](1919-愛丁頓日食.md) 的遠征觀測蓋章。對比之下，哥白尼的日心說（[1543-哥白尼日心說.md](1543-哥白尼日心說.md)）等了六十多年，麥克斯韋的電磁波（[1865-麥克斯韋方程組.md](1865-麥克斯韋方程組.md)）等了二十三年。**等待時間的縮短，本身就是「理論—實驗—技術」迴路加速的證據**——望遠鏡、攝影術、國際科學網絡已經把實驗端武裝到牙齒。

## 結案報告

廣義相對論屬於迴路的**理論**環節，而且是最純粹的一種：從公理出發，數學推演，再等實驗裁決。它的遺產包括：

1. **引力即幾何**——牛頓的「超距力」被時空彎曲取代，太陽系從「機械鐘」變成「彎曲時空中的測地線運動」。
2. **時間不是絕對的**——引力場中時鐘走得慢，這在七十多年後成為 [1995-GPS.md](1995-GPS.md) 每天必須修正的工程參數。
3. **理論先行的新常態**——此後「先推導、後驗證」成為理論物理的標準流程：黑洞、重力波、宇宙膨脹，都是理論跑在前面、實驗用數十年追上。
4. **迴路加速的直接證據**——從 60 年（哥白尼）→ 23 年（麥克斯韋）→ 4 年（愛因斯坦）→ 當代粒子物理的理論與實驗幾乎同步，正反饋迴路的轉速一目了然。

## 證據與工具

```python
# 偵查證物一：水星近日點進動——廣義相對論的第一個勝利
# 廣義相對論修正量：Δφ = 6πGM / (a(1-e²)c²) 每軌道

G  = 6.674e-11      # 萬有引力常數 (m³/kg/s²)
M  = 1.989e30       # 太陽質量 (kg)
a  = 5.791e10       # 水星半長軸 (m)
e  = 0.2056         # 水星軌道離心率
c  = 2.998e8        # 光速 (m/s)

dphi_per_orbit = 6*3.141592653589793*G*M / (a*(1-e**2)*c**2)  # 弳度/軌道
orbits_per_century = 100*365.25*86400 / (2*3.141592653589793*(a**(1.5)/(G*M)**0.5))
arcsec_per_century = dphi_per_orbit * orbits_per_century * (180*3600/3.141592653589793)

print(f"廣義相對論預言的水星進動：{arcsec_per_century:.2f} 角秒/百年")
print("牛頓理論無法解釋的殘差：43 角秒/百年 —— 恰好吻合！")
```

$$\text{偵查證物二：引力時間膨脹}\quad \frac{\Delta t_{\text{遠處}}}{\Delta t_{\text{近處}}} \approx 1 + \frac{gh}{c^2}$$

```python
# 偵查證物三：GPS 衛星上的時鐘每天比地面快多少（僅引力項）
g, h, c = 9.81, 2.02e7, 2.998e8   # 地表重力、衛星高度、光速
ratio = g*h/c**2
```
