# 前3000 青銅與輪子

## 案發現場

公元前四千紀末，兩河流域與尼羅河畔的人類已經擁有城市、文字與灌溉系統，但他們的「科技」是什麼樣子的？答案是兩件器物：**青銅**與**輪子**。

在此之前，人類使用純銅與石器。純銅太軟，石刀易碎，砍伐森林、挖掘溝渠、征戰防衛都受限。同時，搬運重物靠滾木與撬棍，效率低而耗人力。謎團在於：**人類明明已經掌握了火、陶、鑄造，為什麼技術進步仍然以千年為單位緩慢爬行？**

金觀濤的答案一針見血：不是沒有知識，而是**沒有迴路**。此時的技術是單向鏈：手藝→器物。理論（自然哲學尚未誕生，只有神話）不會解釋合金為何變硬；受控的實驗（有計畫地改變單一變數來檢驗假設）更未發明。工匠知道「加錫的銅更硬」，卻不知道為什麼，也無法系統地找出最佳比例。

## 偵查過程

**青銅之謎的破解，靠的是幾千年間無數工匠的試錯。**冶煉者將孔雀石等銅礦與木炭同燒，還原出銅；後來發現某些礦石混入了錫，煉出的金屬明顯更硬、更易鑄造。於是工匠開始刻意配比——但這是「經驗配方」，靠父子師徒口耳相傳，沒有成分分析，沒有定量記錄。

最佳配比大致落在含錫 10% 上下：此時合金硬度可達純銅的三倍，熔點卻比純銅更低（約 800°C，比純銅的 1085°C 更容易澆鑄）。這是一個美妙的巧合——更硬且更易加工——但它只能被「發現」，無法被「推導」。

**輪子的成熟同樣是經驗的勝利。**從約前 3500 年美索不達米亞的陶輪與車輪，到前 2000 年前後出現的**輻條車輪**：把實心圓盤挖空成輻條結構，重量大減而強度保留，戰車因此可以疾馳。輪與軸的摩擦、輪徑與省力的關係，工匠們有手感，卻沒有 $F \cdot L = W \cdot h$ 這樣的語言可以表達。

值得注意的是：這兩項技術各自獨立傳播——青銅術傳遍歐亞，輪子傳入埃及、印度河與中國——但傳播過程中**沒有疊加出任何理論**。每個文明都重新摸索一遍同樣的配方。

## 結案報告

青銅與輪子造就了第一個「金屬時代」：戰車、武器、農具、禮器，城市文明因此擴張。但它們也成為「技術孤立不成循環」最經典的案例：

1. **技術無理論**——沒有任何古代文明發展出解釋合金硬度或輪軸力學的理論；配方是「術」不是「學」。
2. **技術無實驗**——改進靠偶然與試錯，而非「控制變數、檢驗假設」的受控實驗。
3. **理論不俯身**——古希臘自然哲學關心「為什麼天體運行」，不屑於解釋工匠的器物；唯一的例外是阿基米德（見 [前250-阿基米德與機械.md](前250-阿基米德與機械.md)），但要等到兩千七百年後。

正因為缺少「理論—實驗—技術」的迴路，青銅技術用了三千多年才被鐵取代；而近代科學中，一項技術從發明到升級往往只需幾十年。這個對比，正是本書主軸的起點。

## 證據與工具

```python
# 用 Python 模擬青銅配比的取捨：含錫量 vs 硬度與熔點（示意模型，基於經驗數據）

# 含錫量(%) 與布氏硬度(HB)的近似關係（退火鑄造錫青銅的經驗值）
# 以及熔點(°C)隨含錫量下降的近似關係
def hardness(sn_pct):        # 經驗擬合：純銅約 35HB，10% 錫約 90HB
    return 35 + 90 * (sn_pct / 20) ** 0.8 if sn_pct <= 20 else None

def melting_point(sn_pct):   # 簡化：每 1% 錫使熔點下降約 8°C
    return 1085 - 8 * sn_pct

print(f"{'含錫%':>5} {'硬度HB':>8} {'熔點°C':>8}")
for sn in [0, 5, 8, 10, 12, 15, 20]:
    print(f"{sn:>5} {hardness(sn):>8.1f} {melting_point(sn):>8.0f}")

# 古代工匠的「最佳配方」約為 10% 錫：硬度比純銅高一倍以上，熔點更低、更好鑄
best = 10
print(f"\n工匠經驗選出的配方：{best}% 錫")
print(f"硬度增益：{hardness(best)/35:.1f} 倍於純銅；熔點降低 {1085-melting_point(best)}°C")
print("但注意：以上關係要等到近代冶金學（固溶強化理論）才能解釋——")
print("古代工匠只能『知道』，無法『推導』：這就是技術孤行的極限。")
```
