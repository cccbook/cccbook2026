# 1856 貝塞麥轉爐

## 案發現場

1856 年的英國，鋼是貴金屬。鐵軌用熟鐵（含雜質、易變形）、橋樑用鑄鐵（脆）、刀具用坩堝鋼（每噸價格是熟鐵的數十倍）。蒸汽機車（[1825-史蒂芬遜鐵路.md](1825-史蒂芬遜鐵路.md)）、汽船、工廠——整個工業革命的骨架都在呼喊「要鋼」，但鋼的產量低得可憐：英國年產鋼不過數萬噸，製鋼靠攪煉法（puddling）——工人用鐵棒在熔爐裡手工攪拌，一天只能煉一噸多。

本案的「偵探」是一位沒學過冶煉的發明家——亨利·貝塞麥（Henry Bessemer, 1813–1898）。他的背景是機械與軍工（曾發明炮彈來復線），對煉鋼完全是外行。而他的破案關鍵，恰恰是一個內行人不敢想、外行人才敢試的瘋狂動作：**往鐵水裡吹空氣。**

## 偵查過程

**第一步：外行的錯誤直覺，撞上化學真相。** 貝塞麥原本的問題是造炮：來復炮需要強度高又便宜的鋼。他檢視煉鋼的化學：生鐵含碳約 3–4%，鋼只需 0.5–1.5%——煉鋼本質上是**除碳**。傳統方法靠燃料燃燒緩慢氧化除碳；貝塞麥的外行直覺是：鐵水本身很熱，何必再燒燃料？**直接向鐵水吹空氣，讓鐵水裡的碳自己燒掉！**

內行人聽了會發抖：吹冷空氣會讓鐵水降溫凝固。但化學站在貝塞麥這邊：

$$\mathrm{C} + \mathrm{O_2} \longrightarrow \mathrm{CO_2} \uparrow \qquad \mathrm{Si} + \mathrm{O_2} \longrightarrow \mathrm{SiO_2}$$

碳與矽的氧化是**放熱反應**——燃燒釋放的熱，不僅補償了空氣帶走的熱，還讓鐵水**越吹越熱**，甚至白熱化噴濺。這是化學知識（氧化放熱）與工程膽識的完美合體：**燃料免費——燃料就在鐵水裡。**

**第二步：1856 年 8 月的示範。** 貝塞麥在倫敦切爾西的冶煉廠向英國科學促進會示範：把生鐵裝進可傾斜的轉爐，從底部吹入空氣，爐口噴出壯觀的火花與棕色煙柱。十幾分鐘後——**原需數小時的攪煉，十幾分鐘完成**，得到的正是鋼。他隨即申請專利，宣布：

> 「我看不出任何理由，為什麼鋼不能像鐵一樣便宜。」

**第三步：意外的攔路虎——磷與硫。** 系統很快出現問題：貝塞麥用無磷的赫默爾亨普斯特德鐵礦示範成功，但歐洲多數鐵礦含磷，磷會讓鋼**冷脆**——轉爐鋼大批報廢，「貝塞麥騙局」的罵聲四起。破案的是冶金學家馬希特父子（Robert Mushet）添加鏡鐵（含錳）補碳脫氧，以及 1878 年托馬斯（Sidney Gilchrist Thomas）的鹼性爐襯脫磷法。本案提醒我們：**化學的缺口，最終要靠化學補上。**

**第四步：鋼價暴跌的迴路。** 問題解決後，轉爐煉鋼在 20 分鐘內完成過去一整天的工序，噸鋼成本暴跌 80% 以上。1860 年代起英、美鋼產量指數增長；鋼軌取代鐵軌，摩天大樓、大橋、軍艦全部改用鋼。

## 結案報告

貝塞麥轉爐是**化學知識＋工程膽識＝鋼價暴跌**的勝利。用金觀濤的框架說，本案屬於**技術⚙環節**，它對迴路的推動在於：

1. **工業的骨架升級**——鋼鐵從貴金屬變成大宗商品：鐵路（[1825-史蒂芬遜鐵路.md](1825-史蒂芬遜鐵路.md)）、建築、機械、軍工全部改寫。
2. **化學知識的工業化**——氧化放熱、脫磷脫硫，化學實驗室的知識直接變成工廠的利潤：這是「理論—實驗—技術」迴路在冶金領域的閉合，也預示了第六幕「科學的工業化」。
3. **規模效應的正反饋**——鋼越便宜，用途越廣；需求越大，爐子越大；爐子越大，成本越低——工業迴路第一次以鋼鐵的速度自轉。
4. **方法論的教訓**——外行視角有時是資產：內行人被「吹冷空氣會凝固」的直覺束縛，外行人卻敢算化學帳。

## 證據與工具

```python
# 貝塞麥轉爐的化學與熱帳：為何吹空氣反而更熱？

# 生鐵成分（質量比）：C 3.5%、Si 1.5%，其餘鐵
# 氧化放熱（每 kg 元素）：
heat_C, heat_Si = 32700, 30000   # kJ/kg：C→CO2、Si→SiO2 的近似放熱量
m_iron = 1000                     # 1000 kg 生鐵
C_frac, Si_frac = 0.035, 0.015

Q_C = m_iron * C_frac * heat_C    # 碳燃燒放熱
Q_Si = m_iron * Si_frac * heat_Si # 矽氧化放熱
print(f"碳氧化放熱 ≈ {Q_C/1e6:.0f} MJ，矽氧化放熱 ≈ {Q_Si/1e6:.0f} MJ")
print(f"合計 ≈ {(Q_C+Q_Si)/1e6:.0f} MJ——超過把鐵水加熱白熱化所需")
print("=> 『燃料就在鐵水裡』：吹空氣不降溫，反而升溫。")

# 時間帳：攪煉法 vs 轉爐
t_puddling, t_converter = 12*60, 20   # 分鐘：每批 12 小時 vs 20 分鐘
print(f"\n攪煉法每批 {t_puddling} 分鐘，轉爐每批 {t_converter} 分鐘")
print(f"速度提升約 {t_puddling//t_converter} 倍；日產量從 ~1 噸躍升至數十噸。")

# 除碳的目標
print(f"\n生鐵含碳 {C_frac*100:.1f}% → 鋼含碳 0.5–1.5%")
print("煉鋼的本質是『氧化除碳』——化學帳算清楚了，工程才敢下手。")
```
