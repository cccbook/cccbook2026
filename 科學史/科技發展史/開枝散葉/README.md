# 開枝散葉：根源與科技樹（科學史）

> 主書以「理論—實驗—技術」迴路解釋科學革命（見 [../README.md](../README.md)）。本子書換一個視角看同一部歷史：**根與枝**。
>
> 一個真正的「根源」（root），是迴路第一次閉合的時刻——一條理論、一個實驗或一項技術第一次與另外兩環扣在一起。此後它不只是一個事件，而是一棵**科技樹（tech tree）**的種子：樹幹長出第一代應用，第一代又長出第二代，每根枝條上又開出自己的「理論—實驗—技術」小迴路。金觀濤所說的九條促進通道（理論⇒實驗、技術⇒技術……），落到歷史裡就是一棵樹的主幹與側枝。
>
> 例如：麥克斯韋方程（1865）是根，第一代是無線電（1895），第二代是廣播與電視，第三代是雷達與衛星，第四代是光纖與手機——每一代都同時需要新理論（量子力學）、新實驗（波導測量）與新技術（真空管、電晶體）。**樹不是線性的清單，而是迴路的族譜**。
>
> 本子書為每個根源寫一篇 wiki，含：前因（根之前的孤鏈世界）、案發現場（根的第一次閉合）、理論核心（數學式）、**科技樹總覽**（逐代分支表，連結主書既有篇目與枝上的關鍵事件）。

## 閱讀順序建議

1. 先讀 [../README.md](../README.md) 的九通道矩陣——樹的每根枝條都對應一條通道。
2. 再逐篇讀樹：每篇的「科技樹總覽」表逐代列出枝條，並連結主書既有 wiki 與本子書其他樹。
3. 負面與忽視案例（[../負面案例/README.md](../負面案例/README.md)、[../忽視案例/README.md](../忽視案例/README.md)）是樹上結不出果的枝——冷融合在核樹上、N 射線在電磁樹上、魏格納在沒有海底探測技術的年代。
