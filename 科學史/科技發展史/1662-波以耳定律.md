# 1662 波以耳定律

## 案發現場

托里拆利（[1643-托里拆利大氣壓.md](1643-托里拆利大氣壓.md)）造出真空之後，一個更大的謎團浮上桌面：**空氣到底是什麼？它有重量、有彈性嗎？它的「稀薄」服從什麼規律？**

亞里士多德留給後世的答案是「空氣是一種元素」，但這個答案不提供任何可計算的預測。與此同時，技術這邊已經開始出招：奧托·馮·格里克（Otto von Guericke）在 1654 年馬德堡市集上用十六匹馬也拉不開兩個抽成真空的銅半球，轟動全歐洲——真空不只是哲學話題，它有一種可怕而真實的力量。

接手這樁案件的是愛爾蘭貴族**波以耳（Robert Boyle, 1627–1691）**與他的助手**虎克（Robert Hooke, 1635–1703）**。波以耳是剛成立的皇家學會（1660）的靈魂人物，他在《新工具》（[1620-培根新工具.md](1620-培根新工具.md)）的精神下做了一件史無前例的事：**為了檢驗一個假設，專門委託虎克造一台從未存在過的儀器。**

## 偵查過程

**第一件證物：真空泵。** 1658–59 年，虎克設計、波以耳出資，造出歐洲第一台性能穩定的真空泵（借鑑格里克但大幅改良）。用它抽空玻璃容器，波以耳連串實驗：真空中的羽毛與石塊同時落地（伽利略猜想的直接驗證）、真空中的鐘錶聽不見、真空中的動物會死。空氣被剝離出「元素」的舊身分，露出真面目：**一種有重量、有彈性的物質**。

**第二件證物：彈性的定量規律。** 1662 年，波以耳提出假設：空氣的壓力與體積之間可能存在簡單的數學關係。他用一根 J 形玻璃管，閉端封入定量空氣，從開端加入水銀以改變壓力，逐一量測空氣柱長度。

數據的推理過程堪稱實驗科學的教科書。若空氣「像彈簧」，壓力加倍體積應減半；若關係更複雜，數據會說話。波以耳把每一組 $(P, V)$ 相乘：

| 壓力（水銀柱吋） | 體積（空氣柱長） | $P \times V$ |
|---|---|---|
| 29⅛ | 48 | 848 |
| 44⅜ | 32 | 942 |
| 87⅞ | 16 | 940 |

在高壓段，乘積**幾乎恆定**——$PV = \text{常數}$。這就是**波以耳定律**。他甚至用「壓縮的彈簧」意象向讀者解釋：空氣好比一堆微小彈簧，壓得越緊，反抗越強。這個微觀直覺，兩百年後將被氣體分子動力學說（十九世紀）徹底證明。

波以耳在文中寫下這套方法的宣言：

> 「我要說的不只是事情如此，而是**它為什麼必須如此**——而我願意讓新的實驗隨時推翻我。」

## 結案報告

1. **氣體成為定量科學的對象**——化學與物理學共同的第一條氣體定律，直接通往查理—給呂薩克定律與理想氣體方程。
2. **「為檢驗假設而造儀器」的典範**——真空泵不是為了生產，而是為了回答一個問題。這是第一幕與第二幕（伽利略望遠鏡 [1609-伽利略望遠鏡.md](1609-伽利略望遠鏡.md)）路徑的成熟版：技術造出新實驗，新實驗逼出新理論。
3. **真空工業的起點**——抽真空的技術，經由紐科門蒸汽機（[1698-紐科門蒸汽機.md](1698-紐科門蒸汽機.md)）第一次驅動了大工業；拉瓦錫的定量革命（[1789-拉瓦錫定量革命.md](1789-拉瓦錫定量革命.md)）用的氣體量測法，血統正是這裡。
4. **皇家學會的制度化**——波以耳定律的發表與公開重複驗證，就是皇家學會「實驗須當眾可重複」規範的實踐：迴路第一次有了制度載體。

## 證據與工具

```python
# 用 Python 驗證波以耳的原始數據：PV = 常數
data = [(29.125, 48), (35.3125, 40), (44.375, 32),
        (58.25, 24), (87.875, 16)]  # (壓力/吋水銀, 體積/吋)

print("壓力(P)   體積(V)   P*V")
for P, V in data:
    print(f"{P:7.2f}   {V:5d}   {P*V:7.1f}")

products = [P*V for P, V in data]
print(f"\nP*V 的變動範圍：{min(products):.1f} ~ {max(products):.1f}")
print("高壓段（後三組）乘積幾乎恆定 => PV = 常數（波以耳定律成立）")

# 定量預測：若把空氣壓到 1/10 體積，壓力應為 10 倍
V0, P0 = 48, 29.125
print(f"\n預測：體積 4.8 吋時壓力 = {P0*V0/4.8:.1f} 吋（= 10 倍大氣壓）")

# 理想氣體方程的反推：PV = nRT
R = 8.314
print("\n現代形式：P V = n R T")
print("以 1 mol、300 K、101325 Pa 計，V = n*R*T/P =",
      f"{1*R*300/101325*1000:.2f} L")
```
