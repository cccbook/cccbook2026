# 1831 法拉第電磁感應

## 案發現場

1831 年之前的倫敦皇家研究院，一個魔咒籠罩著電磁學：**奧斯特 1820 年證明了電能生磁**（電流通過導線，旁邊的磁針會偏轉），可是反過來——磁能不能生電？——十年間無人成功。安培試過、菲涅爾試過、無數人把磁鐵靜靜地放在導線旁邊，什麼也沒發生。邏輯上「對稱」的事情，實驗上一再失敗。這條「未被違反的禁令」，又一次被當成了自然的定律。

本案的「偵探」是一位鐵匠之子、書店學徒出身的實驗大師——邁克爾·法拉第（Michael Faraday, 1791–1867）。他沒受過數學訓練（終生不會微積分），卻擁有史上最強的實驗直覺與圖像思維——「力線」（field lines）就是他腦中的圖像語言。而他破解魔咒的關鍵，竟是一個極其微妙的洞見：**靜止不生電，變化才生電。**

## 偵查過程

**第一步：十年追問。** 從 1822 年起，法拉第的實驗筆記本上反覆出現「把磁轉化為電」（convert magnetism into electricity）的字樣。他試過把強磁鐵放在線圈旁、讓電流通過另一根導線——全部失敗。關鍵在於：他（和所有人一樣）預設了**穩定的磁場應該能產生穩定的電流**，就像穩定的電流能產生穩定的磁場。這個「對稱性直覺」恰恰是錯的方向。

**第二步：轉折的線索。** 1831 年 8 月 29 日，法拉第用一個軟鐵環，兩邊各繞一組線圈（這就是史上第一個變壓器）。當他接通一側的電池時，另一側的電流計指針**猛地一動，又立刻歸零**。換句話說：只有接通與斷開的**瞬間**才有電流，穩定狀態下什麼都沒有。法拉第立刻抓住這個被所有人忽略的瞬間：

> 「接通時有感應電流，斷開時也有，方向相反；穩定電流不產生任何感應。」

**結論浮出水面：感應的條件不是磁場本身，而是磁場的變化。**

**第三步：確認與定量。** 法拉第接著做了決定性實驗：把一根條形磁鐵插入或拔出線圈——電流計指針隨之擺動；磁鐵靜止不動——指針歸零。他還證明感應電流的方向總是**對抗磁通量的變化**（這就是後來的楞次定律）。一個月內，法拉第把魔咒拆解得乾乾淨淨，寫下了電磁感應定律：

$$\mathcal{E} = -\frac{d\Phi_B}{dt}$$

感應電動勢等於磁通量對時間變化率的負值（負號表示「對抗變化」）。

**第四步：造出發電機。** 法拉第隨即把發現物化：旋轉銅盤在磁極之間轉動，盤心與盤緣之間連續產生電流——史上第一台發電機（法拉第圓盤）。他對首相（一說是財政大臣格萊斯頓）的那句著名回答，成了基礎科學價值的永恆註腳：

> 「先生，新生的東西現在還說不出用處；但我敢說，政府總有一天會對它課稅。」

## 結案報告

法拉第電磁感應是「實驗逼出理論」的極致案例：沒有數學、沒有預設理論，只有十年不放棄的追問和對「異常瞬間」的敏感。用金觀濤的框架說，本案屬於**實驗**環節，它對「雙迴路大加速」的推動是決定性的：

1. **磁終於生電**——電與磁的對稱性補全，為 [1865-麥克斯韋方程組.md](1865-麥克斯韋方程組.md) 提供了四塊拼圖中最關鍵的一塊（法拉第定律）。
2. **發電機的誕生**——機械能可以連續地變成電能：這是 [1800-伏打電堆.md](1800-伏打電堆.md)（化學電源）之後電學的最大轉折，電力工業的全部基礎（從 [1882-珍珠街電廠.md](1882-珍珠街電廠.md) 到今日電網）都始於這個銅盤。
3. **變壓器的誕生**——鐵環雙線圈就是變壓器的原型，遠距離輸電由此可能。
4. **方法論的教訓**——失敗常常是因為問錯了方向；「只有變化才生電」這個洞見，藏在被所有人看漏的指針一動之中。

## 證據與工具

```python
# 法拉第電磁感應定律的數值演示
# E = -dΦ/dt：感應電動勢 = 磁通量變化率

import math

def flux(B, A, theta_deg):
    # B 磁場強度(T)、A 線圈面積(m²)、theta 磁場與法線夾角
    return B * A * math.cos(math.radians(theta_deg))

# 條形磁鐵插入線圈：磁場在 0.1 秒內從 0 升到 0.05 T，線圈 100 匝、面積 0.002 m²
B0, B1, N, A, dt = 0.0, 0.05, 100, 0.002, 0.1
E = N * (flux(B1, A, 0) - flux(B0, A, 0)) / dt
print(f"磁鐵插入：磁通量變化 {flux(B1,A,0)-flux(B0,A,0):.5f} Wb")
print(f"感應電動勢 E = N·ΔΦ/dt = {E:.3f} V（拔出時方向相反）")

# 為何「靜止不生電」？
print(f"\n磁鐵靜止時：ΔΦ = 0，E = 0 V")
print("=> 感應的條件是磁通量的『變化』，不是磁場本身。")

# 法拉第圓盤發電機：旋轉導體在磁場中產生電動勢
# E = 0.5 * B * ω * R²
B, omega, R = 1.0, 2*math.pi*5, 0.15   # 1 T、每秒 5 轉、半徑 15 cm
E_disk = 0.5 * B * omega * R**2
print(f"\n法拉第圓盤：E = ½BωR² = {E_disk*1000:.2f} mV（小但連續！")
print("   電流第一次可以連續地由機械能產生——發電機的起點。")
```
