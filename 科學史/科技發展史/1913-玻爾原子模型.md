# 1913 玻爾原子模型

## 案發現場

1913 年的哥本哈根，原子物理學正面臨一場理論危機：[1897-湯姆生電子.md](1897-湯姆生電子.md) 拆開了原子，盧瑟福 1911 年用 α 粒子散射實驗證明原子中心有一個極小的帶正電核——**原子核**。但這個「行星模型」在經典物理下自相矛盾：電子繞核旋轉必然輻射電磁波（[1865-麥克斯韋方程組.md](1865-麥克斯韋方程組.md) 的推論），能量流失、半徑縮小，**電子會在 10⁻¹⁰ 秒內螺旋墜入原子核**——原子不可能存在！此外，氫原子的光譜是一組分立的亮線（巴耳末 1885 年已總結出譜線位置的經驗公式），經典理論完全無法解釋為何譜線是分立的。

本案的「偵探」是一位年僅 28 歲的丹麥物理學家——尼爾斯·玻爾（Niels Bohr, 1885–1962）。他剛從曼徹斯特盧瑟福門下回國，而他的破案工具是兩件看似無關的拼圖：普朗克 1900 年的**量子假說**（能量以分立的「份」出現）與**氫光譜的經驗公式**。

## 偵查過程

**第一步：豁出去的假設。** 玻爾的偵查風格是「理論可以離線，但不能不和實驗掛鉤」。他做出兩個大膽到近乎蠻橫的假設：

1. **定態假設**：電子只能處在幾個分立的軌道上（定態），繞核旋轉**不輻射**——公然違反麥克斯韋方程；
2. **躍遷假設**：電子從高能態跳到低能態時，輻射一個光子，能量差等於光子能量：

$$h\nu = E_{n_1} - E_{n_2}$$

**第二步：用光譜公式反推。** 關鍵的推理一步：玻爾假設電子的角動量也是量子化的（$L = n\hbar$），從而推出氫原子能級：

$$E_n = -\frac{13.6\ \text{eV}}{n^2}$$

代入躍遷公式，得到的譜線位置**與巴耳末的經驗公式完全吻合**——不只巴耳末系（可見光），還預言了紫外（賴曼系）與紅外（帕邢系）的譜線系。玻爾在論文中寫道：

> 「我們看到，這個假設能夠給出氫光譜的巴耳末公式……而不必對躍遷的機制作任何詳細假設。」

**第三步：實驗的迅速蓋章。** 理論領先實驗極短的時間：1914 年，富蘭克與赫茲（James Franck & Gustav Hertz）用電子撞擊汞蒸氣的實驗，證明**原子確實只能分「份」吸收能量**——定態假設的直接驗證。1914–1915 年，賴曼系（紫外）被觀測到，與玻爾的預言吻合。等待時間以「年」而非「十年」計——迴路轉速的指標。

**第四步：量子力學的橋樑。** 玻爾模型是過渡理論：它對多電子原子失效，1913–1926 年間經索末菲的橢圓軌道修正、最終被薛丁格方程取代（[1926-薛丁格方程.md](1926-薛丁格方程.md)）。但它的核心遺產——**分立能級、躍遷輻射、量子數**——成為量子力學的基石。

## 結案報告

玻爾原子模型是**量子假說＋光譜實驗數據的合流**。用金觀濤的框架說，本案屬於**理論**環節，它對「科學的工業化」時代的推動在於：

1. **理論危機的化解**——「電子會墜入原子核」的悖論被定態假設化解：公然違反經典理論的假設，被實驗蓋章認可。
2. **光譜學的理論化**——巴耳末的經驗公式被理論收編：光譜從「元素的指紋」（化學定性工具）升級為「能級的窗口」（物理定量工具）。
3. **工業的種子**——分立能級是雷射（1960）、半導體能帶理論、日光燈與霓虹燈的原理基礎：量子理論的工業化由此開端。
4. **迴路的加速**——理論（玻爾 1913）→實驗（富蘭克—赫茲 1914、賴曼系 1914）：等待以年計；第七幕「理論領先、實驗追上」的時代由此開幕。

## 證據與工具

```python
# 玻爾模型的氫原子能級與譜線計算
# E_n = -13.6 eV / n²；躍遷輻射 hν = E_n1 - E_n2

RY = 13.6057      # 氫的里德堡能量 eV
h = 4.1357e-15    # 普朗克常數 eV·s
c = 3.0e8         # 光速 m/s

def energy(n):
    return -RY / n**2

print("--- 氫原子能級 ---")
for n in range(1, 6):
    print(f"n = {n}: E = {energy(n):8.3f} eV")

print("\n--- 躍遷與譜線（波長 nm）---")
series = [("賴曼系（紫外）", 2), ("巴耳末系（可見）", 3), ("帕邢系（紅外）", 4)]
for name, n_final in series:
    lines = []
    for n_upper in range(n_final, n_final + 4):
        dE = energy(n_upper) - energy(n_final)
        lam = h * c / dE * 1e9
        lines.append(f"{lam:.1f}")
    print(f"{name}: {', '.join(lines)} nm")

# 驗證巴耳末公式：1/λ = R(1/4 - 1/n²)
R_inf = RY / h / c / 1e9   # 里德堡常數 m^-1
n_upper = 3
lam = 1 / (R_inf * (1/4 - 1/n_upper**2)) / 1e9
print(f"\n巴耳末 H-α 線（n=3→2）：{lam:.1f} nm（實測 656.3 nm）")
print("=> 理論與經驗公式完全吻合：量子假說被光譜數據蓋章。")

# 定態假設：為何電子不墜入原子核？
print("\n--- 定態假設 ---")
print("經典理論：電子繞核輻射 → 能量流失 → 螺旋墜核（10^-10 秒）")
print("玻爾假設：電子在定態軌道不輻射，只有躍遷才輻射光子")
print("=> 公然違反經典理論，卻被富蘭克—赫茲實驗（1914）蓋章。")
```
