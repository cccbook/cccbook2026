# 1280 機械鐘

## 案發現場

十三世紀末的歐洲，教堂尖塔上開始出現一種全新的機器：以重錘為動力、以擒縱器控制節奏的**機械鐘**。文獻記載，1280 年代英格蘭、法國、義大利的教堂與市政廳紛紛裝上大鐘；1271 年羅伯特·英格蘭人（Robertus Anglicus）已提及歐洲工匠正嘗試製造機械計時器。

謎團有三層：

1. 為什麼是此時此地？中國的水運儀象台（[1090-水運儀象台.md](1090-水運儀象台.md)）早已掌握擒縱原理，卻後繼無人。
2. 為什麼歐洲人如此執著於「精確報時」？中世紀修道院的作息（祈禱時辰）與城市工商業（工時、市場開閉）都急迫需要客觀的時間——**時間第一次成為公共的、可計量的資源**。
3. 最重要的：這台日差可達一刻鐘的粗鐘，為什麼會成為三百年後科學革命的基礎設施？

## 偵查過程

歐洲機械鐘的「偵查」是工匠們匿名的集體創作，推理路徑可以重建如下：

1. **動力問題**：水力受氣候與結凍限制，歐洲工匠改用**重錘驅動**——懸吊的石塊或鉛塊，重力恆定、日夜不休。
2. **核心難題——如何讓重錘「慢慢」落下？**重錘若直接下墜，幾秒即盡。解法是**擒縱器（verge escapement，冠狀輪擒縱）**：一個帶尖齒的冠狀輪與一根擺動的立軸（verge）配合，立軸上下兩片托葉交替卡住輪齒，使齒輪一格一格轉動；每次釋放都推動立軸擺動，形成節拍。這正是蘇頌水輪擒縱的歐洲版本——但動力從水換成了重錘。
3. **節拍的控制**：立軸的擺動週期由慣性與摩擦決定，並不精確——這是早期機械鐘日差可達 ±15 分鐘的原因。但工匠們持續改進：均衡擺（foliot，一根可調砝碼位置的橫桿）讓節拍至少可以**校準**。
4. **計時的顯示**：齒輪系把擒縱輪的轉動減速，帶動錶盤指針。教堂鐘面把一天劃分為 24 小時、每小時 60 分——**巴比倫的六十進位與教會的時辰制在此合流為標準化的時間刻度**。

用現代語言說，機械鐘完成了三件劃時代的事：把「時間」從自然節律（日出、日晷）中解放出來，變成機器內部的等時振盪；把時間量化成齒輪的齒數，成為可製造、可傳遞的量；讓時間變成人人可讀的公共刻度。

## 結案報告

機械鐘是「技術孤行」與「技術入圈」的分水嶺——它本身誕生時仍是孤立技術（無理論、無實驗），但它**埋下了迴圈的種子**：

1. **為科學備好基礎設施**——伽利略研究單擺（[1638-兩門新科學.md](1638-兩門新科學.md)）靠的是用自己的脈搏計時；等到惠更斯（[1656-惠更斯擺鐘.md](1656-惠更斯擺鐘.md)）把單擺等時性的理論直接物化為擺鐘，日差從分鐘級躍進到秒級，「理論→技術→更精儀器→新實驗」的迴圈第一次在計時領域轉動。
2. **精確計時成為實驗科學的前提**——力學、天文學（[1576-第谷天文台.md](1576-第谷天文台.md)）、乃至後來的經度測定，全部依賴可靠的時鐘。沒有機械鐘，就沒有可重複的受控實驗。
3. **時間觀念的革命**——機械鐘讓「時間就是資源」的觀念滲透社會；這種量化、標準化的思維方式，正是定量科學（[1620-培根新工具.md](1620-培根新工具.md)）的心理準備。
4. **古代與近代的分界**——蘇頌的擒縱與歐洲的擒縱原理相同，命運迥異：前者隨機構與人亡而失傳，後者因有印刷術（[1450-古騰堡印刷術.md](1450-古騰堡印刷術.md)）傳播圖紙、有科學社群接力改進而成為不斷升級的產業。**同一原理，有無迴圈，天壤之別。**

## 證據與工具

```python
# 用 Python 計算早期機械鐘的齒輪系：從擒縱輪到時針的減速比
# 情境：冕狀輪擒縱，冠狀輪 15 齒，立軸每擺一次放過半齒 → 每擺放 1 齒

# 節拍：立軸完整擺動一個來回，放過 2 齒（上下托葉各 1）
# 目標：擒縱輪每 1 小時轉 1 圈（慣例設計）
teeth = 15                      # 冠狀輪齒數
oscillations_per_rev = teeth / 2 * 2   # 轉一圈所需的擺動數
print(f"冠狀輪 {teeth} 齒，每擺放 {teeth}齒的一半=7.5 → 轉一圈需擺動若干次")
print(f"擒縱輪轉一圈所需擺動數 ≈ {oscillations_per_rev:.0f} 次")

# 節拍週期：若每小時轉一圈，擺動週期 = 3600 秒 / 擺動數
T = 3600 / oscillations_per_rev
print(f"節拍週期 ≈ {T:.2f} 秒/次")

# 減速齒輪系：把「每小時1圈」減速到「時針每12小時1圈」
# 需總減速比 = 12，用兩級齒輪實現，例如 8:1 與 1.5:1
print("\n時針需 12 小時轉一圈 → 總減速比 12")
print("兩級齒輪：64 齒/16 齒 = 4 倍，36 齒/12 齒 = 3 倍 → 4×3 = 12 ✓")
print("齒數比 = 角速度反比 → 機械鐘把『時間』量化為『齒數』")

# 誤差傳遞：節拍誤差如何放大成日差？
err_pct = 0.5   # 節拍平均偏差 0.5%（摩擦、溫度變動）
daily_err = err_pct * 86400 / 60
print(f"\n節拍偏差 {err_pct}% → 日誤差 ≈ {daily_err:.0f} 分鐘")
print("這就是早期機械鐘日差十幾分鐘的原因——")
print("突破要等惠更斯的擺（理論→技術迴圈）把誤差壓到秒級。")
```
