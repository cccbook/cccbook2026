# 1764 珍妮紡紗機

## 案發現場

案發地點是英國蘭開夏的紡織村莊。十八世紀中葉，棉紡織的生產鏈嚴重失衡：飛梭（1733，凱伊發明）讓織布速度倍增，**紡紗卻還是千年不變的手工**——一個紡工用紡車一次只能紡一根紗，織工一人要吃掉六到十個紡工的產量。紗荒引爆：紗價暴漲，織機停工待料，紡工日夜加班也供不上。

這是「技術孤行」的古典病例：**生產鏈上一環升級、下一環卡死**。解決者是蘭開夏木工兼織工**哈格里夫斯（James Hargreaves, 1720–1778）**。傳說 1764 年的一天，他的紡車被不小心碰翻，紡錘立著仍在轉——他靈光一閃：**紡錘為什麼必須臥著、一次只能一個？立著的紡錘可以並排很多個！**

## 偵查過程

哈格里夫斯的偵查是工匠式試錯，但這一次，試錯的對象是一個**可被重新設計的機械結構**。

**關鍵推理：把紡錘從「一個」變成「一排」。** 傳統紡車的紡錘是臥式、水平排列的，一次只能牽引一根紗。哈格里夫斯把紡錘**立起來、垂直並排八個**，再加一根水平夾持粗紗的滑軌：滑軌後拉，八個紡錘同時牽引八根紗；滑軌復位、紡錘加撚、紗繞上筒管。一人搖輪，八倍產量。

他把它命名為「**珍妮機（Spinning Jenny）**」（一般認為是紀念他的妻子或女兒珍妮）。1764 年造出原型，1770 年取得專利，此後紡錘數一路加到八十個——**一人一次紡八十根紗**，產量提升近百倍。

**迴路的點火。** 珍妮機消滅了紗荒，織布反過來成為瓶頸，於是水力紡紗機（1769，阿克萊特）、騾機（1779，克朗普頓）接連出招——紡織業在二十年内完成全鏈條機械化。棉布價格暴跌，需求再暴增，需求又倒逼更深的分工與動力化（[1769-瓦特冷凝器.md](1769-瓦特冷凝器.md) 的蒸汽機提供動力）——**正反饋迴路在紡織工業尺度上完全點火**，這就是工業革命的「棉紡引擎」。

哈格里夫斯本人下場悲慘：他被憤怒的手工紡工抄家砸機（紡工們視他為生計的毀滅者），晚年貧困而死。**技術進步的社會代價**第一次如此赤裸地呈現。

## 結案報告

1. **紡織工業機械化**——珍妮機是工業革命的第一台「多工位機器」，一人多工的理念通往一切近代工廠。
2. **正反饋迴路點火**——紡織鏈一環升級倒逼全鏈升級，棉布價格暴跌引爆需求，需求再倒逼動力與製造升級（[1797-莫茲利車床.md](1797-莫茲利車床.md) 的互換性製造即由此而來）。
3. **技術單點突破的典範**——珍妮機沒有任何科學理論支撐（純粹是機械結構的重新設計），證明在迴路已經成熟的時代，技術也能單獨發難、引發迴路升級——這是古代「技術孤行」（[1044-火藥.md](1044-火藥.md)）在工業時代的翻版，但這一次，迴路接住了它。
4. **社會代價**——手工紡工的暴動是「盧德運動」的先聲，技術進步與社會成本的張力從此成為工業時代的永久課題。

## 證據與工具

```python
# 珍妮機的「產量帳本」：一人多工位的威力

# 傳統紡車：一人一次紡 1 根紗
# 珍妮機：一人一次紡 N 根紗（N = 紡錘數）
jenny_spindles = [8, 16, 30, 80]  # 珍妮機歷代紡錘數
hand_output_per_day = 1.0  # 手工紡工一天產量（單位：束）

print("--- 產量對比 ---")
print(f"手工紡車：一人一天 {hand_output_per_day:.0f} 束")
for n in jenny_spindles:
    print(f"珍妮機（{n:2d} 錘）：一人一天 {n*hand_output_per_day:5.0f} 束"
          f"（提升 {n} 倍）\n")

# 生產鏈平衡：飛梭讓織布吃掉多個紡工的產量
weavers = 1
spinners_needed_traditional = 8  # 傳統：1 織工需 8 紡工
jenny = 8
spinners_needed_jenny = spinners_needed_traditional / jenny
print("--- 生產鏈平衡 ---")
print(f"1 織工傳統需 {spinners_needed_traditional} 個紡工供紗")
print(f"用珍妮機（{jenny} 錘）只需 {spinners_needed_jenny:.1f} 人")
print("=> 紗荒解除，織布反成瓶頸，倒逼水力紡紗機與騾機出招\n")

# 工業迴路的正反饋：棉布價格與需求
price_index = [100, 70, 55, 40, 25]  # 棉紗價格指數 1760-1790（示意）
demand_index = [100, 130, 150, 210, 300]  # 需求指數（示意）
print("--- 工業迴路的正反饋（示意）---")
for p, d in zip(price_index, demand_index):
    print(f"棉紗價格指數 {p:3d} -> 需求指數 {d:3d}")
print("=> 價格暴跌引爆需求，需求倒逼動力與製造再升級")
```
