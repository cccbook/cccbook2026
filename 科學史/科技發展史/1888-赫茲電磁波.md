# 1888 赫茲電磁波

## 案發現場

1888 年的德國卡爾斯魯厄理工學院，[1865-麥克斯韋方程組.md](1865-麥克斯韋方程組.md) 的命運正懸於一線。麥克斯韋 1879 年去世，理論領先實驗二十三年：他預言電磁波以光速傳播，可是**沒有任何人見過這種波**。學界分為兩派：歐洲大陸的「柏林學派」（亥姆霍茲除外）信奉超距作用，視麥克斯韋的「場」為數學幻覺；「場論派」則苦於無實驗證據。理論可以領先，但不能離線太久——這道時間裂縫，需要一場實驗來閉合。

本案的「偵探」是一位漢堡參議員之子、年僅 31 歲的德國物理學家——海因里希·赫茲（Heinrich Hertz, 1857–1894）。他是亥姆霍茲的得意門生，1884 年起研究麥克斯韋理論，卻坦承自己「讀不懂」那些冗長的方程——直到他把理論重推一遍才信服。而他的破案工具，樸實得驚人：一對金屬球、一根感應線圈、一圈銅絲。

## 偵查過程

**第一步：造出振盪器。** 赫茲的裝置堪稱極簡：感應線圈為兩個金屬球充電，電壓夠高時球隙之間**放電火花**——這個火花就是他需要的「振盪電流」：電荷在兩球間來回跳躍，頻率極高（約每秒上億次），按麥克斯韋理論必然輻射電磁波。1886–1887 年間，赫茲先證明了放電火花的高頻特性（他稱之為「快速電振盪」）。

**第二步：捕獲波。** 接收器更簡單：一根彎成環形的銅絲，兩端留一個微小的火花隙。赫茲把它放在振盪器幾米之外——**當振盪器放電時，接收環的隙縫裡也出現了微弱的火花**。看不見摸不著的電磁波，被一個火花隙捕獲了。

**第三步：驗證波的性質。** 這是本案最精彩的偵查。赫茲在 1887–1888 年間逐一證明這個波具有麥克斯韋預言的一切性質：

1. **反射**：波遇到金屬板會反射，形成駐波——測量駐波波長（約 3 米）與振盪頻率，算出傳播速度**等於光速**；
2. **折射**：波穿過大瀝青稜鏡時偏折，與光波一致；
3. **偏振**：波有偏振性，證明它是橫波——正如光；
4. **干涉**：波會干涉，符合波動方程。

每一項都與麥克斯韋的預言吻合。赫茲在 1889 年的論文中寫下結案陳詞：

> 「這些實驗的結果，與麥克斯韋理論的要求完全一致……這個理論的基礎，比我以往相信的更加牢固。」

而最諷刺的一幕是：有人問赫茲這個發現有何用處，他回答：

> 「大概沒什麼用……這只是證明了麥克斯韋大師是對的——除了這個，我們什麼也沒證明。」

**他不知道的是：七年前，一個 15 歲的義大利男孩馬可尼讀到了他的論文，正準備把這個「沒什麼用」的波變成跨越海洋的生意（見 [1895-馬可尼無線電.md](1895-馬可尼無線電.md)）。**

## 結案報告

赫茲實驗是**麥克斯韋的預言被實驗蓋章，迴路閉合**的時刻。用金觀濤的框架說，本案屬於**實驗**環節，它對「雙迴路大加速」的推動是電磁這條線的閉環：

1. **理論—實驗迴路閉合**——法拉第的實驗（[1831-法拉第電磁感應.md](1831-法拉第電磁感應.md)）逼出麥克斯韋的理論，理論預言電磁波，赫茲的實驗又捕獲它：理論→預言→實驗蓋章，迴路完整轉了一圈，等待時間（23 年）本身是迴路加速的證據。
2. **場論的勝利**——超距作用學派退場，「場」成為物理學的核心概念：此後引力場、量子場全部沿此路線。
3. **無線電的種子**——赫茲的火花隙就是最早的發射器與接收器：馬可尼、波波夫的無線電，全部是這套裝置的工程放大。
4. **光電效應的意外**——赫茲同時發現紫外光照射金屬會增強放電（光電效應的第一次觀察）——這道裂縫最終逼出愛因斯坦 1905 年的量子解釋：**一個閉合迴路的實驗，又埋下了下一個迴路的種子。**

## 證據與工具

```python
import math

# 赫茲實驗的關鍵測量：駐波測波長 → 算波速 → 對比光速

# 赫茲的振盪器：半徑約 30 cm 的偶極天線，固有頻率近似
c = 2.99792458e8          # 光速 m/s
L_antenna = 0.6           # 偶極天線全長 m
# 半波偶極子的諧振波長 ≈ 2L
lam = 2 * L_antenna
f = c / lam
print(f"赫茲振盪器波長 ≈ {lam:.1f} m，頻率 ≈ {f/1e6:.0f} MHz")
print("=> 每秒上億次的振盪：感應線圈火花隙即可激發。")

# 駐波測速：赫茲在牆面反射形成駐波，測量節點間距
node_spacing = 1.5        # 相鄰節點間距 m（半個波長）
lam_measured = 2 * node_spacing
f_assumed = f             # 振盪頻率由天線尺寸決定
v_measured = lam_measured * f_assumed
print(f"\n駐波實驗：節點間距 {node_spacing} m → 波長 {lam_measured:.1f} m")
print(f"波速 = λ × f = {v_measured:.3e} m/s")
print(f"光速 = {c:.3e} m/s，相對誤差 {abs(v_measured-c)/c*100:.2f}%")
print("=> 電磁波以光速傳播：麥克斯韋的預言被實驗蓋章！")

# 麥克斯韋理論—實驗迴路的時間帳
print("\n--- 迴路閉合的時間帳 ---")
for name, gap in [("法拉第感應 → 麥克斯韋方程組", 34),
                  ("麥克斯韋預言 → 赫茲實驗", 23),
                  ("赫茲實驗 → 馬可尼無線電", 7)]:
    print(f"{name}：{gap} 年")
print("=> 等待時間逐年縮短：迴路在加速。")
```
