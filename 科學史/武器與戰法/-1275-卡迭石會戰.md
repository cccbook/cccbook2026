# -1275-卡迭石會戰：史上第一場「有戰報」的大會戰

## 案件摘要

西元前 1274 年，埃及法老拉美西斯二世（約 25 歲）親率四個師約兩萬人北征，在奧龍特斯河畔的卡迭石城下，遭遇赫梯王穆瓦塔里二世約三萬五千人、三千餘輛戰車的合圍。埃及「拉」師被戰車洪流衝垮、王營被突破，拉美西斯二世以「阿蒙」師殘部逆勢反擊，撐到「普塔」師趕到，戰至日落成戰術平手。這樁案件的特殊性在於：它是**史上第一場有詳細當事人戰報、且戰後簽署了現存最早和平條約（前 1259）的會戰**——我們第一次能對照「宣傳」與「現實」兩份檔案，還原古代戰術的真相。

## 前因 -- 為什麼會有這個案子

- 埃及與赫梯爭奪黎凡特霸權，卡迭石扼守奧龍特斯河谷，是北上敘利亞的門戶。
- 拉美西斯二世御駕親征，四個師（阿蒙、拉、普塔、賽特）沿黎凡特海岸路線分梯次北進。
- 赫梯人採取「以戰車決勝」的戰略：把主力藏在卡迭石城後，用假情報誘敵。

## 線索與推理 -- 戰術與理論

### 線索一：兩種戰車，兩種戰法

| | 埃及戰車 | 赫梯戰車 |
|---|----------|----------|
| 乘員 | 2 人（駕手＋弓手） | 3 人（駕手＋盾手＋矛手） |
| 定位 | 高速移動射擊平台 | 衝擊突擊平台 |
| 優勢 | 機動性、射速、可反覆繞射 | 正面衝撞力、近戰 |
| 弱點 | 無近戰能力 | 重、慢、轉向半徑大 |

會戰的第一階段，赫梯戰車以衝擊戰法衝垮「拉」師——重車突擊的正確用法；但第二階段，赫梯戰車衝入埃及王營後**失去動量且無步兵跟進**，被埃及弓手與戰車從側翼切割。**「衝擊戰法沒有後續梯隊，就是一次性的」**——這條規律將在兩千年後的騎士衝鋒（克雷西）與一百年前的騎兵衝鋒（第一次世界大戰）反覆驗證。

### 線索二：假情報作為武器

赫梯人放出兩名「逃兵」，謊稱赫梯主力遠在北方。拉美西斯二世據此把四個師的行軍間隔拉開、輕兵冒進，結果「拉」師行至半渡即被合圍。**資訊不對稱 = 戰場選擇權**：掌握敵情者可以讓敵人「自己走進陷阱」。現代術語叫「OODA 循環」的觀察層被污染。

### 線索三：預備隊的價值

會戰勝負的轉折是「普塔」師趕到——四師分梯次行軍在平時是後勤包袱，在會戰中卻變成了**縱深梯隊**：第一梯隊被衝垮時，後續梯隊就是反擊的資本。埃及的勝利一半來自「行軍紀律」而非戰術天才——**組織性（梯隊與紀律）比英雄主義可靠**。

### 線索四：宣傳也是戰法

《彭塔烏爾長詩》把拉美西斯描寫成單騎破敵的英雄，實際戰報（公報）顯示埃及未能攻克卡迭石、次年被迫後退。**內部戰報與對外宣傳分離**——古代統治者已懂得「勝利敘事」是統治工具。對照兩份檔案，偵探才能還原真相：戰術平手、戰略僵持。

## 破案時刻

- 前 1274 卡迭石之戰結束：雙方均未取得決定性戰果。
- 前 1259，拉美西斯二世與赫梯新王哈圖西里三世簽署銀板和約——**現存最早的國際和平條約**，以阿卡德語刻於銀板，條款包含互不侵犯、引渡與同盟義務，其複製品至今懸掛於聯合國紐約總部。

## 後果 -- 改變了什麼

- 戰車戰法達到巔峰：兩國各損失慘重，卻都未放棄戰車軍——但戰車的黃金時代已在倒數（騎兵更便宜）。
- 埃及-赫梯和約確立了「大國均勢＋條約外交」的模式。
- 半世紀後（前 1200 前後），整個青銅時代體系崩潰，戰車帝國一併傾覆（見 [-1200-鐵器革命.md](-1200-鐵器革命.md)）。

## 戰法演進筆記

卡迭石留下的戰法遺產：

1. **衝擊梯隊必須有後續跟進**——單波衝鋒無論多猛，沒有步兵/後續梯隊就無法擴張戰果。
2. **假情報是最便宜的武器**——污染敵人的「觀察」，讓他自己走進陷阱。
3. **梯隊縱深 > 集中突擊**——行軍梯隊在會戰中就是預備隊。
4. **宣傳戰與戰場戰並行**——勝利敘事從此成為戰爭的一部分。
