# 2020 - 疫情 QE 與負油價（零利率下限：央行成為市場的最大買家）

## 案件摘要
2020 年 3 月，COVID 引爆全球拋售——美股**兩週熔斷四次**（史上首次）；
**Fed 兩週內降息至零 + 宣布「無限 QE」**（3.23）——首次買**公司債**；
4 月 20 日，**WTI 原油期貨結算價 -$37**——**史上首見負油價**：
$$\text{疫情衝擊} \xrightarrow{\text{零利率 + 無限 QE + 財政 $5 兆}} \text{資產全面重定價}$$
**零利率下限（ZLB）**時代的臨床——**凱因斯流動性陷阱**（1936）的回歸
（見 `1936-凱因斯一般理論.md`）——**貨幣與財政的融合（MMT 的邊緣）**。

## 前因 -- 為什麼會有這個案子
- **疫情的供需雙殺**：封鎖（需求消失）+ 停工（供給中斷）——
  **實體經濟的斷電**——與金融危機不同的衝擊形態；
- **2008 後的低利率世界**：Fed 資產負債表 $4.5 兆、利率 1.5%——
  **緩衝空間只剩 1.5pp**——**降息的彈藥不足**；
- **美元流動性恐慌**：2020.3 全球搶美元（Treasury 基金贖回、抽離新興市場）——
  **「美元荒」**——**儲備貨幣的危機時效應**；
- **負油價的物理**：原油儲存容量滿倉 + 期貨交割機制——
  **持有成本變成「無限大」**。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：零利率下限（ZLB）與 QE 的理論
名目利率不能顯著低於零（**現金的下限**）：
$$i \ge \underline{i} \approx 0 \quad \Rightarrow \quad \text{降息用盡後只剩「量」的工具}$$
**QE 的兩個理論**：
| 理論 | 機制 |
|------|------|
| 資產組合平衡 | 央行買長債 → 壓縮期限溢酬 → 全資產價格上升 |
| 信號（signaling） | 購債承諾 = 「利率將長期為零」的訊號 |
- **偵推**：**QE = 「價格工具（利率）用盡後的量工具」**——
  **Fed 資產負債表 3 月–6 月從 $4.2T → $7T**（史上最快）。

### 第二條線索：負油價的數學（持有成本的極限）
原油期貨到期 = **實物交割**——庫欣（Cushing）儲油基地滿倉：
$$\text{期貨價} = \text{現貨} + \text{持有成本（倉儲+保險）} \quad \Rightarrow \quad \text{倉儲成本 } > \text{原油價值} \Rightarrow F < 0$$
- **賣方付錢請人接貨**（無處儲存）——**持有成本的無限大 = 價格的負無窮**；
- **偵推**：**期貨的「金融工具」外殼下是「實物交割」的物理**——
  **紙上交易 vs 實物世界的斷裂**——**衍生品的「基礎設施依賴」**
  （與 1848 CBOT 的交割設計同源，見 `1848-芝加哥期貨交易所.md`）。

### 第三條線索：2020.3 的時間線（五週的崩潰與止血）
| 日期 | 事件 |
|------|------|
| 2020.3.3 | Fed 緊急降息 50bp |
| 2020.3.9/12/16/18 | **熔斷四次**（1987 補丁的實戰，見 `1987-黑色星期一.md`）|
| 2020.3.15 | **利率 0% + $7,000 億 QE** |
| 2020.3.23 | **「無限 QE」+ 公司債購買（首次）** |
| 2020.4.20 | **WTI -$37（負油價）** |
| 2020.8 | Fed「平均通膨目標制」（AIT）——允許通膨超標 |
- **偵推**：**3.23 的「無限承諾」是轉折點**——
  **「央行承諾的無限性 = 市場信心的錨」**——
  **Bagehot 教義（自由放款）的 2020 版**。

### 第四條線索：財政與貨幣的融合（MMT 的邊緣）
- 2020 年美國財政赤字 **$3.1 兆（GDP 15%）**，Fed 同步買債——
  **「財政赤字貨幣化」的臨床邊緣**；
- **MMT（現代貨幣理論）的辯論**：**法幣時代（1971 後）**政府可否
  無限支出？——**1923 德國的警告**（見 `1923-德國超通膨.md`）；
- **偵推**：**2020 = 「貨幣-財政融合」的實驗**——
  **通膨的考驗在 2021–22 年到來**（見 `2022-加密崩潰與升息衝擊.md`）。

## 結案 -- 後果與影響
- **零利率 + QE 的常態化**：全球央行資產負債表總和 >$30 兆——
  **央行 = 市場最大買家**——**價格的「央行化」**；
- **資產通膨**：2020–21 股市 +100%、房價 +30%、加密 +500%——
  **「K 型」的財富分配**（資產持有者 vs 現金者）；
- **平均通膨目標制（AIT）**：Fed 的框架進化——
  **「容許超標」的承諾**——**2022 年通膨 9% 的伏筆**；
- **負利率的擴散**：歐日負利率（-0.5%）——
  **「利率的下限」的物理**——**金融業的商業模式壓力**；
- **偵探教訓**：2020 年證明了——**零利率下限時，央行只剩「量與承諾」**——
  **「無限承諾」是流動性恐慌的唯一解藥**——
  **但承諾的代價（資產通膨、分配）在 2022 年結算**。
