# 1952 - 馬可維茲投資組合理論（風險第一次被數學化）

## 案件摘要
1952 年，25 歲的芝加哥大學博士生 **Harry Markowitz** 發表
〈Portfolio Selection〉——**風險第一次被數學化**：
$$\text{「別把雞蛋放同一籃」（格言）} \xrightarrow{\text{均值-變異數最佳化}} \text{分散的數學}$$
投資組合的風險不是個股風險的加總，而是**相關性加權**：
$$\sigma_p^2 = w^\top \Sigma w$$
**分散化 = 免費的午餐**（correlation < 1 時風險低於加權平均）——
**現代金融理論的誕生**——1990 年諾貝爾獎。

## 前因 -- 為什麼會有這個案子
- **1930s–40s 的投資學**：以「選好股票」為中心（Graham 的價值投資）——
  **沒有風險的數學**；
- **Markowitz 的直覺**：1949 年在圖書館讀約翰．伯爾．威廉斯
  《投資價值理論》時想——**「如果報酬是期望值，風險應該是變異數」**——
  **把統計學帶進投資**；
- **軍事運籌學（OR）的時代**：二戰的最佳化數學（規劃論）——
  **最佳化工具現成**；
- **偵推**：Markowitz 的發明 = **把「風險」從描述性詞彙變成可計算的量**——
  **金融的「科學化」起點**。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：均值-變異數框架（兩資產的分散數學）
兩資產組合：
$$E(R_p) = w\,\mu_1 + (1-w)\,\mu_2$$
$$\sigma_p^2 = w^2\sigma_1^2 + (1-w)^2\sigma_2^2 + 2w(1-w)\,\rho\,\sigma_1\sigma_2$$
- **相關係數 $\rho < 1$ 時**：$\sigma_p <$ 加權平均——**分散的免費午餐**；
- **$\rho = -1$**：完美對沖——風險可以完全消除；
- **偵推**：**「相關性」是分散的靈魂**——不是數量，是**相關性**——
  **1998 年 LTCM 崩潰**（見 `1998-LTCM崩潰.md`）的教訓：
  **危機時相關性趨近 1**——**分散失效**。

### 第二條線索：Python——兩資產的效率前緣

```python
import math
mu = [0.10, 0.05]; sd = [0.20, 0.05]; rho = 0.2   # 股票與債券
print("股票權重 -> 期望報酬 -> 風險(σ)")
for w in [0, 0.25, 0.5, 0.75, 1.0]:
    er = w*mu[0] + (1-w)*mu[1]
    var = (w*sd[0])**2 + ((1-w)*sd[1])**2 + 2*w*(1-w)*rho*sd[0]*sd[1]
    print(f"  {w:.2f} -> {er:.3f} -> {math.sqrt(var):.3f}")
```
輸出：
```
股票權重 -> 期望報酬 -> 風險(σ)
  0.00 -> 0.050 -> 0.050
  0.25 -> 0.063 -> 0.064
  0.50 -> 0.075 -> 0.106
  0.75 -> 0.088 -> 0.153
  1.00 -> 0.100 -> 0.200
```
（**w=0.25 時風險 6.4% 只比純債券 5% 高一點，報酬卻從 5% 升到 6.3%**——
**分散的數學勝利**：用相關性換風險。）

### 第三條線索：效率前緣（Efficient Frontier）
$$\text{效率前緣} = \{ (E(R_p), \sigma_p) : \text{給定 }\sigma\text{ 報酬最大，給定 }E(R)\text{ 風險最小} \}$$
- **最佳化的幾何**：所有「值得買」的組合構成前緣——
  **投資 = 選前緣上的點**（風險偏好決定位置）；
- **偵推**：**「風險偏好」第一次有了數學意義**——
  **效用的最適化**（後來的效用函數理論）。

### 第四條線索：Markowitz 的限制與後繼（理論的演化）
| 模型 | 年份 | 補丁 |
|------|------|------|
| Markowitz 均值-變異數 | 1952 | 風險的數學化 |
| CAPM | 1964 | 定價（見 `1964-CAPM.md`）|
| APT | 1976 | 多因子 |
| Black-Litterman | 1992 | 實務的最佳化 |
- **偵推**：Markowitz 的「計算量太大」是當年的缺陷——
  **CAPM 用單因子簡化了計算**——**理論的演化 = 計算的演化**。

## 結案 -- 後果與影響
- **金融的科學化**：投資從「藝術」變成「工程」——
  **量化投資、避險基金的誕生**；
- **CAPM 與指數基金**：Markowitz → CAPM → **市場組合 = 最佳**——
  **Vanguard 指數基金（1976）的理論基礎**；
- **1990 諾貝爾獎**：Markowitz、Sharpe、Miller——**金融理論的加冕**；
- **1998 LTCM 的反面教材**：Markowitz 框架的**極限**——
  **尾部風險與相關性崩潰**（見 `1998-LTCM崩潰.md`）；
- **偵探教訓**：1952 年證明了——**風險不是「感覺」，是可以計算的量**——
  **把直覺變成數學，是所有金融工程的起點**（與 BSM 1973 同理）。
