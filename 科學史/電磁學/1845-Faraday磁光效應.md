# 1845-Faraday 磁光效應

## 案件摘要
1845 年 9 月，法拉第發現偏振光穿過置於磁場中的重火石玻璃時，偏振面會旋轉——磁光效應（法拉第效應）。這是光與電磁之間關聯的第一個實驗證據，為 Maxwell 的光的電磁理論鋪路，並預示了法拉第的場論哲學：場是實體，而非數學工具。

## 前因 -- 為什麼會有這個案子
- **Faraday 一直相信電磁光相關**：早在 1822 年他便在筆記寫下「將磁轉為電，反之亦然」；1834 年起他又在筆記中反覆追問「光的磁化」「電與光的關聯」。
- **十年間的失敗嘗試**：他讓光穿過電解液、通電導線旁的介質、各種磁鐵附近的溶液……用偏振光做探針，全部觀察不到效應。
- **時代背景**：光的波動說（Young、Fresnel）當道，以太被視為光波傳播的介質；電磁（Faraday 的力線）與光（以太中的波）分屬兩套理論，無人能證明兩者相關。
- **線索暗示**：法拉第認為既然力線充滿空間，力線的「緊張狀態」應該會影響穿越其間的光——需要的是恰當的介質（高折射率玻璃）與強磁場。

## 線索與推理 -- 敏學式、程式、理論

### 線索一：實驗細節（1845 年 9 月 13 日）
- 法拉第選用**重火石玻璃**（dense flint glass，高折射率、高色散——他早年為光學儀器製作的玻璃長期保存在實驗室）。
- 他讓一束平面偏振光沿磁力線方向穿過玻璃（此幾何配置至關重要：光必須**沿**磁場方向傳播，而非垂直），在玻璃兩側放置強電磁鐵。
- **關鍵觀察**：通電瞬間，透過 Nicol 稜鏡觀察，偏振面明顯旋轉；斷電後旋轉消失。旋轉方向只取決於磁場方向，與光傳播方向無關（反向傳播不抵消——這與 natural optical activity 不同）。
- 之後他又發現抗磁性（diamagnetism，物質被磁場排斥）：物質在磁場中的行為比想像豐富得多。

### 線索二：法拉第效應的數學式
偏振面旋轉角與磁場 $B$、光穿過介質的路徑長 $d$ 成正比：

$$
\theta = V B d
$$

其中 $V$ 為 **Verdet 常數**（1854 年法國物理學家 Verdet 系統測量後確立），單位 rad/(T·m)。典型值：重火石玻璃約 $20\ \mathrm{rad/(T\cdot m)}$，水約 $13$，稀土鐵石榴石（TGG，今日最常用）約 $134$。

**推理驗證**：若光沿磁場往返一次（反射式光路，$d$ 翻倍），旋轉角 $\theta$ 加倍而非抵消——這正是法拉第效應能疊加放大、成為實用元件的原因。

### 線索三：場論哲學——場是實體
- 法拉第在 1844 年《關於物質的思考》（*A Speculation touching Electric Conduction*）中已提出：原子不是堅硬小球，而是空間中**力線匯聚的中心**；物質的本質是力，空間中的力場是真實的存在。
- 磁光效應成為這套哲學的實驗支柱：磁場（力線）能改變光的偏振，代表光波在介質中感受到磁場的存在——磁場必然是**可以影響光傳播的實體**，而不只是描述磁針受力與否的數學工具。
- 這是超距作用框架的致命一擊：光線穿越其間即受影響，表示「作用」瀰漫於空間本身。

### 線索四：對 Maxwell 的影響
- Maxwell 熟讀法拉第的《實驗電學研究》，自述其任務是「為法拉第的力線翻譯數學」。磁光效應向他展示：光與電磁場同屬一個系統。
- 1865 年 Maxwell 在《電磁場的動力理論》中推導出電磁波速度

$$
c = \frac{1}{\sqrt{\mu_0\varepsilon_0}} \approx 3\times 10^8\ \mathrm{m/s}
$$

與光速吻合，宣告**光就是電磁波**——而法拉第 1845 年的磁光效應正是這條統一之路的第一塊實驗基石。Maxwell 理論中，介質的相對磁導率與折射率關聯（Verdet 常數的微觀解釋）要到 Lorentz 電子論（1890s）與 Zeeman 效應（1896）才完全闡明。

### Python：模擬磁光旋轉與光隔絕器原理

```python
import numpy as np
import matplotlib.pyplot as plt

V, B, d = 134, 1.0, 0.02        # TGG 常數、磁場 1T、玻璃長 2cm
theta = V*B*d                    # 法拉第旋轉角 (rad)
print(f"旋轉角 θ = {np.degrees(theta):.1f}°")

# 光隔絕器原理：45° Faraday 旋轉 + 前後偏振片
E = np.array([1, 0])             # 入射光偏振方向 (x)
R  = np.array([[np.cos(theta), -np.sin(theta)],
               [np.sin(theta),  np.cos(theta)]])
E_fwd = R @ E                    # 順向通過旋轉 θ
pol45 = np.array([1, 1])/np.sqrt(2)     # 45° 檢偏片方向
print("順向透射強度  :", abs(np.dot(E_fwd, pol45))**2)  # ~1.0 全通
# 反向光：先被 45° 偏振片限制為 45° 偏振，通過磁場後又旋轉 θ（同向疊加！）
E_back = R @ pol45
print("反向透射強度  :", abs(np.dot(E_back, E))**2)     # ~0 全擋
```

執行結果：設計 $\theta = 45^\circ$（$B d = \pi/4V$）時，順向光完全透過、反向光完全被擋——這就是今日雷射系統中光隔絕器（optical isolator）的原理。

## 結案 -- 後果與影響
- **光的電磁理論**：磁光效應是光與電磁關聯的第一個實驗證據，直接引導 Maxwell（1865）與 Hertz（1887）完成光的電磁理論。
- **場論的確立**：法拉第的「場是實體」哲學經 Maxwell 數學化、Einstein 相對論發揚，成為現代物理的根本世界觀。
- **Verdet 常數與磁光材料**：1854 年 Verdet 系統測量各介質；現代以 TGG、YIG 等材料製作磁光元件。
- **光隔絕器（optical isolator）**：利用法拉第旋轉的非互易性（與光傳播方向無關），使雷射光只出不進，保護雷射源免受反射光干擾——光纖通訊、雷射實驗室中不可或缺的元件，正是 1845 年那個下午的後裔。
- 磁光效應至今仍是研究材料磁性的工具（磁光克爾效應 MOKE 用於讀取磁畴與硬碟磁性）。
