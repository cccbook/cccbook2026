# 1980s - 行動通訊誕生（1G AMPS 1983 → 2G GSM 1991）

## 案件摘要
1983 年，芝加哥開通世界第一個商用蜂巢式行動網路 AMPS（1G）；1991 年，芬蘭啟用第一個數位蜂巢系統 GSM（2G）。行動電話從車上笨重的「大哥大」變成口袋裡的數位裝置，只用了八年。

## 前因 -- 為什麼會有這個案子
- 1947 年，Bell Labs 的 D. H. Ring 與 W. Rae Young 提出**蜂巢式（cellular）**構想：把服務區切成小細胞，用低功率基地台覆蓋，頻率可重用——但當時沒有足夠的頻譜與切換技術。
- 1960–70 年代：Amos Joel（Bell Labs）發明越區**換手（handoff）**專利；Richard Frenkiel 與 Joel Engel 領導把蜂巢構想變成系統設計。
- 瓶頸：傳統行動電話（如 MTS/IMTS）用一個大功率高塔覆蓋全城，頻譜只能用一次——幾十個用戶就飽和。
- 1973 年，Motorola 的 Martin Cooper 打出第一通行動電話（對手正是 Bell Labs 的 Engel）。
- FCC 於 1970s 規劃 800 MHz 頻段供蜂巢使用，1978 年試驗、1983 年商用 AMPS。

## 線索與推理 -- 數學式、程式、理論

### 1. 蜂巢式細胞概念（cellular）
把服務區域劃分為六角形細胞（hexagonal cells），每個細胞由一個低功率基地台服務。六角形是能無縫拼貼平面的正多邊形中最接近圓形的——數學上的自然選擇。

細胞半徑 $R$、相鄰同頻細胞距離 $D$ 與**重用因子** $N$ 的關係：
$$D = R\sqrt{3N}$$
常見 $N = 7$（4/3 細胞分裂模式）→ 同頻干擾比（co-channel interference）：
$$\frac{C}{I} = \frac{(D/R)^{\gamma}}{n_{\text{interferers}}} = \frac{(\sqrt{3N})^{\gamma}}{6}$$
路徑損耗指數 $\gamma \approx 3.5\text{–}4$（都市），$N=7$ 時 $C/I \approx 18$ dB——恰夠 FM 語音品質。

### 2. 頻率重用與細胞分裂
- **頻率重用**：總頻譜 $S$ MHz、每細胞頻道組 $S/N$，但 $M$ 個細胞重用 → 系統容量 $\sim M \cdot S/N$。容量隨細胞數**線性放大**——這是蜂巢概念的天才之處。
- **細胞分裂（cell splitting）**：都市話務量大時把細胞切小（$R \to R/2$），同面積細胞數 $\times 4$ → 容量 $\times 4$。這讓網路可以按需求「成長」。
- 代價：換手更頻繁、基地台密度與成本上升、干擾管理更複雜。

### 3. AMPS 類比調頻（1G，1983）
- 頻段：824–849 MHz（上行）/ 869–894 MHz（下行），共 832 個雙工頻道，每頻道 30 kHz。
- 語音：**類比 FM 調變**（$\pm 12$ kHz 頻偏）；信令：FSK 數位控制頻道。
- 手機：Motorola DynaTAC 8000X（1983，約 4000 美元，重 790 g，通話 30 分鐘）。
- 缺點：頻譜效率低（1 頻道/30 kHz）、無加密（易被竊聽、IMEI 被盜）、跨系統漫遊困難。

### 4. GSM 數位化（2G，1991）
- 1982 年，歐洲邮电主管會議成立 Groupe Spécial Mobile（後改名 Global System for Mobile）制定泛歐標準——**標準先於產品**的先例。
- 1991 年芬蘭 Radiolinja 首次商用。
- 關鍵技術：
  - **TDMA**（時分多址）：每 200 kHz 載波分 8 個時槽 → 8 用戶共享一載波。
  - 語音壓縮：RPE-LTP 編碼，13 kbps（數位化後可用交錯與通道編碼抗誤差）。
  - **SIM 卡**：用戶與終端分離——「號碼跟人走」的革命，漫遊與換機自由。
  - **簡訊 SMS**：1985 年標準中設計、1992 年發出第一則（"Merry Christmas"）——後來意外的殺手級應用。
  - 數位加密（A5/1 串流密碼）→ 對講機時代結束。
- 頻譜效率：GSM 約 $8/200\,\text{kHz} = 0.04$ 用戶/kHz，是 AMPS（$1/30\,\text{kHz} \approx 0.033$）的數倍，且支援頻率跳頻（frequency hopping）抗衰落。

### 5. Shannon 容量：頻譜效率的天花板
$$C = B\log_2(1 + \text{SNR})\quad \text{[bits/s]}$$
- $B$：頻寬；SNR：訊雜比（線性尺度）。
- 頻譜效率：$\eta = C/B = \log_2(1+\text{SNR})$ [bits/s/Hz]。
- AMPS 類比 FM 每 30 kHz 傳 1 路語音（約等效 $\eta \approx 0.3$ bits/s/Hz）；GSM 每 200 kHz 傳 8×13 kbps → $\eta \approx 0.52$ bits/s/Hz。
- 容量提升的兩條路：加大 SNR（限功率與干擾）或**多天線/更先進調變編碼**（3G/4G 的 OFDMA、MIMO 把 $\eta$ 推向 5–7 bits/s/Hz）。

### 6. 1G → 2G → 3G → 4G 演進表
| 世代 | 年代 | 技術 | 調變/多址 | 峰值速率 | 關鍵應用 |
|------|------|------|-----------|----------|----------|
| 1G | 1983 | AMPS/TACS | 類比 FM / FDMA | 語音 | 行動通話 |
| 2G | 1991 | GSM | 數位 / TDMA | ~14 kbps（GPRS 2.5G ~100 kbps） | SMS、漫遊 |
| 3G | 2001 | WCDMA/CDMA2000 | CDMA | ~2 Mbps（HSPA ~14 Mbps） | 行動上網 |
| 4G | 2009 | LTE | OFDMA + MIMO | ~100 Mbps–1 Gbps | 影音、App 經濟 |
| 5G | 2019 | NR | mmWave + massive MIMO | ~10 Gbps | IoT、超低延遲 |

### 7. Python 計算 Shannon 容量範例

```python
import numpy as np

def shannon_capacity(B_hz, snr_db):
    snr = 10 ** (snr_db / 10)          # dB → 線性
    return B_hz * np.log2(1 + snr)     # bits/s

def spectral_efficiency(snr_db):
    return np.log2(1 + 10 ** (snr_db / 10))  # bits/s/Hz

# --- 各代行動通訊的頻譜效率估算 ---
cases = [
    ("1G AMPS  (類比, 30 kHz/ch, 1 語音)",        30e3, 1, "FM 等效 ~0.3"),
    ("2G GSM   (數位, 200 kHz, 8 時槽 x13 kbps)", 200e3, 8, "實際 ~0.52"),
    ("3G HSPA  (5 MHz, 高階調變+編碼)",            5e6, 1, "實際 ~1.4"),
    ("4G LTE   (20 MHz, OFDMA+64QAM+MIMO)",       20e6, 1, "實際 ~7"),
]
for name, B, users, note in cases:
    # 以「等同 SNR」反推：假設總資料率 R，則 eta = R/B
    print(f"{name:52s} 頻寬 {B/1e3:7.0f} kHz  {note}")

# --- SNR 對容量的曲線 ---
snr_db = np.linspace(-10, 40, 100)
C = shannon_capacity(1e6, snr_db)   # 1 MHz 頻寬
eta = spectral_efficiency(snr_db)

import matplotlib.pyplot as plt
fig, ax = plt.subplots(figsize=(8, 5))
ax.plot(snr_db, eta, lw=2, color="tab:purple")
for x, lbl in [(10, "1G AMPS ~0.3"), (18, "GSM ~0.52"), (25, "3G ~1.4"), (35, "4G ~7")]:
    ax.axvline(x, ls="--", color="gray", alpha=0.6)
    ax.annotate(lbl, (x, spectral_efficiency(x) + 0.3), fontsize=9)
ax.set_xlabel("SNR (dB)"); ax.set_ylabel("Spectral efficiency (bits/s/Hz)")
ax.set_title("Shannon: C = B log2(1+SNR) → 各代行動通訊的頻譜效率天花板")
ax.grid(alpha=0.3)
plt.tight_layout(); plt.savefig("shannon_capacity.png", dpi=120); plt.show()

# --- 細胞分裂容量估算 ---
R0 = 5.0        # 原細胞半徑 km
area = 1000.0   # 服務區 km^2
n_cells0 = area / (2.598 * R0**2)          # 六角形面積 = 2.598 R^2
print(f"\nR=5km: {n_cells0:.0f} 細胞, 每細胞 7 頻道組 → 容量 ~{n_cells0*7*1:.0f} 頻道")
print(f"R=2.5km(分裂): {n_cells0*4:.0f} 細胞 → 容量 ~{n_cells0*4*7:.0f} 頻道 (x4)")
```

### 8. 蜂巢幾何的小算術
六角形細胞面積 $A_{\text{cell}} = \frac{3\sqrt{3}}{2}R^2 \approx 2.598 R^2$。都市細胞從 1G 的數公里縮到 4G 的數百公尺、5G 小基站（small cell）——**重用因子 × 細胞數**的乘積，就是把有限頻譜變成無限容量的把戲。

## 結案 -- 後果與影響
- 1G 證明蜂巢可行；2G 的 SIM 卡與簡訊讓手機成為**個人**裝置而非車輛配件。
- 2G → 3G → 4G 的數位化疊加，催生了智慧型手機、App 經濟、行動支付——通訊與運算（1971 的 4004）在此匯流。
- GSM 的「標準先於產品、跨國漫遊」模式成為 3GPP 的基因，5G 時代全球共用一套標準。
- 結案評語：這案的兇手是「頻譜稀缺」，偵探的解法是「把一個大細胞切成千萬個小細胞，再讓每赫茲承載更多位元」——幾何與資訊理論聯手，解放了行動通訊。
