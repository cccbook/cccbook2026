# 1958-積體電路

## 案件摘要
1958 年夏天，TI 的 Jack Kilby 在一塊鍺上做出第一個積體電路（相移振盪器）；1959 年 Fairchild 的 Robert Noyce 用矽平面製程讓 IC 可以量產。「數字的暴政」被擊敗，摩爾定律時代降臨。

## 前因 -- 為什麼會有這個案子
- 電晶體問世後，電腦、飛彈與衛星需要成千上萬個元件。用手工把電晶體、二極體、電阻、電容焊在一起：
  - 元件數量與可靠度成反比，接點是最易故障處。
  - 體積、重量、耗電隨元件數線性暴增。
- 這個困境被稱為「**數字的暴政（tyranny of numbers）**」——空軍與軍方的報告直言大型系統在現有工藝下不可行。
- Kilby 新到 TI（1958.5），適逢全公司休假、無法申請材料，只能用手邊的鍺與鍺電阻想法做實驗——孤注一擲的一個夏天。

## 線索與推理 -- 數學式、程式、理論
### 1. Kilby 的洞察：「元件不必是不同的材料」
Kilby 的推理鏈：
1. 電晶體、二極體、電阻、電容**全都可以用半導體做出來**。
2. 那就不需要把不同元件「連接」，而是讓它們**在同一塊半導體上形成**。
3. 連接數從 $O(N)$ 個外部接點降到 $O(1)$ 塊晶片上的金屬互連。

1958 年 9 月 12 日，Kilby 在鍺片上做出**相移振盪器**（一個電晶體 + RC 相移網路），示波器上出現正弦波——第一個 IC 誕生。

### 2. Noyce 的平面製程與矽的勝利
Noyce（Fairchild, 1959）與 Hoerni 的平面製程（planar process）讓 IC 可量產：
- SiO₂ 氧化層保護表面、作為擴散遮罩與絕緣。
- 光刻（photolithography）定義圖案，鋁金屬互連沉積在氧化層上。
- 矽取代鍺：SiO₂ 天然、緻密、絕緣（鍺氧化物遇水可溶，無法平面化）。
- Kilby 的 IC 用金線「飛線」互連；Noyce 的互連是製程的一部分——這是量產的分水嶺。

### 3. MOSFET：後來的王者
Kahng 與 Atalla（1960, Bell Labs）提出 MOSFET，驅動電流：

$$I_D = \frac{1}{2}\mu_n C_{ox}\frac{W}{L}\,(V_{GS}-V_{th})^2 \quad (\text{飽和區})$$

其中 $C_{ox} = \varepsilon_{ox}/t_{ox}$。MOSFET 製程步驟少、可微縮，成為摩爾定律的主角。

### 4. 摩爾定律（1965）
Noyce 的合夥人 Gordon Moore 觀測：晶片上元件數每年翻倍（後修正為 18–24 個月）：

$$N(t) = N_0 \cdot 2^{\,t/T}$$

### 5. Python 模擬：Kilby 的 RC 相移振盪器頻率

```python
import numpy as np
import matplotlib.pyplot as plt

def phase_shift_osc_f(R, C, n=3):
    """三節 RC 相移振盪器：每節移相 60 度，共 180 度
       振盪條件：增益 >= 29，頻率 f = 1/(2*pi*R*C*sqrt(6))"""
    return 1/(2*np.pi*R*C*np.sqrt(2*n))

R, C = 10e3, 10e-9
f0 = phase_shift_osc_f(R, C)
print(f"三節 RC 相移振盪器 f0 = {f0/1e3:.2f} kHz（巴克豪森準則：|A|>=29, 相位=-180°）")

# 頻率響應驗證
f = np.logspace(2, 5, 400)
w = 2*np.pi*f
H = (1/(1+1j*w*R*C))**3          # 三節 RC 高通
plt.figure(figsize=(8,4.5))
plt.subplot(2,1,1)
plt.semilogx(f, 20*np.log10(np.abs(H))); plt.ylabel('|H| (dB)')
plt.axhline(-1/29*1, ls='--', c='r', lw=0.8)
plt.subplot(2,1,2)
plt.semilogx(f, np.angle(H, deg=True)); plt.ylabel('相位 (°)')
plt.axhline(-180, ls='--', c='r'); plt.xlabel('頻率 (Hz)')
plt.suptitle(f'三節 RC 相移網路：f0 = {f0/1e3:.2f} kHz')
plt.tight_layout(); plt.show()
```

巴克豪森振盪準則：迴路增益 $|A\beta| \geq 1$ 且相位為 $-180°$（加反相放大器則總相位移 $360°$）。三節 RC 在 $f_0$ 處各移相 $60°$，放大器增益須達 29 倍——Kilby 的鍺原型正是靠這條件振起正弦波。

## 結案 -- 後果與影響
- 1964 年 Fairchild 用平面製程量產 IC；阿波羅計畫的登月電腦（AGC）採用 IC，成為最大的早期客戶，拉低了價格曲線。
- **2000 年諾貝爾物理獎**頒給 Jack Kilby（Noyce 已於 1990 年去世，諾獎不頒給亡者）。
- 摩爾定律驅動半世紀：元件密度從 Kilby 原型的 1 個電晶體到今天的百億級。
- 從 IC 直接長出微處理器（1971, Intel 4004）、DRAM、快閃記憶體——整個數位文明建基於此案。
