# 1591 - Viète 符號代數

## 案件摘要
1591 年，法國數學家韋達（François Viète, 1540–1603）出版《分析術引論》（*In artem analyticem isagoge*），首次系統性地用字母表示數量，將代數從「文字敘述的藝術」蛻變為「符號操作的科學」。這是從修辭代數到符號代數的關鍵飛躍。

## 前因 -- 為什麼會有這個案子
- **修辭代數的困境**：從巴比倫、丟番圖到中世紀的代數，都用冗長文字描述問題，例如「某數的平方加上該數的三倍等於十」。方程無法被「一眼看清」，更難被機械式地操作。
- **縮記代數的過渡**：Diophantus 用縮寫（如 $\varsigma$ 表示未知數），Jordanus、Pacioli 也有局部記號，但只縮寫「未知數」，已知量仍是文字。
- **文藝復興的方程求解潮**：Cardano（1545《大術》）解出三次、四次方程，但解法以幾何語言與文字論證包裹，公式寫出來像一篇短文。
- **韋達的職業背景**：他是律師兼王室密碼解析官，習慣將雜亂訊息化為可操作的符號系統——這個思維被移植到代數上。

## 線索與推理 -- 數學式、程式、理論

### 線索一：母音與子音的密碼
韋達的規則極為簡潔：
- **母音** $A, E, I, O, U$ 表示**未知量**（quaesita，被求的量）
- **子音** $B, C, D, \dots$ 表示**已知量**（data，給定的量）

用現代記法重寫，韋達式的方程就像：

$$A^2 + B A = C \quad\Longleftrightarrow\quad a x^2 + b x = c$$

這一步看似平凡，實則深刻：**方程首次成為「類」的陳述**——它不再是關於某個具體數的問題，而是關於任意係數 $a,b,c$ 與任意根 $x$ 的一般關係式。符號使「解一整類方程」成為可能。

### 線索二：方程的符號操作
有了符號，代數運算變成可機械執行的規則。韋達提出：
- 齊次性原則：各項的「次數」必須一致（他仍受幾何量綱束縛）。
- 運算分類：合併（logistice numerosa）與符號運算（logistice speciosa）——後者正是今日抽象代數的胚胎。

### 線索三：Viète 公式（根與係數的關係）
韋達發現多項式的根與係數之間有固定的對稱關係。對二次方程 $a x^2 + b x + c = 0$，設兩根為 $x_1, x_2$：

$$x_1 + x_2 = -\frac{b}{a}, \qquad x_1\, x_2 = \frac{c}{a}$$

**推理**：由因式分解 $a(x-x_1)(x-x_2) = a x^2 - a(x_1+x_2)x + a\,x_1 x_2$，與原式逐項比較係數即得。

一般 $n$ 次多項式 $\displaystyle\sum_{k=0}^n a_k x^k = a_n \prod_{i=1}^n (x - x_i)$ 的 Viète 公式：

$$\sum_{i=1}^n x_i = -\frac{a_{n-1}}{a_n}, \qquad \sum_{i<j} x_i x_j = \frac{a_{n-2}}{a_n}, \qquad x_1 x_2 \cdots x_n = (-1)^n \frac{a_0}{a_n}$$

### 線索四：Python 數值驗證 Viète 公式

```python
import numpy as np

# a x^2 + b x + c = 0
a, b, c = 2.0, -7.0, 3.0

roots = np.roots([a, b, c])
x1, x2 = roots

print("兩根:", x1, x2)
print("x1 + x2 =", x1 + x2, " 預期 -b/a =", -b / a)
print("x1 * x2 =", x1 * x2, " 預期 c/a =", c / a)

# 一般 n 次驗證
coeffs = [1, -6, 11, -6]          # (x-1)(x-2)(x-3)
rs = np.roots(coeffs)
n = len(coeffs) - 1
print("根之和 =", rs.sum().round(10), " 預期 -a_{n-1}/a_n =", -coeffs[-2] / coeffs[-1])
print("根之積 =", np.prod(rs).round(10), " 預期 (-1)^n a_0/a_n =", (-1)**n * coeffs[-1] / coeffs[-1])
```

輸出中 `x1 + x2 = 3.5`、`x1 * x2 = 1.5`，與 $-(-7)/2 = 3.5$、$3/2 = 1.5$ 完全吻合——符號推得的公式經得起數值檢驗。

## 結案 -- 後果與影響
- **結案陳詞**：代數獲得了一套「通用語言」。此後方程可以被書寫、比較、變換，而非僅被描述。
- **對 Descartes 的影響**：笛卡爾在《幾何學》(1637) 承襲韋達的字母傳統，但改用**開頭子音** $a, b, c$ 表已知數、**末尾子音** $x, y, z$ 表未知數，並發明指數記法 $x^2, x^3$——這正是我們今天使用的記號。
- **通往抽象代數**：Viète 的 logistice speciosa（符號邏輯）是從「數的代數」走向「符號的代數」的第一步，最終在 19 世紀結出群、環、域之果。

## 關鍵人物與文獻
- François Viète, *In artem analyticem isagoge* (Tours, 1591)
- Viète, *De aequationum recognitione et emendatione* (1615, 身後出版) — 詳述根與係數關係
- Cardano, *Ars Magna* (1545) — 前因中的三次方程突破
- Descartes, *La Géométrie* (1637) — 符號現代化的繼承者
