# 2016-ABC 猜想「證明」爭議（IUT 理論）

## 案件摘要
2016 年，望月新一（Mochizuki）宣稱以「宇宙際 Teichmüller 理論（IUT）」證明 ABC 猜想。
Scholze–Stix 指出關鍵推論無法驗證，2021 年 PRIMS 仍予刊登，數學社群陷入分裂——
這是 21 世紀數學驗證機制的最大案件。

## 前因 -- 為什麼會有這個案子
- **ABC 猜想**（Masser–Oesterlé, 1985）：數論中最深刻的未解問題之一，
  被稱為「Fermat 最後定理的推廣」。它斷言加法結構（$a+b=c$）與乘法結構（質因數）幾乎互斥。
- **Fermat 最後定理**：Wiles 1995 年以橢圓曲線與模形式證明 FLT；
  ABC 猜想可推出 FLT 的漸近版本（Ribenboim 型結果），兩者有深刻的等價層次關係。
- **望月新一**：京都大學 RIMS 教授、p-adic Teichmüller 理論專家，
  自 2012 年起在個人網頁公開 500+ 頁的 IUT 理論四部曲，宣稱證明 ABC。
- 證明使用全新自創術語（宇宙際、霍奇劇院、theta 環……），數年間無人能讀懂——案件正式成立。

## 線索與推理 -- 數學式、程式、理論

### ABC 猜想
對互質正整數 $a, b, c$ 滿足 $a + b = c$，定義根積（radical）：
$$\mathrm{rad}(n) = \prod_{p \mid n} p$$
**ABC 猜想**：對任意 $\epsilon > 0$，只有有限多組互質三元組滿足
$$c > \mathrm{rad}(abc)^{1+\epsilon}$$
等價地：$\dfrac{c}{\mathrm{rad}(abc)}$ 有「漸近上界」，例外組是稀疏的。

### 與 Fermat 最後定理的關係
設 $x^n + y^n = z^n$（互質），則 $c = z^n$，而
$$\mathrm{rad}(abc) \le \mathrm{rad}(xyz) \le xyz < z^3$$
由 ABC 猜想：$z^n \le \mathrm{rad}(abc)^{1+\epsilon} < z^{3(1+\epsilon)}$，
故 $n \le 3(1+\epsilon)$。取 $\epsilon$ 足夠小，得 $n \le 4$ 類的漸近結論——
**ABC 幾乎蘊含 Fermat 最後定理**（對足夠大的指數）。

### Python 數值實驗：搜尋 ABC 反例

```python
from math import prod

def rad(n):
    """根積 rad(n) = 所有相異質因數的乘積"""
    out, p = 1, 2
    while p * p <= n:
        if n % p == 0:
            out *= p
            while n % p == 0:
                n //= p
        p += 1 if p == 2 else 2
    if n > 1:
        out *= n
    return out

def abc_quality(a, b):
    """品質 q = log(c) / log(rad(abc))，q > 1 即『逼近反例』"""
    c = a + b
    r = rad(a * b * c)
    from math import log
    return c, r, log(c) / log(r)

# 搜尋高品質三元組（品質越接近或超過 1，越是反例候選）
best = []
for a in range(1, 2000):
    for b in range(a, 2000):
        from math import gcd
        if gcd(a, b) != 1:
            continue
        c, r, q = abc_quality(a, b)
        if q > 1.0:
            best.append((q, a, b, c, r))

best.sort(reverse=True)
print("前三名 ABC 候選（品質, a, b, c, rad(abc)）:")
for row in best[:3]:
    print(row)

# 檢查 c < rad(abc)^{1.1} 是否成立（epsilon = 0.1 的數值驗證）
q, a, b, c, r = best[0]
print(f"c = {c}, rad^1.1 = {r**1.1:.0f}, 違反? {c > r**1.1}")
```

實驗預期：可找到如 $a=1, b=8, c=9$（品質 $\approx 1.227$）或
$2+3^ {10}\cdot 109 = 23^5$（品質 $>1.6$，已知最高品質紀錄之一）這類組合，
但**品質一致被上界壓制**——數值證據支持猜想，卻遠非證明。

### IUT 理論的核心宣稱
望月的策略：
1. 對橢圓曲線 $E$ 與其 p-adic 場，建立「霍奇劇院」$ \mathbb{B}^{+}$；
2. 透過「theta 環」與 Frobenius 類映射 $\Theta$，在**不同宇宙**（不同同構版本的數域）之間搭建橋樑；
3. 關鍵推論 **Corollary 3.12**：由橋樑得到不等式鏈，最終導出
   $$c < \mathrm{rad}(abc)^{1+\epsilon}$$
   這正是 ABC 猜想——也是整個理論唯一出口。

### Scholze–Stix 的質疑（2018 討論、2020 發表）
- Peter Scholze（2018 菲爾茲獎得主）與 Jakob Stix 於 2018 年親赴京都討論後，
  發表報告指出：**Corollary 3.12 的證明「嚴重不完整且無法修補」**——
  其中「縮併同構」（contraction of universes）的論證在關鍵處等同循環論證。
- 望月則回應他們「誤讀了 IUT」。雙方各自發表立場文件，爭議公開化。

## 結案 -- 後果與影響
- **2021 年 PRIMS 刊登**：望月任主編的《Publications of RIMS》於 2021 年刊登 IUT 四部曲，
  但 Scholze、Stix 及多數主流數論家**不承認**其為證明——學界罕見地分裂。
- 部分學者（如 Fesenko、加藤和也團隊）持續發展 IUT 應用；主流則視其為未驗證理論。
- 案件凸顯**數學驗證機制**的危機：當證明長達千頁、術語自創、且無同儕能讀懂時，
  「同行評審」形同虛設。此案件推動了形式化驗證（Lean、Coq）在數學界的地位提升
  （如 Scholze 自己發起的 Liquid Tensor Experiment）。
- 對照前案：[1983-有限單群分類](1983-有限單群分類.md)與
  [2004-有限單群分類補完](2004-有限單群分類補完.md)展示「巨型證明可以被社群消化」，
  而 IUT 案件展示「巨型證明也可能無法被消化」——驗證機制的兩面鏡像。
