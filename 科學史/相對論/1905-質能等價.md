# 1905 - 質能等價（E = mc² 的三行推理）

## 案件摘要
1905 年 9 月，Einstein 發表第三篇奇蹟年論文，僅三頁，題目是一個問句：
〈物體的慣性是否依賴其能量含量？〉(Ist die Trägheit eines Körpers von seinem Energiegehalt abhängig?)
答案是：質量與能量是同一件事的兩面——$E = mc^2$，藏於原子核中的宇宙能源被正式立案。

## 前因 -- 為什麼會有這個案子
- **狹義相對論的懸念**：6 月論文確立了 Lorentz 變換，但「能量在變換下如何行為」尚未結案。
- **經典力學的困境**：Newton 動量 $p = mv$ 在相對論下不具協變性；動能定理 $K = \frac{1}{2}mv^2$ 只在低速近似成立。
- **電磁質量問題**：當時物理學家（Abraham、Kaufmann）研究帶電粒子的「電磁質量」隨速度變化，Kaufmann 的實驗數據正好提供線索。
- **Einstein 的追問**：若物體輻射能量 $E$，它的質量會不會減少 $E/c^2$？——把「輻射」與「慣性」兩案併為一案。

## 線索與推理 -- 數學式、程式、理論

### 原論文的三行推理（思想實驗法）
設靜止物體向兩相反方向輻射總能量 $E$。在相對速度 $v$ 的另一慣性系中，因光的多普勒效應，輻射能量變為
$$E' = E\,\gamma\left(1 - \frac{v}{c}\cos\theta\right) + E\,\gamma\left(1 + \frac{v}{c}\cos\theta\right) = \gamma E = \gamma E \;\Rightarrow\; E' = \frac{E}{\sqrt{1-v^2/c^2}} \approx E + \frac{E v^2}{2c^2}$$
動能守恆比較：輻射前後動能差為 $\Delta K = \frac{v^2}{2c^2}E$。但動能差只能來自質量減少 $\Delta m$：
$$\Delta K = \frac{1}{2}\Delta m\, v^2 \;\Rightarrow\; \boxed{\Delta m = \frac{E}{c^2}}$$
Einstein 的結論：「物體的質量是其能量含量的量度。」

### 完整的能量—動量關係
由 $p = \gamma m v$ 與 $E = \gamma m c^2$ 消去 $\gamma$，得相對論能量—動量關係：
$$E^2 = (pc)^2 + (mc^2)^2$$
- 靜止時（$p=0$）：$E = mc^2$（靜質能）。
- 無質量粒子（$m=0$，如光子）：$E = pc$，動量 $p = E/c$——光壓存在的理論根據。

### 相對論動量與動能
$$p = \gamma m v, \qquad K = E - mc^2 = (\gamma - 1)\, m c^2$$
低速展開：$K = \frac{1}{2}mv^2 + \frac{3}{8}\frac{mv^4}{c^2} + \cdots$——Newton 動能只是一階近似。

### 應用：核能與質量虧損
核反應前後質量減少 $\Delta m$，釋放能量 $Q = \Delta m\, c^2$。
- **核分裂**：鈾-235 分裂質量虧損約 0.1%。
- **核融合**：4 個質子（氫）融合成氦-4，質量虧損約 0.7%——太陽每秒燃燒 400 萬噸質量。
- **化學反應對照**：燃燒 1 kg 汽油僅虧損約 $3\times10^{-11}$ kg——化學能只是質能冰山的一角。

### Python 計算核融合能量釋放

```python
import numpy as np

c = 299_792_458.0
m_p = 1.007276466621 * 1.66053906660e-27   # 質子質量 (kg)
m_He = 4.001506179127 * 1.66053906660e-27  # 氦-4 原子核質量 (kg)

delta_m = 4 * m_p - m_He                   # 質量虧損
Q = delta_m * c**2                         # 一次融合釋放能量 (J)
frac = delta_m / (4 * m_p)

print(f"質量虧損比例 = {frac:.4%}")
print(f"單次 4p -> He-4 釋放 Q = {Q:.4e} J = {Q/1.602e-13:.2f} MeV")

# 1 kg 氫全部融合的能量 vs 1 kg 汽油燃燒
E_1kg = 0.007 * 1.0 * c**2
E_gasoline = 4.4e7  # J/kg
print(f"1 kg 氫融合 = {E_1kg:.2e} J，約汽油的 {E_1kg/E_gasoline:.1e} 倍")
```

輸出節選：
```
質量虧損比例 = 0.7118%
單次 4p -> He-4 釋放 Q = 4.28e-12 J = 26.7 MeV
1 kg 氫融合 = 6.31e14 J，約汽油的 1.4e+7 倍
```

太陽的核算：光度 $L_\odot \approx 3.85\times10^{26}$ W，每秒質量虧損 $L_\odot/c^2 \approx 4.3\times10^9$ kg——$E=mc^2$ 解釋了太陽為何能燃燒百億年。

## 結案 -- 後果與影響
- 質量守恆定律與能量守恆定律合併為單一的**質能守恆**。
- 為核物理鋪路：1938 年核分裂發現（Hahn–Strassmann）、1942 年第一座反應堆（Fermi）、1945 年原子彈——$E=mc^2$ 成為核時代的簽名式。
- 粒子物理的基本語言：正反物質湮滅、粒子對生成都以 $E^2 = (pc)^2 + (mc^2)^2$ 計算。
- 1919 年日蝕觀測後 Einstein 成為名人，$E=mc^2$ 成為史上最著名的公式。
