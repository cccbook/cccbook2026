# 1915-廣義相對論場方程

## 案件摘要
1915 年 11 月，Einstein 在經歷八年的數學迷宮後，於普魯士科學院連續四場演講，最終提出廣義相對論場方程。物理量不再作用於「平直舞台」，而是舞台本身即物理——時空幾何由物質與能量決定。首項勝利：精確解釋水星近日點每世紀多出的 43 角秒。

## 前因 -- 為什麼會有這個案子
- **1907 年「最快樂的想法」**：Einstein 在專利局想到「自由落體的人感覺不到自己的重量」，提出**等效原理**：均勻重力場與加速度局部不可區分。
- **狹義相對論的缺口**：1905 年的理論只適用於慣性系，且無法容納牛頓重力（瞬時超距作用違反光速上限）。
- **兩個實驗事實待解**：
  1. 水星近日點進動有每世紀 $43''$ 的異常殘差（Le Verrier 1859 年發現，牛頓力學算完後無法解釋）。
  2. 光線經過太陽附近應被偏折，偏折量是多少？
- **等效原理的線索**：重力場中時間會變慢（重力紅移），推論下去——重力會「彎曲」時間，也可能彎曲空間。

## 線索與推理 -- 數學式、程式、理論

### 1. 八年奮鬥：從等效原理到張量
1912–1914 年，Einstein 回到蘇黎世，向大學同學、數學家 **Marcel Grossmann** 學習 Riemann 幾何與**絕對微分學**（Ricci 與 Levi-Civita 的張量分析）。他寫信給 Sommerfeld：

> 「我從未如此痛苦地工作過，我敬畏數學的優雅……相比這個問題，原本的狹義相對論不過是兒戲。」

1913 年的「Entwurf（草稿）」理論走錯路：場方程不具有一般座標協變性（hole argument 的誤解），Einstein 甚至一度錯誤地認為一般協變性不可能。1915 年秋他承認錯誤，回到 Riemann 幾何的正道。

### 2. 核心數學：曲率與能量-動量
時空由度規張量 $g_{\mu\nu}$ 描述。由度規可得 Christoffel 符號（聯絡係數）：

$$\Gamma^\mu_{\nu\lambda} = \frac{1}{2} g^{\mu\sigma}\left(\partial_\nu g_{\sigma\lambda} + \partial_\lambda g_{\sigma\nu} - \partial_\sigma g_{\nu\lambda}\right)$$

Riemann 曲率張量收縮得**里奇曲率張量**：

$$R_{\mu\nu} = \partial_\lambda \Gamma^\lambda_{\mu\nu} - \partial_\nu \Gamma^\lambda_{\mu\lambda} + \Gamma^\lambda_{\lambda\sigma}\Gamma^\sigma_{\mu\nu} - \Gamma^\lambda_{\mu\sigma}\Gamma^\sigma_{\lambda\nu}$$

### 3. 場方程（1915 年 11 月 25 日定稿）

$$\boxed{G_{\mu\nu} = R_{\mu\nu} - \frac{1}{2}R g_{\mu\nu} = \frac{8\pi G}{c^4} T_{\mu\nu}}$$

- 左邊 $G_{\mu\nu}$ 是幾何（Einstein 張量），右邊 $T_{\mu\nu}$ 是物質的能量-動量張量。
- 係數 $\frac{8\pi G}{c^4}$ 由牛頓極限（弱場、低速時退化回 $\nabla^2\Phi = 4\pi G\rho$）決定。
- 宇宙學常數項 $\Lambda g_{\mu\nu}$ 是 1917 年後才加入的（後又稱之為他「最大的錯誤」，1998 年暗能量發現後平反）。

**牛頓極限驗證**：設 $g_{00} \approx -(1 + 2\Phi/c^2)$，則場方程的 00 分量給出 $\nabla^2 \Phi = 4\pi G \rho$——正是 Poisson 方程。

### 4. 測地線方程：物質如何運動
自由粒子沿彎曲時空的測地線運動：

$$\boxed{\frac{d^2x^\mu}{d\tau^2} + \Gamma^\mu_{\nu\lambda}\frac{dx^\nu}{d\tau}\frac{dx^\lambda}{d\tau} = 0}$$

其中 $\tau$ 是原時。牛頓的「重力=力」被翻譯成「重力=幾何」：行星不是被拉著走，而是在彎曲時空中走最直的路。

### 5. 水星近日點進動：數值計算
對 Schwarzschild 幾何中的橢圓軌道做微擾，可得每圈進動角：

$$\Delta\varphi = \frac{6\pi G M}{c^2 a(1-e^2)}$$

其中 $a$ 是半長軸，$e$ 是離心率。換算成每世紀角度：

```python
import numpy as np

G = 6.674e-11      # m^3 kg^-1 s^-2
c = 2.998e8        # m/s
M_sun = 1.989e30   # kg

# 水星參數
a = 5.791e10       # 半長軸 (m)
e = 0.2056         # 離心率
T_orbit = 87.969 * 86400      # 公轉週期 (s)
century = 100 * 365.25 * 86400  # 一世紀 (s)

dphi_per_orbit = 6*np.pi*G*M_sun / (c**2 * a * (1 - e**2))
dphi_per_century = dphi_per_orbit * (century / T_orbit)
arcsec = np.degrees(dphi_per_century) * 3600
print(f"GR 預測進動: {arcsec:.2f} 角秒/世紀")   # → 43.03
print(f"觀測殘差:   43.00 角秒/世紀 (Le Verrier)")
```

輸出約 **43.03 角秒/世紀**，與觀測殘差完全吻合。Einstein 1915 年 11 月算出這個結果時，心悸了一整天——他說這讓他「欣喜若狂數天」。

### 6. 座標 vs 幾何：革命的名言
1916 年 Einstein 總結這場革命：

> 「我可以想像，若無這些方程，重力定律將永遠無法獲得純粹幾何的形式。……從前幾何學被視為物理定律不可動搖的前提，如今物理實在的定律必須由幾何本身承擔。」

Wheeler 後來的名言是這場革命的最佳註腳：

> **「物質告訴時空如何彎曲，時空告訴物質如何運動。」**（Spacetime tells matter how to move; matter tells spacetime how to curve.）

## 結案 -- 後果與影響
- **1915.11.25** 場方程定稿；1916 年發表《廣義相對論的基礎》。
- 三大經典驗證：水星進動（已解）、光線偏折（1919）、重力紅移（1959 Pound–Rebka）。
- 衍生出 Schwarzschild 黑洞（1916）、Friedmann 宇宙學（1922）、重力波（1916/1918）、GPS 修正等。
- 數學上推動了微分幾何的復興，Einstein 張量成為微分幾何的標準工具。
