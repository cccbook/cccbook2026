# 1905 - 狹義相對論（特殊相對論的誕生）

## 案件摘要
1905 年 6 月，26 歲的專利局職員 Einstein 發表《論動體的電動力學》(Zur Elektrodynamik bewegter Körper)。
他僅用兩條公設，就重寫了整個力學與電磁學的時間觀與空間觀，宣告「絕對同時」與「以太」死亡。
線索指向一個驚人的結論：時間是相對的，而光速 $c$ 是宇宙的絕對速限。

## 前因 -- 為什麼會有這個案子
- **Maxwell 方程組的矛盾**：Maxwell 方程預言電磁波速度 $c = 1/\sqrt{\mu_0\varepsilon_0} \approx 3\times10^8$ m/s，但沒有說明相對於「誰」。物理學家假設存在傳播介質「以太」。
- **Michelson–Morley 實驗（1887）**：企圖偵測地球相對以太的運動，結果為「零」——光速在各方向都一樣。以太偵測案第一度懸案。
- **Lorentz 與 Poincaré 的補救**：Lorentz 提出變換式與「局部時間」拯救理論，但視之為數學技巧；Poincaré 已喊出「相對性原理」，卻未敢推翻絕對時間。
- **Einstein 的偵探直覺**：與其修補以太，不如把「光速不變」直接升格為公設，並追問一個看似天真的問題——「同時」到底是什麼意思？

## 線索與推理 -- 數學式、程式、理論

### 兩條公設
1. **相對性原理**：所有慣性系中物理定律形式相同。
2. **光速不變原理**：真空中光速 $c$ 對所有慣性觀察者相同，與光源運動無關。

### 同時性的相對性（火車思想實驗）
月台上，火車中點的閃光同時射向車頭與車尾。月台觀察者：兩端同時收到光。
車上觀察者：車尾迎向光、車頭遠離光，故**先收到車尾的光**。
同時收到的事件，對不同觀察者可以「不同時」——絕對同時性被謀殺，兇手正是光速有限且不變。

以 Lorentz 變換量化：事件 $(t, x)$，$t' = \gamma(t - vx/c^2)$。兩個月台同時事件 $\Delta t = 0$、$\Delta x \neq 0$，則
$$\Delta t' = -\gamma \frac{v\,\Delta x}{c^2} \neq 0.$$

### 從公設推導 Lorentz 變換
設 $S'$ 以速度 $v$ 相對 $S$ 運動，線性變換 $x' = A(x - vt)$、$t' = B(t - \alpha x)$。
對光信號 $x = ct$ 要求 $x' = ct'$，對 $x = -ct$ 同理；再要求反變換對稱性（$A B (1-\alpha v) = 1$）。解聯立得：
$$x' = \gamma (x - vt), \qquad t' = \gamma\left(t - \frac{v x}{c^2}\right), \qquad \gamma = \frac{1}{\sqrt{1 - v^2/c^2}}$$
$v \to 0$ 時退化為 Galileo 變換；$v \ge c$ 時 $\gamma$ 發散——光速是絕對速限。

### 時間膨脹與長度收縮
- **時間膨脹**：靜止系中某時鐘的固有時間間隔 $\Delta\tau$，在相對速度 $v$ 的觀察者眼中為
$$\Delta t = \gamma\,\Delta\tau \ge \Delta\tau$$
- **長度收縮**：運動中物體沿運動方向的長度
$$L = \frac{L_0}{\gamma}$$
- **驗證**：$\mu$ 子半衰期約 $2.2\ \mu$s，即使以 $0.999c$ 也只能飛約 660 m，理論上無法從高空（~10 km）到達地面；但時間膨脹使其 $\gamma \approx 22$，飛行距離放大 22 倍——地面確實測到大量 $\mu$ 子。鐵證如山。

### 雙生子悖論
弟弟留在家（慣性系），哥哥搭太空船以 $v = 0.8c$ 去 4 光年外的星球再返回。
- 弟弟計算：哥哥經歷時間 $= 2 \times 4 / 0.8 \times (1/\gamma)$... 直接算：單程弟弟時間 5 年，$\gamma = 5/3$，哥哥單程 3 年，返鄉後哥哥 6 歲差距。
- 表面悖論：「哥哥看弟弟也在動，為何不是弟弟年輕？」
- **結案**：兩者不對稱——哥哥在星球處**掉頭（加速、換慣性系）**，路徑在時空圖上不是慣性直線。固有時間是路徑長（Minkowski 意義下）：
$$\tau = \int \sqrt{1 - v^2/c^2}\; dt$$
慣性直線是「最長」的世界線，哥哥的世界線較短，故哥哥較年輕。悖論不是矛盾，而是對「誰在動」的誤判。

### Python 模擬：時間膨脹數值表（v = 0.1c 至 0.99c）

```python
import numpy as np

c = 299_792_458.0
v = np.arange(0.10, 1.00, 0.01) * c
gamma = 1.0 / np.sqrt(1.0 - (v / c) ** 2)

print(f"{'v/c':>6} {'gamma':>12} {'每秒變慢(s)':>14}")
for b, g in zip(v / c, gamma):
    print(f"{b:6.2f} {g:12.6f} {g - 1:14.6e}")

# mu 子案例：v = 0.999c
g_mu = 1 / np.sqrt(1 - 0.999**2)
tau_mu, h = 2.2e-6, 10_000.0
print(f"\nmu 子 gamma = {g_mu:.2f}, 無膨脹可達 {tau_mu*0.999*c:.0f} m, 膨脹後 {g_mu*tau_mu*0.999*c:.0f} m (高度 {h} m)")
```

輸出節選（$\gamma$ 隨 $v/c$ 上升）：
```
  0.10     1.005038
  0.50     1.154701
  0.90     2.294157
  0.99     7.088812
```

## 結案 -- 後果與影響
- 以太、絕對同時、絕對時間被正式除名；時間與空間成為觀察者相依的量。
- 同年 9 月的後續論文（見「1905-質能等價」）推出 $E=mc^2$。
- 1908 年 Minkowski 將其幾何化（見「1908-Minkowski時空」），Lorentz 變換成為時空旋轉。
- 實際應用：GPS 衛星每天須修正狹義相對論效應約 $-7\ \mu$s（加上廣義相對論 $+45\ \mu$s），否則定位每日漂移數公里。
- 1915 年推廣為廣義相對論；相對論至今通過所有實驗檢驗，本案永久結案。
