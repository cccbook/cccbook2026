# 2019 - EHT 事件視界望遠鏡：M87* 黑洞影像

## 案件摘要
2019 年 4 月 10 日，事件視界望遠鏡（EHT）合作組織公布人類第一張黑洞「照片」：M87 星系中心的超大質量黑洞 M87*。全球 8 台毫米波望遠鏡以 VLBI 甚長基線干涉技術合成一具「地球尺寸」的虛擬望遠鏡，解析出直徑約 $2.6\,r_s$ 的黑洞陰影（shadow）與周圍的發光吸積環。2022 年 EHT 再度公布銀河系中心 Sgr A* 的影像，完成第二件作品。

## 前因 -- 為什麼會有這個案子
- **1915–1916**：Schwarzschild 求出愛因斯坦方程的第一個精確解——黑洞的數學原型。Kerr（1963）給出旋轉黑洞解。
- **1939**：Oppenheimer–Snyder 計算恆星坍縮；1971 Cygnus X-1 被確認為黑洞候選者。但所有證據都是「間接的」——靠伴星軌道與吸積輻射推論，從未直接「看到」黑洞本身。
- **角分辨率的難題**：M87* 距離 55 Mly（1680 萬秒差距）、質量 $6.5\times 10^9\,M_\odot$，其陰影角直徑僅約 42 微角秒（$\mu$as）——相當於從地球看月球上的一枚硬幣。哈伯望遠鏡的分辨率（約 0.05 角秒）差了三個數量級。
- **方案**：VLBI（甚長基線干涉）——分辨率由 $\theta \sim \lambda / B$ 決定（$B$ 為望遠鏡間基線長）。以毫米波（$\lambda = 1.3$ mm）加上地球直徑的基線（$B \approx 10^7$ m）：
  $$\theta \sim \frac{1.3\times 10^{-3}}{10^7} \approx 1.3\times 10^{-10}\ \text{rad} \approx 27\ \mu\text{as}$$
  剛好足以解析 M87* 的陰影。Kip Thorne 等人的理論工作（黑洞陰影的預言）與 Falcke（2000）首次明確提出「可成像」的構想。

## 線索與推理 -- 數學式、程式、理論

### 線索一：事件視界與陰影尺寸
Schwarzschild 半徑：

$$
r_s = \frac{2GM}{c^2}
$$

光子在黑洞附近不再走直線。存在一個**光子球**（photon sphere，$r = 1.5\,r_s$），光線可在此繞行；落向黑洞的光線中，部分被偏折後逃逸、部分被吞噬。觀測者看到的「陰影」邊界由捕獲光線的臨界撞擊參數決定：

$$
b_{\rm crit} = \frac{3\sqrt{3}}{2}\,r_s \approx 2.598\,r_s
$$

即陰影直徑 $\approx 2.6\,r_s$——比事件視界本身大了約 2.6 倍（引力透鏡把視界「放大」了）。以 $M = 6.5\times 10^9 M_\odot$：

$$
r_s = \frac{2 \times 6.674\times 10^{-11} \times 6.5\times 10^9 \times 1.989\times 10^{30}}{(3\times 10^8)^2} \approx 1.92\times 10^{10}\ \text{m} \approx 128\ \text{AU}
$$

陰影直徑約 $2.6 r_s \approx 333$ AU——比整個太陽系（海王星軌道 60 AU）還大五倍以上。EHT 觀測到的環狀結構直徑 42 $\mu$as，反推質量 $M = 6.5^{+0.7}_{-0.6}\times 10^9 M_\odot$，與恆星動力學方法（繞行恆星軌道）獨立測得的 $6.6\times 10^9 M_\odot$ 吻合。

### 線索二：光子環與吸積盤
陰影外圍的亮環來自兩個成分：
1. **光子環**（photon ring）：光線繞行黑洞多圈後逃逸，形成極細的亮環（次級影像的堆疊）。
2. **吸積盤輻射**：M87* 的吸積流在 1.3 mm 波段發出同步輻射（synchrotron），電漿以近相對論速度繞轉。由於黑洞自旋（Kerr 效應）與相對論性 beaming（Doppler boosting），吸積流接近觀測者的一側應更亮——EHT 影像的「新月形」不對稱性證實了這一點：底部較亮，表示電漿順時針旋轉（從我們的視角）。

### 線索三：VLBI 干涉合成
每對望遠鏡記錄的是可見度函數（visibility），即天空亮度分佈 $I(\hat{n})$ 的傅立葉轉換在基線向量 $\mathbf{u}$ 處的取樣：

$$
V(\mathbf{u}) = \int I(\hat{n})\, e^{-2\pi i \mathbf{u}\cdot \hat{n}}\, d\hat{n}
$$

地球自轉使每對望遠鏡的基線在 $(u,v)$ 平面上掃出弧線，8 台望遠鏡（ALMA, APEX, IRAM 30m, IRAM NOEMA, SMT, SPT, JCMT, LMT，加上 SMA/SMA 相關站）在 5 個夜晚累積出數千個取樣點。用反向傅立葉重建（CLEAN + RML 正則化極大似然方法）得影像。分辨率：

$$
\theta_{\rm EHT} \sim \frac{\lambda}{B_{\max}} = \frac{1.3\ \text{mm}}{1.07\times 10^7\ \text{m}} \approx 20\ \mu\text{as}
$$

### 理論：廣義相對論磁流體力學模擬（GRMHD）
EHT 影像不是「直接拍照」——必須用廣義相對論磁流體力學模擬（GRMHD）+ 廣義相對論輻射傳輸（GRRT）生成數十萬張「理論影像庫」，再與觀測的可見度數據比對篩選。模擬中：

- 電漿密度、磁場服從 GRMHD 方程 $\nabla_\mu T^{\mu\nu} = 0$；
- 光線沿零測地線 $k^\mu \nabla_\mu k^\nu = 0$ 傳輸，輻射強度沿測地線積分：
  $$\frac{dI_\nu}{d\lambda} = j_\nu - \alpha_\nu I_\nu$$
- 最後在觀測者屏幕上成像。Kerr 黑洞的自旋參數 $a_\* = Jc/(GM^2)$ 透過陰影形狀與光子環位置被約束在 $0.5 \lesssim a_\* \lesssim 0.98$。

### Python 模擬：黑洞陰影示意圖

```python
import numpy as np
import matplotlib.pyplot as plt

# 幾何模型：陰影 (b_crit = 2.598 rs) + 光子環 + 非對稱吸積輻射
N = 800
x = np.linspace(-3.5, 3.5, N)          # 單位: r_s
X, Y = np.meshgrid(x, -x)              # y 軸向上
R = np.sqrt(X**2 + Y**2)
phi = np.arctan2(Y, X)

b_shadow = 2.598                        # 陰影半徑 (r_s)
img = np.zeros_like(R)

# (1) 陰影：R < b_crit 內為暗區（引力捕獲）
# (2) 光子環：R ≈ b_crit 的細亮環
ring = np.exp(-((R - b_shadow)/0.06)**2)
# (3) 吸積輻射：環外的盤狀輻射，帶都卜勒不對稱（左下較亮）
disk = np.where(R > b_shadow, np.exp(-((R - b_shadow - 0.4)/0.9)**2), 0)
doppler = 1 + 0.5*np.cos(phi + np.pi/4)   # beaming 不對稱

img = 3.0*ring + disk*doppler
img[R < b_shadow] = 0.0                 # 陰影核心全暗

# 加入微小觀測雜訊
rng = np.random.default_rng(1)
img += rng.normal(0, 0.02, img.shape)

fig, ax = plt.subplots(figsize=(6.5, 6))
ax.imshow(img, cmap='inferno', extent=[-3.5, 3.5, -3.5, 3.5])
ax.set_xlabel('$x\\ /\\ r_s$'); ax.set_ylabel('$y\\ /\\ r_s$')
ax.set_title('M87* shadow (schematic): diameter $\\approx 2.6\\,r_s$')
# 標註
ax.axhline(0, color='w', ls=':', lw=0.3, alpha=0.5)
plt.tight_layout(); plt.show()
```

輸出顯示：中央圓形暗區（陰影）、緊貼其外的細亮環（光子環）、以及因都卜勒 beaming 而不對稱的吸積輻射——這正是 EHT 公布的「橙色甜甜圈」的幾何骨架。

## 結案 -- 後果與影響
- **2019 年 4 月 10 日**：EHT 在全球同步記者會公布 M87* 影像，6 篇論文刊於 *ApJL*。影像與 GRMHD 預測吻合，證實：黑洞中心確有一個事件視界尺度的陰影。
- **2022 年 5 月 12 日**：EHT 公布銀河系中心 **Sgr A*** 影像（$M \approx 4.3\times 10^6\,M_\odot$）——質量小 1500 倍、演化時標快 1500 倍（分鐘級 vs 天級），成像難度更高，需結合數萬張模擬影像。
- **深遠影響**：
  - 黑洞由「理論推論」升級為「直接成像」的觀測對象；事件視界物理從數學進入實證。
  - 驗證了強場廣義相對論：陰影尺寸與 Kerr 度規的預測一致（在目前精度下無偏離）。
  - 開啟「黑洞電影」之路：EHT 正以更高頻率（345 GHz）與更多站點（含非洲、南極）追求動態影像——直接拍攝吸積流繞轉的電影。
  - 與 LIGO 的重力波觀測形成互補：一個看「合併瞬間」的恆星級黑洞，一個看「靜態影像」的星系級黑洞。
