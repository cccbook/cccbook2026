# 1963-Kerr 黑洞解

## 案件摘要
1963 年，紐西蘭數學家 Roy Kerr 求出 Einstein 方程描述**旋轉黑洞**的精確解。
恰逢同年類星體被發現（巨大紅移、巨大能量），Kerr 解成為解釋高能天體的關鍵鑰匙，開啟了相對論天體物理的黃金時代。

## 前因 -- 為什麼會有這個案子
- 1916 年 Schwarzschild 求出第一個精確解（靜態、球對稱黑洞），但真實天體都在轉動——太陽、星系無一例外。
- 1918 年 Reissner–Nordström 解（帶電黑洞）問世，但宇宙尺度上電荷會被中和，旋轉才是常態。
- 1939 年 Oppenheimer–Snyder 計算恆星塌縮成黑洞的過程；1960 年代 Quasi-Stellar Object（類星體）的謎團浮現。
- **線索疑點**：旋轉天體塌縮後是什麼？Einstein 方程非線性極強，找到旋轉解被認為幾乎不可能（連 Chandrasekhar 都曾悲觀）。
- 1963 年 3 月，Schmidt 認出 3C 273 的紅移 $z = 0.158$——如此遙遠卻如此明亮，能量機制成謎。

## 線索與推理 -- 數學式、程式、理論

### 1. Kerr 度規概述
Kerr 解在 Boyer–Lindquist 座標下（真空、穩態、軸對稱）：

$$ds^2 = -\left(1 - \frac{2GMr}{\Sigma c^2}\right)c^2dt^2 - \frac{4GMar\sin^2\theta}{\Sigma c}\,dt\,d\phi + \frac{\Sigma}{\Delta}dr^2 + \Sigma\, d\theta^2 + \left(r^2 + a^2 + \frac{2GMa^2 r\sin^2\theta}{\Sigma c^2}\right)\sin^2\theta\, d\phi^2$$

其中：
$$\Sigma = r^2 + a^2\cos^2\theta, \qquad \Delta = r^2 - \frac{2GM}{c^2}r + a^2, \qquad a = \frac{J}{Mc}$$

- $M$：質量，$J$：角動量，$a$：單位質量角動量參數。
- 當 $J \to 0$ 時退回 Schwarzschild 解——Kerr 解是 Schwarzschild 的推廣。
- 交叉項 $dt\,d\phi$ 是「旋轉」的印記：時空本身被拖著轉（參考系拖曳，frame dragging）。

### 2. 兩個視界
令 $\Delta = 0$ 解出視界半徑：

$$r_\pm = \frac{GM}{c^2} \pm \sqrt{\left(\frac{GM}{c^2}\right)^2 - \left(\frac{J}{Mc}\right)^2}$$

- $r_+$：外視界（事件視界），有進無出。
- $r_-$：內視界（Cauchy 視界），數學上存在、物理上不穩定。
- 極限條件 $r_\pm$ 為實數要求 $J \le \frac{GM^2}{c}$：轉得太快的黑洞不存在（裸奇點被 cosmic censorship 排除）。

### 3. 能層（Ergosphere）與 Penrose 過程
在外視界之外、靜態極限面（$r_s(\theta)$）之內的區域稱**能層**：
- 能層內沒有靜止不動的觀察者——時空強迫你跟著轉。
- **Penrose 過程（1969）**：把物體丟進能層並分成兩半，一半落入黑洞、一半飛出——飛出的一半可攜帶**比原物體更多的能量**，能量來自黑洞的轉動。
  黑洞轉動能量上限（不可約質量 $M_{irr}$）：

  $$E_{rot} = (M - M_{irr})c^2, \qquad M_{irr}^2 = \frac{1}{2}\left(M^2 + \sqrt{M^4 - (Jc/G)^2}\right)$$

  最大可萃取約 29% 的質量能量（Schwarzschild 黑洞為 0%）。
- 類星體的巨大光度被認為來自吸積盤＋ Kerr 黑洞的轉動能量萃取（Blandford–Znajek 機制 1977，磁化版 Penrose 過程）。

### 4. 黑洞無毛定理（1960s–70s）
- 推理：任何塌縮天體的詳細信息（化學組成、形狀不規則……）都會以引力波輻射掉，最後只剩三個參數：
  $$\text{質量 } M,\quad \text{電荷 } Q,\quad \text{角動量 } J$$
- 「黑洞無毛（no-hair）」——Israel (1967)、Carter (1971)、Hawking (1972)、Robinson (1975) 逐步證明。
- Kerr–Newman 解（$M, Q, J$ 皆非零）是帶電旋轉的一般解。

### 5. 黑洞熱力學（1970s）
- 1971 年 Wheeler 學生 Bekenstein 提問：黑洞吞掉熵，違反熱力學第二定律？→ 黑洞本身必有熵。
- 1972–74 年 Hawking、Bardeen、Carter 建立黑洞力學四定律，Bekenstein–Hawking 熵：

  $$S_{BH} = \frac{k_B\, A}{4\, l_P^2}, \qquad l_P = \sqrt{\frac{\hbar G}{c^3}} \approx 1.6\times 10^{-35}\,\text{m}$$

  $A$ 為視界面積（Kerr 黑洞 $A = 4\pi(r_+^2 + a^2)$）。熵正比於**面積而非體積**——全息原理的線索。
- 1974 年 Hawking 輻射 $T_H = \frac{\hbar c^3}{8\pi G M k_B}$，熱力學完備。

### 6. Python：Kerr 黑洞視界與能層形狀

```python
import numpy as np
import matplotlib.pyplot as plt

G, c = 1.0, 1.0
M, a = 1.0, 0.8                     # a = J/Mc, 0 <= a <= M

def horizon(a, M, sign):
    return G*M/c**2 + sign*np.sqrt((G*M/c**2)**2 - (a/M*c)**2)

r_out, r_in = horizon(a, M, +1), horizon(a, M, -1)
print(f"外視界 r+ = {r_out:.3f}, 內視界 r- = {r_in:.3f}")

# 能層邊界（赤道面附近的外邊界）: 靜態極限面
theta = np.linspace(0, np.pi, 200)
r_ergo = G*M/c**2 + np.sqrt((G*M/c**2)**2 - a**2*np.cos(theta)**2)

plt.figure(figsize=(6,6))
plt.fill_betweenx(r_ergo*np.sin(theta), r_ergo*np.cos(theta), -r_ergo*np.cos(theta),
                  alpha=0.25, color='orange', label='能層 ergosphere')
plt.plot(r_out*np.sin(theta), r_out*np.cos(theta), 'k-', label='外視界 r+')
plt.plot(r_in*np.sin(theta), r_in*np.cos(theta), 'k--', label='內視界 r-')
plt.title(f'Kerr 黑洞 (M=1, a=0.8): 視界與能層')
plt.xlabel('x'); plt.ylabel('z'); plt.legend(); plt.axis('equal'); plt.grid(alpha=0.3)
plt.show()

# 轉動能量可萃取比例
a_ratio = np.linspace(0, 1, 100)
M_irr = np.sqrt(0.5*(1 + np.sqrt(1 - a_ratio**2)))
plt.figure(figsize=(7,4))
plt.plot(a_ratio, (1 - M_irr)*100)
plt.xlabel('a/M (自旋)'); plt.ylabel('可萃取能量 (%)')
plt.title('Penrose 能量萃取上限 (最高約 29%)')
plt.grid(alpha=0.3); plt.show()
```

自旋 $a/M = 1$ 時最多可萃取約 29% 質量能量——這正是類星體持久亮度的「能量來源判決」。

## 結案 -- 後果與影響
- **結案**：旋轉黑洞的精確解存在且唯一（無毛定理）。Kerr 解是天文學中所有真實黑洞的標準模型。
- 1974 年 Cygnus X-1 確認為黑洞；2019 年 EHT 拍攝 M87 黑洞影像；2022 年拍到銀心 Sgr A*（Kerr 型）。
- 類星體能量之謎結案：Kerr 黑洞＋吸積盤的轉動能量萃取，效率遠超核融合（0.7%）。
- 黑洞熱力學開啟量子重力研究：全息原理、AdS/CFT、資訊悖論至今仍在偵辦中。
- Kerr 2013 年說：「我一生只做對一件事，但那件事很重要。」
