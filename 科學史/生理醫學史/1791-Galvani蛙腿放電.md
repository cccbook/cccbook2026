# 1791 - Galvani 與蛙腿放電（動物電之謎）

## 案件摘要
1791 年，波隆那的解剖學家 Luigi Galvani 發表〈De viribus electricitatis〉：
掛在鐵鉤上的蛙腿，碰到鐵欄杆時**抽搐**——他宣稱發現了「**動物電** (animal electricity)」。
物理學家 Volta 質疑：電來自兩種金屬的接觸，不是蛙腿——這場爭論催生了
**伏打電池（1800）與電生理學**。
**蛙腿只是儀表，爭論才是引擎**——神經是電的導體這件事，從這裡開始。

## 前因 -- 為什麼會有這個案子
- **電的氣氛**：1780 年代，萊頓瓶（電容）與靜電實驗是歐洲沙龍的熱門表演——
  「電能讓死人動起來」的演示到處流傳。**電是當年的AI，蛙腿是當年的機器人。**
- **Galvani 的意外**：他的助手用解剖刀碰到掛在銅鉤（接鐵欄杆）上的蛙腿神經——
  蛙腿抽搐。Galvani 做了幾百次實驗，確認**不含金屬**時（如玻璃壓迫神經）也會抽搐——
  他堅信電來自肌肉本身。
- **Volta 的反駁**：他重複實驗，發現**必須有兩種不同金屬**（銅+鐵/鋅）才會抽搐——
  電流來自金屬接觸電位差，蛙腿只是**靈敏的檢流計**。
  1799 年他造出**伏打電堆**（鋅-銅-鹽水的堆疊）——第一個電池，作為反駁的證據。

## 線索與推理 -- 數學式、程式、理論

### 核心推理：接觸電位差（Volta 的偵破）
兩種金屬接觸時，電子從費米能級高的金屬流向低的，產生接觸電位差：
$$V_{\text{Cu-Zn}} = \phi_{\text{Cu}} - \phi_{\text{Zn}} \approx 0.34 - (-0.76) = 1.10 \text{ V（電化學序列）}.$$
蛙腿的神經-肌肉恰好在這個電路中——1 V 的脈衝足以**引發動作電位**（閾值約 -55 mV 的去極化，
見 `1952-HodgkinHuxley動作電位.md`）。**Volta 是對的：金屬供電。**
**但 Galvani 也是對的：神經本身會放電**——他用不含金屬的實驗（損傷電流, demarcation current）
證明了肌肉損傷面與完好面之間有電位差。**兩人都對了一半，合起來才是真相。**

### 兩棲類實驗的證據鏈
| 實驗 | 結果 | 推理 |
|------|------|------|
| 銅鉤 + 鐵欄杆 | 抽搐 | 有電流通路 |
| 玻璃壓迫神經 | 也抽搐 | 不需要金屬？（Galvani 的證據） |
| 兩種金屬缺一 | 不抽搐 | 電來自金屬接觸（Volta 的反駁） |
| 損傷肌肉的電位差 | 有電流 | **動物電確實存在（兩人都對）** |

### Python：Galvani–Volta 爭論的數值偵查

```python
import numpy as np

# 電化學序列（標準還原電位，V）
E0 = {'Zn': -0.76, 'Fe': -0.44, 'Cu': 0.34, 'Ag': 0.80}
def cell_voltage(m1, m2):
    return E0[m1] - E0[m2]              # 電池電位

for pair in [('Zn','Cu'), ('Fe','Cu'), ('Zn','Fe')]:
    print(f"{pair[0]}-{pair[1]} 電池：{abs(cell_voltage(*pair)):.2f} V")

# 動作電位閾值偵查（見 1952 案）
V_rest, V_thresh = -65.0, -55.0        # 靜息與閾值電位 (mV)
print(f"\n動作電位閾值 = {V_thresh} mV，需去極化 {V_thresh - V_rest} mV")
print(f"1.1 V 的金屬脈衝遠超閾值 → 蛙腿必然抽搐")
```
輸出：
```
Zn-Cu 電池：1.10 V
Fe-Cu 電池：0.78 V
Zn-Fe 電池：0.32 V

動作電位閾值 = -55.0 mV，需去極化 10.0 mV
1.1 V 的金屬脈衝遠超閾值 → 蛙腿必然抽搐
```

## 結案 -- 後果與影響
- **伏打電池（1800）**：Volta 為反駁 Galvani 而發明電池——**持續電流的人類首例**。
  之後的 Oersted（電磁，1820）、Faraday（電磁感應，1831，見電磁學史）
  全部靠電池供電——**一場生物學爭論，點燃了電磁學革命。**
- **電生理學的誕生**：神經是電的導體、肌肉是電的致動器——
  這是 Hodgkin–Huxley（`1952-HodgkinHuxley動作電位.md`）的起點，
  也是現代心電圖（Einthoven, 1903）、腦電圖、除顫器、神經刺激療法的祖先。
- **儀器學的教訓**：Volta 證明「實驗現象可能只是儀器的假象」——
  與「儀器也可能揭示真象」（Galvani 的損傷電流）雙向成立。
  **偵探必須懷疑自己的工具，也必須相信自己的觀察。**
- 歷史花絮：Galvani 的姪子 Aldini 用電刺激死刑犯屍體（1803）震驚倫敦——
  瑪麗·雪萊的《科學怪人》(1818) 的靈感來源。**青蛙的抽搐，寫出了哥德式科幻。**
