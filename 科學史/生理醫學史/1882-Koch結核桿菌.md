# 1882 - Koch 結核桿菌（細菌理論的三條準則）

## 案件摘要
1882 年 3 月，Robert Koch 在柏林生理學會宣布：**發現了結核病的病原菌**——
結核桿菌 (Mycobacterium tuberculosis)。他同時提出 **Koch 法則 (Koch's postulates)**：
$$\text{病原確認的四步驟} = \text{分離} \to \text{培養} \to \text{接種} \to \text{再分離}.$$
這是**細菌理論的完成式**——「某種微生物引起某種疾病」從此成為可驗證的科學準則。
**Pasteur 說微生物是兇手，Koch 造出了抓兇手的程序。**（1905 年諾貝爾生理醫學獎。）

## 前因 -- 為什麼會有這個案子
- **結核的恐怖**：19 世紀的「白色瘟疫」殺死了 1/7 的歐洲人口——
  結核是當年最大的死因，但病因是懸案（有人說遺傳、有人說瘴氣、有人說貧窮）。
- **Pasteur 的半成品**：Pasteur 證明微生物導致疾病（蠶病 1865），但他的方法
  （直接觀察、經驗判斷）**無法確認「哪個微生物對應哪個病」**——
  結核桿菌在病人體內到處都是，**兇手與無辜者混在一起。**
- **Koch 的偵探工具**：他是鄉村醫師出身，自學顯微照相與**細菌培養技術**：
  - **固體培養基**（馬鈴薯片 → 瓊脂平板）：**單菌落 = 純種分離**（液體培養做不到）
  - **細菌染色**（美藍染色）：結核桿菌在組織切片中現形
  - **顯微照相**：證據可以存檔
  **純種分離是偵破的關鍵：把兇手從人群中抓出來單獨審問。**

## 線索與推理 -- 數學式、程式、理論

### 核心推理：Koch 法則（因果確認的程序）
Koch 法則的四步驟——**疾病的微生物病因確認程序**：
1. **分離**：病人體內總能找到該微生物（**流行病學的相關性**）
2. **培養**：微生物能在體外**純種培養**（**把它從宿主分離**）
3. **接種**：純種接種健康動物，**必引發同樣的病**（**因果實驗**）
4. **再分離**：從發病動物**再分離出同一微生物**（**因果閉合**）

$$\text{相關} \to \text{分離} \to \text{誘發} \to \text{再分離} \Longrightarrow \text{因果確認}.$$
**這是科學史上第一套「病因確認的標準程序」**——Semmelweis 的干預、
Snow 的對照、Pasteur 的觀察，全部被制度化。之後的霍亂弧菌（1883）、
白喉桿菌（1884）、鼠疫桿菌（1894）全部按此程序偵破。

### 核心推理二：結核桿菌的偵查
Koch 對結核的偵查：
- **染色**：組織切片用美藍 + 復染——**桿狀微生物現形**
- **培養**：血清凝固培養基上培養出純種
- **接種**：豚鼠接種後引發結核
- **結核菌素**：結核菌的培養濾液（後成為皮膚測試的試劑）

**結核的特殊難題**：結核桿菌生長極慢（培養需 6–8 週）——
**慢是兇手**，Koch 用了數百隻豚鼠、數年的耐心。

### Python：純種分離的機率偵查

```python
import numpy as np

def liquid_pure_rate(n_bacteria, n_species=3, trials=500):
    # 液體培養：所有菌混在一起 → 純種機率 = 樣本只有一種的機率
    rng = np.random.default_rng(0)
    pure = 0
    for _ in range(trials):
        species = rng.integers(0, n_species, size=n_bacteria)
        if len(set(species)) == 1: pure += 1
    return pure / trials * 100

for n in [2, 5, 10]:
    print(f"樣本含 {n} 個菌、3 種：液體培養純種機率 ≈ {liquid_pure_rate(n):.1f}%"
          f"（固體平板 = 100%）")
print("\n結論：固體培養基讓每個菌落單獨生長 → 純種分離從不可能變成必然")
```
輸出：
```
樣本含 2 個菌、3 種：液體培養純種機率 ≈ 35.2%（固體平板 = 100%）
樣本含 5 個菌、3 種：液體培養純種機率 ≈ 0.8%（固體平板 = 100%）
樣本含 10 個菌、3 種：液體培養純種機率 ≈ 0.0%（固體平板 = 100%）

結論：固體培養基讓每個菌落單獨生長 → 純種分離從不可能變成必然
```
**固體培養基的革命**：液體培養的純種機率是 $(1/3)^n \to 0$——
**Koch 的瓊脂平板把「不可能」變成「必然」**（Walter Hesse 的妻子 Fanny 建議用瓊脂——
廚房素材改寫了微生物學）。

## 結案 -- 後果與影響
- **細菌理論的完成**：Koch 法則讓「微生物病因」從理論變成**可驗證的程序**——
  醫學從「猜病因」變成「抓兇手」，**病原學 (etiopathology) 誕生**。
- **傳染病防治的黃金時代**：1882–1900 年間，白喉、鼠疫、霍亂、破傷風等
  幾十種病原菌按 Koch 法則相繼被偵破——**每種病都有了自己的兇手檔案。**
- **疫苗與藥物的鋪路**：純種培養 = 減毒疫苗（結核卡介苗 1921）與
  抗生素篩選（Fleming 的青黴素 1928，見 `1928-Fleming青黴素.md`）的前提——
  **沒有純種培養，沒有抗生素時代的篩選平臺。**
- **Koch 法則的侷限**：無症狀帶原者（傷寒瑪麗）、病毒（無法培養）、
  不可培養的細菌（95% 的環境菌）——法則不是萬能，**但程序的精神永存**：
  相關 → 分離 → 誘發 → 閉合。
- **1905 年諾獎**：Koch 獲諾貝爾生理醫學獎（結核病的研究）。
