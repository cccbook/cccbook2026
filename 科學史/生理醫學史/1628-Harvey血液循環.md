# 1628 - Harvey 血液循環（定量計算推翻一千五百年教條）

## 案件摘要
1628 年，英國醫生 William Harvey 出版《心血運動論》(De Motu Cordis)。
他只用一個簡單的**定量計算**——測量心臟容量與心跳次數，算出心臟每小時泵出的血量
遠超全身血液的總量——就推翻了蓋倫 (Galen) 主導醫學**一千五百年**的「血液潮汐論」。
**這是醫學史上第一個用數學偵破的世紀之謎：血液不是潮汐漲落，而是單向循環。**

## 前因 -- 為什麼會有這個案子
- **蓋倫教條的統治**：公元 2 世紀的蓋倫主張：血液在肝臟製造，像潮汐一樣「漲落」到全身被
  消耗掉，動脈與靜脈是兩套獨立系統。此說被教會加持，1300 年無人敢質疑。**權威是兇手。**
- **蓋倫教條的邏輯漏洞**：蓋倫說血液被「消耗」，但從沒人算過**消耗量是多少**。
  如果心臟泵出的血量遠超全身血量，那血液必然是**循環**的——這個漏洞躺了 1300 年。
- **Harvey 的偵探直覺**：他在帕多瓦大學受教於 Fabricius（靜脈瓣膜的發現者），
  掌握了關鍵線索：**瓣膜只允許單向流動**——潮汐論與瓣膜的觀察直接矛盾。
  Harvey 的名言：「我信賴實驗，不信賴書本。」

## 線索與推理 -- 數學式、程式、理論

### 核心推理：一個除法就能偵破的案子
Harvey 的定量計算（人類史上第一次用數量級推理駁倒權威）：
- 心臟每跳泵出約 **2 英兩（~57 克）** 血（他對垂死動物與病人實測）
- 心跳每分鐘約 **72 次** → 每小時 $72 \times 60 = 4320$ 次
- 每小時泵出量：
$$57 \times 4320 \approx 246{,}000 \text{ 克} \approx 246 \text{ 公斤} \approx \text{體重的 3 倍以上！}$$
- 但人體總血量只有約 **5 公升（5 公斤）**。

**結論只有一種可能**：血液每小時循環全身 50 次——它必然是**循環的**，
且必有一條「看不見的通道」把動脈血送回靜脈。這條通道就是**微血管**，
要等 Malpighi 在 1661 年用顯微鏡才看到——Harvey 用數學預言了它 33 年。

### 配套證據：止血帶實驗
Harvey 用繃帶綁住手臂：
- **鬆綁**（只壓靜脈）：綁帶遠端腫脹——靜脈血回不去
- **綁緊**（動靜脈都壓）：遠端蒼白——動脈血進不來
- 沿靜脈**往心臟方向**推擠可以排空、反向推擠不行——**瓣膜只允許單向流動**

### Python：Harvey 的計算復刻

```python
# Harvey 1628 的定量推理
stroke_volume_ml = 57 * 0.02957 * 1000 / 100 * 1000 / 1000  # 2 英兩 ≈ 59 ml
stroke_volume_ml = 59
heart_rate = 72
total_blood_L = 5.0

per_hour = stroke_volume_ml * heart_rate * 60          # 每小時泵出 ml
circulations = per_hour / (total_blood_L * 1000)       # 每小時循環次數
print(f"每小時泵出 {per_hour/1000:.0f} 公升")
print(f"每小時循環全身 {circulations:.0f} 次")
print(f"每日泵出 {per_hour*24/1000:,.0f} 公升 = 一個小游泳池")
```
輸出：
```
每小時泵出 255 公升
每小時循環全身 51 次
每日泵出 6,117 公升 = 一個小游泳池
```

### Harvey 的證據鏈
| 證據 | 推翻的教條 |
|------|-----------|
| 定量計算：泵出量 >> 全血量 | 血液被「消耗」（根本消耗不完） |
| 瓣膜單向流動 | 血液潮汐漲落（瓣膜不允許回潮） |
| 止血帶實驗 | 動靜脈是兩套獨立系統（實為一體） |
| 預言微血管（1661 年證實） | 血液如何從動脈回到靜脈 |

## 結案 -- 後果與影響
- **定量醫學的誕生**：Harvey 證明「生理學可以用數量級推理偵破」——
  這成為現代生理學的方法論基石：觀察 → 量化 → 推理 → 預言 → 驗證。
- **蓋倫教條崩塌**：醫學從「背誦古書」轉向「實驗解剖」——
  Harvey 被稱為「現代生理學之父」。
- **數學的橋樑**：循環的定量描述後來成為流體力學（見微積分史）的應用對象，
  Poiseuille 定律（1840）把血液動力學徹底數學化。
- **顯微鏡的接力**：Harvey 預言的微血管由 Malpighi（1661）與 Leeuwenhoek 證實，
  顯微鏡成為下一個世紀的偵探工具（見 `1665-Hooke細胞.md`）。
- 歷史花絮：Harvey 出版後病人流失一半——「瘋子 Harvey 說血會轉圈」。
  但 20 年後他的理論成為全歐洲醫學院的標準教材。**真理的接受需要時間。**
