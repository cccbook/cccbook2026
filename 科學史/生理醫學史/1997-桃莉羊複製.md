# 1997 - 桃莉羊複製（分化細胞可以「倒帶」）

## 案件摘要
1997 年 2 月，蘇格蘭 Roslin 研究所的 Ian Wilmut 團隊在《Nature》發表：
**複製羊桃莉 (Dolly)**——第一隻由**成體體細胞**核轉植 (SCNT) 誕生的哺乳動物。
他們把 6 歲母羊的乳腺細胞核，植入去核的卵細胞，成功發育成完整的羊。
**分化的體細胞可以「倒帶」回全能狀態**——細胞命運不是單行道。
**遺傳密碼完全相同、命運卻可以重來——這是發育生物學的最大翻案。**

## 前因 -- 為什麼會有這個案子
- **分化論的教條**：19 世紀以來的主流（Weismann 的學說, 1892）認為：
  細胞分化是**單行道**——體細胞的基因被「不可逆地關閉」，只有生殖細胞（種質）
  帶有完整的遺傳資訊。**分化是兇手：體細胞 = 殘缺的基因組。**
- **兩棲類的殘缺線索**：1962 年，John Gurdon 用非洲爪蟾的腸上皮細胞核轉植，
  得到**正常發育的蝌蚪**——分化可以倒帶在兩棲類成立！
  但哺乳類（胎生、卵極小、易失敗）被認為不可能——**哺乳類是懸案。**
- **Wilmut 的偵探直覺**：Roslin 團隊的目標本是**轉基因家畜**（產藥用蛋白的羊），
  複製是為了穩定轉基因品系。他們的關鍵創新：
  **把供體細胞「餓」到 G0 期**（血清饑餓，讓細胞靜止）——
  使供體細胞核與卵細胞的細胞週期同步，轉植成功率大增。

## 線索與推理 -- 數學式、程式、理論

### 核心推理：細胞命運是表觀遺傳的，不是不可逆的
現代解釋（Waddington 的表觀遺傳景觀, 1942）：
$$\text{全能（受精卵）} \xrightarrow{\text{分化}} \text{多能} \to \text{專能} \to \text{終末細胞}.$$
分化的本質：**基因的表觀遺傳修飾**（DNA 甲基化、組蛋白修飾）——
基因沒有消失，只是被**關閉**。SCNT 的偵破：
**卵細胞的細胞質因子可以擦掉這些修飾，把體細胞核「倒帶」回全能狀態**：
$$\text{體細胞核（已分化）} + \text{去核卵（重編程因子）} \to \text{全能細胞}.$$
這是「**重編程 (reprogramming)**」的偵破——命運是可逆的。
（Gurdon 因此獲 2012 年諾貝爾獎，與 iPSC 的山中伸彌同獲——見結案。）

### 成功率的數學：為什麼這麼低？
桃莉團隊做了 **277 次核轉植**，只有 29 個發育到胚胎移植階段，
**13 隻代孕母羊、1 隻成功**——成功率約 0.4%。
$$P(\text{成功}) = 277 \text{ 次嘗試} \to 1 \text{ 隻桃莉} \approx 0.36\%.$$
失敗主因：表觀遺傳重編程不完整（甲基化擦不乾淨）、印記基因異常、
胎盤發育失敗。**低成功率 = 重編程的不完整性**——這解釋了為什麼桃莉
只活了 6.5 年（同品種羊平均 11–12 歲），且患有關節炎與肺病。

### Python：核轉植成功率的蒙地卡羅偵查

```python
import numpy as np

def scnt_success_rate(n_trials=277, p_success=0.0036, rng=None):
    rng = rng or np.random.default_rng(0)
    outcomes = rng.random(n_trials) < p_success
    return outcomes.sum()

rng = np.random.default_rng(0)
for n in [277, 1000, 10000]:
    successes = scnt_success_rate(n, rng=rng)
    print(f"{n} 次核轉植 → 成功 {successes} 次（成功率 ~0.36%）")
print("\n重編程不完整的原因：表觀遺傳修飾（甲基化）未完全擦除")
```
輸出：
```
277 次核轉植 → 成功 2 次（成功率 ~0.36%）
1000 次核轉植 → 成功 4 次（成功率 ~0.36%）
10000 次核轉植 → 成功 29 次（成功率 ~0.36%）
```

### 從桃莉到 iPSC 的接力
| 年份 | 人物 | 進展 |
|------|------|------|
| 1962 | Gurdon | 爪蟾體細胞核轉植（兩棲類） |
| 1997 | Wilmut 團隊 | 桃莉（哺乳類，SCNT） |
| 2006 | 山中伸彌 | **iPSC**：4 個轉錄因子（Oct4/Sox2/Klf4/c-Myc）直接重編程——**不用卵細胞** |
| 2012 | Gurdon & Yamanaka | 諾貝爾生理醫學獎 |

**山中伸彌的偵探直覺**：與其用卵細胞重編程（稀有、低效、有倫理爭議），
不如**找出卵細胞裡的重編程因子**——24 個候選基因篩到 4 個，皮膚細胞直接變多能幹細胞。
**iPSC = SCNT 的去卵版**——重編程從此成為標準技術。

## 結案 -- 後果與影響
- **分化論死刑**：體細胞核含完整基因組、可以倒帶——
  Weismann 的「種質不可逆」教條崩塌，**細胞命運是表觀遺傳的動態過程**。
- **表觀遺傳學的崛起**：重編程證明命運由甲基化與組蛋白修飾控制——
  表觀遺傳學從邊緣變成顯學（DNA 甲基化、組蛋白密碼、核小體定位）。
- **幹細胞醫學的誕生**：iPSC 讓「病人自己的細胞 → 幹細胞 → 器官修復」成為可能——
  個人化再生醫學、疾病建模（帕金森、心臟病的 iPSC 模型）。
- **倫理的地震**：桃莉引發人類複製的全球恐慌與立法（多國禁止生殖性複製）——
  **技術的偵破先於倫理的共識。**
- **桃莉的壽命懸案**：桃莉只活 6.5 年（端粒較短、表觀年齡較老）——
  重編程不完整的代價。**倒帶不完整 = 提前老化**——這是表觀遺傳時鐘的線索。
