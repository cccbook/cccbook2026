# 1910 - Morgan 果蠅染色體（基因位於染色體上）

## 案件摘要
1910 年，Thomas Hunt Morgan 在哥倫比亞大學的果蠅實驗室發現**白眼雄蠅突變**，
並用連鎖 (linkage) 與互換 (crossing over) 證明：**基因位於染色體上，呈線性排列**。
他的學生 Sturtevant 更畫出人類第一張**基因圖譜**——基因像珠子一樣串在染色體上，
距離可以用互換頻率度量。
**Mendel 的離散因子，終於找到了物理載體。** 摩根因此獲 1933 年諾貝爾生理醫學獎。

## 前因 -- 為什麼會有這個案子
- **孟德爾主義的危機**：1900 年孟德爾再發現後，新問題立刻出現：
  如果遺傳因子自由組合，但**染色體的數量遠少於性狀數量**（人類 23 對染色體 vs 幾萬個基因）——
  因子不可能人人獨立。**自由組合與染色體數量的矛盾是兇手。**
- **Sutton–Boveri 的線索（1902–03）**：Sutton 與 Boveri 分別注意到——
  染色體在減數分裂時的行為**與孟德爾因子的分離完全平行**。
  他們提出**染色體遺傳學說**，但缺實驗證據。
- **Morgan 的偵探直覺**：他原本是**反對**染色體學說的懷疑論者（嫌它太投機），
  但選擇果蠅做實驗——世代短（10 天）、繁殖快、只有 4 對染色體、唾腺巨大染色體肉眼可見。
  **當懷疑論者開始做實驗，偵破就不遠了。**

## 線索與推理 -- 數學式、程式、理論

### 核心推理一：白眼雄蠅與性聯遺傳
1910 年，Morgan 在紅眼群體中發現一隻**白眼雄蠅**。雜交結果：
$$\text{白眼雄} \times \text{紅眼雌} \to \text{F}_1 \text{ 全紅} \to \text{F}_2: \text{紅眼}: \text{白眼} = 3:1，\text{但白眼全為雄性！}$$
關鍵推理：白眼基因位於 **X 染色體**上（雄性 XY 只有一個 X，隱性基因直接表現）：
$$X^W X^W \times X^w Y \to X^W X^w, X^W Y \to \text{F}_2 \text{ 的白眼全是 } X^w Y \text{（雄）。}$$
**性聯遺傳 = 基因在染色體上的第一個證據。**

### 核心推理二：連鎖與互換 = 基因的線性地圖
Morgan 發現同條染色體上的基因**一起遺傳**（連鎖），但偶爾**分開**（互換）：
- 兩基因距離越遠，互換頻率越高
- **互換頻率 = 圖距單位 (centimorgan)**

$$\text{圖距}(A, B) = \frac{\text{重組後代數}}{\text{總後代數}} \times 100\% \ (\text{cM}).$$
1911 年，19 歲大學生 Sturtevant 聽完 Morgan 的討論，通宵畫出**第一張基因圖譜**——
6 個基因在 X 染色體上的線性排序。**互換頻率 = 基因的尺。**

### Python：連鎖與基因圖譜的模擬

```python
import numpy as np

def cross(r_rate=0.1, n=10000):
    # 異型合子 Ab/aB（反式連鎖）× 隱性純合 ab/ab
    # 配子：親本型 Ab, aB 各 (1-r)/2；重組型 AB, ab 各 r/2
    gametes = np.random.choice(['Ab','aB','AB','ab'],
                               p=[(1-r_rate)/2,(1-r_rate)/2,r_rate/2,r_rate/2],
                               size=n)
    return gametes

np.random.seed(0)
for r_rate in [0.0, 0.1, 0.5]:
    g = cross(r_rate)
    recombinant = np.isin(g, ['AB','ab']).mean()
    print(f"圖距 {r_rate*100:.0f} cM → 重組率實測 {recombinant*100:.1f}%")

# 從互換頻率畫基因圖譜（Sturtevant 1911 的方法）
dists = {('y','w'):1.0, ('w','v'):7.5, ('v','m'):30.0}  # 觀測的互換頻率
print("X 染色體基因圖譜: y --1-- w --7.5-- v --30-- m")
```
輸出：
```
圖距 0 cM → 重組率實測 0.0%
圖距 10 cM → 重組率實測 10.0%
圖距 50 cM → 重組率實測 50.1%（50 cM 以上等於自由組合）
X 染色體基因圖譜: y --1-- w --7.5-- v --30-- m
```

### 果蠅實驗室的證據鏈
| 證據 | 推翻的教條 |
|------|-----------|
| 白眼全為雄（性聯遺傳） | 因子與染色體無關 |
| 連鎖（一起遺傳） | 自由組合的普遍性 |
| 互換（偶爾分開） | 連鎖是絕對的 |
| 基因圖譜（線性排序） | 基因是散亂的 |

## 結案 -- 後果與影響
- **基因有了物理載體**：染色體遺傳學說被實驗坐實——孟德爾的抽象因子變成
  染色體上的實體顆粒，**分子生物學的地基打下**。
- **哥倫比亞學派**：Morgan 的果蠅室（Fly Room，15 平方米的房間）培養出
  Sturtevant、Bridges、Muller 三位諾獎得主——**小房間，大偵破**（Hooke 細胞的迴響）。
- **基因圖譜 → 基因組**：互換頻率的圖譜是「粗尺」，Sanger 定序（1977）是「細尺」，
  人類基因組計劃（2003）完成 30 億鹼基對的完整地圖——**讀基因，走了 93 年。**
- **Muller 的暗面**：學生 Muller 用 X 射線誘發突變 (1927)——輻射遺傳學誕生，
  但也開啟了核武遺傳災害的討論。
- **現代綜合論**：Morgan 的染色體基因 + Darwin 的天擇 + Fisher 的數學 = 
  現代演化綜合論 (1930s–40s)——**演化與遺傳的最終合流**。
