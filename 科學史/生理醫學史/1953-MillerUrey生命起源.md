# 1953 - Miller–Urey 生命起源實驗（原始湯的化學偵破）

## 案件摘要
1953 年，芝加哥大學的 23 歲研究生 Stanley Miller 在 Harold Urey 指導下，
做了一個玻璃燒瓶實驗：**甲烷 + 氨 + 氫 + 水蒸氣 + 電火花**（模擬原始地球大氣與閃電）
——**一週後，燒瓶裡出現了胺基酸**（甘胺酸、丙胺酸等）！
**生命的積木可以從無機物 + 能量合成**——生命起源從哲學思辨變成化學實驗。
**這是「自然發生說」的現代重生**（Pasteur 1864 判處死刑的是「現代生物憑空出現」，
Miller 偵破的是「生命積木的化學起源」）——**兩者不矛盾：生命從化學演化而來。**

## 前因 -- 為什麼會有這個案子
- **生命起源的哲學僵局**：自然發生說死後（Pasteur 1864），「生命從何而來」變成懸案——
  有神創論、有外來論（泛種論）、有化學演化論——**沒有任何一個可實驗。**
- **Oparin–Haldane 的假說（1924/1929）**：蘇聯的 Oparin 與英國的 Haldane 獨立提出
  **原始湯假說**：原始地球的大氣是**還原性的**（甲烷、氨、氫、無氧），
  能量（閃電、紫外線）驅動無機物合成有機物——**積木在湯裡累積**。
  但**沒有實驗驗證**——假說躺了 25 年。
- **Urey 的地球化學**：1930 年代的行星科學家 Urey（重水的發現者，1934 諾獎）
  論證了原始大氣的還原性——**1952 年他提出可以實驗檢驗**。
- **Miller 的偵探直覺**：1952 年他向 Urey 提議做這個實驗，Urey 同意但勸他
  「這對博士論文太冒險」——Miller 堅持，**用玻璃器皿 + 真空系統 + 電極**
  建造了原始地球的縮影。**一個研究生的實驗，偵破了人類最大的懸案之一。**

## 線索與推理 -- 數學式、程式、理論

### 核心推理：還原大氣 + 能量 = 有機積木
Miller–Urey 的實驗設計：
$$\text{CH}_4 + \text{NH}_3 + \text{H}_2 + \text{H}_2\text{O（蒸氣）} \xrightarrow{\text{電火花}} \text{胺基酸 + 有機物}.$$
- **閉合玻璃系統**：水加熱蒸發 → 電火花放電（模擬閃電）→ 冷凝回流（模擬降雨）
- **一週後**：褐色的焦油與**胺基酸**（甘胺酸、丙胺酸、天冬胺酸……）

**產量的數量級**：1953 年檢測到 **5 種胺基酸**；2008 年用現代質譜儀重新分析
Miller 的原始樣本——**22 種胺基酸**！**原始湯的產能遠超 1953 年的偵查能力。**

$$\text{反應的能量邏輯}： \text{還原性大氣} + \text{能量} \Rightarrow \text{化學平衡右移（合成有機物）}.$$
**還原性大氣沒有氧**——氧會氧化分解有機物；**沒有氧 = 積木可以累積**——
這是 Urey 的地球化學偵破：原始大氣（氧是 24 億年前光合作用才累積的）。

### 核心推理二：從積木到生命（後續的接力）
Miller 偵破了「積木」，後續偵破了「組裝」：
| 年份 | 偵破 | 內容 |
|------|------|------|
| 1953 | Miller–Urey | 胺基酸的化學合成 |
| 1961 | Oro | **核苷酸鹼基（腺嘌呤）**從 HCN 合成 |
| 1982/1994 | Cairns-Smith | 礦物表面的 RNA 催化 |
| 2009 | Sutherland（英國 MRC） | **核糖核苷酸**（完整）的合成路線——**RNA 世界的化學證據** |
| 2015 | Carell | DNA/RNA 前體的一鍋合成 |

**「RNA 世界」假說**：RNA 既是遺傳物質又是催化劑（核酶, 1982, Cech）——
**生命的第一個分子可能是 RNA**——Miller 的胺基酸 + Sutherland 的核苷酸 = 化學演化的積木齊備。

### 原始湯的積木清單
| 積木 | Miller–Urey 產物 | 生命中的角色 |
|------|-----------------|-------------|
| 胺基酸 | 甘胺酸、丙胺酸等 22 種 | 蛋白質 |
| 糖類 | 甲醛衍生物 | 核糖、代謝 |
| 核鹼基 | 腺嘌呤（HCN 的五聚體） | DNA/RNA |
| 脂肪酸前體 | 鏈狀烴 | 膜 |
| 尿素、羧酸 | 多種 | 代謝中間物 |

## 結案 -- 後果與影響
- **生命起源的實驗化**：Miller–Urey 證明「生命積木可以化學合成」——
  生命起源從哲學變成**實驗科學**（abiogenesis, origin of life）——
  **這是 20 世紀最偉大的偵破之一：人類第一次「在燒瓶裡觸摸到生命的源頭」。**
- **天體生物學的誕生**：原始湯假說 + 行星科學 = 尋找地外生命的科學框架——
  火星、木衛二的探測都以「有沒有有機物與液態水」為目標。
- **RNA 世界的接力**：核酶（1982）、Sutherland 的核苷酸合成（2009）——
  **化學演化的完整路線圖**逐漸成形（積木 → 聚合 → 自我複製 → 膜包覆）。
- **氧的偵破**：原始大氣的還原性（無氧）是積木累積的前提——
  這解釋了為什麼今天的地球**不能**自然發生生命（到處是氧，積木一合成就被氧化）。
- **歷史花絮**：Miller 的原始樣本被保存了 55 年——他 2007 年去世，
  學生 2008 年用現代儀器分析出 22 種胺基酸——**偵探死了，他的證據還在說話。**
