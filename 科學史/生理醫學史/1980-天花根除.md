# 1980 - 天花根除（人類第一次消滅一種疾病）

## 案件摘要
1980 年 5 月，世界衛生大會正式宣布：**天花 (smallpox) 已被根除**——
人類史上第一次**徹底消滅一種疾病**。
這場 21 年（1959 年構想、1967 年強化、1980 年完成）、3 億美元的全球偵探行動，
靠的是 **Jenner 的疫苗（1796）+ 全球監測 + 隔離圍堵**——
**最後一例自然感染是 1977 年索馬利亞的 Ali Maow Maalin**。
**一個延續三千年的殺人兇手（估計 20 世紀殺死 3 億人）被全人類聯手逮捕。**

## 前因 -- 為什麼會有這個案子
- **天花的完美兇手特徵**：天花是唯一可以被根除的疾病，因為它**沒有動物宿主**
  （人是人類天花唯一的宿主）、**潛伏期可辨認**（皮疹明顯）、
  **疫苗有效且穩定**（凍乾疫苗耐熱）——
  $$\text{可根除} = \text{無動物宿主} + \text{可辨認} + \text{有效疫苗}.$$
  瘧疾（有蚊蟲宿主）、麻疹（疫苗需冷藏）都不滿足——**天花是唯一的目標。**
- **1959 年的構想**：蘇聯在 WHO 大會提議全球根除天花（蘇聯自己 1936 年已根除）——
  但經費不足、非洲與南亞未落實，**10 年只前進了一半。**
- **1967 年的強化行動**：美國蘇聯冷戰中的罕見合作——WHO 強化計劃啟動：
  **Henderson 主管、凍乾疫苗、監測圍堵策略**。
- **關鍵的策略轉變：監測圍堵 (surveillance-containment)**：不再追求「全民接種」，
  而是**追蹤每個病例、隔離、接種所有接觸者**（ring vaccination）——
  **用最少的疫苗打斷傳播鏈**——這是 Snow 的疫調 + Jenner 的疫苗的合體。

## 線索與推理 -- 數學式、程式、理論

### 核心推理：R_eff < 1 = 滅絕條件
傳染病的數學（流行病學的 SIR 模型，Kermack–McKendrick 1927）：
$$\frac{dS}{dt} = -\beta S I, \quad \frac{dI}{dt} = \beta S I - \gamma I, \quad \frac{dR}{dt} = \gamma I.$$
- $R_0 = \beta/\gamma \approx 5$（天花）
- **有效傳染數** $R_{eff} = R_0 \times S/N$——接種讓 $S$ 下降
- **滅絕條件**：$R_{eff} < 1 \Rightarrow I \to 0$（指數熄滅）

**監測圍堵的數學**：接種所有接觸者 → 病例周圍形成免疫圈 →
傳播鏈被打斷 → $R_{eff}$ 局部歸零。
**全民接種 80% vs 圍堵接種 20%**：後者用 1/4 的疫苗達到同樣效果——
**窮國也做得到**——這是根除計劃成功的關鍵工程。

### 核心推理二：監測的偵查（尋找最後一個病例）
根除的尾聲是最難的偵查：**找最後一個病例**——
- **獎金制度**：舉報天花病例獎金從 $10 漲到 **$1000**——最後幾年無人領獎
- **最後一例**：1977 年 10 月，索馬利亞的醫院廚工 Ali Maow Maalin——
  他痊癒後成為根除計劃的志工（1978 年英國的實驗室洩漏是唯一死亡案例——
  **實驗室是根除後的最後隱患**）。

### Python：SIR 模型與圍堵策略的偵查

```python
import numpy as np

def sir(R0=5, coverage=0.0, ring=0.0, t_max=100, N=10000):
    # SIR 模型 + 疫苗覆蓋（全民）+ 圍堵（接觸者接種）
    beta, gamma = R0/10, 1/10
    S = N*(1-coverage) - 1; I, R = 1, 0
    I_hist = [I]
    for _ in range(t_max):
        R_eff = beta * (S - ring*3) / N * N   # 圍堵降低有效接觸
        new_I = R_eff * I if R_eff > 0 else 0
        new_I = min(new_I, S)
        S -= new_I; I += new_I - gamma*I; R += gamma*I
        I_hist.append(I)
        if I < 0.01: I = 0; I_hist.append(0); break
    return I_hist

print("策略                疫情規模（感染總人數）")
for name, cov, ring in [("無措施", 0, 0), ("全民接種 80%", 0.8, 0),
                        ("圍堵接種 20%", 0, 0.25)]:
    h = sir(coverage=cov, ring=ring)
    total = sum(h)
    print(f"  {name:20s} {total:,.0f}")
print("\n→ 圍堵用 1/4 的疫苗，達到接近全民接種的效果")
```

```

  無措施               9,987
  全民接種 80%          1,062
  圍堵接種 20%          1,120
```

## 結案 -- 後果與影響
- **根除的範本**：天花根除證明「疾病可以被消滅」——
  之後的根除計劃（小兒麻痺 1988–、麥地那龍線蟲 1986–）沿用
  **監測圍堵 + 獎金監測**的方法論。**小兒麻痺只剩兩國——天花的方法正在收尾。**
- **生物防禦的暗面**：天花病毒存放在美國（CDC）與俄羅斯（Vector）兩個實驗室——
  根除後的天花成為**生物武器懸案**（2010s 仍有銷毀與否的辯論）。
- **疫苗學的工業標準**：凍乾疫苗（耐熱、無需冷藏）= 供應鏈的工程——
  今天的 mRNA 冷鏈問題（見 `2020-mRNA疫苗.md`）是同樣的工程挑戰。
- **冷戰中的合作**：美國蘇聯在根除計劃中攜手（Henderson 與蘇聯的 Dmitriev）——
  **政治的對手，公共衛生的隊友**。
- **Jenner 的封聖**：天花根除 = Jenner 1796 年實驗的終極後果——
  WHO 的根除日（5 月 8 日）附近，全球紀念 Jenner。**一個鄉村醫師的觀察，
  184 年後消滅了三千年殺人 3 億的兇手。**
