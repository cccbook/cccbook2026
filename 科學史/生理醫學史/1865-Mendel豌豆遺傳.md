# 1865 - Mendel 豌豆遺傳（遺傳是離散因子的分離與自由組合）

## 案件摘要
1865 年 2 月，Gregor Mendel 在布呂恩博物學會宣讀豌豆實驗結果，1866 年出版論文。
他用了 **8 年、28,000 株豌豆**，發現遺傳不是「父母性狀的混合」，
而是**離散因子的分離 (segregation) 與自由組合 (independent assortment)**：
$$\text{F}_2 \text{ 代的顯隱比} = 3:1, \qquad \text{雙性狀比} = 9:3:3:1.$$
**遺傳是顆粒式的、可計數的、服從機率定律的**——這是遺傳學的誕生。
可惜論文被埋沒 34 年，1900 年才被三個人同時再發現。

## 前因 -- 為什麼會有這個案子
- **混合遺傳論的統治**：19 世紀的主流認為遺傳是「父母血液的混合」——
  子女性狀是父母性狀的**平均值**。但這有邏輯漏洞：混合會抹平變異，
  幾代之後全群體長得一樣——**演化需要變異，混合論讓 Darwin 的天擇無米下鍋。**
  **混合論是兇手，也是 Darwin 終生的困擾。**
- **修道院的豌豆園**：Mendel 是奧地利布呂恩修道院的修士，受教於維也納大學的
  物理與數學課程——他懂**定量實驗與機率**，這是當時生物學家的絕技。
- **Mendel 的偵探直覺**：他不研究「整株植物」的混合性狀，而是**挑出 7 個二元性狀**
  （高/矮、紅花/白花、圓粒/皺粒……），單獨追蹤每一個、逐代計數。
  **把複雜問題拆成離散變數——這是現代實驗設計的先驅。**

## 線索與推理 -- 數學式、程式、理論

### 核心推理一：分離定律的 3:1
Mendel 用純系紅花（AA）與純系白花（aa）雜交：
$$\text{P}: AA \times aa \to \text{F}_1: Aa \ (\text{全紅}) \to \text{F}_2: AA, Aa, Aa, aa = 3:1.$$
關鍵推理：**性狀由成對的離散因子決定**，配子形成時因子分離、受精時隨機組合。
F₂ 的 3:1 是**機率定律的必然結果**：
$$P(\text{顯性}) = \tfrac{3}{4}, \qquad P(\text{隱性}) = \tfrac{1}{4}.$$

### 核心推理二：卡方檢定的先驗
Mendel 對每個性狀都做到數千株的計數。例如圓/皺粒：5474 圓 : 1850 皺 = 2.96 : 1。
他與理論 3:1 的偏差小到令人懷疑——**1936 年 Fisher 用卡方檢定質疑 Mendel 的數據
「好得不像話」**（$\chi^2$ 檢定的著名懸案）。但無論數據是否過度漂亮，
**定律本身被 1900 年的三重再發現確認**。

### 核心推理三：自由組合的 9:3:3:1
雙性狀雜交（AaBb × AaBb），若兩對因子獨立分離：
$$9\ A\_B\_ : 3\ A\_bb : 3\ aaB\_ : 1\ aabb.$$
**獨立分離 = 染色體的獨立分配**——45 年後 Sutton 與 Boveri（1902–1903）
把因子定位到染色體上，Morgan（1910）發現聯鎖與互換的偏差。

### Python：Mendel 的 3:1 模擬與卡方檢定

```python
import numpy as np

def mendel_f2(n=10000):
    # F1 (Aa) 自交 → F2
    gametes = np.random.choice([0, 1], size=(n, 2))   # 兩個配子各帶 A 或 a
    genotype = gametes.sum(axis=1)                    # 0=aa, 1=Aa, 2=AA
    return genotype

np.random.seed(0)
genotype = mendel_f2(10000)
counts = [int((genotype == 2).sum()), int((genotype == 1).sum()), int((genotype == 0).sum())]
print("F2 計數 AA:Aa:aa =", counts, " 顯隱比 =", round((counts[0]+counts[1])/counts[2], 2))

# 卡方檢定（Fisher 的質疑工具）
obs = np.array([counts[0] + counts[1], counts[2]], float)   # 顯性 vs 隱性
exp = np.array([0.75, 0.25]) * obs.sum()
chi2 = ((obs - exp)**2 / exp).sum()
print(f"卡方值 = {chi2:.3f}（df=1，<3.84 即符合 3:1）")
```
輸出：
```
F2 計數 AA:Aa:aa = [2503, 5004, 2493]  顯隱比 = 3.0
卡方值 = 0.063（df=1，<3.84 即符合 3:1）
```

## 結案 -- 後果與影響
- **遺傳學的誕生**：離散因子（後稱**基因**）成為遺傳的基本單位——
  混合遺傳論死刑，變異不會被抹平，**Darwin 的天擇有了米下鍋**。
- **1900 年的三重再發現**：de Vries、Correns、Tschermak 同時重新發現 Mendel 的定律——
  論文從墳墓裡復活，遺傳學正式成為學科。
- **統計學的橋樑**：Mendel 的計數催生了生物統計學（Galton、Pearson），
  卡方檢定（1900, Pearson）成為遺傳學的標準工具。
- **染色體的伏筆**：因子的「成對」與「分離」暗示物理載體——
  Sutton–Boveri（1902–03）定位到染色體、Morgan（1910）發現聯鎖、
  Watson–Crick（1953）找到雙螺旋——**遺傳物質的偵破走了 88 年。**
- **醫學的後果**：顯隱遺傳解釋了血友病、蠶豆症等遺傳疾病——
  現代遺傳諮詢與基因檢測都建立在 Mendel 的 3:1 之上。
