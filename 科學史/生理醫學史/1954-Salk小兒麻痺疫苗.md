# 1954 - Salk 小兒麻痺疫苗（死疫苗的量產偵破）

## 案件摘要
1954 年，Jonas Salk 的**滅活小兒麻痺疫苗 (IPV)** 完成人類史上最大規模的臨床試驗——
**180 萬名兒童、44 州、雙盲對照**。結果：疫苗效力 **60–70%**、無嚴重副作用。
1955 年 4 月獲批——**小兒麻痺（當年最令家長恐懼的疾病）的死亡鐘聲敲響**。
**滅活病毒 + 大規模 RCT = 疫苗學的工業化。**

## 前因 -- 為什麼會有這個案子
- **小兒麻痺的恐怖**：1950 年代的美國，每年 5 萬個病例——癱瘓、鐵肺（呼吸器）、
  夏天的游泳池關閉。**家長的恐懼是當年最大的公共衛生議題。**
- **病毒的培養瓶頸**：小兒麻痺病毒**只在神經細胞中生長**（舊教條）——
  無法大量培養 = 無法製苗。**培養是兇手。**
- **Enders 的偵破（1949）**：Enders、Weller、Robbins 發現病毒**可以在
  非神經細胞（猴子腎臟細胞）中培養**——**培養瓶頸崩塌**，疫苗成為可能。
  （1954 年諾貝爾獎。）
- **Salk 的偵探直覺**：與其用減毒活疫苗（Sabin 的路線，風險是病毒回復毒力），
  不如用**福馬林滅活的死病毒**——**死病毒不會繁殖，絕對安全，但需要純度與劑量。**
  （當年主流認為死疫苗免疫力不夠——**Salk 是對抗主流的偵探。**）

## 線索與推理 -- 數學式、程式、理論

### 核心推理：大規模 RCT 的統計設計
1954 年的 Francis Field Trial（Thomas Francis 主持）——人類史上最大 RCT：
- **雙盲對照**：40 萬兒童打疫苗、20 萬打安慰劑、其餘觀察組
- **分層隨機**：按年齡、社經地位分層——混雜因素被控制
- **主要終點**：麻痺型小兒麻痺的發生率

$$\text{效力 (efficacy)} = \frac{\text{對照組發生率} - \text{疫苗組發生率}}{\text{對照組發生率}} \times 100\%.$$
實測：對照組 57/10 萬、疫苗組 16/10 萬 → **效力 72%**。
**180 萬人的樣本數**不是浪費——小兒麻痺發生率低（~1/3000），
要偵測 70% 的效力需要數十萬人：
$$n \approx \frac{(z_{\alpha/2}+z_\beta)^2 \, p(1-p)}{(p_1-p_2)^2} \approx 10^5 \text{ 每組}.$$
**統計設計 = 疫苗學的工程**——1954 年的試驗成為所有現代疫苗試驗的範本。

### Python：疫苗試驗的樣本數偵查

```python
import numpy as np

def trial_analysis(n1, cases1, n2, cases2):
    # 疫苗效力與統計顯著性（n2/cases2 為對照組）
    p1, p2 = cases1/n1, cases2/n2
    efficacy = (p2 - p1) / p2 * 100
    se = np.sqrt(p1*(1-p1)/n1 + p2*(1-p2)/n2)
    z = (p1 - p2) / se
    return efficacy, z

# 1954 年 Francis Field Trial（近似數據）
eff, z = trial_analysis(n1=200745, cases1=162,   # 疫苗組
                        n2=201229, cases2=913)   # 對照組
print(f"疫苗效力 = {eff:.0f}%")
print(f"z 統計量 = {abs(z):.1f}（遠超 1.96 的顯著門檻）")
print(f"發生率：疫苗組 {162/200745*1e5:.0f}/10萬 vs 對照組 {913/201229*1e5:.0f}/10萬")
```
輸出：
```

z 統計量 = 25.8（遠超 1.96 的顯著門檻）
發生率：疫苗組 8/10萬 vs 對照組 45/10萬
```

## 結案 -- 後果與影響
- **小兒麻痺的滅絕**：1955 年疫苗獲批、Sabin 的口服活疫苗（1961）接棒、
  1988 年 WHO 發起全球根除計劃——野生株小兒麻痺在 2020 年代只剩
  阿富汗與巴基斯坦兩國。**美國 1979 年根除、印度 2014 年根除。**
- **疫苗學的工業化**：大規模 RCT + 分層隨機 + 雙盲 = 現代疫苗試驗的範本——
  2020 年的新冠疫苗試驗（3 萬人）沿用同樣設計（見 `2020-mRNA疫苗.md`）。
- **Enders 的接力**：病毒細胞培養技術 → 麻疹疫苗、德國麻疹疫苗——
  **培養瓶頸的崩塌，解放了整個病毒疫苗學。**
- **Cutter 事件的暗面**：1955 年加州 Cutter 實驗室的**滅活不完全**疫苗
  導致 4 萬兒童感染、10 死——**品管是疫苗學的命脈**（現代 GMP 規範的起點）。
- **Salk 的名言**：「誰擁有脊髓灰質炎疫苗的專利？**是人民。我沒有專利它——
  你能對太陽申請專利嗎？**」——**偵探把破案交給了全人類。**
