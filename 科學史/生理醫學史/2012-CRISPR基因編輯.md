# 2012 - CRISPR 基因編輯（生命可以「編輯」）

## 案件摘要
2012 年，Jennifer Doudna（UC Berkeley）與 Emmanuelle Charpentier（Umeå）
在《Science》發表：**CRISPR-Cas9** 可以在試管中**精準剪輯任意 DNA 序列**——
只需一段 20 bp 的嚮導 RNA (sgRNA) 指認目標，Cas9 蛋白質就會在那裡剪一刀。
**細菌的免疫系統被改造成生命的編輯器**——讀寫生命的最後一塊拼圖就位。
（2020 年諾貝爾化學獎。）

## 前因 -- 為什麼會有這個案子
- **基因編輯的老困境**：HGP（2003）讓序列可讀，但「寫入」仍是懸案——
  舊方法（同源重組、ZFN、TALEN）要**為每個目標重新設計蛋白質**，
  費時數月、成本數千美元。**蛋白質設計是兇手。**
- **細菌免疫系統的線索**：1987 年，日本學者在大腸桿菌基因組中發現**奇怪的重複序列**
  （clustered regularly interspaced short palindromic repeats）——用途不明。
  2005–2007 年偵破：這是細菌的**後天免疫**——重複序列之間夾著**病毒的 DNA 殘片**，
  是細菌的「通緝令資料庫」。
- **Doudna 的偵探直覺**：2005 年她在 Berkeley 聽到相關報告，決定研究 CRISPR；
  2011 年與 Charpentier 合作——Charpentier 發現關鍵小 RNA **tracrRNA**。
  兩人解出 Cas9 的結構與機制，並證明 tracrRNA + crRNA 可以**合併成一段 sgRNA**——
  **編輯器從「要設計蛋白質」變成「只需寫 20 個字母的 RNA」。**

## 線索與推理 -- 數學式、程式、理論

### 核心推理一：嚮導 RNA = 可程式化的剪刀
CRISPR-Cas9 的機制：
$$\text{sgRNA (20 bp)} + \text{Cas9} \to \text{掃描基因組} \to \text{PAM 旁剪斷 DNA}.$$
- **sgRNA**：與目標序列互補的 20 bp——**只需改這段序列，就能指認任何基因**
- **PAM**（5'-NGG-3'）：Cas9 的「門禁碼」，目標旁必須有此三字母
- **剪斷**：Cas9 的 HNH 與 RuvC 兩個結構域，分別剪兩股 → **雙股斷裂 (DSB)**

**可程式化性的數學**：目標序列 $20$ bp → 可能的目標數 $4^{20} \approx 10^{12}$——
**理論上任何基因都能被指認**（限制於 PAM 的存在）。
這就是 CRISPR 的革命性：**剪刀（Cas9）不變，通緝令（sgRNA）隨寫隨用。**

### 核心推理二：DSB 的修復 = 寫入的入口
剪斷之後，細胞自己修復雙股斷裂：
- **NHEJ**（非同源末端接合）：直接黏回——**隨機突變**（基因敲除）
- **HDR**（同源重組）：用模板修復——**精準寫入**（基因替換）

$$\text{剪斷 (sgRNA + Cas9)} + \text{修復 (NHEJ/HDR)} = \text{敲除或替換}.$$
**CRISPR 只負責剪，寫入靠細胞自己的修復機制**——這是基因編輯的完整公式。

### Python：CRISPR 標靶與脫靶率的偵查

```python
import numpy as np

# 可程式化性的數學：20 bp 嚮導 RNA 的目標空間
n_targets = 4 ** 20                                # 理論上可指認的目標數
pam_freq = 1 / 16                                  # PAM (5'-NGG-3') 的出現頻率
print(f"20 bp sgRNA 的目標空間 = {n_targets:.1e}（理論上任何基因都可指認）")
print(f"PAM (NGG) 每 {1/pam_freq:.0f} bp 出現一次——30 億基因組中有 ~2 億個剪點")

# 脫靶偵查：錯配容忍度 vs 潛在標靶數（組合數學）
from math import comb
def potential_off_targets(n_genome=3e9, L=20):
    for max_mm in [0, 3, 6]:
        # 隨機序列下，與 20bp 目標相差 ≤ max_mm 的機率
        p_mm = sum(comb(L, k) * 3**k for k in range(max_mm+1)) / 4**L
        n = n_genome * p_mm
        print(f"容忍 ≤{max_mm} 錯配 → 30 億基因組中潛在標靶 ≈ {n:.1e} 個")

potential_off_targets()
```
輸出：
```
20 bp sgRNA 的目標空間 = 1.1e+12（理論上任何基因都可指認）
PAM (NGG) 每 16 bp 出現一次——30 億基因組中有 ~2 億個剪點
容忍 ≤0 錯配 → 30 億基因組中潛在標靶 ≈ 2.7e-03 個
容忍 ≤3 錯配 → 30 億基因組中潛在標靶 ≈ 8.9e+01 個
容忍 ≤6 錯配 → 30 億基因組中潛在標靶 ≈ 8.9e+04 個
```
**脫靶 (off-target) 的偵查意義**：錯配容忍度從 0 放寬到 6，潛在標靶從千分之一個
跳到近 9 萬個——**嚮導 RNA 的專一性設計是脫靶率的關鍵**
（高保真 Cas9 變體 2018 年問世，見結案）。
**脫靶 (off-target) 的偵查意義**：$10^{12}$ 個潛在目標中，相近序列可能被誤剪——
20 bp 的設計 + 高保真 Cas9 變體（2018, eSpCas9/SpCas9-HF1）是脫靶率的解藥。

## 結案 -- 後果與影響
- **生命的編輯器**：CRISPR 把基因編輯的成本從數千美元降到**幾十美元**、
  時間從數月降到**數週**——**寫基因從特技變成常規工具。**
- **首個 CRISPR 藥物**：2023 年 Casgevy 獲批治療鐮刀型貧血與乙型地中海貧血——
  **基因疾病從不治變成可治**，這是 Mendel（1865）的遺傳因子的最終翻案。
- **倫理的地震**：2018 年賀建奎的「基因編輯嬰兒」事件震驚全球——
  生殖系編輯的倫理紅線成為國際共識（**技術的偵破再次先於倫理的共識**，桃莉的迴響）。
- **農業與生態**：抗病小麥、基因驅動（gene drive）消滅瘧蚊——
  **天擇（1859）可以被人工設計的選壓改寫。**
- **讀寫生命的閉環**：Hooke 看到細胞（1665）→ Mendel 讀出定律（1865）→
  Watson–Crick 讀出格式（1953）→ Sanger 讀出序列（1977）→ HGP 讀完說明書（2003）→
  **CRISPR 寫入生命（2012）**——觀察、量化、讀、寫，350 年一以貫之。
