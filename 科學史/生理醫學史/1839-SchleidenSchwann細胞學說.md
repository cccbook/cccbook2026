# 1839 - Schleiden 與 Schwann 細胞學說（一切生物皆由細胞構成）

## 案件摘要
1839 年，Theodor Schwann 出版《顯微鏡研究》(Mikroskopische Untersuchungen)，
與植物學家 Matthias Schleiden（1838 年主張植物皆由細胞構成）共同提出**細胞學說**：
$$\text{一切生物（動物、植物）} = \text{細胞的集合}.$$
這是生物學史上第一個**統一理論**——動物與植物從此有了共同的結構單位。
**Hooke 1665 年看到的「小房間」，174 年後被證明是所有生命的通用積木。**

## 前因 -- 為什麼會有這個案子
- **動植物的割裂**：19 世紀初的博物學把動物與植物當成兩個王國，各自的結構理論互不相通。
  植物有細胞壁一看就懂；動物組織（肌肉、神經）看似無定形——**割裂是兇手。**
- **活力論的統治**：當時主流認為生物體有神祕的「活力 (vital force)」驅動，
  有機物不可能用物理化學解釋——「生命」本身就是懸案。
- **Schleiden 的線索**：1838 年他在顯微鏡下研究植物的胚珠，發現**細胞核 (nucleus)**
  是細胞形成的中樞（Brown 1831 年發現細胞核）。他主張：植物體 = 細胞的集合。
- **Schwann 的偵探直覺**：他研究動物的脊索與軟骨，發現**動物細胞也有細胞核**——
  與 Schleiden 的植物細胞同構。他大膽推論：**動物與植物共用同一套結構單位。**

## 線索與推理 -- 數學式、程式、理論

### 核心推理：同構推理（從兩個王國到一個理論）
Schwann 的推理只有兩步：
1. **植物**：Schleiden 證明植物體由細胞構成，細胞核是形成中樞。
2. **動物**：Schwann 在脊索、軟骨、肌肉、神經中都找到**同樣的細胞核結構**。

$$\text{植物細胞} \cong \text{動物細胞} \Longrightarrow \text{一切生物} = \text{細胞的集合}.$$
這是**同構推理**——兩個表面不同的王國，在顯微鏡下呈現同一種結構。
**統一理論的偵破，往往只需找到那個「共同積木」。**

### 細胞學說的三條原理
| 原理 | 內容 | 提出者 |
|------|------|--------|
| 1. 結構原理 | 一切生物皆由細胞構成 | Schleiden (1838) + Schwann (1839) |
| 2. 功能原理 | 細胞是生命的基本功能單位 | Schwann (1839) |
| 3. 來源原理 | 細胞只能來自既有細胞 (Omnis cellula e cellula) | Virchow (1855) |

**第三條的偵破意義最大**：Virchow 1855 年補上「細胞只能來自細胞」，
正式宣告**自然發生說 (spontaneous generation) 死刑**——生命不會從無生命物質憑空冒出。
（此案最終由 Pasteur 1864 年的天鵝頸實驗徹底偵破。）

### Python：細胞生長的指數偵查

```python
# 細胞分裂：Omnis cellula e cellula 的數學後果
import numpy as np

def cell_growth(n0, dt, t_max, t_double=20):
    # 每 20 分鐘分裂一次（大腸桿菌）的指數成長
    t = np.arange(0, t_max + 1, dt)
    N = n0 * 2 ** (t / t_double)
    return t, N

t, N = cell_growth(n0=1, dt=1, t_max=480, t_double=20)   # 8 小時
print(f"1 個細胞，8 小時後 = {N[-1]:.2e} 個")
print(f"24 小時後 = {1 * 2**(24*60/20):.2e} 個（幸好營養會耗盡）")
# 邏輯成長：營養耗盡的修正（Verhulst 1838，同年！）
def logistic(N0, K, r, t_max):
    t = np.arange(0, t_max+1)
    N = [N0]
    for _ in t[1:]:
        N.append(N[-1] + r*N[-1]*(1 - N[-1]/K))
    return np.array(N)
N = logistic(N0=1000, K=1e9, r=0.05, t_max=300)
print(f"邏輯成長 300 期後 = {N[-1]:.2e}（逼近環境上限 K=10^9）")
```
輸出：
```
1 個細胞，8 小時後 = 1.68e+07 個
24 小時後 = 4.72e+21 個（幸好營養會耗盡）
邏輯成長 300 期後 = 7.07e+08（逼近環境上限 K=10^9）
```

### 同構推理的偵探史

## 結案 -- 後果與影響
- **生物學的統一**：細胞學說讓動物學、植物學、組織學、病理學有了共同語言——
  生物學從「收集標本的博物學」變成「有統一理論的科學」。
- **病理學的革命**：Virchow 1855 年把細胞學說引入醫學：**疾病 = 細胞的病變**——
  現代病理學誕生（腫瘤就是失控增殖的細胞）。
- **活力論退潮**：細胞的結構與分裂是可觀察的物理過程——「活力」從解釋淪為占位符，
  最終被生物化學（酵素、DNA）徹底取代。
- **演化的伏筆**：細胞 = 通用積木，意味著所有生命有**共同祖先**——
  20 年後 Darwin 的演化論（`1859-Darwin物種起源.md`）補上了這條線索的時間維度。
- **方法論的伏筆**：Schwann 用同構推理統一兩個王國——這是 1953 年雙螺旋
  （`1953-WatsonCrick-DNA雙螺旋.md`）統一所有遺傳現象的方法論預演。
