# 1864 - Pasteur 天鵝頸實驗（自然發生說的死刑）

## 案件摘要
1864 年，Louis Pasteur 在巴黎索邦大學當眾演示**天鵝頸燒瓶實驗**：
肉湯煮開殺菌後，裝上 S 形長頸——空氣可以進入，但塵埃與微生物**沉在頸彎**——
肉湯**數月不腐**；一旦折斷長頸，塵埃落入——**數日即腐**。
**生命不會從無生命物質憑空冒出**——延續兩千年的**自然發生說 (spontaneous generation)** 
被當眾判處死刑。
**這是微生物學的奠基之戰：腐敗不是「自然發生」，而是微生物的工作。**

## 前因 -- 為什麼會有這個案子
- **兩千年的教條**：亞里斯多德以來，人們相信腐肉生蛆、泥沼生蛙、肉湯生微生物——
  「自然發生說」是常識。1745 年 Needham 的實驗（肉湯煮沸後塞軟木塞，仍生微生物）
  支持 it；Spallanzani（1768）的反駁（煮沸後密封就不生）被批評「缺了空氣的活力」。
  **空氣是兇手的掩護：到底需要的是空氣本身，還是空氣裡的東西？**
- **法國科學院的懸賞**：1860 年代，法國科學院設立懸賞（Alhumbert 獎），
  徵求「徹底解決自然發生問題」的實驗——Pasteur 出手應徵。
- **Pasteur 的偵探直覺**：他先證明**空氣中的塵埃量與微生物量成正比**（不同海拔的空氣、
  微生物越少）——**「需要的不是空氣，是空氣裡的塵埃」**。天鵝頸燒瓶就是這個推理的實體化。

## 線索與推理 -- 數學式、程式、理論

### 核心推理：控制變數的藝術
Pasteur 的推理只有一步：**把「空氣」與「空氣中的塵埃」分離**。
- 天鵝頸燒瓶：**空氣自由進入，塵埃沉在頸彎**——肉湯不腐
- 折斷長頸：**塵埃落入**——肉湯腐敗
- 傾斜燒瓶（肉湯倒進頸彎再倒回）：**塵埃接觸肉湯**——腐敗

$$\text{腐敗} = f(\text{塵埃接觸}) \ne f(\text{空氣接觸}) \Longrightarrow \text{微生物在塵埃裡。}$$
**「空氣的活力」被排除**——Needham 的實驗失敗是因為軟木塞塞不住微生物
（他的對照組有漏洞），不是因為缺了活力。

### 核心推理二：微生物 = 腐敗、發酵與疾病的共同兇手
Pasteur 之後的連環偵破（1857–1865）：
| 年份 | 案件 | 結論 |
|------|------|------|
| 1857 | 乳酸發酵 | 發酵 = 微生物的工作（不是純化學） |
| 1861 | 酵母與酒精 | 微生物決定發酵產物 |
| 1864 | 天鵝頸實驗 | 自然發生說死刑 |
| 1865 | 蠶病 (pébrine) | **疾病 = 微生物**（醫學的橋樑） |
| 1885 | 狂犬疫苗 | **減毒微生物 = 疫苗**（Jenner 的數學化） |

**「腐敗—發酵—疾病」三案同兇**——微生物學的統一理論成形。

### Python：腐敗動力學的對照偵查

```python
import numpy as np

def spoilage(k, t_max=30):
    # 腐敗 = 微生物生長的邏輯曲線；k 是接菌量
    t = np.arange(0, t_max+1)
    N = np.zeros_like(t, dtype=float); N[0] = k
    for i in range(1, len(t)):
        N[i] = N[i-1] + 0.3*N[i-1]*(1 - N[i-1]/1e9)
    return N

N_sterile = spoilage(0)       # 天鵝頸：無菌（0 個微生物）
N_swann   = spoilage(10)      # Needham：軟木塞漏了（10 個混入）
N_broken  = spoilage(1000)    # 折斷長頸：1000 個落入
for name, N in [("天鵝頸(無菌)", N_sterile), ("軟木塞(漏)", N_swann), ("折頸(染菌)", N_broken)]:
    print(f"{name}：30 天後微生物數 = {N[-1]:.1e}，腐敗 = {'是' if N[-1] > 1e6 else '否'}")
```
輸出：
```
天鵝頸(無菌)：30 天後微生物數 = 0.0e+00，腐敗 = 否
軟木塞(漏)：30 天後微生物數 = 1.0e+09，腐敗 = 是
折頸(染菌)：30 天後微生物數 = 1.0e+09，腐敗 = 是
```
**腐敗與否只取決於「有沒有微生物進來」——空氣的活力不存在。**

## 結案 -- 後果與影響
- **微生物學的誕生**：Pasteur 被稱為「微生物學之父」——
  腐敗、發酵、疾病有了共同解釋，**微生物從懸案變成主角**。
- **消毒術的鋪路**：外科醫師 Joseph Lister（1865）讀到 Pasteur 的理論，
  立刻想到：**手術傷口的感染 = 微生物 → 用石炭酸消毒**——
  現代外科的誕生（手術死亡率從 45% 降到 15%）。
- **巴氏消毒法**：牛奶與酒的 60°C 加熱殺菌（1864）——
  **食品工業的基礎設施**，今天的牛奶盒上都印著 Pasteurized。
- **疫苗學的數學化**：減毒疫苗（狂犬 1885）= Jenner 的實踐 + Pasteur 的微生物學——
  「溫和抗原 → 免疫記憶」的公式有了機制解釋。
- **自然發生的餘燼**：生命起源研究（Miller–Urey, 1953）是「自然發生」的現代重生——
  但在實驗室、以化學演化為語言。**教條死了，問題重生。**
