# 程式語言的歷史年表（科學史）

> 程式語言是人類對機器下達指令的語言。從 1843 年 Ada Lovelace 為分析機寫下第一個程式，到 1950s FORTRAN/LISP 誕生、編譯器與解譯器技術成熟，再到 Python/JavaScript 與 AI 時代，程式語言史就是一部「如何讓人類思維與機器執行對接」的演化史。
>
> 本書以「推理探案」的方式，為每個歷史事件寫一篇 wiki，包含前因後果、理論與程式。每篇檔名以年份開頭。

## 寫作方式說明

每篇 wiki 採「推理探案」結構：

1. **案發現場（前因）**：當時的未解之謎是什麼？誰遇到的？為何重要？
2. **偵查過程（推理）**：設計者如何思考？關鍵靈感為何？核心技術（文法、編譯器、VM、型別系統）如何推導。
3. **結案報告（後果）**：謎題如何解？留下什麼遺產？影響了哪些後續語言？
4. **證據與工具**：語言範例程式、編譯/解譯原理示意，以及 Python 模擬程式（如迷你解譯器）。
