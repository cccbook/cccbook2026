# 1935 — EPR 悖論

## 案件摘要
1935 年 5 月，Einstein、Podolsky、Rosen 在 *Physical Review* 發表 "Can Quantum-Mechanical Description of Physical Reality Be Considered Complete?"，指控量子力學「不完備」：它允許「鬼魅般的超距作用」且無法同時預言兩個共軛量的值。同年 Schrödinger 為本案的核心現象命名——**entanglement（糾纏）**。這樁「懸案」直到 1964 年 Bell 提出可實驗檢驗的不等式才算真正開審。

## 前因 -- 為什麼會有這個案子
- 1927 年 Solvay 會議起，Einstein 與 Bohr 就量子力學的完備性反覆交鋒（光子箱、雙縫等思想實驗），Einstein 屢屢落敗。
- 1935 年 Einstein 轉換策略：不再攻擊測不準原理本身，而是證明「波函數不是物理實在的完整描述」——若量子力學對「實在」的描述完整，就必然導出荒謬結論。
- von Neumann 1932 年的「隱變數不可行」證明讓「補充隱變數」的路線看似已被封死，EPR 因此選擇「不完備論證」而非「隱變數方案」。

## 線索與推理 -- 數學式、程式、理論

### 1. 案發現場：糾纏對
考慮兩粒子自旋單態（EPR 原文用連續位置/動量，現代通行版本為 Bohm 的自旋形式）：

$$|\psi\rangle = \frac{1}{\sqrt{2}}\big(|01\rangle - |10\rangle\big)$$

其中 $|0\rangle, |1\rangle$ 為 $\sigma_z$ 的本徵態。此態的關鍵性質：**無法寫成兩個單粒子態的乘積**。

$$|\psi\rangle \neq |\phi_A\rangle \otimes |\phi_B\rangle \quad \forall\, |\phi_A\rangle, |\phi_B\rangle$$

### 2. 糾纏的數學：約化密度矩陣
對子系統 B 取偏跡：

$$\rho_B = \mathrm{Tr}_A\big(|\psi\rangle\langle\psi|\big) = \frac{1}{2}\big(|0\rangle\langle 0| + |1\rangle\langle 1|\big)$$

$\rho_B = I/2$ 是**最大混合態**：單獨看 B 完全沒有確定狀態，但整體 $(A,B)$ 卻是純態——這就是糾纏的數學特徵。糾纏熵（對純態）：

$$S(\rho_B) = -\mathrm{Tr}(\rho_B \ln \rho_B) = \ln 2$$

### 3. EPR 論證的兩條準則
- **實在性準則**：若能「無干擾地確定預言」某物理量，則存在對應的物理實在元素。
- **局域性準則**：若兩系統無交互作用，對其一的測量不能改變另一的實在狀態（「no spooky action at a distance」）。

推理步驟：
1. A、B 相距遙遠，總態為 $|\psi\rangle$。
2. 在 A 處測 $\sigma_z$ 得 $|0\rangle$ ⟹ 立即知道 B 為 $|1\rangle$（無干擾、確定預言）⟹ B 的 $\sigma_z$ 是「實在」。
3. 在 A 處改測 $\sigma_x$ ⟹ B 立即處於 $\sigma_x$ 本徵態 ⟹ B 的 $\sigma_x$ 也是「實在」。
4. 但 $[\sigma_x, \sigma_z] \neq 0$，量子力學說兩者不能同時有值 ⟹ **量子力學不完備**，必有更深層的描述（隱變數）。

### 4. 鬼魅般的超距作用
步驟 2–3 中，A 處的測量選擇「瞬間」決定了 B 處的實在性——但 A、B 之間沒有任何訊號傳遞。Einstein 稱之為 *spukhafte Fernwirkung*（spooky action at a distance）。若堅持局域性，唯一出路是：B 的結果早已由局域隱變數 $\lambda$ 決定，量子力學只是統計平均。

### 5. Schrödinger 的命名與回應
Schrödinger 在 1935 年（應 EPR 邀請評論的 *Proc. Camb. Phil. Soc.* 論文與三篇德文文章）首次使用 **"entanglement"（Verschränkung）**：

> "When two systems ... enter into temporary physical interaction ... and after a time of mutual influence, they separate again, then they can no longer be described in the old way, namely, endow each of them with a representative of its own. I would rather call that not one but rather *the* characteristic trait of quantum mechanics."

他也同時提出著名的貓思想實驗（見另一篇）作為宏觀糾纏的展示。

### 6. Bohr 的回應
Bohr 五週後在 *Physical Review* 以同標題回應：EPR 的「無干擾」預設不成立——**測量儀器與被測系統構成不可分割的整體實驗安排**（contextuality）。你選擇測 A 的 $\sigma_z$ 或 $\sigma_x$，就改變了整個實驗佈置，「實在」的定義必須相對於佈置而言。Bohr 不否認數學，而是否認 EPR 的實在性準則適用於量子世界。Einstein 對此回應不以為然，認為是「溫柔的夢囈」。

### 7. 程式碼範例：驗證單態的關聯性
```python
import numpy as np

# 單態 |psi> = (|01> - |10>)/sqrt(2)
psi = np.zeros(4, dtype=complex)
psi[1] = 1/np.sqrt(2); psi[2] = -1/np.sqrt(2)
rho = np.outer(psi, psi.conj())

sx = np.array([[0, 1], [1, 0]], dtype=complex)
sz = np.array([[1, 0], [0, -1]], dtype=complex)
I2 = np.eye(2, dtype=complex)

def exp2(opA, opB):
    op = np.kron(opA, opB)
    return np.real(np.trace(rho @ op))

print("Tr_A(rho) = I/2 ?",
      np.allclose(np.trace(rho.reshape(2,2,2,2).transpose(1,3,0,2).reshape(2,2)), I2/2))
print("<sz_A sz_B> =", exp2(sz, sz))   # -1 : 完全反關聯
print("<sx_A sx_B> =", exp2(sx, sx))  # -1 : 任意方向都反關聯
print("<sz_A> =", exp2(sz, I2))       # 0  : 單獨看無確定值
```

## 結案 -- 後果與影響
- **表面結案**（1935）：Bohr 以 contextuality 回應，物理社群多數接受「哥本哈根詮釋完勝」，EPR 被視為哲學爭論而冷凍近三十年。
- **重審**（1964）：John Bell 發現 EPR 的局域隱變數方案會導出可檢驗的**Bell 不等式**：

$$|E(a,b) - E(a,b')| \leq 1 + E(a,b') \quad \text{（CHSH 形式：} |S| \leq 2\text{，量子力學預測 } 2\sqrt{2}\text{)}$$

- **實驗判決**（1972–2022）：Freedman–Clauser (1972)、Aspect (1982)、2015 年 loophole-free 實驗、2022 年 Nobel 物理獎（Aspect、Clauser、Zeilinger）——**量子力學獲勝，局域實在論出局**。
- **深遠影響**：糾纏從「悖論」變成「資源」——量子密碼（E91 協議）、量子隱形傳態（1997）、量子計算的加速（superdense coding、測量基礎）皆以 $|\psi\rangle = \frac{1}{\sqrt{2}}(|01\rangle - |10\rangle)$ 為起點。Einstein 的「鬼魅」成了量子資訊時代的第一塊基石。
