# 1964 - Bell 不等式

## 案件摘要
EPR 悖論懸宕 29 年，看似永遠是「哲學口水戰」。1964 年 John Bell 在短篇論文中證明：任何局域隱變數理論都必須滿足一個數學不等式，而量子力學預測會違反它。哲學問題從此變成可實驗的物理問題。

## 前因 -- 為什麼會有這個案子
- 1935 年 Einstein–Podolsky–Rosen 提出 EPR 悖論：糾纏粒子對似乎允許「超距即時關聯」，Einstein 稱之「鬼魅般的超距作用」，主張量子力學不完備，背後應有隱變數。
- Bohm 1952 年提出可用實驗驗證的隱變數版本（Bohm 力學），並將 EPR 簡化為自旋 1/2 粒子對——這正是 Bell 分析的舞台。
- von Neumann 1932 年曾「證明」隱變數理論不可能，但 Bell 指出其證明隱含一個不合理的假設（線性組合的期望值假設對隱變數不成立），證明有漏洞。
- Bell 的問題：量子力學的統計預測，是否與「局域性 + 隱變數」相容？

## 線索與推理 -- 數學式、程式、理論

### 局域隱變數模型
隱變數 $\lambda$（機率密度 $\rho(\lambda)$）事先決定所有測量方向的結果：

$$A(\mathbf{a}, \lambda) = \pm 1, \quad B(\mathbf{b}, \lambda) = \pm 1$$

相關函數為：

$$E(\mathbf{a}, \mathbf{b}) = \int d\lambda\, \rho(\lambda)\, A(\mathbf{a}, \lambda)\, B(\mathbf{b}, \lambda)$$

### Bell（原始）不等式
$$|E(\mathbf{a}, \mathbf{b}) - E(\mathbf{a}, \mathbf{c})| \leq 1 + E(\mathbf{b}, \mathbf{c})$$

推理關鍵：$A(\mathbf{a},\lambda)A(\mathbf{b},\lambda) = A(\mathbf{a},\lambda)A(\mathbf{b},\lambda)\,A(\mathbf{b},\lambda)A(\mathbf{c},\lambda)A(\mathbf{c},\lambda)$（因 $A^2=1$），對 $\lambda$ 積分即得。整個證明只用到「局域性」與「結果事先決定」。

### CHSH 不等式（1969，Clauser–Horne–Shimony–Holt 實驗友好版）
四個測量方向 $a, a'$（Alice 側）、$b, b'$（Bob 側）：

$$|S| = |E(a,b) + E(a,b') + E(a',b) - E(a',b')| \leq 2$$

### 量子力學的預測
取單態 $|\psi\rangle = \frac{1}{\sqrt{2}}(|01\rangle - |10\rangle)$，量子相關為

$$E(\mathbf{a}, \mathbf{b}) = -\mathbf{a} \cdot \mathbf{b} = -\cos\theta_{ab}$$

選角度 $a=0°,\ a'=90°,\ b=45°,\ b'=-45°$，則

$$S_{QM} = \left|-\tfrac{\sqrt2}{2} - \tfrac{\sqrt2}{2} - \tfrac{\sqrt2}{2} + \tfrac{\sqrt2}{2}\right| \cdot \ldots = 2\sqrt{2} \approx 2.828 > 2$$

這個量子最大值 $2\sqrt{2}$ 稱為 **Tsirelson bound**（1980），是量子理論允許的上限——比隱變數的 2 高，但不超過 4（無限制關聯的界線）。

### Python numpy 模擬：隱變數 vs 量子預測

```python
import numpy as np

rng = np.random.default_rng(0)
angles = {'a': 0, "a'": np.pi/2, 'b': np.pi/4, "b'": -np.pi/4}

# ---- 模型一：局域隱變數（事先決定四個結果）----
def local_hidden(N=100000):
    S = 0
    for combo in [('a','b'), ('a',"b'"), ("a'",'b'), ("a'","b'")]:
        a, b = angles[combo[0]], angles[combo[1]]
        # lambda 均勻分布，決定每個方向的符號
        lam = rng.uniform(0, 2*np.pi, N)
        A = np.sign(np.cos(a - lam)); A[A == 0] = 1
        B = np.sign(np.cos(b - lam)); B[B == 0] = 1
        S += np.mean(A * B) * (1 if combo != ("a'","b'") else -1)
    return abs(S)

# ---- 模型二：量子力學（單態，E = -cos(theta)）----
def quantum():
    S = 0
    for combo in [('a','b'), ('a',"b'"), ("a'",'b'), ("a'","b'")]:
        a, b = angles[combo[0]], angles[combo[1]]
        E = -np.cos(a - b)
        S += E * (1 if combo != ("a'","b'") else -1)
    return abs(S)

print("CHSH S (local hidden variable):", local_hidden())  # ~2.0  <= 2
print("CHSH S (quantum prediction):  ", quantum())        # ~2.828 = 2*sqrt(2)
print("Tsirelson bound: 2*sqrt(2) =", 2*np.sqrt(2))
```

輸出顯示：隱變數模型嚴格守在 2，量子力學預測 $2\sqrt{2}$。兩者可分辨——只要做實驗。

## 結案 -- 後果與影響
- Bell 不等式把「Einstein vs Bohr」從形上學辯論轉化為可測量的實驗判決，開啟了整個實驗量子基礎學科。
- 1969 年 CHSH 給出可實作的版本；1972 年 Freedman–Clauser 首次實驗；1982 年 Aspect 實驗決定性違反不等式（見另篇）。
- 違反 Bell 不等式的關聯（非局域性）成為量子資訊科學的資源：量子密鑰分配、裝置無關（device-independent）密碼學、量子隨機數認證都以 Bell 測試為基石。
- Bell 本人終身未獲諾貝爾獎（1990 年過世），但其思想是 2022 年諾貝爾物理獎的直接根源。
- 哲學餘波：局域實在論（local realism）被證明與實驗不相容，必須放棄「局域性」或「實在性」之一。
