# 前300年 — 《九章算術》聯立方程

## 案件摘要
大約在西漢初期（約公元前 2 世紀，內容可追溯至先秦），《九章算術》第八章「方程」記載了聯立一次方程組的系統解法：把係數用算籌排成方陣，透過「遍乘直除」的消去法逐步化簡，最後讀出答案；書中甚至明文規定了**正負數運算法則**。這是線性方程組求解思想的最早系統記錄，比 Gauss 的消去法早了約兩千年。

## 前因 -- 為什麼會有這個案子
- 戰國到秦漢，田畝測量、糧賦分攤、工程調度等實際問題，經常需要同時滿足多個條件——這就是「聯立」的現實來源。
- 中國很早發展了**十進位值制**與**算籌記數**：以小棍的縱橫擺放表示數字，可以在案板上直接操作，像是一塊古代的「計算工作台」。
- 《九章算術》採「問題—答—術」體例：先給題目與答案，再給一般化的「術」（演算法）。這種體例本身就是演算法思維的雛形。
- 「方程」一詞古義是「併列的方陣」：把各題條件的係數「程」排成矩形的行列——這幾乎就是矩陣概念的直覺前身。

## 線索與推理 -- 數學式、程式、理論

### 線索一：第一章案子——「上禾三秉、中禾二秉、下禾一秉，實三十九斗」
《九章算術》方程章第一題：上等禾 3 捆、中等禾 2 捆、下等禾 1 捆，共收穫 39 斗；上禾 2 捆、中禾 3 捆、下禾 1 捆收 34 斗；上禾 1 捆、中禾 2 捆、下禾 3 捆收 26 斗。求各禾一捆之實。設上、中、下禾每捆分別為 $x_1, x_2, x_3$ 斗，即：

$$\begin{cases}3x_1 + 2x_2 + x_3 = 39\\ 2x_1 + 3x_2 + x_3 = 34\\ x_1 + 2x_2 + 3x_3 = 26\end{cases}$$

書中把三組條件以算籌「列」成三行（右、中、左），相當於係數矩陣：

$$\begin{pmatrix}3&2&1&39\\ 2&3&1&34\\ 1&2&3&26\end{pmatrix}$$

### 線索二：「遍乘直除」——消去法的完整演算法
「術曰：以右行上禾遍乘中行而以直除。」意即：用右行首項（3）乘中行，再以中行連續減去右行，直到中行首項歸零。用現代語言：對增廣矩陣做行變換，消去下方各行的首係數——**這正是 Gaussian elimination 的前向消元**。

以中行為例：中行乘 3 得 $(6, 9, 3, 102)$，減去右行 $(3, 2, 1, 39)$ 兩次，得 $(0, 5, 1, 24)$。對左行同法消去首項，再對第二列繼續消元，最後化成上三角（書中是右上方係數只剩主對角），逐行回代即得：

$$x_3 = 2\frac{3}{4}, \qquad x_2 = 4\frac{1}{4}, \qquad x_1 = 9\frac{1}{4}$$

注意：「直除」是連續相減而非「乘倒數再相減」，但因涉及分數，實際操作中古人也會靈活處理。整個流程與現代高斯消去法在本質上完全一致。

### 線索三：正負數——「正負術」
消去過程會產生「不夠減」的情形，書中於是給出人類史上最早的**正負數法則**：「正負術曰：同名相除，異名相益；正無入負之，負無入正之。」

用現代語言：
- 同號相減：$a - b$（$a,b>0$），即 $|a| - |b|$ 取較大者之號；
- 異號相減：實為相加，$a - (-b) = a + b$；
- 無對減（遇零）：正數變負、負數變正。

這套法則對應現代的減法規則 $x - y = x + (-y)$，讓消去法在任何係數下都能執行。歐洲要到 16–17 世紀（Cardano、Descartes 時代）才真正接受負數——中國的負數運算早了一千八百年。

### 線索四：題目中的「損益」思想
方程章還有「損之曰益，益之曰損」的移項思想：把一項從一邊移到另一邊，正負號改變。這正是現代移項法則 $ax + b = c \Rightarrow ax = c - b$，也就是「等式兩邊同減」的表述。移項＋消元＋正負數，三件工具合起來，就是一套完整的線性方程組求解理論。

### 程式碼範例：九章算術消去法的 numpy 實作
```python
import numpy as np
from fractions import Fraction

# 方程章第一題（列以 Fraction 精確表示，模擬算籌操作）
A = np.array([[Fraction(3), Fraction(2), Fraction(1), Fraction(39)],
              [Fraction(2), Fraction(3), Fraction(1), Fraction(34)],
              [Fraction(1), Fraction(2), Fraction(3), Fraction(26)]], dtype=object)

def jiuzhang_eliminate(M):
    n = len(M)
    for col in range(n):                 # 遍乘直除：前向消元
        pivot = M[col][col]
        assert pivot != 0
        for row in range(col + 1, n):
            f = M[row][col]
            for k in range(col, n + 1):
                M[row][k] = M[row][k] - (f / pivot) * M[col][k]
    x = [Fraction(0)] * n
    for i in reversed(range(n)):         # 回代
        s = M[i][n] - sum(M[i][j] * x[j] for j in range(i + 1, n))
        x[i] = s / M[i][i]
    return x

x = jiuzhang_eliminate(A)
print("上禾 =", x[0], "中禾 =", x[1], "下禾 =", x[2])
# 上禾 = 37/4  中禾 = 17/4  下禾 = 11/4

# 與 numpy 現代解法對照
print(np.linalg.solve([[3,2,1],[2,3,1],[1,2,3]], [39,34,26]))  # [9.25 4.25 2.75]
```

輸出 $37/4 = 9\tfrac14$、$17/4 = 4\tfrac14$、$11/4 = 2\tfrac34$，與《九章算術》原文答案完全一致，也與 `numpy.linalg.solve`（現代 LU 分解解法）吻合——兩千年的時空在此對上口供。

## 結案 -- 後果與影響
- 《九章算術》「方程」章確立了**用係數方陣＋消去法解聯立方程**的思想框架，是線性代數最遠古的源頭。
- 「正負術」使人類最早系統化地引入負數與有理數運算，比西方早一千多年。
- 三國時代劉徽（263 年）為《九章》作注，進一步闡明「舉率以相減」的消去原理，並發展割圓術、極限思想。
- 此書傳入朝鮮、日本，影響東亞數學千年；17 世紀起傳入歐洲。
- 兩千年後，Gauss（1795–1810）在天文計算中獨立發展出同樣的消去法並予以成熟應用——這樁「舊案」的偵破手法，被現代數值線性代數重新命名為 Gaussian elimination，成為今日教科書的標準算法。
