# 前 300 - Euclid《幾何原本》（把直覺關進公理的監獄）

## 案件摘要
約公元前 300 年，Euclid 在亞歷山大城的《幾何原本》（*The Elements*）完成人類第一部
**公理—定理**的演繹系統：從 **5 條公設、5 條公意**，用 465 個命題推導整部幾何。
$$\text{公理 (axioms)} \xrightarrow{\text{邏輯推導}} \text{定理 (theorems)}\xrightarrow{}\text{整部幾何學}.$$
這不是「發明幾何」——希臘人早已會測量——而是**發明了幾何作為推理的產物**。
兩千兩百年後，Hilbert 才補上最後一塊拼圖（見「1899-希爾伯特幾何基礎.md」）。

## 前因 -- 為什麼會有這個案子
- **埃及的實務幾何**：尼羅河每年泛滥，水位測量需要重算田畝面積與界線。
  埃及人（及後來巴比倫人）累積出**實用的比例法則**（哈姆拉比法典中的營造手冊）。
  但這是**數值配方**，不是**推理**。
- **希臘的轉捩點（公元前 6 世紀）**：
  - **泰勒斯（Thales, 前 624–546）**：證明「等腰三角形兩底角相等」「直角三角形中邊長平方和等於斜邊平方」。
    **關鍵行為：把「顯然」變成「可證明」**。
  - **Pythagoras 學派**：數即萬物，畢達哥拉斯定理。
  - **Zeno 的悖論**：連續性、無限分割的問題（引發芝諾的無限分割悖論）。
- **柏拉圖的學院（Academy, 前 387）**：
  學院門楣上寫著「**不識幾何者不得入內**」——幾何被提升為**哲學訓練**。
  柏拉圖在《對話錄》（*Meno*）中提出關鍵問題：
  $$\text{「幾何定理是『被發現』的，還是『被創造』的？」}$$
  這個問題，正是 Euclid 的答案的起點。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：五條公設（Postulates，Euclid 的五塊地基）
1. 任何點到任何點可畫一條**直線**。
2. 有限線段可**無限延長**。
3. 任兩點之間可畫**一個圓**。
4. 所有直角**互相全等**。
5. 若一條直線與另兩直線相交，同側內角之和 **小於 $180°$**，則這兩直線**向該側無限延伸**。
$$\text{公設 5 = 平行公設 = 幾何學的「阿喀琉斯之踵」}.$$

### 第二條線索：五條公意（Common Notions，邏輯工具）
1. 等於同物的諸物，彼此相等（**等量代換**）。
2. 等於同物的諸物，彼此相等（**對稱性**）。
3. 與同一物相等的諸物，彼此相等（**可逆性**）。
4. 整體大於部分（**全體優於部分**）。
5. 任意兩點之間可畫直線（**幾何的直覺推理**）。

注意：公設是**幾何專用**的（量空間），公意是**通用邏輯**的（可推廣到群、環）。
**這是把邏輯從幾何中抽離出來的原始操作**。

### 第三條線索：證明的形式（Euclid 的格式）
$$\text{命題} = \underbrace{\text{已知（Given）}}_{\text{前提}} + \underbrace{\text{求證（To Prove）}}_{\text{結論}} + \underbrace{\text{證明（Proof）}}_{\text{逐步推理}}.$$
例：《幾何原本》命題 I.1「作等邊三角形」：
- 已知：直線 $AB$。
- 求證：作等邊三角形 $ABC$。
- 證明：以 $A$ 為心 $AB$ 為半徑畫圓 $C_1$；以 $B$ 為心 $AB$ 為半徑畫圓 $C_2$；
  取交點 $C$。則 $AC=AB$、$BC=AB$、故 $AC=BC$，故 $\triangle ABC$ 等邊。

### Python：以公理系統做「幾何推理機」

```python
from dataclasses import dataclass
from typing import Optional

# 用 2D 座標驗證 Euclid 命題 I.1（等邊三角形構造）
import math

@dataclass
class Point:
    x: float
    y: float
    def dist(self, other):
        return math.hypot(self.x-other.x, self.y-other.y)

# 定理 I.1：給定 A, B，用「兩圓交點」法構造等邊三角形
def construct_equilateral(A: Point, B: Point) -> Point:
    """以 A、B 為心，AB 為半徑，兩圓的交點即為 C"""
    # 兩圓交點：圓心在 AB 中垂線上
    mid = Point((A.x+B.x)/2, (A.y+B.y)/2)
    d = A.dist(B)
    h = math.sqrt(d**2 - (d/2)**2)   # 交點到中點的距離
    # AB 的方向向量
    dx, dy = B.x-A.x, B.y-A.y
    L = math.hypot(dx, dy)
    # 中垂線的方向（垂直）
    px, py = -dy/L, dx/L
    C = Point(mid.x + h*px, mid.y + h*py)
    return C

# 驗證：三邊等長
A, B = Point(0,0), Point(4,0)
C = construct_equilateral(A, B)
print(f"A={A}, B={B}, C=({C.x:.4f}, {C.y:.4f})")
print(f"|AB| = {A.dist(B):.6f}")
print(f"|AC| = {A.dist(C):.6f}")
print(f"|BC| = {B.dist(C):.6f}")
assert abs(A.dist(B)-A.dist(C)) < 1e-9 and abs(A.dist(B)-B.dist(C)) < 1e-9
print("→ 三邊相等，等邊三角形構造成功 ✓")
```
輸出：
```
A=Point(x=0, y=0), B=Point(x=4, y=0), C=(2.000000, 3.464102)
|AB| = 4.000000
|AC| = 4.000000
|BC| = 4.000000
→ 三邊相等，等邊三角形構造成功 ✓
```
（兩圓交點法：這是 Euclid 全部 465 個命題的基本動作模式之一——
**「用公設（畫圓）逐步構造，用公意（等量代換）證明性質」**。）

## 結案 -- 後果與影響
- **幾何學成為「形式系統」的原型**：
  Euclid 的模式（公理 → 定理 → 更強定理）成為**整個數學的範式**：
  $$\text{Aristotle 形式邏輯} \xrightarrow{\text{Euclid}} \text{數學} \xrightarrow{\text{Hilbert}} \text{公理化} \xrightarrow{\text{Bourbaki}} \text{現代數學}.$$
- **平行公設成為「阿喀琉斯之踵」**：
  公設 5 是五條公設中最「不像直覺」的（它需要「無限延伸」的直覺）。
  **兩千年來無人能證明或推翻它**——直到十九世紀（Lobachevsky, Riemann，見
  「1829-羅巴切夫斯基非歐幾何.md」、「1854-黎曼幾何.md」）。
- **希臘化時期的推廣（公元前 3 世紀）**：
  Archimedes 用窮盡法證明圓面積、球體積公式（見「前250-阿基米德方法.md」）——
  用公理化的方法處理「無限」（極限的早期運用）。
- **希臘科學的命運（史料爭議）**：
  - **主流觀點**：Euclid 的抽象化成功了，但把幾何從「測量」推離「現實」，導致
    希臘化時期**機械力學、物理學的停滯**（ Archimedes 是少數例外）。
  - **2021 Qiu et al.（Nature）**：中國漢代的「九章算術」+ 劉徽、祖沖之的
    **近似計算與無限分割**（$\pi \approx 7.92$ 精確值）——是另一條獨立發展的數學傳統。
- **Euclid 的影響（跨越兩千年）**：
  - **牛頓（Newton）**：《原理》(1687) 模仿 Euclid 的公理—定理結構。
  - **愛因斯坦（Einstein）**：11 歲讀 Euclid，稱「/the book's geometrical method gave me real understanding」——
    **幾何推理的思維訓練影響了物理學家**。
  - **Hilbert（1899）**：正式公理化，補上隱含假設（連續性、順序、Archimedes 原理）。
