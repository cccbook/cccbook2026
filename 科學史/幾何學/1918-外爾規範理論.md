# 1918 - Weyl 規範理論（幾何對稱變成物理定律）

## 案件摘要
1918 年，**Hermann Weyl（1885–1955）** 發表《重力與電》
（*Gravitation und Elektrizität*），提出一個大膽的想法：
$$\boxed{\text{電磁場 = 度規的「尺度對稱」（scale symmetry）的規範場}}.$$
他試圖把重力與電磁力統一在**同一個幾何框架**下——
雖然物理上失敗了，但**「規範對稱（gauge symmetry）」這個概念活了下來**，
成為 20 世紀後半物理學（標準模型）的**核心原理**：
$$\text{電磁力、弱力、强力} = \text{三個規範場} = U(1)\times SU(2)\times SU(3).$$

## 前因 -- 為什麼會有這個案子
- **Einstein 的廣義相對論（1915）**：
  Einstein 把重力化為**時空曲率**——物理定律與**座標選擇無關**（廣義協變性）。
  這啟發了一個問題：
  > 「既然物理與座標選擇無關，那物理是否也與**尺度（scale）選擇**無關？」
- **Weyl 的雄心（1918）**：
  Weyl（Hilbert 的學生、Göttingen 的教授）提出：若在每個時空點允許**獨立地重設尺度**，
  則保持物理不變的「規範變換」必產生一個**新的場**——
  這個場**就是電磁場**。
  $$\text{尺度重設} \to \text{規範場 } A_\mu \to \text{電磁力}.$$
- **Einstein 的反對（1918）**：
  Einstein 立即指出致命缺陷：
  > 「若尺度真的可以逐點重設，則兩個相同的原子（如氫）會有不同的光譜線——
  > 但實驗上所有氫原子的光譜完全相同！」
  $$\text{逐點重設尺度} \Rightarrow \text{原子鐘的頻率漂移} \Rightarrow \text{實驗否決}.$$
- **概念的重生（1927–1929）**：
  Weyl 自己在 1929 年修正了理論：**把「尺度重設」換成「相位重設」**——
  $$\text{尺度 } g \to \text{相位 } e^{i\theta} \quad\text{（量子力學的波函數相位）}.$$
  這個修正版**完全正確**，成為**電磁場的量子理論**（QED）的基礎。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：1918 年的「尺度規範」（失敗版）
Weyl 的變換（度規 + 規範場的變換）：
$$g_{\mu\nu} \to e^{2\lambda(x)} g_{\mu\nu},\qquad A_\mu \to A_\mu - \partial_\mu \lambda.$$
- 在此變換下，**Riemann 幾何的曲率張量不變**；
- Weyl 主張 $A_\mu$ 就是電磁位勢。
**Einstein 的反駁**：尺度重設會改變原子的大小 → 光譜線漂移 → 實驗否決。

### 第二條線索：1929 年的「相位規範」（成功版）
Weyl 的修正：把尺度重設換成**波函數的相位重設**：
$$\psi \to e^{i\theta(x)}\psi,\qquad A_\mu \to A_\mu - \frac{\hbar c}{e}\partial_\mu\theta.$$
- 波函數的相位**不可觀測**（只有模方 $|\psi|^2$ 可觀測）——
  所以**相位重設不影響任何實驗**！
- 保持量子力學（Dirac 方程）不變的規範變換**必然引入電磁場**：
  $$\boxed{A_\mu \text{ 的出現不是假設，是「相位對稱」的必然結果}}.$$
- **這是「對稱決定相互作用」的第一個案例**：
  $$U(1)\ \text{規範對稱} \Rightarrow \text{電磁力}.$$

### 第三條線索：楊–米爾斯與標準模型（1954–1970s）
**Yang–Mills（1954）**：把 Weyl 的 $U(1)$ 推廣到非阿貝爾群 $SU(2)$：
$$\boxed{F_{\mu\nu} = \partial_\mu A_\nu - \partial_\nu A_\mu + g[A_\mu, A_\nu]}$$
- $[A_\mu, A_\nu] \ne 0$（非阿貝爾）——場自身也帶電荷（自我相互作用）！
- **標準模型（1960s–1970s）**：
  $$\text{電磁力（} U(1)\text{）} + \text{弱力（} SU(2)\text{）} + \text{强力（} SU(3)\text{）} = SU(3)\times SU(2)\times U(1).$$
  $$\text{全部來自規範對稱——Weyl 的概念統治了物理學}.$$

### Python：規範變換與電磁場的幾何驗證

```python
import numpy as np

# 1) U(1) 規範變換：波函數相位重設不改變觀測量
def gauge_transform(psi, theta_func, x):
    """波函數 ψ → e^{iθ(x)} ψ"""
    return np.exp(1j*theta_func(x)) * psi

def probability(psi):
    """觀測量：|ψ|²"""
    return np.abs(psi)**2

x = np.linspace(0, 1, 100)
psi0 = np.exp(-(x-0.5)**2) * (1 + 0.5j)   # 初始波函數
theta = lambda x: 2*np.pi*x               # 逐點相位重設

psi1 = gauge_transform(psi0, theta, x)
print("U(1) 規範變換（相位重設）：")
print(f"  |ψ₀|² 的一致性：max = {probability(psi0).max():.6f}")
print(f"  |ψ₁|² 的一致性：max = {probability(psi1).max():.6f}")
print(f"  誤差 = {np.abs(probability(psi0) - probability(psi1)).max():.2e}")
print("  → 相位重設不影響任何觀測量（|ψ|² 不變）✓\n")

# 2) 規範場的引入：協變導數
def covariant_derivative(psi, A, x, h=1e-6, q=1.0):
    """協變導數 D = ∂ - iqA/ħc（保持規範對稱的導數）"""
    # 普通導數
    d_psi = (gauge_transform(psi, theta, x+h) - gauge_transform(psi, theta, x-h)) / (2*h)
    # 規範場項（簡化為 1D）
    return d_psi - 1j*q*A(x)*psi

A = lambda x: np.sin(2*np.pi*x)   # 一個規範場
D_psi = covariant_derivative(psi0, A, x)
print("協變導數（D = ∂ - iqA）：")
print(f"  |Dψ| 的範圍 = [{np.abs(D_psi).min():.4f}, {np.abs(D_psi).max():.4f}]")
print("  → 協變導數在規範變換下協變（這就是電磁場的幾何本質）\n")

# 3) 電磁場張量：F = ∂A - ∂A（Abelian 情形）
def field_strength(A, x, h=1e-6):
    """F = ∂A（Abelian 規範場的場強）"""
    return (A(x+h) - A(x-h)) / (2*h)

F = field_strength(A, x)
print("電磁場強（F = ∂A）：")
print(f"  F 的範圍 = [{F.min():.4f}, {F.max():.4f}]")
print(f"  F = 0 的位置（純規範，無物理）：{(np.abs(F)<1e-6).sum()} 個點")
print("  → 規範場本身不可觀測，場強 F 才是物理\n")

# 4) 非阿貝爾場：[A, A] ≠ 0（矩陣情形）
print("非阿貝爾規範場（Yang–Mills, 1954）：")
# SU(2) 的三個生成元（Pauli 矩陣 / 2）
sigma = [np.array([[0,1],[1,0]])/2,
         np.array([[0,-1j],[1j,0]])/2,
         np.array([[1,0],[0,-1]])/2]
for i in range(3):
    for j in range(i+1, 3):
        comm = sigma[i]@sigma[j] - sigma[j]@sigma[i]
        print(f"  [σ{i+1}, σ{j+1}] ≠ 0：範數 = {np.linalg.norm(comm):.4f}")
print("  → 非阿貝爾場自我相互作用（強力的本質）")
print("\n標準模型：U(1)×SU(2)×SU(3) 的三個規範場 = 電磁力 + 弱力 + 强力")
```

## 結案 -- 後果與影響
- **1918 年的失敗與 1929 年的重生**：
  $$\text{Weyl（1918）：尺度規範（失敗）} \xrightarrow{\text{Einstein 反駁}} \text{Weyl（1929）：相位規範（成功）}.$$
  - **Einstein 的反駁是建設性的**——它沒有殺死規範概念，而是逼 Weyl 找到正確版本。
  - **量子力學（1925–1927）**給了 Weyl 鑰匙：波函數的相位天然不可觀測。
- **Weyl 的幾何遺產**：
  1. **活動標架（Cartan, 1926）**：Weyl 的「逐點對稱」與 Cartan 的「逐點標架」是同一思想
     （見「1926-嘉當活動標架.md」）。
  2. **纖維叢（Ehresmann, 1950s）**：規範場的幾何本質是**纖維叢的聯絡**——
     $$\text{規範場 } A_\mu = \text{主纖維叢上的聯絡（connection）}.$$
     這是 20 世紀幾何學的最大統一：**物理的場 = 幾何的聯絡**。
  3. **Chern（1944）**：**陳類（Chern class）**——纖維叢的拓樸不變量，
     成為規範場論的「電荷量子化」的數學基礎。
- **物理學的勝利（1954–）**：
  - **Yang–Mills（1954）**：非阿貝爾規範場（$SU(2)$）——
    楊振寧與米爾斯獲 1957/1980s 諾貝爾級的榮譽；
  - **'t Hooft–Veltman（1972）**：證明 Yang–Mills 可重整化（1999 諾貝爾物理獎）；
  - **標準模型（1970s）**：$SU(3)\times SU(2)\times U(1)$ 的規範理論——
    **已通過所有實驗，是物理學史上最精確的理論**（精度達 $10^{-10}$）；
  - **2012 年 CERN 發現希格斯玻色子**——標準模型的最後一塊拼圖。
  $$\text{Weyl 的概念（1918/1929）} \xrightarrow{} \text{標準模型（1970s）} \xrightarrow{} \text{希格斯（2012）}.$$
- **「對稱決定相互作用」的哲學**：
  $$\boxed{\text{物理定律 = 對稱性的必然結果（不是假設）}}$$
  - 電磁力 ← $U(1)$ 相位對稱；
  - 弱力 ← $SU(2)$ 同位旋對稱；
  - 强力 ← $SU(3)$ 色荷對稱；
  - 重力 ← 微分同胚對稱（座標選擇無關）。
  **Weyl 開創了這個「對稱至上」的思維方式**——
  這是 20 世紀物理學與幾何學最重要的方法论革命。
- **現代應用（2000s–）**：
  - **拓樸絕緣體（2010s）**：陳類的物理實現（2016 諾貝爾物理獎）；
  - **量子計算**：規範場論的量子模擬；
  - **機器學習**：規範對稱的網路（gauge-equivariant networks）。
- 歷史定位：**Weyl 是「幾何學進入物理學核心」的建築師**——
  他失敗的那個理論，孕育了物理學史上最成功的理論。
  $$\text{失敗（1918）} \xrightarrow{} \text{重生（1929）} \xrightarrow{} \text{Yang–Mills（1954）} \xrightarrow{} \text{標準模型（1970s）}.$$
