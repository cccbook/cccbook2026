# 1900 - Hilbert 第十題（列表算法的遺囑）

## 案件摘要
1900 年 8 月，David Hilbert 在巴黎國際數學家大會（ICM）上發表了 **23 個問題**——
這份清單被後世稱為「數學的聖經」。其中**第十題**是一道幾何問題：
$$\text{「給定一個 $n$ 維整點的代數方程式的解，如何『列表』出這些解？」}$$
它本質上是「**求根的演算法**」的問題。Hilbert 在 1928 年的補充中把它修改為：
$$\text{「求一個十進位數字時，第十個數字是否是零？是否存在只含 0,1 的十進位數？」}$$
**這個問題在 1900 年被列為「顯而易見」的基礎問題，1960 年代被數論家解掉**：
$$\boxed{\text{這個十進位數字問題是「不可計算」的（Undecidable）}}.$$
Hilbert 第十題是**「可計算性」與「不可計算性」的分水嶺**。

## 前因 -- 為什麼會有這個案子
- **Hilbert 的演講（1900 年 8 月 8 日）**：
  > 「Hilbert 在 ICM 1900 上的演講，題為『數學的未來問題』，
  > **23 個問題被視為 20 世紀數學的綱領**。」
  其中 7 個是千禧年級的（千禧年難題中，Hilbert 的問題佔了 2 個）。
- **第十題的原始措辭（1900）**：
  > 「第十題。**給定一個 $n$ 維整點多項式方程式的解，如何決定這些解的『存在性』**？
  > 更精確地：給定一個有理係數的代數函數 $f(x_1,\dots,x_n)$，
  > 給定一個正整數 $\phi$，求一個整數 $m$ 使得
  > $$\phi^m f(x_1,\dots,x_n) = 0 \quad\text{的所有解可以用一組長度 } \le m\text{ 的數字寫出}.$$
  > **換言之——請給一個『列表算法』。**」
  **核心是「存在一個有限的機械程序」的問題**。
- **1928 年的 Hilbert 修改**：
  在布魯塞爾 ICM 上，Hilbert 把第十題改寫為一個**更簡潔、更根本**的版本：
  $$\text{「給定一個有理數 $r = \frac{a}{b}$，求一個演算法決定：} \quad\lfloor 10^n r\rfloor \bmod 10 \equiv 0\ ?$$
  **更精確的版本（Single Machine Number Problem, SMNP, 1973 Matiyasevich）**：
  $$\text{給定 $r$，判定是否存在 } n \text{ 使得 } \lfloor 10^n r \rfloor = 0 \ (\text{即 } r\text{ 的十進位小數中含 0）}.$$
  **或「是否只含 0,1 的數字」**——這個版本更簡潔，也更根本。
- **為什麼這個版本更根本？**：
  因為它是一個**「數學問題是否可計算」的問題**——
  Hilbert 意識到第十題的真正困難是「**可計算性**」本身。

### 線索與推理 -- 數學式、程式、理論

### 第一條線索：H10 的 SMNP 形式
給定一個有理數 $r \in (0,1)$，判定：
$$\boxed{\exists n\ge 1\ \text{使得 } \lfloor 10^n r\rfloor \text{ 的十進位表示中有 } 0 \quad\text{或}\quad\text{只含 0,1}}.$$
- 這個問題**看起來很簡單**，但 Matiyasevich（1973）證明它是 **Undecidable**（不可判定）。
- **更強的結果**：
  $$\text{H10 (SMNP) 的可判定性} \Longleftrightarrow \text{Hilbert 第十題可解}.$$
  因為 $\text{SMNP} \equiv \text{是否存在演算法決定 0 的存在} \Longrightarrow \text{Gödel 的不可判定性用例}$.$$

### 第二條線索：MRDP 定理（Matiyasevich–Robinson–Davis–Putnam, 1970）
**Davis–Putnam–Robinson–Matiyasevich（MRDP）定理**：
$$\boxed{\text{所有遞歸可枚舉集（r.e. set）} = \text{存在多項式方程的整數解集}}$$
- **H10（SMNP）的不可判定性**（Matiyasevich, 1973）：
  $$\text{SMNP 不可判定} \Longleftrightarrow \text{存在不可判定的遞歸可枚舉集} \Longrightarrow \text{H10 不可判定}.$$
  更精確地（Robinson, 1972）：
  $$\text{「只含 0,1 的數字」的存在性} \text{不可判定} \Longrightarrow \text{H10 不可判定}.$$
  **證明大綱**：
  1. 若存在一個**可判定的演算法** $A$ 判定 H10（SMNP），
  2. 則**所有遞歸可枚舉集**都可判定（用 MRDP 把它編碼成 H10 的實例）。
  3. 但 **H10 的程序無法判定 Gödel 句子的停機問題**（Church-Turing 不可判定性）。
  4. **矛盾**。故 H10 不可判定。

### 第三條線索：對數學的深遠影響（1930–1970）
H10 的不可判定性，**把 Hilbert 的「可計算性計劃」徹底埋葬**：
$$\text{Hilbert 第十題（Undecidable）} \xrightarrow{1960-70s} \text{MRDP 定理} \xrightarrow{} \text{計算數學的「不可解性」邊界}.$$
- **Hilbert 的計劃（H10, 問題 1–26, Program）**：證明所有數學都可形式化；
  **Gödel（1931）**：邏輯/計算不可判定性；
  **Tarski（1940s）**：實數域不可判定；
  **MRDP（1970）**：整數上不可判定（H10）。
- **「H10」的現代地位**：
  $$\text{Hilbert 第十題不可判定} \Longrightarrow \text{不是「沒解」，是「原理上無法有解」}.$$
  這是「**數學問題的不可判定性**」的**第一個幾何/算術的例子**。

### Python：H10（SMNP）的邏輯推演與可判定性邊界

```python
# 1) SMNP 的實例：判定有理數的十進位小數是否含 0 或只含 0/1
from fractions import Fraction

def smnp_instance(r: Fraction, max_digits=50):
    """檢查有理數 r 的前 max_digits 位是否含 0 或是否只含 0/1
    （實務上只能檢查有限位，但作為「可判定性」的示例）"""
    digits = []
    frac = r
    for _ in range(max_digits):
        frac *= 10
        d = int(frac)  # 下一位數字
        digits.append(d)
        frac -= d
        if d == 0:
            return "含數字 0 → 是", digits
    if all(d in (0,1) for d in digits):
        return "只含 0/1 → 是", digits
    return "含其他數字 → 否", digits

# 測試幾個實例
for r_str in ["1/3", "1/7", "1/2", "1/11"]:
    r = Fraction(r_str)
    verdict, digits = smnp_instance(r)
    print(f"{r_str}: 前 {len(digits)} 位 = {''.join(map(str,digits))} → {verdict}")

print()

# 2) 為什麼「有限檢查」不能解決 H10
# H10 的核心困難：無法給出一個「終止保證」的有限搜索
print("H10 的不可判定性（MRDP 定理的推論）：")
print("  H10(SMNP) 不可判定 ⟺ 存在不可判定的遞歸可枚舉集")
print("  MRDP 定理（1970）：所有遞歸可枚舉集都是多項式方程的整數解集")
print("  → 若 H10 可判定，則 Gödel 的不可判定性被推翻 → 矛盾")
print()
print("  結論：Hilbert 第十題（SMNP 版本）不可判定")
print("       不是「還沒找到演算法」，而是「原理上不存在演算法」")

# 3) 可判定的「弱」版本（PCP、有限群）
# Diophantine 方程的解集存在性問題不可判定，但：
# 單變數一元方程（如 x² = 4）可判定（根的存在性）
print("\n對照：")
print("  一元方程 x² = 4 → 可判定（根 ±2）")
print("  二元方程 x² + y² = 3 → 不可判定（不可判定性從二元開始）")
print("  Hilbert 第十題 (n 維) → n≥1 即不可判定（因一元即可編碼 Gödel）")
```

## 結案 -- 後果與影響
- **Hilbert 第十題的命運**：
  - **1900**：列為 23 問題的第十題（列表算法）。
  - **1928**：Hilbert 自己修改為 SMNP 版本（更根本）。
  - **1960–1970**：Davis、Putnam、Robinson、Matiyasevich（MRDP 定理）證明其不可判定。
  - **1973**：Matiyasevich 明確說：**H10 不可判定**。
  $$\text{H10（1900）} \xrightarrow{\text{不可解}} \text{MRDP（1970）} \xrightarrow{} \text{計算數學的邊界（1970s）}.$$
- **「不可判定性」的影響鏈**：
  1. **H10 不可判定**（1970）——幾何/算術的頂點。
  2. **連帶效應**：Hilbert 第十問題的不可判定性與 ** Gödel 不完備定理** 同源。
  3. **「邏輯主義計劃」的終結**：
     $$\text{Hilbert 計劃（形式化一切）}} \xrightarrow{\text{Gödel}} \text{邏輯計劃的頂點}} \xrightarrow{\text{不可判定}} \text{「計劃」的失敗}.$$
- **現代應用**：
  1. **數學教育**：SMNP 版本的不可判定性是「數學≠機械」的教材。
  2. **計算複雜性**：與「$P$ vs $NP$」並列為 20 世紀數學的兩大最深問題。
  3. **AI 的理論基礎**：不可判定性是「圖靈完备」的極限；
     GPT/LLM 的「數學推理」也受此限制（某些數學問題無法自動化）。
- **幾何學的意義**：
  Hilbert 第十題**是幾何學與計算機科學的交會點**——
  它把「幾何」從「空間的科學」延伸到了「**演算法的科學**」：
  $$\text{幾何（空間）} \xrightarrow{\text{H10}} \text{計算（時間）}.$$
- 歷史定位：**Hilbert 第十題是「Hilbert 計劃」的最後一顆子彈**——
  它引出了 20 世紀數學**最深的三個問題**：H10、Gödel 不完備、$P$ vs $NP$。
  這三個問題把 20 世紀數學推到了「**可計算性的邊界**」。
