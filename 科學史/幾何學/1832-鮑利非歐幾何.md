# 1832 - Bolyai 非歐幾何（父子聯手的一頁奇蹟）

## 案件摘要
1823 年 5 月，匈牙利少年 **János Bolyai（1802–1860）** 在父親 **Farkas Bolyai** 的
《 Tentamen》（Attempt）書稿後附了 **26 頁的「附錄」（Appendix）**，
獨立發展出與 Lobachevsky 相同的非歐幾何：
$$\boxed{\text{「絕對幾何」（Absolute Geometry）}=\text{幾何中不依賴平行公設的部分}}.$$
他在開頭寫下那句名言：
> 「我已經知道了一件真正偉大的事，一旦我告訴你，你就再也忘不掉……
> 我在這個虛構幾何中發現了整套無窮的奇蹟。」

父親在書前加了一句警告：
> 「請不要試圖去理解它；我為此犧牲了我兒子的幸福、我的和平、我的健康。」
176 年後，George Hall 找到德國大學的副本，才讓世人知道這個「奇蹟」。

## 前因 -- 為什麼會有這個案子
- **父親 Farkas Bolyai 的悲劇**：
  **Farkas Bolyai（1775–1856）** himself 也是非歐幾何的先驅：
  - 他在 1800 年代獨自發現了非歐幾何的構想，寫了長篇手稿；
  - 但他**畏懼衝突**，在書前寫道：
    > 「這是一個觸犯天條的計劃，因為它有可能動搖宗教信仰的根基……我寧願被當作幻想家、
    > 被當作瘋子，也不願讓人類在已有的信仰上動搖。」
  - 他花了 20 年（1800–1825）**極度痛苦地自我否定**，最後在手稿末尾寫：
    > 「這是我一生中最大的痛苦。」
  $$\text{父親：獨自發現}\xrightarrow{\text{自我否定、燒毀手稿}}\text{兒子：重獲新生的非歐幾何}.$$
- **János 的起點（1822 年 12 月）**：
  19 歲的 János 在父親的書房裡獨立開始研究平行公設，
  走了完全不同的路：他不是證明或推翻，而是**保留「不決定」**——
  $$\text{若平行公設為真}\Rightarrow\text{歐氏幾何};\qquad
  \text{若為假}\Rightarrow\text{另一個幾何（皆自洽）}.$$
- **1823 年 5 月的突破**：
  János 用**公理化**方法：把「與平行公設無關」的公理列出，
  從中推出「絕對幾何」的所有定理（垂直性定理、外角定理、邊角不等式……），
  再把「平行公設」作為**可插拔的模組**加上去。
  $$\boxed{\text{「幾何 = 絕對幾何（核心）}\ \cup\ \text{平行公設（外掛）」}}.$$
  **這正是 Hilbert 1899 公理化方法的先聲**（見「1899-希爾伯特幾何基礎.md」）。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：絕對幾何與歐氏/雙曲幾何的「外掛」結構
現代的邏輯重構（Bolyai 的直覺被 Tarski 完全形式化）：
$$\boxed{\text{絕對幾何（Neutral Geometry）} = \text{不含平行公設的幾何公理系統}}$$
| 幾何 | 加入的公設 | 內角和 | 「無窮遠線」 |
|------|-----------|--------|-----------|
| **絕對幾何** | （不加任何平行公設） | $\le \pi$ | 未定 |
| 歐氏幾何 | 加入「無窮遠線存在」 | $= \pi$ | 一條 |
| 雙曲幾何 | 加入「無窮遠線不交於有限點」 | $< \pi$ | 兩條以上 |

**Tarski 的完美化（1940s）**：整個平面幾何可分為三層：
$$\text{絕對幾何（Hilbert 式的公理）} + \begin{cases} \text{歐氏平行公理}\\ \text{雙曲平行公理}\\ \text{橢圓平行公理}\end{cases}.$$

### 第二條線索：關鍵的「絕對定理」
以下定理**不依賴平行公設**（可用 SAS 相似性 + 外角定理證明）：
1. **垂直性定理**：若兩直角三角形有一直角邊與一角對應相等，則全等
   $$\triangle ABC \cong \triangle ABD \quad\text{（都是直角三角形，} AC=AD,\ \angle C=\angle D\text{）}.$$
2. **外角定理**：三角形外角大於任一不相鄰內角。
3. **邊角不等式**：較長邊對較大角
   $$AB > BC \Rightarrow \angle C > \angle A.$$
4. **內角和不等式**（**絕對幾何的最弱結論**）：
   $$\boxed{\alpha + \beta + \gamma \le \pi \quad\text{（等號當且僅當歐氏）}}.$$
   注意是 $\le$ 而非 $=$——**Bolyai 的核心洞察**。

### 第三條線索：平行公設的三種「故障模式」
Bolyai 用「虛構幾何」的邏輯，證明了平行公設失敗時的**三種情況**：
| 情形 | 內角和 | 例子 |
|------|--------|------|
| （a）互相平行線的「無窮遠」在有限平面內會合 | $=\pi$ | **橢圓幾何**（球面模型，$K>0$） |
| （b）存在兩條以上互不相交（不共點）的「平行」線 | $<\pi$ | **雙曲幾何**（$K<0$） |
| （c）無窮多條互不相交的平行線 | $<\pi$ | 雙曲幾何的一般情形 |
**Bolyai 證明了（b）和（c）互相等价**，且（a）與（b）（c）不等价。

### Python：Bolyai–Gerwien 定理與「剪拼」的判定

```python
from fractions import Fraction
import math

# Bolyai–Gerwien 定理（1832）：兩個面積相等的封閉多邊形可「剪拼」（scissors congruent）
# 這證明了 Hilbert 第三問題（1900）對平面情形為肯定答案

def area_polygon(pts):
    """多邊形面積（Shoelace 公式，有向面積）"""
    A = 0.0
    n = len(pts)
    for i in range(n):
        x1,y1 = pts[i]; x2,y2 = pts[(i+1)%n]
        A += x1*y2 - x2*y1
    return abs(A)/2

# 三角形 3-4-5
tri = [(0,0),(4,0),(0,3)]
# 與其面積相等的長方形 3×2
rect = [(0,0),(3,0),(3,2),(0,2)]

A_tri, A_rect = area_polygon(tri), area_polygon(rect)
print(f"3-4-5 三角形面積 = {A_tri}")
print(f"3×2 長方形面積 = {A_rect}")
print(f"面積相等？{abs(A_tri-A_rect) < 1e-12} → 可剪拼（Bolyai–Gerwien 定理）\n")

# 絕對幾何的核心不等式：內角和 <= π（歐氏取等）
def angle_sum(deg):
    return sum(deg)*math.pi/180

cases = [("雙曲（理想三角形）", (0,0,0)),
         ("雙曲（一般三角形）", (50,60,50)),
         ("歐氏", (60,60,60))]
print("三角形內角和（Bolyai 的核心定理）：")
for name, angles in cases:
    s = angle_sum(angles)
    verdict = "= π (歐氏)" if abs(s-math.pi)<1e-12 else "< π (雙曲/絕對幾何)"
    print(f"  {name:20s}: {angles} → {math.degrees(s):.2f}° {verdict}")
print("\n→ 絕對幾何只給出 ≤ π；等號成立當且僅當平行公設為真\n")

# Bolyai 的雙曲三角餘弦定理（用 Lobachevsky 的形式驗證）
def hyp_cosh_c(a, b, gamma, k=1.0):
    """雙曲餘弦定理：cosh(c/k) = cosh(a/k)cosh(b/k) - sinh(a/k)sinh(b/k)cos(γ)"""
    return k*math.acosh(math.cosh(a/k)*math.cosh(b/k)
                        - math.sinh(a/k)*math.sinh(b/k)*math.cos(gamma))

# 理想三角形（內角和 = 0）：邊長 → ∞
print("雙曲「理想三角形」（3 個角 = 0°，雙曲幾何中遠方的三角形）：")
for L in [1, 2, 5, 10]:
    a = b = hyp_cosh_c(L, L, math.pi/2)   # 兩直角
    print(f"  兩直角邊 = {L}: 第三邊（理想頂點）= {a:.4f}")
print("→ 邊長隨 L → ∞ 趨近無窮：理想三角形是「無限遠」的圖形")
```

## 結案 -- 後果與影響
- **獨立的雙重發現（1829 vs 1832）**：
  Lobachevsky 於 1829 年出版《虛構幾何》，Bolyai 於 1832 年在《附錄》中給出同一套幾何。
  - **Gauss 於 1832 年 3 月致 Farkas Bolyai 的信**：
    > 「我自己在 30 年前（1832 年前）就已經有了這個結論……收到您兒子的論文後，
    > 我感到極大的驚訝——因為他用的方法與我的方法幾乎一致。我準備立即寫信給他。」
  - **Gauss 於 1843 年再致 Bolyai 的信**：
    > 「我必須坦率地說：對您兒子的工作，我無法給出比『極其欽佩』更高的評價……」
  $$\text{Gauss（1832）}: \text{「獨立發明，幾乎完全一致」} \xrightarrow{\text{1940s Hall 發現副本}} \text{世人終於知道}.$$
- **被遺忘 176 年（1832–1908）**：
  Bolyai 的《附錄》長期無人閱讀：**只有 5 本倖存**，
  且沒有被翻譯。**1865 年才被發現有法文譯本**（Samuel Lauritzen 的手稿）。
  **1940 年 George Bruce Halsted** 在《美國數學月刊》（*American Mathematical Monthly*, 1940）
  發表〈Who Killed Cauchy?〉揭露 Bolyai 的優先權，才引起轟動。
- **Tarski 的完美化（1940s）**：
  **Alfred Tarski** 於 1951 年給出「絕對幾何」的**完全形式化**：
  $$\text{絕對幾何} \xrightarrow{\text{Tarski}} \text{一個「可判定」的公理系統（Hilbert 的幾何核心）}.$$
  這是 **Hilbert 1899 幾何公理化（見「1899-希爾伯特幾何基礎.md」）** 的完成版。
- **Bolyai–Gerwien 定理與 Hilbert 第三問題（1832 / 1900）**：
  **Bolyai 與 Gerwien（1852）** 證明：**任意兩個面積相等的平面多邊形可剪拼成全等形狀**。
  - **Hilbert 1900 第三題**：將此推廣至三維——「兩個體積相等的立體可剪拼成全等形狀否？」
  - **1900–1901 的爭議**：Hilbert 與 Dehn 指出，Bolyai–Gerwien 在三維**失敗**——
    例：正八面體體積 = 2 ×（同棱長的正四面體體積），但體積相等卻不可剪拼
    （因為正八面體的「對角面」不可平分，不能剪拼成兩個正四面體）。
    $$\text{3 維剪拼問題（1901，Hilbert 第三問題）}= \text{Dehn（1900）證明不可剪拼 → 答案是否定}.$$
  - 這是**幾何學中「只有一種量（面積/體積）不足以決定全等」的第一個反例**，
    也是 **Dehn 不變量（1900）** 的起源。
- **遺產（2000s）**：
  - **Bolyai 大學（匈牙利 Szeged）**、**Bolyai 街（Budapest）**；
  - **Bolyai–Lobachevsky–Projective Geometry 期刊**；
  - **2014 年《The Absolute Geometry of Bolyai》** 的再版。
- 歷史定位：**Bolyai 的「絕對幾何」是「幾何學的模組化」的第一個案例**——
  它告訴我們，幾何不是單一的學問，而是「核心 + 可插拔公設」的家族。
  $$\text{現代的模組化思維}} \xrightarrow{200\text{ 年}} \text{Bolyai（1832）的「絕對幾何 + 外掛」}}.$$
