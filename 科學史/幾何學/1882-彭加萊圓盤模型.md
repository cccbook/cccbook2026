# 1882 - Poincaré 圓盤模型（非歐幾何終於被「看見」）

## 案件摘要
1881 年 12 月，Henri Poincaré 在提交給法國科学院的備忘錄中，
用一個**圓盤**把雙曲幾何「畫」了出來：
$$\text{雙曲平面} \cong \text{單位圓內部（圓心 = 圓盤模型的「無窮遠」? 反之）}.$$
這是 1600 年來非歐幾何**第一次有了可視的模型**——
在此之前，Lobachevsky 稱它為「虛構幾何」，
因為人們無法想像「三角形內角和小於 180°」的空間。
$$\text{圓盤模型} + \text{精確的度規} \xrightarrow{} \text{雙曲幾何 = 真實的幾何（不是虛構）}.$$

## 前因 -- 為什麼會有這個案子
- **Beltrami 的雙曲面模型（1868）**：
  **Beltrami（1868）**在《歐氏幾何的一致性》（Saggio sopra il sistema pseudo-riemanniano...）
  中首次用**雙曲面模型（hyperboloid model）**顯示非歐幾何的「物理可實現性」：
  $$\text{雙曲面 } x^2 + y^2 - z^2 = -1 \quad \text{的上半部，其度規是雙曲幾何}.$$
- **Gauss 的恐懼（1840s）**：
  Gauss 依然不公開，寫給 Riemann：
  > 「我對『虛幻世界』（mondes fictifs）的長期沉寂，正是我在幾何學上冒險的唯一原因。」
  他擔心的不是數學，而是**宗教與哲學的衝擊**——「非歐世界」動搖了「空間絕對」的世界觀。
- **Poincaré 的解決（1881）**：
  Poincaré（1854–1912，27 歲）是 Poincaré 猜想、 Poincaré 不等式、
  Poincaré 回歸、Poincaré 吸引子的提出者。他的方法：
  $$\text{幾何 = 研究 }\mathbb{C}\text{ 的全純（holomorphic）映射}.$$
  - Poincaré 發現：**所有保角（conformal）映射都是 Möbius 變換**：
    $$f(z) = \frac{az+b}{cz+d},\quad ad - bc \ne 0.$$
  - 這個群**在圓盤內部自同構**，且是**保角（角度保持）**——
    **正是「圓盤內部」上的「等距 + 保角」變換群**！
  $$\text{圓盤的自同構 + Möbius} = \text{雙曲幾何的等距群}.$$
  Poincaré 據此**建立了圓盤模型與上半平面模型**，並在 1881–1882 年的一系列論文中建立雙曲幾何。
- **為什麼「圓盤」重要？**：
  圓盤模型把**無窮遠放在邊界上**——
  **雙曲幾何裡的「無窮遠線」是圓盤的邊界**（不是直線），
  而**圓盤內的直線是「圓弧（通過邊界圓心的圓周）」**：
  $$\text{「直線」} \to \text{連接原點的圓弧}\quad\text{（圓盤模型）}.$$

### 線索與推理 -- 數學式、程式、理論

### 第一條線索：圓盤模型的度規（Poincaré disk）
設 $z = x+iy$，$|z|<1$（單位圓內）。Poincaré 度規：
$$\boxed{ds^2 = \frac{4(dx^2 + dy^2)}{(1 - x^2 - y^2)^2}}$$
或用極座標 $z = r e^{i\theta}$：
$$ds^2 = \frac{4(dr^2 + r^2\,d\theta^2)}{(1-r^2)^2}.$$
- **在邊界 $r\to 1$**：$(1-r^2)^{-2}\to\infty$——**邊界是「無窮遠」**（距離無限）✓
- **在原點 $r\to 0$**：度規 $\to 4(dr^2 + r^2d\theta^2)$——**局部平坦（歐氏）** ✓
- **Gauss 曲率**：$K = -1$（單位曲率的負曲率）。

### 第二條線索：上半平面模型（Poincaré 的另一種形式）
設 $y>0$（上半平面）：
$$\boxed{ds^2 = \frac{dx^2 + dy^2}{y^2}}$$
- $y\to 0$（實軸）：度規 $\to\infty$——**實軸是「無窮遠」** ✓
- $y\to\infty$：度規 $\to 0$——**「天頂」是有限的**！
  **注意**：雙曲空間是**無限大**（面積 $\pi$），但**「高度」有限**。

### 第三條線索：圓盤與上半平面的對應（Möbius 變換）
**Cayley 變換**把圓盤映射到上半平面：
$$\psi(z) = i\,\frac{1+z}{1-z} \quad\Longrightarrow\quad z = \frac{w - i}{w + i}.$$
- 這是 **Möbius 變換**（保角 + 圓盤自同構）——
  **兩種模型完全等價**。

### Python：Poincaré 圓盤模型的度規與等距群

```python
import numpy as np

# 1) Poincaré 圓盤度規
def ds2_disk(x, y, dx, dy):
    """圓盤模型的度規：ds² = 4(dx²+dy²)/(1-x²-y²)²"""
    return 4*(dx**2 + dy**2)/(1 - x**2 - y**2)**2

# 2) 圓盤中的「直線」：通過原點（或邊界圓心）的圓弧
def disk_geodesic_pointwise(t, center=(0,0), radius=0.5):
    """以圓心為 disk 中心、半徑 radius 的圓弧（圓盤模型的「直線」）"""
    return np.array([center[0] + radius*np.cos(t), center[1] + radius*np.sin(t)])

# 3) 圓盤模型的等距群：Möbius 變換 z → (az+b)/(cz+d)
def mobius(z, a, b, c, d):
    return (a*z + b)/(c*z + d)

# 雙曲平移（對數），中心在原點
def hyperbolic_shift(z, a):
    """雙曲平移（沿實軸），保持圓盤不動的等距變換
    T_a(z) = (z + a)/(1 + a*z)  （對單位圓盤）"""
    return (z + a)/(1 + a*np.conj(z))

# 4) 驗證等距性：雙曲平移保持圓盤度規
def disk_dist_integral(p0, p1, n=10000):
    """用數值積分算圓盤中的雙曲距離（沿直線）"""
    p0 = np.array(p0, dtype=complex); p1 = np.array(p1, dtype=complex)
    ts = np.linspace(0, 1, n)
    pts = p0 + (p1 - p0)*ts
    dsz = np.abs(np.diff(pts))
    r2 = np.abs(pts[:-1])**2
    ds = 2*dsz/(1 - r2)    # |dz| 乘以 2/(1-|z|²)
    return np.trapz(ds, ts)

# 5) 驗證：雙曲平移是等距變換
print("Poincaré 圓盤模型的雙曲平移等距性驗證：")
p = 0.3 + 0.1j
q = -0.2 + 0.4j
a = 0.4   # 平移參數
d_orig = disk_dist_integral(p, q)
p2, q2 = hyperbolic_shift(p, a), hyperbolic_shift(q, a)
d_shift = disk_dist_integral(p2, q2)
print(f"  平移前雙曲距離 = {d_orig:.6f}")
print(f"  平移後雙曲距離 = {d_shift:.6f}")
print(f"  誤差 = {abs(d_orig - d_shift):.2e} → 等距 ✓\n")

# 6) 圓盤的「面積」（有限！）
# Poincaré 圓盤的面積元素：dA = 4 dx dy/(1-r²)²
r = np.linspace(0, 0.999, 200000)
dr = r[1]-r[0]
# 面積 = ∫₀^R 2π r * 4/(1-r²)² dr
area = np.trapz(2*np.pi*r*4/(1-r**2)**2, r)
print(f"圓盤 r<0.999 內的面積 = {area:.4f}（π = {np.pi:.4f}）")
print(f"→ 圓盤的面積有限但「邊界無限遠」——雙曲空間是有限體積的無界空間！\n")

# 7) 對照：歐氏圓盤的面積（無限）
print(f"歐氏圓盤 r<0.999 的面積 = {np.pi*0.999**2:.4f}（趨近 0 時趨近 π*0.999²）")
print(f"但歐氏平面無界 → 面積無限")
print(f"雙曲平面：圓盤的面積 = π（Gauss–Bonnet），不依賴半徑！")
```

## 結案 -- 後果與影響
- **非歐幾何的「洗清」**：
  Poincare 的圓盤模型（1881–1882）讓非歐幾何**第一次有了「物理圖像」**——
  圓盤模型是**真的可見的**（地圖模型）。
  $$「\text{虛構幾何}」\xrightarrow{\text{Poincaré 1881}}「\text{雙曲幾何（圓盤模型）}」.$$
- **三體問題的 Poincaré 最後幾何定理（1890）**：
  Poincare 在〈三體問題與天體力學方程〉（1890）中提出：
  $$\text{三體問題的相空間} = \text{三維流形},\quad \text{其中有不可數的「擬週期環面」}\to_{\text{首個}} \text{Poincaré-Birkhoff 定理}.$$
  他證明了**「混沌」的數學語言**（Poincare 對 KAM 定理的貢獻）。
- **相對論的 Poincaré 世界線（1904）**：
  Poincare 提出了**同時性的相對性**、**光速不變性**、**閔考斯基時空圖（1904）**——
  $$ds^2 = -c^2dt^2 + dx^2 + dy^2 + dz^2$$
  **這是非歐幾何（偽黎曼流形）的第一次物理應用**——
  狹義相對論的直接源頭（見 `相對論/1905-狹義相對論.md`）。
- **雙曲結構的深遠應用（1990s–）**：
  1. **Luo's 幾何化（1980s）**、**Thurston 的幾何化猜想（1982）**：3 維流形的「幾何結構」分類——
     $$\text{每個閉曲 3-流形} \to \text{八種幾何之一（} \mathbb{R}^3, S^3, \mathbb{H}^3, \dots \text{）}.$$
  2. **Poincaré 猜想（1904 提出）**：
     $$「\text{任何單連通的閉 3-流形} \cong S^3」\quad\text{（2003 年 Perelman 證明）}.$$
  3. **群論交叉（2007）**：**Cannon 猜想（1970s）**：「若 $S^2$ 的邊界是
     $\mathbb{H}^3$，則它必是雙曲幾何」。
- **「雙曲幾何」的現代科學應用**：
  - **AdS/CFT 對偶（1997, Maldacena）**：反 de Sitter 空間（$\mathrm{AdS}$）是**雙曲幾何**——
    $$\text{AdS 空間} = \text{雙曲幾何的「推廣」} \xrightarrow{\text{AdS/CFT}} \text{弦論 ↔ 場論}}.$$
  - **網路科學（1998, Kleinberg）**：**小世界網路**的**幾何解釋**是**雙曲幾何**！
- 歷史定位：**Poincaré 的圓盤模型是「幾何的第一個圖像」**——
  非歐幾何從「不可見的虛幻」變成「圓盤裡的真實幾何」，
  並在 20 世紀成為**相對論、量子重力、弦論、網路科學的共同語言**。
