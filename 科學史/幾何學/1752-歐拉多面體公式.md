# 1752 - Euler 多面體公式（拓樸的第一道裂縫）

## 案件摘要
1752 年，Leonhard Euler 在解決一個「歌德斯堡問題」時發現了一條驚人的恆等式：
$$\boxed{V - E + F = 2}$$
任何**凸多面體**（不管它有多少面、多少稜、什麼形狀）都滿足這個等式。
這個式子完全不涉及長度、角度、面積——**它是「形狀本身的/topological」性質**：
$$\text{切一個洞、扭一個把手，} V-E+F \text{ 會變。}$$
**這是拓樸學（topology）的第一次開口**——幾何學第一次意識到：
有一類問題**只跟「結構」有關，與「度量」無關**。

## 前因 -- 為什麼會有這個案子
- **Euler 的「正多面體分類」（1730s）**：
  Euler 先證明**只有 5 種凸正多面體**（柏拉圖立體）：
  $$\text{四面體} \quad \text{六面體} \quad \text{八面體} \quad \text{十二面體} \quad \text{二十面體}.$$
  證明的關鍵是：**若每個面是 $p$ 邊形、每個頂點 $q$ 邊相接，則**
  $$V - E + F = 2 \quad \text{（與} p, q \text{ 無關！）}.$$
- **「歌德斯堡問題」（1752）**：
  Euler 與 Lagrange 的通信中，Lagrange 提出一個關於 **城市道路交叉口數目**的問題
  （把多面體「拉平」成平面圖後，計算交叉口數）。Euler 給出 $V - E + F = 2$——
  **這是第一次把三維物體與平面圖統一**。
- **關鍵的直覺（Euler 的偵探）**：
  從「一個球面」出發，用**銳角剖分**（triangulation）逐步「削角」（cut off a vertex）：
  $$\text{削掉一個頂點} \quad\Longrightarrow\quad V \text{ 減 1},\ F \text{ 不變（三角形換三角形）},\ E \text{ 減 2}.$$
  於是 $V - E + F$ 的變化：
  $$(-1) - (-2) + 0 = +1 \quad ???$$
  **Euler 修正**：每削一個頂點，同時把與之相鄰的面也三角化，使得 $V-E+F$ **不變**：
  $$\Delta V = -1,\quad \Delta E = -3,\quad \Delta F = -2 \quad\Longrightarrow\quad \Delta(V-E+F) = -1+3-2 = 0.$$
  **$V-E+F$ 是「削角不變量」**——不變量 = 拓樸量。

### 線索與推理 -- 數學式、程式、理論

### 第一條線索：柏拉圖立體的分類（Euler 1730s）
凸正多面體需同時滿足：
$$\frac{1}{p} + \frac{1}{q} > \frac12 \quad (p \ge 3,\ q \ge 3).$$
- $(p,q)=(3,3)$ → $V=4$：**四面體**
- $(4,3)$ → $V=6$：**六面體**
- $(3,4)$ → $V=8$：**八面體**
- $(5,3)$ → $V=12$：**十二面體**
- $(3,5)$ → $V=20$：**二十面體**
其他所有 $(p,q)$ 都滿足 $\frac1p+\frac1q \le \frac12$ → **不可能**（必須 $\ge$）。

### 第二條線索：Euler 示性數 $\chi$（拓樸量的推廣）
$V - E + F$ 對**曲面**的推廣（用三角剖分）：
$$\chi(M) = V - E + F \quad\Rightarrow\quad \chi(\text{球}) = 2,\quad \chi(\text{圓盤}) = 1,\quad \chi(\text{莫比烏斯帶}) = 0,\quad \chi(\text{環面}) = 0.$$
- **分類定理（1888–1899，Jordan, von Dyck, Heegaard）**：
  閉合**可定向**曲面的 $\chi$ 決定其拓樸型：
  $$\text{可定向閉曲面} \cong \text{類型 } g \quad\Longleftrightarrow\quad \chi = 2-2g \quad (\text{虧格 } g).$$
  虧格 $g=0$（球）、$g=1$（環面）、$g=2$（雙環面）……
- **不可定向**（如莫比烏斯帶、Klein 瓶）：
  $$\chi = 2 - k \quad (k = \text{交叉帽數}).$$
  **Klein 瓶 $\chi = 0$，但不可定向**——說明 $\chi$ 不完整。

### 第三條線索：Euler 特性的拓樸不變性（用「削角」證明）
任何對曲面的**三角剖分**（triangulation）都給出**同一個 $\chi$**：
$$\text{球}: V - E + F = 2 \quad \text{（對任何剖分）}.$$
**削角操作**：把一個頂點 $v$ 連同相鄰三角剖分成一個「星形」再重新三角化——這是**局部操作**。
三角剖分的改變（flip edge）：
$$\text{一個邊翻轉} \quad\Longrightarrow\quad V, F \text{ 不變},\ E \text{ 不變} \quad\Longrightarrow\quad \chi \text{ 不變}.$$

### Python：Euler 公式的驗證與柏拉圖立體分類

```python
import numpy as np
from itertools import product

# 1) 驗證柏拉圖立體的 V, E, F
def platonic(p, q):
    """每面 p 邊、每頂點 q 面相接的正多面體"""
    if 1/p + 1/q <= 0.5: return None    # 幾何上不可能
    # 對稱性公式：由 2E = pF（每面 p 邊）、2E = qV（每頂點 q 稜）、χ = V-E+F = 2 解出：
    F_val = 4*q / (2*p + 2*q - p*q)   # 面數
    V_val = p * F_val / q             # 頂點數
    E_val = p * F_val / 2             # 稜數
    return V_val, E_val, F_val

print("柏拉圖立體分類（Euler 1730s）：")
for p, q, name in [(3,3,"四面體"),(4,3,"六面體"),(3,4,"八面體"),(5,3,"十二面體"),(3,5,"二十面體")]:
    res = platonic(p, q)
    V, E, F = res
    chi = V - E + F
    print(f"  {name:5s} (p={p},q={q}): V={V:.0f}, E={E:.0f}, F={F:.0f}, χ = {chi:.0f}")

# 2) 對流形計算 χ
def euler_char(M, n_vertices, n_edges, n_faces):
    return n_vertices - n_edges + n_faces

print(f"\n各種曲面的 Euler 示性數 χ：")
print(f"  球面 S²:      χ = {euler_char('S2', 12, 30, 20)}  (V=12, E=30, F=20 icosahedron)")
print(f"  圓盤 D²:      χ = 1")
print(f"  莫比烏斯帶:   χ = 0")
print(f"  環面 T²:      χ = 0")
print(f"  球面 #k 個洞: χ = 2-2k")

# 3) 削角操作驗證 χ 不變（用多面體網格表示）
V, E, F = 6, 12, 8
print(f"\n八面體初始: V={V}, E={E}, F={F}, χ={V-E+F}")
# 削掉一個頂點（削角）
V2, E2, F2 = V-1, E-3, F-2
print(f"削掉一個頂點後: V={V2}, E={E2}, F={F2}, χ={V2-E2+F2}  （χ 不變 ✓）")
```

## 結案 -- 後果與影響
- **拓樸學的起源（1895，Cantor）**：
  幾何學第一次出現「距離、角度都無關，只關結構」的分支。
  $$\text{度量化幾何} \xrightarrow{\text{Euler 特徵數}} \text{拓樸幾何}}.$$
- **Euler 公式的深遠後果**：
  1. **數學生物學（Euler–Poincaré 公式）**：任何緊緻可定向三維流形 $M$：
     $$\chi(M) = \frac{1}{2}\left(\sum_{\text{cell}} (-1)^{\dim} f_{\dim}\right)$$
  2. **代數幾何（Euler 示性數）**：代數曲線的 $\chi = 2-2g$。
  3. **物理（Euler–Poincaré 不等式）**：4D時空的量子重力。
- **「柏拉圖立體只有 5 種」的深遠影響**：
  - **晶體學（1886–1892， Schönflies, Fedorov）**：5 種正多面體對應 32 種晶體對稱群。
  - **物理學（1885，Felix Klein）**：歐拉公式揭示的拓樸量與**物理場論的拓樸量子化**相關。
- **拓樸學的黃金時代（1895–1970）**：
  $$\text{Homeo(空間)} \xrightarrow{\text{同胚}} \text{不變量（} \chi, \text{基本群, 同調群）}.$$
  - **Riemann 面**、**基本群（$\pi_1$）**、**同調論**（1920–1930）。
  - **1940s–1970s**：**代數拓樸學**（Serre, Grothendieck）——把拓樸變成代數。
- 歷史定位：**Euler 的 $V-E+F=2$ 是「幾何學通往抽象的第一級台階」**——
  它證明「有些性質只關乎結構，與度量無關」。
  **這條線索最終走到 Riemann（1854，見「1854-黎曼幾何.md」）與 Poincaré（1882，見「1882-彭加萊圓盤模型.md」）**。
