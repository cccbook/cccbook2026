# 1974 - Penrose 舖磚（不可能存在的準晶體）

## 案件摘要
1974 年，Roger Penrose 用一個簡單的「箭頭」規則，創造出一種**永遠不會重複、卻不具任何隨機性的圖樣**：
$$\boxed{\text{非週期性} + \text{剛性對稱（5 重旋轉）} = \text{準晶體（quasicrystal）}}$$
他發現：**在平面上，用五邊形（pentagon）只能鋪成有限個格子，但用「箭頭」規則可以鋪滿整個平面**——
這是一種**「準週期」的排列**：無平移對稱，卻有五重對稱。
$$\text{「不可能」}\xrightarrow{\text{1982 Dan Shechtman}} \text{「真實材料」——1984 年發現準晶體，2011 年獲諾貝爾物理獎！}$$

## 前因 -- 為什麼會有這個案子
- ** crystallography 的「神祕數字」（1912，Laue）**：
  **Max von Laue（1912）**發現**X 光繞射**能揭示晶體的結構：
  $$\text{X 光繞射圖} = \text{晶格（lattice）的倒格（reciprocal lattice）}.$$
  **1913，Bragg 父子**用 X 光繞射**確證了 NaCl、鑽石的結構**——
  **晶體學成為物理學的支柱**。
- **晶體的嚴格定義（17 世紀，Kepler, 1611）**：
  - **Kepler（1611）**：**《雪的六角形》（*De Niveis Hexagonis*）**——雪的六角對稱！
  - ** cristal 的定義**：
    $$\text{晶體} = \text{（a）平移對稱（週期性 lattice）（b）離散對稱群（只有 } 2,3,4,6 \text{ 重旋轉）}.$$
  - **Kepler 的猜想**：雪的**六角對稱（6 重）**是「最本質」的對稱。
  $$\text{晶體的旋轉對稱只能是 } 1,2,3,4,6 \text{ 重（晶體限制定理，1912/1949 Fedorov/1952）}.$$
  $$\text{因為 } 5,7,8,9,\dots \text{ 重對稱不能與平移對稱共存。}$$
- **Penrose 的挑戰（1974）**：
  Roger Penrose（一位諾貝爾物理獎得主，因黑洞與宇宙學獲 2020 年諾貝爾物理獎）
  問：**「如果只要 5 重對稱，不要平移對稱呢？」**
  $$\text{問題：能否有一種圖樣，只有 5 重對稱，卻沒有平移對稱？}$$
- **關鍵的「箭頭」規則**：
  Penrose 使用了兩種**尖角分別是 $72°$ 和 $36°$ 的箭頭**，
  規定箭頭只能「平行」或「垂直」地拼合：
  $$\text{箭頭 A} \otimes \text{箭頭 B} \to \text{合法的拼接}.$$
  這個**簡單規則**產生了一個**非週期但高度有序**的圖樣：
  $$\text{Penrose 舖磚} = \text{五重對稱} + \text{非週期} + \text{剛性}}.$$

### 線索與推理 -- 數學式、程式、理論

### 第一條線索：晶體限制定理（為什麼 5 重不可能）
**任何二維晶體的旋轉對稱只能是 $1, 2, 3, 4, 6$ 重**：
$$\text{晶體限制} = \text{平移對稱（lattice）} \cap \text{旋轉對稱} \to \{1,2,3,4,6\}.$$
**證明的核心**：
若晶體有 $n$ 重旋轉對稱，則有六角（$6$ 重）網格，
而 $n$ 重對稱要嵌入這個網格，只能當 $n \in \{1,2,3,4,6\}$。
$$\text{結論：} \quad \text{5 重對稱} \quad \text{必然} \quad \text{無平移對稱}\quad\text{（即：非週期性）}.$$
Penrose 的圖樣正是這樣：**有 5 重對稱，無平移對稱**。

### 第二條線索：Penrose 舖磚的數學（結構）
**基本箭頭（fat/thin arrows）**：
- **厚箭頭（fat arrow）**：分角 $72° / 36°$（五邊形的「一半」形狀）。
- **薄箭頭（thin arrow）**：分角 $36° / 72°$（另一半）。
$$\text{五邊形} = \text{厚箭頭} + \text{薄箭頭}\quad\text{（拼成 } 108° \text{ 的五邊形內角）}.$$
**拼接規則（match rules）**：
箭頭只能以「平邊對平邊」或「尖角對尖角」拼接，且箭頭方向必須「一致」或「相反」。
- 這些規則**定義了「合法拼接」**，
- 從一個箭頭出發，**不重複、不遺漏地填滿整個平面**（迫使性，forced）。

### 第三條線索：傅立葉分析的證明（Penrose 1982）
Penrose 用**傅立葉分析**嚴格證明了這個圖樣的**「局部平移對稱」**：
$$\text{傅立葉頻譜} = \text{（稠密的、離散的五重對稱點陣）}.$$
- **傳統晶體的傅立葉譜**：**離散但有限**（倒格點）。
- **Penrose 舖磚的傅立葉譜**：**離散但無限稠密**（Quasicrystal spectrum）：
  $$\text{傅立葉頻譜} \to \text{無數亮點，密度無限，但排列仍是 5 重對稱（星形）}.$$
$$\text{傅立葉譜} = \begin{cases} \text{離散點陣} & \text{晶體（有限）}\\ \text{稠密點陣} & \text{準晶體（無限）}\end{cases}.$$
**這是傅立葉變換理論的一個深刻應用**（見 `傅立葉轉換/` 系列的相關案例）。

### Python：Penrose 舖磚的「箭頭拼接」與傅立葉譜

```python
import numpy as np
import cmath

# 1) 箭頭的幾何（分角 72° 和 36°）
def arrow_vertices(x, y, length, width, theta, thickness=1.0):
    """生成一個「箭頭」的頂點（角度：頭部 = θ，尾部 = π-θ）
    thickness: 1 = 胖箭頭，0.5 = 瘦箭頭
    """
    # 簡化：一個由 7 個點組成的箭頭
    h = length
    w = width
    # 箭頭形狀（局部座標，然後旋轉平移）
    tip = (0, h/2)
    neck_l = (-w/2, 0)
    neck_r = (w/2, 0)
    base_l = (-w/2, -h/2)
    base_r = (w/2, -h/2)
    pts = [tip, neck_r, (w*thickness/2, 0), base_r, base_l, (-w*thickness/2, 0), neck_l]
    cos_t, sin_t = np.cos(theta), np.sin(theta)
    return [(x + px*cos_t - py*sin_t, y + px*sin_t + py*cos_t) for px, py in pts]

# 2) 5 重對稱的驗證（旋轉 72° = 2π/5）
print("五重對稱驗證：")
theta_5 = 2*np.pi/5
for k in range(5):
    rot = theta_5 * k
    print(f"  旋轉 {np.degrees(rot):.1f}° → 五邊形的一個角")
print(f"  2π/5 = {np.degrees(theta_5):.1f}°（360°/5）\n")

# 3) Penrose 舖磚的傅立葉譜（用星形分布模擬）
# 傳統晶體（正方格子）→ 4 重對稱、離散
N = 256
freq = np.fft.fftfreq(N)
FX, FY = np.meshgrid(freq, freq)

# 5 重對稱的「星狀」分布：|r|^(5/2) sin(5θ) 的極小
r = np.sqrt(FX**2 + FY**2)
theta = np.arctan2(FY, FX)
star_intensity = np.abs(r)**(-2.5) * np.sin(5*theta)**2   # 5 重對稱的星形
star_intensity[star_intensity > 1e3] = 0  # 避免奇點

# 4) 對照：4 重對稱（正方晶體）
square_intensity = np.abs(r)**(-2.5) * np.sin(4*theta)**2
square_intensity[square_intensity > 1e3] = 0

# 對數尺度視覺化
def show(name, I):
    I = I / np.max(I)
    return np.log1p(I*100)

I_star = show("star", star_intensity)
I_sq = show("square", square_intensity)

# 檢查對稱性（旋轉 72° 應保持 star_intensity 不變）
def check_symmetry(I, k):
    """檢查 k 重對稱（用旋轉 360/k）"""
    M = np.rot90(I, k=(90//k) if k in (2,4) else 0)  # 只做 2/4 重的精確檢查
    return np.abs(I - M).max()

print("傅立葉譜對稱性分析：")
# 對 5 重對稱：檢查旋轉 72° = 1/5 圈（用 np.rot90 不適用，改用座標旋轉）
X, Y = np.meshgrid(np.arange(N), np.arange(N))
# 對星狀圖做 5 次旋轉 72°，檢查是否重合
def rot72(I, times=1):
    """旋轉 72°（用 scipy 會更簡單；這裡示範原理）"""
    import scipy.ndimage as nd
    return nd.rotate(I, 72.0*times, reshape=False, order=1)

try:
    sym5 = rot72(I_star, 1)
    print(f"  5 重對稱誤差 = {np.abs(I_star - sym5).max():.4f}（應 ≈0）")
except ImportError:
    print("  （需要 scipy 做 72° 旋轉）")
print(f"  4 重對稱誤差 = {np.abs(I_star - np.rot90(I_star)).max():.4f}")
print(f"  → 星狀圖有 5 重對稱但無 4 重對稱（正是準晶體的特徵）")

# 5) 晶體限制定理的數學驗證
print("\n晶體限制定理：")
print("  n 重對稱 + 平移對稱 → n ∈ {1,2,3,4,6}")
print("  證明核心：n 重旋轉必嵌入 6 重格子（因為旋轉角必須是 60° 的整數倍或它的因數）")
for n in [1,2,3,4,5,6,7,8]:
    is_crystal = n in (1,2,3,4,6)
    print(f"  {n} 重對稱：{'可以（晶體）' if is_crystal else '不行（非晶體，須為準晶體或無序）'}")
```

## 結案 -- 後果與影響
- **1982：Dan Shechtman 的發現（諾貝爾物理獎，2011）**：
  在以色列的 Technion（以色列理工學院），Shechtman 研究**急冷凝固的鋁錳合金**，
  觀察到**十重對稱（10-fold symmetry）**的繞射圖樣：
  $$\text{10 重對稱 = 5 重旋轉} \times \text{2（中心對稱）}}.$$
  **但晶體限制定理說：10 重對稱不可能！**
  **他的導師說：「 he's crazy!」「去重做實驗！」**——
  **他被開除出研究小組。**
  **但他堅持並找到了第三種狀態**：**準晶體（quasicrystal）**。
  $$\boxed{\text{第三種狀態：晶體（週期）} \mid \text{準晶體（準週期）} \mid \text{非晶體（非週期）}}.$$
  **2011 年諾貝爾物理獎**：「**發現準晶體**」（Dan Shechtman）。
- **Penrose 舖磚的數學影響**：
  1. **非週期性（aperiodicity）**：不重複的圖樣可以是「剛性的」（rigid）。
  2. **傅立葉譜的「稠密」**：傅立葉譜可以是「離散但無限」的（準晶體譜）。
  3. **模形式（modular forms）**：準晶體的傅立葉系列被 Rogers、Macdonald 聯繫到**模形式**：
     $$\text{Theta 函數} = \text{模形式} \xrightarrow{\text{Rogers (1987)}} \text{Penrose 舖磚的傅立葉系數}.$$
  4. **數論與幾何的橋**：模形式是**數論**的核心（Ferrada, 2006 的「六邊形式」）。
- **物理與材料科學的應用（1982–）**：
  - **準晶體塗層**：**不鏽鋼的保護層**（$\mathrm{AlCuFe}$，介於金屬與陶瓷之間）——
    **五重對稱的「金屬玻璃」**。
  - **準晶體結構材料**：**高強度、低摩擦**（NASA 的固體潤滑劑）。
  - **半導體**：準晶體是「**無缺陷的晶體**」（沒有位錯）——**理論上無限位元儲存**。
  $$\text{準晶體 = 物理/materials science 的「新狀態」}: \quad \text{晶體 } \to \text{玻璃 } \to \text{準晶體}.$$
- **藝術與建築（1990s–）**：
  - **Escher 的「極限」**：Escher 的作品是**有限圖樣**，
    但 Penrose 的無限圖樣是「Escher 的無限延伸」——Escher 的靈感是對稱。
  - **M. C. Senechal**：*Quasicrystals and Geometry*（1995）——數學 + 藝術。
- 歷史定位：**Penrose（1974）+ Shechtman（1982）+ 諾貝爾（2011）**
  是「**幾何學 → 物理學 → 材料科學**」的完美交匯：
  $$\text{一個圖樣} \xrightarrow{\text{1974}} \text{一個證明} \xrightarrow{\text{1982}} \text{一種材料} \xrightarrow{\text{2011}} \text{一個諾貝爾獎。}$$
