# 1829 - Lobachevsky 非歐幾何（平行公設的死亡證明）

## 案件摘要
1829 年，44 歲的俄羅斯喀山的 Nikolai Lobachevsky 出版了《虛構幾何》（*Imaginäre Geometrie*）——
第一份**完整的非歐幾何論著**：
$$\text{三角形內角和} < \pi \quad\text{（而不是等於）}.$$
他花了 30 年經營一套「虛構幾何」——一個平行公設不成立的空間，
裡面有三角、余弦定理、圓周率，面面俱到。
$$\text{平行公設不成立} \xrightarrow{\text{仍有一致的幾何}} \text{歐氏幾何不是唯一的}.$$
**這是「歐氏幾何之外還有別的世界」的第一次嚴格證明**——
兩千年來「證明平行公設」的整個研究議題，在 Lobachevsky 這裡被徹底翻轉。

## 前因 -- 為什麼會有這個案子
- **兩千年的失敗史（Euclid → Gauss）**：
  - **Saccheri（1733）**：假設「銳角三角形內角和 > 90°」為公設，試圖推出矛盾（歸謬法）。
  - **Lobachevsky（1826–1829）**：假設「銳角三角形內角和 < 90°」，發現**沒有矛盾**——
    反而得到一套自洽的幾何。
  - **Bol（1800s）**：Saccheri 的錯誤學說（銳角假設），自認「企圖證明的事實上錯誤」。
- **Gauss 的沉默（1830s）**：
  Gauss 在 1830 年私下寫信給天文學家 Schumacher：
  > 「我慢慢地......開始相信，一旦認識到簡單的、始終如一地應用的『無窮平面的非歐幾何』時，
  > 我們就能有另一種完全合理的幾何。」
  Gauss 的懼怕：**發表非歐幾何會被認為是瘋子、被嘲弄**。
- **Lobachevsky 的孤獨（1804–1856）**：
  - 1804 年起在喀山大學教學，他把幾何學教材全部改成「非歐幾何」。
  - 出版三本著作：**1829《虛構幾何》、1834《虛幻的度量法》、1838《Imaginary Geometry》**。
  - 同時代幾乎無人理解；**他的同事 Schmoller 譏諷他的幾何是「冥想家的夢幻」、「廢紙」**。
  $$\text{Lobachevsky（1792–1856）} \xrightarrow{\text{30 年孤獨研究}} \text{1940 年代被重新發現（Poincaré, Cartan）}.$$
- **同期：Saccheri 的「三假設」與非歐三角（1826，Johann von Schweikart）**：
  「Schweikart 平行性」的提案：假設「三角形內角和 < 180°」——但沒有發表系統化。

### 線索與推理 -- 數學式、程式、理論

### 第一條線索：三角形內角和定理（非歐幾何的核心實驗）
在**歐氏幾何**：
$$\alpha + \beta + \gamma = \pi \quad (180°).$$
在 **Lobachevsky（雙曲）幾何**：
$$\boxed{\alpha + \beta + \gamma < \pi}$$
- 角度愈大（愈接近「歐氏」）→ 和愈接近 $\pi$。
- 角度愈小 → 和愈小（可任意接近 0）。
- **關鍵**：兩者都是**內部一致的（consistent）**——矛盾不存在。

### 第二條線索：雙曲餘弦定理（Lobachevsky 的 Cosine Law）
歐氏的餘弦定理：$c^2 = a^2+b^2-2ab\cos\gamma$。
**Lobachevsky 的雙曲版本**（邊長 $c$ 對應角 $\gamma$）：
$$\cosh\left(\frac{c}{k}\right) = \cosh\left(\frac{a}{k}\right)\cosh\left(\frac{b}{k}\right)
- \sinh\left(\frac{a}{k}\right)\sinh\left(\frac{b}{k}\right)\cos\gamma.$$
其中 $k>0$ 是**曲率半徑參數**。
- $k\to\infty$（極限）：$\cosh(x)\approx 1+x^2/2$，$k\to\infty$ 使 $\cos\gamma$ 項消失 → **還原歐氏餘弦定理**。
- $k$ 越小 → 「非歐-ness」愈強。
- **$k$ 為無窮大時，雙曲幾何退化成歐氏幾何**——這是非歐幾何的**極限觀點**。

### 第三條線索：Lobachevsky 的面積公式
**歐氏幾何**（三角形面積）$A = \frac{1}{2}ab\sin\gamma$。
**Lobachevsky 的雙曲面積**：
$$\boxed{A = k^2\left[\pi - (\alpha+\beta+\gamma)\right]}$$
- **直接可測**：$k^2$ 是絕對常數，$\pi - \Sigma$ 就是**「角度虧損」（angular defect）**。
- **歐氏的極限**：$k\to\infty$，$A\approx k^2\pi - k^2\Sigma$ → 無限，與歐氏面積無直接對應，
  但**角度虧損 $\pi - \Sigma$ 是雙曲幾何的量度**。
- **現代鏈接**：Gauss–Bonnet 定理（1827, Chern, 1944）：
  $$\int_K dA + \sum \text{外角} = 2\pi\chi(M)$$
  Lobachevsky 的面積公式是它的**三角形特例**。

### Python：雙曲幾何 vs 歐氏幾何的數值對照

```python
import math

# 1) Lobachevsky 餘弦定理：求邊 c
def hyperbolic_c(a, b, gamma, k=1.0):
    """雙曲幾何：已知兩邊 a,b 與夾角 gamma（弧度），求第三邊 c
    cosh(c/k) = cosh(a/k)cosh(b/k) - sinh(a/k)sinh(b/k)cos(gamma)
    """
    cosh_c = math.cosh(a/k)*math.cosh(b/k) - math.sinh(a/k)*math.sinh(b/k)*math.cos(gamma)
    return k * math.acosh(cosh_c)

def euclidean_c(a, b, gamma):
    """歐氏幾何：餘弦定理"""
    return math.sqrt(a*a + b*b - 2*a*b*math.cos(gamma))

# 2) 對照：固定角，三邊關係
print("兩邊 a=b=1，夾角 γ 的對照：")
print(f"{'γ(°)':>6s} {'c(歐氏)':>10s} {'c(雙曲 k=1)':>14s} {'c(雙曲 k=0.5)':>16s}")
for deg in [30, 60, 90, 120, 150]:
    g = math.radians(deg)
    ce = euclidean_c(1, 1, g)
    ch1 = hyperbolic_c(1,1,g,k=1.0)
    ch05 = hyperbolic_c(1,1,g,k=0.5)
    print(f"{deg:6d} {ce:10.4f} {ch1:14.4f} {ch05:16.4f}")

# 3) 面積公式：角度虧損
def hyperbolic_area(k, alpha, beta, gamma):
    """Lobachevsky：面積 = k² × (π - 角度和)"""
    return k*k*(math.pi - (alpha+beta+gamma))

# 構造一個雙曲三角形：兩直角 + 第三角 γ
print("\n雙曲直角三角形的面積（k=1）：")
for deg in [30, 45, 60, 80]:
    g = math.radians(deg)
    a = hyperbolic_c(1, 1, g, k=1)   # 兩直角邊
    A = hyperbolic_area(1, math.pi/2, math.pi/2, g)
    print(f"  直角+直角+{deg}°：角度和 = {(math.pi-g)*180/math.pi:.2f}°，面積 = {A:.4f}")

# 4) 極限：k→∞ 回到歐氏
print("\n極限驗證 k→∞（應回到歐氏餘弦定理）：")
a, b, g = 1.0, 1.0, math.radians(60)
for k in [0.1, 1.0, 10.0, 1000.0]:
    ch = hyperbolic_c(a,b,g,k=k)
    print(f"  k={k:8.1f}: c = {ch:.6f}")
print(f"  歐氏值 c = {euclidean_c(a,b,g):.6f}")
```

## 結案 -- 後果與影響
- **「虛構幾何」改為「雙曲幾何」（1900s 的科學界）**：
  1930s 之後，「非歐幾何」被正名為**雙曲幾何**（hyperbolic geometry），
  Lobachevsky 稱它為「虛構的」是因為它「無法在圖上畫」。
  $$\text{Lobachevsky（虛構幾何）} \xrightarrow{\text{1910s}} \text{雙曲平面} \xrightarrow{\text{1882 Poincaré}} \text{圓盤模型（看見它）}.$$
- **第二次非歐幾何革命（Bol、Gauss、Bolyai, 1832）**：
  - **Bolyai（1832，附於父親 Bol 的著作）**：獨立發現同一套幾何；
  - **Gauss（1832，私下稱「和 Bol 的推導幾乎一致」）**；
  - Lobachevsky 的幾何在 1940 年被確認為**唯一性**的（Beltrami, Klein）。
- **20 世紀的震撼（1905–1916）**：
  - **Einstein（1905，狹義相對論）**：「我設想時間可能不存在。」
  - **Minkowski（1908）**：「時間是第四個維度。」
  $$\text{相對論} \xrightarrow{\text{必然}} \text{非歐時空（Lorentz 幾何，hyperbolic signature）}.$$
  狹義相對論的**同時性相對**正是**雙曲幾何（Minkowski 時空）**的直覺。
- **極限 $k\to\infty$ 的物理意義**：
  Einstein 的 **GR（1915）**的**弱場極限** 就是「曲率半徑 $k\to\infty$ 的雙曲空間」：
  $$\text{GR 的弱場} \approx \text{歐氏空間} \xrightarrow{\text{微擾}} \text{雙曲幾何（曲率 } 1/k^2 \text{）}.$$
- **Lobachevsky 的榮譽**：
  - 他的名字被用於 **Lobachevsky 天文台**（喀山大學，1995）；
  - **1992 年**，喀山舉辦「Lobachevsky 200 週年」國際會議；
  - **1994 年**，行星 **(6564) Takoyaki** 與 **(6565) Reiji** 被命名以紀念；
  - 喀山大學主樓前的「**Lobachevsky 三角座雕像**」——他發表的非歐幾何「宇宙學」隱喻。
- 歷史定位：**Lobachevsky 證明了「歐氏幾何不是唯一」**——
  這是「現代物理學與數學的宇宙觀」的起點。
