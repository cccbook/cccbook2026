# 1916 - Einstein 廣義相對論（黎曼幾何成為物理學）

## 案件摘要
1915 年 11 月 25 日，**Albert Einstein（1879–1955）** 在普魯士科學院
發表了**重力場方程**的最終形式：
$$\boxed{G_{\mu\nu} = R_{\mu\nu} - \frac12 R g_{\mu\nu} = \frac{8\pi G}{c^4} T_{\mu\nu}}$$
一句話概括：
> 「**物質告訴時空如何彎曲，時空告訴物質如何運動。**」

這是**黎曼幾何（1854）第一次成為物理學的核心**——
重力不再是「力」，而是**時空的曲率**。
$$\text{Gauss（1827）：內在幾何} \to \text{Riemann（1854）：n 維度規} \to \text{Einstein（1915）：物理現實}.$$
1916 年，**Schwarzschild** 在戰壕裡解出第一個精確解；同年 Einstein 發表
《廣義相對論的基礎》（*Die Grundlage der allgemeinen Relativitätstheorie*）——完整總結。

## 前因 -- 為什麼會有這個案子
- **牛頓重力的「缺陷」（1687–1905）**：
  Newton 的萬有引力 $F = GMm/r^2$ 有兩個問題：
  1. **超距作用**：重力「瞬間」傳播——但狹義相對論（1905）禁止任何超光速影響；
  2. **慣性質量 = 重力質量**（Eötvös 實驗，1889，精度 $10^{-9}$）——
     **為什麼兩種質量完全相等？牛頓理論沒有解釋！**
  $$\text{慣性質量（抵抗加速）} = \text{重力質量（被吸引）}\quad\text{（實驗事實，無解釋）}.$$
- **Einstein 的「最快樂的想法」（1907）**：
  Einstein 在專利局（伯恩）工作時，突然想到：
  > 「如果一個人從屋頂自由落下，他在落下時**感覺不到自己的重量**——
  > 這是我一生中最快樂的想法。」
  $$\boxed{\text{等效原理：自由落下 } = \text{無重力（局部）}}$$
  **推論**：重力可以被「座標變換」消除（局部）——
  **重力不是力，是時空幾何的性質**。
- **Grossmann 的救援（1912）**：
  Einstein 回到蘇黎世（ETH），向大學同學 **Marcel Grossmann**（數學教授）求救：
  > 「Grossmann，你必須幫我，否則我會瘋掉！」
  Grossmann 介紹他讀 **Riemann 幾何與 Ricci 張量**——
  Einstein 花了三年（1912–1915）學習黎曼幾何。
- **三年的錯誤（1912–1915）**：
  Einstein 與 Grossmann 1913 年的「草稿理論」（Entwurf）用了錯誤的場方程；
  **Hilbert（1915 年 11 月 20 日）** 用變分法率先寫出正確形式——
  **Einstein 落後 Hilbert 四天**（但兩人互相獨立）。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：等效原理與測地線
**等效原理**：重力場中自由落體的運動 = 無重力時空的**慣性運動**。
$$\text{自由落體的軌跡} = \text{時空的測地線（geodesic）}.$$
**測地線方程**：
$$\frac{d^2 x^\mu}{d\tau^2} + \Gamma^\mu_{\nu\rho}\frac{dx^\nu}{d\tau}\frac{dx^\rho}{d\tau} = 0$$
- $\Gamma^\mu_{\nu\rho}$（Christoffel 符號）= 聯絡係數——
  **這就是「重力」在方程式裡的位置**！
  $$\boxed{\text{重力 = 聯絡（不是力）}}$$

### 第二條線索：場方程的幾何結構
**愛因斯坦張量**：
$$G_{\mu\nu} = R_{\mu\nu} - \frac12 R g_{\mu\nu}$$
- $R_{\mu\nu}$（Ricci 張量）：曲率的「壓縮」；
- $R$（純量曲率）：曲率的「總和」；
- $T_{\mu\nu}$：物質的能量-動量張量。
**關鍵性質（Bianchi 恆等式的推論）**：
$$\nabla^\mu G_{\mu\nu} = 0 \quad\text{（自動守恆）}$$
**這是場方程「正確」的數學理由**——
愛因斯坦張量**自動滿足守恆律**，與物質的守恆律匹配。

### 第三條線索：三大實驗驗證（1919）
1. **水星近日點進動**（每百年 43 角秒的異常）——廣義相對論精確解釋；
2. **光線偏折**（**Eddington, 1919 年 5 月 29 日日食**）：
   $$\theta = \frac{4GM}{c^2 R_\odot} \approx 1.75\ \text{角秒}$$
   觀測結果 1.61–1.98 角秒——**廣義相對論一夜成名**；
3. **重力紅移**（光從重力場中逃出時波長變長）——1925 年被 Pound–Rebka 精確驗證（1959）。

import numpy as np

# 1) Schwarzschild 度規（1916，第一個精確解）
def schwarzschild_interval(t, r, theta=0, phi=0, M=1.0, c=1.0, G=1.0):
    """ds² = -(1-r_s/r)c²dt² + (1-r_s/r)⁻¹dr² + r²dΩ²，r_s = 2GM/c²"""
    r_s = 2*G*M/c**2
    f = 1 - r_s/r
    return -f*c**2*t**2 + r**2  # 簡化（只看 t-r 平面）

print("Schwarzschild 半徑：")
for M_name, M in [("地球", 5.97e24), ("太陽", 1.99e30), ("黑洞（10 M☉）", 1.99e31)]:

    r_s = 2*G*M/c**2

# 2) 水星近日點進動（每百年 43 角秒）
print("\n水星近日點進動：")
# 進動公式：Δφ = 6πGM/(c²a(1-e²)) per orbit
G, c = 6.674e-11, 3e8
M_sun = 1.99e30
a = 5.79e10      # 水星半長軸
e = 0.2056       # 離心率
T_orbit = 88.0   # 天
dphi_per_orbit = 6*np.pi*G*M_sun / (c**2 * a * (1-e**2))
dphi_per_century = dphi_per_orbit * (100*365.25/T_orbit) * 206265  # 轉角秒
print(f"  每軌道進動 = {dphi_per_orbit*206265:.6f} 角秒")
print(f"  每百年進動 = {dphi_per_century:.2f} 角秒（觀測值 43）")
print("  → 廣義相對論精確解釋了牛頓理論的 43 角秒異常 ✓")

# 3) 光線偏折（太陽附近）
print("\n光線偏折（Eddington 1919）：")
R_sun = 6.96e8   # 太陽半徑
theta_deflection = 4*G*M_sun / (c**2 * R_sun) * 206265
print(f"  理論偏折角 = {theta_deflection:.2f} 角秒")
print(f"  觀測值（1919 Eddington）= 1.61–1.98 角秒")
print(f"  牛頓理論（粒子說）預測 = {theta_deflection/2:.2f} 角秒（只有一半！）")
print("  → 1919 年日食觀測支持廣義相對論 ✓")

# 4) 重力時間膨脹（GPS 的基礎）
print("\n重力時間膨脹（dτ/dt = √(1-r_s/r)）：")
G, c = 6.674e-11, 3e8
M_earth = 5.97e24
r_s_earth = 2*G*M_earth/c**2
for r_name, r in [("地表（6371 km）", 6.371e6), ("GPS 衛星（20200 km）", 2.02e7)]:
    factor = np.sqrt(1 - r_s_earth/r)
    print(f"  {r_name}: dτ/dt = {factor:.12f}")
# 地表 vs 衛星的時鐘差
dt_surface = 1 - np.sqrt(1 - r_s_earth/6.371e6)
dt_gps = 1 - np.sqrt(1 - r_s_earth/2.02e7)
# GPS 衛星時鐘：重力效應每天快 45.7 μs，狹義相對論（速度）慢 7.2 μs → 淨快 38.5 μs
print(f"  → 衛星時鐘每天淨快約 38 μs（重力 +45.7 − 速度 7.2）")

## 結案 -- 後果與影響
- **1919 年的一夜成名**：
  $$\text{1915 場方程} \xrightarrow{\text{1919 日食}} \text{Einstein 成為世界名人}.$$
  **Eddington 的日食觀測**（普林西比島與索布拉爾）把廣義相對論
  從「德國數學家的抽象理論」變成「**世界的新聞頭條**」——
  **這是科學史上第一次「理論物理學家成為文化偶像」**。
- **Schwarzschild 的戰壕奇蹟（1916）**：
  **Karl Schwarzschild** 在第一次世界大戰的東線戰壕裡（俄國前線），
  讀到 Einstein 的論文，**幾個月內**解出了第一個精確解——
  這個解預言了**黑洞（black hole）**的存在：
  $$r_s = \frac{2GM}{c^2} \quad\text{（事件視界）}$$
  Schwarzschild 在完成論文後不久（1916 年 5 月）死於戰場上的天皰瘡，年僅 42 歲。
- **黑洞的世紀（1916–2019）**：
  - **1939**：Oppenheimer–Snyder 證明恆星塌縮成黑洞；
  - **1967**：Wheeler 命名「黑洞」；
  - **1974**：**Hawking 輻射**——黑洞不是全黑的（量子效應）；
  - **2015**：**LIGO 偵測到重力波**（兩個黑洞合併，2017 諾貝爾物理獎）；
  - **2019**：**EHT 拍到第一張黑洞照片**（M87 的中心）。
  $$\text{Schwarzschild（1916）：數學解} \xrightarrow{} \text{LIGO（2015）：重力波} \xrightarrow{} \text{EHT（2019）：照片}.$$
- **宇宙學的誕生（1917–）**：
  Einstein 1917 年把場方程應用到**整個宇宙**：
  - **Friedmann（1922）**、**Lemaître（1927）**：宇宙在膨脹；
  - **1929**：**Hubble 的觀測**證實宇宙膨脹；
  - **大爆炸宇宙學（1948–）**：宇宙有一個起點——
    **這全部是黎曼幾何 + 場方程的推論**。
- **GPS 與日常應用（1970s–）**：
  $$\boxed{\text{每天你用手機導航，都在用廣義相對論}}$$
  衛星時鐘的重力效應（快 45.7 μs/天）與速度效應（慢 7.2 μs/天）
  淨效應快 38 μs/天——不校正則每天累積 10 公里誤差。
- **幾何學史的意義**：
  $$\boxed{\text{黎曼幾何（1854）} \xrightarrow{\text{Einstein（1915）}} \text{物理學的核心語言}}$$
  **「幾何」從此不再是純數學的遊戲，而是物理現實的骨架**——
  我們就住在彎曲的四維偽黎曼時空裡。
  $$\text{Gauss（1827）} \to \text{Riemann（1854）} \to \text{Minkowski（1908）} \to \text{Einstein（1915）}.$$
