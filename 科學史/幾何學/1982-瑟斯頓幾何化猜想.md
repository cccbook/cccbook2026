# 1982 - Thurston 幾何化猜想（三維空間的完整地圖）

## 案件摘要
1982 年，**William Thurston（1946–2012）** 在《美國數學學會公報》發表
*Three-dimensional manifolds, Kleinian groups, and hyperbolic geometry*，
提出了一個比龐加萊猜想**更大、更完整**的猜想：
$$\boxed{\text{每個閉三維流形都能被「切割」成八種幾何結構的有限組合}}.$$
**龐加萊猜想只是它的特例**——若三維流形被切成 8 種幾何的碎片，
單連通的流形只能用 $S^3$，猜想即得。
$$\text{龐加萊（1904）} \subsetneq \text{Thurston（1982）} \xrightarrow{\text{Perelman（2003）}} \text{全部證明}.$$

## 前因 -- 為什麼會有這個案子
- **二維的完整分類（1868–1888）**：
  二維閉曲面的分類早已完成：
  $$\text{二維閉曲面} = \text{球面 } S^2\ \text{或}\ \text{虧格 } g \text{ 的環面（} g\ge 1\text{）}.$$
  且**每一個二維曲面都有常數曲率的度規**（uniformization 定理，1907）：
  $$K > 0\ (S^2),\qquad K = 0\ (g=1),\qquad K < 0\ (g\ge 2).$$
  $$\boxed{\text{二維：一種曲率就夠了}}$$
- **三維的「災難」（1900s–1970s）**：
  三維流形**沒有這麼簡單**：
  - 三維環面 $T^3$ 的「洞」比二維環面複雜得多（$\pi_1(T^3) = \mathbb{Z}^3$）；
  - 三維流形的同倫類**爆炸性地多**（Dehn 引理、透鏡空間、纖維叢……）。
  $$\text{二維：虧格一個數字決定一切};\qquad \text{三維：無限多種「洞」}.$$
- **Thurston 的洞察（1970s）**：
  Thurston 在普林斯頓的課堂與研討會上（1976–1980）提出：
  > 「三維流形雖然不能用『一種』幾何，但可以用『八種』幾何的有限組合。」
  **八種幾何**：$\mathbb{R}^3$、$S^3$、$\mathbb{H}^3$、$S^2\times\mathbb{R}$、
  $\mathbb{H}^2\times\mathbb{R}$、$\widetilde{SL_2(\mathbb{R})}$、Nil、Sol。
- **Mostow 剛性（1968）**：**雙曲幾何的「完全剛性」**——
  $$\boxed{\text{雙曲流形的同構 ⟹ 等距（isometry）}}$$
  這是三維雙曲幾何的「奇蹟」：**拓樸完全決定幾何**。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：八種三維幾何
Thurston 的**八種模型幾何**：
| 幾何 | 模型 | 曲率 | 例子 |
|------|------|------|------|
| $\mathbb{R}^3$ | 歐氏空間 | 0 | 三維環面 $T^3$ |
| $S^3$ | 球面 | + | 龐加萊同調球面 |
| $\mathbb{H}^3$ | 雙曲空間 | − | 結補空間（knot complements） |
| $S^2\times\mathbb{R}$ | 球面×直線 | + | $S^2\times S^1$ |
| $\mathbb{H}^2\times\mathbb{R}$ | 雙曲×直線 | − | 雙曲纖維叢 |
| $\widetilde{SL_2(\mathbb{R})}$ | 通用覆蓋 | − | 單位切叢 |
| Nil | Heisenberg 群 | 0 | 扭環面 |
| Sol | 可解李群 | 0 | Solv 流形 |
**「雙曲佔多數」**：Thurston 的定理（1980s）——
$$\boxed{\text{「隨機」的三維流形幾乎都是雙曲的（volume → ∞ 的極限）}}$$

### 第二條線索：Mostow 剛性定理（1968）
**定理（Mostow, 1968）**：$n\ge 3$ 的緊緻雙曲流形：
$$M_1 \cong M_2 \ (\text{homotopy equivalence}) \Longrightarrow M_1 \cong M_2 \ (\text{isometry}).$$
- **二維不成立**：二維雙曲曲面有**無限多個**不同的度規（Teichmüller 空間）；
- **三維完全剛性**：**同倫等价就是等距**——拓樸完全決定幾何！
- **推論**：雙曲三維流形的**體積是拓樸不變量**（Gromov 的證明，1982）：
  $$\text{Vol}(M) \text{ 只依賴 } M \text{ 的拓樸型}.$$

### 第三條線索：Gromov 範數與「體積的拓樸性」（1982）
**Gromov 範數**（simplicial volume）：
$$\|M\| = \liminf \frac{1}{n}\{\text{「最小」的三角剖分的體積}\}.$$
**Gromov 定理（1982）**：
$$\boxed{\text{Vol}(M) = \frac{\|M\|}{v_n} \quad\text{（$v_n$ 為理想單體的體積）}}$$
- **這是「體積 = 拓樸」的驚人等式**——
  幾何量（體積）完全由拓樸量（最小三角剖分）決定；
- **推論**：體積只能取**特定的實數值**——**體積是「量子化」的**。

### Python：Thurston 八種幾何與 Mostow 剛性的驗證

```python
import numpy as np

# 1) 雙曲空間的體積：理想單體的體積（Lobachevsky 公式）
def lobachevsky(theta, n=100000):
    """Lobachevsky 函數 Λ(θ) = -∫₀^θ ln|2sin t| dt"""
    ts = np.linspace(1e-9, theta, n)
    vals = np.log(np.abs(2*np.sin(ts)))
    return -np.sum((vals[1:]+vals[:-1])/2 * np.diff(ts))

def ideal_tetrahedron_volume(dihedral_angles):
    """理想單體體積：V = Λ(α) + Λ(β) + Λ(γ)，α+β+γ = π"""
    a, b, g = dihedral_angles
    return lobachevsky(a) + lobachevsky(b) + lobachevsky(g)

print("理想單體的體積（Lobachevsky 公式）：")
V = ideal_tetrahedron_volume((np.pi/3, np.pi/3, np.pi/3))
print(f"  正則理想單體（α=β=γ=π/3）：V = {V:.6f}")
print(f"  理論最大值 V_max ≈ 1.01494（Regge–Simons 的常數）\n")

# 2) 體積的最大值：正則理想單體
print("雙曲體積的量子化（Gromov 定理）：")
cases = [(np.pi/3, np.pi/3, np.pi/3, "正則（最大）"),
         (np.pi/2, np.pi/4, np.pi/4, "一般"),
         (np.pi/2, np.pi/2, 1e-9, "退化（極限）")]
for a, b, g, name in cases:
    V = ideal_tetrahedron_volume((a, b, g))
    print(f"  {name:12s}: V = {V:.6f}")
print("  → 體積只取特定值（Lobachevsky 函數的像）\n")

# 3) Mostow 剛性：同倫等价 = 等距（三維）
print("Mostow 剛性定理（n ≥ 3）：")
print("  二維：雙曲曲面的度規 = Teichmüller 空間（無限多個，維數 6g-6）")
print("  三維：同倫等价 ⟹ 等距（唯一！）")
print("  → 三維雙曲幾何『完全剛性』——拓樸決定幾何\n")

# 4) 二維 vs 三維的對照（Teichmüller 空間的維數）
print("Teichmüller 空間維數對照：")
for g in [2, 3, 4]:
    print(f"  虧格 {g} 的雙曲曲面：Teichmüller 空間維數 = 6g-6 = {6*g-6}")
print("  → 二維有『可變形』的空間；三維完全剛性\n")

# 5) Thurston 八種幾何的對照
print("Thurston 八種幾何：")
geoms = [("R³（歐氏）", "0"), ("S³（球面）", "+"),
         ("H³（雙曲）", "−"), ("S²×R", "+"),
         ("H²×R", "−"), ("SL₂~(R)", "−"),
         ("Nil", "0"), ("Sol", "0")]
for name, curv in geoms:
    print(f"  {name:10s}: 曲率符號 = {curv}")
print("  → 隨機三維流形幾乎都是雙曲的（H³）")
```

## 結案 -- 後果與影響
- **Thurston 的獎項（1976/1982）**：
  Thurston 因幾何化猜想與雙曲結構的工作獲 1976 年菲爾茲獎（30 歲）、
  1992 年當選美國國家科學院院士、2012 年獲內默斯數學獎。
- **Perelman 的完成（2003）**：
  $$\text{Thurston 幾何化（1982）} \xrightarrow{\text{Ricci 流 + 手術}} \text{Perelman（2003）}$$
  Perelman 用 **Ricci 流 + 熵**（見「2003-佩雷爾曼龐加萊猜想.md」）
  證明了**完整的幾何化猜想**——龐加萊猜想只是附帶的推論。
- **「隨機流形 = 雙曲」的定理（1990s–2000s）**：
  - **Maher（2010）**、**Rivin（1996）**：隨機三維流形**幾乎必然雙曲**；
  - **Brock–Canary（1996）**：雙曲結構的存在性。
  $$\text{Thurston 的直覺（1982）} \xrightarrow{\text{Rivin（1996）}} \text{嚴格證明}.$$
- **雙曲幾何的計算機革命（1990s–）**：
  - **SnapPea（Jeff Weeks, 1990s）**：計算雙曲三維流形的**體積與不變量**的軟體；
  - **體積的資料庫**：數千個雙曲流形的體積已被計算——
    **最小體積的閉雙曲流形**（Gabai–Meyerhoff–Milley, 2003）：$\approx 0.9427$。
  - **Cannon 猜想（1997）**：閉雙曲流形的邊界圓的**共形結構**——
    **Markovic（2013）** 證明了 Cannon 猜想（閉雙曲流形情形）。
- **物理學的應用（1990s–）**：
  - **Witten 的 3D 拓樸場論（1989）**：Chern–Simons 理論（見「1926-嘉當活動標架.md」）；
  - **量子重力（2000s）**：AdS/CFT 對應——**雙曲空間是量子重力的「隱藏幾何」**；
  - **網路科學（2010s）**：複雜網路的雙曲嵌入（見「1868-貝特拉米偽球面.md」）。
- **幾何學史的意義**：
  Thurston 幾何化是「**幾何學的第三次大統一**」：
  $$\text{Klein（1872）：變換群} \xrightarrow{} \text{Cartan（1926）：聯絡} \xrightarrow{} \text{Thurston（1982）：八種幾何}.$$
  $$\boxed{\text{三維 = 八種幾何的有限組合（像「化學元素」一樣）}}$$
  **Thurston 把三維流形變成了「元素週期表」**——
  每個流形都可以「分解」成 8 種幾何的「分子」。
- 歷史定位：**Thurston 幾何化是「拓樸學的幾何化」的頂點**——
  它告訴我們：**拓樸的分類問題可以完全幾何化**。
  $$\text{Poincaré（1904）：拓樸的猜想} \xrightarrow{\text{Thurston（1982）：幾何化}} \text{Perelman（2003）：全部證明}.$$
