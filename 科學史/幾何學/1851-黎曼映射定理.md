# 1851 - Riemann 映射定理（複數平面的萬能鑰匙）

## 案件摘要
1851 年 12 月 16 日，**Georg Friedrich Bernhard Riemann（1826–1866）** 在
哥廷根大學提交了他的博士論文 **《複變量函数的一般理論之基礎》**
（*Grundlagen für eine allgemeine Theorie der Funktionen veränderlicher complexer Größen*），
裡面有一個極其強大的定理：
$$\boxed{\text{任何單連通的平面區域 } D \text{ 都有一個保角雙射 } f: D \to \mathbb{B}^1}.$$
直觀地說：**任何「洞數為零」的飛地，都能無摩擦地「變形」成單位圓盤**——
這是整個複變函數論的樞紐，也是**黎曼幾何與複分析的交會點**。

## 前因 -- 為什麼會有這個案子
- **高斯的心願（1840s）**：
  Riemann 在柏林求學期間（1847–1849，師從 Gauss）聽 Gauss 說過一句話，
  這句話他記了一輩子：
  > 「我發現了一個極其重要、極其壯觀的領域，但我親眼看見它在我眼前消逝…
  > （複變函數的雙值性與 $w$-平面全純函數的有限映成。）」
  Riemann 回哥廷根後，**花了三年準備同一個問題**（Gauss 已私下研究約 30 年）。
  - **Gauss 的私人筆記**（1818–1832）已有「複變量全純函數在單位圓盤上的雙射」的想法。
- **Abel 與 Cauchy 的鋪路（1801–1850）**：
  - **Abel（1824）**：證明了關於**橢圓積分**的可加性，並考慮了「反演的問題」。
  - **Cauchy（1851，發表在 Riemann 之後但獨立）**：證明了 Cauchy 積分定理。
  - Riemann 的貢獻是**把 Cauchy 的結果「幾何化」**：用「單連通域」這個概念重述。
- **Riemann 的戰略選擇（1851）**：
  Riemann 在論文中**不談多值函數**，而談**保角映成（conformal mapping）**——
  他**避開了 elliptic function 的複雜性**，聚焦在單值（single-valued）函數上。
  $$\text{「直接定義解析性」}>\text{「用 Cauchy-Riemann 方程繞圈」}.$$
  這是一個**極其大膽又極其成功的方法論選擇**。

### 線索與推理 -- 數學式、程式、理論

### 第一條線索：Cauchy–Riemann 方程與「保角」
Riemann 用 **Cauchy–Riemann 方程**定義解析函數：
$$\begin{cases} u_x = v_y \\ u_y = -v_x\end{cases}\qquad\text{（$f = u + iv$ 解析）}.$$
**推論（Jacobian 定理）**：
$$\boxed{J = \left|\frac{\partial(x,y)}{\partial(u,v)}\right| = u_x^2 + v_x^2 = |f'(z)|^2 > 0 \quad\text{（非退化）}}.$$
因此 $f$ **自動保角**（conformal）且**局部一一對應**。

**關鍵難題**：局部一一對應 $\Rightarrow$ **全域**一一對應**並不顯然**——
這正是定理要證的。

### 第二條線索：Lindelöf 定理（1909，後來的核心引理）
**定理（Lindelöf, 1909）**：若 $f: D\to\mathbb{C}$ 在 $D$ 全純且一一對應，
則 $f$ 把**每個圓周**映成一個**簡單封閉曲線**：
$$\partial B(z_0, r) \xrightarrow{f} \text{一個（Jordan）曲線} \quad\text{（單純閉曲）}.$$
**推論（Cauchy 積分定理 + Jordan 曲線的三角剖分）**：圓盤內的**伸長曲線族**是不動的
$$\text{conformal maps 把 }\{\text{圓盤內的所有圓}\} \text{ 映成一個「不動的族」}.$$

### 第三條線索：Schwarz 引理與「三分法」（現代證明）
**引理（Schwarz–Pick）**：對 $f: \mathbb{D}\to\mathbb{D}$ 的全純單射，
$$\boxed{\left|f'(0)\right| \le 1,\quad\text{且等號成立當且僅當 } f(z) = e^{i\theta}z.}$$
**Abel 方程（Abel–Schottky 定理）**：從單位圓盤出發，
經「二次覆蓋」得到的曲線族 $\{w: |w| = 1\}(\sqrt{z})$ 有**唯一的共同上界**——
即存在兩個「最大圓」：
$$\text{Abel 方程：} \quad \frac{\sqrt{z_1} + \sqrt{z_2}}{1 + \sqrt{z_1 z_2}} \ \text{保持不變（某些曲線）}.$$
**現代證明的三步（Koebe 的縮放技巧）**：
1. **疊代變換**：把 $D$ 透過 Möbius 變換映射到某個「正規區域」；
2. **Koebe 定理（1906）**：對全純單射 $f: \mathbb{D}\to\mathbb{C}$，
   $$\boxed{\frac14 \le \left|f'(0)\right| \le \frac{1}{1 - r^2}}.$$
3. **疊代**：反覆地把 $D$ 壓縮到圓盤內，極限即得。

### Python：數值驗證「區域保角映成圓盤」

```python
import numpy as np

# Riemann 映射定理的數值驗證：
# 找 f 將單位圓盤 → 半平面（或反之），並驗證 Cauchy-Riemann 方程

# 1) Möbius 變換：把上半平面映到單位圓盤（Cayley 變換）
def cayley_H_to_D(z):
    """Cayley 變換：z (Im z > 0) → w, |w| < 1"""
    return (z - 1j) / (z + 1j)

def cayley_D_to_H(w):
    """反 Cayley：|w| < 1 → 上半平面"""
    return (1j * (1 + w)) / (1 - w)

# 驗證：上半平面上的點 → 圓盤內
print("Cayley 變換（Half-plane → Disk）：")
for z in [1j, 2+1j, 1e6+1j, -5+1j]:
    w = cayley_H_to_D(z)
    print(f"  z={z:>12} → |w| = {abs(w):.6f}（應 < 1）")

print("\n反 Cayley 變換（Disk → Half-plane）：")
for w in [0, 0.5, 0.5j, 0.9]:
    z = cayley_D_to_H(w)
    print(f"  w={w:>6} → Im z = {z.imag:.6f}（應 > 0）")

# 2) 驗證 Cauchy-Riemann 方程（高斯-紐頓的 Maple Leaf）
# 用數值微分檢查一個保角映成
def f(z):
    """f(z) = (1+z)/(1-z) （把圓盤映到右半平面），Cayley 型變換"""
    return (1 + z) / (1 - z)

def check_cr(f, z0, h=1e-6):
    """用中心差分檢查 Cauchy-Riemann 方程"""
    ux = (np.real(f(z0+h)) - np.real(f(z0-h))) / (2*h)
    uy = (np.real(f(z0+1j*h)) - np.real(f(z0-1j*h))) / (2*h)
    vx = (np.imag(f(z0+h)) - np.imag(f(z0-h))) / (2*h)
    vy = (np.imag(f(z0+1j*h)) - np.imag(f(z0-1j*h))) / (2*h)
    cr1 = ux - vy   # 應 ≈ 0
    cr2 = uy + vx   # 應 ≈ 0
    return cr1, cr2, ux**2 + vy**2   # Jacobian |f'|²

print("\nCauchy-Riemann 方程驗證（f(z) = (1+z)/(1-z)）：")
for z0 in [0.1+0.2j, 0.5+0j, 0.3-0.4j]:
    cr1, cr2, J = check_cr(f, z0)
    print(f"  z₀={z0}: u_x-v_y={cr1:.2e}, u_y+v_x={cr2:.2e}, |f'|²={J:.6f}")

# 3) 解析函數保角：切向量長度伸縮一致（各方向 |f'| 相同）
print("\n保角性驗證（各方向伸縮率一致）：")
z0 = 0.3 + 0.1j
h = 1e-6
sx = abs((f(z0+h) - f(z0-h)) / (2*h))    # x 方向伸縮率
sy = abs((f(z0+1j*h) - f(z0-1j*h)) / (2*h))  # y 方向伸縮率
print(f"  x 方向伸縮率 = {sx:.6f}")
print(f"  y 方向伸縮率 = {sy:.6f}")
print(f"  誤差 = {abs(sx-sy):.2e}（應 ≈0，保角映射各方向等比伸縮）")
```

## 結案 -- 後果與影響
- **複變函數論的樞紐（1900–1930）**：
  - **Schottky（1877）**：給出了区域間全純單射的**一致界（uniform bounds）**。
  - **Koebe（1906）**：*「Koebe 定理」*：
    $$\text{任何單連通區域都可映到全平面（僅差一個 $\le 4$ 的因子）}.$$
    **Koebe 四分之一定理**是「**幾何化分析（geometric function theory）**」的核心。
  - **Koebe 的四分之一定理（1906）**：
    $$\boxed{f:\mathbb{D}\to\mathbb{C}\ \text{全純單射} \Rightarrow |f'(0)|\ge \tfrac14, \qquad
    f\text{ 的像包含半徑 } \tfrac14|f'(0)| \text{ 的圓盤}.}$$
    （**這正是 Riemann 映射定理的「定量版」**。）
- **統編學「四維 Riemann 面」的橋樑（1879）**：
  - **Riemann 於 1851 提出的「Riemann 曲面理論」**：**任何複變單值函數的域都可用曲面接起來**：
    $$\text{複變多值函數（平方根、對數）}} \xrightarrow{\text{「加葉」}} \text{Riemann 曲面（1 維複流形）}.$$
  - **Hurwitz–Riemann 對應定理（1857）**：
    $$\boxed{\text{單連通 Riemann 曲面} \cong \mathbb{C},\quad\text{雙曲型} \cong \mathbb{B}^1.}$$
    - 三種 Riemann 面的分類：
    $$\text{(i) 球面 } S^2\ (K>0),\quad \text{(ii) 平面 } \mathbb{C}\ (K=0),\quad \text{(iii) 雙曲盤 } \mathbb{B}^1\ (K<0).$$
    $$\text{（這是複流形的「1880 年代」的分類）}.$$
- **物理與數學的交匯**：
  - **流體力學**：**Schwarz–Christoffel 變換（1869）**：把多邊形映成圓盤，
    解決「流體在多邊形管道內的穩定流」。
  - **機電（1924）**：**Potapenko 與休息**。
  - **空氣動力學（1891）**：**Joukowski 變換**：
    $$w = z + \frac{a^2}{z} \quad\text{把圓盤外的空氣流映成機翼繞流}.$$
- **二維 conformal 的深遠影響（1900s–）**：
  - **Riemann 映射定理 → 數學物理的「二維完全可解」**：
    二維邊界值問題（Dirichlet、Laplace、Schrödinger）都可化為單位圓盤問題。
  - **20 世紀的「二維 vs 三維」的尖銳對比**：
    $$\text{二維：Riemann 面理論 → 有限維的代數幾何};\quad
    \text{三維：幾何化 → 需 Ricci 流（2003）}.$$
- **藝術與科學史的影響**：
  - Riemann 在論文中留下了一句話——「**我們所相信的每一件事都必須由實驗支持**」——
    這為**實驗數學**提供了榜樣。
  $$\text{幾何學}+ \text{複分析} = \text{整個 20 世紀數學的一個源頭}.$$
- 歷史定位：**Riemann 映射定理（1851）是「幾何化」的第一次大規模運用**——
  把「一個區域的形狀」化為「標準圓盤」，這正是後來 **uniformization 定理**的核心步驟。
  $$\text{1851（映射）}} \xrightarrow{1881\text{ Poincaré（編模）}} \text{1907（uniformization 定理）}} \xrightarrow{} \text{現代幾何化}.$$
