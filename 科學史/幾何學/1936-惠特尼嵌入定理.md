# 1936 - Whitney 嵌入定理（任何流形都能塞進歐氏空間）

## 案件摘要
1936 年，**Hassler Whitney（1907–1989）** 在《數學年刊》發表
*Differentiable manifolds*，證明了微分拓樸學的基礎定理：
$$\boxed{\text{任何 } n \text{ 維光滑流形都能嵌入 } \mathbb{R}^{2n}}$$
**「嵌入」= 一一對應 + 光滑 + 逆映射也光滑（微分同胚到其像）**。
$$\text{任何流形} \hookrightarrow \mathbb{R}^{2n} \quad\text{（}2n\text{ 維就夠了）}.$$
- **Milnor 怪球面（1956）**：$\Sigma^7$ 也能嵌入 $\mathbb{R}^{14}$——
  **怪球面在「夠高」的歐氏空間裡也是光滑子流形**；
- **Nash 嵌入定理（1954）**：進一步要求**等距**（保持度規）——
  需要更多維度（見「1954-納什嵌入定理.md」）。
  $$\text{Whitney（拓樸嵌入）} \xrightarrow{\text{Nash（1954）}} \text{等距嵌入}.$$

## 前因 -- 為什麼會有這個案子
- **抽象流形的「存在性問題」（1900s–1930s）**：
  Riemann（1854）定義了「流形」的抽象概念，但一個自然的問題是：
  $$\text{抽象流形是否「真的存在」於歐氏空間裡？}$$
  若不能嵌入，則流形是「純邏輯的構造」——**没有幾何實體**。
- **Whitney 的身份（1930s）**：
  Whitney 是哈佛的年輕數學家（Birkhoff 的學生），
  他在 1935–1936 年連續發表了**五篇**《Differentiable manifolds》系列論文，
  **奠定了微分拓樸學的整個基礎**。
- **Whitney 的兩個定理（1936）**：
  1. **弱嵌入定理**：任何 $n$ 維流形可嵌入 $\mathbb{R}^{2n+1}$；
  2. **強嵌入定理**：任何 $n$ 維流形可嵌入 $\mathbb{R}^{2n}$。
  **2n 是「最佳可能」**——有些流形（如 $\mathbb{RP}^n$）不能嵌入 $\mathbb{R}^{2n-1}$。
- **Sard 定理（1935/1942）**：
  Whitney 的關鍵工具是**Sard 定理**：
  $$\boxed{\text{光滑映射的「臨界值」集合測度為零}}$$
  $$f: \mathbb{R}^m \to \mathbb{R}^n, \quad \{f(x): \text{rank}(Df_x) < n\} \text{ 測度 } = 0.$$
  **這是「幾乎所有值都是正則的」的定理**——
  微分拓樸的「一般位置（generic position）」思想的基礎。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：嵌入 vs 浸入（immersion）
**浸入**：導數處處單射（局部一一對應）；
**嵌入**：浸入 + **全域**一一對應 + 同胚到其像。
$$\text{浸入（local）} \xrightarrow{+\text{全域單射}} \text{嵌入（global）}.$$
**反例（浸入但非嵌入）**：圓的「8 字形」浸入平面——
兩點重合（不是一一對應）。

### 第二條線索：Whitney 的證明骨架（2n 的由來）
**弱嵌入（$\mathbb{R}^{2n+1}$）的證明**：
1. 用單位分解（partition of unity）把流形映到高維歐氏空間（**浸入**）；
2. 用 Sard 定理：**幾乎所有的投影方向都是單射的**——
   $$\text{從 } \mathbb{R}^{N} \xrightarrow{\text{投影}} \mathbb{R}^{N-1} \quad\text{（若 } N > 2n+1\text{）}.$$
3. 疊代降維，直到 $\mathbb{R}^{2n+1}$。

**強嵌入（$\mathbb{R}^{2n}$）**：需要更細的分析（Whitney 的「摺疊」技巧）。

**為什麼是 $2n$？** 對射故障的模式：
$$\text{兩點重合} \times \text{兩切向量相關} \approx 2(2n) - (2n) = 2n \text{ 維的「故障集」}.$$
**當 $N > 2n$，故障集的維數 < N，故可避開**。

### 第三條線索：嵌入定理的家族（1936–1954）
| 定理 | 條件 | 維數 |
|------|------|------|
| **Whitney 弱嵌入（1936）** | 光滑嵌入 | $\mathbb{R}^{2n+1}$ |
| **Whitney 強嵌入（1936）** | 光滑嵌入 | $\mathbb{R}^{2n}$ |
| **Nash $C^1$（1954）** | 等距（$C^1$） | $\mathbb{R}^{2n}$ |
| **Nash $C^\infty$（1956）** | 等距（光滑） | $\mathbb{R}^{n(n+1)/2+n}$ |
$$\text{條件越強，維數越多}.$$

### Python：Sard 定理與投影降維的數值驗證

```python
import numpy as np
np.random.seed(42)

# 1) Sard 定理的數值驗證：光滑映射的臨界值測度為零
def f(x, y):
    """f: R² → R，f(x,y) = x² + y²（臨界點 = 原點）"""
    return x**2 + y**2

def critical_measure_demo(n_samples=1000000):
    """臨界值 = f(原點) = 0（單點，測度零）"""
    # 隨機取樣，檢查有多少點映射到「臨界值附近」
    xs = np.random.randn(n_samples)
    ys = np.random.randn(n_samples)
    vals = f(xs, ys)
    # 臨界值只有 0（一個點）；檢查 vals 落在極小區間 [0, ε] 的比例
    for eps in [1e-3, 1e-6]:
        frac = np.mean(vals < eps)
        print(f"  ε = {eps}: 臨界值附近比例 = {frac:.6f}（→ 0，Sard 定理）")

print("Sard 定理（f(x,y) = x²+y²，臨界值 = {0}）：")
critical_measure_demo()

# 2) 投影降維：從 R³ 投影到 R²，避開自相交
print("\n投影降維（Whitney 的技巧）：")
# 一個嵌入 R³ 的曲線（結），投影到隨機方向，檢查是否自相交
# 用結的参数化（三葉結）
def trefoil(t):
    return np.array([np.sin(t) + 2*np.sin(2*t),
                     np.cos(t) - 2*np.cos(2*t),
                     -np.sin(3*t)])

ts = np.linspace(0, 2*np.pi, 200, endpoint=False)
pts = np.array([trefoil(t) for t in ts])

def projection_intersects(pts, direction):
    """投影到與 direction 正交的平面，檢查是否有兩點距離極近"""
    d = direction / np.linalg.norm(direction)
    # 建構正交基
    v1 = np.cross(d, [1,0,0]) if abs(d[0]) < 0.9 else np.cross(d, [0,1,0])
    v1 = v1 / np.linalg.norm(v1)
    v2 = np.cross(d, v1)
    proj = np.stack([pts@v1, pts@v2], axis=1)
    # 檢查最小兩兩距離（跳過相鄰點）
    min_dist = float('inf')
    for i in range(len(proj)):
        for j in range(i+3, len(proj)):
            dist = np.linalg.norm(proj[i] - proj[j])
            min_dist = min(min_dist, dist)
    return min_dist

n_intersections = 0
n_trials = 30
for _ in range(n_trials):
    d = np.random.randn(3)
    md = projection_intersects(pts, d)
    if md < 1e-3:  # 極近 = 自相交
        n_intersections += 1

print(f"  隨機投影 {n_trials} 次：自相交次數 = {n_intersections}")
print("  → 幾乎所有投影方向都保持嵌入（Sard 定理的推論）")
print("  → 這就是『從高維降維』的原理：故障集測度為零\n")

# 3) 嵌入維數的對照：2n 的由來
print("Whitney 嵌入維數（2n）：")
for n in [1, 2, 3, 4]:
    print(f"  {n} 維流形 → 嵌入 R^{2*n}")
print("  例：S¹ → R²（圓嵌入平面）、S² → R⁴（可用 R³）、RP² → R⁴（不能用 R³）")
print("  → 2n 是『最佳可能』：某些流形不能嵌入 R^{2n-1}")
```

  ε = 0.001: 臨界值附近比例 = 0.000632（→ 0，Sard 定理）
  ε = 0.000001: 臨界值附近比例 = 0.000000（→ 0，Sard 定理）

投影降維（Whitney 的技巧）：

## 結案 -- 後果與影響
- **微分拓樸學的奠基（1935–1936）**：
  $$\boxed{\text{抽象流形 = 歐氏空間的子流形（嵌入存在）}}$$
  Whitney 的五篇系列論文**奠定了整個微分拓樸學**：
  - **流形的正式定義**（圖冊、座標卡）；
  - **嵌入與浸入**的理論；
  - **向量叢（vector bundle，1943）**——Whitney 發明；
  - **Whitney 和（Whitney sum）**與**示性類**（Stiefel–Whitney 類，1935）。
- **Sard 定理的深遠影響（1935/1942）**：
  $$\text{Sard 定理} \xrightarrow{\text{Thom（1956）}} \text{橫截性理論} \xrightarrow{} \text{微分拓樸的「一般位置」思想}.$$
  - **Thom 的橫截性（transversality，1956）**：兩個子流形「一般位置」相交——
    **Whitney 的技巧的系統化**；
  - **Thom 的配邊理論（cobordism，1954）**：1958 菲爾茲獎——
    **配邨類的分類**是 20 世紀拓樸學的勝利之一。
- **向量叢與示性類（1935–1944）**：
  - **Stiefel–Whitney 類（1935）**：向量叢的拓樸不變量——
    $$\text{嵌入障礙} = \text{Stiefel–Whitney 類（不為零則不能嵌入）}$$
    這是「嵌入維數 2n 是最佳」的證明工具；
  - **Pontryagin 類（1942）**、**陳類（1944）**：示性類的家族
    （見「1918-外爾規範理論.md」、`1926-嘉當活動標架.md`）。
- **Nash 嵌入（1954）的先聲**：
  $$\text{Whitney（1936）：光滑嵌入} \xrightarrow{\text{Nash（1954）：等距嵌入}} \text{「幾何 = 歐氏空間的子流形」}$$
  Nash 的定理要求**保持度規**——比 Whitney 強得多，需要更多維度。
- **現代應用（2000s–）**：
  - **機器學習**：**流形學習（manifold learning）**——
    高維資料假設在低維流形上（Isomap、LLE、t-SNE）——
    **Whitney 定理是「流形假設」的數學依據**；
  - **降維與嵌入**：word embedding、graph embedding——
    把離散資料嵌入歐氏空間；
  - **計算機圖形學**：3D 模型的參數化（UV 映射）。
  $$\text{Whitney（1936）} \xrightarrow{} \text{流形學習（2000s）} \xrightarrow{} \text{AI 的嵌入革命}.$$
- **未解問題**：
  - **光滑 4 維 Poincaré 猜想**（見「1956-異質球面.md」）；
  - **嵌入的最小維數**的完整分類（$\mathbb{RP}^n$ 的嵌入維數是部分已知）。
- 歷史定位：**Whitney 是「微分拓樸學的建築師」**——
  他發明的語言（嵌入、浸入、向量叢、示性類、Sard 定理）
  是**20 世紀幾何與拓樸的共同基礎**。
  $$\text{Riemann（1854）：抽象流形} \xrightarrow{\text{Whitney（1936）：嵌入}} \text{微分拓樸} \xrightarrow{\text{Milnor（1956）}} \text{怪球面}.$$
