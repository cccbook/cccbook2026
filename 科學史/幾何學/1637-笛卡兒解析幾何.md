# 1637 - 笛卡兒《幾何學》（點 (x,y) 與方程式的誕生）

## 案件摘要
1637 年，René Descartes 在《方法論》（*Discours de la méthode*）的附錄《幾何學》中，
做了一件讓幾何學**徹底轉身**的事：**把點用數字表示**：
$$\text{點} \longleftrightarrow (x, y), \qquad \text{圖形} \longleftrightarrow \text{方程式}.$$
幾何從此變成**代數的分支**，而「解析幾何」成了科學的基本語言：
$$\text{數學} = \text{代數（規則）} \times \text{幾何（意義）}\quad\Longrightarrow\quad \text{科學} = \text{代數（規則）} \times \text{物理（意義）}.$$
Newton 在《原理》裡說：他在笛卡兒之後寫的書，「幾乎每一頁都在用笛卡兒的記號」——
**幾何學從此不再是圖形的學問，而是符號的學問**。

## 前因 -- 為什麼會有這個案子
- **兩千年的隔絕**：Euclid 的幾何是**定性**的（哪裡相等、哪裡平行），
  **無法計算**（面積、體積只能對特例推導）。開平方、立方根、三次方程的根在幾何中
  **沒有位置**（直到希臘人發明錐截線來表示倍根——非常笨拙）。
- **1590–1630：費馬（Fermat）與笛卡兒的平行探索**：
  - **費馬的《平面與立體的解析幾何》（1670，晚年出版）**：用一條「線」的兩條坐標軸，
    **清楚寫出圖形的方程表示**（如 $y = x^2$ 的拋物線）。
  - **笛卡兒（1637）**：**更激進**——明確主張「所有幾何問題都可化為代數方程」。
  $$\text{費馬：圖形 = 方程}\quad\text{vs}\quad\text{笛卡兒：幾何 = 代數的一部分}.$$
  費馬是學者（只做筆記），笛卡兒是**方法論者**（要寫「方法」）——**因此歷史記住了笛卡兒**。
- **笛卡兒的方法論（方法論一書，1637）**：
  1. 只接受**不證自明**的真理。
  2. 把問題**化為若干更簡單的子問題**。
  3. **用數學（代數）**求解。
  $$\text{D\issertation} = \text{懷疑一切} \xrightarrow{\text{笛卡兒懷疑論}} \text{確定方法} \xrightarrow{} \text{解決幾何}.$$
- **戰爭背景**：三十年戰爭（1618–1648）中笛卡兒在荷蘭流亡——**戰爭讓他沒有教職，必須用書與戰鬥**。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：笛卡兒座標（點的數字化）
任何點 $P$ 對應一對數字：
$$P = (x, y): \quad x = \text{到 } y\text{ 軸的有向距離},\quad y = \text{到 } x\text{ 軸的有向距離}.$$
- 點 $P_1(x_1,y_1)$ 到 $P_2(x_2,y_2)$ 的距離（乘法只用一次開根號）：
  $$d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}.$$
- **「一個點 = 一對數」的洞見**是整個解析幾何的起點。

### 第二條線索：方程式的圖形解（以「葉形線」為例）
笛卡兒在書中明確舉的例子：**葉形線（Folium of Descartes）**
$$x^3 + y^3 = 3axy.$$
- **極座標形式**：設 $y = tx$，代入得
  $$x^3(1+t^3) = 3at^2x \quad\Longrightarrow\quad x = \frac{3at^2}{1+t^3},\quad y = \frac{3at^2\cdot t}{1+t^3}?$$
  正確參數化（令 $y=tx$）：
  $$x = \frac{3at^2}{1+t^3}, \qquad y = \frac{3at^3}{1+t^3}.$$
- **方程式的圖形是解的集合**——這是「解幾何化」的核心。

### 第三條線索：把幾何問題轉成代數方程（笛卡兒的四條規則）
《幾何學》末尾的四條規則（未證明，但極其重要）：
1. **把幾何問題化為代數方程**（點用數字表示）。
2. **把方程看成「一條線」的關係**（如 $z$ 對 $x$ 的線性依賴）。
3. **用「未知幾何量」的鏈式求值**求解。
4. **回到幾何**：解出數字後還原成點與線。
$$\text{幾何（定性）} \xrightarrow{\text{規則 1–3}} \text{代數（定量求解）} \xrightarrow{\text{規則 4}} \text{幾何（定量）}.$$

### Python：葉形線的參數化與代數驗證

```python
import numpy as np
import matplotlib.pyplot as plt

# 葉形線 x³ + y³ = 3axy，參數 a = 1
a = 1.0
def folium_x(t, a=1.0):
    return 3*a*t**2/(1+t**3)

def folium_y(t, a=1.0):
    return 3*a*t**3/(1+t**3)

# 參數化曲線（t 從 -∞ 到 ∞，跳過 t=-1 的漸近線）
t = np.linspace(-20, 20, 20000)
mask = np.abs(1+t**3) > 1e-3
t = t[mask]
x = folium_x(t)
y = folium_y(t)

# 驗證：代回方程 x³ + y³ = 3axy
residual = x**3 + y**3 - 3*a*x*y
print(f"葉形線代數殘差（最大絕對值）= {np.max(np.abs(residual)):.2e}")
print(f"樣本數 = {len(x)}")

# 葉形線的「迴圈」：t ∈ [0,∞) 的第一象限部分有封閉迴圈
t_pos = t[(t >= 0) & (t <= 10)]
print(f"\n葉形線第一象限封閉迴圈：")
print(f"  極大點 x ≈ {np.max(3*a*t_pos**2/(1+t_pos**3)):.4f}")
print(f"  漸近線：t=-1 → x, y 趨於 ±∞")
print(f"  葉形線最大 x 理論值 = {3*a*np.sqrt(3)/8:.4f}")

# 繪圖
plt.figure(figsize=(7,7))
plt.plot(x, y, 'b-', lw=1.5, label='Folium: $x^3+y^3=3axy$')
plt.axhline(0, color='k', lw=0.5); plt.axvline(0, color='k', lw=0.5)
plt.axline((0,0), slope=1, color='gray', ls='--', lw=0.8, label='asymptote $y=x$')
plt.axis('equal'); plt.xlim(-3, 3); plt.ylim(-3, 3)
plt.legend(); plt.title('Leaf of Descartes (1637)')
plt.xlabel('x'); plt.ylabel('y')
plt.savefig('folium.png', dpi=100, bbox_inches='tight')
print("\n→ 已繪製 folium.png")
```

## 結案 -- 後果與影響
- **「解析幾何」的成立**：
  - **座標 → 圖形 → 方程式 → 座標** 的循環，讓幾何可計算、可微分、可優化。
  - **圓錐曲線的標準方程**（$(x-h)^2/a^2 + (y-k)^2/b^2 = 1$ 等）
    成為高中到大學的通用語言。
- **科學革命的工具箱**：
  $$\text{解析幾何} \xrightarrow{\text{Newton}} \text{微積分} \xrightarrow{\text{Lagrange}} \text{力學} \xrightarrow{\text{Einstein}} \text{廣義相對論}.$$
  - **Newton《原理》(1687)**：用解析幾何 + 微積分描述行星運動。
  - **Lagrange 拉格朗日力學（1788）**：廣義座標 + 能量方程。
  - **Einstein 場方程（1915）**：把时空視為四維流形，用曲率描述引力。
- ** Leibniz 的評論（1670s）**：讀了笛卡兒與費馬後說，
  費馬的《平面與立體幾何》是這個領域的「好的基礎」，笛卡兒的書「幾乎沒寫什麼新的」——
  但**歷史上笛卡兒獲得榮譽，因為他「宣傳」了這個方法**（費馬沒出版）。
  $$\text{科學的勝利} = \text{正確} \times \text{發表} \times \text{可教}.$$
- **現代幾何的三個座標系統**：
  1. **笛卡兒座標（1637）**：$(x,y)$，度量幾何（歐氏幾何）。
  2. **齊次座標（ projective, Desargues/Möbius）**：$(x,y,z)$，射影幾何。
  3. **流形座標（Riemann, 1854）**：$(u,v)$ 在「曲面上」，內在幾何。
  $$\text{三次擴張} = \text{平面} \xrightarrow{} \text{射影平面} \xrightarrow{} \text{任意曲面}.$$
- 歷史定位：**笛卡兒把幾何從「圖形的集合」變成了「方程式的集合」**——
  這是數學史上最大的一次範式轉移，**幾何學至此不再是「看得見的學問」，而是「算得出的學問」**。
