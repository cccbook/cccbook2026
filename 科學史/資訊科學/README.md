# 資訊科學 -- AI 偵探風格

以「推理探案」的方式，追查資訊科學九十年（1936–2026）的每一場危機與轉身：
前因是什麼？線索在哪裡？推理如何展開？後果又如何改變了整個世界？

本卷特別追蹤**圖靈獎（Turing Award）得主**的貢獻——
這是資訊科學界的諾貝爾獎（1966 年設立，獎金 100 萬美元），
每一屆得主都改寫了這門學科的一章。

核心謎題只有一個：**「資訊」到底是什麼？它如何被表示、計算、傳輸與理解？**

## 四大歷史脈絡

1. **可計算性（Turing → Cook）**：從「什麼能算」到「什麼算得快」。
2. **語言與抽象（Backus → Allen）**：程式語言從機器碼到高階抽象，編譯器從翻譯到最佳化。
3. **資料與系統（Codd → Lamport）**：資料庫的數學化、作業系統的可攜化、分佈式的一致性。
4. **資訊的理解（Shannon → 深度學習）**：從位元到神經網路，資訊從「傳輸」到「理解」。

## 圖靈獎主線

圖靈獎（1966 年設立）是資訊科學的最高榮譽，本卷收錄的圖靈獎主線：

$$\text{Turing（1936，奠基）} \to \text{McCarthy（1971，AI 與 LISP）} \to \text{Dijkstra（1972，演算法與結構化）} \to \text{Knuth（1974，演算法分析）} \to \text{Codd（1981，資料庫）} \to \text{Cook（1982，NP-完全）} \to \text{Thompson/Ritchie（1983，UNIX）} \to \text{Kahan（1989，浮點）} \to \text{Engelbart（1997，人機介面）} \to \text{姚期智（2000，量子）} \to \text{RSA（2002，密碼學）} \to \text{Allen（2006，編譯器）} \to \text{Lamport（2013，分佈式）} \to \text{深度學習三巨頭（2018，AI）}$$
