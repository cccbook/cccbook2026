# 1654 -- Pascal–Fermat 賭金分配問題：機率論誕生，保險的數學基礎

## 案件描述

1654 年，法國貴族賭徒 Chevalier de Méré 寫信向數學家 Blaise Pascal 請教一個賭場問題：

> **兩人在賭局中各勝若干局後中斷，賭金該怎麼分配？**（Problem of Points，點問題）

Pascal 寫信給圖魯茲的 Pierre de Fermat，兩人用書信往返解出了這個問題——這次通信被公認為**機率論的誕生時刻**。

而機率論誕生的第一個實際應用，就是**壽險與年金**的定價——金融計算的第一座橋樑，從賭場搭到了人命。

## 前因：賭博與「幸運數學」

- 16 世紀 Cardano 已寫過《論賭博》（Liber de Ludo Aleae，1663 出版），計算過骰子的組合數——但沒有傳播。
- 核心難題：「點問題」看似簡單，但直覺的答案（按已勝局數比例分配）是**錯的**——正確答案必須考慮「**未來還有可能的局**」。
- **線索**：de Méré 自己在賭桌上發現一個悖論：擲一顆骰子 4 次至少出一個六的機率大於 1/2，但擲兩顆骰子 24 次至少出一對六的機率卻**小於** 1/2（雖然 24/36 = 4/6，比例看起來相同）——他請教 Pascal，這是通往點問題的入口。

## 推理過程

### 線索一：de Méré 悖論的組合計算

擲一顆骰子 4 次，至少一個六：

$$P = 1 - \left(\frac{5}{6}\right)^4 \approx 0.5177 > \frac{1}{2}$$

擲兩顆骰子 24 次，至少一對六：

$$P = 1 - \left(\frac{35}{36}\right)^{24} \approx 0.4914 < \frac{1}{2}$$

**教訓**：「比例相同」不等於「機率相同」——機率必須**精確計算**，不能靠直覺。這是「機率論必要性」的第一課。

### 線索二：點問題的正解——期望值的第一次精確使用

設甲還需 $a$ 勝、乙還需 $b$ 勝。Pascal 與 Fermat 的洞察：賭金應按「**各自獲勝的機率**」分配，而機率必須考慮所有未來可能的結局。

Fermat 的方法：窮舉未來 $a + b - 1$ 局的所有組合，數出各自獲勝的比例。

Pascal 的方法：**遞迴**（巴斯卡三角形的應用）。設 $E(a, b)$ 為甲應得的份額：

$$E(a, b) = \frac{1}{2}E(a-1, b) + \frac{1}{2}E(a, b-1)$$

邊界：$E(0, b) = 1$（甲已勝）、$E(a, 0) = 0$。

**歷史意義**：這是「**條件期望 + 遞迴**」的第一次精確使用——正是後來二項樹倒推（見 [1979-CRR二項樹模型.md](1979-CRR二項樹模型.md)）與美式選擇權動態規劃（見 [2001-LongstaffSchwartz蒙地卡羅.md](2001-LongstaffSchwartz蒙地卡羅.md)）的數學祖先。

### 線索三：期望的概念

Pascal 在同時期的《思想錄》中留下著名的「**帕斯卡賭注**」（Pascal's Wager）：用期望值論證信仰——無限的收益 × 有限的機率。雖然是神學論證，它展示了期望值框架的威力：**決策應該按機率加權的結果來比較**——這正是 300 年後 Markowitz（1952）框架的哲學種子。

## 現代程式重現：點問題的遞迴解

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def points(a, b, p=0.5):
    """Pascal 的遞迴解：甲需 a 勝、乙需 b 勝時，甲應得的份額"""
    if a == 0: return 1.0
    if b == 0: return 0.0
    return p * points(a-1, b, p) + (1-p) * points(a, b-1, p)

print(points(2, 3))   # 0.6875 — 不是直覺的 2/5=0.4！
# 這就是 1654 年的發現：賭金按「獲勝機率」分配，不是按「已勝局數」

# de Méré 悖論驗證
print(1 - (5/6)**4)    # 0.5177 > 0.5
print(1 - (35/36)**24) # 0.4914 < 0.5 — 比例相同，機率不同
```

## 後果

- **1657 年**，荷蘭科學家 Huygens 出版《論賭博中的推理》（De Ratiociniis in Ludo Aleae）——第一本機率論專著，直接基於 Pascal–Fermat 通信。
- **1662 年**，Graunt 出版《死亡表》（Natural and Political Observations...）——第一張生命統計表；**1663 年**，Witt 用它為年金定價——**機率論第一次應用於金融**：壽險與年金 = 「人命的賭金分配問題」。
- **保險業的數學化**：從此保險定價 = 期望損失 + 風險溢價——這條公式延伸出現代的 VaR（見 [1994-RiskMetricsVaR.md](1994-RiskMetricsVaR.md)）。
- 期望值 + 遞迴的框架，經 Bernoulli（1738）、Markowitz（1952）、Cox–Ross–Rubinstein（1979）傳承到今天。
- 盲點：1654 年的機率論是「等可能事件」的組合計數，還沒有嚴格的公理化基礎（要等 1933 年 Kolmogorov）。

## 偵探筆記

- 動機：賭桌上的悖論（比例相同，機率不同）
- 工具：組合計數、條件期望、遞迴（巴斯卡三角形）
- 遺產：機率論誕生、保險定價的數學基礎、期望決策框架
- 盲點：等可能性假設的極限、沒有公理化
