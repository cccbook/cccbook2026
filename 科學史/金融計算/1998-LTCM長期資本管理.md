# 1998 -- LTCM 長期資本管理公司：兩位諾貝爾獎得主的崩潰

## 案件描述

1998 年 8–9 月，長期資本管理公司（Long-Term Capital Management, LTCM）——一支由**兩位諾貝爾獎得主**（Scholes、Merton，1997 年才得獎）、前聯準會副主席（Mullins）與傳奇交易員（Meriwether）組成的避險基金——在四週內虧損 46 億美元，瀕臨崩潰。

紐約聯準會被迫召集 14 家銀行注資 36 億美元接管——**史上第一次，一群最聰明的人用最先進的模型，製造了差點掀翻全球金融體系的危機**。

## 前因：天才的組合

- 1994 年，所羅門兄弟前債券交易主管 John Meriwether 創辦 LTCM，網羅 Myron Scholes 與 Robert Merton（Black–Scholes 的作者，見 [1973-BlackScholes選擇權定價.md](1973-BlackScholes選擇權定價.md)）。
- 策略：**收斂套利（convergence arbitrage）**——買便宜的、賣貴的相似債券，等價差收斂。例如：
  - 買俄羅斯公債、賣美國公債（賭利差收斂）
  - 買離岸（off-the-run）公債、賣在岸（on-the-run）公債（賭流動性溢價收斂）
- 前三年成績驚人：年報酬 40%+（費後）。
- **線索一**：LTCM 的槓桿高達 **25:1**（資產 1,250 億 vs 資本 48 億），衍生品名目本金超過 1 兆美元。
- **線索二**：它的風控模型假設「利差收斂是均值回歸的隨機過程」——**但均值回歸的前提是市場正常運作**。

## 推理過程

### 線索一：策略的數學本質

LTCM 的每筆交易都是「買被低估的資產、賣被高估的相似資產」，期望利差 $\Delta_t$ 均值回歸：

$$d\Delta_t = -\kappa(\Delta_t - \bar\Delta)dt + \sigma dW_t$$

在正常市場，這是低風險、高勝率的策略——**但每次利差都很小，必須用巨大槓桿放大**。

**數學弔詭**：策略勝率越高、越接近套利，需要的槓桿就越大；槓桿越大，承受不利波動的能力就越小。

### 線索二：1998 年 8 月——俄羅斯違約

- 1998 年 8 月 17 日，俄羅斯違約其公債（盧布貶值 + 債務重整）。
- 全球金融市場進入「**恐慌模式**」：所有人同時湧向流動性最高的資產（美國國庫券）。
- LTCM 的每筆交易**同方向**虧損：
  - 賣國庫券（流動性最好的）→ 跌得最慘的恰恰是它
  - 買新興市場債、賣美國債 → 利差**暴增**而非收斂
- **關鍵推理**：LTCM 模型的均值回歸假設在恐慌中失效——利差不回歸，反而發散。這是「**相關性在危機中收斂到 1**」的教科書案例：所有「分散」的部位一起崩潰。

### 線索三：保證金追繳的死亡螺旋

1. 虧損 → 資本減少 → 槓桿率上升
2. 債權銀行要求追加保證金 → 被迫平倉（賣出虧損部位）
3. 平倉壓低價格 → 更多虧損 → 更多平倉
4. **正回饋死亡螺旋**（與 1987 年投資組合保險同構，見 [1987-黑色星期一與投資組合保險.md](1987-黑色星期一與投資組合保險.md)）

9 月 23 日，紐約聯準會召集 14 家銀行接管——因為若 LTCM 破產，其 1 兆美元的衍生品部位會同時平倉，可能引爆整個體系。

## 現代程式重現：槓桿與死亡螺旋

```python
import numpy as np

def ltcm_simulation(capital=48e8, leverage=25, spread_vol=0.005,
                    margin_call=0.15, n_days=30, seed=0):
    """槓桿 + 保證金追繳的死亡螺旋"""
    rng = np.random.default_rng(seed)
    capital_path = [capital]
    for _ in range(n_days):
        assets = capital * leverage
        loss = assets * np.random.normal(0, spread_vol)   # 相關性=1 的危機
        capital -= abs(min(loss, 0))
        if capital / (capital * leverage) < margin_call:  # 保證金追繳
            leverage = min(leverage * 0.9, capital/capital)  # 被迫降槓桿（賣出）
        capital_path.append(max(capital, 0))
        if capital <= 0: break
    return np.array(capital_path)

path = ltcm_simulation()
print("存活天數:", len(path)-1, "最終資本:", path[-1]/1e8, "億")
# 槓桿 25x 時，30 天內資本幾乎歸零 — LTCM 的數學本質
```

## 後果

- **「太重要而不能倒」的先例**：紐約聯準會民間接管方案（非官方紓困）成為 2008 年救助的範本。
- **風控理論的修正**：VaR（見 [1994-RiskMetricsVaR.md](1994-RiskMetricsVaR.md)）開始加入壓力測試（stress testing）——「歷史上沒發生過」不代表不會發生。
- **相關性的危機收斂**：危機中相關性趨近 1 的現象成為風險管理的基本常識——分散在恐慌中失效。
- **槓桿的教訓**：Merton 與 Scholes 的模型沒有錯——錯的是**用 25 倍槓桿去放大一個微小的套利**。模型計算的是期望值，槓桿決定的是生存能力。
- **2008 年的預演**：LTCM 的劇本（高槓桿 + 相關性收斂 + 保證金螺旋）在 2008 年以更大規模重演（見 [2008-金融海嘯與CDO.md](2008-金融海嘯與CDO.md)）。
- Lowenstein（2000）的暢銷書《When Genius Failed》記錄了整個案件。

## 偵探筆記

- 動機：微小的套利利差 + 巨大槓桿
- 工具：收斂套利、均值回歸模型、衍生品槓桿
- 遺產：壓力測試、相關性危機收斂、槓桿生存法則
- 盲點：均值回歸假設在恐慌中失效；「模型正確」不等於「策略安全」
