# 1933 -- Alfred Cowles《股票市場預測家能預測嗎？》：用統計擊碎預測神話

## 案件描述

1933 年，大蕭條的陰影尚未散去，美國經濟學家 Alfred Cowles III 在《Econometrica》創刊號發表了一篇題目本身就是質問的論文：

> **"Can Stock Market Forecasters Forecast?"**（股票市場預測家能預測嗎？）

他的答案只有三個字（在論文摘要裡）：

> **"It is doubtful."**（令人懷疑。）

這是金融史上第一次用**大規模統計檢驗**對「專業預測能力」進行法庭審判。

## 前因：預測產業的黃金年代

- 1920 年代華爾街充斥著「預測服務公司」、技術分析師與圖表大師。
- 1929 年股市崩盤與大蕭條讓人質疑：如果這些專家真的能預測，為什麼沒人預測到崩盤？
- Cowles 是一位富裕的芝加哥保險公司繼承人（家族企業 Cowles & Company），他在 1920 年代自己就編製過股市預測指標，親身體驗過「預測看起來很準」的錯覺。
- **線索**：Cowles 質疑的不是某個專家，而是整個產業——他要做的是「全母體」檢驗，而不是抽樣。

## 推理過程

### 線索一：資料本身是兇手最重要的證據

Cowles 不信任現成的資料，自己動手建構了資料庫：

- 收集了 **1928–1932 年間 20 家預測服務公司、16 家保險公司、24 份金融刊物** 的每一筆推薦記錄。
- 重建了數千筆個股與組合的報酬資料（這個資料庫後來發展成著名的 **Cowles 委員會資料庫**，是 Ibbotson 等現代市場資料的前身）。

### 線索二：統計檢驗的設計

核心問題：預測者的報酬是否**顯著優於**隨機選股？

Cowles 的檢驗框架（以現代語言重述）：

1. **虛無假說 $H_0$**：預測者的選股與隨機抽籤無異。
2. **檢定統計量**：將預測組合的實際報酬與「隨機組合報酬分配」比較，計算其百分位數。
3. **顯著水準**：只有在 95% 以上百分位數時，才承認有技術。

他還設計了一個精妙的「**翻面檢驗**」：如果一個預測者把推薦反著做（買跌賣漲），表現如何？若反著做也沒有顯著超額報酬，說明預測既不是正確訊號、也不是反指標——**純粹是雜訊**。

### 線索三：審判結果

- 20 家預測服務公司中，只有少數達到 95% 顯著水準，且在後續期間無法持續。
- 保險公司投資組合的報酬與市場整體幾乎無差異。
- 金融刊物的編輯推薦：「其中最有名的一份刊物，其推薦的反向操作反而略優」。
- **結論**：沒有證據顯示專業預測者具備持續的預測能力。

用現代統計語言：預測者的超額報酬 $t$ 統計量大多不拒絕

$$H_0: \alpha = 0$$

## 現代程式重現：Cowles 的翻面檢驗

```python
import numpy as np

def cowles_test(pred_returns, market_returns, n_sims=10000, seed=0):
    """將預測組合報酬與隨機組合報酬分配比較，回傳百分位數"""
    rng = np.random.default_rng(seed)
    n = len(pred_returns)
    random_perf = []
    for _ in range(n_sims):
        # 隨機挑選：等權重隨機組合
        w = rng.random(n)
        w /= w.sum()
        random_perf.append(np.dot(w, market_returns))
    random_perf = np.array(random_perf)
    actual = np.mean(pred_returns)
    return (random_perf < actual).mean()  # 百分位數

# 若百分位數 < 0.95：無法拒絕「隨機與專家無異」的虛無假說
```

## 後果

- **1932 年**，Cowles 用自己的錢創立了 **Cowles 委員會**（Cowles Commission for Research in Economics），資助計量經濟學研究——後來孕育了眾多諾貝爾獎得主（Koopmans、Klein、Arrow、Debreu、Markowitz 都與之相關）。
- 這篇論文是**有效市場假說（1965, Fama）的直接先聲**：如果專業人士都無法持續擊敗市場，那市場本身就可能是「有效」的。
- 現代指數化投資（John Bogle 的 Vanguard，1976）的哲學根源可以追溯到這篇論文：**如果預測無用，不如買下整個市場。**
- Cowles 的「資料先行」方法論，成為現代量化投資與實證資產定價（empirical asset pricing）的標準。

## 偵探筆記

- 動機：預測產業繁榮 vs 大蕭條的矛盾
- 方法：全母體統計檢驗 + 翻面檢驗 + 顯著性分析
- 遺產：Cowles 委員會、指數化投資的哲學根源、實證金融的方法論
- 盲點：樣本期間太短（1933 年的資料只有幾年），「無法證明有技術」不等於「證明沒有技術」——這個哲學問題至今仍是主動式基金辯論的核心。
