# 1907 — 單值化定理

## 案件摘要
1907 年，Poincaré 與 Koebe 各自獨立證明**單值化定理（Uniformization Theorem）**：每個單連通黎曼面必雙全純同構於三個模型之一——黎曼球 $\hat{\mathbb{C}}$、複平面 $\mathbb{C}$、或雙曲圓盤 $\mathbb{H}$。所有可能的「複一維世界」被壓縮進三個標準模型。這是 19 世紀函數論的最大懸案的最終判決：Riemann 曲面分類問題正式結案，雙曲幾何從 Lobachevsky 的想像躍升為複分析的必然結構。

## 前因 -- 為什麼會有這個案子
- 1851 年 Riemann 博士論文引入**黎曼面**：多值函數（如 $\sqrt{z}$、$\log z$）的自然定義域；代數函數 $w^2 = p(z)$ 的曲面是緊緻黎曼面的原型。
- 1851 年 Riemann 映射定理（1851 提出、1870s 由 Schwarz 等嚴格證明）：單連通真子域 $\Omega \subsetneq \mathbb{C}$ 必雙全純等價於單位圓盤 $\mathbb{D}$。**平面上的域解決了，那緊緻曲面呢？**
- 曲面分類的不變量是**虧格** $g$：球面 $g=0$、環面 $g=1$、多洞曲面 $g \geq 2$。單值化要回答：每個虧格的單連通覆蓋空間是什麼？
- 1880 年代 **Fuchs–Klein 自動函數之爭**：Klein 與 Poincaré 競賽研究自守函數（在雙曲變換群下不變的函數），Poincaré 1882–1884 建立自守函數的一般理論，Klein 因過勞病倒退出競賽。這場競爭的目標，正是單值化所需的自守函數工具。
- 1883 年 Poincaré 已證明單值化定理的特例版本（具循環基本群的域）；1907 年 Koebe（萊比錫，Klein 學派）與 Poincaré（巴黎）分別完成一般證明。

## 線索與推理 -- 數學式、程式、理論

### 線索一：三個模型與曲率
單連通黎曼面 $X$ 必屬於以下三類之一：

| 模型 | 定義域 | 常數曲率 | 典型例子 |
|---|---|---|---|
| 球面型 | $\hat{\mathbb{C}} = \mathbb{C} \cup \{\infty\}$ | $+1$ | 球面 $S^2$、$g=0$ |
| 平面型 | $\mathbb{C}$ | $0$ | 環面 $g=1$ 的覆蓋 |
| 雙曲型 | $\mathbb{H} = \{z : \operatorname{Im} z > 0\}$ | $-1$ | $g \geq 2$ 的覆蓋 |

判據只看一個數：虧格。$g = 0 \Rightarrow \hat{\mathbb{C}}$，$g = 1 \Rightarrow \mathbb{C}$，$g \geq 2 \Rightarrow \mathbb{H}$。複結構決定幾何——這是「分析即幾何」的極致表達。

### 線索二：雙曲度量的顯式公式
雙曲圓盤 $\mathbb{D}$（$\mathbb{H}$ 的雙全純像）的度量為：

$$ds = \frac{2\, |dz|}{1 - |z|^2}, \qquad K = -1$$

測地線是與邊界正交的圓弧。自守變換群 $\mathrm{PSL}(2, \mathbb{R})$ 以 Möbius 變換作用：

$$z \mapsto \frac{az + b}{cz + b}, \quad ad - bc = 1$$

保持度量與複結構。虧格 $g \geq 2$ 的緊緻曲面 $= \mathbb{H} / \Gamma$，其中 $\Gamma$ 是無撓 Fuchs 群；高斯–博內公式驗證曲率：$\int_X K\, dA = 2\pi \chi(X) = 2\pi(2 - 2g) < 0$，負曲率是必然。

### 線索三：Poincaré 的證明思路
Poincaré 的證明（Scanned Series 補遺）核心是用**掃描法（balayage / scanning）**：在曲面上的奇異度量逐步掃平奇點，用 Green 函數與 Dirichlet 原理構造非常數亞純函數，把曲面映射到球面/平面/圓盤，再由映射的分類決定覆蓋模型。Koebe 的證明則沿 Klein 學派的連續變化法：參數化曲面族，用極限論證完成單值化。兩條路線都用到了 1900 年 Hilbert 修復的 **Dirichlet 原理**——Riemann 埋下的伏筆，Hilbert 負責驗屍後復活。

### 線索四：經典例子——$w^2 = z(z-1)(z-\lambda)$
橢圓曲線 $w^2 = z(z-1)(z-\lambda)$ 的黎曼面：兩個球面沿兩條割縫黏合，虧格 $g = 1$，故單值化為 $\mathbb{C}$。單值化映射正是 **Weierstrass $\wp$ 函數**：

$$z = \wp(u), \quad u \in \mathbb{C}/\Lambda, \qquad (\wp')^2 = 4\wp^3 - g_2 \wp - g_3$$

環面 $\mathbb{C}/\Lambda$ 覆蓋橢圓曲線。虧格 $g \geq 2$ 時則需 Fuchs 自守函數——這正是 Poincaré 1882 年自守函數理論的用武之地。$\wp$ 與自守函數，一管 $g=1$、一管 $g\geq 2$，合起來完成全部分類。

### 程式碼範例：雙曲圓盤模型的 numpy 視覺化
```python
import numpy as np
import matplotlib.pyplot as plt

# 雙曲圓盤：測地線 = 與邊界正交的圓弧
fig, ax = plt.subplots(figsize=(6, 6))
theta = np.linspace(0, 2 * np.pi, 200)
ax.plot(np.cos(theta), np.sin(theta), "k", lw=2)  # 邊界圓 |z|=1

# 畫一組測地線：過邊界點 -1 與 1 的正交圓族
for a in np.linspace(-0.8, 0.8, 7):
    # 圓心在虛軸上，半徑 r，過點 (a, 0) 且與單位圓正交
    r2 = 1 / (1 - a**2) if abs(a) < 1 else 0
    cy = 0.0
    cx = a * r2
    r = np.sqrt(cx**2 + r2 - 1)
    t = np.linspace(0, 2 * np.pi, 300)
    ax.plot(cx + r * np.cos(t), cy + r * np.sin(t), lw=0.8, alpha=0.6)
ax.set_aspect("equal"); ax.set_xlim(-1.2, 1.2); ax.set_ylim(-1.2, 1.2)
ax.set_title("Geodesics in the hyperbolic disk (K = -1)")
plt.show()

# Möbius 變換 z -> (z + t)/(t z + 1) 沿測地線平移，檢驗邊界不動
t = 0.3
z = np.array([0.0, 0.5, -0.5 + 0.5j, 0.9])
w = (z + t) / (t * z + 1)
print("平移後的點:", w)
print("邊界點 |w| 檢驗（邊界映至邊界）:")
zb = np.exp(1j * theta)
print("max ||w| - 1| =", np.max(np.abs(np.abs((zb + t) / (t * zb + 1)) - 1)))
```

`max ||w| - 1| ≈ 0` 直接驗證 Möbius 變換保持邊界圓——雙曲等距變換的數值檢驗，正是單值化定理的幾何舞台。

## 結案 -- 後果與影響
- **黎曼曲面分類完成**：任何（不必緊緻）單連通黎曼面三選一；一般曲面 = 模型曲面 / 離散群。這是 19 世紀函數論的收官判決。
- **雙曲幾何的正當化**：Lobachevsky（1829）與 Bolyai 的非歐幾何，從公理遊戲變成複分析的內在結構；相對論的雙曲空間、Thurston 的三維幾何化猜想（1982，Perelman 2003 證明）皆承其衣缽。
- **模形式與模空間**：$g \geq 2$ 的模空間 $\mathcal{M}_g = \mathbb{H}/\mathrm{Sp}(2g, \mathbb{Z})$ 的商空間結構，Wiles 證 Fermat 最後定理（1995）的模形式工具鏈，遠祖即此案。
- **Riemann–Roch 與代數幾何**：單值化 + 緊緻曲面上的亞純函數理論，鋪設代數曲線分類的道路；Grothendieck 的 scheme 理論視其為一維原型。
- **複動力學**：Fatou、Julia 集的研究直接使用單值化語言；有限型有理映射的分類即此案的動力學版本。
