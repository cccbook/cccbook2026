# -3200-文字與最早國家：為了會計而寫字

## 案件摘要

約西元前 3200 年，蘇美城市烏魯克的泥板上出現最早的文字——刻著的內容不是詩，不是禱詞，而是**穀物、牲畜與工資的帳目**。這樁案件的兇手是「剩餘的複雜化」：當神廟經濟需要追蹤數千筆穀物與數千人的勞務時，人腦的記憶不夠用了——**文字是官僚制度的工具，不是詩人的發明**。文字反過來又放大了組織：有記錄的帝國可以徵稅、立法、下達命令——協調半徑第一次跨越了人腦記憶的極限。

## 前因 -- 多因素的局勢

- **經濟**：烏魯克的神廟經濟集中了數千人的穀物、勞務與分配——記帳需求爆炸。
- **組織**：神廟祭司是「最早的管理層」——分配需要記錄與驗證。
- **科技**：泥板（黏土易得、可保存）、楔形筆（蘆葦）——載體與工具俱備。
- **資訊**：陶籌（token）計數傳統（約前 8000 起）是文字的直接前身——Denise Schmandt-Besserat 的陶籌理論。
- **人口**：城市數萬人——遠超任何口述記憶的協調規模。

## 線索與推理 -- 因素咬合

### 線索一：陶籌理論——文字的演化路徑

從實物符號到抽象文字的演化：

| 階段 | 載體 | 功能 |
|------|------|------|
| 陶籌（前 8000） | 陶土小件 | 一籌＝一物（羊、穀） |
| 陶籌封球（前 3500） | 泥球包籌 | 契約（封存後不可改） |
| 籌印泥板（前 3400） | 泥板壓印 | 不需封球的「薄契約」 |
| 楔形文字（前 3200） | 泥板刻符 | 完整記錄：物、量、人、時間 |

**文字是「會計工具的抽象化」**——從「一籌一物」到「一符一音」，中間隔著三千年與一座城市的需求壓力。

### 線索二：記憶外化——協調規模的跳躍

口述記憶的協調上限約數百人（鄧巴數）；文字把「記憶」外化為可查證的記錄：

$$\text{協調規模} = \min\left(\text{人腦記憶}, \text{記錄與檢索能力}\right)$$

**文字解除了「人腦」這個瓶頸**——協調規模的極限從人腦轉移到官僚系統。這是「資訊因素 → 組織因素」的直接因果：有記錄才有稅冊，有稅冊才有帝國。

### 線索三：文字 → 帝國的因果鏈

文字使三種「跨時間與空間的協調」首次可能：

1. **跨空間**：命令與稅冊可以送到遠方（資訊傳輸）。
2. **跨時間**：契約與法律可以超越當事人的生命（漢摩拉比法典的直接前提，[-1754-漢摩拉比法典.md](-1754-漢摩拉比法典.md)）。
3. **跨人**：記錄不因記帳者死亡而消失（組織的「可替換性」——官僚制的基礎，與秦的標準化官員（[-0221-秦的統一與官僚帝國.md](-0221-秦的統一與官僚帝國.md)）同一原理）。

### 線索四：書寫階層的誕生

識字是稀缺技能——書吏成為特權階層（蘇美的 edubba「泥板屋」學校）。**資訊能力 = 權力**：誰控制書寫，誰就控制帝國的記憶——這條規律將在印刷術（[1450-古騰堡印刷革命.md](1450-古騰堡印刷革命.md)）與網路（[1991-全球資訊網.md](1991-全球資訊網.md)）反覆出現。

## 破案時刻

- 約前 3200：烏魯克 IV 層泥板——最早的帳目文字。
- 約前 2600 起：楔形文字成熟，法典、史詩（吉爾伽美什）、書信出現——文字從帳房走進政治與文學。
- 埃及聖書字（約前 3200 同期）、印度河文字（未破譯）、中國甲骨文（約前 1250）——**文字獨立誕生至少四次**，皆出現在農業剩餘與管理需求成熟處。

## 後果 -- 改變了什麼

- **政治**：法典（[-1754-漢摩拉比法典.md](-1754-漢摩拉比法典.md)）、稅冊、官僚帝國。
- **經濟**：契約、信貸、長程貿易的憑證。
- **資訊**：史詩、天文記錄、數學——「可以累積的知識」誕生。
- **社會**：書吏階層、教育、識字特權。

## 因素影響筆記

本案件的因素因果鏈：

1. **經濟剩餘 → 管理需求 → 文字**：文字是需求的產物（先會計後文學）。
2. **文字 → 組織規模 → 帝國**：資訊因素放大組織因素——「記憶外化」是協調的跳躍。
3. **文字 → 標準化 → 可累積的知識**：科學（1543 哥白尼）與官僚制都以「可累積、可比對的記錄」為前提。
4. **識字稀缺 → 書吏權力**：資訊能力=權力的第一定律——直到印刷與網路把「識字權」民主化。
