# -9000-農業革命：剩餘如何創造文明

## 案件摘要

約一萬一千年前，新月沃地的人類開始馴化小麥、大麥、山羊與綿羊，從採集狩獵轉向農耕定居。這樁案件的「兇手」不是某個人，而是一組因素咬合：**氣候（冰期末的穩定溫暖）＋地理（肥沃月彎的可馴化物種）＋科技（馴化與磨石技術）→ 剩餘 → 定居 → 人口爆炸 → 階層與宗教**。農業革命是史上第一次「因素互動的大爆炸」：它創造了國家、文字、戰爭、疾病與神廟——文明的所有零件都在此誕生。

## 前因 -- 多因素的局勢

- **氣候**：約前 12800–前 9700 的新仙女木冷期結束，全球轉為穩定溫暖——農業的時機到了。
- **地理**：肥沃月彎同時擁有野生小麥、大麥、綿羊、山羊、豬、牛——Jared Diamond 所說「可馴化物種的清單」。
- **科技**：採集者已擁有磨石、鐮刀與貯藏技術——「半定居的收穫者」是農業的前身。
- **心理**：早期農民骨骼顯示營養劣於採集者——**農業一開始不是「更好的生活」，是「更高的產量」**。

## 線索與推理 -- 因素咬合

### 線索一：馬爾薩斯的幾何

人口以幾何成長、糧食以算術成長（馬爾薩斯模型）：

$$P_t = P_0 \cdot e^{rt}, \qquad F_t = F_0 + ct$$

農業反轉了這條式子：耕地的糧食密度是採集地的數十倍——**每平方公里可養活的人口從數人跳到數十至數百人**。剩餘就是文明的燃料。

### 線索二：定居 → 生育率

採集者每四、五年生一胎（揹著嬰兒長途遷移）；定居者縮短哺乳間隔，每兩年一胎：

$$\text{人口成長率} \propto \frac{1}{\text{生育間隔}}$$

**定居本身使人口翻倍**——農業與人口形成正向迴路（人口↑→勞力↑→開墾↑→糧食↑→人口↑）。

### 線索三：剩餘的黑暗面——可偷的財富

採集者沒有「可偷的剩餘」；農民的穀倉成為目標。防衛的需求催生：

1. **城牆與戰士**（武器因素：見 [武器與戰法/-3000-戰爭的誕生]）
2. **分配者**（組織因素：管理剩餘的人成為祭司與王）
3. **記錄**（資訊因素：穀倉的帳目→文字，見 [-3200-文字與最早國家.md](-3200-文字與最早國家.md)）

**剩餘 = 階層的誕生**：誰管理剩餘，誰就成為上層。

### 線索四：人畜共生——疾病的代價

與家畜共居使人類感染動物疾病（麻疹、天花來自牛，流感來自豬與鴨）：

$$\text{疾病池} \propto \text{（人畜接觸密度）}$$

農業的隱形代價：**文明的第一批稅，是流行病**——這條線索將在 1347 黑死病（[1347-黑死病.md](1347-黑死病.md)）與 2020 新冠（[2020-新冠疫情與全球測壓.md](2020-新冠疫情與全球測壓.md)）反覆出現。

## 破案時刻

- 約前 9000–前 8000：肥沃月彎的馴化完成；哥貝克力石陣（約前 9500）顯示「祭祀中心可能先於農業」——宗教與農業孰先孰後仍是爭議（案件未完全偵破）。
- 約前 7000 起：農業向歐洲、印度、埃及擴散；約前 5000 中國的稻與粟、美洲的玉米獨立馴化——**農業在全球至少獨立發生七次**。

## 後果 -- 改變了什麼

- **組織**：剩餘→管理階層→酋邦→國家。
- **資訊**：帳目→文字→官僚（[-3200-文字與最早國家.md](-3200-文字與最早國家.md)）。
- **宗教**：祭祀中心→神廟→制度宗教。
- **武器**：可偷的剩餘→戰爭與城牆（[武器與戰法/-3000]）。
- **人口與疾病**：人口爆炸＋人畜共通病。
- **環境**：森林砍伐、馴化物種的擴張——人類第一次大規模改造地貌。

## 因素影響筆記

本案件的因素因果鏈：

1. **氣候 → 農業**：外生觸發器（穩定溫暖）開啟窗口。
2. **地理 → 物種 → 農業**：可馴化清單決定「哪裡先起飛」——地理是選擇器。
3. **農業 → 剩餘 → 組織/宗教/武器/文字**：剩餘是放大器，一切制度的原料。
4. **農業 → 人口 → 勞力 → 更多農業**：第一個正回饋迴路。
5. **農業 → 疾病**：第一個負外部性——文明與瘟疫共生。
