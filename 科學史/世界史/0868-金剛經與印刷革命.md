# 0868-金剛經與印刷革命：東亞的知識複製工程

## 案件摘要

西元 868 年，中國雕版印刷的《金剛經》卷（現藏大英圖書館）成為現存最早有明確日期的印刷書——卷末刻著「咸通九年四月十五日王玠為二親敬造普施」。這樁案件的兇手是一組因素咬合：**紙的量產（科技）＋佛經的複製功德（宗教動機）＋科舉與政府文書（制度市場）**——印刷在東亞首先被「宗教與考試」兩個市場養大。這是知識複製革命的東亞版：比古騰堡早六百年，但走了不同的技術與制度路徑。

## 前因 -- 多因素的局勢

- **科技**：105 蔡倫改進造紙；雕版技術（刻反字、刷墨、拓印）成熟——載體與複製技術俱備。
- **宗教**：佛經的複製被視為功德（「敬造普施」）——宗教動機是印刷的最早投資人。
- **資訊**：漢字字符集龐大——雕版（整版刻）比活字更適合漢字（活字的漢字版要數千字模）。
- **制度市場**：科舉（[0605-科舉與中國官僚帝國.md](0605-科舉與中國官僚帝國.md)）需要標準教材；政府文書量大——「穩定的標準市場」。
- **經濟**：紙的量產與書坊的商業化（唐代長安與四川的書坊）。

## 線索與推理 -- 因素咬合

### 線索一：複製成本的曲線

雕版印刷使「書」從抄本（一冊數月）變成印本（一版千冊）：

$$\text{邊際複製成本} \approx 0 \quad \text{（刻版一次，拓印千次）}$$

**知識複製成本的斷崖**——與古騰堡（[1450-古騰堡印刷革命.md](1450-古騰堡印刷革命.md)）同一物理，早六百年。

### 線索二：宗教動機 = 印刷的早期市場

《金剛經》卷末「為二親敬造普施」：複製佛經=功德——**宗教把「投資印刷」變成積德行為**：

- 佛經、佛像、曆書（政府專營）是唐代印刷的三大市場。
- **宗教與政治是早期印刷的「需求方」**——商業印刷（小說、戲曲）要到宋代才起飛。

### 線索三：雕版 vs 活字的技術路徑

| | 中國雕版 | 古騰堡活字 |
|---|----------|------------|
| 字符集 | 漢字（數千） | 拉丁字母（26＋符號） |
| 適合 | 漢字（整版刻製） | 字母（字模可重組） |
| 改版成本 | 高（整版重刻） | 低（重排字模） |
| 社會效果 | 標準文本（佛經、儒典） | 異議傳播（宗教改革） |

**字符集的大小決定技術路徑**——拉丁字母的小字符集使「活字」經濟；漢字的大字符集使「雕版」經濟。**技術選擇是「因素結構」的函數**（語言結構→技術路徑）。

### 線索四：科舉 = 印刷的「標準市場」

科舉使教材有「全國一致的標準需求」——印刷與科舉互相強化：

$$\text{印刷規模} \propto \text{（標準化的需求）}$$

**制度（科舉）養大技術（印刷）**——與歐洲的對照：古騰堡的第一批大單是「贖罪券」與聖經（宗教市場），其後的爆炸來自「異議」（宗教改革）——**需求結構決定技術的社會效果**。

## 破案時刻

- 868《金剛經》卷：現存最早有日期的印刷書（王玠的功德印刷）。
- 宋代（10–13 世紀）：印刷的黃金時代——官刻、坊刻、私刻並立；活字（畢昇，約 1045）發明但未成主流（雕版仍經濟）。
- 8–10 世紀：印刷術經佛教圈傳入朝鮮、日本；西傳（造紙 751 怛羅斯→撒馬爾罕→巴格達）。

## 後果 -- 改變了什麼

- **資訊**：東亞的標準文本與識字傳統（科舉+印刷的共生）。
- **宗教**：佛經的普及、藏經的量產——佛教的印刷傳播。
- **知識**：宋代的知识爆炸（方志、醫書、農書）。
- **世界史**：印刷在東亞強化了「帝國與考試」，在歐洲強化了「異議與革命」——**同一技術、不同制度、不同效果**（技術的制度決定論的反例）。

## 因素影響筆記

本案件的因素因果鏈：

1. **科技（紙+雕版）→ 複製成本↓**：知識複製的斷崖。
2. **宗教（功德）＋制度（科舉）→ 印刷的需求方**：誰養大技術，誰決定技術的用途。
3. **語言結構（漢字）→ 技術路徑（雕版）**：因素結構決定技術選擇。
4. **同一技術、不同制度、不同效果**：東亞（帝國穩定）vs 歐洲（異議革命）——技術沒有單一「社會效果」，制度的結構才是變數。
