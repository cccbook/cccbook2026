# 1869 Mendeleev 週期表

## 案發現場

1860 年代末，化學終於擁有了可靠的度量衡（見 [1860-Cannizzaro原子量重整.md](1860-Cannizzaro原子量重整.md)）：統一的原子量表確立了，化學式標準化了。到 1869 年，已知的元素已有 63 種，各自的原子量、密度、化學性質都被測定得相當精確。

但這些資料是一盤散沙。化學家面對一個最根本的問題：

**63 種元素，性質五花八門——鈉是活潑的金屬、氯是劇毒的氣體、金是惰性的貴金屬。這些性質之間，有任何規律可言嗎？還是元素的性質只是造化的隨機安排？**

在 Mendeleev 之前，已有數位化學家試圖尋找規律：

- 1829 年德國的 Döbereiner 提出「三元素組」（triads）：鋰鈉鉀、氯溴碘性質相似、原子量居中者約為兩端平均——但只適用於少數幾組。
- 1862 年法國的 de Chancourtois 按原子量把元素排成螺旋（「地螺旋」），可惜未受重視。
- 1864 年英國的 Newlands 提出「八音律」：每第 8 個元素性質重複，像音階——卻被同行嘲笑，論文甚至不被皇家化學會刊載。
- 1868 年德國的 Lothar Meyer 也畫出了週期圖表，但遲遲未發表。

這些嘗試共同的困境：**只按原子量排列，遇到例外就亂了手腳**；而且沒有人敢於回答一個更深的問題——**規律中出現「空位」，是失敗，還是預言？**

破案者，是聖彼得堡大學的俄國化學家德米特里·門得列夫（Dmitri Mendeleev, 1834–1907）。

## 偵查過程

門得列夫的破案方式，堪稱化學史上最著名的一場「資料整理」。據他自述，他為編寫教科書《化學原理》而整理元素資料，把 63 種元素各寫在一張卡片上，像玩紙牌一樣反覆排列組合——按原子量、按性質、按價數，尋找最佳的重複節奏。

他的關鍵突破有兩步：

**第一步：按原子量排列，性質呈週期性重複。**

把元素按原子量由小到大排列，會發現性質相似的元素「每隔固定間隔」重複出現。以第 2、3 週期為例（門得列夫當時的排列）：

$$\mathrm{Li \; Be \; B \; C \; N \; O \; F \; Na \; Mg \; Al \; Si \; P \; S \; Cl \cdots}$$

鋰與鈉（同為活潑鹼金屬）、碳與矽（同為形成四鍵的元素）、氟與氯（同為活潑鹵素）——性質以 8 為週期重複。門得列夫把這條規律寫成：

$$\text{元素的性質，是原子量的週期函數}$$

**第二步（也是最驚人的一步）：遇到矛盾，相信規律勝過相信數據。**

按原子量排列時，門得列夫遇到幾處「例外」：例如碘（127）的原子量大於碲（128 的近鄰），但性質上碘明顯屬於鹵素族、碲屬於氧族。換作 Newlands 等人，這種例外足以推翻整個規律。

門得列夫的處理方式石破天驚：**他宣布，某些原子量一定是測錯了；更重要的是，他在表中留下空位——不是規律失敗了，而是那些元素還沒被發現！**

他在 1869 年的論文中留下三個空位，並**精確預言**了這些未知元素的性質：

- **類鋁（eka-aluminium）**：原子量約 68，密度約 5.9，熔點低，氧化物化學式 $\mathrm{E_2O_3}$——
- **類矽（eka-silicon）**：原子量約 72，密度約 5.5，氧化物 $\mathrm{EO_2}$、氯化物 $\mathrm{ECl_4}$——
- **類硼（eka-boron）**：原子量約 44——

這是科學史上最著名的一次「盲測預言」：他從未見過這些元素，卻連密度、熔點、氧化物化學式都寫了出來。**規律不僅能整理已知，還能預言未知——這才是理論真正的力量。**

兌現來得很快：1875 年，法國的 Boisbaudran 發現鎵（Ga）——原子量 69.7、密度 5.94、熔點 29.8°C，與「類鋁」的預言幾乎分毫不差（門得列夫甚至寫信指出 Boisbaudran 測的密度 4.7 有誤，重測後證實為 5.94！）；1886 年德國的 Winkler 發現鍺（Ge），與「類矽」吻合；1879 年瑞典的 Nilson 發現鈧（Sc），與「類硼」吻合。三大預言全部兌現，懷疑者啞口無言。

## 結案報告

門得列夫週期表的遺產，是化學史上無出其右的：

1. **週期律成為化學的總綱**——元素不再是雜亂的名單，而是有內在秩序的系統。整個無機化學、乃至化學教育，從此以週期表為組織框架。
2. **科學預言力的典範**——鎵、鍺、鈧的預言兌現，是「理論預言未知事實」的教科書案例，與天文學中海王星的預言齊名。
3. **「規律中的例外」的方法論**——遇到矛盾時，先懷疑數據、保留規律、預言未知。這一策略在科學史上反覆奏效。
4. **為原子結構鋪路**——週期律「為什麼」成立，要等到二十世紀：1913 年莫色勒（Moseley）發現以原子序（核電荷數）排列更完美，解決了碘-碲等例外；波耳的殼層模型與量子力學最終解釋了週期性的電子組態根源。門得列夫抓住的是規律，二十世紀的物理學給出了機制。
5. **元素週期表的實用帝國**——從新材料設計（半導體、觸媒）到尋找礦產，週期表至今是化學家、材料科學家每日使用的「地圖」。

1906 年，門得列夫以一票之差與諾貝爾化學獎擦身而過（次年他便去世，諾獎不追授逝者）。但歷史已給了他最高的評價：**今日任何一間化學教室、實驗室牆上那張六彩斑斕的表，就是他的紀念碑。**

## 證據與工具

```python
# 用 Python 重演 Mendeleev 的推理：
# (1) 按原子量排列觀察週期性 (2) 空位預言 (3) 預言兌現檢驗

# --- 1869 年已知元素的部分資料（原子量取當時近似值）---
elements = [
    # (符號, 原子量, 族別)
    ("H", 1, "I"),   ("Li", 7, "I"),  ("Be", 9, "II"),
    ("B", 11, "III"),("C", 12, "IV"), ("N", 14, "V"),
    ("O", 16, "VI"), ("F", 19, "VII"),
    ("Na", 23, "I"), ("Mg", 24, "II"),("Al", 27, "III"),
    ("Si", 28, "IV"),("P", 31, "V"),  ("S", 32, "VI"),
    ("Cl", 35.5, "VII"),
]

# --- 第一步：按原子量排列，觀察族別的週期重複 ---
print("--- 按原子量排列（族別以 8 為週期重複）---")
for sym, aw, group in sorted(elements, key=lambda e: e[1]):
    print(f"  {sym:3s} {aw:6.1f}  族 {group}")

# --- 第二步：空位預言 ---
print("\n--- 空位與預言（eka- = 『下一個同族』）---")
predictions = {
    "類鋁 eka-Al": {"原子量": 68, "密度": 5.9, "氧化物": "E2O3"},
    "類矽 eka-Si": {"原子量": 72, "密度": 5.5, "氧化物": "EO2"},
    "類硼 eka-B":  {"原子量": 44, "密度": 4.0, "氧化物": "E2O3"},
}
for name, p in predictions.items():
    print(f"{name}: 原子量≈{p['原子量']}, 密度≈{p['密度']}, {p['氧化物']}")

# --- 第三步：預言兌現檢驗 ---
print("\n--- 預言 vs 實際（後來發現的元素）---")
actual = {
    "鎵 Ga（1875）": {"原子量": 69.7, "密度": 5.94},
    "鍺 Ge（1886）": {"原子量": 72.6, "密度": 5.32},
    "鈧 Sc（1879）": {"原子量": 45.0, "密度": 3.0},
}
for name, a in actual.items():
    print(f"{name}: 原子量={a['原子量']}, 密度={a['密度']} → 與預言吻合 ✓")

# --- 第四部分：碘-碲例外與原子序 ---
print("\n--- 『規律中的例外』與最終解方 ---")
print("按原子量：碲(127.6) 應排在碘(126.9) 之後")
print("按性質：  碘是鹵素（VII 族），碲是氧族（VI 族）→ 例外！")
print("Mendeleev：相信性質規律，把碘排在碲後（正確！)")
print("1913 年 Moseley：以原子序（核電荷）排列 → Te(52) < I(53)，例外消失")
print("週期律的真正基礎是原子序，不是原子量")
```
