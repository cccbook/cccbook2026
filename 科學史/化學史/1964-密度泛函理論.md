# 1964 密度泛函理論

## 案發現場

量子化學自 1927 年誕生後（見 [1927-HeitlerLondon氫分子.md](1927-HeitlerLondon氫分子.md)），理論上一切皆可計算，實際上卻寸步難行。案發現場的難題是：**多電子波函數的維度災難**。

薛丁格方程 $\hat{H}\Psi = E\psi$ 的解是波函數 $\Psi(\vec{r}_1, \vec{r}_2, \ldots, \vec{r}_N)$——$N$ 個電子的波函數是 $3N$ 個座標的函數。每個電子還要描述自旋與反對稱性。結果是：電子數每增加一個，波函數的自變量就多三個維度——一個含 100 個電子的分子，波函數是 300 維的函數，根本無法儲存、更無法計算。Hartree-Fock 方法用單一 Slater 行列式近似，但電子相關能（correlation energy）的計算代價隨電子數以高次方暴漲。

難道化學的精確計算是永遠的夢？1964 年，兩位物理學家——皮埃爾·霍恩堡（Pierre Hohenberg）與沃特·孔恩（Walter Kohn, 1923–2023）——證明了一個石破天驚的定理，把問題從 $3N$ 維砍回到三維。

## 偵查過程

**第一步：Hohenberg-Kohn 第一定理（破案關鍵）。** 1964 年霍恩堡與孔恩證明：

> **基態能量與所有基態性質，由電子密度 $\rho(\vec{r})$ 唯一決定**（差一個常數的位能除外）。

推理的核心是一個反證法：假設有兩個不同的外部位能 $v(\vec{r})$ 與 $v'(\vec{r})$ 導致**相同的**基態密度 $\rho(\vec{r})$。兩個系統各有一個基態波函數 $\Psi$ 與 $\Psi'$。由變分原理：

$$E = \langle\Psi|\hat{H}|\Psi\rangle < \langle\Psi'|\hat{H}|\Psi\rangle = E' + \int (v - v')\rho\, d\vec{r}$$

$$E' < E + \int (v' - v)\rho\, d\vec{r}$$

兩式相加得 $E + E' < E + E'$——矛盾！因此密度決定位能、位能決定波函數、波函數決定一切。**$\rho(\vec{r})$ 是三維函數**，問題的維度從 $3N$ 砍到 3。而且能量可以寫成密度的泛函：

$$E[\rho] = T[\rho] + \int v(\vec{r})\rho(\vec{r})\, d\vec{r} + V_{ee}[\rho]$$

**第二步：第二定理。** 變分原理在密度空間也成立：對任何滿足條件的密度 $\tilde{\rho}$，

$$E[\tilde{\rho}] \geq E[\rho_0]$$

因此可以用「密度變分」求基態。

**第三步：Kohn-Sham 方程（實用化）。** 難題是：$T[\rho]$ 與 $V_{ee}[\rho]$ 的精確形式未知。1965 年孔恩與沈呂九（Lu Jeu Sham）提出絕妙方案：引入一個虛構的「無相互作用電子系統」，其密度與真實系統相同。這個虛構系統的電子 obey 一組單電子方程——Kohn-Sham 方程：

$$\left[-\frac{\hbar^2}{2m}\nabla^2 + v_{eff}(\vec{r})\right]\phi_i = \varepsilon_i \phi_i$$

其中有效位能包含三部分：

$$v_{eff}(\vec{r}) = v(\vec{r}) + \int \frac{e^2\rho(\vec{r}')}{4\pi\varepsilon_0 |\vec{r} - \vec{r}'|} d\vec{r}' + v_{xc}(\vec{r})$$

最後一項 $v_{xc} = \delta E_{xc}[\rho]/\delta\rho$ 是交換相關位能——所有未知的量子效應都塞進這一項。實務上用近似泛函（如 LDA 局域密度近似、GGA 廣義梯度近似）：

$$E_{xc}^{LDA}[\rho] = \int \rho(\vec{r})\, \varepsilon_{xc}^{unif}(\rho(\vec{r}))\, d\vec{r}$$

於是計算流程自洽：猜一個 $\rho$ → 解 Kohn-Sham 方程得 $\phi_i$ → 由 $\rho = \sum_i |\phi_i|^2$ 更新 $\rho$ → 迭代到自洽。多電子問題變成了「一組單電子方程 + 三維密度」的可解問題。

## 結案報告

孔恩因 DFT 獲 1998 年諾貝爾化學獎（與波普爾 John Pople 共享，後者的 Gaussian 軟體把計算化學大眾化，見 [1995-計算化學.md](1995-計算化學.md)）。頒給化學獎別具意義：一個純數學定理，最終成為化學家的日常工具。遺產包括：

1. **計算化學的主力**：DFT 因計算量隨電子數增長緩慢（約 $N^3$），能處理數百到數千原子——材料科學、催化、生物大分子的計算幾乎全用 DFT。
2. **固態物理的標準工具**：Kohn 本人是固態物理學家，DFT 最初就為固體而生，半導體、金屬、表面的計算由此革命。
3. **泛函的持續進化**：B3LYP、hybrid 泛函、double-hybrid、range-separated 泛函不斷推高精度；「機器學習泛函」是當前前沿。
4. **維度縮減思想的典範**：把 $3N$ 維波函數換成三維密度——這種「換變數」的偵查思路啟發了凝聚態與量子多體理論的諸多發展。

## 證據與工具

```python
# 用 Kohn-Sham 的自洽場（SCF）思想解一個最簡模型：一維「原子」
import numpy as np
import matplotlib.pyplot as plt

# 一維模型：電子在外部位能 v(x) 中，含簡化的 Hartree 交換項
# 迭代：猜密度 → 解方程 → 更新密度 → 直到自洽
Ngrid = 200
x = np.linspace(-10, 10, Ngrid)
dx = x[1] - x[0]

# 外部位能：簡諧阱 + 位障（模擬「原子」）
v_ext = 0.5 * x**2 * 0.1

# 有限差分的拉普拉斯算子（二階）
lap = (np.eye(Ngrid, k=1) - 2*np.eye(Ngrid) + np.eye(Ngrid, k=-1)) / dx**2
H0 = -0.5 * lap + np.diag(v_ext)

# 初始密度：兩個電子占據最低軌域
_, psi = np.linalg.eigh(H0)
rho = 2 * psi[:, 0]**2

# 自洽場迭代（簡化：交換相關用局域近似 Xα）
for it in range(50):
    # Hartree 位能（一維簡化泊松解）
    v_H = np.convolve(rho, 1.0 / (np.abs(x) + 1.0), mode="same") * 0.5
    v_xc = -0.7 * rho**(1/3)        # Xα 交換近似
    H = H0 + np.diag(v_H + v_xc)
    E, psi = np.linalg.eigh(H)
    rho_new = 2 * psi[:, 0]**2
    rho = 0.5 * rho + 0.5 * rho_new   # 混合阻尼收斂

print(f"自洽收斂後基態能量 E = {E[0]:.4f}（任意單位）")
print("→ Kohn-Sham 流程：密度 → 單電子方程 → 新密度 → 迭代至自洽")

plt.plot(x, rho / rho.max(), label=r"電子密度 $\rho(x)$")
plt.plot(x, v_ext / np.abs(v_ext).max(), "--", label="外部位能")
plt.xlabel("x"); plt.ylabel("（歸一化）")
plt.title("Kohn-Sham 自洽場迭代收斂後的電子密度")
plt.legend(); plt.show()
```
