# 1929 Carothers尼龍

## 案發現場

1920 年代末，Staudinger 的大分子假說（見 [1912-Staudinger高分子化學.md](1912-Staudinger高分子化學.md)）仍在學界苦戰，缺乏決定性的化學證據。與此同時，美國化學工業巨頭 DuPont（杜邦）正在轉型：火藥生意受一次大戰後軍備縮減影響，公司決心投入基礎研究，尋找新的化學產品。

1928 年，32 歲的哈佛大學有機化學教授 Wallace Hume Carothers 接受 DuPont 的邀請，出任基礎化學研究部主管。他面對的「案發現場」是：人工合成高分子雖然已有酚醛樹脂等工業產品，但那些製程是憑經驗摸索的「黑箱」，沒有人能說清楚聚合是怎麼發生的、鏈長如何控制。若要讓高分子成為可設計的科學，必須先弄清聚合的機理。而且當時還有一個誘人的目標：天然絲的結構已由 X 射線繞射顯示為長鏈，若能用簡單分子人工合成類絲纖維，市場潛力無可限量。

## 偵查過程

Carothers 的偵查思路是「先設計一個乾淨的案件」：不用成分不明的天然原料，而用純度極高的單一化合物，一步一步追蹤聚合過程。他選擇**縮合聚合**（condensation polymerization）路線：帶兩個官能基的單體（如二酸與二胺）反應時，脫去一個小分子（水），官能基之間形成新鍵，鏈因此逐步增長。

以尼龍 6,6 為例：己二酸 $\mathrm{HOOC-(CH_2)_4-COOH}$ 與己二胺 $\mathrm{H_2N-(CH_2)_6-NH_2}$ 縮合，形成醯胺鍵（胜肽鍵的工業版）：

$$n\,\mathrm{HOOC-(CH_2)_4-COOH} + n\,\mathrm{H_2N-(CH_2)_6-NH_2}
\rightarrow \mathrm{[-OC-(CH_2)_4-CO-NH-(CH_2)_6-NH-]_n} + 2n\,\mathrm{H_2O}$$

他進一步把聚合動力學寫成清晰的數學。定義反應程度 $p$ 為官能基已反應的分數，則平均聚合度（數均）為

$$\bar{X}_n = \frac{1}{1-p}$$

這條「Carothers 方程式」揭示縮合聚合的殘酷本質：要得到長鏈，反應必須幾乎完全。若 $p = 0.98$，$\bar{X}_n = 50$；若 $p = 0.995$，$\bar{X}_n = 200$；要 $\bar{X}_n = 1000$，需要 $p = 0.999$——九成九都不夠！這解釋了為何早期縮合聚合實驗只能得到黏稠低聚物：不是理論錯，而是反應程度不夠高。

Carothers 由此推理出工程解法：用減壓蒸餾把縮合產生的水抽走、提高溫度、精確控制兩種單體的等莫耳比。他還設計「分子蒸餾器」，在 1930 年首先合成出聚酯，1934 年合成出聚醯胺。1935 年 2 月 28 日，尼龍 6,6 問世——強度堪比鋼絲、細度勝過蠶絲。

## 結案報告

Carothers 的工作為 Staudinger 的大分子假說提供了決定性化學證據：既然由已知小分子逐步縮合就能造出與天然絲同級的纖維，聚合物是共價長鏈已無可辯駁。更重要的是，他把聚合從經驗黑箱變成可計算的工程科學：$\bar{X}_n = \frac{1}{1-p}$ 成為所有逐步聚合製程的設計公式，高分子工業由此起飛。

1938 年，DuPont 宣布尼龍量產，1939 年尼龍絲襪在紐約世界博覽會亮相，掀起瘋狂搶購熱潮——發售首日數萬雙售罄，甚至引發「尼龍暴動」。二戰期間尼龍轉作降落傘與軍用繩索，戰後重歸民用，徹底改寫紡織業。可惜 Carothers 本人未能見證榮景：他長期受憂鬱症所苦，1937 年 4 月服毒自盡，年僅 41 歲。尼龍之後，聚酯、芳綸、工程塑膠一路延續，逐步聚合的數學至今仍是材料工程的必修課。

## 證據與工具

```python
# --- Carothers 方程式：X̄n = 1/(1-p) ---
print("反應程度 p    平均聚合度 X̄n")
for p in [0.90, 0.98, 0.99, 0.995, 0.999]:
    print(f"  {p:.3f}        {1/(1-p):>6.0f}")

# 要造出 DP = 1000 的長鏈需要多高的反應程度？
dp_target = 1000
p_need = 1 - 1 / dp_target
print(f"\n目標 X̄n = {dp_target} → 需要 p = {p_need:.4f}（99.9% 官能基都要反應）")

# --- 尼龍 6,6 縮合：質量核算 ---
# 己二酸 C6H10O4 (146 g/mol) + 己二胺 C6H16N2 (116 g/mol)
# 重複單元 = 146 + 116 - 2*18(脫水) = 226 g/mol
M_diacid, M_diamine = 146, 116
M_unit = M_diacid + M_diamine - 2 * 18
n_mol = 1.0  # 1 mol 單體對
print(f"重複單元分子量 = {M_unit} g/mol")
water = 2 * n_mol * 18
print(f"1 mol 單體對完全縮合 → 產生水 {water:.0f} g，聚合物 {M_unit * n_mol:.0f} g")

# 尼龍纖維 DP 估算：典型纖維級分子量約 20,000
dp = 20000 / M_unit
print(f"分子量 20,000 的尼龍 → 聚合度 ≈ {dp:.0f} 個重複單元")
```
