# 1746 鉛室法硫酸：第一個沒有名字的催化劑

## 案發現場

十八世紀中葉，歐洲的化學工業撞上了一堵牆。硫酸——當時被煉金術士稱為「硫酸油」（oil of vitriol）——是染整、漂白、製鹼、金屬加工的萬用鑰匙，但製法原始：把硫磺與硝石混在玻璃鐘罩裡燃燒，讓酸霧凝結。這是**分批、小量、昂貴**的手工業，玻璃鐘罩又貴又易碎，一爐只有幾磅的產量。

需求卻在爆炸式增長：紡織漂白要酸、黃銅加工要酸、幾十年後 Leblanc 蘇打法（[1791-Leblanc蘇打工業.md](1791-Leblanc蘇打工業.md)）的第一道工序就是硫酸分解食鹽。**誰能大量、便宜、連續地生產硫酸，誰就握住化學工業的命脈。**

伯明罕的醫生轉行實業家約翰·羅巴克（John Roebuck）看準了這一點。他面對的工程謎題：

> **玻璃鐘罩又小又貴——有沒有一種便宜、耐酸、可做成大容積的材料來當反應室？**

答案是金屬鉛：稀硫酸對鉛的腐蝕極慢（鉛表面生成難溶的硫酸鉛保護膜），且鉛便宜、可焊接成大箱。1746 年，羅巴克在伯明罕建起第一座**鉛室**——用鉛板焊成的方形大反應室，此後在蘇格蘭普雷斯頓潘斯（Prestonpans）與加伯特定夥伴擴建成工業規模。硫酸從「磅級手工業」進入「噸級大工業」。

## 偵查過程

鉛室法真正的化學謎團是：**硫磺在鉛室裡為什麼「燒」得比在鐘罩裡快得多、完全得多？** 原始製法中的硝石（$\mathrm{KNO_3}$）本以為只是提供氧，但工程師很快發現硝石的用量少得驚人——像是在「循環使用」。用現代化學重建這條偵查鏈：

**線索一：氮氧化物在循環。** 硝石受熱分解提供 $\mathrm{NO_2}$，它把自身的「活化氧」交給二氧化硫，自己變回 $\mathrm{NO}$：

$$\mathrm{SO_2 + NO_2 \rightarrow SO_3 + NO}$$

**線索二：NO 自己會「復活」。** 在鉛室流通的空氣中，$\mathrm{NO}$ 與氧氣結合變回 $\mathrm{NO_2}$：

$$\mathrm{2\,NO + O_2 \rightarrow 2\,NO_2}$$

**線索三：中間儲庫。** 部分 $\mathrm{NO_x}$ 與酸結合成「亞硝醯硫酸」（鉛室晶），$\mathrm{NOHSO_4}$——這正是 NOx 被「留住再放出」的儲庫，解釋了為何硝石用量遠低於計量比。

**總反應（NOx 完全回收）：**

$$\mathrm{2\,SO_2 + O_2 + 2\,H_2O \xrightarrow{\ NO_x\ 循環\ } 2\,H_2SO_4}$$

這就是答案：**氮氧化物是催化劑**——參與反應、改變路徑、加速反應，但自身不被消耗。羅巴克與後來的工程師們憑經驗搭建了人類第一個工業規模的**均相催化循環**，比 Ostwald 給「催化」下科學定義（[1884-Ostwald催化與平衡.md](1884-Ostwald催化與平衡.md)）早了將近一百四十年。Berzelius 要到 1835 年才發明「catalysis」這個詞。

**後續偵查（工程改良）：** 鉛室法的酸只能濃到約 78%（太濃 NOx 揮發損失），且 NOx 尾氣外洩造成污染。1827 年 Gay-Lussac 設計吸收塔把尾氣 NOx 收進濃酸，1859 年 Glover 塔再把它「吐」回系統——催化劑從此真正零損耗循環。1875 年起，接觸法（$\mathrm{V_2O_5}$ 或 Pt 固相催化）以更直接的 $\mathrm{SO_2 \rightarrow SO_3}$ 路線逐漸取代鉛室法，但鉛室法統治硫酸工業整整一個半世紀。

## 結案報告

1. **工業化學的基石**：硫酸產量自此成為各國工業化的經典指標（「一國的工業化程度，看它消耗多少硫酸」）。鉛室法讓硫酸從奢侈品變成大宗化學品。
2. **催化先於催化理論**：鉛室法的 NOx 循環是工業催化的開山案例，啟發了 Ostwald 的催化研究與後來的 Ostwald 法製硝酸——理論姍姍來遲，工程早已跑通。
3. **材料選擇的教科書**：「耐蝕、便宜、可成型」三條件選出鉛，是化工材料選型的原型；當代化工選材（襯鉛、玻璃鋼、聚四氟乙烯——[1938-Teflon與偶然發現.md](1938-Teflon與偶然發現.md)）仍是同一題目。
4. **大工業生態的起點**：硫酸廉價化→漂白量產→棉紡革命→肥料（過磷酸鈣）→化學工業整體起飛。一種酸的規模化，撬動了整個工業革命。

## 證據與工具

**催化循環的圖式化：**

```
        SO2 ──(NO2 交出活化氧)──> SO3 ──(H2O)──> H2SO4
         ↑                          │
        NO <──────────────────────┘（副產物）
         │
         └──(O2)──> NO2 ──（回到第一步）──> 循環
```

**鉛室法 vs 接觸法對照：**

| 項目 | 鉛室法（1746） | 接觸法（1831 專利/1875 商用） |
|------|----------------|-------------------------------|
| 催化劑 | $\mathrm{NO_x}$（均相，氣相循環） | $\mathrm{Pt}$ → $\mathrm{V_2O_5}$（非均相，固相） |
| 酸濃度 | 約 78% | 98% 以上（發煙硫酸） |
| 容器 | 鉛板大室 | 鋼製轉化器 |
| 特點 | 可混入雜質原料、易操作 | 需精製氣體、酸更純更濃 |
| 催化概念問世 | 早於「catalysis」一詞 89 年 | 晚於鉛室法 85 年 |

**鉛耐稀硫酸的原因：** 鉛與稀硫酸反應生成緻密難溶的 $\mathrm{PbSO_4}$ 薄膜覆蓋表面，反應自我阻斷——這是「鈍化」概念的早期工業應用。

$$\mathrm{Pb + H_2SO_4 \rightarrow PbSO_4(難溶膜) + H_2\uparrow}$$

**結論：** 鉛室法的故事示範了工業化學史的一個反覆出現的模式：**工程先跑通，理論後補票**。NOx 循環在「催化劑」一詞誕生前近九十年就已在鉛室裡運轉——偵探破案靠的是現場（鉛室）的異常觀察（硝石用量遠低於計量比），而不是先有理論。
