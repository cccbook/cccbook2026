# 1965 Woodward-Hoffmann 規則

## 案發現場

1960 年代，有機化學家遇到一群「不守規矩」的反應——周環反應（pericyclic reactions）：電環化反應、環加成反應、σ 遷移反應。它們的怪異之處有兩個案發現場：

**現場一：立體化學的詭異選擇。** 加熱丁二烯電環化成環丁烯時，兩端的取代基**同方向**旋轉（順旋）；但光照時卻**反方向**旋轉（對旋）。加熱與光照為什麼會選擇完全不同的立體路徑？用電子效應、空間位阻都解釋不了。

**現場二：狄耳士-阿德反應的專一性。** 環加成反應（如丁二烯 + 乙烯）在加熱下順利進行，但有些 [2+2] 環加成加熱下卻完全不發生、只有光照才行。為什麼 [4+2] 行、[2+2] 不行？

這些規律當時只能靠經驗記憶，沒有統一理論。哈佛大學的有機合成大師伍德沃德（Robert B. Woodward, 1917–1979）在合成維生素 $\mathrm{B_{12}}$ 時碰到了無法解釋的立體化學怪象，他找來年輕的理論化學家霍夫曼（Roald Hoffmann, 1937–），兩人於 1964–65 年合作破解了這個案子——這也是「理論預言反應」的典範之作。

## 偵查過程

**第一步：福井谦一的前線軌域啟發。** 1952 年日本的福井谦一（Kenichi Fukui）已提出「前線軌域」思想：反應主要由最高占據軌域（HOMO）與最低未占軌域（LUMO）的相互作用決定。Woodward 與 Hoffmann 接過這個思想，但走得更深：**軌域的對稱性**。

**第二步：軌域對稱性守恆（破案關鍵）。** Hoffmann 用分子軌道理論計算了丁二烯的 $\pi$ 軌域：四個碳的 $p$ 軌域組成四個分子軌域 $\psi_1$ 到 $\psi_4$，能量遞增，基態時 $\psi_1$、$\psi_2$ 占據（各含兩電子）。關鍵在於這些軌域的**對稱性**：

- 丁二烯的 HOMO 是 $\psi_2$，兩端碳的 $p$ 軌域**相位相反**；
- 環丁烯開環生成的雙鍵要求兩端軌域同相位重疊。

要讓 HOMO 的兩端在環化時「順利對接」，只有一種旋轉方式能保持軌域的相位匹配（對稱性守恆）：**順旋**（conrotatory，兩端同向旋轉）。若對旋（disrotatory），兩端相位相反、破壞性干涉，反應禁阻。而**光照**時電子躍遷到 $\psi_3$（新 HOMO），兩端相位相同——此時**對旋**才對稱允許：

$$\text{加熱（基態）} \to \text{順旋}; \qquad \text{光照（激發態）} \to \text{對旋}$$

**第三步：一般化規則。** Woodward 與 Hoffmann 把規則一般化為「軌域對稱性守恆原理」：**周環反應沿著保持軌域對稱性的路徑進行**。用電子對數判斷：

| 電子對數 | 加熱 | 光照 |
|---|---|---|
| 奇數對（如 $4n+2$ 電子） | 對旋/允許 | 順旋/禁阻 |
| 偶數對（如 $4n$ 電子） | 順旋/允許 | 對旋/禁阻 |

（電環化反應）；環加成則由參與電子數判斷：[4+2]（6 電子）熱允許、[2+2]（4 電子）熱禁阻、光允許——狄耳士-阿德反應的專一性破解。1969 年兩人出版《軌域對稱性守恆》專書，規則的表格形式成為有機化學家的速查工具。

## 結案報告

霍夫曼與福井谦一共享 1981 年諾貝爾化學獎（伍德沃德 1979 年去世，未能分享——這是諾獎史上最令人惋惜的遺珠之一；他已於 1965 年因有機合成獲獎）。遺產包括：

1. **理論預言反應**：有機化學從「經驗歸納」升級為「理論預測」——化學家可以用軌域對稱性預言新反應是否可行、產物是何種立體化學。維生素 $\mathrm{B_{12}}$ 的全合成（Woodward 最偉大的戰役）就用了這些規則設計路徑。
2. **前線軌域理論的確立**：HOMO/LUMO 成為有機反應機構與反應位向預測的核心語言，與路易斯酸鹼（親電/親核）理論接軌（見 [1916-Lewis共價鍵.md](1916-Lewis共價鍵.md)）。
3. **分子軌道理論的勝利**：此規則建立在 MO 對稱性上，使 MO 理論在有機化學中確立主流地位，通往計算化學（見 [1964-密度泛函理論.md](1964-密度泛函理論.md)、[1995-計算化學.md](1995-計算化學.md)）。
4. **光化學的理論基礎**：激發態反應的選擇規則，開啟了現代光化學。

## 證據與工具

```python
# 丁二烯 π 軌域係數與 Woodward-Hoffmann 順旋/對旋判斷
import numpy as np
import matplotlib.pyplot as plt

# 丁二烯（4 個 p 軌域）的 Hückel 分子軌域係數
# c_k(j) = sqrt(2/5) * sin(j·k·π/5)
N = 4
k = np.arange(1, N+1)
j = np.arange(1, N+1)
C = np.array([[np.sqrt(2/5)*np.sin(jj*kk*np.pi/5) for kk in k] for jj in j])
E = [-2*np.cos(kk*np.pi/5) for kk in k]   # Hückel 能量 (α + xβ)

print("丁二烯 π 分子軌域（Hückel）：")
for idx, e in enumerate(E[::-1]):
    occ = "占據(HOMO)" if idx == 1 else ("占據" if idx < 2 else "空軌域(LUMO)" if idx == 2 else "空軌域")
    print(f"  ψ{N-idx}: 能量 x={e:+.3f}β  端點係數 C1={C[0, N-1-idx]:+.3f}, "
          f"C4={C[3, N-1-idx]:+.3f}  [{occ}]")

# 判斷軌域對稱性守恆 → 順旋/對旋
homo = C[:, N//2 - 1]        # 基態 HOMO (ψ2)
lumo = C[:, N//2]            # 基態 LUMO (ψ3)
phase_homo = np.sign(homo[0]) * np.sign(homo[-1])
phase_lumo = np.sign(lumo[0]) * np.sign(lumo[-1])
print(f"\n基態 HOMO 兩端相位相同？{phase_homo > 0}（相反 → 加熱時需順旋）")
print(f"激發態(電子躍遷後)新 HOMO = ψ3 兩端相位相同？{phase_lumo > 0}（相同 → 光照時對旋）")
print("\nWoodward-Hoffmann 規則：")
print("  加熱（4 電子，偶數對）→ 順旋允許；光照 → 對旋允許")

# 畫出 ψ2 與 ψ3 的軌域示意圖
fig, axes = plt.subplots(1, 2, figsize=(8, 3))
for ax, idx, name in zip(axes, [N//2-1, N//2], ["ψ₂ (HOMO)", "ψ₃ (LUMO)"]):
    coef = C[:, idx] * np.sign(C[0, idx])
    xs = np.linspace(0, N-1, 200)
    wave = np.sqrt(2/5)*np.sin((xs+1)*(idx+1)*np.pi/5)
    ax.plot(xs, wave)
    for c_i, cc in enumerate(coef):
        ax.plot(c_i, cc, "o")
    ax.axhline(0, color="gray", ls=":")
    ax.set_title(f"丁二烯 {name}（端點相位關係決定旋轉方式）")
plt.tight_layout(); plt.show()
```
