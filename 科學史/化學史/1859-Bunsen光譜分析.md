# 1859 Bunsen 光譜分析

## 案發現場

1850 年代的海德堡大學，化學家羅伯特·本生（Robert Bunsen）正面臨一個古老而惱人的難題：如何分辨元素的身分？

當時化學家辨識元素的標準工具是「火焰試色」——把樣本放進火焰，看它燒出什麼顏色：鈉是黃色、銅是綠色、鍶是紅色。但這個方法有致命的缺陷。首先，許多元素的火焰顏色彼此相近，例如鍶的紅與鋰的紅幾乎無法用肉眼區分；其次，只要樣品中混有極微量的鈉，那刺眼的黃光就會吞沒其他一切顏色，讓整個測試失效。本生在分析礦泉水的成分時，就飽受這種「鈉的干擾」之苦。

另一個懸案更為深遠：**火焰為什麼會有顏色？** 當時沒有人能回答。顏色究竟是燃燒的產物？是元素的固有屬性？還是某種尚未理解的物理現象？這個謎題看似只是化學實驗室裡的小事，卻關係到一個根本問題——我們能否真正「看見」原子的身分？

與此同時，天文學家也有一個百年之謎：太陽光譜中那些由夫朗和斐（Fraunhofer）於 1814 年發現的數百條黑色暗線，究竟是什麼？太陽由什麼構成？當時哲學家孔德（Auguste Comte）甚至在 1835 年斷言：「恆星的化學組成是人類永遠無法得知的知識。」

這兩樁懸案——火焰顏色之謎與太陽暗線之謎——即將被同一把鑰匙解開。

## 偵查過程

**第一步：把光「拆開」看。** 本生改良的煤氣燈（本生燈）提供了一個近乎無色、高溫且穩定的火焰，這是完美的「光源舞台」。1859 年，物理學家古斯塔夫·基爾霍夫（Gustav Kirchhoff）與本生合作，在本生燈前放置一具稜鏡光譜儀，把火焰發出的光展開成光譜。

關鍵實驗來得極為戲劇化。兩人在實驗室對面的大樓失火時，用光譜儀觀察遠處火焰，意外注意到火焰中的亮線（D 線位置）與太陽光譜中的暗線位置吻合。基爾霍夫隨即設計了一個精妙的實驗：讓太陽光先穿過含鈉蒸氣的火焰，再進入稜鏡。結果發現鈉蒸氣不僅會發射黃色亮線，還會**吸收**同一波長的光，使太陽光譜的 D 暗線變得更深。

**第二步：提出理論推導。** 基爾霍夫由這些實驗歸納出著名的**基爾霍夫光譜定律**：

1. 熾熱的固體或液體發出連續光譜；
2. 熾熱的氣體發出不連續的亮線光譜，且譜線波長是該元素的「指紋」；
3. 較低溫的氣體置於連續光源之前，會吸收與其發射譜線**完全相同波長**的光，形成暗線。

從能量角度，基爾霍夫還提出發射率與吸收率之比的普適關係。對於處於熱平衡的物體，其單色發射本領 $e(\lambda, T)$ 與單色吸收率 $a(\lambda, T)$ 滿足：

$$\frac{e(\lambda, T)}{a(\lambda, T)} = E(\lambda, T)$$

其中 $E(\lambda, T)$ 是只與波長和溫度有關的普適函數（後來催生普朗克的量子假說）。同一元素「發射什麼就吸收什麼」，這正是太陽暗線的成因——太陽大氣中較冷的鈉、鐵等蒸氣，吸收了太陽核心發出的連續光中對應的波長。

**第三步：用「指紋」辦案。** 本生與基爾霍夫接著建立「光譜指紋資料庫」：把每種已知元素的譜線位置一一記錄。1859 至 1860 年間，他們分析杜爾克姆（Dürkheim）礦泉水時，在光譜中發現兩條從未見過的藍色與紅色譜線，判定其中必有新元素。他們耗費大量礦泉水，以化學方法分離濃縮，終於找到兩種新鹼金屬，並依其譜線顏色命名：銫（Cs，拉丁文 caesius，天藍色）與銣（Rb，rubidus，深紅色）。這是人類史上第一次用光譜「破案」找到新元素——而且是憑藉極微量的線索（礦泉水中含量極稀的成分）。

這個方法的威力在於極高的靈敏度：本生估計，只需約 $10^{-7}$ 克的鈉就足以在光譜中顯現黃線。數學上，若譜線強度 $I$ 與元素濃度 $c$ 在低濃度區近似成正比：

$$I \approx k \, c$$

這為後世的光譜定量分析（原子發射光譜法）奠定了理論基礎。

**思路總結**：火焰顏色不是「燃燒的雜訊」，而是原子內部結構發出的信號；把光展開成光譜，就等於讀出原子指紋。這一思路把化學分析從「宏觀試管」推進到「微觀原子」，堪稱化學史上最優雅的偵探手法之一。

## 結案報告

結案，但故事才剛開始。

**第一，光譜化學正式誕生。** 元素鑑定從此有了「光學指紋法」，其靈敏度遠超所有傳統化學方法。本生—基爾霍夫之後，一連串新元素被光譜法發現：鉈（1861，克魯克斯）、銦（1863，賴希與里希特）、氦（1868，讓桑與洛克耶在太陽光譜中發現，名字即來自希臘文的太陽 helios）。

**第二，孔德的斷言被推翻，天體物理學誕生。** 1868 年太陽光譜中的氦線，證明人類真的可以知道恆星的化學組成。太陽與恆星由氫、氦等元素構成——宇宙的「化學普查」從此展開。這也直接證明了地球上的元素與天體中的元素是同一套物質，支持了元素週期性的普遍性，為 [1869-Mendeleev週期表.md](1869-Mendeleev週期表.md) 的預測力提供了跨天地的驗證。

**第三，暗線之謎通往量子力學。** 基爾霍夫提出的「發射與吸收波長相同」現象，最終引導出原子具有分立能級的概念：氫光譜的巴耳末公式（1885）與波耳模型（1913）都建立在「譜線 = 能級躍遷」這條光譜化學開闢的道路上。

**第四，通往原子序。** 光譜是原子內部電子結構的外顯信號。數十年後，莫色勒（Moseley）正是利用 X 射線譜的規律性確立原子序，徹底解決了週期表的排序問題（見 [1913-Soddy同位素與Moseley原子序.md](1913-Soddy同位素與Moseley原子序.md)）。可以說，1859 年那把本生燈點燃的火焰，一路照亮了原子結構、量子論與天體物理的整條道路。

## 證據與工具

```python
# 用 Python 模擬「光譜指紋」：本生燈 + 稜鏡
# 每種元素有特徵譜線（波長，單位 nm）
element_lines = {
    "Na(鈉)": [589.0, 589.6],      # 黃色雙線（D 線）——本生最頭痛的干擾源
    "Cs(銫)": [455.5, 459.3],      # 藍色——1859 年發現的第一個光譜新元素
    "Rb(銣)": [780.0, 794.8],      # 深紅色——第二個光譜新元素
    "Li(鋰)": [670.8],             # 紅色——與鍶火焰顏色相近，肉眼難分
}

def element_from_lines(observed, tol=0.5):
    """偵探模式：給定觀測到的譜線，比對指紋資料庫找出元素"""
    matches = []
    for elem, lines in element_lines.items():
        # 觀測線條至少要有一條落在某元素特徵線的容許誤差內
        hits = sum(any(abs(o - l) <= tol for l in lines) for o in observed)
        if hits > 0:
            matches.append((elem, hits))
    return sorted(matches, key=lambda x: -x[1])

# 案發現場一：礦泉水樣本，肉眼只見微弱藍光
print("== 案件一：杜爾克姆礦泉水 ==")
print("光譜儀觀測:", element_from_lines([455.4, 780.1]))
# -> 銫與銣現形！

# 案件二：肉眼只見紅色火焰，是鋰還是鍶？
print("== 案件二：紅色火焰之謎 ==")
print("光譜儀觀測:", element_from_lines([670.9]))
# -> 鋰。用火焰試色無法分辨，光譜一錘定音。

# 靈敏度示範：譜線強度與濃度成正比 I ≈ k*c
def line_intensity(c, k=1e6):
    return k * c

for c in [1e-3, 1e-5, 1e-7]:
    print(f"濃度 {c:.0e} g -> 譜線強度 {line_intensity(c):.1e}")
# 即使 1e-7 克的鈉，譜線強度仍遠超感官偵測極限
```
