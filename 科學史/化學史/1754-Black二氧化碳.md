# 1754 Black 二氧化碳

## 案發現場

十八世紀中葉，蘇格蘭的醫學界面臨一個實際的難題：改良鹼性水。愛丁堡與格拉斯哥一帶流行用石灰水（氫氧化鈣溶液）治療胃結石與腎結石，藥劑師們用廉價的蘇打（碳酸鈉）與苛性石灰反應製備鹼液。但一個奇怪的現象困擾著所有人：**天然蘇打與人工製備的苛性鹼，性質並不相同**——天然鹼遇酸會冒泡，苛性鹼卻不會；天然鹼在石灰水中會產生沉澱，苛性鹼卻能溶解。

當時的解釋混亂不堪。有人說天然鹼裡「混有雜質」，有人搬出亞里斯多德式的「輕與重」原理，化學親和力表雖然已有（喬弗瓦 1718 年的親和力表），但「鹼性為何時有時無」仍是未解之謎。更奇異的現象是：**石灰石加熱後失去重量，卻在遇水後「恢復」部分重量**——物質憑空消失又憑空出現，彷彿化學裡藏著一個看不見的小偷。

誰接手這樁懸案？一位年輕的蘇格蘭醫生**約瑟夫·布萊克（Joseph Black, 1728–1799）**。他在 1754 年為取得醫學博士學位而研究的論文，正是關於鹼性碳酸鎂與石灰的性質。他手上有一件前輩化學家不曾認真使用的武器：**一架精確的天平**。這樁案件的重要性在於：布萊克發現了第一種被明確認識的氣體——「固定空氣」（fixed air），即二氧化碳 $\mathrm{CO_2}$，並用質量變化的定量記錄開創了**氣體化學**，直接為拉瓦節的氧化說與質量守恆定律鋪路。

## 偵查過程

布萊克的偵查手法可以概括為一句話：**跟蹤質量，不放過任何一克的去向。**

**第一步：稱量石灰石加熱前後的質量。** 布萊克取一定量的石灰石（主要成分 $\mathrm{CaCO_3}$），強熱後變成生石灰（$\mathrm{CaO}$），稱其質量：

$$\mathrm{CaCO_3 \xrightarrow{\ \Delta\ } CaO + \uparrow 固定空氣}$$

他發現：**120 份質量的石灰石，強熱後平均失去約 44 份**（以白堊計算，比例為 100:56，視樣品純度而定）。這 44 份質量不是消失了——它以氣體形式逸散到空氣中。用現代摩爾質量驗證：$\mathrm{CaCO_3}$ 摩爾質量約 100 g/mol，$\mathrm{CO_2}$ 約 44 g/mol，比例正好是 $44/100 = 0.44$，與布萊克的測量驚人地吻合。這是化學史上第一次有人用天平「抓到」一種氣體的存在與質量。

**第二步：解開「石灰遇水復重」之謎。** 生石灰加水會放熱並變成熟石灰（$\mathrm{Ca(OH)_2}$）：

$$\mathrm{CaO + H_2O \rightarrow Ca(OH)_2}$$

質量增加，是因為石灰**吸收了水**。而熟石灰暴露在空氣中會慢慢變回碳酸鹽性質——布萊克證明這是因為它吸收了空氣中的「固定空氣」。

**第三步：關鍵的定性反應——石灰水變混濁。** 布萊克發現，把固定空氣通入石灰水，會產生白色沉澱：

$$\mathrm{Ca(OH)_2 + CO_2 \rightarrow CaCO_3 \downarrow + H_2O}$$

這個反應成為檢驗二氧化碳的標準方法，直到今天高中化學仍在使用。它讓布萊克可以「指認兇手」：任何能讓石灰水混濁的氣體，就是固定空氣。

**第四步：統一解釋鹼性之謎。** 布萊克的天才在於看出：天然鹼（碳酸鈉）與苛性鹼（氫氧化鈉）的差別，不是「雜質」，而是**固定空氣的有無**。天然鹼 = 苛性鹼 + 固定空氣。用酸冒泡，是固定空氣被酸釋放出來：

$$\mathrm{Na_2CO_3 + 2HCl \rightarrow 2NaCl + H_2O + CO_2 \uparrow}$$

這一解釋把看似零散的現象（冒泡、沉澱、失重、復重）全部收進一個統一的理論框架——這正是偵探破案的標誌：一個假說，解釋所有證據。

**第五步：提出「潛熱」概念（偵查的延伸）。** 在研究石灰水化時，布萊克注意到冰融化時溫度不變卻持續吸熱，因而提出**潛熱（latent heat）**概念：$Q = mL$，即吸收的熱量 $Q$ 等於質量 $m$ 乘以潛熱 $L$。這項工作雖屬物理學，卻展現了同樣的定量精神，也間接啟發了他的學生瓦特改良蒸汽機。

布萊克還測量了固定空氣的性質：它比空氣重、不助燃、能使動物窒息、溶於水後使水帶有微酸味（這正是他發現「碳酸水」的由來——現代汽水工業的始祖）。

## 結案報告

布萊克 1754 年的工作，是氣體化學的正式開端。此後十二年間，氣體逐一現形：1766 年卡文迪西發現氫氣「可燃空氣」（見 [1766-Cavendish氫氣.md](1766-Cavendish氫氣.md)），1774 年普利斯特里發現氧氣「脫燃素空氣」（見 [1774-Priestley氧氣.md](1774-Priestley氧氣.md)）。一旦化學家學會了「收集氣體、稱量質量」，一個全新的化學世界便展開了。

布萊克的方法論遺產有三：**第一，天平成為化學家的基本武器**，此傳統由拉瓦節發揚光大，成為質量守恆定律（見 [1789-Lavoisier質量守恆.md](1789-Lavoisier質量守恆.md)）；**第二，用特徵反應指認物質**（石灰水混濁法）成為定性分析的標準做法；**第三，證明「看不見的物質」也能被定量研究**——這一點直接打擊了後來的燃素說：既然二氧化碳這種「看不見的流體」可以用天平抓住，燃素為何不能？拉瓦節最終證明：燃素抓不到，因為它根本不存在。

布萊克本人晚年擔任愛丁堡大學化學教授，教學嚴謹而緩慢，一生發表的論文極少，但每一篇都經得起檢驗。他拒絕了把發現用於商業牟利的誘惑，讓碳酸水的製法公開流通。諷刺的是，這位精確測量熱與質量的科學家，死於 1799 年——據傳他是在用餐時安靜地逝去，身上蓋著的正是他畢生研究過的、能保持溫度的毛毯。

從波以耳的「元素判準」（見 [1661-Boyle元素概念.md](1661-Boyle元素概念.md)）到布萊克的「質量追蹤」，化學的定量革命正式起步，下一棒將交給那位古怪的百萬富翁——卡文迪西。

## 證據與工具

用 Python 重現布萊克的質量追蹤實驗：

```python
# 布萊克實驗重現：石灰石加熱失重與石灰水混濁反應
# 化學計量：CaCO3 -> CaO + CO2

M_CaCO3 = 100.09   # g/mol（碳酸鈣摩爾質量）
M_CaO   = 56.08    # g/mol（氧化鈣）
M_CO2   = 44.01    # g/mol（二氧化碳，布萊克所稱「固定空氣」）

def calcination_loss(mass_CaCO3):
    """石灰石強熱後失去的質量（= 逸出的 CO2 質量）"""
    n = mass_CaCO3 / M_CaCO3          # 莫耳數
    return n * M_CO2                  # 逸出氣體質量

# 布萊克的原始觀察：120 份石灰石約失去 44 份
sample = 120.0
loss = calcination_loss(sample)
print(f"石灰石 {sample} g 加熱後失去 {loss:.1f} g（逸出固定空氣）")
print(f"失重比例 = {loss/sample:.2f}，布萊克實測約 0.37~0.44（視純度）")

# 生石灰加水復重：CaO + H2O -> Ca(OH)2
M_H2O = 18.02
n_cao = loss / M_CO2                       # 由 CO2 反推 CaO 莫耳數
gain = n_cao * M_H2O
print(f"生石灰吸水後增重約 {gain:.1f} g（= 吸收的水質量）")
```

```python
# 石灰水混濁檢驗法：CO2 + Ca(OH)2 -> CaCO3↓ + H2O
# 模擬「通入多少 CO2 會產生多少沉澱」

M_CaOH2 = 74.09    # g/mol
M_CaCO3 = 100.09   # 沉澱物（碳酸鈣）

def limewater_test(mass_CO2):
    """通入 CO2 質量，計算可產生的 CaCO3 沉澱質量（1:1 莫耳比）"""
    n = mass_CO2 / M_CO2
    return n * M_CaCO3

for co2 in [0.5, 1.0, 2.0, 4.4]:
    ppt = limewater_test(co2)
    print(f"通入 CO2 {co2:>4} g -> 產生白色沉澱 CaCO3 {ppt:>6.2f} g")

# 重點：反應比例恆為 1:1（莫耳比），這種固定的計量關係
# 正是後來 Proust 定比定律與 Dalton 原子說的實驗基礎。
```
