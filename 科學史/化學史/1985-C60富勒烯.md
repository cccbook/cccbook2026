# 1985 C60 富勒烯

## 案發現場

1985 年，碳化學遇到一個天外飛來的謎團。當時化學家對碳的認識似乎已經完備：石墨（層狀、導電）與金剛石（四面體、堅硬）是碳的兩種同素異形體，有機化學處理著數以千萬計的碳化合物。碳的化學鍵理論（見 [1931-Pauling價鍵理論.md](1931-Pauling價鍵理論.md)）也早已成熟。

但在萊斯大學（Rice University），斯莫利（Richard Smalley）的團隊建造了雷射蒸發裝置，原本的目標是模擬星際空間中碳原子團的形成——研究紅巨星的碳塵。柯爾（Robert Curl）邀請了英國薩塞克斯大學的克羅托（Harry Kroto）來訪，克羅托對長鏈碳分子（cyanopolyynes）在星際空間的存在感興趣，認為雷射蒸發石墨可以模擬恆星大氣中的碳化學。

1985 年 9 月，實驗開始了：用雷射蒸發石墨靶，把碳原子團送進質譜儀。碳團 $\mathrm{C_n}$ 的質譜訊號如期出現，但其中一個峰異常地突出——**$\mathrm{C_{60}}$ 的訊號（質量 720）比鄰居們強出幾十倍，而且當實驗條件調整（延長碳團在容器中的停留時間）時，$\mathrm{C_{60}}$ 與 $\mathrm{C_{70}}$ 的峰獨占地增強，其他峰全部衰退**。質量 720 之謎誕生：什麼樣的碳結構會如此特別地穩定？

## 偵查過程

**第一步：質譜的推理。** 質譜峰的異常強度意味著 $\mathrm{C_{60}}$ 是一個化學上特別穩定的「閉殼」結構——它的反應性極低（不懸掛任何鍵）。$60 = 4 \times 15$，偶數個碳；如果是平面結構，邊緣的碳必有懸鍵、不會穩定。結論：**$\mathrm{C_{60}}$ 必是一個閉合的籠狀結構**。

**第二步：紙模型的靈感（破案關鍵）。** 深夜，克羅托、柯爾與斯莫利在廚房裡用紙剪出六角形拼接——平面六角網無法閉合。克羅托想起他為蒙特婁萬國博覽會建造的美國館（U.S. Pavilion）——建築師巴克敏斯特·富勒（Buckminster Fuller）設計的網格穹頂（geodesic dome），那是**六角形與五角形混合**的球面結構。數學推理隨即完成：純六角形無法閉合成球，必須混入**恰好 12 個五角形**（尤拉公式：頂點 $V$、面 $F$、邊 $E$ 滿足 $V - E + F = 2$；對由五角形與六角形構成的封閉籠，五角形數恆為 12）。60 個頂點、32 個面（12 個五角形 + 20 個六角形）、90 條邊——每個碳與三個近鄰成鍵、無任何懸鍵，完美的閉殼：

$$V = 60, \quad F = 12 + 20 = 32, \quad E = 90, \quad V - E + F = 60 - 90 + 32 = 2\ \checkmark$$

這個結構像一顆足球（截角二十面體，truncated icosahedron），故命名為「巴克敏斯特富勒烯」（buckminsterfullerene），暱稱「足球烯」（buckyball）。克羅托的靈感來源——富勒的建築——給了整個家族「富勒烯」（fullerene）這個名字。

**第三步：驗證之戰。** 1985 年的證據只有質譜，結構假說缺少直接證據，學界半信半疑。破案的關鍵一擊在 1990 年：德國馬普研究所的克拉茨默（Krätschmer）與霍夫曼（Huffman）發明了電弧蒸發石墨法——**一次能生產毫克級的 $\mathrm{C_{60}}$**！他們的紅外光譜只有四條尖銳譜線（對稱結構的特徵），隨後 ${}^{13}\mathrm{C}$ NMR 只有一條單峰——**60 個碳全部等價**，這只有高對稱的足球結構才可能。全案鐵證如山，富勒烯化學爆炸性展開。

## 結案報告

1996 年，克羅托、柯爾與斯莫利共享諾貝爾化學獎。遺產包括：

1. **碳的第三種同素異形體**：碳從「石墨 + 金剛石」變成「石墨 + 金剛石 + 富勒烯 + ……」，碳化學的疆域爆炸性擴張。
2. **奈米碳材之源**：1991 年飯島澄男（Iijima）在電弧產物中發現**奈米碳管**（carbon nanotube）——捲起來的石墨層，可視為拉長的富勒烯；2004 年 Novoselov 與 Geim 分離出**石墨烯**（graphene，2010 諾獎）。奈米碳管的高強度、導電性開啟了奈米材料與奈米電子學。
3. **超導與應用**：鹼金屬摻雜的 $\mathrm{C_{60}}$ 晶體有超導性；富勒烯衍生物用於有機太陽能電池、藥物載體（如 $\mathrm{C_{60}}$ 衍生物抑制 HIV 蛋白酶）。
4. **間隙化學**：籠內可以封入金屬原子（endohedral fullerene，如 $\mathrm{La@C_{82}}$），開創「分子籠」化學。
5. **偵查方法學**：質譜異常 → 幾何推理 → 紙模型 → 大量合成驗證——「理論偵探」模式又一次戰勝了經驗主義（同 [1951-Pauling螺旋結構.md](1951-Pauling螺旋結構.md)、[1953-WatsonCrickDNA.md](1953-WatsonCrickDNA.md) 的傳統）。

## 證據與工具

```python
# 驗證 C60 的尤拉公式，並畫出足球烯結構示意
import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D  # noqa

# 尤拉公式檢驗：V - E + F = 2
V, pentagons, hexagons = 60, 12, 20
E = 3 * V // 2                 # 每頂點 3 邊，每邊共享 → E = 3V/2
F = pentagons + hexagons
edge_check = pentagons*5 + hexagons*6 == 2*E   # 面邊數守恆
print(f"C60：V={V}, E={E}, F={F}（12 五角形 + 20 六角形）")
print(f"尤拉公式 V - E + F = {V - E + F}（應為 2）✓")
print(f"面-邊守恆檢驗：{edge_check} ✓")

# 畫出足球烯的頂點（截角二十面體頂點座標）
# 生成：三組正交座標的循環排列 (0, ±1, ±3φ) 等
phi = (1 + np.sqrt(5)) / 2    # 黃金比例
coords = set()
for a, b, c in [(0, 1, 3*phi), (1, 2+phi, 2*phi), (phi, 2, 2*phi+1)]:
    for sa in [1,-1] if a else [1]:
        for sb in [1,-1] if b else [1]:
            for sc in [1,-1] if c else [1]:
                for perm in [(0,1,2),(1,2,0),(2,0,1)]:
                    v = (sa*a, sb*b, sc*c)
                    coords.add(tuple(v[p] for p in perm))
coords = np.array(sorted(coords))
print(f"生成頂點數 = {len(coords)}（應為 60）")

fig = plt.figure(figsize=(7, 6))
ax = fig.add_subplot(111, projection="3d")
ax.scatter(coords[:,0], coords[:,1], coords[:,2], s=20)
ax.set_title("C₆₀ 足球烯：60 個碳原子的頂點分布（截角二十面體）")
plt.show()

# 質譜示意：C60 (m/z=720) 的異常強峰
masses = [600, 620, 640, 640+16, 672, 690, 720, 710, 770, 840]
intens = [30, 25, 20, 18, 15, 12, 100, 10, 40, 55]
plt.bar(masses, intens, width=8)
plt.xlabel("質量 m/z"); plt.ylabel("相對強度")
plt.title("質譜示意：C₆₀（720）與 C₇₀（840）的異常強峰")
plt.show()
```
