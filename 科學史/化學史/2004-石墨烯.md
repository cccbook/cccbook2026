# 2004 石墨烯

## 案發現場

2003 年的英國曼徹斯特大學。俄裔物理學家安德烈・海姆（Andre Geim）與康斯坦丁・諾沃肖洛夫（Konstantin Novoselov）面對著一個理論與實驗「互相矛盾」的懸案：二維晶體，到底存不存在？

碳是化學界最會「變形」的元素。同樣由碳原子構成，可以是堅硬透明的鑽石（$sp^3$ 立體網狀），也可以是柔軟烏黑的石墨（$sp^2$ 層狀結構）。石墨的結構早已清楚：碳原子以六角蜂巢狀排列成無限延伸的平面層，層與層之間靠微弱的凡得瓦力堆疊。自 1916 年路易斯共價鍵理論（參閱 [1916-Lewis共價鍵.md](1916-Lewis共價鍵.md)）與 [1931-Pauling價鍵理論.md](1931-Pauling價鍵理論.md) 建立 $sp^2$ 混成的概念以來，每一本教科書都寫著：石墨由無數片「單層碳原子」堆疊而成。1985 年，更有科學家造出了由 60 個碳原子構成的足球狀分子 C60（參閱 [1985-C60富勒烯.md](1985-C60富勒烯.md)），碳的第三種形態問世。

但「單層碳原子」本身——也就是把石墨剝到只剩一層——卻被主流科學界認為是不可能存在的。理由是嚴肅的理論推演：早在 1930 年代，朗道（Lev Landau）與派爾斯（Rudolf Peierls）就證明，熱力學漲落會摧毋任何嚴格二維的晶體——在二維空間中，原子偏離晶格位置的熱漲落 $\langle u^2 \rangle$ 隨晶體尺寸對數發散，長程序無法維持，薄膜必然捲曲或崩解。此後七十年，「二維晶體不存在」是凝聚態物理的教科書常識。人們相信：把一片石墨剝到單層，它會立刻捲起來或黏在一起。

還有一個更深的謎題藏在理論裡。石墨烯的能帶結構由 $sp^2$ 網狀的 $\pi$ 電子決定。計算顯示，石墨烯的導帶與價帶在布里亞淵區的六個角點（K 點）恰好相接——電子的能量—動量關係（色散關係）不是拋物線，而是線性的錐形（「狄拉克錐」，Dirac cone）。這意味著石墨烯中的電子行為像「無質量的狄拉克費米子」，以約 $v_F \approx 10^6\ \mathrm{m/s}$ 的速度運動，服從相對論性的狄拉克方程而非薛丁格方程。固態物理中從未有一種真實材料讓電子表現得像相對論粒子——如果石墨烯存在，它將是桌面上的「量子電動力學實驗室」。

為何重要？因為電子的遷移率決定一切電子元件的速度；因為二維材料是材料科學的極限疆域；更因為「理論說不可能」的東西若真的存在，就必須改寫理論本身。誰能完成這個「不可能」的任務？

海姆與諾沃肖洛夫的答案，令人啼笑皆非卻又理所當然：一卷膠帶。

## 偵查過程

海姆與諾沃肖洛夫的偵查，始於一種實驗室文化：每週五晚上做「瘋狂實驗」。海姆著名的「磁懸浮青蛙」（讓青蛙在強磁場中漂浮）就是這種文化的產物。2003 年，他們決定挑戰「二維晶體不存在」的教科書常識——方法簡單到近乎侮辱：用透明膠帶反覆撕剝石墨。

偵查的第一步：撕。他們把高取向熱解石墨（HOPG）薄片用膠帶貼上、撕開，石墨層隨膠帶一分為二；再把帶著石墨的膠帶對折、再撕——如此反覆十幾次，每次層數減半：

$$N_n = N_0 \cdot \left(\frac{1}{2}\right)^n$$

理論上撕 20 次，層數就從數百萬層降到個位數。但問題是：撕到只剩一層時，那片東西薄到不可見（單層石墨烯厚度僅 0.335 奈米，可見光反射率僅 2.3%），如何找到它？

第二步：找。這是整個偵查的關鍵靈感。他們把撕剝後的膠帶貼在氧化矽（SiO₂/Si）基板上，溶掉膠帶。奇蹟在光學干涉：單層石墨烯厚 0.335 奈米，恰好在特定厚度的氧化矽層（約 300 奈米）上產生微妙的光學干涉色差——單層石墨烯在顯微鏡下呈現淡淡的淺藍紫色。這是「用可見光看見 0.3 奈米厚薄膜」的光學偵探手法。他們隨即在顯微鏡下逐片搜尋，找到了「只有一層」的碳膜。

第三步：證明。找到不等於證明。海姆與諾沃肖洛夫用原子力顯微鏡（參閱 [1981-STM掃描穿隧顯微鏡.md](1981-STM掃描穿隧顯微鏡.md) 的後裔技術）測量薄膜厚度：單層石墨烯的厚度約 0.34 奈米——恰好一個碳原子的直徑。更關鍵的證據是電學測量：他們用微影技術在石墨烯上做出電極，測量「場效應電晶體」特性。結果顯示，這片單層碳膜是「零能隙半金屬」：載流子濃度可以連續調變，從電子型調到電洞型，且在狄拉克點處載流子不消失。

最深刻的證據是量子霍爾效應。石墨烯中電子的線性色散關係為：

$$E = \hbar v_F |k|$$

其中 $k$ 是相對於狄拉克點（K 點）的波向量，$v_F \approx 10^6\ \mathrm{m/s}$ 是費米速度。這條「狄拉克錐」公式意味著：石墨烯中的電子沒有有效質量（$m^* = \hbar k / v_F$ 在 $k \to 0$ 時趨於零），行為像無質量的相對論粒子，服從狄拉克方程：

$$\sigma_x \frac{\partial \psi}{\partial x} + \sigma_y \frac{\partial \psi}{\partial y} = \frac{E}{\hbar v_F}\psi$$

其直接後果是「半整數量子霍爾效應」：量子霍爾電導為 $\sigma_{xy} = \pm 4(n + 1/2)\, e^2/h$——帶著 $1/2$ 的半整數，這是相對論性貝里相位（Berry phase $\pi$）的指紋，教科書上從未在真實材料中出現。2005 年，海姆團隊與哥倫比亞大學的金姆（Philip Kim）團隊分別獨立測得石墨烯的半整數量子霍爾效應——狄拉克錐的理論預測被實驗嚴絲合縫地證實。

那「二維晶體不穩定」的理論呢？答案同樣精彩：電子顯微鏡顯示，石墨烯的表面確實有奈米尺度的微小漣漪（ripples）——熱漲落並沒有消失，只是以「皺褶」的形式存在，使晶格在局部保持穩定。朗道與派爾斯的定理沒有錯，錯的是人們對「二維」的絕對化理解。理論被改寫，而不是被推翻。

## 結案報告

結案的第一頁，寫著「不可能」的破產。海姆與諾沃肖洛夫證明了：二維晶體可以穩定存在於室溫下，靠的是奈米漣漪對熱漲落的容忍。一卷膠帶擊敗了七十年的教科書常識——這是科學史上最「低成本」的革命：沒有加速器、沒有超級電腦，只有膠帶、顯微鏡與不服輸的推理。2010 年，兩人獲得諾貝爾物理學獎。海姆在獲獎時說：我們證明了「教科書說不可能」的事，值得每個人都去試一次。

第二頁，寫著二維材料的大爆發。石墨烯打開了一扇門：既然單層可以穩定，那麼其他層狀材料也都能撕到單層。氮化硼（h-BN，絕緣體）、二硫化鉬（MoS₂，半導體）、黑磷（Black phosphorus，可調能隙）接連問世，「二維材料」成為材料科學的全新領域。更精彩的組合是「凡得瓦異質結構」：把不同二維材料像積木一樣逐層堆疊，人工設計出自然界沒有的電子性質——這是「逐原子設計材料」的哲學實現，與 STM 原子操縱（參閱 [1981-STM掃描穿隧顯微鑆顯微鏡.md](1981-STM掃描穿隧顯微鏡.md)）一脈相承。

第三頁，寫著石墨烯的應用前景。石墨烯的性質近乎完美：電子遷移率約 $200{,}000\ \mathrm{cm^2/(V\cdot s)}$（比矽高百倍）、熱導率極高、力學強度（楊氏模數約 1 TPa）是鋼的兩百倍、可見光透明度 97.7%、可彎曲。這些性質指向柔性電子（可摺疊螢幕）、超高速電晶體、透明導電膜（取代氧化銦錫 ITO）、超高頻感測器、海水淡化濾膜與儲能材料。石墨烯也成為化學的新舞台：單層碳膜上的每一次化學修飾（摻雜、官能化）都直接改變整片材料的電子性質——$sp^2$ 碳化學與量子電子學在這裡合流。

第四頁，寫著理論的新視野。狄拉克錐讓凝聚態物理學家可以在桌面上模擬相對論量子現象：克萊因隧穿（Klein tunneling，無質量粒子可穿透任意高的勢壘）、Zitterbewegung 顫動、假想中的「超導—絕緣—金屬」轉變。2020 年代的「轉角石墨烯」（twisted bilayer graphene）更發現了魔角（約 1.1°）下的超導性——二維材料仍在生長。石墨烯與 C60、奈米碳管共同構成碳奈米材料的三部曲，也是「由下而上」奈米技術（參閱 [1985-C60富勒烯.md](1985-C60富勒烯.md)）最成功的篇章。

海姆與諾沃肖洛夫的結案報告告訴我們：有時候，改變世界的偵查不需要昂貴的儀器，只需要對「教科書說不可能」保持一份懷疑，加上一卷膠帶與十幾次耐心的撕剝。二維世界的門，就此打開。

## 證據與工具

以下 Python 程式碼重現偵查的核心推理：畫出石墨烯的狄拉克錐能帶、模擬膠帶撕剝的層數遞減，並驗算石墨烯的關鍵物理數字。

```python
# 2004 石墨烯：狄拉克錐能帶與膠帶撕剝模擬
import math

# ---- 一、狄拉克錐能帶：E = ħ v_F |k| ----
hbar = 1.0546e-34      # 約化普朗克常數 (J·s)
eV = 1.602e-19         # 1 eV (J)
v_F = 1.0e6            # 費米速度 (m/s)

def graphene_energy(k):
    """狄拉克錐色散：E = ħ v_F |k|，k 相對於 K 點（單位 1/m）"""
    return hbar * v_F * abs(k) / eV  # 單位：eV

# 對照：普通半導體的拋物線能帶 E = ħ²k²/(2m*)
m_star = 0.1 * 9.109e-31  # 有效質量 0.1 me
def parabolic_energy(k):
    return hbar**2 * k**2 / (2 * m_star) / eV

print("狄拉克錐 vs 拋物線能帶（能量隨波向量 k 的變化）：")
print(f"{'k (nm⁻¹)':>10} | {'石墨烯 E (eV)':>14} | {'拋物線 E (eV)':>14}")
for k_nm in [0, 0.5, 1, 2, 3, 5]:
    k = k_nm * 1e9
    print(f"{k_nm:10.1f} | {graphene_energy(k):14.4f} | {parabolic_energy(k):14.4f}")
print("  → 石墨烯的色散是線性的（錐形）：電子像無質量相對論粒子\n")

# 畫出狄拉克錐（文字示意，兩個方向對稱）
print("狄拉克錐示意（E 對 k 的線性錐形）：")
for E_level in [0.6, 0.4, 0.2, 0.0, 0.2, 0.4, 0.6]:
    k_at = E_level * eV / (hbar * v_F) / 1e9  # 對應的 k (nm⁻¹)
    n_spaces = int(k_at * 4)
    line = " " * (20 - n_spaces) + "*" * n_spaces + "|" + "*" * n_spaces
    print(f"  E={E_level:+.1f} eV {line}")
print("  → K 點處導帶與價帶相接（零能隙），形成上下對稱的錐\n")

# ---- 二、膠帶撕剝模擬：層數遞減 N_n = N0 (1/2)^n ----
N0 = 1_000_000  # 初始層數（數百萬層的石墨塊）
print(f"膠帶撕剝模擬（初始 {N0:,} 層，每次撕開層數減半）：")
n = 1
while N0 / 2**n >= 1:
    if n <= 8 or N0 / 2**n <= 2:
        print(f"  撕第 {n:2d} 次：剩 {N0//2**n:,} 層")
    if N0 // 2**n == 1:
        print(f"  → 撕約 {n} 次即可達單層！厚度僅 0.335 nm")
        break
    n += 1

# ---- 三、關鍵物理數字驗算 ----
a_cc = 0.142e-9      # C-C 鍵長 (m)
d_layer = 0.335e-9   # 單層厚度 (m)
R_reflect = 0.023    # 可見光反射率
mobility = 200000    # 遷移率 cm²/(V·s)
mu_steel_ratio = 200 # 與鋼的強度比

print(f"\n石墨烯關鍵數字：")
print(f"  單層厚度 = {d_layer*1e9:.3f} nm（一個碳原子直徑）")
print(f"  可見光反射率 = {R_reflect*100:.1f}%（98% 透明，肉眼難察覺）")
print(f"  電子遷移率 = {mobility:,} cm²/(V·s)（矽約 1400，高出百倍）")
print(f"  力學強度 ≈ 鋼的 {mu_steel_ratio} 倍，卻可彎曲 —— 柔性電子的材料")

# 半整數量子霍爾電導：σ_xy = ±4(n + 1/2) e²/h
h = 6.626e-34
e = 1.602e-19
print(f"\n半整數量子霍爾效應（相對論貝里相位的指紋）：")
for n_q in [0, 1, 2]:
    sigma = 4 * (n_q + 0.5) * e**2 / h
    print(f"  n={n_q}: σ_xy = ±4({n_q} + 1/2) e²/h = {sigma:.4e} S")
print("  → 電導帶著 1/2 的半整數：狄拉克錐理論的實驗證據")
```

執行結果重現了偵查的關鍵：石墨烯的能量—動量關係是線性的狄拉克錐（電子像無質量相對論粒子），與普通半導體的拋物線能帶截然不同；膠帶撕剝約 20 次即可從數百萬層達到單層；半整數量子霍爾電導 $\sigma_{xy} = \pm 4(n+1/2)e^2/h$ 是狄拉克錐的實驗指紋。這就是 2004 年一卷膠帶打開二維世界的推理工具。
