# 1811 Avogadro 分子假說

## 案發現場

十九世紀初，化學界正陷在一場「度量衡危機」之中。道耳頓（John Dalton）的原子論雖然為物質世界提供了第一張藍圖，卻留下一個致命的漏洞：我們知道物質由原子組成，但**一個「原子」到底多重？我們要怎麼稱出一個看不見、摸不著的粒子的重量？**

雪上加霜的是，1808 年蓋呂薩克（Joseph Louis Gay-Lussac）發表了氣體化合體積定律：氣體彼此化合時，體積成簡單整數比。例如：

- 2 體積氫氣 + 1 體積氧氣 → 2 體積水蒸氣
- 1 體積氮氣 + 3 體積氫氣 → 2 體積氨

這條定律原本應該是原子論最好的證據——體積的簡單整數比，不正暗示著粒子的簡單整數比嗎？然而道耳頓本人卻強烈反對這個推論。他的理由看似堅實：如果「同體積含同數原子」，那麼 1 個氧原子加 2 個氫原子應該只產生 1 個「水原子」，怎麼會變成 2 個？除非粒子在反應中**分裂了**——但道耳頓認為原子不可分割，因此他斷定蓋呂薩克的定律「必然有誤」。

這就是案發現場：**一條正確的實驗定律，與一個不完全的理論互相矛盾，整個化學界不知該信哪一邊。** 誰能調解這場糾紛，誰就能為化學建立起統一的原子量標準——那是通往週期表、化學計量學乃至現代全部化學的鑰匙。

## 偵查過程

破案的人是一位都靈大學的物理學教授：阿曼多·阿佛加德羅（Amedeo Avogadro, 1776–1856）。他並非當時化學界的核心人物，這或許反而是優勢——他沒有背負道耳頓的理論包袱，能以旁觀者的清明看出癥結所在。

1811 年，他在《物理雜誌》（Journal de Physique）上發表法文論文〈分子相對質量的測定〉，提出兩個大膽到近乎「離經叛道」的假設：

**假說一：同溫、同壓、同體積的任何氣體，含有相同數目的分子。**

$$N = \frac{pV}{kT} \quad \text{（即理想氣體狀態方程的微觀表述）}$$

也就是說，氣體體積只由「粒子數」決定，與粒子是什麼無關。這一步把蓋呂薩克的體積定律從「有問題的實驗」變成了「原子論的支柱」。

**假說二：許多氣體元素以雙原子分子形式存在。**

氫氣不是一顆顆孤立的 H 原子，而是成對的 $\mathrm{H_2}$；氧氣、氮氣、氯氣亦然。這正是解開悖論的最後一塊拼圖。回到水的例子：

$$2\,\mathrm{H_2} + \mathrm{O_2} \longrightarrow 2\,\mathrm{H_2O}$$

1 個氧分子 $\mathrm{O_2}$ **分裂成兩個氧原子**，分別嫁接到兩個氫分子上，於是生成 2 個水分子——體積比 2:1:2 完美吻合。分裂的不是原子，而是分子；原子依然不可分割，道耳頓的原子論得以保全，蓋呂薩克的實驗也得以保全。兩全其美。

由此，Avogadro 更進一步推出測定分子量的方法。既然同體積含同數分子，則氣體密度之比就是分子量之比：

$$\frac{M_1}{M_2} = \frac{\rho_1}{\rho_2}$$

例如測得氧氣密度是氫氣的 16 倍，便知氧分子量是氫分子的 16 倍，若氫 $\mathrm{H_2}$ 取 2，則氧 $\mathrm{O_2}$ 為 32、氧原子為 16。一整套可操作的原子量測定方案就此誕生。

為了紀念他，今日我們把每莫耳物質所含的粒子數稱為**阿佛加德羅常數**：

$$N_A \approx 6.022 \times 10^{23}\ \mathrm{mol^{-1}}$$

諷刺的是，這個數字在他生前從未被測出——第一個可靠的測定（Perrin，1908 年）距離他的論文已近一百年。

## 結案報告

這樁懸案最令人唏噓之處在於：**正確的答案擺在桌上，卻被冷落了將近五十年。**

Avogadro 用法文寫作、發行量有限的期刊、術語含糊（他稱分子為「molécule」、又稱「molécule intégrante」），加上當時化學權威貝吉烏斯（Berzelius）的電化二元學說與「同種原子相斥」的觀念水火不容，使得 $\mathrm{H_2}$、$\mathrm{O_2}$ 這種「同種原子結合」的想法被視為荒謬。氫取 1 還是 2、原子量以何為準，化學界繼續混亂了半個世紀。

直到 1860 年，坎尼扎羅（Stanislao Cannizzaro）在卡爾斯魯厄國際化學會議上，以小冊子《化學哲學教程》重新闡述 Avogadro 假說，才徹底征服與會者，為原子量混亂畫下句點（見 [1860-Cannizzaro原子量重整.md](1860-Cannizzaro原子量重整.md)）。統一的原子量表隨即在 1869 年催生了門得列夫的週期表（見 [1869-Mendeleev週期表.md](1869-Mendeleev週期表.md)）。

Avogadro 於 1856 年去世，未能親眼目睹自己的假說被平反。他的遺產包括：

1. **分子概念的確立**——「分子」與「原子」從此成為化學的基本語言。
2. **氣體反應體積定律的微觀解釋**——化學計量學（stoichiometry）的基石。
3. **$N_A$ 作為微觀與巨觀世界的橋樑**——今日莫耳定義即以此為核心。
4. **科學社會學的教訓**——正確的理論若無法進入學術主流，可能沉睡數十年；科學的進步不僅需要好的答案，也需要好的「傳播」。

## 證據與工具

```python
# 用 Avogadro 假說重演 1811 年的推理：
# 由氣體密度比推分子量，並驗證水的體積比悖論

# --- 第一部分：由密度比推相對分子量 ---
# 實驗數據（STP 下的氣體密度，g/L）
densities = {
    "H2":  0.0899,
    "O2":  1.429,
    "N2":  1.2506,
    "CO2": 1.977,
}

# 同溫同壓同體積含同數分子 => 分子量比 = 密度比
M_H2 = densities["H2"]  # 以氫分子為基準設 M(H2) = 1（當時的慣例之一）
for gas, d in densities.items():
    rel = d / densities["H2"]
    print(f"{gas:4s}: 相對分子量 = {rel:.2f}")
# 輸出顯示 O2 約為 H2 的 16 倍，即若 H2=2 則 O2=32，氧原子=16

# --- 第二部分：驗證蓋呂薕體積悖論 ---
# 悖論：若"同體積含同數原子"且水以 HO 表示，
# 則 1 體積 O + 2 體積 H -> 1 體積水，與實驗的 2 體積矛盾
print("\n--- 悖論與解方 ---")
print("道耳頓版：1 O + 2 H -> 1 HO  =>  體積比 2:1:1（不符實驗 2:1:2）")
print("Avogadro版：2 H2 + O2 -> 2 H2O => 體積比 2:1:2（完美吻合）")
print("關鍵：O2 分子分裂成 2 個 O 原子，分裂的是分子，不是原子")

# --- 第三部分：N_A 的數量級感受 ---
N_A = 6.022e23
moles_of_water_in_18g = 18 / 18.015  # 1 莫耳水
molecules = moles_of_water_in_18g * N_A
print(f"\n18 克水（約一口）含 {molecules:.3e} 個分子")
print("若把這些分子分給全人類 80 億人，每人可分得",
      f"{molecules/8e9:.3e} 個")
```
