# 1893 Werner 配位化學

## 案發現場

1890 年代，化學價鍵理論正遭遇一樁「棘手的懸案」：自從克庫勒（Kekulé）的價鍵學說確立以來，碳的四價、氧的二價、氫的一價讓有機化學的結構式井然有序。但把這套理論套到**過渡金屬化合物**上，卻處處碰壁。

最典型的「案發現場」是鈷的氨合物。化學家早已合成出一系列鈷—氨化合物：CoCl₃·6NH₃、CoCl₃·5NH₃、CoCl₃·4NH₃……它們的組成清楚，性質卻極為詭異：

1. **氯的行為不一樣**：在 CoCl₃·6NH₃ 中，三個氯全部可以被硝酸銀沉澱出來；但在 CoCl₃·5NH₃ 中，只有兩個氯會沉澱；CoCl₃·4NH₃ 更只剩一個。同是氯原子，為何「活性」不同？
2. **價鍵算不攏**：鈷明明是三價，怎麼會同時抓住六個氨分子？當時流行的鏈式結構理論（如布洛姆斯特蘭 Blomstrand 的 NH₃ 鏈狀模型）勉強拼湊，卻無法解釋所有實驗事實。
3. **異構物之謎**：某些組成完全相同的鈷氨合物（如紫色的 CoCl₃·4NH₃ 與綠色的同組成物），顏色與性質卻截然不同——這是什麼樣的異構現象？碳的四面體異構解釋不了它。

瑞士蘇黎世的年輕講師阿爾弗雷德·維爾納（Alfred Werner）在講課與思考這些化合物時，意識到問題的根源可能在於：**金屬的「價」不只一種。** 1893 年，年僅 26 歲、當時還在教有機化學的維爾納，在凌晨兩點的靈感中想出了答案，據說他一夜之間寫出了配位理論的初稿。

## 偵查過程

**第一步：提出「主價＋副價」的雙重價概念。** 維爾納的推理出發點是：金屬原子有兩種結合力。**主價**（primary valence）即傳統的氧化態，對鈷氨合物中的鈷而言是 +3；**副價**（secondary valence）則是金屬額外抓住中性分子的能力，決定了金屬周圍能容納的「配位數」。以 CoCl₃·6NH₃ 為例，維爾納寫成現代記號：

$$[\text{Co}(\text{NH}_3)_6]\text{Cl}_3$$

六個氨分子緊密地「配位」在鈷周圍，形成一個**配位內界**；三個氯離子則在外界，像普通鹽一樣可被銀離子沉澱。這一筆就把「氯行為不一樣」之謎解開了：內界的氯（如 CoCl₃·5NH₃ 中的 [Co(NH₃)₅Cl]Cl₂）被鈷抓住、不會沉澱；外界的氯才會與 Ag⁺ 反應。

**第二步：確定配位數與立體結構。** 維爾納接著推理：副價有固定的數目與**幾何取向**。對三價鈷，配位數是 6，六個配位基應指向**正八面體**的六個頂點：

$$[\text{Co}(\text{NH}_3)_6]^{3+} \quad \text{（八面體構型）}$$

這是石破天驚的一步——無機化學的立體化學就此誕生。碳的四面體（4 個方向）之外，金屬另有八面體（6 個方向）與平面四方形（4 個共面方向）等幾何。維爾納進一步用立體幾何預言異構物數目：對通式 $[\text{MA}_4\text{B}_2]$ 的八面體，應有**兩種**異構物（兩個 B 相鄰的「順式」與相對的「反式」）。這正好解釋了紫色與綠色的 CoCl₃·4NH₃（即 [Co(NH₃)₄Cl₂]⁺ 的兩種異構物）——順式呈紫色、反式呈綠色。

**第三步：用實驗一錘定音。** 維爾納的理論起初備受質疑，他於是花了近二十年做實驗驗證。最漂亮的證據來自**光學異構**：如果八面體理論正確，那麼某些配位化合物應該像含不對稱碳的有機物一樣，具有鏡像異構體。1911 年，維爾納成功把 [Co(en)₃]Cl₃（en = 乙二胺）拆分出**旋光相反**的兩種晶體，使偏振光向左、向右旋轉。一個不含任何碳不對稱中心的無機化合物竟有光學活性——這只有八面體的螺旋排列才能解釋。連最頑固的反對者也啞口無言。

**思路總結**：維爾納的推理鏈是「化學性質差異 → 配位內界與外界之分 → 配位數固定 → 立體幾何（八面體）→ 預言並證實異構物」。這條鏈條把一堆雜亂的實驗事實，整合成一個優雅的結構理論。

## 結案報告

**第一，配位化學正式誕生。** 主價＋副價、配位數、配位內界的概念，成為現代無機化學的基石。今天的 [Co(NH₃)₆]³⁺ 記號、配位數、順反異構、螯合配基等術語，全部源自維爾納。1913 年，維爾納榮獲**諾貝爾化學獎**——他是第一位獲此殊榮的瑞士籍化學家，也是首位因純無機化學研究獲獎的學者。

**第二，為原子結構理論鋪路。** 維爾納的「副價」在當時只是經驗概念，沒有人知道它的本質。但二十五年後，電子對鍵結理論（路易士，1916）與價鍵理論（鮑林，1930 年代的配位場描述）終於揭曉：副價就是金屬與配位基之間的**配位鍵**——配位基提供電子對給金屬的空軌域。維爾納用實驗先畫出了建築圖，理論物理後來才補上力學原理。

**第三，開啟應用的百寶箱。** 配位化學成為後世無數技術的理論基礎：血液中輸送氧的血紅素（鐵的配位化合物）、葉綠素（鎂的配位化合物）、抗癌藥物順鉑（鉑的平面四方形配位化合物）、觸媒與金屬萃取工業，全部建立在維爾納的框架之上。

**第四，立體化學的普遍化。** 維爾納證明立體異構不是碳的專利，把化學的空間思維推廣到整個元素週期表。這也與晶體結構的研究呼應——固體內部的幾何排列之謎，將由 X 射線繞射接手破解（見 [1912-Bragg晶體繞射.md](1912-Bragg晶體繞射.md)），而維爾納預言的八面體，後來在晶體結構圖中一一現形。

## 證據與工具

```python
# 用 Python 模擬維爾納的推理：八面體配位的異構物計數
import itertools

# 八面體有 6 個配位位置，用編號 0~5 表示
# 0 與 5 相對（反位），1~4 圍成赤道平面
octahedron_opposite = {0: 5, 1: 3, 2: 4, 3: 1, 4: 2, 5: 0}

def isomers_MA4B2():
    """計算 [MA4B2] 八面體的異構物數目（維爾納預言：2 種）"""
    seen = set()
    unique = []
    for pos_B in itertools.combinations(range(6), 2):
        # 判斷順式（相鄰）還是反式（相對）
        if octahedron_opposite[pos_B[0]] == pos_B[1]:
            kind = "trans(反式,綠色)"
        else:
            kind = "cis(順式,紫色)"
        if kind not in seen:
            seen.add(kind)
            unique.append((pos_B, kind))
    return unique

print("== [MA4B2] 八面體異構物 ==")
for pos, kind in isomers_MA4B2():
    print(f"B 佔據位置 {pos} -> {kind}")
# 正好 2 種 —— 維爾納的立體幾何預言！

# 驗證「氯的活性」之謎：內界氯 vs 外界氯
compounds = {
    "CoCl3·6NH3": "[Co(NH3)6]Cl3，3 個氯全在外界",
    "CoCl3·5NH3": "[Co(NH3)5Cl]Cl2，2 個氯在外界",
    "CoCl3·4NH3": "[Co(NH3)4Cl2]Cl，1 個氯在外界",
}
print("\n== AgNO3 沉澱試驗（可沉澱的 Cl 數）==")
for formula, desc in compounds.items():
    outer_cl = 3 - formula.count("·") - 0  # 外界氯數 = 3 - 內界氯數
    inner_cl = formula.count("·")
    print(f"{formula}: {desc} -> 沉澱出 {outer_cl} 個 Cl")
# 同是氯，行為不同 —— 內界氯被鈷抓住，外界氯自由

# 光學異構檢驗：[Co(en)3]Cl3 的鏡像異構
print("\n== [Co(en)3]3+ 的螺旋手性 ==")
print("Δ（右旋）與 Λ（左旋）為鏡像，1911 年維爾納成功拆分")
print("八面體三股螺旋排列 -> 無機化合物的光學活性誕生")
```
