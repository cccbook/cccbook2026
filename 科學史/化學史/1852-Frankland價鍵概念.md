# 1852 Frankland 價鍵概念

## 案發現場

1850 年前後，有機化學正處於一個「資料爆炸、理論真空」的尷尬階段。

一方面，隨著有機合成（見 [1828-Wohler尿素合成.md](1828-Wohler尿素合成.md)）的興起，新的有機化合物以驚人速度湧現，元素分析也日益精確。另一方面，化學家卻**無法解釋**一連串基本的怪事：

- 為什麼 1 個氮原子恰好能結合 3 個氫原子，卻結合不了 4 個？
- 為什麼 1 個氧原子只「想要」2 個氫？
- 為什麼某些取代反應中，1 個氯原子替換 1 個氫，某些反應卻是 2 個換 3 個？

當時的主流理論——貝吉烏斯的電化二元學說（認為化合物由正負電性部分結合）——在有機化學面前節節敗退。取代反應中，帶負電的氯居然能替換掉同樣帶負電的氫，這在二元學說裡根本是悖論。而法國的杜馬（Dumas）提出的「類型論」（type theory），雖然承認分子可以被取代而不崩潰，卻只把化合物按「形式相似」分類，無法回答「**為什麼**」。

真正的謎題是：**原子之間的結合，是隨機的，還是有「定數」的？**

如果每種原子都有固定的「結合能力」——像每個人只有兩隻手，能牽的手就有限——那麼有機分子的結構就有了內在的邏輯，有機化學就能從「分類學」升級為「結構學」。

破案者，是英國化學家愛德華·弗蘭克蘭（Edward Frankland, 1825–1899）。而線索，來自一個看似與有機化學無關的領域——**無機金屬化合物**。

## 偵查過程

弗蘭克蘭的破案之路頗為曲折。1849 年起，他在本生（Bunsen）的實驗室學習，回英國後研究金屬有機化合物——特別是用鋅處理鹵代烷，製備「含鋅有機化合物」（zinc alkyls，如二乙基鋅 $\mathrm{Zn(C_2H_5)_2}$）。這類化合物極為活潑、遇空氣自燃，實驗危險但結果驚人。

1852 年，他在論文〈論含金屬有機化合物的新系列〉中，分析了氮、磷、銻、砷等元素的化合物，注意到一個規律：這些元素與有機基團結合時，**總是傾向於形成固定數目的結合**。他寫道（大意）：

> 「無論元素的結合方式如何，氮、磷、銻、砷總是傾向於以 3 當量或 5 當量的其他元素結合；而由此產生這種結合力背後的原因，或許可以在金屬有機化合物中找到線索。」

這就是「**價（valence）**」概念的誕生——儘管「valence」一詞要到 1868 年才由維奇爾豪斯（Wichgelhaus）正式提出，弗蘭克蘭 1852 年的洞察才是真正的起點。

用現代語言重述弗蘭克蘭的發現：**每種原子有固定的「結合手」數目**。

- 氮、磷、砷、銻：3 隻手（或 5 隻）
- 錫、鋅在金屬有機物中：2 隻手（如 $\mathrm{Zn(C_2H_5)_2}$）
- 氫、氯、鉀：1 隻手

以化學當量表示，若以氫為 1，則某原子 $X$ 的價數即為其氫化物中氫原子數的上限：

$$\text{價數}(X) = \text{分子 } X\mathrm{H}_n \text{ 中的 } n$$

例如 $\mathrm{NH_3}$（氮三價）、$\mathrm{OH_2}$（氧二價）、$\mathrm{CH_4}$（碳——四價，這一步要留給 Kekulé，見 [1858-Kekule碳四價.md](1858-Kekule碳四價.md)）。

價鍵概念一旦確立，化學式就有了內在邏輯：**「手」必須兩兩相牽**。對於由多種原子組成的化合物，各原子價數必須「配平」：

$$\sum_i v_i \cdot n_i = \sum_j v_j \cdot n_j \quad \text{（分子中各原子價鍵總數守恆）}$$

這條簡單的「價鍵守恆」，就是今日所有化學式、結構式的驗算規則。例如水 $\mathrm{H_2O}$：氧二價 × 1 + 氫一價 × 2 = 2 = 2，兩隻氧的手正好被兩隻氫的手牽住。

值得注意的是，弗蘭克蘭當時還沒有「結構式」的圖像——他的「價」是抽象的當量關係，還不是 Kekulé 式的「原子相連圖」。把價鍵畫成原子之間的短線，是後來 1858 年 Kekulé 與 Couper 的功勞（見 [1858-Kekule碳四價.md](1858-Kekule碳四價.md)）。

## 結案報告

弗蘭克蘭的價鍵概念，是有機化學從「分類學」升級為「結構學」的第一塊基石。其遺產包括：

1. **原子結合力「定數」的確立**——化學結合不再是隨機或神秘「親和力」的模糊概念，而是可量化、可驗算的整數規律。
2. **通往 Kekulé 的碳四價與碳鏈理論**——沒有弗蘭克蘭的「價」，就不會有 Kekulé 1858 年的結構理論（[1858-Kekule碳四價.md](1858-Kekule碳四價.md)）與 1865 年的苯環（[1865-Kekule苯環.md](1865-Kekule苯環.md)）。Kekulé 本人也坦承受惠於弗蘭克蘭。
3. **金屬有機化學的開山**——弗蘭克蘭的二乙基鋅成為有機合成的重要試劑，這個領域日後孕育了 Grignard 試劑（1912 年諾貝爾獎）等無數成果。
4. **價鍵守恆成為化學的驗算法**——直到今日，學生寫結構式的第一步仍是「數手」：每個原子的價數是否配平。

有趣的是，價鍵概念的「為什麼」——原子為何有固定結合力——要等到 1916 年路易士（G.N. Lewis）的共價鍵電子理論（價電子配對）才被徹底說清。但弗蘭克蘭在 1852 年，憑著實驗歸納與化學直覺，已經抓住了規律本身：**原子有定數的手，手要兩兩相牽。**

## 證據與工具

```python
# 用 Python 驗算 Frankland 的價鍵概念：
# (1) 氫化物中氫的數目 = 價數 (2) 價鍵守恆檢驗

valence = {"H": 1, "Cl": 1, "O": 2, "S": 2, "Zn": 2, "N": 3,
           "P": 3, "As": 3, "C": 4, "Sn": 4}

# --- 第一部分：由氫化物判斷價數 ---
print("--- 氫化物與價數 ---")
hydrides = {"NH3": "N", "OH2(H2O)": "O", "PH3": "P", "AsH3": "As", "CH4": "C"}
for formula, elem in hydrides.items():
    n = sum(int(ch) if ch.isdigit() else 1 for ch in formula
            if ch.isdigit() or ch.isupper())
    print(f"{formula:10s} → {elem} 的價數 = {n}")

# --- 第二部分：價鍵守恆檢驗器 ---
def check_valence(formula_map):
    """formula_map: {"H": 2, "O": 1} 表示 H2O"""
    total_bonds = sum(valence[e] * n for e, n in formula_map.items())
    return total_bonds % 2 == 0, total_bonds

print("\n--- 價鍵守恆檢驗（總鍵數必為偶數，手要兩兩相牽）---")
molecules = {
    "H2O": {"H": 2, "O": 1},
    "NH3": {"H": 3, "N": 1},
    "CH4": {"H": 4, "C": 1},
    "CO2": {"C": 1, "O": 2},
    "Zn(C2H5)2": {"Zn": 1, "C": 2, "H": 10},
}
for name, comp in molecules.items():
    ok, bonds = check_valence(comp)
    print(f"{name:12s}: 總鍵數 = {bonds}  → {'配平 ✓' if ok else '不配平 ✗'}")

# --- 第三部分：預測未知化合物 ---
print("\n--- 價鍵的預測力 ---")
print("磷價數 3，氫價數 1 → 預測磷化氫為 PH3（實驗確認 ✓）")
print("碳價數 4，氯價數 1 → 預測四氯化碳為 CCl4（實驗確認 ✓）")
print("氧價數 2，氫價數 1 → 水是 H2O 而非 H4O 或 HO2")
print("\nFrankland 的洞見：原子結合不是隨機的，而是有『定數』的")
```
