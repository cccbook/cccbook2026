# 1808 Gay-Lussac 氣體定律

## 案發現場

1800 年代的歐洲，原子說剛剛誕生（見 [1803-Dalton原子說.md](1803-Dalton原子說.md)），但它立刻遇到一個尷尬的矛盾：**道耳頓的原子說無法確定「一個分子由幾個原子構成」**。他假設水是 H+O 的結構，於是算出氧原子量為 8；但若水是 $\mathrm{H_2O}$，氧原子量就是 16。哪個對？原子說本身回答不了。

同時，氣體化學積累了大量實驗數據：卡文迪西早在 1784 年就測得氫氧以約 **2:1 的體積比**化合成水（見 [1766-Cavendish氫氣.md](1766-Cavendish氫氣.md)）；布萊克與普利斯特里的氣體實驗提供了各種體積關係的線索。但沒有人系統性地整理：**氣體與氣體化合時，體積比有什麼規律？**

誰接手這樁案件？**約瑟夫·給呂薩克（Joseph Louis Gay-Lussac, 1772–1850）**，法國化學家與物理學家、拉瓦節定量傳統的繼承人、熱氣球偵探（他曾乘熱氣球升到 7000 公尺高空採集空氣樣品研究大氣成分與地磁）。這樁案件的重要性在於：給呂薩克發現了**氣體化合體積定律**——氣體以簡單整數體積比化合——這條定律成為亞佛加厥假說的孕育土壤，最終解開了原子量表的最大懸案。

## 偵查過程

**第一步：系統性的氣體化合體積實驗（1808 年）。** 給呂薩克沿著定量傳統，用精密的量氣裝置系統性地測量氣體反應的體積關係。他在 1808 年向法國科學院報告《氣體物質彼此化合的規律》，核心發現是：

> 氣體與氣體化合時，它們的體積與生成物的體積（若為氣體）之間，呈現**簡單整數比**。

他測得的關鍵數據：

$$\underbrace{2 \text{ 體積 } \mathrm{H_2}}_{\text{氫}} + \underbrace{1 \text{ 體積 } \mathrm{O_2}}_{\text{氧}} \rightarrow \underbrace{2 \text{ 體積 } \mathrm{H_2O(g)}}_{\text{水汽}}$$

體積比 $2:1:2$。他還測得其他反應：氮與氫化合成氨為 $1:3:1$（$\mathrm{N_2 + 3H_2 \rightarrow 2NH_3}$ 的 1:3:2 經亞佛加厥框架修正後更精確）；一氧化碳與氧為 $2:1:2$（$2\mathrm{CO} + \mathrm{O_2} \rightarrow 2\mathrm{CO_2}$）；氫與氯為 $1:1:2$（$\mathrm{H_2 + Cl_2 \rightarrow 2HCl}$）。**全部是簡單整數比**——就像原子計數一樣。

**第二步：理論的困惑——為什麼是整數比？** 給呂薩克敏銳地意識到這條定律的深層含義：如果體積比是簡單整數，那麼「**同溫同壓下，同體積的氣體含有相同數目的微粒**」就是最自然的解釋。因為若體積比等於微粒數比，整數體積比就等於整數微粒比——這與道耳頓的「化合以簡單整數比結合」完美呼應。

但給呂薩克面臨一個兩難：如果同體積含同數目的原子，那麼 2 體積氫 + 1 體積氧 → 2 體積水汽，意味著 2 個氫原子 + 1 個氧原子 → 2 個「水原子」——這在原子計數上**不可能**（1 個氧原子無法平分給 2 個水單元）。道耳頓立刻以此反駁給呂薩克：氣體原子的分裂違反原子不可分割的假說。給呂薩克本人選擇保守，只發表實驗定律，不做理論推論——他把「為什麼」留給了下一個偵探。

**第三步：亞佛加厥的解答（1811 年，案件的續章）。** 案件的決定性進展來自義大利都靈的物理學家**阿梅代奧·亞佛加厥（Amedeo Avogadro, 1776–1856）**。1811 年他在《法國物理學期刊》上發表論文，提出天才的假說：

> **同溫同壓下，同體積的一切氣體含有相同數目的「分子」——但分子不等於原子；分子可以由多個原子組成。**

用這個假說解讀給呂薩克的數據，一切都通了：

$$\mathrm{2H_2 + O_2 \rightarrow 2H_2O}$$

氫分子是雙原子 $\mathrm{H_2}$、氧分子是雙原子 $\mathrm{O_2}$、水汽分子是三原子 $\mathrm{H_2O}$。同溫同壓下體積比等於分子數比（亞佛加厥假說），所以 2 體積 : 1 體積 : 2 體積 = 2 分子 : 1 分子 : 2 分子——原子計數完美平衡：4 個 H 原子 + 2 個 O 原子 = 2 個 $\mathrm{H_2O}$ 分子中的 4H+2O。✓

用理想氣體定律寫出亞佛加厥假說的數學形式：

$$PV = nRT$$

同溫同壓（$P, T$ 相同）時，體積 $V$ 與莫耳數 $n$ 成正比：$\dfrac{V_1}{n_1} = \dfrac{V_2}{n_2}$，即 $\dfrac{V_1}{V_2} = \dfrac{n_1}{n_2}$。**體積比 = 莫耳（分子）數比**——這就是給呂薩克定律與亞佛加厥假說的統一數學表達。由此，水的正確結構 $\mathrm{H_2O}$ 得以確立，氧原子量修正為 16，原子量表的最終版本成為可能（康尼查羅 1860 年在卡爾斯魯厄會議上以此說服化學界）。

**第四步：理想氣體定律的整合。** 給呂薩克本人的另一項貢獻是**查理–給呂薩克定律**：定壓下氣體體積與溫度成正比 $V/T = k$（他 1802 年精確測定了氣體膨脹係數約 $1/273$ per °C）。與波以耳定律 $PV = k$（[1661-Boyle元素概念.md](1661-Boyle元素概念.md)）、亞佛加厥假說 $V \propto n$ 合併，就是理想氣體定律：

$$PV = nRT$$

這條定律把波以耳以來一百五十年的氣體實驗整合成一句話，成為物理化學的基石。

## 結案報告

給呂薩克氣體化合體積定律的遺產有四條主線。

**第一，亞佛加厥假說的孕育**：沒有給呂薩克的整數體積比，亞佛加厥就沒有解讀的對象。可惜亞佛加厥假說被冷落近半世紀（因為「分子分裂」與當時的電化學二元論衝突），直到 1860 年康尼查羅復活它，原子量才徹底理順，門得列夫的週期表（1869）才得以誕生。

**第二，水結構與原子量的確立**：$\mathrm{H_2O}$ 的正確分子式、氧原子量 16、氫原子量 1，全部由給呂薩克定律 + 亞佛加厥假說確立，補上了道耳頓原子說（[1803-Dalton原子說.md](1803-Dalton原子說.md)）缺的最後一塊拼圖。

**第三，理想氣體定律 $PV = nRT$**：給呂薩克的膨脹係數測定成為理想氣體定律的核心數據，也讓「絕對零度 $-273°C$」的概念浮現（體積外推至零），為熱力學第三定律鋪路。

**第四，氣體化學的定量完成**：從布萊克的固定空氣（[1754-Black二氧化碳.md](1754-Black二氧化碳.md)）、卡文迪西的氫（[1766-Cavendish氫氣.md](1766-Cavendish氫氣.md)）、普利斯特里的氧（[1774-Priestley氧氣.md](1774-Priestley氧氣.md)）到給呂薩克的整數體積比，氣體化學的定量革命完成閉環。

給呂薩克本人後來成為索邦大學化學教授，晚年與學生 LIBES（李比希）的合作影響了有機化學。他留給化學的最深印記是：**氣體的體積，是原子計數的鏡子。** 一位飛上七千公尺的熱氣球偵探，在雲層之上看到了物質結構的謎底。

```python
# 同溫同壓下，體積比 = 莫耳數比（亞佛加厥假說）

def gay_lussac_law(reactant_ratios):
    """給呂薩克定律：氣體化合體積比為簡單整數"""
    # 反應：(係數) 氣體 -> 生成物
    return reactant_ratios

# 給呂薩克 1808 年的關鍵實驗數據（體積比均為簡單整數）
experiments = [
    ("2H2 + O2 -> 2H2O",        (2, 1, 2)),
    ("H2 + Cl2 -> 2HCl",        (1, 1, 2)),
    ("2CO + O2 -> 2CO2",        (2, 1, 2)),
    ("N2 + 3H2 -> 2NH3",        (1, 3, 2)),
]
print("反應式                 體積比（簡單整數比）")
for name, (a, b, c) in experiments:
    print(f"{name:<22} {a} : {b} : {c}")
print("\n重點：全部為簡單整數比 —— 給呂薩克定律！")

# 實際體積模擬：2 L 氫 + 1 L 氧 -> 2 L 水汽（100°C 以上）
vol_H2, vol_O2 = 2.0, 1.0
n_H2, n_O2 = vol_H2, vol_O2           # 體積比 = 莫耳比
reacted_H2 = min(n_H2, 2*n_O2)
produced = reacted_H2                  # 2H2 -> 2H2O，體積 1:1
print(f"\n2 L H2 + 1 L O2 -> {produced:.1f} L 水汽（體積比 2:1:2）")
print("原子計數：4 個 H 原子 + 2 個 O 原子 -> 2 個 H2O 分子（4H + 2O）✓")
```

```python
# 理想氣體定律 PV = nRT 與亞佛加厥假說的驗證

R = 0.08206    # L·atm/(mol·K)

def gas_volume(P, n, T):
    """理想氣體定律：V = nRT/P"""
    return n * R * T / P

# 亞佛加厥假說：同溫同壓下，同體積含同莫耳數
P, T = 1.0, 298.15    # 1 atm, 25°C
gases = [("H2", 1.0), ("O2", 1.0), ("N2", 1.0), ("CO2", 1.0)]
print("亞佛加厥假說：同溫同壓下 1 mol 任何氣體的體積都相同")
for name, n in gases:
    V = gas_volume(P, n, T)
    print(f"  {name}: {n} mol 佔 {V:.2f} L")   # 全部約 24.5 L
molar_volume = gas_volume(P, 1, T)
print(f"  標準莫耳體積 ≈ {molar_volume:.2f} L/mol（25°C, 1 atm）")

# 給呂薩克定律（查理-給呂薩克定律）：定壓下 V/T = 常數
print("\n定壓下氣體體積與溫度的關係（V/T = 常數）：")
n = 1.0
for T_C in [0, 100, 200, 273]:
    T_K = T_C + 273.15
    V = gas_volume(P, n, T_K)
    print(f"  {T_C:>4}°C -> {V:.2f} L，V/T = {V/T_K:.4f}")
print("  外推至體積為零 -> 絕對零度 -273°C（給呂薩克膨脹係數 1/273 的根源）")
```
