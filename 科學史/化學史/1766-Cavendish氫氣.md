# 1766 Cavendish 氫氣

## 案發現場

1760 年代的倫敦，氣體化學剛剛起步。布萊克在蘇格蘭抓到了「固定空氣」（見 [1754-Black二氧化碳.md](1754-Black二氧化碳.md)），證明了看不見的氣體也能被定量研究。但化學界仍有一個古老的謎團懸而未決：**金屬遇酸時冒出的氣泡，究竟是什麼？**

這個現象早已被觀察了幾百年：把鐵或鋅丟進稀硫酸，金屬會冒泡溶解，產生的氣體能夠燃燒，甚至會爆燃。煉金術士稱之為「硫的逸出」（因為可燃，便聯想到硫）；之後的化學家則認為那是「金屬中的可燃本質」。但沒有人收集過它、稱量過它、測量過它的性質。它就像兇案現場一閃而過的影子——人人都見過，卻無人能指認。

誰接手這樁案件？**亨利·卡文迪西（Henry Cavendish, 1731–1810）**，英國貴族德文郡公爵家族的後裔，當時最古怪、也最精確的科學偵探。他極度羞怯，幾乎不與人交談（對女性僕人用字條溝通），一生穿著一件過時的紫色舊衣，卻擁有當時最精密的天平與量氣裝置。這樁案件的重要性在於：卡文迪西第一次系統性地收集、測量並指認了氫氣 $\mathrm{H_2}$——「可燃空氣」——並以驚人的精確度測出其密度，為後來「水的合成」實驗（進而推翻水是元素的舊觀念）埋下伏筆。

## 偵查過程

卡文迪西的偵查精神可以用兩個詞概括：**收集**與**測量**。

**第一步：系統性地收集「可燃空氣」。** 卡文迪西沿著波以耳、布萊克的定量傳統，用金屬與酸反應，以倒置集氣瓶收集產生的氣體：

$$\mathrm{Zn + 2HCl \rightarrow ZnCl_2 + H_2 \uparrow}$$

他系統性地嘗試了多種金屬（鋅、鐵、錫）與多種酸（鹽酸、稀硫酸），發現無論用哪種組合，產生的可燃氣體**性質完全相同**。這是一條關鍵線索：既然不同金屬、不同酸都產生同一種氣體，那麼它就不太可能是「某種金屬的特殊本質」，而是一種獨立的、普遍存在的物質。

**第二步：精確測量密度。** 卡文迪西稱量反應前後的質量差，並測量收集到的氣體體積，算出「可燃空氣」的密度。他測得的結果是：可燃空氣的密度約為普通空氣的 **1/14**（現代值約 1/14.4）。這是當時已知最輕的氣體。用現代數據驗證：$\mathrm{H_2}$ 的摩爾質量約 2.016 g/mol，空氣平均約 29 g/mol，比值 $2.016/29 \approx 0.0695 \approx 1/14.4$，與卡文迪西的測量一致。同時他用排水集氣法處理水蒸氣壓的修正，展現了對誤差來源的敏銳掌握。

**第三步：確立「可燃空氣」的獨立身分。** 卡文迪西在 1766 年發表《論人造空氣（On Factitious Airs）》，把氣體分為三類：固定空氣（$\mathrm{CO_2}$）、可燃空氣（$\mathrm{H_2}$）、以及不純的普通空氣。他證明可燃空氣不溶於水、不使石灰水混濁（可與固定空氣區分）、極易燃燒。他用酸鹼反應的計量記錄指出：可燃空氣來自「酸對金屬的作用」，而非金屬本身所含——（有趣的是，這個結論其實半對半錯：以現代觀點，氫來自酸中的氫離子，確實不是金屬本質；但在燃素說框架下，卡文迪西本人傾向認為可燃空氣就是燃素，或燃素與水的化合物。）

**第四步：與水合成的偵查（1784 年，案件的續章）。** 案件的決定性進展出現在近二十年後。1781 年，普利斯特里報告：電火花點燃可燃空氣與普通空氣的混合物後，容器內壁出現露珠。卡文迪西立刻意識到這是一條重大線索，於是進行了化學史上最著名的定量實驗之一：他精確控制可燃空氣與脫燃素空氣（氧氣）的體積比例，點燃後收集並稱量生成的液體——

$$\mathrm{2H_2 + O_2 \rightarrow 2H_2O}$$

他發現：**可燃空氣與脫燃素空氣以約 2:1 的體積比完全化合，生成純水**。生成的液體蒸乾後不留任何殘渣——它是水，而且只有水。這個實驗證明：**水不是元素，而是氫與氧的化合物**，直接推翻了自亞里斯多德以來「水是四元素之一」的千年信條（呼應 [1661-Boyle元素概念.md](1661-Boyle元素概念.md) 中懸而未決的問題）。拉瓦節隨後以此為基礎命名「氫」（hydrogen，意為「生成水的物質」），並將水的合成納入氧化說體系（見 [1777-Lavoisier氧化說.md](1777-Lavoisier氧化說.md)）。而那個 2:1 的體積比，正是給呂薩克氣體化合體積定律（見 [1808-GayLussac氣體定律.md](1808-GayLussac氣體定律.md)）的最早數據之一，也成為亞佛加厥假說的重要線索。

卡文迪西的精確精神在這些實驗中展露無遺：他考慮水蒸氣飽和壓力、考慮溫度與大氣壓的修正、考慮殘留氣體的重複點燃，最終把誤差控制在百分之幾以內——在那個沒有標準儀器的時代，這是了不起的偵探功夫。

## 結案報告

卡文迪西的遺產有三條主線。

**第一，氫氣的發現與指認**，使氣體化學的版圖擴張：布萊克的 $\mathrm{CO_2}$、卡文迪西的 $\mathrm{H_2}$、普利斯特里的 $\mathrm{O_2}$（見 [1774-Priestley氧氣.md](1774-Priestley氧氣.md)）構成了氣體化學的三大支柱，直接供養了拉瓦節的氧化說革命（見 [1777-Lavoisier氧化說.md](1777-Lavoisier氧化說.md)）。

**第二，水的合成實驗**推翻了水是元素的千年信條，使元素表必須改寫——拉瓦節 1789 年的 33 種元素表中（見 [1789-Lavoisier質量守恆.md](1789-Lavoisier質量守恆.md)），氫正式入列，水被除名。同時，水由「氫的燃素說解釋」轉為「氫氧化合物」，成為氧化說最有力的證據之一。

**第三，2:1 體積比與精確測量的傳統**：卡文迪西的數據成為給呂薩克定律的先聲，而他對誤差的偏執則樹立了定量化學的品質標準。他晚年還完成了著名的扭秤實驗（1798 年）「稱量地球」，測出萬有引力常數 $G$，證明同一種精確精神可以貫穿物理與化學。

卡文迪西本人終身沉默而富有，死時留下上百萬英鎊遺產，是當時英國最富有的學者。劍橋大學的卡文迪西實驗室以他家族命名，延續至今。這位用字條與世界溝通的怪僻偵探留給化學最深的印記是：**真相藏在精確的數字裡。**

用 Python 重現卡文迪西的密度測量與水的合成計量：

```python
# 卡文迪西實驗重現：可燃空氣（H2）的密度測量

M_H2 = 2.016       # g/mol
M_air = 28.97      # g/mol（空氣平均摩爾質量）

def gas_density_ratio(M_gas, M_air=M_air):
    """氣體密度比（同溫同壓下密度比 = 摩爾質量比）"""
    return M_gas / M_air

ratio = gas_density_ratio(M_H2)
print(f"可燃空氣與普通空氣的密度比 = {ratio:.4f} ≈ 1/{1/ratio:.1f}")
print("卡文迪西 1766 年實測約 1/14，與現代值 1/14.4 相符")

# 質量差法：金屬 + 酸 -> H2，由溶液減重推算氣體質量
M_Zn = 65.38
def h2_from_zinc(mass_Zn):
    """Zn + 2HCl -> ZnCl2 + H2，1 莫耳鋅產生 1 莫耳氫"""
    n = mass_Zn / M_Zn
    return n * M_H2

print(f"\n溶解 6.5 g 鋅 -> 產生 H2 約 {h2_from_zinc(6.5):.3f} g")
print(f"在同溫同壓下佔體積約 {h2_from_zinc(6.5)/M_H2*24.5:.2f} L（25°C, 1 atm）")
```

```python
# 卡文迪西 1784 年水的合成實驗：2H2 + O2 -> 2H2O
# 核心計量：體積比 2:1，質量比約 1:8

def water_synthesis(vol_H2, vol_O2):
    """給入氫氧體積，回傳(反應體積, 剩餘氣體)"""
    n_H2, n_O2 = vol_H2, vol_O2        # 同溫同壓下體積比 = 莫耳比
    reacted = min(n_H2, 2*n_O2)         # H2 需要 2 倍 O2 的量
    used_O2 = reacted / 2
    left_H2, left_O2 = n_H2 - reacted, n_O2 - used_O2
    return reacted, left_H2, left_O2

# 卡文迪西的關鍵比例：2 體積氫 + 1 體積氧 -> 完全化合
for h2, o2 in [(2, 1), (4, 1), (2, 2), (10, 5)]:
    r, lh, lo = water_synthesis(h2, o2)
    print(f"H2 {h2} vol + O2 {o2} vol -> 反應 H2 {r} vol、O2 {r/2} vol，"
          f"剩餘 H2 {lh}、O2 {lo}")

# 質量比驗證：H2O 中 H:O = 2*2.016 : 16.00 ≈ 1:8
print(f"\n水中氫氧質量比 = {2*2.016/16.0:.4f}（即 O 約為 H 的 8 倍）")
# 這個恆定的 2:1 體積比與 1:8 質量比，
# 後來成為 Proust 定比定律與 Gay-Lussac 氣體化合體積定律的基礎。
```
