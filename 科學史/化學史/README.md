# 化學的歷史年表（科學史）

> 化學是研究物質組成、結構、性質與變化的科學。從 1661 年 Boyle 重新定義「元素」，經 Lavoisier 的定量革命、Dalton 的原子說、Mendeleev 的週期表，到量子化學與 DNA 結構，化學史就是一部「物質的祕密如何被推理揭開」的偵探史。本書並附「材料發明專輯」：從史前玻璃、青銅到高溫超導與藍光 LED，材料史上每一個「不可能」都是一宗待破的案。
>
> 本書以「推理探案」的方式，為每個歷史事件寫一篇 wiki，包含前因後果、數學式、理論與程式。每篇檔名以年份開頭。

## 寫作方式說明

每篇 wiki 採「推理探案」結構：

1. **案發現場（前因）**：當時的未解之謎是什麼？誰遇到的？為何重要？
2. **偵查過程（推理）**：化學家如何思考？關鍵實驗與靈感為何？逐步推導核心數學式與理論。
3. **結案報告（後果）**：謎題如何解？留下什麼遺產？影響了哪些後續發展？
4. **證據與工具**：數學式、理論推導，以及 Python 程式（如化學平衡計算、分子模擬示範）。
