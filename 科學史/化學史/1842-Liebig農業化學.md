# 1842 Liebig 農業化學

## 案發現場

十九世紀上半葉，歐洲農業仍靠「輪作休耕」與天然肥料（糞肥、綠肥）維持地力。人口快速成長，城市膨脹，糧食供應開始吃緊。馬爾薩斯的人口論陰影籠罩歐洲：人口以幾何級數成長，糧食卻只能以算術級數成長，饑荒似乎是必然的命運。

當時農業最大的未解之謎是：植物究竟靠什麼長大？流行的觀點是「腐殖質說」（humus theory）——由德國農業學家泰爾（Thaer）提出，認為植物的養分主要來自土壤中的腐殖質（有機質），因此要肥田就要多施肥料、多種綠肥。但這個說法有一個無法解釋的現象：為什麼有些土地腐殖質豐富卻貧瘠？為什麼焚燒後的植物灰燼（礦物質）長期被農民忽視？

遇到這個謎題的，是德國化學家尤斯圖斯·馮·李比希（Justus von Liebig, 1803–1873）。他在吉森大學（Giessen）建立了世界第一個化學教學實驗室，訓練出一整代化學家，並且是第一位把化學的定量方法系統性地帶進農業的科學家。這個問題重要，是因為若能解開植物營養之謎，人類就有辦法用化學方法「人工餵養」作物，從而打破馬爾薩斯的詛咒。

## 偵查過程

李比希的推理路線是「灰分分析—礦質假說—最小因子律」：

**第一步：植物灰分的定量分析。** 李比希與其學生把各種作物焚燒後分析灰分，發現灰分中一致含有鉀、磷、鈣、鎂、硫等元素，且比例與土壤供應量相關。他進行田間收支計算：作物收成帶走多少礦質養分，土壤就少了多少。

**第二步：礦質營養學說。** 1840 年他在《化學在農業與生理學上的應用》提出革命性假說：植物的有機質（碳、氫、氧）來自空氣中的 $\mathrm{CO_2}$ 與 $\mathrm{H_2O}$（透過光合作用），而**植物生長的限制來自土壤中的礦質養分**——氮、磷、鉀（N、P、K）等必須從土壤吸收，且無機礦物肥料與有機肥料的養分價值完全等價。植物體內有機質合成的淨反應即：

$$\mathrm{6CO_2 + 6H_2O \to C_6H_{12}O_6 + 6O_2}$$

而蛋白質合成需要氮與磷：

$$\text{胺基酸合成：}\quad \mathrm{CO_2 + H_2O + NH_3 + \ldots \to NH_2{-}CH(R){-}COOH}$$

這直接推翻了腐殖質說：植物不需要「吃」土壤裡的有機質，只需要「喝」礦物鹽。

**第三步：最小因子律。** 李比希由桶板桶（barrel staves）的比喻提出著名的「最小因子律」（Liebig's Law of the Minimum）：作物產量由最稀缺的養分決定，其餘養分再多也無用。用數學式表示：

$$G = \min(N_{\text{avail}},\, P_{\text{avail}},\, K_{\text{avail}},\, \ldots)$$

其中 $G$ 為產量潛力，$N_{\text{avail}}$、$P_{\text{avail}}$、$K_{\text{avail}}$ 等為各養分的有效供應量。桶板桶的圖像直觀：水桶的裝水量由最短的木板決定。這個簡單的式子，成為今日施肥量計算、生態學營養級分析與資源限制模型的基礎。

李比希還進一步推理出**補償律**：若補充最稀缺的養分，產量會提升，直到遇到下一個限制因子為止。他的學生與後繼者據此建立了「施肥配方」：缺氮補氮（如智利硝石 $\mathrm{NaNO_3}$）、缺磷補磷（如過磷酸鈣 $\mathrm{Ca(H_2PO_4)_2}$）、缺鉀補鉀（如氯化鉀 $\mathrm{KCl}$）——這就是 N-P-K 肥料的起源，今日化肥袋上印的 $\mathrm{N{:}P_2O_5{:}K_2O}$ 比例正是李比希的遺產。

## 結案報告

李比希的礦質營養學說起初遭到農學界強烈反彈——他質疑了傳統糞肥的權威，甚至與英國農業化學家洛斯（Lawes）與吉爾伯特（Gilbert）發生長期論戰（後者用田間實驗證明豆科植物可固氮，間接指向根瘤菌的發現）。但事實站在李比希這邊：

- **化肥工業的誕生**：1840 年代起，過磷酸鈣工廠在英國與德國建立起來，智利硝石大量進口，1880 年代德國開採斯塔斯富特鉀鹽礦——今日全球年產 2 億噸以上的化肥工業由此開端。
- **「化學餵養世界」**：化肥與隨後的哈伯法合成氨（見 [1909-Haber合成氨與pH](1909-Haber合成氨與pH.md)）共同構成二十世紀的農業革命，使全球人口從 1850 年的 12 億成長到今日的 80 億。諾貝爾獎得主 Borlaug 的綠色革命，本質上是李比希理論的延伸。
- **化學實驗室的革命**：李比希的吉森實驗室成為現代科學研究與教學的典範，訓練出的學生遍布各國，包括後來的有機合成大師霍夫曼（Hofmann）與凱庫勒（Kekulé，見 [1865-Kekule苯環.md](1865-Kekule苯環.md)）。
- **生態學與資源經濟學**：最小因子律成為生態學「限制因子」概念、米丘林—李比希式營養模型與今日資源限制分析（如臭氧層、漁業資源）的理論源頭。

李比希晚年與農學界的關係有所和解，1873 年去世時已是全歐洲最受尊敬的化學家。他有一句名言：「化學是農業的科學基礎。」這句話兌現了——他用人類史上第一個化肥配方，餵養了整個現代世界。

## 證據與工具

以下 Python 程式碼示範：最小因子律的模擬，並計算施肥量如何影響作物產量的桶板桶模型。

```python
# 李比希最小因子律：桶板桶模型模擬
def liebig_yield(nutrients):
    """最小因子律：產量潛力由最稀缺的養分決定。
       nutrients: dict，如 {"N": 50, "P": 30, "K": 80}"""
    limiting = min(nutrients, key=nutrients.get)
    return nutrients[limiting], limiting

# 情境一：傳統農田的養分供應
field = {"N": 50, "P": 30, "K": 80}
g, lim = liebig_yield(field)
print(f"傳統農田：產量潛力 = {g}（限制因子: {lim}）")

# 情境二：補償律 — 逐次補充限制因子，看產量如何提升
print("\n補充策略           養分供應           產量  限制因子")
field = {"N": 50, "P": 30, "K": 80}
steps = [("不施肥", {}), ("補 P +40", {"P": 40}), ("補 N +60", {"N": 60}), ("補 K +40", {"K": 40})]
for label, add in steps:
    for k, v in add.items():
        field[k] += v
    g, lim = liebig_yield(field)
    print(f"{label:12s}   {field}   {g:4d}   {lim}")

# 情境三：繪出產量與施肥量的關係（邊際報酬遞減）
print("\n氮肥用量   產量   邊際增產")
P_fixed, K = 120, 90
prev = 0
for n in range(0, 201, 40):
    g, lim = liebig_yield({"N": n, "P": P_fixed, "K": K})
    print(f"{n:6d}    {g:4d}   {g - prev:+5d}")
    prev = g
```

執行後可以看到三件事：第一，傳統農田的產量由最稀缺的磷決定，其他養分再多也無用；第二，依補償律逐次補充限制因子，產量逐級提升；第三，氮肥超過鉀的供應量後，邊際增產歸零——產量被下一個限制因子鉀卡住。這正是李比希在 1842 年用灰分分析與田間收支算出來的鐵律：一條簡單的 $\min$ 函數，餵養了整個現代世界。
