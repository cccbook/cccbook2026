# 1774 Priestley 氧氣

## 案發現場

1770 年代的歐洲，化學被一個古老而強大的理論統治著：**燃素說（Phlogiston Theory）**。這套學說由施塔爾（Georg Stahl）在十七世紀末確立，主張一切可燃物質都含有一種稱為「燃素」的火性元素，燃燒就是燃素逸出的過程。金屬燃燒後變成灰渣（脫燃素），木材燃燒後留下灰燼，動物呼吸被解釋為「排出燃素、淨化身體」。

但燃素說有一個致命的麻煩：**金屬燃燒後反而變重了**。如果燃燒是燃素逸出，質量應該減少才對。燃素說的支持者被迫提出荒謬的解釋：「燃素具有『負重量』，像氫氣球一樣會把東西往上拉。」一個需要「負質量」才能自圓其說的理論，已經瀕臨崩潰的邊緣——但沒有人知道出路在哪裡。

另一個相關的謎團是：**空氣為什麼會「用完」？** 密閉容器中燃燒的蠟燭會熄滅，其中的老鼠會窒息。當時認為空氣中含有一種「燃素飽和」的成分，燃燒與呼吸會把空氣「污染」到無法再支持火焰。可是被污染的空氣有時又會「恢復」——綠色的水草在水中能讓水恢復生機，這是普利斯特里親自觀察到的奇象。

誰接手這樁案件？**約瑟夫·普利斯特里（Joseph Priestley, 1733–1804）**，英國非國教派牧師、語言教師、電學家與業餘化學家。他住在釀酒廠隔壁，注意到啤酒桶冒出的氣體能使燃燒的木片熄滅（那就是二氧化碳，見 [1754-Black二氧化碳.md](1754-Black二氧化碳.md)），從此迷上了氣體化學。1774 年 8 月 1 日，他做了一個改變化學史的實驗。這樁案件的重要性在於：普利斯特里發現了氧氣——「脫燃素空氣」——卻始終不接受氧化說，成為科學史上最著名的悖論之一：**發現者親手挖出了舊理論的墳墓，自己卻站在墳墓的這一邊。**

## 偵查過程

**第一步：加熱紅色的氧化汞。** 普利斯特里用直徑 12 吋、焦距 20 吋的大型凸透鏡，聚焦陽光加熱紅色的氧化汞粉末（$\mathrm{HgO}$，俗稱三仙丹）。他發現：粉末受熱後釋出一種氣體，可以用水槽排水法收集：

$$\mathrm{2HgO \xrightarrow{\ \Delta\ } 2Hg + O_2 \uparrow}$$

用摩爾質量驗證：$\mathrm{HgO}$ 約 216.6 g/mol，分解 10 g 氧化汞可釋出 $10 \times 32.0/433.2 \approx 0.74$ g 氧氣。

**第二步：關鍵的定性實驗——蠟燭燃燒更旺。** 普利斯特里逐一測試這種新氣體的性質，發現了一系列令人震驚的現象：他先用「燃燒的蠟燭會熄滅」的標準方法檢驗——結果蠟燭**不熄，反而燃燒得異常明亮旺盛**。他又用帶餘燼的木片測試——木片竟然**重新燃起熊熊火焰**。他親自吸入這種氣體，報告說胸口感到「異常輕鬆舒暢」，並戲言這種氣體將來或許會成為上流社會的奢侈消費品。

這些現象指向一個結論：這種氣體是**空氣中支持燃燒與生命的那個「好成分」**，而且比普通空氣更純、更濃。普利斯特里測得它比普通空氣更易支持燃燒（蠟燭火焰亮度約為普通空氣的數倍）、不溶於水、密度與空氣相近。

**第三步：以燃素說解釋——命名「脫燃素空氣」。** 如果普利斯特里到此為止，他就只是一個優秀的實驗觀察者。下一步才是問題所在：他要用什麼理論解釋？他選擇了燃素說。在他的解釋中，這種氣體是「**脫燃素空氣（dephlogisticated air）**」：普通空氣原本支持燃燒，但燃燒與呼吸會使空氣「吸飽燃素」而失去能力；氧化汞加熱時釋出的氣體不含燃素（脫燃素），所以燃燒能力最強。

這個解釋在燃素說框架內自洽，卻有兩個大問題：**第一**，氧化汞加熱釋出氣體後，剩下的汞比原來更輕了——如果燃素被釋出，氧化汞（含燃素）應該比汞重才對，這在質量關係上恰恰與燃素說的預期相反；**第二**，「脫燃素空氣」這個名稱把新氣體定義為「空氣的淨化版本」，而不是一種獨立的元素，這個框架限制了普利斯特里看出更深的真相。

**第四步：與拉瓦節的交會。** 1774 年 10 月，普利斯特里隨謝爾本伯爵訪問巴黎，在晚宴上向拉瓦節（Antoine Lavoisier）演示了「加熱氧化汞產生新氣體」的實驗。這次交會成為化學史上的轉捩點：拉瓦節聽到這個發現後，立刻用完全不同的框架重新審視它——不是「脫燃素」，而是「**與氧結合**」。普利斯特里提供的是原始證據，拉瓦節提供的才是破案理論（見 [1777-Lavoisier氧化說.md](1777-Lavoisier氧化說.md)）。

**第五步：發現者不接受氧化說的悖論。** 命運的諷刺在於：普利斯特里終其一生拒絕接受拉瓦節的氧化說。他堅持「脫燃素空氣」的說法到死（1804 年），並寫文章反駁氧化說。從偵探小說的角度看，這是罕見的一幕：**第一個找到關鍵證物的人，拒絕承認證物所指向的真相。** 原因有多重：他不是職業化學家，對燃素說有感情與思想的依附；氧化說要求他放棄整套世界觀；而他畢生信仰的「簡潔的燃素解釋」在他看來仍然足夠。科學史的教訓在此清晰可見：**發現與理解是兩回事，證據屬於所有人，但理論的更替需要勇氣。**

## 結案報告

普利斯特里的遺產是矛盾而巨大的。

**第一，氧氣的發現**使燃素說的墳墓正式挖成。拉瓦節以氧氣為核心武器，在 1777 年提出氧化說、1789 年確立質量守恆（見 [1777-Lavoisier氧化說.md](1777-Lavoisier氧化說.md)、[1789-Lavoisier質量守恆.md](1789-Lavoisier質量守恆.md)），徹底改寫了化學。沒有普利斯特里的氧化汞實驗，拉瓦節的革命或許會遲到許多年。

**第二，氣體化學的黃金時代**：普利斯特里一生發現了氨氣（$\mathrm{NH_3}$）、氯化氫、二氧化硫、一氧化碳、氧化亞氮（笑氣）等多種氣體，是史上發現氣體種類最多的化學家之一。他發明的集氣槽技術成為氣體化學的標準工具。

**第三，光合作用的觀察**：他發現綠色植物能在受「污染」的空氣中使其恢復支持燃燒的能力，這是光合作用研究的開端（後來由 Ingenhousz 與 de Saussure 完成定量解釋）。

**第四，悖論的教訓**：普利斯特里與燃素說的故事成為科學哲學的經典案例——科學理論的更替不僅需要證據，還需要接受證據的意願。發現氧氣的是燃素論者，理解氧氣的是化學革命家。

普利斯特里本人後來因同情法國大革命，1791 年伯明罕住所在暴動中被燒毀，1794 年移居美國賓州，在異鄉度過餘生。他失去了家園與藏書，卻從未失去對燃素的信仰——也從未失去對實驗的熱情。這位發現了氧氣卻不理解氧氣的牧師，留給化學的是一把開啟新時代的鑰匙，只是他自己選擇不轉動門把。

## 證據與工具

用 Python 重現普利斯特里的實驗計量：

```python
# 普利斯特里實驗重現：加熱氧化汞產生氧氣
# 化學計量：2HgO -> 2Hg + O2

M_HgO = 216.59    # g/mol
M_Hg  = 200.59
M_O2  = 32.00     # 脫燃素空氣（現名氧氣）

def decompose_HgO(mass_HgO):
    """加熱氧化汞，回傳 (汞質量, 氧氣質量)"""
    n = mass_HgO / M_HgO
    return n * M_Hg, n * M_O2

hg, o2 = decompose_HgO(10.0)
print(f"加熱 10.0 g 紅色氧化汞 -> 得到汞 {hg:.2f} g + 氧氣 {o2:.3f} g")
print(f"氧氣在同溫同壓下佔 {o2/M_O2*24.5:.2f} L（25°C, 1 atm）")

# 質量關係檢驗：汞 + 氧氣 = 氧化汞（質量守恆的先聲）
print(f"質量檢驗：{hg:.2f} + {o2:.3f} = {hg+o2:.2f} g（= 原始氧化汞質量）")
```

```python
# 蠟燭燃燒更旺實驗的模擬：
# 普通空氣含氧約 21%，脫燃素空氣（純氧）支持燃燒能力大增
# 以簡化模型：火焰亮度與氧分壓近似成正比

def candle_brightness(o2_fraction):
    """以氧分壓比例估計相對火焰亮度（簡化模型）"""
    return o2_fraction / 0.21    # 以普通空氣為 1.0

for label, frac in [("普通空氣", 0.21), ("脫燃素空氣", 0.95), ("固定空氣(CO2)", 0.0)]:
    b = candle_brightness(frac)
    status = "熄滅" if frac < 0.10 else f"燃燒（亮度 {b:.1f} 倍）"
    print(f"{label:>12}: {status}")

# 帶餘燼木片復燃：餘燼在純氧中重新燃起 —— 普利斯特里的關鍵定性證據
print("\n帶餘燼木片測試：普通空氣中微亮，脫燃素空氣中復燃成熊熊火焰")
```
