# 1913 Soddy 同位素與 Moseley 原子序

## 案發現場

進入二十世紀，週期表的排序原則出現了兩個致命的「案發現場」：

**現場一：放射性蛻變的荒謬結局。** 拉塞福與索迪（Frederick Soddy, 1877–1956）的蛻變理論說：鈾經 $\alpha$ 蛻變（失去氦核）後變成釷，再一連串蛻變下去。但化學家發現蛻變鏈上出現了化學性質完全相同、卻有不同原子量的「元素」——例如「釷 X」與釷化學性質一模一樣，原子量卻不同；鉛的放射性子代與普通鉛化學上無法區分，原子量也不同。這難道不是道耳頓「同元素必同原子量」的破產？元素到底是什麼？

**現場二：週期表的「倒置」對。** 依照原子量排序，氬（39.9）應排在鉀（39.1）之前，但化學性質明確顯示氬是惰性氣體、鉀是鹼金屬，順序必須倒過來。碲（127.6）與碘（126.9）、鈷與鎳也有同樣的倒置。如果原子量不是排序的真正依據，那什麼才是？

這兩個謎在 1913 年被兩位年輕人分別破解：索迪解開「元素的本質」，莫色勒（Henry Moseley, 1887–1915）解開「排序的真正原則」。

## 偵查過程

**索迪的偵查：同位素。** 索迪推理：放射性蛻變改變的是原子核（$\alpha$ 是氦核、$\beta$ 是電子），蛻變後的原子核質量不同，但核外電子結構（決定化學性質）可以相同。因此他提出：

> **存在原子量不同、化學性質完全相同的原子——它們應放在週期表同一位置，故稱「同位素」（isotope，希臘文「同一位置」）。**

元素的化學性質由核外電子決定，原子量只是同位素的「加權平均」：

$$\bar{M} = \sum_i f_i M_i$$

其中 $f_i$ 是各同位素的豐度。1913 年索迪提出「位移律」：$\alpha$ 蛻變使元素在週期表左移兩格、原子量減 4；$\beta$ 蛻變右移一格、原子量不變。他用這條律成功整理了三大蛻變系，並預言「鉛有兩種同位素」（來自鈾系的 ${}^{206}\mathrm{Pb}$ 與釷系的 ${}^{208}\mathrm{Pb}$），1914 年由理查茲以不同來源鉛的原子量差異證實。

**莫色勒的偵查：X 射線譜定原子序。** 1913 年，在拉塞福門下的年輕物理學家莫色勒做了化學史上最乾淨俐落的實驗之一：用各種元素作 X 射線管的靶，測量它們發出的特性 X 射線頻率。他發現 X 射線頻率的平方根與元素在週期表的順序編號呈完美直線——莫色勒定律：

$$\sqrt{\nu} = a(Z - b)$$

其中 $Z$ 就是原子序（原子核的正電荷數）。用波耳模型還可推導 K 系 X 射線的理論式（見 [1913-Bohr原子模型.md](1913-Bohr原子模型.md)）：

$$\nu = R c (Z - 1)^2 \left(1 - \frac{1}{4}\right) = \frac{3}{4} R c (Z-1)^2$$

$Z-1$ 中的 $-1$ 是因為內層另一顆電子的屏蔽效應。莫色勒用這條直線：一、**確定了每個元素的 $Z$**，氬 $Z=18$、鉀 $Z=19$——週期表真正依 $Z$ 排序，原子量倒置之謎煙消雲散；二、**找出週期表的空格**，預言了未發現的元素（$Z=43, 61, 72, 75$），後來的鎝、鉕、鉿、錸一一歸位；三、**證明氫到鈾之間不會再有未知元素**。

## 結案報告

索迪獲 1921 年諾貝爾化學獎。莫色勒的命運令人唏噓：1915 年他在加里波利戰場陣亡，年僅 27 歲。拉塞福痛惜地說：「他的服務是為了純科學。」若非戰死，諾貝爾獎幾乎必然屬於他。英國因此戰後開始限制科學家上前線。

遺產深遠：

1. **週期表的現代形式**：週期表依 $Z$ 排序，週期律的正確表述是「化學性質是 $Z$ 的週期函數」，為電子組態理論鋪路。
2. **同位素化學**：同位素標記成為化學與生物學的強力工具（如放射性追蹤、碳定年 ${}^{14}\mathrm{C}$）。
3. **原子核物理**：位移律是核反應守恆律（質量數與電荷守恆）的先聲。
4. **X 射線分析**：莫色勒定律至今仍是 X 射線螢光分析（XRF）鑑定元素的原理。

## 證據與工具

```python
# 莫色勒定律：sqrt(ν) 對 Z 為直線；同位素加權平均原子量
import numpy as np
import matplotlib.pyplot as plt

# 特性 X 射線 Kα 頻率理論值：ν = (3/4)·R·c·(Z-1)^2
R, c = 1.097e7, 3.0e8   # Rydberg 常數 (1/m) 與光速 (m/s)
Z = np.arange(15, 41)    # 部分元素
nu = 0.75 * R * c * (Z - 1)**2   # Kα 頻率 (Hz)
nu = nu * 1e-18          # 換成 10^18 Hz 方便繪圖

plt.plot(Z, np.sqrt(nu), "o-")
plt.xlabel("原子序 Z"); plt.ylabel(r"$\sqrt{\nu}$ (×10$^9$ Hz$^{1/2}$)")
plt.title("莫色勒定律：sqrt(ν) 對 Z 呈直線（Kα 系）")
plt.show()

# 同位素豐度 → 平均原子量（元素：氯）
isotopes = {"Cl-35": (34.969, 0.7576), "Cl-37": (36.966, 0.2424)}
M_avg = sum(m * f for m, f in isotopes.values())
print(f"氯的平均原子量 = {M_avg:.3f}（週期表上的 35.45 由此而來）")

# 放射性位移律檢驗：鈾-238 蛻變鏈的頭幾步
# α 蛻變：質量數 -4，原子序 -2；β 蛻變：質量數不變，原子序 +1
chain = [("U-238", 238, 92)]
steps = ["α", "β", "β", "α"]
A, Zn = 238, 92
for s in steps:
    A, Zn = (A-4, Zn-2) if s == "α" else (A, Zn+1)
    chain.append((f"(A={A}, Z={Zn})", A, Zn))
print("\n鈾-238 蛻變鏈前幾步（位移律）：")
for name, a_, z_ in chain:
    print(f"  {name}")
```
