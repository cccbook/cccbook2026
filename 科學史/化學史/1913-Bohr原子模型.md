# 1913 Bohr 原子模型

## 案發現場

1911 年拉塞福用 $\alpha$ 粒子散射實驗證明：原子中央有一個微小、帶正電的原子核，電子在外圍。但這個「行星模型」立刻撞上天花板——依古典電磁學，繞核旋轉的電子是加速運動的電荷，必然連續輻射電磁波、損失能量，在約 $10^{-11}$ 秒內螺旋墜入原子核。**原子應該根本不能穩定存在！** 更糟的是，若電子連續墜落，輻射光譜應是連續光譜，但實際上氫原子的發射光譜是一條條**分立的譜線**——1885 年巴耳末（Balmer）就發現氫的可見光譜線波長服從一個神祕的公式：

$$\frac{1}{\lambda} = R\left(\frac{1}{2^2} - \frac{1}{n^2}\right), \quad n = 3, 4, 5, \ldots$$

其中 $R$ 是里德堡常數（$1.097 \times 10^7\ \mathrm{m^{-1}}$），精確到六位有效數字。這個公式「算得準卻沒人懂」——為什麼是倒數平方差？分立譜線的物理來源是什麼？

在曼徹斯特拉塞福實驗室訪問的丹麥青年波耳（Niels Bohr, 1885–1962）於 1913 年接下這個案子，用一個「離經叛道」的假設震撼了物理學。

## 偵查過程

波耳的推理是一場古典與量子的「混搭偵查」：

**第一步：量子化軌道（大膽假設）。** 波耳假設電子只能在某些特定軌道上運行，這些軌道的角動量必須是 $\hbar = h/2\pi$ 的整數倍：

$$L = m v r = n \hbar, \quad n = 1, 2, 3, \ldots$$

在這些「定態軌道」上，電子**不輻射**——古典電磁學在這裡被公然違反。這一步的靈感來自普朗克（1900）與愛因斯坦（1905）的量子思想：能量本身就是不連續的。

**第二步：推導軌道半徑與能量。** 對氫原子，庫侖力提供向心力 $\frac{e^2}{4\pi\varepsilon_0 r^2} = \frac{mv^2}{r}$，結合量子化條件 $mvr = n\hbar$，解出軌道半徑：

$$r_n = n^2 a_0, \quad a_0 = \frac{\varepsilon_0 h^2}{\pi m e^2} \approx 0.529\ \text{Å}$$

$a_0$ 正是波耳半徑。能量為動能與位能之和：

$$E_n = -\frac{m e^4}{8 \varepsilon_0^2 h^2} \cdot \frac{1}{n^2} = -\frac{13.6}{n^2}\ \mathrm{eV}$$

**第三步：躍遷與巴耳末公式（破案關鍵）。** 電子從高能階 $n_2$ 躍遷到低能階 $n_1$ 時，放出光子，光子能量等於能階差（愛因斯坦的 $E = h\nu$）：

$$h\nu = E_{n_2} - E_{n_1} \implies \frac{1}{\lambda} = \frac{\nu}{c} = \frac{me^4}{8\varepsilon_0^2 h^3 c}\left(\frac{1}{n_1^2} - \frac{1}{n_2^2}\right)$$

括號外的係數正是里德堡常數的理論表達式！代入常數計算，$R_{\text{理論}} = 1.0974 \times 10^7\ \mathrm{m^{-1}}$，與實驗值吻合到千分之一以內。神祕的倒數平方差之謎徹底破解：**譜線就是電子在分立能階之間跳躍時放出的光子**。$n_1=2$ 給出巴耳末系（可見光），$n_1=1$ 是紫外線的萊曼系，$n_1=3$ 是紅外線的帕申系。

**驗證：皮克林譜線之謎。** 天文觀測中的「皮克林譜線系」曾被認為是某種未知氫，波耳模型預言它是 $\mathrm{He^+}$（類氫離子，$Z=2$，能量 $E_n = -54.4/n^2\ \mathrm{eV}$），光譜頻率應為氫的四倍——實驗完全證實，波耳一戰成名。

## 結案報告

波耳獲 1922 年諾貝爾物理學獎。波耳模型的遺產包括：

1. **能階概念**：原子內部能量是分立的——這是全部量子化學的起點，後續的軌域理論（見 [1916-Lewis共價鍵.md](1916-Lewis共價鍵.md)、[1927-HeitlerLondon氫分子.md](1927-HeitlerLondon氫分子.md)）都建築在能階之上。
2. **原子序與電子組態**：類氫離子的成功與 X 射線譜（見 [1913-Soddy同位素與Moseley原子序.md](1913-Soddy同位素與Moseley原子序.md)）讓「核電荷決定元素性質」成為共識，週期表得以用電子組態解釋。
3. **光譜化學**：光譜成為鑑定元素的利器，天體物理學誕生（恆星組成由譜線得知）。
4. **量子力學的先聲**：波耳模型對多電子原子失效，1925–26 年海森堡與薛丁格的量子力學接棒，但「定態與躍遷」的思想骨架保留至今。

## 證據與工具

```python
# 波耳模型：畫出氫原子能階圖與發射光譜（巴耳末系）
import numpy as np
import matplotlib.pyplot as plt

n = np.arange(1, 8)
E = -13.6 / n**2   # 能階 (eV)

# 能階圖
plt.figure(figsize=(8, 5))
for ni, e in zip(n, E):
    plt.hlines(e, 0.3, 0.7, lw=2)
    plt.text(0.75, e, f"n={ni}  {e:.2f} eV", va="center")
# 畫出巴耳末系躍遷（n2→2）
for n2 in range(3, 8):
    plt.annotate("", xy=(0.5, -13.6/4), xytext=(0.5, -13.6/n2**2),
                 arrowprops=dict(arrowstyle="->", color="C0", alpha=0.6))
plt.xlim(0, 1.6); plt.ylabel("能量 (eV)")
plt.title("氫原子能階圖（箭頭：巴耳末系躍遷 n→2）")
plt.show()

# 發射光譜：λ = 1 / [R(1/n1² - 1/n2²)]
R = 1.097e7   # m^-1
series = {"萊曼系(n1=1)": (1, range(2, 6)),
          "巴耳末系(n1=2)": (2, range(3, 8)),
          "帕申系(n1=3)": (3, range(4, 8))}
plt.figure(figsize=(9, 3))
for y, (n1, ns) in series.items():
    for n2 in ns:
        lam = 1 / (R * (1/n1**2 - 1/n2**2)) * 1e9   # nm
        color = "violet" if lam < 400 else ("orange" if lam > 700 else None)
        plt.vlines(lam, 0, 1, lw=2, color=color)
plt.xlabel("波長 (nm)"); plt.yticks([])
plt.title("氫原子發射光譜（理論計算的譜線位置）")
plt.show()

# 驗證巴耳末公式計算的 Hα 譜線（656 nm 紅光）
lam_Ha = 1 / (R * (1/4 - 1/9)) * 1e9
print(f"Hα 譜線計算波長 = {lam_Ha:.1f} nm（實驗值 656.3 nm）")
```
