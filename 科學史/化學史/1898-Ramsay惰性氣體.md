# 1898 Ramsay 惰性氣體

## 案發現場

十九世紀末，化學家們普遍認為元素的清單已經接近完成。Mendeleev 的週期表（1869 年，見週期表篇章）把已知元素排成優美的週期系統，甚至成功預言了鎵、鈧、鍺等未知元素。然而就在科學界沾沾自喜之際，一整**族元素**——不是一兩個，而是整整一縱列——卻完全缺席於週期表，而且**沒有人預言過它們的存在**。

謎題的線索來自天文學。1868 年，法國天文學家 Janssen 與英國的 Lockyer 在日蝕的太陽光譜中發現一條陌生的黃色譜線（波長 587.6 nm），無法對應任何已知元素；Lockyer 大膽命名這個只存在於太陽的元素為 **helium（氦）**——當時地球上沒有人見過它。化學家半信半疑：一個只在太陽出現的元素？

地質與物理的線索接踵而至。1894 年，倫敦的物理學家 Rayleigh（瑞利男爵）在精密測量氣體密度時發現一件怪事：從**空氣**中分離出來的氮氣，密度為 1.2572 g/L；而從**化合物**（氨）分解得到的氮氣，密度只有 1.2507 g/L。兩者都是「氮氣」，密度卻差了 0.0065 g/L——小小的差異，卻遠超過 Rayleigh 的實驗誤差（他的稱量精密度可達萬分之一）。

氮氣為什麼有兩種密度？空氣分離的氮氣裡，是不是混著什麼比氮更重的、**從未被發現的氣體**？

在倫敦大學學院，化學家 William Ramsay（拉姆齊）與 Rayleigh 聯手，展開了追捕「隱形元素」的偵查。

## 偵查過程

**第一步：抓住第一個嫌犯——氬。**Ramsay 把空氣中的氮氣用赤熱的鎂帶吸收掉（鎂與氮反應生成氮化鎂 $\mathrm{Mg_3N_2}$）：

$$3\,\mathrm{Mg} + \mathrm{N_2} \xrightarrow{\Delta} \mathrm{Mg_3N_2}$$

結果殘留了約 1% 體積的氣體，怎麼加熱也不肯與鎂反應。Ramsay 與 Rayleigh 對它做光譜分析與密度測定：密度 1.78 g/L（比氮重），光譜呈現陌生的紅色與綠色譜線。1894 年，他們宣布發現新元素，命名為 **argon（氬）**——希臘文「懶惰、不工作」之意，因為它**完全不肯與任何物質反應**。氬的發現震驚學界：一個佔空氣近 1% 的元素，竟然藏了這麼多年！更麻煩的是：氬的原子量約 40，在週期表中找不到位置——它該排在氯（35.5）與鉀（39）之間嗎？那裡沒有空位！

**第二步：從空氣中「淘金」。**Ramsay 推理：如果空氣中藏著氬，會不會還藏著別的惰性氣體？他與學生 Travers（特拉弗斯）使用當時最新的技術——**液化空氣再分餾**。1898 年，他們把大量空氣液化，緩慢蒸發分餾，再以放電管與光譜儀逐段檢查各餾分。短短一個夏天內連中三元：

1. **氪 krypton**（5 月）：藏於較難揮發的餾分，希臘文「隱藏」；
2. **氖 neon**（6 月）：藏於氬餾分中較易揮發的部分，放電時發出奪目的**橘紅色光**——希臘文「新」；
3. **氙 xenon**（7 月）：藏於最難揮發的殘液，希臘文「陌生」。

**第三步：太陽元素的落地與定位。**同年，Ramsay 從釔鈾礦（cleveite）加熱放出的氣體中，用光譜確認了 **helium（氦）**——那條 1868 年的太陽黃色譜線（587.6 nm）出現在了地球的實驗室裡！太陽元素找到了。

至此，五種惰性氣體齊聚：$\mathrm{He,\ Ne,\ Ar,\ Kr,\ Xe}$。Ramsay 注意到它們的原子量形成完美的序列（4, 20.2, 40, 83.8, 130.2），而**恰好可以插在週期表的鹵素（F, Cl, Br, I）與鹼金屬（Li, Na, K, Rb, Cs）之間**，形成全新的一縱列——**0 族**。週期表不但沒有被氬的出現打亂，反而因為這一族的存在而更加完美：

$$\cdots \to \mathrm{F} \to \underbrace{\mathrm{Ne}}_{\text{0 族}} \to \mathrm{Na} \to \cdots \quad \text{（氖恰好填在氟與鈉之間）}$$

最後的謎題——**為什麼它們完全不反應？**——要等到 1916 年由 Lewis 的電子殼層理論解答（見 [1916-Lewis共價鍵.md](1916-Lewis共價鍵.md)）：惰性氣體的最外層電子已經填滿（8 電子八隅體、氦為 2 電子），無需得失或共享電子，故化學性質極端惰性。

## 結案報告

Ramsay 因惰性氣體的發現獲得 1904 年諾貝爾化學獎（Rayleigh 同年獲物理獎），成為化學史上的一段佳話。

1. **週期表新增 0 族**：一整族元素的發現證明了週期表結構的深層正確性——它不只容納已知元素，還有整個未知的縱列等待發掘。0 族（今日的 18 族）成為理解一切元素週期性的關鍵樞紐。
2. **通往電子殼層理論**：「為什麼不反應」之謎，直接催生了 Bohr 的電子層模型（1913 年）與 Lewis 的八隅體理論（1916 年）——惰性氣體的「滿殼層」成為所有化學鍵理論的參考原點。見 [1916-Lewis共價鍵.md](1916-Lewis共價鍵.md)。
3. **技術遺產**：氖燈（neon signs，1910 年起）點亮了二十世紀的城市夜景；氬氣成為焊接與燈泡的保護氣；氦氣用於飛艇、低溫超導與深潛呼吸；氙用於麻醉與離子推進器。液化空氣分餾工業也因這項偵查而壯大。
4. **精密測量的力量**：整個發現始於 Rayleigh 對 0.0065 g/L 密度差的執著——萬分之五的差異，藏著 1% 的大氣。這是「小數點後第四位的科學」最精采的範例。
5. **例外證明規則**：有趣的是，1962 年 Bartlett 合成了六氟化氙鉑 $\mathrm{XePtF_6}$，證明惰性氣體並非絕對惰性——但這個「例外」反而更深刻地驗證了電子殼層理論：只要足夠強的氧化劑，就能撬開八隅體。

一場對 0.0065 g/L 的追捕，抓住了五種隱形元素，也抓住了原子結構理論的第一把鑰匙。

## 證據與工具

以下 Python 程式重現 Rayleigh 的密度之謎與 0 族的週期定位：

```python
# 1. Rayleigh 的密度之謎：兩種「氮氣」的密度差
rho_air_N2 = 1.2572   # 從空氣分離的氮氣密度 (g/L)
rho_chem_N2 = 1.2507  # 從氨分解的氮氣密度 (g/L)
diff = rho_air_N2 - rho_chem_N2
precision = 0.0001    # Rayleigh 的稱量精密度
print(f"空氣法氮氣密度：{rho_air_N2} g/L")
print(f"化學法氮氣密度：{rho_chem_N2} g/L")
print(f"密度差：{diff:.4f} g/L，是實驗誤差（{precision}）的 {diff/precision:.0f} 倍！")
print("-> 空氣法氮氣中必混有更重的未知氣體 -> 1894 年發現氬")

# 2. 混合物密度估算：空氣法氮氣 ≈ 99% N2 + 1% Ar
rho_N2, rho_Ar = 1.2507, 1.7824
f_Ar = (rho_air_N2 - rho_N2) / (rho_Ar - rho_N2)
print(f"\n若混有 Ar，比例 f = {f_Ar*100:.2f}%（與實際大氣氬含量 ~0.93% 相符）")

# 3. 0 族定位：惰性氣體原子量恰好落在鹵素與鹼金屬之間
groups = [
    ("Li", 6.94),  ("F", 19.00),  ("Ne", 20.18),
    ("Na", 22.99), ("Cl", 35.45), ("Ar", 39.95),
    ("K",  39.10), ("Br", 79.90), ("Kr", 83.80),
    ("Rb", 85.47), ("I", 126.90), ("Xe", 131.29),
]
print("\n週期表定位（鹵素 -> 0 族 -> 鹼金屬）：")
for i in range(0, len(groups), 3):
    alkali, halogen, noble = groups[i], groups[i+1], groups[i+2]
    ok = halogen[1] < noble[1] < alkali[1]
    print(f"  {halogen[0]}({halogen[1]}) < {noble[0]}({noble[1]}) < "
          f"{alkali[0]}({alkali[1]})  -> {'✓ 氬式空位被填滿' if ok else '✗'}")

# 4. 光譜鑑定：各惰性氣體的特徵譜線 (nm)
spectra = {"He": [587.6, 447.1], "Ne": [585.2, 640.2],
           "Ar": [696.5, 706.7], "Kr": [557.0], "Xe": [462.4]}
print("\nRamsay 的光譜指紋（特徵譜線）：")
for gas, lines in spectra.items():
    print(f"  {gas}: {lines}")
print("1868 年的太陽黃線 587.6 nm = 氦 -> 太陽元素在地球上找到了！")
```
