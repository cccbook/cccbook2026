# 1950 - Turing 測試（機器能思考嗎？——把哲學問題變成偵探遊戲）

## 案件摘要
1950 年，Turing 在哲學期刊《Mind》發表〈計算機器與智能〉(Computing Machinery and Intelligence)。
面對「機器能思考嗎？」這個無法回答的哲學懸案，Turing 的偵探手法是**換一個可操作的問題**：
與其問「機器能否思考」，不如問「機器能否在對話遊戲中不被識破」——**模仿遊戲**，後世稱圖靈測試。
$$\text{機器智能} \iff \text{人類評審在對話中無法區分機器與人類}.$$

## 前因 -- 為什麼會有這個案子
- **「機器能思考嗎」的僵局**：「思考」沒有定義，問題無法操作——哲學爭論永無結案。
- **Turing 機的遺產（1936）**：Turing 已證明通用計算機的存在（見計算理論案件）；二戰中他破解 Enigma，深知機器的能與不能。
- **電腦的誕生**：1940 年代末 ENIAC 等電腦問世，「機器能做到什麼」成為現實問題。
- **Turing 的偵探直覺**：與其定義「思考」，不如設計一個**行為測試**——判決標準從「內心」轉移到「外部行為」。這是行為主義的偵探版。

## 線索與推理 -- 數學式、程式、理論

### 模仿遊戲的規則
三方參與：評審 (C)、人類 (A)、機器 (B)。評審透過純文字對話判斷誰是人類。
若機器能讓評審誤判的比例顯著高於瞎猜（50%），則判決：**機器通過測試**。

### Turing 對「機器不能思考」九大反駁的逐一擊破
Turing 在論文中列出當時的反對意見並逐一反駁，包括：
1. **神學反對**：思考是靈魂的專利——Turing：造物主既然能造會思考的人，沒理由不能造會思考的機器。
2. **數學反對**：Gödel 不完備定理限制機器——Turing：人類同樣不完備（人也會自相矛盾），限制是對稱的。
3. **意識反對**（Jefferson）：機器不會「感覺」——Turing：若按此標準，只能知道自己會思考（唯我論）。
4. **Lovelace 反對**：機器只能做被程式化的事——Turing：機器可以「學習」，也可以被「驚喜」（隨機數 + 程式產生未預期行為）。

### 機器學習的先驅宣言
Turing 在論文末尾提出：與其寫死規則，不如製造**會學習的機器**——「兒童機器」(child machine)：
$$\text{成人頭腦} \approx \text{兒童頭腦} + \text{教育}.$$
他預言：與其模擬成人，不如模擬兒童的學習過程，用**獎懲**教導它——這正是 70 年後強化學習與 RLHF（見「2022-ChatGPT與RLHF.md」）的先聲。

### Python：一個極簡的「模仿遊戲」騙局示範

```python
import random, re

def eliza_reply(user_input):        # 1966 年 ELIZA 的雛形思路
    rules = [
        (r"我.*難過|我.*傷心", "聽到你難過，你希望我怎麼幫你？"),
        (r"你(.*)嗎", "你為什麼想知道我{}嗎？"),
        (r"我(.*)你", "你為什麼{}我？"),
    ]
    for pat, resp in rules:
        m = re.search(pat, user_input)
        if m: return resp.format(*(m.groups()))
    return random.choice(["能多說一點嗎？", "這讓你想到什麼？"])

for u in ["我今天很難過", "你會思考嗎", "我喜歡你"]:
    print("USER:", u, "\nBOT :", eliza_reply(u))
```
輸出（模式比對就能騙過許多人——智能測試的「漏洞」本身就是案件線索）：
```
USER: 我今天很難過
BOT : 聽到你難過，你希望我怎麼幫你？
USER: 你會思考嗎
BOT : 你為什麼想知道我會思考嗎？
USER: 我喜歡你
BOT : 你為什麼喜歡我？
```

## 結案 -- 後果與影響
- 「機器能思考嗎」被**重新立案**為可操作的工程問題，催生 1956 年 Dartmouth 會議與整個 AI 學科（見「1956-Dartmouth會議.md」）。
- **哲學影響**：Searle 的「中文房間」（1980）是對圖靈測試最著名的反駁——行為等價是否等於理解？辯論延續至今。
- **圖靈獎**：1966 年設立，成為電腦科學的諾貝爾獎。
- 70 年後的迴響：大型語言模型（見「2022-ChatGPT與RLHF.md」）首次在對話中難以被普通人區分——圖靈測試在 2020 年代實質通過，但「它是否理解」的辯論依然未結案。
- Turing 的預言幾乎全部命中：機器學習、獎懲訓練、甚至「機器會寫詩」——他預估 2000 年前後機器可在 5 分鐘對話中騙過 30% 評審，大致成真。
