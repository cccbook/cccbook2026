# 人工智慧史 -- AI 偵探風格

以「推理探案」的方式，追查人工智慧從 McCulloch–Pitts 神經元到 ChatGPT 的每一步：
前因是什麼？線索在哪裡？推理如何展開？後果又如何改變了整個電腦科學與人類世界？
核心謎題只有一個：**機器真的能「思考」嗎？還是只是在算數學？**
