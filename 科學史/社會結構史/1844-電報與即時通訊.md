# 1844-電報與即時通訊

## 案件摘要
1844 年 5 月 24 日，莫爾斯在華盛頓發出「What hath God wrought」——電報把通訊第一次與**交通**分離：信息跑得比火車、比輪船快。這樁「電流傳信」案件是信息結構的重構：新聞從「周報」變「即時」、金融套利被壓縮（倫敦-紐約價差在電纜通後數日內消失）、帝國獲得「即時統治」能力（1866 大西洋電纜、帝國電報網）。Jevons（1871）以小麥價格證明：**信息成本下降 = 市場整合**。電報是現代通訊技術鏈（電報 → 電話 → 廣播 → 網路）的第一環——每一次都重畫市場、新聞與政治的結構。

## 前因 -- 為什麼會有這個案子
- **信息的交通瓶頸**：信息只能隨交通移動（郵船、驛馬、火車）——倫敦-紐約的信息延遲 10-14 天——市場、政府、新聞都被「延遲」鎖死。
- **電學的累積**：奧斯特（1820 電流磁效應）、安培、莫爾斯碼（1838）——「電流即信息」的技術準備。
- **鐵路的先行者**：鐵路（1825 案）已用電報調度（間隔閉塞）——「電報 + 軌道」共生。
- **市場的需求**：跨洋套利、商品報價、新聞時效——信息的需求方就緒。

## 線索與推理 -- 數學式、理論、表格

### 線索一：信息成本 = 市場整合
Jevons（1871）的實證：電報時代小麥價格的地區離散度大降——

$$\text{價格離散} \propto \text{信息與套利成本} \quad \xrightarrow{\text{電報}} \quad \text{離散收斂}$$

**推理**：信息延遲 → 套利機會存在 → 區域價差；電報讓報價即時可得 → 套利秒級完成 → 價差被壓縮到運費。**市場整合的極限 = 信息速度**——電報把「地方市場」整合成「全球市場」（1825 案鐵路的空間整合 + 本案的信息整合）。

### 線索二：新聞與公眾輿論的重構
| | 電報前 | 電報後 |
|---|--------|--------|
| 新聞時效 | 數天-數週 | 小時級 |
| 通訊社 | 地方稿源 | 路透社（1851）、美聯社（1846）全球網 |
| 新聞形態 | 深度/評論 | 快訊/標題 |

**推理**：即時新聞 → 「同時知道」的大眾（安德森的想像共同體的加強版）→ 全國輿論的同步化；「事件導向」的新聞形態誕生——媒體的政治結構重畫（1789 案印刷輿論的電報加速版）。

### 線索三：帝國的即時統治
1866 大西洋電纜（菲爾德）、帝國電報網（1870s 連通印度、澳洲）——殖民總督與倫敦即時往來——「即時統治」：

$$\text{帝國控制半徑} \propto \frac{\text{信息速度}}{\text{決策延遲}}$$

**推理**：電報讓中央集權跨越地理——地方總督的裁量權被削弱（倫敦遙控），帝國的官僚化（1890s 電報密碼、領事裁判的即時請示）。戰爭也同時改變（克里米亞戰爭 1853-56 是第一場「電報戰爭」——戰報即時傳回，報紙即時動員輿論）。

### 線索四：金融的即時化
跨洋匯率、商品報價的即時化 → 金融市場的全球同步 → 1873、1893 的金融恐慌以「電報速度」傳染——**金融危機的傳染加速**（1929 案的先聲）；證交所的「投機」獲得新工具（電報下單）——信息的雙面刃。

## 結案 -- 後果與影響
- **通訊革命的譜系**：電報 → 電話（1876）→ 無線電（1901）→ 電視 → 網路（1991 案）——「信息與交通分離」是現代通訊的第一原理。
- **市場的全球化**：商品與金融的全球同步定價——世界市場的信息基礎。
- **新聞與政治的即時化**：通訊社、快訊、輿論動員——現代媒體政治的誕生。
- **帝國的電報統治**：帝國管理從「委託」變「遙控」——中央集權的技術升級。
- **時間的再壓縮**：從「天」到「分」——信息延遲的每次壓縮都重畫一次市場與政治（2004 案社交媒體的「秒級」是本鏈的最新一環）。
