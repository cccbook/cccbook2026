# 1315-大飢荒與氣候震盪

## 案件摘要
1315-1317 年，連年暴雨與低溫襲擊歐洲（史稱「狼雨」Wolfsjahr）——收成連續三年腰斬，穀價漲三倍，部分地區餓死 10-15% 人口。這樁「氣候」案件是「非技術因素重構社會」的經典：中世紀溫暖期的頂點（950 案的人口倍增）已撞上土地的極限——氣候波動把「馬爾薩斯頂點」戳破。社會後果：犯罪與動亂（糧食暴動、吃人傳聞）、北歐擴張的轉折（維京格陵蘭殖民的衰落起點）、以及為 1347 黑死病的脆弱結構鋪路（1315 飢荒 + 1347 疫病雙擊）。**氣候是社會結構的隱形變數**——小冰期（1600s）、歐洲大飢荒（1315）、愛爾蘭飢荒（1846）是同一主題的變奏。

## 前因 -- 為什麼會有這個案子
- **人口已到極限**（950 案）：950-1300 人口倍增（英格蘭 150 萬 → 500 萬），邊際土地（坡地、窪地）已被開發——產出的緩衝極小。
- **中世紀溫暖期的反轉**：1300 前後氣候轉冷濕（小冰期的先兆）——北大西洋振盪（NAO）轉負 → 西歐連年多雨。
- **單一作物的脆弱**：穀物（小麥黑麥）為主食，儲備僅一年——連續歉收即系統崩潰（1550 案新作物尚未擴散，沒有馬鈴薯的緩衝）。
- **農業的極限**：三圃制（950 案）已把耕地用到極限——技術的緩衝用罄。

## 線索與推理 -- 數學式、理論、表格

### 線索一：馬爾薩斯頂點的實證
Malthus（1798）的模型：人口指數增長、糧食線性增長 → 生存線的擠壓——1315 是「頂點被戳破」的實證：

| | 1300（頂點前）| 1315-17（飢荒）|
|---|--------------|----------------|
| 人口 | 500 萬（英格蘭）| -10~15% |
| 穀價 | 基準 | ×3（小麥）|
| 收成 | 邊際 | -50%（三年）|

**推理**：人口增長吃掉產出的緩衝 → 氣候波動 → 系統崩潰——「技術紅利 → 人口增長 → 脆弱性」的棘輪（950 案紅利 → 1315 崩潰）——馬爾薩斯陷阱的歷史驗證。

### 線索二：氣候 → 農產 → 社會的因果鏈
氣候學的重建（樹輪、冰芯、歷史記錄）：1315-17 的西歐連年冷濕（NAO 轉負 + 火山活動的可能貢獻）→ 收成腰斬 → 穀價三倍 → 飢荒、疫病（壞血病、痢疾）與動亂：

$$\text{氣候振盪} \to \text{農產波動} \to \text{價格與飢荒} \to \text{動亂與死亡率}$$

**推理**：氣候是社會結構的**外生衝擊變數**——樹輪與冰芯（現代氣候重建）讓「氣候史」成為一門學科（Lamb、Bradley 的古氣候學）——社會史與氣候史的合流（Harper 2017、Campbell 2016）。

### 線索三：社會結構的衝擊面
| 衝擊面 | 表現 |
|--------|------|
| 犯罪與動亂 | 糧食暴動、搶糧、吃人傳聞（波羅的海）|
| 制度反應 | 城市封倉、禁止出口、賑濟 |
| 擴張的轉折 | 維京格陵蘭殖民的衰落起點（氣候轉冷 + 航路受阻）|
| 貧富 | 窮人死、富人囤——「飢荒的分配」（Sen 1981：飢荒常是**分配**問題而非總量問題）|

**推理**：Amartya Sen（1981）的「權利分析」：飢荒死的多是**失去交換權利的人**（無地、無錢）——1315 的死亡分配（城市窮人、無地勞工）驗證——飢荒是分配的社會結構問題，不只是氣候。

### 線索四：為黑死病鋪路
1315 的營養不良 → 免疫力下降 + 人口密集未疏散 → 1347 黑死病的死亡率更高（1347 案）——「飢荒 + 疫病」的疊加（541 案 536 火山冬天 + 疫病的同構）——**氣候、疫病、人口的三重奏**（Campbell 2016《大轉型》的「自然與社會的耦合」）。

## 結案 -- 後果與影響
- **人口頂點的轉折**：1300 前後的人口頂 → 1315 飢荒 → 1347 疫病——中世紀人口曲線的雙重下殺（Campbell 的「大轉型」）。
- **氣候史的誕生**：樹輪、冰芯、歷史記錄的合流——「氣候作為歷史變數」的學科化。
- **飢荒的分配理論**：Sen 的權利分析——飢荒是社會結構（誰有交換權利）的問題——現代發展經濟學的基礎。
- **糧食安全的政策意識**：城市封倉、賑濟、儲備——「糧食安全」成為治理的永恆議題（1846 案愛爾蘭的政策失靈是其反面教材）。
- **非技術因素的定位**：氣候（本案）、疫病（541、1347）、戰爭（1618）——社會結構的推手不只有技術，自然與暴力同樣是主角。
