# 1602-東印度公司與股份制

## 案件摘要
1602 年，荷蘭議會特許「聯合東印度公司」（VOC）——人類第一家可轉讓股份、永久存續的股份公司誕生；同年阿姆斯特丹證券市場開張。這樁「組織發明」案件是社會結構的深層重構：**公司成為超越個人生命的法人**——出資人以有限風險（認繳額）換取遠洋貿易的暴利機會，資金規模首次超越任何家族或王室的財力。股份制 + 證交所 + 有限責任，三件套讓「資本」成為可集合、可流通、可繼承的獨立存在——資本主義的組織硬體自此安裝，殖民帝國（VOC 自己就是半個政府）與現代企業同源而生。

## 前因 -- 為什麼會有這個案子
- **遠洋貿易的風險規模**：一次亞洲遠航需數十萬弗羅林（船 + 貨 + 武裝），回報在 2-3 年後且折損率高——個人與家族無力、也無法承受單次全損。
- **合夥制的瓶頸**：商業革命（1100 案）的 commenda 合夥是「一次航程」式的臨時組織——航程結束即清算，無法累積長期資本。
- **競爭的整合需求**：荷蘭各省的六家遠洋公司互相殺價搶購香料——整合為一家壟斷公司（Oldenbarnevelt 推動）。
- **荷蘭的資本密度**：阿姆斯特丹是歐洲的資本與商品中心（波羅的海穀運 + 安特衛普陷落 1585 的資金遷入）——資本供給充足。

## 線索與推理 -- 數學式、理論、表格

### 線索一：風險分散的數學
遠航的成功率 $p \approx 0.7$（海難、海盜、疫病），一次全損即破產。股份制的解法：

$$\text{一人全額} \implies \text{破產機率} = 1-p = 0.3$$
$$\text{分散於 } n \text{ 航程，各占 } 1/n \implies \text{單次損失} = \frac{1-p}{n}$$

**推理**：股份可轉讓讓投資人「隨時可退」，公司「永久存續」——資本與個別航程脫鉤，風險被時間與人數攤薄。VOC 以 650 萬弗羅林初始資本（相當於數千個家族財富的集合）裝備數百艘船與私人軍隊——資本的「集合」第一次超越王權。

### 線索二：三件套的組織發明
| 發明 | 內容 | 效果 |
|------|------|------|
| 永久法人 | 公司不因股東死亡解散 | 資本可跨代累積 |
| 可轉讓股份 | 股票可在阿姆斯特丹交易所買賣 | 流動性 → 更多人願意投資 |
| 有限責任 | 損失以出資額為限 | 破產風險個人化極小化 |

**推理**：三件套合流後，「公司」成為獨立的經濟主體——比任何個人活得久、比任何家族有錢、風險被制度吸收。這是 476 案「組織比人活得久」邏輯的資本版（漢摩拉比法典讓法律比王活得久；股份公司讓資本比商人活得久）。

### 線索三：公司即帝國
VOC 的特許狀授與其外交（締約）、軍事（艦隊、要塞）、司法（殖民法庭）、鑄幣權——公司在亞洲行使**主權**：占領馬六甲（1641）、錫蘭、爪哇（巴達維亞 1619）。推理：殖民不是「國家的行為」而是「公司的行為」——資本組織直接成為統治組織，公司與帝國的邊界在此模糊（英國東印度公司統治印度到 1858）。

### 線索四：證交所與金融市場
阿姆斯特丹交易所（1602）：股票、後來的期貨（荷蘭鬱金香狂熱 1637——第一次投機泡沫）——資本市場成為價格發現與投機的公共場所。金融革命的荷蘭先聲（1688 英國金融革命的模板）。

## 結案 -- 後果與影響
- **荷蘭黃金時代**：VOC 年均分紅 18%（1630-50），阿姆斯特丹成為世界金融中心——「商業共和國」的政治模式（議會 + 商人精英）。
- **殖民帝國的公司化**：VOC/英 EIC 以公司統治亞洲——殖民體系的公司化模板，19 世紀國家接管（EIC 1858 移交王權）。
- **現代企業的路徑**：股份制 → 1690s 英國股份公司浪潮 → 鐵路公司（1825 案）→ 現代公司——「法人資本主義」的組織譜系。
- **金融市場的誕生**：證交所 + 投機（鬱金香 1637）→ 1929（泡沫案）、2008（金融危機案）——資本市場的雙面刃反覆重演。
- **商業階層的政治化**：荷蘭攝政精英（商人執政）——商業階層首次成為統治階級，資產階級革命的先聲（1688 案）。
