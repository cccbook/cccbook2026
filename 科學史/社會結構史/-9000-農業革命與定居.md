# -9000-農業革命與定居

## 案件摘要
約一萬年前（前9000-8000），黎凡特與兩河流域的人類開始馴化小麥、大麥與山羊綿羊——新石器革命。這樁看似「食物技術」的案件，實則是社會結構的第一場大重構：農業產生**剩餘**，剩餘產生**財產**，財產產生**階層**，階層催生**國家**。採集時代的人人平等讓位於農民、祭司、戰士、酋長的分層世界。此後一萬年的政治與經濟，都在這個「剩餘的詛咒」框架裡展開。

## 前因 -- 為什麼會有這個案子
- **末次冰期結束**（前11000-9700）：氣候轉暖濕，野生穀物（小麥祖先）在肥沃月灣茂生，馴化的原料就位。
- **定居的先聲**：納吐夫文化（前13000-9800）已在豐饒地帶半定居——定居先於農業，倒果為因的線索。
- **人口壓力**：採集社會人口密度受食物密度鎖死，Boserup（1965）推論：人口增長迫使集約化——農業是「被逼出來的技術」。
- **工具就緒**：磨製石器、陶器、織物已陸續出現，儲存與煮食的硬體齊備。

## 線索與推理 -- 數學式、理論、表格

### 線索一：剩餘 = 分層的物理基礎
採集社會的食物無法儲存與運輸，剩餘趨近於零，誰也養不活專職的祭司或將軍。農業改變了這條算式：

$$N_{\text{非農}} = \frac{Y_{\text{總產}} - S_{\text{生存口糧}}}{C_{\text{人均消費}}}$$

只要 $Y > S$，社會就能養活不事生產的專職者（祭司、戰士、工匠、官僚）。戴蒙德（1998）推算：一個農民可養活的人口是採集者的數倍——分層的「供給面」就此打開。

### 線索二：財產與繼承
穀物要耕作、土地要清理、水井要挖掘——投資回收期長達一年以上，**土地成為可持有的財產**。採集者無法囤積（游動即財產），農民的一切都在地上。財產 → 繼承 → 血緣貴族：考古學上，墓葬隨葬品從均一（前9000）變為懸殊（前5000）——階層在墓穴裡現形。

### 線索三：兩種社會的結構對照

| 維度 | 採集社會 | 農業社會 |
|------|---------|---------|
| 人口密度 | < 1 人/km² | 10-100 人/km² |
| 財產 | 幾乎無 | 土地、牲畜、糧倉 |
| 分層 | 年齡/性別為主 | 酋長/祭司/平民 |
| 勞動分工 | 幾乎無 | 專職祭司、工匠、戰士 |
| 政治規模 | 遊群（< 100 人）| 部落 → 酋邦 → 國家 |
| 暴力壟斷 | 無 | 酋長/王權萌芽 |

### 線索四：Boserup vs Malthus 的辯論
- **Malthus**（1798）：糧食決定人口上限；技術進步 → 人口增長 → 回到生存線（馬爾薩斯陷阱）。
- **Boserup**（1965）：反向——人口壓力**驅動**農業集約化（休耕縮短、灌溉、施肥）。
- 兩者合流解釋了此後八千年的劇本：農業技術躍升 → 人口增長 → 生存線重壓 → 下一輪技術——社會結構的「棘輪」。

### 線索五：女性的轉折
採集社會女性採集提供主要熱量（漁獵只占 30-40%），地位相對高；農業的重犁與灌溉勞動偏向男性體力，加之懷孕與定居的束縛——性別分工固化，父權結構在考古與神話記錄中同步浮現。這是農業案件最深遠的社會副作用。

## 結案 -- 後果與影響
- **國家的種子**：剩餘 + 財產 + 分層 = 酋邦（chiefdom），前3000 的城市國家（烏魯克、埃及）在其上長成——沒有農業就沒有官僚與王權。
- **宗教作為分配技術**：糧倉與神廟共生（前3500 烏魯克白廟），祭司掌握「再分配」的正當性——波蘭尼（1944）所謂經濟嵌入宗教。
- **戰爭升級**：定居的糧倉成為可掠奪目標，防禦性城牆（耶利哥，前8000）是最早的軍事建築——戰爭從儀式變成生計之爭。
- **流行病與貧富差距的伏筆**：人畜共居帶來天花、麻疹；糧食單一化帶來營養縮水（農民比採集祖先矮 10cm）——農業紅利與代價並存。
- **此後一切的母題**：剩餘如何分配、誰控制剩餘，成為此後一萬年政治經濟學的核心問題。
