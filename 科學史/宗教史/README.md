# 宗教的歷史年表（科學史）

> 宗教史不只是信仰的歷史，更是人類不斷追問「神聖是什麼」的偵探史：巴比倫的囚徒如何在亡國後救活自己的神？一個 iota 如何分裂了帝國的信仰？為什麼胡司被焚、路德卻存活？史上最保守的機構為什麼自我現代化？為什麼所有文化都會生出宗教？
>
> 本書以「推理探案」的方式，為每個歷史事件寫一篇 wiki，包含前因後果、學術理論與表格。每篇檔名以年份開頭。
>
> 本書立場：以歷史學、社會學、人類學與認知科學的方法研究宗教——歷史與科學追蹤「宣告、文本、機制與後果」，形上真偽則止步於偵查邊界（見 [0030-耶穌受難與復活信仰.md](0030-耶穌受難與復活信仰.md)）。

## 寫作方式說明

每篇 wiki 採「推理探案」結構：

1. **案發現場（前因）**：當時的未解之謎是什麼？誰遇到的？為何重要？
2. **偵查過程（推理）**：歷史學家/社會學家/神學家如何思考？關鍵證據與推理為何？逐步重建機制與理論。
3. **結案報告（後果）**：謎題如何解？留下什麼遺產？影響了哪些後續發展？
4. **證據與工具**：時間表、對照表、機制圖、學術理論（史學方法論、社會學理論、認知科學模型）——非必要不硬寫程式，以表格、公式與理論說明。

本書的方法論底線：歷史與科學追蹤**宣告、文本、機制與後果**；形上真偽（神是否存在、啟示是否為真）超出史學與科學工具的量程，止步於偵查邊界。
