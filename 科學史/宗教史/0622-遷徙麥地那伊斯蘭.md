# 0622 遷徙麥地那與伊斯蘭：為什麼「搬家」是元年？

## 案發現場

約 570 年，穆罕默德生於麥加的古萊氏族。610 年，他在城郊希拉山洞靜修時自稱領受啟示——經由天使吉卜利里（加百列）傳達的獨一神信息：「你當宣讀！」此後啟示持續二十三年。

麥加的核心經濟是**朝聖**：克爾白殿聚集三百六十尊部族神像，各部落來此獻祭——多神崇拜是麥加的商業模式。一神的信息直接衝擊這套經濟與部落秩序：迫害降臨，信徒被抵制、被驅逐。622 年，葉斯里卜（後稱麥地那）的部落因長年血仇難解，邀請穆罕默德前去仲裁——他率信眾遷徙（Hijra）。

> **為什麼伊斯蘭曆以「搬家」為元年，而不是以啟示開始的一年？麥地那階段到底改變了什麼？**

## 偵查過程

**線索一：麥加階段——宗教是「宣告」。** 610–622 年，穆罕默德的宗教是純粹的傳道：對親族宣講獨一神、末日審判、施捨窮人。結果：親族抵制、信徒被迫害。**對血緣群體傳道，傳播效率極低**——信仰改變不了既有的部落結構。

**線索二：麥地那階段——宗教是「共同體」。** 622 年的遷徙改變了單位：從「說服個人」變成「建構共同體」。《麥地那憲章》（Constitution of Medina，存於後世文獻）載明：穆斯林、猶太部落、多神徒組成一個**烏瑪**（ummah，共同體），共禦外侮、共擔費用的同時——各宗教內部事務自理。關鍵的創新：

$$\text{部落血仇（同態復仇）} \rightarrow \text{烏瑪司法（共同體裁決）}$$

長年血仇是麥地那的治理死結；烏瑪把「以部落為單位的復仇」替換成「以共同體為單位的裁決」。**宗教在這裡不是私人信仰，而是司法與社會的憲法。**

**線索三：五功——信仰被寫進時間表。** 麥地那階段確立的五功，把信仰轉成**可執行的時間表**：

| 五功 | 頻率 | 功能 |
|------|------|------|
| 認（念清真言） | 一次起信 | 宣告 |
| 禮（禮拜） | 每日五次 | 時間上的聖所（呼應拉比猶太教的策略） |
| 課（天課 zakat） | 每年 | 制度化再分配 |
| 齋（齋戒） | 每年一月 | 全社群同步的節制 |
| 朝（朝覲） | 終身一次 | 全社群的地理中心 |

與猶太教把聖所裝進安息日與餐桌（[0070-聖殿被毀與拉比猶太教.md](0070-聖殿被毀與拉比猶太教.md)）同一策略：**聖所綁定時間與實踐**。

**線索四：文本工程（又一樁）。** 啟示以口誦流傳；632 年穆罕默德歸真時已有誦本；約 650 年，第三任哈里發奧斯曼主持**標準化定本**（以防讀法分裂），異本被統一。與巴比倫之囚的 Torah 輯成、拉比時期的《米示拿》成書同屬「聖書宗教」的文本工程譜系。

**線索五：政治與軍事。** 麥地那階段的戰役（白德爾 624 等）塑造了政治性的伊斯蘭；630 年麥加和平收復，克爾白成為一神的聖所。632 年穆罕默德歸真，繼承問題（哈里發）立即浮現——656–661 年的第一次內戰孵化出遜尼與什葉的分野。

## 結案報告

1. **一個世紀的擴張**：632–711 年，伊斯蘭從麥地那擴至大西洋（西班牙）與中亞——史上最快的宗教-政治擴張。引擎不是單純的武力：**烏瑪的共同體模式 + 低稅制（非穆斯林的丁稅相對寬鬆）+ 阿拉伯語的統一行政**，讓征服區快速整合。
2. **政教一體的第四條路**：與西歐的教權/王權雙軌（[0800-查理曼加冕.md](0800-查理曼加冕.md)）、拜占庭的皇帝教宗主義不同——伊斯蘭沒有祭司階層，教法（sharia）即法律，學者（ulama）與統治者分立。三種政教模式的差異，形塑了三大文明圈的憲政基因。
3. **聖書宗教的集大成**：可攜帶的一神（承自猶太教）、末日與審判（承自啟示文學傳統）、共同體憲法（麥地那原創）——伊斯蘭以最精簡的制度（無祭司、無聖禮、無階層）完成了「聖書宗教」的整合。
4. **偵探教訓**：遷徙之所以是元年，因為它標記了宗教單位的躍遷——**從宣告到共同體**。622 年之前，伊斯蘭是一個信息；622 年之後，它是一個憲法。

## 證據與工具

**麥加 vs 麥地那階段的對照（本案的核心偵查）：**

| 項目 | 麥加階段（610–622） | 麥地那階段（622–632） |
|------|---------------------|------------------------|
| 宗教單位 | 個人信仰 | 共同體（烏瑪） |
| 傳播方式 | 對親族傳道 | 建構憲政社群 |
| 結構問題 | 部落秩序 | 血仇→共同體司法 |
| 身份 | 信仰者 | 共同體成員（跨部落） |
| 元年地位 | 啟示之年（非元年） | **遷徙之年（伊斯蘭曆元年）** |

**擴張的時間表：**

| 年份 | 事件 |
|------|------|
| 610 | 希拉山洞啟示 |
| 622 | 遷徙麥地那（Hijra，元年） |
| 624 | 白德爾之戰 |
| 630 | 麥加和平收復 |
| 632 | 穆罕默德歸真；繼承問題 |
| 約 650 | 奧斯曼標準化古蘭經 |
| 656–661 | 第一次內戰（遜尼/什葉分野） |
| 711 | 擴至伊比利半島 |

**結論：** 622 年的遷徙是宗教史上最深刻的一次「單位躍遷」：宗教從私人信仰升級為憲政共同體——血仇被共同體司法取代，信仰被寫進時間表，啟示被寫成標準文本。麥加階段證明了「宣告」的極限，麥地那階段證明了「共同體」的力量——**元年不是啟示開始的地方，而是單位躍遷的地方。**
