# 1771-阿克萊特水力紡紗機

## 案件摘要

1771年，理髮師出身的企業家理查·阿克萊特（Richard Arkwright，1732–1792）在英國德比郡克羅姆福德（Cromford）的德文特河畔建立了世界第一座現代意義的工廠——以他取得專利的水力紡紗機（water frame）為核心，靠水輪驅動數十台紡紗機日夜連續生產棉紗。機器、水力、工人班次、集中管理——「工廠制度」（factory system）就此誕生，工業革命的組織形式在這條小河邊定型。

## 前因 -- 為什麼會有這個案子

- 十八世紀英國棉紡織業需求爆發：棉布輕、可水洗、易染色，但英國自產棉紗遠不及需求，進口印度棉布又遭保護法打壓——紡紗是瓶頸。
- 約翰·凱伊（John Kay）1733年發明飛梭（flying shuttle）加速織布，織快了紡跟不上，「紗荒」加劇——1760年代紡紗成為全英國等待被破解的瓶頸。
- 哈格里夫斯（James Hargraves）的珍妮紡紗機（Spinning Jenny，約1764–65）一人可紡多錠，但紗線脆弱、靠人力，只適合家庭副業。
- 理髮師與假髮製造商出身的阿克萊特在遊歷北部收購頭髮時接觸紡紗技術，與鐘錶匠約翰·凱伊（沃靈頓的 John Kay，非飛梭發明人）合作，於1769年取得水力紡紗機專利，1771年與傑迪代亞·斯特拉特（Jedediah Strutt）等合夥在克羅姆福德建廠。

## 線索與推理 -- 數學式、程式、理論

### 理論一：連續牽伸——滾輪對拉出強韌棉紗

水力紡紗機的核心技術是「連續牽伸」（continuous drafting）：棉條先經三對壓花滾輪，後一對轉速是前一對的數倍，把棉條連續拉細，再由錠翼（flyer）加捻成紗。設三對滾輪線速度 $v_1 < v_2 < v_3$，總牽伸比：

$$D = \frac{v_3}{v_1}$$

牽伸使棉條單位長度纖維量減為 $1/D$，纖維平行排列後加捻（每米捻度 $T$），紗線強度大增——珍妮機靠斷續抽拉紗易斷，水力紡紗機靠連續牽伸 + 機械加捻，能紡出遠比手工強韌的經紗（warp），首次讓英國棉布不再依賴亞麻經線。這是紡織力學的關鍵躍升。

### 理論二：水輪功率——工廠的能源帳

克羅姆福德工廠以大水輪驅動全廠。水輪功率由水量與落差決定：

$$P = \eta\, \rho\, Q\, g\, h$$

取流量 $Q = 0.5$ m³/s、落差 $h = 4$ m、效率 $\eta = 0.5$：

$$P \approx 0.5 \times 1000 \times 0.5 \times 9.8 \times 4 \approx 9.8\ \text{kW} \approx 13\ \text{hp}$$

這約等於百餘名成年工人的人力總和，且日夜不停、不需工資。水力紡紗機每台驅動數十枚紗錠，全廠數十台機器同步運轉——只有集中動力才能養得起這樣的機群，這正是「工廠」存在的物理理由。

### 理論三：工廠制度——分工、班次與規模經濟

阿克萊特的組織革命：把工人集中到機器所在處（而非機器遷就家庭），按鐘錶時間排班（每日約13小時、輪班），童工與女工佔多數，配以嚴格紀律與打卡規則。規模經濟上，總成本隨產量攤薄：

$$AC(n) = \frac{C_{fixed} + c\, n}{n} = \frac{C_{fixed}}{n} + c$$

產量 $n$ 越大，單位成本越低；克羅姆福德廠數百名工人使 $AC$ 遠低於家庭紡戶，棉紗價格隨之崩跌。馬克思後來把水力紡紗機與工廠制度視為「從手工業到機器大工業」的轉折範例。

```python
# 驗證：水輪功率 vs. 人力
rho, Q, g, h, eta = 1000, 0.5, 9.8, 4, 0.5
P = eta * rho * Q * g * h
print(f"水輪功率 {P/1e3:.1f} kW ≈ {P/745.7:.0f} hp")
print(f"約等於 {P/75:.0f} 名人力（每人約75W）")
# 牽伸比與產出
D = 4
print(f"牽伸比 {D}: 棉條細度提升 {D} 倍，再經加捻成強韌經紗")
```

## 破案時刻

1771年克羅姆福德工廠建成運轉：河堤引水入大水輪，天軸與皮帶把動力分配到樓上樓下，數百名工人（多為童工女工）按班次操作紡紗機，棉紗源源不絕且強韌均勻。阿克萊特建立完整的產業鏈：自建工人宿舍、教堂、市集——克羅姆福德從小村變成「公司鎮」。破案後的商業爆發：1775年取得改進專利（梳棉機等全流程機械化），到1780年代他在英國多地建立數座工廠，被稱為「棉紡之王」；1786年受封爵士，1790年引入博爾頓—瓦特蒸汽機替代水力。雖然1785年專利因「發明來源爭議」（高致公聽證認定他並非原發明人）被法院撤銷，但工廠制度已無法逆轉。

## 後果 -- 改變了什麼

- 工廠制度誕生：集中動力、機器群、鐘錶班次、工資勞動、紀律管理——現代工業組織的模板，影響了全世界的製造業乃至管理學。
- 英國棉紗產量暴增、價格崩跌，棉紡織業成為工業革命的領頭產業；曼徹斯特從小鎮變成「棉都」。
- 童工與長工時引發最早的勞工問題與社會批評，催生十九世紀的工廠法（Factory Acts，1802年起）與勞工運動——工業社會的矛盾與其組織形式一同誕生。
- 「水力→蒸汽」的動力演進由此廠示範：1790年後蒸汽驅動的紡紗廠擺脫河流限制，工廠散布全國——阿克萊特的組織 + 瓦特的動力 = 工業革命的完整方程式。
