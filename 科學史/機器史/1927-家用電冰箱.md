# 1927-家用電冰箱

## 案件摘要

1927 年，奇異電器（General Electric, GE）推出「Monitor-Top」——史上第一台大獲成功的家用電冰箱，圓頂般的壓縮機組坐在白色櫃體頂上，外型像監視鐵甲艦（USS Monitor）而得名。在此之前，家庭保存食物靠冰塊箱（icebox）與送冰工人；這樁案件的「兇器」是一組密閉的壓縮冷凍循環：它把食物腐敗的時間軸拉長數倍，殺死了送冰產業，也埋下了氟氯碳化物破壞臭氧層的世紀後遺症。

## 前因 -- 為什麼會有這個案子

- 19 世紀美國家庭用冰塊箱保存食物，冰塊從北方湖泊採收、鋸木屑保溫運送，昂貴且不衛生。
- 機械冷凍早已用於商用（1856 年 James Harrison 的氨壓縮製冷、1876 年 Linde 的氨冷凍機），但氨有毒、易漏，不敢放進廚房。
- 早期家用電冰箱如 1913 年的 Domelre 與 1918 年的 Kelvinator 已出現，但昂貴、零件外露、故障率高。
- 關鍵缺口：一種無毒、不易燃、穩定的冷媒，加上可靠、安靜、可整機密封的壓縮機。

## 線索與推理 -- 數學式、程式、理論

### 理論一：蒸氣壓縮冷凍循環

冰箱的心臟是逆卡諾式的蒸氣壓縮循環，四個過程：壓縮（1→2）、冷凝放熱（2→3）、節流膨脹（3→4）、蒸發吸熱（4→1）。理想循環的製冷係數：

$$COP_{\text{Carnot}} = \frac{T_c}{T_h - T_c}$$

廚房室溫 $T_h = 300\,\mathrm{K}$、冷凍室 $T_c = 255\,\mathrm{K}$ 時，理想 COP 約

$$\frac{255}{300-255} \approx 5.7$$

實際循環因不可逆損失（壓縮效率、換熱溫差、節流損失）COP 約 2–3，僅為卡諾極限的一半以下——這是工程上不斷改進的空間。

### 理論二：實際循環的 COP 與功耗

實際蒸氣壓縮循環中，單位質量製冷量 $q_c = h_1 - h_4$、壓縮功 $w = h_2 - h_1$：

$$COP = \frac{Q_c}{W} = \frac{h_1 - h_4}{h_2 - h_1}$$

Monitor-Top 每日耗電約 1–2 kWh（比同時代競品低約一半），維持冷凍室約 -10°C、冷藏室 4°C。耗電低的原因：全封閉式壓縮機減少冷媒洩漏與摩擦損失，頂置散熱利用煙囪效應自然對流。

### 理論三：冷媒的熱力性質要求

理想冷媒需要：適中的蒸氣壓曲線（蒸發壓略高於大氣、冷凝壓可承受）、高蒸發潛熱 $h_{fg}$、無毒不燃。早期的二氧化硫（SO₂）與氨（NH₃）各有缺陷。1930 年 Thomas Midgley Jr. 在 GE/杜邦體系合成氟氯碳化物 CFC-12（Freon-12），沸點 -29.8°C、完全不可燃、被宣稱無毒——熱力學上近乎完美，卻在半世紀後被證實是臭氧層殺手。

$$\mathrm{CF_2Cl_2 + UV} \rightarrow \mathrm{CF_2Cl \cdot + Cl \cdot}, \qquad \mathrm{Cl \cdot + O_3 \rightarrow ClO \cdot + O_2}$$

一個氯原子可催化破壞約十萬個臭氧分子——這是 1927 年無人能預見的化學後遺症。

### 理論四：熱漏失與保溫設計

冰箱的負載主要來自箱體熱漏失（Fourier 導熱定律）：

$$\dot{Q} = \frac{k A \, \Delta T}{d}$$

軟木與日後聚氨酯發泡隔熱層（$k \approx 0.02\,\mathrm{W/m{\cdot}K}$，僅為空氣的八成）把漏熱壓到最低，門開啟次數反而成為主要耗電變數。

### Python 驗證：卡諾 COP 與耗電估算

```python
Th, Tc = 300.0, 255.0          # 室溫 / 冷凍室 (K)
cop_carnot = Tc / (Th - Tc)
cop_real = 0.45 * cop_carnot   # 實際效率約 45%
print("卡諾 COP =", round(cop_carnot, 2))   # 5.67
print("實際 COP =", round(cop_real, 2))     # 2.55

# 每日移除 5 kWh 等效熱量所需電力
qc = 5.0
print("耗電 =", round(qc/cop_real, 2), "kWh/日")  # ≈ 1.96 kWh
```

## 破案時刻

1927 年，GE 推出 Monitor-Top，首年即售出約 100 萬台（部分統計為至 1930 年累計），售價約 525 美元（相當於當時約半年薪水）。它採用密封式壓縮機（由丹麥工程師 Christian Steenstrup 主導設計）與二氧化硫冷媒，噪音低到「可以在廚房裡聽見時鐘滴答」。到 1940 年代，美國家庭冰箱普及率超過 44%，1950 年代超過 80%——送冰工人徹底成為歷史名詞。

## 後果 -- 改變了什麼

- 食物供應鏈重塑：冷凍食品業（Clarence Birdseye 的 Quick Freeze，1924/1930）隨家用冰箱與冷凍櫃爆發成長。
- 家電耗電成為家庭電費主要項目，推動電網與電價結構的演進。
- Freon-12 的世紀後遺症：1974 年 Molina 與 Rowland 提出 CFC 破壞臭氧層理論（1995 年諾貝爾化學獎），1985 年南極臭氧洞被證實，1987 年《蒙特婁議定書》全面淘汰 CFC，改用 HFC，2016 年《吉加第修正案》再淘汰 HFC。
- 教訓：熱力學上完美的設計，可能藏著地球尺度的化學副作用——工程評估的邊界必須擴張到生態系。
- 冰箱成為「冷鏈」的終端節點，今日疫苗、生鲜與 mRNA 藥品的儲存皆仰賴這條百年技術路線。
