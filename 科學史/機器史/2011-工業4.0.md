# 2011-工業4.0

## 案件摘要

2011年，德國在漢諾威工業博覽會（Hannover Messe）上正式提出「工業 4.0」（Industrie 4.0）概念——由德國聯邦教育及研究部（BMBF）支持的「高技術戰略 2020」計畫推動，核心是讓工廠裡的機器以資訊物理系統（Cyber-Physical Systems, CPS）互聯、互相溝通、自我決策。工業 1.0 是蒸汽機、2.0 是流水線、3.0 是電腦與自動化，4.0 則是「機器自己會說話」的智慧工廠。這樁案子的本質：機器第一次從「被操作」變成「自己協調」。

## 前因 -- 為什麼會有這個案子

- 德國面臨的結構性焦慮：美國有網路巨頭（Google、Amazon）與軟體定義製造，亞洲有低成本量產，德國的優勢（高品質工程設備）需要新的護城河。
- 2000年代末物聯網（IoT）概念成熟：1999年 Kevin Ashton 提出 IoT 一詞，2008年前後 RFID、感測器、IPv6 與雲端計算成本齊降，機器互聯在技術上首次可行。
- CPS 的學術根源：2006年美國 NSF 的 Helen Gill 正式提出 Cyber-Physical Systems 概念，嵌入式系統與控制理論、網路結合。
- 德國工業界（西門子、博世、Festo 等）與學界（如 Kagermann 領導的 acatech 通訊）共同起草「工業 4.0」建議書，2013年漢諾威博覽會正式發表行動方案。

## 線索與推理 -- 數學式、程式、理論

### 理論一：CPS 資訊物理系統——回授控制的網路化

CPS 的核心是控制回授環：感測器量測物理量、網路傳輸、控制器決策、致動器作用。經典控制理論的閉環動態為：

$$\dot{x} = f(x, u), \qquad u = -K(x - x_{ref})$$

其中 $x$ 是系統狀態、$u$ 是控制輸入。工業 4.0 的變化在於：$x$ 不再只在本機迴路流動，而是透過網路傳到雲端與其他機器——但網路引入延遲 $\tau_d$，閉環變成時滯系統：

$$\dot{x}(t) = f\big(x(t - \tau_d),\, u(t - \tau_d)\big)$$

穩定性分析的關鍵：延遲過大會讓回授環震盪失穩，這是「工業以太網（如 PROFINET、TSN）要求毫秒級確定性延遲」的理論根源。

### 理論二：物聯網與預測維護——用機率論取代定期保養

智慧工廠的殺手級應用是預測維護（predictive maintenance）：用振動、溫度感測數據預測機器故障，取代固定的定期保養。設故障服從的風險率 $\lambda(t)$（如韋伯分布），可靠度為：

$$R(t) = \exp\!\left(-\int_0^t \lambda(s)\,ds\right), \qquad \lambda(t) = \frac{k}{\eta}\left(\frac{t}{\eta}\right)^{k-1}$$

維護策略的最佳化是在「保養成本」與「故障停機損失」之間最小化期望成本——當感測數據使 $\lambda(t)$ 的估計越準，越能貼近「壞了才修、壞之前預警」的理想。機器不說話時，$\lambda(t)$ 只能靠統計平均猜測。

### 理論三：數位分身——虛擬空間裡的同步模型

數位分身（digital twin）是物理實體在虛擬空間的即時同步模型：物理機器的每個狀態 $x(t)$ 即時映射到虛擬模型 $\hat{x}(t)$，並用模型做模擬、預測與最佳化。同步誤差的動態可寫成觀測器形式：

$$\dot{\hat{x}} = f(\hat{x}, u) + L\left(y - \hat{y}\right)$$

其中 $L$ 是觀測器增益、$y$ 是物理機器的實際量測——這正是卡爾曼濾波器（Kalman filter, 1960）的工業 4.0 版本。分身越同步，虛擬空間裡的「試車」越能代替實體風險：新製程先在分身上跑，再部署到真機。

```python
import math
# 驗證：韋伯可靠度與預測維護
k, eta = 2.0, 10.0   # 形狀、尺度參數（年）
def lam(t): return (k/eta) * (t/eta)**(k-1)
for t in [2, 5, 8]:
    # R(t) = exp(-(t/eta)^k)
    R = math.exp(-((t/eta)**k))
    print(f"t={t} 年: 故障率 {lam(t):.3f}/年, 可靠度 {R:.2f}")
print("故障率隨時間上升 → 老機器需要更密監測（預測維護的根據）")
```

## 破案時刻

2011年漢諾威工業博覽會上，「工業 4.0」一詞首次公開亮相；2013年德國正式發表建議書並啟動公私合作平台（Plattform Industrie 4.0）。西門子在安貝格（Amberg）電子工廠展示智慧工廠示範線：產品「告訴」機器自己需要什麼加工，不良率降到百萬分之十以下。破案的關鍵：德國把 CPS、IoT、智慧工廠三個概念縫合成國家戰略，工業 4.0 從行銷詞變成全球製造業的技術路線圖。

## 後果 -- 改造了什麼

- 工業 4.0 成為全球製造業的共同語言：美國的「工業網路聯盟」（IIC, 2014）、中國的「中國製造 2025」、日本的「社會 5.0」全部與之對話競合。
- 智慧工廠與預測維護落地：設備異常預警、良率最佳化、彈性生產（同線不同產品混線）成為先進工廠標配。
- 數位分身從概念變成商業產品：西門子 Xcelerator、達梭 3DEXPERIENCE、GE Predix——CAD/CAM 時代種下的數位原型樹，在 CPS 時代結成分身之果。
- 反面教訓：IT 與 OT（營運技術）融合帶來全新的網路攻擊面——2010年震網（Stuxnet）病毒攻擊離心機已預警，工業 4.0 的機器互聯同時打開了工業資安的戰場。
