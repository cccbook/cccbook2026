# 2020s-人形機器人

## 案件摘要

2020年代，人形機器人（humanoid robot）從實驗室影片走進產業視野：波士頓動力（Boston Dynamics）的 Atlas 展示跑酷與後空翻，2024年該公司宣布電動版新 Atlas 取代液壓版；特斯拉的 Optimus（2021年 AI Day 公布、2024年量產計畫啟動）；Figure（2022年成立）的 Figure 01/02 進入寶馬（BMW）工廠試用。這些機器的共同點：以雙足行走、雙手操作，訓練方式從手寫控制器轉向強化學習與模仿學習。這樁案子的本質：機器第一次以「通用形體」瞄準人類的所有工作。

## 前因 -- 為什麼會有這個案子

- 雙足機器人學術血脈：1969年早稻田大學加藤一郎的 WAP 系列雙足機器人、1972年 WL-5；本田1996年 P2、2000年 ASIMO 展示穩定雙足行走，但以 ZMP 控制器手寫步態，動作僵硬。
- 2013年波士頓動力 Atlas（DARPA 機器人挑戰賽用）、2016年後液壓 Atlas 連續展示後空翻（2017）與跑酷（2021）——硬體能力已遠超軟體。
- 2020年代轉折：深度強化學習（PPO 等演算法，2017）與大規模 GPU 模擬使「模擬中訓練步態」成為可能；2022年 UC Berkeley 與 Google 的 A1 電動四足以 RL 學會奔跑，sim-to-real 成為主流。
- 產業動機：勞動力短缺與製造業回流，通用形體機器人被視為「不需要為每個任務造一台專用機器」的終極答案。

## 線索與推理 -- 數學式、程式、理論

### 理論一：ZMP 零力矩點——雙足平衡的經典理論

雙足行走的核心問題是動態平衡。南斯拉夫學者 Vukobratović 於1969年提出零力矩點（Zero Moment Point, ZMP）：地面反力的合力作用點，且力矩的水平和分量為零。設總質量 $m$、質心高度 $z_c$、質心加速度 $(\ddot{x}_c, \ddot{y}_c)$，ZMP 位置為：

$$x_{ZMP} = x_c - \frac{z_c\,\ddot{x}_c}{g + \ddot{z}_c}, \qquad y_{ZMP} = y_c - \frac{z_c\,\ddot{y}_c}{g + \ddot{z}_c}$$

不倒的條件：ZMP 必須落在腳掌的支撐多邊形（support polygon）內。傳統 ASIMO 式步態用 ZMP 軌跡預瞄控制（preview control）規劃質心擺動——穩定但僵硬，因為它把行走簡化成線性倒單擺的軌跡跟隨。

### 理論二：強化學習——用獎勵函數取代手寫控制器

2020年代的步態控制轉向強化學習：策略 $\pi_\theta(a \mid s)$（通常是神經網路）在馬爾可夫決策過程（MDP）中最大化期望回報：

$$\max_\theta\; \mathbb{E}\left[\sum_t \gamma^t r(s_t, a_t)\right], \qquad r = w_{vel} r_{vel} - w_{energy} \|a\|^2 - w_{fall} \mathbb{1}[\text{fall}] + \ldots$$

以 PPO（proximal policy optimization, 2017）等演算法在 GPU 大規模平行模擬中訓練數千個機器人同時學習，數小時內等效於數十年的真實經驗。獎勵函數取代工程師的手：工程師不再寫「膝蓋怎麼彎」，只寫「要走得快、省電、別摔」，讓策略自己找出答案——結果常出現人類想不到的步態。

### 理論三：Sim-to-Real——域隨機化與模仿學習

模擬訓練的策略要遷移到真機，瓶頸是模擬與現實的差距（reality gap）。主流解法是域隨機化（domain randomization）：訓練時隨機化質量、摩擦、延遲等參數 $\xi \sim p(\xi)$：

$$\max_\theta\; \mathbb{E}_{\xi \sim p(\xi)}\left[\sum_t \gamma^t r(s_t, a_t; \xi)\right]$$

使策略對參數不敏感，真機上的差距落回訓練分布之內。模仿學習（imitation learning）則提供另一條路：遙操作人類示範的數據 $(s_t, a_t^*)$，以行為克隆損失訓練策略：

$$\mathcal{L}(\theta) = \mathbb{E}\left[\|\pi_\theta(s_t) - a_t^*\|^2\right]$$

Figure 與特斯拉 Optimus 都以遙操作示範 + 模仿學習訓練雙手操作——人類的技能第一次被「抄進」機器。

```python
import numpy as np
# 驗證：線性倒單擺模型的 ZMP 條件
m, zc, g = 80.0, 0.9, 9.81     # 質量、質心高度、重力
foot_half = 0.12                # 腳掌半長（m）
for xdd in [-2, 0, 2]:          # 質心加速度
    xmp = xdd * zc / g          # 相對質心的 ZMP 偏移
    ok = "穩定" if abs(xmp) <= foot_half else "會倒"
    print(f"加速 {xdd:+.0f} m/s^2 → ZMP 偏移 {xmp:+.3f} m, {ok}")
```

## 破案時刻

2023–24年，AI 訓練的雙足步態密集破案：波士頓動力宣布電動新 Atlas（2024年4月）展示超出人類柔性的動作；Optimus Gen 2（2023年12月）展示穩定行走與雙手靈巧操作；Figure 01 接入 OpenAI 大型語言模型（2024年3月）對答如流並完成咖啡端送任務。破案的關鍵：強化學習解決了「走路」，模仿學習解決了「動手」，大語言模型解決了「聽懂人話」——三項技術在 2020 年代中期同時成熟，縫合成人形機器人的完整能力棧。

## 後果 -- 改造了什麼

- 人形機器人從 demo 進入工廠試點：Figure 在 BMW、Optimus 在特斯拉工廠執行搬運與分揀，「通用機器人」的商業驗證開始。
- 訓練範式的典範轉移：從手寫控制器（ZMP、預瞄控制）到 RL + 模仿學習，學界與業界的步態論文幾乎全部轉向學習式方法。
- 產業競賽白熱化：波士頓動力、特斯拉、Figure、Unitree、Agility Robotics（Digit）等數十家投入，人形機器人被預測為下一個兆元級產業。
- 通用機器人的願景與爭議：支持者認為「人類形體 = 人類環境的萬能鑰匙」，質疑者指出專用機器（輪式、機械臂）在多數任務上更簡單便宜——這場「形體之爭」是 2020 年代機器史的進行式懸案。
