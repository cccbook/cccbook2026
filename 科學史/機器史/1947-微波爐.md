# 1947-微波爐

## 案件摘要

1947 年，美國 Raytheon 公司推出「Radarange」——史上第一台商用微波爐。這樁案件的起點是一根融化的巧克力棒：1945 年，Raytheon 工程師 Percy Spencer 站在雷達磁控管（magnetron）旁，發現口袋裡的巧克力融了。他隨後用玉米粒爆出爆米花、用雞蛋炸開實驗室。這樁案件的「兇器」是一台戰爭機器的副產品：把雷達的心臟轉向廚房，用 2.45 GHz 的電磁波直接加熱水分子——從雷達到廚房，只隔著一根融化的巧克力。

## 前因 -- 為什麼會有這個案子

- 二戰期間 Raytheon 為盟軍大量生產雷達磁控管（British cavity magnetron 的美國量產版），戰後軍用訂單驟減，公司急尋民用轉型。
- 介電加熱（dielectric heating）現象 1930 年代已知（高頻電場加熱介電材料），但沒有人想到拿來煮食物。
- Percy Spencer 自學成才（未完成小學學業）、Raytheon 資深工程師，磁控管量產的關鍵人物。
- 戰後冷凍食品興起，「快速加熱冷凍食物」正是剛出現的需求缺口。

## 線索與推理 -- 數學式、程式、理論

### 理論一：水分子偶極加熱（Dipole Heating）

水分子是永久偶極子（電負性差使電荷分離），在 2.45 GHz 高頻電場中不停翻轉：

$$\theta(t) \sim \cos(\omega t), \qquad f = 2.45\,\mathrm{GHz}$$

翻轉過程受到相鄰分子的黏性阻滯，電場能量轉為分子動能（熱）。每單位體積的介電損耗功率：

$$P = 2\pi f \, \varepsilon_0 \, \varepsilon_r'' \, E^2$$

其中 $\varepsilon_r''$ 是水的相對介電損耗因子。功率與頻率、電場強度平方成正比——這就是為什麼微波爐用高頻高場強，而不是低頻市電。

### 理論二：為什麼是 2.45 GHz？

2.45 GHz 是工程折衷：若頻率太低（如 1 GHz），偶極翻轉太「跟得上」電場、損耗反而小；若太高（>10 GHz），波長太短、穿透深度不足。穿透深度：

$$d_p = \frac{\lambda}{2\pi \sqrt{2\varepsilon_r''}} \left[\sqrt{1 + (\varepsilon_r/\varepsilon_r'')^2} - 1\right]^{-1/2} \approx 1\text{–}2\,\mathrm{cm} \text{（水）}$$

波長 $\lambda = c/f \approx 12.2\,\mathrm{cm}$，剛好能穿透食物數公分深度、又被水有效吸收。加上 2.45 GHz 位於 ISM（工業/科學/醫療）頻段，不受通訊干擾管制——這是國際電信聯盟劃定的「免執照頻段」。

### 理論三：熱傳導與加熱不均

微波爐內以駐波模式分布能量，波腹與波節相距 $\lambda/2 \approx 6\,\mathrm{cm}$，造成冷熱不均。旋轉轉盤讓食物掃過波腹；熱在食物內部仍靠傅里葉傳導擴散：

$$\frac{\partial T}{\partial t} = \alpha \nabla^2 T + \frac{P_{\text{微波}}}{\rho c_p}, \qquad \alpha = \frac{k}{\rho c_p}$$

這解釋了「外燙內冷」：微波只穿透 1–2 cm，中心靠熱傳導慢慢升溫。

### 理論四：磁控管——從雷達借來的心臟

磁控管用正交的電場與磁場使電子做輪擺線運動（cycloid），在共振腔中激發微波：

$$\omega_c = \frac{eB}{m_e} \text{（迴旋頻率）}, \qquad \eta_{\text{磁控管}} \approx 50\text{–}70\%$$

家用微波爐磁控管輸出約 700–1,000 W，效率過半、結構簡單便宜——這是雷達技術「軍轉民」的關鍵：戰時量產壓低成本，戰後直接搬進廚房。

### Python 驗證：波長與介電加熱功率

```python
c, eps0 = 3e8, 8.854e-12
f = 2.45e9
lam = c / f
print(f"波長 λ = {lam*100:.1f} cm")          # 12.2 cm

eps_r2 = 10.0       # 水在 2.45GHz 的相對介電損耗（約略值）
E = 5e4             # 有效電場 V/m
P = 2*3.14159*f*eps0*eps_r2*E**2
print(f"單位體積加熱功率 ≈ {P/1e6:.1f} MW/m³")   # 約 3.4 MW/m³

# 波腹間距
print(f"駐波波腹間距 λ/2 = {lam/2*100:.1f} cm")   # 6.1 cm
```

## 破案時刻

1945 年 10 月 8 日，Percy Spencer 提出微波烹飪專利（US 2,495,429，1947/1950 年核發）；他先以金屬盒加開口做出實驗原型，成功爆出爆米花。1947 年 Raytheon 推出「Radarange」：高 1.8 公尺、重 340 公斤、售價約 5,000 美元、水冷式磁控管——只有餐廳與船舶用得起。1967 年，Raytheon 旗下 Amana 推出第一台平價家用檯面型 Radarange（售價約 495 美元），微波爐從此飛入尋常廚房；1980 年代美國家庭普及率過半，今日超過九成。

## 後果 -- 改變了什麼

- 冷凍食品、即食餐與預製菜供應鏈全面爆發，微波爐成為冷鏈的「終端解凍器」。
- 磁控管成為家電標準元件，2.45 GHz 的 ISM 頻段日後更孕育了 Wi-Fi（802.11, 2.4 GHz 頻段）與藍牙——微波爐的干擾至今仍是 Wi-Fi 掉速的經典原因。
- Raytheon 的軍轉民轉型成為後世國防承包商（如二戰後諸多電子公司）的範本；Raytheon 日後再以戰術飛彈聞名。
- 介電加熱技術外溢到工業（木材乾燥、橡膠硫化、醫療腫瘤熱療）。
- 安全規範：1971 年起美國 FDA 對微波爐洩漏設限（5 mW/cm² @ 5 cm），金屬不能進爐（反射微波打火）、帶殼蛋會炸——偶極加熱的物理邊界寫進了每一台爐的說明書。
- 教訓：戰爭機器的副產品（雷達→微波爐、核子→核能、網路→網際網路）是 20 世紀技術史的反覆劇本。
