# 1866-西門子自激發電機

## 案件摘要

1866 年，德國發明家兼企業家維爾納・馮・西門子（Werner von Siemens, 1816–1892）發現發電機可以「自激」（self-excitation）：用自身發出的電流供應自己的電磁鐵，拋棄昂貴的外部永磁體或獨立激磁電源。1867 年 1 月，他在柏林科學院宣讀論文《論不用永磁體把功轉為電流》（Über die Umwandlung von Arbeitskraft in elektrischen Strom ohne permanente Magnete），同年布魯塞爾的格拉姆（Zénobe Gramme）也獨立造出實用的自激環形電樞發電機。強電力工業供電的大門就此打開。

## 前因 -- 為什麼會有這個案子

- 法拉第 1831 年的電磁感應打通了「機械能轉電能」的通路，但早期發電機用永磁體（permanent magnets）產生磁場：永磁體磁場弱、易退磁、又重又貴，發電機輸出功率被卡在幾百瓦量級，只夠點弧光燈做示範。
- 1860 年代電鍍工業（electroplating）與弧光燈（arc lighting）開始需要較大電流，昂貴的伏打電池與永磁發電機都不堪供應。
- 工程師們已發現線索：1850 年代惠茨通（Wheatstone）與庫克（Cooke）專利中提出用電流供應電磁鐵的構想；丹麥的希約爾德（Søren Hjorth, 1854 專利）、義大利的帕奇諾蒂（Antonio Pacinotti, 1860 環形電樞）也各自逼近自激概念，但都未造成實用的自力持續運轉機器。
- 西門子是普魯士砲兵軍官出身的工程師，1847 年創辦西門子與哈爾斯克（Siemens & Halske），長年做電報工程——他清楚知道，電報的未來、乃至整個電力工業的未來，都卡在「廉價大電流」這一關。

## 線索與推理 -- 數學式、程式、理論

### 線索一：剩磁自激原理 -- 雞生蛋的正解

發電機的感應電動勢 $E = k\,\Phi\,\omega$，其中 $\Phi$ 是磁通量、$\omega$ 是轉速。若磁場由自身的電樞電流供應（串激接法），則 $\Phi \propto I$，看似「沒有磁場就沒有電流、沒有電流就沒有磁場」的死結。解開死結的關鍵是剩磁（residual magnetism）：電磁鐵鐵芯在斷電後仍保留微弱剩磁 $\Phi_0$。自激的迭代過程為：

$$I_{n+1} = \frac{k\,\Phi_n\,\omega}{R_{total}}, \qquad \Phi_{n+1} = \Phi_0 + a\, I_{n+1}$$

只要迴路增益 $k a \omega / R_{total} > 1$，電流逐圈放大、磁場逐圈增強，直到磁路飽和（saturation）收斂於穩定工作點——一台完全靠自己站起來的發電機。剩磁是點火的那顆火星，正回饋是燃燒的柴堆。

### 線索二：磁路飽和與穩定工作點

自激發電機不會無限放大，因為鐵芯磁化曲線（B-H curve）會飽和：磁通量 $\Phi(I)$ 先線性後趨平。穩定工作點是兩條曲線的交點——感應電動勢線 $E = k\Phi\omega$（經歐姆定律映射）與磁化曲線 $\Phi(I)$ 的交點：

$$I^* = \frac{k\,\Phi(I^*)\,\omega}{R_{total}}$$

交點存在且穩定的條件是初始斜率大於負載線斜率，否則自激失敗。這解釋了為什麼自激對轉速、電路電阻與接法（串激、並激、複激）敏感——日後發電機的並激（shunt）、複激（compound）設計，都是對這條非線性曲線的工程馴服。

### 線索三：輸出功率的跳升與工業意義

永磁發電機磁通量被永磁體卡死，而電磁鐵可以透過增大激磁電流與鐵芯截面積把 $\Phi$ 推高數十倍。發電機輸出功率為：

$$P = E \cdot I = k\,\Phi\,\omega \cdot I$$

自激使 $\Phi$ 可控可增，輸出功率從永磁機的數百瓦跳升到千瓦乃至數萬瓦量級——第一次足以供應工業負載（電鍍、弧光燈、電解）。格拉姆 1870 年代的環形電樞發電機（借鑑帕奇諾蒂 1860 年的設計）輸出達千瓦級，成為第一台商業成功的工業發電機；愛迪生 1882 年的珍珠街電站（Pearl Street Station）用巨型直流發電機點亮紐約華爾街，工業供電正式登場。

用 Python 模擬剩磁自激的迭代放大：

```python
k, a, omega = 0.02, 50.0, 30.0   # 發電機常數、磁化係數、轉速
R_total, Phi_sat = 1.0, 0.05     # 總電阻、磁路飽和上限
Phi = 0.0005                      # 剩磁
for n in range(8):
    I = k * Phi * omega / R_total
    Phi = min(Phi_sat, 0.0005 + a * I)  # 鐵芯飽和
    print(f"第 {n+1} 圈: I = {I:8.3f} A, Φ = {Phi:.4f} Wb")
print("輸出功率 P = %.1f W" % (k * Phi * omega * I))
```

## 破案時刻

1866 年秋冬，西門子在柏林的實驗中讓一台串激發電機靠自身電流激磁、穩定輸出電流；1867 年 1 月 17 日，他向柏林科學院宣讀論文，宣告「機械功可以不用永磁體轉為電流」。同年，比利時工程師格拉姆在巴黎製成自激環形電樞發電機並於 1870 年獲得專利，商業化遠比西門子成功。兩人互相致意、互認獨立發現——這樁案子由兩位偵探共同結案，而格拉姆把結案書變成了商品。

## 後果 -- 改變了什麼

- **強電力工業誕生**：自激發電機把電力從實驗室的奇觀變成工業的動力源，電鍍、電解、弧光照明率先受益。
- **發電機設計範式確立**：環形電樞（格拉姆/帕奇諾蒂）＋電磁場激磁＋自激啟動，成為此後數十年直流發電機的基本公式；並激、複激接法隨後定型。
- **電力公司的崛起**：西門子與哈爾斯克、格拉姆公司（後併入）、湯姆森-休斯頓、愛迪生通用電氣——1880 年代的電力工業巨頭都以自激發電機為產品核心。
- **直流到交流的伏筆**：自激解決了「電源夠不夠大」，下一個懸案是「電送得夠不夠遠」——1880 年代特斯拉與威斯汀豪斯的交流電之爭，寫在 1866 年這篇論文的延長線上。
