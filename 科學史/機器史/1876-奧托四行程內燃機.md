# 1876-奧托四行程內燃機

## 案件摘要

1876 年，德國工程師尼古勞斯・奧托（Nikolaus Otto, 1832–1891）在科隆（Köln）近郊的德伊茨（Deutz）造出世界第一台實用的四行程內燃機（four-stroke engine）：進氣、壓縮、動力（點火膨脹）、排氣，四個行程構成一個完整循環。這台「奧托循環」引擎熱效率約 14%，是當時任何內燃機的三倍以上，十年內賣出數萬台——車輛與飛機的動力，在這一年定案。

## 前因 -- 為什麼會有這個案子

- 19 世紀中葉的固定動力全靠蒸汽機：笨重、需鍋爐與鍋爐工、升火要數小時，小型工場與移動式負載根本用不起。
- 內燃機的嘗試屢屢失敗：1860 年雷諾阿（Étienne Lenoir）的煤氣機直接在常壓下點火（無壓縮行程），熱效率只有約 4%，功率低、耗氣大。
- 法國工程師博・德・羅沙（Alphonse Beau de Rochas）1862 年在理論上提出四行程循環的構想（進氣、壓縮、點火、排氣），但從未造出實用機器——理論先行，實作懸而未決。
- 奧托原本是科隆的雜貨推銷員，1861 年起自費研究煤氣機，1864 年與尤根（Eugen Langen）合創公司（後成為 Deutz 的 Gasmotoren-Fabrik Deutz），1872 年延攬了戴姆勒（Gottlieb Daimler）與邁巴赫（Wilhelm Maybach）——本案的兩位關鍵配角已經入場。
- 懸案明確：如何讓燃料混合氣先受壓縮、再定時點火、穩定輸出比蒸汽機更高的效率？這是雷諾阿機留下、博・德・羅沙理論化、卻無人能實作的最後一塊拼圖。
- 1875 年前後，奧托經過長年摸索，放棄了雷諾阿式「直接常壓點火」的路線，轉向「先壓縮、後點火」——並想出了用自由活塞預壓裝置解決點火可靠性的工程細節。

## 線索與推理 -- 數學式、程式、理論

### 線索一：壓縮才有效率 -- 理想奧托循環

雷諾阿機失敗的根源是不壓縮：燃料混合氣在常壓下點火，膨脹比小、做功少。奧托循環的理論熱效率只由壓縮比 $r = V_1/V_2$ 決定（理想空氣標準循環）：

$$\eta_{th} = 1 - \frac{1}{r^{\gamma - 1}} = 1 - r^{1-\gamma}, \qquad \gamma = \frac{c_p}{c_v} \approx 1.4\ (\text{空氣，等熵指數})$$

壓縮比 $r$ 越大效率越高：$r = 2.5$ 時 $\eta \approx 30\%$（理論值），扣除實際損耗後奧托機的實測效率約 14%——已是雷諾阿機的三倍以上。這條公式揭示了「壓縮比是內燃機的靈魂」，也預告了後世的永恆難題：爆震（knock，末端混合氣自燃）限制壓縮比的上限，1920 年代的含鉛汽油與辛烷值（octane rating）正是為此而生。

### 線索二：四行程的循環幾何 -- 一個循環兩圈軸

四行程循環把功率產生拆成四段曲軸運動（720° 一個循環）：進氣行程吸入混合氣、壓縮行程絕熱壓縮、動力行程點火絕熱膨脹做功、排氣行程排廢。理想循環各段做功為：

$$W_{net} = \oint p\,dV = W_{ignition\ expansion} - W_{compression}$$

只有動力行程做功，因此飛輪必須儲存 $\tfrac{1}{2}I\omega^2$ 的動能量度過三個不做功的行程。奧托的關鍵工程貢獻是「分層充氣」（stratified charge）式的自由活塞壓縮裝置：先在小型汽缸中預壓混合氣，使壓縮行程末期點火可靠——這讓稀薄混合氣也能穩定燃燒，效率與運轉平順兼得。

### 線索三：定容燃燒與燃料消耗

奧托循環是定容加熱循環（constant-volume cycle）：點火燃燒在活塞接近上死點、容積幾乎不變的瞬間完成，壓力瞬間躍升。每小時每馬力的煤氣消耗量（具體的競賽指標）從雷諾阿機的約 100 立方英尺降到奧托機的約 27 立方英尺——降幅近四倍。點火方式是另一條線索：早期用開放火焰與滑動口的間歇點火，日後才由磁電機點火（戴姆勒/邁巴赫的貢獻）取代——但 1876 年的原型已證明，可靠且省氣的間歇燃燒循環是可能的。

用 Python 驗證壓縮比與理論熱效率：

```python
gamma = 1.4
for r in [1.0, 2.5, 4.0, 6.0, 8.0, 10.0]:
    eta = 1 - r**(1-gamma)
    print(f"壓縮比 r = {r:4.1f} -> 理論熱效率 η = {eta*100:5.1f}%")
# r=1（雷諾阿式不壓縮）效率為零；r 越大效率越高，但受爆震限制
```

## 破案時刻

1876 年，奧托在德伊茨工廠造出第一台實用的四行程臥式煤氣機；1877 年獲得德國專利（DRP 532）。1878 年巴黎世界博覽會的公開測試證實其效率宣稱，訂單如雪片飛來；到 1890 年，Deutz 的引擎銷量已超過數萬台，全球工場（從磨坊到礦場）都裝上了奧托機。1886 年專利糾紛中德國法庭裁定四行程原理屬「公知技術」、專利失效，但 Deutz 的市場地位已無可撼動。1891 年奧托去世於科隆；他創辦的 Deutz 工廠至今仍是發動機製造商。

## 後果 -- 改變了什麼

- **車輛動力的誕生**：1885–1886 年，戴姆勒與邁巴赫造出高速汽油引擎（約 600–900 rpm）與世界第一輛四輪汽車；卡爾・賓士（Karl Benz）同期造出三輪汽車（1886 年專利）。四行程汽油機從此成為汽車的標準心臟。
- **航空的遠祖**：1903 年萊特兄弟的飛行者一號，用的正是自製的四行程汽油引擎——奧托循環載著人類離開地面。
- **大規模生產的模式**：Deutz 以標準化、可複製的工廠量產引擎（1870 年代末年產數百台，1890 年代上千台），是內燃機從手工製品走向工業量產的第一例。
- **熱力學的工程勝利**：壓縮比–效率公式成為內燃機設計的第一定律；1890 年代狄塞爾（Rudolf Diesel）追求更高壓縮比，1897 年造出壓燃式柴油機——本案的結案書直接催生了下一樁大案。
- **蒸汽機退位**：輕、快、隨開隨用的內燃機逐步取代蒸汽機成為車輛與小型動力的霸主，20 世紀的機動化社會由此起步。
- **產業與人才外溢**：戴姆勒 1890 年離開 Deutz 自立 Daimler-Motoren-Gesellschaft，奧托培育的工程師網絡讓德國在 20 世紀初成為世界內燃機與汽車工業的中心——科隆一家工場，寫下了此後一個世紀引擎設計的出發點。
- **燃料的接力**：煤氣機之後，汽油（1880 年代）、柴油（1897 年）先後登場；奧托確立的「壓縮–點火」框架成為所有後繼燃料引擎的共同文法。
