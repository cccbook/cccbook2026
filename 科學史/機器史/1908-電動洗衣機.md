# 1908-電動洗衣機

## 案件摘要

1908 年前後，美國芝加哥的 Hurley 洗衣機公司（Hurley Machine Company）推出了「Thor」——史上第一台商用電動洗衣機，由 Alva J. Fisher 設計並於 1910 年取得專利。在此之前，洗衣是純手工勞動：搓衣板、洗衣板加煮水大鍋，一桶衣物要耗上大半天。這樁案件的「兇器」不是別的，正是一顆小小的電動馬達——它把女性從每週數十小時的家務苦役中解放出來，也揭開了家電革命的序幕。

## 前因 -- 為什麼會有這個案子

- 19 世紀末美國都市化加速，中產家庭衣物量增加，但自来水與電網正在普及。
- 早期已有手搖式洗衣機（如 1851 年 James King 的鼓式手搖洗衣機），但動力仍靠人力。
- 水力、蒸汽驅動的洗衣機曾出現在商用洗衣房，但體積龐大，無法進入家庭。
- 電動馬達小型化、便宜化之後，「把馬達裝進洗衣機」成為顯而易見卻遲遲未被解決的工程課題：馬達轉速快、洗衣攪拌需要慢而有力的往復運動。

## 線索與推理 -- 數學式、程式、理論

### 理論一：馬達功率與洗衣負載的匹配

洗 $m$ 公斤濕衣物、攪拌葉半徑 $r$，衣物攪動的黏性阻力可粗估為

$$P = \tau \omega \approx C \mu \, \frac{v^2}{d} \, A \, v = C' \mu A \frac{(r\omega)^3}{d}$$

其中 $\mu$ 為水與皂液的黏度、$A$ 為攪拌葉面積、$d$ 為特徵尺度。攪拌速度 $\omega$ 過高則功率需求以三次方暴增，這解釋了為何 Thor 採用低速攪拌而非高速旋轉。

### 理論二：齒輪減速與往復機構

早期電動馬達額定轉速約 1,500–1,800 rpm，而攪拌需要每分鐘約 60–90 次的往復擺動。減速比 $i$ 滿足

$$i = \frac{\omega_{\text{馬達}}}{\omega_{\text{攪拌}}} \approx \frac{1500}{70} \approx 20$$

Thor 用皮帶與齒輪組實現減速，再以曲柄連桿（crank-and-linkage）把旋轉運動轉成 agitator 的往復運動——這正是後世「攪拌式」洗衣機的祖先。

### 理論三：雷諾數與攪拌效果

水流是否能有效帶動衣物翻滾，取決於雷諾數

$$Re = \frac{\rho v L}{\mu}$$

$Re$ 遠大於 1,000 時水流呈充分紊流，皂液才能滲入纖維。攪拌式設計用大面積慢速擺動在低功率下仍可達成高 $Re$，是效率上的巧妙折衷。

### Python 驗證：減速比與功率估算

```python
import math

# 馬達 1500 rpm，攪拌往復 70 次/分
motor_rpm, agitator_cpm = 1500, 70
print("減速比 ≈", round(motor_rpm / agitator_cpm, 1))  # ≈ 21.4

# 功率隨轉速三次方成長（相對值）
w1, w2 = 1.0, 2.0
print("轉速加倍 → 功率變為", round((w2/w1)**3, 1), "倍")  # 8 倍

# 雷諾數：水 rho=1000, mu=0.001 Pa.s，v=0.5 m/s，L=0.3 m
rho, mu, v, L = 1000, 0.001, 0.5, 0.3
print("Re =", int(rho*v*L/mu))  # 150000，充分紊流
```

## 破案時刻

1910 年，Alva J. Fisher 獲得美國專利（US Patent 966,677），專利文件中稱該機為「electric washing machine」。Thor 由一組電動馬達、木製桶身與攪拌葉構成，雖然還沒有脫水功能（扭乾仍靠手動絞乾器），但「動力洗衣」的概念正式落地。此後 Bendix（1937 年推出全自動前開式滾筒機）與 General Electric 陸續接力，1940 年代美國約有六成家庭擁有洗衣機，電動洗衣機從奢侈品變成標準配備。

## 後果 -- 改變了什麼

- 家務勞動時間大幅縮短：歷史學者估計每週洗衣時間從 20 小時以上降至 2 小時以內，是女性進入勞動市場的重要推力之一。
- 確立了「攪拌式（agitator）」與「滾筒式（drum）」兩大技術路線，至今仍是美式與歐式洗衣機的分野。
- 帶動家用電器產業鏈：馬達、齒輪、皮帶、電容器與定時器的標準化量產。
- 與電冰箱、吸塵器並列「家電三寶」，象徵 20 世紀家庭自動化的開端。
- 後續副作用：洗衣廢水與磷系清潔劑造成河川優養化，1970 年代起各國開始管制。
