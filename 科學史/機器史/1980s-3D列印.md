# 1980s-3D列印

## 案件摘要

1984年，美國加州的查克·哈爾（Chuck Hull）發明立體光固化（Stereolithography, SLA）技術，並於1986年獲得美國專利（US 4,575,330），同年創立 3D Systems 公司，推出第一台商用 3D 列印機 SLA-1。這台機器用紫外光一層一層固化液態樹脂，把電腦裡的 3D 模型直接「長」成實物——人類第一次讓機器以「層積製造」（additive manufacturing）的方式憑空造物，而不是從整塊材料切削減去。這樁案子的本質：製造的哲學從「減法」翻轉成「加法」。

## 前因 -- 為什麼會有這個案子

- 1970–80年代 CAD 普及，3D 模型存在電腦裡卻變不成實體：從設計到原型（prototype）仍要數週的機械加工與手工樣板。
- 傳統原型製造是「減法」：車、銑、鑽從整塊材料去除多餘部分，材料浪費大、複雜內腔幾乎做不出來。
- Hull 當時在一家生產紫外固化樹脂塗層的公司（UVP）工作，想到：既然光能逐點固化樹脂，就能逐層固化整個物體。
- 同時期其他路線並行：1980年代日本的 Hideo Kodama 發表光固化研究論文、1988年 Scott Crump 發明熔融沉積成型（FDM，1989年專利、創立 Stratasys）、選擇性雷射燒結（SLS）由 UT Austin 的 Carl Deckard 於1987年左右申請專利。

## 線索與推理 -- 數學式、程式、理論

### 理論一：光固化化學——劑量決定固化深度

紫外光照射光敏樹脂時，光引發劑分解產生自由基，使單體聚合成固體。固化深度由光的劑量與樹脂的臨界能量決定（Jacobs 方程）：

$$C_d = D_p \ln\!\left(\frac{E}{E_c}\right)$$

其中 $C_d$ 是固化深度、$D_p$ 是穿透深度（樹脂特性常數）、$E$ 是曝光能量密度、$E_c$ 是臨界膠化能量。曝光不足則固化太淺、層與層黏不住；過曝則精度變差——每一層都必須控制在這個對數關係的甜蜜點上。

### 理論二：切片（slicing）演算法——3D 到 2D 的離散化

3D 列印把實體 $V \subset \mathbb{R}^3$ 沿 $z$ 軸以層厚 $\Delta z$ 離散化，每一層 $z_k$ 取實體與水平面的截面輪廓：

$$S_k = \{(x, y) \mid (x, y, z_k) \in V\}$$

每一層的截面輪廓轉成掃描路徑，逐層堆疊。理論誤差為階梯效應（stair-stepping）：表面斜率為 $\theta$ 時，理論表面偏差約為

$$\varepsilon \approx \frac{\Delta z}{2}\,\sin\theta$$

層厚越薄越精細，但列印時間成正比拉長——這是所有層積製造的基本取捨。

### 理論三：STL 格式——用三角形網格近似實體

Hull 同時發明 STL 檔案格式：用大量三角面片近似實體表面，每個三角形由三個頂點與法向量定義。$n$ 個三角形逼近曲面時的表面誤差隨細分下降——理論上，曲率半徑為 $R$ 的表面以弦高誤差 $\delta$ 細分，三角形邊長約為

$$l \approx 2\sqrt{2R\delta - \delta^2}$$

誤差要求越小（$\delta \to 0$），三角形數量 $n \propto 1/\delta$ 爆炸成長。STL 簡陋（無單位、無拓撲驗證）卻成為事實標準三十年，正因為它「夠用且簡單」。

```python
import math
# 驗證：Jacobs 固化深度方程與階梯效應
Dp, Ec = 0.15, 5.0   # mm, mJ/cm^2（典型 SLA 樹脂）
for E in [10, 15, 20]:
    Cd = Dp * math.log(E / Ec)
    print(f"曝光 {E} mJ/cm^2 → 固化深度 {Cd:.2f} mm")

# 階梯效應：層厚 0.1mm、表面傾斜 45 度
dz, theta = 0.1, math.radians(45)
print(f"階梯誤差 ≈ {dz/2*math.sin(theta):.3f} mm")
```

## 破案時刻

1986年專利獲准、3D Systems 成立，1987–88年 SLA-1 上市，第一個客戶包括通用汽車與安達信顧問等——工程師第一次在一夜之間拿到「摸得到」的設計原型。破案的關鍵瞬間：Hull 把 CAD 模型、光化學、數控掃描三者縫合，證明「從資料直接造物」可行。隨後 FDM（1988年）與 SLS（1980年代末）補齊了塑料與金屬路線，層積製造成為正式的製造學門。

## 後果 -- 改造了什麼

- 快速原型（rapid prototyping）產業誕生，設計驗證週期從數週縮短到數小時。
- 2000年代專利到期引發 RepRap 開源運動（2005年起，Adrian Bowyer），家用 3D 列印機價格從數萬美元跌到數百美元。
- 航太（GE 的 LEAP 燃油噴嘴）、醫療（牙科、義肢、客製化植入物）進入「積層製造量產」時代：複雜內流道只有 3D 列印做得出來。
- STL 之後演化出 AMF、3MF 等新格式，但「切片—層積」的製造哲學至今未變；製造業的想像從「能不能做」變成「怎麼設計給機器長出來」。
