# 1830-莫茲利車床與螺紋標準

## 案件摘要

亨利・莫茲利（Henry Maudslay, 1771–1831），倫敦機械師，被後世稱為「機床之父」。他在 1797 年前後發展出帶滑動刀架（slide rest）與導螺桿（lead screw）的金屬車床，又在工作室裡建立了螺紋切削與標準化的體系。1831 年他去世時留下了一個行業的「基因」：機床——製造機器的機器。本案偵查的是這個基因如何誕生。

## 前因 -- 為什麼會有這個案子

- 18 世紀的車床靠工匠手持刀具（hand-held tool）抵著刀架車削，精度全憑手感和眼力；車出的軸歪斜、螺紋亂配，每一對螺栓螺母都得成對手工打造，壞一個就全組報廢。
- 莫茲利少年時在伍利奇兵工廠（Woolwich Arsenal）與布拉馬（Joseph Bramah）的工場做學徒——布拉馬 1784 年的防盜鎖以精密聞名，莫茲利為它造出了專用機床，練就了「以機器保證精度」的信念。
- 螺紋當時是重災區：每個工匠有自己的螺距，機器上的一顆螺栓換不進另一台機器的螺母。工業擴張急需一個「統一語言」。
- 1797 年，莫茲利自立門戶，在倫敦威爾斯街（Wells Street）開設工場，滑動刀架車床在此定型。

## 線索與推理 -- 數學式、程式、理論

### 線索一：滑動刀架 -- 把手交給機器

滑動刀架的本質是「導軌約束」：刀具被剛性導軌夾持，只能沿直線（平行於工件軸線）進給，由導螺桿驅動。這把工匠的手替換成了機器的約束，誤差來源從人手轉為導軌的直線度。工件加工後的母線直線度誤差 $\delta(x)$ 與導軌誤差近似 1:1 傳遞（誤差映射）：

$$\delta_{work}(x) \approx \delta_{guide}(x)$$

要把工件車得直，先得把導軌刮得直——這催生了莫茲利工場的「三平面刮削互檢法」（three-plate scraping method）：三塊平板兩兩互刮、輪流比對，收斂出真正平面。這個方法至今仍是精密機床裝配的標準工藝。

### 線索二：導螺桿與螺紋切削 -- 運動學的鏈條

車螺紋的原理是「工件轉一圈、刀具走一個螺距」的強制運動鏈。若主軸經交換齒輪（change gears，齒數比 $i = z_1/z_2$）帶動螺距為 $P_s$ 的導螺桿，則車出的螺紋螺距為：

$$P_w = i \cdot P_s = \frac{z_1}{z_2} \cdot P_s$$

只要準備一組交換齒輪，一台車床就能車出任意螺距——螺紋從「手工成對」變成「機器可複製」。而導螺桿本身的精度是雞生蛋問題：精確的導螺桿需要更精確的導螺桿來車。莫茲利的解法是「誤差漸近法」：用較長的螺母多次走刀、多次微修，讓誤差在多次複製中收斂縮小。

### 線索三：標準化的統計意義 -- 螺紋的「共同語言」

莫茲利工作室培養出一批頂尖機械師（ James Nasmyth、Richard Roberts、Joseph Whitworth、David Napier 等）。其中惠特沃斯（Joseph Whitworth）在 1841 年發表了以莫茲利實踐為基礎的英國標準螺紋（BSW, British Standard Whitworth），螺紋角 55°，規定了一系列標準直徑與螺距。標準化的本質是把全行業的螺紋尺寸分布從「多峰雜訊」壓縮成「離散標準點集」：

$$\{P\}_{\text{任意工匠}} \longrightarrow \{P_1, P_2, P_3, \ldots\}_{\text{標準表}}$$

有了標準點集，互換性才可能在行業層級實現。莫茲利自己最著名的作品是為皇家鑄幣局（Royal Mint）打造的自動化造幣機（與博爾頓合作，1810 年代），以及那台 1830 年代刻著「卓越工藝」的巨型千斤頂測試機——他的工場被稱為「機械師的搖籃」。

用 Python 驗證交換齒輪能車出的螺距表：

```python
from fractions import Fraction
P_s = Fraction(4, 1)            # 導螺桿螺距：每吋 4 牙 => 螺距 1/4 吋
gears = [20, 30, 40, 50, 60, 75, 80]   # 常用交換齒輪齒數
results = set()
for z1 in gears:
    for z2 in gears:
        i = Fraction(z1, z2)
        pitch = Fraction(1,1) / (i * (1/P_s))  # 換算成每吋牙數
        results.add(pitch)
print("可車出的每吋牙數（部分）:", sorted(results)[:12])
print("可達牙數種類:", len(results))
```

## 破案時刻

1797 年前後，莫茲利的滑動刀架車床定型：鑄鐵床身、導螺桿、可上下前後進刀的刀架，工件精度不再依賴人手。他的工場隨後成為倫敦最好的機床廠，1830 年代納斯米希回憶：「走進莫茲利的工場，就像走進機械化的聖殿。」1831 年莫茲利死於法國布洛涅（Boulogne）的度假途中，葬禮上他的機械師們以他造的巨型工具致敬。他沒有留下大量專利，卻留下了更貴重的東西：一支訓練有素的機械師隊伍與「以機器造機器」的方法論。

## 後果 -- 改變了什麼

- **機床工業誕生**：車床從工具變成「母機」（mother machine）——製造機器的機器，銑床、刨床、鑽床、磨床的精密化都以它為起點。
- **機械師譜系擴散**：納斯米希（蒸汽打樁機）、羅伯茨（螺紋車床自動化）、惠特沃斯（標準螺紋與量測）、內皮爾（印刷機）——莫茲利的學徒們撐起了英國機械工程半邊天。
- **螺紋標準化**：1841 年惠特沃斯標準螺紋（BSW）成為世界第一個國家螺紋標準，1864 年美國的 Sellers 螺紋（60°）跟進，螺紋互換在工業層級實現。
- **量測文化**：莫茲利工場開啟的精密傳統，經惠特沃斯的百萬分之一英吋測微儀（也稱「機器鍾」）與標準量規，最終催生了現代互換性製造與國家標準體系。
