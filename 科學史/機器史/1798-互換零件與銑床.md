# 1798-互換零件與銑床

## 案件摘要

1798 年，美國發明家伊萊・惠特尼（Eli Whitney, 1765–1825）與美國戰爭部簽下震驚當時的合約：在 28 個月內交付 10,000 支滑膛槍（muskets）。他承諾的關鍵不是速度，而是「互換性零件」（interchangeable parts）——任何一支槍的零件都能裝到另一支槍上。這份合約拉開了「美國製造系統」（American System of Manufacturing）的序幕，也讓銑床（milling machine）這種「製造機器的機器」浮上歷史舞台。

## 前因 -- 為什麼會有這個案子

- 18 世紀的槍械由工匠逐支手工打造，每支槍的零件都獨一無二；戰場上一支槍的撞針壞了，沒有備用零件可換，整支槍就是廢鐵。
- 美國獨立後急於建立自己的軍备工業，1794 年國會通過法案授權聯邦政府與民間簽約製造武器，並設立斯普林菲爾德（Springfield Armory, 1794）與哈珀斯渡口（Harpers Ferry Armory, 1799）兩座國家兵工廠。
- 惠特尼已因軋棉機（cotton gin, 1793）聞名，但他真正想做的是證明「用機器造機器」的量產路線。1798 年 1 月，他以「統一規格、可互換」為賣點，向戰爭部部長詹姆斯・麥克亨利（James McHenry）爭取到這筆合約。
- 當時歐洲（如法國軍械官勒布朗 Honoré Blanc）也在嘗試互換性，但惠特尼是第一位將其商業化推銷給大規模政府訂單的人。

## 線索與推理 -- 數學式、程式、理論

### 線索一：互換性的數學本質 -- 容差（tolerance）理論

互換性的核心是尺寸公差。若零件 $A$ 的尺寸為 $X \sim N(\mu, \sigma^2)$，配合件 $B$ 的孔徑為 $Y \sim N(\mu, \sigma^2)$，則隨機抽取兩件能成功配合的條件是間隙 $D = Y - X > 0$。兩獨立常態變數之差仍為常態：

$$D \sim N(0,\ 2\sigma^2)$$

成功機率 $P(D>0) = 0.5$——這說明只靠「中心值相同」不夠，必須把每件尺寸壓進公差帶 $[\mu - t,\ \mu + t]$ 內，才能保證配合。惠特尼的解法是設計專用夾具（jigs）與樣板（templates），讓機器而非工匠的眼睛來控制 $t$。

### 線索二：銑床的力學優勢 -- 多刃切削

車床是單刃連續切削，而銑床用旋轉的多刃銑刀（milling cutter），每轉一圈多個刀齒輪流切入。若銑刀有 $z$ 齒、轉速 $n$（rpm）、每齒進給量 $f_z$，則每分鐘進給速度為：

$$v_f = f_z \cdot z \cdot n$$

多刃帶來三個好處：(1) 同樣金屬去除率下單齒負載小，刀具壽命長；(2) 切削力波動頻率高、平均力穩定，加工面尺寸一致性高——這正是互換性需要的低 $\sigma$；(3) 便於用導螺桿與樣板控制成形，可銑出槍機的溝槽、平面與曲面。惠特尼在哈珀斯渡口兵工廠推動的銑床（1818 年前後由其工場與 Simeon North 等人逐步發展成形）成為美國製造系統的標準裝備。

### 線索三：分工理論與學習曲線

亞當・斯密在《國富論》（1776）論證分工提升生產力；惠特尼把它推到極端：把造槍拆成數十道工序，每道工序由專用機器與半熟練工人完成。若單件成本隨累積產量 $N$ 依學習曲線下降：

$$C(N) = C_1 \cdot N^{-b}, \quad b = \log_2(\text{學習率})$$

量產的經濟性來自 $N^{-b}$ 項，而這只有能「用機器複製機器」時才能實現。

用 Python 簡單驗證公差配合機率：

```python
import numpy as np
rng = np.random.default_rng(0)
mu, sigma = 10.0, 0.05  # 桿徑與孔徑目標 10mm，標準差 0.05mm
n = 1_000_000
x = rng.normal(mu, sigma, n)      # 軸
y = rng.normal(mu, sigma, n)      # 孔
print("無公差控制、隨機配合成功率:", (y > x).mean())   # ≈ 0.5
# 加入機器把尺寸壓進 ±0.02mm 公差帶（超出即重加工）
x2 = np.clip(rng.normal(mu, sigma*0.3, n), mu-0.02, mu+0.02)
y2 = np.clip(rng.normal(mu, sigma*0.3, n), mu-0.02, mu+0.02)
print("低變異加工後配合成功率:", (y2 > x2 - 0.005).mean())  # 大幅上升
```

## 破案時刻

1801 年 1 月，惠特尼在華盛頓向總統約翰・亞當斯、當選總統傑佛遜與戰爭部官員當眾示範：他帶來 10 支槍的零件堆在桌上，隨機組裝成完整的槍。示範成功，爭議平息——儘管後世史家（如 Merritt Roe Smith）指出惠特尼當年交付的槍其實多有手工修配、互換性名過於實，但「互換性」作為可銷售、可驗收的契約條款，已正式寫入工業史。真正的完全互換要到 1820 年代，由約翰・霍爾（John H. Hall）在哈珀斯渡口以 M1819 霍爾步槍的「全民兵工廠實踐」（American Armory Practices）完成。

## 後果 -- 改變了什麼

- **美國製造系統成形**：專用機床、夾具、樣板、量規與工序分工，在斯普林菲爾德與哈珀斯渡口兩座兵工廠紮根，1850 年代經機械師（如塞繆爾・科爾特 Samuel Colt 的左輪手槍廠）擴散到民間工業。
- **銑床成為關鍵機床**：1818 年前後，羅伯特・約翰遜（Robert Johnson）與惠特尼工場發展出台式銑床；1862 年約瑟夫・布朗（Joseph R. Brown）的萬能銑床（universal milling machine）把它推向成熟。
- **量測學革命**：互換性逼出了精密量規與後來的極限量規制度，最終促成 1901 年美國國家標準局的成立。
- **流水線的遠祖**：「零件流向工人，而非工人追逐零件」的組裝思維，一路傳到 1913 年福特的流動裝配線。一紙 1798 年的軍火合約，其實是現代大量生產的出生證明。
