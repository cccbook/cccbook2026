# 1963 - Lorenz 混沌

## 案件摘要
1961–1963 年，MIT 的氣象學家 Edward Lorenz 用電腦模擬天氣時發現：**初始條件的微小差異（萬分之一）導致軌道完全不同**——「**蝴蝶效應**」：巴西的蝴蝶拍翅，德州掀起龍風暴。他發現的**Lorenz 吸引子**——三個微分方程的簡單系統，產生**永不重複、永不分離**的混沌軌道：

$$\dot{x} = \sigma(y - x), \quad \dot{y} = x(\rho - z) - y, \quad \dot{z} = xy - \beta z$$

**決定論的崩塌**——方程完全確定，長期行為卻**不可預測**——「**決定論的混沌**」（deterministic chaos）。**20 世紀科學的第三次革命**（相對論、量子力學、混沌）——**天氣預報的極限、生態學、心臟節律、經濟波動**的重塑。

## 前因 -- 為什麼會有這個案子
**拉普拉斯的妖**（1814）：「**知道一切粒子的位置與動量，就能預測一切未來**」——決定論的極致（與牛頓力學 1687 的成功相配，見 `1665-Newton微積分.md`）。

**天氣的困惑**：天氣預報為什麼這麼難？——**大氣是流體**（Navier–Stokes，見 `2000-千禧年大獎.md` 的懸案）——**湍流與混沌**。

**Lorenz 的環境**：哈佛數學學士、MIT 氣象學——**數學 + 氣象的雙棲**。1960 年代用 **LGp-30 電腦**（小型計算機）模擬大氣——**12 個微分方程的模型**。

**1961 年的偶然**：Lorenz 重跑模擬，輸入**截斷的初始值**（0.506127 → 0.506）——**萬分之一的差異**——軌道完全不同！「**這不是機器故障，是大氣的本質**」。

## 線索與推理 -- 數學式、程式、理論

### 蝴蝶效應：對初始條件的敏感
**數學**：軌道的**分離**——初始差異 $\delta_0$，$t$ 時後的差異：

$$\delta(t) \approx \delta_0 e^{\lambda t} \quad \text{（}\lambda > 0 \text{ 是 Lyapunov 指數）}$$

**Lyapunov 指數**：$\lambda > 0$ ⟹ **指數分離**——混沌的定義。

**Lorenz 系統**（$\sigma = 10, \rho = 28, \beta = 8/3$）：$\lambda_1 \approx 0.906$——**初始差異翻倍的時間** $\approx \ln 2 / 0.906 \approx 0.77$ 個時間單位——**天氣預報的極限**（約 2 週——即使無限精確的初始值）。

**與拉普拉斯妖的對決**：

| | 拉普拉斯（1814） | Lorenz（1963） |
|---|------|------|
| 初始條件 | 精確已知 | **必然有誤差** |
| 長期預測 | 原則上可能 | **原則上不可能**（誤差指數放大） |
| 決定論 | 完全決定 | **決定但不可預測** |

### Lorenz 吸引子
**三個方程的混沌**（1963 年發表）：

$$\dot{x} = \sigma(y - x), \quad \dot{y} = x(\rho - z) - y, \quad \dot{z} = xy - \beta z$$

**軌道的行為**：
- **永不重複**（不是週期軌道）
- **永不分離**（有界——被「吸引子」困住）
- **蝴蝶形狀**：兩個「翅膀」之間的隨機切換——**分形結構**（Hausdorff 維數 $\approx 2.06$，見 `1984-Mandelbrot分形.md`）

**吸引子**（attractor）：軌道長期收斂到的集合——**混沌吸引子**（ strange attractor，Ruelle–Takens 1971 的命名）——**「簡單方程、複雜行為」**的典範。

### 程式碼：Lorenz 系統

```python
import math

def lorenz(x, y, z, sigma=10, rho=28, beta=8/3):
    """Lorenz 方程組：混沌吸引子"""
    return (sigma*(y-x), x*(rho-z)-y, x*y-beta*z)

def simulate(x0, y0, z0, steps=5000, dt=0.005):
    """Euler 方法模擬"""
    x, y, z = x0, y0, z0
    path = []
    for _ in range(steps):
        dx, dy, dz = lorenz(x, y, z)
        x, y, z = x+dx*dt, y+dy*dt, z+dz*dt
        path.append((x, y, z))
    return path

# 蝴蝶效應：初始差異 0.0001 的分離
p1 = simulate(1.0, 1.0, 1.0)
p2 = simulate(1.0001, 1.0, 1.0)       # 萬分之一的差異

print("蝴蝶效應（初始差異 0.0001）：")
for step in [500, 1500, 3000]:
    d = math.dist(p1[step], p2[step])
    print(f"  t={step}：軌道差異 = {d:.6f}")
# 差異指數放大：0.0001 → 0.001 → 10+——完全分離 ✓

# Lyapunov 指數的估計
import statistics
ratio = []
for i in range(100, 1500):
    d = math.dist(p1[i], p2[i])
    ratio.append(d)
# 估計 λ ≈ ln(d(t2)/d(t1)) / (t2-t1)
lam = math.log(ratio[-1]/ratio[100]) / ((1500-100)*0.005)
print(f"\nLyapunov 指數 λ ≈ {lam:.3f}（> 0 = 混沌 ✓）")
print(f"誤差翻倍時間 = {math.log(2)/lam:.2f} 個時間單位——天氣預報的極限")

# 有界性：軌道被吸引子困住
r = [math.sqrt(x*x+y*y+z*z) for x, y, z in p1[1000:]]
print(f"軌道範圍：[{min(r):.1f}, {max(r):.1f}]——永不分離（有界）但永不重複")
```

### 混沌的革命
**譜系**：
- **Poincaré（1890）**：三體問題的混沌——**最早的發現**（沒有電腦，用幾何）——**「可能存在混沌」**
- **Lorenz（1963）**：電腦模擬的混沌——**「混沌被看見」**（與 Mandelbrot 的分形同源的「視覺化革命」）
- **May（1976）**：logistic 映射 $x_{n+1} = rx_n(1-x_n)$——**一維的混沌**（生態學）
- **Feigenbaum（1975）**：倍增週期的普適常數 $\delta = 4.669$——**混沌的「常數」**（與 π、e 並列）
- **Ruelle–Takens（1971）**：奇怪吸引子——**混沌的理論化**

**偵探筆記**：Lorenz 的推理是「**偶然 + 數學直覺**」——截斷的初始值（偶然）+ 「這是大氣的本質」（直覺）——**電腦模擬的意外發現**（與 Ulam 的接龍、Mandelbrot 的圖形同源：**計算的偶然催生新科學**）。**決定論與可預測性的分離**——20 世紀科學的第三次革命（相對論：時空的彎曲；量子：測量的不確定；混沌：決定的不可預測）。

## 結案 -- 後果與影響
- **決定論的崩塌**：決定但不可預測——**拉普拉斯妖的死亡**。
- **天氣預報的極限**：約 2 週——**蝴蝶效應的量化**（即使無限精確）。
- **混沌理論的黃金年代**（1970s–80s）：logistic 映射、Feigenbaum 常數、奇怪吸引子——**非線性科學的誕生**。
- **生態與醫學**：族群波動（May）、心臟節律（混沌與猝死）——**生命科學的混沌**。
- **經濟的混沌**：市場波動（與 Mandelbrot 的金融分形同源，見 `1984-Mandelbrot分形.md`）——**預測的極限**。
- **Poincaré 的正名**：1890 的三體混沌——**最早發現但無人注意**（與 Galois 遺稿、Mendel 的豌豆並列的「被遺忘的先驅」）。
- **與分形的融合**：奇怪吸引子的分形維度——**混沌與分形是同一革命**（見 `1984-Mandelbrot分形.md`）。
