# 1950 - Nash 均衡

## 案件摘要
1950 年，22 歲的 John Nash 在普林斯頓的博士論文（28 頁！）證明**納許均衡**：**多人非零和博弈存在均衡**——每個人的策略都是「對其他人策略的最佳回應」，**沒有人有單方面改變的動機**。這把 von Neumann 的兩人零和（1928，見 `1928-vonNeumann極小極大.md`）推廣到**一切博弈**——經濟學、政治學、演化生物學的革命。**Nash 30 歲精神分裂**（30 年的黑暗歲月），**66 歲獲諾貝爾經濟學獎（1994）**——數學史上最戲劇性的人生（電影《美麗境界》）。

## 前因 -- 為什麼會有這個案子
**von Neumann 的極限**（1928/1944，見 `1928-vonNeumann極小極大.md`、`1944-vonNeumannMorgenstern博弈論.md`）：兩人零和有解（極小極大），但**多人非零和**（我的贏不是你的輸）——**沒有理論**。

**vN–M 的嘗試**：合作博弈的穩定集——但**非合作的多人博弈**（各自獨立決策）沒有解的概念。

**Nash 的問題**：**多人博弈中，是否存在「穩定的策略組合」**——沒有人想單方面改變？

**Nash 的環境**：西維吉尼亞的天才（父親工程師），Carnegie 學士、普林斯頓博士（1950）——**與 von Neumann 見面時的插曲**：von Neumann 說「這只是不動點定理，平凡的」（Nash 的均衡構想被 vN 輕視——但 Nash 堅持）。

## 線索與推理 -- 數學式、程式、理論

### 納許均衡
**定義**：策略組合 $(s_1^*, \dots, s_n^*)$ 是**納許均衡**，若每個玩家 $i$ 的策略是「對其他人最佳回應」：

$$u_i(s_1^*, \dots, s_i^*, \dots, s_n^*) \ge u_i(s_1^*, \dots, s_i, \dots, s_n^*) \quad \forall s_i$$

**白話**：**沒有人有單方面改變的動機**——**穩定狀態**。

**範例：囚犯困境**：

| | B 沉默 | B 招供 |
|---|--------|--------|
| A 沉默 | (-1, -1) | (-3, 0) |
| A 招供 | (0, -3) | (-2, -2) |

**納許均衡 =（招供，招供）**——雖然（沉默，沉默）對雙方更好——**個體理性 ⟹ 集體非理性**（社會困境的本質——氣候變遷、軍備競賽的模型）。

### 不動點定理的證明
**Nash 的武器**：**Brouwer 不動點定理**（1911）——凸緊集上的連續映射有不動點。

**Nash 的構造**：把「最佳回應映射」$B: (p_1, \dots, p_n) \to (\text{各玩家的最佳回應})$ 定義在策略組合的空間（**凸緊集**——混合策略的單體積）：

$$\text{納許均衡} = \text{B 的不動點} \quad \text{（} B(p) = p\text{）}$$

**由 Brouwer**：不動點存在。$\blacksquare$

**Nash 的證明（28 頁論文 + 1 頁 PNAS 1950）**——**用 Kakutani 廣義不動點**（多值映射版本）更簡潔——**把博弈論化約為拓撲**（與 Atiyah–Singer 指標定理把分析化約為拓撲同源的「化約」傳統，見 `1965-AtiyahSinger指標定理.md`）。

**von Neumann 的輕視**：「**這只是另一個不動點定理**」——但**意義在詮釋**：均衡概念解釋了**社會的穩定與困境**——數學的價值不在技術難度，在詮釋力。

### 程式碼：囚犯困境與納許均衡

```python
import random

# 囚犯困境：納許均衡 =（招供，招供）
def prisoner_dilemma():
    u = {("沉默","沉默"): (-1,-1), ("沉默","招供"): (-3,0),
         ("招供","沉默"): (0,-3), ("招供","招供"): (-2,-2)}
    # A 的最佳回應：對手沉默→招供(0>-1)；對手招供→招供(-2>-3)
    # B 同理 →（招供，招供）是均衡
    print("囚犯困境：納許均衡 =（招供，招供）——個體理性，集體非理性")
    for k, v in u.items():
        print(f"  {k}: {v}")

prisoner_dilemma()

# 蒙地卡羅：重複囚犯困境（合作的演化）
def repeated_pd(rounds=200, tit_for_tat=True):
    """重複博弈：以牙還牙（tit-for-tat）策略"""
    scoreA, scoreB = 0, 0
    history = []
    for r in range(rounds):
        if tit_for_tat and r > 0:
            a = "招供" if history[-1][1] == "招供" else "沉默"   # A 模仿 B 上一步
            b = "招供" if random.random() < 0.1 else "沉默"      # B 偶爾背叛
        else:
            a, b = "招供", "招供"
        scoreA += {("沉默","沉默"): -1, ("招供","沉默"): 0,
                   ("沉默","招供"): -3, ("招供","招供"): -2}[(a,b)][0]
        scoreB += {("沉默","沉默"): -1, ("招供","沉默"): 0,
                   ("沉默","招供"): -3, ("招供","招供"): -2}[(a,b)][1]
        history.append((a, b))
    return scoreA, scoreB

random.seed(42)
sa, sb = repeated_pd()
print(f"\n重複博弈（以牙還牙 vs 隨機背叛）：A={sa}, B={sb}")
print("以牙還牙在重複博弈中促進合作——Axelrod 的演化實驗 (1984)")

# 均衡的搜尋（最佳回應迭代）
def best_response_dynamics(u, init, rounds=100):
    """最佳回應迭代：收斂到納許均衡（有時）"""
    s = list(init)
    for _ in range(rounds):
        changed = False
        for i in range(len(s)):
            others = tuple(s[:i] + s[i+1:])
            # 我的最優回應
            best = max(("沉默", "招供"), key=lambda a: u[(a,) + others][i])
            if s[i] != best:
                s[i] = best; changed = True
        if not changed: break
    return tuple(s)

u = {("沉默","沉默"): (-1,-1), ("招供","沉默"): (0,-3),
     ("沉默","招供"): (-3,0), ("招供","招供"): (-2,-2)}
eq = best_response_dynamics(u, ("沉默", "沉默"))
print(f"\n最佳回應迭代收斂到：{eq}——納許均衡 ✓")
```

### 精神分裂的 30 年
**Nash 的悲劇**：
- **1950–58**：普林斯頓的黃金年代（均衡、流形嵌入、黎曼問題的部分結果）——**30 歲前已是傳奇**
- **1959 年**：**精神分裂症**發作——幻想、被害妄想（「外星人的密碼」）
- **1959–1990**：**30 年的黑暗歲月**——普林斯頓的「幽靈」（校園遊蕩、拒絕服藥）
- **1994 年**：**諾貝爾經濟學獎**（與 Harsanyi、Selten）——**66 歲的救贖**
- **2015 年**：**Abel 獎**（與 Nirenberg，奇異點理論）——**數天後車禍逝世**（86 歲）——**領獎後數日的悲劇**

**電影《美麗境界》**（2001，Oscar 最佳影片）——**數學家的大眾形象**（與 Turing 的模仿遊戲 2014 並列）。

**偵探筆記**：Nash 的推理是「**不動點**」——把「穩定」數學化為「最佳回應映射的不動點」。**「均衡」的詮釋力**：社會的穩定（沒人想改變）、社會的困境（囚犯困境——個體理性 ⟹ 集體非理性）、演化生物學（演化穩定策略 ESS，Maynard Smith 1972）——**數學的價值在詮釋，不在技術難度**（von Neumann 的輕視 vs 歷史的評價）。

## 結案 -- 後果與影響
- **博弈論的推廣**：兩人零和 → 一切博弈——**經濟學、政治學、生物學的革命**。
- **囚犯困境的詮釋**：社會困境的模型——**氣候變遷、軍備競賽、公共財**的數學（Axelrod 的演化實驗 1984）。
- **不動點的化約**：博弈論化約為拓撲——**化約的傳統**（Atiyah–Singer、Arrow 的不動點）。
- **Nash 的悲劇**：30 年精神分裂 + 66 歲諾貝爾 + 86 歲車禍——**數學史上最戲劇性的人生**。
- **演化穩定策略**：Maynard Smith 的 ESS（1972）——**演化生物學的博弈論**（生物的「策略」）。
- **機制設計**：納許均衡的反向（設計博弈使均衡 = 社會最優）——**拍賣、匹配市場**（Hurwicz–Maskin–Myerson 2007 諾貝爾）。
