# 1637 - 笛卡爾解析幾何

## 案件摘要
1637 年，René Descartes 在《方法談》的附錄《幾何學》（La Géométrie）中發明**解析幾何**：用座標 $(x, y)$ 把幾何圖形變成代數方程——**曲線是方程，方程是曲線**。代數與幾何這兩條兩千年的平行線（花拉子米的運算 vs 歐幾里得的圖形）第一次統一。**座標系是微積分（1665）、物理學、電腦圖學的基礎設施**——今天每一張圖表、每一次 GPS 定位都在用 Descartes 的座標。

## 前因 -- 為什麼會有這個案子
1630 年代的兩難：

- **幾何**（歐幾里得的傳統）：直觀、證明優雅，但**運算笨拙**——複雜圖形的性質難以推導
- **代數**（花拉子米的傳統）：運算機械化，但**抽象無圖形**——方程與形狀的關係不明

**Descartes 的背景**：法國貴族、傭兵、哲學家。1619 年 11 月 10 日的三個夢（他自述）啟發「統一科學的夢想」。在荷蘭（1629–1649 隱居）寫作《方法談》——**用理性方法重建一切知識**，幾何學是第一個示範。

**他的問題**：能否把幾何問題**翻譯成代數**，用機械運算取代幾何直覺？

## 線索與推理 -- 數學式、程式、理論

### 座標的發明
**核心想法**：平面上任一點由兩個數 $(x, y)$ 決定（到兩條軸的距離）。

- **曲線 = 方程**：圓是 $x^2 + y^2 = r^2$；拋物線是 $y = x^2$；直線是 $y = ax + b$
- **方程 = 曲線**：任何 $F(x, y) = 0$ 定義一條曲線——**代數式有了幾何圖像**

**兩千年的統一**：

| 幾何問題 | 代數翻譯 |
|----------|----------|
| 兩線是否相交 | 解聯立方程 |
| 圓與直線的關係 | 二次方程的判別式 |
| 曲線的切線斜率 | 導數（1665 牛頓，見 `1665-Newton微積分.md`） |
| 曲線下的面積 | 積分 |

**Descartes 的原話**：「把幾何問題化為代數計算」——**機械化取代直覺**（與花拉子米「照著做就對」同源，見 `0820-Khwarizmi代數學.md`）。

### 為什麼重要：空間的算術化
**深遠的意義**：座標系把**空間算術化**——空間的每個點都是一個「數」，幾何性質都是「數的關係」：

- **維度**：一維（直線）、二維（平面）、三維（空間）、**四維以上**（純代數的擴展——空間直覺不再需要！）
- **向量**：點的差 $(x_2 - x_1, y_2 - y_1)$——向量的代數化（見 `../線性代數/README.md`）
- **距離**：$\sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$（畢氏定理的代數化）
- **高維與無窮維**：函數空間（Hilbert 空間）、資料空間（機器學習的向量表示）——**一切「空間」都是座標化的**

**機器學習的座標化**：一張圖片是 $(1920, 1080)$ 維向量、一段文字是 embedding 向量（見 `../隨機算法/1984-JohnsonLindenstrauss引理.md` 的降維）——**Descartes 的座標是 AI 的基礎設施**。

### 程式碼：座標與曲線

```python
import math

# 曲線 = 方程：圓與直線的相交（判別式）
def circle_line_intersections(r, m, b):
    """圓 x²+y²=r² 與直線 y=mx+b：代入得二次方程，判別式決定交點數"""
    # x² + (mx+b)² = r² → (1+m²)x² + 2mbx + (b²-r²) = 0
    A, B, C = 1 + m*m, 2*m*b, b*b - r*r
    disc = B*B - 4*A*C                    # 判別式——幾何關係變成代數
    if disc < 0: return "不相交"
    if disc == 0: return "相切（一點）"
    return f"相交兩點：x = {(-B+math.sqrt(disc))/(2*A):.3f}, {(-B-math.sqrt(disc))/(2*A):.3f}"

print(circle_line_intersections(5, 0, 3))    # 相交兩點
print(circle_line_intersections(5, 0, 5))    # 相切
print(circle_line_intersections(5, 0, 6))    # 不相交
# 幾何問題 → 二次方程 → 判別式：代數取代幾何直覺

# 距離（畢氏定理的代數化）
def dist(p1, p2):
    return math.sqrt((p1[0]-p2[0])**2 + (p1[1]-p2[1])**2)
print(dist((0, 0), (3, 4)))              # 5.0

# 高維：資料的座標化（機器學習）
img = [[random.randint(0, 255) for _ in range(4)] for _ in range(4)]  # 16 維向量
print(f"圖片 = 16 維向量：{img[0]}")
```

### 笛卡爾與費馬：優先權
**費馬（Fermat）1629–36 年**私下寫了等價的座標幾何（未出版）——與 Descartes 的優先權之爭（比 Cardano–Tartaglia 溫和）。**兩人共同創造**，但 Descartes 先出版——與微積分的牛頓-萊布尼茨之爭（見 `1665-Newton微積分.md`）同為數學史的優先權案例。

## 結案 -- 後果與影響
- **微積分的基礎**：座標是極限、導數、積分的舞台（1665，見 `1665-Newton微積分.md`）——沒有座標就沒有微積分。
- **物理學的數學化**：牛頓《原理》的軌道計算、今天的工程圖學——空間的算術化是物理的基礎設施。
- **高維空間**：維度成為代數概念（不再依賴直覺）——相對論（四維時空）、量子力學（Hilbert 空間）、機器學習（embedding 向量）。
- **線性代數的誕生**：向量、矩陣、變換——座標系的代數化（見 `../線性代數/README.md`）。
- **圖論的伏筆**：Euler（1736，柯尼斯堡七橋）——離散的「幾何」。
- **電腦圖學**：螢幕的像素座標、3D 遊戲的變換矩陣——Descartes 的座標是數位世界的視覺基礎。
