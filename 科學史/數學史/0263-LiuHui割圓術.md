# 263 - 劉徽割圓術

## 案件摘要
263 年，中國三國時期的劉徽在注釋《九章算術》時發明**割圓術**：從正六邊形開始，邊數倍增（12、24、48、96、192 邊形），用勾股定理計算周長，夾逼圓周率——**中國的阿基米德**。劉徽得

$$\pi \approx 3.1416 \quad \text{（割圓至 192 邊形，徽率 157/50 = 3.14）}$$

兩百年後，祖沖之（480 年）推到 $3.1415926 < \pi < 3.1415927$——**精度千年無人超越**（歐洲 15 世紀才達到）。**中國數學的獨立傳統**：算籌計算、實用取向、極限思想的獨立發現。

## 前因 -- 為什麼會有這個案子
《九章算術》（約前 1 世紀成書）是中國數學的經典：246 個實用問題（田畝測量、賦稅、工程）——**取 $\pi = 3$**（「周三徑一」）——**太粗**。

**劉徽的問題**：圓周率到底是多少？「周三徑一」的誤差有多大？——他批評：「學者踵古，習謬為真」——**不能照抄古人，要親自驗證**（與阿基米德對巴比倫 $\pi = 3\frac{1}{8}$ 的態度同源，見 `-0250-Archimedes圓周率.md`）。

## 線索與推理 -- 數學式、程式、理論

### 割圓術
**方法**：從正六邊形開始（半徑 = 邊長，$\pi > 3$），**邊數倍增**：

$$S_{2n} = \text{新多邊形的面積（用勾股定理計算）}$$

**核心公式**：內接正 $n$ 邊形的邊長 $a_n$，倍增後（$2n$ 邊）：

$$a_{2n} = \sqrt{\left(\frac{a_n}{2}\right)^2 + (r - \sqrt{r^2 - (a_n/2)^2})^2} \cdot \ldots \quad \text{（勾股定理兩次）}$$

**劉徽的計算**（用算籌——小棍計數）：96 邊形得 $\pi \approx 3.141024$，192 邊形得 $\pi \approx 3.141024 < \pi$。

**徽率**：$\pi = \frac{157}{50} = 3.14$（實用）。

**極限的思想**：「割之彌細，所失彌少，割之又割，以至於不可割，則與圓周合體而無所失矣」——**無窮分割、極限逼近**的獨立發現（與阿基米德窮竭法、牛頓極限同源——東西方各自發現）。

### 祖沖之的精度（480 年）
**祖沖之（429–500）**：南北朝數學家，把割圓術推到**12288 邊形**（用其子祖暅協助計算）：

$$3.1415926 < \pi < 3.1415927$$

**密率**：$\pi \approx \frac{355}{113} = 3.1415929$——**精度千年無人超越**（歐洲 1585 年 Valentinus 才重新發現 355/113；1913 年 Lazzarini 的可疑擲針恰好用這個分數，見 `../隨機算法/1777-Buffon針實驗.md`）。

**祖暅原理**（祖沖之之子）：「冪勢既同，則積不容異」——**等高處截面積相等則體積相等**（Cavalieri 原理 1635 的 1300 年前身！）——球體積的推導。

### 程式碼：割圓術

```python
import math

def liuhui_pi(sides=96, r=1.0):
    """割圓術：內接正多邊形邊長倍增（勾股定理兩次）"""
    a = r                          # 六邊形：邊長 = 半徑
    n = 6
    while n < sides:
        # 勾股定理：半邊、矢（弓形高）、新半邊
        half = a / 2
        # 矢 = r - sqrt(r² - half²)（勾股）
        arrow = r - math.sqrt(r*r - half*half)
        # 新邊長（勾股兩次）
        a = math.sqrt(half*half + arrow*arrow)
        n *= 2
    perimeter = a * n
    return perimeter / (2 * r)

for n in [6, 12, 24, 48, 96, 192]:
    print(f"{n:5d} 邊形：π ≈ {liuhui_pi(n):.8f}")
# 96 邊形：3.141024，192 邊形：3.141028——劉徽的精度

# 祖沖之的密率：355/113
print(f"\n密率 355/113 = {355/113:.10f}（誤差 {abs(355/113 - math.pi):.2e}）")
print(f"劉徽「割之彌細，所失彌少」——極限思想的獨立發現")
print(f"祖暅原理 = Cavalieri 原理（1635）的 1300 年前身")
```

### 中國數學的獨立傳統
**偵探筆記**：劉徽的推理與阿基米德**平行發展**（互不影響——絲綢之路的有限交流）：

| | 阿基米德（前 250） | 劉徽（263） |
|---|------|------|
| 方法 | 窮竭法（反證，不用極限） | 割圓術（極限思想） |
| 工具 | 幾何作圖 | 算籌（計數棍） |
| 精度 | 96 邊形 | 192 邊形（後續） |

**中國數學的特色**：**實用取向**（九章算術的問題都是工程/賦稅）、**算法化**（「術」= 機械步驟——與花拉子米的演算法同源，見 `0820-Khwarizmi代數學.md`）、**負數的早熟**（九章算術已用負數——歐洲 16 世紀 Cardano 還在掙扎，見 `1545-Cardano三次方程.md`）。

## 結案 -- 後果與影響
- **圓周率的中國譜系**：劉徽（263）→ 祖沖之（480，千年精度）→ 明安圖（18 世紀，分析式）——**獨立於西方的傳統**。
- **極限思想的獨立發現**：「割之彌細，所失彌少」——與阿基米德、牛頓三地的極限思想。
- **祖暅原理**：Cavalieri 原理的 1300 年前身——積分思想的東方先聲。
- **算籌與算法**：中國數學的「術」文化——機械步驟的傳統（與九章算術的算法化）。
- **負數的早熟**：九章算術（前 1 世紀）已用負數——比歐洲早 1500 年。
- **數學的多元起源**：希臘（證明）、中國（算法）、印度（數字）、伊斯蘭（綜合）——**數學史不是單線**。
