# 1614 - Napier 對數

## 案件摘要
1614 年，蘇格蘭數學家 John Napier 出版《奇妙的對數定律說明》（Mirifici Logarithmorum Canonis Descriptio）：發明**對數**——把乘法變加法：

$$\log(xy) = \log x + \log y$$

**天文學與航海的計算革命**：Kepler 的軌道計算、三角測量——繁瑣的大數乘法（手算數小時）變成查表加法（數分鐘）。Kepler 感激地說「這本書讓天文計算加倍輕鬆」。**對數是計算尺（1632）、指數函數的基礎**——把「算術的技術」推向「函數的概念」。

## 前因 -- 為什麼會有這個案子
1610 年代的計算困境：

- **天文學**：Tycho Brahe 的觀測數據、Kepler 的軌道計算——**大數乘法是惡夢**（三角函數的乘法、角度換算）
- **航海**：三角測量、球面三角——**大數乘除**（手算數小時，錯誤致命）
- **銀行與貿易**：複利計算

**Napier 的背景**：蘇格蘭莊園主（沒有大學職位），業餘研究數學與神學（他也發明過戰車與潛艇的設計——愛國工程師）。**20 年的研究**（1594–1614）：尋找「把乘法變加法」的方法。

**他的問題**：能否用**查表**取代繁瑣的乘法？

## 線索與推理 -- 數學式、程式、理論

### 對數的發明
**核心想法**：等差數列 ↔ 等比數列的對應：

$$1, 2, 3, 4, \dots \quad \leftrightarrow \quad 2^1, 2^2, 2^3, 2^4, \dots$$

**等差相加對應等比相乘**：$2^{m} \cdot 2^{n} = 2^{m+n}$——**加法（指數）⟹ 乘法（底數）**。

**Napier 的原始定義**（幾何運動模型）：一個點沿直線以「與剩餘距離成正比的速度」減速，另一個點勻速——兩者的位置對應：

$$\text{Napier 對數：} \log_N(x) = 10^7 \cdot \ln\frac{10^7}{x}$$

（連續的運動模型——**微積分之前的極限思想**，見 `1665-Newton微積分.md` 的極限。）

**現代對數**：Briggs（1617）的改良——以 10 為底（常用對數 $\log_{10}$）：

$$\log(xy) = \log x + \log y$$

**查表的革命**：Napier 的《說明》附 90 頁的對數表——**手算數小時的乘法變成查表加法**。

### 對數與指數：函數的誕生
**深遠的意義**：對數把「算術的技術」推向「**函數的概念**」——

- **指數函數**：$y = e^x$（Euler 1748 的命名，見 `1748-Euler公式.md`）——對數的逆函數
- **微積分**：$\frac{d}{dx}\ln x = \frac{1}{x}$——對數是微積分的核心函數
- **歐拉公式**：$e^{i\theta} = \cos\theta + i\sin\theta$——指數與三角的統一
- **計算尺**（1632 Oughtred）：對數的滑動直尺——**工程師的計算機**（1970 年代電子計算機才取代）

**Napier 的其他發明**：**算籌（Napier's bones）**——乘法計算的棍棒（與中國算籌巧合同名，見 `0263-LiuHui割圓術.md` 的算籌傳統）。

### 程式碼：對數與計算的革命

```python
import math

# 對數的本質：乘法變加法
x, y = 12345.6, 7890.1
print(f"直接乘法：{x * y:.2f}")
print(f"對數加法：{math.exp(math.log(x) + math.log(y)):.2f}")
# log(xy) = log x + log y——查表加法取代大數乘法

# 對數表（Napier 的革命：手算數小時 → 查表數分鐘）
def log_table(base=10, n=20):
    """對數表：查表取代乘法"""
    return {i: math.log(i, base) for i in range(1, n+1)}

table = log_table()
# 6 × 8 = 查表：log6 + log8 = 1.477 → 10^1.477 ≈ 48
result = 10 ** (table[6] + table[8])
print(f"查表 6×8 = {result:.4f}（精確 48）✓")

# 自然對數與微積分
print(f"\nd/dx ln x 在 x=2 = {1/2}（解析）")
h = 1e-6
print(f"數值 = {(math.log(2+h) - math.log(2))/h:.8f} ✓")
# 對數是微積分的核心函數

# Napier 的原始定義（幾何運動模型）
print(f"\nNapier 對數 log_N(0.5) = {10**7 * math.log(10**7 / 0.5):.2f}")
print("（連續運動模型——微積分之前的極限思想）")
```

### Kepler 的感激
**Kepler 的軌道計算**（1609 的《新天文學》）——三角函數的大數乘法。**Napier 的對數表（1614）**使 Kepler 的後續計算（《哥白尼天文學概要》1621）「加倍輕鬆」——**科學的計算基礎設施**。

**偵探筆記**：Napier 的推理是「**等差與等比的對應**」——把乘法（等比）映射到加法（等差）。這個「映射」的思想與對數的「函數」本質——**數學從「數的運算」變成「函數的關係」**。對數的發明也是「計算的工程化」：**查表 + 滑動尺**——人類第一次「用結構省計算」（與 CRT 的權重構造、快速排序的分治同源——**算法的本質是利用結構**）。

## 結案 -- 後果與影響
- **天文與航海的計算革命**：對數表使大數乘法「查表化」——科學的計算基礎設施。
- **指數函數與微積分**：$\ln x$、$e^x$——對數是微積分的核心（歐拉公式的基礎，見 `1748-Euler公式.md`）。
- **計算尺**（1632–1970）：工程師 340 年的計算機——電子計算機前的工具。
- **函數概念的誕生**：對數把「運算」推向「函數」——17 世紀數學的轉折（與 Descartes 座標同時，見 `1637-Descartes解析幾何.md`）。
- **信息的度量**：對數在資訊論（Shannon 1948）成為熵的單位——**bits 的對數本質**。
- **算法的本質**：利用結構（等差-等比對應）省計算——算法設計的靈魂。
