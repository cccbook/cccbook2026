# 1734 - 歐拉巴塞爾問題

## 案件摘要
1734 年，28 歲的 Leonhard Euler 解決了困擾數學界 90 年的巴塞爾問題（Basel problem）：

$$\sum_{n=1}^{\infty} \frac{1}{n^2} = 1 + \frac{1}{4} + \frac{1}{9} + \frac{1}{16} + \dots = \frac{\pi^2}{6}$$

**π 竟出現在平方數的倒數和裡**——這個級數與圓無關，π 卻從中冒出來（與 Buffon 擲針的驚奇同源，見 `../隨機算法/1777-Buffon針實驗.md`）。歐拉的證明手法（把無窮多項式當有限多項式分解）雖不嚴格，卻開啟了**解析數論**——後來黎曼 ζ 函數（1859）與素數定理的基礎。**歐拉是數學史上最多產的人**（866 篇論文），「讀歐拉的書，讀歐拉的書，他是所有人的老師」（Laplace）。

## 前因 -- 為什麼會有這個案子
1644 年，Mengoli 提出：$1 + 1/4 + 1/9 + 1/16 + \dots$ 收斂到多少？

- **收斂性**已知（比較 $1/n^2 < 1/(n(n-1))$，望遠鏡級數），**值**未知
- 牛頓與萊布尼茨的微積分（1665，見 `1665-Newton微積分.md`）也解不了
- 歐拉的老師約翰·伯努利（Johann Bernoulli）攻擊多年無果——**歐拉時代最著名的未解問題**

**歐拉的環境**：巴塞爾，師從約翰·伯努利（萊布尼茨的學生）。1727 年赴聖彼得堡科學院（俄國女皇贊助）——數學史上最多產的時期。

## 線索與推理 -- 數學式、程式、理論

### 歐拉的證明（不嚴格但天才）
**第一步**：多項式的因式分解——$n$ 次多項式的根 $x_1, \dots, x_n$：

$$P(x) = a(x - x_1)(x - x_2)\cdots(x - x_n)$$

**第二步**：把 $\sin x$ 當成「無窮次多項式」（根在 $0, \pm\pi, \pm2\pi, \dots$）：

$$\sin x = x\left(1 - \frac{x^2}{\pi^2}\right)\left(1 - \frac{x^2}{4\pi^2}\right)\left(1 - \frac{x^2}{9\pi^2}\right)\cdots$$

**第三步**：另一邊，$\sin x$ 的泰勒級數：

$$\sin x = x - \frac{x^3}{6} + \frac{x^5}{120} - \dots$$

**第四步**：比較兩邊 $x^3$ 的係數！展開無窮乘積，$x^3$ 係數是：

$$-\left(\frac{1}{\pi^2} + \frac{1}{4\pi^2} + \frac{1}{9\pi^2} + \dots\right) = -\frac{1}{\pi^2}\sum_{n=1}^\infty \frac{1}{n^2}$$

等於泰勒級數的 $-1/6$：

$$\frac{1}{\pi^2}\sum_{n=1}^\infty \frac{1}{n^2} = \frac{1}{6} \implies \sum_{n=1}^\infty \frac{1}{n^2} = \frac{\pi^2}{6} \quad \blacksquare$$

**偵探筆記**：歐拉的推理是「**越界的方法**」——把無窮級數當有限多項式操作（分解、比較係數）。**嚴格性有漏洞**（無窮乘積的分解需要 Weierstrass 乘積定理，1876 才完成），但**答案是對的**——這個「天才越界」的風格貫穿歐拉一生，也成為「物理直覺先於嚴格證明」的典範（與阿基米德用槓桿證明體積同源，見 `-0250-Archimedes圓周率.md`）。

### π 為什麼在這裡
**深遠的意義**：$\sum 1/n^2$ 與圓無關，π 卻出現——為什麼？

答案的層次：
- **歐拉的視角**：$\sin x$ 的根在 $\pm\pi$ 的倍數——圓週期性藏在三角函數裡
- **機率論的視角**：$P(\text{兩個隨機整數互質}) = 6/\pi^2$——π 藏在數論的分佈裡
- **解析數論的視角**：ζ 函數 $\zeta(s) = \sum 1/n^s$ 的極——π 藏在複分析的解析延拓裡

**π 是萬物皆數的體現**——圓的常數滲透到數論、機率、分析（與 Buffon 擲針、$\sum 1/n^2$、高斯分佈（見 `../機率統計/README.md`）的 π 同源）。

### 程式碼：巴塞爾問題的驗證

```python
import math

# 數值驗證：部分和收斂到 π²/6
def partial_sum(N):
    return sum(1/n**2 for n in range(1, N+1))

target = math.pi**2 / 6
print(f"目標值 π²/6 = {target:.6f}")
for N in [10, 100, 1000, 100000, 1000000]:
    s = partial_sum(N)
    print(f"N={N:8d}: {s:.6f}（誤差 {target-s:.2e}）")
# 誤差 ~ 1/N：調和級數的尾巴

# 歐拉證明的第一步：sin x 的「因式分解」（無窮乘積）
def sin_product(x, terms=10):
    p = x
    for n in range(1, terms+1):
        p *= (1 - x*x/(math.pi*n)**2)
    return p

print(f"\nsin(1) 泰勒 = {math.sin(1):.8f}，無窮乘積 = {sin_product(1):.8f} ✓")

# 機率視角：兩個隨機整數互質的機率 = 6/π²
import random
random.seed(42)
from math import gcd
coprime = sum(1 for _ in range(1000000)
              if gcd(random.randint(1, 10**6), random.randint(1, 10**6)) == 1)
print(f"互質機率 = {coprime/10**6:.5f}，預測 6/π² = {6/math.pi**2:.5f} ✓")
# π 藏在數論的分佈裡——萬物皆數
```

### 譜系：ζ 函數與素數
- **歐拉（1737）**：ζ 函數的歐拉乘積公式——$\zeta(s) = \prod_p \frac{1}{1-p^{-s}}$（**素數與分析的橋樑**）
- **黎曼（1859）**：ζ 函數的解析延拓與**黎曼假設**——素數分佈的中心謎題
- **素數定理**（1896，Hadamard–de la Vallée Poussin）：$\pi(x) \sim x/\ln x$——歐拉乘積的果實
- **巴塞爾問題的推廣**：$\zeta(2k)$ 全部有值（$\pi$ 的偶次冪）；$\zeta(2k+1)$（如 $\zeta(3)$，Apéry 1978 證明無理）**仍是謎**

## 結案 -- 後果與影響
- **解析數論的誕生**：歐拉的 ζ 函數把素數與微積分連結——素數定理、黎曼假設的路徑。
- **歐拉的帝國**：866 篇論文——分析（無窮分析引論 1748）、圖論（1736 柯尼斯堡七橋）、力學、光學——「他是所有人的老師」。
- **越界方法的範式**：不嚴格但對的證明——物理數學（Dirac 的 δ 函數、Feynman 積分）的傳統，最終都被嚴格化。
- **π 的滲透**：巴塞爾、Buffon、互質機率——π 是「萬物皆數」的體現。
- **ζ(3) 的謎**：偶數項全解，奇數項（除 Apéry 的無理性）仍是謎——**數學的未完故事**。
