# 1736 - 歐拉七橋問題

## 案件摘要
1736 年，Leonhard Euler 解決柯尼斯堡七橋問題：能否走遍七座橋各恰一次？答案**不可能**——他證明的方法催生了**圖論**（graph theory）：把「橋與陸地」抽象成「邊與頂點」，地理問題變成**連接關係的數學**。**離散數學的誕生**——從「連續的空間」到「離散的關係」，圖論成為電腦科學的基礎（網路、演算法、資料結構）。**歐拉的第二次革命**（第一次是微積分與分析，見 `1665-Newton微積分.md`、`1734-Euler巴塞爾問題.md`）。

## 前因 -- 為什麼會有這個案子
**柯尼斯堡**（Königsberg，東普魯士，今加里寧格勒）：Pregel 河中有兩個島、七座橋連接四塊陸地（A、B、C、D）——

> 市民散步時的娛樂：能否走遍七座橋，每座恰走一次回到起點？

**傳統幾何的無力**：這個問題**與距離、角度無關**——只與「連接關係」有關。**歐幾里得的幾何**（見 `-0300-Euclid幾何原本.md`）與**解析幾何**（見 `1637-Descartes解析幾何.md`）都是「連續量」的數學——**離散的連接關係**沒有工具。

**1735 年**，柯尼斯堡市民寫信給 Euler（聖彼得堡科學院）——Euler 的回應：「這個問題與數學無關，與位置無關」——**但他意識到這正是新數學的機會**。

## 線索與推理 -- 數學式、程式、理論

### 圖的抽象
**Euler 的核心想法**：忽略距離與形狀，只保留**連接關係**：

$$\text{陸地} \to \text{頂點（vertex）}， \quad \text{橋} \to \text{邊（edge）}$$

柯尼斯堡的圖：4 個頂點、7 條邊（A 有 5 條、B 有 3 條、C 有 3 條、D 有 3 條橋）。

**度數（degree）**：每個頂點的邊數。

### Euler 定理：一筆畫的判準
**定理**：圖中存在「經過每條邊恰一次的封閉路徑」（Euler 迴路）⟺ **每個頂點的度數都是偶數**。

**證明（必要性）**：每條邊「進入又離開」頂點——度數必為偶數。$\blacksquare$

**證明（充分性）**：從任一點出發，每次走未走過的邊——由度數偶數，不會「卡住」（進得去就出得來）——最終回到起點構成迴路；刪去迴路重複——**所有邊被覆蓋**。

**柯尼斯堡的判決**：4 個頂點度數為 5, 3, 3, 3——**全是奇數**——**不可能一筆畫**。$\blacksquare$

**推論**：奇數度數頂點為 0 個 → Euler 迴路；恰 2 個 → Euler 路徑（不封閉）；其他 → 不可能。

### 圖論的誕生
**深遠的意義**：圖論把「關係」數學化——

- **頂點與邊**：連接關係的抽象——**離散數學的基礎**
- **與連續數學的分離**：距離、角度不再重要——**拓撲學的先聲**（只看連接，不看形狀——Poincaré 1895 的 analysis situs，見 `2003-Perelman龐加萊猜想.md`）
- **電腦科學的基礎設施**：網路（社群圖）、演算法（最短路徑、生成樹）、資料結構（鏈表、樹）

**Euler 迴路在電腦科學的實例**：DNA 定序（歐拉路徑組裝片段）、郵差問題（中國郵差：邊權重的 Euler 化）、網路測試。

### 程式碼：七橋與 Euler 迴路

```python
def has_euler_circuit(graph):
    """Euler 迴路 ⟺ 每個頂點度數都是偶數"""
    from collections import Counter
    degree = Counter()
    for u, v in graph:
        degree[u] += 1
        degree[v] += 1
    return all(d % 2 == 0 for d in degree.values()), dict(degree)

def has_euler_path(graph):
    """Euler 路徑 ⟺ 奇數度頂點恰 0 或 2 個"""
    from collections import Counter
    degree = Counter()
    for u, v in graph:
        degree[u] += 1
        degree[v] += 1
    odd = sum(1 for d in degree.values() if d % 2 == 1)
    return odd in (0, 2)

# 柯尼斯堡七橋：4 陸地、7 橋
konigsberg = [(0,1), (0,1), (0,2), (0,2), (0,3), (1,3), (2,3)]
# A(0) 有 5 橋，B(1)、C(2)、D(3) 各 3 橋
ok, degree = has_euler_circuit(konigsberg)
print(f"柯尼斯堡度數 = {degree}")
print(f"一筆畫（Euler 迴路）？{ok}——不可能 ✓（全奇數）")
print(f"Euler 路徑（不封閉）？{has_euler_path(konigsberg)}——奇數頂點 4 個，也不行")

# 對照：刪掉一座橋（A-C 橋之一）→ 6 橋
graph2 = [(0,1), (0,1), (0,3), (0,2), (1,3), (2,3)]
ok2, degree2 = has_euler_circuit(graph2)
print(f"\n刪一座橋後：度數 = {degree2}，迴路 = {ok2}")
# 度數 4,3,3,2——還有兩個奇數，仍無迴路（但有路徑）
print(f"Euler 路徑？{has_euler_path(graph2)}——奇數頂點 2 個，有路徑 ✓")
```

### Euler 的兩次革命
**第一次（1665–1736 的分析）**：微積分、巴塞爾、歐拉公式——**連續數學**的帝國。

**第二次（1736 的圖論）**：離散關係的數學——**離散數學**的誕生。

**偵探筆記**：歐拉的推理是「**抽象**」——忽略距離與形狀，只保留連接關係。**「與數學無關的問題」成為新數學的機會**——與 Ulam 的接龍（1946，見 `../隨機算法/1946-Ulam蒙地卡羅.md`）、Karger 的收縮（1989，見 `../隨機算法/1989-Karger最小割.md`）同源：**跨界的問題催生新的數學**。

## 結案 -- 後果與影響
- **圖論的誕生**：頂點與邊的抽象——離散數學的基礎，電腦科學的基礎設施。
- **Euler 迴路的判準**：度數的奇偶——一筆畫的數學（DNA 定序、郵差問題）。
- **拓撲學的先聲**：只看連接不看形狀——Poincaré 的 analysis situs（見 `2003-Perelman龐加萊猜想.md`）。
- **離散與連續的分離**：歐拉的兩次革命——**數學的兩大分支**（分析與離散）。
- **電腦科學的圖**：最短路徑（Dijkstra 1959）、生成樹（Kruskal 1956，見 `../隨機算法/1995-KargerKleinTarjan隨機MST.md`）、網路流——**圖論是算法的教科書**。
- **Euler 的帝國**：866 篇論文——分析、圖論、力學、光學、數論——「他是所有人的老師」。
