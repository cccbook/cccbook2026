# 神經網路 -- AI 偵探風格

以「推理探案」的方式，追查神經網路八十年（1943–2022）的每一場危機與轉身：
前因是什麼？線索在哪裡？推理如何展開？後果又如何改變了整個世界？

本卷特別追蹤**兩次寒冬與三次復興**——
從 1943 年的邏輯神經元，到 2012 年的影像大爆炸，再到 2022 年的對話革命，
每一章都是「寒冬裡活下來的人，改寫了整門學科」。

核心謎題只有一個：**「學習」到底是什麼？一堆簡單的神經元，如何學會看、聽、說與思考？**

## 四大歷史脈絡

1. **學習規則（Hebb → 反向傳播）**：從「一起激發就連在一起」到鏈鎖律的梯度下降。
2. **架構（McCulloch-Pitts → CNN → LSTM → Transformer）**：從邏輯單元到注意力為王。
3. **危機與復興（1969 寒冬 → 1986 復興 → 2012 爆炸）**：寒冬裡活下來的人，改寫了整門學科。
4. **從感知到生成（AlexNet → GAN → GPT-3 → ChatGPT）**：神經網路從「看懂世界」到「生成世界」。
