# 通訊技術史 -- AI 偵探風格

以「推理探案」的方式，追查通訊技術從摩斯電報到 5G 與星群的每一步：
前因是什麼？線索在哪裡？推理如何展開？後果又如何改變了整個文明的樣貌？
核心謎題只有一個：**訊息如何在充滿雜訊、距離與失真的世界中，被完整送到目的地？**
