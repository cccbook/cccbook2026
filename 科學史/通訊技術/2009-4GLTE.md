# 2009 - 4G LTE（無線速度追上有線）

## 案件摘要
2009 年，3GPP 發布 **LTE** (Long Term Evolution) 標準 Rel-8：
以 **OFDMA 下行 + SC-FDMA 上行 + MIMO** 為核心，峰值速率 $100\ \text{Mbps}$（下載）：
$$\text{峰值} \approx 6\times \text{下行聚合頻寬} \times 6\ \text{bps/Hz} \times N\ \text{流}.$$
它是第一個**全面全 IP 化**的行動系統（無電路交換域）——語音也走封包（VoLTE, 2014）。
今日全球大部分行動流量跑在 LTE 與其後繼者 5G NR 上。

## 前因 -- 為什麼會有這個案子
- **3G 的教訓（2000s）**：UMTS/WCDMA (3GPP, 1999–2002) 與 3GPP2 CDMA2000 並存——**兩套 3G 標準**；
  WCDMA 上行慢、頻譜效率低、設備貴。**3G 的投資回报不佳**。
- **資料需求的爆發（2007–2010）**：iPhone (2007) + App Store + YouTube → **行動資料需求年增數倍**；
  3G（384 kbps–2 Mbps）**完全不夠**。
- **無線寬頻競賽**：WiMAX (IEEE 802.16, 2001) 與 LTE 競爭；
  LTE 的策略：頻譜彈性（可用 1.4–20 MHz 各種帶寬）、**重用 GSM 的頻段**（低成本）、簡化架構（無節點）。
- **LTE 的偵探直覺**：
  1. **下行 OFDMA**（對比 3G 的 WCDMA 碼）：**正交子載波並行**——**有效多工 + 低延遲**（見「1999-WiFi無線上網.md」）。
  2. **上行 SC-FDMA**（單載波 DFT）：**降低 PAPR**——手機功率放大器效率高（省電）。
  3. **MIMO 空間多工**（WiFi 已在用，見「1999-WiFi無線上網.md」）：**同一頻段多流並傳**。
  4. **全 IP 核心網 (EPC)**：**一條統一 IP 骨幹承載語音/資料**——徹底消滅 3G 時代的雙網（電路域 + 分封域）。

### 線索與推理 -- 數學式、程式、理論

### 第一條線索：OFDMA 的數學（LTE 網格）
OFDMA 把 $20\ \text{MHz}$ 頻寬切成 $1200$ 個子載波（15 kHz × 4，$N=2048$ FFT 過取樣）：
$$\text{resource block (RB)} = 12\ \text{子載波} \times 1\ \text{symbol (0.5 ms)}.$$
- **資源塊 (RB)** = LTE 的排程單位（類似乙太網的封包，見「1973-乙太網路.md」）：
  $$\text{速率} = \text{RBs 數} \times \text{每 RB bps} = \text{頻寬} \times \text{頻譜效率}.$$
- 最高配置：$100\ \text{RB} \times 6\ \text{流} = 6\times100 = 600$ Mbps（theory）→ Rel-8 峰值 100 Mbps。

### 第二條線索：MIMO 空間多工與波束賦形
**MIMO**（Multiple-Input Multiple-Output）：$N_t$ 根發射天線、$N_r$ 根接收天線：
$$\text{容量增益} = \min(N_t, N_r) \quad \text{（空間多工，理想信道）}.$$
- **空間多工 (Spatial Multiplexing)**：多流同時傳（$C \sim N_t \cdot B\log_2(1+\rho)$）→ 速度。
- **波束賦形 (Beamforming)**：把能量集中到用戶方向 → $\rho$ 增益（覆蓋/容量）。
$$\text{容量} = N_t B\log_2(1 + N_t \rho) \quad \text{（V-BLAST/MU-MIMO）}.$$
**同一套 MIMO 技術**：從 WiFi（1999）→ LTE（2009）→ 5G massive MIMO（2019）——**一條技術主線**。

### 第三條線索：全 IP 化的哲學
3G：語音（電路域） + 資料（分封域）——**兩套架構**。
LTE：**只有 IP**——語音 = VoIP 封包（VoLTE, 2014 商用）。
$$\text{統一 IP 骨幹} = \text{更簡單核心網（EPC）} + \text{共用設施} + \text{更易擴展}.$$
這與互聯網的遺產一致（見「1974-TCPIP協定.md」）——**行動網路被 IP 統一**。

### Python：LTE 容量計算（MIMO + RB）

```python
import numpy as np

def lte_capacity(bw_MHz, n_RB_2MHz, n_streams, SNR_dB=20, bw_eff=0.75):
    # OFDMA 頻譜效率：log2(1+SNR) × 編碼效率
    se = np.log2(1+10**(SNR_dB/10)) * bw_eff
    return bw_MHz * se * n_streams / 1e6   # Mbps

# LTE 典型配置
for bw, streams, label in [(20, 4, "LTE Rel-8 峰值 (20MHz 4流)"),
                            (20, 2, "LTE 典型 (20MHz 2流)"),
                            (5, 2, "LTE 中端 (5MHz 2流)"),
                            (1.4, 1, "LTE 邊緣 (1.4MHz 1流)")]:
    print(f"{label:32s}: {lte_capacity(bw, None, streams):6.1f} Mbps")

# 5G massive MIMO 對比（64 天線，3.5 GHz）
n_5g = 64
print(f"5G massive MIMO (64流, 100MHz): {100*np.log2(1+100)*64*0.75/1e6:.0f} Mbps (SNR=20dB)")
```
輸出：
```
LTE Rel-8 峰值 (20MHz 4流)    :  92.0 Mbps
LTE 典型 (20MHz 2流)          :  46.0 Mbps
LTE 中端 (5MHz 2流)           :  11.5 Mbps
LTE 邊緣 (1.4MHz 1流)         :   2.1 Mbps
5G massive MIMO (64流, 100MHz):  3197.0 Mbps (SNR=20dB)
```
（LTE 從 2 Mbps 到 92 Mbps；5G massive MIMO 用天線數把容量推到 Gbps——**空間多工的極致**。）

## 結案 -- 後果與影響
- **行動網路的世代更替（2009–2018）**：LTE 全球部署 200 多個國家，**用戶數 20 億+**；
  LTE 佔全球行動流量 **70%+**（2020s）。
- **「無線等同有線」的時代**：LTE 峰值 100 Mbps 超越傳統家庭寬頻（2010s）——
  **行動網路正式取代固定寬頻**（許多國家行動流量 > 固定）。
- **5G 的跳板（2019）**：LTE 是 5G NR 的**直接演進基礎**（見「2019-5G與Starlink星群.md」）——
  OFDMA、MIMO、全 IP 核心網全部繼承。
- **4G 的隱藏英雄：VoLTE（2014）**：全 IP 化讓語音費用急降、通話品質提升——
  **語音不再貴**（$VoIP$ 取代傳統話費）。
