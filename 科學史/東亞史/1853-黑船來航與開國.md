# 1853-黑船來航與開國

## 案件摘要
1853 年 7 月，美國海軍准將佩里率四艘蒸汽黑船入浦賀——「黑船來航」；1854《日美和親條約》（下田、箱館開港）；1858《安政五國條約》（開港 + 領事裁判權 + 協定關稅）——日本開國。這樁「黑船」案件的偵辦重點：**外壓 = 改革的政治藉口**——「外壓現代化」模式：黑船給了改革者「攘夷的恐慌 → 開國的決斷」的政治空間；與清鴉片戰爭（1839 案）的對照——日本的「自覺學習」（蘭學 1774 案的知識準備 + 鴉片戰爭的前車之鑑——魏源《海國圖志》傳日）——**他人的失敗 = 自己的教材**。尊王攘夷 → 開國 → 幕末動亂 → 1868 明治維新（1868 案）的十年劇本。

## 前因 -- 為什麼會有這個案子
- **美國的需求**：捕鯨船的補給（北太平洋捕鯨）+ 太平洋航線（加州-上海）——「補給站 + 加煤站」的美國需求。
- **鴉片戰爭的前車之鑑**（1839 案）：1842 南京條約的消息傳日（魏源《海國圖志》1851 傳日）——「他人的失敗 = 自己的教材」。
- **蘭學的知識準備**（1774 案）：西洋知識（醫學、軍事、地圖）的民間積累——「知識的窗口已開」。
- **幕藩體制的財政疲弊**：參勤交代（1603 案）的財政壓縮 + 天保飢荒（1833-39）——「內部的疲弊」。

## 線索與推理 -- 數學式、理論、表格

### 線索一：外壓現代化的模式
「黑船 = 改革的政治藉口」：

| 階段 | 內容 |
|------|------|
| 外壓 | 佩里黑船（1853）——武力威懾 |
| 恐慌 | 「攘夷」的正當性（「外敵」的凝聚）|
| 轉向 | 「開國」的決斷（條約簽訂——1854/1858）|
| 內改 | 幕末動亂 → 王政復古（1868 案）|

**推理**：外壓 = 「改革的正當性來源」（攘夷 → 開國 → 維新）——「外壓現代化」的模式（費正清的衝擊-回應框架下的日本版）——但日本的不同：**蘭學的知識準備 + 鴉片的前車之鑑**讓「回應」的速度與深度不同——「外壓 × 知識準備」的乘積決定改革的成效。

### 線索二：與清的對照——回應速度的結構
| | 清（1839-60）| 日本（1853-68）|
|---|--------------|----------------|
| 首戰失敗 | 鴉片戰爭 | 黑船（未戰）|
| 開港 | 1842 五口 | 1858 五港 |
| 內部知識 | 考據學（西學邊緣）| 蘭學（西學制度化）|
| 改革 | 洋務（1861-，「中體西用」）| 維新（1868-，全面移植）|
| 條約改正 | 1943 英美放棄領事裁判 | 1894 日英通商航海條約 |

**推理**：清日的「回應速度差」——日本的蘭學基礎（1774 案）+ 幕藩體制的可替代性（大政奉還的制度彈性）vs 清的官僚帝國慣性（-221 案超穩定結構）——「知識準備 × 制度彈性 = 回應速度」——東亞「條約時代」的分岔。

### 線索三：尊王攘夷的政治學
幕末的政治工程：尊王攘夷（外壓 → 內部動員）→ 開國 → 討幕：

$$\text{攘夷（動員）} \to \text{薩英戰爭（1863）+ 下關炮擊（1864）的實證} \to \text{開國 + 討幕} \to \text{王政復古（1868）}$$

**推理**：攘夷 = 「內部動員的旗幟」（外壓 → 民族主義的動員——安德森的想像共同體的幕末版）——薩英、下關的「實證失敗」（攘夷不可行）→ 開國 + 討幕的轉向——「旗幟的轉換」：攘夷（動員）→ 開國（政策）——「民族主義 = 動員技術」。

### 線索四：不平等條約的結構
1858 安政五國條約的三件套：

| 條款 | 內容 | 效果 |
|------|------|------|
| 領事裁判權 | 外國人不受日本法 | 司法主權的喪失 |
| 協定關稅 | 關稅的協定（無自主權）| 財政與產業保護的喪失 |
| 最惠國條款 | 利益均霑 | 條約體系的複製 |

**推理**：不平等條約三件套（1839 案南京條約的結構複製）——「條約體系」的東亞化——條約改正（1894 日英）成為明治的外交目標——**主權的條約化**——「主權的可分割性」（領事裁判 = 司法主權的讓渡）。

## 結案 -- 後果與影響
- **幕藩體制的崩潰**：大政奉還（1867）→ 王政復古（1868）——幕府的終局——1868 案明治維新的舞台。
- **尊王攘夷的民族動員**：安德森的想像共同體（幕末版）——「天皇 = 民族的象徵」的重構。
- **條約改正的目標**：1894 日英通商航海條約（領事裁判權的廢除）——「主權的回復」——明治外交的主軸。
- **與清的分岔**：蘭學 × 制度彈性 = 回應速度——東亞「條約時代」的分岔——1895 案甲午的結局（日本的勝利）。
- **「前車之鑑」的知識傳播**：魏源《海國圖志》傳日——「他人的失敗 = 自己的教材」——東亞知識的跨國流動（書籍之路 754 案的近代版）。
