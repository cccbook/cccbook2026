# -108-漢四郡與漢字文化圈

## 案件摘要
前108 年，漢武帝滅衛滿朝鮮，設樂浪、玄菟、真番、臨屯四郡——漢字、鐵器與官僚技術第一次直接植入朝鮮半島。同期的前111 年，漢滅南越，越南北部進入千年郡縣時代（前111-938）。這樁「郡縣外擴」案件的偵辦重點：**官僚技術的輻射**——郡縣制（-221 案）的海外版本：漢字文書、郡縣行政、鐵器農具、漆器工藝沿四郡傳播——半島的部落聯盟（部落首長制）第一次接觸到「文字官僚國家」。樂浪郡四百年（前108-313）是東亞的「制度教室」——高句麗、百濟、新羅都在其旁邊學習國家組織。

## 前因 -- 為什麼會有這個案子
- **衛滿朝鮮的中介**：前195 燕人衛滿亡命朝鮮，推翻箕子系政權，建衛氏朝鮮（王儉城）——「中原亡命者建國」的模式；衛滿為漢的外臣，後斷絕。
- **漢武帝的擴張**：前221-前108 的帝國擴張期（北擊匈奴、南滅南越）——四郡是「北方前哨」的設計。
- **商路的動機**：樂浪控制半島-遼東的貿易（鐵、毛皮、人參）——「郡縣 = 貿易節點 + 軍事前哨」。
- **官僚技術的就緒**：漢的文書行政（簡牘）、度量衡、郡縣-縣-鄉里制——「可移植的國家作業系統」。

## 線索與推理 -- 數學式、理論、表格

### 線索一：郡縣制的移植結構
漢四郡的行政結構（簡牘與考古的重建）：

| 層級 | 機構 | 功能 |
|------|------|------|
| 郡 | 樂浪郡（太守）| 行政、軍事、貿易 |
| 縣 | 不而、吞列等 | 賦稅、戶籍 |
| 鄉里 | 土著豪長的收編 | 間接統治 |

**推理**：四郡的統治是「直接統治 + 土著收編」的混合——漢人官吏 + 半島土著的邑長（「三韓」的辰韓與樂浪交易）——**郡縣制的移植依賴土著中介**（-221 案的統治技術，加上了「異地統治」的結構）。

### 線索二：文字=官僚技術的輸送
樂浪出土的漆器銘文（「蜀郡西工」造、官吏署名）與木簡——漢字文書行政的實物證據：

| 技術 | 傳入 | 效果 |
|------|------|------|
| 漢字文書 | 前108- | 行政可記錄、可稽核 |
| 鐵器 | 前2 世紀 | 農具與武器（「鐵三角」貿易：辰韓產鐵）|
| 律令概念 | 前108- | 「法」與「官」的觀念傳入 |
| 漆器/織造 | 前1 世紀 | 工藝技術的移植 |

**推理**：文字的傳入是「官僚技術的硬體」（-3200 案文字=官僚的公式）——半島的國家形成（三國）以漢字行政為前提——**漢字文化圈的第一次安裝**。

### 線索三：三國的「學習」結構
高句麗（前37 建國，鴨綠江中游）、百濟（前18，漢江下游）、新羅（前57，慶州）——三國在四郡旁邊成長：

$$\text{國家形成的模板} = \text{郡縣的行政技術} + \text{鐵器軍事} + \text{土著動員}$$

- 高句麗：吸收玄菟/夫餘的組織 + 騎馬戰士 → 東北亞強國；
- 百濟：控制漢江（樂浪舊域）→ 海路聯南朝與倭 → 文化中轉站；
- 新羅：辰韓聯盟 → 遲起步但聯唐統一。

**推理**：三國都是「郡縣的鄰居學徒」——學習的方向（借力哪個中國王朝）決定三國的結盟與命運（663 白江口的伏筆）。

### 線索四：越南的平行案例
前111 漢滅南越（趙佗 204 建國）→ 交趾、九真、日南三郡——越南北部千年郡縣（前111-938）。與四郡平行：漢字、儒學（錫光的教化）、鐵器——**「兩翼植入」**：半島（北翼）與越南（南翼）是漢文化圈的兩個外部節點——後來兩地都「脫離郡縣但留在漢字圈」（高麗 918 王朝與越南 968 丁朝）。

## 結案 -- 後果與影響
- **漢字文化圈的地基**：四郡的漢字行政 → 三國的漢字國家 → 日本（經半島）——「漢字 = 東亞的拉丁文」（制度與文化的共同語）。
- **樂浪的四百年教室**：土城、漢墓、漆器——半島的「漢化」考古層——313 年樂浪滅亡後，其技術遺產流入高句麗與百濟。
- **三國競爭的起點**：借力中國的結構（663 白江口的千年伏筆）——半島的統一模式（聯外力）在此定調。
- **越南的千年北屬**：郡縣 → 獨立（938）→ 但漢字科舉持續到 1918——「制度可脫離，文字難脫離」的結構。
- **傳播模式的定調**：技術以「軍事-行政前哨」為節點傳播——東亞的「技術走廊」模式（稻作 → 漢字 → 佛教 → 律令 → 鐵炮）。
