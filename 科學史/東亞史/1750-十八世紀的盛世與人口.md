# 1750-十八世紀的盛世與人口

## 案件摘要
18 世紀，東亞三國同時迎來盛世：清朝康熙-乾隆（人口 1700 年約 1 億 → 1850 年 4 億——攤丁入畝 + 美洲作物 1550 案的擴散）；日本江戶元祿-化政文化（人口 3000 萬穩定、江戶百萬、大阪「天下的廚房」）；朝鮮肅宗-正祖（人口恢復與商業成長）。這樁「盛世」案件的偵辦重點：**盛世 = 剩餘的擴大 + 官僚的清明**（-221 案金觀濤超穩定結構的運轉期）；**馬爾薩斯的陰影**——人口對土地的擠壓（清的人口爆炸）與日本的「停滯平衡」（人口 3000 萬的穩定——堕胎與晚婚的節育文化）；**大分流**（彭慕蘭 2000）——18 世紀末東亞與西歐的對照——盛世的終局是十九世紀的危機（1780s 的飢荒、白蓮教 1796、幕末的動盪）。

## 前因 -- 為什麼會有這個案子
- **清朝的盛世工程**：攤丁入畝（1712 滋生人丁永不加賦 + 1720s 攤丁入畝）——「人丁稅的取消 → 人口自由增長」。
- **美洲作物的擴散**（1550 案）：玉米、番薯的丘陵山地開發——「邊際土地的人口承載」。
- **日本的停滯平衡**：元祿（1688-1704）-化政（1804-30）——「人口 3000 萬的穩定」（間引、晚婚的節育——「農村的人口控制」）。
- **朝鮮的恢復**：壬辰與胡亂的創傷後恢復（1700s 的商業化與人口回升）。

## 線索與推理 -- 數學式、理論、表格

### 線索一：三國盛世的對照
18 世紀的東亞三國：

| | 清 | 日本（江戶）| 朝鮮（李朝）|
|---|---|--------------|-------------|
| 人口 | 1 億 → 4 億（1700-1850）| 3000 萬穩定 | 700 萬 → 1500 萬 |
| 動力 | 攤丁入畝 + 美洲作物 | 節育文化（間引、晚婚）| 戰後恢復 + 商業化 |
| 城市 | 北京百萬 | 江戶百萬、大阪四十萬 | 漢城二十萬 |
| 文化 | 乾嘉考據 | 元祿-化政（町人文化）| 英祖-正祖的實學 |

**推理**：三國的「盛世」結構不同——清 = 人口爆炸型盛世（馬爾薩斯的擠壓）、日本 = 停滯平衡型（節育文化的社會控制）、朝鮮 = 恢復型——**盛世的類型學**（人口、文化、制度的組合差異）。

### 線索二：攤丁入畝 = 稅制的人口效果
攤丁入畝（1712-1729）的經濟邏輯：

$$\text{丁稅（人頭稅）} \to \text{併入田賦（財產稅）} \implies \text{生育的人頭成本歸零} \implies \text{人口爆炸}$$

**推理**：人頭稅 → 財產稅的轉換——「生育的自由化」（多生不增稅）——人口從 1 億到 4 億——**稅制 = 人口政策**（「生育成本的制度設計」）——馬爾薩斯（1798）的「人口幾何級增長」在清的實證。

### 線索三：日本的節育文化
江戶日本的「停滯平衡」（人口 3000 萬的穩定）：

| 機制 | 內容 |
|------|------|
| 晚婚 | 男女初婚 20+ 歲 |
| 間引（堕胎/殺嬰）| 農村的節育（「農村的人口控制」）|
| 非婚生育低 | 婚外生子少 |
| 出稼 | 城市打工（人口流出）|

**推理**：日本的「人口控制文化」（間引與晚婚）——「文化 = 人口政策」——人口 3000 萬的兩百年穩定——**盛世的兩型：清的爆炸型 vs 日本的控制型**——「馬爾薩斯的兩種對策」（中國：放任增長；日本：文化節育）——社會結構的分岔。

### 線索四：大分流的對照
彭慕蘭（Kenneth Pomeranz, 2000）《大分流》：18 世紀末長三角與英格蘭的人均生活水準相近——分流的關鍵：

| | 長三角 | 英格蘭 |
|---|--------|--------|
| 18 世紀末 | 相近（煤 + 殖民地之前的對照）| 相近 |
| 分流原因 | 缺煤（近煤的機運）+ 殖民地 | 煤 + 美洲資源（「鬼田」ghost acres）|

**推理**：18 世紀的東亞盛世與西歐「分流」——彭慕蘭的「資源與煤」論（爭議中）——**盛世的終局**：清的人口擠壓（4 億 + 土地極限）+ 歐洲的工業化 → 19 世紀的「大分流」——1839 案鴉片戰爭的經濟背景。

## 結案 -- 後果與影響
- **盛世的雙面**：清的人口爆炸（4 億）= 農業的極限擠壓（人均耕地從 5 畝跌到 2 畝）——「盛世的陰影 = 十九世紀危機」。
- **白蓮教起義（1796-1804）**：人口壓力 + 官僚腐化——「盛世的終局」——清的轉折。
- **日本的停滯與幕末**：化政文化（1804-30）的繁榮 + 財政危機（藩的債務）——1853 案黑船的內部條件。
- **朝鮮的實學**：英祖-正祖（1724-1800）的實學改革動機（茶山丁若鏞）——1780 案北學派的時代。
- **大分流的世界史**：18 世紀末的對照 → 19 世紀的分流——「東亞盛世 → 西方衝擊」的結構轉換。
