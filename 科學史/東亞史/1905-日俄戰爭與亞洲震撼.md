# 1905-日俄戰爭與亞洲震撼

## 案件摘要
1904-05 年日俄戰爭：旅順攻防、奉天會戰、日本海海戰（東鄉平八郎的 T 字戰法）——1905/9 樸茨茅斯和約（南滿鐵路、關東州租借、樺太南半）——「有色人種首次擊敗白人大帝國」。同年期 1905/11《乙巳條約》（第二次日韓協約）——朝鮮成為日本保護國（伊藤博文統監）。這樁「震撼」案件的偵辦重點：**亞洲的震撼**——甘地（「日本的勝利震醒了我」）、孫文、青年土耳其、波斯立憲——「日俄戰爭 = 亞洲民族主義的催化」（Erez Manela 的「威爾遜時刻」的前奏）；**帝國地圖的重畫**——日本帝國的亞洲化（南滿、朝鮮、關東州）。

## 前因 -- 為什麼會有這個案子
- **俄日的滿洲對抗**：三國干涉（1895）後的俄國南下（東清鐵路、旅順租借 1898）——「滿洲的雙雄對峙」。
- **英日同盟**（1902）：日本的國際背書（「以夷制夷」的日本版）——「同盟 = 戰爭的許可」。
- **朝鮮的爭奪**：高宗俄館播遷（1896）→ 乙巳（1905）——「朝鮮的帝國拉鋸」（1895 案的後續）。
- **日本的海軍建設**：六六艦隊（英國式）——「海軍 = 帝國的基礎」。

## 線索與推理 -- 數學式、理論、表格

### 線索一：亞洲的震撼——心理的政治學
日俄戰爭的亞洲效應：

| 地區 | 效應 |
|------|------|
| 印度 | 甘地：「日本的勝利震醒了我」（1906 南非的抵抗）|
| 中國 | 「立憲戰勝專制」的解讀 → 1906 預備立憲 |
| 波斯 | 1906 立憲革命 |
| 鄂圖曼 | 1908 青年土耳其革命 |
| 越南 | 潘佩珠《越南亡國史》與東遊運動（1905-08）|

**推理**：「日俄戰爭 = 亞洲的震撼」——「白人的不可戰勝」神話的崩潰（Manela 的「威爾遜時刻」的前奏）——**勝利 = 想像的資源**（有色人種的自尊——安德森的民族主義的心理結構）——「戰爭的心理紅利」（1919 案威爾遜時刻的先聲）。

### 線索二：帝國地圖的重畫
樸茨茅斯與乙巳的帝國地圖：

| 領域 | 內容 | 性質 |
|------|------|------|
| 南滿 | 南滿鐵路（長春-旅順）+ 關東州租借 | 租借地 + 鐵路附屬地 |
| 樺太 | 北緯 50 度以南 | 割讓 |
| 朝鮮 | 乙巳條約（保護國）——統監府 | 保護國 |
| 庫頁/滿洲 | 俄的承認 | 勢力範圍 |

**推理**：日本帝國的「亞洲化」——「保護國 → 合併」的階梯（1910 案）——「殖民帝國的亞洲執行者」——**帝國主義的亞洲化**（歐洲列強的模式被日本執行）——東亞帝國地圖（台灣 1895、朝鮮 1910、南滿、關東州）。

### 線索三：日本的勝利結構
日俄戰爭的軍事與財政：

| 面向 | 數據 |
|------|------|
| 戰費 | 17 億日元（外債 8 億——英美的金融）|
| 死傷 | 8.5 萬戰死 + 40 萬傷 |
| 賠款 | **無**（樸茨茅斯的「無賠款」）|

**推理**：勝利但無賠款——「財政的極限」（外債 = 英美金融的支撐——「同盟 = 金融」）——日比谷燒打事件（1905/9 條約的國內暴動）——「勝利的代價」——「無賠款的勝利」成為日本外交的教訓（後來的「賠款」執念——1919 凡爾賽的德國處理）。

### 線索四：亞洲知識人的「日本路線」
亞洲知識人的重估：

$$\text{「白人不可勝」的崩潰} \implies \text{「日本模式」的學習} \implies \text{「立憲 + 軍事」的路線}$$

**推理**：日本成為亞洲的「模範」（立憲 + 軍事 + 工業化）——「亞洲的近代 = 日本式」的想像（後來的「大東亞」的知識根源——潘佩珠的東遊）——「模範的雙面」（解放的想像 → 帝國的現實——1937 案大東亞共榮圈的知識史前奏）。

## 結案 -- 後果與影響
- **帝國地圖的重畫**：南滿、關東州、朝鮮保護國——日本帝國的亞洲骨架——1910 案合併的直前。
- **亞洲民族主義的催化**：甘地、孫文、東遊運動——「震撼的心理紅利」——1919 案威爾遜時刻的先聲。
- **清的立憲企圖**：1906 預備立憲——「勝者的啟發」（立憲 = 強國的解讀）——1911 辛亥的政治背景。
- **日本的金融帝國**：外債（英美的金融）→ 滿鐵（南滿鐵路的殖民經濟）——「金融 + 殖民」的帝國經濟。
- **「無賠款的教訓」**：日比谷燒打——「勝利者的分配」——帝國外交的內部張力。
