# a2-少子化的引擎

> 樹根節點（起火點：人口）——**如果少子化的引擎持續全開發生**，下游分岔：[b1-女性高學歷與機會成本](b1-女性高學歷與機會成本/)、[b2-iPhone與數位生活](b2-iPhone與數位生活/)、[b3-工商業對單身者的支持](b3-工商業對單身者的支持/)、[b4-AI陪伴的雙面](b4-AI陪伴的雙面/)。

## 案件摘要

東亞總生育率（TFR）已跌到人類史無前例：韓國約 0.7、台灣約 0.87、中國約 1.0–1.2、日本約 1.2。少子化不是單一原因，是**六台引擎同時運轉**：女性高學歷的機會成本、iPhone 與數位生活、工商業對單身者的支持（solo economy）、居住與教養成本、規範鬆動、AI 陪伴——如果它們持續全開，人口的曲線會一路下探。

## 起火點 -- 現況證據與觸發條件

- **證據**：一人戶占比（韓 35%、日 38%、台 36%+）；初婚年齡（韓男 34/女 33）；結婚率持續下降；韓國數百兆韓元的政策投入成效有限。
- **觸發條件**：引擎不變＋「世代規模縮小」的動態（適婚人口↓→即使 TFR 不變、出生數也崩）。

## 傳導與理論

生育是「相對價格」的決策（[1769-瓦特蒸汽機與工業革命](../世界史/1769-瓦特蒸汽機與工業革命.md) 的「採用是相對價格的函數」同一邏輯）：

$$\text{生育意願} \propto \frac{1}{\text{生育的機會成本}} \quad \text{機會成本} = f(\text{教育年限}, \text{薪資}, \text{職涯中斷代價})$$

**北歐反例是關鍵**：高女性就業＋相對較高生育率（1.6–1.8）——差異變數不是教育，是「**工作與家庭的可相容性**」。

## 分岔的條件（若…否則…）

| 環節 | 若 | 否則 |
|------|-----|------|
| 可相容性 | 托育＋男性分擔＋職場彈性的工程→回升（c1） | 僵化持續→下探（c2） |
| solo economy | 商業的單身供給持續→正回饋（鏈條自我強化） | 育兒可負擔的均衡→高原 |
| AI 的角色 | 陪伴（替代）強於育兒輔助（支撐）→加深 | 輔助強於替代→回升 |

## 觀察指標

- TFR 年度值、結婚率與初婚年齡、一人戶占比。
- 托育支出占 GDP 與男性育嬰假使用率（可相容性的量測）。
- 單人經濟（一人份食品、單人旅遊）的市場規模。
- 交友軟體滲透率與「長期配對成功率」。

## 不確定性

- 規範可以反轉（戰後嬰兒潮先例），但需「事件+意義」的組合——今日的等價事件未知。
- 六台引擎的證據等級不一（機會成本最強、iPhone 因果最弱）——排序應隨資料更新。
