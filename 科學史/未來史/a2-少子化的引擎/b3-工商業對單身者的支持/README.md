# b3-工商業對單身者的支持

> [a2-少子化的引擎](../) 的下游節點——**如果工商業對單身者的支持（solo economy）持續擴張發生**，下游分岔：[c1-單身舒適化正回饋](c1-單身舒適化正回饋/)、[c2-婚育從必需變選項](c2-婚育從必需變選項/)。

## 這個節點（如果發生）是什麼

工商業對「單身生活」的供給革命：一人份餐點、小宅、單人旅遊、單人保險、寵物經濟、AI 陪伴——單身生活的舒適度↑、成本↓，婚姻與生育的相對吸引力↓。**這是少子化六台引擎中唯一自我強化、不會自行停止的一台**。

## 傳導與理論

正回饋迴路（本書的核心洞見）：

```
越多人單身 → 單身市場越大 → 單身產品越精緻 → 單身越舒適 → 越少人結婚
```

歷史類比：汽車與郊區（[機器史/1913-福特流水線](../../../機器史/1913-福特流水線.md)）——**商業不是跟著生活方式走，是與生活方式共同演化**：量產汽車創造郊區，郊區創造汽車需求。

## 下游分岔（若…否則…）

| 環節 | 若 | 否則 |
|------|-----|------|
| 回饋迴路 | 持續運轉→單身舒適化（c1） | 育兒可負擔的均衡（成本拉平）→高原 |
| 婚育的定位 | 從必需變選項（c2）——規範的重寫 | 「家庭」仍是規範的核心→solo 只減成本 |

## 觀察指標

- 一人份產品與單人服務的市場規模（餐飲、旅遊、保險、住宅）。
- 寵物經濟與 AI 陪伴的成長（「替代性家庭」的份額）。
- 單身者的「生活滿意度」調查（舒適化的實證）。

## 不確定性

- 回饋迴路的「天花板」：如果育兒的成本也下降（a2/b4/c2 的反向鏈），兩者的均衡會出現——迴路不是永動機。
