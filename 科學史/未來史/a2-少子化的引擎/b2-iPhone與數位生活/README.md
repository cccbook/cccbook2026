# b2-iPhone與數位生活

> [a2-少子化的引擎](../) 的下游節點——**如果 iPhone 與數位生活重塑社交與求偶發生**，下游分岔：[c1-交友軟體悖論](c1-交友軟體悖論/)、[c2-娛樂替代與繭居](c2-娛樂替代與繭居/)。

## 這個節點（如果發生）是什麼

智慧手機重塑了求偶與社交的三個機制：娛樂替代（在家的滿足↑→社交動機↓）、交友軟體的選擇悖論（選擇爆炸→不承諾）、注意力掠奪（短影音吃掉社交時間）。如果這三個機制持續，婚育的「前置行為」（社交、約會）本身就萎縮了。

## 傳導與理論

Schwartz 的選擇悖論：

$$\text{承諾的成本} \propto \text{（放棄的其他選項的想像價值）} \quad \text{（選擇越多→承諾越難）}$$

注意力經濟（[世界史/2023-生成式AI與資訊社會](../../../世界史/2023-生成式AI與資訊社會.md)）：內容供給→無限，注意力有限——社交時間被娛樂擠出。

**證據等級誠實標注**：技術因果最弱（相關≠因果；文化變遷與智慧手機同期）——本節點是「疑犯」而非「定罪」。

## 下游分岔（若…否則…）

| 環節 | 若 | 否則 |
|------|-----|------|
| 平台設計 | 黏性優先（演算法餵娛樂）→繭居加深（c2） | 「橋樑型」設計（推薦真人活動）→社交回歸 |
| 交友軟體 | 選擇悖論持續→不承諾（c1） | 撮合的科學化（配對優化）→承諾回升 |
| 規範 | 「線上社交=社交」的規範化→真實社交萎縮 | 「面對面」的價值重估（文化反彈）→回歸 |

## 觀察指標

- 交友軟體的付費率與「配對→見面→承諾」的轉化漏斗。
- 青年世代的「出門時數」與社交活動統計。
- 平台設計的走向（黏性 vs 橋樑）。

## 不確定性

- 文化反彈（「數位排毒」、面對面的價值重估）可能截斷本節點——歷史上技術的社會適應常被低估。
- 因果的證據最弱——本節點可能是「同期現象」而非「原因」。
