# c1-可相容性工程與生育率回升

> 樹葉節點：[a2/b1-女性高學歷與機會成本](../../) 的終點——**如果可相容性工程與生育率回升發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 人口 | 生育率向 1.6–1.8 回升（法國/北歐的高原）——「下探」停止 |
| 經濟 | 女性勞動參與率跳升（機會成本下降）；托育與家務產業的崛起 |
| 財政 | 生育政策從現金津貼轉向「工具與制度補貼」——年金的長期緩解（人口動量修復要 20 年） |
| 社會 | 性別分工的重構（男性家務的常態化）——「家務的社會化」 |
| 心理 | 「生得起也養得起」的信心回復——婚育規範的止跌 |

## 上游（傳導回顧）

機會成本（b1）→「可相容性」是唯一槓桿→托育+男性分擔+彈性工時的工程→生育的相對價格改善→回升。

## 觀察指標

- TFR 的回升（先在托育充裕的都會區出現）。
- 男性育嬰假使用率與家務時數的性別差距。
- 國家生育政策的「工具化」轉向（立法）。

## 不確定性

- 回升的「高原」不是嬰兒潮——1.6–1.8 是上限的估計（北歐先驗）。
- 人口動量的滯後：即使回升，勞動市場要 20 年後才感受——**本節點的紅利是下一代人的**。
