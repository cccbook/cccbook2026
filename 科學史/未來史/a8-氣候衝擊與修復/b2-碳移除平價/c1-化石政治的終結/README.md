# c1-化石政治的終結

> 樹葉節點：[a8/b2-碳移除平價](../../) 的終點——**如果化石政治的終結發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 政治 | 產油國的重構：油氣財政的斷崖——「石油美元」與「油氣威權」的雙重黃昏（與 [a4/b1/c2-美元儲備地位動搖](../../../a4-美國債務懸崖/b1-財政主導/c2-美元儲備地位動搖/) 的去美元化共振） |
| 環境 | 「修復軌道」：累積碳的逐年削減——1.5°C 的「回頭」可能 |
| 地緣 | 能源地緣的重排：油氣的槓桿→電力與關鍵礦物的槓桿——「誰控制能源供應鏈」的答案重寫 |
| 經濟 | 碳移除產業（千億美元級）與碳信用的金融化；化石資產的擱淺 |
| 跨鏈 | 與 [a8/b3-地球工程](../b3-地球工程/) 互補：DAC（慢、穩、可治理）vs SRM（快、險、單方）的兩條修復路 |

## 上游（傳導回顧）

碳移除平價（b2）→大氣的碳可管理→「禁令政治」→「工程政治」——化石燃料的政治槓桿瓦解（[1869-蘇伊士與全球化](../../../世界史/1869-蘇伊士與全球化.md) 的「能源=地緣槓桿」規律的反向）。

## 觀察指標

- 產油國的轉型投資（太陽能、氫）與油氣財政的依賴度。
- 碳信用市場的規模與品質。
- 能源地緣的新槓桿（礦物、電網）的談判。

## 不確定性

- 化石政治的「黃昏」可能被新用途（石化原料、軍事）延後——終結不必然。
- 產油國的「轉型 vs 阻撓」的選擇——政治的混沌。
