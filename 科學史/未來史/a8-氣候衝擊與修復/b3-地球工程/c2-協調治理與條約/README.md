## 上游（傳導回顧）

地球工程（b3）的誘惑與風險→「單方動用」的恐懼使各方尋求條約——**危機的教訓+查證的技術+均衡的利益**三者齊備（軍控三條件的氣候版）。

## 觀察指標

- 國際 SRM 條約的談判進度（禁止/管制/配額）。
- 氣候治理機構（監測與稽核）的成立。
- 「痛苦換制度」的前置災害的發生。

## 不確定性

- 條約可能是「弱者的條約」（缺席者）——治理可能是部分的。
- 「災難的教訓」的累積速度慢（氣候是緩慢的）——條約的時點難以推演。
