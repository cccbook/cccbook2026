# 未來史 -- AI 偵探風格

> 未來無法用年份標記——**時間無法確定，因果可以推理。**
> 本書是一棵**因果樹**：資料夾的層級就是因果的層級。
> - 第一層（a1、a2…）：**起火點**——「如果某件事情發生」；
> - 第二層（a1/b1、a1/b2…）：它造成的第一步後果（分岔）；
> - 第三層（a1/b1/c1、a1/b1/c2…）：後果的後果（再分岔）。
>
> 每個節點都是一篇「推理探案」：從現況證據出發，推演「如果這件事發生，整個世界會有什麼變化」，並在每一步標注「若…否則…」的分岔——**因果鏈從來不是單線，是樹；而這本書本身就是那棵樹。**

（涵蓋：AI 與勞動、少子化的引擎（iPhone、女性高學歷、單人經濟）、AI 陪伴、AI 治理與法律、美國債務、台海與晶片、戰爭形態、壽命與老齡化、氣候）

## 方法論

1. **不武斷**：不寫「X 年會發生 Y」；只寫「如果 A 發生」＋觸發條件＋觀察指標。
2. **不單線**：每個節點都有分岔（子資料夾）；互斥的枝幹並列（例如「AI 陪伴→少子化加深」與「AI 育兒輔助→生育率回升」）。
3. **不孤立**：節點之間以「交叉」連結——因果樹是網路。
4. **理論優先**：每個節點寫出背後的理論（數學式、學術理論、表格），必要時才用範例——不硬寫程式。

## 樹枝之間的交叉（樹是網路）

- 「a2/b4-AI陪伴」餵養「a6/b1-兵源稀缺」（少子化→兵源）與「a7/b2-老齡化加深」（少子化→年金）。
- 「a4/b2-殖利率失控」與「a5-台海封鎖」互相放大（財政危機中的封鎖承受力更低）。
- 「a3/b1-生成內容爆炸」使「a3/b2-治理真空」更難修復（法律的執行依賴證據與共識）。
- 「a1/b1-學徒階梯斷裂」與「a7/b1/c2-繼承延後」是**同一條「青年階梯斷裂」**的兩個來源（職業階梯＋財富階梯）。
- 「a8/b2-碳移除平價」與「a8/b3-地球工程」是修復的兩條路（慢而穩 vs 快而險）。

## 閱讀方式

- 從任一樹根（a 節點）往下讀：每個節點是「如果這件事發生」的推理探案——現況證據→傳導與理論→分岔（若…否則…）→觀察指標→不確定性。
- 樹葉（c 節點）是鏈條的終點：寫的是「這個終點發生後，整個世界的變化總帳」。
- 用各節點的**觀察指標**追蹤現實：未來不是等來的，是查出來的。

本書與 [世界史]（多因咬合的過去）、[武器與戰法]（武器→戰法）、[科技發展史]（金觀濤的理論—實驗—技術循環）互補：**過去看迴路，未來推迴路**——過去的迴路自我完成，未來的迴路正在分岔；讀懂哪條迴路被點火，就讀懂了樹往哪邊長。
