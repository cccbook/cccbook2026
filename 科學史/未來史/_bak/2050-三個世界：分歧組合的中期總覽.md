# 2050-三個世界：分歧組合的中期總覽

> 通道：全通道（收束 2026–2048 的分歧點，組合成三個內部一致的世界——「座標系」不是「預言」）

## 案件摘要

本篇收束 A–K 的分歧點，組合成 **2050 的三個典型世界**——偵探的方法：把各分歧點的枝幹**交叉組合**，取三個內部一致的組合作為「情境座標系」。

## 組合規則：分歧點的相依結構

各分歧點不是獨立的——有相依結構：

```
衝突（B2/B3） ──→ 算力瓶頸（A3）＋轉型放緩（E2）＋財政危機（D3/I3）
AI 紅利（A1） ──→ 軟著陸（I1）＋老齡補償（L1）＋轉型加速（E1）
治理滯後（F2/K2） ──→ 戰爭形態（G1/G3）＋信任崩潰（C2）
少子化下探（H1） ──→ 兵源稀缺→機器化（G1）＋年金擠壓（L2/I2）
```

## 三個典型世界

| | 世界一：寬鬆的富足 | 世界二：緊張的分裂 | 世界三：動盪的重置 |
|---|---------------------|----------------------|----------------------|
| 組合 | A1+B1+C1+I1+E1+F1+H2 | A2+B1/F2+C3+I2+E2+F3+H1 | B2/B3+A3+I3+E2/E3+G3+H1 |
| AI | 生產力紅利、漸進吸收 | 加速取代、階級緊張 | 瓶頸或突跳的極端 |
| 人口 | 少子化高原、老齡補償成功 | 少子化下探、單人圈層化 | 兵源與年金的懸崖 |
| 地緣 | 競而不戰、投資依賴 | 對峙固化、經濟圈化 | 衝突與斷鏈 |
| 氣候 | 轉型軌道（1.8–2.0°C） | 現行軌道（2.5°C） | 適應與危機 |
| 貨幣 | 美元+數位延伸 | 區域貨幣圈 | 危機重置 |
| 法律 | 跟上（K1） | 分裂（K3） | 滯後（K2） |
| 心理 | 信任緩慢重建 | 極化與圈層化 | 恐慌與重置 |

## 各世界的推演

### 世界一：寬鬆的富足

- **條件**：AI 紅利兌現＋地緣競而不戰＋轉型瓶頸突破＋少子化高原。
- **先驗**：1990s 的「長和平+紅利」——但**穩定孕育不穩定**（[2008-金融海嘯](../世界史/2008-金融海嘯.md) 的明斯基）——富足中的自滿是內建風險。

### 世界二：緊張的分裂

- **條件**：AI 加速取代＋經濟圈化＋信任圈層化＋生物與認知的不平等（[2033] 的 G2、[2070] 的 R2）。
- **先驗**：冷戰 1.0 的「平行世界」＋1930s 的集團化（[1929]）——分裂的成本。

### 世界三：動盪的重置

- **條件**：衝突觸發斷鏈→財政與貨幣危機→制度重置。
- **先驗**：1914 的「連接深度=斷裂深度」（[1869-蘇伊士與全球化](../世界史/1869-蘇伊士與全球化.md)）＋1930s 的「蕭條→政治重構」（[1929]）——**重置後的制度是下一個世界的地基**（[1945] 的「痛苦換制度」）。

## 交叉與不確定性

- 三個世界不是「三選一的預言」——**現實是混合與震盪**（十年內在不同世界間擺動；區域間分化）。
- 低機率高衝擊的尾端（熱戰、臨界連鎖、AGI 突跳）不在「典型世界」內——**尾端風險無法組合成「典型」**。

## 觀察指標

2050 的世界由 2030s 的累積決定——指標見各篇（[2026]、[2029]、[2030]、[2035]、[2046]）。本篇無新指標，只有組合規則。

## 不確定性與未解

- 混合與震盪是常態——三個典型世界是「座標系」。
- 相依結構（箭頭）有漏——偵探的卷宗在 2050 之前不可能完全偵破。
