# c2-美元儲備地位動搖

> 樹葉節點：[a4/b1-財政主導](../../) 的終點——**如果美元儲備地位動搖發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 經濟 | 「通膨稀釋=對債權人的部分違約」——外國央行儲備的配置轉移（黃金、實物、非美元結算） |
| 地緣 | 去美元化從論述變制度：區域結算、CBDC 互操作、黃金儲備——**動搖是緩慢斜坡**（美元網路效應延遲取代） |
| 財政 | 美國的借款成本上升（特權侵蝕）——與 [a4/b2-殖利率失控](../b2-殖利率失控/) 的路徑部分匯合 |
| 法律 | 清算網路（SWIFT）的「武器化」與繞道——與 [a5-台海封鎖](../../a5-台海封鎖/) 的制裁戰交叉 |
| 跨鏈 | 與 [a8/b1-保險退潮](../../a8-氣候衝擊與修復/b1-保險退潮/) 無直接關聯，但「美元資產的重估」影響全球財政 |

## 上游（傳導回顧）

通膨稀釋（c1）→「失信」疊加「制裁的武器化」→儲備多元化的動力累積——**「過度特權」的慢性侵蝕**。

## 觀察指標

- 外國央行的黃金與非美元儲備占比（斜坡的斜率）。
- 區域本幣結算與 CBDC 互操作的落地。
- 美債外國持有的持續下降。

## 不確定性

- 美元的網路效應（清算深度、債券市場、法治）延遲取代——動搖可能在十年尺度不可見。
- 「缺乏可信替代品」——人民幣的資本管制、歐元的政治碎片——動搖可能停在「緩降」。
