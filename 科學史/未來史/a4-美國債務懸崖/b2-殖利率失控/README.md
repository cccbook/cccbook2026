# b2-殖利率失控

> [a4-美國債務懸崖](../) 的下游節點——**如果美債殖利率失控發生**，下游分岔：[c1-市場強制緊縮](c1-市場強制緊縮/)、[c2-美元特權反噬](c2-美元特權反噬/)。

## 這個節點（如果發生）是什麼

債券市場的「義勇軍」（bond vigilantes）發動：發行量暴增+買家缺位→期限溢價飆升→10 年期殖利率破心理門檻→**市場使政治做政治上做不到的事**（緊縮與加稅）。英國 2022 mini-budget 的先驗：數日內完成政策的反轉。

## 傳導與理論

利息的「梯」：

$$\text{利息支出} = \text{債務} \times \text{平均利率} \quad \text{（到期重訂價使利息逐段升高）}$$

與 [a4/b1-財政主導](../b1-財政主導/) 互斥：這裡是**市場先動**（信心轉折）、政治被動；財政主導是政治先動、市場跟隨。

## 下游分岔（若…否則…）

| 環節 | 若 | 否則 |
|------|-----|------|
| 聯準會的選擇 | 購債救市（財政貨幣化）→通膨+信心二次危機 | 不購債→流動性危機→衰退更深 |
| 政治的反應 | 危機團結→緊縮止血（劇痛） | 政治僵局→失控持續（市場再逼） |
| 美元的地位 | 避風港仍成立（危機中買盤）→特權延續 | 避風港失效（美元不漲反跌）→特權反噬（c2） |

## 觀察指標

- 10 年期殖利率與期限溢價的「跳升」事件。
- 美債拍賣的「買家缺席」與尾差擴大。
- 利息支出超過國防預算的時點。

## 不確定性

- 「避風港的反諷」：歷史上美債危機反而吸引買盤——失控可能遲遲不來（本節點可能長期不觸發）。
