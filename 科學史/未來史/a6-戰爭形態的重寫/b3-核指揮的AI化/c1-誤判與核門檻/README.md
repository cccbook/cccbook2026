## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 全球 | 情境一（跨越）：小規模戰術核武使用——**七十年禁忌的首次破裂**（[武器與戰法/1945-廣島與核時代](../../../武器與戰法/1945-廣島與核時代.md) 的核禁忌）——擴散與使用的常態化風險 |

| 軍事 | 核使用的「先例」改寫一切威懾算式；小當量戰術核武的「可用化」討論 |
| 法律 | 核與 AI 的責任真空（誰下達、誰執行、誰負責）——與 [a3/b2-治理真空](../../../a3-AI治理與法律/b2-治理真空擴大/) 咬合 |
| 心理 | 核焦慮的世代回歸；「末日鐘」的心理學 |

## 上游（傳導回顧）

核指揮 AI 化（b3）→誤判（演習/故障/干擾被讀為攻擊）→決策時間壓縮下「人類無法審核」→**門檻跨越**。

## 觀察指標

- 「險釀」事件的通報（誤判的統計基數）。
- 戰術核武的「可用化」論述（低當量的政治包裝）。
- 大國的危機熱線與「不對稱升級」的溝通。

## 不確定性

- 跨越後的世界無歷史先驗（核禁忌破裂的後果鏈無法從 1945 推演）——**本書最大的未解**。
- 「不對稱升級」的克制 vs 對稱升級——單一決策的混沌。
