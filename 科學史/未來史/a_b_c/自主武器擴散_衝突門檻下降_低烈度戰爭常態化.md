# 自主武器擴散_衝突門檻下降_低烈度戰爭常態化

## 案件摘要

**如果自主武器擴散發生，就會造成「衝突門檻下降」，進而造成「低烈度戰爭常態化」**——自主武器使「傷亡成本」→己方零、形象成本下降；衝突的「價格」下跌→使用率上升。這條鏈的終點是：戰爭從「例外狀態」變成「常態工具」——灰域的軍事化。

## 起火點 -- 如果自主武器擴散發生

- **現況證據**：軍用 AI 的目標獲取已實戰（烏俄）；自主武器的條約討論（LAWS）停滯；無人機的非國家行為者使用（葉門、緬甸的先例）。
- **觸發條件**：自主武器的量產與擴散（與 [兵源稀缺_無人機量產_軍隊無人化](兵源稀缺_無人機量產_軍隊無人化.md) 咬合）＋非國家行為者的可得＋「無傷亡戰爭」的政治誘惑。

## 連鎖推演 -- A→B→C

### 第一步：自主武器擴散（科技⇒軍事⇒社會）

- 擴散的路徑：國家軍隊→盟友→市場→非國家行為者——**「禁忌的失效條件」**（[武器與戰法/1943-大西洋狼群與反潛](../武器與戰法/1943-大西洋狼群與反潛.md) 的先驗：非國家行為者使「報復可信」失效→禁忌的支撐腿被抽掉）。

### 第二步：衝突門檻下降（軍事⇒政治）

衝突門檻的算式：

$$\text{衝突意願} \propto \frac{\text{預期收益}}{\text{（傷亡成本）} + \text{（法律與形象成本）}}$$

- 自主武器使「傷亡成本」→己方零——**分母的歷史性縮小**。
- 「無人戰爭」的政治容忍度上升：無棺木回國→無反戰運動→**戰爭的「去人性」改變政治的約束**。

### 第三步：低烈度戰爭常態化（政治⇒社會⇒法律）

- 「常態工具」的時代：邊界摩擦、海上檢疫、無人機互射——**低於戰爭門檻的武力成為外交的延續**（與 [武器與戰法/2007-震網與網路戰](../武器與戰法/2007-震網與網路戰.md) 的灰域戰爭同構）。
- 與 [ai責任無法可管_治理真空擴大_制度速度的敗退](ai責任無法可管_治理真空擴大_制度速度的敗退.md) 咬合：法律的真空使「常態化」無約束。

## 分岔 -- 每一步的「若…否則…」

| 環節 | 若 | 否則 |
|------|-----|------|
| 傷亡的不對稱 | 己方零傷亡的政治誘惑→常態化 | 一次「自殺式自主武器」的災難（平民大量死亡）→道德反彈、條約動員 |
| 條約的時機 | 常態化之前的預防性條約（罕見的歷史先例）→門檻維持 | 常態化之後→條約追認現實（門檻鎖定在低位） |
| 社會的約束 | 「無人戰爭」的媒體疲乏→容忍 | 一次「直播的自主屠殺」→道德門檻回升 |

## 整個世界的變化

| 領域 | 變化 |
|------|------|
| 軍事 | 低烈度衝突的常態化；「戰爭與和平」的邊界模糊 |
| 政治 | 武力的「外交工具化」；威懾的再定義（無人戰爭的威懾算式） |
| 法律 | 國際人道法的適用危機（自主武器+責任真空）——與 [2046] 咬合 |
| 社會 | 「戰爭的常態感」——遠方的衝突成為背景噪音（媒體的疲乏） |
| 心理 | 「無人戰爭」的道德鈍化 vs 一次災難的道德反彈（鐘擺） |

## 觀察指標

- 自主武器的條約談判進度（停滯=常態化的時間窗）。
- 低烈度衝突（無人機互射、海上檢疫）的年發生次數趨勢。
- 「無傷亡軍事行動」的公開報導與政治反應（容忍度的量測）。
- 非國家行為者的自主武器使用案例。

## 不確定性

- 「一次災難的道德反彈」可能翻轉鏈條（毒氣的歷史先驗：1915–25 從使用到禁忌）——**鐘擺的方向由單一事件決定**。
- 低烈度常態化可能滑向高烈度（升級的失控）——本鏈與 [自主武器誤判_核門檻跨越_嚇阻體系重構](自主武器誤判_核門檻跨越_嚇阻體系重構.md) 的交界。
