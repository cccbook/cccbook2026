# 氣候升溫_保險退潮_不可保地帶擴張

## 案件摘要

**如果氣候升溫持續發生，就會造成「保險退潮」，進而造成「不可保地帶擴張」**——保險是氣候風險的「即時定價器」：極端天氣使賠付率失控→保險公司撤出高風險區→地產估值↓→地方稅基↓→財政↓→適應能力更弱——**風險的死亡螺旋**。

## 起火點 -- 如果氣候升溫持續發生

- **現況證據**：加州與佛州的保險公司大規模退出；澳洲與南歐的「不可保區」統計；2024 單年破 1.5°C（[世界史] 環境因素的臨界線索）。
- **觸發條件**：極端天氣的連續重擊（賠付率超過保費的年度差額擴大）＋再保險的定價傳導（再保→保險→房主）。

## 連鎖推演 -- A→B→C

### 第一步：氣候升溫持續（環境⇒經濟）

$$\text{極端事件頻率} \propto e^{\Delta T} \quad \text{（小升溫、大頻率——氣候科學的核心非線性）}$$

### 第二步：保險退潮（經濟⇒政治）

- 再保險的定價傳導：再保費↑→保險撤出高風險區——**保險是「風險的即時民調」**（與 [台海封鎖_晶片斷鏈_全球算力配給時代](台海封鎖_晶片斷鏈_全球算力配給時代.md) 的戰爭保險同構）。
- 「不可保化」的地產效應：沒有保險=沒有房貸（銀行不借）→地產估值↓→地方稅基↓→**財政的連鎖**。

### 第三步：不可保地帶擴張（政治⇒社會⇒人口）

- 「不可保地帶」的地圖成為「適應的政治地圖」：誰的政府接管（最後保險人）、誰的居民遷出——**氣候遷徙的經濟觸發**（與 [1947-去殖民化](../世界史/1947-去殖民化與第三世界.md) 的遷徙政治同構）。
- 國家的「最後保險人」角色：接管不可保風險→財政的風險社會化——**與 [老齡化加深_年金擠壓投資_財政死結](老齡化加深_年金擠壓投資_財政死結.md) 的擠壓交叉**。

## 分岔 -- 每一步的「若…否則…」

| 環節 | 若 | 否則 |
|------|-----|------|
| 國家的角色 | 「最後保險人」接管→財政風險社會化 | 自由市場撤資→地帶被棄（「被放棄的地區」） |
| 適應的投資 | 堤防、建築規範、遷村→風險下降（保險回歸） | 不投資→螺旋持續 |
| 遷徙的形態 | 有序（規劃的遷村）→政治可控 | 無序（災後逃離）→政治地震 |

## 整個世界的變化

| 領域 | 變化 |
|------|------|
| 經濟 | 「不可保」成為資產定價的新變數；沿海與邊緣地產的重估 |
| 政治 | 「最後保險人」的財政擠壓；氣候遷徙的政治 |
| 社會 | 「被放棄的地區」的社會問題；遷徙與安置 |
| 財政 | 風險的社會化 vs 放棄的兩難——與 [老齡化加深] 交叉 |
| 跨鏈 | 與 [碳移除平價_修復軌道_化石政治的終結](碳移除平價_修復軌道_化石政治的終結.md)（修復路徑）互為分岔 |

## 觀察指標

- 保險公司退出各州的公告與「最後保險人」的承保規模。
- 高風險區的地產交易量與估值（退潮的實證）。
- 再保險費率的年度變化。
- 氣候遷徙的內部移民統計。

## 不確定性

- 「最後保險人」的財政能力各國不同——本鏈的深度取決於國家的承擔意願。
- 適應投資（堤防、規範）可能使保險回歸——螺旋不是必然。
