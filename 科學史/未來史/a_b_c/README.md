# 未來史 -- AI 偵探風格

> 未來無法用年份標記——**時間無法確定，因果可以推理。**
> 本書的每篇 wiki 是一條因果鏈：**如果 A 發生 → 造成 B → 造成 C → 整個世界的變化**——檔名就是鏈條本身（`a_b_c.md`）。
> 每篇從「如果某件事情發生」起筆，推演整個世界的連鎖變化；並在每一個環節標注「若…否則…」的分岔——因為因果鏈從來不是單線，**是樹**。

（涵蓋：AI 與勞動、AI 陪伴與少子化、生成內容與信任、美國債務與美元、台海與晶片、供應鏈、兵源與無人機、自主武器與核門檻、壽命與老年化、年金、單人社會、氣候與保險、碳移除、地球工程、糧食、治理與法律）

## 方法論：因果鏈的寫法

每篇 wiki 固定七段：

| 段落 | 內容 |
|------|------|
| **案件摘要** | 這條因果鏈的一句話全貌：「如果 A 發生→…→世界變成…」 |
| **起火點** | 如果 A 發生——A 的現況證據（2025–26 可觀察的事實）與觸發條件 |
| **連鎖推演** | A→B→C 的每一步傳導；每步標注因素通道（科技⇒經濟⇒政治…）與背後理論（數學式、學術理論、表格） |
| **分岔** | 每個環節的「若…否則…」——鏈條在分岔處長出樹枝；互斥的分岔並列（例如「AI 陪伴加深少子化」與「AI 育兒輔助回升生育率」） |
| **整個世界的變化** | 鏈條完成後的跨領域總帳（科技／經濟／政治／社會／心理／軍事／法律） |
| **觀察指標** | 現在就能查的數據——判斷「這條鏈正在發生嗎」 |
| **不確定性** | 誠實標注：哪一環的證據最弱、哪一步是猜測 |

三條鐵律：

1. **不武斷**：不寫「X 年會發生 Y」；只寫「如果 A 發生」與「判斷的指標」。
2. **不單線**：每個環節都有分岔；互斥的鏈並列寫出（例如生育率的兩條反向鏈）。
3. **不孤立**：每條鏈的末端都交叉到其他鏈——因果地圖是網路，不是並列的清單。

## 因果地圖（全部連鎖的總圖）

```
【起火點：AI】
  AI 取代初階白領 ──→ 學徒階梯斷裂 ──→ 人才斷供與組織空心化
  AI 陪伴普及 ──→ 真實親密退位 ──→ 少子化加深 ──┐
  AI 育兒輔助 ──→ 育兒成本減半 ──→ 生育率回升 ──┤ ←互斥的分岔
  生成內容爆炸 ──→ 真實性稀缺 ──→ 騙子紅利與信任崩潰 ──→ 選舉正當性危機
  AI 照護補位 ──→ 獨居安全 ──→ 親密的服務化
  AI 與機器人補位 ──→ 扶養比穩住 ──→ 老齡化軟著陸
  AI 責任無法可管 ──→ 治理真空擴大 ──→ 制度速度的敗退（或：算力條約的勝利）

【起火點：債務與美元】
  美國財政主導 ──→ 通膨稀釋債務 ──→ 美元儲備地位動搖
  美債殖利率失控 ──→ 市場強制緊縮 ──→ 美元特權反噬
  （兩鏈互斥；共同上游：利息占歲入的攀升）

【起火點：戰爭與地緣】
  台海封鎖 ──→ 晶片斷鏈 ──→ 全球算力配給時代
  供應鏈區域化 ──→ 三個經濟圈 ──→ 效率讓位韌性
  兵源稀缺 ──→ 無人機量產 ──→ 軍隊無人化
  自主武器擴散 ──→ 衝突門檻下降 ──→ 低烈度戰爭常態化
  自主武器誤判 ──→ 核門檻跨越 ──→ 嚇阻體系重構

【起火點：人口】
  壽命延長 ──→ 繼承延後 ──→ 青年財富階梯斷裂
  健康年限延長 ──→ 退休契約重寫 ──→ 百年人生社會
  老齡化加深 ──→ 年金擠壓投資 ──→ 財政死結
  單人戶主流 ──→ 照護真空 ──→ 「誰照顧誰」的契約重寫

【起火點：氣候與環境】
  氣候升溫 ──→ 保險退潮 ──→ 不可保地帶擴張
  碳移除平價 ──→ 修復軌道 ──→ 化石政治的終結
  地球工程單方動用 ──→ 歸因衝突 ──→ 氣候地緣戰
  糧食歉收連鎖 ──→ 糧食民族主義 ──→ 價格螺旋與動盪
```

**交叉的鏈**（地圖是網路）：

- 「AI 陪伴→少子化加深」餵養「兵源稀缺→軍隊無人化」與「年金擠壓→財政死結」。
- 「美債殖利率失控」與「台海封鎖」互相放大（財政危機中的國家，承受封鎖的韌性更低）。
- 「生成內容→信任崩潰」使「治理真空」更難修復（法律的執行依賴證據與共識）。
- 「壽命延長→青年階梯斷裂」與「AI 取代初階白領→學徒階梯斷裂」是**同一條「階梯斷裂」**的兩個來源。

## 閱讀方式

- 先讀 **因果地圖**：全書 23 條鏈的總圖與交叉。
- 再挑一條鏈讀：每篇都是「如果 A 發生」起筆的完整推演——起火點（證據）→ 連鎖（理論與傳導）→ 分岔（若…否則…）→ 整個世界的變化 → 觀察指標 → 不確定性。
- 最後用 **觀察指標** 追蹤：未來不是等來的，是查出來的——每篇的指標都是現在就能查的數據。
- 本書與 [世界史]（多因咬合的過去）、[武器與戰法]（武器→戰法）、[科技發展史]（金觀濤的理論—實驗—技術循環）互補：**過去看迴路，未來推迴路**——金觀濤說「科學是自我完成的循環」；本書說「未來是自我完成的迴路群——讀懂哪條迴路被點火，就讀懂了未來的分岔」。
