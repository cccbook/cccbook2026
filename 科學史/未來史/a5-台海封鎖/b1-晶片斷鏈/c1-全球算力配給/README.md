# c1-全球算力配給

> 樹葉節點：[a5/b1-晶片斷鏈](../../) 的終點——**如果全球算力配給時代發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 科技 | 算力從「市場商品」變「戰略配給品」：國家儲備與優先序（國防>醫療>經濟）——AI 時代的石油禁運 |
| 經濟 | 算力價格暴漲、配給的非效率；AI 產業的急凍與重構（替代架構：成熟製程+特殊應用） |
| 政治 | 「晶片主權」的急迫投資；中立國的選邊壓力；「算力外交」的誕生 |
| 社會 | 「算力配給」的日常感（AI 服務的限量與排隊）——短缺經濟學的復活 |
| 法律 | 出口管制與反管制的法理戰——與 [a3/b2-治理真空](../../../a3-AI治理與法律/b2-治理真空擴大/) 交叉 |

## 上游（傳導回顧）

晶片斷鏈（b1）→算力的供給衝擊→價格信號（暴漲）與行政配給（優先序）並行——**短缺經濟學的復活**。

## 觀察指標

- 算力價格（雲端 GPU 時租）的跳升與國家配給政策的立法。
- 替代架構（成熟製程 AI）的投資與量產。
- 「算力外交」（誰的晶片給誰）的協議。

## 不確定性

- 配給的「優先序」各國不同——後果分散。
- 替代架構的兌現速度可能使「配給」短暫——短缺經濟學的常態是「替代的賽跑」。
