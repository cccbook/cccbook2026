# b3-階級化壽命

> [a7-壽命革命與老齡化](../) 的下游節點——**如果抗老療法的價格使壽命階級化發生**，下游分岔：[c1-生物階級](c1-生物階級/)。

## 這個節點（如果發生）是什麼

抗老與健康延長的療法價格高懸（與 [ai照護補位] 的普及相反路徑）——「誰能長壽」的答案從醫學變成財富：**壽命的階級化**——不平等進入身體與生物學。

## 傳導與理論

技術採用是相對價格的函數（[1769-瓦特蒸汽機與工業革命](../../../世界史/1769-瓦特蒸汽機與工業革命.md)）：

$$\text{抗老的採用} \propto \frac{1}{\text{（療法的價格）}} \quad \text{（價格高懸=階級化）}$$

與 [世界史/1492-哥倫布大交換](../../../世界史/1492-哥倫布大交換.md) 的階級遺產同構但更深：**不平等進入身體**。

## 下游分岔（若…否則…）

| 環節 | 若 | 否則 |
|------|-----|------|
| 價格的曲線 | 高懸（療法的稀缺與專利）→階級化（c1） | 下降（普及）→與 [b1-健康年限延長](../b1-健康年限延長/) 匯合 |
| 政治的反應 | 「壽命平權」的運動與管制（價格管制、強制授權）→階級化受抑制 | 管制缺席→階級化固化 |

## 觀察指標

- 抗老療法的價格與保險覆蓋範圍。
- 預期壽命的所得差距統計（階級化的實證）。
- 「壽命平權」的政治運動與立法。

## 不確定性

- 醫療的歷史規律：新療法的價格最終下降（抗生素、疫苗）——階級化可能是過渡期。
