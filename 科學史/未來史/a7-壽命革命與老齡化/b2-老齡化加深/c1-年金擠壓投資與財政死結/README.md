# c1-年金擠壓投資與財政死結

> 樹葉節點：[a7/b2-老齡化加深](../../) 的終點——**如果年金擠壓投資與財政死結發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 財政 | 死結：年金剛性+增稅無選票+緊縮壓增長——無解的迴路；出口只剩通膨稀釋或違約——與 [a4-美國債務懸崖](../../a4-美國債務懸崖/) 匯合 |
| 經濟 | 增長引擎（教育、基建、研發）被擠壓；老齡國與年輕國的「增長分流」 |
| 政治 | 世代政治的引爆（年金與選票）——「世代契約」的重談 |
| 社會 | 「世代的犧牲」的政治敘事；移民依賴加深——與 [c2-單人戶與照護真空](./c2-單人戶與照護真空/) 交叉 |
| 心理 | 老齡政治的風險厭惡（日本「失落二十年」先驗的固化） |

## 上游（傳導回顧）

老齡化加深（b2）→社會保障支出占歲入比例攀升→教育、基建、研發被擠壓→增長放緩→稅基弱→**死結**。

## 觀察指標

- 社會保障支出占歲入與教育/研發支出的「剪刀差」。
- 老齡國的主權債利差（死結的市場定價）。
- 年金改革的政治烈度。

## 不確定性

- 「世代契約重談」可能因危機瞬間發生——死結不必然永續。
