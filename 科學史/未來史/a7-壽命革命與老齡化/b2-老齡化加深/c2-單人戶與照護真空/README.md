# c2-單人戶與照護真空

> 樹葉節點：[a7/b2-老齡化加深](../../) 的終點——**如果單人戶主流化與照護真空發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 社會 | 一人戶占四成、獨居老人沒有家人照護者——「誰照顧誰」的社會契約重寫：**誰提供照護，誰獲得忠誠**（[世界史/0313-君士坦丁與基督教的勝利](../../../世界史/0313-君士坦丁與基督教的勝利.md) 的規律） |
| 經濟 | 照護的勞動稀缺（與老齡化搶人力）；照護產業的重構（人力→科技） |
| 政治 | 照護的供給者（國家/平台/社群/AI）競爭「忠誠」——政治的新戰場 |
| 法律 | 「選擇家人」的法律地位（非親屬的醫療/遺囑/急診委託常態化）——與 [a3-法律因素](../../../a3-AI治理與法律/) 咬合 |
| 心理 | 孤獨的公共衛生（社會隔離的健康成本與吸菸同級） |

## 上游（傳導回顧）

單人戶主流化（少子化引擎 b3 的下游）→「家人」照護歸零→照護真空——**與 [ai照護補位] 的鏈互為分岔：AI 頂上 vs 人力與制度頂上**。

## 觀察指標

- 一人戶中「無近親」的比例（真空的深度）。
- 非親屬醫療/遺囑委託的法律案件常態化。
- 長照保險的立法與給付範圍（國家化的訊號）。

## 不確定性

- 「誰獲得忠誠」的競爭結果無法推演——歷史先驗（教會、福利國家）給了模式，結果開放。
- 照護的勞動稀缺可能被移民補位（與 [a4 與 a2 的移民] 交叉）——真空的填法是多解的。
