# b2-老齡化加深

> [a7-壽命革命與老齡化](../) 的下游節點——**如果老齡化加深而補償失敗發生**，下游分岔：[c1-年金擠壓投資與財政死結](c1-年金擠壓投資與財政死結/)、[c2-單人戶與照護真空](c2-單人戶與照護真空/)。

## 這個節點（如果發生）是什麼

健康年限不延長（帶病延年，[2041] 的 J2）＋機器人補位不足＋移民的政治封鎖——扶養比的算式惡化：**老齡化的痛未被抵銷**。

## 傳導與理論

$$\text{扶養比} = \frac{\text{依賴人口}}{\text{勞動人口}} \uparrow \quad \text{（補償條件不滿足：人均產出成長 < 扶養比上升）}$$

補償的三路（機器人/移民/健康年限）——**三者同時失敗**才走本節點（失敗的機率比單路失敗低，但東亞的制度慣性使它成為預設路徑）。

## 觀察指標

- 社會保障支出占歲入比例（擠壓的程度）。
- 補償三路（機器人密度、移民淨流入、健康年限）的統計。
- 年金改革立法的僵局指數。

## 不確定性

- 本節點的前提是「三路同時失敗」——機率低但東亞的制度慣性使它成為預設。
