# c2-繼承延後與青年財富階梯斷裂

> 樹葉節點：[a7/b1-健康年限延長](../../) 的終點——**如果繼承延後與青年財富階梯斷裂發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 經濟 | 財富的世代集中：「繼承」成為主要財富來源——**世襲資本主義**的強化（Piketty 機制的實現） |
| 政治 | 世代政治（投票權與資源的失衡）；遺產稅與房產稅的戰場——與 [a7/b2/c1-年金擠壓](../b2-老齡化加深/c1-年金擠壓投資與財政死結/) 的世代契約重談交叉 |
| 社會 | 「等待繼承」的一代；多代共居 vs 分居的分岔 |
| 心理 | 時間偏好與風險偏好的世代重構（儲蓄無意義、長期規劃無意義） |
| 跨鏈 | 與 [a1/b1-學徒階梯斷裂](../../../a1-AI取代初階白領/b1-學徒階梯斷裂/) 是**同一條「青年階梯斷裂」**的兩個來源（財富階梯＋職業階梯） |

## 上游（傳導回顧）

健康年限延長（b1）→壽命↑→繼承時點延後（從 45 歲到 65–75 歲）→青年的財富階梯（繼承+房產+職業）三根同時被鎖定。

## 觀察指標

- 繼承時點統計與首購年齡。
- 房產持有的世代集中度。
- 遺產稅與房產稅的立法戰場。

## 不確定性

- 「生前贈與的規範化」可能部分修復階梯——本節點的深度取決於稅制與文化。
- 多代共居的回歸可能使「鎖定」變「共享」。
