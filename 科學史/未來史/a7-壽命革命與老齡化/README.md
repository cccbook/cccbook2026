# a7-壽命革命與老齡化

> 樹根節點（起火點：人口與壽命）——**如果壽命與健康年限的重寫發生**，下游分岔：[b1-健康年限延長](b1-健康年限延長/)、[b2-老齡化加深](b2-老齡化加深/)、[b3-階級化壽命](b3-階級化壽命/)。

## 案件摘要

壽命與老齡化的核心算式：**壽命↑但健康年限是否同步↑**，決定一切。健康年限延長（壓縮疾病率）→紅利；帶病延年→長照爆發；抗老的價格→階級化壽命。三條路同時可能——看生醫、看價格、看制度。

## 起火點 -- 現況證據與觸發條件

- **證據**：預期壽命回升（COVID 後）；GLP-1 的健康外溢已實證；senolytics 與重編程的臨床試驗進行中；扶養比的急升曲線（東亞）。
- **觸發條件**：抗老療法的價格下降（普及）或價格高懸（階級化）——兩條路的分岔點在「價格曲線」。

## 傳導與理論

人口轉型的兩幕式（[1928-青黴素與人口革命](../世界史/1928-青黴素與人口革命.md) 先驗）：死亡率↓→人口爆炸→老齡化——現在是第三幕：**壽命的重寫**。

$$\text{健康年限} = \text{壽命} - \text{帶病年數} \quad \text{（壓縮疾病率 vs 延長帶病期——社會帳完全不同）}$$

$$\text{年金負擔} \propto \frac{\text{領取年數}}{\text{繳費年數}} \quad \text{（壽命} \uparrow \text{→算式惡化）}$$

## 分岔的條件（若…否則…）

| 環節 | 若 | 否則 |
|------|-----|------|
| 健康年限 | 同步延長→紅利（b1） | 帶病延年→長照爆發（b2） |
| 抗老的價格 | 下降→普及 | 高懸→階級化（b3） |
| 制度跟進 | 退休與年金的立法重寫→軟著陸 | 制度鎖定→財政死結（b2/c1） |

## 交叉

- 與 [a1/b1-學徒階梯斷裂](../a1-AI取代初階白領/b1-學徒階梯斷裂/) 交叉（職業階梯＋財富階梯=同一條「青年階梯斷裂」）。
- 與 [a2-少子化的引擎](../a2-少子化的引擎/) 交叉（生育時間窗延後=少子化的新變數）。
- 與 [a3-單人戶與照護真空]（b2/c2）交叉（照護的契約重寫）。

## 觀察指標

- 「60+ 健康工作年」的統計趨勢（壓縮疾病率的實證）。
- 抗老療法的價格與保險覆蓋（階級化的訊號）。
- 繼承時點統計與房產的世代集中度。
- 年金改革立法的進度與政治烈度。

## 不確定性

- 「壓縮疾病率」的兌現是生醫前沿——本樹的前提可能長期不滿足（帶病延年更可能）。
- 制度的跟進永遠滯後——「錯配期」（健康的沒工作）可能是常態過渡。
