# c2-判斷力工資暴漲

> 樹葉節點：[a1/b1-學徒階梯斷裂](../../) 的終點——**如果判斷力工資暴漲發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 經濟 | 初階與資深的薪資差距創歷史極值；「判斷力」成為定價核心 |
| 組織 | 「判斷力審計」的新職能；老將的顧問化與「判斷力租賃」 |
| 教育 | 判斷力訓練（實作、倫理、複盤）的產業化——補習班的重構 |
| 社會 | 「經驗世代」的權力上升——與青年焦慮並存 |

## 上游（傳導回顧）

學徒階梯斷裂（b1）→判斷力無法量產→市場定價：稀缺=暴漲。AI 能模仿格式、不能承擔責任——「責任承擔」成為判斷力的定價錨。

## 觀察指標

- 資深/初階薪資比的歷史極值。
- 「判斷力」相關的課程與顧問業產值。
- 高齡專業者的勞動參與率（與 [a7/b1-健康年限延長](../../../a7-壽命革命與老齡化/b1-健康年限延長/) 咬合——經驗的存量更久）。

## 不確定性

- AI 對判斷力的追趕速度——若跨過「責任承擔」門檻，暴漲逆轉。
- 判斷力的定義本身（何謂好判斷）會被這場暴漲重新定義。
