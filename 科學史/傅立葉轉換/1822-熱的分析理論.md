# 1822 - 熱的分析理論（正式問世：級數展開成為顯學）

## 案件摘要
1822 年，Fourier 出版《熱的分析理論》(Théorie analytique de la chaleur)。
在 Lagrange 阻撓 15 年之後，這部著作把 1807 年的「大膽主張」寫成完整的數學體系：
熱方程的求解、三角級數展開、傅立葉積分的雛形，全部集於一書。
傅立葉級數從「案發現場」升格為正式學科——本案從此無法再被封存。

## 前因 -- 為什麼會有這個案子
- **1807 年的懸案**：論文被評審（Lagrange 為首）否決出版，主因是「任意函數可展開為三角級數」與 Lagrange 的偏見衝突（見「1807-Fourier熱傳導論文」）。
- **Fourier 的堅持**：他先後提交 1811 年修改版（仍被擱置），並持續完善理論、累積例子。
- **政治轉機**：Fourier 擔任 Isère 省長期間研究不輟；1822 年他當選法國科學院終身秘書——**評審的反對者勢力消退，論文得以付梓**。
- **Lagrange 的離場**：Lagrange 於 1813 年去世，論戰最強的反對聲音消失。

## 線索與推理 -- 數學式、程式、理論

### 書中核心：熱方程與級數解
一維棒、二維板的熱方程：
$$\frac{\partial u}{\partial t} = \alpha \nabla^2 u.$$
在矩形域上分離變數，解為雙重級數：
$$u(x,y,t) = \sum_{m,n}\ b_{mn}\sin\frac{m\pi x}{L_1}\sin\frac{n\pi y}{L_2}\,e^{-\alpha\pi^2(m^2/L_1^2 + n^2/L_2^2)t}.$$
高頻模（大 $m,n$）指數衰減最快——**熱傳導本質上是低通濾波器**：
$$\hat{u}(t) = e^{-\alpha k^2 t}\,\hat{u}(0).$$

### 傅立葉積分的雛形（無窮長棒）
當棒長 $L \to \infty$，離散頻率 $n\pi/L$ 間距趨於 0，級數「液態化」為積分：
$$u(x,t) = \int_0^\infty A(k)\cos kx + B(k)\sin kx \;\; e^{-\alpha k^2 t}\, dk.$$
這是**傅立葉轉換**的直接前身——今日的連續形式：
$$F(\omega) = \int_{-\infty}^{\infty} f(t)\, e^{-i\omega t}\,dt, \qquad f(t) = \frac{1}{2\pi}\int_{-\infty}^{\infty} F(\omega)\,e^{i\omega t}\,d\omega.$$

### 熱傳導濾波器的 Python 驗證

```python
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0, 1, 512)
f = np.where((x > 0.4) & (x < 0.6), 1.0, 0.0)   # 方塊初始溫度
F = np.fft.rfft(f)
k = np.fft.rfftfreq(len(x), d=x[1]-x[0]) * np.pi
for t in [0.0, 0.001, 0.01]:
    u = np.fft.irfft(F * np.exp(-k**2 * t), len(x))
    plt.plot(x, u, label=f't={t}')
plt.legend(); plt.savefig('heat_diffusion.png', dpi=100)
print("能量比 t=0.01:", np.sum((np.fft.irfft(F*np.exp(-k**2*0.01), len(x)))**2)/np.sum(f**2))
```
輸出：尖銳方塊隨時間迅速抹平、高頻成分指數消失——熱傳導 = 低通濾波，鐵證如山。

### 書中其他破案線索
- **維度突破**：二維熱方程的解用到圓柱函數（後稱 Bessel 函數）——特徵函數思想隨幾何形狀而生。
- **量綱分析**：Fourier 引入量綱齊次性作為物理定律的檢驗工具——近代物理常數分析的先聲。
- **地球年齡推算**：用熱方程外推地球冷卻，得出遠大於 6000 年的數值——引發與教會及 Kelvin 的長期科學論戰。

## 結案 -- 後果與影響
- 傅立葉級數與積分成為分析學核心工具，偏微分方程、數學物理全面改寫。
- 函數概念的現代化被逼上日程：1829 年 Dirichlet 收斂定理（見「1829-Dirichlet收斂定理」）補上嚴格性。
- 頻域思想成為訊號處理的哲學基礎：時域與頻域等價、捲積與乘法對偶：
  $$f * g \;\xleftrightarrow{\;\mathcal{F}\;}\; F(\omega)\,G(\omega).$$
- Green、Kelvin、Maxwell 等人皆從此書學會「特徵函數展開」——傅立葉分析成為 19 世紀數學物理的通用語言。
- 數位時代後續案件全部由此書發芽：取樣定理（1948）、FFT（1965）、DCT/JPEG（1992）。
