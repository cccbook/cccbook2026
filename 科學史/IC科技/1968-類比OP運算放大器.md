# 1968 - 類比 OP 運算放大器：μA741，類比 IC 的標準磚

## 案件摘要
1968 年，Fairchild Semiconductor 量產 μA741 運算放大器——由 Dave Fullager 設計，
將差動輸入級、增益級、輸出級與 30 pF 補償電容全部塞進單一晶片。
它不必外接補償、不怕接錯、價格低廉，工程師只要記住「虛短路、虛斷路」兩條規則就能設計任何放大器。
μA741 從此成為所有電子系統的標準磚，類比設計由工匠手藝變成可量產的行業。

## 前因 -- 為什麼會有這個案子
- **真空管運放又大又貴**：1940 年代的運算放大器（Lovel 系統、K2-W）用真空管做成機架級模組，一枚數百美元；電晶體化後仍是模組，塞不進系統。
- **Widlar 開路先鋒**：Bob Widlar 在 Fairchild 設計 μA702（1963）與 μA709（1965），證明單晶片運放可行；但 702 需要奇怪的電源電壓、709 需要外接補償電容且容易「鎖死燒毀」——工程師苦不堪言。
- **單片化的殺手級優勢**：同一晶圓上兩顆電晶體的**匹配度**遠優於兩顆分立元件（$V_{BE}$ 失配僅數 mV），且同溫漂移——**差動放大器的失調電壓在單片上自動消失**，這是分立世界做不到的物理。
- **關鍵推理**：Widlar 離職後，Dave Fullager 接手解決最後一塊拼圖——把 30 pF **Miller 補償電容做進晶片內部**，讓運放單位增益穩定、使用者零補償負擔：

$$
\underbrace{\text{內建 30 pF 補償}}_{\text{Fullager 1968}} \;\Longrightarrow\; \underbrace{C_{\text{comp}} \text{ 常數}}_{\text{單極點頻率響應}} \;\Longrightarrow\; \underbrace{\text{任何回授組態都穩定}}_{\text{免設計、免燒毀}}
$$

1968 年 μA741 上市，初期單價數十美元，數年內跌到一美元以下——類比世界的「漏斗」打開了。

## 線索與推理 -- 數學式、程式、理論

### 1. 理想運放的兩條規則：虛短路與虛斷路

理想運放：開環增益 $A_{ol} \to \infty$、輸入阻抗 $R_{in} \to \infty$、輸出阻抗 $R_{out} \to 0$。由此導出兩條黃金規則：

$$
V_+ - V_- = \frac{V_{out}}{A_{ol}} \xrightarrow{A_{ol} \to \infty} 0
\quad\Longrightarrow\quad
\underbrace{V_+ = V_-}_{\text{虛短路}}, \qquad
\underbrace{I_+ = I_- = 0}_{\text{虛斷路}}
$$

- **虛斷路**：輸入端不吸電流（$R_{in} \to \infty$），信號源不被加載。
- **虛短路**：兩輸入端等電位，但**沒有真正短路**——電流不會在兩端間流動。
- 負回授把 $V_-$ 拉回 $V_+$：運放輸出以增益 $A_{ol}$ 極力糾正輸入差，回授網路讓糾正恰好平衡。

### 2. 反相與非反相放大：兩條規則的應用

**反相放大器**：信號經 $R_{in}$ 進 $V_-$，$R_f$ 回授。虛斷路 → 流過 $R_{in}$ 的電流全走 $R_f$；虛短路 → $V_- = V_+ = 0$（虛接地）：

$$
\frac{V_{in}}{R_{in}} = -\frac{V_{out}}{R_f}
\quad\Longrightarrow\quad
A_v = -\frac{R_f}{R_{in}}
$$

**非反相放大器**：信號直進 $V_+$，$R_f/R_1$ 分壓回授到 $V_-$。虛短路 → $V_- = V_{in}$：

$$
V_{in}\left(1 + \frac{R_f}{R_1}\right) = V_{out}
\quad\Longrightarrow\quad
A_v = 1 + \frac{R_f}{R_1} \ge 1
$$

- 反相：增益只由**電阻比**決定，與運放參數無關——精準度來自無源元件，這就是運放的魔法。
- 非反相：輸入阻抗趨近無窮大，適合高阻抗信號源（感測器、麥克風前級）。

### 3. 負回授的數學：$A_v \approx 1/\beta$

給定開環增益 $A_{ol}$ 與回授係數 $\beta = V_{feedback}/V_{out}$，閉迴路增益為：

$$
A_v = \frac{A_{ol}}{1 + A_{ol}\,\beta}
$$

當 $A_{ol}\,\beta \gg 1$ 時：

$$
A_v \approx \frac{1}{\beta}, \qquad
\text{增益誤差} = \frac{1}{1 + A_{ol}\,\beta}
$$

- $A_{ol}$ 從 10 萬倍漂到 20 萬倍，閉迴路增益幾乎不動——**負回授把運放的不完美折疊掉**。
- Black（1927，真空管中繼放大器）發明的同一套數學，在 1968 年被壓縮進一枚 1 mm² 的晶片。
- 增益精度、失真、失調、輸出阻抗，全部同時改善 $1 + A_{ol}\beta$ 倍——**負回授是類比設計的萬用清潔劑**。

### 4. 共模拒斥比 CMRR：差動輸入級的功勞

理想運放只放大差模信號 $V_d = V_+ - V_-$，完全拒絕共模信號 $V_c = (V_+ + V_-)/2$。實際運放：

$$
V_{out} = A_d V_d + A_c V_c, \qquad
\text{CMRR} = \frac{A_d}{A_c} \;\;(\text{dB: } 20\log_{10}\tfrac{A_d}{A_c})
$$

- 單片差動級：兩顆電晶體同晶圓、同溫、同製程，$V_{BE}$ 失配僅 1–5 mV，CMRR 可達 90 dB 以上。
- 分立元件 CMRR 頂多 40–50 dB——**單片化不是省成本，是物理上的必然**。
- 雜訊、電源漣波、地彈多以共模形式出現，高 CMRR 把它們全部丟棄。

### 5. 741 內部架構：三級放大加一枚電容

$$
\underbrace{\text{差動輸入級}}_{\text{Q1–Q4，雙端轉單端}} \to
\underbrace{\text{增益級}}_{\text{Q13–Q16，Miller 補償}} \to
\underbrace{\text{AB 類輸出級}}_{\text{Q14/Q20，推挽}}
$$

- **輸入級**：PNP/NPN 差動對，高共模範圍、低失調；有源負載（current mirror）把雙端輸出轉成單端。
- **增益級**：單級提供大部分增益（約 $10^5$ 倍），30 pF Miller 電容讓 $C_{\text{eff}} = C(1 + A)$ 等效放大，單極點 $f_{-3dB} \approx 5\,\text{Hz}$。
- **輸出級**：AB 類推挽，低輸出阻抗、交越失真小，可直接驅動負載。
- 單位增益頻率（GBW）約 1 MHz：$\text{GBW} = A_{ol} \times f_{-3dB} \approx 10^5 \times 10 = 1\,\text{MHz}$。

### 6. Python 實作：負回授增益與 Bode 圖

```python
import numpy as np

# ---- 負回授閉迴路增益：Av = Aol / (1 + Aol*beta) ----
def closed_loop_gain(Aol, beta):
    return Aol / (1 + Aol * beta)

for beta, name in [(1/10, "反相/非反相 ×10"), (1/100, "×100"), (1.0, "電壓追隨器")]:
    Aol = 2e5                               # μA741 開環增益
    Av = closed_loop_gain(Aol, beta)
    ideal = 1/beta
    print(f"{name}: Av = {Av:.2f}, 理想 1/beta = {ideal:.2f}, 誤差 = {abs(Av-ideal)/ideal*100:.4f}%")
# 預期輸出：
# 反相/非反相 ×10: Av = 10.00, 理想 1/beta = 10.00, 誤差 = 0.0050%
# ×100: Av = 100.00, 理想 1/beta = 100.00, 誤差 = 0.0500%
# 電壓追隨器: Av = 1.00, 理想 1/beta = 1.00, 誤差 = 0.0005%

# ---- 頻率響應：單極點開環 + 閉迴路 Bode ----
GBW = 1e6                                   # μA741 單位增益頻寬 1 MHz
f = np.logspace(0, 7, 200)                  # 1 Hz ~ 10 MHz
Aol_f = GBW / f                             # 單極點：Aol(f) = GBW / f

for beta, name in [(1/10, "×10"), (1/100, "×100")]:
    Av_f = Aol_f / (1 + Aol_f * beta)       # 閉迴路頻率響應
    fc = GBW * beta                         # 閉迴路頻寬 = GBW × beta
    print(f"{name}: 閉迴路頻寬 ≈ {fc/1e3:.0f} kHz, GBW = {Av_f[0]*beta*1e6/1e6:.2f} MHz")
# 預期輸出：
# ×10: 閉迴路頻寬 ≈ 100 kHz, GBW = 1.00 MHz
# ×100: 閉迴路頻寬 ≈ 10 kHz, GBW = 1.00 MHz

# 核心結論：增益 × 頻寬 = 常數（GBW），提高增益必犧牲頻寬——負回授的交換律
```

閉迴路增益誤差不到 0.1%，增益 × 頻寬恆等於 GBW——「虛短路、虛斷路」得到數值驗證。

## 結案 -- 後果與影響
- **類比設計標準化**：工程師不再從電晶體級設計放大器，改用「運放 + 回授網路」組合；類比設計從手藝變成工程。
- **標準磚的誕生**：741 之後運放成為所有電子系統的基本建構單元——濾波器、儀表放大器、振盪器、穩壓器全部以 op-amp 為核。
- **類比 IC 生態成形**：comparator（339）、ADC/DAC、電源管理 IC、音頻放大器沿同一條「單片化 + 內建補償」路線展開。
- **單片化的物理遺產**：matched devices、等溫設計、有源負載（current mirror）、Bandgap 參考源——全在 741 這枚晶片上首次同台。
- **至今仍在用**：μA741 的直系後代（TL07x、OP07、低雜訊精密運放）至今仍在出貨；每一代的模擬 IP 內核，源頭都是 1968 這枚 1 mm² 的標準磚。
