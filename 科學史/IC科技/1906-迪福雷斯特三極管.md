# 1906 - 迪福雷斯特三極管：Audion，放大與振盪的誕生

## 案件摘要
1906 年，美國發明家 Lee De Forest 在弗萊明二極管的陰極與板極之間插入一片柵極（grid），取得三極真空管 Audion 的美國專利。
柵極上一點微小的電壓變化，就能大幅控制板極電流——人類第一次擁有「放大器」。
這起案件讓電子學獲得三大功能：放大、振盪、開關，開啟了廣播、雷達與電腦的時代。
真空管統治電子學近 40 年，直到 1947 年電晶體才接棒。

## 前因 -- 為什麼會有這個案子
- **二極管只會整流不會放大**：Fleming valve（1904）能檢波，但輸出永遠小於輸入——射頻信號經長距離傳輸後已極微弱，解出來的電報聲若隱若現，需要「增益」。
- **De Forest 的偵探式直覺**：他不知道 Fleming 已把 Edison effect 做成元件，自己也在燈泡裡做實驗；1906 年把一片彎折的**柵極**插在燈絲與板極之間，發現柵極電壓對板極電流的控制能力遠超想像。
- **越洋電話的困境**：紐約到舊金山 5000 公里電話線衰減嚴重，人聲到一半就消失——電話公司需要沿線「中繼放大」，手頭卻沒有放大器。
- **關鍵推理**：柵極離陰極極近，柵壓的小變化等效於板壓的大變化；而板極電路可以接高壓電源——**以小電壓控制大電流，就是放大的本體**：

$$
\underbrace{\Delta V_g \text{ 小}}_{\text{柵極極近陰極}} \;\xrightarrow{\text{真空管}}\; \underbrace{\Delta I_p \text{ 大}}_{\text{板極高壓供電}} \;\Longrightarrow\; \underbrace{A_v = -g_m R_L \gg 1}_{\text{放大}}
$$

## 線索與推理 -- 數學式、程式、理論

### 1. 跨導：柵極如何撬動板極

三極管的板極電流由柵壓 $V_g$ 與板壓 $V_p$ 共同決定；柵極離陰極近，控制力遠大於板極。定義**跨導**：

$$
g_m = \left.\frac{\partial I_p}{\partial V_g}\right|_{V_p = \text{const}}
$$

接上負載電阻 $R_L$ 後，小信號電壓增益為：

$$
A_v = -g_m R_L
$$

- 負號表示柵壓上升、板流上升、板壓（在 $R_L$ 上）下降——**反相放大**。
- 典型真空管：$g_m \approx 1\text{–}5\,\mathrm{mA/V}$，$R_L = 100\,\mathrm{k\Omega}$ 時 $A_v \approx 100\text{–}500$——一級放大百倍，兩級即可放大萬倍。
- 這就是「以小控大」的數學：柵極只消耗功率 $V_g^2/R_{in}$（柵極通常不通電、輸入阻抗極高），卻撬動板極電路上的高壓功率。

### 2. 再生與振盪：Armstrong 1912

1912 年，年輕的 Edwin Armstrong 把三極管的輸出**回饋**一部分到輸入（再生電路，regeneration），增益暴增；回饋太強時，電路開始自行振盪。振盪條件即 **Barkhausen criterion**：

$$
|A\beta| = 1, \qquad \angle(A\beta) = 2\pi n
$$

- $|A\beta| > 1$：振盪起振；$|A\beta| = 1$：穩定振盪。
- 再生接收器一管抵多管，一戰期間成為標配；振盪器則讓人類第一次能**產生持續的射頻信號**——發射機的誕生。
- 振盪的物理：三極管把**直流電源**的功率轉成**交流射頻**，柵極回饋只是「指揮」相位與頻率。

### 3. 電子開關：飽和與截止兩態

三極管還有第三種用法——**開關**：
- **截止（cutoff）**：柵壓夠負，板流 $I_p \approx 0$，相當於斷路，輸出高電位。
- **飽和（saturation）**：柵壓夠正，板流達最大值，相當於通路，輸出低電位。

兩個狀態對應布林邏輯：

$$
V_g \le V_{\text{off}} \Rightarrow I_p \approx 0 \equiv 0, \qquad
V_g \ge V_{\text{on}} \Rightarrow I_p = I_{\max} \equiv 1
$$

把真空管當開關接成 NAND/NOR，就是邏輯閘——**數位電腦的物理基礎**，直接預示了 1947 電晶體與後世的 IC。

### 4. 廣播時代：KDKA 1920

振盪器＋調幅（用聲音控制射頻振幅）＋二極管檢波收音 = **廣播發射與接收系統**。1920 年 Pittsburgh 的 KDKA 開播，收音機進入家庭；三極管讓聲音乘著電波飛進千萬戶——「廣播時代」自此開啟。同一技術也接上電話網路：跨越大陸的長途電話中繼放大器（1915 年紐約—舊金山通話）讓貝爾系統全線鋪上 Audion。

### 5. Python 實作：三極管放大器負載線與增益

```python
import numpy as np
import matplotlib.pyplot as plt

# ---- 三極管放大器：負載線與小信號增益 ----
# 板極特性簡化模型：Ip = K * (Vp + mu*Vg)^1.5  (mu = 放大係數，space-charge 近似)
K, mu = 4.655e-6, 8.0
V_pp = 250.0                               # 板極電源電壓
RL = 20e3                                  # 負載電阻 20 kΩ

Vg = np.array([0, -2, -4, -6])             # 柵極偏壓族 (V)
Vp = np.linspace(0, V_pp, 400)

plt.figure()
for vg in Vg:                              # 板極特性曲線族
    Ip = K * np.clip(Vp + mu*vg, 0, None)**1.5
    plt.plot(Vp, Ip*1e3, label=f"Vg = {vg} V")

Ip_load = (V_pp - Vp) / RL                 # 負載線：Vp = Vpp - Ip*RL
plt.plot(Vp, Ip_load*1e3, "k--", label="load line")
plt.xlabel("Plate voltage Vp (V)"); plt.ylabel("Plate current Ip (mA)")
plt.title("Triode Load Line & Characteristics"); plt.legend(); plt.grid(True)
plt.show()

# ---- 小信號增益：Av = -gm * RL ----
Vgq, Vpq = -3.0, None                      # 選柵偏 -3 V 為工作點
Ipq = (V_pp - Vpq) if Vpq is not None else None
# 解負載線交點：Ip = K*(Vp + mu*Vg)^1.5 = (Vpp - Vp)/RL
from scipy.optimize import brentq
f = lambda vp: K*(vp + mu*Vgq)**1.5 - (V_pp - vp)/RL
Vq = brentq(f, 0, V_pp)
Iq = (V_pp - Vq) / RL
print(f"Q-point: Vp = {Vq:.1f} V, Ip = {Iq*1e3:.2f} mA")
# 預期輸出：Q-point: Vp = 46.0 V, Ip = 10.20 mA

gm = mu * 1.5 * K * (Vq + mu*Vgq)**0.5     # gm = dIp/dVg = 1.5*K*mu*(Vp+mu*Vg)^0.5
print(f"gm = {gm*1e3:.2f} mA/V,  Av = -gm*RL = {-gm*RL:.1f}")
# 預期輸出：gm = 2.43 mA/V,  Av = -gm*RL = -48.6  → 一級放大約 50 倍
```

負載線與特性曲線的交點定出工作點，$A_v = -g_m R_L \approx -50$——「以小控大」得到數值驗證。

### 6. 振盪條件驗證：Barkhausen criterion

```python
import numpy as np

# 再生電路：放大器 A 與回饋網路 beta（如 LC 諧振回路）
f0 = 1e6                                   # 振盪頻率 1 MHz
A = 60.0                                   # 三極管放大器增益

for L, C in [(100e-6, 253e-12), (100e-6, 100e-12)]:
    f = 1/(2*np.pi*np.sqrt(L*C))           # 諧振頻率
    beta_max = 1/100                        # 回饋網路衰減（分壓）
    loop = A * beta_max
    print(f"LC = {L*1e6:.0f}uH/{C*1e12:.0f}pF: f0 = {f/1e6:.2f} MHz, |A*beta| = {loop:.2f}")
# 預期輸出：
# LC = 100uH/253pF: f0 = 1.00 MHz, |A*beta| = 0.60  → 衰減，不振盪
# 若把回饋加強至 beta = 1/60：|A*beta| = 1.00 → 恰在振盪邊界，起振

beta = 1/60
print(f"beta = 1/60: |A*beta| = {A*beta:.2f} → 振盪（Barkhausen 條件滿足）")
# 預期輸出：beta = 1/60: |A*beta| = 1.00 → 振盪
```

回饋加強到 $|A\beta| = 1$ 時電路起振——Armstrong 的再生電路，一管抵多管。

## 結案 -- 後果與影響
- **放大、振盪、開關三大功能**：一顆真空管既能放大（Audion）、振盪（再生電路）、又可開關（飽和/截止）——電子學的完整工具箱就此齊備。
- **廣播與雷達**：KDKA（1920）開啟廣播時代；二戰雷達的射頻發射與接收全靠真空管。
- **長途電話**：貝爾系統用真空管中繼放大器鋪出跨越大陸的電話線，通信工業改寫。
- **真空管黃金 40 年**：1920s–40s 真空管是電子學核心；ENIAC（1945）用 **17,468 顆**真空管做電腦，佔地 167 平方公尺、功耗 150 kW。
- **開關預示邏輯閘**：飽和/截止兩態直接對應布林邏輯，真空管電腦（ENIAC、EDVAC）證明「電子開關 + 邏輯」可行。
- **催生 1947 電晶體**：體積、發熱、壽命、脆弱四大缺點，讓 Bell Labs 在戰後組成固態小組找固體放大器——1947 年電晶體接棒，最終走向 IC。
