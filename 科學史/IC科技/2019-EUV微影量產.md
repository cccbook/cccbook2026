# 2019 - EUV 微影量產（台積電 N7+）

## 案件摘要
2019 年，台積電以 N7+ 製程首次在量產中使用 ASML 的 EUV（極紫外光，13.5nm）微影機。這台機台研發了 30 年、造價 1.5 億美元，用錫電漿與史上最精密的反射鏡組，把光學微影從 193nm 浸潤式的極限中解放出來。

## 前因 -- 為什麼會有這個案子
- 光學微影的解析度極限：$CD = \dfrac{k_1 \lambda}{NA}$。193nm 浸潤式（immersion，NA=1.35）加上 $k_1 \to 0.27$ 的極限，可解析的最小圖形約 38nm 週期。
- 7nm 以下節點的關鍵層需要更小的圖形，193nm 機台做不到 → 唯一出路：**更短波長**。
- 但 13.5nm EUV 光會被一切物質（包括空氣與玻璃）吸收：**無透鏡可用，必須全反射式鏡組；必須真空環境**。
- 1980 年代起美日（EUV LLC、Nikon、Nikkiso）與後來的 ASML 投入 30 年研發，歷經光源功率不足、鏡片缺陷、良率寒冬，直到 2019 才真正「量產化」。

## 線索與推理 -- 數學式、程式、理論

### 1. 193nm 浸潤式微影的極限與多重曝光
Rayleigh 解析度公式：

$$CD = \frac{k_1 \lambda}{NA}, \qquad \text{DOF（焦深）} = \frac{k_2 \lambda}{NA^2}$$

浸潤式把空氣（$n=1$）換成水（$n \approx 1.44$），$NA = n\sin\theta$ 提升到 1.35，已是物理上限（大於水的折射率無解）。$k_1$ 受相干性限制：

$$k_1 \geq \frac{1}{2} \;\text{(離軸照明等技巧可壓到 } \sim 0.27\text{)}$$

193i 的極限解析週期 $\approx \dfrac{0.27 \times 193}{1.35} \approx 38.6$ nm。7nm 節點金屬層週期僅 ~36-40nm，逼近極限 → 只能用**多重曝光（multi-patterning）**：
- **SADP（Self-Aligned Double Patterning）**：先做出間隔物（spacer），再蝕刻出一半週期的圖形；週期可減半。
- **SAQP**：兩輪 spacer，週期再減半。
- **LELE（Litho-Etch-Litho-Etch）**：同一層曝光兩次，套刻誤差（overlay）是致命傷。

代價：步驟數暴增（一層關鍵層需 3~5 次曝光＋蝕刻），成本與良率壓力巨大。這正是需要 EUV 的經濟動機——**一次曝光解決**。

### 2. EUV 13.5nm 光源：錫電漿雷射放電（LPP）
為什麼是 13.5nm？因為 Mo/Si 多層膜在 13.5nm 附近有反射率峰值（見下節）。產生方法（ASML/Cymer 採用 LPP，Laser-Produced Plasma）：
1. 液態**錫**（Sn）微滴以每秒 5 萬顆落下；
2. 第一道 CO₂ 雷射把微滴打扁成餅狀，第二道高功率雷射擊中，蒸發成**電漿**；
3. 錫離子（Sn⁸⁺~Sn¹⁴⁺）躍遷放出 13.5nm EUV 光。

光譜推理：高價錫離子的 4d→4f 躍遷恰好落在 13.5nm 且有寬頻寬，是元素週期表中最匹配 Mo/Si 鏡的「天然光源」。EUV 光源功率從 2000 年代的個位數 W 苦戰到 2019 年的 250W、今日的 500W+——功率直接決定晶圓產能（wafer/hr）。

### 3. 反射式鏢組：無透鏡可透 EUV，多層膜 Bragg 反射
EUV 光被所有材料強烈吸收（吸收長度僅數十 nm），透鏡無解 → 全用**反射鏡**。反射的原理不是金屬鏡面，而是**多層膜 Bragg 反射**：

- Mo（2.9nm）/Si（4.2nm）交替疊 ~40~50 層，每層界面部分反射；
- 各層反射波同相相長干涉（Bragg 條件）：

$$2 d \sin\theta = m\lambda \;\Rightarrow\; \text{峰值反射率 } \sim 70\%$$

- 即使 70% 已是極限，每面鏡仍損失 30%：10 面鏡組下總穿透率只有 $0.7^{10} \approx 2.8\%$——這就是為什麼光源功率必須極大。
- 鏡面精度要求：面形誤差 < 50 pm（皮米，原子直徑的 1/2），由 Zeiss 製造，是「把德國的面鏡拋光到把光從德州打到紐約只偏差不到 2mm」等級的工程。
- 全程**真空**（EUV 被空氣吸收），掩膜也是反射式（無透射光罩），且照明為離軸，造成掩膜 3D 效應與 shadowing 誤差——EUV 的「案子」比想像中多。

### 4. EUV 機台的史詩工程（30 年研發、1.5 億美元/台）
- 1980s-90s：美日實驗室驗證 13.5nm 可行性；1997 年美國 EUV LLC 聯盟成立。
- 2000s：光源功率不足（數 W），一台機一天只能出幾片晶圓，良率寒冬十年。
- 2012 年：ASML 收購 Cymer（光源龍頭），並拉 Intel、台積電、三星入股，共擔研發風險。
- 2019 年：台積電 N7+ 量產，EUV 首度進入量產線（華為麒麟 990、Apple A 系列後續晶片皆採用）。
- 機台造價 ~1.5 億美元，重 180 噸，需要 40 個貨櫃運輸、3 架波音 747 或 1 架 Antonov An-225 空運；是史上最複雜的商業機器之一。

### 5. EUV vs DUV 對照表
| 項目 | DUV 193nm 浸潤式 | EUV 13.5nm |
|------|------------------|------------|
| 波長 | 193 nm | 13.5 nm |
| 光源 | ArF 準分子雷射 | 錫電漿 LPP |
| 光學系統 | 透射式透鏡 | 全反射多層膜鏡組 |
| 環境 | 大氣 | 高真空 |
| 光罩 | 透射式 | 反射式 |
| NA | 1.35（極限） | 0.33（0.55 開發中） |
| k1 極限解析 | ~38nm 週期 | ~13nm 週期（0.32） |
| 多重曝光 | 需要（SADP/SAQP） | 大多單次曝光 |
| 單層成本 | 高（多重曝光更貴） | 機台貴但步驟少 |
| 量產時間 | 2007 | 2019 |

### 6. Python 模擬：光學解析度與多重曝光

```python
def cd(k1, lam, na):
    """Rayleigh 解析度：CD = k1 * lambda / NA"""
    return k1 * lam / na

def mp_cost(layers_steps, cost_per_step):
    """多重曝光的成本 = 步驟數 x 單步成本"""
    return layers_steps * cost_per_step

NA_I = 1.35; NA_E = 0.33
print(f"193i 極限解析週期 = {cd(0.27, 193, NA_I):.1f} nm")   # ~38.6 nm
print(f"EUV   極限解析週期 = {cd(0.32, 13.5, NA_E):.1f} nm") # ~13.1 nm

# 7nm 金屬層週期 ~36nm：DUV 需要 SADP+SAQP（~5 步），EUV 單次曝光
duv = mp_cost(5, 1.0)          # 相對成本單位
euv = mp_cost(1, 2.5)          # EUV 曝光貴 2.5 倍但只要 1 次
print(f"DUV(SADP+SAQP) 相對成本 = {duv}, EUV 單曝 = {euv}")
# EUV 一次曝光反而更省 → 這是量產化的經濟推理

# 反射鏡組的功率損失
reflectivity = 0.70; mirrors = 10
trans = reflectivity**mirrors
print(f"{mirrors} 面鏡總穿透率 = {trans*100:.1f}%")
# 只有 ~2.8% 的光到達晶圓 → 光源必須 250W+，這是 LPP 的存在理由
```

## 結案 -- 後果與影響
- EUV 量產解除多重曝光的複雜度危機，7nm→5nm→3nm 節點得以推進，摩爾定律續命。
- ASML 成為全球唯一 EUV 光刻機供應商（壟斷），Zeiss 的鏡與 Cymer 的光源成為地緣政治的核心資產（美國對中出口管制）。
- EUV 光罩（反射式）缺陷檢測、pellicle（護膜）成為新的工程戰場。
- 下一站：High-NA EUV（NA=0.55，2024~）進一步縮小解析度，EUV 從「救命工具」變成「微縮主引擎」。
