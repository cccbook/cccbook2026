# 2019 - EUV 極紫外微影量產：13.5 奈米光的史詩工程

## 案件摘要
當 193nm 浸潤式微影走到極限，晶片製造被迫用「多重曝光」硬撐。ASML 花了三十年、
燒掉上百億美元，終於讓 13.5nm 的極紫外光（EUV）在 2019 年量產——這台造價 1.5 億美元、
重 180 噸的機器，是史上最精密的光學儀器，也是摩爾定律延續至今的關鍵。

## 前因 -- 為什麼會有這個案子

線索來自兩個困境：

1. **光學解析度的極限**：微影能印出的最小線寬受瑞利準則限制：

   $$
   CD = \frac{k_1 \lambda}{NA}
   $$

   其中 $\lambda$ 是光源波長，$NA$ 是鏡頭數值孔徑，$k_1$ 是製程係數（理論下限約 0.25）。
   193nm ArF 準分子雷射 + $NA \approx 1.35$（浸潤式）時，單次曝光極限約 $CD \approx 36\,\text{nm}$。

2. **多重曝光的代價**：為了印 20nm 以下線寬，業者被迫用雙重曝光（Double Patterning）、
   甚至 SADP/SAQP（自對準多重曝光），每多一層曝光，成本與 cycle time 就暴漲：

   $$
   \text{Cost}_{\text{multi}} = n \times \text{Cost}_{\text{single}}
   $$

   到 7nm 節點，多重曝光的 mask 費用已超過 1000 萬美元/套。

推理：**與其把 193nm 擠到極限，不如直接縮短波長**——但 13.5nm 的 EUV 光會被幾乎
所有物質吸收（包括空氣與玻璃），傳統透鏡全部失效，必須在「真空中用鏡子」做光學。

## 線索與推理 -- 數學式、程式、理論

### 1. 光源：錫電漿雷射放電（LPP）

EUV 需要 13.5nm 光源（能量 $E = \frac{hc}{\lambda} \approx 92\,\text{eV}$），
沒有天然雷射可用，ASML/Cymer 的解法是：

1. 用高功率 $CO_2$ 雷射（25kW）轟擊直徑僅 $25\,\mu m$ 的錫液滴；
2. 錫被汽化成電漿，溫度達數十萬度，發出 13.5nm 光；
3. 錫液滴每秒滴落 5 萬次，必須先被另一道低功率雷射「預整形」變扁，才能精準命中。

**推理**：EUV 光源功率一開始只有 10W 級，要到 2019 年才達到 250W——
產能（wafer/hour）與光源功率成正比，這是 EUV 延遲十年的核心原因。

### 2. 反射式鏡組：多層膜 Bragg 反射

EUV 幾乎被所有材料吸收，唯一解法是用**多層膜反射鏡**：

- 交替堆疊 Mo（鉬）與 Si（矽）薄膜各約 40 層，每層厚度僅數奈米；
- 當層厚 $d$ 滿足 Bragg 條件時，反射波同相疊加：

  $$
  2d\sin\theta = m\lambda, \qquad m\lambda = 2d\sqrt{1 - \frac{n^2\sin^2\theta}{1}}
  $$

- Mo/Si 介面反射率約 70% 單鏡，但光學系統需 **11 次反射**，總透射率：

  $$
  T = 0.7^{11} \approx 2\%
  $$

**推理**：98% 的光在鏡組中損失！這就是為何 EUV 需要 25kW 雷射，最後
打到晶圓上只剩數百瓦——每一分光的效率都生死攸關。

### 3. EUV vs DUV 對照表

| 項目 | DUV（浸潤式 193nm） | EUV（13.5nm） |
|------|---------------------|----------------|
| 光源 | ArF 準分子雷射 | 錫電漿 LPP |
| 光學 | 透鏡（折射式） | 11 面反射鏡（多層膜） |
| 環境 | 氮氣 | 真空（光被空氣吸收） |
| 單次曝光解析度 | ~38nm | ~13nm |
| mask | 透射式 | 反射式（6 層多層膜） |
| 光罩缺陷檢測 | 可見光即可 | 需要 actinic 檢測 |
| 多重曝光 | 需要（7nm 用 SAQP） | 單次曝光可解決 |
| 機台成本 | ~5000 萬美元 | ~1.5 億美元 |
| 光源功率 | 數百瓦 | 250W（2019） |

### 4. 為什麼 EUV 能「單次曝光」解決 7nm

$k_1 \approx 0.32$、$NA = 0.33$（EUV 第一代鏡頭）時：

$$
CD = \frac{0.32 \times 13.5}{0.33} \approx 13\,\text{nm}
$$

換句話說，EUV 單次曝光就能印出過去 DUV 需要 SAQP 四次曝光才能達成的線寬——
這直接砍掉了 mask 費用與製程誤差累積，這是 EUV 最強的商業邏輯。

### 5. Python 驗證：解析度與多重曝光的成本

```python
import numpy as np
import matplotlib.pyplot as plt

def resolution(lmbda, NA, k1=0.32):
    return k1 * lmbda / NA

# DUV 193nm 浸潤式
duv = resolution(193, 1.35)     # ~45.7 nm 單次曝光極限
# EUV 13.5nm
euv = resolution(13.5, 0.33)    # ~13.1 nm

print(f"DUV 單次曝光極限: {duv:.1f} nm")
print(f"EUV 單次曝光極限: {euv:.1f} nm")

# 多層膜反射率
T_single = 0.70
n_mirrors = 11
print(f"EUV 總透射率: {T_single**n_mirrors*100:.1f}%")

# 良率與 mask 成本：EUV 單次曝光 vs DUV SAQP 四重曝光
mask_cost_single = 3_000_000   # EUV mask（美元）
mask_cost_saqp = 4 * 2_000_000 # SAQP 需 4 個 DUV mask
print(f"EUV mask 成本: {mask_cost_single:,}")
print(f"SAQP mask 成本: {mask_cost_saqp:,}")

NA_range = np.linspace(0.2, 0.6, 100)
plt.plot(NA_range, resolution(13.5, NA_range), label="EUV 13.5nm")
plt.plot(NA_range, resolution(193, NA_range), label="DUV 193nm")
plt.xlabel("NA"); plt.ylabel("CD (nm)")
plt.title("Rayleigh resolution: EUV vs DUV")
plt.legend(); plt.savefig("euv_vs_duv.png")
```

執行結果：
- DUV 單次曝光極限約 45.7nm，EUV 約 13.1nm
- EUV 鏡組總透射率僅約 2%（$0.7^{11}$）
- EUV mask（3 個 mask）成本不到 SAQP（8 個 mask）的一半

## 結案 -- 後果與影響

- **2019**：台積電 N7+ 量產（第一個 EUV 製程），華為 Kirin、Apple A 系列晶片受惠。
- **2020s**：N5、N3 全靠 EUV（每片晶圓最多 20+ 道 EUV 層），ASML 成為全球唯一 EUV 供應商。
- **2024**：High-NA EUV（NA=0.55，解析度 <8nm）問世，單機 3.8 億美元。
- **地緣政治**：EUV 出口管制成為中美科技戰的核心議題（荷蘭/美國管制對中出口）。
- **摩爾定律的守門員**：沒有 EUV，3nm 以下節點幾乎不可能量產。
