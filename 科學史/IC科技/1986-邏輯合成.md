# 1986 - 邏輯合成：EDA 商業化的誕生

## 案件摘要
1986–1987 年，Synopsys（Aart de Geus 創立）推出 Design Compiler，讓工程師用 HDL 寫 RTL、由機器自動「合成」成閘級電路，並自動挑選最佳標準單元（standard cell）。邏輯合成把設計自動化工具從「大公司的內部秘密」變成「可銷售的商業產品」，EDA 產業正式誕生。

## 前因 -- 為什麼會有這個案子
- 手工設計閘級電路：數萬閘的晶片要人手畫出每個 NAND/NOR 的接線，錯誤率與人力成本都不可承受。
- 學界已有理論積累：Berkeley 的 Espresso（1984）解決兩層邏輯化簡、MIS（1987）解決多層邏輯優化。
- IBM、Bell Labs 等大公司有內部合成工具，但僅自用，不外售。
- Aart de Geus 在 GE（通用電氣）做內部合成工具時體認：**把工具獨立成公司、支援各家半導體廠的 cell library，才能把自動化推向全產業** —— 1986 年 Synopsys（原 Optimal Solutions）成立。

## 線索與推理 -- 數學式、程式、理論

### 1. 邏輯合成流程：RTL → 邏輯優化 → 閘級網表

$$
\text{RTL (HDL)} \xrightarrow{\text{high-level synthesis}} \text{布林網路}
\xrightarrow{\text{邏輯優化}} \text{優化網路} \xrightarrow{\text{technology mapping}} \text{閘級網表 (netlist)}
$$

1. **轉譯**：把 Verilog/VHDL 的 `always` 區塊轉成布林方程式集合。
2. **優化**：最小化布林函數的閘數與級數（兩層 → 多層）。
3. **Technology mapping**：把優化後的網路「映射」到目標製程的標準單元庫（standard cell library），使延遲/面積/功耗在給定 timing constraint 下最佳。

### 2. 卡諾圖與 Quine–McCluskey 演算法
兩層化簡的目標：求 SOP（Sum of Products）的最小覆蓋：

$$
f = \sum_{m \in M} m_i \quad\Rightarrow\quad f = \bigcup_{p \in P} p,\ \ |P| \text{ 最小}
$$

- **卡諾圖（Karnaugh Map, 1953）**：相鄰格子的最小項只差一個位元（格雷碼排序），可用人眼圈選 $2^k$ 大小的合併塊 —— 適合 4~6 變數。
- **Quine–McCluskey 演算法（1956）**：卡諾圖的系統化版本，可處理任意變數數。步驟：
  1. 列出所有最小項，兩兩比較合併（差一個位元者合併，記號打上 `-`），反覆迭代得**質蘊含項（prime implicants）**。
  2. 建立 **Prime Implicant Chart**：每個最小項需被至少一個質蘊含項覆蓋；先用 Essential PI 必選，再用 Petrick 氏法（或分支限界）求最小覆蓋 —— 本質上是集合覆蓋問題（NP-hard）。

### 3. Espresso：兩層化簡的工程突破（Berkeley, 1984）
Exact minimization（Q-M + Petrick）在變數多時爆炸，Espresso 啟發式（heuristic）地迭代：
- **EXPAND**：把每個 cube 擴張成儘可能大的質蘊含項。
- **IRREDUNDANT**：刪除多餘的 cube。
- **REDUCE**：縮小 cube 以便下一輪擴張出更好的解。

$$
C \xrightarrow{\text{EXPAND}} C' \xrightarrow{\text{IRREDUNDANT}} C'' \xrightarrow{\text{REDUCE}} C \quad (\text{迭代至不再改進})
$$

Espresso 以近似最優的速度與可擴展性，成為所有商業合成器的核心引擎，也被植入 IBM、Intel 內部工具。

### 4. 兩層 vs 多層邏輯優化
- **兩層邏輯**（AND-OR / PLA）：$f = \bigcup p_i$，優化目標是 cube 數與 literal 數（Espresso 的戰場）。
- **多層邏輯**（standard cell / ASIC）：允許巢狀結構，例如：

$$
f = x_1x_2x_3 + x_1x_2x_4 \;\Rightarrow\; f = x_1 x_2 (x_3 + x_4)
$$

  從 4 literals + 2 AND + 1 OR 降為 3 literals + 2 AND + 1 OR；級數（logic depth）增加但閘數減少 —— 在連線延遲主導的先進製程中，多層優化與 technology mapping 才是決勝關鍵（Berkeley MIS、Synopsys Design Compiler 的戰場）。

### 5. Technology Mapping（standard cell mapping）
理論上可轉換為**以樹覆蓋（tree covering）**為模型：把布林網路切成 DAG，用動態規劃在 cell library 中挑選匹配的子樹，最小化：

$$
\min_{\text{cover } T} \sum_{g \in T} \big(\alpha \cdot \text{area}(g) + \beta \cdot \text{delay}(g)\big)
$$

在 timing constraint（如 `create_clock -period 5`）下，合成器以「時間驅動」的 cost function 迭代優化面積與延遲。

### 6. Python 實作 Quine–McCluskey 簡化範例

```python
from itertools import combinations

def combine(a, b):  # 差一個位元則合併，差異處記 '-'
    diff = [i for i in range(len(a)) if a[i] != b[i] and '-' not in (a[i], b[i])]
    return None if len(diff) != 1 else a[:diff[0]] + ('-',) + a[diff[0]+1:]

def qm(minterms, nvars):
    groups = {tuple(format(m, f'0{nvars}b')) for m in minterms}
    primes = set()
    while groups:
        merged, used = set(), set()
        gs = sorted(groups)
        for a, b in combinations(gs, 2):
            c = combine(a, b)
            if c:
                merged.add(c); used |= {a, b}
        primes |= set(gs) - used          # 沒被合併者即質蘊含項
        groups = merged
    # 選擇覆蓋：貪婪近似（完整版應做 Prime Implicant Chart + Petrick）
    def covers(p, m): 
        return all(pc == '-' or pc == bit for pc, bit in zip(p, format(m, f'0{nvars}b')))
    cover = []
    remaining = set(minterms)
    while remaining:
        best = max(primes, key=lambda p: len({m for m in remaining if covers(p, m)}))
        cover.append(best)
        remaining -= {m for m in remaining if covers(best, m)}
    return cover

def to_string(cover, names):
    terms = []
    for p in cover:
        lits = [names[i] if b == '1' else f"{names[i]}'" 
                for i, b in enumerate(p) if b != '-']
        terms.append(''.join(lits) if lits else '1')
    return ' + '.join(terms)

if __name__ == '__main__':
    # f(x,y,z) = Σ m(1, 3, 5, 7)  =>  f = z（所有項都含 z）
    cover = qm([1, 3, 5, 7], 3)
    print(to_string(cover, ['x', 'y', 'z']))   # 輸出: z
    # f(a,b,c,d) = Σ m(0, 2, 8, 10) => f = b'd'（卡諾圖四角合併）
    cover = qm([0, 2, 8, 10], 4)
    print(to_string(cover, ['a', 'b', 'c', 'd']))  # 輸出: b'd'
```

## 結案 -- 後果與影響
- Design Compiler 成為業界事實標準，直到今日仍是 ASIC 前端合成的市場龍頭；「RTL + constraint → netlist」成為所有晶片公司的標準流程。
- EDA 從公司內部工具轉為獨立產業：Synopsys（1986）、Cadence（1988，由 SDA/ECAD 合併）、Mentor Graphics 更早（1981）—— 三強格局成形。
- 半導體廠專注製程與 cell library，設計公司專注 RTL 與架構，催生了 **fabless 模式**（TSMC 1987 成立正好接上這波浪潮，見 IP 授權與代工生態）。
- 邏輯合成理論持續演進：SAT-based optimization、實體合成（physical synthesis）、機器學習輔助合成（如 Google 用 RL 優化 place & route）。
