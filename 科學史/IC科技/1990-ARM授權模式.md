# 1990 - ARM 授權模式：IP-based SoC 的誕生

## 案件摘要
1990 年 Acorn Computers 與 Apple、VLSI Technology 合資成立 Advanced RISC Machines（ARM），獨立於母公司之外，開創「賣架構授權 + 收權利金」的 IP 商業模式。ARM 不製造晶片，卻成為全球手機與嵌入式時代的處理器霸主。

## 前因 -- 為什麼會有這個案子
- **Acorn RISC Machine 的源頭**：1985 年 Acorn 推出 ARM1（第一顆 ARM 晶片），原本是為自家 BBC Micro 電腦設計的 32 位元處理器。
- **RISC 哲學**：1980 年 Berkeley RISC（David Patterson）與 Stanford MIPS（John Hennessy）證明「精簡指令集 + 管線化」能用更簡單硬體達到更高效能：

$$
\text{CPI}_{\text{RISC}} \approx 1 \ll \text{CPI}_{\text{CISC}}
$$

- Acorn 用 Silicon Graphics 的 Biba 模擬器驗證想法後，以 NMOS 試製、後轉 CMOS，做出功耗極低的 ARM1（约 0.1 W 級），意外地在低功耗賽道上無人能敵。
- 1990 年前後 Acorn 財務困難；Apple 為 Newton PDA 尋找低功耗處理器，VLSI Technology 是 ARM 的代工夥伴 —— 三方合資，ARM 獨立成公司。

## 線索與推理 -- 數學式、程式、理論

### 1. RISC 架構特點
ARM 繼承 RISC 哲學的核心原則：

| 原則 | 說明 |
|------|------|
| Load/Store 架構 | 只有 `LDR`/`STR` 存取記憶體，運算指令只在暫存器間進行 |
| 固定長度指令 | ARM 指令一律 32 位元（Thumb 為 16 位元），解碼簡單、管線友善 |
| 大型暫存器堆 | 16 個通用暫存器 R0–R15（R13=SP, R14=LR, R15=PC） |
| 管線化 | ARM1 為 3 級管線（Fetch–Decode–Execute） |
| 條件執行 | 幾乎每條指令可帶條件碼（如 `ADDEQ`），減少分支 |

理論定義（load/store）：記憶體與暫存器的資料流被嚴格分離，

$$
\text{mem}[a] \leftrightarrow R_i \quad \text{僅限 load/store}, \qquad R_i \leftarrow f(R_j, R_k) \quad \text{運算指令}
$$

### 2. ARM 指令範例

```asm
; ARM 組合語言：計算 1+2+...+10（條件執行典範）
        MOV   r0, #0          ; sum = 0
        MOV   r1, #10         ; i = 10
loop    ADD   r0, r0, r1      ; sum += i      （r0 = r0 + r1）
        SUBS  r1, r1, #1      ; i-- 並設定旗標（S 後綴）
        BNE   loop            ; 若 Z=0 則跳回（條件分支）
        ; 結果 r0 = 55
```

```c
// 同邏輯的 C 版本，編譯後即上面的 ARM 碼
int sum10(void) {
    int sum = 0;
    for (int i = 10; i != 0; i--) sum += i;   // sum = 55
    return sum;
}
```

Thumb 指令集（1994，ARM7TDMI）把常用指令壓縮為 16 位元，程式碼密度提升约 30%，對記憶體有限的嵌入式系統（與手機）是致命武器：

$$
\text{code density}_{\text{Thumb}} \approx 1.3 \times \text{code density}_{\text{ARM}}
$$

### 3. ARM 授權模式（License + Royalty）
ARM 的商業創新在於「不賣晶片，賣設計」：

$$
\text{ARM 收入} = \underbrace{L}_{\text{授權費（license fee，一次性）}} + \underbrace{r \cdot N}_{\text{權利金（royalty，每顆晶片）}}
$$

- **處理器授權（Core License）**：被授權廠取得某代 ARM 核（如 Cortex-M4）的 RTL，整合進自己的 SoC，每出貨一顆付權利金 $r$（傳聞數美分至數美元）。
- **架構授權（Architecture License）**：取得完整 ISA 授權，可自行設計相容核心（Apple、高通（歷史）、Samsung 均為架構授權客戶）。
- 這個模式讓 ARM 風險極低（無晶圓廠、無庫存），卻隨客戶量產而指數成長 —— 「IP 授權」從此成為半導體產業的標準商業模式。

### 4. Apple Newton 與 ARM6
- 1990 年合資後第一個大客戶就是 Apple：Newton PDA 採用 **ARM610**（1993，ARMv3 架構），低功耗是 PDA 唯一能接受的選擇。
- Newton 商業上雖失敗，但證明了 ARM 核在手捧式裝置的價值；Apple 的投資（43% 股份）成為 ARM 早期的救命錢，1998 年 ARM 於 Nasdaq/LSE 上市，Apple 出售持股獲利豐厚。
- 2010 年代 Apple 自行設計 Apple Silicon（A 系列、M 系列），仍基於 ARM 架構授權 —— 2020 年 Mac 全面轉向 ARM（Apple M1）。

### 5. ARM 在手機時代的霸主地位
$$
\text{低功耗} \Rightarrow \text{電池裝置的唯一解} \Rightarrow \text{手機時代的全贏}
$$
- 1990 年代手機興起（Nokia 6110 用 ARM7TDMI），ARM 憑 Thumb + 低功耗拿下手機應用處理器市場。
- 今日智慧型手機的 SoC（Snapdragon、Apple A/M、MediaTek Dimensity、Samsung Exynos）全部以 ARM 架構為基礎；全球出貨的 ARM 晶片累計超過 2500 億顆。

### 6. IP-based SoC 設計的誕生
ARM 模式催生了「晶片即積木」的 SoC 設計方法學：

$$
\text{SoC} = \text{ARM Core} + \text{GPU IP} + \text{NPU IP} + \text{I/O IP} + \text{Bus (AMBA)}
$$

- ARM 同時制定了 **AMBA 匯流排標準**（AHB/APB/AXI），讓不同廠商的 IP 可以即插即用。
- IP 市場形成：ARM（處理器）、Imagination（GPU）、Synopsys/Cadence（介面 IP）、CEVA（DSP）—— 設計公司只需專注差異化模組，其餘「買 IP 積木」。
- 配合 fabless + TSMC 代工（1987），形成「IP 授權 → SoC 設計 → 代工製造」的現代半導體分工體系。

## 結案 -- 後果與影響
- ARM 證明「不製造晶片的晶片公司」可以成為產業霸主，IP 授權模式被 RISC-V（2010，開源 ISA）等後繼者效法。
- 手機、物聯網、嵌入式系統的處理器市場被 ARM 壟斷（智慧型手機應用處理器市佔超過 99%）。
- 2016 年 SoftBank 收購 ARM（320 億美元）；2023 年 ARM 重新於 Nasdaq 上市 —— IP 價值獲得資本市場認證。
- 2020 年 Apple M1 開啟 PC 產業的 ARM 轉向，RISC 架構首次在伺服器與桌機挑戰 x86（AWS Graviton、NVIDIA Grace）。
- Berkeley RISC → Stanford MIPS → ARM1 → ARM 授權 → RISC-V：一條跨越 40 年的精簡指令集血脈。
