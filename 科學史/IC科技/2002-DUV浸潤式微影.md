# 2002 - DUV 浸潤式微影：用一層水把 193nm 撐到 7nm

## 案件摘要
2002 年，林本堅（Burn-Jeng Lin）提出浸潤式微影構想：在鏡頭與晶圓之間注入一層水，
讓等效波長縮短、數值孔徑（NA）突破 1.0。ASML 於 2002–2004 年推出 TWINSCAN 量產機。
當 EUV 研發難產、乾式 193nm 撞上天花板時，這杯水為半導體業爭取了十年——
193nm 浸潤式從 90nm 一路撐到 7nm，TSMC 押寶成功，ASML 也自此登上霸主。

## 前因 -- 為什麼會有這個案子
- **乾式 193nm 撞牆**：Rayleigh 公式 $\text{CD} = k_1\lambda/\text{NA}$ 中，空氣折射率 $n=1$ 限制 NA $\le 1$（$\sin\theta \le 1$），實務上限約 0.93，65nm 以下走不下去。
- **EUV 難產**：13.5nm 光源功率、反射鏡與光阻全部不成熟，2000s 初期量產遙遙無期——產業需要過渡方案。
- **F2 157nm 是死路**：氟化物鏡片與光阻問題更兇，投資等於燒錢。
- **關鍵推理**：水的折射率 $n = 1.44$，把空氣換成水，等效波長變 $\lambda/n$、NA 變 $n\sin\theta$——

$$
\text{CD} = k_1 \frac{\lambda/n}{\text{NA}_{\text{water}}} ,\qquad \text{NA}_{\text{water}} = n \sin\theta \approx 1.35
$$

不用新光源，只加一層水，解析度直接提升一個世代。

## 線索與推理 -- 數學式、程式、理論

### 1. 案件現場：乾式 vs 浸潤式的對照

$$
\begin{aligned}
\text{乾式} &: \text{CD} = k_1\frac{193}{0.93} \approx 0.3\,\mu\text{m}\cdot k_1,\qquad \text{DOF} = k_2\frac{\lambda}{\text{NA}^2} \\
\text{浸潤} &: \text{CD} = k_1\frac{193/1.44}{1.35} = k_1\frac{134}{1.35},\qquad \text{等效波長} = 134\,\text{nm}
\end{aligned}
$$

- 浸潤的等效波長約 $134\,\text{nm}$，比乾式短 $30\%$；NA 從 0.93 推到 1.35，解析度再進一步。
- 景深 $\text{DOF} \propto \lambda/\text{NA}^2$ 在浸潤下更短——光阻厚度、晶圓平整度與 topcoat 成為新戰場。

### 2. NA 的物理：$n\sin\theta$ 的極限

數值孔徑定義 $\text{NA} = n\sin\theta$，$\theta$ 是最大會聚半角：

- 空氣（$n=1$）：$\text{NA} \le 1$，實務 0.93——乾式永遠過不了 1.0。
- 水（$n=1.44$）：理論上限 1.44，實務 1.35（考慮極化損耗與鏡頭設計）。
- 浸潤式不是新技術的發明，而是**舊光學的極限利用**——Scoppel（1980s）早有專利，林本堅把它推到量產可行。

### 3. TWINSCAN：雙工藝台的產能翻倍

量產微影是「曝光一張 → 換下一張 → 對準 → 曝光」，對準時間是死時間。
ASML TWINSCAN 用**兩個獨立工件台**：一個在量測對準，另一個同時在曝光——

$$
\text{產能} = \frac{1}{\max(\text{曝光時間},\ \text{對準時間})} \quad\text{（原本是兩者相加）}
$$

工件台的磁浮高速移動（秒級對準）讓浸潤式機台的產能不降反升。

### 4. 極化與缺陷：水的代價

- **極化效應**：NA > 1.0 後光線以大角度入射，p 極化與 s 極化的透射率分離，必須控制入射偏振。
- **水痕與缺陷**：晶圓高速移動時水膜拖尾、氣泡與污染風險——以浸沒罩（inmersion hood）與 topcoat 防護膜解決。
- **光阻要求**：水中折射與光阻介面需要專用頂層塗布，防止光阻成分溶出。

### 5. Multi-patterning：浸潤式的續命術

 immersion + 雙重曝光（SADP/SAQP，self-aligned double/quadruple patterning）把 pitch 再減半：

$$
\text{pitch}_{\text{final}} = \frac{\text{pitch}_{\text{immersion}}}{2} \ (\text{SADP}),\qquad \frac{\text{pitch}}{4} \ (\text{SAQP})
$$

以 spacer 工藝（側壁沉積＋蝕刻）自我對準，套準誤差由 spacer 厚度決定而非機台 overlay——
浸潤式靠這招從 28nm 一路撐到 7nm，直到 2019 年 EUV 接班。

### 6. Python 實作：乾式 vs 浸潤式解析度

```python
def rayleigh(k1, wavelength, na):
    return k1 * wavelength / na

def dof(k2, wavelength, na):
    return k2 * wavelength / na**2

k1, k2 = 0.30, 0.50
configs = [                        # (名稱, 波長 nm, 等效折射率, NA)
    ('g-line 乾式',   436, 1.00, 0.60),
    ('i-line 乾式',   365, 1.00, 0.65),
    ('KrF 248 乾式',  248, 1.00, 0.80),
    ('ArF 193 乾式',  193, 1.00, 0.93),
    ('ArF 193 浸潤',  193, 1.44, 1.35),   # 水浸潤：等效波長 134nm
]
for name, lam, n, na in configs:
    eff = lam / n
    cd = rayleigh(k1, eff, na)
    print(f"{name:12s} λ_eff={eff:5.0f}nm NA={na:.2f}  CD={cd*1000:6.1f}nm  DOF={dof(k2, eff, na)*1000:6.1f}nm")
# g-line 乾式   λ_eff=  436nm NA=0.60  CD= 218.0nm  DOF= 605.6nm
# i-line 乾式   λ_eff=  365nm NA=0.65  CD= 168.5nm  DOF= 432.1nm
# KrF 248 乾式  λ_eff=  248nm NA=0.80  CD=  93.0nm  DOF= 193.8nm
# ArF 193 乾式  λ_eff=  193nm NA=0.93  CD=  62.3nm  DOF= 111.6nm
# ArF 193 浸潤  λ_eff=  134nm NA=1.35  CD=  29.8nm  DOF=  36.7nm  ← 半個世代
```

（浸潤式把 CD 從 62nm 推到 30nm——以 k1 優化與 multi-patterning，實務做到 20nm 以下。）

## 結案 -- 後果與影響
- **193nm 撐了三個世代**：90nm → 65nm → 45nm → 28nm → 14/7nm（加 multi-patterning），一種波長用十五年，半導體史上最長壽的光刻方案。
- **TSMC 的賭注**：林本堅說服台積電押寶 immersion，跳過 157nm；Intel 堅持 EUV-first 反而落後——浸潤式戰役是 TSMC 超車的轉捩點。
- **ASML 登基**：Nikon/Canon 在 immersion 路線上慢半拍，ASML TWINSCAN 獨占量產市場，為 2019 年 EUV 霸業鋪路。
- **理論延續**：極化控制、multi-patterning、stitching、以及 EUV 的 k1 優化，都建立在 immersion 時代的工具鏈上。
