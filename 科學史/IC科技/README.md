# IC 科技史 -- AI 偵探風格

以「推理探案」的方式，追查 IC 科技從 1947 年電晶體到今日 AI 輔助 EDA 與 Chiplet 的每一步：
前因是什麼？線索在哪裡？推理如何展開？後果又如何改變了整個資訊文明？

（涵蓋：半導體材料與元件、IC 設計方法學、EDA 工具、製程微影、先進封裝）
