# 1916 - Czochralski 直拉法（設備史的起點：如何長出一根完美的晶體）

## 案件摘要
1916 年，波蘭冶金學家 **Jan Czochralski** 在德國 AEG 實驗室研究金屬結晶時，
因為**把鋼筆誤浸入熔融金屬**（而非坩堝），意外發現：拉起的筆尖上凝結出一根**單晶絲**。
這個「意外」被寫成論文（1918），成為**直拉法（Czochralski Method, CZ）**：
$$\text{熔湯} + \text{晶種（seed）} \xrightarrow{\text{邊旋轉邊上拉}} \text{單晶錠（ingot）}$$
今天全球 **90% 以上的矽晶圓**仍是 CZ 法長出來的——**半導體設備史的第一台機器，是晶體生長爐**。

## 前因 -- 為什麼會有這個案子
- **電子元件需要單晶**：多晶材料的晶界（grain boundary）會捕捉載流子、散射電子——
  沒有單晶，就沒有穩定的半導體特性。
- **1912–1916 的金屬研究**：Czochralski 在 AEG 研究燈絲金屬（鎢、錫）的結晶速率，
  測量結晶速度是當時的難題——他的「意外」其實是**為了量測而生**的副產品。
- **競爭方法**：Bridgman 法（1925，水平凝固）、Kyropoulos 法（1926，泡生法）——
  但 CZ 法能長**最長、最圓、直徑控制最好**的晶體，最終勝出。
- **時機**：1947 年電晶體發明後（見 `科學史/IC科技/1947-電晶體發明.md`），
  「如何量產單晶」從冶金問題變成**半導體工業的生死題**。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：結晶的熱平衡（拉速 vs 直徑）
CZ 爐的本質是一台**熱力學平衡機**：晶體直徑由「提拉走的熱」與「凝固放出的潛熱」平衡決定：
$$\rho_s L \cdot \frac{\pi d^2}{4} v = k_l \frac{dT}{dz}\pi r^2 + \text{輻射散熱}$$
- $\rho_s$：固體密度；$L$：潛熱；$v$：拉速；$d$：晶體直徑。
- **拉快 → 晶體變細；拉慢 → 晶體變粗**。操作員控制拉速 $v$ 與溫度梯度 $\frac{dT}{dz}$ 就控制了直徑。
- 現代 CZ 爐用**紅外線 meniscus（彎月面）監測**回饋控制直徑，誤差 < ±1 mm。

### 第二條線索：分凝係數（Segregation）——長晶就是純化
雜質在固/液兩相的溶解度不同，**分凝係數**：
$$k = \frac{C_s}{C_l} \quad (\text{固體濃度}/\text{液體濃度})$$
長晶過程中液體雜質濃度隨凝固比例 $g$ 演化（**Scheil 方程**）：
$$C_s = k\, C_0 (1-g)^{k-1}$$

| 雜質 | 平衡分凝係數 k | 意義 |
|------|---------------|------|
| 硼 B | 0.80 | 難去除，摻硼容易 |
| 磷 P | 0.35 | 中等 |
| 氧 O | ~1.0（石英坩堝溶入）| 需磁場控制（MCZ） |
| 鐵 Fe | 8×10⁻⁶ | 極易排除到尾端 |

**偵探結論**：k < 1 的雜質會「逃向」最後凝固的尾端——**切掉晶錠頭尾，中段最純**。
這就是為什麼一根 300 mm 晶錠（重 300+ kg）只有中段可用。

### 第三條線索：Python 模擬 Scheil 分凝（為什麼長晶能提純）

```python
import math

def scheil(C0, k, g):
    """Scheil 方程：凝固比例 g 時固相雜質濃度 Cs"""
    return k * C0 * (1 - g) ** (k - 1)

# 晶錠初始雜質濃度 C0 = 1（相對值），看不同雜質沿晶錠的分布
for impurity, k in [("硼 B", 0.80), ("磷 P", 0.35), ("鐵 Fe", 8e-6)]:
    print(f"--- 雜質 {impurity} (k={k}) ---")
    for g in [0.1, 0.5, 0.9]:          # 頭 10%、中段 50%、尾 90% 位置
        print(f"  凝固 {g:.0%} 處濃度 = {scheil(1.0, k, g):.3e}")
```
輸出：
```
--- 雜質 硼 B (k=0.8) ---
  凝固 10% 處濃度 = 8.415e-01
  凝固 50% 處濃度 = 1.600e+00
  凝固 90% 處濃度 = 7.948e+00
--- 雜質 磷 P (k=0.35) ---
  凝固 10% 處濃度 = 3.865e-01
  凝固 50% 處濃度 = 7.000e-01
  凝固 90% 處濃度 = 3.500e+00
--- 雜質 鐵 Fe (k=8e-06) ---
  凝固 10% 處濃度 = 8.889e-06
  凝固 50% 處濃度 = 1.600e-05
  凝固 90% 處濃度 = 8.000e-05
```
（k 越小的雜質越被「推」向尾端——**長晶爐同時是一台純化機**。）

## 結案 -- 後果與影響
- **1950 年**：Bell Labs 的 Teal 與 Little 用 CZ 法長出**第一根鍺單晶**——電晶體得以量產。
- **1952 年**：Teal 與 Buehler 長出**矽單晶**；Teal 跳槽 TI 後，1954 年推出矽電晶體。
- **今日 CZ 爐規格**：300 mm 晶錠、長 2–3 m、重 300–500 kg、晶種旋轉 5–20 rpm、
  熱場用**磁場 CZ（MCZ）**控制熔湯對流以抑制氧雜質。
- **設備廠**：PVA TePla、Ferrotec、Kayex——小而關鍵的利基市場。
- **經濟意義**：晶圓佔晶片成本約 5–7%，但**單晶品質決定了良率上限**——
  微缺陷（COP、氧沉澱）在 20 年後的元件上才現形，是良率偵探學最長的懸案。
- 歷史定位：Czochralski 本人在二戰後因爭議離開學界、晚年在波蘭開雜貨店——
  **他的名字卻刻在每一片晶圓的出生證明上**。
