# 2020s-量子糾錯與未來

## 案件摘要
2020 年代的主題是「從 NISQ 走向容錯」：用糾錯碼把不可靠的物理量子位元，編織成可靠的邏輯量子位元。偵探追蹤 2023–2024 年的多項里程碑——Google 證明 surface code 可低於門檻、IBM Heron 改善品質——線索指向容錯量子電腦的路線圖。

## 前因 -- 為什麼會有這個案子
- NISQ 時代（2018–）的硬體每個雙量子位元門都有約 1% 誤差，深度電路會被誤差淹沒——Shor 分解 2048 bit 整數需要約 $10^8$ 個閘，NISQ 無法承受。
- 經典糾錯靠「複製」位元，但 **no-cloning theorem** 禁止複製量子態；且量子錯誤是連續的（不僅是位元翻轉，還有相位翻轉 $Z$，以及任意組合 $X^a Z^b$）。
- 1995–1996 年 Shor 與 Steane 證明量子糾錯碼存在，開啟理論；但需要數千個高品質物理量子位元，硬體到 2020 年代才剛剛接近門檻。
- 謎題：誤差率多少以下，糾錯才能「越糾越好」而非「越糾越糟」？答案是**門檻定理**。

## 線索與推理 -- 數學式、程式、理論
### Shore code（9 量子位元碼，1995）
Shor code 用 9 個物理量子位元編碼 1 個邏輯量子位元，同時對抗位元翻轉與相位翻轉：

$$|0_L\rangle = \frac{1}{2\sqrt{2}}\big(|000\rangle+|111\rangle\big)^{\otimes 3},\quad |1_L\rangle = \frac{1}{2\sqrt{2}}\big(|000\rangle-|111\rangle\big)^{\otimes 3}$$

邏輯編碼：$|0\rangle \to |0_L\rangle$、$|1\rangle \to |1_L\rangle$。三層結構：內層 3 碼對抗 $Z$ 錯誤（相位），外層 3 碼對抗 $X$ 錯誤（位元翻轉）。可糾正任意單量子位元錯誤：

$$|\psi\rangle \to \alpha|0_L\rangle + \beta|1_L\rangle, \quad E|\psi\rangle \;\xrightarrow{\text{糾錯}}\; |\psi\rangle$$

### Surface code（2012 起主流）
surface code 是拓樸碼，將量子位元排列在 2D 方格上，以 **stabilizer**（穩定子）定義碼空間：

- 面算符（plaquette）：$A_p = \prod_{i \in p} Z_i$（檢測 $X$ 錯誤）
- 頂點算符（star）：$B_s = \prod_{i \in s} X_i$（檢測 $Z$ 錯誤）

碼空間滿足 $A_p|\psi\rangle = |\psi\rangle$、$B_s|\psi\rangle = |\psi\rangle$。距離 $d$ 的 surface code 用 $2d^2-1$ 個物理量子位元編碼 1 個邏輯位元，可糾正 $\lfloor (d-1)/2 \rfloor$ 個錯誤。例如 $d=3$（9 量子位元）糾 1 錯、$d=5$（25 量子位元）糾 2 錯。

邏輯錯誤率隨碼距指數衰減：

$$p_L \approx A\left(\frac{p}{p_{\mathrm{th}}}\right)^{(d+1)/2}$$

### 邏輯量子位元 vs 物理量子位元
- **物理量子位元**：真實硬體上的 transmon/離子/光子，誤差率 $10^{-3} \sim 10^{-4}$。
- **邏輯量子位元**：多個物理量子位元經糾錯編碼而成的「虛擬」高品質量子位元。
- **物理/邏輯開銷比**：surface code 約 100–1000:1，取決於物理誤差率與目標邏輯錯誤率。分解 RSA-2048 估計需約 400 萬個物理量子位元（較早期估計 2000 萬大幅下降）。

### 門檻定理
Aharonov–Ben-Or（1997）、Knill–Laflamme–Zurek（1997）證明：若每個物理閘的錯誤率低於門檻 $p_{\mathrm{th}}$，則可用糾錯將邏輯錯誤率壓到任意低，容錯量子計算可行，開銷僅為 polylog 因子。

- surface code 的門檻約 **~1%**（模擬值 $p_{\mathrm{th}} \approx 0.01$），是所有已知碼中最高的之一，這正是它成為硬體主流的原因。
- 條件：獨立、局部、且錯誤率低於門檻。若錯誤相關（如宇宙射線造成相鄰多位元錯誤），需額外處理。

### 2023–2024 里程碑
- **2023/2 Google**：3×3 與 5×5 surface code 實驗顯示 $d=5$ 的邏輯錯誤率低於 $d=3$，首次在真實硬體上驗證「碼距越大、邏輯越準」。
- **2023/12 IBM**：公布 **Heron** 處理器（133 量子位元，雙量子位元誤差約 0.1%），放棄盲目堆量子位元數，轉向品質；同時宣布以「邏輯量子位元」為路線圖核心。
- **2024/4 Google（Nature）**：d=7 surface code 實驗，邏輯量子位元壽命超過其最佳物理成分（below break-even），並展示即時解碼。
- **2024/9 Quantinuum + Microsoft**：用離子阱 + tesseract code 展示 12 個邏輯量子位元，邏輯錯誤率 $10^{-4}$ 量級。
- **2024/12 Google（Willow）**：105 量子位元 chip，d=3→5→7 邏輯錯誤率指數下降（低於門檻，each code distance step halves error），達成「below threshold」與「below breakeven」雙里程碑。

### 容錯量子電腦路線圖（Python 偽碼：surface code 邏輯錯誤率模擬）
```python
import numpy as np

def logical_error_rate(p, d, p_th=0.01, A=0.1):
    # 門檻定理下的邏輯錯誤率近似
    return A * (p / p_th) ** ((d + 1) / 2)

p = 0.003   # Heron 級別物理誤差率
for d in [3, 5, 7, 9, 11, 15]:
    n_phys = 2 * d * d - 1
    pL = logical_error_rate(p, d)
    print(f"d={d:2d}, phys={n_phys:4d}, p_L={pL:.2e}")

# 路線圖：先證明 below threshold，再 below breakeven，
# 最後用數百個邏輯量子位元跑 Shor 分解與量子化學
```

## 結案 -- 後果與影響
- **「below threshold」與「below breakeven」的雙重確認**（2023–2024）是本案的結案：容錯量子計算從理論證明走向工程現實。
- **路線圖**：2025–2030 年目標是數百至數千個邏輯量子位元，跑出 Shor 分解、量子化學模擬（FeMoco）、QEC 感知演算法。
- **量子網路**：量子中繼器 + 糾纏分發 → 量子網際網路；量子密碼（QKD、後量子密碼學）與 QEC 並行發展。
- **量子感測**：量子糾錯與糾纏增強的感測器（原子鐘、磁力計、重力儀）在 2020 年代初期商業化。
- 深遠影響：量子糾錯是把「量子霸權的存在性證明」轉化為「有實用價值的量子優勢」的唯一已知道路；2020 年代是這條道路的奠基十年。
