# 1995 - DVD

## 案件摘要
1995 年，Sony、Philips、Toshiba、Time Warner 等陣營達成 DVD 統一規格；1996 年在日本上市。光碟容量從 CD 的 0.7 GB 躍升到 4.7 GB（單層）／8.5 GB（雙層），電影發行被數位光碟重塑。

## 前因
- CD 容量裝不下 2 小時的 MPEG-2 影片（約 4–8 GB）。
- 1990 年代兩大陣營競爭：Sony/Philips 的 MMCD 與 Toshiba/Warner 的 SD-DVD，規格分裂將重演 VHS/Betamax 大戰——電腦業者（IBM 等）施壓統一，避免市場災難。

## 線索與推理

### 線索一：容量的物理偵探題
容量提升靠三件事：雷射波長縮短（780 nm → 650 nm 紅光雷射）、軌距縮小（1.6 μm → 0.74 μm）、雙層記錄。光學繞射極限決定最小記錄點：

$$d \approx \frac{\lambda}{2\,NA}$$

藍光（2006）再縮到 405 nm，容量再升到 25 GB/層——**波長就是容量**，這是繞射物理直接決定產品規格的案例。

### 線索二：MPEG-2 壓縮
DVD 採用 MPEG-2（1994）：I/P/B 幀結構 + 可變位元率（VBR）。電影的複雜場景分配更多位元、簡單場景更少，平均 4–6 Mbps 即可達到廣播級畫質——VBR 是「把位元花在刀口上」的統計智慧。

### 線索三：內容保護
數位完美複製帶來盜版恐懼，DVD 內建 CSS 加密。1999 年 DeCSS 破解（挪威少年 Jon Johansen）成為著名的法律與技術案件——**DRM 對抗**就此成為影音工業與網路世代的主戰場，一直延續到今日串流的 Widevine。

## 後果
- DVD 機成為史上普及最快的消費電子之一，租賃與銷售收入超越影院票房。
- MPEG-2 也成為數位電視廣播（ATSC、DVB）的基礎。
- 之後藍光（2006）接棒，再之後被串流（2010 年代）取代——光學介質的黃金時代落幕。
