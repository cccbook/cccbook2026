# 1952 Miller-Urey 原始湯實驗

## 案發現場

1950 年代初，生命起源是科學上最大懸案之一：地球誕生至今約 45 億年，最古老的化石證據顯示生命在數十億年前就已出現，但「無生命分子如何變成有生命系統」完全沒有實驗答案。當時主流的假設是蘇聯生化學家歐巴林（Alexander Oparin）與英國學者霍爾丹（J. B. S. Haldane）在 1920 年代提出的「原始湯」（primordial soup）理論：早期地球大氣是還原性的，充滿甲烷（$\mathrm{CH_4}$）、氨（$\mathrm{NH_3}$）、氫氣（$\mathrm{H_2}$）與水蒸氣（$\mathrm{H_2O}$），在閃電、紫外線等能量來源驅動下，這些簡單分子可以自發地合成出胺基酸等有機物，累積在原始海洋中，成為生命的化學原料。

但這只是「講得通的推測」。批評者指出：即使大氣成分如所推測，也從來沒有人能示範這種反應真的會發生。如果還原性大氣無法自發產生構成蛋白質的胺基酸，整個理論就會崩潰。

芝加哥大學的諾貝爾獎得主尤里（Harold Urey）正是行星大氣化學的權威，他對早期地球大氣成分的推斷是整個理論的基石。他的研究生米勒（Stanley Miller）在 1952 年提出一個大膽的博士論文計畫：與其空談假說，不如直接在實驗室裡「重演」早期地球。尤里起初很猶豫，擔心實驗失敗會浪費學生的時間，但在米勒的堅持下同意指導。這個實驗要回答的問題非常明確而重要：**生命的基本建材，能不能從無機分子加能量直接做出來？** 如果答案是肯定的，生命起源的研究就從哲學思辨變成可檢驗的實驗科學。

## 偵查過程

米勒的推理非常精巧。他首先問：早期地球有哪些現成的條件？他列出三項——還原性氣體混合物（$\mathrm{CH_4}$、$\mathrm{NH_3}$、$\mathrm{H_2}$、$\mathrm{H_2O}$）、液態水（模擬原始海洋）、以及閃電與紫外線（能量來源）。接著他設計一套密閉玻璃迴路系統：下方的燒瓶裝水加熱產生水蒸氣，蒸氣與混合氣體一起進入上方放電燒瓶，由連續電火花（模擬閃電）提供能量；反應產物經冷凝管凝結後流回燒瓶，再次蒸發循環——這模擬了「海洋蒸發、雨水落下」的水循環，讓反應產物不斷累積而不流失。

實驗的關鍵在於：整套系統是**隔絕外界汙染的密閉迴路**，因此實驗結束後任何有機物必定來自容器內的無機原料，這是鐵證般的邏輯設計。

從化學熱力學的角度看，這個反應的挑戰在於：胺基酸（例如甘胺酸 $\mathrm{NH_2CH_2COOH}$）相對於 $\mathrm{CH_4}$、$\mathrm{NH_3}$、$\mathrm{H_2O}$、$\mathrm{H_2}$ 是高自由能的分子。以標準生成吉布斯自由能估算，合成甘胺酸的反應

$$2\,\mathrm{CH_4} + \mathrm{NH_3} + 2\,\mathrm{H_2O} \rightarrow \mathrm{NH_2CH_2COOH} + 4\,\mathrm{H_2}$$

其 $\Delta G \approx +290\ \mathrm{kJ/mol}$，在熱力學上是明顯「上坡」的反應，平衡位置極度偏向左邊。米勒的策略因此有兩個支柱：第一，用電漿放電把 $\mathrm{CH_4}$ 等分子「打碎」，產生高能的中間體（如 H、$\cdot$CH$_3$、$\cdot$NH$_2$、HCN、HCHO 等自由基與活性分子）；第二，用持續迴路讓產物離開放電區、累積在水相中，使平衡不斷被「拉走」（Le Chatelier 原理的巧妙應用）——產物一旦生成就被移除，反應持續向右推進。

其反應網路的核心可概括為：

$$\mathrm{H_2O,\ CH_4,\ NH_3,\ H_2} \xrightarrow{\text{放電}} \mathrm{HCN,\ HCHO,\ 自由基} \xrightarrow{\text{水中縮合}} \text{胺基酸等有機物}$$

其中 HCN 與醛類的 Strecker 型縮合是生成胺基酸的主要途徑：醛與氨、HCN 反應生成胺基腈，再水解成胺基酸。

1952 年實驗執行一週後，米勒打開系統，發現水變成了黃褐色，裡面累積了豐富的有機物。以當時新問世的紙層析技術分析，證實其中含有甘胺酸與丙胺酸等多種 $\alpha$-胺基酸——正是構成蛋白質的建材。尤里看到結果後激動地說：「如果上帝沒有這樣安排，我也要這樣做。」這個「一週時間、兩個燒瓶」的實驗，把數十億年的地質時間壓縮到實驗室尺度。

值得一提的是，米勒保留的原始樣品在半世紀後（2008 年）被後人以更靈敏的現代質譜技術重新分析，發現當年其實產生了二十種以上的胺基酸，遠超過 1953 年論文報告的數量——技術進步讓老證據說出更多真相。

## 結案報告

1953 年，米勒以 23 歲之齡在《Science》發表了這篇成為傳奇的論文，題目只有兩句話的摘要。它的遺產極為深遠：

1. **生命起源化學的誕生**：這是第一個「前生物化學」（prebiotic chemistry）實驗，證明生命建材可從無機分子經能量驅動合成，讓生命起源從思辨變成實驗學科。
2. **實驗範式**：此後數十年，科學家改變氣體成分（加入 $\mathrm{CO_2}$、$\mathrm{N_2}$、$\mathrm{H_2S}$ 等）、改變能量源（紫外線、宇宙射線、衝擊波），重複了數百次變體實驗，幾乎都能產生有機物——顯示有機分子的生成在宇宙中是「普遍現象」而非偶然。
3. **地外化學與天體生物學**：米勒-尤雷類型的化學後來在隕石（如 1969 年的 Murchison 隕石發現數十種胺基酸）、彗星、星際塵埃雲中獲得直接驗證，催生了天體生物學。NASA 的星際探測任務（如泰坦號土衛六大氣研究）的化學基礎正是米勒-尤雷化學。
4. **與生物化學的橋樑**：胺基酸之外，後續實驗還合成了核糖核苷酸前驅物、脂質等，串起從簡單分子到 [1953-WatsonCrickDNA.md](1953-WatsonCrickDNA.md) 所揭示的核酸-蛋白質系統之間的化學階梯。

當然，此後的科學史也修正了原始理論：現代研究認為早期大氣可能不是純還原性的，而深海熱泉、乾濕循環、礦物表面催化等可能是更重要的場景。但無論細節如何修正，米勒-尤雷實驗證明的核心命題——**生命建材可以從簡單分子自發生成**——至今仍然成立。那兩個燒瓶裡的黃褐色液體，是化學史上離「生命的謎底」最近的一次撞擊。

## 證據與工具

**密閉迴路的動力學邏輯：** 設無機原料 A（$\mathrm{CH_4}$、$\mathrm{NH_3}$、$\mathrm{H_2O}$）、活性中間體 B（HCN、HCHO、自由基）、產物 C（胺基酸）。放電區以一階速率把 A 打碎成 B，B 在水相中縮合成 C：

$$\mathrm{A} \xrightarrow{\,k_1,\ \text{放電}\,} \mathrm{B} \xrightarrow{\,k_2,\ \text{縮合}\,} \mathrm{C}, \qquad \frac{d[\mathrm{C}]}{dt} = k_2[\mathrm{B}] > 0$$

密閉系中 C 只增不減、單調累積——這正是米勒裝置「冷凝回流」設計的動力學意義：產物一旦生成就離開放電區，平衡不斷被拉走（Le Chatelier 原理）。

| 裝置部位 | 對應反應 | 化學意義 |
|---|---|---|
| 放電燒瓶 | A → B（打碎分子） | 提供能量，驅動上坡反應 |
| 冷凝管＋水相 | B → C（縮合）並累積產物 | 產物離開反應區，拉動平衡 |
| 密閉迴路 | 原料回流、產物不流失 | 鐵證：有機物必來自容器內的無機原料 |

**熱力學上坡的定量檢驗：**

```python
import numpy as np

# 甘胺酸合成 2CH4+NH3+2H2O -> Gly+4H2 的 ΔG ≈ +290 kJ/mol
R = 8.314e-3          # kJ/(mol·K)
dG, T = 290.0, 298.0  # 標準自由能與溫度
K = np.exp(-dG / (R * T))
print(f"ΔG = +{dG} kJ/mol → K = {K:.3e}")
```

計算得 $K = e^{-290000/(8.314 \times 298)} \approx 10^{-51}$，平衡極度偏向反應物——沒有電漿放電等能量輸入，胺基酸幾乎無法自發累積。米勒的兩大支柱由此更清晰：(1) 放電打碎分子、供給能量；(2) 迴路移除產物、拉動平衡。
