# 1887 van't Hoff 滲透壓

## 案發現場

1880 年代，化學正面臨一場「溶液中的懸案」：氣體有明確的狀態方程 $PV = nRT$，溫度、壓力、體積之間的關係清晰優美；但溶液呢？把糖溶進水裡，溶液的行為似乎毫無規律可言——沒有人能寫出溶液的「狀態方程」。

這個問題之所以重要，是因為溶液現象到處都是：生理學家想知道為什麼紅血球放進純水會脹破、放進濃鹽水會皺縮；植物學家早已觀察到水會穿透半透膜往溶液一側移動（滲透現象，1748 年諾萊首次記載）；釀酒與製糖業需要計算糖液的濃度行為。但沒有一套理論能把這些現象串起來。

荷蘭化學家凡特何夫（Jacobus Henricus van't Hoff）遇到的直接難題，來自植物學家蒲弗雷（Wilhelm Pfeffer）1877 年的實驗數據。蒲弗雷用亞鐵氰化銅沉積在多孔瓷筒上製成堅固的半透膜，辛苦測量了蔗糖溶液的滲透壓。他的數據精確而規律，但蒲弗雷自己是植物學家，看不出數據背後的深意。

凡特何夫在瀏覽蒲弗雷的論文時，注意到一件令人起疑的事：**滲透壓隨濃度與溫度的變化方式，看起來神似氣體定律。** 這是巧合，還是暗示溶液中藏著一個「看不見的氣體」？

## 偵查過程

**第一步：檢驗數據的「神似之處」。** 凡特何夫把蒲弗雷的數據重新整理，逐一檢查滲透壓 $\pi$ 與濃度 $c$、溫度 $T$ 的關係。他發現兩條驚人的規律：

1. 定溫下，滲透壓與濃度成正比：$\pi \propto c$；
2. 定濃度下，滲透壓與絕對溫度成正比：$\pi \propto T$。

這兩條規律合起來，形式上正是氣體定律：

$$\pi V = nRT$$

其中 $V$ 是溶液體積，$n$ 是溶質莫耳數，$R$ 是與氣體常數**完全相同**的常數。凡特何夫甚至比較了數值：1 莫耳蔗糖在 22.4 升溶液中，0°C 時的滲透壓恰好約 1 大氣壓——與 1 莫耳理想氣體在同條件下的壓力一樣！

**第二步：提出理論推導。** 為什麼溶質明明被水分子包圍、根本不「自由」，卻表現得像理想氣體？凡特何夫的推理是：滲透壓只由溶質粒子的「撞擊」產生，溶質分子在稀溶液中稀疏地分散著，彼此幾乎不交互作用，行為如同理想氣體分子。數學上，若把濃度寫成 $c = n/V$，則滲透壓定律可改寫為：

$$\pi = cRT = \frac{n}{V}RT$$

這正是理想氣體定律的形式。更進一步，凡特何夫利用熱力學推導，把滲透壓與溶質的化學勢聯繫起來。對稀溶液，溶質的化學勢 $\mu = \mu^{\circ} + RT\ln c$，半透膜兩側的平衡條件要求施加壓力 $\pi$ 來抵消化學勢差，最終自然導出 $\pi V = nRT$。這條推導證明：**滲透壓定律不是經驗巧合，而是熱力學的必然。**

**第三步：遇上「電解質之謎」。** 正當理論看似完美時，一個新疑點出現了。凡特何夫把定律套用到電解質（如食鹽 NaCl、氯化鈣 CaCl₂）溶液時，發現測得的滲透壓**總是比理論值偏大**，有時大出一倍甚至數倍。數學上，這迫使凡特何夫引入一個修正係數 $i$（後稱凡特何夫因子）：

$$\pi V = i \, nRT$$

對蔗糖等非電解質，$i = 1$，理論完美；但對 NaCl，實驗給出 $i \approx 2$；對 CaCl₂，$i \approx 3$。這些奇怪的數值是什麼意思？為什麼恰好是 2 和 3？凡特何夫坦承無法解釋，只把 $i$ 稱為「不安分的係數」，並在論文中公開呼籲：「這個係數的意義，有待更深入的研究。」

這個懸案的答案，要等到他的鄰居——瑞典青年阿瑞尼士（Arrhenius）的電解解離說：NaCl 在水中解離成 Na⁺ 與 Cl⁻ 兩個獨立粒子，所以溶液中的「粒子數」是原來的兩倍，$i \approx 2$ 就這樣被自然解釋了（見 [1887-Arrhenius電解解離.md](1887-Arrhenius電解解離.md)）。兩人的理論互為佐證，成為科學史上跨領域合作的典範。

## 結案報告

**第一，溶液有了「狀態方程」。** $\pi V = nRT$ 把混亂的溶液現象納入定量框架，滲透壓、凝固點下降、沸點上升、蒸氣壓下降（統稱「依數性」colligative properties）連成一氣——它們只取決於溶質**粒子數**，而非粒子種類。這正是溶液粒子性的直接證據，支持了原子—分子學說。

**第二，為電解解離說提供了關鍵旁證。** 凡特何夫因子 $i$ 的數值規律（NaCl≈2、CaCl₂≈3）成為阿瑞尼士解離說最有力的獨立證據。1887 年兩人互讀論文後結為盟友，奧斯華（Ostwald）隨後加入，三人組成「離子學派」，共同催生了物理化學這門學科。

**第三，1901 年第一屆諾貝爾化學獎。** 諾貝爾獎首度頒發時，評審委員把化學獎授予凡特何夫，表彰他「發現化學動力學與滲透壓定律」。這是對整個物理化學新領域的加冕——溶液理論從植物學實驗室的旁支，一躍成為化學的核心支柱。

**第四，深遠的後續影響。** 滲透壓概念成為生理學的基礎（輸液的等張調配、腎臟的滲透調節）、高分子科學的分子量測定方法（20 世紀上半葉測量蛋白質與聚合物的莫耳數就靠滲透壓），以及逆向滲透海水淡化的理論源頭。一瓶糖水裡藏著的氣體定律，至今仍在醫院與海水淡化廠中運轉。

## 證據與工具

```python
# 用 Python 重現凡特何夫的「偵查」：檢驗滲透壓數據
R = 0.0821  # L·atm/(mol·K)，與氣體常數完全相同

def osmotic_pressure(c, T, i=1.0):
    """凡特何夫滲透壓定律 pi = i * c * R * T"""
    return i * c * R * T

# 案件一：蔗糖（非電解質）——與氣體定律完美吻合
print("== 蔗糖溶液（i=1）==")
print(f"1 M 蔗糖在 273 K（0°C）: π = {osmotic_pressure(1.0, 273):.2f} atm")
# 理想氣體 1 mol 在 22.4 L、0°C 也是 ~1 atm，數值神似！

# 檢驗比例關係：π ∝ c 與 π ∝ T
print("\n== 規律檢驗 ==")
for c in [0.1, 0.2, 0.3]:
    print(f"c={c} M, T=300K -> π={osmotic_pressure(c, 300):.3f} atm")
# 濃度加倍，滲透壓加倍 —— 與氣體定律同構

# 案件二：電解質之謎——實測值偏大
print("\n== 電解質之謎 ==")
solute = {"蔗糖": 1, "NaCl": 2, "CaCl2": 3}
for name, i in solute.items():
    pi_theory = osmotic_pressure(0.1, 300, i=1)   # 不考慮解離
    pi_actual = osmotic_pressure(0.1, 300, i=i)   # 考慮解離後的粒子數
    print(f"{name}: 理論 π={pi_theory:.3f} atm, 實際 π={pi_actual:.3f} atm, i={i}")
# i 恰為 2、3 —— 每個分子解離出的獨立粒子數
# 這正是阿瑞尼士電解解離說的獨立旁證
```
