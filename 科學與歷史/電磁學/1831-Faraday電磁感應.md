# 1831-Faraday 電磁感應

## 案件摘要
1831 年 8 月，法拉第（Michael Faraday）在追尋「轉磁為電」十年之後，發現變化的磁場會在導體迴路中感應出電流。法拉第定律 $\varepsilon = -d\Phi_B/dt$ 與冷次定律（負號）完成電磁學的對稱拼圖，並直接誕生發電機與變壓器。

## 前因 -- 為什麼會有這個案子
- **Oersted（1820）翻轉了問題**：既然「電生磁」，那麼「磁生電」應當也成立——這是自然對稱性的呼喚。
- **十年追尋（1821–1831）**：安培的分子電流假說問世後，法拉第於 1821 年成功製成電磁旋轉裝置（最早的馬達），但「磁生電」始終不得其門。他反覆嘗試：讓磁棒靜止靠近導線、讓導線靠近磁鐵、用地球磁場……全部失敗。
- **哲學預感**：法拉第相信自然力量彼此相連，磁力與電力之間必有轉換通道，只是尚未找到正確的「動態條件」。
- 線索暗示：他注意到靜電感應（帶電體使導體感應電荷）是「靜態」的；或許電磁感應也該存在某種一瞬間的效應，而他過去一直在找穩定電流。

## 線索與推理 -- 數學式、程式、理論

### 線索一：鐵環線圈實驗（1831 年 8 月 29 日）
- 法拉第用軟鐵彎成圓環，繞上兩個彼此絕緣的線圈 A（接電池與開關）與 B（接電流計）。
- **關鍵觀察**：僅在開關**接通與切斷的瞬間**，B 線圈的電流計指針才偏轉；電流穩定流動時指針完全靜止。
- 現代解釋：接通瞬間磁通量從 0 上升、切斷瞬間從飽和下降，兩次都是 $\Phi_B$ 隨時間**變化**才感應出電動勢。
- 法拉第當即追問：如果讓磁棒在線圈中**插入與拔出**呢？10 月 17 日他證實：磁棒插入或拔出的瞬間有電流，方向相反；磁棒靜止時無電流。「轉磁為電」終於成功。

### 線索二：法拉第定律
感應電動勢等於磁通量對時間變化率的負值：

$$
\varepsilon = -\frac{d\Phi_B}{dt}, \qquad \Phi_B = \int_S \mathbf{B}\cdot d\mathbf{A}
$$

### 線索三：冷次定律（負號的物理意義）
1834 年俄國物理學家冷次（Heinrich Lenz）指出：感應電流的方向總是**抵抗磁通量的變化**——這正是公式中的負號。$N$ 匝線圈時：

$$
\varepsilon = -N\frac{d\Phi}{dt}
$$

**推理驗證**：若感應電流「助長」而非抵抗磁通變化，能量將無中生有（永動機），違反能量守恆。故負號是能量守恆在電磁學中的必然表現：磁棒插入時線圈排斥它（你必須做功），這份功正是感應電流的能量來源。

### 線索四：場線概念的發明
- 法拉第拒絕超距作用：磁鐵與導線之間並無接觸，電流卻出現。他提出**場線（力線）**概念——磁鐵周圍佈滿真實的力線，導線切割力線（或力線被迴路包圍的數目變化）時即感應電流。
- 場線把「超距作用」轉換為「場是空間中的實體，變化以某種方式在場中傳播」。這是場論的誕生：Maxwell 正是繼承法拉第的力線圖像，將其翻譯為數學，寫出 Maxwell 方程組。

### 線索五：發電機與變壓器的誕生
- 法拉第緊接著於 1831 年 10 月製成**圓盤發電機**：銅盤在馬蹄形磁鐵間旋轉，盤心與盤緣即可引出持續電流——第一台發電機。
- 鐵環線圈本身就是**變壓器**的原型：$N_1/N_2$ 匝數比決定電壓比，$\varepsilon_2 = -N_2\, d\Phi/dt$。交流電技術（Westinghouse、Tesla）的理論基礎由此奠定。

### Python：模擬感應電動勢

```python
import numpy as np
import matplotlib.pyplot as plt

N   = 100        # 線圈匝數
A   = 0.01       # 線圈面積 (m^2)
B0  = 0.5        # 磁場峰值 (T)
w   = 2*np.pi*5  # 磁場變化角頻率（5 Hz，模擬磁棒往復插入拔出）

t = np.linspace(0, 1, 1000)
B = B0*np.cos(w*t)               # 隨時間變化的磁場
dPhi_dt = -B0*w*np.sin(w*t) * A  # dPhi/dt
emf = -N*dPhi_dt                 # 法拉第定律 ε = -N dΦ/dt

fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(8, 6), sharex=True)
ax1.plot(t, B, 'b', label=r'$B(t)$ (磁棒位置)')
ax1.set_ylabel('B (T)'); ax1.legend(); ax1.grid(alpha=0.3)
ax2.plot(t, emf, 'r', label=r'$\varepsilon = -N\,d\Phi/dt$')
ax2.set_ylabel('EMF (V)'); ax2.set_xlabel('t (s)')
ax2.legend(); ax2.grid(alpha=0.3)
ax2.set_title('Faraday induction: EMF peaks when B changes fastest,\n'
              'zero when B is at extremum (磁棒靜止時無電流)')
plt.tight_layout(); plt.savefig('faraday_emf.png', dpi=120); plt.show()
```

觀察模擬結果可驗證實驗規律：磁棒在極端位置（$B$ 最大，即插得最深、靜止）時電動勢為零；磁棒運動最快（$B$ 變化最陡）時電動勢最大；插入與拔出（$B$ 上升與下降）產生反向電流——完全對應法拉第 1831 年電流計指針的行為。

## 結案 -- 後果與影響
- **電力時代**：發電機（法拉第圓盤 → 西門子自激發電機 1866 → 交流發電機）使人類得以大規模生產電能；變壓器使交流輸電成為可能。現代文明的一切電力皆源於 $\varepsilon = -d\Phi_B/dt$。
- **場論的誕生**：場線概念由 Maxwell 數學化（1865），再由 Einstein 發揚（狹義相對論即源於電磁場的對稱性）。
- **對稱拼圖完成**：電生磁（Oersted/Ampère）＋磁生電（Faraday）→ Maxwell 方程組的四式已有其三，只待位移電流補全。
- 法拉第拒絕受封爵士、兩度婉拒皇家學會主席，只以「自然哲學家」自居；法拉第常數（每莫耳電子電量 96485 C）與感應單位以他命名。
