# 1637 - Descartes 解析幾何

## 案件摘要
1637 年，笛卡爾（René Descartes）在《方法論》附錄《幾何學》（*La Géométrie*）中，用座標與方程統一了幾何與代數：曲線就是方程，方程就是曲線。幾何問題從此可以翻譯成代數問題機械求解，並為微積分的誕生鋪路。

## 前因 -- 為什麼會有這個案子
- **古希臘幾何的束縛**：歐幾里得與阿波羅尼奧斯的幾何全靠圖形與公理推理，圓錐曲線的研究繁瑣而封閉；每條曲線需要專門的幾何理論。
- **代數工具已就位**：韋達 1591 年的符號代數提供了字母表示數量的方法（見前案 1591-Viète），但韋達仍受「齊次性」量綱束縛，未將數與線段自由等同。
- **實際需求**：17 世紀天文、光學、力學需要描述運動軌跡（橢圓、拋物線、旋輪線），古法不堪用。
- **費馬的平行工作**：費馬（Pierre de Fermat）約 1629 年寫成《平面與立體軌跡引論》（*Ad locos planos et solidos isagoge*，1679 年才出版），已獨立建立「方程 ↔ 軌跡」的思想。

## 線索與推理 -- 數學式、程式、理論

### 線索一：座標系統與曲線方程的統一
笛卡爾的關鍵操作：取一條基準線與一點 $O$，平面上任一點 $P$ 由兩個「長度」$(x, y)$ 決定。曲線的**幾何條件**被翻譯為 $x, y$ 之間的**代數方程**。

| 幾何問題 | 代數翻譯 |
|---|---|
| 到兩定點距離相等的點的軌跡 | $x^2 + y^2 = r^2$（圓） |
| 到定點與定直線等距的點的軌跡 | $y^2 = 4px$（拋物線） |
| 兩定點距離之和為常數 | $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$（橢圓） |

**推理核心**：一旦曲線 = 方程，「解幾何問題」就化約為「操作代數式」——求交點是解聯立方程，求切線是分析方程在該點的行為。幾何的每個難題都獲得了一條代數的機械通路。

### 線索二：費馬的獨立發現與優先權之爭
- 費馬約 1629 年的手稿已陳述：凡含 $x, y$ 的方程皆對應一條軌跡（locus），並給出直線、圓、圓錐曲線的方程形式。
- 笛卡爾的《幾何學》1637 年出版後，費馬去信指出優先權並批評其方法；兩人透過 Mersenne 學術圈往來筆戰多年。
- **史學裁定**：兩人獨立發現。費馬的版本更接近現代座標幾何（垂直座標、系統的軌跡理論）；笛卡爾的版本影響更廣（出版問世、符號現代化、斜座標與尺規作圖的分類）。此案無唯一兇手，是「同時案的雙兇」。

### 線索三：符號現代化
笛卡爾完成了我們今天使用的記號系統：
- **未知數**用末尾字母 $x, y, z$；**已知數**用開頭字母 $a, b, c$（承襲並改進 Viète 的母音/子音方案）。
- **指數記法**：$x^2, x^3, x^4$ 取代「x 的平方」的文字描述（雖然 $x^2$ 曾以 $xx$ 過渡）。
- 引入 $=$、$+$、$-$ 的近似現代用法，使方程式緊湊可讀。

### 線索四：通往微積分
《幾何學》提出求法線與切線的方法（以圓與曲線的交點極限處理），直接啟發了：
- Newton 與 Leibniz 在 1660–1670 年代發展微積分時，處理的對象正是「曲線的方程」——導數 $y' = \frac{dy}{dx}$ 是座標語言下的瞬間變化率。
- 沒有解析幾何，「函數」與「曲線」無法同一化，微積分便無處著力。

### 線索五：Python matplotlib 畫出方程對應的曲線

```python
import numpy as np
import matplotlib.pyplot as plt

t = np.linspace(-2, 2, 400)
X, Y = np.meshgrid(t, t)

fig, axes = plt.subplots(1, 3, figsize=(14, 4))
curves = [
    ("圓: x^2 + y^2 = 4",        X**2 + Y**2 - 4),
    ("拋物線: y = x^2 - 1",      Y - (X**2 - 1)),
    ("橢圓: x^2/4 + y^2 = 1",    X**2/4 + Y**2 - 1),
]
for ax, (title, F) in zip(axes, curves):
    ax.contour(X, Y, F, levels=[0], colors="navy")
    ax.set_title(title); ax.set_aspect("equal"); ax.grid(True, alpha=0.3)
plt.tight_layout(); plt.show()
```

每個代數方程畫出一條幾何曲線——這正是「幾何問題 → 代數問題」雙向通路的直接展示。

## 結案 -- 後果與影響
- **幾何代數化**：幾何不再自足，成為代數的「應用領域」；阿波羅尼奧斯數百頁的圓錐曲線理論，被幾個方程式壓縮。
- **催生微積分**：解析幾何是 Newton–Leibniz 微積分的必要前置條件（17 世紀數學的樞紐案件）。
- **推廣到高維**：座標思想日後推廣至三維、$n$ 維空間、乃至 19 世紀的非歐幾何與 20 世紀的廣義相對論（時空座標）。
- **記號的勝利**：$x, y, z, a, b, c$ 與 $x^2$ 成為全球通用、三百餘年不變的標準記法。
