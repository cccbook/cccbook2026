# 1915-米爾斯手榴彈：口袋裡的炮彈

## 案件摘要

1915 年，英國工程師威廉·米爾斯（William Mills）設計 No.5 手榴彈：鑄鐵刻槽彈體、槓桿擊針、七秒延期引信——**塹壕戰把這門已退役的古老武器重新請回戰場，並以工業量產的方式把它變成步兵常備**。到 1918 年，英軍產量約三千五百萬枚。本案偵破的問題是：為什麼日俄戰爭與一戰壕溝，會讓一種近乎被遺忘的冷兵器時代遺物復活？

## 前因 -- 為什麼會有這個案子

- 1904–1905 日俄戰爭：旅順塹壕戰中，日軍以手投炸藥攻擊俄軍據點——手榴彈的戰場價值被重新發現（[1905-旅順攻防戰.md](1905-旅順攻防戰.md)）。
- 1914 開戰即短缺：英軍以果醬罐、釘子與炸藥自製「果醬罐炸彈」（加里波里大量使用）——**武器的缺口用廚房填補**。
- 1913 年德國已有鋼珠手榴彈（Kugelhandgranate）——德軍先行，英軍追趕。
- 投擲距離的物理極限：人臂拋投 15–30 公尺——手榴彈是「人臂射程內的炮彈」。

## 線索與推理 -- 破片力學與引信行為學

### 線索一：破片力學

鑄鐵刻槽彈體：爆轟波沿刻槽撕裂鑄鐵，產生數百枚破片，初速約數百 m/s：

| 半徑 | 性質 |
|------|------|
| 0–10 公尺 | 有效殺傷（破片密度高） |
| 10–30 公尺 | 隨機殺傷（破片稀疏） |
| 投擲距離 | 約 15–30 公尺 |

**殺傷半徑 ≈ 投擲距離**——投彈者自己就站在殺傷半徑邊緣：手榴彈的戰術本質是「與死神交換位置」的近距離武器。

### 線索二：引信設計——時間即戰術

槓桿擊針＋延期藥盤：**釋放槓桿即起計時，約七秒後爆炸**。

- 七秒的設計：長到可滾入壕溝、短到敵人來不及回扔；
- 但投彈者可以「捏著引信預延」（cook-off 一至兩秒再扔）壓縮對方反應時間——代價是引信公差下的自爆風險；
- **引信時間不只是工程參數，是行為設計**：它決定了「松手即計時」的戰術文化與危險規則。

### 線索三：戰役紀錄與成效

| 戰場 | 年代 | 成效 |
|------|------|------|
| 旅順 | 1904–1905 | 手投炸藥攻擊塹壕據點——復活的預演（[1905-旅順攻防戰.md](1905-旅順攻防戰.md)） |
| 加里波里 | 1915 | 果醬罐炸彈 vs 德式鋼珠彈——短缺之戰 |
| 索姆河 | 1916 | 「轟炸隊」（bombing parties）沿壕開路，逐段清掃（[1916-索姆河與坦克登場.md](1916-索姆河與坦克登場.md)） |
| 一戰全線 | 1915–1918 | 英軍產約 3,500 萬枚；塹壕夜襲與坑道戰標配 |

### 線索四：編制創新——轟炸隊

塹壕跳蚤戰催生「轟炸隊」編制：投彈兵（前方投擲）＋掩護槍手（壓制壕溝拐角）＋搬運兵（循環補彈）——**隊形跟著武器射程走**：15–30 公尺的人臂射程，產生了沿壕逐段推進的「接力投彈」戰法。

## 破案時刻

- 1915–1916：米爾斯彈量產＋斯托克斯迫擊炮（[1915-斯托克斯迫擊炮.md](1915-斯托克斯迫擊炮.md)）＋馬克沁機槍——**塹壕近戰三件套完成**。
- 手榴彈從「短缺時的應急品」變成「步兵常備」：每名士兵口袋裡的標準負重。

## 後果 -- 改變了什麼

- 手榴彈成為步兵常備至今：破片控制（預製破片）、衝擊彈、燃燒彈、反裝甲彈——門類爆發。
- 班級火力進一步下放：每名士兵都是「單人炮兵」——與 MP18 衝鋒槍（[1918-MP18衝鋒槍.md](1918-MP18衝鋒槍.md)）共同重寫近戰。
- 城市戰的通用武器：從斯大林格勒到現代巷戰，手榴彈是「進屋的第一聲問候」。

## 戰法演進筆記

1. **武器的考古復活**：冷兵器時代的擲石 → 日俄的手投炸藥 → 1915 的鑄鐵彈——武器演化不是單向淘汰，是「舊概念＋新工藝」的復活。
2. **引信時間＝行為設計**：七秒引信決定了投彈戰術、危險規則與「cook-off」文化——工程參數生成戰術行為。
3. **殺傷半徑 ≈ 投擲距離**：手榴彈是「與死神交換位置」的武器——射程即風險。
4. **便宜＋可量產＋單兵**＝永遠不會退役的武器（同規律：RPG-7、FPV 無人機 [2022-俄烏戰爭與FPV無人機.md](2022-俄烏戰爭與FPV無人機.md)）。
