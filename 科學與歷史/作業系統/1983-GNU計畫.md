# 1983 - GNU 計畫（自由軟體運動的開端）

## 案件摘要
1983 年 9 月，MIT 人工智慧實驗室的 Richard Stallman 宣布 **GNU** 計畫：
重建一個**完全自由**的 Unix 相容作業系統——「GNU's Not Unix」。
$$\text{自由} = \text{使用、研究、修改、再發布的權利}.$$
軟體從「商品」變成「知識的共同體」——**自由軟體運動的誕生**，
9 年後 GNU 工具 + Linux 核心（見「1991-Linux誕生.md」）組合成 GNU/Linux——
史上最大的軟體協作體系。

## 前因 -- 為什麼會有這個案子
- **MIT 實驗室的共享文化**：1970 年代 MIT AI Lab 的軟體**自由共享**——任何人可以讀、改、改進任何程式。Stallman 是這個文化的化身。
- **文化的崩潰**：1980 年代初，實驗室的工程師紛紛**帶著程式創業**（Symbolics、LMI）——原始碼變成商業機密；印表機驅動程式事件（Stallman 想修改 Xerox 印表機的驅動程式，卻拿不到原始碼）成為導火線。
- **Stallman 的偵探直覺**：與其哀悼共享文化的死亡，不如**重建它**——寫出一個「自由的 Unix」，永遠不會再被封閉。
- **法律武器**：1985 年設立 FSF（自由軟體基金會），1989 年發布 **GPL 授權**——用**著作權法保障自由**（copyleft）——法律上的偵探手法。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：四大自由（自由的定義）
Stallman 給「自由軟體」精確定義：
1. **自由之 0**：為任何目的執行程式的自由。
2. **自由之 1**：研究與修改程式的自由（需原始碼）。
3. **自由之 2**：再發布副本的自由。
4. **自由之 3**：發布修改版的自由。

### 第二條線索：Copyleft 的法律推理（GPL）
傳統版權禁止複製；**GPL 用版權**強制自由：
$$\text{GPL 軟體的衍生品} \quad \Longrightarrow \quad \text{必須也以 GPL 發布（原始碼公開）}.$$
- **病毒式授權**：一旦連結 GPL 程式碼，整個作品必須 GPL——**自由的法律傳染性**。
- 這是一個博弈論上的聰明設計：個別企業想封閉，但法律結構使「封閉」不可能——**自由成為不可逆的均衡**。
- **LGPL**（1991）：函式庫版放寬（允許非自由軟體連結）——務實的折衷。

### 第三條線索：GNU 工具鏈的重建
Stallman 逐件重建 Unix 的工具鏈——**每件都是自由版**：
| 工具 | 說明 |
|------|------|
| GNU Emacs (1985) | 可擴充編輯器 + Lisp 直譯器 |
| GCC (1987) | 可移植的 C 編譯器（→ 全語言家族） |
| GNU Make / Bash / Coreutils | 建構與 shell 工具 |
| GLibc (1987) | C 函式庫 |

缺一塊拼圖：**核心 (kernel)**。GNU 自己的 Hurd 核心進度緩慢——這個缺口由 Linux（1991）補上（見「1991-Linux誕生.md」）。

### Python：GPL 生態的博弈模擬

```python
import numpy as np

# 簡化博弈：各企業選擇「開放」或「封閉」
# GPL 規則：用了 GPL 程式碼必須開放 → 封閉者無法搭便車
n = 100
choices = np.random.choice(["open", "closed", "proprietary"], n, p=[0.2,0.3,0.5])
# GPL 的傳染性：proprietary 若連結 GPL 組件 → 法律風險 → 轉向 open 或自寫
turn = np.random.rand(n) < 0.5
choices[(choices=="proprietary") & turn] = "open"
print("轉向後生態分佈:", {c: (choices==c).sum() for c in set(choices)})
```
（GPL 使「搭便車」在法律上不可能——開放成為穩定均衡。）

## 結案 -- 後果與影響
- **自由軟體運動誕生**：FSF（1985）、GPL（1989）、四大自由——**軟體自由的哲學與法律基礎**。
- **GNU 工具鏈的統治**：GCC、Emacs、Bash、Coreutils 成為所有 Unix/Linux 系統的標準配備——**自由工具鏈無所不在**。
- **GNU/Linux 的組合**：1991 年 Linux 核心補上缺口（見「1991-Linux誕生.md」）——GNU 工具 + Linux 核心 = 完整的自由作業系統，統治伺服器與手機世界。
- **開源運動的先驅**：1998 年 OSI「開源 (open source)」術語從 GPL 生態中分化——務實派與理念派並行；今天 AI 的開源模型（Llama 等）都站在 GPL 的肩膀上。
- 歷史定位：Stallman 獲 1990 年 MacArthur 獎——**一個人的宣言，啟動了史上最大的軟體協作**。
- 歷史教訓：**文化的死亡可以被法律結構復活**——copyleft 用敵人的武器（版權法）保障自由，是這場破案最精妙的推理。
