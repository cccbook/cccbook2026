# 1974 - CACM 論文與授權擴散（一篇論文的連鎖反應）

## 案件摘要
1974 年 7 月，**Ritchie 與 Thompson 的〈The UNIX Time-Sharing System〉** 發表於《Communications of the ACM》——Unix 第一次向學術界正式亮相。
由於 **AT&T 受 1956 年反壟斷協議限制，不得販售軟體**，Unix 只能以「授權＋原始碼」象徵性收費散布給大學——**管制反而成了免費的行銷**，Unix 在校園裡病毒式擴散。

## 前因 -- 為什麼會有這個案子
- **論文的動機**：Unix 要被學界承認為「研究成果」，必須發表；CACM 論文詳述檔案系統、行程管理、shell——**一篇論文 = 一份完整卷宗**。
- **AT&T 的管制**：1956 年反壟斷判決禁止 AT&T 進入電腦商業市場——Unix 不能賣錢，只能「教育用途」授權——**反而讓原始碼流通全美大學**。
- **彌補的缺陷**：當時大學教 OS 只有理論（如 IBM OS/360 太龐大不能讀），Unix 小到能整本讀完——**第一個「學生能讀懂的作業系統」**。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：原始碼擴散的網路效應
$$\text{大學授權} \;\Rightarrow\; \text{學生讀原始碼} \;\Rightarrow\; \text{畢業生帶 Unix 進企業} \;\Rightarrow\; \text{Unix 成為事實標準}.$$
- **理論基礎**：軟體的可複製性使其邊際成本趨近於零——原始碼一旦流通，網路效應自會放大。

### 第二條線索：CACM 論文的關鍵主張
1. 互動式分時比批處理更能提升生產力。
2. 檔案系統無型別（位元組流）→ 簡單且通用。
3. 系統小（<10K 行）→ 可理解、可修改、可移植。
- **彌補的缺陷**：OS/360 式龐然巨物無人能懂；Unix 用「小」取勝。

### 第三條線索：教育與人才管道
John Lions 的《A Commentary on the UNIX Operating System》（1976–77，解讀第 6 版核心）在地下流傳十餘年，成千上萬學生靠它讀懂核心——**Unix 的「人才管道」比它的程式碼更深遠**。

### 範例：第 6 版核心的極簡（可讀性實證）

```c
/* V6 核心風格：整個 fork 只有一頁篇幅，今日學生仍可逐行理解 */
int fork(void) {
    /* 1. 複製行程表項 (proc[]) */
    /* 2. 複製使用者映像 (user 區 + 資料段) */
    /* 3. 子行程回 0，父行程回子 pid */
    return child_pid;
}
```
（V6 核心總計約 9,000 行——**一個人一學期可讀完**；對照 OS/360 數百萬行，孰優孰劣立判。）

### Python 範例：模擬「授權擴散」的網路效應

```python
licenses = 1  # 1974 年：只有 Bell 內部
for year in range(1974, 1985):
    licenses *= 1.6   # 每年學生畢業後再傳播
    print(year, round(licenses))
# 1984 年時：數百所大學、數十家廠商——網路效應完成
```

## 結案 -- 後果與影響
- **1975 年第 6 版隨原始碼流出** → 1977 年加州大學 Berkeley 出現 1BSD（見 `1975-Version6與BSD起源.md`）。
- **企業版 Unix**：1980 年 Microsoft/Xenix、1982 年 System III、1983 年 System V——Unix 商業化時代開啟。
- **人才管道**：1980–90 年代的工程師幾乎都讀過 Lions 書或 Unix 原始碼——Linux 的作者 Linus Torvalds 正是讀著這套傳統長大。
- 歷史教訓：**開放原始碼不是慈善，而是史上最強的行銷與人才招募**。
