# 1916-重力波預言

## 案件摘要
1916 年，Einstein 以線性化近似求解自己的場方程，預言時空應以光速傳播「重力波紋」。但這個預言一波三折：座標規範的迷霧讓 Einstein 自己都懷疑重力波是否真的存在（1936 年甚至投稿一篇「不存在」的反駁論文）。直到 1957 年 Pirani 用曲率的測地偏離效應釐清物理實在性，才為 LIGO 的世紀偵測鋪路。

## 前因 -- 為什麼會有這個案子
- **場方程的雙曲性質**：$G_{\mu\nu} = \frac{8\pi G}{c^4}T_{\mu\nu}$ 是非線性偏微分方程。Maxwell 方程有電磁波解，那麼場方程有沒有「波」解？
- **超距作用的幽靈**：若太陽突然移動，地球感受到的重力變化不能瞬時傳遞（違反因果律）——必然存在以有限速度傳播的擾動。
- **物理動機**：變化的質量分佈（如雙星系統）應向外輻射時空漣漪，帶走能量。
- **難題**：廣義相對論有一般座標協變性——「波」會不會只是座標的假象（規範偽影）？這是本案的核心謎團。

## 線索與推理 -- 數學式、程式、理論

### 1. 線性化重力：弱場近似
把度規分解為平直背景加小擾動：

$$g_{\mu\nu} = \eta_{\mu\nu} + h_{\mu\nu}, \qquad |h_{\mu\nu}| \ll 1$$

保留一階小量，場方程線性化。引入**跡反轉擾動** $\bar{h}_{\mu\nu} = h_{\mu\nu} - \frac{1}{2}\eta_{\mu\nu} h$，並取跡反轉規範（Lorenz 規範）$\partial^\mu \bar{h}_{\mu\nu} = 0$，場方程化為波動方程：

$$\boxed{\Box\, \bar{h}_{\mu\nu} = \left(-\frac{1}{c^2}\frac{\partial^2}{\partial t^2} + \nabla^2\right)\bar{h}_{\mu\nu} = -\frac{16\pi G}{c^4} T_{\mu\nu}}$$

真空時 $T_{\mu\nu} = 0$，得齊次波動方程 $\Box h_{\mu\nu} = 0$——**重力波以光速 $c$ 傳播**。

### 2. 橫向四極極化
在波傳播方向為 $z$ 的 TT（transverse-traceless）規範下，平面重力波只剩空間橫向分量：

$$h_{\mu\nu}^{TT} = \begin{pmatrix} 0 & 0 & 0 & 0 \\ 0 & h_+ & 0 & 0 \\ 0 & 0 & -h_+ & 0 \\ 0 & 0 & 0 & 0 \end{pmatrix} + \begin{pmatrix} 0 & 0 & 0 & 0 \\ 0 & 0 & h_\times & 0 \\ 0 & h_\times & 0 & 0 \\ 0 & 0 & 0 & 0 \end{pmatrix}$$

兩個極化態：$+$（plus）與 $\times$（cross）。**重要事實**：重力波只有**四極**輻射——單極（球對稱脈動）與偶極（質心振盪）都因守恆律（質量守恆、動量守恆）而不輻射。這與電磁波（偶極主導）根本不同。

### 3. 測地偏離：波如何「搖晃」空間
重力波產生相鄰自由粒子間的距離振盪（測地偏離方程）：

$$\frac{d^2 \xi^x}{dt^2} = \frac{1}{2}\frac{\partial^2 h_+}{\partial t^2}\xi^x, \qquad \frac{d^2 \xi^y}{dt^2} = -\frac{1}{2}\frac{\partial^2 h_+}{\partial t^2}\xi^y$$

一個自由質點環在 $+$ 極化波下被反覆拉伸-壓縮成橢圓——這是所有干涉儀偵測器的原理。

```python
import numpy as np
import matplotlib.pyplot as plt

t = np.linspace(0, 2*np.pi, 200)
h0, omega = 0.05, 1.0
h = h0 * np.cos(omega * t)

# + 極化波下自由質點環的形變
x = (1 + h/2) * np.cos(t)
y = (1 - h/2) * np.sin(t)

plt.figure(figsize=(5,5))
plt.plot(np.cos(t), np.sin(t), 'k--', lw=0.5, label='原形')
for i in range(0, 200, 40):
    plt.plot((1 + h[i]/2)*np.cos(t), (1 - h[i]/2)*np.sin(t), alpha=0.6)
plt.gca().set_aspect('equal'); plt.legend()
plt.title('+ 極化重力波下的質點環形變')
plt.show()
```

### 4. 四極輻射公式
1918 年 Einstein 補上能量流失速率（四極公式）：

$$\boxed{P = \frac{G}{5c^5}\left\langle \dddot{Q}_{ij}\,\dddot{Q}_{ij} \right\rangle}$$

其中 $Q_{ij}$ 是質量四極矩，三點是對時間的三階導數。**數值感受**：係數 $G/c^5 \approx 2.7\times10^{-53}$ 極小，故日常物體的輻射功率可忽略；只有天體級的四極矩（如雙黑洞）才有可觀輻射。

**Hulse–Taylor 脈衝雙星**（1974 年發現）：軌道週期衰減率觀測值與四極公式預測吻合到 0.2% 以內——1993 年諾貝爾獎，間接證實重力波存在。

```python
import numpy as np
# 雙黑洞（各 29 倍太陽質量，最後幾圈）的輻射功率量級
G, c, M_sun = 6.674e-11, 2.998e8, 1.989e30
m = 29 * M_sun
r_orbit = 350e3           # 間距 ~350 km（合併前）
omega = np.sqrt(2*G*2*m/r_orbit**3)   # 開普勒頻率
# 簡化四極估計 P ~ G/c^5 * (m r^2 omega^3)^2
P = G/c**5 * (m * r_orbit**2 * omega**3)**2
print(f"輻射功率 ~ {P:.2e} W  (可見光宇宙總功率的量級!)")
```

### 5. 1936 年的反駁論文風波
- 1916–1918：Einstein 兩度計算重力波，但深陷座標規範問題，對「波是物理還是座標假象」始終不安。
- **1936**：Einstein 與 Rosen 投稿《物理評論》論文《Do Gravitational Waves Exist?》，結論是「不存在」——他們的平面波解被誤判為座標奇點。審稿人（推測是 Robertson）指出錯誤，Einstein 憤怒撤稿並揚言不再投稿該刊。後由 Howard Per Beggs 建議下與助手 Infeld 重寫，1937 年發表時結論已翻轉：**重力波存在**。
- **1957 年 Chapel Hill 會議**：**Felix Pirani** 用測地偏離方程證明：重力波對粒子間距離的效應是**規範不變的物理實在**（由 Riemann 曲率分量 $R_{0x0x}$ 描述）。Bondi 與薩克斯進一步用「黏性棒」思想實驗確認波攜帶能量。謎團正式偵破。

## 結案 -- 後果與影響
- **間接驗證**：Hulse–Taylor 雙脈衝星（1974–1993）軌道衰變精確吻合四極公式。
- **直接偵測**：2015 年 9 月 14 日 **LIGO** 偵測到 GW150914（雙黑洞併合，$36+29 M_\odot$），2017 年諾貝爾獎。
- **多信使天文學**：2017 年 GW170817 雙中子星併合與電磁對應體同時觀測，開啟新紀元。
- 技術遺產：雷射干涉（LIGO/Virgo/KAGRA）、脈衝星計時陣列（NANOGrav，2023 年偵測奈赫茲重力波背景）。
