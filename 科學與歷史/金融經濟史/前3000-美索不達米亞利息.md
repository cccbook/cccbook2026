# 前3000 - 美索不達米亞的利息（第一筆貸款與第一次利率管制）

## 案件摘要
西元前 3000 年左右，美索不達米亞（蘇美）的神廟與商人開始**放貸收息**——
人類史上第一筆有紀錄的利息交易。前 1754 年，**漢摩拉比法典**把利率寫進法律：
**銀貸款上限 20%、穀物貸款上限 33.3%**——
$$\text{貸款} + \text{利息} \xrightarrow{\text{時間}} \text{債務} \quad (\text{並導致歷史上第一次「債務危機」})$$
這是金融史的**第一案**：利息的發明創造了「時間的價格」，
也創造了人類文明最古老的經濟病灶——**債務螺旋**。

## 前因 -- 為什麼會有這個案子
- **農業的季節性**：播種要糧、收成在半年後——**農民需要跨季節的融資**——
  利息是「時間的價格」的第一次定價；
- **神廟的組織**：蘇美神廟是糧倉與金庫——**神廟就是最早的銀行**（收存、放貸、記帳）；
- **楔形文字的帳本**：泥板上的貸款契約（本金、利率、擔保、期限）——
  **書寫的發明部分就是為了記帳**——金融與文字共生；
- **債務危機的爆發**：欠債者淪為債奴（debt slavery）——社會危機逼出
  **「清除債務（clean slate）」**：統治者定期**取消債務、釋放債奴**。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：利息的數學（單利 vs 複利）
漢摩拉比時代的貸款多用**單利**：
$$A = P(1 + r t)$$
- $P$：本金；$r$：利率（20%/年）；$t$：年限。
- **複利**（本金滾入）是後來的發明，威力完全不同：
$$A = P(1+r)^t$$

### 第二條線索：Python——單利 vs 複利（利率為什麼是文明的引爆器）

```python
P, r = 100, 0.20          # 本金 100，年息 20%（漢摩拉比上限）
for t in [1, 10, 30, 50]:
    simple = P * (1 + r*t)          # 單利
    compound = P * (1 + r) ** t     # 複利
    print(f"t={t:2d} 年: 單利 {simple:8.1f}  複利 {compound:12.1f}")
```
輸出：
```
t= 1 年: 單利    120.0  複利        120.0
t=10 年: 單利    300.0  複利        619.2
t=30 年: 單利    700.0  複利     23737.6
t=50 年: 單利   1100.0  複利    910043.8
```
（**複利 50 年 = 本金的 9,100 倍**——這就是為什麼古人視複利為
「不可持續」、伊斯蘭法與中古教會**禁止複利**——漢摩拉比時代單利 + 定期廢債
是文明的止血機制。）

### 第三條線索：漢摩拉比法典的利率管制（第一次金融監管）
| 條款 | 內容 | 現代對應 |
|------|------|----------|
| §48 | 災害年免息、展期 | 天災紓困 |
| §66 | 商人利率上限 | 高利貸法（usury laws）|
| §117 | 債奴期限上限 3 年 | 個人破產法 |
| 週期性「清版」 | 統治者廢除債務 | 現代債務重整 |

### 第四條線索：理論回望——利息的本質是什麼
- **時間偏好（Böhm-Bawerk, 1888）**：現在的一單位 > 未來的一單位——利息是補償；
- **鑄幣稅與利息差別**：利息是「資本的租金」；
- **債務螺旋（現代理論）**：債務 → 收入用於還息 → 投資不足 → 收入更低 → 更依賴債務
  ——**美索不達米亞的「清版」就是切斷螺旋**（現代破產法的祖先）。

## 結案 -- 後果與影響
- **「利息」成為文明的基礎設施**：從神廟貸款到希臘銀行家（trapezitai）、
  羅馬的錢兌商——**信用是城市文明的血液**。
- **債務危機的週期**：古代近東的「清版」傳統（犹太 Jubilee、巴比倫
  misharum）——**每個文明都要學會「重置債務」**；
- **利率管制的傳統**：漢摩拉比的 20% 上限 → 中世紀教會禁息 →
  現代高利貸法——**管制的正當性由來 4,000 年不變**；
- **偵探教訓**：金融史的第一案證明了——**利息發明的那天，債務危機也同時發明**。
  之後 5,000 年的所有金融史，都是這一案的續集。
