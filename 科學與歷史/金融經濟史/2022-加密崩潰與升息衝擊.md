# 2022 - 加密崩潰與升息衝擊（穩定幣擠兌與存續期風險的雙重崩潰）

## 案件摘要
2022 年三場崩潰同時發生：
$$\text{Terra/Luna（5 月，}-\$40B\text{）} \to \text{FTX（11 月，}-\$8B\text{）} \to \text{英國 LDI 危機（9 月）}$$
**Fed 全年升息 425bp**（1980 年以來最快，見 `1979-沃克衝擊.md` 的對照）——
**穩定幣的擠兌**（UST 脫鉤）+ **存續期風險**（英國退休基金的 LDI 槓桿）+
**交易對手的欺詐**（FTX）——
**「零利率時代」的槓桿結構在升息中的總清算**——
**2023 SVB（見 `2023-SVB倒閉.md`）的序曲**。

## 前因 -- 為什麼會有這個案子
- **零利率十年的槓桿**（2010–2021）：超低利率 + QE（見 `2020-疫情QE與負油價.md`）
  ——**「現金荒」（TINA）→ 所有資產的槓桿化**；
- **Terra 的算法穩定幣**：UST 用 Luna 吸收脫鉤壓力——
  **「用自家股票穩定自家貨幣」的循環**；
- **FTX 的挪用**：交易所挪用客戶資產（Alameda）——
  **「中心化交易所 = 不透明的銀行」**；
- **英國的 LDI 槓桿**：退休基金用**長債 + 利率交換槓桿**——
  **金價波動 → 保證金追繳 → 賣債 → 債價再跌**——**存續期的螺旋**；
- **偵推**：**升息 = 「零利率槓桿」的壓力測試**——
  **每一個槓桿結構都逐一崩潰**（與 1929、2008 的清算邏輯相同）。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：算法穩定幣的死亡螺旋（Terra 的數學）
UST 的設計：燒 1 美元的 Luna = 鑄 1 UST——
**脫鉤時的螺旋**：
$$\text{UST 賣壓} \to \text{燒 Luna 救脫鉤} \to \text{Luna 供給暴增} \to \text{Luna 價格崩} \to \text{更難救} \to \cdots$$
- Luna 從 $119 → $0.00002（一週）——**「鑄幣的印鈔機反向運轉」**——
  **交子（1024）/明寶鈔的算法版**（見 `1024-交子紙幣.md`）——
  **「無準備的穩定承諾」的崩潰**。

### 第二條線索：存續期風險的數學（英國 LDI 危機）
退休基金的 LDI（負債驅動投資）：**長債 + 利率交換（槓桿 5–7 倍）**：
$$\Delta P = -D \cdot A \cdot \Delta r \quad (D = \text{存續期})$$
- 存續期 15 年的債組合，利率 +1pp → 價格 **-15%**；
- **槓桿 5 倍 → 權益 -75%** → **保證金追繳 → 賣債 → 債價再跌**；
- **偵推**：**「金價波動率飆升 → 保證金追繳 → 賣壓」的螺旋**——
  **與 1929 保證金、2008 回購同構**——**槓桿的第三種載體**。

### 第三條線索：Python——存續期的計算（英國 LDI 的算術）

```python
D, A, lev = 15, 100, 5     # 存續期 15 年、資產 100 億、槓桿 5 倍
equity = A / lev            # 權益 = 20 億
for dr in [0.5, 1.0, 1.5]:  # 利率上升 pp
    dP = -D * A * dr / 100  # 債券價格變化
    print(f"利率 +{dr}pp -> 債券 -{dP:.0f} 億 -> 權益變化 {(dP/equity)*100:+.0f}%")
```
輸出：
```
利率 +0.5pp -> 債券 -8 億 -> 權益變化 -37%
利率 +1.0pp -> 債券 -15 億 -> 權益變化 -75%
利率 +1.5pp -> 債券 -23 億 -> 權益變化 -113%（爆倉）
```
（**存續期 15 年 + 槓桿 5 倍 = 利率 +1.5pp 即爆倉**——
**英國退休基金的結構性脆弱**——**存續期 × 槓桿 = 利率敏感度的乘法**。）

### 第四條線索：FTX 的欺詐解剖（交易所的「銀行化」）
| 病灶 | 內容 |
|------|------|
| 挪用 | 客戶資產 → Alameda（關聯公司）的交易虧損 |
| 偽帳 | 「FFTT」假準備金憑證 |
| 治理 | 無董事會制衡、審計失職 |
- **偵推**：**「交易所 + 交易部門」= 利益衝突**——
  **1933 Glass-Steagall（分業）的加密版缺位**（見 `1933-格拉斯斯蒂格爾法.md`）——
  **「加密的影子銀行」**。

## 結案 -- 後果與影響
- **加密總市值 -70%**（$3T → $0.9T）：**「去中心化的承諾」被中心化的
  槓桿與欺詐背叛**（見 `2009-比特幣創世.md` 的承諾問題）；
- **穩定幣的監管化**：USDT/USDC 的準備揭露、MiCA（歐盟 2023）——
  **「穩定」需要「準備 + 揭露」**——**1933 FDIC 邏輯的加密版**；
- **英國央行的止血**：BoE 緊急購債（9.28）——
  **Bagehot 教義的 2022 版**——**「市場失靈時央行是最後買家」**；
- **Fed 的堅持**： despite 崩潰繼續升息——**「通膨優先」的教訓**
  （Volcker 的遺產）——**2023 年通膨回落**；
- **偵探教訓**：2022 年證明了——**升息 = 零利率時代所有槓桿結構的壓力測試**——
  **算法穩定幣（循環承諾）、LDI（存續期槓桿）、交易所（挪用）逐一崩潰**——
  **每一次危機都暴露「新一種槓桿」**。
