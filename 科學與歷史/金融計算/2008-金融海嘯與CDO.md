# 2008 -- 金融海嘯：CDO 定價失敗、Copula 崩潰與 VaR 失靈

## 案件描述

2008 年 9 月 15 日，雷曼兄弟破產——美國史上最大破產案。全球金融體系陷入二戰以來最嚴重的危機。

這是金融計算史上最大的案件：

> **數兆美元的 CDO 用一個假設「違約幾乎不會同時發生」的模型定價；全球銀行用同一套 VaR 度量風險；當房市崩盤，模型與風控同時失靈——這不是一次「算錯」，而是一次「所有人都用同一個錯誤的模型」的系統性失靈。**

## 前因：泡沫的技術基礎

- **房市泡沫**（2002–2007）：美國房價指數（Case–Shiller）上漲 80%+，次級貸款（subprime）氾濫。
- **證券化機器**：貸款 → MBS → CDO → CDO²——一層層打包，每一層都用數學模型定價。
- **高斯 Copula**（Li 2000，見 [2000-Li高斯Copula.md](2000-Li高斯Copula.md)）：用單一相關係數為違約相關建模——尾部相關太弱，模型說「AAA 分層幾乎不可能違約」。
- **評等機構**：Moody's、S&P 給 80% 以上的 CDO 分層 AAA 評等——用的是同樣的高斯 Copula 假設。
- **VaR 的普及**（1994，見 [1994-RiskMetricsVaR.md](1994-RiskMetricsVaR.md)）：所有銀行用同一套 VaR + 巴塞爾規定，風控行為同質化。
- **線索一**：2005–2006 年，CDO 分層的價差（spread）越壓越低——市場在說「風險消失了」。
- **線索二**：少數先知開始警告——Michael Burry、John Paulson 用數據發現次貸的違約率與房價脫鉤的異常，反向做空（Paulson 賺了 150 億美元，史上最大單筆交易獲利）。

## 推理過程

### 線索一：相關性假設的崩潰

高斯 Copula 的假設：房價是**全國分散**的（局部泡沫不會同時發生）。但：

- 2006 年房價開始全國性下跌——第一次「全國同時崩盤」（大蕭條以來首見）。
- 違約相關性**收斂到 1**：所有 MBS、所有 CDO 分層同時爆發違約。
- **數學事實**：AAA 分層的定價假設違約機率 $P(\text{AAA 違約}) \approx 0.01\%$；實際危機中，部分 AAA CDO 違約率超過 **50%**——相差 3–4 個數量級。

### 線索二：模型同質性的系統性風險

每個人都用同一個模型（高斯 Copula + 同一套評等 + 同一套 VaR），造成三重同質化：

1. **定價同質**：所有人都用同樣的相關係數 → 錯誤定價無法被市場修正
2. **風控同質**：所有人都用同樣的 VaR → 壓力下同時去槓桿
3. **評等同質**：評等機構與銀行用同樣模型 → 信用品質的資訊失效

**與 1987 年的教訓同構**（見 [1987-黑色星期一與投資組合保險.md](1987-黑色星期一與投資組合保險.md)）：**模型不是照相機，是引擎——所有人都開同一台引擎時，方向錯了就一起撞牆。**

### 線索三：流動性螺旋

1. 房價下跌 → MBS 違約 → CDO 減值
2. 銀行資本受損 → 收緊信用 → 市場流動性枯竭
3. 被迫拋售（fire sale）→ 價格再跌 → 更多減值
4. **流動性螺旋**（Brunnermeier–Pedersen 2009 的數學模型：融資流動性與市場流動性互為因果）

雷曼 9/15 破產 → 貨幣市場基金跌破面值 → 商業票據市場凍結 → 全球信用市場停擺。

### 線索四：VaR 的失靈

- VaR 假設「過去的波動率預測未來」——但危機是**結構性斷裂**（regime change），不是常態波動的延續。
- 2008 年 9 月，銀行的 VaR 與實際虧損相差 10 倍以上——VaR 說「一日 1% 機率虧 5 億」，實際虧了 50 億。
- **尾端風險**：VaR 不說「超過之後虧多少」；期望短缺（ES）與壓力測試成為必要補充。

## 後果

- **監管革命**：
  - **多德–弗蘭克法案（2010）**：壓力測試常態化（CCAR/DFAST）、系統重要性金融機構（SIFI）監管、Volcker Rule（限制自營交易）
  - **巴塞爾協定 III（2010）**：資本要求提高、流動性覆蓋率（LCR）、槓桿率上限、CVaR 取代 VaR
- **模型文化的反省**：MacKenzie、Critique of Gaussian copula；「模型風險」（model risk）成為風控的正式學科。
- **量化方法的修正**：
  - 尾部相依：t-Copula、Vine Copula、極值理論（EVT）
  - 壓力測試與情境分析常態化
  - 機器學習進入風控（非線性、非參數的相關結構）
- **反向操作的勝利**：Burry、Paulson 證明——模型失效時，「親自看數據」的人賺得最多。
- **2010 年後**：量化金融進入機器學習與高頻時代（見 [2010-閃電崩盤與高頻交易.md](2010-閃電崩盤與高頻交易.md)）。

## 現代程式重現：模型同質性 vs 多樣性

```python
import numpy as np

def portfolio_crash(n_banks=100, homogeneous=True, shock=-0.3, seed=0):
    """模擬：模型同質化 → 同時去槓桿 → 系統性崩潰"""
    rng = np.random.default_rng(seed)
    if homogeneous:
        # 所有人用同一個模型 → 相關性 = 1
        exposures = np.full(n_banks, shock)
    else:
        # 模型多樣化 → 相關性 < 1
        exposures = rng.normal(shock, 0.1, n_banks)
    # 銀行資本受損 → 收緊信用（第二輪衝擊）
    total_loss = exposures.sum()
    return total_loss

print("同質模型總虧損:", portfolio_crash(homogeneous=True) / -1e2, "（相關性=1，無分散）")
print("多樣模型總虧損:", portfolio_crash(homogeneous=False) / -1e2, "（相關性<1，部分分散）")
# 同質性殺死分散 — 這是 2008 的系統性教訓
```

## 偵探筆記

- 動機：高斯 Copula 的尾部相關太弱 + 模型同質化
- 工具：證券化、高斯 Copula、VaR、評等模型
- 遺產：監管革命（多德–弗蘭克、巴塞爾 III）、模型風險學科、尾部相依方法
- 核心教訓：**危機不是「模型算錯」，而是「所有人都用同一個模型」——多樣性本身就是風險管理。**
