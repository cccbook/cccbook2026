# 1965 -- Eugene Fama 的有效市場假說：市場已經知道一切

## 案件描述

1965 年 1 月，芝加哥大學的年輕教授 Eugene Fama 在《Journal of Business》與《Financial Analysts Journal》連載發表《股票市場價格的行為》（The Behavior of Stock Market Prices）。論文的核心主張後來被整理成金融學最有名的假說：

> **有效市場假說（Efficient Market Hypothesis, EMH）：資產價格完全反映所有可得資訊。**

推論：**股價是隨機漫步（random walk）**——未來價格的變動不可預測。

## 前因：Cowles 留下的懸案

- Cowles（1933）已經用統計檢驗懷疑預測大師的能力，但只檢驗了幾年、幾十個預測者。
- 1950 年代 Kendall（1953）分析英國股價，發現價格序列「幾乎像隨機漫步」，但沒有經濟學解釋——「為什麼市場會是隨機的？」是一團謎。
- Samuelson（1965）用理論證明：在競爭市場中，可預測的利潤會被套利消除，所以價格應該是（條件期望意義下的）鞅（martingale）。
- **線索**：Fama 在芝加哥大學讀博時做過「股票濾嘴法則」（filter rules）的交易模擬實驗，發現簡單的技術分析策略在扣除交易成本後無利可圖。他的博士論文（1963）就是這些實證的基礎。

## 推理過程

### 線索一：從「資訊」到「價格」的映射

Fama 的推理：如果價格**沒有**完全反映資訊，就存在基於資訊的無風險（或超額）獲利機會；套利者會利用它，迫使價格回到反映資訊的水準。因此：

$$E[P_{t+1} \mid \mathcal{I}_t] = P_t \quad (\text{鞅性質})$$

### 線索二：三種資訊集合 → 三種效率

Fama（1970）把假說精煉為三種形式：

| 形式 | 資訊集合 $\mathcal{I}_t$ | 推論 |
|------|------|------|
| 弱式 | 歷史價格 | 技術分析無用 |
| 半強式 | 一切公開資訊 | 基本面分析無用 |
| 強式 | 一切資訊（含內線） | 連內線都無利可圖 |

### 線索三：實證武器庫

Fama 檢驗隨機漫步的一整套統計工具：

1. **序列相關檢驗**：股價日報酬的自相關係數應接近 0。實測：日報酬自相關約 0.01–0.03——微弱但接近零。
2. **游程檢驗（runs test）**：漲跌的序列模式應與丟銅板無異。
3. **濾嘴法則模擬**：「漲 x% 就買、跌 x% 就賣」的策略，在扣除交易成本後不優於買入持有。

Fama 用數十年的資料（從 1920 年代到 1960 年代）系統性地做這些檢驗——這是金融實證研究的工業化。

## 現代程式重現：隨機漫步檢驗

```python
import numpy as np

def emh_tests(returns):
    """對日報酬序列做三種 EMH 檢驗"""
    # 1. 序列自相關（滯後 1 期）
    r1 = returns[:-1]; r2 = returns[1:]
    ac1 = np.corrcoef(r1, r2)[0, 1]

    # 2. 標準誤：隨機漫步下 ac1 的標準誤約 1/sqrt(n)
    se = 1 / np.sqrt(len(returns))
    t_stat = ac1 / se

    # 3. 游程檢驗（簡化版）：正報酬的連續段數
    runs = 1 + np.sum((np.sign(returns[1:]) != np.sign(returns[:-1])))
    expected_runs = 2 * (returns > 0).sum() * (returns < 0).sum() / len(returns) + 1

    return ac1, t_stat, runs, expected_runs

# |t_stat| < 2 → 無法拒絕隨機漫步
```

## 後果

- **指數化投資**：EMH 為 Bogle（1976）的 Vanguard 提供了完整的理論武器。
- **實證資產定價的誕生**：EMH 假說與 CAPM 結合，成為「聯合假說」——檢驗市場效率必須同時假設一個定價模型，這是 Fama 自己承認的方法論難題（也是 Roll 批評的根源）。
- **異象研究的黃金年代**：EMH 的「不可預測」宣稱激發了尋找異象（anomalies）的產業——規模效應、一月效應、動量（Jegadeesh–Titman 1993）、價值溢價（Fama–French 1993）……
- Fama 獲 **2013 年**諾貝爾獎（與 Shiller 同年——一個說市場太有效、一個說市場太瘋狂，諾貝爾委員會的幽默）。
- 盲點：2008 年金融海嘯中資產價格嚴重偏離基本面，讓 EMH 遭受猛烈批評。Fama 的回應：「價格反映資訊」不等於「價格正確」——市場可以有效率地錯。

## 偵探筆記

- 動機：Cowles 懸案 + Kendall 的隨機漫步之謎
- 工具：序列相關、游程檢驗、交易策略模擬、鞅理論
- 遺產：EMH 三形式、指數化投資、異象研究綱領
- 盲點：聯合假說問題——無法單獨檢驗市場效率
