# 法律與制度史 -- AI 偵探風格

以「推理探案」的方式，追查法律與制度從美索不達米亞的泥板會計到 GDPR、平台治理的每一步：
前因是什麼？線索在哪裡？推理如何展開？後果又如何改變了整個文明？

核心謎題只有一個：**如何讓「權力」受約束、「信用」可驗證？**
法律與制度史的本質，是一部「治理機器」的升級史——
法典把權力寫成規則（漢摩拉比 → 十二銅表 → 查士丁尼 → 拿破崙），
憲政把權力關進籠子（大憲章 → 權利法案 → 三權分立 → 成文憲法），
會計把財富變成可驗證的數字（泥板 → 複式簿記 → 審計 → SOX），
而每一次崩潰（帝國覆滅、革命、金融海嘯、資安危機）都催生一套新的制度補丁。

$$\text{權力擴張} \to \text{濫用/危機} \to \text{法典或憲政補丁} \to \text{可預期性} \to \text{信用擴張} \to \text{新的濫用}\ldots$$

三條主線交織：

1. **法律線**：從身分到契約（梅因），從神啟到成文，從地方習慣到法典與憲法；
2. **組織線**：從神廟經濟到官僚帝國（上計、戶籍、科舉），從封建到民族國家，從特許公司到法人登記；
3. **財務制度線**：從泥板核算到複式簿記，從上計到國家預算，從審計到內部控制與壓力測試。

理論（deterrence、社會契約、可信承諾、計算辯論、機制設計）與實務（法典、法院、銀行、監管）
相互促進——每一次危機，都催生一套新理論與新制度。

## 全書的主線總結

| 時代 | 治理問題 | 制度發明 | 理論 |
|------|----------|----------|------|
| 古代 | 如何記帳與裁決 | 泥板會計、成文法典 | 威嚇模型 p×f ≥ g |
| 古典帝國 | 如何治理大國 | 郡縣、戶籍、上計、公民權 | 委託-代理、激勵相容 |
| 中世紀 | 如何約束王權 | 大憲章、議會、複式簿記 | 可信承諾（North & Weingast） |
| 近代 | 如何設計政府 | 三權分立、成文憲法、民法典 | 社會契約、機制設計 |
| 20世紀 | 如何面對危機 | 行政國家、國際法、計畫/市場之辯 | 計算辯論、Radbruch formula |
| 當代 | 如何治理全球與資料 | WTO、審計監管、GDPR | 交易成本、隱私經濟學 |

**偵探的最終教訓**：制度不是被「設計」出來的完美機器，而是被危機「逼」出來的補丁——
每一次崩潰都是一次 Minsky 時刻，每一部法典、每一部憲法、每一套會計準則，
都是對上一次災難的回答。而補丁本身又會製造新的漏洞——這就是制度史永遠寫不完的原因。
