# 1445-古騰堡印刷術：教育的媒體革命

## 案件摘要

1440 年代，古騰堡（Johannes Gutenberg）在美因茨完成金屬活字＋油墨＋螺旋壓印機的組合；1455 年印出《四十二行聖經》。到 1500 年，歐洲印書逾兩萬種——**一冊書的價格從「數月工資」跌到「數日工資」**。教科書量產、頁碼與索引發明、方言書籍湧現——這是教育史上第一次「媒體革命」。本案偵破的問題是：印刷術改變的不是書，是教學的什麼？

## 前因 -- 為什麼會有這個案子

- 手抄書的經濟：一名抄手一年抄數本——**書是奢侈品，教學依賴「口傳＋記憶」**。
- 紙坊在德意志成熟（1390 紐倫堡）——媒體成本下降的前半段。
- 加洛林小寫體（[0789-查理曼辦學令.md](0789-查理曼辦學令.md)）的標準字形——活字刻製的字形基礎。
- 東方的前例：畢昇泥活字（1040s）、朝鮮金屬活字（1234）——技術的傳播與再發明（但中文活字受字數限制，歐洲拼音文字的 26 字母使活字極有效率——**媒體與文字系統的耦合**）。

## 線索與推理 -- 印刷改變教學的四個機制

### 線索一：成本曲線——規模經濟的誕生

| 指標 | 手抄 | 印刷 |
|------|------|------|
| 一冊書價 | 數月工資 | 數日工資 |
| 產速 | 一抄手一年數本 | 一機一天數百頁 |
| 錯誤率 | 每次抄寫累積 | **同一版印刷——錯誤不複製** |
| 檢索 | 無頁碼 | 頁碼、目錄、索引 |

固定成本高（製版與鑄字）、邊際成本低（印刷）——**教育媒體第一次出現規模經濟**：書從「傳家寶」變成「教科書」。

### 線索二：教科書量產＝教學標準化

印刷讓全歐洲的學生讀**同一版本**的教材：多納圖斯文法、阿爾昆文法的印刷版、伊拉斯謨的課本——**「課本」作為教學的統一媒體誕生**。中世紀教學依賴教師口傳與記憶；印刷後，「讀同一本書」成為可能——教學的變異數驟降，標準化課程（[1599-耶穌會教學規範.md](1599-耶穌會教學規範.md)）的媒體前提到位。

### 線索三：資訊檢索的發明

頁碼（paginatio）、目錄、索引都是印刷時代發明的——**資訊檢索層**誕生：讀者第一次可以「翻到第 100 頁」——知識的查找從記憶轉為索引。這是四千年來第二次「記憶外包」（第一次是文字本身，[-2100-蘇美文士學校.md](-2100-蘇美文士學校.md)）——**檢索層讓「引文」與「參照」成為學術標配**。

### 線索四：方言與識字率

拉丁文壟斷 → 方言書籍（路德德語聖經 1522）——**讀寫的語言門檻下降**：識字不再需要拉丁文，方言識字成為可能。識字率曲線開始爬升：印刷前德意志城市男性識字率約一到三成；十七世紀新教地區顯著領先（[1524-路德的全民識字革命.md](1524-路德的全民識字革命.md)）——**媒體成本 → 識字率的因果鏈**。

### 線索五：制度成效表

| 指標 | 成效 |
|------|------|
| 產能 | 1450–1500 印書逾兩萬種、數百萬冊 |
| 教材 | 教科書量產——教學標準化的媒體前提 |
| 識字 | 方言書籍使識字門檻下降——識字率爬升 |
| 路徑依賴 | 宗教改革（1517）三週傳遍德意志——媒體的速度 |

## 破案時刻

1517 年路德的《九十五條論綱》數週傳遍德意志——**印刷機讓「一個人的思想」以前所未有的速度繁殖**；1522 德語聖經讓平信徒第一次直接讀經——**媒體革命催生宗教改革，宗教改革反過來要求全民識字**（[1524-路德的全民識字革命.md](1524-路德的全民識字革命.md)）。

## 後果 -- 改變了什麼

- 宗教改革＝媒體革命：印刷傳單、方言聖經、問答教材——新教的辦學運動（1524 起）。
- 教科書工業誕生：標準化課程（[1599-耶穌會教學規範.md](1599-耶穌會教學規範.md)）與課本同步。
- 科學革命的媒體條件：1543 哥白尼、1620 培根「印刷改變了世界面貌」——同版本科學文本使知識累積與批判成為可能。
- 識字率的長期爬升 → 義務教育（[1763-普魯士義務教育.md](1763-普魯士義務教育.md)）的社會前提。

## 教育演進筆記

1. **媒體成本決定教學法**：書貴則口傳（記憶為主），書廉則課本（閱讀為主）——媒體成本曲線直接改寫教學。
2. **教科書＝教學標準化的媒體**：同一版本讓「全班同讀」成為可能——課程標準化的第一步。
3. **檢索層是第二次記憶外包**：頁碼與索引讓知識查找脫離記憶——引文與參照的誕生。
4. **媒體與文字系統耦合**：拼音文字＋活字＝高效率繁殖；漢字活字的低效率反而強化了抄印並行的路徑——媒體效率取決於與文字系統的匹配。
