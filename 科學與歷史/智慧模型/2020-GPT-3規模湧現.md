# 2020 - GPT-3 規模湧現

## 案件摘要

2020 年 5 月，OpenAI 發表 **GPT-3**：**1750 億（175B）參數**、在 300B token（570GB 清洗後網頁資料）上訓練的 Transformer 解碼器。核心發現不是翻譯也不是問答，而是：

$$\text{Few-shot prompt} \; \{\, \text{範例}_1, \dots, \text{範例}_k, \text{問題} \,\} \;\longmapsto\; \text{答案}$$

**In-context learning（上下文內學習）**：不更新任何權重、不做任何梯度下降，只在 prompt 裡放幾個範例，模型就「現場學會」新任務。更震撼的是**規模湧現（emergent abilities）**：某些能力（算術、詞義消歧、少樣本翻譯）在小模型上接近隨機，跨過某個規模後突然出現。這是「提示即程式」的誕生日——寫 prompt 從此成為一種編程。

## 前因 -- 為什麼會有這個案子

- **2019-GPT-2危險模型.md** 已證明零樣本多任務存在，但能力不穩（翻譯只有 5 BLEU）——缺的是什麼？規模，還是範例？
- **2018-BERT與GPT預訓練典範.md** 的微調典範與 OpenAI 的 AGI 藍圖矛盾：每任務一次訓練無法擴展到「任意任務」。
- **2017-Transformer注意力機制.md** 的並行性使「大資料 × 大模型」的訓練在工程上可行——GPU 叢集可以吃下 300B token。
- Kaplan 等人的規模法則（scaling laws, 2020 年 1 月）已給出理論依據：損失隨參數、資料、算力呈**冪律**下降——「再大就好」有數學背書。
- GPT-2 的 few-shot 迹象：零樣本 prompt 放一個範例（one-shot）比零範例好——範例本身就是學習訊號。
- 動機：OpenAI 押注「規模就是全部」——GPT-3 是這個賭注的實證法庭；Microsoft 獨家雲端合作提供了算力彈藥。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：規模的跳升——從 1.5B 到 175B

| | GPT-1 | GPT-2 | **GPT-3** |
|---|---|---|---|
| 參數 | 117M | 1.5B | **175B** |
| 層數 | 12 | 48 | 96 |
| 隱藏維度 | 768 | 1600 | 12288 |
| 上下文 | 512 | 1024 | **2048** |
| 訓練 token | ~1B | ~10B | **300B** |
| 訓練算力 | — | ~10²³ FLOPs | **~3.14×10²³ FLOPs** |

架構仍是 GPT-2 的（僅加 alternating dense/sparse attention），跳升 100 倍的只有規模。這是本書「規模即智慧」主張的最重一擊。

### 第二條線索：In-context learning——不用梯度的學習

GPT-3 的 few-shot 推理：把 $k$ 個範例與問題串成一條 prompt，模型在**一次前向傳播**內完成「學習」：

$$P(\text{答案} \mid \underbrace{\text{範例}_1, \dots, \text{範例}_k}_{\text{上下文內示範}}, \text{問題}) \quad \text{vs} \quad P(\text{答案} \mid \text{問題}) \;\; (\text{zero-shot})$$

| 設定 | 梯度更新 | LAMBADA（詞預測）準確率 |
|---|---|---|
| Zero-shot | 0 | 76.2% |
| One-shot | 0 | 78.9% |
| **Few-shot (k=many)** | **0** | **86.4%** |
| SOTA 微調模型 | 數千步 | 86.5% |

few-shot 幾乎追平微調 SOTA——**零梯度**。機制之謎（模型在內部做了什麼「學習」？）成為此後多年的研究案件：誘導頭（induction heads）、隱式貝葉斯推斷、梯度下降的內部模擬——這條線索至今未完全合攏。

### 第三條線索：規模湧現——能力的臨界點

GPT-3 論文給出損失與能力的關鍵曲線：

$$\mathcal{L} \propto N^{-\alpha}, \qquad \alpha \approx 0.076 \;\text{(參數冪律)}$$

損失平滑下降，但**下游任務能力**不平滑：

| 任務 | 1.3B 模型 | 13B | 175B |
|---|---|---|---|
| 2 位數加法 | 接近隨機 | 約 60% | **~100%** |
| 少樣本翻譯（英→法） | 弱 | 有用 | **接近監督式 SOTA** |
| 新聞文章生成 | 可讀 | 連貫 | **難以與人類區分** |

湧現的成因之一是評估指標的階梯性（全對才算對），但真實的質變也存在：某些能力需要多步組合，只有模型大到能「一次想完」才會出現。線索至此清晰：**能力不是線性累積，而是跨過臨界規模後的相變**——像水結冰。

### 第四條線索：SuperGLUE 之戰——理解榜的改朝換代

GPT-3 few-shot 在 SuperGLUE 達 71.8（BERT 系微調模型約 89 仍領先），但在多數理解任務上 few-shot 已接近甚至超越同量級微調模型。更重要的是：**微調一個 175B 模型在工程上已不現實**——「提示取代微調」從經濟現實變成必然。這是「提示即程式」的誕生：工程師從「訓練模型」變成「寫 prompt」。

## 結案 -- 後果與影響

- 「預訓練 + 提示」取代「預訓練 + 微調」成為大模型時代的主流範式；prompt engineering 成為新職業。
- API 模式誕生：GPT-3 於 2020 年 6 月以 API 商用（不開源權重）——「模型即服務」的商業模式確立，催生 OpenAI 的估值躍升與整個生成式 AI 產業。
- 規模競賽全面開打：Gopher、MT-NLG（530B）、PaLM（540B）——直到 **2022-Chinchilla規模法則.md** 判定「資料與參數要等比放大」，競賽方向才修正。
- In-context learning 成為研究案件：誘導頭（Anthropic, 2022）、ICL 的貝葉斯解釋——這條線索直接通往 RLHF 與對話模型。
- 湧現能力之辯持續：2023 年「鏡像湧現」論文質疑部分湧現是評估假象——但算術、多步推理的真實質變已被普遍接受。
- 主線伏筆：GPT-3 的補全模型仍「有問必答但不對話」，且會一本正經地胡說——加上 **2022-ChatGPT與RLHF.md** 的 RLHF 對齊後，同一個模型蛻變成全球現象。GPT-3 是 ChatGPT 的直系前身：差別不是規模，是**對齊**。
- 多模態伏筆：語言模型的提示介面即將擴展到影像與聲音——**2023-GPT-4多模態.md** 的能力全部以 GPT-3 的「提示即程式」為地基。
