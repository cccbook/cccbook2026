# 2020 - DDPM 擴散模型

## 案件摘要

2020 年 6 月，UC Berkeley 的 Ho、Jain、Abbeel 發表 **DDPM（Denoising Diffusion Probabilistic Models）**：一個把生成寫成「逐步加噪、再學會去噪」的模型。前向過程把資料一步步推成純高斯雜訊：

$$q(x_t \mid x_{t-1}) = \mathcal{N}(x_t;\, \sqrt{1-\beta_t}\, x_{t-1},\, \beta_t I)$$

訓練一個網路 $\epsilon_\theta(x_t, t)$ 學會反向去噪，而驚人的是——**訓練目標簡化後只是一個均方誤差**：

$$\mathcal{L}_{\text{simple}} = \mathbb{E}_{x_0, \epsilon, t}\left[\big\| \epsilon - \epsilon_\theta(x_t, t) \big\|^2\right]$$

GAN 的訓練不穩、VAE 的模糊，都在這條「去噪之路」上被繞過。這是生成模型的第三次權杖交接：對抗生成（2014）→ 自回歸 → **擴散**——而 Stable Diffusion 與 Sora 全部由此案直出。

## 前因 -- 為什麼會有這個案子

- **2014-GAN對抗式生成.md** 的樣本銳利但訓練是場內戰：生成器與判別器的博弈導致模式崩塌、不收斂、需要精心的平衡術。
- **2013-VAE變分自編碼器.md** 的訓練穩定但樣本模糊：ELBO 的重建項與 KL 項角力，均值預測抹平了細節。
- 擴散思想的譜系：Sohl-Dickstein et al., 2015 年《Deep Unsupervised Learning using Nonequilibrium Thermodynamics》已提出「加噪—去噪」框架，但只是概念驗證，樣本品質遠不及 GAN。
- 分數匹配與朗之萬動力學：Hyvärinen 的分數匹配（2005）、Song & Ermon 的去噪分數匹配（2019）證明「學習 $\nabla_x \log p(x)$」可以生成——但多尺度雜訊的設計繁瑣。
- 動機：Ho 等人想問——若把 2015 年的擴散框架**訓練目標簡化**到底，會發生什麼？答案是：品質追平 GAN 的門檻被跨過。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：前向過程——把資料推成雜訊

固定（無參數）的馬可夫鏈，每步加一點高斯雜訊：

$$q(x_t \mid x_{t-1}) = \mathcal{N}(x_t;\, \sqrt{1-\beta_t}\, x_{t-1},\, \beta_t I), \qquad t = 1, \dots, T \;(\text{通常 } T = 1000)$$

$\beta_t$ 是雜訊排程（noise schedule），從 $10^{-4}$ 線性升到 $0.02$。關鍵重排：任意時刻 $t$ 可以**一步直達**（不需迭代）：

$$x_t = \sqrt{\bar{\alpha}_t}\, x_0 + \sqrt{1-\bar{\alpha}_t}\, \epsilon, \qquad \alpha_t = 1-\beta_t, \quad \bar{\alpha}_t = \prod_{s=1}^{t} \alpha_s$$

這個重排讓訓練可以隨機抽 $t$、一次算出 $x_t$——**與 GAN 一樣的訓練並行性**。$t = T$ 時 $\bar{\alpha}_T \approx 0$，$x_T$ 就是純雜訊：資料被完全「溶解」。

### 第二條線索：反向過程——學會去噪

真正要學的是反向條件分佈 $q(x_{t-1} \mid x_t)$。當 $\beta_t$ 足夠小時，它近似高斯，且可用貝葉斯定理寫出：

$$p_\theta(x_{t-1} \mid x_t) = \mathcal{N}(x_{t-1};\, \mu_\theta(x_t, t),\, \Sigma_\theta(x_t, t))$$

DDPM 固定 $\Sigma_\theta = \sigma_t^2 I$（不學），只學 $\mu_\theta$。由 $x_t = \sqrt{\bar\alpha_t} x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon$ 反解，預測 $\mu_\theta$ 等價於**預測雜訊 $\epsilon_\theta$**：

$$\mu_\theta(x_t, t) = \frac{1}{\sqrt{\alpha_t}}\left(x_t - \frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\, \epsilon_\theta(x_t, t)\right)$$

生成的採樣鏈從純雜訊出發，逐步去噪 1000 步，還原出一張影像——像雕塑家從大理石塊裡鑿出雕像。

### 第三條線索：訓練目標的「驚人簡化」

ELBO 的嚴格下界可以逐項拆開，其中主導項是：

$$\mathcal{L}_{t-1} = \mathbb{E}_q\left[\frac{\beta_t^2}{2\sigma_t^2 \alpha_t (1-\bar\alpha_t)} \big\| \epsilon - \epsilon_\theta(\sqrt{\bar\alpha_t} x_0 + \sqrt{1-\bar\alpha_t}\, \epsilon, t) \big\|^2\right]$$

DDPM 的破案時刻：**把加權係數直接丟掉**（重加權後仍是合法的變分界），得到：

$$\mathcal{L}_{\text{simple}} = \mathbb{E}_{t, x_0, \epsilon}\left[\big\| \epsilon - \epsilon_\theta(x_t, t) \big\|^2\right]$$

一個普通的均方誤差——訓練像訓練回歸模型一樣穩定。線索至此合攏：**GAN 用對抗學「真不真」，VAE 用變分界學「像不像」，DDPM 用回歸學「雜訊在哪」**——第三條路最穩。

### 第四條線索：連接與骨架——U-Net 與分數的視角

DDPM 用 **U-Net**（2015 年的影像分割骨架）做 $\epsilon_\theta$，加上時間嵌入（正弦位置編碼，與 **2017-Transformer注意力機制.md** 同源）注入 $t$。分數匹配的視角揭示數學本質：

$$\epsilon_\theta(x_t, t) \approx -\sqrt{1-\bar\alpha_t}\, \nabla_{x_t} \log p(x_t)$$

預測雜訊 ≈ 預測對數機率的梯度（分數）——DDPM 與 Song & Ermon 的去噪分數匹配在數學上是同一件事的兩種寫法。這條線索後來在 Song et al., 2021 的 score-based SDE 中被完全統一。

### 第五條線索：案發現場的成績——FID 的翻盤

CIFAR-10 上的生成品質（FID 越低越好）：

| 模型 | CIFAR-10 FID |
|---|---|
| StyleGAN2（GAN 巔峰） | 2.67 |
| VAE 系 | 40+ |
| **DDPM** | **3.17** |
| SNGAN | 21.7 |

DDPM 首次讓擴散模型追近 GAN 巔峰，且訓練穩定性完勝——GAN 需要：生成/判別平衡、學習率精調、正則化技巧；DDPM 只需要：一個 MSE 損失 + 一個 U-Net。同時 DDPM 的**模式覆蓋（mode coverage）**遠優於 GAN：GAN 崩塌時只生成少數模式，DDPM 的似然式訓練保證了分佈全覆蓋；反過來，DDPM 的負對數概似（NLL）也優於 GAN（GAN 根本不建模似然）。線索至此全部合攏：**穩定 + 全覆蓋 + 可量測 = 第三條生成之路**。

## 結案 -- 後果與影響

- 影像生成品質追平 GAN：CIFAR-10 的 FID 首次被擴散模型壓過 GAN（DDPM 3.17），此後 GAN 在影像生成的主導權迅速流失。
- 典範外溢：Guided Diffusion（2021）、**2022-StableDiffusion開源擴散.md**（latent diffusion，把擴散搬進潛空間）、DALL-E 2、Imagen——文字生圖全面擴散化。
- 影像之外：音訊（DiffWave，呼應 **2016-WaveNet語音合成.md** 的 DeepMind 同源）、影片（**Sora / 影像擴散**）、分子生成（蛋白質與藥物設計）、**2021-AlphaFold2.md** 之後的蛋白質結構生成（RFdiffusion）——擴散成為科學生成的通用工具。
- 「噪聲排程—採樣步數—蒸餾」成為後續案件：DDIM（2020，少步採樣）、progressive distillation、consistency models（2023）都在壓縮那 1000 步。
- 生成模型三分天下後的版圖：自回歸（語言）、擴散（影像/影片）、流匹配（新興）——語言界的自回歸未被攻破，影像界被擴散全面接管。
- 主線伏筆：**DDPM → Stable Diffusion（2022，開源）→ Sora（2024，影片世界模擬）**——從去噪一張圖到去噪一段時空，擴散思想一路通向世界模型。
