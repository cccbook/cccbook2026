# 前 500 - 畢達哥拉斯

## 案件摘要
約西元前 500 年，薩摩斯島的畢達哥拉斯（Pythagoras）在義大利南部的克羅頓建立學派，提出「**萬物皆數**」（all is number）：數是宇宙的本質，和聲是比例（$2:1$ 八度、$3:2$ 五度）、畢氏定理（$a^2 + b^2 = c^2$）是空間的定律。但學派自己的發現——**$\sqrt{2}$ 是無理數**——毀滅了「萬物皆（有理）數」的信仰：**希波索斯（Hippasus）因洩漏無理數被傳說投入海中**。畢氏定理成為人類史上最重要的定理之一——從歐幾里得的證明（見 `-0300-Euclid幾何原本.md`）到 Descartes 距離（見 `1637-Descartes解析幾何.md`）到機器學習的距離度量。

## 前因 -- 為什麼會有這個案子
前 6 世紀的希臘：米利都的 Thales 開始「證明」（前 600）——數學從巴比倫/埃及的實用技藝轉向邏輯。**畢達哥拉斯的學派**（半宗教性質）：

- 信條：「萬物皆數」——宇宙的和諧由數的比例構成
- **和聲的發現**：弦長 $2:1$ 是八度、$3:2$ 是五度、$4:3$ 是四度——**音樂是比例**（最早的物理定律）
- **數的神秘主義**：完全數（6 = 1+2+3）、友好數（220 與 284）、三角數

**學派的地緣**：克羅頓（義大利南部）——政治勢力龐大（數百追隨者），被視為異端教派（前 5 世紀末被燒毀）。

## 線索與推理 -- 數學式、程式、理論

### 畢氏定理
**陳述**：直角三角形兩股平方和等於斜邊平方：

$$a^2 + b^2 = c^2$$

**巴比倫（前 1800）已知**：Plimpton 322 泥板記錄大量三元組（3,4,5；5,12,13；119,120,169）——**知道結果，沒有證明**。**希臘（前 500）證明**——畢氏學派的證明（重組面積）失傳，歐幾里得 I.47（見 `-0300-Euclid幾何原本.md`）的證明流傳至今。

**歐幾里得的證明**：以直角三角形三邊作正方形，**面積拼圖**——大正方形 = 兩個小正方形（不依賴相似形，嚴格）。

### 無理數的地震
**希波索斯的發現（前 5 世紀）**：正方形對角線與邊長**不可公度**（無公共測量單位）：

$$\frac{\text{對角線}}{\text{邊長}} = \sqrt{2} \notin \mathbb{Q}$$

**證明（反證法）**：假設 $\sqrt{2} = p/q$（最簡分數，$p, q$ 互質）：

$$2q^2 = p^2 \implies p^2 \text{ 偶} \implies p \text{ 偶} = 2k \implies 2q^2 = 4k^2 \implies q^2 \text{ 偶} \implies q \text{ 偶}$$

$p, q$ 皆偶——**與互質矛盾**。$\blacksquare$

**「萬物皆（有理）數」的毀滅**：$\sqrt{2}$ 是實際存在的量（正方形對角線），卻**不是有理數**——畢氏學派的宇宙觀崩塌。**傳說**：希波索斯因洩漏這個秘密被投入海中（畢氏教派的保密文化——與 Enigma 的反射器、Galois 的遺稿同源的「秘密」主題）。

**深遠的後果**：**比例論的誕生**（Eudoxus，見 `-0300-Euclid幾何原本.md` 第 V 卷）——不用「數」也能比較量（實數理論的兩千年前身）。

### 程式碼：畢氏定理與無理數

```python
from math import isqrt

def pythagorean_triples(limit):
    """生成畢氏三元組：a = m²-n², b = 2mn, c = m²+n²"""
    triples = []
    for m in range(2, int(limit**0.5)):
        for n in range(1, m):
            a, b, c = m*m - n*n, 2*m*n, m*m + n*n
            if c <= limit:
                triples.append((a, b, c))
    return triples

# Plimpton 322 的驗證
print([t for t in pythagorean_triples(200) if t[0] == 119 or t[1] == 119])
# [(119, 120, 169)]——巴比倫泥板前 1800 年就知道！

# sqrt(2) 無理數：反證法的數值直覺
def sqrt2_irrational_search(denom_limit=1000):
    """搜尋 sqrt(2) 的有理近似——永遠找不到精確的"""
    approx = []
    for q in range(2, denom_limit):
        p = round(2**0.5 * q)
        if p*p != 2*q*q:              # 永不成立——無理數！
            approx.append((p, q, abs(p/q - 2**0.5)))
    best = min(approx, key=lambda t: t[2])
    return best

p, q, err = sqrt2_irrational_search()
print(f"最接近的有理近似：{p}/{q} = {p/q:.10f}（誤差 {err:.2e}）")
# 永遠近似、永不精確——無理數的本質

# 調和的比例（畢氏的音樂）
for ratio, name in [(2/1, "八度"), (3/2, "五度"), (4/3, "四度")]:
    print(f"{name}：弦長比 {ratio}——音樂是比例")
```

### 譜系：從和聲到科學
**偵探筆記**：畢氏學派的推理是「**數是本質**」——音樂（比例）、空間（定理）、宇宙（和諧）皆是數。這個「萬物皆數」的信念：

- **Keppler（1619）**：行星軌道的多面體模型（錯的，但驅動了對數與軌道的研究）
- **歐拉的 π**（1734，見 `1734-Euler巴塞爾問題.md`）：π 滲透數論——「萬物皆數」的體現
- **物理學的數學化**（Newton 1687，見 `1665-Newton微積分.md`）：宇宙服從數學定律
- **機器學習**：一切的「距離」與「向量」——畢氏定理是 AI 的基礎設施

## 結案 -- 後果與影響
- **人類最重要的定理**：畢氏定理——從巴比倫泥板到 GPS 到機器學習的距離度量。
- **無理數的地震**：$\sqrt{2}$ 毀滅「萬物皆（有理）數」——比例論（Eudoxus）與實數理論的誕生。
- **數學與音樂**：和聲的比例——畢氏的發現是物理定律的鼻祖。
- **保密文化的悲劇**：希波索斯的傳說——數學「秘密」的歷史（Galois 遺稿、Bletchley Park 的 Ultra）。
- **反證法的經典**：$\sqrt{2}$ 無理的證明——希臘數學的推理典範（與質數無窮並列）。

## 關鍵人物與文獻
- **Pythagoras**（約前 570–前 495）：克羅頓學派、萬物皆數
- **Hippasus**（前 5 世紀）：無理數的發現（傳說被投入海中）
- **Thales**（約前 624–前 546）：證明的開端
- **Eudoxus**（前 408–前 355）：比例論——無理數危機的回應
