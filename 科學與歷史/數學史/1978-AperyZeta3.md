# 1978 - Apéry ζ(3)

## 案件摘要
1978 年 6 月，61 歲的法國數學家 Roger Apéry 在赫爾辛基的國際數學家大會（ICM）宣佈：**$\zeta(3) = \sum 1/n^3$ 是無理數**——聽眾的質疑聲一片（「證明有漏洞！」），但 1979 年證明被確認成立。**奇數項 ζ 的第一個突破**：偶數項全解（$\zeta(2) = \pi^2/6$，見 `1734-Euler巴塞爾問題.md`），奇數項（$\zeta(3), \zeta(5), \dots$）是謎——Apéry 打破了一角。**老年數學家的孤注一擲**——證明方法（快速收斂的級數 + 連分數）被稱為「Apéry 的奇蹟」。

## 前因 -- 為什麼會有這個案子
**歐拉的遺產**（1734–37，見 `1734-Euler巴塞爾問題.md`）：

$$\zeta(2k) = \sum_{n=1}^{\infty} \frac{1}{n^{2k}} \in \pi^{2k} \cdot \mathbb{Q} \quad \text{（偶數項全解！）}$$

- $\zeta(2) = \pi^2/6$、$\zeta(4) = \pi^4/90$、$\zeta(6) = \pi^6/945$……
- **奇數項**：$\zeta(3) = 1 + 1/8 + 1/27 + \dots = 1.2020569\dots$——**是什麼？**

**270 年的困惑**（自 Euler 1734）：
- **歐拉的攻擊**：偶數全解、奇數全部失敗——歐拉猜測 $\zeta(3)$ 與某「奇 π 次冪」無關
- **推廣的謎**：$\zeta(2k+1)$ 是否無理？是否與 $\pi$ 無關？——**無人能動**
- **Hilbert 的間接**：第 7 題（超越數）1900（見 `../計算理論/1900-Hilbert23問題.md`）的果實（Gelfond–Schneider 1934）不涵蓋 ζ(3)

**Apéry 的問題**：$\zeta(3)$ 是無理數嗎？——**答案：是**。

## 線索與推理 -- 數學式、程式、理論

### Apéry 的級數
**核心武器**：$\zeta(3)$ 的**快速收斂級數**：

$$\zeta(3) = \frac{5}{2} \sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n^3 \binom{2n}{n}}$$

**為什麼快**：$\binom{2n}{n} \approx \frac{4^n}{\sqrt{\pi n}}$——項衰減 $\approx 4^{-n} n^{-5/2}$——**指數收斂**（原級數 $1/n^3$ 只是多項式收斂——慢 1000 倍）。

**收斂比較**：
- 原級數 $\sum 1/n^3$：1000 項誤差 $\approx 5 \times 10^{-10}$
- Apéry 級數：**20 項**誤差 $\approx 10^{-12}$——**50 倍效率**

### 無理性的證明骨架
**方法**：構造**有理逼近** $p_n/q_n \to \zeta(3)$，使誤差衰減**快於**分母的增長：

$$\left|\zeta(3) - \frac{p_n}{q_n}\right| < \frac{1}{q_n^{1+\delta}} \quad (\delta > 0)$$

**若 $\zeta(3)$ 是有理數** $a/b$，則誤差 $\ge \frac{1}{b q_n}$——**與 $q_n^{-(1+\delta)}$ 的快速衰減矛盾**（當 $q_n$ 足夠大）。$\blacksquare$

**Apéry 的構造**：用**連分數**（與 $\pi$ 的連分數同源的技術，見 `0480-ZuChongzhi圓周率.md`）與**遞迴關係**定義 $p_n, q_n$——**誤差衰減 $\approx q_n^{-1.08}$**（$\delta = 0.08$，剛好大於 0——臨界線的一點點，與張益唐的素數間距同源，見 `2013-ZhangYitang素數間距.md`）。

### 赫爾辛基的風暴
**1978 年 6 月 ICM**：Apéry 宣佈證明——**聽眾的質疑**：

- 「**證明有漏洞**！」——聽眾（包括專家）的喊聲
- **van der Poorten 的記錄**：〈A proof that Euler missed...〉（1979）——「Apéry 的報告像魔術」
- **確認**：Cohen 的學生（Henri Cohen）與 Beukers 數月內**重構並確認**證明——1979 年確認成立

**「老年數學家的孤注一擲」**：Apéry 61 歲（多數數學家的黃金年齡是 20–40）——**業餘方法的奇蹟**（快速收斂級數的「土法」）。

### 程式碼：Apéry 級數

```python
import math
from math import comb

def zeta3_original(n=100000):
    """原級數：Σ 1/n³（多項式收斂，慢）"""
    return sum(1/k**3 for k in range(1, n+1))

def zeta3_apery(terms=20):
    """Apéry 級數：指數收斂，快 50 倍"""
    from math import factorial
    s = 0.0
    for n in range(1, terms+1):
        # binom(2n, n) 的遞迴計算（避免大階乘）
        c = 1
        for i in range(n):
            c = c * 2 * (n + i) // (i + 1)
        s += (-1)**(n-1) / (n**3 * c)
    return 2.5 * s

target = 1.202056903159594
print(f"ζ(3) 真值 = {target:.15f}")
print(f"原級數 10^5 項：{zeta3_original():.15f}（誤差 {abs(zeta3_original()-target):.2e}）")
print(f"Apéry 級數 20 項：{zeta3_apery():.15f}（誤差 {abs(zeta3_apery()-target):.2e}）")
# Apéry：20 項達到原級數 10^5 項的精度——指數收斂的威力

# 無理性的直覺：有理逼近的快速衰減
print("\n無理性的證明骨架：|ζ(3) - p_n/q_n| < q_n^{-1.08}")
print("若 ζ(3) = a/b 有理，誤差 ≥ 1/(b·q_n)——與快速衰減矛盾 → 無理 ✓")
```

### ζ(3) 之後的謎
**Apéry 的遺產**：
- $\zeta(3)$ 無理 ✓（1978）
- $\zeta(5), \zeta(7), \dots$ 的無理性——**仍懸**（Apéry 的方法不夠推廣）
- $\zeta(3)/\pi^3$ 的**無理性**（與 π 無關？）——**仍懸**
- **Zagier 的觀察**：$\zeta(2k+1)$ 與「多重 zeta 值」（MZV）的代數結構——**新的謎題空間**

**偵探筆記**：Apéry 的推理是「**土法的奇蹟**」——快速收斂級數 + 連分數的有理逼近。**61 歲、業餘方法、聽眾的質疑**——與張益唐的素數間距（2013，見 `2013-ZhangYitang素數間距.md`）、Wiles 的費馬（1995，見 `1994-Wiles費馬定理.md`）同源：**數學的突破常來自「意想不到的人與方法」**。

## 結案 -- 後果與影響
- **奇數項 ζ 的第一角**：$\zeta(3)$ 無理——270 年困惑（自 Euler）的第一個突破。
- **快速收斂的技術**：Apéry 級數——**數值計算與理論證明的橋樑**（$\zeta(3)$ 的百萬位計算用其變體）。
- **多重 zeta 值（MZV）**：Zagier 的推廣——**新的數論空間**（與量子場論的 Feynman 積分連結）。
- **ζ(5) 的懸案**：Apéry 的方法不夠推廣——**數學的未完故事**（與黎曼假設並列，見 `1859-Riemann假設.md`）。
- **老年數學家的鼓勵**：61 歲的突破——**數學不問年齡**（與張益唐的 58 歲、Perelman 的隱居同源）。
- **證明的確認文化**：ICM 的質疑與數月後的確認——**數學的同行審查**（與四色定理的爭論、Perelman 的驗證同源）。
