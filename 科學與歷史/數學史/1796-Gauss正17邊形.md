# 1796 - 高斯正 17 邊形

## 案件摘要
1796 年 3 月 30 日清晨，19 歲的 Carl Friedrich Gauss 在床上想到：**正 17 邊形可以用尺規作圖**——**2000 年無人解的幾何懸案**！自歐幾里得（前 300，見 `-0300-Euclid幾何原本.md`）以來，尺規作圖的可及範圍（正 3、4、5、6、15 邊形）被認為已窮盡——Gauss 證明正 $2^{2^k}+1$ 邊形（**費馬素數**）皆可作圖。**這個發現讓 Gauss 放棄語言學、投身數學**——「數學王子」的起點。**Göttingen 大學為他立了 17 邊形的紀念碑**（實際是 17 角星——工匠怕 17 邊形太像圓）。

## 前因 -- 為什麼會有這個案子
**尺規作圖的兩千年**：歐幾里得的《幾何原本》給出正 3、4、5、6、15 邊形的作圖——**古代的極限**。**哪些正 $n$ 邊形可作圖？**——兩千年的懸案：

- 正 7 邊形？——不可（Archimedes 嘗試失敗）
- 正 9 邊形？——不可（三等分角問題）
- **一般判準**：無

**Gauss 的背景**（見 `1799-Gauss代數基本定理.md`）：不倫瑞克貧困家庭的神童，1795 年入 Göttingen——**原本猶豫語言學還是數學**。

**1796 年 3 月 30 日清晨**（起床前）：想到正 17 邊形的作圖——**「數學的誕生日」**（Gauss 的日記記載）——決定投身數學。

## 線索與推理 -- 數學式、程式、理論

### 尺規作圖的數學
**尺規作圖**：只用圓規與無刻度直尺——可構造的量是**二次擴張塔**：

$$\mathbb{Q} = F_0 \subseteq F_1 \subseteq \dots \subseteq F_k$$

每步 $F_{i+1} = F_i(\sqrt{a_i})$——**平方根的擴張**（維度每次 $\times 2$）。

**判準**：可作圖的量在 $2^k$ 次擴張內——**正 $n$ 邊形可作圖 ⟺ $\varphi(n)$ 是 2 的冪**（$\varphi$ 是 Euler 函數）！

### Gauss 的證明
**核心**：正 $n$ 邊形的作圖 = 構造 $\cos\frac{2\pi}{n}$——**等價於在 $\mathbb{Q}(\zeta_n)$ 中構造**（$\zeta_n = e^{2\pi i/n}$，$n$ 次單位根）。

**Gauss 的定理**：

$$\text{正 } n \text{ 邊形可尺規作圖} \iff n = 2^k p_1 p_2 \cdots p_m$$

其中 $p_i$ 是**相異費馬素數**（$F_j = 2^{2^j} + 1$）。

**推理**：$\varphi(n) = 2^{k-1} \prod (p_i - 1)$——可作圖需要 $\varphi(n)$ 是 2 的冪——$(p_i - 1)$ 必須是 2 的冪——$p_i$ 必須是費馬素數。

**費馬素數**：$3, 5, 17, 257, 65537$（前 5 個）——**可作圖的正 $n$ 邊形**：

$$n = 3, 4, 5, 6, 8, 10, 12, 15, 16, 17, 20, \dots, 257, 65537$$

**正 17 邊形**（Gauss 的突破）——**2000 年的新發現**。

### 正 17 邊形的構造
**17 = $2^{2^2} + 1$**（第 3 個費馬素數）——$\varphi(17) = 16 = 2^4$——**4 次平方根擴張**：

$$\cos\frac{2\pi}{17} = \frac{-1 + \sqrt{17} + \sqrt{34 - 2\sqrt{17}} + 2\sqrt{17 + 3\sqrt{17} - \sqrt{34 - 2\sqrt{17}} - 2\sqrt{34 + 2\sqrt{17}}}}{16}$$

**巢狀平方根**——尺規可作圖！**Gauss 的日記**：「這個發現超過正 17 邊形本身，它開啟了一片全新的數學領域」——**分圓理論（cyclotomy）的誕生**。

### 程式碼：正 17 邊形的驗證

```python
import math, cmath

def constructible_check(n):
    """正 n 邊形可尺規作圖 ⟺ n = 2^k × 相異費馬素數"""
    def is_power_of_2(x):
        return x > 0 and (x & (x-1)) == 0
    # 移除 2 的冪
    while n % 2 == 0: n //= 2
    if n == 1: return True
    # 檢查剩餘部分是否為相異費馬素數之積
    fermat = [3, 5, 17, 257, 65537]
    for f in fermat:
        if n % f == 0:
            n //= f
            if n % f == 0: return False     # 相異！
    return n == 1

for n in [3, 5, 7, 9, 15, 17, 257, 100]:
    print(f"正 {n} 邊形可作圖 = {constructible_check(n)}")

# 正 17 邊形：cos(2π/17) 的巢狀平方根（Gauss 公式）
s17 = math.sqrt(17)
x = (-1 + s17 + math.sqrt(34 - 2*s17) +
     2*math.sqrt(17 + 3*s17 - math.sqrt(34-2*s17) - 2*math.sqrt(34+2*s17))) / 16
print(f"\ncos(2π/17) 高斯公式 = {x:.12f}")
print(f"數值驗證 = {math.cos(2*math.pi/17):.12f} ✓")
# 巢狀平方根 = 尺規可作圖（二次擴張塔）

# 單位根的對稱性（Gauss 的分圓理論）
zeta = cmath.exp(2j * math.pi / 17)
print(f"\nζ₁₇ = {zeta:.4f}——17 次單位根，Galois 群的循環結構")
print("分圓理論（cyclotomy）：Gauss 1796 的發現開啟 Galois 理論的先聲")
```

### 數學的誕生日
**Gauss 的決定**：正 17 邊形的發現讓 Gauss **放棄語言學**——「1796 年 3 月 30 日是數學的誕生日」（他自己的日記，用密碼記載 146 項發現）。

**紀念碑的傳說**：Göttingen 的紀念碑（17 角星）——**工匠怕 17 邊形太像圓**（雕不出差異）——數學與工程的幽默。

**偵探筆記**：Gauss 的推理是「**把幾何化為代數**」——尺規作圖 = 平方根擴張塔 = 費馬素數。**與 Descartes 解析幾何（1637，見 `1637-Descartes解析幾何.md`）、Hamilton 四元數（1843，見 `1843-Hamilton四元數.md`）同源**：**幾何問題的代數化**。**分圓理論**（$\zeta_n$ 的結構）是 Galois 理論（1832，見 `1832-Galois群論.md`）的直接先聲——**Gauss 的 1796 是 Galois 的 1832 的地基**。

## 結案 -- 後果與影響
- **2000 年懸案終結**：正 17 邊形的尺規作圖——兩千年幾何的極限被打破。
- **尺規作圖的完整判準**：費馬素數——**可作圖性的完整分類**（Wantzel 1837 證明必要性）。
- **分圓理論的誕生**：$\zeta_n$ 的結構——**Galois 理論的直接先聲**（1832，見 `1832-Galois群論.md`）。
- **費馬素數的謎**：只有 5 個已知（$3, 5, 17, 257, 65537$）——**是否還有？**（與費馬定理的譜系，見 `1994-Wiles費馬定理.md`）。
- **Gauss 的帝國**：數學的誕生日（1796）→ 代數基本定理（1799）→ 算術研究（1801）→ 非歐幾何——**數學王子的起點**。
- **數論與幾何的橋樑**：分圓理論連結兩者——**現代代數數論的誕生**。
