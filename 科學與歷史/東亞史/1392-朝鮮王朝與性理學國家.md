# 1392-朝鮮王朝與性理學國家

## 案件摘要
1392 年 7 月，李成桂在威化島回軍（1388）後受禪建立朝鮮——親明路線（「事大」）、性理學國家的建立：兩班、科舉、《經國大典》（1470s）、鄉約——儒學從「官僚技術」升級為「國家意識形態」。這樁「意識形態國家」案件的偵辦重點：**性理學 = 國家的作業系統**——朝鮮把朱子學制度化為「小中華」的自我定位（明 = 中華、朝鮮 = 小中華、日本 = 倭）——「意識形態作為國家技術」（-221 案儒法混合 vs 朝鮮的純性理學極致化）——兩班階層的固化與 518 年的王朝穩定。

## 前因 -- 為什麼會有這個案子
- **高麗末的困境**：倭寇（14 世紀後期）、紅巾軍入侵、禪佛的腐化——高麗的危機。
- **威化島回軍**（1388）：遼東征伐的半途回軍（李成桂的政治決斷）——「親明」路線的武力確立。
- **性理學士人的崛起**：鄭夢周、鄭道傳——高麗末的性理學（安珦 1286 引入朱子學）——「士林的成長」。
- **明的冊封**（1368 案）：朝鮮以「事大」換取安全與正當性——「小中華」的定位。

## 線索與推理 -- 數學式、理論、表格

### 線索一：性理學 = 國家的作業系統
朝鮮把性理學制度化為國家結構：

| 層面 | 制度 | 性理學的角色 |
|------|------|-------------|
| 官僚 | 科舉（四書五經）| 意識形態的考試化 |
| 階層 | 兩班（文武兩班）| 「士」的世襲化 |
| 法律 | 《經國大典》（1470s）| 儒家禮制的法典化 |
| 地方 | 鄉約、書院 | 士林的基層組織 |
| 教育 | 成均館、鄉校 | 性理學的教育體系 |

**推理**：性理學 = 意識形態的作業系統（-221 案「儒表法裡」vs 朝鮮的「純性理學」）——朝鮮把儒學極致化到「性理學國家」——**意識形態的深度 = 國家的穩定度**（518 年的王朝壽命——東亞最長的王朝之一）。

### 線索二：小中華思想的結構
朝鮮的自我定位（事大主義的世界觀）：

| 範疇 | 定位 |
|------|------|
| 明（清後）| 中華（文明中心）|
| 朝鮮 | 小中華（禮儀之邦的邊緣中心）|
| 日本 | 倭（「獸性」的島夷）|
| 女真/蒙古 | 胡狄 |

**推理**：小中華思想 = 冊封體系（1368 案）的意識形態內化——「華夷之辨」的自我定位——**「事大」 = 安全 + 正當性 + 文明身份**的三合一——1876 案江華島條約（日本的不平等條約）對小中華的衝擊是雙重的（安全與認同同時崩解）。

### 線索三：兩班階層的固化
兩班（文武官僚）的階層結構：

| 階層 | 內容 |
|------|------|
| 兩班 | 科舉及第者與其子孫（世襲傾向）|
| 中人 | 技術官（譯官、醫官、算官）|
| 良人 | 平民（農民、商人）|
| 賤民 | 奴婢、樂工 |

**推理**：兩班的世襲化（蔭敘 + 互婚）→ 階層的固化（16 世紀後）——「科舉的名額 vs 兩班的人口」（16-17 世紀的科舉名額停滯、兩班人口膨脹）——**階層固化 = 財政與改革的瓶頸**（1800s 的兩班過剩與衰落——1864 大院君的改革動機）。

### 線索四：士林與黨爭
士林（地方性理學派）的成長（書院、鄉約）→ 士林 vs 勳舊 → 黨爭（1575 東人西人分黨——四色黨爭：老論、少論、南人、北人）：

$$\text{士林} \to \text{黨爭} \to \text{黨派的世襲化} \implies \text{政治的僵局}$$

**推理**：意識形態的深度（性理學）反噬政治的彈性——黨爭以「義理」為名（正邪之辨）——「意識形態國家的政治病」（政爭的極致化）——1800s 的衰落與 1864 大院君、1895 甲午改革與 1897 大韓帝國的內部變革動機。

## 結案 -- 後果與影響
- **518 年的王朝穩定**：性理學 + 事大 + 兩班——朝鮮王朝（1392-1910）的長壽結構——「意識形態國家」的穩定性與僵化同體。
- **訓民正音（1446 案）的土壤**：性理學的「民本」（世宗的民本主義）——文字創制的意識形態條件。
- **事大主義的定型**：明（1392-1637）、清（1637-1895）——「事大」的單軌（對照越南的「內帝外王」雙軌）——1895 甲午的翻轉（宗主權的終結）。
- **壬辰倭亂的深重創傷**（1592 案）：性理學國家的「防倭」記憶——「北伐論」與「北學論」的張力（1780 案北學派的出現）。
- **兩班的遺產**：士林、書院、鄉約——朝鮮的「士人社會」——近代的「開化派」（1868 案後）與獨立運動的知識基礎。
