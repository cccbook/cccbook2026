# 372-佛教傳入東亞

## 案件摘要
372 年，前秦苻堅遣使高句麗，贈佛像與經論——佛教正式傳入朝鮮；384 年東晉胡僧到百濟；552 年百濟聖明王獻佛像與經論給日本欽明天皇——**東亞佛教圈**的三級傳播鏈完成。這樁「宗教網絡」案件的偵辦重點：佛教是東亞第一個**跨國組織**——寺院 = 學校 + 醫院 + 翻譯所 + 藝術工坊的複合體；「書籍之路」（王勇）：經典的抄寫與流動讓東亞第一次有「跨國知識共同體」。宗教網絡先於任何政治統一，把東亞縫合。

## 前因 -- 為什麼會有這個案子
- **絲路的中轉**：印度 → 中亞（龜茲、于闐）→ 中國（341 鳩摩羅什入長安前的譯經傳統）——佛教的中轉網。
- **中國的接受**：漢末-東晉的亂世——「救贖宗教」的需求（亂世的苦難）；玄學與般若的對接（格義）——知識準備就緒。
- **苻堅的外交**：前秦統一北方後的「文化帝國主義」——遣使高句麗送經像——「宗教作為外交」。
- **半島的接收條件**：三國的王權建設期——「護國佛」的需求（王權的正當性工具）。

## 線索與推理 -- 數學式、理論、表格

### 線索一：傳播鏈的時差
佛教東傳的三級時差：

| 站點 | 佛教到達 | 中介 |
|------|---------|------|
| 印度 → 中亞 | 前2-1 世紀 | 絲路商旅 |
| 中亞 → 中國 | 1 世紀（白馬寺 68）| 譯經僧 |
| 中國 → 高句麗 | 372 | 前秦使者（順道僧）|
| 中國 → 百濟 | 384 | 東晉胡僧摩羅難陀 |
| 百濟 → 日本 | 552（一說 538）| 百濟聖明王獻佛 |

**推理**：佛教沿「絲路 → 中國 → 半島 → 列島」的走廊傳播——時差逐級遞延（百年級）——**宗教傳播 = 貿易路線 + 國家的接收條件**（王權需「護國佛」時才正式接受）。

### 線索二：寺院 = 跨國的複合組織
寺院的功能矩陣：

| 功能 | 內容 | 社會角色 |
|------|------|---------|
| 學校 | 經典教育、漢字 | 識字與知識的普及點 |
| 翻譯所 | 經典漢譯/日譯 | 跨語言的知識加工 |
| 醫院 | 藥師信仰、濟病 | 醫療的宗教載體 |
| 藝術工坊 | 造像、繪畫、建築 | 技術（乾漆、金銅）的傳播 |
| 經濟 | 寺院莊園、質庫（抵押貸款）| 金融與土地 |

**推理**：寺院是前近代東亞的「多功能組織」——學校+醫院+銀行+工坊的複合體——**宗教網絡 = 基礎設施網絡**——佛教把「跨國組織」的概念帶入東亞（世俗國家之外的橫向組織）。

### 線索三：護國佛與王權的正當性
三國與日本的接收都是「王權需求」驅動：

| 國 | 接收 | 用法 |
|----|------|------|
| 高句麗 | 372 | 護國信仰（平壤的寺院）|
| 百濟 | 384 | 外交（東晉-南朝的佛教外交）|
| 新羅 | 527-（異次頓殉教後）| 貴族制的打破（花郎與佛教）|
| 日本 | 552 | 氏族政治（蘇我氏 vs 物部氏的鬥爭——645 大化改新的伏筆）|

**推理**：佛教的接受 = 王權的鬥爭（氏族政治的清洗——蘇我氏以佛教對抗物部氏的神道）——「宗教 = 政治技術」——645 大化改新的滅蘇我是宗教鬥爭的延續。

### 線索四：書籍之路的啟動
王勇的「書籍之路」理論：東亞文化交流的載體不是絲綢而是**書籍**——佛教經典的抄寫流動：中國譯經 → 半島抄寫 → 日本（552 的經論、《法華經》）——「書的流動 = 知識的共同體」——經典的跨國一致（版本對照）是東亞知識圈的共同體驗。

## 結案 -- 後果與影響
- **東亞佛教圈的成形**：經典、戒律、造像的跨國一致——東亞的「橫向共同體」先於任何政治統一。
- **寺院 = 知識的載體**：識字、翻譯、藝術、醫療——寺院是漢字文化圈的「技術節點」。
- **王權的宗教工具**：護國佛、寺院莊園——宗教的正當性功能（新羅的佛國土、日本的神佛習合）。
- **文化的跨國流動**：乾漆、金銅像、壁畫（高句麗古墳壁畫）——技術沿佛教網流動——「書籍 + 技術」的複合傳播。
- **政治鬥爭的宗教化**：蘇我 vs 物部（日本）、異次頓（新羅）——宗教的接受 = 氏族政治的重構——645 大化改新的直接伏筆。
