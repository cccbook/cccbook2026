# 1965-東亞經濟奇蹟

## 案件摘要
1955-73 日本高度成長（十年兩位數增長——神武景氣、岩戶景氣、伊奘諾景氣）；1961- 韓國漢江奇蹟（朴正熙的五年計畫 1962-）；1960s 台灣奇蹟（土地改革 + 出口導向）。這樁「奇蹟」案件的偵辦重點：**發展型國家**（Chalmers Johnson 1982《通產省》——官僚主導的市場經濟）；**雁行理論**（赤松要 1935——產業的雁行轉移：日本 → NIEs → ASEAN → 中國）；「出口導向 + 國家主導 + 教育」的東亞模式——東亞經濟奇蹟的模式學（1965 案的「東亞模式」）。

## 前因 -- 為什麼會有這個案子
- **日本的戰後基礎**：韓戰特需（1950 案）+ 財閥解體 → 系列企業 + 農地改革（農村的購買力）——「奇蹟的基礎」。
- **韓台的土地改革**：1949-53 韓台的土地改革（農地的再分配）——「農村的平等 → 勞動的供給」。
- **美國的市場與安全傘**：冷戰的市場（美國的開放市場）+ 安全（安保條約的軍費節省）——「冷戰 = 東亞經濟的外部條件」。
- **赤松要的雁行**：1935 雁行理論（日本 → 殖民地的產業轉移）——戰後的雁行（日本 → NIEs）。

## 線索與推理 -- 數學式、理論、表格

### 線索一：發展型國家的結構
Johnson（1982）《通產省》的發展型國家：

| 要素 | 內容 | 實例 |
|------|------|------|
| 官僚主導 | 通產省的產業政策（指導與誘導）| 日本的通產省 |
| 出口導向 | 貿易立國（出口的獎勵）| 日韓台的出口 |
| 金融壓抑 | 低利率 + 郵儲 → 政策金融 | 日本的郵儲、韓國的銀行國有 |
| 教育 | 義務教育 → 高等教育 | 人力資本的投資 |
| 民間企業 | 財閥/財團的成長（系列、財閥）| 三井 → 豐田；三星、現代 |

**推理**：發展型國家 = 「官僚主導的市場經濟」（-1917 案計畫經濟的中間解——不是計畫經濟也不是自由放任）——「國家主導 + 市場機制 + 出口導向」——**東亞模式的結構**（Johnson 的「計畫理性」——官僚的產業政策）——韓台的漢江奇蹟是日本模板的移植。

### 線索二：雁行理論——產業的轉移
赤松要（1935）的雁行理論：

$$\text{日本（紡織 → 重工 → 電子）} \to \text{NIEs（紡織 → 電子）} \to \text{ASEAN → 中國}$$

**推理**：雁行的產業轉移——先進國的「夕陽產業」轉移到後進國（成本優勢）——「雁行 = 東亞的產業梯隊」——1965 案的奇蹟（日）→ 1970s-80s NIEs（韓台）→ 1990s ASEAN → 2001 案中國入世——**雁行的東亞梯隊**（產業的接力）。

### 線索三：東亞模式的要素
奇蹟的要素組合：

| 要素 | 內容 | 效果 |
|------|------|------|
| 高儲蓄 | 家計儲蓄率 20%+ | 投資的資金 |
| 教育 | 義務教育 → 高中升學 | 人力資本 |
| 出口 | 出口導向（外匯 → 技術）| 技術的移轉 |
| 官民合作 | 通產省的指導 + 財閥的執行 | 產業政策 |
| 冷戰 | 美國的市場與安全傘 | 外部條件 |

**推理**：東亞模式的「要素組合」——「高儲蓄 + 教育 + 出口 + 官民合作 + 冷戰」的五要素——**奇蹟 = 制度 + 外部條件的乘積**——「模式」的辯論（World Bank 1993《東亞奇蹟》——「市場 vs 政府」的辯論——發展型國家 vs 自由市場的解釋競爭）。

### 線索四：韓台的移植與調整
漢江奇蹟與台灣奇蹟：

| | 韓國 | 台灣 |
|---|------|------|
| 起點 | 1961 朴正熙（軍事政變）| 1949 土改 + 1960s 出口導向 |
| 策略 | 財閥培育（現代、三星）+ 重工業化 | 中小企業 + 加工出口區（1965 高雄）|
| 外援 | 美援（1950s-60s）+ 越戰特需 | 美援（1950s）|
| 結果 | 1965-90 增長 9%+ | 1960-90 增長 9% |

**推理**：漢江與台灣 = 日本模板的移植與調整（財閥 vs 中小企業的差異）——「發展型國家的兩型」（韓：財閥型；台：中小企業型）——**移植的調整**（1868 案明治的「選型」邏輯的經濟版）。

## 結案 -- 後果與影響
- **東亞模式**：發展型國家 + 雁行——「東亞的經濟模式」——World Bank 1993 的肯定與 1997 案危機的挑戰。
- **雁行的梯隊**：日 → NIEs → ASEAN → 中國——產業的東亞接力——2001 案中國入世的生產網絡。
- **官治金融的伏筆**：金融壓抑 + 財閥 → 1997 案危機的結構條件——「奇蹟的陰影」。
- **冷戰紅利**：美國市場 + 安全傘——「冷戰 = 東亞經濟的外部條件」——1972 案重組的伏筆。
- **教育與人力資本**：義務教育的先投資——「人力資本 = 奇蹟的內部條件」——東亞教育的模式。
