# 04.3 根軌跡法

## 本章導讀

頻域方法畫的是頻率響應；Evans 的根軌跡畫的是另一個面向：
**當迴路增益 $k$ 從 0 變到 $\infty$，閉迴路極點在複平面上走出的軌跡**。
一張圖看盡「增益調大會怎樣」，1948 年誕生後立刻成為工程標準。

## 淺顯說明

閉迴路極點決定一切動態（振盪？衰減？多快？）。
增益 $k$ 是工程師唯一能轉的旋鈕。
根軌跡就是：**轉動旋鈕時，極點在複平面上畫出的地圖**。
地圖上哪裡安全（左半平面）、哪裡危險（右半平面）、路會怎麼走——一目了然。

## 正規理論

### 根軌跡方程

單位回饋，迴路 $L(s) = k\,G(s)$，閉迴路特徵方程：

$$
1 + k\,G(s) = 0 \quad\Longleftrightarrow\quad G(s) = -\frac{1}{k}
$$

$k$ 從 $0$ 到 $\infty$，$-1/k$ 沿負實軸從 $-\infty$ 走到 $0$。
滿足此方程的所有 $s$，就是根軌跡。

### 幅角與大小條件

$s \in$ 根軌跡 ⇔：

$$
\angle G(s) = (2m+1)\pi \quad\text{（幅角條件）}, \qquad |G(s)| = \frac{1}{k} \quad\text{（大小條件）}
$$

幅角條件決定「軌跡在哪裡」，大小條件決定「這個 $k$ 時極點在哪」。

### Evans 規則（摘選）

設開迴路極點 $p_i$（$n$ 個）、零點 $z_j$（$m$ 個）：

1. 軌跡分支數 = $n$（= 極點數），起點 $k=0$ 在極點，終點 $k=\infty$ 在零點或無窮遠。
2. 實軸上的軌跡：其右側的（極點 + 零點）總數為奇數的線段。
3. 漸近線：$n - m$ 條，角度 $\theta = \dfrac{(2m'+1)\pi}{n-m}$，交點在實軸
   $\sigma = \dfrac{\sum p_i - \sum z_j}{n - m}$。
4. 離開實軸處（分離點）：滿足 $\dfrac{d}{ds}G(s) = 0$。

## 簡易範例：二階系統的根軌跡

$G = \dfrac{1}{s(s+2)}$，$L = \dfrac{k}{s(s+2)}$，特徵方程：

$$
s^2 + 2s + k = 0 \quad\Rightarrow\quad s = -1 \pm \sqrt{1 - k}
$$

軌跡：

- $k = 0$：極點在 $0$ 與 $-2$（起點）。
- $0 < k < 1$：兩極點沿實軸相向移動（$-1+\sqrt{1-k}$ 向左，$-1-\sqrt{1-k}$ 向右）。
- $k = 1$：分離點 $s = -1$（重根）。
- $k > 1$：共軛複極點 $s = -1 \pm j\sqrt{k-1}$，**沿垂直線 $\Re(s) = -1$ 上下走**。

關鍵觀察：**實部永遠 $= -1 < 0$——不管 $k$ 多大，這個系統都不會不穩**！
但阻尼比 $\zeta = \dfrac{1}{\sqrt{k}}$ 隨 $k$ 增大而減小——增益大則振盪大。

對照反例：$G = \dfrac{1}{s(s+1)(s+2)}$ 的根軌跡有漸近線
$\theta = \pm 60°, 180°$，交點 $\sigma = -1$——
增益大於臨界值（03.1 的 $k = 6$）時，兩條分支穿越虛軸進入右半平面：**不穩**。
