# 忽視案例：正確卻被冷落的百年（科學史）

> 金觀濤「理論—實驗—技術」循環的第三面：**一個正確的理論或發現，若缺乏循環中的「對接點」——沒有實驗工具能檢驗它、沒有理論框架能容納它、或觸犯了當時的權威與常識——就會被冷落數十年甚至上千年**。
>
> 負面案例（見 [負面案例](../負面案例/README.md)）是「假象被奉為真」；本幕是它的鏡像：「**真相被晾在旁邊**」。阿里斯塔克的日心說早了哥白尼一千八百年；孟德爾的遺傳定律等了三十五年；魏格納的大陸漂移等了半個世紀；麥克林托克的轉座子等了三十年。
>
> 這些案例共同說明：**科學的進步不是「真相一出就被接受」，而是等整個迴路的其餘環節趕上之後，舊的真相才被重新點火**——這正是「理論-實驗-技術相互促進」的反面證明：缺少促進，正確也會沉睡。

## 為什麼正確的會被忽視？——五條規律

1. **缺乏對接的實驗工具**——孟德爾的統計定律在沒有細胞學、沒有染色體觀察的時代無法「落地」；魏格納沒有古地磁與海底探測技術，機制無從檢驗。**沒有技術對接，正確也只是空中樓閣**。
2. **觸犯常識與權威**——阿里斯塔克違反亞里士多德的物理學整體框架；塞麥爾維斯暗示「紳士醫生的手是髒的」，等於控訴同行殺人。**社會結構讓正確的聲音被消音**。
3. **機制不明，結果再好也被丟棄**——魏格納說大陸在漂移卻答不出「什麼力量推動」；麥克林托克看見基因跳躍卻沒有分子機制。**科學要求的不只是現象，而是可檢驗的機制**。
4. **跨領域的答案沒有收件人**——茲維基是天文學家卻算出粒子物理的東西；艾弗里是細菌學家卻答了化學的問題。**循環未打通的領域邊界上，真相會掉進縫隙**。
5. **勝利總是留給「時機正確」的重複者**——孟德爾的定律被三位重新發現者在染色體學說成熟時（1900）同時接受；魏格納的觀察在海底擴張技術成熟時（1960s）被重新點火。**金觀濤迴路的反面證明：單點的正確不足以啟動科學，必須等整個循環的其餘環節到位**。
