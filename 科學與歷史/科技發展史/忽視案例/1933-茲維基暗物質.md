# 1933 茲維基暗物質與中子星

## 案發現場

1933 年，瑞士天文學家弗里茨·茲維基（Fritz Zwicky, 1898–1974）在加州理工學院帕洛瑪天文台的資料室裡，對著後髮座星系團（Coma cluster）的照片做了一件當時沒人想做的事：**替整個星系團「稱重」**。

他手上的工具是兩樣：其一，同事巴德（Walter Baade）提供的星系光譜——可以量出星系在團內奔走的速度（色散速度）；其二，力學課本裡的老定理——**維里定理（virial theorem）**：一個束縛系統達到平衡時，動能與位能之間有固定關係，於是「速度 × 半徑 ÷ G」就能估出系統總質量。

算出來的答案嚇了他一跳：**星系團的引力質量，是可見恆星光度推算質量的數百倍**。茲維基在論文中留下冷靜而大膽的結論：團內必定存在大量不發光的物質——他稱之為「**暗物質（dunkle Materie）**」。隔年（1934），他又進一步預言：超新星是恆星向內坍縮的產物，坍縮的殘骸是「由中子構成的星」——**中子星**，比白矮星緻密得多的天體。

兩個正確的預言。然後呢？然後是四十年的沉默。

## 偵查過程

茲維基的方法在 1933 年其實無可挑剔，問題出在**迴路的其他環節全部缺席**：

**第一，觀測技術無法對接。** 暗物質——顧名思義——看不見。當時沒有任何望遠鏡、任何波段的儀器能直接或間接檢驗團內的隱匿質量；中子星更是天方夜譚：一個直徑只有二十公里的天體，光學望遠鏡永遠不可能解析。**儀器追不上理論，預言只能躺在論文裡。**

**第二，跨界的答案沒有收件人。** 茲維基是天文學家，卻在算粒子物理的東西——「中子」1932 年才被查兌克發現，天文學界普遍覺得「中子星」是理論物理學家的胡思亂想；而粒子物理學家又不管星系團。他的維里定理計算則違反了當時常識：宇宙的質量帳本，怎麼可能錯上幾百倍？

**第三，茲維基的個性把盟友推開了。** 他以暴躁毒舌聞名，稱同行為「球狀混蛋」，也曾說「我在帕洛瑪的同事們都是非常平庸的人」。他的正確，往往用最得罪人的方式說出來——在小圈子的科學界，這等於自己拆掉橋樑。他與巴德關於超新星的爭執、與哈勃學派的緊張，都讓「茲維基說的話」打了折扣。

之後四十年，星系團動力學幾乎無人追問。變化從兩處開始：**1967 年，Jocelyn Bell 在休伊什的射電望遠鏡上發現脈衝星**——週期 1.337 秒的規則脈衝，只能來自高度緻密、快速自轉的天體，正是茲維基 1934 年預言的中子星（見 [1965-宇宙微波背景.md](../1965-宇宙微波背景.md) 所在的射電天文時代）；**1970 年代，Vera Rubin 與 Kent Ford 用新式光譜儀量出星系旋轉曲線**——外圈恆星的速度遠高於可見質量所能解釋，平坦的旋轉曲線讓「暗物質」從冷門猜想變成宇宙學的中央議題。

## 結案報告

射電天文與光譜技術補上對接之後，茲維基的兩個預言先後復活：

1. **中子星證實（1967→）**——脈衝星、X 射線雙星、脈衝雙星 PSR B1913+16（間接證實重力波，1993 年諾貝爾獎）接連登場。茲維基當年「粗算」的緻密天體，成為極端物理的天然實驗室。
2. **暗物質成為主流（1970s→）**——Rubin 的旋轉曲線、重力透鏡、宇宙微波背景的溫度漣漪（[1965-宇宙微波背景.md](../1965-宇宙微波背景.md)），一齊指向：宇宙中約 85% 的物質不發光。暗物質的具體身分（WIMP？軸子？）至今仍是最大的未破之案——**這樁 1933 年的案子，還在偵查中**。
3. **貝葉斯式的教訓**——茲維基的「質量帳本」沒有錯，錯的是時代假設「帳本不會錯」。當儀器與理論框架終於到位，正確的異常就被重新點火。

諷刺的是，茲維基本人終其一生未獲諾貝爾獎——中子星的名單上沒有他，暗物質的名單上也不會有他。**正確不等於被記住；時機與人緣，有時比正確更能決定科學史的座位表。**

## 冷落分析

**為什麼被忽視：**

- **缺工具對接**——暗物質看不見，中子星小到光學無法解析；沒有任何 1930 年代的儀器能檢驗這兩個預言。理論跑在儀器前面四十年。
- **跨界無收件人**——天文學家算粒子物理的東西、力學家算宇宙的帳，領域邊界上沒有誰「負責收信」。
- **觸犯常識與權威**——「宇宙質量錯幾百倍」違反當時的宇宙圖像；茲維基的暴躁作風更讓權威圈（哈勃學派）沒有動機為他背書。

**為什麼後來被接受：**

- **儀器補上了對接點**——射電望遠鏡（脈衝星）、光電光譜儀（旋轉曲線）、X 射線天文，讓「看不見的質量」變成可測量的訊號。
- **理論框架成熟**——恆星演化理論、緻密物態方程、宇宙學模型，一一為中子星與暗物質準備好「座位」。
- **金觀濤迴路的反面證明**——單點的正確（茲維基的計算）不足以啟動科學；必須等理論—實驗—技術的其餘環節趕上，真相才被重新點火。這與孟德爾（[1865-孟德爾遺傳定律.md](1865-孟德爾遺傳定律.md)）、魏格納（[1912-魏格納大陸漂移.md](1912-魏格納大陸漂移.md)）的等待，是同一條規律。

## 證據與工具

```python
# 用 Python 重做茲維基 1933 年的維里定理估算：
# 星系團質量 M ~ (速度色散)^2 * (團半徑) / G，與可見質量比較

G = 4.302e-6   # 引力常數，單位：kpc (km/s)^2 / M_sun

# --- Coma 星系團的觀測量（現代值，茲維基當年的數量級相同）---
sigma_v = 1000.0   # 星系速度色散，km/s（茲維基量到的數量級）
R = 1500.0         # 團的特徵半徑，kpc（約 5 百萬光年）

# --- 維里定理：2K + U = 0  =>  M ~ 3 * sigma^2 * R / G ---
M_virial = 3 * sigma_v**2 * R / G
print(f"維里質量：{M_virial:.3e} 太陽質量（約 {M_virial:.2f} M_sun）")

# --- 可見質量：數星系的光度 ---
n_galaxies = 800        # 團內可見星系數
L_per_gal = 1.5e10      # 每個星系平均光度，太陽光度
M_over_L = 5.0          # 恆星質光比（太陽附近）
M_visible = n_galaxies * L_per_gal * M_over_L
print(f"可見質量：{M_visible:.3e} 太陽質量")

ratio = M_virial / M_visible
print(f"暗/明之比：{ratio:.0f} 倍")
print("=> 引力質量遠大於可見質量：團內必有大量暗物質（茲維基 1933）")

# --- 中子星的緻密度檢查（茲維基 1934 的預言）---
import math
M_ns = 1.4 * 1.989e30      # 中子星質量，kg
R_ns = 10e3                # 半徑 10 km，m
rho_ns = M_ns / (4/3 * math.pi * R_ns**3)
rho_sun_core = 1.5e5       # 太陽核心密度，kg/m^3
print(f"\n中子星密度：{rho_ns:.2e} kg/m^3，是太陽核心的 {rho_ns/rho_sun_core:.1e} 倍")
print("一顆方糖大的中子星物質 ≈ 十億噸 => 光學望遠鏡永遠解析不了它")
```
