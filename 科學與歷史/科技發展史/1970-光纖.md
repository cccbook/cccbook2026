# 1970 光纖

## 案發現場

1970 年 9 月，紐澤西州，康寧玻璃公司（Corning）實驗室。三位研究員——毛高爾（Robert Maurer）、卡普隆（Donald Keck）、舒爾茨（Peter Schultz）——測量一段石英玻璃纖維的光損耗：每公里只損失 **17 分貝**——遠低於當時公認的理論門檻（20 dB/km）。卡普隆在實驗筆記上寫下「**eureka**」——人類歷史上第一根**低損耗光纖**。

在此之前，光通訊的「案發現場」是兩道懸案：雷射已問世（[1960-雷射.md](1960-雷射.md)），但光在**空氣與普通玻璃中**傳不了幾米就衰減殆盡——大氣的水汽與霧霾、玻璃的鐵雜質把光吃光。通訊史家在 1960 年代普遍認為：光通訊是「美麗但無用」的理論玩具。康寧的 17 dB/km，把這條路打開。

## 偵查過程

**線索一：理論——全反射。** 光從折射率高的介質射向折射率低的介質，入射角超過臨界角時**全部反射**——光被「關」在纖維芯裡，像水在水管中流動。這個物理原理（[1865-麥克斯韋方程組.md](1865-麥克斯韋方程組.md) 時代光學已成熟）早在十九世紀就有人用來做光的噴泉玩具；把「光的導管」變成通訊幹線，只等兩件事：**低損耗材料**與**雷射光源**。

**線索二：損耗的偵查——雜質是兇手。** 1966 年，標準電訊實驗室的高錕（Charles Kao, 1933–2018）與霍克漢姆（Hockham）發表關鍵論文：他們的推理是——玻璃的光損耗**不是玻璃本身**（石英的本徵吸收在紅外、散射極低），而是**鐵、銅等過渡金屬雜質**（百萬分之一等級即可吃掉大量光）。只要把雜質降到百萬分之一以下，光纖損耗可望低於 20 dB/km——**通訊可行**。高錕的這一推斷被當時輿論嘲笑（「玻璃做通訊幹線？」），他卻跑遍玻璃工廠尋找合作者——最後康寧接下挑戰。2009 年高錕獲諾貝爾物理獎，「光纖通訊之父」之名由此而來。

**線索三：康寧的材料偵破。** 康寧團隊用**氣相沉積（CVD）**——把超純石英蒸汽沉積成預製棒，再拉絲——把雜質壓到十億分之一等級。1970 年的 17 dB/km（在 633 nm 波段）；1972 年降到 4 dB/km；1973 年起，工作波段移到 850 nm、1310 nm、1550 nm（石英的本徵損耗最低點，約 0.2 dB/km）——雷射工作波段與材料透明窗口的**匹配**，是理論與技術的合體。

**線索四：系統的合流。** 1977 年，美國芝加哥與日本東京先後鋪設商用光纖電話幹線；1988 年跨大西洋光纖（TAT-8）開通——資訊傳播徹底脫離交通（[1844-莫斯電報.md](1844-莫斯電報.md) 的第一次脫離之後，光纖把帶寬提升十個數量級）。光纖與雷射提供物理載體，[1948-夏農資訊論.md](1948-夏農資訊論.md) 提供理論極限（通道容量 C = B·log₂(1+S/N)），封包交換（[1969-ARPANET.md](1969-ARPANET.md)）提供網路架構——**資訊高速公路的全部要素在此匯流**。

## 結案報告

低損耗光纖屬於迴路的**實驗+技術**合體環節——材料實驗（高錕的雜質推斷＋康寧的 CVD 製程）＋通訊理論（夏農極限、全反射），資訊高速公路鋪設。其深遠遺產：

1. **資訊傳播的十個數量級**——從銅線的 kbps 到光纖的 Tbps，帶寬暴跌/暴漲成為 [1989-全球資訊網.md](1989-全球資訊網.md) 與 [2007-智慧型手機.md](2007-智慧型手機.md) 時代的物理基礎。
2. **材料科學的偵破樣板**——「兇手是雜質而非材料本身」的推斷，是迴路中「實驗數據逼出理論」的經典案例。
3. **理論與技術的波段匹配**——雷射（[1960-雷射.md](1960-雷射.md)）與石英透明窗口的合流，顯示迴路的兩個環節必須「對上頻率」才能閉合。
4. **高錕的冤案與正名**——被嘲笑四十年的推斷，2009 年獲諾貝爾獎；重大理論常被當代視為異想，迴路的裁決者永遠是時間與實驗。

## 證據與工具

```python
# 偵查證物一：光損耗的帳本 — 為什麼「低損耗」是關鍵
import math

def transmission(loss_db_per_km, length_km):
    # 透射率：P_out = P_in · 10^(-損耗·長度/10)
    return 10**(-loss_db_per_km*length_km/10)

length = 10  # 10 公里
cases = [("1960 年代普通玻璃", 1000.0),
         ("1966 年高錕門檻", 20.0),
         ("1970 年康寧", 17.0),
         ("1970 年代後期", 0.5),
         ("現代光纖（1550nm）", 0.2)]
print("--- 光纖損耗帳本（10 公里後剩餘光功率）---")
for name, loss in cases:
    print(f"{name}: {loss} dB/km → 剩餘 {transmission(loss,length)*100:.1e}%")
print("→ 20 dB/km 以下通訊可行（高錕 1966 年的裁決線）")

# 偵查證物二：夏農容量 — 光纖的頻寬暴漲
B_copper, B_fiber = 1e9, 5e12   # 銅線 1 GHz vs 光纖 5 THz
snr = 1000
C_copper = B_copper * math.log2(1+snr)/1e9
C_fiber = B_fiber * math.log2(1+snr)/1e12
print(f"\n通道容量：銅線約 {C_copper:.0f} Gbit/s，光纖約 {C_fiber*1000:.0f} Gbit/s")
print(f"帶寬暴漲 {B_fiber/B_copper:.0e} 倍 —— 資訊高速公路的物理基礎")

# 偵查證物三：全反射的臨界角
n_core, n_clad = 1.468, 1.462   # 纖芯/包層折射率
theta_c = math.degrees(math.asin(n_clad/n_core))
print(f"\n全反射臨界角：{theta_c:.1f}° → 光被關在纖芯裡（光的導管）")
```
