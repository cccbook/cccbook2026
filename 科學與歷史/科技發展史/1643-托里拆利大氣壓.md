# 1643 托里拆利大氣壓

## 案發現場

案發地點是佛羅倫斯。伽利略晚年在《兩門新科學》（見 [1638-兩門新科學.md](1638-兩門新科學.md)）中記錄了一樁讓礦工與水井技師困擾兩千年的懸案：**汲水泵無論怎麼改進，吸水高度都無法超過約十公尺（約 34 英呎）**。

亞里士多德學派的官方解釋是「**自然厭惡真空**（nature abhors a vacuum）」——水泵活塞一提，水就跟著填補真空，所以水理應無限上升。但礦井的實測數據戳穿了這個說法：既然自然如此厭惡真空，為什麼吸到十公尺就停了？「厭惡」居然有個精確的上限，這本身就不是哲學，而是物理。

伽利略對此提出過一個不太成功的猜測（水柱會被自身重量「扯斷」）。真正接手這樁案件的是他的學生、數學家**托里拆利（Evangelista Torricelli, 1608–1647）**，以及一位熱衷實驗的貴族李奇（Raffaele Magiotti）。伽利略在 1642 年初去世，托里拆利次年就用一根玻璃管結了案。

## 偵查過程

托里拆利的推理關鍵在於**換一種液體做比例實驗**。水太重，玻璃管就得十公尺長，難以操作；水銀的密度是水的 13.6 倍，若同一機制成立，水銀柱高度應只有水的 1/13.6——約 760 毫米，一根一米長的玻璃管就夠了。

1643 年，托里拆利在玻璃管中灌滿水銀，倒立插入水銀槽。水銀柱下降，停在**約 760 毫米**處，頂端留出一段空無一物的空間——後世稱之為「**托里拆利真空**」。這是實驗史上第一次人為製造出持續存在的真空。

接著他做了決定性的**對照推理**：如果水銀柱是被「厭惡真空」吸住的，那麼管口粗細、管的形狀都應無關緊要；但如果水銀柱是被**外界大氣壓力**壓著的，那麼同一根管子在水銀槽中只要管長不同、傾斜與否，**水銀柱的垂直高度都必須相同**。托里拆利與同事用不同形狀的管子反覆驗證——垂直高度永遠是 760 毫米。

推理鏈完整了：管內水銀柱的重量 $=$ 外界大氣壓作用在槽面的力。大氣不是虛無，而是一層有重量的「海洋」，我們都住在海底。

托里拆利還留下了一句精準的墓誌銘式表述：

> 「我們生活在空氣之海的底部，而且無可懷疑地，這片海是有重量的。」

他更觀察到水銀柱高度會隨天氣日日微變——這根玻璃管後來成為**氣壓計**，人類第一個能「預報天氣」的科學儀器。可惜托里拆利 1647 年就病逝，年僅 39 歲，未及看到他的發現如何點燃整個第三幕。

## 結案報告

1. **「自然厭惡真空」被處決**——亞里士多德體系中最頑固的教條之一，被一根玻璃管終結。解釋權從哲學書轉到實驗桌。
2. **真空成為可製造、可研究的對象**——直接催生了[1656-惠更斯擺鐘.md](1656-惠更斯擺鐘.md)時代的氣壓計研究，以及馬德堡半球（1654）、波以耳—虎克的真空泵（[1662-波以耳定律.md](1662-波以耳定律.md)）。
3. **大氣壓成為新的物理量**——巴斯卡隨即在多姆山做海拔實驗（1648），證實氣壓隨高度遞減，大氣「海洋」有了可測量的深度。
4. **迴路意義**：這是「假設→儀器→實驗→理論修正→技術（氣壓計）」完整閉合的早期標本，是[1687-牛頓原理.md](1687-牛頓原理.md)之前實驗哲學成熟的關鍵一環；紐科門蒸汽機（[1698-紐科門蒸汽機.md](1698-紐科門蒸汽機.md)）的整個原理就建立在這次的結論之上。

## 證據與工具

```python
# 托里拆利實驗的定量驗證：水銀柱與水柱高度比
rho_water = 1000.0   # 水的密度 kg/m^3
rho_mercury = 13546.0  # 水銀密度 kg/m^3
g = 9.81

# 平衡條件：大氣壓 = rho * g * h
# 同一大氣壓下，液柱高度與密度成反比
h_ratio = rho_water / rho_mercury
print(f"水柱高度 / 水銀柱高度 = {h_ratio:.2f}")

h_Hg = 0.760  # 實測水銀柱 760 mm
print(f"水銀柱 {h_Hg*1000:.0f} mm -> 對應水柱應為 {h_Hg/h_ratio:.2f} m")
print("（礦井實測汲水上限約 10 m，與預測吻合！）")

# 大氣壓數值
P = rho_mercury * g * h_Hg
print(f"大氣壓 P = {P:,.0f} Pa ≈ 1 atm")

# 巴斯卡的海拔檢驗：氣壓隨高度遞減（簡化等溫模型）
import math
H = 8000.0  # 標高尺度（約 8 km）
for z in [0, 1500, 4807]:
    print(f"海拔 {z} m：氣壓約 {P*math.exp(-z/H):,.0f} Pa")
```
