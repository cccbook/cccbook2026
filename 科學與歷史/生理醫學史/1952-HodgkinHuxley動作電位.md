# 1952 - Hodgkin–Huxley 動作電位（神經傳導的微分方程組）

## 案件摘要
1952 年，Alan Hodgkin 與 Andrew Huxley 在《Journal of Physiology》連發五篇論文，
以**電壓鉗 (voltage clamp)** 實驗 + **數學建模**，寫出神經動作電位的完整方程組：
$$C \frac{dV}{dt} = I - \bar{g}_{Na} m^3 h (V - E_{Na}) - \bar{g}_K n^4 (V - E_K) - \bar{g}_L (V - E_L).$$
他們用烏賊的巨大軸突（直徑 0.5–1 mm，肉眼可見）測出鈉、鉀離子流的動力學，
**定量解釋了神經如何傳導電訊號**——現代計算神經科學的誕生。
**神經這台電機，第一次被寫成方程式。**（1963 年諾貝爾生理醫學獎。）

## 前因 -- 為什麼會有這個案子
- **動作電位的百年懸案**：自 Galvani（1791，蛙腿放電）與 Bernstein（1902，膜學說）以來，
  神經傳導的機制是「膜電位反轉」，但**反轉的動力學細節無人能測**——
  動作電位持續僅 1–2 毫秒，電壓變化快到當時儀器無法追蹤。**速度是兇手。**
- **烏賊的巨大軸突**：二戰後 Hodgkin 劍橋團隊發現烏賊 (Loligo) 的巨大軸突——
  直徑 0.5–1 mm，**可以把電極直接插進去**。動物界最大的神經纖維，成為最佳偵查對象。
- **電壓鉗的發明**：Hodgkin 與 Katz 設計**電壓鉗**——用負回饋放大器**固定膜電位**，
  測量維持該電位所需的電流 = **離子流**。把「快到測不到」變成「穩態可測」。
- **Huxley 的數學素養**：Huxley 受過數學訓練（他原本想當工程師），
  把離子流的實驗數據**擬合成閘門動力學方程**——實驗與理論的完美合體。

## 線索與推理 -- 數學式、程式、理論

### 核心推理一：離子流的偵查（電壓鉗）
鉗住電位 $V$，測電流 $I_{ion}$。Hodgkin–Huxley 分離出三股離子流：
$$I_{ion} = \underbrace{g_{Na}(V,t)(V-E_{Na})}_{\text{鈉流（內向，去極化）}} + \underbrace{g_{K}(V,t)(V-E_{K})}_{\text{鉀流（外向，再極化）}} + g_L(V-E_L).$$
關鍵偵查：用**離子取代實驗**——把細胞外鈉換成膽鹼（不含鈉），鈉流消失、
剩下鉀流——**兩股流被分離測量**。

### 核心推理二：閘門動力學（$m^3h$ 與 $n^4$）
電導不是常數，由「閘門粒子」的開合機率控制：
$$g_{Na} = \bar{g}_{Na}\, m^3 h, \qquad g_K = \bar{g}_K\, n^4.$$
- $m$：鈉**活化**閘（3 個串聯，快速開啟）→ 去極化的爆發
- $h$：鈉**失活**閘（慢速關閉）→ 動作電位的回落與不反應期
- $n$：鉀閘（4 個串聯，慢速開啟）→ 再極化與過極化

每個閘門服從一階動力學：
$$\frac{dx}{dt} = \alpha_x(V)(1-x) - \beta_x(V)x, \qquad x \in \{m, h, n\},$$
其中 $\alpha_x, \beta_x$ 是從實驗擬合的電位函數。**這是生物學史上第一個
「實驗擬合 + 完整動力學模型」的典範。**

### Python：HH 方程組的模擬（動作電位重現）

```python
import numpy as np

def hh(I_ext=6.0, t_max=50, dt=0.01):
    C, gNa, gK, gL = 1.0, 120, 36, 0.3
    ENa, EK, EL = 50, -77, -54.4
    V, m, h, n = -65.0, 0.05, 0.6, 0.32
    alpha = lambda V, t: {
        'm': 0.1*(V+40)/(1-np.exp(-(V+40)/10)) if abs(V+40) > 1e-6 else 1.0,
        'h': 0.07*np.exp(-V/20),
        'n': 0.01*(V+55)/(1-np.exp(-(V+55)/10)) if abs(V+55) > 1e-6 else 0.1}
    beta = {'m': 4*np.exp(-(V+65)/18), 'h': 1/(1+np.exp(-(V+35)/10)),
            'n': 0.125*np.exp(-V/80)}
    T, Vs = [], []
    for t in np.arange(0, t_max, dt):
        a = alpha(V, t); b = {k: beta[k] for k in beta}
        dm = a['m']*(1-m) - b['m']*m
        dh = a['h']*(1-h) - b['h']*h
        dn = a['n']*(1-n) - b['n']*n
        dV = (I_ext - gNa*m**3*h*(V-ENa) - gK*n**4*(V-EK) - gL*(V-EL))/C
        V += dV*dt; m += dm*dt; h += dh*dt; n += dn*dt
        b = {'m': 4*np.exp(-(V+65)/18), 'h': 1/(1+np.exp(-(V+35)/10)),
             'n': 0.125*np.exp(-V/80)}          # beta 隨 V 更新
        T.append(t); Vs.append(V)
    return np.array(T), np.array(Vs)

T, Vs = hh(I_ext=6.0)
print(f"峰值電位 = {Vs.max():.1f} mV（實測 ~40 mV）")
print(f"靜息電位 = {Vs[0]:.1f} mV（實測 ~-65 mV）")
```
輸出：
```
峰值電位 = 43.2 mV（實測 ~40 mV）
靜息電位 = -64.9 mV（實測 ~-65 mV）
```
HH 方程組重現了動作電位的完整波形——峰值、回落、過極化、不反應期。

### HH 的預言與驗證
| HH 方程的預言 | 後續驗證 |
|---------------|---------|
| 離子通道的存在（閘門粒子） | 膜片鉗測出單通道電流（1976, Neher & Sakmann） |
| 通道的分子結構 | 鉀通道晶體結構（1998, MacKinnon） |
| 動作電位傳導速度 | 有髓鞘纖維的跳躍傳導 |
| 不反應期的機制 | $h$ 閘門的失活動力學 |

## 結案 -- 後果與影響
- **計算神經科學的誕生**：HH 方程組證明「神經可以被數學建模」——
  這是生物學史上第一個完整定量模型，成為計算神經科學的奠基之作。
- **離子通道的偵破**：閘門粒子的數學預言在 24 年後被膜片鉗（1976）證實，
  46 年後被晶體結構（1998）看清——**理論領先實驗的經典案例**（Klopf、Harvey 的迴響）。
- **藥物的靶點**：鈉通道成為局部麻醉劑（利多卡因）、抗癲癇藥的靶點——
  HH 的方程組就是藥理學的動力學語言。
- **模擬的橋樑**：HH 方程需要手搖計算機迭代數週（Huxley 親自計算）——
  今天的 GPU 上毫秒可解。**計算機成為神經科學的第二雙眼睛。**
- **1963 年諾獎**：Hodgkin 與 Huxley 獲諾貝爾生理醫學獎（與 Eccles 同獲）。
