# 1769-瓦特蒸汽機

## 案件摘要

1769年，蘇格蘭格拉斯哥的儀器製造師詹姆斯·瓦特（James Watt，1736–1819）取得第一項蒸汽機專利：「減少蒸汽與燃料消耗的方法」——分離冷凝器（separate condenser）。他讓蒸汽在獨立的冷凝室冷凝、汽缸永遠保持高溫，把紐科門機約0.5%的熱效率提升三到四倍。此後他又發明行星齒輪（把往復運動轉為旋轉）與離心調速器（自動控制轉速），並提出「馬力」單位。瓦特蒸汽機成為工業革命的通用動力心臟。

## 前因 -- 為什麼會有這個案子

- 1763–1764年，瓦特受格拉斯哥大學之託修理一台紐科門機教學模型，修理後發現它耗煤驚人。
- 瓦特以物理學家氣質「算帳」：紐科門機每循環把整個汽缸加熱又冷卻，大量熱量浪費在汽缸壁上——問題不在漏汽，而在熱管理。
- 1765年5月，瓦特在格拉斯哥綠地散步時靈光乍現：「既然蒸汽是彈性體，何不讓蒸汽衝入一個保持低溫的獨立容器冷凝？」——分離冷凝器誕生。
- 商業化的關鍵是伯明罕製造商馬修·博爾頓（Matthew Boulton）：1775年兩人合夥成立 Boulton & Watt，並透過國會延長專利至1800年；博爾頓的 Soho 工廠提供精密鏗孔技術（威尔金森 John Wilkinson 的鏗床，1774年）解決汽缸漏汽。
- 市場動機明確：康沃爾錫銅礦排水需要省煤的機器——煤在那裡不便宜，效率就是利潤。

## 線索與推理 -- 數學式、程式、理論

### 理論一：分離冷凝器——把浪費的熱帳算回來

紐科門機每循環的熱損失主要來自反覆加熱汽缸體。設汽缸鐵重 $m_{cyl}$、比熱 $c_{iron} \approx 0.45$ kJ/(kg·K)，每循環溫差 $\Delta T \approx 80$ K（從約20°C加熱到約100°C）：

$$Q_{waste} \approx m_{cyl}\, c_{iron}\, \Delta T$$

分離冷凝器讓汽缸恆維持高溫，只有少量蒸汽進入冷凝室放熱。瓦特實測其機器耗煤僅為紐科門機的約1/3至1/4，效率提升至約2–3%：

$$\eta_{Watt} \approx \frac{W}{Q_{in,Watt}} \approx 3\,\eta_{Newcomen}$$

此外瓦特引入「膨脹做功」（steam expanding）：蒸汽在衝程中途切斷進汽，靠自身膨脹繼續推動活塞，進一步省汽。理想絕熱膨脹中：

$$P V^{\gamma} = \text{const}, \qquad W_{expand} = \int_{V_1}^{V_2} P\,dV = \frac{P_1 V_1 - P_2 V_2}{\gamma - 1}$$

（$\gamma \approx 1.3$ 為水蒸氣的絕熱指數；此理論要到十九世紀熱力學才完全建立，瓦特以經驗曲線先行。）

### 理論二：行星齒輪與平行運動——往復變旋轉

要驅動紡織機與磨坊，需要旋轉運動。瓦特原想用曲柄，但被競爭者皮卡德（James Pickard）搶先取得專利，遂發明「行星齒輪」（sun-and-planet gear，1781年專利）：連桿上固定齒輪與飛輪軸齒輪嚙合，往復運動即轉為單向旋轉。傳動比 $i = 2$：連桿轉一圈、飛輪轉兩圈。另以「平行運動連桿機構」（parallel motion，1784年專利）讓活塞桿直線運動帶動橫樑端點弧線運動——用連桿幾何近似直線軌跡（此即後來 Peaucellier 直線機構要解決的問題的前身）。飛輪則以轉動慣量 $J$ 平滑轉速波動：

$$E_{flywheel} = \tfrac{1}{2} J \omega^2$$

### 理論三：離心調速器——反饋控制的誕生

1788年，瓦特引入離心調速器（centrifugal governor，概念源自磨坊的「flyball」離心擺）：兩個重球隨主軸旋轉，轉速升高時離心力使球外張、連桿上提，自動調小蒸汽節流閥；轉速下降則反向。離心力的力學：

$$F_c = m \omega^2 r$$

這是一個負反饋系統：輸出（轉速）經測量（球的角度 $\theta$）回饋修正輸入（蒸汽流量），使系統穩定在設定轉速——控制論的最早工程實例之一。麥克斯韋（1868年〈論調速器〉）即以此為題奠定控制理論的數學基礎。

```python
# 驗證：離心調速器的平衡角與反饋
import math
m, g = 0.5, 9.8      # 球重
h = 0.15             # 懸掛臂長（垂直）
for omega in [10, 15, 20]:   # rad/s
    # 平衡時 tan(theta) = omega^2 * r / g，r = h*tan(theta)
    # => r = omega^2 * h^2 * tan / g 解出：sin(theta) = omega^2 * h * sin? 簡化：
    # 平衡方程: m*omega^2*r*(h/r) = m*g*h?  用經典結果 tan? 直接解二次式
    # m ω² r = T sinθ, m g = T cosθ, tanθ = ω² r/g, r = L sinθ
    # => cosθ = g/(ω²L), L=0.3 m
    L = 0.3
    c = g / (omega**2 * L)
    theta = math.degrees(math.acos(c)) if c <= 1 else float('nan')
    print(f"轉速 {omega} rad/s → 球張角 {theta:.0f}°（轉速↑角度↑ → 自動關小閥門）")
```

## 破案時刻

1769年1月，瓦特取得「減少蒸汽燃料消耗之新方法」專利；1765年的綠地頓悟成為專利核心。1776年首批商用瓦特機在康沃爾礦場與倫敦拉德蓋特（Ludgate）的自來水廠啟用，實測省煤約75%，礦場主人爭相訂購。Boulton & Watt 採用聰明的商業模式：不賣機器，而按「省下的煤」抽取權利金（通常為1/3）——效率直接變成收入。1781年行星齒輪、1782年雙動式汽缸（蒸汽輪流推活塞兩側，功率倍增）、1788年離心調速器、1790年壓力計——一台自動、旋轉、可調速的通用動力機器就此完成。瓦特也為行銷定義了「馬力」：一匹拉磨的馬每分鐘做功約33,000英尺磅，即

$$1\ \text{hp} = 33000\ \frac{\text{ft·lbf}}{\text{min}} \approx 745.7\ \text{W}$$

## 後果 -- 改變了什麼

- 熱效率提升數倍使蒸汽機擺脫「只能守在煤礦邊」的命運，成為工廠、磨坊、啤酒廠、自來水廠的通用動力，工廠從此不必建在河邊。
- 旋轉動力 + 離心調速器使蒸汽機能驅動阿克萊特式紡紗廠——動力紡織與蒸汽機在1780年代會師，工業革命全面啟動。
- 反饋控制（調速器）與自動閥門開啟自動化傳統，直通麥克斯韋的控制理論與二十世紀的控制工程。
- 專利制度與「按省煤抽成」的商業模式展示了創新—資本—製造的鐵三角；瓦特1800年退休時，英國已裝設約500台瓦特機，「馬力」沿用至今成為功率的日常單位。
