# 未來史 -- AI 偵探風格

> 推演未來的人常犯兩種錯誤：**單線推理**（假設一條路走到底）與**武斷**（把「可能」寫成「必然」）。
> 思想家金觀濤在剖析近代科學起源時指出：科學革命的本質是「理論—實驗—技術」三環相互促進、自我完成的循環結構。
> 未來史同樣有一個結構：**未來的形狀，由「因素—傳導—鎖定」三段結構決定**——本書即以這個結構為主軸，做樹狀推演。

本卷的核心方法只有一句話：**未來不是一條線，是一棵由迴路長出來的樹。**
每個分歧點（branch point）都是某條「因素⇒因素」通道的**臨界時刻**——促進與抑制的符號在那裡翻轉、迴路在那裡跨過門檻。偵探的工作不是猜中哪一枝，而是：

1. **還原分歧點**：哪條通道到了臨界？翻轉的條件是什麼？
2. **樹狀推演**：每一枝的傳導鏈與後果。
3. **給出觀察指標**：現在就能查的數據，判斷「我們正在哪一枝上」。
4. **誠實標注不確定性**：本書每篇都是「假設的集合」，不是預言。

## 未來推演的結構理論（金觀濤循環的未來版）

金觀濤以 $x, y, z$（理論、實驗、技術）之間的完整有向圖（九條促進通道）解釋「科學為何加速」；未來史以同構的三段結構解釋「未來為何分岔」：

- **因素（x）**：十三種歷史因素的現況與張力——科技、政治、經濟、戰爭、心理、組織、環境、人口、少子化、壽命、債務、法律、資訊（[世界史] 因素框架向未來的延伸）。
- **傳導（y）**：任兩因素之間都存在「促進／抑制」通道——$a \Rightarrow b$，$a, b \in \{x\}$，**任兩者雙向、同類內部也自我促進**（科技⇒科技：AI 加速 AI 研究；經濟⇒經濟：投資→報酬→更多投資）。
- **鎖定（z）**：路徑依賴——投資、制度與規範累積到臨界後**自我強化**，分支被「寫入」；「穩定孕育不穩定」（明斯基）是負向鎖定的特例。

**分歧點 = 通道符號翻轉（促進↔抑制）或迴路跨過臨界的時刻。**

還有第四個要素貫穿每一條通道：**資訊／媒體**。傳播速度決定通道的轉速——印刷、電報、網路、AI 的四次「點火」（見 [世界史] 資訊因素），每一次都讓所有通道的運轉速度跳升一個量級。

### 與金觀濤循環的對照

| 金觀濤的科學循環 | 未來史的推演結構 |
|------------------|------------------|

| 實驗：以受控手段檢驗假設 | **傳導**：通道與回饋——檢驗哪些迴路被點火 |
| 技術：把知識物化為工具 | **鎖定**：投資與制度把未來「物化」——路徑被寫入 |

| 九條促進通道（任兩環雙向） | 十三因素的 $a \Rightarrow b$ 通道圖 |

金觀濤的洞見是「近代科學是一個自我完成的組織結構，不是發現的清單」；本書的洞見是：**未來不是事件的清單，而是一組正在運轉的迴路——讀懂迴路，才讀得懂分歧。**

## 閱讀方式

每篇 wiki 依「推理探案」格式撰寫（與 [世界史] 的過去探案平行）：

- **案件摘要**：這個分歧點推演什麼、為何重要。
- **前因**：現況與線索——從 2025–26 的可觀察事實出發，加上歷史先驗。
- **線索與推理**：因素傳導與背後理論（數學式、學術理論、表格與迴路圖），並標註本篇體現的通道。
- **推演**：情境樹——分支的觸發條件與樹狀圖（ASCII）。
- **分支的後果**：若走到這一枝，各因素如何被改寫（前因後果的樹狀延伸）。
- **觀察指標**：現在就能追蹤的數據與判讀方式。
- **不確定性與未解**：誠實標注盲點——**本書每篇都是假設集合，不是預言**。

與 [世界史]（多因咬合的過去）與 [武器與戰法]（武器→戰法的單線深化）互補：本卷以同一因素框架向未來做樹狀推演；歷史規律（成本曲線、連接的雙面刃、穩定孕育不穩定、外生衝擊重置系統）是先驗，觀察指標是偵測工具，**謙遜是方法**。
