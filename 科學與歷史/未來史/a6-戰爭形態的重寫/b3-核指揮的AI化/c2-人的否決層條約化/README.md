# c2-人的否決層條約化

> 樹葉節點：[a6/b3-核指揮的AI化](../../) 的終點——**如果「人的否決層」條約化發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 政治 | 「險釀」的教訓（古巴危機先驗的當代版）→核與 AI 的穩定性條約：「人的否決」成為條約義務——與 [a3/b3-算力條約](../../../a3-AI治理與法律/b3-算力條約/) 匯合 |
| 軍事 | 核指揮的「人審核」制度化：AI 只能建議、人類否決——決策時間壓縮與人審核的張力以制度解 |
| 法律 | 核與 AI 的「責任鏈」立法（誰下達、誰負責）——與 [a3/b2-治理真空](../../../a3-AI治理與法律/b2-治理真空擴大/) 的收縮 |
| 心理 | 「制度趕得上」的信心回復；核焦慮的緩解 |
| 跨鏈 | 嚇阻的升級版：核秩序的重新談判（新 START 之後的第一個條約） |

## 上游（傳導回顧）

核指揮 AI 化（b3）→一次「差點開戰」的險釀→「人的否決層」的條約動員——**嚇阻體系的重構**（與 [武器與戰法/1962] 的「古巴危機→熱線→條約」同構）。

## 觀察指標

- 「人的否決」條約的談判與簽署。
- 各國核指揮「人審核」的公開聲明。
- 核軍控談判的回歸（新 START 之後）。

## 不確定性

- 條約可能是「弱者的條約」（缺席者、新核國家）——勝利可能是部分的。
- 條約的「查證」（AI 參與決策的稽核）技術上可行嗎——軟體無法稽核的老問題。
