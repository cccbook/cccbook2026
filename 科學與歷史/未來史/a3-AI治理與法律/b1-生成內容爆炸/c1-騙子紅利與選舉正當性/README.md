# c1-騙子紅利與選舉正當性

> 樹葉節點：[a3/b1-生成內容爆炸](../../) 的終點——**如果騙子紅利與選舉正當性危機發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 政治 | 選舉爭議進入「無法驗證」地帶：敗選方稱證據為深偽——正當性的常態侵蝕 |
| 法律 | 證據法的重建：數位證據的「出身驗證」成為訴訟核心；「深偽辯護」的攻防 |
| 社會 | 「證據素養」成為基本教育；「眼見為憑」的認知規則失效 |
| 心理 | 「一切都是假的」的犬儒化 vs「只信小圈」的部落化——兩種退化 |
| 跨鏈 | 與 [a3/b2-治理真空擴大](../../b2-治理真空擴大/) 咬合（法律執行依賴證據） |

## 上游（傳導回顧）

騙子紅利（liar's dividend）：

$$P(\text{真的被否認}) \propto P(\text{偽造被相信})$$

偽造越猖獗，否認越有力——**否認成本→零→真實性的稀缺**。

## 觀察指標

- 選舉爭議的司法結案率（下降=正當性危機）。
- 「深偽辯護」在訴訟與政治言論的頻率。
- 付費/簽章媒體的訂閱增長（分層信任的成形訊號）。

## 不確定性

- 「分層信任」的社會適應可能取代崩潰——選舉的正當性危機可能被「制度化驗證」化解。
- 各國的選舉制度差異使後果分散（不在同一時間點爆發）。
