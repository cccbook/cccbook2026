# c1-不可保地帶擴張

> 樹葉節點：[a8/b1-保險退潮](../../) 的終點——**如果不可保地帶擴張發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 經濟 | 「不可保」成為資產定價的新變數；沿海與邊緣地產的重估 |
| 政治 | 「最後保險人」的財政擠壓；「被放棄的地區」的政治問題——與 [a7/b2/c1-年金擠壓](../../../a7-壽命革命與老齡化/b2-老齡化加深/c1-年金擠壓投資與財政死結/) 的財政死結交叉 |
| 社會 | 被棄地帶的社會問題（服務撤出、人口流失）；遷徙與安置 |
| 財政 | 風險的社會化 vs 放棄的兩難 |
| 心理 | 「家園的不可保」的心理衝擊 |

## 上游（傳導回顧）

保險退潮（b1）→沒有保險=沒有房貸=地產重估→稅基↓→財政↓→適應能力更弱——**螺旋的完成式**：地圖上的「不可保地帶」擴大。

## 觀察指標

- 「不可保區」的地圖統計（保險業的退出清單）。
- 被棄地帶的人口流失與房產拋售。
- 國家「最後保險人」的財政負擔。

## 不確定性

- 國家的承擔意願（最後保險人）各國不同——本節點的深度取決於政治。
- 適應投資（堤防、規範）可能使保險回歸——螺旋可逆。
