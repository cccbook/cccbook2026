# 台海封鎖_晶片斷鏈_全球算力配給時代

## 案件摘要

**如果台海封鎖發生，就會造成「晶片斷鏈」，進而造成「全球算力配給時代」**——先進製程約九成在台灣（晶片=新錫貿易，[武器與戰法/-3000] 的供應鏈短板規律）；封鎖是「可否認的戰爭」，斷鏈是「無聲的全球衰退」。這條鏈的終點是：算力從「市場商品」變成「戰略配給品」——AI 時代的石油禁運。

## 起火點 -- 如果台海封鎖發生

- **現況證據**：先進製程高度集中；「檢疫式演練」與灰色地帶操作常態化；封鎖討論（檢疫、隔離）從沙盤推演變成公開論述。
- **觸發條件**：政治事件的升級＋「可否認」的封鎖形式（檢疫、演練轉常態）＋「成本核算」的戰略判斷（封鎖比登陸便宜）。

## 連鎖推演 -- A→B→C

### 第一步：台海封鎖（戰爭⇒經濟）

封鎖=「可否認的戰爭」：以「檢疫」名義的海空封鎖——與 [武器與戰法/1943-大西洋狼群](../武器與戰法/1943-大西洋狼群與反潛.md) 的噸位戰同構：**不必登陸，只要斷流**。

### 第二步：晶片斷鏈（經濟⇒科技）

- 供應鏈的短板規律：先進製程（≤7nm）的斷供=AI、手機、車用、國防的一切上游停擺——**「晶片=新錫貿易」**（與 [武器與戰法/-3000] 的「錫斷供→兵器停擺」同構）。
- 晶圓、封測、設備、材料的連鎖缺料——「庫存的天數」成為全球企業的生死線。

### 第三步：全球算力配給時代（科技⇒政治⇒經濟）

- 算力從「市場商品」變「戰略品」：國家的「算力儲備與配給」（優先順序：國防>醫療>經濟）——**AI 時代的石油禁運**。
- 價格信號 vs 行政配給：市場的自動配給（價格暴漲）vs 國家的優先序——**短缺經濟學的復活**。
- 地緣的重排：與 [美債殖利率失控_市場強制緊縮_美元特權反噬](美債殖利率失控_市場強制緊縮_美元特權反噬.md) 交叉（財政危機中的封鎖承受力）。

## 分岔 -- 每一步的「若…否則…」

| 環節 | 若 | 否則 |
|------|-----|------|
| 封鎖的型態 | 灰色（檢疫式、可否認）→斷鏈緩慢累積 | 公開宣戰→直接衝突（與核門檻鏈交叉） |
| 全球庫存 | 高庫存的產業（車用）撐一年→緩衝 | 低庫存（AI 資料中心即時化）→數週即斷——**即時化的脆弱** |
| 替代產能 | 海外先進產能＋成熟製程頂上→算力配給而非全斷 | 無替代→斷鏈的全面衰退 |
| 決戰的走向 | 封鎖長期化→「窒息戰」消耗 | 快速攤牌→軍事衝突（核門檻風險） |

## 整個世界的變化

| 領域 | 變化 |

| 科技 | 算力的「戰略化」：國家儲備、優先序、替代架構（成熟製程+特殊應用）的加速 |
| 政治 | 「晶片主權」的急迫投資；中立國的壓力（選邊） |
| 軍事 | 封鎖與反封鎖的海空對峙；無人機與水雷的角色（→[兵源稀缺_無人機量產_軍隊無人化](兵源稀缺_無人機量產_軍隊無人化.md)） |
| 社會 | 「即時化文化」的終結（庫存回歸）；消費的配給感 |
| 法律 | 封鎖的「檢疫」法理戰；制裁與反制裁的清算網路戰——與 [美國財政主導_通膨稀釋債務_美元儲備地位動搖](美國財政主導_通膨稀釋債務_美元儲備地位動搖.md) 的武器化金融交叉 |

## 觀察指標

- 台海「檢疫式演練」的頻率與持續時間（封鎖的路徑累積）。
- 海外先進產能的落地比例（替代產能=配給時代的緩衝）。
- 全球科技業的「庫存天數」回歸（即時化的反向）。
- 戰爭風險保險費率與貨櫃運費的跳升。

## 不確定性

- 封鎖的「可否認性」使國際反應的門檻模糊——衝突的升級與否是政治判斷，無法推演。
- 海外產能的緩衝程度取決於「發生時點」——本鏈的後果隨時間變化（越晚發生、緩衝越大）。
