# c1-市場強制緊縮

> 樹葉節點：[a4/b2-殖利率失控](../../) 的終點——**如果市場強制緊縮發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 經濟 | 緊縮衰退+利率高懸的滯脹；全球風險資產的定價基準（美債）重寫 |
| 政治 | 「債券市場治國」的民主危機：選民意志與市場強制的正面衝突——政治地震（英國 2022 先例的放大） |
| 財政 | 緊縮與加稅的劇痛（年金、國防、福利的排擠）——與 [a7/b2/c1-年金擠壓](../../../a7-壽命革命與老齡化/b2-老齡化加深/c1-年金擠壓投資與財政死結/) 交叉 |
| 地緣 | 防衛負擔的排擠→同盟承諾打折——與 [a5-台海封鎖](../../a5-台海封鎖/) 的威懾可信度交叉 |
| 社會 | 「通膨+緊縮」雙重壓力世代——政治極化的燃料（1930s 先驗） |

## 上游（傳導回顧）

殖利率失控（b2）→利息爆炸→被迫緊縮——**「市場使你做政治上做不到的事」**——民主政治的算式被債券市場改寫。

## 觀察指標

- 緊縮立法（預算案）的通過速度與市場反應。
- 殖利率的「止血」時點（緊縮的成效）。
- 政治地震（政府垮台、提前選舉）的發生。

## 不確定性

- 緊縮的「止血」可能成功（1990s 加拿大先例）——地震不必然持續。
- 政治的反應（團結 vs 僵局）是本節點的分水嶺，無法推演。
