# 社會結構史 -- AI 偵探風格

以「推理探案」的方式，追查人類社會結構從農業革命到生成式 AI 的每一次重構：
政治權力如何組織？經濟剩餘如何分配？人民生活如何改變？組織方式如何演替？
特別追問：**每一項技術（農業、青銅、鐵器、貨幣、文字、印刷、航海、蒸汽、電力、汽車、電報、微處理器、網路、智慧手機、區塊鏈、AI）如何撬動社會結構、經濟、政治、生活與組織？**
並追查隱形的結構推手：**疾病與醫療**（瘟疫、疫苗、細菌學、抗生素、全球衛生）、**地理交換**（美洲發現、新食物、白銀、奴隸貿易）與**其他力量**（氣候、戰爭、作物、移民、人口轉型）如何同樣重構社會。

（涵蓋：農業革命、官僚帝國、封建莊園、商業革命、印刷與宗教改革、股份公司與金融革命、工業革命與階級社會、總體戰與福利國家、資訊革命與平台社會）

## 破案主線一覽

1. **剩餘的詛咒**（前9000–前1754）：農業剩餘 → 財產 → 階層 → 國家——社會分層的因果鏈，技術（農業）是第一推手。
2. **記錄技術與組織**（前3200–2008）：泥板記帳 → 成文法 → 複式記帳 → 區塊鏈——「怎樣記錄信任」決定組織的規模。
3. **能源與組織方式的演替**（前1000–1971）：人力 → 鐵器 → 蒸汽 → 電力 → 晶片——每種能源對應一種組織（莊園 → 工廠 → 公司 → 平台）。
4. **通訊與政治**（前3200–2004）：文字 → 印刷 → 電報 → 廣播 → 社交媒體——傳播半徑決定政治共同體的大小（帝國 → 民族 → 極化部落）。
5. **市場與國家的拉鋸**（前600–1944）：硬幣市場 → 重商主義 → 自由放任 → 凱因斯革命 → 福利國家——「嵌入」與「脫嵌」的百年鐘擺（Polanyi）。
6. **計算與經濟制度**（1917–2022）：蘇聯計畫經濟的計算難題（Mises/Hayek）→ 電腦 → 平台演算法定價——「社會主義計算論戰」以演算法形式重演。
7. **算力升維與工作重構**（1769–2022）：蒸汽（體力→機器）→ 流水線（技能→節拍）→ 電腦（常規→自動化）→ 生成式 AI（非常規→也自動化）——每次都重畫勞動的階層圖。
8. **疾病與社會結構**（541–2020）：瘟疫 → 勞力、工資與階層重組（541、1347）→ 公共衛生國家（1854、1885）→ 全球衛生治理（1980、2020）——傳染病是社會結構的隱形推手。
9. **醫療技術與人口轉型**（1796–1943）：疫苗、細菌學、抗生素 → 死亡率崩降 → 人口爆炸 → 生育率下降 → 家庭與性別結構重構。
10. **非技術的結構力量**：氣候震盪（1315）、宗教戰爭與主權體系（1618）、作物單一化與大移民（1846）——社會結構的推手從不只是技術，地理、疾病、戰爭與人口同樣是主角。
11. **地理交換與生物全球化**（1492–1650）：美洲發現 → 白銀（1545）、新食物（1550）、奴隸（1650）與疫病的全球流動——新作物改寫人口地圖（中國、歐洲、非洲），殖民體系種下種族階層與依附結構，價格革命讓全球貨幣網成形。
