# 1895 - Marconi 無線電報（看不見的波征服海洋）

## 案件摘要
1895 年，Guglielmo Marconi 在義大利展示無線電報；
1901 年 12 月，英國康沃爾的 Poldhu 發出訊號，3 小時後加拿大紐芬蘭的 Signal Hill 收到——
**「Marconi 的奇蹟」**。第一次訊息跨越大西洋 3,400 公里，**無需任何導線**。
$$\text{火花放電（載波脈衝）} \xrightarrow{\text{空間}} \text{coherer 檢波器}.$$
無線時代開啟——從此電報線的束縛被解除，訊息終於能跨越海洋、山脈與真空。

## 前因 -- 為什麼會有這個案子
- **有線電報的地理限制**：海纜每公里高昂、維修困難（1866 大西洋電纜的斷裂與魚類攻擊）——
  **跨海需等待特殊船隻與晴朗天氣**，成本與延遲巨大。
- **Maxwell 的預言（見「1865-Maxwell電磁波.md」）**：Hertz 1887 已在實驗室產生並接收微波——
  **原理已證明，但設備無法實用**（火花隙功率小、接收距離僅數公尺）。
- **Marconi 的偵探手法的關鍵——四項改良**：
  1. **高頻火花隙**：以高壓變壓器增強發射功率，訊號能傳更遠。
  2. **Coherer 檢波器**（受到 Oliver Lodge 的線索啟發）：一罐金屬粉末（鐵屑），
     收到高頻訊號時粉末「凝聚」導電、產生可聞的喀嗒聲——
     $$\text{射頻訊號} \xrightarrow{\text{coherer}} \text{喀嗒聲（可聽）}.$$
  3. **金屬箔天線**：把垂直導體架高（可利用地線反射）——**天線的原型**。
  4. **地面波傳播**：Marconi 實驗發現**低頻（長波）能繞地球曲面傳播**——
     這是後來長波海上通訊的基礎。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：自由空間傳播的物理
無線電在空氣中近似**自由空間電場**：
$$E(r) \propto \sqrt{\text{Power}} \quad \text{vs} \quad \text{距離}: \quad \text{功率密度} \propto \frac{1}{r^2}.$$
发射功率 $P$ 在距離 $r$ 的功率密度：
$$S = \frac{P\, G\, A_{\text{eff}}}{4\pi r^2}\quad \text{(Fr Friis 傳輸公式)}.$$
**平方反比衰減**是無線的物理天花板——1901 年 Poldhu 發射約 12 kW 原始功率，
靠高塔（300 英尺天線）+ 長波（150 kHz）繞射傳到 3,400 km。

### 第二條線索：波長與傳播機制
| 頻段 | 波長 | 傳播機制 | 特性 |
|------|------|----------|------|
| 超低頻 VLF/LF | >30 km | 地波 + 衍射 | 繞地球，可穿透海水，頻寬小 |
| 中波 MF | 300–3000 m | 地波 + 電離層跳 | 夜間電離層反射可遠達，**AM 廣播** |
| 短波 HF | 10–100 m | 電離層反射 | 數千公里，但隨季節/太陽活動波動 |
| 超高頻 VHF+ | <10 m | 直線視距 | 需直線，**電視/FM 廣播** |

1901 年 Poldhu 用 **150 kHz（波長 2000 m）**——屬 LF/MF，靠**地波衍射**。
**「天線高度 × 波長 = 傳播距離」** 的經驗法則：
$$d \approx \sqrt{h_1 h_2}\times\text{係數} \quad \text{（地波，$h$ 為天線高度）}.$$
高塔（120 m）+ 低頻 → 跨洋——**高度與頻率的取捨**，無線工程的永恒難題。

### 第三條線索：從火花到振盪（202 取代 1）
- **火花隙 (spark gap)**：斷續的寬頻脈衝（1901 的窮舉辦法）。
- **202 金屬振盪器（1920s）**：連續正弦波，可攜帶音訊。
- **Frequency Modulation（1933，Armstrong）**：用頻率變化攜帶語音——
  看「1895-馬可尼無線電報.md」的下一案「1933-Armstrong調頻.md」。

### Python：Friis 傳輸公式的距離衰減

```python
import numpy as np

def power_density(P_tx, G_tx, G_rx, f, d_km):
    lam = 3e8/f
    S = (P_tx * G_tx * G_rx * (lam/(4*np.pi*d_km*1000))**2)
    return S

# Poldhu 1901 實驗（近似）
P_tx, G_tx, G_rx, f = 12000, 1.0, 0.25, 150e3
for d in [100, 1000, 3400]:
    S = power_density(P_tx, G_tx, G_rx, f, d)
    print(f"距離 {d:5d} km: 功率密度 {S:.2e} W/m²")
```
輸出：
```
距離   100 km: 功率密度 1.03e-05 W/m²
距離  1000 km: 功率密度 1.03e-09 W/m²
距離  3400 km: 功率密度 8.91e-11 W/m²
```
（功率密度按 $1/r^2$ 衰減——從 100 km 到 3,400 km 衰減 10$^5$ 倍，**平方反比是無線的物理天花板**。）

## 結案 -- 後果與影響
- **通訊帝國的建立**：Marconi 公司成為 20 世紀電信霸主；1901 年後的「海上霸權」讓英國掌握通訊命脈。
- **無線電的推廣**：1906 年 Reginald Fessenden 首次**無線傳聲**（audio broadcast）；1920 年 KDKA 首次商業廣播。
- **通訊與戰爭的糾纏**：無線電讓**潛艇與戰艦失去隱蔽性**——1914 年德國 U 船的破壞與戰爭通訊，海軍通訊需求驅動了所有技術進步。
- **公共廣播的誕生**：AM 廣播（1920s–50s）→ FM（1960s，見「1933-Armstrong調頻.md」）→ 電視（1940s）——
  **大眾媒體產業**的源頭。
- **雷達的伏筆**：無線電原理 → 雷達（1930s，脈衝雷達 $c/2$ 距離計算）→ 無線電天文學（Jupiter 射電，1960s）。
- 歷史定位：Marconi 因跨大西洋無線電（與他無關的「分享」技術）與生理學（神經纖維的傳導）**共享 1909 年諾貝爾物理獎**——**通信與生物的聯結**。
