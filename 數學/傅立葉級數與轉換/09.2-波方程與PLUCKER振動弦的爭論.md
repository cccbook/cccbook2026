# 9.2 波方程與弦振動爭論

## 本章導言

1.2 節回顧了 1746–1790 年的**弦振動論戰**（d'Alembert、Euler、Bernoulli、Lagrange）；本節回到 PDE 的技術層面，把波方程解個徹底：**d'Alembert 公式**（波傳播）、**Bernoulli–Fourier 級數解**（模態疊加）、兩者的**等價性證明**（爭論的數學裁決）、特徵線與有限傳播速度、以及邊界/阻尼/非線性的現代延伸。波方程是雙曲方程的 prototype，與 9.1 節熱方程（拋物型）形成「傳播 vs. 擴散」的宇宙兩極——**兩者的對照表是本書 PDE 部分的心智地圖**。

### 波方程與 d'Alembert 公式

**方程**： $u_{tt} = c^2 u_{xx}$ （ $c$ = 波速，由張力與密度決定： $c = \sqrt{T/\rho}$ ，弦論之父 Pythagoras 與 Mersenne 的經驗、1746 年被 d'Alembert 公式化）。

**d'Alembert 通解（1746/1747）**：令 $r = x - ct$ 、 $s = x + ct$ （**特徵座標**），方程化為 $u_{rs} = 0$ ——通解

$$
u(x, t) = \phi(x - ct) + \psi(x + ct),
$$

**兩個任意函數**：右行波 + 左行波，**形狀不變、速度恆定**。這是 PDE 史上第一個通解——**特徵線 $x \pm ct = \text{const}$ 是資訊的行進路線**。

**初始值問題**： $u(x,0) = f(x)$ 、 $u_t(x,0) = v(x)$ 給出 **d'Alembert 公式**：

$$
u(x,t) = \frac{f(x - ct) + f(x + ct)}{2} + \frac{1}{2c}\int_{x-ct}^{x+ct}v(s)\,ds.
$$

**直接讀出的三條性質**：（1）**有限傳播速度**： $u(x,t)$ 只依賴 $[x - ct, x + ct]$ 內的初始資料——**依賴域**； $f$ 的擾動以速度 $c$ 傳播，**走不到的地方永遠不知道**（與熱方程的「瞬時全域」截然對立，9.1 節）；（2）**波形保持**：奇性（ $f$ 的跳躍）沿特徵線**永遠傳播**（ $\phi$ 的跳躍原樣跑）——**雙曲方程不光滑化**；（3）**可逆性**： $t \to -t$ 解仍有效——**雙曲 = 時間可逆**。

### Bernoulli–Fourier 級數解與爭論的裁決

**模態解**（1.2 節 Bernoulli 1753 的立場）：兩端固定的弦（ $u(0,t) = u(L,t) = 0$ ），特徵函數 $\sin\frac{n\pi x}{L}$ 、特徵頻率 $\omega_n = \frac{n\pi c}{L}$ ：

$$
u(x,t) = \sum_{n=1}^{\infty}\left[a_n\cos\omega_n t + b_n\sin\omega_n t\right]\sin\frac{n\pi x}{L}, \qquad
a_n = \frac{2}{L}\int_0^L f\sin\frac{n\pi x}{L}dx,\; b_n = \frac{v_n}{\omega_n}.
$$

**與 d'Alembert 公式等價嗎？**——**是**，這正是爭論的裁決：把 $\sin\frac{n\pi x}{L} = \frac{1}{2i}\left(e^{i\frac{n\pi(x-ct)}{L}} - e^{-i\frac{n\pi(x+ct)}{L}}\right)\cdot(\text{重組})$ 展開，級數可**重組為** $\phi(x - ct) + \psi(x + ct)$ 型，其中 $\phi$ 恰是 $f$ 的**奇 $2L$ 週期延拓**的行波分量。**條件**： $f$ 需 Dirichlet 條件（2.2 節）使級數收斂——**d'Alembert 的「任意函數」在級數語言下被精確化為「Dirichlet 可展開的函數」**。表列裁決：

| 論戰方 | 主張 | 現代裁決 |
|--------|------|----------|
| d'Alembert： $\phi$ 须解析 | 通解需可微 | 太嚴：弱解語言下折線也合法 |
| Euler：任意可畫曲線 | 廣義解合法 | **對**（但當時無語言） |
| Bernoulli：模態疊加萬能 | 級數表示一切 | **方向對**：條件為 Dirichlet 型 |
| Lagrange：離散化極限 | 係數公式對但否認等式 | 計算對、概念保守（1.2 節） |

**更深一層（弱解視角，5.2 節）**：折線初始形狀的解是**弱解**—— $u$ 連續但 $u_{tt}, u_{xx}$ 在角點是分配。**PDE 在分配意義下滿足**——Sobolev/Schwartz 的語言使 Euler 的直觀（可畫曲線合法）獲得兩百年後的公理化。**爭論的終極裁決：雙方都對，前提是分清「經典解」與「弱解」**。

### 振動的譜結構：諧音與泛音

**固有頻率** $\omega_n = n\omega_1$ （ $\omega_1 = \frac{\pi c}{L}$ = 基音）——**諧音系列**：頻率比 $1 : 2 : 3 : \cdots$ 。**這是弦樂器的音色秘密**：撥弦激發整個譜（係數按 1.3 節由撥點決定：撥在 $\frac{L}{p}$ 處則第 $p$ 諧音係數為零——**撥弦點不發出其倍數節點處的音**！）。**Pythagoras 的音程**（ $2:1$ 八度、 $3:2$ 五度）在 $\omega_n$ 的整數比結構中獲得物理根據——**數學音樂學的起源正是弦的譜**。

**對照：桿與膜**。均勻桿（縱振動）同為諧音；**圓膜（鼓面）不是**：特徵頻率由 **Bessel 函數零點** $j_{m,n}$ 決定（ $\omega_{m,n} = c\,j_{m,n}/R$ ， $j_{0,1} = 2.405, j_{1,1} = 3.832, j_{2,1} = 5.136, \ldots$ ）——**非整數比**，故**鼓無固定音高**（8.1 節練習 5(a) 的譜根源）。**「諧音與否」由域的幾何與維數決定**——一維弦的奇蹟（諧音）不可推廣，這條事實在 18 世紀已由 Euler 計算環膜時發現。

### 一個具體例題

**例題 9.2.1**：弦 $L = 1$ 、 $c = 1$ ，初始形狀為**撥弦三角**： $f(x) = 2hx$ （ $0 \le x \le \frac12$ ）、 $2h(1 - x)$ （ $\frac12 \le x \le 1$ ），初速為零。（1）求級數解並指出哪些諧音消失；（2）用 d'Alembert 公式描述 $t = \frac{1}{4}$ 時的波形（行波分離）；（3）兩種描述的等價性檢查。

**解**：

（1）係數： $a_n = \frac{2}{L}\int_0^L f\sin(n\pi x)dx$ 。對三角撥弦（經典計算）：

$$
a_n = \frac{8h}{\pi^2}\cdot\frac{\sin\frac{n\pi}{2}}{n^2} \;\Rightarrow\; \text{偶數 } n \text{ 全部為零（對稱性：} f \text{ 關於 } x = \frac12 \text{ 對稱}).
$$

解： $u(x,t) = \frac{8h}{\pi^2}\sum_{k=0}^{\infty}\frac{(-1)^k}{(2k+1)^2}\sin\big((2k+1)\pi x\big)\cos\big((2k+1)\pi t\big)$ 。**音色**：只含奇諧音、幅值 $\frac{1}{n^2}$ 衰減——**柔和的音色**（撥在 $\frac12$ 處：第 2、4、6 諧音的節點恰在撥點，係數為零——1.3 節對稱性 + 節點消音的雙重解讀）。

（2） $t = \frac{1}{4}$ ：右行波 $u(x, \frac14) = \frac{\tilde f(x - \frac14) + \tilde f(x + \frac14)}{2}$ （ $\tilde f$ = 奇 $2L$ 週期延拓，初速零）。**行波分離圖像**：初始三角剖半、兩半反向奔跑——在 $t = \frac14$ 時，原三角已分裂為兩個「半高反向平台」相背移動，中段呈現由兩個截斷三角組成的複合波形。**有限速度的直觀**： $x = 0.9$ 處（距撥點 0.4）在 $t < 0.4$ 時**完全靜止**——擾動尚未到達。

（3）等價性：級數解（1）在每個點收斂到（2）的行波和（Dirichlet 定理 + 角點取中點值 $\frac{h}{2}$ 型）。**驗證一個點**： $x = \frac12$ 、 $t = 0$ ：級數給 $\sum\frac{(-1)^k 8h/\pi^2}{(2k+1)^2}\sin\frac{(2k+1)\pi}{2} = \frac{8h}{\pi^2}\sum\frac{1}{(2k+1)^2}\cdot(\pm1) = h$ （Catlan 常數型級數 $= \frac{\pi^2 h}{8}$ ）——等於 $f(\frac12) = h$ ✓。**兩種語言、同一個解**——1746–1753 的論戰在現代符號下 10 分鐘講完：**數學的進步之一，就是讓昨日的戰爭變成今日的習題**。

### 歷史啟示

- **爭論的裁決需要兩個新概念**：「可畫曲線」（函數概念擴張）與「弱解」（分配導數）。**PDE 的歷史就是「解」的概念不斷擴張的歷史**：經典解 → 弱解 → 黏性解 → 分配解——每級擴張都放寬一類「物理上顯然合法」的解。
- **有限速度的深刻性**：特徵線把因果結構寫進幾何——**相對論的光錐是 $c = 1$ 的特徵線結構**（Minkowski 1908 明確借用雙曲方程的幾何語言）。**波方程是時空因果律的數學原型**。
- **譜結構即音色**：模態分析把「音質」變成係數表——從 Mersenne（1636）的經驗定律到今日的模態測試（7.1 節），**樂器學 = 特徵值工程**。

## 進階研讀：波方程的五個深化場景

**場景一：Huygens 原理與維數奇蹟**。三維波方程的基本解**嚴格集中在光錐上**（ $u = \frac{\delta(r - ct)}{r}$ 型）——**擾動有清晰的前沿與後沿**（Huygens 原理，Poisson 1819 的嚴格化）；二維**沒有**（解在光錐內部持續——**水波有尾跡**，石子入水漣漪久久不散！）。**Hadamard 的分類**：Huygens 原理成立的維數是**偶數維的例外**（3、5、7…奇數空間維成立）——**「為什麼我們的世界（3 維）可以清晰傳話」**的數學根據；二維世界（Flatland）的通訊將永遠拖尾。

**場景二：特徵線與雙曲守恆律**。非線性波 $u_t + f(u)_x = 0$ （交通流、淺水）：特徵線**可能相交** → 解破裂 → **激波**（shock）誕生——弱解 + Rankine–Hugoniot 條件（5.2 節分配語言）+ **熵條件**（選物理解）。**Burgers 方程** $u_t + uu_x = \nu u_{xx}$ ：黏性使激波光滑化——**雙曲 + 拋物的混合血統**。**線性波方程的「永遠友好」在非線性處終結**；激波捕捉數值格式（Godunov、WENO）是計算流體的核心戰場。

**場景三：邊界控制與振盪模態**。兩端固定的弦的**可控制性**：能否用一端的驅動把任意初始狀態歸零？答案是肯定的（**Russell 1978 開創的一維波控制理論**：在 $\frac{2L}{c}$ 時間內精確控制）——**可控性用特徵線的「時空金字塔」論證**。應用：撓性衛星、吊橋、機器人柔性臂的振動主動抑制。**PDE 控制是現代工程數學的活躍前線**。

**場景四：Klein–Gordon 與相對論波**。 $u_{tt} - c^2u_{xx} + \omega_0^2 u = 0$ ：色散關係 $\omega^2 = c^2k^2 + \omega_0^2$ ——**相速度 ≠ 群速度**（ $\frac{\omega}{k}$ vs. $\frac{d\omega}{dk}$ ）。**電磁波在波導/等離子體、量子相對論波**都是此型。**「無色散的弦是特例；色散是常態」**——群速度概念（Stokes 1876、Rayleigh）是時頻思想（第 8 章）的 19 世紀前哨。

**場景五：數值波動的 CFL 與吸收邊界**。顯式差分的穩定性條件 **CFL**（1928）： $c\frac{\Delta t}{\Delta x} \le 1$ ——**數值資訊的速度必須 ≥ 物理波速**（否則因果結構崩壞、解爆炸）。**吸收邊界**（Mur 1981、PML Berenger 1994）：計算域必須有限，邊界要「不反射」——PML 以複座標拉伸實現**完美吸收**，是 FDTD 電磁模擬（手機天線設計、雷達截面計算）的標配。**「邊界處理 = 9.1 節場景二對稱化技術的數值版」**——理論與數值在邊界處再度握手。

### 補充：Daniel Bernoulli 的音樂背景與 Euler 的計算

**Daniel Bernoulli（1700–1782）** 生於 Groningen（Bernoulli 家族數學王朝），醫學博士（植物呼吸的力學），聖彼得堡院士（1725–33，與 Euler 同事），後 Basel 教授。他 1753 年的模態疊加主張有**聲學的職業根基**：他把弦振動視為「無窮多個獨立振子的和」，這在力學上是**疊加原理的首次大規模宣言**（後來成為線性系統的公理，7.1 節）。**Euler 的計算貢獻**：1755 年他系統計算了環膜與矩形膜的特徵頻率（用三角函數），確認**膜非諧音**——這件事被他當作反駁 Bernoulli 的武器（「連矩形膜都無法諧音表示！」），卻不知道自己算的正是**一般正交展開**的第一批例子（1.3 節 Bessel/Legendre 的先聲）。**論戰雙方都在生產未來理論的零件**——科學爭議的建設性往往在半世紀後結算。

### 名詞速查表（本節出現的核心術語）

- **波方程**： $u_{tt} = c^2u_{xx}$ ；雙曲型 prototype。

- **特徵線**： $x \pm ct =$ const；資訊的行進路線。

- **諧音系列**： $\omega_n = n\omega_1$ ；弦的譜奇蹟。
- **節點 / 撥點消音**：撥點處的節點模態不激發。
- **弱解**：分配意義滿足 PDE；折線解的合法身分。
- **Huygens 原理**：3 維波的清晰前沿（奇數維專利）。
- **Rankine–Hugoniot / 熵條件**：非線性激波的弱解與選擇。
- **CFL 條件**： $c\Delta t \le \Delta x$ ；數值因果律。
- **PML**：完美匹配層；計算域的吸收邊界。
- **色散關係 / 群速度**： $\omega(k)$ 與 $\frac{d\omega}{dk}$ 。

### 深化問答三則

**問：為什麼弦有諧音而鼓沒有？**
答：一維區間的特徵值 $n^2$ （ $n$ 連續整數平方）；二維域的特徵值由 Bessel 零點/域幾何決定，**無法排成整數比**。**諧音是低維 + 可分離幾何的偶然禮物**。音樂史對此的依賴（旋律理論建築在諧音比上）是文明的幸運——若人類的耳朵先接觸的是鼓，音樂理論將完全是另一套數學。

**問：d'Alembert 與 Bernoulli 的解「等價」，那論戰還有意義嗎？**
答：有意義——**等價性本身就是他們無法證明的東西**（需要收斂理論 + 函數概念）。論戰逼出了三個未來概念：任意函數、正交展開、弱解。**「誰對」的問題促使概念誕生；概念誕生後，誰對變得不再重要**——這是科學論戰的最優結局。

**問：波方程在什麼意義下是「最基本」的方程？**
答：三個意義。（1）**結構**：二階雙曲 = 有限速度因果律的最簡模型；（2）**物理**：電磁、聲、彈性、線性化流體、（虛時間）量子——全部以其為線性骨架；（3）**數學**：雙曲型理論（特徵、弱解、數值格式）都以它為試金石。**熱方程寫「歷史」（不可逆、遺忘），波方程寫「地理」（可逆、定位）**——兩者合起來是本書 9 章的宇宙觀。
