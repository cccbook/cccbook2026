# 5.3 分配的傅立葉轉換

## 本章導言

經典傅立葉轉換（第 4 章）有明顯的覆蓋缺口：常數函數 $1$ 的轉換是什麼？純正弦 $\sin\omega_0 t$ ？Dirac 梳？——它們**不可積**，經典積分定義全部失效，但它們是工程中最常見的訊號（直流分量、載波、取樣脈衝列）！本章用緩增分配空間 $\mathcal{S}'$ 修復一切：**分配的傅立葉轉換**把 $\delta \leftrightarrow 1$ 、梳 $\leftrightarrow$ 梳納入同一定義，使「任何合理訊號都有譜」成為定理。本節是第 5 章的收官，也是第 6 章（取樣與 DFT）的技術地基——取樣定理的證明將完全建立在 Dirac 梳的譜性質上。

### 定義：用對偶把轉換搬進分配

**出發點**：對「好函數」 $f$ （Schwartz 空間 $\mathcal{S}$ ），經典轉換滿足一條**對偶恆等式**（Fubini 換序可得）：

$$
\int \hat f(\omega)\,\varphi(\omega)\,d\omega = \int f(t)\,\hat\varphi(t)\,dt \quad(\text{按本書常數約定，實際有 } 2\pi \text{ 因子的對稱安排}),
$$

精確地（本書約定 $\hat f(\omega) = \int f e^{-i\omega t}dt$ 、 $f(t) = \frac{1}{2\pi}\int\hat f e^{i\omega t}d\omega$ ）：

$$
\langle \hat T, \varphi\rangle \equiv \langle T, \hat\varphi\rangle \cdot(\text{含 } 2\pi \text{ 的對稱常數：取 } \langle\hat T,\varphi\rangle = \langle T, \hat\varphi\rangle \text{ 並在 } \delta\text{ 的例子中校正}).
$$

**關鍵的事實**： $\mathcal{S}$ 在傅立葉轉換下不變（4.2 節場景三：微分/平移性質在 $\mathcal{S}$ 內封閉），所以「對每個緩增分配 $T \in \mathcal{S}'$ ，定義 $\hat T$ 為 $\langle\hat T, \varphi\rangle = \langle T, \hat\varphi\rangle$ （配合常數約定）」是**良定義**的，且 $\hat T \in \mathcal{S}'$ 。**分配的傅立葉轉換 = 經典轉換的對偶搬運**——定義本身無積分、無極限，只有「把轉換推向檢驗函數一側」。這又是 Schwartz 範式：**新對象的性質 = 舊對象的性質經對偶傳播**。

由此，第 4 章性質表**逐條無條件化**：微分（ $\widehat{T'} = i\omega\hat T$ ）、平移、縮放、捲積、Plancherel 型能量公式（在合適子空間）——**整張表對一切 $\mathcal{S}'$ 成立**。經典理論的「例外情況」（常數、階躍、脈衝）不再是例外。

### 核心對照表：分配的譜

| 時域 | 頻域 | 說明 |
|------|------|------|
| $\delta(t)$ | $1$ | 衝擊 = 白譜（全頻率等幅） |
| $1$ | $2\pi\,\delta(\omega)$ | 直流 = 零頻單線 |
| $e^{i\omega_0 t}$ | $2\pi\,\delta(\omega - \omega_0)$ | 純音 = 載頻單線 |
| $\cos\omega_0 t$ | $\pi[\delta(\omega - \omega_0) + \delta(\omega + \omega_0)]$ | 實餘弦 = 對稱雙線 |
| $\sin\omega_0 t$ | $\frac{\pi}{i}[\delta(\omega - \omega_0) - \delta(\omega + \omega_0)]$ | 實正弦 = 反對稱雙線 |
| $\mathrm{sgn}(t)$ | $\frac{2}{i\omega}$ （主值） | 符號函數 = 有理譜 |
| $u(t)$ | $\pi\delta(\omega) + \frac{1}{i\omega}$ | 階躍 = 直流 + 有理尾巴 |
| $\mathrm{pv}\frac{1}{\pi t}$ | $-i\,\mathrm{sgn}(\omega)$ | **Hilbert 變換核**（7.3 節） |
| $\text{III}_T(t) = \sum\delta(t - nT)$ | $\frac{2\pi}{T}\sum\delta\!\left(\omega - \frac{2\pi k}{T}\right)$ | **梳的自對偶**：梳 ↔ 梳 |

**兩條最核心的驗證**：

- ** $\widehat{\delta} = 1$ **： $\langle\hat\delta, \varphi\rangle = \langle\delta, \hat\varphi\rangle = \hat\varphi(0) = \int\varphi(\omega)d\omega$ （因 $\hat\varphi(0) = \int\varphi$ ）——即 $\hat\delta$ 是常數函數 $1$ 的分配。**物理意義：脈衝的能量均勻灑在所有頻率**——白雜訊的定義譜（7.1 節）。
- ** $\widehat{1} = 2\pi\delta$ **： $\langle\hat 1, \varphi\rangle = \langle 1, \hat\varphi\rangle = \int\hat\varphi(\omega)d\omega = 2\pi\varphi(0)$ （反演公式在 $t = 0$ ！）。**直流只在零頻**。兩者互為傅立葉對（對偶原理的分配版）。

**Dirac 梳的自對偶（Poisson 求和的分配形式）**： $\widehat{\text{III}_T} = \frac{2\pi}{T}\text{III}_{2\pi/T}$ 。證明骨架：兩邊都是週期分配，在基本胞腔上用級數展開（ $\text{III}_T$ 的傅立葉**級數**展開恰為 $\frac{1}{T}\sum_k e^{ik\frac{2\pi t}{T}}$ ）與逐項轉換。**取樣定理的一號引擎**：梳的譜還是梳（頻率間距 $\frac{2\pi}{T}$ = 取樣率的倒數）。

### 一個具體例題

**例題 5.3.1**：用分配的傅立葉轉換做三件事：（1）計算方波 $f(t) = \mathrm{sgn}(\sin t)$ 的譜（分配語言）並與第 2 章級數對照；（2）證明 Hilbert 變換 $\mathcal{H}f = \mathrm{pv}\frac{1}{\pi t} * f$ 的譜效果是 $-i\,\mathrm{sgn}(\omega)\hat f(\omega)$ ——**相位移 $90°$ 濾波器**；（3）由此解釋「解析訊號」構造（7.3 節 AM 解調的標準工具）。

**解**：

（1）方波是週期函數，其傅立葉**級數**為 $\frac{4}{\pi}\sum_{k\ge0}\frac{\sin(2k+1)t}{2k+1}$ （第 2 章）。分配意義逐項轉換（週期分配的譜 = 級數譜的 $\delta$ 加權和）：

$$
\hat f(\omega) = \frac{4}{\pi}\sum_{k\ge0}\frac{1}{2k+1}\cdot\frac{\pi}{i}\left[\delta\!\left(\omega - (2k+1)\right) - \delta\!\left(\omega + (2k+1)\right)\right].
$$

**譜是離散脈衝列**：權重 $\frac{4}{2k+1}\cdot\frac{1}{i}$ 型，只落在奇頻率。對照級數理論：級數的係數 $b_n = \frac{4}{\pi n}$ （奇數 $n$ ）——**同一資訊的兩種記帳法**（級數帳本 vs. 分配譜帳本），內容完全一致。這示範了分配理論的統一力：**級數（離散譜）與轉換（連續譜）的鴻溝被「 $\delta$ 權重」填平**。

（2）由上表 $\widehat{\mathrm{pv}\frac{1}{\pi t}} = -i\,\mathrm{sgn}(\omega)$ ，捲積定理（分配版）：

$$
\widehat{\mathcal{H}f}(\omega) = -i\,\mathrm{sgn}(\omega)\,\hat f(\omega).
$$

對每個頻率成分：正頻率乘 $-i$ （相位移 $-90°$ ）、負頻率乘 $+i$ （移 $+90°$ ）、直流乘 0（消滅）。**Hilbert 變換 = 全通、恆定 $90°$ 相移、消直流的濾波器**。注意核 $\frac{1}{\pi t}$ 不可積（ $\frac1t$ 奇性）——經典捲積定義失效，需主值 + 分配框架才能成為合法濾波器：**這是分配理論「救活一個工程濾波器」的直接案例**。

（3）**解析訊號** $z = f + i\,\mathcal{H}f$ ：其譜 $\hat z = \hat f + i(-i\,\mathrm{sgn})\hat f = \hat f\big(1 + \mathrm{sgn}(\omega)\big)$ = **只保留非負頻率**（幅值加倍於正頻、直流減半）。**時域複值化 = 頻域單邊化**：複訊號的負頻譜為零（共軛對稱被打破），於是包絡、瞬時頻率、瞬時相位可以唯一定義——AM 通訊的解調（7.3 節）、音訊處理的移頻、地震學的包絡分析都用它。**分配譜讓「解析」這個形容詞變成一行濾波算式**。

### 歷史啟示

- **擴張中的兼容性設計**：分配的傅立葉轉換在好函數上**還原**經典轉換（對偶定義的必然），同時把例外對象收編為普通成員。**「新理論含舊理論為真子集」是成功擴張的標誌**（Lebesgue 對 Riemann、Hilbert 對 Euclid 同款）。
- **白雜訊的數學身份**： $\widehat\delta = 1$ 宣告「脈衝 = 全頻域平坦譜」。這句話使「白雜訊」從比喻變成可計算的對象（寬平穩過程 + 譜測度常數，Wiener 1930；廣義隨機過程，Gelfand 1955）。**隨機訊號理論是分配理論的第一個跨學科客戶**。
- **演算的完整性勝過對象的完备性**：Schwartz 沒有把分配定義成「某種更一般的函數」（如超實數路線），而是定義成「演算封閉的泛函空間」。**先保證運算規則，對象的形而上地位可以懸置**——Leibniz 的實用主義（1.1 節）在 20 世紀的嚴格復刻。

## 練習

1. 用對偶定義驗證 $\widehat{e^{i\omega_0 t}} = 2\pi\delta(\omega - \omega_0)$ ，並用平移性質由 $\widehat{1} = 2\pi\delta$ 導出。
2. 計算 $\cos\omega_0 t$ 與 $\sin\omega_0 t$ 的譜，並畫出（描述）幅值譜與相位譜；說明兩者相位譜的差別（ $90°$ ）正是「餘弦 vs. 正弦」的全部資訊。
3. 驗證分配捲積 $\delta' * f = f'$ （ $f$ 光滑），並由此解 $T' = \delta$ 的分配解（答： $u + c$ ， $u$ 為階躍）。
4. 用本節表計算半波整流訊號 $f(t) = \max(\sin t, 0)$ 的譜的離散成分（提示： $\max(\sin t,0) = \frac{\sin t + |\sin t|}{2}$ ， $|\sin t|$ 的級數已知），驗證直流分量為 $\frac{1}{\pi}$ 、基波 $\frac12$ 、偶次諧波 $\frac{2}{\pi(1-4n^2)}$ 型。
5. 思考題：Dirac 梳取樣 $f\cdot\text{III}_T$ 的譜是 $\frac{1}{T}\sum_k \hat f\!\left(\omega - \frac{2\pi k}{T}\right)$ （頻譜週期複製）。用此式解釋：（a）為什麼取樣後訊號自動變成「週期頻譜」；（b）混疊（aliasing）發生的條件；（c）為第 6.1 節的 Nyquist 率鋪路。

## 進階研讀：分配譜的五個深化場景

**場景一：主值與 Hadamard 有限部分**。 $\mathrm{pv}\frac{1}{t}$ 之外還有 $\mathrm{fp}\frac{1}{t^2}$ （Hadamard 有限部分）、 $\mathrm{fp}\frac{1}{t^n}$ ——**奇性越強的核，越需要「扣除發散部分」的正規化**。它們的譜是 $\omega\,\mathrm{sgn}(\omega)$ 型多項式；**核的奇性階 ↔ 譜的多項式增長階**——又一條價碼表（2.1 節）的分配版。偏微分方程的基本解（如 $\Delta^{-1}$ 、雙調和算子 $\Delta^2$ ）就住在這個家族裡。

**場景二：基本解的譜公式**。常係數算子 $P(D)$ 的基本解在譜域是 $\hat E(\omega) = \frac{1}{P(i\omega)}$ ——**除以符號多項式**！但 $P(i\omega)$ 有實零點時 $\frac1{P}$ 是分配意義的除法（需奇性正規化）。波算子 $\partial_t^2 - c^2\partial_x^2$ 的基本解在光錐上集中（Huygens 原理，3 維時嚴格成立）——**PDE 的因果結構寫在基本解的支撐上**（9.2 節波方程的分配解法）。

**場景三：週期分配與 Fourier 級數的統一**。週期分配的譜 = 離散 $\delta$ 列（係數為 $c_n$ 的 $2\pi$ 週期複製）；反之任何 $\delta$ 列譜的分配，其反變換是週期分配。**「週期性 $\Leftrightarrow$ 譜的離散性」在分配世界是嚴格的雙向定理**——第 2 章與第 4 章的「四象限表」至此獲得完備的數學基礎：四種情況（級數/轉換 × 離散/連續）是同一個 $\mathcal{S}'$ 轉換的特例。

**場景四：白雜訊與 Brown 運動**。Brown 運動 $B_t$ 的「導數」 $\dot B_t$ （白雜訊）不是函數，而是廣義隨機過程：對檢驗函數 $\varphi$ ， $\langle\dot B, \varphi\rangle = -\int B_t\varphi'(t)dt$ 是方差為 $\int\varphi^2$ 的 Gauss 變數——**白雜訊是分配，其譜是常數**。Gelfand 的廣義隨機過程（1955）把這一切公理化；Lévy 的 Brown 運動譜、Kolmogorov 的 $\frac{5}{3}$ 定律（湍流能譜）都以分配譜為語言。**隨機世界的傅立葉分析需要分配，正如確定性世界需要函數**。

**場景五：小波框架的對偶**。小波變換（8.3 節）的重建公式在分配語言下是「連續框架的對偶分解」： $\int\!\!\int \langle f, \psi_{a,b}\rangle\psi^{a,b}\,\frac{da\,db}{a^2} = C_\psi f$ （admissibility 常數 $C_\psi < \infty$ ）。**Calderón 恆等式（1964）先於小波誕生**，正是分配的 Parseval 型公式——小波革命（1984）的種子埋在分配理論的土壤裡。跨章的主線再次浮現：**分配框架是調和分析 1950–1990 所有進展的共同地基**。

### 補充：Lighthill 的一冊小書

英國流體力學家 **M. J. Lighthill（1924–1998）** 在 1958 年出版《Fourier Analysis and Generalised Functions》，用 80 頁把分配的傅立葉轉換寫成工程師與物理學家可用的教科書（他以氣動聲學聞名——飛機噪聲理論）。此書與 Schwartz 的兩卷巨著形成絕妙對照：**一個是公理系統，一個是使用手冊**。Lighthill 書中反覆演示的正是本節的方法：「把物理訊號表示為分配、用對偶計算譜、最後取好函數極限回收物理意義。」工程教育的傅立葉課程從此有了分配的標準入口。

### 深化問答三則

**問：分配的傅立葉轉換是「新的轉換」還是「舊轉換的推廣」？**
答：**同一個轉換的同一個定義，域變大了**。就像實數冪 $a^x$ 推廣到複數 $a^z$ ：定義精神（連續性 + 指數律）不變，適用對象擴張。判斷「推廣做得對」的標準：在舊對象上還原舊值、在全域保持舊性質（微分、平移、捲積）——分配的 FT 兩者皆滿足。

**問：既然 $\widehat\delta = 1$ ，那「白雜訊經過理想低通」的輸出譜是什麼？**
答：譜 $= 1\cdot\chi_{[-B,B]}$ ——帶限白雜訊；其反變換是 $\frac{\sin Bt}{\pi t}$ 型**隨機過程**（帶限高斯雜訊），相關函數 $r(\tau) = \frac{\sin B\tau}{\pi\tau}$ （Wiener–Khinchin）。**帶限雜訊自動是光滑的**（帶限 ⇒ 解析，4.1 節場景四）——這就是為什麼通訊系統的帶寬限制了雜訊的「粗糙度」，也是取樣定理（6.1）能在雜訊存在時仍給出插值界的原因。

**問：本節與第 2 章「級數」的關係，用一句話？**
答：**週期分配的譜是 $\delta$ 列，係數即傅立葉級數係數**——第 2 章的每一條理論（Dirichlet、Parseval、Fejér）都是本節分配譜理論在「週期 + 好函數」子空間的精細版。傅立葉分析在 $\mathcal{S}'$ 完成大統一：**級數與轉換是同一變換在不同支撐上的兩種記帳**。
