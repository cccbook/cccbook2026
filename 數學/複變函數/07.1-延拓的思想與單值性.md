# 7.1 延拓的思想與單值性

## 本章導言

解析函數有一條實變函數完全沒有的性質：**一個小片段決定整體**。 $\log z$ 在實軸上取值後，可以「沿著路徑走」把定義域一路擴充到複平面的更多地方——這就是**解析延拓**。但延拓會遇到兩種命運：路徑不同、結果不同（多值性），或撞上不可逾越的牆（自然邊界）。本節建立延拓的正式理論（函數芽、鏈式延拓、單值性定理）、與兩個經典案例： $\Gamma$ 函數的延拓與 Riemann 的 $\zeta$ 延拓（8.3 篂的前奏）。

### 函數芽與延拓的正式定義

**函數芽（germ）**：在點 $a$ 附近的解析函數（取定義於某鄰域者，等價類）——由 Taylor 級數（4.1）唯一編碼。記芽為 $(f, a)$ 。

**延拓鏈**： $(f_0, a_0) \to (f_1, a_1) \to \cdots \to (f_n, a_n)$ ，其中 $f_{k+1}$ 是 $f_k$ 在相鄰圓盤重疊區上的延拓（兩芽在交集上一致——由單位定理 4.3 篂，一致即同一芽）。

**解析延拓**：芽 $(f, a)$ 的**全部**經由一切路徑的延拓系統，稱為（Weierstrass 意義的）**解析函數**。

**兩條鐵律**：

1. **延拓唯一**：沿給定路徑的延拓結果唯一（Taylor 展開唯一性 + 重疊區單位定理）。**路徑定了，終點芽就定了**。
2. **局部決定全域**：芽在一個任意小的圓盤上的值決定整個延拓系統——**解析函數是「全息」的**。

**單值性問題**：沿不同路徑延到同一點 $b$ ，可能得到**不同芽**（例： $\log$ 沿繞 0 與不繞 0 的路徑）。什麼條件保證「路徑無關」？——**單值性定理**（見下）。

### 單值性定理（Monodromy Theorem）

**定理**：設 $D$ 單連通， $(f, a)$ 是 $D$ 內的芽，且**沿 $D$ 內一切路徑皆可延拓**。則延拓結果在 $D$ 上拼成單值解析函數。

**證明思想**：兩條路徑 $\gamma_0, \gamma_1$ （同起終）在 $D$ 內同倫（單連通！）；對同倫參數 $t$ ，考慮「沿 $\gamma_t$ 的延拓」；由**延拓的局部穩定性**（小擾動路徑不改變終點芽——因為覆蓋同倫的提升唯一性思想）， $t \mapsto$ 終點芽連續；芽集是離散的（同一點的芽由 Taylor 係數離散編碼）——連續 + 離散 ⇒ 恆常。∎

**定理的威力**：**「可延拓 + 單連通 = 單值」**。多值性是「路徑不同倫」的症狀—— $\log z$ 在 $\mathbb{C}\setminus\{0\}$ （非單連通）多值；在任何不含 0 的單連通域（如去掉負實軸的平面）單值。**7.3 篂的分支切割、7.2 篂的 Riemann 面**，都是對這條定理的工程化與幾何化。

### 延拓的障礙

- **奇點**：極點/本性奇點/支點（branch point）是路徑的牆（繞行可能改變芽——支點）。
- **自然邊界**：Hadamard 間隙定理（4.1 篂場景一）—— $\sum z^{2^n}$ 在 $|z| = 1$ 上奇點稠密，**任何點都延不出去**。延拓的「地圖」可以比收斂圓大得多，也可能一格不讓。
- **解析阻礙的分類**：芽的延拓系統 $\mathcal{F}$ 的「可達點集」是開的；邊界點分為孤立奇點（可分類，4.3 篂）與自然邊界（不可分類）。**「函數的定義域」本身是延拓理論的產物**。

### 經典案例一： $\Gamma$ 函數的延拓

Euler 積分 $\Gamma(s) = \int_0^\infty e^{-t}t^{s-1}dt$ 只在 $\operatorname{Re} s > 0$ 收斂。**延拓**：分部積分 $\Gamma(s+1) = s\Gamma(s)$ 反覆用，或以 Weierstrass 乘積（8.1 篂）

$$
\frac{1}{\Gamma(s)} = s e^{\gamma s}\prod_{n=1}^\infty\left(1 + \frac{s}{n}\right)e^{-s/n}
$$

直接定義**全平面**的半純函數：極點在 $s = 0, -1, -2, \ldots$ ，留數 $\frac{(-1)^n}{n!}$ 。**積分定義 → 函數方程 → 乘積延拓**：同一函數的三副面孔，後兩副是前一副的「延拓產物」。 $\Gamma$ 的延拓是「實積分函數必須複化」的元範例： $\Gamma(\frac12) = \sqrt{\pi}$ 、 $\Gamma$ 在負半軸的行為（階乘往回走）只有複變語言能講。

### 經典案例二： $\zeta$ 的延拓與函數方程（預告 8.3 篂）

Riemann 1859 年論文《論小於給定值的素數個數》：Euler 級數 $\zeta(s) = \sum n^{-s}$ （ $\operatorname{Re} s > 1$ ）被延拓到全平面（除 $s = 1$ 單極點），並滿足**函數方程**

$$
\zeta(s) = 2^s\pi^{s-1}\sin\frac{\pi s}{2}\,\Gamma(1-s)\,\zeta(1-s).
$$

延拓的技術（Riemann 原法）：以 $\frac{1}{e^t - 1}$ 的積分表示 + 分部積分的週期鏈；現代法： Mellin 變換 + $\theta$ 函數的模性。**延拓不是技術花絮，是定理的發動機**：素數定理（1896）需要 $\zeta$ 在 $\operatorname{Re} s \ge 1$ 無零點——這條資訊只存在於**延拓後**的函數上。**「延拓即發現」**：級數沒說的話，延拓後的函數說了。

### 單值性與恆等定理的分工

| 原理 | 內容 | 角色 |
|------|------|------|
| 單位定理（4.3） | 零點有極限點 ⇒ 恆零 | 兩芽在重疊區一致即同芽 |
| 延拓唯一性 | 沿路徑的延拓唯一 | 路徑定、結果定 |
| 單值性定理 | 單連通 + 可延 ⇒ 單值 | 路徑無關的拓撲條件 |
| 解析延拓（全域） | 芽系統 = 解析函數 | Weierstrass 的本體論 |

四條原理構成「局部 → 全域」的階梯：單位定理是原子層、延拓唯一是分子層、單值性是材料層、芽系統是建築層。

### 一個具體例題

**例題 7.1.1**：設 $f(z) = \sum_{n=0}^\infty z^n$ （ $|z| < 1$ ）。(a) 沿路徑延拓 $f$ 到 $z = 2$ （不過 $z = 1$ ），給出延拓芽；(b) 證明 $z = 1$ 是「延拓障礙」但非「函數牆」；(c) 討論沿繞 1 的兩條路徑延到 $z = 2$ 是否一致。

**解**：

(a) $f(z) = \frac{1}{1 - z}$ 在 $|z| < 1$ 。這個有理式**就是**延拓：以 $a = \frac12$ 為新中心展開：

$$
f(z) = \frac{1}{1 - z} = \frac{1}{\frac12 - (z - \frac12)} = 2\sum_{n=0}^\infty 2^n\left(z - \frac12\right)^n, \quad \left|z - \frac12\right| < \frac12.
$$

收斂半徑 $\frac12$ （到奇點 $z = 1$ 的距離，4.1 篂）✓。再以 $a = \frac34$ 展開（半徑 $\frac14$ ）、 $a = \frac{9}{10}$ ……逐步逼近 $z = 2$ 側：可延拓到 $\mathbb{C}\setminus\{1\}$ 的**任何點**。 $z = 2$ 處的芽 = $\frac{1}{1-z}$ 在 2 的 Taylor 展開 $= -\sum(z - 2)^n \cdot$ （ $\frac{1}{1-z} = \frac{-1}{1 + (z-2)} = -\sum(-1)^n(z-2)^n$ ， $|z-2| < 1$ ）。

(b) $z = 1$ ： $\frac{1}{1-z}$ 的極點——**延拓障礙**（任何芽鏈不能穿過）。但障礙是「一個點」：繞過它照樣延拓。對照自然邊界（ $|z| = 1$ 稠密奇點的級數）：那是**牆**，一寸不讓。**障礙可以繞，牆不能**。

(c) 到 $z = 2$ 的延拓芽只依賴**同倫類**（單值性定理的逆： $\mathbb{C}\setminus\{1\}$ 的基本群 $\mathbb{Z}$ ）——所有不繞 1 的路徑給同一芽 $\left(\frac{1}{1-z}, 2\right)$ ；**繞 1 的路徑**： $\frac{1}{1-z}$ 是有理函數（單值半純），繞圈的芽回來仍是一樣的——**本函數的 monodromy 平凡**。對照 $\log z$ ：繞 0 一圈芽移 $2\pi i$ 。**有理函數無 monodromy， $\log$ 有**——monodromy 群（7.3 篂）是「延拓的迴聲」的完整記錄。

### 歷史背景：Weierstrass 的延拓綱領

- **1842–1856**：Weierstrass 中學教師時期建立「冪級數 = 函數、延拓 = 函數的存在方式」的綱領（4.1 篂）。他把「解析函數」**定義為**芽的延拓系統——多值性不是缺陷而是本體： $\sqrt z$ 的兩個芽屬於**同一個**解析函數。
- **1884**：Weierstrass 的講義與論文（解析函數論的系統化）出版；「延拓」成為教科書標準章節。
- **1851**：Riemann 的平行路線：延拓 = Riemann 面上的單值函數（7.2 篂）——幾何化。
- **1883–86**：Poincaré、Picard 建立單值性定理的現代形式（覆疊空間語言的先聲）。

**Weierstrass vs. Riemann 的本體論分歧**：Weierstrass：函數 = 芽的代數系統（形式主義）；Riemann：函數 = 曲面上的單值對象（幾何主義）。現代觀點：兩者由**覆疊空間理論**（Poincaré 1895–1904）統一——Riemann 面是芽系統的拓撲實現。**哲學之爭以「兩者皆對」收場**，這是數學史上少見的皆大歡喜。

### 歷史啟示

- **「函數」的定義被延拓改寫**：十八世紀的「函數 = 表達式」到十九世紀的「函數 = 延拓系統」——本體論的升級由技術（冪級數）驅動。
- **障礙即地理**：延拓理論把「函數的定義域」變成可測繪的對象（奇點地圖、自然邊界、monodromy）。**函數有了疆域與國界**。
- **延拓即發現**： $\zeta$ 的延拓創造了素數定理的可能性； $\Gamma$ 的延拓揭開負數階乘。**分析的知識邊界由延拓擴張**。

## 練習

1. 以「換中心展開」延拓 $\sum_{n=0}^\infty z^n$ 的芽到 $z = -2$ ，寫出中間鏈與終點芽。
2. 證明： $\sum_{n=0}^\infty z^{n!}$ 的單位圓是自然邊界（提示：對稠密的根 of unity 點集，證 $\lim_{r\to1^-} f(r\zeta) = \infty$ ）。
3. 對 $f(z) = \log(1 + z)$ ：從芽（在 0，主值）出發沿 $|z| = 1$ （不過 $-1$ ）逆時針一圈延拓，計算回到起點的芽移動量（答案 $2\pi i$ ——支點在 $-1$ 與 $\infty$ ）。
4. 證明單值性定理的「局部穩定性」步驟：若芽沿路徑 $\gamma$ 可延拓，則對充分接近的路徑 $\tilde\gamma$ 終點芽相同。
5. 思考題：Weierstrass 說「 $\sqrt z$ 的兩個芽是一個函數」，Riemann 說「單位圓盤上有兩個函數在曲面上合一」。這兩種說法如何被覆疊空間理論統一？

## 進階研讀：延拓的五個深化場景

**場景一：monodromy 群**。固定基點 $a$ 與芽 $\mathcal{F}_a$ ；基本群 $\pi_1(D, a)$ 作用於芽集（每個圈 → 芽的置換）。**monodromy 群** = 這個作用的像。 $\log$ : $\mathbb{Z}$ （平移 $2\pi i$ ）； $\sqrt z$ : $\mathbb{Z}/2$ （換芽）；超幾何方程： $\mathrm{S}_3$ （Riemann 1857 的計算——monodromy 理論的誕生文獻）。**延拓的「迴聲」是一個群**——這是 7.3 篂分支理論與 Riemann–Hilbert 問題的核心結構。

**場景二：單值化與覆疊空間**。芽系統 $\mathcal{F}$ 天然構成 Riemann 面（芽 + 收斂盤的拓撲）——**Weierstrass 綱領的幾何化身**；這個曲面是 $\mathbb{C}\setminus\{\text{支點}\}$ 的覆疊。覆疊空間理論（Poincaré 1904）說：一切覆疊由基本群的子群分類——**延拓理論 ⇔ 拓撲理論**的等價是十九世紀末數學統一化的樣板。

**場景三：自然邊界的應用面**。Tauber 型冪級數（機率生成函數、組合學母函數）常有單位圓自然邊界——**「母函數不能延拓」**意味著漸近分析必須在邊界上做（singularity analysis 沿自然邊界的「軟」奇點：4.1 場景二）。相反， $\zeta$ 型 Dirichlet 級數的延拓能力正是數論可用複分析的原因——**延拓性是函數的「分析學通行證」**。

**場景四：Borel–Watson 延拓與 Stokes 現象**。漸近級數的 Borel 求和（4.1 篂場景五）沿**不同方向**（arg $z$ ）延拓 Borel 變換，得到**不同**的求和結果（差 $2\pi i$ 的指數小項 $e^{-A/z}$ ）——**Stokes 線**（沿它的解改變指數成分）是延拓理論在漸近分析的化身：物理學的量子隧穿、WKB 連接公式（Airy 函數）以 Stokes 現象為結構。**延拓的方向 = 物理的相選擇**。

**場景五：多複變的 Hartogs 現象**。 $n \ge 2$ ：挖去緊集的域上解析 ⇒ 可延拓過洞（2.2 篂場景三）——**多複變的延拓幾乎總是可能的**（沒有自然邊界於緊集、沒有孤立奇點的延拓障礙）。單複變的「障礙地圖學」在多複變中大片荒漠化，取而代之的是 $CR$ 幾何（邊界的實子流形結構）——**延拓理論的維數對照**是理解複幾何為何分裂為兩門學科的鑰匙。

### 名詞速查表（本節出現的核心術語）

- **函數芽**： $(f, a)$ ，局部解析函數的等價類。
- **解析延拓**：沿路徑的芽鏈延拓；唯一性由單位定理保證。
- **單值性定理**：單連通 + 可延 ⇒ 單值。
- **解析函數（Weierstrass）**：芽的延拓系統。
- **自然邊界**：稠密奇點構成的不可逾越邊界。

- **支點**：繞行改變芽的奇點（如 $\sqrt z$ 於 0）。
- **Stokes 線**：Borel 求和方向依賴的臨界線。

### 深化問答三則

**問：為什麼「沿路徑的延拓唯一」如此重要？**
答：它使「延拓」成為**確定性的程序**而非選擇：給定路徑與起點芽，終點芽被定理鎖死。多值性只出現在「不同路徑」之間——於是「多值」被精確化為「monodromy 非平凡」，而後者是群論對象。**把曖昧的「多值」翻譯成確定的「群作用」**是延拓理論的最大功績。

**問：自然邊界「長什麼樣」？能看見嗎？**
答：能。用 domain coloring 畫 $\sum z^{2^n}$ （4.1 篂場景一的例子）的色相圖：單位圓內圖案規則，圓周處**色彩混沌爆發**——稠密奇點使邊界成為「色相噪聲環」。這是少數可以**直接看見**的抽象定理（Hadamard 1892）。

**問：延拓理論對「定義域」的觀念改變了什麼？**
答：十九世紀前，定義域是「表達式有意義的地方」（被動）；延拓理論後，定義域是「芽系統可達的地方」（主動）——**同一表達式可以有多個合法定義域**（如 $\log$ 的各種切割），函數的「身分」由芽系統決定、不由初遇的公式決定。這種「本體與表示分離」的觀念是現代數學（範疇論的對象/態射分離、表示論）的先聲。
