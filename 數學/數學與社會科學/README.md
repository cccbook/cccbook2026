# 數學與社會科學

一本探討數學如何塑造、並被社會科學塑造的教科書。全書以「前因後果」為主軸：每一個數學工具的誕生，都是為了回應某個真實的社會問題；而每一個社會科學理論的突破，又往往反過來催生新的數學。

## 本書的方法論

每一節都遵循同一個敘事結構：

1. **問題**：當時社會面臨什麼真實困境？
2. **數學**：什麼數學工具被發明出來回應它？
3. **後果**：這個工具如何改變了社會科學？
4. **回饋**：社會科學的反省又如何催生新的數學？
