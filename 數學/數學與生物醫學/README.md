## 本書的主線

1. **數學→生物**：Malthus 的方程啟發達爾文；傅立葉變換使 DNA 可被「看見」；波松分佈裁定突變時機。
2. **生物→數學**：生物變異逼出迴歸與 ANOVA；序列資料催生動態規劃與 HMM 的應用擴張。
3. **雙向閉環**：AlphaFold 中演化統計餵給幾何深度學習，AI 再設計新蛋白——兩者的驅動關係成為對稱的閉環。
