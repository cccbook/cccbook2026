# 0.1 雙螺旋：數學與生物的相互驅動

## 為什麼需要這本書

生物學常被誤認為「描述性」的科學，但過去四百年的歷史顯示相反：**每當生物學遇到新的現象，就逼出一門新的數學；每當新數學誕生，就反過來重寫生物學。**

- Malthus 用一個 $dP/dt = rP$ 讓達爾文「看見」生存鬥爭（1.1）。
- 孟德爾的 3:1 是純機率論，卻要等 35 年才被讀懂（1.2）。
- 沒有傅立葉變換，人類看不見 DNA 的螺旋（4.2）。
- 沒有動態規劃，基因體時代無從開始（4.3、5.2）。
- AlphaFold 用演化統計學會了五十年未解的摺疊密碼（5.3）。

## 本書的分析框架

每一節都用三段式拆解因果：

1. **前因**：什麼樣的生物現象或既有理論的失敗，創造了需求？
2. **構造**：數學工具如何被發明/移植，核心方程與演算法是什麼？
3. **後果**：它如何改變生物學，又如何反饋回數學/計算科學？

三個反覆出現的模式：

| 模式 | 例子 |
|---|---|
| 理論先於觀測 | Schrödinger 預言非週期性晶體（4.1）→ DNA |
| 生物需求催生數學 | 生物變異 → 卡方檢定、ANOVA（3.1、3.2） |
| 方法論跨域遷移 | 語音 HMM → 基因預測（5.1）；動態規劃 → 序列比對（4.3） |

## 閱讀建議

章節間有依賴但可跳讀：第 1 章是機率與代數的入門，第 2 章是微分方程與動力系統，第 3 章是統計推論，第 4–5 章是資訊與計算。若你的目標是理解 AlphaFold，建議按 1.2 → 4.1 → 4.2 → 4.3 → 5.1 → 5.3 的順序，體驗「從豌豆到 AI」的完整因果鏈。
