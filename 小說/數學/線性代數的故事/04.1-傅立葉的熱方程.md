# 4.1 傅立葉的熱方程：把函數看成無窮維向量

## 一個關於熱的問題

1807 年，格勒諾布爾的前任行政官約瑟夫·傅立葉向巴黎科學院提交了一篇論文：固體中的熱傳導如何用數學描述。傅立葉不是職業數學家——他跟著拿破崙遠征埃及，是埃及研究所的祕書，回國後任伊澤爾省省長，管理道路、教育與考古。研究熱傳導，起因相當實際：他關心火藥的冷卻、建築的保暖、冶金爐的溫度控制。

他寫下的偏微分方程，今天被稱為熱方程：

$$\frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2}$$

接著他做了一件驚世駭俗的事：宣稱任意函數都可以展開成三角函數的無窮級數——

$$f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty} \left( a_n \cos nx + b_n \sin nx \right)$$

## 為什麼這是「無窮維向量」？

當時的爭議焦點是「任意函數」四個字。拉格朗日反對：他只承認某些足夠「好」的函數能這樣展開。這場爭論持續了半個世紀，最終逼出分析學的嚴格化。

但換個角度看，傅立葉其實在不知不覺間把線性代數推廣到了無窮維。回想向量：一個三維向量由三個數 $(x, y, z)$ 構成，可寫成基向量的組合 $x\mathbf{e}_1 + y\mathbf{e}_2 + z\mathbf{e}_3$；內積 $\mathbf{u} \cdot \mathbf{v}$ 量出「平行程度」。

現在，把一個區間上的函數 $f$ 想成一個擁有無窮多個分量的向量——每個點 $x$ 上的函數值是一個分量。三角函數族 $\{1, \cos nx, \sin nx\}$ 就是一組「基底」。傅立葉係數

$$a_n = \frac{1}{\pi} \int_{-\pi}^{\pi} f(x) \cos nx \, dx$$

正是 $f$ 在第 $n$ 個基向量方向上的「投影長度」——積分扮演內積的角色。於是：

| 有限維 | 無窮維（函數空間） |
|---|---|
| 分量 $(x_1, \dots, x_n)$ | 函數值 $f(x)$ |
| 基向量 $\mathbf{e}_i$ | 三角函數 $\cos nx, \sin nx$ |
| 內積 $\sum u_i v_i$ | 積分 $\int f g\,dx$ |
| 投影座標 $\mathbf{f}\cdot\mathbf{e}_i$ | 傅立葉係數 $a_n, b_n$ |

「函數是無窮維空間中的向量」——這個想法是傅立葉級數最深刻的遺產，比任何一條公式都重要。

## 為什麼熱方程需要它？

數學上的理由很漂亮：$\sin nx$、$\cos nx$ 恰好是熱方程的「特徵模式」——它們隨時間演化時形狀不變，只以速率 $e^{-\alpha n^2 t}$ 衰減。$n$ 越大（波紋越細），衰減越快。所以把初溫分佈分解成三角模式後，解就是「每個模式各自指數衰減」。

這就是「特徵值—特徵向量」思想在微分方程中的化身：好的基底讓複雜問題變成一堆獨立的簡單問題。這個策略後來統治了數理物理——波動方程、薛丁格方程、馬克士威方程組的解法，全是同一套思路。

## 從爭議到工業

傅立葉 1822 年出版《熱的解析理論》。他關於「任意函數」的爭議性主張，直接推動了狄利克雷、黎曼對積分與級數的研究，最終導致勒貝格積分（1902）與實分析。可以說：現代分析的嚴格性，是被「熱」逼出來的。

而傅立葉分析的應用史，是一部技術史：十九世紀用於電報訊號與聲學；二十世紀的無線電、抽樣定理、快速傅立葉變換（FFT，1965 年庫利與圖基的演算法，被譽為二十世紀最重要的演算法之一）讓頻譜分析進入所有電子設備；今天的 JPEG 影像壓縮、MP3 音訊、5G 通訊，都是傅立葉思想在不同基底上的變形。

## 歷史迴響

傅立葉自己沒有「向量空間」的語言——那是格拉斯曼先想出、而世界還沒準備好的。要到二十世紀初，兩條線才在希爾伯特那裡交會：無窮維空間終於有了嚴格的幾何。而讓這門學問走上世界舞台的，是一場物理革命。
