# 《數學證明的故事：從泰勒斯的定理到 Lean 裡的黎曼猜想》

> 一本關於「證明」本身的書。從愛琴海的一次提問，到 2026 年 11 月一份 1700 萬行的 Lean 程式碼被社群正式認證，看見推理如何被發明、標准化、再一次重新定義。穿插其中的，是抄本、學會、期刊、戰爭、國家、資本與人。

## 本書的幾條線索

- **線索一：媒介。** 紙草、羊皮紙、紙、印刷機、期刊、程式碼。每一種新的記錄載體，都重新分配了一次「誰能寫、誰能讀、誰能改」。
- **線索二：制度。** 亞歷山大城的圖書館與薪資、君士坦丁堡與巴格達的翻譯廠、法國綜工的競賽制度、洪堡改革後的研究型大學、皇家學會與匿名評審、冷戰的國防資助、今天的基金會與新創公司。
- **線索三：政治與經濟。** 波旁王朝與共和派、拿破崙的工程師、兩次世界大戰與「大腦流失」、數學與戰時密碼、陶哲軒與資本家的億萬捐款。
- **線索四：不可解。** $\sqrt{2}$、化圓為方、五次方程、非歐幾何、集合論的悖論、哥德爾、停機問題、費爾馬大定理，以及 2026 年之前的所有黎曼猜想嘗試。
- **線索五：理解 vs 驗證。** 從「一個理由鏈」到「一個可重放的物件」，中間一而再、再而三地重演過的取捨。

## 關於格式

- 內文使用標準 GitHub Markdown，數學式以 TeX 書寫（行內用 `$...$`，獨立段落用 `$$...$$`），流程圖使用 mermaid。
- 本書所述的史實均以現存文獻與可查證的記錄為依據；對有爭議之處，書中會標明爭議所在。
- 2026 年 11 月的段落，資料取自當事人的公開備忘錄、Lean 與 Mathlib 社群的聯合聲明，以及麻省理工大學的公開驗證頁面。
