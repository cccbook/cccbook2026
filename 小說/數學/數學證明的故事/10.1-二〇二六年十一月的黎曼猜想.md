# 10.1 二〇二六年十一月的黎曼猜想

## 11 月 20 日

2026 年 11 月 20 日，一位數學家在他的個人網站上發布了一份只有幾頁的備忘錄，外加十幾個壓縮檔。備忘錄的開頭是這樣一句話：

> 「我相信我與 Claude 一起工作時，發現了黎曼猜想的一個證明。」

作者是 Levent Alpöge。他不是業餘愛好者，也不是大學講師——他是 Anthropic 的研究員，此前在柏克萊的 MSRI 從事博士後研究，並且是 Lean 社群中「平滑素數密度界的形式化」這項工作的參與者之一（Galliford、Buzzard 等人 2021 年的〈The smoothed prime density bounds in Lean〉）。這篇工作的意義是：它第一次在 Lean 裡形式化了素數分布誤差的一個真實定理。

備忘錄接下來的內容，在科學史上罕見地坦率：

> 「但現在 Claude 遠遠超過了我——在終線附近。是的，Claude 改寫了、舞動了、在終線附近閃閃發光。」

以及一段技術描述，其中提到，論證的後裔是 Stepanov 在函數域上解決黎曼式的論證，而其中的關鍵是「重數」——但重數在整數上難以找到，對應的就像是「對整數求導」。

備忘錄裡還寫下了一句 Alpöge 自認為「會讓數學家從椅子上掉下來」的線索：

> 「對長度為 $X$ 的 von Mangoldt 求和，Claude 建議的 theta 提升鏈的長度，考慮到每個都要模仿『重數』，是 $\sqrt{X}$。」

而他說「還能是什麼別的呢？」

## 那個數字：1700 萬行

根據隨後公布的驗證資料，這次發布的規模是：

| 項目 | 數據 |
|---|---|
| Lean 模組數 | 175,187 |
| 程式碼行數 | 約 1,700 萬行 |
| 壓縮原始碼 | 239 MB，分成 14 個部分（`lean.tar.gz.part01` … `part14`） |
| 匯出的證明項 | 61,570,595,788 位元組（約 61.6 GB），sha256 `5ea74b91…244e` |
| 工具鏈 | Lean v4.33.1 + Mathlib v4.33.1 |

十幾個壓縮檔、四百多兆的原始碼、六十一 GB 的證明匯出檔——這不是「一篇長論文」，這是一整座圖書館。

## 五個定理

在提交的 `Main.lean` 裡，被證明的是五個定理。它們不是任意挑選的：每一個都對應社群事先公開的「挑戰檔案」（challenge file）所陳述的命題，而挑戰檔案只匯入 mathlib，不含任何提交者的程式碼。這是一個極其重要的制度設計：**命題由第三方事先寫死，參賽者無法偷換概念。**

五個定理是：

1. **黎曼猜想**，用 mathlib 自己的定義：

```lean
def RiemannHypothesis : Prop := ∀ (s : ℂ) (_ : riemannZeta s = 0) (_ : ¬∃ n : ℕ, s = -2 * (n + 1)) (_ : s ≠ 1), s.re = 1 / 2

theorem riemannHypothesis : RiemannHypothesis
```

（$s \neq 1$ 這一條是必要的，因為 mathlib 給 $\zeta$ 在 $s = 1$ 處指定了一個慣例值。）

2. 同一命題用提交者自己的話重寫：

```lean
theorem riemannZeta_eq_zero_re : ∀ s : ℂ, riemannZeta s = 0 → (¬∃ n : ℕ, s = -2 * ((n : ℂ) + 1)) → s ≠ 1 → s.re = 1 / 2
```

3. 對每個模 $N$ 與每個 Dirichlet 角色 $\chi$（不必是本原的），若 $\operatorname{Re}(s) > 1/2$ 且不是平凡角色在 $s=1$ 的情形，則 $L(\chi, s) \neq 0$。

4. 對每個 Dirichlet $L$ 函數，落在臨界帶內的零點必在臨界線上。

5. 對本原（primitive）角色，同樣的結論——這就是通常所說的 Dirichlet $L$ 函數版本的廣義黎曼猜想。

這裡有一個必須說清楚的範圍問題：**在這次發布中，「GRH」指的是 Dirichlet $L$ 函數**（所有模與所有角色）。Dedekind zeta 函數、Hecke $L$ 函數、以及一般自守 $L$ 函數，並不在被檢查的陳述之內。Alpöge 在備忘錄裡說，他期待同一方法可以延伸到「Extended Riemann Hypothesis」。

## 11 月 21 日：認證

隔天，Lean 社群與 Mathlib 社群發表了一份聯合聲明，由 Lean FRO 與 Mathlib Initiative 背書。聲明中說：

> 「黎曼猜想的**命題與證明都是正確的**」，並對結果有「完全的信心」。

這是形式數學組織第一次對一個重大數學結論給出機構性的背書。

聯合聲明借用了 **Xena Project** 的公開驗證標準，列出四道檢查：

**第一，檢查命題。** 被證明的定理必須就是 mathlib 的 `RiemannHypothesis`，而不是一個看起來類似的弱化版本。社群解釋：形式證明的意義取決於它所證明的形式命題，使用既有圖書館的定義，可以消除「悄悄證明了一個比較弱的東西」的風險。

**第二，檢查編譯。** 聲稱有數十人各自獨立編譯了整個庫，重現了同一份原始證明匯出檔，沒有任何錯誤或建置失敗。

**第三，檢查命題匹配。** 一個社群檔案把命題隔離出來（只匯入 mathlib），再用兩個獨立工具 `comparator` 與 `con-leche --compare` 確認被證明的定理與挑戰檔中的命題一致。

**第四，檢查證明的有效性。** 匯出的證明被交給：Lean 自己的核心（kernel）；兩個獨立的第三方核心——`con-leche` 與 `con-ron`；以及幾個用其他語言寫的檢查器。社群特別說明，`con-leche` 與 `con-ron` 相對於集合論「有形式證明說明它們不會接受一個錯誤的證明」。

## 麻省理工的驗證頁面

MIT 的 Andrew Sutherland 維護著一個公開的驗證頁面（math.mit.edu/~drew/grh），記錄了每一道檢查的狀態。根據該頁面在 2026 年 11 月 21–22 日的更新：

| 檢查 | 結果 |
|---|---|
| 175,187 個模組全部編譯（Lean v4.33.1 / Mathlib v4.33.1） | 零錯誤，耗時 16:43:21 |
| 對五個定理執行 `#print axioms` | 只出現 `propext`、`Classical.choice`、`Quot.sound` |
| 核心之外的公理宣告 | 沒有；環境中的 15 個公理全在 Lean 核心內 |
| Mathlib 檔案與官方快取比對 | 8,322 個 Mathlib 檔案與 378 個相依檔案，逐位元組相同 |
| 沙箱中的獨立 `lake build`（無網路、唯讀原始碼、另一台機器） | 成功，零錯誤；匯出檔與公布者匯出檔逐位元組相同 |
| `leanchecker` 核心重播每一個模組 | 175,187 / 175,187 通過，零拒絕 |
| `nanoda`（獨立的 Rust 實作核心） | 接受整份匯出檔，80 執行緒下 27 分 42 秒 |
| `con-leche`（master，含 `--verified` 模式） | 接受 1,468,418 個宣告，64 執行緒下 3 分 15 秒 |
| `con-leche --compare`（挑戰 vs 解答） | 五個定理全部「justified by the solution」 |
| `con-ron --compare`（Rust 移植的比較器） | 同樣五個定理全部通過 |
| `lean4lean`（模組逐一檢查） | 175,187 / 175,187 通過 |

頁面也坦誠列出限制：用的是沒有沙箱的雲端機器、只有一個 77 個模組的樣本與標準 `lake build` 逐一比對、匯出檔的校驗碼當時尚未與沙箱匯出檔比對（後來已完成，並且逐位元組相同）、`lake comparator` 與 Lean 核心對匯出檔的重播在更新時仍在進行（單執行緒，預期需要數小時）。

## 一個獨立的算術檢查

除了核心檢查之外，還有一道不依賴 mathlib 對 $\zeta$ 之定義的檢查。

驗證者把這次證明與一個獨立的 Lean 形式化——kimihiro64 的 `Robin1984`（Robin 與 Lagarias 的判準）——合併，得到兩個不含 $\zeta$ 字樣的定理：

```lean
theorem robin_inequality : ∀ n : ℕ, 5040 < n → ((ArithmeticFunction.sigma 1 n : ℕ) : ℝ) < Real.exp Real.eulerMascheroniConstant * (n : ℝ) * Real.log (Real.log (n : ℝ))

theorem lagarias_inequality : ∀ n : ℕ, 0 < n → ((ArithmeticFunction.sigma 1 n : ℕ) : ℝ) ≤ (harmonic n : ℝ) + Real.exp (harmonic n : ℝ) * Real.log (harmonic n : ℝ)
```

這兩個不等式與黎曼猜想等價（Robin 1984）。所以這次認證實際上給出了兩條獨立的支撐：一條是「$\zeta$ 函數的零點都在臨界線上」，一條是「因數和函數的明確不等式」。

（其中 Lagarias 不等式的形式化陳述長到必須把 `pp.all` 打開才能讀完——它直接命名了 27 個常數。這是一個提醒：在形式系統裡，「一個簡潔的句子」和「一個龐大的項」是兩回事。）

## 社群的反應

聯合聲明發布後，各方給出的評價分成了幾種。

《科學美國人》報導的標題是《AI 找到的黎曼猜想證明幾乎可以肯定是真的》，內文提到多位獨立數學家的初步評估認為該證明很可能是正確的，並且描述了社群已經完成的核對工作。

與此同時，《解碼者》（The Decoder）報導提到，陶哲軒曾預測這個問題要到 2050 年左右才會被解決，也不預期 AI 能單獨解決它。

而 Alpöge 自己在備忘錄裡保持著一種可敬的克制：

> 「這個論證目前非常長……以我走的路來看，我只不過邁出了一步。我打算盡我所能去理解它、去教會別人理解它、去把它寫得更好。」

他也說，他直覺認為這個證明會被大幅簡化，「很可能立刻就能簡化」。

## 為什麼這件事重要

把時間尺度拉開來看：

| 年份 | 事件 |
|---|---|
| 1859 | 黎曼寫下那個「假設」 |
| 1900 | 希爾伯特把它列為第 8 號問題的一部分 |
| 1932 | 西格爾把它命名為「黎曼猜想」 |
| 2000 | 克里姆研究所設定百萬美元獎金 |
| 2021 | 素數密度界在 Lean 中被形式化 |
| 2025 | $\zeta$ 函數與 RH 的形式陳述進入 mathlib |
| 2026.11.20 | 證明發布 |
| 2026.11.21 | 社群認證 |

一百六十七年。

而這次認證在「證明」這本書的主題上，具有一個歷史性的意義：

**它把「相信一個論證是對的」與「知道一個論論證是對的」之間的距離，壓縮到了可以被第三方獨立重放的尺度。** 一百六十七年來，人們對黎曼猜想的信心從來不是建立在「有人給出了可以重放的證明」上，而是建立在「有許多人各自用不同的方法接近了它」的統計性理由上。而 2026 年 11 月 21 日之後，這件事第一次有了別的答案。

下一節，我們把鏡頭拉遠，看這件事在更大的圖景裡的位置：AI 是怎樣進入數學的，以及「數學家」這個職業正在被怎樣重新定義。
