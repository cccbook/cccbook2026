# 1.1 巴比倫泥板上的未知數：收成、利息與二次方程

## 一塊要學生抄寫的泥板

西元前約 1800 年，古巴比倫王國的書記學校（edubba，意為「泥板之屋」）裡，未來的稅吏正在練習一道題：

> 「正方形面積加上邊長的 2/3 等於 35/2，求邊長。」

用今天的記號就是解 $x^2 + \frac{2}{3}x = \frac{35}{2}$。漢摩拉比法典時代的抄寫員沒有任何符號，他們把解法寫成一步步的食譜：「取 2/3 的一半，得 1/3；將 1/3 自乘，得 1/9；加到 35/2 上……」——這正是配方法的完整流程，比古希臘人早了一千多年，比我們課本上的公式早了三千五百年。

## 為什麼巴比倫人需要二次方程？

答案不在哲學，而在經濟制度。

兩河流域的農業建立在兩件事上：灌溉網絡與借貸。穀物貸款有法定利率（約 20%/年），土地以矩形丈量後按面積課稅。一個典型的經濟問題會自然長成二次方程：田的長與寬共 10（周長資訊），面積已知（面積資訊），求長與寬——即解 $x + y = 10,\ xy = 21$，等價於二次方程。記帳、分遺產、算複利，全部會撞上「知道和與積、反求兩數」的問題。

換句話說，二次方程在巴比倫不是數學遊戲，而是官僚制度的日常工具。泥板 YBC 6967 的題面甚至帶有諷刺：「長比寬大 7，積為 60」——很可能就是某類實際丈量問題的課堂化。

## 一元二次方程的巴比倫解法

對 $x^2 + px = q$，書記員的食譜是：

$$x = \sqrt{\left(\frac{p}{2}\right)^2 + q} - \frac{p}{2}$$

這正是 $x = \frac{-p + \sqrt{p^2 + 4q}}{2}$。他們甚至知道負根「不合理」而直接捨棄——在丈量與分穀的世界裡，長度不可能是負的。

更驚人的是泥板 Plimpton 322（約前 1800 年）：一張列有上千組畢氏三數的表格，精度遠超需要。學界至今仍在爭論它是三角函數表、教師出題的參數清單，還是求倒數的副產品——但無論哪種解釋，都指向一個結論：這是「標準化作業流程」被制度化傳授的證據。

## 為什麼沒有符號？

巴比倫數學用六十進位楔形數字表達一切已知量，卻始終沒有「未知數符號」。解法寫成對具體數字的操作步驟。原因可能有二：

1. 書記員的身分是技術官僚，數學是職業技能，像駕照一樣「會操作就好」；
2. 沒有發展出「證明」的文化——解法正確與否由結果對不對（穀物分得平不平）檢驗，而非由邏輯檢驗。

這個缺口要等希臘人來補。而希臘人補上邏輯的同時，也種下了另一個更深的困擾：他們拒絕接受「未知數」作為獨立對象，硬要把代數畫成線段。下一節，我們就看這場長達千年的「幾何固執」。
