# 4.1 哈密頓的四元數：在橋上刻下 $i^2=j^2=k^2=ijk=-1$

## 一個糾纏了十五年的問題

十九世紀三〇年代，都柏林的天文學家與數學家威廉·哈密頓（William Rowan Hamilton）已是皇家天文學家——這個職位是他二十二歲大學未畢業時便被任命的。他當時最執著的研究題目很實際：座標幾何。平面上的向量可以用複數 $a+bi$ 表示，加法是平移、乘法是旋轉縮放，美不勝收。

那麼空間中的向量呢？三維旋轉與三維力學（他正在研究光學與天體力學）需要一個「三維版的複數」。哈密頓設想形式 $a + bi + cj$，卻在乘法上撞牆十五年：若沿用複數規則令 $ij = -ji$、$ii = jj = -1$，算出 $(ij)^2 = i^2j^2 = 1$，但由 $ij=-ji$ 又得 $(ij)^2 = -i^2j^2 = -1$，矛盾。

## 1843 年 10 月 16 日的布魯姆橋

哈密頓自己日後記述了那個下午：他與妻子沿都柏林皇家運河散步，走到布魯姆橋（Brougham Bridge）時，靈光乍現——

> 「那裡孕育的火花是：$i, j, k$ 之間滿足 $i^2 = j^2 = k^2 = ijk = -1$。」

他當場用小刀把公式刻在橋的石頭上（原刻已風化，1958 年立牌紀念）。他放棄的是三維，跳到四維：四元數 $a + bi + cj + dk$。代價是接受 $ij = k,\ ji = -k$——乘法交換律犧牲了。

這是數學史上第一次有人「蓄意違反一條兩千年來被視為天經地義的運算律」。哈密頓本人承認猶豫：「這一步在當時對我而言非常叛逆。」

## 為什麼這是革命

這件事改變了「什麼是數學」的定義。在此之前，代數被視為關於「量」的科學，交換律是量的本性；哈密頓證明：只要自洽，就可以自創公理系統。代數從此不是「計算的法則」，而是「結構的研究」——公理化思想的開端。

四元數本身立了功，也嘗了敗績。它確實擅長描述三維旋轉：單位四元數用四個參數表示旋轉，比三個尤拉角更平滑、無奇點。哈密頓傾其餘生推廣它，但物理界主流（吉布斯、亥維賽）後來改造出更簡便的向量分析，四元數一度被遺忘。誰知一百多年後，航太姿態控制、電腦圖學（3D 遊戲引擎的旋轉插值）與機器人學全面採用四元數——因為它沒有萬向節鎖、計算便宜。都柏林橋上的火花，點亮了今天的手機螢幕。

## 同時代的共振

哈密頓不是孤例，而是時代風氣的先鋒：

- 1843 年稍早，格拉斯曼發表《線性擴張論》，建立一般 $n$ 維向量代數，同樣被冷落數十年；
- 1854 年，凱萊定義抽象群；1858 年發表矩陣代數（下一節）；
- 非歐幾何（1830 年代）已證明：幾何公理可以更換。

經濟與技術也在背後推動：愛爾蘭的實際工作是航海與天文計算，鐵路時代的工程測量需要強大的空間計算工具——需求催生理論，理論超前三十年，然後被下一輪科技回收。這個模式，將在四元數的後繼者（矩陣、李代數）身上再次上演。
