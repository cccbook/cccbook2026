# 1.3 遺產的接力：印度與阿拉伯世界的代數浪潮

希臘的窮竭法嚴格而不靈活，阿基米德之後，地中海世界再無人能把面積與體積的計算往前推。弔詭的是，讓分析學有朝一日能誕生的，不是希臘傳統的直接繼承者，而是幾百年間在世界另一端成長起來的計算文化。

第一棒在印度。笈多王朝的四到六世紀是印度數學的黃金期，天文計算的需求，即預測日食月食與制定曆法，驅動了數字的進步。到了阿耶波多與婆羅摩笈多的時代，印度數學家發展出十進位值制記數法與零的觀念。這件事的重要性怎麼說都不誇張：羅馬數字做乘除法要靠算盤輔助，而印度數字讓計算變成可以在紙上攤開的演算法。後來大約在十二世紀，婆什迦羅第二在莉拉沃蒂一書中已經能處理相當複雜的方程，而喀拉拉邦的天文學家學派在十四到十六世紀之間，為了改善行星模型，發展出正弦函數的冪級數展開，甚至有了類似現代餘項估計的想法。用今天的記號，他們寫下了 $\sin x = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \cdots$ 這樣的式子。可惜這些成果寫在棕櫚葉與方言詩歌裡，從未與地中海的幾何傳統相遇，也隨著葡萄牙人到來之後喀拉拉學院制度的瓦解而失傳，要到十九世紀才被歐洲學者重新發現。

第二棒在阿拉伯。八世紀的阿拔斯王朝建都巴格達，強盛的帝國與充沛的財力支撐起史上著名的翻譯運動。哈里發馬蒙設立智慧宮，派人到拜占庭搜購希臘典籍，歐幾里得與托勒密被譯成阿拉伯文，印度的天文著作與數字系統也傳了進來。九世紀的花拉子米在智慧宮任職，他寫了一本關於解方程的書，書名中的代數一詞來自書中術語，意思是移項還原；而他的名字拉丁化後成為演算法一詞。花拉子米解二次方程的方法是幾何的：用面積拼補來說明配方過程，希臘與印度兩種傳統在這裡真正交會。

之後的幾百年，阿拉伯數學家在代數與三角學上持續推進。奧馬爾海亞姆用圓錐曲線交點解三次方程，這是幾何與代數結合的先聲；比魯尼與納西爾丁圖西把三角學發展成獨立學科。同時，阿拉伯的實務文化也很重要：遺產分配法要求精確的算術，天文台需要精密的三角函數表，商業城市巴格達與開羅的紙張貿易讓書籍流通遠勝歐洲。分析學需要的兩種素質，嚴格的演繹與靈活的計算，此時分別沉睡在希臘遺產與阿拉伯代數之中。

十一到十二世紀，這些遺產開始西傳。西班牙的托雷多在基督教收復後成為翻譯中心，克雷莫納的傑拉德一個人翻譯了幾何原本、托勒密天文學大成等數十部著作。中世紀大學在波隆那、巴黎與牛津相繼建立，亞里士多德的自然哲學成為課程核心，而亞里士多德對無限的否定，實無限不可能存在，又把芝諾的陰影帶回了歐洲。十四世紀，牛津墨頓學院的學者研究勻加速運動，提出了平均速度定理，巴黎的奧雷姆用圖形表示運動，畫出了後來座標幾何的雛形。

到十五世紀，所有的材料已經備齊：希臘的幾何與窮竭法、阿拉伯的代數與演算法、印度的數字與級數直覺、歐洲大學裡的運動學研究。缺的是一個社會契機，讓這些傳統在同一批人手中相遇。那個契機，是印刷術、商業革命與天文學的危機，下一章就從那裡說起。
