# 5.1 勒貝格的測度與積分：把面積交還給碎裂的世界

十九世紀末，黎曼積分的理論看起來已經相當完善，但怪物越積越多。狄利克雷函數在有理數上取 $1$、無理數上取 $0$，它在每個區間上振盪，黎曼積分不存在，可是直覺上它的積分應該是 $0$，因為有理數很少。傅立葉級數的逐項積分、極限與積分的交換、以及微積分基本定理在什麼條件下成立，這些問題在黎曼框架裡都非常棘手。魏爾斯特拉斯的處處連續不可導函數與康托爾的稠密集更讓人懷疑：區間的長度概念本身就不夠用了。

亨利勒貝格 1875 年出生於博韋，父親是排字工人。他就讀巴黎高等師範學院，1902 年以論文積分、長度與面積獲得博士學位。他的核心想法聽來簡單，卻是積分學兩千年來最大的翻轉：黎曼積分把定義域切小，勒貝格積分把值域切小。要積 $f$，先問函數值落在 $[y, y + dy]$ 這一層的自變量集合是哪些，量這些集合的測度，再把值層的長度乘以集合的測度加起來。用他的比喻：黎曼是把一堆零錢按幣值一疊一疊相加，勒貝格是先把錢按幣值分類再相加，後者當然更有效率。

要讓這個想法成立，必須先回答：什麼樣的集合可以量長度。勒貝格用開區間覆蓋來定義外測度：集合 $E$ 的外測度是所有能覆蓋 $E$ 的區間列總長度的下確界 $m^*(E) = \inf \sum_{n} |I_n|$。這樣定義出來的勒貝格測度有平移不變性，可數可加，並把康托爾集測度為零、把不可數集也量得清清楚楚。可以量長度的集合稱為可測集，在此之上可測函數、勒貝格積分逐一建立。

新積分的威力立刻顯現。勒貝格控制收斂定理保證，在很弱的條件下 $\int \lim_n f_n = \lim_n \int f_n$，十八世紀以來數學家們憑直覺交換極限與積分的心願，第一次有了嚴格而通用的許可證。狄利克雷函數輕鬆可積，積分為 $0$。傅立葉級數的收斂理論、機率論的期望值、微分方程的解空間，全部搬到勒貝格的框架裡重建。機率論的重建者是柯爾莫哥洛夫，他 1933 年以測度論定義機率空間，把機率化為測度，這個公理化至今仍是機率論的語言，而機率論能成為金融與統計力學的基石，靠的正是勒貝格積分。

勒貝格本人的一生卻有辛辣的諷刺。他的博士論文起初反應冷淡，有老一輩學者私下說這不是數學。傳說勒貝格自己說過：我當了四十年的新積分的宣傳者，這職業比發明它更艱難。他的求職之路也不順利，先在雷恩任教，直到 1910 年代才回到巴黎。他的老師與同事皮卡起初反對他的理論，波萊爾是他早年最重要的支持者，兩人往來的書信留下了測度論誕生的心路。批評者的論點也不全然守舊：可測集與不可測集的劃分確實依賴選擇公理，維塔利 1905 年構造的不可測集讓人不安，這條線索通往二十世紀基礎問題的深處。

到 1930 年代，實分析的教育已經制度化：法國的阿達瑪學派、蘇聯的莫斯科函數論學派、波蘭的利沃夫與華沙學派都以測度與積分為基本訓練。巴拿赫與斯通把空間的概念推廣到極致，泛函分析誕生，量子力學的數學基礎由馮諾伊曼在希爾伯特空間中建立。勒貝格 1941 年去世時，他的理論已是數學的呼吸空氣。而這一切的大背景，是十九世紀末德國數學的另一場運動：把數學變成一座由公理撐起的大教堂。
