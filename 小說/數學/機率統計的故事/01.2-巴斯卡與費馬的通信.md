# 1.2 巴斯卡與費馬的通信：機率論誕生之夜

## 一位賭徒朋友的來信

1654 年夏天，法國數學家巴斯卡（Blaise Pascal）收到一封信，來自貴族德·梅雷騎士（Chevalier de Méré）。這位騎士是職業賭徒，也是巴黎沙龍的常客，他以實戰經驗向巴斯卡提出兩個賭題。其一是著名的「骰子悖論」：擲一顆骰子，四擲之內出現六點是有利的；那麼擲兩顆骰子，既然是兩倍的組合數，是否二十四擲之內出現雙六也有利？實戰經驗卻說不利。第二個問題正是帕喬利的一百年舊題：賭局中斷，賭金如何分配？

巴斯卡單獨解不了，於是寫信給圖魯斯（Toulouse）的費馬（Pierre de Fermat）——這位以「費馬最後定理」聞名的法官兼業餘數學家。1654 年 7 月至 10 月間，兩人往返七封信，機率論就在這些信件中誕生。

## 兩種解法，同一個答案

費馬的解法優雅而直接：既然賭局最多再進行幾輪就必然分出勝負，那就窮舉這幾輪「所有可能的未來」，數一數每種未來下誰會贏，按勝出的比例分金。他把未來「模擬」到終局，是徹底的組合計數。

巴斯卡則提供了更深刻的工具。他用一張他自己稱為「算術三角形」的表格——後世稱為巴斯卡三角形——把賭局逐輪遞推：要算某狀態下的分配額，只需看下一輪贏或輸兩種情況的平均。這個遞迴思想正是今天的動態規劃，也首次明確使用了「期望值」的概念。

以 5:3、先得 6 分勝的例子來算：甲只需再得 1 分就勝，機率為 $1/2$；若乙拿下這一輪，變成 5:4，再下一輪甲勝機率仍為 $1/2$。逐層展開：

$$E(\text{甲}) = \frac{1}{2}\cdot 1 + \frac{1}{2}\cdot\left(\frac{1}{2}\cdot 1 + \frac{1}{2}\cdot\frac{1}{2}\right) + \cdots = \frac{7}{8}$$

即甲應得賭金的 7/8，乙得 1/8。這個答案否定了帕喬利的比例分配，也否定了「按領先分」的直覺：分配依據不是過去的戰績，而是未來的期望。

## 骰子悖論：直覺的破產

德·梅雷的骰子問題同樣被解開。四擲一骰，不出六點的機率為 $(5/6)^4 \approx 0.482$，出現六點的機率約 0.518，確實有利。但若把參數加倍，二十四擲雙六不出現的機率為 $(35/36)^{24} \approx 0.509$，出現機率只剩約 0.491——賭之不利。比例的直覺在這裡失效：機率不是線性地隨機會數增加。這個小小的計算告訴賭徒世界一個殘酷的事實：靠經驗與直覺的賭術，從此敵不過紙筆。

## 電腦時代的回聲

巴斯卡與費馬當年用信件往返數週才完成的計算，今天幾行程式就能驗證：

```python
import random

def win_prob(n_sims=1_000_000):
    win = sum(
        all(random.random() < 0.5 for _ in range(3))  # 甲連勝三輪即乙無望
        for _ in range(n_sims)
    )
    return win / n_sims
```

更耐人尋味的是，這場通信發生在巴斯卡信仰轉折的前夕。數月之後的 1654 年 11 月 23 日夜，他經歷了著名的「火之夜」神秘體驗，從此淡出數學，轉向神學寫作（《致外省人書》《沉思錄》）。他在《沉思錄》中甚至留下了一個用機率論證「該不該信神」的「巴斯卡賭注」——機率思維滲透到他對命運與信仰的全部思考。

## 歷史意義

這七封信當時並未公開出版，但透過抄本與梅雷騎士的傳播，很快抵達了荷蘭的惠更斯手中，直接催生了下一章的主角——第一部機率著作。一次沙龍閒談、兩位天才、七封信，就為「不確定」建立了數學。思想的傳播鏈條，正是如此具體：賭場供給問題，沙龍供給交流，書信供給傳播——十七世紀的歐洲學術共和國，已經具備了讓新科學萌芽的完整生態。
