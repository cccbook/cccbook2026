# 10.2 微小的初值差異如何引發巨變？（非線性微分方程）

## 為什麼「線性」世界如此溫馴？

線性方程 $\dot{x} = ax$ 的解 $x(t) = x_0 e^{at}$ 有個溫馴的性質：**初值加倍，處處加倍**。誤差不會「質變」。疊加原理成立，任何解都是基本解的組合——十九世紀物理（熱傳導、波動、電磁）的大成功，很大程度上是因為它們的方程**都是線性的**。

非線性方程則打破一切保證。看一個最小的例子——**邏輯斯蒂映射**（人口模型的離散版）：

$$x_{n+1} = r\, x_n (1 - x_n)$$

只是個開口向下的拋物線疊代。但參數 $r$ 的變化產生整部「動力系統百科全書」：

| $r$ 範圍 | 行為 |
|---------|------|
| $r < 1$ | 滅絕：$x \to 0$ |
| $1 < r < 3$ | 收斂到穩定平衡 |
| $3 < r < 3.449$ | **倍週期**：在兩個值之間振盪 |
| $3.449 < r < 3.544$ | 四週期、八週期…… |
| $r \approx 3.57$ | **混沌誕生**：永不重複 |
| $r = 4$ | 完全混沌，遍歷整個區間 |

**費根鮑姆的發現（1975）**：倍週期的分岔點以固定比例收斂：

$$\delta = \lim_{n\to\infty}\frac{r_n - r_{n-1}}{r_{n+1} - r_n} = 4.6692\ldots$$

更驚人的是：**這個常數對一切「單峰映射」都相同**——邏輯斯蒂、正弦映射、任何有單一峰的疊代，都給出 4.6692……。這是**普適性（universality）**：混沌不是雜亂，它有跨越系統的普適常數。費根鮑姆用**計算器 + 圖形計算**「看」出這個常數，之後才有重正化群理論的嚴格解釋（借自量子場論的工具——又一次跨領域輸送）。

## 敏感依賴的精確定義：李雅普諾夫指數

「混沌」不是形容詞，它有度量。**李雅普諾夫指數** $\lambda$：

$$\delta(t) \approx \delta(0)\, e^{\lambda t}$$

- $\lambda < 0$：誤差萎縮（可預測，吸引到平衡/週期）
- $\lambda = 0$：臨界
- $\lambda > 0$：**誤差指數放大——混沌**，可預報時間 $T \sim \frac{1}{\lambda}\ln\frac{L}{\delta_0}$

以洛倫茲系統為例：$\lambda_1 \approx 0.906$。初值精度加倍，預報時限只延長有限個時間單位——**線性回報，遞減收益**。這解釋了為什麼天氣預報實際收斂到約 7–10 天的理論上限：改進感測器與超級電腦仍能推遲極限，但**指數放大是方程的性質，不是技術的缺陷**。

## 非線性世界觀的四個後果

**1. 可預測性是一種資源，需要管理。** 氣象機構的「集合預報」（同時跑 50+ 個微擾初值，輸出機率式預報）本質上是把蝴蝶效應產品化。**經濟與政治決策（颱風停班課、保險定價）依賴的不是「預報值」而是「預報的機率分布」——混沌把機率論寫進了公共行政。**

**2. 短期可測 ≠ 長期可測。** 天氣只能預報 10 天，但**氣候**（統計性質）可以預測數十年。混沌不否認長期預測，它改變了預測的對象（從軌跡到分布）。這是公眾誤解氣候科學的常見根源。

**3. 「穩定」需要論證。** 非線性系統可以有**多重平衡、臨界點、滯後**——湖泊優養化、生態系崩潰、金融擠兌、冰蓋融化的「不可逆轉折點」（tipping point），全部是非線性動力學的詞彙。**環境政策與金融監管在 2000s 之後大量引入「臨界點」思維**，這是混沌理論對公共政策最直接的輸出。

**4. 保守的工程學。** 塔科馬海峽大橋 1940 年風毀（氣動力自激振盪）、化學振盪反應、生理節律——工程師學會了尊敬非線性：**「看起來穩」不是理由，「證明穩定」才是。** 李雅普諾夫 1892 年的穩定性理論從俄國數學傳統（服務於炮塔穩定與電網）走向了全球工程課綱。

## 動手實驗：五分鐘體驗蝴蝶效應

用試算表或 Python 疊代 $x_{n+1} = 4x_n(1-x_n)$：

1. 從 $x_0 = 0.2$ 開始，記 30 步
2. 從 $x_0 = 0.2000001$ 開始，再記 30 步
3. 比較兩列——前 15 步幾乎相同，20 步後完全脫鉤

兩個初值只差 $10^{-7}$，約在第 20 步後毫無關聯。**這就是混沌：不是因為方程複雜（就一行），而是因為拉伸與摺疊反覆放大誤差。**
