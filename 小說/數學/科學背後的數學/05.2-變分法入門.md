# 5.2 變分法入門：尋找極值曲線的數學工具

## 問題：微積分不夠用了

微積分找「函數的極值點」：給定 $f(x)$，找 $x$ 使 $f'(x) = 0$。

但費馬原理問的是更難的問題：**給定兩端點，在所有可能的曲線 $y(x)$ 中，找使積分 $J[y] = \int L(x, y, y')\,dx$ 取極值的那一條。**

自變數不再是數，而是**整條曲線**。這是「函數的函數」——泛函（functional）的極值問題。需要新數學：**變分法（calculus of variations）**。

## 兩個傳奇的誕生問題

**1696 年，約翰·白努利在《教師學報》上公開挑戰全歐洲數學家**——「最速降線問題」（brachistochrone）：小球沿什麼曲線從 $A$ 滑到 $B$（不計摩擦）最快？這是科學共同體第一次用「公開挑戰賽」的方式推進數學——**學術期刊 + 榮譽競爭**，啟蒙時代知識市場的新機制。

牛頓收到匿名挑戰信，一天之內解出，回信說：「我不想讓外國人嘲笑我們的數學家。」萊布尼茨、洛必達、約翰與雅各布·白努利也都解出。答案是**擺線**（cycloid）——不是直線！

**直覺**：直線最短但不最快；先陡降加速、後平緩直行的曲線贏得時間。這個問題定義了新學科，而它的社會形式（國際挑戰）定義了現代數學競賽與期刊文化的原型。

## 歐拉—拉格朗日方程

核心工具由歐拉（1736）開創、拉格朗日（1755，**19 歲時**！他寫信給歐拉，歐拉回覆「你超越了我」）最終定形。

對泛函 $J[y] = \int_a^b L(x, y, y')\,dx$，極值曲線必滿足：

$$\boxed{\frac{d}{dx}\frac{\partial L}{\partial y'} - \frac{\partial L}{\partial y} = 0}$$

**推導思路**（直觀版）：把極值曲線 $y(x)$ 擾動成 $y(x) + \varepsilon\,\eta(x)$（$\eta$ 是任意的「虛位移」函數，兩端為零）。極值要求一階變化為零：

$$\left.\frac{d}{d\varepsilon}J[y + \varepsilon\eta]\right|_{\varepsilon=0} = \int_a^b \left(\frac{\partial L}{\partial y}\eta + \frac{\partial L}{\partial y'}\eta'\right) dx = 0$$

對第二項分部積分（$\eta(a) = \eta(b) = 0$）：

$$\int_a^b \left(\frac{\partial L}{\partial y} - \frac{d}{dx}\frac{\partial L}{\partial y'}\right)\eta\, dx = 0$$

因為 $\eta$ **完全任意**，被積函數必須恆為零——即得方程。（嚴格性由變分法基本引理保證。）

## 三個經典應用

**1. 最短距離**：$L = \sqrt{1 + y'^2}$。代入歐拉—拉格朗日方程，得 $y'' = 0$——直線。✓（幾何的「顯然」被代數證實）

**2. 費馬折射**：$L = n(x, y)\sqrt{1+y'^2}/c$，直接推回斯涅爾定律。

**3. 最速降線**：答案是擺線 $x = a(\theta - \sin\theta),\ y = a(1 - \cos\theta)$——與單擺等時曲線相同！惠更斯為鐘錶設計的擺線齒輪（1.2 章）與數學家的最速降線是同一條曲線。**理論與工程的殊途同歸。**

## 拉格朗日力學：變分法成為物理的作業系統

拉格朗日在《分析力學》（1788，一本**沒有一張圖**的力學教科書——他把力學徹底代數化）中給出：

$$\frac{d}{dt}\frac{\partial \mathcal{L}}{\partial \dot{q}} - \frac{\partial \mathcal{L}}{\partial q} = 0, \qquad \mathcal{L} = T - V$$

對比牛頓：向量分解、逐個受力分析；拉格朗日：寫下一個純量函數 $\mathcal{L}$，機械地套方程。對約束系統（單擺、雙擺、剛體）威力懸殊。**方法的經濟學：好的數學形式讓解題成本下降幾個數量級**——這也是它後來被諾特定理（見下）與量子場論選中的原因。

## 諾特定理（1918）：對稱 ⇔ 守恆——二十世紀物理的總綱

埃米·諾特（Emmy Noether）證明：**作用量的每一個連續對稱性，對應一個守恆律**。

| 對稱性 | 守恆量 |
|--------|--------|
| 時間平移 | 能量 |
| 空間平移 | 動量 |
| 空間旋轉 | 角動量 |
| 規範對稱 | 電荷 |

注意她面對的制度性歧視：哥廷根大學拒絕給她正式教職（「婦女不得任私講師」，1915 年希爾伯特為她抗辯的名言：「這是大學，不是洗澡堂」），她只能以希爾伯特的名義代課，直到 1919 年才獲資格；1933 年又因猶太裔被納粹解職，流亡美國布林茅爾。**諾特定理誕生在雙重邊緣性（女性＋猶太裔）的位置上**——制度如何浪費與延遲天才，這是科學史的持續教訓。

而諾特定理的直系子孫統治著當代物理：粒子物理的標準模型就是「以對稱性為出發點」寫成的作用量理論；楊振寧與米爾斯的規範場論（楊—米爾斯理論）正是諾特思想的推廣——**從 1755 年拉格朗日的方程，到 1960s 的粒子物理，是同一條數學血脈。**

## 變分法的現代迴響

- **最佳控制與運籌學**：火箭最省燃料軌道（龐特里亞金極大值原理，1956，蘇聯太空計畫）、物流路線優化
- **經濟學**：拉姆齊模型（1928）、動態最優化——宏觀經濟學的標準工具
- **機器學習**：梯度下降在「參數空間」找極值；更深一層，變分推斷（variational inference）直接把推論問題寫成泛函極值
- **大语言模型**：訓練目標本質是對損失泛函的最小化——你今天與之對話的每一個模型，都是變分思想的後裔
