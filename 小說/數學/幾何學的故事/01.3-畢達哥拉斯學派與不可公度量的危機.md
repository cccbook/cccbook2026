# 1.3 畢達哥拉斯學派與不可公度量的危機

## 一個政商學合一的團體

畢達哥拉斯（Pythagoras，約前 570–前 495）生於薩摩斯島，據傳曾遊學埃及與巴比倫，後來定居南義大利的克羅頓，創立了一個結合宗教、政治與學術的社團。這個社團有嚴格的入會儀式、財產共有、禁食豆子等規範，還參與城邦政治，因此曾遭政治打擊、會所被焚。

在知識上，他們確立了一個改變世界的信條：

> 「萬物皆數」——宇宙的秩序可以用數與比例來把握。

這不是空談，而是有硬證據的。畢達哥拉斯學派最著名的發現來自音樂：把單弦分成 2:1 得到高八度，3:2 得到純五度，4:3 得到純四度——音程的和諧對應簡單的整數比。這是世界上第一個「物理定律是數學關係」的實例，直接啟發了兩千年後伽利略與開普勒的信念：「宇宙這本大書是用數學語言寫成的。」

## 比例理論：以整數比理解世界

學派的數學以比例論為核心。他們用「中和比例」刻畫和諧：

$$\frac{a+b}{2} \text{（算術平均）}, \quad \frac{2ab}{a+b} \text{（調和平均）}, \quad \sqrt{ab} \text{（幾何平均）}$$

並發現連續四個整數 $6, 8, 9, 12$ 具有奇妙的對稱性：$\frac{6}{8} = \frac{9}{12}$（幾何比例）、$\frac{8}{6} = \frac{12}{9}$（調和）、$\frac{9}{8}$（音程）。數、和諧、宇宙，在他們眼中是同一件事的三個面相。

## 崩塌：正方形的對角線

然後危機來了。用希臘人的方式說：正方形的對角線與邊「不可公度」（incommensurable）——不存在任何一個小單位，能同時整除兩者。用現代語言說，對角線與邊之比是

$$\sqrt{2} \neq \frac{p}{q} \quad \text{對任何整數 } p, q$$

歐幾里得《原本》第十卷之前的附註記錄了經典的歸謬證明：若 $\sqrt{2} = p/q$ 且 $p, q$ 已約至最簡，則 $p^2 = 2q^2$，故 $p$ 為偶數，設 $p = 2r$；代入得 $q^2 = 2r^2$，故 $q$ 也是偶數——與最簡假設矛盾。所以 $\sqrt{2}$ 不是兩個整數之比。

用反證的圖示更容易直觀：

```mermaid

    A[假設 √2 = p/q<br>最簡整數比] --> B[p² = 2q² ⇒ p 偶]
    B --> C[q² = 2r² ⇒ q 偶]
    C --> D[與「最簡」矛盾]
    D --> E[√2 不可公度]
```

傳說中，發現此事的希帕索斯（Hippasus）因洩露秘密而被同門拋入大海。故事真偽難考，但傳說的流傳本身說明：這件事被視為動搖根基的醜聞。

## 為什麼是危機？

因為「萬物皆數」在當時意謂著「萬物皆整數之比」。若兩條線段不能表成整數比，那麼比例理論就有窟窿，用比例定義的相似形理論全面失守，建立在比例上的幾何證明連環失效。這不是發現一個新數字，而是既有數學大廈的地基出現裂縫。

後果持續了一個多世紀。直到歐多克索斯（Eudoxus，約前 408–前 355）提出天才的補救：不依賴整數比，而用「比例」的全新定義——對任意自然數 $m, n$，比較 $ma$ 與 $nb$ 的大小關係來定義 $a : b = c : d$。這個定義繞開了「量必須可公度」的要求，使比例理論對可公度與不可公度量一律有效。現代分析學家戴德金在 1872 年重建實數理論時坦言：他的「戴德金分割」正是歐多克索斯思想的翻版。

## 危機的深遠影響

- 數學性格的轉向：不可公度量逼使希臘數學與「數」拉開距離，轉向以圖形與量為主體的幾何。此後兩千年，歐洲數學的主導語言是幾何而非代數——連二次方程都要用面積圖形來解釋（所謂「幾何代數」）。代數的復興要等到阿拉伯與文藝復興時代。
- 邏輯的成熟：亞里士多德正是在這個時代系統化了演繹邏輯與公理化方法。很難說是巧合——數學需要更嚴格的基礎，邏輯學應運而生。
- 一個文化教訓：畢達哥拉斯學派企圖用秘密結社的方式壟斷知識，結果危機被藏成醜聞；歐多克索斯用公開的、可檢驗的定義化解危機。知識制度上，公開論證再一次戰勝了權威與保密。

有趣的歷史迴響：兩千五百年後，當電腦用有限小數表示 $\sqrt{2}$ 時，我們仍在和「不可公度」打交道——浮點數只是整數比的近似。畢達哥拉斯學派的幽靈，還住在每一台計算機裡。
