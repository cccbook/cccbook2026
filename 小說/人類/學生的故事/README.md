# 學生的故事：從竹簡書童、師徒烙印到學潮火種與演算法時代的終身學習者

本書跨越數千年，講述「學生」這個身份如何從古文明中少數精英的師徒傳承，經歷科舉與大學制度的確立、印刷術與國民教育的普及、學生運動對歷史的改寫，一路演變成大眾高等教育、線上學習，以及 AI 時代對「學習者」概念的徹底重構。
