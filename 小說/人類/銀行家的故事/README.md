## 核心線索

本書以四大維度貫穿全書：

1. 業務核心與形態：實物金銀保管與兌換 → 票號匯票與信用放貸 → 國家公債與中央銀行 → 證券化與衍生品交易 → 演算法金流與去中心化網絡。
2. 信任的基石：神廟與君王的威權 → 家族血緣與個人聲譽 → 國家法律與央行背書 → 演算法數據與區塊鏈密碼學。
3. 與權力的關係：受掠奪的對象 → 資助帝國戰爭的盟友 → 貨幣政策的體制核心 → 受監管與被 AI/DeFi 衝擊的傳統中介。
4. 工具與技術：泥板、算盤、帳簿 → 複式簿記、信鴿快遞 → 電報、彭博終端機 → 高頻交易、AI 信用模型、智慧合約。
