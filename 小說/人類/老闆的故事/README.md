# 老闆的故事：從王室特許、資本巨頭到演算法平台與未來創業者的權力史詩

本書跨越數千年，講述「老闆」這個角色如何從古代莊園主與特權商人開始，經歷大航海時代的股份公司、工業革命的工廠主、鍍金時代的資本巨頭，演變為職業經理人、矽谷創業家、平台演算法管理者，直至 AI 時代的組織締造者。

全書沿四條主線交織：角色與身份、權力來源、對員工的態度、經營與工具。
