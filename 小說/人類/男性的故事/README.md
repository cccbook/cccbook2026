# 男性的故事：從獵人英雄、騎士榮譽到情感解放與男性氣質重構

本書跨越數萬年，講述「男性」這個性別角色如何從遠古荒野中的獵人與部落保護者開始，經歷戰爭體制、君權與騎士道、工業革命的鋼鐵勞動，一路演變成現代社會對男性氣質的反思、情感表達的解放，以及科技與性別平權時代下的角色重塑。

全書依照四條主線交織而成：身份與使命、情感與心理、男性氣質的定義、男性與社會制度的關係。
