# 附錄B：歷代主要死因演變一覽

一張表看完人類頭號殺手的換人史。每一任「殺手」的下台，幾乎都對應著全書中的某項科技、制度或思想變革。

| 時代 | 頭號死因 | 其他主要死因 | 殺手下台的關鍵 |
|---|---|---|---|
| 石器時代 | 外傷與感染 | 產褥熱、飢餓、急性傳染病 | 農業剩餘、社群互助 |
| 古典時代 | 瘧疾與腸道傳染病 | 結核、戰亂、安東尼瘟疫 | 引水道與城市規劃（局部有效） |
| 14–16世紀 | 鼠疫（腺/肺型） | 結核、麻風、饑荒 | 檢疫制度（威尼斯 quarantine） |
| 16–18世紀 | 天花 | 斑疹傷寒、猩紅熱、產褥熱 | 人痘接種（1721）、牛痘疫苗（1796） |
| 19世紀 | 霍亂、肺結核 | 白喉、產褥熱 | 寬街地圖（1854）、下水道、李斯特無菌術（1865）、洗手（1847） |
| 1900s–1950s | 肺炎→心臟病 | 結核、流感（1918）、癌症 | 青黴素（1941）、疫苗、公衛水質 |
| 1960s–1990s | 缺血性心臟病 | 中風、癌症、AIDS（1980s） | 加護醫學、HAART（1996） |
| 2000s–2020s | 心血管疾病 | 中風、失智症、肺癌、COVID-19 | 標靶/免疫療法延後、但未取消死亡 |
| 未來趨勢 | 失智症與衰弱 | 抗藥性細菌、新興疫病 | CRISPR、AI 醫療、mRNA 平台化 |

注意接力賽的規律：每當上一任殺手被制服，死亡並未消失，而是「轉移陣地」——從急性傳染轉為慢性退化，再轉為照護與意義的問題。這正是本書各章交替出現的主旋律。
