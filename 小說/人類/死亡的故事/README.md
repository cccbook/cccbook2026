# 死亡的故事：一部人類的死亡醫學史與文明史

從遠古墓葬到數位永生——每一個時代如何死去，就如何活著。

本書以「年代死亡統計、環境與醫療條件、著名人物死因、死亡文化與信仰」四條主軸，
貫穿人類數萬年的死亡史，並著重書寫科技、經濟、制度、文化、政治、思想、教育
之間互相驅動的前因後果。所有事件與數據均為真實歷史。
