# 附錄C：死亡觀與醫療制度大事年表

橫跨五萬年的時間軸，左欄是「人類做了什麼」，右欄是「人類怎麼想死亡」。技術與觀念從來不是兩條平行線，而是互相驅動的雙螺旋。

timeline
    title 死亡史大事年表
    section 遠古

        前3300 : 冰人奧茨死於箭傷 : 生存暴力日常化
        前2400 : 埃及金字塔與《亡靈書》傳統 : 秤心審判、永生產業
    section 古典
        前399 : 蘇格拉底飲毒芹 : 哲學式的尊嚴赴死

        180 : 安東尼瘟疫殺馬可·奧理略 : 瘟疫動搖帝國根基
    section 中世紀

        2018 : 古道爾瑞士之旅 : 高齡死亡選擇權
        2020 : COVID-19 大流行 : 過剩死亡 1,500 萬+
        2022 : 伊莉莎白二世老衰 : 自然老死最後典範

年表的最後一格是未完成的：CRISPR、AI 與數位永生正在書寫下一行，但五萬年前埋下第一座墓葬的人類，追問的仍是同一個問題——如何面對必然的終點。這個問題的答案，將由下一位讀者續寫。
