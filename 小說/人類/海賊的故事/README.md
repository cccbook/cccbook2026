# 海賊的故事：從青銅時代的劫掠者、維京長船、私掠特許到加勒比海盜共和國與現代索馬利亞的海洋文明史詩

本書跨越四千年，講述「海賊」如何與貿易、帝國、科技、法律與國家體系互相塑造。海盜從來不只是罪犯：他們是海洋貿易的影子，是國家權力的工具，也是底層水手反抗船長專制的實驗。全書以東西方雙線對比，追問同一個問題：當海上的法律真空出現時，誰來制定秩序？
