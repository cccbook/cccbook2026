# 3.3 無敵艦隊覆滅與帆船砲戰革命

一五八八年夏天，西班牙無敵艦隊——一百三十艘船、約三萬人——從里斯本啟航，任務是護送帕馬公爵的陸軍橫渡英吉利海峽登陸英格蘭。這是當時歐洲最龐大的海上力量，結果卻遭遇了一場近乎完敗：一路被英艦騷擾，在格拉沃利訥會戰中被火船衝散陣形，撤退時又在蘇格蘭與愛爾蘭外海的風暴中損失慘重，最終只有約半數船隻回到西班牙。

傳統敘事喜歡把這場失敗歸於天氣與神意（西班牙人自己也說，上帝的風比人的火力更致命）。但軍事技術史給出更系統的解釋：這是一場海上作戰典範的更替——從「接舷跳幫」到「遠程砲戰」。

西班牙艦隊的作戰學說源自地中海傳統：靠近敵船、用鉤索接舷、讓陸戰隊跳上去肉搏，把海戰當成浮動的陸戰。他們的船是高大的運兵平台，配備的是短程重砲，射速慢。英格蘭艦隊則代表了新的思考：船體更低、更快、更靈活，配備長管加農砲（culverin），射程明顯更遠。英軍的戰術是保持距離，用縱隊航行反覆掠過西艦側翼，遠距離開火——「English line」的雛形。西艦的砲打不著英艦，英艦的砲持續消耗西艦的士氣與結構。換句話說，無敵艦隊的失敗不是船不夠多，而是作戰概念落後了一個世代。

這場革命背後有深層的經濟與制度原因。英格蘭是島國，沒有大陸軍的傳統負擔，海防是生死問題，因此海軍技術的投入有明確的政治優先級；伊莉莎白時代的私掠航行本身就是常年的實戰訓練與技術試驗場——德雷克與霍金斯不僅是海盜，也是砲術與船型改革的推動者。霍金斯擔任海軍司庫時主持了船型改造，壓低船艏樓與艉樓，提升速度與穩定性。反觀西班牙，龐大的帝國資源被陸權承諾（尼德蘭戰爭、地中海對奧斯曼）分散，海軍思維仍受接舷傳統與宮廷政治束縛。

無敵艦隊的覆滅改寫了此後兩百年的地緣格局。第一，它打破了西班牙海權不可戰勝的神話，向英荷法私掠者與海盜宣告：加勒比不再是禁地。第二，西班牙被迫長期維持昂貴的護航體系與大陸戰爭，白銀收入的財政效率持續下滑，帝國走向「白銀依賴症」的慢性死亡——白銀一到手就用於戰爭與還債，無法轉化為本國的製造與制度能力。第三，英格蘭確立了「海權立國」的國家路線，這條路線在下一個世紀由克倫威爾的航海法案與三次英荷戰爭繼續強化，最終造就日不落帝國。

從海盜史的角度看，一五八八年是一道分水嶺。此前，加勒比是西班牙的內海與他國的走私場；此後，它成為所有歐洲列強的競技場。戰爭頻繁化意味著私掠特許狀大量發放，私掠水手的供給不斷累積。當某一刻戰爭突然結束、特許狀集體失效，這批人何去何從的問題，就會以最戲劇性的方式爆發——那是十八世紀初拿騷的故事。
