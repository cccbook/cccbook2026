# 2.3 塞納河圍城與諾曼第公國的誕生

八四五年，數百艘維京船沿塞納河西上，法蘭克國王禿頭查理無力阻擋，維京人首次攻入巴黎，以七千鎊白銀的貢金離開。用錢換和平自此成為法蘭克的慣例，但慣例養大了胃口：此後數十年間，塞納河水道成為維京人的常態高速公路，八五六年起他們甚至開始在河口過冬紮營，不再返回北方——季節性劫掠轉變為常駐占領。

最戲劇性的一幕發生在八八五至八八六年。維京艦隊圍攻巴黎超過一年。當時加洛林帝國已經衰落，實際組織防禦的是巴黎伯爵厄德（日後他被推舉為西法蘭克國王），老將兼修道院長戈茲林死守橋樑與城島。巴黎之所以守得住，靠的是塞納河上的兩座橋——橋墩與塔樓鎖住了河道，讓長船無法通行，維京人的機動優勢被土木工程抵消了。這是戰術層面的啟示：對抗以水路機動見長的敵人，關鍵是鎖住水道節點。

政治層面的解決方案更具歷史意義。國王胖子查理前來解圍，卻選擇付錢並允許維京人溯勃艮第河道去劫掠別處——這種「把災難轉包給鄰居」的做法讓他威信掃地，次年即被廢黜。法蘭克的政治體制在維京壓力下加速演化：地方伯爵掌握了防務與司法，封建制度在實戰中成形；九一一年的凡爾登條約分家之後，西法蘭克的政治重心進一步從加洛林王朝轉向了能打仗的貴族。

而徹底的解法來自一個出人意料的政治發明。九一一年，西法蘭克國王糊塗查理與塞納河的維京首領羅洛簽訂《埃普特河畔聖克萊爾條約》：羅洛受洗成為基督徒，宣誓效忠國王，防衛塞納河口，並獲封魯昂周邊的土地。這片賜地日後發展為諾曼第公國——字面意思就是「北方人之地」。

這筆交易的本質，是把海盜轉化為邊防軍，把劫掠的成本轉化為封建的收益。從羅馬時代的龐培到九世紀的法蘭克，「收編」一再被證明是最省錢的解方。對維京人而言，這同樣是理性選擇：土地、爵位與基督教正當性，是比每年冒險劫掠更穩定的資產；羅洛的傳記作家迪多記載，羅洛受封時被要求親吻國王的腳，他拒絕彎腰，讓部下代勞，部下一抬腳把國王掀翻在地——這則故事無論真偽，都說明了諾曼人對自己「以武力換體面」的自豪。

歷史的長效回報遠超所有人預期。諾曼人迅速法語化、基督教化，卻保留了北歐的軍事組織與擴張動能：一〇六六年，諾曼第公爵威廉渡海征服英格蘭；同時代另一批諾曼人奪取了南義大利與西西里，甚至參與十字軍。換句話說，諾曼第公國是海盜問題的「體制化終點」——當劫掠者獲得了領地與制度身分，他們的後代成為建立新王國的王朝。這也揭示了海盜史的又一條規律：海盜問題的最終解法往往不是消滅，而是改造他們的激勵結構。問題只在於，什麼樣的時代能拿出土地與頭銜，什麼樣的時代只能拿出絞索。
