本書跨越數百年，講述「風險投資」這股資本力量如何從遠洋冒險與捕鯨業的高風險分紅傳統，經歷美東先驅的機構化實驗、矽谷沙丘路的生態定型、網路泡沫的洗禮，演變為推動獨角獸誕生、重塑全球科技地緣競爭、並進入 AI 時代的終極資本引擎。
