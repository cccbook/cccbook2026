# 6.2 微軟與 IBM 的世紀結盟：比爾·蓋茲如何靠作業系統授權改寫商業規則？

## 1980：IBM 的遲到與「授權模式」的意外

IBM 是世界上最大的電腦公司，但它**錯過了個人電腦**——內部官僚（**公司分部制**，即使個人電腦也用「 分部管理和硬件標準」大規模審核的種種決策就是過慢）。1980 年，IBM 決定進入 PC 市場，但因為時間緊迫，決定採取「**與外界合作，而不是自己全部做**」的策略——**正是這個「快速外包」決定，造成了未來 30 年的產業格局**。

IBM 來到西雅圖的一間小型軟體公司 **Microsoft**——Bill Gates（1955-; Paul78 & 1976 兩人哈维集) 与 Paul Allen 的定位是「**軟體編程語言（BASIC）的服務商**」——過去 5 年間 —他們在 Altair BASIC 上的專注，使其幾乎成為 **一個行業標準**。

Gates 滿會見 IBM 經理 & selection 做了 **「 三個決定」**感人史册**：

**1. 找到了 PC-DOS / MS-DOS 的關鍵組合方式**：

- IBM 需要**作業系統 (OS)**，遍尋之下原目標廠商是 **Digital Research** 的 **CP/M**（Gary Kildall）——但是談判未果（Kildall 忽略了 IBM 的傳聞）
- Microsoft 立刻以 **~$75,000** 從 Seattle Computer Products 的 Tim Paterson 手上買下 **86-DOS / QDOS**——**重新改造**成 MS-DOS，並**轉手授權給 IBM**

**2. 保留「**開放授權**」的條款**——這是 Bill Gates 的**一生最大商業判斷**：

- Gates 給了 IBM 一個「**per processor** + **non-exclusive**」 的版權許可——換句話說：**IBM 只得到了一個 PC-DOS 的非獨占授權，且不少於 IBM 里可以允許兩側使用**
- 十分elikely，**Microsoft 才有自己的股票**——將 DOS **獨立授權給任何第三方**（Compaq、Dell、HP 各種 PC 廠商）——**這個「開放的專利協議」首創了我們所知的**「**軟體授權 as business**」**——**「每台電腦都付錢給微軟」成為 IT 業最持久、最暴利的市場之一**

**3. 預見到「**software = platform**」**：

- Gates 在 1976 年發表的著名的 **《Open Letter to Hobbyists》**—— 抱怨「 Homebrew club 們偷軟體」—— **率先說出**「軟體是**做的商品，必須付費」**—— 這句話是軟體行業商業化基調宣言
- (多年後，「軟體 as-a-service (SaaS)」、 app store、 cloud subscription— 都在同一條邏輯路上，我們今天 pay per API instance 與 pay per token 的**軟體付費文化** 秋草之前 Just 由此奠定)

## Microsoft vs. Apple：兩種策略的對照

**Apple** 選擇封閉整合：硬件 + OS + 光碟應用全部自己設計——**高品質 + 高價位**
**Microsoft** 選擇的最多是 **horizontalization**：OS 是標準功能，讓硬件廠（IBM/Compaq/Dell/HP）在底層競爭——**低價 + 市場份額**——**

| 維度 | Apple 策略 | Microsoft 策略 |
|------|------------|----------------|
| 硬件 | 自己做 | 給第三方廠家 |
| OS | Mac OS 自用 licensing 閉鎖 | MS-DOS/Windows **大量授權** |
| 收入結構 | 銷售 P＆ Smoak hardware | OS license 之費 + Office 軟件 |
| 市場份額 | 15% 之下的 奇idence | **90% 主導地位**
| 品牌價值 | 強烈**樣子** & 品牌忠誠 | 《 平台收费 solid loyalty （+ 更与 消費者 game emotional ）

**蘋果的高利润在高品牌，而 Microsoft 的 prote出家 是**：**每一台 PC 都替 Microsoft 收租**——無論第三方的 PC 是誰做出都是 IBM-compatible platform——** MS platform 的 **市場份額為**超過龐大」

**IT 公司皈 edit 兜說明**： Microsoft 1990s 在 **90%+ desktop OS 年30% + 20% office** 而出現，2001 年 的時 Microsoft 必須面對 **反壟斷訴訟**（美國「Compaq vs U.S. министерawmarket джоз ي给我》） — 2010s 反壟斷 Hours 模式 中 MS 的 ThreatReduce 變動/與另一台 SaaS 時代 Or the 死掉 （zephered Azure . cloud) 到課新 心地&Mobi （100% 顧 branches 奶果 达 Sales）
