
檔案名稱如 

* 01.1-yyyyyy.md
...
* 05.3-yyyyyy.md
...
* n.4-yyyyyy.md

yyyyyyy 是中文標題

目錄寫在 README.md 中，如下

* 第1章-xxxxxx
    * [1.1-yyyyyyy](01.1-yyyyyy.md)
...
* 第5章-xxxxxx
    * [5.1-yyyyyyy](05.1-yyyyyy.md)

* 第n章-xxxxxx
    * [n.1-yyyyyyy](n.1-yyyyyy.md)

....

格式採用標準的 github markdown ，可以用 tex 與 mermaid.

要盡量寫出歷史關聯與前因後果，包含科技，經濟，制度，文化，政治，思想，教育，.... 互相的驅動關係。

這些故事可以有趣，但是不可以虛假，必須是真實事件。

請一篇一篇寫，不要用程式產生。

內文不要用太多格式化的標記，像是 **...**

先寫目錄讓我確認，確認 OK 再開始寫，可以開 sub-agent 平行去寫

如果有不知道的，可以先查外部資料再寫
