# 舞蹈的故事：從祭祀狂歡到肢體革命的身體史詩

舞蹈是最古老的藝術，也是最短命的藝術：它不需要任何工具，卻在動作結束的瞬間消失。正因如此，舞蹈史是一部「看不見的歷史」——直到攝影與錄影出現之前，所有舞蹈都只存在於文字描述與繪畫之中。本書沿著四條主線展開：動作與規範的演變、鞋子與身體的關係、場所與受眾的遷移、主題表達的擴張，從篝火旁的模仿，一路講到手機螢幕裡的舞姿。
