# 藝術的故事：從洞穴壁畫到數位時代的靈魂演義

這是一本關於人類如何「看世界」的歷史。藝術從來不只是美麗的物件，它是宗教信仰、帝國權力、科技發明、經濟結構與思想革命共同作用的結果。從黑暗洞穴中的火光，到演算法生成的影像，這條路走了三萬多年。

全書分五篇、十三章，依時代順序展開。
