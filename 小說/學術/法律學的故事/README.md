# 法律學的故事：從石柱雕刻、正義女神到演算法時代的正義史詩

本書時間跨越數千年，講述人類如何從神授的戒律與嚴刑峻法開始，逐步探索理性、自然法、人權與憲政，並最終建立起現代法治體系（大陸法系與英美法系），乃至於在現代面對 AI 與數位時代的法理挑戰。
