# 第 2 節 Linux 核心與 GitHub：沒有實體牆壁的全球百萬工程師線上智者群落

## 一封信、一個磁場

1991 年 25 歲的芬蘭大學生 **Linus Torvalds** 在 comp.os.minix
郵件列表發了一封信：「我在做一個（免費）操作系統，
只是個 hobby……」隔了 34 年，這個 hobby 變成**伺服器、
安卓手機、超級電腦的作業系統底座**，而它的治理卻
幾乎完全靠**郵件列表 + 程式碼 + 修補**。

## 全球開源磁場的三個構件

- **Linux（1991）+ GCC + GNU 工具鏈**：開源作業系統的
  技術基底；
- **Git（2005）**：Linus 為協作而設計的**分散式版本控制**，
  讓「每個人都可以有自己的分叉，而無須經過任何機構」；
- **GitHub（2008）**：面向社群的平台——**「磁場即網站」**
  讓全球 1 億開發者以代碼交換互通意見。

## 制度：開散式群雜馬爾科夫「優質異識」

Torvalds 的 **「Benevolent Dictator for Life」**
（柔性專制意見決策），配合**協會互助的 code review**，
成為人類工程史上第一次「智慧磁場在不只是行政
的方式運轉、開放結合 Merrick 的科學」：

```mermaid
graph LR
  P[提案 code] --> R1[線上審查 (mailing list/PR)]
  R1 --> M[ Linus 合成]
  M --> X[釋出 kernel 版本]
  X -- 意測回饋 --> P
```

**提出**：墙上無物、虎狼无数開源磁場的有它**問连繫的本生
文化規範**；它是本書對 **Faithocracy** `（官方磁場）` 與
**雜派** 的國產，elastic 自的三期。
