# 第 3 節 企業官僚的盲目：為什麼最偉大的發明室產出了顛覆世界的主意，母公司卻毫不知情？

## 辦公室的「信號系統設計錯誤」

PARC 的教訓不是「研究人員太聰明、母公司太笨」，而是**管理制度
讓好思想的可見度為零**：

- **預算線：部門型財會**：印表機在列管報表上是「硬體收入」，
  而軟體/介面不出現在 Xerox 財務指標中——**無法核算的創新
  就無法存活於會議**；
- **主管的 KPI**：總部監測的是銷售與成本，而**創新在公司
  週報中沒有欄位**；
- **代理人問題**：PARC 的研究員對母公司的成功**不附有
  直接責任** —— 結果自然往「實驗文化」漂移。


## 「磁場的困境」總結（Ch8–Ch9 的共同公式）

貝爾實驗室與 PARC 都是**有錢、自由、人才密度極高**的磁場，
它們的衰敝有共同特徵：

1. **磁場的價值不等於母公司的財報價值**；
2. **當磁場的發現與母公司的核心業務脫鉤時，母公司只能
   「估而且看不到」**；
3. **最好的產權保護是「有人愛」**：成功的磁性，不是名牌
   而是**一種代際文化**：PARC 學徒（艾倫·凯、Metcalfe、
   Warnock、 Geschke）接着闖出 Sun、Silicon Graphics
   、3Com、Adobe —— **Adobe 這家公司成立的動機
   正是「把 PARC 的 PostScript」帶出社會**。
