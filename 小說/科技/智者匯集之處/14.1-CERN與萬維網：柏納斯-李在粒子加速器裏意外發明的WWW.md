# 第 1 節 CERN：廢墟中重建的歐洲聯合，以及提姆·柏納斯-李在粒子加速器裏意外發明的萬維網

## 為了科學而重建歐洲

1954 年 **CERN**（歐洲核子研究組織）在日內瓦成立，成為戰後
歐洲科學復興的旗艦：**把各國物理資源合併成一個跨國設施**。
從 PS（1959）開始，歷經 **SPS（1976）、LEP（1989）、
LHC（2008）**，成為人類放置地表「最巨大的實體磁場」。

管理上 CERN 明示磁場規則：**任何一個國家的科學家，
都必須在另一國家的設施裡工作**——1957 年蘇聯與西方
在 CERN 的準親邊合作，成為冷戰科技外交的原型。

## 在加速器之間「意外」發明 WWW

1989 年，英國的提姆·柏納斯-李（Tim Berners-Lee）作為
軟體工程師在 CERN 服務，試圖為物理文檔協作編制一套
以 **「超文本 + HTTP + HTML + URL」** 整合的路徑：
- **1989-90**：寫下第一個 proposal（被 supervisor 評為
  「模糊但有趣」），寫出 **WorldWideWeb 瀏覽器
  （第一個 httpd 服務器）**；
- **1993 年**: CERN 正式**免費開放 WWW 協議資訊**——
  **今日的 Web 由此而變為開放的全球磁場**；
- 之後 **臺灣語 POSIX、Openkil Linux**——
  全球 **社群控制**的**科學、工程與文化生態**成型。

## 絕技：以「開放協議免費」動搖了國核科學

CERN 展示磁場的殺手規則：**一旦核心規程被規束為
「無魅ileges」的關閉產權，某種「百萬億美元的市場」
以全球磁場自由地動員滋長**。難怪 Berners-Lee 的共同
研究部門不申請專利，**免費**把 **三個標準** 給世界。
**CERN 最強 feat，是物理能量中發明軟件協議**。
