# 第 3 章　槓桿、滑輪與斜面

# 3.2 魯班與諸葛亮的神話：鋸子、滾木與木牛流馬等古代木工與運輸機械工具

## 3.2.1 魯班：把「工藝」制度化的人

魯班（公輸班，春秋末期）在記載中是「**木工工具系統**」的人格化：鋸、曲尺（矩）、墨斗、鑿子、刨的傳統譜系雖然許多未必指名一人所創，但在《墨子》《禮記》與各種傳說層累中，魯班成為「**手工業的技術神**」。值得指出的技術點：

1. **鋸齒的斜齒設計**：把「切」與「排屑」分開設計；
2. **墨斗＋曲尺**：以輔助工具把幾何直線副產品化——**工具代償了視覺精度**，核心概念與後世量具（5.2）一脈相承；
3. **雲梯與攻城器械**：重大國防項目（與楚國攻宋的故事，《墨子·公輸》）。

## 3.2.2 木牛流馬：運輸機器的戰場急就章

三國諸葛亮北伐（公元 3 世紀）在史書《三國志》有「木牛流馬」的明確記載（裴松之注引蜀志），其實物形態至今有論爭，主流學說包括：

- **獨輪車說**：木牛＝改良獨輪車（單輪手推車），流馬＝四輪框架車；
- **省力機構說**：以槓桿與連桿替代部分抬抬人力；
- 無論真身為何，其**制度意義**確鑿：北伐後勤諸葛亮把「**運糧工具工程化**」寫進軍事制度——機械化後勤的早期記錄。

## 3.2.3 中國古典機械的整體譜系（對照希臘）

| 機械 | 時代 | 性質 |
|---|---|---|
| 翻車（鏈斗汲水，龍骨車） | 漢代（馬鈞改良） | 機械式灌溉工具 |
| 指南車、記里鼓車 | 三國西晉（馬鈞） | 差速齒輪系統的方位／里程記錄機 |
| 蜀錦提花機 | 漢代 | 提花織機（6.3 的同源譜系） |
| 水排 | 東漢杜詩 | 水力鼓風（2.2 已述） |
| **傳送運轉與小件機械** | 戰國漢唐 | 靠人力／畜力驅動的複雜齒輪系 |

中國古典機械的**制度特色**：與中央政府的「將作監」「大工臣」類職官系統緊密相連——機械是**官府工程**的一部分，是一個中央政權的管理競賽；不像地中海世界那樣，因城邦貿易和外資生態而流行天才個人。

## 3.2.4 前因後果

- **前因**：木構建築的長期需求＋戰場後勤壓力。
- **事件**：鋸／矩／墨斗標準化、木牛流馬、翻車指南車等譜系。
- **後果**：**「木構工具系統」成為東亞工匠的世界母語**（日本、韓國木工職統皆由此）；墨家「守備器械＋邏輯學」也在木牛流馬與魯班的對抗故事中留下紀錄——工具、軍事、思想的三角在古典中國同樣精彩。
