# 通訊技術的故事

一部關於人類如何突破時空枷鎖的真實技術史——從長城上的烽火狼煙，到電報改變時間的價值，從 Shannon 把資訊變成數學、高錕把一縷光束進玻璃，到 5G 巨量天線、Starlink 天網與量子通訊的物理級安全。這裡的主角不是抽象的「技術」，而是性格迥異的工程師、數學家、企業家與制度設計者，以及科技、經濟、制度、文化、政治之間相互驅動的歷史關聯。
