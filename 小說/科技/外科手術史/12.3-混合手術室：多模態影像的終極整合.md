# 第 3 節 混合手術室（Hybrid OR）：多模態影像與手術檯的終極整合

## 一、手術室的影像革命

二十世紀的手術室是「盲目」的：外科醫師靠肉眼與雙手，影像診斷則屬於放射科的暗房。兩個世界隔牆相望，病人必須在手術室與影像科之間搬運往返。混合手術室（Hybrid Operating Room）打破了這道牆——把血管造影 C 臂、甚至 CT、MRI 搬進手術室，讓「診斷」與「治療」在同一張手術檯上連續完成。

核心設備是懸吊式數位減影血管造影（DSA）C 臂：C 形機架環繞手術檯，可即時顯示血管與導管的動態影像；高階混合手術室更配備術中 CT 或可移動 MRI，讓醫師在手術中途重新掃描、更新導航。術中影像成為外科的「第三隻眼」：置入物位置對不對？支架有沒有內漏？切除邊界夠不夠？答案在關胸之前就能揭曉，而不必等二次手術。

## 二、TAVR：混合手術室催生的治療革命

混合手術室最具代表性的果實，是經導管主動脈瓣置換（TAVR）。主動脈瓣狹窄的傳統療法是開胸、體外循環、切開心臟換瓣——對高齡病人風險極高。TAVR 改由股動脈送入導管，將壓縮在支架上的人工瓣膜撐開於原位，全程不開胸。但這個技術必須「一邊造影、一邊具備隨時中轉開刀的能力」：瓣膜若釋放錯位或阻斷冠狀動脈，必須在數分鐘內轉為開心手術。只有混合手術室能同時滿足這兩個條件——可以說，沒有 Hybrid OR，就沒有 TAVR 的臨床普及。

TAVR 更瓦解了一個百年界線：「內科」用導管、「外科」用刀，各行其道。TAVR 的執行需要介入心臟科醫師與心臟外科醫師同台，遂催生了「心臟團隊」（Heart Team）制度：心臟科、外科、影像科、麻醉科共同評估每個病人該走哪條路徑。這是二十世紀「內外科分家」的一次歷史性和解——治療方式的選擇權，從科室本位交還給病人的利益。

## 三、資本競賽的經濟學

混合手術室造價驚人：頂規系統逾億元新台幣，另需強化樓板承重、防輻射屏蔽與巨大吊臂的無影燈整合。對醫院而言，這是一場典型的資本競賽：擁有 Hybrid OR 的醫院能吸引 TAVR、複雜主動脈支架、神經外科與創傷手術的病人，形成「設備—病人—收入—再投資」的正迴路；沒有的醫院則面臨病人流失。經濟學的邏輯在此深刻地塑形了醫療：技術採購不只決定於醫學證據，也決定於市場競爭與醫院治理者的判斷。各國健保對 TAVR 給付的政策，更直接左右了這場競賽的速度——支付制度成為技術擴散的油門或煞車。

## 四、治療個人化與一站式手術

混合手術室使「治療個人化」獲得實質工具：術中影像即時更新，讓每一步都依病人當下的解剖狀態修正，而非死守術前計畫。由此誕生「一站式複合手術」（hybrid procedure）：冠心症病人在同一手術檯上，先由外科進行血管繞道，再由介入科放置支架；複雜主動脈剝離則「開刀置換血管＋導管支架」一次完成。過去需要分次麻醉、分次住院的治療，被壓縮為單次、低創傷的整合方案。

更根本的變化是：手術室本身成為一個資訊系統。影像設備、導航、監視器、麻醉機、電刀與器械追蹤全部連網，中央整合控制；手術室的設計者不再是建築師，而是資訊工程師與人因工程師。手術室由「場所」變成「平台」，為下一章 AI 導航與即時資料運算預留了介面。

## 因果鏈條

影像技術（DSA、術中 CT/MRI）成熟 → 醫院將影像搬入手術室形成 Hybrid OR → TAVR 等跨科技術因「造影＋隨時中轉開刀」的需求而被催生 → 內科與外科界線瓦解、心臟團隊制度誕生 → 治療選擇權回歸病人利益 → 混合手術室高造價引發醫院資本競賽 → 健保給付政策調節技術擴散速度 → 一站式複合手術與個人化治療成為常態 → 手術室轉型為資訊系統，為 AI 時代鋪路。
