## 💡 本目錄亮點

1. **完整穿透影音科技演進史**：愛迪生留聲機與黑膠唱片 → 磁帶卡帶、Walkman 與 Betamax/VHS 大戰 → CD/DVD/藍光革命 → MP3 與 P2P 轉折 → H.264/HEVC 壓縮與串流媒體 → 4K/8K、AI 計算畫質、Dolby Atmos 空間音訊與 Vision Pro。

2. **深度解構影音兩大核心技術軸線**：

| 軸線 | 演進路徑 | 對應章節 |
|---|---|---|
| **聲音** | 類比溝槽/磁頭 → PCM/DAC 數位化 → MP3 心理聲學壓縮 → Hi-Res／空間音訊物件 | 1, 3, 5, 7, 10 |
| **視訊** | 膠捲/CRT → 磁帶螺旋掃描 → 光學雷射讀取 → LCD/OLED 面板與 H.264/HEVC 壓縮 | 2, 4, 6, 8, 9 |

3. **結構嚴謹**：全書 10 章，每章 3 個深度小節，嚴格遵循年代軸。

4. **史實紀律**：從愛迪生 1877 年錫箔留聲機、飛利浦免權利金授權的卡帶策略、1984 年最高法院 Betamax 合理使用判決、1995 年九家廠商共寫 DVD 規格、2008 年華納倒戈藍光陣營，到 2019 年《曼達洛人》LED 虛擬攝影棚——所有故事皆為真實事件，含歷史考辨與科技—經濟—制度—文化的因果鏈分析。
