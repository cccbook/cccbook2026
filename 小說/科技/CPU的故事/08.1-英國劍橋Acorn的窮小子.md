# 8.1 英國劍橋 Acorn 電腦公司的窮酸窮小子：為什麼 RISC 哲學天生適合低功耗行動裝置？

> 1985 年，一家英國小公司用 25,000 個電晶體造出一顆 32 位元處理器，功耗不到 0.1 瓦。當時的矽谷沒人在意。三十年後，這顆晶片的後代統治了地球上的每一個口袋。

## 一、BBC 的訂單與英國的電腦教育運動

故事的起點是**教育制度**：1981 年，英國廣播公司（BBC）推行「BBC 電腦素養計畫」（Computer Literacy Project），要為每所學校提供一台電腦。劍橋的 Acorn Computers 贏得合約，BBC Micro 成為一代英國人的電腦啟蒙機——**這是一場由公共媒體驅動的資訊教育運動**，與同期美國的 Apple II 進校園運動相映成趣。

Acorn 的工程師（Sophie Wilson 設計指令集、Steve Furber 負責硬體）在設計 BBC Micro 時發現：市面上沒有合用的 CPU（6502 太弱、16 位元晶片太貴），於是決定自己造。

## 二、窮困逼出的天才設計

1983 年，Acorn 開發 ARM1（Acorn RISC Machine）。他們的資源窘迫到誇張的程度：整個硬體團隊只有 Steve Furber 與幾位實習生，設計工具是一張**紙**——工程師用麥克筆在紙上畫邏輯，再打孔驗證。沒錢買先進製程，只能用 Acorn 1985 年找得到的 3μm 製程（同時期 Intel 386 用 1.5μm）。

窮困逼出了三個影響深遠的設計決策：

1. **極簡 RISC**：ARM1 只有 **25,000 電晶體**（同代 386 是 275,000），面積小一半以上，自然省電、便宜；
2. **條件執行（conditional execution）**：每條指令帶 4 位元條件碼，減少分支——既是補償早期管線的簡陋，也成為 ARM 指令集的招牌；
3. **低功耗作為「被迫的選擇」**：沒有先進製程與散熱預算，就把「每瓦效能」刻進基因。**這個「缺陷」在十五年後成為它統治世界的超能力。**

1985 年，Acorn 的員工測試 ARM1 時發現功耗低到可以**直接用漏電供電**——這個插曲成為 ARM 史的傳奇註腳：低功耗不是目標，是意外，而這個意外恰好撞上時代的未來。

## 三、蘋果的救命錢與「不賣晶片賣藍圖」

1990 年，Acorn 的 ARM 部門、蘋果（想做 Newton 掌上型電腦，需要低功耗 CPU）與 VLSI Technology 合資成立 **ARM Ltd.**。蘋果的投資救了這家瀕臨破產的公司——歷史在此埋下 30 年後蘋果自研晶片（M1 也基於 ARM 架構）的伏筆。

新公司做出商業史上最重要的決策之一：**ARM 自己不製造晶片，只設計核心架構，以 IP 授權方式賣給所有晶片公司**（詳見 8.2）。這個模式與當時所有半導體公司（自己設計自己造）完全相反。

## 四、為什麼 RISC 天生適合行動裝置？

把第七章的低功耗工程需求與 ARM 的基因對照：

| 行動裝置的需求 | ARM 的天生特質 |
|----------------|----------------|
| 電池續航 | 小面積 + 簡單邏輯 = 低動態與漏電功耗 |
| 成本敏感 | 極少電晶體，授權費低，可內嵌於 SoC |
| 單晶片整合（SoC） | 核心小 → 同一晶片可塞 GPU、數據機、NPU |
| 效能需求適中 | RISC 管線簡單即可達標，無需亂序豪賭 |
| 生態多元 | 架構授權 → 數百家廠商各自特化 |

反觀 x86：亂序引擎、深管線、複雜譯碼——這些在桌上型是效能利器，在手機上是**功耗災難**。Intel 不是沒試過（StrongARM 來自收購 DEC 的設計、XScale 亦售出），而是它的商業模式（高毛利桌上型 CPU + 自有晶圓廠）無法接受行動晶片「單價 5–20 美元、毛利低、量再大也薄利」的現實。**2006 年 Intel 把 XScale 賣給 Marvell，正式退出手機戰場——這一步退讓，讓出了二十年的王座。**

## 五、文化與制度的餘韻

- **英國的工程文化**：Acorn 團隊的自嘲式幽默（ARM1 的測試矩陣印著 "VERBATIM" 與工程師簽名）與「用最少的資源做最聰明的事」，成為英式工程的標誌；
- **ARM 命名的軼事**：原名 Acorn RISC Machine，因 Acorn 商標問題改名，遂取 "Advanced RISC Machine"——一個因命名法務而誕生的官方縮寫；
- **劍橋與矽谷的對照**：矽谷靠創投與規模取勝，劍橋靠節儉與巧思——ARM 的成功證明：**在科技史中，資源劣勢有時反而孕育出最適配未來的設計**。

> **歷史因果鏈**：BBC 教育計畫 → Acorn 自研 CPU → 窮困逼出極簡低功耗 RISC → 蘋果注資成立 ARM Ltd. → 授權模式（下一節）→ 行動時代降臨，低功耗基因變成王座。一隻英國蜜蜂的逆襲，即將展開。
