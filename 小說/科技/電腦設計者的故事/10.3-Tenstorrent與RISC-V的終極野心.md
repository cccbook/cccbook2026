# 節標題：Tenstorrent 與 RISC-V 的終極野心

二○二一年，Jim Keller 悄悄加入一家新創公司 Tenstorrent 擔任技術長；二○二三年一月，他坐上執行長位置。這是他職涯第一次從「架構天才」變成「公司意志」。此前的他，習慣在大公司內部推播（Apple、AMD、Intel），這一次他要直接向資本市場與整個半導體秩序挑戰——用 RISC-V 加自研向量引擎，同時開打三個戰場。

## Keller 的終極拼圖

Keller 說自己一生的訓練都指向一個問題：「運算的未來形態是什麼？」他自己給的答案在 Tenstorrent 落地為兩條產品線：一是自研 RISC-V CPU 核心（Tensix core，內建向量引擎與矩陣運算單元），搭成 Wormhole（2023）、Blackhole（2024）等 AI 加速器晶片；二是 Galaxy 系列的多晶片 systems——把數百個核心透過乙太網路互連拼成大型運算叢集，走「以多打大」的路線，不追求單晶片 SuperScale。他常說 Tenstorrent 相對 NVIDIA 的差異策略是「晶片沒有那麼大，但系統更靈活，價格更好」——不走 HBM 巨獸路線，用開源軟體棧與 RISC-V 降低整體總成本。同時 Tenstorrent 也賣 IP：授權自家 RISC-V CPU 核心與設計服務，這一條腿對沖了 AI 晶片戰場的高風險。二○二三年，公司以約六億美元估值募得 D 輪資金，投資方包括三星、Hyundai 汽車（據信投入 Hyundai 下世代車載晶片的機會視窗）與 LG；二○二四年又獲美國商務部 CHIPS 補助與 LG 對 Galaxy 系列的採購協議。局面正在由「法人投機」轉向「戰略夥伴」。

## RISC-V 的誕生：伯克利的精神火種

RISC-V 的立足點是一種制度性選擇——開放。二○一○年前後，UC Berkeley 的 Krste Asanović、David Patterson 與研究生 Yunsup Lee、Andrew Waterman 在實驗室裡開始打造一套**免授權費、完全開源**的指令集架構（ISA），命名 RISC-V，意指「第五代 RISC」——延續 1980 年代伯克利 RISC 的學術血統。2015 年成立的 RISC-V Foundation（後更名 RISC-V International）將 ISA 作為公共財管理，成員公司各自發展核心設計，誰也不壟斷 ISA 本身。這個模式的歷史意義在於：x86 的設計權力被 Intel 與 AMD 鎖死，ARM 則以授權費與權利金抽成，而 RISC-V 是首度在「晶片 ISA」層面徹底開放。它的政治意涵很快被大國看到——中國企業（如阿里平頭哥）推出玄鐵系列 RISC-V 核心，印度政府資助的計畫以 RISC-V 打造本土晶片；歐洲也把它列為主權晶片政策的一個選項。RISC-V International 更因美國出口管制的政治壓力，於 2020 年遷址瑞士，一度成為地緣政治的新聞標的。Asanović 後來創立 SiFive，成為 RISC-V 商業生態的先行者；Patterson 則以《計算機組織與設計》的 RISC-V 版本塑造了下一代工程師，並因此獲得圖靈獎。他曾半開玩笑：「在我們的年代，RISC 是一個學術理論；今天，它是各國戰略晶片的主權指令集。」

## 開源 ISA 的制度性衝擊：商業模式革命

RISC-V 對壟斷的挑戰，本質是**商業模式**的革命。傳統難以撼動 ARM 或 x86 授權費模式，因為 ISA 由個別公司私有（x86 只有 Intel/AMD 能設計 ARM 授權採用世代性 稅）。RISC-V 把「買 ISA 授權」變成「自由使用 ISA，花錢買 IP 或晶片」。Keller 的商業算盤很直接：

```mermaid
flowchart LR
    subgraph 舊世界
    A1[ARM 授權費 / x86 門戶] --> A2[等於給架構稅]
    A1 --> A2b[生態被封閉]
    end
    subgraph RISC-V 世界
    B1[免費開放 ISA] --> B2[各家自研核心 或買 Tenstorrent IP]
    B2 --> B3[賣晶片賣系統賣設計服務獲利]
    B3 --> B4[軟體棧開源\nTT-Metalium 等]
    end
    舊世界 -.對比.-> RISC-V 世界
```

> Keller 語錄：「賣架構授權費是十九世紀的地租模型；賣晶片與 IP 才是二十一世紀的生意。」

## 為張量而生的新架構：戰略與風險

Keller 押注的第一個賭局技術上是「資料流」——Tenstorrent 的晶片在架構上強調「以張量為中心」的傳播數流，而非傳統矩陣乘法 + GPU 排程。這條路如果成功，就是 AI 晶片從「GPU 通用計算」轉向「專用 AI 架構」的下一次典範移轉；但這條路的風險也巨大——與其說 NVIDIA 有 CUDA 三層生態，不如說「軟體工程師重寫一整層」的成本才是 Tenstorrent 賣不動的真正原因。軟體棧（TT-Metalium、TT-NN）開源甚至推出開源的 Tensix 微架構白皮書，都是為了降低遷移心理成本。更大的風險是資本環境：AI 晶片已內捲到 Cerebras、Groq、Graphcore、Sambanova 等項目都在薄冰上奔跑，Tenstorrent 是少數在 AI 加速器 + 開源 ISA + 商業 IP 三條腿同時站立的公司。

## 浪人的最後一站？

Keller 已年逾六十，卻在 Tenstorrent 做他一生最激進的一件事。有人問他為何還要再戰一局，他的回答一貫務實中帶著工程師的窄心：

> 「因為這件事還沒有做好。我自己三十年前就知道該怎麼做了，只是還沒找到一個組織讓我去完成。」

從 DEC 的 Alpha，到 AMD 的 Zen，到蘋果的 iPhone 心臟，特斯拉的方向盤，這位 CPU 浪人最終落腳在 RISC-V。如果說黃仁勳的歷史地位是用資本與生態把 GPU 煉成 AI 的通用載體，那麼 Jim Keller 想寫下的下一章則是：用一套開放的指令集、一個簡潔的架構，把運算從帝國手中解放回工程師與國家手上。歷史會不會如他所願？沒人知道。但至少他知道自己在哪裡——在白板前，拿著原子筆，刪掉那些不必要的複雜度。
