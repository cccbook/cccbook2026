# 3.2 網際網路與 GNU/Linux 的世紀大結合：補齊 GNU 缺少的最後一顆核心

## 兩半拼圖的命運交會

1990 年代初，自由軟體運動最關鍵的事實是：**GNU 差一塊，Linux 差一堆**。

- **GNU**：有完整的工具鏈（Emacs、GCC、Bash、Utilities……）卻**沒有核心**——自家的 Hurd 微核心因技術複雜（Mach + 使用者空間服務器架構）而多年難產；
- **Linux**：有 0.11/0.12 版的核心，卻**幾乎什麼用戶工具都沒有**。

1992 年初，這兩半拼圖相遇。Linux 核心從一開始就設計為可搭配 GNU 工具（編譯用 GCC、目標符合 POSIX），而 GNU 系統裝上 Linux 核心後**立即成為一個完整可用的自由作業系統**——史稱 **GNU/Linux**（FSF 力主的稱呼；多數人則簡稱 Linux）。

## 為什麼是 Linux 補位，而非 Hurd？

技術史在此給出一個殘酷而深刻的答案：

| | GNU Hurd（微核心） | Linux（單體核心） |
|---|---|---|
| 設計 | 理論優雅：Mach + 使用者空間服務器 | 實務直接：一切在核心空間 |
| 難度 | 訊息傳遞、效能與鎖的複雜度極高 | 簡單直接，初學者能看懂 |
| 協作 | 架構門檻高，難以吸引群體貢獻 | 任何會 C 的人都能寫驅動 |
| 結果 | 到 2020 年代仍不夠成熟 | 1991–94 年高速演進 |

**「簡單勝過優雅」**是 Linux 席捲一切的原因之一——但更深的原因是協作模式：Linux 的單體核心雖然「不夠美」，但其可理解的結構讓千萬人可以同時打補丁。這是網路時代的開發美學：**出貨勝過完美**（下一節 Raymond 將把這個現象理論化）。

RMS 日後數次坦言：Hurd 的失敗是 GNU 計畫最大的戰略挫敗——「我們太追逐漂亮，Linux 只是先可用」。

## 1992–1994：從玩具到生態

三股力量的匯流，使 GNU/Linux 三年內從愛好者玩具變成真實生態：

1. **GNU 工具鏈補位**：GCC/bash/coreutils 上 Linux，系統開箱即用；
2. **X Window System 上 Linux（1992）**：圖形介面到來，1993–94 年 XFree86 的 Linux 移植引爆桌面探索潮；
3. **發行版（distribution）的誕生**：
   - 1992 年 MCC Interim Linux（曼徹斯特，最早的發行版之一）；
   - 1992 年 SLS（Softlanding Linux System）；
   - 1993 年 Slackware（Patrick Volkerding，最古老的存活發行版）與 Debian（Ian Murdock 創立，以社群自治與嚴謹品管聞名）；
   - 1994 年 Red Hat（Bob Young 與 Marc Ewing，日後商業化的主力）。

每個發行版本質上是「**核心 + GNU 使用者空間 + 打包安裝器**」的組裝工廠——**作業系統從一個產品，變成一條由社群主導的供應鏈**。

## 1994 年 3 月 14 日：Linux 1.0

**1994 年 3 月**，Linux 正式發布 1.0 版（約 17 萬行程式碼），支援 TCP/IP、多硬體平台。同年 1.0 發表已出現贊助廠商——**三年內，從 BBS 玩笑到大學與公司的正式選項**。

## 網際網路：開源的第一個基礎設施

Linux 的爆發證明了一件空前的工程事實：**一個由網際網路協調、無商業合約、無中心管理的志願者網路，可以寫出品質達到生產等級的系統軟體**。支撐它的四個技術條件：

1. **Usenet 與郵件列表**：協調與溝通的公共場所；
2. **CVS 等版本控制（1990s）**：多人改碼的組織工具（雖然當時仍是集中式，與日後 Git 有本質差別）；
3. **FTP／匿名下載**：0.01 版以「任何人抓」的方式散布——**下載即參與**；
4. **GNU GPL**：法律架構讓數千名自主貢獻者的工作可以合法堆疊而不互相污染。

## 政治與經濟的潮汐

1990 年代的社會脈絡同樣關鍵：

- **教育擴散**：全世界的資工系都在找廉價的 UNIX 替代品——學生宿舍裡的 386 PC 是 Linux 的溫床（Ken Thompson 的 UNIX 文化透過 Tanenbaum 的教科書轉譯成為母語）；
- **伺服器市場的缺口**：專有 UNIX（Sun/Solaris、HP-UX、AIX）以工作站與小型機的高價壟斷，Linux + 便宜的 x86 硬體以「夠用的一小時十分之一價格」從下方顛覆——**克里斯坦森的低端破壞理論的教科書案例**；
- **網際網路的爆發**（1995 Netscape、dot-com 狂潮）：Web 伺服器需要廉價、穩定、可客製的系統——這個需求爆炸與 Linux 的供給崛起精準同步。

## 小結

GNU 提供了物資，Linux 提供了引擎，網際網路提供了神經系統。1992 年的結合不只是技術補位，更是一場社會實驗的勝利：**共享的生產方式成功了**。下一節，一本小冊子將把這場成功翻譯成矽谷的政治語言，成為進入商業世界的通行證——《大教堂與集市》。
