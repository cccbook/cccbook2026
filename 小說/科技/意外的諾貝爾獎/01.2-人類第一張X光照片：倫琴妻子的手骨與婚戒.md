# 人類第一張X光照片：倫琴妻子的手骨與婚戒

一八九五年十二月二十二日，倫琴終於做了一件事：他把妻子安娜．貝莎（Anna Bertha）帶進實驗室。這位與他同甘共苦多年的伴侶，被請把手放上塗有感光乳劑的玻璃底板，暴露在自家裝置發出的未知射線之下。數分鐘後顯影完成，玻璃片上浮出一幅前所未見的圖像：五指的骨骼清晰可辨，無名指上那枚金婚戒的陰影環繞指骨，像一個小小的光合環。

安娜的反應被後世反覆引用——她驚呼：「我看到了自己的死。」（Ich habe mein Todesurteil gesehen.）這句話的重要性遠超一則軼聞：它說明在第一時間，人們就本能地把 X 光與「看見身體內部」、進而與死亡連結。骨頭歷來只能屬於墳墓與解剖臺，如今卻活生生印在眼前，維多利亞時代的人感到的恐怕不只是驚奇，還有一種身體被窺破的不安。

## 一則維也納新聞引爆世界

倫琴本想守住低調，但他把論文連同照片寄給了各地同行，其中包括維也納的舊識——舒格特（Franz Sigmund Exner）等物理學家。1896 年 1 月 5 日，維也納《新自由報》（Die Presse／Neue Freie Presse）刊出報導，標題語帶驚悚：〈驚人的發現〉。報導者埃格哈特（Egbert Hiederhausen 之類的筆名傳聞）據說正是經由倫琴在維也納的朋友圈取得消息。新聞以電報速度傳遍歐洲與美洲，報紙爭相轉載，《紐約時報》等很快跟進，倫琴一夜之間從沉默的教授變成全球聞人。

一八九六年一月二十三日，倫琴打破隔絕，在維爾茨堡物理—醫學學會做了此生唯一一次關於 X 射線的公開演講。演講結束時，他邀請年邁的解剖學家克立克（Rudolf Albert von Kölliker）上前，當眾為老人的手拍下 X 光片，隨即顯影。克立克看完自己手骨的影像，當場高呼：「萬歲！倫琴先生！」（Es lebe die Wissenschaft! 之類的讚辭由此傳開。）醫學界與物理學界在同一張照片上達成共識：物理學的儀器，從此可以為醫學所用。

## 狂熱、恐慌與亂象

隨之而來的是一場席捲大眾文化的風暴。倫敦的商人火速推出「X 光防護內衣」，聲稱可免遭紳士用 X 射線偷窺紳士淑女的身體；婦女報刊上流傳「透視服」的焦慮，彷彿身體在這種光線下已無隱私可言；紐約報紙刊登的諷刺漫畫裡，連律師都想用 X 光看透法庭對手的心思；咖啡館流傳的笑話則是：店家用「X 光檢視」客人皮包裡的鈔票。截至目前尚待考證的種種傳聞之外，確鑿的亂象是：早期商用 X 光毫無劑量概念而言，理髮師、鞋匠與江湖郎中用裸管「透視」顧客的腳與頭骨，號稱能看病；操作者長期暴露，陸續出現皮膚灼傷、潰瘍與癌症，成為第一批輻射傷害的受害者。「Round advances」式的巡迴展覽把 X 光當作嘉年華奇觀在大城市巡演，儀器在民眾排隊下日夜運轉。

## 醫學的第一批救命案例

恐慌之外，真正改變歷史的是臨床。一八九六年一月，倫琴的助手已為醫院測試骨骼影像；同年英國的利物浦、曼徹斯特，德國的各外科診所，迅速用 X 光為骨折複位、為槍傷與異物定位。著名案例之一：一名傷者體內的異物（縫入皮肉的針與子彈）在 X 光下現形，使手術從盲探改為導航。戰場上，一八九六年之後希臘—土耳其戰爭等衝突中，X 光車已被開赴前線。外科醫生第一次不用開膛即可「看見」，診斷由推測變成影像——循證醫學的地基，就從這張婚戒與手骨的照片開始。

回頭看，安娜那聲驚呼彷彿一語成讖：X 光既能救命，也能傷人。人類與游離輻射的漫長周旋，從那一夜起才真正開始。
