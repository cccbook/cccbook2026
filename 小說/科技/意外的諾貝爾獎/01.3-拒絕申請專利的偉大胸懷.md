# 拒絕申請專利的偉大胸懷

一八九六年的頭幾個星期，倫琴的信箱被海外各地湧來的信件塞滿：公爵與外科醫生、企業與報社、想臨床試用 X 光的醫院與想量產放電管的儀器商。到三月，他已收到五十多封信函，內容尋求合作、洽談授權、請求指導。商業的嗅覺如此靈敏，一份倫琴式專利幾乎可說唾手可得——放電管已是成熟商品，加上一紙方法專利，足可坐收全世界每一張 X 光片的權利金。

然而倫琴的選擇，以他自己的話說，是他「應該不受任何約束地公之於眾」：X 射線的發現與使用方式，應當毫無保留地屬於全人類。他不申請專利，不與儀器商簽約，不收取任何授權費。他在給同行的回信中親筆描繪自己的實驗細節，甚至寄出自己手工製作的 X 光照片，讓任何人可以照圖重做。

## 榮譽找上門來

這種無私反而提升了他的地位。德皇威廉二世親自召見，授予二等紅鷹勳章，聲望更上層樓；一九○○年倫琴轉任慕尼黑大學物理研究所所長；而在維爾茨堡，他早已被聘為物理研究所所長與終身教授，一八九四年出任該校校長。帝國的授勳邏輯十分清楚：把「德國科學的榮光」具象化在一個德國人身上，既是獎賞，也是宣傳——俾斯麥之後的德意志帝國，正以科學與技術作為國家競爭力的名片。

一九○一年他獲首屆諾貝爾物理學獎，獎金五萬瑞典克朗。他又做了一個出人意料的決定：把全部獎金捐給母校——他早年求學的蘇黎世與他任教最久的維爾茨堡大學（以及巴塞爾）充作科學基金，自己分文不留。他晚年立下的遺囑同樣低調：把論文與信件盡數焚毀，彷彿要連同他一生的方式一起，不讓後人代作文章；僅留下寥寥數語交代後事，於一九二三年死於腸癌。

## 對照：專利大戰的年代

倫琴的選擇之所以特殊，須放到同時代的背景上看。十九世紀末正是專利訴訟的全盛期：愛迪生與西屋為交流電、燈泡與電影放映機在美國打著曠日費時的官司，發明家的身分日益與「占有一項方法」綁定；德國的化學工業（拜耳、巴斯夫）以染料專利在世界市場攻城略地，把實驗室成果轉化為壟斷利潤的制度已臻成熟。在這樣的氣氛中，倫琴把「可能值數百萬的權利」扔進公共領域，等於逆著時代的大潮而行。

結果令人意外地證明這是對的：因為人人可用，X 光以極快的速度擴散到全世界的醫院、戰場與實驗室，骨折與異物定位馬上成為例行，戰地醫療的面貌為之改觀，救命的關鍵正在於「無私」。倫琴的判斷很清楚：一項診斷技術，壟斷遠比開放昂貴——它救命的規模，才是發現的真正價值。

## 留下的名字

一九二八年，國際輻射單位委員會把 X 射線與 γ 射線的照射量單位定為「倫琴」（roentgen, $R$），定義為在標準狀況下使一立方厘米乾燥空氣產生一靜電單位離子對的照射量——以一個人的姓氏作為物理量的單位，是科學界能給的近乎最高的紀念。J. J. Thomson 的評語是：X 光「開啟了物理學上的新時代」；的確，這束穿過黑色卡紙的光，照亮了貝克勒爾的鈾鹽、居禮的鐳，以及二十世紀整座輻射物理的殿堂。
