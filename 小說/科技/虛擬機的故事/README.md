# 《虛擬機的故事：從 IBM 大型機的幻覺、x86 的艱難破解到雲端運算與 MicroVM 革命》

> 虛擬機從來不只是「軟體模擬硬體」，它是計算機科學中最精妙的**幻覺藝術**——
> 用程式碼在矽晶片之上創造出無數個獨立的平行世界，讓每一套作業系統都相信自己獨佔了整台機器。
>
> 本書以**歷史演進與隔離範式轉移**為主軸，記錄人類如何從 1960 年代 IBM 大型機的創世紀，
> 走過 x86「不可虛擬化」的絕望死局、VMware 的二進制動態翻譯神操作，
> 經歷硬體輔助虛擬化革命、雲端運算大戰，直到當代的 MicroVM、容器化與 AI 雲端虛擬化新紀元。

### 💡 本書亮點

1. **完整穿透技術演進史**：CP-40 → x86「不可虛擬化」斷言 → VMware 二進制動態翻譯（DBT）破局 → 晶片級硬體輔助（VT-x）→ 雲端 AWS EC2 → 容器與 MicroVM（Firecracker）→ 機密運算與 AI GPU 虛擬化。
2. **直擊技術核心痛點**：特權指令陷阱、動態二進制翻譯、影子頁表、硬體輔助虛擬化、MicroVM 冷啟動優化……全部以歷史故事與圖解拆解。
3. **跨領域驅動關係**：每篇皆討論科技、經濟、制度、文化、政治與教育如何互相驅動虛擬化的演進。
4. **結構嚴謹**：全書 10 章，每章 3 個深度小節，共 30 篇，皆為真實歷史事件。
