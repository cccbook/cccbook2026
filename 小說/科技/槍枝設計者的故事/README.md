# 《槍枝設計者的故事：從黑火藥燧發、米尼彈線膛、自動閉鎖到卡拉什尼柯夫與現代模組化槍族》

> 一本專為輕兵器工程師、軍事歷史愛好者、機械結構專家與全球工業文明觀察者設計的專題目錄。
