# 亞里士多德四元素說：壓倒原子論的千年權威

## 從柏拉圖學園走出來的體系家

亞里士多德（Aristotle，前 384–前 322）生於馬其頓的斯塔吉拉，父親是宮廷醫師，這使得他一生都對「可觀察、可分類的生物與實物」懷有醫家式的親近。他在柏拉圖學園求學二十年，卻逐漸與老師分道：柏拉圖把真實放在永恆的理念之中，可感世界只是影子；亞里士多德則反轉過來——形式不離個別事物而存在，知識必須從觀察經驗入手。正因這副經驗主義的嘴臉，他其實比柏拉圖更接近「科學」，但他在物質結構上的結論，卻頑固地站到了德謨克利特的對面。

## 四元素、四性質與「第五元素」

在《物理學》《論天》《論生成與毀滅》中，亞里士多德搭建了一個優雅到令千年學者難以割捨的體系。地上的萬物由四種元素構成：火、土、水、氣；它們由兩對基本「性質」——熱與冷、乾與濕——兩兩結合而成：

- 火 = 熱 + 乾
- 土 = 冷 + 乾
- 水 = 冷 + 濕
- 氣 = 熱 + 濕

性質是主動的原則，元素之間可以互相轉化：把水的濕換成乾，就得到土；這正是古代煉金術「轉換金屬」夢想的理論溫床。天空則由神聖不朽的第五元素「以太」（αἰθήρ）構成，作完美的圓周運動。

在這個連續的、性質可以互相滲透的宇宙裡，沒有留給原子與虛空的位置。亞里士多德一一反駁原子論的論證堪稱教科書式的凌厲：

1. **運動需要連續的介質**。若虛空中沒有阻力，一物在其中運動將瞬間完成（速度無限），這顯然荒謬，故虛空不可能存在。
2. **「自然懼怕真空」（horror vacui）**。抽掉水，周圍的物質會立刻擠進來填補，可見自然界不容許空隙。
3. **不可分的原子若真無部分，則無形狀與大小可言**；若有部分，便可再分，自相矛盾。
4. 同一物質的連續性可用實驗訴諸直觀：感官告訴我們水與空氣「接連不斷」，何須假設看不見的顆粒？

他勝在方法：亞里士多德用語言邏輯與常識經驗作戰，而德謨克利特提出的所有證據都依賴不可見之物。在沒有氣壓計與顯微鏡的時代，前者天然占上風。

## 經院哲學：權威如何被制度鑄造

如果亞里士多德只是另一位希臘哲人，四元素說也會與原子論一樣在漫長的中世紀裡沉浮。決定性的是十二、十三世紀的知識制度革命：十字軍與西班牙的翻譯學派把亞氏全集從阿拉伯文譯回拉丁文，湧入新興的歐洲大學（波隆那、巴黎、牛津）。托馬斯·阿奎那（Thomas Aquinas，1225–1274）以驚人的系統工程把亞里士多德哲學與基督教神學熔為一體：上帝是「第一推動者」，天體由以太推動，自然秩序即理性的階梯。1277 年巴黎主教的譴責案後，教會審查反而確認了經亞奎那調和的亞氏體系為正統。

於是自然哲學成為大學文科七藝（liberal arts）與藝學院課綱的骨幹：學生必須逐卷誦讀亞氏的《物理學》《論天》《氣象學》，以「裝訂問題」（quaestio）形式的辯論訓練畢業，方可晉身醫學、法律或神學。德謨克利特的文本則早已佚盡——沒有一部原子論著作被納入任何大學課表。知識的勝負第一次不是由論證優劣決定，而是由「誰的書在課綱上」決定。這是教育—宗教—政治權力合鑄知識正統的經典案例：教會好惡、大學課程、書籍抄寫經濟、拉丁學界的行話共同體，四者咬合成一台千年運轉的權威機器。

## 千年權威的第一道裂縫：真空的實測

裂縫來自一個樸素的工程問題。十六世紀義大利礦區的工程師發現，最好的薩沃納或佛羅倫斯水泵，無論唧筒多麼完善，水最多只能吸到約十米高，於是有人問伽利略（Galileo）：「自然是這樣懼怕真空嗎？」伽利略坦然承認他不明白為何極限恰在此處——他半開玩笑地猜是某種看不見的「真空的阻力」。1643 年，他的學生托里拆利（Evangelista Torricelli，1608–1647）做了那個改變科學史的實驗：將灌滿水銀的玻璃管倒插入水銀槽，管內水銀下降到約 760 毫米處停住，管頂留出一段以前亞里士多德派所認為「不可能存在」的真空。空隙已在管頂形成——這正是亞里士多德主義者判定「不可能存在」的真空。托里拆利推論：支撐水銀柱的不是虛空的「吸力」，而是大氣的重量。——同一緯度氣壓相同故水銀柱等高；山上海拔更高、空氣更稀薄，水銀柱應更矮（此點於 1647 年由帕斯卡的姐夫佩里耶在多姆山實測證實）。

「自然懼怕真空」至此被一截水銀柱擊穿。千年權威並未被推翻——它仍統治著大學——但人們第一次帶著儀器、氣壓與數字，而不是《物理學》引經據典，進入了物質結構的辯論場。原子論的復興，正等在下一位讀過伽利略的人手中。
