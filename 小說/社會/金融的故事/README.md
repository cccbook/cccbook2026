# 金融的故事

**——從泥板上的大麥到 AI 決策的五千年**

> 金融不是發明出來的，而是長出來的：神廟書吏在泥板上記下大麥的借貸、義大利商人發明匯票、荷蘭人賣出第一張股票、英國人為戰爭發行國債、美國人在梧桐樹下握手、眾人把黃金窗口關上、數學家為風險寫出公式、工程師把信任寫成程式——直到今天，AI 開始替人類「判斷」。本書以真實歷史為軸，拆解金融技術、經濟、制度、政治與思想的驅動力，以及每一次危機背後的「制度發明」。
