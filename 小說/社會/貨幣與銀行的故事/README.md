# 貨幣與銀行的故事

**——從貝殼、黃金到位元組的信用史詩**

> 貨幣比鑄幣早了兩千年，銀行比央行早了兩千年，紙幣比歐洲早了六百年。本書跨越五千年：神廟的金庫與泥板上的借據、呂底亞的獅頭金幣、羅馬錢莊的擠兌、宋朝的交子、聖殿騎士團的匯兌、麥第奇的分行、阿姆斯特丹的帳本、英格蘭銀行的國債、牛頓的定價、加州的黃金、摩根的鎖門、聯準會的誕生、布雷頓森林的協定、尼克森的關窗、塑膠卡的革命、SWIFT 的電文、量化寬鬆的印鈔機，直到比特幣的創世區塊。每一章都拆解技術、經濟、制度、政治與思想如何互相驅動——以及「陌生人們對一份共同帳本的相信」如何一次次被建立、濫用與重建。
