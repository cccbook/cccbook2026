# 會計的故事

**——從記帳石子到數位時代的信用密碼**

> 會計不是枯燥的借貸規則，而是人類文明最古老的信任工程：從公元前 8000 年的黏土籌碼，到 1340 年的熱那亞帳簿、1494 年的帕喬利教科書、1720 年的南海泡沫、1929 年的大崩盤、2001 年的安隆塌陷，再到區塊鏈與 AI 時代的帳簿革命。本書以真實歷史為軸，追蹤每一次記帳技術升級背後的科技、經濟、政治與思想驅動力。

## 本書特色

1. **史實優先**：庫辛泥板、施曼特-貝瑟拉的籌碼研究、1340 熱那亞帳簿、帕喬利《Summa》、安隆重述、SOX 條款號碼——皆為可考據的真實歷史。
2. **因果結構**：每節以「前因 → 制度設計 → 後果」展開，附 Mermaid 圖呈現科技、經濟、政治、思想的互相驅動。
3. **一條主線**：「在上一層之上再架一層核對」——封印、複式、審計、GAAP、監管、區塊鏈，三千年遞歸。
4. **格式**：GitHub-flavored Markdown，含 Mermaid 圖。
