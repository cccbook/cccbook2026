# 金融詐欺的故事

**——從鑿沉的商船到 FTX 的 Slack 私訊**

> 金融詐欺不是現代病，而是與金融同年齡的寄生蟲：雅典商人鑿沉自己的船騙取保險借款、宋朝偽鈔氾濫、南海議員收股受賄、龐氏用後來者的本金付先來者的利息、安然把虧損藏進表外、麥道夫三十年不交易、Wirecard 的十九億歐元只是掃描的 PDF、FTX 直接挪用八百萬用戶的資產。本書以真實案例為軸，拆解每場詐欺的技術、會計、法律與心理結構——以及每一次崩塌之後的「制度進化」。
