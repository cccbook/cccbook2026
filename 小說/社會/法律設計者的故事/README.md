# 法律設計者的故事

**——從漢摩拉比石碑、大憲章、拿破崙法典到 Code is Law 的三千年制度工程史**

> 法律從來不是枯燥的死法條，而是歷史上最頂尖的天才、偏執狂、理想主義者與野心家，在權力鬥爭與社會崩潰邊緣，用文字與邏輯搭建起來的「人類規則系統」。本書以傳奇法律設計者為主角，按年代軸追蹤每一次制度發明的前因後果——科技、經濟、文化、政治與思想如何互相驅動。所有事件、名言與判例皆基於真實歷史。

## 本書特色

1. **史實優先**：所有事件、條款、判例與名言皆為可考據的真實歷史（Loomis 案、The DAO、Olmstead 異議、蘭尼米德、聯邦黨人文集……）。
2. **人物驅動**：不條列法條，聚焦設計者的性格、處境與抉擇——從漢摩拉比的霸總工程到萊斯格的駭客行動。
3. **因果網絡**：每節附 mermaid 時間線或因果圖，呈現科技、經濟、制度、文化、政治、思想、教育的互相驅動。
4. **格式**：GitHub-flavored Markdown，含 Mermaid 圖與少量 LaTeX 適用情境。
