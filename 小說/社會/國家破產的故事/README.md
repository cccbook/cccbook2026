# 國家破產的故事

**——從帝國毀滅到債務帝國的終局**

> 國家破產不是新聞，而是人類兩千三百年的老習慣：尼祿把銀幣摻銅、元朝把紙鈔印爆、腓力二世三次賴帳、路易十六被帳單送上斷頭臺、威瑪以兆為單位買麵包、阿根廷九度違約、斯里蘭卡的總統府被民眾佔領。本書以真實歷史為軸，拆解主權債務危機的科技、經濟、政治與思想驅動力——以及每一次「從破產到重建」的制度發明。

## 本書特色

1. **史實優先**：銀幣含銀量計量、1340 前後的債轉 juros、威瑪匯率節點、1982 年 8 月 12 日、PSI 減記比例、漢班托塔租約——皆為可考據的真實歷史。
2. **破產的五種形態**：稀釋、重組、違約、轉嫁、執行——全書以這五種工具的演化為主線。
3. **因果結構**：每節「前因 → 危機 → 制度後果」＋ Mermaid 時間線，串聯科技、經濟、政治、思想驅動。
4. **跨書連結**：與《會計的故事》（審計、GAAP）及《法律設計者的故事》（漢密爾頓、禿鷹基金司法戰）互相呼應。
