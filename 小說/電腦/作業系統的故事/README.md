# 《作業系統的故事：從機械開關、UNIX 烏托邦、Linux 傳奇到雲端與 AI 時代的核心演化史》

> 一本為系統架構師、作業系統核心開發者、資工系學生與科技史愛好者而寫的專題書。
>
> 「作業系統」從來不只是開機時看到的桌面或指令視窗，它是**人類在複雜硬體之上構建的「數位國度憲法與權力分配中樞」**。本書以**歷史演進與核心抽象範式轉移**為主軸，記錄人類如何從打孔卡批次運作、分時共用系統，走過 UNIX 的美學統一、Minix 與 Linux 的開源對決，經歷微核心與宏核心的架構之爭，直到當代的行動端 OS、容器化核心，以及迎向 AI 異質運算與分散式作業系統的新紀元。

## 💡 本目錄亮點

1. **完整穿透歷史時間軸**：早期批次處理與分時系統 → UNIX 哲學與 BSD → Minix 與 Linux 宏核心/微核心世紀之爭 → 行程與記憶體管理底層 → 行動端 OS（Android/iOS）→ 雲原生與 AI 異質算力作業系統。
2. **直擊 OS 三大核心支柱**：深刻剖析「處理器調度（CPU Scheduling）」、「記憶體管理（Memory Management）」與「檔案/I/O 系統（File & I/O Systems）」的底層運作邏輯。
3. **多維因果敘事**：每章皆交織**科技 × 經濟 × 法律 × 政治 × 文化 × 教育**的驅動關係——從 1956 反壟斷判決到歐盟 DMA，從貝爾實驗室的官僚縫隙到赫爾辛基的宿舍網線。
4. **結構嚴謹**：全書 10 章，每章 3 個深度小節，另含前言與結語；全文採 GitHub Markdown，配以 mermaid 圖表與 LaTeX 式表述。
