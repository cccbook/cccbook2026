# 前言：矽晶片上的憲法——作業系統如何將冰冷硬體化為有序的數位世界

## 一個日常瞬間的深度

你在手機上打開一則訊息、切換到相簿、再回到瀏覽器，全程不到三秒。在這三秒裡，作業系統完成了數百次 CPU 排程切換、數十次記憶體頁面的分配與回收、數百次電池與 CPU 頻率的能效判斷、以及對每一個 App 資料邊界的沙盒檢查——而你完全無感。

無感，正是作業系統最偉大的成就，也是最深的誤解來源。我們說它「隱形」，其實它無所不在：**它是人類在複雜硬體之上構建的「數位國度憲法與權力分配中樞」**——它規定行程（公民）能做什麼（系統呼叫）、不能做什麼（保護環與沙盒）、何時存在、何時消失、資源歸誰、依何種秩序交換。硬體是土地與礦藏，作業系統是土地法、戶政系統與資源分配機制的總和。

## 全書的敘事軸承：一部憲法經驗史

本書以**歷史演進與核心抽象範式轉移**為主軸，講述這部「矽晶片上的憲法」如何在七十年間起草、動搖、修訂與轉世。每一章都包含三個洞察層次：

**技術層**：緩衝區、分段、PCB、MLFQ、CoW、cgroups——每個抽象都會講清楚它的「數學骨架」；
**歷史層**：誰在什麼機器上、為什麼什麼而造——ENIAC 的六位女性計算員、Multics 的廢墟、赫爾辛基的 4MB 記憶體 386；
**制度層**：**科技、經濟、法律、政治、文化如何互相驅動**——1956 年反壟斷判決意外催生了 UNIX 的自由擴散；1984 年 AT&T 拆分引爆 BSD 版權戰爭；NSA 的安全工程成為全球手機的沙盒底層；歐盟的立法改寫 App 的存亡規則。

## 全書的路線圖

```mermaid
flowchart LR
    A[1940s-60s<br/>批次與分時的黎明] --> B[1969-1980s<br/>UNIX 哲學與 BSD]
    B --> C[1987-1991<br/>MINIX vs Linux]
    C --> D[2000s<br/>行程/記憶體的深水區]
    D --> E[2010s<br/>行動與沙盒革命]
    E --> F[2013-2026<br/>容器、雲 OS 與 AI 異質算力]
```

各篇的敘事重點如下：

- **第一篇（1940s-1960s）**：機械開關與人工換帶的血汗、磁帶監控程式的第一縷自動化、以及 MIT 一群年輕人用分時系統翻轉「機器效率 > 人類等待」的價值序列；
- **第二篇（1969-1980s）**：Thompson 在 PDP-7 上的那一週、UNIX 的哲學戒律、Berkeley 的 BSD 獨秀、AT&T 的版權重錘與 POSIX 的立法；
- **第三篇（1987-1991）**：微核心與宏核心的聖戰、Minix 與 Linux 的交會、GNU 與 Linux 的世紀嵌合、開源的崛起；
- **第四篇（2000 前後的基礎工程）**：PCB、排程演算法、虛擬記憶體與置換、保護模式與零日漏洞防禦——一切前線故事的技術深水區；
- **第五篇（2010s至今）**：行動 OS 的電池經濟學、Android 與 iOS 的雙雄爭霸、容器與 Kubernetes 的叢集憲法、以及 AI 時代 GPU/NPU 排程的新憲法起草。

## 為什麼要讀史？

弗雷德里克·布魯克斯在《人月神話》中說：「**複雜的軟體系統唯一真正有效的解藥，是對本質複雜性的深刻理解**。」作業系統的七十年史，造福的不只是系統工程師。它是一部**關於稀缺的經濟學**（算力、記憶體、能量、注意力的稀缺催生了排程、分頁、省電、注意力治理）、**關於權力的政治學**（每次抽象都是一次憲政安排）、與**關於協作的社會學**（管道、開源、Git）。

而作業系統精神的當代意義不可忽視：**每一次你使用電腦，你都在隱性地簽署一份數位憲法**。這份憲法是誰寫的？依什麼利益？靠什麼機制執行？——本書的使命，就是讀懂它。
