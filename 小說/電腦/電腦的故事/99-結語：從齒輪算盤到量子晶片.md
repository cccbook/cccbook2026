# 結語：從齒輪算盤到量子晶片——電腦作為人類文明永恆的智慧放大器

## 一條兩百年的弧線

1837 年，巴貝奇在紙上畫下分析機的 store 與 mill；2022 年，橡樹嶺國家實驗室的 Frontier 突破每秒一百京次運算。如果把他們排成一列——巴貝奇、洛夫萊斯、圖靈、馮紐曼、蕭克利與他的八個叛徒、基爾比與諾伊斯、摩爾、霍夫與法金、沃茲尼克與賈伯斯、蓋茲、伯納斯-李、安德森、佩吉與布林、貝佐斯、與量子時代的新一代工程師——你會看到一個驚人的共同點：

**每一個人都曾被告知「這不可能」。**

- 帝國官僚告訴巴貝奇，蒸汽不可能承載分析。
- 同行告訴圖靈，密碼戰場不是數學家的舞台。
- 蕭克利告訴八個年輕人，離開他們一無所有。
- IBM 告訴 Gates，沒有人要為作業系統付錢。
- 投資人告訴貝佐斯，書店不需要伺服器。

## 計算精神的四種美德

回望這兩百年，偉大的電腦設計者大致共享四種美德：

1. **抽象的勇氣**：從圖靈機的數學抽象到馮紐曼架構的五器官分離，最深刻的進步來自「把現象抽象成規則」的能力。
2. **相容的制度**：從 IBM System/360 的統一指令集、伯納斯-李放棄 Web 專利、到 AWS 的標準化 API——技術只有一半，另一半是「大家都能接上」的制度設計。
3. **指數的耐心**：摩爾定律不是自然律，是一群人五十年的自我實現；AWS 不是一夜建成，是二十年基礎設施的複利。時間尺度越長，複利越可怕。
4. **去中心化與開放**：從 Homebrew Computer Club 的分享文化、FreeBSD、Linux、到 W3C 的標準制定——計算最驚人的力量，來自被自由連接的眾人。

## 當電腦開始思考

本書的終章停在了一個弔詭的時刻：當 AlphaFold 能預測蛋白質摺疊、大模型能寫出能執行的程式碼、「全球大腦」正在成形，人類計算者的角色在哪裡？

歷史反復給出同一個答案：**每一次計算能力的躍遷，都吞掉了一批「勞動」，而放大了一批「判斷」。** 黃銅齒輪取代了計算員，沒有消滅數學家；編譯器取代了組合語言碼農，沒有消滅軟體工程；AI 正在吞掉 routine 的編碼與觀測，而「定義問題、價值取捨、為一個想法護航」的判斷，依然落在人類手上。這也是從巴貝奇到今天，所有偉大設計者共同的、無法自動化的地層。

## 智慧放大器

矽本是地殼中最平凡的元素，沙灘上俯拾即是；電本是轉瞬即逝的物理現象。兩百年來，一代代設計者用邏輯、幾何與電路，把石頭與閃電煉成了文明的引擎——這是現代版的點金術，而點金的手，始終是人類的。

那些固執的、偏執的、失敗的、勝利的設計者告訴我們：**計算的邊界，從來不是被晶片決定的，而是被想像力與膽量決定的。**

下一個在車庫裡畫電路圖的年輕人，也許正在讀這本書。
