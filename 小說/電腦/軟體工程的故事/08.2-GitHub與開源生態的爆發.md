# GitHub 與開源生態的爆發

## 一、四個年輕人與「社交編程」

2007 年秋天，兩個 Rails 開發者——Tom Preston-Werner 與 Chris Wanstrath——在舊金山一家酒吧聊天時想出一個主意：Git 的分散式設計讓「每個人都能複製倉庫」，那為什麼不把網站做成**程式設計師的社交網路**？像 Flickr 分享照片那樣分享程式碼：追蹤（follow）、關注（watch）、複製（fork）、按讚。他們拉進了 PJ Hyett，後來 Scott Chacon（Git 社群佈道者，《Pro Git》作者）也加入。2008 年 4 月，GitHub 正式上線。

GitHub 的關鍵發明是 **Pull Request 工作流**：想貢獻程式碼的人不用寫信寄 patch，而是 fork 倉庫、在自己的分支修改、然後發起「拉取請求」——一個附帶差異對比、行內討論、自動測試的公開審查頁面。貢獻從郵件列表的精英禮儀，變成網頁上的點擊操作。開源貢獻的門檻被壓到大學生與業餘愛好者都能跨過的高度。

## 二、開源的前史：從志工到職業

GitHub 爆發的地基是三十年開源運動的積累。1983 年 Richard Stallman 發起 GNU 計畫與自由軟體運動（思想是「軟體自由是道德問題」）；1991 年 Linus Torvalds 釋出 Linux 核心，1992 年 GNU/Linux 合體；1998 年 Eric Raymond 與 Bruce Perens 成立開源促進會（OSI），把「自由軟體」重新包裝為「開源」——從道德訴求轉為**開發效率的商業論證**。這個話語轉向至關重要：1990 年代末，IBM 投資 Linux（2000 年宣布 10 億美元投入）、Netscape 開源瀏覽器、Apache 基金會成立，企業終於敢把關鍵基礎設施押在「志工寫的程式碼」上。

但 2008 年之前的開源協作仍有巨大摩擦：CVS/SVN 集中式倉庫讓「提交權限」是稀缺資源；貢獻要透過郵件列表與補丁檔案。Git 解決了技術摩擦（便宜分支、人人有完整歷史），GitHub 解決了社交摩擦（一鍵 fork、網頁化審查）。兩者疊加，開源從「少數核心的馬拉松」變成「百萬人的接力賽」。

## 三、生態效應：從倉庫託管到行業基礎設施

GitHub 的成長曲線驚人：2008 年上線，2011 年宣布託管超過一百萬個倉庫，2013 年達一千萬，2020 年代已超過 4 億個倉庫與 1 億開發者。它演化出的不只是託管服務，而是一整套行業制度：

- **Issues 與專案看板**：把錯誤追蹤與任務管理標準化；
- **GitHub Actions（2019）**：把 CI/CD 內建進平台，管線即程式碼；
- **Open Source Arcade 般的社群機制**：star 數成為專案聲譽貨幣、README 與 CONTRIBUTING 檔案成為文化規範、Hacktoberfest 把貢獻變成節日；
- **安全供應鏈工具**：Dependabot、安全公告——因為當一切軟體都由開源零件組裝，依賴管理本身成為工程學科（Supply chain attacks 也隨之而來）。

「用開源的方式工作」從開源社群逆向輸出到企業內部：內部 Git 平台（GitLab 自託管、GitHub Enterprise）讓銀行與航空公司的內部代碼也走 fork + PR 流程。Conway 定律的新表述由此誕生：**平台形狀決定組織形狀**。

## 四、被微軟收購與模式之爭

2018 年 6 月，微軟宣布以 75 億美元收購 GitHub。這樁交易充滿歷史反諷——微軟前 CEO Steve Ballmer 曾稱 Linux 是「癌症」（2001），而收購時的微軟已是全球最大的開源貢獻者之一（Satya Nadella 的雲端轉型需要開源生態，Azure 上跑著無數 Linux）。開發者社群一度恐慌「微軟會毀了 GitHub」，但實際運營保持了獨立性。

競爭與批判也從未停止。GitLab（2011，烏克蘭裔開發者 Dmytro Zaporozhets 與荷蘭人 Sytse Sijbrandij 創立）以開放核心（open core）模式與自託管能力分庭抗禮，成為許多企業與政府的選擇。批評者則指出 GitHub 的中心化悖論：用最分散式的工具（Git）打造了最中心化的平台——如果 GitHub 停擺，全球軟體開發當天就半癱瘓。2020 年代，開源的可持續性危機（維護者倦怠、Log4Shell 之類的基礎庫無人資助、XZ Utils 後門事件 2024）讓人重新思考：社群驅動的榮耀模式，能養活支撐世界的底層基礎嗎？

## 五、歷史定位

GitHub 的本質貢獻，是把 Linus 在 Git 裡埋下的「人人擁有歷史副本」的技術可能性，轉譯成了「人人可參與」的社會制度。開源不再是意識形態運動，而是**行業的預設生產方式**：今天任何一個嚴肅的軟體專案，其依賴樹裡都有成百上千個開源套件。Preston-Werner 當年在酒吧裡的那個比喻——「程式碼的 Flickr」——最終塑造的不是一個網站，而是二十一世紀軟體文明的公地。
