# 2.3 微型電腦與 PC 浪潮的衝擊：大型機虛擬化為何在 1980 年代一度被冷落？

## 1984 年的尷尬：教科書裡的「過時技術」

1980 年代中期，如果你在大學圖書館查「虛擬機」，找到的多半是 1970 年代的論文與 IBM 手冊，以及一種揶揄的口吻——**「VM 是大型機時代的遺物」**。事實上，1978 年戈德堡在《Computer》期刊的回顧文章中已注意到虛擬機研究降溫的跡象；到 1980 年代，這個領域在主流學術界幾乎銷聲匿跡。

一門十年前還是顯學的技術，為什麼會被整個時代遺棄？

## 原因一：摩爾定律讓「共享」失去誘惑

虛擬機誕生的根本動機是**機器太貴**。但 1970 年代末開始的微處理器革命把這個前提撕碎了：

```text
1965: IBM System/360 主機 ≈ 數百萬美元，全公司共享一台
1977: Apple II ≈ 1,300 美元，一人一台
1981: IBM PC ≈ 1,565 美元起，一人一台
1984: Sun-1 工作站 ≈ 8,500 美元，工程師一人一台
```

當 CPU 每 18 個月便宜一半，**「把一台貴機器切成好幾台」的經濟學徹底破產**。80 年代工程師的直接反應是：與其搞複雜的 hypervisor，不如每個人買一台新機器。**摩爾定律成了虛擬化的第一個殺手。**

## 原因二：PC 的指令集天生「無藥可救」

即使有人想在 PC 上做虛擬化（學界確實有零星嘗試），普佩克–戈德堡體檢表給 x86 開出的判決是死刑（細節見第 3 章）：

- x86 的敏感指令大量「漏網」成非特權指令；
- 修改 guest OS 需要原始碼——而 DOS/Windows 是封閉的微軟王國；
- 硬體廠商（Intel）當時對虛擬化毫無興趣。

**理論判了死刑 ＋ 產業沒有動機 ＋ 客戶沒有需求**——三重否定。

## 原因三：文化轉向——個人運算的意識形態勝利

這是一場深刻的文化變遷。1970 年代計算的社會意象是「**集中的機房、珍貴的資源、專業的操作員**」——虛擬化正是這個意象的完美配套。而 1980 年代的意象變成了「**個人電腦、賈伯斯、每張桌面一台機器**」。

- 業界語言從「分時、共享」變成「個人、獨立」；
- 大學課程的重心從大型機作業系統轉向 Unix 工作站與 PC 程式設計；
- 一代新工程師根本沒聽過 CP/CMS——它活在大型機的操作手冊裡，而大型機活在銀行的地下室裡。

**思想決定了技術的能見度。** 虛擬機沒有消失，只是退出了聚光燈。

## 沉寂中的火種：VM 並沒有死

在聚光燈之外，四條暗線仍在燃燒，成為 1990 年代復興的火種：

### 1. IBM 大型機上 VM 持續進化
VM/370 → VM/XA → VM/ESA → **z/VM**。全球銀行、航空公司訂票系統（如 SABRE 類系統）的關鍵負載持續運行在 VM 之上。**企業的鐵路系統從未停駛，只是不再上新聞。**

### 2. 程式語言的「虛擬機」傳統
1970 年代末，**UCSD Pascal 的 p-System** 用一個「P-code 虛擬機」讓 Pascal 程式跨硬體執行；1980 年代末的 **Smalltalk-80** 進一步把「VM = 語言執行環境」的概念深耕。這條線與硬體虛擬化平行發展，日後將在 **Java JVM（1995）** 與 **.NET CLR** 上大放異彩——「虛擬機」一詞的雙重身世（硬體幻覺 vs 語言沙盒）就此定型。

### 3. 安全研究的沙盒思想
1980–90 年代，學界（包括 Goldberg 的學生們）持續研究用 VM 做**沙盒與入侵偵測**——在虛擬機裡放病毒樣本、從 VMM 位置監視 guest。這條線日後成為惡意軟體分析與 honeypot 的標準做法。

### 4. 模擬器文化（Emulation）
蘋果 Mac 上的 PC 模擬器（如 SoftPC, 1989）證明「用軟體模擬另一台機器」在 PC 上可行——雖然慢得像烏龜。它驗證了一個關鍵技術：**二進制翻譯（binary translation）**。這顆種子將在十年後發芽成 VMware 的核心黑魔法。

## 經濟的鐘擺：1990 年代的反轉

歷史在 1990 年代末戲劇性反轉。三股力量同時降臨：

```text
1. 經濟：伺服器爆炸式增長
   網路泡沫期企業瘋狂買伺服器，每台只跑一個應用（因為
   「不隔離就會互相干擾」），利用率卻只有 10–15%。
   機房電力、空調、維運成本失控 → 「server sprawl 伺服器蔓延」
   → 「共享昂貴機器」的經濟學重新成立！

2. 技術：CPU 快到有餘裕做軟體翻譯
   1990 年代末 x86 效能暴漲，虛擬化開銷首次可以被「吃掉」。

3. 制度：IT 治理危機
   管理數百台低利用率伺服器的運維噩夢，逼企業尋找整併之道。
```

**三十年前虛擬化被發明的理由（機器貴而閒），以全新的形式（伺服器蔓延）再度成立。** 歷史不是重複，是押韻。

> **歷史關聯**：沉寂年代留下的火種——模擬器的二進制翻譯、語言 VM 的分層思想、安全沙盒的隔離哲學——即將在史丹佛大學的一間辦公室裡匯流，誕生本書最戲劇性的主角：VMware。
