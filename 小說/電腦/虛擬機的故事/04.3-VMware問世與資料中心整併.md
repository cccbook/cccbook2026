# 4.3 VMware Workstation 與 ESX Server 問世：Windows 與 Linux 在同一台 PC 上和平共處

## 1999：demo 震驚世界

1999 年，VMware 發布 **VMware Workstation 1.0**。當時的 demo 讓所有人瞠目結舌：一台普通的 PC 視窗裡，**Windows 98 完整地跑在另一個視窗裡**，外面是 Linux——兩個作業系統同時存活、滑鼠一移就切換、網路互 ping 互通。

更驚人的是：**跑在裡面的 Windows 是原封不動的零售版**。沒有打補丁、沒有改原始碼、沒有和微軟合作。教科書上「不可虛擬化」的指令集，就這樣被馴服了。

```text
1999 年 Workstation 1.0 的衝擊波：
  學界：「定理說不可能……但它就在這裡跑著。」
  業界：「我可以在一台機器上測試所有 OS 組合了！」
  微軟：暫時沒當回事（幾年後將追悔莫及）
```

## Workstation：開發者的瑞士刀

Workstation 定位於開發者與 IT 專業人員的桌面市場，殺手級場景立即浮現：

- **測試矩陣**：軟體要在 Win95/98/NT/2000/Linux 上都跑？不用買十台機器；
- **安全沙盒**：來路不明的軟體先丟進 VM 跑，中毒就刪掉整個虛擬機；
- **快照（Snapshot）**：系統狀態隨時存檔、隨時回滾——這對當時的工程師是魔法般的功能；
- **可攜性**：整台「機器」就是幾個檔案，可以拷貝、隨身攜帶。

**「機器從硬體變成了檔案」**——這個觀念轉變的意義，要到五年後的雲端時代才被完全理解。

## 2001：ESX Server 進攻資料中心

真正改寫歷史的是 2001 年發布的 **VMware ESX Server**——目標從桌面轉向企業機房。ESX 是裸機（bare-metal）hypervisor：直接安裝在實體伺服器上，其下跑多個企業級 guest。

兩代 ESX 架構的演進值得注意：

```text
ESX 1.x（2001）：
  核心中的「VMkernel」直接管理硬體，
  效能敏感路徑由 VMkernel 原生處理
  （服務主控台基於裁剪過的 Linux）

ESX 3.x（2006）起：
  全面導入 VMkernel 自成體系，
  硬體輔助虛擬化（VT-x/AMD-V）成為預設
```

配合 **VirtualCenter** 管理平台（2003），企業終於可以在一個介面裡管理數百台實體機上的數千個虛擬機。

## VMotion：殺死「伺服器蔓延」的最後一刀

2003 年的 **VMotion** 是 VM 史上最戲劇性的發明：**在不停機的前提下，把一台正在運行的虛擬機從實體機 A 整台「搬」到實體機 B**——記憶體頁面在背景持續複製、CPU 狀態在毫秒間移交、TCP 連線不中斷、使用者毫無知覺。

```text
VMotion 的價值：
  1. 硬體維護：不用挑凌晨三點停機了，把 VM 搬走再關機
  2. 負載平衡：忙的機器把 VM 搬給閒的機器
  3. 故障轉移：機器要壞之前，先搬空它

結果：實體機從「承載特定應用的身份」
      降級為「可互換的運算資源池」
      ——這是雲端運算的哲學前夜
```

## 商業奇蹟與產業鏈的重構

VMware 的財務數字說明了一切：成立三年獲利，2004 年被儲存巨頭 **EMC 以 6.35 億美元收購**（並保留獨立營運），2007 年 IPO 市值一度接近 200 億美元。**一家賣「幻覺」的公司，成為當時史上最賺錢的軟體 IPO 之一。**

產業連鎖反應：

1. **伺服器廠商**（Dell、HP、IBM）主動為伺服器預裝/優化 VMware 支援——賣硬體的開始替軟體公司打工；
2. **微軟** 從嘲笑轉為全力反擊（Virtual PC 收購、Hyper-V 研發）；
3. **開源社群** 受刺激開發 Xen 與 KVM，掀起 hypervisor 的群雄逐鹿（見第 6 章）；
4. **Intel/AMD** 終於承認：必須把虛擬化做進晶片（見第 5 章）。

## 文化餘波：一個新的職業誕生

VMware 造就了一個全新職業類別：**VMware 管理員／虛擬化工程師**。2000 年代中期，取得 VMware 認證（VCP）成為 IT 從業者加薪的捷徑；「P2V（實體轉虛擬）」成為行業黑話；企業 IT 部門的組織結構、預算科目（從買伺服器變成買軟體授權）隨之改寫。**技術的勝利，最終體現為組織與制度的重塑。**

> **歷史關聯**：VMware 用純軟體贏得了戰役，但也暴露了軟體路線的天花板：DBT 的工程複雜度極高、開銷終究存在、且每顆新 CPU 都可能引入新陷阱。天花板上方那片天空，屬於硬體——接下來，Intel 與 AMD 將親手把 1974 年定理要求的「敏感⊆特權」刻進矽晶片。
