# 6.1 伺服器虛擬化率從 5% 飆升至 80%：企業機房迎來整併狂潮

## Y2K 之後的機房噩夢

2000 年前後，企業 IT 留下了一個尷尬的遺產：**伺服器蔓延（server sprawl）**。

```text
蔓延的成因：
  1. 應用程式「一個伺服器只跑一個應用」的部署慣例
     （怕互相干擾、怕升級牽連、怕版本衝突）
  2. 伺服器越來越便宜，採購比協調容易
  3. 專案各自為政，誰也不肯把自己的應用搬去「共用」機器

蔓延的後果：
  大型企業動輒數千台 x86 伺服器
  平均利用率 10–15%（八成半的錢在發熱）
  每台伺服器 2006 年前後年耗電與冷卻成本數百至逾千美元
  IT 預算被「養機器」吃掉，無錢投入新應用
```

## 整併的黃金理由：不省 CPU，省「周邊」

VMware 的行銷天才之處，是把整併的理由從「CPU 利用率」升級為**全生命週期會計**：

```text
一台被整併掉的實體伺服器，省下的不只是它的 CPU：
  ✓ 採購成本（硬體折舊）
  ✓ 電力＋冷卻（占機房營運成本的大頭）
  ✓ 機架空間（市中心機房每平方英尺天價）
  ✓ 網路埠、KVM、布線
  ✓ 系統管理員的照顧時間（每人管幾百台 VM vs 幾十台實體機）
  ✓ 災難復原：VM 是檔案，複製即備援
```

ROI（投資報酬率）試算成為 VMware 銷售團隊的標準武器：**「買我們的軟體授權，半年內省回來。」** 在 2001 年網路泡沫破裂、IT 預算凍結的蕭條期，這個賣點精準擊中 CFO 的痛處。

## 數字說話：虛擬化率的狂飆

產業調查（Gartner、IDC 等多年報告的綜合口徑）顯示，x86 伺服器的虛擬化滲透率走出一條驚人的曲線：

```text
2005   ≈ 5%    （先驅者的小眾實驗）
2008   ≈ 15-20%（P2V 專案大爆發）
2010   ≈ 40-50%（「預設虛擬化」成為新常識）
2015   ≈ 75-80%（不虛擬化的應用反而需要提出理由）
```

十年間，**虛擬化從「要不要用」變成「預設就用」**——基礎設施的範式完成轉移。VMware 一度占據 x86 虛擬化軟體市場約七到八成的份額，成為企業資料中心事實上的作業系統。

## 制度與文化的連鎖反應

1. **IT 組織重構**：傳統「伺服器組、儲存組、網路組」的分工，被「虛擬化平台組」打穿——因為 VM 橫跨三個領域。**技術的整合倒逼組織的整合。**
2. **採購制度改變**：預算科目從「資本支出（買機器）」轉向「營運支出（買授權）」，IT 決策者從 CFO 辦公室回到工程部門。
3. **職業文化**：VCP 認證熱潮、「P2V 黑話」、VMware vExpert 社群——一個技術的周邊文化生態完全成形。
4. **新問題誕生**：VM 蔓延（VM sprawl）——虛擬機太容易建立，沒人記得誰的 VM 該刪。**隔離讓資源便宜，便宜讓資源氾濫。**

## 陰影：VMware 的定價霸權

虛擬化率飆升的另一面，是 VMware 授權費用的節節攀升。到 2010 年前後，大型企業每年支付給 VMware 的軟體維護費動輒數百萬美元，怨聲漸起：

- 開源陣營的 **Xen**（劍橋大學出品）與 **KVM**（紅帽押注）磨刀霍霍；
- 微軟的 **Hyper-V** 搭著 Windows Server 免費搭售；
- 客戶用「雙供應商策略」壓價。

**定價霸權孕育了自己的敵人**——這條規律貫穿每一場基礎設施戰爭，從作業系統到資料庫再到雲端。

> **歷史關聯**：企業內部的整併狂潮，本質是「讓昂貴資源的利用率最大化」——與 1967 年 CP-40 的動機完全同構。而當這套整併哲學離開企業圍牆、面向公眾零售時，歷史翻開了全新的一頁。
