第 1 章的結尾停在「幾何已經數位化，但格式戰國」。本章講述統一標準如何到來：2.1 分析 Calma GDS 的原始突破；2.2 討論 GDSII（1978）標準化及其成為 45 年長壽語言的奇蹟與原因；2.3 則把鏡頭轉向「幾何之外」的另一片地基——SPICE 電路模擬的萌芽。**幾何資料格式的標準化（製造介面）＋電路行為模擬（設計介面）**兩件事，合起來構成了後來所有 EDA 大廈的兩根承重柱。

# 2.1 Calma GDS（Graphic Data System）格式的問世：幾何圖形結構化儲存的第一次突破

## 2.1.1 從「圖形」到「圖形資料庫」的哲學跳躍

Calma 於 1971 年發表 **GDS（Graphic Data System）**。它的核心創新不在繪圖，而在**資料結構**：GDS 將版圖定義為一種層次化的「**單元（cell）引用**」資料庫——每個電路單元（例如反相器、記憶單元）只被定義一次，之後在其它地方以「引用（reference，放置＋轉換）」的方式重複使用。

這聽起來平淡，卻是個奇蹟般的設計決策。因為真實晶片天然具有**重複結構**（記憶體尤其如此），層次化引用讓檔案大小從線性增長壓縮到亞線性。沒有這一結構，1970 年代末的磁碟與磁帶根本存不下大晶片。

## 2.1.2 GDS 檔案的物理形態

早期的 GDS 檔案以「**資料流（stream）**」方式記錄：一連串記錄（record），每筆記錄帶有型別標籤——BGNLIB、LAYER、BOUNDARY、TEXT 等關鍵字今日依然一字不變地存在於 GDSII 裡。一個簡化的語意示意：

```
BGNLIB        （開始一個 cell）
LAYER  m1     （指定金屬一層）
BOUNDARY      （開始一個多邊形）
  (x1,y1) (x2,y2) ...  （頂點座標）
ENDEL
SREF          （放置一個 cell 引用）
  name=INV01  (x,y)  angle=90
ENDLIB
```

工程師日常工作中，這串記錄最終被打孔成卡、寫上磁帶、寄到光罩廠。**紙上的一生一死**，都被壓縮進這些位元流裡。

## 2.1.3 商業與制度上的位置

Calma 的商業模式是「賣工作站＋賣格式」的正循環：越多人用 GDS 交換資料，越多晶圓廠接受 GDS，越多人被迫買 Calma。到 1970 年代中後期，GDS 已成為美國主要半導體廠與光罩廠之間的**事實標準**。GE 於 1983 年收購 Calma，之後又經 Valid Logic Systems 輾轉——但**格式脫離了公司本身**，成為公共財產，這是格式戰略勝利於產品戰略的經典案例。

## 2.1.4 前因後果

- **前因**：1.3 的格式戰國、磁帶介質的容量限制。
- **事件**：GDS 的層次化資料結構＋stream 記錄格式。
- **後果**：格式本身成了產業基礎設施，1978 年升級為 GDSII（2.2）；「cell + reference」的抽象也直接影響後世硬體階層設計語言（Verilog 的 module，4.2）。
