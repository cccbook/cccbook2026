# 8.2 谷歌開源 Kubernetes 與雲原生計算基金會（CNCF）：巨頭如何靠開源重新定義雲端標準？

## 背景：Google 的 Borg 思想與 Docker 的突然催化

2013 年之前，**Google 內部早已以「Borg」系統**管理數十萬台機器與億計的容器化工作負載——但這門技術從未對外商品化。

2013 年，一個新創公司的產品掀起巨浪：**Docker**（dotCloud 的 Solomon Hykes）把**Linux namespaces + cgroups** 包裝成**人人可用的容器**，宣告「**一次構建、處處執行**」。Docker 在兩年內成為全世界的選擇——但**大規模集群的調度**（scheduling）問題，Docker 自身仍不完備。

Google 看到了歷史車輛：

- 内部有 **Borg 遺產**；
- 外部有 **Docker 敦促的新興容器生态**；
- AWS 正以**專有介面**壟斷，雲端缺一個**中立標準**。

Google 作出決定：**把自家的王牌拋向街頭**——**2014 年 6 月**，Google 開源 **Kubernetes**（希臘語「舵手」），正式投入容器調度的開放戰場。

## Kubernetes 的三層戰略

1. **技術層**：吸收 Borg 的精華（宣告式 API、Pod 模型、調度器、健康檢查），接上 Docker 生态，**成為「事實上的資料中心作業系統」**；
2. **生態層**：以**中立許可證（Apache 2.0）**開源，免除「Google 綁定」的疑慮；
3. **治理層**：**2015 年 7 月** Cloud Native Computing Foundation（CNCF）宣布成立，Kubernetes 成為其「種子專案」——**沿用 Linux Foundation 的管理框架**，讓商業巨頭與中立基金會共同治理。

## 「開源標準」的帝國之路

| 年份 | 事件 |
|---|---|
| 2014/6 | Google 在 DockerCon 宣布 Kubernetes |
| 2015/7 | v1.0 發布，CNCF 成立，Kubernetes 為「種子技術」 |
| 2016 | AWS、Azure、IBM、多家廠商宣布 K8s 託管服務 |
| 2017 | Docker 宣布**官方支援 Kubernetes**；AWS EKS 登場 |
| 2018 | Kubernetes 晉身 CNCF「**畢業專案（graduated）**」 |
| 2020 前後 | **Kubernetes 贏得容器編排之戰**（勝過 Docker Swarm、Mesos），成為事實標準 |
| 2022– | Google 在 K8s 貢獻榜長期領先；AWS、Red Hat、微軟等亦居貢獻前列 |

### 開源殖民主義（strategic open source）的完美

Kubernetes 是**商業策略學上的教科書級開源**：

- **零授權費**：任何人可用，包括競爭雲商——**大家站上同一張地圖**；
- **多廠商可遷移**：K8s 的介面在各大雲之間**通用**（EKS/GKE/AKS），**正好矯正 AWS 的鎖定**（Google 的市場劣勢反而成為主張公開標準的動機）；
- **上層的溢價**：Google 本家不但賣 GKE 託管，還以 Anthos、GKE Autopilot 等管理服務收取穩定的訂閱費；
- **CNCF 的催化**：**Prometheus、Envoy、etcd、Istio、Harbor**…K9s 的生態漸進成為**「雲原生家族」**。

## CNCF：中立的外交部

CNCF 的治理模式包括：

- **技術監督委員會（TOC, Technical Oversight Committee）** 制定**「沙盒 → 孵化 → 畢業」**的三級准入機制；
- **專案成熟度與治理審查**制度化；
- 截至 2020 年代前期，CNCF 已託管**數百個專案**，成為整個雲原生技術的外交部。

## 對 AWS 的地緣反擊

有趣的是，**最先點火的 Google**在市場份額上竟被動反饋：AWS 的容器服務（EKS、Fargate）在 Kubernetes 標準之下反而佔據規模優勢。**「建立標準的人，不一定是最終赢家」**——**標準生而民主，蛋糕的切法由市場決定**。

## 小結

Kubernetes 把「開源」從防禦武器升級為**帝國級戰略武器**：**公開技術、砌築標準、匯聚生態、坐收自家服務的溢價**。它讓「避免鎖定」成為雲端時代的最低共識，也為下一節的「**白嫖 vs 反白嫖許可證之戰**」埋下伏筆——**當基礎設施成為公共財，受益者是否要回饋，成為最尖銳的制度難題**。
