# 5.1 萬事皆因 Linux 起：微軟內部萬聖節文件（Halloween Documents）洩露事件

## 背景：1997 年開源敲門，微軟高層失眠

1997 年，開源浪潮已不可忽視：Linux 核心成熟、Apache 市占攀升、GNU 工具鏈完備、Netscape 正醞釀開源。**微軟內部把 Linux 列為對手**——不是因為它已經在桌上擊敗 Windows，而是因為它正在**伺服器領域**快速蠶食 NT 的陣地。

1998 年上半年，微軟內部就 Linux 寫下多份戰略分析備忘錄。**1998 年 8 月**起，這些文件被匿名人士陸續洩露至網路，**Eric Raymond 第一時間放上網並逐行注釋**（第一份文件的作者署名被指出與消費者對手部門相關，但真實洩露者不曾公開），史稱**萬聖節文件（Halloween Documents）**——系列文件陸續於 1998–2000 年代初洩出多篇續篇。

## 核心內容：敵方的攻擊計畫與內心恐懼

萬聖節文件中最著名的第一份（Halloween I）包含驚人的坦白與惡毒的對策：

### 恐懼的部分

> "Linux has been deployed in mission critical, commercial environments and has an excellent performance for a networking and web-serving environment… Linux's development process is **short, efficient and open**……與微軟內部流程相比，**「短週期、開放的開發循環」是我們難以匹敵的乘數**。"

文件還指出：Linux 的**開發者社群規模正以驚人速度擴張**；伺服器市場上 Linux 已經「可用、便宜、可客製」，是最迫在眉睫的價格與功能雙重威脅。

### 反擊的部分

文件中提的「FUD（Fear, Uncertainty, Doubt）戰略」極具歷史參考價值：

1. **貶低品質**：把 Linux 描繪成「業餘之作」，宣揚 Windows NT 的企業級支援與 SLA；
2. **攻擊許可證**：渲染 GPL 的「病毒性」與企業法律風險——把「使用 GPL 軟體」塑造成律師夢魘；
3. **拖延服務與兼容性**：強調 Windows 的驅動、應用生態與支援體系成熟；
4. **生態鎖定**：以 Exchange、SQL Server、IIS 等專有功能綁住企業用戶；
5. **企業折價與捆綁**：在有多競標的企業交易中，以極低價或贈送 Windows NT 阻斷 Linux 的中標機會——此優惠策略於眾多用戶證言中可被證實，被視為純粹的反競爭定價。

## Raymond 的回應：把恐慌變成彈藥

Eric Raymond 立刻把文件當作反擊武器：

- **逐行注釋**：把微軟自己承認的讚美（「開發週期之短令我們羨慕」）變成最有力的宣傳素材；每次新文件洩出，他就更新 annotations——**敵人的內部文件成為最有效的武器**。

- 萬聖節文件由此成為「**FUD 的世紀案例**」，被寫進政商、法律與商學院課堂。它一方面**把開源從「業餘愛好」升格為「業界的現實威脅」**（被巨大的公司當成頭號敵人），另一方面加速了**「開源 vs 專有」的公共辯論**。

## 連鎖效應

1. **開源的知名度上升**：萬聖節文件的輿論餘波，直接推動 1998–2000 年 IBM/HP/Sun 的 Linux 佈局與 Red Hat IPO 的熱潮；
2. **微軟反壟斷案的實質化**：1998 年 5 月，美國司法部與 20 州正式起訴微軟，為 IE 捆綁案展開拉鋸。萬聖節文件在**證據與輿論層面**為「微軟害怕開源競爭」提供注腳——雖然判決主軸是瀏覽器市場壟斷，但**「微軟的不正當競爭文化」已深入人心**；
3. **開源的自我確認**：文件證明 Linux 已被微軟「視為而立」——對反對者與支持者，這是最有說服力的廣告；
4. **內部路線分裂**：微軟內部其實也分為「Linux 是威脅必殺」派與「開放可學習」派——這場內部思想之戰，日後成為 2014 年微軟擁抱開源的前奏（詳見第 8 章）。

## 小結

萬聖節文件展示了**帝國的恐懼变成戰略**的全過程：恐懼 → FUD → 反噬。它給開源運動帶來的是**合法性加冕**——「敵人的承認」比任何支持者的讚美都有效。而當微軟的高階管理層公開把 Linux 稱為「癌症」時，這場戰爭將達到語言暴力的最高潮——下一節。
