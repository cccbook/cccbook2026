# 2.2 1983 年 GNU 計畫啟動與自由軟體基金會（FSF）：「自由（Free as in Freedom），而非免費」

## 一個「不可能的任務」：重寫整個作業系統

1983 年 RMS 宣告 GNU 計畫時，重寫一個完整作業系統被普遍視為癡人說夢——連 AT&T 與 IBM 都投入數百人年。RMS 的策略有兩個天才之處：

1. **站在 UNIX 的肩膀上**：GNU 是「GNU's Not UNIX」——不是要發明新的系統，而是**自由重實作**一個 UNIX 相容系統。所有工具的「規格」已經由 UNIX 定義，只需照著做，風險與設計成本大減。
2. **從工具鏈開始**：不先寫核心（最難），先寫編輯器、編譯器、shell——這些工具對所有系統都有用，可以**立即吸引貢獻者**。

## GNU 的里程碑

| 年份 | 成果 | 意義 |
|---|---|---|
| 1983 | GNU 宣告 | 運動啟動 |
| 1985 | **GNU Emacs** | RMS 以 C + Lisp 架構寫出可擴展編輯器，銷售二元檔+磁帶支持計畫——**最早的「開源商業模式」實驗之一** |
| 1985 | **自由軟體基金會（FSF）** 成立 | 以 501(c)(3) 非營利組織制度化募款與推廣 |
| 1987 | **GCC（GNU Compiler Collection）** | 自由的 C 編譯器，日後幾乎成為所有開源平台的基礎工具鏈 |
| 1988 | Bash shell | 自由的命令列解譯器 |
| 1990 | 核心仍未完成 | GNU 的 **Hurd** 微核心進展緩慢——這個「缺口」將改變歷史（下一章） |

## 「Free Software」的四項自由

FSF 把「自由軟體」定義為**四項基本自由**（0–3 號，2000 年代加入第 4 項）：

- **自由之 0**：不受限制地執行程式；
- **自由之 1**：研究程式如何運作，並修改（前提是原始碼可得）；
- **自由之 2**：重新散布原版；
- **自由之 3**：散布修改版。

這個定義把爭論從「要不要付錢」移開，聚焦在「**使用者是否掌控自己的運算**」——這是 RMS 對付「free = cheap」誤解的核心話語武器。

## 制度創新：非營利組織 + 象徵性收費

FSF 的營運模式值得注意：

- **銷售磁帶與光碟**：以 50–150 美元賣 GNU 工具的磁帶/CD，附源碼——買者自願付費支持，**「自由」與「收費」完全不矛盾**（自由 2/3 允許任何人複製轉贈，但廠商樂於付費拿「方便」）；
- **會員與捐贈**：公司與個人捐款；
- **不申請軟體專利、不簽 NDA、不寫專有程式**：以**道德純潔性**作為組織的原則資產。

這套模式證明了一件當時被認為不可能的事：**軟體可以在沒有專利壁壘的情況下獲得資金**——為日後整個開源商業世界鋪路。

## 文化與教育的擴散

GNU/FSF 的影響遠超軟體本身：

- **「copyleft」概念**（下一節詳述）成為法律工具的新類別；
- **GNU 通用公共許可證（GPL, 1989）**成為自由軟體的法律核心；
- RMS 的人格與言論（如「自由是道德問題」）使運動帶有濃厚的**道德運動色彩**——這既是凝聚力的來源，也為日後「自由軟體 vs 開源軟體」的路線分裂埋下伏筆（第 4 章）；
- GNU 的術語與哲學透過大學、Usenet、會議擴散——**一場以教育為武器的社會運動**。

## 小結

GNU 計畫證明：重寫一個作業系統是可行的，而「自由」可以是一個可執行、可募款、可制度化的事業。但它還缺一塊拼圖——**核心（kernel）**。這塊拼圖，將由一位芬蘭學生在網際網路上意外補上。在那之前，先看 GNU 最鋒利的武器：Copyleft 與 GPL。
