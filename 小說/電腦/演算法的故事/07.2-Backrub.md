# 第 7 章　拉里·佩奇與謝爾蓋·布林：PageRank——用網頁連結投票撬動網際網路帝國

# 7.2 佩奇與布林在史丹佛的奇妙靈感：把「網頁之間的超連結」當作學術論文的引用投票（Backrub 演算法）

## 7.2.1 兩個博士生的相遇（1995）

Larry Page（密西根大學畢業，父母皆計算機教授）1995 年入史丹佛博士班；Sergey Brin（六歲自蘇聯移民，數學天才，馬里蘭大學本科）負責帶他參觀校園——兩人一見即爭論不休，隨即成為搭檔。Page 的博士課題選了「網頁連結的數學性質」：他先寫爬蟲抓取整個 Web 的連結結構（1996 年爬得約 2,400 萬頁），再把連結圖倒過來看——這台玩具叫 Backrub（後來 logo 的紅色小手即為其遺跡）。

## 7.2.2 「反向引用」與加權投票

Page 的直覺來自學術評價：論文重要性由被引次數決定，且重要論文的引用更有分量。推廣到 Web：

- 每條入鏈是一票；
- 來自「重要頁面」的票更重——而「重要」由演算法自身定義（遞迴！）

布林（數學系）把它寫成可計算的線性代數。1998 年兩人發表論文《The Anatomy of a Large-Scale Hypertextual Web Search Engine》（WWWC7，布里斯班）——PageRank 一詞首次公開（也是 Page 的雙關姓氏）。

## 7.2.3 同期的工程整合

論文的另一半同樣關鍵：大規模工程——分佈式爬蟲、索引壓縮（5.3 的 DEFLATE 思想）、以錨文本（anchor text）把連結文字併入被連頁的索引。演算法＋系統的合奏使一台由校園二手機器拼成的伺服器群（主板上架到樂高積木外殼的著名照片）打敗了資本雄厚的大公司。

## 7.2.4 前因後果

- 前因：7.1 的機制危機＋引文分析＋線性代數訓練（Brin）＋史丹佛 Terman 工程院文化。
- 事件：1996–98 Backrub→Google；1998 年 9 月公司成立（車庫）。
- 後果：7.3 的數學細節與商業帝國；Angel 投資含 Andy Bechtolsheim 的十萬美元支票（開給「Google Inc.」——當時公司尚未註冊）的傳奇插曲。
