# 6.2 ICANN 與 IP 位址分配機制：IPv4 枯竭危機與 IPv6 升級的漫長拉鋸戰

## 32 位元的詛咒

IPv4 位址長 32 位元，理論上限約 $2^{32} \approx 43$ 億個。1970 年代設計時，Vint Cerf 曾估算這「夠用了」——以當時全球只有幾百台電腦的現實，這是完全合理的工程判斷。但沒有人預料到：

- **手機**會是電腦；
- **每個家戶**會有多台聯網設備；
- **物聯網**會讓燈泡也要 IP。

43 億對 80 億人口、人均數台設備，數學上早就注定不夠。1990 年代中期，工程社群已經拉響警報。

## 分配制度：從 IANA 到 RIR

IP 位址按「分層再分配」治理：

```
IANA/ICANN（全球）
   ↓ 分配
RIR 區域網際網路註冊機構（5 個）
   ├─ ARIN（北美）、RIPE NCC（歐洲）、APNIC（亞太）、
   ├─ LACNIC（拉丁美洲）、AFRINIC（非洲）
   ↓ 分配
ISP / 國家註冊機構 → 終端組織
```

1990 年代對分配規則的修正是避免過早枯竭的關鍵：**CIDR（無類別域間路由，1993）**取代僵化的 A/B/C 分類，以任意長度的前綴精細切分位址，同時壓縮路由表。CIDR 是「避免浪費」與「控制路由表膨脹」的雙贏工程。

## IPv6：早熟的解方，遲到的採用

1998 年，**IPv6（RFC 2460）**定稿：128 位元位址（$2^{128}$，號稱「為地球上每粒沙子都分配一個位址」），內建自動配置、更簡潔標頭、原生支援 IPsec。

但推廣陷入近二十年的僵局，原因是**冷啟動問題（chicken-and-egg）**：

- ISP 不升級：反正 NAT 能撐；
- 內容商不升級：反正用戶沒 IPv6；
- 設備不支援：反正沒內容逼我升。

### 兩條岔路：NAT 與 IPv6 的分水嶺

**NAT（網路位址轉換）**——把私網位址藏在共享的公網 IP 後面——是 1990 年代的權宜之計，卻成為 IPv6 的最大敵人：

- **好處**：數十台設備共享一個公網位址，枯竭危機被無限期延後；
- **代價**：打破端到端原則——外部無法主動連入內網主機，P2P、自架伺服器、物聯網直連全部受苦；安全性與可追溯性也變得複雜。

**歷史的殘酷在於：正是 NAT 的成功，讓 IPv6 失去了緊迫性。**

## 轉折：亞洲與「公開日」

- **亞洲的危機感**：中國、日本、韓國在 1990 年代末人均 IPv4 極少（歷史分配偏向美國），反而是 IPv6 最早的積極推動者。
- **APNIC 首先耗盡**（2011 年）：亞太率先發出「IPv4 分配完畢」公告；RIPE（2012）、LACNIC（2014）、ARIN（2015）、AFRINIC（2017）相繼告罄。
- **世界 IPv6 Day（2011/6/8）**：Google、Facebook、Yahoo 等大廠 24 小時集體開啟 IPv6 壓力測試；**World IPv6 Launch（2012/6/6）**永久開啟——內容商終於先動，打破了雞蛋困境。
- **政府出手**：中國「IPv6 規模部署行動」（2017 起）、美國聯邦機構 mandation、印度以行動電信商角度大規模發放 /64 等前綴——**制度力量最終補上了市場失靈**。

今天，Google 統計的 IPv6 全球採用率已超過四成，印度、法國、德國等國家過半流量走 IPv6；但 IPv4 位址市場（單價數十美元）仍將長期存在——**升級永遠不會「完成」，只會「完成到夠用」**。

## 深層教訓：稀缺、制度與技術債

IPv4/IPv6 的拉鋸戰是一部「技術債的政治經濟學」教科書：

1. **稀缺創造市場**：IPv4 位址從免費贈品變成數十美元一個的資產，催生了位址經紀與投機。
2. **短期的聰明延誤長期的正確**：NAT 是 brilliant hack，卻也讓整個產業多繞了二十年路。
3. **轉型需要三力合擊**：技術方案（IPv6）+ 制度強制（政府/RIR 告罄）+ 市場信號（內容商先動）。任何單獨一項都推不動。

## 小結

IP 位址的枯竭，逼出了網際網路史上最漫長的一次「溫水換引擎」。它證明：協定可以升級，但**全球基礎設施的升級速度，由制度而非技術決定**。下一節回到物理層——真正的流量，始終要靠海底光纖與交換節點傳送。
