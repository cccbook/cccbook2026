# 《網頁設計的故事：從 CERN 第一個網頁、瀏覽器大戰、CSS 革命、響應式設計到 WebGL 與 AI 互動介面》

本書是寫給前端工程師、UI/UX 設計師、網頁視覺狂熱者與網際網路文明觀察者的專題史。網頁設計從來不只是排版文字和挑選顏色，它是人類為了將全球資訊網從枯燥的物理學家文字檔案，轉化為視覺沉浸、互動流暢的賽博空間建築藝術的歷史。全書 100% 基於真實歷史事件，以傳奇人物為主軸，按技術演進的時間順序推進。
