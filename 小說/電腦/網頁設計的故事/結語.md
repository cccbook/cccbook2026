# 結語：螢幕上的永恆流體——網頁設計者作為人類數位文明視覺邊界的拓荒者

## 五十六年，五次解放

從 1990 年 NeXT 電腦上的第一行 HTML，到 2026 年一句話生成的完整介面，網頁設計史的三十五年被五次解放串成。

第一次解放（1990 到 1993）：連結的誕生。柏內茲-李以 HTML 把人類文獻織成網，並以無償開源將未來交給所有人——這是制度性的解放。

第二次解放（1993 到 1998）：視覺的誕生。Mosaic 的 `<img>`、網景的 `<font>` 與表格，讓網頁從文字荒漠變成資本競逐的視覺舞台——這是表現力的解放。

第三次解放（1996 到 2005）：結構的誕生。CSS 把內容與外觀分離，AJAX 把互動與刷新分離——網頁第一次同時成為「出版物」與「應用程式」——這是設計職業本身的解放。

第四次解放（2007 到 2015）：流動的誕生。iPhone 與 RWD 教會設計師放棄對版面的絕對控制，擁抱沒有固定形狀的螢幕——這是哲學的解放。

第五次解放（2013 至今）：宣告的誕生。從 React 的元件到 Headless CMS、從 GPU 渲染到 AI 介面生成，網頁的製造方式不斷被推往更高層的抽象——這是製造方式的解放，也把「什麼是設計師」的問題推到了極限。

## 恆定的拉鋸

勝利之下，是五對從未被徹底解决的矛盾——它們構成了這門手藝的永恆張力：

表現力與效法的拉鋸：Flash 與 WebGL 都在「美到極致」與「重到拖垮」之間被審判。Core Web Vitals 與 Awwwards 之間，是效能與野心的溫和協議。

開放與圈佔的拉鋸：柏內茲-李的無償開源、W3C 的共識程序，與微軟的捆綁、蘋果的封殺、SaaS 的私圈——開放從來是結果而非預設。

工程與設計的拉鋸：從表格排版時代的設計委屈，到元件化時代的「設計即程式碼」，兩種思維的和解是靠工具的中介完成的——而新的工具總是帶來新的隔閡。

民主化與專業化的拉鋸：jQuery 民主化了互動，React 重設了門檻，AI 把門檻降到一句話——每一次降低都伴隨更高層專業技能的誕生。

圖形與意義的拉鋸：從搜尋引擎讀不懂 Flash，到今天 AI 生成代碼跑不出可及性規範——介面越眼花撩亂，「結構要能被機器與所有的人讀懂」這條底線就越是倫理問題。

## 留給下一個三十年

1990 年的那個中 encounter 裏，一個挪威工程師在一份提案的封面上寫下「Vague but exciting」。三十五年後回望，這六個字對每一個站在技術門檻前的人依然有效：一切革命開始時都含糊，一切新範式都曾令人興奮又令人不安。

2026 年的我們正面對新的「含糊」：AI 寫得出介面，但寫不出品味；算得出效能，但算不出責任；生成得了畫面，但「畫面該說什麼」仍然需要一個人的答案。這或許就是網頁設計者的最終也最深的職業本質——不是切版的人，不只是寫代碼的人，而是為人類的第二眼球做決定的人。

螢幕上的流體將繼續流動，物件的形體將繼續翻新，而「如何在像素與意義之間做出判斷」——這份手藝，將比任何一種框架、任何一家公司、任何一個模型，活得更久。

這是網頁設計者的故事，也是每位讀者在三十年後將親自續寫的下一章。
