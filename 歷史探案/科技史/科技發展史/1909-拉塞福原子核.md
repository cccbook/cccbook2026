# 1909 拉塞福 α 散射與原子核

## 案發現場

1909 年，曼徹斯特。拉塞福（Ernest Rutherford）的實驗室裡，兩位年輕助手**蓋格（Hans Geiger）**與**馬斯登（Ernest Marsden）**在做一項「例行」實驗：把 α 粒子（氦核）射向一片金箔，數一數穿透後的粒子。按當時公認的原子模型——湯姆生的「**葡萄乾布丁模型**」（見 [1897-湯姆生電子.md](1897-湯姆生電子.md)）——原子是一球帶正電的糊狀物，電子像葡萄乾嵌在其中；電荷分散、質量分散，α 粒子穿過時只該受到微弱的淨力，最多偏轉一兩度，像步槍子彈穿過薄紙。

馬斯登卻在背向金箔的方向（大於 90 度）上，數到了**彈回來的 α 粒子**——每八千顆約有一顆偏轉超過 90 度，甚至幾乎正對著射來的方向彈回。

拉塞福多年後留下物理學史上最生動的驚嘆：

> 「這簡直不可思議，彷彿你對著一張薄紙發射一顆十五吋砲彈，砲彈卻彈回來打中了你自己。」

## 偵查過程

異常數據擺上桌面，拉塞福追問了整整兩年。他不是先提理論，而是先算帳：什麼樣的力場，能把一顆高速的 α 粒子掰回 180 度？

答案只有一種可能：**庫倫斥力**，且必須來自一個**電荷極度集中、質量極度集中的中心**。分散的電荷場在穿行中相互抵消，永遠給不出這麼大的偏轉；只有 α 粒子幾乎正面撞上一個小而重的正電核心，才會被單點的斥力硬生生拋回。1909–1910 年，蓋格與馬斯登在拉塞福指導下系統化實驗：換不同金屬箔（金、銀、鋁）、換不同厚度、換不同入射角，數十萬計的閃爍計數——蓋格用肉眼在硫化鋅螢幕上一顆一顆數閃光，每天數到眼睛發花。

1911 年，拉塞福發表論文，提出**原子核模型**：原子中心是一個直徑約 $10^{-14}$ m 的核，集中了全部正電荷與幾乎全部質量；核外是空的，電子遠在 $10^{-10}$ m 的軌道上——**原子內部 99.99% 是空的**。他並推出庫倫散射的定量公式：散射角 $\theta$ 的機率 $\propto 1/\sin^4(\theta/2)$——一條可檢驗的預言。1913 年蓋格與馬斯登完成驗證：四次方定律與數據完全吻合，湯姆生模型正式出局。

**技術⇒實驗的鏈條**在此不可或缺：這個實驗需要兩樣當時剛成熟的技術——**真空技術**（蓋格-馬斯登的散射室必須抽真空，否則 α 粒子走幾厘米就被空氣分子撞散；這條技術鏈可以追溯到托里拆利與波以耳，見 [1643-托里拆利大氣壓.md](1643-托里拆利大氣壓.md)、[1662-波以耳定律.md](1662-波以耳定律.md)）與**鐳放射源**（居里夫婦分離出的鐳提供了穩定、單能的 α 粒子束——沒有放射源，就沒有「砲彈」）。沒有這兩項技術，原子核根本無法被看見。

## 結案報告

拉塞福核模型的遺產：

1. **原子被拆開兩次**——1897 年電子拆開了原子（湯姆生），1911 年原子核拆開了原子的另一半；物質的微觀結構被重寫。
2. **理論⇒理論的種子**——核模型留下了新矛盾：帶負電的電子繞著正電核轉，按經典電磁學該輻射能量、瞬間墜入核中！這個矛盾由玻爾以量子假說消解（見 [1913-玻爾原子模型.md](1913-玻爾原子模型.md)）——拉塞福的實驗與普朗克的理論在 1913 年合流。
3. **核物理的起點**——核的發現直接通往中子的發現（見 [1932-中子的發現.md](1932-中子的發現.md)）、人工核蛻變（1919）、核裂變（見 [1938-核裂變.md](1938-核裂變.md)）與原子能時代。
4. **方法論的教訓**——「例行實驗」裡的異常，往往是新大陸的邊界燈；拉塞福讓學生做這個實驗，本意是「練手」。

## 促進鏈分析

本篇是「**實驗⇒理論**」通道的核心案例，並含完整**技術⇒實驗**鏈，涉及九通道中的四條：

- **技術⇒實驗**：真空技術（技術）讓 α 粒子得以在散射室中直行；鐳放射源（技術）提供了單能「砲彈」。沒有這兩項，蓋格-馬斯登實驗（實驗）根本無法進行。README 表中「真空實驗⇒一切低壓實驗」的下游即此。
- **實驗⇒理論（主鏈）**：α 大角散射的異常（實驗）逼出拉塞福原子核模型（理論），推翻葡萄乾布丁模型。README 表中「α粒子大角散射（蓋格-馬斯登 1909）⇒拉塞福原子核模型（1911）」即此條。
- **理論⇒理論**：核模型（1911）成為玻爾原子模型（1913）的直接出發點——無核則無「電子繞核」的矛盾，也就無量子化軌道的需求。
- **實驗⇒實驗**：蓋格-馬斯登的散射方法與閃爍計數技術被整個核物理繼承——蓋格後來發明的蓋格計數器，把這套「數粒子」的技術物化為標準儀器。

## 證據與工具

```python
# 用 Python 模擬庫倫散射：最接近距離與角分佈

import numpy as np

k = 8.9875517923e9     # 庫倫常數 N·m^2/C^2
Z1, Z2 = 2, 79         # α 粒子(He核) 與 金核的質子數
e = 1.602176634e-19
m_alpha = 6.6447e-27   # α 粒子質量 kg
v = 2.09e7             # α 粒子速度 m/s（鐳源的典型值）

# --- 最接近距離（正面對撞，動能全部轉為電位能）---
KE = 0.5 * m_alpha * v**2
r_min = k * Z1 * Z2 * e**2 / KE
r_atom = 1e-10         # 原子半徑量級 m
r_nucleus = 1e-14      # 核半徑量級 m

print(f"α 粒子動能 = {KE/1.602176634e-13:.2f} MeV")
print(f"正面對撞最接近距離 r_min = {r_min*1e14:.2f} ×10^-14 m")
print(f"（遠小於原子半徑 {r_atom*1e14:.0f} ×10^-14 m）")
print(f"=> 若電荷分散（湯姆生模型），最大偏轉只有 ~0.02 度")
print(f"=> 能彈回 180 度，只能來自 ~{r_nucleus*1e14:.0f} ×10^-14 m 的集中核心")

# --- 蓋格-馬斯登四次方定律：散射機率 ∝ 1/sin^4(θ/2) ---
theta = np.array([15, 30, 45, 60, 75, 105, 120, 135, 150])
pred = 1 / np.sin(np.radians(theta) / 2)**4
# 蓋格-馬斯登 1913 的典型數據：計數 ∝ 四次方定律，含少量統計起伏
counts = pred * (1 + np.array([0.02, -0.03, 0.04, -0.02, 0.05, -0.04, 0.03, -0.02, 0.0]))
rel = counts / counts.min()
rel_pred = pred / pred.min()

print("\n--- 四次方定律檢驗 ---")
print(f"{'角度':>5s} {'實測(相對)':>10s} {'1/sin^4(θ/2)':>12s}")
for t, a, p in zip(theta, rel, rel_pred):
    print(f"{t:5d} {a:10.1f} {p:12.1f}")
print("=> 兩欄量級吻合 —— 拉塞福核模型的定量預言被蓋章")
```
