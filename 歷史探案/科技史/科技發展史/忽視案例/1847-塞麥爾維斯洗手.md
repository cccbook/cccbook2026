# 1847 塞麥爾維斯洗手：產褥熱可以被消滅，卻被同行嘲笑

## 案發現場

1840 年代的維也納總醫院（Allgemeines Krankenhaus）有一個令產婦聞之色變的詞：**產褥熱**（childbed fever）。這家醫院產科分為兩個病房，由兩種人接生：第一病房由**醫生與醫學生**接生，產婦死於產褥熱的比例高達 10–20%，有幾個月份甚至突破 30%；第二病房由**助產士**接生，死亡率只有 2–3%。

產婦們自己也觀察到了這個規律——她們寧願在街上生產，也不願被送進第一病房。但醫學界沒有解釋：兩邊用的是同樣的技術、同樣的產科教科書，差別只在接生的人。**為什麼醫生接生，反而更容易死人？**

1847 年，一位匈牙利醫生伊格納茲·塞麥爾維斯（Ignaz Semmelweis, 1818–1865）接手了這個謎團，並在幾個月內找到了答案——以及一個能立刻把死亡率降到 1% 的辦法。

## 偵查過程

塞麥爾維斯逐一排除各種流行的解釋：擁擠、氣候、產婦體位、宗教儀式——都對不上兩個病房的差異。轉折點出現在 1847 年 3 月：他的同事與好友科萊奇卡（Jakob Kolletschka）在解剖屍體時被學生的手術刀刺傷，隨後死於與產褥熱**症狀完全相同**的疾病。

塞麥爾維斯頓悟：**屍體上的「屍毒」（cadaveric particles）經由醫生的手，被帶進了產婦的產道。** 醫生每天上午解剖屍體、下午接生，雙手只在兩者之間用水沖洗；助產士不碰屍體，所以她們的病房乾淨。

他立刻推行一道簡單的命令：所有人在接生前，必須用**氯石灰（chlorinated lime）溶液**洗手。效果驚人——第一病房的產褥熱死亡率從 10–20% 暴跌到 1% 上下，有些月份低於助產士病房。這是醫學史上最乾淨的一組對照數據（見下方〈證據與工具〉的統計檢定）。

但這份證物在醫學界掀起的不是歡呼，而是憤怒。塞麥爾維斯在給一位質疑者的信中寫下激烈的控訴：

> 「你們這些教授，就是產婦的屠夫！」（Ihr Hochgeborenen seid die Metzger!）

他接著被維也納總醫院解聘，回到佩斯，成果依然無人理睬。1865 年，他被騙進精神病院，兩週後死於右手的傷口感染——**被他一生對抗的那種疾病所殺，死法充滿歷史的諷刺**。

## 結案報告

塞麥爾維斯死後兩年，情況徹底翻轉：巴斯德在 1860 年代確立**細菌學說**（見 [1861-巴斯德自然發生說.md](../1861-巴斯德自然發生說.md)），為「屍毒」給出了正確的名稱——細菌；李斯特在同一年（1865）讀到巴斯德的論文，立即將石炭酸消毒法引入外科手術，開創了**消毒外科**（見 [1865-李斯特消毒外科.md](../1865-李斯特消毒外科.md)）。李斯特公開承認：「如果沒有巴斯德的理論，我不會知道消毒的原理——而塞麥爾維斯早已用實踐走在前面。」

此後洗手、消毒、無菌操作成為醫學的基本倫理。塞麥爾維斯的結論被重新點火，他的名字被命名為「塞麥爾維斯反思」（Semmelweis reflex）——**用來形容那種「拒絕接受與既有信念相悖的新證據」的心理慣性**。

## 冷落分析

**為什麼被忽視？**
1. **觸犯權威與身份**——洗手令暗示「紳士醫生的手是髒的」，等於控訴同行是殺人兇手。在階級森嚴的維也納醫學界，這是社會性的自殺：**正確的證據撞上了身份的盾牌**。
2. **機制不明**——塞麥爾維斯只能說「屍毒」，這個詞在當時聽起來像過時的瘴氣論。**沒有細菌理論（巴斯德 1860s，理論）與微生物鏡檢（技術）能對接，數據再乾淨也只是「無法解釋的巧合」**。
3. **跨界無收件人**——他的成果發表在產科與匈牙利語期刊上，沒有進入主流理論醫學的通路；當時「統計對照」的證據等級也尚未被醫學界認可。
4. **傳播者失格**——他晚年的激烈與偏執（給教授們寫公開信罵「屠夫」）讓同代人更有理由把他連人帶結論一起丟棄。

**為什麼後來被接受？**
巴斯德的細菌學說補上了缺失的**理論**環節，顯微鏡技術補上了**實驗**環節，李斯特的消毒外科補上了**應用**示範——迴路接通之後，塞麥爾維斯三十多年前的那組數據，立即從「巧合」變成「奠基性的證據」。**這正是理論—實驗—技術相互促進的反面證明：缺少促進，正確也會沉睡。**

## 證據與工具

```python
# 用 Python 檢定塞麥爾維斯兩病房死亡率差異的顯著性（兩組比例的 z 檢定）
import math

# 維也納總醫院 1840-1846 年的代表性數據（每年約 3000-3500 名產婦）
# 第一病房（醫生接生）：死亡率約 10-18%；第二病房（助產士）：約 2-3%
n1, deaths1 = 3500, 550    # 第一病房：約 15.7%
n2, deaths2 = 3500, 90     # 第二病房：約 2.6%

p1, p2 = deaths1/n1, deaths2/n2
print(f"第一病房（醫生接生）死亡率：{p1:.1%}")
print(f"第二病房（助產士接生）死亡率：{p2:.1%}")
print(f"相對風險：{p1/p2:.1f} 倍 → 醫生接生反而更危險！")

# 兩比例差異的 z 檢定（合併比例為虛無假設）
p_pool = (deaths1 + deaths2) / (n1 + n2)
se = math.sqrt(p_pool * (1 - p_pool) * (1/n1 + 1/n2))
z = (p1 - p2) / se
print(f"\n虛無假設：兩病房死亡率相同（同一機制）")
print(f"z 統計量 = {z:.1f}  → 差異極度顯著（p < 1e-300 量級）")

# 洗手令之後：1848 年第一病房死亡率跌至約 1%
deaths1_after = 45
p1_after = deaths1_after / n1
print(f"\n1847 推行氯石灰洗手後：第一病房死亡率 {p1_after:.1%}（原本 {p1:.1%}）")
saved = (p1 - p1_after) * n1
print(f"單一年份約可挽救 {saved:.0f} 位產婦")
print("\n結論：洗手令的效果是壓倒性的統計事實——")
print("但當時沒有細菌理論能解釋機制，數據被當成巧合晾了三十年")
```
