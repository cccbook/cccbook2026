# 負面案例：迴路的自我糾錯（科學史）

> 金觀濤「理論—實驗—技術」循環的另一面：**這個迴路不僅會加速，還會自我糾錯**。
>
> 錯誤的理論會讓實驗與技術瞎忙數十年甚至數百年（燃素說、以太說、永動機）；造假的實驗會讓假的理論被奉為真（皮爾當人、黃禹錫、Schön）。但每一次，糾錯的力量**仍然來自迴路本身**：更精的儀器、更嚴的統計、更獨立的複製實驗——**「複製與檢驗」正是科學區別於一切信仰體系的根本機制**。
>
> 本幕的每篇 wiki 都是「負面探案」：謎團不是「自然為什麼這樣」，而是「**假象為什麼成立得這麼久**」——以及是誰、用什麼工具把它拆穿的。

## 糾錯機制的規律

1. **假象的壽命與「檢驗成本」成反比**——N 射線只需拔掉一塊稜鏡（兩年）；皮爾當人需要化學定年（四十年）；冷融合需要全世界的重複實驗（至今）。檢驗工具（技術）越強，謊言壽命越短。
2. **權威與民族自尊是假象的保護殼**——N 射線源於法國想跟進德國 X 光的榮耀焦慮；皮爾當人迎合了英國人「英國才是人類搖籃」的期待。**社會心理讓假理論免於被檢驗**。
3. **拆穿者幾乎總是外來者或持異見者**——Wood 是路過的美國人；拆穿皮爾當人的是南非的氟定年專家；質疑 Schon 的是普林斯頓的 Lydia Sohn 與康乃爾的 Paul McEuen。
4. **糾錯的工具本身來自迴路**——化學定年法、電子顯微鏡、統計比對、DNA 檢驗：每個拆穿工具都是理論-實驗-技術循環的產物。**科學的自我糾錯不是道德，而是結構**。
5. **造假之後，正常的科學照常前進**——幹細胞研究在黃禹錫之後由山中伸彌（2012，iPS 細胞）完成突破；N 射線死後雷射（[1960-雷射.md](../1960-雷射.md)）照樣誕生。**迴路的自我修復能力，正是它能永不停下的原因之一**。
