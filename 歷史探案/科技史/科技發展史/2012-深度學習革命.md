# 2012 深度學習革命

## 案發現場

2012 年 10 月，ImageNet 大規模視覺辨識競賽（ILSVRC）結果揭曉：多倫多大學一支由辛頓（Geoffrey Hinton）與他兩名學生克里澤夫斯基（Alex Krizhevsky）、蘇茨克弗（Ilya Sutskever）組成的團隊，以一個名為 **AlexNet** 的深度神經網路，把辨識錯誤率從上屆的 25.8% 一舉壓到 15.3%——領先第二名超過 10 個百分點。評審驚呆了：傳統方法的誤差率幾乎紋風不動，這支黑馬卻是斷崖式躍進。

這不是一次普通的競賽勝利，而是三股力量——**演算法（理論）、大數據（實驗）、算力（技術）**——在這一年精準匯流的總爆發。

## 偵查過程

偵查線索有三條，每條都沉澱了數十年：

**第一條（理論）：神經網路的思想積澱。**1958 年羅森布拉特的感知機、1986 年辛頓與魯梅爾哈特的**反向傳播（backpropagation）**演算法，已給出訓練多層神經網路的數學方法。但深層網路長期被視為「訓練不動、容易過擬合」的旁門左道，主流是支持向量機等統計方法。理論在等它的兩個同伴。

**第二條（實驗）：大數據的量產。**2009 年史丹佛李飛飛團隊建成 **ImageNet**：1,400 萬張人工標註圖片、2 萬多個類別。這是實驗數據的量產——沒有這座資料寶庫，深層網路的數百萬參數只會過擬合。**實驗數據的規模，第一次成為理論能否成立的先決條件。**

**第三條（技術）：GPU 的算力。**AlexNet 用兩張遊戲用的 GTX 580 顯示卡訓練一週。神經網路的矩陣運算恰好與 GPU 的平行架構完美匹配——把算力提升數十倍。這是 [1971-微處理器.md](1971-微處理器.md) 與 [1965-摩爾定律.md](1965-摩爾定律.md) 的集大成：**算力，從機房奢侈品變成消費電子零件。**

辛頓說：「我們一直都知道深層網路是對的，我們只是在等夠多的數據和夠快的電腦。」

## 結案報告

深度學習革命是「**全迴路**」的總結案例：理論（反向傳播、卷積架構）、實驗（ImageNet 大數據）、技術（GPU 算力）三者缺一不可，同時到位，於是迴路瞬間閉合並全面爆發。

1. **理論反哺的加速**——AlexNet 之後，殘差網路（ResNet，2015）、Transformer（2017，Google「注意力就是你所需要的一切」）接連出現，深度學習從視覺擴散到語言、語音、蛋白質折疊（AlphaFold，2020）。
2. **實驗的新形態**——大數據集成為科學的常設基礎設施，「資料即實驗」成為新範式。
3. **技術的匯流**——GPU 算力+雲端服務，讓任何研究者都能訓練模型：迴路終端進入每個實驗室。
4. **迴路擴散為全球網絡**——開源框架（TensorFlow、PyTorch）與預訓練模型公開分享，**每個人手中都握有一個理論-實驗-技術終端**：一部筆電就能下載模型、微調、發表。科學循環從精英機構擴散為全球開源網絡——這是第九幕的完成式，也為 [2020-mRNA疫苗.md](2020-mRNA疫苗.md) 的全球大匯流鋪路。

## 證據與工具

```python
# 極簡神經網路：反向傳播 + 梯度下降（AlexNet 的數學核心）
# 用一個 2 層網路學習 XOR，演示「理論-實驗-技術」的匯流點

import numpy as np
np.random.seed(42)

# --- 實驗：數據（XOR 問題）---
X = np.array([[0,0],[0,1],[1,0],[1,1]], dtype=float)  # 輸入
y = np.array([[0],[1],[1],[0]], dtype=float)          # 目標

# --- 理論：網路結構與前向傳播 ---
sigmoid = lambda z: 1/(1+np.exp(-z))
W1 = np.random.randn(2,4); b1 = np.zeros(4)   # 隱藏層
W2 = np.random.randn(4,1); b2 = np.zeros(1)   # 輸出層

def forward(X):
    h = sigmoid(X @ W1 + b1)
    return sigmoid(h @ W2 + b2), h

# --- 技術：反向傳播 + 梯度下降訓練 ---
lr = 1.0
for epoch in range(3000):
    out, h = forward(X)
    loss = np.mean((out - y)**2)                    # 均方誤差
    d_out = 2*(out - y) * out*(1-out)               # 輸出層梯度
    d_h   = (d_out @ W2.T) * h*(1-h)                # 隱藏層梯度（鏈式法則）
    W2 -= lr * h.T @ d_out; b2 -= lr * d_out.sum(0) # 梯度下降
    W1 -= lr * X.T @ d_h;  b1 -= lr * d_h.sum(0)

out, _ = forward(X)
print("訓練後預測：")
for xi, yi, oi in zip(X, y, out):
    print(f"  {xi} -> {oi[0]:.4f}（目標 {yi[0]}）")
print(f"最終誤差：{np.mean((out-y)**2):.6f}")
print("\n反向傳播 = 理論（鏈式法則）+ 實驗（數據）+ 技術（算力）的匯流")
```
