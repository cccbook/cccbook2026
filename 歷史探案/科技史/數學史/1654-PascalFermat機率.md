# 1654 - Pascal–Fermat 機率

## 案件摘要
1654 年，法國的 Blaise Pascal 與 Pierre de Fermat 通信解決**賭金分配問題**（problem of points）：賭局中斷時，賭金怎麼分？他們的通信建立**期望值與條件機率**——**機率論的誕生**。一封貴族的信（de Méré 問 Pascal）引出七封通信——**賭徒的問題催生了嚴肅的數學**。這是機率統計（見 `../機率統計/README.md`）與隨機算法（見 `../隨機算法/README.md`）的源頭。

## 前因 -- 為什麼會有這個案子
**賭金分配問題**：兩個賭徒（A、B）比賽，先贏 $n$ 局者得全部賭金。**中斷時**（A 贏 $a$ 局、B 贏 $b$ 局，$a < n, b < n$）——賭金怎麼分？

**傳統的答案**（15 世紀義大利）：按已贏局數比例分——**顯然不對**（A 贏 1 局 vs B 贏 0 局的優勢遠大於 1:0 的比例）。

**de Méré 騎士的問題**（1654 年寫信給 Pascal，他本人是職業賭徒）：

1. **骰子的悖論**：丟一顆骰子 4 次，出現 6 的機率 > 1/2 ✓；丟兩顆骰子 24 次，出現雙 6 的機率 > 1/2？——**實際 < 1/2**——賭徒的直覺失效！
2. **賭金分配**：中斷的賭局怎麼分？

**Pascal 的環境**：17 歲的天才（錐線論）、巴黎沙龍的數學家。**他轉信 Fermat**（圖盧茲的律師、業餘數學家）——七封通信（1654 年 7–10 月）。

## 線索與推理 -- 數學式、程式、理論

### 期望值與條件機率
**賭金分配的解法（Pascal–Fermat）**：不按已贏局數分，按**未來獲勝的機率**分——**期望值**：

**假設**：每局等可能（$p = 1/2$），先贏 $n$ 局得 $S$。中斷時 A 需再贏 $n - a$ 局、B 需 $n - b$ 局。

**Fermat 的方法（遞迴/枚舉）**：列出所有可能的未來局（最多 $n - a + n - b - 1$ 局），統計 A 獲勝的比例：

$$\text{A 的份額} = S \cdot P(\text{A 最先贏 } n \text{ 局})$$

**範例**：先贏 3 局，中斷時 A 贏 2、B 贏 1（各再需 1、2 局）：

- 未來兩局的可能：AA（A 贏）、AB、BA、BB——**A 獲勝 3/4**（除 BB 外都贏）
- A 的份額 $= \frac{3}{4}S$，B 的份額 $= \frac{1}{4}S$

**Pascal 的方法（Pascal 三角形）**：遞迴關係

$$P(a, b) = \frac{1}{2}P(a+1, b) + \frac{1}{2}P(a, b+1)$$

——**邊界條件** $P(n, b) = 1$、$P(a, n) = 0$——Pascal 三角形（楊輝三角，見 `0263-LiuHui割圓術.md` 的中國傳統）。

### 期望值的定義
**期望值**（Fermat–Pascal 的隱含概念，Huygens 1657 正式化）：

$$E[X] = \sum_i p_i x_i$$

**賭局的公平價值**——**機率論的核心概念**（與 Bernoulli 1713 的大數法則、蒙地卡羅方法 1946 的平均估計同源，見 `../隨機算法/1946-Ulam蒙地卡羅.md`）。

### 骰子悖論的解決
**de Méré 的悖論**：
- 一顆骰子 4 次出現 6：$P = 1 - (5/6)^4 \approx 0.518 > 1/2$ ✓
- 兩顆骰子 24 次出現雙 6：$P = 1 - (35/36)^{24} \approx 0.491 < 1/2$ ✗

**推理**：de Méré 錯在「線性外推」（4 次:6 面對 24 次:36 面的「比例」）——**機率是指數關係**，不是線性。**賭徒直覺的失敗 = 數學的必要**——這就是機率論誕生的動力。

### 程式碼：賭金分配與期望值

```python
import random

def points_recursion(a, b, n, memo={}):
    """Pascal 的遞迴：P(先贏 a 局，需 n 局得全部) 的獲勝機率"""
    if a >= n: return 1.0
    if b >= n: return 0.0
    if (a, b) in memo: return memo[(a, b)]
    # 一半機率 A 贏下一局、一半 B 贏
    memo[(a, b)] = 0.5 * points_recursion(a+1, b, n, memo) + 0.5 * points_recursion(a, b+1, n, memo)
    return memo[(a, b)]

# 範例：先贏 3 局，中斷時 A=2, B=1
p_a = points_recursion(2, 1, 3)
print(f"A 的獲勝機率 = {p_a:.4f}（3/4 = 0.75）→ 份額 {p_a*100:.0f}%")

# 蒙地卡羅驗證（Ulam 1946 的方法，見 ../隨機算法/1946-Ulam蒙地卡羅.md）
random.seed(42)
wins = 0
for _ in range(100000):
    a, b = 2, 1
    while a < 3 and b < 3:
        if random.random() < 0.5: a += 1
        else: b += 1
    if a == 3: wins += 1
print(f"蒙地卡羅驗證：A 獲勝 = {wins/100000:.4f} ✓")

# de Méré 的骰子悖論
p1 = 1 - (5/6)**4          # 一顆骰子 4 次
p2 = 1 - (35/36)**24       # 兩顆骰子 24 次
print(f"\n一顆骰子 4 次出 6：{p1:.4f} > 1/2 ✓")
print(f"兩顆骰子 24 次出雙 6：{p2:.4f} < 1/2 ✗——賭徒直覺的失敗")
print("機率是指數關係，不是線性——數學的必要")
```

### 從賭局到科學
**譜系**：
- **1654 Pascal–Fermat 通信**：期望值、條件機率
- **1657 Huygens**：《論骰子賭局的推理》——期望值的正式化（第一本機率教科書）
- **1713 Bernoulli**：《猜度術》——大數法則（頻率收斂）
- **1777 Buffon**：幾何機率（見 `../隨機算法/1777-Buffon針實驗.md`）
- **1812 Laplace**：《機率的解析理論》——古典機率的頂峰
- **1933 Kolmogorov**：公理化（見 `1933-Kolmogorov公理化.md`）

**偵探筆記**：Pascal–Fermat 的推理是「**按未來機率分，不按過去局數分**」——把「公平」從經驗（已贏多少）變成數學（未來獲勝的期望）。**賭徒的問題催生嚴肅的數學**——與 Ulam 的接龍（1946，見 `../隨機算法/1946-Ulam蒙地卡羅.md`）同源：**遊戲是數學的溫床**。

## 結案 -- 後果與影響
- **機率論的誕生**：期望值與條件機率——從賭局的經驗到數學的概念。
- **Pascal 三角形**：組合數學的工具（與楊輝三角的中國傳統匯流）。
- **期望值的概念**：決策理論、保險、經濟學的基礎——「公平價值」的數學化。
- **賭徒直覺的教訓**：指數關係 vs 線性外推——**機率直覺的不可靠**（與 Lazzarini 的造假、蒙地卡羅的統計陷阱同源）。
- **Pascal 的轉向**：1654 年 11 月的「夜火」宗教體驗——Pascal 棄數學轉神學（《思想錄》）。**數學天才的另一種人生**。
