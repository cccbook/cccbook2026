# 1703 - 萊布尼茨二進制

## 案件摘要
1703 年，Gottfried Leibniz 在巴黎科學院發表《論只用 0 與 1 的算術》（Explication de l'Arithmétique Binaire）：系統化**二進制**——只用 0 與 1 表示一切數。他驚喜地發現中國《易經》的六十四卦（伏羲八卦的陰爻陽爻）正是二進制的排列——「**東方哲學與西方數學的相遇**」。**二進制是電腦的數學語言**——Leibniz 夢想的「通用計算機」二百年後由 Turing（1936，見 `../計算理論/1936-Turing機與停機問題.md`）與 von Neumann（1945）實現。

## 前因 -- 為什麼會有這個案子
**Leibniz 的兩大夢想**：

1. **通用語言（characteristica universalis）**：把一切思想化為符號——推理變成計算（「讓我們計算吧！」——哲學爭論的終極方案）
2. **通用計算機**：機械化計算——他 1673 年製作的**步進計算器**（stepped reckoner）能做乘除（Pascal 的加法器 1642 只能加減）

**二進制的線索**：1679 年 Leibniz 已寫下二進制的手稿——**為什麼用二進制**？「**最簡單的符號系統**：只有 0 與 1，一切數都可以表示」。

**1701 年**，傳教士 Bouvet（白晉）從中國寄來《易經》的六十四卦圖——**Leibniz 的驚喜**：陰爻（⚋）與陽爻（⚊）的組合正是二進制 0–63 的排列——「**伏羲是二進制的發明者**」（他錯了——《易經》是占卜文本，不是數學——但這個「誤會」催生了二進制的發表）。

## 線索與推理 -- 數學式、程式、理論

### 二進制的數學
**位值系統**（與花拉子米的十進制同構，見 `0820-Khwarizmi代數學.md`，但基底為 2）：

$$n = \sum_{i} b_i 2^i \quad (b_i \in \{0, 1\})$$

**範例**：$13 = 8 + 4 + 1 = 1101_2$。

**四則運算的簡化**：

- **加法**：只有 $1+1 = 10$（進位）——**最小的加法表**
- **乘法**：只有 $1 \times 1 = 1$——**與布爾代數同構**（AND）！
- **邏輯**：1 = 真、0 = 假——**數與邏輯的合一**（Leibniz 的夢想：推理 = 計算）

**Leibniz 的推理**：「用最少的符號表示最多的數」——**資訊的編碼**（與 Shannon 熵 1948 的 bit 同源——**bit 就是 binary digit**）。

### 《易經》與二進制
**Leibniz 的對應**：

$$\text{陽爻 } \text{⚊} = 1, \quad \text{陰爻 } \text{⚋} = 0$$

六十四卦 = 6 位二進制（$2^6 = 64$ 種組合）——Leibniz 排列卦序發現與二進制**完全一致**。

**現代的檢驗**：《易經》的卦序**不是**二進制排序（是占卜的傳統排序）——Leibniz 的「發現」是**誤讀**（但數學上 64 卦確實**可以**用二進制編碼——「可以編碼」≠「本來就是」）。

**深遠的教訓**：**後見之明的編碼**——任何結構都可以「事後」用二進制編碼，但「可以編碼」不等於「原意如此」。這個教訓在現代 AI（見 `../密碼學/2022-LLM時代密碼學.md` 的記憶攻擊）與資料科學中依然適用。

### 程式碼：二進制與易經

```python
def to_binary(n):
    """十進制轉二進制（位值系統）"""
    if n == 0: return "0"
    bits = []
    while n:
        bits.append(str(n % 2))
        n //= 2
    return ''.join(reversed(bits))

# 13 = 1101（8 + 4 + 1）
print(f"13 = {to_binary(13)}")
print(f"驗證：{1*8 + 1*4 + 0*2 + 1*1}")

# 二進制加法的簡化（最小加法表）
def binary_add(a, b):
    """二進制加法：只有 0+0, 0+1, 1+0, 1+1=10 四種情況"""
    result, carry = [], 0
    for x, y in zip(reversed(a), reversed(b)):
        s = int(x) + int(y) + carry
        result.append(str(s % 2))
        carry = s // 2                     # 1+1 = 10（進位）
    if carry: result.append('1')
    return ''.join(reversed(result))

print(f"1101 + 1011 = {binary_add('1101', '1011')}（= {13+11} = {to_binary(24)}）✓")

# 易經的六十四卦（Leibniz 的對應）
def hexagram(i):
    """i (0-63) → 六爻（陽 = 1 ⚊，陰 = 0 ⚋）"""
    bits = to_binary(i).zfill(6)
    return ''.join('⚊' if b == '1' else '⚋' for b in bits)

print("\n六十四卦 = 6 位二進制（Leibniz 的驚喜）：")
for i in [0, 1, 42, 63]:
    print(f"  {i:2d} = {hexagram(i)}（二進制 {to_binary(i).zfill(6)}）")
# 63 = ䷀（乾卦，全陽）——二進制 111111
print("——伏羲卦序不是二進制排序，但 64 卦可以二進制編碼")
```

### 通用計算機的夢想
**Leibniz 的推理鏈**：二進制（0 與 1）→ 邏輯（真與假）→ **推理 = 計算**——「讓我們計算吧！」

**兩百年後的實現**：
- **Boole（1854）**：布爾代數——邏輯的代數化（AND、OR、NOT）
- **Turing（1936）**：通用圖靈機——一切「有效計算」的極限（見 `../計算理論/1936-Turing機與停機問題.md`）
- **Shannon（1937）**：**二進制 + 布爾代數 = 電路**——電腦的數學基礎（Shannon 的碩士論文！）
- **von Neumann（1945）**：二進制電腦（EDVAC 報告）——現代電腦的架構

**Shannon 的橋樑**：**Leibniz 的夢想（推理 = 計算）→ Boole 的代數 → Shannon 的電路 → 電腦**——二進制是這條鏈的地基。

**偵探筆記**：Leibniz 的推理是「**最簡符號系統**」——只有 0 與 1，數與邏輯合一。**《易經》的誤讀**（占卜 ≠ 數學）催生了發表——**美麗的誤會推動歷史**（與 Lazzarini 的擲針、Galileo 的望遠鏡誤讀同源）。

## 結案 -- 後果與影響
- **電腦的數學語言**：二進制——從 Leibniz 的夢想到 von Neumann 架構。
- **Shannon 的橋樑**（1937）：二進制 + 布爾代數 = 電路——**數位電路的誕生**。
- **bit 的本質**：binary digit——資訊論（Shannon 1948）的單位。
- **《易經》的誤讀**：可以編碼 ≠ 本意如此——**後見之明的教訓**。
- **通用語言的夢想**：推理 = 計算——Leibniz 的夢想在電腦科學（與 LLM 的「計算語言學」）中部分實現。
- **邏輯的代數化**：與 Boole（1854）、Frege（1879）的邏輯傳統匯流（見 `1902-Russell悖論.md`）。
