# 1976 - 四色定理

## 案件摘要
1976 年，伊利諾大學的 Appel 與 Haken 用**電腦**證明四色定理：任何平面地圖只需 4 種顏色就能相鄰著色不同——**人類史上第一個電腦證明的重大數學定理**。證明依賴 1200 小時的電腦運算與 1834 個「不可約構形」的檢驗——**人類無法逐一檢查**。這引發數學界的哲學地震：**電腦證明是證明嗎？**「可檢驗性」這個數學的本質屬性被挑戰——形式化驗證（2005 年 Gonthier 的 Coq 證明）最終回應了這個疑慮。

## 前因 -- 為什麼會有這個案子
**1852 年**，英國的 Francis Guthrie 在為英國地圖著色時提出：**任何地圖只需 4 種顏色**？——弟弟 Frederick 問了 De Morgan，De Morgan 寫信給 Hamilton——**四色問題誕生**。

**陳述**：平面上的任何地圖（區域相鄰關係），4 種顏色足夠使相鄰區域不同色。

**125 年的攻擊**：
- **1879 年 Kempe**：宣稱證明——**1890 年 Heawood 發現錯誤**（但 Heawood 用同方法證出**五色定理**——5 色足夠）
- **19 世紀末–20 世紀**：數百篇「證明」全錯——**這是數學史上「錯誤證明」最多的問題**
- **1922 年 Franklin**：28 個國家以內成立——範圍逐步擴大
- **1950 年代**：Heesch 提出「不可約構形」的策略——**用電腦窮舉構形**

**Appel–Haken 的問題**：能否用電腦**窮舉所有不可約構形**，逐一檢驗？

## 線索與推理 -- 數學式、程式、理論

### 不可約構形（unavoidable set）
**策略（Heesch → Appel–Haken）**：

1. **不可約構形**：某些小圖案（構形）——若地圖包含它，可以用「 reducibility」技術縮小
2. **不可避集（unavoidable set）**：一組構形，**任何平面地圖必包含其中之一**
3. **證明結構**：不可避集 + 每個構形可縮小 ⟹ **歸納證明**（地圖 → 縮小 → 歸納）——4 色成立

**關鍵**：需要找到一組「既不可避、又全部可約」的構形——**1834 個構形**（Appel–Haken 的最終數字）。

**數學**：

$$\text{每個構形可約} \implies \text{4 色成立（歸納）} \quad \blacksquare$$

**但**：1834 個構形的可約性檢驗——**每個都要數小時的電腦運算**，總共 1200 小時——**人類無法逐一檢查**。

### 電腦證明的哲學地震
**數學證明的傳統**：證明 = **可被任何人檢驗**的邏輯推理——數學的「民主性」（與 Kerckhoffs 原則的公開檢驗同源，見 `../密碼學/1883-Kerckhoffs原則.md`）。

**四色定理的挑戰**：

- 證明依賴**電腦程式**——誰檢驗程式？（Appel–Haken 自己的程式也有 bug——後來被發現並修正）
- **人類無法逐一檢查** 1834 個構形——「信任電腦」成為必要
- **哲學問題**：數學證明的本質是「理解的邏輯」還是「機器的檢驗」？

**爭論的兩派**：
- **接受派**：證明 = 正確性的保證，電腦算力也是證據（Appel–Haken、現代多數）
- **懷疑派**：證明 = 可理解性，電腦證明「不透明」（Tymoczko 的哲學批評 1979）

### 2005 年的形式化驗證
**Gonthier 的 Coq 證明（2005）**：把四色定理的證明**完全形式化**（Coq 證明助理——每一步邏輯都機器檢驗）：

$$\text{數學證明} \to \text{形式化（Coq）} \to \text{機器檢驗的邏輯推理}$$

**推理**：形式化後，證明不再是「電腦暴力 + 人類無法檢查」，而是「**機器檢驗的完整邏輯**」——可檢驗性恢復（雖然「可理解性」仍是問題）。**2008 年**：Gonthier 的團隊又形式化證明了**奇數階定理**（Feit–Thompson 定理，2012 完成）——形式化驗證的帝國。

**偵探筆記**：四色定理的推理鏈：不可避集 + 可約性 → 歸納。**「人類直覺找結構（構形）、電腦暴力檢驗（可約性）」**——人機協作的典範，預示了現代的**電腦輔助證明**（如 Kepler 猜想、Hales 的 Flyspeck 2014）與**實驗數學**（見 `2013-ZhangYitang素數間距.md` 的素數間距資料）。

### 程式碼：平面圖著色

```python
import random

def four_color_check(graph, coloring):
    """檢查著色：相鄰節點不同色"""
    for u, v in graph:
        if coloring[u] == coloring[v]:
            return False
    return True

def greedy_color(graph, nodes, colors=4):
    """貪心著色（概念示範：平面圖 4 色可著色——四色定理保證）"""
    coloring = {}
    for n in nodes:
        used = {coloring[u] for u, v in graph if v == n and u in coloring}
        used |= {coloring[u] for u, v in graph if u == n and v in coloring}
        for c in range(colors):
            if c not in used:
                coloring[n] = c
                break
    return coloring

random.seed(42)
# 平面圖（概念）：4 個區域兩兩相鄰 = K4（需要 4 色）
graph = [(0,1), (0,2), (0,3), (1,2), (1,3), (2,3)]
nodes = [0, 1, 2, 3]
coloring = greedy_color(graph, nodes)
print(f"K4 著色 = {coloring}——4 色剛好足夠")
print(f"檢查：{four_color_check(graph, coloring)} ✓")
print("\n四色定理（Appel–Haken 1976）：任何平面地圖 4 色足夠")
print("證明：1834 個不可約構形 + 1200 小時電腦——第一個電腦證明")
print("2005 年 Gonthier 的 Coq 形式化——可檢驗性恢復")
```

## 結案 -- 後果與影響
- **電腦證明的誕生**：四色定理是第一個——Kepler 猜想（Hales 1998/2014 Flyspeck）、Feit–Thompson 的形式化。
- **數學的哲學**：「證明是什麼」的爭論——可檢驗性 vs 可理解性，形式化驗證（Coq、Lean）的動機。
- **人機協作**：人類找結構、電腦暴力檢驗——實驗數學與電腦輔助證明的範式。
- **形式化驗證的帝國**：2005 Gonthier 的 Coq、2012 奇數階定理、Lean 數學庫（2020s）——**機器檢驗的數學**。
- **五色定理的教訓**：Kempe 的錯誤證明 → Heawood 的五色——**錯誤證明也能產生正確的副產品**。
- **電腦科學的回饋**：圖著色是 NP 完備（1979 Garey–Johnson，見 `../計算理論/1971-Karp21問題.md`）——平面圖 4 色是**多項式可解**的罕例。
