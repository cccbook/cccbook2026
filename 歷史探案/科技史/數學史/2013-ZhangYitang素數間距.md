# 2013 - 張益唐素數間距

## 案件摘要
2013 年 5 月，58 歲的張益唐（Yitang Zhang）在《數學年鑑》發表《素數間的有界間距》（Bounded gaps between primes）：證明**存在無窮多對素數，其間距小於 7000 萬**——首次證明素數間距**有上界**。這是孿生素數猜想（間距 = 2）的第一個**有界性突破**——雖然 7000 萬離 2 很遠，但這是**從「無界」到「有界」的質變**。數學界立即接力（Polymath 8 與 Maynard），幾個月內把 7000 萬壓到 246——**素數間距的世紀進展**。張益唐的故事更是傳奇：**沈寂 20 年（賽百味會計、旅館雜工）的中年數學家，一鳴驚人**。

## 前因 -- 為什麼會有這個案子
**孿生素數猜想**（1849 年 de Polignac 提出）：存在無窮多對素數間距為 2：

$$3, 5; \quad 5, 7; \quad 11, 13; \quad 17, 19; \quad 101, 103; \dots$$

**數值證據**：$10^{16}$ 以內有大量孿生素數——但**無窮性未證**（與黎曼假設同列數論中心的懸案）。

**攻擊的困境**：素數的分佈（素數定理 1896）給出**平均**間距 $\ln n$，但**孿生**的無窮性需要**局部分佈**的精確控制——篩法（sieve）的極限：

- **Brun 篩法（1919）**：孿生素數的密度有限（$\sum 1/p$ 收斂）——但無窮性未證
- **陳景潤（1966/1973）**：「1+2」——每個大偶數 = 素數 + 「半素數」——**最近的結果**，但孿生素數仍懸
- **Bombieri–Davenport（1966）**：間距 < 常數的「幾乎」結果——還差臨門一腳

**張益唐的路徑**：**GPY 方法（2005，Goldston–Pintz–Yıldırım）的改進**——GPY 證明間距可以**任意小於平均**（$\liminf (p_{n+1} - p_n)/\ln p_n = 0$），但**無界性**（絕對常數上界）還需要「分布水準」的突破。

## 線索與推理 -- 數學式、程式、理論

### 張益唐的突破
**核心想法**：GPY 方法卡在「素數在短區間中的分佈」（Elliott–Halberstam 猜想的級別）——張益唐用**修正的篩法**（Selberg 篩的權重優化）繞過：

**證明結構**：

1. **考慮區間** $[x, x + 7000\text{萬}]$——若其中無窮多次有**至少兩個素數**，則間距有界
2. **修正篩法**：用自訂的權重函數 $w(n)$，計算區間中「準素數」的期望數量
3. **關鍵的改進**：把 GPY 需要的「分佈水準」從 1/2 降到 1/2 + $\delta$（張益唐實現 $\delta \approx 1/200$）——**剛好越過臨界線**
4. **結論**：$\liminf (p_{n+1} - p_n) \le 7000\text{萬}$——**有界！** $\blacksquare$

**數學意義**：

$$\liminf_{n \to \infty} (p_{n+1} - p_n) < 7 \times 10^7$$

——**素數間距第一次有絕對上界**：無窮多次，兩個素數相距不到 7000 萬。

### 接力：Polymath 8 與 Maynard
**張益唐論文發表後數月**（2013–2014）：

- **Polymath 8（陶哲軒組織）**：群體協作優化參數——7000 萬 → 4680 → 246
- **Maynard（2013/2015）**：**獨立**改進——多維篩法，$k$ 個素數的間距：$k = 5$ 時間距 $\le 246$
- **現況（2024）**：間距 $\le 246$（在 Elliott–Halberstam 猜想下 $\le 6$）——**孿生素數（間距 2）仍懸**

**數學的接力**：張益唐的「存在」→ 群體的「優化」——**從 7000 萬到 246 只花一年**——與四色定理（1834 構形）、Perelman 的 Ricci 流同源：**結構的突破 + 參數的優化**。

### 程式碼：素數間距的資料

```python
import math

def sieve_primes(n):
    """埃拉托斯特尼篩法"""
    is_p = [True] * (n + 1)
    is_p[0] = is_p[1] = False
    for i in range(2, int(n**0.5) + 1):
        if is_p[i]:
            for j in range(i*i, n+1, i):
                is_p[j] = False
    return [i for i in range(n+1) if is_p[i]]

# 素數間距的資料（數值實驗——實驗數學的傳統）
primes = sieve_primes(1000000)
gaps = [primes[i+1] - primes[i] for i in range(len(primes)-1)]
print(f"10^6 以內有 {len(primes)} 個素數，最大間距 = {max(gaps)}")
print(f"平均間距 ≈ {sum(gaps)/len(gaps):.2f}（理論 ln(10^6) ≈ {math.log(1e6):.2f}）")

# 孿生素數的資料（間距 = 2）
twins = sum(1 for g in gaps if g == 2)
print(f"孿生素數對（間距=2）：{twins} 對——無窮性未證（孿生素數猜想）")

# 小間距的資料：間距 ≤ 246 的比例
small = sum(1 for g in gaps if g <= 246) / len(gaps)
print(f"間距 ≤ 246 的比例 = {small:.3f}——張益唐證明：無窮多次（有界性）")
print(f"張益唐 2013：liminf(p_{{n+1}} - p_n) ≤ 7×10^7 → Polymath/Maynard：≤ 246")
```

### 張益唐的傳奇
**沈寂的 20 年**：

- **1985 年**：北京大學數學系（師從潘承彪，陳景潤的傳統）赴美，Purdue 博士（1991）——導師關係不合，**沒有推薦信**
- **1991–1999**：找不到學術職位——**賽百味（Subway）會計、旅館雜工、Denny's 服務生**
- **1999–2013**：新罕布什爾大學的**講師**（lecturer，非終身職）——教微積分，默默研究素數間距
- **2013 年**：58 歲，《數學年鑑》發表——**一鳴驚人**

**正名的勝利**：2014 年科羅拉多大學教授、MacArthur 獎、2016 年加州大學聖巴巴拉——**沈寂 20 年的中年數學家**，與 Wiles 的 7 年秘密（見 `1994-Wiles費馬定理.md`）、Perelman 的隱居（見 `2003-Perelman龐加萊猜想.md`)並列——**數學不問出身與年齡**。

**偵探筆記**：張益唐的推理是「**繞過障礙**」——GPY 卡在「分佈水準」，張益唐用修正篩法繞過（降臨界線一點點）。這與 Fermat 定理的 Wiles（見 `1994-Wiles費馬定理.md`）同源：**卡住的最後一步，需要一個「巧妙的轉彎」**——數學的深刻常在「臨界線的一點點」。

## 結案 -- 後果與影響
- **素數間距的有界性**：從「無界」到「有界」的質變——孿生素數猜想的第一個重大突破。
- **數學的接力**：Polymath 8（陶哲軒的群體協作）+ Maynard——7000 萬 → 246 只花一年——**開放協作的數學**。
- **張益唐的傳奇**：賽百味會計到《數學年鑑》——**數學不問出身**，激勵無數研究者。
- **實驗數學的傳統**：素數間距的數值資料（$10^{16}$ 的計算驗證）——**計算與理論的配合**（與四色定理的電腦證明同源，見 `1976-四色定理.md`）。
- **篩法的復興**：Selberg 篩的權重優化、GPY 方法——**組合數論的新工具箱**。
- **孿生素數仍懸**：間距 2 的無窮性——數論的中心謎題（與黎曼假設並列）。
