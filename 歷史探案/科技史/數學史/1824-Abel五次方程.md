# 1824 - 阿貝爾五次方程

## 案件摘要
1824 年，22 歲的挪威數學家 Niels Henrik Abel 自費出版《論代數方程》——證明**五次方程沒有根式解**：一般五次方程 $x^5 + ax^4 + \dots = 0$ 的根**無法**用係數的有限次加減乘除與開方表示。困擾數學界 270 年的懸案（自 Cardano 1545 解三次方程，見 `1545-Cardano三次方程.md`）終結——**不是解開，是證明解不開**。Abel 26 歲死於肺結核（貧困中），Galois（1832，見 `1832-Galois群論.md`）給出更深的判準——**兩位早夭的天才改寫了代數**。

## 前因 -- 為什麼會有這個案子
16–19 世紀代數的階梯：

| 次數 | 根式解 | 年代 |
|------|--------|------|
| 2 | ✓ | 花拉子米（820）|
| 3 | ✓ | del Ferro / Tartaglia / Cardano（1545）|
| 4 | ✓ | Ferrari（1545）|
| 5 | **?** | 懸案 270 年 |

**自然的假設**：五次也能解——只要找到方法。**250 年的攻擊**：

- **Tschirnhaus（1683）**：變換法——失效
- **Euler、Lagrange（1770–71）**：《關於代數方程解法的反思》——系統化前人的方法，發現**對稱性**是關鍵（置換的視角——Galois 理論的先聲），但仍未證明不可能
- **Ruffini（1799）**：宣稱證明不可能——證明有漏洞（缺少完整的置換群分析）

**Abel 的問題**：五次方程的根，能否用根式表示？——**答案：不能**。

## 線索與推理 -- 數學式、程式、理論

### 根式解是什麼
**定義**：根式解（solution by radicals）= 係數經過**有限次** $+, -, \times, \div, \sqrt[n]{}$ 運算得到的表達式。

$$\text{二次：} x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \quad \text{（用 } \sqrt{\ }\text{）}$$

$$\text{三次：Cardano 公式（用 } \sqrt{\ } \text{與 } \sqrt[3]{\ }\text{）}$$

**五次的懸案**：是否存在類似的公式（只用 $\sqrt[2]{}, \sqrt[3]{}, \sqrt[4]{}, \sqrt[5]{}$ 等開方）？

### Abel 的證明思路
**核心**：根式解 ⟺ 根域是**根式塔**的擴張：

$$F = F_0 \subseteq F_1 \subseteq F_2 \subseteq \dots \subseteq F_k \ni \text{根}$$

其中每步 $F_{i+1} = F_i(\sqrt[n_i]{a_i})$（加一個開方）。

**推理**：根式塔的擴張有特殊的**對稱性結構**（Galois 群的可解性，見 `1832-Galois群論.md`）——Abel 證明：**根式解 ⟺ 對稱群可解**。而五次方程的對稱群 $S_5$ **不可解**（$A_5$ 是單群，不可再分解）——**無根式解**。

Abel 的原始證明（1824）用**置換的分析**：假設根式解存在，追蹤「根的置換」在開方下的行為——推出五次方程的置換結構**容不下**根式塔——矛盾。

**Abel–Ruffini 定理**：一般五次及以上方程無根式解。$\blacksquare$

### 範例：x^5 - x - 1 = 0 沒有根式解
**具體案例**：$x^5 - x - 1 = 0$——有實根（約 $1.1673$），但**無法用根式表示**：

- 經典算法（Newton 迭代）可以**數值**逼近——無限逼近
- 但**有限步**的 $+, -, \times, \div, \sqrt[n]{}$ 表達式**不存在**——**數值解 vs 根式解的分離**

**偵探筆記**：Abel 的推理是「**證明解不開**」——不是找解法，而是證明解法不存在。這與 Turing 的停機問題（1936，見 `../計算理論/1936-Turing機與停機問題.md`）同源：**「不存在」的證明比「存在」的構造更深刻**——Lagrange（1770）的置換視角 + Abel 的不可能性 + Galois 的判準，共同把代數從「解方程的技術」變成「結構的理論」。

### 程式碼：五次方程的數值解（非根式）

```python
def newton_root(f, f_prime, x0, tol=1e-12, max_iter=100):
    """Newton 迭代：數值逼近根——無限逼近，但無根式表達"""
    x = x0
    for _ in range(max_iter):
        x = x - f(x) / f_prime(x)
    return x

f = lambda x: x**5 - x - 1
fp = lambda x: 5*x**4 - 1
root = newton_root(f, fp, 1.0)
print(f"x^5 - x - 1 = 0 的實根 ≈ {root:.10f}")
# 數值解存在（Newton 迭代無限逼近）
# 但根式解不存在（Abel–Ruffini 1824）——數值與根式的分離！
```

**置換群可解性的判準**（Galois 1832 給出完整理論）：

| 對稱群 | 可解？ | 根式解 |
|--------|--------|--------|
| $S_2$ | ✓（鏈：$S_2 \triangleright \{e\}$） | ✓ 二次公式 |
| $S_3$ | ✓（$S_3 \triangleright A_3 \triangleright \{e\}$，商群全交換） | ✓ Cardano |
| $S_4$ | ✓（$S_4 \triangleright A_4 \triangleright V_4 \triangleright C_2 \triangleright \{e\}$） | ✓ Ferrari |
| $S_5$ | ✗（$A_5$ 是單群且非交換——鏈斷） | ✗ Abel–Galois |

### Abel 的悲劇
**貧困與早夭**：Abel 生於挪威貧困家庭（牧師之子），1824 年自費出版（500 冊，售罄極少），1826 年遊柏林與巴黎（Cauchy 把他的論文弄丟！），1829 年死於肺結核——**26 歲**，死前兩天收到柏林大學的教授聘書（遲到的承認）。

**Galois 的接棒**：1832 年，20 歲的 Galois 在決鬥前夜寫下遺書與數學手稿（見 `1832-Galois群論.md`）——**兩位早夭天才**（26 歲與 20 歲）改寫了代數。

## 結案 -- 後果與影響
- **代數的革命**：從「解方程的技術」到「結構的理論」——Abel 的不可能性證明是轉折點。
- **Galois 理論的伏筆**：Abel 的置換分析 → Galois 的群論判準（見 `1832-Galois群論.md`）——可解性 = 群可解。
- **數值與根式的分離**：Newton 迭代的數值解 vs 根式解——**「算得出」與「寫得出」是不同的**。
- **早夭天才的悲劇**：Abel（26 歲）、Galois（20 歲）、Ramanujan（32 歲）——數學史上最深的遺憾。
- **置換群的誕生**：Lagrange 的置換視角 → Abel 的分析 → Galois 的群——**群論的譜系**（見 `1832-Galois群論.md`）。
