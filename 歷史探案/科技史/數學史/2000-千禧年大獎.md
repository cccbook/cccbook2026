# 2000 - 千禧年大獎

## 案件摘要
2000 年 5 月，Clay 數學研究所（Clay Mathematics Institute）在巴黎宣布**千禧年大獎難題**（Millennium Prize Problems）：七個數學難題，**每個獎金 100 萬美元**——向 Hilbert 的 23 問題（1900，見 `../計算理論/1900-Hilbert23問題.md`）致敬。二十多年後：**龐加萊猜想**（Perelman 2003，見 `2003-Perelman龐加萊猜想.md`）已解（他放棄了獎金）；**P vs NP、黎曼假設、Navier–Stokes、Hodge 猜想、Yang–Mills、Birch–Swinnerton-Dyer** 仍懸——**七題六懸**，21 世紀數學的中心戰場。

## 前因 -- 為什麼會有這個案子
**Hilbert 的遺產**（1900）：23 個問題統領 20 世紀數學——**大多已解**（10、17、21 等未完全解決）。1998 年巴黎的 ICM（國際數學家大會）上，數學界討論「21 世紀的 Hilbert 問題」。

**Clay 研究所的成立**（1998）：波士頓，金融家 Landon Clay 與妻子創立——資助數學研究。**千禧年大獎的動機**：

1. **致敬 Hilbert**：1900 年巴黎的 Hilbert 演講 → 2000 年巴黎的 Clay 宣布（同一座城市，整整一世紀）
2. **數學的明星效應**：百萬獎金吸引公眾注意（與 P vs NP 的電腦科學意義疊加）
3. **問題的選擇**：由專家委員會（Wiles、Atiyah 等參與）選出**中心且可陳述**的難題

**規則**：在權威期刊發表、兩年緩衝、委員會審查——**與 NIST 競賽（見 `../密碼學/2001-AES.md`）公開攻擊的精神同源，但無截止日**。

## 線索與推理 -- 數學式、程式、理論

### 七大難題
**七題的清單與現況**：

| # | 問題 | 領域 | 現況 |
|---|------|------|------|
| 1 | **P vs NP** | 計算複雜度 | 懸（見 `../計算理論/2000-PvsNP千禧年大獎.md`） |
| 2 | **黎曼假設** | 數論 | 懸（ζ 函數零點，見 `1734-Euler巴塞爾問題.md`） |
| 3 | **Navier–Stokes** | 流體力學 | 懸（解的存在光滑性） |
| 4 | **Hodge 猜想** | 代數幾何 | 懸（拓撲與代數的關係） |
| 5 | **Yang–Mills 質量隙** | 數學物理 | 懸（量子場論的嚴格化） |
| 6 | **Birch–Swinnerton-Dyer** | 數論 | 懸（橢圓曲線的秩） |
| 7 | **龐加萊猜想** | 拓撲 | **✓ 已解**（Perelman 2003，見 `2003-Perelman龐加萊猜想.md`） |

**共同的特徵**：每題都可**簡潔陳述**（一頁內）但**極深**——與費馬定理（1637→1995）、四色定理（1852→1976）的傳統同源：**簡單問題、深刻答案**。

### P vs NP：電腦科學的中心
**陳述**：多項式時間可驗證的問題（NP）是否多項式時間可解（P）？

$$P \overset{?}{=} NP$$

**意義**：
- **P = NP**：密碼學崩潰（RSA 的分解、見 `../密碼學/1977-RSA.md`）、優化全解——**理想世界**
- **P ≠ NP**：計算的階層存在——**現實世界**（多數相信）

**背景**：Cook–Levin 定理（1971，見 `../計算理論/1971-CookLevin定理.md`）的 NP 完備、Karp 的 21 問題——**P vs NP 是千禧年獎與電腦科學的交點**。

### 黎曼假設：數論的中心
**陳述**：ζ 函數的非平凡零點都在 $\Re(s) = 1/2$：

$$\zeta(s) = \sum_{n=1}^{\infty} \frac{1}{n^s} = 0 \implies \Re(s) = \frac{1}{2}$$

**意義**：素數分佈的精確控制——素數定理的誤差界（歐拉 ζ 乘積的傳統，見 `1734-Euler巴塞爾問題.md`）。

**攻擊的譜系**：計算驗證（$10^{13}$ 個零點 ✓）、Hilbert–Pólya 的譜理論（零點 = 某算子的特徵值？）、與隨機矩陣（Montgomery 對關聯）——**158 年懸案**（1859 年提出）。

### 程式碼：千禧年難題的數值窗口

```python
import math, random

# 黎曼假設：ζ 函數的零點（數值窗口）
def zeta_re_half_check(t_max=100):
    """非平凡零點 s = 1/2 + it 的數值驗證（前若干個）"""
    # 前幾個零點的 t 值（已知）
    zeros_t = [14.1347, 21.0220, 25.0109, 30.4249, 32.9351, 37.5862, 40.9187]
    print("ζ(s) 的非平凡零點（實部都是 1/2）：")
    for t in zeros_t[:5]:
        print(f"  s = 0.5 + {t:.4f}i ✓")
    print("——黎曼假設：所有零點都在 Re(s) = 1/2（計算驗證到 10^13 個）")

zeta_re_half_check()

# P vs NP：NP 完備問題的視窗（子集和）
def subset_sum_dp(a, target):
    """子集和的動態規劃：偽多項式 O(n·target)"""
    dp = {0}
    for ai in a:
        dp |= {v + ai for v in dp if v + ai <= target}
    return target in dp

random.seed(42)
a = [random.randint(1, 100) for _ in range(20)]
print(f"\n子集和（target={sum(a)//2}）：{subset_sum_dp(a, sum(a)//2)}")
# 子集和是 NP 完備（Karp 21 問題），但偽多項式可解——P vs NP 的微妙

# Navier–Stokes：流體方程（數值模擬的視窗）
print("\nNavier–Stokes：∂u/∂t + (u·∇)u = -∇p/ρ + ν∇²u")
print("解的存在與光滑性：3D 的懸案（2D 已解）——千禧年獎 2000")
```

### 百萬獎金的哲學
**錢能買到證明嗎？**——千禧年大獎的獎金吸引公眾，但**解題者的動機是數學本身**：

- **Perelman（2003）**：解龐加萊猜想，**放棄 Fields 獎（2006）與百萬獎金（2010）**——「數學與金錢無關」（見 `2003-Perelman龐加萊猜想.md`）
- **Wiles（1995）**：費馬定理不在千禧年清單（1995 年前已解）——但他的成功是千禧年清單的動機之一

**數學的榮譽體系**：Fields 獎（40 歲以下）、Abel 獎（終身成就）、千禧年獎（特定問題）——**三層榮譽**。

## 結案 -- 後果與影響
- **21 世紀數學的中心戰場**：七題六懸——每個進展都是大新聞（如 2013 年張益唐的素數間距，見 `2013-ZhangYitang素數間距.md`）。
- **公眾的數學**：百萬獎金使數學難題進入大眾視野——「黎曼假設」成為流行文化詞彙。
- **P vs NP 的電腦科學意義**：密碼學（見 `../密碼學/2017-後量子密碼學.md`）、優化、AI 的理論基礎。
- **龐加萊的勝利**：唯一已解（2003）——Perelman 的放棄使它成為「數學與名利」的寓言。
- **Hilbert 的傳統**：1900 → 2000——**問題驅動的數學**（與 Bourbaki 的結構驅動對照）。
