# 日本電子產業的興衰史 -- AI 偵探風格

以「推理探案」的方式，追查日本電子產業從收音機、家電、電視、半導體霸主，到失落的三十年、材料與設備的「隱形冠軍」轉身：
前因是什麼？線索在哪裡？推理如何展開？後果又如何改寫了東亞科技版圖？

核心謎題只有一個：**一個曾經讓美國矽谷聞風喪膽、DRAM 占全球 80% 的電子帝國，為什麼在三十年間幾乎全線潰敗？**
推理的答案：**戰後的賭注（家電）贏了，但組織、資本與標準的三場賽局（個人電腦、半導體、軟體/數位）全輸**——輸在自己最擅長的「改善」邏輯，無法應對「典範轉移」。

$$\text{帝國的邏輯}： \text{製造精良} \xrightarrow{\text{模組化}} \text{被標準化 } \xrightarrow{\text{成本}} \text{被韓台取代} \xrightarrow{\text{數位化}} \text{價值轉移到軟體}$$

日本模式的本質是「**垂直整合的工廠帝國**」：設計、零組件、組裝、品牌一體。而 1980 年代後的全球遊戲規則是「**水平分工**」——Wintel 標準 + 亞洲代工。帝國不是被打敗的，是被「架構」打敗的。

## 推理主線總覽

1. **1952–1968**：電晶體授權 → 收音機/電視/家電 →「小而美」的全球品牌
2. **1975–1985**：VHS、Walkman、VLSI 計畫 → 半導體 + 家電雙霸權
3. **1986–1995**：美日協定、泡沫破裂、PC 標準化 → 帝國的結構性弱點曝光
4. **1997–2010**：韓台崛起、數位化失敗、家電潰敗
5. **2012–2025**：品牌帝國解體 → 材料/設備/感測器的「隱形冠軍」轉身

## 日本為什麼衰落？（偵探的最終推理）

| 變數 | 日本（1980） | 日本（2020） | 韓國 | 台灣 | 美國 |
|------|-------------|-------------|------|------|------|
| 組織模式 | 垂直整合帝國 | **被解體為零件廠** | 財閥集中 | 水平分工冠軍 | 品牌與設計 |
| 標準話語權 | 自有格式（Betamax、MD、MiniDisc） | **被 Wintel/iOS 標準吞沒** | 開放（Android） | 開放代工 | 定義標準 |
| 人才機制 | 終身雇用、內部晉升 | 同上（但外流） | 競爭性內訓 | 跳槽生態 | 全球挖角 |
| 資本市場 | 銀行為主、排斥重整 | **股東資本主義（晚 20 年）** | 財閥資本 | 快速上市文化 | 積極併購 |
| 結果 | 品牌潰敗 | **零件與材料霸主** | IDM 強權 | 代工霸主 | 設計霸權 |

這本書的每一篇 wiki，都是帝國解體與轉身路上的一個「案發現場」——推理的終點不是「日本失敗了」，而是「**日本把帝國拆解成了帝國賴以存在的零件，然後統治了所有帝國的零件**」。
