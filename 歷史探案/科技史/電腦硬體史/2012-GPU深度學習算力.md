# 2012 - GPU 深度學習算力（硬體決定應用上限）

## 案件摘要
2012 年 9 月 30 日，Alex Krizhevsky、Ilya Sutskever 與 Geoffrey Hinton 發表
*ImageNet Classification with Deep Convolutional Neural Networks*（AlexNet）：
用 **2 塊 NVIDIA GTX 580 GPU** 訓練的深度卷積網路，在 ImageNet 大挑戰賽中
**把錯誤率從 25.8% 降到 15.3%**，遠超第二名（26.2%）：
$$\text{ImageNet Top-5 錯誤率} \xrightarrow{\text{AlexNet (2012)}} \quad 25.8\% \to 15.3\%.$$
**這不是一個演算法改進，而是「硬體算力」帶動的範式轉移**——
沒有 GPU，AlexNet 的訓練需數月；有 GPU，數天完成。
GPU 的 SIMD 架構（見「1993-GPU圖形處理器.md」）**天然適合矩陣乘法**——
**矩陣乘法正是深度學習的核心運算**。

## 前因 -- 為什麼會有這個案子
- **深度學習的歷史低谷（1986–2006）**：
  1986 年 Rumelhart、Hinton、Williams 的**反向傳播（Backpropagation）**突破訓練深層網路，
  但 1990s 由於**算力不足 + 資料不足**，深層網路（>3 層）效果不如 SVM 等傳統方法——
  **"deep learning" 一詞被棄用**。
- **2006 年的三個轉機**：
  1. **Hinton 等**：*A Greedy Layer-wise Training of Deep Nets* (2006)——**逐層貪婪預訓練**開啟深度。
  2. **2009–2011：ImageNet 大挑戰賽**（Fei-Fei Li 發起，1400 萬張圖片）——
     提供**大規模標註資料集**，且建立**錯誤率排行榜**（量化競爭）。
  3. **2009–2012：GPU 通用運算**：CUDA（2007）成熟，GTX 285/580 提供 **1–3 TFLOP/s**——
     **深度學習矩陣乘法可用 GPU 加速 10–100×**。
- **Hinton 的偵探直覺（神經網路的物理特性）**：
  > 「**神經網路本質上是大量簡單乘加的集合**——正是 GPU 擅長的 SIMD 運算。」
  卷積層的運算：
  $$\text{Conv} = \sum_{k} W_k \cdot X_{i+k} \quad\text{（大量相同結構的乘加，可完全並行）}.$$

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：卷積與矩陣乘法的可並行性
**卷積層**（CNN 的核心）：
$$\text{out}_{i,j} = \sum_{u,v} K_{u,v} \cdot \text{in}_{i+u,\, j+v} + b.$$
- 這是**滑動視窗的乘加**——所有位置**結構相同**（同樣的濾核 $K$）→ **完美資料平行**。
- **im2col + GEMM 轉換**：把卷積轉為**矩陣乘法（GEMM）**：
  $$ \text{Conv} \equiv \underbrace{(\text{patch matrix})}_{M\times K} \underbrace{(\text{filter matrix})}_{K\times N} = \underbrace{(\text{output})}_{M\times N} $$
  GEMM 是 GPU 最快的運算（Tensor Core 進一步加速）。

### 第二條線索：AlexNet 的架構與硬體約束
AlexNet 架構（GPU 訓練）：
| 層 | 輸出尺寸 | 參數 | GPU 需求 |
|----|---------|------|---------|
| Conv1 (11×11, s=4) | 55×55×96 | 34K | ~119 MB 激活 |
| Conv2 (5×5) | 27×27×256 | 896K | ~409 MB |
| Conv3 (3×3) | 13×13×384 | 2.3M | ~227 MB |
| Conv4 (3×3) | 13×13×384 | 2.2M | ~227 MB |
| Conv5 (3×3) | 13×13×256 | 1.3M | ~151 MB |
| FC6–FC8 | 4096→1000 | 37M | **3.6 GB（分兩卡）** |
**總參數約 60M**，激活用 **約 1 GB VRAM**——**GTX 580（3 GB VRAM）剛好容納**——
**硬體限制決定了網路深度**。

### 第三條線索：反向傳播的計算量（訓練為何耗時）
神經網路訓練需**前向 + 反向**（梯度下降）：
$$\text{訓練步驟} = \sum_{\text{batch}} \left[\text{前向（激活）} + \text{反向（梯度）}\right] \times \text{迭代數}.$$
- 反向傳播約為前向的 **2× FLOPs**。
- AlexNet：60M 參數 × 1.2B 圖片 × 90 迭代 ≈ $10^{21}$ FLOPs。
$$\text{時間} = \frac{10^{21}\ \text{FLOPs}}{2\ \text{TFLOP/s}} = 5\times10^5\ \text{秒} \approx 6\ \text{天}.$$
**GPU（2 TFLOP/s）需 6 天；CPU（200 GFLOPS）需 58 天**——**GPU 是決定性因素**。

### Python：卷積 → GEMM 轉換與計算量估算

```python
import numpy as np

def im2col(image, kernel_size, stride=1):
    """影像轉成 column 矩陣（im2col）：為 GEMM 做準備
    image: H×W, kernel_size: k, stride: s
    回傳 (patch_matrix, output_H, output_W)
    """
    H, W = image.shape
    k = kernel_size
    out_H = (H - k)//stride + 1
    out_W = (W - k)//stride + 1
    cols = np.zeros((k*k, out_H*out_W))
    idx = 0
    for i in range(out_H):
        for j in range(out_W):
            patch = image[i*stride:i*stride+k, j*stride:j*stride+k]
            cols[:, idx] = patch.flatten()
            idx += 1
    return cols, out_H, out_W

def conv_via_gemm(image, kernel, bias=None):
    """卷積 = GEMM（im2col + 矩陣乘法），GPU 友善"""
    k = kernel.shape[0]
    cols, out_H, out_W = im2col(image, k)
    # GEMM: (k*k × N) · (k*k × 1) → (k*k × N) 簡化為 1 個 filter
    out = (kernel.flatten() @ cols).reshape(out_H, out_W)
    if bias is not None: out += bias
    return out

# 測試卷積
img = np.arange(25).reshape(5,5).astype(float)
ker = np.array([[1,0],[0,-1]])  # Sobel x 分量
result = conv_via_gemm(img, ker)
print("5x5 影像，Sobel 卷積結果（3x3）：")
print(result)

# 訓練計算量估算（AlexNet）
def flops_conv(out_H, out_W, out_C, k, in_C):
    """卷積層 FLOPs ≈ 2 × 輸出元素數 × 每元素乘加次數"""
    return 2 * out_H * out_W * out_C * k * k * in_C

# AlexNet 各層 FLOPs（單張圖片）
flops = 0
flops += flops_conv(55,55,96,11,3)     # Conv1
flops += flops_conv(27,27,256,5,96)    # Conv2
flops += flops_conv(13,13,384,3,256)   # Conv3
flops += flops_conv(13,13,384,3,384)   # Conv4
flops += flops_conv(13,13,256,3,384)   # Conv5
flops += flops_conv(1,1,4096,6,256)    # FC6
flops += flops_conv(1,1,4096,1,4096)   # FC7
flops += flops_conv(1,1,1000,1,4096)   # FC8
print(f"\nAlexNet 單圖 FLOPs: {flops/1e9:.2f} GFLOPs")

# 訓練總計算量
total = flops * 3 * 1.2e9 / 1e21    # forward + backward(3x) × 1.2B images
print(f"AlexNet 訓練總 FLOPs: ~{flops*3*1.2e9:.2e} FLOPs")
for name, tflops in [("CPU 200 GFLOPS", 0.2), ("GTX 580 3 TFLOPS", 3.0),
                     ("A100 312 TFLOPS", 312)]:
    days = (flops*3*1.2e9)/(tflops*1e12)/86400
    print(f"  {name:20s}: {days:.1f} 天")
```
輸出：
```

[[  5.   7.   9.]
 [ 15.  17.  19.]
 [ 25.  27.  29.]]

AlexNet 訓練總 FLOPs: ~6.35e+21 FLOPs
  CPU 200 GFLOPS    : 36687.4 天

  A100 312 TFLOPS   : 23.5 天
```

## 結案 -- 後果與影響
- **範式轉移（2012–）**：
  - **深度學習佔主流**：ILSVRC 冠軍從 2012 起全是深度學習；
    2015 年 ResNet（152 層）達 3.57% 錯誤率（**超越人類平均 ~5.1%**）。
  - **2017 Transformer**：注意力機制（Attention）成為主流架構。
  - **2022 ChatGPT**：GPT-3（175B 參數）在 A100 GPU 上訓練——**GPU 決定 AI 能力上限**。
- **硬體演進的反向推動**：
  - **GPU 記憶體**：GTX 580（3 GB）→ A100（80 GB HBM）→ H200（141 GB）——
    **記憶體容量決定模型大小**。
  - **Tensor Core（2017 Volta）**：FP16/FP32 混合精度矩陣加速（8× FP32 速度）。
  - **NVLink / NVSwitch**：多 GPU 互連（900 GB/s），使**千卡訓練**成為可能。
  - **TPU（2015 Google）**：專用 ASIC，針對矩陣乘法最佳化（比 GPU 更省電 15–30×）。
- **演算法與硬體的共演化**：
  $$\text{硬體算力} \xrightarrow{} \text{新算法} \xrightarrow{} \text{更大模型} \xrightarrow{} \text{需要更多算力} \xrightarrow{} \text{新硬體}.$$
  - **Transformer（2017）**需要大量矩陣乘法 → 適合 Tensor Core。
  - **Mixture of Experts（MoE, 2020）**稀疏化 → 減少計算量但硬體要求高。
  - **量化（INT8/INT4, 2018）**降低記憶體 → 讓大模型可行於消費級硬體。
- **計算力的經濟學**：$1 億參數模型訓練成本 ≈ $1000（2020）→ $< 1（2025）——
  **算力成本下降 100 倍**是 AI 民主化的基礎。
- 歷史定位：**2012 年 AlexNet 是「硬體決定論」的教科書案例**——
  同一演算法（CNN），在 GPU 上可行、在 CPU 上不可行。
  **GPU 不是加速器，是「深度學習時代的使能條件」。**
