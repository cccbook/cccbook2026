# 1972：C 語言 — Ritchie 在貝爾實驗室鍛造的「可攜式組合語言」

## 案情

1972 年，貝爾實驗室的 Dennis Ritchie 在新澤西州 Murray Hill 完成了 C 語言的設計與早期實作。1973 年，他與 Ken Thompson 用 C 重寫了 UNIX 核心的大部分——這是史上第一次，一個完整的作業系統核心以高階語言（而非組合語言）寫成，證明高階語言可以兼得效率與可攜性。

## 前因

- **語言族譜：CPL → BCPL → B → C**：1960 年代劍橋的 CPL 過於龐大；Martin Richards 精簡出 BCPL（1966）；Thompson 在貝爾實驗室將 BCPL 再度簡化，做出無型別、字組導向的 B 語言（1969–1970），用來在 PDP-7 上寫 UNIX 雛形。
- **硬體改變了遊戲規則**：UNIX 1971 年移植到 PDP-11 後，問題浮現——PDP-11 是位元組定址的 16 位元機器，B 語言的字組導向設計格格不入，無法處理位元組層級的資料（如字元）。
- **效率的雙重要求**：貝爾實驗室買 PDP-11 名義上是給專利部門做文書處理，機器資源有限（最初 24KB 記憶體），作業系統必須小而快。

## 線索與推理

Ritchie 的推理堪稱教科書級的工程取捨。B 語言的病根是「無型別」：所有資料都是機器字組。但 PDP-11 有位元組、有多種整數長度、有浮點運算。Ritchie 的解法不是拋棄 B，而是「替 B 補上型別系統」——加入 char、int、long、float，並引入指標型別的宣告語法，同時保留 BCPL/B 最精華的遺產：大括號區塊、簡潔運算子、以及指標算術。

指標算術是 C 的靈魂，其決策邏輯是：

$$p + n \Leftrightarrow p + n \times \text{sizeof}(*p)$$

讓陣列與指標幾乎互通（`a[i] ≡ *(a+i)`），使 C 既能像組合語言一樣精準操作記憶體，又保有高階語言的結構。1973 年的重寫行動就是最終的驗證實驗：UNIX 核心改用 C 後只留下極少量的組合語言（I/O 驅動與極少數機器相依部分），而性能損失可接受。1978 年 Ritchie 與 Brian Kernighan 出版《The C Programming Language》（K&R），成為影響後世四十年的程式語言聖經。

## 理論

**C 的演化鏈**：

| 語言 | 年代 | 作者 | 特徵 |
|---|---|---|---|
| CPL | 1963 | 劍橋/倫敦 | 學術理想，過於龐大 |
| BCPL | 1966 | Martin Richards | 無型別、精簡 |
| B | 1969 | Ken Thompson | 字組導向、PDP-7 適用 |
| C | 1972 | Dennis Ritchie | 加入型別、位元組定址、指標算術 |

**經典範例**（K&R 式的第一個 C 程式）：

```c
#include <stdio.h>
int main(void) {
    int i;
    char msg[] = "hello, world";
    for (i = 0; msg[i] != '\0'; i++)
        putchar(msg[i]);
    return 0;
}
```

**可攜性定理（Ritchie 的實踐）**：若作業系統核心僅依賴有限的一組原語（暫存器、中斷、記憶體映射），則：

$$\text{移植成本} = O(\text{機器相依模組}) \ll O(\text{重寫整個系統})$$

1983 年 Ritchie 因 C 與 UNIX 獲得圖靈獎。

## 後果

- **UNIX 的可攜性革命**：C 讓 UNIX 能移植到各種硬體，從而滲透學術界與產業界——沒有 C，就沒有 UNIX 的天下。
- **作業系統的血液**：Linux、Windows 核心的關鍵部分、macOS 的 Darwin、嵌入式系統韌體，至今仍以 C 為基礎。
- **語言家譜的源頭**：C++（1983）、Objective-C（1984）、Java（1995）、C#（2000）、Go（2009）等語言的語法皆可上溯至 C。
- **標準化**：1989 年 ANSI C（C89）→ ISO C90 → C99 → C11 → C23，標準歷經三十餘年仍在演進。

## 冷案檔案

- 時間：1972 年設計完成；1973 年 UNIX 核心以 C 重寫
- 案由：Ritchie 為解決 B 語言無法適應 PDP-11 的問題，在 BCPL/B 基礎上設計出帶型別的 C 語言
- 歷史定位：C 是史上影響最深遠的程式語言——現代幾乎每一台電腦的底層，都運行著 C 寫成的程式
