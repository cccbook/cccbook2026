# 1985：Windows 1.0 案 — 微軟的圖形介面跟隨策略

## 案情

1985 年 11 月 20 日，微軟在美國華盛頓州雷德蒙推出 Windows 1.0——一套跑在 MS-DOS 之上的圖形操作環境，提供重疊視窗（非真正重疊，採平鋪式）、滑鼠支援與隨附程式（Paint、Notepad、Write、計算機）。這是微軟對 Apple Macintosh 的延遲回應，也埋下了日後與 IBM 在 OS/2 上決裂的伏筆。比爾·蓋茲（Bill Gates）與新任 Windows 負責人 Steve Ballmer 在這條路上走了整整十年，才等到 Windows 稱王的 1995。

## 前因

- 1980 年 11 月微軟與 IBM 簽約提供 PC 作業系統，蓋茲買下 QDOS（86-DOS）改為 PC DOS，並保留向其他廠商授權 MS-DOS 的權利——這是本案最關鍵的前案。
- 1982 年 Compaq 淨室相容機成功，PC 相容生態確立，DOS 成為標準，微軟向整個相容機市場收租。
- 1983 年 1 月 Apple Lisa、1984 年 1 月 Macintosh 相繼展示 GUI 的魅力；Xerox PARC 的示範在前。
- 1983 年 11 月微軟宣布 Windows（代號 Interface Manager），承諾 1984 年春季上市——卻一再跳票，被業界譏為 vaporware（霧件）。
- 1985 年前後 IBM 與微軟共同開發 OS/2 的協議正在成形，微軟身兼兩面。

## 線索與推理

偵探先看第一條線索：Windows 1.0 並不優秀——平鋪視窗、效能差、依賴 DOS。第二條線索卻揭示蓋茲的策略本質：他不需要 Windows 立刻贏，他只需要「PC 生態裡存在一個 GUI 答案」，防止使用者流向 Macintosh，同時鎖住相容機廠商與軟體開發者。跟隨者策略的精髓是讓領先者替你教育市場、承擔試錯成本，自己則等標準戰的網路效應發酵。

決策邏輯的第二層：微軟同時與 IBM 合搞 OS/2、又私發 Windows，看似騎牆，實為對沖。OS/2 需要 286 以上硬體、與 DOS 相容性差且由 IBM 主導；Windows 則活在每一台既有 PC 上。當 1990 年 Windows 3.0 大賣（首年賣出逾兩百萬套）、1991 年 7 月 Windows 3.0 開始預裝擴張時，IBM 才驚覺微軟已把賭注全押在 Windows——雙方 1991-92 年正式決裂，IBM 獨自續推 OS/2 Warp，終告失敗。伏筆早在 1985 年就已埋下：微軟從不曾把未來託付給 IBM。

## 理論

標準戰中的跟隨者模型：設領先者（Apple）先行投入市場教育成本 $E$，跟隨者（微軟）免費獲得 $E$ 的外溢。跟隨者的價值為

$$V_{follower} = \alpha E + V_{installed\ base} - C_{imitation}$$

微軟的 $V_{installed\ base}$ 來自 DOS 裝機量與相容機生態；$C_{imitation}$ 由法律承擔（1988 年 Apple 訴微軟，1994 年和解，法院認定 1985 年授權合約涵蓋 Windows 的視覺比喻）。

與 IBM 決裂的賽局可視為囚徒困境變體：合作開發 OS/2 是「合作」，暗推 Windows 是「背叛」。微軟背叛的報酬（獨占 PC OS）遠大於合作報酬（與 IBM 分租），且 IBM 無有效報復手段——它已失去 BIOS 獨占（Compaq 案），唯一籌碼是品牌，而品牌抵不過 n² 的應用生態。

$$\pi_{MS}^{Windows} > \pi_{MS}^{OS/2}, \quad \pi_{IBM}^{OS/2} \text{ 隨 } n_{clone} \downarrow \text{ 而崩解}$$

| 版本 | 年份 | 意義 |
|---|---|---|
| Windows 1.0 | 1985 | 宣示存在，平鋪視窗 |
| Windows 2.0 | 1987 | 支援重疊視窗，引發 Apple 訴訟 |
| Windows 3.0/3.1 | 1990/1992 | 爆發點，相容性與 386 增強模式 |
| Windows 95 | 1995 | 獨立 OS 外觀，全球狂銷，Windows 時代正式開啟 |

## 後果

1. 1990 年代 Wintel 聯盟完全體：英特爾供晶片、微軟供 OS，共同主宰 PC 產業價值鏈。
2. IBM 的 PC 部門邊緣化，1990 年代轉向服務與企業市場，2005 年 PC 業務售予聯想。
3. Apple 訴訟敗訴後 GUI 介面公有化，全人類共享桌面比喻。
4. 微軟的 OS 壟斷引來 1998 年美國司法部反托拉斯案，成為監管科技壟斷的分水嶺。
5. 跟隨者策略被寫入教科書：讓對手教育市場、以相容性與分發優勢後發制人。

## 冷案檔案

時間：1985 年 11 月 20 日。案由：微軟推出品質平庸卻戰略意義重大的圖形環境，同時暗埋 OS/2 決裂伏筆。歷史定位：Windows 1.0 是「跟隨者標準戰」的起手式——微軟用十年耐心把 Apple 的發明與 IBM 的舞台，轉化為自己的帝國地基。
