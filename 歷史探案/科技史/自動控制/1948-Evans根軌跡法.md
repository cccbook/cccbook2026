# 1948 - Evans 根軌跡法

## 案件摘要

1948 年，Walter Evans（伊凡斯）在 General Electric 發表根軌跡法（root locus method）：
畫出**增益變動時閉環極點的移動軌跡**。Nyquist/Bode 的頻域方法（見 [1932-Nyquist判據.md](1932-Nyquist判據.md)、[1945-Bode回饋放大器設計.md](1945-Bode回饋放大器設計.md)）
回答「穩不穩」，但**不回答「極點在哪裡、怎麼移動」**——
根軌跡把閉環極點的全域圖像畫在一張圖上，設計者一眼看出增益從 0 到 $\infty$ 時
系統從穩定到不穩定的全過程。**時域直觀與頻域設計的橋樑誕生**。

## 前因

- **二戰的伺服設計需求**：GE 的伺服系統（火炮、雷達）需要快速設計工具——頻域方法需要量測與作圖，時域直觀缺失。
- **Maxwell–Routh 的遺產**：閉環極點決定暫態行為（超調、振盪、收斂速度）——但五階以上**解根**不可行（Abel 定理）。
- **繪圖式計算的傳統**：戰前的線路圖分析（smith 圖、圓圖）——「用幾何規則畫圖代替計算」是工程慣用手法。
- **Nyquist 判據的限制**：頻域回答穩定性，但**暫態響應（時域）與頻域的對應模糊**——工程師想要「直接看極點」。

## 線索與推理

### 第 1 步：問題的精確形式

閉環系統的特徵方程：

$$
1 + k\,G(s) = 0, \qquad k \in [0, \infty)
$$

**問題**：當 $k$ 從 0 變到 $\infty$，特徵根 $s_i(k)$ 在複數平面上怎麼移動？

五階以上解根不可行——但 Evans 發現：**軌跡本身服從簡單的幾何規則**，
不用解根就能畫出來！

### 第 2 步：軌跡的幾何規則

特徵方程等價於兩個條件：

$$
|k G(s)| = 1 \quad(\text{增益條件}), \qquad \angle G(s) = (2m+1)\pi \quad(\text{相位條件})
$$

**相位條件與 $k$ 無關**！所以軌跡的「形狀」由相位條件唯一決定，
$k$ 只決定「在軌跡上的位置」。從這個觀察，Evans 導出一組**幾何規則**：

| 規則 | 內容 |
|------|------|
| 1. 起點與終點 | 軌跡從開環極點（$k=0$）出發，止於開環零點（$k=\infty$） |
| 2. 分支數 | 軌跡分支數 = $\max(n, m)$（$n$ 個極點、$m$ 個零點） |
| 3. 實軸段 | 實軸上，右側極點+零點總數為奇數的區段屬於軌跡 |
| 4. 漸近線 | $n - m$ 條漸近線，角度 $\dfrac{(2m+1)\pi}{n-m}$，交於重心 $\sigma = \dfrac{\sum p_i - \sum z_i}{n-m}$ |
| 5. 分離點 | 軌跡離開實軸的點：$\dfrac{d}{ds}G(s) = 0$ |
| 6. 虛軸交點 | 與虛軸交點 = 臨界增益（Routh 判據可求） |

**用這六條規則，手繪就能畫出全域軌跡**——不用解任何方程。

### 第 3 步：範例——二階系統的根軌跡

$$
G(s) = \frac{1}{s(s+2)}, \qquad 1 + k G(s) = 0
$$

特徵方程：$s^2 + 2s + k = 0$，根 $s = -1 \pm\sqrt{1 - k}$。

| $k$ | 極點位置 | 行為 |
|-----|----------|------|
| $k = 0$ | $s = 0, -2$（開環極點） | — |
| $0 < k < 1$ | 實軸上兩個負實根 | 過阻尼 |
| $k = 1$ | $s = -1$（雙重根，分離點） | 臨界阻尼 |
| $k > 1$ | $s = -1 \pm j\sqrt{k-1}$（共軛複根） | 欠阻尼，虛部隨 $k$ 增大 |
| $\infty$ | $\pm j\infty$ | 漸近線 $\pm 90°$，交於 $-1$ |

**一張圖看盡系統的全域行為**：增益從 0 加到 $\infty$，系統從過阻尼 → 臨界 → 欠阻尼，
永遠穩定（實部恆為 $-1$）但越來越振盪——**設計者一眼選出最佳增益**（如 $k = 1$ 附近，臨界阻尼）。

### 第 4 步：為什麼根軌跡有價值？

頻域方法（Bode/Nyquist）與時域（極點）的**對應關係**：

| 時域指標 | 極點位置 | 頻域指標 |
|----------|----------|----------|
| 上升速度 | 實部 $\sigma$（越負越快） | 頻寬 $\omega_{gc}$ |
| 超調量 | 阻尼比 $\zeta = \cos\theta$（$\theta$ 是極點角度） | 相位裕度 PM |
| 振盪頻率 | 虛部 $\omega_d$ | 諧振峰 |

根軌跡讓設計者**直接在時域語言（極點位置）中做設計**，
再用對應關係換算成頻域驗收——**時域與頻域的橋樑**。

## 後果

- 根軌跡成為經典控制的三大工具之一（Nyquist、Bode、根軌跡），至今仍在教科書中。
- GE 與 aerospace 工業的伺服設計標準化。
- 手繪時代結束後，MATLAB 的 `rlocus` 延續這個方法——思想不變，工具進化。
- 「極點配置」的設計思想延續到現代控制：狀態回饋的極點配置（pole placement）是 Kalman 時代的方法（見 [1960-Kalman狀態空間與濾波.md](1960-Kalman狀態空間與濾波.md)）。

## 結案陳詞

Evans 的偵探手法是「找軌跡的幾何規則」：五階以上解根不可行，
但軌跡本身服從相位條件給出的簡單幾何——**不解根、畫出全域**。
根軌跡是經典控制最直觀的工具，把「穩定」與「性能」畫在同一張圖上。
