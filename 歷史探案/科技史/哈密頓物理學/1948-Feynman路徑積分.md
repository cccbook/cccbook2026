# 1948 - Feynman 路徑積分——作用量成為量子振幅

## 案件摘要
1948 年，Feynman 發表《非相對論性力學的空間–時間方法》，正式發表**路徑積分**（思想源於 1942 年普林斯頓博士論文）：
量子振幅 = **所有可能路徑的疊加**，每條路徑的權重是相位 $e^{iS/\hbar}$，其中 $S$ 正是經典作用量：
$$\mathcal{A}(b \leftarrow a) = \int_{q(t_a)=q_a}^{q(t_b)=q_b} \mathcal{D}q(t)\; e^{\frac{i}{\hbar}S[q]}, \qquad S[q] = \int_{t_a}^{t_b} L(q, \dot q, t)\,dt$$
Maupertuis（1744）的最小作用量原理（見 [1744-Maupertuis最小作用量.md](1744-Maupertuis最小作用量.md)）在此徹底改寫：
經典路徑不是「唯一的真路」，而是**相位穩定（駐相）的那條**——其他所有路徑互相抵消。

## 前因
- **雙縫實驗的謎題**：電子同時「穿過兩縫」並干涉——粒子軌跡的語言徹底破產。Feynman 問：「若電子能『嘗試所有路徑』，干涉自然出現？」
- **Dirac 的線索（1933）**：Dirac 在《量子力學原理》附註中寫下：傳播子 $K(b, a)$ 與 $e^{iS/\hbar}$「在 $\hbar \to 0$ 時等價」——
  一句未發展的附註，被 Feynman 讀出並發展成完整理論。
- **Wheeler–Feynman 吸收體理論（1941）**：Feynman 的博士研究（時間對稱的電磁學）中，「路徑的疊加」思想已成型。
- **作用量的中心地位**：Planck 常數 $\hbar$ 的單位正是「作用量」——量綱上早已暗示作用量是量子的主角。

## 線索與推理

### 第一步：駐相原理——經典力學是量子的極限
考慮兩條鄰近路徑的相位差 $\delta S/\hbar$：
- $|\nabla S| \gg \hbar$：鄰近路徑相位隨機、互相抵消 → 無貢獻；
- 駐相路徑（$\delta S = 0$）：鄰近路徑相位相同、相長疊加 → **唯一存活**。

$$\hbar \to 0 \;\Longrightarrow\; \text{只有 } \delta S = 0 \text{ 的路徑存活} \;\Longleftrightarrow\; \text{Euler–Lagrange 方程}$$
**經典力學 = 路徑積分的駐相近似。** 最小作用量原理從「公設」降級為「近似」——它的真身是量子干涉。

### 第二步：傳播子滿足薛丁格方程
把時間切成薄片，路徑積分成為多重重積分。短時傳播子：
$$K(x_{n+1}, t_{n+1}; x_n, t_n) \approx \sqrt{\frac{m}{2\pi i\hbar\,\Delta t}}\exp\left[\frac{i}{\hbar}\left(\frac{m(x_{n+1}-x_n)^2}{2\Delta t} - V(x_n)\Delta t\right)\right]$$
對 $\Delta t \to 0$ 展開，可證明 $K$ 滿足**薛丁格方程**（見 [1926-波動力學誕生.md](1926-波動力學誕生.md)）——
路徑積分與波動力學等價，且推廣更容易（場論、多體、規範理論）。

### 第三步：雙縫的解釋
兩條縫的路徑振幅相加：
$$\mathcal{A} = \mathcal{A}_{縫1} + \mathcal{A}_{縫2} = e^{iS_1/\hbar} + e^{iS_2/\hbar}$$
$$P = |\mathcal{A}|^2 = P_1 + P_2 + 2\sqrt{P_1 P_2}\cos\frac{S_1 - S_2}{\hbar}$$
最後一項正是**干涉條紋**——「粒子嘗試所有路徑」的語言一舉解釋干涉，無需軌道、無需波函數塌縮的詭辯。

### 經典 ↔ 量子對照（路徑積分版）
| 經典 | 量子（路徑積分）|
|---|---|
| 唯一軌跡：$\delta S = 0$ | 所有路徑的疊加，權重 $e^{iS/\hbar}$ |
| 最小作用量原理 | 駐相近似（$\hbar \to 0$）|
| 正則方程 | 薛丁格方程 / 傳播子 |
| 哈密頓主函數 $S$ | 振幅的相位 |

### Python 感受：駐相原理的數值示範
```python
import numpy as np

hbar = 1.0
# 類比：多條「路徑」的相位疊加，x 是路徑偏離駐相點的量
x = np.linspace(-10, 10, 2000)          # 遠離駐相點：相位快速振盪
S = 100 * x**2 / 2                       # 駐相點 x=0
amp = np.exp(1j * S / hbar).sum()
amp_off = np.exp(1j * S[:10] / hbar).sum()
print(abs(amp), abs(amp_off))            # 駐相點附近貢獻遠大於遠處
```
$\hbar$ 極小時，只有 $\delta S \approx 0$ 的路徑相長——「最小作用量」的量子真相。

## 結案
- 路徑積分成為現代場論的語言：QED、QCD、希格斯機制、重整化群、瞬子、路徑積分蒙地卡羅——全部以 $\int \mathcal{D}\phi\, e^{iS/\hbar}$ 為出發點。
- 哈密頓結構的三次量子變奏至此齊備：矩陣力學（正則對易關係）、波動力學（HJ 方程）、路徑積分（作用量相位）——**三者等價，全是 Hamilton 遺產**。
- 歷史註腳：Dirac 1933 年的附註只有半頁；Feynman 花了六年把它長成整套力學——「讀出別人沒讀完的線索」是偵探的最高技藝。
