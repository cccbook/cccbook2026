# 簡易-自由落體的哈密頓量

## 題目
一顆質量 m = 1 kg 的石頭從高處自由落下（重力加速度 g = 10 m/s²）。
請寫出它的哈密頓量 H，並用哈密頓正則方程求出運動方程式。

## 先備知識
- 動能 K = ½mv²
- 位能 V = mgh
- 哈密頓量 H = 動能 + 位能（當能量守恆時）

## 解說

### 第 1 步：寫出哈密頓量

哈密頓力學不用「速度 v」當變數，而是用「動量 p = mv」。

所以把 v = p/m 代入動能：

$$H = \frac{1}{2}m v^2 + mgh = \frac{p^2}{2m} + mgh$$

這就是石頭的哈密頓量。想像它是一個「能量計分板」：
- 第一項 p²/2m 是動能（跑得越快分數越高）
- 第二項 mgh 是位能（站得越高分數越高）

### 第 2 步：哈密頓正則方程

哈密頓給了兩條漂亮的方程式：

$$\dot{h} = \frac{\partial H}{\partial p}, \qquad \dot{p} = -\frac{\partial H}{\partial h}$$

（符號上的點代表「對時間的變化率」，∂ 代表「偏微分」，意思就是：
「其他變數都固定不動，只看這一個變數的影響」。）

### 第 3 步：代入計算

**求 h 的變化率：**

$$\dot{h} = \frac{\partial}{\partial p}\left(\frac{p^2}{2m} + mgh\right) = \frac{p}{m} = v$$

（對 p 微分時，mgh 裡沒有 p，就像常數一樣消失。p²/2m 微分後變成 p/m，
這只是告訴我們「動量除以質量就是速度」，很合理！）

**求 p 的變化率：**

$$\dot{p} = -\frac{\partial}{\partial h}\left(\frac{p^2}{2m} + mgh\right) = -mg = -10 \text{ N}$$

（對 h 微分時，p²/2m 裡沒有 h，消失。剩下 mgh 微分得 mg，前面的負號
告訴我們：重力把動量往「下」拉，所以動量越來越負。）

### 第 4 步：解讀結果

- $\dot{p} = -mg$ 正是牛頓第二定律 F = ma！
- 積分得 p(t) = -mgt（初速為 0），再由 $\dot{h} = p/m$ 積分得：

$$h(t) = h_0 - \frac{1}{2}gt^2$$

這和高中用牛頓定律算出來的答案完全一樣。

## 重點整理
| 牛頓力學 | 哈密頓力學 |
|---|---|
| 變數：位置 + 速度 | 變數：位置 + 動量 |
| F = ma（一條二階方程） | 兩條一階方程（正則方程） |
| 力是主角 | 能量（H）是主角 |
