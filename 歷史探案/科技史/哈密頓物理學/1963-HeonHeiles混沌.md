# 1963 - Hénon–Heiles 混沌相圖——混沌的標準照

## 案件摘要
1963 年（與 Arnold/Moser 完成 KAM 定理同年），天文學家 Hénon 與 Heiles 為研究
「恆星在星系引力場中的軌道」，提出一個簡化的二自由度哈密頓系統：
$$H = \frac{1}{2}(p_x^2 + p_y^2) + \frac{1}{2}(x^2 + y^2) + x^2 y - \frac{1}{3}y^3$$
他們用 Poincaré 截面畫出相圖，發現：低能量時軌跡規則（KAM 環面），
能量超過臨界值後，相空間被**混沌海**吞噬。
這是混沌第一次以清晰的數值相圖示人——KAM 定理的抽象敘述，有了具體的「標準照」。

## 前因
- **星系動力學的問題**：恆星在軸對稱星系勢中繞行，軌道是否「可積」（第三積分是否存在）？Lindblad 的實驗軌道說有，數學說不知道。
- **KAM 定理（1954/1963）**：理論上「近可積 ⇒ 多數環面存活」，但缺乏直觀圖像（見 [1954-KAM定理.md](1954-KAM定理.md)）。
- **FPUT 實驗（1955）**：電腦模擬已證明能「發現」意外（見 [1955-FPUT實驗.md](1955-FPUT實驗.md)）。
- **Hénon–Heiles 的直覺**：與其分析星系勢，不如構造一個**最簡模型**，用 Poincaré 截面把結構「畫出來」。

## 線索與推理

### 模型的來源：星系勢的簡化
軸對稱星系的柱座標勢 $V(r, z)$ 展開到三階，保留 $x^2 y$ 與 $y^3$ 項：
$$V \approx \frac{1}{2}(x^2 + y^2) + x^2y - \frac{1}{3}y^3$$
（原論文中以 $\omega = 1$ 歸一化。）這個勢有三角對稱性，且在 $y > 1$ 時開口（粒子可逃逸）。

### Poincaré 截面：把 4 維相空間「切片」
取 $y = 0$、$p_x > 0$ 的截面，記錄每次穿越時的 $(x, p_x)$：
| 能量 $E$ | 截面圖像 |
|---|---|
| $E = 1/12 \approx 0.083$ | 全部點落在光滑曲線上（KAM 環面）——完全規則 |
| $E \approx 0.13$ | 多數曲線仍在，但出現混沌島鏈與稀疏散點 |
| $E \gtrsim 0.16$ | 混沌海吞噬大部分相空間，僅存小島 |
| $E \gtrsim 1/6$ | 大量軌道逃逸到無窮遠 |

**臨界能量 $E_c = 1/12$ 附近，規則轉為混沌。**

### 侦查線索：第三積分的生滅
低能量時，截面上的光滑曲線 = 一個「第三積分」$F(x, y, p_x, p_y) = \text{const}$ 的影子（$H$ 與 $F$ 對合，系統可積）。
高能量時曲線破碎 = **第三積分消失**，系統不可積，軌跡在 3 維能量面上自由遊走（混沌）。
Hénon–Heiles 的貢獻：把「可積性」變成**可畫、可看、可量**的東西。

### Lyapunov 指數：混沌的定量指標
相鄰軌跡的距離 $\delta(t)$ 的放大率：
$$\lambda = \lim_{t\to\infty} \frac{1}{t}\ln\frac{\delta(t)}{\delta(0)}$$
| 情況 | $\lambda$ |
|---|---|
| 規則軌跡（環面上）| $\lambda = 0$ |
| 混沌軌跡 | $\lambda > 0$（指數敏感）|

**$\lambda > 0$ 是混沌的嚴格定義**——Hénon–Heiles 系統成為計算 Lyapunov 指數的標準測試題。

### Python 重現：Hénon–Heiles 相圖
```python
import numpy as np
from scipy.integrate import solve_ivp

def hh(t, z):                     # H = ½(px²+py²) + ½(x²+y²) + x²y − y³/3
    x, y, px, py = z
    return [px, py, -x - 2*x*y, -y - x*x + y*y]

E = 0.14                          # 高於臨界值 1/12
# 起跑於 y=0 截面，py = sqrt(2E - px² - x² - 2x²y + (2/3)y³) = sqrt(2E - px² - x²)
for x0, px0 in [(0.0, 0.1), (0.1, 0.2), (-0.2, 0.0)]:
    py0 = np.sqrt(2*E - px0**2 - x0**2)
    sol = solve_ivp(hh, [0, 300], [x0, 0.0, px0, py0], rtol=1e-11, atol=1e-11,
                    t_eval=np.linspace(0, 300, 3000))
    # 每次 y=0 且 py>0 記錄 (x, px)——散點=混沌，曲線=規則
```

## 結案
- 混沌有了標準模型與標準照；Hénon–Heiles 系統成為此後半世紀所有混沌研究的測試基準。
- 連鎖反應：Lyapunov 指數、分岔圖、奇異吸子（Lorenz 1963 同年）——「非線性動力學」成為獨立學科。
- 星系動力學的答案：棒旋星系中恆星軌道部分混沌——星系棒的形狀與演化由混沌程度決定。
- KAM 定理的敘述與 Hénon–Heiles 的圖像合體：**混沌與秩序並存**的完整圖景就此確立。
