# 1869 - Miescher 核素（DNA 的第一次現形）

## 案件摘要
1869 年，瑞士巴塞爾的年輕醫師 Friedrich Miescher 從**膿皰的白血球**（繃帶上的膿）
萃取出一種**含磷的酸性物質**——他不認識它，命名為「**核素 (nuclein)**」。
**這就是 DNA 的第一次現形**——比 Mendel 的論文（1866）晚 3 年、
比雙螺旋（1953）早 84 年。
**DNA 被發現了 84 年，卻一直被當成無聊的配角**——直到 Avery（1943）與
Watson–Crick（1953）才讓它當上主角。**發現與理解之間，隔著 84 年的偏見。**

## 前因 -- 為什麼會有這個案子
- **細胞化學的空白**：1860 年代，細胞學說（1839）已確立，但**細胞核裡有什麼**仍是懸案——
  Brown 1831 年發現了核（命名 nucleus），內容不明。**核是兇手的藏身處。**
- **Miescher 的偵查素材**：醫院繃帶上的**膿皰**——白血球密集（核大），
  是純度最高的核素材（當年沒有培養技術）。**膿——噁心的材料，最好的偵查對象。**
- **Miescher 的偵探直覺**：他用**鹽溶液溶解蛋白質**（留下的沉澱是核）、
  **胃蛋白酶消化蛋白質**（剩下的不溶物）——最後得到一種**含磷量高、酸性、
  不被蛋白酶消化**的物質——**它不是蛋白質！**
  他的舅舅（醫師）勸他：「這可能是遺傳的物質基礎」——**Miescher 自己不敢下這個結論。**

## 線索與推理 -- 數學式、程式、理論

### 核心推理：含磷 + 酸性 + 抗蛋白酶 = 核素
Miescher 的化學偵查（排除法的先聲——Avery 1944 的迴響）：
- 蛋白質：**不含磷**（多數）、鹼性 → 被排除
- 脂肪：不含磷（多數）、不溶於鹼 → 被排除
- **新物質：含磷 2.5%、酸性、分子量大、不被蛋白酶消化**——**新物種！**

$$\text{核素} = \text{酸性} + \text{含磷} + \text{抗蛋白酶} \quad (\text{今日所知} = \text{DNA 與蛋白質的複合體})，$$
Miescher 看到的其實是**核蛋白**（DNA + 組蛋白的複合體）——
但他正確地指出：**核裡有一種不屬於蛋白質的新物質。**
（他後來分離出純的「核素」——1889 年他的學生 Altmann 命名純物質為**核酸 (nucleic acid)**。）

### 核心推理二：精子中的確認
Miescher 轉用**萊茵河的鮭魚精子**（核最大、純度最高）——確認核素在精子中大量存在。
**精子 = 遺傳的載體（常識）+ 核素 = 精子的主要成分**——
**遺傳的物質基礎就在眼前**！但 Miescher 保守地下結論：
「核素可能只是細胞的磷儲存庫」——**證據在手，結論不敢下。**

### 核素的接力偵破
| 年份 | 人物 | 進展 |
|------|------|------|
| 1869 | Miescher | 核素的發現（膿與精子） |
| 1889 | Altmann | 純物質命名「核酸」 |
| 1900s | Levene | 四種鹼基、核苷酸的結構（但「四核苷酸假說」錯誤——低估了 DNA 的複雜度） |
| 1943 | Avery | 轉型因子 = DNA |
| 1950 | Chargaff | A=T、G=C 定則（推翻四核苷酸假說） |
| 1953 | Watson–Crick | 雙螺旋 |

## 結案 -- 後果與影響
- **核酸化學的誕生**：Miescher 開啟了核酸化學——
  Levene 的核苷酸結構、Chargaff 的定則、雙螺旋——
  **DNA 從膿皰裡的未知物質，走到生命的中心舞臺，用了 84 年。**
- **「配角」的偏見史**：1869–1943 年，核酸被視為「結構材料」（四核苷酸假說——
  DNA 只是 ACGT 的重複，無資訊量）——**偏見讓主角等了 74 年**
  （Avery 1943 的翻案、雙螺旋 1953 的封聖）。
- **素材的偵探學**：膿、精子、魚精——**噁心與平凡的材料，可以是最大的線索**
  （Fleming 1928 的污染培養皿的迴響）。
- **發現與理解的距離**：Miescher 發現了它、卻不理解它——
  **「發現」與「理解」是兩個案件**（Ivanovsky 1892/1898、Mendel 1865/1900 的迴響）。
- 歷史花絮：Miescher 1872 年在萊茵河撈鮭魚——他寫信給舅舅：
  「核素在精子中如此豐富，或許它就是受精的化學基礎」——
  **他幾乎說出了真相，又自己縮了回去。**
