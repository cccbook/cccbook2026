# 2003 - 人類基因組計劃（30 億鹼基對全部讀出）

## 案件摘要
2003 年 4 月，人類基因組計劃 (Human Genome Project, HGP) 宣布完成：
**30 億鹼基對、約 2 萬個基因**的人類基因組全部定序。
這場 13 年、27 億美元、跨六國的偵探行動（1990–2003），
與私人公司 Celera（Venter）展開著名的競賽——
**生命的完整說明書被讀出**，醫學從此進入基因組時代。

## 前因 -- 為什麼會有這個案子
- **讀完的誘惑**：Sanger 定序（1977）證明序列可讀，但通量太低——
  30 億鹼基對用 1980 年代的方法要**數千年**。**通量是兇手。**
- **HGP 的誕生（1985–1990）**：1985 年 UC Santa Cruz 的會議提出構想；
  1988 年美國國會撥款、Watson 出任首任主管（後由 Collins 接任）；
  1990 年正式啟動——目標：15 年、30 億美元、讀完 30 億鹼基對。
- **公共 vs 私人的競賽**：1998 年，Craig Venter 的 Celera Genomics 宣布
  用**霰彈槍定序 (whole-genome shotgun)** + 超級電腦，**3 年**讀完——
  直接跳過公共計劃的「逐步作戰」策略。**競賽加速了偵破。**

## 線索與推理 -- 數學式、程式、理論

### 核心推理一：霰彈槍定序的數學
Celera 的策略：把基因組**隨機打碎**成數千萬段短讀，
全部定序後用**重疊比對**組裝回來：
$$\text{覆蓋率 } C = \frac{N \times L}{G}, \qquad N \text{ 讀數}, L \text{ 讀長}, G \text{ 基因組大小}.$$
Lander–Waterman 定律（1988）：讀的起點在基因組上的分佈是**泊松過程**，
缺口（gaps）的期望數：
$$E[\text{gaps}] = N e^{-C}, \qquad C = \ln N \text{ 時缺口趨近 } 1.$$
**覆蓋率 8–10 倍**即可組裝出近乎完整的基因組——30 億 × 10 = **300 億鹼基的定序量**，
Celera 的 300 台 Capillary 電泳儀 + Compaq 超級電腦，日夜不停跑了 3 年。

### 核心推理二：公共計劃的逐步作戰（Hierarchical）
公共計劃的策略：先把基因組切成**大片段（BAC，~150 kb）**、
畫出每段在染色體上的位置（**物理圖譜**）、再逐段霰彈槍定序。
慢但**組裝容易**（每段位置已知）。
**兩種策略的競賽 = 電腦科學的經典權衡**：組裝的簡單性 vs 定序的通量。

### Python：覆蓋率與缺口的泊松偵查

```python
import numpy as np

def shotgun_coverage(G, N, L, rng=None):
    rng = rng or np.random.default_rng(0)
    starts = rng.integers(0, G - L, size=N)      # 讀的起點（均勻隨機）
    genome = np.zeros(G, bool)
    for s in starts: genome[s:s+L] = True
    return genome

G, L = 10_000_000, 500                          # 10 Mb 模擬、讀長 500
for C_target in [1, 5, 10]:
    N = int(C_target * G / L)
    covered = shotgun_coverage(G, N, L)
    print(f"覆蓋率 {C_target}x → 實際覆蓋 {covered.mean()*100:.1f}%")
```
輸出：
```
覆蓋率 1x → 實際覆蓋 63.2%
覆蓋率 5x → 實際覆蓋 99.4%
覆蓋率 10x → 實際覆蓋 100.0%
```
覆蓋率 1x 時恰好覆蓋 $1 - e^{-1} = 63.2\%$——**泊松過程的精確預測**（Lander–Waterman 定律）。

## 結案 -- 後果與影響
- **基因組時代的誕生**：30 億鹼基對可讀之後——
  個人化醫學、癌症基因組、罕見疾病診斷、藥物基因組學全部起飛。
- **意外的謎題**：基因只有 **~2 萬個**（與線蟲差不多！）——
  「基因數 = 複雜度」的假設崩塌。**複雜度藏在表觀遺傳、非編碼 RNA、
  選擇性剪接**——這些是 HGP 之後的新懸案。
- **定序成本的暴跌**：2003 年定序一個人類基因組要 ~27 億美元（HGP 成本）；
  2023 年只要 **~200 美元**——比摩尔定律還快 1000 倍（"超摩尔定律"）。
  **讀基因從國家級工程變成消費級服務。**
- **CRISPR 的鋪路**：能讀才能寫——HGP 的序列資料是 CRISPR
  （見 `2012-CRISPR基因編輯.md`）設計嚮導 RNA 的必要資料庫。
- **競賽的公道**：HGP 與 Celera 各自發表（Nature vs Science, 2001），
  組裝方法論的功勞屬於兩陣營——**公共的嚴謹 + 私人的速度 = 雙引擎偵破**。
