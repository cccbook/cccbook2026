# 1887 Arrhenius 電解解離

## 案發現場

1880 年代，溶液化學中有一個天大的異常之謎：**凝固點下降與滲透壓的「失控」**。拉烏爾（Raoult）發現，非揮發性溶質使溶劑凝固點下降 $\Delta T_f = K_f m$，這對糖、酒精等溶液完美成立。但把鹽水、酸溶液拿來測量，凝固點下降卻是理論值的將近兩倍——好像一個分子在溶液中變成了「兩個粒子」！氯化鈉近乎 2 倍，氯化鈣近乎 3 倍，越「鹽」的物質倍數越整齊地偏大。這絕不是實驗誤差，而是理論的破洞。

同時，傳統觀點認為鹽溶於水後仍是「分子」狀態，電解（通電後在電極析出物質）是通電才把分子「撕開」。但為什麼電解不需要通電就會發生？為什麼鹽溶液在沒有電流的情況下也導電良好？

斯德哥爾摩一位年輕的博士生阿瑞尼士（Svante Arrhenius, 1859–1927）在 1883 年的博士論文中提出了一個大膽到近乎「異端」的答案，論文差點不及格，卻最終摘下諾貝爾獎。

## 偵查過程

阿瑞尼士的靈感來自一個簡單的觀察：**純水幾乎不導電，但溶入鹽後立刻導電**——導電性是溶質帶來的，不是通電產生的。他的推理鏈條：

**第一步：鹽在水中「自己」解離成離子。** 他提出電解質（鹽、酸、鹼）溶於水時自發分解為帶電的離子：

$$\mathrm{NaCl \ (s) \xrightarrow{水} Na^+ (aq) + Cl^- (aq)}$$

$$\mathrm{HCl \xrightarrow{水} H^+ + Cl^-}, \qquad \mathrm{CaCl_2 \xrightarrow{水} Ca^{2+} + 2Cl^-}$$

水在溶液中「打架」的不只是分子，而是離子。離子能自由移動，因此溶液導電；通電只是讓離子定向遷移、在電極放電而已。

**第二步：解釋凝固點異常。** 依拉烏爾定律，凝固點下降正比於溶液中「粒子總數」。若 NaCl 解離成 2 個離子，粒子數加倍：

$$\Delta T_f = i \cdot K_f m, \qquad i \approx 2 \ (\text{NaCl}), \quad i \approx 3 \ (\text{CaCl}_2)$$

這個 $i$ 因子（後來稱為凡特荷甫因子）的整數規律，正是解離說的鐵證。滲透壓、沸點上升同樣被 $i$ 修正。

**第三步：離子濃度與平衡。** 阿瑞尼士進一步提出解離度 $\alpha$ 與稀釋定律的雛形，並用電導率測量 $\alpha$。他的老師辈奥斯特瓦德隨即把它精煉為奥斯特瓦德稀釋定律（見 [1884-Ostwald催化與平衡.md](1884-Ostwald催化與平衡.md)）：

$$K = \frac{c \alpha^2}{1 - \alpha}$$

弱電解質（如乙酸）稀釋時 $\alpha$ 增大，這由電導數據完美驗證。

**艱難的求證之路。** 1883 年阿瑞尼士向烏普薩拉大學提交論文，評審認為「離子不可能是真實存在的」——帶電的原子怎麼能在水中穩定存在？論文僅獲得第四等成績（差點不及格）。他寄論文給歐洲各大家：克勞修斯不以為然，但范特荷甫看到了 $i$ 因子的救星，奥斯特瓦德親自到斯德哥爾摩拜訪他。1887 年阿瑞尼士發表了完整的電解解離理論，此後二十年歐洲學界為此激辯不休。

## 結案報告

1903 年，阿瑞尼士獲得諾貝爾化學獎——化學界第一座諾貝爾獎，而且當年物理與化學獎評審還為了「該歸物理還是化學」爭論（最後給了化學獎）。那篇差點不及格的博士論文，成了科學史上最著名的「鹹魚翻身」故事。

電離解離說的遺產深遠：

1. **酸鹼理論**：阿瑞尼士定義「酸在水中解離出 $\mathrm{H^+}$、鹼解離出 $\mathrm{OH^-}$」，這是現代酸鹼理論的第一步，後續發展為 Brønsted-Lowry 與 Lewis 理論（見 [1916-Lewis共價鍵.md](1916-Lewis共價鍵.md)）。
2. **溶液理論**：$i$ 因子、活量、電導——吉布斯熱力學終於能完整應用到電解質溶液。
3. **化學動力學**：阿瑞尼士的離子概念也為他後來的活化能理論鋪路（見 [1889-Arrhenius活化能.md](1889-Arrhenius活化能.md)）。
4. **生物化學**：神經傳導、體液平衡都依賴離子概念。

## 證據與工具

```python
# 用凝固點下降數據驗證電解解離：計算凡特荷甫因子 i
import numpy as np

Kf_water = 1.86  # 水的凝固點下降常數 Kf (K·kg/mol)

# 實驗測得的凝固點下降（假設數據，質量莫耳濃度均為 0.10 m）
samples = {
    "蔗糖 (非電解質)": 0.188,
    "NaCl": 0.348,
    "CaCl2": 0.524,
}
expected_particles = {"蔗糖 (非電解質)": 1, "NaCl": 2, "CaCl2": 3}

print(f"{'樣本':<16}{'ΔTf 實測':>10}{'i 實驗值':>10}{'理論粒子數':>12}")
for name, dTf in samples.items():
    i_exp = dTf / (Kf_water * 0.10)   # i = ΔTf / (Kf·m)
    print(f"{name:<16}{dTf:>10.3f}{i_exp:>10.2f}{expected_particles[name]:>12}")

# 結論：非電解質 i≈1（無解離），NaCl i≈2（解離成 2 離子），CaCl2 i≈3
# 這正是 Arrhenius 解離說的定量證據
print("\n→ i 因子的整數規律證明：電解質在水中自發解離成離子")
```
