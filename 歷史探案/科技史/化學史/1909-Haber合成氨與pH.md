# 1909 Haber合成氨與pH

## 案發現場

二十世紀初，人類面臨一個看似簡單卻攸關生存的難題：氮肥從哪裡來？空氣中百分之七十八是氮氣 $\mathrm{N_2}$，但它以極穩定的三鍵 $\mathrm{N \equiv N}$ 結合，幾乎不與任何物質反應。當時的肥料主要依賴智利硝石礦藏，而專家預言這些礦將在數十年內枯竭。化肥短缺意味著糧食危機，甚至有「用空氣造麵包」的口號流傳。德國化學家 Fritz Haber 在 Karlsruhe 大學任教，他決心挑戰這個熱力學與動力學的雙重難關。

同一年，在丹麥哥本哈根的 Carlsberg 實驗室，化學家 Søren Peter Lauritz Sørensen 也面對自己的「案發現場」：啤酒釀造與蛋白質研究中，酸鹼度控制至關重要，但當時用「氫離子濃度」的數值跨越十幾個數量級，記錄與比較都極不方便，例如 $\mathrm{[H^+]} = 3.2 \times 10^{-7}\ \mathrm{mol/L}$ 這樣的數字難以直觀理解。誰能想到，這兩件表面上毫無關聯的事——工業合成氨與酸鹼標度——都在 1909 年發生，並共同塑造了現代化學工業的樣貌。

## 偵查過程

Haber 的偵查思路是先「審問」化學平衡本身。合成氨反應

$$\mathrm{N_2(g) + 3H_2(g) \rightleftharpoons 2NH_3(g)}$$

的特徵是：放熱（$\Delta H \approx -92\ \mathrm{kJ/mol}$），且氣體分子數由 4 減為 2。根據 Le Chatelier 原理，低溫與高壓都有利於氨的生成。但這裡藏著矛盾：低溫下反應速率極慢，因為氮氣的三鍵解離能高達 $941\ \mathrm{kJ/mol}$，需要極高的活化能 $E_a$，依 Arrhenius 方程式

$$k = A\, e^{-E_a/RT}$$

溫度越低，速率常數 $k$ 指數級下降。Haber 的推理是：用高壓把平衡「推」向產物，用催化劑把活化能「拉」下來，再在兩者之間找妥協點。他經過數百次實驗，篩選出鋨（Os）與後來改用的鐵系催化劑，在約 $200\ \mathrm{atm}$、$500\ ^\circ\mathrm{C}$ 下達到約 6–8% 的單程轉化率，並設計氣體循環迴路，把未反應的氮氫回收再進料，使總轉化率接近 100%。1913 年，工程師 Carl Bosch 在 BASF 將其放大為日產 30 噸的工廠，史稱 Haber–Bosch 法。

Sørensen 的偵查則是「換一把尺」。他注意到氫離子濃度跨越大範圍，正離散的氫光譜與能量階梯的對數規律給了他靈感：為何不用對數壓縮？他定義

$$\mathrm{pH} = -\log_{10}[\mathrm{H^+}]$$

於是 $\mathrm{[H^+]} = 3.2 \times 10^{-7}$ 變成 $\mathrm{pH} = 6.5$，一個一目了然的數字。他還發明了電位測定法，用氫電極與甘汞電極組成原電池，由 Nernst 方程式

$$E = E^{\circ} - \frac{RT}{F}\ln[\mathrm{H^+}] = E^{\circ} + \frac{2.303\,RT}{F}\,\mathrm{pH}$$

從電動勢直接讀出 pH，讓酸鹼度量從「滴定估計」升級為「儀器測量」。每降 1 個 pH，氫離子濃度增加十倍——這條對數階梯至今仍是化學、生物、環境科學的通用語言。

## 結案報告

Haber–Bosch 法被譽為「從空氣中製造麵包」：今日地球上約一半人口的糧食依賴合成氮肥。但硬幣有兩面——Haber 也在一次大戰期間主導化學武器研發，氨工業同時供應炸藥原料硝酸，讓德國在封鎖下仍能持續作戰。這使 Haber 成為科學史上最具爭議的人物之一：1918 年獲諾貝爾化學獎，卻也被稱為「毒氣之父」。工業與倫理的張力，成為後世科學教育的必讀案例。

Sørensen 的 pH 標度則在 1920 年代迅速傳遍世界，成為後續酸鹼理論發展的度量基礎：1923 年 Brønsted 的質子理論（見 [1923-Bronsted酸鹼理論.md](1923-Bronsted酸鹼理論.md)）以 $\mathrm{p}K_a$ 精確量化酸鹼強度，玻璃電極 pH 計在 1930 年代問世，今日從血液檢驗到土壤改良、從泳池管理到半導體清洗，pH 無所不在。一案養活了世界，一案量化了世界。

## 證據與工具

```python
import numpy as np

# --- 案件一：合成氨的溫度-平衡權衡 ---
# 近似：Kp 隨溫度下降而增大（放熱反應），van't Hoff 方程式
R = 8.314  # J/(mol K)
dH = -92000  # J/mol，放熱
K_ref, T0 = 6.0e5, 298  # 298K 的近似 Kp

for T_c in [300, 400, 500, 600]:  # 攝氏
    T = T_c + 273
    # van't Hoff: ln(K2/K1) = -dH/R * (1/T2 - 1/T1)
    lnK = np.log(K_ref) - dH / R * (1 / T - 1 / T0)
    print(f"T = {T_c}°C, Kp ≈ {np.exp(lnK):.3e}  （低溫利於平衡，但速率慢）")

# --- 案件二：pH 對數標度驗算 ---
conc = 3.2e-7  # mol/L
print(f"\n[H+] = {conc} mol/L  →  pH = {-np.log10(conc):.2f}")

# Nernst 方程式：由電動勢反推 pH（25°C）
F = 96485
E_deg, E = 0.0, 0.414  # 氫電極 vs 甘汞電極的示意值
pH = (E - E_deg) * F / (2.303 * R * 298)
print(f"電動勢 E = {E} V  →  pH ≈ {pH:.2f}")
```
