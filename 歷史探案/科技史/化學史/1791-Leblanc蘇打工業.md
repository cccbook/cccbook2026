# 1791 Leblanc 蘇打工業

## 案發現場

十八世紀末，歐洲的玻璃、肥皂、紡織與造紙工業都仰賴一種關鍵原料：純鹼（碳酸鈉 $\mathrm{Na_2CO_3}$，又稱蘇打）。傳統上純鹼取自兩個來源：燃燒海草或內陸鹽生植物取得的「植物鹼」，以及西班牙巴塞隆納附近的海岸灰。但人口爆炸與工業成長使天然鹼供不應求，價格高漲，法國尤其受制於英國海草灰的進口。

1775 年，法國科學院懸賞 12,000 里弗爾獎金，徵求「以最經濟的方法從食鹽製造純鹼」的方案。食鹽（氯化鈉 $\mathrm{NaCl}$）便宜又無窮無盡，但它與碳酸鈉之間隔著一道化學鴻溝：$\mathrm{Cl^-}$ 與 $\mathrm{CO_3^{2-}}$ 如何交換？這道鴻溝困住了全歐洲的化學家。

遇到這個問題的，是法國外科醫生兼業餘化學家尼古拉·勒布朗（Nicolas Leblanc, 1742–1806）。他出身孤兒，靠行醫維生，卻懷著工業化的雄心。1789 年法國大革命爆發，局勢動盪，但勒布朗仍秘密投入研究，終於在 1791 年找到答案並取得專利——也展開了他悲慘的一生。

## 偵查過程

勒布朗的推理分成兩步，核心是「先轉成硫酸鹽，再交換出碳酸鹽」：

**第一步：鹽轉硫酸鈉（曼海姆法）。** 食鹽與硫酸共熱，產生硫酸鈉與氯化氫：

$$\mathrm{2NaCl + H_2SO_4 \to Na_2SO_4 + 2HCl\uparrow}$$

氯化氫當時被視為廢氣排放，造成嚴重汙染——這是工業化學史上第一個大型空汙問題。

**第二步：硫酸鈉與煤、石灰石共熔（黑灰法）。** 將硫酸鈉、煤炭（提供碳作還原劑）與碳酸鈣混合高溫鍛燒，先還原成硫化鈉，再經交換反應生成碳酸鈉：

$$\mathrm{Na_2SO_4 + 2C \to Na_2S + 2CO_2\uparrow}$$

$$\mathrm{Na_2S + CaCO_3 \to Na_2CO_3 + CaS}$$

反應的熱力學動力來自兩處：碳還原反應中 $\mathrm{C \to CO_2}$ 的強烈驅動（生成氣體逸出使熵增），以及第二步中較穩定的 $\mathrm{CaS}$ 固相生成。勒布朗以質量守恆做化學計量設計：理論上每 100 份食鹽約可產出 90 份硫酸鈉，再轉為約 50 份純鹼。他用水浸出「黑灰」中的碳酸鈉、結晶純化，得到可供玻璃與肥皂工業使用的產品。

這套流程的聰明之處在於：它不依賴任何昂貴的天然原料，只用食鹽、硫酸、煤與石灰石——全是當時最廉價的工業品。1791 年勒布朗在奧爾良公爵資助下建廠，日產 300 公斤純鹼，成本只有植物鹼的一半以下。

## 結案報告

勒布朗的結局卻是化學史上最令人唏噓的悲劇之一。法國大革命中，奧爾良公爵被送上斷頭台，工廠被沒收，勒布朗未拿到法國科學院的獎金（該獎最終從未正式發出）。他花了十幾年打官司要回專利，卻失敗了；工廠最後由他人經營獲利，他一貧如洗，1806 年在一家療養院附近開槍自殺身亡。

但他的發明開啟了整個**工業化學**時代：

- **純鹼量產**：Leblanc 法統治歐洲約一個世紀，1880 年代英國產量達每年 20 萬噸以上，使玻璃、肥皂、造紙、紡織成為大眾消費品。
- **單元操作的誕生**：鍛燒、浸出、結晶、蒸餾等步驟被標準化、連續化，成為現代化學工程的雛形。
- **合成氨的伏筆**：其副產物氯化氫的處理與回收問題，引發了氯鹼工業與接觸法硫酸，也間接推動了後來哈伯法合成氨（見 [1909-Haber合成氨與pH](1909-Haber合成氨與pH.md)）的化肥體系。
- **綠色化學的教訓**：黑灰法的硫化鈣廢渣與鹽酸廢氣汙染，成為史上第一場「工業環境抗爭」，催生了英國 1863 年《鹼業法》（Alkali Act）——世界第一個空汙管制法。

勒布朗的故事告訴我們：發明者的榮耀未必屬於他自己，但他的方法卻餵養了整個十九世紀的工業世界。直到 1861 年索爾維（Solvay）氨鹼法問世，Leblanc 法才逐漸被淘汰，但工業化學的根基已由勒布朗奠定。

## 證據與工具

以下 Python 程式碼示範 Leblanc 法的完整化學計量計算，從食鹽一路追蹤到純鹼產量與理論收率。

```python
# Leblanc 蘇打法的化學計量模擬
# 第一步: 2NaCl + H2SO4 -> Na2SO4 + 2HCl
# 第二步: Na2SO4 + 2C -> Na2S + 2CO2
# 第三步: Na2S + CaCO3 -> Na2CO3 + CaS
MOL_MASS = {"NaCl": 58.44, "Na2SO4": 142.04, "Na2CO3": 105.99, "C": 12.01, "CaCO3": 100.09}

def leblanc_process(mass_NaCl, yield_step=0.85):
    """從食鹽質量(克)依 Leblanc 法三步反應追蹤到純鹼產量(克)。
       yield_step 為每步的實際收率(黑灰法損耗大，設 0.85)"""
    n_NaCl  = mass_NaCl / MOL_MASS["NaCl"]
    n_Na2SO4 = n_NaCl / 2 * yield_step            # 2 NaCl -> 1 Na2SO4
    n_Na2S   = n_Na2SO4 * yield_step              # 1 Na2SO4 -> 1 Na2S
    n_Na2CO3 = n_Na2S * yield_step                # 1 Na2S -> 1 Na2CO3
    mass_Na2SO4 = n_Na2SO4 * MOL_MASS["Na2SO4"]
    mass_Na2CO3 = n_Na2CO3 * MOL_MASS["Na2CO3"]
    return mass_Na2SO4, mass_Na2CO3

mass_NaCl = 100.0  # 以 100 克食鹽為基準
m1, m3 = leblanc_process(mass_NaCl)
print(f"100 g NaCl -> 硫酸鈉 {m1:.1f} g -> 純鹼 {m3:.1f} g")
print(f"理論總收率: {m3/100*100:.1f}%（每 100 份食鹽約得 50 份純鹼）")

# 需要的輔助原料量（以化學計量反推）
n_NaCl = 100.0 / MOL_MASS["NaCl"]
n_H2SO4 = n_NaCl / 2
n_C = n_NaCl / 2 * 2      # 2 C per Na2SO4
n_CaCO3 = n_NaCl / 2
print(f"需 H2SO4 {n_H2SO4*MOL_MASS.get('H2SO4',98.08):.1f} g、"
      f"煤(碳) {n_C*MOL_MASS['C']:.1f} g、石灰石 {n_CaCO3*MOL_MASS['CaCO3']:.1f} g")
```

執行後可以看到勒布朗設計的核心：原料全是最便宜的工業品，而每 100 份食鹽約轉出 50 份純鹼——這個簡單的計量關係，撐起了整個十九世紀的玻璃與肥皂工業。
