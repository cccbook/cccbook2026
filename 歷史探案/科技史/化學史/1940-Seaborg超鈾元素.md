# 1940 Seaborg 超鈾元素

## 案發現場

1940 年春天，加州大學柏克萊分校。在 60 吋迴旋加速器旁的實驗室裡，年輕的化學家格倫・西博格（Glenn T. Seaborg）與物理學家埃德温・麥克米倫（Edwin McMillan）正面對一張「不完整的化學地圖」——元素週期表的末端。

自門捷列夫（參閱 [1869-Mendeleev週期表.md](1869-Mendeleev週期表.md)）繪出週期表以來，化學家相信表上的每一格都對應一種自然存在的元素。到 1930 年代末，已知最重的元素是鈾（U，原子序 92），恰好是週期表第 7 列的最後一格。92 之後是什麼？週期表在此斷裂，像一張地圖的邊緣寫著「此處有龍」。

費米 1934 年的中子實驗（參閱 [1939-Hahn核分裂.md](1939-Hahn核分裂.md)）一度讓人以為已經造出 93 號元素，但核分裂的發現說明那些「產物」其實是裂變碎片。真正造出超鈾元素的任務懸而未決。

1940 年，麥克米倫在用中子轟擊鈾的實驗中，注意到一個關鍵線索：裂變碎片都是高能的、會從靶上飛出去；但有一種放射性產物卻留在靶上不動——它半衰期約 2.3 天。麥克米倫與化學家艾貝爾森（Philip Abelson）用化學方法證明：這個產物的化學性質不像任何稀土元素，而像「鈾的下一代」——這就是第 93 號元素，他們以海王星（Neptune）之名將其命名為錼（Neptunium，Np）。化學地圖的第一格新大陸出現了。

但更大的謎題隨之而來：錼會經 $\beta^-$ 衰變變成原子序 94 的元素。這個「94 號」是什麼？它有什麼化學性質？當時甚至有人認為 92 之後的元素會越來越像鈾（「鈾系元素」），週期表可能就此走向混亂。更迫切的現實問題是：1940 年代的戰爭陰影下，如果能找到一種可分裂的超鈾元素，它可能成為鏈反應的燃料。這個問題之所以重要，不僅因為它是元素合成的邊疆，更因為它可能決定核時代的能源與武器。

誰能辨認出肉眼不可見、總量不到百萬分之一克的元素？答案只有放射化學家——用「化學偵探」的手法，靠元素的化學性質而非重量來指認。而這齣大戲的主角，正是剛加入麥克米倫團隊的西博格。

## 偵查過程

西博格的偵查策略有三步：造出它、分離它、讀懂它。

第一步：造出。1940 年底至 1941 年初，西博格、麥克米倫、約瑟夫・甘迺迪（Joseph W. Kennedy）與阿瑟・瓦爾（Arthur Wahl）用柏克萊的迴旋加速器，以氘核轟擊鈾靶，先造出錼-238，再讓它 $\beta^-$ 衰變成 94 號元素：

$$\mathrm{^{238}U + {}^{2}H \rightarrow {}^{238}Np + 2\,{}^{1}n}, \qquad \mathrm{^{238}Np \xrightarrow{\beta^-} {}^{238}Pu}$$

第二步：分離。這是化學偵探的真功夫。新的 94 號元素總量極微（初期的實驗樣品不到 1 微克，肉眼完全不可見），如何證明它存在？西博格的關鍵推理是一個假說：如果 94 號元素的化學性質「像鈾」，那就難以分離；但如果它像稀土（錒系），或像「鈾的下一個同族元素」，就能找到分離之道。團隊在 1941 年 2 月用氧化沉澱法證明：這個新元素的氧化態行為與鈾不同——它可以被氧化到 +6 態而與鈾分離。他們以冥王星（Pluto，比海王星更遠的行星）之名命名為鈽（Plutonium，Pu），並首次測得純化後的 $\mathrm{^{238}Pu}$ 樣品。

更重要的目標是可分裂的 $\mathrm{^{239}Pu}$。用中子照射天然鈾，可以經由下列路徑生成：

$$\mathrm{^{238}U \xrightarrow{(n,\gamma)} {}^{239}U \xrightarrow{\beta^-\ (23.5\ min)} {}^{239}Np \xrightarrow{\beta^-\ (2.36\ d)} {}^{239}Pu}$$

1941 年 3 月，西博格團隊用迴旋加速器造出約 0.5 微克的 $\mathrm{^{239}Pu}$，並證明它被慢中子照射時會發生核分裂，分裂截面遠大於鈾-238。這是一個石破天驚的結論：$\mathrm{^{239}Pu}$ 可以取代稀有的鈾-235，成為鏈反應的燃料——而鈽可以從天然鈾中用反應堆「量產」。

第三步：讀懂。西博格做出了一個重排整個週期表的理論決斷。當時的長式週期表把鈾放在鎢、錸之下，暗示 93、94 號元素應與錸、鋨同族（過渡金屬）。但化學實驗一再顯示錼、鈽的行為不像錸、鋨，反而像稀土元素——彼此相似、難以分離、有多重氧化態。西博格據此提出「錒系概念」（actinide concept）：從錒（Ac，89）到鋨（Lr，103）這 15 個元素，是「第二個稀土系列」——像鑭系（鑭到鎦）一樣，是 $5f$ 軌域逐漸填滿的系列，應該在週期表中自成一行，放在鑭系元素之下。

這個推論的根基是電子組態。鑭系元素的 $4f$ 軌域在原子序 57 之後開始填入；西博格推論 $5f$ 軌域也在錒（89）之後開始填入，兩系列元素的外層電子組態相似（皆為 $\mathrm{7s^2}$ 或 $\mathrm{6s^2}$ 加上漸填的 $f$ 電子），故化學性質相似：

$$\text{錒系：} [\mathrm{Rn}]\,5f^{n}\,7s^{2} \quad (n = 0\text{–}14), \qquad \text{鑭系：} [\mathrm{Xe}]\,4f^{n}\,6s^{2} \quad (n = 0\text{–}14)$$

1944 年，西博格把錒系概念寫進論文，並據此「重排」週期表：鈾、錼、鈽不再放在第 7 列的過渡金屬位置，而是移到鑭系之下。這是一次自門捷列夫以來最大膽的週期表重構——第 7 列的末端被整個重新定義，93 至 103 號元素的化學預測從此有了理論藍本。用這個藍本，西博格團隊在 1944 至 1974 年間接連合成了鋂（Am，95）、鋦（Cm，96）、鉳（Bk，97）、鉲（Cf，98）、鑀（Es，99）、鐨（Fm，100）、鍆（Md，101）、鍩（No，102）、鐒（Lr，103），以及 104 之後的𨭎（Sg，106）——他個人生涯參與合成了九個元素，全部依錒系概念的預測找到分離之道。

## 結案報告

結案報告的第一頁，寫著戰爭。$\mathrm{^{239}Pu}$ 可分裂的證明，直接催生了曼哈頓計畫的鈽生產線：1942 年起的漢福德反應堆量產鈽，1945 年 7 月 16 日「三位一體」核試驗使用的正是鈽彈，8 月 9 日長崎遭鈽彈轟炸。西博格親手合成的元素，成為結束戰爭的武器，也成為冷戰核軍備競賽的籌碼——這是他一生揮之不去的倫理重量。

第二頁，寫著核化學工業。戰後，鈽成為核電與核武的雙面燃料；混合氧化物燃料（MOX）、快中子增殖反應堆、核廢料管理，全都建立在鈽化學之上。西博格主持美國原子能委員會十年（1961–1971），推動核能的和平利用。放射化學從實驗室絕技，發展為處理公斤級放射性物質的核化工產業——從微克到噸，只用了二十年。

第三頁，寫著化學的骨架。錒系概念重排了週期表，把 89 至 103 號元素納入 $5f$ 系列，使第 7 列的末端成為可預測、可探索的疆域。這個框架直接指引了後續所有超鈾元素的合成與鑑定，直到 118 號鿫（Og）；錒系化學（多重氧化態、螯合分離、鑭繫鋼系相似性）也成為核廢料分離（如 TALSPEAK 製程）的理論基礎。電子組態與週期表的關係，可回溯至 [1913-Soddy同位素與Moseley原子序.md](1913-Soddy同位素與Moseley原子序.md) 與 [1913-Bohr原子模型.md](1913-Bohr原子模型.md) 的量子架構。

1951 年，西博格與麥克米倫因「發現超鈾元素的化學」獲得諾貝爾化學獎。更罕有的榮耀在身後：1997 年，國際純粹與應用化學聯盟（IUPAC）把 106 號元素命名為𨭎（Seaborgium, Sg）——西博格成為史上第一位在生前就「擁有以自己命名的元素」的科學家。他在命名典禮上說：「能與門捷列夫、居里夫婦同列一表，是化學家最大的光榮。」

西博格在《超鈾元素》一書中寫道：錒系概念告訴我們，週期表不是已完成的名冊，而是仍在生長的有機體。從 1940 年那不到 1 微克的樣品，到今日週期表延伸至 118 號，這片新大陸的每一格，都是化學偵探用智慧與耐心一格格「推理」出來的。

## 證據與工具

以下計算示範偵查的核心推理：追蹤 $\mathrm{^{239}Pu}$ 的生成鏈（放射化學的衰變計算）；錒系概念的電子組態邏輯與各氧化態的分離條件則以表格呈現。

```python
# 1940 Seaborg 超鈾元素：衰變鏈追蹤與錒系概念驗算
import math

# ---- 一、追蹤 239Pu 的生成鏈：238U(n,γ) → 239U → 239Np → 239Pu ----
# 半衰期（單位：天）
half_life = {"U-239": 23.5/24/60*60/60/24,  # 23.5 分鐘 → 0.0163 天
             "Np-239": 2.36,                # 2.36 天
             "Pu-239": 24110}               # 24110 年 ≈ 8.8e6 天

def decay_frac(t, T_half):
    """經時間 t 後未衰變的比例：N/N0 = (1/2)^(t/T_half)"""
    return 0.5 ** (t / T_half)

def production_chain(t, flux_factor=1.0):
    """簡化模型：239U 已立即生成，追蹤 239Np→239Pu 的轉換進度"""
    # 239Np 未衰變比例
    f_Np = decay_frac(t, half_life["Np-239"] / flux_factor)
    # 239Pu 生成比例（239Np 衰變掉的都變成 239Pu，且 Pu-239 半衰期極長可忽略衰變）
    f_Pu = 1 - f_Np
    return f_Np, f_Pu

print("238U(n,γ) 生成 239Pu 的進度（反應堆照射）：")
print(f"{'照射天數':>8} | {'239Np 殘留':>10} | {'239Pu 生成':>10}")
for t in [0.5, 1, 2.36, 5, 7, 10]:
    f_Np, f_Pu = production_chain(t)
    print(f"{t:8.2f} | {f_Np:10.4f} | {f_Pu:10.4f}")
print("  → 照射約 7~10 天後，大部分 239Np 已轉為 239Pu，可進行化學分離\n")
```

衰變計算依 $N/N_0 = (1/2)^{t/T_{1/2}}$ 追蹤 239Np（$T_{1/2} = 2.36$ 天）的殘留；239Np 衰變掉的都變成 239Pu，而 Pu-239 半衰期極長（24,110 年）可忽略衰變，故 239Pu 生成比例 $= 1 - N/N_0$。反應堆照射約 7~10 天後大部分 239Np 已轉為 239Pu，可進行化學分離。

**錒系概念的電子組態邏輯：** 鑭系與錒系元素的價電子組態皆為 $[\text{Xe/Rn}]\,f^n\,s^2$ 型，外層組態相似故化學性質相似——這是 89~103 號元素應如鑭系自成一行（週期表重構）的依據：

| 元素 | $Z$ | 價電子組態 |
|---|---|---|
| 錒 Ac | 89 | $[\mathrm{Rn}]\,5f^0\,7s^2$ |
| 鈾 U | 92 | $[\mathrm{Rn}]\,5f^2\,7s^2$ |
| 鈽 Pu | 94 | $[\mathrm{Rn}]\,5f^2\,7s^2$ |
| 鋦 Cm | 96 | $[\mathrm{Rn}]\,5f^4\,7s^2$ |
| 鉲 Cf | 98 | $[\mathrm{Rn}]\,5f^6\,7s^2$ |
| 鐒 Lr | 103 | $[\mathrm{Rn}]\,5f^{14}\,7s^2$ |

**化學分離：氧化態調變（西博格分離鈽的關鍵手法）：** 鈽的多重氧化態 +3、+4、+6 各有不同安定性；藉氧化/還原循環與載體共沉澱即可分離：

| 氧化態 | 安定性 | 典型化合物 | 分離用途 |
|---|---|---|---|
| Pu(III) | 中 | $\mathrm{PuF_3}$ | 與鑭系共沉澱 |
| Pu(IV) | 高 | $\mathrm{PuF_4}$ | 氟化鑭載體攜帶沉澱 |
| Pu(VI) | 中 | $\mathrm{PuO_2^{2+}}$ | 與鈾(IV)分離 |

**分離量級驗算：** 0.5 微克 $\mathrm{^{239}Pu}$ 的原子數 $N = 0.5\times10^{-6} / 239 \times 6.022\times10^{23} \approx 1.3\times10^{15}$ 個——肉眼完全不可見。放射化學：靠化學性質而非重量指認元素，化學偵探的極致。
