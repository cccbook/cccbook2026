# 1825 Faraday 苯

## 案發現場

十九世紀初，倫敦的煤氣照明工業蓬勃發展。煤在乾餾後除了產生煤氣，還會殘留一種黏稠的黑色副產物——**煤焦油**（coal tar）。這種油狀物氣味刺鼻、成分複雜，當時幾乎沒人知道裡面藏著什麼，多數工廠把它當廢棄物傾倒或廉價販賣。

1825 年，法拉第（Michael Faraday, 1791–1867）在倫敦皇家研究院工作。他當時的興趣已從單純的化學分析轉向「物質的組成單元」：有機物究竟由什麼基本「氫碳比例」的成分構成？這個問題重要，因為道耳頓的原子說與貝采利烏斯的定量分析（見 [1803-Dalton原子說](1803-Dalton原子說.md)）已確立「元素比例決定化合物」的觀念，但有機化學的分析技術仍粗糙，人們無法確定煤焦油這類複雜混合物的內容。

法拉第遇到的機緣是一小瓶樣品：倫敦煤氣公司的煤焦油上層浮著一層清亮的油滴。他能從這層油滴中分離出純物質嗎？這個謎題之所以關鍵，是因為煤焦油是十九世紀最大的有機化學「寶庫」，誰先解開它的成分，誰就打開了染料、藥物與高分子工業的大門。

## 偵查過程

法拉第的推理路線是「分離—提純—定量—命名」。他發展了一套關鍵的**雙液分層技術**：

1. **分餾**：將煤焦油緩慢加熱，按沸點分段收集餾分；
2. **分層**：他注意到上層油滴與鹼性水溶液互不相溶，可利用密度差與不互溶性把油滴從焦油中分出；
3. **冷凍結晶**：法拉第的獨門絕活——把油滴冷卻到攝氏零度以下，會析出片狀晶體；把晶體與母液分離再加溫熔化，重複多次即得純物質。

結晶提純的原理，是利用雜質在固相與液相中的分配差異：純物質在凝固點析出時，雜質留在母液中。這正是現代「區域熔煉」（zone refining）純化矽晶圓的同一原理，只是當年法拉第用的是冰塊與玻璃瓶。

得到純物質後，他進行元素定量分析，發現碳與氫的質量比約為 $12 : 1$，即碳氫原子比為 $1:1$。他命名這新物質為「重碳化氫」（bicarburet of hydrogen），其分子式即今日的苯：

$$\mathrm{C_6H_6} \qquad \frac{w_{\mathrm{C}}}{w_{\mathrm{H}}} = \frac{6 \times 12.01}{6 \times 1.008} \approx 12$$

法拉第還測得其密度約為氫氣的 39 倍（同溫同壓），由此推得分子量約 78，與 $\mathrm{C_6H_6}$ 完全吻合——這是用氣體密度法定分子量的早期傑作，比亞佛加厥分子說被廣為接受還早了三十多年。

但他沒有解開苯最大的謎：這樣一個「碳氫比 1:1」的分子，高度不飽和，化學性質卻異常穩定、不易起加成反應——這違反了當時對不飽和烴的預期。這個結構之謎懸宕四十年，直到 1865 年克庫勒（Kekulé）夢見蛇咬尾巴，提出苯環結構（見 [1865-Kekule苯環.md](1865-Kekule苯環.md)）才真相大白：六個碳排成六角環，$\pi$ 電子離域於整個環上。

## 結案報告

法拉第在 1825 年的發現，當時只是眾多有機分析中的一項，但它是化學史上最有「後勁」的發現之一：

- **苯環結構的起點**：沒有法拉第分離出的純苯，克庫勒無法做苯的取代反應實驗，苯環理論無從建立（見 [1865-Kekule苯環.md](1865-Kekule苯環.md)）。
- **染料工業的基礎**：1856 年珀金（Perkin）從煤焦油中的苯胺合成出第一個合成染料「淡紫紅」（mauveine），開啟了德國合成染料工業霸權，而苯胺正源自苯的硝化。
- **芳香族化學的誕生**：苯及其衍生物（甲苯、苯酚、萘）成為「芳香族」化學的核心，日後的阿斯匹靈、 TNT 炸藥、聚苯乙烯塑膠全都由此發展。
- **分離技術的遺產**：法拉第的結晶提純原理，成為今日半導體工業與藥物純化的基礎。

有趣的是，法拉第本人對苯的後續發展幾乎沒有參與——他在 1831 年之後轉向電磁感應研究，成為電學之父（見 [1834-Faraday電解定律](1834-Faraday電解定律.md)）。化學史學者常說：法拉第用一根玻璃瓶與一塊冰，同時為電磁學與染料工業埋下了種子。

## 證據與工具

以下 Python 程式碼示範：以氣體密度法推算苯的分子量，並模擬分餾苯—甲苯混合物的蒸氣組成（拉午耳定律）。

```python
# 法拉第苯的鑑定：氣體密度法 + 拉午耳定律模擬
R = 0.0821  # L·atm/(mol·K)

def molar_mass_from_density(d_g_per_L, T_C, P=1.0):
    """由氣體密度(g/L)、溫度(°C)、壓力(atm)推算分子量 g/mol"""
    T = T_C + 273.15
    return d_g_per_L * R * T / P

# 法拉第的數據：苯蒸氣密度約為氫氣的 39 倍（同溫同壓）
M_H2 = 2.016
M_est = 39 * M_H2
print(f"相對密度法估計分子量: {M_est:.1f} g/mol")

M_benzene = 78.11
print(f"理論 C6H6 分子量: {M_benzene:.2f} g/mol -> 吻合！")

# 拉午耳定律：苯-甲苯混合物的蒸氣組成（分餾的理論基礎）
P_b = 75.0   # 純苯在 80°C 的蒸氣壓 (kPa)
P_t = 38.0   # 純甲苯在 80°C 的蒸氣壓 (kPa)

print("\n液相苯莫耳分率  蒸氣苯莫耳分率  蒸氣中苯/甲苯比")
for x_b in [0.0, 0.2, 0.4, 0.5, 0.6, 0.8, 1.0]:
    y_b = x_b * P_b / (x_b * P_b + (1 - x_b) * P_t)  # 拉午耳定律 + 道耳頓分壓
    ratio = y_b / (1 - y_b) if 0 < y_b < 1 else float("inf")
    print(f"{x_b:10.1f}      {y_b:10.3f}      {ratio:8.2f}")
```

執行後可以看到兩件事：第一，法拉第用相對密度法得到的 78 g/mol 與 $\mathrm{C_6H_6}$ 完全吻合；第二，蒸氣中苯的莫耳分率永遠高於液相——這正是法拉第分餾提純苯的熱力學依據：苯永遠先「跑」進蒸氣裡。
