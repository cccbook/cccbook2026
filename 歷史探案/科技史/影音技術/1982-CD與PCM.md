# 1982 - CD 與 PCM

## 案件摘要
1982 年，Sony 與 Philips 推出雷射唱片（CD），以 16 位元、44.1 kHz 的 PCM 編碼儲存音樂。數位音響從實驗室走進客廳，音樂工業的介質被徹底數位化。

## 前因
- 1960 年代 PCM（脈衝編碼調變）技術已在錄音室用於數位錄音（NHK、Denon），但儲存介質（磁帶錄 PCM）笨重昂貴。
- 1970 年代末 Sony 與 Philips 分別研發光碟技術，1979 年協議共訂規格——**儲存容量、取樣率、位元深度必須同時拍板**。

## 線索與推理

### 線索一：為什麼是 44.1 kHz
人耳聽覺上限約 20 kHz，取樣定理要求 $f_s > 40$ kHz。但工程上需要留抗混疊濾波器的過渡帶，且 44.1 kHz 恰好相容於當時的 PCM 錄音設備（影像錄影帶轉錄：NTSC 每場 245 行 × 60 場 × 3 樣本 = 44100）：

$$245 \times 60 \times 3 = 44100 \ \text{Hz}$$

這是「以錄影帶為數位儲存介質」年代的歷史遺跡。

### 線索二：為什麼是 16 位元
量化信噪比 $SNR \approx 6.02b + 1.76$ dB。16 位元 ≈ 96 dB，恰好涵蓋人耳動態範圍（從極安靜到痛覺約 120 dB 的主要音樂區間）。取捨：14 位元不夠，20 位元當時儲存成本過高。

### 線索三：光學儲存的容量偵探題
CD 直徑 12 cm，雷射波長 780 nm，單片容量 650–700 MB。傳說容量是為了「裝下貝多芬第九號交響曲完整版（約 74 分鐘）」而設計——74 分鐘 × 44100 × 16 bit × 2 聲道 ≈ 680 MB。規格由物理極限與音樂需求共同決定。

### 線索四：糾錯
光碟刮傷不可避免，CD 用 Reed–Solomon 糾錯碼（CIRC）+ 交錯儲存，可修正數千位元的連續錯誤——**數位介質的優勢（可完美複製）依賴糾錯碼**，這與密碼學同源的數學在此發揮關鍵作用。

## 後果
- 1980–90 年代 CD 取代黑膠與卡帶，音樂工業數位化。
- CD 的 PCM 參數成為數位音響的基準；DVD（1995）、藍光（2006）接續光學家族。
- 數位複製的「完美性」也埋下盜版問題——MP3（1987/1993）與網路帶來下一場革命。
