# 1793-惠特尼軋棉機

## 案件摘要

1793年，美國康乃狄克州出身的年輕發明家伊萊·惠特尼（Eli Whitney，1765–1825）在喬治亞州薩凡納附近的穆爾格雷夫（Mulberry Grove）種植園——將軍納撒內爾·格林（Nathanael Greene）的遺孀凱瑟琳·格林（Catherine Greene）家中——用約十天時間造出了一台簡單的機器：軋棉機（cotton gin，gin 為 engine 之縮寫）。它以轉動的齒筒把棉纖維從棉籽上剝下，效率是手工的數十倍。這是機器史上最弔詭的案件：一項旨在省力的發明，反而使奴隸制在美國南方擴張扎根。

## 前因 -- 為什麼會有這個案子

- 獨立戰爭後美國南方經濟低迷：菸草使土壤耗竭，棉花是候補作物，但短纖維陸地棉（upland cotton，適合南方氣候）的纖維與綠色棉籽黏著極緊，除籽幾乎只能靠手工。
- 一個奴隸整天手工除籽只能清理約1磅（約0.5公斤）皮棉，成本使陸地棉無商業價值——南方的「棉花之夢」卡在這一步。
- 惠特尼1789年入耶魯大學，1792年畢業後南下喬治亞想當家庭教師謀生，卻在格林夫人莊園接觸棉花問題；她與種植園監工菲尼亞斯·米勒（Phineas Miller）鼓勵他著手解決。
- 惠特尼參考了種植園裡失敗的除籽嘗試，十天內以木滾筒、鐵絲齒與網格做出原型。

## 線索與推理 -- 數學式、程式、理論

### 理論一：齒筒剝離——摩擦與鉤掛的機械分離

軋棉機的核心：一端裝有鐵絲齒的滾筒在網格（grid）縫隙中旋轉，棉籽過大無法通過網格縫，纖維被齒鉤住拉過縫隙，與棉籽強制分離；另用反向旋轉的毛刷滾筒把纖維從齒上刷下。機理是「尺寸篩選 + 鉤掛摩擦」：網格縫寬 $d_{gap}$ 滿足

$$d_{seed} > d_{gap} > d_{lint}$$

棉籽直徑約數毫米、纖維束極細，一個簡單的幾何條件就完成了機械分離。齒對纖維的拉力須超過纖維與籽的黏附力 $F_{adhesion}$，而低於把纖維拉斷的力 $F_{break}$：

$$F_{adhesion} < F_{tooth} < F_{break}$$

惠特尼用經驗調整齒距、轉速與縫寬，恰好落進這個窗口——十天完成的洞察，價值連城。

### 理論二：效率數量級——從1磅到50磅

手工除籽：每人每日約1磅皮棉。惠特尼手搖原型：一人力操作每日約50磅；後來的馬力/水力版本達每日數百至上千磅。提升倍數：

$$\frac{P_{gin}}{P_{hand}} \approx 50 \text{（原型）} \sim 1000 \text{（後續大型機）}$$

功率帳很簡單：剝離每磅棉纖維所需功 $w \approx$ 數百焦耳（克服黏附與摩擦），機器以 $P$ 瓦持續輸出，日產量 $= P \cdot t / w$。能量本身微不足道，瓶頸全在「分離動作的重複次數」——機器把重複交給齒筒，人只負責餵料。

### 理論三：經濟學的弔詭——傑文斯悖論的奴隸制版本

省力發明理應減少勞動需求，但棉花的結果相反。原因在需求彈性：英國蘭開夏紡織業（阿克萊特體系之後）對原棉需求近乎無限，軋棉使皮棉價格與成本崩跌，種植面積因此暴增，總勞動需求不降反升：

$$L_{total} = \frac{A_{cotton} \cdot y \cdot c_{gin}}{\eta_{gin}} \uparrow \quad (\text{因 } A_{cotton} \uparrow \text{ 遠快於 } \eta_{gin} \uparrow)$$

其中 $A_{cotton}$ 為種植面積、$y$ 為單產、$c_{gin}$ 為單位皮棉所需勞動、$\eta_{gin}$ 為軋棉效率。面積擴張（從1790年的數千畝到1860年的數百萬畝）吞沒了效率提升——這是傑文斯悖論（Jevons paradox，效率提升反而增加資源消耗）在勞動制度上的殘酷版本。

```python
# 驗證：軋棉效率提升 vs. 種植面積擴張對勞動需求的影響
years = [1790, 1800, 1820, 1860]
bales_M = [0.003, 0.073, 0.33, 4.5]   # 美國皮棉年產量（百萬包，500磅/包）
# 粗略模型：勞動需求 ∝ 產量 / 軋棉效率；效率每十年約提升3倍
eta = 1.0
for y, b in zip(years, bales_M):
    print(f"{y}: 年產 {b:.2f} 百萬包，軋棉效率倍率 {eta:.0f}，勞動需求相對值 {b/eta:.2f}")
    eta *= 3
```

## 破案時刻

1793年，惠特尼的原型機在穆爾格雷夫莊園示範：轉動曲柄，棉絮從齒筒上被毛刷拋出，籽粒留在網格上——圍觀的種植園主立刻明白這是「南方經濟的鑰匙」。1794年3月惠特尼取得美國專利（專利號X72），與米勒合夥，採用「按軋棉量抽成」的授權模式經營。但破案後的遭遇是機器史上著名的悲劇：機器構造極簡、極易仿製，南方各處工坊私造「saw gin」泛濫，惠特尼的訴訟成本高於收益，專利幾乎無法執行；1798年他放棄軋棉事業，轉向康乃狄克州承包美國政府毛瑟槍合約，轉而推行可互換零件（interchangeable parts）與銑床，成為美國製造體系之父。棉花的暴利他沒賺到，制度性的後果卻由整個國家承受。

## 後果 -- 改變了什麼

- 美國南方棉花產量從1790年約3千包暴增至1860年約450萬包，棉花佔美國出口的一半以上，「棉花王國」（King Cotton）成形。
- 奴隸人口從1790年約70萬增至1860年約400萬，奴隸制非但未如建國一代預期般消亡，反而向西南（阿拉巴馬、密西西比、路易斯安那）擴張——惠特尼的機器成為奴隸制擴張的技術支柱，這是本案最深的弔詭。
- 棉花經濟加深南北經濟結構分裂，成為1830–1860年政治衝突（密蘇里妥協、堪薩斯內戰）的物質基礎，直通南北戰爭（1861–1865）。
- 惠特尼本人轉向武器製造，以可互換零件、標準化與分工（雖然史學界對其「可互換」宣稱有部分保留，實現者是後來的斯普林菲爾德兵工廠）奠定美國製造體系（American System of manufacturing）——一項發明開啟了兩條路：南方的奴隸種植園，北方的現代工廠。
