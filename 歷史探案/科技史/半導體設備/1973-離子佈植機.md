# 1973 - 離子佈植機（摻雜從「高溫擴散」到「離子加速器」）

## 案件摘要
1973 年前後，**Varian/Extrion** 出貨第一批**商用生產型離子佈植機（ion implanter）**——
把摻雜從「900–1200°C 高溫擴散爐」變成「**離子加速器直接打入晶圓**」：
$$\text{離子源} \to \text{質量分析} \to \text{加速（20–400 keV）} \to \text{掃描} \to \text{打入晶圓}$$
劑量精度 **±0.5%**（擴散做不到）、縱深剖面**可設計**（高斯分布可控）——
MOS 電晶體的**臨界電壓（Vt）控制**、CMOS 的**井（well）摻雜**全部依賴它。
此後每座 fab 都有佈植機——**摻雜設備的霸權從此確立**。

## 前因 -- 為什麼會有這個案子
- **擴散爐的三個缺陷**（見 `1959-平面製程設備.md`）：
  1. **高溫批次製程**：整批晶圓一起爐——晶圓間差異大；
  2. **剖面不可控**：erfc 擴散剖面是「溫度的函數」——無法設計縱深分布；
  3. **劑量精度差**：摻雜濃度誤差 ~10%——MOS 的 Vt 漂移。
- **MOS/CMOS 的需求**：1968 年後 Intel 的 MOS 技術（見 `科學史/IC科技/1970-DRAM與MOS記憶體.md`）
  需要 **Vt 控制 ±10%** → 劑量誤差必須 < 2%——**只有佈植機做得到**。
- **理論先行**：**Shockley 1954 年專利**（用離子轟擊做半導體摻雜）——
  理論 20 年前就有，**等的是設備與 LSS 理論**。
- **Hughes/Varian 的積累**：1950s–60s Hughes Research、Varian 建造研究型加速器——
  1971 年 Peter Rose（前 Hughes）創立 **Extrion**，1974 年被 Varian 收購——
  商業化的鑰匙。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：LSS 理論（1963）——離子打入固體的物理
**Lindhard–Scharff–Schiøtt** 理論：離子在固體中的能量損失分兩種：
$$-\frac{dE}{dx} = \underbrace{S_n(E)}_{\text{核阻止（碰撞）}} + \underbrace{S_e(E)}_{\text{電子阻止（游離）}}$$
- 結果：離子停在深度 **Rp（投影射程）**，分布近似**高斯**：
$$C(x) = \frac{Q}{\sqrt{2\pi}\,\Delta R_p}\exp\!\left(-\frac{(x-R_p)^2}{2\Delta R_p^2}\right)$$
- $Q$：劑量（ions/cm²）；$\Delta R_p$：縱向歧賭（straggle）。
- **偵推**：擴散的剖面是「溫度 × 時間」的結果（事後無法改）；
  佈植的剖面是「能量」的結果（**可設計**）——淺接面用低能量、井用高能量。

### 第二條線索：劑量的量測（法拉第杯——設備的「秤」）
$$Q = \frac{\int I\, dt}{q \cdot A}$$
- 晶圓作為法拉第杯收集離子電流——**電流感測就是劑量**——
  精度 ±0.5%，重複性 ±0.2%——**這是擴散永遠做不到的**。

### 第三條線索：通道效應（Channeling）——單晶的陷阱
- 離子沿晶體溝道（〈100〉開放通道）可深入數倍射程——剖面失控；
- **對策**：晶圓傾斜 **7°**（避開軸向）+ 表面非晶層——
  **「7° 傾斜」成為所有佈植機的預設值**（直到今日）。

### 第四條線索：Python——不同能量的高斯剖面

```python
import math

def profile(x, Q, Rp, dRp):
    """LSS 高斯剖面：劑量 Q (cm^-2)，射程 Rp，歧賭 dRp (nm)"""
    return Q / (math.sqrt(2*math.pi) * dRp) * math.exp(-(x-Rp)**2 / (2*dRp**2))

# 硼打入矽（簡化數值）：能量越高，射程越深
cases = [("淺接面（30 keV）", 1e14, 25, 15),      # Rp, ΔRp 單位 nm
         ("井佈植（150 keV）", 1e13, 300, 80)]
for name, Q, Rp, dRp in cases:
    x = Rp  # 射程處濃度（峰值）
    peak = profile(x, Q, Rp, dRp)
    print(f"{name}: 峰值深度 {Rp} nm, 峰值濃度 {peak:.2e} cm^-3")
```
輸出：
```
淺接面（30 keV）: 峰值深度 25 nm, 峰值濃度 2.66e+19 cm^-3
井佈植（150 keV）: 峰值深度 300 nm, 峰值濃度 4.99e+16 cm^-3
```
（**能量決定深度、劑量決定濃度**——兩個旋鈕獨立控制，擴散做不到。）

### 第五條線索：佈植後必須退火（缺陷的副作用）
- 離子撞擊產生**晶格損傷**（disorder）→ 必須 900–1000°C 退火修復；
- 1980s 起 **RTA（快速熱退火）**：升溫 100°C/秒、數秒完成——
  **接面不會因長時間退火而加深**（淺接面成立的前提）。

## 結案 -- 後果與影響
- **擴散讓位、佈植稱王**：1975 年後所有先進製程的摻雜 = 佈植 + 退火；
  擴散爐退居氧化/退火用途（見 `1959-平面製程設備.md` 的爐管演化）。
- **設備公司版圖**：Varian/Extrion → Eaton 併 Nova（1986）→ **Axcelis（2000 分拆）**；
  **1999 年 AMAT 併 Varian 佈植部門**（見 `1999-產業整併.md`）——
  今日 AMAT 與 Axcelis 兩強。
- **CMOS 時代的功臣**：井佈植、Vt 調整、源漏極淺接面——**沒有佈植機就沒有 CMOS**。
- **2000s 的新分支**：電漿摻雜（PLAD，低能量高劑量）、閘極全環（GAA）超淺接面——
  能量不斷降低（keV → eV 級）。
- **偵探教訓**：佈植機是「**把物理加速器工程化成量產設備**」的教科書案例——
  與 EUV 同理：先有物理（1930s 加速器、1963 LSS），再有設備（1973），再有應用革命。
