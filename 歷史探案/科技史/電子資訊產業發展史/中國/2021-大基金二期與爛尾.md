# 2021：大基金二期與「爛尾潮」 — 國家資本的教訓

## 案情

2019 年大基金二期成立（2,040 億人民幣），重點投向設備、材料「補短板」。但同期，全國 20+ 個地方晶圓廠項目爆出「**爛尾**」：武漢弘芯（千億投資爛尾、唯一一台光刻機被抵押）、濟南泉芯、成都格芯……**「地方豪賭晶片」成為 2021 年的行業笑話與國家痛點**。

## 前因

- 2018 後「晶片熱」——地方政府把晶圓廠當 GDP 政績。
- 大基金一期的成功刺激各地「晶片新城」衝動。
- 漢芯模式（2006）的變體：騙地方政府。

## 線索與推理

**爛尾潮的解剖——武漢弘芯案**：

| 騙局要素 | 內容 |
|---------|------|
| 「專家」 | 蔣尚義（台積電前 COO）被聘為 CEO（他本人也是受害者） |
| 「設備」 | 一台二手 ASML 光刻機，**抵押給銀行後始終未啟用** |
| 「資本」 | 註冊資本 1,530 億，實繳極少 |
| 結局 | 2021 年全面停工、政府接盤 |

**爛尾的共同公式**：

$$P_{爛尾} \propto \frac{\text{地方政府政績衝動}}{\text{技術與人才實力}} \times \frac{1}{\text{國家審查}}$$

**大基金二期與一期的差異**（回應爛尾潮）：

| | 一期（2014） | 二期（2019） |
|--|-------------|-------------|
| 方向 | 製造為主 | **設備、材料、EDA** |
| 治理 | 市場化選項目 | 更嚴格盡調、跟投 |
| 目標 | 產能 | **自主率** |

## 理論：軟預算約束（Soft Budget Constraint）

Kornai 的經典理論：國有/地方資本的虧損會被「救助」→ **缺乏紀律**。

$$\text{投資紀律} \propto \text{破產的真實性}$$

地方平台的「隱性擔保」→ 風險定價失真 → 爛尾潮。**解法**：2021 年後中央要求地方晶片項目「報備審查 + 風險自擔」。

## 後果

- 2021 年起爛尾項目清算，數千億資金蒸發——「**最貴的全民晶片課**」。
- 大基金高管腐敗案（2022）——國家資本的治理成本再曝光。
- 但同期真正的贏家浮現：北方華創、中微、滬硅、江豐——**大基金二期的標的長出了能力**。
- 歷史定位：爛尾潮證明「**國家資本需要國家紀律**」——大基金二期/三期的制度化正是回應。

## 冷案檔案

- 時間：2019–2021
- 案由：政績衝動 + 軟預算約束 = 千億爛尾
- 教訓：**半導體不接受「舉辦熱情」作為投入要素**。
