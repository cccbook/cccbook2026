# 1976：MITI「VLSI 計畫」 — 國家級半導體攻勢

## 案情

1976–1980 年，日本通產省（MITI）主導「超大型積體電路（VLSI）技術研究組合」，集結 NEC、東芝、日立、富士通、三菱五大廠，投入 720 億日圓（其中政府補助 40%），共同研發 DRAM 微影、蝕刻、矽晶圓技術。五年後，日本 DRAM 擊潰美國。

## 前因

- 1970 年代中期，美國（Intel、TI、Mostek）壟斷 DRAM。
- 日本廠商認為：DRAM 是「戰略物資」，必須國產化。
- 1973 年石油危機後，日本經濟轉向「知識密集型產業」。

## 線索與推理

**VLSI 計畫做了什麼？**

| 項目 | 內容 | 產出 |
|------|------|------|
| 聯合實驗室 | 五大廠互派研究員（日立中央研究所、NEC 基礎研究所） | 共享製程知識 |
| 設備研發 | 開發微影、蝕刻、晶圓設備 | 日本設備業起步（Tokyo Electron、Nikon） |
| 材料研發 | 矽晶圓、光阻、特用氣體 | 信越、SUMCO、JSR 崛起 |
| 專利共享 | 計畫內專利共同所有 | 免內耗 |

**為什麼美國做不到？** 反托拉斯法禁止美國競爭者共研（Sematech 1987 年靠立法豁免才成立——晚了 11 年）。

**效果驗證**：VLSI 計畫後日本 DRAM 良率與成本大幅改善：

$$Y_{日本} = e^{-D_{日本} \cdot A}, \quad D_{日本} < D_{美國}$$

日本晶圓廠的**無塵室等級、材料純度、作業員紀律**成為「品質神話」的微觀基礎。

## 理論：國家創新系統的「共同研發組合」

VLSI 計畫是「**研究組合（Research Consortium）**」的教科書：

```
政府（MITI）→ 補助 40% + 協調 + 專利池
五大廠 → 研發人力 + 資金
設備/材料廠 → 被培養成全球霸主
```

**與美國模式的對比**：

| | 日本 VLSI 計畫 | 美國 Sematech |
|--|---------------|---------------|
| 時間 | 1976 | 1987 |
| 主導 | 通產省 | 國防部 + 產業 |
| 結果 | 日本占 DRAM 80% | 美國維持先進製程 |

## 後果

- 1980 年代日本 DRAM 市占 80%（見 1981、1985 檔案）。
- 日本設備與材料業從此站穩全球（Nikon 微影、Tokyo Electron、信越化學、JSR）——**這是日本半導體「帝國遺產」**，直到 2020 年仍是美台的關鍵供應鏈。
- 副作用：1980 年代日本的集體行動讓美國反彈（見 1986 協定）。
- **伏筆**：VLSI 計畫讓日本習慣「政府協調 + 集體研發」——這在「突破性創新」上反而失效（見 1995、2009 檔案）。

## 冷案檔案

- 時間：1976–1980
- 案由：國家協調的成功案例（及其長期副作用）
- 教訓：政策能加速「追趕」，但無法替代「突破」。
