# 台灣電子資訊產業史 -- AI 偵探風格

以「推理探案」的方式，追查台灣電子資訊產業從美軍採購收音機、到筆電代工王國、IC 設計群雄、專業晶圓代工、先進封裝與 AI 供應鏈的每一步：
前因是什麼？線索在哪裡？推理如何展開？後果又如何改變了世界半導體版圖？

本書有**兩個核心謎題**：

1. **一個沒有天然資源、被殖民與戒嚴反覆塑造的小島，為什麼能成為全球電子硬體的中心？**
   推理的答案是：**地理＋人才＋政策設計＋「垂直分工」的商業模式創新**，四者在一條時序上恰好咬合。

2. **同一批人、同一個島——為什麼軟體產業輸給硬體那麼多？**
   推理的答案藏在「六角鎖」裡：市場小 × 盜版 × 標案文化 × 資本偏見 × 人才虹吸 × 政策錯配（見 [1997-軟體產業為何輸給硬體.md](1997-軟體產業為何輸給硬體.md)）。

$$\text{技術移轉} \xrightarrow{\text{公部門承擔風險}} \text{衍生公司} \xrightarrow{\text{垂直分工}} \text{代工/設計分離} \xrightarrow{\text{摩爾定律}} \text{贏者全拿}$$

台灣模式的本質是一條「風險遞移鏈」：政府先賭（工研院研發）、再移轉（衍生公司）、再由市場淘汰（股市與訂單）。每一次產業升級，都是一次風險從國家向市場的轉移。

## 推理主線總覽

1. **1964–1973**：外商來台組裝 → 人才與「電子工人階級」的養成
2. **1974–1979**：政府用公務預算賭半導體 → RCA 技術移轉 → 示範工廠
3. **1980–1989**：園區＋衍生公司 → 垂直分工（設計/製造/封測分離）誕生
4. **1990–1999**：代工模式擴散到電腦（筆電）、IC 設計群起
5. **1997**：平行線的答案——軟體為什麼沒有跟上（六角鎖）
6. **2000–2009**：兩兆雙星 → 部分成功（晶圓代工）、部分失敗（DRAM、面板）
7. **2010–2019**：智慧手機十年 → 台鏈內化於蘋果/安卓供應鏈
8. **2020–2026**：地緣政治 → 台積電成為戰略資產，先進封裝與 AI 接棒

## 為什麼是台灣？（偵探的最終推理）

| 變數 | 台灣 | 韓國 | 日本 | 中國 |
|------|------|------|------|------|
| 國家介入方式 | 研發承擔＋退出（衍生公司） | 財閥主導＋國家補貼 | 通產省指導＋財閥 | 國家直接操盤 |
| 商業模式創新 | **專業晶圓代工**（fabless–foundry 分工） | IDM 三星 | IDM（衰落） | IDM＋代工追趕 |
| 垂直分工深度 | 全世界最深 | 中（財閥內部） | 低 | 追趕中 |
| 人才機制 | 留美回流＋工研院 | 留美回流＋三星內訓 | 本土培養 | 海歸＋規模 |
| 結果 | fabless/foundry 雙中心 | IDM 強權 | 逐步退出 | 追趕者 |
