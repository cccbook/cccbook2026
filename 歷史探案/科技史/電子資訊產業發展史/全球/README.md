# 全球電子資訊產業史 -- AI 偵探風格

以「推理探案」的方式，追查全球電子資訊產業從伏打電堆、愛迪生的電力帝國、真空管與電晶體、積體電路與摩爾定律、個人電腦與軟體產業、網際網路、行動通訊，到 AI 晶片時代的每一步：
前因是什麼？線索在哪裡？推理如何展開？後果又如何重塑了世界？

核心謎題只有一個：**從一節銅鋅電池到 3nm 晶片與 ChatGPT，人類是如何把「電」變成「資訊」，再把「資訊」變成全球最大的產業？**

推理的答案是：**能量 → 訊號 → 開關 → 邏輯 → 計算 → 網路 → 智慧**，每一次躍遷都依賴一個「新的最小單位」——
電荷（伏打）、電磁波（馬克士威）、真空管（佛萊明/德福雷斯特）、電晶體（貝爾實驗室）、積體電路（Kilby/Noyce）、微處理器（Intel）、封包（ARPANET）、App 與雲（Apple/Amazon）、神經網路權重（深度學習）。

$$\text{能量} \to \text{訊號} \to \text{開關} \to \text{邏輯} \to \text{計算} \to \text{網路} \to \text{智慧}$$

而貫穿全局的推進引擎只有一條定律：**摩爾定律**——每 18~24 個月，電晶體密度翻倍、單位運算成本減半。它是物理定律嗎？不是。它是**自我實現的產業預言**，是一場持續六十年的集體賭注。

## 本書的破案方法

每篇檔案皆為一樁「科技懸案」，固定六段結構：

| 章節 | 推理角色 |
|------|----------|
| 案情 | 案發現場：誰、何時、做了什麼 |
| 前因 | 動機與背景：為什麼是「此時此地此人」 |
| 線索與推理 | 偵探分析：決策邏輯、關鍵抉擇、被忽略的細節 |
| 理論 | 法醫報告：數學公式、工程理論、經濟模型 |
| 後果 | 連鎖效應：此案如何改寫產業版圖 |
| 冷案檔案 | 結案陳詞：歷史定位 |

## 貫穿全書的三條暗線

1. **成本的指數崩落**：從電報每字元的昂貴，到每 GB 儲存、每 FLOP 運算成本的自由落體。
2. **分工的持續深化**：IDM → fabless/代工分離 → 封測獨立 → chiplet 異質整合——價值鏈不斷切片。
3. **通訊與計算的螺旋**：電報→電話→無線電→蜂巢→網際網路→行動上網→物聯網，每次通訊革命都為計算產業創造新市場，反之亦然。
