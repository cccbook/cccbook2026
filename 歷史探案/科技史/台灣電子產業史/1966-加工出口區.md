# 1966：高雄加工出口區成立 — 「全球分工」的原始實驗場

## 案情

1966 年 12 月，全球第一個加工出口區（Export Processing Zone, EPZ）在高雄楠梓誕生。這是一個被法律「圈出來」的自由貿易飛地：區內原料免稅進口、產品全數外銷。

## 前因

- 1950 年代台灣以「進口替代」工業化，但島內市場太小，外匯見底。
- 1958–1961 年尹仲容主導「外匯貿易改革」，把匯率貶到反映真實成本。
- 美國 1965 年結束對台經濟援助——台灣必須「自己養自己」。

## 線索與推理

**為什麼需要「區」而不直接全島開放？** 答案是政治經濟學的：

| 全島開放 | 設加工出口區 |
|---------|-------------|
| 動搖保護主義者利益 | 既有產業不受威脅 |
| 需修數十種法規 | 單一法規（《加工出口區設置管理條例》）一次解決 |
| 外商怕官僚刁難 | 區內管理處「一站式」服務（一個窗口搞定簽證、報關、外匯） |

這是「**改革飛地理論**」：在舊體制旁建一個新體制，讓新舊制度競爭，倒逼全面改革。深圳特區 1980 年的做法，明顯師法高雄。

**經濟學本體**：加工出口區解決的是發展經濟學的「Leatherby 綁架問題」——開發中國家即使勞動力便宜，也因為**基礎設施、行政摩擦、關稅**而實際成本不低。用數學表示：

$$C_{real} = w + \underbrace{c_{infra}}_{降低} + \underbrace{c_{admin}}_{單一窗口} + \underbrace{t_{tariff}}_{歸零}$$

把後三項壓到趨近於零，台灣的 w（工資）優勢才真正兌現。

## 理論：比較利益與出口導向工業化

李嘉圖比較利益：即使台灣在所有工序都「較差」，只要**相對成本差**存在，專業化代工仍可獲利。高雄 EPZ 是李嘉圖理論在制度設計上的第一次完整實作。

```
1958 外匯改革 → 匯率真實化
1960 獎勵投資條例 → 租稅誘因
1966 加工出口區 → 物理載體
（三件套 = 台灣出口奇蹟的制度基礎）
```

## 後果

- 1971 年楠梓、台中加工出口區相繼設立，電子業占區內產值一半以上。
- 培養數十萬電子組裝工人——台灣後來 IC 產業的技術員、領班，都從這批人及其子女而來。
- 「前店後廠」模式成形：外商接單在美，製造在台。1980 年代資訊硬體業是這模式的放大版。
- 世界銀行後來把 EPZ 當作發展藥方推薦給數十國，但成功率極低——關鍵差異在於台灣有（1）工程人才供給（2）之後的技術升級政策。**園區只是容器，內容物是人才**。

## 冷案檔案

- 時間：1966 年 12 月
- 地點：高雄前鎮（第一個）、楠梓（1971）
- 案由：全球首創的出口導向制度實驗
- 教訓：制度創新可以像技術一樣被「設計」，但需要配套的人力資本政策才有長期效果。
