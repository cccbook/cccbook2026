# 2009：金融海嘯與 DRAM 雙 D 慘案 — 記憶體週期律的數學教訓

## 案情

2008–2009 年金融海嘯，DRAM 與面板（俗稱「雙 D」：DRAM & Display）雙雙崩盤。力晶、茂德、南亞科、華亞科陷入巨額虧損，台灣政府動用國安基金規格的紓困，仍無法阻止產業全面重整——這是台灣產業政策史上最昂貴的失敗。

## 前因

- 1994–2008 年台灣先後投入 DRAM 的公司：力晶、茂德、南亞科、華亞科、世界先進、華邦、茂矽……
- 每家都是「技術授權 + 資本擴產」模式（見 1994 檔案）。
- 2008 年 DRAM 價格暴跌 90%（1Gb DDR2 從 6 美元跌到 0.6 美元）。

## 線索與推理

**為什麼 2008 年特別慘？** 三重打擊同時落下：

1. **需求崩潰**：全球金融海嘯，PC 需求急凍。
2. **供給過剩**：2007–2008 年全球 DRAM 擴產（三星、海力士、奇夢達、爾必達、台灣多家）同時開出。
3. **製程轉換**：70nm→50nm 轉換期，台灣廠（靠授權）轉換慢，成本高於對手。

**成本結構的數學**：

$$C_{台灣} = C_{設備折舊} + C_{技術授權} + C_{管理}$$
$$C_{三星} = C_{設備折舊} + C_{自研攤提} + C_{管理}$$

三星自研攤提 $< $ 技術授權費，且三星規模最大 → $AC_{三星} < AC_{台灣}$。

當市場價格 $P$ 跌到：
$$P < AC_{台灣} < AC_{三星}$$

三星仍然獲利（或小虧），台灣每片晶圓都在流血。

**政府紓困的博弈論困境**：

```
政府紓困 → 產能不退出 → 價格繼續低 → 產業繼續虧 → 需要更多紓困
政府不紓困 → 公司倒 → 銀行呆帳 → 金融風險
```

兩難的根源：**紓困救得了公司，救不了產業結構**。台灣最終選擇紓困（2009–2010），代價是數千億的銀行呆帳與股東損失。

## 理論：蛛網模型的「殺死版本」

見 1989、1994 檔案。2008 年是蛛網模型加上「**規模經濟殺人**」的完美風暴：

$$\text{存活者} = \text{成本最低者} \times \text{資本最雄厚者}$$

這個法則在 1996、2001、2008、2016 年的每個 DRAM 週期都重演——台灣每次都以「再一輪投資就能翻身」的信念進場，每次都輸。

## 後果

- 力晶 2012 年下市重整（後轉型代工，2021 年重新上市）。
- 茂德、茂矽倒閉；華亞科 2016 年被美光收購；南亞科縮編。
- 台灣 DRAM 產業整體虧損超過一兆台幣——「雙 D 慘案」成為台灣產業政策的最大教訓。
- 政策轉向：政府此後明確「不救商品化產業」，半導體資源集中到邏輯代工與 IC 設計。
- 副產品：力晶、南亞科的**人才**流向 IC 設計與代工——DRAD 陣亡者的能力被其他產業吸收。

## 冷案檔案

- 時間：2008–2012
- 案由：商品化 + 資本密集 + 技術依賴 = 必敗結構
- 最終推理：**台灣的正確選擇不是 DRAM，是邏輯代工**——張忠謀 1987 年的判斷，用一兆台幣的學費再次驗證。
