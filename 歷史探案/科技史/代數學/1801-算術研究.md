# 1801 - 算術研究

## 案件摘要
1801 年，24 歲的高斯出版《算術研究》（*Disquisitiones Arithmeticae*），發明同餘記法 $a \equiv b \pmod n$，證明二次互反律，並以分圓理論解出正十七邊形作圖。整數論從零散結果變成有結構、有記號的體系，並意外成為現代密碼學的基石。

## 前因 -- 為什麼會有這個案子
- **數論的記號荒漠**：Fermat、Euler、Lagrange 留下大量漂亮定理（費馬小定理、二次剩餘的觀察），但敘述全靠文字，缺少統一的運算語言，難以系統推廣。
- **二次互反律的懸案**：Euler (1783)、Legendre (1785) 觀察到「$p$ 是否為 $q$ 的二次剩餘」與反方向有神秘對稱關係，Legendre 給出符號 $(\frac{p}{q})$ 但證明不完整。高斯稱之為「黃金定理」，1796 年（19 歲）率先完成證明。
- **正多邊形作圖的千年懸案**：自古希臘以來，人們只會用尺規作正 $3, 4, 5, 6, 15$ 邊形；哪些邊數可作圖是懸而未決的問題。
- **高斯的積累**：1795–1798 年間高斯在 Göttingen 大量計算與思考，將數論重組為演繹體系。

## 線索與推理 -- 數學式、程式、理論

### 線索一：同餘記法的發明
高斯定義並發明記號：

$$a \equiv b \pmod n \quad\Longleftrightarrow\quad n \mid (a - b)$$

即 $a, b$ 除以 $n$ 的餘數相同。他同時確立剩餘類的概念：模 $n$ 的全體整數劃分為 $n$ 個類 $\mathbb{Z}/n\mathbb{Z} = \{[0], [1], \dots, [n-1]\}$，且類之間可做加法與乘法。

**推理核心**：有了記號，模算術成為「可操作的代數」——
- 費馬小定理：$a^{p-1} \equiv 1 \pmod p$（$p$ 質數、$p \nmid a$）
- Euler 定理：$a^{\varphi(n)} \equiv 1 \pmod n$（$\gcd(a,n)=1$）

這套語言直接孕育了 19 世紀的群論（$\mathbb{Z}/n\mathbb{Z}$ 是循環群的範例）與環論。

### 線索二：二次互反律
定義 Legendre 符號 $(\frac{a}{p}) = +1$（$a$ 是模奇質數 $p$ 的二次剩餘）、$-1$（非剩餘）、$0$（$p \mid a$）。高斯證明的**黃金定理**：

$$\left(\frac{p}{q}\right)\left(\frac{q}{p}\right) = (-1)^{\frac{p-1}{2}\,\frac{q-1}{2}} \qquad (p, q \text{ 為奇質數})$$

即：$p \equiv q \equiv 3 \pmod 4$ 時兩方向「相反」，其餘情況「相同」。配上補充公式 $\left(\frac{-1}{p}\right) = (-1)^{\frac{p-1}{2}}$、$\left(\frac{2}{p}\right) = (-1)^{\frac{p^2-1}{8}}$，任何二次剩餘問題都可機械判定。高斯一生給出 8 種證明；此律日後被推廣為 Artin 互反律，成為類域論的心臟。

### 線索三：分圓方程與正十七邊形作圖
《算術研究》第七節研究二項方程 $x^n - 1 = 0$ 的分圓理論。設 $\zeta = e^{2\pi i/n}$，其根為 $1, \zeta, \zeta^2, \dots, \zeta^{n-1}$；高斯證明 $\varphi(n)$ 次的「分圓多項式」可進一步分解，並得出：

**尺規可作圖判準**：正 $n$ 邊形可用尺規作圖 $\iff$ $n = 2^k \, p_1 p_2 \cdots p_m$，其中 $p_i$ 為相異的**費馬質數**（形如 $2^{2^r}+1$）。

**17 的推理**：$17 = 2^{2^2}+1$ 是費馬質數，故正十七邊形可作圖。高斯 1796 年發現此事，視為畢生傑作，遺願將其刻於墓碑（石刻工匠最終只刻了正 17 角星）。作圖核心是構造「週期」：

$$\sum_{j=0}^{15} \zeta^{g^j} = -1, \quad \zeta = e^{2\pi i/17}$$

並逐層以平方根解出（17−1 = 16 = $2^4$，恰好四層二次擴張）。

### 線索四：模運算成為密碼學基礎（RSA）
高斯的語言在兩千年後成為網路安全的地基。RSA（Rivest–Shamir–Adleman, 1977）：
1. 取大質數 $p, q$，$n = pq$，$\varphi(n) = (p-1)(q-1)$。
2. 取 $e$ 與 $\varphi(n)$ 互質，$d \equiv e^{-1} \pmod{\varphi(n)}$。
3. 加密 $c \equiv m^e \pmod n$；解密 $m \equiv c^d \pmod n$。
其安全性依賴「由 $n$ 分解 $p, q$ 之難」——正是同餘與質數理論的直接應用。

### 線索五：Python 實作模運算與二次互反律驗證

```python
from itertools import product

def legendre(a, p):                    # p 為奇質數
    a %= p
    if a == 0: return 0
    sq = {x*x % p for x in range(1, p)}
    return 1 if a in sq else -1

def reciprocity(p, q):                 # 驗證二次互反律
    lhs = legendre(p, q) * legendre(q, p)
    rhs = (-1) ** ((p-1)//2 * (q-1)//2)
    return lhs, rhs

primes = [3, 5, 7, 11, 13, 17, 19, 23]
for p, q in product(primes, primes):
    if p < q:
        lhs, rhs = reciprocity(p, q)
        assert lhs == rhs, f"違反互反律: p={p}, q={q}"
print("二次互反律: 所有奇質數對驗證通過")

# 模運算 / 費馬小定理 / RSA 小例
p = 13
assert all(pow(a, p-1, p) == 1 for a in range(2, p))   # 費馬小定理
n, e, m = 5*11, 3, 7
d = pow(e, -1, (5-1)*(11-1))          # 模反元素
c = pow(m, e, n)
print("RSA: 密文 =", c, " 解密 =", pow(c, d, n), " 原文 =", m)
```

輸出確認互反律對所有質數對成立，且 RSA 小例中解密還原出原文——高斯的記號在 220 年後仍是加密網路的骨架。

## 結案 -- 後果與影響
- **結案陳詞**：數論獲得統一記號與演繹結構；二次互反律定讞，正十七邊形作圖之謎破解。
- **催生抽象代數**：$\mathbb{Z}/n\mathbb{Z}$ 的剩餘類是群、環理論的原型；Galois 理論與分圓理論一脈相承。
- **密碼學革命**：同餘、質數、模反元素成為 RSA、Diffie–Hellman、橢圓曲線密碼的核心。
- **作圖的推廣**：尺規可作圖判準連結代數（二次擴張）與幾何，是 Galois 理論的前奏；1832 年高斯學生 Richelot 完成正 257 邊形作圖。

## 關鍵人物與文獻
- Carl Friedrich Gauss, *Disquisitiones Arithmeticae* (Leipzig, 1801)
- Euler (1783)、Legendre (1785) — 二次互反律的先驅觀察與不完整證明
- Fermat 質數 $2^{2^r}+1$ — 正多邊形作圖判準的關鍵
- Rivest, Shamir, Adleman (1977) — RSA，高斯遺產的現代繼承者
