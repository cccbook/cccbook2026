# 1950-區域提純與單晶生長

## 案件摘要
電晶體發明後，兇手找到了，但「證物」——半導體材料——卻滿是雜質、晶界叢生。1950 年代，Czochralski 拉晶法與 Pfann 的區域熔煉聯手破案，將鍺與矽提純到 9N（99.9999999%）並拉出完美單晶，為積體電路備齊了乾淨的犯罪現場。

## 前因 -- 為什麼會有這個案子
- **純度的殘酷要求**：半導體對雜質極度敏感。摻雜濃度 $10^{15}\,\mathrm{cm^{-3}}$ 就能主導導電行為，而原子密度約 $5\times10^{22}\,\mathrm{cm^{-3}}$，故雜質須低於 **$10^{-7}$ 量級——即 9N（99.9999999%）純度**，遠超冶金級原料（僅 ~99%）。
- **雜質是污染源**：晶界、差排、金屬沾污會載子捕獲、降低少數載子壽命 $\tau$，使電晶體增益 $\beta$ 崩落。
- **單晶是必要條件**：多晶材料中晶界阻礙載子輸遷，元件需大面積無缺陷單晶作為基板。

## 線索與推理 -- 數學式、程式、理論

### 線索一：Czochralski 柴氏法（1916）
波蘭科學家 Jan Czochralski 1916 年偶然發現：將晶種浸入熔融液再緩慢上拉，可拉出單晶。電晶體發明後，Teal 與 Little 在 Bell Labs 將此法用於鍺（1950）與矽（1952）。

流程：
1. 多晶料在石英坩堝中熔化（矽熔點 1414 °C）。
2. 晶種（seed）接觸熔面，控制溫度使界面僅部分熔解。
3. 緩慢上拉（~mm/min）並旋轉，長成圓柱狀單晶錠（ingot）。
4. 直徑由拉速與溫度梯度控制，今日可達 300 mm。

### 線索二：區域熔煉（zone refining, Pfann 1952）
Bell Labs 的 William Pfann 發現雜質在液相與固相中的溶解度不同，定義**偏析係數**：

$$k_0 = \frac{C_s}{C_l}$$

對鍺中多數雜質 $k_0 < 1$（如銅 $k_0 \approx 10^{-5}$），雜質偏愛待在液相。於是：讓一個熔融窄帶沿著錠**反覆單向掃過**，雜質便被「掃」向錠尾。

多次通過後，距起端 $x$ 處的雜質濃度（單次通過、區長 $L$）：

$$\frac{C_s(x)}{C_0} = 1 - (1 - k_0)\, e^{-k_0 x / L}$$

**懸浮區熔（float zone, FZ）**：不用坩堝，靠表面張力與射頻感應加熱懸浮熔區垂直通過多晶棒——避免石英坩堝帶來的氧沾污，可得最高純度，多用於功率元件與高阻矽。

### 線索三：矽 vs 鍺的選擇
| 特性 | 鍺 (Ge) | 矽 (Si) |
|---|---|---|
| 能隙 $E_g$ | 0.67 eV | 1.12 eV |
| 熔點 | 937 °C（易提純） | 1414 °C |
| 逆偏漏電流 | 大（能隙小） | 小 |
| 表面氧化膜 | 無穩定氧化層 | SiO2 天然鈍化 |

鍺因熔點低、易提純而贏得第一戰（1947 電晶體是鍺做的）；但矽能隙大、漏電流小、且有 SiO2 保護層，終成量產霸主——這條線索直接連向 1959 平面製程。

### 線索四：晶圓製作流程
1. 長晶（CZ 或 FZ）→ 單晶錠。
2. 切邊（晶向標記）→ 切片（diamond saw，厚度 ~0.5–0.8 mm）。
3. 研磨（lapping）→ 化學機械拋光（CMP）至鏡面。
4. 清洗（RCA clean）→ 檢驗包裝，即為晶圓（wafer）。

### Python 模擬：區域熔煉的雜質分佈

```python
import numpy as np
import matplotlib.pyplot as plt

C0, k0, L, N = 1.0, 0.1, 0.1, 10   # 原始濃度、偏析係數、區長、通過次數
x = np.linspace(0, 1, 500)

C = np.ones_like(x) * C0
for _ in range(N):
    Cn = C.copy()
    # 逐段掃過：區間內固相濃度重新結晶
    for xi in x[:-1]:
        seg = (x >= xi) & (x < xi + L)
        Cs = C[(seg)].mean()  # 局部液相平均濃度
        Cn[seg] = 1 - (1 - k0) * np.exp(-k0 * (x[seg] - xi) / L) * Cs
    C = Cn

plt.plot(x, C / C0, lw=2)
plt.yscale("log")
plt.xlabel("Position along ingot x (normalized)")
plt.ylabel("C / C0")
plt.title(f"Zone Refining, k0={k0}, {N} passes")
plt.grid(True)
plt.show()
```

模擬顯示：起端 80% 區段的雜質被壓低數個數量級，尾端濃度飆升——「截去尾部即得超純材料」，與 Pfann 的實驗完全一致。

## 結案 -- 後果與影響
- 9N 級高純矽/鍺 + 大單晶問世，電晶體從實驗室珍品變成可設計、可重製的工程元件。
- 1954 年 Teal 在 TI 用柴氏矽單晶做出矽電晶體，宣告矽時代來臨。
- 區域提純技術至今仍用於 FZ 矽（高壓、射頻、探測器元件），柴氏法則是 90% 以上 IC 晶圓的來源。
- 「乾淨的基板」使日後的積體電路（1958）與平面製程（1959）得以在可信的材料上施工——證物齊備，全案可結。
