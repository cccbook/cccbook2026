# 1990s - CMP 化學機械研磨：讓晶圓回到平原的偵探行動

## 案件摘要
1990 年前後，IBM 悄悄把一項老技藝——玻璃研磨——搬進半導體量產線，用「化學腐蝕＋機械研磨」協同作用把晶圓表面磨回平原，這就是 **CMP（Chemical Mechanical Planarization/Polishing）**。
1990 年代它從內部機密變成多層金屬互連的必備製程：沒有 CMP，金屬層堆不上去、銅 damascene 做不出來、STI 隔離也無法量產。
這是晶片史上少見「用機械力量對抗微米高低差」的案件，靈魂卻是一條 1952 年的經驗公式。

## 前因 -- 為什麼會有這個案子
- **多層互連的罩門**：元件做得越小，連線延遲越主導，設計者只能往上加金屬層；但每疊一層，下層的金屬線與介電層就累積新的**表面起伏（topography）**。
- **step coverage 惡化**：金屬層數一多，沉積在高低起伏上的薄膜厚度不均、斷線風險上升；上一層的光刻景深 **DOF（Depth of Focus）** 容不下高低差——
  
  $$\mathrm{DOF} \approx k_2 \frac{\lambda}{NA^2}$$
  
  微影進入次微米後 DOF 只有零點幾微米，整片晶圓「平原」不到這個程度，圖案就會整片失焦。
- **化學拋光救不了、機械磨也救不了**：僅用濕式蝕刻會等向性腐蝕、越磨越糟；僅用機械研磨則刮傷脆弱的薄膜。關鍵推理：必須**化學軟化＋機械移除協同**，讓「軟化的表層被溫和磨掉」，兩者缺一不可。
- **IBM 的動機**：1990 年前後 IBM 決定衝多層互連與後來的銅製程，內部率先把 CMP 導入量產，並建立 pattern density、dummy fill 等配套理論。

## 線索與推理 -- 數學式、程式、理論

### 線索一：Preston 方程式（1952）——研磨速度的經典公式
玻璃研磨老將 F. W. Preston 在 1927 年提出、1952 年定型的經驗律：材料移除率正比於**壓力**乘以**相對速度**：

$$\frac{dT}{dt} = K \cdot P \cdot v$$

其中 $T$ 為移除厚度（nm）、$P$ 為晶圓所受壓力（psi 或 Pa）、$v$ 為晶圓與研磨墊的相對速度（m/s）、$K$ 為 Preston 常數（製程與漿料決定）。
積分後固定壓力與轉速，移除厚度與時間成正比——量產線因此可以精準「磨掉多少微米」：

$$\Delta T = K\, P\, v\, t$$

### 線索二：CMP 機台現場——化學與機械的雙人舞
晶圓正面朝下貼在**carrier**上，倒扣壓在旋轉的 **polyurethane pad** 上；漿料（slurry）含氧化矽或氧化鋁磨粒與鹼性/酸性腐蝕液，不斷注入墊面。

```
     carrier（晶圓吸住、旋轉）
        │  壓力 P
        ▼
   ═══ 晶圓（正面朝下）═══
   ─────────────────────
     polyurethane pad（旋轉、彈性）
     ↑ slurry：磨粒 + 腐蝕劑
   [旋轉平台 platen]
```

化學劑把表層軟化或氧化，磨粒再把軟化層機械刮除；高點同時承受「化學＋機械」雙重作用、低點只受化學腐蝕——平原化就此發生。

### 線索三：dishing 與 erosion——平原化的兩個陷阱
CMP 不是完美平原。圖案化晶圓上有兩種缺陷：
- **dishing（碟陷）**：寬金屬線或大開口中間被磨得比邊緣低，因研磨墊彈性下陷擠進開口。
- **erosion（侵蝕）**：高密度圖案區（如密集的線）整體被過度研磨，因漿料在此區滯留量較大。

簡化模型：圖案區域的過磨量隨 **pattern density** 上升，dishing 隨開口寬度增大。以經驗式描述：

$$\text{erosion} \propto \rho_{\text{pattern}} \cdot \Delta T, \qquad \text{dishing} \propto w_{\text{open}} \cdot P$$

其中 $\rho_{\text{pattern}}$ 為局部圖案密度、$w_{\text{open}}$ 為開口寬度。解法是 **dummy fill（假填充）**：在不通電的區域塞入假金屬，把整片晶圓的局部密度拉平，讓 CMP 磨出接近全域平坦的表面。

### 線索四：pattern density 的移除模型——為什麼要 dummy fill
真實晶圓不是均勻平面，CMP 移除率隨**局部圖案密度**變化。經典的密度修正模型把 Preston 方程式改寫為：

$$\frac{dT}{dt} = K \cdot P \cdot v \cdot f(\rho), \qquad f(\rho) = \frac{1}{1 + \alpha\,\rho}$$

其中 $\rho$ 為局部圖案密度（0–1）、$\alpha$ 為製程參數。密度高的區域漿料滯留量大、有效壓力被分散，移除反而變快，造成 erosion。
工程解法是 **dummy fill**：把整片晶圓切成分塊（tile），在每塊內塞入不通電的假金屬，讓每塊密度 $\rho_i$ 收斂到全域平均：

$$\rho_i \longrightarrow \bar{\rho} = \frac{A_{\text{metal}}}{A_{\text{tile}}}$$

這也成為 EDA 實體設計的新任務——fill 插入（fill insertion）自此列入標準流程，與 CMP 製程綁定。

### 線索五：終點偵測（endpoint detection）——磨到哪裡停？
CMP 最大的工程難題是**何時停磨**：磨太少平原化不足、磨太多則 dishing/erosion 惡化。三種手段：
- **馬達電流偵測**：磨穿不同材料時摩擦力改變，主軸馬達電流出現階梯訊號——最量產化的方法。
- **光學反射偵測**：以雷射照晶圓背面，反射率隨下層材料（如 Si3N4、TaN）露頭而改變。
- **固定過磨（fixed over-polish）**：預估磨穿時間後再多磨固定秒數，靠 dummy fill 把過磨傷害壓到可接受。

STI 以 Si3N4/SiO2 的高選擇比（stop layer）做天然終點，damascene 則以 TaN 障礙層為停點——選擇比是 CMP 終點的護身符。

### 線索六：STI 與 damascene——CMP 的兩大舞台
- **STI（Shallow Trench Isolation）**：1990 年代以 CMP 做元件隔離，取代 LOCOS。流程：以硬罩蝕刻出淺溝槽 → 填入 SiO2 → **CMP 磨掉多餘氧化層、停在氮化矽上**（以 Si3N4/SiO2 選擇比做終點偵測）→ 平坦的主動區就此誕生。
- **銅 damascene（1997 IBM）**：先蝕刻溝槽 → 填入障礙層/TaN → 電鍍銅把溝槽**全部填滿並溢出** → **CMP 磨掉溢出的銅、停在障礙層上**。銅不能用電漿蝕刻（無揮發性氯化物），**蝕刻不可行，CMP 是 damascene 的靈魂**——沒有 CMP 就沒有銅互連。

兩大舞台的製程流程對照：

```
STI：  淺溝槽蝕刻 → [填入 SiO2] → CMP（停在 Si3N4） → 平坦隔離
Damascene：溝槽蝕刻 → [障礙層 TaN] → [電鍍銅（溢出）] → CMP（停在 TaN） → 銅互連
```

共通哲學：**「先填滿、再磨平」**——傳統減法製程（沉積後蝕刻）在此失效，CMP 的加法＋研磨範式改寫了互連與隔離的製作方式。

### Python 實作：Preston 方程式研磨計算與 dishing 模擬

```python
# Preston 方程式：dT/dt = K·P·v；給定壓力、轉速、時間算移除厚度
def preston_removal(K, P, rpm, r_wafer, t_min):
    v = 2 * 3.141592653589793 * (rpm / 60.0) * r_wafer   # 相對速度 m/s（線速度）
    return K * P * v * t_min * 60.0 * 1e9                 # ΔT，nm
# IBM 典型條件：K ≈ 1e-13 m²/N（經驗值）、P = 4 psi ≈ 27579 Pa
# 晶圓半徑 100 mm（線速度取最外緣）、研磨 60 秒
dt = preston_removal(1e-13, 27579, 100, 0.1, 60)
print(f"移除厚度 ΔT ≈ {dt:.0f} nm（{dt/1000:.2f} μm）")
# 預期輸出：移除厚度 ΔT ≈ 10397 nm（10.40 μm）

# 密度修正模型：dT/dt = K·P·v·f(ρ)，f(ρ) = 1/(1 + α·ρ)
def removal_with_density(K, P, v, rho, alpha=1.0, t_min=60.0):
    return K * P * v * t_min * 60.0 * 1e9 / (1 + alpha * rho)   # ΔT，nm

for rho in (0.0, 0.3, 0.7):
    d = removal_with_density(1e-13, 27579, 0.628, rho)    # v = 0.628 m/s（100 rpm, r=60mm）
    print(f"密度 ρ = {rho:.1f} → ΔT ≈ {d:.0f} nm")
# 預期輸出：密度 ρ = 0.0 → ΔT ≈ 6240 nm
#           密度 ρ = 0.3 → ΔT ≈ 4800 nm
#           密度 ρ = 0.7 → ΔT ≈ 3670 nm

# 簡化 dishing 模擬：dishing 隨開口寬度增大（彈性研磨墊擠進開口）
import numpy as np
w = np.linspace(0.1, 10, 100)            # 開口寬度 μm
dishing = 30 * np.log1p(w) / np.log1p(10)  # 經驗式：對數飽和成長，最大約 30 nm
print(f"開口 0.1 μm → dishing ≈ {dishing[0]:.1f} nm")
print(f"開口 10  μm → dishing ≈ {dishing[-1]:.1f} nm")
# 預期輸出：開口 0.1 μm → dishing ≈ 1.2 nm
#           開口 10  μm → dishing ≈ 30.0 nm
```

模擬顯示：Preston 方程式讓移除厚度可由壓力、轉速、時間三個機台參數直接換算，量產線因此能精準控制「磨掉一層微米級薄膜」；而 dishing 隨開口寬度對數成長——寬金屬線必須靠 dummy fill 與更硬的研磨墊來抑制。

## 結案 -- 後果與影響
- **多層互連成為可能**：6 層以上金屬互連在 1990 年代後期量產，摩爾定律的「往上蓋樓」路線從此暢通——每疊一層都必須先 CMP。
- **damascene 銅製程的基礎**：1997 年 IBM 推出銅互連量產製程，CMP 是整條流程的核心工序；銅從「不能蝕刻的死路」變成「填滿再磨平的活路」。
- **STI 取代 LOCOS**：元件隔離從鳥嘴突出的局部氧化，變成溝槽填入＋CMP 磨平的平坦結構，主動區面積利用率大增。
- **至今每層金屬都要 CMP**：先進製程每層金屬與介電層之間都要平原化，CMP 從 1990 年代的「新招」變成晶圓廠的基本功。
- **設備要角誕生**：化學機械研磨機成為晶圓廠最貴的設備之一，Applied Materials、Ebara 成為此一市場的要角；終點偵測、漿料化學、研磨墊壽命成為新的學問。
- **跨領域的偵探教訓**：本案的破案關鍵不在半導體，而在玻璃研磨的百年工藝——$R = K \cdot P \cdot v$ 這條 1952 年的經驗公式，四十年後救了整個摩爾定律。
