# 1907 - 等效原理（通往廣義相對論的門票）

## 案件摘要
1907 年 11 月，Einstein 在專利局坐著時靈光一閃，自稱「一生中最快樂的思想」：
一個自由落體的人感覺不到自己的重量。
重力與加速度可以被互相抵銷——若徹底追究，重力也許根本不是「力」，而是時空的幾何。廣義相對論的大門由此打開。

## 前因 -- 為什麼會有這個案子
- **狹義相對論的限制**：1905 理論只適用於慣性系，且與 Newton 重力 $F = GMm/r^2$（瞬時超距作用）不相容——重力違反光速極限。
- **Newton 的舊懸案**：為何「重力質量」與「慣性質量」恰好相等？Newton 自己只驗證到 $10^{-3}$ 精度，把巧合留給後人。
- **Galileo 的落體實驗**：所有物體以相同加速度下落——這個「巧合」正是本案最古老的線索。
- **Einstein 的偵探直覺**：若兩種質量本質相同，則重力場與加速座標系在局部完全不可區分——重力可被「幾何化」。

## 線索與推理 -- 數學式、程式、理論

### 「最快樂的思想」（電梯思想實驗）
- 封閉電梯自由落體：內部的人飄浮，感覺不到重力——重力被加速度「消滅」。
- 封閉電梯在無重力太空中以 $g = 9.8$ m/s² 加速：內部的人被壓向地板，與站在地球表面**完全無法區分**。
- **結論**：在足夠小的時空區域內，重力場與加速參考系物理等效。這就是**等效原理**。

### 等效原理與兩種質量
$$m_{\text{inertial}} = m_{\text{gravitational}}$$
- 慣性質量：$F = m_{\text{inertial}}\,a$ 中的 $m$。
- 重力質量：$F = G\frac{M m_{\text{gravitational}}}{r^2}$ 中的 $m$。
- 由等效原理，自由落體加速度 $a = GM/r^2$ 與落體本身無關——Galileo 的觀察由此獲得理論解釋。

### Eötvös 實驗（扭秤實驗）
Eötvös (1885–1909) 用扭秤比較不同材料的重力加速度與離心加速度比值：
$$\eta(A, B) = 2\,\frac{|a_A - a_B|}{a_A + a_B} < 5\times10^{-9} \;(1909)$$
材料（木材、鉑、石棉等）的兩種質量在 $10^{-9}$ 精度內相等——本案最強的實驗鐵證。
後續：Dicke (1964) $10^{-11}$、Eöt-Wash 實驗組 (2008) $10^{-13}$、 MICROSCOPE 衛星 (2022) $10^{-15}$。等效原理至今無一反例。

### 重力紅移的預言
由等效原理推導：在重力場中爬升高度 $h$ 的光子，對上方的觀察者而言頻率降低。以加速電梯推理（光爬升時間 $h/c$，接收者已獲得速度 $v = gh/c$，多普勒紅移）：
$$\frac{\Delta\nu}{\nu} = \frac{\Delta\lambda}{\lambda} \approx \frac{v}{c} = \frac{gh}{c^2} \quad(\text{弱場})$$
推廣到一般重力場（Schwarzschild 解）：
$$\frac{\Delta\nu}{\nu} = \frac{GM}{c^2}\left(\frac{1}{r_2} - \frac{1}{r_1}\right)$$
**驗證**：Pound–Rebka 實驗 (1959) 用 $\gamma$ 射線在 Harvard 22.5 m 高塔測得 $\Delta\nu/\nu \approx 2.5\times10^{-15}$，與預言一致（1% 誤差內）。GPS 衛星也需據此修正鐘率。

### 光線彎曲：1911 的錯誤值 vs 1915 的正確值
- **1911 年（只用等效原理 + 牛頓式推理）**：光經過太陽邊緣的偏折角，Einstein 預言
$$\theta_{1911} = \frac{2GM}{c^2 R_\odot} \approx 0.875'' \;(\text{弧秒})$$
此值只計算了「時間膨脹部分」（等效原理的貢獻），相當於把光當作在以太中受牛頓式重力——與 1801 年 Soldner 的牛頓計算巧合相同。
- **1915 年（完整廣義相對論）**：空間幾何本身的彎曲**再貢獻一半**，總偏折
$$\theta_{1915} = \frac{4GM}{c^2 R_\odot} \approx 1.75''$$
- **結案**：Eddington (1919) 日蝕觀測得 $\approx 1.75''$，支持 1915 值——「空間本身會彎曲」擊敗牛頓式的光學補救。這是廣義相對論的加冕時刻。

### Python 數值驗證

```python
import numpy as np

G, c = 6.674e-11, 299_792_458.0
M_sun, R_sun = 1.989e30, 6.96e8
arcsec = 206264.806

theta_1911 = 2 * G * M_sun / (c**2 * R_sun) * arcsec
theta_1915 = 4 * G * M_sun / (c**2 * R_sun) * arcsec
print(f"1911 錯誤值: {theta_1911:.3f} arcsec")
print(f"1915 正確值: {theta_1915:.3f} arcsec (Eddington 1919 測得 ~1.75)")

# 重力紅移: 地表 22.5 m (Pound-Rebka)
g, h = 9.8, 22.5
dn = g * h / c**2
print(f"gh/c^2 = {dn:.3e}，Pound-Rebka (1959) 測得 ~2.5e-15")
```

輸出：
```
1911 錯誤值: 0.849 arcsec
1915 正確值: 1.699 arcsec (Eddington 1919 測得 ~1.75)
gh/c^2 = 2.448e-15，Pound-Rebka (1959) 測得 ~2.5e-15
```

## 結案 -- 後果與影響
- 重力從「力」被改寫為**時空幾何**：質量與能量彎曲時空，物體沿測地線運動（1915 場方程 $G_{\mu\nu} = 8\pi G T_{\mu\nu}/c^4$）。
- 預言並驗證：重力紅移 (1959)、光線偏折 (1919)、水星近日點進動 (43''/世紀)、重力波 (2015 LIGO)。
- 等效原理的量子版本（量子疊加態的落體實驗）至今仍是活躍研究前沿。
- 黑洞、宇宙學、重力透鏡皆由此案衍生——1907 年電梯裡的一個念頭，改寫了整個宇宙的劇本。
