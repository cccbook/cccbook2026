# 猶太文化與資本主義之精神

> The Jewish Ethos and the Spirit of Capitalism
> ——從流散歷史、律法思辨到現代無形資本的形成

仿照韋伯《新教倫理與資本主義精神》的問題意識，本書追問：若新教倫理只是資本主義精神的源頭之一，那麼猶太人的歷史經驗——制度縫隙、宗教倫理與流散網路——又貢獻了什麼？全書五章，沿「斷裂 → 制度 → 解放 → 比較 → 總結」的長時段軸線，梳理科技、經濟、制度、文化、政治、思想與教育之間的互相驅動關係。

## 三個核心假說

| 假說 | 核心主張 | 主要章節 |
| --- | --- | --- |
| H1 制度縫隙說 | 猶太人被排除在土地與行會之外，反而填補了基督教世界的金融制度缺口 | 第2、3章 |
| H2 宗教倫理說 | 塔木德的理性主義、契約倫理與全民識字傳統塑造了可遷移的人力資本 | 第2、5章 |
| H3 網路資本說 | 流散網路是低成本的信任與資訊基礎設施，降低了跨國交易成本 | 第2、4章 |
