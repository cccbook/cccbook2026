# -0350-亞里士多德論貨幣與貨殖：經濟學的第一份起訴書

## 案件摘要

西元前 350 年前後，呂克昂學園的**亞里士多德**（！柏拉圖最出色的學生！）在《政治學》第一卷與《尼各馬可倫理學》第五卷中，做出西方思想史上第一筆關於經濟的系統判決：他把「獲取財貨」分成兩種——**家計管理（oikonomia！）**，以使用與自足為目的，**有自然的限度**（！像吃飯吃飽就停！）；以及**貨殖（chrēmatistikē！）**，以貨幣增殖貨幣為目的，**沒有限度**（！像醫生無限開藥——瘋了！）——核心武器是貨幣二分：貨幣本是**交換的尺**（為了便利交易而生！），卻被反過來**「錢生錢」**（tokos！利息的字源就是「子息」——錢竟然會生育！）——判詞如下（！）：**「以錢生錢是所有獲取方式中最不自然的。」**（！）——這一句話，統治歐洲經濟倫理**整整兩千年**（→阿奎那、教會法、莎士比亞的夏洛克、一直到馬克思筆記裡還在引！）（！）。

## 前因 -- 多因素的局勢

- **希臘商業革命**：鑄幣（呂底亞發明，希臘普及！）＋遠洋貿易＋殖民城市——**雅典成為愛琴海的錢莊**（！比雷埃夫斯港的金錢氣味！）。
- **信用與高利貸的擴張**：借錢收息已經普遍（！農民典押土地——「六一農」因還不起六分之一的重利而失去土地！）——**梭倫改革前的社會創傷記憶仍在**。
- **柏拉圖的遺產**：《理想國》已懷疑貨幣與私產腐蝕靈魂（！）——**亞里士多德既繼承又反駁**（→他反對共產共妻：財產私有但使用可以慷慨！）。
- **奴隸制家計經濟**：生產靠奴隸與土地（！）——**城邦公民不勞動而議政**——「經濟」在當時就是「治家的技術」。
- **詭辯學派的相對主義**：「人是一切尺度的尺度」（！）——**亞里士多德急著替價值找一個客觀的尺**（！貨幣正是那把尺！）。

## 線索與推理 -- 因素咬合

### 線索一：使用價值 vs 交換價值的原始切分

《政治學》的推理鏈（！）：

$$\text{物} \Rightarrow \text{有兩種用途：用（穿鞋！）與換（賣鞋！）}$$

以物易物（酒換穀物！）→ 為便利而發明貨幣（！交換的尺，本身不是目的！）→ **有人發現：錢可以換出更多錢**（！）——**這一步是「不自然」的越界**（→貨幣從「尺」變成了「目的」——手段篡奪目的！）

### 線索二：有限與無限——家計 vs 貨殖

| | 家計 oikonomia | 貨殖 chrēmatistikē |
|---|---|---|
| 目的 | 使用、自足（！） | 貨幣增殖（！） |
| 限度 | **自然有限**（吃飽即止） | **無限**（慾望無底！） |
| 手段 | 農、牧、狩獵 | 貿易囤積、**放貸生息**（！） |
| 判決 | 自然、正當 | **最不自然**（！） |

（！邏輯的狠處：貨殖把「活得好」偷換成「活得多」——**量對質的暴政**，兩千年後仍在！）

### 線索三：利息判詞——「錢不會生孩子」

tokos（子息！）的類比（！）：《政治學》I.10——**貨幣是為交換而生，不是為生殖而生**；讓錢生子就像（！）**讓不會動的東西動起來生後代**——違反自然（physis！）——**這個類比成為基督教反高利貸的希臘軍火庫**（→阿奎那直接引經據典！）

### 線索四：公正價格的胚胎

《尼各馬可倫理學》第五卷：交換正義（！）——鞋匠與農夫的交換要「按比例相等」（！）——貨幣讓不可通約的物**變成可通約**（！）——**馬歇爾的均衡、阿羅的一般理論，源頭都在這一段**（→驚人的譜系！）

## 後果 -- 改變了什麼

- **基督教經濟倫理**：反高利貸教義的理論地基（→見 [1282-阿奎那與正義價格.md](1282-阿奎那與正義價格.md)）——**中世紀銀行家必須在神學縫隙裡做金融**（！）。
- **經濟學的長期問題清單**：使用與交換、有限與無限、貨幣中立與否（！）——**今天討論金融化、投機、加密貨幣，仍在打這場官司**（！）。
- **「經濟」一詞**：oikonomia → economy（！）——**學科的名字就是治家**（！）。
- **現代翻案**：費雪與資本理論把利息解釋為時間偏好（！錢果然會「生育」，因為未來的貼現！）——見 [1906-費雪資本與收入的性質.md](1906-費雪資本與收入的性質.md)；馬克思則在《資本論》筆記裡一面引他一面翻案（！G—W—G′正是貨殖的現代實現！）（！）。

**偵探結語**：這樁案子的深處（！）是一個尚未解決的偵辦懸念：**亞里士多德其實沒有錯，他只是早了兩千年**——他指控貨殖「無限」時（！），尚未見過複利的力量、證券化與比特幣；但「手段無限膨脹、目的被遺忘」的結構（！），正是今天注意力經濟與金融化批判的原始碼（！見 [2021-數位平台與注意力的政治經濟學.md](2021-數位平台與注意力的政治經濟學.md)）。最耐人尋味的是（！）他發明了「經濟」這個詞，卻不會承認後來的經濟學是一門學科——他會說：**你們把治家的技術變成了無限增殖的技術**（）。第一份起訴書至今沒有結案；它只是在每個金融泡沫破掉時（！）被重新裝訂一次。
