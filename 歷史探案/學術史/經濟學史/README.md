# 經濟學史 -- AI 偵探風格

以「推理探案」的方式，追查經濟思想史的重大轉折：亞里士多德的貨幣、阿奎那的正義價格、配第的政治算術、魁奈的經濟表、斯密的看不見的手、馬爾薩斯的人口、李嘉圖的比較利益、穆勒的折衷、邊際革命、馬歇爾的均衡、費雪的資本、凱因斯的有效需求、柯斯的交易成本、馮諾依曼的賽局、海耶克的知識、阿羅的不可能、菲利普曲線、寇斯的社會成本、傅利曼的自由、施蒂格勒的訊息、貝克爾的人類行為、諾斯的制度、卡尼曼的偏誤、2008 危機、席勒的敘事、迪頓的福祉、隨機對照試驗、注意力經濟——
前因是什麼？線索在哪裡？推理如何展開？後果又如何改寫了「**財富如何被解釋**」？

本卷的核心命題只有一句話：**經濟學史是「財富如何被解釋」的偵辦史。**
每一樁案件都是一次「對富裕與貧窮的重新起訴」：貨殖（錢可以生錢嗎？！）、正義價格（市場有道德上限嗎？！）、政治算術（國家用數字丈量自己！）、經濟表（生產有迴路！）、看不見的手（自利可以公共利益！）、人口（幾何對算術的悲劇！）、比較利益（貿易是雙贏的數學證明！）、邊際（價值從成本轉向效用！）、一般理論（市場不會自我痊癒！）、賽局（策略相互依存！）、訊息（價格裡藏著知識！）、行為（人是偏誤的動物！）、注意力（免費服務的代價是誰在付！）。
解釋財富的方法變了，「經濟」的疆界就重劃了。每個重大轉折都是一樁「多因懸案」：偵探的工作，就是把因素鏈一環一環還原出來。

（涵蓋：亞里士多德、阿奎那、配第、魁奈、斯密、馬爾薩斯、李嘉圖、穆勒、傑文斯／門格爾／瓦拉斯、馬歇爾、費雪、凱因斯、柯斯、馮諾依曼與摩根斯坦、海耶克、阿羅、菲利普斯、傅利曼、施蒂格勒、貝克爾、諾斯、卡尼曼、2008 危機群像、席勒、迪頓、班納吉與迪弗洛、數位平台）

| 改寫 | 機制 | 經典案例 |
|------|------|----------|
| **道德化** | 錢要服務靈魂 | 阿奎那正義價格；反高利貸 |

        ↓                                        ↓
  病灶 ──→ 診斷 ──→ 模型 ──→ 政策處方 ──→ 教科書 ──→ 反思
   │                ↑        ↑                  │
   │                │        │                  ↓
   └──→ 方法論之戰 ←── 諾貝爾獎 ←── 期刊與學系 ──→ 政策反噬
              ↑                       ↑
              └── 下一場危機 ←──（模型失靈！）┘

   正向迴路（加速）：數據→模型→預測→政策→更多數據
   正向迴路（加速）：危機→新典範→諾貝爾獎→教科書改版
   負向迴路（抑制）：意識形態→拒絕證據（！）→延遲修正

**偵探的訣竅**：找到「誰丈量、誰建模、誰開處方、誰背鍋」，把鏈條畫出來；再問一句——**這個模型把「人」看成了什麼（道德主體？計算機？偏誤的動物？注意力的租戶？）？**案件的因果鏈就浮現了。

## 案件卷宗（歷史年表）

### 一、市場被發明之前：道德與算術（-0350–1758）

- -350：亞里士多德《政治學》《尼各馬可倫理學》——貨幣是交換的尺（！）、貨殖（chrēmatistikē！）無限而家計有限；「利息是最不自然的」判詞統治歐洲兩千年。［[-0350-亞里士多德論貨幣與貨殖.md]］
- 1282：阿奎那與「正義價格」——中世紀經院學者的市場倫理；高利貸禁令的縫隙（！外幣兌換、風險補償——金融的後門從神學開出！）。［[1282-阿奎那與正義價格.md]］
- 1664：配第《政治算術》——「用數字、重量與尺度說話」；國民收入估算的鼻祖（！政治經濟學的第一把尺！）。［[1664-配第政治算術.md]］
- 1758：魁奈《經濟表》——生產、流通、再生產的迴路圖（！國民經濟的第一張系統圖——凱因斯的遠祖！）。［[1758-魁奈經濟表.md]］

### 二、古典體系：市場的黃金起訴書（1776–1890）

- 1776：斯密《國富論》——分工＋看不見的手；財富的來源從金銀改判為勞動（！政治經濟學的獨立宣言！）。［[1776-亞當斯密國富論.md]］
- 1798：馬爾薩斯《人口論》——幾何對算術；人口壓力的第一個經濟模型（→達爾文與凱因斯都欠他一句話！）。［[1798-馬爾薩斯人口論.md]］
- 1817：李嘉圖《政治經濟學及賦稅原理》——比較利益：貿易雙贏的數學證明（！兩個數字的表格改寫世界貿易！）。［[1817-李嘉圖比較利益.md]］
- 1848：穆勒《政治經濟學原理》——古典學派的總結算；生產法則 vs 分配法則（！「分配可以由社會決定」的縫隙！）。［[1848-穆勒政治經濟學原理.md]］
- 1871：邊際革命三傑——傑文斯、門格爾、瓦拉斯同時發難：價值由邊際效用決定（！水與鑽石的悖論結案！）。［[1871-邊際革命三傑.md]］
- 1890：馬歇爾《經濟學原理》——供給與需求的剪刀；局部均衡；「經濟學」取代「政治經濟學」（！ceteris paribus 的誕生！）。［[1890-馬歇爾經濟學原理.md]］

### 三、貨幣、預期與大蕭條（1906–1945）

- 1906：費雪《資本與收入的性質》——資本＝收入的現值；存量與流量；利率是耐心與投資的交點（！現代財務學的地基！）。［[1906-費雪資本與收入的性質.md]］
- 1936：凱因斯《就業、利息和貨幣通論》——有效需求；流動性偏好；儲蓄悖論（！市場不會自我痊癒——總體經濟學誕生！）。［[1936-凱因斯一般理論.md]］
- 1937：柯斯《企業的性質》——市場有成本，所以有企業（！交易的價格標籤上看不見的成本！）。［[1937-柯斯企業的性質.md]］
- 1944：馮諾依曼與摩根斯坦《賽局理論與經濟行為》——策略相互依存；期望效用；「囚徒困境」之前傳（！經濟學取得數學的核武級工具！）。［[1944-馮諾依曼與摩根斯坦賽局理論.md]］
- 1945：海耶克《知識在社會中的運用》——價格是知識的電報（！中央計畫算不出的分散知識——社會主義計算辯論的結案陳詞！）。［[1945-海耶克知識的使用.md]］

### 四、戰後的黃金與反叛（1951–1976）

- 1951：阿羅《社會選擇與個人價值》——不可能定理：沒有完美的投票制度（！福利經濟學的地震——社會偏好在數學上不可能無懈可擊！）。［[1951-阿羅社會選擇與個人價值.md]］
- 1958：菲利普曲線——通膨與失業的取捨被畫出來（→1970s 停滯通膨把它撕成兩半——傅利曼的預言成真！）。［[1958-菲利普曲線.md]］
- 1960：寇斯《社會成本問題》——外部性互為因果；財產權與談判成本（！「牛吃麥子」的案子顛倒起訴方向！）。［[1960-寇斯社會成本問題.md]］
- 1962：傅利曼《資本主義與自由》——經濟自由是政治自由的前提；志願兵、學券、負所得稅（！芝加哥學派的政策聖經！）。［[1962-傅利曼資本主義與自由.md]］
- 1971：施蒂格勒《訊息經濟學》——搜尋成本與價格離散；「沒有免費的資訊」（→資訊不對稱革命的開端！）。［[1971-施蒂格勒訊息經濟學.md]］
- 1976：貝克爾《人類行為的經濟分析》——歧視、犯罪、家庭、時間全進了模型（！經濟學帝國主義的宣言書！）。［[1976-貝克爾人類行為的經濟分析.md]］

### 五、制度、行為與危機的反思（1990–2015）

- 1990：諾斯《制度、制度變遷與經濟成就》——制度是遊戲規則；路徑依賴；交易成本決定國家的貧富（！「為什麼有些國家窮」的答案在規則裡！）。［[1990-諾斯制度變遷理論.md]］
- 2002：卡尼曼與行為經濟學的登基——捷思與偏誤；前景理論；損失趨避（！心理學家拿走諾貝爾經濟學獎——理性人假設的修正案！）。［[2002-卡尼曼行為經濟學.md]］
- 2008：全球金融危機與總體經濟學反思——雷曼倒閉；DSGE 盲區；總體模型的審判日（！「我們之中沒有人預見到」——女王之問！）。［[2008-金融危機與總體經濟學反思.md]］
- 2013：席勒《敘事經濟學》——故事像病毒一樣傳染；泡沫是敘事的流行病（→行為總體的補完！）。［[2013-席勒敘事經濟學.md]］
- 2015：迪頓與福祉經濟學——從收入到幸福；以消費數據測量貧窮（！貧窮的定義本身被改寫！）。［[2015-迪頓與貧窮經濟學.md]］

### 六、當代戰場：證據、平台與注意力（2019–2021）

- 2019：班納吉、迪弗洛與克雷默的隨機對照試驗——發展經濟學的實驗室化（！窮人的行為與富人一樣理性——證據取代意識形態！）。［[2019-隨機對照試驗與發展經濟學.md]］
- 2021：數位平台與注意力的政治經濟學——免費服務的代價；數據作為勞動；平台的「看不見的手」握著你的眼球（→兩側市場與零價格之謎！）。［[2021-數位平台與注意力的政治經濟學.md]］

## 偵探的結案陳詞

兩千三百多年的經濟學史，可以壓縮成三條因果鏈：

1. **模型鏈**：道德判詞（錢要服務靈魂！）→ 政治算術（國家可數！）→ 經濟表（生產有迴路！）→ 看不見的手（市場自洽！）→ 邊際（效用定價！）→ 一般理論（市場會生病！）→ 賽局（策略纏鬥！）→ 行為（人會犯錯！）→ 敘事（故事會傳染！）——**每一個新模型，重審一次「財富」**。
2. **人物鏈**：哲學家（亞里士多德！）→ 神學家（阿奎那！）→ 測量員（配第！）→ 醫生（魁奈！）→ 教授（斯密！）→ 股票經紀人（李嘉圖！）→ 邏輯學家（穆勒！）→ 工程師（瓦拉斯！）→ 數學家（費雪馮諾依曼！）→ 記者轉智者（凱因斯！）→ 芝加哥步兵團（傅利曼施蒂格勒貝克爾！）→ 心理學家（卡尼曼席勒！）——**先是道德家，再是科學家，最後又回來面對人性**。
3. **危機鏈**：高利貸之爭（中世紀！）→ 谷物法與饑荒（李嘉圖！）→ 大蕭條（凱因斯！）→ 停滯通膨（傅利曼！）→ 2008 危機（行為總體！）→ 平台經濟（注意力！）——**教科書的每一版修訂，背後都是一場崩潰**。

三條鏈咬合在一起，就是本卷二十六樁案件的全部真相：**經濟學從未真正離開過它的起點——「人該如何一起生活、一起富裕、一起免於匱乏」的問題**；它只是不斷換上新的數學、新的數據、新的故事，把同一個問題再偵辦一次。
