# 1882 · 尼采上帝之死：快樂科學瘋人案

## 案件摘要
1882 年，尼采（1844–1900）出版《快樂的科學》，第 125 節「瘋人」：瘋人提著燈籠在集市上找上帝，「我們殺了他——你們和我！」（!兇手是所有人，兇器是現代性本身！）同年《查拉圖斯特拉如是說》開筆：「上帝死了……我們必須自己成為神，才配得上此事。」

## 前因 -- 多因素的局勢
1. **世俗化的進度條**：達爾文《物種起源》（1859）衝擊創造論、聖經批評學（施特勞斯《耶穌傳》1835）瓦解字面信仰、德國大學神學的歷史化——「上帝」在知識階層已是禮貌用語。
2. **叔本華的遺產對賬**：尼采 1865 年偶然讀《作為意志和表象的世界》，先當信徒（早期《悲劇的誕生》1872 滿是叔本華+華格納），1876 年後反水——（!從拜師到斷絕，尼采把導師的悲觀主義改裝成「肯定的實驗」！）
3. **華格納決裂（1876–78）**：拜魯特首演失望、華格納轉向基督教與反猶主義（《帕西法爾》）——尼采《人性的，太人性的》（1878）公開分手：文化偶像的崩塌先於上帝。
4. **健康崩壞與退休**：劇烈頭痛、嘔吐、失明恐懼；1879 年三十五歲辭巴塞爾大學教授（十年任期，病假連年）——此後十年以旅館與療養地為家，靠退職金寫作。
5. **歐洲虛無主義診斷**：教會權威衰落而「道德價值」仍在——尼采看到的是**未完成**的無神論：人們殺了神，還用神的名字立法。

## 線索與推理 -- 因素咬合
### 線索一：瘋人案發現場的偵查
「瘋人」段落結構：上帝死了→誰幹的→「我們殺了他」→我們如何自我安慰（這是空前偉業）→必須發明節日與遊戲來配得上兇案。關鍵：尼采不是宣布無神論（那是舊聞），而是審理**殺神之後的後果鏈**——虛無主義：「最高的價值自行貶值。」（→ 「上帝死了」是案情通報，「虛無主義」才是起訴書！）

### 線索二：價值重估的施工圖
| 概念 | 內容 | 功能 |
|---|---|---|
| 力量意志（Wille zur Macht） | 生命=力量的增殖與克服 | 替換叔本華的「否定意志」 |
| 永恆輪迴 | 《快樂的科學》§341：惡魔提議，你會否擁抱？ | 最重的存在試金石 |
| 超人（Übermensch） | 查拉圖斯特拉前言 | 死神之後的人類方案 |
| 重估一切價值 | 《善惡的彼岸》(1886) 起 | 未竟主工程 |

注意偵探細節：「上帝死了」在《查拉圖斯特拉》中出自教宗之口——（!連神職人員都出庭作證，教會的信用破產是內部證詞！）

### 線索三：道德的家譜審訊
《道德的譜系》（1887）：「善/惡」出自「善/壞」的奴隸起義——弱者無力報復，轉而在價值上倒轉（把強者的「好」改名「惡」）；內向化的殘暴=罪惡感=良心。（→ 心理學化的道德史：尼采給道德做DNA檢測，檢出怨恨（ressentiment）的單親家庭！）

### 線索四：瘋與書的邊界
1889-1-3 都靈卡羅·阿爾伯托廣場：抱住被鞭打的馬，隨後精神崩潰（遺傳腦病？梅毒說已被多數學者棄用）。母親與妹妹伊莉莎白接管：她 1885 年嫁反猶主義者福斯特、1890s 建「檔案館」、任意剪接《力量意志》遺稿、後投向納粹——（!哲學家的遺囑被妹妹私改，希特勒出席其葬禮——受害與被利用的雙重卷宗，此案最髒的附頁！）

## 破案時刻
- 1858–1864：舒爾塔文科中學（普福塔）；1865 萊比錫遇叔本華。
- 1869：24 歲未取得博士學位即任巴塞爾古典語文學教授（破格）。
- 1872：《悲劇的誕生》；學界冷遇（維拉莫維茨討伐）。
- 1876：拜魯特出走；1878《人性的，太人性的》與華格納決裂。
- 1879：辭巴塞爾教職。
- 1882-4：《快樂的科學》出版；8 月遇露·莎樂美求婚遭拒（雙重提案），11 月絕交。
- 1883–85：《查拉圖斯特拉》四部（第四部私人印 7 冊）。
- 1886–87：《善惡的彼岸》《道德的譜系》；1888 年產能暴增五書。
- 1889-1-3：都靈崩潰；1900-8-25 卒於魏瑪。

## 後果 -- 改變了什麼
1. 虛無主義成為二十世紀核心診斷：韋伯「祛魅」、海德格《尼采》講座（「西方形上學的完成」）、雅斯佩斯——（→ [1927-海德格存有與時間.md](1927-海德格存有與時間.md) 與 [1943-沙特存在與虛無.md](1943-沙特存在與虛無.md) 都在審理此案遺留的「價值真空」！）
2. 存在主義的精神系譜：加繆《薛西弗斯神話》開篇即處理「自殺與沒有上帝」——荒謬是虛無主義的法文譯本。
3. 後現代的引爆線：福柯的譜系學、德希達的解構直接自認尼采傳人（見 [1967-德里達論文字學.md](1967-德里達論文字學.md)）。
4. 名譽案的二審：二戰後瓦爾特·考夫曼等清理妹妹的剪接，尼采從「納粹哲學家」改判為「反民族主義者」——（!同一作者，兩次判決，檔案政治的教科書案例！）

**偵探結語**：看清楚這樁案的吊詭：尼采沒有殺上帝，他只是第一個到達現場並報案的人——兇手是達爾文的讀者、聖經批評家、辭了教職的資產階級，也就是他自己的階級。他的錯誤在於以為公告可以代替葬禮：一百年過去，人們仍然在神的名字下立法、又在科學的名字下撒謊。至於那個抱著馬哭的結局——瘋人早說過他會回來找兇手算帳，結果第一個找到的是他自己。
