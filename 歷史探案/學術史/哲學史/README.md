# 哲學史 -- AI 偵探風格

以「推理探案」的方式，追查哲學史上的重大轉折：泰勒斯的水、畢達哥拉斯的數、蘇格拉底的死刑、柏拉圖的洞穴、阿奎那的綜合、奧卡姆的剃刀、笛卡爾的懷疑、休謨的斷裂、康德的哥白尼革命、黑格爾的辯證、馬克思的翻轉、尼采的上帝之死、維也納學圈、存在主義、維根斯坦的兩把鑰匙、德里達的解構、羅爾斯的正義——
前因是什麼？線索在哪裡？推理如何展開？後果又如何改寫了思想史？

本卷的核心命題只有一句話：**哲學史是「問題的偵辦史」。**
每一樁案件都是一次問題的革命：本原（萬物由什麼構成？）、存在（變與不變？）、倫理（如何活得好？）、信仰與理性（能否兼得？）、方法（我如何確知？）、界限（理性管到哪裡？）、歷史（觀念如何自己運動？）、語言（思想被什麼困住？）。問題變了，哲學就換了法庭。每個重大轉折都是一樁「多因懸案」：偵探的工作，就是把因素鏈一環一環還原出來。

（涵蓋：米利都、畢達哥拉斯、孔子、赫拉克利特—巴門尼德、佛陀、芝諾、原子論、蘇格拉底之死、柏拉圖學院、亞里士多德呂克昂、伊壁鳩魯與斯多亞、獨尊儒術、奧古斯丁、雅典學院關閉、阿拉伯哲學、翻譯運動、阿奎那、奧卡姆、笛卡爾、斯賓諾莎、洛克、休謨、康德、黑格爾、叔本華、克爾凱郭爾、馬克思、尼采、摩爾與分析哲學、胡塞爾、維根斯坦《邏輯哲學論》、科玄論戰、海德格、維也納學圈、沙特、維根斯坦《哲學研究》、德里達、羅爾斯）

## 哲學的問題革命：八種法庭如何審判世界

| 法庭 | 核心問題 | 經典案例 |
|------|----------|----------|
| **本原** | 萬物由什麼構成？ | 泰勒斯之水；畢達哥拉斯之數；原子論 |
| **存在** | 變與不變孰真？ | 赫拉克利特河流；巴門尼德之路 |
| **倫理** | 如何活得好？ | 蘇格拉底德性即知識；伊壁鳩魯花園；斯多亞 |
| **信仰與理性** | 雅典與耶路撒冷能否和解？ | 奧古斯丁；阿奎那；奧卡姆的分手 |
| **方法** | 我如何確知？ | 笛卡爾懷疑；洛克白板；休謨因果之謎 |
| **界限** | 理性管到哪裡？ | 康德二律背反；維根斯坦可說與不可說 |
| **歷史** | 觀念如何自己運動？ | 黑格爾辯證；馬克思翻轉；尼采系譜 |
| **語言** | 思想被什麼困住？ | 維也納學圈；哲學研究；德里達延異 |

## 問題的迴響迴路

```
       ┌────（時代危機：城邦崩解、信仰動搖、科學革命、戰爭）────┐
       ↓                                                      ↓
 舊問題 ──→ 異端/危機 ──→ 新方法 ──→ 學派 ──→ 制度化 ──→ 新問題
   │            ↑          ↑                     │
   │            │          │                     ↓
   └──→ 政治宗教鎮壓 ←── 傳承（手稿、翻譯、學院）←── 反叛
       ↑                              ↑
       └── 經濟—技術（印刷、翻譯、期刊）┘

   正向迴路（加速）：翻譯→新文本→新問題→新學派
   正向迴路（加速）：懷疑→方法→體系→下一個懷疑
   負向迴路（抑制）：權威鎮壓→地下傳播（蘇格拉底毒杯、斯賓諾莎絕罰、《邏輯哲學論》戰壕）
   偵探迴路（本卷特有）：危機→懷疑→方法→體系→反叛→危機
```

**偵探的訣竅**：找到「什麼問題在法庭上、誰提起訴訟、用什麼方法審、判決推翻了什麼」，把鏈條畫出來；再問一句——**被告是誰（神？因果？語言？權力？）？**案件的因果鏈就浮現了。
