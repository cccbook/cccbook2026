# 1967 · 德里達論文字學：書寫的炸彈案

## 案件摘要
1967 年，巴黎高等師範的阿爾及利亞裔猶太教師德里達（1930–2004）一年連出三書：《論文字學》《書寫與差異》《聲音與現象》。《論文字學》的定時炸彈：西方兩千年的「在場形上學」（語音中心主義）被判有罪——書寫（écriture）不是言語的補充，而是**原初補充**（supplément originaire）：語言從一開始就已是書寫。（!結構主義的黃金年代，德里達瞄準的不是人文科學，而是整個西方自柏拉圖以來的存有論底盤！）

## 前因 -- 多因素的局勢
1. **結構主義的全盛與縫隙**：索緒爾《普通語言學教程》(1916 遺作) 的符號=所指/能指二分；列維-斯特勞斯《野性的思維》(1962) 統治人文科學——德里達選它做靶：書中批評盧梭的「自然/文化」對立恰是「西方文字暴力」的標本。
2. **高師-索邦的職業結構**：德里達 1956–59 哈佛/高師交換、 agrégation 第十名、索邦助教、1965 回高師教師——（!法國哲學界的階梯制使「造反者」必先入學院核心！）
3. **阿爾及利亞猶太人的身分卷宗**：1942 被逐出本雅明中學（維希種族法）、學籍被取消的少年創傷；「小黑猶太人」的雙重邊緣——（!解構的「邊緣即中心」有其傳記地下層！）
4. **胡塞爾研究的嚴格訓練**：1962《胡塞爾幾何學起源導論》（翻譯+130 頁導言）、1964 任《太凱爾》(Tel Quel) 顧問——從現象學內部爆破的路線圖已備。
5. **結構主義的媒體-學院熱潮**：《太凱爾》《批評》、高師研討班——出版市場對「新理論」需求極旺，1967 三書同時上市是市場行為。

## 線索與推理 -- 因素咬合
### 線索一：在場形上學的起訴書
柏拉圖《斐德羅篇》：文字是毒藥（pharmakon）——既治病又害病；列維-斯特勞斯《憂鬱的熱帶》「文字課」一節：文字是剝削的工具。德里達翻案：這種「言語在場、文字缺席」的等級制統治了整個西方（神學的道、現象學的聲音自我在場）。（→ 「延異」（différance）：意義永遠是差異與延宕的遊戲——在場從未真正在場！）

### 線索二：原初補充的偵查邏輯
盧梭《懺悔錄》用「補充」罵文字，卻自己一生寫作補充面對面；德里達揭示：補充不是外加的——**沒有被補充者先於補充存在**（「沒有本源，只有補充的鏈條」）。（→ 這一手同時解構了結構主義的「結構」：中心只是被指定為中心者，從未真正中心——「遊戲」（jeu）取代「結構」！）

### 線索三：對結構主義的內部爆破
《人文科學話語中的結構、符號與遊戲》（1966 霍普金斯會議，德里達的英語世界首演）：尼采、佛洛伊德、海德格是三個「顛覆在場」的先驅；列維-斯特勞斯在「神話自身也是神話」處自我暴露。（!這場演講在美國激起更深的迴響——1967 年的三書在美國校園成為「理論」的進口母船！）

## 破案時刻
- 1930：生於阿爾及爾近郊埃爾比亞爾。
- 1942：維希法令退學；1949 赴巴黎。
- 1956–59：哈佛交換、agrégation、勒芒中學教書、服阿爾及利亞戰爭期間的教學兵役。
- 1962：《幾何學起源導論》；1965 回高師任教。
- 1966-10：霍普金斯「批評語言與人的科學」會議主講。
- 1967：三書齊發。
- 1968：五月風暴中參與教師公會運動；1970s 起哥倫比亞、耶魯客座——「耶魯學派」成形。
- 1983：創建巴黎國際哲學學院（首任院長）；2004-10-9 卒於巴黎。

## 後果 -- 改變了什麼
1. 後結構主義定名與「理論」帝國：1970s–90s 美國英語系被解構殖民（耶魯學派：德曼、哈特曼、米勒、布魯姆）——文學研究成為哲學的第二戰場。
2. 「延異/踪跡/補充」成為思想通用詞：法律（批判法學）、建築（解構主義建築：屈米、蓋里）、神學（激進正統）、人類學——（!一個法語詞的全球擴張史，本身是傳播學的案例！）
3. 學院政治的長期訴訟：1980 劍橋授榮譽學位風波（哲學家聯名反對、聲請覆議通過）、索卡爾事件（1996 物理學家偽造論文測試「後現代」期刊）——（!解構的合法性与可讀性至今在審！）
4. 對德里達本人的再審：晚年《馬克思的幽靈》（1993）與「友誼政治」轉向——解構者最後被要求對政治現實表態，如所有被解構者一樣。

## 因素影響筆記
```
阿爾及利亞猶太邊緣身分 ──┐
胡塞爾內部訓練(1962) ────┼──> 1967 三書齊發
結構主義全盛（靶場充足）─┤
高師-索邦職業階梯 ───────┤
太凱爾/出版市場熱潮 ────┘
                              v
     在場形上學起訴：延異/補充/遊戲
             ├──> 耶魯學派 ──> 美國「理論」帝國
             ├──> 傅柯回火(1972) ──> 後結構主義內訟
             └──> 解構擴散至法律/建築/神學 ──> 索卡爾事件(1996)
```

**偵探結語**：此案的手法最講究：德里達不推翻結構主義，他住在它裡面，把它的地基術語（對立、符號、起源）逐一查出「自我拆臺」的病歷。延異說穿了是一句話：任何「在場」都要靠它宣稱不在場的東西支撐。但要害在職業結構——高師階梯、太凱爾陣地、美國英語系的巨大市場：解構是學院資本的一次完美運作。當「文本之外無物」被寫進美國英文系的招聘啟事時，這樁爆炸案就完成了從哲學到職業的資產重組。德里達自己說得最誠實：解構不是方法，是**在場的機遇**——而機遇，歷來偏愛有教職的人。
