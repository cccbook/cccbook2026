# 管理學史 -- AI 偵探風格

以「推理探案」的方式，追查管理學的重大轉折：斯密的製針工廠、巴貝奇的機器與製造業、西部鐵路的分層、鐵路公司的現代企業、泰勒的科學管理、福特的流水線、法約爾的一般管理、霍桑實驗、巴納德的經理職能、德魯克的管理革命、麥格雷戈的XY、錢德勒的戰略與結構與看得見的手、安索夫的公司戰略、明茲伯格的管理本質、大野耐一的豐田方式、波特的競爭策略、霍夫斯泰德的文化維度、彼得斯的卓越、聖吉的學習型組織、漢默與錢皮的企業改造、敏捷宣言、藍海策略、精實創業、遠距工作、靜默離職——
前因是什麼？線索在哪裡？推理如何展開？後果又如何改寫了「何為管理」？

本卷的核心命題只有一句話：**管理學史是「組織如何被馴服」的偵辦史。**
每一樁案件都是一次「把人群變成機構」的革命：分工（動作可以被分解！）、機器（生產可以被計價！）、分層（指揮可以有層級！）、科學管理（動作可以被標準化與計時！）、流水線（人可以被工序帶著走！）、一般管理（管理是一門通用職能！）、霍桑（工人不是機器！）、巴納德（組織是合作的系統！）、德魯克（管理是社會的器官！）、XY（人性假設決定管理方式！）、戰略與結構（結構追隨戰略！）、文化（管理有國籍！）、卓越與改造（組織可以再造！）、敏捷與精實（計畫讓位給迭代！）、遠距與靜默離職（馴服被反馴！）。
管理的對象從「動作」放大到「人」、「系統」、「文化」、「平台」，最後回到了「不願被管理的人」。每個重大轉折都是一樁「多因懸案」：偵探的工作，就是把因素鏈一環一環還原出來。

（涵蓋：斯密、巴貝奇、西部鐵路、現代企業組織、泰勒、福特、法約爾、霍桑、巴納德、德魯克、麥格雷戈、錢德勒、安索夫、明茲伯格、大野耐一、波特、霍夫斯泰德、彼得斯、聖吉、漢默與錢皮、敏捷宣言、金偉燦、艾瑞克·萊斯、遠距管理、靜默離職）

## 組織的馴服：七道枷鎖如何套上又鬆開

| 枷鎖 | 機制 | 經典案例 |
|------|---------------------|----------|
| **動作** | 分工把工作切碎 | 斯密製針；巴貝奇 |
| **計時** | 秒錶量度每一動作 | 泰勒《科學管理原理》 |
| **工序** | 傳送帶帶著人走 | 福特流水線 |
| **職能** | 管理是可教的一門學問 | 法約爾；霍桑；巴納德 |
| **戰略** | 結構追隨戰略、五力定位 | 錢德勒；安索夫；波特 |
| **文化** | 管理有國籍與軟肋 | 霍夫斯泰德；彼得斯；聖吉 |
| **迭代** | 計畫讓位給試錯 | 豐田；敏捷；精實創業 |
| **反馴** | 知識工人的還價 | 德魯克；遠距；靜默離職 |

## 枷鎖的回饋迴路

```
              ┌────（時代病：工業化—戰爭—石油危機—全球化—疫情）────┐
              ↓                                          ↓
   動作 ──→ 計時 ──→ 工序 ──→ 職能 ──→ 戰略 ──→ 文化 ──→ 迭代 ──→ 反馴
    │                  ↑        ↑                     │
    │                  │        │                     ↓
    └──→ 罷工與怠工 ←── 人性假設 ←── 心理學 ←── 霍桑與巴納德
               ↑                            ↑
               └── 知識工人議價力 ←──（教育與市場）┘

   正向迴路（加速）：分工→產量→規模→更細的分工→更大的組織
   正向迴路（加速）：危機→新工具→新典範→教科書改寫
   負向迴路（抑制）：剝削→怠工與罷工→管理讓步（霍桑的教訓！）
   管理迴路（本卷特有）：馴服→反抗→再馴服→再反抗→馴服的對象變成人本身

**偵探的訣竅**：找到「誰量度、誰設計工序、誰定人性假設、誰改寫遊戲規則」，把鏈條畫出來；再問一句——**這道枷鎖把「人」套成了什麼（齒輪？資源？合夥人？自由業者？）？**案件的因果鏈就浮現了。

## 案件卷宗（歷史年表）

### 一、枷鎖之前：分工與機器（1776–1841）

- 1776：亞當·斯密《國富論》製針工廠——十人分工日產四萬八千枚；分工是財富之源也是管理的第一定理。［[1776-分工與製針工廠.md](1776-分工與製針工廠.md)］
- 1832：巴貝奇《論機器與製造業的經濟》——用數學家的眼睛解剖工廠；「巴貝奇原則」：分工連技能工資一起切省。［[1832-巴貝奇論機器與製造業.md](1832-巴貝奇論機器與製造業.md)］
- 1841：西部鐵路大事故——列車對撞、乘客死亡；資本家不會開火車，管理第一次與所有權分家。［[1841-西部鐵路事故與管理分層.md](1841-西部鐵路事故與管理分層.md)］
- 1886：美國鐵路公司與現代企業組織——電報與時刻表織出全國網；支薪經理人階層誕生；管理的職業化。［[1886-鐵路公司與現代企業組織.md](1886-鐵路公司與現代企業組織.md)］

### 二、馴服的手：科學管理與流水線（1911–1916）

- 1911：泰勒《科學管理原理》——秒錶、動作分解、差別計件；「一天公平的工作量」被科學地定價；勞資和諧的承諾與罷工聽證會。［[1911-泰勒科學管理原理.md](1911-泰勒科學管理原理.md)］
- 1913：福特流水線——移動的裝配線把工序帶到人面前；Model T 十二年；五美元日薪的算計與代價。［[1913-福特流水線.md](1913-福特流水線.md)］
- 1916：法約爾《工業管理與一般管理》——計畫、組織、指揮、協調、控制；管理是可以傳授的通用職能。［[1916-法約爾工業管理與一般管理.md](1916-法約爾工業管理與一般管理.md)］

### 三、人的回歸：霍桑到德魯克（1924–1954）

- 1924：霍桑實驗——照明實驗的意外結果；「霍桑效應」；被看見的工人效率更高；人群學派誕生。［[1924-霍桑實驗.md](1924-霍桑實驗.md)］
- 1938：巴納德《經理人員的職能》——組織是合作系統；權威來自接受；非正式組織的發現。［[1938-巴納德經理人員的職能.md](1938-巴納德經理人員的職能.md)］
- 1954：德魯克《管理的實踐》——目標管理MBO誕生；管理是社會的器官；知識工人預言；（1946《公司的概念》為前傳，本卷於1954破案）。［[1954-德魯克管理的實踐.md](1954-德魯克管理的實踐.md)］

### 四、人性假設與戰略帝國（1960–1965）

- 1960：麥格雷戈《企業的人性面》——X理論與Y理論；管理者的假設決定被管理者的人性；管理學的自我照鏡。［[1960-麥格雷戈X理論Y理論.md](1960-麥格雷戈X理論Y理論.md)］
- 1961：錢德勒《戰略與結構》——四巨頭個案；「結構追隨戰略」；M型組織的誕生。［[1961-錢德勒戰略與結構.md](1961-錢德勒戰略與結構.md)］
- 1962：錢德勒《看得見的手》——管理資本主義；經理人取代市場之手；現代企業的通史判詞。［[1962-錢德勒看得見的手.md](1962-錢德勒看得見的手.md)］
- 1965：安索夫《公司戰略》——產品—市場矩陣；戰略從暗語變成可以教的表格；計畫學派登基。［[1965-安索夫公司戰略.md](1965-安索夫公司戰略.md)］

### 五、批判與文化：管理的成人禮（1973–1990）

- 1973：明茲伯格《管理工作的本質》——秒錶跟蹤五位CEO；管理不是法約爾說的那回事；角色的實證解剖。［[1973-明茲伯格管理工作的本質.md](1973-明茲伯格管理工作的本質.md)］
- 1978：大野耐一《豐田生產方式》——徹底排除浪費；看板與及時化；與福特相反的流水線哲學。［[1978-大野耐一豐田生產方式.md](1978-大野耐一豐田生產方式.md)］
- 1980：波特《競爭策略》——五力分析、三種通用戰略；產業組織經濟學入侵管理學院。［[1980-波特競爭策略.md](1980-波特競爭策略.md)］
- 1980：霍夫斯泰德《文化的後果》——IBM十一萬份問卷；權力距離、個人主義、不確定性規避；管理有國籍。［[1980-霍夫斯泰德文化維度.md](1980-霍夫斯泰德文化維度.md)］
- 1982：彼得斯與沃特曼《追求卓越》——麥肯錫七S框架；「把人當大人」；八項卓越原則的暢銷奇蹟。［[1982-追求卓越.md](1982-追求卓越.md)］
- 1990：聖吉《第五項修練》——學習型組織；系統思考；組織的學習障礙與自我超越。［[1990-聖吉第五項修練.md](1990-聖吉第五項修練.md)］

### 六、重造與迭代：從企業改造到精實創業（1993–2011）

- 1993：漢默與錢皮《企業改造》——流程再造；「忘掉你懂的一切」；資訊科技下手術刀與裁員的爭議。［[1993-漢默與錢皮企業改造.md](1993-漢默與錢皮企業改造.md)］
- 2001：敏捷宣言——十七名程式設計師在猶他滑雪場；個體與互動高於流程與工具；軟體危機的民間革命。［[2001-敏捷宣言.md](2001-敏捷宣言.md)］
- 2005：金偉燦與莫伯尼《藍海策略》——價值創新、四項行動框架；不打競爭的戰略學反叛（→直接頂撞1980年的波特！）。［[2005-金偉燦藍海策略.md](2005-金偉燦藍海策略.md)］
- 2011：艾瑞克·萊斯《精實創業》——最小可行產品MVP、建構—量度—學習、軸轉；新創的科學管理。［[2011-精實創業.md](2011-精實創業.md)］

### 七、反馴的時代：遠距、平台與靜默離職（2020–2022）

- 2020：疫情與遠距工作——辦公室法典一夜作廢；管理從監督變成輸出契約；管理學的重構壓力測試。［[2020-遠距工作與管理重構.md](2020-遠距工作與管理重構.md)］
- 2022：靜默離職——不做超出工資的事；大離職潮的餘波；「組織如何被馴服」的反向判詞。［[2022-靜默離職與管理學反思.md](2022-靜默離職與管理學反思.md)］

## 偵探的結案陳詞

兩百五十年的管理學史，可以壓縮成三條因果鏈：

1. **枷鎖鏈**：分工（動作可切！）→ 計時（動作可量！）→ 工序（人可被帶走！）→ 職能（管理可教！）→ 戰略（組織可佈局！）→ 文化（管理有國籍！）→ 迭代（計畫可放棄！）——**每一道新枷鎖，重馴一次組織**。
2. **人物鏈**：解剖者（斯密巴貝奇！）→ 量度者（泰勒福特！）→ 立法者（法約爾！）→ 傾聽者（霍桑巴納德！）→ 系統論者（德魯克麥格雷戈！）→ 歷史家（錢德勒！）→ 表格化者（安索夫波特！）→ 實證者（明茲伯格霍夫斯泰德！）→ 反叛者（大野聖吉敏捷！）——**先解剖，再量度，再聽人的聲音，再回頭拆自己的表格**。
3. **反抗鏈**：怠工（工廠制！）→ 罷工（科學管理！霍桑！）→ 知識工人（德魯克！）→ 扁平化（改造與敏捷！）→ 零工與遠距（平台！）→ 靜默離職（最低限度執行！）——**馴服的技術越精密，反馴的武器也越精緻**。

三條鏈咬合在一起，就是本卷二十六樁案件的全部真相：管理學史的終極懸案不在公司裡，而在每一代工人與知識工作者口袋裡——**他們同意被管理的條件，一直在變**。
