# 1848-馬克思與恩格斯《共產黨宣言》：階級鬥爭的總起訴書

## 案件摘要

1848 年 2 月，**馬克思**（Karl Marx！30 歲！被三國先後驅逐的流亡哲學家！）與**恩格斯**（Friedrich Engels！曼徹斯特工廠主之子！共產主義者同盟委託起草！）在倫敦出版《共產黨宣言》。核心證詞：「**到目前為止的一切社會的歷史都是階級鬥爭的歷史**」（！自由民與奴隸、領主與農奴……！）——政治的被告席上坐的不是君主或制度，而是**生產方式的結構**。名句：「一個幽靈，共產主義的幽靈，在歐洲徘徊」；布爾喬亞「生產出自己的掘墓人」；結語「全世界無產者，聯合起來！」。這樁案件是**政治學物質基礎論的成典**（→政治被還原為經濟的函數——影響整個 20 世紀政治學與革命史！）。

## 前因 -- 多因素的局勢

- **工業革命的陣痛**：英德法工廠、童工、14 小時工作日（！恩格斯 1845《英國工人階級狀況》實地記錄曼徹斯特！）——**材料**。
- **1847 經濟危機**：歐洲糧荒與失業（→1848 革命浪潮的燃料！）。
- **工人運動**：憲章運動（英！）、西里西亞織工起義（1844！）——**讀者已存在**。
- **共產主義者同盟**：正義者同盟改組（倫敦！委託起草綱領！兩易其稿！）——**組織需求**。
- **思想資源**：黑格爾辯證法（翻轉！）、費爾巴哈唯物論、李嘉圖勞動價值論、法國社會主義——**四源合流**（→「哲學家只解釋世界，問題在於改變世界」1845 提綱！）。

## 線索與推理 -- 因素咬合

### 線索一：政治 = 上層建築的還原公式

$$\text{法律、國家、意識形態} = f(\text{（經濟基礎！）}) \Rightarrow \text{階級統治的組織化}$$

「現代國家政權不過是管理整個資產階級事務的委員會」（！最具爭議的單句！→此後「國家的階級性」成為百年戰場——達爾［[1961-達爾多元政體.md]］的多元主義正面迎擊！）

### 線索二：資產階級的自我革命——辯證的悖論

宣言對資產階級的讚美出乎意料（！「不斷革命化全部生產關係」「一切堅固的東西都煙消雲散」！）：

| 辯證環節 | 內容 |
|----------|------|
| 破壞 | 資產階級摧毀封建秩序（進步！） |
| 集中 | 生產與人口向城市集中（組織無產者！） |
| 危機 | 生產過剩的週期（！） |
| 掘墓 | 無產者「成為階級→成為政黨」（！） |

（→**敵人的勝利就是敵人的判決書**——宣言最精緻的邏輯結構！）

### 線索三：全球化的預言清單

世界市場（！）、城鄉對立消解、民族隔閡打破、週期危機——1848 年的清單在 20–21 世紀幾乎逐條對號（→預言力是它生命力的祕密！）。

## 破案時刻

- 1847-6：倫敦同盟大會（恩格斯起草草案！）。
- 1847-11：第二稿指令（「以宣言形式」！）。
- 1848-2-21 前後：《宣言》倫敦印行（23 頁小冊！）。
- 1848-2-22：巴黎革命爆發（！宣言與革命同週誕生！）。
- 1848–49：歐洲革命潮席捲→全部失敗（！馬克思轉向經濟學研究——1859《政治經濟學批判》序言公布歷史唯物論正式版！）。
- 1871：巴黎公社（馬克思讚譽並修正「打碎國家機器」論！）。

## 後果 -- 改變了什麼

- **革命世紀**：1917 俄國、1949 中國……20 世紀近半人口在其旗幟下生活（→理論影響力的最大值！）。
- **社會科學**：階級分析、歷史唯物論、批判理論——政治學與社會學的永久工具箱（→即使反馬克思者也在與他對話！）。
- **福利與勞動法**：資本主義國家的讓步部分是「防掘墓」工程（→宣言的反面催生劑！）。
- **爭議**：極權體制以其之名建立（！馬克思死前自稱「不是馬克思主義者」的傳聞——理論與實踐的著名分裂！）。

**偵探結語**：《宣言》的偵探手法是**把被告從個人換成結構**：不是誰在剝削，而是什麼結構必然產生剝削。它以 23 頁完成三件大事——還原政治的物質基礎、讚美並判決資產階級、向全世界發出組織令。無論你是接受還是駁斥「階級鬥爭史觀」，都無法繞開它提出的問題：**政治鬥爭的深層是不是經濟利益的鬥爭？**二十世紀的政治學就是這個問題的實驗場；而宣言對全球化的逐條預言，仍是它最令人不安的段落。
