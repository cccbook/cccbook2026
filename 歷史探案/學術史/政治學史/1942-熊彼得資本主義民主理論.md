# 1942-熊彼得《資本主義、社會主義與民主》：菁英競爭的民主定義

## 案件摘要

1942 年，哈佛經濟學家**熊彼得**（Joseph Schumpeter！奧地利出生！財政部長背景！企業家精神理論的作者！）出版《資本主義、社會主義與民主》。核心炸彈是第 21–23 章：**古典民主理論死刑判決**——「人民的意志」不是民主的起點，因為人民根本無法形成一致意志（！意志是被製造出來的！廣告與宣傳可塑造！）；民主只能**從方法上定義**：「**為了爭取人民選票而競爭政治決策權的制度安排**」（！民主＝市場競爭＋菁英！投票者「選人」而非「決策」！）。資本主義正在自我毀滅（！企業家精神官僚化！知識分子批判！），社會主義可以行得通（！但他個人未必贊成！）。這樁案件是**極簡民主定義（minimal definition）的誕生**（→20 世紀民主測量與比較政治的語法！）

## 前因 -- 多因素的局勢

- **兩次大戰間的民主危機**：魏瑪崩潰（1933！）、法西斯席捲（→「民主意志」被希特勒動員的恐怖實例！）——**理論動機**。
- **經濟學的理性批判**：熊彼得的企業家理論（創新＝非常規行為！）——**方法資產**（→把企業家競爭模型平移到政治市場！）。
- **芝加哥的流亡學者圈**：熊彼得 1932 移居哈佛——**寫作環境**。
- **古典民主論的困境**：盧梭式公意、密爾式公民學校［[1861-密爾代議政府.md]］在大眾社會失效（！選民無知！政治冷漠！現實投票行為研究揭示！）。
- **1930s 輿論研究**：李普曼《幻影公眾》1925——**思想前導**。

## 線索與推理 -- 因素咬合

### 線索一：拆解「人民意志」

四個經典命題逐一爆破：

| 古典命題 | 熊彼得的反駁 |
|----------|--------------|
| 存在共同福祉 | 價值因人而異（！） |
| 人民能形成共同意志 | 意志是群體心理的產物（！可被操縱！） |
| 意志→政策 | 實際是領袖製造意志（！） |
| 選票 = 理性決策 | 選民「集體非理性」（！） |

（→結論：倒轉因果——**先有競爭的菁英，才有人民的選擇**！）

### 線索二：民主的極簡公式

$$\text{民主} = \text{（菁英！）} \times \text{（選票競爭！）} \Rightarrow \text{授權（！但僅授權！）}$$

「民主不是也不能是人民統治，它是**人民在互相競爭的領袖之間做選擇**」——（→授權說：投票是委託，不是指揮！）

### 線索三：資本主義的自毀方程

創新→大企業研發常規化（企業家精神消亡！）→ 知識分子批判階層壯大 → 資本主義的政治正當性流失（！→社會主義接管——他的預言錯了，但機理分析常被引用！）

## 破案時刻

- 1919：熊彼得任奧地利財政部長（！短命！）。
- 1932：移居哈佛。
- 1939：《經濟週期》——景氣循環工程完成。
- 1942：《資本主義、社會主義與民主》出版（！）。
- 1950：去世；《資本主義》第三版補「兩張口訣」——「創造性毀滅」的定音。
- 1956–71：達爾、唐斯、羅肯分別修正並發揚「競爭模型」（→民主經驗理論的擴散期！）。

## 後果 -- 改變了什麼

- **民主經驗理論**：達爾的多元政體（polyarchy！［[1961-達爾多元政體.md]］）、唐斯選票市場［[1957-唐斯民主的經濟理論.md]］、民主測量（！Polity、V-Dem 的「競爭＋參與」二維皆可溯源！）。
- **選舉研究**：投票行為研究的方法論合法性（→密西根學派！）
- **批判**：把民主降為選舉（！無視參與、審議、平等——帕特南與參與民主論的反擊、魯拉「選舉式民主」的空洞化指控！）。
- **企業與創新**：「創造性毀滅」成為創新經濟學核心（→科技政策、平台經濟的語言！）。

**偵探結語**：熊彼得的偵探手法是**把民主的浪漫假設逐一驗傷**：共同福祉不存在、人民意志可被製造、選民集體非理性——那麼民主還剩下什麼？剩下的是一場乾淨的競爭：菁英出價，選民換票。這個冷酷的定義成為 20 世紀民主科學的地基——今日所有「民主指數」背後，都是 1942 年那個極簡公式。但它同時留下永遠的爭議：**如果民主只是選舉，那麼靠選舉上臺的暴君算不算民主？**這個問題要到選舉威權主義研究（2010）才算真正開庭。
