# 政治學史 -- AI 偵探風格

以「推理探案」的方式，追查政治學史上的重大轉折：克利斯提尼的部落詐術、柏拉圖的哲學王、亞里斯多德的一百五十八部憲法、波利比烏斯的混合憲政、大憲章的封印、馬基維利的權術、博丹的主權、霍布斯的利維坦、洛克的同意、孟德斯鳩的三權、盧梭的公意、費城的全國大會、柏克與潘恩的世紀對決、托克維爾的美國、馬克思的宣言、密爾的代議、白芝浩的尊嚴與效率、威爾遜的行政國家、拉斯韋爾的誰得到什麼、熊彼得的菁英競爭、達爾的誰統治、唐斯的選票市場、羅爾斯的無知之幕、哈耶克的奴役之路、沃澤爾的正義諸領域、福山的歷史終結、選舉威權主義、數位威權與極化——
前因是什麼？線索在哪裡？推理如何展開？後果又如何改寫了權力史？

本卷的核心命題只有一句話：**政治學史是「權力如何被設計」的偵辦史。**
每一樁案件都是一次權力的再設計：**誰統治**（一人？少數？多數？）、**憑什麼**（血統？武力？同意？公意？選票？）、**如何防止濫權**（混合！分立！制衡！問責！）、**權力的真相是什麼**（壓迫？交換？操縱？演算法？）。政治學從希臘的城邦法庭一路開到數位時代的演算法法庭，但被告始終只有一位：**不受約束的權力**。每個重大轉折都是一樁「多因懸案」：偵探的工作，就是把因素鏈一環一環還原出來。

（涵蓋：克利斯提尼、柏拉圖、亞里斯多德、波利比烏斯、大憲章、馬基維利、博丹、霍布斯、洛克、孟德斯鳩、盧梭、費城制憲、柏克、潘恩、托克維爾、馬克思、密爾、白芝浩、威爾遜、拉斯韋爾、熊彼得、達爾、唐斯、羅爾斯、哈耶克、沃澤爾、福山、選舉威權主義、數位威權）

## 權力的迴響迴路

```
       ┌────（時代危機：內戰、革命、戰爭、經濟崩潰、技術革命）────┐
       ↓                                                      ↓
 舊政體 ──→ 合法性危機 ──→ 新理論 ──→ 新制度 ──→ 制度化 ──→ 新問題
   │            ↑          ↑                     │
   │            │          │                     ↓
   └──→ 暴力鎮壓/流亡 ←── 傳播（印刷、選舉、憲法抄襲）←── 反叛
       ↑                              ↑
       └── 經濟—技術（印刷機、報紙、電視、網路、AI）┘

   正向迴路（加速）：新理論→新憲法→示範效應→更多制憲
   正向迴路（加速）：危機→集權→濫權→反集權理論→新制衡
   負向迴路（抑制）：鎮壓→地下流通（君王論死後出版、宣言被禁、薩米亞特）
   偵探迴路（本卷特有）：危機→理論→制度→副作用→新危機
```

**偵探的訣竅**：找到「誰在統治、憑什麼、被誰挑戰、用了什麼制度工具」，把鏈條畫出來；再問一句——**被告是誰（僭主？國王？多數？資本？演算法？）？**案件的因果鏈就浮現了。
