# 1861-密爾《代議政府》：參與與能力的平衡術

## 案件摘要

1861 年，**約翰·斯圖亞特·密爾**（John Stuart Mill！東印度公司職員出身！史上最著名的父職教育實驗品！議員 1865–68！）出版《代議制政府》（Considerations on Representative Government）。核心證詞：政府優劣的判準有二——**運作得好不好**＋**能否提升公民的品質**（！第二條是密爾的獨門標準——政府是「品格的學校」！）。他為**代議制**辯護（！直接民主在大國不可行！），同時裝上雙重保險：**參與**（地方自治！陪審！——公民學校！）與**能力**（知識階層複數票！比例代表制！婦女選舉權！）。這樁案件是**自由主義民主制度論的完成式**（→民主從「危險物」轉為「可工程化體制」的轉捩點！）。

## 前因 -- 多因素的局勢

- **英國選舉改革壓力**：1832 改革法案後選民仍僅約 18%（！憲章運動六請願、1867 第二次改革法在即！）——**時刻問題**。
- **《論自由》的先行**：1859 剛出版（！防「多數的暴政」——直接引托克維爾［[1835-托克維爾論民主.md]］！）——**理論前置**。
- **密爾的東印度公司經驗**：35 年治理殖民地的行政訓練（！他深知「無能的政府」長什麼樣！）。
- **功利主義的修正**：從邊沁的「算術」到密爾的「質量」（！快樂有高低級之分——能力論的哲學根！）
- **婦女議題**：1861 同年寫作《婦女的從屬地位》——**同時代的平等議程**。

## 線索與推理 -- 因素咬合

### 線索一：雙重判準——效率 × 品格

$$\text{良善政府} = \text{（事務辦得好！）} + \text{（公民被提升！）} \Rightarrow \text{代議制雖慢但教育公民}$$

（→「人民參與公共事務，即使手續繁瑣，也勝過最有效率的專制」——政治教育論的定音錘！）

### 線索二：代議制的四大病與密爾的藥方

| 病 | 藥方 |
|----|------|
| 愚昧代表 | 知識階層**複數票**（！受教育者多票——最被後世詬病的方案！） |
| 階級立法 | **比例代表**（Hare 制！托馬斯·黑爾的發明！密爾盛讚） |
| 一窩蜂多數 | 議院內反對派的功能（「魔鬼辯護人」常設化！） |
| 行政弱化 | 議會只監督不施政（！部長專業化——→威爾遜［[1887-威爾遜行政學研究.md]］行政二分的先聲！） |

### 線索三：參與的學校——地方與陪審

全國層面代議、地方層面**直接參與**（鄉村評議會、陪審團——→托克維爾方案的吸收！）：

$$\text{公民能力} = \text{（全國代議！）} + \text{（地方參與！）} \times \text{（義務任職！）}$$

## 破案時刻

- 1832：第一次改革法案（密爾年輕時的辯論現場！）。
- 1848：《政治經濟學原理》（社會改革思路成形！）。
- 1859：《論自由》（個人自由的憲章！同期寫作代議的草稿！）。
- 1861：《代議制政府》成書（Conservative 先在期刊發表！）。
- 1865：密爾當選議員（！把理論帶入現場：倡議婦女選舉權、代表工人選區！）。
- 1867：第二次改革法案（城市工人獲得選票——密爾議場內為「人」對「男」投票奮戰（！206 票對 73 票落敗！）。

## 後果 -- 改變了什麼

- **代議民主理論**：選舉不只是選人，是**教育公民**——參與民主與菁英民主兩條路的共同起點（→熊彼得［[1942-熊彼得資本主義民主理論.md]］僅取「選舉」、參與論者僅取「教育」！）。
- **選舉制度設計**：比例代表制的哲學辯護（→今日 90+ 國家採用某種 PR！）。
- **婦女選舉權**：議會內第一位正式倡議者的文本基礎（1893 紐西蘭、1918 英國！）。
- **批判**：複數票的能力論被指「教育貴族制」（！等級選票在 1948 年才從英國徹底廢除——大學選區！）。


**偵探結語**：密爾的偵探姿勢是**同時握住兩個互相打架的證物**：民主需要人民的參與，但人民的判斷參差不齊。他的解法不是二選一，而是**分工**——全國選代議士、地方練公民、選票隨能力加權、席位按比例分配。複數票方案今天看來 elitist 得刺眼，但他的初衷是誠實的：**承認能力差異，又不取消政治平等，這是民主制度論永遠要付的帳**。1861 年的這份平衡術，至今仍是每個擴大選舉權的國家正在重算的算式。
