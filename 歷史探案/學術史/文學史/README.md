# 文學史 -- AI 偵探風格

以「推理探案」的方式，追查人類如何一步步把「說故事」從祭司的吟唱、宮廷的娛樂、教會的訓誡，變成印刷廠的商品、民族的旗幟、市場的暢銷書與世界的正典——
前因是什麼？線索在哪裡？推理如何展開？後果又如何改變了「誰有資格敘述世界」？

本卷的核心命題只有一句話：**文學的歷史，就是「敘事權如何被爭奪」的歷史。**
每個重大事件都是一樁「多因懸案」：技術（口傳、印刷、連載、平裝、電子書、網路）、社會（識字率、都市化、中產階級、女性讀者）、政治（審查、民族國家、帝國與後殖民）、市場（出版產業、暢銷書制度、文學獎與諾貝爾建制）——這些因素互相咬合。偵探的工作，就是把「文學為何在此時此地如此變形」的因素鏈一環一環還原出來：每一次形式革命（史詩、傳奇、小說、意識流、魔幻寫實），背後都是一次敘事權的轉手。

（涵蓋：荷馬口傳、詩經詩教、源氏物語、坎特伯里、古騰堡、烏托邦、莎士比亞、失樂園、魯濱遜、湯姆瓊斯、維特、科學怪人、惡之華與包法利、連載小說、王爾德審判、普魯斯特、尤利西斯、卡夫卡、卡繆、百年孤寂、摩里森、Kindle、網路文學、大型語言模型）

## 本卷的破案框架：六條主軸

| 主軸 | 問題 | 關鍵轉折 |
|------|------|----------|
| **口傳→書寫→複製** | 故事如何離開身體 | 荷馬吟唱 → 詩經采詩 → 源氏物語 → 古騰堡 → Kindle |
| **誰的語言** | 從聖典語言到民族語言 | 拉丁文的壟斷 → 但丁/喬叟/路德的方言起義 |
| **小說的誕生** | 誰買書、書寫誰 | 中產階級讀者 → 笛福 → 菲爾丁 → 連載工業 → 暢銷書制度 |
| **寫實與其反叛** | 文學該寫什麼 | 莫爾的虛構批評 → 寫實主義受審（波德萊爾/福樓拜）→ 現代主義（普魯斯特、喬伊斯、卡夫卡） |
| **帝國與後殖民** | 誰被允許說話 | 民族文學 → 存在主義 → 魔幻寫實 → 摩里森入正典 → 世界文學市場 |
| **作者之死與復活** | 誰在寫作 | 莎士比亞的集體劇場 → 作者成名的制度 → 網路同創 → LLM 2.0 |

## 案件卷宗（歷史年表）

### 一、口傳與書寫：敘事權的第一戰（前8世紀–10世紀）

- 約前8世紀：荷馬史詩定本——口傳吟唱被寫下，敘事第一次獲得「可重複的固定形體」。［[-0770-荷馬史詩與口傳傳統.md](-0770-荷馬史詩與口傳傳統.md)］
- 約前6世紀：詩經編定與孔子詩教——「采詩」制度把民間歌謠收編為教化文本，東方敘事權歸於禮樂。［[-0550-詩經與孔子詩教.md](-0550-詩經與孔子詩教.md)］
- 約前500–前300：希臘悲劇與戲劇競賽——神話成為城邦的公共辯論；亞里斯多德《詩學》為文學立法。
- 1世紀：紫式部之前的世界——中國《史記》確立紀傳傳統；羅馬維吉爾《埃涅阿斯紀》為帝國寫神話。
- 4世紀：紫式部的遠因——手抄本文化、女房文學、物語傳統在平安宮廷累積。
- 1008：《源氏物語》——世界最早的長篇心理小說，出自宮廷女性之手。［[1008-源氏物語.md](1008-源氏物語.md)］

### 二、方言起義與印刷革命（11–16世紀）

- 11–12世紀：《源氏物語繪卷》與平曲——文學從文本回流為表演與圖像。
- 1304–1321：但丁《神曲》以托斯卡尼語寫成——方言對拉丁文的正面起義。
- 1387：喬叟《坎特伯里故事集》——英語文學的起身，倫敦方言成為民族語言的胚種。［[1387-坎特伯里故事集.md](1387-坎特伯里故事集.md)］
- 1450：古騰堡活字印刷——文本複製成本崩跌，敘事權從抄寫僧侶轉向出版商。［[1450-古騰堡印刷術.md](1450-古騰堡印刷術.md)］
- 1516：莫爾《烏托邦》——虛構作為社會批評的形式實驗，人文主義的暗門。［[1516-烏托邦.md](1516-烏托邦.md)］
- 1522：路德德文聖經——印刷與方言合流，民族語言的標準化。
- 1557：倫敦書商公會獲得出版特許——審查與市場同時建制化。
- 1600–1601：莎士比亞《哈姆雷特》——公共劇場的世俗敘事高峰，演員取代教士佔領城市。［[1600-莎士比亞劇場.md](1600-莎士比亞劇場.md)］

### 三、小說的誕生與立法（17–18世紀）

- 1667：彌爾頓《失樂園》——古希臘式史詩的最後一次偉大嘗試，也是史詩的終結。［[1667-失樂園.md](1667-失樂園.md)］
- 1670s：法國沙龍與女性書信傳統——拉法耶特夫人《克萊芙王妃》(1678)，心理小說的伏筆。
- 1687–1704：洛克經驗論與報刊興起——《閒談者》《旁觀者》(1709–1711) 訓練出第一批期刊讀者。
- 1719：笛福《魯濱遜漂流記》——小說以「真實記述」的偽裝誕生，中產階級讀者上場。［[1719-魯濱遜漂流記.md](1719-魯濱遜漂流記.md)］
- 1749：菲爾丁《湯姆瓊斯》——小說為自己立法：敘事結構、全知敘述者、作者的自覺。［[1749-湯姆瓊斯.md](1749-湯姆瓊斯.md)］
- 1750s：流通圖書館興起——租書制度讓女性讀者成為文學市場的主力軍。
- 1774：歌德《少年維特的煩惱》——暢銷書的誕生與「維特熱」，情感商品化的第一案。［[1774-少年維特的煩惱.md](1774-少年維特的煩惱.md)］

### 四、寫實主義與其審判（19世紀）

- 1798：華茲華斯與柯勒律治《抒情歌謠集》——浪漫主義宣言，「詩是強烈情感的自然流露」。
- 1818：瑪麗雪萊《科學怪人》——科幻的誕生，工業時代的創傷寓言。［[1818-科學怪人.md](1818-科學怪人.md)］
- 1830s：巴爾札克《人間喜劇》與都市報刊——寫實主義的系統工程開工。
- 1857：波德萊爾《惡之華》受審與福樓拜《包法利夫人》被訴——現代性美學與寫實主義同時出庭。［[1857-惡之華與包法利夫人.md](1857-惡之華與包法利夫人.md)］
- 1859：狄更斯《雙城記》——連載小說工業的成熟，文學成為週期性商品。［[1859-雙城記與連載小說工業.md](1859-雙城記與連載小說工業.md)］
- 1862：雨果《悲慘世界》——國際暢銷書與翻譯市場成形。
- 1890s：廉價平裝、鐵道書報攤與大眾雜誌——福爾摩斯與偵探小說的大眾市場。
- 1895：王爾德審判——文學與道德的法庭對決，「為藝術而藝術」的敗訴與勝利。［[1895-王爾德審判.md](1895-王爾德審判.md)］

### 五、現代主義與存在主義（20世紀前半）

- 1899：佛洛伊德《夢的解析》——潛意識成為文學的新礦脈。
- 1913：普魯斯特《追憶似水年華》首卷自費出版——意識流與時間的考古學。［[1913-追憶似水年華.md](1913-追憶似水年華.md)］
- 1922：喬伊斯《尤利西斯》在巴黎出版——現代主義的爆炸，倫敦紐約查禁、巴黎印行。［[1922-尤利西斯.md](1922-尤利西斯.md)］
- 1925：卡夫卡《審判》遺作出版——官僚現代的寓言，死後建檔的文學。［[1925-審判.md](1925-審判.md)］
- 1925：吳爾芙《戴洛維夫人》、艾略特《荒原》餘波——意識流與碎片詩學的正典化。
- 1933：納粹焚書——審查的極端形態，流亡文學與「被燒掉的書單」成為道德檔案。
- 1947：卡繆《異鄉人》——存在主義文學，荒謬成為戰後世代的共同語言。［[1947-異鄉人.md](1947-異鄉人.md)］
- 1948：歐威爾《一九八四》——冷戰文學與政治寓言的全球市場。

### 六、後殖民、世界文學與數位時代（1950–2026）

- 1955：拉美爆炸前夜——魯佛、卡彭鐵爾「神奇寫實」理論與波西米亞小雜誌網絡。［[1955-拉美爆炸前夜.md](1955-拉美爆炸前夜.md)］
- 1967：馬奎斯《百年孤寂》——魔幻寫實的爆炸年，後殖民敘事奪回詮釋權。［[1967-百年孤寂.md](1967-百年孤寂.md)］
- 1970s–80s：諾貝爾文學獎擴張——奈波爾、馬奎斯（1982）、索因卡（1986，非洲首位）——世界文學建制改版。
- 1984：昆德拉《生命中不能承受之輕》——流亡作家與全球文學市場的合流。
- 1993：童妮·摩里森獲諾貝爾文學獎——美國非裔文學正式入正典。［[1993-摩里森諾貝爾獎.md](1993-摩里森諾貝爾獎.md)］
- 2007：Kindle 問世——電子書與「圖書館在手掌上」，出版產業的再洗牌。［[2007-Kindle與電子書.md](2007-Kindle與電子書.md)］
- 2012：起點中文網簽約制度與 AO3 創立——網路文學與同人社群，作者與讀者的界線溶解。［[2012-網路文學與同人社群.md](2012-網路文學與同人社群.md)］
- 2022：ChatGPT 問世——大型語言模型與文學創作，「作者之死 2.0」立案。［[2022-大型語言模型與文學創作.md](2022-大型語言模型與文學創作.md)］
