# 1861-梅因古代法：「從身分到契約」的一句話地質學

## 案件摘要

1861 年，英國法學家**梅因**（Henry Sumner Maine！）出版《古代法》（Ancient Law）——副標題「其與早期社會觀念的關係及與現代觀念的關係」（！）——開篇即挑戰布萊克斯通與孟德斯鳩式思辨：**要用比較與歷史的方法研究法律**（！）——書末留下一句被引用一百六十年的公式：**「迄今為止，進步社會的運動是一場從身分到契約的運動」**（from Status to Contract！）（！）——解釋羅馬法如何從家父權的凝固體系，經**擬制、衡平、立法**三個解放工具（！）走向現代：個人取代家族成為法律單位（！）——**法學的演化比較方法誕生**（！人類學式法學！），梅因成為**法律人類學與歷史社會學的創始人之一**（！）。

## 前因 -- 多因素的局勢

- **進化論氛圍**：達爾文《物種起源》1859（！）——**前一秒是物種，下一秒是制度**（→比較人種學、比較法學的時代精神！）。
- **英屬印度經驗**：梅因 1862 年後任印度法律委員（！本書成於其印度任職前後的長期積累！）——**親眼看到「活著的古代法」**（！村落共同體、種姓習慣！）。
- **薩維尼的傳染**：歷史方法經英國學界傳入（！）——**但梅因要的不止民族史，是普遍演化**（→見 [1814-薩維尼與歷史法學派.md](1814-薩維尼與歷史法學派.md)！）。
- **羅馬法學的英國缺口**：普通法律師不讀羅馬法（！）——**梅因用羅馬法做對照組**（！）。

## 線索與推理 -- 因素咬合

### 線索一：法律化石層——「判例裡埋著青銅時代」

梅因把古代法當**地質剖面**閱讀（！法律擬制＝化石間的堆積物！）：

$$\text{古代法} = \text{（家父權！）} \xrightarrow{\text{擬制！衡平！立法！}} \text{個人主義法}$$

**擬制**（！宣稱收養之子＝親生！法律假裝不變而實質改變！）——**第一個被命名的「法律變遷機制」**（！）。

### 線索二：身分→契約——「法律的單位從家族變成個人」

| 古代 | 現代 |
|------|------|
| 法律責任附著於家戶（！父債子償！） | 附著於個人（！） |
| 地位由出生決定（！） | 關係由合意創造（！） |
| 權利義務成束（！） | 可逐項交易（！） |

**單位的原子化＝現代法的地質事件**（！）——**社會學（滕尼斯！涂爾幹！）的機械/有機連帶在法律上的投影**（！）。

### 線索三：比較的剎車——「進化不是單行道」

梅因補充：停滯社會並非「落後」，而是**缺少解放工具**（！）——並警告**立法不能拔苗**（→與薩維尼同調！但他把「民族」換成「人類」——普遍化的歷史法學！）（！）。

## 破案時刻

- 1822：生於英國（！）。
- 1847：劍橋大學攝政法律講座（！）。
- 1850s：倫敦中殿律師學院講師＋《古代法》寫作（！）。
- 1861：《古代法》出版（！）。
- 1862–69：赴印度任法律委員（！）——親手起草法律（！）。
- 1869：任牛津首任比較法學講座（！）——**世界第一個比較法教席**（！）。
- 1871：《村落共同體》（！印度田野！）。
- 1888：逝於戛納（！）。

## 後果 -- 改變了什麼

- **法律人類學誕生**：梅因→摩爾根→馬林諾夫斯基、格拉克曼（！）——**用田野研究法律的學科樹根**（！）。
- **殖民立法學**：印度習慣法編纂（！）——**「活的法律」的官僚版本，也是同化工具**（→見 [1907-艾利希活的法律.md](1907-艾利希活的法律.md) 的對照！）。
- **社會理論**：從身分到契約→涂爾幹、滕尼斯、帕森斯的演化社會學（！）。
- **反面**：單線進化論被批（！馬林諾夫斯基：原始社會也有精密交換法！）；契約時代自身也衰變（！20 世紀福利法、僱傭法、格蘭特·吉爾莫「從契約到身分的回歸」！1975！）——**梅因的箭頭會掉頭**（！）。

**偵探結語**：梅因的破案手法是**把法典當化石層讀**：他在「收養擬制」與「家父權」裡讀出整個社會組織的地質史，然後用一句話壓縮成現代化的震央——**從身分到契約**（！）——一個詞組劃分了人類法律的兩個紀元（！）。但卷宗的後半本才是精華：二十世紀的僱傭法、消費者保護、反歧視法把「契約自由」重新塞回身分框架（！僱員！消費者！少數群體——都是新身分！）（）——**「從身分到契約」不是終點，是鐘擺**；每一代法學家都要重新回答：法律的基本單位，該是自由的人，還是被結構困住的人（→這個問題在數位時代以「使用者條款下的用戶」形式再度襲來！見 [1999-網路法與程式碼即法律.md](1999-網路法與程式碼即法律.md)！）。
