# 法學史 -- AI 偵探風格

以「推理探案」的方式，追查法學史上的重大轉折：十二銅表法的刻石、亞里斯多德的正義三分、羅馬法學家的解答權、查士丁尼的彙纂、格里高利七世的教皇革命、格拉提安的教令集、大憲章的正當程序、格勞秀斯的戰爭與和平、孟德斯鳩的法的精神、貝加利亞的刑罰計算、拿破崙法典、薩維尼的民族精神、邊沁的功利計算、梅因的身分到契約、蘭德爾的案例教學、霍姆斯的法律道路、艾利希的活法、龐德的社會工程、凱爾森的純粹體系、紐倫堡的法與不法、世界人權宣言、布朗案的能動、哈特與富勒的世紀對決、德沃金的權利牌、波斯納的價格、批判法學的拆解、萊斯格的代碼——
前因是什麼？線索在哪裡？推理如何展開？後果又如何改寫了正義史？

本卷的核心命題只有一句話：**法學史是「正義如何被制度化」的偵辦史。**
每一樁案件都在追問：**誰立法**（習俗？君王？教會？人民？法官？代碼？）、**法憑什麼有效**（神意？理性？民族精神？功利？預測？承認規則？）、**正義如何操作化**（程序！先例！法典！權利！成本！）、**法與道德的界線在哪裡**（分開！纏繞！重疊！）。被告始終只有一位：**不義的裁決**——而兇手經常就是法律自己（惡法！合法的不義！）每個重大轉折都是一樁「多因懸案」：偵探的工作，就是把因素鏈一環一環還原出來。

（涵蓋：十二銅表法、亞里斯多德、羅馬法學、查士丁尼、格里高利七世、格拉提安、大憲章、格勞秀斯、孟德斯鳩、貝加利亞、拿破崙法典、薩維尼、邊沁、梅因、蘭德爾、霍姆斯、艾利希、龐德、凱爾森、紐倫堡、世界人權宣言、布朗案、哈特、富勒、德沃金、波斯納、批判法學、萊斯格）

## 正義的迴響迴路

```
       ┌────（時代危機：內戰、革命、戰爭、殖民、技術革命）────┐
       ↓                                                     ↓
 舊秩序 ──→ 不義事件 ──→ 新學說 ──→ 新法典/新判決 ──→ 制度化 ──→ 新問題
   │           ↑         ↑                        │
   │           │         │                        ↓
   └──→ 法外暴力/私刑 ←── 傳播（法典繼受、判例引用、教科書）←── 平反
       ↑                             ↑
       └── 經濟—技術（印刷、契約經濟、工業、網路、AI）┘

   正向迴路（加速）：新學說→新立法→繼受→全球法典化
   正向迴路（加速）：冤案→平反運動→新權利→新審查
   負向迴路（抑制）：惡法→惡法亦法之辯→自然法復活→超越實證的標準
   偵探迴路（本卷特有）：不義→理論→制度→副作用→新不義
```

**偵探的訣竅**：找到「誰在立法、憑什麼有效、誰被排除、誰來執行」，把鏈條畫出來；再問一句——**這條法對誰不義（奴隸？婦女？工人？殖民地人民？被告？用戶？）？**案件的因果鏈就浮現了。

## 案件卷宗（歷史年表）

### 一、古代：法從習俗到條文（-0450 -- 0533）

- -0450：十二銅表法——十人委員會刻石；成文法對祭司與貴族知識壟斷的爆破；同罪不同罰的裂痕。［[-0450-十二銅表法.md]］
- -0350：亞里斯多德論正義——分配與矯正的幾何學；自然法與人定法的分岔；衡平（epieikeia）對普遍規則的救援。［[-0350-亞里斯多德論正義.md]］
- 0533：查士丁尼法典彙纂——《學說彙纂》五萬三千條片段；帝國獨占法律解釋權；羅馬法千年沉船被封箱。［[0533-查士丁尼法典彙纂.md]］

### 二、中世紀：法學作為職業的誕生（1076 -- 1215）

- 1076：教皇革命與格里高利七世——《教皇敕令》；教權俗權決裂；「西方第一場革命」與法系統的自立。［[1076-教皇革命與格里高利七世.md]］
- 1140：格拉提安教令集——《矛盾教令之調和》；博洛尼亞經院註釋；法學成為大學學科。［[1140-格拉提安教令集.md]］
- 1215：大憲章與正當程序——蘭尼米德草地；第 39 條「同儕審判＋國法」；國王之上還有法律。［[1215-大憲章與正當程序.md]］

### 三、近代早期：戰爭、理性與啟蒙（1625 -- 1764）

- 1625：格勞秀斯《戰爭與和平法》——即使上帝不存在自然法仍有效；萬民法到國際法；三十年戰爭中的秩序藥方。［[1625-格勞秀斯戰爭與和平法.md]］
- 1748：孟德斯鳩《論法的精神》——法律是社會的指紋；三權分立；以權力約束權力。［[1748-孟德斯鳩論法的精神.md]］
- 1764：貝加利亞《論犯罪與刑罰》——刑罰的功利計算；罪刑法定；反對酷刑與死刑；現代刑法學的出生證明。［[1764-貝加利亞論犯罪與刑罰.md]］

### 四、十九世紀：法典、民族與科學（1804 -- 1897）

- 1804：拿破崙法典——民法典的工程學；所有權神聖與契約自由；大陸法系的世界擴散。［[1804-拿破崙法典.md]］
- 1814：薩維尼《立法與法學的使命》——反對倉促法典化；法是民族精神的自然生長；歷史法學派成立。［[1814-薩維尼立法與法學的使命.md]］
- 1832：邊沁法理學——《法律概論》體系；功利原理；自然權利是「踩在高蹺上的胡說」；法典化與法律改革。［[1832-邊沁法理學.md]］
- 1861：梅因《古代法》——「從身分到契約」；法律擬制、衡平、立法的演化三式；法學的歷史比較方法。［[1861-梅因古代法.md]］
- 1881：蘭德爾與案例教學法——哈佛案例法；合同法案例集；形式主義的科學夢。［[1881-蘭德爾與案例教學法.md]］
- 1897：霍姆斯「法律的道路」——法律是對法院將做什麼的預測；法與道德分家；經驗主義的宣言。［[1897-霍姆斯法律的道路.md]］

### 五、二十世紀前半：社會、體系與廢墟（1907 -- 1948）

- 1907：艾利希「活的法律」——紙上的法與行動中的法；法在聯合體裡生長；法律社會學的奠基。［[1907-艾利希活的法律.md]］
- 1917：龐德社會法學——法律是社會工程的工具；法律在書本與行動中；利益衡量。［[1917-龐德社會法學.md]］
- 1934：凱爾森純粹法學——法體系的自足塔；基本規範；法與道德、政治、社會學的徹底切割。［[1934-凱爾森純粹法學.md]］
- 1945：紐倫堡審判——「執行命令」不是抗辯；惡法亦法體系的崩塌；違反和平罪與反人道罪的創設。［[1945-紐倫堡審判.md]］
- 1948：世界人權宣言——無國籍難民起草的權利清單；自然法的世界版；國際人權法的起點。［[1948-世界人權宣言.md]］

### 六、當代：權利、方法與代碼（1954 -- 1999）

- 1954：布朗案——「分離但平等」被判違憲；社會科學進入法庭；司法能動的爭議起點。［[1954-布朗案與司法能動.md]］
- 1961：哈特《法律的概念》——承認規則；法律體系的核心與陰影；法實證主義的重建。［[1961-哈特法律的概念.md]］
- 1964：富勒《法律的道德性》——八項合法性原則；法治的內在道德；哈特—富勒論戰的正面決戰。［[1964-富勒法律的道德性.md]］
- 1973：德沃金《認真對待權利》——權利是王牌；赫拉克勒斯法官；原則與政策的分野。［[1973-德沃金認真對待權利.md]］
- 1973：波斯納《法律的經濟分析》——普通法的效率邏輯；財富最大化；成本收益進入法學。［[1973-波斯納法律的經濟分析.md]］
- 1986：批判法學運動——法律是不確定的政治；形式主義的拆解；權利批判與轉化。［[1986-批判法學運動.md]］
- 1999：萊斯格《網路法》——代碼即法律；網路的可規制性；四種約束力（法、規範、市場、架構）。［[1999-萊斯格網路法.md]］
