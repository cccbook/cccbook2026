# 法學史 -- AI 偵探風格

以「推理探案」的方式，追查法學史上的重大轉折：十二銅表法的青銅、亞里士多德的正義算術、查士丁尼的彙纂工程、教皇革命的法典化、格拉提安的調和術、大憲章的正當程序、格勞秀斯的萬國法、孟德斯鳩的法之精神、貝加利亞的刑罰算盤、拿破崙法典的理性化、薩維尼的民族精神、邊沁的功利測量、梅因的「從身分到契約」、蘭德爾的案例教學、霍姆斯的預測論、艾利希的活的法律、韋伯的理性化、凱爾森的純粹規範、紐倫堡的惡法非法、世界人權宣言、布朗案的司法能動、哈特的承認規則、富勒的合法性八原則、德沃金的權利王牌、波斯納的財富最大化、批判法學的拆解、萊斯格的「程式碼即法律」、數位時代的隱私與平台——
前因是什麼？線索在哪裡？推理如何展開？後果又如何改寫了正義史？

本卷的核心命題只有一句話：**法學史是「正義如何被制度化」的偵辦史。**
每一樁案件都在追問同一組問題：**正義由誰宣布**（祭司？國王？法官？人民？程式碼？）、**憑什麼**（習慣？神意？理性？主權？民意？效率？）、**如何被寫下**（口訣？銅表？法典？判例？條款與條件？）、**寫下之後誰來解釋**（法學家！教會！學院！最高法院！平台！）——而被告始終只有一位：**不受節制的裁斷權**。法學從羅馬廣場上的銅表一路開到雲端的使用者條款，但每個重大轉折都是一樁「多因懸案」：偵探的工作，就是把「暴力 → 儀式 → 文字 → 學問 → 職業 → 官僚 → 權利 → 程式」的鏈條一環一環還原出來。

（涵蓋：十二銅表法、亞里士多德、查士丁尼、教皇革命、格拉提安、大憲章、格勞秀斯、孟德斯鳩、貝加利亞、拿破崙法典、薩維尼、邊沁、梅因、蘭德爾、霍姆斯、艾利希、韋伯、凱爾森、紐倫堡、世界人權宣言、布朗案、哈特、富勒、德沃金、波斯納、批判法學、萊斯格、數位監管）

## 正義的審判庭：八種法庭如何回答「什麼是法律」

| 法庭 | 核心問題 | 經典案例 |
|------|----------|----------|
| **成文** | 誰把法律寫下來？寫給誰看？ | 十二銅表法；查士丁尼彙纂；拿破崙法典 |
| **正義理論** | 公正是什麼算術？ | 亞里士多德分配與矯正正義；貝加利亞罪刑均衡 |

## 正義的迴響迴路

```
     ┌────（時代危機：階級鬥爭、宗教戰爭、革命、大戰、技術革命）────┐
     ↓                                                      ↓
暴力裁斷 ──→ 成文化 ──→ 學問化（法學院！）──→ 職業化 ──→ 官僚化 ──→ 新問題
   │           ↑          ↑                     │
   │           │          │                     ↓
   └──→ 私力復仇/暴亂 ←── 傳播（銅表、印刷、法典輸出、判例資料庫）←── 不滿
       ↑                              ↑
       └── 經濟—技術（商業、印刷機、鐵路、電腦、網路、平台）┘

  正向迴路（加速）：成文→解釋→註釋層疊→再彙纂（查士丁尼→註釋學派→拿破崙！）
  正向迴路（加速）：暴行→審判→規範升級（紐倫堡→人權宣言→國際刑事！）
  負向迴路（抑制）：惡法→抗命→惡法非法論（安提戈涅→索雷爾→紐倫堡！）
  偵探迴路（本卷特有）：寫法→釋法→活法偏離→再立法
```

**偵探的訣竅**：找到「誰裁斷、依據什麼、寫在哪裡、被誰解釋、偏離到哪裡」，把鏈條畫出來；再問一句——**被判的到底是行為還是身分？（！從身分到契約，再從契約到演算法評分？）**案件的因果鏈就浮現了。

## 案件卷宗（歷史年表）

### 一、古代：把正義刻在銅上（-0450 -- -0034）

- -0450：十二銅表法——平民與貴族的十人委員會；法第一次公開成文；口訣與殘暴並存。［[-0450-十二銅表法.md]］
- -0350：亞里士多德論正義——《尼各馬科倫理學》第五卷；分配與矯正正義；衡平對法律的救濟。［[-0350-亞里士多德論正義.md]］
- -0034 前：羅馬法學家的裁判官告示與答復權（！蓋尤斯、烏爾比安的基礎）——**本卷未單獨成篇，散見各案**。

### 二、中世紀：羅馬的復活與教會的法典（0533 -- 1215）

- 0533：查士丁尼法典彙纂——《學說彙纂》五十卷；羅馬法的打包封存；千年後被再發現。［[0533-查士丁尼法典彙纂.md]］
- 1076：教皇革命與教會法——格里高利七世《教皇敕令》；教俗分離催生西方第一套跨國法體系。［[1076-教皇革命與教會法.md]］
- 1076：教皇革命與格里高利七世——卡諾莎之行的對峙細節；沃爾姆斯協定與兩把劍的憲政化。［[1076-教皇革命與格里高利七世.md]］
- 1140：格拉提安教令集——《調和矛盾的教令》；經院方法進入法律；法學院（波隆那！）的誕生。［[1140-格拉提安教令集.md]］
- 1215：大憲章與正當程序——蘭尼米德；第 39 條「同儕之審與國法」；程序正義的種子。［[1215-大憲章與正當程序.md]］

### 三、近代早期：自然法與啟蒙的測量（1625 -- 1764）

- 1625：格勞秀斯《戰爭與和平法》——萬國法；即使上帝不存在自然法也有效（！）；國際法的出生證明。［[1625-格勞秀斯戰爭與和平法.md]］
- 1748：孟德斯鳩《論法的精神》——法律是社會因素的函數；三權分立；比較法方法的誕生。［[1748-孟德斯鳩論法的精神.md]］
- 1764：貝加利亞《論犯罪與刑罰》——刑罰的功利算術；罪刑法定；反對酷刑與死刑（！二十六歲寫成）。［[1764-貝加利亞論犯罪與刑罰.md]］

### 四、革命與法典化：理性的編纂（1804 -- 1832）

- 1804：拿破崙法典——《法國民法典》；公民平等的統一私法；法典輸出到全世界。［[1804-拿破崙法典.md]］
- 1814：薩維尼與歷史法學派——《論立法與法學的當代使命》；反對倉促立法；法是民族精神的產物。［[1814-薩維尼與歷史法學派.md]］
- 1814：薩維尼《論立法與法學的使命》——對決蒂鮑的原始卷宗；法學者階層與 BGB 的長線工程。［[1814-薩維尼立法與法學的使命.md]］
- 1832：邊沁的法理學——「自然權利是胡說」；功利原理與法典化；解剖學式立法學。［[1832-邊沁法理學.md]］

### 五、十九世紀：法成為科學與職業（1861 -- 1913）

- 1861：梅因《古代法》——「從身分到契約」；法學的演化比較方法；擬制、衡平、立法三部曲。［[1861-梅因古代法.md]］
- 1881：蘭德爾與案例教學法——《合同法案例集》；哈佛法學院的案例方法；法學院成為專業堡壘。［[1881-蘭德爾與案例教學法.md]］
- 1897：霍姆斯「法律的道路」——法律是對法院將怎麼判的預測；經驗而非邏輯；美國法律現實主義的起點。［[1897-霍姆斯法律的道路.md]］
- 1907：艾利希「活的法律」——《法的發現》；書本上的法 vs 行動中的法；法社會學宣言。［[1907-艾利希活的法律.md]］
- 1913：韋伯法律社會學——《經濟與社會》；形式理性法；法律家與資本主義的共生。［[1913-韋伯法律社會學.md]］
- 1917：龐德社會法學——「法是社會工程的工具」；利益衡量；書本上的法與行動中的法。［[1917-龐德社會法學.md]］

### 六、二十世紀：規範、暴行與權利（1934 -- 1964）

- 1934：凱爾森純粹法學——《純粹法理論》；排除一切非規範因素；基本規範的先驗假設。［[1934-凱爾森純粹法學.md]］
- 1945：紐倫堡審判——「執行命令不是辯護」；惡法非法的法庭測試；國際刑法誕生。［[1945-紐倫堡審判.md]］
- 1948：世界人權宣言——《聯合國憲章》之後；三十條；非拘束文件的道德爆炸力。［[1948-世界人權宣言.md]］
- 1954：布朗案與司法能動——「隔離但平等」被判違憲；社會科學進法庭；司法審查的能動時刻。［[1954-布朗案與司法能動.md]］
- 1961：哈特《法律的概念》——承認規則；規則的內在觀點；法實證主義的現代重建。［[1961-哈特法律的概念.md]］
- 1964：富勒《法律的道德性》——合法性八原則；法律的內在道德；與哈特的世紀論戰。［[1964-富勒法律的道德性.md]］

### 七、當代：權利、效率與程式碼（1973 -- 2020）

- 1973：德沃金《認真對待權利》——權利是王牌；赫拉克勒斯法官；對實證主義的總攻。［[1973-德沃金認真對待權利.md]］
- 1977：波斯納《法律的經濟分析》——普通法的效率邏輯；財富最大化；法與經濟學統治學界。［[1977-波斯納法律的經濟分析.md]］
- 1986：批判法學運動——「法律是不確定的政治」；拆解客體性神話；會議室裡的知識分子游擊。［[1986-批判法學運動.md]］
- 1999：萊斯格《網路空間的法》——「程式碼即法律」；架構是最強的規範；網路自由主義的告別式。［[1999-網路法與程式碼即法律.md]］
- 2020：數位時代的隱私與平台監管——GDPR 時代；平台成為裁斷者；正義被寫進演算法。［[2020-數位時代的隱私與平台監管.md]］
