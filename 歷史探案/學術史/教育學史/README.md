# 教育學史 -- AI 偵探風格

以「推理探案」的方式，追查教育史上的重大轉折：柏拉圖的護國者、漢代的太學、阿爾昆的宮廷學校、波隆那的大學、古騰堡的活字、夸美紐斯的班級、洛克的白板、盧梭的愛彌兒、赫爾巴特的統覺、福祿貝爾的恩物、賀瑞斯曼的公立學校、莫里爾的贈地、杜威的實驗學校、蒙台梭利的兒童之家、維高斯基的最近發展區、八年研究、史普尼克的衝擊、布魯納的螺旋、ESEA 的聯邦支票、伊里奇的非學校化、《國家在危機中》、PISA 的全球考場、生成式 AI 的論戰——
前因是什麼？線索在哪裡？推理如何展開？後果又如何改寫了「人如何被塑造」的歷史？

本卷的核心命題只有一句話：**教育學史是「人如何被塑造」的偵辦史。**
每一樁案件都是一次塑造權的移交或革命：誰有資格教（祭司、士、教士、國家、專家）？教誰（貴族、自由民、男孩、所有兒童）？教什麼（經典、教義、實用、科學、素養）？怎麼教（個別、班級、做中學、測驗驅動）？為誰（靈魂、帝國、市場、民主、經濟競爭力）？每一次答案的更換，都是一樁「多因懸案」：偵探的工作，就是把塑造權的交接鏈一環一環還原出來。

## 塑造權的迴響迴路

```
      ┌────（時代危機：帝國選才、蠻族滅學、宗教分裂、工業革命、戰爭、科技衝擊）────┐
      ↓                                                                ↓
 舊制度 ──→ 危機/新知 ──→ 新理論 ──→ 新學校 ──→ 制度化 ──→ 僵化 ──→ 新危機
   │            ↑          ↑                    │                │
   │            │          │                    ↓                ↓
   └──→ 權力收編 ←── 傳承（印刷、課本、師範、學會）←── 反叛（進步主義、非學校化）
       ↑                                    ↑
       └── 經濟—技術（活字、鐵路、測驗、演算法）┘

  正向迴路（加速）：新媒介→新課本→新課程→新學校
  正向迴路（加速）：戰爭/競賽→國家介入→教育軍備化
  負向迴路（抑制）：僵化考試→反叛→實驗學校→再制度化
  偵探迴路（本卷特有）：危機→誰來塑造？→理論→制度→反叛→危機
```

**偵探的訣竅**：找到「塑造權原本在誰手上、為何移轉、新塑造者承諾什麼、實際生產了什麼人」，把鏈條畫出來；再問一句——**被塑造者有沒有發言權（兒童何時才從容器變成主體）？**案件的因果鏈就浮現了。

## 案件卷宗（歷史年表）

### 一、古代：塑造權的發明（-0387 -- -0165）

- -0387：柏拉圖學院與護國者教育——阿卡德米樹林；洞穴之喻；教育即靈魂轉向；哲學王的選拔課程。［[-0387-柏拉圖學院與護國者教育.md]］
- -0165：漢代太學與察舉——武帝設太學、置博士弟子員；獨尊儒術；察舉選才；帝國第一所官學。［[-0165-漢代太學與察舉.md]］

### 二、中世紀與印刷革命：保存、大學與技術（0797 -- 1450）

- 0797：阿爾昆與加洛林文藝復興——查理曼宮廷學校；抄經救古籍；七藝與書寫標準。［[0797-阿爾昆與加洛林文藝復興.md]］
- 1150：波隆那大學誕生——學生行會僱用教授；註釋法典；大學作為自治法人。［[1150-波隆那大學誕生.md]］
- 1450：古騰堡與教科書革命——活字印刷；課本標準化；識字率起飛；教學脫離抄本稀缺。［[1450-古騰堡與教科書革命.md]］

### 三、理性與自然：理論的誕生（1632 -- 1762）

- 1632：夸美紐斯《大教學論》——「把一切知識教給一切人」；班級授課制；教科書與插圖（世界圖解）。［[1632-夸美紐斯大教學論.md]］
- 1693：洛克《教育漫話》——白板與紳士教育；體育第一；習慣的力量；家庭導師制。［[1693-洛克教育漫話.md]］
- 1762：盧梭《愛彌兒》——自然教育；兒童不是小大人；消極教育；被焚之書改寫教育觀。［[1762-盧梭愛彌兒.md]］

### 四、十九世紀：科學化與國家化（1806 -- 1862）

- 1806：赫爾巴特《普通教育學》——教育學成為科學；統覺與興趣；教學形式階段；師範教育的聖經。［[1806-赫爾巴特普通教育學.md]］
- 1837：福祿貝爾與幼兒園——布蘭肯堡開園；恩物與作業；童年有權遊戲。［[1837-福祿貝爾與幼兒園.md]］
- 1837：賀瑞斯曼與公學運動——麻州教育廳長；免費普遍公立學校；師範學校；公民塑造工程。［[1837-賀瑞斯曼與公學運動.md]］
- 1862：莫里爾法案與贈地大學——聯邦撥地辦學；農工實用高等教育；知識服務產業。［[1862-莫里爾法案與贈地大學.md]］

### 五、進步主義世紀：兒童站上舞台（1896 -- 1938）

- 1896：杜威芝加哥實驗學校——做中學；學校即社會；作業與民主生活。［[1896-杜威芝加哥實驗學校.md]］
- 1907：蒙台梭利兒童之家——羅馬貧民窟的實驗；預備環境與敏感期；幼兒自主工作。［[1907-蒙台梭利兒童之家.md]］
- 1916：杜威《民主與教育》——教育即生活之改造；經驗與成長；民主作為教育目的。［[1916-杜威民主與教育.md]］
- 1934：維高斯基《教學與發展》——最近發展區；教學引導發展；社會文化工具論。［[1934-維高斯基教學與發展.md]］
- 1938：八年研究與進步主義教育——三十校實驗；畢業生大學表現反超；進步主義的證據時刻。［[1938-八年研究與進步主義教育.md]］

### 六、冷戰與聯邦化：國家的接管（1957 -- 1983）

- 1957：史普尼克與課程改革——蘇聯衛星震動美國；國防教育法；課程軍備競賽開跑。［[1957-史普尼克與課程改革.md]］
- 1960：布魯納《教育過程》——結構與螺旋課程；發現學習；「任何知識都能以某種誠實形式教給任何兒童」。［[1960-布魯納教育過程.md]］
- 1965：初等與中等教育法——詹森大社會；聯邦資金直達課堂；教育機會均等的制度化。［[1965-初等與中等教育法.md]］
- 1971：伊里奇《非學校化社會》——學習網絡；廢校論；隱藏課程的控訴。［[1971-伊里奇非學校化社會.md]］
- 1983：《國家在危機中》——攀升的平庸潮；標準化測驗問責時代開幕。［[1983-國家在危機中.md]］

### 七、全球化與演算法：新法庭（2000 -- 2023）

- 2000：PISA 誕生與全球教育治理——OECD 三年一測；排名政治；比較教育的全球市場。［[2000-PISA誕生與全球教育治理.md]］
- 2023：生成式 AI 與教育論戰——ChatGPT 衝擊作文與評量；照本宣科教學的末日；塑造權流向演算法？［[2023-生成式AI與教育論戰.md]］
