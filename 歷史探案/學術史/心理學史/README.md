# 心理學史 -- AI 偵探風格

以「推理探案」的方式，追查人類如何一步步把「心靈」從哲學思辨、神學玄談，變成可以在實驗室測量、在醫院治療、在電腦上模擬的科學對象——
前因是什麼？線索在哪裡？推理如何展開？後果又如何改變了我們對「人是什麼」的理解？

本卷的核心命題只有一句話：**心理學的歷史，就是「心靈如何被測量」的歷史。**
每個重大事件都是一樁「多因懸案」：技術（儀器、統計）、哲學（經驗論與理性論）、醫學（精神病理學）、社會（戰爭、都市、教育）、政治（軍事需求、思潮管制）、生物學（演化論、神經科學）——這些因素互相咬合。偵探的工作，就是把「心靈為何在此時此地被如此定義」的因素鏈一環一環還原出來。

（涵蓋：希臘心靈哲學、二元論、經驗論、康德、顱相學、心理物理學、達爾文、布羅卡、馮特、艾賓浩斯、詹姆斯、佛洛伊德、巴夫洛夫與桑代克、智力測驗、行為主義、維高斯基、馬斯洛、控制論、認知革命、依附理論、米爾格蘭、監獄實驗、認知心理學、展望理論、神經網路、fMRI、正向心理學、重現性危機、AI 與心理學）

## 本卷的破案框架：五條主軸

| 主軸 | 問題 | 關鍵轉折 |
|------|------|----------|
| **心靈是什麼** | 從靈魂到機制 | 柏拉圖 → 笛卡爾 → 洛克 → 康德 → 達爾文 |
| **如何測量** | 從內省到儀器 | 顱相學（假測量）→ 心理物理學 → 反應時間 → 智力測驗 → fMRI |
| **如何治療** | 從驅魔到談話 | 精神病院 → 梅斯梅爾 → 佛洛伊德 → 行為治療 → 認知治療 |

| **如何解釋社會的人** | 從個體到群體 | 勒龐 → 米爾格蘭 → 依附理論 → 卡尼曼 |

## 案件卷宗（歷史年表）

### 一、前科學時代：心靈的哲學（前600–1800）

- 約前600：泰勒斯與米利都學派——第一次用「自然原因」解釋世界，心靈也被納入自然。
- 約前400：柏拉圖「靈魂三分」與亞里斯多德《論靈魂》——心靈問題的第一份完整卷宗。［[-0400-希臘心靈哲學.md](-0400-希臘心靈哲學.md)］
- 約前350：亞里斯多德的聯想論——「相近、相似、對比」三律，日後一切學習理論的遠祖。
- 約170：蓋倫的「氣質體液說」——身心合一的醫學傳統，統治西方一千五百年。
- 約1000：阿維森納《醫典》——伊斯蘭醫學對精神疾病的分類與治療。
- 1637–1650：笛卡爾「我思故我在」與心物二元論——心靈被移出肉體，也替日後的生理心理學開了門。［[1637-笛卡爾心物二元論.md](1637-笛卡爾心物二元論.md)］
- 1690：洛克《人類理解論》——「白板說」與經驗論，心靈的內容來自經驗。［[1690-洛克白板說.md](1690-洛克白板說.md)］
- 1748：拉美特利《人是機器》——把笛卡爾的動物機器推廣到人。
- 1750–1790：梅斯梅爾的「動物磁力」——假科學，卻是催眠與暗示研究的起點。
- 1781：康德《純粹理性批判》——心靈不是白板，而是「戴著眼鏡看世界」；心理學被他判為「不可能成為精確科學」，這是後人必須翻案的懸案。［[1781-康德的心靈地圖.md](1781-康德的心靈地圖.md)］
- 1796：加爾的顱相學——第一次宣稱「心理功能可以定位、可以測量」，測量的工具是錯的，命題卻留了下來。［[1796-顱相學.md](1796-顱相學.md)］

### 二、科學的誕生（1834–1900）

- 1834：韋伯定律——感覺差異與刺激強度成比例，心理量的第一條數學定律。［[1834-韋伯定律.md](1834-韋伯定律.md)］
- 1859：達爾文《物種起源》——心靈也是演化的產物，人與動物的心智連續性。［[1859-達爾文與心智演化.md](1859-達爾文與心智演化.md)］
- 1860：費希納《心理物理學綱要》——物理量與心理量的對數關係，實驗心理學的數學地基。
- 1861：布羅卡的「Tan 病人」——語言功能定位在左額葉，定位論擊敗整體論。［[1861-布羅卡失語症.md](1861-布羅卡失語症.md)］
- 1868：唐得斯（Donders）的反應時間實驗——用時間差「測量」看不見的心理歷程。
- 1879：馮特在萊比錫設立第一個心理學實驗室——心理學正式從哲學分家。［[1879-馮特實驗室.md](1879-馮特實驗室.md)］
- 1885：艾賓浩斯《論記憶》——第一個以自己為受試者的記憶遺忘曲線。［[1885-艾賓浩斯遺忘曲線.md](1885-艾賓浩斯遺忘曲線.md)］
- 1890：詹姆斯《心理學原理》——意識之流、功能主義，美國心理學的憲法。［[1890-詹姆斯心理學原理.md](1890-詹姆斯心理學原理.md)］
- 1896：維特默在賓州大學開設第一家心理診所——「臨床心理學」誕生。
- 1898：桑代克的貓與迷籠——效果律，工具制約的前身。［[1898-桑代克效果律.md](1898-桑代克效果律.md)］

### 三、精神分析與行為主義的雙雄時代（1900–1930）

- 1900：佛洛伊德《夢的解析》——潛意識、自由聯想、談話治療。［[1900-佛洛伊德夢的解析.md](1900-佛洛伊德夢的解析.md)］
- 1901–1904：巴夫洛夫的狗——古典制約，生理學家意外闖入心理學。［[1904-巴夫洛夫條件反射.md](1904-巴夫洛夫條件反射.md)］
- 1905：比奈與西蒙的智力測驗——為了篩選學童而生，卻長成了影響百年的社會制度。［[1905-比奈智力測驗.md](1905-比奈智力測驗.md)］
- 1911–1912：科勒的黑猩猩與「頓悟」；完形心理學宣言。
- 1913：華生〈行為主義者眼中的心理學〉——「預測並控制行為」，把意識逐出實驗室。［[1913-華生行為主義宣言.md](1913-華生行為主義宣言.md)］
- 1917–1934：維高斯基的「最近發展區」——心理的社會文化起源。［[1934-維高斯基思維與語言.md](1934-維高斯基思維與語言.md)］
- 1920：華生與雷納的小亞伯特實驗——恐懼可以被制約，也引發第一波研究倫理爭議。
- 1923：布羅伊勒命名「自閉式思考」；同年肯納日後（1943）定義自閉症。

### 四、戰爭、診所與應用心理學（1930–1950）

- 1933：納粹掌權，德國心理學界被清洗——哥士基、勒溫、阿斯其等流亡，重心移往美國。
- 1936：薩皮爾—沃夫假說的語言相對論爭論。
- 1938：史金納《有機體的行為》——操作性制約與增強的工程學。［[1938-史金納操作性制約.md](1938-史金納操作性制約.md)］
- 1939：二戰爆發——軍方大規模徵用心理學：人因工程、篩選、士氣、戰後創傷（日後的 PTSD）。
- 1943：馬斯洛〈動機理論〉——需求層次，人本主義的第三勢力開場。［[1943-馬斯洛需求層次.md](1943-馬斯洛需求層次.md)］
- 1943：肯納描述 11 名「早幼兒自閉症」兒童。
- 1948：香農的資訊論與維納的控制論——「訊息、回饋、處理」的語言成形，認知革命的火種。［[1948-控制論與資訊革命.md](1948-控制論與資訊革命.md)］
- 1949：希爾加德的學習理論綜述；同年紐約「希克森會議」，認知革命的前夜。

### 五、認知革命（1950–1979）

- 1950：圖靈〈計算機器與智能〉——「機器能思考嗎？」測試的誕生。［[1950-圖靈測試.md](1950-圖靈測試.md)］
- 1953：米勒、加蘭特、普里布拉姆的行為主義批判；同年 DNA 雙螺旋——心理學的生物學根基重整。
- 1956：達特茅斯會議與「神奇數字 7」——認知革命的關鍵年。［[1956-認知革命.md](1956-認知革命.md)］
- 1957：喬姆斯基《句法結構》——心理語言學；1959 他對史金納《言語行為》的書評，行為主義的致命一擊。
- 1961：鮑比《依附理論》——母嬰連結不是餵食的副產品。［[1961-鮑比依附理論.md](1961-鮑比依附理論.md)］
- 1963：米爾格蘭服從實驗——普通人的惡，倫理辯論的引爆點。［[1963-米爾格蘭服從實驗.md](1963-米爾格蘭服從實驗.md)］
- 1967：奈瑟《認知心理學》——教科書為新典範命名。
- 1971：史丹佛監獄實驗——情境的力量，也埋下日後重現性問題的地雷。［[1971-史丹佛監獄實驗.md](1971-史丹佛監獄實驗.md)］
- 1972：卡尼曼與特沃斯基開始一系列捷思與偏誤研究。［[1979-展望理論.md](1979-展望理論.md)］
- 1976：道金斯《自私的基因》——演化心理學的思想前奏。
- 1979：展望理論——人不是理性動物，而是「相對參考點的動物」。［[1979-展望理論.md](1979-展望理論.md)］

### 六、神經科學、演化與正向（1980–2010）

- 1982：魯利亞遺作出版，神經心理學的系統化。
- 1986：魯梅哈特與麥克蘭德的《平行分散處理》——神經網路復興，認知科學的新引擎。［[1986-神經網路復興.md](1986-神經網路復興.md)］
- 1990：fMRI 上市——把「思考時大腦哪裡亮」變成常規測量。［[1990-fMRI與認知神經科學.md](1990-fMRI與認知神經科學.md)］
- 1992：巴爾可（Cosmides）與托比（Tooby）的演化心理學宣言。
- 1998：塞利格曼的 APA 主席就職演說——正向心理學運動。［[1998-正向心理學.md](1998-正向心理學.md)］
- 2002：卡尼曼獲諾貝爾經濟學獎——心理學家改寫經濟學的人性假設。

### 七、當前懸案（2010–2026）

- 2011：Bem（貝姆）（Bem）的超感應論文引發風暴——「顯著結果」的統計與出版制度問題現形。
- 2015：可開放科學合作組織（OSF）重現 100 項心理學研究，僅約 1/3 成功重現——重現性危機正式立案。［[2015-重現性危機.md](2015-重現性危機.md)］
- 2016：AlphaGo 擊敗李世石——深度學習證明「統計學習」足以逼近人類認知的許多面向。
- 2020：新冠疫情——心理學的遠距實驗與心理健康危機。
- 2022–2026：大型語言模型時代——AI 是否「理解」、測驗能否測量機器心智、心理學作為「機器心智測量學」的新角色。［[2022-大型語言模型與心理學.md](2022-大型語言模型與心理學.md)］
