# 1963-米爾格蘭服從實驗：普通人的電擊開關

## 案件摘要

1961–1963 年，耶魯大學的米爾格蘭（Stanley Milgram）招募普通人做「記憶與學習」實驗：受試者扮演老師，對答錯的「學生」（實為演員）施加最高 450 伏的電擊。宣稱的結果：**65% 的受試者按到了最後一檔**——儘管牆那頭傳出慘叫、抗議與靜默。（→ 本案是心理學史上最著名的「平庸之惡」示範：不是瘋子，是鄰居！）但偵探必須立刻出示第二份卷宗：2000 年代檔案重審發現，耶魯檔案中的錄音與紀錄顯示**多數受試者其實懷疑電擊是假的、且不聽命者遠比公開數字多**——本案同時是一樁科學發現案與一樁科學敘事失真案。

## 前因 -- 多因素的局勢

- **艾希曼審判**：1961 年納粹劊子手艾希曼在耶路撒冷受審；漢娜·鄂蘭提出「平庸之惡」——罪惡不需要惡魔，只需要照章辦事的普通人（→ 米爾格蘭實驗被視為鄂蘭命題的實驗室驗證——這是它瞬間爆紅的原因！）
- **猶太裔身世**：米爾格蘭出身布朗克斯的猶太移民家庭，二戰親戚受難的陰影；他的問題直白如刀：「德國人是不是特別服從？」（後來他承認：這不是德國人的問題，是所有人的問題。）
- **社會心理學的黃金期**：阿希從眾實驗（1951）、津巴多的先例——戰後美國社會心理學正在以震撼性實驗建立學科聲望（→ 「驚人實驗」成為學科的行銷模式！）。
- **冷戰氛圍**：對極權、洗腦、韓戰戰俘「招供」的恐慌——服從是國防議題。
- **倫真空期**：當時沒有 IRB（機構審查委員會）制度——實驗倫理全憑研究者的良心（→ 本案直接催生了倫審制度，是它最重要的制度遺產！）

## 線索與推理 -- 因素咬合

### 線索一：操縱服從的變項 = 真正的科學貢獻

米爾格蘭的系列變式顯示服從率隨情境劇變：

| 情境 | 服從到最高檔（約） |
|---|---|
| 權威在場、遙距 | 65% |
| 權威離開房間 | ~20% |
| 學生在同一房間 | ~40% |
| 受試者要按住學生的手 | ~30% |
| 兩位權威意見分歧 | 0% |

（→ 服從不是人格特質，是情境函數——這是本案的真命題！）變式之間的落差，比 65% 這個單一數字重要得多。

### 線索二：檔案重審 = 敘事的裂縫

2000 年代研究者（Perry 的《電擊實驗的幕後》、Reicher 與 Haslam 的分析）檢視耶魯檔案發現：①許多受試者不相信電擊是真的（有受試者直接問，實驗者語焉不詳）；②750 名受試者中，多數在程序結束前拒絕繼續；③「65%」是特定變式的最大值，被當成了總體結論（！標準的「最戲劇化切片當門面」——媒體與教科書合謀放大！）；④實驗者對不服從者施加的勸說腳本（「你別無選擇，必須繼續」）本身就揭示服從的語言機制。偵探裁定：**命題（情境塑造行為）存活；數字（65%）與敘事（人類會盲目殺人）需要減刑。**

### 線索三：米爾格蘭的下一步 = 小世界與六度分離

同一個人在 1967 年做了「小世界實驗」（內布拉斯加—波士頓鏈式信件）——「六度分離」的來源（→ 網路時代的社會網絡科學的祖師爺！）。偵探的觀察：米爾格蘭一生都在做「普通人有多容易受系統擺布」的變奏——服從、從眾、網路——他的問題意識一致，方法大膽，倫理粗放。

### 線索四：倫理的翻案

受試者事後調查：84% 表示「樂於參與」，但這可能是事後合理化；當場的顫抖、出汗、癲癇樣反應有影片為證。（→ 1963 年當代已有學者公開譴責）本案直接促成 1970s 倫理準則：知情同意、事後解說、有權退出——今日所有心理實驗的倫理框架，是這樁案件的最硬遺產。

## 破案時刻

- 1961-8：艾希曼審判開庭；米爾格蘭實驗啟動。
- 1963：〈服從的行為研究〉刊於《變態與社會心理學期刊》。
- 1965：變式系列完成。
- 1974：《服從權威》專書——「65%」成為文化符碼。
- 1971：史丹佛監獄實驗（[1971-史丹佛監獄實驗.md](1971-史丹佛監獄實驗.md)）接棒震撼敘事。
- 1970s：美國心理學會倫理準則與 IRB 制度確立。
- 2000s–2013：檔案重審與部分複製（波蘭 2017 複製服從率約 90%，但情境更溫和）——學界開始改寫教科書。
- 結案：情境主義存活，數字與英雄敘事重審。

## 後果 -- 改變了什麼

- **倫理制度**：知情同意、IRB、欺瞞研究限制——本案是心理學倫理法典的母案。
- **社會心理學的情境主義**：權威、角色、制服、制度——情境對行為的力量成為核心教義。
- **文化引用**：從鄂蘭到電影（〈浪潮〉、〈實驗者〉）——「65%」成為大眾對人性悲觀的快捷鍵（→ 大眾版本比科學版本極端得多——科普的失真也是本案罪證之一！）
- **方法論的反省**：欺瞞、扮演、社會壓力實驗的效度與倫理之間的張力，持續至今（[2015-重現性危機.md](2015-重現性危機.md)）。

**偵探結語**：米爾格蘭的案子要分兩審：第一審，他證明了一件事——權威的白袍、儀器的按鈕與「實驗需要你」的指令，就足以讓普通人把手放上開關，這對鄂蘭命題的實驗室轉譯是真功勞。第二審，他自己也服從了另一種權威——「震撼性實驗」的學科行銷邏輯：把最戲劇化的變式當成總結論，把懷疑的受試者寫成盲目執行者。一個研究服從的人，未能免於服從學界的獎勵結構——這才是本案最深的一層證詞。普通人會按開關；科學家會按的是統計的選擇鍵。
