# 1913-華生行為主義宣言：心理學的宮廷政變

## 案件摘要

1913 年，約翰霍普金斯大學的華生（John B. Watson）在《心理學評論》發表〈行為主義者眼中的心理學〉——通稱行為主義宣言。主張只有一句話的分量：**心理學應放棄意識，只研究可觀察的行為；人與動物沒有本質界線**。目的論上，華生要把心理學變成「純客觀的自然科學」。（！注意：宣言幾乎沒有新實驗資料——這是一場方法論政變，不是一場發現！（→ 但它成功改寫了美國心理學的權力地圖，統治長達四十年。）真兇是「可測量」的暴政：內省死於自身的不可靠。

## 前因 -- 多因素的局勢

- **內省的內戰**：馮特與鐵欽納的構造主義（[1879-馮特實驗室.md](1879-馮特實驗室.md)）內省結果在各實驗室互相矛盾（「影像有無？清晰度幾何？」眾說紛紜）——方法本身成了笑柄。
- **動物心理學的興起**：桑代克（[1898-桑代克效果律.md](1898-桑代克效果律.md)）與巴夫洛夫（[1904-巴夫洛夫條件反射.md](1904-巴夫洛夫條件反射.md)）證明動物研究產出硬資料——而你無法問貓「內省一下」。（→ 動物實驗天然排除了內省，行為主義是其方法論的延伸！）
- **美國實用主義文化**：詹姆斯的功能主義（[1890-詹姆斯心理學原理.md](1890-詹姆斯心理學原理.md)）已把心靈工具化；實用、量化、管理的時代需要可預測的人。
- **個人野心**：華生 30 歲任教授，急欲建立自己的學派；他自承「永遠看不到自己做的事——換言之，內省對我而言不可行」。（！宣言的起點之一，是研究者本人的能力缺陷！）
- **時機**：卡泰爾《心理學評論》主編之位、心理學期刊擴張——學術市場正缺一個鮮明的旗幟。

## 線索與推理 -- 因素咬合

### 線索一：宣言的骨架 = 四個替換

| 舊心理學 | 行為主義 |
|---|---|
| 研究對象 | 意識 |
| 方法 | 內省 |
| 目標 | 描述意識內容 |
| 資料 | 主觀報告 |

（→ 這張表不只是換方法，是換掉研究對象本身——「心」被逐出心理學，學科改名而不改招牌！）華生承諾的獎賞：預測與控制行為——工程學的訂單，科學的自我期許，一次付清。

### 線索二：小亞伯特 = 宣言的血證

1920 年，華生與雷納（Rayner）以條件反射（[1904-巴夫洛夫條件反射.md](1904-巴夫洛夫條件反射.md)）使一歲嬰兒「小亞伯特」對白鼠產生恐懼（鐵棒敲擊聲配對七次），並類化到兔子、皮草。（→ 「情緒是可製造的」——這是行為主義最震撼的展示，也是最臭名昭著的倫理案底：亞伯特未曾被消除制約，數月後離開醫院，下落成謎！）此實驗證明「情緒」可以被外顯程序操縱——內省在此案中毫無用武之地。

### 線索三：誇張的修辭學

宣言的名句：「給我一打健康的嬰兒……我可以保證把任意一個訓練成任何專家——醫生、律師、藝術家，甚至乞丐與小偷。」（！這句話在方法上沒有任何證據支持——它是廣告詞！）偵探的解讀：行為主義的勝利一半靠資料，一半靠行銷——**學派鬥爭中，極端化是生存策略**。華生 1920 年因師生戀醜聞被逐出學界，轉入廣告業（J. Walter Thompson）——把行為主義的技巧直接用在賣香菸與咖啡上（→ 理論與市場在創立者身上就直接合流了！）

### 線索四：反對者的真問題

麥獨孤、拉胥里（Lashley）等人指出：完全否認內在歷程，連「注意力」「目的」都無法談論——行為主義初期只能靠迴避。但弔詭的是：行為主義的紀律（操作性定義、控制實驗、可重複）成為整個心理學的底層素養——**連後來打倒它的人，都用它的規則作戰**（[1956-認知革命.md](1956-認知革命.md)）。

## 破案時刻

- 1903：芝加哥大學博士（安吉爾門下）。
- 1908：約翰霍金斯大學教授，主持動物心理實驗室。
- 1913：宣言發表於《心理學評論》。
- 1914：《行為：比較心理學導論》。
- 1915：當選 APA 主席（35 歲）——學界的快速加冕。
- 1920：小亞伯特實驗；同年因離婚醜聞被解聘，轉入廣告業。
- 1930：《行為主義》修訂版——「一打嬰兒」名句發表。
- 結案：意識被逐出美國心理學教科書近四十年。

## 後果 -- 改變了什麼

- **學科權力重組**：美國心理學 1920s–1960s 由行為主義主導；動物實驗室、操作性定義、控制組設計成為標準配備。
- **行為治療與應用**：系統減敏感、代幣制度、行為矯正——臨床獲得可教、可驗的技術。
- **教育與社會工程**：史金納（[1938-史金納操作性制約.md](1938-史金納操作性制約.md)）把路線推到頂點（教學機、烏托邦小說《桃源二村》）。
- **反彈與遺產**：認知革命的口號之一是「重新打開黑箱」；但認知科學沿用的操作化、可測量標準，是行為主義留下的紀律（→ 政變失敗者統治了政變成功者的政府！）。

## 因素影響筆記

```
內省內戰(方法失效) ─┐
動物實驗(硬資料) ───┼─→ 宣言 1913：研究行為，不研究意識
美國實用文化 ───────┘         │
              ┌───────────────┼────────────────┐
              ↓               ↓                ↓
        小亞伯特(1920)   學科紀律制度化    廣告/社會工程
              │               │
              └→ 行為治療     └→ 史金納路線 → 認知革命反擊
                                （但繼承其操作化紀律）
```

**偵探結語**：這樁政變最精彩的地方在於：勝利者沒有新證據，只有新規則。華生宣布「你們量不了的東西不存在」，一個學科就照辦了四十年——因為在他的時代，「量不了」約等於「升不了等、發不了期刊、請不到經費」。意識沒有被駁倒，只是被失業了。而華生本人的結局像一句註腳：他被學院驅逐後去賣了咖啡，用同一套刺激—反應心理學寫廣告文案。政變者最後證明，他最忠實的實驗場從來不是實驗室，是市場。
