# 1898-托雷斯海峽探險：田野訓練的誕生

## 案件摘要

1898 年，劍橋大學派出史上第一支專業人類學田野探險隊，前往**托雷斯海峽**（澳洲與新幾內亞之間！）：哈頓領隊，成員有里弗斯、塞利格曼、麥克杜格爾等（！）——帶著儀器（聽力計！色覺測試！體質測量！）、問卷與相機，**住進島上、學當地語言、做系統觀察**（！）——**「田野」從旅行採集升級為職業訓練**。此前：搖椅學者靠傳教士報告（→泰勒！）；此後：**親臨、長住、學語**成為人類學的入門禮（→馬林諾夫斯基 1922 集大成）。這樁案件是「方法的產房」。

## 前因 -- 多因素的局勢

- **泰勒之催**：1894《人類學的任務》（！）——**呼籲親身田野**（→「傳教士報告不可靠」！）。
- **里弗斯的轉身**：心理學家（！）被派去解釋托雷斯人「奇怪」的視覺（！）——**一個課題引出一次革命**。
- **帝國網絡**：英屬海峽殖民地（！）——**交通與許可**（→殖民方便也是條件！）。
- **劍橋資源**：賽克斯資助（！）——**經費決定出發**。

## 線索與推理 -- 因素咬合

### 線索一：視覺之謎——「為什麼他們『看不懂』照片？」

托雷斯人讀照片困難（！）＋里弗斯調查（！）：

$$\text{課題} = \text{（視覺：測試！）} \Rightarrow \text{發現：文化差異而非能力差異}$$

**破除種族能力論**（→「不是智力問題，是經驗問題」！）——**方法即平反**。

### 線索二：譜系法——「里弗斯的發明」

問親屬稱謂＋繫譜圖（！）：

$$\text{譜系法} = \text{（稱謂！）} \times \text{（圖表！）} \Rightarrow \text{社會結構可繪製}$$

**面對面取證**（→取代第二手報告！）——**後來成為田野標配**（→努爾人譜系！[1940](1940-努爾人與非洲政治制度.md)！）。

### 線索三：團隊模式——「多學科齊下」

體質（塞利格曼！）＋心理（麥克杜格爾！）＋社會（里弗斯！）：

$$\text{田野} = \text{（長住！）} \times \text{（學語！）} \times \text{（儀器！）} \Rightarrow \text{專業化誕生}$$

**1898 六個月＋1901 續程**（！）——**第二次停留更久、方法更鬆**（→「從實驗室式走向聊天式」！）——**直通馬林諾夫斯基**。

## 破案時刻

- 1894：泰勒呼籲（！）——動員。
- 1898.4：探險隊啟程（！）——出發。
- 1898—99：默雷島大本營（！）——第一輪。
- 1901—02：續程（！）——方法成熟。
- 1901：里弗斯《托雷斯海峽報告》譜系卷（！）——遺產。

## 後果 -- 改變了什麼

- **方法**：長住＋學語＋譜系（！）——**田野標準化**（→倫敦政經學院訓練馬林諾夫斯基！）。
- **學科**：田野經驗成為就業門檻（！）——**「下過田野」＝資格**。
- **英國學派**：里弗斯→梅耶斯→拉德克利夫-布朗（！）——**譜系法餵養結構功能論**。
- **反面**：殖民便利仍是底色（！）——**探險隊的倫理陰影**（→後殖民批判的伏筆！）。

## 因素影響筆記

```

長住學語（！）──→ 1922馬林諾夫斯基（集大成！）
```

**偵探結語**：托雷斯海峽案件是「方法的產房案」：**一切始於一個小謎題——為什麼島民看不懂照片？**里弗斯原本只想解釋視覺差異，結果發現那不是智力問題而是經驗問題，於是親自下場、住進島上、發明譜系法——**一個課題把整個學科的方法帶出了搖椅**。第二次停留（1901）時，隊伍已從「搬儀器的實驗室」變成「坐在人群裡聊天」——**這半步就是馬林諾夫斯基的帳篷**。偵探的註腳：探險隊乘的是帝國的船、拿的是殖民的許可——**產房的地基裡有殖民的鋼筋**，這筆帳要到 1978（東方主義！）與 1986（寫作文化！）才被公開清算。
