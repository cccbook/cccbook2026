# 1934-本尼迪克特文化模式：四個舞蹈與一種科學

## 案件摘要

1934 年，波士頓（！）——魯思・本尼迪克特出版《文化模式》（！）——**全書骨架竟是四段人類學經典案例**：祖尼人（新墨西哥普韋布洛！）、多布人（新幾內亞！）、夸扣特爾人（北美西北海岸！）與舞蹈（！）——她宣稱：**每個文化像人格一樣，只從無限可能中「選取」少數特徵加以放大**（！）——祖尼是「日神型」（節制！中庸！），夸扣特爾與多布是「酒神型」（誇富宴！瘋狂競爭！）（！）——**這樁案件是「把心理學類型學嫁接到民族誌上」**：一位博厄斯的頭號女弟子（→[1911](1911-博厄斯反種族主義.md)），用尼采的日神酒神（！）與精神分析的類型語彙，把文化相對論推上了暢銷書榜（！）——也埋下了日後被稱為「文化整體論過度簡化」的引信。

## 前因 -- 多因素的局勢

- **博厄斯學派缺理論**：反種族主義打得贏（！）——**但文化「如何整合」尚無學說**（→描述有餘、解釋不足！）。
- **完形心理學東漸**：格式塔「整體大於部分之和」（！）——**可移植的思維工具**。
- **精神分析時尚**：人格、無意識、童年決定論（！）——**薩丕爾與米德正在搞文化與人格學派**（→[1928](1928-米德薩摩亞.md)先鋒！）。
- **1930s 經濟大蕭條**：讀者渴望「文化為何病態」的答案（！）——**暢銷書的社會土壤**。

## 線索與推理 -- 因素咬合

### 線索一：文化的選擇性——「選配說」

本尼迪克特的公式（！）：

$$\text{文化} = \text{（全人類潛能的無限庫！）} \div \text{（該社會的「選取與放大」！）} \Rightarrow \text{獨特模式}$$

**大部分潛能被「棄置」**（！）——**跨文化差異不是進化程度，而是選材不同**（！）——**反進化論、反種族主義的第二波總攻**。

### 線索二：三案例對照——「一份類型學表格」

| 社會 | 模式 | 特徵 |
|---|---|---|
| 祖尼 | 日神型 | 節制、儀式秩序、避衝突 |
| 夸扣特爾 | 酒神型 | 誇富宴、燒毀銅盤、競逐聲望 |
| 多布 | 妒嫉型 | 惡毒巫術、交易猜忌 |

**問題**：同一地區（西北海岸）內部差異遠大於她的類型（！）——**民族誌家抗議：案例被削足適履**（！）。

### 線索三：從描述到「配置」——「整合論誕生」

$$\text{整合論} = \text{（各特徵互相加強！）} \Rightarrow \text{文化是有機整體}$$

**克拉克洪、克魯伯接力**（！）——**價值觀成為分析單位**（→格爾茨「文化即意義之網」的遠祖！[1973](1973-格爾茨文化的詮釋.md)！）——但**「過度整合」批評同時到貨**：文化內部有階級、有矛盾（！）。

## 破案時刻

- 1922—30s：本尼迪克特整理祖尼等田野文獻（！）——大量借用他人材料（她本人田野有限！）。
- 1932：完形心理學啟發定稿（！）——類型學成型。
- 1934：《文化模式》出版（！）——學術與大眾雙爆。
- 1942：博厄斯去世，訃文由她撰寫（！）——學派權杖交接。
- 1946：《菊花與劍》（！）——整合論應用於國民性（→戰時政府委託！）。

## 後果 -- 改變了什麼

- **國民性研究**：《菊花與劍》開創「遠距離文化分析」（！）——**戰時不進日本也能寫日本**（→[1964](1964-駱駝項目與冷戰人類學.md)的冷戰應用先例！）。
- **文化相對論普及**：成為美國大眾常識（！）——**教科書與暢銷書的合流**。
- **理論反彈**：埃文思-普里查德等批評「心理化簡化」（！）——**英國結構功能論的對照組**（→[1940](1940-努爾人與非洲政治制度.md)！）。
- **女性學術典範**：米德與本尼迪克特並立（！）——**人類學成為女性學者的主戰場**。

## 因素影響筆記

```
完形心理學（！）＋精神分析（！）→ 博厄斯學派補理論缺口
「選取與放大」（1934！）──→ 文化整合論 ──→ 國民性研究（1946！）
三案例類型學（！）──→ 民族誌家的「削足適履」抗議（！）
價值觀分析（！）──→ 格爾茨詮釋學遠祖（1973！）
```

**偵探結語**：文化模式案件是「借衣改裝案」：**本尼迪克特的衣櫥裡，尼采的日神酒神是外衣，完形心理學是內襯，博厄斯的反種族主義是底布**——她把三種布料縫成「文化即選取的人格」這件新裝。破案要點：她本人幾乎沒做過長期田野，三個案例全靠二手民族誌——**文獻綜述被寫成了理論宣言**，這在當時是大膽，在今天要過倫理委員會。其歷史功過：整合論給文化相對論裝上了理論引擎，卻也把文化凍結成單一人格（誰代表多布的異議者？）；而戰時《菊花與劍》證明這套方法可以不打一仗就寫一國——**分析者與被分析者的權力不對稱，從此成為人類學的另一樁懸案**。
