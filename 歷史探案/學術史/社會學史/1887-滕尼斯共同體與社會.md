# 1887-滕尼斯：共同體與社會——現代化的坐标系

## 案件摘要

1887 年，滕尼斯（Tönnies！石勒蘇益格人！）出版《共同體與社會》（Gemeinschaft und Gesellschaft！）——**兩個德文詞，劈開整個現代史**（！）：Gemeinschaft（共同體！血緣—地緣—精神！本質意志！）vs Gesellschaft（社會！契約—計算—交易！選擇意志！）；此前的背景：石勒蘇益格農村（滕尼斯的故鄉！丹麥統治→1864 普丹戰爭→普魯士吞併！）——**一個村莊被現代化碾過的親身目擊**；此後的影響：韋伯（「共同體關係」！）、齊美爾（都市陌生人！）、芝加哥學派（鄉土社會！）、甚至毛澤東《蘇區報告》的譯介——**現代化的坐標系**。這樁案件是「一個名詞的謀殺」：**用兩個概念，給舊世界驗屍、給新世界立案**。

## 前因 -- 多因素的局勢

- **出身**：1855 舊恩斯多夫（！農場主之子！）——**鄉村的血**（→「共同體是記憶」！）。
- **戰爭**：1864 普丹戰（！石勒蘇益格易手！）——**普魯士化**（→「農村被並入」！）。
- **師承**：霍姆霍爾茨（！哲學！）＋蘭克（！史學！）——**哲學＋歷史**（→「概念的工具」！）。
- **時代**：1871 德意志統一（！工業化狂飆！）——**失序的都市**（→「社會的焦慮」！）。

## 線索與推理 -- 因素咬合

### 線索一：石勒蘇益格——「被吞併的故鄉」

1864（普丹戰！）→ 1866（普奧戰！）→ 滕尼斯的村子（從丹麥→普魯士！）→ 法理接管（登記！地契！官僚！）→ 禮俗失效（→「共同體的死亡」！）：

$$\text{共同體之死} = \text{（戰爭併吞！）} \times \text{（法理接管！）} \Rightarrow \text{親身驗屍}$$

**故鄉就是解剖台**（→「我不是在抽象，我在報案」！）——農場的童年（！互助！節慶！）——**本質意志的樣本**（→ Wesenwille！）。

### 線索二：兩個概念——「一張現代化的地圖」

共同體（！血緣！地緣！友誼！）＝有機體（→「活在一起」！）；社會（！契約！交易！計算！）＝機械體（→「為了利益而聚」！）：

$$\text{Gemeinschaft} \xrightarrow{\text{（現代化！）}} \text{Gesellschaft}$$

**不可逆的箭頭**（→「歷史的方向」！）——但滕尼斯不是懷舊者（！他也承認社會解放個人！）——**不鄉愁的驗屍官**（→「分析而非哀悼」！）。

### 線索三：影響的擴散——「概念的家族樹」

韋伯（1922《經濟與社會》！共同體關係 vs 結合關係！）＋齊美爾（1903《都市與心智生活》！）＋芝加哥學派（1929 鄉土—都市連續體！Redfield！）：

$$\text{概念影響} = \text{（韋伯！）} + \text{（齊美爾！）} + \text{（芝加哥！）} \Rightarrow \text{整門學科的地圖}$$

**一個 1887 年的名詞**（！當年無人問津！）——**五十年後全世界的教科書**（→「概念的長跑」！）。

## 破案時刻

- 1855–1872：石勒蘇益格的童年（！）＋戰爭（！）——素材。
- 1877–1881：博士論文（Philister！）＋霍姆霍爾茨指導（！）——方法。
- 1887：《共同體與社會》出版（！）——破案。
- 1930s：芝加哥學派接棒（！Redfield！）——擴散。
- 1936：滕尼斯死於納粹上台之年（！）——舊世界的驗屍官隨舊世界而去。

## 後果 -- 改變了什麼

- **概念史**：Gemeinschaft 進入日常語言（→納粹還濫用了「Volksgemeinschaft」！滕尼斯本人 1930 反納粹！）。
- **社會學**：現代化理論的模板（→「傳統 vs 現代」！）。
- **都市研究**：鄉土—都市連續體（→「芝加哥」！）。
- **政治焦慮**：共同體的鄉愁（→保守主義！）——**概念被左右兩邊搶著用**。

## 因素影響筆記

```
石勒蘇益格（1864戰！）──→ 滕尼斯的鄉愁素材 ──→ 1887 兩概念出爐

芝加哥學派（1929！）──→ 現代化坐標系 ──→ 全世界教科書（概念長跑！）
```

**偵探結語**：滕尼斯的案件是「概念的偵探學」：他沒有發現新大陸（！現代化人人看見！），他做的是**給兩個看不見的兇手命名**——Gemeinschaft（死於普丹戰爭＋登記簿！）與 Gesellschaft（兇手本人也買了它的房！）——**驗屍官住在兇手家裡**（→普魯士公民！）。最深的諷刺：1933 納粹搶走「Volksgemeinschaft」這個詞（→濫用！），滕尼斯（78 歲！）簽名抗議後逝世——**概念比人活得久，也比人被歪曲得久**。而每個從農村走進城市的學生（！今天的我們！），都在不自覺地重演 1887 年那個石勒蘇益格孩子的觀察——**你不是讀了滕尼斯，你就是滕尼斯**。
