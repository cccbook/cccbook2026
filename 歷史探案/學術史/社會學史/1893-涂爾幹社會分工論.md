# 1893-涂爾幹社會分工論：社會學的開業執照

## 案件摘要

1893 年，愛彌兒·涂爾幹（Durkheim！猶太拉比世家出身的法國教授！）以博士論文《社會分工論》（De la division du travail social！）——**一頁答覆亞當·斯密，一頁起訴現代性**（！）——分工的功能不是增加產量，是**製造團結**（！）——兩種團結：機械團結（！相似性！集體意識強！壓制法！）vs 有機團結（！互賴！分化！恢復法！）——診斷現代社會的病灶：**失範（anomie）**（！分工被迫加速、缺乏規範！）——**社會學第一次正式地以「社會事實解釋社會事實」**（！）——這樁案件是「**用博士論文替一門學科申請營業執照**」（！）。

## 前因 -- 多因素的局勢

- **法國危機**：1870 普法戰敗（！）＋1871 巴黎公社（！）＋經濟蕭條（！）——**「社會如何凝聚」成為國家問題**（！）。
- **第三共和的教育重建**：世俗學校運動（！）——**涂爾幹＝共和國的教育工程師**（！）。
- **斯賓塞的挑戰**：分工＝自由競爭的產物（！）——**涂爾幹的靶子**（見 [1851-斯賓塞社會靜力學.md](1851-斯賓塞社會靜力學.md)）。
- **德國學院派**：瓦格納、謝夫勒的「社會學」講座（！）——**留德經驗**（！）。
- **猶太家庭背景**：拉比世家（！）——**「集體」的早年 imprint**（！）。

## 線索與推理 -- 因素咬合

### 線索一：功能主義方法——「先問功能，再問起源」

涂爾幹的方法革命（！）：

$$\text{社會事實} \neq \text{個體動機之和} \quad \text{（反還原！）}$$

「**一個社會事實的解釋，必須從它能產生的功能中尋找**」（！）——**功能分析的正式誕生**（→帕森斯！默頓！見 [1948-默頓自我實現預言.md](1948-默頓自我實現預言.md)）——**社會學獨立於心理學＋經濟學的憲法條款**（！）。

### 線索二：兩種團結——「社會的兩副骨架」

| | 機械團結 | 有機團結 |
|---|----------|----------|
| 基礎 | 相似性 | 差異互賴 |
| 集體意識 | **強而瀰漫** | 弱而抽象 |
| 法律 | 壓制法（刑法！） | 恢復法（民法、商法！） |
| 典型 | 傳統社會 | 現代社會 |

$$\text{分工} \uparrow \Rightarrow \text{個性} \uparrow + \text{互賴} \uparrow \Rightarrow \text{有機團結（新凝聚！）}$$

**分工不是病，是新的凝聚形式**（→直接對打霍布斯與斯密！見 [1776-亞當斯密國富論.md](1776-亞當斯密國富論.md)）——**法律類型學＝社會團結的指標**（！可觀測！可比較！）。

### 線索三：失範——「病理報告的第一頁」

分工的**異常形態**（！）：強制分工（！不公！階級！）、**失範分工**（！勞資衝突！規範真空！）——「**一旦勞動被分化，就需要一種新的道德**」（！）——**anomie 第一次成為社會學概念**（→自殺論！見 [1897-涂爾幹自殺論.md](1897-涂爾幹自殺論.md)）——**職業倫理與法團（corporation）作為處方**（！）。

## 破案時刻

- 1858：生於阿爾薩斯埃皮納勒（！）——猶太拉比世家。
- 1879–82：巴黎高師（！）——師承布特魯、費斯泰爾·德·庫朗熱（！）。
- 1885–86：留德一年（！）。
- 1887：波爾多大學首任「社會學與教育學」講席（！）——**法國第一個社會學教席**（！）。
- 1893：《分工論》答辯（！）——博士＋副論文〈孟德斯鳩與盧梭〉。
- 1895：《社會學方法的準則》（！）——方法憲法。
- 1896：《自殺論》研究啟動（！）——1897 出版（！）。
- 1902：巴黎大學（！索邦！）——1913 頭銜正式冠「社會學」（！）。

## 後果 -- 改變了什麼

- **學科制度化**：波爾多→索邦（！）→《社會學年鑑》1898（！）——**社會學從哲學的分支獨立出來**（！）。
- **功能分析**：帕森斯、默頓（！）——**結構功能論的家譜**（見 [1951-帕森斯社會系統.md](1951-帕森斯社會系統.md)）。
- **失範概念**：犯罪學（！）、偏差研究（！）——**默頓失範理論的源頭**（！）。
- **法團與職業倫理**：福利國家的社會學藍圖（！）——**塗爾幹的「中介團體」影響法國社會政策**（！）。

**偵探結語**：涂爾幹的案件是「**一個拉比之子為世俗科學舉行祝聖禮**」：《分工論》表面上答斯密、斯賓塞（！），實際上**在為第三共和國定做心臟**（！世俗化的集體意識！教育的救贖！）——**社會學在法國不是書房產物，是國家重建工程**（→教育學講席！德育課綱！）。最深的諷刺：他說分工製造團結（！），而他自己遭逢的分工（！猶太裔、外省人、在索邦被視為「外來者」！）讓他加倍需要「集體」這個詞——**德雷福斯案件（1894！）中他站在辯方**（！）——**社會學家是社會的辯護律師兼法醫**（）。而「失範」這個詞（！）從 1893 年出發，經過默頓的監獄、犯罪學的課堂，到今天每一則「躺平」與「內卷」的討論（！）——**規範真空不是學術概念，是生活在真實年代的呼吸困難**（！）。
