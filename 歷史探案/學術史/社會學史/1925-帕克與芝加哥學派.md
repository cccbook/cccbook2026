# 1925-帕克與芝加哥學派：把整座城市當作社會學實驗室

## 案件摘要

1925 年，羅伯特·帕克（Park！記者出身的社會學家！）與伯吉斯（Burgess！）主編《城市》（The City！）——**芝加哥學派（Chicago School！）的宣言**（！）——核心：**城市不是背景，是研究對象**（！）——**人類生態學（human ecology）**：城市像生態系統（！競爭！侵蝕！繼承！）——**同心圓理論**（伯吉斯！中央商業區→過渡區→工人住宅區→中產→通勤帶！）——**「把社區當作實驗室」**（！）——**都市社會學＋種族關係研究＋偏差研究的第一所重鎮**（！）——這樁案件是「**在美國最兇惡的城市裡，把混亂變成資料**」（！）。

## 前因 -- 多因素的局勢

- **芝加哥的瘋狂**：1833 小鎮→1900s 百萬大都會（！）——**世界最快的城市生長**（！）。
- **移民潮**：南歐！東歐！黑人遷徙！（！）——**「世界移民城」**（！）。
- **社會問題**：貧民窟！幫派！犯罪！娼妓！（！）——**「社會病態」的展示櫃**（！）。
- **帕克的經歷**：記者（！）＋杜波依斯秘書（！）＋布克·華盛頓助手（！）＋西默爾學生（！）——**多元視野的合成人**（見 [1903-杜波依斯黑人的靈魂.md](1903-杜波依斯黑人的靈魂.md)）。
- **洛克菲勒基金**：研究資金（！）——**制度化的推手**（！）。

## 線索與推理 -- 因素咬合

### 線索一：人類生態學——「城市是生物群落」

帕克借用植物生態學（！）：

$$\text{城市} = \text{競爭（！)} \Rightarrow \text{侵蝕（!)} \Rightarrow \text{繼承（!)} \Rightarrow \text{群落的更替}$$

**「社會距離」**（！移民！種族！）——**「陌生人」**（！齊美爾的遺產！）——**把城市當作「有機體」但拒絕生物決定論**（！）。

### 線索二：同心圓理論——「芝加哥的切片」

伯吉斯模型（！）：

| 圈層 | 內容 |
|------|------|
| 1 | 中央商業區（Loop！） |
| 2 | **過渡區**（貧民窟！工廠！）——**混亂與更新** |
| 3 | 工人住宅區 |
| 4 | 中產住宅 |
| 5 | 通勤帶 |

**「過渡區」是芝加哥學派的顯微鏡**（！）——**犯罪！幫派！貧民窟的實地調查**（！）——**克里西（Cressey！）的舞廳研究！佐巴夫的青少年幫派！肖與麥凱的少年犯罪地圖！**——**都市「自然區域」的概念**（！）。

### 線索三：實地調查傳統——「用腳做社會學」

方法（！）：

- **生活史**（！《索也的帽子》！波蘭農民！）——**第一人稱的社會學**（！）。
- **參與觀察**（！）——**「你必須弄髒雙手」**（帕克：**「去坐下來聽那些大人物談話是不夠的；你得去街角、去賭場、去下三濫的旅館」**！）。
- **多學科**（！）——**記者＋社會工作者＋學者**（！）。

**「參與觀察」的正式化**（！）——**影響懷特的街角社會（！1943！）**——**質性研究的源頭**（！）。

## 破案時刻

- 1864：帕克生於賓州（！）。
- 1899：哈佛哲學碩士（！）。
- 1905–13：杜波依斯與華盛頓的助手（！）——種族調查（！）。
- 1914：芝加哥大學（！）——**「大學應該研究城市」**（！）。
- 1921：《社會學導論》（與伯吉斯！）。
- 1925：《城市》（！）——**學派的宣言**（！）。
- 1929：《人類社區》（！）——**理論的成熟**（！）。
- 1933：赴華（！）——燕京大學授課（！費孝通是其學生！）。

## 後果 -- 改變了什麼

- **都市社會學**：同心圓！自然區域！（）——**城市規劃＋地理學＋犯罪學的共同語言**（！）。
- **種族關係研究**：戈登！布勞！（）——**美國種族社會學的基礎**（！）。
- **質性研究方法**：參與觀察＋生活史（！）——**社會學的方法多樣性**（！）。
- **國際傳播**：費孝通！燕京學派！（）——**中國社會學的芝加哥影響**（！）。

**偵探結語**：芝加哥學派的案件是「**把一個最混亂的城市當作最乾淨的實驗室**」：帕克的偉大（！）在於**拒絕道德譴責，只做結構分析**——**貧民窟不是「壞人」的聚落，是城市生態的功能區**（！）——**這一個立場，為社會學贏得了科學的尊嚴，也替官僚的冷漠鋪了路**（！批評！）。最深的諷刺：這群研究「社會距離」的人（！），本身就被黑人社區研究者（！杜波依斯！見 [1903-杜波依斯黑人的靈魂.md](1903-杜波依斯黑人的靈魂.md)）批評為**以白人視角掃描黑人**（！）——**觀察者的位置，永遠是他自己看不見的偏見**（！）。而今天（！）——「社會空間數據化！城市即平台！」——**每一張熱力圖、每一個導航避開的「紅區」，都是 1925 年同心圓的數位後代**（！）——**芝加哥學派教會我們：城市會說話，但它只對願意走到街上的人說真話**（！）。
