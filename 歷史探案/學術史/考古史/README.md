# 考古史 -- AI 偵探風格

以「推理探案」的方式，追查考古學的重大轉折：龐貝、羅塞塔、楔形文字、三期系統、尼安德塔人、特洛伊、甲骨文、圖坦卡門、殷墟、死海古卷、碳十四、兵馬俑、露西、三星堆、古DNA、光達、AI卷軸——
前因是什麼？線索在哪裡？推理如何展開？後果又如何改寫了人類史？

本卷的核心命題只有一句話：**考古史是「證據的發明史」。**
每一樁案件都是一次證據革命：地層（上下關係）、類型（形態序列）、文字（雙語鑰匙）、測年（絕對時鐘）、基因（分子檔案）、遙感（穿透植被）、AI（虛擬開卷）。證據變了，歷史就重寫了。每個重大發現都是一樁「多因懸案」：偵探的工作，就是把因素鏈一環一環還原出來。

## 考古學的證據革命：七種證據如何改寫歷史

| 證據 | 機制 | 經典案例 |
|------|---------------------|----------|
| **地層** | 上下疊壓即時間先後，挖寶變科學 | 梁思永後岡三疊層；特洛伊九層 |
| **類型** | 形態序列即演化，抽屜整理出時鐘 | 湯姆森三期系統；皮特—里弗斯 |
| **文字** | 雙語鑰匙復活死文字，地下對紙上 | 羅塞塔；貝希斯敦；甲骨二重證據 |
| **測年** | 絕對時鐘校準相對序列 | 碳十四；鉀氬；年輪IntCal |
| **基因** | 分子檔案追溯親緣遷徙 | 尼人混血；丹人EPAS1；夏娃 |
| **遙感** | 穿透植被揭露城市全貌 | 光達吳哥；Pacunam瑪雅 |
| **AI** | 虛擬開卷識別未解文字 | 赫庫蘭尼姆卷軸；線A印度河在排隊 |

## 證據的回饋迴路

```
              ┌────（偶然發現：農民—工人—少年—牧羊童）────┐
              ↓                                          ↓
   遺址 ──→ 偶然 ──→ 業餘者 ──→ 權威驗證 ──→ 學科 ──→ 技術 ──→ 新遺址
    │                  ↑        ↑                     │
    │                  │        │                     ↓
    └──→ 殖民—民族主義 ←── 博物館 ←── 申遺旅遊 ──→ 保護倫理
              ↑                            ↑
              └── 戰爭—政治 ←──（破壞與返還）┘

   正向迴路（加速）：發現→媒體→經費→技術→更多發現
   正向迴路（加速）：文字破解→王表→年代→更多破解
   負向迴路（抑制）：權威壟斷→延遲（阿爾塔米拉14年、死海40年）
   考古迴路（本卷特有）：偶然→業餘→權威→技術→偶然
```

**偵探的訣竅**：找到「誰發現、誰驗證、誰壟斷、誰平反」，把鏈條畫出來；再問一句——**證據是什麼（地層？文字？基因？）？**案件的因果鏈就浮現了。

## 偵探的結案陳詞

二百五十年的考古史，可以壓縮成三條因果鏈：

1. **證據鏈**：地層（上下！）→ 類型（序列！）→ 文字（雙語！）→ 測年（絕對！）→ 基因（分子！）→ 遙感（穿透！）→ AI（開卷！）——**每一種新證據，重寫一次歷史**。
2. **人物鏈**：偶然（農民工人少年！）→ 業餘（教師商人建築師！）→ 權威（驗證壟斷！）→ 平反（認錯解放！）——**發現靠偶然，確認靠權威，進步靠認錯**。
3. **政治鏈**：殖民（修復統治！）→ 民族（認同建構！）→ 戰爭（破壞流失！）→ 申遺（國際保護！）→ 返還（正義！）——**鏟子下面是政治**。

三條鏈咬合在一起，就是本卷三十五樁案件的全部真相。
