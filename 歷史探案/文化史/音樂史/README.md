# 音樂史 -- AI 偵探風格

音樂是聽覺的建築：從泥版上的頌歌到串流上的演算法，本書以「推理探案」的方式，追查每個音樂事件背後的**前因、推動力與組織**——誰出資？誰立法（教義/專利/平台規則）？誰反抗？聲音的政治如何隨時代轉向？

## 主線索：貫穿三千年的推動力

1. **記譜即權力**：誰能記下音樂，誰就能支配它的傳播——楔形文字（前1400）、紐姆譜（1025）、印刷樂譜（1501）、MIDI/CD（1982）、串流資料庫（2015）。
2. **音與數的統一**：畢達哥拉斯（前550）→ 平均律調音（1691）→ 十二音列（1923）→ 數位取樣——每次「音樂可以被計算」都重定義作曲。
3. **場所的政治**：教會（0590）→ 宮廷（1607、1721）→ 公眾音樂廳（1808）→ 錄音室（1954）→ 網路（1999）——每一個新場所都創造新的音樂職業與新的聽眾。
4. **儀式與反抗**：聖歌的規範 vs 民間的狂歡；藍調與爵士出於底層（1920、1959），搖滾與龐克的憤怒（1954、1976），前衛的爆破（1913）。
5. **跨界與混血**：爵士×古典（1924）、民俗×前衛（1913）、黑人音樂×白人市場（1954）、AI×人類（2023）——偉大的音樂常誕生在文化的斷層線上。
