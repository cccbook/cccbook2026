# 舞蹈史 -- AI 偵探風格

舞蹈是人類最古老的藝術：在文字之前，身體就是第一個記錄儀。本書以「推理探案」的方式，追查每個舞蹈事件背後的**前因、推動力與組織**——誰出資？誰立法？誰反抗？身體的政治如何隨時代轉向？

## 主線索：貫穿三千年的推動力

1. **儀式 → 劇場 → 展演**：從祭祀（希臘酒神、印度吠陀、唐代郊廟）到職業劇場（1661 學院制），再到純粹展演（1962 Judson）。
2. **身體的政治**：誰的身體可以動、怎麼動——教會禁舞（0500）、太陽王的身體即王權（1653）、蘇聯對芭蕾的國家化、街舞對體制的反抗（1973）。
3. **技術即語言**：記譜法（1700 Feuillet、1928 Laban）、足尖（1832）、地面動作（Graham）——每次技術突破都重定義「舞蹈是什麼」。
4. **性別與身體**：男舞者獨尊（路易十四時代）→ 女舞者登台（1681）→ 女性編舞家（Graham 1926）。
5. **跨文化流動**：絲路樂舞入唐（0713）、意大利舞入法（1581）、俄國舞入西歐（1909）、街舞出紐約（1984）、K-Pop 出首爾（2012）。
