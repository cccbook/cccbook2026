# 1489 - 宴會劇：芭蕾的史前案件的現場

## 案件摘要
1489 年，意大利北部小城**托爾托納**（Tortona）：宮廷侍臣**貝爾岡喬·迪·博塔**（Bergonzio di Botta）為米蘭公爵夫人**伊莎貝拉·阿拉貢**（Isabella d'Aragona）的到訪設計了一場史無前例的盛大宴會娛樂——後世稱「**博塔的凱旋**」（Trionfo di Botta）。宴會的每道菜上桌，都伴隨舞蹈、音樂、佈景與機關：主題是「阿爾戈號遠征」（金羊毛神話），舞者扮成伊阿宋與同伴，從一幕「航行」演到另一幕。**這被視為芭蕾的史前案件現場：第一次把舞蹈、音樂、佈景、機關與敘事統合成一場總體劇場。**

## 前因 -- 為什麼會有這個案子
- **意大利城邦的宴會競賽**：15 世紀的費拉拉、米蘭、佛羅倫斯、曼圖亞等城邦宮廷，以宴會娛樂的規格互相較勁——**排場是外交語言**，請柬是一場宣傳戰。托爾托納地方法官博塔辦這場宴會，正是小城向米蘭公國展示忠誠與財力的公關工程。
- **幕間劇（intermedio）**：15 世紀意大利的正式戲劇（拉丁喜劇）之間穿插神話主題的歌舞幕間——幕間越來越比本戲精彩。音樂、佈景、機關的技術在幕間劇中持續累積。
- **宮廷舞蹈教師的興起**：1455 年前後，皮埃蒙特的**多梅尼科·達·皮亞琴察**（Domenico da Piacenza）寫下歐洲第一篇舞蹈理論，並獲聘為費拉拉宮廷舞蹈教師——歐洲第一批有名有姓的職業舞師誕生（見 `1300-Carole圓舞.md`）。

## 線索與推理 -- 總體劇場的組裝

### 博塔宴會的結構：一頓飯演一齣神話
後世檔案（同代人書信與記載可考）顯示宴會的統合設計：

| 元素 | 內容 |
|------|------|
| 敘事 | 阿爾戈號遠征——金羊毛的神話旅程 |
| 舞蹈 | 舞者扮伊阿宋與阿爾戈英雄，逐一登場 |
| 音樂 | 專為各幕創作的器樂與歌唱 |
| 佈景與機關 | 桌景即佈景：城堡、海洋、船隻，配機關變換 |
| 菜餚 | 每道菜對應神話中的一幕——上菜即換景 |

**推理**：這不是「宴會＋餘興」，而是**總體劇場**（Gesamtkunstwerk 的史前原型）：所有感官元素被統合進一條敘事線。166 年後華格納追求的「總體藝術」，1489 年的宴會廳裡已經預演。

### 誰執行：maestro di ballo 的職業化
博塔宴會的舞蹈由專業舞師設計指導——「**maestro di ballo**」（舞蹈大師）從此成為意大利宮廷的標準職位。這個職業的出現是本案的關鍵線索：**舞蹈從社交活動（carole 的即興）變成可設計、可教授、可跨境輸出的專業技藝**。意大利宮廷培養的舞師是一個「人才物流系統」，而他們的下一站是——法國。

### 推動力與組織
- **誰出資**：托爾托納地方政府與米蘭宮廷——宴會是政治投資，花費以「國家預算」的規格計算。
- **誰推動**：意大利城邦的宮廷文化（費拉拉的 Este 家族、米蘭的 Sforza 家族）——競爭機制逼出創新。
- **誰受益**：舞師階層——職業地位確立，待遇以「宮廷要員」計。
- **誰反抗**：道德家照例抨擊排場奢靡——但城邦競賽的邏輯無視告誡，排場只增不減。

## 結案 -- 後果與影響
- **總體劇場的範式確立**：舞蹈＋音樂＋佈景＋機關＋敘事的統合成為宮廷慶典的標準——1539 年佛羅倫斯（科西莫一世婚禮）、1554 年以降的 intermedio 大作持續累積技術。
- **舞師北伐**：1533 年，佛羅倫斯的**凱瑟琳·德·美第奇**（Catherine de' Medici）嫁入法國王室，把意大利舞師、機關師與慶典文化整批帶去巴黎——這是意大利宮廷文化的「人才輸出」最關鍵的一票。
- **直通芭蕾**：凱瑟琳主政的 1581 年，她的意大利舞師 **Beaujoyeulx** 在巴黎羅浮宮推出《王后喜劇芭蕾》——博塔宴會的直系繼承人，且規格更大、更制度化（見 `1581-王后喜劇芭蕾.md`）。
- **芭蕾的族譜**：1489 托爾托納 → 1533 美第奇嫁入法國 → 1581 王后芭蕾 → 1653 夜之芭蕾（見 `1653-夜之芭蕾.md`）→ 1661 皇家舞蹈學院（見 `1661-皇家舞蹈學院.md`）——芭蕾不是一夜發明，而是**兩百年宮廷工程的總合**。

## 關鍵人物與文獻
- **Bergonzio di Botta**（15 世紀）：托爾托納宴會設計者——「博塔的凱旋」
- **伊莎貝拉·阿拉貢**（1470–1524）：米蘭公爵夫人、宴會的貴賓
- **Domenico da Piacenza**（約 1420–75）：歐洲第一篇舞蹈理論作者、費拉拉宮廷舞師
- **Catherine de' Medici**（1519–1589）：意大利舞師的輸出者、法國宮廷芭蕾的總推手
