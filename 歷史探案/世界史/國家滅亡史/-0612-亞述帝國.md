# -0612 亞述帝國：殘暴招來的聯軍斬首

## 案發現場

公元前 612 年，新巴比倫（那波帕拉薩爾）+米底（基亞克薩雷斯）聯軍攻陷亞述首都尼尼微——屠城、焚宮，亞述帝國（橫跨近東的軍事巨獸）迅速灰飛煙滅（殘部 609 年滅）。亞述以殘暴聞名：剝皮、釘樁、徙民，宮殿浮雕炫耀酷刑。建國靠恐怖，亡國也因恐怖——仇恨的複利到期了。

> **恐怖能建國，為何保不住國？當所有鄰居都恨你，聯盟的形成需要幾個受害者？**

## 偵查過程

**線索一：恐怖統治的資產負債表。** 亞述政策：屠城立威（反抗者剝皮示眾）、大規模徙民（打散認同）、重稅（供養常備軍）。短期收益：征服順利（聽說屠城就投降）；長期成本：**仇恨記賬**——每個被屠的城市都是未來的聯軍成員。偵查結論：恐怖是**高利貸**：借來的順從，利息是仇恨——到期（亞述衰弱）一次償還。尼尼微陷落時，聯軍中有太多「前受害者」（巴比倫被西拿基立毀過、米底被擄過）——**受害者聯盟是恐怖政策的標準產出**。希特勒（參見本書 [1945-納粹德國.md](1945-納粹德國.md)）同理：殘暴製造反法西斯聯盟——**敵人的敵人自動結盟，恐怖是最好的紅娘**。

**線索二：巴比倫—米底聯盟（不可能的聯姻）。** 巴比倫（閃族）+米底（伊朗人）素無交情——聯姻（尼布甲尼撒娶米底公主）+共同敵人（亞述）=聯軍。偵查結論：聯盟的公式——**共同仇恨＞一切分歧**：沒有亞述的殘暴，巴米不可能聯手（語言宗教皆異）。亞述的外交（無盟友，全是附庸+仇敵）注定結局：**零和外交的終點是所有人聯合起來對付你**。對照秦（遠交近攻，參見 [../世界發展史/-0221-秦統一.md](../世界發展史/-0221-秦統一.md)）：秦至少有盟友（輪流），亞述一個沒有——**外交信用為零的帝國，崩潰時無人扶**（參見蘇聯解體，[本書 1991 篇](1991-蘇聯解體.md)：紅旗落地無人扶，同款）。

**線索三：尼尼微的速陷（首都的虛胖）。** 尼尼微城牆宏偉（15 公里、15 座城門）、護城河、皇家軍械庫——但守軍是拼湊（附庸部隊倒戈）、河水倒灌（一說底格里斯河漲水沖垮城牆，預言應驗）。偵查結論：**首都的堅固是紙面的**：城牆擋得住軍隊，擋不住背叛（附庸開門）+天災（河水）。圍城三個月即破——對比亞述圍別人（拉吉、耶路撒冷）經年，**屠人者被屠只用一季**。速陷的真正原因：帝國末代（辛沙立什昆）眾叛親離——**首都陷落的速度=眾叛親離的程度**。城牆的厚度從來不是防禦力，人心的向背才是。

**線索四：灰飛煙滅（為何無人復國）。** 亞述亡後無復國運動（對比猶太、波蘭）——語言（阿卡德語）被阿拉姆語取代，認同消散。偵查結論：恐怖政策的終極代價：**沒有朋友，連同情者都沒有**——亡國時無人掉淚（聖經《那鴻書》歡呼尼尼微陷落：「萬民拍掌」）。**認同是復國的種子**：猶太有信仰、波蘭有語言，亞述只有恐懼——恐懼隨施暴者入土。滅亡的徹底性定理：**被恨的程度=被遺忘的速度**——亞述被恨透，故被忘光。此案給所有恐怖統治的忠告：**你可以靠恐懼統治活人，但恐懼養不出替你收屍的人**。

## 結案報告

1. **恐怖即高利貸**：借順從，還仇恨——受害者聯盟是標準產出。
2. **零和外交必死**：無盟友全仇敵——崩潰時無人扶，紅娘是恐怖。
3. **城牆即紙面**：速陷三個月——防禦力=人心向背，不是牆厚。
4. **被恨即被忘**：無復國無同情——恐懼養不出收屍人。

**仇恨複利（示意）：**

```
每年恐怖 → 仇恨記賬（+利息）。
亞述衰弱（末代內亂）→ 債主聯合討債（巴米聯軍）。
償還：首都＋帝國＋認同——一次付清。
```

**結論：** 亞述案是「恐怖滅國」的標準樣本：借來的順從連本帶利還，債主是所有受害者，收債人是聯軍。**恐怖是最貴的統治——便宜在當下，貴在結賬**。尼尼微的灰燼裡沒有復國的火星，只有《那鴻書》的掌聲——被恨透的帝國，連墓誌銘都是別人寫的賀電。
