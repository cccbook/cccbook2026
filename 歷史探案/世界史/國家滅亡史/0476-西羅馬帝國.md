# 0476 西羅馬帝國：奧多亞克廢帝與轉型之辯

## 案發現場

公元 476 年，日耳曼傭兵領袖奧多亞克廢黜末代西羅馬皇帝羅慕路斯·奧古斯圖路斯（16 歲少年），將帝徽寄往君士坦丁堡，自任義大利王。傳統史學以此為西羅馬滅亡標誌（愛德華·吉本《衰亡史》）。但現代史學爭論：是「浩劫說」還是「轉型說」——羅馬法、拉丁語、教會全活著，死的只是皇帝和稅收。

> **476 年到底死了什麼？貨幣劣化、軍隊蠻族化、東西分治——西羅馬是病死的，還是被分死的？**

## 偵查過程

**線索一：銀幣劣化（通膨的慢性毒藥）。** 三世紀危機起，銀幣（第納爾）含銀量從 95% 降至 5%（加里恩努斯時代近乎銅幣），物價飛漲（戴克里先限價令形同廢紙）。偵查結論：這是**古代版量化寬鬆**：軍費（蠻族邊防壓力）+稅收（貨幣稅收實值縮水）→鑄幣稀釋→通膨→稅收再縮水——**死亡螺旋**。君士坦丁改金幣（索利都斯，324 年）穩住東部，西部跟不上（金礦少、貿易逆差）。**貨幣信用是帝國的體溫**：體溫（幣值）歸零時，軍隊（拿廢紙當餉）不再效忠——蠻族傭兵要的是土地（實物），不是廢幣。通膨把軍隊推向土地賞賜→軍隊蠻族化→皇帝被廢——**貨幣崩潰是第一塊骨牌**（參見財政亡國鏈，[本書 1933 篇](1933-魏瑪共和國.md)：同一公式，紙幣版）。

**線索二：軍隊蠻族化（傭兵的反客為主）。** 三世紀起，羅馬公民不願當兵（逃兵役），軍隊日耳曼化（哥特、法蘭克、汪達爾充斥），將領（斯提利科、埃提烏斯、里西梅爾）多為蠻族或半蠻族。偵查結論：這是**國防外包的終點**：外包（同盟者條約）→依賴（野戰軍全蠻族）→反噬（奧多亞克索要土地被拒即廢帝）。**誰拿槍，誰就是主人**——皇帝（羅慕路斯，名字諷刺：建城者+開國者合體）無一兵一卒，廢立只是一道手續。與秦（郡縣兵，參見 [../世界發展史/-0221-秦統一.md](../世界發展史/-0221-秦統一.md)）對照：**暴力壟斷外包之日，即主權讓渡之時**。奧多亞克沒有「滅亡」羅馬，他只是**把外包合同撕了，自己當甲方**。

**線索三：東西分治（分家埋下的雷）。** 395 年狄奧多西死後永久分治：東部（君士坦丁堡，富庶、貿易、長城）+西部（羅馬，空心、蠻族、無錢）。偵查結論：分治是**風險隔離**（東部活下來，活了一千年，參見本書 [1453-拜占庭帝國.md](1453-拜占庭帝國.md)），也是**見死不救的許可證**：455 年汪達爾洗劫羅馬，東部按兵不動（留著錢打波斯）。**分家的兄弟，死時不奔喪**——東羅馬給奧多亞克封官（貴族頭銜），承認既成事實。476 年的真相：不是羅馬死了，是**西部分公司倒閉，總公司（東部）不注資**。吉本的「滅亡」是西歐中心視角——君士坦丁堡的人覺得，羅馬一直活著（他們自稱羅馬人到 1453 年）。

**線索四：轉型之辯（死了皇帝，活了主教）。** 476 年後：羅馬法（蠻族法典抄襲）、拉丁語（教會+學者用）、基督教會（主教接管城市行政，格里高利一世）、莊園制（大土地所有制延續）——全活著。偵查結論：現代史學（彼得·布朗）主張**轉型非滅亡**：死的是稅收機器（中央集權）和皇帝（元首制），活的是文明底盤（法律語言宗教）。**國家的兩層皮**：上層（政權）可換，下層（文明）長存——蠻族王（狄奧多里克）穿羅馬官服、用羅馬法官、修羅馬水道。476 年的精確定義：**西羅馬中央政府的營業執照被吊銷，羅馬文明有限公司繼續營業**（換了蠻族主事者）。滅亡史的分類學：**政權亡≠文明亡**（參見波斯，[本書 -0330 篇](-0330-波斯阿契美尼德.md)：同款）。

## 結案報告

1. **貨幣先死**：銀幣 95%→5%——通膨推軍隊要土地，土地推蠻族掌權。
2. **外包即讓渡**：軍隊全蠻族——誰拿槍誰是主人，廢帝只是撕合同。
3. **分家不救**：東部見死不救——分公司倒閉，總公司不注資還發追認函。
4. **政權亡文明活**：皇帝死，主教活——營業執照吊銷，公司繼續營業。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 滅亡工程 | 跨域效應 |
|------|----------|----------|

| 經濟 | 銀幣劣化、稅收實值崩 | 財政死亡螺旋 |
| 科技 | 軍事技術停滯（對蠻族無代差） | 無力回天 |
| 政治 | 奧多亞克廢帝 | 西部政府關門 |
| 文化 | 教會接管城市 | 文明底盤存續 |

**東西羅馬（分家對照）：**

| 項目 | 東部（活到 1453） | 西部（亡於 476） |
|------|-------------------|------------------|
| 貨幣 | 金幣索利都斯 | 銀幣變銅幣 |
| 軍隊 | 本土+希臘火（後） | 全蠻族傭兵 |
| 首都 | 君士坦丁堡（要塞） | 羅馬（空城）/拉文納 |
| 鄰居 | 波斯（可談） | 蠻族（住進來了） |

**死亡螺旋（示意）：**

```
軍費↑ → 鑄幣稀釋 → 通膨 → 稅收實值↓ → 再稀釋
  → 幣成廢紙 → 軍隊要土地 → 蠻族掌權 → 皇帝被廢。
第一塊骨牌是貨幣，不是蠻族。
```

**結論：** 西羅馬案是「慢性滅亡」的總複習：貨幣先死（通膨）、軍隊再死（外包）、兄弟見死不救（分治）、文明續命（教會）——476 年死的只是一個營業執照。**吉本寫的是訃告，布朗寫的是轉院通知**——都對，看你查的是政權還是文明。本書的立場：查政權，476 年死亡確認；查文明，它活到了今天（羅馬法還在）。
