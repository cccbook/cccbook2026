# 0651 薩珊波斯：與拜占庭互耗後的阿拉伯收屍

## 案發現場

651 年，末代薩珊王伊嗣埃三世在木鹿被殺（一說被磨坊主為錢所殺），薩珊波斯（224–651，四百年，瑣羅亞斯德教帝國）滅亡。此前：卡迪西亞之戰（636，阿拉伯勝）、尼哈萬德之戰（642，「勝利之勝利」）、首都泰西封陷落（637）。曾與拜占庭分庭抗禮的帝國，被新興的阿拉伯哈里發國十五年推平。

> **四百年帝國為何十五年就亡？拜占庭打了四百年沒打死，阿拉伯十五年就收屍——薩珊死於新敵人，還是死於老對手？**

## 偵查過程

**線索一：拜占庭互耗（二十六年總力戰）。** 602–628 年，庫思老二世與拜占庭希拉克略打了 26 年——波斯一度攻陷耶路撒冷（614，奪聖十字架）、亞歷山大（619）、兵臨君士坦丁堡（626），希拉克略反攻（627 尼尼微之戰），波斯慘敗求和。偵查結論：這是**雙輸的總力戰**：波斯贏了地盤（短暫），輸了國力（財政空、軍隊殘、貴族離心）；拜占庭同樣殘血（靠希拉克略個人能力續命）。**老對手互捅二十六年，新敵人在旁邊滿血看戲**——阿拉伯（穆罕默德 622 年建國，正好在戰爭中段）全程觀摩，學會了雙方戰術。薩珊死於拜占庭之手（耗盡），阿拉伯只是收屍——**兇手是老對手，收屍的是新鄰居**。滅亡史定理：**長期對手互耗的最大受益者，永遠是第三方**（參見三國：一戰打殘歐洲，美國摘桃）。

**線索二：貴族離心（庫思老的眾叛親離）。** 庫思老二世晚年猜忌（殺功臣、重稅），貴族廢殺之（628，兒子喀瓦德二世弒父），此後四年換五王（宮廷走馬燈）。阿拉伯入侵（633）時，波斯無統一指揮（伊嗣埃年幼，貴族各保地盤）。偵查結論：**內耗的政治學**：二十六年戰爭透支合法性（敗仗+重稅），貴族用弒君止損——但弒君開了潘多拉盒（誰都可以廢王），中央權威碎裂。卡迪西亞（636）波斯軍雖眾（號稱十萬），指揮分裂（貴族各懷心思）——**人數在組織分裂面前歸零**。與波斯阿契美尼德（參見本書 [-0330-波斯阿契美尼德.md](-0330-波斯阿契美尼德.md)）對照：同樣拼盤大軍、同樣一戰即崩——**波斯帝國的死法是遺傳的：中央一弱，拼盤即散**。

**線索三：阿拉伯的新戰法（沙漠閃電+信仰加成）。** 哈立德·本·瓦利德（「安拉之劍」）沙漠行軍（伊拉克—敘利亞穿越無人區）、駱駝機動、輕裝速決；士兵有信仰加成（殉教上天堂）+戰利品（五分之四歸戰士）。偵查結論：這是**不對稱戰爭的早期版**：輕（沙漠機動）打重（波斯重騎兵+戰象，卡迪西亞戰象踩踏自家）、新（信仰+分贓激勵）打舊（欠餉+離心）。**激勵機制的代差**：阿拉伯戰士為天堂+戰利品打仗（全押），波斯士兵為欠餉的貴族打仗（混日子）——**all-in 對混日子，不用打就知道結果**。尼哈萬德（642）後，波斯再無野戰軍——**十五年推平四百年，靠的不是人多，是對面不想打**。

**線索四：伊嗣埃之死（末代皇帝的流浪）。** 伊嗣埃三世（11 歲即位）東逃：木鹿→吐火羅→求助唐朝（661 年其子卑路斯入長安，設波斯都督府，客死）。磨坊主為錢殺之（一說）——四百年帝國的皇帝，死於貪財的磨坊主。偵查結論：**末代的流浪是帝國的體溫計**：還有人護送（將軍、祭司），說明法統未死；越逃越遠（木鹿已是邊疆），說明實地全失。向唐求助（卑路斯）是**國際版的借師助剿**（參見新羅，[../韓國史/0676-新羅統一.md](../韓國史/0676-新羅統一.md)）——唐太宗自身難保（剛滅東突厥，忙）+太遠，借不到。**求救信的投遞距離=帝國的絕望程度**：從泰西封逃到長安求救，絕望值拉滿。磨坊主的刀只是句號——**帝國死於卡迪西亞，伊嗣埃多活了十五年（流浪的餘溫）**。

## 結案報告

1. **互耗定律**：老對手打殘，新鄰居收屍——第三方永遠是最大受益者。
2. **拼盤遺傳**：中央弱即散——波斯帝國的死法四百年不變。
3. **激勵代差**：全押對混日子——信仰+分贓勝欠餉+離心。
4. **流浪體溫計**：求救距離=絕望程度——帝國死於卡迪西亞，皇帝多活十五年。

**收屍公式（示意）：**

```
滅亡 ＝ 互耗（26 年掏空）× 內亂（四年五王）＋ 新敵（信仰加成）。
薩珊死於拜占庭（耗盡），葬於阿拉伯（收屍）。
兇手與葬禮承辦人不是同一家——這是常態。
```

**結論：** 薩珊案是「互耗滅國」的標準樣本：二十六年打殘自己，四年五王打散指揮，阿拉伯十五年收屍，皇帝流浪到長安求救。**帝國最危險的時刻不是有強敵，而是和老對手同歸於盡的路上——新敵人正在旁邊滿血熱身**。四百年波斯，死於一場看了二十六年的戲，和一封寄到長安的求救信。
