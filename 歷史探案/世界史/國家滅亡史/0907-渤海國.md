# 0907–926 渤海國：海東盛國的速亡之謎

## 案發現場

926 年（正月—二月），契丹皇帝耶律阿保機親征渤海，攻克上京龍泉府，末王大諲譔出降——立國 228 年的「海東盛國」，在**不到半年**內滅亡。此前：907 年唐朝崩解（參見 [0907-唐朝.md](0907-唐朝.md)），東亞秩序真空；契丹統一草原諸部，九年後揮師東進。滅國後阿保機改渤海為「東丹國」（東契丹之意），以長子耶律倍為人皇王治理，實為傀儡政權；渤海遺民大批南奔，王氏高麗（918 建國，參見 [../韓國史/0918-高麗建國.md](../韓國史/0918-高麗建國.md)）陸續收容數十萬計的渤海遺民。一個文化昌盛、號稱盛國的政權，為何亡得比誰都快？

> **「海東盛國」的盛，究竟是國防的盛，還是宮殿的盛？契丹的刀為何一揮即中？**

## 偵查過程

**線索一：鄰國崛起——權力轉移理論的草原版。** 按 Organski 的權力轉移理論，戰爭最易發生於**崛起國追上守成國、且對現狀不滿**之時。九世紀末的東北亞正是如此：渤海是區域守成強權（仿唐制設五京十五府，遣使日本、通好新羅），契丹則是暴起的新興國（907 阿保機稱汗，916 建國）。對阿保機而言，渤海不僅是「不滿現狀者眼中的障礙」，更是**可掠奪的人口、糧倉與合法性獎品**——中原已亂，征服渤海可向草原諸部證明：取代唐的東亞新秩序由契丹定義。偵查結論：**渤海之亡的殺手不在境內，在境外**——鄰國的崛起速度，遠超守成國的警覺速度（參見 [../北亞史/0907-契丹遼朝與燕雲.md](../北亞史/0907-契丹遼朝與燕雲.md)）。

**線索二：戰略突襲——失去屏障的閃電戰。** 渤海立國的地理邏輯，是靠松花江—長白山一線的地緣屏障抵擋西面的草原騎兵；且唐亡之前，渤海與契丹之間隔著營州一帶的緩衝地帶。907 年後屏障消失：契丹先吞奚、平室韋，再降黑車子諸部，**把刀架到渤海門口的每一步都沒有遭到干預**。925 年十二月契丹大舉東征，翌年正月初越過邊境，十三天後攻陷扶餘府，再南下直取上京——末王大諲譔舉城投降，前後不足一個月。偵查結論：這是**標準的安全困境單向崩潰**——渤海多年承平，把契丹的擴張當作「內部事務」，等它覺察威脅時，動員窗口已經關閉；突襲的邊際成本極低，因為防禦方的警報系統早已鏽死。

**線索三：盛國的內部鏽蝕——承平二百年的代價。** 渤海後期（大玄錫、大瑋瑎、大諲譔在位期間）史載「渤海勢衰，政亂」，貴族內鬥、朝綱廢弛；考古所見上京宮室愈修愈奢，而邊防記錄愈來愈少。九世紀末至十世紀初，陸續有渤海貴族率部投契丹——**逃亡本身就是警報**，中央卻無整軍經武的動作。偵查結論：這是「盛國悖論」：文明化的成功（漢化、都市化、佛寺經濟）與軍事化衰退同步進行。對照同樣漢化的高句麗（參見 [../北亞史/0037-高句麗帝國.md](../北亞史/0037-高句麗帝國.md)）：高句麗強在山城與動員體制，渤海富在宮室與詩書——**富而不設防，是給鄰居看的菜單**。

**線索四：亡而未絕——遺民的去向證明了什麼。** 契丹滅渤海後設東丹國，隨即強遷渤海豪族於遼東（後又南遷燕雲），並鎮壓 926 年後陸續出現的復國運動（定安國、興遼國等，皆旋起旋滅）；大批遺民渡鴨綠江投高麗，高麗太祖王建一律收容授官，視渤海為「同源之國」。偵查結論：遺民的大規模流亡證明——**國家滅亡不等於社會滅亡**：渤海的技術（製鐵、製陶）、僧侶與文官，一部分融入高麗建國的骨血，一部分成為遼的行政人才。但復國運動全部失敗也證明：**沒有根據地與外部庇護的遺民，只能做人才，做不了復仇者**。

## 結案報告

1. **鄰國崛起即喪鐘**：權力轉移窗口（唐亡真空期）被契丹獨佔；守成者渤海未投一兵一卒去拖延這個進程。
2. **屏障丟失＋戰略突襲**：緩衝地帶被契丹逐步蠶食而無反應，最後一擊一個月亡國——警報鏽死的代價。
3. **盛國悖論**：二百年承平把軍事化換成文明化，富招刀，刀至無兵。
4. **滅而有人收**：遺民投高麗成為王氏建國的助力——亡國者的餘燼，可以在鄰居的爐灶裡復燃。

```

契丹吞奚、室韋（緩衝消失）→ 渤海零反應；
925 十二月出兵 → 926 正月陷扶餘 → 二月上京降。

```

**結論：** 渤海案是「文明亡於鄰國崛起」的極速樣本：殺死它的三把刀——**鄰國崛起**（契丹填補唐亡真空）、**勢力消長**（草原軍事化 vs 農耕文明化）、**發動戰爭**（一場零預警的戰略突襲）——沒有一把是在渤海境內鍛造的。海東盛國的「盛」，盛在宮殿與佛寺；契丹的刀落下時，才發現盛國從來沒有第三道城牆。遺民南渡高麗，算是這樁案件唯一的安慰結局：**國亡了，人與技藝活了下來**。
