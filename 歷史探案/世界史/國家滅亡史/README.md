# 國家滅亡史：案例集（推理探案）

> 國家為何滅亡？阿卡德帝國是被乾旱殺死的，還是被自己殺死的？秦朝三年而亡——是趙高的錯、胡亥的錯，還是制度的錯？西羅馬是被蠻族推倒的，還是自己先爛掉的？南宋死於蒙古的刀，還是死於會子的印刷機？印加帝國是被 168 個西班牙人打敗的，還是被天花和內戰打敗的？波蘭是被鄰國瓜分的，還是被自己的否決權癱瘓的？蘇聯沒有打一槍就解體了——沒有兇手的命案怎麼破？保加利亞死於拜占庭的復興，渤海死於契丹的崛起，雅典死於自己發動的戰爭——**鄰國在長大，而你在變老**，這是不是最常見的死法？
>
> 本書是一部「國家滅亡案例集」，以「推理探案」的方式，為 71 個滅亡案例各寫一篇 wiki：案發現場（怎麼亡的）、偵查過程（前因後果與學術理論）、結案報告、證據與工具（跨領域影響矩陣＋滅亡公式）。每篇檔名以滅亡年份開頭（西元前以負號表示，四碼不足補零）。
>
> 本書的核心命題：**滅亡從來不是單一死因，而是「壓力—脆弱性模型」**——內部制度高度脆弱（財政空虛、政治腐敗、認同分裂）時，一次外在衝擊（外敵、氣候、通膨）即如塔羅牌般倒塌。每篇 wiki 都用量化公式與對照表，還原這個連鎖反應。
>
> 本書特別強化「外力三因素」：**鄰國的崛起**（新興強權改寫力量對比——權力轉移理論）、**勢力消長**（貿易改道、保護人易手、權力真空傳導）、**發動戰爭**（先發制人、掠奪性入侵、跨海遠征）。三因素與內部脆弱性相乘，才是完整的滅亡公式。

## 國家崩潰五維度模型

```
       ┌─────────────────────────────────────────┐
       │             國家崩潰五維度模型          │
       └────────────────────┬────────────────────┘
                            │
     ┌───────────┬──────────┼───────────┬───────────┐
     ▼           ▼          ▼           ▼           ▼
  【政治】    【經濟】   【軍事】    【環境】    【社會】
 (體制僵化)  (財政破產) (外敵/強權)  (氣候/瘟疫) (分裂/信仰)
 (權臣/內訌) (通膨/斷路) (戰術代差)  (水文沙漠) (種族滅絕)
```

- **政治維度**：合法性喪失、繼承危機、權臣外戚篡位、制度僵化、內訌政變。
- **經濟維度**：財政赤字、惡性通膨、貿易路線轉移、單一資源枯竭、債務陷阱。
- **軍事維度**：強敵入侵、過度擴張、武器戰術代差、傭兵反噬。
- **環境維度**：極端氣候、水資源枯竭、傳染病、生態崩潰。
- **社會維度**：種族宗教對立、人口結構劇變、極端意識形態自殘、認同解體。
