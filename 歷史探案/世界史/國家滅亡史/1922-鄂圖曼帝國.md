# 1922 鄂圖曼帝國：選錯陣營與蘇丹制廢除

## 案發現場

1922 年 11 月，土耳其大國民議會（安卡拉，凱末爾）廢除蘇丹制，末代蘇丹穆罕默德六世乘英艦出逃。鄂圖曼帝國（1299–1922，623 年）滅亡。此前：一戰站同盟國（1914，恩維爾賭博）、加里波利慘勝（1915，唯一亮點）、阿拉伯起義（1916，勞倫斯）、摩蘇爾—巴勒斯坦全丟（1918）、色佛爾條約（1920，瓜分土耳其本土）。**623 年帝國，為何選錯一次陣營就歸零？**

> **站隊錯誤的代價是什麼？青年土耳其的賭博、阿拉伯的背叛、凱末爾的接管——鄂圖曼的死亡分幾步？**

## 偵查過程

**線索一：恩維爾的賭博（站隊的數學）。** 1914 年，青年土耳其三巨頭（恩維爾、塔拉特、傑馬勒）密約德國（戈本布雷斯勞號事件），對俄宣戰（高加索）。動機：收復巴爾幹失地（1912–13 巴爾幹戰爭慘敗）+泛突厥夢（中亞，恩維爾後戰死中亞，參見 [../中亞史/1916-中亞起義與巴斯瑪奇.md](../中亞史/1916-中亞起義與巴斯瑪奇.md)）+德國貸款。偵查結論：這是**弱國的豪賭**：押德國（強）贏了收復失地，輸了亡國——**孤注一擲，賭注是國運**（參見達里恩，[本書 1707 篇](1707-蘇格蘭王國.md)：同款）。賭輸的直接原因：薩勒卡默什慘敗（1914 冬，高加索凍死 8 萬，一說）+英國封鎖（達達尼爾）+阿拉伯起義。**站隊錯誤的代價=國運**：站對（英國？不，英國要瓜分鄂圖曼，站哪邊都輸——此即悲劇：**弱國無正確選項**，站同盟輸戰爭，站協約輸領土（亞美尼亞、阿拉伯照樣分））。鄂圖曼的真正死因不是站錯，是**弱到站哪都錯**。

**線索二：阿拉伯起義（帝國的內爆）。** 1916 年，漢志謝里夫侯賽因（英國勞倫斯許諾阿拉伯王國）起義，佔亞喀巴、大馬士革（1918），鄂圖曼丟漢志、敘利亞、美索不達米亞。偵查結論：這是**民族主義的內爆**（參見奧匈，[本書 1918 篇之奧匈](1918-奧匈帝國.md)）：阿拉伯人（帝國第二大族群）被許諾獨立（麥克馬洪—侯賽因通信）+不滿突厥化（青年土耳其的中央集權+突厥民族主義）——**帝國的普世性（伊斯蘭哈里發）敗給民族性（阿拉伯）**。諷刺：英國許諾（戰後食言，賽克斯—皮科瓜分中東）——**阿拉伯為別人的承諾打仗，得到的是委任統治**（英法託管）。起義的歷史評價兩面：阿拉伯民族主義的起點+中東碎片化的起點（賽克斯—皮科線，至今流血）。**帝國死於內爆，內爆死於承諾**——承諾（獨立）兌現為託管，託管兌現為百年戰爭。

**線索三：色佛爾條約（瓜分的圖紙）。** 1920 年，蘇丹政府簽色佛爾條約：土耳其本土被切（希臘得士麥那、亞美尼亞獨立、庫爾德自治、法意分區、海峽國際化）。偵查結論：這是**最狠的瓜分圖紙**（比分波蘭，[本書 1795 篇](1795-波蘭立陶宛.md)：波蘭全分，土耳其留核）——留安納托利亞核心，但連首都（君士坦丁堡國際化）都不要了。**條約的激勵反效果**：苛刻到無人能接受→人人拿槍（凱末爾安卡拉）——**壓迫性條約是最好的動員令**（參見凡爾賽→納粹，[本書 1933 篇](1933-魏瑪共和國.md)：同款）。蘇丹簽字（賣國）vs 凱末爾拒簽（救國）——**合法性轉移**：簽字者失國，不簽者得國。色佛爾從未執行（洛桑取代，1923）——**廢紙條約的歷史地位：激怒一個民族，捧紅一個國父**。

**線索四：凱末爾的接管（廢墟上的新國家）。** 凱末爾：加里波利成名（1915）→安卡拉組議會（1920）→薩卡里亞血戰（1921）→伊茲密爾收復（1922，希臘軍隊下海）→廢蘇丹（1922）、建共和（1923）、廢哈里發（1924）。偵查結論：這是**帝國廢墟上的民族國家**：不要帝國（多民族），要土耳其（單一民族）——**人口交換（希土 1923，150 萬人）、世俗化（廢哈里發、拉丁字母）、六箭主義**。與俄羅斯（蘇聯繼承帝國）對照：**土耳其選擇斷裂（不要帝國遺產），俄羅斯選擇繼承（蘇聯接沙俄盤）**——斷裂的好處（輕裝：無民族包袱）+代價（亞美尼亞問題、庫爾德問題至今）。凱末爾的冷酷（亞美尼亞大屠殺 1915，青年土耳其時期，責任歸屬爭議至今）——**新國家的地基裡有白骨**，土耳其至今不認（否認種族滅絕）。**國父的光環下有陰影**——所有民族國家的原罪。

## 結案報告

1. **弱即原罪**：站哪都錯——弱國無正確選項，賭注是國運。
2. **內爆定律**：普世敗給民族——為承諾打仗，得託管，百年流血。
3. **苛約即動員**：色佛爾捧紅國父——壓迫條約是最好的徵兵令。
4. **斷裂即新生**：不要帝國要民族——輕裝上陣，地基有白骨。

**豪賭公式（示意）：**

```
國運賭博 ＝ 贏（收復失地，小概率）× 輸（亡國，大概率）。
恩維爾：孤注一擲 → 薩勒卡默什 → 阿拉伯起義 → 色佛爾。
期望值為負的賭，賭的是帝國的錢——輸了心疼也晚了。
```

**結論：** 鄂圖曼案是「弱國豪賭」的標準樣本：站隊豪賭、內爆失血、苛約動員、斷裂重生——623 年帝國，八年走完（一戰四年+獨立戰爭四年）。**弱是原罪，賭是加速，苛約是動員，國父是收屍人**——凱末爾收的不是鄂圖曼的屍，是土耳其的新生兒。帝國的葬禮和民族的滿月酒，同一年擺——1922 年，安卡拉。
