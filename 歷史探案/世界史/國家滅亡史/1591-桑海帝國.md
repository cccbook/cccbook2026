# 1591 桑海帝國：通迪比的火器代差

## 案發現場

1591 年 3 月，通迪比戰役（廷巴克圖附近）：摩洛哥薩阿德王朝 4,000 遠征軍（火繩槍+大砲，西班牙傭兵教官）擊潰桑海帝國 4 萬大軍（長矛弓箭）。此後：加奧陷落、皇帝遜尼·阿里系逃亡、帝國分裂。西非最大帝國（跨撒哈拉貿易，廷巴克圖學術中心），亡於一場戰役。

> **4,000 如何打敗 40,000？火器對長矛——代差戰爭的數學是什麼？**

## 偵查過程

**線索一：通迪比的戰術（牛群衝炮陣）。** 桑海皇帝阿斯基亞·伊沙克驅牛群衝擊摩洛哥火槍陣（學漢尼拔？不，是絕望），牛受驚回衝自家陣；摩洛哥火繩槍齊射+大砲，桑海軍崩。偵查結論：這是**代差碾壓的標準畫面**：冷兵器（長矛，射程數米）vs 火器（火繩槍百米+大砲）——**射程差一個數量級，人數差一個數量級也沒用**。4,000 火槍兵的火力密度 > 40,000 長矛兵的衝擊力——**蘭徹斯特平方律的古代演示**：火力集中方勝，人海在射程面前只是靶子。牛群衝陣的寓言：**用舊時代的奇謀對抗新時代的武器，牛比人先明白——調頭就跑**。

**線索二：摩洛哥的遠征（撒哈拉的豪賭）。** 曼蘇爾蘇丹為蘇丹金（傳說）+擺脫鄂圖曼壓力，派朱達爾·帕夏率軍穿越撒哈拉（四個月，減員過半，4,000 到達）。偵查結論：這是**遠征的極限操作**：穿越沙漠死一半，剩下的一半靠火器以一當十——**豪賭的數學**：成功收益無限，失敗虧掉國庫。曼蘇爾賭贏了戰役，輸了戰略：4,000 人守不住偌大帝國（游擊不斷），金礦也沒找到多少（傳說誇大）。**贏了面子（滅一國），輸了裡子（國庫空+駐軍陷）**——摩洛哥此後衰落（曼蘇爾死後內亂）。**滅桑海的代價是把自己也拖下水**。

**線索三：桑海的內部分裂（王位爭奪）。** 遜尼·阿里死後（1492），阿斯基亞·穆罕默德篡位，此後王位爭奪不斷（1580 年代兄弟相殺，伊沙克靠政變上位）。通迪比時貴族離心（部分投敵）。偵查結論：**內亂是代差的幫兇**：沒有內亂，40,000 長矛結陣，火槍再強也要打幾仗（彈藥有限）；有了內亂，未戰先散（一觸即潰，皇帝逃跑）。**代差殺死軍隊，內亂殺死抵抗**——兩者疊加，一戰亡國。所有代差戰爭的通式：**新武器×舊內亂=速亡**（參見高加米拉，[本書 -0330 篇](-0330-波斯阿契美尼德.md)：同款）。

**線索四：廷巴克圖的學者（文明的陪葬）。** 通迪比後，摩洛哥流放廷巴克圖學者（艾哈邁德·巴巴等，星曆、法學著作被掠），經學院關閉。偵查結論：**征服者最怕讀書人**：學者=記憶+合法性（編年史《塔里赫·蘇丹》即此時前後所修）——流放學者=刪除記憶。但刪不掉：巴巴在摩洛哥繼續寫作，名氣更大——**流放是最好的出版**。桑海的政治死了，學術活著（手稿傳世，廷巴克圖手稿數十萬卷，至今是非洲驕傲）。**帝國的兩層皮**（參見西羅馬，[本書 0476 篇](0476-西羅馬帝國.md)）：政權可滅，文脈難斷——摩洛哥贏了戰爭，輸了文化戰（被征服者的書比征服者活得久）。

## 結案報告

1. **射程即正義**：差一個數量級，人數來湊也沒用——牛比人先懂。
2. **豪賭即雙輸**：贏面子輸裡子——滅他國的代價是拖垮自己。
3. **內亂即幫兇**：代差殺軍隊，內亂殺抵抗——新武器乘舊內亂等於速亡。
4. **學者即種子**：流放是最好的出版——政權可滅，文脈難斷。

**代差公式（示意）：**

```
戰損比 ＝ （射程差 × 火力密度）÷ 士氣。
通迪比：百米對數米 → 桑海崩 → 皇帝逃 → 帝國散。
人數在代差面前是分母——越多，靶子越大。
```

**結論：** 桑海案是「代差滅國」的非洲樣本：一場戰役、一個下午、四千對四萬——西非最大帝國歸零。**武器差一代，戰術差一世，帝國差一戰**。廷巴克圖的手稿還在，桑海的皇宮沒了——書比刀長壽，這是文脈對武器的最終復仇。
