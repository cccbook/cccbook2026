# 1943 孟加拉大饑荒：丘吉爾的餐桌與三百萬具屍體

## 案發現場

1943 年，英屬孟加拉大饑荒：死亡 200–300 萬（一說）。此前：緬甸失守（1942，稻米斷源）、日軍封鎖（孟加拉灣航運停）、1942 氣旋（作物毀）+稻田真菌（一說）、英政府糧食徵購（軍需+城市優先）、拒絕外援（美加澳運糧船被倫敦拒）、邱吉爾言論（一說有貶損印度人的粗口，「饑荒是他們自己造成的」一說）。**戰時的糧倉，為何餓死三百萬？**

> **饑荒是缺糧，還是缺人性？當運糧船被拒、倫敦在開宴會——三百萬人的死因，填哪一格？**

## 偵查過程

**線索一：供需的謊言（缺糧嗎）。** 1943 年孟加拉稻米產量：僅略低於年均（一說 5%，非絕收）——**供給夠吃，分配崩潰**。機制：緬甸斷米（佔進口大頭）+恐慌囤積（商人+中產）+徵購（軍需加城市：加爾各答優先）→農村米價飆（漲數倍）→窮人買不起（有糧在城，無錢在鄉）。偵查結論：這是**阿馬蒂亞·森的權利失效論**：饑荒不是沒糧，是**買不起糧**（交換權利崩：工資未漲糧價飛）——森（孟加拉人，諾獎得主）的理論直接來自此案。**饑荒的經濟學**：不是供給問題，是分配問題——**糧食在城裡，飢餓在鄉下**（與烏克蘭同構：出口+封鎖，[../國家滅亡史/1932-烏克蘭大饑荒.md](../國家滅亡史/1932-烏克蘭大饑荒.md)；與越南同構：[../東南亞史/1945-越南大飢荒.md](../東南亞史/1945-越南大飢荒.md)——**殖民饑荒三兄弟**）。

**線索二：倫敦的拒絕（政治的冷血）。** 孟加拉政府求援：美加澳有糧（澳船已在印洋），倫敦戰時內閣拒（航運緊張+「印度人自作自受」一說+要求緬甸先復）。邱吉爾（1943）：一說有貶損言論（粗口紀錄爭議）+「饑荒與德國轟炸的死亡相比不算什麼」（一說）——記錄爭議，但**拒援的事實**（官方檔案：多次拒絕運糧申請）無爭議。偵查結論：這是**帝國的優先級**：戰爭（歐洲優先）>殖民地（印度人可死）——**印度是帝國的加油站，不是帝國的家人**（參見越南：[../東南亞史/1945-越南大飢荒.md](../東南亞史/1945-越南大飢荒.md) 的法日雙重徵米——同款殖民邏輯）。邱吉爾的種族主義言論（一說檔案證實部分）+爭議（二戰英雄的陰暗面：加爾各答 vs 倫敦的命價差）——**英雄的塑像旁，是否該立死者的碑**（2010s 英國殖民史辯論，雕像去留運動同源）。

**線索三：加爾各答的盛宴（城市的隔離）。** 1943 年，加爾各答：酒店照常（英軍+富人宴會，一說照片流傳）、糧價飆但城市供應足（優先配給）——**鄉下人進城乞討，死在街頭（數千陳屍，一說）**。偵查結論：這是**城市的免疫**：配給制保護城市（軍需+秩序），犧牲農村——**饑荒的分區設計**：城市飽，鄉村死。與烏克蘭（城市配給，農村黑名單）同構：**饑荒的地理學：死亡在農村，糧食在城市**——城市是政權的眼睛（軍隊+官僚在），農村是政權的盲區（餓死無人看）。**配給制的倫理**：誰進名單（城市）誰出（農村）——名單就是生死簿。孟加拉的生死簿由倫敦+加爾各答的官僚寫——**農民不在名單上，也不在墳單上**（無名，一說統計缺失至今）。

**線索四：獨立的回力鏢（饑荒的政治利息）。** 1943 饑荒→1946 加爾各答騷亂（印度教穆斯林衝突，數千死）+1947 分治（孟加拉一分為二：西孟加拉印度+東巴基斯坦）→1971 孟加拉國（獨立，饑荒記憶+語言運動）。偵查結論：**饑荒是獨立的加速器**：殖民政府（救不了+不救）→合法性感人（英國連飯都不管）→「退出印度」運動（1942 前後）士氣增。**饑荒的利息**：300 萬人死，換來 1947 年帝國的提前離場（比預期早，一說）——**殖民者自己都驚訝：走得這麼快**（艾德禮：1947 提前，因印度已不可治，一說）。孟加拉的百年迴響：1971 孟加拉國成立（脫巴基斯坦——第二輪殖民）——**孟加拉人三次被別人管（英→巴→獨立），每次都伴隨饑荒**（1943、1974 獨立後饑荒）——**饑荒是南亞的長期病，殖民與主權都治不徹底**（主權後的饑荒：治理失敗）。

## 結案報告

1. **權利失效**：有糧買不起——饑荒是分配問題，森的諾獎由此案。
2. **優先級冷血**：戰爭大於人命——印度是加油站不是家人。
3. **城市免疫**：配給護城，農村等死——名單即生死簿。
4. **利息定律**：饑荒加速帝國離場——三百萬人，提前四年送走殖民者。

**饑荒公式（示意）：**

```
死亡 ＝ 供給略減（5%）× 分配崩潰（囤積+徵購）＋ 拒援（倫敦）。
供給只降 5%，死亡 300 萬——
其餘的，全是政治。
```

**結論：** 孟加拉案是「殖民饑荒」的總清算：供給微降、分配崩潰、倫敦拒援、加爾各答盛宴——三百萬人，死於政治而非天災。**饑荒的兇手從來不是旱災，是表格**：誰在配給名單上，誰不在——孟加拉農民不在，加爾各答酒店在。邱吉爾的餐桌與孟加拉的屍布，同一張 1943 年的英國報紙報導——**一版是勝利，一版是訃告，同一個帝國簽發**。饑荒的最大遺產：森的理論（饑荒=權利失效）——從此，我們知道：**看饑荒，別看雨量，看誰買得起米**。
