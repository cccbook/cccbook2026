# -0146 迦太基：三次布匿戰爭與徹底抹除

## 案發現場

公元前 146 年，羅馬軍（小西庇阿）攻陷迦太基——屠城、焚城十七天（一說）、犁平土地（一說撒鹽，後世附會）、五萬居民賣為奴隸。同年，科林斯亦被毀——羅馬同時終結兩個文明。迦太基（腓尼基殖民地，地中海貿易帝國，三百年）從地圖上被抹去，直到羅馬自己在此建新城（奧古斯都時代）。

> **為何要抹除？打敗不夠，為何要毀滅——羅馬對迦太基的仇恨賬本上記了什麼？**

## 偵查過程

**線索一：三次戰爭的升級（從爭霸到滅族）。** 第一次（前 264–241，西西里制海權，羅馬勝）；第二次（前 218–201，漢尼拔翻阿爾卑斯，坎尼殲八萬羅馬軍，羅馬慘勝）；第三次（前 149–146，老加圖「此外，我認為迦太基必須被毀滅」，羅馬藉口繳械後開戰）。偵查結論：**仇恨的複利**：坎尼之恥（羅馬史上最大敗仗）→世代復仇教育→加圖每場演說結尾必喊毀滅——**復仇從政策變成儀式**。第三次戰爭的藉口（迦太基自衛反努米底亞=違約）之牽強，證明**開戰不需要理由，需要的是三代人的恨**。滅亡史定理：**被羞辱過的強權，復仇時不講比例**——坎尼死八萬，迦太基死全城。

**線索二：漢尼拔的悲劇（戰術天才，戰略孤兒）。** 漢尼拔十五年轉戰義大利不敗（特拉西梅諾、坎尼），但：無攻城器械（打不下羅馬城）、迦太基本土不增援（政敵掣肘，商人算盤）、弟弟哈斯德魯巴援軍被截（梅陶羅）。偵查結論：這是**遠征無後方的絕境**：戰術全勝（殲敵數十萬），戰略全敗（羅馬越打越多——公民兵制+同盟體系，死了八萬再徵八萬）。**羅馬的體制（公民+同盟，參見相關）是漢尼拔打不垮的**：殺的是人，殺不死制度。扎馬之戰（前 202，西庇阿學漢尼拔的戰術反殺）——**學生用老師的戰術殺老師**。迦太基的死因一半是羅馬強，一半是**自己人不支援前線**（商人共和國的短視：前線打仗，後方算賬）。

**線索三：商業共和國的短視（算盤打不過元老院）。** 迦太基是寡頭商人共和國：雇傭兵打仗（花錢）、議會吵架（省錢）、前線缺糧（議價）。羅馬是公民兵共和國：公民打仗（拼命）、元老院堅韌（坎尼後不議和）。偵查結論：**體制決定戰爭耐力**：花錢買的忠誠（雇傭兵，第一次戰爭後即譁變——雇傭兵戰爭）vs 命換的忠誠（公民兵）——持久戰必然後者勝。迦太基議會給漢尼拔的增援，十五年不如羅馬一年徵的兵——**算盤精的打不過不要命的**（短期），但不要命的也需制度（長期）。第三次戰爭，迦太基交出武器求和，羅馬要城市搬遷（離海十英里）——**求和者連談判地位都沒有**，因為前兩次已證明：迦太基議和是為了再戰（漢尼拔備戰）。**信用破產者，投降也不被接受**。

**線索四：抹除的政治學（為何撒鹽）。** 屠城+焚城+犁平（撒鹽多為後世附會，但犁平是羅馬詛咒儀式（建城犁溝的反向操作——建城犁溝，毀城反犁）。偵查結論：抹除是**信號**：發給地中海所有城邦（反抗羅馬=迦太基下場）+發給羅馬公民（大患已除，安心）。**恐怖的廣告費**（參見帖木兒，[../中亞史/1370-帖木兒.md](../中亞史/1370-帖木兒.md)）：一次投入，百年震懾（科林斯同年被毀是連帶廣告）。但諷刺：羅馬五十年後在此建「羅馬迦太基」（非洲糧倉）——**地理位置太好，詛咒管不住**。抹除的城市復活了，抹除的文明（布匿語、巴力神）真的死了——**殺城易，殺文明需斷根（語言宗教）**。羅馬做到了：布匿文明只剩奧古斯丁筆下的隻言片語。

## 結案報告

1. **復仇即儀式**：坎尼之恥三代記——被羞辱的強權復仇不講比例。
2. **體制定耐力**：雇傭兵算盤 vs 公民兵拼命——持久戰後者勝，議和信用破產。
3. **學生殺老師**：扎馬反殺——學對手的戰術，再用它殺對手。
4. **抹除即廣告**：屠城發信號——殺城易，殺文明需斷根，羅馬全做了。

```

```

**結論：** 迦太基案是「徹底滅絕」的標準樣本：三代記賬、體制碾壓、議和無門、抹除示眾——地中海第一強權變成鹽地（傳說）和糧倉（現實）。**商業共和國的墓誌銘：算盤精於一時，短視誤了一世**；而復仇的複利是最準時的——坎尼的八萬亡魂，等了七十年，等來一座城的陪葬。
