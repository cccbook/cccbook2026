# -0218-漢尼拔與坎尼會戰：完美殲滅與拖延的賽局

## 案件摘要

西元前 218 年，二十九歲的迦太基統帥漢尼拔（Hannibal Barca）帶著戰象與部隊翻越阿爾卑斯山，突入意大利——軍事史上最大膽的遠征。前 216 年，他在坎尼（Cannae）以約五萬人殲滅羅馬八萬大軍，**單日陣亡人數超過近代任何歐洲戰役**，操作的是一個至今仍是軍校教材的「包圍殲滅」幾何學。然而——這場完美勝利沒有贏得戰爭。羅馬拒絕談判，以費邊（Fabius）的「拖延戰略」（cunctatio）拖了十餘年，最後在西庇阿（Scipio）手上於前 202 年扎馬（Zama）翻盤。這樁案件是兩場賽局的疊加：漢尼拔的**殲滅賽局**（賭對手會崩潰），對上羅馬的**消耗賽局**（賭自己不會崩潰）。**殲滅戰的天才，敵給了制度化的耐心**。

## 前因 -- 多因素的局勢

- **第一次布匿戰爭的遺恨**：迦太基失去西西里與賠款（參見 [-0264-第一次布匿戰爭.md](-0264-第一次布匿戰爭.md)），巴卡家族轉經營西班牙，積蓄復仇資源。
- **漢尼拔的童年誓言**：九歲隨父哈米爾卡在神廟前宣誓「永與羅馬為敵」——個人的復仇劇本與家族戰略重合。
- **薩貢托（Saguntum）藉口**：前 219 年漢尼拔攻陷羅馬保護的西班牙城市，羅馬最後通牒未遂——開戰的法理引爆點。
- **戰略不對稱**：羅馬的優勢是人力與同盟；迦太基的優勢是漢尼拔的天才與職業軍。漢尼拔的解法：**直接攻入敵方人力庫，打散同盟**。
- **羅馬戰略的慣性**：羅馬人信奉「正面決戰」——執政官親率大軍求戰，正是漢尼拔要的。

## 線索與推理 -- 因素咬合

### 線索一：三次大捷——把「決戰」變成陷阱

前 218–216，漢尼拔三連勝：特雷比亞（Trebia）、特拉西梅諾湖（Trasimene）、坎尼。他的戰法是**誘敵**：以行軍路線、補給挑釁與陣形弱點，引誘羅馬指揮官（每個執政官都急於在自己的任期內建功）接受決戰。坎尼的陣形是教科書：

- 漢尼拔以**凸月形陣**應敵：中央是較弱的高盧與西班牙步兵，刻意前凸。
- 羅馬八萬人採密集縱深，向月心猛壓——**月形被壓成凹形，兩翼的非洲重步兵包抄合攏**。
- 努米底亞騎兵驅散羅馬騎兵後，從後方封閉口袋。

$$\text{殲滅條件} = \text{正面牽制} + \text{兩翼合圍} + \text{後方封鎖}$$

羅馬軍在口袋中被壓縮至無法揮劍，約五萬至七萬人死於單日。元老等級的執政官保盧斯（Paullus）陣亡，八十名元老隨軍戰死。

### 線索二：坎尼之後——殲滅戰略的失效

漢尼拔的賭注：**羅馬同盟會在連續慘敗後解體**。部分如願——卡普亞（Capua）、他林敦、部分南意城市倒戈；馬其頓的腓力五世、敘拉古也入局。但核心同盟**沒有崩潰**。原因：

1. **同盟的利益結構**：羅馬的公民權階梯（參見 [-0753-羅馬建城傳說.md](-0753-羅馬建城傳說.md)）使多數同盟寧可賭羅馬重來，也不賭漢尼拔的「解放」承諾——何況漢尼拔無法兌現任何長期承諾（他沒有後勤基地、沒有攻城器械、沒有援軍航道）。
2. **羅馬的制度化恢復力**：元老院拒絕贖回戰俘（宣示「絕不示弱」）、武裝奴隸與少年（volones）、甚至重新徵召——人力存量被證明大於任何單日損失。
3. **殲滅戰略的數學困境**：漢尼拔的軍隊（約 2.5–3 萬，且無補充）每贏一場都在耗損，而羅馬的動員半徑仍在擴大——這正是皮洛士困境的放大版（參見 [-0280-皮洛士戰爭.md](-0280-皮洛士戰爭.md)）。

### 線索三：費邊戰略 = 高貼現對手的「時間之盾」

費邊・馬克西穆斯（Fabius Maximus，「拖延者」Cunctator）在特拉西梅諾慘敗後獨裁，定下戰略鐵律：**不決戰、騷擾糧道、焦土、讓漢尼拔自耗**。這是博弈論的教科書：

| | 漢尼拔的期望 | 費邊的回應 |
|---|--------------|------------|
| 求決戰 | 以殲滅壓垮羅馬 | 避不接戰——決戰賽局不成立 |
| 誘降 | 同盟倒戈 | 懲罰倒戈者（殺雞儆猴），動搖其他觀望者 |
| 就地取糧 | 以戰養戰 | 焦土＋緊釘尾隨，使掠奪成本大於收益 |
| 等待羅馬崩潰 | 時間是我的敵人 | **時間是我的朋友**——貼現率對調 |

費邊的核心洞察：**漢尼拔的軍隊是一筆「折舊中的資產」**——沒有補充線，每過一個冬天、每損一名老兵，他的戰鬥力都不可逆地遞減。羅馬只需讓時間站在自己那邊：

$$V_{\text{羅馬}}(t) \uparrow, \quad V_{\text{漢尼拔}}(t) \downarrow \quad \Rightarrow \quad \text{避免交戰即是最優策略}$$

費邊的代價是政治的：拖延在羅馬國內極不受歡迎（「賣國者」「懦夫」），農田被燒、損失直接壓在農民身上——**拖延戰略需要政治成本由全國分攤，而集中在他人的田地上**。羅馬的制度（元老院的權威、獨裁官的任期）承受了這種政治壓力而不崩潰——**個人統治者做不到的耐心，制度做到了**。

### 線索四：扎馬——同一套數學的反向執行

前 203 年，漢尼拔回防北非；前 202 年扎馬會戰，西庇阿以其人之道還治其人之身：

- 西庇阿在西班牙已打碎迦太基的補充基地（前 206 伊利帕）——**先斬補充線，再談決戰**。
- 陣形上，他讓羅馬縱隊**錯開通道**，讓漢尼拔的戰象衝進「空巷」而不攪亂陣列——坎尼的幾何被反轉使用。
- 騎兵：努米底亞王馬西尼薩（Masinissa）倒戈羅馬——**漢尼拔賴以封口的騎兵優勢易手**。

漢尼拔第一次敗於會戰，迦太基求和：賠款、裁軍、交出艦隊與戰象——迦太基從霸主降為被看管的城邦。

## 破案時刻

- 前 218–217：阿爾卑斯遠征 → 特雷比亞、特拉西梅諾兩勝。
- 前 216：坎尼——完美殲滅，但未贏得戰爭。
- 前 217–203：費邊戰略＋「義大利戰場上的無人區」——漢尼拔在意大利縱橫十五年是勝利者，也是囚徒。
- 前 207：梅陶羅河，漢尼拔之弟哈斯德魯巴的援軍被殲——補充線夢碎。
- 前 202：扎馬——時間的貼現終於兌現。

## 後果 -- 改變了什麼

- **「坎尼」成為殲滅戰的同義詞**：從軍事教材到商業用語（「給對手一場坎尼」）。
- **費邊主義進入戰略詞典**：不對稱劣勢方的「拖延換時間」範式，影響後世一切以弱抗強的戰略（包括游擊戰理論）。
- **羅馬的自信與擴張**：戰勝漢尼拔使羅馬確立對西地中海的霸權，轉而進攻迦太基本土與希臘東方。
- **漢尼拔的個人結局**：流亡、被羅馬追索至死（前 183 年自盡）——天才的最後一課：**打不贏制度的天才，連逃亡也沒有終點**。

## 因素影響筆記

1. **殲滅賽局 vs 消耗賽局**：戰場上的完美勝利，可能在戰略圖上是零分——勝負要看「哪個賽局在主導」。
2. **無補充線的資產 → 時間折舊 → 拖延者的勝利**：費邊戰略的本質是「讓敵人的資產負債表自然惡化」。
3. **制度化的耐心 > 個人的天才**：羅馬能承受戰略的「政治不滿」，個人統治者不能——制度是耐心的載體。
4. **騎兵易手（馬西尼薩倒戈）→ 扎馬翻盤**：聯盟的政治戰，往往比會戰的幾何學更早決定結局。
