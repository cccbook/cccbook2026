# -0509-羅馬共和國建立：把王關進制度籠子

## 案件摘要

西元前 509 年，羅馬人驅逐了最後一位國王——「傲慢者」塔克文（Tarquinius Superbus），此後五百年不再設王。這樁案件的兇手不是一支軍隊，而是一套制度設計：**執政官（consul）的雙頭制與一年任期**。羅馬人面對的核心問題是：沒有國王，誰來打仗？誰來主持祭儀？誰來執行死刑？答案不是「一個更溫和的王」，而是「把王的權力拆成可拆式零件，分給兩個任期一年的行政官」——人類史上最早的「決策冗餘系統」之一。共和國不是民主的勝利，而是**對獨裁風險的工程學解**。

## 前因 -- 多因素的局勢

- **王政末期的暴政敘事**：塔克文七世（Superbus，即「傲慢者」）未經元老院同意處死元老、強徵勞役、以兒子們的名義壟斷司法。
- **路克蕾提亞事件**（前 510）：塔克文之子強暴貴族之妻路克蕾提亞，她當眾控訴後自殺——「貞節與榮譽」的道德炸彈，引爆貴族布魯圖斯（L. Junius Brutus）領導的政變。
- **族群背景**：末代諸王是伊特魯里亞裔，羅馬貴族对「外族王朝」的不滿與當時伊特魯里亞霸權衰落重疊——「反王」也是「反伊特魯里亞」。
- **制度累積**：王政晚期已有元老院（senatus，約百名貴族「父老」）、庫里亞大會與祭司團——「無王運轉」的零件其實已備齊。
- **外部威脅**：塔克文聯合伊特魯里亞城市（如克魯西烏姆的波塞納 Lars Porsenna）試圖復辟——新共和國第一天就面臨戰爭。

## 線索與推理 -- 因素咬合

### 線索一：雙執政官 = 決策冗餘與互惠監督

共和國的解法：以兩位執政官取代一位國王。每位執政官擁有完整的軍事指揮權（imperium）與十二名扈從（lictors，斧束笞杖），但——**互相擁有否決權（intercessio）**。任何一方說「veto」（拉丁文「我禁止」），命令即失效。

用可靠性工程（reliability engineering）的角度看：

$$P_{\text{暴政}} = P(\text{一人腐化}) \quad \text{vs.} \quad P'_{\text{暴政}} = P(\text{兩人同時腐化}) \times P(\text{互相勾結})$$

- 串聯系統（兩人都必須同意）：命令要生效需兩人一致——**降低輕率決策**。
- 並聯監督（互有否決）：任何一人可制止另一人——**降低單點腐化**。

代價是效率：戰場上兩個司令官會打架。羅馬的工程解法是**分日輪替指揮**（輪流持斧束）與必要時指定獨裁官（dictator，任期六個月的緊急一職）——「平時冗餘、戰時集中」的可切換架構。

### 線索二：一年任期 = 防止「權力的複利」

執政官任期僅一年，且（經驗法則上）卸任後須隔十年才能再任。這是對「權力複利」的數學防禦：

$$\text{權勢}_{t} = \text{權勢}_{0} \times (1 + r)^{t}$$

若任期 $t \to \infty$，即使每年的權勢累積率 $r$ 極小，權勢也會指數成長，最終無人能制。羅馬的解法：**強制 $t \le 1$，使 $r$ 沒有時間複利**。同時卸任執政官進入元老院終身任職——「權力的年輪」：權力像樹木一樣一圈圈累積在元老院這個「緩衝器」裡，而不是累積在個人身上。

| 制度 | 目標 | 手段 |
|------|------|------|
| 雙頭制 | 防單點腐化 | 互否決 |
| 一年任期 | 防權力複利 | 時間切斷 |
| 卸任入元老 | 經驗留存 | 制度記憶 |
| 獨裁官備援 | 戰時效率 | 六個月自動失效 |

### 線索三：不流血政變的「規範暴力」

驅逐塔克文的過程出奇地和平——國王正在外征戰，羅馬關閉城門即可。但布魯圖斯做了一件更重要的事：**強迫全體人民宣誓「永不許再有王」**（與前 753 建城神話的「聖界不可越」互為表裡，參見 [-0753-羅馬建城傳說.md](-0753-羅馬建城傳說.md)）。布魯圖斯甚至處死了密謀復辟的親生兒子——把「反王」變成不可逆的承諾（commitment device）：

$$\text{制度的可信度} = \text{公開宣誓} + \text{示範性執行（連兒子也不赦）}$$

**承諾問題的古典解**：只有當「復辟」的成本高到連發起者自己都無法承受時，承諾才可信。布魯圖斯以親子之血為制度做了「首期保證金」。

### 線索四：制度的壓力測試

前 509–前 494 年間，新共和國通過了一連串測試：

- **前 509–508**：擊退塔克文與波塞納的復辟軍（傳說中Horatius Cocles守橋、Mucius Scaevola燒手，都是「犧牲者神話」的宣傳戰）。
- **前 503**：塔克文死於流亡——復辟威脅自然解除。
- **前 496**：雷吉盧斯湖之戰擊敗拉丁同盟。
- 但**平民問題**浮出：連年征戰的債務壓在平民身上——引發前 494 第一次聖山撤退（參見 [-0494-平民撤退與護民官.md](-0494-平民撤退與護民官.md)）。

## 破案時刻

- 前 510/509：路克蕾提亞之死 → 政變 → 國王流亡。
- 共和國第一年：布魯圖斯與瓦列里烏斯（Valerius Publicola）任首屆執政官；瓦列里烏斯立法——斧束在城內不豎斧（象徵人民之上無絕對生殺權）、死刑可上訴公民大會（provocatio）。
- 制度定型：雙頭＋一年＋元老院＋民會——「混政體」（波利比烏斯後來總結為執政官／元老院／民會的混合憲法）。

## 後果 -- 改變了什麼

- **五百年無王**：直到前 27 年屋大維以「元首」（princeps）之名恢復實質王政——但名義上仍避「王」字，可見此禁忌的強度。
- **混合憲法思想**：波利比烏斯前二世紀的《歷史》將羅馬共和國總結為君主制（執政官）＋貴族制（元老院）＋民主制（民會）的混合——直接影響孟德斯鳩與美國憲法（總統、參眾兩院、否決權）。
- **「intercessio → veto」的詞彙遺產**：今日各國議會的否決權制度，詞源直接來自羅馬執政官互否。
- **隱患**：防獨裁的設計在超級大國規模下逐漸失靈——馬略、蘇拉、凱撒將一一測試其極限（參見 [-0107-馬略軍制改革.md](-0107-馬略軍制改革.md)、[-0082-蘇拉獨裁.md](-0082-蘇拉獨裁.md)）。

## 因素影響筆記

1. **暴政事件（路克蕾提亞）→ 道德動員 → 政變**：制度的誕生需要「道德炸彈」作為引信。
2. **對王的恐懼 → 決策冗餘設計（雙頭＋一年）→ 防獨裁**：風險分散是制度的第一原理。
3. **公開宣誓＋示範處決 → 承諾可信化 → 「永不為王」規範**：制度需要不可逆的初始承諾。
4. **效率代價 → 獨裁官備援制度**：冗餘與效率的平衡，靠「可切換」的緊急條款維持。
