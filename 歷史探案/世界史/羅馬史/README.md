> 從台伯河畔的城邦到橫跨三洲的帝國，再到千年東羅馬的餘暉——羅馬是人類史上最完整的「政體實驗室」：王政、共和、霸權、內戰、元首、主宰、分裂、基督教化、崩潰與延續，全部走過一遍。本卷以推理探案拆解每個轉折點背後的制度、經濟與軍事邏輯。
