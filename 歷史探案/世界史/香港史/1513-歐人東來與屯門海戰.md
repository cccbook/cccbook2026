# 1513-歐人東來與屯門海戰：歐亞相遇的第一現場

## 案件摘要

1513 年（明正德八年），葡萄牙航海家**歐維士**（Jorge Álvares）抵達**屯門**——第一批登上中國土地的歐洲人。葡人隨後在屯門設營築寨、私市貿易；1521 年（嘉靖元年）明廣東海道副使**汪鋐**率軍驅逐，是為**屯門海戰**——歐洲武裝商船與明帝國海防體系的第一次正式交火。此案之後，葡人輾轉最終於 1557 年**租居澳門**。這樁案件的意義遠超一場小海戰：**香港海域是歐亞體系相遇的第一現場**——四百年後黑船叩關的劇本，在這裡已經預演過一次（[1853-黑船來航.md](../日本史/1853-黑船來航.md)）。

## 前因 -- 多因素的局勢

- **歐洲**：大航海時代——1498 達伽馬繞好望角抵印度，葡人沿印度洋—馬六甲東進（1511 佔馬六甲）。
- **明帝國**：朝貢體系運作中——海外貿易須掛朝貢之名、行於貢舶規制之內，私商是走私。
- **技術**：葡人佛郎機銃＋帆船火砲 vs 明軍衛所水師——代差初現但尚未壓倒。
- **地理**：屯門是珠江口泊點（唐以來的外港傳統，[0214-秦置南海郡與百越海洋先民.md](0214-秦置南海郡與百越海洋先民.md)）——外船入廣州前的天然等候區。

## 線索與推理 -- 因素咬合

### 線索一：為什麼停屯門——「外船的泊點函數」

外洋船無法直入省城，必在珠江口外候風候檢：

$$\text{外船泊點} = \arg\max\big(\text{泊地水深} + \text{補給} - \text{官府控制強度}\big)$$

屯門水道深、離廣州近、又在外洋防線邊緣——**唐代的泊點邏輯在葡人手中變成私市據點**。同一地理，帝國用來候關，商人用來繞關——泊點與走私港只有一線之隔。

### 線索二：兩種貿易邏輯的相撞——「朝貢 vs 契約」

| | 明帝國朝貢體系 | 葡萄牙武裝商船 |
|---|---|---|
| 貿易前提 | 冊封＋表文 | 契約＋武力護航 |
| 貿易地點 | 貢期、貢道、貢舶 | 何處有利即何處 |
| 主權觀念 | 天下—藩屬 | 平等條約 |

**相撞的根源不是火砲，是兩套不相容的「貿易合法性」定義**。葡人按歐洲邏輯要通商條約，明廷按朝貢邏輯視之為海寇——溝通的失敗先於武器的失敗。

### 線索三：屯門海戰——「帝國的學習速度」

1521 年汪鋐圍攻屯門葡寨：初攻不利（佛郎機銃射程火力佔優），汪鋐改用水攻——**募潛水鑿船、火攻縱燒、斷水斷糧**，葡船潰逃：

$$\text{戰果} = \text{（戰術學習）} - \text{（技術代差）} > 0 \quad \text{（在近岸條件下）}$$

**明軍此役贏了，而且贏在學習**——汪鋐繳獲佛郎機銃後上呈仿製（「佛郎機」從此成為明軍制式火器）。但**學習是戰術的，體制是停滯的**：仿製了火砲，沒有仿製東印度公司。四百年後的代差，正是這一次「只學工具、不學制度」的利息。

## 破案時刻

- 1513.5：歐維士抵屯門豎立石刻——第一批登陸中國的歐洲人。
- 1517：安德拉德艦隊入廣州、葡使皮雷斯求貢——通交嘗試。
- 1519–20：葡人屯門設營、私市武裝貿易；火者亞三冒名事件敗露。
- 1521.6–9：屯門海戰——汪鋐驅逐葡人（明軍獲勝）。
- 1522：茜草灣（新會西草灣）之戰——明軍再勝、繳佛郎機銃。
- 1557：葡人租居澳門——廣東當局的「以商制寇」安排，屯門之役的間接結果。

## 後果 -- 改變了什麼

- **政治**：明廷確認「驅逐＋有限容納」模式——拒絕條約式通商，改以澳門一港安置西人。
- **軍事**：佛郎機銃仿製——明軍火器升級；但海防體制未動，「海禁」邏輯延續。
- **經濟**：廣州—澳門雙港體系成形——歐亞貿易改道珠江口，屯門—伶仃洋海域成為常年航線。
- **國際**：葡—明相遇的先例——武裝叩關不行、據點租居可行；此劇本被後來的歐洲人反覆研讀（[1757-一口通商與廣州十三行.md](1757-一口通商與廣州十三行.md)）。

## 因素影響筆記

```
大航海（推力）──→ 1511 馬六甲 ──→ 1513 歐維士抵屯門
朝貢體系（拉力＋排他）──→ 合法性不相容 ──→ 衝突
                              ↓
        1521 屯門海戰（明勝）──→ 仿製佛郎機（學工具）
                              ↓
        1557 澳門租居（學妥協）──→ 珠江口成歐亞貿易常設舞台
```

**偵探結語**：本案證明：**第一次相遇決定了之後四百次的相遇模式**——屯門海戰讓明帝國相信自己守得住，讓歐洲人學會了要先找一個「落腳點」而不是主港。香港海域做了歐亞相遇的第一現場，卻把主角讓給了對岸的澳門；而它自己，只是繼續等在航線上——等下一艘改變一切的船。
