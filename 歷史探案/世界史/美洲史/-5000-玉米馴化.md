# -5000 玉米馴化：從野草到文明的糧倉

## 案發現場

約九千年前，墨西哥南部巴爾萨斯河谷（Balsas Valley）的採集者開始馴化一種名為**大芻草**（teosinte，墨西哥類蜀黍）的野生禾草——它沒有飽滿的穗軸，只有一排脆弱的小穗，每穗不到數十粒硬殼籽粒。經過數千年選育，它蛻變為**玉米**（Zea mays）：一根穗軸數百粒裸露籽粒，養活了中美洲此後所有的文明——奧爾梅克、瑪雅、阿茲特克的糧倉基礎。

> **一種不起眼的野草，如何被選育成新大陸最重要的作物？為什麼「玉米→人口→文明」的鏈條，比任何王朝更早決定了中美洲的命運？而玉米若不經鹼化處理就當主糧，為什麼反而會致病？**

## 偵查過程

**線索一：馴化的地點與時間（案發現場定位）。** 玉米的野生祖先是巴爾萨斯河谷的一年生大芻草（parviglumis）——基因組比對（2002 年起的多項研究）證實所有玉米品系都源自這一個族群，馴化起始約九千年前，最早的考古穗軸（Guilá Naquitz 洞穴，約 6250 年前）顯示早期玉米穗僅數公分長。**基因（單一起源）+ 考古（小型穗軸）互為印證**——馴化不是多點獨立發明，而是單一河谷的長期工程。

**線索二：性狀的巨變（選擇壓的遺傳學）。** teosinte 與玉米的差異由少數關鍵基因控制：**tb1**（teosinte branched 1）讓植株從多分枝的野草變成單稈大穗；**tga1** 基因的突變讓籽粒的硬殼（fruitcase）退化——籽粒裸露、可被人類取食。穗軸逐漸變大變粗，但籽粒緊包於穗軸上無法自行散播——**玉米離開人類就無法繁殖**，這是徹底的馴化依存。選擇壓來自人類的種子偏好：每一代留下最大、最多粒的穗作種，數千年的定向選擇累積出戲劇性的形態變化。**人類偏好（selection pressure）→ 等位基因頻率改變 → 表型劇變**——達爾文演化論最快速的實地示範之一。

**線索三：玉米→人口→文明的鏈條。** 玉米高產（單位面積熱量遠超採集）→ 聚落可以定居擴大 → 人口增長催生政治組織與祭祀中心——奧爾梅克（約 -1200）到瑪雅與阿茲特克的國家體系，都建立在玉米農業的剩餘上。中美洲語言中的「人」與「玉米」常同源（瑪雅經典文獻《波波爾·烏》稱人類以玉米造成）——玉米不只是作物，是**文明的身分證**。參見 [../美洲史/-1200-奧爾梅克文明.md](../美洲史/-1200-奧爾梅克文明.md)：母文明的祭祀政治即以玉米剩餘為燃料。

**線索四：鹼化處理的化學（nixtamalization）。** 玉米蛋白缺乏離胺酸與色胺酸，菸鹼酸（維生素 B3）被**束縛態**（niacytin）鎖住——若以未處理玉米為主糧，會引發**糙皮病**（pellagra：皮炎、腹瀉、癡呆）。中美洲的解法：以石灰水（氫氧化鈣）或草木灰（碳酸鉀）煮玉米、浸泡過夜（**nixtamalization**）——鹼性環境切斷菸鹼酸的束縛鍵、釋放菸鹼酸，並補充鈣質、提升離胺酸利用率、還讓玉米粉可揉成糰（masa）。這是一項**前於化學知識的化學工程**：歐洲人把玉米帶走卻沒帶走鹼化技術，十六世紀後歐美的糙皮病（如美國南方，二十世紀初仍流行）正是缺席的技術寫下的病歷。

**線索五：玉米的傳播（從河谷到兩大陸）。** 馴化後的玉米並未停留在巴爾萨斯河谷：約七千年前傳入中美洲高地與南部低地，約四千年前抵達南美洲安第斯地區（與馬鈴薯、藜麥並列為安第斯糧倉），約兩千年前經由墨西哥北部傳入北美西南部（普韋布洛人的主糧）。傳播的每一站都伴隨**品種分化**——高地耐寒種、低地高產品種——玉米的遺傳多樣性在傳播中重新膨脹。偵查結論：**馴化是一次發明，傳播是無數次在地馴化**——玉米→人口→文明的鏈條，在每一個抵達地重演一次。

## 結案報告

1. **單一起源的長期工程**：玉米源自巴爾萨斯河谷的單一大芻草族群，九千年的定向選擇由少數關鍵基因（tb1、tga1）承載——馴化是演化論在田野中的極速版。
2. **文明的糧倉前提**：玉米→定居聚落→人口剩餘→祭祀中心與國家——中美洲文明史的物質地基。
3. **缺席技術的病歷**：nixtamalization 是玉米成為健康主糧的必要配套；技術（而非作物本身）決定了營養結局。
4. **偵探教訓**：追蹤一種作物，要同時追**基因、技術與人**——作物本身不寫歷史，「作物 + 配套技術」才寫歷史；把玉米與石灰水分開偵辦，就會把糙皮病誤判為玉米的罪。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 變化 | 機制 |
|------|------|------|
| 遺傳學 | teosinte → 玉米（tb1、tga1） | 定向選擇、瓶頸效應 |
| 考古學 | 巴爾萨斯河谷單一起源 | 基因組比對 + 穗軸化石 |
| 人口 | 定居聚落、人口增長 | 高產熱量作物 |
| 政治 | 祭祀中心、國家興起 | 農業剩餘 |
| 化學 | nixtamalization 鹼化處理 | 釋放菸鹼酸、補鈣 |

**teosinte → 玉米對照表：**

| 性狀 | teosinte | 玉米 | 負責基因 |
|------|---------|------|---------|
| 分枝 | 多分枝、穗小 | 單稈、大穗 | tb1 |
| 籽粒外殼 | 硬殼包裹 | 裸露籽粒 | tga1 |
| 穗軸 | 脆、數十粒 | 粗、數百粒 | 多基因累積 |
| 繁殖 | 自行散播 | 依賴人類剝取 | 馴化依存 |

**選擇壓遺傳學：** 每代留種即為一次定向選擇。等位基因頻率的變化 Δp ≈ s·p(1−p)（s 為選擇係數）——人類的偏好（最大穗作種）讓 s 長期為正且方向固定，數千代累積即成劇變。分子標記顯示馴化過程經歷了明顯的**瓶頸效應**（founder effect）：玉米的遺傳多樣性低於 teosinte——瓶頸的指紋證實了單一起源。

**中美洲飲食三角與鹼化化學：**

```
玉米（熱量）+ 豆類（離胺酸、蛋白質）+ 辣椒（維生素 A/C）
   ↓ 補足玉米的營養缺口
完整氨基酸譜的飲食
   ↓ 但玉米的菸鹼酸仍被束縛
nixtamalization：Ca(OH)₂ 或 K₂CO₃ 鹼煮浸泡
   ↓ 水解 niacytin、釋放菸鹼酸、補鈣
玉米可成為健康主糧 → 文明的糧倉
```

**結論：** 玉米馴化是「野草→基因→作物→人口→文明」的完整鏈條：九千年的人工選擇把一種野草改寫成依賴人類的糧倉，中美洲的祭祀與帝國建立其上；而 nixtamalization 證明——**作物與配套技術是一對共犯結構**，少了石灰水，玉米的歷史就是一部營養病史。
