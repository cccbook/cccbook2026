# 1947 國家安全法：冷戰的國家機器組裝圖

## 案發現場

1947 年 7 月《國家安全法》（National Security Act）簽署生效：設立國防部（統合陸海空三軍的國家軍事機構）、國家安全會議（NSC）、中央情報局（CIA），並把參謀首長聯席會議（JCS）法制化。此前美國在珍珠港前情報分散、三軍各自為政——二次大戰剛結束、蘇聯對峙成形之際，美國用一部法律重寫了國家的「安全作業系統」。

> **一個建國傳統上「警惕常備軍」的共和國，為什麼在和平來臨時反而擴建龐大的安全機器？1947 年的改裝，如何讓美國從「戰時才動員的共和國」變成「常年備戰的帝國共和國」？**

## 偵查過程

**線索一：珍珠港的記憶與組織學習。** 1941 年的災難（參見 [../世界發展史/1941-珍珠港與航艦時代.md](../世界發展史/1941-珍珠港與航艦時代.md)）被歸因於情報分散與軍種本位：海軍與陸軍情報互不通氣、破譯與判讀各自為政。戰後調查報告的處方是**組織整合**：建立統一情報協調機構與統一國防指揮——1947 年法案是組織學習的制度化結案。

**線索二：戰略環境的永久化。** 凱南的「長電報」（1946）與杜魯門主義（1947）把蘇聯定性為長期擴張威脅，遏制（containment）成為跨政黨的戰略共識。司法心理學式的偵查要問：**威脅的時間尺度變了**——從「打完就解散」的戰爭，變成「數十年的對峙」，動員邏輯因此必須常態化。

**線索三：軍種政治的妥協工程。** 法案是海軍與陸軍激烈角力的妥協：國防部長初版權力有限（三軍仍保高度自主，直到 1949 年修正案才強化統合）；CIA 被刻意設計為**僅海外行動、不涉國內執法**，以安撫「秘密警察」的憲政恐懼。這提醒偵探：制度設計從來不只是效率問題，**是政治勢力的資產負債重組**。

**線索四：預算與技術的複利。** 1950 年 NSC-68 號文件把國防開支推向 GDP 的兩位數；噴射機、核武、雷達、後來的電腦與航太（見 [1962-古巴飛彈危機.md](1962-古巴飛彈危機.md)、[1957-仙童半導體與矽谷起源.md](1957-仙童半導體與矽谷起源.md)）都在這套採購體系內孵化。艾森豪 1961 年的告別演說點名「軍工複合體」（military-industrial complex）——組裝完成的機器開始有自己的意志。

## 結案報告

1. **機構跟著威脅的時間尺度走**：熱戰式動員 → 冷戰式常備，1947 年是「轉檔」的那一下。
2. **組織整合是珍珠港的遺囑**：情報共享與聯合指揮，是用人命買來的組織設計教訓。
3. **妥協留下縫隙**：軍種本位與國內外權限切分，成為日後九一一情報失靈與海外秘密行動爭議的遠因。
4. **偵探教訓**：看一部組織法要問三題——它要防止上次的什麼失敗？它向誰的既得利益讓步？它的預算曲線此後長什麼樣？

## 證據與工具

**1947 年組裝清單：**

| 新機構 | 職能 | 防止的舊失敗 |
|--------|------|--------------|
| 國家軍事機構（1949 改稱國防部） | 統合三軍預算與作戰 | 軍種本位、重複建設 |
| 中央情報局 | 海外情報協調與分析 | 珍珠港式的「信號淹沒」 |
| 國家安全會議 | 總統戰略決策平台 | 戰略各自解讀、政出多門 |
| 參謀首長聯席會議 | 軍事建言整合 | 各軍種單獨向總統喊價 |

**預算與結構的正回饋：**

```
威脅永久化 → 常備動員 → 國防預算↑ → 採購餵養科技業
   → 技術優勢 → 新威脅論 → 預算再↑（軍工複合體迴路）
```

**結論：** 1947 年法案是美國版的「憲法第二卷」：第一卷寫分權制衡，第二卷寫常年備戰。它讓美國贏了冷戰，也讓美國從此離不開這台機器——**安全機器一旦組裝，最難拆下的零件，是組裝它的人自己也變成的零件**。
