## 閱讀路徑

- **生態與人口線**：克洛維斯 → 玉米馴化 → 哥倫布抵達 → 淘金潮
- **征服與帝國線**：奧爾梅克 → 特奧蒂瓦坎 → 瑪雅 → 印加 → 科爾特斯/皮薩羅 → 波托西 → 米塔勞役制
- **政治制度線**：五月花號 → 獨立宣言 → 制憲 → 門羅主義 → 重建終結 → 民權法案
- **經濟整合線**：詹姆斯鎮 → 契約勞工 → 路易斯安那 → 鐵路 → 大蕭條 → NAFTA
- **原住民命運線**：普韋布洛起義 → 印第安遷移法 → 小巨角/傷膝河
- **奴隸制長線（新增）**：契約勞工（1619） → 糖業革命（1640） → 美國獨立（1776） → 海地革命（1791） → 重建終結（1877） → 民權法案（1964）
- **科技因素線**：橫貫鐵路 → 福特T型車 → TVA → 仙童半導體（製造—能源—資訊三級跳）
- **制度因素線（新增）**：阿茲特克貢賦（1430） → 米塔勞役（1573） → 宅地法（1862） → 美聯儲（1913） → 布雷頓森林（1944） → 401k（1978）
- **地峽主權線（新增）**：巴拿馬獨立與運河條約（1903） → 巴拿馬運河（1914） → 美西戰爭（1898）
- **危機與轉型線（新增）**：美聯儲（1913） → 大蕭條（1929） → 國家安全法（1947） → 移民法（1965）——金融恐慌→國家機器→人口結構，三個超長期轉折
