# -0168-彼得納會戰與羅馬軍團：長矛牆的敗訴

## 案件摘要

西元前 168 年，希臘本土的彼得納（Pydna）平原，馬其頓末代國王珀爾修斯以五臂長的 sarissa 長矛方陣（約四萬人）對陣羅馬執政官埃米利烏斯·保盧斯的兩個軍團（約三萬八千人）。開戰之初，羅馬步兵的標槍與短劍「像砍稻草般彈開」，長矛牆勢不可擋；但地面的起伏與追擊中的隊形撕裂，讓方陣出現縫隙——羅馬人丟下標槍，拔出短劍，鑽進矛林肉搏。一小時後，世界最強的長矛體系崩潰，馬其頓王國亡國。這樁案件宣判：**前二世的戰場已屬於「彈性 + 個體近戰」的軍團，不再屬於「剛性 + 集體推力」的方陣**。亞歷山大的遺產（見 [-0338-喀羅尼亞與馬其頓體系.md](-0338-喀羅尼亞與馬其頓體系.md)）就此移交羅馬。

## 前因 -- 為什麼會有這個案子

- 坎尼之後（見 [-0216-坎尼會戰.md](-0216-坎尼會戰.md)），羅馬用「避戰消耗 + 兵源優勢」贏得第二次布匿戰爭，接著把矛頭轉向東方希臘化王國。
- 馬其頓安提柯王朝的軍事資產仍是腓力二世配方：長矛方陣 + 夥伴騎兵。但騎兵的比例與素質已大幅衰退，方陣從「鐵砧」退化為唯一的賭注。
- 前 197 庫諾斯克法萊（狗頭山）戰役中，羅馬軍團已在地形破碎處擊潰方陣一次；珀爾修斯重整軍備，想在決戰中雪恥——**他選了平地，卻忘了方陣的真正弱點不是地形，而是陣形自身的剛性**。

## 線索與推理 -- 為什麼軍團能破方陣

### 線索一：兩種武器體系的物理參數

| 參數 | 馬其頓長矛方陣 | 羅馬軍團 |
|------|----------------|----------|
| 主要武器 | sarissa 長矛 4–6 公尺 | 短劍 gladius + 大盾 + 標槍 |
| 殺傷距離 | 5 公尺內密集推刺 | 貼身 1 公尺內劈刺 |
| 隊形彈性 | 幾乎為零（連續矛牆） | 中隊（maniple）棋盤式、可分合 |
| 地形依賴 | 極高（地面起伏即破陣） | 極低（小隊各自為戰） |
| 轉向能力 | 極慢（整體轉向以分計） | 快（中隊各自旋轉） |

### 線索二：剛性系統的失效模式

方陣的戰力來自「長矛同時到位」的集體幾何，可用一條不等式表達：

$$\text{方陣有效} \iff \text{矛牆連續} \land \text{接觸距離} \ge 3\,\text{m}$$

一旦對手進入 3 公尺以內的貼身區，長矛過長無法劈刺、盾牌單手難以格擋——**武器優勢瞬間反轉為武器劣勢**。羅馬人正是系統性地製造這個瞬間：先以標槍（pila）齊射打亂矛尖，再以中隊滲入撕裂縫隙。

### 線索三：一頭骡子的傳說

普魯塔克記載：會戰前夕保盧斯讓士兵看一隊人在平原挖溝、築牆、搬運，隨即問：「這些障礙會把那麼多根長矛切分成幾段？」——**軍團指揮官的核心功課，是把敵人的剛性系統引入非均質地形**。彼得納的地面有田埂、岩層與沖溝，方陣追擊時隊形被地面「拉扯出洞」，羅馬人從洞裡進去了。

### 線索四：後方沒有騎兵鎚

喀羅尼亞與高加米拉的公式是「方陣釘住、騎兵錘擊」（見 [-0338-...](-0338-喀羅尼亞與馬其頓體系.md)）。彼得納的馬其頓騎兵無力執行錘擊——方陣獨自上場，從「鐵砧＋鐵鎚」退化為只剩鐵砧。**體系少了一半，體系就不是體系。**

## 破案時刻

長矛牆初期的碾壓感騙過了所有人，但矛牆追擊中裂開的縫隙被羅馬中隊逐一楔入；貼身近戰中，短劍對長矛是屠殺。約一小時，方陣崩解，兩萬馬其頓人陣亡，珀爾修斯逃亡被俘。羅馬隨後肢解馬其頓為四個共和區（前 167），前 148 直接併為行省——希臘化軍事傳統就此出局。

## 後果 -- 改變了什麼

- 東地中海被納入羅馬體系，前 30 年（埃及托勒密滅亡）後整個地中海成為「羅馬湖」。
- 軍團編制（中隊→大隊的彈性階層）成為兩千年後普魯士營制與現代步兵班組的遠祖——**組織彈性壓倒武器長度**，這是本卷規律「戰法比武器更稀缺」的古典例證。
- 職業化壓力：長期駐防東方使前 107 年馬略改革（無產者入役、軍隊效忠將領）成為必然，直接通向共和國的終局。
- 但軍團對草原騎射的無力並未解決：五十年後卡萊之戰（[-0053-卡萊之戰.md](-0053-卡萊之戰.md)）將揭示這套勝利體系的另一個盲區——**機動**。

## 戰法演進筆記

1. **剛性 vs 彈性**：密集矛牆是「最大化的正面輸出」，軍團是「最小化的失效傳播」——現代系統工程的冗餘與模組化思想，兩千年前已在戰場上驗證。
2. **貼身區反轉**：任何武器的優勢距離之外，都是它的死地；戰法設計就是「把敵人拖進他的死地」。
3. **體系完整性**：方陣亡於騎兵缺位，正如戰車亡於步炮協同缺位——孤立兵種沒有未來。
