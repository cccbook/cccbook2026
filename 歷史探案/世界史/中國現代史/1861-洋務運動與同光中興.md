# 1861-洋務運動：中體西用的三十年

## 案件摘要

1861–1895 年，洋務派（恭親王奕訢！文祥！曾國藩！李鴻章！左宗棠！張之洞！）推行**洋務運動**（「中學為體、西學為用」！張之洞《勸學篇》！）：此前 1860 北京條約（[1840-鴉片戰爭.md](1840-鴉片戰爭.md)！圓明園！）、總理衙門（1861！）、辛酉政變（1861！兩宮—恭親王誅肅順！同治中興！）；此後：江南製造局（1865！）、福州船政（1866！左宗棠—沈葆楨！）、輪船招商局（1872！）、開平煤礦（1878！）、北洋水師（1888！定遠—鎮遠！亞洲第一！）、留美幼童（1872–81！容閎！詹天佑！）、京師同文館（1862！）→ 1894–95 甲午慘敗（[1894-甲午戰爭.md](1894-甲午戰爭與公車上書.md)！）——**洋務破產**。這樁案件是「器物改革的天花板」：**只學槍炮、不學制度，甲午一戰現形**。

## 前因 -- 多因素的局勢

- **戰爭**：太平—捻—回亂（[1851-太平天國.md](1851-太平天國.md)！）＋英法（圓明園！）——「剿—攘」雙需（→「師夷長技」！馮桂芬《校邠廬抗議》！）。
- **人事**：恭親王（總理衙門！）＋曾—李—左—張（漢人督撫！團練！）——**漢人掌兵掌財**（→中央—督撫新平衡！）。
- **財政**：釐金（厘金！1853！ domestic tariff！）＋海關（赫德！1863 總稅務司！）——**新稅種**（→洋務錢包！）。
- **思想**：「中體西用」（馮桂芬—張之洞！）vs 頑固（倭仁！「立國之道尚禮義不尚權謀」！）——**體用之爭**（→馬建忠—郭嵩燾開眼！）。

## 線索與推理 -- 因素咬合

### 線索一：江南—福州—北洋——「軍工的系譜」

| 企業 | 創辦 | 結局 |
|---|---|---|
| 江南製造局（上海！1865！） | 曾—李（「蒸汽機」！翻譯館！徐壽—華蘅芳！） | 官辦（虧損！→江南造船！） |
| 福州船政（1866！） | 左—沈（法國！日意格！學堂！嚴復！） | 船（萬年清！）＋人才（嚴復—詹天佑系！） |
| 輪船招商局（1872！） | 李鴻章（「官督商辦」！盛宣懷！） | 商辦（→招商局！至今！） |
| 開平煤礦（1878！） | 李—唐廷樞（開平！） | 礦（→開灤！） |
| 北洋水師（1888！） | 李鴻章（定遠—鎮遠！德國！劉步蟾！） | 甲午覆滅（→劉公島！） |

$$\text{洋務} = \text{（官辦軍工：虧損！）} + \text{（官督商辦：糾紛！）} \Rightarrow \text{「官辦」魔咒}$$

**官辦即虧損**（→盛宣懷—鄭觀應！「商辦」呼聲！）——北洋水師（亞洲第一！紙面！）→ 甲午（黃海—威海！丁汝昌自殺！）——**紙面艦隊**（→挪用頤和園！李鴻章背鍋！慈禧！）。

### 線索二：留美幼童——「幼苗的悲劇」

1872–81：容閎（耶魯！）策劃、120 幼童（10–16 歲！詹天佑—唐紹儀—梁敦彥！）赴美（康州！）→ 1881 撤回（「全盤西化」恐懼！吳子登！「忘本」！）：

$$\text{幼童} = \text{（留學：最早！）} \times \text{（撤回：中斷！）} \Rightarrow \text{人才斷層}$$

**撤回的代價**（→詹天佑修京張 1909！唐紹儀民國總理！梁敦彥外務！——倖存者撐起晚清—民國！）。同文館—廣方言館（京師—上海—廣州！）＋翻譯（《幾何原本》後續！江南譯書！）——**西學的管道**（→嚴復《天演論》1898！「物競天擇」！）。

### 線索三：甲午現形——「三十年一戰歸零」

1894–95：豐島—平壤—黃海（致遠鄧世昌！「撞吉野」！）—旅順（屠殺！）—威海衛（劉公島！丁汝昌！）→ 馬關（李鴻章！2 億兩！割台！）：

$$\text{甲午敗} = \text{（日本：明治 20 年！徵兵—參謀—海軍！）} \times \text{（清：洋務 30 年！官僚—挪用—無體制！）}$$

**同是移植，差在體制**（→日本：學制—憲法！清：只學槍！）——李鴻章（「以夷制夷」！馬關簽字！「老佛爺」！）——**洋務總管簽下賣身契**（→公車上書！[1894-甲午戰爭.md](1894-甲午戰爭與公車上書.md)！）。北洋覆滅（→「海軍衙門」！醇親王！）——**洋務的訃告**。

## 破案時刻

- 1860–1861：北京條約—總理衙門—辛酉政變（兩宮！）——開幕。
- 1862–1875：同文館—江南局—船政—招商局—幼童（同治—同光中興！）——建設。
- 1875–1885：海防—塞防之爭（李鴻章—左宗棠！新疆建省 1884！中法戰爭！）——爭議。
- 1885–1894：海軍衙門—北洋水師（定遠！）—張之洞（漢陽鐵廠！）——頂點。
- 1894–1895：甲午（黃海—威海！）—馬關——破產。

## 後果 -- 改變了什麼

- **軍事**：北洋覆滅（→新軍！袁世凱小站！[1911-辛亥革命.md](1911-辛亥革命與民國肇建.md)！）——洋務養大北洋（→軍閥！）。
- **經濟**：招商—開平—漢陽（→民族資本！盛宣懷—張謇！）——「官督商辦」的遗产（→買辦—民族資產階級！）。
- **思想**：中體西用破產（→嚴復—梁啟超！變法！[1898-戊戌變法.md](1898-戊戌變法與百日維新.md)！）——「器—制」之辨（→孫中山革命！）。
- **人物**：李鴻章（「背鍋」！馬關！）—左宗棠（新疆！）—張之洞（「中興名臣」！）——晚清三傑（→蓋棺！）。

## 因素影響筆記

```
太平英法（雙需！）×恭曾李左張 ──→ 總理衙門—江南船政（軍工！）
官辦魔咒（虧損！）＋幼童中斷 ──→ 北洋紙面（亞洲第一！）
日本體制移植（明治！）×清器物移植 ──→ 甲午現形（馬關！）──→ 破產
```

**偵探結語**：洋務案件是體用的審判：**中學為體（科舉—八股！）、西學為用（槍炮—船！）**——體不動，用也爛（北洋！挪用！）。李鴻章（1872 幼童！1888 北洋！1895 馬關！）一生三事：送孩子（留美！）、買軍艦（定遠！）、簽條約（馬關！）——**送出去的是希望，買回來的是廢鐵，簽下的是訃告**。甲午的炮聲（黃海！）是洋務的喪鐘——鐘聲裡，康梁（公車上書！）上場了。
