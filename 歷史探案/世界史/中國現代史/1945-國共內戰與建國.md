# 1945-國共內戰：三大戰役與天安門

## 案件摘要

1945–1949 年，國共內戰（**解放戰爭**！）；此前：1945.8 蘇聯出兵東北（[1931-九一八.md](1931-九一八事變與滿洲國.md)！）、重慶談判（毛蔣！雙十協定！）、1946 政協（軍調！馬歇爾！）；此後：1946–47 內戰爆發（中原突圍！延安轉戰！「蘑菇」！）、1947 劉鄧大別山（「狹路相逢」！）、1948–49 **三大戰役**（遼瀋—淮海—平津！林彪—粟裕—聶榮臻！）、1949.4 百萬雄師過江（南京！「宜將剩勇追窮寇」！）、1949.9 政協（共同綱領！）、1949.10.1 **開國大典**（天安門！「中國人民站起來了」！）→ 12 月成都（蔣飛台灣！）——**中華人民共和國**。這樁案件是「人心向背的四年」：**430 萬（國！）vs 120 萬（共！）開局，倒過來結局**。

## 前因 -- 多因素的局勢

- **國民黨**：接收腐敗（「五子登科」！金子—房子—車子—女子—面子！）＋法幣崩（1948 金圓券！「十萬」！）＋軍隊派系（嫡系—雜牌！「保存實力」！）——**勝利者的腐爛**（→「金圓券」！）。
- **共產黨**：延安整風—七大（[1937-全面抗戰.md](1937-盧溝橋與全面抗戰.md)！）＋土改（《土地法大綱》1947！「耕者有其田」！）＋新式整軍（訴苦—三查！）——**翻身—訴苦—支前**（→「民心」！）。
- **東北**：蘇聯（出兵—搬機器！「戰利品」！）＋林彪（10 萬進東北！）＋杜聿明（接收！）——**決戰之地**（→遼瀋！）。
- **美國**：馬歇爾調停（1946！「第三條路」！）＋援華（《中美商約》！美械！）——**拉偏架**（→魏德邁！）。

## 線索與推理 -- 因素咬合

### 線索一：土改—金圓券——「民心的天平」

| 共產黨 | 國民黨 |
|---|---|
| 土改（1947 大綱！「打土豪分田地」！） | 接收（「劫收」！五子登科！） |
| 新式整軍（訴苦！官兵一致！） | 派系（嫡雜！「友軍有難不動如山」！） |
| 支前（淮海 500 萬民工！「小推車」！陳毅！） | 壯丁（抓丁！「刮」！） |
| 紀律（三大紀律八項注意！） | 軍紀（「劫」！） |

$$\text{內戰勝} = \text{（土改：翻身！）} \times \text{（支前：小推車！）} \times \text{（俘虜：解放戰士！）} \div \text{（金圓券：通脹！）}$$

**淮海（1948.11–1949.1！60 萬勝 80 萬！）是小推車推出來的**（→500 萬民工！陳毅「淮海戰役的勝利是人民用小車推出來的」！）——金圓券（1948.8！宋子文—俞鴻鈞！「十萬」！）——**通脹逼反中產**（→上海！「打老虎」！蔣經國！）。孟良崮（1947！張靈甫！74 師！）——**整編師的覆滅**（→粟裕！）。

### 線索二：三大戰役——「 Five 個月的改朝換代」

遼瀋（1948.9–11！林彪！錦州—長春—瀋陽！衛立煌！「關門打狗」！）、淮海（11 月–1949.1！粟裕—劉伯承！徐州—杜聿明！「吃一個夾一個」！）、平津（1948.12–1949.1！聶榮臻！傅作義！北平和平！「古都保全」！）：

$$\text{三大戰役} = \text{（遼瀋：關門！）} + \text{（淮海：吃夾！）} + \text{（平津：和平！）} = 154\text{萬國軍}$$

**5 個月殲 154 萬**（→國軍主力！）——傅作義（北平和平！「保全古都」！梁思成！）——**文物的勝利**（→故宮—城牆！）。天津（劉亞樓！29 小時！）——**打給傅作義看**（→「打」促「談」！）。

### 線索三：天安門——「站起來的儀式」

1949.9.21–30：政協（共同綱領！國旗—國歌—國徽—紀年！曾聯松—田漢—梁思成！）→ 10.1 開國大典（林伯渠主持！毛宣告！「佔人類總數四分之一」！54 門禮炮！28 響！）：

$$\text{建國} = \text{（軍事：過江！）} + \text{（政治：政協！）} + \text{（儀式：天安門！）} = \text{新中國}$$

**「中國人民站起來了」**（→天安門！）——蔣（12 月成都飛台！「一年準備」！）——**海峽兩岸**（→金門 1958！→ECFA！至今！）。上海（5 月！陳毅！「不入民宅」！）——**紀律的展示**（→「露宿街頭」！宋慶齡！）。

## 破案時刻

- 1945.8–1946.6：受降—重慶談判（雙十！）—政協—馬歇爾（調停！）——和平假象。
- 1946.6–1947.6：中原突圍—全面內戰（蔣「三個月」！）—延安轉戰（「蘑菇」！）——相持。
- 1947.6–1948.9：劉鄧大別山（反攻！）—孟良崮—沙土集—土地會議（西柏坡！）——轉折。
- 1948.9–1949.1：三大戰役（154 萬！）——決戰。
- 1949.4–10：過江（南京！）—上海—政協—開國（天安門！）——建國。
- 1949.12：成都（蔣飛台！）——分治（→海峽！）。

## 後果 -- 改變了什麼

- **中國**：中華人民共和國（→[1950-抗美援朝.md](1950-抗美援朝與一邊倒.md)！→土改—鎮反—三反五反！）——「站起來」（→「富起來—強起來」！後話！）。
- **台灣**：蔣（200 萬軍民！故宮！黃金！）——海峽分治（→823！→民主化！）——**內戰的延續**（→至今未簽和約！）。
- **美國**：「丟掉中國」（麥卡錫！「誰丟的」！）——**對華政策**（→封鎖！→1972 尼克森！[1971-聯合國席位.md](1971-恢復聯合國席位與中美解凍.md)！）。
- **蘇聯**：中蘇同盟（1950！《友好條約》！）——「一邊倒」（→156 項！→1958–60 中蘇分裂！）。

## 因素影響筆記

```
接收腐敗（五子！）×金圓券（通脹！）──→ 國統區離心（中產反！）
土改翻身（大綱！）×支前小推車 ──→ 解放區向心（民心！）
三大戰役（154萬！5個月！）──→ 過江（南京！）──→ 政協天安門（建國！）
```

**偵探結語**：內戰案件是民心的四年：**430 萬（國軍！美械！）打 120 萬（共軍！小米！）**——開局 3:1，結局倒過來。淮海（小推車！500 萬民工！）證明：**戰爭打的是後勤，後勤打的是民心**——金圓券（「十萬」！）把中產推過去，土改（「分田」！）把農民拉過來。1949.10.1，毛澤東（天安門！）說站起來了——54 門禮炮（28 響！）里，蔣介石（成都！12 月！）的飛機起飛了。**同一個中國，兩個機場**：北京降下五星旗，台北升起青天白日。內戰沒結束——只是換了海峽繼續。
