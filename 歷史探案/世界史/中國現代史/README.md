# 中國現代史 -- AI 偵探風格（自晚清起）

以「推理探案」的方式，追查中國近二百年的重大轉折：鴉片戰爭、太平天國、洋務、甲午、戊戌、義和團、新政、辛亥、洪憲、五四、建黨、北伐、九一八、長征、西安事變、抗戰、內戰、抗美援朝、一五計劃、反右、大躍進、廬山、兩彈一星、文革、解凍、懷仁堂、改革開放、懲越、特區、利改稅、破產股份、闖關、六四、南巡、分稅制、回歸、炸館、入世、SARS、奧運、動車、新時代（總案）——
前因是什麼？線索在哪裡？推理如何展開？後果又如何改變了這個國家？
總案之外，十九樁「專案」深挖關鍵節點：股災熔斷、貿易戰、修例、新冠、共同富裕、白紙、疫後經濟、DeepSeek——總案給地圖，專案給現場。
科技線十七案：接入互聯網、網路長城、門戶與BAT、淘寶、神舟五號、山寨機、3G、Android本地化、微信、餘額寶、共享單車、墨子號、短視頻、5G、北斗、百模大戰、嫦娥六號——技術如何改寫動員、治理與國力。

本卷的核心命題只有一句話：**中國現代史是「救亡壓倒啟蒙」的兩百年。**
每一場運動（洋務、維新、革命、北伐、抗戰、改革）都是「救亡」（國家危亡！）驅動；啟蒙（民主、科學、法治）往往是救亡的副產品或犧牲品。從「師夷長技」到「中國特色」，從「中體西用」到「市場經濟」，變的是藥方，不變的是病症意識：落後就要挨打。每個重大事件都是一樁「多因懸案」：偵探的工作，就是把因素鏈一環一環還原出來。

（涵蓋：鴉片戰爭、太平天國、洋務運動、甲午戰爭、戊戌變法、義和團、清末新政、辛亥革命、洪憲帝制、五四運動、中共成立、北伐戰爭、九一八事變、長征、西安事變、全面抗戰、國共內戰、抗美援朝、一五計劃、統購統銷、反右運動、大躍進、人民公社、廬山會議、兩彈一星、文化大革命、中美解凍、懷仁堂政變、改革開放、對越自衛反擊、經濟特區、利改稅、破產法、價格闖關、六四事件、南巡講話、香港回歸、炸館事件、加入WTO、SARS、神舟五號、北京奧運、動車事故、新時代總案；專案：股災熔斷、貿易戰、反修例、新冠封城、共同富裕、防疫轉向、疫後經濟、DeepSeek；科技專案：接入互聯網、網路長城、門戶BAT、淘寶、神舟五號、山寨機、3G、Android本地化、微信、餘額寶、共享單車、墨子號、短視頻、5G、北斗、百模大戰、嫦娥六號）

## 歷史因素：各自如何影響其他因素

| 因素 | 影響其他因素的機制 | 中國現代史經典案例 |
|------|---------------------|-------------------|

| **經濟** | 賠款掏空財政；通脹引爆街頭 | 馬關2億→大借款；金圓券→通脹→1988搶購 |

| **武器** | 槍桿子出政權；核武定地位 | 南昌八一；兩彈一星1964—1970 |

| **地理** | 海洋來敵、內陸縱深、台灣海峽 | 海防—塞防之爭；大三線；台海 |
| **災害** | 旱災、地震引爆政治 | 華北旱災→義和團；汶川→公開救災 |

## 因素的回饋迴路

```
              ┌────（災害／戰爭：外生衝擊）────┐
              ↓                                ↓
   地理（海陸）──→ 通商—賠款 ──→ 經濟 ──→ 政治 ──→ 組織 ──→ 武器
    │                            ↑        ↑                   │
    │                            │        │                   ↓
    └──→ 科技 ←── 資訊（報刊—網路）┘        心理 ←──────── 心理迴路
              ↑                            ↑   （國恥—救亡—復興）
              └── 思想 ←──（合法性與動員）┘

   正向迴路（加速）：挨打→學器→學制→革命→再挨打→再學
   正向迴路（加速）：改革→增長→自信→更多改革
   負向迴路（抑制）：運動→噤聲→浮誇→災難→糾偏→再運動
   救亡迴路（中國特有）：危亡→救亡壓倒啟蒙→啟蒙欠帳→下一次危亡
```

**偵探的訣竅**：找到「哪個因素先動、哪個因素放大、哪個因素抑制」，把迴路畫出來；再問一句——**這次救亡的帳單是誰付的？**案件的因果鏈就浮現了。

## 偵探的結案陳詞（階段性）

近二百年的中國現代史，可以壓縮成四條因果鏈：

1. **挨打鏈**：鴉片（炮艦！）→ 甲午（2 億！）→ 辛丑（4.5 億！）→ 辛亥（帝制終！）→ 抗戰（2000 萬！）→ 建國（站起來！）——**賠款—割地—革命—建國的救亡史**。
2. **運動鏈**：反右（噤聲！）→ 大躍進（浮誇！）→ 文革（失控！）→ 懷仁堂（政變終！）→ 真理標準（解放！）——**運動—災難—糾偏的循環**（→1981 決議！）。
3. **改革鏈**：小崗（吃飽！）→ 特區（開放！）→ 南巡（重啟！）→ 入世（工廠！）→ 四萬億（透支！）→ 雙循環（未完！）——**增長—代價—再平衡的進行式**。
4. **科技鏈**：接入（64K！）→ 門戶（上市！）→ 淘寶（電商！）→ 山寨（供應鏈！）→ 微信（連接！）→ 5G（標準！）→ 北斗（時空！）→ DeepSeek（突圍！）——**隔離—模仿—超越的技術史**（→卡脖子—自研！）。

四條鏈咬合在一起，就是本卷六十八樁案件的全部真相（二十八總案＋四十專案；階段性——DeepSeek一案仍在書寫，偵探不結案，只記錄）。
