# 1854-諾斯科特文官制：考試如何取代賣官鬻爵

## 案件摘要
1854 年《諾斯科特–屈維廉報告》（Northcote–Trevelyan Report）主張：英國文官應以**公開競爭考試**錄用、**功績晉升**、**政治中立**。此前官職靠恩庇（patronage）分贓，克里米亞戰爭後勤潰敗成為導火線。本案追查：考試制如何把「官僚」從成本變成國家能力？

$$\text{恩庇分贓} \to \text{行政無能曝光} \to \text{考試＋常任文官} \to \text{政策連續性} \to \text{財政金融可信}$$

## 前因 -- 為什麼會有這個案子
- **政治**：克里米亞（1854）英軍缺衣少藥，《泰晤士報》記者 Russell 前線直擊，選民震怒指向陸軍部冗官。
- **經濟**：自由貿易＋所得稅常設化（見 `1842` 前後脈絡）後，稅務、海關、審計業務暴增，外行官員管不了複雜財政。
- **法律**：議會主權下部長隨選舉輪替，若文官同進退則政策斷裂；需以法律確立**常任（permanence）＋中立**。
- **思想**：邊沁功利主義、東印度公司 Haileybury 學院考試先例、中國科舉經傳教士譯介，提供「考試取士」想像。
- **財政**：恩庇官員冗薪＋貪污，納稅人（已繳所得稅的中產）要求「錢花得值」。

## 線索與推理 -- 因素咬合

### 線索1：恩庇均衡的數學 -- 為何劣幣逐良幣
恩庇制下部長用職位買票，均衡為：
$$U_{\text{部長}} = \text{選票收益} - \text{行政無能的遠期成本（選民看不見）}$$
無能成本遞延、選票收益即時，故均衡必是庸官充斥。公開考試把錄用權從部長手中外包給**文官委員會**，切斷此函數。

### 線索2：報告的四根支柱
| 支柱 | 內容 | 針對的病 |
|------|------|----------|
| 公開競爭考試 | 筆試＋年齡學歷門檻 | 賣官、裙帶 |
| 分級（高低兩級） | 智識工作 vs 事務工作分流 | 高材生抄謄、庸才決策 |
| 功績晉升 | 考績＋年資，非年資自動升 | 論資排輩 |
| 政治中立＋常任 | 政務官輪替，事務官留任 | 政策斷裂 |

理論對應 **Weber 官僚制**（層級、專業、檔案、規則）與 **Wilson 政治行政二分**：政治決定價值，行政講求效率。

### 線索3：考試的雙面性 -- 公平與階級再製
初期考試重古典語文，牛津劍橋壟斷高級文官（Administrative Class），工人子弟只能進事務級。偵探註記：**考試消滅了恩庇，卻用「文化資本」設了新門檻**，此批評催生 1968 年富爾頓報告改革。

### 線索4：為何財政金融先受益
常任財政部（Treasury）＋稅務官僚穩定後，公債發行、預算編列、審計（見 `1866-國庫審計法.md`）才有連續數據與專業記憶：
$$\text{文官常任} \to \text{跨年度預算紀律} \to \text{公債利率風險溢價} \downarrow \to \text{資本成本} \downarrow$$
North（1990）制度經濟學：可信承諾降低交易成本，文官制是財政可信的底層。

## 破案時刻
- **1853**：Gladstone 授命 Stafford Northcote 與 Charles Trevelyan 調查文官。
- **1854-02**：報告出版，建議公開考試＋文官委員會。
- **1855**：樞密院令設文官委員會，先行認證考試。
- **1870**：樞密院令全面實施競爭考試，恩庇制正式終結。

## 後果 -- 改變了什麼
- **制度**：美 1883《彭德爾頓法》、法日德相繼建立功績制；考試＋中立成為現代國家標配。
- **經濟**：專業稅務、海關、統計、審計官僚使所得稅、預算、公司監理可執行，福利國家與央行治理皆立於其上。
- **金融**：財政部—英格蘭銀行—市場的三方信任鏈，因文官連續性而穩定，英國公債長期溢價低於法俄。
- **代價**：官僚保守主義、考試階級偏誤，成為 20 世紀行政改革的永恆對手戲。

## 因素影響筆記
1. 戰爭潰敗曝光 → 恩庇合法性崩 → 考試改革窗口開啟。
2. 考試外包錄用權 → 恩庇均衡瓦解 → 功績官僚形成。
3. 常任＋中立 → 政策連續 → 預算審計可執行 → 財政可信。
4. 古典科目偏誤 → 階級再製 → 富爾頓式再改革 → 考試內容之爭。
5. 專業官僚 → 統計稅務能力 → 福利／央行治理的資訊地基。
