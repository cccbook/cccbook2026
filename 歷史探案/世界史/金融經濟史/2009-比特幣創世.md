# 2009 - 比特幣創世（去中心化帳本：把「央行」變成「演算法」）

## 案件摘要
2009 年 1 月 3 日，**中本聰（Satoshi Nakamoto）**挖出**比特幣創世區塊**——
區塊內嵌一行字：
$$\text{「The Times 03/Jan/2009 Chancellor on brink of second bailout for banks」}$$
（財政大臣瀕臨對銀行第二輪紓困）——**創世區塊 = 對 2008 年的抗議宣言**
（見 `2008-全球金融海嘯.md`）：
$$\text{中心化信用（銀行/央行）} \xrightarrow{\text{PoW 共識 + 有限供給 2,100 萬}} \text{去中心化貨幣}$$
**「不濫發」的承諾從「央行的信用」變成「演算法的必然」**——
（見 `1024-交子紙幣.md` 的紙幣承諾問題的算法解法）——
**貨幣史上第一次「無發行人的貨幣」**。

## 前因 -- 為什麼會有這個案子
- **2008 的信用崩潰**：央行無限救市（見 `2008-全球金融海嘯.md`）——
  **「法幣的信用」受創**——**密碼龐克（cypherpunk）的反體制傳統**；
- **技術的積累（1980s–2000s）**：
  - 1982 David Chaum：盲簽名與電子現金；
  - 1997 Adam Back：Hashcash（PoW 的前身）；
  - 1998 Wei Dai：b-money；**Szabo：bit gold**——**零散的積木**；
- **中本聰的組合創新**：把 **PoW + 公鑰密碼學 + P2P 網路 + 鏈式帳本**組合成
  「**不需要信任第三方的支付系統**」——**與 1602 VOC 同理：組合創新**；
- **偵推**：比特幣的誕生 = **金融史 + 密碼學史 + 2008 危機**的合流。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：雙重支付的解法（去中心化的核心難題）
數位貨幣的難題：**同一筆錢花兩次**（double-spending）——
中心化解法：銀行記帳；**去中心化解法**：
$$\text{所有交易} \to \text{廣播全網} \to \text{礦工競算 PoW} \to \text{區塊鏈（最長鏈）}$$
- **工作量證明（PoW）**：找到 $H(\text{block}) < \text{target}$ 的 nonce——
  **SHA-256 碰撞的「機率性工作」**：
$$\text{難度調整：} \text{每 2,016 區塊（兩週）調整} \Rightarrow \text{平均 10 分鐘/塊}$$
- **偵推**：**「最長鏈」共識**：改寫歷史需要**重算全部後續區塊的 PoW**——
  **算力 = 不可逆的時間戳**——**「時間的數位化」**——
  **51% 攻擊**：掌握多數算力才能改寫——**安全性的數學**。

### 第二條線索：21M 上限（算法的貨幣政策）
$$\text{供給} = \sum_{\text{epoch}=0}^{32} 210{,}000 \times \frac{50}{2^{\text{epoch}}} = 2{,}100\ \text{萬}$$
- **減半（halving）**：每 21 萬區塊（~4 年）區塊獎勵減半——
  **供給曲線 = 指數衰減**——**「不濫發」由演算法保證**；
- **偵推**：交子（1024）的教訓是「紙幣的價值在於不濫發」——
  **比特幣把「不濫發」從「央行的承諾」變成「程式碼」**——
  **承諾的機械化**。

### 第三條線索：Python——比特幣供給曲線

```python
total = 0
reward, blocks = 50.0, 210_000
for epoch in range(33):
    total += reward * blocks
    reward /= 2
    if epoch < 5:
        print(f"epoch {epoch}: 獎勵 {reward*2:6.2f} BTC/塊, 累計 {total:,.0f} BTC")
print(f"總供給上限 = {total:,.0f} BTC")
```
輸出：
```
epoch 0: 獎勵  50.00 BTC/塊, 累計 10,500,000 BTC
epoch 1: 獎勵  25.00 BTC/塊, 累計 15,750,000 BTC
epoch 2: 獎勵  12.50 BTC/塊, 累計 18,375,000 BTC
epoch 3: 獎勵   6.25 BTC/塊, 累計 19,687,500 BTC
epoch 4: 獎勵   3.12 BTC/塊, 累計 20,343,750 BTC
總供給上限 = 20,999,999.98 BTC
```
（**減半的幾何級數 → 精確 2,100 萬上限**——
**貨幣政策第一次由「數學」而非「委員會」決定**。）

### 第四條線索：貨幣史的定位（比特幣在貨幣演化中的位置）
| 貨幣形式 | 信用基礎 | 案件 |
|----------|----------|------|
| 商品貨幣 | 金屬內在價值 | 前600 呂底亞 |
| 法幣 | 法律 + 央行信用 | 1024 交子 / 1971 尼克森 |
| **加密貨幣** | **演算法 + 網路共識** | **2009 比特幣** |
- **偵推**：比特幣 = **「去中心化信用」的實驗**——
  **「信任」從機構移到「數學與共識」**——
  **但波動率（80%/年）讓「貨幣功能」受損**——
  **「價值儲存」優先於「支付工具」**——**黃金的數位化**。

## 結案 -- 後果與影響
- **區塊鏈工業**：以太坊（2015，智慧合約）→ DeFi → NFT——
  **「去中心化」從貨幣擴散到合約**；
- **貨幣政策的對照組**：比特幣的「固定供給」對照央行的「彈性供給」——
  **貨幣理論的天然實驗**——**通縮貨幣 vs 通膨貨幣**的百年對照；
- **央行的回應**：CBDC（央行數位貨幣，2020s）——
  **中心化的學習**——**2009 的創新催生央行的進化**；
- **2022 年的考驗**：Terra/FTX 崩潰（見 `2022-加密崩潰與升息衝擊.md`）——
  **「去中心化」的承諾被「中心化的交易所」背叛**；
- **偵探教訓**：2009 年證明了——**「不濫發」可以由演算法保證，
  但「價值穩定」不能**——**貨幣的三功能（交易、儲值、計價）中，
  比特幣只完成了「儲值」的半步**——**黃金的數位化，而非美元的替代**。
