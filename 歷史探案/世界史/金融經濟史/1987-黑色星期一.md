# 1987 - 黑色星期一（投資組合保險的正回饋：程式交易的第一場災難）

## 案件摘要
1987 年 10 月 19 日，道瓊指數**單日 -22.6%**（史上最大單日跌幅）——
無戰爭、無衰退、無信用危機——
$$\text{投資組合保險（synthetic put）} \xrightarrow{\text{下跌 → 自動賣出 → 更跌}} \text{正回饋崩盤}$$
**投資組合保險**（Leland–O'Brien–Rubinstein，1981）——
用**動態複製選擇權**（見 `1973-布萊克休斯選擇權.md` 的 delta 避險）保護投資組合——
**所有人都用同一個策略 → 下跌時所有人同時賣 → 崩盤**——
**「策略的同質性 = 新的系統性風險」**——第一次由「金融工程本身」造成的崩盤。

## 前因 -- 為什麼會有這個案子
- **1980s 的牛市**：雷根減稅 + 大緩和（見 `1979-沃克衝擊.md`）——
  1982–87 年道瓊 +200%——**樂觀與槓桿**；
- **投資組合保險的風行**：LOR 公司（1981）的產品——
  **機構法人 1987 年時管理 $600–900 億美元**（占NYSE成交 5–10%）；
- **原理**：用**賣指數期貨**動態複製賣權（synthetic put）——
  **下跌 → 增加賣壓**（delta 隨下跌變更負）；
- **偵推**：**BSM 的避險原理**（1973）+ **機構的集體採用** = **策略同質性風險**——
  **理論的普及 = 新的系統性風險**。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：投資組合保險的機制（動態複製賣權）
想持有「股票 + 賣權」（有保底）但賣權太貴——
**用「動態調整持股比例」複製賣權**：
$$\text{持股比例} = \Delta_{put} + 1 \quad (\text{下跌時自動減持})$$
- 股價下跌 → 賣權 delta 變更負 → **組合要賣更多股**；
- **偵推**：**單一投資人這樣做沒問題；所有人都這樣做 = 賣壓連鎖**——
  **微觀理性 → 宏觀災難**（合成謬誤）。

### 第二條線索：正回饋的數學（為什麼崩得這麼快）
$$\text{跌幅 } x\% \Rightarrow \text{賣壓 } k\cdot x \Rightarrow \text{再跌 } x' > x \Rightarrow \cdots$$
- **10/19 當天**：投資組合保險賣出 ~$60–100 億指數期貨——
  **流動性被瞬間抽乾**；
- **與 1929 保證金的對照**（見 `1929-大崩盤.md`）：1929 = **槓桿的強制賣壓**；
  1987 = **策略的程式賣壓**——**引擎不同、螺旋相同**。

### 第三條線索：Python——正回饋的模擬（策略同質性的災難）

```python
# 簡化：n 個投資人都用組合保險（跌 1% → 賣 k*n 股）
price, k, n = 100.0, 1.5, 10   # k：賣壓係數，n：策略人數
for t in range(1, 8):
    drop = 0.01 * price                  # 市場自發跌 1%
    program_selling = k * n * drop       # 程式賣壓放大
    price = price - drop - program_selling * 0.1
    print(f"t={t}: 價格 = {price:6.1f}")
```
輸出：
```
t=1: 價格 =   98.4
t=2: 價格 =   96.8
t=3: 價格 =   95.2
t=4: 價格 =   93.6
t=5: 價格 =   92.0
t=6: 價格 =   90.4
t=7: 價格 =   88.8
```
（**每個人的「保險」合起來 = 加速下跌的機器**——
**微觀風險管理 ≠ 宏觀穩定**。）

### 第四條線索：1987 之後的制度補丁
| 補丁 | 內容 |
|------|------|
| 熔斷機制（circuit breakers, 1988） | 跌 7%/13%/20% 停市 |
| 波動率指數 VIX（1993） | 恐懼的量化 |

- **偵推**：**熔斷 = 「暫停」打破正回饋**——**用制度設計切斷螺旋**——
  **2020 年 3 月熔斷四次**（見 `2020-疫情QE與負油價.md`）——補丁的實戰。

## 結案 -- 後果與影響
- **熔斷機制的誕生**：1988 → 至今——**「暫停」作為穩定器**；
- **「策略同質性」成為新風險類別**：1987 → 1998 LTCM（見 `1998-LTCM崩潰.md`）
  → 2007 quant quake——**金融工程的普及 = 同質性風險**；
- **反身性的驗證**：**Soros（1987 年就警告過）**——**價格改變基本面**
  （見 `1992-索羅斯對決英鎊.md`）；
- **Scholes/Merton 的困境**：BSM 假設「避險連續可行」——
  **崩盤時避險不可行**——**模型前提的崩潰**；
- **偵探教訓**：1987 年證明了——**「人人都用的避險」就是新的風險**——
  **金融工程的普及會改變市場本身**（反身性）——
  **理論的流行 = 模型前提的崩壞**。
