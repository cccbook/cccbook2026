# 1024 - 交子紙幣（世界第一張紙幣與部分準備的實驗）

## 案件摘要
1024 年，北宋四川發行**官方交子**——**世界第一張政府紙幣**：
$$\text{鐵錢（重，難運）} \xrightarrow{\text{兌換券（交子）}} \text{紙幣（部分準備）}$$
16 家錢鋪的私交子（真宗年間）→ 交子務（1024 官方化）→ **準備金約 28–36%**——
**部分準備銀行（fractional reserve）的第一次實驗**。
結果：濫發 → 貶值 → 元朝寶鈔崩潰 → 明朝寶鈔崩潰——
**紙幣的價值取決於「不濫發」的承諾**——這是法幣的第一次大考。

## 前因 -- 為什麼會有這個案子
- **四川的鐵錢噩夢**：一匹布要鐵錢 100–130 斤——**重金屬在商業上的運輸成本**；
- **私交子（10 世紀末）**：成都 16 家錢鋪發行兌換券——**存款憑證變成貨幣**——
  與現代銀行券同構；
- **政府看到了鑄幣稅**：交子務（1024）把私券國營——**紙幣 = 鑄幣稅的放大器**；
- **時代背景**：北宋商業革命（交子、飛錢、櫃坊）——**紙幣是商業發展的必然**。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：部分準備的數學（交子的信用引擎）
$$\text{可發行紙幣} = \frac{\text{準備金}}{\text{準備率}}$$
- 交子務初期：準備率 ~28–36%（鐵錢準備）——**可發行 3 倍於準備的紙幣**；
- **現代銀行業的縮影**：部分準備 = **信用擴張的引擎**——
  也是**擠兌脆弱性的來源**。

### 第二條線索：數量方程（紙幣濫發的物理）
$$MV = PY \quad \Rightarrow \quad \pi \approx \dot{M} + \dot{V} - \dot{Y}$$
- 交子濫發（徽宗年間戰爭財政）→ $\dot{M} \gg \dot{Y}$ → **物價飆升**；
- **元朝寶鈔**（1260–）：無準備濫發 → 1368 崩潰；**明朝寶鈔**（1375–）：
  同樣崩潰——**三次連續實驗，三次同一結論**。

### 第三條線索：Python——貨幣濫發與物價（交子的數學）

```python
# 簡化：物價 = 貨幣量/實質產出（V 不變）
M0, Y = 1.0, 1.0          # 初始貨幣量、產出
print("貨幣成長率 -> 30年後物價倍數")
for g in [0.05, 0.15, 0.30]:       # 年貨幣成長率
    P30 = (1+g)**30 * M0 / Y       # 產出不變的簡化
    print(f"  {g:.0%}/年 -> 物價 x{P30:,.0f}")
```
輸出：
```
貨幣成長率 -> 30年後物價倍數
  5%/年 -> 物價 x4
  15%/年 -> 物價 x66
  30%/年 -> 物價 x2,620
```
（**30% 年貨幣成長 = 30 年物價 2,620 倍**——交子、寶鈔、
1923 年德國（見 `1923-德國超通膨.md`）都是同一條數學。）

### 第四條線索：紙幣信用的三要素（穩定性的偵探學）
| 要素 | 交子初期 | 交子後期 | 結果 |
|------|----------|----------|------|
| 發行紀律 | 分界發行（2 年一界）| 界期混亂、超發 | 貶值 |
| 準備 | 鐵錢 28–36% | 侵蝕 | 信用崩潰 |
| 財政約束 | 貿易需求 | 戰爭融資 | 濫發 |

## 結案 -- 後果與影響
- **世界金融史的第一張紙幣**：比歐洲早 600 年（歐洲 1661 年瑞典紙幣）——
  **中國金融科技的領先**；
- **三次崩潰的教訓**：交子 → 元寶鈔 → 明寶鈔——**明朝放棄紙幣、回到銀兩**——
  **東亞貨幣的銀本位傳統**（直到清末）；
- **部分準備的永恆命題**：信用擴張的引擎 vs 擠兌的脆弱——
  現代銀行業（FDIC、巴塞爾）都是對這一案的補丁；
- **偵探教訓**：紙幣的價值不在紙，在**「不濫發」的承諾**——
  這個承諾的技術（中央銀行、獨立性、通膨目標）要到 700 年後才發明
  （見 `1694-英格蘭銀行.md`）。
