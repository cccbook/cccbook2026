# 金融經濟史 -- AI 偵探風格

以「推理探案」的方式，追查金融經濟從美索不達米亞的利息到加密貨幣、量化寬鬆的每一步：
前因是什麼？線索在哪裡？推理如何展開？後果又如何改變了整個文明？

核心謎題只有一個：**如何讓「信用」擴張而不崩潰？**
金融史的本質是一部信用機器的升級史——每一次繁榮都是信用擴張，每一次崩潰都是 Minsky 時刻，
每一個新制度（中央銀行、存款保險、清算所）都是對上一次崩潰的補丁。

$$\text{信用擴張} \to \text{資產膨脹} \to \text{Minsky 時刻} \to \text{崩潰} \to \text{新制度} \to \text{再擴張}$$
理論（利息、複式簿記、馬可維茲、布萊克–休斯）與實務（銀行、交易所、衍生品）
相互促進——每一次危機，都催生一套新理論與新制度。
