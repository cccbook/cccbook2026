# 古巴比倫史的歷史年表（推理探案）

> 古巴比倫史是泥板、運河與帝國互相塑造的偵探史：人類第一筆賬為什麼記在泥板上？薩爾貢如何用女兒統治帝國？世界第一部法典為什麼先談工資再談殺人？一場大火如何把檔案館變成圖書館？馬爾杜克神像被搶來搶去，搶的到底是神還是稅？巴比倫之囚囚住的猶太人，為何走出了一部《聖經》？拿波尼度挖古廟，是考古還是奪權？居魯士不戰而入巴比倫，城門是誰打開的？最後一塊楔形文字泥板，寫的是星星還是訃告？
>
> 本書以「推理探案」的方式，為每個歷史事件寫一篇 wiki，包含前因後果、學術理論與跨領域影響矩陣。每篇檔名以年份開頭（西元前以負號表示，四碼不足補零）。
>
> 本書的核心命題：**巴比倫三千年的歷史，是「灌溉—書記—帝國」的三重奏**——幼發拉底河的運河養活人口，泥板書記養活帝國，帝國養活神廟；水斷則城空，板焚則史存。每篇 wiki 都以「跨領域影響矩陣」拆解政治、經濟、科技、文化與法律的互動。

## 閱讀路線（偵探式提問）

- **文字與權力線**：烏魯克泥板（-3200）→ 舒爾吉學校（-2112）→ 馬里書信（-1761）→ 圖書館（-0650）→ 最後泥板（0075）——書寫如何從賬本變成帝國，最後變成星星。
- **法典線**：烏爾納姆（-2100）→ 漢摩拉比（-1792，詳見亞洲史法典篇）→ 埃蘭搬走石柱（-1158）——法律刻在石頭上，石頭會走路。
- **神像政治線**：馬爾杜克像失蹤（-1595）→ 被搬到蘇薩（-1158）→ 西拿基立劫持（-0689）→ 居魯士歸還（-0539）——神像在哪，稅收就在哪。
- **毀滅與重生線**：烏爾陷落（-2004）→ 巴比倫被淹（-0689）→ 耶路撒冷陷落（-0587）→ 巴比倫開城（-0539）——每一座倒掉的城，都在為下一座交學費。
- **帝國更替線**：薩爾貢（-2334）→ 漢摩拉比（-1792）→ 提格拉特帕拉沙爾（-0729）→ 那波帕拉薩爾（-0626）→ 居魯士（-0539）→ 亞歷山大（-0323）——王冠在兩河流域轉了七次手。
