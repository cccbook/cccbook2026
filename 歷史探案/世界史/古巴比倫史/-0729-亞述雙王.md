# -0729 亞述雙王：提格拉特帕拉沙爾的兩頂王冠

## 案發現場

公元前 729 年（一說前 728 年），亞述王提格拉特帕拉沙爾三世征服巴比倫，自兼巴比倫王（以「普魯」之名行巴比倫王權，一說）。此前：巴比倫內亂（迦勒底部落酋長輪流稱王）、亞述軍事改革（常備軍+攻城+驛站）。此後：亞述王兼巴比倫王成慣例（薩爾貢二世、辛那赫里布之子），直到 -689 年翻臉（參見本書 [-0689-西拿基立毀滅.md](-0689-西拿基立毀滅.md)）。**一個王戴兩頂王冠——這是統一，還是合租？**

> **征服者為什麼要當兩次王？直接吞併多省事——戴兩頂帽子，累不累？**

## 偵查過程

**線索一：雙王冠的算計（統治成本學）。** 提格拉特帕拉沙爾滅巴比倫諸王（迦勒底酋長），不設行省（亞述本土模式），親自兼任巴比倫王（行新年節牽神手儀式）。偵查結論：這是**差異化統治**：亞述本土（行省+總督+重稅）vs 巴比倫（保留王號+神廟特權+輕稅）——**一國兩制的前傳**。成本賬：直接吞併（行省化）→巴比倫祭司貴族反抗（新年節停辦=神怒）→駐軍鎮壓（燒錢）；雙王（兼任）→祭司配合（儀式照辦）→稅收照交（便宜）。**王冠是統治的接口**：巴比倫只認「牽過馬爾杜克手的王」，提格拉特帕拉沙爾去牽一下，稅就來了。**一場儀式，省一支駐軍**——投資回報 最高的加冕。

**線索二：普魯之名（馬甲的藝術）。** 在亞述稱提格拉特帕拉沙爾，在巴比倫稱普魯（普魯，一說是王號非本名）——**一人兩名**。偵查結論：這是**身份套利**：亞述人要征服者（尚武），巴比倫人要傳統（古風）——**一個身體，兩套人設**，見什麼人說什麼話。與清朝皇帝（北京稱皇帝，蒙古稱大汗，西藏稱文殊）同構：**多民族帝國的標配是多重身份**——身份越多，統治越滑。普魯之名的真相（學界爭議：是否篡位者別名）不重要——**重要的是雙名制的發明**：此後亞述王（薩爾貢二世兼巴比倫王，辛那赫里布之子阿淑爾那丁舒米）紛紛效仿——**馬甲成了制服**。直到西拿基立撕破臉（-689，參見毀滅篇）——**制服總有脫下的一天**。

**線索三：軍事改革的底氣（常備軍+驛站）。** 提格拉特帕拉沙爾改革：常備軍（王室部隊，脫產）、攻城器械（衝車、坑道）、驛站（快馬情報網，一說）。偵查結論：這是**亞述軍事革命**：部落徵召（農忙打仗，農閒種地）→職業軍隊（全年打仗）——**暴力專業化**。常備軍的財政：重稅+戰利品（以戰養戰）——**軍隊是盈利單位**（搶來的>養的）。驛站（快馬接力，七天尼尼微到前線，一說）=**信息高速公路**：叛亂一起，中央即知——**通訊速度決定帝國半徑**（參見蒙古驛站，[../亞洲史/1206-成吉思汗.md](../亞洲史/1206-成吉思汗.md)：同款）。-729 年的雙王冠，是軍事改革的**變現**：刀快了，才有資格談儀式（沒刀，祭司不讓你牽神手）。**先有軍隊，後有馬甲**——順序不能反。

**線索四：慣例的詛咒（雙王制的保質期）。** 此後百年：亞述王兼巴比倫王（薩爾貢二世、辛那赫里布之子），巴比倫人造反（米羅達巴拉丹兩次，-721、-703，聯合埃蘭），西拿基立翻臉（-689 毀城）。偵查結論：**雙王制是止痛藥，不是解藥**：儀式安撫祭司，安撫不了迦勒底部落（要的是自治，不是儀式）——**麵包（自治）比儀式（牽手）實在**。米羅達巴拉丹（迦勒底酋長，兩次稱王，聯合埃蘭、以色列希西家？一說《聖經》使節）證明：**只要亞述主力外出（打烏拉爾圖、打埃及），巴比倫即反**——雙王制的有效期=亞述駐軍在場期。**合租的本質：房東（亞述）在，房客（巴比倫）老實；房東出門，房客換鎖**。-689 年西拿基立不演了（毀城）——**合租撕毀，改強拆**（參見毀滅篇）。

## 結案報告

1. **接口定律**：王冠是統治接口——一場儀式省一支駐軍。
2. **馬甲定律**：一人兩名——多民族帝國標配多重身份。
3. **刀先定律**：先有軍隊後有馬甲——沒刀，祭司不讓牽手。
4. **合租定律**：房東在房客老實——雙王制有效期等於駐軍在場期。

**直接吞併與雙王（對照）：**

| 項目 | 行省化（亞述本土） | 雙王制（巴比倫） |
|------|-------------------|------------------|
| 成本 | 駐軍鎮壓（貴） | 儀式安撫（便宜） |
| 風險 | 叛亂（高） | 叛亂（中，房東出門即反） |
| 壽命 | 長（同化） | 短（-689 翻臉） |
| 適用 | 小邦 | 大城（祭司強） |

**統治公式（示意）：**

```
統治成本 ＝ 駐軍費 − 儀式節省。
雙王：駐軍少 − 儀式多 → 便宜。
房東出門：節省歸零 → 叛亂 → 強拆（-689）。
```

**結論：** 亞述雙王案是「差異化統治」的完整樣本：兩頂王冠、兩個名字、一場儀式、百年合租——征服者學會了算賬。**統一不只有一種姿勢**：吞併（貴，長久）、雙王（便宜，短命）——提格拉特帕拉沙爾選了便宜的。此後百年，巴比倫人用四次叛亂證明：**便宜沒好貨**。-689 年，房東不演了，直接強拆——合租合同到期，推土機進場。
