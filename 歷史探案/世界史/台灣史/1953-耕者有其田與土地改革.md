# 1953-耕者有其田：農業剩餘變工業資本

## 案件摘要

1953 年 1 月，《耕者有其田條例》生效：政府強制徵收地主超額土地，轉售給佃農，約十四萬戶佃農受惠，台灣完成土地改革三部曲（三七五減租 1949、公地放領 1951、耕者有其田 1953）。這不只是「分田」——它把農業部門的剩餘，經由肥料換穀、低糧價與地主股份化，整套轉移到工業部門，成為台灣工業化的第一桶金。本案要追查：一場溫和的土地改革，為何能同時做到「安定農村」與「累積資本」？

## 前因 -- 多因素的局勢

- **政治**：國民政府失去大陸後檢討失敗原因——大陸的農民革命（共產黨靠土地改革動員農民）是最大的教訓。
- **二二八與戒嚴**：本土精英受挫、威權體制確立——改革的政治阻力被壓制。
- **經濟**：日據時期土地分配不均延續；通膨未平，農村需要穩定。
- **組織**：陳誠主導，行政體系的執行力強；日據留下的地籍、戶政資料完整——丈量與登記的成本低。
- **國際**：美援（1951 起）提供資金與技術顧問（如中美農村復興委員會），支持改革的設計。

## 線索與推理 -- 因素咬合

### 線索一：地租理論 = 為什麼要限租

李嘉圖地租理論：佃農地租若達五成以上，佃農缺乏增產誘因——

$$\text{佃農努力} \propto \text{邊際產出的分成} - \text{努力的邊際成本}$$

三七五減租把分成從 50% 提升到起碼 62.5%（剩餘歸佃農）——**誘因結構改變，農業生產立即上升**。這是「制度就是生產力」的經典證明（後來經濟學者如張五常對分成租佃的進一步討論，都以此案為素材）。

### 線索二：溫和補償 = 為什麼地主不流血

台灣土改與共產黨的暴力土改完全不同：政府以土地債券（實物債券）與四大公營事業（台泥、台紙、農林、工礦）的股票補償地主——**土地資本被轉換為工業資本**。部分地主（如辜振甫家族）轉型為企業家，土地階級被「資本化」而非消滅。這是改革政治學的精髓：讓舊階級有出口，阻力就消失。

### 線索三：農業剩餘的榨取 = 發展經濟學的核心公式

土改同時配「肥料換穀」（農民以稻穀換肥料，價格不利農民）與低糧價政策——政府以廉價糧食維持低工資、供出口賺外匯：

$$\text{工業資本累積} = \text{農業剩餘} + \text{美援} + \text{勞動的低成本}$$

這是戰後發展經濟學的標準配方（劉易斯二元經濟模型：農村剩餘勞動轉移到工業部門，工業起飛）——台灣用最溫和的方式實現。

### 線索四：產出成長 = 制度改革的乘數

土改後 1950 年代稻米單位產量與農家所得明顯成長，農村成為國民黨的穩定票倉（農會系統），同時為 1960 年代出口導向工業化提供廉價勞力與糧食基礎——**改革的多重紅利**：安定、資本、勞力一次到位。

## 破案時刻

- 1949.4：三七五減租（限租）。
- 1951：公地放領（公地轉售農民）。
- 1953.1：耕者有其田（徵收地主超額土地，轉售佃農）。
- 1953 起：肥料換穀、農業剩餘支援工業。

## 後果 -- 改變了什麼

- **經濟**：農村安定、農業剩餘轉工業資本——1960 年代經濟起飛的地基（見 [1966-加工出口區與經濟起飛.md](1966-加工出口區與經濟起飛.md)）。
- **政治**：農民成為國民黨的基層支持；土地改革的正當性補償了威權統治的暴力面。
- **社會**：地主階級轉型為企業家與都市中產；土地分配平均化，所得差距縮小。
- **世界史**：與韓國並列的「溫和土改＋發展型國家」案例，與共產國家的暴力土改形成對照組。

## 因素影響筆記

1. **政治教訓（大陸失敗）→ 改革決心**：競爭與失敗是改革的溫床。
2. **限租 → 誘因改變 → 產出成長**：制度設計就是生產力。
3. **補償機制 → 階級轉型 → 阻力消失**：改革的出口設計決定成敗。
4. **本案件的總教訓**：最好的改革不是消滅舊階級，而是把舊資本轉換為新生產力——安定與成長可以同時達成。
