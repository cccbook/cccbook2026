# 1919-糖業帝國與總督府：米糖王國與殖民地經濟的算式

## 案件摘要

1919 年前後，台灣已成為日本的「糖庫」：總督府以「產業殖產興國」為綱領，扶植製糖會社（三井、三菱、明治、鹽水港等），建立「原料採收區域制度」——糖廠劃定原料區，農民被迫（或被利誘）種甘蔗，以官方核定價格賣給指定糖廠。同時水利與米作並進，最終在 1930 年完成嘉南大圳，形成「農業台灣、工業日本」的米糖王國格局。這樁案件的謎題是：**為何台灣的農業產值狂飆，農民卻相對貧困？**答案是「強制交易的價格剪刀差」——殖民經濟學教科書式的樣本。

## 前因 -- 多因素的局勢

- **殖民戰略**：日本工業化（日清、日俄戰爭後）需要糖與米的供應地——台灣的亞熱帶氣候是天然的糖庫。
- **制度**：第四任總督兒玉源太郎與民政長官後藤新平（1898–1906）奠定「生物學原則的殖民統治」——舊慣調查、土地林野調查、保甲制、警察網。
- **資本**：日本財閥資本（三井、三菱）進入台灣糖業——規模化與壟斷化的資本結構。
- **政策**：原料採收區域制度（1925 年法制化）、米糖輪作——制度性的強制收購。
- **工程**：八田與一規劃嘉南大圳（1920 動工，1930 完成，烏山頭水庫為核心）——亞洲最大的灌溉工程之一。

## 線索與推理 -- 因素咬合

### 線索一：原料採收區域 = 制度化的賣方困境

糖廠在劃定區域內是**唯一的買方**（買方壟斷，monopsony），農民則近乎沒有替代買家：

$$\text{農民剩餘} = (\text{官方核定收購價}) - (\text{生產成本})$$

收購價由糖廠與官方核定，不由市場競價——當買方唯一且價格被核定，農民的談判力趨近於零。這與秦代郡縣制「官員不可替換」（[-0221-秦的統一與官僚帝國.md](-0221-秦的統一與官僚帝國.md)）是同一結構問題的經濟版：**沒有替代選項的一方，永遠是弱勢方**。

### 線索二：米糖王國 = 比較利益的殖民版

「農業台灣、工業日本」是李嘉圖比較利益的殖民應用：台灣產米糖（土地密集），日本做工業（資本密集）——分工在效率上成立，但殖民結構下：

| | 市場經濟的分工 | 殖民地分工 |
|---|------|------|
| 價格決定 | 市場競價 | 官方與壟斷資本核定 |
| 剩餘分配 | 依議價力 | 向宗主國資本傾斜 |
| 產業升級 | 自動發生 | 被制度抑制（工業留在日本） |

**比較利益決定「做什麼」，殖民結構決定「誰獲利」**——台灣的剩餘以利潤匯出、低收購價、稅負的形式流向日本。

### 線索三：嘉南大圳 = 灌溉的算式與其代價

八田與一的嘉南大圳（烏山頭水庫＋三年輪灌制）：灌區約十五萬公頃，米、糖、雜作三年輪作。灌溉提升產量：

$$\Delta \text{產出} = \text{灌溉面積} \times (\text{單位增產}) - (\text{工程成本} + \text{水租} + \text{輪作限制})$$

但農民付出的是：強制入會的水租、輪作對作物選擇的限制、以及竣工前近十年的勞役與徵收。**產量的增加不等於福利的增加**——分配結構才是關鍵。烏山頭水庫的土石壩工法（當時東亞最大）是工程技術的傑作——技術是中性的，制度決定技術為誰服務。

### 線索四：統治哲學 = 「生物學原則」的後藤新平

後藤新平的統治論：先「舊慣調查」（了解社會的器官），再「漸進同化」——把台灣社會當作生物體來解剖與管理。1919 年首任文官總督田健治郎行「內地延長主義」——表面同化（內地延長、共學、市街庄制），實質上工業與資本的控制不變。**統治的軟化與經濟的控制是同一政策的兩面**——高壓的終結（[1915-西來庵事件.md](1915-西來庵事件.md)）與糖業帝國的成熟是同時發生的。

## 破案時刻

- 1898–1906：兒玉—後藤體制；土地調查、保甲制、糖業獎勵。
- 1900s–1910s：新式糖廠量產，台灣糖出口激增，日本財閥壟斷糖業。
- 1920 年：嘉南大圳動工。
- 1925 年：原料採收區域制度法制化。
- 1930 年：嘉南大圳完工——米糖王國的完成式。

## 後果 -- 改變了什麼

- **經濟**：台灣成為日本米糖的最大供應地——農業產值高峰，但農民所得分配惡化（「糖業帝國、糖農貧困」的對比）。
- **社會**：佃農、半自耕農與糖廠的矛盾累積——1920 年代農民組合運動的土壤。
- **工程**：水利與農業基建成為戰後台灣農業的遺產（嘉南大圳至今運作）。
- **政治**：經濟剝奪養成知識份子的批判意識——與議會運動合流。

## 因素影響筆記

本案件的因素因果鏈：

1. **日本工業化需求 → 台灣成為糖庫**：殖民經濟是宗主國產業的延伸。
2. **原料採收區域 → 買方壟斷**：沒有替代買家，農民剩餘被制度性榨取。
3. **比較利益＋殖民結構 → 剩餘向宗主國傾斜**：分工決定做什麼，結構決定誰獲利。
4. **灌溉工程 → 產量與福利的分歧**：技術中性、制度決定分配——「米糖王國」的內在矛盾。
