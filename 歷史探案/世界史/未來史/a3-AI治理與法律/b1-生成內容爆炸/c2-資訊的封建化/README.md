# c2-資訊的封建化

> 樹葉節點：[a3/b1-生成內容爆炸](../../) 的終點——**如果資訊的封建化發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 社會 | 信任退回「小圈圈」（親友、付費訂閱、黨派媒體）——**資訊結構的碎片化**（與 [世界史/0476-西羅馬的崩潰](../../../世界史/0476-西羅馬的崩潰.md) 後的中世紀資訊結構對照） |
| 經濟 | 「可信媒體」的付費市場；「信任」成為稀缺資本（簽章產業、驗證服務） |
| 政治 | 「共同事實」的消失→協商的基礎崩塌——極化的制度化 |
| 心理 | 資訊繭房的固化；「圈外資訊」的自動過濾 |
| 跨鏈 | 使 [a3/b2-治理真空](../../b2-治理真空擴大/) 更難修復（共識的基礎消失） |

## 上游（傳導回顧）

生成內容爆炸→真實性稀缺→信任崩潰→「只信小圈」的防衛——**封建的資訊結構**：每個圈有自己的「事實」。

## 觀察指標

- 付費訂閱與黨派媒體的市占率（圈層化的實證）。
- 跨圈的「共同事實」清單（可共識議題的縮小）。
- 資訊繭房的程度測量（演算法的過濾偏好）。

## 不確定性

- 「分層信任」的制度化（正式場合靠簽章）可能重建「公共層」——封建化不必然全面。
- 歷史先驗（中世紀的資訊封建以印刷術打破）——新的「打破技術」可能出現。
