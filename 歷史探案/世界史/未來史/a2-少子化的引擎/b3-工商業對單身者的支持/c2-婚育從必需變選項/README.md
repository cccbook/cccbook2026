# c2-婚育從必需變選項

> 樹葉節點：[a2/b3-工商業對單身者的支持](../../) 的終點——**如果婚育從必需變選項發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 社會 | 「家庭」從社會的預設單位變成「選項之一」——規範的重寫（像「宗教從必需變選項」的世俗化先例） |
| 人口 | 婚育與「人生正軌」脫鉤——生育只屬於「選擇生育的人」；TFR 隨選擇而非規範移動 |
| 政治 | 「家庭價值」政黨 vs 「個人自由」政黨的新戰場；育兒支持的普遍化（因為生育已成少數人的選擇，補貼的政治正當性變化） |
| 法律 | 「選擇家人」的法律地位（非親屬委託、伴侶登記的多元化）——與 [a7/b2/c2-照護真空](../../../a7-壽命革命與老齡化/b2-老齡化加深/c2-單人戶與照護真空/) 咬合 |
| 心理 | 「人生正軌」的腳本消失——意義的自由化與漂浮感並存 |

## 上游（傳導回顧）

solo economy（b3）→單身的舒適與完整→婚育從「必需」降級為「選項」——**世俗化的歷史先驗**（宗教的必需→選項，用了兩百年；婚育的重寫可能更快——媒體時代）。

## 觀察指標

- 「家庭為預設單位」的政策與語言的退場（稅制、保險、用語）。
- 非婚生育與「選擇生育」的占比。
- 「人生正軌」腳本在文化產品的消失。

## 不確定性

- 規範的反轉（嬰兒潮先驗）——「必需→選項」的方向可能被宗教或文化運動逆轉。
- 「選項化」不必然減少生育（如果選擇生育的人得到充分支持，TFR 可能回升——法國先驗）。
