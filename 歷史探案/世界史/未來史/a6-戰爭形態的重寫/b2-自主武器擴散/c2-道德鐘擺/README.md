# c2-道德鐘擺

> 樹葉節點：[a6/b2-自主武器擴散](../../) 的終點——**如果道德鐘擺回擺發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 政治 | 一次「自主武器的平民災難」（直播的自殺式攻擊）→道德反彈→條約的動員（與 [武器與戰法/1915-毒氣戰](../../../武器與戰法/1915-毒氣戰.md) 的「1915 使用→1925 禁忌」先驗同構） |
| 法律 | 自主武器條約的誕生（LAWS 的管制）——與 [a3/b3-算力條約](../../../a3-AI治理與法律/b3-算力條約/) 匯合 |
| 軍事 | 自主武器的「人的否決層」制度化；擴散的收束（出口管制） |
| 社會 | 「直播的屠殺」的震撼與疲乏的鐘擺——媒體的角色 |
| 心理 | 道德門檻的回升——但疲乏可能使鐘擺再擺回 |

## 上游（傳導回顧）

自主武器擴散（b2）→一次「自殺式自主武器」的災難→道德反彈→條約動員——**鐘擺的方向由單一事件決定**（毒氣的歷史先驗）。

## 觀察指標

- 「平民災難」事件後的條約談判速度。
- 出口管制與「人的否決層」的立法。
- 媒體疲乏 vs 道德反彈的民意調查。

## 不確定性

- 鐘擺可能再擺回（疲乏）——條約可能是「弱者的條約」。
- 災難的「可歸因性」決定條約的動員力——不可歸因則無共識。
