# c1-低烈度戰爭常態化

> 樹葉節點：[a6/b2-自主武器擴散](../../) 的終點——**如果低烈度戰爭常態化發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 軍事 | 「戰爭與和平」的邊界模糊：邊界摩擦、海上檢疫、無人機互射——低於戰爭門檻的武力成為外交的延續（與 [武器與戰法/2007-震網與網路戰](../../../武器與戰法/2007-震網與網路戰.md) 的灰域戰爭同構） |
| 政治 | 武力的「外交工具化」；威懾的再定義（無人戰爭的威懾算式） |
| 法律 | 國際人道法的適用危機（自主武器+責任真空）——與 [a3/b2-治理真空](../../../a3-AI治理與法律/b2-治理真空擴大/) 咬合 |
| 社會 | 「戰爭的常態感」——遠方衝突成為背景噪音（媒體的疲乏） |
| 心理 | 「無人戰爭」的道德鈍化 |

## 上游（傳導回顧）

自主武器擴散（b2）→衝突門檻下降：

$$\text{衝突意願} \propto \frac{\text{預期收益}}{\text{（傷亡成本）} + \text{（法律與形象成本）}} \quad \text{（分母的歷史性縮小）}$$

## 觀察指標

- 低烈度衝突（無人機互射、檢疫）的年發生次數趨勢。
- 「無傷亡軍事行動」的政治反應（容忍度的量測）。
- 國際人道法的修訂討論。

## 不確定性

- 低烈度可能滑向高烈度（升級的失控）——與 [a6/b3/c1-誤判與核門檻](../../b3-核指揮的AI化/c1-誤判與核門檻/) 的交界。
