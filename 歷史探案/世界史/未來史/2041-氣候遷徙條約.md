# 2041-氣候遷徙條約：為「無家可歸的氣候」立戶籍

## 案件摘要

**如果保險退潮（a8/b1）讓沿海與乾旱帶的房產「不可保也不可賣」，受影響人口就會從「災害受災戶」轉為「結構性遷徙者」，進而逼出首部《氣候遷徙條約》——遷徙從緊急救助變成配額與補償的制度**。這條鏈是 [a8-氣候衝擊與修復](a8-氣候衝擊與修復) 的社會收尾：碳移除與地球工程管住「大氣」，本案管住「搬家的人」。

## 起火點 -- 如果不可保地帶擴張到數億人

- **現況證據**：佛州與加州的私營保險大規模退出；世界銀行估計 2050 年前內部氣候移民可達 2 億以上；太平洋島國已預簽「舉國遷居」協議（如與澳洲的條約）。
- **觸發條件**：一次海岸城市（人口百萬級）的「五年內放棄」官方宣告，房價與保單同時歸零——**「提前放棄」第一次成為國家正式政策**。

## 連鎖推演 -- A→B→C

### 第一步：資產的死亡螺旋（氣候⇒財政）

- 不可保⇒不可抵押⇒房價崩⇒地方稅基崩⇒防災公共支出無源——**氣候風險沿著「保險→信貸→財政」三級火箭放大**。
- 金融監理的反應：央行氣候壓力測試把「 stranded assets（擱淺資產）」寫進銀行的資本計提——風險從災害模型進入資產負債表。

### 第二步：條約的誕生（財政⇒國際法）

- 遷徙的舊框架全數失靈：1951 難民公約不含「氣候難民」（受迫害標準不適用）、內部遷徙無國際法地位。
- 條約三支柱：**預測性配額**（按海平面與乾旱模型的接收名額，先於災難）、**補償基金**（來源：碳價收入與化石出口國的分攤——污染者付費的國際化）、**資產重置權**（放棄的土地經註冊後在接收國換取安置權益）。
- 政治結構：接收國（高緯度、水源充沛）換取**勞動力與碳權抵換**——遷徙從慈善變成交易。

### 第三步：人口地圖的重繪（國際法⇒社會）

- 「留人工程」與「有序撤離」的評估並行：荷蘭式防禦（保住）與孟加拉式搬遷（放棄）按成本效益分流。
- 城市的勝者組：五大湖、北歐、紐西蘭、塔斯馬尼亞——「氣候避風港」的房價與移民政策成為新的政治主軸。
- 身份的新物種：數位公民權（土地淹沒、國籍保留）——太平洋島國的「舉國上雲」成為條約附件的先例。

## 分岔 -- 每一步的「若…否則…」

| 環節 | 若 | 否則 |
|------|-----|------|
| 配額制 | 預測性接收（災前規劃）→有序且便宜 | 等災後再談→邊境危機與排外反彈 |
| 基金財源 | 碳價+出口國分攤→可持續 | 只靠援助預算→年年討價還價 |
| 接收誘因 | 勞動力+碳權對價→接收國自願 | 純義務分攤→條約成為空文 |

## 整個世界的變化

| 領域 | 變化 |
|------|------|
| 財政 | 擱淺資產入表；「提前放棄」成為會計科目 |
| 法律 | 氣候遷徙者獨立於難民公約的第三身份誕生 |
| 地緣 | 水源與宜居帶成為新的戰略資產（與地球工程的歸因衝突交織） |
| 社會 | 遷徙者的政治代表權；「家鄉的數位孿生」成為文化產業 |
| 保險 | 只剩「可遷移資產」的保險——不動產保單絕跡於風險帶 |

## 觀察指標

- 保險公司在風險帶的承保退出速度（領先官方宣告約十年）。
- 各國「計畫性退讓」（managed retreat）的預算科目出現與否。
- 條約談判中接收國與排放國的對價結構（碳權抵換比例）。
- 太平洋島國數位公民制度的立法進度（先例的擴散）。

## 不確定性

- 碳移除平價（a8/b2）若提前兌現，遷徙壓力被削減，條約可能「生不逢辰」——但保險市場的定價不會等人。
- 大規模接收的政治反噬（新排外運動）可能讓配額制在首批執行後凍結。

**結論：** 本案是氣候衝擊鏈的社會結算：大氣的談判（減排、移除、工程）決定「熱多少」，遷徙條約決定「誰搬、誰付、誰收」。**氣候變遷的最終帳單不是溫度，是人口的重新分配——而分配的規則，要嘛在災前寫成條約，要嘛在災後由邊境的鐵絲網口述。**
