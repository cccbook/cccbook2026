# 2040-照護機器人與單人社會：一億個人的夜裡誰開燈

## 案件摘要

**如果獨居老人＋照護人力缺口同時越過臨界，就會逼出「機器照護準入制」（安全認證＋責任保險＋給付掛鉤），進而造成「照護從人力服務變成人機混合服務」**——夜間巡房、服藥提醒、跌倒處置先被機器接管，人類護工退守情感與複雜處置。這條鏈是 [2034-社保算法化.md](2034-社保算法化.md)（管錢）之後管「人手」的一步：給付公式化解決了錢從哪來，沒解決半夜三點誰扶起跌倒的老人。

## 起火點 -- 如果准入發生

- **現況證據**：日韓歐照護人力缺口以十萬計；單人戶比例持續攀升；跌倒偵測、服藥機器人、陪伴 AI 已進入試點給付。
- **觸發條件**：一次照護機構人力崩潰事件（夜班無人＋多起延誤處置曝光），迫使政府把機器照護納入長照給付目錄。

## 連鎖推演 -- A→B→C

### 第一步：機器接管夜間（人力⇒機器）

- 從最低風險環節切入：夜間巡房（毫米波雷達＋跌倒偵測）、服藥提醒與配藥核對、如廁與移位輔助——**先接管「無聊且危險」的時段**，事故率下降是准入的通行證：

$$\text{准入條件} = P(\text{機器事故}) < P(\text{缺人事故}) \quad \Rightarrow \quad \text{缺人越嚴重，機器越容易達標}$$

- 照護的「人力短缺」反過來是機器的降維打擊條件——短缺本身就是准入證。

### 第二步：責任與保險（機器⇒法律）

- 機器照護事故適用舉證倒置（見 [2033-AI責任與算法審計.md](2033-AI責任與算法審計.md) 的責任鏈）：廠商自證無過錯，否則賠償——責任保險變成機器上市的前置成本，保費定價事故數據。
- 給付掛鉤：使用認證機器的家庭／機構，長照給付加成；拒絕使用的，人力排隊等——**用價格引導人機混合**，而非強制。

### 第三步：單人社會的重構（法律⇒社會）

- 獨居＋機器照護常態化→「機構集中照護」需求下降→社區散居＋上門混合服務成為主流——照護從「地方」（養老院）變成「網絡」（家＋機器＋巡迴護工）。
- 與 [2044-百年人生與第二幕制度.md](2044-百年人生與第二幕制度.md) 咬合：健康年限延長＋機器照護＝獨居可行年齡上移十年——百年人生住得起、也住得下去。

## 分岔 -- 每一步的「若…否則…」

| 環節 | 若 | 否則 |
|------|-----|------|
| 夜間接管 | 事故率先降→信任建立 | 首案即大案→准入凍結十年 |
| 責任保險 | 舉證倒置→廠商自律 | 舉證在受害者→維權不能、市場劣幣 |
| 社會重構 | 人機混合→散居可行 | 全機器化→親情外包、孤獨流行病 |

## 整個世界的變化

| 領域 | 變化 |
|------|------|
| 照護 | 夜間機器化；護工轉情感與複雜處置 |
| 法律 | 舉證倒置＋責任保險前置 |
| 財政 | 給付加成引導混合；機構補貼下降 |
| 社會 | 散居養老主流化；單人戶可行年齡上移 |
| 倫理 | 親情外包爭議；機器陪伴的同意問題 |

## 觀察指標

- 照護人力缺口 vs 機器照護給付目錄品項數。
- 機器照護事故率 vs 缺人機構事故率。
- 責任保險保費曲線（風險定價的溫度計）。
- 獨居老人急診延誤處置率。

## 不確定性

- 首起重大機器事故的政治衝擊可能凍結准入多年——與核能（感知殺死好技術）同構。
- 孤獨與情感外包：機器解決了跌倒，解決不了「沒人說話」——陪伴 AI（a2/b4）的另一面在此相遇。
