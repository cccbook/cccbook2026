# c1-條約重談與太空軍備

> 樹葉節點：[a12/b2-太空主權與軌道圈地](../../) 的終點——**如果條約重談失敗與太空軍備競賽發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 軍事 | 反衛星武器常備化、軌道攔截與「衛星護航」——與 a6-戰爭形態交叉：制天權成為制空權的續集 |
| 民生 | 衛星（導航、通訊、氣象）被視為戰時目標——民用基礎設施的軍事化陰影 |
| 外交 | 太空聯盟分化（阿提密斯陣營 vs 月球站陣營）——大國競爭的第三戰場 |
| 法律 | 事實上「誰佔了算」；和平利用外空的規範倒退到「不先動手」的默契 |

## 上游（傳導回顧）

資源價值浮現（a12）→規則未定＋先發誘因（b2）→重談失敗→軍事化墊底圈地。

## 觀察指標

- 反衛星試驗次數與太空態勢感知（SSA）投資。
- 軍用太空預算佔太空總預算比重。

## 不確定性

- 太空資產的脆弱性（無法藏、難以修）反而可能催生「太空互毀恐怖平衡」→ 新型軍控——武器化的極端也是規範化的起點（與 a3/b3-算力條約同構）。
