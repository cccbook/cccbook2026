# b2-太空主權與軌道圈地

> [a12-太空資源](../) 的下游節點——**如果太空主權與軌道圈地發生**，下游分岔：[c1-條約重談與太空軍備](c1-條約重談與太空軍備/)、[c2-軌道資源公用化](c2-軌道資源公用化/)。

## 這個節點（如果發生）是什麼

1967 外層空間條約是冷戰妥協：禁止主權聲索，沒有資源產權規則。當「利用」變成「開採」變成「定居」，先佔者製造既成事實——阿提密斯協定（美國主導的雙邊承諾網）與中俄國際月球科研站（對抗軸）已經把「太空的日內瓦」問題搬上桌：**法律真空＋技術先發＝圈地**。

## 傳導與理論

先佔博弈（搶椅子模型）：當所有參與者都知道規則未定，每個人都有誘因搶先行動製造事實——

$$\text{搶先行動的誘因} \propto \text{先發優勢貼現} - \text{報復與法律風險}$$

對照大航海時代：教皇子午線（1493）是用條事後追認既成事實——太空版的前提是「誰能實際到場」。

## 觀察指標

- 阿提密斯協定簽署國數與中俄站的參與國數。
- 聯合國外空委員會（COPUOS）對「太空資源活動」規則的議程進度。
- 月面著陸點／軌道槽位的佔用公告。

## 不確定性

- 最可能的劇本是「模糊共存」：沒有新條約、也沒有攤牌——各國用國內法與雙邊協定堆出習慣法，如同深海採礦的國際海底管理局困局。
