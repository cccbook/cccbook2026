# c1-地球稀缺金屬的地緣反轉

> 樹葉節點：[a12/b1-小行星採礦與太空製造](../../) 的終點——**如果地球稀缺金屬的地緣反轉發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 地緣 | 稀土與鉑族金屬的出口國（中、南非、俄）籌碼稀釋——「礦產詛咒」與卡脖子鏈反轉 |
| 產業 | 電池、觸媒、電子業的上游成本曲線重寫；地面採礦的環境外部性議題重構 |
| 金融 | 大宗商品定價權向太空資產延伸；小行星礦權成為新資產類別 |
| 制度 | 「誰運回來算誰的」的產權判例成為太空商法基石 |

## 上游（傳導回顧）

商業迴路閉合（a12）→採礦規模化（b1）→地球市場供給曲線右移→稀缺租金消失——李嘉圖地租理論在地球之外的第一次兌現。

## 觀察指標

- 鉑族金屬與稀土價格對小行星採礦新聞的事件反應。
- 太空礦權登記與保險產品的誕生。

## 不確定性

- 地面礦的成本下限很低（人類採礦技術也會進步）；「反轉」更可能是壓縮暴利而非歸零。
