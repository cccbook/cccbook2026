# b1-小行星採礦與太空製造

> [a12-太空資源](../) 的下游節點——**如果小行星採礦與太空製造的商業迴路閉合發生**，下游分岔：[c1-地球稀缺金屬的地緣反轉](c1-地球稀缺金屬的地緣反轉/)、[c2-太空自持經濟](c2-太空自持經濟/)。

## 這個節點（如果發生）是什麼

M 型小行星（金屬型）的鉑族金屬豐度是地殼礦的百倍；近地小行星的變軌能遠低於月球。當發射成本夠低、在軌自動化夠成熟，「開採—提煉—製造」從地面運來設備、在太空就地完成——**第一座真正的星際工廠不在行星上，在小行星上**。

## 傳導與理論

商業迴路的判別式：

$$\text{利潤} = (\text{產品單價} - \text{採運成本}) \times \text{規模} - \text{固定投資}$$

兩種產品路線：①運回地球（鉑、稀土——與地面市場競爭）②太空自用（推進劑、鋼鐵結構——與發射成本競爭）。路線②的對手是「每公斤入軌成本」，隨萊特定律遞減，門檻自動下降——**太空自用先閉合的機率高得多**。

## 下游分岔（若…否則…）

| 環節 | 若 | 否則 |
|------|-----|------|
| 產品路線 | 太空自用（推進劑）先行 → c2 | 運回地球獲利 → c1 |
| 自動化 | 遠程遙控＋在軌機器人成熟 → 採礦可行 | 需載人作業 → 成本爆炸，鏈條停住 |

## 觀察指標

- 商業小行星任務的投資輪與示範任務結果。
- 在軌製造（微重力纖維、藥物結晶）的營收成長。
- 推進劑在軌補給的單價報價。

## 不確定性

- 小行星採礦在 2010 年代第一波（Deep Space Industries、Planetary Resources）已失敗一次——死於發射成本，不死於構想；本節點的觸發條件正是那個成本條件。
