# c2-綠色禁運與糧食人權

> 樹葉節點：[a11/b2-糧食地緣與出口禁運](../../) 的終點——**如果綠色禁運與糧食人權議程發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 制度 | 糧食被正名為「人權與公共財」：WTO 級的糧食出口限制紀律、國際糧食儲備條約 |
| 道德 | 禁運的正當性分裂：餓平民的禁運=戰爭罪擴張論 vs 施壓政權的合法工具論 |
| 貿易 | 「碳邊境」與「糧食邊境」合流：高碳農產品（牛、棕櫚油）承擔類關稅——綠色條款成為新禁運外衣 |
| 人道 | 俄烏戰爭黑海走廊的模式制度化：聯合國級的「糧食走廊」條約與護航機制 |

## 上游（傳導回顧）

禁運常態化（b2）→國際社會的規範反彈→糧食人權議程與綠色條款交纏——**武器化的另一面是規範化的誕生**。

## 觀察指標

- 多邊糧食出口紀律的談判進度（WTO 農業談判）。
- 碳邊境機制擴及農產品的範圍。
- 糧食走廊／人道豁免條約的簽署數。

## 不確定性

- 「綠色禁運」可能被濫用為保護主義（以碳為名的農業壁壘）——規範化與武器化共用同一件外衣。
