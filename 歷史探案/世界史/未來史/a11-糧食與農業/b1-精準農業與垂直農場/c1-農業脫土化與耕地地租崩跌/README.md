# c1-農業脫土化與耕地地租崩跌

> 樹葉節點：[a11/b1-精準農業與垂直農場](../../) 的終點——**如果農業脫土化與耕地地租崩跌發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 地緣 | 「穀倉國家」（烏克蘭、阿根廷、黑海走廊）的地緣籌碼稀釋；農業出口國的貿易結構重寫 |
| 金融 | 農地是萬億級抵押品池——地租崩跌即**抵押品通縮**，農業信貸與農地 REIT 重估 |
| 城市 | 食物里程歸零：城市周邊與城內的植物工廠——城市供應鏈韌性重定義 |
| 生態 | 露天耕地退耕還林成為可能——農業碳排放與生物多樣性的大逆轉選項 |
| 政治 | 農業補貼（美國、歐盟年數百億）的政治經濟學重寫；「農民抗爭」與技術路線的政黨化 |

## 上游（傳導回顧）

新技術平價（a11）→設施農業規模化（b1）→土地稀缺性被稀釋→李嘉圖地租重估→農地資產價格與以農地為錨的信用體系連環調整。

## 觀察指標

- 農地價格與作物收益的比價（類本益比）趨勢。
- 糧食出口國的政治籌碼語言變化（糧食是否還上談判桌）。
- 退耕還林／碳權農地的面積成長率。

## 不確定性

- 地租崩跌是漸進的（萊特定律是曲線不是斷崖）；農地同時承載碳權與太陽能租約，資產價值未必歸零、可能是「換錨」。
