# a11-糧食與農業

> 樹根節點（起火點：糧食）——**如果農業生產體系被新技術改寫發生**，下游分岔：[b1-精準農業與垂直農場](b1-精準農業與垂直農場/)、[b2-糧食地緣與出口禁運](b2-糧食地緣與出口禁運/)。

## 案件摘要

糧食是「最老的地緣武器」——從羅馬的埃及穀倉到二戰的封鎖與烏克蘭戰爭的黑海穀物走廊，誰控制卡路里，誰就控制談判桌。如果精準農業、基因編輯與垂直農場同時跨過平價門檻，糧食從「土地與天氣的函數」變成「資本與能源的函數」——農業地緣政治的底層邏輯被改寫。

## 起火點 -- 現況證據與觸發條件

- **證據**：CRISPR 育種週期從十年壓縮到兩三年；荷蘭（彈丸之地）已成全球第二大農產出口國——「單位面積產量的技術密度」已被證明；垂直農場的電力成本曲線與 LED／太陽能同步下探；極端氣候造成的主糧減產頻率上升。
- **觸發條件**：糧食價格波動率跨越政治臨界點（糧價漲三成→進口國政局動盪的歷史先驗）＋農業電力成本降至平價＋基因編輯法規鬆綁（歐盟 2023 起對新育種技術重新立法的風向）。

## 傳導與理論

馬爾薩斯的現代版：馬爾薩斯陷阱說人口按指數、糧食按線性成長——技術每次重設天花板，但陷阱的**結構**不變，只是門檻抬高：

$$\text{糧食供給} = f(\text{土地}, \text{天氣}) \longrightarrow f(\text{資本}, \text{能源}, \text{知識})$$

綠色革命的教訓（灌水增產 30%→地下水超抽）：每次增產技術都附帶新的脆弱性——本次的脆弱性是**電網與種子專利**。李嘉圖地租理論反推：若土地的稀缺性被技術稀釋，地租（與農地抵押品價值）應同步重估。

## 分岔的條件（若…否則…）

| 環節 | 若 | 否則 |
|------|-----|------|
| 技術平價 | 垂直農場電力成本 < 露天農業＋運輸 → 脫土化展開（b1） | 僅為高端蔬果利基 → 鏈條停住 |
| 法規 | 基因編輯（非轉基因）鬆綁 → 產量技術落地 | 歐盟式嚴管 → 技術外流到寬管國 |
| 地緣 | 極端氣候連年減產 → 出口禁運常態化（b2） | 全球庫存充足 → 禁運失去籌碼 |

## 觀察指標

- 垂直農場的每公斤生菜電力成本 vs 露天價格的交叉點。
- 糧食出口禁運次數與全球庫存／消耗比的年度變化。
- 各國「糧食自給率」政策目標的上修。
- CRISPR 育種作物的法規核准數。

## 不確定性

- 能源價格是外生變數：若電力平價被能源危機中斷，整條鏈延後一個世代。
- 消費者對「技術食物」的接受度可能反向（有機／自然標籤的溢價）。
