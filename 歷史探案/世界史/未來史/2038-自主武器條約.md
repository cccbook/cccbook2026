# 2038-自主武器條約：給「扣扳機的判斷」立憲

## 案件摘要

**如果自主武器在兩場區域戰爭中展現「一個人的軍隊」的作戰效率，各國就會被迫談「人的否決層」條約，進而造成「殺傷決策的歸屬」成為國際法的新分界**——武器可以自主飛行，但不可以自主決定殺人。這條鏈是 [a6-戰爭形態的重寫](a6-戰爭形態的重寫) 與 [2035-無人機蜂群與戰爭民主化.md](2035-無人機蜂群與戰爭民主化.md) 的法律收尾：2030 年代管住了「怎麼打」，本案推演「誰能下令打」的條約化。

## 起火點 -- 如果自主殺傷出現系統性誤擊

- **現況證據**：區域衝突中 FPV 與遊蕩彈藥已實現「發射後目標自主選定」；多國宣布「人類控制原則」但定義不一；聯合國特定常規武器公約（CCW）的自主武器談判停擺十餘年。
- **觸發條件**：一次高解析度拍攝的自主系統誤擊平民車隊事件在社群媒體引爆，且證據顯示**人類操作者來不及否決**（否決層形同虛設）。

## 連鎖推演 -- A→B→C

### 第一步：規範的醜聞驅動（戰爭⇒法律）

- 仿 1915 毒氣與 1995 地雷的模式：**一次足夠上鏡的誤擊=條約的政治燃料**。
- 談判的核心變數不是技術（技術已成熟），是**核驗**：如何證明「人在迴路」不是紙面宣告？——與化武公約同構：**無核查的禁令等於沒有禁令**。

### 第二步：人的否決層條約（法律⇒軍事）

- 條約核心義務：殺傷決策鏈上**至少一個可追溯的人類確認**（簽章式：目標清單由人授權、武器的執行日誌密碼學封存、誤擊可回放）。
- 「防區外」定義：目標獲取可自主、**開火不可自主**——把自主性的刀口停在扳機前。
- 出口管制：蜂群 AI 的「目標辨識模型」列入兩用清單——與晶片管制同構（見 [a5-台海封鎖](a5-台海封鎖) 的技術封鎖邏輯）。

### 第三步：威懾的重新定價（軍事⇒地緣）

- 大國簽約但保留「例外條款」（自衛、對手違約即失效）——條約成為**可預期性的裝置**：至少所有人都知道「開火需人確認」是常態，誤判的解釋空間縮小。
- 非國家行為者的漏洞：FPV 的零件全是消費級——條約管得住國家，管不住地下改裝；**低烈度戰爭的民主化不受條約約束**（見 a6/b2）。
- 核指揮的紅線：條約明文禁止核武的自主交戰授權——把 [a6/b3-核指揮的AI化](a6-戰爭形態的重寫) 的最壞情境提前立法封死。

## 分岔 -- 每一步的「若…否則…」

| 環節 | 若 | 否則 |
|------|-----|------|
| 核查機制 | 執行日誌封存+第三方抽檢→可信 | 只靠自報→紙面合規氾濫 |
| 大國參與 | 美中俄都簽→規範成為均勢語言 | 一家拒簽→先動手者的單邊優勢誘惑 |
| 條款範圍 | 含核紅線 | 核指揮留白→AI 誤判直通末日按鈕 |

## 整個世界的變化

| 領域 | 變化 |
|------|------|
| 軍事 | 「有人確認」成為武器的合規規格；採購書新增條款 |
| 法律 | 殺傷責任鏈（指揮官→工程師→政府）進入國際刑法 |
| 產業 | 民用無人機的目標辨識模組被列管；消費市場與軍用市場分流 |
| 外交 | 仿化武/地雷的「規範競賽」：誰不簽誰承擔道義成本 |
| 戰場 | 低烈度衝突繼續無人機化，但大國戰爭保留人的扳機 |

## 觀察指標

- CCW 或後續公約對「人類確認」的操作性定義（是否可核查）。
- 主要武器出口國的採購規格是否寫入否決層。
- 誤擊事件的回放證據是否被公開與追責。
- 非國家行為者使用自主武器的案件數（條約盲區的體溫計）。

## 不確定性

- 蜂群戰術的時效優勢（毫秒級）與「人的否決」在物理上衝突——高強度戰爭中條約可能被「防禦例外」掏空。
- 對等簽約國之間的核查需要互信基礎設施，而地緣對抗正在拆除此類基礎。

**結論：** 本案的推演邏輯與 1915 毒氣案同構：**技術先跑、醜聞立法、規範靠核查與道義成本維持**。自主武器的條約化擋不住低烈度戰場的民主化，但可能守住兩條底線——大國戰爭保留人的扳機、核指揮永遠有人否決。**條約管不住所有槍，但能管住最後一支按鈕。**
