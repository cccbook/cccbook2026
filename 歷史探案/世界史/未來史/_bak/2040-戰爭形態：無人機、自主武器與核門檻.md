# 2040-戰爭形態：無人機、自主武器與核門檻

> 通道：戰爭⇒科技⇒法律（暴力成本→零的政治後果——[武器與戰法/2022-俄烏戰爭與FPV無人機] 的成本交換比規律的延伸；核軍控（[武器與戰法/1962]）的 AI 版考驗）

## 案件摘要

2022–25 的烏俄戰爭完成無人機革命：FPV 量產、透明戰場、電子戰週期賽。本篇推演 2040 的戰爭形態分歧：**自主武器的擴散常態化、「AI+核」的新裁軍架構、還是機器人戰爭的先例？**——核心風險是「**暴力成本→零→衝突門檻下降**」的結構。

## 前因 -- 現況與線索

- **無人機現況**：FPV 年產百萬、光纖免疫干擾、AI 末端制導——「便宜量產+迭代」的戰爭軟體化（[武器與戰法/2022]）。
- **自主現況**：自主武器的倫理與條約討論（LAWS）停滯；軍用 AI 的目標獲取已實戰。
- **核現況**：三位一體現代化＋高超音速——核秩序老化；軍控條約真空（新 START 後無條約）。
- **歷史先驗**：**新武器在舊戰法裡失敗、在新戰法裡制勝**（[武器與戰法/1884-馬克沁機槍] 的認知滯後）；**軍控三條件**（查證+均衡+教訓，[武器與戰法/1962]）；**禁忌的失效條件**（非國家行為者使報復不可信，[武器與戰法/1943]）。

## 線索與推理 -- 理論

### 理論一：衝突門檻的算式

$$\text{衝突意願} \propto \frac{\text{預期收益}}{\text{（傷亡成本）} + \text{（法律與形象成本）}}$$

自主武器使「傷亡成本」→己方零、形象成本下降——**衝突門檻的歷史性下降**——與 [1915-毒氣戰](../世界史/1915-毒氣戰.md) 的「禁忌」結構相反：低成本可能**提高**使用率（禁忌的失效）。

### 理論二：AI 誤判與核門檻

核指揮體系的 AI 化（預警與決策）——「AI 誤判→核門檻」的風險結構：

$$\text{核風險} \propto \text{（AI 參與決策的比例）} \times \frac{1}{\text{（人的否決層）}}$$

與 [武器與戰法/1962] 的「潛艇指揮官授權過大」同構——**授權與否決的設計是核安全的新戰場**。

### 理論三：兵源稀缺與軍事自動化

少子化（[2027]）使兵源腰斬——**兵源的價格上升使機器的相對價格下降**（與 [1769-瓦特蒸汽機與工業革命](../世界史/1769-瓦特蒸汽機與工業革命.md) 的「以煤換人力」同一算式：**少子化是軍事自動化的補貼**）。

## 推演 -- 情境樹

```
2040 現況（自主武器擴散＋核秩序老化）
  └─ 分歧點 ──┬─ G1 擴散常態化（無人機+機器人+AI 的量產戰爭）
              ├─ G2 新裁軍架構（AI+核的穩定性條約）
              └─ G3 機器人戰爭先例（自主系統對決）
```

| 分支 | 觸發條件 |
|------|----------|
| G1 擴散常態化 | 便宜量產邏輯延續（成本交換比 1:1000 的時代） |
| G2 新裁軍架構 | 一次「AI 誤判」的危機教訓＋查證（攻擊性自主武器的算力登記） |
| G3 機器人戰爭 | 兩強的自主系統直接對決（人員傷亡極小→門檻下降） |

## 分支的後果

- **G1**：便宜量產對昂貴平台的體系性勝利深化（坦克與大型艦的黃昏）；「作坊式戰爭」擴散——非國家行為者能力上升（與 [武器與戰法/1943] 的禁忌失效同構）。
- **G2**：「AI+核」的穩定性條約（人的否決層制度化）——需要罕見的政治條件（[1962] 先驗：三條件齊備）。
- **G3**：衝突門檻下降的先例——「無人戰爭」的政治容忍度↑——**戰爭的「去人性」改變政治的約束**；治理緊迫性上升（→[2046] 的法律真空）。
