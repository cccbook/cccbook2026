# 2031-能源轉型的三條路

> 通道：科技⇒經濟⇒地緣（能源是經濟的底層——[1769-瓦特蒸汽機與工業革命](../世界史/1769-瓦特蒸汽機與工業革命.md) 的「能源革命=文明分界」規律的當代版）

## 案件摘要

2025–26 年，太陽能與電池成本曲線持續斷崖、AI 資料中心用電需求暴增、核能（含 SMR）投資升溫。本篇推演分歧：**電力充足、電網瓶頸、還是核復興？**——本篇的分岔決定 2030s 的工業與算力佈局。

## 前因 -- 現況與線索

- **成本現況**：太陽能 LCOE 十年下降約九成、電池七成——發電端已平價。
- **瓶頸現況**：電網（傳輸、變壓器、許可）成為新瓶頸——併網等待以年計。
- **需求現況**：AI 資料中心用電以雙位數年增——過去十年的「效率紅利」被需求反彈抵銷。
- **歷史先驗**：**能源轉換的天花板被「新的能量轉換方式」打破**（[武器與戰法/1939-噴射機的誕生] 的推進規律）；**基礎設施轉換要一個世代**（[1830-鐵路與電報](../世界史/1830-鐵路與電報.md)）。

## 線索與推理 -- 理論

### 理論一：Jevons 悖論

效率提升→使用成本下降→**需求反增**：

$$\text{總消耗} \uparrow \quad \text{（即使單位效率} \uparrow\text{）}$$

AI 用電是當代驗證：演算法效率提升反而使總算力需求暴增——**「能源充足」在需求彈性面前是暫態**。

### 理論二：瓶頸的轉移

發電已平價→瓶頸轉移到「電網與許可」——**制度延遲成為最大瓶頸**：

$$\text{轉型速度} = \min(\text{技術速度}, \text{制度速度}) \quad \text{（制度慢於技術）}$$

與 [1450-古騰堡印刷革命](../世界史/1450-古騰堡印刷革命.md) 的「管制跟不上傳播」同構——**法律的滯後律**（[2046-法律體系的分岔] 的先驗）。

### 理論三：能源=地緣權力的重排

油→電的地緣重排：產油國的槓桿侵蝕、電力與關鍵礦物（鋰、銅、稀土）的新槓桿——**「誰控制能源供應鏈，誰控制地緣」**（與 [武器與戰法/-3000] 的錫貿易同構）。

## 推演 -- 情境樹

```
2031 現況（發電平價＋電網瓶頸＋AI 用電）
  └─ 分歧點 ──┬─ O1 電力充足（儲能+需求管理）
              ├─ O2 電網瓶頸（制度與許可拖慢）
              └─ O3 核復興／化石延壽（AI 用電的化石回頭）
```

| 分支 | 觸發條件 |
|------|----------|
| O1 電力充足 | 儲能成本持續降＋電網數位化＋需求側管理 |
| O2 電網瓶頸 | 許可與設備短缺持續——「有電併不上網」 |
| O3 核復興 | SMR 量產成功＋資料中心直接購電＋化石延壽容忍 |

## 分支的後果

- **O1**：電力密集產業依「電價套利」重新佈局（與 [1769] 的「煤價決定產業佈局」同構）；產油國地緣槓桿侵蝕；**A3（AI 瓶頸）的能源面解除**。
- **O2**：轉型放緩→化石延壽→**E2（現行軌道）強化**；AI 成長受電力約束（A3）。
- **O3**：SMR 的「工廠化」；化石延壽與氣候軌道的張力（E2/E3 強化）；核能地緣（鈾、燃料棒）重排。
