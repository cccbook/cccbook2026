# 1405 鄭和下西洋：國家資本的海上遠征與退場

## 案發現場

1405 年，鄭和率 200 餘艘寶船、2.7 萬人首下西洋，此後 28 年七度遠航，最遠抵東非。然後——1433 年之後戛然而止，檔案散失，海禁收緊。一個能造出世界最大木船的國家，為何主動退出海洋？

> **七次遠征的帳本是賺是賠？國家壟斷海洋 vs 特許公司下海——鄭和與達伽馬走了兩條什麼樣的路？**

## 偵查過程

**線索一：朝貢貿易的會計學（政治收益>經濟收益）。** 鄭和船隊滿載絲綢瓷器出海，帶回長頸鹿、香料與「萬國來朝」的威望。偵查結論：這筆帳**政治上大賺、財政上虧損**——朝貢體系講究「厚往薄來」（賞賜價值高於貢品），每次遠征都是國庫補貼的面子工程。與葡萄牙的特許公司模式對照（參見 [../世界發展史/1492-哥倫布大交換.md](../世界發展史/1492-哥倫布大交換.md)）：**達伽馬為利潤下海，鄭和為威望下海**——前者可持續（利潤再投資），後者依賴皇帝的個人意志。

**線索二：寶船的技術（被凍結的知識）。** 鄭和寶船長逾百米、水密隔艙、導航用牽星術——當時世界頂級造船技術。偵查結論：技術本身不是問題，問題是**技術的載體**——知識存在工匠與檔案裡，停航+銷毀檔案=知識斷代。歐洲把航海知識寫進公司章程與海圖（可累積、可交易）；明朝把知識綁在皇權項目上（人亡政息）。**技術的壽命=載體的壽命**。

**線索三：機會成本（艦隊經費 vs 北方邊防）。** 永樂同時五征漠北、營建北京、修《永樂大典》——國庫多線作戰。仁宣之後，文官集團主張「海禁省費、專注北邊」，停航派勝出。偵查結論：退場不是「愚昧」，是**預算約束下的理性選擇**——北方遊牧威脅是生存問題，遠洋威望是奢侈品。當財政收緊，奢侈品先被砍掉。**戰略收縮的邏輯永遠是：先保生存，再談面子**。

**線索四：退場的後果（真空由歐洲填補）。** 官方退出後，私人海商（走私）填補需求——海禁下的走私武裝化（參見本書 [1368-朱元璋與明朝.md](1368-朱元璋與明朝.md)）；一個世紀後葡萄牙人抵達（1513 到達廣東），**東亞海域的遊戲規則改由歐洲制定**。偵查結論：退場的代價不是省下的軍費，是**制海權的定價權**——此後三百年，中國在海上從規則制定者變成規則接受者，直到黑船與鴉片戰爭（參見本書 [1839-鴉片戰爭.md](1839-鴉片戰爭.md)、[1853-黑船來航.md](1853-黑船來航.md)）。

## 結案報告

1. **兩種下海模式**：國家威望型（鄭和）vs 公司利潤型（達伽馬）——**動機決定可持續性**，利潤比威望活得久。
2. **知識載體論**：寶船技術隨項目終結而斷代——技術必須綁在可累積的載體（公司、海圖、學校）上，而非綁在人治項目上。
3. **理性的收縮**：停航是預算約束下的選擇——但**省下的錢買不回失去的海洋定價權**。
4. **三百年迴響**：中國退出→歐洲接管→條約體系反噬——鄭和的退場是鴉片戰爭的前傳，兩者相隔四百年，邏輯同一條。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 遠征工程 | 跨域效應 |
|------|----------|----------|
| 法律 | 海禁、朝貢體制 | 私人海貿非法化 |
| 經濟 | 厚往薄來的補貼貿易 | 國庫失血、走私補位 |
| 科技 | 寶船、水密隔艙、牽星術 | 技術隨停航斷代 |
| 政治 | 萬國來朝的威望 | 文官停航派勝出 |
| 文化 | 長頸鹿（麒麟）、伊斯蘭網絡 | 海洋想像曇花一現 |

**鄭和 vs 達伽馬（下海模式對照）：**

| 項目 | 鄭和（1405–1433） | 達伽馬（1498 起） |
|------|------------------|-------------------|
| 出資 | 國庫（皇帝意志） | 王室+商人合股 |
| 動機 | 威望、朝貢 | 利潤、香料 |
| 會計 | 政治賺、財政賠 | 利潤再投資 |
| 知識載體 | 工匠+檔案（可銷毀） | 公司+海图（可累積） |
| 結局 | 人亡政息 | 公司帝國 |

**退場連鎖（示意）：**

```
停航 → 檔案散失 → 技術斷代 → 私人走私補位 → 海禁緝私
  └──> 歐洲接管海域 → 定價權易手 → 四百年後條約體系反噬
```

**結論：** 鄭和案是「國家資本下海」的完整實驗：規模空前、動機威望、載體人治——退場理性而必然。**誰為海洋定價，誰就為未來定價**——把海洋讓出去的國家，終將在別人的規則裡付學費。
