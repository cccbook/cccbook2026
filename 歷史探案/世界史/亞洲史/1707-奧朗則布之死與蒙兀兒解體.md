# 1707 奧朗則布之死：帝國被信仰撐爆

## 案件摘要

1707 年，蒙兀兒皇帝奧朗則布死於南征途中（享年 88、在位 49 年）——**印度最大帝國由盛轉衰的拐點**。此前：巴布爾火炮建國（參見 [1526-蒙兀兒帝國.md](1526-蒙兀兒帝國.md)）；此後：1757 普拉西（參見 [1757-普拉西之戰.md](1757-普拉西之戰.md)）一家公司就敢挑戰皇帝，病根全在此五十年。這樁案件要回答：**最勤政的皇帝，為何親手拆了帝國？**

## 前因 -- 多因素的局勢

- **版圖**：帝國極盛（南抵坦賈武爾、人口約 1.5 億、財政占世界 GDP 近四分之一）——**大到管不動**。
- **信仰**：奧朗則布恢復人頭稅（吉茲亞 1679）、拆廟、禁音樂節慶——**從阿克巴的寬容轉向伊斯蘭正統**。
- **馬拉塔**：希瓦吉游擊（1674 稱王）——**打不死的山地耗材**。
- **錫克**：第九代古魯被處死（1675）→第十代建卡爾薩武裝——**又樹一敵**。

## 線索與推理 -- 因素咬合

### 線索一：德干泥潭——「二十六年御駕親征」

1681–1707 奧朗則布坐鎮德干、滅比賈普爾與戈爾康達，卻陷入馬拉塔游擊：

$$\text{帝國損耗} = \text{（德干駐軍成本）} \times \text{（游擊戰時間）} - \text{（新征服稅收）} < 0$$

打下的都是負資產。皇帝離開德里二十六年——**首都空轉、北印度離心**。

### 線索二：寬容的逆轉——「曼薩布達里的離心」

| 阿克巴體制 | 奧朗則布改動 | 後果 |
|---|---|---|
| 拉其普特聯姻＋高官 | 疏遠拉其普特、用人唯教 | 戰將集團離心 |
| 宗教寬容（Din-i-Ilahi） | 吉茲亞＋拆廟 | 印度教精英叛離 |
| 扎吉爾輪換制 | 軍費膨脹、封地不夠分 | 曼薩布達爾內捲搶奪 |

$$\text{統治同盟} = \text{（穆斯林官僚）} + \text{（印度教武人} \downarrow\text{）} \Rightarrow \text{多數人變敵人}$$

### 線索三：繼承詛咒——「每代用戰爭選太子」

無嫡長制（兄弟自相殘殺：奧朗則布自己就殺兄囚父）——1707 死後三子立即開戰，1719 一年三帝。學術理論：達龍·阿傑莫魯「榨取型制度」——**包稅＋曼薩布＋無繼承規則的三重榨取**，盛世即末世的起點。

## 破案時刻

- 1679：恢復吉茲亞——統治同盟破裂的公開宣告。
- 1681–1707：德干親征——帝國心臟停在南方的二十六年。
- 1707：奧朗則布死（遺囑自承「罪孽深重」）——拐點。
- 1739：納迪爾沙洗劫德里（孔雀寶座被搬走）——**帝國破產的驗屍報告**。
- 1757：普拉西——公司來收屍。

## 後果 -- 改變了什麼

- **印度**：馬拉塔、錫克、海德拉巴、孟加拉實質獨立——**普拉西時英國面對的是碎片，不是帝國**。
- **財政**：曼薩布—扎吉爾體系崩解→包稅層層轉包（→鄂圖曼包稅（參見 [1582-奧斯曼包稅制.md](1582-奧斯曼包稅制.md)）的印度版）。
- **宗教**：印度教—穆斯林對立制度化——**1947 分治（參見 [1947-印巴分治.md](1947-印巴分治.md)）的遠因之一**。
- **公司**：東印度公司從貿易商變包稅人（→1765 迪瓦尼）——**普拉西敢動手的底氣**。

## 因素影響筆記

```
極盛版圖（大！）×正統轉向（窄！）──→ 同盟破裂
德干泥潭（耗！）×扎吉爾不夠分（搶！）──→ 財政空轉
兄弟相殺（繼承！）──→ 一年三帝──→ 普拉西（1757！）
```

**偵探結語**：奧朗則布案是「勤政亡國案」：**每天工作十小時、親自批閱奏章的皇帝，用四十九年把帝國批倒閉**——版圖越大、同盟越小，打仗越多、稅收越少。遺囑裡他說「我兩手空空而來，仍將兩手空空而去」——**偵探補一句：他帶走的不只是自己，還有帝國的統治公式**。普拉西的那家公司，不過是來撿他掉在地上的印章。
