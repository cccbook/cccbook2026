# 1905 日俄戰爭：亞洲首次打贏歐洲強權

## 案發現場

1904–05 年，日俄為爭奪朝鮮與滿洲開戰。對馬海峽，東鄉平八郎率聯合艦隊全殲俄波羅的海艦隊；奉天會戰日軍慘勝。樸資茅斯條約：俄國承認日本在朝鮮的優勢、割南庫頁島。**有色人種國家第一次在現代戰爭中打敗歐洲列強**——全世界都聽見了這聲炮響。

> **小國日本如何打贏龐然大物俄國？一場發生在滿洲的戰爭，為何同時引爆了俄國革命與亞洲民族主義？**

## 偵查過程

**線索一：情報與集中（以小搏大的數學）。** 俄國艦隊分駐歐亞兩端，日本以內線優勢各個擊破——對馬海戰前，日本破譯俄艦航線情報，堵住必經之海峽。偵查結論：勝利公式是**局部優勢壓倒全局劣勢**——

```
全局：俄國體量 >> 日本
對馬時刻：聯合艦隊（集中）vs 第二太平洋艦隊（遠航疲憊＋分散）
局部：日本 > 俄國 → 殲滅戰
```

後勤線的長度決定戰力：俄艦繞行半個地球，抵達時已是強弩之末。尼布楚的「後勤等高線」邏輯（參見本書 [1689-尼布楚條約.md](1689-尼布楚條約.md)）在此重演——**遠征的終點是戰力的谷底**。

**線索二：戰爭債（金融實力的證據）。** 高橋是清兩度赴倫敦發行外債，籌得巨款支撐戰費。偵查結論：能借到錢=信用=國力——國際資本市場願意押注日本，本身就是**對明治財政（地稅改革+金本位預期）的投票**。對照甲午賠款（參見本書 [1894-甲午戰爭.md](1894-甲午戰爭.md)）：甲午日本靠賠款致富，日俄日本靠信用融資——**從賠款依賴到信用融資，是財政現代化的升級**。但外債也掏空國庫，樸資茅斯無賠款引發東京暴動（日比谷騷動）——**贏了戰爭、輸了預期**。

**線索三：俄國 1905 革命（戰敗的外溢）。** 戰敗+傷亡+饑荒→彼得堡「血腥星期日」→全國總罷工→十月宣言立憲。偵查結論：對馬的炮彈炸沉的不只是俄艦，還有**沙皇的合法性**——戰敗證明專制無能，革命者拿到最好的宣傳。日本無意輸出革命，但**戰敗是專制政權最危險的時刻**（清朝甲午後亦然）——此後每個帝國都記住了這條公式。

**線索四：黃禍論與亞洲鼓舞（認知的兩面）。** 西方驚呼「黃禍」——種族優越敘事破裂，轉而恐懼；亞洲（中國革命者、印度國大黨、越南志士）則歡呼——**被殖民者第一次看見殖民者可被打敗**。孫中山、尼赫魯都記載此戰的鼓舞。偵查結論：日俄戰爭是**去殖民化的心理起點**——不是槍炮的勝利，是「可能性的證明」。但硬幣另一面：日本隨即併吞韓國（1910）、經營滿鐵——**反殖民的英雄轉身成為殖民者**，亞洲主義的承諾與帝國的現實從此撕裂。

## 結案報告

1. **局部優勢公式**：內線集中+情報+敵方遠征疲憊——小國勝大國的數學只有一種：把決戰安排在對自己最有利的時空。
2. **信用即戰力**：倫敦戰爭債=財政現代化的驗收——借得到錢的國家才打得起現代戰爭。
3. **戰敗傳染革命**：對馬→血腥星期日→俄國立憲——專制政權的合法性在戰敗時刻最脆弱。
4. **鼓舞與背叛**：亞洲民族主義的心理起點，也是日本帝國主義的起點——**英雄與殖民者可以是同一個國家的兩面**。

**勝利公式（示意）：**

```
勝利 ＝ 局部兵力優勢 × 情報 × 敵後勤衰減 ÷ 本國財政可持續性
對馬：集中 ＋ 航線破譯 ＋ 俄艦繞地球疲憊 ＋ 倫敦債券 ＝ 殲滅戰。
```

**結論：** 日俄案是「小勝大」的標準作業：情報選定戰場、集中製造局部優勢、信用支撐持久、敵人的後勤替你消耗敵人。**但每場勝利都有兩個帳本——戰場的殲滅，與政治的外溢**：俄國收穫革命，亞洲收穫希望，韓國收穫併吞——同一場戰爭，三種結局。
