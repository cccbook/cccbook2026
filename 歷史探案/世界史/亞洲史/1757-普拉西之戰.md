# 1757 普拉西之戰：一家公司如何征服一個帝國

## 案發現場

1757 年 6 月 23 日，英國東印度公司職員克萊武率 3,000 人，在普拉西擊敗孟加拉納瓦布 5 萬大軍。關鍵不是戰術——納瓦布的主將米爾·賈法爾事先已被收買，按兵不動。戰後公司取得孟加拉稅收包辦權（1765 年 diwani），一家貿易公司變成了印度的主人。

> **三千人如何打敗五萬人？當戰爭可以用賄賂結算，公司的資產負債表如何變成帝國的稅基？**

## 偵查過程

**線索一：賄賂戰（收買比開炮便宜）。** 克萊武事先與賈法爾密約：倒戈即扶為納瓦布，並許以巨款。偵查結論：這場「戰役」的真正成本是**賄賂金**，不是軍費——

```
正規戰爭成本 = 軍隊 × 時間 × 傷亡風險（高且不確定）
收買成本 = 一筆固定賄金（低且確定）
理性選擇：能買就不打。
```

公司把戰爭變成了**併購交易**——納瓦布政權被「惡意收購」，賈法爾是內應董事。這是金融戰的原型：**資本可以直接購買戰爭的結果**。

**線索二：公司軍隊（外包戰爭的商業模式）。** 東印度公司養著歐式訓練的印度兵（sepoy）——軍費來自貿易利潤，戰利品與賠款再投入擴軍。偵查結論：這是一台**戰爭盈利機器**：貿易利潤→雇軍隊→勒索賠款→更多利潤。與國家軍隊不同，公司軍隊必須**自負盈虧**——每一場戰爭都要算 ROI。普拉西的 ROI 極高（賄金換一個省的稅收），於是擴張自我強化。可連結 [../世界發展史/1602-東印度公司.md](../世界發展史/1602-東印度公司.md) 的特許公司邏輯——**有限責任+股份制讓戰爭風險可分攤、可持續**。

**線索三：蒙兀兒的權力真空。** 奧朗則布死後（1707）帝國分裂，孟加拉納瓦布實質獨立、馬拉塔崛起。偵查結論：公司不是打敗了一個強大帝國，是**在一個碎裂的棋盤上逐子收割**——先收買分裂勢力，再各個吞併。對照曼陀羅理論（參見本書 [-0321-孔雀帝國.md](-0321-孔雀帝國.md)）：克萊武玩的正是「鄰國的敵人是朋友」——**帝國的碎片是征服者的槓桿**。

**線索四：榨取型制度的起點。** 取得 diwani 後，公司把孟加拉稅收最大化——稅率飆升、紡織業被壓價收購，1770 年大饑荒餓死千萬人。偵查結論：公司的治理目標是**股東分紅**，不是民生——榨取到饑荒也不停手，因為董事會在倫敦，看不見災民。這是「榨取型制度」的完整示範（參見 [../世界發展史/1884-柏林會議.md](../世界發展史/1884-柏林會議.md) 的有效占領邏輯）：**當統治者的收益與被統治者的福利脫鉤，災難只是財報上的外部性**。最終英國政府被迫接管（參見本書 [1858-英屬印度.md](1858-英屬印度.md)）——公司證明了自己會賺錢，也證明了自己不會治理。

## 結案報告

1. **戰爭的金融化**：普拉西證明資本可直接購買政權——賄賂是成本最低的武器，併購是最便宜的征服。
2. **公司戰爭機器**：貿易利潤→軍隊→賠款→擴張——自負盈虧的軍隊必然擴張，因為停戰等於虧損。
3. **碎片即槓桿**：蒙兀兒分裂給了公司逐個收買的機會——**帝國死於分裂，公司生於分裂**。
4. **榨取的終點**：diwani→重稅→大饑荒→政府接管——股東利益與民生脫鉤的統治註定崩潰，為 1857 大起義埋下火種。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 公司工程 | 跨域效應 |
|------|----------|----------|
| 法律 | diwani 稅收包辦 | 公司變相主權者 |
| 經濟 | 賄賂併購、重稅榨取 | 孟加拉財富外流、饑荒 |
| 科技 | 歐式操練 sepoy、火炮 | 少量精兵勝大量舊軍 |
| 政治 | 收買分裂勢力 | 蒙兀兒碎片逐個吞併 |
| 文化 | 倫敦董事會遠距統治 | 災難在財報上不可見 |

**國家征服 vs 公司征服（對照）：**

| 項目 | 國家（如蒙兀兒） | 公司（東印度） |
|------|------------------|----------------|
| 動機 | 領土、威望、稅收 | 股東分紅 |
| 戰爭會計 | 國庫負擔 | ROI 計算 |
| 風險分攤 | 王室承擔 | 股東分攤 |
| 治理目標 | 王朝延續 | 分紅最大化 |
| 失控後果 | 改朝換代 | 大饑荒→政府接管 |

**擴張飛輪（示意）：**

```
貿易利潤 → 雇 sepoy → 賄賂＋威脅 → 割地賠款 → 更多稅收
    ↑                                                │
    └────────── 再投入擴軍（停戰＝虧損）──────────────┘
```

**結論：** 普拉西案是「公司征服帝國」的原型事件：用賄賂結算戰爭，用財報驅動擴張，用分紅代替治理。**當戰爭有了 ROI，征服就停不下來；當統治者遠在倫敦，饑荒就只是外部性**——這條邏輯從孟加拉一路走到 1857，直到帝國親自接手爛攤子。
