# 1842 三合會與苦力貿易：黑幫即人力仲介

## 案發現場

1842 年南京條約後，五口通商，西方在華南招募「苦力」（契約華工）赴美洲、東南亞、澳洲——豬仔館（澳門、汕頭、廈門）、三合會（天地會）組織拐賣、苦力船死亡率高企，1872 年「瑪耶西」號事件（日本橫濱扣船，國際仲裁釋放苦力）。數十年間逾百萬華工出洋。黑幫為何成了跨國人力仲介？

> **拐賣何以產業化？三合會、豬仔館、洋行——苦力貿易的鏈條上，誰賺最多，誰死最多？**

## 偵查過程

**線索一：豬仔館的產業鏈（拐賣的標準化）。** 招募（誘騙：去金山挖金）→豬仔館（關押，等船）→驗身（脫衣檢查，如牲口）→簽約（畫押，不識字）→裝船（底艙，死亡率高）→拍賣（古巴、秘魯種植園）。偵查結論：這是**人口販賣的工業化**：三合會（地盤加打手）負責「貨源」（拐、騙、買），洋行負責運輸銷售，種植園主負責「使用」。**分工明確的三方合資**：黑幫出暴力，洋行出資本，殖民者出需求（廢奴後缺勞力：英國 1833 年廢奴，古巴秘魯糖棉種植園要人）。**廢奴的替代品**：奴隸不合法了，苦力（契約，名義自願）來補——**名義自由，實質奴隸**（八年約，逃跑按逃犯論）。法律的文字遊戲：**廢的是「奴隸」二字，不是強迫勞動**。

**線索二：三合會的轉型（反清變人口販子）。** 天地會原是反清復明秘密會黨，鴉片戰爭後部分堂口轉向拐賣。偵查結論：這是**黑幫的商業化轉型**：革命不賺錢（起義要貼錢），拐賣賺錢（一個豬仔數十元）——**理想讓位給利潤**。組織優勢（秘密、暴力、地盤）無縫轉換：反清時對付官府，拐賣時對付苦力——**暴力是通用資產**，用在哪都賺。與禁酒黑幫（參見 [../世界發展史/1929-禁酒令與黑幫.md](../世界發展史/1929-禁酒令與黑幫.md)）同構：**黑幫的本質是暴力企業**，產品可以是酒、是人、是毒——市場要什麼，賣什麼。三合會的招牌（反清）成了掩護——**革命傳統是最好的犯罪品牌**：義氣掩護拐賣。

**線索三：瑪耶西號事件（國際司法的介入）。** 1872 年，載秘魯苦力的「瑪耶西」號停靠橫濱，苦力逃上岸求救，日本扣船，國際仲裁（俄皇裁決：苦力獲釋，契約無效）。偵查結論：這是**人權外交的早期案例**：日本（明治初年）藉此展示「文明國」（廢除苦力等於加入國際法俱樂部，參見 [本書 1868 篇](1868-明治維新.md)）——**救苦力，賺名聲**。事件後，清政府派陳蘭彬調查（1873，赴古巴），李鴻章交涉，1874 年續增專條禁拐——**晚清第一次領事保護**（朝廷雖弱，開始管海外子民）。苦力貿易 1870 年代後漸息（替代：印度勞工、日本契約工、中國自費移民）——**國際壓力加成本上升等於產業終結**。拐賣的終結不是道德勝利，是**風險溢價吃掉利潤**。

**線索四：華僑的源頭（苦難的另一面）。** 百萬苦力中，部分期滿留居（秘魯、古巴、美國排華前）、部分攢錢回鄉（僑匯：潮汕、福建僑鄉蓋樓辦學）。偵查結論：這是**華僑史的黑暗序章**：今日唐人街（利馬、哈瓦那、舊金山）的祖輩，多是豬仔館出來的——**苦難是移民的啟動資金**（啟動資金：命一條）。僑匯（19 世紀末潮汕僑匯佔比極高，一說）回流建祠堂學校——**被賣者的錢，蓋了家鄉的樓**。與印度勞工（英國販印工到加勒比、斐濟）對照：**帝國缺勞力，全世界抓替**——廢奴（1833）後的全球勞工重組，華工印工日工輪番上場。苦力貿易的歷史地位：**奴隸制和自由移民之間的中間形態**——名義契約，實質販賣，過渡了五十年。

## 結案報告

1. **產業鏈定律**：黑幫出暴力、洋行出資本、殖民者出需求——三方合資賣人。
2. **轉型定律**：革命變拐賣——暴力是通用資產，市場要什麼賣什麼。
3. **仲裁定律**：瑪耶西號——救苦力賺名聲，風險溢價終結產業。
4. **序章定律**：苦難是移民啟動資金——唐人街的祖輩，僑鄉的樓。

**販賣公式（示意）：**

```
利潤 ＝ （拍賣價 − 收購拐騙成本 − 運輸死亡損耗）× 量。
廢奴（需求）加三合會（暴力）加洋行（資本）等於產業。
終結：仲裁風險上升 → 利潤下降 → 轉印度工。
```

**結論：** 苦力貿易案是「人口販賣產業化」的完整樣本：黑幫供貨、洋行運輸、殖民者收貨、國際仲裁收尾——百萬華工，十年豬仔館，一紙仲裁。**廢奴廢的是字，不是業**——業轉了個身（契約），繼續了五十年。三合會的招牌從反清變成賣人——招牌沒換，貨換了。唐人街的燈籠下，祖輩的契約還壓在箱底——自由的第一代，是被賣來的。
