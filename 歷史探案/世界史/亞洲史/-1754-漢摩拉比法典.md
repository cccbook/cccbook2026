# -1754 漢摩拉比法典：把法律刻上石柱的統治術

## 案發現場

約公元前 1754 年，巴比倫王漢摩拉比命人把 282 條法律刻在一根**玄武岩石柱**上，頂端雕著他從太陽神沙瑪什手中接受權杖的浮雕，立在神廟中供所有人閱讀。他面對的難題：**如何讓一個多民族、多城市的帝國相信——王的法律就是所有人的法律**。

> **為什麼要把法律公開刻在石頭上？法律公開與統治正當性之間，藏著什麼樣的資訊工程？**

## 偵查過程

**線索一：法不可知，則權不可預測。** 在此之前，法律多由祭司與貴族口耳相傳、個案裁決——**普通人無從預知自己行為的後果**，判決標準隨裁決者而變。漢摩拉比的解法是**公開化**：把法律寫下、刻上、立在公共場所。這是一場資訊革命——**規則從裁決者的私人知識，變成公共知識**。人人可讀，則人人可預測；可預測，則王權的裁決不再依賴每個法官的良心，而依賴一個**固定、可查、無法抵賴的文本**。石柱本身就是「不可篡改的資料庫」。

**線索二：同態復仇的威懾經濟學。** 法典最著名的是「以眼還眼，以牙還牙」。表面殘忍，實為**威懾的定價公式**——把傷害的價格牌示出來：

```
期望懲罰成本 = 被查獲機率 × 懲罰强度
若 P(查獲)=0.3，則懲罰需≈3.3 倍傷害才等值——
同態復仇把「懲罰=傷害」寫成明碼，配合高查獲率（社區證人），嚇退暴力。
```

偵查補充：法典其實**分階層定價**——傷害自由人賠銀、傷害奴隸賠給主人；同態復仇僅適用同等身分之間。這不是粗糙的報仇，而是**用身分等級給人身定價**的精細系統。

**線索三：契約與證人（降低交易成本）。** 法典大量條文規範商業：借貸利率上限、租傭傭金、合夥分帳、寄賣責任。其共同邏輯：**交易要有憑證**——契約需書面、需證人在場、需官方蓋章。偵查結論：這是在降低**交易成本**——沒有憑證，糾紛無法查證，信任半徑只能限於親屬；有了契約+證人制度，陌生人間的大宗貿易（兩河流域的長途商隊）才有可能。法律是**商業的基礎設施**。

**線索四：阿卡德語言市場。** 法典不用蘇美語，而用**阿卡德語（巴比倫語）**——當時近東的「通用語」。這是一個語言選擇問題：**法律要讓最多人讀懂，就必須用市場上流通的語言**。蘇美語是祭司與古文書的語言，阿卡德語是商人與庶民的語言。王選擇了讀者最多的那個——**公開的法律必須搭配通用語，公開才有意義**。此舉也反過來鞏固了阿卡德語作為近東國際溝通媒介的地位（埃及阿瑪納書信仍以阿卡德語書寫）。

**線索五：王權與神意的廣告。** 石柱頂端的浮雕是本案的「商標」——漢摩拉比從沙瑪什（正義之神）手中受權。這是**正當性的視覺宣告**：法律不是王的私意，是神意的轉譯，王只是「公道的守護者」。結案線索：把法律與神綁定，等於**把執法成本外包給信仰**——違反神授之法，不只是犯法，是瀆神。一柱、一浮雕、一通用語，構成完整的統治傳播工程。

## 結案報告

1. **法律的公開化革命**：成文+公開+通用語——規則從裁決者的私人知識變成公共知識，是「法可預測」的最早工程；此後近東法律傳統（赫梯法典、亞述法典）皆循此模式。
2. **威懾的定價系統**：同態復仇不是野蠻，是把傷害明碼標價的威懾經濟學；但以身分定價，也把不平等寫進了法律。
3. **契約制度=商業基礎設施**：契約+證人+利率上限，讓陌生人貿易成為可能——法律先於貨幣成為市場的黏著劑。
4. **影響後世**：法典的結構（條文+序言+神授意象）與若干條文，被認為影響了《舊約》律法（如出埃及記中的以眼還眼）——近東法律傳統經此一柱，流入猶太教與基督教文明。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 事件工程 | 跨域效應 |
|------|----------|----------|
| 法律 | 282 條成文法公開刻石 | 規則可預測、判決有據可查 |
| 經濟 | 契約/證人/利率上限 | 交易成本下降、長途貿易興起 |
| 科技 | 玄武岩雕刻（耐久媒材） | 「不可篡改」的資訊載體 |
| 政治 | 神授浮雕、王為守護者 | 執法成本外包給信仰 |
| 文化 | 阿卡德語書寫 | 通用語成為近東國際媒介 |

**口頭裁決 vs 成文法典（對照）：**

| 項目 | 口傳/個案裁決 | 刻石成文法典 |
|------|----------------|----------------|
| 可預測性 | 低（因人而異） | 高（明碼規則） |
| 篡改難度 | 易（隨口修改） | 難（刻在石上） |
| 讀者範圍 | 祭司貴族 | 公眾（通用語） |
| 正當性來源 | 裁決者身分 | 神授+公開文本 |

**公開法律的資訊迴路（示意）：**

```
王（神授權威）──立法──> 石柱（公共文本）──人人可讀──> 庶民可預測
   ↑                                                    │
   └──< 違法有明碼代價（威懾） <──────────────────────────┘
```

**結論：** 漢摩拉比案是「法律=公開資訊工程」的最早完整示範：文本（規則）、媒材（石）、語言（通用）、意象（神授）四件套，把裁決變成可預測的系統。**兩千年後秦的「書同文、以法為教」（[../世界發展史/-0221-秦統一.md](../世界發展史/-0221-秦統一.md)）重演了同一條偵查路線**——統治的正當性，始於讓被統治者看得見規則。
