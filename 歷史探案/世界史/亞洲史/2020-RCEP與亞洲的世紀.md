# 2020 RCEP：世界最大自貿區與亞洲的世紀

## 案發現場

2020 年 11 月，15 國簽署《區域全面經濟夥伴協定》（RCEP）——覆蓋 23 億人口、全球約三成 GDP，人類史上最大的自貿區。從張騫鑿空（參見本書 [-0126-張騫鑿空.md](-0126-張騫鑿空.md)）的駝鈴，到鄭和的寶船（參見本書 [1405-鄭和下西洋.md](1405-鄭和下西洋.md)），再到貨櫃與原產地規則——亞洲的貿易整合走了兩千多年，終於寫成一紙制度。

> **為何是亞洲、為何是現在？一紙自貿協定的真正威力——是關稅，還是藏在附錄裡的原產地規則？**

## 偵查過程

**線索一：亞洲世紀的數據（GDP 東移的長期曲線）。** 1960 年亞洲佔全球 GDP 約一成，2020 年約三分之一——日本起飛、四小龍、中國崛起、印度跟進的接力曲線。偵查結論：RCEP 不是原因，是**結果的制度化**——先有四十年的供應鏈整合（日本技術+四小龍資本+中國勞力+東協腹地），再有協定把既成事實寫成規則。**制度追認現實，而非創造現實**——與其說 RCEP 創造了亞洲世紀，不如說亞洲世紀生產了 RCEP。

**線索二：原產地規則（附錄裡的真正武器）。** RCEP 允許**累積原產地規則**——在任一成員國的加工都可累積計算，達標即享零關稅。偵查結論：這條技術細節決定供應鏈形態——

```
無累積：越南用中國零件出口日本 → 不算越南製 → 無優惠。
有累積：中越日同屬 RCEP → 零件價值累積 → 達標享零關稅。
```

結果：**供應鏈被鎖在區域內**——廠商為享優惠，優先在成員國間採購（中國+1 布局的加速器）。關稅減讓是門面，原產地規則是地基——**真正的貿易政治寫在附錄，不寫在標題**。

**線索三：供應鏈重組（中國+1 與腹地承接）。** 中美摩擦+疫情斷鏈後，廠商分散風險——越南、印度、印尼承接製造環節，但零件仍多來自中國。偵查結論：RCEP 恰好為這種「分散但相連」的布局提供制度外殼——**組裝在越南、零件在中國、市場在日韓**，全鏈條零關稅。脫鉤的噪音很大，整合的現實更大——**供應鏈用腳投票，投給了有規則的區域**。

**線索四：CPTPP 對照（市場准入 vs 規則整合）。** CPTPP（跨太平洋夥伴）標準更高（勞工、環保、國企條款），RCEP 更重市場准入、規則較淺。偵查結論：這是**兩種整合哲學**——CPTPP 是「價值觀俱樂部」（門檻高、成員少），RCEP 是「發展階段包容體」（門檻低、體量大，含柬緬寮）。亞洲選擇了先做大、再做深——**包容的廣度優先於規則的深度**，因為區域內發展落差太大。印度退出（2019）則暴露了包容的邊界——連 RCEP 的門檻，印度都擔心中國製造業衝擊。**整合的半徑=最弱成員的承受力**。

## 結案報告

1. **制度追認現實**：四十年供應鏈整合在前，協定在後——RCEP 是亞洲世紀的出生證明，不是助產士。
2. **附錄決定形態**：累積原產地規則把供應鏈鎖在區域內——貿易政治寫在技術細節裡。
3. **分散但相連**：中國+1 布局的最佳外殼——脫鉤是噪音，區域整合是現實。
4. **廣度優先哲學**：包容發展落差，先做大再做深——但印度退出標示了整合半徑的邊界。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 協定工程 | 跨域效應 |
|------|----------|----------|
| 法律 | 關稅減讓+累積原產地 | 供應鏈區域鎖定 |
| 經濟 | 三成 GDP 自貿區 | 供應鏈重組加速 |
| 科技 | 電子商務、海關數位化章節 | 數位貿易規則起步 |
| 政治 | 東協中心性、中日韓同框 | 區域秩序骨架 |
| 文化 | 人員流動、供應鏈人流 | 區域認同萌芽 |

**RCEP vs CPTPP（整合哲學對照）：**

| 項目 | RCEP | CPTPP |
|------|------|-------|
| 體量 | 三成 GDP、23 億人 | 較小 |
| 規則深度 | 淺（准入為主） | 深（勞工環保國企） |
| 包容性 | 含低度開發國家 | 高門檻俱樂部 |
| 哲學 | 先做大、再做深 | 先做對、再擴大 |
| 缺席者 | 印度退出 | 美國退出 |

**兩千年閉環（示意）：**

```
-0126 絲路（駝隊＋綠洲）：陸上商路。
1405 鄭和（寶船＋朝貢）：國家壟斷海洋。
2020 RCEP（貨櫃＋原產地規則）：制度整合供應鏈。
載體從駝鈴變成附錄，邏輯始終如一：降低交易成本者，得亞洲。
```

**結論：** RCEP 案是「亞洲兩千年貿易史」的制度終章：從駝隊到寶船到貨櫃，變的是載體，不變的是**降低交易成本的勝利**。協定的真正武器不在關稅數字，在附錄的累積規則——**誰定義原產地，誰就定義供應鏈**。絲路從地理變成法律，亞洲的世紀從預言變成條文。
