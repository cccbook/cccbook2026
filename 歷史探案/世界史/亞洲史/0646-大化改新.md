# 0646 大化改新：用法律抄寫中國的移植實驗

## 案發現場

公元 646 年，日本孝德天皇改元「大化」，頒布《改新之詔》：廢除氏族豪門（蘇我氏）的世襲私領，仿唐朝推行**律令制**——中央集權、戶籍、班田收授、租庸調。此前一年，中大兄皇子（後的天智天皇）與中臣鐮足發動乙巳之變，誅殺權臣蘇我入鹿。

日本朝廷面對的核心難題：氏族豪門瓜分土地與人民，天皇權力空洞化——**如何把散裝的氏族聯盟，改造成一個可計算的中央集權國家**？答案不在島內，在海對岸的唐朝（參見 [../世界發展史/-0221-秦統一.md](../世界發展史/-0221-秦統一.md) 的律法帝國模板）。

> **一個國家的制度可以整包抄襲嗎？遣唐使的知識引進管線如何運作？律令制移植到島國，水土不服的成本是什麼？**

## 偵查過程

**線索一：遣唐使=外部知識引進管線。** 大化改新的知識來源是一條持續兩百年的管線：**遣唐使船**（630 年起，共十餘次）+ **留學生**（吉備真備、僧旻等在唐留學數十年，回國後直接參與改新）。用現代語言：**制度移植=先派的人，後抄的法**——留學生是「活的知識載體」，他們帶回的不是文獻，是在唐朝官僚體系內部的親身經驗。這比任何書面抄寫的資訊損耗都低。

**線索二：律令制的移植內容（抄了什麼）。** 大化改新與其後的《大寶律令》（701）幾乎整包移植唐制：

```
唐制            ──移植──>    日本版
租庸調（稅制）   ──────────>  租庸調（同構）
班田收授（授田） ──────────>  口分田六年一班
戶籍/計帳        ──────────>  庚午年籍（670）
律令法典         ──────────>  《大寶律令》《養老律令》
中央官制（三省） ──────────>  二官八省一台
```

配套邏輯與秦漢同構：**戶籍（資訊）→ 班田（土地）→ 租庸調（財政）**——先知道每個人，才能分田，才能收稅。

**線索三：移植成本與水土不服（抄不動的部分）。** 律令制在日本的運行遠不如唐：班田需要精確的土地測量與人口調查（資訊成本極高），日本山林地形破碎、耕地分散，**測量成本超過唐的中原平原**；租庸調要農民把絹布運到中央（物流成本），日本道路基礎薄弱。結果：**班田持續衰退**——農民棄田逃亡，土地向貴族與寺院集中，私人領地（**莊園**）從制度裂縫裡長出來。移植的成本公式：**移植可行域 = 源地條件 − 目標地環境差距**；抄得了法條，抄不了法條背後的平原與驛道。

**線索四：氏族豪門（先除掉的阻力）。** 改新的第一刀砍向**蘇我氏**——三代專權、私建宮殿陵墓、把皇室土地當自家領地（最典型的委託代理失控）。乙巳之變以宮廷政變清除蘇我氏，是中央集權的前提：**不先收回被架空的任免權，任何移植都無從下手**。但中臣鐮足家族本身（後賜姓藤原）成為新的豪門——舊代理人倒下，新代理人補位，代理問題只是換了姓氏。

**線索五：「唐風」vs「和魂」的張力（移植的長期效應）。** 改新之後一百年，日本全面唐化：平城京（710）仿長安棋盤格局、官制衣冠、漢字詩文。但張力始終存在：律令之名、氏族之實——藤原氏以外戚攝政（攝關政治），實際架空律令政府。**形式上的移植完成，實質上的運行靠本地邏輯**——這為武士的崛起埋下伏筆（[1192-鎌倉幕府.md](1192-鎌倉幕府.md)）：莊園需要武力保護，武士團在莊園中成長，最終取代貴族朝廷。

## 結案報告

1. **留學生=知識載體**：遣唐使管線證明制度移植的關鍵是「活的人」而非「死的書」——在源體系內的親身經驗，資訊損耗最低。
2. **移植有其可行域**：戶籍—班田—租庸調的同構移植，被日本的地形與物流成本打敗——**抄得了法，抄不了法背後的地理**。
3. **代理問題的置換**：除掉蘇我氏只是換代理人，藤原氏補位——權力結構的形式改變，不等於代理問題消失。
4. **偵探教訓**：看一場制度移植，先問三件事——知識管線是誰、環境差距多大、舊代理人去了哪裡；形式移植而實質變形，是歷史的常態而非例外。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 事件工程 | 跨域效應 |
|------|----------|----------|
| 法律 | 《大寶律令》 | 中華法系擴散至島國 |
| 經濟 | 班田、租庸調 | 移植受挫→莊園經濟萌芽 |
| 政治 | 乙巳之變、中央集權 | 舊豪門倒、新豪門起 |
| 科技 | 遣唐使船、測量技術 | 知識管線兩百年不斷 |
| 文化 | 平城京仿長安、漢字 | 唐風與和魂的長期張力 |

**唐制 vs 日本移植對照表：**

| 項目 | 唐制 | 日本移植 | 結果 |
|------|------|----------|------|
| 土地 | 均田（平原、測量易） | 班田（山林、測量難） | 持續衰退 |
| 財政 | 租庸調（驛運發達） | 租庸調（物流薄弱） | 收入流失 |
| 官僚 | 科舉流動 | 氏族世襲殘存 | 藤原專權 |
| 壽命 | 延續至唐末 | 百年即鬆動 | 莊園與武士接班 |

**移植成本示意（可行域公式）：**

```
移植成功 = 源地制度 − 環境差距（地形、物流、氏族慣性）
唐：平原 + 驛道 + 官僚流動   → 均田可行
日：山林 + 弱驛運 + 氏族殘存 → 班田失效 → 莊園從裂縫長出
```

**結論：** 大化改新案證明：**制度移植=知識管線+可行域檢驗+代理人問題**三重考驗。日本抄走了唐朝的法律全文，卻抄不走支持這套法律的中原平原與驛道路網——裂縫裡長出的莊園與武士，最終把「唐風律令國家」改寫成幕府。**形式可以移植，運行條件不能。**
