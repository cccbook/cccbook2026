# 0871-阿爾弗雷德大帝：沼澤中重建王國

## 案件摘要

871 年阿爾弗雷德（Alfred）繼威塞克斯王位（時 22 歲！四兄皆戰死或病死！）→ 878 初被 Guthrum 打到 Somerset 沼澤（Athelney！燒餅傳說！）→ 878.5 **Edington 決戰**反殺 → 886 收復倫敦、立 Danelaw 界線——**英格蘭唯一「大帝」（the Great！）**。此後：burghs（設防鎮 30＋！）、海軍（長船仿造！）、《阿爾弗雷德法典》、英文教育（親譯 Boethius—Gregory！「英文復興」！）。這樁案件是「亡國邊緣的系統重建」：**軍事—行政—文化三線同時開工**。

## 前因 -- 多因素的局勢

- **軍事**：865 大軍滅五國（[0793-維京入侵.md](0793-維京入侵.md)）、876–878 威塞克斯獨存（Chippenham 突襲！阿爾弗雷德逃沼澤！）——**開局即地獄**。
- **財政**：威塞克斯田賦（hide 制！）＋倫敦商稅——重建的錢包（burghal hidage：5 hide 供一兵！量化動員！）。
- **人力**：thegn（貴族武士）＋fyrd（農民兵）——舊瓶裝新酒（burghs 常備化！）。
- **文化**：拉丁文衰微（「亨伯河以南無人懂拉丁」！阿爾弗雷德語！）——英文復興的動機（**亡國之痛→文化自覺**！）。

## 線索與推理 -- 因素咬合

### 線索一：Edington 為何能贏？——「沼澤的動員」

878.1 Chippenham 陷 → 阿爾弗雷德 Athelney 集結（thegn 親兵＋Somerset—Wiltshire—Hampshire fyrd！）→ 5 月 Edington 會戰（盾牆對決！）→ 圍 Guthrum（Chippenham！）→ Wedmore 條約（Guthrum 受洗！取名 Athelstan！）：

$$\text{Edington勝} = \text{（fyrd動員：三郡！）} \times \text{（盾牆紀律）} \times \text{（Guthrum輕敵：以為威塞克斯已亡！）}$$

**關鍵是「國家還在」**——阿爾弗雷德活著，王國的法人資格就在（→法國查理七世—聖女貞德同構！領袖即國家！）。Guthrum 受洗（教父即阿爾弗雷德！）——**宗教即和平條約**（→Rollo 911 受洗同構！）。

### 線索二：Burghs——「設防鎮的系統工程」

30＋ burghs（ Winchester、Wallingford、Wareham！）：土牆—壕溝—常備軍（輪值！）＋ Burghal Hidage（全國 hide—兵力—牆長換算表！**最早的國防預算表**！）：

$$\text{防衛} = \sum(\text{burghs}) \quad \text{且任意兩鎮間距} < \text{一日行軍（} \approx 30\text{km！）}$$

**維京機動被 burghs 網抵銷**（搶一鎮、援軍即至！）——899 阿爾弗雷德死後，子 Edward the Elder＋女 Æthelflæd（麥西亞夫人！巾幗！）用 burghs 逐鎮收復 Danelaw（910–918！）——**系統戰勝個人**（維京英雄多、英格蘭系統強！）。

### 線索三：英文復興——「翻譯即建國」

「我要讓所有英格蘭自由青年都識字」（前言！）→ 親譯（Boethius《哲學慰藉》、Gregory《牧靈指南》、Bede！）→ 《盎格魯—撒克遜編年史》（起編！**英文史學的起點**！）：

$$\text{認同} = \text{（英文書寫）} \times \text{（共同歷史：編年史！）} \times \text{（共同法律：法典！）}$$

**語言—歷史—法律三件套＝民族國家的胚胎**（→比德 gens Anglorum 的落實！）。West Saxon 方言成標準書面語（→喬叟—欽定本的遠祖！）。阿爾弗雷德是「英格蘭之父」（→維多利亞時代造神：溫徹斯特銅像！）。

## 破案時刻

- 871：繼位（Ashdown 首勝！）；878.1：Chippenham 陷—沼澤。
- 878.5：Edington——反殺；Wedmore 條約（Guthrum 受洗！）。
- 886：收復倫敦（重建 Lundenburh！）；Danelaw 界線。
- 890s：burghs 網＋海軍（910s 收復 Danelaw 的基礎！）。
- 890s：翻譯計劃—法典—編年史——文化重建。
- 899：駕崩（子 Edward 續統一：927 埃塞爾斯坦 Rex Anglorum！）。

## 後果 -- 改變了什麼

- **國家**：英格蘭統一的熔爐（威塞克斯→927 全英！）——「英格蘭」從部落名變國家名。
- **軍事**：burghs 系統（→諾曼城堡—都鐸民兵的遠祖！）＋海軍傳統（「阿爾弗雷德建海軍」神話→皇家海軍認祖！）。
- **文化**：英文書面語（West Saxon！）＋編年史傳統（→末日審判—議會記錄的文書國家！）。
- **神話**：燒餅（Athelney 農婦！）、燒蛋糕、jury 試金石（偽託！）——維多利亞的造神工程（愛國主義教材！）。

## 因素影響筆記

```
地獄開局（獨存威塞克斯）×領袖存活 ──→ Edington（國家法人續存）
burghs網（系統）＋海軍 ──→ 維京機動抵銷 ──→ 子女收復Danelaw

```

**偵探結語**：阿爾弗雷德案件是系統的勝利：**Edington 贏的是戰役，burghs 贏的是戰爭，英文贏的是千年**——維京人有英雄（Ivar、Guthrum！），英格蘭有表格（Burghal Hidage！）。表格贏了。而「大帝」稱號（英格蘭唯一！）是後人追贈——追贈的理由不是他打贏了，是他留下了 burghs、法典與英文——打仗是當代的，系統是千年的。
