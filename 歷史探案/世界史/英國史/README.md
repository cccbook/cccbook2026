# 英國史 -- AI 偵探風格

以「推理探案」的方式，追查英國兩千年的重大轉折：羅馬邊疆、維京、諾曼征服、大憲章、黑死病、百年戰爭、玫瑰戰爭、宗教改革、無敵艦隊、東印度公司、內戰、光榮革命、聯合法案、工業革命、失去美洲、特拉法加、改革法案、飢荒、兵變、一戰、分治、二戰、福利國家、帝國解體、蘇伊士、柴契爾、脫歐——
前因是什麼？線索在哪裡？推理如何展開？後果又如何改變了這個島國？

本卷的核心命題只有一句話：**英國史是「島國的槓桿史」。**
島國位置＋議會財政＋海軍＋工業——四根槓桿撬起世界帝國；每一次轉折都是槓桿的增減：諾曼的中央集權、大憲章的稅權、黑死病的工資、宗教改革的土地、光榮革命的國債、工業革命的蒸汽、福利國家的承諾。每個重大事件都是一樁「多因懸案」：偵探的工作，就是把因素鏈一環一環還原出來。

（涵蓋：羅馬不列顛、七國基督教化、維京、阿爾弗雷德、諾曼征服、末日審判、大憲章、模範議會、黑死病、農民起義、百年戰爭、玫瑰戰爭、宗教改革、無敵艦隊、東印度公司、清教徒革命、光榮革命、聯合法案、工業革命、失去美洲、特拉法加、滑鐵盧、改革法案、愛爾蘭飢荒、印度兵變、一戰、愛爾蘭分治、空戰、福利國家、印度獨立、蘇伊士、柴契爾、脫歐）

## 因素的回饋迴路

```
              ┌────（瘟疫／天氣：外生衝擊）────┐
              ↓                                ↓
   地理（島國）──→ 海軍—貿易 ──→ 經濟 ──→ 政治（議會）──→ 組織 ──→ 武器
    │                              ↑        ↑                         │
    │                              │        │                         ↓
    └──→ 科技（蒸汽—雷達）←── 資訊 ──┘        心理 ←──────── 心理迴路
              ↑                            ↑
              └── 宗教 ←──（合法性與動員）┘

   正向迴路（加速）：戰爭→稅收→議會→國債→更多戰爭
   正向迴路（加速）：煤→蒸汽→工廠→城市→更多煤
   負向迴路（抑制）：帝國擴大→維持費↑→透支→解體
   島國迴路（英國特有）：制海→貿易→金融→海軍→更多制海
```

**偵探的訣竅**：找到「哪個因素先動、哪個因素放大、哪個因素抑制」，把迴路畫出來；再問一句——**這次是誰付錢（稅收—國債—石油—巴士）？**案件的因果鏈就浮現了。

## 偵探的結案陳詞

兩千年的英國史，可以壓縮成三條因果鏈：

1. **憲政鏈**：索爾茲伯里（人人忠王）→ 大憲章（稅權）→ 模範議會（代表）→ 內戰（弒君）→ 光榮革命（議會主權）→ 改革法案（普選長路）——**弱王＋戰爭＋稅收＝議會的成長史**。
2. **帝國鏈**：EIC 特許狀 → 迪瓦尼稅收 → 失去美洲（轉向）→ 特拉法加（制海）→ 工業（世界工廠）→ 一戰透支 → 蘇伊士黃昏 → 香港落幕——**特許狀的複利與透支的複利**。
3. **島國鏈**：1066 最後被征服 → 百年戰爭（輸法贏英）→ 光榮孤立（離岸平衡）→ 空戰（少數人）→ 脫歐（奪回控制）——**海峽兩面的百年擺盪：介入歐洲 vs 退出歐洲**。

三條鏈咬合在一起，就是本卷三十三樁案件的全部真相。
