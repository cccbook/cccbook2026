# 1769-瓦特與工業革命：蒸汽改寫的國力公式

## 案件摘要

1769 年，瓦特（James Watt！格拉斯哥儀器匠！）獲分離冷凝器專利（＋1781 行星齒輪！＋1788 離心調速器！）→ 1776 與 Boulton 合夥（Soho！）→ 蒸汽機效率×4（Newcomen 0.5%→Watt 2–3%！）——**工業革命的動力心臟**；同期：1764 珍妮紡紗機（Hargreaves！）、1769 水力紡紗（Arkwright！工廠制！）、1779 騾機（Crompton！）、1785 動力織布（Cartwright！）、1776《國富論》（Smith！）、1776–79 Coke—Townshend 農業革命（輪作—圈地！）。這樁案件是「煤炭—蒸汽—工廠的三角」：**島國的煤＋殖民地的棉＋議會的專利＝世界工廠**。

## 前因 -- 多因素的局勢

- **能源**：英格蘭煤（Newcastle！淺層—水運！）＋木材危機（煉鐵—造船耗林！）——**燃料轉換的壓力**（→1709 焦炭煉鐵 Darby！→ coke！）。
- **市場**：殖民地—奴隸三角（棉—糖—菸！）＋印度棉布刺激（Calico Acts 禁令！→走私—仿製！[1600-東印度公司.md](1600-東印度公司.md)！）＋人口增長（1750–1800 翻倍！）——**需求的爆炸**。
- **制度**：專利法（1624 壟斷法案！）＋普通法產權（圈地法案！）＋英格蘭銀行—國債（資本市場！）——**創新的產權—資本**。
- **知識**：蘇格蘭啟蒙（Smith—Hume—Black！瓦特在格拉斯哥大學修儀器！Black 潛熱理論！）＋皇家學會（工匠—紳士網絡！）——**科學—工匠的聯姻**。

## 線索與推理 -- 因素咬合

### 線索一：為何是英國？——「五項全能」

| 要素 | 英國 | 對手（法—中—印） |
|---|---|---|
| 煤—鐵共生 | 煤田壓鐵礦（Shropshire—南威爾斯！） | 法煤少—中國運煤貴 |
| 工資高 | 高工資→機器替代划算（Allen 論！） | 中印工資低（無需機器！） |
| 殖民市場 | 美洲—印度—奴隸三角（棉—糖！） | 法殖民地小—中國內向 |
| 專利—產權 | 1624 專利＋圈地（資本集中！） | 法行會壟斷—中國官營 |
| 科學—工匠 | 皇家學會—倫敦工匠—蘇格蘭大學 | 法科學院脫離工匠—中國士大夫輕技 |

$$\text{工業革命} = \text{（煤）} \times \text{（高工資）} \times \text{（殖民市場）} \times \text{（專利產權）} \times \text{（科學工匠）}$$

**五項乘數全中**（→加州學派—Allen 爭論！多因懸案！）。瓦特（蘇格蘭人！[1707-聯合法案.md](1707-聯合法案.md)合併紅利！）＋Boulton（伯明翰資本！）——**啟蒙＋資本的合資**。

### 線索二：工廠制——「時間的發明」

Arkwright Cromford（1771！水力—晝夜—童工！）→ 工廠（紀律：鐘—罰款—監工！）→ 曼徹斯特（Cottonopolis！1780–1800 棉產量×10！）：

$$\text{工廠} = \text{（機器：集中動力！）} \times \text{（紀律：時間規訓！）} \times \text{（童工—女工：廉價！）}$$

**工廠發明「上班」**（E.P. Thompson 時間規訓！）——圈地失地農民（→濟貧法！）＋愛爾蘭移民（→[1845-愛爾蘭大飢荒.md](1845-愛爾蘭大飢荒.md)！）＝勞動力。盧德（Luddites 1811–16！砸機器！）→ 鎮壓（Peterloo 1819！騎兵砍工人！）——**機器的血稅**（→工會—憲章派！）。

### 線索三：國力公式——「煤的帝國主義」

1800–70：英國煤佔世界 80%＋（！）→ 鐵（Darby—Cort！攪煉！）→ 鐵路（Stephenson 1825 Stockton！1830 Liverpool—Manchester！）→ 輪船（螺旋槳—鐵殼！）→ 電報（1851 英吉利海峽！1866 大西洋！）：

$$\text{不列顛治世} = \text{（煤—鐵—蒸汽）} \times \text{（海軍：煤船—炮艦！）} \times \text{（金融：倫敦—金本位！）}$$

**「煤 Kil？不——煤即權力」（Sadi Carnot！）**——Jevons《煤問題》（1865！耗竭預言！早產但邏輯對！）。曼徹斯特—伯明翰—格拉斯哥（→世界工廠！→「日不落」的鍋爐房！）——1851 萬國博覽會（水晶宮！「世界工廠開幕」！）。

## 破案時刻

- 1709：Darby 焦炭煉鐵；1764：珍妮機；1769：瓦特專利＋Arkwright 水力機——同年雙響。
- 1771：Cromford 工廠；1776：Boulton—Watt 合夥＋《國富論》——思想—機器同年。
- 1785：Cartwright 動力織布；1788：調速器——蒸汽成熟。
- 1800–30：煤—鐵—棉爆發（棉布價 −90%！）；1825：鐵路——運輸革命。
- 1830s–40s：盧德—Peterloo—憲章派（機器的政治帳單！）；1851：水晶宮——世界工廠加冕。

## 後果 -- 改變了什麼

- **國力**：世界工廠（→不列顛治世 [1815-滑鐵盧與治世.md](1815-滑鐵盧與不列顛治世.md)！→海軍—金融—殖民！）——煤的帝國主義。
- **社會**：工廠—城市（曼徹斯特 25 萬！貧民窟—霍亂！）→ 工會—合作社—工黨（→[1945-工黨與福利國家.md](1945-工黨與福利國家.md)！）——機器的政治後代。
- **全球**：棉—煤—鐵路輸出（→美國—德國—日本工業化！）＋氣候（CO₂ 起點！）——**人類世的開幕**（→今碳中和的遠祖！）。
- **思想**：Smith—Malthus（1798 人口論！）—Ricardo—Marx（《資本論》大英博物館！）——**政治經濟學誕生於曼徹斯特的煙霧**。

## 因素影響筆記

```
煤鐵共生（地理）×高工資（誘因）×殖民市場（需求）──→ 五項全能
瓦特專利（1769）＋Boulton資本 ──→ 蒸汽心臟 ──→ 工廠制（時間發明！）
                                                        ↓
                              煤—鐵—鐵路—電報 ──→ 不列顛治世（國力公式）
```

**偵探結語**：1769 案件是五項全能：**煤（地理！）、高工資（誘因！）、殖民地（市場！）、專利（制度！）、工匠＋科學（知識！）**——五項乘起來，瓦特的冷凝器才有意義。而工廠最狠的發明不是機器，是「上班」——鐘、罰款、監工，時間被切成工資。曼徹斯特的煙，飄進 Marx 的《資本論》（大英博物館閱覽室！）——機器的孩子，起來革命了。
