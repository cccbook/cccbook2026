# 歐洲史 -- AI 偵探風格

以「推理探案」的方式，追查歐洲文明的重大轉折：希臘城邦、羅馬興亡、基督教、封建、民族國家、宗教改革、科學與工業、革命、大戰與歐洲整合——
前因是什麼？線索在哪裡？推理如何展開？後果又如何改變了整個歐洲？

本卷的核心命題只有一句話：**歐洲史是「分裂中的競爭」的歷史。**
地理破碎（山脈半島）→ 多國並立 → 軍事競爭 → 制度與科技的軍備賽 → 全域擴張。每個重大事件都是一樁「多因懸案」：偵探的工作，就是把因素鏈一環一環還原出來。

（涵蓋：希臘、羅馬、基督教、蠻族、查理曼、封建、十字軍、大憲章、黑死病、文藝復興、宗教改革、三十年戰爭、光榮革命、法國大革命、維也納體系、民族主義、大戰、冷戰、歐盟）

## 歐洲史的五條主軸

| 主軸 | 機制 | 經典案例 |
|------|------|----------|
| **地理破碎 → 競爭** | 無法一統 → 多國軍備競賽 → 制度創新壓力 | 希臘城邦、歐洲列強、歐盟 |
| **宗教與王權的拉鋸** | 教皇 vs 皇帝的二元結構 → 權力真空 → 城市與法治 | 敘任權之爭、大憲章、宗教改革 |
| **武器成本曲線** | 誰能負擔新武器，誰就重寫權力結構 | 方陣、軍團、騎士、火藥、徵兵、坦克 |
| **人口與疾病的重置** | 外生衝擊摧毀舊制度，工資與階級重洗牌 | 黑死病、百年戰爭、兩次大戰 |
| **思想市場的爆炸** | 傳播速度決定動員半徑 | 印刷術→宗教改革；報刊→革命；電視→冷戰 |

## 因素的回饋迴路

```
   地理破碎 ──→ 多國並立 ──→ 軍事競爭 ──→ 財政壓力 ──→ 制度創新
      │                          │                        │
      │                          ↓                        ↓
      └──→ 貿易與城市 ←── 技術 ←────────────────── 法律與法治
                                   ↑
   宗教 ←──→ 王權（二元拉鋸）──────┘
      │
      ↓
   思想市場（印刷、大學、啟蒙）──→ 動員 ──→ 革命／改革

   正向迴路：競爭→戰爭→技術→貿易→財政→更多競爭
   正向迴路：印刷→識字→科學→技術→工業→印刷更多
   負向迴路：帝國擴大→行政成本↑→邊疆壓力→崩潰（羅馬）
```

**偵探的訣竅**：歐洲與中國的關鍵差異在「無法一統」——競爭使制度創新不可逆（逃亡的工匠與資本帶著制度走）。

- 前264–前146：三次布匿戰爭——羅馬吞併西地中海。
- 前133–前121：格拉古兄弟改革失敗——共和的社會契約破裂。
- 前107：馬略軍事改革——職業軍隊效忠將領而非國家（共和的死亡倒數）。
- 前60：前三頭同盟（凱撒、龐培、克拉蘇）。
- 前49–前45：凱撒內戰，「渡過盧比孔河」。［[-0044-凱撒與羅馬共和的終結.md](-0044-凱撒與羅馬共和的終結.md)］

## 卷尾：歐洲史的偵探總結

1. **古典的遺產**：羅馬的法律、希臘的理性、基督教的組織——三筆遺產在「分裂」的地理中互相競爭與合成。
2. **中世紀的意外**：教皇與皇帝的二元拉鋸，意外地創造了「王在法下」與「自由城市」——法治的搖籃。
3. **黑死病的重置**：人口衝擊使工資與階級重洗牌——封建的解體是「疾病的經濟學」。
4. **印刷的革命**：資訊成本崩跌使宗教改革、科學革命、啟蒙連鎖引爆。
5. **競爭的軍備賽**：多國並立使戰爭不斷，但戰爭財政逼出國債、銀行、議會——「戰爭造就國家，國家造就戰爭」（蒂利）。
6. **革命的世紀**：1789 的劇本（思想→組織→暴力）在 1848、1917 重演——民族主義是總體戰的燃料。
7. **大戰的教訓**：兩次世界大戰摧毀歐洲的舊中心地位——但摧毀本身成為整合的催化劑（煤鋼聯營→歐盟）。
8. **分裂的終點？**：1989 柏林圍牆倒塌後，歐洲以「制度整合」取代「軍事統一」——地理破碎的歷史第一次被制度設計回應。
