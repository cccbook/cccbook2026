# 1077-卡諾莎之行：跪在雪裡的皇帝與敘任權之爭

## 案件摘要
1077 年 1 月，神聖羅馬帝國皇帝亨利四世赤足披氈，在托斯卡納的卡諾莎城堡雪地中跪了三天，求教皇格里高利七世收回絕罰令。偵辦發現：這場「羞辱大戲」不是皇帝認輸，而是棋局中盤的緩兵之計——真正的爭議是**誰有權任命主教**（敘任權，Investiture Controversy）。主教的戒指與牧杖不只是宗教信物，而是土地、稅收與官職：帝國一半的財政與行政靠「主教們」撐著。這場 1075–1122 的四十七年拉鋸，是歐洲「宗教與王權二元拉鋸」主軸的第一場高潮，也是「王在法下」觀念的產房。

## 前因 -- 多因素的局勢
- **財政**：奧托王朝以「帝國教會體制」治國——主教由皇帝任命、終身不婚（領地不外流）、兼具行政與軍事職能。主教座堂區等於帝國的「省級國企」。
- **宗教改革**：克呂尼修院運動（10 世紀起）主張教會擺脫俗世控制；1059 年教廷選舉樞機團制度化，教皇第一次可以不看皇帝臉色產生。
- **政治**：亨利三世 1046 年廢立三位教皇（「薩克森王朝的教皇時代」）埋下教廷復仇記憶；1075 亨利四世平定薩克森內亂，自覺腰桿硬了。
- **思想**：「兩把劍」理論（靈界之劍由教皇執掌、俗界之劍由皇帝執掌但教皇有權審查）開始被格蘭西等教會法家系統化——思想武器先於政治攤牌。
- **社會**：授予俗人聖職（simony，買賣聖職）與教士娶妻被輿論視為末世腐敗——「清潔教會」是當時的全民運動。

## 線索與推理 -- 因素咬合
### 線索1：主教座堂區的資產負債表
皇帝為何拼死不肯放棄敘任權？算一筆帳：
$$\text{主教任命權} = \text{領地} + \text{什一稅} + \text{軍役} + \text{官職} \Rightarrow \text{失去敘任權} \approx \text{帝國一半財政破產}$$
格里高利七世 1075 年《教皇敕令》（Dictatus Papae）宣稱教皇有權廢黜皇帝——這在財政上等同沒收帝國的行政系統。衝突的本質是**兩種組織架構搶同一批資產**。

### 線索2：絕罰是武器，認慫是武器
1076 亨利四世召開德意志主教會議宣布廢黜教皇；格里高利反手絕罰並解除諸侯效忠誓約——薩克森諸侯聞風而動，計畫另立新王。亨利的「卡諾莎之跪」是一次精算：取得赦免 → 解除絕罰 → 諸侯失去另立國王的法理。偵查結論：**羞辱是買時間的貨幣**。但諸侯不買帳，照樣選出對立國王魯道夫——內戰照打，亨利反而打出了「救國者」的身位。

### 線索3：妥協的技術設計（1122 沃爾姆斯宗教協定）
| 項目 | 皇帝讓 | 教皇讓 |
|---|---|---|
| 主教選舉 | 教會自由選舉 | 德意志主教選舉時皇帝在場監督 |
| 象徵物 | 交還戒指與牧杖（靈職） | 皇帝授予權杖（世俗封地） |
| 資產 | 失去靈職敘任 | 承認世俗領地敘任權 |

妥協公式：**靈職歸教會、俗權歸皇帝、德意志特例「雙軌並存」**。這是歐洲第一次用「分割產權」解決主權衝突——後世憲政的「權力分立」在此排練。經濟學家諾斯的視角：制度創新發生於談判力變動之處——教廷的談判力（輿論＋絕罰武器＋諸侯勾連）上升，逼出新的產權界定。

### 線索4：誰贏了？看後續半世紀
亨利四世死時眾叛親離；1122 協定後帝國教會體制瓦解，皇帝財政與行政基礎流失；教廷權威攀頂（1170 貝克特案、1198 英諾森三世）。但長期看：**德意志因二元拉鋸而碎片化**（見 0962 卷的補完），英法因教俗權界清晰化而加速中央集權——同一場衝突，對不同政治體的後果相反。

## 破案時刻
- 1075：《教皇敕令》發布；亨利無視禁令敘任米蘭大主教。
- 1076：互相廢黜；教皇絕罰皇帝並解除效忠誓約。
- 1077.1：卡諾莎之跪，赦免；諸侯仍另立魯道夫，內戰續打。
- 1080：格里高利再絕罰亨利；亨利反立對立教皇，1084 攻入羅馬。
- 1085：格里高利客死薩萊諾：「我愛正義、恨不義，故我死於流亡。」
- 1122：沃爾姆斯宗教協定，敘任權分割。

## 後果 -- 改變了什麼
- **法治觀念**：教會法學家論證「權力受法律約束、暴君可被廢黜」——大憲章（1215）前四十年，約束王權的觀念已有理論庫（見 1215 卷）。
- **政治地理**：德意志諸侯趁機坐大，神聖羅馬帝國走向「選侯聯邦化」；西歐民族國家的中央集權反而加速——二元拉鋸的空間溢出。
- **大學與法律**：教會法（Canon Law）與羅馬法研究在衝突刺激下勃興（1088 博洛尼亞大學）——專業法學家階層誕生。
- **教訓**：組織理論的經典——當兩個最高權威搶同一批資源，結果不是一方吞掉另一方，而是發明「分割產權」的新制度。

## 因素影響筆記
1. 帝國教會體制的財政依賴 → 敘任權成死穴（經濟）。
2. 克呂尼運動＋教廷選舉改革 → 教廷獨立談判力（宗教）。
3. 絕罰武器化＋諸侯勾連 → 皇帝必須下跪（政治）。
4. 沃爾姆斯分割產權 → 法治與大學的制度紅利（制度）。
5. 德意志碎片化 vs 西歐集權化 → 歐洲多國競爭格局固化（長期）。
