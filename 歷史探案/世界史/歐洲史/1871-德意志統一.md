# 1871-德意志統一：鐵血、外交與經濟的多因案件

## 案件摘要
1871年1月18日，普魯士國王威廉一世在凡爾賽鏡廳加冕為德意志皇帝，德意志統一收案。此案沒有單一兇手：1848年自由民族統一運動的失敗、關稅同盟的經濟整合、俾斯麥「鐵與血」的現實政治、三次精準的王朝戰爭、以及法國的外交失誤互相咬合。統一不是民族主義的自然果實，而是經濟整合鋪路、軍事與外交工具到位後，由普魯士主導的國家建設工程。

## 前因 -- 多因素的局勢
- **經濟**：1834年普魯士主導的「關稅同盟」（Zollverein）將多數德意志邦納入單一市場；1850年代工業化（魯爾煤鐵、鐵路網）使德意志經濟以普魯士為軸心整合，小邦經濟上離不開普魯士。
- **政治**：1848年法蘭克福議會失敗證明自下而上的自由統一此路不通；普魯士1850年憲法維持容克貴族與國王權力，1862年俾斯麥就任首相，以「鐵與血」演說宣告武力統一路線。
- **心理**：德意志民族意識自拿破崙戰爭與1848年持續累積；但各邦王朝效忠仍在——民族認同需要政治工程轉化為國家。
- **軍事**：陸軍大臣羅恩的軍事改革與毛奇的參謀本部使普魯士軍隊現代化；鐵路動員（利用關稅同盟的鐵路網）使快速集中作戰成為可能。
- **外交**：俾斯麥逐一孤立敵手：確保俄國與英國中立、拉攏義大利、誘使奧地利與法國先出手——每場戰爭都精心控制參戰名單。
- **資訊**：1866年普奧戰爭速勝震驚全歐，改寫各方對權力平衡的評估，為1870年對法戰爭的心理鋪路。
- **地理**：普魯士本土被分為東西兩塊、荷爾斯泰因問題與南德邦聯問題，地緣矛盾提供開戰藉口。

## 線索與推理 -- 因素咬合
### 線索1：經濟整合先於政治整合——關稅同盟的鋪路
$$\text{關稅同盟(1834)} \to \text{單一市場與鐵路網} \to \text{南德邦經濟依賴普魯士} \to \text{1870年南德參戰} \to \text{統一水到渠成}$$
「經濟先行、政治跟進」：1867年北德邦聯成立時，南德在關稅與軍事同盟上已被綁定，普法戰爭只是完成臨門一腳。

### 線索2：俾斯麥的「鐵與血」——現實政治（Realpolitik）
俾斯麥1862年演說：「當代重大問題不是靠演說與多數決解決，而是靠鐵與血。」這是對1848年的回答：**統一的正當性來自成功，而非來自理念辯論**。但鐵血需配合外交計算——三次戰爭每次都只結一個敵人、留足退出條件，是武力與外交的雙軌工程。

### 線索3：蒂利命題——戰爭造就國家的實戰驗證
| 戰爭 | 敵手 | 戰果 |
|---|---|---|
| 1864 普丹戰爭 | 丹麥 | 石勒蘇益格-荷爾斯泰因共管 |
| 1866 普奧戰爭 | 奧地利 | 奧地利退出德意志事務，北德邦聯成立 |
| 1870–71 普法戰爭 | 法國 | 南德參戰，帝國成立 |

每場戰爭都是國家建設的一步：軍事勝利轉化為條約、邦聯與帝國——蒂利「戰爭造就國家」在此案完美體現。

### 線索4：外交誘敵——埃姆斯電報的心理戰
$$\text{西班牙王位繼承問題} \to \text{法國抗議} \to \text{俾斯麥刪改埃姆斯電報發布} \to \text{法國羞辱感爆發宣戰(1870.7.19)} \to \text{法國孤立作戰} \to \text{色當潰敗}$$
資訊操作使法國成為「宣戰方」，俄英不介入的保證生效——1870年的戰場只剩法國對普魯士與南德聯軍，色當之役（1870年9月）拿破崙三世被俘。

### 線索5：1848年的反面教材——兩條統一之路的對照
1848年：議會請願、理念動員、無軍隊——失敗。1864–71：武力、外交、經濟整合——成功。俾斯麥吸收了1848年民族主義的能量，卻以保守王權形式收編它——**民族主義被現實政治收購，而非擊敗**。

## 破案時刻
- 1862年9月：俾斯麥就任普魯士首相，「鐵與血」演說。
- 1864年：普丹戰爭，取得石勒蘇益格-荷爾斯泰因。
- 1866年6–8月：普奧戰爭，克尼格雷茨（薩多瓦）之役大勝；《布拉格和約》解散德意志邦聯。
- 1867年：北德邦聯成立，俾斯麥任總理；南德簽秘密軍事同盟。
- 1870年7月19日：法國宣戰；9月2日色當之役拿破崙三世被俘。
- 1871年1月18日：威廉一世於凡爾賽鏡廳加冕為德意志皇帝；5月《法蘭克福和約》，法國割亞爾薩斯-洛林並賠款。

## 後果 -- 改變了什麼
- **政治**：歐洲均勢被改寫——新興強權德意志帝國誕生，法國復仇主義抬頭；奧地利改組為奧匈帝國（1867），退出德意志。
- **經濟**：單一市場擴及全德，德國工業化加速，數十年內超越英國成為歐洲第一工業強權。
- **心理**：「現實政治」成為國際關係主流語彙；法國的民族屈辱（鏡廳加冕故意選在凡爾賽）為兩次世界大戰埋下遠因。
- **世界**：民族國家模式成為範本，激勵義大利完成統一（1870）與各民族獨立運動；同時德法對立使歐洲體系從協調轉向陣營化。
- **教訓**：經濟整合鋪路、軍事外交收網、民族主義收編——統一是多因素工程的產物；俾斯麥的體系依賴他個人的操作，留下的結構性對立則由後人承受。

## 因素影響筆記
1. 經濟鏈：關稅同盟 → 單一市場與鐵路網 → 南德經濟依賴 → 政治統一的物質基礎。
2. 軍事鏈：軍事改革＋參謀本部 → 三次王朝戰爭 → 勝利轉化為條約與帝國（蒂利命題）。
3. 外交鏈：逐一孤立敵手 → 俄英中立＋南德參戰 → 法國孤立 → 1870年決定性勝利。
4. 資訊鏈：西班牙王位問題 → 埃姆斯電報操作 → 法國羞辱宣戰 → 心理戰成功。
5. 心理鏈：1848年理念統一失敗 → 鐵血路線 → 民族主義被王權收編 → 德意志帝國成立。
