# 1599-耶穌會教學規範：第一套國際標準化課程

## 案件摘要

1540 年依納爵·羅耀拉創立耶穌會；1548 年墨西拿第一所學院開辦；1599 年頒布《教學規範》（Ratio atque Institutio Studiorum）——**史上第一套國際標準化課程與教學法**：統一的班級制、統一的教材、統一的進度表、統一的考核，全世界一致。到十七世紀中葉，耶穌會經營八百餘所學院，笛卡爾（拉弗萊什）、莫里哀、伏爾泰皆為校友。本案偵破的問題是：一個修會如何把教育做成「跨國連鎖店」？

## 前因 -- 為什麼會有這個案子

- 反宗教改革（特倫托會議 1551–63）：天主教需要對抗新教的辦學運動（[1524-路德的全民識字革命.md](1524-路德的全民識字革命.md)）——**教義競爭即教育競爭**。
- 人文主義課程成熟：伊拉斯謨與西塞羅式拉丁文——課程內容已有現成藍本。
- 修會的軍事化組織：依納爵曾是軍人，修會採「服從、紀律、報告制度」——**組織理論已到位**。
- 新教的問答法成功展示：標準化教材的效果可見——耶穌會以更精密的版本回應。

## 線索與推理 -- 標準化的工程學

### 線索一：「教育連鎖店」的組織模式

Ratio Studiorum 的標準化範圍：

| 標準化項目 | 內容 | 現代對應 |
|------------|------|----------|
| 班級制 | 按程度分班（文法五級→人文→修辭→哲學→神學） | 年級／學程 |
| 教材 | 全會統一課本與讀本 | 統編教材 |
| 進度 | 每年、每月的教學進度規定 | 教學計畫 |
| 考核 | 統一競試、口試與辯論 | 標準化評量 |
| 師資 | 兩年訓練＋宣誓＋報告制度 | 師培＋督學 |

**SOP（標準作業程序）使品質跨國一致**——麥當勞式品質控制的四百年前身：**教育連鎖店的組織理論誕生**。

### 線索二：教學法——經院方法與人文主義的合流

Ratio 的課堂結構：講授（praelectio）→ 背誦（recitatio）→ 競賽與辯論（disputatio／emulatio）：

- 保留經院辯論（[1200-巴黎大學與經院哲學.md](1200-巴黎大學與經院哲學.md)）的方法骨架；
- 內容換成人文主義的西塞羅式拉丁文與古典；
- 加入**名譽競賽**（emulatio）：每月排名與獎勵——**名譽作為動機設計**（競爭式學習的四百年前身）。

### 線索三：班級制的定型

Ratio 把「按程度分班」制度化：同一級的學生同進度、同考核——**班級授課制（class system）在此定型**：一個教師對一個班的結構，成為此後四百年學校的基本形態（夸美紐斯 [1632-誇美紐斯大教學論.md](1632-誇美紐斯大教學論.md) 給它理論，耶穌會給它實踐）。

### 線索四：制度成效表

| 指標 | 成效 |
|------|------|
| 規模 | 1600 年代中葉 800+ 學院；全球（含美洲與亞洲傳教區） |
| 品質 | 全會統一課程與考核——跨國一致 |
| 產出 | 笛卡爾、莫里哀、伏爾泰等精英——「歐洲精英的母校」 |
| 競爭力 | 十七世紀天主教地區的中學教育近乎壟斷 |

### 線索五：標準化的代價

全會統一課程的代價：**僵化與反彈**——笛卡爾抱怨拉弗萊什的經院哲學（他出校後另闢方法論）；十八世紀啟蒙運動把耶穌會當作「保守教育」的象徵攻擊；1773 年教宗解散耶穌會（政治壓力）——**標準化換來品質，也儲存了反彈的能量**。

## 破案時刻

1599 Ratio 頒布：全世界每一所耶穌會學院讀同一本書、走同一個進度、考同一場試——**教育的跨國標準化工程完成**。笛卡爾在拉弗萊什受業十年（1604–12），他抱怨經院方法、卻也帶走了它的邏輯訓練——**《方法論》（1637）的推理訓練來自這套標準化課程**。

## 後果 -- 改變了什麼

- 班級授課制定型：一師一班、按程度分級——四百年學校形態的基礎。
- 標準化課程成為國家學制的藍本：普魯士（1763）、法國（lycée 1802、帝國大學 1808）全數以「統一課綱＋統一考核」為骨架。
- 「教育連鎖店」的組織模式：SOP＋師培＋督學——跨國教育組織（國際學校、補教集團）的遠祖。
- 標準化與反彈的循環：品質 ↔ 僵化——教育標準化的永恆張力。

## 教育演進筆記

1. **SOP 使教育品質跨國一致**：統一課綱＋統一考核＋師培＋督學——「教育連鎖店」的組織理論。
2. **班級制在實踐中定型**：一師一班的結構是效率與規模的妥協——四百年的基本形態。
3. **名譽是動機設計**：排名與競賽（emulatio）——競爭式學習的四百年前身。
4. **標準化儲存反彈**：品質的代價是僵化——笛卡爾們總會出現，教育標準化必須為「下一個改革者」留出縫隙。
