# -0930-王國分裂：一個帝國敘事撐不起兩套行政

## 案件摘要

約西元前 930 年，所羅門死後其子羅波安繼位。北方各支派在示劍集會，請求減輕勞役與重稅；羅波安拒絕並揚言「我父親用鞭子責打你們，我要用蠍子鞭責打你們」。北方十支派擁立耶羅波安自立，王國一分為二：北國以色列（十支派、較大較富）、南國猶大（大衛家＋聖殿）。這樁案件的謎題是：**聯合王國為何只維持了不到一個世紀？** 兇手是「治理規模超過行政能力」——統一的政治收益被財稅不公的交易成本吃光。

## 前因 -- 多因素的局勢

- **結構**：北方（以法蓮、瑪拿西等）土地較肥、人口較多、商路較富；南方猶大有首都與聖殿——資源與符號權威分屬兩地。
- **勞役**：所羅門的大工程（聖殿、王宮、米吉多等設防城）靠強制勞役（mas）支應——負擔由誰出是政治炸藥。
- **前例**：所羅門晚年已鎮壓過耶羅波安起事（先知亞希雅預言北方的背叛）——裂痕在王朝內部早已存在。
- **財稅**：統一王國的貢賦體系以耶路撒冷為中心，北方視為單向輸血。

## 線索與推理 -- 因素咬合

### 線索一：分裂 = 一次「脫離聯盟談判」的破裂

用政治學的退出—發言框架（Hirschman）看示劍大會：北方先選擇「發言」（要求減負），羅波安選擇拒絕，北方只剩「退出」。

$$\text{維持統一條件}：\text{中心剝削率} < \text{分離的啟動成本}$$

羅波安把稅負維持在高位，而啟動成本（耶羅波安已返國、民氣可用、埃及示撒正在南方邊境施壓）剛好降低——不等式反轉，分裂發生。

### 線索二：治理規模 vs. 行政技術

所羅門的「帝國」依賴個人紐帶與聯姻外交，而非制度化官僚體系（對照秦的郡縣，見 [-0221-秦的統一與官僚帝國.md](-0221-秦的統一與官僚帝國.md)）：

| | 秦帝國 | 聯合王國 |
|---|---|---|
| 治理手段 | 郡縣、可調任官員 | 總督＋強制勞役 |
| 標準化 | 文字度量衡 | 無 |
| 統一的經濟基礎 | 全國市場 | 北方補貼南方 |

**沒有標準化與整合性紅利的統一，只是加稅的藉口**——統一的收益（共同防禦）由北方承擔成本卻感受不到，統一注定變成套利對象。

### 線索三：宗教的雙城記

耶羅波安為防止人民上耶路撒冷朝聖（政治忠誠的流失），設但與伯特利金牛犢聖所——**宗教體系跟著國界分裂**。從此北國有多處聖所與複雜的王朝更迭（兩百年九朝皆以政變開場），南國維持單一大衛家＋單一聖殿——制度差異決定了兩國不同的死亡方式。

## 破案時刻

- 約前 931/930：示劍集會、拒絕減負、北方立國。
- 前 925：埃及示撒入侵，掠耶路撒冷聖殿寶物——統一的殘餘紅利也沒了。
- 前 885–前 870：北國內戰定都撒瑪利亞，兩國常態化對峙（偶有聯盟）。

## 後果 -- 改變了什麼

- **政治**：兩個猶太小國並立近兩百年，戰略上都更脆弱。
- **宗教**：北國的多元聖所 vs. 南國的聖殿集中——為申命記的「中央化」運動提供反例與動力。
- **文獻**：南北各有史官傳統（被編入列王紀），北國的先知傳統（以利亞、以利沙）成為以色列宗教的核心資產。
- **世界史**：小規模聯盟的統一若無行政整合，分手只是時間問題——希臘城邦聯盟、近代邦聯都重演此案。

## 因素影響筆記

1. **財稅不公 → 退出**：分裂的直接機制。
2. **行政技術不足 → 規模超載**：統一規模不能超過行政能力。
3. **符號權威（聖殿）集中 → 失衡恐懼**：宗教資本的地理分配決定聯盟黏性。
4. **分裂 → 北國暴露於亞述**：通往 [-0722-北國以色列亡於亞述.md](-0722-北國以色列亡於亞述.md) 的第一塊骨牌。
