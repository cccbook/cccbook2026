> 一個人口從未超過世界 0.5% 的民族，卻在神學、法律、科學、金融與地緣政治上留下不成比例的痕跡。這卷書不是英雄傳——它是一連串「倖存機制」的推理：離散、經典化、自治社區、雙語性、慈善網路、教育投資，以及反猶主義這個反覆出現的病理。每一次大流散，猶太社群都在重新發明自己的制度。
