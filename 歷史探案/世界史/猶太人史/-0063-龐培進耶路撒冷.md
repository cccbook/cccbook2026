# -0063-龐培進耶路撒冷：羅馬吞併猶太與代理王的成本

## 案件摘要

西元前 63 年，羅馬將軍龐培兵臨耶路撒冷，趁哈斯蒙尼王朝兩兄弟（許爾堪二世與阿里斯托布魯斯二世）內鬥之機介入，圍城三個月後破城。據傳龐培進入聖殿至聖所——在猶太人眼中是褻瀆，在羅馬人眼中只是「偵查敵方據點」。猶太從此失去獨立，成為羅馬的附庸，先後由許爾堪任大祭司兼「民族首領」、安提帕特家族（後來的希律）擔任實權代理。這樁案件的真相是：**羅馬不直接統治，而是外包統治**——帝國邊疆治理的成本最小化解法，卻埋下了六百年衝突的引信。

## 前因 -- 多因素的局勢

- **猶太內鬥**：哈斯蒙尼王朝本就是祭司（Zadok 系）奪權的政權，法利賽與撒都該的張力使王位繼承持續動盪。
- **兩兄弟內戰**：許爾堪二世與阿里斯托布魯斯二世爭位，各自向羅馬求援——主動把強權引進家門。
- **羅馬東擴**：前 66–前 62 龐培東征米特里達梯，前 64 吞併敘利亞——猶太正好在進軍路線上。
- **地緣位置**：猶太夾在羅馬的敘利亞省與埃及（托勒密）之間，是控制東地中海走廊的關鍵緩衝帶。
- **羅馬的財政**：內戰時代的將軍需要戰利品與貢金養兵——吞併與徵貢是將軍的個人財政。

## 線索與推理 -- 因素咬合

### 線索一：附庸制 = 邊疆治理的外包

羅馬面對廣土眾民，不可能處處設省（設省=派總督+駐軍+行政成本）。於是採用「客戶王／代理統治」（client kingship）：

$$\text{統治成本} = \text{直接統治成本} + \text{鎮壓機率} \times \text{鎮壓成本}$$

代理王制度讓羅馬只付「貢金監督」的低固定成本，把日常治理（收稅、治安、宗教）外包給本地人。問題在於：代理王對羅馬忠誠、對本地卻缺乏正當性——**代理人的正當性赤字**是內建缺陷。

| | 直接設省 | 代理王 |
|---|------|------|
| 羅馬成本 | 高（總督、駐軍） | 低（貢金） |
| 正當性 | 低（外來官員） | 表面高（本地人），實質存疑 |
| 代理風險 | 低 | 高（可能反叛） |
| 前提 | 羅馬化成功 | 當地精英接受 |

### 線索二：希律的結構性弱點

前 37 年安提帕特之子希律以羅馬軍力奪回王位，成了「以東人」出身、靠羅馬刺刀上位的王。他修聖殿（換取宗教正當性）、建港口與堡壘（換取羅馬信任）、重稅養宮廷與貢金——三頭馬車的財政全壓在農民身上。希律越有效率，猶太人越恨他，且越把恨意轉向羅馬：**代理王是仇恨的變壓器，把怨恨集中到帝國**。

### 線索三：宗教與政治的一體性

在猶太傳統中，「王」必須出自大衛、祭司必須出自利未——哈斯蒙尼以祭司稱王已是張力，希律以非猶太血統稱王更是對制度的雙重冒犯。羅馬的代理制只考慮忠誠，不考慮**本地憲法的相容性**：制度錯配（institutional mismatch）不是抽象問題，而是會在六十年後爆炸的火藥。

### 線索四：龐培之後的結局

龐培本人前 48 年死於法沙羅，但他的安排延續了——羅馬的帝國機器比個人長命。許爾堪失去王位只留大祭司；聖殿財寶被運往羅馬凱旋式。猶太第一次學到：神權國家的「至聖所」擋不住軍團，**軍事弱勢＋內部分裂＝被強權定義疆界**。

## 破案時刻

- 前 67–前 63：兩兄弟內戰，先後向龐培申訴。
- 前 63：龐培圍耶路撒冷三月，破城、入聖殿；猶太併入敘利亞體系。
- 前 63–前 37：許爾堪名義統治，安提帕特實權，帕提亞入侵插曲（前 40）。
- 前 37–前 4：希律大帝——代理王制度的高峰與民怨的高峰。

## 後果 -- 改變了什麼

- **政治**：猶太獨立終結；從此六百年（至阿拉伯征服）在羅馬—拜占庭體系內生存。
- **制度**：代理王—總督的混合統治（希律家管王權、羅馬巡撫管軍事稅務），權責不清成為治理災難。
- **宗教**：希律重建聖殿（輝煌但「非大衛之王」所建）——宗教正當性與政治權力的分裂固化。
- **世界史**：耶穌誕生於這個體系下（路加福音的「該撒亞古士督、居里扭報名上冊」）——基督教的故事發生在羅馬代理統治的縫隙裡。

## 因素影響筆記

1. **內部分裂 → 外部介入**：兩兄弟的求援是被吞併的直接觸發——「強權是被請進來的」是邊疆史的通則。
2. **代理統治 → 成本轉移**：羅馬省了行政成本，卻累積了正當性赤字——便宜的統治往往最貴。
3. **制度錯配 → 衝突延遲爆炸**：代理王與猶太宗教憲法不相容，怨恨以彌賽亞運動的形式儲存。
4. **地緣價值 → 統治強度**：猶太位於敘利亞—埃及走廊，其戰略價值使羅馬絕不容許失控——後來的兩次猶太戰爭（[0066-第一次猶太戰爭.md](0066-第一次猶太戰爭.md)）正是這條引信的引爆。
