# 1551-波蘭四議會：猶太自治的頂點

## 案件摘要

十六世紀的波蘭立陶宛聯邦，聚居著當時世界最大的猶太人口（數十萬人）。他們透過「四議會」（Va'ad Arba Aratzot，大波蘭、小波蘭、魯塞尼亞、沃里尼亞四省的代議機構）建立了近代早期歐洲最完整的少數族自治體系：自己收稅、自己立法、自己審案。這樁案件的謎題是：**一個天主教王國，為什麼允許猶太人建立準政府？** 答案藏在成本結構裡——對王室而言，猶太自治是最便宜的統治技術。

## 前因 -- 多因素的局勢

- **移民潮**：黑死病後猶太人東遷，波蘭王室刻意招攸（1264 年卡利什特許狀保障權利）——東歐是「政策性招商」的結果。
- **聯邦的鬆散結構**：波蘭立陶宛貴族共和制（什拉赫塔民主）王權有限，無力直接治理基層。
- **經濟角色**：貴族莊園需要代理人——管理領地（arenda 承包制）、收租、開酒館、經營森林與鹽場。
- **宗教寬容**：1573 年華沙聯盟是歐洲最早的宗教容忍法案之一——多教派並存的聯邦需要先例。
- **既有基礎**：各社群已有的 kehillah（社區自治會）與猶太法庭（beth din），只缺一個協調層。

## 線索與推理 -- 因素咬合

### 線索一：自治 = 徵稅的外包

王室的核心問題不是「喜歡不喜歡猶太人」，而是「怎麼便宜地收到猶太人的稅」。逐戶徵收需要官僚；官僚需要俸祿；還會激起反抗。四議會的解法：**猶太人自己評稅、自己徵收、整批繳庫**：

$$\text{王室淨收入} = \text{稅額} - (\text{徵收成本} + \text{反抗損耗})$$

自治使括號內兩項同時下降。這是制度經濟學的經典解：**把監督成本轉嫁給被統治者的內部網絡**。

### 線索二：四議會的設計

| 機制 | 內容 | 解決的問題 |
|---|---|---|
| 年度大議會 | 各省代表於盧布林/雅羅斯瓦夫集會 | 協調稅額分配 |
| 稅收承包 | 議會認繳總額、內部分攤 | 降低王室徵收成本 |
| 宗教法院 | 各地 beth din 與「四省首席法院」 | 民事糾紛免入基督教法庭 |
| 《平恰斯》議事錄 | 詳錄決議 | 制度記憶與先例 |
| 共同上書 | 對國王集體交涉 | 集體談判能力 |

這是一套**聯邦制**：社群（kehillah）→ 地區議會 → 四議會 → 國王。與同時期歐洲其他地方（驅逐、隔都）相比，波蘭是制度實驗的離群值。

### 線索三：宗教法院 = 法律多元主義

猶太人婚喪、商業、內部糾紛依哈拉卡（猶太律法）裁決，並由王室承認其效力。這不是善意，而是「治理分割」：**每一種臣民歸自己的法管，王權只管收稅與治安**——與鄂圖曼米勒特制度同構，是近代早期帝國的標準技術。

### 線索四：中間人制度的內在張力

猶太人多是貴族莊園的承租代理人——在烏克蘭農民眼中，收租的是猶太人，而地主的保護傘不會延伸到代理人身上。這個結構埋下了 1648 年的炸藥（[1648-赫梅爾尼茨基屠殺.md](1648-赫梅爾尼茨基屠殺.md)）：**自治的繁榮建立在「可被憎恨的位置」上**。

## 破案時刻

- 1515/1551 年代：四議會的運作紀錄（《平恰斯》）開始成形，成為常設機構。
- 1580 年代：議事錄制度化，首席法院（Va'ad 的司法支柱）確立。
- 1764 年：因稅收承包流弊與王權改革，四議會被廢除。

## 後果 -- 改變了什麼

- **猶太社會**：意第緒語、哈拉卡網絡、印刷與教育體系在東歐扎根——後世東歐猶太文化的母體。
- **政治傳統**：代議、分稅、集體談判的經驗，深植於猶太社群的自我治理記憶。
- **人口**：波蘭成為世界猶太人口中心（18 世紀末約佔全球一半）。
- **風險累積**：中間人階層與農民的矛盾持續蓄積。

## 因素影響筆記

1. **王權弱 + 稅收需求 → 外包統治**：自治不是寬容的果實，而是徵稅成本的函數。
2. **內部網絡 = 徵收基礎設施**：社群凝聚力本身成為國家套利的對象。
3. **法律多元主義降低治理成本**：各法各管是前現代多族群的穩定器。
4. **自治繁榮與階級仇恨同構**：中間人的富裕正是農民的帳單——制度的成功與其崩潰是同一枚硬幣。
