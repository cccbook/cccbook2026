# -3000-南島語族大擴散：獨木舟寫成的海洋史詩

## 案件摘要

約西元前 3000 年起，台灣一帶的南島語族（Austronesian）駕獨木舟（或綁木筏）向南擴散——經菲律賓、婆羅洲、蘇拉威西，約前 1500 抵達美拉尼西亞，前 1000 年前後抵玻里尼西亞與馬達加斯加（向西橫越印度洋！）。這是人類史上最大規模的史前遷徙之一：**沒有文字、沒有羅盤，靠星象、浪湧、海鳥，用獨木舟殖民了半個地球的島嶼**。東南亞（印尼、菲律賓、馬來西亞、馬達加斯加）的族群底層，正是這場擴散的後代。

## 前因 -- 多因素的局勢

- **科技**：縫合船板獨木舟（lashed-lug）、蟹爪帆、雙體船——遠洋航行的硬體。
- **資訊**：天文導航（星象羅盤）、浪湧判讀、海鳥與雲相——「無儀器的精密導航」軟體。
- **經濟**：根莖作物套裝（芋頭、山藥、香蕉）＋豬雞狗——「可攜式農業」，登島即種植。
- **人口**：台灣—華南的人口壓力＋海平面穩定後的島嶼空位——擴散的推拉力。

## 線索與推理 -- 因素咬合

### 線索一：語言是「化石 GPS」

南島語系（1,200＋語言，從馬達加斯加到復活節島）的親緣樹，可重建遷徙路徑：

| 語言分支 | 地區 | 分化時間（語言學估計） |
|---|---|---|
| 台灣南島語（九族） | 台灣 | 最深分化（源頭） |
| 馬來—玻里尼西亞語 | 菲律賓→印尼 | 約前 2000 |
| 大洋洲語 | 美拉尼西亞→玻里尼西亞 | 約前 1500–1000 |
| 馬拉加什語 | 馬達加斯加 | 約 500（婆羅洲 Barito 起源！） |

$$\text{遷徙路徑} = \text{語言親緣樹} \cap \text{考古（Lapita 陶器）} \cap \text{基因}$$

**三重證據收斂台灣源頭**——語言學、考古學、基因體學的罕見一致。馬達加斯加人的語言來自婆羅洲——**橫越印度洋的史前航行**，比哥倫布早一千年。

### 線索二：Lapita 陶器——考古的指紋

Lapita 文化（約前 1500–500）： dentate-stamped 陶器從俾斯麥群島擴散至薩摩亞——**陶器紋飾＝遷徙的指紋**。陶器＋馴化動植物套裝＋航海技術——「Lapita 包裝」所到之處，就是南島人到之處。

### 線索三：為何是南島人殖民海洋？——「技術—生態位」匹配

- 地中海—印度洋的季風航路是「來回道」；太平洋的信風＋島鏈是「跳島道」——**不同的海需要不同的船**。
- 南島的蟹爪帆＋雙體船是「逆風性能」最強的史前船型——**技術決定生態位**：誰的船能逆風，誰就擁有太平洋。

## 破案時刻

- 約前 3000：台灣南島語分化、向南擴散開始。
- 約前 2000：抵菲律賓、婆羅洲——馬來—玻里尼西亞語分化。
- 約前 1500：Lapita 文化出現（俾斯麥群島）——大洋洲擴散開始。
- 約前 1000：抵西玻里尼西亞（薩摩亞、東加）。
- 約 500：馬達加斯加殖民（婆羅洲出發、橫越印度洋）。
- 約 1000–1300：抵夏威夷、復活節島、紐西蘭——擴散完成（人類最後的大規模史前殖民）。

## 後果 -- 改變了什麼

- **族群**：印尼、菲律賓、馬來人的祖先——東南亞的「底層作業系統」；馬達加斯加的亞洲血統。
- **農業**：芋、蕉、薯的島嶼農業——東南亞的糧食基礎（稻作是後來的印度—中國輸入）。
- **航海**：季風—信風知識＋造船術——三佛齊、滿者伯夷、馬六甲海權的技術祖先。
- **語言**：世界最大語系之一（以語言數量計）——印尼語、馬來語、他加祿語的同源家族。

## 因素影響筆記

```
人口壓力（推）＋島嶼空位（拉）──→ 南島擴散
蟹爪帆＋雙體船（硬體）×星象導航（軟體）──→ 遠洋能力
可攜農業套裝 ──→ 登島即定居 ──→ 半個地球的島嶼殖民
```

**偵探結語**：南島擴散案件證明：**技術定義人類的邊界**——當船能逆風、導航靠星星，海洋就從屏障變成高速公路。而語言是時間膠囊：馬達加斯加農民口中的詞彙，藏著一千五百年前橫越印度洋的航線圖。
