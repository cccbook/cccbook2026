# 1930-印支共產黨：阮愛國的建黨工程

## 案件摘要

1930 年 2 月，阮愛國（胡志明）在香港—九龍建**越南共產黨**（後改印支共產黨 ICP）——統一三個青年革命組織。此後：1930–31 乂安—河靜蘇維埃（Xo Viet Nghe Tinh，法國鎮壓、死數千）、1930 安沛兵變（國民黨 VNQDD 誅）、1941 越盟（Viet Minh）、1945 八月革命——**印支共產黨是越南獨立戰爭的組織母體**。這樁案件是「列寧式政黨的移植」：**第三國際＋監獄＋農村＝革命機器**。

## 前因 -- 多因素的局勢

- **殖民**：法國米—橡膠剝削（[1862-法國殖民交趾支那.md](1862-法國殖民交趾支那.md)）＋佃租火藥庫＋1929 大蕭條（米價崩、橡膠園裁員）——革命的燃料。
- **思想**：潘佩珠東遊失敗（1908 驅逐）、潘周楨改良死（1926）——**舊民族主義破產**；阮愛國（1911 出洋、1920 法共、1923 莫斯科、1925 廣州青年革命同志會）——第三國際的越南代理人。
- **組織**：1927–29 三個共產小組分裂——1930 九龍統一（共產國際指示＋阮愛國威望）。
- **對手**：VNQDD（學國民黨、城市—軍官）1930 安沛兵變失敗被誅——**非共民族主義的出局**。

## 線索與推理 -- 因素咬合

### 線索一：為何是共產黨贏？——「組織技術的代差」

| | VNQDD（國民黨式） | ICP（列寧式） |
|---|---|---|
| 組織 | 城市—軍官密謀 | 細胞—農村—工會全覆蓋 |
| 紀律 | 鬆散（安沛洩密！） | 民主集中＋清洗 |
| 國際 | 中國國民黨（自身難保） | 共產國際（錢—訓— sommes？不——錢＋訓練＋庇護） |
| 農村 | 無綱領 | 土地革命（打土豪分田地） |

$$\text{革命勝率} = \text{（組織密度）} \times \text{（農村綱領）} \times \text{（國際支援）}$$

**列寧式政黨是「革命的作業系統」**——細胞滲透（廠—村—校—軍）、民主集中（效率）、統戰（越盟的廣泛陣線）。VNQDD 一次兵變洩密即滅；ICP 被鎮壓（1931）後轉入地下—監獄（崑崙島「革命大學」！）——**監獄是幹部的學校**。

### 線索二：乂安—河靜蘇維埃——「早產的革命」

1930.9–1931：乂安—河靜農民蘇維埃（分田、廢稅、婦女會）——法國飛機—外籍兵團鎮壓（死數千、萬人被捕）：

$$\text{1930失敗} = \text{（左傾冒險：共產國際「第三時期」路線）} \times \text{（法軍優勢）} \div \text{（準備不足）}$$

**早產但留下火種**：蘇維埃證明農村動員可行；監獄培養第二代（黎筍、長征！）；阮愛國被共產國際冷藏（1934–38 莫斯科「反省」）——**失敗是學費**。1936 人民陣線（法國 Blum 政府鬆綁）→ 合法期（報紙—工會）→ 1939 再鎮壓 → 1941 越盟（民族陣線包裝！）。

### 線索三：越盟的包裝——「民族遮蓋階級」

1941.5 越盟成立（邊界 Pac Bo）：綱領「反法—反日—獨立」，**不提社會主義**：

$$\text{越盟動員} = \text{（民族主義：全民）} \times \text{（共產黨：核心）} \div \text{（階級語言：隱藏）}$$

**統戰是列寧主義的本土化**：地主—資產階級—教徒（和好教、高台教後來！）皆可入盟——先獨立、後革命的兩階段論。1945 飢荒（二百萬死、日軍徵米！）＋日本投降真空 → 八月革命（[1945-八月革命.md](1945-八月革命.md)）——**越盟的組織網接管全國**。

## 破案時刻

- 1930.2：九龍建黨——三組合一（阮愛國主持）。
- 1930.2：安沛兵變（VNQDD）失敗——非共路線出局。
- 1930.9–1931：乂安—河靜蘇維埃——早產、鎮壓。
- 1931–36：白色恐怖（萬人被捕、崑崙島監獄大學）＋阮愛國莫斯科冷藏。
- 1936–39：人民陣線合法期——報紙工會復甦。
- 1941.5：越盟成立——民族陣線包裝。
- 1944.12：武裝宣傳隊（武元甲 34 人！）——人民軍的種子。

## 後果 -- 改變了什麼

- **越南**：ICP→越盟→1945 建國→1954 奠邊府（[1954-奠邊府.md](1954-奠邊府.md)）→1975 統一（[1975-越南統一.md](1975-越南統一.md)）——三十年戰爭的組織母體。
- **寮柬**：「印支」框架——寮國人民黨（1955）、柬埔寨人民黨的共產國際系譜（＋赤棉的叛變、[1975-赤色高棉.md](1975-赤色高棉.md)）。
- **理論**：農村包圍城市（毛—胡共鳴）——第三世界革命的範本；監獄大學—統戰包裝的技術輸出。
- **代價**：土改（1953–56）擴大化、1956 人文佳品事件——列寧主義的陰暗面（革新 Đổi Mới 1986 的遠因）。

## 因素影響筆記

```
殖民剝削×大蕭條（燃料）＋第三國際（技術）──→ 1930建黨
VNQDD出局（對手死）＋蘇維埃早產（學費）＋監獄大學 ──→ 地下存續
1936合法期 ──→ 1941越盟（民族包裝）──→ 1945接管 ──→ 三十年戰爭
```

**偵探結語**：1930 案件是組織的勝利：**VNQDD 有勇氣，ICP 有系統**——細胞、紀律、統戰、監獄大學，四件套熬死法國人。而越盟的包裝術（民族遮蓋階級）是最高明的本土化：先讓全民一起獨立，再談革命——這一「先」一「後」，走了三十年。
