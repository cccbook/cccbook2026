# 1602-VOC與巴達維亞：股份公司的殖民發明

## 案件摘要

1602 年，荷蘭聯省議會特許**荷蘭東印度公司**（VOC）——**人類史上第一家股份公司＋第一個企業國家**（可鑄幣、訂約、養軍、宣戰）。1619 燕・彼得森・昆（Jan Pieterszoon Coen）夷平雅加達（Jayakarta）、建**巴達維亞**（Batavia）——VOC 總部；壟斷香料（摩鹿加丁香—肉豆蔻：滅絕班達島民 1621！）、爪哇咖啡—蔗糖（Priangan 種植制）。1799 VOC 破產收歸國有、1816 荷屬東印度——**公司殖民 200 年**。這樁案件是「資本主義的殖民發明」：**股東的錢＋國家的槍＝VOC**。

## 前因 -- 多因素的局勢

- **歐洲**：荷蘭獨立戰爭（1568–1648）＋金融革命（阿姆斯特丹交易所 1602）——股份制的發明。
- **亞洲**：葡萄牙稅卡體系（[1511-葡萄牙攻陷馬六甲.md](1511-葡萄牙攻陷馬六甲.md)）的腐朽＋香料暴利——搶奪的動機。
- **爪哇**：馬打蘭（Mataram）蘇丹阿貢（Sultan Agung）圍攻巴達維亞（1628–29 失敗）——本地強權的制衡。
- **技術**：荷蘭造船（fluyt 廉價大運量）＋金融（匯票、保險）——成本優勢。

## 線索與推理 -- 因素咬合

### 線索一：VOC 為何是發明？——「風險的證券化」

| | 葡萄牙王室壟斷 | VOC 股份制 |
|---|---|---|
| 資本 | 王室國庫（有限） | 股東（17 室＋公眾、可增發） |
| 風險 | 國王承擔 | 股東分擔（有限責任！） |
| 期限 | 無限（王室永續） | 特許 21 年（可續） |
| 軍隊 | 王室艦隊 | 公司軍（成本計入損益） |

$$\text{VOC競爭力} = \text{（資本規模} \times \text{風險分散）} - \text{（股息壓力導致的短期掠奪）}$$

**股份制讓殖民可融資**——但股息壓力（年 18%＋分紅！）驅動掠奪式壟斷：班達屠殺（1621，滅島民、代之以奴隸種植肉豆蔻）、丁香樹拔除（壟斷限產）——**資本主義的原罪現場**。

### 線索二：巴達維亞——「運河複製的殖民都市」

昆建巴達維亞：運河網（阿姆斯特丹翻版）＋城牆＋華人區（kapitan 華人甲必丹制）——**殖民都市的種族區隔**：

$$\text{巴達維亞} = \text{（荷人城內）} + \text{（華人城外商區）} + \text{（爪哇—奴隸勞力）}$$

華人（顏永輝？不——林六哥、雷珍蘭等甲必丹）承包稅收、開礦、運輸——**殖民者用華人當中介**（與西班牙菲律賓 Sangley、英屬馬來亞錫礦華工同構）。1740 紅溪慘案（華人屠殺萬人）——**中介族群的周期性清洗**（1998 排華的遠祖）。

### 線索三：種植制的發明——Priangan 咖啡

1720s 起：強制 Priangan（西爪哇）農民種咖啡、定量交售（contingenten）——**強迫種植制的原型**：

$$\text{VOC利潤} = \text{（歐洲咖啡價} - \text{強制收購價）} \times \text{（農民勞役）}$$

**剪刀差的制度化**——此後 Cultivation System（1830–70，[1830-強迫種植制.md](1830-強迫種植制.md)）是放大版。VOC 1799 破產（腐敗＋英法戰爭＋股息掏空）——**掠奪式壟斷的壽命＝香料樹的壽命＋股東的耐心**。

## 破案時刻

- 1602：VOC 特許——股份公司誕生；1605：奪安汶（Ambon）——香料基地。
- 1619：昆夷平雅加達、建巴達維亞——總部。
- 1621：班達屠殺——肉豆蔻壟斷的血腥確立。
- 1628–29：馬打蘭圍攻巴達維亞失敗——本地制衡的極限。
- 1641：奪馬六甲（葡→荷）——海峽稅卡換主人。
- 1740：紅溪慘案——華人屠殺。
- 1799：VOC 解散、收歸國有——公司殖民終結（→荷屬東印度）。

## 後果 -- 改變了什麼

- **資本主義**：股份制＋交易所——現代公司的原型（阿姆斯特丹 1602）；「企業國家」的範本（英國東印度公司學 VOC）。
- **印尼**：巴達維亞→雅加達（首都）；華人甲必丹—中介傳統；種植制傳統（→Cultivation System→今棕櫚油莊園的影子）。
- **族群**：華人中介地位＋周期性排華（1740→1965→1998）——結構性悲劇的起點。
- **全球**：香料降價（胡椒—丁香平民化）→ 歐洲飲食＋藥劑；鬱金香狂熱（1637）同期——金融投機的雙生子。

## 因素影響筆記

```
金融革命（股份制）×香料暴利 ──→ 1602VOC ──→ 1619巴達維亞
                                              ↓
班達屠殺（壟斷）＋Priangan（種植制）──→ 掠奪式利潤 ──→ 腐敗＋戰爭
                                              ↓
                              1799破產 ──→ 荷屬東印度 ──→ 印尼民族主義
```

**偵探結語**：VOC 案件是資本主義的出生證明：**第一家股份公司，第一個企業國家，第一場為股息發動的屠殺**。班達島民的滅絕與阿姆斯特丹股東的分紅，是同一張損益表的兩面——而巴達維亞的運河至今還在——流的是殖民都市的種族區隔，與四百年後的雅加達塞車。
