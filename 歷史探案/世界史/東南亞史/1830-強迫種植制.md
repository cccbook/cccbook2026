# 1830-強迫種植制：爪哇的剪刀差機器

## 案件摘要

1830 年，荷蘭總督凡・登・博施（Van den Bosch）推行**強迫種植制**（Cultivation System, Tanam Paksa）：爪哇農民須將五分之一土地種政府指定經濟作物（甘蔗、咖啡、靛藍）、定價交售——**殖民母國的財政提款機**：1831–77 年為荷蘭國庫貢獻約 8.32 億盾（「有利餘額」batig slot，最高佔荷蘭歲入三分之一！）、還清拿破崙戰爭債務、建荷蘭鐵路。這樁案件是「剪刀差的制度化」：**農民的飢餓＝阿姆斯特丹的鐵路**。

## 前因 -- 多因素的局勢

- **母國**：荷蘭拿破崙戰爭債務（Java Bank？不——國債危機）＋比利時獨立（1830，失南部工業稅基）——財政絕境。
- **殖民地**：爪哇戰爭（Diponegoro 1825–30，花費 2,000 萬盾！）剛結束——**戰爭債務要用爪哇還**。
- **制度**：VOC 種植制遺產（[1602-VOC與巴達維亞.md](1602-VOC與巴達維亞.md)Priangan）＋爪哇封建勞役（bupati 攝政中介）——現成工具。
- **市場**：歐洲蔗糖—咖啡需求＋英廢奴（1833，糖價漲）——剪刀差空間。

## 線索與推理 -- 因素咬合

### 線索一：五分之一的數學——名義 vs 實際

| 名義規定 | 實際執行 |
|---|---|
| 五分之一土地 | 三分之一—二分之一（bupati 加碼） |
| 66 天勞役上限 | 200＋天（蔗糖廠役） |
| 高於市價收購 | 低於成本收購＋運費自付 |
| 免地租（代償） | 地租照收 |

$$\text{農民實際負擔} = \text{名義} \times 2\text{–}3 \quad \text{（中介層層加碼）}$$

**Bupati（本地攝政）＋華人包稅商的中介加碼**——殖民剝削的乘數。1848–50 中爪哇飢饉（死數十萬）——**甘蔗吃掉稻田**。Multatuli《Max Havelaar》（1860）——荷蘭良心文學的控訴（「偷竊合法化」的名言）。

### 線索二：有利餘額——殖民財政的全球史地位

1831–77 batig slot 約 8.32 億盾——**殖民地財政反哺母國的極端案例**：

$$\text{荷蘭工業化資本} = \text{（爪哇剪刀差）} + \text{（國債償還）} + \text{（鐵路投資）}$$

對比：英國印度（財政自給＋「本土費」Home Charges 抽血）、法國印度支那（自給）——**荷蘭是唯一靠殖民地盈餘養母國的帝國**。1870 廢除（自由派＋糖價跌＋《Max Havelaar》輿論）→ 私營種植園時代（ Deli 菸草、蘇門答臘橡膠：契約苦力「豬仔」！）。

### 線索三：倫理政策的迴力鏢——1901 的贖罪與後果

1901 荷蘭女王宣布**倫理政策**（Ethical Policy：灌溉、教育、移民三綱）——贖「剪刀差之罪」：

$$\text{倫理政策} \Rightarrow \text{（荷語學校）} \Rightarrow \text{（印尼知識階層）} \Rightarrow \text{（民族主義）}$$

STOVIL（醫學校）、 Rechtschool（法學校）畢業生：蘇加諾（萬隆理工！）、哈達（鹿特丹經濟！）、沙里爾——**殖民者出錢培養了掘墓人**。1928 青年誓言（一祖國、一民族、一語言：印尼）——倫理學校生的作品。

## 破案時刻

- 1830：Cultivation System 推行——剪刀差機器開工。
- 1831–77：batig slot（8.32 億盾）——荷蘭國債償還＋鐵路。
- 1848–50：中爪哇飢饉——甘蔗 vs 稻米的死亡交叉。
- 1860：《Max Havelaar》出版——輿論轉折。
- 1870：糖業法＋廢除強迫種植——私營種植園時代（契約苦力）。
- 1901：倫理政策——贖罪與迴力鏢（→1928 青年誓言→1945 獨立）。

## 後果 -- 改變了什麼

- **荷蘭**：國債償還＋鐵路＋工業化資本——「爪哇養阿姆斯特丹」半世紀。
- **爪哇**：飢饉＋稻作萎縮＋蔗糖景觀（中爪哇糖廠鐵路網至今）——農業結構的殖民烙印。
- **印尼民族主義**：倫理學校 → 知識階層 → 1928 誓言 → 1945 獨立（[1945-印尼獨立.md](1945-印尼獨立.md)）——迴力鏢的完整軌跡。
- **全球史**：殖民剝削的量化範本（8.32 億盾）——依附理論（dependency）的經典證據。

## 因素影響筆記

```
荷蘭債務絕境（推）×爪哇戰爭債務（引）──→ 1830強迫種植
名義1/5×中介加碼 ──→ 實際1/2＋飢饉 ──→ batig slot 8億盾（母國鐵路）
                                              ↓
Max Havelaar輿論＋自由派 ──→ 1870廢除 ──→ 1901倫理政策 ──→ 培養掘墓人
```

**偵探結語**：強迫種植案件是剪刀差的機器：**名義五分之一，實際二分之一；農民的飢餓，變成阿姆斯特丹的鐵路**——8.32 億盾的帳本至今可查。而最貴的不是錢，是迴力鏢：1901 年的贖罪學校，培養出 1945 年的獨立宣言起草人——殖民者付學費，民族主義者領畢業證。
