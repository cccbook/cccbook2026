# 東南亞史 -- AI 偵探風格

以「推理探案」的方式，追查東南亞三千年的重大轉折：南島擴散、印度化、海峽帝國、吳哥水利、伊斯蘭化、歐洲殖民、民族獨立、冷戰戰爭、東協、金融風暴——
前因是什麼？線索在哪裡？推理如何展開？後果又如何改變了這片群島與半島？

本卷的核心命題只有一句話：**東南亞史是「十字路口的歷史」。**
季風、香料、海峽——地理把這裡變成印度與中國之間的世界通道；通道帶來富裕（收費站帝國），也帶來強盜（殖民者）；本地王國在通道上採購文明（印度化、伊斯蘭化、西方化），再用變異後的版本建國。每個重大事件都是一樁「多因懸案」：偵探的工作，就是把因素鏈一環一環還原出來。

## 因素的回饋迴路

```
              ┌────（季風／氣候：外生衝擊）────┐
              ↓                                ↓
   地理（海峽＋季風）──→ 通道貿易 ──→ 經濟 ──→ 政治 ──→ 組織 ──→ 武器
    │                              ↑        ↑                   │
    │                              │        │                   ↓
    └──→ 科技（航海—火器）←── 資訊 ──┘        心理 ←──────── 心理迴路
              ↑                            ↑
              └── 宗教 ←──（商網信任＋合法性）┘

   正向迴路（加速）：貿易→稅收→紀念碑→合法性→更多貿易
   正向迴路（加速）：殖民→學校→民族主義→獨立→更多學校
   負向迴路（抑制）：收費太狠→客戶派海軍→稅卡易主
   通道迴路（東南亞特有）：咽喉永存→主人輪換→租金照收
```

**偵探的訣竅**：找到「哪個因素先動、哪個因素放大、哪個因素抑制」，把迴路畫出來；再問一句——**這條水道的租金，這次是誰在收？**案件的因果鏈就浮現了。

## 偵探的結案陳詞

三千年的東南亞史，可以壓縮成三條因果鏈：

1. **通道鏈**：季風貿易 → 收費站帝國（三佛齊—馬六甲—新加坡，同一條水道四代主人）→ 殖民搶稅卡（葡—荷—英）→ RCEP 供應鏈——**咽喉永存，主人輪換，租金照收**。
2. **採購鏈**：印度化（梵文—神王）→ 伊斯蘭化（商網—沙里亞）→ 西方化（公司—學校—憲法）——**每一次文明跳躍都是通道上的採購，採購者是本地王權**。
3. **獨立鏈**：日本佔領（打碎舊帝國）→ 1945 真空（十五天建國）→ 冷戰戰爭（越—柬—印尼屠殺）→ 東協（弱連結和平）→ 風暴—政變（可逆的民主）——**獨立是搶來的，民主是租來的，租金按時繳納給歷史**。

三條鏈咬合在一起，就是本卷三十樁案件的全部真相。
