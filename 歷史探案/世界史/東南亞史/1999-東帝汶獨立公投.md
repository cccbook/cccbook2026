# 1999-東帝汶獨立公投：小島的大投票

## 案件摘要

1999.8.30，東帝汶78.5%選民選獨立（44萬登記、98%投票率），親印尼民兵焦土（1400死、30萬流離），9.20澳洲為首INTERFET登陸，2002.5.20獨立——**印尼佔領24年（1975–99）的終局**。前案亞洲金融風暴（見 [1997-亞洲金融風暴.md](1997-亞洲金融風暴.md)）講蘇哈托倒台，後案無——**改革（Reformasi）如何結出一個新國家？一場公投為何要流血？**本案收尾印尼九三〇（見 [1965-印尼九三〇.md](1965-印尼九三〇.md)）的新秩序遺產。

## 前因 -- 多因素的局勢

- **印尼**：1998蘇哈托倒（風暴＋學運）、哈比比接任求合法性（IMF＋美壓）→ 1999.1允公投（自治vs獨立二選一，誤判會贏）。
- **帝汶**：1975印尼入侵（葡萄牙康乃馨後真空）、聖克魯斯屠殺（1991，烙在CNN上）、沙納納古斯芒獄中領導＋主教貝洛（1996諾貝爾獎）——抵抗（武裝—教會—流亡）三軌。
- **國際**：美（克林頓斷軍援壓哈比比）＋澳（霍華德信敦促公投、後出兵）＋葡（前宗主在聯合國死纏）——大國首次一致挺小島。
- **軍方**：印尼陸軍（kopassus）＋民兵（Aitarak、Besi Merah Putih）——公投敗即焦土（Lotus行動預案）。

## 線索與推理 -- 因素咬合

### 線索一：哈比比為何敢賭？——「誤判的算術」

| 哈比比假設 | 實際 |
|---|---|
| 佔領輸血24年（遷移＋基建）換感恩 | 輸血＝殖民記憶（印尼語學校教的是雅加達史） |
| 天主教帝汶（90%）會怕穆斯林多數？不，怕的是兵 | 教會即國家（貝洛主教府＝影子內閣） |
| 自治方案＋威脅（不選自治就放棄）會嚇住人 | 威脅＝送獨立理由 |

$$\text{公投敗} = \text{（24年佔領成本：20萬死）} \div \text{（自治讓步：太晚太少）} \to \infty$$

偵探結論：**1999.1承諾公投時，結局已定**——聖克魯斯（1991）後出生的一代（公投時18–28歲）全是抵抗學校（教會＋游擊電台）畢業。哈比比用半年（1–8月）賭24年，賠率倒掛。

### 線索二：焦土兩週——「敗選者的報復菜單」

9.4宣布結果→民兵屠帝力（主教府、紅十字）、強遷西帝汶30萬、毀75%建築：

$$\text{焦土} = \text{（軍方：保顏面＋滅證）} \times \text{（民兵：分贓終止的憤怒）} \div \text{（國際反應時差：約10天）}$$

9.12克林頓斷軍援＋IMF斷貸威脅、9.15安理會1264號、9.20INTERFET（澳5500＋22國）——**錢比槍快**：雅加達外匯見底（風暴後），美一句斷援即跪。學術理論（Robinson「民兵政治」）：民兵是軍方外包暴力，敗選即外包結算——燒完即散，無人認帳（阿迪謀殺案無罪至今）。

### 線索三：2002獨立—2010s石油詛咒——「自由後的帳單」

UNTAET託管（1999–2002，塞爾吉奧·德梅洛）、2002古斯芒總統—阿爾卡蒂里總理、帝汶海石油（Bayu-Undan＋Greater Sunrise與澳分成）：

$$\text{建國} = \text{（石油基金：挪威模式）} - \text{（2006東部—西部兵變）} - \text{（文官斷層：印尼時代無帝汶人任高官）}$$

2006危機（600死、15萬流離、澳再出兵）證明：**公投 независимости ≠ 國家能力**。2018海界條約（與澳重劃）、石油基金40億護體——小島學會了新加坡（見 [1965-新加坡獨立.md](1965-新加坡獨立.md)）的反面教材：**被迫獨立的新加坡靠人，公投獨立的帝汶靠油**——油會枯，人還在長。

## 破案時刻

- 1975.12：印尼入侵——佔領開幕。
- 1991.11：聖克魯斯屠殺——國際化。
- 1998.5：蘇哈托倒——窗口開。
- 1999.8.30：公投78.5%獨立——定局。
- 1999.9.4–20：焦土—INTERFET——止血。
- 1999–2002：UNTAET託管——建國實習。
- 2002.5.20：獨立——21世紀首個新國家。

## 後果 -- 改變了什麼

- **印尼**：改革CTL...不，改革派甩掉帝汶包袱（年耗數億美元＋外交污點）——民主化少一負資產，多一軍方心結（至今無人為佔領負責）。
- **東協**：2002東帝汶申請加入（至今觀察員）——不干涉原則（見東協案） vs 人道干預的裂縫。
- **國際法**：INTERFET＋UNTAET＋混合法庭（帝汶特別法庭）——科索沃同期的人道干預雙胞胎，R2P（保護責任）的前身演習。
- **帝汶**：石油基金＋葡語—德頓語雙語＋天主教國——東南亞唯一的葡語—天主教國家，葡帝國的最後遺腹子（1512到達、2002斷臍）。

## 因素影響筆記

```
風暴倒蘇哈托 ──→ 哈比比賭公投 ──→ 8.30壓倒獨立 ──→ 9月焦土
                                                  ↓
美斷援＋澳出兵（錢比槍快）──→ INTERFET止血 ──→ UNTAET ──→ 2002獨立
                                                  ↓
                                          石油基金＋2006危機（建國下半場）
```

**偵探結語**：東帝汶用24年證明：**佔領可以買基建，買不到祖國**——印尼修的每條路都通向公投站。1999.8.30那天，44萬人排隊投票，隊伍的长度就是答案的長度。而焦土兩週證明另一句：輸不起的賭徒，會掀桌——幸好這次，桌邊站著拿錢包（IMF）的美國人。
