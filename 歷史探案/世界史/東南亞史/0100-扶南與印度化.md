# 0100-扶南與印度化：季風吹來的文明套裝

## 案件摘要

約 1–6 世紀，湄公河三角洲出現東南亞最早的國家**扶南**（Funan）——中國史書載其「有城郭、宮室、文字、稅法」，混填（Huntian）與柳葉（ Liuye）的建國神話，王都特目（Vyadhapura），吳哥波雷（Oc Eo）是國際港。扶南的真正案件是**「印度化」（Indianization）**：梵文、婆羅門教、佛教、王權神授（devaraja）、曆法、建築——整套印度文明經商人—婆羅門輸入，東南亞從部落社會跳進國家時代。

## 前因 -- 多因素的局勢

- **地理**：季風航路（印度—馬來半島—扶南—中國）的中繼點——Oc Eo 出土羅馬金幣、印度珠飾、中國銅鏡——**世界體系的十字路口**。
- **經濟**：稻作剩餘（湄公河三角洲）＋轉口貿易稅——國家的財政雙引擎。
- **資訊**：婆羅門（祭司—學者—顧問）隨商船而來——「識字＋曆法＋王權理論」的攜帶者。
- **政治**：部落聯盟需要超部落權威——印度王權理論恰好是現成答案。

## 線索與推理 -- 因素咬合

### 線索一：印度化是「自助餐」，不是征服

關鍵證據：**沒有印度軍隊殖民東南亞的任何記錄**——印度化是本地統治者的主動採購：

| 輸入組件 | 本地用途 |
|---|---|
| 梵文 | 王室銘文、行政文書 |
| Devaraja（神王） | 超部落王權的合法性 |
| 婆羅門祭司 | 宮廷儀式＋曆法＋顧問 |
| 佛教 | 商人網絡＋庶民宗教 |
| 建築（磚塔） | 權力的永久展示 |

$$\text{印度化程度} = \text{（貿易富裕度）} \times \text{（統治者的採購意願）}$$

**誰有錢、誰買**——扶南、占婆、 later 吳哥、蒲甘，買的是同一套菜單。這與日本的大化革新（唐制採購）同構——**前近代的文明跳躍都是「採購式現代化」**。

### 線索二：混填神話——「外來者的合法性」

扶南神話：外來婆羅門混填娶本地龍女柳葉、建國——**神話本身就是印度化的寓言**：外來（印度）＋本地（龍／水）的結合生出王權。吳哥、占婆、爪哇皆有類似「外來聖者＋本地公主」神話——**神話是採購行為的收據**。

### 線索三：Oc Eo——世界體系的證據

Oc Eo 遺址：羅馬安東尼王朝金幣、印度紅玉髓珠、中國東漢銅鏡、波斯風玻璃——**一座港口同時連接羅馬、印度、中國**：

$$\text{扶南國力} = \text{（三角洲稻作）} + \text{（轉口稅} \times \text{季風貿易量）}$$

6 世紀真臘（Chenla）興起、扶南衰落——**貿易路線與灌溉中心的轉移**（吳哥的伏筆、[0802-吳哥帝國.md](0802-吳哥帝國.md)）。

## 破案時刻

- 約 1 世紀：扶南立國（混填神話）；3 世紀范旃遣使孫吳——進入中國史書。
- 243–245：康泰、朱應出使扶南（《吳時外國傳》）——最早的詳細記錄。
- 4–5 世紀：僑陳如（Kaundinya）系王統——印度化深化；Oc Eo 全盛。
- 6 世紀末–7 世紀初：真臘攻滅扶南——湄公河中心的轉移。

## 後果 -- 改變了什麼

- **政治**：東南亞國家時代的開幕——神王（devaraja）理論成為此後一千年的王權範本。
- **宗教**：婆羅門教＋佛教的雙軌——上座部佛教（蒲甘、暹羅）與大乘（爪哇、越南）的分流起點。
- **文字**：梵文—帕拉瓦字母 → 高棉文、爪哇文、緬文、泰文的祖先——東南亞文字的共同源頭。
- **貿易**：季風貿易網的確認——三佛齊（[0670-三佛齊的海峽帝國.md](0670-三佛齊的海峽帝國.md)）、馬六甲（[1405-馬六甲海峽帝國.md](1405-馬六甲海峽帝國.md)）的同一條水道。

## 因素影響筆記

```
季風貿易（富裕）＋婆羅門攜帶（供給）──→ 本地統治者採購印度套裝
                                                    ↓
神王合法性＋梵文行政＋港口稅收 ──→ 扶南（1–6 世紀）──→ 真臘取代
                                                    ↓
                                        印度化範本 → 吳哥、蒲甘、爪哇
```

**偵探結語**：扶南案件的真相是：**文明可以批發**——沒有一兵一卒，整套印度國家技術經由商船與祭司上架，本地國王刷卡買單。Oc Eo 的羅馬金幣證明：早在羅馬帝國時代，東南亞已是世界體系的收銀台。
