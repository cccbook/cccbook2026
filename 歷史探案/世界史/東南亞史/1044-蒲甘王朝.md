# 1044-蒲甘王朝：萬塔之城的上座部革命

## 案件摘要

1044 年，阿奴律陀（Anawrahta）統一蒲甘（Pagan）——此後兩百年：征服直通（Thaton，1057 得巴利三藏）、上座部佛教定為國教、建造**萬座佛塔**（蒲甘平原 2,000＋遺存）、烏茲那（1256 建太陽宮般的寺院）。1287 忽必烈蒙古軍入侵（元緬戰爭 1277–1287）、蒲甘崩潰。這樁案件是「宗教改革的國家工程」：**用上座部佛教統一緬族—孟族—撣族**，以及萬塔的剩餘經濟學。

## 前因 -- 多因素的局勢

- **地理**：伊洛瓦底江中游乾燥區——灌溉（堰＋水庫）＋江運的樞紐。
- **宗教**：直通（孟族）的大乘—上座部混合 vs 蒲甘的阿利（Ari，密教—泛靈混合）——阿奴律陀選上座部（「淨化」敘事）。
- **資訊**：1057 得巴利三藏（Tipitaka）＋僧團——**正統文本＋正統僧團的進口**。
- **外部**：宋—印度洋貿易＋馬蹄銀（ Oh？不——蒲甘的對外貿易）——寺院經濟的資金。

## 線索與推理 -- 因素咬合

### 線索一：為何選上座部？——「正統的壟斷」

阿奴律陀滅阿利僧（沒收寺產）、迎三藏——表面是信仰淨化，實質是**宗教市場的國有化**：

$$\text{統治效率} = \text{（單一正統）} \div \text{（教派數量）}$$

上座部（巴利語、戒律嚴明、僧團科層）比阿利（密教、泛靈、分散）**更適合當國家機器**：僧團＝識字官僚的儲備、寺院＝地方行政網、功德＝稅收的宗教包裝（捐地給寺院＝功德＋避稅的雙重動機——與歐洲修道院、日本莊園寄進同構！）。

### 線索二：萬塔的經濟學——功德的通貨膨脹

蒲甘兩百年建萬塔——國王、貴族、富人競相捐建（功德＋避稅＋展示）：

$$\text{建塔動機} = \text{（功德）} + \text{（免稅莊園）} + \text{（地位展示）}$$

後果：**寺院領地膨脹到佔全國耕地三分之一以上**（烏茲那時期）——**免稅黑洞**（日本奈良寺院問題的翻版！）。王室財政被功德掏空——**虔誠的財政自殺**。1287 蒙古入侵只是最後一擊，財政早被佛塔掏空。

### 線索三：蒙古入侵——「大象 vs 騎兵」的體系戰

1277 牙嵩關之戰（緬軍戰象＋蒙古騎射）、1283–87 蒙古史天澤—雲南軍攻入蒲甘——**熱帶步象軍 vs 大陸騎兵＋火器**：

$$\text{蒲甘戰敗} = \text{（財政空洞）} \times \text{（戰術代差）} \times \text{（撣族離心）}$$

國王 Narathihapate（「逃跑王」）棄城——蒲甘崩潰，撣族小邦並立（阿瓦、卑謬的前奏）。但蒙古未久留——**熱帶疾病＋補給線是蒙古的上限**（與越南陳朝抗元同理）。

## 破案時刻

- 1044：阿奴律陀即位——統一戰爭開始。
- 1057：征服直通——得三藏、上座部定國教。
- 12–13 世紀：萬塔建造期（阿南達寺 1105、達瑪央吉 1167、蘇拉瑪尼 1183）。
- 1256–87：烏茲那（Narathihapate）——寺院領膨脹頂點。
- 1277–87：元緬戰爭——蒲甘崩潰。
- 1364：阿瓦王朝——緬族重建（蒲甘遺產的繼承）。

## 後果 -- 改變了什麼

- **宗教**：上座部佛教定為緬甸國教——至今（僧團 Sangha 的政治力量：2007 番紅花革命、2021 政變後的僧侶動員）。
- **文字**：緬文（巴利—孟文系）——蒲甘碑銘是緬語文學的起點。
- **建築**：蒲甘萬塔——世界級遺產（UNESCO 2019）；「功德通膨」的財政教訓。
- **政治**：伊洛瓦底江統一範本——阿瓦、東吁（[1510-東吁王朝.md](1510-東吁王朝.md)）、貢榜的同一條路。

## 因素影響筆記

```
伊洛瓦底樞紐（地理）×三藏進口（資訊）──→ 1044蒲甘 ──→ 上座部國教化
                                                    ↓
功德＋避稅＋展示 ──→ 萬塔（剩餘紀念碑化）──→ 寺院領1/3（財政黑洞）
                                                    ↓
                        蒙古入侵（1287）──→ 崩潰 ──→ 阿瓦重建
```

**偵探結語**：蒲甘案件是虔誠的資產負債表：**功德是無限的，耕地是有限的**——當三分之一耕地免稅，帝國的財政就死了。蒙古人只是來宣讀訃告的；而萬座佛塔至今矗立——證明剩餘可以變成永恆，永恆養不活國家。
