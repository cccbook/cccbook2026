# 工業革命史 -- AI 偵探風格

以「推理探案」的方式，追查工業革命的重大轉折：為什麼是英國？為什麼是 1760–1850？蒸汽、鋼鐵、鐵路、電力、石油、汽車、流水線、電晶體如何一環扣一環？
前因是什麼？線索在哪裡？推理如何展開？後果又如何改變了整個世界？

本卷的核心命題只有一句話：**工業革命不是「發明的列表」，而是「成本曲線連鎖崩跌」的案件。**
能源成本崩跌 → 動力普及 → 交通成本崩跌 → 市場規模放大 → 分工深化 → 製造成本崩跌 → 資訊成本崩跌 → 協調半徑放大 → 下一輪成本崩跌。每個發明都是一條線索，真正的兇手是「正反饋迴路」。

（涵蓋：紡織機械化、蒸汽動力、焦炭煉鐵、鐵路、電報、鋼鐵、石油、電力、化工、汽車、飛機、科學管理、流水線、電晶體、微處理器、精實生產、AI；以及作業系統層：股份制、專利版權、貿易航海法、貨幣秩序、央行管制、社保環保、數據法）

## 工業革命的五條主軸

| 主軸 | 機制 | 經典案例 |
|------|------|----------|
| **能源成本** | 動力從肌肉→水力→蒸汽→電力→石油，每一步都改寫「什麼是可能的」 | 紐科門→瓦特→發電廠→內燃機 |
| **材料成本** | 熟鐵→鋼→合金→塑膠→半導體，材料決定機器的上限 | 攪拌法→貝塞麥→平爐→電爐 |
| **運輸成本** | 運費崩跌使市場規模從地方變成全球，分工得以深化 | 運河→鐵路→汽船→貨櫃→飛機 |
| **資訊成本** | 協調半徑決定組織規模，資訊越便宜，工廠與市場越大 | 電報→電話→電腦→網路 |
| **組織技術** | 工廠、公司、流水線、品管——「怎麼組織人」本身就是技術 | 工廠制→泰勒制→福特制→豐田制 |

## 成本崩跌的回饋迴路

```
   煤（廉價能源）──→ 蒸汽機 ──→ 礦場排水更深 ──→ 更多更便宜的煤
      │                  │
      ↓                  ↓
   焦炭煉鐵 ──→ 便宜鐵 ──→ 鐵路 ──→ 運費崩跌 ──→ 市場規模↑
      │                                      │
      ↓                                      ↓
   鋼（貝塞麥）──→ 機器工具 ──→ 分工深化 ──→ 製造成本崩跌
                                              │
   資訊（電報）──→ 協調半徑↑ ──→ 更大組織 ────┘
      │
      ↓
   電力／石油 ──→ 第二波迴路（汽車、化工、家電）
      │
      ↓
   半導體 ──→ 第三波迴路（電腦、網路、AI）

   正向迴路：成本↓→需求↑→規模↑→學習曲線→成本再↓
   負向迴路：污染、工傷、壟斷、失業 → 社會立法與反托拉斯（抑制）
```

**偵探的訣竅**：每次問「為什麼是這裡、為什麼是此時」，答案永遠是多因素咬合——燃料、材料、市場、金融、法律、勞動力、資訊，缺一不可。單一發明從不成案，成案的是迴路。

## 案件卷宗（歷史年表）

### 一、前傳：為什麼是英國（1500–1760）

- 16世紀：圈地運動——自耕農變成「無產可賣、只剩勞動力」的雇工（勞動力市場的誕生）。
- 1600–1602：東印度公司（英、荷）——海外市場與棉布競爭的壓力（「為什麼要機械化紡織」的第一因）。
- 1688：光榮革命；1694：英格蘭銀行——可信承諾＋國債＋低利率（資本成本崩跌）。
- 1709：達比（Abraham Darby）焦炭煉鐵——木炭危機的替代方案（森林耗盡→煤）。［[1709-達比焦炭煉鐵.md](1709-達比焦炭煉鐵.md)］
- 1712：紐科門大氣蒸汽機——礦場排水的「吃煤怪獸」。［[1712-紐科門大氣蒸汽機.md](1712-紐科門大氣蒸汽機.md)］
- 1733：凱伊（John Kay）飛梭——織布快過紡紗，「紗荒」誕生。［[1733-飛梭與紗荒.md](1733-飛梭與紗荒.md)］
- 1761：布里奇沃特運河通航＋運河狂熱——內陸運費先崩跌一輪，市場規模第一次放大。［[1761-運河狂熱.md](1761-運河狂熱.md)］

### 二、第一次工業革命：紡織＋蒸汽＋鐵（1760–1840）

- 1764：哈格里夫斯珍妮紡紗機——一機多錠。［[1764-珍妮紡紗機.md](1764-珍妮紡紗機.md)］
- 1769：阿克萊特水力紡紗廠（克羅姆福德）——「工廠制」的誕生；同年瓦特改良蒸汽機獲專利。［[1769-瓦特蒸汽機.md](1769-瓦特蒸汽機.md)］
- 1776：亞當·斯密《國富論》——分工與市場規模的理論（「分工受市場規模限制」）。
- 1779：克朗普頓走錠紡紗機（結合珍妮＋水力機）——細紗能與印度布競爭。
- 1785：卡特萊特動力織布機——紗多布少，瓶頸漂移到織布，外行牧師的動作分解。［[1785-卡特萊特動力織布機.md](1785-卡特萊特動力織布機.md)］
- 1784：考特（Henry Cort）攪拌法＋軋輥——熟鐵量產，鐵價崩跌。［[1784-攪拌法煉鐵.md](1784-攪拌法煉鐵.md)］
- 1785：卡特萊特動力織布機——蒸汽進入織布。
- 1793：惠特尼軋棉機——美國南方棉花供給爆炸（與奴隸制的黑暗合流）。［[1793-軋棉機.md](1793-軋棉機.md)］
- 1799：法國封存檔案米——公制與度量衡標準，可互換零件的源頭。［[1799-公制與度量衡標準.md](1799-公制與度量衡標準.md)］
- 1810：莫茲利機床工坊——溜板車床與可互換零件，「製造機器的機器」。［[1810-機床與可互換零件.md](1810-機床與可互換零件.md)］
- 1800：博爾頓–瓦特蒸汽機累計銷售 500 台——旋轉動力進入各行各業。
- 1804：特里維西克蒸汽機車——鐵軌上的蒸汽動力。［[1804-蒸汽機車的誕生.md](1804-蒸汽機車的誕生.md)］
- 1807：富爾頓「克萊蒙特號」汽船——河流運輸不再靠天（風）吃飯。［[1807-汽船時代.md](1807-汽船時代.md)］
- 1811–1816：盧德運動——機器破壞者的「技術性失業」抗議。［[1811-盧德運動與技術性失業.md](1811-盧德運動與技術性失業.md)］
- 1825：斯托克頓–達靈頓鐵路通車——鐵路時代開啟。［[1825-鐵路時代開啟.md](1825-鐵路時代開啟.md)］
- 1830：利物浦–曼徹斯特鐵路（客貨兩用＋時刻表）——現代鐵路的模板。［[1830-利物浦曼徹斯特鐵路.md](1830-利物浦曼徹斯特鐵路.md)］
- 1833：《工廠法》——童工、工時的國家干預（負反饋迴路啟動）。［[1833-工廠法與勞工.md](1833-工廠法與勞工.md)］
- 1837：戶籍統計與現代國家——GRO 強制登記＋Farr 生命表，社保精算的地基。［[1837-戶籍統計與現代國家.md](1837-戶籍統計與現代國家.md)］
- 1844：《銀行特許法》（皮爾法案）——金本位與中央銀行的制度化。

### 三、鐵路＋電報：距離的死亡（1830–1870）

- 1837：惠斯通–庫克電報；1844：莫爾斯「上帝創造了何等奇事！」——資訊成本崩跌。［[1844-電報革命.md](1844-電報革命.md)］
- 1840年代：鐵路狂熱（英國國會批准上千英里）——泡沫＋路網的雙面性。［[1845-鐵路狂熱與泡沫.md](1845-鐵路狂熱與泡沫.md)］
- 1846：英國廢《穀物法》——自由貿易時代（鐵路＋汽船使美國穀物可進口）。
- 1848：《共產黨宣言》——對工廠制的理論反擊。
- 1851：倫敦萬國博覽會（水晶宮）——「世界工廠」的加冕典禮，也是德美追趕的起跑槍。［[1851-萬國博覽會.md](1851-萬國博覽會.md)］［[1851-水晶宮萬國博覽會.md](1851-水晶宮萬國博覽會.md)］
- 1856：貝塞麥轉爐煉鋼法——鋼價崩跌，鐵路、橋梁、船艦換材料。［[1856-貝塞麥煉鋼法.md](1856-貝塞麥煉鋼法.md)］
- 1858：第一條大西洋海底電纜（短暫成功）；1866：永久開通——全球資訊網的前身。
- 1858：倫敦大惡臭與下水道工程——外部性內部化，公共衛生國家的硬體誕生。［[1858-倫敦大惡臭與公共衛生法.md](1858-倫敦大惡臭與公共衛生法.md)］
- 1859：德雷克賓州油井——石油時代開啟。［[1859-石油時代開啟.md](1859-石油時代開啟.md)］
- 1860年代：西門子–馬丁平爐煉鋼——優質鋼量產。
- 1867：諾貝爾炸藥專利——礦山、鐵路、戰爭同時提速。
- 1869：蘇伊士運河通航＋美國橫貫大陸鐵路貫通——全球運費再崩跌。［[1869-蘇伊士運河.md](1869-蘇伊士運河.md)］
- 1869：橫貫大陸鐵路（普羅蒙特里）——美國大陸市場規模一體化。

### 四、第二次工業革命：鋼鐵＋電力＋化工（1870–1914）

- 1870年代：德國、美國以關稅＋技術教育追趕英國——「後發優勢」。
- 1876：貝爾電話——聲音进入電線。［[1876-電話.md](1876-電話.md)］
- 1879：愛迪生白熾燈；1882：珍珠街發電站——電力網的誕生。［[1879-白熾燈與電力網.md](1879-白熾燈與電力網.md)］
- 1880年代：拜耳、巴斯夫——合成染料與化工巨頭（實驗室進入工廠）。
- 1886：賓士專利汽車——內燃機上路。［[1886-汽車誕生.md](1886-汽車誕生.md)］
- 1888：特斯拉交流電系統（電流戰爭）——遠距輸電使工廠擺脫河流與煤堆。［[1888-交流電大戰.md](1888-交流電大戰.md)］
- 1890：《謝爾曼反托拉斯法》——對壟斷的負反饋。
- 1895：倫琴 X 光；1896：馬可尼無線電——新頻譜的開啟。
- 1903：萊特兄弟基蒂霍克首飛——第三維度的運輸。［[1903-飛機.md](1903-飛機.md)］
- 1908：福特 T 型車上市；1913：海蘭公園流水線——汽車價格崩跌。［[1913-福特流水線.md](1913-福特流水線.md)］
- 1911：泰勒《科學管理原理》——動作研究與計時。［[1911-泰勒科學管理.md](1911-泰勒科學管理.md)］
- 1914–1918：一戰——化工（炸藥、毒氣）、汽車、飛機的軍事加速器。

### 五、大量生產與消費社會（1914–1970）

- 1920年代：美國「咆哮的二十年代」——汽車、家電、收音機的分期付款消費。
- 1929–1933：大蕭條——需求崩潰暴露「生產過剩」的迴路斷裂。
- 1930年代：杜邦尼龍（1935）、聚乙烯——塑膠時代。
- 1936：胡佛水壩——巨型公共工程的模板。
- 1939–1945：二戰——雷達、青黴素量產、原子彈（曼哈頓計畫：國家主導研發的頂點）。
- 1947：貝爾實驗室電晶體——半導體時代的種子。［[1947-電晶體.md](1947-電晶體.md)］
- 1950年代：貨櫃革命（麥克萊恩，1956）——海運成本再崩跌一個數量級。［[1956-貨櫃革命.md](1956-貨櫃革命.md)］
- 1956：英國卡爾德霍爾核電站——民用核能開端。
- 1958：積體電路（基爾比、諾伊斯）——電晶體的規模化。［[1958-積體電路.md](1958-積體電路.md)］
- 1960年代：石化＋高速公路（美國州際公路）——郊區化與汽車社會完成體。
- 1969：阿波羅登月——系統工程的頂點展示。

### 六、第三次工業革命：半導體＋網路（1970–2010）

- 1971：英特爾 4004 微處理器——電腦進入晶片。［[1971-微處理器.md](1971-微處理器.md)］

- 1974：淡馬錫與主權工業資本——控股隔離馴服政治之手，產業政策的資本版。［[1974-主權基金與工業政策.md](1974-主權基金與工業政策.md)］
- 1970–1980年代：豐田生產方式（JIT、看板、品管圈）——「精實」的組織革命。［[1980-豐田生產方式.md](1980-豐田生產方式.md)］
- 1981：IBM PC——個人電腦標準化。
- 1989–1991：全球資訊網（伯納斯-李）——資訊成本趨近於零。［[1989-全球資訊網.md](1989-全球資訊網.md)］
- 1995：瀏覽器大戰（網景 vs 微軟 IE）——入口之爭點燃網路股時代。［[1995-瀏覽器大戰.md](1995-瀏覽器大戰.md)］
- 1990年代：全球供應鏈（中國＋貨櫃＋網路）——「世界工廠」的轉移。
- 1992：卡德伯里報告——獨董＋審計委員會＋遵守或解釋，公司治理的全球模板。［[1992-卡德伯里公司治理.md](1992-卡德伯里公司治理.md)］
- 1998：歐洲央行開張——條約鎖死獨立性，保守央行家的頂點。［[1998-歐洲央行治理.md](1998-歐洲央行治理.md)］
- 2002：SOX 與審計獨立——CEO 具名＋404 內控，安隆後的信任重建。［[2002-SOX與審計獨立.md](2002-SOX與審計獨立.md)］
- 1997：IBM 深藍擊敗卡斯帕羅夫——AI 的第一次宣言。
- 2007：iPhone——運算＋通訊＋感測的三合一（行動網路時代）。［[2007-iPhone與行動革命.md](2007-iPhone與行動革命.md)］

### 七、第四次工業革命：AI 與智慧製造（2010–）

- 2012：AlexNet——深度學習引爆點（GPU＋大數據＋演算法的咬合）。［[2012-AlexNet與深度學習.md](2012-AlexNet與深度學習.md)］

### 八、制度、金融與法律：迴路的作業系統（1474–2018）

機器 gente 改變成本，制度決定「誰敢投資、誰能交易、誰負責任」。以下三組案件是工業革命的作業系統層：

**甲、公司與資本動員**
- 1602：荷蘭東印度公司（VOC）——永久股本＋阿姆斯特丹交易所，陌生人合資的誕生。［[1602-東印度公司與股份制.md](1602-東印度公司與股份制.md)］
- 1694：英格蘭銀行——國債＋可信承諾，資本成本崩跌。［[1694-英格蘭銀行與國債.md](1694-英格蘭銀行與國債.md)］
- 1720：南海泡沫——債轉股的正反饋失控，泡沫動力學的第一課。［[1720-南海泡沫.md](1720-南海泡沫.md)］
- 1855：有限責任法——陌生人合資的風險上限鎖死，經理人階層誕生。［[1855-有限責任法.md](1855-有限責任法.md)］

**乙、專利、版權與產權**
- 1474：威尼斯專利法——新穎＋公開＋十年保護，創新的第一份保險單。［[1474-威尼斯專利法.md](1474-威尼斯專利法.md)］
- 1624：壟斷法（Statute of Monopolies）——專利與尋租的分界線。［[1624-壟斷法與專利制度.md](1624-壟斷法與專利制度.md)］
- 1710：安妮法令——作者本位的版權，出版商壟斷的終結。［[1710-安妮法令.md](1710-安妮法令.md)］

## 卷尾：工業革命的偵探總結

1. **沒有單一發明**：每個「偉大發明」都是成本迴路的一個節點——蒸汽機需要煤礦，煤礦需要蒸汽排水；鐵路需要便宜鐵，便宜鐵需要焦炭；缺一不可。
2. **英國的偶然與必然**：高工資＋廉價煤＋殖民地市場＋光榮革命後的低資本成本——四個因素在英格蘭同時咬合（艾倫的「高工資經濟」命題）。
3. **學習曲線是真正的兇手**：$$C_n = C_1 \cdot n^{-b}$$——累積產量每翻一倍，成本下降固定比例（ Wright 定律）。所有成本崩跌的數學骨架都是這一條。
4. **運輸與資訊是放大器**：市場規模決定分工深度（斯密定理）——鐵路、汽船、電報、貨櫃、網路，每一次都是市場規模的階躍。
5. **組織本身就是技術**：工廠制、泰勒制、福特制、豐田制——「怎麼組織人」的創新與機器同等重要，且更難複製。
6. **負反饋不可少**：工廠法、工會、反托拉斯、環保法——抑制迴路使系統可持續，否則革命會吃掉自己的合法性。
7. **追趕者的劇本**：德、美、日、韓、中——後發者用「國家＋教育＋技術引進」複製迴路，英國的劇本被重演了五次。
8. **迴路仍在轉**：鋰電池、太陽能、AI——成本崩跌的數學沒有變，變的只是主角。下一樁案件正在發生。
