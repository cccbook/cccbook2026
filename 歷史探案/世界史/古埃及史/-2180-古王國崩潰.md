# 前2180年-古王國崩潰：氣候、饑荒與離心離德的多因案件

## 案件摘要
第六王朝末（約前2180年），延續五百年的金字塔國家轟然解體，埃及墜入第一中間期的分裂。沒有單一兇手：4.2ka 氣候事件拉低尼羅河水位釀成饑荒，諾姆長世襲掏空中央稅基，佩皮二世超長統治後的繼承真空點燃引信。三刀齊下，法老從神跌落為凡人。

## 前因 -- 多因素的局勢
- **氣候**：全球 4.2ka 事件（約前2200–前2100）：東非季風減弱，尼羅河源頭降水銳減，氾濫連年失敗；古氣候（冰芯、湖芯、尼羅三角洲沉積）與文獻互證。
- **經濟**：低水位→糧食歉收→王室糧倉無糧可賑；安赫提菲（Ankhtifi）墓自傳：「全上埃及都在挨餓，我給了北方大麥」，地方豪強取代中央成為救濟者。
- **政治**：第六王朝起諾姆長（nomarch）由任命轉世襲，地方王朝（如埃德富、底比斯）自建軍隊、稅收與墓葬，中央政令不出孟菲斯；佩皮二世（Pepi II）在位約 90 年（約前2278–前2184，學界最長統治說，今多取約 60–90 年之約數），超長統治堵塞晉升、積壓繼承矛盾。
- **宗教**：神廟地產免稅膨脹（王室為換取合法性不斷賞賜），王室財政失血；饑荒中法老求雨無應，「神王失靈」敘事蔓延。
- **軍事**：中央無力供養邊軍，努比亞、利比亞邊疆鬆動，地方豪強武裝割據。
- **社會**：《能言善辯的農夫》《伊普味陳辭》（Admonitions of Ipuwer，成文或晚至中王國，反映崩潰記憶）：「窮人成富人，富人成流浪者」，秩序（瑪阿特）顛倒的文學回聲。
- **技術**：灌溉依賴中央協調修堤，中央癱瘓則水利失修，歉收—失修惡性循環。

## 線索與推理 -- 因素咬合

### 線索1：4.2ka 事件——全球共犯
美索不達米亞阿卡德帝國崩潰、印度河城市衰落與埃及古王國終結同步於前2200年前後。古氣候學（Faiyum 湖芯水位、Kilimanjaro 冰芯塵埃、三角洲沉積鹽度）顯示降水驟降 20–30%。尼羅河洪水記錄模型：

$$\text{東非季風} \downarrow \to \text{青、白尼羅流量} \downarrow \to \text{氾濫高度} < 閾值 \to \text{盆地無水} \to \text{歉收}$$

| 氾濫高度（象島尼羅尺） | 後果 |
|----------------------|------|
| >7 公尺 | 豐年 |
| 5–7 公尺 | 平年 |
| <5 公尺 | 饑荒（古王國末連年低於此線） |

### 線索2：諾姆長世襲——財政被掏空
第六王朝諾姆長墓（如阿斯旺庫貝特·哈瓦 Qubbet el-Hawa）規模直追王墓，自稱「世襲親王」，稅收截留本地。財政社會學公式：中央收入＝總剩餘×汲取率，世襲使汲取率從中央轉向地方，王室陷入「有天下之名、無天下之稅」。

$$\text{諾姆長世襲} \to \text{稅收截留} \to \text{王室糧倉見底} \to \text{無力賑災} \to \text{合法性崩盤}$$

### 線索3：神廟免稅——影子政府的蛀蝕
王室為買祭司支持，大量頒布免稅敕令（第六王朝科普托斯敕令 Coptos Decrees 尚存）：神廟地產、祭品、勞役豁免。負反饋迴路：

```
王室收入↓ → 更需祭司背書 → 更多免稅賞賜 → 王室收入↓↓
```

祭司—影子政府命題：崩潰前夜，神廟是唯一有糧的組織，饑民投奔神廟，王權被架空。

### 線索4：佩皮二世的超長統治——繼承堰塞湖
在位約九十年意味兩代精英老死任上，王子熬成老臣仍未即位；駕崩後繼承者皆高齡短命（曼涅托記第七王朝「七十王在七十天」雖誇張，卻是記憶的變形）。政治學「 succession crisis」模型：超穩定→超脆弱，一死即雪崩。

## 破案時刻
- 約前2278年：佩皮二世幼年即位（傳 6 歲登基），長期統治開始，矛盾堰塞。
- 約前2200–前2150年：4.2ka 事件高峰，尼羅河連年低水位，安赫提菲自稱賑濟上埃及。
- 約前2184–前2181年：佩皮二世去世，孟菲斯王權速朽，第七、八王朝名存實亡。
- 約前2181–前2055年：第一中間期：赫拉克雷奧波利斯（九、十王朝） vs 底比斯（十一王朝前身）南北對峙，地方文學（《農夫》《伊普味》）書寫崩潰創傷。
- 約前2055年：曼圖霍特普二世再統一（見下一篇），古王國正式結案。

## 後果 -- 改變了什麼
- **政治**：中央集權神話破滅，中王國改行「強幹弱枝＋地方制衡」的新集權術。
- **經濟**：地方糧倉—市場興起，中央壟斷再分配的舊模式終結。
- **宗教**：奧西里斯信仰普及（人人可求死後審判），王室壟斷來世的時代結束；「瑪阿特失序」成為政治批判語言。
- **技術**：地方灌溉自主化，小型水利技術擴散。
- **教訓**：埃及史第一個「崩潰三件套」樣本——氣候×財政×繼承，後世中王國、新王國崩潰皆是翻版。

## 因素影響筆記
1. 4.2ka 季風減弱 → 尼羅河低水位連年 → 歉收饑荒 → 中央無糧可賑。
2. 諾姆長世襲＋截留 → 中央稅基流失 → 救災與水利失能。
3. 神廟免稅膨脹 → 王室財政失血 → 饑民投奔神廟 → 影子政府取代王權。
4. 佩皮二世超長統治 → 繼承堰塞湖 → 駕崩即權力真空 → 地方割據公開化。
5. 饑荒＋失序敘事 → 「神王失靈」→ 第一中間期分裂與文學創傷記憶。
