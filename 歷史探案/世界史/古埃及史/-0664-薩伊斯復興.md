# -0664-薩伊斯復興：普薩姆提克一世、希臘雇傭兵與晚期復興的多因案件

## 案件摘要
前664年，亞述扶植的薩伊斯小王普薩姆提克一世（Psamtik I，約前664–前610）借亞述內亂與希臘—卡里亞雇傭兵，十年間一統埃及，開創第二十六王朝——史稱薩伊斯復興，埃及最後的本土榮光。本案無單一英雄，真兇是亞述霸權鬆動、愛琴雇傭兵市場成形、以及薩伊斯家族三代經營三角洲三因咬合。

## 前因 -- 多因素的局勢
- **政治**：亞述洗劫底比斯（前663）後以夷制夷，立尼科一世（普薩姆提克之父）守薩伊斯；亞述巴尼拔晚年陷巴比倫叛亂（沙馬什舒馬烏金之亂，前652–前648），無暇南顧，出現權力窗口。
- **軍事**：地中海雇傭兵市場成熟——希臘重裝步兵（hoplite）青銅盔甲＋長矛方陣、卡里亞水手＋三列槳戰術，對埃及舊式軍隊具代差。
- **經濟**：薩伊斯控三角洲糧倉＋地中海商路，以糧食、 Natron（泡鹼）、亞麻換雇傭兵軍餉；瑙克拉提斯（Naukratis）商埠雛形已現，外匯充裕。
- **地理**：薩伊斯踞三角洲西緣，進可攻孟菲斯、退可聯希臘海路，兼得尼羅河與地中海兩條生命線。
- **宗教**：普薩姆提克迎娶底比斯阿蒙神妻養女（收養體系），和平接收南埃及神廟財政，避免南北戰爭。
- **技術**：希臘青銅鎧＋鐵槍頭＋艦隊機動，使薩伊斯軍首次在裝備上追平亞述—努比亞系軍隊。

## 線索與推理 -- 因素咬合
### 線索1：希羅多德的「銅人」預言——雇傭兵如何登場
希羅多德《歷史》卷二載：普薩姆提克被同僚放逐沼澤，神諭稱「銅人自海而來相助」，適有愛奧尼亞—卡里亞海盜身披銅甲登陸，便雇為親軍。此說雖傳奇，內核可信：
$$\text{亞述鬆綁} \to \text{雇傭兵可買} \to \text{薩伊斯出價} \to \text{精銳入彀} \to \text{小邦無力抵抗}$$
阿布辛貝、卡納克的卡里亞—希臘塗鴉（「我們隨普薩姆提克而來」）是雇傭兵親筆簽到簿，證實其存在。

### 線索2：十年統一時間表——收買比打仗多
| 年份（約數） | 事件 |
|-------------|------|
| 前664 | 繼父尼科一世（為努比亞反撲所殺），亞述承認為薩伊斯王 |
| 前656 | 兵不血刃入底比斯，神妻收養完成，南北名義統一 |
| 前653–前651 | 遣返亞述駐軍（亞述陷巴比倫戰爭，無力干涉），收回孟菲斯 |
| 前640s | 圍攻亞實突（Ashdod）29年（一說為長期封鎖），重建迦南勢力圈 |
| 前610 | 去世，子尼科二世繼位，復興達頂 |

推理：統一靠的不是決戰，而是「亞述內亂＋雇傭兵威懾＋神妻收編」三件套——晚期復興是精算，不是神蹟。理論：雇傭兵制度（mercenary state）——國家把暴力外包給市場，財政必須跟上。

### 線索3：復古主義——薩伊斯文藝復興的雙面性
普薩姆提克—阿瑪西斯大力復古：文字摹古王國、雕像摹中王國、亡靈書標準化、行政區恢復諾姆舊制。底層邏輯：
$$\text{外族統治百年創傷} \to \text{復古＝去利比亞、去努比亞化} \to \text{合法性重建} + \text{書吏階層動員}$$
但復古也是枷鎖：藝術程式化、宗教繁瑣化，創造力被「正統」凍結。學術理論：古物主義（archaism）——弱國用過去裝飾現在，短期凝聚、長期僵化。

### 線索4：瑙克拉提斯與運河——地中海轉向
尼科二世（約前610–前595）開米利都商埠瑙克拉提斯、試鑿尼羅—紅海運河、據希羅多德遣腓尼基人環航非洲（三年繞好望角，見「太陽在右邊」的關鍵證詞）。雅赫摩斯二世（阿瑪西斯，約前570–前526）更以親希臘政策聞名：
$$\text{雇傭兵} \to \text{商埠} \to \text{關稅} \to \text{更多雇傭兵}$$
埃及從尼羅河國家變成地中海國家——這是復興最深遠的轉向，也是波斯覬覦的原因：富了，就有人搶。

## 破案時刻
- 前671–前667：亞述征服埃及，立薩伊斯尼科一世為代理人。
- 前664：尼科一世死於努比亞反撲，普薩姆提克一世繼位（第二十六王朝開端）。
- 前656：和平接收底比斯，埃及名義再統一（阿蒙神妻收養文書為證）。
- 前653：趁亞述內亂驅逐亞述駐軍，實質獨立。
- 前616–前605：聯亞述抗巴比倫（卡爾基米什會戰前夜），哈蘭遠征失敗，黎凡特轉入巴比倫之手。
- 前610–前595：尼科二世開運河、建海軍、環非航行，復興達頂。
- 前525：岡比西斯佩魯西姆戰役滅第二十六王朝，第一次波斯統治開始。

## 後果 -- 改變了什麼
- **政治**：終結第三中間期四百年分裂，恢復中央集權＋諾姆官僚制，為托勒密行政奠基。
- **軍事**：希臘—卡里亞雇傭兵常態化，埃及軍隊地中海化；代價是本土兵（馬丘亞 mashwesh 階層）失勢，埋下階級對立。
- **宗教/文化**：薩伊斯復古 canon 化埃及藝術—宗教，希臘人由此認識「古老埃及」（柏拉圖、希羅多德的埃及想像源頭）。
- **世界**：瑙克拉提斯成為希臘—埃及知識中轉站（泰勒斯、梭倫訪埃傳說），為希臘哲學的埃及學養分開窗。
- **教訓**：外包暴力能復國，也能誤國——雇傭兵只認軍餉，波斯出價更高時，防線即轉會。

## 因素影響筆記
1. 亞述陷巴比倫叛亂 → 尼羅河權力窗口 → 普薩姆提克趁機坐大。
2. 愛琴雇傭兵市場＋三角洲財力 → 銅甲方陣＋艦隊代差 → 小邦骨牌歸附。
3. 神妻收養＋復古主義 → 低成本接收南埃及＋合法性滿格 → 避免南北內戰。
4. 商埠＋運河＋海軍 → 地中海轉向 → 財政—軍事正向循環 → 晚期復興達頂。
5. 財富暴露＋雇傭兵忠誠度標價 → 波斯覬覦＋本土兵不滿 → 前525年一戰歸零，復興終結。
