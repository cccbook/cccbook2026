# 公元前280年-亞歷山大圖書館與燈塔：知識帝國、海權與奇觀的多因案件

## 案件摘要
托勒密一世（約公元前305–282年在位）創穆塞昂（Mouseion），其子托勒密二世（約公元前285–246年在位）建成大圖書館與法羅斯燈塔（一說燈塔約公元前279–270年落成），使亞歷山大城同時擁有古代藏書之最與世界七大奇觀之一。本案無單一兇手：王朝贊助、抄書工業與海權展示三力咬合，打造了一個以知識統治世界的帝國。

## 前因 -- 多因素的局勢
- **地理**：亞歷山大城居地中海十字路口，船隻進港須繳驗書卷抄錄（傳托勒密三世扣雅典原本即源於此制），書源不斷。
- **經濟**：埃及紙草（papyrus）壟斷＋穀物盈餘，足以供養百名學者免稅食宿專事研究，知識生產有財政底氣。
- **政治**：托勒密王朝為馬其頓外來者，需以希臘文化正統性壓服亞歷山大城公民與埃及祭司，圖書館即文化王冠。
- **宗教**：穆塞昂奉繆斯女神，館長多由王室指定，學者兼祭司，知識即祭祀。
- **技術**：紙草卷標準化、亞歷山大校勘符號（aristarchian signs）、燈塔多層石構＋青銅鏡火光系統，皆為當時頂尖工程。
- **軍事**：法羅斯燈塔高逾百公尺（傳約110–130公尺），晝煙夜火導航兼宣示制海權：進港者先見王權。
- **外交**：托勒密二世與雅典、羅德、以弗所爭奪學者與書籍，開出高薪挖角（如召歐幾里得、卡利馬科斯）。
- **資訊**：藏書量傳說自40萬至70萬卷不等，數字誇大但反映古代「總匯一切書籍」的帝國野心。

## 線索與推理 -- 因素咬合
### 線索1：圖書館如何收書？帝國知識政治的抄寫機器
傳說港務官扣留入港船隻書卷抄副本、還副本留原本；托勒密三世借雅典悲劇三大家原本，寧棄巨額押金不還。適用「帝國知識政治」理論：

$$\text{制海權} \to \text{書籍攔截權} \to \text{抄寫工坊量產} \to \text{標準版本輸出} \to \text{文化霸權}$$

| 機制 | 做法 | 效果 |
|------|------|------|
| 港口扣書 | 抄副本還船主 | 母本盡歸館藏 |
| 王室收購 | 雅典、羅德買書 | 稀本集中 |
| 學者校勘 | 卡利馬科斯編《書目》（Pinakes） | 世界首部圖書分類目錄 |

### 線索2：穆塞昂——吃公家飯的學者公社
穆塞昂供食宿、免稅、有解剖室、天文台與植物園，歐幾里得在此寫《幾何原本》，埃拉托斯特尼在此算出地球周長，希羅菲盧斯在此解剖人體。

$$\text{王室年金} \to \text{學者聚集} \to \text{校勘＋註疏＋發明} \to \text{亞歷山大標準通行地中海}$$

此即「贊助—創新模型」：穩定的長期資助比天才個人更能批量生產突破。

### 線索3：法羅斯燈塔——燈塔還是砲台？
燈塔建於法羅斯島東端，相傳建築師索斯特拉圖斯（Sostratus）署名「獻給拯救者諸神」。三層收分（一說方—八角—圓），頂層火光加青銅鏡反射，晴夜可見逾50公里。

```pseudocode
if 白天: 燃煙為標
else: 燃火 + 銅鏡聚光
功能 = 導航(商船入大港) + 軍事(瞭望敵艦) + 宣傳(王權奇觀)
```

燈塔（pharos）一詞後成羅曼語系「燈塔」通名，足見其原型地位。

### 線索4：焚毀之謎——圖書館究竟毀於誰手？
凱撒亞歷山大港之火（公元前48年）、奧勒良之亂（3世紀）、狄奧克里先鎮壓、基督徒毀塞拉皮雍（391年）皆被指為兇手。真相是多次損耗而非一次焚毀：

$$\text{戰火} + \text{經費中斷} + \text{紙草脆化} + \text{學者外流} \to \text{漸進式消亡}$$

單一兇手論本身就是反證：知識帝國死於多因，正如其生於多因。

## 破案時刻
- **約公元前306–300年**：托勒密一世延攬德米特里烏斯（Phaleron），倡議建穆塞昂與圖書館。
- **約公元前295–285年**：圖書館雛形與王宮藏書並立，歐幾里得執教。
- **約公元前285–270年**：托勒密二世大擴建，卡利馬科斯編目，七十士譯本（舊約希臘文譯本）傳說即此時。
- **約公元前279–270年**：法羅斯燈塔落成（年份諸說並存，取學界常用約數）。
- **約公元前240年**：埃拉托斯特尼任館長，測量地球周長，圖書館達鼎盛。

## 後果 -- 改變了什麼
- **政治**：托勒密王朝以文化合法性彌補血統外來性，亞歷山大城成為希臘世界新雅典。
- **經濟**：紙草出口＋抄書業＋學者消費形成知識產業鏈，支撐城市繁榮。
- **文化**：荷馬校勘本、歐幾里得幾何、七十士譯本皆定型於此，塑造西方經典面貌。
- **世界**：燈塔列名七大奇觀，穆塞昂（museum）一詞成為後世博物館之源。
- **教訓**：知識集中保存若無分散備份，帝國一衰即文明浩劫；現代數位保存思的正源於此。

## 因素影響筆記
1. 地理樞紐＋制海 → 書籍與學者匯流 → 藏書壟斷。
2. 經濟盈餘（穀物＋紙草） → 供養全職學者 → 研究專業化。
3. 政治需求（外來王朝合法性） → 贊助希臘文化 → 圖書館成王冠。
4. 技術突破（校勘學＋燈塔工程） → 標準版本＋安全航道 → 霸權可複製輸出。
5. 多因興＋多因廢 → 無單一兇手 → 集中式知識庫的永恆警示。
