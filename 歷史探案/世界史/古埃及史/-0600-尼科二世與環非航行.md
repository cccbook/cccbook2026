# 公元前600年-尼科二世與環非航行：運河、制海權與帝國過度擴張的多因案件

## 案件摘要
公元前約610–595年在位的尼科二世（Necho II），一面開鑿尼羅河—紅海運河，一面派遣腓尼基人從紅海南下環繞非洲，卻又在敘利亞—巴勒斯坦連年用兵，最終在迦克米施慘敗收場。本案沒有單一兇手：地理野心、經濟動機與軍事冒進三股力量互相咬合，成就了航海史上的傳奇，也埋下了賽斯王朝（第二十六王朝）由盛轉衰的伏筆。

## 前因 -- 多因素的局勢
- **地理**：埃及居地中海與紅海之間，卻被西奈陸橋與尼羅河三角洲沙洲困住；打通尼羅河—紅海通道即可連接兩海。
- **經濟**：亞述帝國崩潰後，近東商路重組；埃及亟需香料、黃金與龐特（Punt）貿易，並以海軍保護穀物出口。
- **政治**：普薩美提克一世統一埃及後，尼科二世繼承擴張路線，欲重建新王國時期的亞洲帝國。
- **軍事**：埃及倚重希臘—卡里亞傭兵與腓尼基水手，本土重步兵不足，卻要兩線作戰（海軍建設＋陸軍北伐）。
- **技術**：腓尼基雙層槳座戰船與沿岸航行技術成熟，具備長程遠航能力；運河工程則沿用賽索斯特里斯舊渠道加以拓寬。
- **外交**：亞述殘部、新巴比倫與米底三方混戰，埃及誤判可扶植亞述牽制巴比倫，反被拖入大國戰爭。
- **資訊**：希羅多德《歷史》卷四第42節是環非航行的唯一傳世記載，真偽成為兩千年學術公案。

## 線索與推理 -- 因素咬合
### 線索1：運河開鑿之謎——為何挖了又停？
希羅多德稱運河工程死了十二萬人，尼科因神諭「為蠻族作嫁」而停工。此說顯然誇大，但透露帝國成本—收益賽局：

$$\text{兩海連通收益} \to \text{勞役與財政成本} \uparrow \to \text{神諭背書停工} \to \text{戰略轉向北伐}$$

| 階段 | 路線 | 狀態 |
|------|------|------|
| 賽索斯特里斯舊渠（約公元前19世紀說） | 尼羅河布巴斯提斯—苦湖—紅海 | 淤塞 |
| 尼科二世拓寬段（約公元前610–595年） | 同上，加寬可容雙船並行 | 未完工即停 |
| 大流士一世完成段（約公元前518年） | 同上並立碑 | 通航 |

推理：運河不是單純工程，而是「帝國過度擴張（imperial overstretch）」指標——保羅·甘迺迪式困境：埃及同時要運河艦隊與亞洲陸軍，財政只能二選一。

### 線索2：環非航行——太陽跑到右邊去了
希羅多德記載腓尼基人受尼科派遣，從紅海出發南下，耗時三年，每年上岸播種收穫，繞過「利比亞」經直布羅陀返抵埃及。水手回報「太陽到了右舷（北邊）」，希羅多德不信，後世天文學家卻視為最有力的真實性證據。

$$\text{南半球航行} \to \text{正午太陽在北方} \to \text{右舷見日} \to \text{反證航行屬實}$$

此即「反意圖證據法則」：記載者不理解卻如實抄錄的細節，反而最可信。學界以「季節風＋沿岸補給」模型重建其可行性。

### 線索3：迦克米施前傳——外交豪賭如何破產？
公元前616–605年，尼科北上支援亞述殘軍，途經米吉多擊殺猶大王約西亞（公元前609年），一度控制敘利亞。但公元前605年迦克米施之戰，新巴比倫王儲尼布甲尼撒二世大破埃軍，埃及勢力退回西奈。

```pseudocode
if 扶植亞述成功:
    埃及 = 黎凡特霸主
else:
    巴比倫崛起 AND 埃及陸軍重創 AND 運河/艦隊計畫失血
# 歷史執行了 else 分支
```

適用理論為「依附與同盟賽局」：埃及押注已死的亞述，等於為殭屍盟友支付沉沒成本。

### 線索4：希臘傭兵與海軍——誰在為法老打仗？
尼科擴建地中海與紅海兩支艦隊，大量啟用愛奧尼亞 Greeks 與腓尼基人。此舉短期提升戰力，長期卻造成軍事外包依賴：

$$\text{傭兵制海} \to \text{本土軍事空洞化} \to \text{戰敗即鳥獸散} \to \text{賽斯王朝後期屢敗於波斯}$$

## 破案時刻
- **約公元前610年**：尼科二世即位，啟動尼羅河—紅海運河拓寬工程。
- **約公元前609年**：米吉多之戰，約西亞王陣亡；埃及立約雅敬為傀儡，控制猶大。
- **約公元前609–605年**：埃及駐軍迦克米施，與巴比倫對峙。
- **公元前605年**：迦克米施之戰，尼布甲尼撒大勝；同年哈馬之戰再敗，埃及退守邊境。
- **約公元前600–595年（希羅多德系年）**：腓尼基人三年環非航行（現代學者多置於運河停工前後）。
- **約公元前595年**：尼科二世去世，普薩美提克二世繼位，運河工程停頓。

## 後果 -- 改變了什麼
- **政治**：埃及亞洲帝國夢碎，新巴比倫獨霸黎凡特；賽斯王朝轉為守勢，半世紀後亡於波斯。
- **經濟**：雖未完成運河，但紅海—地中海轉運概念確立，為大流士運河鋪路。
- **文化**：環非記載成為希臘地理學的起點，托勒密、斯特拉波皆援引討論非洲可航性。
- **世界**：若記載屬實，這是人類首次有文字記錄的環非洲航行，比葡萄牙人迪亞士早約兩千年。
- **教訓**：工程奇蹟不能彌補戰略誤判；兩線作戰是大國最常見的死因。

## 因素影響筆記
1. 地理樞紐野心 → 同時啟動運河與遠洋探險 → 財政與人力透支。
2. 經濟求利（紅海貿易） → 倚重腓尼基—希臘外包 → 本土海軍傳統未建立。
3. 外交誤判（扶植亞述） → 迦克米施慘敗 → 陸軍失血，運河被迫停工。
4. 資訊單源（僅希羅多德） → 真偽爭議兩千年 → 反以天文細節證其可信。
5. 技術可行＋政治短視並存 → 航海成功、帝國失敗 → 傳奇與悲劇同一根源。
