# 1784-廈台對渡與郊行貿易：被跳過的一百五十年

## 案件摘要

展界（1684）與開埠（1842）之間，本書年表出現了 158 年的大跳躍——但這一百五十年正是金廈史上最安靜也最富庶的歲月：清廷指定廈門為對渡台灣的唯一正口（鹿耳門），福建水師提督駐廈，郊行（泉郊、廈郊）壟斷兩岸貿易，1784 年清廷再開彰化鹿港與泉州蚶江對渡，1788 年開淡水八里坌，三口對渡成型。本案補上這段「平靜的海」：沒有戰爭的年頭，海峽靠什麼運轉？

## 前因 -- 多因素的局勢

- **政治**：施琅取台（[1683-施琅取台與鄭氏降清.md](1683-施琅取台與鄭氏降清.md)）後，清廷視台灣為「防而不管」的邊疆，嚴格管制往來。
- **制度**：對渡須由官方指定口岸、領執照、配額載運，官府意在控制，結果製造了稀缺。
- **人口**：康乾閩南人口爆炸，田少人稠，台灣是唯一的新邊疆（「唐山過台灣」）。
- **先例**：廈門自鄭氏時代已是內外港樞紐，復界後（[1684-展界與廈門興起.md](1684-展界與廈門興起.md)）迅速接手。

## 線索與推理 -- 因素咬合

### 線索一：正口制度的經濟學——管制創造利潤

清廷的邏輯：只准廈門—鹿耳門一線往來，所有船隻掛號、驗放、繳費。這在管制經濟學裡是教科書案例：

$$\text{地下經濟規模} \propto \text{合法管道的稀缺度} \times \text{兩岸價差}$$

官方口岸的壟斷利潤養肥了廈門的洋行與船戶，但閩南人私渡「客頭」載偷渡客的生意同樣興旺——溺水者的「烏水溝」傳說正來自此時。**管制沒有阻止移民，只決定了誰死在海上**。

### 線索二：郊行——前現代的兩岸供應鏈

廈門的「郊」（商業公會）分工精密：泉郊對泉州、廈郊對台灣府城、米郊專營台米西運。台灣出產米、糖，閩南供給布、瓷、日用品——這是十八世紀版的兩岸貿易協定，只不過締約方是商會而非國家。郊行還承擔匯兌（銀信）、保險（船難互保）、仲裁（商業糾紛不進官府），**商會把國家不想做、不會做的公共服務全包了**。

### 線索三：金門的「文教紅利」

承平百年，金門從前線變成科舉之島：明清兩代金門進士數十人，「無金不成同安」；海商致富回鄉起大厝、辦書院（浯江書院）。這解釋了為何今日金門保留閩南建築與宗祠最完整——**戰地之前，金門先是一個科舉與僑鄉社會**，這個底子將在 1842 後直接轉化為下南洋的動員網。

### 線索四：平靜的代價——武備的荒廢

百年無大戰，福建水師船隻朽壞、操練廢弛，綠營吃空餉成風。1790s 蔡牽海上勢力崛起時，清軍幾乎無船可戰，要靠地方團練與「義民」助剿。**承平是武備的慢性毒藥**——五十年後鴉片戰爭（[1842-廈門開埠.md](1842-廈門開埠.md)）時，廈門炮台面對英艦仍然一模一樣地不設防。

## 破案時刻

- 1684：廈門—鹿耳門單口對渡確立。
- 1784：開蚶江—鹿港對渡（本案紀年點）。
- 1788：開八里坌—蚶江（福州五虎門）對渡，三口成型。
- 1795–1809：蔡牽之亂，暴露水師虛弱。

## 後果 -- 改變了什麼

- **人口**：台灣漢人從清初十餘萬增至嘉慶年間二百萬——和平對渡是台灣漢人社會的真正助產士。
- **經濟**：廈門成為閩南與台灣、南洋之間的轉運節點，郊行財富累積為後來開埠後的洋行網與僑批網打底。
- **僑鄉**：航海知識、宗族連帶與南洋航線在承平年代埋好，1840s 苦力貿易（見後續案件）幾乎零成本接軌。
- **軍事**：武備荒廢埋下 1840、1853（小刀會）、1860s 兩度失守的伏筆。
- **史鑑**：大跳躍的年代往往不是沒有歷史，而是歷史換了主角——槍聲停了，帳本在響。

## 因素影響筆記

1. **管制（正口）→ 稀缺 → 郊行壟斷利潤**：官方管制養出民間商業巨頭。
2. **人口壓力 → 移民潮 → 台灣開發**：合法管道不足則偷渡補位。
3. **承平百年 → 武備荒廢**：下一場戰爭的敗因在本案已經寫好。
4. **商會網絡 → 僑鄉網絡的直系祖先**：本案是本書「僑鄉線」的隱藏第一章。
