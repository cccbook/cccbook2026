## 破案主線一覽

1. **農業與技術的時差**（前2500–前100）：長江稻作 → 半島（前1000）→ 日本（前300）——東亞的「農業—國家」時差三級，傳播通道是山東-遼東-朝鮮-對馬。
2. **漢字與官僚技術的輻射**（前108–900）：漢四郡 → 律令國家 → 科舉（高麗、李朝、越南）——文字與行政的擴張畫出漢字文化圈（半島、日本、越南三翼）。
3. **佛教與書籍之路**（372–1600）：宗教網絡以書籍為載體——鑑真、空海、朝鮮刻經——知識的跨國傳播先於任何政治統一。
4. **冊封體系的兩面**（前57–1895）：朝貢 = 正當性 + 貿易執照（濱下武志）——「內帝外王」的雙重性（越南），勘合貿易（明），直到甲午翻轉。
5. **海權與鎖國的循環**（1274–1603）：元寇 → 倭寇與海禁 → 鎖國與出島——東亞海域的開放與封閉反覆重演。
6. **敗者學習的日本模式**（663–1868）：白江口敗 → 派遣唐使；黑船 → 明治維新——戰敗與外壓總是日本「制度移植」的引擎。
7. **帝國主義的亞洲化**（1895–1945）：甲午 → 日本成為列強 → 殖民半島台灣 → 大東亞共榮圈——亞洲的帝國主義由亞洲人執行。
8. **冷戰的分斷與奇蹟**（1945–1997）：38 度線 → 韓戰 → 發展型國家（日韓台）→ 雁行 → 金融風暴——分裂反而催生了奇蹟（特需、援助、安全傘）。
9. **經濟整合 vs 安全分斷**（2001–2024）：生產網絡一體化（零件-組裝-消費）與安全對抗（薩德、半導體戰）並存——東亞秩序的永恆矛盾。
