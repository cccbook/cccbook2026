# 1543-鐵炮傳入與軍事革命

## 案件摘要
1543 年 8 月，葡萄牙人（明船漂流）抵達種子島——「鐵炮」（火繩槍）傳入；種子島時堯購入兩挺，委託刀匠八板金兵衛複製——1543 到 1575 僅 32 年，織田信長在長篠以三千鐵炮壓制武田騎馬隊——**東亞的軍事革命**。這樁「鐵炮」案件的偵辦重點：技術傳播的速度（32 年從傳入到量產應用——嘉靖倭寇的海商網是通道）；軍事革命的東亞版（Geoffrey Parker 的 Military Revolution——火器 + 石垣城 + 兵農分離）；社會改造的軍事動機（1588 刀狩、太閤檢地——秀吉的「農民與武器分離」——社會結構的手術）。

## 前因 -- 為什麼會有這個案子
- **南蠻貿易**：1543 前後的葡萄牙海商（嘉靖倭寇的貿易網）——「鐵炮的傳播通道」——海上走私網是技術的高速公路。
- **戰國的軍備競賽**：1467 應仁之亂後的戰國——「火器的需求」——戰國大名的競爭（技術採用的動機）。
- **種子島的地利**：九州南端（南蠻船的停泊）——種子島時堯的決斷（兩挺購入、命刀匠複製）。
- **量產的條件**：國友（近江）、堺、雜賀——「鐵炮的產業群」——刀匠的複製能力。

## 線索與推理 -- 數學式、理論、表格

### 線索一：技術傳播的速度
鐵炮傳入的時間線：

| 年份 | 事件 |
|------|------|
| 1543 | 種子島傳入（兩挺）|
| 1544 | 八板金兵衛複製成功 |
| 1550s | 國友、堺、雜賀的量產 |
| 1575 | 長篠之戰（織田的三千鐵炮）|

**推理**：32 年從傳入到「三千鐵炮的戰場應用」——**傳播速度 = 軍事需求 × 商業網**（南蠻貿易的海商網 + 戰國的競爭）——對照歐洲火器的傳播（半世紀）——技術傳播的速度結構（需求強度 × 產業基礎）。

### 線索二：軍事革命的東亞版
Geoffrey Parker 的 Military Revolution（火器 + 要塞 + 軍隊規模）的東亞版：

| 歐洲軍事革命 | 日本版 |
|--------------|--------|
| 火繩槍部隊 | 鐵炮三千（長篠 1575）|
| 稜堡（trace italienne）| 石垣城（安土 1576）|
| 軍隊規模擴大 | 10-20 萬（秀吉的動員）|
| 陣法與紀律 | 三段擊、兵農分離 |

**推理**：東亞的「軍事革命」與歐洲平行——鐵炮 + 石垣城 + 兵農分離——**軍事技術 → 社會結構**（兵農分離 = 階層的手術）——1592 案壬辰倭亂的軍事基礎。

### 線索三：石垣城與攻城的算式
戰國的築城革命（石垣城）：石垣 + 櫓 + 堀——「火器防禦」的建築：

$$\text{石垣} = \text{抗火炮的斜面} + \text{視野與射口} \quad (\text{對稜堡的東亞調整})$$

**推理**：鐵炮 → 城郭的形態革命（木柵 → 石垣）——安土城（1576）、大阪城——「技術 → 空間」的軍事結構——城下町（武士集中）——**軍事技術 → 城市與社會空間**。

### 線索四：刀狩與太閤檢地——社會的手術
秀吉的社會改造（1582-1590s）：

| 政策 | 內容 | 社會效果 |
|------|------|---------|
| 刀狩（1588）| 收繳農民的武器 | 農民與武器分離 |
| 太閤檢地 | 土地丈量、一地一作人 | 農民與土地綁定 |
| 兵農分離 | 武士集中城下町 | 階層的身份固化 |
| 人掃令（1587-91）| 身份固定（士農工商）| 身份制的固化 |

**推理**：「武器與農民分離 + 土地與農民綁定 + 身份固定」——社會結構的手術——**軍事革命的社會面**（兵農分離 = 身份制的誕生——江戶士農工商的基礎）——「戰爭 → 社會秩序」的轉換。

## 結案 -- 後果與影響
- **戰國的統一工具**：鐵炮 + 石垣城 + 兵農分離——織豐政權的統一機器——1603 案江戶幕府的軍事基礎。
- **身份制的誕生**：兵農分離 + 人掃令——江戶「士農工商」的身份制——社會結構的固化。
- **1592 壬辰倭亂的軍事基礎**：鐵炮軍隊的渡海（秀吉的 15 萬）——「軍事革命的出口」。
- **技術傳播的通道**：南蠻貿易的海商網——「貿易網 = 技術網」（嘉靖倭寇的商業網）——1549 案耶穌會的同通道。
- **對朝鮮的衝擊**：壬辰的鐵炮壓制 → 朝鮮的鐵炮仿製（《武藝圖譜通志》? 不——朝鮮的鐵炮自造）——「敗者學習」的半島版（1603 案後的武備重整）。
