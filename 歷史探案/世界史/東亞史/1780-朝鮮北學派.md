# 1780-朝鮮北學派

## 案件摘要
1780 年，朴趾源隨燕行使團赴清（祝乾隆七十壽），回國後寫《熱河日記》——朝鮮「北學派」的誕生：向「北」（清）學習實用技術與制度——「北學」對抗「衛正斥邪」的正統。洪大容（1765《湛軒書》）、朴趾源、丁若鏞（茶山）的實學——兩班內部的知識革命。這樁「北學」案件的偵辦重點：**知識結構的內部革命**——「今之中國即我的老師」（北學宣言）對「小中華」（1392 案）的自我定位的顛覆——去中華中心的知識結構；「利用厚生」的實學（技術與民生的學問）——1860s 開化派與近代改革的知識伏筆。

## 前因 -- 為什麼會有這個案子
- **燕行使的管道**：1637 臣服清後的年度使團（燕行使）——「朝貢 = 情報通道」（勘合與燕行使的「觀察之旅」）。
- **壬辰胡亂的創傷**：1592 倭亂、1627/1636 胡亂——朝鮮的「北伐論」（尊周思明）vs 現實的清強——「意識形態與現實的張力」。
- **清的盛世**（1750 案）：乾隆的繁榮與技術（琉璃廠的書市、西洋技術）——「實地的震撼」。
- **兩班內部的批判**：柳馨遠（磻溪）的實學（17 世紀）、李瀷（星湖）的批判學問——實學的知識準備。

## 線索與推理 -- 數學式、理論、表格

### 線索一：北學宣言的知識結構
朴趾源《熱河日記》的宣言：「今之中國即我的老師」——

| 舊正統（衛正斥邪）| 北學派 |
|------------------|--------|
| 清 = 胡狄（尊周思明）| 清 = 盛世的現實 |
| 漢字學問的道統 | 「利用厚生」的實學 |
| 中華 = 文明的定義 | 技術與民生 = 文明的實質 |

**推理**：北學 = 「去中華中心」的知識結構——「文明的實質是技術與民生」（不問誰是中華，問誰能富民）——**知識的內部革命**（兩班內部對正統的顛覆）——與日本蘭學（1774 案「通過荷蘭看世界」）的平行：**「窗口的更換」**（中華 → 清的實用 / 荷蘭 → 西洋）。

### 線索二：實學的知識結構
丁若鏞（茶山，1762-1836）的實學：

| 學問 | 內容 | 西學的元素 |
|------|------|-----------|
| 經世 | 《經世遺表》（制度論）| 天主教的間接影響 |
| 地理 | 《與猶堂全書》 | 輿圖的實測 |
| 醫學 | 《麻科會通》 | 種痘法（牛痘的朝鮮傳入 1800s）|
| 土地 | 均田論 | 土地改革的方案 |

**推理**：實學 = 「經世致用」的知識結構（不問道統、問民生）——兩班內部的「知識民主化」——1860s 開化派（金玉均）的知識準備——「實學 → 開化」的知識鏈。

### 線索三：燕行使 = 情報的管道
燕行使團的結構（年度赴北京）：

| 組成 | 功能 |
|------|------|
| 正使、書狀官 | 外交與報告 |
| 譯官（中人）| 情報與技術的仲介 |
| 畫員 | 繪圖（輿圖）|
| 商人（隨行）| 貿易（白銀與書籍）|

**推理**：燕行使 = 「朝貢 = 情報 + 貿易」的複合管道（1368 案冊封的結構）——北學派的知識來源（洪大容與清學者的交流——湛軒書的《醫山問答》）——**朝貢 = 知識的管道**（冊封體系的知識面——濱下武志的貿易面之外的補充）。

### 線索四：尊周思明 vs 北學的張力
朝鮮知識界的兩極：

$$\text{尊周思明（正統）} \Leftrightarrow \text{北學（現實）} \quad \text{的張力} \quad \xrightarrow{1860s} \quad \text{開化派 vs 衛正斥邪}$$

**推理**：意識形態（小中華）與現實（清的盛世）的百年張力——「北學」是內部的突破——1860s 開化派（金玉均 1876 案）是北學的政治化——「知識的內部革命 → 政治的內部革命」的鏈條——朝鮮近代化的知識伏筆。

## 結案 -- 後果與影響
- **實學的遺產**：茶山的經世學問（土地、制度、醫學）——1860s 開化派與近代改革的知識基礎。
- **去中華中心的知識結構**：北學的「文明的實質 = 技術與民生」——「東亞史的內部近代化」（朝鮮的內部近代動能——韓國史學的「內發近代」論）。
- **1860s 開化派的伏筆**：北學 → 開化（金玉均）——知識革命的政治化——1876 案江華島條約的內部條件。
- **與日本蘭學的平行**：「窗口的更換」（中華 → 清/荷蘭 → 西洋）——東亞的「內部西學」對照（1774 案）。
- **「利用厚生」**：民生優先的實學——「文明的評價標準」（不問正統、問民生）——近代「文明開化」的朝鮮先行版本。
