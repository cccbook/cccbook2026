# 2001-中國入世與東亞生產網絡

## 案件摘要
2001/12/11 中國加入 WTO——「世界工廠」的十年：出口從 2001 到 2010 增長五倍；2010 中國 GDP 超越日本（東亞經濟基礎的轉移）。這樁「入世」案件的偵辦重點：**東亞生產網絡**——日韓台的零件 + 中國的組裝 + 歐美的消費（「微笑曲線」的全球分工——1991 案供應鏈的重心移轉）；**雁行的新形態**（1965 案雁行的中國化——產業升級的中國版）；**全球價值鏈（GVC）**——「貿易 = 價值鏈的中段」——東亞生產網絡的一體化（「工廠東亞」）。

## 前因 -- 為什麼會有這個案子
- **改革開放的積累**（1972 案外交前提 → 1978 開放）：深圳特區、鄉鎮企業、外資——「開放的 20 年積累」。
- **台日的產業外移**：1990s 台灣與日本的產業外移（工廠 → 中國）——「雁行的轉移」（1965 案）。
- **WTO 的談判**：1999 中美協議 → 2001 多哈——「入世的談判工程」（15 年的談判）。
- **美國的市場開放**：冷戰後的美國市場（PNTR 2000）——「外部需求的確認」。

## 線索與推理 -- 數學式、理論、表格

### 線索一：東亞生產網絡的結構
「工廠東亞」的價值鏈：

| 環節 | 地區 | 附加價值 |
|------|------|---------|
| 設計/品牌 | 美歐 | 高 |
| 關鍵零件 | 日韓台（晶片、面板、機械）| 中高 |
| 組裝 | 中國（珠三角、長三角）| 低 |
| 消費 | 美歐 | — |

**推理**：「微笑曲線」的東亞分工——日韓台的零件（中高價值）+ 中國的組裝（低價值）+ 歐美的品牌與消費（高價值）——**東亞生產網絡的一體化**（「工廠東亞」——貿易 = 價值鏈的中段——「對美順差的實質 = 日韓台的零件順差」（「全球價值鏈的會計」——貿易順差的重新計算——GVC 的理論）。

### 線索二：雁行的新形態——產業升級的中國版
雁行（1965 案）的中國化：

$$\text{日本（技術）} \to \text{NIEs（資本與零件）} \to \text{中國（組裝 → 產業升級）} \to \text{「升級的雁行」}$$

**推理**：雁行的新形態——中國的「組裝 → 產業升級」（從組裝到零件到品牌——華為、比亞迪的升級）——「雁行 = 產業升級的東亞模式」——「升級的競爭」（中國的產業升級 vs 日韓台的原有位置——「技術的民族主義」的伏筆——2020s 案半導體戰的經濟基礎）。

### 線索三：全球價值鏈（GVC）的理論
GVC 的計量與理論：

| 概念 | 內容 |
|------|------|
| 附加價值貿易 | TiVA（貿易附加價值帳）——「誰的附加價值」 |
| 前向/後向參與 | 零件出口 vs 組裝進口 |
| 「世界工廠」的重新計算 | 出口 = 零件 + 組裝（本國價值 ~60%）|

**推理**：GVC = 「貿易的重新計算」（出口 ≠ 本國的附加價值——「對美順差的重新計算」）——「貿易 = 價值鏈的中段」——**「世界工廠」的實質 = 組裝中心**（低價值段的高比例）——「微笑曲線」的理論化——「東亞 = 全球價值鏈的製造段」。

### 線索四：經濟基礎的轉移
2010 中國 GDP 超日：

| 年 | GDP（日→中的轉移）|
|----|-------------------|
| 1990 | 日本 3 兆，中國 0.4 兆 |
| 2001 | 日本 4.2 兆，中國 1.3 兆 |
| 2010 | **中國 6.1 兆，日本 5.7 兆（逆轉）** |

**推理**：經濟基礎的轉移——「東亞秩序的經濟基礎」（1895 案甲午的經濟翻轉的 115 年後——**經濟的再逆轉**）——「經濟基礎 = 秩序基礎」——2020s 案新冷戰（政治與安全的再對抗）的經濟基礎。

## 結案 -- 後果與影響
- **東亞生產網絡的一體化**：日韓台零件 + 中國組裝——「工廠東亞」——「經濟的一體化」。
- **產業升級的競爭**：中國的升級（華為、比亞迪）vs 日韓台的位置——「升級的雁行」——技術的民族主義。
- **「世界工廠」的重新計算**：GVC 的理論——「順差的重新計算」——貿易的政治（對美順差的結構）。
- **經濟基礎的轉移**：2010 GDP 超日——「東亞秩序的經濟基礎轉移」——2020s 案新冷戰的經濟背景。
- **雁行的完成與新形態**：日 → NIEs → 中國的雁行——「產業梯隊的完成」——「升級的競爭」的新雁行。
