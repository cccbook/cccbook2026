# 1985-廣場協議與雁行的改道

## 案件摘要
1985 年 9 月 22 日，紐約廣場飯店：美、日、英、法、西德五國財長達成「廣場協議」——聯合干預外匯市場，讓美元有序貶值。日圓從 1 美元兌 240 升到 1988 年的 120——**兩年升值一倍**。這樁「匯率會議」案件的謎題：一份外交備忘錄如何引爆資產泡沫、泡沫破滅、產業外移與「失落的十年」？兇手是**升值恐懼症**：日本銀行為對沖升值而長期超寬鬆 → 股地雙漲 → 1990 泡沫破滅 → 零利率與通縮陷阱；同時升值逼製造業外移 → 「雁行陣列」改道飛向東亞四小龍與中國——**廣場協議是東亞經濟奇蹟（1965 案）與亞洲金融風暴（1997 案）之間失落的關鍵一環**，也是 2019 科技戰（2019 案）之前美日經濟戰的預演。

## 前因 -- 為什麼會有這個案子
- **貿易摩擦的白熱化**：1970s 以降對日逆差擴大 → 1981 自願出口限制（汽車）、1981–1988 半導體協定——**關稅打不完，就打匯率**。
- **里根經濟學的雙赤字**：減稅 + 增軍費 → 財政與貿易雙赤字 → 美元高估（強勢美元政策）→ 製造業失血——「必要的修正」成共識。
- **五國集團（G5）的協調**：1975 以降的財長會議機制——首次以「聯合干預匯市」為主要議程。
- **日本的顧慮**：害怕美國國會的保護主義立法（報復性關稅）——**用升值買政治保險**——大藏省的誤判：升值 10–15% 可承受。

## 線索與推理 -- 理論、表格、因果鏈

### 線索一：升值的連鎖反應
廣場協議後的政策鏈：

| 時間 | 事件 | 後果 |
|------|------|------|
| 1985.9 | 五國聯合賣美元 | 日圓 240 → 200（三個月）|
| 1986.1 | 日銀五度降息（貼現率 5% → 3%）| 對沖「升值蕭條」 |
| 1987.10 | 黑色星期一 → 日銀續降（2.5%！）| 全球最低利率，錢潮湧入 |
| 1988–89 | 股地雙漲（日經 3.9 萬！地價漲 2–3 倍）| 「賣掉東京買下美國」 |
| 1989.5–1990.8 | 日銀連續升息至 6% | 泡沫戳破 |
| 1991– | 資產負債表衰退 | 失落的十年 |

$$\text{泡沫} = \text{（急升值的對沖需求）} \times \text{（寬鬆的維持過久）} \times \text{（土地神話：地價不跌的信仰）}$$

**推理**：升值本身不必然製造泡沫——德國馬克同樣升值、德國沒有同等泡沫——**日本的差異變量**：大藏省—日銀的「升值蕭條恐懼」（シ ョック安プ）＋銀行以土地為抵押的放款文化＋法人交叉持股的股市結構——**泡沫是「貨幣政策 × 金融結構」的乘積**，匯率只是扳機（野口悠紀雄《土地經濟學》的土地神話論）。

### 線索二：雁行的改道
赤松要的「雁行陣列」：先進國產業向後進國梯度轉移。廣場協議把它推向第二曲線：

| 產業 | 升值前 | 升值後 |
|------|--------|--------|
| 組裝製造 | 日本本土 | 四小龍 → 東協 → 中國 |
| 資本輸出 | 貿易順差再投資美國國債 | 直接投資（FDI）湧向亞洲 |
| 技術 | 總量集中日本 | 模組化分工（1987 半導體案）|

**推理**：日圓升值使日本生產成本翻倍 → 「境內空心化」→ 亞洲各國接收投資 → 1990s 的「東亞奇蹟下半場」——但外資（多為短期美元債）也是 1997 金融風暴（1997 案）的燃料——**同一條雁行線，上半場載來奇蹟，下半場載來風暴**。

### 線索三：失衡的全球迴路
廣場協議的另一端——日本的「順差轉投資」：

$$\text{全球失衡} = \text{（日本順差買美債）} + \text{（美國逆差印美元）} \Rightarrow \text{低利率 × 過度消費的全球化}$$

**推理**：日方答應維持低利率、續買美元資產——「反廣場協議」（1987 羅浮宮協議）的默契——**出口國融資進口國**的模式自此定型，二十年後換中國接棒（2001 入世案、2018 貿易戰案）——廣場協議是「亞洲儲蓄補貼美國消費」的第一份合約。

## 結案 -- 後果與影響
- **日本經濟的斷代**：1990 泡沫破滅 → 1997 山一證券倒閉、1998 長期信用銀行國有化 → 通縮與零利率——「失落的二十年」——與明治維新（1868 案）的「學習型成功」相對，日本成為「調整型失敗」的教材。
- **四小龍與中國的機運**：雁行改道造就台韓的半導體升級（1987 東亞半導體分工案）與中國的出口起飛（2001 案）——**日本的失落是鄰居的奇蹟**。
- **美日經濟戰的模板**：出口限制 → 匯率協議 → 智慧財產權談判 → 半導體協議——2018 對華貿易戰（2018 案）逐項復刻——**霸權國的工具箱三十年沒換**。
- **宏觀政策的教訓入課本**：流動性陷阱、資產負債表衰退（辜朝明）、過早戳破 vs 過晚拆除的兩難——廣場協議成為經濟學與政策史的分水嶺案例。
- **政治心理的遺產**：「日本的傲慢」（日本 No.1 → 買下洛克菲勒中心的狂言）→ 破滅後的退縮——國家的過度自信與過度自卑共用同一個心理開關。
