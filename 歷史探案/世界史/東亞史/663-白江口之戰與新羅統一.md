# 663-白江口之戰與新羅統一

## 案件摘要
660 年唐-新羅聯軍滅百濟；663 年 8 月，白江口（錦江口）之戰——唐水軍四百艘擊潰倭軍千餘艘（復興的百濟+倭援軍）；668 年唐滅高句麗；676 年新羅驅唐軍，統一大同江以南——半島的第一次統一。這樁「海戰」案件的偵辦重點有二：**日本模式的第一次「敗者學習」**——白江口慘敗後，日本轉向防禦與學習（遣唐使最盛期、大寶律令），「敗者學習」成為日本模式的第一次完整展演（1868 明治的千年前例）；**新羅的統一結構**——「聯外力滅近鄰」的半島模式（三國競爭 -57 案的結局）。

## 前因 -- 為什麼會有這個案子
- **三國競爭的終局**（-57 案）：新羅聯唐的策略（金春秋親唐）——「借力消滅近鄰」的外交路線。
- **百濟的滅亡與復國**：660 唐滅百濟 → 百濟復國軍（鬼室福信）求援倭 → 倭齊明天皇的半島下注（-57 案倭與百濟的傳統連結）。
- **倭的國家動員**：倭的渡海遠征（27,000-42,000 人、千餘船）——「規模」的豪賭。
- **唐的遼東戰線**：唐太宗 645 高句麗親征的未竟 → 高宗的持續進攻——唐的兩線作戰（陸高句麗、海百濟）。

## 線索與推理 -- 數學式、理論、表格

### 線索一：白江口的戰術數學
白江口之戰的兵力與戰術：

| | 唐軍 | 倭軍 |
|---|------|------|
| 船數 | 170 艘（劉仁軌）| 400-1000 艘 |
| 戰術 | 火攻、陣型、弩炮 | 單艦突擊（數量優勢）|
| 結果 | 全勝（燒四百艘）| 慘敗 |

**推理**：倭軍的數量優勢被唐軍的**戰術與技術**（火攻、大型戰艦、弩炮）碾壓——「規模 ≠ 勝利，技術與戰術才是」——這場敗仗成為日本「技術學習」的政治動員（國內的危機感——築防人、大宰府防衛、白村江的「恐怖記憶」）。

### 線索二：敗者學習——日本模式的第一次展演
白江口後的日本反應：

| 反應 | 內容 |
|------|------|
| 防禦 | 大宰府防人、築紫的城柵（朝鮮式山城）|
| 學習 | 遣唐使的最盛期（653-669 年年派遣）|
| 制度化 | 大寶律令（701）——改新遺志的完成 |

**推理**（敗者學習模式）：慘敗 → 危機感 → 制度移植（遣唐使的加強 + 律令化）——「敗者的學習」是日本模式的第一次完整展演：**663 白江口 → 701 大寶律令；1868 黑船 → 1871 廢藩置縣**——同一結構（外敗 → 內改）反覆重演——「敗者學習」是日本史的元模式。

### 線索三：新羅的統一結構
660 滅百濟、668 滅高句麗（唐軍主攻）、676 驅唐（新羅的反戈）——「借力 → 滅近鄰 → 趕走外援」的三步：

$$\text{聯唐滅百濟} \to \text{聯唐滅高句麗} \to \text{反戈驅唐（統一大同江以南）}$$

**推理**：新羅的統一是「借力的雙面刃」——外援滅近鄰後，外援成為新的主權威脅——半島的「統一模式」（借外力統一 + 驅逐外力）——李朝（1392 案）的親明路線、甲午（1895 案）的清日拉鋸，都是「半島在帝國夾縫中」的結構重演。

### 線索四：東亞格局的重畫
白江口後的東亞：唐-新羅-日本（渤海 698 加入）——「四國格局」：

$$\text{唐（大陸霸權）} + \text{新羅（半島統一）} + \text{日本（列島自閉化）} + \text{渤海（東北雙屬）}$$

**推理**：東亞的「五國平衡」（唐、新羅、渤海、日本、後來的南詔/吐蕃）——冊封體系（-57 案）內的多極平衡——新羅的統一讓半島單一化（對唐的冊封），日本轉向「脫離冊封」（白江口後不再入唐冊封——「絕交」的政策）——**東亞秩序的首次分裂**（冊封圈內外的分化）。

## 結案 -- 後果與影響
- **半島的統一與「南北國」**：新羅統一大同江以南，高句麗舊域由渤海（698）接手——「南北國時代」的記憶——高麗（918 案）的「南北國統一論」由此而來。
- **日本的敗者學習模式**：白江口 → 大寶律令——「敗者學習」的元模式（1868 明治的千年前例）。
- **日本的「絕交」政策**：白江口後日本不再入唐冊封——「脫離冊封圈」的自主路線——遣唐使的持續（754 案鑑真）但政治自主——「文化學習、政治自主」的二元。
- **唐的半島經營收縮**：676 營州都督府的收縮——唐的半島直接統治放棄——「帝國的邊界成本」（唐的擴張極限）。
- **半島模式的定調**：借外力統一 → 驅逐外力 → 夾縫中的自主——朝鮮半島千年地緣結構的原型。
