# 1370 帖木兒：人頭金字塔與琉璃瓦

## 案發現場

1370 年，帖木兒（Timur，瘸子）於撒馬爾罕稱埃米爾，此後三十五年：滅西察合台諸部、破金帳（脫脫迷失，1395）、下德里（1398，屠城）、敗鄂圖曼（安卡拉，1402，俘巴耶濟德）、 號稱五十萬大軍遠征中國（1405，死於途中）。撒馬爾罕：比比哈努姆清真寺、沙希辛達陵群、烏魯伯格天文台（孫子建）。人頭堆成金字塔，首都覆上琉璃瓦——瘸子要什麼？

> **屠殺與建設矛盾嗎？帖木兒的恐怖是瘋狂、是戰術，還是世界帝國的會計學？**

## 偵查過程

**線索一：人頭金字塔（恐怖的廣告）。** 德里、巴格達（1401）、大馬士革——屠城後以人頭堆塔（德里號稱十萬）。偵查結論：這是**恐怖的規模經濟**：堆一次，傳十國——下一個城市聽說金字塔，開城投降（大馬士革先降後屠是例外，工匠被掠）。**屠殺是廣告費**：一次投入，多城免戰。與蒙古屠城立威（參見本書 [1219-花剌子模與蒙古入侵.md](1219-花剌子模與蒙古入侵.md)）同師——帖木兒自稱成吉思汗繼承者（雖是突厥化蒙古巴魯剌思部），連恐怖都繼承。但賬要細算：屠的是富庶城市（德里、巴格達），毀的是稅基——**廣告費超過營收**，帖木兒死後帝國速分（子孫內戰，沙哈魯守波斯，烏魯伯格守河中）。恐怖的ROI：生前有效，死後歸零。

**線索二：安卡拉之戰（1402，兩個帝國的對撞）。** 帖木兒俘鄂圖曼蘇丹巴耶濟德（一世，閃電），鄂圖曼空位時代（1402–13）。偵查結論：這是**中亞遊牧對地中海帝國的最後勝利**：帖木兒的騎射+戰象（印度繳獲）+奧斯曼火器未穩——巴耶濟德的耶尼切里還嫩。安卡拉的蝴蝶效應：鄂圖曼推遲滅拜占庭五十年（1453 變 1402+50）——**君士坦丁堡多活半世紀，因為中亞來了個瘸子**（參見 [../亞洲史/1453-君士坦丁堡陷落.md](../亞洲史/1453-君士坦丁堡陷落.md)）。而帖木兒無意佔小亞細亞（搶完就走）——**劫掠型帝國的邊界：搶得到，守不住**。安卡拉證明帖木兒的極限：能打敗任何人，不能統治任何地方（除河中本部）。

**線索三：撒馬爾罕的琉璃瓦（建設的合法性）。** 比比哈努姆（為中國遠征祈福而建？一說）、沙希辛達、古爾—埃米爾陵（帖木兒自陵）。工匠從大馬士革、德里、安卡拉掠來——絲綢之路的手藝集中營。偵查結論：這是**贓物美學**：搶來的工匠蓋的首都，每一塊琉璃瓦都是戰利品。與薩曼布哈拉（參見本書 [0875-薩曼王朝.md](0875-薩曼王朝.md)）對照：薩曼用稅收養學者，帖木兒用搶掠養工匠——**合法性都靠建設，現金流一贓一稅**。烏魯伯格天文台（1420s，星表精度當時第一）是孫子的轉型：從搶掠轉向贊助——**第二代知道第一代的路走不通**，帖木兒帝國的文化遺產（帖木兒文藝復興：赫拉特、比哈扎德細密畫）全是第二代以後的事。瘸子搭台，孫子唱戲。

**線索四：遠征中國之死（世界帝國的句號）。** 1405 年，帖木兒率五十萬（號稱）東征明朝（藉口：朱棣篡位+不奉伊斯蘭），死於訛答剌（途中，嚴寒+病）。偵查結論：這是**劫掠邏輯的終點**：搶完印度、波斯、小亞細亞，下一個最富的是中國——**強盜的盡頭是明朝**。但七十歲+嚴冬+補給線三千里=尼布楚定律（參見 [../亞洲史/1689-尼布楚條約.md](../亞洲史/1689-尼布楚條約.md)）的終極演示：**遠征的終點是墳墓**。帖木兒死，明朝君臣（朱棣）鬆口氣——《明實錄》載「帖木兒死，中國免大患」。**兩個帝國的邊界由瘸子的死亡劃定**：他活著，邊界在訛答剌；他死了，邊界回錫爾河。死亡是最有效的邊界談判。

## 結案報告

1. **廣告費理論**：人頭塔一次投入多城免戰——但廣告費超營收，死後歸零。
2. **搶守悖論**：能敗任何人，不能治任何地——劫掠型帝國的邊界是守不住。
3. **贓物美學**：搶來工匠蓋首都——合法性靠建設，現金流一贓一稅。
4. **死亡劃界**：遠征終點是墳墓——瘸子之死劃定兩個帝國邊界。

| 項目 | 成吉思汗 | 帖木兒 |
|------|----------|--------|
| 恐怖 | 屠城立威 | 人頭金字塔 |
| 建設 | 驛站（制度） | 撒馬爾罕（面子） |
| 繼承 | 分封（雖分但續） | 速分（子孫內戰） |
| 遺產 | 驛站+基因 | 琉璃瓦+星表 |

**劫掠公式（示意）：**

```
劫掠帝國壽命 ＝ 首領壽命 ＋ 一代。
帖木兒（1370–1405）→ 沙哈魯守成 → 烏魯伯格被殺（1449）→ 分裂。
搶來的江山，搶不來繼承——人亡政息，夫妻店（家族店）同理。
```

**結論：** 帖木兒案是「劫掠帝國」的巔峰樣本：人頭廣告、安卡拉改向、琉璃首都、死於遠征——三十五年，四個傳奇。**瘸子想要世界，世界給了他撒馬爾罕**——一座城，幾座陵，一張星表。搶來的都還了（德里、巴格達、大馬士革皆復），留下的都是蓋的。歷史的結賬：屠刀歸零，琉璃永存。
