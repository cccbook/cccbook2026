# 0977 加茲尼王朝：奴兵變蘇丹的跨境帝國

## 案發現場

977 年，突厥奴隸出身的將領賽布克特勤在加茲尼（今阿富汗）自立為王——加茲尼王朝正式成型。其子馬哈茂德（998–1030 在位）十七次入侵印度，洗劫索姆納特神廟，自號「真主的劍」；王朝全盛時疆域從伊朗東部到旁遮普。但僅僅十年後，就是丹丹納干（參見本書 [1040-丹丹納干之戰.md](1040-丹丹納干之戰.md)）——加茲尼被自己當年雇來守邊的部落掀翻。

> **奴隸兵如何變成蘇丹？一個靠搶印度維持的帝國，為何註定被更輕的部落取代？**

## 偵查過程

**線索一：奴兵的晉升通道（古拉姆制度）。** 薩曼王朝（參見本書 [0875-薩曼王朝.md](0875-薩曼王朝.md)）的軍事核心是古拉姆——買來的突厥少年奴兵，受波斯式教育與嚴格軍訓，逐級晉升為軍官、總督。他們沒有部落親族、只忠於主人。偵查結論：這是**人力資源的極端方案**：切斷身分、只留效忠——但也埋下後果：奴兵既無宗族牽制，也就沒有不可取代的根；一旦擁兵，轉身即自成體系。賽布克特勤從薩曼的呼羅珊總督位置上出走自立，正是這條邏輯的必然。

**線索二：劫掠型財政（為何十七次去印度）。** 馬哈茂德的收入結構：印度戰利品（神廟金庫）＋呼羅珊稅收＋絲路關稅。蘇丹身兼遜尼守護者（哈里發冊封）與「異教徒懲罰者」。偵查結論：這是**不可持續的現金流**——

$$\text{帝國支出（宮廷＋禁衛＋戰爭）} \propto \text{掠奪收入} \Rightarrow \text{搶一次，胃口大一圈}$$

神廟金庫是一次性資產：搶完索姆納特，下一次要搶更遠的廟。劫掠不是財政收入，是**財政透支**——每一次凱旋都在掏空下一次的本金。馬哈茂德死後，帝國找不到下一個「十七次」。

**線索三：雙頭的內耗（王朝的結構性裂縫）。** 加茲尼雙中心：阿富汗山區的加茲尼（突厥軍事核心）與呼羅珊的行政層（波斯官僚）。馬哈茂德晚年與弟弟馬蘇德的繼承內戰，波斯文官與突厥武人的裂痕日深。偵查結論：奴兵王朝的通病是**繼承即內戰**——沒有合法血統傳統，權力只認刀與近臣，父子兄弟互殺成為標準流程（薩曼如此，加茲尼如此，日後的花剌子模與德里蘇丹國也如此）。1040 年丹丹納干敗給塞爾柱時，加茲尼的組織裂縫早已張開。

**線索四：與薩曼的接力（波斯化突厥的成型）。** 加茲尼雖是突厥武力，宮廷卻是薩曼的完整複刻：波斯語官府、維齊爾制度、資助詩人（菲爾多西《列王紀》正是獻給馬哈茂德——雖然稿費糾紛鬧得不愉快）。偵查結論：加茲尼的真正遺產是**「突厥劍＋波斯筆」的標配**——武人蘇丹、波斯文官、伊斯蘭法統三件套。這套配置此後成為中亞—南亞王朝的通用作業系統：塞爾柱、花剌子模、德里蘇丹國直到蒙兀兒（參見 [../亞洲史/1526-蒙兀兒帝國.md](../亞洲史/1526-蒙兀兒帝國.md)），全是它的迭代版本。

## 結案報告

1. **奴兵悖論**：切斷身分換忠誠，也切斷了根——擁兵即自立。
2. **劫掠透支論**：戰利品是一次性資產——十七次遠征是在掏本金。
3. **繼承即內戰**：無合法傳統的王朝，每次交接都是賭局。
4. **波斯化突厥標配**：突厥劍＋波斯筆＋伊斯蘭章——中亞八百年的通用作業系統。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 加茲尼工程 | 跨域效應 |
|------|----------|----------|
| 軍事 | 古拉姆奴兵制 | 中亞王朝軍事模板 |
| 經濟 | 印度劫掠財政 | 不可持續現金流示範 |
| 宗教 | 遜尼守護者、印度聖戰 | 南亞伊斯蘭化的前奏 |
| 文化 | 資助菲爾多西 | 波斯語宮廷文學的制度化 |
| 政治 | 蘇丹制＋維齊爾 | 後世突厥王朝的憲制 |

**加茲尼的自毀曲線（示意）：**

```
奴兵晉升 → 出走自立 → 劫掠印度 → 財政透支
  → 繼承內戰 → 組織裂縫 → 1040 丹丹納干 → 退守印度
劫掠型帝國的一生：由搶起家，由搶不起結束。
```

**結論：** 加茲尼案是「劫掠型帝國」的完整標本：用奴兵解決忠誠、用聖戰包裝搶劫、用波斯官僚包裝突厥武力——樣樣都對，只有現金流是錯的。它填補的正是薩曼（875）與丹丹納干（1040）之間的前因斷環：塞爾柱不是從天而降的挑戰者，而是這套系統生產出來的接班人。**帝國的壽命不等於勝仗的次數，等於收入結構的可持續性**——這道算術題，丹丹納干的沙漠替歷史判了卷。
