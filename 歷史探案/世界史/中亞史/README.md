# 中亞史的歷史年表（推理探案）

> 中亞史是草原、綠洲與帝國互相塑造的偵探史：青銅時代的戰車如何從草原衝向四方？托米麗司女王如何砍下居魯士大帝的頭？亞歷山大為何在粟特娶了羅克珊娜、卻殺不完斯皮塔米尼的游擊隊？希臘人如何在阿姆河畔建起一座希臘城？迦膩色迦的佛教會議與犍陀羅佛像之間是什麼關係？突厥汗國的石碑上，最古老的突厥文字寫了什麼？屈底波如何用二十年把中亞變成伊斯蘭世界？布哈拉為何能同時生出阿維森納與《列王紀》？丹丹納干一戰如何讓塞爾柱從部落變帝國？卡特萬之戰的西遼，為何是契丹人的第二帝國？花剌子模的算學家沙發上想著代數、蒙古大軍卻已兵臨撒馬爾罕？帖木兒的金字塔用人頭堆成、撒馬爾罕卻用琉璃瓦覆頂？昔班尼與哈薩克的分家，如何寫出烏茲別克與哈薩克的國界？準噶爾的滅亡是平叛還是種族滅絕？俄羅斯的鐵路與英國的間諜，如何在「大博弈」中瓜分中亞？巴斯瑪奇打了十六年，為何輸給民族劃界？史達林如何用鉛筆畫出五個加盟共和國？處女地的麥浪與鹹海的乾涸之間是什麼公式？獨立三十年後，中亞為何成為一帶一路的樞紐？
>
> 本書以「推理探案」的方式，為每個歷史事件寫一篇 wiki，包含前因後果、學術理論與跨領域影響矩陣。每篇檔名以年份開頭（西元前以負號表示，四碼不足補零）。
>
> 本書的核心命題：**中亞史是「通道的歷史」**——草原通道（遊牧遷徙與征服）、綠洲通道（絲路貿易與轉口）、帝國通道（波斯、希臘、阿拉伯、蒙古、俄羅斯的輪番進入）；誰控制通道，誰就定義中亞；每篇 wiki 都以「跨領域影響矩陣」拆解政治、經濟、科技、文化與法律的互動。

## 閱讀路線（偵探式提問）

- **通道控制線**：戰車擴散（-2000）→ 粟特商路（-0329）→ 突厥保鏢（0552）→ 蒙古驛站（1219）→ 俄羅斯鐵路（1865）→ 中歐班列（2013）——控制通道者定義中亞。
- **征服與反噬線**：居魯士之死（-0530）→ 斯皮塔米尼游擊（-0329）→ 花剌子模陷落（1219）→ 準噶爾終結（1757）——帝國在中亞的勝利全是分期付款。
- **認同製造線**：伊斯蘭化（0715）→ 波斯復興（0875）→ 烏茲別克化（1500）→ 民族劃界（1924）——今日五國的認同是四層沉積。
- **水與棉線**：綠洲灌溉（0875）→ 處女地（1954）→ 鹹海之死（1960）——改造自然的帳單總會寄到。
- **大國平衡線**：大博弈（1865）→ 巴斯瑪奇（1916）→ 獨立平衡（1991）→ 一帶一路（2013）——夾縫的藝術：永遠不只抱一條大腿。
