# 1960 鹹海之死：棉花與河流的死亡公式

## 案發現場

1960 年代起，蘇聯為擴大棉花種植，大規模截流阿姆河、錫爾河（卡拉庫姆運河等）——鹹海水位年年下降：1960 年 6.8 萬平方公里，2000 年代縮水近九成，漁港姆伊納克退到沙漠中（船隻墳場），鹽塵暴毒害沿岸。此後哈薩克建科卡拉爾壩（2005）搶救北鹹海。一個海，是怎麼被棉花喝乾的？

> **棉花重要還是海重要？當計劃經濟給河流下指標，大海的死亡需要幾年——生態賬的複利是什麼？**

## 偵查過程

**線索一：白金之國（棉花獨立的執念）。** 蘇聯要擺脫進口棉（美國、埃及）——中亞定為棉花基地（烏茲別克「白金之國」），計劃指標層層加碼（完成獎、完不成罰）。偵查結論：這是**自給自足的執念**：紡織業是工業化的面子（軍裝、出口），棉花是面子的原料。計劃的邏輯：要棉花→要水→截河流——**河流是計劃的免費投入品**（不計價）。與維特鐵路（參見 [../俄羅斯史/1891-西伯利亞鐵路.md](../俄羅斯史/1891-西伯利亞鐵路.md)）對照：同樣為工業化，維特借外資，這次借河流——**借來的都要還，河流的利息是海**。

**線索二：截流的數學（死亡公式）。** 鹹海水量平衡：入流（兩河）=蒸發。1960 年代入流銳減（棉田耗水+運河滲漏過半）——水位年降數十厘米，1980 年代 加速（年降近米）。偵查結論：死亡公式——

```
水位變化 ＝ 入流（被截）−蒸發（不變）。
入流＜蒸發→年年下降→鹽度上升→魚死→海退→鹽塵。
```

決策者知道嗎？知道（學者警告過）——但**計劃的貼現率是零**：今年的棉花是政績，明年的海是別人的問題。與處女地（參見本書 [1954-處女地運動.md](1954-處女地運動.md)）同構：**生態賬不記當年**——處女地十年後沙塵，鹹海二十年後見底。**貼現率為零的體制，生態必死**。

**線索三：船隻墳場（姆伊納克的隱喻）。** 漁港退到沙漠中 150 公里，漁船鏽在沙地上，漁民改行或搬走，嬰兒死亡率飆升（鹽塵+農藥殘留）。偵查結論：船隻墳場是**發展主義的紀念碑**：鏽船=工業化的代價，可參觀，不可逆轉（南鹹海已基本消失）。鹽塵暴把鹽和農藥吹到農田牧場——**毒素循環**：棉田的藥，回到棉田的人。1980 年代 莫斯科撥款搶救（西伯利亞調水計劃，夭折）——**搶救的錢不到死亡的零頭**，蘇聯解體（參見 [../俄羅斯史/1991-蘇聯解體.md](../俄羅斯史/1991-蘇聯解體.md)）後更無人管。南鹹海（烏茲別克側）至今荒漠，北鹹海（哈薩克側）築壩回升——**同一個海，兩種命運**：有錢築壩的活，沒錢的死。

**線索四：科卡拉爾壩（搶救的經濟學）。** 2005 年哈薩克在世行貸款下建科卡拉爾壩——北鹹海水位回升、魚回來了（部分）。偵查結論：搶救證明**死亡可逆（部分）**，但條件苛刻：只需救一半（北鹹海）+國際貸款+放棄南鹹海。**生態搶救的公式：錢+決心+放棄**——三者缺一即全死。烏茲別克至今在南鹹海底試種梭梭（防鹽塵）+開發油氣——**屍體利用**：海死了，海底的油氣和耐鹽植物接著用。鹹海的結局：北邊是搶救樣本，南邊是墳場樣本——**同一個死亡，兩種處理**，供後人參觀。

## 結案報告

1. **執念即動機**：棉花自給→河流免費→截流——借來的都要還，利息是海。
2. **貼現率為零**：今年棉花是政績，明年海是別人的事——生態賬二十年後到期。
3. **墳場即豐碑**：鏽船+鹽塵+毒素循環——發展主義的紀念碑，可參觀不可逆。
4. **搶救三條件**：錢+決心+放棄——北活南死，同一個死亡兩種處理。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 截流工程 | 跨域效應 |
|------|----------|----------|
| 法律 | 計劃指標、運河法令 | 河流國有化 |
| 經濟 | 棉花單一種植 | 白金之國+生態破產 |
| 科技 | 卡拉庫姆運河（滲漏過半） | 水利的粗放 |
| 政治 | 蘇聯解體後分治 | 南北兩種命運 |
| 文化 | 船隻墳場、紀錄片 | 災難美學 |

**南北鹹海（對照）：**

| 項目 | 北鹹海（哈薩克） | 南鹹海（烏茲別克） |
|------|------------------|-------------------|
| 現狀 | 築壩回升、魚回歸 | 基本消失、荒漠 |
| 手段 | 科卡拉爾壩+世行貸款 | 梭梭+油氣開發 |
| 邏輯 | 搶救一半 | 屍體利用 |
| 評價 | 樣本 | 墳場 |

**死亡公式（示意）：**

```
水位 ＝ 入流（截走）−蒸發（照舊）。
1960：平衡。1970：年降。1980：加速。2000：九成消失。
貼現率零→生態死→鹽塵→毒素循環→墳場。
```

**結論：** 鹹海案是「計劃殺海」的完整樣本：棉花執念、截流數學、墳場豐碑、半邊搶救——一個海用四十年喝完。**河流不投票，但河流記賬**——賬記在鹽塵裡，記在嬰兒死亡率裡，記在沙漠中的鏽船裡。後人參觀墳場時，導遊應該加一句：兇手是計劃，幫兇是棉花，動機是自給自足——多麼正當，多麼致命。
