# -0329 斯皮塔米尼：讓亞歷山大流血七年的粟特人

## 案發現場

前 329–327 年，亞歷山大東征進入粟特（澤拉夫尚河流域），粟特貴族斯皮塔米尼舉兵反抗——劫糧道、圍孤軍、打了就跑，亞歷山大名將亦陣亡。馬其頓軍屠滅七城、強遷人口，仍剿而不滅。最終斯皮塔米尼被部下殺害（首級獻亞歷山大），亞歷山大娶粟特公主羅克珊娜（Roxana）為妻，設防收場。征服世界的人，在中亞耗了整整三年。

> **為何橫掃波斯的方陣，在粟特寸步難行？游擊戰的數學是什麼——亞歷山大最後為何選擇娶新娘而不是砍人頭？**

## 偵查過程

**線索一：游擊戰的數學（正規軍的噩夢）。** 斯皮塔米尼避決戰、劫糧道、圍小股（波利伯孔部被全殲）——馬其頓方陣天下無敵，但追不上馬背上的敵人。偵查結論：游擊戰的公式——

```
佔領成本 ＝ 據點數 × 駐軍 × 時間。
游擊隊讓據點數→無窮（處處可襲），駐軍需求→無窮。
```

亞歷山大被迫分兵把守、屠城立威（七城之屠）——**屠城是佔領成本的止痛藥**：殺雞儆猴，減少駐軍。但止痛藥有毒：屠城製造更多仇恨，仇恨製造更多游擊隊。**反游擊的悖論：越狠，敵人越多**。七年（連同巴克特里亞，329–327 集中）耗掉亞歷山大東征近三分之一時間——**粟特是帝國的泥潭**，第一個，但不是最後一個（阿富汗至今仍是）。

**線索二：七城之屠（恐怖的資產負債表）。** 亞歷山大屠滅沿錫爾河七城、殺降卒、強遷。偵查結論：恐怖的短期收益（震懾）vs 長期成本（仇恨+人口損失+稅基毀滅）——與特轄區（參見 [../俄羅斯史/1547-伊凡四世.md](../俄羅斯史/1547-伊凡四世.md)）同樣的損益表：**搶來的順從抵不上毀掉的稅基**。亞歷山大很快調整：屠城之後改安撫（免稅、通婚）——**大棒之後必須有胡蘿蔔，否則大棒越打越貴**。七城之屠的真正教訓：恐怖是佔領的啟動資金，不是運營資金。

**線索三：羅克珊娜聯姻（新娘即條約）。** 亞歷山大娶粟特貴族之女羅克珊娜（傳說一見鍾情，實為政治聯姻）+鼓勵馬其頓將士娶波斯女子（蘇薩集體婚禮，324 年）。偵查結論：這是**血緣併購**（參見王建，[../韓國史/0918-高麗建國.md](../韓國史/0918-高麗建國.md)）：娶了粟特的女兒，粟特貴族變成親家——抵抗的合法性減半。亞歷山大的融合政策（波斯人入伍、通婚、東方宮廷禮）服務同一目的：**用血緣和制服把被征服者變成自己人**。馬其頓老兵嘩變（奧皮斯）證明融合有代價——**征服者被被征服者同化一半**，老部下不認了。但戰略上正確：羅克珊娜之子（亞歷山大四世）是帝國法統的混血證明——雖然帝國隨亞歷山大之死分裂。

**線索四：泥潭定律（中亞是帝國的試紙）。** 亞歷山大之後：塞琉古丟掉東方（大夏獨立，參見本書 [-0256-大夏希臘王國.md](-0256-大夏希臘王國.md)）、貴霜、阿拉伯、蒙古、英國、蘇聯、美國——個個在中亞—阿富汗耗損。偵查結論：**中亞地形（山地+綠洲+草原）+社會（部落+游擊傳統）=佔領成本無窮大**。帝國的試紙：能在中亞全身而退的，才是真強權；陷進去的，一律放血。亞歷山大耗三年、英國耗三次戰爭、蘇聯耗十年、美國耗二十年——**試紙從不說謊，只是每次都有人以為自己例外**。

## 結案報告

1. **游擊數學**：據點無窮→駐軍無窮——正規軍追不上馬背，屠城是止痛藥兼毒藥。
2. **恐怖損益**：啟動資金非運營資金——大棒之後必須有胡蘿蔔。
3. **新娘即條約**：血緣併購減半抵抗——融合的代價是老部下嘩變。
4. **泥潭定律**：中亞是帝國試紙——每次都有人以為自己例外，試紙從不說謊。

**游擊公式（示意）：**

```
佔領成本 ＝ 據點（無窮）× 駐軍 × 時間。
游擊隊：不決戰、劫糧道、打完跑。
解法：屠城（止痛）＋聯姻（收編）——亞歷山大兩樣都用了。
```

**結論：** 斯皮塔米尼案是「游擊戰」的原型事件：沒有一場決戰，卻耗掉世界征服者三年——最終用一顆部下獻上的人頭和一場婚禮收場。**中亞教帝國的第一課：打贏戰爭容易，贏得和平難；第二課：新娘比屠刀便宜**。亞歷山大學會了，後來者多半沒學會。
