# -0300-彌生革命與稻作東傳：一條河（稻）改寫整座群島

## 案件摘要

約西元前 300 年起，日本進入**彌生時代**（約前 300–250）：濕地稻作從朝鮮半島東傳九州，兩百年內擴散至關東。這是日本史上第一次「革命速度」的社會重寫：**稻作剩餘 → 人口爆炸 → 階層分化 → 村落戰爭 → 政治體**。繩紋一萬年沒長出的東西，彌生六百年全部補齊——兇手是一株植物：水稻。

## 前因 -- 多因素的局勢

- **科技**：朝鮮半島的濕田稻作技術（育種、灌溉、農具）＋青銅器與鐵器同時東傳。
- **移民**：大陸移民（渡來人）攜技術抵達九州北部——戰國末期至秦漢之際的大陸動盪推動移民潮。
- **地理**：九州—瀨戶內—近江—關東的平原走廊，稻作擴散的「高速公路」。
- **繩紋底層**：高度定居的村落與陶器傳統——稻作「插上即用」，不需從零建立定居。

## 線索與推理 -- 因素咬合

### 線索一：稻作是「剩餘集中度」最高的作物

| | 採集（繩紋） | 稻作（彌生） |
|---|---|---|
| 剩餘 | 分散於林地海岸 | 集中於穀倉 |
| 人口密度 | 約每平方公里數人 | 十倍以上 |
| 可壟斷性 | 低 | 高（控制水源＝控制所有人） |
| 戰爭誘因 | 低 | 高（搶穀倉、搶水源） |

$$\text{社會複雜度} \propto \text{（剩餘集中度）} \times \text{（人口密度）}$$

**灌溉稻作同時最大化兩個變數**——這是彌生六百年追平三千年演化的數學。

### 線索二：水是權力

濕田稻作需要跨村落的灌溉與排水系統——**協調半徑決定權力半徑**。誰組織水利，誰就是首長；首長的權威再被青銅器（銅鐸、銅鏡）的宗教象徵加固。這條「水利→王權」的因果鏈，與兩河、中國（[0605-科舉與中國官僚帝國](../世界簡史/0605-科舉與中國官僚帝國.md)前的先秦水利國家）同構。

### 線索三：技術移植的「時間壓縮」

彌生不是重演繩紋→農業的漸進，而是**整套套裝（稻作＋金屬器＋織布＋儲存技術）一次移植**——像電腦直接裝上現成的作業系統：

$$\text{演化時間} = \frac{\text{內生發展所需}}{\text{技術移植程度}}$$

移植程度高 → 演化時間被壓縮兩個量級。此後日本史反覆出現同一模式：**645 大化革新、1868 明治維新——每一次「文明跳躍」都是大規模技術移植**。

## 破案時刻

- 約前 300：九州北部（佐賀、福岡）最早水田遺跡；渡來人聚落。
- 前 200–100：稻作沿瀨戶內海東進；銅鐸文化在近畿擴散。
- 前 100–250：戰爭遺跡（環濠聚落、箭鏃傷）激增——階層與軍事組織成形。
- 57：漢委奴國王金印（《後漢書》記載）——彌生政體進入中國冊封體系。

## 後果 -- 改變了什麼

- **政治**：小型首長制 → 區域聯盟 → 邪馬台國等「準國家」（[0250-邪馬台國與卑彌呼.md](0250-邪馬台國與卑彌呼.md)）。
- **社會**：階層分化（豪族—農民—奴婢）、軍事貴族誕生——武士的千年伏筆。
- **文化**：稻作祭祀成為神道核心（插秧祭、收穫祭）；稻＝財富＝權力，此後日本以米本位計算一切。
- **人口**：彌生人口從數十萬成長至數百萬——「稻作人口炸彈」是此後所有日本史的動能來源。

## 因素影響筆記

```
大陸動盪 ──→ 渡來人移民 ──→ 稻作＋金屬器移植
                                 ↓
灌溉協調 ──→ 首長權威 ──→ 階層分化 ──→ 村落戰爭 ──→ 政治體
```

**偵探結語**：彌生革命證明：**一個社會的演變速度，等於它吸收外來技術的能力**。繩紋的一萬年等待，被一船稻種終結——而「吸收、改造、再輸出」將成為此後兩千年日本史的主旋律。
