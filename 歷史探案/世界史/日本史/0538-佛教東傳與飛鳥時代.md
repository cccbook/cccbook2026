# 0538-佛教東傳與飛鳥時代：宗教作為國家工程的進口

## 案件摘要

538 年（一說 552），百濟聖明王獻釋迦佛像與經論給欽明天皇——**佛教正式傳入日本**。這樁案件的表面是宗教傳播，實質是**政治工程的進口競標**：佛教連同其整套「中國式國家技術」（文字、律令、建築、官僚觀念）一起抵達。蘇我氏擁佛、物部氏排佛的「崇佛之爭」（587 滅亡），本質是**要不要全盤引進大陸國家體制**的路線之爭。此後飛鳥時代（592–710）的聖德太子改革與隋唐交流，都是這場競標的後果。

## 前因 -- 多因素的局勢

- **地緣**：朝鮮半島三國（高句麗、百濟、新羅）競爭，百濟以佛教＋技術輸出拉攏大和——佛教是外交禮物。
- **政治**：大和政權內部，蘇我氏（掌財政與外交）與物部氏（掌軍事與祭祀）對立。
- **宗教**：神道是分散的氏族祭祀——**沒有中央集權的宗教基礎設施**；佛教恰好補上。
- **資訊**：文字（漢字）隨佛教經典一同進口——識字技術與宗教捆綁輸出。

## 線索與推理 -- 因素咬合

### 線索一：佛教是「國家作業系統」的載體

佛教傳入的不是一尊佛像，而是整套中國式國家的基礎設施：

| 捆綁組件 | 功能 |
|---|---|
| 漢字與經典 | 文書行政的技術前提 |
| 律令與戒律 | 成文法與組織紀律的範本 |
| 寺院建築 | 永久性的政治—經濟據點（瓦、水車等技術） |
| 官僚與歷法觀念 | 中央集權的觀念工具 |

$$\text{佛教傳入} = \text{宗教} \oplus \text{文字} \oplus \text{律令} \oplus \text{建築技術}$$

**誰控制進口，誰就壟斷新技術**——蘇我氏掌外交，壟斷佛教進口，從而壟斷新的國家技術。

### 線索二：崇佛之爭是路線之爭

物部氏主張「國家拜神道即可」，蘇我氏主張引佛。表面教義之爭，實質：**接納佛教＝接納中國式中央集權的整個前景**——物部氏的軍事貴族地位，將被官僚帝國稀釋。587 年蘇我馬子殺物部守屋，路線之爭以武力結案——**日本選擇了「全盤中國化」**。

### 線索三：聖德太子的「制度搶跑」

593 年推古女帝即位，聖德太子攝政（與蘇我氏共治——又是「名義權威＋實權代理」結構，見 [0250-邪馬台國與卑彌呼.md](0250-邪馬台國與卑彌呼.md)）：

- 603 冠位十二階：以官位取代氏族世襲的序位——**官僚制的胚胎**。
- 604 憲法十七條：以「和」（和を以て貴しとなす）與佛教、儒教混合的成文政治綱領——**日本史上第一部「政治哲學文本」**。
- 遣隋使（607）：直接向隋學習，跳過朝鮮中介——「對等外交」與「技術直購」。

$$\text{制度移植} = \text{派遣學生} \times \text{（留學時間）} \times \text{回國後的位階}$$

遣隋使攜回的不只是佛經，而是一批**留學三十年後回國主政的官僚**（高向玄理等）——他們將在 645 大化革新中落地整套律令制。

## 破案時刻

- 538/552：百濟獻佛；欽明天皇問「可崇否」——佛像是外交籌碼。
- 587：蘇我馬子滅物部守屋——崇佛路線確立。
- 592–622：推古朝、聖德太子攝政；法興寺、法隆寺建立（現存世界最古老木建築群）。
- 607：遣隋使小野妹子（「日出處天子致書日沒處天子」）——對等國書的最早嘗試。
- 645：大化革新——太子時代培養的留學生集團發動政變（[0645-大化革新.md](0645-大化革新.md)）。

## 後果 -- 改變了什麼

- **政治**：氏族制 → 律令官僚制的軌道確立；寺院成為準官僚機構。
- **宗教**：神佛習合——神道吸收佛教形式存活，「本地垂跡」理論讓兩神共存。
- **文化**：漢字、書法、建築、美術的全面輸入——飛鳥文化（法隆寺）是「移植期」的產物。
- **對外**：遣隋唐使的傳統確立——「學習—移植—改造」成為日本史主旋律。

## 因素影響筆記

```
朝鮮三國競爭 ──→ 佛教＋國家技術捆綁輸出
                        ↓
蘇我（擁佛）vs 物部（排佛）── 路線之爭 ──→ 587 武力結案
                        ↓
聖德太子：冠位＋憲法＋遣隋使 ──→ 留學官僚集團 ──→ 645 大化革新
```

**偵探結語**：佛教東傳案件的真相是：**宗教從來不只是信仰，它是組織技術的載體**。日本選佛，等於選擇了整個中國式國家的作業系統——而這個選擇，將在六十年後以「大化革新」的形式安裝完成。
