# 1560-桶狹間之戰與信長崛起：兩千對兩萬五的數學

## 案件摘要

1560.5.19，尾張守護代織田信長率約2000兵，暴雨中奇襲桶狹間山，斬今川義元——**東海道第一弓取的兩萬五千大軍一夕崩盤**。前案鐵炮（見 [1543-鐵炮傳來.md](1543-鐵炮傳來.md)）講了武器，後案本能寺（見 [1582-本能寺之變.md](1582-本能寺之變.md)）講了結局，中間獨缺：**信長如何從尾張「大傻瓜」變成天下布武？**本案還原下剋上的組織革命。

## 前因 -- 多因素的局勢

- **地理**：尾張處三河—美濃—伊勢三叉口，熱田—津島湊連通伊勢灣海運，木曾川氾濫造就輪中耕地＋高商品化率。
- **政治**：斯波守護—織田守護代—三奉行家臣團三層空轉，信長1559統一尾張下四郡（浮野之戰滅岩倉織田）。
- **軍事**：今川假名目錄＋大高城兵糧入れ（松平元康先鋒）——義元志在上洛，號稱兩萬五（實約一至兩萬）。
- **技術**：尾張已裝備國產鐵炮數百挺（津島商人輸入堺筒），馬廻眾常備化萌芽。

## 線索與推理 -- 因素咬合

### 線索一：今川為何必敗？——「行軍縱隊的資訊災難」

| 項目 | 今川軍 | 織田軍 |
|---|---|---|
| 兵力 | 約20000（縱隊綿延數里） | 約2000–3000（集中） |
| 情報 | 不知信長出城（以為籠城） | 梁田政綱＋佐佐一線目付網 |
| 地形 | 桶狹間隘路休息吃飯 | 大高道—中島砦迂迴 |
| 天氣 | 暴雨＝鎧甲弓弦失效 | 暴雨＝掩護接近 |

$$\text{奇襲成功率} = \frac{\text{（情報不對稱）} \times \text{（敵縱隊脆弱度）} \times \text{（暴雨掩護）}}{\text{（兵力比 } 1:10\text{）}}$$

分子三項皆爆表，分母被局部集中抵銷——信長只打義元本陣3000人，外圍萬人不戰自潰。**不是以少勝多，是以多（局部）打少（本陣）**。

### 線索二：尾張組織革命——兵農分離的前夜

信長戰後繳獲今川假名目錄，反向輸出「分國法升級版」：黑母衣眾、赤母衣眾（常備親衛）、馬廻＋足輕長槍化、樂市樂座（津島—熱田免稅）：

$$\text{動員力} = \text{（樂市商稅）} \times \text{（常備足輕）} \div \text{（動員季節約束} \to 0\text{）}$$

傳統守護動員＝農忙停戰；尾張常備化後**一年十二個月皆可戰**——1560–1568連戰美濃（齋藤龍興）、伊勢（北畠），1568擁足利義昭上洛。學術理論（藤木久志「兵農分離」）：桶狹間是**兼業武士向職業軍隊的相變點**。

### 線索三：松平元康的選擇——人質變盟友

義元死，大高城中19歲松平元康（後家康）拒退三河、清洲同盟（1562）：

$$\text{同盟穩定} = \text{（共同敵人：今川殘部＋武田）} + \text{（姻親：信康—五德）} - \text{（領土重疊} \approx 0\text{）}$$

東面屏障外包給德川，信長得以西向——**桶狹間的最大戰利品不是甲冑，是德川**。沒有清洲同盟就沒有小牧—關原（見 [1600-關原之戰.md](1600-關原之戰.md)）的百年伏筆。

## 破案時刻

- 1559：浮野之戰——尾張統一。
- 1560.5.18：今川入大高城、今川軍田樂狹間休息。
- 1560.5.19午：暴雨奇襲、義元戰死、松平退守大高。
- 1562：清洲同盟——織德軸心成立。
- 1567：稻葉山落城、岐阜改名、天下布武印啟用。
- 1568.9：上洛、義昭就將軍——戰國終局開幕。

## 後果 -- 改變了什麼

- **軍事**：常備足輕＋鐵炮＋樂市財政三件套，成為信長—秀吉—家康統一戰爭的標準配備（長篠、關原皆其放大版）。
- **政治**：守護—守護代體制總崩潰示範——全國大名競相仿效下剋上組織升級（武田、毛利皆學尾張）。
- **經濟**：樂市樂座擴散——座壟斷解體，堺—京商人資本轉向尾張—美濃，統一的錢袋紮口。
- **心理**：「大傻瓜」敦盛舞出陣傳說——非常識決策的神話化，後世政變者的髮型目錄。

## 因素影響筆記

```
尾張商品化＋鐵炮 ──→ 常備化 ──→ 桶狹間局部集中 ──→ 義元死
                                                        ↓
清洲同盟（德川外包東面）──→ 西向美濃伊勢 ──→ 1568上洛
                                                        ↓
                                            天下布武（統一前半）
```

**偵探結語**：桶狹間不是奇蹟，是算術——**把決戰縮小到能贏的尺寸，再用暴雨把尺寸藏起來**。信長此後二十二年，不過是把同一道算術題做大十倍而已。
