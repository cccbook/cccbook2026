# 1185-平家滅亡與鎌倉幕府：武士集團的第一次親政

## 案件摘要

1167 年**平清盛**以太政大臣權力組建首個武士政權（平氏政權），1180 年**源賴朝**在伊豆舉兵，1185 年壇浦合戰平家滅亡（安德天皇抱劍投海），1192 年賴朝任**征夷大將軍**、開設**鎌倉幕府**。這樁案件是[0940-承平天慶之亂與武士崛起.md](0940-承平天慶之亂與武士崛起.md) 的兌現：**暴力供給者從朝廷手中接管政權**——日本政治從此進入「雙重政府」（Dual Polity：京都朝廷＋鎌倉幕府）近七百年。

## 前因 -- 多因素的局勢

- **政治**：保元・平治之亂（[1086-院政時代.md](1086-院政時代.md)）後武士成為內戰主角；平氏政權（1167–1185）證明武士可以親政。
- **軍事**：平清盛排斥源氏（流放賴朝）→ 以仁王令旨（1180）給源氏舉兵的合法性。
- **組織**：源賴朝在關東重建「御恩↔奉公」網絡——御家人制（gokenin）。
- **經濟**：關東的開發領主經濟 → 武士團的財政獨立於朝廷莊園。

## 線索與推理 -- 因素咬合

### 線索一：平氏為何失敗？——「貴族化」的組織自殺

平清盛掌權後，迅速貴族化：遷都福原（1180 半年即還都）、任太政大臣、女兒入宮——**武士政權的領袖放棄了武士組織的基礎**：

| | 平氏政權 | 源氏（鎌倉） |
|---|---|---|
| 權力基礎 | 宮廷官位 | 御家人主從網 |
| 財政 | 依賴朝廷莊園 | 關東開發領主＋守護地頭 |
| 軍事 | 僱用武士 | 自己就是武士集團 |
| 對天皇 | 操控皇位（高倉→安德） | 形式尊重、實質獨立 |

$$\text{政權耐久度} \propto \text{（組織基礎的獨立性）}$$

**平氏把武力交換成宮廷地位——當戰爭來臨，交換不回來**。1180–1185 五年戰爭，平氏的宮廷官位一文不值，鎌倉的御家人網絡才是真正的資本。

### 線索二：賴朝的組織工程——御家人制

賴朝在關東做的不是征服，而是**契約網絡的重建**：武士「參」賴朝 → 賴朝確認其「本領安堵」（領地保證）+ 任命守護、地頭 → 武士奉公。**御家人制的本質是「全國化的御恩↔奉公」**：

$$\text{鎌倉權力} = \sum(\text{各御家人的領地}) \times \text{（主從忠誠度）}$$

1185 年後設置**守護（軍事警察）＋地頭（徵稅）**——武家政權的行政網從此覆蓋全國。1192 征夷大將軍任命只是**朝廷對既成事實的追認**。

### 線索三：承久之亂（1221）——雙重政府的確認戰

後鳥羽上皇趁（尼將軍）北條政子垂簾與執權北條義時對立而舉兵——結果幕府軍上洛、**上皇配流、朝廷從此無力**。北條氏此後以「執權」攝政（又是「名義權威＋實權代理」！）統治至 1333。承久之亂證明：**軍事上鎌倉已凌駕京都**——雙重政府的權力重心確定。

## 破案時刻

- 1180.5：以仁王令旨；賴朝伊豆舉兵——源平合戰開始。
- 1183：俱利伽羅峠、木曾義仲入京；後白河法皇與賴朝結盟。
- 1184：一之谷合戰——平氏西走。
- 1185.3：壇浦合戰——平家滅亡；同年設置守護、地頭。
- 1192：賴朝任征夷大將軍——幕府的法律起點。
- 1219：賴家、實朝被殺——源氏將軍家斷絕；北條執權確立。
- 1221：承久之亂——幕府上洛、朝廷臣服。

## 後果 -- 改變了什麼

- **政治**：雙重政府（京都＋鎌倉）——日本政治的七百年結構；武家從此是實權的擁有者。
- **組織**：御家人制 → 主從制的全國化——「御恩↔奉公」成為武士社會的原始碼。
- **文化**：武士道的萌芽（弓馬之道）、《平家物語》的軍記文學——「驕者必敗」的敘事。
- **宗教**：鎌倉新佛教（法然、親鸞、日蓮、道元）——免於貴族化的「庶民宗教」爆炸。

```
以仁王令旨（1180）──→ 賴朝舉兵 ──→ 御家人網 ──→ 1185 壇浦
                                              ↓
                            1192 幕府 ──→ 1221 承久 ──→ 雙重政府定型
```

**偵探結語**：源平合戰案件的真相是：**組織擊敗地位**。平清盛有太政大臣的地位，賴朝有御家人的組織——戰爭是最殘酷的組織審計，平氏交了白卷，而鎌倉用契約網買下了日本。
