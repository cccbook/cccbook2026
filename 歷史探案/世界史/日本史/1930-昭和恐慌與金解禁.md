# 1930-昭和恐慌與金解禁：最壞時機的直角相遇

## 案件摘要

1929.11，濱口雄幸民政黨內閣宣布**金解禁**（1930.1 執行）：解除 1917 以來的金本位禁輸，並以**舊平價**復歸——等於日圓實質升值近一成。兩週前，華爾街已崩盤（1929.10.24）——**兩件巨災以直角相遇**：升值砍出口，大恐慌砍外需，出口腰斬、失業暴增、農村賣兒賣女。井上準之助（大藏相・日銀總裁）堅持緊縮——1931.11 被右翼刺殺；同年 12 月，**高橋是清接任：切斷金本位＋日圓貶值＋赤字公債＋軍擴財政**——日本成為世界最早脫離恐慌的國家，**凱因斯式政策的先手**。但軍費的後門由此打開——1936 二二六事件高橋被殺（[1936-二二六事件.md](1936-二二六事件.md)），剎車拔除。恐慌→農村絕望→青年將校的溫床——經濟危機與軍事冒險的因果鏈，在此案完整現形。

## 前因 -- 多因素的局勢

- **貨幣**：一戰出口暴增（[1914-一次大戰與日本的躍進.md](1914-一次大戰與日本的躍進.md)）→ 1917 金輸出禁止——戰後回歸金本位成為「正統」執念。
- **金融**：關東大地震（[1923-關東大地震.md](1923-關東大地震.md)）震災手形→昭和金融恐慌（1927）——金融體系帶傷上陣。
- **政治**：民政黨（濱口）主張協調外交＋緊縮正統財政；井上準之助為「舊平價復歸」的信仰者——**通貨升值被誤認為國家信用問題**。
- **國際**：世界大恐慌（1929.10）——金本位制的連鎖緊縮（各國以緊縮保衛平價）——**正統政策成為全球同步放大器**。

## 線索與推理 -- 因素咬合

### 線索一：舊平價的升值——「信用的代價標錯了價」

戰前平價 1 日圓＝0.5 美元；1930 通貨已貶約 10%——按舊平價解禁＝**實質升值**：

$$\text{出口競爭力} = \frac{\text{外國物價}}{\text{本國物價} \times \text{匯率}}$$

匯率升高 → 競爭力分母膨脹 → 出口劇減。井上的邏輯：貶值復歸＝「國家的不誠實」，舊平價＝信用——**反直覺洞見：金本位的「誠實」在恐慌期是最貴的奢侈品**——英國 1931.9 放棄金本位、日圓隨之浮動後，出口立刻復活——證明問題不在信用而在價格。生絲（對美出口主力）價格腰斬——養蠶農家的現金收入（占農家所得近四成）蒸發——**升值打擊的是都市工廠，恐慌消滅的是農村的現金流**。

### 線索二：農村的絕望——「恐慌的社會剖面」

| 指標 | 1929 | 1931 前後 |
|------|------|-----------|
| 生絲價格 | 高位 | 腰斬（約半價） |
| 農家米價 | — | 暴跌（豐作も凶作像） |
| 失業（都市） | — | 數十萬人（一說 200 萬＋含半失業） |
| 東北農村 | 貧困 | 賣兒賣女・緊縮到不吃午飯 |

豐收年米價反跌（豐作饑饉）——**農家的會計：收入彈性為負**。東北（青森、岩手、秋田）成為絕望的地帶——賣女兒、小學生便當只有芋粥——**這不是統計的谷底，是青年將校的故鄉**：陸軍下級軍官多出身農村，二二六事件的「昭和維新」訴求（尊皇・擊倒財閥・拯救農村）直接引用家鄉的慘狀。恐慌的咬合：

$$\text{激進化風險} = \text{（農村絕望）} \times \text{（官僚・財閥的距離感）} \times \text{（軍部獨立性）}$$

三項同時最大化——緊縮（井上）被右翼視為財閥共犯——1931.11 井上準之助在相馬事件中被射殺——**緊縮的第一具遺體**。

### 線索三：高橋的轉向——「脫離恐慌的先手與後門」

1931.12 高橋是清就任：金輸出再禁止（金本位脫離，日圓貶值約 50% 至舊平價的 2/3）＋**赤字公債（日銀承銷）＋軍擊擴充＋低利率**——與世界各國（仍困於金本位緊縮）相比：

$$\text{脫離速度} = \text{（匯率貶值）} + \text{（財政擴張）} - \text{（金本位拘束）}$$

日本 1932-33 復甦——**早於羅斯福新政一年，凱因斯《一般理論》出版（1936）之前四年**——高橋的實踐先於理論。但先手有後門：軍費從 1931 的約 4.5 億日圓膨脹到 1936 年度預算近半——高橋反對無限增額——**軍部（皇道派青年將校）的預算剎車手，1936.2.26 被殺**——財政省的「公債剎車」拔除，此後預算由軍部定價。滿洲事變（[1931-滿洲事變與軍國主義.md](1931-滿洲事變與軍國主義.md)）恰在高橋轉向的三個月前發動——**「恐慌的出口」與「軍事的出口」在同一個冬天被同時提出**，軍事的出口更快、更受歡迎——這是本案最深的咬合：**高橋財政救了景氣，卻沒能救走軍部的動能**。

## 破案時刻

- 1929.10：華爾街崩盤。
- 1929.11：濱口內閣宣布金解禁（舊平價）。
- 1930.1：解禁執行——實質升值＋大恐慌直角相遇。
- 1930-31：出口腰斬、生絲崩價、農村慘狀。
- 1930.11：濱口首相被射（翌年死）。
- 1931.9：滿洲事變（關東軍自導）；英國脫離金本位。
- 1931.11：井上準之助被刺殺。
- 1931.12：高橋是清就任——金輸出再禁止、赤字財政。
- 1932-33：日本率先復甦（世界最早脫離恐慌）。
- 1936.2.26：二二六事件——高橋被殺、剎車拔除。

## 後果 -- 改變了什麼

- **經濟**：早期復甦＋重化學工業軍事化——「軍需景氣」取代「船成金」——產業結構向戰爭經濟傾斜。
- **財政**：公債剎車失效 → 軍費常態化 → 通膨與戰時統制經濟的前奏。
- **政治**：井上・濱口・高橋（三位緊縮與節制的守門人）相繼死於暗殺——**守門人消失後，預算成為軍部的獵場**。
- **社會**：農村絕望的記憶 → 青年將校的意識形態 → 二二六的「昭和維新」訴求——恐慌的社會遺產以軍事政變的形式結帳。

## 因素影響筆記

```
一戰繁榮＋金本位執念 ──→ 1930 舊平價解禁（實質升值）
                              ↓
華爾街崩盤（1929.10）──直角相遇──→ 出口腰斬＋生絲崩價
                              ↓
        農村絕望 ──┬──→ 右翼暗殺（井上・濱口）
                    └──→ 青年將校的溫床（東北出身）
                              ↓
高橋轉向（1931.12）：切斷金本位＋赤字公債＋軍擴 ──→ 最早復甦
                              ↓
        軍費膨脹 ──→ 高橋踩剎車 ──→ 二二六（1936）──→ 剎車拔除
                              ↓
              戰爭經濟軌道 ──→ 1937 以後的全面戰爭
```

**偵探結語**：昭和恐慌案是「時機」的刑事案件：日本在最壞的時刻做了最正統的事——**正確的政策放在錯誤的時點，傷害等於加倍**。高橋是清用貶值與赤字證明了先見之明，卻無法給軍費裝上煞車——**能救景氣的財政，救不了被景氣餵大的軍隊**。三位守門人的血案告訴我們：恐慌真正的遺產不是失業率，而是絕望被誰回收——軍部回收了它，於是農村的饑饉變成了滿洲的鐵路和東京的叛亂。
