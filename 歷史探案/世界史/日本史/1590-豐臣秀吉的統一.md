# 1590-豐臣秀吉的統一：農民出身者的天下布武

## 案件摘要

1590 年小田原征伐（北條氏滅亡）——**豐臣秀吉完成日本統一**（戰國時代終結）。秀吉出身尾張農民（足輕→信長家臣→天下人）——日本史上唯一的「平民天下人」。此後八年（1590–1598）：太閤檢地、刀狩、戶口調查、文祿慶長之役（[1592-壬辰戰爭.md](1592-壬辰戰爭.md)）——**統一的制度化與對外膨脹的雙軌**。這樁案件是「流動性的頂點與終結」：秀吉用下剋上的梯子爬上頂點，然後**親手抽掉梯子**（兵農分離的固定化）。

## 前因 -- 多因素的局勢

- **政治**：本能寺之變（[1582-本能寺之變.md](1582-本能寺之變.md)）後的繼承戰——清洲會議、賤岳之戰（1583 勝柴田）、小牧長久手（1584 和德川）。
- **軍事**：信長遺產（鐵炮、樂市樂座、兵農分離）＋秀吉的動員力（四國 1585、九州 1587、小田原 1590）。
- **社會**：戰國的身份流動化——農民→足輕→武士的通道仍開。
- **經濟**：石高制（米本位）的確立——全國土地的量化管理。

## 線索與推理 -- 因素咬合

### 線索一：秀吉的統一技術——「包圍網＋大動員」

秀吉的戰略：不與強敵決戰，而是**經濟封鎖＋多路大軍壓境**（小田原：20 萬大軍圍城三月、水陸封鎖）：

$$\text{統一速度} = \text{（動員規模）} \times \text{（補給能力）} \times \text{（敵方孤立度）}$$

秀吉的動員規模（數十萬）是戰國前所未見——**統一不是打贏，而是讓對手「算出必敗」而開城**。小田原北條開城、奧羽大名臣服——皆是「算術的勝利」。

### 線索二：太閤檢地＋刀狩——「身份的凍結」

- 太閤檢地（1582–1598 全國）：丈量土地、確定石高與耕作者——**全國土地的資料庫**。
- 刀狩令（1588）：沒收農民武器——「農民持刀→一揆」的歷史終結。
- 人掃令（1591）、戶口調查：**武士—町人—農民的身份固定**。

$$\text{統治穩定} = \text{（身份凍結）} \times \text{（武器壟斷）} \times \text{（土地資料庫）}$$

**秀吉用下剋上的梯子登頂，然後燒掉梯子**——此後日本再無農民天下人。德川幕藩體制（[1603-江戶幕府.md](1603-江戶幕府.md)）直接繼承這套凍結。

### 線索三：對外膨脹——統一剩餘的出口

1592 文祿之役、1597 慶長之役（朝鮮出兵）——為何統一後立即對外用兵？偵探的經濟學：

$$\text{對外用兵動機} = \text{（戰國武士團的剩餘武力）} + \text{（恩賞不足）} + \text{（秀吉的明國征服幻想）}$$

統一後數十萬武士無仗可打、無地可封——**對外戰爭是「剩餘武力的出口」**。七年戰爭耗盡豐臣財政與武將忠誠——**秀吉的對外膨脹，是豐臣滅亡的起點**（關原的伏筆）。

## 破案時刻

- 1583：賤岳之戰——勝柴田勝家；築大坂城——政權據點。
- 1584：小牧長久手——與德川和解（聯盟）。
- 1585：關白就任——公家官位的頂點（「豐臣」賜姓）；四國平定。
- 1586：太政大臣——武家官位的頂點。
- 1587：九州平定；伴天連追放令（[1549-天主教傳來.md](1549-天主教傳來.md)）。
- 1590：小田原征伐——統一完成；奧羽仕置。
- 1591–1598：檢地、刀狩、戶口調查的制度化。
- 1592/1597：文祿慶長之役——對外膨脹（[1592-壬辰戰爭.md](1592-壬辰戰爭.md)）。
- 1598.8：秀吉病死——五大老五奉行的遺制、幼主秀賴。

## 後果 -- 改變了什麼

- **政治**：戰國終結 → 豐臣政權——大名聯盟體制（參勤交代的雛形）；關原（[1600-關原之戰.md](1600-關原之戰.md)）的舞台。
- **社會**：士農工商的凍結——身份制的起點；「下剋上」時代的終結。
- **經濟**：石高制＋全國檢地——米本位的財政國家；大坂的商業中心化。
- **對外**：壬辰戰爭（1592–1598）——東亞國際秩序的震盪；豐臣財政的透支。

## 因素影響筆記

```
本能寺（1582）──→ 清洲＋賤岳＋小牧 ──→ 秀吉繼承
                                            ↓
包圍網＋大動員 ──→ 1590 小田原統一 ──┬──→ 檢地＋刀狩（身份凍結）
                                      └──→ 壬辰戰爭（剩餘武力出口）──→ 財政透支
```

**偵探結語**：秀吉案件是流動性的輓歌：**最後一個爬上頂點的人，親手封了路**。太閤檢地與刀狩是統一的制度化，也是下剋上的訃告——而對朝鮮的出兵，是剩餘武力的出口，也是豐臣壽命的倒數。
