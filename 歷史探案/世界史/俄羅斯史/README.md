# 俄羅斯史的歷史年表（推理探案）

> 俄羅斯史是森林、草原與帝國互相塑造的偵探史：留里克是北歐海盜還是斯拉夫酋長——為何一個起源問題能吵兩百年？弗拉基米爾為何在伊斯蘭、猶太教、天主教、東正教之間選擇了拜占庭？蒙古枷鎖的兩百年，是災難還是俄羅斯中央集權的產房？伊凡四世的特轄區是瘋狂還是精算？彼得大帝為何要親手剪掉貴族的鬍子？拿破崙的大軍為何走進莫斯科、卻走不出去？農奴解放為何解放了農奴、卻沒解放土地？十月革命是政變還是革命——七個月的臨時政府為何守不住？五年計劃的鋼鐵產量是奇蹟還是謊言？大清洗為何先清洗自己人？史達林格勒的轉折點，是冬天、是伏爾加河，還是蘇聯的動員體制？赫魯雪夫的秘密報告為何一邊反史達林、一邊保體制？加加林上天之後，為何是美國先登月？戈巴契夫想救蘇聯，為何親手埋葬了它？
>
> 本書以「推理探案」的方式，為每個歷史事件寫一篇 wiki，包含前因後果、學術理論與跨領域影響矩陣。每篇檔名以年份開頭（四碼不足補零）。
>
> 本書的核心命題：**俄羅斯的歷史是「空間、集權與趕超」的三重奏**——無險可守的平原逼出中央集權，落後的焦慮逼出自上而下的西化與工業化；每篇 wiki 都以「跨領域影響矩陣」拆解政治、經濟、科技、文化與法律的互動。

## 閱讀路線（偵探式提問）

- **枷鎖與集權線**：蒙古納貢（1240）→ 莫斯科收稅權（1480）→ 特轄區（1547）→ 彼得官秩表（1682）——對外屈服如何內化為對內集權。
- **西化趕超線**：彼得剪鬍子（1682）→ 維特鐵路（1891）→ 五年計劃（1928）→ 太空競賽（1961）——落後焦慮驅動的三次自上而下趕超。
- **改革與反噬線**：農奴解放（1861）→ 十月宣言（1905）→ 新經濟政策（1921）→ 秘密報告（1956）→ 改革開放（1985）——每一次鬆綁都走向失控或回潮。
- **戰爭塑造線**：庫里科沃（1380）→ 波爾塔瓦（1709/1682 篇）→ 衛國戰爭（1812）→ 史達林格勒（1941）——外敵是俄羅斯國家建構的接生婆。
- **合法性枯竭線**：十二月黨人（1825）→ 二月（1917）→ 大清洗（1936）→ 解體（1991）——當統治的理由耗盡，帝國無論新舊都會倒塌。
