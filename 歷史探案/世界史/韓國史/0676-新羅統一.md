# 0676 新羅統一：借唐刀殺人，再把刀主請出去

## 案發現場

660 年，新羅聯合唐軍滅百濟；668 年，再聯唐滅高句麗。然後——新羅掉轉槍口，675–676 年羅唐戰爭，把曾經的盟友唐軍趕出半島（僅留安東都護府於遼東）。半島首次統一在一個本土政權手裡。借來的刀用完了，刀主也被請走了。

> **為何新羅敢對宗主國開戰？借師助剿是引狼入室，還是請君入甕——新羅的兩步棋是如何算好的？**

## 偵查過程

**線索一：借師助剿（弱者的槓桿）。** 新羅同時面對百濟（武烈王）與高句麗的夾擊，金春秋赴唐求援——唐高宗正欲經略東北，雙方一拍即合。偵查結論：這是**曼陀羅外交的半島實踐**（參見 [../亞洲史/-0321-孔雀帝國.md](../亞洲史/-0321-孔雀帝國.md)）——「敵人的敵人是朋友」，新羅用唐軍當槓桿，撬掉兩個強鄰。弱者的生存術：**自己打不贏的仗，借別人的手打**——代價是戰後分贓（唐設熊津、安東都護府，意圖直轄）。

**線索二：唐的直轄企圖（盟友變佔領軍）。** 滅百濟後，唐置熊津都督府；滅高句麗後，置安東都護府，劉仁軌留守平壤——唐的意圖很明確：**把半島變成直轄州縣**。偵查結論：新羅文武王看穿了這一點——借來的刀不還了，變成了插在自家的刀。羅唐戰爭的動機不是背叛，是**自衛**：要麼接受唐直轄（半島版安史前的節度使），要麼開戰。此時唐軍遠征疲憊、補給線橫跨黃海——**佔領軍的虛弱窗口**正是開戰時機。

**線索三：羅唐戰爭（把補給線當武器）。** 675 年買肖城、稷山之戰，新羅勝；676 年唐軍撤至遼東。偵查結論：新羅的勝因與薩水同構（參見本書 [0612-薩水之戰.md](0612-薩水之戰.md)）——唐軍跨海遠征，補給係數低；新羅本土作戰，又得百濟、高句麗遺民支持（佔領軍不得人心）。加上唐廷同時面對吐蕃威脅（參見 [../亞洲史/0755-安史之亂.md](../亞洲史/0755-安史之亂.md)前史），無心東顧——**多線作戰的帝國必然收縮戰線**。新羅賭的是唐的理性：為半島南部與新羅死磕，不如保住遼東的基本盤。

**線索四：統一的代價（半島的南北斷裂）。** 新羅統一僅及大同江以南——以北故高句麗地歸唐安東都護府，後崛起渤海國（參見本書 [0698-渤海國.md](0698-渤海國.md)），形成「南北國時代」。偵查結論：這次統一是**不完整的統一**——半島政權首次整合南部，但北部（滿洲故地）永久丟失。此後韓國史的疆域以大同江—元山一線為北界——**統一的邊界寫好了此後一千三百年的地圖**。借唐刀的代價：刀主走時，帶走了遼東。

## 結案報告

1. **借刀殺人**：借唐軍滅百濟高句麗——弱者的槓桿，用別人的軍隊打自己的戰爭。
2. **刀主變佔領軍**：唐設都護府意圖直轄——盟友的軍隊不走，就是佔領軍；新羅開戰是自衛。
3. **賭帝國的理性**：唐多線作戰必收縮——新羅算準唐會為遼東放棄半島南部。
4. **不完整的統一**：大同江為界、渤海南北國——統一的邊界寫好了一千三百年的地圖，遼東從此是別人的。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 統一工程 | 跨域效應 |
|------|----------|----------|
| 法律 | 骨品制維持、唐律令參考 | 統一後的等級秩序 |
| 經濟 | 統一市場、唐朝貿易 | 南部經濟整合 |
| 科技 | 唐文化輸入（佛寺、曆法） | 慶州佛國寺前身 |
| 政治 | 借唐—抗唐兩步棋 | 半島首個統一政權 |
| 文化 | 佛教護國、鄉歌 | 統一認同的建構 |

**借刀 vs 驅刀（兩步棋對照）：**

| 步驟 | 借唐刀（660–668） | 驅唐軍（675–676） |
|------|-------------------|-------------------|
| 目標 | 滅百濟、高句麗 | 收復熊津等地 |
| 唐軍狀態 | 生力軍、有求於新羅 | 疲憊、補給線長 |
| 新羅籌碼 | 嚮導+補給+遺民 | 本土+民心+吐蕃牽制 |
| 結果 | 三國歸一（名義） | 半島自主（實際） |

**兩步棋邏輯（示意）：**

```
第一步：敵強我弱 → 借外力滅強敵（分贓：唐得都護府）。
第二步：外力變佔領 → 趁其疲憊開戰（賭：帝國多線必收縮）。
代價：遼東故地歸唐 → 南北國時代。
```

**結論：** 新羅案是「借外力統一」的標準作業：借刀時算好分贓，驅刀時算好時機——唯一的敗筆是算不到遼東。**借來的力量一定附帶帳單**：唐的帳單是遼東，此後每個借外力的半島政權（從新羅到韓戰的聯合國軍）都收到過同款帳單。
