# 1776 正祖改革與奎章閣：朝鮮的文藝復興未遂

## 案發現場

1776年，正祖（李祘）即位，設奎章閣（王立圖書館+政策智庫）、擢實學派（丁若鏞、朴齊家），行蕩平策、編《奎章全韻》、建華城。**1636丙子降清（見 [1636-丙子胡亂.md](1636-丙子胡亂.md)）到1866丙寅洋擾之間230年空白的正中央**，只此一亮。前案只講屈辱，後案直跳開港——**朝鮮後期是停滯兩百年，還是改革未遂兩百年？** 正祖24年（1776–1800）正是驗屍關鍵孔。

> **同樣開明，為何雍正成了、ARIA...不，正祖敗了？奎章閣、華城與蕩平——改革的三支箭為何全斷？**

## 偵查過程

**線索一：蕩平策——在黨爭上走鋼絲。** 老論、少論、南人、北人四色黨爭，英祖（祖父）以蕩平（超脫黨派、按才錄用）續命，正祖加碼：南人丁若鏞擢用、老論金鍾秀並用。偵查結論：**蕩平是「人事聯合政府」**，無制度配套（科舉仍兩班壟斷、薦舉仍門閥把持）。英祖殺世子思悼（1762壬午禍變，正祖生父）——正祖合法性自帶裂縫，老論隨時以「逆產」相脅。**改革者本人是人質**：華城遷都之議（顯隆園+水原）被解讀為逃離漢陽老論巢穴，未成先夭。

**線索二：奎章閣+實學——沒有科舉配套的智庫。** 奎章閣藏書十萬、設檢書官（抄寫+研究+政策諮詢三合一）、編《同文彙考》、引西學（南懷仁《時憲曆》、天主教《天主實義》流入）。偵查結論：這是**朝鮮的「江南製造局」早一百年**：丁若鏞設計舉重機（華城築城用）、朴趾源《熱河日記》倡北學（學清開商）。但經國大典體制（見 [1471-經國大典.md](1471-經國大典.md)）不動：兩班免稅+奴婢制+科舉詩賦取士——**智庫的每一份奏摺都撞在同一堵牆上**。對照日本松平定信寬政改革（1787–93）同樣失敗：**東亞舊體制的改革天花板是同步的**，未撞南牆不回頭的是明治（外壓夠大）。

**線索三：華城——新都之夢與毒殺之死。** 1789遷父墓顯隆園、1794–96築華城（丁若鏞舉重機+磚石混築、東亞最早的新式要塞）、試行新稅（ Fal...不，華城府屯田）。偵查結論：**華城是「遷都公投」**：成功則漢陽老論地盤作廢，失敗則人亡政息。1800正祖暴斃（53...實年48，疑毒殺，史爭議）→ 貞純王后垂簾、老論復辟、1801辛酉邪獄（南人+天主教徒屠殺、丁若鏞流放）。**改革派與天主教的重疊（南人多信教）給了反撲最好的刀**：異端罪名一舉清洗智庫。華城未遷、人亡、書散——朝鮮失去最後的自我更新窗口，遂直滑向江華島（見 [1876-江華島條約.md](1876-江華島條約.md)）。

## 結案報告

1. **人質改革**：壬午禍變原罪——正祖每一步都被老論記帳。
2. **無配套智庫**：奎章閣+實學撞科舉+免稅牆——思想對了，制度不讓。
3. **華城賭局**：遷都未成、暴斃收場——1801邪獄是改革的葬禮。
4. **230年空白的答案**：不是無改革，是改革恰在中央夭折——下一個窗口要等甲午（見 [1894-甲午改革.md](1894-甲午改革.md)），代價是國權。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 正祖工程 | 跨域效應 |
|------|----------|----------|
| 法律 | 蕩平錄用 | 人事聯合、制度未動 |
| 經濟 | 華城屯田、北學開商議 | 萌芽、隨死而廢 |
| 科技 | 舉重機、時憲曆 | 工程+西學輸入 |
| 政治 | 奎章閣檢書 | 智庫孤島 |
| 文化 | 奎章全韻、正祖文集 | 朝鮮文藝復興殘篇 |

**英正 vs 雍乾對照：**

| 項目 | 正祖（1776–1800） | 雍正—乾隆（同時） |
|------|------------------|------------------|
| 君權 | 受老論制衡 | 軍機處獨裁 |
| 財政 | 兩班免稅不動 | 攤丁入畝+耗羨歸公 |
| 下場 | 暴斃+邪獄 | 盛世延續 |
| 差別 | 無財政—軍事配套 | 配套齊全 |

**改革方程式（示意）：**

```
成功 ＝ 君權（正祖半分）× 財政配套（0）× 軍事外壓（0）。
三項缺二——奎章閣藏書十萬卷，抵不過老論一包藥（傳說）。制度不讓，圖書館只是陵墓的裝修隊。
```

**結論：** 正祖案是朝鮮版「戊戌早一百年」：**人對了（丁若鏞不輸康梁）、書對了、時錯了**——無外壓則舊體不讓，無財政則新政無米。華城的城牆至今猶在（世界遺產），牆裡的新都夢只做了四年。
