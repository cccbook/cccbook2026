# 0958 光宗改革：用考試打破豪族壟斷

## 案發現場

958 年，高麗光宗行雙冀獻策，開科舉取士；956 年頒奴婢按檢法，解放豪族私奴。豪族激烈反彈——雙冀險遭暗殺，光宗大殺功臣（史稱光宗屠豪族）。一個王為何要對自己的開國功臣動刀？考試與解放奴婢之間是什麼關係？

> **科舉是選才制度，還是削藩武器？當王用考試對抗豪族，考場上考的是文章，考場下爭的是什麼？**

## 偵查過程

**線索一：豪族壟斷（開國的帳單）。** 王建靠豪族聯姻得國（參見本書 [0918-高麗建國.md](0918-高麗建國.md)）——代價是豪族分據地方、蔭敘（靠門第做官）壟斷官職。偵查結論：開國的併購款到期了——**王建用豪族統一，王建的子孫被豪族架空**。光宗面對的是典型的「創業股東坐大」：不削藩，王室變傀儡。科舉+解放奴婢=**釜底抽薪**：考試給寒門開上升通道（製造新股東），解放私奴削弱豪族經濟（拆除舊股東的錢袋）。

**線索二：科舉（忠誠的生產線）。** 科舉取士授官——新進官僚無門第、無根基，只能依附王權。偵查結論：考試的真正產品不是人才，是**忠誠**：寒門士人的一切來自王的錄取，天然是王黨。與秦郡縣（參見 [../世界發展史/-0221-秦統一.md](../世界發展史/-0221-秦統一.md)）同理——**把代理人的任免權收歸中央**，只是工具從任免狀換成考卷。中國科舉（0605）已有三百多年，光宗是**制度進口**：買現成的考試機，裝自己的削藩刀。雙冀（後周降臣）就是進口商——**改革需要外部顧問，因為內部全是既得利益者**。

**線索三：奴婢按檢法（打錢袋比打人有效）。** 豪族廣占田土、私蓄奴婢——奴婢是豪族的勞動力與私兵來源。按檢法把豪族奴婢辨正為良人（國家編戶）。偵查結論：這招比殺人狠——**殺豪族會引發叛亂，解放其奴婢是合法沒收其資產**：勞動力歸國家（稅基擴大），豪族經濟釜底抽薪。與商鞅「燔詩書」異曲同工：**改革的本質是產權重分配**，考試分的是官職產權，按檢分的是人口產權。兩場分配，一場針對未來（官），一場針對現在（錢）。

**線索四：屠豪族的代價（改革者的孤獨）。** 光宗晚年大殺功臣，史書（高麗史，朝鮮王朝所修）把他寫成暴君。偵查結論：這是**勝利者的史書問題**——修史的是此後被文官化的王朝，不喜歡動刀的王。但客觀效果：豪族坐大之勢被遏制，中央集權確立，此後高麗科舉延續四百年。**改革者的歷史評價=手段的殘忍度×史官的立場**——光宗用屠刀買了四百年科舉，史官用「暴君」兩字結帳。划算與否，後人自有公論。

## 結案報告

1. **開國帳單到期**：聯姻得國→豪族坐大→子孫削藩——創業股東終須清理。
2. **考試產忠誠**：科舉的真正產品不是人才，是依附王權的新股東——寒門即王黨。
3. **打錢袋不打人**：按檢法合法沒收豪族資產——產權重分配是改革的本質。
4. **史書即結帳**：屠刀買四百年科舉，史官回敬「暴君」——改革者的評價由敵人書寫。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 改革工程 | 跨域效應 |
|------|----------|----------|
| 法律 | 雙舉制、按檢法 | 官職與人口產權重分 |
| 經濟 | 奴婢解放為良 | 稅基擴大、豪族失血 |
| 科技 | 考試技術進口（雙冀） | 改革需外部顧問 |
| 政治 | 屠豪族、王權集中 | 中央集權確立 |
| 文化 | 儒學上升、佛教受抑 | 文治轉向起點 |

**兩場分配（對照）：**

| 項目 | 科舉（分官） | 按檢法（分人） |
|------|--------------|----------------|
| 對象 | 未來官職 | 現在勞動力 |
| 手段 | 考試 | 辨正身份 |
| 打擊面 | 豪族壟斷仕途 | 豪族經濟基礎 |
| 產出 | 王黨新股東 | 國家稅基 |

**削藩邏輯（示意）：**

```
豪族（錢＋蔭敘）→ 架空王室。
光宗：考試（造新股東）＋ 按檢（拆舊錢袋）＋ 屠刀（清不服者）
  → 中央集權 → 科舉延續四百年。
```

**結論：** 光宗案是「考試削藩」的完整樣本：考卷是刀，按檢是另一把刀，屠刀是刀鞘——三刀齊下，豪族時代結束。**考試從來不只是選才，更是權力重組的工具**——誰定義考什麼，誰就定義誰能當官；誰能當官，誰就擁有未來。
