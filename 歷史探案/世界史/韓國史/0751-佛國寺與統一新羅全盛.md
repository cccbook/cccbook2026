# 0751 佛國寺與統一新羅全盛：石頭上的南北國

## 案發現場

751年，宰相金大城重建佛國寺、開鑿石窟庵（774完工），慶州貴族建雁鴨池、瞻星台修繕。前案新羅統一（見 [0676-新羅統一.md](0676-新羅統一.md)）只講到趕走唐軍，後案渤海（見 [0698-渤海國.md](0698-渤海國.md)）只講北國——**中間二百年統一新羅（676–935）如何治理？為何史稱海東盛國卻突然崩解？** 751正是全盛的定影：石頭工程.MAX。

> **統一卻不強幹：新羅為何寧可雕石頭也不削豪族？佛國寺的錢從哪裡來，又流去哪裡？**

## 偵查過程

**線索一：骨品制——堵死的升遷天花板。** 聖骨、真骨、六頭品世襲官階，真骨以下不得任高官，大王须聖骨（後真骨代）。偵查結論：**統一靠真骨貴族聯軍，打完卻不分紅**。六頭品知識人（崔致遠系）只能做學者，地方豪族（村主）永為外官。對照高麗光宗科舉（見 [0958-光宗科舉.md](0958-光宗科舉.md)）打破壟斷：**新羅把科舉（758讀書出身科）做成安慰獎**——取士不授實職，人才遂流向海商（張保皋）與唐朝。**制度的天花板有多低，叛亂的地板就有多硬**。

**線索二：寺院經濟——免稅的黑洞。** 佛國寺、浮石寺、海印寺莊田免租稅，僧侶免役，貴族捨身布施（景德王以降）。偵查結論：**信仰即避稅**。三國遺民與豪族把田「寄進」寺院（名義布施、實質託管），國家稅基空心化。石窟庵一尊本尊動員采石、運輸、雕刻數千人年——**稅收變成石頭**，石頭不能當軍餉。9世紀三萬僧兵對三千府兵（中央軍）：**寺院比國家更像國家**，後來甄萱、王建（見 [0918-高麗建國.md](0918-高麗建國.md)）接收的正是這個空殼。

**線索三：張保皋的海——錯過的海洋選項。** 828張保皋設清海鎮，控唐—新羅—日本三角貿易， hộ送遣唐使，兵萬人船百艘。偵查結論：這是**新羅唯一的結構改革機會**：海商資本+私兵+外交（唐徐州節度往來）本可變成「海商王權」（如王建模式）。841張保皋被貴族暗殺、清海鎮廢——**內陸骨品貴族絞殺了海洋選項**。對照渤海上京—日本—唐 Egg belt 貿易：南北國時代北國（渤海）搞海陸雙收，南國（新羅）自廢武功。**殺張保皋者，殺新羅**。

## 結案報告

1. **骨品鎖死**：聖骨斷、真骨壟斷——統一紅利零分紅，人才外流。
2. **寺院黑洞**：寄進避稅+石頭工程——稅基變佛像，府兵變僧兵。
3. **海洋自殺**：清海鎮被廢——唯一的改革引擎被貴族掐滅。
4. **崩解公式**：892甄萱完山起兵、901王建松嶽——接盤的正是被新羅趕走的人（海商+六頭品+村主聯軍）。

**全盛悖論（示意）：**

```
全盛 ＝ 石頭（可見）× 免稅（不可見流失）× 骨品（流動鎖死）。
石頭越大，稅基越小——佛國寺的每一塊石頭都是從府兵名冊上摳下來的。
```

**結論：** 751案是「盛世的驗屍報告」：**統一新羅把統一紅利全數兌成石頭與經卷**，留給王建一個空國庫和一本花郎世記。石窟庵的微笑越完美，慶州的府兵名冊越空白——美與亡是同一尊佛的兩面。
