# 1636 丙子胡亂：三跪九叩的生存計算

## 案發現場

1636 年，清太宗皇太極親征朝鮮，仁祖逃往南漢山城，46 天後開城投降。三田渡立碑，仁祖對皇太極行三跪九叩；朝鮮斷絕與明關係，對清稱臣納貢，世子赴瀋陽為質（長達八年）。朝鮮士林稱此為「千古之恥」，此後兩百年尊明攘夷（崇禎皇帝牌位供於大報壇）。

> **下跪是恥辱，還是精算？當明朝將亡、清朝將興，夾縫中的小國如何下注——三跪九叩買到了什麼？**

## 偵查過程

**線索一：實力對比（南漢山城的數學）。** 清軍十二萬圍城，朝鮮勤王軍被殲（金化、金化之戰），江都（王室避難所）陷落，糧盡。偵查結論：抵抗的期望收益=零——

```
抵抗：城破概率≈1 → 王室被俘 → 國滅（如南明）。
投降：稱臣納貢 → 國祚得保 → 自治得存。
```

仁祖的選擇不是懦弱，是**破產清算中的最優解**：用尊嚴（跪拜）換國體（存續）。與南明（抵抗到底、社稷丘墟）對照：**活下來的恥辱 vs 壯烈的滅亡**，朝鮮選了前者。這是小國的終極理性——**尊嚴是奢侈品，存續是必需品**。

**線索二：下注轉向（從明到清的改換門庭）。** 丁卯胡亂（1627）後朝鮮已與後金立約（兄弟之盟），丙子再降一級（君臣）。背景：明朝內憂外患（李自成、關寧錦防線吃緊），清朝統一女真、蒙古，勝負已分。偵查結論：朝鮮的投降是**提前改換門庭**——在明亡（1644）之前八年認清大勢。這是新羅借唐（參見本書 [0676-新羅統一.md](0676-新羅統一.md)）的反向操作：新羅借強者打敵人，朝鮮降強者保自己。**事大主義的精髓不在忠誠，在跟對贏家**——跟明的朝鮮（壬辰）得救，跟清的朝鮮（丙子）得存，跟錯的（南明）得死。

**線索三：質子外交（人質即熱線）。** 昭顯世子、鳳林大君（後孝宗）赴瀋陽為質八年——學滿文、通清廷、建人脈。偵查結論：質子是**雙向投資**：清朝拿人質保忠誠，朝鮮拿質子建溝通管道。鳳林大君回國即位（孝宗），推行北伐計劃（雖未成）——**質子經歷反而成為改革資本**（懂敵人、懂外語、懂天下大勢）。與土耳其德夫希爾梅（基督徒子弟變禁衛軍）同理：**人質制度是跨國精英的旋轉門**，受害者學成歸來當改革者。

**線索四：尊明的補償（大報壇的心理工程）。** 降清後，朝鮮建大報壇祭祀崇禎，自稱「小中華」（明亡後朝鮮以中華正統自居）。偵查結論：這是**尊嚴的心理補償機制**——膝蓋跪了，嘴上不能跪。用「尊明」維持士大夫的認同（我們是被迫的，心向故國），用「小中華」把恥辱翻譯成使命（中華亡了，我們替它活著）。**意識形態是戰敗者的止痛藥**——大報壇祭了兩百年，直到甲午戰爭（參見本書 [1894-甲午改革.md](1894-甲午改革.md)）才撤下。止痛藥吃太久，會變成毒品（鎖國攘夷、拒絕開化）。

## 結案報告

1. **跪拜即精算**：抵抗期望收益為零——用尊嚴換國體，小國理性的終極形態。
2. **跟對贏家**：明亡前八年改換門庭——事大不在忠誠，在選邊的時機。
3. **質子即投資**：八年人質換溝通管道+改革者——人質制度是精英旋轉門。
4. **止痛藥變毒品**：大報壇尊明補尊嚴，兩百年後變鎖國藉口——心理補償會過期變質。

**抵抗 vs 投降（期望對照）：**

| 選項 | 概率 | 結果 |
|------|------|------|
| 抵抗到底 | 城破≈1 | 王室被俘、國滅（南明結局） |
| 開城投降 | 存續≈1 | 稱臣納貢、自治得存 |
| 選擇 | 投降 | 用跪拜買國祚 |

**事大時機（示意）：**

```
1627 丁卯：兄弟之盟（試探）。
1636 丙子：君臣之盟（確認贏家）。
1644 明亡：提前八年下注正確。
事大＝選邊，選邊的價值＝時機。
```

**結論：** 丙子案是「小國投降學」的完整樣本：算清期望（抵抗必死）、選對時機（提前改換）、用人質建管道、用祭壇補尊嚴。**膝蓋可以彎，國祚不能斷**——這是半島五百年事大主義的總公式，從南漢山城到今日的大國平衡，一脈相承。
