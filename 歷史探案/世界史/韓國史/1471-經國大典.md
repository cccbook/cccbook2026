# 1471 經國大典：兩班官僚國家的法典完工

## 案發現場

1471 年（成宗二年），《經國大典》頒行——六典（吏戶禮兵刑工）一千餘條，把太祖（1392）開國、世宗（1443）的積累一次法典化：**科舉取士、兩班分治、田制俸祿、奴婢身分，全部寫死**。朝鮮從此成為東亞最徹底的「考試—官僚國家」：四百年不改版。這部法典是兩班的出生證，也是四百年後甲午改革（[1894-甲午改革.md](1894-甲午改革.md)）必須炸掉的大樓圖紙。

> **同樣學唐律令，為何朝鮮比日本更「科舉化」？一部法典如何同時製造清廉與僵化？**

## 偵查過程

**線索一：科舉兩班制（用考試壟斷權力）。** 大典規定文武兩班分途、科舉三場（初試覆試殿試）、及第即授職。偵查結論：這是光宗科舉（[0958-光宗科舉.md](0958-光宗科舉.md)）的完成版——高麗雙舉制的門閥後門被堵死，理論上「白衣也可登龍」。但蔭敘（高官子弟保送）、漢城—嶺南學閥、奴婢賤民禁考三條暗門並存——**考試越公平，備考資本越不公平**。布迪厄（Bourdieu）文化資本理論在此驗證：兩班子弟從小讀四書，農民子弟先認字就輸了。**考試打破了血統壟斷，又建立了學歷壟斷**——這句話此後六百年有效。

**線索二：職田制與俸祿（用土地養官僚）。** 大典給現職官按品級授職田（收租代俸）、罷職即還田。偵查結論：這是反高麗私田氾濫的設計——官不養田、田不養私，斬斷李成桂起家時看到的莊園毒瘤。但人口增長＋職田不足，16 世紀職田改俸米、再改貢納——官員收入縮水，只能靠「外職收刮＋科田轉私」。**養廉的錢不夠，貪腐就是制度性加班**。田制史公式：

```
官僚清廉度 ＝ （俸祿／生活成本）× 監察強度 − （田制崩解率）。
16 世紀後第一項小於 1，第二項靠台諫虛耗，第三項只升不降——燕山、中宗朝士禍皆由此式引爆。
```

**線索三：奴婢法（把一半人口寫成財產）。** 大典戶典詳定奴婢相訟、從母法（子女隨母賤良）：一旦為奴，世世為奴。偵查結論：兩班的體面生活（詩書、科舉、黨爭）靠奴婢剩餘供養——18 世紀奴婢占人口三到四成。**官僚國家的背面是奴婢國家**，一體兩面。甲午改革第一刀（廢奴、廢科舉）必須同時砍兩面——只廢一面，大樓不倒。

## 結案報告

1. **法典即國家**：六典一次寫死——四百年朝鮮政治只是這部法典的註腳與違規記錄。
2. **考試雙刃**：打破門閥、製造學閥——公平的門越窄，門口的補習越貴。
3. **俸祿詛咒**：職田養廉設計精巧、崩解註定——錢不夠的清官制度，生產貪官。
4. **奴婢底座**：兩班文明的成本由賤民支付——廢科舉必須連廢奴，否則改革落空。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 大典設計 | 跨域效應 |
|------|----------|----------|
| 法律 | 六典法典化 | 四百年援引不改 |
| 政治 | 兩班分治＋台諫 | 士林黨爭的擂台 |
| 經濟 | 職田代俸 | 崩解後貢納搜刮 |
| 文化 | 科舉獨尊性理學 | 訓民正音（[1443-訓民正音.md](1443-訓民正音.md)）被壓四百年 |
| 社會 | 從母法奴婢世襲 | 階級凍結至甲午 |

**朝鮮 vs 明朝（法典對照）：**

| 項目 | 朝鮮經國大典 | 明大明律＋會典 |
|------|-------------|---------------|
| 科舉開放度 | 理論開放、實則學閥 | 南北榜、地域配額 |
| 官僚俸祿 | 職田（易崩） | 祿米（低俸同病） |
| 身分彈性 | 奴婢世襲更嚴 | 軍匠籍可贖 |
| 結果 | 黨爭＋僵化 | 宦官＋廠衛 |

**法典穩定方程式（示意）：**

```
穩定 ＝ 法典完備度（高）× 官僚既得利益（極高）÷ 外部衝擊（壬辰、丙子前≈0）。
衝擊為零時穩定無限大——兩次外侵（1592、1636）後分母驟增，法典即空殼。
```

**結論：** 經國大典案是「好法典的壞運氣」：設計越完美，補丁越難打。四百年不修法不是因為沒問題，是因為**每個問題的受益者都在法庭上坐著**——修法的人，恰是靠法吃饭的人。
