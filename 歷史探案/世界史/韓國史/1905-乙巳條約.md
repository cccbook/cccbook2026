# 1905 乙巳條約：五條條文切走一個國家

## 案發現場

1905 年 11 月，日俄戰爭（參見 [../亞洲史/1905-日俄戰爭.md](../亞洲史/1905-日俄戰爭.md)）日本勝利後，伊藤博文率軍壓境，在德壽宮逼高宗批准《乙巳條約》（第二次日韓協約）——五條條文：韓國外交交日本統監府掌管。外部大臣朴齊純等五大臣簽字（乙巳五賊），高宗拒絕用璽。韓國成為日本保護國，五年後（1910）正式併吞。

> **五條條文如何吃掉一個國家？從開港到保護國到併吞——主權是怎樣被切片出售的？**

## 偵查過程

**線索一：切片戰術（主權的薩拉米）。** 回顧三十年：1876 開港（通商主權失）→1882 壬午（駐軍）→1894 甲午（內政改革權失）→1904 第一次日韓協約（財政外交顧問）→1905 乙巳（外交權失）→1907 丁未（內政權失、軍隊解散）→1910 併吞。偵查結論：日本用的是**薩拉米戰術**——每次只切一片，每片都「不大」（顧問、外交、軍隊），切完發現國家沒了。**主權的喪失從來不是一次性的，是分期付款的**——每期的金額小到不足以引發全面戰爭，大到改變力量對比。乙巳是最大的一片（外交=國家的對外人格），切完後韓國在國際法上已非完全國家。

**線索二：日俄戰爭的帳單（勝利者收費）。** 日本打贏日俄，代價是巨額外債（參見 [../亞洲史/1905-日俄戰爭.md](../亞洲史/1905-日俄戰爭.md)）——需要韓國的米、韓國的兵、韓國的市場來付帳。偵查結論：乙巳條約是**戰爭帳單的轉嫁**：日本把戰爭成本轉給韓國（米穀供出、軍費分攤），把戰略收益留給自己（滿洲+朝鮮）。桂—塔夫脫密約（美日）、第二次英日同盟——**列強用承認日本在韓特權，交換日本承認各自的贓物**（美得菲律賓、英得印度安穩）。韓國的主權是列強交易的籌碼——**小國的命運在大國的密約裡被定價**。

**線索三：高宗的抵抗（海牙密使的悲劇）。** 高宗派密使赴海牙和會（1907）控訴條約無效（未用璽=程序瑕疵）——列強拒絕受理（日本已打點）。偵查結論：這是**國際法的殘酷真相**：法律只保護有實力執行的人。高宗的程序主張（沒蓋璽）在法律上成立，在政治上無效——**沒有槍的法條是紙**。海牙密使事件反被日本利用，逼高宗退位（純宗繼位）、簽丁未條約解散軍隊。**反抗的姿態若無實力支撐，只會招來更重的懲罰**——這是弱者的兩難：不反抗是慢性死，反抗是速死。

**線索四：義兵與愛國啟蒙（切片下的反抗）。** 乙巳後義兵大起（許蔿、李麟榮等十三道倡義）、愛國啟蒙運動（皇城基督教青年會、國債報償運動——百姓捐金還外債）。偵查結論：主權被切時，社會的反應是雙軌的——**武裝的（義兵）與非武裝的（啟蒙、報償）**。國債報償運動尤其意味深長：百姓看懂了「外債=主權抵押」的公式（參見辛亥鐵路國有化，[../亞洲史/1911-辛亥革命.md](../亞洲史/1911-辛亥革命.md)），用捐款贖主權。**人民比朝廷先看懂金融帝國主義**——可惜捐款被日本統監府挪用。看懂了，擋不住——**認知的領先救不了實力的代差**（參見黑船，[../亞洲史/1853-黑船來航.md](../亞洲史/1853-黑船來航.md)）。

## 結案報告

1. **薩拉米切片**：主權分期喪失——每片不足以引發戰爭，總和等於亡國。
2. **帳單轉嫁**：日俄戰費轉給韓國——勝利者的成本由被保護者支付。
3. **密約定價**：列強交易韓國主權——小國命運在大國密約裡被定價。
4. **看懂擋不住**：國債報償證明人民懂金融帝國主義——認知的領先救不了實力的代差。

**薩拉米公式（示意）：**

```
亡國 ＝ Σ（每次切一片）。
每片＜戰爭閾值 → 無全面反抗。
Σ＝主權歸零 → 1910 併吞。
切香腸的人從不一次下刀。
```

**結論：** 乙巳案是「主權切片」的教科書：三十年、五刀、從通商權切到存在權——每刀都不致命，總和是死亡。**小國的警鐘：對每一次「不大」的讓步標價——薩拉米的總價是國家本身**。而列強的密約桌上，永遠有小國的位置——作為菜單。
