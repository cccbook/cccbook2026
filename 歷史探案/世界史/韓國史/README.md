# 韓國史的歷史年表（推理探案）

> 韓國史是半島在強權夾縫中求生的偵探史：檀君神話為何同時是建國故事與史學戰場？薩水一戰如何讓隋煬帝的百萬大軍崩潰？新羅為何聯合唐朝統一三國、又反過來把唐軍趕出去？蒙古鐵騎踏遍歐亞，為何在高麗留下八萬塊經版？韓文為何被兩班罵了四百年、卻成為今日韓國識字率的引擎？龜船、義兵與壬辰戰爭如何構成「全民戰爭」的原型？甲午改革與乙巳條約之間，主權是如何一片片被切走的？三一運動的非暴力為何能動搖帝國？漢江奇蹟的真正公式是什麼？光州的槍聲如何變成民主的種子？
>
> 本書以「推理探案」的方式，為每個歷史事件寫一篇 wiki，包含前因後果、學術理論與跨領域影響矩陣。每篇檔名以年份開頭（西元前以負號表示，四碼不足補零）。
>
> 本書的核心命題：**半島國家的生存術=在大國之間維持自主的動態平衡**——事大（對強者低頭）與自主（對內整合）是一體兩面；每篇 wiki 都以「跨領域影響矩陣」拆解政治、經濟、科技、文化與法律的互動。

## 閱讀路線（偵探式提問）

- **生存平衡線**：高句麗抗隋（0612）→ 新羅借唐（0676）→ 丙子降清（1636）→ 乙巳被併（1905）——事大與自主的天平如何擺動，何時斷裂。
- **文字與知識線**：漢字壟斷 → 直指活字（1377）→ 訓民正音（1443）——資訊載體的民主化如何改寫權力。
- **考試與階級線**：光宗科舉（0958）→ 朝鮮兩班 → 甲午廢科舉（1894）——考試是打破壟斷的刀，也是製造壟斷的模。

- **經濟躍遷線**：漢江奇蹟（1961）→ IMF 危機（1997）→ 韓流（2012）——從代工到品牌到文化的三級跳。
