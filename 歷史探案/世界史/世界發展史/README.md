# 世界發展史的歷史年表（科學史）

> 世界發展史是各領域互相塑造的偵探史：貧民槳手如何逼出雅典的民主？秦帝國的成敗為何寫在「資訊系統」裡？一場戰俘如何帶來七百年後的印刷革命？瘟疫的死亡名單如何瓦解封建制度？為什麼借貸利率從 10% 降到 3% 是制度變遷的證據？冷戰的勝負為何在財政帳本上決定？
>
> 本書以「推理探案」的方式，為每個歷史事件寫一篇 wiki，包含前因後果、學術理論與跨領域影響矩陣。每篇檔名以年份開頭。
>
> 本書的核心命題：**政治、經濟、科技、文化與法律不是平行條列，而是互相驅動的系統**——每篇 wiki 都以「跨領域影響矩陣」拆解各領域的互動。

## 寫作方式說明

每篇 wiki 採「推理探案」結構：

1. **案發現場（前因）**：當時的未解之謎是什麼？誰遇到的？為何重要？
2. **偵查過程（推理）**：史家/經濟學家/法學家如何思考？關鍵證據與推理為何？逐步重建機制與理論。
3. **結案報告（後果）**：謎題如何解？留下什麼遺產？影響了哪些後續發展？
4. **證據與工具**：跨領域影響矩陣、時間表、對照表、機制圖、學術理論（制度經濟學、宏觀經濟學、國際法、發展經濟學）——非必要不硬寫程式，以表格、公式與理論說明。
