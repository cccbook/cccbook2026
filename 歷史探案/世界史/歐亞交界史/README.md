> 專注歐亞之間的區域，特別是**通道區**：波斯御道、絲路、草原走廊、高加索、安納托利亞、河中、蒙古、西伯利亞、滿洲——帝國在此相遇、碰撞、交換。
> 以「推理探案」體例書寫：每個事件都是一案，前因後果即偵查過程，背後的理論、公式與分析即證據與工具。
> 各案詳文見本目錄中 `YYYY-標題.md`（年份不足四位補 0，西元前以負號表示）。
> 已在 [世界發展史](../世界發展史/) 立案的案件，年表中直接連結，不重複立案。
