# -138 張騫通西域：被俘十三年帶回來的世界地圖

## 案發現場

前 138 年，漢武帝派出郎官張騫，率百餘人西行：目標是聯絡遷徙至西域的大月氏，東西夾擊宿敵匈奴。這是一場豪賭——漢朝對玉門關以西幾乎一無所知，使團走入的是一片情報空白。

結果使團剛出隴西即被匈奴俘獲，扣留十餘年；張騫娶妻生子卻始終持漢節不失，後趁隙西逃，經大宛、康居抵達大月氏。聯盟雖未談成（大月氏已安居、不願東返復仇），張騫卻用雙腳測繪了西域：前 126 年歸漢，百人僅餘其與堂邑父兩人生還。

> **一次外交上的失敗任務，為何被司馬遷稱為「鑿空」？一份沒有達成目標的情報，如何反而開通了一條延續兩千年的絲綢之路？**

## 偵查過程

**線索一：聯大月氏的戰略算計。** 漢初和親納貢、文景韜晦，至武帝時國力已可支撐反擊；匈奴單于庭控弦數十萬，漢軍若孤軍深入漠北勝算難料。武帝的構想是**兩面夾擊**：聯合被匈奴逐走的大月氏（舊恨最深的受害者），漢出兵北方、月氏出兵西方。偵查結論：張騫之行的起點是**軍事同盟工程**——地緣壓力（politics）→情報需求（information）→使節西行。

**線索二：被俘十三年的情報學徒期。** 匈奴扣留張騫並非下獄，而是軟禁同化：授妻室、給牛羊，意在磨掉其漢使身分。張騫卻把囚禁變成田野調查：學會匈奴語言、掌握草原行軍與水草規律、摸清匈奴與西域諸國的羈縻關係。**囚徒身分反而給了他最稀缺的敵方視角**——逆境（constraint）→語言與地理知識（information）→第二次出使的資本。

**線索三：帶回的地理情報清單。** 張騫 report 的不是盟約，而是一份西域諸國調查報告：大宛（費爾干納）產汗血馬；烏孫有良馬、可招徠斷匈奴右臂；康居、大夏（巴克特里亞）富庶多市肆；更聞西南有身毒（印度）、安息（帕提亞）以絲綢轉售。司馬遷《史記·大宛列傳》幾乎全據此寫成。**情報（information）→皇帝的認知地圖改寫**——漢朝第一次「看見」了帕米爾以西的世界。

**線索四：情報→和親→屯田→絲路的因果鏈。** 張騫歸漢後，武帝依其情報改弦更張：聯月氏不成，改聯烏孫（細君、解憂公主和親）；為取汗血馬發動大宛戰爭（李廣利伐大宛得馬）；設河西四郡、屯田居延，以農耕據點切斷匈奴與羌胡聯繫；烏孫、康居朝貢使節絡繹西來。**一條軍事情報線，轉化為和親、屯田、設郡的連鎖工程**——情報→外交→軍事→商路自然貫通，絲路是副產品而非原計畫。

**線索五：第二次出使與鑿空之功。** 前 119 年張騫再使西域，率三百人分遣副使至大宛、康居、大月氏、大夏、安息、身毒諸國，自此「漢使西域絡繹」。張騫於前 114 年卒，但副使們帶回的使節與商人延續其路線。班固稱其「鑿空」——在無路處鑿出路來。偵查結論：**情報史上的成功不在談判桌，而在路線圖**——使節（politics）→路線知識（information）→商旅跟進（economy）。

## 結案報告

1. **失敗的外交、成功的情報**：聯月氏夾擊匈奴的原目標落空，但帶回的西域地理與物產情報，價值遠勝一紙盟約——情報工作的成果常在任務之外。
2. **絲路是情報的副產品**：從聯盟構想，到和親烏孫、屯田河西、伐大宛取馬，每一步都由張騫情報驅動；商路貫通是軍事—外交工程完成後的自然溢出。
3. **汗血馬與軍事革命**：大宛良馬改良漢軍騎兵，使對匈戰爭從步兵方陣轉向騎兵對決——物產情報直接改寫了戰爭形態。
4. **偵探教訓**：評估一次遠行，別只看它談成了什麼，要看它畫回了什麼——「認知地圖的擴大」才是鑿空之功的本意，地圖一改，國策與商路遲早跟著改。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 變化 | 機制 |
|------|------|------|
| 軍事 | 對匈由守轉攻、騎兵改良 | 汗血馬情報；斷匈奴右臂戰略 |
| 外交 | 和親烏孫、聯康居 | 張騫路線與副使網絡 |
| 農業 | 河西四郡屯田 | 居延、敦煌農耕據點切斷匈羌 |
| 經濟 | 絲路開通 | 使道既通、商旅隨之 |
| 史學 | 《史記·大宛列傳》 | 司馬遷據張騫報告寫成 |

**情報→絲路的因果鏈：**

```
武帝聯月氏夾擊匈奴（戰略需求）
   ↓ 前138年首使、被俘十三年
西域地理物產情報（大宛馬、烏孫、安息、身毒）
   ↓ 前119年再使、分遣副使
和親烏孫 → 伐大宛取馬 → 河西四郡屯田
   ↓ 使道暢通、沿線設障保護
商旅跟進 → 絲綢之路貫通（情報的副產品）
```

**張騫情報中的西域諸國速覽：**

| 國名 | 張騫報告要點 | 後續漢策 |
|------|--------------|----------|
| 大宛 | 汗血馬、葡萄酒、城郭 | 李廣利伐大宛取馬 |
| 烏孫 | 人多馬眾、可招徠 | 細君解憂和親 |
| 康居 | 與月氏鄰、尚武 | 通使結好 |
| 大夏 | 富庶、無大君長 | 通使市易 |
| 安息 | 以漢絲轉售、善市 | 商旅往來之樞紐 |

**結論：** 張騫兩次西使（前 138—前 126、前 119—前 115），以十三年囚徒生涯換來一幅西域地圖。武帝要的是一個盟友，歷史得到的卻是一條絲路——**情報一旦流入帝國的決策迴路，和親、屯田、戰爭與商路都會沿著它重新排布**。所謂鑿空，鑿的是認知的空。
