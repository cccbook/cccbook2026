# 1863 鄂圖曼帝國銀行：誰替蘇丹管錢包，誰就擁有帝國

## 案發現場

1863 年，英法資本與蘇丹合資成立鄂圖曼帝國銀行（Banque Impériale Ottomane）：特許發鈔、代理國庫、經辦外債，還款直接從關稅、鹽稅中坐扣。此前：1854 年首借外債（克里米亞戰爭！）、紙幣濫發（kaime！貶值九成！）、包稅餘毒（稅收在路上被吃掉！）——**蘇丹有帝國，無錢包**。此後：1875 年違約、1881 年債務管理局接管半壁稅收、1914 年銀行大樓即金融首都——**國庫搬進外資銀行**。一家銀行，如何從出納變成太上皇？

> **當國家的錢包外包給債權人——中央銀行是主權的工具，還是主權的債主？**

## 偵查過程

**線索一：發鈔權的抵押（貨幣主權論）。** 現代貨幣理論（MMT）謂主權＝以本幣徵稅還債的能力。鄂圖曼反其道：以英鎊、法郎借債，以關稅（多為外國商人繳納的金幣）還債，發鈔還需銀行董事會（倫敦、巴黎）批准。公式：

```
主權貨幣：政府花本幣 → 以本幣收稅 → 閉環。
鄂圖曼：花里拉 → 欠英鎊 → 以關稅金幣還 → 缺口再借。
匯率一貶，債務自動膨脹——貶值即加稅，加稅即叛亂。
```

偵查結論：帝國銀行名為央行，實為**匯率與債權的看守**——替債主看住蘇丹的手。與英格蘭銀行（1694，議會管國王錢包！）對照：英格蘭以銀行馴服王權，鄂圖曼以銀行馴服蘇丹——**同一個制度，債主不同，主人不同**。

**線索二：稅收坐扣的技術（財政自動扣款）。** 債務合約規定：指定稅種（關稅、鹽、酒、印花）由銀行或債務管理局代收，優先還債，餘額才交財政部。偵查結論：此即**主權的現金流瀑布**（cash waterfall）——債主在水龍頭處先接水，蘇丹喝剩下的。1881 年後債務管理局僱員逾五千，深入各省設分局——**一個國中之國的稅務總局**，比蘇丹的財政部更有效率，也更不受 Optional 監督。

**線索三：鐵路債券的迴路（巴格達鐵路案）。** 德國巴格達鐵路（1903）以鄂圖曼擔保的「公里保證金」融資：每修一公里，蘇丹保證債券收益，不足由稅收補——修得越多，財政包袱越重；停修則賠違約金。偵查結論：**基礎設施金融化＝主權期權化**——鐵路通車之日，即稅收被鎖定之時。參見本書 [1891-西伯利亞鐵路.md](1891-西伯利亞鐵路.md)：俄國以國債修路（主權修路！），鄂圖曼以主權為外債修路（借路修路！）——**同樣是鋼軌，一條通向動員，一條通向接管**。

## 結案報告

1. **錢包外包**：發鈔、國庫、外債經辦三權合一於外資銀行——央行即債主辦事處。
2. **瀑布扣款**：稅收在源頭先還債——財政部變成剩餘索取者。
3. **鐵路鎖定**：公里保證金把未來稅收預售給債券持有人——每公里鋼軌都是一張稅收期貨。
4. **偵探教訓**：看一個國家的主權，先看**錢包在誰手裡**——發鈔機與稅務局的產權，就是主權的產權。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 帝國銀行的角色 | 跨域效應 |
|------|---------------|----------|
| 貨幣 | 特許發鈔、穩定里拉 | 穩定靠外匯儲備，主權讓渡 |
| 財政 | 代理國庫、坐扣關鹽稅 | 債主優先、蘇丹殿後 |
| 債務 | 經辦歷次外債發行 | 1875 違約→1881 債務管理局 |
| 基建 | 巴格達、海賈茲鐵路融資 | 鐵路即稅收抵押品 |
| 政治 | 英法德以金融爭奪帝國 | 金融瓜分先於領土瓜分 |

**主權流失的因果鏈（LaTeX）：**

$$S_{sovereignty} = \frac{T_{discretionary}}{D_{foreign}} \cdot \frac{1}{1 + \gamma \cdot G_{guarantee}}$$

$T_{discretionary}$ 為蘇丹可自由支配稅收，$D_{foreign}$ 為外債存量，$G_{guarantee}$ 為鐵路等收益擔保。1863–1914 年分子被坐扣機制壓縮，分母與 $\gamma$ 同步膨脹——$S \to 0$。**央行成立之日，即主權計量歸零的起點**——資產負債表從不說謊，說謊的是「改革成功」的新聞稿。

**結論：** 帝國銀行案是「央行即債主」的樣本：它穩定了里拉、修通了鐵路、養肥了債券持有人——唯獨沒有養活帝國。**蘇丹把錢包交給銀行保管，銀行把帝國裝進錢包帶走**——金融史的終極教訓：出納做久了，就成了主人。
