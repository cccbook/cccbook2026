## 閱讀路徑

- **安地斯文明線**：卡拉爾 → 查文 → 蒂瓦納庫與瓦里 → 馬雅古典期崩潰（中美洲對照） → 印加擴張（美洲史） → 征服奇穆 → 比爾卡班巴 → 圖帕克·阿馬魯二世
- **殖民制度線**：托爾德西里亞斯（美洲史） → 卡布拉爾 → 唐納塔里亞糖業（1534） → 華拉度列辯論 → 波托西（美洲史） → 米納斯黃金潮 → 瓜拉尼戰爭
- **寡頭出口線**：考迪羅時代 → 鳥糞繁榮（1845） → 巴拉圭戰爭 → 硝石戰爭 → 大蕭條（1929） → 瓦加斯
- **獨立戰爭線**：米納斯密謀 → 葡宮廷遷巴西 → 五月革命 → 聖馬丁 → 玻利瓦爾與波亞卡 → 巴西獨立 → 阿亞庫喬 → 大哥倫比亞解體
- **國家暴力線**：考迪羅時代 → 巴拉圭戰爭 → 硝石戰爭 → 瓦加斯 → 庇隆 → 瓜地馬拉政變 → 骯髒戰爭 → 福克蘭 → 民主化浪潮
- **毒品經濟線**：麥德林集團與古柯經濟 → 墨西哥毒品戰爭
- **加勒比奴隸制線**：海地革命（美洲史） → 海地獨立與法國賠款 → 巴西黃金法
- **資源主權線**：波托西（美洲史） → 硝石戰爭 → 墨西哥石油國有化 → 坎塔雷爾油田 → 查維茲 → 鹽下層石油
- **制度因素線**：監護征賦制 → 進口替代工業化 → 債務危機 → 布雷迪債券 → 龍舌蘭危機（1994） → 美元化
- **美國因素線**：瓜地馬拉政變 → 古巴革命（美洲史） → 進步聯盟（1961） → 智利政變（美洲史） → 債務危機 → 華盛頓共識（1994） → 粉紅浪潮
