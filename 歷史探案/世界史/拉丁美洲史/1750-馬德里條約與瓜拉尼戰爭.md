# 1750 馬德里條約與瓜拉尼戰爭：地圖上一筆，地上三十個城

## 案發現場

1750 年，西班牙與葡萄牙在馬德里簽訂條約：雙方廢棄沿用兩百五十年的托爾德西里亞斯線，改以實際占領與河流山川重劃南美邊界。交換條件中有一條看似輕描淡寫——西班牙把烏拉圭河東岸的七個耶穌會瓜拉尼傳教區（reductions）割讓給葡萄牙，換取西岸的科洛尼亞（Colonia del Sacramento）。一紙條約，三十座經營近百年的傳教城鎮、上萬瓜拉尼人的家園，被當成找零的硬幣撥了出去。

瓜拉尼人不接受。1754–1756 年，在首領塞佩·蒂亞拉胡（Sepé Tiaraju）率領下，傳教區民兵拿起耶穌會教出來的槍炮與樂器（此地以管弦樂團聞名）對抗兩國聯軍，最終在 1756 年的凱巴特戰役（Caibaté）中被屠殺，塞佩戰死， reductions 化為廢墟。

> **三十個自給自足、識字率冠絕美洲的烏托邦社區，為什麼會被兩個遠在歐洲的宮廷一筆勾銷？而一支拿小提琴的手，又是何時學會開炮的？**

## 偵查過程

**線索一：馬德里條約的交易邏輯（地圖的理性）。** 為什麼西葡要重劃邊界？偵查：托爾德西里亞斯線早已名存實亡——葡萄牙 bandeirantes 向西擴張占了大半內陸，西班牙要的是把「實際占領合法化」，用**uti possidetis（有效占領原則）**取代紙上子午線。西班牙割讓東岸七鎮，換取葡萄牙歸還拉普拉塔河口的走私巢科洛尼亞並承認西班牙對菲律賓的權益。**地緣交易（geopolitics）→人口被當成領土的附屬品**，談判桌上沒有瓜拉尼人的席位，因為條約的單位是河流，不是人民。

**線索二：reductions 的三十年烏托邦（傳教區的真相）。** 耶穌會在巴拉圭—巴拉那一帶建立的三十個 reductions 收容了約十萬瓜拉尼人：土地公有、勞動集體、產品按需分配，識字教育、管弦樂團、印刷所、民兵操練一應俱全，教堂是巴洛克藝術的叢林版本。經濟上自給且有餘（馬黛茶、棉花、皮革外銷），軍事上有裝備火器的萬人民兵——**在奴隸獵捕隊橫行的邊疆， reductions 是唯一能保護印第安人不被 bandeirantes 抓走的堡壘**。偵查結論：烏托邦不是空想，是邊疆暴力逼出來的自衛共同體——**外部威脅（violence）→集體組織（community）→繁榮（economy）**。

**線索三：樂器與槍炮（民兵從哪裡來）。** 耶穌會教瓜拉尼人拉小提琴，也教他們列陣放槍——兩者是同一套紀律：識譜與操典同源，合唱團的服從即步兵的服從。reductions 的民兵曾多次為西班牙王室作戰（抵禦 bandeirantes 與葡萄牙人），是王室在邊疆最可靠的武力。如今這支王室親手武裝的軍隊掉轉槍口，條約的執行者才發現自己面對的是美洲訓練最精良的印第安部隊。**傳教（mission）→紀律（discipline）→武力（force）**，耶穌會的成功正是它被出賣的原因——太能幹的烏托邦讓兩個王室都不放心。

**線索四：塞佩·蒂亞拉胡與 1754–56 戰爭（抵抗的兩年）。** 塞佩是傳教區出身的民兵領袖，口號「這片土地屬於我們」（Esta terra é nossa）傳遍七鎮。瓜拉尼游擊隊利用河網與叢林伏擊聯軍兩年，但西葡聯軍擁有野戰炮與正規騎兵，1756 年凱巴特一戰，瓜拉尼軍阵亡逾千（含塞佩），聯軍僅傷亡數人——**前膛槍對滑膛炮的代差**在開闊地無解。戰後 reductions 被移交，居民被強制遷徙，田園荒蕪。偵查結論：勇氣撐了兩年，技術與國家機器的差距決定了結局。

**線索五：烏托邦被一紙終結的機制（誰殺了 reductions）。** 真正的兇手不是某場戰役，而是三層絞索：其一，條約把社區當籌碼（法理層）；其二，歐洲啟蒙輿論正把耶穌會描繪成「國中之國」，葡萄牙龐巴爾侯爵（Pombal）與西班牙王室都想剷除教團（政治層，耶穌會 1759 年在葡、1767 年在西被驅逐）；其三，殖民者覬覦傳教區的土地與勞動力（經濟層）。瓜拉尼戰爭只是第一聲槍響——**條約（law）＋反耶穌會運動（politics）＋土地貪欲（economy）**三鏈合絞，烏托邦沒有活路。

## 結案報告

1. **地圖的暴力**：馬德里條約證明，現代邊界理性（有效占領、河流為界）可以比子午線更文明，也可以更殘酷——十萬人的家園在談判桌上只是一欄找零。
2. **烏托邦的悖論**：reductions 因自衛而武裝，因武裝而強大，因強大而被猜忌——它的成功正是它的罪狀，保護者的角色注定得罪所有覬覦者。
3. **教團覆滅的前奏**：瓜拉尼戰爭是歐洲驅逐耶穌會（1759、1767）的前哨戰，啟蒙君主與教團的決戰先在南美叢林開火。
4. **偵探教訓**：審理「一紙終結一國」的案件，要同時打開三本卷宗——**條約文本、宮廷輿論、土地帳本**，只讀其中一本，永遠找不到真正的兇手。**法理、政治、利潤三線並查**。

**烏托邦終結的因果鏈：**

```
 bandeirantes 擴張 → 托爾德西里亞斯線作廢
   ↓ 西葡重劃邊界（有效占領原則）
馬德里條約（1750）：七鎮當籌碼
   ＋ 反耶穌會輿論（龐巴爾等人）
   ＋ 殖民者覬覦土地勞力
   ↓
瓜拉尼戰爭（1754–56）→ 凱巴特屠殺
   ↓
 reductions 廢墟化 → 耶穌會全面被逐前奏
```

**結論：** 瓜拉尼一案的卷宗只有一句判詞：**在帝國的地圖上，烏托邦只是可以找零的硬幣**。小提琴與火槍都救不了它，因為下令終結它的三隻手——外交官的筆、啟蒙大臣的印、殖民者的犁——全在戰場之外。
