# 0698-渤海國：海東盛國的三百年

## 案件摘要

698 年，大祚榮（高句麗遺將！粟末靺鞨！）據東牟山（敦化！）建**震國**（→713 唐冊「渤海郡王」！國號渤海！）——**「海東盛國」**（《新唐書》！）；719 武藝（大武藝！）遷中京、731 文王大欽茂（ اتحادیه？不——在位 737–793！57 年！）遷上京（龍泉府！寧安！）、786–809 康王、 espionage？不——813–871 宣王大仁秀（「建興」！全盛！「扶餘府—鄚頡府」！十五府！）、891–926 末王大諲譔 → 926 契丹滅（阿保機！「丹東」？不——扶餘城降！上京陷！）。這樁案件是「遺民的建國」：**高句麗亡（[0037-高句麗帝國.md](0037-高句麗帝國.md)！）30 年，遺民建海東盛國**。

## 前因 -- 多因素的局勢

- **遺民**：高句麗遺民（貴族—武士！）＋靺鞨（粟末部！）——大祚榮雙重血統（父乞四比羽！）。
- **時機**：武則天—契丹李盡忠叛（696！營州！）→ 唐東北空虛（→大祚榮據東牟山！「震國」！）——**亂中建國**。
- **唐**：中宗—玄宗羈縻（713 冊封！「渤海郡王—忽汗州都督」！）＋遣學生（「宿衛—太學」！日本留學生學渤海？不——渤海—日本通交！）——**冊封即保護**。
- **日本**：727–929 渤海—日本通交（34 次！渤海使—日本！「渤海靺鞨」！）——**日本海通道**（→正倉院寶物有渤海貢物！）。

### 線索一：上京龍泉府——「長安的縮小版 2.0」

$$\text{渤海} = \text{（唐制：三省—十五府！）} \times \text{（高句麗：山城—重甲！）} \times \text{（靺鞨：漁獵—人參！）}$$

### 線索三：926 契丹滅——「新主的收編」
