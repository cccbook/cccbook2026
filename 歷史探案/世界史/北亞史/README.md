# 北亞史 -- AI 偵探風格

以「推理探案」的方式，追查北亞（蒙古高原、滿洲、西伯利亞）三千年的重大轉折：匈奴、鮮卑、五胡、北魏、突厥、渤海、回鶻、契丹、女真、蒙古帝國、大元、北元、俄羅斯東進、滿洲崛起、尼布楚、多倫會盟、準噶爾、中東鐵路、外蒙獨立、滿洲國、諾門罕、珍寶島、蒙古民主化、西伯利亞力量——
前因是什麼？線索在哪裡？推理如何展開？後果又如何改變了這片草原、森林與凍土？

本卷的核心命題只有一句話：**北亞史是「草原帝國的發明—複製—終結史」。**
冒頓發明十進制帝國，此後突厥、回鶻、契丹、蒙古全是學生；森林（女真、滿洲）與農耕（中原、俄羅斯）輪流當考官；考題永遠一道：游牧的機動 vs 定居的資源。近代以後考場換成鐵路、石油、天然氣。每個重大事件都是一樁「多因懸案」：偵探的工作，就是把因素鏈一環一環還原出來。

（涵蓋：匈奴帝國、匈奴分裂、高句麗、鮮卑、五胡十六國、北魏改革、突厥汗國、渤海國、回鶻汗國、契丹遼朝、長白山噴發、女真金朝、蒙古帝國、大元朝、北元中興、俄羅斯征服西伯利亞、後金滿洲崛起、尼布楚條約、多倫會盟、準噶爾之亡、中東鐵路、外蒙古獨立、滿洲國、諾門罕、珍寶島、蒙古民主革命、西伯利亞力量）

## 因素的回饋迴路

```
              ┌────（大雪／火山：外生衝擊）────┐
              ↓                                ↓
   地理（草原—森林）──→ 畜牧—毛皮 ──→ 經濟 ──→ 政治 ──→ 組織 ──→ 武器
    │                                ↑        ↑                   │
    │                                │        │                   ↓
    └──→ 科技（騎射—火器—鐵路）←── 資訊 ──┘    心理 ←──────── 心理迴路
              ↑                            ↑
              └── 宗教 ←──（合法性與動員）┘

   正向迴路（加速）：統一→朝貢→富裕→更多統一
   正向迴路（加速）：鐵路→移民→稅收→更多鐵路
   負向迴路（抑制）：繼承爭位→分裂→中原—俄羅斯介入→再分裂
   草原迴路（北亞特有）：漢化→自殺／不漢化→野蠻（毗伽碑文的詛咒）
```

**偵探的訣竅**：找到「哪個因素先動、哪個因素放大、哪個因素抑制」，把迴路畫出來；再問一句——**這次是誰在給草原帝國當老師（中原？俄國？）？**案件的因果鏈就浮現了。

## 偵探的結案陳詞（階段性）

三千年的北亞史，可以壓縮成三條因果鏈：

1. **帝國鏈**：匈奴（十進制發明！）→ 突厥（粟特財政！）→ 回鶻（摩尼商國！）→ 契丹（雙軌！）→ 蒙古（世界體系！）→ 滿洲（八旗！）——**每一代複製上一代的作業系統，再加一個新補丁**。
2. **邊界鏈**：長城（農耕防線！）→ 尼布楚（拉丁文平等！）→ 璦琿北京（大炮反轉！）→ 珍寶島（0.74km²戰爭！）→ 黑瞎子勘定（句號！）——**墨與血輪流執筆的三百年**。
3. **資源鏈**：紫貂（yasak！）→ 茶葉（萬里茶道！）→ 鐵路（中東路！）→ 石油天然氣（西伯利亞力量！）——**北亞永遠在賣大自然，買家從沙皇換成世界**。

三條鏈咬合在一起，就是本卷二十七樁案件的全部真相（後兩案仍在書寫，偵探不結案，只記錄）。
