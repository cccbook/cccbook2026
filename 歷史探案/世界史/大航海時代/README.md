> 1405 年鄭和下西洋，1415 年葡萄牙攻下休達——東西方幾乎同時把船開向遠洋。此後三百年間，香料、白銀、蔗糖與奴隸織成第一張全球貿易網，股份公司、現代海軍與國際法應運而生。這是「全球化 1.0」的現場。
