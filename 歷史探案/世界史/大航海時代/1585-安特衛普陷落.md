# 1585-安特衛普陷落：資本北遷與荷蘭黃金時代的引爆點

## 案件摘要

1585 年 8 月，西班牙名將帕爾馬公爵（Parma）經長期圍城奪下安特衛普——當時北歐最大的商港與金融中心，此地承轉香料、英呢、波羅的海穀物與德意志白銀。城陷前，安特衛普向新教叛軍交涉失敗，兩年內**一半人口（逾十萬人，多為商人、工匠、資本家）北逃阿姆斯特丹**。今日讀者熟悉的阿姆斯特丹「黃金時代」、1602 年 VOC、1609 年證交所，本質上都是這批難民船隻運來的。

## 前因 -- 多因素的局勢

- **宗教**：尼德蘭新教（加爾文派）反抗西班牙天主教鎮壓，阿爾瓦公爵的血腥委員會（1567）結下深仇。
- **軍事**：1576 西班牙軍譁變洗劫安特衛普（「西班牙暴行」），1584 帕爾馬緩步收復法蘭德斯城市。
- **經濟**：安特衛普的繁榮依賴自由港制度與里斯本香料轉運——戰爭使轉運鏈中斷。

## 線索與推理 -- 因素咬合

### 線索一：知識與資本的可攜帶性

難民帶走的不是工廠，而是**人力資本與商業網絡**：葡萄牙裔猶太商人把與殖民地（巴西糖、印度鑽石）的連線帶到阿姆斯特丹；法蘭德斯織工把高級呢絨技術帶到萊頓。用公式說：

$$\text{北遷資本} = \text{人際信用網} + \text{行業技藝} + \text{客戶名單}$$

### 線索二：沉默的接收政策

阿姆斯特丹當局並未高喊「歡迎難民」，而是採低調吸納：給予居留、默許新教禮拜、開放行會外圍。**城市的競爭力政策，就是移民政策**。

### 線索三：堵住南方，逼出航海

1585 年伊麗莎白政府與叛軍結盟、英國封鎖對安特衛普的貿易，荷蘭因此被迫**直接出海取貨**——1590 年代直航東印度（見 1595 案）正是這個「被切斷者必自建航線」的邏輯。安特衛普陷落不僅北遷資本，更切斷了中間商角色，創造了荷蘭出海的動機。

## 偵查時間線

```
1566    尼德蘭聖像破壞運動（宗教衝突開端）
1567    阿爾瓦公爵血腥委員會
1576    西班牙軍譁變洗劫安特衛普
1584    帕爾馬開始收復法蘭德斯城市
1585.8  安特衛普陷落（圍城十四個月）
1585-90 難民潮北遷阿姆斯特丹
1588    無敵艦隊覆滅（後案）
1595    荷蘭首航遠東（後案）
```

## 破案時刻

- 1584–85：帕爾馬圍城十四個月，8 月城降；市民獲兩年限期決定去留。
- 1585–1590：北方難民潮高峰，阿姆斯特丹人口結構質變（新教徒、移民過半）。
- 1590s：直航東印度試航啟動，1595 首航成行。

## 後果 -- 改變了什麼

- **金融地理**：北歐金融中心由安特衛普遷至阿姆斯特丹（1609 證交所、1609 格勞秀斯的海洋自由論都是後續）。
- **戰爭格局**：伊麗莎白出兵援荷，直接捲入與西班牙的無敵艦隊決戰（1588）。
- **貿易結構**：波羅的海「母親貿易」（穀物—木材）由荷蘭掌控，並延伸出直航亞洲的遠洋資本。

## 因素影響筆記

1. **圍城 → 難民 → 首都轉移**：戰爭的長期效應往往表現為資本的地理遷徙。
2. **中間商之死 → 直航**：切斷中介者，等於替終端市場造船。
3. **寬容是資本磁鐵**：宗教寬容在此不是德性而是經濟政策。
