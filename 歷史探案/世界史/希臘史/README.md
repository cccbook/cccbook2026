> 每個事件都是一案，前因後果即偵查過程，背後的理論、公式與分析即證據與工具。
> 各案詳文見本目錄中 `YYYY-標題.md`（年份不足四位補 0，西元前以負號表示）。
> 已在其他卷立案的案件（如雅典帝國、君士坦丁堡）直接連結，不重複立案。
