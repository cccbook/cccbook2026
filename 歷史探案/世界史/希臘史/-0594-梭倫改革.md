# -0594 梭倫改革：解負令與階級政治的數學

## 案發現場

-594 年，梭倫（Solon）獲選為雅典執政官，獲授權修改法律。此時雅典瀕臨內戰：土地兼併嚴重，自耕農以自身人身作借貸擔保（債奴制），欠債即淪為債主田莊的奴工，外邦人買走雅典農地與雅典人；窮人（thetes）要求重分土地，貴族要求保護產權。梭倫的答卷是三箭齊發：解負令（seisachtheia，債務搖脫——廢除以人身為擔保的債，釋放債奴、追回賣往海外的雅典人）、按財產分四級（廢除按血統的權利分配）、設立四百人會議與陪審法庭開放給三、四級。他自己說：這塊土地上豎起了解放碑。

> **同時得罪窮人（不分地）與富人（廢債）的改革者，憑什麼活著離開雅典？——「不偏袒」是政治智慧還是政治算術？**

## 偵查過程

**線索一：六一漢與債奴危機（金融俘虜農民）。** hectemorioi（六一漢）為佃農階層，向貴族地主交收成的六分之一（一說六分之五，學界有爭論）為租，另可借貸——一旦欠債，以人身抵押（欠債即為奴，horos 記債石立在田中與人身上）。農業收入波動大（歉收、油價），農民天然是債務脆弱族群；債奴制把經濟波動轉成人身奴役，危機積累成政治炸彈。偵查結論：這是**信用制度的野蠻版**——貸款無擔保物就以人身為擔保，等於把人力資本全部抵押；一次歉收，農民失去的不止收成而是自由。債奴制是雅典的系統性風險：債主（貴族）賬面增值，社會（兵源、勞動力、公民團）持續失血——**私有產權以人身為抵押時，公民社會在為債權融資**。

**線索二：解負令（廢債而不分地）。** 梭倫取消人身抵押債務、解除 horos 石碑、釋放債奴、禁止以人身為擔保的借貸（從此只能以土地為擔保）。但他**拒絕重分土地**（窮人的最大訴求）。偵查結論：這是**精準的外科手術**——廢債拆除的是人身依附（公民自由權的底線），不分地保住的是財產權（秩序的底線）。政治數學：窮人要的是地（財富），梭倫給的是自由（權利）——自由不可逆轉（人格權），土地可逆轉（產權重分會啟動無窮追溯）；給前者成本低於後者，且只給前者。梭倫自評：「我給人民恰好足夠的權利，不多榮譽，也不奪其應得。」債奴的廢除，是雅典公民社會的地基：**沒有自由的農民，就沒有後來的重裝步兵與陪審員**（參見 [../武器與戰法/-0650-希臘重裝步兵方陣.md](../武器與戰法/-0650-希臘重裝步兵方陣.md)）。

**線索三：四級財產制（按收入不按血統）。** 梭倫以年產（穀、油、酒）計，分四級：五百斗級（pentakosiomedimnoi）、騎士級、雙牛級、日佣級（thetes）。前三級可任執政官與四百人會議，日佣級僅能入公民大會與陪審法庭——但**血統不再是唯一的門票**：暴發戶可入高級，貴族窮光蛋跌級。偵查結論：這是**以財產取代血統的階層重定義**——流動性首次被寫進制度：貴族壟斷的行政職位向財富開放，貴族集團被稀釋；日佣級握有法庭（陪審）與大會（表決），雖不任職，卻握有裁判權。這個配置是精算過的：**財富階層出任職（責任重），全體公民掌法庭與表決（風險散）**——中間階層（雙牛級的農民與工匠）成為制度的中軸：他們既怕富人奪權、又怕窮人分產，天然支持遊戲規則本身。亞里士多德所謂中產階級是穩定基石，其政治學的原型就在此。

**線索四：自願放逐十年（改革者的退場設計）。** 梭倫拒絕成為僭主（雙方都來勸進），立法規定各方須宣誓十年內維持其改革，然後自己出遊埃及、塞浦路斯十年——把改革留在身後，把自己移出戰場。代價立現：親梭倫派分裂、庇西特拉圖隨即僭位（-546），但庇氏**沿襲梭倫法制不改**（僭主也離不開這套制度）；庇氏被逐（-510）後，克利斯提尼在梭倫地基上建立民主（參見 [../世界簡史/-0508-雅典民主與海權.md](../世界簡史/-0508-雅典民主與海權.md)）。偵查結論：這是**改革者的最佳退場策略**——不帶走權力，就無人為奪他的權而拆他的改革；人走，制度留。因果鏈：

```
債奴廢除 → 公民人權底線確立 → 兵源與陪審員擴充
→ 四級制開放官職 → 財富政治取代血統政治
→ 僭主也守其法 → -508 民主直接在此地基上動工。
```

## 結案報告

1. **廢債不分地**：拆人身依附、保財產權——給自由不給財富，是政治外科手術的最小切口。
2. **財產代血統**：四級制把流動性寫進制度——貴族被稀釋，中產成為規則的守夜人。
3. **改革者退場**：拒僭主、立法後出遊十年——不掌權的改革者，改革最不易被報復性拆除。
4. **民主的地基**：債奴廢除→兵源→法庭→大會，梭倫的水渠通向 -508 的雅典民主。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 改革工程 | 跨域效應 |
|------|----------|----------|
| 法律 | 廢人身擔保 | 債務契約限於財產 |
| 政治 | 四級制 | 血統貴族制解體起點 |
| 軍事 | 自由農民擴充 | 重裝步兵階層擴大 |
| 經濟 | 金融穩定 | 信用以地為擔保重啟 |
| 制度 | 四百人會議、陪審法庭 | 代議＋司法民做的原型 |

**梭倫三角（對照）：**

| 訴求方 | 得到 | 未得到 |
|--------|------|--------|
| 窮人 | 自由＋法庭＋表決 | 土地重分 |
| 富人 | 產權＋官職保留 | 債奴制（人力擔保） |
| 中產 | 政治軸心地位 | —— |

**中間階層的政治數學（code block）：**

```
穩定度 ＝ 中產規模 × 規則可信度。
中產同時反對：富人奪權（寡頭化）與窮人分產（激進化）
→ 中產的理性選擇＝維護規則本身。
梭倫四級制 → 擴大中產基座 → 雅典制度韌性上升。
```

**結論：** 梭倫案的答案在「不偏袒」的真相：不是道德姿態，是**政治算術**——在窮人與富人互不信任的死局中，唯一活路是各讓一項不可逆轉的底線（窮人的自由、富人的產權），而把可談判的部分（官職、法庭）改成規則化。改革十人後他被請回雅典修改法律條文，被他拒絕：「我若有神諭之力也不改一字。」這份固執是制度的護城河：**改革者的價值不在其在場，在其退場後制度仍然運轉**——雅典民主 -508 年動工，地基澆築於 -594。
