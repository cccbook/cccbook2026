# 03.2 算子代數：動量、能量與角動量的數學交換律

## 1. 導言：當「乘法順序」開始重要

古典力學中，$xp=px$ 天經地義；但 1925 年 Heisenberg 重新詮釋光譜頻率的躍遷強度時，發現可觀測量必須用**不對易**的量表示。Born 指出這正是矩陣乘法，並寫下劃時代的對易關係：

$$[\hat{x},\hat{p}] = i\hbar$$

這個「非交換代數」不是數學癖好，而是量子世界全部奇異性的濫觴：不確定性原理、Pauli 不相容、原子殼層結構、化學鍵的方向性，全都由交換子的代數性質決定。本章以線性代數的「交換律」為主軸，串起動量、能量與角動量。

## 2. 定義：交換子與 Lie 代數

**定義 2.1（交換子）** $\ [\hat{A},\hat{B}] \equiv \hat{A}\hat{B} - \hat{B}\hat{A}$

**定義 2.2（基本對易關係，Heisenberg 1925 / Born–Jordan）**

$$[\hat{x}_i,\hat{p}_j]=i\hbar\,\delta_{ij},\qquad [\hat{x}_i,\hat{x}_j]=[\hat{p}_i,\hat{p}_j]=0$$

**定義 2.3（角動量算子）** $\ \hat{L} = \hat{\mathbf{r}}\times\hat{\mathbf{p}}$，分量為

$$\hat{L}_x = -i\hbar\left(y\frac{\partial}{\partial z}-z\frac{\partial}{\partial y}\right),\ \ \text{（輪換 }x,y,z\text{）}$$

## 3. 定理：交換子的三大後果

**定理 3.1（可同時測量判據）**
兩可觀測量可同時具有確定值 $\iff$ $[\hat{A},\hat{B}]=0$（且它們有共同本徵函數完備基）。

> **化學意義**：$[\hat{H},\hat{L}^2]=[\hat{H},\hat{L}_z]=0$（中心位能），所以氫原子的態可同時標定 $\{n,l,m\}$——量子數不是發明出來的，是從交換子的代數裡**算出來**的，它們就是一組對易算子集（CSCO）的共同本徵值標籤。

**定理 3.2（角動量代數）**

$$[\hat{L}_x,\hat{L}_y]=i\hbar\hat{L}_z,\quad \text{（輪換）};\qquad [\hat{L}^2,\hat{L}_z]=0$$

由純代數推演（Dirac 1926，階梯算子 $\hat{L}_\pm=\hat{L}_x\pm i\hat{L}_y$）可得：

$$\hat{L}^2|l,m\rangle = l(l+1)\hbar^2|l,m\rangle,\qquad \hat{L}_z|l,m\rangle=m\hbar|l,m\rangle$$

且 $l=0,1,2,\dots$、$m=-l,\dots,+l$，每個 $l$ 有 $2l+1$ 個 $m$ 值。

> **化學意義**：$2l+1$ 的簡併度直接給出軌域形狀與數量——$s$（1 個）、$p$（3 個）、$d$（5 個）、$f$（7 個）。**週期表的骨架就是角動量 Lie 代數的表示論。**

**定理 3.3（能量的對易與守恆）**
若 $[\hat{H},\hat{A}]=0$ 且 $\hat{A}$ 不顯含時間，則 $\langle \hat A\rangle$ 為運動常數（Noether 式守恆的量子版）。

## 4. 動量算子與平移對稱

Dirac 指出：動量生成子的身分來自平移變換。對小位移 $a$：

$$e^{-i a\hat{p}/\hbar}\,\psi(x)\,e^{+i a\hat{p}/\hbar} = \psi(x-a)$$

以 Taylor 展開即可驗證。**對稱性 ↔ 守恆量 ↔ 對易關係**的三位一體：

| 對稱性 | 生成子 | 守恆量 | 對易關係 |
|---|---|---|---|
| 空間平移 | $\hat p$ | 動量 | $[\hat H,\hat p]=0$ |
| 時間平移 | $\hat H$ | 能量 | 能量守恆 |
| 空間旋轉 | $\hat L$ | 角動量 | $[\hat H,\hat L]=0$（球對稱位能） |

> **化學實例**：孤立原子的球對稱性使其 $2p_x,2p_y,2p_z$ 簡併；一旦形成分子（如 $\mathrm{H_2O}$ 的 $C_{2v}$ 對稱），旋轉對稱破壞，簡併解除——「對稱降低 ⇒ 能階分裂」正是群論與算子代數的合奏（見 04.3 節）。

## 5. 交換子的計算示範

**例 5.1** 證明 $[\hat{x}^2,\hat{p}] = 2i\hbar\hat{x}$：

$$\hat{x}^2\hat{p}\psi - \hat{p}\hat{x}^2\psi
= -i\hbar\left(2x\right)\psi + i\hbar\,x^2\frac{\partial\psi}{\partial x} - \left(-i\hbar\,x^2\frac{\partial\psi}{\partial x}\right)\cdot(-1)\cdots$$

用 $[\hat{x}^2,\hat{p}]=\hat{x}[\hat{x},\hat{p}]+[\hat{x},\hat{p}]\hat{x}=2i\hbar\hat{x}$ 即得。一般地，對多項式 $f$：$[f(\hat{x}),\hat{p}]=i\hbar f'(\hat{x})$。

**例 5.2** 動能算子與 $x$ 的交換子：

$$[\hat{p}^2,\hat{x}] = -2i\hbar\hat{p}$$

這兩條公式在變分法（04.1）與微擾理論（04.2）中頻繁出現，是「壓縮位置 ⇒ 動能上升」的數學機制。

## 6. 數值實驗：驗證矩陣版本的不對易性

有限維中交換子可用矩陣直接計算。取諧振子的 $\hat x,\hat p$ 截斷矩陣表示：

```python
import numpy as np

n = 8                       # Fock 空間截斷
a  = np.diag(np.sqrt(np.arange(1, n)), 1)          # 降算子
ad = a.T                                            # 升算子
X  = (a + ad) / np.sqrt(2)                          # x = (a+a†)/√2
P  = 1j*(ad - a) / np.sqrt(2)                       # p = i(a†-a)/√2

comm = X @ P - P @ X
print("|| [x,p] - iħI || =", np.linalg.norm(comm - 1j*np.eye(n)))
# 截斷誤差隨 n 增大而減小：無限維極限下精確成立
```

此實驗揭示：$[\hat x,\hat p]=i\hbar$ 是**無限維**特性——任何有限矩陣都滿足 $\mathrm{Tr}([A,B])=0$，但 $\mathrm{Tr}(i\hbar I)\neq 0$。這也預告了為何量子化學必須處理無限維空間，再用基底截斷（04.3 節）。

## 7. 階梯算子：用代數解出軌域

Dirac 階梯法的化學紅利：不需解微分方程，僅用交換關係即可得 $\hat L^2,\hat L_z$ 的譜，且由 $Y_l^m$ 的代數結構直接得到 $p$、$d$ 軌域的節面與角向形狀。例如 $l=1$ 時 $m=-1,0,+1$ 三個態，其實係數線性組合即 $p_x,p_y,p_z$：

$$p_x \propto \tfrac{1}{\sqrt2}(Y_1^{-1}-Y_1^{1}),\qquad p_z = Y_1^{0}$$

化學家熟悉的「啞鈴形軌域」，本質是角動量 Lie 代數 $\mathfrak{su}(2)$ 不可約表示的基底變換。

## 7.5 位置表象 vs 動量表象：同一向量，兩種座標

Dirac 記號的威力在於：$|\psi\rangle$ 是抽象向量，「波函數」只是它在某基底下的座標。

| 表象 | 基底 | 波函數 | 算子樣貌 |
|---|---|---|---|
| 位置表象 | $|x\rangle$ | $\psi(x)=\langle x|\psi\rangle$ | $\hat p=-i\hbar\frac{d}{dx}$（微分） |
| 動量表象 | $|p\rangle$ | $\phi(p)=\langle p|\psi\rangle$ | $\hat x=+i\hbar\frac{d}{dp}$（微分） |
| 能量表象 | $|n\rangle$ | $c_n=\langle n|\psi\rangle$ | $\hat x,\hat p$ 皆為無限矩陣 |

兩表象之間由傅立葉變換橋接：$\phi(p)=\frac{1}{\sqrt{2\pi\hbar}}\int e^{-ipx/\hbar}\psi(x)\,dx$。**不確定性原理在此現身為訊號處理的帶寬定理**：函數與其傅立葉變換的「寬度」不可能同時任意小。化學中的化學鍵定域描述（價鍵理論）與離域描述（分子軌域）正是這兩種表象的對偶——是同一物理的兩種座標選擇。

## 8. 進階視角：Jacobi 恆等式與 Lie 代數的封閉性

**定理 8.1（Jacobi 恆等式）**
對任意算子 $\hat A,\hat B,\hat C$：

$$[\hat A,[\hat B,\hat C]] + [\hat B,[\hat C,\hat A]] + [\hat C,[\hat A,\hat B]] = 0$$

這條恆等式保證交換子本身構成一個封閉的代數結構（Lie 代數）：算子集合在「取交換子」這個二元運算下自足。量子力學因此不只是「一堆算子」，而是有內在幾何的代數体系。

**例 8.2** 驗證 $\hat L_i$ 滿足 Jacobi 恆等式：
$[L_x,[L_y,L_z]]+[L_y,[L_z,L_x]]+[L_z,[L_x,L_y]] = i\hbar([L_x,L_x]+[L_y,L_y]+[L_z,L_z])=0$。

> **化學意義**：群論章節（01、02 章）中特徵標表的行與列，正是一群對易的對稱算子表示矩陣的「共同對角化紀錄」。Lie 代數是群論的無窮小版本——分子對稱性與角動量代數在此交會。

**例 8.3（自旋與電子結構）**
電子自旋 $\hat S$ 滿足與 $\hat L$ 相同的對易代數 $[\hat S_x,\hat S_y]=i\hbar\hat S_z$，但 $s=\frac12$（半整數）——Dirac 1928 年的相對論方程證明自旋是四維時空對稱性的必然產物。自旋與空間的**反對稱耦合**（自旋–軌域耦合）產生精細結構，解釋了鈉黃光 D 線的雙線分裂。

## 9. 章末小結

1. $[\hat x,\hat p]=i\hbar$ 是量子理論的公理級核心；對易即「可同時確定」。
2. 角動量代數 $[\hat L_i,\hat L_j]=i\hbar\varepsilon_{ijk}\hat L_k$ 純由 Lie 代數給出量子數與簡併度 $2l+1$，奠定週期表結構。
3. 對稱性—生成子—守恆量的對應，解釋原子簡併與分子能階分裂。
4. 交換子在無限維才嚴格成立；數值上以矩陣截斷逼近，誤差隨維度增大而消失。

## 延伸思考

- 為什麼自然界選擇「非交換」的幾何？一種觀點：若 $[\hat x,\hat p]=0$，則相空間可同時無限精確解析，原子的離散能階與物質的穩定性將不復存在。非交換性是「物質有結構」的代數代價。
- 交換子代數與量子計算：Pauli 算子 $\{I,X,Y,Z\}$ 的交換關係構成量子糾錯的數學基礎，與本章同一套代數。
