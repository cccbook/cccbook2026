# 04.1 變分法：尋求系統最低能量的數學優化

## 1. 導言：從「解方程」到「求最小值」

薛丁格方程 1926 年問世後，隨即遭遇殘酷現實：除了氫原子與諧振子，多電子体系的 TISE **無解析解**。1927 年，D. Hilbert 學派出身的物理學家把問題反轉——不求解微分方程，改求**能量泛函的最小值**。1928 年 Hartree 提出自洽場，1930 年 Slater 與 Fock 加入反對稱化，變分法自此成為量子化學的引擎。

數學上，這是 Rayleigh–Ritz 理論（1908–1909）在 Hilbert 空間的應用：把「解本徵值問題」化為「在子空間中做約束優化」。本節介紹其定理、實作與化學應用。

## 2. 變分原理

**定義 2.1（Rayleigh 商）**
對 Hermite 算子 $\hat H$ 與歸一化試探函數 $|\tilde\psi\rangle$ ：

$$\varepsilon[\tilde\psi] = \frac{\langle\tilde\psi|\hat H|\tilde\psi\rangle}{\langle\tilde\psi|\tilde\psi\rangle}$$

**定理 2.2（變分定理 / Rayleigh–Ritz 上界定理）**
設 $\hat H$ 的基態能量為 $E_0$ ，則對任意 $|\tilde\psi\rangle$ ：

$$\varepsilon[\tilde\psi] \ge E_0$$

等號若且唯若 $|\tilde\psi\rangle$ 為基態。

**證明**：將 $|\tilde\psi\rangle$ 以真本徵基展開 $|\tilde\psi\rangle=\sum_n c_n|n\rangle$ ，則

$$\varepsilon = \frac{\sum_n |c_n|^2 E_n}{\sum_n |c_n|^2} \ge E_0 \quad\left(\because E_n\ge E_0\right) \qquad\blacksquare$$

> **化學意義**：變分法把「猜波函數」變成可控的科學活動——任何猜測都給出真值的**上界**，猜得越好數字越低。量子化學軟體的核心循環就是：改進試探函數 → 能量下降 → 收斂。

## 3. Ritz 線性變分法：把無限維化為有限矩陣

**方法 3.1（線性變分）** 取基函數 $\{\phi_1,\dots,\phi_M\}$ ，令

$$|\tilde\psi\rangle = \sum_{i=1}^M c_i|\phi_i\rangle$$

代入 Rayleigh 商並對 $\{c_i\}$ 求極值，得**廣義本徵值問題**：

$$\mathbf{Hc} = E\,\mathbf{Sc}$$

其中 $H_{ij}=\langle\phi_i|\hat H|\phi_j\rangle$ （Hamilton 矩陣）、 $S_{ij}=\langle\phi_i|\phi_j\rangle$ （重疊矩陣）。因 $\mathbf H,\mathbf S$ 皆 Hermite 且 $\mathbf S$ 正定，可先對 $\mathbf S$ 做 Cholesky 或 Löwdin 正交化 $\mathbf S^{-1/2}$ ，轉成標準對稱本徵值問題：

$$(\mathbf S^{-1/2}\mathbf H\,\mathbf S^{-1/2})\,\mathbf c' = E\,\mathbf c'$$

**定理 3.2（Hylleraas–Undheim–MacDonald 階層定理）**
$M$ 維變分空間的 $M$ 個能量 $E_0^{(M)}\le E_1^{(M)}\le\cdots\le E_{M-1}^{(M)}$ 分別是真實能階的上界： $E_k^{(M)}\ge E_k^{(真)}$ ，且**擴大基底時各階能量單調不增**。

這保證了計算化學的收斂哲學：基底越豐富，結果越接近真值且永不變差（變分上界意義下）。

## 4. 化學實例一：變分法解氫原子

取試探函數 $\psi(r)=e^{-\alpha r}$ （ $\alpha$ 為變分參數），對有效核電荷 $Z$ 的氫樣原子：

$$\varepsilon(\alpha) = \frac{\hbar^2\alpha^2}{2m} - Z e^2\alpha\,\frac{1}{4\pi\varepsilon_0}\cdot\frac{1}{a} \;\Rightarrow\; \frac{d\varepsilon}{d\alpha}=0 \;\Rightarrow\; \alpha=\frac{Z}{a_0}$$

最優 $\alpha$ 恰等於 Bohr 半徑倒數，變分能量 $E=-\frac{Z^2}{2}E_h$ **正是精確值**——因為真基態就在試探函數族內。氫的 $E_1=-13.6$ eV 由一次求導即得，無需解徑向方程。

## 5. 化學實例二：H₂⁺ 與 LCAO–MO 的誕生

1927 年，Heitler–London 與 Burrau 用變分法處理 $\mathrm{H_2^+}$ ：取

$$\psi = c_1\,1s_A + c_2\,1s_B$$

由對稱性 $c_1=\pm c_2$ ，得成鍵（ $+$ ）與反鍵（ $-$ ）軌域：

```python
import numpy as np

# H2+ 線性變分（原子單位），R = 2.0 a0
R = 2.0
Z = 1.0
def S(R):                       # 重疊積分（解析式）
    return np.exp(-R)*(1 + R + R**2/3)
def H(R):                       # Hamilton 矩陣元（近似解析式）
    s = S(R)
    return np.array([[ -0.5, -0.5*np.exp(-R)*(1+R) ],
                     [ -0.5*np.exp(-R)*(1+R), -0.5 ]])
Hm = H(R); Sm = np.array([[1.0, S(R)],[S(R), 1.0]])
E = np.linalg.eigvals(np.linalg.inv(Sm) @ Hm).real
print(f"成鍵 E = {min(E):.4f} Eh, 反鍵 E = {max(E):.4f} Eh")
```

儘管此處矩陣元為近似式，變分框架完整展示了「化學鍵 = 本徵值分裂」： $+$ 組合能量低於孤立原子（成鍵）， $-$ 組合偏高（反鍵）。**鍵能、鍵長、光譜皆可由 $\varepsilon(R)$ 曲線讀出**——量子化學的第一個化學預言。

## 6. Hartree–Fock：變分法 × Pauli 原理

多電子波函數必須是 Slater 行列式（03.3 節）。對單一行列式試探函數做變分，得 Hartree–Fock（HF）方程：

$$\hat F\,\chi_i = \varepsilon_i\,\chi_i,\qquad \hat F = \hat h + \sum_j(\hat J_j - \hat K_j)$$

其中 $\hat J$ 為庫倫算子、 $\hat K$ 為**交換算子**（Pauli 反對稱化的直接產物，無古典對應）。因 $\hat F$ 依賴於未知軌域，須**自洽迭代**：

```mermaid
flowchart LR
    A[猜初猜軌域] --> B[建構 Fock 算子]
    B --> C[對角化得新軌域]
    C --> D{能量收斂?}
    D -- 否 --> B
    D -- 是 --> E[HF 極限能量]
```

HF 能量是 Slater 行列式族的變分極小值，因此仍是精確基態的**上界**。其誤差稱「相關能」，由 04.2 的微擾法（MP2）或日後的耦合群處理。

## 7. 變分法與優化的數學血緣

變分法本質是無限維優化，與機器學習的梯度法同源：

| 概念 | 有限維優化 | 量子變分 |
|---|---|---|
| 目標函數 | $f(\mathbf x)$ | $\varepsilon[\psi]$ |
| 極小條件 | $\nabla f=0$ | $\langle\delta\psi|\hat H-E|\psi\rangle=0$ |
| 曲率 | Hessian | $\hat H-E_0$ （半正定） |
| 收斂保證 | 凸性 | 變分上界定理 |

現代量子計算中的 VQE（Variational Quantum Eigensolver）甚至把變分參數放到量子硬體上優化——Rayleigh 1908 年的思想仍在驅動 2020 年代的化學。

## 7.5 變分法的失敗模式與診斷

變分法雖有上界保證，實務仍有陷阱：

1. **試探函數族不含真解**：任何單一行列式（HF）都無法描述鍵斷裂——能量曲線在解離區嚴重偏高，這不是數值誤差而是「變分空間本身錯了」。診斷：比較不同基底下的 HF 解離能是否收斂；不收斂即方法論缺陷。
2. **變分坍縮（variational collapse）**：激發態變分中若不加正交約束，優化器會滑落回基態。對策：在子空間中對角化（一次取所有本徵向量），而非逐一優化。
3. **局部極小**：SCF 迭代可能收斂到非最低的自洽解（如 $\mathrm{O_2}$ 的錯誤自旋態）。對策：多重初猜、穩定性分析。

```python
# 診斷 SCF 是否落在局部極小：比較不同初猜
from pyscf import gto, scf
mol = gto.M(atom="O 0 0 0; O 0 0 1.2", spin=2, basis="6-31g", verbose=0)
for guess in ("minao", "huckel", "1e"):
    mf = scf.RHF(mol); mf.init_guess = guess
    print(guess, f"{mf.kernel():.6f} Eh")
# 若不同初猜收斂到不同能量 → 存在多個自洽解，需取最低者
```

## 8. 歷史註腳：Rayleigh–Ritz、Hylleraas 與計算化學的誕生

Rayleigh（1908）以變分法研究音叉振動，Ritz（1909）將其系統化為線性組合方法——兩人皆非為量子力學工作，但 1926 年後此方法成為量子化學的支柱。1930 年 Hylleraas 以顯含電子間距離 $r_{12}$ 的座標做變分，將氦原子能量算到 $-2.90324\ E_h$ ，與實驗吻合至小數第四位——**首次證明薛丁格方程確實「包含」了化學**。

| 年代 | 人物 | 變分法里程碑 |
|---|---|---|
| 1908–09 | Rayleigh, Ritz | Rayleigh 商與線性變分 |
| 1927 | Heitler, London | H₂ 共價鍵的量子解釋 |
| 1928–30 | Hartree, Slater, Fock | 自洽場與反對稱化 |
| 1930 | Hylleraas | 氦原子的精確變分 |
| 1951 | Roothaan, Hall | LCAO 化為矩陣對角化 |
| 1960s– | Pople 團隊 | 商業化量子化學程式 |

> **驅動關係**：化學問題（多電子無解析解）逼迫數學發展「有限維逼近 + 優化」的技術路線；反過來，矩陣對角化演算法（如 1950 年代的 QR 演算法）成熟後，才使全電子計算成為日常。方法與需求互相拉動，是計算科學史的典範。

## 9. 章末小結

1. 變分定理：Rayleigh 商恆 $\ge$ 基態能量，把「解方程」化為「求最小值」。
2. Ritz 線性變分導出廣義本徵值問題 $\mathbf{Hc}=E\mathbf{Sc}$ ；Hylleraas–Undheim–MacDonald 定理保證基底擴大時能量單調改善。
3. Heitler–London 對 $\mathrm{H_2^+}$ 的處理誕生 LCAO–MO；HF 是「變分 × Slater 行列式」的極小值，須自洽迭代。
4. 交換積分來自 Pauli 原理，是化學鍵方向性與磁性的數學根源。

**下一步**：變分法給上界，卻難以系統化改進。微擾理論提供另一條路——從已知問題出發，按小參數逐階展開，精準處理「幾乎可解」的化學体系。見 04.2 節。
