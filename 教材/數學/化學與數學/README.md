# 《化學的矩陣與對稱：分子形狀、動力學與量子世界的數學架構》

> The Mathematics of Chemistry: Symmetry, Quantum Mechanics, and Dynamic Systems
>
> 本書回答化學系學生最常問的問題：**「為什麼學化學要背那麼多點群？為什麼量子化學充滿了矩陣？」**
>

## 本書寫作核心觀點

化學長期被誤解為單純的「實驗歸納與試管觀察」，但現代化學早已被**群論（對稱性）、線性代數（量子化學）、拓撲與圖論（分子結構）、微積分與動態系統（熱力學與動力學）**徹底重塑。掌握這些數學結構後，化學不再是記憶之學，而是推演之學。
