# 07.1 化學振盪反應：別洛索夫-扎博京斯基反應的極限環

## 1. 一個被埋沒的發現：Belousov 的十年

1951 年，蘇聯軍方醫療研究院的 Boris Belousov 想找一個酶促檸檬酸氧化的無機替代模型，把溴酸鉀、檸檬酸、硫酸鈰（$\mathrm{Ce^{3+/4+}}$）混在稀硫酸裡。他觀察到不可思議的現象：**溶液的顏色在無色（$\mathrm{Ce^{3+}}$）與黃色（$\mathrm{Ce^{4+}}$）之間週期性交替，振盪持續數十次，像鐘錶一樣規律。**

當時的教條：化學反應單調地走向平衡，如同滾落的球不會自己爬回山頂；振盪「應該」違反熱力學第二定律。Belousov 的論文 1951–1957 年被多個期刊退稿，審稿人甚至要求他證明「實驗不是污染造成的假象」。他最後只能把論文摘要收進 1959 年一篇輻射醫學會議文集（非正式刊物）——**這可能是化學史上引用次數最高的「灰色文獻」**。失意的 Belousov 於 1970 年過世；1977 年、1980 年，Prigogine 的耗散結構理論與後續研究還了這個發現公道（Belousov 在 1980 年被追授列寧獎）。

1961 年，研究生 Anatol Zhabotinsky 讀到這篇摘要，改用丙二酸與鐵菲囉啉指示劑重做，反應更鮮豔（紅↔藍）、更容易控制——這就是今天教科書裡的 **BZ 反應**（Belousov–Zhabotinsky reaction）。1970 年代 Field、Körös、Noyes（FKN 機理，1972）用十八個基元步驟解開了它的機理，並在 1974 年把三個關鍵物種抽成著名的 **Oregonator 模型**。

> **第二定律的平反**：BZ 反應不違反熱力學。系統是開放的（若連續進料）或遠離平衡（批次中反應物逐漸消耗）；振盪的是**中間物濃度**，總自由能始終單調下降。Prigogine 的**耗散結構**（dissipative structures）理論（1967–1977，1977 年諾貝爾化學獎）正式確立：**遠離平衡的開放系統可以自發形成時間或空間上的有序結構，代價是持續的熵輸出。**「平衡 = 死寂，遠平衡 = 可能有序」從此成為化學、生物學、氣候學的共同語言。

## 2. FKN 機理的骨幹與自催化

簡化後的關鍵回路：

$$\mathrm{BrO_3^- + Br^- + 2H^+ \to HBrO_2 + HOBr} \quad \text{(A：Br⁻ 消耗)}$$
$$\mathrm{HBrO_2 + BrO_3^- + H^+ \to 2HBrO_2 + HOBr} \quad \text{(B：自催化！)}$$
$$\mathrm{2HBrO_2 \to BrO_3^- + HOBr + H^+} \quad \text{(自催化終止)}$$
$$\mathrm{HBrO_2 + Ce^{3+} + H^+ \to HOBr + Ce^{4+}} \quad \text{(C：氧化金屬離子)}$$
$$\mathrm{Ce^{4+} + BrO_3 有機物 \to Ce^{3+} + Br^-} \quad \text{(D：Br⁻ 再生)}$$

步驟 B 是**正回饋**（$\mathrm{HBrO_2}$ 催化自己的生成），步驟 A/D 是**負回饋**（$\mathrm{Br^-}$ 壓制自催化）。**正回饋 + 延遲的負回饋**——這正是振盪的通用配方，與鐘擺、生態 predator–prey、神經元放電同構。

## 3. 極限環：Poincaré 的禮物

數學上，振盪的載體是**極限環**（limit cycle）：

> **定義（極限環）**：二維自治系統 $\dot{x} = f(x,y),\ \dot{y} = g(x,y)$ 的孤立封閉軌道 $\Gamma$：附近其他軌道隨時間**趨近**（穩定）或**遠離**（不穩定）$\Gamma$。

歷史因果：Poincaré 在 1880–90 年代研究三體問題時，發明相平面、軌道、橫截面（Poincaré section）的語言，並證明了「環形域原理」——這套原本為天體力學打造的工具，九十年後在化學燒杯中找到最漂亮的應用。

> **定理（Poincaré–Bendixson）**：若平面區域 $D$（單連通）內軌道有界且不趨於任何定點，則存在極限環。
> **實用判據（無環定理）**：若在單連通區域內 $\dfrac{\partial f}{\partial x} + \dfrac{\partial g}{\partial y}$ 恆不變號且不為零，則**沒有**極限環（Bendixson 判據）。

後者常用來「排除」振盪：例如純線性系統與許多簡單機理被證明不可能振盪，這解釋了為什麼 BZ 之前的化學動力學總收斂到平衡——**機理中必須有足夠的非線性**（如自催化的二次項、Holling 型飽和）才可能繞過此判據。

## 4. 振盪如何誕生：Hopf 分岔

從「趨向穩態」到「持續振盪」的轉換叫做 **Hopf 分岔**：系統參數（如進料濃度、溫度）越過臨界值時，不動點從穩定變不穩定，同時「吐出」一個小振幅極限環。數學條件：Jacobian 的一對共軛特徵值實部穿過零軸。BZ 反應中調整 $\mathrm{[BrO_3^-]}$ 或流速，可以看到振盪從無到有、再到不規則（過渡到混沌，下一節）——整條路線就是一連串分岔。

## 5. 數值模擬：Oregonator 模型

Field–Noyes 的 Oregonator（1974）是 BZ 的標準玩具模型，兩變數無量綱形式：

$$\varepsilon\frac{du}{dt} = u - u^2 - \frac{fv(u - q)}{u+q}$$
$$\frac{dv}{dt} = u - v$$

$u \propto [\mathrm{HBrO_2}]$（快、自催化）、$v \propto [\mathrm{Ce^{4+}}]$（慢、回復），$q, f, \varepsilon$ 是參數（$\varepsilon \ll 1$，正是上一節的奇異攝動小參數！）。

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.integrate import solve_ivp

f, q, eps = 1.1, 0.002, 0.01   # Oregonator 標準參數

def oregonator(t, y):
    u, v = y
    du = (u - u*u - f*v*(u - q)/(u + q)) / eps
    dv = u - v
    return [du, dv]

# 從不同初值出發，都會被吸到同一個極限環
sol = solve_ivp(oregonator, [0, 30], [0.5, 0.5],
                t_eval=np.linspace(0, 30, 20000), rtol=1e-9)

# 相軌跡（u-v 平面）
plt.figure(figsize=(11, 4.2))
plt.subplot(1, 2, 1)
plt.plot(sol.y[0], sol.y[1], lw=0.5)
plt.xlabel("u (∝ [HBrO₂])"); plt.ylabel("v (∝ [Ce⁴⁺])")
plt.title("極限環：相空間中的封閉軌道")
# 標出定點位置
u_star = (1 - f - q + np.sqrt((f+q-1)**2 + 4*q*(1+f))) / 2
v_star = u_star
plt.plot(u_star, v_star, "r*", ms=14, label="不穩定定點")
plt.legend()

# 時間序列
plt.subplot(1, 2, 2)
plt.plot(sol.t, sol.y[0], label="u")
plt.plot(sol.t, sol.y[1], label="v")
plt.xlabel("t"); plt.ylabel("濃度")
plt.title("BZ 振盪：顏色週期變化的數學影子")
plt.legend()
plt.tight_layout()
plt.show()

# 估計振盪週期
v = sol.y[1]
crossings = np.where(np.diff(np.sign(v - v.mean())) > 0)[0]
T = np.mean(np.diff(sol.t[crossings]))
print(f"平均振盪週期 ≈ {T:.2f}（無量綱時間單位）")
```

無論初值如何，軌道都收攏到同一個封閉曲線——**穩定極限環的標誌性圖像**。燒杯裡看到的紅藍交替，正是 $v(t)$ 的鋸齒狀波形。

## 6. 化學波：極限環在空間中伸展

若反應在**未攪拌**的淺皿中進行，每個局部都是 BZ 振盪器，透過擴散耦合，形成向外擴張的同心圓化學波——螺旋波、甚至多臂螺旋。數學框架是反應-擴散方程（下一章 07.3 的主題）。心臟的螺旋波心律不整、大腦癲癇波，與 BZ 螺旋波共享同一套數學——**Belousov 被埋沒的燒杯，最後照亮了醫學**。

## 7. 定性理論工具箱：如何「不用解方程」判斷振盪

在 Oregonator 之前，數學家已累積了一套定性工具，化學動力學家至今天天在用：

**（a）線性化與穩定性**：在定點 $(u_*, v_*)$ 處計算 Jacobian

$$J = \begin{pmatrix} \partial \dot{u}/\partial u & \partial \dot{u}/\partial v \\ \partial \dot{v}/\partial u & \partial \dot{v}/\partial v \end{pmatrix}_{*}$$

特徵值 $\lambda_{1,2}$ 的符號決定定點命運：兩個負實部=穩定結點或螺線點；一正一負=鞍點；共軛複數且實部為正=**不穩定焦點**（軌道螺旋離開——若外面有個吸引邊界，Poincaré–Bendixson 定理立刻保證極限環存在）。

**（b）零斜線（nullcline）分析**：畫 $\dot{u}=0$ 與 $\dot{v}=0$ 的曲線，交點即定點，曲線形狀決定軌道流向。Oregonator 的 $u$-nullcline 是 N 形（來自自催化的三次型 $u - u^2$ 項），這個 N 形是**激發性介質**（excitable media）的通用圖像——神經元的 FitzHugh–Nagumo 模型（1961）與之同構，連神經放電都可用同一套 nullcline 分析。

**（c）無量綱化**：Oregonator 的 $\varepsilon \ll 1$ 是把六個速率常數、五個濃度尺度壓縮成三個參數的結果。無量綱化不僅簡化計算，更揭示了**哪些參數組合真正重要**（$\varepsilon$ = 快慢比、$f$ = 化學計量因子、$q$ = 自催化閾值比）——這是量綱分析在動力學中的高級應用。

**（d）分岔圖**：把 $f$ 或 $\varepsilon$ 當控制參數，追蹤定點與極限環的穩定性變化，即得**分岔圖**。BZ-CSTR 實驗中逐步改變流速所得的「振盪週期對流速圖」就是實驗版的分岔圖——理論與實驗在同一張圖上會師。

## 8. 更多化學振盪系統一覽

BZ 不是孤例。回饋機理存在處，振盪就會生：

| 系統 | 回饋機制 | 歷史 |
|------|----------|------|
| Bray–Liebhafsky（碘酸分解） | 碘物種自催化 | Bray 1921（早於 BZ，同樣被忽視） |
| Briggs–Rauscher | 碘鐘：BZ + $\mathrm{Mn^{2+}}$/丙酮 | 1973，演示實驗首選 |
| 過氧化物酶-氧化酶 | NADH 氧化鏈 | 1970s，**生物振盪** |
| 糖解作用 | ATP/ADP 回饋 | Chance 1964，細胞代謝振盪 |
| CO 氧化（Pt 表面） | 吸附-反應回饋 | Ertl 1980s（2007 諾獎） |
| 生物時鐘 | 轉錄-轉譯延遲負回饋 | 2017 諾獎（晝夜節律） |

Bray 的遭遇尤其值得銘記：他比 Belousov 早三十年看到化學振盪，同樣因教條被忽視。**兩次被埋沒的發現之間，站著的是同一堵牆——「平衡是化學的唯一歸宿」的教條**。Prigogine 耗散結構理論的功績，正是拆掉這堵牆。

## 9. 位置資訊：極限環如何變成「時鐘」與「波源」

極限環還有一個被低估的性質：**相位**。沿環轉一圈的進度（$\theta = 0$ 到 $2\pi$）是系統的內建時鐘。兩個耦合振盪器會**鎖相**（phase locking）：Kuramoto（1975）證明大量耦合振盪器只要頻率分佈夠窄，就會自發同步——這解釋了螢火蟲同步閃爍、心臟節律細胞叢、以及化學實驗中數千個 BZ 微液滴的自發同步（Toiya 與 Epstein，2008）。

相位對擾動的響應由**相位響應曲線**（PRC）描述：在振盪的哪個階段給一劑化學脈衝，會提前還是延後下一峰？這不只是化學——**心律調節器與時差調整藥物的設計，數學上就是在操作 PRC**。Belousov 的燒杯，最後連到人類的作息。

## 10. 章末小結

- Belousov 1951 年的發現因「違反教條」被拒稿埋沒近十年；Zhabotinsky 1961 年復活它；Prigogine 的耗散結構理論給出理論地位：遠離平衡的開放系統可以有時空有序。
- 機理核心：自催化（正回饋）+ 延遲抑制（負回饋）；FKN 機理 1972、Oregonator 1974。
- 數學載體是極限環（Poincaré）：Poincaré–Bendixson 定理保證其存在，Bendixson 判據解釋「為何多數反應不振盪」。
- Hopf 分岔是「從穩態到振盪」的標準通道。
- 未攪拌系統中極限環耦合擴散形成化學波，連接到心律與腦波。
