# 9.2 橢圓函數

## 本章導言

$\sin z$ 有一個實週期；**雙週期**的半純函數存在嗎？答案是**橢圓函數**：$f(z + \omega_1) = f(z + \omega_2) = f(z)$（$\omega_1/\omega_2 \notin \mathbb{R}$），它們是**虧格 1 Riemann 面（環面）上的半純函數**（7.2 篂）。本節以 Weierstrass $\wp$ 函數為主角，講述雙週期結構、Liouville 定理的約束（二階極點的必然）、加法定理、與從橢圓積分（弧長問題）到橢圓函數的兩百年長跑——**Abel（1802–1829）與 Jacobi（1804–1851）兩位早逝天才的雙星史**。

### 從橢圓積分到橢圓函數：逆轉的發明

**起點（1700s）**：橢圓弧長積分。橢圓 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ 的弧長：

$$
s = a\int_0^\phi\sqrt{1 - e^2\sin^2\theta}\,d\theta,
$$

**不能初等積分**（Fagnano 1716 對特殊情形、Euler 1738 的加法定理）。**單擺**的精確週期 $\oint\frac{d\theta}{\sqrt{1 - k^2\sin^2\theta}}$、**Lemniscate 的弧長**（Fagnano 1718：$\int_0^x\frac{dt}{\sqrt{1-t^4}}$）全是同族積分——**橢圓積分** $\int\frac{dt}{\sqrt{p(t)}}$（$p$ 三、四次多項式）。

**Abel 與 Jacobi 的天才逆轉（1826–1829）**：**不要積分函數，研究它的反函數**：

$$
u = \int_0^x \frac{dt}{\sqrt{(1-t^2)(1-k^2t^2)}} \;\Longleftrightarrow\; x = \operatorname{sn}(u, k).
$$

正弦之於 $\arcsin$，正如 $\operatorname{sn}$ 之於橢圓積分。**反函數 $x = \operatorname{sn}(u)$ 是雙週期的**！Abel 1826 年論文《橢圓函數的一般研究》與 Jacobi 1829《橢圓函數理論新基礎》**同時獨立發明**橢圓函數論——十九世紀最著名的雙重發現之一。**「積分的多值性 = 反函數的週期性」**——這條逆轉把 7.1–7.3 篂的多值性難題變成週期結構的財富。

**等價視角**（7.2 篂）：反函數 $\operatorname{sn}$ 定義在**環面** $\mathbb{C}/(\omega_1\mathbb{Z} + \omega_2\mathbb{Z})$ 上；環面上單值的半純函數 = 雙週期半純函數。**橢圓函數論 = 虧格 1 的函數論**。

### WEIERSTRASS $\wp$ 函數

**構造**（1862 講義）：給定格 $\Lambda = \omega_1\mathbb{Z} + \omega_2\mathbb{Z}$（$\operatorname{Im}\frac{\omega_1}{\omega_2} \ne 0$），定義

$$
\wp(z; \Lambda) = \frac{1}{z^2} + \sum_{\omega \in \Lambda\setminus\{0\}}\left(\frac{1}{(z - \omega)^2} - \frac{1}{\omega^2}\right).
$$

**收斂校正**（$\frac{-1}{\omega^2}$ 項——Weierstrass 式的「殺尾巴」，8.1 篂技術）使級數一致收斂。性質：

1. **雙週期**：$\wp(z + \omega) = \wp(z)$（$\omega \in \Lambda$）——**逐項檢查**（校正項的作用）。
2. **半純**：每個格點 $z^2$ 型二階極點，留數 0。
3. **偶函數**：$\wp(-z) = \wp(z)$。
4. **滿足微分方程**（**橢圓曲線的函數方程**）：

$$
\wp'^2 = 4\wp^3 - g_2\wp - g_3, \qquad g_2 = 60\sum_{\omega\ne0}\omega^{-4},\; g_3 = 140\sum_{\omega\ne0}\omega^{-6}.
$$

**命題**：$u \mapsto \left(\wp(u), \wp'(u)\right)$ 是環面到**橢圓曲線** $w^2 = 4z^3 - g_2z - g_3$ 的保角同構（加 $\infty$ 點）。**「環面 = 三次曲線」**——分析（$\wp$）、代數（曲線方程）、幾何（環面）的三重同一，是 **Fermat 大定理**所用的橢圓曲線（8.3 篂場景四）的解析化身。

**Liouville 定理的約束（1847）**：非恆常的橢圓函數**必有極點**（有界整函數恆常）；**極點留數之和為零**（球面留數守恆，4.2 篂場景二）；**零點數 = 極點數（計重數）**；**至少二階極點**（一階極點留數非零違反守恆）——$\wp$ 的二階極點是「最小的病態」。**Liouville 正是為了橢圓函數發明他的定理**（4.1 篂——定理的誕生語境）。

**加法定理**：

$$
\wp(u + v) = -\wp(u) - \wp(v) + \frac14\left(\frac{\wp'(u) - \wp'(v)}{\wp(u) - \wp(v)}\right)^2.
$$

**「角的和的公式」的雙週期版**（對照 $\sin(u+v)$ 的公式，1.3 篂）——**代數群的結構**：環面 = 交換群（$\mathbb{C}/\Lambda$ 的平移群），$\wp$ 把群律翻譯成曲線上的弦切線法則——**橢圓曲線密碼學（ECC）的數學心臟**：$P + Q$ 的弦割法群律 = 加法定理的幾何。

### 一個具體例題

**例題 9.2.1**：設 $\Lambda = \mathbb{Z} + i\mathbb{Z}$（正方形格）。(a) 說明 $g_3 = 0$（由格的旋轉對稱）；(b) 寫出 $\wp$ 的微分方程；(c) 求 $\wp$ 在基本域內取值 0 的點；(d) 說明 $\wp$ 誘導環面到橢圓曲線的同構，曲線是什麼？

**解**：

(a) $\Lambda$ 對 $z \mapsto iz$ 不變（旋轉 $90^\circ$）。$\wp(iz) = \frac{1}{(iz)^2} + \sum\left(\frac{1}{(iz - \omega)^2} - \frac{1}{\omega^2}\right) = -\frac1{z^2} - \sum_{\omega'\ne0}\left(\frac{1}{(z - \omega')^2}\cdot\frac{1}{i^2}\right) + \cdots$——直接驗證：$\wp(iz) = -\wp(z)$（旋轉對稱把格映到自身、二階極點結構保持）。則 $\wp'^2 = 4\wp^3 - g_2\wp - g_3$ 中代入 $z \to iz$：$\wp'^2(iz) = 4(-\wp)^3 - g_2(-\wp) - g_3 = -4\wp^3 + g_2\wp - g_3$；而 $\wp'(iz) = \frac{d}{d(iz)}\wp(iz) = \frac{-\wp'(z)\cdot(-1)}{i}$——**更簡單地**：$\wp'^2(iz) = \wp'^2(z)$（因 $\wp(iz) = -\wp(z)$ 求導 $\wp'(iz)\cdot i = -\wp'(z)$，平方後 $-\wp'^2(z) = $ ……細節：$\wp'(iz) \cdot i = -\wp'(z) \Rightarrow \wp'^2(iz) = -\wp'^2(z)$？$\left(\frac{-\wp'}{i}\right)^2 = -\wp'^2$）。故 $-\wp'^2 = -4\wp^3 + g_2\wp - g_3$，與原方程（乘 $-1$）：$\wp'^2 = 4\wp^3 - g_2\wp - g_3$ 對照，得 $-g_2\wp + g_3 = g_2\wp + g_3 \Rightarrow$ 比較係數：$g_2 = 0$？**標準結果**：正方形格 $g_3 = 0$、**三角形格 $g_2 = 0$**——由係數和 $\sum\omega^{-6}$：旋轉 $e^{i\pi/2}$ 使 $\omega^{-6} \to (i\omega)^{-6} = \omega^{-6}i^{-6} = -\omega^{-6}$，而和不變 ⇒ $g_3 = -g_3 = 0$ ✓（$g_3$ 是六次和，$i^{-6} = -1$）。**同理 $g_2$（四次和）：$(i\omega)^{-4} = \omega^{-4}$ 不變——$g_2 \ne 0$ ✓**。故 $g_3 = 0$。

(b) $\wp'^2 = 4\wp^3 - g_2\wp$（$g_2 = 60\sum_{\omega\neq0}\omega^{-4} \approx 189.07$ 對單位正方格）。

(c) $\wp$ 偶函數、二階極點：基本域內 $\wp$ 取每值兩次（計重數）。$\wp(z) = 0$：由對稱（$\wp(iz) = -\wp(z)$），$\wp = 0$ 需 $\wp(z) = -\wp(z)$，即**不動點型解**：$z = \frac{\omega_1 + \omega_2}{2} = \frac{1+i}{2}$（半週期點）——**驗證**：$\wp\left(\frac{1+i}2\right) = -\wp\left(\frac{1+i}{2}\right)$（代入 $z = i\cdot\frac{1+i}{2}\cdot(-i)$……直接：$\frac{1+i}{2} = i\cdot\frac{1-i}{2}$，而 $\frac{1-i}{2} \equiv \frac{1+i}{2} - i \equiv \frac{1+i}{2} \pmod \Lambda$，故 $\wp\left(\frac{1+i}{2}\right) = \wp\left(i\cdot\frac{1+i}{2}\right) = -\wp\left(\frac{1+i}{2}\right)$ ⇒ $\wp = 0$ ✓）。**半週期點 $\frac{\omega_1+\omega_2}{2}$ 處 $\wp = 0$**（正方格情形）。

(d) 曲線 $w^2 = 4z^3 - g_2 z$（$g_3 = 0$）：有 $z = 0$ 的根——曲線 $w^2 = 4z(z^2 - \frac{g_2}{4})$ 有三實根（$0, \pm\sqrt{g_2}/2$ 型——$g_2$ 實正）——**橢圓曲線 $y^2 = 4x^3 - g_2x$**，環面 $\mathbb{C}/(\mathbb{Z} + i\mathbb{Z})$ 與它的解析同構（復乘 $\tau = i$ 的著名情形——**「復乘」橢圓曲線**，有額外對稱 $z \mapsto iz$）。**這條曲線就是 7.2 篂例題 $w^2 = z^3 - z$ 的近親**（$g_2$ 規範化後同型）——虧格 1 的兩章（7.2 幾何、9.2 分析）在同一條曲線上合龍。

### 歷史背景：雙星與孤星

- **Fagnano（1716–1718）**：Lemniscate 弧長的二等分問題——橢圓積分的史前史。
- **Euler（1738–1753）**：發現橢圓積分的**加法定理**（單擺與彈性曲線的力學需求）。
- **Legendre（1786–1827）**：三十年系統研究橢圓積分（三類積分的標準型），卻**止步於積分**——他與函數論的失之交臂。Legendre 晚年讀到 Abel/Jacobi 的逆轉，寫道：「**這個年輕人的工作，比我餘生所做的更值得紀念**」——科學史上最動人的讓位之一。
- **Abel（1802–1829）**：27 歲死於肺結核（貧困中），死前兩天收到未婚妻家書、死後兩天寄到柏林大學的聘書。**橢圓函數、Abel 積分、五次方程不可解（與 Galois）、Abel 群**——七年工作生涯奠定四個領域。Abel 獎（2003 起，挪威）以其命名。
- **Jacobi（1804–1851）**：Königsberg 教授，發明 $\theta$ 函數（雙週期函數的「平方根」，Fourier 級數的雙週期版）、與 Abel 競爭中建立函數論的第二條路（$\theta$ 函數路線——**模形式的祖先**，8.3 篂場景一）。
- **Weierstrass（1862 講義）**：以 $\wp$ 函數重建整個理論（第一條路），並推廣到 Abelian 函數（虧格 $g \ge 2$）——他的中學教師時期研究正是橢圓函數（1854 成名論文）。

**「兩類函數論」**：Jacobi 的 $\theta$ 函數路線（Fourier/模形式風格）與 Weierstrass 的 $\wp$ 路線（級數/構造風格）——現代雙曲函數論（Langlands、模形式）繼承前者，代數幾何繼承後者。**一門數學的兩個學派**再次證明「多源匯流」的生產力。

### 歷史啟示

- **逆轉的威力**：「研究反函數」把不可積的積分變成可研究的函數——**當直接路徑堵死，走對偶路**（與 4.2 篂「Laurent 負冪」、5.2 篂「圍道翻轉」同型思維）。
- **特例孕育一般**：Lemniscate（Fagnano）→ 橢圓積分（Legendre）→ 橢圓函數（Abel/Jacobi）→ Abelian 函數（Weierstrass）→ 模形式（Langlands）。**一個特例的深挖通向整個綱領**。
- **早逝與傳承**：Abel 27 歲、Galois 20 歲、Ramanujan 32 歲、Ramanujan 的 $\theta$ 函數……數學史上「天才早逝、理論永生」的名單令人唏噓；Abel 獎的設立是數學共同體的記憶儀式。

## 練習

1. 證明：非常數橢圓函數在基本域內的零點總數（計重數）等於極點總數。（提示：$\oint \frac{f'}{f}$ 沿基本域邊界——對邊貢獻相消，輻角原理 5.3 篂的環面版。）
2. 由 $\wp'^2 = 4\wp^3 - g_2\wp - g_3$ 推出 $\wp$ 的三階 ODE：$\wp''' = 12\wp\wp' - g_2\wp'$，並驗證 $\wp'' = 6\wp^2 - \frac{g_2}{2}$。
3. 對正方格，驗證半週期點 $\frac12, \frac{i}{2}, \frac{1+i}{2}$ 處 $\wp$ 的值分別是三次方程 $4z^3 - g_2z = 0$ 的三根（對稱性論證）。
4. 證明：橢圓函數的加法定理保證「環面上有群結構」，並說明 $\wp$ 如何把「模 $k$ 加法」變成曲線上的弦切線法則。
5. 思考題：Legendre 三十年研究積分卻錯過函數論；Abel 兩年完成逆轉。「及時轉換研究對象」在數學史上的意義是什麼？列出另外兩個「換對象而突破」的案例。

## 進階研讀：橢圓函數的五個深化場景

**場景一：$\theta$ 函數與模形式**。$\theta(\tau) = \sum_{n\in\mathbb{Z}}e^{i\pi n^2\tau}$ 的模變換 $\theta(-1/\tau) = \sqrt{-i\tau}\,\theta(\tau)$——**Jacobi $\theta$ 是第一個模形式**；$\wp$ 可由 $\theta$ 構造（$-\frac{d^2}{dz^2}\log\theta$ 型）。8.3 篂的 $\zeta$ 函數方程正是 $\theta$ 模性的直接推論——**橢圓函數論是模形式論的 $g = 1$ 起點**。

**場景二：橢圓曲線的算術**。曲線 $y^2 = x^3 - x$ 上的有理點：弦切法從 $(0,0)$ 生成無窮多有理點（**Mordell 定理 1922：有理點群有限生成**）。**BSD 猜想**（千禧年問題）：$L$ 函數在 1 的行為 = 有理點群的秩——**橢圓函數論的分析（$L$ 函數）與算術（有理點）的等價猜想**。Wiles 的模性定理（1995）：每條半穩定橢圓曲線是模形式——**Fermat 大定理是這座橋的第一份大禮**。

**場景三：橢圓曲線密碼學**。有限域 $\mathbb{F}_p$ 上的橢圓曲線點群：$y^2 = x^3 + ax + b \pmod p$ 的點 + 弦切群律 = 有限交換群；**ECDLP**（離散對數）難解性 = Bitcoin、TLS 的安全基礎。**1829 年的加法定理在 2009 年的加密貨幣中運行**——數學應用的最長程交付之一。

**場景四：可積系統與 cnoidal 波**。KdV 方程 $u_t + 6uu_x + u_{xxx} = 0$ 的週期解 $u = 2\wp$ 型（**cnoidal 波**，Korteweg–de Vries 1895 的運河淺水波）——**橢圓函數是非線性波動的精確解庫**；逆散射法（Gardner–Greene–Kruskal–Miura 1967）把 KdV 解與譜理論連接——**可積系統 = 橢圓/Abel 函數的現代力學**。

**場景五：Abel 積分與高虧格**。虧格 $g$ 曲面上的積分 $\int R(z, w)dz$（$w^m = p(z)$）：$2g$ 個獨立週期、Abel 定理、Jacobi 反演——**Weierstrass 1850s 的 Abelian 函數綱領**（他的成名作）。現代化身：Hodge 理論（週期矩陣）、Griffiths 的 Abel 定理推廣（1970s）、弦論的 B 模積分。**「積分的多值性 = 曲面的拓撲」在任意虧格的完全展開**——7.2 篂的承諾在此兌現。

### 名詞速查表（本節出現的核心術語）

- **cnoidal 波**：KdV 的橢圓函數解。

### 深化問答三則

**問：為什麼「反函數」策略在橢圓積分上如此有效？**
答：積分 $\int\frac{dt}{\sqrt{p(t)}}$ 的多值性（$\sqrt{p}$ 的兩葉）是死結；反函數把「多值的積分」換成「雙週期的函數」——**單值性的丟失轉化為週期性的獲得**（$\arcsin$ 的 $\pm$ 多值 vs $\sin$ 的 $2\pi$ 週期，同型）。這是「換對偶面」戰術的巔峰：**積分難題 = 週期財富**。

**問：橢圓函數為什麼「至少二階極點」？**
答：Liouville：極點留數之和 = 0（球面守恆）。一階極點留數非零、和必非零——矛盾。二階極點（$\frac{1}{z^2}$ 型）留數為零——最小可行。**$\wp$ 的 $\frac{1}{z^2}$ 不是設計選擇而是邏輯必然**——「群結構（平移週期）+ 守恆律（留數）」共同鎖定最小病態。**簡單性是被定理逼出來的**。

**問：橢圓函數論與 $\zeta$ 函數論「像」在哪裡？**
答：兩者都是「函數方程 + 乘積/週期結構」的雙支柱理論：$\zeta$ 有函數方程（模性）+ Euler 乘積（質數）；橢圓函數有雙週期 + $\wp$ 乘積/加法定理。**「對稱性 + 編碼（乘積/週期）」**是十九世紀函數論的通用語法；Langlands 綱領把它們統一（$\zeta$ = $GL(1)$ 的 L 函數、橢圓曲線 L = $GL(2)$ 的對應）——**8.3 與 9.2 是同一綱領的兩個縮影**。
