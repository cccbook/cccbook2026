# 8.2 MITTAGLEFFLER定理

## 本章導言

Weierstrass 因子分解（8.1）用**乘積**編碼零點；它的對偶——用**部分分數**編碼極點——是 Mittag-Leffler 定理（1884）：給定任意離散極點集與各點的主部，可造半純函數以它們為極點、留數精確。**「零點 → 乘積、極點 → 部分分數」**是整函數論的雙支柱，而部分分數展開正是 5.1 篂採樣技術（$\pi\cot\pi z$）的全面升級。本節講述定理、收斂校正、兩個經典展開（$\pi\cot$、$\pi\csc$、$\Gamma$ 的部分分數），與 Gösta Mittag-Leffler 的傳奇人生。

### 定理

**Mittag-Leffler 定理（1884）**：給定離散點列 $\{a_n\} \subset \mathbb{C}$（無有限聚點）與每點的**主部**（多項式，無常數項）

$$
P_n\left(\frac{1}{z - a_n}\right) = \frac{c_{n,1}}{z - a_n} + \cdots + \frac{c_{n,m_n}}{(z - a_n)^{m_n}},
$$

則存在半純函數 $f$，其極點恰為 $\{a_n\}$（重數 $m_n$），且在 $a_n$ 的主部恰為 $P_n\left(\frac{1}{z-a_n}\right)$。一般解 = 特解 + **整函數**（自由度）。

**構造與證明思想**：天真的 $\sum_n P_n\left(\frac{1}{z - a_n}\right)$ 在 $z$ 遠處不收斂（各項 $\to 0$ 太慢）。**Mittag-Leffler 的校正**：$P_n(w) - Q_n(w)$，其中 $Q_n$ 是 $P_n$ 在 $\{|z| < R_n\}$ 內 Taylor 展開的前若干項（$R_n \to \infty$ 快速）——**在擴大的圓上把 $P_n$ 減成 $O(\text{小})$**：

$$
f(z) = \sum_n \left[P_n\left(\frac{1}{z - a_n}\right) - Q_n(z)\right],
$$

收斂成立（每項在大圓內 $|z| \le R_n$ 上 $\le C/2^n$ 型）。**「減去 Taylor 頭、保留極點尾」**——與 Weierstrass 的「乘校因子」完全對偶：一個乘指數殺尾巴、一個減多項式殺尾巴。

**對偶表**：

| | Weierstrass | Mittag-Leffler |
|---|---|---|
| 編碼 | 零點 | 極點（主部） |
| 形式 | 乘積 | 級數（部分分數） |
| 校正 | $E_p$ 指數因子 | 減 Taylor 頭 |
| 自由度 | $e^{g(z)}$ | 整函數 |
| 求導關係 | $\left(\prod\right)' / \left(\prod\right) = \sum \frac{a_n'}{a_n}$ | 部分分數 |

### 三個經典展開

**一、$\pi \cot \pi z$（5.1 篂採樣器的出身）**：

$$
\pi\cot\pi z = \frac{1}{z} + \sum_{n=1}^\infty\left(\frac{1}{z - n} + \frac{1}{z + n}\right) = \frac{1}{z} + \sum_{n\ne0}\left(\frac{1}{z - n} + \frac{1}{n}\right)\;(\text{收斂校正形式}).
$$

極點 $n \in \mathbb{Z}$、每處主部 $\frac{1}{z - n}$（留數 1）。**由 $\sin\pi z$ 的 Euler 乘積對數求導**（8.1 篂練習 3）可得同一公式——**乘積與部分分數在此互證**。應用：級數求和（5.1 篂應用二）。

**二、$\pi \csc \pi z$**：

$$
\pi\csc\pi z = \sum_{n=-\infty}^{\infty}(-1)^n\frac{1}{z - n}.
$$

極點 $\mathbb{Z}$、留數 $(-1)^n$（$\sin\pi z$ 的導數在整數處交替符號）。應用：**交錯級數求和**與 $\Gamma$ 的餘元公式。

**三、$\Gamma$ 的部分分數**：

$$
\frac{\Gamma'(z)}{\Gamma(z)} = -\gamma - \frac{1}{z} + \sum_{n=1}^{\infty}\left(\frac{1}{n} - \frac{1}{z + n}\right), \qquad \frac{\Gamma(z)}{\;?} \;\text{型展開}.
$$

直接形式：$\Gamma(z) = \sum_{n=0}^\infty \frac{(-1)^n}{n!}\cdot\frac{1}{z + n} + \text{整函數}$——**留數序列 $(-1)^n/n!$ 的部分分數展開**；由 $1/\Gamma$ 的 Weierstrass 乘積（8.1 篂）取對數導數得 digamma 展開（上式）。**9.1 篂將全面展開**；本節要點：**$\Gamma$ 的「極點簽名」與「乘積簽名」互相換算**——8.1 與 8.2 兩節的定理在同一函數上會師。

### 一個具體例題

**例題 8.2.1**：用 Mittag-Leffler 展開求 $\displaystyle\sum_{n=1}^{\infty}\frac{(-1)^{n}}{n^2 - a^2}$（$a \notin \mathbb{Z}$）。

**解**：考慮 $f(z) = \frac{\pi\csc\pi z}{z^2 - a^2}$。極點：$z = n \in \mathbb{Z}$（留數 $\frac{(-1)^n}{n^2 - a^2}$）與 $z = \pm a$（留數 $\frac{\pi\csc \pi a}{\pm 2a}$）。

沿大方圈積分（$\csc$ 在方圈上有界：取圈過半整數點 $\pm(N + \frac12) \pm i(N+\frac12)$，$|\csc\pi z| \le C$；$f \sim \frac{1}{z^3}$，積分 $\to 0$）。留數總和為零：

$$
\sum_{n=-\infty}^{\infty}\frac{(-1)^n}{n^2 - a^2} + \frac{\pi\csc\pi a}{2a} + \frac{\pi\csc\pi a}{-2a}\cdot(-1)\cdots
$$

**細算**：$\operatorname{Res}_a f = \frac{\pi\csc\pi a}{2a}$；$\operatorname{Res}_{-a} f = \frac{\pi\csc(-\pi a)}{-2a} = \frac{-\pi\csc\pi a}{-2a} = \frac{\pi\csc\pi a}{2a}$。兩者之和 $= \frac{\pi\csc\pi a}{a}$。

$$
\underbrace{\sum_{n=-\infty}^{\infty}\frac{(-1)^n}{n^2 - a^2}}_{\text{含 } n=0 \text{ 項 } -\frac{1}{a^2}} + \frac{\pi\csc\pi a}{a} = 0.
$$

故 $\displaystyle\sum_{n=-\infty}^{\infty}\frac{(-1)^n}{n^2 - a^2} = -\frac{\pi\csc\pi a}{a}$。拆出 $n = 0$ 與對稱項（$n \ge 1$ 兩倍）：

$$
-\frac{1}{a^2} + 2\sum_{n=1}^\infty\frac{(-1)^n}{n^2 - a^2} = -\frac{\pi\csc\pi a}{a}
\;\Rightarrow\;
\boxed{\sum_{n=1}^{\infty}\frac{(-1)^{n}}{n^2 - a^2} = \frac{1}{2a^2} - \frac{\pi}{2a}\csc\pi a}.
$$

**檢算**（$a \to 0$）：左邊 $\to \sum \frac{(-1)^n}{n^2} = -\frac{\pi^2}{12}$；右邊展開：$\frac{1}{2a^2} - \frac{\pi}{2a}\left(\frac{1}{\pi a} + \frac{\pi a}{6} + \cdots\right) = \frac{1}{2a^2} - \frac{1}{2a^2} - \frac{\pi^2}{12} - \cdots \to -\frac{\pi^2}{12}$ ✓（用 $\csc x = \frac1x + \frac{x}{6} + \cdots$）。**留數 + 對稱 + 極限檢查**——5.1 篂方法論的完整重演。

### 歷史背景：Mittag-Leffler 的雙面人生

**Magnus Gösta Mittag-Leffler（1846–1927）**：

- **數學**：Weierstrass 的學生（柏林，1875 前後），把柏林學派的嚴格構造精神帶回瑞典。1884 年部分分數定理；其後四十年的「Mittag-Leffler 星」（指數多項式和的收斂域理論，1905），預告了準解析理論與現代逼近論。
- **制度建設**：**1882 年創辦《Acta Mathematica》**——至今仍是頂級數學期刊。他說服瑞典國王資助，並以期刊為槓桿調停了**Poincaré 與 Weierstrass 學派的緊張**、推廣 Cantor 的集合論（他是 Cantor 在國際上最重要的支持者！）、資助 Kovalevskaya（Weierstrass 的學生、歷史上第一位女數學教授）在 Stockholm 的職位。
- **Nobel 之謎**：流行的說法稱 Mittag-Leffler 與 Nobel 有隙、故無數學 Nobel 獎——**此說是神話**（史家 Crawford 1984 考證：Nobel 未設數學獎與個人恩怨無關）。但他確實是 1900 年代「數學應否有 Nobel 級獎」討論的中心人物之一。
- **別墅與定理**：他的別墅 Djursholm 及圖書館捐給瑞典科學院，即今日 **Mittag-Leffler 研究所**（瑞典數學的國際交流中心）。

**歷史意義**：Mittag-Leffler 是「**學術基建者**」的典範：定理重要、期刊更重要、研究所影響一個世紀。數學史通常記載定理發明者；本書特別記錄制度發明者——**數學的生態系需要園丁**。

### 歷史啟示

- **對偶的生產力**：零點–乘積、極點–部分分數，兩兩對偶。**「找到對偶面」常使一個理論變成兩個**，且互相餵養（乘積求導得分數、分數求積得乘積）。
- **校正技術的通用性**：Weierstrass 乘指數、Mittag-Leffler 測多項式——**「保留局部、馴服全域」**的兩種實現。現代分析（截斷、Mollifier、Renormalization）反覆使用同型思想。
- **期刊的力量**：《Acta Mathematica》使北歐數學在 1880–1930 從邊陲變成重鎮。**發表渠道本身就是數學生產力**。

## 與其他章節及領域的關聯

- **5.1 節**：留數定理與採樣函數是部分分數展開的積分證明路線；Mittag-Leffler 是其定理化。
- **8.1 篂**：乘積與分數的對偶；對數求導是兩者的翻譯機。
- **8.3 篂**：$\zeta$ 的部分分數（$\zeta' / \zeta$ 的展開）是素數定理的計算形式。
- **9.1 篂**：$\Gamma$ 的展開族（digamma、trigamma）。
- **10.1 篂**：Z 域的部分分數展開 = **離散系統的部分分數反演**（差分方程解、IIR 濾波器係數）——工程師每天用 Mittag-Leffler 的特例。
- **調和分析**：Cauchy 核的展開、Hilbert 變換核 $\frac{1}{\pi}\,\text{p.v.}\frac{1}{t - s}$ 的格點化——部分分數是「核的原子分解」。
- **物理**：Green 函數的頻譜展開（$\sum_n \frac{|\psi_n\rangle\langle\psi_n|}{E - E_n}$）——**譜分解 = 物理版部分分數**，極點留數 = 態的權重。

## 進階研讀：部分分數的五個深化場景

**場景一：Mittag-Leffler 星與準解析性**。Mittag-Leffler（1905）考慮 $\sum a_n e^{-\lambda_n z}$ 型「廣義指數和」的收斂域（複平面上的**星形域**），其唯一性問題（何時由一條線上的值唯一決定）直接通向 **Denjoy–Carleman 準解析理論**（1920s）。**部分分數構造的收斂調優**成為現代唯一性理論的起點——定理的「校正自由度」問題發育成一門學科。

**場景二：$\zeta'/\zeta$ 的展開與素數定理**。$\frac{\zeta'}{\zeta}(s) = \sum_n \frac{\Lambda(n)}{n^s}$（Dirichlet 級數）在 $s$ 平面的部分分數（極點：$s = 1$ 與 $\zeta$ 零點 $\rho$，主部 $\frac{1}{s - \rho}$）——**素數計數函數 $\psi(x)$ 的顯式公式**（Riemann 1859 的「夢想公式」）：

$$
\psi_0(x) = x - \sum_\rho \frac{x^\rho}{\rho} - \log 2\pi - \frac12\log(1 - x^{-2}).
$$

**零點的部分分數 = 素數的顯式波形**——8.3 篂的主題在此預告：Mittag-Leffler 定理是解析數論的結構工程。

**場景三：譜展開與算子理論**。自伴算子 $A$ 的預解式 $(A - z)^{-1}$ 是 $z$ 的算子值半純函數（離散譜時）：$\operatorname{Res}$ = 投影。**Mittag-Leffler 展開 = 預解式的譜分解**：$R_z = \sum \frac{P_n}{z - E_n} + \text{修正}$。量子力學的 Green 函數方法（譜表示、Lehmann 表示）就是「無窮維 Mittag-Leffler」。**極點位置 = 能階、留數 = 態振幅**。

**場景四：Padé 逼近與部分分數**。有理逼近 $R(z) = \frac{p(z)}{q(z)}$ 的部分分數分解 = Padé 表的極點結構；Stieltjes 級數（矩量問題）的 Padé 逼近對應測度的離散化（Gauss 求積節點 = 極點）。**部分分數是「連續測度 ↔ 離散節點」的橋**（5.1 篂場景二的工程化）：正交多項式、Gauss 求積、Lanczos 演算法（數值線性代數的 Krylov 方法）都是這座橋的現代形態。

**場景五：數位濾波器的部分分數反演**。Z 變換 $H(z) = \frac{N(z)}{D(z)}$ 的部分分數 $H(z) = \sum_k \frac{c_k}{1 - p_k z^{-1}}$ → 衝激響應 $h[n] = \sum c_k p_k^n u[n]$——**差分方程的解 = 離散 Mittag-Leffler**。工程教科書的「partial fraction expansion」章節，數學上就是本節定理在 $g = 0$、有限極點的特例。**1884 年的定理在每片 DSP 晶片上運行**。

### 深化問答三則

**問：Mittag-Leffler 定理中「解不唯一」是缺陷嗎？**
答：不，是**結構**：解空間 = 特解 + 整函數。加上增長規範（如「大圓上有界」或「最小階」）後唯一。這種「差是整函數」的結構在複分析反覆出現（原函數差常數、延拓差 monodromy）——**解的集體形狀由「壞點資料 + 好點自由」兩層組成**。工程上「最小階實現」（濾波器的 canonical form）正是選擇整部為零。

**問：部分分數與「留數定理」的關係？**
答：部分分數展開可由留數定理證明（大方圈 + $\pi\cot$ 採樣——例題的路線），也可由 Mittag-Leffler 定理構造性證明。前者是「驗證型」（先猜 $\pi\cot\pi z$ 形式），後者是「構造型」（任意主部可實現）。兩條路線的對照與 3.2 篂 Cauchy 定理的兩種證明同構：**積分法與構造法的雙軌**。

**問：為什麼工程師那麼愛部分分數？**
答：因為它把**微分方程/差分方程的解**化為指數的線性組合：每個極點貢獻一個模態 $e^{pt}$ 或 $p^n$。控制理論的「極點配置」、濾波器的「模態分解」、振動分析的「主模態」——**極點 = 模態**的字典使部分分數成為系統論的語法。數學史上，這是「函數的極點編碼」最成功的下游應用。
