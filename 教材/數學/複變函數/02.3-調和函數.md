# 2.3 調和函數

## 本章導言

解析函數的實部與虛部滿足拉普拉斯方程——這句話使複分析成為**數理物理的後勤基地**：靜電場、穩態溫度、理想流體的速度勢，全部由調和函數治理。本節正式介紹調和函數：定義、與解析函數的雙向關係、平均性質與最大值原理，以及著名的 Dirichlet 問題與圓盤上的 Poisson 公式。歷史主線是 Riemann 對 Dirichlet 原理的信賴與 Weierstrass 的摧毀性批判——一場持續五十年的方法論戰爭。

### 定義與基本例子

設 $u$ 在開集 $D$ 上有二階連續偏導，若

$$
\Delta u := \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} = 0,
$$

則稱 $u$ 在 $D$ 上**調和**（harmonic）。$\Delta$ 稱為 Laplace 算子（「差分算子」$\nabla\cdot\nabla$）。

基本例子：

- $u = x^2 - y^2$：$u_{xx} + u_{yy} = 2 - 2 = 0$ ✓（即 $\operatorname{Re} z^2$）。
- $u = \log r = \log|z|$：在 $\mathbb{C}\setminus\{0\}$ 上，$\Delta \log r = 0$（驗證：$u_r = 1/r$、$u_{rr} = -1/r^2$，極座標下 $\Delta u = u_{rr} + \frac1r u_r + \frac{1}{r^2}u_{\theta\theta} = -\frac{1}{r^2} + \frac{1}{r^2} = 0$）。原點是**奇點**：$\Delta \log r$ 在分布意義下等於 $2\pi\delta_0$——「點電荷的勢」。
- $u = \operatorname{Re}\dfrac{1}{z}$、$u = e^x\cos y$、$u = r^n\cos n\theta$。

**關鍵定理（調和性來自解析性）**：若 $f = u + iv$ 解析（$u, v$ 二階可微），則 $u, v$ 調和（2.2 節已推導）。反向也有**部分**的成立：

**定理（調和函數局部是解析函數的實部）**：$u$ 在單連通區域 $D$ 上調和 $\iff$ 存在解析函數 $f$，使 $u = \operatorname{Re} f$ 在 $D$ 上成立。

**構造證明思想**（單連通是關鍵）：給定 $u$，定義

$$
g = u_x - iu_y.
$$

由 $u$ 調和可驗 $g$ 滿足 C–R（$g$ 的實虛部為 $u_x, -u_y$；$(u_x)_x = (-u_y)_y$ 由 $\Delta u = 0$、$(u_x)_y = -(-u_y)_x$ 平凡）。故 $g$ 解析；單連通保證 $g$ 有原函數 $G$（沿路徑積分構造），且

$$
\frac{\partial}{\partial \bar z}(f - u) = 0, \quad \text{取 } f = G + u,\; \text{可調整常數使 } \operatorname{Re} f = u.
$$

細節化簡後即得：$f$ 解析、$\operatorname{Re} f = u$。$v = \operatorname{Im} f$ 稱為 $u$ 的**調和共軛**——在不計常數與（多連通時的）週期下唯一。**單連通的作用**：在環形區域上，$u = \log r$ 的調和共軛是 $\theta$（多值！）——單值調和共軛不存在，這是多連通域的典型現象（7.3 節主角）。

### 平均值性質與最大值原理

**平均值性質**：$u$ 在圓盤 $\overline{B(z_0, R)}$ 上調和，則

$$
u(z_0) = \frac{1}{2\pi}\int_0^{2\pi} u(z_0 + Re^{i\theta})\,d\theta.
$$

**圓心值 = 圓周值的平均**。證明思想：$u = \operatorname{Re} f$ 解析，由 Cauchy 積分公式（3.3 節）$f(z_0) = \frac{1}{2\pi}\oint f\,d\theta$，取實部即得。（也可以獨立地由調和函數的 Green 恆等式證明。）

**最大值原理**：非恆常的調和函數在區域內部不能達到最大值（或最小值，考慮 $-u$）。證明：若 $u$ 在內點 $z_0$ 達最大值 $M$，則由平均值性質，小圓周上的值平均也為 $M$，而各處 $\le M$，故小圓周上恆為 $M$；圓盤上同理恆為 $M$；由連通性與連續性蔓延，$u$ 恆常——矛盾。

最大值原理的直觀：調和函數是「繃緊的膜」（肥皂膜、橡膠膜）的高度——膜上不能有內部鼓包，除非有支撐（邊界）。這條直觀將在 10.2 節的物理敘事中完全兌現。

### Dirichlet 問題與 POISSON 公式

**Dirichlet 問題**：給定區域 $D$ 與邊界上的連續函數 $g$，求 $D$ 上調和、邊界上取值 $g$ 的函數 $u$。

物理原型：金屬環邊界加熱到指定溫度 $g$，求內部穩態溫度分布。**唯一性**由最大值原理立刻得到（兩解之差調和且邊界為零，最大最小都是零，故恆零）。**存在性**才是硬仗。

**圓盤上的解：Poisson 公式（1820s）**。單位圓盤上，邊界函數 $g(e^{i\phi})$ 的解為

$$
u(re^{i\theta}) = \frac{1}{2\pi}\int_0^{2\pi} \underbrace{\frac{1-r^2}{1 - 2r\cos(\theta - \phi) + r^2}}_{P_r(\theta-\phi)}\, g(e^{i\phi})\,d\phi,
$$

其中 $P_r$ 是 **Poisson 核**。它滿足：$P_r > 0$、$\frac{1}{2\pi}\int P_r\,d\phi = 1$、且 $r \to 1^-$ 時 $P_r$ 集中於 $\theta = \phi$（近似恆等）。因此 $u(re^{i\theta})$ 是 $g$ 的「調和軟化」，邊界上收斂回 $g$。Poisson 核同時是**Fourier 分析**的入場券：把 $g$ 展成 Fourier 級數，$u(re^{i\theta}) = \sum \hat g_n r^{|n|} e^{in\theta}$——「半徑 $r$ 的阻尼」濾掉高頻，這正是 10.1 節低通濾波器的數學原型。

### 歷史主戲：Dirichlet 原理的興衰

**Dirichlet 原理**（得名於 G. L. Dirichlet，1805–1859，其 1856 年講義推廣了 Gauss 與 Thomson 的想法）：在所有邊界值為 $g$ 的函數中，「能量」積分

$$
\mathcal{E}[u] = \iint_D \left(u_x^2 + u_y^2\right)\,dx\,dy
$$

的最小化問題有解，且解必為調和函數（Euler–Lagrange 方程即 $\Delta u = 0$）。

**Riemann 的賭注（1851–1857）**：Riemann 把這個原理當作整個函數論的地基——用「能量極小必有極小點」論證 Dirichlet 問題有解，進而建立 Riemann 面上的函數存在性（Riemann–Roch 的前身）、映射定理（6.2 節）。他承認這一步「尚未完全嚴格」，但他相信物理直觀（平衡態必然存在）。

**Weierstrass 的轟炸（1870）**：Weierstrass 展示了一個著名的能量泛函，其下確界為 0 卻**不可達**（例如在單位圓內取 $u_\varepsilon$ 型的函數序列：能量趨於 0，但極限不可能是連續的邊值延拓）。**下有界 + 可趨近 $\ne$ 可達**。Riemann 的地基塌了。Riemann 於 1866 年早逝（39 歲），未及回應。

**重建（1900 前後）**：Hilbert 在 1900 年巴黎數學家大會的著名演講中把「挽救 Dirichlet 原理」列為問題之一，並於 1904–1906 年以「變分直接法」完成：不假設極小點存在，而是**取極小化序列、用緊性論證收斂子列、證極限就是解**。Fredholm 積分方程理論（1900）提供了另一條路。歷史裁決：**Riemann 的結論全對，他的論證不嚴；Weierstrass 的批評全對，卻沒有動搖 Riemann 的定理**。這場戰爭的現代總結寫在 Sobolev 空間理論中：能量泛函在 $W^{1,2}$ 中確實達到極小——只是「函數」的定義必須放寬（見 2.2 節進階研讀）。

### 一個具體例題

**例題 2.3.1**：單位圓盤上求調和函數 $u$，使在邊界 $|z| = 1$ 上 $u = g(\theta) = 1 + \cos\theta + \cos 2\theta$（弧長參數 $\theta$）。並求 $u(0)$ 與 $u(1/2, 0)$。

**解**：Fourier 展開恰為有限項：$g(\theta) = 1 + \cos\theta + \cos 2\theta$。由 Poisson 公式的 Fourier 形式（$r^{|n|}$ 阻尼）：

$$
u(r, \theta) = 1 + r\cos\theta + r^2\cos2\theta.
$$

驗證：每項 $r^n\cos n\theta = \operatorname{Re}(z^n)$ 是解析函數 $1 + z + z^2$ 的實部，故 $u = \operatorname{Re}(1 + z + z^2)$ 調和 ✓；邊界 $r = 1$ 時還原 $g$ ✓。

$u(0) = 1 + 0 + 0 = 1$。**與平均值性質對照**：$\frac{1}{2\pi}\int_0^{2\pi} g\,d\theta = 1 + 0 + 0 = 1$ ✓（$\cos$ 項的平均為零）。

$u(1/2, 0) = 1 + \frac12 + \frac14 \cdot 1 = 1.75$。由 Poisson 公式驗證：$P_{1/2}(\phi) = \frac{3/4}{5/4 - \cos\phi}$，$u = \frac{1}{2\pi}\int P_{1/2}(\phi)(1 + \cos\phi + \cos2\phi)\,d\phi$；利用 $\int P_r \cos n\phi\,d\phi = 2\pi r^n \cos n\theta$（$n=1,2$、$\theta = 0$）得 $\frac{1}{2\pi}(2\pi + 2\pi \cdot \frac12 + 2\pi \cdot \frac14) = 1.75$ ✓。

### 歷史啟示

- **物理直觀可以指對結論、錯在論證**：Riemann 依賴的「平衡態存在」是真的，但他引用的原理有洞。批評者（Weierstrass）正確，卻也無法否定結論——數學的進步常常需要**先保住定理、再換掉地基**。
- **平均值性質是調和性的靈魂**：它把偏微分方程（局部計算）翻譯成積分恆等式（整體平衡）。最大值原理、唯一性、Poisson 表示全部從平均性質流出。
- **邊界值決定內部**：Dirichlet 問題的唯一性說，調和函數是「聽邊界話」的函數；這與解析函數的「聽小區域話」（解析延拓）共同構成複分析兩大剛性。

## 練習

1. 驗證 $u = e^x \cos y$ 調和，求其調和共軛 $v$，寫出 $f = u + iv$ 並化為 $z$ 的初等表達式。
2. 證明：若 $u$ 調和且非常數，則 $u$ 的水平集（等值線）上沒有內部閉曲線圍成的單連通區域完全落在其中（提示：最大值原理反證）。
3. 單位圓盤上邊界值 $g(\theta) = \sin^2\theta$。用 Poisson 公式的 Fourier 形式求 $u(r,\theta)$，並驗證 $u(0) = \frac12$。
4. 用平均值性質證明：實部為 $u$ 的解析函數若在整個 $\mathbb{C}$ 上 $u$ 有上界，則 $u$ 為常數。（提示：Liouville 定理將在 4.1 節正式登場，先用平均值的圓周表達 + 令 $R\to\infty$ 估計。）
5. 思考題：解釋為什麼環形區域 $1 < |z| < 2$ 上，$u = \log r$ 沒有單值調和共軛，卻仍是好用的調和函數；「調和 $\Rightarrow$ 局部有解析實部」的定理如何精確地與此相容。

## 進階研讀：調和函數的五個深化場景

**場景一：Harnack 定理與單調收斂**。Harnack 不等式：非負調和函數在緊集上滿足 $\sup u \le C \inf u$（常數只依賴緊集與區域）。Harnack 收斂定理：調和函數的單調遞增列若在一點收斂，則內閉一致收斂且極限調和。這條定理是 modern PDE（熱方程、橢圓方程）的收斂理論原型，也是 6.2 節 Riemann 映射存在性論證（法圖、Montel、Carathéodory 路線）的關鍵組件。

**場景二：Poisson 核的三種身分**。(1) **機率身分**：$u(z) = E_z[g(B_\tau)]$——從 $z$ 出發的 Brown 運動首次撞擊邊界時的位置 $\tau$ 處之 $g$ 的期望值（Kakutani 1944：「調和函數 = Brown 運動的平均報酬」）。(2) **Fourier 身分**：$P_r$ 的 Fourier 級數 $\sum r^{|n|}e^{in\phi}$——阻尼恆等逼近。(3) **幾何身分**：$P_r(\phi) = \operatorname{Re}\frac{e^{i\phi} + z}{e^{i\phi} - z}$——Cauchy 核的實部。三種身分分別通向隨機分析、諧波分析與複幾何。

**場景三：奇異點的勢論分類**。孤立點處的調和函數若 $o(\log r)$ 有界，則可去（Riemann 定理的調和版）；對數奇點 $\log r$ 是二維點源。**能量有限則奇點可去**：$\int|\nabla u|^2 < \infty$ 的孤立奇點必可去（二維的臨界性！三維中 $\int|\nabla u|^2$ 有限不足以去除點奇點）。臨界維數現象是位勢論最精緻的主題之一。

**場景四：Green 函數與 Riemann 面**。區域 $D$ 對基點 $a$ 的 Green 函數 $G_a(z)$：調和、除 $a$ 外、邊界為零、$a$ 處對數爆發。它同時解決：(1) Dirichlet 問題（積分表示 $u(z) = -\oint g \frac{\partial G}{\partial n}ds$）；(2) 保角映射（單連通時 $G_a = -\log|f_a|$，$f_a$ 是映射 $a \mapsto 0$ 的 Riemann 映射）；(3) 電容/容量（多連通時的模不變數）。Green 函數是把「邊值問題」物件化的通用貨幣，9.2 節的橢圓積分是它在多連通域上的化身。

**場景五：從調和到次調和**。把「平均性質 = 圓心不超過圓周平均」的**單側**版本作為定義，得到**次調和函數**（subharmonic）：$\Delta u \ge 0$ 的凸性化。最大值原理對次調和函數仍成立，且它們構成上格（上確界封閉）。Perron 方法（1923）：用次調和函數的「上包絡」直接構造 Dirichlet 問題的解——**完全不依賴變分、也不依賴 Green 函數**，是 6.2 節映射定理現代證明（Koebe、Carathéodory 路線）的標準引擎。Perron 方法教訓：當「取最大」比「取極小」容易時，換個偏序再來一遍。

### 名詞速查表（本節出現的核心術語）

- **調和函數**：$\Delta u = 0$ 的 $C^2$ 函數。
- **調和共軛**：$v$ 使 $u + iv$ 解析；單連通域上存在（差常數唯一）。
- **平均值性質**：圓心值 = 圓周平均。
- **最大值原理**：內部無極值（除非恆常）。
- **Dirichlet 問題**：求調和函數滿足指定邊界值。
- **Poisson 核**：$P_r(\phi) = \frac{1-r^2}{1-2r\cos\phi + r^2}$。
- **Green 函數**：帶點源、零邊值的調和函數，Dirichlet 問題的萬能表示工具。
- **次調和函數**：$\Delta u \ge 0$（弱意義），Perron 方法的積木。
- **Dirichlet 原理**：能量極小化產生調和函數的變分原理。

### 深化問答三則

**問：為什麼「調和 = 解析函數的實部」只在單連通域局部成立而非全域保證？**
答：全局障礙是拓撲的：$\log r$ 在環域調和，但其共軛 $\theta$ 繞一圈增 $2\pi$——單值性失敗。這個「週期障礙」正是 de Rham 上同調（閉形式不恰當）的最早範例。Riemann 在 1857 年以「橫截割線」（Querschnitte）切開曲面強制單連通來處理——7.2 節 Riemann 面與同調論的直接前身。

**問：最大值原理「無內部極值」與日常經驗（金屬板中間最熱）矛盾嗎？**
答：不矛盾——「中間最熱」的板必有內部熱源（$\Delta u \ne 0$，Poisson 方程 $\Delta u = -f$）。調和函數是**無源**穩態：熱從邊界流入、一路均勻化，內部不積聚。最大值原理就是「無源則無內部極值」的數學表述。

**問：Weierstrass 的反例為什麼沒有殺死 Riemann 的定理？**
答：因為反例攻擊的是**方法**（「能量極小可達」的未經證明假設）而非**命題**（Dirichlet 問題在好區域上有解）。命題為真、方法有洞的局面上，正確策略是：保命題、換方法。Hilbert 直接法、Perron 方法、Fredholm 積分方程都是換法的成果。數學史反覆出現「定理比證明長壽」的現象，本例是最著名的之一。
