# 10.2 位勢論與流體力學

## 本章導言

複分析的物理大門：**二維理想流體、靜電場、穩態熱傳**都由調和函數（2.3 篂）治理，而**解析函數 = 調和函數對**（2.2 篂）——於是複變技術成為流場與場論的計算引擎。本節以兩大勝利為主角：**Joukowski 映射與機翼升力**（Kutta–Joukowski 定理——飛機為什麼飛）、以及**保角映射解位勢問題**的一般方法——並回顧 Helmholtz、Kelvin、Joukowski、Prandtl 的航空數學史。

### 複位勢：流場的複數封裝

**理想流體**（無黏、不可壓縮、無旋）的二維流動：速度場 $(u, v)$ 滿足

$$
\text{無源（不可壓）}： u_x + v_y = 0, \qquad \text{無旋}： v_x - u_y = 0.
$$

**這恰是 C–R 方程**（2.2 篂，d'Alembert 1752 的原始出場！）——對**複速度**

$$
w(z) = u - iv,
$$

**無源無旋 ⟺ $w(z)$ 解析**。其原函數

$$
F(z) = \phi + i\psi \quad(\text{複位勢})
$$

中：$\phi$ = **速度勢**（$u = \phi_x, v = \phi_y$）、$\psi$ = **流函數**（$\psi$ 的水平集 = 流線！$u = \psi_y, v = -\psi_x$）。**複位勢一把抓**：流線（$\psi = c$）、等勢線（$\phi = c$）——兩族正交（2.2 篂例題 (d) 的雙曲線族直觀），**複函數的實虛部水平集 = 流動的全息圖**。

**經典流場字典**：

| 複位勢 $F(z)$ | 流動 |
|---|---|
| $Uz$ | 均勻流（速度 $U$） |
| $\frac{m}{2\pi}\log z$ | **點源**（$m > 0$）/ 點匯（$m < 0$）——留數 = 源強！ |
| $\frac{\Gamma}{2\pi i}\log z$ | **點渦**——**留數 = 環量 $\Gamma$**（5.1 篂指紋的物理身份） |
| $\frac{\mu}{2\pi z}$ | 偶極子（源匯併合） |
| $Uz + \frac{\mu}{2\pi z}$ | **繞圓柱的流動**（$|z| = a$ 上 $\psi = 0$：圓是流線！） |

**疊加原理**：解析函數相加 = 流場疊加——**線性性（解析函數是向量空間）= 流體疊加法**。圓柱繞流 $F = U\left(z + \frac{a^2}{z}\right)$：**鏡像法**（圓柱的效應 = 在鏡像點放偶極子）——**位勢論的鏡像原理**（6.3 篂 Schwarz 鏡像的物理化身）。

### KUTTA–JOUKOWSKI：機翼升力的誕生

**Joukowski 映射**（1910 前後系統化）：

$$
\zeta = \frac12\left(z + \frac{a^2}{z}\right).
$$

性質：把過 $z = a$ 的圓映為**帶尖後緣的機翼剖面**（Joukowski 翼型）；$z = \pm a$ 處 $\zeta' = 0$（臨界點——**尖角由導數零點製造**，6.3 篂 SC 的角點機制）；外域保角映射到外域。

**繞翼型的流動**：圓柱繞流（易解）+ Joukowski 映射（保角）= 翼型繞流——**映射定理（6.2）的航空兌現**。

**Kutta 條件**（Kutta 1902）：流動必須**平滑離開尖後緣**（後緣速度有限）——這**唯一確定環量** $\Gamma$：圓柱繞流的環量參數由「後緣不撕裂」的物理條件鎖定。

**Kutta–Joukowski 定理**（Joukowski 1906）：

$$
\boxed{\;L = \rho U\Gamma\;}
$$

**升力 = 密度 × 來流速度 × 環量**。**證明思想**：Bromwich–Blaschou 定理——流體對物體的合力（壓力積分）由**複積分**給出：

$$
F_x - iF_y = \frac{i\rho}{2}\oint_C w(z)^2\,dz.
$$

繞翼型的 $w(z)^2$ 的**一階極點留數**由環量與來流決定：計算給 $L = \rho U\Gamma$——**留數定理算出升力**（5.1 篂！）。**「飛機能飛」的數學 = 一條複積分的留數**。

**歷史瞬間**：Wilbur Wright 1903 飛行、Kutta 1902 理論、Joukowski 1906 定理、Prandtl 1904 邊界層理論（黏性修復 d'Alembert 佯謬——理想流體預測零阻力！）、Lanchester 1907 翼尖渦。**理論與飛行在十年內互相追逐**——複分析直接參與了航空時代的第一步。今日 CFD（計算流體力學）的前身**面元法（panel method，Hess–Smith 1960s）**正是「分佈源匯 + 保角/位勢求解」——**波音、空客的初步氣動設計仍先跑位勢碼**。

### 保角映射解位勢問題：方法論

**流程**（6.2–6.3 篂的物理總裝）：

1. 把複雜域 $D$（電極、壩體、機翼外域）保角映射到**標準域**（半平面、條形、圓盤）。
2. 在標準域解 Laplace 方程（顯式：鏡像、分離變數、均勻場）。
3. 映射回原域；**物理量在映射下變換**：電場 $\sim |f'|^{-1}$、電容與**調和模數**不變（6.2 篂）。

**經典案例**：

- **平行板電容器邊緣**（條形域映射——6.3 篂例題）：邊緣場增強 $E \sim \frac{1}{\sqrt d}$ 型——**擊穿與尖端放電**的定量。
- **橢圓柱導體電容**（Joukowski 反用）：$C = \frac{2\pi\varepsilon}{\operatorname{arcosh}(a/b)}$ 型。
- **土壩滲流**（Polubarinova–Kochina 1940s）：浸潤線 = 自由邊界 = **SC 映射的未知參數**——自由邊界問題的複變解法。
- **微帶線特性阻抗**（6.3 篂場景四）：$Z_0 = \frac{60}{\sqrt{\varepsilon_r}}\ln\left(8\frac{h}{w} + 0.25\frac{w}{h}\right)$ 型公式的來源——**PCB 設計的每條走線**。

### 一個具體例題

**例題 10.2.1**：均勻流 $U$（沿實軸正向）繞半徑 $a$ 的圓柱，**帶環量 $\Gamma$**。(a) 寫複位勢並驗證圓柱面是流線；(b) 求圓柱面上的速度分布；(c) 用 Bernoulli 定律求壓力分布與合力（驗證 Kutta–Joukowski）；(d) 討論臨界環量 $\Gamma^* = 4\pi U a$。

**解**：

(a) 複位勢：

$$
F(z) = U\left(z + \frac{a^2}{z}\right) - \frac{i\Gamma}{2\pi}\log z.
$$

複速度 $w = F' = U\left(1 - \frac{a^2}{z^2}\right) - \frac{i\Gamma}{2\pi z}$。**圓柱面** $z = ae^{i\theta}$：

$$
w(ae^{i\theta}) = U(1 - e^{-2i\theta}) - \frac{i\Gamma}{2\pi a}e^{-i\theta} = e^{-i\theta}\left[2iU\sin\theta - \frac{i\Gamma}{2\pi a}\right] = i e^{-i\theta}\left(2U\sin\theta - \frac{\Gamma}{2\pi a}\right).
$$

**純虛係數 × 單位復向量**：速度沿切向——**圓面是流線** ✓（邊界條件滿足）。

(b) 切向速度（取實量）：$v_\theta(\theta) = 2U\sin\theta - \frac{\Gamma}{2\pi a}$（正負號依約定，量值正確）。**上表面**（$\theta = \frac\pi2$，若來流沿 $+x$、上側 $\sin\theta = 1$）：$v_\theta = 2U - \frac{\Gamma}{2\pi a}$；**下表面**（$\theta = -\frac\pi2$）：$-2U - \frac{\Gamma}{2\pi a}$（量值 $2U + \frac{\Gamma}{2\pi a}$ 取向後）。**環量使一側加速、另一側減速**——升力的機制。

(c) **Bernoulli**（無旋定常）：$p + \frac{\rho v^2}{2} = p_\infty + \frac{\rho U^2}{2}$。合力（積分壓力）：

$$
F_x - iF_y = -\oint_{|z|=a} p\,n\,ds \;\text{化為複積分}\; = \frac{i\rho}{2}\oint_C w^2 dz.
$$

計算 $w^2$ 在 $z = 0$ 的留數：$w = U - \frac{Ua^2}{z^2} - \frac{i\Gamma}{2\pi z}$，$w^2 = U^2 - \frac{2U^2a^2}{z^2} - \frac{iU\Gamma}{\pi z} + \cdots$，留數 $= -\frac{iU\Gamma}{\pi}$。故

$$
F_x - iF_y = \frac{i\rho}{2}\cdot 2\pi i\left(-\frac{iU\Gamma}{\pi}\right) = \frac{i\rho}{2}\cdot(-2U\Gamma) = -i\rho U\Gamma.
$$

**$F_x = 0$、$F_y = \rho U\Gamma$**——**升力豎直、量 $\rho U\Gamma$** ✓（Kutta–Joukowski）。阻力為零（**d'Alembert 佯謬**——理想流體的著名缺陷，Prandtl 1904 邊界層修復）。

(d) 駐點條件 $v_\theta = 0$：$\sin\theta = \frac{\Gamma}{4\pi Ua}$。若 $\frac{\Gamma}{4\pi Ua} \le 1$（$|\Gamma| \le 4\pi Ua$）：駐點在圓上（位置隨環量移動）；**若 $|\Gamma| > 4\pi Ua$**：$\sin\theta$ 無解——**駐點離開圓柱進入流場**，流動出現「封閉氣泡」型拓撲（臨界環量 $\Gamma^* = 4\pi Ua$ 是流場**拓撲相變**）。**翼型的實際 $\Gamma < \Gamma^*$ 恆成立**（Kutta 條件 + 失速限制）。

**方法論**：複位勢構造（疊加 + 邊界條件）→ 複速度（求導）→ 複積分合力（留數）——**本書第 2、3、5 章在一個流體問題中的全員出動**。

### 歷史啟示

- **數學結構 = 物理守恆**：C–R（無源無旋）、留數（源強/環量）、Green 函數（響應核）、共形映射（座標自由）——**複分析的每個抽象結構都有物理身分**。學複分析就是學「場的語法」。
- **佯謬是理論的邊界牌**：d'Alembert 佯謬（理想流體零阻力）不是錯誤而是**模型邊界**——Prandtl 用「黏性只在一薄層」修復它，邊界層理論誕生。**「理論正確 + 現實相反」的局勢 = 新理論的入口**。
- **升力定理的美學**：$L = \rho U\Gamma$——三個量的簡單乘積，背後是位勢論全副武裝。**物理定律的簡潔來自數學結構的深刻**。

1. 求複位勢 $F(z) = \frac{m}{2\pi}\log(z - z_0)$ 的速度場，並計算繞 $z_0$ 的圓上通量（驗證留數 = 源強）。
2. 構造「均勻流 + 點源」的複位勢，找出駐點並描述流場拓撲（Rankine 半體）。
3. 對繞圓柱無環量流（$\Gamma = 0$），計算圓柱面速度分布與壓力系數 $C_p = 1 - 4\sin^2\theta$，說明合力為零（d'Alembert 佯謬的直接計算）。
4. 用 Bromwich–Blaschou 公式計算「圓柱 + 環量 + 偶極修正」情形的合力，驗證 Kutta–Joukowski 的普適性（合力只依賴 $\Gamma$ 與 $U$）。

## 進階研讀：位勢論的五個深化場景

**場景一：面元法與現代 CFD**。物面分佈源匯 $\mu(s)$（積分方程 $\frac{\mu}{2} + \oint\frac{\mu(s')}{s - s'}$ 型——**Cauchy 型奇異積分方程**）→ 解線性系統 → 位勢流場。XFOIL（Drela 1989，MIT）——**翼型設計的標準工具**——正是「位勢 + 邊界層耦合」的傑作；空客與波音的概念設計階段仍以面元法先行。**5.1 篂留數 + 6.2 篂映射 = 每張機翼圖紙的幕後**。

**場景二：點渦動力學與湍流**。點渦系統 $\dot z_k = \sum_{j\ne k}\frac{\Gamma_j}{2\pi i}\frac{1}{\bar z_k - \bar z_j}$——**解析函數的動力系統**！Kirchhoff 1876、Onsager 1949（負溫度——渦對的統計力學）、二維湍流的 inverse cascade（Kraichnan 1967）。**「渦 = 複平面上的粒子」**：相變（渦對束縛–游離）在二維流體中真實可測。**9.2 篂橢圓函數**在環面點渦（雙週期邊界條件）中直接出場（vortex crystal——Tkachev、Aref 的平衡構形）。

**場景三：超流與量子化環量**。超流體（He-4，Landau 1941；Feynman 1955 渦旋理論）：環量**量子化** $\oint\vec v\cdot d\vec l = n\frac{h}{m}$——**波函數單值性（= 輻角單值性，1.3 篂）強制「留數離散」**：超流渦旋是「複相位的多值性 + 物理單值性」的實體化。渦晶格（Abrikosov 1957，第二類超導）的三角格——**超導磁鐵（MRI、磁懸浮列車）裡的「離散留數」**。

**場景四：自由邊界與可積性**。Hele–Shaw 流（黏性指進，Saffman–Taylor 1958）：界面演化 = **Loewner 型演化**（映射函數的方程——6.2 篂場景三 SLE 的流體前身！）、「雪晶生長」（晶體生長的複變模型，Caroli–Caroli）、Laplacian growth。**「生長 = 映射函數的動力學」**——6.3 篂 SC 的動態版；隨機版就是 SLE（2000s 菲爾茲級工作）。

**場景五：數論的「流體」視角**。**Kiselev–Peres 的 Euler 式證明**（1997）：素數定理的「複分析最小化」路線；**靜電 RH 路線**：$\zeta$ 的零點 = 某靜電問題的平衡位置（de Branges 的 Hilbert 空間路線、Connes 的非交換空間——把零點變成「譜的平衡態」）。**「勢論的極值原理（2.3 篂）能否證 RH」**是活躍的邊界研究——本書 2.3 篂的最大值原理與 8.3 篂的零點，在 RH 的攻城圖上相連。

### 深化問答三則

**問：為什麼二維流體「恰好」是複分析？**
答：二維無旋無源的兩個純量條件（$u_x + v_y = 0$、$v_x - u_y = 0$）**形式上就是 C–R**（虛部差一符號）——這是 d'Alembert 1752 的發現。三維沒有這種巧合（向量場比「解析」豐富）——**複分析 = 二維物理的母語**；這也解釋了為什麼複分析在十九世紀（電報、流體、地圖的時代）爆發。

**問：Kutta 條件「後緣平滑」為什麼能唯一確定環量？**
答：環量是**自由參數**（理想流體的解族），物理上由「黏性把流體帶到後緣、歷史（Kelvin 定理的起始渦）選定唯一環量」。**數學上**：尖後緣處若速度非零則無窮大（6.3 篂角點的速度行為），物理不允許——**「消除奇點」的數學條件 = 環量的選擇條件**。這是「數學奇點排除 → 物理參數鎖定」的美妙交換。

**問：留數定理在流體中的「物理意義」是什麼？**
答：閉路積分 $\oint w\,dz$ 的**實部 = 環量、虛部 = 通量**（3.1 篂）——留數同時編碼「旋轉的渦」與「吞吐的源」。**複積分對內部「奇點」敏感 = 流體對「渦與源」敏感**——複分析的「指紋」概念在流體中就是「探測旋渦」。留數定理 = 「用邊界測量讀出內部源」——這正是電磁學的 Ampère–Gauss 定律的結構。
