# 5.1 留數定理

## 本章導言

前三章的一切武裝（線積分的指紋、Cauchy 定理、Laurent 級數、奇點分類）在本節合體為複分析的「計算機器」：**留數定理**。閉路積分 = $2\pi i \times$（圈內奇點留數之和）。一條公式，把「繞圈」與「抽係數」焊接起來，使實積分、級數求和、根計數變成機械操作。本節建立定理、計算技術與第一輪應用；5.2 節進入實積分的臨床實戰。

### 留數的定義

設 $a$ 是 $f$ 的孤立奇點，Laurent 展開 $f(z) = \sum_{n=-\infty}^{\infty} a_n(z-a)^n$。**留數**定義為

$$
\operatorname{Res}_{z=a} f = a_{-1}.
$$

名稱來源（Cauchy 1826）：閉路積分「剩餘」（résidu）的部分——其他冪項積分歸零，只有 $a_{-1}$「留下來」：

$$
\oint_{|z-a|=r} f(z)\,dz = \sum_n a_n \oint (z-a)^n dz = a_{-1}\cdot 2\pi i.
$$

### 留數定理

**定理（Cauchy, 1826）**：設 $D$ 是由有限條簡單閉曲線圍成的區域，$f$ 在 $D$ 內除孤立奇點 $a_1, \ldots, a_m$ 外解析（在閉包上除這些點外解析），則

$$
\oint_{\partial D} f(z)\,dz = 2\pi i \sum_{k=1}^{m} \operatorname{Res}_{z=a_k} f.
$$

**證明**：以小圓 $C_k$ 分別圈住各奇點。在挖去小圓的區域上 $f$ 解析，由（同調形式的）Cauchy 定理，外圍道積分 = 各小圓積分之和（切割論證：3.2 節例題的推廣——「放射狀割線」的兩側往返抵消）。每個小圓積分 $= 2\pi i \operatorname{Res}_{a_k}$。∎

**定理的結構**：全域積分 **=** 局部資訊之和。Cauchy 定理是「零個奇點」的特例；3.3 篂積分公式是「單極點且 $f = \frac{g}{z - z_0}$、$\operatorname{Res} = g(z_0)$」的特例。留數定理是它們的統一：**所有複積分問題 = 奇點清單 + 各點留數**。

### 留數的計算技術

**技術一：單極點公式**。$a$ 為單極點（$f = \frac{g}{z-a}$，$g(a) \ne 0$）：

$$
\operatorname{Res}_{a} f = g(a) = \lim_{z\to a}(z-a)f(z).
$$

若 $f = \frac{p}{q}$、$q(a) = 0$、$q'(a) \ne 0$：$\operatorname{Res}_a \frac{p}{q} = \frac{p(a)}{q'(a)}$。

**技術二：高階極點公式**。$m$ 階極點：

$$
\operatorname{Res}_{a} f = \frac{1}{(m-1)!}\left.\frac{d^{m-1}}{dz^{m-1}}\left[(z-a)^m f(z)\right]\right|_{z=a}.
$$

（來源：乘 $(z-a)^m$ 消主部，求導 $m-1$ 次把 $a_{-1}$ 項推到常數位。）**實務建議**：$m = 2$ 時此公式好用；$m \ge 3$ 時直接展開 Laurent 級數常更快。

**技術三：級數展開**。本性奇點或複雜情形：直接寫出 Laurent 級數，讀 $a_{-1}$。例：$e^{1/z}$ 在 0：$a_{-1} = 1$（$\frac{1}{z}$ 項係數）。$\sin\frac{1}{z}$：$a_{-1} = 1$（$\frac1z$ 來自 $\sin w = w - \frac{w^3}{3!}+\cdots$ 的首項）。

**技術四：無窮遠的留數**。$\operatorname{Res}_\infty f := -\frac{1}{2\pi i}\oint_{|z|=R}f\,dz = -a_{-1}^{(\infty)}$（$f$ 在 $R < |z| < \infty$ 的 Laurent 展開中 $\frac1z$ 係數取負）。**全體留數和（含 $\infty$）恆為零**——檢算利器。

### 第一輪應用：閉路積分與級數求和

**應用一**：$\displaystyle\oint_{|z|=2} \frac{dz}{z^2(z-i)}$。奇點：$z = 0$（2 階）、$z = i$（單）。$\operatorname{Res}_i = \frac{1}{i^2} = -1$；$\operatorname{Res}_0 = \left.\frac{d}{dz}\frac{1}{z-i}\right|_{0} = -\frac{1}{(0-i)^2} = 1$。積分 $= 2\pi i(1 - 1) = 0$。**檢算**（無窮遠）：$f \sim \frac{1}{z^3}$ 在 $\infty$ 解析，$\operatorname{Res}_\infty = 0$ ✓（$0 + (-1) + 1 = 0$ ✓）。

**應用二（級數求和）**：$\displaystyle\sum_{n=1}^\infty \frac{1}{n^2 + a^2} = \frac{\pi}{2a}\coth(\pi a) - \frac{1}{2a^2}$（$a > 0$）。證明思想：積分 $f(z) = \frac{\pi\cot(\pi z)}{z^2 + a^2}$ 沿大方圈；$\cot(\pi z)$ 在每個整數有單極點、留數 $\frac{1}{\pi}$，故 $\pi\cot(\pi z)$ 留數為 1——**$\pi\cot\pi z$ 是「採樣器」**，在大方圈上積分 $\to 0$（被積函數 $\sim \frac{C}{z^3}$），圈內掃過的整數點留數相加 $= \sum \frac{1}{n^2+a^2}$，而極點 $z = \pm ia$ 的留數給出右端。這是 **Euler 求和技術的複變嚴格化**；Euler 1735 年以同一思想（含 $\zeta(2) = \frac{\pi^2}{6}$）震撼歐洲，但缺嚴格證明——留數定理補上了最後一塊。**函數 $\pi\cot\pi z$ 在現代傅立葉/譜理論中化身為「整數格點的 Green 函數」**，9.2 篂橢圓函數會把它一般化到雙週期。

### 一個具體例題

**例題 5.1.1**：計算 $\displaystyle\oint_{|z| = 3} \frac{e^z}{z(z+1)^2}\,dz$（逆時針），並用無窮遠留數檢算。

**解**：奇點在 $z = 0$（單極點）與 $z = -1$（2 階極點），均在 $|z| = 3$ 內。

$z = 0$：$\operatorname{Res} = \lim_{z\to0} z\cdot\frac{e^z}{z(z+1)^2} = \frac{e^0}{1} = 1$。

$z = -1$（$m = 2$）：$\operatorname{Res} = \left.\frac{d}{dz}\left[(z+1)^2\cdot\frac{e^z}{z(z+1)^2}\right]\right|_{z=-1} = \left.\frac{d}{dz}\frac{e^z}{z}\right|_{-1} = \left.\frac{e^z(z - 1)}{z^2}\right|_{-1} = \frac{e^{-1}(-2)}{1} = -2e^{-1}$。

積分 $= 2\pi i\left(1 - \dfrac{2}{e}\right) = 2\pi i \cdot \dfrac{e - 2}{e} \approx 2\pi i \times 0.2642 \approx 1.6602\,i$。

**檢算（無窮遠）**：$\frac{e^z}{z(z+1)^2}$ 在 $|z| > 3$ 展開。$\frac{1}{z(z+1)^2} = \frac{1}{z^3}\cdot\frac{1}{(1+1/z)^2} = \frac{1}{z^3}\left(1 - \frac{2}{z} + \frac{3}{z^2} - \cdots\right)$；乘 $e^z = 1 + z + \frac{z^2}{2} + \frac{z^3}{6} + \cdots$：

$$
f = \frac{1}{z^3} + \frac{1}{z^4} + \cdots \; \text{中 } \frac1z \text{ 的係數：需 } \frac{1}{z^3}\cdot e^z \text{ 產生 } \frac1z \Rightarrow e^z \text{ 的 } z^2 \text{ 項 } \frac12 \Rightarrow a_{-1}^{(\infty)} = \frac12 \cdot (-2) = -1.
$$

逐步：$\frac{1}{z^3}(1 - 2/z + 3/z^2 - \cdots)(1 + z + z^2/2 + z^3/6 + \cdots)$，$\frac1z$ 項 = $\frac{1}{z^3}\times\left[z^2 \text{ 係數}\right]$，$z^2$ 係數 $= 1\cdot\frac12 + (-2)\cdot 1 + 3\cdot 0 = -\frac32$；$\frac{1}{z^2}$ 修正：展開首項是 $\frac{1}{z^3}(1+1/z)^{-2}$？重算：$\frac{1}{z(z+1)^2} = \frac{1}{z^3(1 + 1/z)^2}$。$e^z\cdot\frac{1}{z^3}\sum_k \binom{-2}{k}(1/z)^k$。$\frac1z$ 係數 = $z^2$ 係數：$e^z$ 的 $z^{2+j}$ 乘 $\binom{-2}{j}z^{-j}$：$j=0$: $\frac12$；$j=1$: $1\times(-2) = -2$；$j\ge2$: $z^{2-j}$ 次 $\ge 0$ 不貢獻 $\frac1z$（需要 $2 - j = 0 \Rightarrow j = 2$：$\frac{1}{2}\times\binom{-2}{2} = \frac12\times 3 = 1.5$）。合計 $z^2$ 係數 $= \frac12 - 2 + \frac32 = 0$。故 $a_{-1}^{(\infty)} = 0$，$\operatorname{Res}_\infty = 0$。總和 $1 - 2/e + 0 \stackrel{?}{=} 0$——**不為零**！

**糾錯**：$\infty$ 留數公式要求 $f$ 在 $|z| > R$ 無窮遠**解析**且展開正確。重算 $j = 2$ 項：$\binom{-2}{2} = \frac{(-2)(-3)}{2} = 3$，貢獻 $\frac{z^2}{2}\cdot\frac{3}{z^2} = \frac32$。$j=3$：$z^3/6\cdot\binom{-2}{3}z^{-3}$，$\binom{-2}{3} = \frac{(-2)(-3)(-4)}{6} = -4$，$\frac{z^3}{6}\cdot\frac{-4}{z^3}\cdot z^{?}$——這是 $z^0$ 常數項，不貢獻 $\frac1z$ ✓。$z^2$ 係數 $= \frac12 - 2 + \frac32 = 0$。那 $\operatorname{Res}_0 + \operatorname{Res}_{-1} + \operatorname{Res}_\infty = 1 - 0.7358 + 0 = 0.2642 \ne 0$——**必有一處錯**。

**檢查 $\operatorname{Res}_\infty$ 的定義**：$\operatorname{Res}_\infty = -a_{-1}^{(\infty)}$ 其中 $a_{-1}^{(\infty)}$ 是 $f$ 在 $\infty$ 附近 $\frac1z$ 的係數。但更可靠：$\operatorname{Res}_\infty = -\operatorname{Res}_{w=0}\left[\frac{1}{w^2}f(1/w)\right]$。$f(1/w) = \frac{e^{1/w}}{(1/w)(1/w+1)^2} = \frac{w^2 e^{1/w}}{1 + 2w + w^2}\cdot\frac{1}{1/w}\cdot$……直接算：$\frac{1}{w^2}f(1/w) = \frac{1}{w^2}\cdot\frac{e^{1/w}}{(1/w)(1 + w)^2/w^2} = \frac{1}{w^2}\cdot\frac{w^3 e^{1/w}}{(1+w)^2} = \frac{w e^{1/w}}{(1+w)^2}$。在 $w=0$ 的展開：$w(1 + \frac1w + \frac{1}{2w^2} + \cdots)(1 - 2w + \cdots) = (1 + \frac{1}{2w} + \cdots)(1 - 2w + \cdots)$。$w^{-1}$ 係數 $= \frac12$，故 $\operatorname{Res}_\infty = -\frac12$。**先前展開錯在漏了指數的更深項**（$e^z$ 的 $z^3/6$ 乘 $(1+1/z)^{-2}$ 的 $z^{-1}$ 項：$\frac{z^3}{6}\cdot(-4)z^{-1}$——啊，這是 $z^2$ 項不是 $\frac1z$ 項；錯在 $(1+1/z)^{-2}$ 展開的 $j=1$ 項 $\binom{-2}{1} = -2$ 乘 $e^z$ 的 $z^1$ 項 1：貢獻 $-2/z^2$……）。

**正確總帳**：$\operatorname{Res}_\infty = -\frac12$，檢算：$1 + (-2/e) + \left(-\frac12\right) = \frac12 - \frac{2}{e} = \frac{e - 4}{2e}$？仍非零。**再查 $\operatorname{Res}_{-1}$**：$\left.\frac{d}{dz}\frac{e^z}{z}\right|_{-1} = \frac{e^{-1}(-1) - e^{-1}(1)}{(-1)^2}$（商法則：$\frac{e^z z - e^z}{z^2} = e^z\frac{z-1}{z^2}$，在 $z=-1$：$e^{-1}\cdot\frac{-2}{1} = -2e^{-1}$ ✓）。**再查 $\operatorname{Res}_0$**：$z f(z) = \frac{e^z}{(z+1)^2}$，在 0：$= e^0/1 = 1$ ✓。

**最終糾錯——$\operatorname{Res}_\infty$ 重新精算**：$\frac{1}{w^2}f(1/w)$：$f(1/w) = \frac{e^{1/w}}{\frac1w(\frac1w + 1)^2} = \frac{e^{1/w}}{\frac1w\cdot\frac{(1+w)^2}{w^2}} = \frac{w^3 e^{1/w}}{(1+w)^2}$。$\frac{1}{w^2}f(1/w) = \frac{w e^{1/w}}{(1+w)^2}$ ✓。$w e^{1/w} = w + 1 + \frac{1}{2w} + \frac{1}{6w^2} + \cdots$。$(1+w)^{-2} = 1 - 2w + 3w^2 - \cdots$。積：$\left(w + 1 + \frac{1}{2w} + \cdots\right)(1 - 2w + 3w^2 - \cdots)$。$w^{-1}$ 係數 $= \frac12$（只有 $\frac{1}{2w}\cdot 1$）。$\operatorname{Res}_\infty = -\frac12$。

**總帳**：$1 - \frac2e - \frac12 = \frac12 - \frac2e \approx -0.2358 \ne 0$。**矛盾未解——說明三個留數中必有一錯**。重新檢驗：$\oint_{|z|=3}$ 圈內奇點是 $0$ 與 $-1$。$\operatorname{Res}_\infty$ 對應大圓積分的負值，但**大圓必須不含其他結構**——沒有問題。那麼錯在何處？**檢查 $z=-1$ 是否真是 2 階極點**：$z(z+1)^2$——是。**檢查單極點 $z=0$ 的留數**：$f = \frac{e^z}{z(z+1)^2}$，$zf = \frac{e^z}{(z+1)^2}$，$z=0$：$\frac11 = 1$ ✓。

**用 $\infty$ 的行為重新思考**：$e^z$ 在 $\infty$ 是本性奇點！$f$ 在 $\infty$ 附近**不是 Laurent 展開收斂的情形**（$e^z = \sum z^n/n!$ 在 $|z|>R$ 不收斂為展開——它是冪級數而非 Laurent，形式上的「$\infty$ 處 Laurent 展開」需以 $f(1/w)$ 的 Laurent 展開定義，我們已做，$w e^{1/w}/(1+w)^2$ 的展開**在 $w=0$ 是本性奇點的展開，但它是形式 Laurent 級數且收斂**（$e^{1/w}$ 對 $w\neq0$ 收斂）✓。所以 $\operatorname{Res}_\infty = -\frac12$。

**真相**：**「全體留數和為零」要求函數在球面上只有限個奇點**——$e^z$ 型函數不滿足我們假設的「大圓外解析」！$f$ 在 $\mathbb{C}$ 上有奇點 $0, -1$，但 $\infty$ 是本性奇點——留數和公式仍應成立（$\infty$ 是孤立奇點）……**但 $e^z$ 在 $\infty$ 的「留數」定義依賴大圓積分的極限，而大圓積分 $\oint_{|z|=R}\frac{e^z}{z(z+1)^2}dz$ 當 $R$ 掃過奇點時不變（圍道變形），其值 $= -2\pi i(\operatorname{Res}_0 + \operatorname{Res}_{-1}) = -2\pi i(1 - 2/e)$，故 $\operatorname{Res}_\infty = -(1 - 2/e) = \frac2e - 1$。與 $\frac{1}{w^2}f(1/w)$ 展開的 $-\frac12$ 矛盾 ⇒ 展開必有誤**。

**再算 $w e^{1/w}/(1+w)^2$ 的 $w^{-1}$ 係數**：$w e^{1/w} = w\sum_k \frac{1}{k! w^k} = \sum_k \frac{w^{1-k}}{k!}$。$(1+w)^{-2} = \sum_j \binom{-2}{j}w^j = \sum_j (-1)^j(j+1)w^j$。$w^{-1}$ 係數：$1 - k + j = -1 \Rightarrow j = k - 2$。貢獻 $\sum_{k\ge2}\frac{1}{k!}(-1)^{k-2}(k-1) = \sum_{k\ge2}\frac{(-1)^k(k-1)}{k!}$。數值：$k=2$: $\frac{(+1)(1)}{2} = 0.5$；$k=3$: $\frac{(-1)(2)}{6} = -\frac13$；$k=4$: $\frac{(+1)(3)}{24} = \frac18$；$k=5$: $-\frac{4}{120} = -\frac1{30}$；……部分和：$0.5 - 0.333 + 0.125 - 0.033 + 0.0063 - \cdots$。求和 $S = \sum_{k\ge2}\frac{(-1)^k(k-1)}{k!} = \sum_{k\ge2}\frac{(-1)^k k}{k!} - \sum_{k\ge2}\frac{(-1)^k}{k!} = \sum_{k\ge1}\frac{(-1)^k}{(k-1)!} - (\cos(-1) + 1 - 1 + \frac{1}{2} - \frac{1}{6}\cdot(-1)^{?})$。仔細：$\sum_{k\ge0}\frac{(-1)^k}{k!} = e^{-1}$。$\sum_{k\ge2}\frac{(-1)^k}{k!} = e^{-1} - 1 + 1 = e^{-1}$。$\sum_{k\ge2}\frac{(-1)^k k}{k!} = \sum_{k\ge2}\frac{(-1)^k}{(k-1)!} = -\sum_{j\ge1}\frac{(-1)^j}{j!} = -(e^{-1} - 1) = 1 - e^{-1}$。故 $S = (1 - e^{-1}) - e^{-1} = 1 - \frac2e$。**$w^{-1}$ 係數 $= 1 - \frac2e$，故 $\operatorname{Res}_\infty = -(1 - \frac2e) = \frac2e - 1$** ✓✓——與圍道論證一致！先前手算展開截斷錯誤（漏高階項）。

**結論**：$\oint_{|z|=3}\frac{e^z}{z(z+1)^2}dz = 2\pi i\left(1 - \frac2e\right)$，且留數總帳 $1 - \frac2e + \left(\frac2e - 1\right) = 0$ ✓。**本例的「計算事故」正是教學價值所在**：留數檢算是強制紀律；「展開截斷」在無窮遠處必須以解析求和完成，不能憑前幾項目測。

### 歷史背景

留數概念由 Cauchy 在 1826–1829 年的一系列短文（《論無窮小量積分學中的各類留數》）中建立——**「留數」一詞與理論都是 Cauchy 命名與鑄造**。他立即展示威力：計算實積分、級數求和、方程根的計數。當時（1820s）「函數」概念尚混亂，Cauchy 的留數理論是第一個「以積分為本位」的函數論系統。1846 年他把圍道變形與同調觀念補全，1850s Riemann 幾何化，1870s Weierstrass 級數化——留數理論隨整個複分析一起成熟。**二十世紀的推廣**：多元留數（Leray 1959 的 Cauchy–Fantappiè 核）、代數幾何的殘差（residue）理論（Grothendieck 對偶），「留數」成為現代數學的普適概念——積分對局部的「線性回饋」。

### 歷史啟示

- **一個係數的專用機器**：留數定理本質上是「積分 = 提取 $a_{-1}$」的定理化。十九世紀最強的計算工具來自最不起眼的觀察（其他係數積分為零）。**理論工程 = 把一個巧合升格為系統**。
- **檢算文化**：無窮遠留數守恆是天然的自檢器。複雜計算中的錯誤（如本例的展開截斷）靠守恆律暴露——**數學計算需要會計學**。
- **從積分到抽取**：留數定理把「積分」變成「選係數」的離散操作。這種「連續 → 離散」的轉換（也見於 10.1 篂 Z 變換反演）是複分析改變數學風格的方式之一。

## 進階研讀：留數的五個深化場景

**場景一：圍道設計的藝術**。留數定理的威力在「圍道自由」：半圓圍道（有理 × 三角）、矩形圍道（$e^{-z^2}$ 的 Fresnel 積分）、扇形圍道（分支函數 $\sqrt z$）、鑰匙孔圍道（$\log$）、狗骨頭圍道（割線上的跳躍）。每一種圍道對應一類實積分；5.2 篂給出圖譜。設計原則：**圍道上的「不想要的邊」必須可估計為零或可用對稱消去**；割線上的跳躍恰是目標積分。

**場景二：矩量問題與 Stieltjes 積分**。留數法計算 $\int_{-\infty}^\infty \frac{p(x)}{q(x)}dx$ 型積分，其反問題——「由矩 $\int x^n d\mu$ 重構測度 $\mu$」——是 Padé 逼近與正交多項式的地盤（Gauss 求積的收斂、譜的 Stieltjes 表示）。圍道積分在反問題中出場：測度的 Cauchy 變換（Stieltjes 變換）$\int\frac{d\mu(t)}{z - t}$ 的割線跳躍就是測度密度——**「割線 = 譜，跳躍 = 密度」**是算子譜論（自伴算子譜表示）的複變語言。

**場景三：多重留數與 Grothendieck 對偶**。多複變的「留數」作用於 $n$ 個變數：$\operatorname{Res}\left[\frac{f(z)}{z_1\cdots z_n}\right]$ 型，全域版本是 Leray–Norguet 積分。代數幾何中，留數定理升格為**對偶性**（Serre 對偶、Grothendieck 殘差定理）：曲線上的留數和為零 ⇔ $H^1$ 的配對。**「局部貢獻之和 = 全域拓撲」**的原型——留數定理是 Atiyah–Singer 指標定理（1963）直系祖先之一（以 Ehresmann 陳類的圍道表示）。

**場景四：物理學的留數**。(1) **量子場論**：Feynman 傳播函數 $\frac{1}{p^2 - m^2 + i\varepsilon}$ 的極點留數 = 殘差譜；圍道選擇（Feynman 規則）即因果性。(2) **光學**：Sellmeier 方程的極點 = 吸收線；Kramers–Kronig（3.3 場景二）以留數閉合。(3) **共振**：散射振幅在複能量平面的極點 = 亞穩態壽命（$\tau = \hbar/|\operatorname{Im}E|$）——**複極點的虛部 = 衰減率**，物理常數由留數讀出。

**場景五：數值留數與奇點掃描**。現代數值複分析（Trefethen 譜方法、AAA 有理逼近）以「極點掃描」為核心：在圍道上採樣，用奇異值分解找函數的極點與留數，重建函數或解 Laplace/PDE 問題（2020 年代的「lightning Stokes solver」以指數收斂解帶角點域的位勢問題）。**留數從手算技術變成數值演算法的原子**——Cauchy 1826 年的發明仍在加速。

### 名詞速查表（本節出現的核心術語）

- **留數**：$\operatorname{Res}_a f = a_{-1}$，Laurent 係數。
- **留數定理**：$\oint_{\partial D} f\,dz = 2\pi i\sum\operatorname{Res}$。
- **單極點公式**：$\operatorname{Res} = \frac{p(a)}{q'(a)}$。
- **高階極點公式**：$\frac{1}{(m-1)!}\left[(z-a)^m f\right]^{(m-1)}(a)$。
- **無窮遠留數**：$\operatorname{Res}_\infty = -\operatorname{Res}_0\left[\frac{1}{w^2}f(1/w)\right]$；全體留數和為零。
- **採樣函數**：$\pi\cot\pi z$（整數格點留數 1），級數求和的引擎。
- **割線跳躍**：分支函數在割線兩側的差，狗骨頭圍道的收穫。

### 深化問答三則

**問：留數定理為什麼「只看 $a_{-1}$」就夠？**
答：因為閉路積分對 $(z-a)^n$ 的響應是 $\delta$ 型：$n = -1$ 給 $2\pi i$，其餘全零（3.1 節實驗）。積分算子在冪基下是「抽樣 $a_{-1}$」的投影。這是**對偶性**的最純形態：積分與「$\frac{1}{z-a}$ 係數」互為 Fredholm 對偶。其他係數的資訊（極點階數、主部）需要導數型積分（$\oint \frac{f}{(z-a)^{n+1}}$）——3.3 篂導數公式正是這些投影。

**問：留數定理與散度定理的類比到什麼程度？**
答：結構同型：全域積分 = 局部源之和。差別：散度定理的「源」是連續分布（$\nabla\cdot\vec F$ 的體積分），留數定理的「源」是離散奇點（有限個）。半純函數是「源集中於點」的場；調和函數是「無源」的場。兩個定理在 Green 函數語言下統一（2.3 場景四）：**Green 函數的奇點就是留數**。

**問：本節例題的「事故」暴露了什麼方法論？**
答：三點。(1) 守恆律（留數總和）是錯誤探測器——任何計算系統都應內建。(2) 無窮遠留數的「級數展開」法在 $\infty$ 為本性奇點時極易截斷出錯，應改用「$\operatorname{Res}_\infty = -\operatorname{Res}_0\left[\frac{f(1/w)}{w^2}\right]$ + 圍道論證」。(3) 手算與 CAS 交叉驗證是現代標準作業——本例的錯誤模式（前幾項目測）正是 CAS 能立刻暴露的。
