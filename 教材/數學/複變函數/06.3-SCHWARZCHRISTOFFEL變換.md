# 6.3 SCHWARZCHRISTOFFEL變換

## 本章導言

Riemann 映射定理保證存在，Schwarz–Christoffel 公式**兌現公式**：把上半平面映到任意多邊形內部的映射，其導數有顯式積分表達：

$$
f'(z) = C\prod_{k=1}^{n}(z - x_k)^{\alpha_k - 1}.
$$

內角 $\alpha_k\pi$ 直接寫進指數！這是 1867–1869 年 Schwarz 與 Christoffel 的發明，是「存在性定理變成計算工具」的典範，也是十九世紀以來電極設計、機翼理論（10.2）的核心技術。本節講述公式、證明思想、積分反演的困難，與現代數值實現。

### 公式的推導思想

目標：$f$ 把上半平面 $\operatorname{Im} z > 0$ 映到多邊形 $P$（內角 $\alpha_k\pi$，頂點對應實軸上的 $x_1 < x_2 < \cdots < x_n$）。

**關鍵觀察：導數的輻角**。$f$ 把實軸（被 $x_k$ 分段）映到多邊形邊（方向恆定）。在區間 $(x_k, x_{k+1})$ 上，像邊的方向是常數 ⇒ $\arg f'(x)$ 在該區間**恆定**；跨越 $x_k$ 時方向轉過 $(1 - \alpha_k)\pi$（外角）。所以 $\arg f'$ 是**階梯函數**——在 $x_k$ 處跳 $(1 - \alpha_k)\pi$。

什麼函數的輻角是階梯？**乘冪**：$(z - x_k)^{\alpha_k - 1}$ 的輻角在 $x_k$ 處跳 $(\alpha_k - 1)\pi = -(1-\alpha_k)\pi$（上半平面繞行時輻角增 $\pi$，乘 $(\alpha_k - 1)$ 次冪）——正是需要的跳變。乘積的輻角 = 各因子輻角之和 = 階梯總和。故

$$
f'(z) = C\,(z - x_1)^{\alpha_1 - 1}(z - x_2)^{\alpha_2 - 1}\cdots(z - x_n)^{\alpha_n - 1}, \qquad \sum_k (\alpha_k - 1)\pi = -2\pi \;\text{（外角和，含 } \infty \text{）}.
$$

積分即得 Schwarz–Christoffel 公式：

$$
f(z) = A + C\int^z \prod_{k=1}^{n}(\zeta - x_k)^{\alpha_k - 1}\,d\zeta.
$$

**內角和**：$n$ 邊形 $\sum\alpha_k\pi = (n-2)\pi$，但公式允許一個頂點放在 $\infty$（$\alpha_n$ 可「超額」），此時積分仍收斂（條件：$\sum\alpha_k = n - 2$ 或含 $\infty$ 頂點的相容條件）。

### 證明的嚴格化要點

推導只用了「輻角必須是階梯」，嚴格證明還需：

1. **$f'$ 在實軸上的行為**：$f$ 在 $x_k$ 附近的角度行為（$f(z) - w_k \sim (z - x_k)^{\alpha_k}$）——由解析延拓 + 邊界的單葉性。
2. **單葉性**：$\operatorname{Im} f' $ 的符號控制（對凸多邊形，$f'$ 的輻角在區間內恆定、模不變號 ⇒ 映射保持定向、單葉）。
3. **積分的收斂與分支**：$\alpha_k - 1 \in (-1, 1)$，積分在實軸附近的可積奇性（$\sim |z - x_k|^{\alpha_k - 1}$，$\alpha_k > 0$ 可積）。

**Schwarz（1867）與 Christoffel（1868/1870）的分工**：Christoffel 先在一般形式給出（研究測地線的論文中！）；Schwarz 以鏡像原理獨立發現並系統應用（圓弧多邊形、先驗誤差估計）。優先權近乎並列——Christoffel 命名於德語文獻、Schwarz 的應用使工具流行，今日合稱。

### 積木範例

**例一：半平面 → 條形域**。條形 $0 < \operatorname{Im} w < \pi$ 視為「二邊形」（兩頂點 $0, \infty$，內角 $\pi, 0$）。$x_1 = 0$（$\alpha_1 = 1$）、$x_2 = \infty$（$\alpha_2 = 0$）：

$$
f'(z) = C z^{0}(z - \infty)^{-1} \to f(z) = C\log z + A.
$$

$\log z$ 把上半平面映為條形（輻角 $(0, \pi)$ 即條形高度 $\pi$）✓——**SC 公式退化為對數**。

**例二：半平面 → 帶缺口的半平面**。頂點 $x_1 = -1$（$\alpha_1 = \frac12$，內角 $\frac\pi2$）、$x_2 = 1$（$\alpha_2 = \frac12$）：

$$
f'(z) = C(z+1)^{-1/2}(z-1)^{-1/2} = \frac{C}{\sqrt{z^2 - 1}} \quad\Rightarrow\quad f(z) = C\,\operatorname{arcosh} z + A.
$$

**arcosh 型積分**是 SC 的家常便飯——特殊函數（9 章的橢圓積分）正是 SC 積分的積分表。

**例三：半平面 → 正三角形**。$x_1 = 0, x_2 = 1, x_3 = \infty$、內角 $\frac\pi3$：

$$
f(z) = \int_0^z \zeta^{-2/3}(1-\zeta)^{-2/3}d\zeta = B\left(\frac13, \frac13\right)\text{-型積分}.
$$

邊長比由 $\int_0^1 t^{-2/3}(1-t)^{-2/3}dt = B(\frac13,\frac13) = \frac{\Gamma(1/3)^3}{\Gamma(2/3)}$ 決定——**SC 積分連接 Beta/Gamma 函數**（9.1 篂）。

### 一個具體例題

**例題 6.3.1**：用 SC 變換把上半平面映到「半無限條形」$P = \{0 < \operatorname{Im} w < h, \operatorname{Re} w > 0\}$（無限長的半條，三頂點：$0$（內角 $\frac\pi2$）、$ih$（內角 $\frac\pi2$）、$-\infty + ih\mathbb{?}$……）。

**正確建模**：$P$ 的頂點：$w = 0$（內角 $\frac\pi2$，$\alpha_1 = \frac12$）、$w = ih$（內角 $\frac\pi2$，$\alpha_2 = \frac12$）、$w = -\infty$（內角 $0$，$\alpha_3 = 0$，在 $\infty$）。實軸上取 $x_1 = 1$、$x_2 = -1$、$x_3 = \infty$：

$$
f'(z) = C(z - 1)^{-1/2}(z + 1)^{-1/2} = \frac{C}{\sqrt{z^2 - 1}}, \qquad f(z) = C\,\operatorname{arcosh} z + A.
$$

定分支與常數：$z = 1 \mapsto w = 0$：$\operatorname{arcosh} 1 = 0$，取 $A = 0$、$C = \frac{h}{\pi}\cdot$……驗證上緣：$z = it$（$t > 1$？在上半平面邊界 $z = x$ 與 $z = it$）——**用純虛檢驗**：$z = iy$（$0 < y < 1$，實軸上的「缺口邊」）：$\operatorname{arcosh}(iy) = i\arcsin y$，$f = iC\arcsin y$——**純虛**，即映到豎直邊 $[0, ih]$：$y: 0 \to 1$ 給 $w: 0 \to iC\cdot\frac\pi2$。要求 $ih$：$C\cdot\frac{\pi}{2} = h$，$C = \frac{2h}{\pi}$。

$$
f(z) = \frac{2h}{\pi}\operatorname{arcosh} z.
$$

**驗證其餘邊**：$z = x > 1$（實軸右段）：$f = \frac{2h}{\pi}\operatorname{arcosh} x$ 實正——**底邊** ✓。$z = x < -1$：$\operatorname{arcosh} x$ 主值 $= \operatorname{arcosh}(-|x|) \to i\pi - \operatorname{arcosh}|x|$ 型——像落在 $\operatorname{Im} w \approx h$ 的水平線：**上緣** ✓。三條邊各就各位。

**應用價值**：半條形域是**微帶線（microstrip）**與**槽縫電極**的標準模型——電容 $= \varepsilon \times \frac{\text{映射後的條形寬}}{\text{高}}$ 型公式直接讀出。SC 變換把「複雜電極的電場」化為「條形域的均勻場」。

### 數值實現：參數問題

SC 公式的困難：頂點 $x_k$（稱**參數**）預先未知——多邊形的**邊長**是積分

$$
L_k = |C|\int_{x_k}^{x_{k+1}}\prod_j |t - x_j|^{\alpha_j - 1}dt
$$

的結果，而邊長是**給定數據**。反解 $x_k$ 使邊長匹配 = **SC 參數問題**（nonlinear system）。

**歷史與現代**：

| 年代 | 進展 |
|------|------|
| 1867–70 | Schwarz、Christoffel 公式（手工積分時代） |
| 1975 | Trefethen 的 SC 軟體（數值參數問題，gauss–jacobian 迭代） |
| 1980s | Howell、Driscoll 的 SC Toolbox（MATLAB） |
| 2005+ |跨比法（cross-ratio）、 lightning 法（2020s，指數收斂的有理逼近） |

**Driscoll–Trefethen《Schwarz–Christoffel Mapping》（2002）**是標準參考：複雜多邊形（百頂點）的映射如今秒級計算，用於**電磁模擬、地下水滲流、空氣動力學預處理網格生成**。

### 歷史啟示

- **從存在到顯式**：Riemann 映射定理（1851）存在、SC（1867–70）給出多邊形的顯式積分——**理論的「兌現層」常比存在層更有工程價值**。
- **邊界的局部資訊決定全域**：SC 公式只吃「內角」就能拼出整個映射——多邊形的解析結構由離散資料（角度）編碼，連續資訊（邊長）由積分產生。**離散–連續的分工**在此域內極為乾淨。
- **參數問題的教訓**：顯式公式 ≠ 可計算。SC 的反演困難（參數問題）催生了整個數值共形映射領域——**公式與演算法之間有一個世紀的工程**。

## 練習

1. 用 SC 公式推導：把上半平面映到「帶有半無限切割的上半平面」的映射，並化簡為 $\sqrt{z^2 - 1}$ 型積分。
2. 求把上半平面映到矩形（寬 $2K$、高 $K'$）的 SC 映射，說明積分是第一類橢圓積分（9.2 篂預告）。
3. 對三角形映射（例三），計算邊長比 $\frac{B(1/3, 1/6)}{B(1/3, 1/3)}$ 型表達式並用 Gamma 函數化簡。
4. 證明：SC 映射在頂點附近 $f(z) - w_k \sim (z - x_k)^{\alpha_k}$——角度放大 $\frac{1}{\alpha_k}$ 倍，與 2.2 篂臨界點理論一致。
5. 思考題：為什麼 SC 參數問題「邊長匹配」是非線性的？說明自由度計數（$n$ 個 $x_k$ + 複常數 vs $n$ 個邊長 + 2 個定位）為什麼恰好平衡。

## 進階研讀：SC 的五個深化場景

**場景一：圓弧多邊形與 Schwarz 鏡像**。邊為圓弧的多邊形（如透鏡域）SC 推廣需要「反演型因子」；Schwarz 的**鏡像原理**（解析函數過解析弧的對稱延拓，7.1 篂正式化）把多邊形映射延拓到整個平面，得「自守函數」的雛形——**SC + 鏡像 = 自守函數論的前廳**（三角形群 $\triangle(2,3,7)$ 的映射給出 Klein 四元群與 1880 年代的單值化前史）。

**場景二：橢圓積分與模函數**。矩形域映射 $f(z) = \int_0^z\frac{dt}{\sqrt{(1-t^2)(1-k^2t^2)}}$：反函數是**Jacobi 橢圓函數** $\operatorname{sn}$（9.2 篂主角）。SC 變換是「從幾何（矩形）到函數（sn/cn/dn）」的出廠通道；模數 $k$ 的變化 = 矩形長寬比 = 模空間的座標。**SC 積分 → 橢圓函數 → 模形式 → 數論**的一條龍在此接通。

**場景三：lightning 法與指數收斂**。2020 年代（Trefethen、R orazek 等）：用**極點疊加的有理函數** $f'(z) \approx \sum_j \frac{c_j}{z - \zeta_j}$（$\zeta_j$ 指數逼近角落）逼近 SC 導數，誤差隨極點數**指數衰減**——角點的 $|z - x_k|^{\alpha_k - 1}$ 奇性被極點「吃掉」。這是「用函數的奇點地圖設計數值基」的哲學（5.1 篂場景五的延伸）：**知道奇點在哪，就把它放進基底**。

**場景四：物理工程的清單**。(1) **微帶線/共面波導**：SC 求特徵阻抗（工業標準工具）。(2) **壩體滲流**：土壩浸潤線 = SC 映射的自由邊界問題（Polubarinova–Kochina 1940s）。(3) **電子束/離子鏡**：靜電透鏡的場形。(4) **晶片散熱**：帶熱源的 L 型域溫度場。**「二維拉普拉斯 + 多邊形邊界」的問題，SC 全包**——這是十九世紀數學在當代晶片與 PCB 設計中的日常崗位。

**場景五：推廣與未竟**。(1) **Schwarz–Christoffel 的 Riemann 面版**：高虧格曲面的單值化與Abel 映射（9.2 篂）。(2) **隨機 SC**：Loewner 演化（SLE）的驅動函數取 Brown 運動時，映射域的邊界是隨機曲線——**SC 的「連續頂點極限」成為隨機過程**（6.2 篂場景三）。(3) **未竟問題**：任意 Jordan 域的高效保角映射（lightning 法接近解決）、反問題（由邊界電壓重構域形——Calderón 問題的複變近似）仍是活躍前沿。

### 深化問答三則

**問：SC 公式「只吃內角」為什麼夠？**
答：因為**解析函數由邊界的局部行為唯一決定**（Riemann 映射的唯一性 + 鏡像延拓）：內角決定 $f'$ 在每段邊上的輻角（階梯函數），模長資訊（邊長）不進入 $f'$ 的形式、只進入積分常數與參數位置。**輻角管形狀、模長管尺寸**——1.2 篂「模管分析、輻角管幾何」的又一次分工。

**問：SC 積分為什麼常常「積不出來」？**
答：$\int \prod(z - x_k)^{\alpha_k - 1}dz$ 是一般超橢圓積分：頂點 $\ge 4$ 時反函數不再是初等或經典單變數函數，而是**Abel 積分**（9.2 篂）——它們定義在 Riemann 面上，多值且需週期理論。「積不出來」不是計算技巧不足，而是**函數類的邊界**：SC 的反函數世界就是橢圓/Abel 函數的世界。

**問：數值 SC 的「lightning 法」為什麼快？**
答：它放棄「顯式積分表達」，直接用**與解同奇性結構的有理函數基底**：角點的 $(z - x_k)^{\alpha_k-1}$ 型奇性由聚攏在 $x_k$ 附近的極點模擬，誤差指數衰減。哲學：**數值方法的收斂率由「基函數能否表達真解的奇點」決定**——譜方法、SC、乃至 10.1 篂的濾波器設計，都是這一條原理。
