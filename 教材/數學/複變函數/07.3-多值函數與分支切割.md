# 7.3 多值函數與分支切割

## 本章導言

Riemann 面（7.2）給多值函數蓋了正確的房子；但日常計算需要**平地**——我們要在 $\mathbb{C}$ 上工作。**分支切割**（branch cut）是折衷方案：在平面上切一刀，限制行走的路徑，使多值函數在「殘缺的平面」上單值。本節系統化這門手藝：支點的辨認、切割的選擇、分支的標註、單值域的構造，以及 $\log$、$\sqrt{}$、$\arcsin$ 等經典函數的分支圖譜——並回顧這門技術從 Cauchy 到現代 CAS 的演變。

### 支點：多值性的「結」

**定義**：$a$ 是 $f$ 的**支點**（branch point），若沿繞 $a$ 的小圈延拓後，芽不回到原值。**階**：繞 $n$ 圈回到原值（$\sqrt z$：$n = 2$；$\log z$：$n = \infty$——**對數支點**）。

**辨認規則**：

| 函數 | 支點 | 原因 |
|------|------|------|
| $\sqrt z$ | $0, \infty$ | 輻角半值 |
| $\log z$ | $0, \infty$（對數型） | 輻角無界 |
| $z^\alpha$（$\alpha \notin \mathbb{Z}$） | $0, \infty$ | 同 $\sqrt z$ 型（$\alpha$ 分數）或 $\log$ 型（$\alpha$ 無理） |
| $\sqrt{z^2 - 1}$ | $\pm 1, \infty$ | 根的零點是支點 |
| $\log\frac{z-1}{z+1}$ | $\pm 1$ | 輻角差 |
| $\arcsin z$ | $\pm 1, \infty$ | $\frac{1}{\sqrt{1-z^2}}$ 的支點 |

**規則**：$\sqrt{p(z)}$ 的支點 = $p$ 的**奇數階零點**（+ 可能的 $\infty$）；$\log g(z)$ 的支點 = $g$ 的零點與極點。**「多值性藏單在根號與對號內的奇偶性裡」**。

### 切割與分支的構造

**程序**：

1. 找出全部支點 $S$。
2. 用連接支點的曲線（割線）把 $\mathbb{C}\setminus S$ 切成**單連通**域 $D$（每個支點的「繞行環路」被割斷）。
3. 在 $D$ 的某一點 $z_0$ 選定初值（**分支標註**），沿 $D$ 內路徑延拓（單值性定理 7.1 保證單值）。

**經典配置**：

- **$\log z$ 主值分支**：割線 = 負實軸；$D = \mathbb{C}\setminus(-\infty, 0]$；$\operatorname{Log} z = \log r + i\theta$，$\theta \in (-\pi, \pi)$。初值 $\operatorname{Log} 1 = 0$。
- **$\sqrt z$ 主值分支**：同割線；$\sqrt z = \sqrt r\, e^{i\theta/2}$，$\theta \in (-\pi, \pi)$。
- **$\sqrt{z^2 - 1}$**：割線連接 $-1$ 與 $1$（線段 $[-1, 1]$）；$D = \mathbb{C}\setminus[-1,1]$ 上單值（繞 $1$ 一圈：根號內相角變化 $2\pi$ → 開方換號；但割線使繞 $1$ 不可行……**需細心**：割線 $[-1,1]$ 使任何閉路繞 $1$ 時必同時繞 $-1$（可從割線外繞）——繞兩個支點一圈：兩處各換號，共換兩次 = 不換 ✓ 單值）。**「割線連接支點對」的原理：跨過割線 = 同時改變奇偶支點數，保持單值**。
- **$\operatorname{Log}\frac{z-1}{z+1}$**：支點 $\pm 1$；割線 $[-1, 1]$ 或兩條射線（$(-\infty, -1]$ 與 $[1, \infty)$）皆可——**切割的選擇不唯一**，不同選擇給「同族」分支（相差常數 $2\pi i$ 的倍數，對 $\log$ 型）。

### 分支跳躍與「切割線的物理」

跨過割線，分支值跳躍：

- $\operatorname{Log} z$：跳 $2\pi i$。
- $\sqrt z$：跳 $-2\sqrt z$（變號）。
- $\sqrt{z^2-1}$（割 $[-1,1]$）：跳 $2\sqrt{x^2 - 1}\,i$ 型（割線上取虛值）——**5.2 篂鑰匙孔圍道吃的正是這個跳躍**。

**跳躍 = Riemann 面的「葉間通道」的平面投影**：割線兩岸在 Riemann 面上是**黏合的**；在平面上被「剪開」。**切割是 Riemann 面的省略號**——工程便利，理論上要記得「割線兩岸本是一家」。

### 一個具體例題

**例題 7.3.1**：對 $f(z) = \sqrt{z^2 - 1}$：(a) 確定支點並構造割線使上半平面 $+ |z| > 1$ 型域上單值；(b) 在割線 $[-1, 1]$ 配置下，求 $f(i)$（$z = i$）與 $f(2i)$ 的值（取「$z > 1$ 處 $f = +\sqrt{x^2-1}$」的分支）；(c) 計算割線上的跳躍；(d) 說明為什麼「割兩條射線（$(-\infty,-1]$ 與 $[1, \infty)$）」也合法，並比較兩種配置下 $f(0)$ 的值。

**解**：

(a) 支點：$z = \pm 1$（$z^2 - 1$ 的單零點）與 $z = \infty$（$f \sim z$，繞 $\infty$：$z \to ze^{2\pi i}$，$f \to -f$ ✓）。割線 $[-1, 1]$ 連接 $\pm1$：域 $D = \mathbb{C}\setminus[-1,1]$。單值性：$D$ 內閉路要麼不繞支點、要麼同時繞 $\pm1$（奇偶性守恆）→ 根號內的相角變化是 $4\pi$ 的倍數 → 開方不變號 ✓。

(b) 分支標註：$x > 1$ 取 $f = +\sqrt{x^2 - 1}$（正實）。$z = i$：$z^2 - 1 = -2$；$z = i$ 從 $z > 1$ 出發沿上半平面繞行至 $i$：輻角 $z^2 - 1$ 從 $0$（在 $x > 1$）連續增至 $i$ 處 $= \pi$（路徑 $z^2 - 1$ 從正實軸轉上半圈到負實軸）。故 $f(i) = \sqrt 2\, e^{i\pi/2} = i\sqrt 2$。$z = 2i$：$z^2 - 1 = -5$，路徑輻角仍 $\pi$：$f(2i) = i\sqrt 5$。**核對**：$f^2 = z^2 - 1$：$(i\sqrt2)^2 = -2$ ✓、$(i\sqrt5)^2 = -5$ ✓。

(c) 割線 $x \in (-1, 1)$：上岸 $z = x + i0^+$，$z^2 - 1 = x^2 - 1 + 2x i 0^+ = -(1 - x^2) + i\,0^+$：輻角 $\to \pi$，$f_+ = i\sqrt{1 - x^2}$；下岸：輻角 $\to -\pi$，$f_- = -i\sqrt{1 - x^2}$。**跳躍 $= 2i\sqrt{1 - x^2}$**——正是 5.2 篂計算 $\int_{-1}^1 \frac{dx}{(x^2+1)\sqrt{1-x^2}}$ 型積分時鑰匙孔/犬骨圍道收割的資產。

(d) 割兩條射線 $(-\infty, -1] \cup [1, \infty)$：域 = 去掉兩射線的平面（仍單連通？**不是單連通**——它是含 $[-1,1]$ 橋的「啞鈴補」……實際上 $\mathbb{C} \setminus \big((-\infty,-1] \cup [1,\infty)\big) = \mathbb{C} \setminus$ 兩射線，任何閉路繞 $1$ 一圈會跨 $[1, \infty)$ 割線被禁，繞 $\pm1$ 各一圈也不可行（中間橋 $[-1,1]$ 沒割）——繞「啞鈴」整體一圈：兩支點各換一次號 → 淨不換 ✓。單值性成立但域**多連通**（含一個「啞鈴洞」）。本配置下 $z = 0$：$z^2 - 1 = -1$，路徑（在域內從 $x > 1$ 繞到 0——需跨中間橋區，輻角 $z^2 - 1$ 變化 $\pi$）$f(0) = i$。**與 (b) 配置同值**（兩配置的分支在共同域上相差常數且初值條件相同時一致）。**教訓**：切割方式不唯一；分支的「身分」由初值標註決定，不由割線決定。

### 歷史背景：從 Cauchy 的習慣到 CAS 的規範

- **Cauchy（1820s–40s）**：以「主值」（valeur principale）一詞處理 $\log$ 與多值積分——主值概念（3.3 篂 p.v. 積分同一人發明）是分支思想的萌芽。
- **Riemann（1851）**：多值的幾何解決（Riemann 面）；切割被視為「曲面的平面圖」。
- **Weierstrass（1840s+）**：芽與延拓——多值的代數解決；「分支」成為芽系統的葉。
- **二十世紀教材**（Ahlfors 1953、Conway 等）：「分支切割」成為標準教學語言；約定俗成的主值配置（$\operatorname{Log}$ 割負軸）由 CAS（MATLAB、NumPy、Mathematica）**程式化**——`np.log` 的返回值就是主值分支。**十九世紀的約定成為二十一世紀的 API 行為**。

**教學要點**：CAS 的分支選擇（割負實軸）與物理慣例（時間諧波 $e^{-i\omega t}$ 選割負軸保因果）多數一致，但**複變函數庫之間有細微差異**（$\sqrt{z^2-1}$ 的分支在高級應用中出過著名的庫間 bug）——工程上「先查分支約定文檔」是紀律。

### 歷史啟示

- **約定即接口**：分支選擇是「數學接口規範」——初值 + 割線完全確定行為。現代軟體的 API 設計（參數、預設值、文檔）在數學中的原型就是「分支標註」。
- **偷懶的代價與收益**：切割域是 Riemann 面的投影，方便計算但丟失全域性（割線附近的跳躍要手動處理）。**何時該上 Riemann 面、何時平面夠用**是複分析的實踐判斷：積分計算用切割（5.2）、結構理解用曲面（7.2、9.2）。
- **多值性是資源**：跳躍編碼資訊（割線跳躍 = 譜密度、= 極化強度）——5.2 篂的鑰匙孔圍道、10.2 篂的翼型環量，都是「把多值性變成測量值」。

## 練習

1. 對 $\operatorname{Log} z$（主值，割負軸）：計算 $\operatorname{Log}(-i)$、$\operatorname{Log}(1+i)$，並驗證 $\operatorname{Log}(z_1 z_2) \ne \operatorname{Log} z_1 + \operatorname{Log} z_2$ 的具體反例。
2. 確定 $f(z) = \sqrt[3]{z^2(z-1)}$ 的支點與階，設計割線使全域（去割線）單值，並計算 $f(2)$（標註 $z = \frac12$ 處 $f$ 為正實）。
3. 計算 $\sqrt{z^2-1}$ 在割線 $[-1,1]$ 下於 $z = -2$ 的值（沿上半平面延拓 vs 沿下半平面延拓，比較）。
4. 證明：割線 $[-1, 1]$ 的域 $D = \mathbb{C}\setminus[-1,1]$ 上，$\sqrt{z^2 - 1}$ 的兩個分支都存在，且互為負。
5. 思考題：$\log(z^2 - 1)$ 的支點是 $\pm1$（對數型）與 $\infty$；它與 $\operatorname{Log}(z-1) + \operatorname{Log}(z+1)$ 差 $2\pi i$ 的多少倍？設計一個「繞圈實驗」揭示兩者的 monodromy 差異。

## 進階研讀：分支技術的五個深化場景

**場景一：單值域與極座標**。割負軸的域 = 「$(r, \theta)$，$r > 0$、$-\pi < \theta < \pi$」的極座標全域——**切割域 = 極座標的單值圖冊**。更多切割（對 $\arcsin$ 割 $(-\infty,-1]\cup[1,\infty)$）= 更多「角度資源的分配」。**分支切割的本質是「把輻角從 $\mathbb{R}/2\pi\mathbb{Z}$ 提升為 $\mathbb{R}$」的座標工程**。

**場景二：割線跳躍 = 譜測度**。Stieltjes 變換 $G(z) = \int\frac{d\mu(t)}{z - t}$ 割線 = 譜支集，跳躍 $G_+ - G_- = -2\pi i \mu'$——**測度密度由割線跳躍讀出**（5.1 篂場景二）。隨機矩陣理論的 Wigner 半圓律、無序系統的態密度，全靠「複化函數 + 割線跳躍」技術。**分支切割是譜論的顯微鏡**。

**場景三：Wick 旋轉與因果性**。Minkowski 積分 $\int e^{iEt}f(E)dE$ 的收斂需要 $E$ 平面的分支配置（Feynman $i\varepsilon$：極點 $E \pm i\varepsilon$ 移位）。**Wick 旋轉 $t \to -i\tau$** 把振盪變衰減、把實時量子力學變虛時統計力學——分支切割與圍道旋轉（5.2 篂 Fresnel 技術）在 QFT 中的合體。**「旋轉 + 切割」是量子場論的座標系操作**。

**場景四：Lambert W 與分支樹**。$W e^W = z$ 的反函數 $W(z)$ 有**無窮多分支** $W_0, W_{-1}, W_1, \ldots$（支點 $z = -1/e$ 二階）。應用：電路方程 $I = \frac{V}{R}e^{...}$ 的解析解、延遲微分方程、組合學（Cayley 樹的母函數）。**現代 CAS（Mathematica `ProductLog`）管理整棵分支樹**——多值函數論在符號計算中的直接實現。

**場景五：分支與電腦圖形學**。像素著色中的複函數視覺化（domain coloring）必須處理分支：色相輻角天然是 $\mathbb{R}/2\pi\mathbb{Z}$ 的；「分支感知的 coloring」以割線為色相跳變線。**1.2 篂場景四的染色圖在此成熟**：可視化本身就是分支管理的實訓場。

### 名詞速查表（本節出現的核心術語）

- **支點**：繞行改變芽的奇點；階 = 回原值所需圈數。
- **分支切割**：連接支點的割線；使域單值化。
- **主值分支**：標準約定分支（$\operatorname{Log}$、$\sqrt{\ }$ 割負軸）。
- **分支跳躍**：跨割線的值差；= Riemann 面葉間通道的投影。
- **單值域**：切割後的多連通/單連通工作域。
- **Stieltjes 變換**：$\int\frac{d\mu}{z-t}$；割線 = 譜。
- **Lambert W**：$We^W = z$ 的無窮分支反函數。
- **Wick 旋轉**：實時間 ↔ 虛時間的圍道操作。

### 深化問答三則

**問：割線「割在哪裡」真的無所謂嗎？**
答：對「函數的存在性」無所謂（任何合法切割都給單值分支）；對「計算的方便性」與「物理的因果性」大有關係。$\operatorname{Log}$ 割負軸使 $\arg \in (-\pi, \pi)$ 對稱、適合濾波器（10.1 篂最小相位）；割正軸適合 Stieltjes 變換（譜在正軸）。**切割 = 針對問題的座標剪裁**。

**問：為什麼 $\sqrt{z^2-1}$ 割 $[-1,1]$ 一條就夠，而 $\log\frac{z-1}{z+1}$ 也割同樣一條？**
答：兩者的支點集都是 $\{\pm1\}$（$+\infty$），但 monodromy 結構不同：$\sqrt{z^2-1}$ 繞單個支點換號、繞兩個不換——割線使「單支點環路」非法即可；$\log\frac{z-1}{z+1}$ 繞 $1$ 增 $2\pi i$、繞 $-1$ 減 $2\pi i$——同樣需要禁單支點環路。**同一割線服務不同 monodromy**——割線的標準是「斷掉所有單支點環路」，這只依賴支點集、不依賴 monodromy 細節（後者由分支標註與值計算承擔）。

**問：「分支」與「函數」的哲學關係？**
答：Riemann 面上只有一個函數；平面上有「多個分支」。分支是函數的**平面投影**，如同多面體的不同投影圖。工程用投影（單值、可計算），理論用本體（單一的曲面函數）。本書 7.2/7.3 兩節的先後順序（先曲面後切割）正是「先本體後投影」的教學選擇——與歷史順序（Riemann 1851 在前、切割教材化在後）一致。

### 補充：分支計算的「標準作業程序」

涉及多值函數的圍道積分（5.2 篂）與極限計算，建議嚴格執行以下五步，避免本節例題示範過的各類陷阱：

1. **報分支**：明確寫出「割線位置 + 標註點取值」（如「割 $[-1,1]$、$x > 1$ 取 $+\sqrt{x^2-1}$」）——沒有標註的 $\sqrt{\ }$ 與 $\log$ 是無意義符號。
2. **畫支點圖**：標出全部支點（含 $\infty$）與割線；檢查工作圍道是否與割線相交。
3. **算跳躍**：割線兩岸的分支差（如 $2i\sqrt{1-x^2}$）——這是鑰匙孔圍道的「收穫量」，預先算出可避免符號事故。
4. **追路徑**：被積函數沿圍道走時，**連續追蹤輻角**（不回到主值！），特別是繞支點半圈的段落（5.2 篂 Fresnel/鑰匙孔例題的關鍵步驟）。
5. **守恆檢查**：可用「共軛對稱」「$x \mapsto 1/x$ 對稱」「特殊值代入」做獨立驗證——多值計算的錯誤率是單值計算的數倍，**檢算不是美德而是必需**。

**與 CAS 的分工**：Mathematica/NumPy 的分支約定（割負軸主值）應先查文檔再使用；把 CAS 值當作「主值分支的值」而非「函數的值」——語義錯位是數值事故的最大來源。
