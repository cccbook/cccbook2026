# 9.3 貝塞爾函數的複變觀點

## 本章導言

圓柱的振動、鼓膜的振動、波的繞射、行星的軌道擾動——凡是「圓柱對稱」的波動與位勢問題，都會遇到 **Bessel 方程**

$$
z^2 w'' + z w' + (z^2 - \nu^2)w = 0
$$

與它的解 **Bessel 函數** $J_\nu, Y_\nu$。Daniel Bernoulli 1732（單擺鏈）、Euler、Fourier 1822（熱傳導）、**Bessel 1824**（行星擾動——函數以他命名）先後觸及；**Frobenius 1873** 的正則奇點理論（5.3 篂場景三）給出系統解法。本節以複變觀點（級數、複積分表示、漸近、生成函數）全面解剖 Bessel 函數——特殊函數論的「第二課」。

### Frobenius 方法：正則奇點的解

$z = 0$ 是 Bessel 方程的**正則奇點**（5.3 篂）：$p(z) = \frac1z$（一階極點）、$q(z) = 1 - \frac{\nu^2}{z^2}$（二階極點）——可控爆發。**Frobenius 嘗試** $w = z^r\sum_{n\ge0}a_n z^n$（$a_0 \ne 0$），代入方程：

$$
\sum_n a_n\left[(n + r)^2 - \nu^2\right]z^{n + r} + \sum_{n\ge1}a_n z^{n + r} = 0.
$$

**指標方程**（最低次項）：$r^2 = \nu^2$，$r = \pm\nu$。取 $r = \nu$，遞推：

$$
a_n = -\frac{a_{n-1}}{(n + \nu)^2 - \nu^2} = -\frac{a_{n-1}}{n(n + 2\nu)} \;\Rightarrow\; a_n = \frac{(-1)^n}{n!\,(1 + \nu)(2 + \nu)\cdots(n + \nu)}a_0.
$$

規範化 $a_0 = \frac{1}{2^\nu\Gamma(\nu + 1)}$（使 $J_\nu \to \frac{(z/2)^\nu}{\Gamma(\nu+1)}$ 當 $z\to0$）：

$$
\boxed{\;J_\nu(z) = \sum_{n=0}^{\infty}\frac{(-1)^n}{n!\,\Gamma(n + \nu + 1)}\left(\frac z2\right)^{2n + \nu}\;}
$$

**複變的角色**：係數中的 $\Gamma(n + \nu + 1)$ 使 $\nu$ **複數化**——Bessel 函數是「$\nu$ 的半純函數、$z$ 的整函數（$\nu$ 非整數時）」。**$\Gamma$ 函數（9.1 篂）在這裡上崗**：Bessel 級數是「Gamma 編碼的冪級數」。

**第二解**：$\nu \notin \mathbb{Z}$ 時 $J_{-\nu}$ 獨立（線性無關）；$\nu \in \mathbb{Z}$ 時 $J_{-n} = (-1)^n J_n$（**相關**！指標方程根差整數的退化），需要**第二種解**：

$$
Y_\nu(z) = \frac{J_\nu(z)\cos\pi\nu - J_{-\nu}(z)}{\sin\pi\nu} \;\xrightarrow{\nu \to n}\; \text{（極限給出第二類）}.
$$

**$Y_n$ 在 0 有對數奇點**（$Y_n \sim -\frac{(n-1)!}{\pi}(\frac z2)^{-n} + \cdots + \frac{2}{\pi}\log\frac z2\,J_n$）——**Wronskian** $W(J_\nu, Y_\nu) = \frac{2}{\pi z}$ 驗證線性無關。**「根差整數 → 對數項第二解」**是正則奇點理論的一般模式（超幾何、Legendre 全同此病）。

### 複積分表示與生成函數

**生成函數（Schläfli 1857 / Bessel 型）**：

$$
e^{\frac z2\left(t - \frac1t\right)} = \sum_{n=-\infty}^{\infty}J_n(z)\,t^n.
$$

**驗證**：展開指數 $e^{\frac z2 t}\cdot e^{-\frac{z}{2t}} = \sum_m \frac{(z/2)^m t^m}{m!}\sum_k \frac{(-z/2)^k t^{-k}}{k!}$；$t^n$ 項（$m - k = n$）：$\sum_k \frac{(-1)^k (z/2)^{2k+n}}{k!(k+n)!} = J_n(z)$ ✓。**生成函數是「Laurent 級數的係數定義」**——$J_n(z)$ 是複指數的 Laurent 係數（4.2 篂技術的直接應用）。

**圍道表示**：由 Laurent 係數公式（4.2 篂）：

$$
J_n(z) = \frac{1}{2\pi i}\oint_{|t|=1}\frac{e^{\frac z2(t - 1/t)}}{t^{n+1}}\,dt \;\xrightarrow{\;t = e^{i\theta}\;}\; \frac{1}{\pi}\int_0^\pi\cos(n\theta - z\sin\theta)\,d\theta.
$$

**Bessel 1824 的原始積分**（行星擾動的 Kepler 方程展開）——**複積分表示使 $J_n$ 的對稱性（$J_{-n} = (-1)^n J_n$）、估計、漸近全部可讀**。**Hankel 表示**（全平面版，9.1 篂技術）：

$$
J_\nu(z) = \frac{(z/2)^\nu}{2\pi i\,\Gamma(\nu + \frac12)\Gamma(\frac12)}\int_{\text{围道}} e^{it}(1 - t^2)^{\nu - \frac12}dt\ \text{型}
$$

——**特殊函數論的通用格式**：級數（局部）、積分（全域）、方程（結構）、生成函數（離散）、漸近（極限）——五張面孔像 $\Gamma$ 一樣配套（9.1 篂）。

### 漸近與零點

**大 $z$ 漸近**（$z$ 複變、$|\arg z| < \pi$）：

$$
J_\nu(z) \sim \sqrt{\frac{2}{\pi z}}\cos\left(z - \frac{\pi\nu}{2} - \frac\pi4\right), \qquad
Y_\nu(z) \sim \sqrt{\frac{2}{\pi z}}\sin\left(z - \frac{\pi\nu}{2} - \frac\pi4\right).
$$

**證明思想**：由圍道表示換元 $t = e^s$、指數 $\frac z2(e^s - e^{-s}) = z\sinh s$，鞍點在 $s = \pm\frac{\pi}{2}i$（**最陡下降法**，5.2 篂場景一）——**振盪漸近 = 復鞍點的貢獻**；虛部方向決定衰減（$K_\nu$ 函數 $J_\nu(i z)$ 型：$K_\nu \sim \sqrt{\frac{\pi}{2z}}e^{-z}$——**「振盪與衰減 = 同一函數旋轉 $90^\circ$」**，1.3 篂「虛指數 = 旋轉」的函數論兌現）。

**零點**：$J_n$ 有無窮多實零點（漸近 $\cos$ 的零點位置：$j_{n,k} \sim \left(k + \frac{n}{2} - \frac14\right)\pi$）——**鼓膜的本徵頻率**（半徑 $a$ 的圓膜：$\omega_{nk} = \frac{j_{n,k}}{a}c$）。**複變視角**：零點分布 = Sturm 型定理 + 漸近展開的零點追蹤；**Rayleigh 1872 的鼓膜譜**、**Chladni 圖（1787 實驗）**的數學本體就是 $J_n$ 的零點格。

### 一個具體例題

**例題 9.3.1**：(a) 用生成函數證明遞推式 $J_{n-1}(z) + J_{n+1}(z) = \frac{2n}{z}J_n(z)$；(b) 用漸近估計 $J_0(10)$；(c) 計算積分 $\int_0^\infty e^{-at}J_0(bt)\,dt = \frac{1}{\sqrt{a^2 + b^2}}$（$a > 0$）——Laplace 變換表的核心公式。

**解**：

(a) 對生成函數 $\sum J_n t^n = e^{\frac z2(t - 1/t)}$ 兩邊對 $t$ 求導：

$$
\sum n J_n t^{n-1} = \frac z2\left(1 + \frac{1}{t^2}\right)\sum J_n t^n.
$$

比較 $t^{n-1}$ 係數：$nJ_n = \frac z2 J_n + \frac z2 J_{n-2}$？——**小心**：$\frac z2\frac{1}{t^2}\cdot J_{n-3}t^{n-3}$ 給 $t^{n-1}$ 項是 $\frac z2 J_{n-3}$……重做：$\frac z2\sum J_k t^{k-2}$ 的 $t^{n-1}$ 係數 = $\frac z2 J_{n+1}$（$k - 2 = n - 1 \Rightarrow k = n+1$）。故 $n J_n = \frac z2(J_n + J_{n+1})$？$\frac z2\sum J_k t^k$ 的 $t^{n-1}$ 系數 = $\frac z2 J_{n-1}$。總：$nJ_n = \frac z2 J_{n-1} + \frac z2 J_{n+1}$，即

$$
J_{n-1} + J_{n+1} = \frac{2n}{z}J_n \;✓.
$$

**方法論**：生成函數把遞推式變成「係數比較」——離散關係的機械化（母函數法，4.1 篂場景二）。

(b) $J_0(10) \approx \sqrt{\frac{2}{10\pi}}\cos\left(10 - \frac\pi4\right) = 0.2523\cos(10 - 0.7854) = 0.2523\cos(9.2146)$。$9.2146 \,\mathrm{rad} = 9.2146 - 2\pi = 2.9314$ rad，$\cos(2.9314) \approx -0.978$。故 $J_0(10) \approx -0.2468$。**真值 $J_0(10) = -0.2459$**——誤差 $0.4\%$（首項漸近，10 附近已可用；下一階修正 $O(1/z^2)$ 約 $1\%$ 內）。

(c) 用積分表示 $J_0(bt) = \frac{1}{\pi}\int_0^\pi\cos(bt\sin\theta)d\theta$：

$$
\int_0^\infty e^{-at}\cos(bt\sin\theta)dt = \frac{a}{a^2 + b^2\sin^2\theta}.
$$

故目標積分 $= \frac{1}{\pi}\int_0^\pi\frac{a\,d\theta}{a^2 + b^2\sin^2\theta} = \frac{1}{\pi}\cdot\frac{\pi}{\sqrt{a^2(a^2+b^2)}}\cdot a = \frac{1}{\sqrt{a^2+b^2}}$（內層積分用 5.2 篂標準公式 $\int_0^\pi\frac{d\theta}{a^2 + b^2\sin^2\theta} = \frac{\pi}{a\sqrt{a^2+b^2}}$）。**驗證**（$b = 0$）：$\frac1a$ ✓（$\int e^{-at}dt$）。**這條公式是波動傳播（Hankel 變換）與阻尼振子響應的橋**——工程表格的第一行。

### 歷史啟示

- **方程、級數、積分、漸近的四位一體**：Bessel 函數像 $\Gamma$ 一樣擁有多副面孔，**每副面孔回答一類問題**（方程管對稱性、級數管局部、積分管全域、漸近管極限）——特殊函數論的「多表示原則」。
- **物理先行**：振動（膜、柱、球）→ Sturm–Liouville → 特殊函數——**數學物理是特殊函數的母體**；純數學（Frobenius 理論、複漸近）後到而系統化。
- **圓柱對稱的普遍性**：從鼓膜到光纖（Bessel 光束，1987 實現的無繞射光）、到 MRI 的 Fourier–Bessel 重建——**圓柱座標系的「正弦」就是 $J_n$**。

2. 用生成函數證明 $\sum_{n=-\infty}^\infty J_n^2(z) = 1$（提示：$\left|e^{\frac z2(t - 1/t)}\right| = 1$ 當 $|t| = 1$——**能量守恆的 FM 版**）。

## 進階研讀：Bessel 的五個深化場景

**場景一：Sturm–Liouville 與譜**。圓柱上的 Laplace 算子分離變數：徑向方程 = Bessel 方程，**譜 $j_{\nu,k}^2$**。一般理論：正則奇點 + 邊界條件 → 離散譜、正交性 $\int_0^a J_\nu\left(\frac{j_{\nu,k}r}{a}\right)J_\nu\left(\frac{j_{\nu,l}r}{a}\right)r\,dr = \frac{a^2}{2}J_{\nu+1}^2(j_{\nu,k})\,\delta_{kl}$——**Fourier–Bessel 級數**（圓柱的 Fourier 分析）。Weyl 律（譜漸近 $N(\lambda) \sim \frac{A}{4\pi}\lambda$）的圓柱驗證：$\{j_{\nu,k}\}$ 的密度——**譜幾何（「聽音辨鼓」，Kac 1966）的最簡案例**。

**場景二：Hankel 變換**。圓柱對稱的 Fourier 變換 = Hankel 變換 $\hat f(k) = \int_0^\infty f(r)J_0(kr)r\,dr$；**Parseval、卷積定理的 Bessel 版**。應用：MRI 的 k-space 重建、光學的 Airy 斑（圓孔繞射 $= \left(\frac{2J_1(x)}{x}\right)^2$——**望遠鏡解析度的衍射極限就是 $J_1$ 的第一零點** $1.22\lambda/D$）、Bessel 光束。

**場景三：漸近的 Stokes 結構**。$J_\nu$ 在複平面的漸近有**三個扇區**（振盪 $|\arg z| < \frac\pi2$、指數增長/衰減 $\frac\pi2 < |\arg z| < \pi$）——扇形邊界（$\arg z = \pm\frac\pi2$）是 **Stokes 線**（7.1 篂場景四）；跨線時指數項 $e^{-z\sinh}$ 的係數跳變。**Airy 函數**（$\mathrm{Ai}$：$\frac13$ 次冪變換聯通 Bessel $\pm\frac13$ 階）是 Stokes 現象的另一標本（彩虹的光學理論——Airy 1838 焦散線積分）。**特殊函數的複漸近 = Stokes 幾何**，是現代漸近分析（Berry 的 exponential asymptotics）的主題。

**場景四：隨機行走與 Bessel**。$n$ 步等長隨機行走的位置分布的 Bessel 表示（$n$ 維隨機行走的徑向分布 = Bessel 密度：$\chi$ 分布 = $J$-生成）；**Bessel 過程**（$dR = dW + \frac{\nu - 1}{2R}dt$，維數 $\nu$ 的布朗運動半徑）——**Bessel 函數在隨機分析中的「半群核」身份**（Bessel 函數的 Laplace 變換 = 熱核，9.3 例題 (c) 的過程論意義）。機率論與特殊函數的又一接口（2.3 篂 Brown 運動表示的延續）。

**場景五：Zeta 的 Bessel 聯繫與 Riemann–Siegel**。素數定理的顯式公式計算中，**Riemann–Siegel 公式**（1932，由 Riemann 遺稿發掘）以 $\theta$ 函數與近似泛函方程高效計算 $\zeta\left(\frac12 + it\right)$——其結構中 Bessel 型漸近與 Poisson 求和是核心；**KTP（Keiper–Li 係數）**與零點檢驗的數值方法大量使用 Bessel 漸近。**特殊函數是計算數論的工具箱**——8.3 篂的數值驗證（$10^{13}$ 零點）幕後是 Bessel/階乘級數的穩定求值（mpmath 庫的實現）。

### 深化問答三則

**問：為什麼 Bessel 函數無所不在？**
答：因為**圓柱對稱 + 二階線性方程 = Bessel**。任何「二階線性 + 常係數化後 $z^2$ 項」的物理（波動、擴散、薛丁格的圓柱位勢）分離變數都撞上它。它是「圓柱世界的正弦函數」——正如 6.2 篂「單連通域只有一種」、圓柱問題的解空間也只有一族（$J, Y$ 的線性組合）。**對稱性決定函數**。

**問：$Y_n$ 的對數奇點「物理上是什麼」？**
答：點源！圓柱位勢的 Green 函數：$\Delta G = \delta$ 的圓柱解在源點 $\sim \log r$（2.3 篂 $\log r$ 是二維點源）——**$Y_0$ 的對數奇點 = 線源**。振動問題中 $Y_n$ 被丟棄（原點正則性），源問題中 $Y_n$ 是主角（輻射條件 + 源奇異性）。**同一函數族，正則解與奇異解的分工**。

**問：生成函數與 FM 調製的「巧合」是什麼？**
答：不是巧合。FM 訊號 $e^{i(\omega t + \beta\sin\Omega t)} = \sum_n J_n(\beta)e^{in\Omega t}e^{i\omega t}$——**頻率調製的邊帶幅度 = $J_n(\beta)$**（生成函數取 $t = e^{i\Omega t}$）。Bessel 1824 研究的天文展開與 1930s 的 FM 理論（Armstrong 1933）是同一條恆等式的兩次生命——**數學恆等式的應用橫跨一個世紀與兩個行業**。
