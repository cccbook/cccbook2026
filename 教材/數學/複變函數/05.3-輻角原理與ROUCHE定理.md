# 5.3 輻角原理與ROUCHE定理

## 本章導言

留數定理計算積分；本節把它反轉為**計數器**：閉路積分 $\oint \frac{f'}{f}dz$ 數出圈內零點與極點的個數。由此出發的 **Rouché 定理**給出「比較法」——用一個已知函數壓制擾動，判定根的數量不變。這兩件工具使「方程有多少根」從難題變成估計題，也是代數基本定理最自然的證明、第 6 章映射理論（單葉性）、與 10.3 篂複動力學（迭代根計數）的地基。

### 對數導數與輻角原理

**對數導數**：$g = \frac{f'}{f} = (\log f)'$。若 $f$ 在 $a$ 有 $m$ 階零點：$f = (z-a)^m h$、$h(a) \ne 0$，則

$$
\frac{f'}{f} = \frac{m}{z-a} + \frac{h'}{h}.
$$

**$\frac{m}{z-a}$ 的留數恰為 $m$**（單極點、整數留數）；若 $f$ 在 $a$ 有 $n$ 階極點：$f = (z-a)^{-n}h$，$\frac{f'}{f} = \frac{-n}{z-a} + \frac{h'}{h}$，留數 $-n$。$\frac{h'}{h}$ 部分在 $a$ 解析。

**輻角原理（Argument Principle）**：設 $f$ 半純（meromorphic）於閉曲線 $\gamma$ 及其內部，$\gamma$ 上 $f \ne 0$。則

$$
\frac{1}{2\pi i}\oint_\gamma \frac{f'(z)}{f(z)}\,dz = N - P,
$$

其中 $N$、$P$ 是 $\gamma$ 內部的零點總數與極點總數（計重數）。

**兩種讀法**：

1. **留數讀法**：$\frac{f'}{f}$ 的留數恰是各零點/極點的重數（正/負），留數定理直接求和。
2. **輻角讀法**：$\frac{1}{2\pi i}\oint \frac{f'}{f}dz = \frac{1}{2\pi i}\oint d(\log f)$ = $\log f$ 沿 $\gamma$ 的淨變化 = $\frac{1}{2\pi}\Delta\operatorname{Arg} f(\gamma(t))$——**$f$ 的像曲線繞原點的圈數**。「數根」=「數圈」。這就是名稱由來，也是 1.2 篂「winding number」的函數版。

### Rouché 定理

**定理（Rouché, 1862）**：$f, g$ 在 $\gamma$ 及內部解析，且在 $\gamma$ 上 $|g| < |f|$。則 $f$ 與 $f + g$ 在 $\gamma$ 內零點數相同。

**證明思想**：在 $\gamma$ 上，$f + g$ 的像與 $f$ 的像「足夠近」（$|g| < |f|$ 保證 $f+g$ 不過原點，且 $F_t = f + tg$（$0\le t\le 1$）是一條連續變形，途中不過原點）——**繞圈數在同倫中不變**：

$$
\frac{1}{2\pi i}\oint_\gamma \frac{(f+tg)'}{f+tg}dz
$$

關於 $t$ 連續且取整數值，故恆定。$t = 0$ 給 $N_f$、$t = 1$ 給 $N_{f+g}$。∎

**直觀**：大艦 $f$ 帶著小艇 $g$ 航行，只要小艇拖不出大艦繞港的圈數，總繞圈數不變。**「強者定調」**——根的存在性由主項決定，擾動不奪權。

### 三個即時勝利

**勝利一：代數基本定理的 Rouché 版**。$p(z) = z^n + a_{n-1}z^{n-1} + \cdots$。取大圓 $|z| = R$，$|a_{n-1}z^{n-1} + \cdots| \le C R^{n-1} < R^n = |z^n|$（$R$ 充分大）。Rouché：$p$ 與 $z^n$ 在圓內零點數相同 = $n$。∎

**勝利二：根的定位**。$z^5 + 3z + 1 = 0$ 在 $|z| < 1$ 內幾個根？在 $|z| = 1$ 上：$|3z + 1| \le 4 > |z^5| = 1$？不對，要選主項：$|z^5| = 1 < |3z + 1|$ 的下界？$|3z+1| \ge |3| - |1| = 2 > 1 = |z^5|$。故 $p$ 與 $3z + 1$ 在單位圓內零點數相同 = 1。**單位圓內恰一根**。（其餘四根在 $|z| > 1$——再用大圓 Rouché 總數 5。）

**勝利三：開映射定理（預告 6.1）**。非恆常解析函數把開集映為開集。證明思想：取 $w_0 = f(z_0)$，考察 $f(z) - w_0$：$z_0$ 是 $m$ 階零點；小圓上 $|f - w_0| \ge \delta > 0$；對 $|w - w_0| < \delta$，Rouché 給 $f - w$ 與 $f - w_0$ 在小圓內零點數同為 $m \ge 1$——**每個近旁值都被取到**。開映射定理是 Rouché 的直接推論；6.1 篂的保角映射理論（單葉 = 零點數恰 1）以它為起點。

### Hurwitz 定理與根的連續依賴

**Hurwitz 定理（1889）**：$f_n$ 內閉一致收斂到 $f \ne 0$，若每個 $f_n$ 在 $D$ 內無零點，則 $f$ 在 $D$ 內無零點（或恆零）。

**推論**：單葉解析函數的內閉一致極限若非常數，則單葉（Rouché：$f_n(z) - f_n(z_0) \ne 0$ 的極限傳遞）。這是 6.2 篂 Riemann 映射定理存在性論證（極限函數的單葉性）的關鍵組件。

### 一個具體例題

**例題 5.3.1**：證明方程 $z^4 + 6z + 3 = 0$ (a) 在 $|z| < 1$ 恰有一個實根且無複根（即恰一根，且為實）；(b) 在 $1 < |z| < 2$ 恰有三個根。

**解**：

(a) 在 $|z| = 1$ 上：$|6z + 3| \ge 6 - 3 = 3 > 1 = |z^4|$。Rouché（主項 $6z + 3$）：$p$ 與 $6z + 3$ 在 $|z|<1$ 內零點數相同 = 1。

這個根是實的嗎？**Descartes 符號法則**：$p(x) = x^4 + 6x + 3$ 的係數 $+,+,+$ 無變號 → 無正根；$p(-x) = x^4 - 6x + 3$ 兩次變號 → 至多 2 個負根。$p(-1) = 1 - 6 + 3 = -2 < 0$、$p(0) = 3 > 0$：$(-1, 0)$ 中有負根。$p(-2) = 16 - 12 + 3 = 7 > 0$：$(-2,-1)$ 中有負根！這有兩個負根了——但 (a) 說圓內恰一根。檢查：$-2$ 與 $-1$ 的模都 $> 1$，兩個負實根都在 $|z| > 1$（若 $|x| \ge 1$）。$(-1, 0)$ 內的根 $x_0 \in (-0.5, 0)$：$p(-0.5) = 0.0625 - 3 + 3 = 0.0625 > 0$、$p(-0.6) = 0.1296 - 3.6 + 3 = -0.4704 < 0$：根在 $(-0.6, -0.5)$，$|x_0| < 1$ ✓。所以 $|z|<1$ 內的唯一根是實根 $x_0 \approx -0.51$。**與 Rouché 相容**：圓內 1 根 = 這個實根；另三根（兩負實 + ？）在 $|z| > 1$。

等等，若四根中三個是實的（$x_0, y_1 \in (-2,-1), y_2$？），$p(-x) = x^4 - 6x + 3$ 至多 2 個正根即 $p$ 至多 2 個負根。我們找到 $(-1,0)$ 與 $(-2,-1)$ 兩個負根 → 負實根恰 2 個。剩餘 1 根：共軛成對要求非實根成對——$4 = 1(\text{實 } x_0) + 2(\text{負實根}) + 1$？不成對！**矛盾**——重查 Descartes：$p(-x) = x^4 - 6x + 3$ 係數 $+,-,+$：變號 2 次 → $p$ 至多 2 負根；$p(x)$ 無正根。4 根 = 至多 2 負實 + 0 正實 + 剩餘非實根對。若負實根恰 2，則非實根 2 個（一對共軛）。**總數對上**：$x_0 \approx -0.51$、$y_1 \approx -1.63$（檢查 $p(-1.63) = 7.06 - 9.78 + 3 = 0.28$？算 $(-1.63)^4 = 7.06$、$6(-1.63) = -9.78$，和 $0.28 > 0$；$p(-1.5) = 5.06 - 9 + 3 = -0.94 < 0$：根在 $(-1.6, -1.5)$，$|y_1| \approx 1.56 > 1$ ✓）、一對共軛複根（在 $1 < |z| < 2$，見 (b)）。

(b) 在 $|z| = 2$ 上：$|z^4| = 16 > |6z + 3| \le 15$。Rouché（主項 $z^4$）：$p$ 在 $|z|<2$ 內零點數 = 4。配合 (a) 的「$|z|<1$ 內 1 根」，**環 $1 < |z| < 2$ 內恰 $4 - 1 = 3$ 根** ✓（兩負實根 + 一對共軛複根）。

**方法論**：Rouché 給「每個圓內的根數」，環狀區域用相減；實根與複根的分布用 Descartes + 共軛配對交叉驗證。**多重工具的總帳必須平衡**——這是根定位題的紀律。

### 歷史背景

- **輻角原理**的根：Cauchy 1837 年《關於方程根的數目》已給出「$\frac{1}{2\pi i}\oint \frac{f'}{f}$ 計數」的表述；「輻角」的幾何讀法由 Riemann（1851，映射的度數）與 Poincaré（指標理論，1881）發揚。
- **Rouché**：Eugène Rouché（1832–1910），法國應用數學家（紡織力學教授），1862 年論文以「壓制擾動」判定根數；定理的現代形式（同倫論證）由 Hurwitz 1889 年整理。Rouché 同時是代數曲面論與法國數學教育（Cours de mathématiques）的推手。
- **Hurwitz**：Adolf Hurwitz（1859–1919），Kronecker 學生、Hilbert 的同僚與摯友（Hilbert 稱他「無所不知的 Hurwitz」）。他 1889 年的收斂–零點理論（Hurwitz 定理）是正規族思想的先聲；他也是「Hurwitz 多項式」（穩定性，控制理論的 Routh–Hurwitz 判據）的命名者——**根計數的複變技術直接進入工程控制論**：閉環系統穩定 $\iff$ 特徵多項式根全在左半平面（以 $\frac{1+z}{1-z}$ 變換映射到單位盤，Rouché/輻角原理應用）。

### 歷史啟示

- **積分是離散的計數器**：$\oint\frac{f'}{f}$ 的值是整數——連續積分輸出離散資訊。這種「分析 → 拓撲/組合」的翻譯是二十世紀數學（指標定理、拓撲量子數）的原型。
- **同倫不變性是 Rouché 的靈魂**：「繞圈數在連續變形下不變」——拓撲直觀第一次成為根定位的核心論證。
- **工程學的反哺**：Routh–Hurwitz 判據（1876/1895）把「根是否都在左半平面」變成係數不等式——複變根計數 → 控制系統穩定性，數學工具進入工程標準。

## 進階研讀：計數技術的五個深化場景

**場景一：Jensen 公式與函數的「收支平衡」**。$f$ 在 $|z| \le R$ 半純，$\log|f(0)| = \sum_{|a_k|<R}\log\frac{R}{|a_k|}$（零點）$-\sum\log\frac{R}{|b_k|}$（極點）$+ \frac{1}{2\pi}\int_0^{2\pi}\log|f(Re^{i\theta})|d\theta$。**零點位置（內圈貢獻大）由邊界平均對數付帳**。Jensen 公式（1899）是整函數的階與乘積表示（8.1 篂）、$\zeta$ 零點密度（8.3）的基礎量具。

**場景二：Littlewood 定理與臨界線計數**。把輻角原理對 $\frac{f'}{f}$ 與對 $\log f$ 分別積分、相減，得 **Littlewood 定理（1924）**：$N(R)$（零點數）可由「邊界上 $\log|f|$ 的積分」表出——**不用知道零點位置就能數零點**。Levinson（1974）用它證明 $\zeta$ 臨界線上零點超過三分之一（後被 Conrey 1989 推到 40%、經多人至目前的 5/12）；對數–輻角的組合是解析數論的計數核心。

**場景三：Riemann–Hurwitz 公式**。覆疊映射 $f: X \to Y$（Riemann 面之間，度 $d$）：$2g_X - 2 = d(2g_Y - 2) + \sum (e_p - 1)$，$e_p$ 是分歧指數（= 輻角原理的局部根數）。**「分支點的虧損」決定曲面的拓撲**——輻角原理的曲面版。$z \mapsto z^n$ 把球面覆疊球面（$g=0$，分支點 $0, \infty$ 各 $e = n$）：$-2 = n(-2) + 2(n-1) = -2$ ✓。此公式統治 7.2 篂的 Riemann 面分類與模空間計數。

**場景四：Nyquist 判據的工程細節**。閉環傳遞函數 $\frac{G}{1 + GL}$ 穩定 $\iff$ $1 + L$ 無右半平面零點 $\iff$ $L$ 的像繞 $-1$ 的圈數 = $L$ 的右半平面極點數。實作中只需畫 $\omega \in (-\infty, \infty)$ 的 $L(i\omega)$ 曲線（共軛對稱 → 正頻率半支 + 鏡像）。**1932 年 Nyquist 在 Bell 實驗室用「繞圈數」解決回饋放大器振盪問題**——輻角原理最成功的應用，穩定裕度（gain/phase margin）的圖解文化至今是控制工程的通用語言。

**場景五：同倫計數與代數幾何**。Bezout 定理（兩 $n$ 次曲線交 $n^2$ 點，計重數與無窮遠）的證明可用 Rouché 式擾動：把一條曲線微擾成 $n$ 條直線，交點數目在同倫中不變。**「擾動 + 計數不變」**是代數幾何的通用策略（虛擬基本類、局部化定理的哲學）；Rouché 定理是它的最簡模型。

### 深化問答三則

**問：輻角原理「數根」與代數基本定理「保證根存在」是什麼關係？**
答：代數基本定理保證 $n$ 次方程根的**總數**（全域）；輻角原理給出根的**區域分布**（每個圓內幾個）。Rouché 是在兩者之間工作的「定位器」：先用大圓確定總數，再用小圓/環分配。三件工具構成「根的普查系統」。

**問：Rouché 定理的條件「$|g| < |f|$」是最優的嗎？**
答：充分不必要。最小化版本（同一原則）：只需 $f + tg$（$t\in[0,1]$）在 $\gamma$ 上不過原點——即 $|g|$ 可以局部超過 $|f|$，只要擾動路徑不掃過 0。工程上的穩定裕度（gain margin、phase margin）正是「離破壞條件還有多遠」的計量——Rouché 的不等式只是「裕度 > 0」的簡單充分版本。

**問：Hurwitz 定理為什麼要求極限 $f \ne 0$（非常數）？**
答：因為極限函數可能恆零（如 $f_n = z/n$），此時「零點無窮多」自然成立——定理排除的是「極限憑空產生有限個零點」的可能。這是緊性論證的標準邊界情況：正規族的極限要麼繼承結構、要麼退化為常數——**「繼承或退化」的兩分法**在複分析（Hurwitz、Vitali 定理）與泛函分析（Banach–Alaoglu）中同構。
