# 1.2 借貸恆等式與守恆觀

## 本章導言

1.1 節留下一個待解的疑問：為什麼「借方合計＝貸方合計」永遠成立？答案不在簿記規則裡，而在一個更古老的數學事實中——**若一個量在每次變換下都保持不變，那它就是守恆量**。資產恆等式

$$
\text{資產} = \text{負債} + \text{權益}
$$

就是會計的守恆式。本節要證明：每一筆合規的分錄都不會破壞它，因此從期初的「真」可歸納出任何時刻的「真」；同時要說明，這個守恆式如何反過來成為偵錯工具。

### 一、恆等式是一個「面」，不是一個「數」

把一家公司的全部科目餘額排成一列，資產類放正號、負債與權益類放負號，則會計方程等價於

$$
\sum_{\text{資產}} x_i - \sum_{\text{負債}} x_j - \sum_{\text{權益}} x_k = 0.
$$

所有滿足這個條件的餘額組合，在 $n$ 維空間中構成一個**通過原點的超平面** $H$ 。公司任何時候的財務狀態都是 $H$ 上的一個點；「帳不平」在幾何上就是**離開了這個平面**。這個圖像是 2.1 節的正式內容，本節先借用它來理解守恆。

### 二、分錄不會把點推離平面

一筆合規分錄的本質是：某科目增加 $a$ 、另一科目減少 $a$ 。寫成向量 $\mathbf{v}$ ，其帶號分量之和為

$$
\sum_i s_i v_i = a - a = 0,
$$

其中 $s_i$ 是該科目的借貸號誌（借方 $+1$ 、貸方 $-1$ ）。這樣的 $\mathbf{v}$ 恰好是超平面 $H$ 的方向向量，於是

$$
\mathbf{x} \in H \;\Longrightarrow\; \mathbf{x} + \mathbf{v} \in H.
$$

一連串分錄 $v_1, v_2, \ldots, v_m$ 之後，狀態為 $\mathbf{x}_0 + \sum_{j} v_j$ ，仍在 $H$ 上。**歸納法完成了證明**：期初平衡、每筆分錄平衡，故永遠平衡。這與力學中「合力為零則動量守恆」是同一種論證結構。

還要注意：「借方總額＝貸方總額」只是守恆式在**總帳層次的投影**，真正的守恆是逐科目、逐層級成立的。試算表兩方相等卻仍可能出錯（例如一筆 900 的交易兩邊同記成 990），因為試算表檢驗的只是一個**標量**，而守恆式本身是一個**向量條件**。

### 三、收入與費用如何暫時「撐開」方程

初學者常困惑：為何銷貨收入會讓資產增加、權益也同時增加，兩邊一起變大？因為權益是個**蓄水池**：

$$
\text{權益} = \text{投入資本} + \text{收入} - \text{費用} - \text{提取}.
$$

代回會計方程得

$$
\text{資產} = \text{負債} + \text{投入資本} + (\text{收入} - \text{費用} - \text{提取}).
$$

收入與費用只是權益內部的暫存科目，期末結帳後併回資本。所以**恆等式在結帳前後同樣成立**，只是變數劃分不同。這也解釋了為何試算表上同時存在資產負債表科目與損益表科目，而兩方仍然相等。

### 四、偵錯：用差額反推被破壞的那一筆

守恆式最大的實務價值在於它**可以被違反**——一旦違反，就一定有具體的記錄出了問題，而且差額的方向還能指示錯誤類型：貸方偏大，通常是漏記了某筆的借方，或貸方金額多記。

**例題 1.2.1**：某公司結算後試算表如下（單位：元）。試檢查是否平衡；若不平衡，找出錯誤並修復，再以會計方程覆核。

| 科目 | 借方 | 貸方 |
|------|-----:|-----:|
| 現金 | 19,100 | |
| 應收帳款 | 9,500 | |
| 存貨 | 26,000 | |
| 銷貨成本 | 17,000 | |
| 營業費用 | 4,600 | |
| 應付帳款 | | 12,300 |
| 業主資本 | | 45,000 |
| 銷貨收入 | | 19,800 |
| **合計** | **76,200** | **77,100** |

**解**：借方 76,200、貸方 77,100，貸方多出 $77{,}100-76{,}200=900$ 。差額是整數元且「貸方偏多」，暗示有一筆 900 的交易只記了貸方。翻查日記簿可見：「以現金償還應付帳款 900」只做了「貸記現金 900」，漏記「借記應付帳款 900」。

補記後，應付帳款貸方餘額修正為 $12{,}300-900=11{,}400$ ，借方合計維持 76,200，貸方變為 $77{,}100-900=76{,}200$ ，兩方相等。

再用守恆式覆核：資產 $=19{,}100+9{,}500+26{,}000=54{,}600$ ；權益 $=45{,}000+19{,}800-17{,}000-4{,}600=43{,}200$ ；負債＋權益 $=11{,}400+43{,}200=54{,}600$ 。修復前右端為 $12{,}300+43{,}200=55{,}500$ ，恰比左端多 900，與試算表差額完全一致——**兩種獨立檢驗給出同一個數字**，這就是守恆式的力量。

## 前因後果與驅動關係

- **實務驅動**：中世紀商埠的合夥清算要求「帳能對得起來」。沒有守恆式，帳簿錯誤只能逐筆重算；有了守恆式，一個差額就能把範圍縮到單筆交易——**偵錯成本從 $O(n)$ 降到近乎 $O(1)$ 的定位**。
- **理論的回饋**：十九世紀末起，「兩方平衡」成為審計意見的最低門檻；現代準則不斷增設新科目（折舊、攤銷、估計項目），卻從未動搖恆等式本身——**科目可以增刪，守恆結構不變**，這正是 2.1 節「子空間」概念的現實版本。
- **走向更抽象**：當分錄被寫成矩陣、科目被寫成座標軸，守恆式就升級為線性條件 $s^{\mathsf T}\mathbf{x}=0$ 與映射的像空間（2.2、2.3 節）；當錯誤需要被機率化處理，就進入 7.3 節的差異檢定與 9.3 節的抽樣稽核；到了 10.3 節的區塊鏈帳本，守恆式更被寫成每個區塊都必須驗證的程式斷言。
- **兄弟書接點**：物理學守恆律（能量、動量）與本節共享同一套數學——對稱性產生守恆量；《經濟的數學》第 5 章一般均衡也以「流量收支相等」為核心約束；《金融的數學》第 1 章的時間價值則提醒：守恆的是**名目金額**，其「現在價值」另有一套折現運算（見 4.1 節）。

## 練習

1. 某公司資產 250,000、負債 96,000，求權益總額。若業主增資 40,000（收現），增資後資產與權益各為多少？恆等式是否維持？
2. 若試算表兩方合計相等，是否保證帳目一定正確？請舉出一種「兩方相等但確實出錯」的情境，並說明為何試算表查不出來。
3. 一筆分錄「借記應收帳款 5,000、貸記銷貨收入 5,000」，試寫出它在超平面 $H$ 上的位移向量（依資產、負債、權益的號誌），並驗證其代數和為 0。
4. 某公司期初資產 120,000、負債 45,000。當期收入 90,000、費用 60,000、業主提取 10,000，且期末負債為 40,000。求期末資產總額。
5. 思考題：物理學的守恆律往往來自「對稱性」（諾特定理）。請論述：複式簿記中「借貸對稱」的對稱群是什麼？換句話說，哪些操作不會改變帳目的正確性？（提示：同時交換兩科目的名稱、把一筆分錄拆成兩筆等價分錄……）

### 名詞速查表

- **會計恆等式**：資產＝負債＋權益，會計中最基本的守恆關係。
- **借貸號誌**：以 $+1$ （借方）、 $-1$ （貸方）標記科目方向的指標函數。
- **超平面 $H$ **：滿足 $s^{\mathsf T}\mathbf{x}=0$ 的所有餘額向量構成的子空間。
- **標量檢驗 vs 向量條件**：試算表只驗總和，守恆式則要求逐項正確。
- **結帳**：把收入與費用科目餘額併入資本科目的期末程序。
