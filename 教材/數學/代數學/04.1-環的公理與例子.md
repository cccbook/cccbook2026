# 4.1 環的公理與例子

## 本章導言

群只有一個運算；但數的世界有兩個——加法與乘法，且由分配律牽手。**環**（ring）正是「一個加法 Abel 群 + 一個乘法結構 + 分配律」的代數系統。環論誕生於十九世紀末 Dedekind 的數論工作（「序」與「理想」），公理化完成於 1914 年 Fraenkel、成熟於 Noether 學派。本節給出環的公理，巡禮各種典型環——從整數到矩陣到多項式——並說明環論與群論的分工：群管「對稱」，環管「計算」。

### 環的定義

**定義**：非空集合 $R$ 搭配兩個運算 $+, \cdot$ ，若

1. $(R, +)$ 是 Abel 群（單位元記 $0$ ，逆記 $-a$ ）；
2. 乘法結合： $(ab)c = a(bc)$ ；
3. 分配律： $a(b+c) = ab + ac$ ， $(a+b)c = ac + bc$ ；

則稱 $R$ 為**環**。若有乘法單位元 $1 \ne 0$ ，稱**含么環**；若乘法交換，稱**交換環**；若 $ab = 0 \Rightarrow a = 0$ 或 $b = 0$ ，稱**無零因子**；交換、含么、無零因子的環稱**整環**（integral domain）。若還要求每個非零元有乘法逆，稱**體**（field，第 5 章主角）。

**公理的分工圖**：

| 公理 | 供應者 | 管轄的現象 |
|------|--------|------------|
| 加法 Abel 群 | 群論（2.2 節） | 加減法、0、負數 |
| 乘法結合 | 半群 | 連乘的次序 |
| 分配律 | 橋樑 | 展開、因式分解 |
| 無零因子（可選） | 數論 | 消去律是否安全 |

**分配律為何是靈魂**：沒有分配律，加法與乘法是兩個互不相干的群/半群貼在一起。分配律使「多項式展開」「因式分解」「數的豎式計算」全部合法——它是小學算術、高中代數、大學環論共享的唯一深層法則。

### 環的例子大觀園

| 環 | 交換？ | 含么？ | 零因子？ | 備註 |
|----|--------|--------|----------|------|
| $\mathbb{Z}$ | 是 | 是 | 無 | 整環原型 |
| $\mathbb{Q}, \mathbb{R}, \mathbb{C}$ | 是 | 是 | 無 | 體（最強的環） |
| $\mathbb{Z}/n\mathbb{Z}$ | 是 | 是 | $n$ 合數時有 | $\mathbb{Z}/p\mathbb{Z}$ 是體 |
| $M_2(\mathbb{R})$ | **否** | 是 | 有 | 非交換環的代表 |
| $\mathbb{Z}[x]$ （整係數多項式） | 是 | 是 | 無 | 4.3 節主角 |
| $C[0,1]$ （連續函數，加乘） | 是 | 是 | 有 | 函數環，分析與代數的橋 |
| 高斯整數 $\mathbb{Z}[i]$ | 是 | 是 | 無 | 數論的樂園 |
| 偶整數 $2\mathbb{Z}$ | 是 | **否** | 無 | 無么環的例子 |

每個例子都攜帶一個教訓：

- $M_2(\mathbb{R})$ ： $AB$ 可以是零矩陣而 $A, B \ne 0$ （如 $\begin{pmatrix}0&1\\0&0\end{pmatrix}^2 = 0$ ）——**非交換與零因子常同時出現**，消去律在這裡非法。
- $\mathbb{Z}/6\mathbb{Z}$ ： $2 \times 3 = 0$ ——「時鐘世界」裡可以把非零數乘成零，這正是 10.1 節 RSA 要**避免**（取模素數）而某些應用要**利用**的性質。
- $\mathbb{Z}[i]$ ： $\mathbb{Z}$ 的複數版親戚，其中 5 可以分解為 $(2+i)(2-i)$ ，而 3 不能——**素數的定義在更大的環裡會改變**，這是 Kummer「理想數」（4.2 節）的歷史溫床。

### 為什麼「零因子」是環論的第一道關卡

**定理 4.1.1**：在含么交換環中， $R$ 無零因子 $\iff$ 消去律成立（ $ab = ac,\ a \ne 0 \Rightarrow b = c$ ）。
**證**： $ab = ac \Rightarrow a(b - c) = 0 \Rightarrow b = c$ （無零因子）；反之取 $c = 0$ 。 $\blacksquare$

零因子的存在使環論「失去」群論的舒適：非零元不構成乘法群，Lagrange 定理的類比失效。環論的應對策略是**分層隔離**：把「好元素」（非零因子）與「壞元素」分開——前者組成乘法子集，後者被理想（4.2 節）吸走。**環論的歷史就是不斷把群論定理在「部分適用」條件下重建的歷史**。

### 從 $\mathbb{Z}$ 讀出環論的全部主題

整數環是最小的完整樣本，它身上能讀出環論四個核心概念：

1. **子環**： $n\mathbb{Z}$ 在加乘下封閉（但 $n \ge 2$ 時不含 1——子環不必含么，視約定）。
2. **理想**： $n\mathbb{Z}$ 不僅封閉，還「吸收」外面的乘法（ $r \cdot nk \in n\mathbb{Z}$ ）——這是比子環強得多的條件，4.2 節的主角。
3. **素性**： $p\mathbb{Z}$ 是「極大理想」（4.2 節），對應 $\mathbb{Z}/p\mathbb{Z}$ 是體——**素數的代數定義**。
4. **唯一分解**：算術基本定理；它在 $\mathbb{Z}[i]$ 成立、在 $\mathbb{Z}[\sqrt{-5}]$ **失效**（ $6 = 2 \times 3 = (1+\sqrt{-5})(1-\sqrt{-5})$ ）——失效催生理想論。

環論不是「更複雜的群論」，而是**以 $\mathbb{Z}$ 為原型、以整除性為主題的新大陸**。

### 環的三大構造術

1. **多項式化**： $R[x]$ （4.3 節）——從係數環長出多項式環。
2. **取商**： $R/I$ （4.2 節）——沿理想壓扁。
3. **局部化**： $S^{-1}R$ ——「允許分母」，如 $\mathbb{Z} \rightsquigarrow \mathbb{Q}$ （取全體非零元為分母）。局部分式把整環嵌入其「分式體」，是 5.1 節體擴張的日常經驗。

三構造加上直積 $R \times R'$ ，構成環論的基本操作集。它們與群論的對應（子群/直積/商）平行，但每一步的「良定義條件」都更精細——理想的「吸收性」正是群論「正規性」在雙運算世界的加強版。

### 一個具體例題

**例題 4.1.1**：證明 $\mathbb{Z}/n\mathbb{Z}$ 是體 $\iff$ $n$ 是素數；並說明 $\mathbb{Z}/6\mathbb{Z}$ 的零因子全體。

**解**：（⇒）若 $n = ab$ （ $1 < a, b < n$ ），則 $\bar a \bar b = \bar n = \bar 0$ ， $\bar a, \bar b \ne \bar 0$ 是零因子，故不是體。
（⇐）若 $n = p$ 為素數，對任意 $\bar a \ne \bar 0$ （即 $p \nmid a$ ）， $\gcd(a, p) = 1$ ，由 Bézout 存在 $u, v$ 使 $au + pv = 1$ ，模 $p$ 得 $\bar a \bar u = \bar 1$ ，故 $\bar u$ 是逆元。 $\blacksquare$

$\mathbb{Z}/6\mathbb{Z}$ 的零因子： $\bar 2, \bar 3, \bar 4$ （ $\bar2\bar3 = \bar6 = \bar0$ 、 $\bar4\bar3 = \bar 0$ ）；單位元群為 $\{\bar1, \bar5\}$ 。注意每個元素要麼是單位、要麼是零因子（有限交換環的普遍規律，5.2 節將在有限體框架下證明）——**有限的環沒有「中間分子」**，這與無限環（如 $\mathbb{Z}$ ，2 既非單位也非零因子）形成鮮明對照，是「有限性改變邏輯」的第一課。

### 歷史啟示

- **環論誕生於數論危機**：Kummer 為了救 Fermat 大定理的證明而發明「理想數」（1847），Dedekind 把它實體化為「理想」（1871），Noether 把環公理化（1921）。一門理論的公理往往比其原始問題晚七十年。
- **分配律是「唯一的深法則」**：環論的驚人處在於，僅靠分配律就長出二項式定理、多項式理論、行列式展開——一條橋樑公理承載兩個世界的全部往來。
- **例子的多樣性就是理論的疆界**：矩陣環（非交換）、函數環（無限維）、模算術（有限）各有性格；「環」不是一種東西，而是一個**光譜**。學環論的第一要務是建立例子庫。

## 練習

1. 在 $M_2(\mathbb{Z})$ 中找出兩個非零矩陣使乘積為零矩陣；並說明這為何違反消去律。
2. 在 $\mathbb{Z}/12\mathbb{Z}$ 中列出全部單位與全部零因子，驗證兩集不相交且併為全集。
3. 證明：若 $R$ 是含么環且 $1$ 的加法階有限，則該階是素數（提示：考慮 $R$ 的特徵）。
4. 證明高斯整數 $\mathbb{Z}[i]$ 是整環（提示：複數乘法無零因子），並求 $2+i$ 的「範數」 $N(2+i) = (2+i)(2-i)$ ，用範數說明 $2+i$ 不可再分解。
5. 思考題：若在環公理中把分配律只保留單邊（ $a(b+c) = ab + ac$ ），舉例說明 $(b+c)a$ 展開失效會破壞哪些常見計算。

## 進階研讀：環公理的四個深化場景

**場景一：特徵——環的「化學週期」**。含么環中 $1 + 1 + \cdots + 1$ （ $n$ 個）首次為零的最小 $n$ 稱**特徵**；無此 $n$ 則特徵為 0。 $\mathbb{Z}, \mathbb{Q}$ 特徵 0； $\mathbb{Z}/n\mathbb{Z}$ 特徵 $n$ ；體的特徵必為 0 或素數（5.2 節）。特徵是環的「第一不變量」：特徵 $p$ 的體中 $(a+b)^p = a^p + b^p$ （Frobenius 同態！二項式中間項全滅）——**有限的模算術世界有自己的代數規則**，這條規則將在 5.2 節成為有限體理論的引擎。

**場景二：非交換環的物理化身——算子代數**。量子力學的狀態由 Hilbert 空間上的算子描述：位置算子 $Q$ 與動量算子 $P$ 滿足 $PQ - QP = -i\hbar I$ （Heisenberg 交換關係，1925）。這是**非交換環**的物理宣言：兩個運算的「不可交換量」恰是物理量 $\hbar$ 。Weyl、von Neumann 在 1930 年代建立算子環（ $C^*$ -代數、von Neumann 代數），今日的量子場論以「算子代數的分類」為數學骨架——環論的最深支流直接通向物質理論。

**場景三：唯一分解的病理與「代數數」的世界**。 $\mathbb{Z}[\sqrt{-5}]$ 中 $6$ 的兩種分解顯示唯一分解失效；進一步計算可證 $2, 3, 1 \pm \sqrt{-5}$ 都「不可再分」（不可約元），但都不是素元（可整除乘積卻不整除任何因子）。Dedekind 的診斷：問題不在數而在「缺了數」——添加「理想數」後分解恢復唯一（理想層面的唯一分解定理，4.2 節）。Kummer 由此在 1847 年證明了 Fermat 大定理的若干指數情形；一百五十年後 Wiles（1995）的完整證明仍在同一條「代數數 + 理想」的路線上，只是工具升級為橢圓曲線與模形式（10.1 節將見其密碼學另一面）。

**場景四：從環到幾何——代數幾何的字典**。交換環 $R$ 可視為「某個幾何空間的函數環」：指定 $R$ 的極大理想為「點」、素理想為「不可約子集」，得**譜** $\mathrm{Spec}\,R$ （Grothendieck 1960）。字典雙向翻譯：理想 ↔ 子簇、商環 ↔ 閉子簇、局部化 ↔ 開鄰域、Krull 維數 ↔ 幾何維數。環論從此成為幾何學；Fermat 曲線 $y^2 = x^3 - x$ 的整數點問題變成環 $\mathbb{Z}[x,y]/(y^2 - x^3 + x)$ 的性質問題。**「環是空間的函數」是二十世紀數學最偉大的隱喻之一**，它使本節的每一條抽象定義都有幾何畫像。

### 補充：Noether 與環公理化的革命

Emmy Noether（1882–1935），Erlangen 數學教授之女，因性別被拒絕正式教職多年，1915 年起在 Göttingen 以 Hilbert 之名授課（Hilbert 名言：「大學不是澡堂」），1933 年遭納粹驅逐流亡美國。她在 1921 年《理想論中的理想理論》提出交換環的公理化，並證明 Noether 條件（每個理想有限生成）下的核心定理（升鏈條件 ⇒ 分解存在）。她還證明了物理學的 Noether 定理（10.2 節）。**一位數學家同時奠基了抽象代數與理論物理的兩塊基石**，是科學史上的獨例。Bourbaki 學派的「結構數學」與 van der Waerden 教科書（1930，直接基於她的講義）都是她的直接遺產。

### 名詞速查表（本節出現的核心術語）

- **環**：加法 Abel 群 + 結合乘法 + 分配律。
- **含么 / 交換 / 整環**：有 $1$ / 乘法交換 / 交換且無零因子。
- **零因子**：非零的 $a$ 使存在 $b \ne 0$ 而 $ab = 0$ 。
- **單位群 $R^\times$ **：有乘法逆的非零元構成的群。
- **特徵**： $1$ 的加法階；體的特徵是 0 或素數。
- **子環 / 理想**：加乘封閉的子集 / 額外吸收乘法的子集。
- **分式體**：整環允許分母後得到的體。

### 深化問答三則

**問：群論與環論的「心理差異」是什麼？**
答：群問「操作如何對稱地疊加」，環問「量如何算、如何分解」。群的基本動詞是「合成」，環的基本動詞是「分解」（因式分解、理想分解、單元分解）。因此群論的主定理常是存在性（Sylow：子群存在），環論的主定理常是唯一性（唯一分解、4.2 節的理想唯一分解）。初學者易犯的錯：把群論的直覺（一切子集皆可成子群）搬進環論（子環可以，但「好的子環」必須是理想——強得多）。

**問： $\mathbb{Z}/6\mathbb{Z}$ 的例子說「有限環中每個元素非單位即零因子」，這對 $\mathbb{Z}[x]$ 為何失效？**
答：因為無限環有「第三種人」： $2$ 在 $\mathbb{Z}[x]$ 中既無逆（ $\frac12$ 非整係數）、也非零因子。這種「正則但非單位」的元素是分式體構造的原料，也是多項式理論中「次數會上升」的根源。有限與無限的分野在環論中比群論中更早、更尖銳——本節例題是這個分野的第一個實驗。

**問：為什麼說「環論誕生於錯誤」？**
答：Kummer 1847 年曾宣布證明 Fermat 大定理，隨後被 Liouville 指出他默認了「唯一分解」在 $\mathbb{Z}[\zeta_p]$ 中成立——這是錯的。Kummer 的補救（理想數）不僅救回了部分證明，還開創了整個環論。**偉大理論常以一次著名錯誤為出生證明**——類似的還有集合論（Cantor 的無窮之爭）與非歐幾何。
