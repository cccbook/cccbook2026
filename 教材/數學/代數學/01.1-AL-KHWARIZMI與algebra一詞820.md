# 1.1 Al-Khwarizmi 與 algebra 一詞：820 年的智慧之屋

## 本章導言

代數學的故事，通常從一個波斯數學家在巴格達寫下的一本書說起。西元 820 年前後，**al-Khwarizmi（花拉子米，約 780–850）** 在阿拔斯王朝的「智慧之屋」（Bayt al-Hikma）完成了《還原與對消計算概要》（al-Kitab al-mukhtasar fi hisab al-jabr wa'l-muqabala）。書名中的 **al-jabr**（還原）一詞，經拉丁轉寫成為今日英語的 **algebra**。本節將追溯這一詞源的來龍去脈，並理解早期代數如何從「解方程的技術」一步步走向「研究結構的科學」。

### 智慧之屋：翻譯運動的黃金年代

八至九世紀的巴格達是人類知識史上罕見的匯流點。哈里發 al-Ma'mun（813–833 在位）設立智慧之屋，組織大規模翻譯運動：

| 來源文明 | 被翻譯的文本 | 帶來的數學遺產 |
|----------|--------------|----------------|
| 希臘 | Euclid《幾何原本》、Ptolemy《天文學大成》 | 公理化演繹方法、三角學 |
| 印度 | Brahmagupta 的天文與算術著作 | 十進位值制記數法、「零」的運算規則 |
| 波斯與本土 | 天文觀測傳統、行政計算需求 | 曆法、遺產分配、土地測量 |

正是印度記數法經過 al-Khwarizmi 的另一本著作《印度計算法》傳入歐洲，「algorithm」（演算法）一詞即由他的名字拉丁化（Algoritmi）而來。一個人給世界留下了兩個基本詞彙：**algebra** 與 **algorithm**。

### al-jabr 與 al-muqabala：兩種操作的命名

《還原與對消》書名中的兩個詞，描述了解方程時的兩種標準操作：

- **al-jabr（還原）**：把方程一側的負項移到另一側變成正項。例如 $x^2 = 40x - 4x^2$ 經還原得 $5x^2 = 40x$。
- **al-muqabala（對消）**：把兩側同類項約去。例如 $50 + x = 38 + 4x$ 經對消得 $12 = 3x$。

由於 al-jabr 也有「接骨、復位」的日常意義，中世紀歐洲曾出現「algebrista」（接骨師）的雙關用法，Don Quixote 中就有此戲語。一門嚴肅科學的命名，竟帶著市井的體溫。

### 六種標準型：沒有負數的代數

al-Khwarizmi 時代沒有負數與零係數的觀念，因此二次方程必須按係數正負分成六種標準型：

| 標準型 | 現代形式 | 解法 |
|--------|----------|------|
| 方等於根 | $x^2 = bx$ | $x = b$ |
| 方等於數 | $x^2 = c$ | $x = \sqrt{c}$ |
| 根等於數 | $x = c$ | $x = c$ |
| 方與根等於數 | $x^2 + bx = c$ | 公式：$x = \sqrt{\left(\frac b2\right)^2 + c} - \frac b2$ |
| 方與數等於根 | $x^2 + c = bx$ | 兩個正根，需分情形討論 |
| 根與數等於方 | $x^2 = bx + c$ | $x = \frac{b}{2} + \sqrt{\left(\frac b2\right)^2 + c}$ |

注意他只取正根——因為根代表的是可測量的長度。這種「幾何代數」的態度，是早期代數的共同特徵：**方程是關於線段面積的陳述，解是可作的長度**。

### 幾何證明的護身符

有趣的是，al-Khwarizmi 為二次方程公式給出的證明是**幾何的**：用拼圖法把 $x^2 + bx = c$ 解釋為在邊長 $x$ 的正方形外接長方形，補角完成平方。這是對 Euclid《幾何原本》第二卷命題傳統的繼承。為什麼一個「計算之書」需要幾何證明？因為在九世紀的數學文化中，**只有幾何才具有證明的權威**。這種「計算結果靠代數、正當性靠幾何」的分工，持續了七百年，直到 Descartes（1637）把兩者熔為一爐。

### algebra 詞彙的漫長旅程

- 1145 年：Chester 的 Robert 將該書譯為拉丁文 *Liber algebrae et almucabola*，algebra 進入歐洲。
- 十三世紀：Fibonacci《計算之書》（1202）吸收伊斯蘭代數，把它帶入商業算術。
- 十六世紀：義大利代數學派（見 1.2 節）爆發三次方程之戰，algebra 從實用技術轉為理論學科。
- 1859 年：清代李善蘭與偉烈亞力合譯 De Morgan《代數學》，「代數」一詞首次以漢語定名——「以字代數」。

### 從解方程到抽象結構：本書的路線圖

本書的主線，是講述代數如何在九百年間完成三次昇華：

1. **技術→學科**（820–1545）：從 al-Khwarizmi 的操作手冊，到 Cardano《大術》的系統理論。
2. **學科→語言**（1770–1830）：Lagrange 預感「方程的可解性藏於其對稱之中」，Abel 與 Galois 把對稱對象化，**群**誕生。
3. **語言→結構之眼**（1870–1950）：Dedekind、Noether、van der Waerden 把群、環、體、模統一為公理體系，代數成為研究一切「運算結構」的普適語言。

### 一個具體例題

**例題 1.1.1**：用 al-Khwarizmi 的還原—對消方法，解 $x^2 + 10x = 39$，並用他的幾何拼圖法驗證。

**解**：此方程屬於「方與根等於數」型。

第一步（代數解法）：按他的公式，

$$
x = \sqrt{\left(\frac{10}{2}\right)^2 + 39} - \frac{10}{2} = \sqrt{25 + 39} - 5 = \sqrt{64} - 5 = 8 - 5 = 3.
$$

第二步（幾何拼圖）：作邊長 $x$ 的正方形（面積 $x^2$），在其兩側各接一個 $x \times 5$ 的長方形（面積共 $10x$）。方程說這三塊面積合計為 $39$。在缺角處補上一個 $5 \times 5$ 的小正方形，整體成為邊長 $x+5$ 的大正方形，面積為 $39 + 25 = 64$。故 $x + 5 = 8$，即 $x = 3$。

第三步（驗證）：$3^2 + 10 \times 3 = 9 + 30 = 39$，正確。這正是他書中的原始例題——十進制下完美開方的數字，顯示作者刻意挑選教學友善的例子；但公式本身對任意係數都有效，這正是「公式」優於「逐題拼解」之處。

### 歷史啟示

- **命名即傳承**：一門科學的名稱往往凍結了它的誕生時刻。algebra 來自「還原」這個機械操作，提醒我們抽象科學源於具體技藝。
- **翻譯孕育創造**：巴格達的翻譯運動表明，文明的數學高峰常出現在多種傳統交會處，而非孤立的原創。
- **計算與證明的張力**：al-Khwarizmi 用幾何為代數背書，這種「借來的合法性」是年輕學科的常態；代數要到十九世紀才獲得自己的公理尊嚴。

## 與其他章節及領域的關聯

- **1.2 節**：三次方程的義大利決鬥，是本節「六種標準型」傳統的暴力延伸與終結。
- **2.2 節**：當「解方程」抽象為「研究運算」，群公理登場；本節的 $x \mapsto x^2$ 型操作是其歷史前身。
- **4.3 節**：多項式環把 al-Khwarizmi 的「根與方」升級為嚴格的代數對象。
- **5.3 節**：al-Khwarizmi 的幾何拼圖法正是尺規作圖可作性的原始直觀——用平方補全構造線段。
- **數值分析**：algorithm 一詞的來源提醒我們，代數與計算科學共享同一位父親。
- **數學教育史**：六種標準型的分類教學法，是今日「標準形式」（standard form）教學傳統的源頭。

## 練習

1. 用還原與對消兩步驟，把 $3x + 20 = x^2 - 2x$ 化為 al-Khwarizmi 的標準型之一，並解出正根。
2. 用幾何拼圖法（畫圖或文字描述）解釋 $x^2 + 6x = 16$ 的解法，並驗證 $x = 2$。
3. 說明為什麼沒有負數觀念的代數必須把二次方程分成六型；現代記法下它們合併為哪一型？
4. 查閱資料，說明「algorithm」一詞如何由 Algoritmi 演變而來，並指出它在十九世紀曾被誤寫為 algorism 的原因。
5. 思考題：al-Khwarizmi 只取正根。從「根代表線段長度」的幾何代數觀點，解釋這一限制為何在當時是合理的而非錯誤的。

## 進階研讀：從花拉子米到結構主義的四個深化場景

**場景一：還原操作的現代化身**。al-jabr「把負項搬過去變正」在現代語言中是「兩邊同加」——它依賴加法的可逆性。這種「用逆運算消除元素」的思想，在群論中成為 $g a g^{-1}$ 的共軛操作，在環論中成為理想 $I$ 的商化（見 4.2 節）：把不想要的東西「約去」，正是商結構的本質。八世紀的簿記技術與二十世紀的商代數，共享同一個心理動作。

**場景二：三次翻譯浪潮與代數的三次變形**。伊斯蘭翻譯運動（8–10 世紀）造就了 algebra 的誕生；文藝復興的希臘文本回潮（15–16 世紀）造就了 Cardano 時代的符號化；十九世紀德國大學的講義文化（Gauss–Dedekind–Noether）造就了結構化。每一次「外來文本的吸收」都迫使本土傳統重組自己的語言——這是數學史反覆出現的「輸入—消化—變形」循環。

**場景三：命名的社會學**。比較三個詞的命運：algebra（成功全球化）、almucabola（消失）、algorithm（第二次生命，二十世紀隨計算機復活）。一個術語能否存活，取決於它標記的概念是否成為核心操作。「還原」存活、「對消」消亡，因為現代代數把「對消」吸收進了等價關係的定義而不再需要單獨命名。讀者可借此體會：**術語的存亡是概念地圖變遷的化石記錄**。

**場景四：零與負數的姍姍來遲**。al-Khwarizmi 的六型分類之所以必要，是因為係數不允許為負。印度傳統（Brahmagupta 628 年已給出負數運算法則）與伊斯蘭主流在此分道：後者選擇幾何安全感。負數要到十七世紀才在歐洲獲得普遍承認（Wallis 1685 年仍在辯護），而**代數結構的抽象化恰恰要求容忍「不直觀的元素」**——這是本書第 2 章群公理出現前的心理準備。

### 補充：al-Khwarizmi 之後的伊斯蘭代數譜系

Karaji（約 953–1029）擺脫幾何束縛，首次以純算術方式處理多項式，提出二項式係數表；Omar Khayyam（1048–1131）用圓錐曲線交點系統解決三次方程，並明確意識到三次方程一般無法用尺規求解——這一正確直覺要到十九世紀才獲得嚴格證明（見 5.3 節）；Sharaf al-Din al-Tusi（約 1135–1213）研究三次方程根的存在條件，實質上觸及了判別式與極值分析的邊緣。這條被歐洲數學史長期低估的線索，如今被科學史家重新評價為「代數獨立於幾何」的第一次自覺。

### 深化問答三則

**問：為什麼說 al-Khwarizmi 的書「不是希臘式的，也不是印度式的，而是新東西」？**
答：希臘數學問「圖形有什麼性質」，印度數學問「數怎麼算」，而他的書問「**未知量滿足什麼條件，如何把它系統地逼出來**」——以未知量為主角、以操作程序為方法，這是嶄新的問題姿態。「algebra 是關於未知數的科學」這一定位由他確立。

**問：幾何證明是護身符還是實質？**
答：兩者皆是。就內容而言，拼圖證明對二次方程是實質的——它解釋了公式為何成立；但選擇「幾何」作為證明語言，是文化決定（希臘傳統的權威）。同一個證明若寫成現代恆等式 $(x+\frac b2)^2 = x^2 + bx + \frac{b^2}{4}$，內容不變而地位全變——可見數學敘事的形式承載著時代的認識論。

**問：從本節看，學習抽象代數需要什麼心理準備？**
答：需要接受「操作的合法性先於對象的直觀性」。al-Khwarizmi 的讀者先學會還原與對消，很久之後人類才接受負數；同樣，本書讀者將先使用商群、商環（第 3、4 章），其「直觀意義」往往在最後才豁然開朗。**先做後懂**是代數學固有的學習節奏。
