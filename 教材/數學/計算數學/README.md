# 離散的連續：計算數學的演算法、幾何與結構

> 計算數學不是單純的「程式碼實現」，也不是純粹的「筆記本定理證明」，而是將連續的數學概念離散化、演算法化，並在有限的計算資源與浮點數精確度下，求解複雜數學結構的藝術與科學。它是連接「純粹數學（代數／幾何／分析）」與「現實應用（AI／工程／物理模擬）」的樞紐。
