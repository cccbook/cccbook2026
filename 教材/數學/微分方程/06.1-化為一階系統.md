# 6.1 化為一階系統

## 本章導言

十九世紀末，**Henri Poincaré（龐加萊，1854–1912）** 做了一個改變學科命運的決定：**不要把方程寫成一個高階 ODE，而要寫成一階系統**：

$$
\dot{x} = f(x, y), \qquad \dot{y} = g(x, y).
$$

原因深刻：高階方程的解是「一條曲線 $y(t)$」，而一階系統的解是「狀態空間中的一條軌道」$(x(t), y(t))$——**後者可以畫出來、可以幾何化**。本節講述高階方程與系統的雙向翻譯、矩陣記號、以及這一視角轉換如何孕育了動力系統理論。

### 翻譯：高階方程 → 一階系統

以二階方程 $y'' = F(t, y, y')$ 為例。定義新變數

$$
x_1 = y, \qquad x_2 = y',
$$

則

$$
\dot{x}_1 = x_2, \qquad \dot{x}_2 = F(t, x_1, x_2).
$$

**每個 $n$ 階方程都等價於 $n$ 維一階系統**（一般寫 $\dot{\mathbf{x}} = \mathbf{f}(t, \mathbf{x})$，$\mathbf{x} \in \mathbb{R}^n$）；初值 $y(t_0), \ldots, y^{(n-1)}(t_0)$ 恰好成為向量 $\mathbf{x}(t_0)$ 的分量——3.2 節的存在唯一性定理在系統語言中反而更乾淨：**一點定未來**（在 $\mathbb{R}^n$ 中就是一個向量，而非一串條件）。

**反方向（系統 → 高階）**不總是容易，需要消元與可逆性條件；這正說明**系統是更一般的語言**——高階方程是它的特例。教科書從方程走向系統，歷史則是從系統（力學的哈密頓方程本來就是一階系統）走向「把一切都看成系統」。

### 線性系統與矩陣指數

自治線性系統

$$
\dot{\mathbf{x}} = A\, \mathbf{x}, \qquad A \in \mathbb{R}^{2 \times 2}.
$$

試 $\mathbf{x} = e^{\lambda t}\, \mathbf{v}$（4.2 節指數猜測的矩陣版）：$A\mathbf{v} = \lambda \mathbf{v}$——**特徵值問題**！解的結構完全由 $A$ 的特徵值 $\lambda_{1,2}$ 決定：

| 特徵值 | 軌道行為 | 名稱 |
|--------|----------|------|
| 實、同號 $\lambda_{1,2} < 0$ | 全部軌道流入原點 | 穩定結點（sink） |
| 實、同號 $> 0$ | 流出 | 不穩定結點（source） |
| 實、異號 | 沿一軸進、沿另一軸出 | 鞍點（saddle） |
| 複 $\alpha \pm i\beta$，$\alpha < 0$ | 螺旋收縮 | 穩定焦點（spiral sink） |
| 複，$\alpha > 0$ | 螺旋擴張 | 不穩定焦點 |
| 複，$\alpha = 0$ | 閉合橢圓 | 中心（center） |
| 實，一個為零 | 一條直線不動點線 | 非雙曲（退化） |

**矩陣指數** $\mathbf{x}(t) = e^{At}\, \mathbf{x}_0$ 統一所有情形（$e^{At} = \sum \frac{(At)^n}{n!}$；對角化時 $= P\,\mathrm{diag}(e^{\lambda_i t})\, P^{-1}$）。**行列式的宿命**（4.1 節場景一 Liouville 公式）：$\det e^{At} = e^{\operatorname{tr}(A)\, t}$——**跡的符號決定相面積膨脹或收縮**（阻尼系統 $\operatorname{tr} A < 0$：相空間收縮，機械能耗散的幾何化身）。

### 哈密頓系統：不收縮的相空間

力學的哈密頓方程（Hamilton 1834）：

$$
\dot{q} = \frac{\partial H}{\partial p}, \qquad \dot{p} = -\frac{\partial H}{\partial q}.
$$

發散度 $\nabla \cdot \mathbf{f} = H_{qp} - H_{pq} = 0$——**相空間體積守恆**（Liouville 定理 1838，與 4.1 節的 Liouville 是同名不同定理，皆出 Liouville 之手）。**保守系統的軌道像不可壓縮流體**：不聚焦、不耗散、結點與焦點**不可能**出現（能量守恆禁止一切流入）——中心與鞍點是僅有的平衡。這解釋了為什麼阻尼（$\operatorname{tr} A < 0$）是「走出哈密頓世界」的代價。

### 一個具體例題

**例題 6.1.1**：把阻尼振子 $m\ddot{x} + c\dot{x} + kx = 0$ 化為一階系統，以 $m = 1, c = 2, k = 5$ 分類平衡點，並求通解。

**解**：令 $x_1 = x$、$x_2 = \dot{x}$：

$$
\dot{x}_1 = x_2, \qquad \dot{x}_2 = -5 x_1 - 2 x_2,
\qquad A = \begin{pmatrix} 0 & 1 \\ -5 & -2 \end{pmatrix}.
$$

特徵方程：$\lambda^2 + 2\lambda + 5 = 0$，$\lambda = -1 \pm 2i$。

**分類**：複特徵值、實部 $-1 < 0$——**穩定焦點**（螺旋流入）。原點 = 平衡（擺錘靜止於最低點）。

**通解**：實部衰減 $e^{-t}$、虛部振盪 $\cos 2t, \sin 2t$，分量式

$$
x_1(t) = e^{-t}(A\cos 2t + B\sin 2t),
$$

與 4.2 節例題的阻尼振盪完全一致；但在相平面 $(x_1, x_2)$ 中，解是**向原點收縮的螺線**：每繞一圈，半徑乘 $e^{-\pi} \approx 0.043$。

**能量觀點**：機械能 $E = \frac12 \dot{x}^2 + \frac52 x^2$，求導 $\dot{E} = \dot{x}\ddot{x} + 5x\dot{x} = \dot{x}(-2\dot{x} - 5x) + 5x\dot{x} = -2\dot{x}^2 \le 0$——能量單調衰減；相平面中 $E$ = 常數的橢圓是「無阻尼軌道」，螺線不斷跨越能量橢圓向內跳。**「耗散 = 軌道橫穿等能面」**——這句話是 6.3 節 Lyapunov 方法的第一句台詞。

**歷史評註**：Poincaré 在《論微分方程所定義的積分曲線》（1881–1886 四篇）中建立這套幾何語言時，明確宣稱「**方程的解不是一組公式，而是一幅圖**」。此範式後經 **Aleksandr Lyapunov（1857–1918）**（1892 穩定性專著）、**George Birkhoff**（1910s–20s）發展為動力系統學科；**Stephen Smale**（1960s）的馬蹄映射與 **Lorenz**（1963，7.3 節）把它推向混沌時代。**一次記號的切換，換來一門新數學**。

### 歷史啟示

- **狀態優先於函數**：把「解曲線 $y(t)$」換成「軌道 $\mathbf{x}(t)$」，就是把注意力從「何時在哪」轉向「去往何方」——定性理論的第一原理。
- **特徵值是系統的 DNA**：四類平衡（結點、鞍點、焦點、中心）由兩個特徵值完全分類（6.2 節完整圖譜）；「算特徵值、讀出行為」是線性系統的全部分析流程。
- **跡與行列式的物理**：$\operatorname{tr} A$ 管耗散（體積收縮率），$\det A$ 管平衡類型的乘積判據（$\det > 0$ 且 $\operatorname{tr} < 0$ ⇒ 吸引）。**線性代數不變量 = 動力學不變量**。

- **7.2 節**：極限環——非線性系統中「螺線不收縮到點而收縮到圈」的現象。

- **控制與電路**：狀態空間方法（Kalman 1960）就是本節語言的工程化。

## 練習

1. 把 $y''' + 3y'' + 3y' + y = 0$ 化為 $3 \times 3$ 一階系統，寫出矩陣 $A$ 並求特徵值。
2. 對 $\dot{x} = y$、$\dot{y} = -4x$：求特徵值、分類平衡點、寫出通解，並求出恰當的不變量 $E$（提示：$E = \frac{y^2}{2} + 2x^2$，驗證 $\dot{E} = 0$），說明軌道是橢圓。
3. 計算 $\dot{\mathbf{x}} = A\mathbf{x}$、$A = \begin{pmatrix} -2 & 1 \\ 0 & -3 \end{pmatrix}$ 的通解（三角矩陣，特徵值直接讀出），並驗證 $\det e^{At} = e^{\operatorname{tr}(A) t}$。
4. 考察 Lotka–Volterra 系統（10.2 節預習）$\dot{x} = x(a - by)$、$\dot{y} = y(-c + dx)$：計算發散度 $\partial_x \dot{x} + \partial_y \dot{y}$（不為零！），再驗證不變量 $V = d x - c \ln x + b y - a \ln y$ 沿解恆定——討論「非零發散卻仍有不變量」的幾何意義。
5. 思考題：為什麼「哈密頓系統不可能有吸引子（結點、焦點、極限環）」？請從體積守恆（Liouville 定理）出發論證，並說明這對「保守宇宙中穩態如何存在」的含義。

## 進階研讀：系統觀點的五個深化場景

**場景一：Jordan 塊與重特徵值**。$A = \begin{pmatrix}\lambda & 1 \\ 0 & \lambda\end{pmatrix}$ 給解 $(C_1 + C_2 t) e^{\lambda t}$——重根的 $t$ 因子在系統語言中是 Jordan 塊的冪零作用。**不可對角化 = 解空間「多項式化」**（4.2 節重根的系統版）。臨界阻尼（7.1 節）正是此情形的物理身份。

**場景二：非自治系統與增廣法**。$\dot{\mathbf{x}} = \mathbf{f}(t, \mathbf{x})$ 加一維 $\dot{t} = 1$ 化為自治系統 $\dot{\tilde{\mathbf{x}}} = \tilde{\mathbf{f}}(\tilde{\mathbf{x}})$（$\tilde{\mathbf{x}} = (t, \mathbf{x})$）——**時間本身成為狀態**。受迫振子（7.1 節）由此在三維相空間中變成自治流，其軌道永不交叉的性質（3.2 節）得以運用——Poincaré 截面（7.2 節）技術的前提。

**場景三：Floquet 理論**。週期係數線性系統 $\dot{\mathbf{x}} = A(t) \mathbf{x}$（$A(t + T) = A(t)$）的解 $\mathbf{x}(t) = P(t) e^{Bt}$（Floquet 1883）：**乘性結構**——週期因子乘指數因子；特徵乘子 $e^{\mu T}$ 的模決定參數激發（parametric resonance，鞦韆越盪越高）的穩定性。Mathieu 方程（1868）是其標本；月球軌道、離子阱（Paul trap，1989 諾貝爾獎）都是 Floquet 分析的用戶。

**場景四：Poincaré 截面**。把三維流（如受迫振子的增廣相空間）與固定相位面（$\phi = 0 \bmod 2\pi$）相交，得到**離散映射**（stroboscopic map）。連續流的週期解變成映射的不動點；混沌變成映射的複雜疊代。**降一維、離散化、看疊代**——Poincaré 1899 年為三體問題發明的顯微鏡，7.2、7.3 節的關鍵工具。

**場景五：數值積分的幾何保真**。哈密頓系統的標準數值方法（如顯式 Euler）會讓能量漂移（10.1 節）；**辛積分器**（symplectic integrators, 1980s–）以保持體積/辛結構為設計目標，長期能量誤差有界。分子動力學（蛋白質折疊模擬）與天體力學（太陽系積分）必用之。**數值方法要尊重系統的幾何**——這是本節幾何觀點對 10.1 節的直接回饋。

### 補充：Poincaré 四篇論文的歷史地位

1881–1886 年《論由微分方程定義的曲線》系列中，Poincaré 引入：相空間軌道、平衡點分類、橫截性、指標理論，並第一次遇見「同宿軌道」的複雜行為——他自述解「複雜到連圖都畫不出來」。這些論文是動力系統的獨立宣言。**數學史上罕見：一個人在一系列論文中同時發明語言、定理與未來六十年的問題清單**。

### 補充：為什麼二維自治系統「沒有混沌」

Poincaré–Bendixson 定理（7.2 節）將證明：平面自治系統的緊軌道極限集只能是**平衡點、閉軌、或連接它們的圖**——不可能有混沌。混沌需要 $\ge 3$ 維（連續流）。這解釋了為什麼 Lorenz 系統（7.3 節）必須是三個方程：維數是混沌的入場券。**維數不是量的差別，而是質的門檻**。

### 名詞速查表（本節出現的核心術語）

- **一階系統**：$\dot{\mathbf{x}} = \mathbf{f}(t, \mathbf{x})$；動力系統的標準形式。
- **狀態空間／相空間**：$\mathbf{x}$ 所在的空間；軌道的舞台。
- **矩陣指數**：$e^{At}$；線性系統的解算子。
- **平衡點**：$\mathbf{f}(\mathbf{x}^*) = 0$ 的點；流動停駐處。
- **結點／鞍點／焦點／中心**：特徵值分類的四大平衡類型。
- **Liouville 公式**：$\det X(t) = e^{\int \operatorname{tr} A}$；體積演化律。
- **哈密頓系統**：$\dot q = H_p, \dot p = -H_q$；體積守恆的保守流。
- **Floquet 理論**：週期係統的乘性分解（1883）。
- **Poincaré 截面**：流的閃頻取樣，映射化技術。
- **辛積分器**：保持哈密頓幾何的數值方法。

### 深化問答三則

**問：化為一階系統「只是記號」嗎？**
答：遠不止。記號的變化改變了**可見性**：$y(t)$ 的圖像不能直接顯示「收縮到平衡」還是「趨向週期」，但相平面軌道一眼可辨。這與 1.3 節等角螺線的教訓一致：**選對表示，答案自己浮現**。Poincaré 的天才不在計算，而在選擇觀看的座標。

**問：為什麼系統語言中存在唯一性定理「更乾淨」？**
答：因為初始條件從「一串條件」塌縮為「一個向量」：$\mathbf{x}(t_0) = \mathbf{x}_0$。高階形式中 $n$ 個條件像是 $n$ 個附約；系統形式揭示它們本是**同一個點的 $n$ 個座標**。這是「找到正確的對象，定理自然簡潔」的又一實例（呼應 4.1 節解空間的座標化）。

**問：線性系統的分類（四類平衡）為什麼值得背？**
答：因為非線性系統在平衡點附近「長得像」它的線性化（Hartman–Grobman 定理，6.2 節）——除了少數臨界情況。**線性分類是全部非線性分析的字典**；不懂字典就讀不懂相平面。這也是 1.2 節「線性是特例卻是可教的特例」的最強論證。
