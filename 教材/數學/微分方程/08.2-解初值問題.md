# 8.2 解初值問題

## 本章導言

8.1 節備好了字典與性質；本節把它們裝配成完整的生產線：**初值問題 → 變換域代數方程 → 部分分式 → 逆變換 → 解**。這條流水線的效率驚人：二階非齊次 IVP 常在六行內解完，且每一步無需靈感。本節以完整案例展示流程、討論共振情形的極點處理，並用「極點—行為對照表」把變換域結果翻譯回物理。

### 流水線總覽

解 $y'' + a y' + b y = g(t)$、$y(0) = y_0$、$y'(0) = y_1$：

**第一步：變換**（微分律，8.1 節性質 2）：

$$
(s^2 + as + b)\, Y(s) = G(s) + (s + a)\, y_0 + y_1.
$$

**第二步：解出 $Y$**——**純代數**：

$$
Y(s) = \underbrace{\frac{(s + a) y_0 + y_1}{s^2 + as + b}}_{\text{初值響應（齊次模態）}} + \underbrace{\frac{G(s)}{s^2 + as + b}}_{\text{強迫響應}}.
$$

**注意結構**：分母 $s^2 + as + b$ 就是**特徵多項式**（4.2 節）！其根（極點）決定齊次模態；$G$ 的極點決定強迫成分。**通解 = 特解 + 齊次解的結構（4.3 節）在變換域中一目了然**。

**第三步：部分分式**——把 $Y$ 拆成查表項。

**第四步：逆變換**——逐項查表得 $y(t)$。

### 極點—行為對照表（翻譯字典）

| $Y(s)$ 的極點 | $y(t)$ 的成分 | 物理意義 |
|---------------|----------------|----------|
| $r$ 單實極點 | $Ce^{rt}$ | 指數模態 |
| $r$ 重極點（$k$ 重） | $(C_1 + C_2 t + \cdots + C_k t^{k-1}) e^{rt}$ | 共振（7.1 節） |
| $\alpha \pm i\beta$ | $e^{\alpha t}(C\cos\beta t + D\sin\beta t)$ | 阻尼振盪 |
| $s = 0$ | 常數（階躍響應的終值成分） | 直流/靜態 |
| 左半平面 | 衰減 | 穩定模態 |
| 右半平面 | 增長 | 不穩定（7.1 顫振） |

**工程師讀極點如讀病歷**：極點位置就是系統的命運。這張表是 4.2 節三案例、6.1 節平衡分類、7.1 節共振在變換域的統一入口。

### 一個具體例題（完整流水線）

**例題 8.2.1**：解初值問題

$$
y'' + 3y' + 2y = e^{-t} u(t), \qquad y(0) = 0, \quad y'(0) = 0.
$$

**解**：

**第一步**：$G(s) = \mathcal{L}\{e^{-t}\} = \frac{1}{s + 1}$（$u(t)$ 只表示信號從 0 開始，單邊變換自動處理）。初值皆零，微分律乾淨落地：

$$
(s^2 + 3s + 2)\, Y(s) = \frac{1}{s + 1} \quad\Longrightarrow\quad Y(s) = \frac{1}{(s + 1)^2 (s + 2)}.
$$

**第二步**：部分分式。設

$$
Y(s) = \frac{A}{s + 1} + \frac{B}{(s + 1)^2} + \frac{C}{s + 2}.
$$

蓋住法（cover-up）：$C = \lim_{s \to -2} (s + 2) Y = \frac{1}{(-2 + 1)^2} = 1$。$B = \lim_{s \to -1} (s+1)^2 Y = \frac{1}{-1 + 2} = 1$。$A$：通分比對 $s$ 的一次係數（或取 $s = 0$）：$1 = A(s+1)(s+2)|_{\text{整理}} \cdots$，系統做法：兩邊乘 $(s+1)(s+2)$ 後展開

$$
1 = A(s + 1)(s + 2) + B(s + 2) + C(s + 1)^2,
$$

代入 $C = 1, B = 1$：$1 = A(s^2 + 3s + 2) + s + 2 + s^2 + 2s + 1$。比對 $s^2$ 係數：$0 = A + 1 \Rightarrow A = -1$。（驗證常數項：$1 = 2A + 2B + C = -2 + 2 + 1 = 1$ ✓。）

故

$$
Y(s) = \frac{-1}{s + 1} + \frac{1}{(s + 1)^2} + \frac{1}{s + 2}.
$$

**第三步**：查表逆變換（$t e^{at} \to \frac{1}{(s - a)^2}$ 型，此處 $a = -1$）：

$$
\boxed{\;y(t) = -e^{-t} + t\, e^{-t} + e^{-2t}\;}
$$

**第四步：檢驗與解讀**。$y(0) = -1 + 0 + 1 = 0$ ✓；$y'(0) = (1 - 0) + 1 + (-2)$……細算：$\frac{d}{dt}(t e^{-t}) = (1 - t)e^{-t}$，故 $y'(0) = 1 + 1 - 2 = 0$ ✓。

**行為解讀**：強迫 $e^{-t}$ 與系統的齊次模態 $e^{-t}$ **同頻**——這是**共振**（7.1 節）：響應含 $t e^{-t}$ 項（重極點 $(s+1)^2$ 的時間域簽名，對照表第二行）。但阻尼（$+2$ 模態 $e^{-2t}$）與強迫自身的衰減使振盪有界：$t e^{-t} \to 0$（指數壓過線性），峰值在 $t = 1$ 附近 $y \approx 0.37$，此後衰減歸零。**「與衰減強迫共振」是暫時的放大而非災難**——真正的災難需要**持續**的正頻率強迫（7.1 節 $t\sin\omega_0 t$）。

**歷史評註**：本例的「蓋住法」部分分式技巧在 Heaviside 的運算微積分中已具雛形（他稱之「Heaviside expansion」）；今日的系統化表述歸功於二十世紀教科書。**一個電報工程師的操作，成為全世界的標準技能**。

### 共振情形的極點語言

強迫頻率與齊次模態重合 ⇔ $G(s)$ 的極點與特徵多項式的根**重合** ⇔ 部分分式出現**重極點** ⇔ 時間域出現 $t e^{rt}$ 或 $t\sin\omega_0 t$。**4.3 節的「撞形修正乘 $x^s$」在變換域中就是「重數相加」**——兩種語言的精確互譯：

$$
\text{撞形 } s \text{ 次} \;\Longleftrightarrow\; \text{極點重數 } k = s + 1 \;\Longleftrightarrow\; t^{s} \text{ 因子}.
$$

### 一個具體例題（工程型：階躍輸入）

**例題 8.2.2**：RLC 電路 $q'' + 4q' + 5q = 10 u(t)$（$q(0) = q'(0) = 0$），求電荷 $q(t)$ 與穩態值。

**解**：$G(s) = \frac{10}{s}$，

$$
Y(s) = \frac{10}{s(s^2 + 4s + 5)} = \frac{A}{s} + \frac{Bs + C}{s^2 + 4s + 5}.
$$

$A = \frac{10}{5} = 2$。$1 = A(s^2 + 4s + 5) + (Bs + C) s$：比對 $s^2$：$0 = A + B \Rightarrow B = -2$；$s$：$0 = 4A + C \Rightarrow C = -8$。

$$
Y(s) = \frac{2}{s} - \frac{2s + 8}{s^2 + 4s + 5} = \frac{2}{s} - \frac{2(s + 2)}{(s+2)^2 + 1} - \frac{4}{(s+2)^2 + 1}.
$$

逆變換（配平方完成，$\alpha = 2, \beta = 1$）：

$$
q(t) = 2 - 2 e^{-2t}\cos t - 4 e^{-2t}\sin t \qquad (t \ge 0).
$$

**穩態**：$q(\infty) = 2 = CV$ 型靜態電荷 ✓（終值定理覆核：$\lim_{s\to 0} sY = \frac{10}{5} = 2$ ✓）。**行為**：欠阻尼衰減振盪（$\alpha = 2, \beta = 1$，對數衰減率 $4\pi$）叠加在靜態終值 2 之上——**開關合上後，電荷以約 6.3% 的每週期衰減率「盪」到終值**（7.1 節暫態/穩態語言）。∎

### 歷史啟示

- **代數化的極致**：微分方程的求解被壓縮為「展開分式 + 查表」——**可教、可查、可編程**。1950 年代類比計算機與今日的符號軟體（Mathematica 的 `InverseLaplaceTransform`）都是這條流水線的機械化。
- **極點視角的統一**：4.2 節特徵根、6.1 節特徵值、本節極點、7.1 節共振——**一個代數對象（多項式之根）穿四件衣服**。學會極點視角，振動、控制、濾波、電路是同一門課。
- **驗算文化**：本例的初值檢驗與終值定理覆核成本極低、收益極高——**變換域方法的一個隱藏優點是「檢查點多」**（初值、終值、微分律、極點符號都可以獨立驗證）。

## 進階研讀：初值問題的變換視角五場景

**場景一：零狀態與零輸入分解**。$Y = \frac{\text{初值項}}{\text{特徵多項式}} + \frac{G}{\text{特徵多項式}}$——**零輸入響應**（由初值）與**零狀態響應**（由輸入）天然分解，且兩者對初值/輸入分別線性。系統理論（疊加的工程版）以這個分解為公理級結構。

**場景二：脈衝響應是系統的完整描述**。$\mathcal{L}\{h\} = G(s)$（單位脈衝的響應 = 傳遞函數）：**知道 $h(t)$ 就知道系統的一切**（任意輸入的響應 = 捲積 $h * u$，Duhamel）。8.3 節將以 $\delta$ 正式化；這裡只需知道：**傳遞函數的時域化身是脈衝響應**——測量工程師「敲一下看怎麼震」（modal testing）的理論根據。

**場景三：剛性系統的變換視角**。極點 $-1$ 與 $-10000$ 並存的系統（快慢模態混合，3.3 節場景四）：顯式數值法被快極點鎖死步長；變換域中，「剛性」就是**極點模差距懸殊**。隱式方法（10.1）的 A-穩定性在 $s$ 域中一目了然（映射 $z = \frac{1}{1 - s h}$ 把左半平面映入單位圓）。**剛性是極點幾何，不是方程的道德缺陷**。

**場景四：離散時間的鏡像**。採樣後的系統 $Y(z) = G(z) U(z)$，極點在單位圓內外決定穩定（6.1 節場景五）。連續 $s$ 平面 → 離散 $z$ 平面的映射 $z = e^{sT}$：**左半平面映到單位圓內**——兩個世界的穩定域互為鏡像。數位控制（飛控、馬達驅動）的穩定性證明都在 $z$ 域完成。

**場景五：從部分分式到譜分解**。高階系統的傳遞函數 $G(s) = \sum \frac{R_i}{s - p_i}$（留數展開）：**留數 $R_i$ = 各模態的「權重」**，由極點—零點幾何決定。留數理論（複分析，Cauchy 積分公式）是 Bromwich 積分的引擎——**部分分式不是技巧，是 Cauchy 留數定理的初等化身**。

### 補充：為什麼「蓋住法」有效

$\frac{A}{s + 1}$ 的係數 $A = \lim_{s \to -1} (s + 1) Y(s)$——這正是**留數**（複分析語言）：$A = \operatorname{Res}_{s = -1} Y$。蓋住法不是小聰明，是 Cauchy 積分公式的一次應用。**中學代數技巧的底下埋著十九世紀最深定理**——數學的分層結構常以這種方式咬合。

### 補充：終值定理的陷阱

$f(\infty) = \lim_{s \to 0} s F(s)$ **只在** $F$ 的極點全在左半平面（除可能單極點在原點）時成立。反例：$f(t) = \sin t$，$F = \frac{1}{s^2 + 1}$，$\lim_{s\to 0} sF = 0$ 但 $f(\infty)$ 不存在（振盪不止）。**定理的條件不是修辭，是防彈衣**——工程考試與真實設計中，誤用終值定理的「穩態為零」結論曾導致真實事故。查極點，再用定理。

### 深化問答三則

**問：初值為零（零狀態）的問題，變換法與 4.3 節經典法哪個快？**
答：多數情況變換法快（無需猜特解、無需匹配常數），尤其輸入是 $e^{-t}$、$u(t)$、$\sin$ 等查表族時。但若輸入複雜（如 $\sec t$），$G(s)$ 本身難求，經典法（參數變異）反而可用。**方法選擇的準則是「表示成本」**：哪個空間裡問題更簡單，就在哪個空間工作（6.1 節的座標選擇哲學）。

**問：為什麼「共振」在變換域中那麼顯眼（重極點）？**
答：因為變換域把「頻率匹配」從時間域的動態現象壓縮成**代數的重合**：$G$ 的極點與分母的根重疊 → 部分分式分母的冪升高 → 時域多項式因子。**時間域的「能量累積過程」在 $s$ 域只是一次代數接觸**——這就是變換視角的壓縮魔力（對比 7.1 節的能量收支敘事：同一現象，兩種解析度）。

**問：變換法有解不了的情況嗎？**
答：有，且邊界清晰：（1）$g$ 無指數階（如 $e^{t^2}$）；（2）變係數方程（$t y'' + y' = 0$ 型——變換產生 $s$ 域微分方程，只對 Euler 型（5.1 節場景）友好）；（3）非線性方程（乘積 $y y'$ 變成 $s$ 域捲積——換了形式沒換難度）。**Laplace 是線性常係數的專屬武器**；它的成功恰好丈量了「線性常係數」這個王國的面積。
