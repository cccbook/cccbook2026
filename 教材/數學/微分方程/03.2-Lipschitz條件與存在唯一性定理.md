# 3.2 Lipschitz 條件與存在唯一性定理

## 本章導言

「初值問題有解嗎？解唯一嗎？」這兩個問題在 1890 年前後由 Picard 與 **Rudolf Lipschitz（利普希茨，1832–1903）** 的聯合遺產給出教科書形式的答案。本節正式陳述**Picard–Lindelöf 定理**（存在唯一性定理），剖析 Lipschitz 條件的意義，並以 $y' = 2\sqrt{|y|}$ 等經典反例展示條件失效時的「多重未來」現象。這是全書理論的高峰之一：它把「初值決定未來」的決定論，變成有精確條件的定理。

### Lipschitz 條件：一種溫和的「不許太陡」

**定義**：$f(x, y)$ 在區域 $D$ 上對 $y$ 滿足 **Lipschitz 條件**，若存在常數 $L$（Lipschitz 常數）使

$$
|f(x, y_1) - f(x, y_2)| \le L\, |y_1 - y_2| \qquad \forall (x, y_1), (x, y_2) \in D.
$$

幾何意義：固定 $x$，$f$ 對 $y$ 的圖像被兩條斜率 $\pm L$ 的直線夾住——**斜率場的「豎直傾斜度」一致有界**。

**與可微性的關係**：

$$
f_y \text{ 連續且 } |f_y| \le L \;\Longrightarrow\; f \text{ 滿足 Lipschitz 條件（由均值定理）};
$$

反之，Lipschitz 函數**未必可微**（如 $f(y) = |y|$，$L = 1$）。可見 Lipschitz 條件**嚴格弱於**連續可微、**嚴格強於**連續——它恰好卡在「足夠好以保唯一、足夠寬以容納 $|y|$ 這類尖角」的位置。

| 條件 | 存在性 | 唯一性 | 例 |
|------|--------|--------|-----|
| $f$ 連續 | ✓（Peano 定理，1890） | ✗ | $y' = 2\sqrt{|y|}$ |
| $f$ 對 $y$ Lipschitz | ✓ | ✓ | $y' = y^2$（局部）、$y' = \|y\|$ |
| $f_y$ 連續 | ✓ | ✓ | 大多數「好」方程 |

**Peano 定理**：**Giuseppe Peano（皮亞諾，1858–1932）** 1890 年證明：僅 $f$ 連續就足以保證**存在**（用緊性 + Arzelà–Ascoli 列緊論證，非建構性）。存在與唯一需要的條件不同——這是十九世紀末微分方程理論的精緻成果。

### 主定理：Picard–Lindelöf（存在唯一性）

> **定理**：設 $f(x, y)$ 與 $f_y(x, y)$ 在矩形 $R = \{|x - x_0| \le a,\ |y - y_0| \le b\}$ 上連續。令 $M = \max_R |f|$，$\alpha = \min\big(a, \frac{b}{M}\big)$。則初值問題
> $$
> y' = f(x, y), \qquad y(x_0) = y_0
> $$
> 在 $|x - x_0| \le \alpha$ 上有**唯一**解。

**證明骨架**（三幕劇，讀者已在本書 3.1 節看過第一幕）：

1. **化為積分方程**（3.1 節）：$y = y_0 + \int_{x_0}^x f(t, y)\, dt$。
2. **Picard 疊代收斂**：$f_y$ 連續 $\Rightarrow$ Lipschitz（常數 $L$）$\Rightarrow$ 在 $|x - x_0| \le \alpha$ 上 Picard 算子壓縮（必要時取 $\alpha' < \min(\alpha, 1/L)$ 分兩段工作）$\Rightarrow$ Banach 不動點給出收斂解 $y$。
3. **唯一性**（Grönwall 引理）：設 $u, v$ 都是解，$w = |u - v|$ 滿足 $w(x) \le L \int_{x_0}^x w(t)\, dt$。**Grönwall 不等式**（1919 由 Thomas Hakon Grönwall 系統化）逼出 $w \equiv 0$：

$$
w(x) \le \frac{(L(x - x_0))^n}{n!} \sup w \to 0 \quad (n \to \infty).
$$

**1926 年瑞典數學家 Torsten Grönwall（1877–1932）** 之前的版本由 Peano 等人零星使用；今日 Grönwall 不等式是非線性微分方程估計的萬用扳手，出現在穩定性理論（6.3 節）、數值誤差分析（10.1 節）等處。

**命名注記**：德國數學家 **Ernst Lindelöf（林德勒夫，1870–1946）**（分析學大家，其子羅爾夫是著名拓撲學家）在 1894 年給出更一般條件下的證明，故歐洲文獻常稱 **Cauchy–Lipschitz 定理**（法國傳統）或 **Picard–Lindelöf 定理**（德國傳統）——**同一定理至少四個名字**，見證十九世紀末歐洲多國並進的分析學黃金期。

### 經典反例：條件失效的多重未來

**例**：$y' = 2\sqrt{|y|}$、$y(0) = 0$。$f(y) = 2\sqrt{|y|}$ 連續，故解存在（Peano）；但 $f_y = \frac{1}{\sqrt{|y|}}$ 在 $y = 0$ 爆炸，Lipschitz 失效。後果——**無窮多解**：

$$
y(x) = 0; \qquad y(x) = x^2 \ (x \ge 0),\ y = 0\ (x < 0); \qquad \text{以及任意「延遲起跑」} \ y = (x - c)^2\ (x \ge c),\ 0\ (x < c).
$$

物理圖像：一輛車停在原點，可以永遠不動，也可以**在任意時刻自行起跑**（滿足方程！）。這不是數學怪癖，而是「非唯一 = 系統內含選擇自由」的模型：相變、自發對稱破缺、及臨界點現象的數學原型。

第二個經典：$y' = y^{2/3}$、$y(0) = 0$ 同型；第三個：$y' = x e^{-y^2}$ 之類（$f$ 連續但 $f_y$ 有界嗎？——有界，故其實唯一。反例的精確性很重要）。

### Grönwall 不等式：估計的瑞士刀

> **Grönwall 不等式（簡化版）**：若連續函數 $w \ge 0$ 滿足 $w(t) \le A + B\int_0^t w(s)\, ds$（$A, B \ge 0$ 常數），則 $w(t) \le A e^{Bt}$。

證明思路：令 $z(t) = A + B\int_0^t w$，則 $z' = Bw \le Bz$，故 $(e^{-Bt} z)' \le 0$，$z \le A e^{Bt}$。**「把積分不等式變微分不等式」**——這一招把靜態估計變成動態傳播估計，是 6.3 節 Lyapunov 穩定性證明與 10.1 節數值誤差界的共同引擎。

### 定理的三個推論

1. **階數與常數**（1.1 節的經驗法則成立）：$n$ 階方程 $y^{(n)} = f(x, y, \ldots, y^{(n-1)})$、初值 $y(x_0), \ldots, y^{(n-1)}(x_0)$ 給定——化為 $n$ 維一階系統後定理適用，解唯一，故通解恰有 $n$ 個自由參數。
2. **解對初值的連續依賴**：$|y(x; y_0) - y(x; \tilde y_0)| \le |y_0 - \tilde y_0|\, e^{L|x - x_0|}$——初值的小誤差只造成（至多指數增長的）小偏差。這是「可預測性」的嚴格表述；7.3 節將看到指數增長如何在混沌系統中壓垮這份承諾。
3. **解不能「交叉」**：兩個不同的解曲線不能相交（相交則由唯一性合而為一）。這個拓撲事實是相平面分析（6.2 節）的基礎。

### 一個具體例題

**例題 3.2.1**：對初值問題 $y' = x^2 + y^2$、$y(0) = 0$，在矩形 $R = \{|x| \le 1, |y| \le 1\}$ 上驗證 Picard–Lindelöf 條件，計算保證區間，並證明解在 $[0, \alpha]$ 上唯一。

**解**：$f = x^2 + y^2$，$f_y = 2y$。在 $R$ 上：$|f| \le 1 + 1 = 2 = M$；$|f_y| = 2|y| \le 2 = L$（連續 ✓，Lipschitz 常數 $L = 2$）。

保證區間：$\alpha = \min\big(a, \frac{b}{M}\big) = \min\big(1, \frac{1}{2}\big) = \frac12$。

由定理，解在 $[-\frac12, \frac12]$ 上存在且唯一。收斂率 $L\alpha = 2 \times \frac12 = 1$——恰在壓縮臨界，取更細的 $\alpha' = \min(\frac12, \frac{1}{L} \cdot 0.9) = 0.45$ 則 $L\alpha' = 0.9 < 1$，疊代收斂誤差按 $0.9^n$ 衰減。

**延拓的預告**：實際上（可由比較論證與數值觀察）此解存在到某個有限正值 $x^* \approx 0.96$ 附近才爆破（$y \to \infty$）。定理的 $\alpha = 0.5$ 是保守下界；3.3 節的延拓理論將解釋：**只要解保持有界且遠離 $f$ 的不良區域，就能一路延拓**。解的死亡不是時間到了，而是「撞牆」——此處的牆是無窮遠。

### 歷史啟示

- **決定論獲得條款**：Laplace 之妖（1814）說「知初值即知未來」；Picard–Lindelöf 說「**在 Lipschitz 條件下**，初值唯一決定未來」。決定論從哲學斷言變成數學定理——附帶條件。
- **反例的教學價值**：$y' = 2\sqrt{|y|}$ 用一個初等函數粉碎了「連續就唯一」的直覺。好反例比十個正例更能劃定理論邊界。
- **條件的精緻化是活的研究**：Carathéodory（1918）把條件放寬到可測函數；Osgood 條件（1898）用 $\omega(|y_1 - y_2|)$ 模組化；今日的非唯一性理論連接微分包含（differential inclusions）與最優控制。**定理的「邊界」本身是學科**。

## 與其他章節及領域的關聯

- **3.1 節**：本定理的建構性半邊（疊代收斂）。
- **3.3 節**：解的最大存在區間與延拓；「撞牆」的分類。
- **6.2 節**：「解不交叉」支撐相平面軌道的整體結構。
- **6.3 節**：Grönwall 不等式是 Lyapunov 穩定性證明的關鍵估計。
- **7.3 節**：連續依賴的指數界 $e^{Lt}$ 在 Lorenz 系統中成為「誤差爆炸」——同一定理的另一面。
- **10.1 節**：數值方法的收斂性證明以 Grönwall 為核心（Euler 法誤差 $O(h)$ 的證明）。
- **物理**：牛頓力學的可預測性 = Picard–Lindelöf + 連續依賴；混沌 = 連續依賴中指數因子的不可忽視性。
- **PDE**：對應的存在唯一性（Cauchy–Kowalevski 定理 1875，解析係數情形）是十九世紀 PDE 理論的起點。

2. 證明 $f_y$ 連續且 $|f_y| \le L$ 時 $f$ 滿足 Lipschitz 條件（用均值定理）。
3. 用 Grönwall 不等式證明唯一性：設 $u, v$ 為 $y' = f(x, y)$、同一初值的兩解，$f$ Lipschitz 常數 $L$，導出 $|u - v| \equiv 0$。
4. 對 $y' = 1 + y^2$、$y(0) = 0$ 在 $R = \{|x| \le 1, |y| \le 1\}$ 求保證區間；真解 $y = \tan x$ 的爆破點在哪裡？比較並評論定理的保守性。
5. 思考題：$y' = 2\sqrt{|y|}$、$y(0) = 0$ 的解族包含「延遲 $c$ 起跑」的解。請解釋：為何初值條件 $y(0) = 0$ 無法區分它們？若改成 $y(0) = 1$，解是否唯一？（檢查 $y = 1$ 處 $f_y$ 的行為。）

## 進階研讀：存在唯一性的五個深化場景

**場景一：Peano 存在的代價——非建構性**。Peano 的證明用 Arzelà–Ascoli 緊性抽出收斂子列，**不給出具體是哪一個解**。建構性（Picard）與緊性（Peano）是存在性證明的兩大範式：前者附贈算法，後者覆蓋更寬條件。二十世紀直覺主義學派（Brouwer、Bishop）堅持只接受建構性存在——數學哲學的分野在此有具體案例。

**場景二：Osgood 條件與唯一的精細刻畫**。1898 年 **William Osgood（1864–1943）** 證明：若 $|f(x, y_1) - f(x, y_2)| \le \omega(|y_1 - y_2|)$ 且 $\int_0^\epsilon \frac{du}{\omega(u)} = \infty$，則唯一。檢驗：$\omega(u) = \sqrt u$ 給 $\int_0^\epsilon u^{-1/2} du < \infty$——不唯一（正確！）；$\omega(u) = u|\ln u|$ 給 $\int \frac{du}{u \ln u} = \infty$——唯一。**唯一性的邊界由一個積分的斂散性決定**——異常精緻的臨界現象。

**場景三：解對參數的依賴**。方程 $y' = f(x, y, \lambda)$ 的解 $y(x; \lambda)$ 對 $\lambda$ 光滑（若 $f_\lambda$ 連續）——**微擾理論**（天體力學、量子力學）的合法性來源。攝動法（1.2 節場景二）不是技巧，是定理：解作為參數函數的光滑性由 Picard–Lindelöf 的強化版本保證。

**場景四：隨機微分方程**。$dX_t = b(X_t)\, dt + \sigma(X_t)\, dW_t$ 的存在唯一性（Itô 1942、Kiyosi Itô 1915–2008）是 Picard–Lindelöf 的隨機版：Lipschitz 條件照用，但「收斂」的意義變成均方收斂。金融定價、粒子濾波、隨機控制都站在這個定理上——**確定性理論的骨架在隨機世界幾乎原樣保留**。

**場景五：當唯一性崩塌時——微分包含**。非唯一系統可用**微分包含** $y' \in F(x, y)$（集值映射）統一處理：所有解的集合本身是良定義對象。最優控制（Pontryagin 1956）、可達集分析、機器人路徑規劃都活在「解集合」而非「唯一解」的世界裡——**放棄唯一性後，數學不是變空了，而是變成集合論的**。

### 補充：Lipschitz 的人生速寫

Rudolf Lipschitz（1832–1903）出生於普魯士王國（今波蘭境內的 Königshütte）的猶太家庭，任職波昂大學四十餘年。他的名字以「Lipschitz 條件」進入所有教科書，但他本人的主要工作在代數（Clifford 代數的獨立發現者之一）、位勢理論與力學。**科學史的反諷：一個人被記住的往往不是他最用力的地方**——與此對照，Peano（記憶以皮亞諾公理與符號邏輯聞名）倒是在存在性定理上真正投入了大量心力。

### 補充：Grönwall 不等式的離散版

數值分析用的是離散 Grönwall：$w_{n+1} \le A + B h \sum_{k \le n} w_k \Rightarrow w_n \le A e^{B n h}$。它是 10.1 節證明「Euler 法誤差 $\le C h$」的唯一工具——連續理論與離散理論由同一個不等式縫合。**一個好不等式的形狀，決定一整個領域的證明風格**。

### 名詞速查表（本節出現的核心術語）

- **Lipschitz 條件**：$|f(x, y_1) - f(x, y_2)| \le L|y_1 - y_2|$。
- **Lipschitz 常數**：上式中的最小可行 $L$。
- **Picard–Lindelöf 定理**：$f, f_y$ 連續時初值問題局部存在唯一。
- **Peano 定理**：$f$ 連續時解存在（未必唯一）。
- **Grönwall 不等式**：$w \le A + B\int w \Rightarrow w \le A e^{Bt}$。
- **局部 Lipschitz**：在每點的小鄰域內 Lipschitz（全域未必）。
- **連續依賴**：初值微變導致解微變；量化為 $e^{Lt}$ 界。
- **解不交叉**：唯一性的幾何推論。
- **Osgood 條件**：$\int_0^\epsilon \frac{du}{\omega(u)} = \infty$ 時唯一的模組化判準。
- **微分包含**：$y' \in F(x, y)$，非唯一系統的統一框架。

### 深化問答三則

**問：為什麼存在性需要的條件比唯一性弱？**
答：存在性只需「斜率場有定義且連續」——緊性就能擠出極限；唯一性需要「斜率場不許分岔」——這是斜率場對 $y$ 的橫向敏感性控制（Lipschitz）。存在是「有」，唯一是「只一個」，後者天然更強。物理上：動力學方程給出流（存在），但若斜率場在臨界點「發散性變化」（如 $\sqrt{|y|}$），流可以分岔成多條軌道（非唯一）——自發破缺的數學形狀。

**問：定理給的區間 $\alpha = \min(a, b/M)$ 為何要這樣取？**
答：因為疊代要讓 $\phi_n$ 留在矩形 $R$ 內（$f$ 只在 $R$ 上被控制）。$b/M$ 保證「以最大斜率 $M$ 走 $\alpha$ 步長，豎直位移不超過 $b$」——**解不溜出研究窗口**。這是「理論在局部工作、靠延拓拼裝全局」的典型安排：先保安全，再談遠行（3.3 節）。

**問：連續依賴定理與混沌矛盾嗎？**
答：不矛盾，而是精確互補。連續依賴說：誤差 $\delta_0$ 經時間 $t$ 至多變成 $\delta_0 e^{Lt}$——這在**有限時間**內是可用的；混沌說：$L > 0$ 時誤差按 $e^{Lt}$ **指數放大**，可預測時域 $\sim \frac{1}{L}\ln\frac{\Delta}{\delta_0}$ 對 $\delta_0$ 只對數敏感。同一定理：短時間可信、長時間失控——**決定論與可預測性的分離（1.1 節場景四）在此獲得定量形式**。
