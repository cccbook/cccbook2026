# 8.1 Laplace 變換的定義與性質

## 本章導言

第 2、4 章的解法都是「直接動手」；**Laplace 變換**是另一種哲學：**把問題搬到另一個空間去解，再搬回來**。變換

$$
\mathcal{L}\{f\}(s) = F(s) = \int_0^{\infty} e^{-st} f(t)\, dt
$$

把微分運算變成**乘法**（$\mathcal{L}\{f'\} = sF - f(0)$）——微積分問題在變換域中是**代數**問題。這個方法由 **Pierre-Simon Laplace（拉普拉斯，1749–1827）** 在機率論（1782《機率的解析理論》前身工作）中發展，**Oliver Heaviside（亥維賽，1850–1925）** 在 1880–1890 年代把它打造成電報工程的操作工具（以完全不合邏輯但屢試不爽的「運算微積分」），嚴格化（Bromwich 積分 1916、Carson 1920s、Doetsch 1930s 教科書化）晚了三十年。**工程實踐又一次跑在數學嚴格化前面**。

### 定義與存在條件

$$
F(s) = \mathcal{L}\{f(t)\} = \int_0^\infty e^{-st} f(t)\, dt \qquad (s \in \mathbb{C}).
$$

**存在定理**：若 $f$ 在 $[0, \infty)$ 分段連續，且**指數階**（$|f(t)| \le M e^{ct}$），則 $F(s)$ 對 $\operatorname{Re} s > c$ 存在且解析。

**基本積分表**（由定義直算）：

| $f(t)$ | $F(s)$ | 條件 |
|--------|--------|------|
| $1$ | $\dfrac{1}{s}$ | $\operatorname{Re} s > 0$ |
| $t^n$ | $\dfrac{n!}{s^{n+1}}$ | 同上 |
| $e^{at}$ | $\dfrac{1}{s - a}$ | $\operatorname{Re} s > \operatorname{Re} a$ |
| $\sin\omega t$ | $\dfrac{\omega}{s^2 + \omega^2}$ | |
| $\cos\omega t$ | $\dfrac{s}{s^2 + \omega^2}$ | |
| $e^{at}\sin\omega t$ | $\dfrac{\omega}{(s - a)^2 + \omega^2}$ | 頻移律 |
| $t\, e^{at}$ | $\dfrac{1}{(s - a)^2}$ | $s$-微移律 |

**觀察**：$F(s)$ 的**極點位置**（分母零點）編碼了 $f(t)$ 的行為——$s = a$ 處極點 ⇔ $e^{at}$ 成分；$\pm i\omega$ 處極點 ⇔ $\sin/\cos$ 成分。**變換域的代數結構 = 時間域的函數行為**——這是「另一個空間」視角的又一次勝利（呼應 4.2 節特徵方程：兩者其實是同一代數！特徵多項式 $ar^2 + br + c$ 與 Laplace 域分母 $as^2 + bs + c$ 逐字相同）。

### 六大運算性質：方法的心臟

1. **線性**：$\mathcal{L}\{af + bg\} = aF + bG$。
2. **微分**：$\mathcal{L}\{f'\} = sF(s) - f(0)$；推廣 $\mathcal{L}\{f''\} = s^2 F - s f(0) - f'(0)$——**初值自動入帳**！
3. **積分**：$\mathcal{L}\{\int_0^t f\} = \dfrac{F(s)}{s}$。
4. **頻移**（第一平移）：$\mathcal{L}\{e^{at} f\} = F(s - a)$。
5. **時移**（第二平移，Heaviside 函數）：$\mathcal{L}\{u(t - a) f(t - a)\} = e^{-as} F(s)$。
6. **捲積**：$\mathcal{L}\{(f * g)(t)\} = F(s) G(s)$，其中 $(f*g)(t) = \int_0^t f(\tau) g(t - \tau)\, d\tau$——**捲積變乘法**，Duhamel 原理（4.3 節場景二）的代數化。

**性質 2 是整套方法的鑰匙**：初值問題

$$
y'' + 3y' + 2y = g(t), \quad y(0) = y_0,\ y'(0) = y_1
$$

兩邊變換：

$$
(s^2 Y - s y_0 - y_1) + 3(sY - y_0) + 2Y = G(s) \quad\Longrightarrow\quad Y(s) = \frac{(s + 3) y_0 + y_1 + G(s)}{s^2 + 3s + 2}.
$$

**一次代數運算同時處理方程與初值**——沒有通解、特解之分，沒有待定係數的猜測。**這是 4.3 節兩法之外的第三條路，且是機械化的**。

### 逆變換：怎麼搬回來

$$
f(t) = \mathcal{L}^{-1}\{F\}(t) = \frac{1}{2\pi i} \int_{\gamma - i\infty}^{\gamma + i\infty} e^{st} F(s)\, ds \qquad \text{（Bromwich 積分，1916）}.
$$

實務上**不積分**：部分分式 + 查表。例：$Y(s) = \frac{2s + 3}{(s + 1)(s + 2)} = \frac{1}{s + 1} + \frac{1}{s + 2}$，逆變換 $y(t) = e^{-t} + e^{-2t}$。**部分分式 = 把變換域的「極點結構」翻譯回時間域的「指數組合」**——4.2 節特徵根與本節極點的逐字對應在此兌現：**同一個代數，兩種語言**。

### 一個具體例題

**例題 8.1.1**：求 $\mathcal{L}\{t \sin 2t\}$，並用其結果導出 $\mathcal{L}\{t e^{3t} \sin 2t\}$。

**解**：

**核心恆等式（$s$-微移律）**：$\mathcal{L}\{t f(t)\} = -\dfrac{d}{ds} F(s)$。

**證明**：$F(s) = \int_0^\infty e^{-st} f\, dt$，對 $s$ 求導（合法：一致收斂保證積分號下求導）：

$$
F'(s) = \int_0^\infty (-t)\, e^{-st} f(t)\, dt = -\mathcal{L}\{t f(t)\}. \;✓
$$

**第一步**：$F(s) = \mathcal{L}\{\sin 2t\} = \frac{2}{s^2 + 4}$，故

$$
\mathcal{L}\{t \sin 2t\} = -\frac{d}{ds} \frac{2}{s^2 + 4} = \frac{4s}{(s^2 + 4)^2}.
$$

**第二步（頻移律）**：$\mathcal{L}\{e^{3t} g(t)\} = G(s - 3)$，其中 $G = \mathcal{L}\{t\sin 2t\} = \frac{4s}{(s^2 + 4)^2}$：

$$
\mathcal{L}\{t e^{3t} \sin 2t\} = \frac{4(s - 3)}{\big[(s - 3)^2 + 4\big]^2}.
$$

**解讀**：時間域的「乘 $t$」是 $s$ 域的「求導」（微移律）；時間域的「乘 $e^{3t}$」是 $s$ 域的「平移」（頻移律）——**兩個空間的操作互為鏡像**。這種鏡像字典（時域微分 ⇔ $s$ 域乘 $s$；時域捲積 ⇔ $s$ 域乘積；時域平移 ⇔ $s$ 域乘 $e^{-as}$）就是 Laplace 變換的全部力量來源。

### 歷史啟示

- **工程先於嚴格**：Heaviside 的運算微積分（把 $D$ 當代數量除、用 $p = \partial_t$「除法展開」函數）被同代數學家斥為「無根基」，他回敬：「**我不拒絕我的晚餐，只因為我不完全了解消化過程**。」1916 年 Bromwich 以圍道積分嚴格化，證明 Heaviside 基本全對——**實用主義者的直覺 + 後來者的嚴格 = 現代教科書**（重演 1.3 節 Leibniz 分數記號的劇本）。
- **兩個空間的哲學**：對數把乘法變加法、Fourier 把捲積變乘積、Laplace 把微分變乘法——**「變換」是人類對抗運算複雜性的通用武器**。Laplace 變換是其中最工程化的一個。
- **初值內建**：4.3 節需要「通解 + 定常數」兩步；Laplace 一步到位。**問題表示法的改進，等價於算法的改進**（6.1 節「化為系統」的教訓再現）。

## 與其他章節及領域的關聯

- **4.2 節**：特徵多項式 = Laplace 域分母；重根 = 重極點（部分分式多項式因子）。
- **4.3 節**：非齊次問題的第三解法；待定係數的撞形修正對應部分分式的重極點處理。
- **8.2 節**：完整 IVP 求解流程。
- **8.3 節**：Heaviside 函數（時移律）、脈衝（$\delta$ 函數）、方波、鋸齒——工程輸入的全譜。
- **9.1 節**：分離變數的時間因子 $e^{-\alpha \lambda t}$ 的 Laplace 變換 $\frac{1}{s + \alpha\lambda}$——PDE 求解中的常客。
- **控制理論**：傳遞函數 $G(s) = \frac{Y(s)}{U(s)}$、極點—零點配置、Bode 圖——**整個自動控制建立在變換域**；7.1 節的 $Q$ 對應極點與虛軸的距離。
- **機率論**：矩母函數 $E[e^{sX}]$ 是隨機變數的 Laplace 變換；更新過程、排隊論用它解積分方程。
- **PDE 與積分方程**：對 $t$ 做 Laplace 把熱方程/波方程變成 ODE（半無限域問題尤甚）。

## 進階研讀：變換思想的五個深化場景

**場景一：傳遞函數與系統思維**。零初值線性系統 $Y(s) = G(s) U(s)$——$G(s)$ 是系統的**身份證**：極點（固有模態）與零點（抑制頻率）完全決定輸入輸出行為。Bode（1940）把 $|G(i\omega)|$ 畫成對數圖，Nyquist（1932）用圍道判穩定——**控制工程的全部語言就是 Laplace 域幾何**。

**場景二：初值與終值定理**。$f(0^+) = \lim_{s\to\infty} sF(s)$、$f(\infty) = \lim_{s\to 0} sF(s)$（後者需極點在左半平面）——**不用逆變換就讀出系統的起點與終點**。工程師先查終值（穩態誤差）再查極點（穩定性），全部在 $s$ 域完成。

**場景三：Z 變換——離散世界的工作服**。序列 $y_n$ 的 $\mathcal{Z}\{y\} = \sum y_n z^{-n}$；性質逐條平行 Laplace（$z$ 域平移、捲積變乘積、差分變乘 $z$）。數位濾波器設計（FIR/IIR）以 $z$ 域極零圖為圖紙。**Laplace 的離散表弟統治了所有數位設備**（手機音效、數位相機降噪）。

**場景四：分布的變換**。$\delta(t)$ 的變換是 $1$——**脈衝是變換域的「1」**（乘法單位元）；$\delta'(t) \to s$。Schwartz 分布理論（1945，1.1 節場景）使 Laplace/ Fourier 變換對奇異信號自洽。8.3 節將以 $\delta$ 為主角。

**場景五：兩邊變換與 Green 函數**。對 $t$ 變換 PDE（熱方程）得 ODE 對 $x$；再解、再逆變換，得到**Green 函數的積分表達**（4.1 節場景四）。半無限桿的突然加熱、波導的瞬態激勵——**變換法是「層層降維」的將軍**：PDE → ODE → 代數。

### 補充：Heaviside 的「不講理」操作示範

Heaviside 解 $y' + y = 1$、$y(0) = 0$：寫 $(D + 1) y = 1$，形式除法：

$$
y = \frac{1}{D + 1}\, 1 = (1 - D + D^2 - \cdots)\, 1 = 1 - 1 + 1 - \cdots
$$

——發散級數？他改用「**真分式部分**」：$\frac{1}{D+1}$ 作用於常數 1 給 $1 \cdot (1 - e^{-t})$（正確答案！）。他的理由：「**結果對、夠用、且每次都對**。」1887 年 Poincaré 評其方法「不嚴格但引人深思」。**正確性與合法性在歷史上常常是兩場審判**。

### 補充：為什麼是「單邊」變換（從 0 積到 $\infty$）？

物理初值問題的時間起點是 $t = 0$（開關合上、事件發生）。單邊變換讓 $f(0)$ 自動進入微分律——**初值內建**（性質 2）。雙邊變換（Fourier 的任務）適合穩態/全域信號分析。**單邊管暫態（IVP），雙邊管穩態（譜分析）**——8.3 節的 Heaviside/脈衝是暫態世界的公民，9 章的 Fourier 級數是穩態世界的公民。

### 名詞速查表（本節出現的核心術語）

- **Laplace 變換**：$F(s) = \int_0^\infty e^{-st} f\, dt$。
- **指數階**：$|f| \le Me^{ct}$；變換存在的關鍵條件。
- **微分律**：$\mathcal{L}\{f'\} = sF - f(0)$；初值內建。
- **頻移律 / 時移律**：$e^{at}f \leftrightarrow F(s - a)$；$u(t - a)f(t - a) \leftrightarrow e^{-as}F$。
- **捲積定理**：$f * g \leftrightarrow FG$。
- **部分分式**：極點結構 → 指數組合的翻譯機。
- **Bromwich 積分**：逆變換的圍道積分（1916）。
- **傳遞函數**：$G(s) = Y(s)/U(s)$；系統的變換域身份。
- **Heaviside 運算微積分**：不合邏輯但正確的先驅操作（1880s）。
- **Z 變換**：離散序列的 Laplace 表親。

### 深化問答三則

**問：Laplace 變換與特徵方程（4.2 節）重複嗎？**
答：重複的是**代數**（同一個多項式 $as^2 + bs + c$），不重複的是**覆蓋面**：特徵方程只解齊次常係數；Laplace 解非齊次、處理不連續/脈衝輸入、內建初值、直接讀穩態。**同一把代數鑰匙，Laplace 打開的門多得多**——但也更費工（部分分式）。小問題用手算特徵方程，工程問題用 Laplace，是自然的分工。

**問：為什麼 Heaviside 的「不合法」操作能給出正確答案？**
答：因為背後有定理（雖然他不知道）：他操作的所有對象（指數階信號）都在變換一一對應的範圍內，他的「除法」實為變換域的乘除，他的「級數展開」實為部分分式。**非法操作 + 恰好符合後設定理 = 直覺先行**——數學史上大量方法（1.3 節分離法、本節運算微積分、10.1 節的 delta 近似）都是這個劇本。

**問：初值「自動入帳」意味着什麼方法論轉變？**
答：初值從「待定常數」變成「方程的係數」。傳統流程是「解通解 → 匹配初值」兩階段；Laplace 是「一次代數包含全部資訊」。這是**把條件吸收進問題表示**的範式——6.1 節化為一階系統（初值成為向量）與其同源。**好的表示法讓「附加條件」變成「內建參數」**——這是方法設計的高級品味。
