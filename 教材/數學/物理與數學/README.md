# 物理與數學：相互驅動的雙螺旋

* Physics and Mathematics: The Twin Helix of Discovery

本書記錄物理與數學四百年來的相互驅動：物理的危機逼出數學的發明（微積分、傅立葉級數、黎曼幾何、希爾伯特空間、纖維叢），數學的抽象反過來預言並重構物理（規範場論、鏡像對稱、拓撲相、量子資訊）。每一節依「前因 → 構造 → 後果」展開，並標註驅動方向：

- **物理 → 數學**：物理問題催生新數學。
- **數學 → 物理**：既有數學成為新物理的語言或預言工具。
- **雙向**：兩者共演化。
