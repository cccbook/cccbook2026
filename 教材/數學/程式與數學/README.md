## 本書寫作核心觀點

本書的靈魂在於打破「寫 code 的人不懂數學、搞數學的人不會寫 code」的二分法。透過展示 **Lambda 演算與證明的同構**、**型別系統對邏輯的具體實現**，以及 **Lean 等工具如何讓電腦檢驗數學**，讀者將會明白：**現代高階程式設計，本質上就是一門在電腦上執行的、活生生的數學。**
