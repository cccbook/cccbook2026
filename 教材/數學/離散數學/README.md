## 本書寫作核心觀點

離散數學的每一章都不是孤立名詞的堆疊，而是一條驅動鏈：

$$
\text{邏輯（推理）} \to \text{集合（物件）} \to \text{計數（量化）} \to \text{圖（結構）} \to \text{代數（對稱）} \to \text{自動機（計算）}
$$

歷史上的推動力同樣環環相扣：Boole 想把邏輯代數化（1847），Cantor 為 Fourier 級數研究集合（1870s），Euler 為七橋問題發明圖（1736），Gauss 為天文計算發展同餘（1801），Turing 為判定問題造出機器（1936），而 RSA（1977）讓兩千年「無用」的數論成為全球網路的安全基礎。**純數學的耐心，最終都會被工程需求兌現。**
