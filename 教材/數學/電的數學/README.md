# 電的數學

從庫倫的扭秤到光子積體電路——一本以「數學 ⇄ 工程」互相驅動為主軸的電學教科書。每一個電學理論的誕生都是為了回應真實的工程困境；每一個工程突破又反過來催生新的數學。

## 本書的方法論

每節遵循同一敘事結構：

1. **問題**：當時工程/科學面臨什麼困境？
2. **數學**：什麼數學被發明或引入？
3. **後果**：如何改變了技術？
4. **回饋**：技術的反省如何催生新數學？
