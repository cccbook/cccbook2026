# 4.3 1971年：謝林的隔離模型——微觀偏好如何湧現出宏觀秩序

## 1. 問題：美國住宅隔離之謎

1960 年代的美國，住宅隔離極端嚴重（芝加哥、底特律等地黑人社區幾乎完全隔離）。官方解釋有二：歧視性制度（紅線貸款、種族契約）或強烈的種族偏好。但 Thomas Schelling 觀察到一個經驗難題：

> 民意調查顯示大多數白人**不要求**完全隔離——他們只是希望「同種族鄰居占多數」。那麼，**溫和的偏好如何產生完全的隔離**？

這是社會科學的根本之謎：**宏觀秩序（隔離、族群極化、都市分化）是否需要宏觀原因？還是微觀互動就能湧現？**理性選擇傳統（第 1 章）把社會結果歸因於個體偏好；結構傳統（4.1 節）強調位置——謝林要證明：**兩者都對，但方式出人意料**。

## 2. 數學：棋盤上的不動點與湧現

Schelling (1971)《Dynamic Models of Segregation》用紙上棋盤做實驗（當時無電腦模擬之便，此點本身即是社會科學與計算關係的歷史註腳）：

- 棋盤上有兩色棋子（佔多數）與空格；
- 每個棋子有**溫和偏好**：希望鄰居中同色比例至少為 $t$ （例如 $t = 0.5$ ）；
- 不滿足者移動到最近的滿意空格。

核心數學結構：

1. **個體目標函數是局部的**：滿意度 $s_i = \frac{\text{同色鄰居數}}{\text{鄰居數}} \ge t$ ；
2. **系統狀態是全域的**：隔離度 $S =$ 全棋盤同色相鄰對的比例；
3. **關鍵定理式結果**：均衡態（無人再移動，不動點）的隔離度**遠高於** $t$ 。模擬顯示 $t=0.5$ 的溫和偏好導致近乎完全隔離（ $S \to 0.9+$ ）。

```mermaid
graph LR
    A[溫和偏好 t=0.5] --> B[局部移動]
    B --> C[鄰居組成改變]
    C --> D[他人被迫移動: 連鎖]
    D --> E[全域隔離 S >> t]
    E --> F[湧現: 宏觀 != 微觀放大]
```

為什麼？數學直覺：局部移動是**非線性、有反饋**的——你移入一區改變別人的滿意度，引發連鎖遷移；加上空格是**公共資源**（一人移動改變所有人的選項集），個體的局部最適化透過互動放大成極端的集體結構。這正是 2.2 節「個體理性 ≠ 集體理性」的空間版本。

## 3. 後果

- **湧現概念的典範化**：Schelling (1978)《Micromotives and Macrobehavior》將「微觀動機—宏觀行為」確立為社會科學的基本問題；社會學的「結構」概念首次獲得生成式解釋。
- **基於主體的模擬（ABM）誕生**：Epstein 與 Axtell 的 Sugarscape（1996）、Axelrod 的文化傳播模型（1997）把謝林路線擴充為完整的計算社會科學方法論（5.3 節的直接源頭）。
- **政策啟示**：若隔離是湧現的，**廢除歧視法律可能不足以消除隔離**——需要改變互動結構（如學區劃分、住宅補貼的空間安排）。Segregated 美國學區與都市政策的辯論至今引用此模型。
- **普遍適用**：語言分化、政黨極化、飲食習慣、標準鎖定——任何「局部互動 + 溫和偏好」的系統皆然。

## 4. 回饋

謝林模型太簡單，暴露三個數學缺口，每個都催生了新研究：

1. **解析性**：棋盤模擬只有數值結果。Young (1998)、Zhang (2004) 用**勢賽局**（potential game）與馬可夫過程（4.2 節工具回歸！）證明：偏好門檻越高、隔離均衡越穩定，且**隨機擾動下系統長期停在極端隔離態**——溫和偏好 + 噪音 = 更頑固的隔離（與 2.3 節 Kandori–Mailath–Rob 的長期極限思想同構）。
2. **網絡版**：母體不是棋盤而是社會網絡（4.1 節），隔離發生在網絡同質化（homophily）上，與意見動力學（DeGroot 模型、選民模型）結合。
3. **規範問題**：湧現的隔離「沒有人想要」也「沒有人負責」——集體結果的道德歸責問題，把數學模型逼回政治哲學，並連結到 5.1 節：**社會偏好不能由個體偏好加總得到**。

## 5. 延伸思考

1. 湧現的宏觀模式會「反饋」塑造微觀偏好（住在隔離社區 → 更強的內群偏好），形成雙向因果——如何用數學捕捉？（互饋動力學、共演化網絡）
2. 若你是政策設計者，知道隔離是湧現的，「小的結構干預」（如混合住宅的最低比例）是否可能撬動整個均衡？（臨界質量與 tipping，Granovetter 1978 的閾值模型）
