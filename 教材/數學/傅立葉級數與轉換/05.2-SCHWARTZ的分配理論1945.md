# 5.2 Schwartz 的分配理論 1945

## 本章導言

1945 年秋天，在戰後法國被德軍佔領結束的廢墟氛圍中，**Laurent Schwartz（1915–2002）** 在《Annales de l'Institut Fourier》發表論文〈廣義函數理論〉，隨後在 1950–51 年出版兩卷巨著《分配理論》（Théorie des distributions），為 Dirac δ 及其整個家族建造了嚴格而**可運算**的家園。這個理論的洞見驚人地簡單：**不要問「這個奇怪對象是什麼函數」，要問「它如何作用於正常的函數」**——把對象重定義為泛函。本節將建立分配的定義、基本演算（導數、乘法、捲積），展示「無條件可微」的解放，並講述這位數學家在納粹佔領下、以偽造文書逃亡的傳奇經歷——理論的誕生地不是安樂椅，而是躲藏的閣樓。

### Schwartz 其人：抵抗者與公理家

Schwartz 1915 年生於巴黎一個猶太裔富裕家庭（父親是解剖學家，母親來自 Debré 家族——法國政界顯赫世家）。他在師範學院（École Normale Supérieure）受訓，同時是托洛斯基主義政治活動家（終生未改）。1940 年納粹佔領法國後，作為猶太人與左翼活動者的雙重身份使他面臨被遣送集中營的危險。他與妻子 **Marie-Hélène Lévy**（數學家 Paul Lévy 的女兒）逃亡到 Vichy 自由區，靠**偽造的證件與化名（Maréquin）** 輾轉於 Grenoble、Murols 等地，一邊躲藏一邊研究。

正是在這種條件下，Schwartz 統合了當時散落各處的「廣義對象」思想：Sobolev 的弱導數（1936）、Bochner 的廣義函數（1932）、Dirac 的 δ（1930）、Temple 與 Lighthill 的脈衝處理——**他做的不僅是定義，而是建造演算**：分配之間可以加、可以無限次求導、可以乘以光滑函數、可以做捲積、可以做傅立葉變換，且一切經典運算律（線性、Leibniz 律的推廣、捲積代數）在合適範圍內成立。1945 年論文一發表，迅速被 Hörmander、Gelfand、Malgrange 等人接上，成為 20 世紀後半 PDE 理論的通用語言。1950 年首屆**菲爾茲獎**授予 Schwartz——這個獎對「一個新演算」的加冕，標誌著 20 世紀數學價值觀的變化：**好的框架比孤立的定理更偉大**。

### 檢驗函數空間 $\mathcal{D}$ 與分配的定義

**檢驗函數空間** $\mathcal{D}(\mathbb{R}) = C_c^\infty(\mathbb{R})$：**緊支撐的無窮光滑函數**——處處無限可微、且在有限區間外恆為零（「快樂的小帽子」，bump functions）。標準範例：$\varphi(x) = e^{-1/(1-x^2)}$（$|x|<1$）、0（$|x|\ge1$）——**它證明 $\mathcal{D}$ 不是空集**（非零光滑緊支撐函數存在！19 世紀的人曾懷疑這一點）。$\mathcal{D}$ 帶有自然的極限概念（$\varphi_n \to \varphi$：支撐一致有界 + 各階導數一致收斂）。

**分配（distribution）**：$\mathcal{D}$ 上**連續線性泛函**。記 $T(\varphi)$ 或對偶記號 $\langle T, \varphi\rangle$。三個立即的例子：

1. **正則分配**：每個局部可積函數 $f \in L^1_{loc}$ 定義 $T_f(\varphi) = \int f\varphi\,dx$——**普通函數是分配的特例**（嵌入定理：$f \mapsto T_f$ 是單射，$L^1_{loc}$ 完整嵌入 $\mathcal{D}'$）。分配空間 $\mathcal{D}'$ 是函數世界**嚴格的擴張**。
2. **δ**：$T_\delta(\varphi) = \varphi(0)$。**一個泛函，不是任何函數的化身**——正是 5.1 節「一句話定義」的正式化。
3. **Heaviside 的導數**：$T_u(\varphi) = \int_0^\infty\varphi\,dx$；其導數（見下）恰是 $\delta$。

**哲學重述**：經典問題「$\delta$ 的值是多少？」在 $\mathcal{D}'$ 語言中**無意義且不必要**——分配不按點取值，只按檢驗函數取值。「δ 在 0 處無窮大」這句話的分配翻譯是：**不存在任何 $L^1_{loc}$ 函數 $f$ 使 $T_f = T_\delta$**（反證：若 $\int f\varphi = \varphi(0)$ 對一切 $\varphi$，取支撐遠離 0 的 $\varphi$ 得 $f = 0$ a.e.，再取 $0<\varphi\le1$ 支撐含 0 得 $0 = \varphi(0) > 0$，矛盾）。**矛盾證明把「δ 不是函數」變成了定理**——1945 年前這句話只是信念。

### 分配的演算：無限次可微的自由

**導數**：$\langle T', \varphi\rangle = -\langle T, \varphi'\rangle$——**把積分號下的求導「分部積分到檢驗函數頭上」**。這個定義的天才之處：（1）對 $T = T_f$（$f$ 光滑）它恰還原經典導數（分部積分，緊支撐消邊界項）；（2）**它對一切分配、一切階次無條件成立**——$C_c^\infty$ 的函數可微任意次，其對偶空間因此**永遠不缺導數**。「不可微函數」的問題被消解：階躍 $u' = \delta$，$\delta' = $ 偶極，$\delta^{(n)}$ 全部存在且可再運算。

**Leibniz 律**：分配 $T$ 乘以光滑函數 $a$：$\langle aT, \varphi\rangle = \langle T, a\varphi\rangle$；則 $(aT)' = a'T + aT'$ 依然成立（直接驗證）。**光滑係數的世界裡分配運算與函數運算同構**——PDE 理論（9 章）中「係數 × 廣義解」因此毫無障礙。

**不可乘之處**：兩個分配相乘**一般不存在**（$\delta\cdot\delta$ 無定義）——這是理論的**已知邊界**而非缺陷：物理上「兩個瞬時衝擊相乘」本無意義；數學上 Colombeau 代數（1980s）試圖突破此界但代價複雜。**知道演算的邊界，與擁有演算同等重要**。

**平移與縮放**：$\langle T(t - a), \varphi(t)\rangle = \langle T, \varphi(t + a)\rangle$ 型（注意檢驗函數反向變換）。**分配的捲積**：$S * T$ 在至少一方緊支撐時有定義，滿足結合、交換、與微分交換（$(S*T)' = S'*T = S*T'$）——**δ 是單位元**：$\delta * T = T$。4.3 節「缺席的單位元」回家了。

### 一個具體例題

**例題 5.2.1**：（1）驗證 $u' = \delta$（$u$ 為 Heaviside 階躍）在分配意義下成立；（2）計算 $x\,\delta(x) = 0$、$\big(x\,\delta(x)\big)' = \delta$，並證明 Leibniz 律給出自洽結果；（3）解分配意義的 ODE：$xT = 1$（求所有分配解），說明其解集含「經典解 $1/x$（主值）」與「自由項 $c\,\delta$」。

**解**：

（1）$\langle u', \varphi\rangle = -\langle u, \varphi'\rangle = -\int_0^\infty\varphi'(x)dx = -\big(\varphi(\infty) - \varphi(0)\big) = \varphi(0) = \langle\delta, \varphi\rangle$。（用到 $\varphi$ 緊支撐使 $\varphi(\infty) = 0$。）**三行完成**——1945 年前同款論證需要構造近似核序列、估誤差、取極限，費一頁。$\blacksquare$

（2）$\langle x\delta, \varphi\rangle = \langle\delta, x\varphi\rangle = (x\varphi)\big|_{x=0} = 0$，故 $x\delta = 0$。求導（Leibniz）：$(x\delta)' = \delta + x\delta' = \delta$，即 $x\delta' = \delta - \delta = 0$？——**驗證**：$\langle x\delta', \varphi\rangle = \langle\delta', x\varphi\rangle = -\langle\delta, (x\varphi)'\rangle = -(x\varphi)'|_0 = -\varphi(0)$。等一下，$-\varphi(0) = \langle -\delta, \varphi\rangle$，故 $x\delta' = -\delta$！重算 Leibniz：$(x\delta)' = x'\delta + x\delta' = \delta + x\delta'$，而左邊 $(x\delta)' = 0' = 0$，故 $x\delta' = -\delta$ ✓——兩法一致。**自洽性檢查通過**：演算內部一致（初學者常在這裡搞錯符號，動手驗是最好的訓練）。

（3）方程 $xT = 1$（右邊 $1$ 為常數分配）。在 $x \ne 0$ 的開集上（分配限制到檢驗函數支撐遠離 0 的部分），$T = \frac1x$（經典解）。**跨奇點的黏合自由度**：設 $T = \mathrm{pv}\frac{1}{x} + c\,\delta$（pv = Cauchy 主值，見 5.3 節），則 $x\cdot\mathrm{pv}\frac1x = 1$（驗證：$\langle x\,\mathrm{pv}\tfrac1x,\varphi\rangle = \mathrm{pv}\int\varphi\,dx = \int\varphi\,dx$ ✓）且 $x\delta = 0$ ✓。**所有解** $= \mathrm{pv}\frac1x + c\delta$：一維參數族，經典理論只能看到 $c = 0$ 的那個。**分配理論不僅合法化怪對象，還暴露了經典理論看不見的解**——這是它統治 PDE 的根本原因（弱解多於經典解！9.1 節）。

### 歷史啟示

- **對偶性是對象的定義**：「一個對象 = 它與一切檢驗對象的作用關係」——這個範式（Yoneda 式思維）在 20 世紀數學多處爆發（範疇論、譜理論、同調代數）。Schwartz 的分配是此範式最成功的應用之一。
- **戰爭與理論**：分配理論誕生於躲藏歲月。數學史上多次重大工作在流亡中完成（Erdős 的戰年遊歷、Gelfand 的戰時疏散）。**理論的誕生條件可以極端簡陋；唯一必需品是持續思考**。
- **框架的複利**：Schwartz 之後 30 年，PDE 理論（Hörmander 的偏微分算子理論、Malgrange–Ehrenpreis 常係數方程基本解存在定理 1955）全部在 $\mathcal{D}'$ 語言中書寫。**一個好框架的產出以世代計**。

## 練習

1. 證明非零光滑緊支撐函數存在：$f(x) = e^{-1/(1-x^2)}$（$|x|<1$、0 其他）在 $x=\pm1$ 處所有階導數為零（提示：$e^{-1/(1-x^2)}$ 在 $|x|\to1^-$ 時比任意冪都快地趨於零——1.1 節場景一的「超快無窮小」回歸）。
2. 驗證分配導數的定義還原經典導數：若 $f \in C^1$ 且 $f$ 有界，證明 $T_f' = T_{f'}$。
3. 計算 $\big(\mathrm{sgn}\,x\big)' = 2\delta$，進而推 $\big(|x|\big)' = \mathrm{sgn}\,x$、$\big(|x|\big)'' = 2\delta$——說明「凸函數的二階導數是正測度」的分配現象。
4. 求所有分配解 $T' = 0$（答案：常數分配），以及 $T'' = \delta$（答案：$x_+ + \text{一次函數}$，$x_+ = \max(x, 0)$）——這些是「分配意義的初等積分」。
5. 思考題：為什麼 $\mathcal{D}$（緊支撐檢驗函數）比 Schwartz 空間 $\mathcal{S}$（快衰減）更適合做傅立葉轉換的分配對偶？——其實相反：$\mathcal{S}$ 自身不變且對偶 $\mathcal{S}'$（緩增分配）容納常數與多項式，而 $\mathcal{D}$ 的對偶不容納常數（為什麼？提示：$\varphi$ 需緊支撐，$\int 1\cdot\varphi$ 有限啊——那 1 的分配在 $\mathcal{D}'$ 中！問題出在傅立葉轉換映射 $\mathcal{D}$ 到何處）。本題訓練「分配框架的選型」：**5.3 節用 $\mathcal{S}'$**。

## 進階研讀：分配理論的五個深化場景

**場景一：支撐與階**。分配 $T$ 的**支撐**：使 $T$ 在其上「非零」的最小閉集。δ 的支撐是 $\{0\}$——**點支撐分配的結構定理**：支撐在單點的分配恰為 $\delta^{(n)}$ 的有限線性組合。分配的**階**：需要多少階導數的范數才能控制它；δ 是 0 階、δ′ 是 1 階。「支撐 + 階」是分配的兩個基本指紋，PDE 奇性分析（波前集，Hörmander 1970）以它們為起點。

**場景二：緩增分配與 Fourier 的完美舞台**。$\mathcal{S}$（Schwartz 空間：快衰減光滑函數）的對偶 $\mathcal{S}'$ = **緩增分配**（tempered distributions）——增長慢於多項式。常數、多項式、δ、Dirac 梳、週期函數全部屬於 $\mathcal{S}'$；且 $\mathcal{S}$ 在傅立葉轉換下不變 $\Rightarrow$ $\mathcal{S}'$ 亦然。**$\mathcal{S}'$ 是傅立葉分析的終極通用空間**：5.3 節將在這裡完成「一切函數（與非函數）都有譜」的夢想。

**場景三：基本解與 Green 函數**。**Malgrange–Ehrenpreis 定理（1955）**：非常數常係數線性微分算子 $P(D)$ 恆有基本解 $E$（即 $P(D)E = \delta$）。則 $P(D)u = f$ 的解為 $u = E * f$——**所有常係數 PDE 的解 = δ 的響應與源的捲積**。Laplace 算子的基本解：$\Delta E = \delta$ 給 $E = \frac{1}{2\pi}\ln|x|$（2D）或 $-\frac{1}{4\pi|x|}$（3D）——**點電荷位勢正是 Laplace 的 Green 函數**（5.1 節練習 5 的嚴格家園）。

**場景四：Sobolev 空間與現代 PDE**。$H^m = \{T \in \mathcal{S}' : \widehat{T}(\omega)(1 + |\omega|^2)^{m/2} \in L^2\}$：**用譜的加權平方可積性定義光滑度**。Sobolev 嵌入（$H^s \hookrightarrow C^k$ 當 $s > k + \frac{n}{2}$）把「分配多少階才連續」量化。波方程解的有限傳播速度、熱方程的即時光滑、橢圓正則性——現代 PDE 的三大奇蹟全部在 Sobolev/分配語言中證明。**9 章將用初等級數版本體驗這些定理**。

**場景五：Colombeau 代數與乘法難題**。分配不能相乘是理論的軟肋（物理：量子場論的非線性項！）。**Colombeau 代數**（1983）用「函數族 + 等價階」重造廣義函數，容納乘法但犧牲簡潔。量子場論的路徑積分至今在分配框架內外反覆折騰——**理論的邊界正是下一代理論的入口**。

### 補充：Gelfand 學派的平行宇宙

蘇聯的 **Israel Gelfand（1913–2009）** 團隊在 1950s 出了五卷《廣義函數》（Generalized Functions），從**譜理論與表示論**角度重建分配理論，並發展了廣義隨機過程、測度論的推廣。Gelfand 三元組（$\mathcal{D} \subset H \subset \mathcal{D}'$，H 是 Hilbert 空間）成為量子力學的數學框架（**rigged Hilbert space**）：位置本徵態 $|x\rangle$（非正常態）住在 $\mathcal{D}'$、正常態住 $H$、試驗函數住 $\mathcal{D}$。**Schwartz 與 Gelfand 兩條路線在 1950s 匯流**——分配理論是冷戰兩陣營少數同步進展的領域之一，數學的通用語言性在此展露。

### 名詞速查表（本節出現的核心術語）

- **檢驗函數空間** $\mathcal{D} = C_c^\infty$：緊支撐無窮光滑；分配的「受眾」。
- **分配**：$\mathcal{D}$ 上連續線性泛函；廣義函數的正式名。
- **正則分配**：$L^1_{loc}$ 函數的嵌入；函數是分配的特例。
- **分配導數**：$\langle T', \varphi\rangle = -\langle T, \varphi'\rangle$；無條件可微。
- **Leibniz 律**：光滑係數下分配可乘可微。
- **分配捲積**：$\delta$ 為單位元；結合交換成立。
- **支撐 / 階**：分配的兩個基本指紋。
- **緩增分配** $\mathcal{S}'$：傅立葉分析的終極舞台（5.3 節）。
- **基本解**：$P(D)E = \delta$ 的解；Green 函數的理論化身。
- **Sobolev 空間** $H^m$：譜加權 $L^2$ 定義的光滑度階梯。
- **Gelfand 三元組**：$\mathcal{D} \subset H \subset \mathcal{D}'$；量子力學的數學骨架。

### 深化問答三則

**問：分配理論是「放寬了定義」嗎？會不會讓分析失去嚴格性？**
答：恰恰相反——它**收緊**了語言：每個分配都是完備拓撲向量空間上的嚴格定義的連續泛函，每個運算都有公理與定理。放寬的是「對象的範圍」，不是「推理的標準」。**擴張定義域、不降推理規格**，是 20 世紀分析學的總方針（Lebesgue 積分同款）。

**問：為什麼導數定義要加負號（$-T(\varphi')$）？**
答：因為它是「分部積分的抽象化」：經典 $\int f'\varphi = -\int f\varphi'$（緊支撐消邊界）。負號使分配導數在正則分配上**還原**經典導數——兼容性要求。這是「向後兼容」的數學設計：新理論必須在舊對象上給出舊結果。

**問：如果分配不能相乘，量子場論怎麼辦？**
答：分三層。（1）微擾 QFT 用**正規化**（regulization）：先給 δ 光滑化、乘完、取極限（如維數正規化）；（2）**重整化**處理極限中的發散——本質上是「乘積不存在」的物理症狀；（3）構造性 QFT 在低維（2D、3D 模型）用 Osterwalder–Schrader 公理在分配框架內完成。**分配理論給了 QFT 詞彙，但語法（乘法）仍欠完備**——這是今日數學物理的活前沿。
