# 9.3 Laplace 變換與常微分方程

## 本章導言

傅立葉變換要求函數在整條實軸可積；工程中的訊號（階躍、增長的指數）達不到。**Laplace 變換**的解法優雅：先乘一個衰減因子 $e^{-\sigma t}$ 再做傅立葉變換——

$$
F(s) = \mathcal{L}\{f\}(s) = \int_0^\infty f(t)\,e^{-st}\,dt, \qquad s = \sigma + i\omega.
$$

**複平面上的傅立葉變換**：收斂域（$\mathrm{Re}\,s > \sigma_0$，增長指數）以內一切合法。Laplace 變換把常微分方程變成**代數方程**（微分 $\to$ 乘 $s$、初值自動編碼），是控制工程（傳遞函數）、電路分析、ODE 求解的百年主力。本節建立 Laplace 變換的性質表與反演（部分分式 + 留數）、經典 ODE 應用、與 Heaviside 運算微積分的歷史（合法性補發），並把它放在本書「四象限」譜理論的完整地圖上。

### 定義、收斂域與性質表

**定義與 ROC**：對「指數階」函數（$|f(t)| \le Ce^{\sigma_0 t}$），積分在半平面 $\mathrm{Re}\,s > \sigma_0$ 收斂（**收斂域 = 右半平面**）。**單邊**變換（$t \ge 0$）是工程標準（初值問題的時間自然從 0 開始）。

**核心性質表**：

| 時域 | $s$ 域 | 說明 |
|------|--------|------|
| 微分 $f'(t)$ | $sF(s) - f(0^+)$ | **初值自動入帳**（ODE 解法的心臟） |
| 二階微分 | $s^2F - sf(0^+) - f'(0^+)$ | 同上 |
| 積分 $\int_0^t f$ | $\frac{F(s)}{s}$ | 積分 = 除 $s$（4.2 節的 $s$ 版） |
| 平移 $f(t - a)u(t - a)$ | $e^{-as}F(s)$ | 時移 = 相位因子（因果版） |
| 指數乘 $e^{at}f(t)$ | $F(s - a)$ | $s$ 域平移 |
| 捲積 $(f*g)(t)$ | $F(s)G(s)$ | 捲積定理（4.3 節 $s$ 版） |
| 終值 | $\lim_{t\to\infty}f(t) = \lim_{s\to0}sF(s)$（若存在） | 穩態直讀 |
| 初值 | $f(0^+) = \lim_{s\to\infty}sF(s)$ | 初態直讀 |
| $\delta(t)$ | $1$ | 衝擊的規範像 |
| $\sin\omega_0 t$ | $\frac{\omega_0}{s^2 + \omega_0^2}$ | 諧振器的代數像 |

**與傅立葉的關係**：$\mathcal{L}$ = 帶權傅立葉：$F(\sigma + i\omega) = \widehat{f\,e^{-\sigma\cdot}}(\omega)$。**$s$ 平面的豎線 = 不同衰減下的頻率響應**；$s = i\omega$（虛軸）= 純傅立葉；**極點位置 = 模態行為**（實極點 = 指數、虛極點 = 振盪、複極點 = 衰減振盪——**7.1 節極點分析的 $s$ 域原生版**）。穩定性：極點在左半平面（$z$ 域的單位圓內，7.2 節）。

**反演**：（1）**部分分式**：$F(s) = \sum\frac{c_k}{s - p_k}$，逐項反查表 $e^{p_k t}$；（2）**留數定理**（Cauchy–Mellin 反演）：$f(t) = \frac{1}{2\pi i}\int_{\sigma - i\infty}^{\sigma + i\infty}F(s)e^{st}ds$，閉圍道拾極點殘數——**「反演 = 數極點」**在好情況下字面成立。

### ODE 求解的標準流程

**範式**：二階常係數 ODE + 初值 + 強迫項：

$$
y'' + 2\zeta\omega_n y' + \omega_n^2 y = g(t), \qquad y(0) = y_0,\; y'(0) = v_0.
$$

**三步**：（1）變換：$(s^2Y - sy_0 - v_0) + 2\zeta\omega_n(sY - y_0) + \omega_n^2Y = G(s)$；（2）解代數：$Y(s) = \frac{sy_0 + v_0 + 2\zeta\omega_n y_0 + G(s)}{s^2 + 2\zeta\omega_n s + \omega_n^2}$；（3）反演（部分分式 + 查表）。**微分方程 → 有理函數 → 指數/三角的組合**——**初值不出現在公式末尾（它們已編碼在分子的 $s$ 項）**，整個過程機械化、可查表、可由機器執行。

**傳遞函數觀點**：$Y = \frac{1}{s^2 + 2\zeta\omega_ns + \omega_n^2}G + \frac{sy_0 + \cdots}{(\text{同})}$——**強迫項部分 = 輸入 × 傳遞函數 $H(s) = \frac{1}{(\cdot)}$、初始條件部分 = 自然響應**。**零狀態 + 零輸入的分解**是線性系統理論的語法（7.1 節的 $s$ 域版）；**$H(s)$ 的極點 = 分母多項式零點 = 自然模態**——特徵方程的根，工程師叫「閉環極點」。

### 一個具體例題

**例題 9.3.1**：阻尼振子受階躍力：$y'' + 3y' + 2y = u(t)$（$u$ 為單位階躍），$y(0) = y'(0) = 0$。（1）用 Laplace 變換求解；（2）用終值定理驗證穩態；（3）解讀 $H(s)$ 的極點與響應的關係。

**解**：

（1）變換（零初值）：$(s^2 + 3s + 2)Y(s) = \frac{1}{s}$，故

$$
Y(s) = \frac{1}{s(s+1)(s+2)} = \frac{1/2}{s} - \frac{1}{s+1} + \frac{1/2}{s+2} \quad(\text{部分分式}).
$$

反演：$y(t) = \frac12 - e^{-t} + \frac12 e^{-2t}$。

**驗證**：$y(0) = \frac12 - 1 + \frac12 = 0$ ✓；$y'(t) = e^{-t} - e^{-2t}$，$y'(0) = 0$ ✓；代入方程（略）成立 ✓。

（2）終值定理：$\lim_{s\to0}sY(s) = \lim_{s\to0}\frac{1}{(s+1)(s+2)} = \frac12$ = 時域 $\lim y(t) = \frac12$ ✓（**穩態 = 階躍增益 $\frac{1}{2} = H(0)$**——直流增益）。

（3）極點 $s = -1, -2$（實數、左半平面——**過阻尼**，無振盪）：兩個指數模態 $e^{-t}, e^{-2t}$；**快極點（$-2$）先消失**（長時間由慢極點 $-1$ 主導——9.1 節「第一模態暴政」的 $s$ 域版）。**若極點是 $-1 \pm 2i$（複數）**：響應為衰減振盪 $e^{-t}\cos 2t$ 型——**極點的實部 = 衰減率、虛部 = 振盪頻率**（7.1 節的幾何解讀再次生效）。**階躍響應的「形狀」完全由極點配置決定**——控制工程的「極點配置法」（pole placement）由此而來。

### 歷史啟示

- **Heaviside 的合法化史詩**：Heaviside（1880s）用純形式的 $p$ 算子解電報方程（把 $\frac{d}{dt}$ 當數乘、展開級數、讀出答案），**算得又對又快，證明一個沒有**。數學界（如 Poincaré 曾譏諷）與工程界長期對峙；1910s–20s Bromwich、Carson、Doetsch 用 Laplace 積分與圍道理論**補發了合法性**——**運算微積分 = Laplace 變換的工程速記**。**「先勇敢計算、後補嚴格證明」的模式**（δ、Heaviside、Dirac comb 一脈相承）在 5.1 節已是主題；本節是它的 ODE 版本。
- **Laplace 的優先權問題**：變換的核 $e^{-st}$ 最早出現於 **Euler（1737）與 Lagrange（1762）** 的積分方程研究；**Laplace（1782–85）** 系統用於機率生成函數的連續版。**冠名是「推廣者 + 教科書化」的紅利**（與 Parseval、Fourier 的冠名史互文——3.1 節）。
- **控制理論的誕生**：1930s–50s，Nyquist（1932 判據）、Bode（1940 圖解）、Evans（1948 根軌跡）把 $s$ 域語言鑄成控制工程的母語——**「設計 = 放極點」**的百年工程傳統由此確立。

## 練習

1. 求 $\mathcal{L}\{t^n e^{at}\} = \frac{n!}{(s-a)^{n+1}}$（用微分性質對 $s$ 求導 $n$ 次），並以 $n = 1, a = -1$ 驗證。
2. 解初值問題：$y' + 2y = \sin t$、$y(0) = 1$（部分分式 + 反演；驗證 $y(0) = 1$ 與 ODE 成立）。
3. 用捲積定理證明 Duhamel：零初始條件下 $y = h * g$（$h = \mathcal{L}^{-1}\{H\}$ 為衝擊響應）——**衝擊響應決定一切輸入的響應**（7.1 節的 $s$ 域證明）。
4. 對例題 9.3.1 的系統，若改強迫為 $\sin t$（諧振輸入），用變換法求解並討論：分母因式 $(s^2 + 1)$ 與極點 $-1, -2$ 的關係——**強迫頻率與自然頻率的分離**何時產生共振放大（本系統不共振，為什麼？提示：本系統自然頻率非 $\sqrt{2}$… 實際上 $s = \pm i$ 與極點不重合；討論若強迫為 $e^{-t}$ 則重根出現）。
5. 思考題：終值定理要求 $sF(s)$ 的極點都在左半平面（不含虛軸）。構造反例：$y' = 1$（$y = t$）——$Y = \frac{1}{s^2}$，$\lim_{s\to0}sY = \infty$ 與 $\lim y = \infty$ 一致嗎？再試 $y' = \cos t$（$Y = \frac{s}{s^2+1}\cdot\frac{1}{s}$… 討論）：**終值定理的失效方式**如何反映「虛軸極點 = 不衰減模態」——控制工程用終值定理「探測穩定性」的邏輯。

## 進階研讀：Laplace 方法的五個深化場景

**場景一：分佈的 Laplace 變換**。δ、δ′、階躍的導數鏈在 $s$ 域的像極乾淨（$\delta \to 1$、$\delta' \to s$、$u \to \frac1s$）——**5.2 節分配理論把 Heaviside 的算子魔法完全收編**：$\frac{d}{dt} \leftrightarrow s$ 的「除不盡的初值項」問題（經典變換要求 $f$ 光滑）在分配框架下無條件成立（分配的導數定義天生含邊界資訊）。**「分配理論是 Laplace 變換的完成態」**——工程教科書的「初值項」腳註其實是整個分配理論的縮影。

**場景二：預解式與泛函演算**。$(sI - A)^{-1}$ = **預解式**：算子 $A$ 的譜完全編碼在預解式的奇點（**譜 = 預解式極點集**，離散情況）。**Dunford 演算**：$f(A) = \frac{1}{2\pi i}\oint f(s)(sI - A)^{-1}ds$（圍道積分定義算子函數）——**「把純量函數搬到算子」的嚴格機器**，矩陣函數、半群、譜分解的統一工具。9.1 節的 $e^{tA}$ 在此獲得最終定義（10.1 節的續篇）。

**場景三：Laplace 反演的漸近技術**。閉式反演常不可能，**漸近反演**（Watson 引理 1918、saddle point / 最速下降法，Riemann–Debye 1909）把大 $t$ 行為讀自 $F(s)$ 的**最近奇點**：$\hat f(s) \sim \frac{C}{(s - a)^\alpha} \Rightarrow f(t) \sim \frac{C e^{at}}{\Gamma(\alpha)}t^{\alpha - 1}$。**「奇點的類型決定長時間行為」**——與 7.1 節極點分析同源、與 2.1 節價碼表互文。**漸近分析是「不求精確解的藝術」**，漸近 Laplace 變換在應用數學的教材（Bender–Orszag）中是皇冠章節。

**場景四：生滅過程與排隊論**。馬爾可夫鏈的 Fokker–Planck（無窮 ODE 組）用 Laplace（或生成函數）解耦：**M/M/1 排隊的暫態、賭徒破產、流行病 SIR 模型的早期解**都以 Laplace 標準流程完成。**「指數階 + 線性 = 可變換」**的適用域在隨機過程同樣堅固——矩生成函數的收斂域 = ROC 的機率版。

**場景五：分數階微積分**。**分數階導數** $\frac{d^{1/2}}{dt^{1/2}}$ 的定義：Laplace 域乘 $s^{1/2}$（**「分數階 = $s$ 的分數冪」**，Caputo/Riemann–Liouville 定義在初值條件上分歧）。**異常擴散**（亞擴散：等待時間重尾——分數階熱方程 $D^{1/2}u = u_{xx}$）、黏彈性材料（應力–應變的分數階律）、分數階控制器（CRONE）——**Laplace 域的代數威力使「半階微分」成為可計算對象**。2010s 起分數階模型在生物擴散、金融（記憶核）快速滲透——**變換域思維的又一處新殖民**。

### 補充：Doetsch 與 Laplace 變換的教科書化

**Gustav Doetsch（1892–1977）**（Freiburg）在 1930–40 年代出版三卷《Laplace 變換的理論與應用》，把 Heaviside–Bromwich–Carson 的工程傳統與德國嚴格性（ROC 的明確處理、唯一性定理、收斂細節）熔合——**「ROC 是身份證」的教學法**（7.2 節 Z 變換的平行原則）由他確立。有趣的是 Doetsch 也為希特勒政權服務（戰爭數學顧問），其政治污點與學術貢獻並存——**科學史人物的政治評價與技術遺產的分離**，是讀史者的必修習題（與 1.1 節拿破崙–Fourier 關係的道德問題呼應）。

### 名詞速查表（本節出現的核心術語）

- **Laplace 變換**：$F(s) = \int_0^\infty f e^{-st}dt$；單邊、複變數。
- **收斂域（ROC）**：右半平面；序列/函數的身份證。
- **微分性質**：$f' \to sF - f(0^+)$；初值自動編碼。
- **捲積定理**：$f*g \to FG$。
- **部分分式反演**：極點展開 + 查表。
- **Bromwich 積分 / 留數反演**：$\frac{1}{2\pi i}\int F e^{st}ds$。
- **傳遞函數 $H(s)$**：零狀態輸出/輸入比；極點 = 自然模態。
- **終值 / 初值定理**：$s\to0$ / $s\to\infty$ 的極限直讀。
- **預解式** $(sI - A)^{-1}$：算子譜的載體。
- **零狀態 / 零輸入分解**：強迫響應與自然響應。
- **Watson 引理 / 最速下降**：漸近反演技術。
- **分數階導數**：$s^\alpha$；異常擴散的語言。
- **Heaviside 運算微積分**：Laplace 的工程前身。

### 深化問答三則

**問：Laplace 和 Fourier，工程師何時用哪個？**
答：**看邊界與增長**：初始值問題（$t \ge 0$、可能增長/含階躍衝擊）用 Laplace；穩態頻率分析（全時軸、平穩訊號）用 Fourier。**Laplace 適合「開機過渡」、Fourier 適合「穩態診斷」**；兩者由 $s = \sigma + i\omega$ 連續過渡——**工程師其實天天在同一個複平面工作**（左半平面穩定、虛軸頻率、右半平面爆炸）。

**問：為什麼「初值自動編碼」這麼重要？**
答：因為它使**變換法的 ODE 求解完全機械化**：不用先猜通解結構、不用特解齊解的組合技巧、不用最後代初值解聯立——**一步變換、代數求解、反演完事**。這是 19 世紀「積分技巧的浩繁」變成 20 世紀「流程的標準化」的典型案例——**工程化 = 技巧的表化**。

**問：本節與 9.1、9.2 構成什麼樣的三角？**
答：三種「線性方程 → 代數」的路線：（1）**空間譜**（9.1）：對空間算子特徵展開，時間保持微分；（2）**時間譜**（本節）：對時間變換，空間保持微分；（3）**特徵線**（9.2）：不變換、直接幾何。**選哪條取決於問題的結構藏在哪個變數裡**——熱方程藏空間譜（邊界條件）、ODE 藏時間指數、波方程藏時空耦合的幾何。**「對角化那個惹麻煩的算子」**是三者的共同哲學。
