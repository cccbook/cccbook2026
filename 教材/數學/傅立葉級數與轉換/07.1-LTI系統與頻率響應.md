# 7.1 LTI 系統與頻率響應

## 本章導言

放大器、濾波器、聲道、光學系統、力學結構——一大類物理系統共享兩個性質：**線性**（兩個輸入之和的輸出 = 輸出之和）與**時不變性**（輸入延遲，輸出同樣延遲）。這類**線性時不變系統**（Linear Time-Invariant, LTI）的全部行為由一個函數——**衝擊響應** $h(t)$——完全決定：輸出 $y = f * h$（4.3 節）。傅立葉變換把這一切升華為一句話：**LTI 系統 = 頻域乘法**，$\hat y(\omega) = \hat f(\omega)\,\hat h(\omega)$，其中 $\hat h$ 稱為**頻率響應**。本節將建立 LTI 理論的骨架：衝擊響應、頻率響應、特徵函數觀點、穩定性與因果性的約束、以及 Bode 圖與極點分析的工程語言——這是傅立葉分析最大宗的「客戶」。

### LTI 系統的公理與衝擊響應

把系統抽象為算子 $T: f \mapsto y$。**公理**：

1. **線性**：$T(\alpha f + \beta g) = \alpha T f + \beta T g$；
2. **時不變**：$T(f(\cdot - t_0)) = (Tf)(\cdot - t_0)$。

**基本定理**：連續且時不變的線性系統必為**捲積算子**：$y(t) = (h * f)(t)$，其中 $h = T\delta$ 是衝擊響應。

**證明思想（δ 展開）**：任何輸入可寫為衝擊的連續疊加：$f(t) = \int f(s)\,\delta(t - s)\,ds$。線性把「積分」搬到輸出：$y(t) = \int f(s)\,T[\delta(\cdot - s)](t)\,ds$；時不變使 $T[\delta(\cdot - s)](t) = h(t - s)$。合併：$y(t) = \int f(s)\,h(t - s)\,ds = (h * f)(t)$。$\blacksquare$

這個證明的合法性依賴 δ 展開（分配語言，第 5 章）——**LTI 理論是分配理論的第一個工業客戶**。物理意義：**衝擊響應是系統的「指紋」**——敲一下（δ 輸入）、聽全音（$h$ 的全形），系統從此被看穿。實務中的測量手段：直接打脈衝（錘擊試驗）、用白雜訊激勵 + 互相關（$h \approx$ 輸入輸出之積的捲積）、或掃頻（chirp）輸入。

### 頻率響應：特徵函數觀點

**為什麼是複指數**：$e^{i\omega t}$ 是一切 LTI 系統的**共同特徵函數**：

$$
T[e^{i\omega\cdot}](t) = (h * e^{i\omega\cdot})(t) = \int h(s)\,e^{i\omega(t - s)}ds = e^{i\omega t}\underbrace{\int h(s)e^{-i\omega s}ds}_{\hat h(\omega)}.
$$

**輸出 = 輸入 × $\hat h(\omega)$**——複指數通過 LTI 系統只改幅值與相位，不改形狀、不生新頻率。這是 1.3 節深化問答第三點（平移本徵函數）的系統版，也是**傅立葉基「天生配得上」LTI 的最終理由**：它們同時對角化一切捲積算子。

$\hat h(\omega)$ = **頻率響應**（轉移函數）：$|\hat h(\omega)|$ = 各頻率的增益、$\arg\hat h(\omega)$ = 相移。工程語言：**Bode 圖**（幅值與相位 vs. 頻率，對數軸）；增益以 dB 記（$20\log_{10}|\hat h|$）；**-3dB 點**定義帶寬（增益降到 $\frac{1}{\sqrt2}$，功率減半）。

**穩定性**：BIBO 穩定（有界輸入 → 有界輸出）$\Leftrightarrow h \in L^1$（$\|y\|_\infty \le \|h\|_1\|f\|_\infty$，捲積的次可乘性）。穩定系統的 $\hat h$ 有界連續（4.1 節練習 4）。

**因果性**：$h(t) = 0$（$t<0$）$\Leftrightarrow$ $\hat h$ 滿足 Paley–Wiener 條件（4.3 節）$\Leftrightarrow$ $\hat h$ 的實部與虛部經 **Hilbert 變換**（5.3 節）相鎖：$\mathrm{Re}\,\hat h = \mathcal{H}[\mathrm{Im}\,\hat h]$（在適當歸一下）。**最小相位系統**：幅值響應唯一決定相位響應——這是控制理論「知道幅值就差不多知道一切」的數學根據。

### 極點、零點與共振

對由微分方程描述的系統（如 RLC 電路、機械振動），$h$ 是指數衰減振盪的組合，$\hat h$ 是**有理函數**：

$$
\hat h(\omega) = \frac{b_m (i\omega)^m + \cdots + b_0}{a_n (i\omega)^n + \cdots + a_0}.
$$

分母零點 = **極點**（複平面 $\omega = \sigma + i\omega_r$）：極點的**虛部** = 振盪頻率、**實部**（離軸距離） = 阻尼——**離軸越近，共振峰越尖、時間響應衰減越慢**（4.2 節例題的定量版）。二階系統範例：$h(t) = \frac{1}{\omega_d}e^{-\sigma t}\sin\omega_d t\,u(t)$ 的

$$
\hat h(\omega) = \frac{1}{(\sigma + i\omega)^2 + \omega_d^2},
$$

極點 $\omega = \pm\omega_d + i\sigma$（上下半平面各一，因果性要求）。**品質因子** $Q = \frac{\omega_0}{2\sigma}$：$Q$ 大 = 尖峰 = 長餘音（鐘、音叉）；$Q$ 小 = 寬峰 = 快衰减（剎車片、隔振墊）。**從 Bode 圖讀出極點、從極點讀出系統**——這是「頻域診斷」的全部本領（橋樑健康監測、電路除錯、聲學測量的共同方法論）。

### 一個具體例題

**例題 7.1.1**：RLC 串聯電路（$R = 10\,\Omega$、$L = 1\,\mathrm{mH}$、$C = 1\,\mu\mathrm{F}$），輸入電壓 $v_{in}$、輸出電容電壓 $v_{out}$。（1）列寫 ODE 並求頻率響應；（2）求諧振頻率、$Q$ 值、-3dB 帶寬；（3）解釋為何此電路可作 AM 收音機的選台器。

**解**：

（1）KVL：$L\ddot q + R\dot q + \frac{q}{C} = v_{in}$，$v_{out} = \frac{q}{C}$。複數域（$e^{i\omega t}$ 代入）：$(-L\omega^2 + iR\omega + \frac{1}{C})\,\hat q = \hat v_{in}$，故

$$
\hat h(\omega) = \frac{\hat v_{out}}{\hat v_{in}} = \frac{1/C}{-L\omega^2 + iR\omega + 1/C} = \frac{1}{1 - \omega^2 LC + i\omega RC}.
$$

（2）諧振：分母實部最小處 $\omega_0 = \frac{1}{\sqrt{LC}} = \frac{1}{\sqrt{10^{-3}\times10^{-6}}} = 10^5$ rad/s $= 15.9$ kHz。$Q = \frac{\omega_0 L}{R} = \frac{10^5\times10^{-3}}{10} = 10$。-3dB 帶寬 $\Delta\omega = \frac{\omega_0}{Q} = 10^4$ rad/s $\approx 1.59$ kHz。**校驗**：$\omega = \omega_0$ 時 $|\hat h| = \frac{1}{\omega_0 RC} = Q = 10$（增益 20 dB、90° 相移——諧振時電容電壓超前輸入）。

（3）AM 電台的載波間隔 9 kHz（中波）：$Q = 10$ 的電路通帶 1.59 kHz **不足以**分離 9 kHz 間隔的電台——實務用**可變電容調諧 + 高階多級濾波**（級聯 $n$ 級使阻帶衰減 ×$n$）。本例演示的是**單級的極限**：一個二階系統的選台能力由 $Q$ 封頂。**「增益、帶寬、階數」的三角交換**是濾波器設計的第一課——提升 $Q$ 需要降低 $R$（損耗）或加級數（成本），沒有免費午餐（4.3 節理想與可實現鴻溝的電路版）。

### 歷史啟示

- **Heaviside 的遺產**：運算微積分（1880s）把電路方程當代數解，$p = \frac{d}{dt}$ 的「阻抗」概念是頻率響應的前身。工程師先算對、數學家後補證（9.3 節 Laplace 變換的合法化）——**電路理論是傅立葉/Laplace 方法的最大練習場**。
- **Bode 的工作**：**Hendrik Wade Bode（1905–1982）**（貝爾實驗室）在 1940 年《回授放大器設計》系統化了對數頻率響應圖與回授理論（增益–帶寬積、穩定裕度）。Bode 圖至今是控制工程與類比設計的通用圖紙——**好的記號系統（dB、對數軸）與好的定理同樣重要**。
- **特徵函數觀點的普遍性**：「找對基使算子對角化」從 LTI 系統延伸到量子力學（能量本徵態）、主成分分析（協方差本徵向量）、圖訊號（拉普拉斯本徵函數）。**本書的反覆主題**：傅立葉只是「平移不變系統」的特例，對角化思想才是本體。

## 練習

1. 證明：因果 LTI 系統若穩定，其頻率響應在 $\mathrm{Im}\,\omega \ge 0$ 半平面解析（提示：$h(t)u(t)\in L^1$，對上半平面 $\omega$ 積分收斂），極點必在下半平面。
2. 一階系統 $h(t) = \frac{1}{\tau}e^{-t/\tau}u(t)$：（1）求 $\hat h$ 與 -3dB 頻率；（2）證明其階躍響應在 $t = \tau$ 達 63.2%（工程慣用的「時間常數」）；（3）說明為何一階系統無振鈴（極點實數）。
3. 兩個 LTI 系統級聯：$h = h_1 * h_2$。證明 $\hat h = \hat h_1\hat h_2$，並對「增益帶寬」討論級聯的效果（$n$ 個相同一階級聯的 -3dB 頻率如何移動？答：收窄，$f_{3dB}^{(n)} = f_{3dB}\sqrt{2^{1/n} - 1}$）。
4. 由 Bode 圖反推系統：某系統幅值響應在低頻平坦（0 dB）、從 $\omega = 100$ rad/s 起以 $-40$ dB/decade 下降。判斷階數（二階）、寫出可能的 $\hat h$、估計諧振行為（有無尖峰取決於阻尼比 $\zeta$）。
5. 思考題：為什麼「掃頻輸入（chirp）」能一次測量整條頻率響應？（提示：chirp 的瞬時頻率隨時間掃過全頻段，配合 8.2 節短時分析可「按時間讀出頻率」；或用相關法把輸出與參考 chirp 對齊。）比較脈衝法、雜訊法、掃頻法的適用場景（線性度、信噪比、峰值功率限制）。

## 進階研讀：LTI 理論的五個深化場景

**場景一：Wiener–Khinchin 定理與隨機訊號**。對平穩隨機訊號（無確定性波形，只有統計性質），**功率譜** $S_f(\omega)$ 定義為自相關 $r_f(\tau) = E[f(t)f(t+\tau)]$ 的傅立葉變換（Wiener 1930、Khinchin 1934）。**線性系統對隨機輸入**：$S_y = |\hat h|^2 S_f$——**幅值響應平方 = 功率譜的放大器**。這條公式使通訊（雜訊功率預算）、雷達（匹配濾波）、金融（波動率譜）共用一套理論。**確定性訊號講振幅、隨機訊號講功率**——頻域語言自動分岔為兩支。

**場景二：回授與 Nyquist 判據**。負回授系統 $H_{closed} = \frac{\hat h}{1 + \hat h k}$ 的穩定性取決於 $1 + \hat h k$ 是否有零點穿越——**Nyquist 判據（1932）**：畫 $\hat h k$ 沿實軸頻率的圍道，看它繞 $-1$ 點的圈數。**回授的悖論**：降低增益換取寬頻平坦（負回授放大器，Black 1934 的發明讓 AT&T 的跨洋電話可行）。**控制理論與濾波理論在此合流**——都是「$1 + $ 環路增益」的代數。

**場景三：時變與非線性的邊界**。LTI 之外的世界：**線性時變**（LTV，如旋轉機械的時變頻響——第 8 章時頻方法上場）；**非線性**（Volterra 級數把「捲積」推廣為多階捲積核——類比放大器的失真分析、揚聲器的 THD 指標）。**LTI 的邊界就是它的定義價值**：知道哪裡失效（諧波失真、互調、混沌），才知道該換什麼工具。

**場景四：多通道與 MIMO**。多輸入多輸出系統的 $\hat h$ 是**矩陣** $\hat H(\omega)$；「對角化」由奇異值分解（SVD）承擔：**MIMO 通訊（5G、WiFi）的空間流 = 通道矩陣的奇異向量**——「特徵函數觀點」的矩陣版。音訊的立體聲/環繞聲處理（串擾消除、房間校正）同屬此框架。**從純量捲積到矩陣捲積，理論結構不變，只是基從函數換成函數向量**。

**場景五：系統識別——從數據反推 $h$**。反問題：由輸入輸出數據估 $\hat h$。方法譜系：頻域除法 $\hat h = \hat y/\hat f$（噪聲敏感！需正則化）、Wiener 反濾波（$\frac{\overline{\hat f}}{|\hat f|^2 + \epsilon}$，4.3 節場景二）、子空間法（Hankel 矩陣）、深度學習端到端。**系統識別是「傅立葉 + 統計 + 優化」的交匯口**，橋樑模態分析、聲學成像、經濟計量（脈衝響應函數，1970s Sims 得諾獎的工作！）共用。

### 補充：超外差——1918 年的頻域思維革命

**Edwin Armstrong（1890–1954）** 1918 年發明**超外差接收機**（superheterodyne）：把任意接收頻率**混頻**（乘以本地振盪 → 譜平移，4.2 節調變性質）到固定中頻（IF），再在 IF 做 LTI 濾波與放大。**妙處**：濾波器只需在**一個**頻率工作良好（IF），不必在整個接收波段都可調——把「可變的高性能濾波器」化約為「固定的高性能濾波器 + 可變振盪器」。**頻域思維的工程極致**：至今一切收音機、雷達、手機接收鏈路的骨架。Armstrong 的悲劇（與 RCA 的專利訴訟拖垮他、1954 年自殺）是無線電史最沉痛的一頁——**工程史上「正確技術 vs. 商業力量」的反覆上演**。

### 名詞速查表（本節出現的核心術語）

- **LTI 系統**：線性 + 時不變；$y = f * h$。
- **衝擊響應** $h$：δ 輸入的輸出；系統指紋。
- **頻率響應** $\hat h$：複指數的特徵值；幅值 + 相位。
- **Bode 圖 / dB**：對數頻響圖；$-3$dB 帶寬。
- **BIBO 穩定性**：$\Leftrightarrow h \in L^1$。
- **因果性**：$h(t)=0$（$t<0$）；Paley–Wiener 約束。
- **最小相位**：幅值唯一決定相位。
- **極點 / 零點**：有理頻響的奇點；極點位置定共振。
- **品質因子** $Q = \frac{\omega_0}{\Delta\omega}$：尖銳度。
- **Wiener–Khinchin 定理**：功率譜 = 自相關的 FT。
- **Nyquist 判據**：回授穩定性的圍道判別。
- **超外差**：混頻至固定中頻的接收架構。
- **MIMO / SVD**：多通道系統的矩陣對角化。

### 深化問答三則

**問：為什麼「線性 + 時不變」這兩條公理如此強大？**
答：它們恰好把系統類限制為**捲積算子**，而捲積算子被複指數**同時對角化**。兩條代數公理 → 一個函數（$h$）→ 一切行為。這是數學中「公理的性價比」最高的例子之一：**兩條假設換取整個頻域方法論**。

**問：實際系統都不嚴格 LTI（溫漂、失真、老化），理論還有用嗎？**
答：三個層次。（1）**局部線性化**：小訊號分析（電晶體的 $h$ 參數模型）——在工作點附近 LTI 近似夠用；（2）**分段/慢時變**：LTI 理論在短窗內適用（8.2 節短時方法的合法性）；（3）**誤差預算**：非線性失真作為「干擾項」量化（THD、IP3 指標）。**LTI 是零階近似，工程是「近似 + 誤差管理」的藝術**。

**問：為什麼工程師偏愛「極點–零點圖」勝過頻響曲線？**
答：因為極點圖是**生成語法**：每個極點對應一個時間模態（$e^{pt}$）、一個頻域峰形（Lorentzian）、一個物理參數（$\omega_0, Q$）——一張圖解釋時間、頻率、物理三界。頻響曲線只是「生成結果的投影」。**學會讀極點圖 = 掌握系統的 DNA**；這也是 7.2 節 Z 平面設計數位濾波器的方法論。
