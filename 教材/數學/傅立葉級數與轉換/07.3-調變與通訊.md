# 7.3 調變與通訊

## 本章導言

語音的頻譜在 300–3400 Hz，但無線電波以 MHz–GHz 傳播——**訊號必須被「搬運」到合適的頻段**才能發射、複用、傳播。這個搬運就是**調變**（modulation）：用訊號去控制載波的幅值（AM）、頻率（FM）、相位（PM/QAM）。調變的數學核心只有一條（4.2 節調變性質：時域乘 $e^{i\omega_0 t}$ = 頻域平移 $\omega_0$），但它的工程史（從 Marconi 到 5G）與社會史（廣播、行動電話、衛星）是 20 世紀最壯闊的技術敘事。本節將建立 AM/FM/數位調變的譜理論、解調方法（包括 Hilbert 變換的登場）、頻分/時分複用、以及 Shannon 容量對調變的統轄——**通訊就是「頻譜的不動產管理」**。

### AM 調變的譜解剖

**調變**：$s(t) = f(t)\cos\omega_0 t$（$\omega_0$ = 載波頻率）。由積化和差：

$$
s(t) = f(t)\cdot\frac{e^{i\omega_0 t} + e^{-i\omega_0 t}}{2}
\;\Longrightarrow\;
\hat s(\omega) = \frac{1}{2}\left[\hat f(\omega - \omega_0) + \hat f(\omega + \omega_0)\right].
$$

**譜 = 原譜的兩份複製（各乘 $\frac12$）搬到 $\pm\omega_0$**——調變就是頻譜搬運。若 $f$ 帶限 $[-W, W]$，則 $s$ 佔據 $[\omega_0 - W, \omega_0 + W]$，**帶寬 $2W$**（雙邊帶）。

**解調（相干檢測）**：接收端再乘一次載波：

$$
s(t)\cos\omega_0 t = f(t)\cos^2\omega_0 t = \frac{f(t)}{2} + \frac{f(t)\cos 2\omega_0 t}{2},
$$

**低通**濾掉 $2\omega_0$ 項即得 $\frac{f}{2}$——**乘載波 + 低通 = 搬回基帶**。**難點**：接收端必須有**相位同步**的本地載波（相位差 $\theta$ 使輸出乘 $\cos\theta$——$90°$ 失步則歸零！）。**包絡檢波**（非相干）：若發射**大載波 AM**（$s = (1 + mf(t))\cos\omega_0 t$、$m f \ge -1$ 使包絡恆正），則**二極體 + 電容**（整流 + 平滑）直接跟蹤包絡——**廉價收音機的百年方案**（1900s–）；代價是載波浪費功率（載波攜帶無資訊）。

**DSB–SC 與 SSB**：**抑制載波雙邊帶**（DSB-SC）省功率但需相干解調；**單邊帶**（SSB）更進一步砍掉一半頻譜（上下邊帶攜帶**同一資訊**——實訊號譜的共軛對稱性使一份就夠！）：SSB 用 **Hilbert 變換**（5.3 節）構造解析訊號後取單邊——**頻譜效率 ×2**。業餘無線電、軍事短波至今用 SSB。**調變技術的譜效率進化**：AM（1）→ DSB-SC（1，省功率）→ SSB（2）→ 數位（見下，QAM 達 6+）。

### FM 與角度調變

**FM**：瞬時頻率隨訊號變化：$s(t) = A\cos\big(\omega_0 t + k\int f\big)$。**分析比 AM 難**（頻率的函數比幅值的函數非線性）：嚴格譜需 Bessel 函數（單音調製 $f = \cos\omega_m t$ 時，譜為載波 ± $n\omega_m$ 的無窮線列，權重 $J_n(\beta)$，$\beta = \frac{k}{\omega_m}$ = **調製指數**）。

**Carson 帶寬規則**：FM 訊號帶寬 $\approx 2(\beta + 1)\omega_m = 2(\Delta\omega + \omega_m)$——**FM 用帶寬換信噪比**。**關鍵性質**：FM 解調後的信噪比隨 $\beta^2$ 增長（**FM 增益**）——**帶寬換 SNR** 是調變理論的深層交換，Shannon 公式 $C = W\log_2(1+\mathrm{SNR})$ 是它的最終形式（帶寬與功率是可互換的資源！）。FM 廣播（1940s，Armstrong 又是主角）以 200 kHz 帶寬換取高保真與抗噪，擊敗了 AM 的靜電噪聲——**帶寬在 20 世紀中期是稀缺品，FM 的勝利是「以寬換淨」的賭博成功**。

**數位調變**：$M$ 進制 **QAM**（幅相聯合調變，星座圖）：每符號攜帶 $\log_2 M$ 位元。**16-QAM → 64-QAM → 256-QAM**：譜效率升，但星座點更擠、抗噪要求升（**星座距離 vs. 雜訊球的幾何交換**）。OFDM（4G/5G/WiFi 的物理層）：把頻道切成數千個正交子載波（IFFT/FFT 一次調變/解調數千子載波——**FFT 在通訊中的最大單筆紅利**），每子載波獨立 QAM，頻域均衡化繁為簡。

### 複用：頻譜的不動產開發

**FDM（頻分）**：多路訊號調變到不同載波、頻譜並排（電台的「波段」）；**TDM（時分）**：時間切片輪流傳送（數位電話 T1）；**CDM（碼分）**：寬頻擴頻 + 正交碼（CDMA 手機、GPS）；**OFDMA**：頻時二維格子按需分配（5G 排程器）。**一切複用的數學本質：找一組互相正交的「載波座標」**（不同頻率/時槽/碼型），使多路訊號在同一媒體上互不串擾——**正交性（1.3 節）從「求係數的工具」升格為「分享資源的契約」**。

### 一個具體例題

**例題 7.3.1**：語音訊號 $f(t)$（帶限 $4$ kHz）要進行 AM 調變，載波 $f_0 = 1$ MHz。（1）求發射譜的頻段與總帶寬；（2）設計相干解調與包絡檢波兩種接收方案，指出各自前提；（3）若改用 SSB，帶寬節省多少？（4）10 路語音 FDM 複用到同一電纜，頻譜如何安排？

**解**：

（1）$\hat s(\omega) = \frac12[\hat f(\omega \pm 2\pi\cdot10^6)]$：發射頻段 $996$–$1004$ kHz，**帶寬 8 kHz**（雙邊帶，$2W$）。

（2）**相干解調**：本地振盪器產生 $\cos\omega_0 t$（需與發射載波**同頻同相**——同步問題！），相乘後低通（截止 4 kHz），得 $\frac{f}{2}$。**包絡檢波**：前提是發射「大載波 AM」（$1 + mf(t) > 0$，調變深度 $m \le 1$）；二極體整流 + RC 平滑（$\frac{1}{RC}$ 需滿足：跟得上 4 kHz 包絡變化、又濾掉 1 MHz 載波——$2\pi\cdot4\mathrm{k} < \frac{1}{RC} < 2\pi\cdot1\mathrm{M}$ 量級）。

（3）SSB 只發一個邊帶：帶寬 $4$ kHz——**節省一半**。構造：相移法（Hilbert 變換產生 $\hat f$ 的 $90°$ 相移版，與原訊號組成解析訊號，取正頻邊帶）或濾波法（水晶濾波器切除一邊帶——商用短波機的實際做法）。

（4）10 路 SSB 複用：載波間隔 4 kHz，頻段佔 $4\times10 = 40$ kHz（CCITT 標準群：60–108 kHz 的 12 路群！）。**電信的階層化頻譜設計**（群→超群→主群）在 1960s 就把 FDM 工程做到極致——SDH/OTN 的時分階層是其數位後裔。

### 歷史啟示

- **調變 = 傅立葉理論的經濟學化**：搬頻（乘法定理）、正交（複用）、帶寬–SNR 交換（Shannon）、譜效率（星座密度）——**每一代調變技術都是一條傅立葉性質的商業化**。
- **Armstrong 的雙重遺產**：超外差（7.1 節）與 FM 都出自他；兩者都是「把問題搬到更好的頻域位置再處理」的思維。**頻域思維的發明者，無意間設計了整個無線電世紀**。
- **數位化不是目的，是手段**：SDR（軟體無線電）把儘可能多的調變/解調搬進數位域（ADC 盡量靠近天線），因為**數位濾波與 FFT 的靈活遠勝類比電路**——「越早數位化、越自由的設計」成為射頻工程的現代信條（6.1 節帶通取樣是理論根據）。

## 練習

1. 訊號 $f(t) = \cos(2\pi\cdot2t) + 0.5\sin(2\pi\cdot3t)$ 調變到 $f_0 = 100$ kHz 的 AM。寫出發射譜的全部譜線（頻率與幅度），並求包絡的最大/最小值（判斷 $m \le 1$ 是否成立）。
2. 證明：DSB-SC 訊號 $f(t)\cos\omega_0 t$ 的包絡（$|s|$ 的上包絡）**不等於** $|f(t)|$——因此包絡檢波對 DSB-SC 失效（過零點反轉問題），這正是 SSB/DSB 需要相干解調的原因。
3. 用 Hilbert 變換構造 $f(t)\cos\omega_0 t$ 的解析訊號，驗證其正頻譜為 $\hat f(\omega - \omega_0)$（$|\omega|<\omega_0$ 內），並由此寫出 SSB 訊號的時域表達式（上邊帶：$f\cos\omega_0 t - \mathcal{H}f\sin\omega_0 t$）。
4. 單音 FM $s(t) = \cos\big(\omega_0 t + \beta\sin\omega_m t\big)$：查/推 $J_n(\beta)$ 展開，對 $\beta = 1$ 列出前 4 個有效譜線的相對功率（$J_0(1)=0.765, J_1(1)=0.440, J_2(1)=0.115, J_3(1)=0.020$），驗證 98% 功率集中在 $\pm(\beta+1)$ 個邊帶內（Carson 規則的實證）。
5. 思考題：5G 的「毫米波 + 大 MIMO + OFDM」三件套，分別對應本節哪些數學資源？（提示：帶寬換容量——Shannon；空間正交——MIMO SVD；頻域格子正交——OFDM/FFT。）討論：**資源的正交維度越多，通訊容量越大**——這條「維度經濟學」的數學極限在哪裡（香農界 + 測不準界）？

## 進階研讀：調變的五個深化場景

**場景一：瞬時頻率與解析訊號**。對解析訊號 $z(t) = A(t)e^{i\phi(t)}$，**瞬時頻率** $\omega_i(t) = \phi'(t)$、**包絡** $A(t)$ 可唯一定義——但**僅對單分量訊號**有意義：多分量（兩個同時的音）的解析訊號，其 $\phi'$ 會產生「頻率跳變」偽象。**瞬時頻率的陷阱**正是 8.2 節短時方法（把訊號按時間窗切成單分量片段）的動機——**「一個時刻一個頻率」的直觀需要工具來實現**。

**場景二：擴頻與 CDMA**。把窄帶訊號乘上高速碼片（頻譜展寬數百倍），接收端用同一碼字相關解擴——**處理增益** $= \frac{\text{擴頻比}}{}$ 使訊號「藏在雜訊下」仍可恢復（軍事通訊的 LPI 特性）；多用戶以不同碼正交共享同一頻帶（CDMA）。**「能量攤薄 + 相關聚攏」**——捲積與正交（1.3、4.3 節）的通訊應用極致。GPS（1970s–）的民用普及使擴頻成為生活科技。

**場景三：OFDM 的數學**。OFDM 符號 = $N$ 個子載波的 IFFT；**循環前綴**（CP，把符號尾部複製到頭部）使多徑通道的**線性捲積變循環捲積**——頻域均衡化為逐子載波除法（$Y_k = H_k X_k$）！**「把邊界問題變成週期問題」**——與 1.3 節「環形桿」、3.2 節「週期延拓」同源的思想在通訊中的復活。CP 的長度 = 多徑時延擴展的預算——**時域結構換頻域簡單**的又一交易。

**場景四：調變與編碼的合流**。Shannon 證明容量存在但未給構造；**Turbo 碼（1993）/LDPC（1962 提出、1999 復活）** 以迭代解碼逼近香農界（距理論極限 0.1 dB 內！）。**調變（星座）+ 編碼（糾錯）+ 均衡（通道）** 的聯合設計（bit-interleaved coded modulation）是現代通訊標準的組織原理。**「逼近香農」的 50 年工程馬拉松**（1948–1993）是資訊理論最壯麗的完成式之一。

**場景五：頻譜的社會史**。泰坦尼克（1912）後的《無線電法》（1912）首創「頻譜屬於公共、須持照使用」；1927 美國聯邦無線電委員會；1994 頻譜拍賣引入市場；今日動態頻譜共享（認知無線電）以「感知 + 讓路」實現時間維度的複用。**「頻譜稀缺」的物理根據正是本節的互擾分析（非正交即串擾）**——調變理論的最終下游是法律與經濟制度。數學 → 工程 → 制度，一條完整的文明傳播鏈。

### 補充：載波同步的百年技藝

相干解調的前提是本地載波與發射載波同頻同相——**載波恢復**（carrier recovery）因此成為接收機的靈魂：鎖相環（PLL，1932 Bellescize 的提出、1950s 系統化）以回授鎖住相位；Costas 環（1956）專解抑制載波訊號（DSB-SC 的譜裡沒有載波線，需非線性重建）。**相位噪聲**（振盪器不純）直接壓縮星座的可行密度——高階 QAM（1024-QAM，DOCSIS 3.1 有線電視標準）對振盪器純度的要求達到百萬分之一量級。**「資訊的速度受制於石英與原子」**——晶體振盪器、銫原子鐘（GPS 的時間基準）、光鐘（2010s），通訊性能的天花板一升再升，本質是相位基準的升級。**頻率是當代最精確的物理量**（$10^{-18}$ 級）——傅立葉分析的實踐推動了計量學。

- **QAM / 星座圖**：幅相聯合數位調變；$\log_2M$ 位元/符號。

### 深化問答三則

**問：為什麼所有調變的數學核心都是「乘一個複指數」？**
答：因為**平移不變世界裡，頻譜搬運的唯一線性操作就是乘 $e^{i\omega_0 t}$**（4.2 節調變性質是充要的：任何把譜平移的線性時變操作都是這個形式）。天線尺寸（$\lambda$ 決定天線長度）、傳播特性（頻率相關衰減）、複用需求共同決定「必須搬頻」；而搬頻的唯一鑰匙就是調變。**物理限制 + 數學唯一性 = 百年不變的核心操作**。

**問：OFDM 為什麼戰勝了單載波高階調變？**
答：因為多徑通道（城市無線的宿命）使單載波需**時域均衡器**（高階自適應 FIR，貴且難調），而 OFDM 把通道頻率響應變成「每子載波一個複數增益」——**均衡 = 逐箱除法**。循環前綴的代價（帶寬損失 ~7%）遠低於均衡器的節省。**「把捲積變成乘法」的執念**（4.3 節捲積定理的哲學）再次獲勝——這次是在通道上。

**問：頻譜真的「稀缺」嗎？**
答：物理上不稀缺（射頻譜是連續的無限資源），**稀缺的是「無互擾的容量」**：給定功率與傳播條件，互擾使可用正交維度有限。香農容量 + 正交分解聯合給出上界；技術進步（更高頻段、MIMO 空間維、動態共享時間維）不斷「增維」——**頻譜稀缺是技術狀態的函數，不是自然常數**。這也是 10.2 節壓縮感知「以計算換帶寬」思想的通訊版。
