# 7.2 Z 轉換與數位濾波器

## 本章導言

離散訊號（取樣後的數列 $x_n$）需要自己的「傅立葉工具」：**Z 轉換**

$$
X(z) = \sum_{n=-\infty}^{\infty} x_n\,z^{-n},
$$

一個以複變數 $z$ 為主的冪級數。Z 轉換之於離散訊號，如 Laplace 轉換之於連續訊號；它在**單位圓** $z = e^{i\omega}$ 上的取值恰是 DTFT（離散時間傅立葉變換），在 $N$ 個均勻點上的取值恰是 DFT（6.2 節）。本節將建立 Z 轉換的性質與收斂域（ROC）、以**傳遞函數** $H(z)$ 的極點–零點語言設計**數位濾波器**（IIR 與 FIR 兩大家族）、並追溯 1960 年代 Kaiser、Rabiner 等人把濾波理論從類比遷移到數位的工程史——數位濾波器是今日一切數位音訊、通訊、控制的核心零件。

### Z 轉換的定義、ROC 與性質

**定義與收斂域**：$X(z) = \sum x_n z^{-n}$ 收斂於環形域 $r < |z| < R$（**ROC**）。ROC 不是技術細節而是**身份證**：同一個閉式表達式對應不同序列，取決於 ROC！經典範例：

$$
\sum_{n=0}^{\infty}a^n z^{-n} = \frac{1}{1 - az^{-1}} \quad (|z| > |a|) \qquad\text{右序列（因果）},
$$
$$
-\sum_{n=-\infty}^{-1}a^n z^{-n} = \frac{1}{1 - az^{-1}} \quad (|z| < |a|) \qquad\text{左序列（反因果）}.
$$

**同一個 $X(z)$，ROC 在極點外 = 因果系統、在極點內 = 反因果**。穩定性要求 ROC 含單位圓（DTFT 存在）；**因果 + 穩定 $\Leftrightarrow$ 全部極點在單位圓內且 ROC 含單位圓**——這是數位濾波器設計的第一鐵律（與 7.1 節連續版「極點在左半平面」完全平行：$s$ 平面 ↔ $z$ 平面，左半 ↔ 圓內）。

**核心性質表**（與 4.2 節平行）：

| 時域（序列） | Z 域 |
|---|---|
| 延遲 $x_{n-k}$ | $z^{-k}X(z)$（$z^{-1}$ = 「單位延遲算子」） |
| 線性 | 線性（ROC = 交集） |
| 捲積 $x * y$ | $X(z)Y(z)$ |
| 乘 $a^n$ | $X(a^{-1}z)$（ROC 縮放） |
| 差分 $x_n - x_{n-1}$ | $(1 - z^{-1})X(z)$ |
| 初值/終值定理 | $x_0 = \lim_{z\to\infty}X(z)$；$\lim_{n\to\infty}x_n = \lim_{z\to1}(z-1)X(z)$（若極限存在） |

**$z^{-1}$ 的物理身份**：一拍延遲——數位系統的「記憶單元」。**差分方程 → 代數方程**：LCCDE（線性常係數差分方程）

$$
\sum_{k=0}^{M}a_k\,y_{n-k} = \sum_{j=0}^{N}b_j\,x_{n-j}
\quad\Longrightarrow\quad
H(z) = \frac{\sum b_j z^{-j}}{\sum a_k z^{-k}},
$$

**傳遞函數 = 兩個多項式之比**。數位濾波器的實現就是按此式搭「加法器、乘法器、延遲器」的電路或程式（直接 I 型/II 型、級聯二階節 biquad——數值穩定性的考量使 biquad 級聯成為標準）。

### IIR 與 FIR：兩大家族

**IIR（無限衝擊響應）**：$H(z)$ 是真分式有理函數（有回授、有極點）。**優點**：階數低、效率高（$n$ 階 IIR 可達 $2n$ 個乘加）；**缺點**：相位非線性（色散）、可能有極限環（量化噪聲被回授放大）、穩定性需驗證。**設計法**：**類比原型遷移**——Butterworth/Chebyshev/橢圓濾波器在 $s$ 域設計好，經 **雙線性變換** $s = \frac{2}{T}\cdot\frac{1 - z^{-1}}{1 + z^{-1}}$（$s$ 左半平面 ↔ $z$ 單位圓內，一對一映射）搬到 $z$ 域。**代價**：頻率軸被壓縮畸變（需**預畸變**：設計前把目標頻率 $f \to \frac{2}{T}\tan\frac{\pi f T}{2}$ 校正回來）——雙線性變換的這個小技巧是數位濾波器課程的必考點。

**FIR（有限衝擊響應）**：$H(z) = \sum_{k=0}^{K-1}h_k z^{-k}$（多項式、無回授、只有零點）。**優點**：**永遠穩定**、可實現**精確線性相位**（對稱係數 $h_k = h_{K-1-k}$ ⇒ 純延遲的相位——無色散，波形不變形！）、無極限環；**缺點**：達到同等阻帶需要較高階數。**設計法**：（1）**窗函數法**：理想 sinc 響應 × 窗（Hann/Kaiser——6.2 節窗家族的濾波器版）；（2）**Parks–McClellan 算法（1972，Remez 交換）**：等波紋最佳化（Chebyshev 逼近），在給定階數下最小化最大誤差——**數位濾波器設計的「皇冠算法」**，把切比雪夫逼近論（多項式最小最大逼近）變成商用工具。

**選型口訣**：**相位要直（音訊、成像）用 FIR；算力要省（即時控制）用 IIR**。DSP 課程的標準答案是兩者並用：FIR 做線性相位的成形、IIR 做高效的粗濾。

### 一個具體例題

**例題 7.2.1**：設計並分析一階數位低通：$y_n = (1-\alpha)y_{n-1} + \alpha x_n$（指數移動平均，EWMA）。（1）求 $H(z)$、極點位置、穩定性條件；（2）求 -3dB 截止頻率（以 $\alpha$ 與取樣率表示）；（3）對 $\alpha = 0.1$、$f_s = 1000$ Hz 計算截止頻率與階躍響應到達 90% 的時間。

**解**：

（1）取 Z 轉換（假設零初始條件）：$Y(z) = (1-\alpha)z^{-1}Y(z) + \alpha X(z)$，故

$$
H(z) = \frac{\alpha}{1 - (1-\alpha)z^{-1}}.
$$

極點 $z_p = 1 - \alpha$（實數、單位圓內，$\alpha \in (0, 1)$ 時）——**穩定**。衝擊響應 $h_n = \alpha(1-\alpha)^n u_n$（幾何衰減——指數移動平均的字面來源）。

（2）$|H(e^{i\omega})|^2 = \frac{\alpha^2}{(1 - (1-\alpha)\cos\omega)^2 + \big((1-\alpha)\sin\omega\big)^2} = \frac{\alpha^2}{1 - 2(1-\alpha)\cos\omega + (1-\alpha)^2}$。令 $= \frac12$（增益降 3dB）解出

$$
\omega_c = \arccos\!\left(1 - \frac{\alpha^2}{2(1-\alpha)}\right).
$$

（3）$\alpha = 0.1$：$1 - \frac{0.01}{1.8} = 0.9944$，$\omega_c = \arccos(0.9944) \approx 0.1053$ rad，$f_c = \frac{0.1053}{2\pi}\times1000 \approx 16.8$ Hz。階躍響應 $y_n = 1 - (1-\alpha)^{n+1}$；達 90% 需 $(0.9)^{n+1} \le 0.1$，$n + 1 \ge \frac{\ln 0.1}{\ln 0.9} \approx 22$ 拍 = **22 ms**。**解讀**：$\alpha$ 越小，截止越低（濾得越兇）、響應越慢——**「平滑」與「延遲」在這個一階濾波器中由同一參數鎖死**（與 4.3 節例題的窗長交換完全同構，只是離散化）。EWMA 是金融（技術指標）、工控（濾波器初值）、品管（控制圖）通用的「最便宜低通」。

### 歷史啟示

- **從類比到數位的遷移戰**：1960 年代數位電腦速度尚低，設計師的問題是「如何把百年類比濾波器智慧搬進數位」。雙線性變換、脈衝不變法（$h_n = h(nT)$ 取樣）等遷移技術應運而生。**1975 年 Rabiner–Gold《數位訊號處理的理論與應用》** 標誌學科獨立。**新媒體時代的理論往往是舊理論的座標變換**——遷移不是抄襲，是再發明。
- **Parks–McClellan（1972）** 把 Remez 交換算法引入 FIR 設計，配合當時新興的計算機輔助設計，使「給定規格自動出濾波器」成為可能。**算法 + 規格語言 = 自動化設計**，是 CAD 時代的縮影。
- **定點 vs. 浮點**：嵌入式 DSP 晶片（TI C54x 世代）用定點運算，係數量化與溢位是設計的「第二數學」——**同一個 $H(z)$，不同的實現（直接型 vs. 級聯 biquad）可以有不同的數值命運**。理論的濾波器與實現的濾波器之間，隔著量化理論（6.1 節場景三的延伸）。

## 練習

1. 求 $x_n = a^n u_n$ 的 Z 轉換與 ROC；再求 $-a^n u_{-n-1}$ 的轉換，驗證兩者閉式相同、ROC 不同。
2. 求系統 $y_n = 0.9y_{n-1} + x_n + 0.5x_{n-1}$ 的 $H(z)$，標出極點與零點，判斷穩定性，並用長除法求 $h_n$ 的前三項。
3. 用雙線性變換（$T = 1$）把一階類比低通 $H(s) = \frac{1}{1 + s/\omega_c}$ 映到 $z$ 域；驗證極點在單位圓內；說明需要預畸變的原因（比較 $\omega = \omega_c$ 處的增益）。
4. 對稱 FIR：$K = 5$、係數 $h = (h_0, h_1, h_2, h_1, h_0)$。證明其相位精確線性（$H(e^{i\omega}) = e^{-2i\omega}\times$ 實函數），並以 $h = (0.1, 0.25, 0.3, 0.25, 0.1)$（歸一化後）畫出幅值響應特徵（低通、過渡帶、阻帶第一零點）。
5. 思考題：極限環（limit cycle）——IIR 濾波器在定點實現中，輸入為零時輸出可能永久小幅振盪（量化噪聲被極點附近的回授圈住）。查閱：為何 FIR 無此問題？**無回授 = 誤差只衰減不增強**——這條結構性差異如何影響音訊錄音室 vs. 助聽器的晶片選型？

## 進階研讀：數位濾波的五個深化場景

**場景一：多速率與抽取/內插**。**抽取**（decimation，降取樣）與**內插**（interpolation，升取樣）是音訊重取樣（44.1↔48 kHz）、多載波通訊、濾波器組的基礎。**Noble 恆等式**（先濾後抽 = 先抽後濾的交換規則）使多速率系統的計算量最小化——**操作順序即效率**，多速率理論（Croisier–Bellanger–Kunt、Vaidyanathan 1990s）是「濾波 + 重取樣」的代數。

**場景二：濾波器組與子帶編碼**。把頻譜切成子帶（分析濾波器組）、各帶按信噪比分配位元、合成恢復——**MP3/AAC 的心理聲學編碼**就建立在正交鏡像濾波器組（QMF）上。**完美重建條件**（PR）：分析 + 合成濾波器組的總響應 = 純延遲——這組多項式方程的解正是 **2 項小波濾波器**（8.3 節）！**子帶編碼與小波在 1980s 匯流**（Meyer、Mallat、Vetterli 的工作），是「壓縮需求催生數學」的現代案例。

**場景三：自適應濾波**。係數隨資料更新（LMS 算法，Widrow–Hoff 1960）：$h_{n+1} = h_n + \mu\,e_n x_n$（誤差 × 輸入的梯度步）——**回聲消除**（電話會議）、**主動降噪**（耳機！）、**線性預測**（語音編碼 LPC）都是自適應濾波。**LMS 是「隨機梯度下降」在濾波器上的首演**——深度學習優化器的祖先之一。收斂性分析（學習率 $\mu$ 的界、特徵值展開比）用向量空間的二次型語言——10.1 節 Hilbert 空間觀點的實用一面。

**場景四：頻域自適應與 Fast Convolution**。長 FIR 的自適應更新昂貴——**頻域 LMS（FLMS）** 在 FFT 域更新（乘法在頻域、梯度也搬過去），配合重疊儲存，使千階濾波器的自適應即時可行。**「6.3 節 FFT × 本節自適應」= 大回聲消除系統的實際架構**（VoIP 會議橋的核心模組）。

**場景五：圖訊號處理——離開時間軸**。把「序列」推廣為**圖上的訊號**（節點上有值）：圖拉普拉斯 $L$ 的特徵向量扮演傅立葉基、圖濾波 $H(L) = \sum h_k L^k$（多項式濾波）。**圖卷積網路（GCN）= 圖濾波的學習版**。傳遞函數、極點（$L$ 的特徵值）、頻率（變異度）整套語言遷移成功——**「傅立葉」的最終身份是「交換算子族的聯合對角化」**，圖版本是 2010s 的最新成員（10.1 節抽象譜理論的應用前哨）。

### 補充：DSP 晶片的黃金年代

1980 年 **TI TMS32010** 問世：單晶片、單週期乘加（MAC）、Harvard 架構（程式/數據分離匯流排）——**為「$y_n = \sum h_k x_{n-k}$」這一行程式特製的 CPU**。此後 20 年，DSP 晶片統治數據機、手機、MP3 播放器；2000s 後逐漸被通用處理器 + SIMD（以及 DSP 指令融合進 ARM）吸收。**「為一個算法造一個處理器」的專用化浪潮**（DSP → GPU → NPU/TPU）是計算架構史的反覆節奏——FFT 與捲積永遠是第一個被硬化的對象（6.3 節場景的硬體續篇）。

### 名詞速查表（本節出現的核心術語）

- **Z 轉換**：$X(z) = \sum x_n z^{-n}$；離散訊號的複變數表示。
- **ROC**：收斂域；序列身份（因果/反因果）的載體。
- **傳遞函數** $H(z)$：輸出/輸入的 Z 比；LCCDE 的代數化身。
- **極點 / 零點**（Z 平面）：穩定性（圓內）與頻響形狀的載體。
- **$z^{-1}$**：單位延遲；數位記憶的代數符號。
- **IIR / FIR**：無限/有限衝擊響應；效率 vs. 線性相位的兩家族。
- **雙線性變換**：$s \leftrightarrow z$ 的遷移映射；含頻率預畸變。
- **Parks–McClellan**：FIR 等波紋最佳設計（Remez 交換）。
- **線性相位**：對稱 FIR 的精確性質；無色散。
- **Biquad 級聯**：二階節串接；數值穩定的實現常態。
- **LMS / 自適應濾波**：係數在線更新；回聲消除與降噪的核心。
- **濾波器組 / 子帶編碼**：頻譜切分與完美重建；小波的工程前身。
- **多速率 / Noble 恆等式**：抽取內插的交換代數。

### 深化問答三則

**問：Z 轉換和 DTFT 是什麼關係？**
答：DTFT（單位圓取樣）$X(e^{i\omega}) = X(z)|_{z = e^{i\omega}}$ 是 Z 轉換的「赤道切面」。Z 轉換多了**徑向自由度**（ROC），因此能區分因果性、能做極點分析、能處理 DTFT 發散的序列（ROC 不含單位圓但含 $z = 2$）。**DTFT 是「頻率報表」，Z 轉換是「完整地圖」**——工程上先看赤道、必要時看全域。

**問：為什麼音訊圈如此執著「線性相位」？**
答：因為非線性相位 = **不同頻率延遲不同** = 波形畸變（即使幅值響應平坦）。人耳對短暫波形的相位畸變敏感（暫態、定位）。對稱 FIR 的線性相位保證「只延遲、不變形」——監聽鏈、母帶處理、專業混音的標準訴求。但注意：聽覺研究對「絕對線性相位是否可聞」仍有爭議——**工程保守主義與心理聲學的前沿在此交錯**。

**問：既然 IIR 效率高，為何 FIR 反而成為 AI 時代的寵兒？**
答：FIR 的**無回授結構**使其（1）可並行化（每個輸出獨立計算——GPU/矩陣友好）；（2）數值行為可預測（無極限環、無條件穩定）；（3）可學習（CNN 卷積核就是可訓練 FIR）。**結構的平行性與可微性，在硬體與深度學習時代比漸近效率更值錢**——IIR 仍在低功耗控制中稱王，但主流訊號鏈已向 FIR 遷移。
