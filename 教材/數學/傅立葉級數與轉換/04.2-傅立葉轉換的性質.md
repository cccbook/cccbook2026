# 4.2 傅立葉轉換的性質

## 本章導言

掌握了傅立葉轉換的定義與反演（4.1 節）之後，本節編纂它的**操作手冊**：微分、平移、縮放、調變、乘積、對偶——每一條性質都是「時域操作 $\leftrightarrow$ 頻域操作」的雙語詞典。這份詞典是傅立葉方法真正強大的原因：**把難的運算換到另一邊變成容易的運算**。本節還將透視一條深層結構：轉換的不動點與自對偶性（Gauss 函數、Hermite 函數），以及由對偶性導出的「時域微分 = 頻域乘 $i\omega$」——這條性質把微分方程變成代數方程，是第 9 章全部應用的引擎。

### 操作手冊：核心性質表

設 $f, g$ 滿足必要可積條件，$\hat f(\omega) = \int f(t)e^{-i\omega t}dt$。

| 時域操作 | 頻域效果 | 證明要點 | 直觀比喻 |
|----------|----------|----------|----------|
| 平移 $f(t - a)$ | $e^{-i\omega a}\hat f(\omega)$ | 變數替換 $s = t - a$ | 延遲 = 相位斜坡 |
| 調變 $e^{i\omega_0 t}f(t)$ | $\hat f(\omega - \omega_0)$ | 積分因式合併 | 搬頻：譜整體平移 |
| 縮放 $f(at)$，$a \ne 0$ | $\dfrac{1}{\|a\|}\hat f\!\left(\dfrac{\omega}{a}\right)$ | 替換 $s = at$ | 時間壓縮 = 頻率擴張 |
| 微分 $\dfrac{df}{dt}$ | $i\omega\,\hat f(\omega)$ | 分部積分（$f\to 0$ 於無窮遠） | 求導 = 乘 $i\omega$ |
| 積分 $\displaystyle\int_{-\infty}^{t} f$ | $\dfrac{\hat f(\omega)}{i\omega} + \pi\hat f(0)\delta(\omega)$ | 微分之逆 | 積分 = 除以 $i\omega$（+直流項） |
| 乘法 $f(t)g(t)$ | $\dfrac{1}{2\pi}(\hat f * \hat g)(\omega)$ | Fubini + 反演 | 時域相乘 = 頻域捲積 |
| 捲積 $(f*g)(t)$ | $\hat f(\omega)\hat g(\omega)$ | Fubini，換序 | **捲積定理**（4.3 節主角） |
| 共軛 $\overline{f(t)}$ | $\overline{\hat f(-\omega)}$ | 共軛入積分 | 實函數譜的對稱性 |
| 反轉 $f(-t)$ | $\hat f(-\omega)$ | 替換 | 反轉的譜也反轉 |

**重點條目的證明**：

- **微分性質**：$\widehat{f'}(\omega) = \int f'e^{-i\omega t}dt = \left[f e^{-i\omega t}\right]_{-\infty}^{\infty} + i\omega\int f e^{-i\omega t}dt = i\omega\hat f(\omega)$（邊界項要求 $f\to0$，$L^1$ 中夠好的函數可滿足）。**時域求導 = 頻域乘 $i\omega$**——2.1 節「價碼表」的理論化：微分放大高頻，故雜訊被放大。
- **縮放性質**：$\widehat{f(at)}(\omega) = \int f(at)e^{-i\omega t}dt = \frac{1}{|a|}\int f(s)e^{-i\frac{\omega}{a}s}ds = \frac{1}{|a|}\hat f\left(\frac{\omega}{a}\right)$。**時頻互斥的種子**（8.1 節）：壓縮時間必然擴張頻譜，乘積 $|a|\cdot\frac1{|a|}$ 守恆。
- **平移性質**：$f(t-a)$ 的譜是 $\hat f(\omega)$ 乘以 $e^{-i\omega a}$——**只改相位、不改幅值**，因此 $|\widehat{f(\cdot - a)}| = |\hat f|$：能量譜對平移不變。這就是為什麼功率譜（3.1 節）「看不見」時間原點，也是第 8 章需要短時方法（丟掉平移不變性換取時間定位）的根源。

### 對偶性與自對偶函數

傅立葉轉換有近乎完美的對稱：正變換與反變換只差 $\frac{1}{2\pi}$ 與指數的符號。由此得**對偶原理**：若 $g = \hat f$，則 $\hat g(\omega) = 2\pi f(-\omega)$——**對 $f$ 成立的公式，把時頻互換、乘 $\frac{1}{2\pi}$、反轉後仍然成立**。對偶使性質表的記憶量減半（捲積定理 $\Leftrightarrow$ 乘法定理即同一條的對偶）。

**自對偶（不動點型）函數**是傅立葉分析的「神聖幾何」：

1. **Gauss 函數** $e^{-t^2/2}$：$\widehat{e^{-t^2/2}} = \sqrt{2\pi}\,e^{-\omega^2/2}$——形狀完全自相似（僅常數差；用對稱歸一化 $\frac{1}{\sqrt{2\pi}}$ 後是不動點）。**Gauss 是時頻最平衡的波形**，8.1 節證明它是測不準原理的唯一極小值點。
2. **Hermite 函數** $h_n(t) = H_n(t)e^{-t^2/2}$：$\hat h_n = (-i)^n\sqrt{2\pi}\,h_n$——特徵函數，特徵值 $(-i)^n \in \{1, -i, -1, i\}$。**傅立葉轉換的譜（作為算子）恰好是這四個值**，因為 $\mathcal{F}^4 = I$（四次轉換回到原函數）。分數傅立葉轉換（光學、8.2 節）定義為 $\mathcal{F}^\alpha$——把「旋轉時頻平面 $\alpha\times 90°$」數學化。
3. **sinc 函數與矩形窗**：互為對偶對（例題 4.1.1 的反面）——矩形 $\leftrightarrow$ sinc。**有限時窗的譜是 sinc；帶限訊號的波形是 sinc**——同一對偶，兩個行業各取所需（6.1 節取樣插值用後者）。

### 複平面技術：留數與圍道

對解析函數（如 $e^{-a|t|}$ 型、有理型），傅立葉積分可用**圍道積分**閉式計算：把 $\omega$ 延拓到複平面，用 Jordan 引理把半圓弧上的積分消去，剩下極點的殘數。範例：$\widehat{e^{-a|t|}} = \frac{2a}{a^2 + \omega^2}$——Lorentzian；其在複平面的極點 $\omega = \pm ia$ 的**離實軸距離**就是時域指數衰減率 $a$。**一般規律：時域衰減越慢，頻域極點離軸越近，譜峰越尖**——2.1 節價碼表的複分析版本，也是共振系統（RLC 電路、機械振動）「極點位置定頻寬」的數學基礎（7.1 節）。

### 一個具體例題

**例題 4.2.1**：利用性質表「組裝」計算：（1）$g(t) = e^{-a t}u(t)\cos\omega_0 t$（單邊指數衰減的餘弦，模擬按鈴後的餘音）的傅立葉轉換；（2）$h(t) = t\,e^{-t^2/2}$ 的轉換（用微分性質）；（3）說明（1）的結果如何體現「共振峰 + 衰減寬度」的關係。

**解**：

（1）先備兩個基本譜：$u(t)e^{-at}$（$u$ 為單位階躍）的譜為 $\frac{1}{a + i\omega}$（$\int_0^\infty e^{-(a+i\omega)t}dt$）；由平移性質，$\cos\omega_0 t = \frac{e^{i\omega_0 t} + e^{-i\omega_0 t}}{2}$ 把譜**分裂平移**成

$$
\hat g(\omega) = \frac12\left[\frac{1}{a + i(\omega - \omega_0)} + \frac{1}{a + i(\omega + \omega_0)}\right] = \frac{a + i\omega}{(a + i\omega)^2 + \omega_0^2}.
$$

幅值譜在 $\omega = \pm\omega_0$ 有雙峰，**峰寬（半高全寬）$= 2a$**：衰減越快（$a$ 大）峰越寬——時域短命、頻域含糊，測不準原理的工程面孔。

（2）$t\,e^{-t^2/2}$：由 Gauss 自對偶 $\widehat{e^{-t^2/2}} = \sqrt{2\pi}\,e^{-\omega^2/2}$ 與微分性質的對偶版（$-it\,f(t) \leftrightarrow \frac{d}{d\omega}\hat f$）：

$$
\widehat{t\,e^{-t^2/2}}(\omega) = i\,\frac{d}{d\omega}\left[\sqrt{2\pi}\,e^{-\omega^2/2}\right] = -i\sqrt{2\pi}\,\omega\,e^{-\omega^2/2}.
$$

（3）（1）顯示：餘音的譜是兩根共振峰，峰位 = 振動頻率、峰寬 = 阻尼——**從頻譜讀出振子的兩個參數**，這是模態分析（橋樑監測、樂器聲學）的原理；（2）顯示：時域乘 $t$ = 頻域求導——Hermite 家族就這樣逐級生成（$h_1 = 2t e^{-t^2/2}$ 是第一個非平凡特徵函數）。

### 歷史啟示

- **性質表就是生產力**：Fourier 本人在 1822 年書中已系統列出微分、平移性質（以餘弦變換形式）。**定理的價值一半在陳述、一半在操作手冊**——數學教學常重前者輕後者，工程則相反；本書力求並重。
- **對偶是記憶的槓桿**：捲積定理與乘法定理是同一條對偶式。學會「對偶地讀表」，性質表從 18 條變 9 條。
- **自對偶函數是理論的試金石**：Gauss、Hermite 這些「不動點」在測不準原理（8.1）、相干態（8.2）、量子諧振子的本徵態（9 章）反覆擔任極值點與基——**轉換的不動點是跨領域的特殊座標**。

## 練習

1. 用性質表計算 $f(t) = e^{-a|t|}\cos\omega_0 t$ 的轉換，並與例題（1）的單邊版比較：雙邊版譜是實函數（偶對稱），單邊版有虛部——說明「時域不對稱 → 頻域相位斜坡」。
2. 證明對偶原理：$\hat g(\omega) = 2\pi f(-\omega)$（$g = \hat f$），並用它由捲積定理推出乘法定理。
3. 用微分性質解 ODE：求 $y' + ay = f$（$y(-\infty) = 0$）的解，答案為 $y = (f * h)$、$h(t) = e^{-at}u(t)$——這是 7.1 節 LTI 系統衝擊響應的雛形。
4. 證明 $\mathcal{F}^2 f(t) = 2\pi f(-t)$（兩次轉換 = 反轉），從而 $\mathcal{F}^4 = I$。
5. 思考題：音樂的「音高」對應譜峰位置、「音色」對應譜形、「節奏」對應譜包絡的時域結構。用性質表解釋：為什麼把一段音樂快放（$a > 1$）會音調升高（縮放性質）？為什麼延遲播放不變音色（平移不變幅值譜）？

## 進階研讀：性質表的五個深化場景

**場景一：不確定性的初現**。縮放性質 $\widehat{f(at)} = \frac1{|a|}\hat f(\omega/a)$ 暗示時寬 $\times$ 頻寬在縮放下不變——這個不變量的下界就是 Heisenberg 型不等式（8.1 節）：$(\Delta t)^2(\Delta\omega)^2 \ge \frac14$，等號僅 Gauss。本節的縮放表條目是測不準原理的「前傳」。

**場景二：相位的重要性**。幅值譜 $|\hat f|$ 決定能量（Plancherel），但**相位譜** $\arg\hat f$ 決定波形細節：兩幅值譜相同、相位不同的訊號波形迥異（例：同一濾波器的零相位 vs. 線性相位版本，時域對稱性不同）。影像處理的名實驗（Oppenheim）：取影像 A 的幅值 + 影像 B 的相位做反變換——結果長得像 B！**相位攜帶「結構」，幅值攜帶「能量」**。相位恢復（phase retrieval）今日是 X 射線晶體學與計算成像的核心數學問題。

**場景三：快速衰減函數的 Schwartz 空間**。第 5 章將定義 **Schwartz 空間** $\mathcal{S}$：$f$ 與一切導數都衰減快於任意多項式倒數。$\mathcal{S}$ 在傅立葉轉換下**不變**（微分性質 + 縮放性質聯手），且轉換是 $\mathcal{S}$ 上的同構——這使 $\mathcal{S}$ 成為傅立葉理論最舒適的舞台（一切運算合法、一切交換免檢）。5.2 節 Schwartz 分配理論正以 $\mathcal{S}$ 為試驗函數空間。

**場景四：短時衰減與 Paley–Wiener**。$\hat f$ 的支撐與解析性控制 $f$ 的衰減：**Paley–Wiener 定理**（1934）：$\hat f$ 支撐在 $[-B, B]$ $\Leftrightarrow$ $f$ 是指數型整函數（帶限訊號的解析性，6.1 節）；更細的版本把「$\hat f$ 的支撐端點附近的行為」與「$f$ 的代數衰減率」對應起來——**頻域的銳利邊緣 = 時域的多項式尾巴**（sinc 的 $\frac1t$ 尾巴即例）。時頻互斥的精確版圖在 Paley–Wiener 理論中完成。

**場景五：分數傅立葉轉換與光學**。光學系統中，透鏡實現「空間頻譜」（Fraunhofer 繞射 = 物面的傅立葉變換）、而球面波傳播對應時頻平面的小角度旋轉——**分數傅立葉轉換** $\mathcal{F}^\alpha$（Namias 1980；光學詮釋 Mendlovic–Ozaktas 1993）把「繞射 $\to$ 成像」的連續過程表為 $\alpha$ 從 $\frac{\pi}{2}$ 連續變到 $0$。Hermite 函數作特徵函數、譜 $(-i)^n$ 作旋轉半徑——4.2 節的代數在光學實驗室裡字面成真。

### 補充：微分性質的「危險使用須知」

$\widehat{f'} = i\omega\hat f$ 要求邊界項消失：$f(t)\to 0$（$t\to\pm\infty$）。若 $f$ 是常數或階躍，邊界項非零，公式**失效**——正確處理需要 $\delta$（第 5 章：$\widehat{1} = 2\pi\delta$，微分後 $\widehat{0} = 0$，但 $i\omega\cdot 2\pi\delta$ 是分配意義的運算，剛好為零——分配理論把例外也收編）。**性質表的每一行都暗含適用條件**；分配理論（第 5 章）的哲學正是「把條件內建進對象的定義，使表變成無條件成立」。

### 名詞速查表（本節出現的核心術語）

- **平移性質**：時移 = 乘相位因子 $e^{-i\omega a}$；幅值譜不變。
- **調變性質**：乘 $e^{i\omega_0t}$ = 譜平移；AM 通訊的基礎。
- **縮放性質**：時域壓縮 = 頻域擴張；測不準的種子。
- **微分性質**：$\widehat{f'} = i\omega\hat f$；ODE 代數化的鑰匙。
- **捲積定理 / 乘法定理**：一條對偶的兩面。
- **對偶原理**：時頻互換 + 常數調整，公式成對。
- **Gauss 自對偶**：唯一測不準極小值波形。
- **Hermite 函數**：$\mathcal{F}$ 的特徵函數；$\mathcal{F}^4 = I$。
- **分數傅立葉轉換**：$\mathcal{F}^\alpha$，時頻平面旋轉。
- **Paley–Wiener 定理**：頻域支撐 $\leftrightarrow$ 時域解析/衰減的精確對應。
- **Schwartz 空間** $\mathcal{S}$：無窮光滑 + 快速衰減；FT 的不變舞台。

### 深化問答三則

**問：為什麼微分性質是「最重要的」性質？**
答：因為科學的語言是微分方程，而微分性質把「求導」變成「乘 $i\omega$」——**微積分問題降維成代數問題**。9.3 節的 Laplace 變換解 ODE、9.1 節的熱方程譜解、7.1 節的系統分析，全部是這一條性質的職業生涯。

**問：幅值譜相同、相位不同的兩個訊號，聽起來一樣嗎？**
答：人耳對短時幅值譜敏感、對相位相對遲鈍（但相位決定瞬時波形與定位）。語音的「相位失真」在小範圍可容忍，影像則反過來（相位主導輪廓）。**感覺系統選擇了不同的時頻權衡**——這也是壓縮演算法按媒體類型分道（MP3 vs. JPEG）的心理物理根據。

**問：$\mathcal{F}^4 = I$ 有什麼實際用處？**
答：三個用處。（1）**算法檢驗**：對 FFT 實現做 $\mathcal{F}^2$、$\mathcal{F}^4$ 自洽測試；（2）**對偶設計**：任何時域演算法立刻免費得到一個頻域孿生（對偶原理）；（3）**分數推廣**：$\mathcal{F}^\alpha$ 提供連續可調的時頻旋轉，在 Chirp 訊號檢測（線性調頻）中，選對 $\alpha$ 可把 Chirp 壓成一個衝——訊號處理的「換座標找簡單」。
