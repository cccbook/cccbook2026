# 影音與數學

從透視法到擴散模型——一本以「影音 ⇄ 數學」互相驅動為主軸的教科書。影像、影片、音樂的本質是訊號與幾何；JPEG、MPG、MP3 是把人類感知的「冗餘」用數學剝掉的工程。全書追問同一個問題：**人如何感知，機器就如何計算。**

## 本書的方法論

每節遵循同一敘事結構：

1. **問題**：當時的感知/藝術/工程困境是什麼？
2. **數學**：什麼數學被發明或引入？
3. **後果**：如何改變了影音技術？
4. **回饋**：技術的反省如何催生新數學？
