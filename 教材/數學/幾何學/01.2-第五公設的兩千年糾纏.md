# 1.2 第五公設的兩千年糾纏

## 本章導言

一條公設，糾纏數學界兩千年——這在數學史上絕無僅有。Euclid 的第五公設（平行公設）因其冗長與不直觀，從古希臘晚期開始就被視為《原本》的「瑕疵」。無數一流頭腦前赴後繼，企圖把它從公理降格為定理，全部失敗；而這兩千年的失敗史，最終在十九世紀釀成幾何學的哥白尼革命：**非歐幾何的誕生**。本節回顧這條糾纏之路的關鍵驛站，直達 Lobachevsky 與 Bolyai 的黎明前夜。

### 第五公設的等價命題群

第五公設原文（見 1.1 節）處理的是「同側內角和小於兩直角則兩線相交」。後世把它改寫成更順口的形式。以下命題彼此**等價**（在絕對幾何——前四公設推出的全部定理——的框架下）：

1. **Playfair 公理**（1795，實為 Proclus 已述）：過直線外一點，恰有**一條**直線與之平行。
2. 三角形內角和等於 $180°$。
3. 存在一個內角和為 $180°$ 的三角形。
4. 存在相似而不全等的三角形。
5. 存在面積任意大的三角形。
6. 圓內接六邊形三組對邊平行（即存在內接正六邊形邊長等於半徑）。
7. 直角三角形斜邊的平方等於兩直角邊平方和（Pythagoras 定理的全域成立）。

注意等價命題3與4的精妙：只要**一個**三角形內角和為 $180°$，就足以斷定歐氏幾何成立；只要**存在**大小不同但形狀相同的三角形，平行公設就在場。反過來說，在非歐幾何中，相似形退化為全等形——形狀決定大小，這是非歐世界的驚人特徵。

### Proclus 的批評與古代攻防

新柏拉圖主義哲學家 **Proclus（普羅克洛斯，412–485）** 在《評註》中留下了最早的系統批評：

> 「此公設應當完全從公理中刪去。它是一個需要證明的定理。」

Proclus 記錄了 Ptolemy（二世紀）的「證明」及其錯誤，並給出自己的嘗試——他證明了一個關鍵引理：**若過線外一點恰有一條平行線，則同側內角和不能大於兩直角**。但他隨後偷用了「距離不會無界增長」的直觀假設——這個假設本身等價於第五公設。**「等價命題的循環」**成為兩千年攻防的宿命模式：每個「證明」都在暗中假設了某個等價命題。

### 阿拉伯世紀：ibn al-Haytham 與 Omar Khayyám

伊斯蘭黃金時代接棒。**ibn al-Haytham（伊本·海賽姆，約965–1040）** 用「運動學方法」嘗試證明：設想一條線段的端點垂直移動掃出矩形——批評者指出這引入了「移動的線」這一非幾何概念，且暗中假設了掃過的軌跡寬度處處相等（又回到等距假設）。

**Omar Khayyám（歐瑪爾·海亞姆，1048–1131）**——以《魯拜集》詩名傳世、以曆法改革聞名——則提出更精緻的方案：考慮「薩凱里四邊形」的前身，兩底角皆為直角、兩腰相等的四邊形，討論頂角是直角、鈍角還是銳角。他的論證已觸及非歐幾何的核心分岔，惜受限於哲學立場（頂角必須是直角，否則「不合理」）而止步。

### Saccheri：離非歐幾何一步之遙

**Girolamo Saccheri（薩凱里，1667–1733）**，耶穌會士，1733年出版《歐幾里得無懈可擊》（Euclides ab omni naevo vindicatus）——書名宣告使命，內容卻幾乎發明了非歐幾何。

他考慮**薩凱里四邊形**：$AB \perp AD$、$BC \perp AD$、$AB = CD$（兩個直角、兩腰相等）。可證 $\angle B = \angle C$。三種假設：

- **銳角假設**：$\angle B = \angle C < 90°$
- **直角假設**：$\angle B = \angle C = 90°$
- **鈍角假設**：$\angle B = \angle C > 90°$

直角假設等價於第五公設。Saccheri 證明鈍角假設與「直線可無限延長」矛盾（公設2排除它——它實際上活在球面上，只是那裡直線要重新定義見 6.3 節）。然後他進攻銳角假設，一路推得大量奇異定理（過線外一點有無窮多條平行線、三角形內角和小於 $180°$、面積由角虧決定），幾乎建立了雙曲幾何的全部基礎，最後以一句曖昧的「這與直線的本性矛盾」草草收場。

**他距離非歐幾何只差一個思想動作：承認矛盾不存在的可能。** Saccheri 的悲劇在於：他的方法完全正確，他的目的（「排除」）卻讓他對自己證出的東西視而不見。

### Lambert：銳角假設的量化研究

**Johann Heinrich Lambert（蘭伯特，1728–1777）**，1766年寫成《平行線理論》（死後1786年出版），比 Saccheri 更進一步：

1. 他用**三直角四邊形**做同樣的三分法，並系統研究銳角假設下的面積：發現三角形面積正比於角虧 $\delta = \pi - (A + B + C)$——這正是日後雙曲幾何的公式（見 6.2 篂）！
2. 他注意到：在鈍角假設下，面積正比於角盈，而球面三角形恰好如此——**鈍角幾何 = 球面幾何**（半徑為虛數的球面！Lambert 猜測「虛半徑球面」上實現銳角幾何——這個猜想在十九世紀完全應驗）。
3. 他寫下關鍵的開放語氣：「由此我幾乎不得不推論：第五公設不成立的幾何，或許可以自洽地存在。」

Lambert 已站在門口，但他沒有推門——他無法想像「實在的空間」可以不是歐氏的。

### Legendre 的執著與 Wallis 的嘗試

**Adrien-Marie Legendre（勒讓德，1752–1833）** 在其《幾何原理》（1794–1823多版）中反覆嘗試證明第五公設，給出多個「證明」又逐版撤回。他證得的最重要結果：**若存在一個三角形內角和為 $\pi$，則一切三角形皆然**（等價命題3），以及內角和不超過 $\pi$（絕對幾何定理，即 Saccheri–Legendre 定理）。他晚年仍不甘：「至今無人能給出第五公設的證明，也無人能否證。」——這份誠實成為後繼者的路標。

**John Wallis（沃利斯，1616–1703）** 1663年的嘗試則假設「存在相似而不全等的三角形」（等價命題4），實質是以另一條「更直觀」的公理替換第五公設——換湯不換藥，但他的講稿讓歐洲數學界持續關注此問題。

### Gauss 的沉默

**Carl Friedrich Gauss（高斯，1777–1855）** 早在1792年（15歲）就開始思考平行公設，1810年代私下得出結論：**否定第五公設的幾何完全自洽**。他甚至實測三座山頭（Brocken、Hohenhagen、Inselsberg）構成的三角形內角和，檢驗實際空間是否歐氏——差異在測量誤差內。

但他**終生不發表**。1818年起他私下通信透露：「我害怕愚昧者的叫囂（Boeotier 的鼓譟）。」他的沉默使非歐幾何的桂冠落到兩位年輕人頭上——而其中一位，正是他的摯友之子。

### 一個具體例題

**例題 1.2.1**：證明「三角形內角和等於 $180°$」與第五公設等價（絕對幾何框架下）。

**解**：分兩個方向。

**方向一（第五公設 $\Rightarrow$ 內角和 $180°$）**：設 $\triangle ABC$。延長 $BC$ 至 $D$，過 $C$ 作 $CE \parallel BA$（第五公設保證過 $C$ 恰有一條平行線）。則 $\angle A = \angle ACE$（內錯角相等，此為 I.29，恰需第五公設），$\angle B = \angle ECD$（同位角）。故

$$
\angle A + \angle B + \angle ACB = \angle ACE + \angle ECD + \angle ACB = \angle ACD = 180°.
$$

**方向二（內角和 $180°$ $\Rightarrow$ 第五公設）**：設直線 $l$ 外一點 $P$。過 $P$ 作 $m \parallel l$（存在性由絕對幾何的 I.27 保證）。設 $n$ 是過 $P$ 的任一其他直線，與 $m$ 夾角 $\theta$（$0 < \theta < 180°$，不妨 $\theta < 90°$）。在 $n$ 上取 $Q$，作 $\triangle PQR$ 使 $R$ 在 $l$ 側，並取 $Q'$ 使 $PQ' = PQ$ 且角配置對稱。由內角和 $180°$ 可推出相似三角形存在（Legendre 的連鎖論證：內角和 $180°$ 可得薩凱里四邊形頂角為直角，進而得相似三角形與位似放大），因此可將三角形放大，使第三頂點越過 $l$，迫使 $n$ 與 $l$ 相交。故過 $P$ 只有唯一平行線 $m$。

**評注**：方向二正是兩千年來所有人繞的圈子——「內角和 $180°$」看似比第五公設自然，其實兩者是同一枚硬幣的兩面。在雙曲幾何中內角和小於 $180°$ 且隨面積變小，在球面上則大於 $180°$（見 6.3 節）。

### 歷史啟示

- **「顯然」是最強的成見**：兩千年間，障礙不是智力而是想像力——沒有人敢於認真考慮「空間可能不是歐氏的」。Saccheri 手握全部鑰匙卻拒絕開門。
- **失敗的研究也是研究**：兩千年的失敗積累了等價命題群、薩凱里四邊形、角虧公式——非歐幾何不是 1829 年憑空出現的，它是兩千年失敗的沉澱物結晶而成。
- **一致的體系未必描寫「實在」**：非歐幾何迫使人類承認，數學體系的真理性在於內部一致性，而非與直觀或物理空間的吻合。這是數學觀念論的第一次勝利，也為二十世紀數學的多元世界打開大門。

## 練習

1. 證明「存在相似而不全等的三角形」與第五公設等價（可從例題方向二借用論證）。
2. 薩凱里四邊形中，證明 $\angle B = \angle C$（提示：連對角線，用 SAS 與 SAC 全等）。
3. 用 Playfair 公理證明：同位角相等 $\Rightarrow$ 兩線平行（即 I.29 的內容），並指出哪一步用到唯一性。
4. Lambert 觀察到「面積正比於角虧」在銳角假設下成立。設三個三角形滿足可加性，推導 $\delta(\triangle_1 \cup \triangle_2) = \delta_1 + \delta_2$，說明這為何支持「面積 $= k\delta$」。
5. 思考題：Gauss 因「害怕叫囂」而不發表。你認為數學家對革命性成果應當即時發表還是謹慎觀望？從非歐幾何的歷史給出你的論證。

## 進階研讀：公設糾纏的五個深化場景

**場景一：等價命題的「距離」並不平等**。同樣與第五公設等價，但等價的「代價」不同：Playfair 公理的證明幾乎不需工具，而「存在內接正六邊形」的等價證明需要圓的性質。數學家後來發展出「絕對幾何中命題的強度階層」研究——哪些非歐定理需要多少歐氏假設——這正是今日**逆幾何**（reverse mathematics）的先聲：確定定理與公理的最小匹配。

**場景二：Saccheri 的「replusio」為何不成立**。Saccheri 在證明鏈末端寫道銳角假設「自相矛盾」，他的論證依賴「過線外一點的直線束中存在到 $l$ 距離無界增長的成員，故必有垂直線」——但這個「距離函數達到最小值後回升」的性質在雙曲幾何中並不導出垂直線：距離單調遞減趨於極限線（horocycle 方向），永不相交。距離函數可以「漸近而不觸底」——這個可能性需要極限概念（參見《微積分》第1章）才能精確描述，十八世紀的幾何學家缺乏這件工具。

**場景三：天文學的隱形證人**。Stellar 觀測其實檢驗過第五公設：恆星視差的測量在某種意義上對應三角形內角和。Gauss 的山頭測量精度（角秒級）遠不足以區分曲率半徑為宇宙尺度的非歐空間與歐氏空間。這提出深刻問題：**幾何是先驗的還是經驗的？** Riemann 1854 年講演與 Einstein 1915 年給出了答案：空間幾何是物理量，由質能分布決定。

**場景四：非歐幾何的「發明權」第三候選人**。喀山教授 Ferdinand Karl Schweikart（1780–1859）在1818年私下寫給 Gauss 一份備忘錄，稱否定第五公設的幾何為「星空幾何」（astral geometry），Gauss 回信確認其正確。Schweikart 沒有深入發展，但這說明：當問題成熟時，多個頭腦同時逼近答案——這是「同時發現」現象的又一案例（與 Newton–Leibniz、Darwin–Wallace 呼應）。

**場景五：一致性問題的現代迴響**。Beltrami 1868 年的模型把「雙曲幾何一致」化歸為「歐氏幾何一致」——但歐氏幾何自身的一致性呢？化歸鏈條（雙曲 → 歐氏 → 實數算術 → 集合論）在 Gödel 之後我們知道無法在系統內完成。第五公設的兩千年糾纏，最終接上了二十世紀數學基礎的核心難題：**我們永遠無法絕對地證明任何足夠豐富的體系無矛盾**——只能相對化、只能相信。

### 補充：三種幾何的薩凱里四邊形對照

| 幾何 | 頂角 | 平行線數 | 內角和 | 面積公式 |
|------|------|----------|--------|----------|
| 雙曲 | 銳角 | 無窮多 | $< 180°$ | $k^2 \delta$ |
| 歐氏 | 直角 | 恰一條 | $= 180°$ | 與角虧無關 |
| 球面/橢圓 | 鈍角 | 無（任意兩大圓相交） | $> 180°$ | $R^2(\alpha + \beta + \gamma - \pi)$ |

表中「面積由角差決定」在三種幾何中對稱出現——這是 Gauss–Bonnet 定理的初等影子，該定理的現代形式在《微分幾何》一書中闡述。

### 補充：中世紀的第三條戰線——Levi ben Gerson

猶太數學家 **Levi ben Gerson（1288–1344）** 在1321年的《度量之書》中系統批評既有證明，主張第五公設不可證、只能作為公理接受——這個「不可證論」立場比 Saccheri 的三分法更接近最終答案。可惜其工作長期不被拉丁世界知曉，直到十九世紀末才被數學史家挖掘。數學史的敘事常以「勝利者」為軸，實際上「正確的失敗者」與「被遺忘的先知」同樣塑造了學科的走向。

### 名詞速查表（本節出現的核心術語）

- **絕對幾何**：僅用前四公設（及公理）能證明的全部定理。
- **Playfair 公理**：過線外一點恰有一條平行線；第五公設的通行等價形式。
- **薩凱里四邊形**：兩底角直角、兩腰相等的等腰雙直角四邊形。
- **銳角／直角／鈍角假設**：薩凱里四邊形頂角的三種可能，對應三種幾何。
- **角虧（defect）**：$\pi$ 減去三角形內角和；雙曲幾何中與面積成正比。
- **角盈（excess）**：球面三角形內角和超過 $\pi$ 的部分。
- **漸近線（asymptotic line）**：雙曲幾何中「向一側漸近於給定直線」的平行線。
- **星空幾何**：Schweikart 對非歐幾何的命名。
- **等價命題**：在絕對幾何中與第五公設互相推出的命題。
- **相對一致性**：以模型把一體系的一致性化歸為另一體系的方法。

### 深化問答三則

**問：為什麼兩千年間沒有人「乾脆」構造一個反例模型？**
答：因為模型需要一個母體系來容納它。構造雙曲幾何模型需要實數連續統、座標方法與距離函數的抽象概念——這些要到十九世紀才齊備。Beltrami 用偽球面（tractrix 旋轉面）的測地線實現局部雙曲幾何，Poincaré 用圓盤與 Möbius 變換實現全局模型（6.2 節）——模型方法本身是十九世紀抽象化浪潮的產物。**要否定一個世界，你需要先學會建造世界。**

**問：Saccheri 算不算非歐幾何的發現者？**
答：他是「未發現的發現者」。他證出的定理（平行線無窮多、面積角虧公式）全屬雙曲幾何，但他把這些視為「矛盾」的證據鏈。科學史學界的一般共識：發現的標準是**認知**——知道自己的怪物是什麼。以此標準，Lobachevsky 與 Bolyai 才是發現者，正如觀察到新星的望遠鏡操作員不等於天文學的發現者。

**問：第五公設的糾纏對「科學革命的形態」有什麼啟示？**
答：Kuhn 式革命需要「反常積累」與「範式候選」同時就位。本節顯示的圖景更精細：反常（第五公設的不自然）積累了兩千年，範式候選（Lambert 的開放態度、Gauss 的結論）也在醞釀，真正缺少的是**勇氣加傳播**——Lobachevsky 的偉大在於他敢於出版並面對嘲笑（他的手稿被喀山審查委員會退回，最後自費印行）。革命常在「所有材料備齊後的那個人敢說出口」的時刻發生。
