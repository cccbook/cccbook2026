# 1.3 上下極限與 Bolzano–Weierstrass 定理

## 本章導言

1817 年，**Bolzano（波爾查諾，Bernard Bolzano，1781–1848）** 在布拉格發表《二項定理的反證法證明與純粹分析的證明》（Rein analytischer Beweis），首次嚴格陳述並證明了一個至今以他與 **Weierstrass** 命名的定理：**有界無窮序列必有收斂子列**。這條定理是完備性的「序列面孔」，是中間值定理、極值定理、Heine–Borel 定理的共同祖先。本節同時引入**上下極限**——把「不收斂」的序列也納入精確分析的語言。

### Bolzano：被遺忘四十年的人

Bolzano 是波希米亞的天主教神父與哲學家，因宗教與社會觀點於 1819 年被解除布拉格大學教職，此後作品大多無法公開出版或難以流通。他的 1817 年論文包含：

- $\varepsilon$–$\delta$ 連續性的首次嚴格定義（早於 Weierstrass 約四十年）；
- 中間值定理的嚴格證明（以最小上界原理為引擎）；
- 有界序列存在收斂子列的證明。

然而 Bolzano 的著作在當時幾乎無人閱讀。1860 年代，Weierstrass 在柏林的講義獨立重述並推廣了這些結果（含多維版本），經由學生（Cantor、Kovalevskaya、Mittag-Leffler 等的筆記）傳遍歐洲。史家如今稱 1817 年論文為「分析算術化（arithmetization of analysis）的起點」，但影響是**事後追認**的——正規的傳播網絡（期刊、大學、師承）缺席，再好的數學也會沉睡。

### 上極限與下極限：不收斂的序列也能分析

**定義**：對序列 $(a_n)$，定義

$$
\limsup_{n\to\infty} a_n = \lim_{n\to\infty} \sup_{k \ge n} a_k, \qquad \liminf_{n\to\infty} a_n = \lim_{n\to\infty} \inf_{k \ge n} a_k.
$$

（尾項集的上確界隨 $n$ 增大而不增，故極限總存在——允許 $\pm\infty$。）

直觀：$\limsup$ 是「序列反覆達到的高度」，$\liminf$ 是「序列反覆跌到的深度」。

**關鍵性質**：

| 性質 | 敘述 |
|------|------|
| 收斂判準 | $a_n$ 收斂 $\iff$ $\limsup a_n = \liminf a_n$（皆有限） |
| 子列刻畫 | $\limsup a_n$ 是所有收斂子列極限中的最大者；$\liminf$ 為最小者 |
| 比較 | $a_n \le b_n$（最終）$\Rightarrow \limsup a_n \le \limsup b_n$ 且 $\liminf a_n \le \liminf b_n$ |
| 和差 | $\liminf a_n + \liminf b_n \le \limsup(a_n + b_n) \le \limsup a_n + \limsup b_n$ |
| 疊不等式 | $\liminf a_n + \liminf b_n \le \liminf (a_n + b_n)$ 不總成立（見例題） |

**定理（上下極限的子列存在性）**：若 $\limsup a_n = L \in \mathbb{R}$，則存在子列 $a_{n_k} \to L$。

**證明思想**：對每個 $k$，取 $n_k > n_{k-1}$ 使 $a_{n_k} > L - \frac1k$ 且 $n_k > k$（由「$\sup_{j \ge n} a_j \to L$」的定義保證這樣的項存在）；同時 $a_{n_k} \le \sup_{j \ge n_k} a_j \le L + \frac1k$ 對足夠大的 $k$。由夾逼 $a_{n_k} \to L$。$\blacksquare$

### Bolzano–Weierstrass 定理

**定理（序列形式，Bolzano 1817 / Weierstrass 1860s）**：$\mathbb{R}$ 中有界序列必有收斂子列。

**證明一（上下極限法）**：$(a_n)$ 有界，故 $\liminf a_n = L \in \mathbb{R}$；由上述子列存在性定理，存在子列 $a_{n_k} \to L$。$\blacksquare$

**證明二（區間套法，最接近 Bolzano 原證）**：設 $|a_n| \le M$，將 $[-M, M]$ 對半分，至少一半含無窮多項，取其一為 $I_1$；對 $I_1$ 再對半分，取含無窮多項的一半為 $I_2$；……得區間套 $I_1 \supset I_2 \supset \cdots$，長度 $2M/2^n \to 0$。由**實數完備性**（1.1 節）區間套有唯一公共點 $a$。取 $n_k = \min\{n > n_{k-1} : a_n \in I_k\}$，則 $|a_{n_k} - a| \le 2M/2^k \to 0$。$\blacksquare$

**註**：證明二把「完備性」用在區間套的公共點存在性上——這正是 1.1 節完備性定理的直系應用。三個層次（切割→區間套→收斂子列）構成實數理論的骨幹。

**定理（聚點形式）**：$\mathbb{R}^n$ 中有界無窮集至少有一個聚點。序列形式與聚點形式互相蘊含（由序列取值集合與由聚點取序列）。

### 定理的三個直接推論

1. **有界收斂判準**：單調有界序列收斂（取子列收斂於 $L$，單調性推得整列趨於 $L$）。
2. **極值定理（Weierstrass）**：閉區間上連續函數有最大值與最小值（需 2.3 節緊性技術，但子列原理是核心）。
3. **中間值定理**（Bolzano 1817）：連續函數 $f$ 滿足 $f(a)f(b)<0$ 時有根。原證用二分法 + 完備性，與區間套法同源。

第四個推論留給 2.3 節：**Heine–Borel 定理**（閉區間上連續函數一致連續，Heine 1872；緊性語言的成形）。

### 歷史餘波：$\limsup$ 的誕生與「聚點」概念

「聚點」（Häufungspunkt）概念由 Weierstrass 在柏林講義中系統化，Cantor 在 1872 年論文中以之為起點逐階定義**導集**（derived set）$P, P', P'', \ldots$ 乃至超窮序數——**集合論誕生於本節定理的技術需求**。Cantor 自己承認：導集研究是「從 Bolzano–Weierstrass 定理出發的必然延伸」。另外，$\limsup/\liminf$ 記號在 19 世紀末（Peano、Stolz 時代）定型，20 世紀成為測度論（4.2 節集列的 $\limsup$、Borel–Cantelli 引理）與級數論（Cauchy–Hadamard 收斂半徑公式 $R = 1/\limsup |a_n|^{1/n}$）的標準語言。

### 一個具體例題

**例題 1.3.1**：求序列 $a_n = (-1)^n \dfrac{n}{n+1} + \dfrac{(-1)^{n+1}}{n}$ 的 $\limsup$、$\liminf$，並求出所有收斂子列極限。

**解**：分奇偶。$n = 2k$：$a_{2k} = \dfrac{2k}{2k+1} - \dfrac{1}{2k} \to 1 - 0 = 1$。$n = 2k+1$：$a_{2k+1} = -\dfrac{2k+1}{2k+2} + \dfrac{1}{2k+1} \to -1 + 0 = -1$。

序列不收斂（兩個子列極限不同）。取值大於 $\frac12$ 的項最終都在偶指標處，且 $a_{2k} = 1 - \frac{1}{2k(2k+1)} \uparrow 1$，故 $\sup_{n \ge N} a_n \to 1$，即 $\limsup a_n = 1$。同理 $\liminf a_n = -1$。

由子列刻畫：所有收斂子列極限介於 $-1$ 與 $1$ 之間；實際上任一子列的奇偶成分各自趨於 $\mp 1$，只有「最終全偶」或「最終全奇」的子列才收斂，極限分別為 $1$ 與 $-1$。（驗證：若子列含無窮多奇指標與無窮多偶指標，取這兩段再取子列得兩個不同極限，原子列不收斂。）

**例題 1.3.2**：序列 $a_n = \sin n$ 是否有收斂子列？極限集是什麼？

**解**：$|a_n| \le 1$ 有界，由 Bolzano–Weierstrass 存在收斂子列。深層事實（Kronecker 逼近定理，1884）：對任意 $\theta \in [-1, 1]$，存在 $n_k$ 使 $\sin n_k \to \theta$（因 $1/(2\pi)$ 無理，$\{n \bmod 2\pi\}$ 在圓上稠密）。故收斂子列極限集為整個 $[-1,1]$——**有界序列的「命運集合」可以是一整個區間**。$\blacksquare$

### 歷史啟示

- **無界的代價**：Bolzano–Weierstrass 只對有界序列成立；$\mathbb{R}$ 中無界序列如 $a_n = n$ 沒有收斂子列。「緊」＝「有界＋封閉」的等式（2.3 節）正是為了保住這條定理而命名。
- **沉睡的定理**：Bolzano 1817 → Weierstrass 1860s 的四十年斷層提醒我們：數學進步依賴**傳播機制**，不只依賴個人才華。
- **從定理到學科**：Cantor 從聚點概念走到集合論，說明基礎定理的深化可以催生全新學科——「解決技術問題」與「開拓理論疆域」常常是同一件事。

## 與其他章節及領域的關聯

- **1.1、1.2 節**：本節定理是完備性的序列化身，證明全程依賴最小上界原理。
- **2.1–2.3 節**：聚點、閉集、緊性的定義直接建構在本節之上；Heine–Borel 是其拓撲化。
- **3.1 節**：逐點收斂函數列的行為分析大量使用 $\limsup$（例如收斂域的端點判斷）。
- **4.2 節**：集列 $\limsup A_n$（無窮多次落入的點集）與 Borel–Cantelli 引理。
- **6.2 節**：Riesz–Fischer 定理的證明用快速收斂子列技術（本節定理的無窮維版）。
- **機率論**：大數法則、重對數律的敘述全部以 $\limsup/\liminf$ 為語言。

## 進階研讀：上下極限的五個深化場景

**場景一：級數論中的 $\limsup$**。根值判別法：$\rho = \limsup |a_n|^{1/n}$，$\rho < 1$ 收斂、$\rho > 1$ 發散。用 $\limsup$ 而非普通極限，是因為序列可能「混亂」而判準依然有效——例如 $a_n = 2^n$（$n$ 為質數）、$a_n = 1$（否則），此時 $\limsup |a_n|^{1/n} = 2 > 1$，級數發散，雖然普通 $\lim$ 不存在。

**場景二：測度論中的集列 $\limsup$**。$\limsup A_n = \bigcap_N \bigcup_{n \ge N} A_n$（屬於無窮多個 $A_n$ 的點集）。**Borel–Cantelli 引理**：若 $\sum P(A_n) < \infty$ 則 $P(\limsup A_n) = 0$。這是機率論「無窮多次事件」理論的基石（9.2 節）。

**場景三：動力系統**。迭代 $x_{n+1} = f(x_n)$ 的 $\omega$-極限集（所有收斂子列極限之集）可以是點、週期軌道、Cantor 集（如 logistic 映射的混沌參數）甚至奇怪吸子。Bolzano–Weierstrass 保證 $\omega$-極限集非空，是所有漸近行為分析的第一步。

**場景四：多維與一般拓撲空間**。$\mathbb{R}^n$ 中有界集有收斂子列（逐坐標取子列的對角法）。但無窮維空間失效：$C[0,1]$ 中序列 $f_n(x) = x^n$ 有界（$\|f_n\|_\infty = 1$）卻無一致收斂子列（極限不連續）——**緊性的喪失**是無窮維分析（6.2、6.3 節）的核心難題，催生弱收斂與 Arzelà–Ascoli 定理。

**場景五：相對緊性與 Arzelà–Ascoli**。「有界＋等度連續 $\Rightarrow$ 存在一致收斂子列」——Bolzano–Weierstrass 在函數空間的正確推廣。它是 Peano 存在定理（常微分方程解的存在）、Fourier 級數收斂性研究（10.2 節）的共同工具。

### 名詞速查表

- **上／下極限**：尾項上（下）確界的極限；收斂子列極限的最大（小）值。
- **收斂子列**：原序列的子序列且收斂；其極限稱為序列的**極限點**。
- **聚點（limit point）**：點的任意鄰域都含集合之無窮多點。
- **區間套法**：反覆對半取「含無窮多項」的半區間，以完備性收縮到極限點。
- **Bolzano–Weierstrass 定理**：有界序列必有收斂子列（$\mathbb{R}^n$ 中）。
- **等度連續**：一族函數共享同一個連續模；相對緊性的關鍵條件。
- **$\omega$-極限集**：迭代序列所有收斂子列極限之集。

### 年表速查

- 1817：Bolzano《純粹分析的證明》——連續性、中間值定理、收斂子列。
- 1860s：Weierstrass 柏林講義系統化聚點與子列理論（多維推廣）。
- 1872：Cantor 由導集出發創建集合論。
- 1883：Cantor 引入超窮序數（導集的無窮疊代）。
- 1884：Kronecker 逼近定理（$\sin n$ 子列極限集問題的深層答案）。
- 1890s：Peano、Stolz 等定型 $\limsup/\liminf$ 記號。
- 1899：Baire 綱理論（完備性＋子列原理的新舞台）。
- 20 世紀初：Arzelà、Ascoli 建立函數空間的相對緊性判準。

### 深化問答三則

**問：$\limsup$ 為何總存在，即使序列發散甚至無界？**
答：尾項上確界 $S_n = \sup_{k \ge n} a_k$ 隨 $n$ **單調不增**，單調序列的極限在擴充實數系 $[-\infty, +\infty]$ 中總存在（可能為 $-\infty$ 或 $+\infty$）。把極值「移到無窮遠」而不是「宣布不存在」，是分析學處理病態的標準策略。

**問：Bolzano–Weierstrass 與 Heine–Borel 哪個更基本？**
答：互相等價（都可由完備性推出，且互相推導）。序列版更適合計算與反例；覆蓋版（2.3 節）更適合抽象化到一般拓撲空間（那裡「序列緊」與「覆蓋緊」可以不等價）。現代數學以覆蓋版為「緊」的正式定義。

**問：$\sin n$ 的例子說明了什麼？**
答：有界只是「有收斂子列」的存在性保證，**不控制極限集的形狀**。極限集可以是不動點、兩點、區間、Cantor 集——刻畫它需要額外結構（等距、動力系統、數論性質）。Bolzano–Weierstrass 是起點而非終點。
