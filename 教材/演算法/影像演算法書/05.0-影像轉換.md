# 第5章 影像轉換

前四章的運算都直接作用在像素上，屬於「空間域」。但有些問題換一種表示法就會變得異常簡單：週期性的條紋在空間域是一堆難看的數字，在頻域卻只是兩根尖峰；JPEG 壓縮能把影像縮小十倍，靠的正是把能量集中到少數係數的轉換。本章介紹影像處理的三大轉換：**傅立葉轉換**把影像分解成頻率的組合，讓濾波變成乘法、卷積定理連接了空間與頻域兩個世界；**離散餘弦轉換 (DCT)** 是傅立葉的實用變形，能量集中性極佳且只需實數運算，是 JPEG 與現代視訊編碼的心臟；**小波轉換**則突破了傅立葉「只知道有哪些頻率、不知道它們發生在哪裡」的根本限制，用可伸縮的視窗同時取得時間與頻率資訊，成為 JPEG 2000 與去雜訊的基礎。

學習本章需要一點線性代數與複數的耐心，但回報巨大：你會真正理解「模糊 = 低通濾波」「雜訊 = 高頻」「壓縮 = 丟棄人眼不敏感的係數」這些口號背後的數學。三節都附上可執行的 numpy 程式碼，請親手把影像送進頻域、再送回來，觀察每一次操作的頻譜變化——頻域的直覺一旦建立，第 6 章的壓縮原理就會豁然開朗。
