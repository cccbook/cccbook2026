# 第4章 測量與不可克隆

## 章前言

前兩章我們刻意避開了一個問題：算完之後，「答案」怎麼讀出來？本章正面處理量子計算中最微妙也最根本的議題——測量。

4.1 節把 Born 規則寫成完整的數學形式，說明投影測量、機率分佈與期望值的計算，以及「部分測量」（只量系統的一部分位元）如何改變其餘位元的狀態；4.2 節證明量子力學最著名的定理之一——不可克隆定理：不存在任何物理程序能複製未知的量子態，這是量子密碼學（如 BB84）安全的基石，也解釋了為什麼量子計算無法用「多跑幾份再比對」的方式除錯；4.3 節介紹量子隱形傳態（teleportation）：利用一對糾纏位元與兩位元的古典通訊，把一個未知量子態「傳送」到遠方——注意它傳的是態而不是物質，且不違反不可克隆定理，因為原態會被測量摧毀。

**學習目標**

1. 會計算任意態的測量機率、期望值與部分測量的條件狀態。
2. 完整寫出不可克隆定理的證明，並說明它對量子密碼與除錯的含義。
3. 用第 3 章的模擬器實作隱形傳態電路並驗證其正確性。
