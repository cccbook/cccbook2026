# 1.2 量子位元與疊加

## 什麼是量子位元？

古典位元只能處於 $0$ 或 $1$ 兩種狀態之一。**量子位元（qubit）** 則可以處於兩者的**線性組合（疊加）**：

$$|\psi\rangle = \alpha |0\rangle + \beta |1\rangle$$

其中 $\alpha, \beta$ 是複數，我們用狄拉克記號 $|\cdot\rangle$（ket）表示狀態向量。這個式子的物理意義是：當我們測量這個量子位元時，以機率 $|\alpha|^2$ 得到 $0$、以機率 $|\beta|^2$ 得到 $1$。由於機率總和必須為 1，狀態必須**歸一化**：

$$|\alpha|^2 + |\beta|^2 = 1$$

在數學上，一個量子位元的狀態就是二維複數向量空間 $\mathbb{C}^2$ 中的單位向量，寫作：

$$|0\rangle = \begin{pmatrix}1\\0\end{pmatrix}, \qquad |1\rangle = \begin{pmatrix}0\\1\end{pmatrix}$$

因此 $|\psi\rangle$ 對應向量 $(\alpha, \beta)^T$。這是第二、三章數學工具的起點。

## 全域相位：物理上無法區分的狀態

一個微妙但重要的事實：$\alpha|0\rangle + \beta|1\rangle$ 與 $e^{i\theta}(\alpha|0\rangle+\beta|1\rangle)$ 測量機率完全相同。這個係數 $e^{i\theta}$ 稱為**全域相位**，對單一系統的測量不可觀察。但請注意：**相對相位**是可觀察的。$|0\rangle+|1\rangle$ 與 $|0\rangle-|1\rangle$ 機率分佈相同，但通過 Hadamard 閘後，前者變成 $|0\rangle$、後者變成 $|1\rangle$——相對相位會在干涉中顯現。Grover 與 Shor 演算法的核心技巧都在於精心安排相對相位。

## 布洛赫球：量子位元的幾何圖像

任何單量子位元純態都可以寫成：

$$|\psi\rangle = \cos\frac{\theta}{2}|0\rangle + e^{i\varphi}\sin\frac{\theta}{2}|1\rangle$$

參數 $\theta, \varphi$ 把狀態映射到三維球面上的點，這個球稱為**布洛赫球（Bloch ball）**。$|0\rangle$ 是北極、$|1\rangle$ 是南極，赤道上是 $(|0\rangle \pm |1\rangle)/\sqrt{2}$ 與 $(|0\rangle \pm i|1\rangle)/\sqrt{2}$ 這四個「等重量疊加」。量子閘的作用在幾何上就是繞球面某個軸旋轉——這個圖像讓第 3 章的旋轉閘變得直觀。

## 測量抽走了一部分資訊

從 $n$ 個實數才能參數化的布洛赫球，測量後只剩一個位元。這是量子資訊與古典資訊最根本的落差：**不可讀出、不可克隆（第 4 章）**，但也因此提供了只有在提取某些特定資訊（如全域函數性質）時才能利用的資源。

## 程式範例：用 numpy 表示疊加態

```python
import numpy as np

ket0 = np.array([1, 0], dtype=complex)
ket1 = np.array([0, 1], dtype=complex)

def state(alpha, beta):
    s = alpha*ket0 + beta*ket1
    assert abs(np.vdot(s, s) - 1) < 1e-12, "狀態未歸一化"
    return s

# 等重量疊加：( |0> + |1> ) / sqrt(2)
plus = state(1/np.sqrt(2), 1/np.sqrt(2))
minus = state(1/np.sqrt(2), -1/np.sqrt(2))

def measure_probs(psi):
    return np.abs(psi)**2

print(measure_probs(plus))   # [0.5 0.5] => 測量各半
print(measure_probs(state(3/5, 4j/5)))   # [0.36 0.64]

# 驗證相對相位的效果（喂給 Hadamard 閘）
H = np.array([[1, 1], [1, -1]], dtype=complex) / np.sqrt(2)
print(H @ plus)    # [1 0] => 恆為 0（振幅同相加強）
print(H @ minus)   # [0 1] => 恆為 1（振幅反相抵消）
```

練習後你可看到：`plus` 與 `minus` 測量機率相同，但對機率分佈「逆運算」後行為截然不同。這個程式就是最簡單的「量子模擬器」——第 3 章將把它推廣成多量子位元版本。

## 命題—證明範例

**命題**：任何二維單位複向量都可寫成 $\cos\frac{\theta}{2}|0\rangle + e^{i\varphi}\sin\frac{\theta}{2}|1\rangle$ 的形式。

**證明**：設 $|\psi\rangle = \alpha|0\rangle+\beta|1\rangle$，$|\alpha|^2+|\beta|^2=1$。因 $\alpha$ 是複數，可取全域相位使 $\alpha \ge 0$（全域相位如上所述不影響物理），令 $\alpha=\cos\frac{\theta}{2}$，$\theta \in [0,\pi]$ 由 $\cos^2$ 值唯一決定（因 $\alpha\ge0$ 且 $|\alpha| \le 1$）。此時 $|\beta|=\sin\frac{\theta}{2}$，故 $\beta = e^{i\varphi}\sin\frac{\theta}{2}$，其中 $\varphi = \arg\beta$。$\blacksquare$

## 複雜度觀點

一個量子位元的純態以兩個實數參數化，$n$ 個相互糾纏的量子位元需要**指數多**的參數（第 2 章證明）。這是「量子模擬很難、量子計算可能很快」的同一枚硬幣兩面。
