# 9.1 去相干與雜訊

## 概念說明

**為什麼量子態會壞掉？** 量子位元不是孤立的：它與環境（熱振動、雜散電磁場、控制線路的電子雜訊）耦合。環境「偷看」了量子位元，疊加中的相位資訊就洩漏出去——這是**去相干**（decoherence）。兩個典型時間尺度：

- $T_1$ （能量弛豫）： $|1\rangle$ 衰變回 $|0\rangle$ ；
- $T_2$ （相位相干時間）：疊加態的相對相位隨機化。實務上 $T_2 \le 2T_1$ ；超導量子位元 $T_1 \sim 100\,\mu s$ ，離子阱可達分鐘級。

**數學描述：密度矩陣與克勞斯算子**。純態推廣為密度矩陣 $\rho = |\psi\rangle\langle\psi|$ ，雜訊通道 $\mathcal E$ 寫成

$$\mathcal E(\rho) = \sum_k E_k \rho E_k^\dagger, \qquad \sum_k E_k^\dagger E_k = I$$

常見通道：

| 通道 | 克勞斯算子 | 物理意義 |
|---|---|---|
| 位元翻轉（機率 $p$ ） | $\sqrt{1-p}\,I,\ \sqrt p\,X$ | 偶然翻位元 |
| 相位翻轉 | $\sqrt{1-p}\,I,\ \sqrt p\,Z$ | 相位隨機 |
| 退極化 | $\sqrt{1-p}\,I,\ \sqrt{p/3}(X,Y,Z)$ | 完全隨機化 |
| 振幅阻尼 | $E_0=\mathrm{diag}(1,\sqrt{1-\gamma}),\ E_1=\begin{pmatrix}0&\sqrt\gamma\\0&0\end{pmatrix}$ | $T_1$ 衰變 |

**特徵指標**：保真度 $F(\rho, \sigma) = (\mathrm{tr}\sqrt{\sqrt\rho\sigma\sqrt\rho})^2$ 衡量「兩態有多像」；純態時 $F = \langle\psi|\sigma|\psi\rangle$ 。

## Python 範例

```python
import numpy as np

I2 = np.eye(2, dtype=complex)
X = np.array([[0,1],[1,0]], dtype=complex)
Z = np.array([[1,0],[0,-1]], dtype=complex)
Y = np.array([[0,-1j],[1j,0]], dtype=complex)

def channel(rho, ops, probs):
    """克勞斯通道"""
    out = np.zeros_like(rho)
    for E, p in zip(ops, probs):
        E = np.sqrt(p)*E
        out += E @ rho @ E.conj().T
    return out

def fidelity(psi, rho):
    return (psi.conj() @ rho @ psi).real

plus = np.array([1,1], dtype=complex)/np.sqrt(2)
rho_plus = np.outer(plus, plus.conj())

# 相位翻轉雜訊對 |+> 的破壞
for p in [0.05, 0.2, 0.5, 1.0]:
    rho_n = channel(rho_plus, [I2, Z], [1-p, p])
    print(f"相位翻轉 p={p:<4}: F(|+>, rho) = {fidelity(plus, rho_n):.3f}")
# p=0.5 時 |+> 完全失去相干性，F = 0.5

# 振幅阻尼：T1 衰變隨時間演化
def amplitude_damping(rho, gamma):
    E0 = np.diag([1, np.sqrt(1-gamma)]).astype(complex)
    E1 = np.array([[0, np.sqrt(gamma)],[0,0]], dtype=complex)
    return E0 @ rho @ E0.conj().T + E1 @ rho @ E1.conj().T

rho1 = np.array([[0,0],[0,1]], dtype=complex)   # |1><1|
for t in [0, 0.25, 1, 4]:
    rho_t = amplitude_damping(rho1, gamma=1-np.exp(-t))
    print(f"t={t} T1: P(仍為|1>) = {rho_t[1,1].real:.3f}")   # 指數衰變 e^{-t/T1}
```

## 複雜度分析

密度矩陣模擬是 $d\times d$ 矩陣（ $d = 2^n$ ）：單通道作用成本 $O(d^2)$ 、記憶體 $O(d^2)$ ——比純態模擬貴一個 $2^n$ 因子， $n>12$ 就吃緊。這是雜訊模擬必須付出的代價；大規模雜訊模擬需用張量網路或蒙地卡羅軌跡法（quantum trajectories）。
