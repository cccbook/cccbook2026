# 第2章 數學基礎

## 章前言

量子力學的語言是線性代數：狀態是複數向量、閘是么正矩陣、多量子位元系統用張量積組合。本章用最精簡的方式把需要的線性代數一次補齊，並且每一節都配有可執行的 Python（numpy）程式，讓抽象公式變成看得見、算得出的物件。

2.1 節回顧複數、向量、內積與範數——這些是描述「狀態」與「機率」的工具；2.2 節介紹么正矩陣，說明為什麼量子演化必須是么正的，並認識幾個重要的矩陣（Pauli 矩陣、Hadamard、相位閘）；2.3 節則處理多量子位元的關鍵——張量積，以及糾纏態為何無法寫成兩個向量的乘積。

讀者若已學過線性代數，可快速瀏覽本節並著重於「量子化」的記號習慣：狄拉克符號 $|0\rangle$、$|\psi\rangle$ 與矩陣的對應關係。所有範例都只依賴 numpy，可直接在本機執行驗證。

**學習目標**

1. 熟練複數向量運算、內積、正規化與正交性。
2. 說明么正性的物理意義，並驗證常見量子閘矩陣的么正性。
3. 會計算張量積，理解多量子位元狀態向量的維度成長與糾纏態的不可分離性。
