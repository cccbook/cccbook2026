# 10.3 總結與進階閱讀

## 概念說明

回顧全書的知識地圖：第 1~2 章建立了「多項式時間 = 有效率」的度量標準與 P 類問題；第 3 章引入 NP——「多項式時間可驗證」的問題類別，以及 P = NP 這個世紀難題；第 4 章用多項式化約把問題等價連結，定義出 NP-hard 與 NP-complete，並以 Cook-Levin 定理確立 3-SAT 的原型地位；第 5~6 章走訪經典問題並動手實作化約；第 7~9 章給出三條應對路線——精確加速（分支限界、DP、SAT 求解器）、近似與啟發式（近似比、貪婪、模擬退火）、隨機與參數化（BPP、FPT、量子）；第 10 章把它們串成實戰流程。

本書希望你帶走的三個核心素養：

1. **辨識力**：看到新問題先問「它像 3-SAT、SUBSET-SUM、還是 TSP？」，並有能力用限制化約或構造化約完成證明。
2. **務實觀**：NP-complete 不等於「放棄」。偽多項式 DP、FPT、近似、啟發式的工具箱，足以應付絕大多數現實實例。
3. **謙遜與好奇**：P ≠ NP 仍是未解之謎，多項式階層、去隨機化、量子複雜度的邊界都還在前沿推進——這是仍允許新入者做出歷史性貢獻的領域。

## 進階閱讀路線

- **教科書**：
  - Sipser, *Introduction to the Theory of Computation*——自動機與複雜度理論的標準入門。
  - Arora & Barak, *Computational Complexity: A Modern Approach*——NP、PCP、去隨機化的現代觀點。
  - Williamson & Shmoys, *The Design of Approximation Algorithms*——近似演算法的完整訓練。
  - Cygan et al., *Parameterized Algorithms*——FPT、核心化、樹寬 DP 的權威教材。
- **論文起點**：Cook (1971)、Karp (1972)、Levin (1973)、Grover (1996)、Shor (1994)。
- **線上資源**：Complexity Zoo（複雜度類別百科）、SAT 競賽（SAT Competition）網站、Milp/SAT 求解器文件（OR-Tools、Z3）。
- **實作練習場**：用 OR-Tools CP-SAT 重解本書各章問題；參加 ICPC 或 Google Hash Code 類型的排程路線題。

## 演算法步驟（本書知識的使用決策樹）

1. 新問題 ⟹ 判斷複雜度（10.1 流程）。
2. 在 P 中 ⟹ 直接設計多項式演算法。
3. NP-hard ⟹ 檢查是否偽多項式可解（數值小：DP）或參數可解（k 小：FPT）。
4. 都不行 ⟹ 需要保證？用近似演算法（含三角不等式則 TSP 有 1.5）；不需要保證？用啟發式（貪婪 + 局部搜尋 + 模擬退火）。
5. 是邏輯/約束本質？⟹ 建模成 SAT/ILP 交給求解器。
6. 規模極大、即時性要求高 ⟹ 貪婪 + 線上對偶價格。

## Python 程式碼範例

（全書收尾：用 OR-Tools 風格的簡易 CP 求解思路，一個介面解多個 NP 問題）

```python
def solve_via_backtracking(problem, verify, next_moves,
                           depth=0, path=()):
    """通用回溯框架：本書多數精確法的共同骨架"""
    if verify(problem, path):
        return path
    if depth >= len(problem):
        return None
    for move in next_moves(problem, depth, path):
        result = solve_via_backtracking(
            problem, verify, next_moves, depth + 1,
            path + (move,))
        if result is not None:
            return result
    return None

# SAT：problem = 子句列表
clauses = [[1, -2], [-1, 3], [2, 3]]

def next_assign(clauses, i, path):
    return [True, False]

def sat_verify(clauses, path):
    if len(path) < 3:
        return False
    assign = {i + 1: path[i] for i in range(3)}
    return all(any(assign[abs(l)] == (l > 0)
                   for l in c) for c in clauses)

print(solve_via_backtracking(
    clauses, sat_verify, next_assign))   # (True, True, True)
```

## 複雜度分析

- 通用回溯框架：最壞 O(b^d)（b 為分支因子、d 為深度）——正是第 4~7 章反覆出現的指數搜尋；框架的價值在於 `next_moves` 換成帶剪枝/限界/學習的版本，就分別蛻變為分支限界、DPLL 與 CDCL。
- 求解器時代意義：CP-SAT、Z3 等工具把「建模 + 求解」抽象化，工程師今天面對 NP-hard 問題的第一步常是「先建模再說」，演算法知識用於判斷模型能否擴展。
- 學習曲線：本書內容對應大學演算法課的 NP 理論單元，進階可銜接研究所的複雜度理論、近似演算法、參數化演算法三條主線。
