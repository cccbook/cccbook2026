# 密碼學

本書是一本面向程式設計初學者與資訊科系學生的密碼學入門教科書，以繁體中文撰寫，內容涵蓋古典密碼、對稱式加密、雜湊函數、訊息驗證、公開金鑰密碼、數學基礎、實務應用，一直到最新的後量子密碼學。

每一節都包含概念說明、演算法步驟、可執行的 Python 程式碼範例、安全性分析與練習題。書中的程式碼以「教學示範」為目的，讓讀者透過實作理解原理；除非特別註明，這些程式碼**不應**直接用於實際產品或生產環境。實務上請使用經過審查的標準函式庫（如 Python 的 `hashlib`、`hmac`、`secrets`，或 `cryptography`、`PyCryptodome` 等套件），並遵循第 9 章所述的密碼學工程最佳實務。

閱讀本書只需要基本的 Python 程式設計能力與高中程度的數學；較深的數學主題（模運算、群論、離散對數、橢圓曲線）都在第 8 章集中說明，讀者可先跳過、需要時再回來查閱。

祝學習愉快，也祝你在破解凱薩密碼時玩得開心。
