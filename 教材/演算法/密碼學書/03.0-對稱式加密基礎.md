# 第3章 對稱式加密基礎

古典密碼全數潰敗之後，密碼學需要回答兩個根本問題：**「絕對安全」存在嗎？** 以及 **「把一塊固定大小的資料加密」該長什麼樣？** 本章給出這兩問的答案。

我們先證明香農 1949 年的經典結果：**一次性密碼本（OTP）是唯一擁有「完美保密」的加密法**——密文對任何知道金鑰以外的人來說不攜帶任何資訊。理解 OTP 的嚴苛條件（真隨機、與明文等長、只用一次），你就能明白為什麼實務必須妥協，也才能欣賞後續所有設計的取捨。

接著進入現代對稱加密的核心建築：**區塊加密（block cipher）**與 **Feistel 結構**——一個絕妙的想法：用「可逆的半區交換」把任何不可逆的函數變成可逆的加密。最後回顧 **DES**——第一個公開的國家級加密標準，它開創了「演算法公開受檢驗」的傳統，也用 56 位元金鑰示範了「標準也會過時」。

學完本章你將能：說明完美保密的定義與 OTP 的成立條件、用 Python 實作 Feistel 網路、並從歷史與技術兩面評價 DES。
