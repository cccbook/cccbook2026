# 第6章 訊息驗證與完整性

到目前為止，我們解決了「偷看」與「偵測單純的意外損壞」。但真實世界的攻擊者是主動的：他會**竄改密文、重播舊訊息、冒充身分**。本章建構「驗證」的三層體系。

首先是 **MAC 與 HMAC**：共享金鑰的訊息驗證碼，能確認「訊息出自持有金鑰的人、且未被竄改」；接著是**數位簽章**：用私鑰簽、公鑰驗，把「不可否認性」變成可能——收發雙方共用金鑰的 MAC 永遠做不到這點；最後是**憑證與 PKI**：公鑰本身是誰的？由憑證授權機構（CA）用簽章為「公鑰 ⇄ 身分」的綁定背書——這就是你瀏覽器網址列那把鎖的來源。

學完本章你將能：正確使用 `hmac` 模組與 `compare_digest`、解釋 MAC 與簽章的差別、並看懂一張 X.509 憑證的欄位與驗證鏈。
