# 第8章 密碼學的數學基礎

公開金鑰密碼的全部戲碼都發生在「數」的世界裡：模運算、群、離散對數、質因數分解。本章把第 7 章用到但按下不表的數學補齊，集中在一章講清楚。

8.1 節從**模運算**出發，介紹最大公因數、擴展歐幾里得、費馬小定理與歐拉定理，再升級到**群、環、體**的抽象定義——你會發現 RSA 的加解密正確性不過是歐拉定理的直接推論。8.2 節討論**離散對數問題**：DH 與 ECC 的根基，以及已知的攻擊演算法與它們的時間界。8.3 節是**大數分解**：質因數分解的難題地位、Miller–Rabin 素性測試與 Pollard rho，並理解為什麼「分解」與「離散對數」是現代密碼學的兩根柱子、也是量子時代最先被鋸斷的兩根。

本章不需要超出高中數學的背景；看不懂的符號就當成「某種關於餘數的規則」，先讀 Python 範例建立直覺，再回來精讀定義。
