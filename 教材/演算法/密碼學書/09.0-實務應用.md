# 第9章 實務應用

前八章像是在實驗室裡認識一個個零件：加密、雜湊、簽章、金鑰交換。本章把它們組裝成你在真實世界每天使用的機器。

9.1 節拆解 **TLS/HTTPS**——現代網際網路的信任底座，你會看到前面所有主題（ECDHE、AEAD、簽章、憑證）如何在一次 TLS 交握中協同運作。9.2 節進入**區塊鏈**：一個用雜湊、簽章與對稱加密重新發明「不依賴 CA 的信任」的系統，也是理解 Merkle 樹與橢圓曲線簽章的絕佳案例。9.3 節則是本章最有價值的部分——**密碼學工程陷阱與最佳實務**：統計真實世界裡系統被攻破的原因，你會發現幾乎從來不是「演算法被破解」，而是「用法錯了」。
