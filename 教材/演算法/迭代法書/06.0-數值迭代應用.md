# 第6章 數值迭代應用

## 章前言

前面各章建立了迭代的理論與方法，本章展示它們如何化為具體的數值成果：算出圓周率的更多位數、計算超越函數的值、求矩陣的特徵值、以及用隨機性本身作為迭代引擎。

**6.1 節**以圓周率為主角：從阿基米德夾逼、萊布尼茲級數、Machin 公式到 AGM 迭代，一條迭代次數從「百萬」縮到「二十」的演化史，順帶學會用級數與迭代計算 $\sin$、$e^x$ 等超越函數。**6.2 節**介紹冪法：只靠反覆矩陣-向量乘，就能擠出矩陣最大的特徵值與特徵向量——Google 早期 PageRank 的核心運算正是超大矩陣上的冪法。**6.3 節**蒙地卡羅法把「重複取樣、統計平均」當作迭代：以 $O(1/\sqrt{N})$ 的緩慢但維度無關的收斂率，解決積分、機率與取樣問題。

本章的方法看似鬆散，骨幹仍是同一条：**構造一個收斂到答案的迭代過程，並量化它的收斂速度與誤差**。學會把新問題「翻譯」成迭代形式，是本書最想傳授的能力。
