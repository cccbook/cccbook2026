# 第2章 時域分析

拿到一段數位音訊後，最直觀的分析方式就是直接看它的波形：訊號隨時間起伏的樣子。時域分析計算便宜、語意直觀，是所有進階處理的第一關，也是即時系統（例如通話軟體、助聽器）最常採用的低延遲手段。

本章介紹三個最經典的時域指標。第一是能量與均方根（RMS），它對應人耳感知的音量，是音訊分段、自動增益控制（AGC）與音量正規化的基礎。第二是過零率（zero crossing rate），它統計訊號穿越零點的次數，能粗略區分有聲音（濁音）與無聲音（氣音、摩擦音），在端點偵測與樂器分類中扮演偵測器的角色。第三是自相關（autocorrelation），它衡量訊號與自己平移後的相似度，能找出語音的基頻週期，是調音器與音高偵測演算法的祖先。

三個方法都只需要加減乘除與迴圈，卻能回答「哪裡有人說話」「聲音有多大」「音調是多少」這些有用的問題。我們會用 numpy 實作每個演算法，並以文字視覺化呈現結果，讓你親眼看見數字背後的波形行為。
