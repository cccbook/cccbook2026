# 第 5 章 線性代數演算法

線性代數是科學計算的脊椎：天氣預報、影像壓縮、Google 的 PageRank、深度神經網路，核心都是矩陣運算。本章的主軸是一個觀念——**把矩陣問題化約成一連串可預測成本的代數操作**，而化約的主角就是矩陣分解。

5.1 節介紹高斯消去與 LU 分解：解 Ax = b 的標準流程，包含部分軸選（partial pivoting）如何保證數值穩定，以及「先分解、後代換」如何讓多組右邊向量共用一次 O(n³) 的分解成本。5.2 節在此基礎上處理行列式與反矩陣：你會看到行列式其實是 LU 分解的「免費贈品」，而反矩陣雖然在數學上地位崇高，實務上卻常應該被避免。5.3 節走向特徵值問題，介紹冪法（power iteration）——一個只用矩陣—向量乘法就能找出最大特徵值的優雅迭代，它是 PageRank 與譜聚類背後的共同祖先。

學完本章，你將能回答三個實務問題：解線性系統的成本是多少？什麼時候矩陣是「病態」的、答案不可信？以及如何在 n 大到無法做 O(n³) 分解時，仍舊取得有用的譜資訊。
