# 第 4 章 求根與方程式

「解方程式」是數學最古老的任務之一：從巴比倫人的二次方程，到五次方程無公式解的證明，人類花了數千年追求「精確解」。但實務上，絕大多數方程式（例如 `cos(x) = x` 或 `e^(-x) = x`）根本沒有封閉形式的解。電腦時代的答案是：**不求精確解，改求足夠接近的數值解**。這就是「求根演算法」的核心思想——給定函數 f(x)，找出使 f(x) = 0 的 x 值。

本章介紹三種層次遞進的方法。4.1 節的二分法與假位法只需要「函數連續」與「知道一個變號區間」兩個假設，是最穩健的入門方法，收斂速度為線性。4.2 節的牛頓法利用切線斜率資訊，達到驚人的二次收斂——正確位數每次迭代翻倍——但代價是需要導數，且可能發散。4.3 節則專注於多項式：多項式有獨特的代數結構（係數、合成除法、斯圖姆定理），讓求根可以做得更系統化，例如以牛頓法搭配多項式求值或用商差法同時逼近所有根。

求根演算法是後續章節的基礎：最優化（第 10 章）本質上就是對導函數求根，冪法求特徵值（第 5 章）也依賴特徵多項式的概念。學完本章，你將能針對「函數性質多好、導數可得嗎、要幾個根」這三個問題，選出最合適的求根策略。
