# 2.3 匯出與分享：/export 與 /share

## 從一個問題開始

除錯完一個棘手問題，你想把整個會話存檔歸檔，或貼給同事看。Pi 提供兩條路：**匯出成檔案**，或**上傳取得連結**。

## /export：匯出成 HTML 或 JSONL

```text
/export [path]    # 互動模式內：匯出當前會話
```

- **HTML**：可讀的網頁版，含訊息、工具呼叫與結果、樹狀結構
- **JSONL**：原始條目格式，可供程式處理或 `/import` 回來

CLI 也有對應選項：

```bash
pi --export <input> [output]    # 把會話檔匯出成 HTML，省略 output 自動推導
```

## /share：上傳取得檢視連結

```text
/share    # 上傳會話，取得可分享的檢視 URL
```

上傳方式的優先順序：

1. 有 **Radius** 認證 → artifact 對你的 Radius 組織可見
2. 否則 → 透過 GitHub CLI 建立**私有 GitHub gist**，取得可渲染的分享 URL

> 分享出來的頁面像這樣：[Example session](https://pi.dev/session/#0ea51497613daf7e1de28ee99950b074)。

## ⚠️ 分享前必看

匯出或分享的會話可能包含：

- 你的提示與模型回應
- 工具參數、指令輸出
- **檔案內容**
- **對話過程中暴露的憑證（credentials）**

分享前先審視內容，或用編輯器先跑掉敏感部分。

## 複製結果

| 動作 | 快捷鍵 / 指令 |
|---|---|
| 複製最後一條 assistant 回應 | `Ctrl+X` 或 `/copy` |

## 匯出 OSS 開發會話：貢獻社群

如果你用 Pi 做 open source 工作，官方鼓勵你分享會話資料——公開的 OSS 會話資料能幫助改進模型、提示、工具與評測。

```bash
# 用 Hugging Face 帳號與 CLI 發布會話
# 見 github.com/badlogic/pi-share-hf
```

已發布的 Pi 開發會話範例：[badlogicgames/pi-mono on Hugging Face](https://huggingface.co/datasets/badlogicgames/pi-mono)。

## 回報 Bug

```text
/bug [描述]    # 為 Pi 開發者準備私有回報
```

- 可包含會話記錄、省略它，或讓模型幫你摘要問題
- 回報含環境與提供商設定（不含憑證值）與錯誤診斷
- 透過 `radius.pi.dev` 上傳（不需登入），或匯出成 zip 自行檢視

## 除錯資訊

終端機渲染或會話狀態出問題時：

```text
/debug    # 寫出渲染的終端機行與當前會話訊息到 pi-debug.log
```

檔案位置在 agent directory（`~/.pi/agent/`）。**分享前一樣要先審視**——它可能含提示、模型回應、檔案內容。
