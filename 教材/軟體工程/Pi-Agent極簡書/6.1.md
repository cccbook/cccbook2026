# 6.1 常用內建命令

## 互動模式 Slash 指令

在編輯器輸入 `/` 搜尋可用指令。**命令選單才是你這個會話的精確參考**——extensions、prompt templates、skills 都會加指令進來。

### 模型與設定

| 指令 | 說明 |
|---|---|
| `/model [provider/model]` | 選擇模型（`Ctrl+L` 同） |
| `/thinking [level]` | 設定思考等級（`Shift+Tab` 循環） |
| `/scoped-models` | 設定互動循環使用的模型清單 |
| `/login [provider]` | 新增提供商認證 |
| `/logout` | 移除提供商認證 |
| `/llama` | 管理 llama.cpp 路由器上的模型 |
| `/settings` | 開啟設定 |

### 會話與 context

| 指令 | 說明 |
|---|---|
| `/new` | 開新會話 |
| `/resume` | 切換到另一個已存會話 |
| `/name [name]` | 設定會話名稱 |
| `/session` | 顯示會話資訊與統計 |
| `/tree` | 導航會話樹 |
| `/fork` | 從較早的使用者訊息另開新會話 |
| `/clone` | 在目前位置複製會話 |
| `/compact [instructions]` | 手動壓縮 context（可帶指示） |
| `/import <path>` | 匯入並接續 JSONL 會話 |

### 匯出與分享

| 指令 | 說明 |
|---|---|
| `/copy` | 複製最後一條 assistant 訊息（`Ctrl+X` 同） |
| `/export [path]` | 匯出會話成 HTML 或 JSONL |
| `/share` | 上傳會話，取得檢視連結 |
| `/bug [description]` | 準備私有 bug 回報 |

### 執行環境與專案

| 指令 | 說明 |
|---|---|
| `/trust` | 儲存專案信任決定 |
| `/reload` | 重新載入 keybindings、extensions、skills、templates、themes、context files |
| `/hotkeys` | 顯示目前生效的快捷鍵 |
| `/mcp` | 檢視 MCP 伺服器連線狀態 |
| `/skill:name [args]` | 強制載入某個 skill |
| `/changelog` | 顯示版本變更 |
| `/quit` | 離開 Pi |

## CLI 指令

```sh
pi [options] [--] [@files...] [messages...]
pi install <source>        # 安裝套件
pi remove <source>         # 移除套件（uninstall 別名）
pi list                    # 列出已設定套件
pi config                  # 設定要載入的資源
pi update [target]         # 更新 Pi / 套件 / 模型目錄
pi auth <check|print-api-key|print-bearer-token>
pi mcp <list|login|logout>
```

### 最常用的 CLI 選項

| 選項 | 說明 |
|---|---|
| `-p`, `--print "..."` | 執行一次、輸出回應、結束 |
| `--mode json` | 輸出 JSONL 事件流 |
| `--mode rpc` | RPC 模式（stdin/stdout JSONL） |
| `-c`, `--continue` | 接續此專案最近會話 |
| `-r`, `--resume` | 開啟會話選擇器 |
| `--model <pattern>` | 選模型（支援 `provider/id` 與 `:thinking` 尾綴） |
| `--thinking <level>` | 設定思考等級 |
| `-t`, `--tools <list>` | 以允許清單取代預設工具 |
| `-xt`, `--exclude-tools <list>` | 停用指定工具 |
| `-nt`, `--no-tools` | 所有工具停用 |
| `-e`, `--extension <path>` | 載入擴充（可重複） |
| `--skill <path>` | 載入 skill（可重複） |
| `--session-dir <dir>` | 指定會話儲存位置 |
| `--no-session` | 不持久化會話 |
| `--system-prompt <text|path>` | 取代系統提示詞 |
| `--append-system-prompt <...>` | 附加系統提示詞（可重複） |
| `-a` / `-na` | 信任 / 忽略專案設定 |
| `--export <input> [output]` | 匯出會話成 HTML |

## 內建工具清單

| 工具 | 用途 |
|---|---|
| `read` | 讀取文字檔與圖片 |
| `bash` | 跑 shell 指令 |
| `powershell` | Windows PowerShell 指令 |
| `edit` | 對既有檔案做精確文字替換 |
| `write` | 建立或覆寫檔案 |
| `grep` | 搜尋檔案內容 |
| `find` | 用 glob 找路徑 |
| `ls` | 列目錄 |

預設啟用：`read`、`bash`、`edit`、`write`。另有兩個內建 extension 工具預設關閉：`codemode`（JS 沙箱組合工具）與 `tool_search`（搜尋未宣告工具）——用 `"defaultTools": ["+codemode"]` 或 `--tools` 啟用。

## 日常 12 條（背這個就夠）

```text
pi                          # 啟動
/model                      # 換模型（Ctrl+L）
Ctrl+P                      # 快速循環換模型
Enter（工作中）              # Steer：中途修正
Alt+Enter（工作中）          # Follow-up：排隊追加
!git status                 # 直接跑終端指令
/tree                       # 樹狀導航、分岔試錯
/compact                    # 壓縮 context
/new  /  /resume            # 新會話 / 接續
/export                     # 匯出 HTML/JSONL
/reload                     # 改了設定或擴充後重新載入
pi --continue               # 離開後接續最近會話
```
