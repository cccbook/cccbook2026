# 5.1 從專家系統的脆弱到貝葉斯網路：Pearl 的革命（1985）

## 歷史背景

專家系統（2.2 節）在真實世界的不確定性面前節節敗退：MYCIN 的確定因子在規則鏈中重複計分，XCON 的規則庫無法表達「症狀通常但未必表示疾病」。1980 年代的 AI 社群普遍認為機率論「太貴」：完整聯合機率分布 $P(X_1, \ldots, X_n)$ 需要 $2^n - 1$ 個參數，一個 100 個二元變數的系統就要 $10^{30}$ 個數字——知識工程師連寫都寫不完，遑論保持一致。

1985 年，UCLA 的 Judea Pearl 發表《Bayesian Networks: A Model of Self-Activated Memory for Evidential Reasoning》，1988 年出版專著《Probabilistic Reasoning in Intelligent Systems》，提出**貝葉斯網路**（Bayesian Network）。革命性主張是：$2^n$ 的爆炸可以用**條件獨立性**的圖結構瓦解——真實世界的變數大多只與少數鄰居直接相關，網路只需每個節點存一個**條件機率表**（CPT），參數量從指數降回多項式。

這場革命的意義超出工程：Pearl 用圖論讓機率「看得見、講得通」，把 1960-70 年代被符號主義邊緣化的機率方法拉回 AI 中心，開啟了「機率圖模型」這個橫跨 AI 與統計的領域，並最終為 2011 年圖靈獎鋪路（Pearl 獲 2011 年圖靈獎，理由正是貝葉斯網路）。本書敘事上，這是傳統 AI 內部第一次「用嚴格數學修復工程湊合」的成功範例——與 CF 模型的失敗形成精確對照。

## 貝葉斯網路的定義

**定義**：貝葉斯網路是有向無環圖（DAG）$G = (V, E)$，節點為隨機變數 $X_1, \ldots, X_n$，每個節點附一個條件機率分布 $P(X_i \mid \text{Pa}(X_i))$，並滿足**鏈式分解**：

$$P(X_1, \ldots, X_n) = \prod_{i=1}^{n} P(X_i \mid \text{Pa}(X_i))$$

若每個節點至多有 $k$ 個父親，參數量為 $O(n \cdot 2^k)$——線性於變數數，而非指數。**圖結構就是知識**：邊編碼了「誰直接影響誰」，條件獨立性可從圖的**d-分離**（d-separation）讀出。

### d-分離：從圖讀出獨立性

三種基本連接：

- 鏈 $A \rightarrow B \rightarrow C$：給定 $B$，$A \perp C$（間接影響被阻斷）。
- 分叉 $A \leftarrow B \rightarrow C$：給定 $B$，$A \perp C$（共同原因被觀察後，其孩子互獨立）。
- 碰撞 $A \rightarrow B \leftarrow C$：**相反**——未觀察 $B$ 時 $A \perp C$，**一旦觀察（或其後代被觀察）$B$，$A$ 與 $C$ 變得相依**（explaining away，「解釋掉」效應）。

碰撞結構的反直覺性正是貝葉斯網路超越直覺的地方：兩個獨立的病因，在病人被確診後會互相「競爭」解釋同一症狀。符號規則系統完全無法表達這種推理方向的反轉——從原因推症狀（診斷）與從症狀推原因（病因）在機率中是同一套公理的兩個方向（貝葉斯反轉），而 CF 模型對此一籌莫展。

## 推理：從證據到假設

### 精確推理

給定證據 $e$，要算後驗 $P(Q \mid e) = \frac{P(Q, e)}{P(e)}$。樸素方法是枚舉所有變數賦值（$O(2^n)$）；聰明方法利用分解：

- **變數消元**（Variable Elimination, Zhang & Poole 1994）：按順序逐個「消掉」非查詢變數，把中間因子（factor）相乘再求和，避免重複計算。複雜度由**樹寬**（treewidth）決定——圖越像鏈越快，越像網越爆炸。
- **聯合樹/聚類演算法**（Junction Tree, Lauritzen & Spiegelhalter 1988）：把 DAG 編譯成樹狀的 clique 結構，兩次傳播（collect/distribute evidence）得到所有節點的邊際。Hugin 系統等商用推理引擎的基礎。

### 近似推理

樹寬大於約 25 的網路精確推理不可行，實務靠取樣與變分：

- **拒絕取樣**：按先驗抽樣，丟掉不符證據的樣本——證據機率低時效率極差。
- **概似加權**（Likelihood Weighting）：固定證據節點為觀察值，對每個樣本加權 $w = \prod P(e_i \mid \text{pa}(e_i))$——重要的工程改良。
- **Gibbs 取樣**（MCMC）：從任一狀態出發，反覆按條件分布重抽單一變數，馬可夫鏈收斂到後驗。
- **變分推理**（變分貝葉斯、信念傳播 Belief Propagation）：把推理化為優化。信念傳播在樹狀圖上**精確**，在含環圖上近似但有時驚人地準（後來成為現代編碼理論 turbo 碼的數學基礎——AI 與通訊工程的意外交會）。

## Pearl 的更大野心：因果革命

貝葉斯網路最初只回答「證據→假設」的**觀測推理**。Pearl 很快意識到更深的問題：$P(\text{雨} \mid \text{傘多})$ 高，不代表「多帶傘會下雨」。**觀察與干預是兩回事**——相關不等於因果。他在 1995 年提出**do-算子**：$P(Y \mid do(X=x))$ 表達「強迫 $X=x$」的分布，在圖上等價於**切斷指向 $X$ 的所有邊**後再推論。由此發展出 do-演算、潛在結果模型的統一（與 Rubin 的框架合流），以及「因果階梯」：

1. **關聯**（seeing）：$P(Y \mid X)$——貝葉斯網路層次
2. **干預**（doing）：$P(Y \mid do(X))$——因果圖層次
3. **反事實**（imagining）：「如果當初沒做 X 會如何」

《The Book of Why》（2018）總結了這場長達三十年的革命：因果推理讓 AI 從「資料的鸚鵡」走向「會問為什麼的系統」。這條線今天在機器學習的可解釋性、因果發現（causal discovery）、去混淆學習中活躍，也是 LLM 時代被頻繁質疑的盲點（LLM 天生只會階梯第一層）。

## Python 程式碼範例：醫療診斷貝葉斯網路

以經典的「感冒—流感—發燒—咳嗽」網路為例，手工實作精確推理與概似加權取樣：

```python
import itertools, random

# 網路: 感冒→發燒, 感冒→咳嗽, 流感→發燒, 流感→倦怠
# CPT: P(變數 | 父親值) 以 dict[(變數, 父親賦值tuple)] = P(True) 表示
CPT = {
    ("感冒", ()): 0.30,
    ("流感", ()): 0.05,
    ("發燒", ("感冒", "流感")): {(0,0):0.02, (0,1):0.90, (1,0):0.60, (1,1):0.98},
    ("咳嗽", ("感冒",)):        {0: 0.10, 1: 0.85},
    ("倦怠", ("流感",)):        {0: 0.05, 1: 0.80},
}

def joint_prob(assign):
    p = 1.0
    for var in CPT:
        pa = tuple(assign[q] for q in parent_of(var))
        cpt = CPT[var]
        prob_true = cpt[pa] if isinstance(cpt, dict) and pa in cpt else cpt[()]
        p *= prob_true if assign[var] else (1 - prob_true)
    return p

def parent_of(var):
    m = {"感冒": [], "流感": [], "發燒": ["感冒","流感"], "咳嗽": ["感冒"], "倦怠": ["流感"]}
    return m[var]

VARS = ["感冒", "流感", "發燒", "咳嗽", "倦怠"]

def enumerate_inference(query, evidence):
    """精確推理: 枚舉所有隱變數賦值"""
    hidden = [v for v in VARS if v not in evidence and v != query]
    post = 0.0, 0.0
    pos = neg = 0.0
    for combo in itertools.product([0,1], repeat=len(hidden)):
        assign = dict(evidence); assign.update(dict(zip(hidden, combo)))
        assign[query] = 1; p1 = joint_prob(assign)
        assign[query] = 0; p0 = joint_prob(assign)
        pos += p1; neg += p0
    return pos / (pos + neg)

def likelihood_weighting(query, evidence, N=200000):
    weights = {1: 0.0, 0: 0.0}
    for _ in range(N):
        assign, w = {}, 1.0
        for var in VARS:                       # 拓撲序: 此例手排
            cpt = CPT[var]; pa = tuple(assign[q] for q in parent_of(var))
            pt = cpt[pa] if isinstance(cpt, dict) and pa in cpt else cpt[()]
            if var in evidence:
                assign[var] = evidence[var]
                w *= pt if evidence[var] else (1 - pt)
            else:
                assign[var] = 1 if random.random() < pt else 0
        weights[assign[query]] += w
    return weights[1] / (weights[1] + weights[0])

evidence = {"發燒": 1, "咳嗽": 1}
print(f"精確推理 P(感冒|發燒,咳嗽) = {enumerate_inference('感冒', evidence):.3f}")
print(f"概似加權   P(感冒|發燒,咳嗽) = {likelihood_weighting('感冒', evidence):.3f}")
print(f"精確推理 P(流感|發燒,咳嗽) = {enumerate_inference('流感', evidence):.3f}")

# explaining away: 再加入倦怠證據後, 流感機率上升 → 感冒被「解釋掉」
e2 = {"發燒": 1, "咳嗽": 1, "倦怠": 1}
print(f"精確推理 P(感冒|發燒,咳嗽,倦怠) = {enumerate_inference('感冒', e2):.3f}")
```

典型輸出：

```
精確推理 P(感冒|發燒,咳嗽) = 0.824
概似加權   P(感冒|發燒,咳嗽) = 0.824
精確推理 P(流感|發燒,咳嗽) = 0.357
精確推理 P(感冒|發燒,咳嗽,倦怠) = 0.466
```

最後一行是**本節的心臟**：加入「倦怠」證據後，感冒的後驗從 0.82 掉到 0.47——因為倦怠替「發燒」提供了另一個解釋（流感），感冒被「解釋掉」了。這種證據間的動態競爭，CF 模型與規則系統都無法表達。

## 貝葉斯網路的影響譜系

```mermaid
flowchart TD
    A[CF模型失敗 1976<br>Adams批評 1976] --> B[1985 Pearl 貝葉斯網路]
    B --> C[精確推理: 變數消元/聯合樹]
    B --> D[近似推理: MCMC/信念傳播]
    B --> E[因果革命: do-算子 1995<br>因果階梯]
    D --> F[圖模型統一: MRF/CRF<br>2000s 統計NLP主力]
    E --> G[因果發現/可解釋ML/去混淆]
    F --> H[隱馬可夫模型(5.2節)<br>條件隨機場]
    G --> I[現代ML科學基礎]
    H --> J[2012後: 圖模型被神經網路大面積取代<br>但因果推理存活並持續影響ML]
```

2000 年代初，機率圖模型（HMM、CRF、主題模型 LDA）統治了 NLP 與語音（第 5.2、7.2 節）；2012 年後神經網路以端到端學習接管，圖模型大幅退潮——但**因果推理**作為 Pearl 遺產中最不可替代的部分，在 LLM 時代反而更顯重要（9.2 節）。

## 本節重點

1. 專家系統的 ad hoc 不確定性處理（CF）在數學上不自洽；Pearl 用條件獨立性把 $2^n$ 參數爆炸壓回 $O(n \cdot 2^k)$，貝葉斯網路是「嚴格數學修復工程湊合」的典範。
2. d-分離從圖結構讀出條件獨立性；碰撞結構的 explaining away 效應是符號規則無法表達的推理現象。
3. 精確推理（變數消元、聯合樹）受樹寬制約；實務依賴概似加權、Gibbs 取樣、信念傳播等近似方法。
4. Pearl 的因果革命（do-算子、因果階梯）把「相關」與「因果」區分開，是貝葉斯網路留給現代機器學習最持久的遺產。
5. 圖模型在 2012 年後被神經方法大面積取代，但因果推理與機率思維存活並持續塑造 LLM 時代的討論（幻覺、可解釋性、反事實）。
