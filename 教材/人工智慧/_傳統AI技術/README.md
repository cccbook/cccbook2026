# 傳統 AI 技術：LLM 崛起之前的方法

本書是「cccbook 教材系列」的第五本，系統性梳理 1950-2026 年間 LLM 崛起之前的傳統 AI 技術：符號主義與專家系統、搜尋與博弈、邏輯與自動推理、貝葉斯網路與 HMM、統計機器學習、手工特徵的視覺與 NLP、演化計算與元啟發式，以及傳統方法的遺產如何與深度學習／LLM 時代融合。

全書以「技術與理論的前因後果、互相驅動關係」為主軸：每章說明當時遇到什麼問題、為何舊方法失效、新方法如何解決、又引出什麼新問題，並以兩次 AI 寒冬的興衰週期貫穿全書。

**與系列其他四本的關係**：
- 第一本《Python 程式設計》提供實作基礎語言；
- 第二本《資料結構與演算法》是本書搜尋、優化各章的先行課程；
- 第三本《機器學習／深度學習》正面講述本書第 9 章的勝出範式（表示學習、神經網路）；
- 第四本《大型語言模型》講述 2017 年後的主角（Transformer、LLM）；
- 本書則回頭補齊「前傳」——理解 LLM 為何勝出、哪些傳統技術被取代、哪些以知識圖譜、Neuro-Symbolic、混合系統的形態存活並融合，必須先讀懂 LLM 崛起之前的這五十年。
