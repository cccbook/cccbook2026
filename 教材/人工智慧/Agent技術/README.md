# Agent 技術：從符號 AI 到 Code Agent

一本追蹤「Agent」概念七十年演化的繁體中文教科書：從 1950 年代的 Sense-Plan-Act 與符號 AI，途經知識表示、強化學習與深度學習的積累，到 2022 年 LLM 與 In-context Learning 點燃的 Agent 迴圈，再到 MCP 工具生態、Code Agent、多 Agent 社會、記憶與規劃、評估基準，最後回到安全與 AGI 之問。

本書強調**技術與理論的前因後果**：每章說明當時遇到什麼問題、為何舊方法失效、新方法如何解決、又引出什麼新問題——理解因果鏈，才能看清 2026 年 Agent 技術的每一塊積木為何長成今天的形狀。

各章均含歷史背景、架構解析、Mermaid 圖（sequenceDiagram/flowchart）、程式碼範例、本節重點與思考問題。
