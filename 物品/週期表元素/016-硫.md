# 硫 (Sulfur, S)

## 基本資料
- **全名／簡稱**：硫 / S（Sulfur / Sulphur）
- **原子序**：16
- **原子量**：32.06
- **位置**：第 3 週期、第 16 族（VIA，氧族）
- **分類**：非金屬

## 化學特性
- 黃色脆性固體，俗稱「硫黃」，燃燒時發出藍色火焰與刺鼻 SO₂。
- 氧化態多樣（-2 至 +6）；易形成硫化物、硫酸鹽與多硫鏈。
- 同素異形體眾多（斜方硫、單斜硫、彈性硫）。

## 重要化合物
- 硫酸（H₂SO₄，「化學工業之母」）、二氧化硫、硫化氫（臭蛋味毒氣）、二硫化碳、硫化橡膠、石膏。

## 用途
- 硫酸：肥料、電池、化工原料（用量最大的工業化學品之一）。
- 橡膠硫化（固特異法）、火藥（黑火藥成分）、殺菌劑（波爾多液、硫磺粉）。
- 醫藥（硫磺軟膏治皮膚病）。

## 發現者與歷史
- 古代即知（聖經中「硫磺火」、中國煉丹與黑火藥）。
- 1777 年**拉瓦節（Lavoisier）**證明硫是元素而非化合物。
- 20 世紀弗雷許法（Frasch process）從地下直接熔取硫，現多從石油脫硫回收。
