# 週期表元素

化學元素的完整目錄：001 氫到 118 鿫，共 118 個元素，每個元素一個條目檔案。

## 條目一覽

- 第 1–18 族依原子序編號：`001-氫.md` 至 `118-鿫.md`
- 命名格式：`原子序-中文名.md`（三位數補零）
- 包含 94 種天然元素與 24 種人工合成元素（93 鿿起及少數短半衰期者）

## 檢索提示

- 鹼金屬：鋰、鈉、鉀、銣、銫、鍅（003、011、019、037、055、087）
- 鹼土金屬：鈹、鎂、鈣、鍶、鋇、鐳（004、012、020、038、056、088）
- 過渡金屬：鈧至鋅、鎵系後各族（021–030 等）
- 鑭系：鑭至鎦（057–071）；錒系：錒至鐒（089–103）
- 惰性氣體：氦、氖、氬、氪、氙、氡、鿫（002、010、018、036、054、086、118）
