# Linkabit 傳記——從編碼理論到無線帝國的源頭

1968 年，兩位 MIT 教授 Irwin M. Jacobs 與 Andrew J. Viterbi 在聖地牙哥創立 Linkabit 公司，把 channel coding 與 Viterbi 演算法從學術論文變成衛星與軍事通訊的實際設備，孕育了聖地牙哥的無線與衛星通訊產業；1980 年併入 M/A-COM 後因文化衝突，兩人於 1985 年離開並創立 Qualcomm，以 OmniTRACS 起家、押注 CDMA，歷經 IS-95 標準之戰、3G 專利與晶片帝國、4G/5G 轉型，最終塑造了現代手機的技術基礎。本傳記以因果鏈的方式，講述「一條演算法如何長成一個產業」的完整故事。
