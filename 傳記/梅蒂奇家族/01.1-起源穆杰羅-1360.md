# 1.1 起源穆杰羅（1360）

1360 年，喬凡尼·迪·比奇·德·梅蒂奇（Giovanni di Bicci de' Medici）出生於佛羅倫斯北郊穆杰羅的鄉村。梅蒂奇（Medici）意為「醫生」——家徽六顆藥丸（palle），傳說是祖先當藥劑師的標誌（另一說是錢幣）。從鄉下人到銀行家，第一代。

## 佛羅倫斯的機會

- 14 世紀佛羅倫斯：羊毛業 + 銀行業，歐洲最富的城邦之一；
- 黑死病（1348）殺死一半人口，活下來的人分到更多資源——災難製造階級流動；
- 喬凡尼伯父在羅馬開銀行，他去投奔學徒——**朝中有人好辦事**，文藝復興也不例外。

## 與羅斯柴爾德的對照

|  | 梅蒂奇（1360） | 羅斯柴爾德（1744） |
|---|---|---|
| 起點 | 鄉下人 | 隔離區 |
| 行業 | 銀行（教皇的錢） | 銀行（王室的錢） |
| 政治 | 幕後統治佛羅倫斯 | 從不直接統治 |
| 結局 | 成為王朝（大公） | 保持銀行家 |

兩個銀行家族，兩種命運——梅蒂奇選擇了王冠（第 4 章）。
