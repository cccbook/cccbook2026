# 歐拉傳 -- Leonhard Euler (1707-1783)

18 世紀最偉大的數學家，一生寫下 850+ 篇論文與著作，革命了記號（ $e$ 、 $i$ 、 $\pi$ 、 $f(x)$ ）、創立圖論與變分法，並在失明後以心算繼續推動數學前行。
