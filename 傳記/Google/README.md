# Google 傳記：組織資訊世界的四分之一世紀

本書是一部 Google 的編年傳記，從 1996 年史丹佛宿舍裡的 BackRub 爬蟲，到 2023 年後與 OpenAI 激戰的生成式 AI 时代。全書以「因果鏈」為敘事主軸：技術突破如何催生產品、產品如何驅動商業模式、商業成功如何重塑組織，而組織又如何投入下一波技術競賽。搜尋、廣告、行動、雲端、AI——每一波的後果都是下一波的前因。
