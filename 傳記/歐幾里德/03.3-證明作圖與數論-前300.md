# 3.3 證明作圖與數論

原本的魅力不僅在幾何，更在多樣的證明典範。第一卷第四十七命題給出畢氏定理的經典證明，以面積拼補展現直角三角形的關係，成為後世教科書的標準圖像。第九卷第二十命題則以反證法證明質數無窮：假設質數有限，將其連乘加一，必得新質因數，矛盾。

$$ \text{設質數為 } p_1,p_2,\dots,p_n \text{，令 } N = p_1 p_2 \cdots p_n + 1 $$

則 $N$ 的任一質因數皆不在原表之中，故質數無窮無盡。

第七卷還載有輾轉相除法求最大公因數，以幾何語言描述遞歸過程：

$$ \gcd(a,b) = \gcd(b, a \bmod b) $$

作圖、反證、窮竭、歸謬在此交會，顯示演繹方法的多樣性。數論命題以幾何形式出現，也反映當時數形未分的特色。

## 因果分析

方法的示範是因，後世的模仿是果。畢氏定理的證明樹立了面積轉換的範式，質數無窮展示了反證法的威力，輾轉相除則預示了算法思想。這些具體案例使抽象的公理方法落到實處，讓讀者不僅信服結論，更學會技藝。正因原本提供了可複用的證明模板，它才超越了知識彙編，成為思維訓練的母本，持續驅動數學創造。
