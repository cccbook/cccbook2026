# 好萊塢傳記 Hollywood (1908-)

好萊塢不是一個地名，而是一種能力的傳記：把技術變成夢、把夢變成錢、把錢再變成下一個技術。本書從 1908 年愛迪生專利托拉斯追殺獨立製片人寫起，經八大片廠、有聲革命、海斯法典、派拉蒙判決、電視衝擊、黑名單、新好萊塢、大白鯊與星戰、錄影帶與併購、獨立電影與 CGI、漫威宇宙與中國市場、串流戰爭與疫情，直到 2023 年編劇演員工會大罷工與 AI 爭議。全書主線是事件之間的因果鏈：技術→商業模式→創作→法規→下一波技術，每節附 mermaid 因果圖與「因果鏈」小結。
