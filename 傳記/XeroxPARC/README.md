# Xerox PARC 傳記：改變世界卻錯失世界的實驗室

本書講述全錄帕洛阿圖研究中心（Xerox Palo Alto Research Center, PARC）的故事：一家靠影印機獨占利潤滋養的公司，如何在 1970 年代於加州創造了個人電腦（Alto）、圖形使用者介面（GUI）、乙太網路、雷射印表機、Smalltalk、所見即所得編輯等定義現代運算的發明，卻因組織隔閡、商業視野與人才流失，讓成果大多由 Apple、Adobe、3Com、Sun 等他人收割。全書以因果鏈貫穿——利潤養出實驗室、實驗室生出發明、發明因公司失誤而外溢、外溢最終改寫整個產業。
