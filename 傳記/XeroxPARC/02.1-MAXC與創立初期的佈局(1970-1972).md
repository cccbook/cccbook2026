# 2.1 MAXC 與創立初期的佈局（1970-1972）

PARC 成立後的第一個大型工程，是一部大型積體電路電腦 **MAXC**（Multiple Access Computer，暱稱刻意致敬 DEC 的 PDP-10，兩者的關係微妙——Xerox 才剛併購 SDS，而 MAXC 直接與之競爭）。柏克萊 Genie 團隊的 Butler Lampson、Chuck Thacker 主導設計，採用當時最先進的 MOS 半導體記憶體，並率先使用 PROM/Microcode 的系統化設計方法。

MAXC 在管理層眼中是「Xerox 進入電腦業」的載體，在研究員眼中則是練兵之作：它讓 PARC 建立了從晶片設計、電路到作業系統的完整自製能力。同一時期，Alan Kay 開始構想 **Dynabook**——一台孩子也能用的、書本大小的個人電腦，這個願景成為整個 PARC 的「北極星」：不是做更大的電腦，而是做屬於每個人的電腦。

這兩件事共同界定了 PARC 的早期路線圖：要讓「未來辦公室的每個人都有一台互動電腦」，就需要（1）便宜夠快的個人機器（→Alto）、（2）連接它們的網路（→乙太網路）、（3）高品質的文件輸出（→雷射印表機）、（4）友善的介面（→GUI 與 Smalltalk）。這個完整的系統想像，正是 PARC 與其他實驗室的根本差異——他們不是在發明零件，而是在發明一個生態系。

```mermaid
flowchart LR
    A[MAXC 專案 1970-72] --> B[建立自製電腦/晶片/OS 能力]
    C[Alan Kay 的 Dynabook 願景] --> D[『人人都有一台電腦』的路線圖]
    B --> D
    D --> E[四件套：個人機器、網路、列印、介面]
    E --> F[Alto + Ethernet + 雷射印表機 + GUI/Smalltalk]
```

### 因果鏈
Genie 團隊帶來的系統工程能力 → MAXC 作為練兵場 → Alan Kay 的 Dynabook 願景賦予方向 → PARC 反推所需的四大技術支柱 → 每一根支柱都對應後來的一項劃時代發明。Dynabook 雖然從未以原貌問世，但它是 Alto、GUI 與筆記型電腦共同的精神源頭。
