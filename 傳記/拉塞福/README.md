# 拉塞福傳記：原子核物理之父

埃內斯特·拉塞福（Ernest Rutherford, 1871–1937），紐西蘭農家之子，憑藉對放射性與原子結構的研究，開創了原子核物理。本傳記共五章，追溯他從南島鄉村到卡文迪許實驗室、再到曼徹斯特與劍橋的科學旅程。
