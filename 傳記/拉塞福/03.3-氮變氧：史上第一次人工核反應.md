# 3.3 氮變氧：史上第一次人工核反應

蛻變理論確立後，拉塞福面臨新問題：α粒子究竟是什麼？他在麥吉爾的電磁偏轉與光譜實驗已強烈暗示α粒子是氦離子（此結論1908年在曼徹斯特最終證實）。離開加拿大前夕，他又注意到一個古怪現象：純α射線通過空氣時，游離計數中偶爾出現射程特別長的粒子。這個異常成為他心中懸而未決的謎。

這個謎正是通往人工核反應的線索。拉塞福的推理是：α粒子若真是氦核，質量大、動能高，與原子碰撞時或許能撞出什麼東西。他回到英國後持續追查，最終在1919年完成實驗：讓α粒子穿過氮氣，發現產生的長射程粒子確為氫核（質子），而氮原子轉化為氧的同位素。這是人類歷史上第一次人工核反應，把煉金術士「點石成金」的夢想變成科學事實。

其核反應可寫為：

$${}^{14}\mathrm{N} + \alpha \rightarrow {}^{17}\mathrm{O} + p$$

這項成果的因果意義有三層：第一，證明α粒子確實能夠「改變」原子核，蛻變理論從自發現象擴展到人工誘發；第二，質子從核中被撞出，暗示原子核由更基本的粒子構成，直接引向日後的原子核模型與中子假說；第三，確立了「以粒子為炮彈轟擊原子核」的研究範式，此後加速器的發明都是這一範式的技術延伸。

**因果分析**：從麥吉爾時期的異常觀察到1919年的確證，歷時十餘年——說明重大發現往往不是靈光一現，而是長期「懸置問題」的收穫。拉塞福對異常數據的執著，是因果鏈得以延伸的關鍵：別人眼中無關緊要的長射程粒子，在他眼中卻是原子核向人類發出的信號。
