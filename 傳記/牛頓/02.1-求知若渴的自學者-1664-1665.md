# 2.1 求知若渴的自學者

1664至1665年是牛頓的「自我塑造期」。他的筆記簿（後世稱為「某些哲學問題」筆記）記錄了他在這段時間的自學軌跡：從笛卡兒的光學理論、伽利略的落體運動，到波義耳的氣體實驗，再到惠更斯的擺鐘研究。牛頓讀書的方式不是接受，而是拆解與驗證——他重算笛卡兒的每個證明，重做波義耳的實驗，並在頁邊寫下自己的質疑。

在數學上，這段時間的牛頓經歷了一場「壓縮式成長」。1665年初，他開始思考如何處理「連續變化的量」。當時數學家已能處理曲線的切線與面積兩大問題，但方法零散。牛頓從沃利斯（John Wallis）的《無窮算術》出發，把沃利斯的插值法推廣到負指數與分數指數，得到二項式級數：

$$(1+x)^n = \sum_{k=0}^{\infty} \binom{n}{k} x^k \quad (\text{對任意 } n)$$

有了二項式級數，牛頓就能把複雜曲線展開成冪級數，逐項積分求面積。這正是微積分的第一塊基石。與此同時，他開始用「流數」（fluxion）一詞描述隨時間變動的量，並發展出求切線的普遍方法。

在物理上，他記錄了對「重力」的初步思考：重物的墜落是否與月球繞地球的運行出於同一原因？這個問題當時只是筆記中的一行猜想，尚未成熟。

## 因果分析

這一節的因果主線是「輸入決定輸出」：經院教育的空洞（因）使牛頓轉向當代前沿著作（果），而這些著作各自的缺陷恰好成為他的突破口——沃利斯的級數不完備，牛頓便推廣它；笛卡兒的力學模糊，牛頓便重構它。科學史家稱此為「站在巨人肩上，但把梯子自己重搭」。1665年前的自學積累是必要條件，它與隨後的瘟疫隔離（充分條件）共同構成「奇蹟年代」的完整成因。
