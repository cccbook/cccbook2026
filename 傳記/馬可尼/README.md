# 馬可尼傳記——剪斷電線的人：從火花到全球無線網

古列爾莫·馬可尼（Guglielmo Marconi, 1874-1937）是把赫茲實驗室裡數公尺的火花變成橫跨大西洋的產業的人。本傳記共五章十五節，自博洛尼亞別墅的槍聲寫起，經倫敦創業、英吉利海峽、波爾德胡與聖約翰斯的三聲「S」、專利戰與1909年諾貝爾獎、鐵達尼救難與一戰軍用化、廣播前夜，迄於短波重生、法西斯糾葛與馬可尼公司的百年浮沉，突出事件之間的因果驅動：每一項距離紀錄如何被前因逼出，又如何引發下一場豪賭、官司或立法。
