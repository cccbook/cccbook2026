# AT&T 傳記：從貝爾電話到光纖帝國 (1876-2026)

美國電話電報公司（AT&T）是美國監管資本主義的最佳標本：它以一紙電話專利起家，以 Vail 的「One Policy, One System, Universal Service」建成百年壟斷，以貝爾實驗室的電晶體、資訊理論、Unix 間接催生數位時代，又因壟斷而三度被切（1913、1956、1984），最終由昔日子公司 SBC 反向收購借屍還魂，歷經 iPhone 獨家、DirecTV 與時代華納豪賭、WarnerMedia 分拆，回归 5G 與光纖本業。本書共 5 章 15 節，每節以事件因果鏈貫穿，揭示壟斷—分拆—重組的百年迴圈如何互相驅動。
