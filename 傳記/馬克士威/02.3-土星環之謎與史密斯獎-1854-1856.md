# 2.3 土星環之謎與史密斯獎

1855 年，亞當斯獎（Adams Prize）出題：土星環是固體、液體還是顆粒群？馬克士威的解答贏得 1857 年首獎。

## 問題的物理本質

- 環若是**剛性固體**：內側與外側的角速度應相同，但潮汐力會撕裂它——不成立；
- 環若是**液體**：波動會使其破碎——不成立；
- 環必是**無數獨立小質點**（衛星群）：這是唯一穩定的解。

## 方法論的突破

他把環簡化為「無數自由質點的集合」，用微擾分析證明其穩定性。這是統計方法應用於大數系統的先聲。

```mermaid
flowchart LR
    A[土星環穩定性問題] --> B[大數目獨立質點系統]
    B --> C[微擾與統計分析]
    C --> D[直接預備了氣體分子運動論的方法]
    D --> E[1859-1860: 速度分布律]
```

**因果**：研究土星環必須處理「億萬質點的集體行為」，這迫使他發展出處理大數系統的技巧與思想——三年後他把同一套思想用於氣體分子，得到馬克士威速度分布律。土星環是分子運動論的「演習場」。

1859 年證據到位（望遠鏡觀察到環的縫隙，暗示環由獨立質點組成），他的理論預測被證實。這增強了他「用數學結構推斷不可見世界」的信心——同樣的信心後來支撐了電磁波的預言。
