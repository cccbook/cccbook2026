# 三愛電子傳記——台灣電子業的搖籃

三愛電子（1972–1994）是台灣第一家由本土資金、技術創辦的電子公司。資本額僅 250 萬元，卻走出溫世仁、林百里、葉國一——日後英業達（2356）、廣達（2382）的創辦人。它只活了 22 年，倒閉時無聲無息；但台灣每年數兆元的電子產值，源頭都在承德路那間小工廠。本書共五章十五節，重建這段「母雞雖死、小雞滿天」的產業因果鏈。
