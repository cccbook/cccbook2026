# 愛因斯坦傳（Albert Einstein, 1879–1955）

本書以因果鏈的方式敘述愛因斯坦的一生：從馬克士威方程與光速之謎，到1905奇蹟年、廣義相對論、1919日食驗證與世界成名、諾貝爾獎、量子論戰、納粹崛起下的流亡，最後到普林斯頓歲月與羅素—愛因斯坦宣言。
