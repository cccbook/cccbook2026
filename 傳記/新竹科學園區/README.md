# 新竹科學園區（竹科）傳記

新竹科學園區（1980–）是台灣第一座科學園區，也是全球半導體產業密度最高的一平方公里。從 1973 年工研院、1976 年 RCA 技術移轉，到 1980 年聯電第一家進駐、1987 年台積電誕生，再到兆元產值、2 奈米寶山擴建，竹科的歷史是一部「技術官僚賭國運」的台灣現代史。本書共五章十五節，按時序重建其政策賭注、產業聚落與社會因果鏈。
