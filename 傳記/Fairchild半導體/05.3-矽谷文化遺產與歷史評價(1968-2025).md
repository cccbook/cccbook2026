# 5.3 矽谷文化遺產與歷史評價(1968-2025)

## 一家公司如何變成一種文化

Fairchild 作為企業已淡出，但作為文化基因無處不在：

1. **股權創業範式**：八叛逆持股、Intel 全員選擇權，確立「人才以股權定價」的規則。此後矽谷默認：好公司必須給工程師股票，否則招不到人。
2. **創投業誕生**：Arthur Rock 因撮合 Fairchild、Intel 而領悟風險投資；Eugene Kleiner 1972 年創 Kleiner Perkins，Don Valentine 1974 年創 Sequoia。沒有 Fairchild 的示範，就沒有這兩家投出蘋果、Google、亞馬遜的帝國。
3. **自由流動 + 寬容失敗**：加州競業禁止無效 + Fairchildren 證明「叛逃能成功」，形成「離職創業光榮、失敗回爐正常」的氛圍。波士頓 128 號公路輸給矽谷，輸的正是這一點。
4. **製程至上與摩爾定律**：Hoerni 平面製程 → Moore 論文 → Intel Tick-Tock，半導體業此後六十年照此節拍起舞，直到 $n(t)$ 逼近原子極限。

Noyce 晚年說：「Fairchild 最大的產品不是電晶體，而是公司本身——我們生產公司。」（The company itself was the product.）這句話是全書最好的註腳。

## 因果鏈（全書總鏈）

- 電晶體發明 → Shockley 出走西岸 → 八叛逆 → 平面製程 → IC → 軍事訂單 → 規模化 → 摩爾定律 → 母公司衝突 → Intel/AMD → Fairchildren → 創投業 → 矽谷生態 → 功率重生。每一環都是前一環的果、後一環的因。
- 核心驅動只有兩條：**技術的可製造性**（平面製程解決量產）與**人才的自由流動**（出走解決創新）。Fairchild 同時點燃兩者，又同時被兩者反噬——這正是它偉大而悲壯的原因。
- 歷史評價：作為公司，Fairchild 是失敗者（市占歸零、兩度被賣）；作為母體，它是矽谷最成功者（子體市值總和超母體萬倍）。評價它，必須用生態系的尺，而非公司的尺。
