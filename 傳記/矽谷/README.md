# 矽谷：一個地區與生態系的人物傳記式歷史

本書以「人」為經、以「因果」為緯，書寫矽谷從果園到AI時代的歷史。核心因果線是「叛徒文化」與人才循環：每一代的離職者成為下一代的創辦人，資金、技術與公司的系譜不斷繁衍。
