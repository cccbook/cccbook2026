# Fairchild Semiconductor 快捷半導體傳記

Fairchild Semiconductor（快捷半導體，1957–2016）是矽谷的母體：它源於貝爾實驗室電晶體發明與蕭克利半導體實驗室的「八叛逆」出走，以 Hoerni 平面製程與 Noyce 積體電路開創半導體量產時代，靠阿波羅與民兵飛彈訂單登上巔峰並孕育摩爾定律，卻因母公司衝突在 1968–1969 年裂變出 Intel、AMD 與數十家 Fairchildren，反而催生創投業與矽谷生態；本書以因果鏈貫穿始終，解釋一家公司的衰落如何變成一個時代的繁榮。
