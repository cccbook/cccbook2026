# 台積電（TSMC）傳記

台積電（台灣積體電路製造公司，1987–迄今）是半導體史上最徹底的分工革命：張忠謀以「純晶圓代工、不與客戶競爭」的理念，在新竹科學園區一座舊廠房起家，歷經銅製程、十二吋晶圓、浸潤式微影、FinFET 四場豪賭全勝，於 7 奈米超越英特爾與三星登頂，又以蘋果 A 系列、海思麒麟、AMD 與輝達 AI 晶片為憑，成為全球九成先進製程的製造者；本書以因果鏈貫穿十五節，解釋一家代工廠如何從邊陲走向「護國神山」，又如何在晶片短缺、晶片法案與美日德擴廠的地緣政治時代，走進 2 奈米與魏哲家的新局。
