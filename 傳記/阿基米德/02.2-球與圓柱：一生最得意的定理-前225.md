# 2.2 球與圓柱：一生最得意的定理

阿基米德在《球與圓柱》中證明：球的表面積等於其最大圓（大圓）面積的四倍，球的面積等於外切圓柱側面積的三分之二，體積亦為外切圓柱體積的三分之二。以公式表示：

$$S_{球} = 4\pi r^2, \qquad V_{球} = \frac{4}{3}\pi r^3 = \frac{2}{3}V_{圓柱}$$

據普魯塔克記載，阿基米德認為這是畢生最傑出的發現，遺囑中要求把「內切於圓柱的球」圖形刻在自己的墓碑上。一百多年後，羅馬執政官馬塞勒斯家族的友人西塞羅任西西里財務官時，果然在荒草中憑此圖形找到了他的墳墓。

證明的核心工具是窮竭法與「阿基米德公理」（任何量都可被自身足夠多的倍數超過另一量），再以雙重歸謬法收尾：先假設球與圓柱體積之比不等於 2:3，推出矛盾。

```mermaid
    A[窮竭法逼近球體積] --> B[內接外切多面體分割]
    B --> C[提出猜想比值 2:3]
    C --> D[雙重歸謬證明]
    D --> E[定理成立]
    E --> F[遺囑刻墓碑圖形]
    F --> G[西塞羅尋獲墳墓 遺產延續]
```

**因果分析**：這條定理的因果網絡橫跨阿基米德一生與身後。前因：圓柱與球的體積對當時的度量衡（如球形容器容積換算）有直接意義，推動他攻堅；而窮竭法提供了可行性。後果有三層：數學上，它開啟了「曲面立體可精確度量」的信念，直接刺激後世積分思想的發展；文化上，墓碑圖形成為知識分子超越政治的象徵；傳播上，正因西塞羅找到並修繕了墳墓，阿基米德的名字在羅馬精英中保持記憶，為其手稿的拉丁傳承鋪路。一個幾何比值，串起了數學、死亡與記憶。
