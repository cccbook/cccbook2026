# 2.1 移動夢網簡訊分成救活騰訊

2000年底，中國移動推出「移動夢網」計劃，向內容與應用服務提供商（SP）開放短信通道，採用「移動代收費、與SP二八分成」的模式——用戶通過短信訂購服務，運營商收兩成、SP收八成。騰訊敏銳抓住機會，推出移動QQ：用戶以短信方式與QQ好友互通消息，每月數元包月費。僅靠這一項，騰訊在2001年即實現首次盈虧平衡，2001年收入近5000萬元人民幣，並於當年實現首次盈利，擺脫了燒錢困局。隨後QQ行、短信聊天、圖鈴下載等SP業務層層展開，構成騰訊早期收入的絕對主力。

```mermaid
flowchart LR
    A[移動夢網計劃] --> B[騰訊成為SP]
    B --> C[移動QQ短信互通]
    C --> D[二八分成收入]
    D --> E[2001年盈利]
    E --> F[解除生存危機]
```

**因果分析**：沒有移動夢網，騰訊大概率倒在2001年；而移動夢網之所以選中騰訊，正是因為QQ的巨量用戶是天然的短信變現入口——用戶規模第一次轉化為商業價值。但這一救生圈也埋下隱患：收入命脈握在中國移動手中，2004年後運營商政策收緊、SP打擊整頓，使騰訊再次被逼向自主變現模式，這直接催生了下一節的虛擬道具與會員體系。
