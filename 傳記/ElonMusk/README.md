# 伊隆·馬斯克傳記

本書是一部關於伊隆·馬斯克（Elon Musk, 1971–）的中文繁體傳記，從他在南非的童年、加拿大的求學歲月，到 Zip2、X.com/PayPal 的網路創業，再到賭上全部身家創立 SpaceX、入主 Tesla，最終走向火箭回收、電動車普及、星艦、AI 與機器人的宏大版圖。全書以「事件因果鏈」為主軸，說明每一次成功與危機如何互相驅動：PayPal 的資本催生了火箭夢，2008 年的瀕臨破產換來了 NASA 合約與獵鷹9 的回收革命，而電動車與自駕的積累則推向 AI 與人形機器人的未來。
