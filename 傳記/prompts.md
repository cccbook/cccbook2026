請按照以下模式，寫一本傳記 xxx=./全錄Parc研究中心/  Google/ Elon-Musk/ 

檔案名稱如 

* 01.1-yyyyyy.md
...
* 05.3-yyyyyy.md

yyyyyyy 是標題（標題最好加上年份）

目錄寫在 README.md 中，如下

* 第1章-xxxxxx
    * [1.1-yyyyyyy](01.1-yyyyyy.md)
...
* 第5章-xxxxxx
    * [5.1-yyyyyyy](05.1-yyyyyy.md)

* 第n章-xxxxxx
    * [n.1-yyyyyyy](n.1-yyyyyy.md)

....

格式採用標準的 github markdown ，可以用 tex 與 mermaid.

要盡量寫出事件關聯與前因後果，互相的驅動關係。
