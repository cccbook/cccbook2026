# 愛迪生傳記（Thomas Edison, 1847–1931）

本書敘述托馬斯·阿爾瓦·愛迪生從電報少年到企業化研發先驅的一生，著重各事件之間的因果驅動：電報員經歷孕育其電學素養，留聲機使他聲名鵲起，門洛帕克實驗室開創團隊發明模式，白熾燈與直流配電系統點亮城市，卻也引爆與特斯拉、西屋的電流戰爭；晚年他在西奧蘭治推動電影與礦業、水泥等事業，留下企業化研發實驗室的深遠遺產。
