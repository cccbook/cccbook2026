# 2.3 電話改良與碳粒傳聲器

1876年貝爾電話公司成立後，西方聯盟因誤判而退出電話業，隨後反悔，委託愛迪生開發競爭性電話。當時貝爾話機的弱點是音量小、距離短。愛迪生於1877年提出碳粒傳聲器（carbon transmitter）：以碳粒受壓改變電阻，使聲波調變電流強度，而非僅靠電磁感應，靈敏度與傳輸距離大幅提升。

這項發明引發與貝爾的專利訴訟，纏訟多年，最終庭外和解：西方聯盟以碳粒傳聲器專利換取電話業務分成並退出終端市場。愛迪生再度體驗專利作為談判籌碼的力量，也深刻理解了「聲音—電流—聲音」的轉換機制。正是在反覆測試傳聲膜片的振動時，他想到：既然膜片能將聲音轉為電流，那麼用針記錄膜片振動、再讓針重放振動，聲音便可能被「儲存」——這個直覺幾天內就化為留聲機的錫箔滾筒原型。

碳粒傳聲器的商業收益雖有限，戰略意義卻極大：它既為愛迪生贏得電話產業的持續分成，又直接催生留聲機，而留聲機的名聲又為他吸引投資、建立門洛帕克實驗室鋪路。

因果分析：西方聯盟的市場挫敗創造了研發委託；碳粒的電阻特性提供了技術方案；專利訴訟的和解帶來穩定收入與業界地位；傳聲器實驗中的類比聯想則直接觸發留聲機構想。一連串環環相扣的事件，顯示愛迪生的發明鏈條總是「上一項發明的副產品成為下一項發明的起點」。
