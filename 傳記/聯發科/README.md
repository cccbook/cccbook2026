# 聯發科（MediaTek）傳記

聯發科（MediaTek Inc., 2454.TW）是台灣第一大、全球前列的 IC 設計公司，由蔡明介於 1997 年率聯電 IC 設計部門分拆創立。從光儲存（CD-ROM/DVD）晶片稱霸全球，到以「交鑰匙」（Turnkey）方案引爆中國山寨機浪潮，再歷經智慧機轉型落後、高通打壓、合併晨星，到以 5G「天璣」（Dimensity）系列超車、登上台灣 IC 設計市值王，並佈局 Wi-Fi、電視、車用與 ASIC，聯發科的歷史是一部「以小搏大、以整合取勝」的台灣半導體逆襲史。本書共五章十五節，按時序重建其技術轉折、商業模式與產業因果鏈。
