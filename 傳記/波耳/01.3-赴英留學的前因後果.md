# 1.3 赴英留學的前因後果

1911年秋，波耳持卡爾斯貝里基金會獎學金前往劍橋，加入J.J.湯木生（電子發現者）的卡文迪許實驗室。原計畫是將博士論文譯成英文並請湯木生指導。然而合作並不順利：湯木生對論文興趣寥寥，波耳英語生硬、行事認真到近乎固執，兩人頻率不合。此時，父親的朋友、丹麥物理學家克里斯蒂安森建議他去曼徹斯特見拉塞福——這一建議改變了二十世紀物理的走向。

1911年11月，波耳拜訪拉塞福。當時拉塞福剛發表α粒子散射實驗的結論：原子有一個極小、帶正電的核心（原子核）。這個「核式模型」與經典電磁學矛盾——繞核電子會輻射能量而崩塌，且無法解釋原子的固定譜線。波耳意識到：把蒲朗克的量子假設 $E=h\nu$ 引入原子模型，或許能同時解決穩定性與光譜兩大難題。1912年春，他轉赴曼徹斯特。

```mermaid
    A[博士論文<br>經典電子論困境] --> B[赴劍橋投湯木生]
    B --> C[合作受挫]

    E --> F[孕育1913量子化原子模型]
```

**因果分析**：這是一連串「失敗引導成功」的因果。湯木生的冷遇看似挫折，卻促成波耳接觸拉塞福；而拉塞福的實驗事實（原子核）恰好是解決波耳博士論文困境的鑰匙。個人際遇與科學難題在此互相驅動：若無散射實驗，量子假設無落點；若無波耳的理論敏感，核式模型仍是孤立的實驗結論。
