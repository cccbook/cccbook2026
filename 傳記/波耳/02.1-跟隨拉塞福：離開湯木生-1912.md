# 2.1 跟隨拉塞福：離開湯木生

1912年4月至7月，波耳在曼徹斯特跟隨拉塞福工作。這段時間雖短，卻是他科學人生的轉捩點。拉塞福風格與湯木生截然不同：他信任直覺、鼓勵獨立、放手讓年輕人闖。波耳後來自稱「我是拉塞福的學生」，並說「拉塞福對我而言幾乎如同第二位父親」。這種亦師亦父的關係，日後被他複製到哥本哈根研究所的師徒文化中。

在曼徹斯特，波耳接觸到α粒子射程的測量數據（馬斯登與蓋革的實驗），並嘗試用電子與原子核的結合方式解釋放射性與化學性質。他寫了一份備忘錄（1912年6月，人稱「曼徹斯特備忘錄」），提出電子在原子中有「結合能」的量子化軌道概念雛形。7月他回丹麥完婚並在哥本哈根任教，但心仍在原子問題上。

**因果分析**：拉塞福的放權式指導 → 波耳獲得獨立攻堅的勇氣 → 備忘錄的粗糙構想 → 得到拉塞福肯定 → 回丹麥後持續演算 → 1913年初從巴耳末公式切入完成突破。可見「導師風格」是科學產出的實質變因：湯木生的威權壓抑了波耳，拉塞福的信任釋放了波耳；而波耳又將這種信任文化制度化，成為哥本哈根學派的組織基因。
