# 西南聯大傳記——戰火中的大學

國立西南聯合大學（1937–1946）由北京大學、清華大學、南開大學南遷合組，先有長沙臨時大學（1937–1938），後有昆明八年（1938–1946）。約 8000 人就讀，畢業 2000 餘；走出 2 位諾貝爾獎得主、6 位兩彈一星功勳、近百位院士。在土坯房裡證明：大學不在大樓，而在人。本書共五章十五節，重建這段「剛毅堅卓」的教育史因果鏈。
