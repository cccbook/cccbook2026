# 2005 · 肖萬、施羅克與格拉布——雙鍵的交換

> 2005 諾貝爾化學獎：伊夫·肖萬（Yves Chauvin，1930–2015，法國）、理查·R·施羅克（Richard R. Schrock，1945– ，美國）與羅伯特·H·格拉布（Robert H. Grubbs，1942– ，美國）——表彰「其對烯烴複分解反應之發展的貢獻」。**化學家學會了讓碳—碳雙鍵彼此「交換搭檔」。**

## 懸案（案情提要）

1990 年代的化學工業與合成化學，有一個「明明不該缺」的轉換：

- 烯烴是化工的基礎分子（乙烯、丙烯），而它們的官能基是**碳—碳雙鍵**；
- 但「**把雙鍵換掉**」——例如把 $\mathrm{RCH{=}CHR'}$ 變成 $\mathrm{RCH{=}CH''}$，或把兩個烯烴「配對」成新的烯烴——在當時**幾乎不可能**；
- 工業上想做這件事，只能用**高溫高壓下的自由基裂解**（產物複雜）或**以小分子為橋的逐步偶聯**（多步、產率低）；
- 合成化學家更常見的痛點是**逆需求**：烯烴的**交叉複分解（cross-metathesis）**——把兩個不同的烯烴「互換搭檔」，是製備複雜烯烴最直覺的方法，但沒人做得出來；
- 此外，天然產物與材料中的烯烴立體化學（$E$/$Z$）的控制，也一直缺乏溫和的方法。

**懸案的本質**：碳—碳雙鍵的 $\pi$ 鍵是一個「被鎖住的」反應中心，**如何讓它鬆動、並重新配對？**

偵辦人：肖萬（提出「金屬碳烯」途徑）、施羅克（發現金屬碳烯並做出可用的催化劑）、格拉布（做出穩定、易用的催化劑）。

## 前因

| 年份 | 事件 |
| --- | --- |
| 1930 / 1945 / 1942 | 肖萬生於法國 Châlons-sur-Marne；施羅克生於美國伊利諾伊州；格拉布生於美國肯塔基州。 |
| 1970s | 肖萬在**法國石油研究院（IFP）**研究烯烔的定向聚合（**定向聚合**）與烯烴的異構化；**1971 年**他提出：**若存在「金屬—碳烯」（metal carbene，$\mathrm{M{=}CHR}$）中間體，則烯烴的複分解必然經由「[2+2] 環加成 → 環丁烷 → 逆環加成」的路徑**——**這是機制的理論提案，當時沒有實驗證據。** |
| 1974–1975 | 施羅克在**埃默里大學**（與其導師 **Richard R. Schrock**）發展**環戊二烯前驅的「金屬烷基idene」前驅物**：$\mathrm{Cp_2Ta(=CHCMe_3)(CH_2CMe_3)}$，以 $\mathrm{PMe_3}$ 處理後釋出**游離的「Schrock 卡賓」** $\mathrm{Cp_2Ta{=}CHCMe_3}$。 |
| 1975 | 施羅克證明**這類金屬碳烯可催化烯烴的複分解**——**第一次「金屬碳烯」路徑的實驗證明**。 |
| 1990–1995 | **格拉布**在**加州理工學院**發展**Grubbs 催化劑**：以釕的**氮雜環卡賓（NHC）**配體製成$\mathrm{RuCl_2(=CHR)(\mathrm{PR}_3)_2}$ 型的催化劑（第一代為 $\mathrm{RuCl_2(=CHPh)(\mathrm{PPh_3)_3}$）——**對空氣、水與各種官能基穩定**。 |
| 1992 | 格拉布與其合作者（包括 **Fu**）發表 $\mathrm{RuCl_2(=CHPh)(\mathrm{PCy_3)_2}$ 與 NHC 配體的催化劑；**1995 年第二代「Grubbs 催化劑」問世**。 |
| 2001 | 格拉布與其合作者報告**乙烯與大環烯的複分解可驅動「環平衡 metathesis polymerizatio」**——**開啟了「環狀烯烴開環聚合（ROMP）」與「烯烔轉環聚合（RCM）」**。 |
| 2005 | 三人共享諾貝爾化學獎。 |
| 2010s | 複分解用於**天然產物合成**（環烯驅動的大環合成，如環狀肽的合成）、**材料科學**（可降解聚合物、烯烃 metathesis 聚合的自修補材料）、**油脂化工**（生物柴油的烯烔轉化）。 |

## 調查

**偵查一：肖萬的機制提案——「把最直覺的機構畫出來」。**

$$\text{肖萬的提議（1971）}：\ \mathrm{M{=}CHR} + \mathrm{R'CH{=}CH_2'} \xrightarrow{[2+2]\ \text{環加成}} \text{金屬環丁烷} \xrightarrow{\text{逆}[2+2]} \text{R'CH{=}CHR} + \mathrm{M{=}CH_2'}$$

$$\text{即：兩個烯烴「交換搭檔」，經由} \textbf{金屬環丁烷}\text{中間體}$$

**注意其大膽**：$[2+2]$ 環加成在一般的烯烔上是熱禁止的（見 [1981-福井與前沿軌域](1981-福井與前沿軌域.md)）——**但在金屬碳烯的參與下，它變得可行，因為「金屬的 $d$ 軌域」提供了不同的電子路徑**。

**偵查二：施羅克的發現——「游離的金屬碳烯是活性的」。**

$$\mathrm{Cp_2Ta(=CHCMe_3)(CH_2CMe_3)} + \mathrm{PMe_3} \rightarrow \mathrm{Cp_2Ta(=CHCMe_3)} + \text{烷烴}$$

$$\mathrm{Cp_2Ta(=CHCMe_3)} \xrightarrow[\text{烯烔}]{\text{催化}} \text{複分解產物}$$

**這證明了肖萬的提案**——**一個半世紀以來第一次，金屬碳烯被分離並被證明能催化反應。**

**偵查三：催化劑的實用化——「從活性到可用」。**

$$\text{Schrock 催化劑}：\ \mathrm{W(=CHCMe_3)(CH_2CMe_3)_2}\ (\text{極活潑，但極敏感})$$

$$\text{Grubbs 催化劑}：\ \mathrm{RuCl_2(=CHR)(\mathrm{NHC})(\mathrm{PR}_3)}\ (\text{穩定、耐水、耐氧})$$

$$\boxed{\text{同樣的機制、不同的金屬} \Rightarrow \text{實用性的差距} \Rightarrow \text{化學工業的接受度}}$$

**施羅克的催化劑活性高但壽命短（對酸與氧敏感）；格拉布的釕催化劑活性稍低但耐用得多。**這是科學史上的著名對照：**機制相同時，「可用性」決定成敗**。

**偵查四：立體化學——「E/Z 的可控性」。**

$$\text{舊催化劑} \Rightarrow \text{E/Z 選擇性差};\qquad \text{Grubbs II} \Rightarrow \text{高 E 選擇性（} \sim 90\%\text{）}$$

$$\text{原因}：\text{催化劑的} \mathrm{NHC} \text{配體的立體環境決定了} \textbf{金屬碳烯的取向}$$

**「用配體控制立體選擇性」——這是今日不對稱複分解（今日由 Schrock/Hoveyda 系統主導）的設計原理。**

**偵查五：從反應到聚合與材料。**

$$\mathrm{ROMP}：\ \text{環烯} \xrightarrow{\text{複分解}} \text{聚烯} \quad(\text{以雙鍵為「鉸鏈」})$$

$$\mathrm{RCM}：\ \text{二烯} \xrightarrow{\text{複分解}} \text{環烯} + \text{乙烯} \quad(\text{用複分解「關環」）}$$

$$\text{RCM 使大環天然產物（環狀肽、大環內酯）得以合成；ROMP 給出可降解、可自我修補的高分子}$$

```mermaid

    A[双键不能「交换搭档」<br>交叉複分解與逆轉皆不可能] --> B[1971 肖萬: 金属碳烯 + [2+2] 環加成<br>逆環加成 的機制提案]
    B --> C[1975 施羅克: 分离出金属碳烯<br>並證明其可催化複分解]
    C --> D[1990s 格拉布: 釕-NHC 催化劑<br>穩定、耐水、耐氧]
    D --> E[1995 第二代 Grubbs 催化劑<br>高 E 選擇性]
    E --> F[2001 環平衡聚合<br>ROMP / RCM]
    E --> G[2005 共享諾貝爾化學獎]
    F --> H[大環天然產物合成、可降解聚合物<br>生物柴油烯烃轉化]
```

## 理論裁決

**判決一：$[2+2]$ 環加成如何被「解禁」。**

$$\text{一般烯烴的} [2+2]\ \text{：熱禁止（} 4n\ \text{電子的} \sigma\text{ 環加成）}$$

$$\text{金屬碳烯參與時}：\ \text{金屬的} d\ \text{軌域參與成鍵} \Rightarrow \text{形成} \textbf{金屬環丁烷} \text{（} \pi\text{ 與} d\text{ 軌域的組合）}$$

$$\text{因此「熱禁止」的選擇定則並未被違背}，\text{而是走了另一條電子路徑}$$

**這是選擇定則的優雅示範：所謂「禁止」，指的是特定機構；換一條路徑，反應仍可發生。**

**判決二：複分解的熱力學驅動力——「乙烯是廢氣」。**

$$\mathrm{RCH{=}CHR' + R''CH{=}CH''' \rightleftharpoons RCH{=}CH''' + R''CH{=}CHR'}$$

$$\Delta G \approx 0\ \text{（平衡）};\qquad \text{但若移除乙烯（逸出）} \Rightarrow \Delta G < 0 \Longrightarrow \textbf{驅動}$$

$$\text{這解釋了 RCM 的實用性}：\ \text{環的形成 + 乙烯逸出} \xrightarrow{} \text{平衡被拉向產物}$$

**「用一個平衡反應做一件事，再用移除副產物（乙烯）把它推到底」——這是化學工程式的思考。**

**判決三：配體控制立體化學——「催化劑的立體環境」。**

$$\text{催化劑的立體環境} \xrightarrow{} \text{決定底物接近的取向} \xrightarrow{} \textbf{E/Z 或手性選擇性}$$

**這與 2001 年的手性催化（見 [2001-諾爾斯與手性催化](2001-諾爾斯與手性催化.md)）是同一原理**——只不過前者控制「面」，這裡控制「雙鍵兩側的排列」。

**判決四：機制的「三段式」——可預測性。**

$$\text{肖萬的提案} \xrightarrow{\text{施羅克的驗證}} \text{金屬碳烯} \xrightarrow{\text{格拉布的工程化}} \text{可用的催化劑}$$

$$\text{這是化學中最典型的「理論—驗證—應用」三元結構，也是諾貝爾獎最鍾愛的敘事節奏}$$

**因為三者共享同一個機制理解，所以三人在 2005 年共享同一座獎是自然的。**

## 後果

| 領域 | 影響 |
| --- | --- |
| 天然產物合成 | **環烯驅動的大環合成**：環狀肽（如環孢素）、大環內酯、大環二酮哌嗪的合成，因 RCM 而大幅簡化。 |
| 聚合與材料 | ROMP 與「乙烯轉位聚合」；可降解聚合物、**自我修補材料**（以dynamic covalent chemistry 為基礎的網狀聚合物）；工業上的 **Ziegler–Natta 烯烔聚合的替代路徑**（茂金屬催化劑的複分解聚合）。 |
| 油脂與燃料 | 油脂的烯烔轉化（生物柴油的「烯化」步驟）；單體的交叉複分解。 |
| 藥物 | 不對稱複分解（Schrock–Hoveyda 型催化劑）用於製備手性藥物中間體。 |
| 科學文化 | 肖萬是**法國石油研究院（工業實驗室）**做出諾獎級工作的代表；格拉布的催化劑被化工界稱為「最通用的工業催化劑之一」，並曾被《Time》列入 2001 年最具影響力的發明。 |
