# 1960 · 碳-14 定年法：讓古代遺物自己報年齡

> 1960 諾貝爾化學獎：威拉德·利比（Willard Libby），表彰碳-14 定年法

## 案情提要

1946 年前，考古學對「多老」的判斷只能靠地層、文獻與猜測：圖坦卡門的金面具可以比對埃及年表，但一塊無字頭蓋骨呢？有沒有一種方法，讓**任何含碳的古代遺物**自己說出死亡年代？利比的靈感來自一個宇宙級的線索來源：**宇宙射線不斷在天上生產碳-14**。

## 前因：碳-14 的身世

| 年份 | 事件 |
|---|---|
| 1934 | 庫里在實驗室首見碳-14 蹤跡（被誤判為氮雜質） |
| 1939 | 魯賓與登斯特推論宇宙射線中子會與大氣氮反應生成 ¹⁴C——**利比把這條註腳讀成了主案情** |
| 1940 | 橡樹嶺以中子轟擊製得可稱量的 ¹⁴C |

生成反應：

`¹⁴N + ¹n → ¹⁴C + ¹p`（宇宙射線中子）

¹⁴C 衰變（β⁻，半衰期 5730 年）：

`¹⁴C → ¹⁴N + e⁻ + ν̄`

## 調查：四步推理鏈

1. **假設一：穩態庫存**。宇宙射線流量數千年大致恆定 → 大氣中 ¹⁴C 的生成率 ≈ 衰變率，建立穩態，大氣 CO₂ 的 ¹⁴C/¹²C 比值是**常數**（利比以巴爾的摩污水廠甲烷實測驗證——現代活體碳的比活度 ≈ 15.3 dpm/g C）。
2. **假設二：死亡即停錶**。生物活著時不斷交換碳（光合作用/進食），體內 ¹⁴C 比值 = 大氣值；死亡後交換終止，¹⁴C 只減不增。
3. **數學**：

`t = −(1/λ) ln(N/N₀) = 8033 × ln(N₀/N)` 年

`λ = ln2/5730 yr⁻¹`。量出殘餘放射性（或 ¹⁴C/¹²C 比值），年齡直接算出。
4. **跨文明校準**：取已知年齡的樣本（埃及第一王朝木棺約 4600–5000 年、死海古卷亞麻、龐貝木材）檢驗——理論年齡與史載吻合。1949 年首篇論文公布：**三個紅杉木段與王朝年表一致**。方法成立。

探測的工程挑戰：天然碳中 ¹⁴C 僅約 10⁻¹²——利比以**固體碳計數器**（把樣本轉成純碳黑，堆疊在環繞蓋革管的圓柱壁上）繞過低計數率的死鎖；1949–50s 改用氣體正比計數器與液體閃爍法，並以**反符合屏蔽**壓低宇宙射線背景。

## 理論裁決與限制

- 可測範圍約 300–50,000 年（10 個半衰期後信號淹沒於背景）。
- 穩態假設的兩處修正（後續鑑識補丁）：
  - **Suess 效應**：工業化石燃料（無 ¹⁴C）稀釋大氣。
  - **炸彈峰**：1950s 核試使大氣 ¹⁴C 近倍增（反向利用：可用於測 1960s 後的新生物）。
  - **樹輪校準曲線**（IntCal）：太陽活動變動使大氣 ¹⁴C 濃度漂移，以連續樹輪-珊瑚-洞穴石筍數據校準，已延伸至 55,000 年。
- **加速器質譜（AMS）**（1980s）改「數原子」而非「數衰變」，樣本需求從克級降到毫克級，都靈裹屍布（1988：中世紀織物，1260–1390 AD）、死海古卷、雪人（Ötzi，約 5300 年）皆以 AMS 斷代。

## 後果

| 領域 | 變化 |
|---|---|
| 考古學 | 從「相對年代」進入「絕對年代」；「新石器革命」等宏大敘事得以定年 |
| 地質/氣候 | 冰芯、湖泥、深海沈積物建立時間軸 |
| 法醫 | 象牙、毒品、人體組織（炸彈峰技術）溯源 |
| 科學方法論 | 「用物理時鐘校準人文歷史」的典範；後續：鉀-氬、鈾鉛（地球 45.4 億歲）、光激發光 |
