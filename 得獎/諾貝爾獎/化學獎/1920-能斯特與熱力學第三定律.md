# 1920 · 能斯特與熱力學第三定律

> 1920 諾貝爾化學獎：沃爾特·赫爾曼·能斯特（Walther Hermann Nernst，1864–1941，德國）——表彰「其熱力學之研究，特別是第三定律之建立」。第一、第二定律處理能量與熵的「增量」，第三定律則告訴我們熵的**絕對起點**。

## 懸案（案情提要）

1920 年的物理化學有兩個半個世紀的懸案：

1. **卡諾的幽靈**：卡諾循環給出熱機效率上限，卻要求循環在兩溫間運作；每臺機器都有最低工作溫度，可「絕對零度」會怎樣？熵的絕對值究竟是多少？
2. **量熱的難題**：化學家想用「生成焓」比較物質的穩定性，但生成焓是相對量（只能比較差值），無法跨物質求絕對值。當年 $0$ 點的選擇——是取 $\mathrm{H_2}$、$\mathrm{O_2}$、石墨的焓為零，還是取「最穩定單質」為零？兩套慣例互相打架，化學家算能量帳時總是心虛。
3. **熵的絕對值問題**：玻爾茲曼在 1877 年提出 $S = k\ln W$（ Sackur-Tetrode 型），但 $W$ 只能算相對值——熵的「絕對零點」在 1900 年代仍是空白。

能斯特在 1906–1913 年間，用數百種物質的低溫比熱數據，找出那個空白點的規律，並把它推成**第三定律**——一條宣布「絕對零度不可達、完美晶體在 $0\ \mathrm{K}$ 熵為零」的絕對律。

## 調查

**偵查一：比熱的奇蹟——$C_p$ 在絕對零度歸零。**

能斯特系統測量許多物質在極低溫的莫耳定壓比熱，發現共同行為：

$$C_p \rightarrow 0 \quad \text{as}\quad T \rightarrow 0$$

這與經典 Dulong–Petit 定律 $C_p = 3R$（原子每自由度 $3R$）完全衝突——量子論給出解釋：低溫時激發模式被凍住，只剩基態的自由度貢獻，故比熱按 $T^n$ 趨近零。檢驗式寫成：

$$C_p = a + bT + cT^2 + \cdots \quad (\text{在極低溫只取首項}) \;\Rightarrow\; C_p \approx aT$$

（對理想晶格，低溫極限為 $C_p \propto T^3$。）

**偵查二：積分——把熵的絕對值算出來。**

熵變由比熱積分：

$$S(T) = S(0) + \int_0^T \frac{C_p(T')}{T'}\,dT'$$

能斯特熱定理說明等溫過程的 $\Delta S$ 在 $T\to 0$ 時趨零，等價於給出 $S(0) = 0$ 的錨點（對完美晶體）。於是任何物質的**絕對熵**可由「低溫比熱 ＋ 相變潛熱」全程積分求得：

$$S(T) = \int_0^{T_m}\frac{C_{p,\text{固}}}{T}dT + \frac{\Delta H_{fus}}{T_m} + \int_{T_m}^{T_b}\frac{C_{p,\text{液}}}{T}dT + \frac{\Delta H_{vap}}{T_b} + \int_{T_b}^{T}\frac{C_{p,\text{氣}}}{T}dT$$

注意相變項的形式：$\Delta S_{fus} = \Delta H_{fus}/T_m$——**相變熵就是相變潛熱除以相變溫度**。這條簡潔的關係本身就是能斯特判據的實驗核心。

**偵查三：跨物質的一致性審計。**

能斯特定理的強版本不是「每個物質的 $S$ 趨零」，而是「**任何兩個物質在同一溫度的熵差**在 $T\to 0$ 時趨零」。檢驗方法極為漂亮：以已知 $\Delta S_{m}$（由半導體低溫比熱測得）為基準，比較各物質的 $\Delta H_f$ 與 $\Delta S_f$：

$$\Delta S_f \approx \frac{\Delta H_f - \Delta H_{f,\text{元素}}}{T}$$

能斯特發現：不同化合物在同一元素組合下的 $\Delta S_f$ 趨近同一數值（例如「氧的熵約為 $13.4\ \mathrm{J/(mol\cdot K)}$」這類加和規則）——這就是**鍵熵加和性**，化學家從此能估算未知物質的熵。

**偵查四：能斯特方程式——把不可測的量變成可測的量。**

1887 年的能斯特方程式是本案的實用側翼：

$$E = E^\circ - \frac{RT}{nF}\ln Q \;\xrightarrow{\;25\,^\circ\mathrm{C}\;}\; E = E^\circ - \frac{0.05916}{n}\log Q$$

它把電池電動勢（可量測）與離子濃度（可配製）直接相連，使標準還原電位 $E^\circ$ 成為化學的通用尺規——也讓生物學的膜電位、藥物的代謝穩定性可用同一把尺量度。1920 年後，它甚至成為今日化學電池理論與生理學離子分佈的共同語言。

## 理論裁決

**判決一：第三定律的四種等價表述。** 1920 年代能斯特、玻爾茲曼、普朗克與愛因斯坦共同把它打磨成互等價的系統：

1. **能斯特熱定理**：$\lim_{T\to 0}\Delta S = 0$（任何等溫過程）；
2. **普朗克形式**：完美晶體在 $T = 0$ 時 $S = 0$；
3. **不可達陳述**：不可能在有限步驟內把系統冷卻到絕對零度（否則可由單一溫度循環製造熱機，違反卡諾定理）；
4. **零點表述**：$C_p$、$C_V$、$S$、$U$、$H$、$A$（Helmholtz 自由能）等所有熱力學函數在 $T=0$ 皆趨於零或極限值。

**判決二：不可達原理的推導（第三定律的物理核心）。** 假設存在某程序可在有限步驟把物體冷卻至 $0\ \mathrm{K}$，且過程為等溫可逆——那就可以在此溫度與另一溫度間建立卡諾循環，取得 $100\%$ 效率的熱機，導致第二定律被推翻。故第三定律同時是**物理學的邊界宣告**：

$$T \to 0 \ \text{不可達（有限步驟）}, \qquad \text{但}\ \lim_{T\to 0} S = 0 \ \text{可外推}$$

**判決三：殘餘熵——第三定律的實測反例。** 玻璃態物質把隨機排列「凍」在固體裡，低溫下仍有排列熵，$S(0) > 0$，違反第三定律的嚴格形式。這不是第三定律錯了，而是它預設「完美晶體」——**有序是前提，混亂是例外**。玻爾茲曼的 $S = k\ln W$ 在此給出定量解釋：$W$ 若在 $0\ \mathrm{K}$ 仍有多重基態，熵就不為零。

**判決四：化學熱力學的可用性。** 第三定律讓化學家可以列出標準摩耳熵表：

$$\Delta_r S^\circ = \sum_{\text{產物}} \nu_i S_i^\circ - \sum_{\text{反應物}} \nu_i S_i^\circ$$

配合 $\Delta_r G^\circ = \Delta_r H^\circ - T\Delta_r S^\circ$，任何反應的平衡常數 $K$ 可由標準表數據直接算出（見 [1901-凡特荷夫與物理化學](1901-凡特荷夫與物理化學.md)）。**化學從此有了完整的「熱力學資料庫」**，這是哈伯氨合成（見 [1918-哈伯與合成氨](1918-哈伯與合成氨.md)）、奧斯特華德硝酸製程（見 [1909-奧斯特瓦德與催化](1909-奧斯特瓦德與催化.md)）能夠「算著辦」的底層原因。

## 後果

| 領域 | 影響 |
| --- | --- |
| 低溫物理 | 第三定律提供絕對零點的定義，開啟低溫物理的定量時代；昂內斯液化氦、超導的溫標獲得嚴格基礎（見 [../物理學獎/1913-昂內斯與超導](../物理學獎/1913-昂內斯與超導.md)）。 |
| 化學工業 | 標準生成焓與標準熵表成為化工設計的基礎資料；反應器的溫度、壓力選擇有了理論依據。 |
| 統計力學 | 玻爾茲曼、普朗克、愛因斯坦的統計解釋與經驗定律匯流；「熵＝態的數目」成為現代物理的基本語彙。 |
| 固態物理 | 殘餘熵現象引出玻璃的結構研究與低溫比熱測量（自旋玻璃、重整子的磁性基態）。 |
| 生物化學 | 蛋白質的構象變化以 $\Delta G = \Delta H - T\Delta S$ 分解時，熵項的絕對值來自第三定律的數據體系（見 [1972-安芬森與核糖核酸酶](1972-安芬森與核糖核酸酶.md)）。 |
| 科學史地位 | 能斯特是萊比錫學派（奧斯特瓦德—范特荷夫—阿瑞尼斯）的最後一位諾獎得主，替這個學派畫上句號。 |
