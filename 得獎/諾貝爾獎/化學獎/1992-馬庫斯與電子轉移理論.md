# 1992 · 馬庫斯與電子轉移理論——為什麼越有利的反應反而越慢

> 1992 諾貝爾化學獎：魯道夫·阿瑟·馬庫斯（Rudolph Arthur Marcus，1923–2026，加拿大／美國）——表彰「其對化學體系中電子轉移反應理論的貢獻」。他解釋了一個違反直覺的現象：**當電子轉移變得更有利（釋放更多能量）時，反應反而變慢。**

## 懸案（案情提要）

陶布（見 [1983-陶布與電子轉移](1983-陶布與電子轉移.md)）在 1960 年代累積了大量「外層電子轉移」的速率數據，並得到幾條經驗規則：

- 反應的**自由能變化** $\Delta G^\circ$ 越負（反應越有利），速率**起初增加**；
- 但當 $\Delta G^\circ$ 變得非常負時，速率**反而開始下降**——呈現一個**倒 U 形曲線**，峰值出現在 $\Delta G^\circ$ 與「重組能」$\lambda$ 相當之處；
- 這個「反轉區」（inverted region）**違反直覺**：更自發的反應應該更快才對呀？

**懸案的意義極為實際**：太陽能電池、燃料電池、酵素電子傳遞、光合作用——**所有以電子轉移為核心的技術**，其效率都取決於電子轉移速率；而「反轉區」意味著**把驅動力推得太大，反而會損失效率**（功率密度下降）。若不理解它，設計就會南轅北轍。

偵辦人：魯道夫·馬庫斯。他把這些經驗規則升格為一個**完整的理論**。

## 調查

**偵查一：核心概念——「重組能」。**

外層電子轉移過程中，**反應物與產物各有自己的平衡構形**。在電子轉移之前，溶劑與配位球必須「重組」到產物的構形：

$$\lambda = \underbrace{\lambda_{\text{in}}}_{\text{分子內部重組}} + \underbrace{\lambda_{\text{out}}}_{\text{溶劑（外層）重組}}$$

**重組能 $\lambda$ 是價值的函數**：

$$\lambda = \left[\frac{1}{2}\left(\frac{1}{\varepsilon_{\text{op}}}-\frac{1}{\varepsilon_{\text{s}}}\right)\right]\left(\frac{1}{a} - \frac{1}{b}\right)\left(\frac{e^2}{4\pi}\right)\left(\frac{1}{2}\left(\frac{1}{r_D}+\frac{1}{r_A}-\frac{1}{R}\right)\right)$$

其中 $a$、$b$ 是反應物與產物的有效半徑，$r_D$、$r_A$ 是電子供體與受體的半徑，$R$ 是兩者間距，$\varepsilon_{\text{op}}$ 與 $\varepsilon_{\text{s}}$ 是操作（高頻）與靜態介電常數。

**物理意義**：溶劑的極化需要「跟著」電荷移動而重新排列——這要花能量。**外層電子轉移的能垒，主要來自溶劑必須「跟上」這個負擔。**

**偵查二：馬庫斯方程式——拋物線的出現。**

$$\boxed{\;\Delta G^\ddagger = \frac{\lambda}{4}\left(1 + \frac{\Delta G^\circ}{\lambda}\right)^2\;}$$

**推導的骨架**（ Marcus–Hush 交叉關係的拋物線形式）：

$$\text{過渡態}：\ \text{電子在兩側「等量」重疊} \Rightarrow \text{能垒} = \frac{(\lambda + \Delta G^\circ)^2}{4\lambda}$$

**其物理圖景**：把兩個拋物線（反應物與產物的吉布斯自由能隨反應坐標變化）疊在一起：

$$\text{反應物拋物線頂點} \xrightarrow{\Delta G^\circ} \text{產物拋物線頂點};\qquad \text{交點即過渡態}$$

$$\text{兩拋物線的偏移量} = \Delta G^\circ \qquad\text{兩拋物線的「寬度」相同（由 } \lambda \text{ 決定）}$$

**能量圖的繪製（Marcus 圖）**：

| $\Delta G^\circ$ 範圍 | $\Delta G^\ddagger$ 行為 | 速率 |
| --- | --- | --- |
| 接近 0 | 下降 | **正常區（Marcus 正常區）** |
| $\Delta G^\circ = -\lambda$ | 最小 | **速率極大點** |
| $\Delta G^\circ < -\lambda$ | 上升 | **反轉區（inverted region）** |

**「反轉區」是物理學的必然**：當產物谷比反應物谷低太多時，兩條拋物線的交點「跑到谷外」，過渡態反而更高——**這是幾何，不是化學。**

**偵查三：內層機制的對照。**

馬庫斯也把框架推廣到**內層**（有化學鍵橋）電子轉移，此時能垒由「化學步驟」主導：

$$\Delta G^\ddagger_{\text{inner}} \ \text{由中間體的穩定性决定，而非拋物線幾何}$$

**這解釋了為什麼內層反應的速率與 $\Delta G^\circ$ 的關係是單調的（沒有反轉區）。**

**偵查四：Marcus 交叉關係——可檢驗的預言。**

$$\frac{k_{12}}{k_{21}} = \exp\left(-\frac{\Delta G^\circ_{12}}{RT}\right) \quad\text{（能斯特等價式）}$$

$$\text{更強的形式：}\quad k_{12} = A\left(\frac{k_{21}}{A}\right)^{1/2}\exp\left[-\frac{\Delta G^\circ_{12}}{2RT} + \frac{\lambda}{4RT}\right]$$

**這使得「跨系列的速率常數」可以被預測**——例如已知 $\mathrm{Fe^{2+}/Fe^{3+}}$ 的數據，可用來預測 $\mathrm{Co^{2+}/Co^{3+}}$ 的速率（只要 $\lambda$ 已知）。**這是物理化學罕見的定量預言能力。**

**偵查五：生物與技術的驗證。**

$$\text{生物體中的電子傳遞鏈} \xrightarrow{\text{蛋白質調整 } \lambda \text{ 與 } R} \text{優化速率}$$

**演化把蛋白質當作「電子傳遞的設計工具」**：調整兩個金屬中心的距離 $R$、改變配位環境以改變 $\lambda_{\text{in}}$，以使速率最優——**這正是 Marcus 理論在生物學中的直接應用**。

    A[陶布的經驗規則: 速率對 ΔG° 呈倒U形<br>反轉區違反直覺] --> B[馬庫斯: 拋物線幾何<br>重組能 lambda]

## 理論裁決

**判決一：電子轉移能垒的完整表達。**

$$\boxed{\;\Delta G^\ddagger = \frac{\lambda}{4}\left(1 + \frac{\Delta G^\circ}{\lambda}\right)^2\;}$$

$$\text{其中} \quad \lambda = \lambda_{\text{in}} + \lambda_{\text{out}}$$

**這條公式把「化學驅動力」與「結構重組」兩個獨立的物理量，組合成可計算的能垒**——它是 20 後半電子轉移理論的核心，並在 2020 年代的「分子電子學」與「人工光合作用」中仍是設計公式。

**判決二：反轉區的存在——「越有利的反應越慢」的幾何解釋。**

$$\Delta G^\ddagger\ \text{在}\ \Delta G^\circ = -\lambda \ \text{時最小};\qquad \Delta G^\circ < -\lambda \ \text{時能垒反升}$$

**這是「結構決定動力學」最戲劇性的例子**：反應物與產物的自由能面形狀（拋物線）不變，只是彼此滑動——滑得太遠，交點就跑到「幾乎不可能通過」的區域。

**判決三：Marcus 交叉關係——物理化學的定量預言力。**

$$\text{已知三組數據} \Rightarrow \text{可預測第四組}$$

$$\frac{k_{12}}{k_{21}} = e^{-\Delta G^\circ_{12}/RT}$$

**這使得電子轉移研究從「測量」進入「預測」的階段**——是物理化學少數能跨體系外推的領域。

**判決四：生物體的「分子設計」觀。** Marcus 理論揭示：

$$\text{蛋白質的作用} = \text{調整 } \lambda \text{ 與 } R \text{，把反應「擺」在速率最大點}$$

**「生物體用蛋白質當作電子傳遞的電阻調節器」——這是演化把化學物理原理用來設計功能的漂亮例子**，並與費歇爾的鎖鑰（見 [1902-費歇爾與醣類偵探學](1902-費歇爾與醣類偵探學.md)）、巴頓的構象（見 [1969-巴頓與構象分析](1969-巴頓與構象分析.md)）並列為「結構決定功能」的經典證據。
