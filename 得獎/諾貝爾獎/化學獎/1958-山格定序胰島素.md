# 1958 · 山格定序胰島素：為蛋白質讀出字母表

> 1958 諾貝爾化學獎：弗雷德里克·山格（Frederick Sanger），表彰蛋白質結構（尤其胰島素）之研究；1980 年再獲化學獎（DNA 定序，見 [1980-DNA定序](1980-DNA定序.md)）——史上唯一兩度獲同一科學門諾獎者

## 案情提要

1940 年代的共識：蛋白質是一團「膠體」，未必有固定組成、更未必有確定的結構。胰島素（1921 年發現，1923 生理醫學獎，見 [1923-胰島素](../生理醫學獎/1923-胰島素.md)）是小分子蛋白質——51 個胺基酸——卻沒有人知道**它的氨基酸是以什麼順序排的**。如果蛋白質有確定的序列，它就是「分子」，如果沒有，就只是「統計混合物」。這是本世紀化學與生物學的分水嶺問題。

## 前因

| 年份 | 事件 |
|---|---|
| 1902 | 費歇爾提出肽鍵假說：蛋白質由胺基酸以酰胺鍵相連（1902 得主） |
| 1926 | 薩姆納結晶出尿素酶（1946 諾獎）——蛋白質至少可以「像鹽一樣純」 |
| 1945 | 山格加入劍橋，接手一個「小而尖銳」的問題：胰島素的序列 |

## 調查：DNP 標記——讓 N 端自己亮起來

山格的發明是一個「偵探染料」：1-氟-2,4-二硝基苯（FDNB，Sanger 試劑）。它專門與肽鏈游離的 N 端胺基反應，且反應產物**耐酸水解**——把蛋白質水解成胺基酸碎片後，N 端那顆胺基酸會帶著黃色的 DNP 標籤被認出來：

`DNP-FDNB + H₂N–肽 → DNP–AA–肽…（黃色）→ 水解 → DNP–氨基酸`

鑑識流程：

1. **測 N 端**：胰島素給出 Gly 與 Phe 各一——**兩條肽鏈**（A、B 鏈）。
2. **部分水解**：把鏈切成 2–5 聚體碎片，逐一測每片的首尾。
3. **拼圖**：用「重疊法」（overlapping peptides）——同一段序列被多種切割方式覆蓋，碎片間的重疊區決定全局順序（與 1953 年 DNA 定序讀取的重疊邏輯同源）。
4. **二硫鍵定位**：氧化切斷 S–S 橋，分別定序 A、B 鏈。

1955 年結案：胰島素 = A 鏈（21 個殘基）+ B 鏈（30 個殘基），由兩對雙硫鍵相連。**人類第一次讀出一個蛋白質的完整字母表。**

## 理論裁決

- **序列決定結構**：既然序列精確無誤，蛋白質就是分子而非膠體。1950s–60s 安芬森的核糖核酸酶復性實驗（1972 諾獎）進一步證明：**一級序列本身含有摺疊成三級結構的全部資訊**——今日 AlphaFold（[2024-AlphaFold與蛋白質設計](2024-AlphaFold與蛋白質設計.md)）預測的正是「序列 → 結構」這條 1958 年奠基的因果鏈。
- 「序列 → 功能」：胰島素的活性賴於精確序列，突變即致病——分子病學（鐮刀型貧血由一個氨基酸替換造成，1957 英格拉姆）由此開張。
- **中心法則的化學預言**：1958 年克里克提出「序列假說」——核酸的序列決定蛋白質的序列。山格 1955 年讀出蛋白質序列，山格 1977 年讀出 DNA 序列，首尾呼應。

## 後果

- 蛋白質定序儀（Edman 降解 1950s 併行發展，自動化）→ 酵素學、免疫學全面獲得「分子地址」。
- 1980 年山格二度獲獎，自嘲自己是「一生只會做一件事的人」；拒絕封爵（自稱「Academician」的共產主義者），諾獎獎金全數投入研究所。
- 山格研究所（Wellcome Sanger Institute）今日是人類基因組計畫的最大貢獻機構之一。
