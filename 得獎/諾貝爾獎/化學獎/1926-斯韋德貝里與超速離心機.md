# 1926 · 斯韋德貝里與超速離心機

> 1926 諾貝爾化學獎：西奧多·斯韋德貝里（Theodor Svedberg，1884–1971，瑞典）——表彰「其以超速離心機對膠體與蛋白質之研究」。人類第一次量到了蛋白質的分子量。

## 懸案（案情提要）

1920 年代有兩樁案子在物理化學的卷宗上同時懸著：

1. **膠體的沉降案**：有些溶膠能懸浮數年不沉——它們為什麼不會像粗分散液那樣沉降？靠什麼維持？此前的解釋（分子自身的布朗運動？）從未被直接目擊過。
2. **蛋白質的「分子量」案**：蛋白質是「巨大的膠體粒子」還是真的巨分子？它們的分子量是多少？它們是**單一**物種還是混合物？在此之前，沒有任何方法能回答——蛋白質無法結晶到足以測量的程度，滲透壓法在這樣的稀溶液裡信號太小。

斯韋德貝里的解法是一臺機器：**超速離心機**（ultracentrifuge），把重力場從 $1\ g$ 推到數十萬 $g$，讓那些「永遠不會沉降」的粒子，在一小時內被迫交代自己的下落。

## 調查

**偵查一：把沉降變成可量測的一維問題。**

在離心場中，粒子的沉降速度為：

$$\frac{dr}{dt} = s\,\omega^2 r, \qquad s = \frac{M(1-\bar{v}\rho)}{N_A f}$$

其中 $s$ 為**沉降常數**、$M$ 為分子量、$\bar{v}$ 為偏容積、$\rho$ 為溶劑密度、$f$ 為摩擦係數、$\omega$ 為角速度。實驗上，由界面的移動速率直接求出 $s$。

**偵查二：沉降—擴散聯立——斯韋德貝里方程式。**

單靠 $s$ 無法解出 $M$（因為摩擦係數 $f$ 未知）；但若同時量到**擴散常數** $D$（由界面的模糊化程度求得），兩式相除，$f$ 被消去：

$$\boxed{\;\frac{s}{D} = \frac{M(1-\bar{v}\rho)}{RT}\;}$$

這就是**斯韋德貝里方程式**：只要量得沉降與擴散，就能直接算出分子量，不需要知道粒子的形狀與大小。這是本案的核心發明——**它把「蛋白質有多大」變成兩個可量測的擴散與沉降參數的組合**。

**偵查三：沉降平衡——分布本身就是尺規。**

更精妙的是「沉降平衡」實驗：讓離心機长时间運轉，直到擴散與沉降達到平衡，濃度隨半徑的分布服從玻爾茲曼型指數律：

$$c(r) = c_0 \exp\!\left[-\frac{M(1-\bar{v}\rho)\,\omega^2 r^2}{2RT}\right]$$

取對數：

$$\ln c(r) = \ln c_0 - \frac{M(1-\bar{v}\rho)\,\omega^2 r^2}{2RT}$$

**直線的斜率直接給出分子量**——這是一把不需要標定、不需要外推的「分子量尺」。蛋白質溶液在平衡時呈現漂亮的鐘形濃度分布，照片至今仍是最具說服力的教科書插圖。

**偵查四：單一性審計——蛋白質是混合物嗎？**

1926–27 年斯韋德貝里與科恩對血紅蛋白做的實驗，是全案的最高潮：若蛋白質是許多不同分子的混合物，在沉降平衡下濃度分布將是多個分布的疊加；實測卻是**單一條曲線**，且在整個分布中分子量恆定。

$$\text{結論：血紅蛋白是單一、均一、確切的巨分子，} M \approx 67\,000 \ (\text{當年測值})$$

（1930 年代佩魯茨與肯德魯的結構研究後，才知道血紅蛋白其實由 4 個次單元組成——見 [1962-佩魯茨與血紅蛋白](1962-佩魯茨與血紅蛋白.md)——但「分子量確定」這個大結論不變。）

**偵查五：膠體沉降的物理結論。**

超速離心機同時也讓「膠體為何懸浮」有了機制說明：在數十萬 $g$ 的場中，溶膠粒子會緩慢沉降，但沉降速度 $\propto r^2$，而布朗擴散 $\propto 1/r$；在特定粒徑以下，擴散足以抵銷沉降——這正是溶膠長久懸浮的定量理由，也是席格蒙迪（見 [1925-席格蒙迪與膠體化學](1925-席格蒙迪與膠體化學.md)）膠體疆域的收官。

## 理論裁決

**判決一：沉降—擴散聯立方程。** 對球形粒子 $f = 6\pi\eta r$，代入後可同時解出分子量與半徑：

$$r = \frac{s f}{M(1-\bar{v}\rho)} \quad\text{與}\quad D = \frac{k_B T}{6\pi\eta r} \;\Longrightarrow\; M \text{ 與 } r \text{ 皆可得}$$

**判決二：沉降平衡的統計力學基礎。** 沉降平衡分布正是重力場中的玻爾茲曼分布；把「對流、擴散、沉降」的競爭寫成連續方程，即可預測實驗中觀察到的界面向外擴散與峰值銳化：

$$\frac{\partial c}{\partial t} = D\frac{1}{r^2}\frac{\partial}{\partial r}\!\left(r^2\frac{\partial c}{\partial r}\right) - s\omega^2 \frac{\partial (rc)}{\partial r}$$

**判決三：巨分子的「分子量」終於是物理量。** 在此之前，「蛋白質的分子量」只是外推的猜測；此後它是沉降與擴散兩條獨立量測的產物。分子生物學的第一個數字——蛋白質有多大——由此取得。

**判決四：巨分子世界的邊界畫定。** 超速離心機加上海爾和（1924）、拉姆齊（1926–27）、克尼（1920s）的方法，把「分子」與「膠體」的分界線徹底拆掉：所謂膠體，只是**特別大的分子**；所謂溶液，只要夠稀，宏觀行為就與真溶液無異。

## 後果

| 領域 | 影響 |
| --- | --- |
| 蛋白質化學 | 分子量均一性確立；「單一分子物種」的觀念成為蛋白質純化的標準判準；同時揭開血紅蛋白的次單元結構之謎。 |
| 分子生物學 | 沉降分析（今日的 sedimentation-velocity analytical ultracentrifugation, SV-AUC）至今仍是測量蛋白質與核糖體等大分子複合體質量、組裝狀態的標準方法。 |
| 高分子化學 | 分子量分佈（多分散性）的測定能力，使施陶丁格（見 [1953-施陶丁格與高分子](1953-施陶丁格與高分子.md)）得以用滲透壓與超速離心交叉驗證「巨分子」假說。 |
| 醫學 | 血紅蛋白的分子量與形狀數據，使鐮刀型貧血的分子病理學（單一胺基酸置換）得以在化學層面被理解（見 [1956-鏈反應與爆炸](1956-鏈反應與爆炸.md) 與 [1959-海羅夫斯基與極譜](1959-海羅夫斯基與極譜.md) 的姊妹案：生化遺傳學的起步）。 |
| 核酸 | 核酸作為高分子被認定（後由 1946 年諾思羅普與斯坦利於病毒中證得蛋白質性、1953 年 DNA 結構釐清遺傳物質的地位）——超速離心是這條線的技術前提。 |
| 儀器工業 | 超速離心機成為二十世紀生物與化工實驗室的標準設備；斯韋德貝里因此獲諾貝爾獎，烏普薩拉成為蛋白質研究的全球重鎮（蒂塞利烏斯 1948 年獎即出自同一學派）。 |
