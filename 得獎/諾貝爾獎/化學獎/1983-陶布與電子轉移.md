# 1983 · 陶布與電子轉移——金屬之間怎麼傳電子

> 1983 諾貝爾化學獎：亨利·陶布（Henry Taube，1915–2005，加拿大／美國）——表彰「其對電子轉移反應機構之研究，特別是對金屬錯合物的研究」。他解開了一個化學裡最神秘、最快的過程：**電子是怎麼從一個金屬跳到另一個金屬的？**

## 懸案（案情提要）

1960 年代的化學裡，有一個所有人都見過、卻沒有人解釋的現象：

- **電子轉移（electron transfer）是化學中最基本、也最快的反應**：當 $\mathrm{Fe^{2+}}$ 與 $\mathrm{Fe^{3+}}$ 混合，顏色立刻改變——電子「瞬間」從 $\mathrm{Fe^{2+}}$ 跳到 $\mathrm{Fe^{3+}}$，速率接近擴散極限（$10^{9}$–$10^{10}\ \mathrm{M^{-1}s^{-1}}$）；
- 但「瞬間」只是測量上的說法：**它真的需要時間嗎？電子是像光子一樣「飛越」過去，還是透過化學鍵「接力」傳遞？**
- 更關鍵的問題：**同樣是金屬離子，為什麼電子的傳遞速率會差十個數量級？**例如 $\mathrm{Co(NH_3)_6^{2+}/^{3+}}$ 的電子轉移慢得可憐（$10^{-6}$–$10^{-3}$），而 $\mathrm{Fe(H_2O)_6^{2+}/^{3+}}$ 幾乎是瞬間的；
- 商業上的後果極為實際：**電池、燃料電池、光伏、Corrosion（腐蝕）、酵素的電子傳遞鏈**（見 [1978-米切爾與化學滲透](1978-米切爾與化學滲透.md)）——全都依賴這條機制。

偵辦人：亨利·陶布。他用**同位素標記**（把某一個金屬原子標記，觀察電子是「留在原地」還是「跑到別處」）與**配位化學的系統操弄**，把電子傳遞分成兩種機制，並證明：**外層電子轉移可以快到幾乎是「隧穿」，而內層電子轉移慢得像是需要「化學步驟」來完成。**

## 調查

**偵查一：同位素示蹤——電子「是誰的」。**

陶布的基本實驗設計：把反應物之一用**放射性同位素標記**，觀察反應後標記的去向：

$$\text{例如：} \quad {}^{59}\mathrm{Fe}^{2+} + \mathrm{Fe}^{3+} \rightarrow \mathrm{Fe}^{2+} + {}^{59}\mathrm{Fe}^{3+}$$

**若電子的轉移與配位球的置換有關，則標記會「混雜」；若電子的轉移「留在原地」，標記的分佈會顯示電子是在兩個金屬間「直接跳躍」。**

**結果**：對 $\mathrm{Fe(H_2O)_6^{2+}/^{3+}}$ 這類「外層」錯合物，標記的分佈顯示電子是直接跳躍的；而對 $\mathrm{Co(NH_3)_6^{2+}/^{3+}$ 等，電子轉移**必須伴隨配位球的置換**——**兩種機制就此被區分開來。**

**偵查二：外層電子轉移——「幾乎是隧穿」。**

外層機制的特徵：**氧化還原中心不共享配體，電子直接跨越配位圈之間的空隙。**其速率由兩條自由能曲線的「重疊」決定：

$$\Delta G^\ddagger = \frac{\lambda}{4}\left(1 + \frac{\Delta G^\circ}{\lambda}\right)^2 \quad (\text{Marcus 公式，1992 年，見 [1992-馬庫斯與電子轉移理論](1992-馬庫斯與電子轉移理論.md)})$$

其中 $\lambda$ 為**重組能**（reorganization energy，即配位球重排所需的能量）。這解釋了著名的**「馬庫斯反轉區」**：

$$\text{當 } -\Delta G^\circ = \lambda \text{ 時，} \quad \Delta G^\ddagger = 0 \ \text{（速率達極大）}$$

**當反應變得更「有利」（$\Delta G^\circ$ 更負）時，反應反而變慢**——這違反直覺，卻是電子轉移最著名的反常現象。

**偵查三：內層電子轉移——電子要走「化學的路」。**

陶布提出的內層機制：**氧化還原中心先經由配體形成橋（例如 $\mathrm{Cl^-}$ 或 $\mathrm{OH^-}$），電子再沿橋傳遞**：

$$\begin{aligned}
\text{① 前置配位（置換）：} &\quad \mathrm{Co(NH_3)_5Cl^{2+}} + \mathrm{Cr^{2+}} \to \mathrm{Co(NH_3)_5Cl{-}Cr^{2+}} \\
\text{② 電子傳遞（經橋）：} &\quad \mathrm{Co(NH_3)_5Cl{-}Cr^{2+}} \to \mathrm{Co(NH_3)_5Cl^{2+}} + \mathrm{Cr^{3+}} \\
\text{③ 橋的釋出：} &\quad \mathrm{Co(NH_3)_5Cl^{2+}} \to \mathrm{Co(NH_3)_5(H_2O)^{2+}} + \mathrm{Cl^-}
\end{aligned}$$

**電子傳遞後，金屬的配位數與配體發生了變化**——這就是「內層」與「外層」的判別特徵：

$$\text{內層：}\ \Delta(\text{配位圈}) \neq 0 \qquad \text{外層：}\ \Delta(\text{配位圈}) = 0$$

**陶布用這套機制解釋了 $\mathrm{Co(NH_3)_6}$ 系列反應的緩慢**，並預言：**只要引入能形成橋的配體，反應速率會大幅提升**——這個預言被實驗證實。

**偵查四：配位球重組的能垒——「慢」的來源。**

$$\text{外層電子轉移的 } \Delta G^\ddagger \text{ 中包含配位球重組能 } \lambda$$

對 $\mathrm{Co(NH_3)_6}$ 而言，$\mathrm{Co(III)}$ 的 $\mathrm{d^6}$ 低自旋八面體與 $\mathrm{Co(II)}$ 的 $\mathrm{d^7}$ 高自旋八面體**鍵長差異極大**（約 $0.2$ Å），因此重組能 $\lambda$ 很大，速率極慢；而 $\mathrm{Fe(H_2O)_6}$ 的 $\mathrm{Fe(II)}$／$\mathrm{Fe(III)}$ 鍵長幾乎相同，$\lambda$ 小，速率快。

$$\boxed{\text{電子轉移速率} \approx e^{-\lambda/4RT}\ \text{——鍵長變化越大，電子越難跳}}$$

**這把「配位化學的結構」與「電子轉移的動力學」連結成同一套語言。**

**偵查五：應用的延伸——生物體中的電子傳遞鏈。**

陶布的內層／外層區分，直接對應到生物體中的電子傳遞：

$$\text{呼吸鏈：} \quad \text{血基質（內層）} \to \text{鐵硫簇（外層/內層）} \to \text{銅蛋白（配體橋）}$$

**而他的學生與合作者（包括化學家 **John F. Endicott** 與後來的研究者）把這套觀念帶進了酵素電子轉移的機制研究。**

## 理論裁決

**判決一：兩種電子轉移機制的分類。**

| | 外層（outer-sphere） | 內層（inner-sphere） |
| --- | --- | --- |
| 電子路徑 | 直接跨越配位圈間隙 | 經由橋配體的化學鍵 |
| 配位圈變化 | 無 | 有（配體的得失或轉移） |
| 幾何重組 | 大 | 小（只需局部變化） |
| 典型例子 | $\mathrm{Fe(H_2O)_6^{2+/3+}}$ | $\mathrm{Co(NH_3)_5Cl^{2+}}$ + $\mathrm{Cr^{2+}}$ |
| 速率 | 極快（接近擴散極限） | 慢（需化學步驟） |

**這套分類是 20 後半氧化還原化學的基本詞彙**，並被沿用到今日的**光合作用電子傳遞鏈**、**酵素催化**與**太陽能電池的染料敏化**。

**判決二：重組能與速率的關係。** 外層電子轉移的能垒可寫成（Marcus 形式，1992 年正式化）：

$$\Delta G^\ddagger = \frac{\lambda}{4}\left(1+\frac{\Delta G^\circ}{\lambda}\right)^2$$

**其物理內容**：反應物與產物各有自己的「平衡構形」，電子轉移需要兩者「重疊」，因此必須付出**重組能** $\lambda$ 的代價；而反應驅動力 $\Delta G^\circ$ 與之競爭。

**判決三：配位球的結構決定速率。** 陶布的核心洞見：

$$\text{電子轉移速率} \text{ 由「氧化態與還原態的結構差異」決定}$$

$$\mathrm{Co^{III}(NH_3)_6}\ (d^6,\ \text{低自旋})\ \text{vs}\ \mathrm{Co^{II}(NH_3)_6}\ (d^7,\ \text{高自旋}):\quad \Delta r \approx 0.2\ \text{Å} \Rightarrow \lambda \text{ 大} \Rightarrow \text{慢}$$

$$\mathrm{Fe^{III}(H_2O)_6}\ \text{vs}\ \mathrm{Fe^{II}(H_2O)_6}:\quad \Delta r \approx 0.01\ \text{Å} \Rightarrow \lambda \text{ 小} \Rightarrow \text{快}$$

**「結構—速率」的對應，是把無機化學與物理化學焊接起來的一環。**

**判決四：內層機制的驗證性預言。** 陶布的機制不只是事後解釋，而是**可檢驗的預言**：

$$\text{預言 1：}\ \text{橋配體（如 } \mathrm{Cl^-}\text{）應能催化內層反應} \xrightarrow{}\ \text{實測成立}$$

$$\text{預言 2：}\ \text{若反應後配位圈出現變化（配體被「拉走」），則為內層機制}$$

$$\text{預言 3：}\ \text{可透過設計配體來「設計」電子轉移速率}$$

**這第三條預言直接催生了 1980–90 年代的「分子電子裝置」設計**（分子导线、分子開關），以及今日的**人工光合作用**與**單分子電子學**。

## 後果

| 領域 | 影響 |
| --- | --- |
| 無機化學 | 氧化還原化學的分類與機制語言；過渡金屬的電子傳遞、磁性與結構的關係（$\mathrm{Co}$、$\mathrm{Fe}$、$\mathrm{Ru}$、$\mathrm{Os}$ 系列的配位化學）。 |
| 生物化學 | 呼吸鏈與光合作用鏈的電子傳遞機制；酵素電子轉移（細胞色素 $c$、鐵硫蛋白、銅蛋白）。 |
| 能源 | 燃料電池與太陽能電池（染料敏化）的電子轉移動力學，是陶布理論的工業延伸。 |
| 理論 | Marcus 公式（1992 年諾貝爾獎，見 [1992-馬庫斯與電子轉移理論](1992-馬庫斯與電子轉移理論.md)）把陶布的經驗規律提升為理論；陶布本人因此被視為「電子轉移研究的奠基者」。 |
| 科學傳記 | 陶布是加拿大出生者中第二位化學獎得主（第一位是 1949 年的吉奧克，見 [1949-吉奧克與超低溫](1949-吉奧克與超低溫.md)）；他以「寧可孤獨地做對的事」的風格著稱，並長期擔任《化學會會志》主編。 |
