# 諾貝爾化學獎 歷史年表（詳細版）

> 詳細的「推理探案式」wiki 請見本目錄下以年份開頭的各篇檔案。

## 序幕（1895–1900）

| 年份 | 事件 |
|---|---|
| 1895-11-27 | 諾貝爾遺囑設立化學獎，由瑞典皇家科學院頒發 |
| 1901-12-10 | 第一屆化學獎頒給凡特荷夫 |

## 1901–1920：物理化學革命與元素偵探

| 年份 | 得主 | 事件／貢獻 |
|---|---|---|
| 1886 | — | 凡特荷夫提出滲透壓與化學動力學理論；阿瑞尼士提出電離學說（當時被嘲笑） |
| 1887 | — | 奧士華創辦《物理化學期刊》，物理化學成為學科 |
| 1894–98 | — | 雷姆賽發現氦、氖、氬、氪、氙（鈍氣家族） |
| 1898 | — | 居禮夫婦發現釙與鐳 |
| 1901 | 凡特荷夫 | 化學動力學與滲透壓（首屆化學獎） |
| 1902 | 費歇爾 | 醣類與嘌呤結構（「化學界歌德」） |
| 1903 | 阿瑞尼士 | 電離學說（十年前的「異端」平反） |
| 1904 | 雷姆賽 | 鈍氣之發現 |
| 1905 | 拜耳 | 染料化學（靛藍合成） |
| 1906 | 莫瓦桑 | 氟之單離（為此殉職的元素） |
| 1907 | 布赫納 | 無細胞發酵（酵素化學的誕生） |
| 1908 | 盧瑟福 | 元素蛻變理論（物理學家獲化學獎，幽默自嘲「瞬間從物理學家變成化學家」） |
| 1909 | 奧士華 | 催化作用與平衡原理 |
| 1910 | 瓦拉赫 | 萜烯化學 |
| 1911 | 居禮夫人 | 鐳與釙之發現及鐳的分離（唯一兩科學門雙得主） |
| 1912 | 格林尼亞（格氏試劑）、薩巴梯（催化氫化） | 有機合成的工具箱 |
| 1913 | 維爾納 | 錯合物化學（配位理論） |
| 1914 | 理查茲 | 精密原子量測定 |
| 1915 | 威爾斯泰特 | 葉綠素 |
| 1916–17 | 從缺 | 一戰（哈伯的毒氣爭議：1918 獲獎時毀譽參半） |
| 1918 | 哈伯 | 氨之合成（Fe 催化高壓法）——養活四十億人，也製造炸藥 |
| 1920 | 能斯特 | 熱化學第三定律 |

| 2004 | 切哈諾沃、赫什科、羅斯 | 泛素調控的蛋白質降解 |

| 2007 | 埃特爾 | 表面化學（哈伯-波施催化機理的現代版） |
| 2008 | 下村脩、查爾菲、錢永健 | 綠色螢光蛋白 GFP（活體成像） |

| 2016 | 索維日、斯托達特、費林加 | 分子機器（分子馬達、分子車） |
