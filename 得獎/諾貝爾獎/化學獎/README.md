# 諾貝爾化學獎 歷史年表（詳細版）

本書以「推理探案」的視角，把 1901–2024 年每一屆諾貝爾化學獎寫成一篇懸案卷宗：科學難題是懸案，實驗是偵查，理論是裁決，得獎與工業應用是後果。本頁是全書的總年表與檔案索引。

## 序幕（1895–1900）：諾貝爾遺囑設獎與首屆頒獎

| 年份 | 事件 |
| --- | --- |
| 1895 | 阿佛烈·諾貝爾（Alfred Nobel，炸藥發明人）於 11 月 27 日簽署遺囑，把遺產利息分為五份，設立物理、化學、生理或醫學、文學、和平五獎。化學獎交由瑞典皇家科學院頒發，「授予做出最重要化學發現或改良者」。諷刺的是：諾貝爾本人正是化學工業的最大受益者與受害者。 |
| 1896 | 12 月 10 日諾貝爾逝世於義大利聖雷莫，遺囑公開，旋即掀起親屬訴訟與瑞典輿論的猛烈批評——有人主張把財產歸還祖國。 |
| 1897–1898 | 遺囑執行人拉格納·索爾曼與工程师魯道夫·利列克維斯特奔走各國清點資產；瑞典國王奧斯卡二世起初反對，直到輿論轉向才默許。 |
| 1900 | 6 月 29 日瑞典政府核准《諾貝爾基金會章程》，諾貝爾基金會成立；瑞典皇家科學院設立化學獎與物理獎諾貝爾委員會。 |
| 1901 | 12 月 10 日（諾貝爾逝世五週年）於斯德哥爾摩頒發首屆獎項。化學獎首冠落在荷蘭人雅各布斯·亨里克斯·范托夫頭上——象徵物理化學這門新學科的加冕。每位得主獲得 150,782 瑞典克朗。 |

## 1901–1920：經典化學的黃金奠基（物理化學、有機合成與放射性）

| 年份 | 得主 | 事件／貢獻 |
| --- | --- | --- |
| 1901 | 雅各布斯·亨里克斯·范托夫（荷蘭） | 首屆化學獎。表彰「化學動力學與滲透壓定律的發現」。渗透壓 $\pi = iRTc$ 把溶液拉進熱力學版圖；他與奧斯特華德、阿瑞尼斯三人組創立《物理化學期刊》，化學自此有了數學骨架。 |
| 1902 | 赫爾曼·埃米爾·費歇爾（德國） | 表彰「醣類與嘌呤類合成的開創性工作」。苯肼找出糖的指紋、費歇爾投影式定立體、三個己糖全合成；嘌呤化學後來長出咖啡因、尿酸乃至核酸。 |
| 1903 | 斯凡特·奧古斯特·阿瑞尼斯（瑞典） | 表彰「電解質解離學說」。鹽溶於水會「自己拆開」的異端主張（1887），最終用凝固點下降與滲透壓數據定案；同時給出溫度—速率定律 $k = A e^{-E_a/RT}$。同年物理獎由居里夫婦與貝克勒分享。 |
| 1904 | 威廉·拉姆齊（英國） | 表彰「發現稀有氣體元素家族並測定其週期表位置」。氬（1894 與瑞利）、氦（1895 礦石中）、氖氪氙（1898 與特拉弗斯）——週期表上憑空多出一整個縱行。 |
| 1905 | 阿道夫·馮·拜耳（德國） | 表彰「有機染料與氫化芳香族化合物的研究」。1878–1883 年完成靛藍全合成，德國染料工業的地基；苯環的應力張力學說也是他的遺產。 |
| 1906 | 亨利·莫瓦桑（法國） | 表彰「分離氟單質與以電爐開創高溫化學」。1886 年氫氟酸電解加鉑帽陷阱，兩年報仇二十年未竟之業；同年宣稱人造金剛石（日後存疑）。得獎數月後去世。 |
| 1907 | 愛德華·畢希納（德國） | 表彰「無細胞發酵的發現」。1897 年砂磨酵母的「破瓶事件」：不靠活細胞也能把糖變酒精，酒化酶（zymase）登場，酵素化學與生物化學自此分家。 |
| 1908 | 歐內斯特·盧瑟福（英國／紐西蘭） | 表彰「放射性元素蛻變與放射性物質化學的研究」。與索迪提出元素蛻變理論（1902–03）：衰變律 $\lambda = \lambda_0 e^{-kt}$、半衰期概念；「化學家」獎頒給了未來的原子核之父。 |
| 1909 | 威廉·奧斯特瓦爾德（德國） | 表彰「催化作用、化學平衡與反應速率的研究」。把「催化」從煉金術謠言升格為熱力學概念——催化劑只加速、不改變平衡；實務上開出氨氧化製硝酸的奧斯特華德製程。 |
| 1910 | 奧托·瓦拉赫（德國） | 表彰「脂環族與萜類化學的奠基工作」。替數百種萜烯（松節油家族）理出系譜，異戊二烯規則成為天然物化學的第一把尺。 |
| 1911 | 瑪麗·居里（法國／波蘭） | 表彰「發現鐳與釙、分離鐳並研究其性質」。以瀝青鈾礦渣蒸餾出 0.1 克氯化鐳、測定鐳原子量；成為史上第一位兩度獲獎者（1903 物理、1911 化學）。 |
| 1912 | 維克多·格林尼亞（法國）；保羅·薩巴捷（法國） | 兩人共享。格林納：有機鎂試劑 $RMgX$ 給碳—碳鍵裝上千能扳手；薩巴捷：鎳催化氫化（油脂硬化等）與接觸催化的系統研究。同一年，鐵達尼號沉沒。 |
| 1913 | 阿爾弗雷德·維爾納（瑞士） | 表彰「原子價理論與配位化學」。鈷氨絡合物異構體數目判決了「主價＋副價」之争，八面體構型寫進教科書。 |
| 1914 | 西奧多·理查茲（美國） | 表彰「精密測定大量元素的原子量」。量化分析的極致工藝，其氫原子量數據亦為同位素的發現埋下暗線。 |
| 1915 | 里夏德·維爾施泰特（德國） | 表彰「植物色素（尤其葉綠素）的研究」。析出葉綠素 $a$ 與 $b$ 並定出鎂絡合結構骨架；一戰中延誤，1916 年才補行講演。 |
| 1916 | 從缺 | 第一次世界大戰：交戰國科學家全數入列動員，瑞典皇家科學院決定不頒獎。 |
| 1917 | 從缺 | 第一次世界大戰，化學獎連續第二年從缺（同年文學、和平照常頒發）。 |
| 1918 | 弗里茨·哈伯（德國） | 表彰「氨的合成——以氮與氫直接合成氨」（哈伯法）。1913 年巴登苯胺純鹼公司（BASF）奧保廠投產；「從空氣造麵包」養活了地球一半人口，也讓德國打了更久的仗。哈伯於 1919 年才領獎，且因毒氣戰飽受抗議。 |
| 1919 | 從缺 | 第一次世界大戰剛結束，科學界元氣未復，化學獎從缺。 |
| 1920 | 沃爾特·能斯特（德國） | 表彰「熱化學的研究」（熱力學第三定律 $\lim_{T \to 0} S = 0$ 與能斯特熱定理）。還有他 1889 年的電池方程式 $\Delta G = \Delta G^\circ + RT \ln Q$。戰後德國人首獎，領獎時 banned 國旗高懸。 |

## 1921–1950：同位素、大分子與戰火中的化學

| 年份 | 得主 | 事件／貢獻 |
| --- | --- | --- |
| 1921 | 弗雷德里克·索迪（英國） | 表彰「放射性化學與同位素的起源與本質」。1901 年與盧瑟福的蛻變理論、1913 年「同位素」命名：化學性質相同、原子量不同的兄弟元素。 |
| 1922 | 弗朗西斯·阿斯頓（英國） | 表彰「質譜儀與整數定則」。氯 35.5 的謎團拆成 $^{35}\mathrm{Cl}$ 與 $^{37}\mathrm{Cl}$ 兩兄弟；湯姆森的學生、卡文迪許的儀器。 |
| 1923 | 弗里茨·普雷格爾（奧地利） | 表彰「有機化合物的微量分析」。把碳氫分析從克級壓到毫克級，天然物化學從此不再被樣本量卡死。 |
| 1924 | 從缺 | 本年度化學獎未頒發（無合適候選／委員會保留）。 |
| 1925 | 里夏德·阿道夫·席格蒙迪（德國／奧地利） | 表彰「膠體化學與超顯微鏡的研究」。金溶膠的丁達爾實驗、發明縫隙超顯微鏡看見肉眼不可見的膠粒；玻璃工業（舒特玻璃）的科學化。 |
| 1926 | 特奧多爾·斯韋德貝里（瑞典） | 表彰「分散系的研究」。發明超速離心機（1924），測出蛋白質分子量，為後世分子生物學備好武器。 |
| 1927 | 海因里希·奧托·威蘭（德國） | 表彰「膽汁酸及其相近物質結構的研究」。膽酸的骨架解析是類固醇化學的第一場大捷。 |
| 1928 | 阿道夫·溫道斯（德國） | 表彰「固醇的研究及其與維生素的關聯」。麥角固醇經紫外線轉為維生素 D 的光化學路徑。 |
| 1929 | 阿瑟·哈登（英國）；漢斯·奧伊勒-克爾平（瑞典／德國） | 表彰「醣類發酵與發酵酵素的研究」。磷酸化中間物、輔酶的發現——發酵這門老手藝終於被拆成一張反應流程圖。 |
| 1930 | 漢斯·費歇爾（德國） | 表彰「血紅素與葉綠素結構的研究，尤其血紅素之合成」。兩大色素的結構在手，生物化學有了顏色。 |
| 1931 | 卡爾·博施（德國）；弗里德里希·貝吉烏斯（德國） | 表彰「高壓化學方法的發明與發展」。哈伯法工業化（博施）與煤之氫化液化（貝吉烏斯）——化學工程對能源與糧食的兩記重拳。 |
| 1932 | 歐文·朗繆爾（美國） | 表彰「表面化學的研究」。第一個入企業實驗室（通用電氣）領諾獎的人：單分子層、吸附理論、朗繆爾槽。 |
| 1933 | 從缺 | 本年度化學獎未頒發（該年獎金依章程撥回基金）。 |
| 1934 | 哈羅德·尤里（美國） | 表彰「發現重氫（氘 $^2\mathrm{H}$）」。蒸餾液態氫的光譜搜捕；重水後來成為核子時代的關鍵物資。 |
| 1935 | 弗雷德里克·約里奧-居里；伊倫·約里奧-居里（法國） | 表彰「人工放射性元素的合成」。鋁箔照 $\alpha$ 射線跑出正電子與磷-30；居里家族的第二代諾獎，敲開核化學的大門。 |
| 1936 | 彼得·德拜（荷蘭／德國／美國） | 表彰「偶極矩與 X 射線、電子繞射對分子結構的研究」。分子「歪不歪」有了量測方法，氣體繞射看見鍵角。 |
| 1937 | 沃爾特·霍沃思（英國）；保羅·卡勒（瑞士） | 表彰霍沃思：醣類結構與維生素 C 合成；卡勒：類胡蘿蔔素、黃素與維生素 A、B$_2$。維生素化學的全盛年。 |
| 1938 | 里夏德·庫恩（德國／奧地利） | 表彰「類胡蘿蔔素與維生素的研究」。希特勒政權禁止他領獎，戰後 1949 年才補領獎章（獎金依規則已歸基金）。 |
| 1939 | 阿道夫·布特南特（德國）；拉沃斯拉夫·魯日奇卡（瑞士／克羅埃西亞） | 表彰布特南特：性激素（雌酮、睾固酮）之結晶分離；魯日奇卡：聚亞甲基與萜烯、麝香酮。布特南特同樣被德國政府禁止領獎。 |
| 1940 | 從缺 | 第二次世界大戰：德國入侵丹麥挪威，北歐交通中斷，諾貝爾獎停頒。 |
| 1941 | 從缺 | 第二次世界大戰，連續第二年停頒。 |
| 1942 | 從缺 | 第二次世界大戰，連續第三年停頒。 |
| 1943 | 喬治·德海韋西（匈牙利／瑞典） | 表彰「以同位素作為化學過程之示蹤劑」。1923 年的放射性鉛示蹤實驗；戰時他與玻爾把諾獎章溶在王水裡藏過納粹搜查。 |
| 1944 | 奧托·哈恩（德國） | 表彰「重原子核分裂的發現」。1938 年底柏林實驗室鋇的異常，邁特納與弗里施的理論解釋——核分裂改寫了世界，也讓哈恩獲獎時人在英國被拘。 |
| 1945 | 阿爾圖里·伊爾馬里·維爾塔寧（芬蘭） | 表彰「飼料保存方法（AIV 法）的研究」。酸化青貯飼料，農業化學登堂入室。 |
| 1946 | 詹姆士·薩姆納；約翰·霍華德·諾思羅普；溫德爾·斯坦利（美國） | 表彰薩姆納：酵素尿素酶之結晶（1926）；諾思羅普與斯坦利：酵素與病毒蛋白之純化結晶。酵素是蛋白質，病毒亦然——生物化學的成年禮。 |
| 1947 | 羅伯特·魯賓遜（英國） | 表彰「植物產物（生物鹼）的研究」，包括嗎啡、罌粟鹼結構與生物鹼合成路徑之推想。 |
| 1948 | 阿爾內·蒂塞利烏斯（瑞典） | 表彰「電泳與吸附分析之研究，尤其血清蛋白複雜性質之發現」。發明電泳儀並主持諾貝爾基金會。 |
| 1949 | 威廉·吉奧克（美國） | 表彰「超低溫下物質性質的研究」。磁冷卻把溫度推到 $10^{-3}\,\mathrm{K}$ 量級，化學熱力學的極地遠征。 |
| 1950 | 奧托·迪爾斯；庫爾特·阿爾德（德國） | 表彰「雙烯合成（Diels–Alder 反應）的發現與發展」。1928 年環戊二烯與順丁烯二酸酐的一鍋成環，日後成為全合成的瑞士刀。 |

## 1951–1980：結構與鍵結的王朝（晶體學、量子化學與生命分子）

| 年份 | 得主 | 事件／貢獻 |
| --- | --- | --- |
| 1951 | 埃德溫·麥克米倫；格倫·西奧多·西博格（美國） | 表彰「超鈾元素化學的發現」。錼、鈽（1940）之後，西博格團隊一路造到鋦以上；週期表向後延伸。 |
| 1952 | 阿徹·約翰·波特·馬丁；理察·勞倫斯·米林頓·辛格（英國） | 表彰「分配層析法的發明」。紙層析拆開氨基酸；辛格後來又拿 1958 年化學獎（胰島素序列）。 |
| 1953 | 赫爾曼·施陶丁格（德國） | 表彰「高分子化學的開創」。堅持大分子是共價長鏈（1920s 的異端）而對抗膠體學派；塑料時代的理論地基。 |
| 1954 | 萊納斯·鮑林（美國） | 表彰「化學鍵本質的研究」（雜化軌域、共振、電負度）。氫鍵與 $\alpha$ 螺旋；兩年後他又拿和平獎。 |
| 1955 | 文森特·迪維尼奧（美國） | 表彰「催產素與加壓素等含硫多肽激素之全合成」。第一個多肽激素全合成。 |
| 1956 | 西里爾·欣謝爾伍德（英國）；尼古拉·謝苗諾夫（蘇聯） | 表彰「鏈反應機構的研究」。氫氧爆炸與支鏈反應、自動催化；冷戰兩邊各一位科學家共享同一座獎。 |
| 1957 | 亞歷山大·R·托德（英國） | 表彰「核苷酸與核苷輔酶的研究」。DNA/RNA 骨架化學的鋪路石。 |
| 1958 | 弗雷德里克·桑格（英國） | 表彰「胰島素胺基酸序列的測定」。蛋白質是有順序的分子；桑格後來再拿 1980 年獎（定序法）。 |
| 1959 | 雅羅斯拉夫·海羅夫斯基（捷克） | 表彰「極譜法的發現與發展」。滴汞電極上的電流—電位曲線，電化學分析的新世代。 |
| 1960 | 威拉德·利比（美國） | 表彰「碳-14 定年法」。宇宙射線造出 $^{14}\mathrm{C}$，半衰期 5,730 年，考古學與地質學因此有了時鐘。 |
| 1961 | 梅爾文·卡爾文（美國） | 表彰「光合作用中二氧化碳同化反應路徑之研究」。$^{14}\mathrm{CO_2}$ 追蹤出卡爾文循環。 |
| 1962 | 馬克斯·佩魯茨；約翰·肯德魯（英國） | 表彰「球狀蛋白（血紅蛋白、肌紅蛋白）結構之 X 射線解析」。重原子標記破局；分子生物學有了三維。 |
