# 1973 · 菲舍爾與威爾金森——二茂鐵與均相催化的時代

> 1973 諾貝爾化學獎：恩斯特·奧托·菲舍爾（Ernst Otto Fischer，1918–2007，德國）與傑弗里·威爾金森爵士（Sir Geoffrey Wilkinson，1921–1996，英國）——表彰「其對金屬有機化合物的研究，尤其是二茂鐵與類似夾心化合物」。同年另一份化學獎頒給了生物化學的「生物合成原理」（見 [1975-康福思與普雷洛格](1975-康福思與普雷洛格.md)）。

## 懸案（案情提要）

1950 年代的有機金屬化學有兩樁大案：

1. **Grignard 試劑（格氏試劑）好用但笨重**：$\mathrm{RMgX}$ 能做幾乎所有的碳—碳鍵接合（見 [1912-格林納與薩巴捷](1912-格林納與薩巴捷.md)），但它是**敏感的、難以保存的、必須在無水乙醚中操作**的。化學家一直想要「更穩定的金屬有機試劑」。
2. **一個新物質的謎團**：1951 年，德國的菲舍爾與同事在還原二茂鐵（ferrocene）時，得到**極穩定的橙色結晶**。它的行為完全不像任何已知的有機金屬化合物：
   - 極穩定（可 sublimation、可在空氣中操作、可溶於有機溶劑甚至水）；
   - 有漂亮的、類似苯的紫外可見光譜；
   - 可以被氧化成**帶藍綠色的陽離子**，且此陽離子**出奇地穩定**；
   - 磁性測量顯示**所有電子都已配對**。

**這是什麼？**答案是：**夾心（sandwich）化合物**——兩個環戊二烯環像三明治一樣夾住一個金屬原子。**金屬有機化學由此進入「分子級設計」時代，而均相加氫催化也在同一時期被威爾金森建立。**

## 前因

| 年份 | 事件 |
| --- | --- |
| 1918 / 1921 | 菲舍爾生於巴伐利亞的蘇伊森；威爾金森生於英國 Todmorden。 |
| 1930s–40s | 菲舍爾在慕尼黑（隨威蘭，見 [1927-威蘭與膽汁酸](1927-威蘭與膽汁酸.md)）與二乙基鋁等金屬有機化合物打交道；研究**乙炔的羰基化**（ Reppe 碳基化反應，即 CO 加到炔烴上製備烯醛/烯酮，是工業上製備塑膠單體與藥物的關鍵反應）。 |
| 1951 | 菲舍爾與同事在處理由 $\mathrm{FeCl_3}$ 製備的環戊二烯時，意外得到**二茂鐵**：$\mathrm{2\,C_5H_6} + \mathrm{FeCl_2} \to \mathrm{Fe(C_5H_5)_2} + 2\,\mathrm{HCl}$。 |
| 1952–1954 | 結構之謎：磁性（無未成對電子）與光譜顯示**非游離的雙環戊二烯**結構——但當時的 X 射線無法確認金屬的位置（因為電子密度疊加）。**菲舍爾提出了「雙環戊二烯」的模型並以化學證據（烷基化、氧化還原）支持之。** |
| 1953 | 威爾金森（於劍橋）獨立發展出**銠的類二茂鐵化合物**並研究其催化性質。 |
| 1954–1956 | **威爾金森的均相加氫催化**：發現 $\mathrm{RhCl(PPh_3)_3}$（ Wilkinson's catalyst）在常壓、室溫下即可催化烯烴的加氫——這是均相加氫的里程碑（此前加氫多用鎳/鉑的非均相催化，見 [1912-格林納與薩巴捷](1912-格林納與薩巴捷.md)）。 |
| 1956–1960s | 兩人建立「**夾心化合物**」的完整化學：合成了鉻、錳、鈷、鎳、鈦等數十種夾心化合物（**sandwich compounds**），並發展出第四類結構——**夾心式（half-sandwich / piano-stool）與斜置（bent metallocene）**。 |
| 1973 | 兩人共享諾貝爾化學獎。 |

## 調查

**偵查一：二茂鐵的結構之謎——磁性與光譜的推理。**

1951–1952 年的推理鏈：

1. **磁性**：$\mathrm{Fe(C_5H_5)_2}$ 的磁性顯示**沒有未成對電子**；
2. 若結構是 $\mathrm{Fe^{2+}}$ 配兩個 $\mathrm{C_5H_5^-}$（各自的 6 個 $\pi$ 電子），鐵的 $d^6$ 電子在八面體場中為**低自旋**（$t_{2g}^6$，全配對）→ **與觀察相符**；
3. **光譜**：可見光譜在約 $440\ \mathrm{nm}$ 有吸收（呈橙紅色）；**紫外光譜顯示只有** $\pi \to \pi^*$ 躍遷，**沒有**金屬 $d \to d$ 躍遷——這意味著金屬的 $d$ 軌域與配體的 $\pi$ 軌域**強烈混成**，即電子是**離域的**。

**結論：兩個 $\mathrm{C_5H_5}$ 環以 $\eta^5$ 方式與金屬中心鍵結（$\eta^5$ 表示五個碳都參與鍵結），金屬居中，形成「三明治」。**

**偵查二：費舍爾的化學驗證——烷基化與氧化還原。**

在 X 射線無法確定金屬位置的情況下，菲舍爾用化學證據補位：

$$\text{二茂鐵} + \mathrm{CH_3Li} \xrightarrow{\text{THF}} \underbrace{\mathrm{Fe(C_5H_5)(C_5H_4CH_3)}}_{\text{甲基二茂鐵}} + \mathrm{Li[C_5H_5]}$$

$$\mathrm{[Fe(C_5H_5)_2]^+} \text{（ferrocenium）}\ \text{是穩定的藍綠色陽離子，} \quad \mathrm{[Fe(C_5H_5)_2]} \xrightarrow{\text{氧化}} \mathrm{[Fe(C_5H_5)_2]^+} + e^-$$

**可逆的單電子氧化還原**是「金屬中心參與電子傳遞」的證據，也是二茂鐵成為「可插拔的電子載體」的原因——今日的有機電子裝置（OFET、染料敏質太陽能電池、有機光伏）都以二茂鐵的氧化還原可逆性為設計基礎。

**偵查三：威爾金森的催化劑——均相加氫的突破。**

威爾金森的催化劑 $\mathrm{RhCl(PPh_3)_3}$（三方錐形，$d^8$，16 電子）在常壓下即可催化烯烴加氫：

$$\mathrm{RhCl(PPh_3)_3} + \mathrm{H_2} \rightleftharpoons \mathrm{RhHCl(PPh_3)_3} + \mathrm{PPh_3} \xrightarrow{\text{烯烴}} \text{加成產物} + \text{催化劑再生}$$

**其關鍵優勢：選擇性高**——只加氫雙鍵，不動羰基、苯環、硝基等：

$$\text{選擇性加氫} \xrightarrow{\text{Rh 催化劑}} \text{工業上製備維生素 A、藥物中間體、香料}$$

**這開啟了「均相催化」的時代**——催化劑溶解在反應介質中，因此可以像溶液反應一樣控制選擇性、立體選擇性與區分性。

**偵查四：結構家族的擴張。**

兩人共同建立的結構分類（今日教科書的標準）：

| 類型 | 結構 | 例子 |
| --- | --- | --- |
| **夾心（sandwich）** | 兩個平行環夾住金屬 | 二茂鐵 $\mathrm{Fe(C_5H_5)_2}$、二 Ruthenocene $\mathrm{Ru(C_5H_5)_2}$ |
| **半夾心（half-sandwich）** | 一個環 + 三個配體 | $\mathrm{CpFe(CO)_2{-}R}$（Fp 基金屬） |
| **斜置（bent metallocene）** | 兩環但夾角非 180° | $\mathrm{Cp_2TiCl_2}$、$\mathrm{Cp_2MoH_2}$ |
| **單環（single ring）** | 一個環 | $\mathrm{CpFe(CO)_2{-}CN}$ |

**「$\eta$ 記號」（$\eta^1$–$\eta^6$）**成為描述「配體以幾個原子與金屬鍵結」的標準語言。

**偵查五：橙色的來源——一個「金屬—配體混成」的教課。**

二茂鐵呈橙紅色（吸收約 $440\ \mathrm{nm}$），原因不是金屬的 $d \to d$ 躍遷（那會很弱），而是：

$$\text{金屬—配體 charge-transfer}\ (\mathrm{Fe}^{2+} \to \mathrm{Cp}^{\bullet\bullet})\ \text{躍遷}\ \text{（允許、強度大）}$$

**這是金屬有機光化學的開端**——今日的光敏劑、OLED 的發光層（$\mathrm{Ir(ppy)_3}$ 等）、光動力治療的鉗形配合物，都是這條線的後代。

## 理論裁決

**判決一：η 配位與「電子計數」。** 金屬有機化學的基本語言：

$$\text{18 電子規則} : \quad \text{金屬價電子} + \text{配體電子捐贈} + \text{中性配體} \times 2 = 18$$

以二茂鐵為例：$\mathrm{Fe^{2+}}$（$d^6$）＋兩個 $\eta^5\text{-Cp}^-$（各 6 電子）＝ $6 + 12 = 18$。**「18 電子」是穩定配合物的判準**，這是 1960–70 年代發展出的核心規則（相對的「16 電子規則」也常用於描述反應中間物）。

**判決二：電子計數作為「反應性的預測器」。**

$$\text{缺電子} \Rightarrow \text{易與配體結合};\quad \text{滿電子} \Rightarrow \text{需先失電子或解離配體才能反應}$$

**這套「計數—反應性」的對應，使金屬有機反應第一次可以像有機反應那樣被預測**——例如 $\mathrm{Cp_2TiCl_2}$（14 電子）易於加成配體，而二茂鐵（18 電子）非常穩固。

**判決三：均相加氫的機構。** 威爾金森催化劑的循環（**unanimous（unsaturate）路徑**）：

$$\begin{aligned}
\text{① 活化：} &\quad \mathrm{RhCl(PPh_3)_3} + \mathrm{H_2} \rightarrow \mathrm{RhHCl(PPh_3)_3} \\
\text{② 配位：} &\quad \mathrm{RhHCl(PPh_3)_3} + \text{烯} \rightarrow \mathrm{RhHCl(PPh_3)_2(\text{烯})} \\
\text{③ 插入：} &\quad \text{烯插入 Rh–H} \rightarrow \text{烷基中間物} \\
\text{④ 還原消除：} &\quad \text{還原消除} \rightarrow \text{加氫產物} + \mathrm{RhCl(PPh_3)_3}
\end{aligned}$$

**這是 20 世紀最有機理的催化反應之一**，並在 1990 年代的諾貝爾化學獎（見 [2001-諾爾斯與手性催化](2001-諾爾斯與手性催化.md)）中被延伸為手性版本。

**判決四：設計催化劑的可能性。** 二茂鐵與其衍生物提供了「可攜帶、可調控的電子與配位環境」：

$$\text{金屬} + \text{配體} \Rightarrow \text{可設計的催化劑家族}$$

今日的策略（以二茂鐵骨架為出發點）：改變金屬（Ru、Ir、Pd）、改變環的取代基、改變夾角（斜置金屬茂化物）、改變橋連配體——**這套「金屬茂化物設計」語言，直接通向 2010 年鈀偶聯（見 [2010-赫克與鈀催化偶聯](2010-赫克與鈀催化偶聯.md)）與 2005 年烯烴複分解（見 [2005-格拉布與烯烴複分解](2005-格拉布與烯烔複分解.md)）。**

## 後果

| 領域 | 影響 |
| --- | --- |
| 催化化學 | 均相催化的工業應用（加氫、羰基化、聚合、製藥）；鉑族金屬的工業地位由此建立。 |
| 有機電子 | 二茂鐵類氧化還原可逆、穩定、易衍生，是 OFET、二茂鐵衍生物配體、氧化還應答探針的標準結構；**二茂鐵是化學界「最受歡迎的建築磚」之一**。 |
| 光與電 | 鉗形鉑(II) 發光體（$\mathrm{Pt(dpy)Cl_2}$）是 2000 年代 OLED 研究的起點；金屬配合物的光敏與光動力治療亦由此發展。 |
| 醫藥 | 金屬配合物藥物（順鉀見 [1913-維爾納與配位化學](1913-維爾納與配位化學.md)、碳化鈾 $\mathrm{[UO_2(CH_3)_3]^-}$ 的技術）與生物分子傳感器（葡萄糖電化學感測器）。 |
| 結構化學 | 夾心與斜置金屬茂化物的結構化學，成為理解金屬—配體鍵結的教科書內容。 |
