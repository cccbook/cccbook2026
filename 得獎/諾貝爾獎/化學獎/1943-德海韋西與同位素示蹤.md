# 1943 · 德海韋西與同位素示蹤

> 1943 諾貝爾化學獎：喬治·夏爾·德·海韋西（George Charles de Hevesy，1885–1966，匈牙利）——表彰「其在以放射性示蹤劑研究化學過程（如動物代謝）上之關鍵角色」。他讓化學家第一次能夠「看見」原子去了哪裡。

## 懸案（案情提要）

1920 年代的生物化學正面臨一個方法學上的絕境：**生命過程是看不見的。**

- 骨骼會不斷被分解又重建——但「重建得多快」？沒有任何方法能量。
- 元素在體內會被吸收、轉移、排泄——但它究竟走了哪條路？
- 當年測定鉀、鈣、磷的**收支平衡**，只能得到「靜止的總量」，無法分辨「快速周轉的小池」與「長期儲存的大池」。

1938 年核分裂被發現之後（見 [1944-哈恩與核分裂](1944-哈恩與核分裂.md)），**放射性同位素的供給突然變得幾乎無限**——這是一場工具的革命。但工具到手之前，還有一個更基本的問題沒有解決：

> **能不能給一個元素「做記號」，讓它在化學行為完全不變的情況下，被我們偵測到它的行蹤？**

偵辦人：喬治·德·海韋西——匈牙利人，本案的兩條戰線（生理代謝與元素預測）他都參與。

## 調查

**偵查一：示蹤的物理——化學不變，信号可見。**

示蹤法的原理極簡：同一元素的**同位素**在化學上行為幾乎相同（差異僅在質量與核自旋，可用同位素效應估計），但其中一個是**放射性**的，可以被偵測：

$$A = \lambda N \qquad (\text{活度 } \propto \text{放射性原子數})$$

若以放射性同位素取代穩定同位素，則被標記的分子在反應中「照常參與」，但其命運可由放射性追蹤。這是化學史上第一個真正的「追蹤工具」：**物質不再需要被看見，只需要被計數。**

**偵查二：第一件示蹤物證——柳枝上的鉛。**

1923 年的實驗設計極為精妙：德海韋西發現，釷系礦物中的放射性鉛 B（$^{212}\mathrm{Pb}$）與穩定鉛在化學上無法區分，但前者可被計數。他把柳樹枝條浸入含放射性鉛的溶液中，測量枝條各部位的放射性，藉此描繪**鉛在植物體內的吸收路徑與分布**。

$$\text{結果：植物把鉛累積在葉片（蒸散流）與根部的特定部位}$$

這是人類第一次「用放射性追蹤元素的行蹤」——今日環境科學中追蹤污染物遷移的方法，源頭在此。

**偵查三：骨骼的更新速率——醫學方法的誕生。**

1930 年代的問題：骨質流失（骨質疏鬆）與骨質重建的速率關係不明，鈣的收支平衡無法解釋骨疾病。德海韋西的做法是「打點計數」：

1. 給動物注射（或讓人攝入）一次放射性鍶／鉛；
2. 追蹤其放射性在骨骼中的**消失曲線**；
3. 由消失速率反推**骨骼的更新（置換）速率**。

以單指數模型描述：

$$A(t) = A_0\, e^{-k t}, \qquad k = \text{置換率}, \qquad t_{1/2} = \frac{\ln 2}{k}$$

這套「追蹤 + 動力學」的方法，後來發展成今日的**骨密度檢測**（核醫學的骨掃描，即以 $^{99m}\mathrm{Tc}$-磷酸鹽示蹤骨血流量與骨親和力）與**骨代謝疾病**（骨軟化症、甲状旁腺功能異常）的鑑別診斷。

**偵查四：戰爭帶來的工具革命——放射 dangers 與生物化學的雙面。**

1938 年核分裂被發現後，鈾中子轟擊可產生各種放射性同位素，示蹤劑的種類爆炸式增加。但其中有一條發現必須記在帳上：**放射性磷（$^{32}\mathrm{P}$）與放射性鍶（$^{90}\mathrm{Sr}$）會集中在骨骼**——因為它們模仿鈣的行為被骨基質吸收。這既是：

- **醫療資源**：$^{32}\mathrm{P}$ 治療白血病、$^{90}\mathrm{Sr}$ 骨標記測量骨吸收；
- **也是危害**：早期放射學家（含德海韋西本人關注的同業）的骨癌與死亡，根源正是在缺乏屏蔽與劑量觀念的年代接觸了這些示蹤劑。

**偵查五：把「靜態收支」變成「動態流率」。**

示蹤法的根本貢獻，是讓生物化學從**存量（pool size）**走向**流率（flux）**：

$$\text{存量} \quad \xrightarrow{\ \text{示蹤}\ } \quad \text{周轉率（turnover rate）}$$

在示蹤之前，生物化學只能說「體內有 1 千克鉀」；示蹤之後，它能說「其中 0.3 克每天在換一次」。**這是 1950 年代代謝研究（凱利、艾爾貝爾、施文克等以 $^{14}\mathrm{C}$ 追蹤碳流）得以開展的技術前提**，也是 2024 年諾貝爾獎主題（蛋白質結構與代謝預測）的方法學祖先。

**偵查六：戰時的另一件案子——溶解的獎牌。**

1943 年 10 月，蓋革計數器的發明者斯特勞斯（Straub）在哥本哈根向德海韋西求援：納粹已得知包括勞厄（Max von Laue）、法蘭克（James Franck）在內的數位諾貝爾獎牌正被德海韋西收藏，若被查出將被沒收。為保住這些獎牌，德海韋西把獎牌**溶於王水（aqua regia）**，之後又設法重新析出並交還。**這段「物理學家藏起物理學家的獎章」的插曲，是諾貝爾獎史上最動人的一幕。**

## 理論裁決

**判決一：示蹤劑的判準。** 一個元素要能當示蹤劑，須同時滿足：

1. **化學恆等性**：與穩定同位素在所研究的條件下行為相同（差異僅為同位素效應，可用空白試驗校正）；
2. **可偵測性**：具放射性（壽命適合實驗時程），或可用質譜／活化分析偵測；
3. **不擾動系統**：用量極微（十幾毫克的 ${}^{140}\mathrm{La}$ 可標記整隻動物的鈣）。

$$\text{用量} \ll \text{體內該元素的總量}, \qquad \text{比活度} = \frac{A}{m_{\text{標記物}}} \text{（越高越好）}$$

**判決二：速率方程式的生物學應用。** 示蹤實驗的數據處理，就是把化學動力學搬到生物系統。以簡單的單指數轉移為例：

$$\frac{dN_{\text{標記}}}{dt} = -k\,N_{\text{標記}}, \qquad N_{\text{標記}}(t) = N_0 e^{-kt}$$

若系統有兩個可交換的庫（組織與血漿），則標記物的時間曲線是**雙指數**：

$$\text{比活度}(t) = A_1 e^{-k_1 t} + A_2 e^{-k_2 t}$$

由此可解出兩個庫的大小與交換速率——**這是 1940–50 年代「動態區隔（dynamic compartment）」概念的數學形式**，並在 1950 年代由艾爾貝爾（Axelrod 等）用於藥物動力學。

**判決三：骨代謝的定量框架。** 「注射一次放射性鍶 → 追蹤其在骨中的消失 → 反推置換率」建立了**骨動力學（bone turnover）**的量測法。今日的骨密度測量（DXA）與雙能 X 光吸收（吸收測定雙光子）其實是同一問題的不同技術解：測量骨骼的礦物質含量與置換速率。

**判決四：示蹤法的通用化——「化學的 X 光」。** 德海韋西的方法有個直觀的比喻：**它像給化學反應拍一部電影——普通化學只能看見反應前後的靜態快照，示蹤法能追蹤特定分子的旅程。**這個比喻在 1950 年代被用得更廣：放射性標記讓科學家能追蹤藥物在體內的代謝路徑、鈣在骨骼的分布、氮在蛋白質的周轉。

## 後果

| 領域 | 影響 |
| --- | --- |
| 生物化學 | 碳、氮、磷的代謝流率研究成為可能；1950 年代以 $^{14}\mathrm{C}$ 標記的生物合成研究（凱利與艾文斯、艾爾貝爾與本德、施文克的 TCA 循環工作）奠立今日的代謝組學。 |
| 核醫學 | 骨掃描（$^{99m}\mathrm{Tc}$-MDP）、甲狀腺掃描（$^{131}\mathrm{I}$）、心肌灌注（ $^{99m}\mathrm{Tc}$-MIBI）等以放射性示蹤劑為基礎；放射治療（$^{60}\mathrm{Co}$、$^{192}\mathrm{Ir}$）亦為同一技術樹。 |
| 環境科學 | 追蹤污染物遷移（${}^{129}\mathrm{I}$、${}^{137}\mathrm{Cs}$、$^{210}\mathrm{Po}$）與生態系的物質循環研究。 |
| 骨骼與內分泌 | 骨代謝疾病（骨軟化、甲狀腺功能異常、轉移性骨癌）的鑑別診斷；今日的骨密度儀是同一目標的無放射性版本。 |
| 元素史 | 1913 年與科斯特發現**鉿**（元素 72），是玻爾預測的實現——「先預測元素的存在，再在自然界中把它揪出來」是化學史上最美的案例之一；鉿今日用於核控制棒與高溫合金。 |
| 科學精神 | 戰時溶解諾貝爾獎牌的義舉，使德海韋西成為諾貝爾獎史上的象徵人物之一。 |
