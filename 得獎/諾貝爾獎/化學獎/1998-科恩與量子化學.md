# 1998 · 科恩與波普——用電子密度取代波函數

> 1998 諾貝爾化學獎：瓦爾特·科恩（Walter Kohn，1923–2016，奧地利／美國）與約翰·波普爵士（Sir John Pople，1925–2004，英國）——表彰「其對量子化學的計算方法的發展」。**化學家終於有了能算出分子性質的「設計工具」。**

## 懸案（案情提要）

1990 年代的化學計算，有一個「原理上無解」的障礙：

- 量子力學給出的答案是**波函數** $\Psi(\mathbf{r}_1, \ldots, \mathbf{r}_N)$——它描述 $N$ 個電子的**完整**狀態；
- 但 $N$ 個電子的波函數是 $3N$ 維的空間中的函數。對一個中等大小的分子（$N \sim 50$），變數是 150 維；
- 這個維度的增長使**精確解**（波恩—奧本海默近似、多體微擾動理論）**只在極小分子上可行**；
- 而化學家真正想算的，是**實際系統**：一個酵素、一個材料、一個藥物分子——它們的波函數根本寫不出來；
- 結果是：**理論化學在 1990 年代之前基本只能「解小分子、猜大分子」。**

偵辦人：科恩與波普。科恩提出**密度泛函理論（DFT）**——**用電子密度取代波函數**；波普則發展了**Hartree–Fock 與從頭計算（ab initio）**的實用化學版本（Gaussian 系列程式）。

## 調查

**偵查一：問題的重新表述——「我們真的需要波函數嗎？」**

哈密頓量：

$$\hat{H} = \underbrace{\hat{T}}_{\text{動能}} + \underbrace{\hat{V}}_{\text{勢能}} = \sum_i \left[-\frac{\hbar^2}{2m}\nabla_i^2\right] + \sum_i v_{\text{ext}}(\mathbf{r}_i) + \sum_{i<j}\frac{e^2}{4\pi\epsilon_0 r_{ij}}$$

**波函數解法**：$\hat{H}\Psi = E\Psi$ 的 $3N$ 維本徵值問題。

**科恩的洞見**：**能量與所有可觀測量都只是電子的空間密度 $\rho(\mathbf{r})$ 的函數**：

$$E[\rho] \quad \text{而非}\quad E[\Psi]$$

$$\text{維數壓縮}：\ \underbrace{3N\ \text{維（波函數）}}_{\text{不可行}} \xrightarrow{\text{科恩定理}} \underbrace{3\ \text{維（密度）}}_{\text{可行！}}$$

**這是物理化學史上維數最大的一次降維**。

**偵查二：科恩–肖爾方程——「用假的單電子算真的密度」。**

$$\text{真實的多電子基態} \xrightarrow{\text{假設}} \left[-\frac{\hbar^2}{2m}\nabla^2 + v_{\text{eff}}(\mathbf{r})\right]\varphi_i(\mathbf{r}) = \varepsilon_i\varphi_i(\mathbf{r})$$

$$n(\mathbf{r}) = \sum_i f_i\,|\varphi_i(\mathbf{r})|^2 \quad(\text{佔據數 } f_i)$$

$$\text{有效勢} \quad v_{\text{eff}}(\mathbf{r}) = v_{\text{ext}}(\mathbf{r}) + \int \frac{\rho(\mathbf{r}')}{|\mathbf{r}-\mathbf{r}'|}\,\mathrm{d}\mathbf{r}' + v_{\text{xc}}[n] + v_{\text{ext}} - v_H[n]$$

**其中 $v_{\text{xc}}$（交換—關聯泛函）是整個理論的「未知項」，也是今日 DFT 研究的核心對象。**

**偵查三：泛函的選擇——「精確性與效率的取捨」。**

| 泛函類型 | 例子 | 特徵 |
| --- | --- | --- |
| **LDA**（局域密度近似） | Slater、Perdew–Zunger | 只用 $\rho(\mathbf{r})$ 的值；便宜，但精度有限 |
| **GGA**（廣義梯度近似） | PBE、BLYP | 加入 $\nabla\rho$；目前的主流 |
| **雜化泛函** | B3LYP、B97 | 混入部分 Hartree–Fock 交換；精度高、成本高 |
| **範圍分離雜化** | ωB97X | 短程用 HF、長程用 DFT；**今日計算化學的主流之一** |

**「DFT 的誤差系統性地來自 $v_{\text{xc}}$」**——這是 1990 年代末至今的主戰場，也帶動了**機器學習泛函**（2010 年代至今）。

**偵查四：波普的「從頭計算」——「把 Hartree–Fock 算準」。**

$$\hat{F}\phi_i = \varepsilon_i\phi_i \quad(\text{Roothaan 方程，見 [1966-馬利肯與分子軌域](1966-馬利肯與分子軌域.md)})$$

$$\text{Hartree–Fock}：\ \text{包含交換、忽略關聯};\qquad \text{MP2/MP4}：\ \text{以微擾動加入關聯項}$$

**波普的貢獻是「把它變成可用」**：高斯基組、數值積分、基組最佳化、幾何最佳化、頻率計算——**把量子化學從專家的算圖變成研究生的日常工具**。

**偵查五：軟件的誕生——「Gaussian 程式」。**

$$\text{輸入：} \ \text{分子座標} + \text{方法/基組} \xrightarrow{\text{Gaussian}} \text{能量、幾何優化結果、頻率、軌域圖}$$

**1990 年代 PC 的普及 + Gaussian 的易用 = 量化化學從「三個實驗室」到「全球普及」**。今日的化學家在做任何計算前，都會先「跑一次 DFT」——**這是諾貝爾級工作改變研究習慣的最直接例子之一**。

## 理論裁決

**判決一：科恩定理——「波函數是可被繞過的」。**

$$\text{若 } \Psi \text{ 與 } \Psi' \text{ 給出相同的 } n(\mathbf{r}) = \sum_i|\psi_i(\mathbf{r})|^2,\ \text{則} \ E[\Psi] = E[\Psi']$$

$$\text{推論}：\ \text{所有的基態性質} \xrightarrow{} \text{泛函 } E[n]\ \text{（三維函數的泛函）}$$

**這把量子化學從「解方程」變成「找泛函」**——問題性質的轉變，也是 DFT 能被不同領域的人（物理、化學、材料）共同使用的原因。

**判決二：Kohn–Sham 的「自洽場」迴圈。**

$$n(\mathbf{r}) \xrightarrow{v_{\text{eff}}[n]} \text{解 Kohn-Sham 方程} \xrightarrow{} \{\varphi_i\} \xrightarrow{} n'(\mathbf{r}) \xrightarrow{\text{迭代}} n(\mathbf{r})$$

$$\text{自洽場迭代} \Rightarrow \text{收斂到基態};\qquad \text{成本} \propto N^3\text{–}N^4\ (\text{與波函數法同階，但無} 3N\ \text{維})$$

**判決三：計算化學的分層——「方法 $\times$ 基組」的兩維選擇。**

$$\text{精度} = f(\text{方法层级},\ \text{基組大小})$$

$$\text{方法层级}：\ \text{HF} < \text{MP2} < \text{MP4} < \text{CCSD(T)} < \text{DFT（雜化）}$$

$$\text{基組}：\ \text{STO-3G} < \text{6-31G(d)} < \text{6-31+G(d,p)} < \text{aug-cc-pVTZ} < \text{cc-pV5Z}$$

**波普的「系統性誤差」概念（引入 $\mathrm{ZPE}$、電子的非經典性）是今日計算化學「誤差預算」的源頭。**

**判決四：從計算到「預測」。**

$$\text{計算化學的終極目標}：\ \text{不必做實驗，即可預測性質、篩選候選分子、解釋機制}$$

$$\text{今日}：\ \text{從} \ \text{催化劑篩選、藥物候選優化} \ \text{到} \ \text{蛋白質結構預測（2024）}$$

**這條線的最終形態是 2024 年的諾貝爾獎**：AlphaFold2 之所以可能，正是因為物理（機器學習＋物理先驗）能代替無法完成的實驗。

## 後果

| 領域 | 影響 |
| --- | --- |
| 化學研究 | 量化化學成為化學家的標準工具；「先計算再實驗」成為研究流程的標準步驟。 |
| 材料科學 | DFT 是材料設計（催化劑、電池材料、半導體、合金）的核心工具；「高通量計算材料篩選」在 2010 年代成為常規。 |
| 藥物設計 | 計算化學在虛擬篩選、ADMET 預測中的地位；今日的「AI 藥物設計」皆以量化化學生成的資料為訓練集。 |
| 能源 | 催化劑的理論設計（燃料電池、$\mathrm{CO_2}$ 還原）、電池材料、太陽能材料。 |
| 教學 | 「先算再想」成為化學教育的常態；Gaussian 等軟體的用戶以百萬計。 |
| 科學制度 | 1998 年的化學獎**首次頒給計算方法**——這是諾貝爾獎對「理論—計算」傳統的正式承認（此前僅物理學獎偶爾涉及）。 |
