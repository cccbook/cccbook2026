# 1972 · 安芬森、摩爾與斯坦——序列決定形狀

> 1972 諾貝爾化學獎：克里斯琴·波希默·安芬森（Christian B. Anfinsen，1916–1995，美國）、斯坦福·摩爾（Stanford Moore，1913–1982，美國）與威廉·霍華德·斯坦（William Howard Stein，1911–1980，美國）——表彰「其對核糖核酸酶之研究，尤其是對胺基酸序列與其生物活性構形之關係的發現」。**安芬森法則**：序列決定構形。

## 懸案（案情提要）

1970 年初，蛋白質研究有兩塊拼圖，卻缺了把它們接起來的第三塊：

- **拼圖一（序列）**：桑格在 1958 年讀出胰島素的序列（見 [1958-桑格與胰島素序列](1958-桑格與胰島素序列.md)）——蛋白質是「一串胺基酸」，這已無疑问。
- **拼圖二（形狀）**：佩魯茨與肯德魯在 1958–60 年解出血紅蛋白與肌紅蛋白的三維結構（見 [1962-佩魯茨與血紅蛋白](1962-佩魯茨與血紅蛋白.md)）——蛋白質是「摺起來的一條鏈」，這也無疑問。
- **缺的那塊**：**是序列決定形狀，還是形狀決定序列？**這不是文字遊戲——它是整個分子生物學的關鍵假設：
  - 若序列決定形狀，那麼**只要知道序列，就理論上能預測結構**（今日 AlphaFold 的全部合法性都建立在這條上）；
  - 若形狀決定序列，則蛋白質的形成需要「模板」，蛋白質將是遺傳訊息的第二位主角。

偵辦人：安芬森。他選了一個極小、極合適的目標：**核糖核酸酶（RNase A）**——一條 124 個胺基酸的單鏈酵素，含 4 個二硫鍵。

| 1990s | 安芬森主張「**蛋白質設計**」的可能性（以序列指定結構），並於 1996 年推動成立**蛋白質設計競賽（Protein Design Contest）**——這直接通往 2024 年的諾貝爾獎（見 [2024-貝克與蛋白質設計](2024-貝克與蛋白質設計.md)）。 |

## 調查

**偵查一：復性實驗——把折疊「拆開再裝回去」。**

安芬森的實驗設計是 20 世紀生物化學最乾淨的實驗之一：

$$\text{天然 RNase A} \xrightarrow{\ 8\ \mathrm{M}\ \text{尿素}\ +\ \text{β-巰基乙醇}\ } \underbrace{\text{完全變性、還原的 RNase}}_{\text{活性} \approx 0}$$

$$\text{變性 RNase} \xrightarrow{\text{除去尿素、氧化}} \underbrace{\text{天然 RNase}}_{\text{活性} \approx 100\%}$$

**關鍵在於最後一步不需要任何「模板」**：只要環境恢復，蛋白質就自己折回原來的形狀。**「資訊只存在於序列之中」——這就是安芬森法則（Anfinsen's dogma）。**

**偵查二：次序實驗——決定性的一步。**

復性實驗仍可能被質疑：「會不會是某個特定的『折疊中間體』在幫忙？」安芬森與同事用同位素標記做了關鍵實驗：

- 在**還原態**下，把 4 對半胱胺酸以**隨機配對**的方式重新氧化成二硫鍵（例如本該配對的 $26$ 與 $84$ 卻配成 $26$ 與 $117$）；
- 若「形狀需要特定配對」，則亂配的分子會得到**活性很低**；
- 實測：**亂配的分子活性約為天然分子的 5–10%**——**不為零**！

**結論：特定的二硫鍵配對不是折疊的「必要條件」，而是「最穩定的結果」。**序列本身提供了足夠資訊，使蛋白質傾向於形成天然的那個配對。

**偵查三：單一胺基酸置換——功能的原子對應。**

以 RNase A 為例（安芬森實驗室與後續工作）：

$$\text{第 121 位} = \text{異白胺酸} \xrightarrow{\text{置換}} \text{第 121 位} = \text{半胱胺酸} \;\Longrightarrow\; \text{活性} \downarrow \ (\text{立體干擾})$$

**「序列中的一個字母 ↔ 結構中的一個位置 ↔ 功能中的一個開關」——三層一一對應**。

**偵查四：物理化學的量測能力。**

摩爾與斯坦的貢獻，是提供了判定「構形變化」的定量工具：

$$\text{測量} : \ \text{沉降} (S,\ D) + \text{擴散} + \text{旋光} + \text{紫外吸收} + \text{黏度} + \text{光散射}$$

$$\text{由 } \frac{s}{D} = \frac{M(1-\bar{v}\rho)}{RT} \text{ 得 } M;\quad \text{由 } \theta \text{ 與 } [n] \text{ 得構形與螺旋含量}$$

**正是這些物理化學量測，讓「變性／復性」成為可量化的科學事實**，而非「看起來活性回來了」。

**偵查五：摩爾—斯坦的胰蛋白酶水解法——序列分析的另一條路。**

摩爾與斯坦在 1950 年代發展的**胰蛋白酶水解胜肽的分離與定量測定**，是桑格定序的重要補充（桑格用 N 端降解，摩爾—斯坦用 C 端片段分析），兩者的**交叉驗證**提高了序列判定的可靠性。

## 理論裁決

**判決一：安芬森法則。**

$$\boxed{\text{蛋白質的天然構形} \text{ 是其胺基酸序列所決定的自由能最低的構形（在適當環境下）}}$$

其物理內容可用統計力學表述：

$$\Delta G_{\text{fold}} = \Delta H - T\Delta S, \qquad \Delta G_{\text{fold}} < 0 \ (\text{摺疊有利})$$

**在生理條件下，序列所隱含的「摺疊偏好」總和，使天然構形成為全域（global）最低自由能態。**這就是「熱力學假說（thermodynamic hypothesis）」。

**判決二：科恩的模型——摺疊是搜尋。**

安芬森的法則被戴維·科恩（David Kaeb）與比奧里提出的「**漏斗模型（funnel model）**」具體化：

$$\text{未摺疊態（巨大熵）} \to \text{摺疊中間態} \to \text{天然態（最低自由能）}$$

**能量與熵的競爭形成漏斗**：序列提供局部偏好（局部 $\alpha$ 螺旋、轉角偏好），把搜尋空間大幅壓縮——這解釋了為何**蛋白質能在毫秒內摺疊完成**（「利文索爾悖論」，Levinthal, 1969）。

**判決三：環境的必要性與錯誤摺疊疾病。** 安芬森的法則有重要的限定條件：

$$\text{「序列決定構形」} \;\Rightarrow\; \text{「環境決定序列能給出哪個構形」}$$

- **溫度、pH、離子、伴護分子**都影響摺疊；
- **錯誤摺疊**會導致疾病：鐮刀型貧血（見 [1954-鮑林與化學鍵](1954-鮑林與化學鍵.md)）、阿茲海默症的 $\mathrm{A}\beta$ 纖維、帕金森症的 $\alpha$-突觸核蛋白——**「構形病理學」**成為一整類疾病機制。

**判決四：可設計性的開端。** 若序列決定構形，則反過來：**可以設計序列來得到想要的構形。**安芬森在 1970 年代已明確提出此目標，並於 1996 年推動首屆蛋白質設計競賽（以計算設計的序列在實驗室中摺疊並展現功能）。

$$60\ \text{年之後：} \quad \underbrace{\text{安芬森的目標}}_{\text{設計序列}} \xrightarrow{} \underbrace{\text{AlphaFold2 預測結構}}_{\text{2024}} + \underbrace{\text{設計工具}}_{\text{Rosetta/蛋白質設計競賽}} \xrightarrow{} \underbrace{\text{人工設計的酵素}}_{\text{2024 年諾貝爾獎}}$$

**2024 年的化學獎（貝克、哈薩比斯、江珀）正是這條線的集結點**（見 [2024-貝克與蛋白質設計](2024-貝克與蛋白質設計.md)）。

## 後果

| 領域 | 影響 |
| --- | --- |
| 分子生物學 | 「序列 → 構形 → 功能」成為中心法則的核心鏈條；蛋白質摺疊研究（摺疊漏斗、分子伴護蛋白 HSP70/HSP90、核糖體生成與摺疊的分工）成為結構生物學的主流。 |
| 醫學 | 「構形病理學」——鐮刀型貧血、阿茲海默症、帕金森症、杭氏症等的分子機制，皆以此模型解釋；蛋白質錯誤摺疊的藥物研究（如今天的 misfolding 抑制劑）由此起步。 |
| 生化技術 | 蛋白質復性與重組（**蛋白質工程的第一課**）；「序列化學（sequence-based engineering）」今日是酵素與抗體工程的核心。 |
| 蛋白質設計 | 1996 年起的蛋白質設計競賽、Rosetta 設計工具、AlphaFold 的結構預測——一路通向 2024 年諾貝爾獎。 |
| 科學制度 | 摩爾與斯坦的合作（37 年的共同研究、12 年的「星期三會議」）被譽為科學協作的典範；他們共同獲獎，是諾貝爾獎史上少數由「長期合夥」共享的案例。 |
