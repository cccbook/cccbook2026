# 1911 · 居禮夫人再獲化學獎：諾獎史上的孤例

> 1911 諾貝爾化學獎：瑪麗·居禮（Marie Curie），表彰鐳與釙之發現、鐳的分離與其化合物研究。至今唯一在兩個不同科學門各獲一次諾獎者

## 案情提要

1903 年她已與皮耶·居禮、貝克勒共享物理學獎（見 [1903-放射性之發現](../物理學獎/1903-放射性之發現.md)）。1906 年皮耶車禍身亡，瑪麗接任其索邦講座——**巴黎大學首位女教授**。她決定完成一件「最枯燥卻最關鍵」的收尾工作：**把鐳做成純金屬**。物理學獎表彰的是「發現」，化學獎表彰的是「證明鐳是一種元素」——按定義，必須有純物質、可稱量、可定原子量。

## 調查過程：噸級礦渣的化學苦役

1. 原料：波希米亞約阿希姆斯塔爾提鈾廠的瀝青鈉礦渣（提鈾後的廢料）。
2. 手段：全手工的分級結晶與沉澱——酸浸、硫化氫分組、氫氧化物分離、碳酸鹽/硫酸鹽循環。
3. 戰果：四年（1898–1902），在漏雨的棚屋裡，從 **8 噸礦渣**煉出 **0.1 克氯化鐳**（RaCl₂，光譜純度極高的晶體）。
4. 收官：1907–1910 與德比埃納合作用汞陰極電解氯化鐳，首次取得**金屬鐳**，並精密測得原子量 225.9（今值 226.03）——元素身分證齊備。
5. 標準化：建立鐳的「居禮」放射性單位與國際鐳標準，巴黎萬國度量衡局的鐳樣本成為全球放療的基準。

## 理論裁決：放射性是原子性質

化學獎判詞的核心命題：放射性的強度只取決於鐳的**量**，與其化學結合狀態（氯化物、硫酸鹽、金屬）無關——

`A ∝ n(Ra)，與化合物種類無關`

這條線性關係宣告：放射性居住在**原子內部**，化學鍵（原子間的電子互動）對它毫無影響。這是「原子內部另有一個世界」最直接的化學證據，直接為 1919 年盧瑟福的核蛻變、1935 年的中子案（[1935-中子的發現](../物理學獎/1935-中子的發現.md)）鋪路。

## 1911 年的另一樁風暴

頒獎同年，法國小報爆出她與物理學家朗之萬的婚外情醜聞（朗之萬有家庭），記者圍堵其宅、右派報紙公開羞辱「外國女科學家」。瑞典科學院有人寫信勸她勿親自領獎。她的回信已成經典：

> 「獎項是頒給科學工作的，與我的私生活無關。」——她仍赴斯德哥爾摩領獎。

（這與 2022 年物理獎貝爾案的當代讀者形成呼應：科學榮譽與人身評價應否分離，至今仍無一致判例。）

## 後果

| 項目 | 內容 |
|---|---|
| 榮譽 | 1903 物理 + 1911 化學；唯一雙科學門得主（鮑林獲化學 1954 與和平 1962，屬不同性質） |
| 家族 | 五座諾獎：夫妻 1903、她 1911、女兒伊雷娜與女婿 1935（見 [1935-人工放射性](1935-人工放射性.md)） |
| 產業 | 鐳療法商業化；居禮夫人本人拒絕申請製程專利 |
| 代價 | 長期輻射暴露，1934 年死於再生不良性貧血；筆記本至今仍具放射性，需鉛盒保存 |
| 教育界 | 一戰組建「小居禮」流動 X 光隊，親自駕車上前線（逾百萬人次照射） |
