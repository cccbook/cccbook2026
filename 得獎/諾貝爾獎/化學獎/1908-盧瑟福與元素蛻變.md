# 1908 · 盧瑟福與元素蛻變

> 1908 諾貝爾化學獎：歐內斯特·盧瑟福（Ernest Rutherford，1871–1937，紐西蘭／英國）——表彰「其對元素蛻變之研究，以及放射性物質之化學」。物理學家領走化學獎，因為他判決了一樁化學的宿命懸案：原子能否改變。

## 懸案（案情提要）

1896 年貝克勒（Becquerel）發現鈾鹽自行放出穿透射線；居里夫婦分離出釙與鐳（見 [1911-居里夫人與0.1克鐳](1911-居里夫人與0.1克鐳.md)）。到 1900 年，放射性已是公認的現象，卻沒有任何人能回答它的**本質**問題：

1. **能量從哪來？** 鐳標本就這樣日夜不停地發熱，比同質量的任何化學反應猛烈百萬倍，卻不見消耗。開爾文勳爵（Lord Kelvin）以此論證地球與太陽都只有幾千萬年壽命——與達爾文演化所需的億年正面衝突。
2. **元素能改變嗎？** 自拉瓦錫以來，「元素不可轉變」是化學的第一憲法條文。但放射性樣本會不斷長出新的「雜質」：釙會變、釷會析出氣態的射氣——難道一種元素正在**變成另一種元素**？這在當時聽起來像煉金術復辟，是學術上的自殺主張。

一位從紐西蘭來的年輕物理學家，帶著化學家索迪（Frederick Soddy），在蒙特婁的麥吉爾大學地下室裡，把這樁「煉金術懸案」辦成了現代原子科學的立案卷宗。

## 調查

**偵查一：半衰期的誕生——時間的指紋。**

1900–1903 年，盧瑟福與歐文斯對釷射氣做了關鍵測量：不論樣本多大多小，放射性強度**減半所需的時間恆定**（釷射氣約 $54.5\ \mathrm{s}$；論文記 111.5 s 是由於當時測定條件，後世修訂為約 55 秒）。盧瑟福為此現象創造了「半衰期」（half-life）一詞。這指向一個數學上極端乾淨的定律——每一個原子隨時以**固定機率**自行瓦解：

$$\frac{dN}{dt} = -\lambda N$$

其中 $N$ 是放射性原子數、$\lambda$ 是蛻變常數。積分得**衰變律**：

$$N(t) = N_0\, e^{-\lambda t}$$

半衰期由此定義：

$$t_{1/2} = \frac{\ln 2}{\lambda} \approx \frac{0.693}{\lambda}$$

平均壽命 $\tau = 1/\lambda$。這條指數律是**一級反應動力學**（見 [1901-凡特荷夫與物理化學](1901-凡特荷夫與物理化學.md)）的純種案例，但它管轄的不是分子碰撞，而是原子核的命運——單原子、無干擾、不可阻擋。取對數 $\ln N = \ln N_0 - \lambda t$，直線斜率即 $\lambda$，放射性成為第一種可以用鐘錶量測原子內部過程的方法。1904 年起，它也給了地球科學一把地質時鐘。

**偵查二：蛻變系譜——元素在鏈上排隊自殺。**

索迪把釷樣本化學純化後，放射性幾天內「復活」——母體不斷生出子體。盧瑟福與索迪 1902–1903 年發表《放射性變化及其原因》《放射性變化定律》，提出**蛻變理論**：

1. 放射性原子自發瓦解，產生**化學性質全新的**子體元素；
2. 每次瓦解發射 $\alpha$ 或 $\beta$ 粒子；
3. 子體若仍放射性，繼續瓦解，形成**蛻變系**（釷系、鈾系、錒系）。

以釷系為例（今記法）：$^{232}\mathrm{Th} \rightarrow \cdots \rightarrow ^{220}\mathrm{Rn}\ (\text{射氣}) \rightarrow ^{216}\mathrm{Po} \rightarrow \cdots \rightarrow ^{208}\mathrm{Pb}$。化學性質隨鏈上位置突變——鹼土變惰性氣體、惰性氣體變金屬——這是元素「可變」的直接化學證詞。

**偵查三：$\alpha$ 粒子的驗明正身。**

1907–1909 年，已移教曼徹斯特的盧瑟福與蓋革以電離室＋硫化鋅閃爍屏計數 $\alpha$ 粒子：總電荷除以粒子數得每粒電荷 $+2e$；再與羅伊茲（Royds）讓 $\alpha$ 粒子穿入薄窗抽真空管、累積數日後點燃放電，光譜赫然是**氦**——$\alpha$ 粒子即氦原子核 $^{4}\mathrm{He}^{2+}$。這也解開了拉姆齊（見 [1904-拉姆齊與稀有氣體家族](1904-拉姆齊與稀有氣體家族.md)）礦石中氦的來源之謎：地殼裡的氦就是億萬年 $\alpha$ 蛻變的存貨。

**偵查四：能量帳本。**

蛻變常數雖小，能量帳卻驚人：一克鐳全蛻變釋出約 $2 \times 10^{10}\ \mathrm{J}$，是等量碳燃燒的百萬倍量級。1904 年盧瑟福據此當面回敬開爾文：放射性給了地球與太陽遠超化學能的熱源，地質與演化的時間尺度得以成立——克爾文地球年齡案就地翻案。

## 理論裁決

**判決一：原子可變——憲法條文廢止。** 自拉瓦錫以來不可侵犯的「元素不滅不變」被判決為**限縮條款**：化學反應不改變元素，但放射性是**原子核**層級的事件，核蛻變可以把一種元素變成另一種。煉金術士轉變元素的夢想被裁定「在核層級為真、在化學層級為不可能」——化學與核物理自此分疆。

**判決二：放射性是一級隨機過程。** 衰變律 $N = N_0 e^{-\lambda t}$ 是純機率律：特定原子何時瓦解不可預測，統計行為卻嚴格指數。盧瑟福、蓋革與貝特曼 1910 年證明 $\alpha$ 計數服從**卜瓦松分布**——放射性成為隨機過程數學進入物理學的案例，也成為考古定年（$^{14}\mathrm{C}$，$t_{1/2} = 5730\ \mathrm{yr}$，見 [1960-利比與碳-14定年](1960-利比與碳-14定年.md)）與同位素地質學的理論母法。

**判決三：蛻變系與位移律的前奏。** 盧瑟福—索迪的系譜法確立「$\alpha$ 衰變使原子量減 4、$\beta$ 衰變不變原子量」的經驗規則，日後由法揚斯（Fajans）與索迪正式寫成**位移律**，直接催生同位素概念（見 [1921-索迪與同位素](1921-索迪與同位素.md)）。

**餘案（本案之外的最高裁決）：原子核。** 1909 年蓋革—馬斯登受盧瑟福指點的 $\alpha$ 散射實驗發現極大偏轉角——「就像用 15 吋砲彈轟紙，砲彈彈回來打中你」。1911 年盧瑟福據此提出**原子核模型**：原子質量與正電荷集中於極小核心。1919 年他以 $\alpha$ 轟擊氮完成首例人工核反應 $^{14}\mathrm{N} + \alpha \rightarrow\ ^{17}\mathrm{O} + \mathrm{p}$，並命名質子；1920 年預言中子（1932 年查兌克證實）。這是「元素蛻變」案卷裡寫得最深的一頁，卻是以物理學獎與物理學系譜結案的。

## 後果

| 領域 | 影響 |
| --- | --- |
| 核物理建國 | 半衰期、蛻變系、$\alpha$ 證身、原子核——本案是核物理的全部立案基礎；查兌克（中子）、考克饒夫與瓦爾頓（擊破原子核）皆出自其門下。 |
| 地球科學 | 放射定年把地球年齡從「數千萬年」拉到 45 億年量級；演化論與地質學的時間帳目全部重算。 |
| 醫學 | 放射性同位素療法與示蹤技術的源頭——其學生德海韋西以示蹤法獲 1943 年化學獎。 |
| 能源史 | 1933 年盧瑟福「任何人談從原子轉變取能都是在說月亮上的事」（moonshine）的譏評，恰好刺激西拉德構想鏈式反應——一句反話成為核能時代的引信。 |
| 化學獎譜系 | 本案是化學獎罕見地承認「化學的邊界被物理改寫」；索迪（1921）、哈恩（1944 核分裂）、約里奧-居里夫婦（1935 人工放射性）皆沿此卷宗續辦。 |
| 象徵 | 1997 年第 104 號元素命名 rutherfordium（$\mathrm{Rf}$）；紐西蘭 100 元鈔票印其肖像。 |
