# 1914 · 理查茲與精密原子量

> 1914 諾貝爾化學獎：西奧多·威廉·理查茲（Theodore William Richards，1868–1928，美國）——表彰「其對大量化學元素原子量的精確測定」。第一位獲諾貝爾化學獎的美國科學家。

## 懸案（案情提要）

原子量是整座化學的度量衡基準：化學方程式的係數靠它、氣體常數靠它、門得列夫週期表的排列靠它、藥廠配料的帳靠它。但十九世紀末的實際狀況是——**全世界的原子量表彼此對不上**：

- 氧有 15.94、15.96、16.00、16.03 等多個版本；
- 氯是 35.2、35.45 還是 35.5？差 0.3% 就是三個不同的答案；
- 同一元素由不同人測定，結果可差半個百分點以上。

而問題不只是「小數點後的爭執」。原子量若有 $0.1\%$ 誤差，所有摩爾數、所有產率、所有平衡常數都跟著偏；1890 年代德國化學界甚至分裂成「嚴格派」與「概略派」吵不完。更糟的是：**没有人说得清这些差异到底来自哪里**——是元素本身不纯？化合物含水？仪器有误差？还是……原子量根本不是唯一值？

理查茲接下這樁「度量衡懸案」，做法與所有前人不同：他不去爭論，而是**把錯誤來源一個一個消掉，然後把數字做到別人無法挑剔**。

## 調查

**偵查一：把錯誤來源逐條列印（偵查守則）。**

理查茲首先建立「可疑來源清單」，再一一以實驗設計排除：

| 可疑誤差源 | 理查茲的排除手法 |
| --- | --- |
| 試藥不純 | 所有試藥自行再純化、熔點與沸點雙重驗證 |
| 結晶水未除盡 | 樣品在乾燥器中恆重（連續兩次稱量差 $< 0.1\ \mathrm{mg}$）才啟用 |
| 容器吸附／反應不完全 | 反應後產物須「再熔、再沉澱」直至恆重 |
| 揮發損失 | 採用封閉玻璃管操作（後來所謂「熔封法」），蒸發損失以空白試驗校正 |
| 稱量時空氣浮力 | 對所有物件作**浮力校正**：$m_{\text{真}} = m_{\text{視}}\left(1 - \dfrac{\rho_{\text{空氣}}}{\rho_{\text{樣}}}\right)$ |
| 銀的吸附（微量殘留） | 避免使用銀製器皿，改用石英與鉑製品 |
| 人為湊整 | 廢棄「化學原子量」慣例，改用**原子量基準 O = 16** 的相對標度 |

**偵查二：雙路徑交叉驗算（本案的核心技術）。**

理查茲不肯讓任何一個原子量建立在單一條路徑上。以溴為例，他走兩條完全不同的路：

- 路徑 A：$\mathrm{AgNO_3}$ 沉澱出 $\mathrm{AgBr}$，稱重、還原成 $\mathrm{Ag}$ 再稱重；
- 路徑 B：$\mathrm{Cu}$ 與 $\mathrm{Br_2}$ 直接生成 $\mathrm{CuBr_2}$，再以金屬銅還原。

兩條路給出同樣的溴原子量（誤差 $<0.01\%$）——**雙證一致才能定案**。這套「雙路徑驗算」後來成為原子量工作的標準程序。

**偵查三：氫的 $0.8\%$ 缺口——全案的引爆點。**

1910 年前後，理查茲以極精密的天平燃燒純氫於純氧中，測定生成水的質量：

$$\mathrm{H_2} + \frac{1}{2}\,\mathrm{O_2} \rightarrow \mathrm{H_2O}$$

取 $\mathrm{O} = 16.000$，反推得氫的原子量：

$$A_r(\mathrm{H}) = A_r(\mathrm{O})\cdot\frac{M(\mathrm{H_2O}) - A_r(\mathrm{O})}{2\,A_r(\mathrm{O})} \approx 1.008$$

**不是 1.000。** 差 $0.8\%$。這正是普勞特假說（所有元素的原子量皆為氫的整數倍）最頑固的漏洞，也是後來「同位素」概念的入口：若氫有兩種（同位素），加權平均自然不是整數。此缺口由 1913 年起索迪（見 [1921-索迪與同位素](1921-索迪與同位素.md)）與拉姆齊等人接手。

**偵查四：統計裁定——什麼數字才算數。**

面對同一元素的十幾次測定值，理查茲採用**加權平均**並剔除離群值：

$$A_r(\text{最終}) = \frac{\sum_i w_i A_r^{(i)}}{\sum_i w_i}, \qquad w_i \propto \frac{1}{\sigma_i^2}$$

並公開全部原始數據與差異，讓他人可以重算。他的名言式原則：**「元素沒有原子量這回事；有的只是測量值。」**（Every element has several atomic weights, depending on the method; the true value is that which is approached by best methods.）

## 理論裁決

**判決一：原子量的定義與基準。** 理查茲時代的共識被固定下來：

$$A_r(X) = \frac{m(X)}{m(\text{單位})}, \qquad A_r(\mathrm{O}) = 16.000 \ (\text{1913–1960 年的基準})$$

這一定義在 1961 年改為以 $^{12}\mathrm{C}$ 為基準 $A_r({}^{12}\mathrm{C}) = 12$（原子量單位 u 的出現），但理查茲確立的「**基準必須有可操作定義**」精神延續至今。

**判決二：誤差預算的物理學。** 理查茲證明：原子量的不確定度可以分解為若干可量測項，並以下式估算總和：

$$\frac{\Delta A_r}{A_r} \approx \sqrt{\left(\frac{\Delta m}{m}\right)^2 + \left(\frac{\Delta M_{\text{反應}}}{M_{\text{反應}}}\right)^2 + \cdots}$$

其結論令人吃驚：主限制不是天平的靈敏度（$0.01\ \mathrm{mg}$ 已足夠），而是**化學操作本身的不完美**——稱量只是次要矛盾。這個判斷徹底改變了後世測定策略：花大力氣提純樣品，比多買一台好天平有效得多。

**判決三：純度是量的最高形態。** 理查茲與同事證明：極純物質的物理常數會「收斂」——樣品愈純，不同批次測得的原子量愈接近。此結論在 1960–70 年代被半導體產業用矽同位素再次證實（純度極高的 $^{28}\mathrm{Si}$ 晶格常數與雜質樣品差異顯著），可謂理查茲方法論的產業級復刻。

**副案：化學熱力學的溫床。** 原子量精度提升，使燃燒熱、生成焓、鍵能等數據才有意義——理查茲的實驗室成為美國化學熱力學的發源地，後來奧斯特華德、能斯特、能斯特方程的數據基礎多出於此。

## 後果

| 領域 | 影響 |
| --- | --- |
| 測量觀念 | 「精確測定 + 雙路徑驗算 + 公開原始數據」成為物理化學的標準倫理；理查茲的實驗室被譽為美國科學的模範。 |
| 同位素 | 氫原子量 $1.008$ 的缺口是同位素理論的直接線頭；1913 年莫斯萊以 X 射線譜證實原子序與原子量的關係（發現 $A_r$ 隨 $Z$ 上升但有跳躍），並與拉姆齊的稀有氣體（見 [1904-拉姆齊與稀有氣體家族](1904-拉姆齊與稀有氣體家族.md)）發現共同構成「氬-鉀-鈣」反常的解謎材料。 |
| 工業 | 精確原子量使藥物劑量、化工配方的算量可靠；哈伯法所需的高純氮氣與氫氣也依賴同樣的純度觀念。 |
| 制度 | 理查茲長期擔任國際原子量委員會委員（主席），使「定期重算原子量表」成為一項持續的國際義務。 |
| 科學史地位 | 第一位獲諾貝爾化學獎的美國人（1914）；也是美國物理化學的開路人，其學生包括哈佛的哈伯（1918 年化學獎）、范特荷夫式的溶液理論推手之一。 |
