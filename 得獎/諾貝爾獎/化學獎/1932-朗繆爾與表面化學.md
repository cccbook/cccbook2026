# 1932 · 朗繆爾與表面化學

> 1932 諾貝爾化學獎：艾文·朗繆爾（Irving Langmuir，1881–1957，美國）——表彰「其對表面化學之發現與研究」。他把「表面」從物體的邊緣，提升為化學與物理的獨立戰場，並在通用電氣公司內建起史上第一個企業研究實驗室。

## 懸案（案情提要）

1910 年代有三樁懸案，都圍著「表面」打轉：

1. **薄膜之謎**：肥皂泡、脂肪酸在水面上的油膜，薄到某個極限就破裂。**這層膜到底有多厚？是不是只有一個分子那麼厚？**如果只有一個分子厚，那麼分子的「體積」就能從面積直接量出來——這是通往分子尺度的捷徑，但沒有人做得到這種量測。
2. **催化之謎**：為什麼某些固體表面（鉑、鎳、鐵）能讓氣體反應加速，而同樣的元素溶解成鹽卻毫無催化性？**表面到底提供了什麼？**催化劑的「表面積」是不是關鍵變數？
3. **原子之謎**：1916 年路易士提出八隅體與立方原子模型，科塞爾提出價鍵理論——**誰對？**朗繆爾在 1919 年發表「原子與分子中電子的排列」，把路易士的模型推廣成完整模型，並因此捲入一場優先權之爭（本案中的「附帶戰爭」，他最終承認功績主要屬於路易士）。

偵辦人：艾文·朗繆爾——奇異公司（GE）工程師出身、自學成材的表面科學先驅。

## 調查

**偵查一：單分子層的量測——把不可見變成可見。**

朗繆爾的膜天平是本案的第一件凶器：在水面上放一道可移動的柵欄，把溶於苯的脂肪酸滴在水面，脂肪酸展開成薄膜；用天平測量**表面壓力** $\pi$（單位面積的表面自由能變化）隨可用面積變化的關係。

若薄膜是一個**單分子層**，每個分子占的面積 $\sigma$ 應為定值。1917 年朗繆爾以硬脂酸（$\mathrm{C_{17}\mathrm{H}_{35}\mathrm{COOH}$）實驗，得到：

$$\sigma \approx 20\ \text{Å}^2/\text{分子} \quad (20 \times 10^{-20}\ \mathrm{m^2})$$

**這個數字與今日的分子直徑估計完全一致**——單分子層的存在由此被「看見」，分子尺度的面積第一次被量出。

**偵查二：等溫線的數學——吸附的動力學平衡。**

朗繆爾把表面當成「有限座位的集合」：分子可吸附（佔位）、可脫附（讓位），兩者速率平衡：

$$\text{吸附速率} = k_a\,p\,(1-\theta), \qquad \text{脫附速率} = k_d\,\theta$$

令兩者相等，得**朗繆爾吸附等溫式**：

$$\boxed{\;\theta = \frac{K\,p}{1 + K\,p}\;}$$

其中 $\theta$ 為覆蓋率、$K$ 為吸附平衡常數、$p$ 為氣體分壓。極限情形：

- $Kp \ll 1$：$\theta \approx Kp$（**低壓線性**，表面多數空置，符合朗繆爾模式）；
- $Kp \gg 1$：$\theta \to 1$（**飽和吸附**，表面被單層覆蓋）；
- 這就是「表面只有一層」的數學表述——催化劑的活性隨表面積而非總量增加。

**偵查三：二維理想氣體方程——表面壓力。**

把吸附層視為二維理想氣體，得到表面壓力與面積的關係：

$$\pi\,\sigma = RT\left(\frac{\theta}{1-\theta}\right) \quad (\text{或}\ \pi A = -nRT\ln(1-\theta))$$

**這是壓縮機與氣體定律的「表面版」**——物質在表面上 behaves like a 2D gas。此式可反解出膜的分子數、面密度，並檢驗「單層」假設。

**偵查四：催化理論——反應在表面發生。**

朗繆爾提出多分子反應（multi-molecular reaction）的表面機構：反應物先在表面吸附（形成活化複合物），再在表面反應，產物脫附。**表面覆蓋率 $\theta$ 因此成為催化劑活性的定量變數**：

$$\text{反應速率} \propto \theta_A\,\theta_B \quad (\text{或}\ \theta_A\,\theta_B\,(1-\theta_C))$$

這解釋了「為什麼催化劑的物理狀態（金屬 vs 鹽、塊狀 vs 分散）會改變活性」——因為改變的是表面積與覆蓋率，而不是元素的化學性質。**表面化學在此正式成為獨立學科。**

**偵查五：原子結構的推進與讓步。**

1919 年朗繆爾把路易士的立方原子擴充為**同心殼層模型**：電子分佈於 $K$、$L$、$M$ 等層，滿殼層為「2、8、8、18……」；他並以此解釋電離能、鹼金屬與鹵族的高度相似性。但他也在 1920 年公開承認：**模型的想法主要來自路易士與科塞爾**，功勞應歸他們——這場優先權之爭最終以朗繆爾的讓步收場（1932 年諾貝爾演講中他也再次澄清）。

## 理論裁決

**判決一：Langmuir 等溫式與「有限座位」語言。** 它的深遠之處不在公式，而在**模型選擇**：把表面當成有限容量的座位集合，而不是無限的連續介質。這使得「吸附飽和」成為可預測的現象，進而解釋：

$$\frac{1}{\theta} = \frac{1}{K\,p} + 1 \quad (\text{線性化，實驗上最常用的檢驗式})$$

**「直線化後是否成直線」是判定模型正確與否的標準檢驗**——這是 Langmuir 模型在百年後仍被引用的原因（多層吸附則需 1938 年的 BET 方程）。

**判決二：二維狀態方程——表面熱力學的語言。** 表面壓力的概念把「界面」提升為獨立的熱力學對象：

$$\text{界面自由能} \; \gamma \;=\; \left(\frac{\partial G}{\partial A}\right)_{T,p,n} \quad (\text{單位 J/m}^2\text{，取代了bulk的壓力概念})$$

由此可定義**表面張力**、**表面熵**、**Marangoni 效應**（表面張力梯度驅動流動，昆蟲爬水面的力學解釋）。

**判決三：覆蓋率作為催化劑設計的變數。** 在朗繆爾框架下，催化劑的選擇不再是「哪種金屬」而是「什麼表面結構與什麼中間體匹配」：

$$\theta_{\text{key}} = \frac{K_{\text{key}}\,p_{\text{key}}}{1 + \sum_i K_i p_i}$$

這套語言在 1960 年代被表面化學的實驗（愛爾蘭、哈明等對 $\mathrm{N_2}$ 在鐵上的解離吸附研究）量化，並在 2007 年埃特爾獲諾貝爾獎的表面化學工作中被推到極致（見 [2007-埃特爾與表面化學](2007-埃特爾與表面化學.md)）。

**判決四：工業研究實驗室的制度發明。** 朗繆爾在 GE 建立的「基礎研究不問近期應用」的實驗室模式，是二十世紀企業研發的原型：**由科學家自由選題、成果回流到產品**。GE 的氣體充填空心燈、鈷絲技術、氟碳化合物與塑膠（其成果含氟冷媒一路通向 2000 年黑格等人的導電聚合物與 2023 年量子點）都出自這套制度。

## 後果

| 領域 | 影響 |
| --- | --- |
| 界面科學 | 表面化學、膠體科學、催化理論、界面張力的定量框架皆在此成型；1930–40 年代的吉布斯吸附等溫式、BET 多層方程、DLVO 理論是主要續篇。 |
| 照明與電工 | 氣體填充燈泡（氬、氪填充）是朗繆爾表面研究的直接商業化；白熾燈的效率因此倍增，現代照明革命的起點。 |
| 奈米薄膜 | 朗繆爾—布羅aget（LB）技術可逐層堆積單分子膜（奈米尺度精確），成為生物感測器、LB 膜光學濾片、化學電子學與藥物包覆的基礎技術；2020 年諾貝爾化學獎的「奈米顆粒」與今日的氧化石墨烯膜都站在這條線上。 |
| 催化工業 | 表面覆蓋率語言滲透入今日的化工設計：氨合成催化劑、汽車排氣淨化（1970 年代起）、燃料電池電極（2010 年代）等皆以「表面中間體的生命週期」描述。 |
| 醫學 | Langmuir 膜模型是理解肺泡表面活性物質（表面活性劑）的基礎；呼吸道生理學用它解釋肺不張的機制。 |
| 科學史地位 | 優先權案例的教材：諾貝爾得主的名字掛在模型上，模型的優先權歸路易士——科學社群如何處理這類案件的一個樣本。 |
