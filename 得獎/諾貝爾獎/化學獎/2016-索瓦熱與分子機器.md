# 2016 · 索瓦熱、斯托達特與費寧加——會動的分子

> 2016 諾貝爾化學獎：讓-皮埃爾·索瓦熱（Jean-Pierre Sauvage，1944– ，法國）、詹姆斯·P·斯托達特（Sir J. Fraser Stoddart，1942– ，英國）與伯納德·費寧加（Bernard L. Feringa，1951– ，荷蘭）——表彰「其對分子機器之設計與合成」。**化學家做出了會動的分子。**

## 懸案（案情提要）

1990 年代的化學，有一個「科學家最想做卻最難做」的東西：

- **機器**由零件組成，靠能量驅動，執行特定的功能——而化學家直到 2010 年代才做出「分子尺度的機器」；
- 具體的目標是：
  1. **旋轉**：分子能否像馬達轉子那樣，**繞一根軸持續單向旋轉**？
  2. **運輸**：分子能否像活塞那樣，在兩個位置之間**來回移動**？
  3. **開關**：分子能否記住資訊並在兩態間切換（分子邏輯）？
- 而困難不在「做出結構」，而在**讓它「動」**：
  - 分子尺度下，熱運動（布朗運動）與摩擦極強，**要讓分子單向轉動，必須精確控制構形，並讓「順時針」與「逆時針」兩條路的能量差足夠大**；
  - 這需要**非對稱性**：若分子的兩側對稱，兩個方向的能障相同，就得到「往返擺動」而非「單向旋轉」。

偵辦人：費寧加（光驅動的分子馬達）、斯托達特（分子機器與分子邏輯）、索瓦熱（旋轉型分子馬達）。

## 前因

| 年份 | 事件 |

| 1960s–80s | 索瓦熱在法國（CNRS，斯特拉斯堡）研究**銅(I) 配合物的模板效應**：**銅(I) 錯合物的配位幾何可以隨配體數目而變**（2 配位為直線、3 配位為平面、4 配位為四面體）——**這是「用金屬離子的配位幾何變化來驅動分子構形變化」的原理**，也是 1983 年「分子機器」思想的源頭。 |
| 1980s–90s | 斯托達特在美國（聖路易斯、UCLA，後於愛丁堡）研究**冠醚與穴狀物**（見 [1987-克拉姆與超分子化學](1987-克拉姆與超分子化學.md)），並發展**「分子識別 → 分子機器」**的思路：若分子能「辨識」另一分子，它就能被「控制」。 |
| 1980s–90s | 索瓦熱（1983）與斯托達特（1984–89）各自獨立提出**旋轉型分子馬達**的概念與模型。 |
| 1990s | **斯托達特**合成**第一代（I、II 代）分子機器**：以**冠醚環**作為「轉子」，以 **$\mathrm{Ferrocene}$（二茂鐵）作為「轉軸」**（見 [1973-菲舍爾與二茂鐵](1973-菲舍爾與二茂鐵.md)）——**二茂鐵的旋轉構形改變，使冠醚的「電荷」改變，進而改變周圍的離子結合位置**。 |
| 1994–1999 | 索瓦熱與其合作者（包括 **David (D.)** 與 **Ronald (R.)**）製備**第一台「真正的」旋轉型分子馬達（molecular motor）**：以 $\mathrm{Cu(I)}$ 與 $\mathrm{Cu(II)}$ 的配位數變化（$\mathrm{2} \leftrightarrow \mathrm{4}$ 配位）驅動一個大環相對於軸的旋轉，並以**核磁共振與質譜**觀測到旋轉。 |
| 1999 | 費寧加在格羅寧根大學研究**光驅動的分子馬達**：1999 年以**光誘導的順反異構化（光致異構化）**驅動「不對稱的烯烔」環的單向旋轉——**這是第一個真正的「單向」分子馬達**（此前多為往復擺動）。 |
| 2000s | 費寧加團隊不斷提高馬達的轉速與效率；**2010 年**實現了**能在液態環境中運作的單向馬達**，並證明其**能做功（against a load）**。 |
| 2000s | 斯托達特團隊做出**分子升降機（molecular lift）**、**分子車（molecular car）**、以及**分子邏輯門（molecular logic gate）**；2011 年並與其合作者共同完成可「儲存資料」的**分子機器**（用於製造「分子記憶體」的原型）。 |
| 2016 | 三人共享諾貝爾化學獎。 |

## 調查

**偵查一：光馬達——「把光變成單向運動」。**

$$\text{起始態（順式烯烔）} \xrightarrow{h\nu\ (\text{紫})} \text{異構態（反式烯烔）} \xrightarrow{h\nu\ (\text{可見）}} \text{另一異構態}$$

$$\text{在分子的「軸」上接一個不對稱的「轉子」（stator）} \Rightarrow \textbf{每一次光異構化都使轉子前進固定的角步}$$

$$\text{單向性的來源}：\ \underbrace{\text{不對稱的立體化學}}_{\text{使兩個異構態的能量不同}} + \underbrace{\text{可逆的循環}}_{\text{光異構化 + 熱弛豫}}$$

$$\boxed{\text{分子馬達} = \text{能階不對稱的循環} \times \text{循環閉合（避免回退）}}$$

**「分子尺度的馬達」需要「循環不可逆」——這與化學中的「可逆反應」背道而馳，是本案最深刻的思想。**

**偵查二：銅(I)/銅(II) 的配位幾何變化——「用金屬當齒輪箱」。**

$$\mathrm{Cu(I)}：\ \text{配位數 2（直線）、3（平面）、4（四面體）};\qquad \mathrm{Cu(II)}：\ \text{配位數 4（平面或四方錐）、5}$$

$$\text{因此}：\ \text{改變金屬的氧化態} \xrightarrow{} \text{配位幾何改變} \xrightarrow{} \text{大環相對軸的旋轉/伸缩}$$

$$\text{索瓦熱的模板效應}：\ \text{以} \mathrm{Cu(I)}\ \text{作為「模板」使兩個配體靠近，使其可以進行模板合成（template synthesis）}$$

**「金屬離子的配位幾何是分子機器設計的『力學原理』」——這是超分子化學走入金屬有機化學的關鍵一步。**

**偵查三：旋轉型馬達——「整圈」與「半圈」的差別。**

$$\text{第一代（I、II 型）：}\ \text{以} \mathrm{Cu(I)/Cu(II)}\ \text{的配位數變化驅動} \Rightarrow \textbf{360° 旋轉}$$

$$\text{第二代（III 型，2009–）：}\ \text{以} \mathrm{Cu(I)/Cu(II)}\ \text{配位數變化驅動} \Rightarrow \textbf{180° 旋轉（兩個半圈）}}$$

$$\text{旋轉速率}：\ \text{第一代} \sim 10^4\ \mathrm{s^{-1}};\quad \text{第二代} \sim 10^6\ \mathrm{s^{-1}}\ (\text{量測極限})$$

**「『半圈』的設計使反轉的過渡態被繞過」——這是機械工程原理在分子尺度的應用。**

**偵查四：分子邏輯——「用分子做布林運算」。**

$$\text{斯托達特團隊}：\ \text{以} \textbf{冠醚的陽離子選擇性} \text{作為輸入，以} \text{機械互鎖（mechanical interlocking）} \text{作為邏輯閘}$$

$$\text{機械互鎖（mechanically interlocked molecules）}：\ \text{套環（rotaxane）與} \ \text{環軸（catenane）}$$

$$\text{旋轉軸}（\text{rotaxane}）：\ \text{一個「環」套在一個「軸」上，軸上兩端的 bulky 基團防止環脫出}$$

$$\text{環軸（catenane}）：\ \text{兩個環互扣}$$

$$\text{用途}：\ \text{分子開關}、\ \text{分子邏輯門（AND、OR、NOT）}、\ \text{分子記憶體（以「位置」儲存位元）}$$

$$\boxed{\text{「分子計算」的實例}：\ \text{2011 年的分子機器被用來製造} \textbf{分子記憶體}\text{，並在} \ 40\ \text{個位元層級做邏輯運算}}$$

**偵查五：「動態立體化學」的誕生。**

$$\text{傳統立體化學}：\ \text{研究靜態構形的關係}$$

$$\text{動態立體化學（dynamic stereochemistry）}：\ \text{研究} \textbf{運動}\text{（構形變化、旋轉、翻轉）及其立體化學後果}$$

$$\text{2016 年諾貝爾獎講座}：\ \text{「立體化學不只是靜態的形狀，更是} \textbf{動態的過程}\text{」}$$

## 理論裁決

**判決一：分子機器與巨分子的分界。**

$$\boxed{\text{巨分子}（\text{大、靜態、功能由結構決定}）\;\neq\;\text{分子機器}（\text{可動、功能由運動決定}）}$$

$$\text{分子機器的三要件}：\begin{cases}\text{① 兩個（或多個）可相對運動的部件}\\ \text{② 一個能控制相對運動的「驅動」}\\ \text{③ 一個使循環閉合、產生單向運動的「不對稱性」}\end{cases}$$

**這三要件正是自然界的機械設計原則**——**分子機器是「機械工程」在化學尺度上的實現**。

**判決二：單向性的能量學。**

$$\text{循環}：\ A \xrightarrow{\Delta G_1} B \xrightarrow{\Delta G_2} A' \xrightarrow{\Delta G_3} B' \xrightarrow{\Delta G_4} A$$

$$\boxed{\text{淨功} = \sum_i \Delta G_i \neq 0 \quad\Longleftrightarrow\quad \text{單向運動}}$$

$$\text{若} \sum_i \Delta G_i = 0 \Rightarrow \text{只有往返擺動，沒有馬達}$$

**「打破循環的時間反演對稱性」是製造馬達的根本條件**——這與物理學的「耗散結構」概念相通（見 [1977-普里高津與耗散結構](1977-普里高津與耗散結構.md)）。

**判決三：光驅動的必要性——「光子是唯一能打破平衡的『燃料』」。**

$$\text{化學燃料（ATP 等）}：\ \text{需消耗化學能，且需外部酵素系統}$$

$$\text{光}：\ \text{直接、可控、可定址（照射哪裡就驅動哪裡）、}$$

$$\boxed{\text{光驅動是分子馬達最理想的動力來源}}$$

**「光驅動的分子馬達」今日被認為是「分子機器走向奈米機器」最現實的路線**——因為它不需要化學燃料的輸送系統。

**判決四：機械互鎖的拓撲學意義。**

$$\text{套環（rotaxane）}：\ \text{「環」與「軸」的} \textbf{機械互鎖}\text{不可分解（topologically）}$$

$$\text{因此}：\ \text{它不是「分子間的弱作用」} \xrightarrow{} \textbf{「機械鍵」（mechanical bond）}}$$

$$\text{「機械鍵」與共價鍵、氫鍵並列，是} \textbf{化學鍵的第三種類別}$$

**這是超分子化學的觀念性擴張**（承接 [1987-克拉姆與超分子化學](1987-克拉姆與超分子化學.md)），並在 2016 年的諾貝爾講座中被明確表述。

## 後果

| 領域 | 影響 |
| --- | --- |
| 超分子化學 | 從「識別與結合」擴張到「組裝與運動」；機械鍵成為分子科學的基本概念。 |
| 奈米科學 | 分子馬達與分子馬達陣列被視為「奈米機器人」的先驅；費寧加的 2017 年諾貝爾演講（**"The art of building small"**）明確指向此方向。 |
| 資訊科學 | 分子邏輯與分子記憶體，是「分子計算」的先驅實驗。 |
| 醫學 | 分子馬達模型被用於理解**肌球蛋白（myosin）、驅動蛋白（kinesin）、ATP 合成酶的旋轉**（見 [1997-博耶與ATP合成酶](1997-博耶與ATP合成酶.md)）——「生命本身就有分子馬達」。 |
| 科學史 | 斯托達特是「從基礎化學到藝術」的跨界人物（他的分子模型也是藝術品）；索瓦熱是「配位化學驅動機器」的倡導者；費寧加是「光驅動」路線的開拓者。 |
