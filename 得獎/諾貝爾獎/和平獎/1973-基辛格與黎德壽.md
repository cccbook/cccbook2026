# 1973 · 基辛格與黎德壽：史上最爭議的一屆——得主之一拒領

> 1973 諾貝爾和平獎：亨利・基辛格（Henry Kissinger，美國國務卿）；黎德壽（越南民主共和國）——巴黎和平協定的兩位主要談判者。破的是一樁「拒領案」：得主之一黎德壽**拒絕領獎**，另一位得主在轟炸仍在進行時得獎——本屆被廣泛認為是和平獎史上最具爭議的判決。

## 懸案（案情提要）

1969–1973 年，基辛格同時主持美國在越南的戰爭擴大化（轟炸柬埔寨、老撾）與秘密談判。1973 年 1 月《巴黎和平協定》簽署，美軍撤離，越戰停火。10 月，委員會把獎發給兩位談判代表——黎德壽拒領，聲明和平尚未實現（戰爭在 1975 年才真正結束）。美國國內兩名委員會委員辭職抗議。

案子懸在這裡：**得主拒領＋得主同時是戰爭的執行者**——這是和平獎結構性矛盾的極端案例。此後凡是「政治家得主」的爭議（2009 歐巴馬）都會被對照本屆。

## 前因

| 年份 | 事件 |
|------|------|
| 1913 | 基辛格生於德國，1938 年移民美國。 |
| 1969 | 任美國國家安全顧問；秘密訪華、訪蘇。 |
| 1969–72 | 越南戰爭擴大化：轟炸柬埔寨、老撾。 |
| 1972 | 秘密談判持續；十二月轟炸河內。 |
| 1973 | 《巴黎和平協定》簽署；任國務卿。 |
| 1973 | 10 月獲和平獎；黎德壽拒領。 |
| 1975 | 越南統一，戰爭終於結束。 |
| 2023 | 基辛格逝世，享年 100。 |

## 調查

**第一步：核對「談判與轟炸」的並行。**
基辛格的技術是**兩手並用**：談判桌上討價還價，戰場上保持軍事壓力。這在談判學上是有效策略，在和平獎評選上是致命爭議——**同時主持戰爭與和平談判的人可否得獎**成為此後的標準質疑。

**第二步：核對黎德壽的拒領。**
黎德壽的聲明直指協定的缺陷：停火不穩定、美軍撤離但南越政權存續、戰俘問題未決。他的拒領是和平獎史上唯一由得主本人宣布的「此獎不合時宜」——**得主成為評選的批評者**。

**第三步：確認委員會的內部裂痕。**
兩名委員公開辭職抗議——這是委員會內部第一次因得主選擇而公開分裂。此後 2009 歐巴馬案時，委員會秘書長也公開表達保留意見。**評選的內部異議成為本屆的持久遺產**。

## 技藝裁決

本屆裁決確立了和平獎的「**爭議上限**」：政治家得主的容忍極限在哪裡。基辛格案表明：談判成就可以被承認，但若談判者同時是戰爭的執行者，獎的公信力會受損。此教訓在 2009 歐巴馬案的「過早頒獎」爭議中被反覆引用——**頒獎時機與得主行為的一致性**成為評選的隱性標準。

## 後果

| 年份 | 影響 |
|------|------|
| 1973 | 黎德壽拒領；兩位委員辭職。 |
| 1975 | 越南統一，戰爭結束，協定內容多被推翻。 |
| 2009 | 歐巴馬獲獎引發「過早」爭議，基辛格案被反覆引用。 |
| 2023 | 基辛格逝世，爭議評價持續。 |
| 至今 | 本屆仍是和平獎史上被引用最多的爭議案例。 |
