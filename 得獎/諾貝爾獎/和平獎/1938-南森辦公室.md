# 1938 · 南森辦公室：難民檔案的第二章，國聯體系的最後一份獎

> 1938 諾貝爾和平獎：南森國際難民辦公室（Nansen International Office for Refugees，國際聯盟）。破的是一樁「機構續卷案」：創辦人南森已在 1930 年去世，機構自己撐了八年，最後在歐洲難民危機最嚴重時獲獎。

## 懸案（案情提要）

1930 年南森逝世後，國際聯盟把他的難民辦公室改組為「南森國際難民辦公室」，繼續發南森護照、協調安置。1930s 的難民問題急劇惡化：俄國難民之後，亞美尼亞人、薩爾人、德國猶太人接連成為無國籍群體。1938 年，委員會把獎發給這個辦公室——**距第二次世界大戰爆發不到一年**。

案子懸在這裡：這是和平獎第一次頒給「救濟難民的機構」，也是國聯體系的最後一份獎（次年停發）。委員會等於在戰爭前夜確認：**難民問題已經成為國際和平的核心議題**。

## 前因

| 年份 | 事件 |
|------|------|
| 1922 | 南森獲獎；南森護照問世。 |
| 1930 | 南森逝世；辦公室改組為「南森國際難民辦公室」。 |
| 1933 | 納粹上台，德國猶太人開始逃亡。 |
| 1935 | 薩爾區公民投票後的難民潮。 |
| 1936 | 南森護照持有人數達高峰。 |

| 1939 | 二戰爆發，和平獎停發。 |
| 1946 | 辦公室工作由國際難民組織（IRO）接手。 |

## 調查

**第一步：核對「繼承」的組織技術。**
辦公室在創辦人去世後繼續運作，靠的是**南森護照的制度延續**：護照的國際承認已成為固定機制，不依賴任何個人。這是「機構比人活得久」的標準案例。

**第二步：核對 1930s 難民問題的擴大。**
從俄國人擴至亞美尼亞人、薩爾人、德國猶太人——難民群體的性質從「戰敗國的流亡者」變成「被政權清除的族裔」。辦公室的技術從**身分證明**擴展到**安置協調**。

**第三步：確認獲獎時機的沉重。**
1938 年埃維安會議上，三十二國代表拒絕增加猶太難民配額——**同一年的獎發給了唯一在做事的機構**。這使本屆判決帶有明顯的抗議色彩。

## 技藝裁決

本屆裁決確立了「**難民救援作為和平技術**」的獨立路線：難民問題不是戰爭的附屬品，而是和平的前提。此路線的後續是 1954 難民署、1958 皮爾、1981 難民署二度獲獎——難民工作成為和平獎的長期支柱。
