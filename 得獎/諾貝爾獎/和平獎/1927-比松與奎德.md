# 1927 · 比松與奎德：一個辦法國成人教育，一個寫《德國軍國主義的起源》

> 1927 諾貝爾和平獎：費迪南・比松（Ferdinand Buisson，1841–1932，法國教育家）；路德維希・奎德（Ludwig Quidde，1858–1941，德國史學家）。破的是一樁「教育和解案」：法德之間的和解，除了條約還需要什麼？答案是兩邊都要有人**改寫教科書與史觀**。

## 懸案（案情提要）

1927 年，委員會把獎拆給兩位「教育系統的人」。比松是法國初等教育的總建築師（朱爾・費里時代的教育官員），一生推動世俗教育與和平教學；奎德是德國史學家，1894 年出版《德國軍國主義的起源》——直接點名德皇是軍備競賽的推手，為此被控叛國而離開德國。

案子懸在這裡：委員會把「法德和解」的獎發給一位法國人與一位**流亡的德國人**，等於承認：和解不能只靠兩國政府，還需要有人先在各自的國家裡**對自己的戰爭史提出批判**。

| 年份 | 事件 |
|------|------|

| 1894 | 奎德出版《德國軍國主義的起源》。 |
| 1895 | 奎德因該書受政治壓力，退出官方活動。 |
| 1898 | 比松參與左拉為德雷福斯案辯護的公開信連署。 |

| 1919 | 比松參與戰後和解活動；奎德流亡瑞士日內瓦。 |
| 1927 | 兩人同屆獲獎。 |
| 1941 | 奎德逝世於日內瓦，終生未返德。 |

## 調查

**第一步：核對比松的「教育即和平」主張。**
比松認為民族主義戰爭的根源在**教科書**：他把世俗、理性、批判的教學法視為長期反戰工程。他創立的人權聯盟則是把教育成果組織成政治力量。

**第二步：核對奎德的「自批判」技術。**
奎德做的是當時最危險的事：**一個德國史學家批判德國的軍國主義起源**。他的論證結構是史學式的——用普魯士憲政史證明軍備競賽的制度根源。這使他的和平主義有學術地基，也使他成為流亡者。

**第三步：確認雙案的和解結構。**
一個在勝利國推動批判教育，一個在戰敗國推動自我批判。委員會同年頒給兩人，等於宣示：**和解的長期工程要兩邊同時施工**。

## 技藝裁決

本屆裁決確立了「**教育和解**」作為和平技術：教科書、史觀、公民教育是比條約更持久的和平工具。此路線後來在 1961（哈馬舍爾德的聯合國教育工作）、2011（三位女性得主中的教育工作者）等案中反覆出現。
