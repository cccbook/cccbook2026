# 1949 · 博伊德奧爾：營養學家把「饑餓」變成和平問題

> 1949 諾貝爾和平獎：約翰・博伊德・奧爾（John Boyd Orr，1880–1971，英國）——營養學家、聯合國糧農組織（FAO）首任總幹事。破的是一樁「饑餓案」：委員會第一次承認**吃飽飯是和平工作的範圍**。

## 懸案（案情提要）

1930s，蘇格蘭的營養學家博伊德奧爾做了一系列調查，證明英國工人階級的膳食普遍不足——「貧窮即營養不良」。戰後他被任命為 FAO 首任總幹事，提出「世界糧食委員會」方案：用全球性的糧食儲備與貿易安排消除饑荒。方案未被大國採納，他辭職，但 FAO 的框架保住了。1949 年他獲獎。

案子懸在這裡：**一個營養學家得和平獎**——委員會的判決把「饑餓」認定為和平問題的一部分。這是經濟和平主義路線（1933 安吉爾）的擴充版：不只是貿易，連營養都是。

## 調查

**第一步：核對「營養調查」的技術。**
博伊德奧爾的方法是**用科學調查把貧困可視化**：抽樣家庭膳食、計算熱量與營養素、與醫療統計交叉。這使「吃不飽」從道德敘述變成可測量的社會指標——**科學作為和平動員**。

**第二步：核對 FAO 的組織方案。**
他的世界糧食委員會方案是超國家的糧食儲備與貿易協調——比 FAO 本身更激進。大國否決後 FAO 保留為情報與協調機構。他的技術是**先提出最大方案，再守住可成的部分**。

**第三步：確認「饑餓作為和平議題」的判定。**
委員會第一次把營養學家納入和平獎。此路線的後續是 1970 布勞格（綠色革命）、2020 世界糧食計劃署——**饑餓與和平的關聯被持續認定**。

## 技藝裁決

本屆裁決確立了「**饑餓即和平問題**」的路線。其技術基礎是：可測量的科學證據能讓饑荒從「自然災害」重新定義為「可預防的政治後果」。此路線與 1933 安吉爾（經濟論證）同構，尺度從貿易擴到營養。

## 後果

| 年份 | 影響 |
|------|------|
| 1949 | FAO 框架保留至今。 |
| 1961 | 世界糧食計劃署（WFP）成立，承接其糧食儲備構想。 |
| 1970 | 布勞格獲獎，綠色革命路線。 |
| 2020 | 世界糧食計劃署獲獎，饑餓路線的七十年後續卷。 |
| 2015 | 聯合國可持續發展目標 SDG2「零饑餓」，沿其路線。 |
