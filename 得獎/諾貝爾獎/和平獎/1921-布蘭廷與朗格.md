# 1921 · 布蘭廷與朗格：評選者自己得獎——北歐議會和平主義的第三代

> 1921 諾貝爾和平獎：卡爾・亞爾馬・布蘭廷（Hjalmar Branting，1860–1925，瑞典首相）；克里斯蒂安・勞斯・朗格（Christian Lous Lange，1869–1938，挪威）——後者曾任挪威諾貝爾委員會首任秘書長。破的是一樁「自己評自己」案：得獎者之一是評選機構的前職員，這件事該怎麼處理？

## 懸案（案情提要）

1921 年的雙得主裡，朗格的履歷最特殊：他是挪威諾貝爾委員會的首任秘書長（1890s），後轉任各國議會聯盟秘書長。換句話說，他長期就是**評選機器的一部分**。布蘭廷則是瑞典首相、瑞典社會民主黨創始人，一個帶著黨派身分的國家元首。

案子懸在這裡：委員會把獎發給「前評選工作人員」，這在程序上合法（他早已離職），在觀感上極為敏感。這是和平獎第一次明確暴露「評選者與被評選者的距離」這個結構性問題——此後每屆得主若與評選體系有關聯，都會被拿來對照本屆。

## 調查

**第一步：核對布蘭廷的「社會主義和平主義」。**
布蘭廷的論證獨特：他認為**軍國主義與階級剝削是一體**，裁軍與社會改革是同一件事。他在 1905 年瑞典—挪威聯盟解體中堅持談判路線，並在戰間期推動瑞典加入國聯——他的和平工作是一種「社會民主黨式的國際主義」。

**第二步：核對朗格的「秘書長生涯」。**
朗格離開諾委會後主持議聯十年，把克里默與戈巴特的組織擴成覆蓋三十國的常設機構。他的技術是**議會間情報**：讓各國議員在開會前就掌握彼此立場。

**第三步：確認「評選者得獎」的程序處理。**
朗格獲獎時早已離開諾委會多年，程序上無可挑剔；但這次頒獎迫使委員會此後制定了更明確的利益迴避慣例。**本屆的爭議反而成為評選制度自我修復的起點**。

## 技藝裁決

本屆裁決的方法論點是「**和平主義的政治化**」：布蘭廷證明和平不只是外交家的領域，政黨政治、社會改革、工會運動都是和平工作。這條路線後來在 1971 布蘭特、1983 華勒沙等案中反覆出現——**黨派身分不再是被判詞迴避的事，而是技術的一部分**。

## 後果

| 年份 | 影響 |
|------|------|
| 1921 | 瑞典首位、挪威繼 1908 巴耶爾後的得主。 |
| 1925 | 布蘭廷逝世，瑞典社民黨持續執政。 |
| 1938 | 朗格逝世，其《議會聯盟史》成為重要史料。 |
| 1971 | 布蘭特（西德總理）獲獎，黨派和平主義路線的戰後續卷。 |
| 2020s | 評選體系的利益迴避慣例已制度化。 |
