# 1910 · 國際和平局：一個辦公室，四十年，得了一個獎

> 1910 諾貝爾和平獎：常設國際和平局（Bureau International de la Paix，瑞士伯恩）——首個「純民間 NGO」得主。破的是一樁「機構壽命案」：帕西、克里默都是人，機構能自己得獎嗎？答案是能，而且靠的是一本通訊錄。

## 懸案（案情提要）

1890 年，伯恩。瑞士議員在聯邦議會贏得一項不尋常的撥款：贊助一個「國際和平組織的常設辦事處」。這個辦事處位於伯恩一處樸素的辦公樓，編制幾乎可以忽略——榮譽秘書長（迪科門）不領薪，行政人員屈指可數。

案子懸在這裡：它沒有兵、沒有錢、沒有外交官身分，唯一的功能是**收發信件**。二十年後，這個辦公室自己獲得了諾貝爾和平獎。委員會的判詞只有一句：「各國和平社會之間的紐帶。」——這句話承認了一個技術事實：**把所有人連起來，本身就是和平工作**。

## 前因

| 年份 | 事件 |
|------|------|
| 1889 | 巴黎和平大會決議設立常設辦事處。 |
| 1890 | 國際和平局在伯恩成立，迪科門任首任榮譽秘書長。 |
| 1891 | 巴耶爾出任首任主席。 |
| 1892 | 出版《國際和平》年鑑，收錄各國和平組織名錄。 |
| 1900 | 通訊網絡覆蓋歐美 90 餘個和平組織。 |
| 1902 | 迪科門與戈巴特獲獎（機構的兩位首任首長）。 |
| 1906 | 戈巴特接任秘書長。 |
| 1910 | 機構本身獲獎。 |
| 1914 | 一戰爆發，伯恩中立的瑞士使其得以維持國際通訊。 |

## 調查

**第一步：核對「紐帶」的技術內容。**
和平局的核心產品是**情報與協調**：各國和平組織的會議日期、請願進度、議員立場、報刊輿論——全部整理成年鑑與通報。這是十九世紀末最早的「NGO 交換台」，也是後來國際非政府組織網絡的母版。

**第二步：核對其組織壽命。**
創辦人到 1906 年已相繼離世或交接，機構卻持續運作——證明**制度比人活得久**，這正是它獲獎的技術理由。

**第三步：確認機構判決的路線圖。**
1904（法研究院）→ 1910（和平局）→ 1917（紅十字），委員會在十年內三次頒給機構，等於宣告：**和平的持久戰要靠常設機構打**。

## 技藝裁決

本屆裁決的方法論點是**連接本身即技術**。和平局的發明不是任何一場談判或條約，而是「讓所有和平工作者有一個共同的地址」。這條技術路線後來在國際特赦（1977）、無國界醫生（1999）、國際反地雷組織（1997）的判決中被反覆引用——**網絡的價值不在單點，在連接**。

## 後果

| 年份 | 影響 |
|------|------|
| 1910 | 首個純民間機構得主。 |
| 1919 | 和平局網絡成為國際聯盟非政府參與的模板。 |
| 1963 | 恢復活動，總部遷回日內瓦。 |
| 1970s | 成為冷戰時期「民間外交」的通道之一。 |
| 2010 | 百週年，聯合國致賀；至今仍是世界上最老的和平 NGO。 |
