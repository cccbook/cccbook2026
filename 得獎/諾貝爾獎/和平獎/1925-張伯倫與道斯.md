# 1925 · 張伯倫與道斯：歐洲和平的兩本帳——一本政治，一本財政

> 1925 諾貝爾和平獎：奧斯丁・張伯倫（Austen Chamberlain，1863–1937，英國外相）；查爾斯・道斯（Charles G. Dawes，1865–1951，美國副總統）——前者是《羅加諾公約》的英國推手，後者是道威斯計畫的設計者。破的是一樁「賠款案」：德國付不起賠款，法國要占魯爾，歐洲的和平懸在一份付不出來的帳單上。

## 懸案（案情提要）

1923 年，法比聯軍占領魯爾，德國以消極抵抗回應，通貨膨脹到天文數字。道斯委員會出來做一件當時最不體面的事：**算帳**。道威斯計畫重新核定德國的賠款額、貸款與支付安排，德國經濟得以復甦。1925 年，張伯倫促成《羅加諾公約》——法德比英義相互承認邊界、德國加入國聯。同年兩人同獲和平獎。

案子懸在這裡：一個得獎者是**外交**（公約），一個是**財政**（賠款重訂）。委員會第一次承認：和平的帳本不只是政治帳，還有經濟帳。

| 年份 | 事件 |

| 1923 | 法比占領魯爾；德國通膨失控。 |
| 1923 | 道斯委員會成立，重訂賠款方案。 |
| 1924 | 道威斯計畫生效，美國貸款流入德國。 |
| 1925 | 《羅加諾公約》簽署；兩人同獲和平獎。 |

| 1929 | 大蕭條爆發，整個體系崩塌。 |

## 調查

**第一步：核對道威斯計畫的技術。**
道斯的方案不是減免，而是**重訂支付能力**：德國按工業產出分年支付，同時獲得美英貸款。這是「賠款作為可持續經濟安排」的首次嘗試——他的發明是**把政治賠款翻譯成財務模型**。

**第二步：核對羅加諾的政治工程。**
張伯倫的做法是把德國拉進**條約體系**而不是懲罰體系：德國承認西部邊界，換取東部邊界的仲裁安排。英國成為擔保人。這是「安全共同體」的早期版本。

**第三步：確認兩案的互補。**
財政安排（道斯）使德國付得起；政治安排（張伯倫）使德國願意付。委員會同年頒給兩人，等於宣告：**和平同時需要銀行與條約**。

## 技藝裁決

本屆裁決確立了**經濟和平主義**作為獨立路線：和平不一定來自調停一場戰爭，也可能來自重新設計一筆賠款。此路線後來在 1953 馬歇爾計畫、2006 尤努斯（小額信貸）等判決中重複出現。

## 後果

| 年份 | 影響 |
|------|------|
| 1925 | 歐洲進入「羅加諾時代」的短暫和平。 |
| 1929 | 楊格計畫、大蕭條，體系瓦解。 |
| 1933 | 納粹上台，體系終結。 |
| 1953 | 馬歇爾計畫獲獎，經濟和平主義的戰後版。 |
| 1945 | 道斯逝世前已任美國駐德大使。 |
