# 1912 · 魯特：一個帝國主義者的仲裁案，判詞與履歷同時被讀

> 1912 諾貝爾和平獎：伊萊休・魯特（Elihu Root，1845–1937，美國前國務卿、參議員）。破的是一樁「履歷矛盾案」：他做過帝國主義擴張的法律推手，又主持了國際法庭的建設——評審要怎麼在同一份判詞裡處理兩段履歷？

## 懸案（案情提要）

1901–1905 年，魯特任國務卿，期間美國拿下菲律賓、古巴、波多黎各，並敲定巴拿馬運河區的安排——他是這套擴張的法律架構師。幾年之後，他又主持了 1907 年海牙會議的美國代表團，推動設立國際法庭。1912 年，挪威委員會把獎發給他。

案子懸在這裡：這是和平獎史上第一樁「履歷雙面」案——不評價他做了什麼帝國主義，只表彰他做了什麼仲裁。批評者當時就指出：**同一個人可以同時是擴張的推手與法庭的建築師**，這個矛盾，後來每屆「政治家得主」都要再答一次。

## 前因

| 年份 | 事件 |
|------|------|
| 1845 | 生於紐約州，著名律師出身，曾任美國律師協會主席。 |
| 1899 | 出任陸軍部長，主導菲律賓占領區的法律架構。 |
| 1905 | 出任國務卿。 |
| 1906 | 主持美日《魯特—高平協定》，承認門羅主義與日本在中國的利益。 |
| 1907 | 率美國代表團赴第二次海牙會議。 |
| 1909 | 出任紐約州參議員。 |
| 1912 | 獲和平獎；同年參與常設仲裁法院的事務。 |
| 1920s | 主張美國加入國際法庭，未果。 |

## 調查

**第一步：核對其「法律建構」的技巧。**
魯特的技術是把**權力安排翻譯成法律**：巴拿馬運河條約、古巴《普拉特修正案》、菲律賓行政令——都是他起草或監督的。同一套技巧反過來用在國際仲裁上，就成了「為國際法庭寫章程」。

**第二步：核對海牙代表團的工作。**
1907 年他率團赴海牙，推動《和平解決爭端公約》的擴充與常設仲裁的實質化。他的論證是律師式的：**先給法庭找案子，再談法庭的權力**。

**第三步：確認判詞的選擇性。**
委員會的判詞完全基於仲裁工作，迴避了帝國主義履歷——這種「選擇性判詞」成為和平獎處理政治家得主的標準模式，一直用到今天。

## 技藝裁決

魯特的裁決點是**法律架構作為和平工具**：他不靠道德感動，靠條文與法庭。這條路線與 1904 法研究院、1907 雷諾、1911 阿賽爾同屬「法學和平主義」，其極致案例是 1929 年凱洛格的非戰公約。但魯特案也首次暴露了該路線的結構問題：**建構國際秩序的人，多半同時是現行秩序的既得利益者**。

## 後果

| 年份 | 影響 |
|------|------|
| 1912 | 第三位美國得主，美國「法學和平主義」路線確立。 |
| 1919 | 出席巴黎和會，參與國際聯盟章程的修正工作。 |
| 1921 | 支持華盛頓會議的裁軍架構。 |
| 1926 | 參與國際法庭章程起草，美國最終未加入。 |
| 1937 | 逝世。 |
