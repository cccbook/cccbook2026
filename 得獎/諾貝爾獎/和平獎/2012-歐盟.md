# 2012 · 歐盟：整個大陸的一紙獎狀——戰場變成市場的六十年案

> 2012 諾貝爾和平獎：歐洲聯盟——表彰「六十年來對歐洲和平與和解、民主與人權的推進」。破的是一樁「大陸案」：和平獎第一次頒給整個地區性組織——把法德百年宿怨寫成共同關稅表，把戰場改成市場。

## 懸案（案情提要）

從 1951 年六國煤鋼共同體到 1993 年歐盟，歐洲的發明是：把戰略物資（煤、鋼）放進共同管理，使開戰在技術上不可能；再用擴員（2004 年東擴十國）把前蘇聯陣營整批轉入民主市場。委員會的判詞：歐盟把「一個戰爭的大陸」變成「一個和平的大陸」。

案子懸在這裡：**頒獎當下正是危機**——歐債危機撕裂南北（希臘緊縮引發街頭衝突），失業率飆高，疑歐黨派崛起。委員會的裁定等於說：別忘了六十年前這裡是戰壕。批評者則問：以緊縮踐踏成員國民生的機構，配得上和平獎嗎？

## 前因

| 年份 | 事件 |
|------|------|

| 1957 | 《羅馬條約》，共同市場成形。 |
| 1973–86 | 三波西擴：英國、希臘、西班牙、葡萄牙等民主化後入盟。 |

| 2004 | 史上最大東擴，十國入盟。 |
| 2010–12 | 歐債危機，希臘、西班牙街頭示威。 |
| 2012 | 12 月三任首長代表領獎。 |

## 調查

**第一步：核對「煤鋼」的技術設計。**
戰略物資共同管理＝開戰原料公有。這是 1926 白里安與施特雷澤曼、1925 羅加諸案的延續與制度化：當年靠條約與互訪，這次靠機構與否決權。**和平的硬件化**是本案核心工程。

**第二步：核對「擴員」的和平技術。**
入盟條件（哥本哈根標準）：民主、法治、人權、市場經濟。候選國為了入盟自改憲法與司法——這是和平動機被轉成改革動力的設計。南歐民主化（1970s）與東歐轉型（1990s）皆循此門。

**第三步：核對「危機中頒獎」的裁決邏輯。**
委員會明說：獎是提醒歐盟的原始使命——團結不只是在順境。這是獎項第一次以「鞏固既有工程」而非「表彰新功績」為目的，承 1963 紅十字百年慶典案的先例。

## 技藝裁決

本屆裁決確立了「**制度和平**」路線的頂點：機構本身作為和平工程得獎（承 2001 聯合國與安南格式）。它與 1919 威爾遜（國聯構想）、1945 赫爾（聯合國）構成「國際組織案卷」三卷——威爾遜的構想失敗了，歐盟是它在大陸尺度的成功版本。

## 後果

| 年份 | 影響 |
|------|------|
| 2012 | 頒獎後疑歐聲浪未減，獎被部分輿論譏為「鼓勵獎」。 |
| 2016 | 英國公投脫歐，2020 年完成——本案工程首次出現退會者。 |
| 2022 | 俄烏戰爭爆發，歐盟的和平敘事重新校準，烏克蘭獲候選國地位。 |
| 2020s | 擴員作為和平技術的判例地位不變：巴爾幹與東歐入盟進程持續。 |
