# 1937 · 塞西爾：國聯的英國守護者

> 1937 諾貝爾和平獎：羅伯特・塞西爾（Robert Cecil，1864–1958，英國）——國際聯盟的英國主要推手、國聯英國協會的創始人。破的是一樁「守護案」：國聯在 1936 年衣索比亞危機中已顯示無力，委員會卻把獎發給它的守護者——像在給一個正被拆除的機構的建築師留影。

## 懸案（案情提要）

塞西爾是《凡爾賽條約》的英國代表團成員、國聯章程的主要起草人之一、1923–24 年英國代表團團長。戰間期他把重心轉到民間：創辦國聯英國協會，把國聯理念變成英國的群眾運動（鼎盛時期會員逾四十萬）。1937 年他獲獎——但此時國聯已在衣索比亞事件中失敗，德國與日本相繼退出。

案子懸在這裡：**機構正在失敗，建築師獲獎**。委員會的判決在結構上與 1920 布爾茹瓦（理論家得獎）呼應，但時機更沉重——這是和平獎對一個即將消亡的秩序的致敬。

## 調查

**第一步：核對「民間國聯」的組織技術。**
塞西爾把國聯的理念從政府層面搬到**公民層面**：國聯英國協會組織演講、教材、青年運動——「讓國聯成為英國人的日常事務」。這是國際組織的第一次大規模民眾動員。

**第二步：核對他在章程起草中的角色。**
他與威爾遜、布爾茹瓦是章程的三位主要思想源頭。他堅持**裁軍條款**與**和平解決爭端的義務**——這兩條後來成為聯合國章程的骨架之一。

**第三步：確認「失敗中的致敬」判決。**
1937 年頒獎時，國聯已被三國退出、制裁失效。委員會表彰的不是國聯的成功，而是**它的理念與它的守護者**——這是和平獎對「失敗的理想主義」第一次明確致敬。

## 技藝裁決

本屆裁決確立了「**理念的守護者**」作為得主類別：一個機構的價值可以在機構失敗後被承認。此後凡是「制度失敗而理念存活」的判決（1945 赫爾、2001 聯合國與安南）都在重複這一條。

## 後果

| 年份 | 影響 |
|------|------|
| 1937 | 國聯體系的最後一屆得主（1938 南森辦公室為其續卷）。 |
| 1939 | 二戰爆發，和平獎停發。 |
| 1945 | 聯合國成立，國聯理念被繼承。 |
| 1946 | 國聯正式解散。 |
| 1958 | 塞西爾逝世，享年 94。 |
