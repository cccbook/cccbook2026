# 1913 · 拉方丹：國際和平局的局長，得獎時機選在大戰前夜

> 1913 諾貝爾和平獎：亨利・拉方丹（Henri La Fontaine，1854–1943，比利時律師、參議員）——國際和平局局長。破的是一樁「時機案」：1913 年是戰雲密布的一年，委員會在巴爾幹戰爭的陰影下頒獎——是表彰，也是抗議。

## 懸案（案情提要）

1912–1913 年，巴爾幹兩次戰爭相繼爆發，歐洲大陸的軍備競賽進入高峰。就在這樣的背景下，挪威委員會把 1913 年的獎發給比利時的和平運動者拉方丹——國際和平局局長、比利時參議員、和平主義的法學理論家。

案子懸在這裡：獲獎者不是什麼「大國調停者」，而是一個民間組織的負責人。委員會的選擇幾乎等於一份政治聲明：**在大戰陰影下，把獎發給民間和平網絡的總協調人**。次年，大戰爆發，和平獎連續兩年停發。

## 調查

**第一步：核對「局長」的技術角色。**
拉方丹不是和平局的創辦人，而是它的**職業化接班人**：他把迪科門時代的交換台，升級成一個有年度報告、有專業秘書、有國際議程的機構。他的獲獎表彰的不是一場戰役，而是**機構的成熟**。

**第二步：核對其法學工作。**
他同時是國際法學家，參與起草多項和平主義的法學方案，包括國際仲裁與裁軍的法律基礎。他的技法是**理論＋組織**的雙軌。

**第三步：確認時機的政治性。**
1913 年的判決在巴爾幹戰爭後、大戰爆發前——委員會幾乎是在用頒獎表達「和平還有可能」。這是和平獎第一次**帶有抗議性質的頒獎**，這個模式後來在 1935（奧西茨基）、1948（甘地缺席）、1975（沙卡洛夫）等屆反覆出現。

## 技藝裁決

拉方丹的裁決點是**機構職業化**：一個和平組織要存活，必須從志願者網絡變成有專業秘書處的機構。這條「職業化」路線，後來成為所有國際 NGO 的組織範式——從紅十字到國際特赦再到無國界醫生，判決邏輯都在重複這一條。

## 後果

| 年份 | 影響 |
|------|------|
| 1913 | 比利時首位得主。 |
| 1914–18 | 一戰期間和平獎多次停發，國際和平局的工作幾乎中斷。 |
| 1920 | 國際聯盟成立，拉方丹的「民間網絡」構想部分被吸收。 |
| 1943 | 逝世，享年 89。 |
| 2013 | 百週年，布魯塞爾建紀念碑。 |
