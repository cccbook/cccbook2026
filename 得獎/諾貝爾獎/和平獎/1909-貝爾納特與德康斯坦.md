# 1909 · 貝爾納特與德康斯坦：兩次海牙會議的「代表團經濟學」

> 1909 諾貝爾和平獎：奧古斯特・貝爾納特（Auguste Beernaert，1829–1912，比利時前首相）；保羅・德康斯坦（Paul d'Estournelles de Constant，1852–1924，法國外交官）。破的是一樁「代表團案」：和平會議開得再多，如果代表團不會工作，一切白費——兩人是 1899 與 1907 兩次海牙會議裡最會工作的代表。

## 懸案（案情提要）

1899 年與 1907 年，兩次海牙和平會議。二十六國代表團先後抵達，多數人是來表態的，少數人是來**起草**的。貝爾納特（比利時前首相）與德康斯坦（法國大使）屬於後者：一個主持會議程序，一個推動雙邊仲裁協定。1909 年委員會把獎發給他們，判詞罕見地直接點名「兩次海牙和平會議的代表」。

案子懸在這裡：這是和平獎第一次獎勵**會議工程**——不是誰提出了理想，而是誰把理想的會開成了有產出的會。

## 前因

| 年份 | 事件 |
|------|------|
| 1829 | 貝爾納特生於比利時，1878–84 年任比利時首相。 |
| 1899 | 海牙和平會議，貝爾納特為比利時代表，主持多組議程。 |
| 1852 | 德康斯坦生於法國，歷任駐美、駐英外交官。 |
| 1890s | 創立法國議會友好集團，推動法德、法英民間交流。 |
| 1900 | 創辦《國際調解》期刊，推廣仲裁案例。 |
| 1907 | 第二次海牙會議；兩人皆為核心代表。 |
| 1909 | 兩人同屆獲獎。 |
| 1912 | 貝爾納特逝世。 |

## 調查

**第一步：核對貝爾納特的會議工程。**
海牙會議的難處在於二十多個代表團、四百多項提案。貝爾納特的貢獻是**分組與裁決順序**：把議題拆成可通過的整數塊，避免每項都變成全體表決。這種「會議程序學」是他獲獎的直接技藝。

**第二步：核對德康斯坦的雙邊仲裁網。**
德康斯坦不滿足於大會決議，他在會議間隙撮合**雙邊仲裁協定**（法德、法英、法意等），把海牙精神變成一對一的合約。他的發明是：**先談小案子，再等大案子**。

**第三步：確認「程序即和平」的判決邏輯。**
委員會首次把「會議技術」列為和平工作——此後凡是涉及大會、公約起草的得主（1929 凱洛格、1945 赫爾），判詞都會回到這條線。

## 技藝裁決

本屆裁決確立了**外交程序學**作為和平技術：分組、議程、雙邊先例。它與 1904 年國際法研究院的「法典化」互補——一個寫規則，一個讓規則有機會被寫出來。兩者合起來，構成後來國際組織法與多邊外交的基本技術栈。

## 後果

| 年份 | 影響 |
|------|------|
| 1909 | 比利時與法國各自的「海牙系」得主首次並列。 |
| 1910 | 國際和平局獲獎，「程序學」得到組織層面的認可。 |
| 1913 | 海牙體系成為國際聯盟的直接模板。 |
| 1912 | 貝爾納特逝世，其會議程序學由繼任者繼續。 |
| 1920 | 國際聯盟大會採用海牙式分組與議程技術。 |
