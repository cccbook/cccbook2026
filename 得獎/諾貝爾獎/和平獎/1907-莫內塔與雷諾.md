# 1907 · 莫內塔與雷諾：一個老兵辦報紙，一個法學家上法庭

> 1907 諾貝爾和平獎：埃內斯托・泰奧多羅・莫內塔（Ernesto Teodoro Moneta，1833–1918，義大利）；路易・雷諾（Louis Renault，1843–1918，法國法學家）。破的是一樁「雙聲道案」：一個從軍三次的老兵天天在報紙上罵戰爭，一個海牙的法學家把仲裁寫成可執行的條文——兩人的技法完全相反，卻在同年並列。

## 懸案（案情提要）

1907 年，委員會把獎拆給兩個極端。莫內塔是義大利的老兵，參加過 1866、1870 兩次戰爭，辦了一份叫《和平瞭望台》的報紙，把反戰寫成四十年的日記體；雷諾是巴黎大學的國際法教授，在海牙常設仲裁法院任職，他的成名案是把「貝魯特—索爾費里諾式」的爭端翻譯成法條。一個是輿論戰場，一個是條約戰場。

案子懸在這裡：委員會第一次在同一年判決兩種**不同時間尺度**的和平技術——莫內塔的工作以「天」為單位（每天一篇社論），雷諾的工作以「代」為單位（一條條文可用幾十年）。

## 調查

**第一步：核對莫內塔的「老兵反戰」結構。**
他的權威不來自反戰理念，而來自**親身打過仗**。他寫「我參加過戰爭，所以我懂它」，這種論證方式在當時極為有效——它讓和平主義擺脫「文弱書生」的標籤。報紙是他的主武器，四十年的持續出版比任何單篇宣言都致命。

**第二步：核對雷諾的條文工程。**
雷諾的技術是把**衝突翻譯成法條**：1899 年海牙會議的《陸戰法規》草案、《和平解決爭端公約》都有他的手筆。他的職業生涯證明「法庭式仲裁」可以繞過外交僵局——兩個國家打不下去了，就讓第三方依條文判。

**第三步：確認雙案的互補。**
輿論改變民意，條文改變規則。委員會同年頒給兩人，等於確認和平運動需要這對齒輪——沒有莫內塔式的輿論，條文缺乏動力；沒有雷諾式的條文，輿論沒有落點。

## 技藝裁決

本屆裁決確立了和平技術的**雙時間尺度**：短期動員（媒體）與長期制度（法學）。這個二元結構後來在 1929 年凱洛格（條文）、1977 年國際特赦（輿論）等判決中反覆出現，也成為和平運動的通用分工表。

## 後果

| 年份 | 影響 |
|------|------|
| 1907 | 義大利與法國各自的「首位得主」之一。 |
| 1910 | 國際和平局獲獎，承認「莫內塔式」機構網絡的價值。 |
| 1913 | 雷諾參與的《海牙國際私法公約》進入實施。 |
| 1918 | 兩人相繼去世，均未能見到一戰結束。 |
