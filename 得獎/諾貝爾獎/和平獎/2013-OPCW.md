# 2013 · OPCW：敘利亞化武核查的臨時案——化學武器的銷毀卷

> 2013 諾貝爾和平獎：禁止化學武器組織（OPCW，1997 年設於海牙）——表彰「在消除化學武器上的大量努力」。破的是一樁「臨時案」：一個常設核查機構在內戰正酣時入場，十個月內把一國宣報的化武庫運出銷毀——戰爭中第一次即時拆除大規模毀滅性武器。

## 懸案（案情提要）

2013 年 8 月，敘利亞大馬士革郊區古塔發生沙林毒氣攻擊，數百至逾千平民死亡，西方一度劍指軍事干預。9 月，美俄達成框架協議：敘利亞加入《化學武器公約》（CWC），庫存交由 OPCW 監督銷毀。OPCW 聯合聯合國組成聯合特派團，在戰火中查封、裝箱、船運、銷毀。

案子懸在這裡：**核查趕得上戰爭嗎？**——特派團在武裝衝突中作業，2014 年 6 月完成宣報庫存的移除。委員會裁定：以核查取代空襲，是「武檢外交」的勝利。但裁決書也預留伏筆：宣報不等於全數——氯氣與後續沙林攻擊證明案未結。

## 前因

| 年份 | 事件 |
|------|------|
| 1925 | 《日內瓦議定書》禁止化學戰。 |
| 1980s | 兩伊戰爭毒氣戰，國際監管呼聲升高。 |
| 1993 | 《化學武器公約》開放簽署。 |
| 1997 | CWC 生效，OPCW 成立——首個全面銷毀一類武器的常設機構。 |
| 2013.8 | 古塔沙林攻擊。 |
| 2013.9 | 美俄框架協議；敘利亞入約；OPCW 入場。 |
| 2013.10 | 獲獎。 |

## 調查

**第一步：核對「即時銷毀」的工程。**
此前 OPCW 的銷毀對象是和平時期（美、俄、利比亞的庫存）。敘利亞案是戰區首例：核查員戴防護裝備確認庫房、聯合國提供武裝護衛、丹麥與挪威船艦跨海轉運。**把銷毀作業排進戰爭時程表**，是本案的工程突破。

**第二步：核對「核查外交」的路線。**
古塔案的政治解方不是干預而是入約＋核查——即：以條約義務換取免於空襲。這承 2005 IAEA 巴拉迪案「核查報告優先於政治情報」的路線，並把它推到戰爭進行式中。

**第三步：核對「案未結」的後續卷。**
敘利亞多次再犯：2014 年起氯氣指控、2017 汗謝渾沙林、2018 杜馬案。OPCW 設「調查與鑑定小組」（IIT）溯源定責——核查機構第一次被賦予「指名道姓」的調查權。本案卷因此分為兩半：銷毀卷（成功）與溯源卷（持續爭訟）。

## 技藝裁決

本屆裁決確立了「**核查即時介入**」路線：武檢不是戰後清點，而是戰中拆彈。它與 2005 IAEA 案（核核查）、2017 ICAN 案（條約禁核）構成「大規模毀滅武器案卷」三連；與 1929 凱洛格案遙相呼應——把「戰爭違法」從宣言落到庫房鎖與封條。

## 後果

| 年份 | 影響 |
|------|------|
| 2014 | 敘利亞宣報庫存全數移除銷毀，史上首次銷毀整類宣報武器。 |
| 2018 | IIT 成立，溯源機制制度化。 |
| 2020s | 敘利亞申報持續存疑；OPCW 的報告成為相關司法與外交行動的證據基礎。 |
| 長期 | 本案成為「武器銷毀可談判」的判例，後續多國化武申報循此模式。 |
