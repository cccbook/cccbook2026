# 1960 · 盧圖利：非洲第一個得主——非暴力反抗種族隔離的測試案

> 1960 諾貝爾和平獎：艾伯特・盧圖利（Albert Luthuli，1898–1967，南非）——非洲人國民大會（ANC）主席，首位非洲得主。破的是一樁「非暴力測試案」：種族隔離制度剛剛升級，委員會把獎發給一個主張非暴力反抗的人——五年後南非政府剝奪了他的自由。

## 懸案（案情提要）

1952 年，南非政府推出新的種族隔離法律，盧圖利率 ANC 推動「藐視運動」——用非暴力的不合作對抗種族隔離。他被政府罷免酋長職位、限制自由。1960 年獲獎——此時南非剛剛發生沙佩維爾大屠殺（警察射殺六十九名和平示威者），他的非暴力路線正在被現實挑戰。

案子懸在這裡：**非暴力在極端壓迫下的可行性測試**。委員會把獎發給他，等於在沙佩維爾屠殺後宣告：非暴力路線仍被國際社會認可。1964 年曼德拉放棄非暴力選擇武裝鬥爭——盧圖利路線與曼德拉路線的分岔，成為南非反抗史的核心懸案。

## 調查

**第一步：核對「藐視運動」的技術。**
盧圖利的方法是甘地式**不合作**：違反種族隔離法規（用白人廁所、不辦通行證）、自願被捕、法庭陳述。其技術核心是**讓壓迫者的每一次執法都成為公開表演**——暴力的可見度是武器。

**第二步：核對南非政府的反應。**
罷免、限制令、叛國罪審判——每一項都是對非暴力路線的**成本測試**。盧圖利在獲獎聲明中堅持非暴力立場，即使此時 ANC 內部已有人主張武裝鬥爭。

**第三步：確認「非暴力測試」的判定。**
委員會在屠殺後頒獎，等於宣告：非暴力路線仍有國際支持。此路線的後續是 1964 馬丁路德金（美國版）與 1993 曼德拉（最終和解）——**南非的三段路線（非暴力→武裝→和解）在和平獎史上都有對應**。

## 技藝裁決

本屆裁決確立了「**極端壓迫下的非暴力**」路線：在種族隔離這種系統性壓迫下，非暴力是否可行？盧圖利案提供了第一份國際級測試——它的結論是：可行，但成本極高。此路線後續見於 1964 金、1989 達賴喇嘛、1991 翁山蘇姬。

## 後果

| 年份 | 影響 |
|------|------|
| 1960 | 首位非洲得主；南非禁止其領獎。 |
| 1961 | 赴奧斯陸領獎，演說被稱為「非洲的良心」。 |
| 1964 | 曼德拉被捕入獄，非暴力與武裝路線分岔。 |
| 1967 | 逝世，享年 69。 |
| 1994 | 曼德拉當選總統，盧圖利的非暴力遺產被追認。 |
| 2004 | 南非最高勳章以他命名（盧圖利勳章）。 |
