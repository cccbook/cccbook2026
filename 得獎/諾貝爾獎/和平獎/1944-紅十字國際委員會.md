# 1944 · 紅十字國際委員會：二戰中的第三次獲獎，也是最沉重的一次

> 1944 諾貝爾和平獎：紅十字國際委員會（ICRC，瑞士）——第二次獲獎。破的是一樁「沉默的案」：它在二戰中救了戰俘，卻對納粹集中營保持了近乎全面的沉默——評審該怎麼判？

## 懸案（案情提要）

1939–1945 年，紅十字國際委員會在戰俘問題上做了大量工作：戰俘卡片索引、探視、通信恢復。但它在猶太人問題上幾乎沉默：1942 年有代表團建議公開譴責納粹滅絕政策，委員會主席以「中立」為由拒絕——這個決定後來被委員會自己在 1990s 公開承認為錯誤。

案子懸在這裡：**機構的工作巨大，機構的沉默也巨大**。1944 年委員會仍把獎發給它。這是和平獎第一次面對「人道機構的政治中立是否也是一種共謀」的問題——此後每屆救援機構得主都會被對照本屆。

## 前因

| 年份 | 事件 |
|------|------|
| 1917 | 一戰中第一次獲獎。 |
| 1929 | 《日內瓦戰俘公約》簽署。 |
| 1939 | 二戰爆發，委員會成立戰俘情報局。 |
| 1942 | 委員會內部討論公開譴責滅絕政策，被主席否決。 |
| 1943 | 戰俘卡片索引系統擴至數千萬份。 |
| 1944 | 第二次獲獎。 |
| 1945 | 戰爭結束，戰俘遣返工作持續至 1948。 |
| 1995 | 委員會公開承認二戰期間對滅絕政策的沉默是錯誤。 |

## 調查

**第一步：核對戰俘工作的規模。**
戰俘情報局在日內瓦累積卡片逾三千六百萬份，促成數百萬戰俘與家屬通信、數十萬人被探視。**規模**是本屆判決的技術基礎——它證明了《日內瓦戰俘公約》（1929）在實戰中的有效性。

**第二步：核對「沉默」的結構。**
委員會對納粹滅絕政策幾乎不置評——它的邏輯是：公開譴責會導致失去進入戰俘營的通行證。這個算盤在戰俘工作上是對的，在滅絕問題上是錯的。**中立作為一種制度，第一次暴露了它的成本**。

**第三步：確認獲獎的雙重意義。**
委員會表彰的是戰俘工作；批評者紀錄的是沉默。這使本屆成為「救援機構的政治邊界」的教科書案例——後來的無國界醫生（1999）正是從紅十字出走的人建立的，其宣言「作證先於沉默」直接針對本屆的教訓。

## 技藝裁決

本屆裁決確立了**救援機構的政治邊界**問題：中立保護的是通行權，但通行權的代價可能是沉默。此路線的教訓最終在 1999 無國界醫生的判決中被制度化——「作證」（témoignage）被正式承認為人道工作的一部分。
