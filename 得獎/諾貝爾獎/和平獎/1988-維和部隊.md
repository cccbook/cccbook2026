# 1988 · 聯合國維和部隊：藍盔的總帳——四十年的部署史

> 1988 諾貝爾和平獎：聯合國維持和平部隊（UN Peacekeeping Forces）——集體獲獎。破的是一樁「總帳案」：和平獎第一次發給一支**部隊**，而且是四十項任務的累積——判詞表彰的是「為實現聯合國基本原則所做的貢獻」。

## 懸案（案情提要）

1948 年起，聯合國在中東部署軍事觀察員；1956 年皮爾遜的 UNEF（1957 得主）首創完整維和模式。到 1988 年，聯合國已部署逾四十項維和任務——中東、剛果、塞浦路斯、戈蘭高地。1988 年，委員會把獎發給整支「藍盔」系統。

案子懸在這裡：**部隊獲獎**——這是和平獎結構的一次突破：和平不僅是條約與談判，還可以是**持槍但不開火的中立部署**。判決確認了「維和」作為一種獨立的和平技術。

## 前因

| 年份 | 事件 |
|------|------|
| 1948 | 中東停火監督組織（UNTSO）成立，維和工作開始。 |
| 1956 | 蘇伊士危機，UNEF 成立（皮爾遜案）。 |
| 1960 | 剛果行動（ONUC），大規模維和首次實驗。 |
| 1964 | 塞浦路斯維和部隊（UNFICYP）部署。 |
| 1967 | 埃及要求 UNEF 撤離，六日戰爭爆發。 |
| 1974 | 戈蘭高地觀察部隊部署。 |
| 1988 | 獲和平獎。 |
| 1990s | 冷戰結束後維和任務急增。 |

## 調查

**第一步：核對「維和」的技術定義。**
其核心限制：**不主動開火、須經東道國同意、部隊不來自五大常任理事國**。這三條使藍盔成為「武裝的中立者」——既有威懾，又不構成干預。這個設計是維和能在主權體系中存活的關鍵。

**第二步：核對「中立性」的成本。**
1967 年埃及要求 UNEF 撤離，導致六日戰爭——維和的**依賴東道國同意**原則使其隨時可能失效。此後維和行動的失敗（1994 盧安達）都是此結構性問題的變體。

**第三步：確認「總帳式」判決的意義。**
本屆不表彰單一任務，而是**四十年的累積**——委員會承認：維和的價值在於**它始終存在**。此後凡是機構型判決（1997 反地雷、2013 OPCW）都會被對照本屆。

## 技藝裁決

本屆裁決確立了「**武裝的中立**」作為和平技術：部隊的價值不在開火，而在**在場**。它與 1957 皮爾遜（發明人）、1961 哈馬舍爾德（制度化者）構成維和路線三案——發明、制度化、總帳表彰。

## 後果

| 年份 | 影響 |
|------|------|
| 1988 | 首支部隊獲獎。 |
| 1992 | 冷戰後首波維和擴張。 |
| 1994 | 盧安達維和失敗，成為世紀之恥。 |
| 2000s | 維和任務覆蓋全球逾十萬人。 |
| 2020s | 維和部隊仍是聯合國最主要的和平操作工具。 |
