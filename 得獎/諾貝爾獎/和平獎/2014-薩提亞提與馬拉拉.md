# 2014 · 薩提亞提與馬拉拉：17 歲的最年輕得主——兒童權利的雙國案

> 2014 諾貝爾和平獎：凱拉什・薩提亞提（Kailash Satyarthi，1954–，印度兒童權利運動家）；馬拉拉・優素福扎伊（Malala Yousafzai，1997–，巴基斯坦）——表彰「他們對抗兒童所受壓迫、爭取所有兒童受教育權的奮鬥」。破的是一樁「雙國案」：印度教徒與穆斯林、印度與巴基斯坦、六十歲的營救者與十七歲的倖存者——同案表彰。

## 懸案（案情提要）

薩提亞提 1980 年創立「拯救童年運動」（BABA），以突擊查廠、司法訴訟與復學安置，營救被債役與童工綁架的兒童逾八萬人；1998 年發起橫跨一百零三國的「全球反童工大遊行」，直逼國際勞工組織。馬拉拉在斯瓦特河谷以筆名為 BBC 烏爾都語寫日記，記錄塔利班禁女生上學；2012 年 10 月在校車上被近距離槍擊頭部，輾轉英國治療，康復後成為全球最年輕的教育權發言人。

案子懸在這裡：**童工與失學是同一案卷**——把孩子留在工廠與把孩子趕出教室，是同一種剝奪的兩面。委員會以兩人分別站在供給端（營救）與權利端（上學）合併審理，並用印巴同案發出象徵訊號。

## 調查

**第一步：核對營救的工程鏈。**
薩提亞提的方法是三段式：偵查（線人與臥底）、解救（突擊與司法配合）、重建（復學與職訓）。單純救出沒有用，須切斷再拐賣的循環。承 1977 國際特赦（營救＋記錄）與 1969 國際勞工組織（勞動規範）的路線，對象第一次是兒童勞動。

**第二步：核對馬拉拉的「見證者升級」技術。**
她的案卷分兩卷：受害者卷（被槍擊）與發言人卷（康復後的全球演說）。**傷痕本身成為證物**——她把「一個女孩被禁止上學」放大成全球教育權議程。與 2018 穆拉德案（受害者轉發言人）同構，早了四年。

**第三步：核對同案的象徵結構。**
印巴同案、兩代同案、兩教同案——委員會用配對傳達：兒童權利超越國界與宗教對立。這承 1926 白里安與施特雷澤曼「宿敵同案」的設計，把「和解」寫進得主名單本身。

## 技藝裁決

本屆裁決確立了「**兒童權利即和平**」路線：受教育權第一次成為裁決主題。它承 1965 兒童基金會（機構卷）的路線，補上「個人卷」；與 2011 三位女性案共同構成 2010s「弱勢者權利入卷」的雙主線。

## 後果

| 年份 | 影響 |
|------|------|
| 2014 | 馬拉拉基金會擴張，女孩教育成為全球發展議程核心。 |
| 2015 | 永續發展目標（SDG）將教育與童工終結列入指標。 |
| 2020 | 薩提亞提持續發起全球反童工倡議，營救與安置規模擴大。 |
| 2020s | 馬拉拉於牛津完成學業，轉入聯合國難民署顧問工作；塔利班重掌阿富汗後，本案議題再度緊繃。 |
