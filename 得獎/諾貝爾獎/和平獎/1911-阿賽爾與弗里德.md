# 1911 · 阿賽爾與弗里德：海牙的法庭與維也納的報紙，同年得獎

> 1911 諾貝爾和平獎：托比亞斯・阿賽爾（Tobias Asser，1838–1913，荷蘭）；阿爾弗雷德・弗里德（Alfred Hermann Fried，1864–1921，奧匈帝國）。破的是一樁「雙軌案」：一個把私法衝突變成可執行的公約，一個把和平主義寫成報紙與理論——法律與輿論的同屆對照。

## 懸案（案情提要）

1911 年，委員會把獎拆給兩個不同戰場的人。阿賽爾是海牙的私法專家，他做的事聽起來不浪漫：讓跨國婚姻、商務、繼承的糾紛有**統一的衝突法規則**可循。弗里德是維也納的和平運動者，辦了德語世界最重要的和平期刊《和平瞭望者》，還寫了一本和平主義的教科書。

案子懸在這裡：私法看起來和「和平」無關——但一場跨國商務糾紛如果沒有可循的規則，最終會變成外交摩擦、甚至軍事摩擦。委員會的判決實際上是：**法律秩序本身就是和平結構的一部分**。

## 調查

**第一步：核對阿賽爾的私法工程。**
他的技術是**規則的統一**：不同國家的民法典不同，跨國交易要靠一套「衝突法」決定適用哪國法律。他把這套理論變成每隔幾年一次的國際會議（海牙國際私法會議，至今仍在開），使法律秩序成為跨國日常的底層。

**第二步：核對弗里德的「和平主義理論化」。**
他不只辦報，還把和平主義寫成**可教的課程**：戰爭的經濟成本、仲裁的程序、國際法的意義——整理成教材與年鑑。他的期刊成為德語世界和平運動的技術手冊。

**第三步：確認兩案的分工。**
阿賽爾築「地基」（法律秩序），弗里德築「輿論」（認知結構）。委員會同年頒給兩人，等於確認：**和平的長期工程需要同時維修地基與照明**。

## 技藝裁決

本屆裁決確立了「法律秩序即和平」的判決路線：跨國私法統一、仲裁條約、常設法庭——這些不是浪漫的和平主義，而是讓日常衝突失去升級理由的結構。它與 1904 年國際法研究院、1907 年雷諾構成同一路線的三案。

## 後果

| 年份 | 影響 |
|------|------|
| 1911 | 阿賽爾成為荷蘭首位和平獎得主。 |
| 1913 | 阿賽爾逝世；海牙私法會議制度化。 |
| 1920 | 常設國際法院在海牙成立，阿賽爾的路線成為其基礎。 |
| 1921 | 弗里德逝世。 |
| 1955 | 海牙國際私法會議設常設局，其體系延續至今。 |
