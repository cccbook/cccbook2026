# 1902 · 迪科門與戈巴特：和平運動需要的不是英雄，而是秘書長

> 1902 諾貝爾和平獎：埃利・迪科門（Élie Ducommun，1833–1906，瑞士）——國際和平局首任榮譽秘書長；夏爾・阿爾貝・戈巴特（Charles Albert Gobat，1843–1914，瑞士）——各國議會聯盟首任秘書長。破的是一樁「幕後案」：兩個既不上戰場也不上講台的人，憑什麼得獎？

## 懸案（案情提要）

1902 年，獎項第二年，委員會做了一個耐人尋味的判決：兩位得主都是「秘書長」。和平運動此時不缺雄辯家——帕西、克里默都還在世——缺的是一個能把各地散沙般的和平組織黏在一起的辦公室。委員會把獎發給行政者，等於宣告：**和平不是情懷的問題，是組織的問題**。

案子懸在這裡：這是整個諾貝爾獎史上第一次把「維持機構運轉」認定為和平工作的核心技能。此後一百二十年，凡是得主為組織者的年份，判詞裡都有這一層影子。

## 前因

| 年份 | 事件 |
|------|------|
| 1833 | 迪科門生於日內瓦，曾為律師、記者，後任鐵路公司秘書長。 |
| 1867 | 參與國際和平與自由聯盟的創立事務。 |
| 1890 | 國際和平局在伯恩成立，迪科門出任首任榮譽秘書長，無薪。 |
| 1843 | 戈巴特生於特羅韋，後任瑞士國民議會議員。 |
| 1889 | 各國議會聯盟在巴黎成立，戈巴特任首任秘書長。 |
| 1902 | 兩位「秘書長」同屆獲獎。 |
| 1906 | 迪科門逝世；戈巴特繼任國際和平局秘書長。 |
| 1914 | 戈巴特在世時獲知獲獎的延續安排；同年逝世。 |

## 調查

**第一步：確認迪科門的物證——一個無薪的國際辦公室。**
國際和平局在伯恩的辦公室規模極小，卻是當時全球和平組織的總交換台：轉信、通報、催議程。迪科門以鐵路公司秘書長的行政功力運作它——他把「和平」當成一條需要準點的鐵路線來經營。

**第二步：確認戈巴特的物證——議員之間的常設對話。**
各國議會聯盟的發明是：讓**民選議員**而不是外交部繞過官方渠道彼此會面。戈巴特把這個發明行政化——安排會議、整理紀要、追蹤各國議會的投票。這是「第二軌道外交」的雛形，比官方國際組織早了近三十年。

**第三步：核對兩案的分工。**
迪科門經營民間網絡（公民社會），戈巴特經營議會網絡（政治系統）。委員會把兩人並列，等於判決：和平運動要同時抓住這兩個層面，缺一即墜。

## 技藝裁決

本屆裁決的技術點是**和平的基礎設施化**。和平主義在 19 世紀是演講與請願；到 1902 年，它有了辦公室、通訊錄、議程表與年度報告。迪科門與戈巴特的功績是證明：一項理念要活過創始人的壽命，必須先變成一個會記錄、會交接、會開會的機構。這項「組織技藝」後來在紅十字（1917）、國際聯盟（1920）、聯合國系統（1954 年起）的歷次判決中被反覆引用。

## 後果

| 年份 | 影響 |
|------|------|
| 1906 | 迪科門逝世，戈巴特一人身兼兩職，機構未因失去創辦人而解體。 |
| 1910 | 國際和平局本身獲獎——機構從幕後走到前台。 |
| 1919 | 議會聯盟的「第二軌道」構想被國際聯盟吸收為常設制度。 |
| 1949 | 議會聯盟復會，至今仍是世界最大議會間組織。 |
| 2020 | 議會聯盟已 179 國參與，其秘書處模式仍沿用戈巴特的框架。 |
