# 1947 · 英美教友會：兩個分會，一份獎——宗教救濟的百年檔案

> 1947 諾貝爾和平獎：英國教友會（Quakers）；美國教友會（美國）——同屆頒給同一宗教的兩國分會。破的是一樁「分會案」：委員會第一次把一個宗教團體的兩個國家分支同時獲獎——因為兩邊在戰時救濟做的事幾乎一樣，只是戰場不同。

## 懸案（案情提要）

教友會（貴格會）是和平主義的宗教源頭之一：十七世紀起就主張絕對和平、拒服兵役。一戰與二戰期間，英美兩地教友會的救濟工作覆蓋戰俘、孤兒、饑荒地區——戰後又投入德國與日本的城市重建救濟。1947 年，委員會把和平獎同時發給兩國分會。

案子懸在這裡：這是和平獎第一次頒給**同一組織的兩個國家分支**。判決的技術含義是：教友會的救濟工作不靠中心指揮，靠的是**分會自治**——兩邊各自做了同樣的事，所以兩邊各自得獎。

## 前因

| 年份 | 事件 |
|------|------|
| 1647 | 教友會由福克斯創立，主張「內在之光」與絕對和平。 |
| 1660s | 英國教友會因拒服兵役遭迫害。 |
| 1681 | 賓夕法尼亞成為美國教友會的基地，推行無戰爭殖民地。 |
| 1914–18 | 一戰：兩地教友會組織戰俘與饑荒救濟。 |
| 1920 | 美國教友會成立美國友人服務委員會（AFSC）。 |
| 1939–45 | 二戰：兩地教友會繼續救濟，包括猶太難民。 |
| 1945 | 戰後投入德、日城市的重建救濟。 |
| 1947 | 兩國分會同屆獲獎。 |

## 調查

**第一步：核對「和平主義教派」的證據基礎。**
教友會是少數把和平主義寫進**教義**的團體：從建會起就拒服兵役。委員會判決的基礎是三百年的連續紀錄——這是「長期性」作為和平技術的極致案例。

**第二步：核對分會自治的運作。**
兩國教友會沒有總部，只有共同的信仰與救濟傳統。AFSC（美國）與英國友人委員會各自動員志工——**去中心化的救濟網**，在戰後物資匱乏時比集中機構更靈活。

**第三步：確認「宗教和平主義」路線的定位。**
此前的宗教得主（1930 瑟德布盧姆）是推動教會合一的機構型人物；教友會是**純宗教救濟型**。委員會把兩種都認定為和平工作——此路線後續見於 1958 皮爾、1979 德蕾莎修女。

## 技藝裁決

本屆裁決確立了「**去中心化救濟網**」作為和平技術：不需要總部與命令鏈，需要的只是共同的紀律與地方行動。此技術後來在 1999 無國界醫生、2017 ICAN 的判決中被反覆引用——**NGO 的力量可以來自分散**。

## 後果

| 年份 | 影響 |
|------|------|
| 1947 | 兩分會同獲獎，AFSC 成為美國最知名的和平 NGO。 |
| 1950s | AFSC 投入美國民權與反核運動。 |
| 1960s | 教友會在南非、越南等地持續工作。 |
| 2017 | 教友會的「良知拒服兵役」主張被多國法律承認。 |
