# 1919 · 威爾遜：把一場世界大戰的結束，寫成一份國際組織的章程

> 1919 諾貝爾和平獎：伍德羅・威爾遜（Woodrow Wilson，1856–1924，美國總統）。破的是一樁「章程案」：一場大戰打完了，勝利者分土地，他卻想把戰後的和平**寫成永久的機構**——這案他本人最終沒有答成。

## 懸案（案情提要）

1919 年，巴黎和會。威爾遜提出《十四點計畫》，其中的國際聯盟構想讓歐洲各國半信半疑：一個由所有國家組成的、以談判代替戰爭的組織。國聯成立，他獲 1919 年和平獎。

案子懸在這裡：他獲獎的美國參議院卻拒絕批准《凡爾賽條約》——**得獎者自己的國家沒有加入他建立的組織**。這是和平獎史上最著名的「得獎與失敗同框」案例：判詞表彰的是構想，歷史記錄的是構想在他國會裡的死亡。

| 年份 | 事件 |

## 調查

**第一步：核對《十四點計畫》的結構。**
計畫的前十四條不是道德宣言而是**具體制度清單**：公開外交、公海自由、裁軍、民族自決、最後一條是國際聯盟。這使它成為一份可執行的談判文件，而不只是願望。

**第二步：核對國聯章程的技術。**
國聯章程的關鍵是**集體安全條款**：一國受攻擊即全體視為受攻擊。這在當時是全新的技術，也因為太新而缺乏可執行力。

**第三步：確認參議院否決的原因。**
美國國會的反對主要來自兩處：條約把「宣戰權」讓渡給國際組織；以及黨爭（威爾遜是民主黨，共和黨控制參議院）。**得獎者的制度失敗與他的制度成功來自同一份文件**。

## 技藝裁決

威爾遜的裁決點是**構想的制度轉譯**：他證明「和平」可以被寫成一份組織章程，而不只是一份條約。國聯失敗了，但其章程結構（集體安全、會員國大會、常設秘書處）直接被聯合國繼承——1945 年赫爾（和平獎得主）的聯合國案是它的戰後重啟。

## 後果

| 年份 | 影響 |
|------|------|
| 1920 | 國聯成立，美國缺席。 |
| 1936 | 國聯的軟弱在衣索比亞事件暴露。 |
| 1945 | 聯合國成立，其章程直接沿襲國聯架構。 |
| 1948 | 威爾遜基金會在美國設立。 |
| 1950s | 《十四點計畫》被反覆引用為「民主和平論」的先聲。 |
