# 1917 · 紅十字國際委員會：大戰打了三年，唯一照常運作的國際機構得了獎

> 1917 諾貝爾和平獎：紅十字國際委員會（ICRC，瑞士）——第一次獲獎。破的是一樁「中立者的案」：一場世界大戰打得七國為敵，一個只有瑞士人身分的機構憑什麼繼續在所有戰俘營裡走動？

## 懸案（案情提要）

1914 年 8 月起，歐洲各國斷交、扣人、封鎖邊境。紅十字國際委員會卻在戰俘營之間建立了一個龐大的卡片索引：每封戰俘與家屬的信件、每次探視的紀錄，都被登記、複製、寄達。1917 年，委員會把和平獎發給這個機構——不是因為它阻止了什麼戰爭，而是因為**它在戰爭之中仍然按照公約行事**。

案子懸在這裡：一戰期間 1914、1916、1918 都停發獎項，唯 1917 年照發，得主的身分是「戰爭中立者」。這是整個和平獎第一次承認：**即便和平失敗，人道工作也不失敗**。

| 年份 | 事件 |

| 1916 | 停發獎項；委員會繼續戰俘工作。 |
| 1917 | 第一次獲獎。 |
| 1918 | 停發獎項；戰俘工作持續至戰後交換完成。 |

## 調查

**第一步：核對戰俘情報局的運作。**
戰時紅十字的核心產品是**卡片索引**：戰俘姓名、營地編號、健康狀況、信件往來，全部登記並分寄家屬。到戰末，索引卡片逾七百萬份。這是「人道主義的檔案學」，也是它可被認定為制度性工作的證據。

**第二步：核對探視制度的建立。**
委員會談得動交戰各方，允許代表進入戰俘營**監察待遇**。這個探視權的建立靠的不是道德呼籲，而是《日內瓦公約》的條文——**法律是它的通行證**。

**第三步：確認中立的結構性作用。**
瑞士的中立不是巧合而是技術條件：紅十字的人員不持任何交戰國護照，這是它能在所有陣營之間走動的物理基礎。委員會的判詞等於承認「中立作為和平技術」。

## 技藝裁決

本屆裁決確立了**戰時人道主義**作為和平工作的合法路線：即便戰爭未被阻止，減少其暴行也是和平的一部分。這條路線在 1944（二戰續卷）、1963（百年慶典）兩度獲獎，並構成 1959 無國界醫生、1985 防止核戰醫生等後續判決的模板。

## 後果

| 年份 | 影響 |
|------|------|
| 1917 | 第一次獲獎，機構判決路線的三連發（1904、1910、1917）。 |
| 1918 | 戰俘情報局運作至 1919 年完成交換。 |
| 1929 | 《日內瓦戰俘公約》簽署，紅十字的探視權成文。 |
| 1944 | 二戰中第二次獲獎。 |
| 1963 | 第三次獲獎，百年慶典。 |
| 2024 | 紅十字系統仍是全球最大戰時人道機構。 |
