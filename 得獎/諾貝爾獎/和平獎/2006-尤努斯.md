# 2006 · 尤努斯：把銀行放進村子——小額信貸的貧窮案

> 2006 諾貝爾和平獎：穆罕默德・尤努斯（Muhammad Yunus，1940–，孟加拉經濟學家）與格萊珉銀行——表彰「通過小額信貸推進經濟與窮人社會機遇的努力」。破的是一樁「銀行案」：一位經濟學教授發現窮人不是還不了錢，而是從來借不到錢——於是把銀行開進村子。

## 懸案（案情提要）

1974 年孟加拉大饑荒期間，尤努斯在吉大港大學任教，走訪喬布拉村：一位編竹凳的婦女借了二十二美分的周轉錢，利息吃光利潤。他自掏二十七美元借給四十二戶，全數歸還。1983 年他正式成立格萊珉（鄉村）銀行。

案子懸在這裡：**信貸是和平問題嗎？**——委員會的裁定是：貧窮不是天然狀態，而是被制度排除的結果；把「信用」還給窮人，就是在拆衝突的引信。貸款幾乎全部發給婦女、五人小組互保、周訪收款——還款率長期在九成七以上，遠勝許多商業銀行。

## 前因

| 年份 | 事件 |
|------|------|
| 1940 | 生於吉大港，留學美國范德堡大學獲經濟學博士。 |
| 1971 | 孟加拉獨立，尤努斯回國任教。 |
| 1974 | 大饑荒；喬布拉村二十七美元實驗。 |
| 1976 | 展開「喬布拉計畫」，透過政府銀行放貸。 |
| 1983 | 格萊珉銀行正式成立，尤努斯任總經理。 |
| 1990s | 婦女借款人占比升至九成以上；模式輸出全球。 |
| 2006 | 10 月尤努斯與銀行同獲獎。 |

## 調查

**第一步：核對放貸技術的三件發明。**
一是**五人小組互保**：以同儕壓力取代抵押品；二是**周訪收款**：銀行員下鄉，門檻降到腳程；三是**婦女優先**：資金進入家庭教育與營養，回報率高於男性借款人。三件合起來，是把「信用評等」從資產表改成社區關係表。

**第二步：核對「和平」的因果鏈。**
委員會的判詞理路：大貧窮＋大不平等→衝突溫床；小額信貸→微創業→婦女經濟地位→兒童入學率上升。貧窮被當成**可拆解的結構問題**，這承 1949 博伊德奧爾（饑餓即和平）與 1979 德蕾莎修女（貧窮本身作為和平問題）的路線，但多了一個機構解法。

**第三步：核對模式的複製與爭議。**
至得獎時格萊珉借出逾五十億美元、觸及八萬村。複製品（各國微型金融）良莠不齊，商業化小貸在部分地區變成高利債務——本案的裁決書其實內建了警語：手段（信貸）可以是和平工具，也可以是新的剝削。

## 技藝裁決

本屆裁決確立了「**制度設計即和平**」路線：得主不是調解者、不是運動者，而是一家銀行。它與 1949 博伊德奧爾、1979 德蕾莎修女構成「貧窮案卷」三卷；與 2002 卡特案並列「第二職業式」制度發明——前者蓋屋與治病，這裡放貸。

## 後果

| 年份 | 影響 |
|------|------|
| 2007 | 尤努斯短暫籌組政黨後退出政治。 |
| 2011 | 政府以其年齡為由解除其銀行職務，雙方長年訴訟。 |
| 2010s | 微型金融業因過度商業化受整頓，「格萊珉原則」成為監管參照。 |
| 2024 | 孟加拉政權更迭後，尤努斯受命領導臨時政府——獲獎十八年後重進公共舞台。 |
