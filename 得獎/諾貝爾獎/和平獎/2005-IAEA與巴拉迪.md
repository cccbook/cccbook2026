# 2005 · IAEA與巴拉迪：核查員的難案——伊拉克之後的核檔案

> 2005 諾貝爾和平獎：國際原子能機構（IAEA，1957 年設於維也納）與總幹事穆罕默德・巴拉迪（Mohamed ElBaradei，1942–，埃及）——表彰「防止核能用於軍事目的、確保核能和平使用於最安全方式上的努力」。破的是一樁「難案」：機構在伊拉克戰前說出「沒有核武」的話，被開戰者無視，卻被委員會蓋章認可。

## 懸案（案情提要）

IAEA 成立於冷戰核擴散的起點，職責是核查：確認簽約國的核材料沒有轉作武器。巴拉迪 1997 年出任總幹事。2002–03 年核查伊拉克期間，IAEA 與武檢團未發現大規模毀滅性武器證據，公開與美英情報唱反調；美國仍開戰，戰後證明核查員是對的。

案子懸在這裡：**核查員的說話權**——技術機構通常只交報告，不做政治表態。巴拉迪選擇把報告讀進公共辯論：核問題不能靠先發制人解決，只能靠核查與外交。2005 年頒獎正值伊朗核計畫曝光、北韓退約之際——委員會用獎項保護「核查權」本身。

## 前因

| 年份 | 事件 |
|------|------|
| 1957 | IAEA 成立，艾森豪「原子能和平使用」演說的產物。 |
| 1968 | 《禁止核子擴散條約》（NPT），IAEA 為核查執行機構。 |
| 1991 | 海灣戰爭後首度對伊拉克執行特別核查。 |
| 1997 | 巴拉迪出任總幹事。 |
| 1998 | 印巴相繼試核，擴散警報升高。 |
| 2002–03 | 對伊拉克核查：未發現核武計畫，與開戰陣營對立。 |
| 2003 | 伊朗濃縮設施曝光；北韓退出 NPT。 |
| 2005 | 10 月機構與總幹事同獲獎。 |

## 調查

**第一步：核對核查的技術本質。**
核查是「不信任的工程學」：環境採樣、封條、衛星影像、檔案比對，把各國申報與物理證據對帳。IAEA 的獨立性靠的是資料而非兵力——它與 1977 國際特赦（良心犯資料庫）、2022 三國檔案案同屬「以檔案制約權力」譜系。

**第二步：核對伊拉克案的裁決意義。**
戰前 IAEA 公開否認鋁管說與再啟核計畫說。開戰後事實證明核查無誤。委員會在此刻頒獎，等於裁定：**在戰爭辯論中，核查報告優先於政治情報**。這是本案最尖銳的一筆。

**第三步：核對「伊朗與北韓」的兩難。**
同年伊朗曝光地下濃縮設施、北韓退約——證明核查也有極限：被核查者可以退出。巴拉迪的路線是「條約內講理＋條約外示警」，為 2015 年伊朗核協議的核查設計留下範本。

## 技藝裁決

本屆裁決確立了「**核查即和平**」路線：科學監督機構與其首長同案（承 2001 聯合國與安南的「機構＋個人」格式）。它與 1995 羅特布拉特與帕格沃什（科學家反核）、1985 防止核戰醫生（醫生核戰報告）構成「核檔案」主線三案；並直接下啟 2013 OPCW（化武核查）與 2017 ICAN（非核條約）。

## 後果

| 年份 | 影響 |
|------|------|
| 2005 | 頒獎辭明言「核武威脅再度升高」，為不擴散外交定調。 |
| 2007 | 與伊朗達成「工作計畫」核查安排，協議外交成形。 |
| 2011 | 巴拉迪回埃及參與革命後過渡，短任副總統。 |
| 2020s | 伊朗核查僵局與北韓退出後，IAEA 核查報告成為國際判斷的標準證據。 |
