# 2019 · RCT 與貧困：把發展經濟學變成臨床試驗

> 2019 經濟學獎：Abhijit Banerjee、Esther Duflo（夫婦）、Michael Kremer，表彰「以實驗方法減輕全球貧困」——Duflo 為最年輕得主（46 歲）

## 案情提要

1990 年代的發展經濟學陷入大而無當的口水戰：「外債太多」「殖民遺毒」「腐敗」「人口爆炸」——**每個理論都能解釋一切，因此沒有一個能被檢驗**。Kremer 1994 年在肯亞做了一件「笨事」：**把學校隨機分成幾組，發課本、發驅蟲藥、發免費午餐，看哪一組成績變好。**這個「笨辦法」後來被 Banerjee–Duflo 發展成系統方法：**隨機對照試驗（RCT）**。懸案：**在無法做「整體發展實驗」的世界，能否把貧困拆成一千個可試驗的小問題？**

## 前因

| 年份 | 事件 |
|---|---|
| 1994 | Kremer 的肯亞學校實驗（課本、驅蟲）——發現**免費驅蟲藥比發課本有效 20 倍**（成本效益比驚人） |
| 2003 | Banerjee–Duflo 創立 J-PAL（MIT Poverty Action Lab） |
| 2000s | RCT 擴散：小額信貸、疫苗、教師激勵、氯化水分發 |
| 2011 | 《Poor Economics》（貧窮的本質）出版，RCT 思想進入大眾 |

## 調查：RCT 的方法學結構

**問題分解**（small questions philosophy）：

`「如何終結貧困」→ 拆成：「疫苗為何不被接種？」「教師為何缺勤？」「小額信貸是否有效？」`

**因果推斷的數學**：

- 觀察性資料的困境：`E[Y|D=1] − E[Y|D=0]` 含**選擇偏差**（去接種的媽媽本來就更重視健康）。
- RCT 的解法：隨機分派 D，則 D 與潛在結果獨立：

`E[Y(1)−Y(0)] = E[Y|D=1] − E[Y|D=0]`（選擇偏差 = 0）

- 這正是藥物臨床試驗的方法（[1945-青黴素](1945-青黴素.md) 的 1940-05-25 八鼠對照實驗即原型），被移植到社會政策。

**RCT 的世界觀**（與 Sachs/Easterly 的大計畫之辯）：

- 不追求「大推動」，而追求「**每個干預的成本效益比**」——把發展援助當投資組合管理。

## 理論裁決

| 發現 | 反直覺 |
|---|---|
| **驅蟲藥**（肯亞） | 成本 ~$0.5/人年，提高就學 > 25%——**比任何教育硬件都便宜** |
| **小額信貸** | 對創業有幫助，但**對整體消費與貧困的效果微弱**（多項 RCT 一致） |
| **免費疫苗+扁豆獎勵** | 比教育宣導有效數倍——**物流與誘因，不是觀念** |
| **教師激勵** | 對成績提升顯著；班級人數的效果則很小 |

**理論框架：貧困陷阱的「S 型曲線」**——窮人不是不理性，而是**每項小決策都因缺乏緩衝而放大**（展望理論的損失規避，[2002-Kahneman與展望理論](2002-Kahneman與展望理論.md) 的貧窮版本）。

## 後果

| 層面 | 影響 |
|---|---|
| 政策 | 世界銀行、IMF 的評估方法轉向；肯亞全國驅蟲計畫（Deworm the World，惠及數億兒童） |
| 方法論 | 「**evidence-based policy**」成為全球發展圈共識；RCT 數量 2000–2020 增長 20 倍 |
| 批評 | 2019 年同時引發「**RCT 帝國主義**」批判（Deaton 2015 費爾茲獎得主為主要批評者）：RCT 擅長小干預、不擅長結構問題（制度、貿易、巨觀政策）——**本案的二審持續**（對照 [2024-制度與繁榮](2024-制度與繁榮.md) 的「制度面」路線） |
| 人物 | Duflo 46 歲（最年輕經濟學獎得主）、與 Banerjee 夫婦同獲——諾獎史上罕見的家庭檔案 |
