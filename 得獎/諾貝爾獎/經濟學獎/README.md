# 諾貝爾經濟學獎 歷史年表（詳細版）

> **正名**：本獎全名為「**瑞典央行紀念阿爾弗雷德·諾貝爾經濟學獎**」（Sveriges Riksbank Prize in Economic Sciences in Memory of Alfred Nobel）。它**不在**諾貝爾 1895 年遺囑之內——由瑞典央行（Sveriges Riksbank）為紀念建行 300 週年於 **1968 年**捐設、1969 年首頒。由瑞典皇家科學院評選，程序與諾獎相同，獎金亦同源（2024 年約 1,100 萬瑞典克朗）。民間常稱「諾貝爾經濟學獎」，純粹派則堅持其「紀念獎」身分。

## 序幕（1895–1969）

| 年份 | 事件 |
|---|---|
| 1895 | 諾貝爾遺囑僅設五獎；經濟學未被納入（當時「政治經濟學」在瑞典屬法學與哲學系） |
| 1968 | 瑞典央行 300 週年，行長 Per Åsbrink 提議設立；諾貝爾基金會最初反對（「違反遺囑精神」），經瑞典政府修法後通過 |
| 1969-05 | 皇家科學院宣布首屆得主；**Frisch 本人提議獎項名稱** |
| 1969-12-10 | 首屆頒獎：Frisch 與 Tinbergen（計量經濟學）；同年取消「文學獎」也鬧風波，新獎低調登場 |

## 歷屆得主全表（1969–2024）

| 年份 | 得主（貢獻關鍵詞） |
|---|---|
| 1969 | **Frisch、Tinbergen**（計量經濟學：動態模型、經濟週期） |
| 1970 | **Samuelson**（《經濟學分析基礎》：以數學統一微觀/宏觀） |
| 1971 | **Kuznets**（國民所得核算與經濟成長實證） |
| 1972 | **Arrow、Hicks**（一般均衡與福利理論；Arrow 不可能性定理） |
| 1973 | **Leontief**（投入產出分析） |
| 1974 | **Myrdal、Hayek**（貨幣與經濟波動；兩人意識形態相反的同台） |
| 1975 | **Kantorovich、Koopmans**（線性規劃與資源最優配置） |
| 1976 | **Friedman**（貨幣主義、消費函數、自然失業率） |
| 1977 | **Ohlin、Meade**（國際貿易與跨國資本流動） |
| 1978 | **Simon**（有限理性；組織內決策） |
| 1979 | **Schultz、Lewis**（發展經濟學：農業、二元經濟） |
| 1980 | **Klein**（大型計量模型） |
| 1981 | **Tobin**（q 理論、投資組合分析） |
| 1982 | **Stigler**（產業組織、管制經濟學） |
| 1983 | **Debreu**（一般均衡的存在性與核心） |
| 1984 | **Stone**（國民帳戶體系 SNA） |
| 1985 | **Modigliani**（生命週期假說、MM 定理） |
| 1986 | **Buchanan**（公共選擇：政治的經濟學） |
| 1987 | **Solow**（成長模型：Solow 剩餘） |
| 1988 | **Allais**（市場理論與資源效率；Allais 悖論） |
| 1989 | **Haavelmo**（計量經濟學的機率革命） |
| 1990 | **Markowitz、Miller、Sharpe**（金融經濟學：投資組合、CAPM、MM） |
| 1991 | **Coase**（交易成本與產權；Coase 定理） |
| 1992 | **Becker**（把微觀經濟學推廣至人力資本、家庭、犯罪、歧視） |
| 1993 | **North、Fogel**（新經濟史：制度與計量史） |
| 1994 | **Nash、Harsanyi、Selten**（非合作賽局理論與均衡） |
| 1995 | **Lucas**（理性預期、宏觀計量政策評估） |
| 1996 | **Mirrlees、Vickrey**（信息不對稱下的誘因：最優所得稅、拍賣） |
| 1997 | **Merton、Scholes**（Black–Scholes 選擇權定價；Black 已逝） |
| 1998 | **Sen**（福利經濟學、貧困與飢荒；能力方法） |
| 1999 | **Mundell**（最優貨幣區、蒙戴爾-弗萊明模型——歐元的理論之父） |
| 2000 | **Heckman、McFadden**（微觀計量：選擇偏差、離散選擇） |
| 2001 | **Akerlof、Spence、Stiglitz**（檸檬市場與信息不對稱） |
| 2002 | **Kahneman、Smith**（行為經濟學與實驗經濟學——心理學家首次獲得） |
| 2003 | **Engle、Granger**（時間序列：ARCH、共整） |
| 2004 | **Kydland、Prescott**（時間一致性與真實景氣循環 RBC） |
| 2005 | **Aumann、Schelling**（衝突與合作的賽局理論） |
| 2006 | **Phelps**（跨期權衡：自然率、黃金律） |
| 2007 | **Hurwicz、Maskin、Myerson**（機制設計理論） |
| 2008 | **Krugman**（新貿易理論與新經濟地理） |
| 2009 | **Ostrom、Williamson**（治理：公地自治、交易成本與企業邊界——**Ostrom 首位女性得主**） |
| 2010 | **Diamond、Mortensen、Pissarides**（搜尋摩擦與失業 DMP 模型） |
| 2011 | **Sargent、Sims**（宏觀計量的因果：理性預期實證、SVAR） |
| 2012 | **Roth、Shapley**（穩定匹配與市場設計：腎臟交換、學區、配對） |
| 2013 | **Fama、Shiller、Hansen**（資產價格的實證：EMH vs 泡沫——三人觀點相反） |
| 2014 | **Tirole**（產業組織：規制與平台理論） |
| 2015 | **Deaton**（消費、貧困與福利的測量） |
| 2016 | **Hart、Holmström**（契約理論） |
| 2017 | **Thaler**（行為經濟學的系統化：心理帳戶、助推） |
| 2018 | **Nordhaus、Romer**（氣候變遷整合模型、內生成長理論——環境議題首次登台） |
| 2019 | **Banerjee、Duflo、Kremer**（隨機對照試驗 RCT 攻克全球貧困——**Duflo 最年輕得主，46 歲；夫婦同獲**） |
| 2020 | **Milgrom、Wilson**（拍賣理論與新型拍賣設計：頻譜拍賣） |
| 2021 | **Card（勞動市場的自然實驗）、Angrist、Imbens（因果推斷方法學）** |
| 2022 | **Bernanke、Diamond、Dybvig**（銀行擠兌與金融危機） |
| 2023 | **Goldin**（女性勞動參與的 200 年：貪婪工作）——**第三位女性得主，首位單獨獲得者** |
| 2024 | **Acemoglu、Johnson、Robinson**（制度如何形成並影響繁榮：《國家為什麼會失敗》） |

| 行為與實驗 | 1978、1988、2002、2017 |
| 政策應用與市場設計 | 1996、1999、2010、2012、2014、2020 |

## 著名插曲

| 年份 | 事件 |
|---|---|
| 1974 | Myrdal（左）與 Hayek（右）同台——兩人互相批評對方思想，「意識形態對照組」 |
| 1975 | Koopmans 為蘇聯同行 Kantorovich 代讀演說（蘇聯限制出境，如 Margulis 之例） |
| 1986 | Krebs 等科學家聯名要求**廢除**經濟學獎（「非自然科學，非諾貝爾遺囑」）；之後每年皆有抗議 |
| 1990 | 得主三人（Markowitz 等）皆以「金融數學」登台——華爾街學術化元年 |
| 1994 | Nash（精神疾病康復後）領獎，成為電影《美麗境界》的原型 |
| 2009 | Ostrom 成為首位女性得主（「公地治理」讓無名社區自治躍上主舞台） |
| 2013 | Fama（市場有效）與 Shiller（泡沫存在）同獲——「觀點相反，同案頒獎」 |
| 2019 | Banerjee 與 Duflo 夫婦同獲——諾獎史上少見的夫妻檔（居禮家族之外的另一例） |
| 2023 | Goldin 單獨獲獎，領獎演說呼籲「貪婪工作」的結構性改革 |
