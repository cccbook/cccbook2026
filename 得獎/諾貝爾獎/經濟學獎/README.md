# 諾貝爾經濟學獎 歷史年表（詳細版）

> **獎項正名**：本獎全名「瑞典央行紀念阿爾弗雷德·諾貝爾經濟學獎」（Sveriges riksbanks pris i ekonomisk vetenskap till Alfred Nobels minne，The Sveriges Riksbank Prize in Economic Sciences in Memory of Alfred Nobel）。
> 它**不在**阿爾弗雷德·諾貝爾 1895 年的遺囑之內——遺囑只設立物理、化學、生理或醫學、文學、和平五獎。
> 1968 年，瑞典中央銀行（Sveriges Riksbank）為紀念**建行 300 週年**，捐資設立本獎並「永續」出資；**1969 年首次頒發**。
> 由**瑞典皇家科學院**依諾貝爾獎章程評選（與物理、化學獎同一程序），諾貝爾基金會管理；頒獎典禮與其他諾貝爾獎同場，於每年 12 月 10 日（諾貝爾忌日）在斯德哥爾摩舉行。
> 1969–2024 **每年皆有頒發，無缺頒年份**。

## 序幕（1895–1969）：從遺囑未含經濟學到央行捐設

| 年份 | 事件 |
|---|---|
| 1895 | 阿爾弗雷德·諾貝爾簽署遺囑，設立五項諾貝爾獎；**經濟學不在其中** |
| 1901 | 五項諾貝爾獎首度頒發 |
| 1929–1939 | 大蕭條震撼世界，各國政府亟需「科學的」經濟政策；國民帳戶、計量經濟學、宏觀模型先後成形 |
| 1930 | 美國經濟學會創立計量經濟學會（Econometric Society）的呼聲漸起；Ragnar Frisch 提出計量經濟學（econometrics）與宏觀／微觀二分 |
| 1933 | Frisch 創辦《Econometrica》；丁伯根（Jan Tinbergen）建成第一個荷蘭經濟的計量模型 |
| 1936 | 凱恩斯《就業、利息和貨幣通論》出版，宏觀經濟學誕生，也需要可操作的統計工具 |
| 1941 | Simon Kuznets 主持美國國民收入帳戶標準化，國民核算成為政府基礎設施 |
| 1944 | von Neumann–Morgenstern《賽局理論與經濟行為》出版，數理經濟學大軍進駐 |
| 1950s | 列昂惕夫（Wassily Leontief）投入產出法、Arrow–Debreu 一般均衡、Klein 宏觀計量模型相繼成熟 |
| 1955 | 瑞典央行成立 300 週年（1668–1955）的紀念氛圍埋下伏筆 |
| 1968 | 瑞典央行為慶祝建行 300 週年，向諾貝爾基金會捐設「經濟科學獎」，以紀念阿爾弗雷德·諾貝爾 |
| 1969 | 首獎頒給 Ragnar Frisch（挪威）與 Jan Tinbergen（荷蘭），表彰「發展並應用動態模型分析經濟過程」 |

## 歷屆得主全表（1969–2024）

| 年份 | 得主（貢獻關鍵詞） |
|---|---|
| 1969 | 朗納·弗里施 Ragnar Frisch（挪威）、簡·丁伯根 Jan Tinbergen（荷蘭）— 計量經濟學、動態經濟模型、宏觀經濟計量模型 |
| 1970 | 保羅·薩繆爾森 Paul A. Samuelson（美國）— 靜態與動態經濟理論的數學化、顯示偏好、對應原理、公共財 |
| 1971 | 西蒙·庫茲涅茨 Simon Kuznets（美國）— 實證經濟增長研究、國民所得帳戶、經濟增長的長期數量史 |
| 1972 | 約翰·希克斯 John R. Hicks（英國）、肯尼斯·阿羅 Kenneth J. Arrow（美國）— 一般均衡理論與福利理論的開創性貢獻（IS–LM、替代定理、社會選擇與不可能性定理） |
| 1973 | 華西里·列昂惕夫 Wassily Leontief（美國）— 投入產出法及其在重大經濟問題上的應用 |
| 1974 | 貢納爾·默達爾 Gunnar Myrdal（瑞典）、弗里德里希·哈耶克 Friedrich A. Hayek（奧地利／英國）— 貨幣與經濟波動理論；經濟、社會與制度現象相互依存的深刻分析（循環累積因果、自發秩序） |
| 1975 | 列昂尼德·坎托羅維奇 Leonid V. Kantorovich（蘇聯）、特亞林·科普曼斯 Tjalling C. Koopmans（美國／荷蘭出生）— 資源最優配置理論（線性規劃、活動分析） |
| 1976 | 米爾頓·弗里德曼 Milton Friedman（美國）— 消費分析（永久收入假說）、貨幣史與貨幣理論、穩定政策的複雜性 |
| 1977 | 貝蒂爾·奧林 Bertil Ohlin（瑞典）、詹姆斯·米德 James E. Meade（英國）— 國際貿易與國際資本流動理論（Heckscher–Ohlin 模型、國際收支調節） |
| 1978 | 赫伯特·西蒙 Herbert A. Simon（美國）— 經濟組織內決策過程的開創性研究（有限理性、滿意解、組織理論） |
| 1979 | 威廉·阿瑟·劉易斯 W. Arthur Lewis（聖露西亞／英國）、西奧多·舒爾茨 Theodore W. Schultz（美國）— 發展經濟學研究，特別關注發展中國家問題（二元經濟、人力資本與農民經濟） |
| 1980 | 勞倫斯·克萊因 Lawrence R. Klein（美國）— 建立經濟模型並應用於經濟波動與經濟政策的實證分析（大型宏觀計量模型、LINK 體系） |
| 1981 | 詹姆斯·托賓 James Tobin（美國）— 金融市場與消費、投資等實際支出決策的關聯（托賓 q、資產組合理論） |
| 1982 | 喬治·斯蒂格勒 George J. Stigler（美國）— 產業結構、市場運作與公共管制的實證研究（信息經濟學、管制俘虜理論） |
| 1983 | 羅拉爾·德布魯 Gérard Debreu（法國／美國）— 一般均衡理論的公理化（《價值理論》、存在性與最優性定理） |
| 1984 | 理查德·斯通 Richard Stone（英國）— 國民帳戶體系的建立與發展（SNA） |
| 1985 | 佛朗哥·莫迪利安尼 Franco Modigliani（義大利／美國）— 儲蓄與金融市場分析（生命週期假說、Modigliani–Miller 定理） |
| 1986 | 詹姆斯·布坎南 James M. Buchanan（美國）— 公共選擇理論：政治過程的經濟分析 |
| 1987 | 羅伯特·梭羅 Robert M. Solow（美國）— 經濟增長理論（Solow 模型、技術進步與餘值） |
| 1988 | 莫里斯·阿萊 Maurice Allais（法國）— 市場理論與資源有效利用（一般均衡的早期證明、Allais 悖論） |

| 1991 | 羅納德·科斯 Ronald H. Coase（英國／美國）— 交易成本與產權理論、社會成本問題 |

| 1993 | 羅伯特·福格爾 Robert W. Fogel、道格拉斯·諾斯 Douglass C. North（皆美國）— 計量經濟史：用理論與計量解釋制度與經濟變遷 |
| 1994 | 約翰·納什 John F. Nash、約翰·海薩尼 John C. Harsanyi、萊因哈德·澤爾騰 Reinhard Selten — 非合作賽局均衡（納什均衡及其精煉） |

## 著名插曲

| 插曲 | 說明 |
|---|---|
| 「非諾貝爾」的身世 | 諾貝爾家族後人（如 Peter Nobel）曾抗議本獎「借用」諾貝爾之名；批評者稱其為經濟學界的「公關傑作」。官方名稱因此幾度微調，且始終冠以「瑞典央行……紀念」字樣 |
| 1974 意識形態對照 | 左翼的 Myrdal 與自由意志主義的 Hayek 同年獲獎，被稱為評獎的「意識形態平衡」之作；Myrdal 事後批評委員會把獎頒給「反動分子」，甚至主張廢除本獎 |
| Hayek 的致辭 | Hayek 在晚宴演說中稱：若事先徵詢，他會「斷然反對」設立經濟學諾獎——經濟學家不應擁有如此權威，因為其影響主要落在政治家與公眾身上 |
| 1976 的抗議 | Friedman 因貨幣主義及 1975 年智利之行引發國際抗議；四位諾獎得主聯名投書《紐約時報》反對授獎 |
| 1978 首位「非經濟學家」 | Simon 的博士學位是政治學，是首位非經濟學博士得主；1994 年 Nash（數學家）獲獎後，委員會規則改動，獎項範圍重新定義為社會科學 |
| 夫妻檔 | Gunnar Myrdal（1974 經濟學）與 Alva Myrdal（1982 和平獎）是世界僅有的夫妻各自獲不同諾獎的組合 |
| 女性得主 | 至 2024 年僅三位：Elinor Ostrom（2009）、Esther Duflo（2019）、Claudia Goldin（2023，首位單獨獲獎的女性） |
| 同年頒給互相矛盾的理論 | 2013 年同時頒給支持效率市場的 Fama 與研究泡沫非理性的 Shiller，被稱為「矛盾對決」 |
| 共同得主的親師緣 | 1972 Arrow 師承 Hotelling；1997 Merton 之師 Samuelson（1970）、2004 Kydland–Prescott、2019 Banerjee–Duflo 為夫妻合作者——本獎的師徒／伴侶網絡極為密集 |
| 2013 年的「矛盾對決」 | Fama（效率市場）與 Shiller（泡沫非理性）同時獲獎，委員會刻意只提「實證分析」，兩人在《金融時報》公開互批 |
| 2019 年的夫妻檔 | Abhijit Banerjee 與 Esther Duflo 是史上第六對共同獲諾貝爾經濟學獎的夫妻，也是「共同做 RCT」的典範 |
| 2022 年的自我批判 | Bernanke 在 2022 年 8 月 Jackson Hole 演說公開承認自己在 2008 年前的寫作低估了金融系統的脆弱性與央行權力的侷限 |
| 2023 年的首位單獨獲獎女性 | Claudia Goldin 成為史上第三位女性得主（首位單獨獲獎者），以「女性勞動市場結果」為主題 |
| 2024 年的制度定調 | Acemoglu–Johnson–Robinson 以「殖民者死亡率」作為工具變數，使「制度決定繁榮」成為可被識別的因果命題 |
| 旗幟鮮明的對壘 | 1974 Hayek vs 1976 Friedman（市場派）對 1980 Klein vs 2008 Krugman（干預／模型派）；「薩繆爾森–弗里德曼之爭」貫穿 1970、1976 兩獎 |
