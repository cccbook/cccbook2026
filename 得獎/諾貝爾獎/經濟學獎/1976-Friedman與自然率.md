# 1976 · Friedman 與自然率：把「菲利普斯曲線」拆穿

> 1976 經濟學獎：Milton Friedman（芝加哥），表彰消費分析、貨幣史與穩定政策之複雜性

## 案情提要

1958 年 Phillips 用英國 1861–1957 資料畫出一條「魔幻曲線」：**通貨膨脹率與失業率負相關**——政府可以用一點通膨「買」到一點就業。1960 年代，西方各國以此為政策指南。Friedman 1968 年的總統就職演說（AER《貨幣政策的作用》）提出致命反問：**這條曲線是假象——長期而言，失業率由實體經濟決定，通膨買不到就業。**懸案：**通膨與失業到底是「取捨」還是「誤導」？**

## 前因

| 年份 | 事件 |
|---|---|
| 1958 | Phillips 曲線 |
| 1963 | Friedman–Schwartz《美國貨幣史》：大蕭條源於**聯準會緊縮貨幣**（貨幣量 1929–33 下跌 1/3），非「資本主義自毀」 |
| 1957 | 消費的永久收入假說（消費平滑，駁凱恩斯簡單消費函數） |
| 1968 | Friedman 總統就職演說提出「自然失業率」；同期 Phelps（2006 費爾茲獎）獨立給出相似結論 |

## 調查：三段推理

### 1. 自然失業率假說

失業由**實體結構**（工會、最低工資、技能錯配）決定，不由名目變數決定。短期通膨或許「騙到」工人提高勞動供給（貨幣幻覺），但一旦預期調整，失業回到自然率、通膨**留在更高位置**：

`短期：u < u*（通膨↑）`
`長期：u = u*，π 上升（菲利普斯曲線垂直）`

### 2. 預期的重要性

`π_t = πᵉ_t + α(u* − u_t)`

若預期 πᵉ 追趕實際 π，**α 項的效果蒸發**——「加速主義」：要壓低失業，通膨必須**加速**上升（不可能持續）。Friedman 主張貨幣規則（固定貨幣成長率）取代勘酌權衡（discretion）。

### 3. 貨幣數量說的復活

`MV = PY`（長期）——通膨本質上是貨幣現象（「Inflation is always and everywhere a monetary phenomenon」）。

## 理論裁決：1970 年代的實證大反轉

| 事件 | 驗證 |
|---|---|
| 1970s 美國「**滯脹**」（失業與通膨同時上升） | Phillips 曲線崩潰——Friedman 預言應驗 |
| 1979–82 Volcker 緊縮 | 以貨幣規則（實際上以利率規則）終結高通膨，失業暫時升過自然率後回落——**垂直長期曲線的教科書驗證** |
| 1990s 起央行獨立性、通膨目標制 | 全球央行制度改革的理論基礎（Bernanke 2022 費爾茲獎案的制度面） |

## 後果

| 層面 | 影響 |
|---|---|
| 宏觀 | 「預期」成為第一公民 → Lucas（[1995-Lucas批判](1995-Lucas批判.md)）把它推向極致 |
| 政策 | 貨幣主義 → 泰勒規則 → 通膨目標制；「貨幣不是萬能，但貨幣亂來必出事」 |
| 意識形態 | 芝加哥學派崛起；Friedman《自由選擇》使自由市場成為 1980s 全球主流話語 |
| 爭議 | 智利皮諾契特政權的「芝加哥男孩」顧問案——Friedman 一生最重的道德爭議 |
| 後續修正 | 2008 金融危機後「貨幣中性」受到新凱因斯主義挑戰（ZLB、量化寬鬆的實踐）——二審持續 |
