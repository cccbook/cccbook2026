# 2009 · Ostrom 與公地治理：漁民比理論家更早解決「公地悲劇」

> 2009 經濟學獎：Elinor Ostrom（首位女性經濟學獎得主）與 Oliver Williamson，表彰「經濟治理，特別是公共資源」的分析

## 案情提要

1968 年 Hardin 的《公地悲劇》給出著名預言：**共用牧場上，每個牧民都有動機多放一頭牛，最終草場毀滅。**標準藥方只有兩種：**私有化**（[1991-Coase定理](1991-Coase定理.md) 的方案）或**政府管制**。Ostrom 的問題：**等等——現實中沒有私有化也沒有中央管制的公地（瑞士高山牧場、菲律賓灌溉系統、緬因州龍蝦場），為什麼幾百年沒有崩潰？**她用三十年田野調查找到了第三種答案：**社區自治**。

## 前因

| 年份 | 事件 |
|---|---|
| 1954–68 | Gordon（1954）、Hardin（1968）公地悲劇模型 |
| 1960s–80s | Ostrom（印第安納大學政治學家）與丈夫 Vincent 建立 Workshop in Political Theory |
| 1985–90 | Ostrom 團隊田野調查 5,000+ 灌溉、漁場、森林案例，建立 CPR 資料庫 |
| 1990 | 《Governing the Commons》出版 |
| 2009-10-12 | Ostrom 成為**首位女性經濟學獎得主**（2012 年逝世） |

## 調查：Ostrom 的八條設計原則

從田野資料中歸納出**成功自治體的共同特徵**：

| # | 原則 |
|---|---|
| 1 | **清晰邊界**（誰能用、用多少） |
| 2 | **規則符合當地條件**（不成文的本地慣例） |
| 3 | **集體選擇安排**（使用者參與制定規則） |
| 4 | **監督**（由本地人執行） |
| 5 | **分級制裁**（輕罪輕罰、慣犯重罰） |
| 6 | **衝突解決機制**（廉價、本地的法庭） |
| 7 | **最低限度的國家承認**（政府不推翻自治權） |
| 8 | **嵌套式治理**（大系統分層結構） |

**理論裁決的關鍵**：公地悲劇的博弈結構是**一次性囚徒困境**（[1994-Nash均衡](1994-Nash均衡.md)），但真實社區是**重複賽局**——

`若貼現因子 δ 夠大，合作（少放牛）可成為子賽局完美均衡（Folk theorem）`

**社會規範、名譽、監督**是把一次性困境轉成重複賽局的制度機器。Ostrom 的貢獻是**指出哪些制度能穩定地維持這種重複**。

## 理論裁決

- Ostrom 的 IAD 框架（Institutional Analysis and Development）成為治理研究的通用工具。
- Williamson（同案）以「**交易成本 + 資產專用性**」給出企業/市場/混合制的選擇理論（[1991-Coase定理](1991-Coase定理.md) 的量化版）：資產專用性越高，越傾向內部組織而非市場。

## 後果

| 層面 | 影響 |
|---|---|
| 環境 | 漁業配額、社區林業（尼泊爾、印度）、水權——「社群治理」成為第三條路 |
| 氣候 | Ostrom 2010 年公開主張**多層級、多中心治理**（polycentric）——2018 Nordhaus 得主同脈 |
| 方法論 | **田野資料 + 博弈論 + 制度分析**——政治學與經濟學的交界 |
| 判例 | 首位女性經濟學獎得主（2009）；2023 Goldin 為第二例（相隔 14 年） |
