# 1952 · 鏈黴素：第一個對抗結核病的抗生素

> **1952 諾貝爾生理學 or 醫學獎**：賽爾曼·亞伯拉罕·瓦克斯曼（Selman Abraham Waksman，美國）— 表彰「發現鏈黴素，第一個有效對抗結核病的抗生素」（"for his discovery of streptomycin, the first antibiotic effective against tuberculosis"）。

## 懸案（案情提要）

1940 年代末，結核病仍是工業化國家的頭號死因之一：抗結核的化學藥物只有對氨苯甲酸（PABA）類的**磺胺劑**（對早期病灶有效，但療效有限、需長期服用），以及 1940 年代被寄予厚望的**異菸鹼醯肼（isoniazid，INH）**——但 INH 的臨床效果要到 1952 年才被確立。結核桿菌（見 [1905-結核桿菌與柯霍法則](1905-結核桿菌與柯霍法則.md)）在體內的行為極其頑強：**細胞壁含分枝菌酸、繁殖緩慢、會進入潛伏狀態**，是所有病原中最難對付的之一。

於是有一個極具野心的目標：**找到一個能滲透進結核病灶、直接殺死結核桿菌的抗生素**。

瓦克斯曼的答案是：**鏈黴素（streptomycin）**——第一個 aminoglycoside（胺基糖苷）類抗生素，也是第一個對結核病有效的抗生素。

## 前因

| 年份 | 事件 |
| --- | --- |

| 1903–1904 | 瓦克斯曼隨 Selman Waksman 的老師 **Martinus W. Beijerinck**（微生物學的先驅之一）學習；Beijerinck 於 1898 年提出「病毒（contagium vivum fluidum）」概念。 |
| 1915–1920s | 瓦克斯曼在 Rutgers 大學建立土壤微生物學研究，開始研究**放線菌（actinomycetes）**——這類微生物是土壤中微生物數量最多的類群之一。 |
| 1913 | 瓦克斯曼與他的研究生 **Albert Schatz** 分離出 ** Streptomyces griseus**（當時稱 *Actinomyces griseus*）。 |

| 1943 年 9 月 | 瓦克斯曼的研究生 **Albert Schatz** 在實驗室分離出一株能抑制結核桿菌的放線菌：**Streptomyces griseus**（後來被瓦克斯曼命名）。 |
| 1943–1944 | Schatz 完成了初步的抗菌試驗，證明其對多種革蘭氏陰性菌與陽性菌有效。 |

| 1944–1945 | Feldman 與 Hinshaw 在 1944–1946 年進行人體試驗，治療結核腦膜炎與粟粒性結核，取得劃時代的成功。 |
| 1946–1948 | 大量臨床試驗展開，確認鏈黴素是「第一種能治療結核病（尤其肺結核）的抗生素」。 |
| 1952 | 瓦克斯曼獲諾貝爾生理學 or 醫學獎。 |
| 1950s–1960s | 鏈黴素的耳毒性與腎毒性被認識；**1962 年Howard 表霉（kanamycin）** 問世；1960 年代**乙胺丁醇**與**利福平**加入，形成現代的抗結核多藥聯合治療。 |
| 1970s–2000s | 瓦克斯曼的基金會被他的學生 Schatz 控告「淡化 Schatz 的貢獻」，最終在 2000 年代以 300 萬美元的和解終結。 |

## 調查

### 第一幕：篩選器的設計——「土壤是抗生素的寶庫」

瓦克斯曼的核心洞見是**生態學的**：放線菌在土壤中數量極多，而它們的代謝產物被用來**競爭**其他微生物——那麼，這些物質很可能就是天然的抗生素。他的篩選系統如下：

```mermaid
flowchart TD
    A[采集全球土壤樣本<br>數千株放線菌] --> B[純化培養，每株編號]
    B --> C[抑制圈測試:<br>與各種病原菌共同培養]
    C --> D[記錄抑制圈直徑<br>作為活性的定量指標]
    D --> E{最高活性株}
    E --> F[Streptomyces griseus<br>(Schatz 找到, 1943)]
    F --> G[液體培養 + 萃取 + 濃縮]
    G --> H[對結核桿菌的體內療效測試]
    H --> I[Mayo Clinic: Feldman 與 Hinshaw<br>豚鼠 → 人體]
```

抑制圈法本身就是本案最實用的工具貢獻之一——它把「抗菌活性」變成**可量化、可比較**的數值，是現代抗生素篩選（96 孔微量稀釋法）的直系祖先。

### 第二幕：Feldman 與 Hinshaw 的關鍵實驗

這是本案科學價值的核心。梅奥診所的結核病權威 Feldman 與 Hinshaw 做了三件事：

1. **體外驗證**：鏈黴素在試管中抑制結核桿菌的生長（MIC 極低）；
2. **體內驗證（豚鼠）**：**感染結核桿菌的豚鼠**，給予鏈黴素後**病灶不再進展、甚至癒合**；未治療對照組則迅速死亡。這是藥物對抗結核的第一份體內證據；
3. **臨床驗證（人體）**：1944 年起，他們以鏈黴素治療結核性腦膜炎與粟粒性結核——**在抗生素之前，這些診斷等同死刑**；治療後的部分病人得以存活。

第二、三項之所以關鍵，是因為結核的臨床試驗有個麻煩：**肺結核的病程變異極大，傳統的臨床印象難以判定療效**。Feldman 與 Hinshaw 選的 meningitis 與粟粒性結核則是「可判定」的終點明確的疾病——這是抗生素臨床驗證方法學的重要一步。

### 第三幕：機制的破解——「不可被鈍化的酵素」

鏈黴素的作用機制在 1950–1970 年代逐步被釐清：

1. **作用部位**：**30S 核糖體次單元**（16S rRNA 與 S12 蛋白）——這是 aminoglycoside 類的共同靶點，與其他抗生素類別（如抑制 50S 的 macrolide、抑制 50S peptidyl transferase 的 chloramphenicol）不同；
2. **機制**：鏈黴素進入細菌後，經主動運輸進入細胞，結合 30S 次單元，造成 **mRNA 的錯誤讀取（misreading）**，插入錯誤胺基酸，並抑制蛋白質合成的起始：

   $$\text{mRNA codons} \xrightarrow{\text{streptomycin}} \text{wrong amino acids} \Rightarrow \text{misfolded proteins}$$

3. **細菌對它的抗性機制**：最常見的是**胺基糖苷修飾酵素（aminoglycoside-modifying enzymes）**——如磷酸轉移酶、腺苷轉移酶——將藥物磷酸化或腺苷酸化使其失活；這些基因常位於**質體（plasmids）**上，因而可在細菌群落中水平轉移——這是多重抗藥性的分子基礎之一。

4. **耳毒性的機制**：鏈黴素對**耳蝸感覺細胞**與**腎臟近曲小管**有親和性，經自由基生成與訊號干擾造成細胞損傷——這也是今日「耳毒性藥物」（aminoglycoside、vancomycin、loop diuretics）需要血中濃度監測（TDM）的原因。

### 第四幕：從單藥到多藥——現代抗結核方案的形成

鏈黴素開啟了抗結核化療，但單藥迅速遭遇**抗藥性**（結核桿菌的抗藥性突變率中等，且在體內大量繁殖時不可避免）。1960 年代的突破是**多藥聯合**：

| 藥物 | 機制 | 引入年代 |
| --- | --- | --- |
| 異菸鹼醯肼（INH） | 抑制 mycolic acid 合成（inhA） | 1952 年臨床確立 |
| 利福平（Rifampin） | 抑制 RNA 聚合酶（rpoB） | 1960 年代 |
| 乙胺丁醇（Ethambutol） | 抑制 arabinosyl transferase（embB） | 1960 年代 |
| 吡嗪醯胺（PZA） | 影響分枝菌酸合成（pncA） | 1950–60 年代 |
| 鏈黴素（Streptomycin） | 30S 次單元 | 1944 |

現代標準方案是 **2HRZE/4HR**（異菸鹼醯肼、利福平、吡嗪醯胺、乙胺丁醇），短期使用鏈黴素僅用於重症（結核腦膜炎）。

## 理論裁決

1. **多藥聯合的數學理據**：抗結核治療需至少兩種作用機制不同的藥物，其理由可用抗藥性突變概率說明：

   $$P(\text{多重抗藥}) \approx p_1 p_2 p_3 p_4$$

   若各藥單獨的抗藥率約 $10^{-6}\text{–}10^{-5}$ ，四藥聯用使抗藥性出現的概率降至約 $10^{-24}$ 量級——這在數學上解釋了為何「至少兩種藥、最好四種」成為結核治療的鐵律。

2. **藥代動力學與給藥間隔**：aminoglycoside 具有**濃度依賴性殺傷（concentration-dependent killing）**與**高後效（post-antibiotic effect）**，因此每日一次高劑量給藥比分次給藥更有效——這是 1990 年代藥動學的重要發現，直接影響了鏈黴素的用法。

3. **抗生素敏感試驗的量化**：MIC 與 MBC 測定（以及 Kirby–Bauer 擴散法）成為全球標準，正是鏈黴素的篩選與臨床使用所催生：

   $$\text{MIC} = C_{\min}\ \text{such that growth is inhibited}$$

4. **「發現者」歸屬的倫理**：瓦克斯曼獲得全部榮譽與專利收益（包含後來價值數十億美元的專利授權），而真正的第一發現者——他的研究生 **Albert Schatz**——只得到 4% 的專利收益與一份被大幅縮水的諾獎提名。Schatz 於 1950 年退出並最終在 2000 年代訴訟勝利（瓦克斯曼基金會以 300 萬美元與 Schatz 姓名被放入 Rutgers 的 Waksman 實驗室徽章與「Albert Schatz 博士」榮譽館達成和解）。**這樁 50 年的正義遲到案，是科學史上歸屬不公最著名的案例之一**。

## 追查支線（未結之謎）

- 鏈黴素的耳毒性（尤其在結核腦膜炎患兒中造成不可逆耳聾）催生了「耳毒性監測」的臨床規範，也促成 1960 年代**卡那黴素（kanamycin）**等毒性較低者的開發；
- 結核病在 1990 年代因 HIV 疫情而回潮（見 [1990-器官與骨髓移植](1990-器官與骨髓移植.md) 時代的公共衛生），2000–2010 年代又因 MDR-TB 與 XDR-TB 的出現而再度緊張；
- 今日的結核研究重點已轉向**宿主反應**（如宿主遺傳多型性影響的發病風險）與**新藥研發**（bedaquiline、delamanid）；
- 瓦克斯曼 1952 年獲獎時已 64 歲，是諾獎史上最年長的生理學或醫學獎得主之一（至 2020 年代仍保持紀錄）；
- 瓦克斯曼基金會的部分收益曾資助具爭議性的項目（如對早期種族智力差異的研究），成為諾獎財富使用倫理討論的另一個案例。
