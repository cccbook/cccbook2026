# 1962 · DNA 結構諾獎：雙螺旋的三份證詞與一位缺席者

> 1962 諾貝爾生理學或醫學獎：華生（James Watson）、克里克（Francis Crick）、威爾金斯（Maurice Wilkins），表彰 1953 年 DNA 分子結構之發現；羅莎琳·富蘭克林（Rosalind Franklin）1958 年死於卵巢癌，未獲追授

## 案情提要

1953 年 4 月 25 日《Nature》同期刊出三篇論文：華生-克里克的模型（900 字）、威爾金斯與斯托克斯的 X 光數據、富蘭克林與戈斯林的 B 型 DNA 照片。結構之謎由「證物」與「推理」兩半拼成：富蘭克林提供了最關鍵的證物（**照片 51**），華生與克里克完成了推理。本案的爭議不在科學對錯，而在**證物如何流轉**。

| 年份 | 事件 |

| 1944 | 艾弗里的肺炎雙球菌轉化實驗：**轉化因子是 DNA**（主流仍不信） |
| 1952 | 赫希-蔡斯攪拌實驗：噬菌體注入細菌的是 DNA——**DNA 是遺傳物質定讞** |
| 1950 | 查加夫法則：A=T、G=C（數量恆等） |
| 1950–52 | 富蘭克林在倫敦國王學院拍出 **B 型 DNA 的 X 光繞射圖**（濕態、生理構型） |

## 調查：證物與推理

富蘭克林的 X 光結晶學提供了四條定量線索：

1. **十字花樣**（cross）：螺旋特徵，直徑均一。
2. **層線間距 3.4 Å**：相鄰鹼基對垂直間距。
3. **每 10 鹼基旋轉一圈**（螺距 34 Å）。
4. **雙向對稱的纖維圖**指向**兩條反向平行鏈**（雙螺旋）。

華生-克里克的推理（多倫多-劍橋，模型建造法）：

- 以鹼基配對模型對帳：A–T 之間 2 個氫鍵、G–C 之間 3 個——**查加夫等式自動成立**；嘌呤配嘧啶使雙鏈直徑恆定。
- 骨架在外（親水磷酸朝外）、鹼基朝內像「梯子的橫檔」——熱力學合理。
- **自我複製的暗示**：兩鏈互補，解開即模板——遺傳機制的幾何基礎（克里克後來以半保留複製預言，1958 梅塞爾森-斯塔爾實驗證實）。

著名公案：1953 年初，威爾金斯在華生訪問時**未經富蘭克林同意**出示了照片 51；倫敦國王學院還把富蘭克林未發表的報告（MRC report）經 Max Perutz 交到劍橋小組手中。**推理者看了證物而證物採集者不知情**——科學倫理的世紀案例。

## 理論裁決

- 雙螺旋模型的精髓：`A=T`、`G≡C` 的**互補性**使「結構」與「資訊」合而為一——序列既存儲資訊，又規定複製。
- 中心法則（1958 克里克）：`DNA → RNA → 蛋白質`；序列假說（1958）：核酸序列決定蛋白質序列（[1958-山格定序胰島素](../化學獎/1958-山格定序胰島素.md) 的理論對仗）。
- 例外清單（後續修訂）：反轉錄（[1975-反轉錄酶](1975-反轉錄酶.md)）、RNA 干擾（2006）、表觀遺傳（甲基化、組蛋白修飾）——法則是「主流路徑」，非「唯一路徑」。

## 後果與遺憾

| 層面 | 事件 |
|---|---|
| 科學 | 分子生物學全面開張：遺傳密碼（1968）、操縱子（[1965-操縱子](1965-操縱子.md)）、重組 DNA（[1980-DNA定序](../化學獎/1980-DNA定序.md)） |
| 富蘭克林 | 1958 年 37 歲死於卵巢癌（可能與 X 光長期暴露相關）；諾委會規則不追授死者。若在世，依慣例極可能成為第四位得主（或依三人上限成為另一場分配慘案） |
| 威爾金斯 | 坦承「從未與富蘭克林正常合作」；晚年致力和平運動 |
| 性別史 | 「Photo 51 之爭」成為科學界性別偏見的標誌案例；2012 年倫敦國王學院設富蘭克林研究所以為紀念 |
| 命名 | 「DNA 之母/父」的敘事至今在教材中爭論不休——本案的**社會學判決仍在二審** |
