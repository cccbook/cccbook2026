# 1979 · 電腦斷層掃描：科馬克與豪斯費爾德把 X 射線的疊影變成身體的切片

> **1979 諾貝爾生理學 or 醫學獎**（共享）：阿蘭·麥克萊德·科馬克（Allan McLeod Cormack，美國）— 表彰「開發電腦輔助的斷層掃描技術」；高弗雷·豪斯費爾德（Godfrey Newbolt Hounsfield，英國）— 同上。

## 懸案（案情提要）

1970 年代的醫學影像有兩塊互補的短板：

1. **X 光平片**：把三維身體疊成二維影像——縱隔、肋骨與心臟互相重疊，無法看清胸腔內的細節；
2. **侵入性檢查**：血管造影、心導管、超聲（當時解析力有限）——有風險，且大多只能看到「管子」而非「組織」。

核心疑點：

1. **能不能只顯示身體的某一個薄層？** 若能把三維物體的投影資料，重建為每一層的影像，就等於給醫生一個「身體的切片檢視器」。
2. **反過來想**：X 射線的透視投影是**資訊損失**的過程——數百張投影圖真的包含足夠資訊來重建三維物體嗎？（答案是肯定的，但需要正確的數學與演算法。）
3. 放射劑量能否降到可接受？

科馬克在 1963–1964 年的理論計算，與豪斯費爾德在 1971–1972 年的工程實作，給出了答案：**CT（computed tomography，電腦斷層掃描）**。

## 調查

### 第一幕：科馬克的「逆問題」——從影子重建實體

科馬克的問題，是一個純粹的**數學問題**，卻有巨大的生物醫學意義：

**問題陳述**：給定物體各個方向的投影（透視 X 光），能否重建其內部結構？

```mermaid
flowchart TD
    A[物體的 3D 密度分布 f(x,y,z)] --> B[X 射線從多個角度投影<br>得到 2D 影像 p(θ, t)]
    B --> C{這是什麼類型的問題?}
    C --> D["逆問題 (inverse problem)<br>：已知投影，求 f"]
    D --> E[科馬克的解法:<br>用 Radon 變換的數學<br+ 迭代反演演算法]
    E --> F[得到 f(x,y,z) 的近似<br>= 每個體素的 CT 值]
    F --> G[重建出身體的「切片」]
```

**科馬克的兩項貢獻**：

1. **證明重建在數學上是可能的**（用簡單模型驗證，並指出實務上的噪聲與不完全投影需要「反覆修正」的演算法——他的思想後來被稱為**「反覆反投影法（iterative back-projection）」**與「**代數重建法（algebraic reconstruction technique, ART）」**的先驅）；
2. **把放射劑量降到可接受**：他論證以「拉東變換的反演」重建，**理論上只需原平片劑量的一小部分**——這是 CT 能夠臨床化的關鍵前提。

**科馬克的科學處境**：他的論文發表在《計算生物物理與生物醫學雜誌》——一本冷門的邊緣期刊，**完全沒有被生物醫學界注意到**。他投給《自然》的姊妹期刊的相關稿件被拒。他一直不知道 EMI 的工程師 Hounsfield 已經把想法實現了。**兩人在 1972 年的一次會議上才第一次見面**——這是科學史上最戲劇性的「平行發現」之一（另一樁類似的平行案例是 [1946-X 射線誘發突變](1946-X射線誘發突變.md) 時代的 X 射線工作）。

### 第二幕：豪斯費爾德的工程實現

Hounsfield 的問題是：**如何在 1970 年代的技術條件下做出可用的機器？**

**關鍵的工程決策**：

1. **光源**：最初使用 **He-Ne 雷射**（ $632.8\ \mathrm{nm}$ ，單色性好、便於濾波），後改為 **X 射線管**（今日的標準），因雷射昂貴且功率不足；
2. **掃描幾何**：早期為**平移—旋轉（translate-rotate）**方式——X 射線管與偵測器同步平移，然後繞頭部旋轉；今日的**錐形束幾何（cone-beam）**則更快速；
3. **「分次抽取（divided scan）」與「累積掃描（accumulation scan）」**：Hounsfield 發明兩種掃描模式以在**降低劑量**與**降低偽影**之間取捨；
4. **數位化與濾波**：早期影像用類比方式處理（因為當時的電腦太慢），必須用**反卷積（deconvolution）**來重建，否則邊緣模糊——Hounsfield 的「反卷積核（convolution kernel）」設計極為精細。

**第一台 EMI 掃描器的規格**：掃描時間約 4–5 分鐘／切片、單一 slice 厚約 15 mm、**輻射劑量約 3 倫琴（3 R）**（相當於約 70 次胸片的劑量，但集中在狹窄的一層）。

**1971 年 10 月 1 日的第一位病人**：一位懷疑腦腫瘤的病人做了檢查，掃描清楚顯示一個大的、對比低於正常腦組織的區域——後來開刀證實是一個囊性腫瘤。**放射科醫師 James Ambrose 描述那一刻：「那就像打開了一盞燈。」**

### 第三幕：CT 值——HU 標度

掃影重建的每一個體素都給出一個數值，稱為 **CT 值（Hounsfield Unit, HU）**，以純水定為 0：

| 組織 | HU（近似） |
| --- | --- |
| 空氣 | $-1000$ |
| 脂肪 | $-100$ 至 $-50$ |
| 水 | $0$ |
| 血液 | $+30$ 至 $+45$ |
| 軟組織 | $+20$ 至 $+70$ |
| 鈣化、骨 | $+700$ 以上 |

這個**線性的灰階標度**是 CT 臨床價值的核心：醫生可以直接由灰階判讀組織性質（出血 vs 缺血 vs 腫瘤），這在傳統 X 光平片上是做不到的。

### 第四幕：從頭部到全身——CT 的擴張

1976 年 EMI 推出全身掃描器後，CT 迅速擴展到急診醫學：

1. **急診室的標準工具**：**頭部 CT**（急性中風、腦出血、外傷）成為急診室的基本檢查；
2. **胸部 CT**：肺部結節、縱隔淋巴结的判讀；
3. **腹部與骨盆腔 CT**：急腹症、結石、腫瘤分期；
4. **冠狀動脈 CT 造影（CTA）**（2000 年代）：非侵入性檢查冠狀動脈；
5. **CT 導引介入手術**（活檢、引流、穿刺）；
6. **骨密度測量（DXA）**：骨質疏鬆的診斷與骨折風險評估——這是 CT 的一個平行分支（今日的 DXA 是扇形束 CT 的應用）。

**CT 與 MRI 的分工**（1970s 以後的影像學史）：

| | CT | MRI |
| --- | --- | --- |
| 物理基礎 | X 射線吸收 | 核磁共振 |
| 對比度來源 | 密度（原子序） | 質子密度與弛豫時間 |
| 對鈣化 | 極佳 | 差 |
| 對軟組織 | 較差 | **極佳** |
| 骨頭伪影 | 有 | 無 |
| 速度 | **快**（數秒） | 慢（數分鐘） |
| 費用 | 較低 | 較高 |

## 理論裁決

1. **拉東變換與重建定理**：CT 的數學核心是：

   $$p(\theta, t) = \int_{\text{射線}} f(x,y,z)\, d\ell = \mathcal{R}f(\theta,t)$$

   **投影切片定理（Projection-Slice Theorem）**說明：物體的傅立葉轉換在極角為 $\theta$ 的徑向切片上，等於其投影的傅立葉轉換——**只要在足夠多的角度採集投影，就可重建 $f$**。這是 CT 的存在性定理。

2. **濾波反投影（Filtered Back Projection, FBP）**：Hounsfield 與其團隊在 EMI 實際使用的重建方法（由 **Cormack 與 1970 年代的投影切片定理**提供理論基礎，演算法由 **Kak 與 Slaney 系統化**）：

   $$\text{影像} = \mathcal{F}^{-1}\left[\vert \omega(\theta)\vert \cdot \mathcal{F}[p(\theta,t)] \right] \text{ 對所有角度平均}$$

   其中 $\vert\omega\vert$ 是**拉東濾波器（Radon filter）**，其高頻加權用來**補償射線束的模糊**——這是 CT 影像「銳利」的關鍵，也是 Hounsfield 早期類比反卷積核的理論對應。

3. **劑量與重建的關係**：**提高射線光子數**可降低量子雜訊，但也增加病人劑量。CT 的設計本質是在**影像品質（SNR）與劑量**間取捨：

   $$\mathrm{SNR} \propto \sqrt{N_{\text{photons}}}$$

   早期頭部掃描用極少的光子數（劑量低、雜訊大），今日的迭代重建技術則可在**更低劑量**下獲得更好影像——這是 1990 年代以後的技術革命。

4. **CT 與「數位時代」的相乘效應**：CT 把影像變成**數據**，從而使「影像的處理」成為可能——今日的**影像 AI（結節偵測、分割、放射治療自動定位）**是這條路的延伸；而 2000 年代的 **DICOM 標準**則讓影像可以跨機構流通。

## 追查支線（未結之謎）

- **平行發現的悲喜**：科馬克與 Hounsfield 各自獨立構想了解決方案，卻直到 1972 年才互相認識——科馬克隨後為 EMI 提供數學諮詢，並與 Hounsfield 共同獲得諾獎。**科馬克後來形容，這段經歷「像兩個人各自在不同時間發明了飛機，卻在同一天相遇」**；
- **諾貝爾委員會的表態**：委員會在 1979 年的新聞稿中特別指出，CT 帶來的「**對人類經濟與社會的效益**」——這在諾獎史上相當罕見，因為委員會通常只談科學貢獻；
- **輻射防護的張力**：CT 帶來了「**影像過度使用（over-imaging）**」的問題——今日全球的 CT 檢查量以每年數十億計，兒童的輻射暴露尤其受關注；這是 20 世紀「影像醫學」與「放射防護」之間持續的張力；
- **EMI 的命運**：EMI 是英國的電器巨頭，CT 是它歷史上最成功的產品之一，也是**英國在 1970–80 年代科技競爭中的旗艦成就**（與 1980 年的巡空母艦「_invincible」並列為英國的科技象徵）；但 EMI 後來因財務危機被 GEC 收購，再併入 Thomson，2018 年被法國湯臣倍億（Technicolor）收購；
- **今日的 CT 競爭者**：MRI、PET、超聲與 CT 各有擅長的領域；而 CT 的「終極版本」是**光子計數 CT（photon-counting CT）**，今日正在進入臨床——它以光子計數取代劑量測量，可在**更低劑量**下獲得更高解析度，並能直接做能譜成像（碘定量、物質分解）。
