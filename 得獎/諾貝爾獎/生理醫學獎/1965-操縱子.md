# 1965 · 操縱子：基因並非全部開著

> 1965 諾貝爾生理學或醫學獎：雅各（François Jacob）、莫諾（Jacques Monod）、勒夫（André Lwoff），表彰基因調控與病毒合成之研究（巴斯德研究所，1958–1961）

## 案情提要

1950 年代的公認圖景：DNA 上每一個基因都「隨時待命」，轉錄與否只取決於酶的活性調節。但疑點明顯：**為什麼大腸桿菌只有在培養液裡有乳糖時，才大量合成乳糖消化酶？**（1959 年 Pardee-Jacob-Monod 的「巴斯德效應」測量顯示：誘導後 β-半乳糖苷酶合成速率提升千倍。）若所有基因全時轉錄，細胞將浪費大量資源——必然有「開關」。開關在哪？

## 前因

| 年份 | 事件 |
|---|---|
| 1940s | 莫諾研究細菌「二次生長現象」（diauxie）：先吃葡萄糖、後吃乳糖——**乳糖酶系統是可誘導的** |
| 1953 | 華生-克里克雙螺旋（[1962-DNA結構諾獎](1962-DNA結構諾獎.md)）確立「資訊在序列裡」 |
| 1957–58 | 帕迪-雅各-莫諾（PaJaMo）實驗：以接合遺傳法證明調控者是**基因層級**而非酶層級 |

## 調查：巴斯德研究所的四條證據

雅各與莫諾以大腸桿菌乳糖系統（lac）為案發現場，鑑定出四個嫌疑人：

1. **阻遏蛋白（repressor，lacI）**：突變 `lacI⁻` → 不誘導也持續表達（組成型）。存在一個「關閉者」。
2. **操縱基因（operator，lacO）**：`Oᶜ` 突變 → 即使有阻遏蛋白也關不住。阻遏的**結合位點**在基因「上游相鄰處」，且**順式**作用（只管同一條 DNA 上的基因）。
3. **操縱子（operon）**：Z（β-半乳糖苷酶）、Y（通透酶）、A（轉乙醯酶）三個結構基因**一條 mRNA 同時轉錄**（多順反子 mRNA，1961 電鏡與生化證據）——基因以「模組」被統一開關。
4. **誘導物**：乳糖（真實誘導物為異乳糖 allolactose）與阻遏蛋白結合 → 構象改變、從操縱基因脫落 → 轉錄開始。

模型總結（1961 年《分子生物學雜誌》著名論文）：

`無乳糖：lacI → 阻遏蛋白 → 結合 lacO → RNA 聚合酶被擋 → OFF`
`有乳糖：異乳糖 + 阻遏蛋白 → 脫離 → 轉錄 Z-Y-A → ON`

## 理論裁決

- **調控的單位是「模組」**：雅各與莫諾提出 operon 與 messenger RNA（mRNA）兩個概念——後者直接催生分子生物學的「資訊流」語言（中心法則的動力學版）。
- 莫諾的哲學收尾（1970《偶然與必然》）：酶的調控如同**變構效應**（allostery，Wymon–Monod–Wyman 模型 1965）——蛋白質有兩種構象、配體改變構象平衡。**變構是生命的開關語言**（血紅蛋白 S 型曲線、受體信號、神經通道，一脈相承）。
- 「電路思維」進入生物學：操縱子=邏輯閘（NOT/AND），回饋環=控制論——今日合成生物學（toggle switch、振盪器）直接沿用 1961 年的語法。

## 後果

| 層面 | 影響 |
|---|---|
| 分子生物學 | 「基因有開與關」→ 發育生物學（[1975-反轉錄酶](1975-反轉錄酶.md) 同期的真核調控接力）、表觀遺傳 |
| 醫學 | 抗生素以操縱子機制被設計（四環素、大環內酯阻斷核糖體）；致癌基因=失控的調控（1989 諾獎） |
| 生物技術 | 啟動子-操縱基因成為基因工程的「接口」（lac、T7、tet 啟動子系統）——每一個重組蛋白製程都在用 1961 年的開關 |
| 演化 | 莫諾「偶然與必然」：突變是偶然、選擇是必然——與 1977 年的「中性演化」（木村資生）展開的世紀辯論 |
