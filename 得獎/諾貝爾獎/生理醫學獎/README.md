# 諾貝爾生理學或醫學獎 歷史年表（詳細版）

> 本年表由卡羅琳斯卡醫學院（Karolinska Institutet）諾貝爾大會（Nobel Assembly）頒發之「諾貝爾生理學或醫學獎」全部得主與事由編成，涵蓋 1901–2025 年。獎項依阿爾弗雷德·貝恩哈德·諾貝爾（Alfred Bernhard Nobel, 1833–1896）1895 年遺囑設立，每年 12 月 10 日（諾貝爾忌日）在斯德哥爾摩頒發。

本書體裁為「推理探案式 wiki」：每一年份一宗「醫學懸案」，把謎團寫成案情、把實驗寫成偵查、把機制寫成裁決。逐年檔案見文末清單。

## 序幕（1895–1900）：一紙遺囑，五項大獎

| 年份 | 事件 |
| --- | --- |
| 1895 | 諾貝爾於巴黎簽署著名遺囑，指定以遺產利息設立五項大獎，其中「生理學或醫學獎」由**卡羅琳斯卡醫學院**（當時的卡羅琳學院，瑞典皇家醫學校）頒發——這是唯一由醫學院校主導的諾貝爾獎。 |
| 1896 | 12 月 10 日，諾貝爾於義大利聖雷莫逝世，遺囑曝光，引來瑞典王室與學界激烈爭議。 |
| 1897 | 遺囑經多年訴訟後獲瑞典國王核准；諾貝爾基金會於 1900 年正式成立。 |
| 1900 | 各頒獎機構章程底定：生理學或醫學獎的評選權交由卡羅琳學院醫學教授團（後於 1977 年改制為獨立的諾貝爾大會）。 |
| 1901 | 首屆頒獎典禮於 12 月 10 日在斯德哥爾摩舉行，生理學或醫學獎首度頒出——德國細菌學家埃米爾·阿道夫·馮·貝林以白喉血清療法摘下第一頂桂冠。 |

## 1901–1920：血清、瘧蟲與神經的黃金偵查年代

細菌學革命的收穫期：血清療法、瘧疾傳播鏈、結核桿菌、免疫理論、神經元學說陸續定案；一戰迫使獎項停頓四年。

| 年份 | 得主 | 事件／貢獻 |
| --- | --- | --- |
| 1901 | 埃米爾·阿道夫·馮·貝林（Emil Adolf von Behring，德國） | 白喉血清療法：以馬免疫血清中的抗毒素治療白喉，開啟被動免疫醫學，首屆諾貝爾生理學或醫學獎。 |
| 1902 | 羅納德·羅斯（Ronald Ross，英國） | 證明瘧疾由瘧蚊（按蚊）傳播，於鳥類體內發現瘧原蟲在蚊胃中的發育週期，奠定抗瘧防治基礎。 |
| 1903 | 尼爾斯·呂貝里·芬森（Niels Ryberg Finsen，丹麥） | 以聚集光線（碳弧燈）照射治療尋常狼瘡（皮膚結核），開創光療醫學。 |
| 1904 | 伊萬·巴甫洛夫（Ivan Petrovich Pavlov，俄國） | 消化生理學：以犬隻慢性實驗（唾液瘻管、假飼、巴甫洛夫小胃）闡明消化腺的神經調節，並由此發現條件反射。 |
| 1905 | 羅伯特·柯霍（Robert Koch，德國） | 結核病研究：1882 年發現結核桿菌、確立柯霍法則，1890 年發表結核菌素；獲獎表彰其結核病相關研究與發現。 |
| 1906 | 卡米洛·高基（Camillo Golgi，義大利）與聖地牙哥·拉蒙-卡哈爾（Santiago Ramón y Cajal，西班牙） | 神經系統結構研究：高基染色法（1873）與卡哈爾的神經元學說，確立神經系統由獨立神經元構成。 |
| 1907 | 夏爾·路易·阿方斯·拉韋朗（Charles Louis Alphonse Laveran，法國） | 證明原生動物（瘧原蟲、錐蟲等）可致病：1880 年在人血中發現瘧原蟲，開創醫學原蟲學。 |
| 1908 | 伊利亞·梅契尼科夫（Élie Metchnikoff，俄國）與保羅·埃爾利希（Paul Ehrlich，德國） | 免疫學研究：梅契尼科夫的吞噬細胞學說（細胞免疫）與埃爾利希的側鏈學說（體液免疫），兩派合併獲獎。 |
| 1909 | 埃米爾·特奧多爾·科赫爾（Emil Theodor Kocher，瑞士） | 甲狀腺的生理學、病理學與外科學：確立甲狀腺全切除術技術，研究甲狀腺功能低下與黏液性水腫。 |
| 1910 | 阿爾布雷希特·科塞爾（Albrecht Kossel，德國） | 細胞核化學：分離出核素的組成成分——腺嘌呤、胸腺嘧啶等五種含氮鹼基（核苷酸研究先聲）。 |
| 1911 | 阿爾瓦·古爾斯特蘭德（Allvar Gullstrand，瑞典） | 眼睛屈光學：締造精密的眼屈光學說、設計裂隙燈，修正亥姆霍茲的眼光學模型。 |
| 1912 | 亞歷克西·卡雷爾（Alexis Carrel，法國） | 血管縫合術與血管、器官移植：三線縫合法使血管吻合成為可能，為器官移植與現代心血管外科奠基。 |
| 1913 | 夏爾·羅貝爾·里歇（Charles Robert Richet，法國） | 過敏反應（anaphylaxis）研究：發現免疫不只是保護——抗原再暴露可致致命休克，開啟過敏學。 |
| 1914 | 羅伯特·巴拉尼（Róbert Bárány，奧匈帝國） | 前庭器官（內耳平衡器）的生理與病理：確立溫度試驗（冰水灌耳誘發眼震）等前庭功能檢查法。 |
| 1915 | **從缺** | 第一次世界大戰爆發，本年未頒獎。 |
| 1916 | **從缺** | 一戰期間未頒獎。 |
| 1917 | **從缺** | 一戰期間未頒獎。 |
| 1918 | **從缺** | 一戰期間未頒獎。 |
| 1919 | 朱爾·博爾代（Jules Bordet，比利時） | 免疫學發現：補體與補體結合反應（1895–1901，後衍生瓦瑟曼梅毒血清診斷法）。 |
| 1920 | 奧古斯特·克羅（August Krogh，丹麥） | 毛細血管運動調節機制：證明毛細血管開閉受局部代謝物調控，為微循環生理學奠基。 |

## 1921–1950：胰島素、維生素、青黴素——治療醫學的世紀

| 年份 | 得主 | 事件／貢獻 |
| --- | --- | --- |
| 1921 | **從缺** | 戰後醫學界仍未恢復，本年未頒獎。 |
| 1922 | 阿奇博爾德·希爾（Archibald Hill，英國）與奧托·邁爾霍夫（Otto Meyerhof，德國） | 肌肉生熱研究與肌肉中氧耗與乳酸代謝的固定關係：肌肉收縮生化學（糖酵解研究）的開端。 |
| 1923 | 弗雷德里克·班廷（Frederick Banting，加拿大）與約翰·麥克勞德（John Macleod，英國） | 發現胰島素（1921 年多倫多大學）：糖尿病由絕症轉為可控疾病。 |
| 1924 | 威廉·埃因托芬（Willem Einthoven，荷蘭） | 發明弦線式心電圖機（1903），確立心電圖臨床診斷學（P、Q、R、S、T 波命名）。 |
| 1925 | **從缺** | 本年未頒獎。 |
| 1926 | 約翰尼斯·菲比格（Johannes Fibiger，丹麥） | 「發現螺旋體癌」（鼠胃癌線蟲假說）——史上最著名的諾獎錯案，後證明其致癌結論不成立，維生素 A 缺乏才是真因。 |

| 1929 | 克里斯蒂安·艾克曼（Christiaan Eijkman，荷蘭）與弗雷德里克·霍普金斯（Frederick Gowland Hopkins，英國） | 艾克曼以雞隻腳氣病模型發現抗神經炎維生素（維生素 B1）；霍普金斯提出「輔助食物因子」與生長刺激維生素——維生素時代開幕。 |
| 1930 | 卡爾·蘭德施泰納（Karl Landsteiner，奧地利） | 發現人類血型（ABO 系統，1901）：輸血醫學由賭命變成科學。 |

| 1932 | 查爾斯·斯科特·謝靈頓（Charles Scott Sherrington，英國）與埃德加·阿德里安（Edgar Adrian，英國） | 神經元功能：突觸（synapse）概念與神經整合；單神經纖維放電的「全或無」律。 |
| 1933 | 托馬斯·亨特·摩根（Thomas Hunt Morgan，美國） | 染色體遺傳學：果蠅白眼突變、連鎖與互換，遺傳的染色體學說定案。 |
| 1934 | 喬治·惠普爾（George Whipple）、喬治·邁諾特（George Minot）、威廉·莫菲（William Murphy，皆美國） | 惡性貧血的肝臟療法（1926）：以生肝治療惡性貧血，開啟血液病現代治療。 |
| 1935 | 漢斯·斯佩曼（Hans Spemann，德國） | 胚胎發育中的組織者效應：蝶螈背唇移植實驗，發育生物學的里程碑。 |
| 1936 | 亨利·哈利特·戴爾（Henry Hallett Dale，英國）與奧托·勒維（Otto Loewi，奧地利） | 神經衝動的化學傳遞：勒維的「雙蛙心實驗」證明迷走神經釋放乙醯膽鹼。 |
| 1937 | 聖捷爾吉·阿爾伯特（Albert Szent-Györgyi，匈牙利） | 生物燃燒過程、維生素 C 的分離（1928）與延胡索酸的催化作用——三羧酸循環研究的先聲。 |
| 1938 | 柯奈爾·海門斯（Corneille Heymans，比利時） | 頸動脈竇與主動脈弓的化學與壓力感受器對呼吸、血壓的調節。 |
| 1939 | 格哈德·多馬克（Gerhard Domagk，德國） | 發現百浪多息（磺胺）抗菌效果（1932）：抗生素時代的前奏；被納粹政府禁止領獎。 |
