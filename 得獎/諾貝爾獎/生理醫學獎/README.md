# 諾貝爾生理學或醫學獎 歷史年表（詳細版）

> 由斯德哥爾摩卡羅琳斯卡醫學院諾貝爾大會頒發（非瑞典皇家科學院）。
> 詳細「推理探案式」wiki 請見本目錄下以年份開頭的各篇檔案。

## 序幕

| 年份 | 事件 |
|---|---|
| 1895 | 諾貝爾遺囑指定「生理學或醫學獎」由卡羅琳斯卡學院頒發——史上首見「醫學院掌握科學最高裁判權」 |
| 1901-12-10 | 第一屆頒給馮·貝林（白喉血清療法） |
