# 1912 · 血管縫合與器官移植：卡雷爾的「三線縫合法」開啟器官移植時代

> **1912 諾貝爾生理學或醫學獎**：亞歷克西·卡雷爾（Alexis Carrel，法國）— 表彰「在血管縫合以及血管和器官移植的研究上的工作」。

## 懸案（案情提要）

十九世紀末，血管破裂即是死刑：縫了會漏血、結紮了會遠端壞死；而「移植一顆還在跳動的心臟、一顆活的腎臟」更是醫學科幻。案情卡在兩個技術死結與一個生物死結：

1. **技術死結一**：血管壁薄如紙，傳統縫合會讓縫線穿透內膜、血小板上門、血栓封路；
2. **技術死結二**：斷端的血管一夾即潰，如何在流體高壓下讓兩截血管「無縫對接」？
3. **生物死結**：即使手術成功，異體移植的器官為何數日內被宿主「拒絕」——排斥反應的真面目要到 1940 年代才揭開（見 [1960-後天免疫耐受](1960-後天免疫耐受.md)）。

## 前因

| 年份 | 事件 |
| --- | --- |
| 1889 | Jaboulay（法國）嘗試以「套接法」吻合血管：把一截血管像袖套一樣套進另一截，但易致狹窄與血栓。 |
| 1900 | Dorfler 嘗試以細線直接縫合血管壁全層，效果仍差。 |
| 1894 | 法國總統卡諾（Sadi Carnot）遇刺，內臟血管破裂無法修補而死；此事震動外科界，年輕的卡雷爾立志攻克血管吻合術。 |
| 1902 | 卡雷爾在里昂以精緻縫線與「三定點」幾何佈局完成犬隻血管端對端吻合實驗。 |
| 1904–1905 | 卡雷爾赴芝加哥與生理學家古思里（Charles Guthrie）合作，完成血管吻合、腎臟移植、心肺移植等系列動物實驗。 |

## 調查

卡雷爾的偵查核心是**「三定點縫合法（triangulation technique）」**：

1. **等分三角**：在血管斷端圓周上取三個等距點（120° 間隔），各縫一針留線，把圓形斷面「繃成」三角形——三條線既是縫合的導軌，也把管腔均勻撐開，避免內膜皺摺重疊；
2. **連續細線縫合**：以極細縫線沿三段弧連續縫合，**縫線只穿外膜與中膜外層、不穿內膜**，使光滑的內膜面對合如初——血小板與纖維蛋白無從附著，血栓的「作案條件」被拆除；
3. **無菌與溫和操作**：全程遵守無菌術，避免血管痙攣與內膜損傷。

他在實驗記錄中反覆強調「血管不喜歡粗暴」：鉗夾之力、縫針之粗、張力之緩急，每一項都要寫進操作規範——這套以失敗案例反推操作細節的做法，正是外科「標準作業程序（SOP）」的誕生過程。卡雷爾自述曾反覆練習上百次、以最小號的縫針在桌面刺布上磨鍊手法，才敢回上手術台。

以數學語言描述其幾何：血管斷端半徑 $R$ ，三定點把圓周三等分，每段弧長為 $\tfrac{2\pi R}{3}$ ，縫合時使內膜外翻對合，管腔截面積保持 $A = \pi R^2$ 的 $90\%$ 以上即可維持層流、避免湍流與血栓。這一幾何直覺——**以最小擾動維持截面幾何**——正是本案的技術精髓。

1. **腎臟自體移植（1905–1908）**：卡雷爾與 Guthrie 把犬腎切下、移植回原位（自體移植），腎臟存活並分泌尿液——**「器官可以離體重植」**首次被系統證明；
2. **異體移植的「壁壘」**：他也觀察到異體移植的器官幾日內壞死——他記錄了現象、稱之為「生物學障礙」，但當時無法解釋（免疫排斥的真相要到 1940 年代 Medawar 的皮膚移植實驗才揭曉）；
3. **心臟移植與體外灌流**：他嘗試犬心移植、以及與 Lindbergh（1930 年代）合作設計**玻璃灌流泵**，維持離體器官存活——這台「卡雷爾—林白灌流泵」是體外循環與器官保存技術的直系祖先；
4. **血管保存與輸血管道的標準化**：他確立了血管取材、保存與移植的操作規範，使血管外科成為標準手術。

## 理論裁決

1. **血管吻合的幾何—流變學原則**：吻合成功的三要素——管腔幾何保持、內膜完整、無菌無損——可寫成層流條件（雷諾數）
   $$Re = \frac{\rho v d}{\mu} < \text{threshold}$$
   截面不均、內膜粗糙都會使局部 $Re$ 與剪應力異常，誘發湍流與血栓。三定點法正是以幾何控制來維持層流的**工程解**。
2. **移植免疫的「障礙」假說**：卡雷爾提出異體移植存在「生物學障礙」——雖然他未解開其機理（免疫排斥），但這一概念把問題**提對了**，直接啟發 1940 年代 Medawar 的排斥實驗與 1960 年免疫耐受諾獎（見 [1960-後天免疫耐受](1960-後天免疫耐受.md)）。
3. **「離體器官仍可存活」的系統觀**：器官不是解剖標本，而是需要**血流、溫度、代謝支持**的動態系統——這一觀點催生了體外循環（Gibbon, 1953）、器官保存液、體外灌流與今日的離體器官維持技術（ex vivo perfusion）。
4. **外科技術的精微化路線**：以更細縫線、更少組織損傷為方向的「微血管吻合」，日後發展為顯微外科（1960 年代 Jacobson 顯微鏡下吻合），斷肢再植、游離皮瓣移植皆由此而來。

## 後果

| 領域 | 影響 |
| --- | --- |
| 血管外科 | 動脈瘤修補、血管重建、冠狀動脈繞道手術的技術基礎；三定點法至今仍是教學標準。 |
| 器官移植 | 1954 年默里完成首例成功腎移植（同卵雙生）、1990 年移植醫學再獲諾獎（見 [1990-器官與骨髓移植](1990-器官與骨髓移植.md)），全部以卡雷爾的技術平台為前提。 |
| 體外循環 | 心肺機、人工心肺、ECMO 的概念源頭；體外器官灌流保存技術延續至今。 |
| 組織培養 | 卡雷爾與同事建立長期組織培養技術（「不死細胞株」雞心培養），為病毒培養（1954 年 polio 疫苗前提，見 [1954-脊髓灰質炎病毒](1954-脊髓灰質炎病毒.md)）鋪路。 |
| 科學史 | 卡雷爾晚年與神祕主義、優生學糾葛（1935 年《人，未知者》），成為「技術天才與思想暗面」的複雜案例。 |

## 追查支線（未結之謎）

- 「生物學障礙」的本體——移植排斥的細胞免疫機理——在 1940 年代由 Medawar 的兔子皮膚移植實驗定案，1960 年與伯內特共享諾獎（見 [1960-後天免疫耐受](1960-後天免疫耐受.md)）；
- 卡雷爾的組織培養「不死細胞」爭議：其雞心培養是否真的存活三十四年，成為實驗室紀錄可信度的經典考據案；
- 體外灌流泵在 1930 年代未能成功的工程瓶頸（無菌、抗凝、氧合），到 1953 年 Gibbon 人工心肺機才被攻克，心內直視手術由此開啟；
- 血管吻合在顯微鏡下（1960 年代 Jacobson）重做，斷肢再植與游離皮瓣移植使本案技術進入微米尺度；
- 卡雷爾與優生學、神秘主義的糾葛（1935 年《人，未知者》、1941 年維希政權合作爭議）是本案卷宗中最陰暗的一章；
- 他的「人工心臟」構想（與 Lindbergh 討論的離體心臟灌流）在半世紀後以全人工心臟與心室輔助裝置的形式落地；
- 三定點法的現代變身——連續縫合、機械吻合器、生物膠——都在他「以幾何控制管腔」的原則之內；
- 「自體移植可行、異體有障礙」的二分法，至今仍是移植免疫學的第一課；異種移植（豬心人心，2022 年首例）是本案的最新續篇；
- 他與 Lindbergh 合作的灌流泵故事，是「外科醫生＋工程師」跨域協作的早期範本，預告了今日醫工合作的科研範式；
- 卡雷爾式的「器官離體存活」目標在 21 世紀以常溫灌注（normothermic perfusion）機器實現——移植器官在「體外生命維持」中等待運送，正是他 1935 年構想的落地。

卷宗中還有一條橫跨半世紀的延續線：卡雷爾在洛克菲勒研究所與同事建立的**組織培養**技術，把離體組織長期養在培養基中——他的「不死雞心細胞」培養（雖後世對其存活年限存疑）示範了「細胞可以在體外存活並增殖」。這一技術直系演化為 1948 年 L929 細胞株、1952 年 HeLa 細胞，再到 1949 年恩德斯團隊讓脊髓灰質炎病毒在非神經組織培養中生長（見 [1954-脊髓灰質炎病毒](1954-脊髓灰質炎病毒.md)），直接催生了沙克與沙賓疫苗。換言之，卡雷爾的血管縫合線與培養皿，分別通向了移植醫學與疫苗學兩座大山。至於排斥反應這樁「生物死結」，他在世時未解；1954 年默里在同卵雙生間完成首例成功腎移植（避開免疫），1960 年代硫唑嘌呤與環孢素（1980s）陸續上場，移植免疫學在 [1960-後天免疫耐受](1960-後天免疫耐受.md) 與 [1990-器官與骨髓移植](1990-器官與骨髓移植.md) 兩案中完成續篇。
