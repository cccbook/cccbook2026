# 1919 · 施皮特勒與奧林匹亞之春：一個瑞士人，在德語世界裡當希臘人

> 1919 諾貝爾文學獎：卡爾・弗里德里希・格奧爾格・施皮特勒（Carl Friedrich Georg Spitteler，1845–1924，瑞士）——表彰「特別表彰其史詩《奧林匹亞之春》」。他破的是一樁語言邊境上的案子：這位瑞士人用德語寫古希臘語的韻文，卻被自己的祖國當成德國人。

## 懸案（案情提要）

1919 年 11 月，斯德哥爾摩。諾貝爾委員會開完會，結論是：這一年的候選人沒有一個符合諾貝爾遺囑所寫的「理想方向」。依章規，獎項可以保留到次年。於是 1919 年的文學獎被「掛」起，直到 1920 年才頒出——頒給了一部十年前就寫完的史詩：《奧林匹亞之春》。

這部史詩的作者是瑞士人卡爾・施皮特勒。他生於瑞士北部的利斯塔爾，在巴塞爾讀中學，老師裡有語文學家瓦克納格爾與歷史家雅各布・布克哈特；他到蘇黎世學法律，又到海德堡與巴塞爾學神學，牧師的職位擺在面前時他拒絕了——他認定自己的使命是當一名史詩詩人。他後來到俄羅斯當家庭教師待了八年，回國後在《新蘇黎世報》當編輯。

案子就懸在這裡：一個瑞士國籍的人，寫的是古希臘神話，用的卻是德語；大戰期間他站在少數派的瑞士德語區，公開反對德國人的戰爭立場，於是兩邊都不喜歡他——德語界認為他不夠親德，瑞士人認為他太德國。他還被心理學家榮格拿來當作「阿尼瑪」原型的文學來源。

## 調查

**第一步：先確認被告的語言。**
翻開《奧林匹亞之春》，會發現它同時是德語文學與古希臘語文學。施皮特勒用的是德語，但通篇仿照古希臘語的格律與節奏；他寫詩的同時還寫神話學考證。這是一個極不尋常的操作：他把德語當成希臘語的轉寫載體，而不是當成翻譯的中介。難題是：他至今幾乎沒有英譯（2025 年為止，除小說外多數作品仍未譯成英文），這本身就是這條技藝路徑的後果——他的寫作深度依賴未被翻譯的雙語系統。

**第二步：拆開四卷結構，看它怎麼運作。**
《奧林匹亞之春》四卷的卷名本身就是一條時間線：啟程、婚配、鼎盛、轉折——這不是情節，是宇宙秩序的推演。他用同樣的節奏處理人、神與時間，把「崇高理想」寫成一種可朗讀的、具有建築感的東西。這就回答了判詞裡那個「特別表彰」：委員會表彰的不是某個主題，而是把哲學命題放進史詩格律而不致散架的技術。

**第三步：用榮格的心理分析讀法反向檢驗。**
1921 年，榮格在《心理類型》中對《普羅米修斯與埃庇米修斯》寫了長篇心理學詮釋；榮格後來還說，他對「阿尼瑪」原型的構想，部分來自施皮特勒筆下的「我的女士之靈」。這是文學與心理學史上一件罕見的事：一部文學作品先被讀成神話，再被讀成個案，最後反過來餵養了心理學的方法論。

**第四步：檢查中產階級那一段。**
《伊馬戈》（1906）寫的是「創造的心靈」與「中產階級的規矩」之間的衝突，而且用了內心獨白。施皮特勒本人在《少女厭惡者》（1907）裡寫童年，在《我最早年的經歷》（1914）裡寫回憶——他的寫作始終在「以抒情形式處理一個被規訓的人如何保存自己」這個題目上。

**第五步：核對一戰期間的位置。**
《我們的瑞士立場》讓他在本國右翼與親德派眼中成為賣國者；他因此在自己的國家被排斥，在德語界則被視為外來者。這個處境後來成為他文學接受史的核心：他不是被遺忘，而是被放到了「國界之外」的位置上。

## 技藝裁決

**裁決一：格律是可以承載哲學的結構，不是裝飾。** 施皮特勒用抑揚六步格把「人是什麼」這種命題撐了四卷而不散。這與同年普呂多姆式的做法同源（見 [1901-普吕多姆與詩的抱負](1901-普吕多姆與詩的抱負.md)），但施皮特勒的示範是外來的：他示範的是把外國的格律引進另一種語言。

**裁決二：寓言是哲學與神話之間的轉接器。** 《普羅米修斯與埃庇米修斯》用兩個神話人物對照「理想」與「教條」，這是一種可被心理學與宗教學同時接住的寫作策略——它不給結論，只給對照。

**裁決三：田園史詩必須用「重複」而非「進程」推動。** 四卷的卷名說明他的結構觀：宇宙的運動是週期性的，重複本身就是內容。這與同代寫實主義的「生活向前流」正好相反，也預告了後來高爾斯華綏《福爾賽世家》那種連環式家族敘事。

**裁決四：跨語境的作家要自己承擔「翻譯」的工作。** 他不假手於譯者，直接把希臘韻律搬進德語；今天他的作品仍幾乎沒有英譯（除 1920 年代的幾種選譯外），這件事本身就是他技藝路徑的後果——他的寫作深度依賴未被翻譯的雙語系統。

## 後果

| 年份 | 影響 |
|------|------|
| 1919–1920 | 諾貝爾文學獎第一次使用「保留後頒發」程序；此後 1925、1926、1927 年重演。 |
| 1920 | 《奧林匹亞之春》與《普羅米修斯與埃庇米修斯》因榮格的《心理類型》（1921）而成為歐洲心理學與文學的共同話題。 |
| 1921 | 榮格在《心理類型》中以《普羅米修斯與埃庇米修斯》為長篇心理學詮釋，確立了「文學文本可作為心靈模型」的讀法。 |
| 1924 | 改寫本《受難的普羅米修斯》（Prometheus der Dulder）問世；同年 12 月 29 日他在盧塞恩逝世，遺稿分別歸於瑞士文學檔案館、蘇黎世中央圖書館與利斯塔爾詩人博物館。 |
| 1930 年代 | 維護尼采傳統的學者重印《奧林匹亞之春》，使其在二戰前維持德語史詩的少數標本地位。 |
| 20 世紀中期 | 瑞士文學研究開始重新評估他的「德國化」問題，把他從德語作家改列為瑞士作家。 |
| 1970–80 年代 | 他的作品在德語區重新被評為「封閉的、被誤解的史詩」，研究重心由「民族」轉向「格律」。 |
| 2015 | 藝術家兼作家 Tanja Stark 指出施皮特勒與榮格的「我的女士之靈」概念，與鮑伊 Bowie 自稱榮格式的 1973 年歌曲〈Lady Grinning Soul〉之間存在對應關係，史詩與搖滾因此被拉進同一條線。 |
