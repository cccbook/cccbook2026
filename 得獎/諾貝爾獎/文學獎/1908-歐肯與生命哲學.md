# 1908 · 歐肯與生命哲學：哲學系的人被文學獎抓了起來

> 1908 諾貝爾文學獎：魯道夫・克里斯托夫・歐肯（Rudolf Christoph Eucken，1846–1926，德國）——表彰其「對真理的認真探求、洞察的穿透力、視野的廣闊，以及在其眾多作品中展現並發展的理想主義人生哲學的溫暖與力量」。【案發現場：耶拿大學的講堂，一位哲學教授在回答一個學生的問題——「那我該怎麼活？」兇手不是答案，是他把一個生活問題寫成了一部可以拿諾貝爾獎的書。】

## 懸案（案情提要）

案發現場是 1883 年前後耶拿大學的講堂。一個在巴塞爾取得教職、來到耶拿執教的哲學家，被學生追問：如果道德只是一套靜態的教義，人在現實裡還剩下什麼？他沒有給一句格言，而是寫了一本書：《偉大思想家的生命觀》（Die Lebensanschauungen der großen Denker，1890），把柏拉圖、康德與一長串思想家排成一列，問每一個人同樣的問題。

案子為什麼懸？因為它挑的是文學獎的邊界。諾貝爾遺囑說要獎給「在理想方向上」的寫作者——哲學講義算不算？1908 年的答案是算，而且被寫成了判例：第一位以哲學教授身分獲得文學獎的作家由此誕生。此後柏格森（1927）、羅素（1950）、甚至卡內蒂（1981）都在這條縫裡走過；每一屆都要重新說一次「哲學散文到底算不算文學」。

歐肯的答案本身也構成一樁案子。他主張「倫理行動主義」（ethischer Aktivismus）：道德不是一套靜態的教義，而是必須在與世界的衝突中不斷實踐的行動；人不是靠知道正確而變好，而是靠去做、去承受、去與現實相撞才變好。這套主張由他晚年寫成《當代精神思潮》（Geistige Strömungen der Gegenwart）等書，帶著「溫暖」與「力量」——1908 年頒獎理由裡的這兩個詞，指的正是哲學散文要達到的那種溫度。

## 調查

**第一步：把抽象命題放進具體的人。**
歐肯的寫法與柏格森、維特根斯坦式的哲學散文不同：他偏好**群像式的思想史敘事**。《偉大思想家的生命觀》裡，每一位思想家都被還原成一個活生生的人：他的時代、他的困頓、他面對的問題。哲學命題因此不再是定義，而是衝突的歷史。「生命哲學」這個詞在他手裡，指的是「人生的問題」，不是「生命的科學」。

**第二步：抓住核心機制——行動與衝突。**
「倫理行動主義」是全案的關鍵：人不是因為擁有正確觀念而成為道德的人，而是因為在與客觀世界的衝突中不斷實踐而成為道德的人。這意味著他的散文有一個穩定的**戲劇結構**：先是僵化的信念（教條、既成秩序），然後是它的失敗，最後是實踐者在失敗中站起來。這個結構既可以拿來分析德國的宗教，也可以拿來分析一個人的一生。

**第三步：量詞的精確與群眾的可讀性。**
歐肯一方面做哲學史考據（亞里士多德的方法、哲學術語史），另一方面寫能面向大眾的講堂式散文。他的句法有一種可辨識的節奏：先提出問題，再排除一種簡單答案，再給出一個需要持續行動的開放答案。這套「三段式」在當時被讀者視為溫暖的力量，在後來的分析者眼裡，卻是「結論不封閉」的可溝通性設計。

**第四步：檢查這個獎帶來的制度後果。**
1908 年之後，諾貝爾委員會收到的候選人名單裡，哲學家開始穩定出現。歐肯的兒子瓦爾特・歐肯後來成為德國「秩序自由主義」的經濟學奠基者，另一個兒子阿諾德・歐肯是化學家與物理學家；**一個靠文字得獎的人，把兩個兒子送進了學術與政策的現場**，這是這樁案子最耐人尋味的家族後果。

## 技藝裁決

**裁決一：哲學散文要有「可被引用的句子」。** 歐肯的句子常被單獨摘出轉載（如「真正的哲学是生活哲学」一類的箴言），因為它們把複雜的道德問題壓縮成一句可記憶的話。這是散文技藝與哲學內容的交會處：壓縮必須保留問題的張力，否則就只剩格言。

**裁決二：把體系寫成敘事，而不是寫成目錄。** 他在耶拿的講義與著作裡，把抽象體系拆成「問題—失敗—實踐」的連續故事；讀者可以跟著走，而不必先背完一章術語。這套「敘事化哲學」的路線，日後在胡塞爾的现象學描述、薩特的《存在與虛無》裡都可以看到。

**裁決三：把爭議內建於文本。** 他的書不是要終結討論，而是要讓讀者在「行動」與「靜止」之間無法不選邊。這使他的作品在文學獎史上很特別：**得獎的不是一種答案，而是一種提問方式**。1908 年獎理由中的「溫暖與力量」，正是這種提問方式的溫度。

**裁決四：邊界案的第一刀。** 1908 年之後，文學獎的門檻被明確寫成：「不是科學的成就，而是以文學方式表達的思想。」這句話後來反覆被援引——1913 年評泰戈爾、1927 年評柏格森，用的都是同一條界線。

## 後果

| 年份 | 影響 |
|------|------|
| 1908 | 諾貝爾文學獎史上首位以哲學教授身分獲獎者，確立「哲學散文亦可獲文學獎」的判準，此後柏格森、羅素等循此路徑受評。 |
| 1913 | 泰戈爾獲獎時，委員會仍以「技藝」為標準表揚詩人，說明「能寫」比「寫什麼」更關鍵的判準已成形。 |
| 1927 | 柏格森以「豐富而充滿活力的思想，以及呈現這些思想的卓越技巧」獲獎，理由幾乎是歐肯那句「溫暖與力量」的延伸版。 |
| 1950 | 羅素以《數理哲學原理》與人道主義散文獲獎，把哲學帶著數學與邏輯進入文學獎的射程。 |
| 1960–70 年代 | 歐肯的學生與追隨者把「倫理行動主義」發展成德國神學與教育學的重要流派；其子瓦爾特・歐肯的秩序自由主義成為戰後西德經濟政策的理論骨架。 |
| 1981 | 卡內蒂獲獎，他把歐肯式的「人如何實踐」問題轉成群眾心理學，《聽眾與權力》延續了「行動主義」的提問方式。 |
| 20 世紀後期 | 歐肯在英語世界的譯介重新整理，《當代精神思潮》被視為理解 1900 年代德國思想的入口，而不再只是哲學史的過場。 |
