# 1999 · 格拉斯與鐵皮鼓：一個拒絕長大的孩子，敲醒了戰後德國

> 1999 諾貝爾文學獎：君特・格拉斯（Günter Grass，1927–2015，德國）——表彰「其嬉戲的黑色寓言描繪了被遺忘的歷史面貌」。他破的是德國戰後文學的第一樁大案：經歷過那場災難的整個國家，集體選擇了失憶——而證人只有一個三歲小孩的敘事視角。

## 懸案（案情提要）

1959 年，法蘭克福。一部 700 頁的小說出版，主角是個自己砸傷自己、拒絕再長高的男孩奧斯卡，他敲著一面鐵皮鼓，用能把玻璃震碎的尖叫聲，目擊了但澤小市民世界的整段歷史。評論界最初手足無措：這到底是童話、色情、怪譚，還是史書？

案子懸在這裡：德國戰後文學想要「清白地重新開始」，而格拉斯偏偏把最不體面的證物——小市民的共謀、政府的骯髒、旁觀者的快活——全部搬上檯面。**「被遺忘的歷史面貌」**這句官方頒獎理由，指的不是納粹官方罪行，而是：普通人是怎麼一邊正常生活、一邊讓災難發生的。

## 調查

**第一步：鎖定敘事者的物理證據——鐵皮鼓與尖叫。**
奧斯卡在三歲生日那天故意摔傷，讓自己停在三歲的身高。這個裝置不是心理學障礙，而是一種敘事策略：**拒絕成長就是拒絕加入共犯結構**。鐵皮鼓的節奏為整部小說定拍，尖叫聲則是證人的唯一武器——它能震碎玻璃，卻震不動大人世界的判決。

**第二步：核對敘事視角的雙重性。**
《鐵皮鼓》以第一人稱自傳體開場，中段改為第三人稱、後段再回到第一人稱。這種視角漂移刻意讓讀者無法確定：奧斯卡到底是受害者、旁觀者，還是共犯？格拉斯把這個問題留成懸案，並用它審判的不只是納粹，而是**所有在廢墟裡繼續過日子的德國人**。

**第三步：拆解「黑色寓言」的技術成分。**
格拉斯的寓言不是口號式的道德劇，而是把色情、髒話、食譜、鄉野傳說與嚴格的編年史混在一種表面上不莊重的文體裡。這種「嬉戲」是計算過的：越滑稽的部分，事實上的控訴力越強。

**第四步：追蹤「但澤三部曲」的地圖。**
《鐵皮鼓》《貓與鼠》《狗年月》共用同一座城市，卻分別採用三種體裁（自傳式小說、中篇小說、史詩式小說）。這種以地理而非情節統一的三部曲結構，成為後世寫「一城多史」的範本。

## 技藝裁決

格拉斯的核心突破是**寓言作為史學方法**：他不用論證證明德國的集體失憶，而是用一個拒絕長大的敘事者去強迫讀者記起。這就是為什麼委員會用「黑色寓言」與「被遺忘的歷史」作為獲獎理由——兩者是同一件事的技術面與題材面。

第二項裁決點是**語言的雜食性**。他的德語大量摻入意第緒語、波蘭語、方言、官話與兒歌，形成一種既粗俗又精細的語體。這是戰後德語文學最顯著的語言擴容事件之一，也把俚語與平民聲音正式納入了德語敘事的高級文體。

第三項是**文體跨越**：格拉斯同時以小說家、詩人、劇作家、雕塑家、版畫家與公共知識分子的身分活動，他甚至把繪畫與雕塑放進小說的排版裡，開創德語「多媒體小說」的先例。

## 後果

| 年份 | 影響 |
|------|------|
| 1979 | 電影版獲坎城金棕櫚，使《鐵皮鼓》進入國際文化記憶。 |
| 1980s | 《比目魚》的烹飪史結構影響德語後現代小說的寫法。 |
| 1990s | 格拉斯成為德國公共知識分子的代表人物，常在選舉前發表政論。 |
| 2006 | 回憶錄《剝洋蔥》自承十七歲時曾被徵入武裝親衛隊，引發德國全國辯論。 |
| 2007 | 英、法、波等譯本重印，其書寫「普通人共謀」的方法被寫入德國教科書。 |
| 2012 | 詩作批評歐洲對希臘的緊縮政策，引發國際政治爭論。 |
| 2015 | 4 月 13 日於呂貝克去世。 |
| 2017 | 呂貝克成立君特・格拉斯之家，將其雕塑、版畫與手稿合併展出。 |
