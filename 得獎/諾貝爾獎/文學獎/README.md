# 諾貝爾文學獎 歷史年表（1901–2024）

> **獎項身世**：文學獎是阿爾弗雷德・諾貝爾 1895 年遺囑明列的五獎之一，由**瑞典學院**（Svenska Akademien，1786 年由古斯塔夫三世創立）依遺囑評選，頒給「在文學界創作出具有理想傾向的最佳作品的人」。
> 1901 年首度頒發；典禮每年 12 月 10 日（諾貝爾忌日）在斯德哥爾摩舉行，由瑞典國王頒發。
> **未頒發的 7 屆**：1914、1918（第一次世界大戰）；1935；1940、1941、1942、1943（第二次世界大戰）——共 117 屆有頒發。
> 本目錄每一屆（含雙得主合併檔）都有一篇推理探案式 wiki，全表 117 個檔案見文末清單。

## 序幕（1895–1901）：一句「理想傾向」，審了一百年

| 年份 | 事件 |
|---|---|
| 1895 | 阿爾弗雷德・諾貝爾簽署遺囑，將遺產利息分設五獎；文學獎的判詞只有一句：「在文學界創作出具有理想傾向的最佳作品」——「理想傾向」四字沒有定義，成為此後百年一切爭議的源頭 |
| 1896 | 諾貝爾去世；遺囑公布，瑞典社會、俄國（其家族油田在巴庫）、親屬群起攻擊「理想」與「文學」的模糊 |
| 1897 | 瑞典學院（18 位終身院士）正式受託評選文學獎；諾貝爾基金會章程成立 |
| 1900 | 帝王批准章程；基金會運作確立 |
| 1901 | 首屆頒給法國詩人蘇利・普呂多姆，並以「不合乎理想方向」排除大熱門左拉——第一個判例就是「理想」的解釋權之爭 |
