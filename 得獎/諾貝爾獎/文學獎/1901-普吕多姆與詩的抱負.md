# 1901 · 普呂多姆與詩的抱負：第一個案子，判給了不寫小說的人

> 1901 諾貝爾文學獎：雷內・弗朗索瓦和阿爾芒・普呂多姆（René François Armand Prudhomme，通稱 Sully Prudhomme，1839–1907，法國）——表彰「其詩作顯示崇高的理想主義、藝術的完美，以及心與智力的罕見結合」。他破的是全獎第一案：遺囑裡那個寫作「理想的方向」的模糊詞，究竟該由誰來兌現。

## 懸案（案情提要）

1901 年 12 月 10 日，斯德哥爾摩。諾貝爾文學獎第一次頒發，瑞典學院手上是一樁沒有前例的案子。阿爾弗雷德・諾貝爾的遺囑只說要獎給「在理想方向上」的寫作者，卻沒有說明「理想」是什麼、該由哪一種文體來兌現。當年委員會收到 37 份提名、26 位候選人——名單第一個名字是 Émile Zola。

委員會在報告裡把左拉排除，理由是他的作品「不被視為符合遺囑所要求的理想方向」。這句話聽起來像是判決書，實際上卻是一樁未決案：文學獎到底該獎給寫實的小說家，還是獎給把哲學寫成十四行詩的人？諾貝爾獎史上第一個判例，就這樣被推到了檯面上。

被判有罪的，其實是另一種寫作：那位被推上被告席又獲得開釋的候選人，恰恰是當年最不像「小說家」的讀者。

## 調查

**第一步：從《破碎的花瓶》裡翻出物證。**
《Le vase brisé》不是抒情小品，而是一次微型的實驗：詩人把「心」與「世界」都放進同一只花瓶，花瓶碎裂時，兩者同時毀滅。帕納斯派的口號是「客觀」，普呂多姆卻在客觀的框架裡塞進心理學的機制——暗示、象徵、可拆解的意象鏈。這條線後來一直貫穿他的長詩與散文。

**第二步：把哲學題目強行搬進詩格。**
《正義》（1878）與《幸福》（1888）是他的兩樁大案：他用亞歷山大詩行這種最「貴族」的格律，去處理「什麼是正義」「幸福是否可能」這類本來屬於哲學系的題目，並把盧克萊修《物性論》第一卷譯成詩韻。他要證明的不是詩之美，而是：**抽象思想可以被行進在韻腳之中**。諾貝爾基金會後來寫的頒獎理由「心與智力的罕見結合」，正是這個方法的官方摘要。

**第三步：把技藝寫成條款。**
《關於詩藝的思考》（1892）與《藝術中的表現》（1884）不是文學評論的閒筆，而是偵查用的規範表：何謂可用的意象、何謂該廢棄的抽象名詞、節奏與轉喻如何檢驗。他還在巴黎沙爾曼與波拿巴兩所高中教文學，把寫詩當成一門可以傳授的技藝來示範。

**第四步：核對被告身分。**
1901 年的委員會檔案留下三條線索：一是左拉因「不符合理想方向」被排除；二是法蘭西學院 17 位院士聯名提名普呂多姆，報告認為他比同樣入選的米斯特拉爾「更在多數人之上」代表「理想方向」；三是《費加羅報》用兩個頭版加一篇專訪報道他——這是法國文學界對這個新獎的第一反應。

**第五步：處理獎金去向。**
普呂多姆把獎金的大部分交給法國文學家協會（Société des gens de lettres）設置詩獎；1902 年又與 José-Maria de Heredia、Léon Dierx 共同創立「法國詩人協會」（Société des poètes français）。他不是把榮譽換成年金，而是換成機構——這在文學獎史上是第一次。

## 技藝裁決

**裁決一：形式不是外衣，而是論證的骨架。** 帕納斯派在普呂多姆手裡不是裝飾，而是把抽象命題固定下來的工具：亞歷山大詩行、十四行、抒情頌歌（ode），每一種格律都對應一種思維速度。議題越大，格律越要穩——這與浪漫派「情緒溢出格律」的邏輯正好相反。

**裁決二：象徵系統必須可回推。**《破碎的花瓶》的比喻不是裝飾性意象，而是有內部邏輯的模型：容器、裂痕、散落、外力。這種「可回推」的要求，後來在《正義》《幸福》裡擴展成整卷長詩的骨架——正義是裂開的城邦，幸福是無法實現的容器。

**裁決三：抒情邏輯＝把科學語言情緒化。** 他自稱要寫「科學的詩」，並翻譯盧克萊修；但他的科學不是論文式的，而是被情緒浸透的：法律問題（《正義》）與心理問題（《幸福》）在他筆下共用同一套節奏。諾貝爾委員會看中的「心與智的結合」，正是這套譯寫系統的成果。

**裁決四：詩人須先是讀者與教師。** 他的散文（《藝術中的表現》《關於詩藝的思考》）把欣賞判準與寫作判準合一：先能說出「為什麼好」，才允許自己寫。這條標準在文學獎史上被反覆引用——1908 年評歐肯、1913 年評泰戈爾，評語都在「理念是否被技藝承載」上打轉。

## 後果

| 年份 | 影響 |
|------|------|
| 1901 | 首獎定調：諾貝爾文學獎被定義成「整體著作＋理想方向」的整體性授予，而非單部作品的表揚；此模式沿用至今。 |
| 1901 | 委員會以「理想方向」為由排除左拉，確立了諾貝爾遺囑在文學獎中的操作性解讀；1906、1909、1913 年多次沿用同一判準。 |
| 1901 | 大部分獎金撥予法國文學家協會的詩人獎，該獎延續至今。 |
| 1902 | 與 Heredia、Léon Dierx 創立「法國詩人協會」，把詩的標準從個人趣味轉為社團制度。 |
| 1902 | 當選法蘭西學院院士後，學院共識成為往後提名與評選的骨幹；1904 年的埃切加雷正是由西班牙皇家學院正式提名而勝出。 |
| 1909 | 拉格洛夫獲獎時，瑞典學院仍援引普呂多姆式的「理想主義」語彙評價她，首屆的判準延續到女性得主身上。 |
| 1913 | 委員會評泰戈爾時仍以「理想方向」為衡量尺，判準的源頭正是 1901 年這份報告。 |
| 1920–30 年代 | 帕納斯派形式在法語詩壇退潮，但「客觀寫作」從此成為可被引用、也可被反駁的固定典範。 |
| 20 世紀後期 | 法國學界重新整理其散文論著與長詩，《正義》《幸福》的哲學雄心被重新評價，不再只當作過渡期裝飾。 |
