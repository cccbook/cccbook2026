# 1944 · 延森與北歐想像：把一座村莊寫成一部自然史

> 1944 諾貝爾文學獎：約翰內斯・V・延森（Johannes V. Jensen，1873–1950，丹麥）——表彰其「罕見而豐饒的詩性想像力，並結合廣範圍的智識好奇心與大膽而新穎的創作風格」。這樁案的線索是一個怪才：他寫神話、寫歷史小說、寫詩、譯《唐吉訶德》、替報紙寫稿，卻偏要用北日德蘭的一座村莊，回答「一個民族是怎麼長出來的」。

## 懸案（案情提要）

1944 年 10 月，斯德哥爾摩宣布丹麥作家約翰內斯・V・延森獲諾貝爾文學獎。哥本哈根那時仍在納粹占領之下，這是文學獎史上少數在戰火中宣布的案例之一。麻煩的是線索本身：延森的寫作橫跨神話、歷史小說、自然隨筆、抒情詩、譯作與新聞短評，任何單一體裁都裝不下他；文學史家因此稱他為「二十世紀北歐最難分類的作家」。

案子要從一個地方說起。1898 年起，他以家鄉北日德蘭的「希默蘭」（Himmerland）為材料，寫出一系列短篇與神話：農夫到山裡掘金、掘到一半放棄、或在回程路上把金子撒給孩子。這些民間故事在他筆下不再是獵奇，而變成丹麥人性格的骨架。他自己在諾貝爾自傳裡寫，這些「傳說」與「神話」是他最偏愛的文體，一共出了九卷。

那麼，一個靠村談起家的作家，憑什麼被評為「詩性想像力」的代表人？他的答案是演化。他說自己要在文學裡做一件沒人做過的事——把演化論的哲學引進文學，因為十九世紀末對達爾文的誤解與「超人」（Übermensch）的崇拜，最終引發了兩次世界大戰。要檢驗這份野心，只需讀兩組書：《國王的傾覆》（1900–1901），以及六卷本的《漫長的旅程》（1908–1922）。

## 調查

**第一步：把村談升格成神話系統。** 希默蘭系列不是民俗的轉述，而是重建。延森把「去山裡掘金」寫成一則國民寓言：掘金者不是尋寶人，而是一個不肯留在原地的人；金子在手裡會變成沙子，人在回程上把它分給孩子，最後回來的仍是他自己。這種「把口頭故事改寫成有性格邏輯的現代寓言」的手法，構成他晚期作品的骨架。

**第二步：用演化論替小說裝上時間軸。** 他在自傳中明說，他要把演化哲學帶進文學，因為「超人」崇拜造成了兩次大戰。《漫長的旅程》六卷寫一個家族從石器時代走到現代，歷史不再是背景而是主角；相對地，《國王的傾覆》把中世紀的宮廷權謀寫成「丹麥式的猶豫與缺乏生命力」——學者馬丁・塞繆爾-史密斯正是這樣解讀它的。醫學與博物學訓練在這裡變成方法：延森寫身體、寫動物、寫昆蟲，靠的是觀察者的耐心，不是想像的奔馳。

**第三步：讓語域跳躍成為批判工具。** 延森的散文最醒目的技術，是突然從崇高跌落到市井：神話段落裡夾一句笑話，抒情詩之後接一段乾巴巴的自然觀察。他自認詩集《Digte》是要反對「帶著波特萊爾有毒印記的、標榜細膩的時代風格」，主張「簡單的風格與健全的題材」。語域的不連續因此不是失控，而是他的道德姿態——把神話與日常放在同一頁上，暴露出「崇高」本身有多容易偽造。

**第四步：譯《唐吉訶德》，等於替民族重寫一遍自己。** 1906 年的丹麥語《唐吉訶德》不只是譯本。延森選擇以自己最熟悉的瘋狂與清醒的語域去對譯塞萬提斯，把一本外國名著拉進丹麥的口音裡；此後數十年，這部譯本一直被當作丹麥文學的古典化工程反覆重印。

**第五步：把報紙跑腿帶進文學。** 他多年為日報寫特稿與編年記錄，卻從不加入任何一家報社的正式職員名單，也從未加入任何政黨。這種「以記者身分介入當代」的做法，讓他的長篇小說裡常插入報告式的段落與新鮮資料，成為「短篇小說才是他的真正體裁」這個判斷的實證。

## 技藝裁決

延森的突破不在某一項技巧，而在**體裁的策略性混用**。他同時是神話蒐集者、歷史小說家、抒情詩人、譯者與報人，這在文學獎史上是罕見配置；後來人稱呼他那些跳躍式句子為「延森式」（jensensk），正說明這種雜質已成為可辨識的風格標記。

第二項突破是**把民族神話當成可操作的敘事結構**。他從「金匠／掘金者」這種民俗角色出發，讓它承擔整個民族的道德隱喻；這在北歐語言裡與後來拉美「魔幻寫實」共享同一種思路——以神話的權威替日常經驗取得深度。文學史研究者常把延森 1930 年前後的「超現實主義」一詞，看成拉美那條線路在歐洲的先行表述（此一說法至今仍有爭議）。

第三項突破是**敘事視角的科學化**。他不從神的角度、也不從全知者的角度寫，而是從一個受過訓練的觀察者角度寫：蟲的活動、人體的疲勞、器械的磨損。他的動物觀察與「掘金者」母題結合時，產生了二十世紀歐洲散文中最獨特的一種抒情——不靠形容词堆疊，而靠準確。

## 後果

| 年份 | 影響 |
|------|------|
| 1944 | 獲諾貝爾文學獎，戰時的丹麥文學第一次得到國際肯定 |
| 1946 | 自傳體散文《我的孩子》（Min Kilder）問世，把口述家族史推成一種散文體裁 |
| 1950 | 逝於諾勒・瑟比；丹麥文學界開始系統整理他的「掘金者」母題 |
| 1950–1970 | 北歐民俗研究把延森的掘金者故事納入斯堪的那維亞金匠神話的考證 |
| 1960 年代 | 文學史把「超現實主義」一詞溯源到延森 1930 年前後的文章，視為拉美魔幻寫實的歐洲先聲（尚有爭議） |
| 1970–1980 | 「延森式」的語域跳躍成為丹麥語文學的標準術語，也成為新寫作者模仿的對象 |
| 1980–2000 | 學界整理「延森檔案」，其手稿、與畫家合作製版的手抄本成為版刻與插圖研究的課題 |
| 2000 年代 | 「以地方神話承載整個民族」的做法，被北歐與格魯吉亞等國的作家繼續沿用 |
