# 1907 · 吉卜林與帝國的聲音：把殖民地內部的雜音寫成世界的標準英語

> 1907 諾貝爾文學獎：拉迪亞德・吉卜林（Rudyard Kipling，1865–1936，英國）——表彰其「觀察的力、想像的原創、理念的剛健與敘事的非凡天賦」。【案發現場：孟加拉的一間辦公室，編輯在一堆來稿中挑出一篇關於小人物的短篇；兇手不是人，是一個帝國的眼睛——它決定了誰的聲音值得被聽見。】

## 懸案（案情提要）

案發現場是 1886 年 11 月到 1887 年 6 月的拉合爾：《Civil and Military Gazette》副編吉卜林在這七個月裡發表了三十九篇短篇，其中多數在半年後被收進《山間故事》（Plain Tales from the Hills，1888 年 1 月於加爾各答出版）。這批小說裡有軍官、醫生、報童、混血侍者與一條會說話的蛇；它們用的是白人在印度寫公文的英語，卻記錄了印度士兵、孟加拉民眾與森林動物的生活。

案子為什麼懸？因為它牽涉一個更大的問題：誰有權替帝國說話？1907 年的頒獎理由寫著「觀察的力、想像的原創、理念的剛健與敘事的非凡天賦」，幾乎每一項都指向他的技術，卻沒有一項處理他的立場。這在文學獎史上留下了一條至今未結的裂縫：得主的作品裡同時存在《白人的負擔》（1899）那樣替帝國辯護的詩，也存在《Kim》（1901）裡對帝國內部茫然失措的少年。

更麻煩的是反應。當年英國輿論為這個決定分裂成兩半：有人認為把諾貝爾獎給一個把帝國寫成英雄詩歌的作家是國恥，有人認為他是英格蘭在海外的喉舌。此後數十年，吉卜林的聲譽隨著帝國本身的興衰起落——文學史家道格拉斯・科爾的說法是，他始終是「一個能激起激烈異議的作者」。這樁案子，最後是隨著帝國的解體而重新被翻出來的。

## 調查

**第一步：把新聞的速度帶進短篇。**
吉卜林的短篇是在報紙截稿日之間寫出來的，這賦予它一種報告文學的節奏：開場即入事、結尾不留餘地。但更關鍵的是**框結構**——《山間故事》與《叢林之書》都由一個在印度服務過的人講述，敘事者一邊自嘲經驗不足，一邊被故事吸走。《Kim》裡那個來自印度的少年，則是全書的視角開關：英國讀者透過一雙「本地人的眼睛」看見自己的帝國。

**第二步：讓次要人物與動物擁有發言權。**
《叢林之書》裡的莫格利由諸狼長老會議撫養，鳄鱼、豹、熊各有性格與語氣；《Kim》裡有喇嘛、有抽水泵的司機、有 bazaar 裡的小販。吉卜林的技術核心是**語域的分配**：同一個故事裡，帝國說英語、本地人說夾雜的洋涇浜、而敘事者用一種介於兩者之間的敘事節奏翻譯。這套配置後來被批評為刻板化，但當時它確實讓帝國的內部第一次有了聽眾。

**第三步：檢查帝國的自我證詞。**
《白人的負擔》（1899）是帝國最難反駁的一篇詩，也因此是最常被引用、最常被引用來反駁的一篇；同一年的〈The Absent-Minded Beggar〉卻寫帝國的錢從何而來、落到誰手上。**吉卜林最好的作品幾乎總是同時提供兩份證詞**，這使他的帝國描寫無法被簡化成宣傳或花瓶。

**第四步：處理那場沒人簽收的輿論風暴。**
1907 年的頒獎在英國是一場國民性事件：收到的祝賀與譴責信件數以千計，報紙分成了兩營。諾貝爾委員會選的是「敘事天賦」，公眾爭的卻是「帝國的姿態」。這樁案子後來被反覆重新審判：帝國解體之後，《Kim》反而被讀成一部關於「帝國無法理解自己」的悲劇小說。

## 技藝裁決

**裁決一：短篇可以像戰地通訊一樣寫。** 吉卜林重新定義了英語短篇的速度：一篇只處理一個事件、只用一組對立（帝國／本地、成人／孩子、森林／城市）、結尾給一個不解釋的轉折。這套配置在報紙連載的條件下成型，卻因此改變了短篇小說的體量觀。

**裁決二：視角的選擇就是政治。** 讓印度少年成為《Kim》的主人公，等於宣告「帝國的內部必須透過本地人的眼睛才能被看見」；這種把讀者放進被觀察位置的寫法，是二十世紀後殖民敘事的技術前身。

**裁決三：語言必須分層。** 吉卜林示範的是複數聲部的英語：帝國的正式英語、士人的半夾雜口語、本地人的玩笑、動物的擬人化語言。他也因此付出了被指為刻板印象的代價——但沒有這種分層，帝國的異質性根本無法在紙上出現。

**裁決四：抒情要有可重唱的形狀。** 從〈Gunga Din〉到《Just So Stories》的笑話體，吉卜林證明了一件事：一段話如果不能被群眾重複，它就留不下來。這條「可重複性」的要求，是他把文學寫成社會物件的方式。

## 後果

| 年份 | 影響 |
|------|------|
| 1907 | 首位獲諾貝爾文學獎的英語作家；頒獎理由的「觀察力／想像原創／理念剛健／敘事天賦」四項，確立了文學獎的技術性判準。 |
| 1909 | 拉格洛夫以《尼爾斯・霍爾姆松的旅行》獲獎，與《叢林之書》同屬「把異域寫成可進入的世界」的兒童文學策略。 |
| 1913 | 泰戈爾獲獎，其《頌歌集》由英國詩人助譯推入西方——與吉卜林同屬「為非西方讀者處理語言」的技術難題。 |
| 1936 | 骨灰安葬西敏寺詩人角，是諾貝爾文學獎史上首位獲此待遇的得主。 |
| 1945–70 年代 | 隨著帝國解體與兩次大戰的記憶，吉卜林在英美的聲譽大幅下滑，被視為帝國主義的代言人，其作品退出學校教材。 |
| 1980–2000 年代 | 學界與出版界重新評價《Kim》與《叢林之書》，視其為「後殖民敘事」與「兒童文學跨界寫作」的源頭。 |
| 2010 年代 | 《白人的負擔》是否應留在美國學校教學綱要的爭議，讓這首詩回到公共討論的檯面上，成為「文學是否為帝國辯護」的一個測試案例。 |
| 2020 年代 | 《Kim》與《山間故事》持續被改編與重譯，吉卜林的作品被同時當作帝國史料與純文學來讀。 |
