# 1917 · 耶勒魯普與龐托皮丹：一屆之內，同一個國家交出兩張面孔

> 1917 諾貝爾文學獎：卡爾・阿道夫・耶勒魯普（Karl Adolph Gjellerup，1857–1919，丹麥）——表彰「其豐富而多彩的詩作，其靈感源自崇高的理想」；亨利克・龐托皮丹（Henrik Pontoppidan，1857–1943，丹麥）——表彰「其對當代丹麥生活的真實描寫」。兩人同屆同國，獎金對半分；一個用德語寫作，一個用丹麥語寫農民。

## 懸案（案情提要）

1917 年是第一次世界大戰的第三年。丹麥宣布中立，但文學界沒有中立：這一年諾貝爾文學獎由兩位丹麥人共得，獎金各分一半。

第一位的案卷本身就是矛盾的。耶勒魯普是丹麥人，卻用德語寫作，1892 年起定居德國，娶了德國妻子；一戰爆發後他完全認同德國的戰爭目標。丹麥人普遍視他為「德國人」——左翼罵他，右翼也罵他。他獲得的這一半獎金，正是給一個「在語言邊境上」的作家。

第二位的案卷相反地真實。龐托皮丹寫的是丹麥本身的農民、無產者與鄉村知識分子，他被稱為丹麥現代文學「突破」一代中最年輕、最有原創性、也活得最久的一位；他的作品寫盡一個半農半商社會的階層升降與精神崩解。

懸案的問題因此變得尖銳：為什麼瑞典學院要把同一枚獎金切給「德國的丹麥人」和「丹麥的丹麥人」？這是在分獎，還是在做一個關於「一個民族可以有多張面孔」的示範？

## 調查

**第一步：拆開「一個民族」的假設。**
耶勒魯普的整個寫作生涯，是一次對「國籍」的壓力測試。他先寫丹麥語（詩集《Extramundana》，1882），然後轉用德語寫小說，最後在《朝聖者卡瑪尼塔》（1906）裡把主題推到佛教——一個丹麥人用德語寫印度人的轉世。技術上他做的事情是：把「民族文學」的前提拆掉，只留下語言與觀看的方式。結果是他在自己祖國幾乎被遺忘，在德語界卻長期是重要作家。

**第二步：測試「理想」到底能有多高。**
委員會給耶勒魯普的判詞是「靈感源自崇高的理想」。要檢驗這句話，就看他敢不敢把理想寫到祖國之外：《朝聖者卡瑪尼塔》讓主角在轉世中遇見的陌生和尚其實就是釋迦牟尼本人；《世界的漫遊者》（1910）讓同一批靈魂在數個時代裡反覆相遇；詩劇《完美者之妻》（1907）直接借但丁《神曲》的三段結構寫悉達多與耶舍陀羅。凡此都沒有政治用途，卻正是「崇高理想」在技術上的樣子：把情節結構交給神話，而不是交給事件。

**第三步：檢驗「真實描寫」是不是等於寫實主義。**
龐托皮丹被評為「對當代丹麥生活的真實描寫」，但他真正做的技術動作是「反理想化」。《村莊速寫》裡的農民不是文學傳統裡那種純樸的農民；他是會算計、會歧視、會破產的人。《幸福彼爾》（1898–1904）寫階層上升與精神崩落，結尾是成功者放棄一切、獨自下山——這正是「丹麥版」的階級小說。更狠的是《北極熊》（1887）與《夜巡》（1894），後者直接拿他的畫家朋友 L. A. Ring 作原型，對方認為遭到背叛而與他斷交。

**第四步：追查一次「褻瀆」案的屍體。**
1889 年《彌賽亞》、1890 年《老亞當》匿名刊出，惹來宗教案件；出版商 Ernst Brandes 被罰 300 克朗，1892 年自殺身亡。這樁舊案說明龐托皮丹的「真實描寫」從來伴隨風險——他的寫作方法建立在細節、方言與不客氣的細節上，因此觸怒的不只是教會，也是讀者的自我形象。

**第五步：把獎金切開，看兩半各自說了什麼。**
瑞典學院把同屆的同一枚獎金分成兩半給同國作家；此後同屆雙得主只再出現兩次（1904、1966 年），而同國瓜分則要等到 1974 年才由兩位瑞典作家重演。1917 這一次的切法非常精準：耶勒魯普代表的是「一個作家可以比他的國籍更寬」，龐托皮丹代表的是「一個作家可以比他的國籍更窄、更硬」。丹麥文壇對前者冷淡、對後者尊敬，說明當時的北歐讀者已經準備好接受現實描寫，卻還沒準備好接受歐洲化的理想。

## 技藝裁決

**裁決一：語言選擇本身就是政治敘事。** 耶勒魯普用德語寫作，等於宣告「我的讀者不在我的國境內」。這在文學獎史上第一次把「作家是誰的」這個問題與「作品用什麼語言寫」拆開來處理；此後流亡文學的一切難題，都可以說是從這個切口開始的。

**裁決二：神話結構是最高效的哲學裝置。** 《完美者之妻》借《神曲》寫佛陀人生，等於把「普遍的人性問題」放進讀者已有的架構裡，而不必另建一套說明。諾貝爾基金會所謂「崇高的理想」指的不是情懷，是這種結構能力。

**裁決三：反理想化是寫實主義真正的起點。** 龐托皮丹的第一個技術動作是取消好農民的刻板印象；取消之後，才輪得到階級、暴力與道德的細節。1930–40 年代的林格倫、麥卡錫等人都從這一課開始學寫鄉村。

**裁決四：句法的方言化同時是價值的表態。** 他大量使用丹麥中部鄉村的方言與土語，把「標準語」讓給官方與報紙；語言的階級性被直接搬進小說句子裡。這是北歐寫實主義與歐洲寫實主義分岔的地方。

## 後果

| 年份 | 影響 |
|------|------|
| 1917 | 1917 年成為諾貝爾文學獎史上第一次由同國雙得主瓜分獎金（同一屆出現兩位得主的情形另見 1904、1966、1974 年）。 |
| 1917–19 | 耶勒魯普在德語界持續享有聲望，在丹麥本土卻長期被冷落；此後丹麥文學史把他稱為「世紀末的界外人」。 |
| 1920 年後 | 龐托皮丹的《幸福彼爾》成為北歐讀者理解階層流動的標準文本，與丹麥的社會民主討論長期糾纏。 |
| 1933–1943 | 龐托皮丹寫成兩個版本的《回憶錄》，為北歐作家建立「以自傳重構自我」的新體例。 |
| 1943 | 龐托皮丹 8 月 21 日逝於哥本哈根；晚年失明失聰仍參與政治文化討論。 |
| 1950–70 年代 | 丹麥文學史重新評價「突破」一代，龐托皮丹被確認為其中最長壽、最具持續影響力者。 |
| 2010 | 娜歐蜜・雷博維茲（Naomi Lebowitz）譯的《幸福彼爾》完整英譯本問世，是這部小說第一次完整進入英語世界。 |
| 2025 | 保羅・拉金（Paul Larkin）重譯《北極熊》與《夜巡》（NYRB），北歐寫實主義的經典開始系統性重譯。 |
| 20 世紀末 | 學界為耶勒魯普正名：確認他並非「德國作家」，而是一位自覺進行跨文化實驗的作家。 |
