# 1902 · 莫姆森與羅馬史：史家中年翻案，把小說的力氣塞進了考證

> 1902 諾貝爾文學獎：提奧多・莫姆森（Theodor Mommsen，1817–1903，德國）——表彰「他是偉大的歷史書寫藝術在世的大師，尤其就其宏偉的《羅馬史》而言」。他破的是一樁類型案：歷史書到底算不算文學？答案得由他用整卷的語氣來裁決。

## 懸案（案情提要）

1902 年的諾貝爾文學獎，最後頒給了一個寫羅馬史的人。這在文學獎史上至今只發生過一次。

問題出在諾貝爾遺囑的字面：獎給「在理想方向上」的寫作者。歷史書寫得夠不夠「理想」？委員會內部並不一致。當年被認真考慮的還有托爾斯泰、易卜生與比昂松——托爾斯泰被評為思想「無政府主義」，易卜生被評為「過於激進的風格」；比昂松則被推遲到下一屆，理由是他與易卜生可以共享一份獎。

永久秘書 C. D. af Wirsén 是易卜生與托爾斯泰的死對頭，於是把莫姆森端上桌當作大家都能接受的替代方案。這是一樁典型的「用類型換共識」的案子：把文學獎交給一位寫學問的人，好讓其他所有人都不必輸。

而被選中的那位學問人，交出的答案是小說。

## 調查

**第一步：確認被告身分與不在場證明。**
莫姆森本人並不是「歷史家寫小說」：他是受過完整法律訓練的古典學者、銘文學家，《拉丁銘文集》強調的「目驗法」要求每一條抄本都回到原物比對。這條物證鏈是全案的底盤——他不是憑想像寫羅馬，而是先從石頭上把話讀出來。

**第二步：重建案發現場。**
1850 年在萊比錫那次「格拉古兄弟」演講是關鍵轉折。莫姆森自述：演講後兩天，出版商 Reimer 與 Hirzel 便請他寫一部羅馬史；他想的是「一部分為了生計，一部分因為這工作很吸引我」。出版商指定：寫事件與情勢，不要談學問過程；但必須有文學分量，讓受過教育的公眾讀得下去。學術與暢銷的合同，就這樣在講臺上簽成。

**第三步：拆解寫法。**
第一卷問世即造成巨大聲響。G. P. Gooch 在《十九世紀的史家與史學》中寫：「《羅馬史》使莫姆森一夜成名。」批評也隨之而來——學界覺得語氣太像報紙、像政論；莫姆森自己回得更硬：「我想把古人從那個想像的高台上拉回到真實世界裡來。這就是為什麼執政官必須變成市長。」

**第四步：重演第三卷的語氣轉折。**
到了第三卷（1856），共和國走向崩解，敘事幾乎是電影化的：Sauders 與 Collins 在 1958 年的節選本序言裡說，莫姆森在第三卷裡「以專業史家中幾乎未見的想像之火與情感之火寫作；這裡有科學的學問，卻有小說般的風格力道」。在這裡，寫史與寫小說不再互相排斥，而是同一套技術。

**第五步：清點懸案——消失的第四卷。**
《羅馬史》原訂五卷，第四卷（帝國史）因《拉丁銘文集》十五卷的編纂而被無限期延後，最終只有第五卷於 1885 年問世。1980 年，其學生 Sebastian Hensel 與 Paul Hensel 的筆記在紐倫堡一家舊書店被翻出，才於 1992 年以《Römische Kaisergeschichte》重建出版——這樁舊案在 1990 年代才結案。

## 技藝裁決

**裁決一：史家的合法身分是「事件的敘述者」，不是「結論的發言人」。** 諾貝爾基金會在 1902 年的說明裡特別指出，莫姆森的寫作「生動而富同情心」——這是文學獎第一次用「寫作品質」而不是「研究貢獻」來描述一位歷史作者。

**裁決二：人物塑造靠「獨白式的直接介入」。** 莫姆森不讓史料自己說話，而是讓人物在關鍵處自己辯護：談元老院時讓塞拉敘（Sallust）的語氣壓過道德判斷，談凱撒時直接搬出他的政治理由。這是一種把小說的主觀性引進史家的寫法，也是他後來被指為「把德國議會政治寫進古羅馬」的技術來源。

**裁決三：德語長句的節奏＝敘事引擎。** 莫姆森的德文長句以從句疊加、動詞置後與插入語製造出「一氣呵成」的推進感，讀者幾乎無法中途停頓。這種「句法即敘事」的技術，後來成為德語歷史散文的標準，也讓《羅馬史》的英文譯本長久以「讀起來不像翻譯」聞名。

**裁決四：研究與文學的分工被重新劃界。** 莫姆森的做法是：考證放到《拉丁銘文集》與專論裡去，把最尖銳的判斷留在《羅馬史》的正文。歷史學界此後沿用同一分工——引文可查，敘事負責說服。諾貝爾獎史上唯一一次把獎給史家，正建立在這套分工之上。

## 後果

| 年份 | 影響 |
|------|------|
| 1854–56 | 《羅馬史》三卷問世即成經典，被讀者視為「一夜成名」的範例，確立了「研究＋敘事」的雙軌寫法。 |
| 1862–66 | 迪克松英譯本問世，隨後近百版重印，讓《羅馬史》成為近代世界讀羅馬史的標準途徑。 |
| 1902 | 諾貝爾文學獎史上唯一一次頒給「歷史書寫藝術」的大師，委員會並在理由中直接引用《羅馬史》，文學獎因此承認了非虛構寫作的文學價值。 |
| 1902 | 委員會原本屬意托爾斯泰（被評「無政府主義」）與易卜生（被評「過於激進」），並曾考慮讓比昂松與易卜生共享獎——這樁未發生的「共享獎」案，直接影響 1903 與 1904 兩屆的結果。 |
| 1903 | 比昂松以「個人作品與寫作技巧的大師地位」被提名，最終單獨獲獎，延續了「文學獎不必靠小說兌現」的判準。 |
| 1904 | 委員會再拒絕歷史學家 Albert Sorel，理由是不願連續兩年頒給歷史學者——說明 1902 年的破例是特例而非新制。 |
| 1922 | 莫姆森學術整理的《拉丁銘文集》完成，1928 年全部出齊，古典學界沿用至今。 |
| 1980–92 | 失落的第四卷以學生的聽講筆記重建出版（《Römische Kaisergeschichte》），並於 1996 年英譯，補上了《羅馬史》最關鍵的缺口。 |
| 1994 | 《羅馬史》第一卷中譯本由商務印書館出版，這部德文巨著第一次以中文進入中國讀者的視野。 |
