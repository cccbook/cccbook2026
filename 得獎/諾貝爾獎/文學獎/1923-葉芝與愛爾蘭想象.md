# 1923 · 葉芝與愛爾蘭想象：把一個民族交給詩人保管

> 1923 諾貝爾文學獎：威廉・巴特勒・葉芝（William Butler Yeats，1865–1939，愛爾蘭）——表彰「其始終受靈感驅動的詩作，以極其藝術的形式表達一個民族的精神」。他破的是一樁委託案：愛爾蘭剛剛獨立，誰有資格替它說話？

## 懸案（案情提要）

1923 年 12 月，斯德哥爾摩。評審委員面前有一份很難解釋的得獎理由：「始終受靈感驅動的詩作，以極其藝術的形式表達一個民族的精神」。這不是給一位詩人的獎，這是給一個國家的委託。

時間點說明了一切。愛爾蘭自由邦在 1922 年成立，1923 年第一次有了自己的貨幣、自己的參議院、自己的國歌。文化界正在爭論：民族文學到底是繼續用英文寫（因為英文是全球通用的語言，也因為很多愛爾蘭作家自己也只會寫英文），還是用愛爾蘭語寫？

葉芝的答案是第三條路。他既不用愛爾蘭語寫，也不放棄英語；他用英語寫愛爾蘭，並且成立劇團、辦劇院、造出一整套公共文化機器，讓「愛爾蘭」成為一件可以在舞台上被看見的東西。他的《凱爾特人的黃昏》（1893）造出神話，《卡瑟琳・尼・胡利漢》（1902）造出女英雄，他與葛萊夫人等人在 1904 年落成的艾比劇院裡，造出一整代演員與觀眾。

案子還有一層較晚才結清：他 1922 年被任命為愛爾蘭自由邦第一任參議院議員，1925 年再任一屆，在那裡為天主教與新教的政治衝突發言——他把文學家的身分帶進了立法機關。

## 調查

**第一步：確認委託人是誰。**
葉芝不只是寫愛爾蘭，他是替愛爾蘭建立文學的公共機構。1899 年他與葛萊夫人等人創立愛爾蘭文學劇院並撰寫宣言，宣稱：「我們希望在愛爾蘭找到一個未被敗壞的、有想像力的觀眾群，他們受過對雄辯的熱愛所訓練……並具備別處的劇院所沒有的那種自由實驗。」（艾比劇院宣言）這句話的關鍵不是修辭，而是「觀眾群」——他相信文學要成立，必須先有一群被訓練過的觀眾。1904 年艾比劇院落成，公共文化制度於是成型。

**第二步：拆解「民族精神」是怎麼被造出來的。**
《凱爾特人的黃昏》（1893）把愛爾蘭的精靈與民間故事系統化，形成「蓋爾文主義」的文學運動：民俗、神祕主義與詩的形式結合。他的方法是把口述材料轉成文學語彙庫——精靈、妖精、殉道者、女人。接著《卡瑟琳・尼・胡利漢》（1902）把這套材料政治化：女主角在劇中象徵愛爾蘭，演出本身就是一次民族象徵的儀式。

**第三步：檢查英語的問題。**
葉芝的關鍵技術選擇是：**用英語寫愛爾蘭，同時不斷在作品內部重建愛爾蘭的語感**。他大量使用古蓋爾語的構詞法、名字與地名，把英國讀者的耳朵拖進一個異質的語言環境。這正是他與葉芝派（Éire Óg）同道、卻與「全愛爾蘭語化」主張分道揚鑣的原因。1923 年後，愛爾蘭語文學與英語文學長期分流，葉芝的路線贏得了世界性的讀者。

**第四步：測試晚年的轉向。**
1925 年的《幻象》（A Vision）把他早年的直覺整理成一套可演算的系統：文明在「相」與「迴旋」中週期性傾斜。詩集《塔》（1928）裡的〈駛向拜占庭〉把這個觀點壓縮成一句：藝術家不能住在現實世界裡，只能住在手工藝的世界裡；老人必須化成水、化成石，否則就會被文明的浪頭沖走。他自嘲寫《幻象》時說：「我想我是在自欺，幻想這是我一生之書。」這段自嘲本身就是方法：**他把密宗系統公開做成可懷疑的架構，而不是藏起來。**

**第五步：查他在議會裡說了什麼。**
他在參議院兩度發言，處理天主教與新教的政治緊張。他說過：「我們不要以為我們是卑微的人。」也曾批評教會在立法討論中的姿態：「我出生的教會的光榮之一，就是我們把主教們放在了他們的位置上，在需要立法的事上如此。」文學家進入立法機關、直接用宗教立場說話，是愛爾蘭文化政治裡罕見的一筆。

## 技藝裁決

**裁決一：民族詩是一項工程，不是一種情緒。** 葉芝的示範是：要表達「一個民族的精神」，你得同時擁有神話材料（民間故事與古物）、一種能承載它的語言策略、一群能聽懂的觀眾，以及一個讓它們相遇的制度。他把四件事一起做，這是文學獎史上第一次有人以「民族文學的基礎建設」自任。

**裁決二：寫別人的語言，反而要更用力地做「語言考古」。** 他在英語裡重建愛爾蘭語感，靠的是把古蓋爾語的地名、人名與句法痕跡密集地放進詩中；這等於用英語的介面逼讀者正視愛爾蘭性的存在。這個方法後來在所有「用殖民者語言寫本土經驗」的場合被反覆使用。

**裁決三：儀式性演出可以承載政治。** 《卡瑟琳・尼・胡利漢》不是歷史劇，而是讓觀眾在劇院裡共同完成一次象徵行動；它的效應與它的文本同等重要。這是把文學轉成公共文化的關鍵技術。

**裁決四：把密宗系統做成公開的可辯論架構。** 《幻象》不把神祕說法當真理，而是設計成一套有條理、可用來解釋歷史與藝術的圖式，並容許讀者懷疑它。這讓他的晚年詩在哲學上站得住腳，也讓「民族詩人」的形象不必建立在信仰之上。

## 後果

| 年份 | 影響 |
|------|------|
| 1893–1907 | 《凱爾特人的黃昏》與艾比劇院共同開啟愛爾蘭文學復興，蓋爾文主義成為一整套可教的寫作課程。 |
| 1897 | 他以首席劇作家的身分提拔艾茲拉・龐德，庞德隨後成為英語現代主義的關鍵人物。 |
| 1904 | 艾比劇院落成開幕；愛爾蘭文學從此有了常設機構與固定的觀眾群。 |
| 1922–1925 | 兩度出任愛爾蘭自由邦參議院議員，把詩人帶進立法辯論，是愛爾蘭文化政治史上的特例。 |
| 1924 | 他主持愛爾蘭自由邦貨幣設計委員會，把愛爾蘭的象徵放上第一套硬幣。 |
| 1926–27 | 《幻象》推出修訂版並持續改寫，密宗式宇宙觀成為二十世紀英語詩學的重要文獻。 |
| 1933 | 《旋梯》出版，〈駛向拜占庭〉與〈第二次降臨〉成為英語世界最常被引用、也最常被誤讀的二十世紀詩作。 |
| 1939 | 1 月 28 日逝於法國 Menton；其墓在斯萊戈郡。 |
| 1939 年後 | 艾比劇院自 1967 年起改由國家資助，成為愛爾蘭的國立劇院，艾比劇獎（Abbey Awards, 1968 年起）成為愛爾蘭戲劇最重要的獎項，延續了他建立的公共文化體制。 |
| 20 世紀後期 | 葉芝研究從「民族詩人」轉向「思想系統的作者」，其晚年的迴旋理論與文學史、非西方思想史產生大量對話。 |
