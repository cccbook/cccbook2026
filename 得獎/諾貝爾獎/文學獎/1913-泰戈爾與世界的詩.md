# 1913 · 泰戈爾與世界的詩：第一個非歐洲得獎者，和一場關於「譯者」的案件

> 1913 諾貝爾文學獎：羅賓德拉納特・泰戈爾（Rabindranath Tagore，1861–1941，印度）——表彰其「極其敏感、新穎而美麗的詩，以精湛技藝使自己的詩意思想——用他自己寫的英文——成為西方文學的一部分」。【案發現場：1912 年倫敦一家小出版社印出一本薄薄的《頌歌集》，序言署名 William Butler Yeats；兇手不是人，是一本用英文寫成的孟加拉語詩集——誰是它的作者？】

## 懸案（案情提要）

案發現場是 1912 年 11 月的倫敦。印度協會（India Society）出版了一本小開本的《頌歌集》（Gitanjali: Song Offerings）：作者是孟加拉的泰戈爾，英文卻是英國詩人威廉・巴特勒・葉芝作序、威廉・羅森斯坦（William Rothenstein）協助翻譯、泰戈爾本人逐行校訂的「作者譯本」。這是一樁麻煩的案子：**如果文本是合作產物，作者欄該寫誰的名字？** 泰戈爾自己解決了這個問題——他把自己的孟加拉語原詩帶著，用自己的英文重寫了一遍，於是那個英文版本成了「用他自己的話寫的詩」。

案子為什麼懸？因為它同時是三樁。第一樁是文學的：一個非歐洲的詩人，用英語寫的短歌集，能不能進入西方文學的正統？第二樁是制度的：1913 年的諾貝爾基金會為此徵詢了英國與印度兩方面的意見，這在文學獎史上是破天荒的程序。第三樁是政治的：1913 年印度剛被切成英屬印度與孟加拉分治，一個主張「精神而非國界」的人，用最受帝國歡迎的語言（英語）說話，立刻在孟加拉知識界引發了一場國民論戰——他到底是代表印度，還是代表一個跨國的文學？

而在諾貝爾的演說詞裡，瑞典學院的措辭意味深長：「以精湛技藝使自己的詩意思想——用他自己寫的英文——成為西方文學的一部分。」他們沒有談民族、談政治，只談**技藝**；這是諾貝爾文學獎史上第一次把「翻譯與傳譯」本身當成獲獎的技術問題。

## 調查

**第一步：把「歌」當成詩的原子。**
《頌歌集》不是分節的長詩，而是上百首彼此獨立的短歌。這種形態的好處是技術性的：**每首歌是一個完整的意象循環**——開頭一個畫面，中間一次轉折，結尾一個反覆的句子。它能被記誦、能被配樂、能在沒有宗教背景的讀者身上生效。泰戈爾把印度宗教歌（bhajan、kirtan）的口傳傳統，轉成了一種可跨文化的抒情單位。

**第二步：重譯自己的詩。**
英文《頌歌集》不是轉移語言，而是**重寫**：泰戈爾保留了意象的骨架，卻把句子壓短、把反覆的節奏打得更乾淨，讓不懂孟加拉語的讀者可以直接承受那份「直觀」。這套「作者自譯」的策略，也讓他能同時對兩個文學系統負責。1903 年諾貝爾獎的理由強調他「以自己的英文」表達詩意，正是在承認這項雙重技術。

**第三步：檢查孟加拉的回聲。**
英文版《頌歌集》出版後，孟加拉知識界立刻分裂成兩派：一派認為以英語創作是背叛，一派認為詩是超國界的。1913 年諾貝爾獎落在他身上，等於官方裁決了這場論戰——**但裁決的方式是承認他的英語身分，同時保留他的孟加拉根源**。他的解決方案是把自己的機構帶出去：1901 年創辦的聖蒂尼克坦林間學苑，1921 年成為「梵社」（Visva-Bharati）大學。

**第四步：核對另一份卷宗——勳章。**
1915 年他接受爵士勳章；1919 年阿姆利則屠殺之後，他寫信給英國總督說，這些處罰的「不成比例的嚴酷」在文明政府的歷史上無與前例，「我們的恥辱在這種不相稱的羞辱情境裡變得刺眼」，然後退還了勳章。**一位寫田園與兒童的詩人，把榮譽制度本身列入了他要控訴的對象。**

## 技藝裁決

**裁決一：翻譯可以是一種詩學，而不是降格。** 泰戈爾示範的是「作者重寫自己的詩」：他讓英文版本成為一首獨立成立的英文詩，同時保住原詩的意象骨架。這後來成為非西方詩人進入世界文學的標準路徑。

**裁決二：歌謠單元適合於跨文化的傳播。** 短歌不要求讀者先掌握一套神學或歷史，就能被記誦與引用；它是詩歌、歌曲與朗誦之間最耐用的介面。廿世紀的「短詩」風潮，多少繼承了這條線。

**裁決三：把意象系統收斂到極少數。** 泰戈爾的反覆意象（水、塵、孩子、鳥）構成一套可被辨識的哲學裝置：自然的循環對上人的有限。他的靜物詩因此不是「寫景」，而是同一套命題的不同變奏。

**裁決四：散文與戲劇也用同一套語法。** 《人生實現》《人格》是散文詩；〈契達〉（1914）、〈香達莉卡〉（1938）、〈夏摩〉（1939）把印度古典舞的動作語法寫進戲劇；音樂與舞蹈在他這裡不是裝飾，而是思考的方式。

## 後果

| 年份 | 影響 |
|------|------|
| 1913 | 首位非歐洲的諾貝爾獎得主（任何獎項），也是首位以抒情詩得獎者；「用他自己的英文」一語，把翻譯能力正式寫入諾貝爾文學獎的判準。 |
| 1915 | 印度詩人與諾貝爾獎的關係成為世界文學的公共事件；殖民地的文學首次被授予與歐洲同等的榮譽。 |
| 1923 | 葉芝以《愛爾蘭想像》獲獎——正是他為《頌歌集》寫序、協助引介泰戈爾入英語世界；同年《飛鳥集》中譯本在中國與歐洲同時走紅。 |
| 1924 | 泰戈爾訪華與訪南美，同年《家庭與世界》（1916）與後續作品在中國引發「泰戈爾熱」，徐志摩、林徽因一代由此接上世界的文學。 |
| 1921 | 他在聖蒂尼克坦創立「梵社」（Visva-Bharati），後成為亞洲最具影響力的跨國學府之一，把他的詩學變成教育制度。 |
| 1950–60 年代 | 冰心等中國譯者推介的《飛鳥集》《新月集》在華流傳數十年，泰戈爾在中文世界長期是「被介紹的印度詩人」第一人選。 |
| 1971 | 聶魯達以「喚醒一個大陸的命運與夢想的詩」獲獎，亞洲詩與拉美詩在諾貝爾獎上接成同一條線。 |
| 20 世紀後期 | 泰戈爾研究從「代表亞洲」轉向「技術與翻譯史」，他對西方現代詩的影響（尤其透過龐德與葉芝）被重新估量。 |
