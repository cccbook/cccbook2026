# 1929 · 湯瑪斯曼與布登勃洛克：一個商人家族的四代興衰

> 1929 諾貝爾文學獎：托馬斯・曼（Thomas Mann，1875–1955，德國）——表彰「其偉大小說《布登勃洛克》，它穩步增長地贏得認可，成為當代文學的經典之作」。他破的是一樁家族破產案：呂貝克一個商人家族的四代人、兩間店、一座宅邸，和一條緩慢下沉的地基。

## 懸案（案情提要）

案發現場是呂貝克一棟商人的宅邸。故事從一七五六年的一次遠征結束的那一天開始——七十六歲的約翰・布登布羅克在豪宅裡過生日——然後寫到下一代：兒子拿到戰爭生意的紅利，買下隔壁的「河屋」與新宅；再下一代是克利斯蒂安，一個無法承擔家業的音樂家兒子，選擇了藝術也選擇了破產；最後是艾利克，一個為了維持門面而幾乎毀掉自己的商人。

《布登勃洛克》（Buddenbrooks, 1901）問的問題很冷靜：一個家族為什麼會死？答案不是腐敗、不是災難、不是惡人作祟，而是**每代人都在用自己的方式盡責，而盡責的方向一代比一代窄**。第一代盡的是城市的責任，第二代盡的是商業的責任，第三代盡的是「維持體面」的責任。到第四代，剩下的只有門面本身。

而這部小說的作者，正是這個家族。托馬斯・曼出身呂貝克的漢薩市民階層，他的祖父與外祖父都做過商人；他在《布登勃洛克》裡寫自己的家族，被呂貝克的世家們視為一種背叛，據說多年不與他往來。1929 年得獎時，委員會只提這一部書。

## 調查

**第一步：先把時間標尺釘死。**
《布登勃洛克》分三部，每一部由幾個有明確年份的章節構成：從一七五六年到一八七七年，一個半世紀裡四代人的生意、婚喪、疾病與破產。每一章的開頭都是一個可查證的日期與一個可指認的物件——店裡的貨櫃、家族的宅邸、餐桌上的餐具、被賣掉的房子。技術上，這是把小說變成**有帳可查的家族檔案**。

**第二步：追蹤那座宅邸。**
房子是這部小說的真正主角。河屋（das Flusshaus）、白色樓梯、被拆掉的穀倉、孩童砸掉的門鈴、屋頂的顏色變化——房子的每一次修繕都意味著一次權力轉移，賣屋那一段寫盡了「體面」如何一寸一寸地被拆掉。評論者稱之為把巴爾扎克《人類喜劇》式的家族史「具體化為不動產」：資產清單同時是價值觀清單。

**第三步：檢查那條「音樂」暗線。**
艾利克——那個放棄商業去學音樂的兒子——在家族裡是最不受理解的成員，也是唯一真正接近幸福的人。湯瑪斯・曼在此處埋下了一整套反向的價值觀：把音樂（無用的、不能變現的）當作最高的實在，把商業（能變現的）當作一種不斷失敗的嘗試。這條暗線在十年後長成《魔山》（1924）——整部小說的主題是「無利害性」（Interessenlosigkeit），一位工程師在 sanatorium 裡學會如何對世界的重大問題保持距離。

**第四步：拆解官樣文章與真話的落差。**
小說裡大量出現德國式的「半私人信件」與家族慶典演說——外交式的套話、社交場合的語言。湯瑪斯・曼讓這些套話在小說內部被家族的實際行為一一駁倒。他後來在《魔山》與《日瓦爾醫生》裡把這個手法推到底：語言與行為之間那道無法彌補的縫，是德國知識界的核心病。

**第五步：核對他自己與這宗案子的關係。**
《布登勃洛克》寫的是他自己的家族與家鄉。1933 年之後他流亡瑞士、1939 年後移居美國，成為「流亡文學」（Exilliteratur）的核心人物——一位先解剖祖國的作家，隨後不得不以客居者的身分檢視那個世界。戰後他回到呂貝克，看見父母的房子在戰時轟炸中部分毀壞、其後才重建；而那些世家對《布登勃洛克》的怨憤也已成往事。同一個人，同一座城市，構成本案最後的一層反轉。

## 技藝裁決

**裁決一：家族小說可以用「損益表」當骨架。** 每一代人的生意數字、房產清單、喪葬支出同時是情節、歷史與價值判斷。托馬斯・曼把巴爾扎克式的社會全景收斂成一間店與一個家庭，讓歷史的變化只能透過具體的物的增減被看見。

**裁決二：諷刺不靠語氣，靠對照。** 官樣文章與實際行為被並置，譏誚自然產生；這種「結構性反諷」比機智的警句更耐久，也更容易被翻譯與流傳。

**裁決三：藝術與功利的對立可以成為長篇小說的主題。** 艾利克的音樂不是浪漫插曲，而是《布登勃洛克》的價值判準；這條線在《魔山》發展成完整的主題（無利害性），並直接影響後來的德語小說傳統。

**裁決四：把主角寫成自己的家族，需要距離也需要殘忍。** 《布登勃洛克》的寫作宣告是文學史上少見的一次公開的自我解剖；它的技術前提是：**必須同時能看見家族的尊嚴與家族的虛假，而且不必為任何一方辯護。**

## 後果

| 年份 | 影響 |
|------|------|
| 1901 | 《布登勃洛克》問世即成暢銷書，二十世紀德語長篇小說的敘事典範由此確立。 |
| 1909–26 | 《皇家殿下》《威尼斯之死》《魔山》《馬利歐與魔術家》相繼問世，「小說家的小說」（Künstlerroman）一脈由他打通。 |
| 1929 | 諾貝爾文學獎史上第一次以「某一部小說」為單一主要理由獲獎；委員會在演說中特別稱許《布登勃洛克》。 |
| 1930–32 | 以獎金在尼達建屋並寫作《約瑟夫與他的兄弟們》，把諾貝爾獎的實際收益轉成寫作基地。 |
| 1933 | 因拒絕在納粹時代保持沉默而流亡，慕尼黑住處被搜查、房產被扣押、並被發出逮捕令；從此被視為流亡文學的代表性作家。 |
| 1933–43 | 《約瑟夫與他的兄弟們》四卷本出版，他以聖經敘事的結構重寫西亞的歷史，成為二十世紀歷史小說的高峰之一。 |
| 1944 | 《日瓦爾醫生》出版，成為德語小說中對音樂家與德國病的最著名文本之一。 |
| 1950–51 | 與愛因斯坦等人在日內瓦倡議「人民世界大會」，續寫流亡文學的政治面向。 |
| 1955 | 8 月 12 日逝於蘇黎世；在他返鄉之後，人們重新評價《布登勃洛克》的自傳性與它的文學史地位。 |
| 20 世紀後期 | 《布登勃洛克》被譽為二十世紀最常被翻譯的德語長篇之一，並在文學史教科書中成為「家族小說」的範本。 |
