# 1904 · 埃切加雷與米斯特拉爾：一屆之內，文學的地理被重新定義

> 1904 諾貝爾文學獎：荷塞・埃切加雷（José Echegaray y Eizaguirre，1832–1916，西班牙）與弗雷德里克・米斯特拉爾（Frédéric Mistral，1830–1914，法國）——前者表彰「以獨特而嶄新的方式復興西班牙戲劇偉大傳統的眾多傑出作品」，後者表彰「其詩作的新鮮原創與真正的靈感，忠實反映其人民的大自然景色與本土精神，以及他作為普羅旺斯語學者的重要工作」。【案發現場：同一座頒獎台，一邊是橋樑工程師在算劇情的力矩，一邊是方言學家在編字典；兇手不是人，是兩種把「地方」推上世界的方法。】

## 懸案（案情提要）

1904 年的頒獎現場有兩個被告。頭一個手裡拿的不是筆，是測量儀：荷塞・埃切加雷是西班牙最傑出的土木工程師之一，在「道路、運河與港口工程學院」以第一名畢業，1854 年起教數學、射影幾何與水力學，寫過《分析幾何問題》（1865），並在共和政體下擔過教育、公共工程與財政三任部長。他真正的犯罪是：把工程思維裝進劇本。代表作《El gran Galeoto》（《大加萊托》，1881）讓一則無根據的風流謠言活活拆散一個家庭——兇手是一個送信僕人與整座小鎮的集體意識，沒有一個人可以被定罪。

第二個被告更奇特：弗雷德里克・米斯特拉爾是普羅旺斯富裕農家的兒子，卻在 1854 年與老師魯馬尼耶等七人創立「費利布里」（Félibrige），要讓普羅旺斯語重新成為「文明歐洲的第一文學語言」。他的《Mirèio》（1859）用十二支歌謠寫一個貧窮籃筐匠與地主女兒的婚事，被拉馬丁讚為「我們時代真正的荷馬」，後由古諾改編成歌劇；他編的《費利布里的寶藏》（1878–86）至今仍是奧克語最完整的辭典。

懸案因此不在於誰寫得好，而在於：**文學獎憑什麼越過國界去承認一個地區的語言？以及一個人憑什麼讓西班牙古典戲劇傳統重新開機？** 這是諾貝爾文學獎史上第一次把獎金平分給兩位背景迥異的作家，也是第一次讓「代表一個民族」與「復興一段傳統」同時成為頒獎理由。

## 調查

**第一步：先量結構，再寫衝突——工程師的劇本。**
埃切加雷的劇是十九世紀末的「問題劇」（drama de tesis）：每一部都設一個道德兩難，觀眾的任務是判斷哪一條職責較高。但技術不在題目，在**力的分佈**——《大加萊托》裡沒有真正的反派，只有一個送信僕人、一封被誤讀的信與一座傳播謠言的小鎮。當年被批評為「過火」的舞台指示，正是他專業的痕跡：替演員精確排定動作與停頓，等於把導演的工作寫進劇本。

**第二步：把「黃金時代」重新接上電。**
埃切加雷要接的是卡尔德隆與洛佩・德・維加的傳統，接法不是考古，而是把「家族榮譽、社會體面、女性的沉默」三個變數放進現代布爾喬亞的舞臺：《La duda》（1898）處理教權與良心的摩擦，《兩個職責的衝突》（1882）讓一位總督在「對君主的忠」與「對正義的忠」之間被撕開。頒獎理由中的「復興西班牙戲劇偉大傳統」，指的就是這條接線。

**第三步：把方言寫成有詞典的文學語言。**
米斯特拉爾的做法是工程式的：先造工具，再寫作品。《費利布里的寶藏》（1878–86）是奧克語—法語雙語辭典，收羅各種奧克語方言，定義精確，被視為最可靠的語言學工具之一；《Mirèio》詩前還附了一段「普羅旺斯語發音小告示」。更關鍵的是《羅訥河之歌》（1897）：這條河既是地理也是歷史，沿途是腓尼基人、羅馬人、中世紀自由城邦與卡馬格人的後裔——他讓「地方」成為連續的主體，而不是一堆風光。

**第四步：處理獎金去向。**
米斯特拉爾把一半獎金全數投入阿爾勒的「Museon Arlaten」（阿爾拉坦博物館，收藏普羅旺斯民間家具、服飾與農具），並獲法國榮譽勳章——這枚勳章通常只頒給在國家層面有貢獻的人，他的貢獻卻是區域性的，本身就是沒有前例的案子。

## 技藝裁決

**裁決一：把衝突當成可計算的結構。** 埃切加雷帶進劇本的是工程師的問題意識：給定材料（聲譽、良心、家庭），求解（誰該退讓）。劇情因此不是情緒堆積，而是一連串必然的後果。這套「無反派但有必然性」的寫法，是十九世紀末西班牙戲劇最重要的技術遺產。

**裁決二：集體可以當主角。** 《大加萊托》的兇手是一個群體：僕人、茶館、鄰居的竊語。它把鄉鎮社會寫成一台集體發言的機器，日後的群像劇譜系都能從這裡找到源頭。

**裁決三：先造工具，再造文學。** 文學革命往往先是一場語言工程：詞典、發音規範、文法與詩體互相加固，最後才讓一個地區的語言取得「文學語言」的資格。這條路後來被威爾斯語、近代希臘語等運動接力。

**裁決四：一屆之內，兩種尺度共存。** 埃切加雷向內回收（西班牙戲劇的傳統），米斯特拉爾向外推進（一個地區的語言地圖）。同一年把兩種尺度寫進理由，等於宣告文學獎可以同時是「傳統的復興」與「地圖的重繪」。

## 後果

| 年份 | 影響 |
|------|------|
| 1904 | 諾貝爾文學獎史上第一次由兩位得主平分獎金，並首次把「語言學研究」寫入頒獎理由，確立文學獎可涵蓋非虛構的語文學成就。 |
| 1909 | 拉格洛夫獲獎時，瑞典學院仍以「忠實反映其人民的大自然景色與本土精神」的語彙評價她——1904 年為地方文學打開的口子一直沒有關上。 |
| 1922 | 貝納文特以「愉快的方式延續西班牙戲劇的光榮傳統」獲獎，等於是埃切加雷路線的官方續集。 |
| 1945 | 智利詩人加夫列拉・米斯特拉爾獲獎——與 1904 年得主同名而不同人，諾貝爾史上著名的「同名案」。 |
| 1957 | 普羅旺斯語被正式納入法國與歐洲的語言法制，《費利布里的寶藏》成為語言復權運動的標準文獻。 |
| 20 世紀後期 | 西班牙學界重新評價埃切加雷：舞台指示不再被視為「過火」的瑕疵，而被當成導演制的先驅。 |
