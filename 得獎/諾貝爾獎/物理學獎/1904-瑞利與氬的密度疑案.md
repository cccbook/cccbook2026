# 1904 · 瑞利與氬：小數點後第三位捉到的懶惰氣體

> 1904 諾貝爾物理學獎：約翰·威廉·斯特拉特（第三代瑞利男爵，John William Strutt, 3rd Baron Rayleigh, 1842–1919，英國）——表彰「他對最重要氣體之密度的研究，以及在此研究中發現氬」（for his investigations of the densities of the most important gases and for his discovery of argon in connection with these studies）。

## 懸案（案情提要）

這樁案子的起點小到可笑：**氮氣的密度，在小數點後第三位對不上。**

1892 年，瑞利在為《大英百科全書》撰寫氣體密度條目時，把自家十年積累的數據翻出來複核。同一種「氮氣」，兩種來源，密度卻差了一點：

- 從**空氣**中製得（除盡氧氣與二氧化碳）：約 $1.2572\,\mathrm{g/L}$；
- 從**化學品**製得（氨、亞硝酸銨分解）：約 $1.2505\,\mathrm{g/L}$。

相對差約千分之五。以當時的量氣技術，這不是誤差——瑞利的稱量可重複到萬分之一量級。他試遍所有該試的藉口：溫度、濕度、管壁吸附、雜質、漏氣——一一排除。只剩一個無法迴避的結論方向：**空氣來的氮氣裡，混著某種比氮更重的東西。**

更玄的是，這不是新案。卷宗裡躺著一份 1785 年的老檔：卡文迪許（Henry Cavendish）當年以電火花讓空氣中的氮氧結合成亞硝酸再吸收掉，發現最後總剩下一個約佔空氣百分之一的「頑固小氣泡」，怎麼打火也打不掉。他如實記錄了，卻無從解釋。一百零九年前的一粒氣泡，和 1892 年的一個小數位，指向同一個兇手——一種在空氣裡藏了億萬年、卻從未與任何東西起反應的元素。

| 年份 | 事件 |

| 1840s–1880s | 雷尼奥（Regnault）等建立精密氣體密度測量傳統；各實驗室的氮密度數據長年彼此不一，被當作「儀器脾氣」擱置。 |
| 1871–1879 | 瑞利接任劍橋卡文迪許實驗室首任教授，把「用天平與溫度計追問物性」做成一門精密科學。 |
| 1879 | 瑞利辭去卡文迪許職務，在自家泰雷爾斯莊園建私人實驗室，繼續氣體密度計劃——本案的主戰場就在莊園裡。 |
| 1882 | 瑞利在演講中指出：以氫為基準，氧與氮的密度從不同實驗來看一致性差，值得重測。 |

| 1894-04 | 瑞利在皇家學會報告此差異；化學家拉姆齊（William Ramsay）讀到後毛遂自薦加入偵查——物理與化學雙偵探並案。 |

## 調查

**第一階段：排除所有「測量冤案」。** 瑞利的偵查從自我懷疑開始。他用兩種完全獨立的路徑重測：(1) 熱銅除氧法（空氣通過灼熱銅屑，氧被吃掉）；(2) 火花放電法（氮氧結合為亞硝酸，以鹼液吸收）。兩條路徑製出的「空氣氮」密度一致地偏重；而化學氮（氨氧化、亞硝酸銨分解、尿素分解）一致地偏輕。誤差假說全部陣亡——差異是真实的。

**第二階段：密度差變大。** 瑞利與拉姆齊發現：若把「空氣氮」通過灼熱鎂（鎂與氮反應生成氮化鎂），氣體會**不斷變重、變少**——氮被吃掉後，剩下的殘餘氣體密度越來越高。這是決定性的偵查動作：他們不是在找雜質，而是在**提純一個未知氣體**。殘餘氣體佔原空氣約百分之一——正好對上卡文迪許 1785 年那顆氣泡的口供。老案併案成功。

**第三階段：嫌疑犯的畫像。** 對新氣體做全面體檢：

| 檢查項目 | 結果 |
|----------|------|
| 光譜 | 一組全新譜線，特別是紅色與綠色區的強線——地球上從未見過的元素指紋 |
| 化學反應性 | 與鎂、與電火花、與一切試劑皆不反應——「懶惰」 |
| 密度 | 約 $1.782\,\mathrm{g/L}$，比氮重（$1.251\,\mathrm{g/L}$）約四成 |
| 原子量 | 以 $1.29$ 倍氮氣計，約 $40$——與任何已知元素週期表位置對不上 |

1894 年 8 月 13 日，英國科學促進會年會上，瑞利與拉姆齊聯合宣布新元素，命名 **argon**（希臘語「懶惰者」）。

**第四階段：為它定「性」。** 當時最尖銳的質疑是：$40$ 的原子量在門捷列夫週期表裡沒有位置（氯 $35.5$ 與鉀 $39$ 之間本無縫隙）。瑞利與拉姆齊搬出物理武器——**絕熱指數**。氣體的定壓比熱與定容比熱之比

$$\gamma = \frac{C_p}{C_V}$$

由分子自由度決定：雙原子分子（如氮）理論值 $\gamma = 7/5 = 1.4$，單原子分子 $\gamma = 5/3 \approx 1.667$。測氬的聲速與絕熱膨脹，得 $\gamma \approx 1.66$——**氬是單原子氣體**。單原子、化學惰性、原子量 $40$：這不是「氮的同素異形體」，而是一整族未知元素的開端。1895 年拉姆齊又從釔鈾礦加熱中放出同樣惰性的氣體——太陽光譜裡 1868 年那條未知黃線的元兇**氦**，在地球上現身。到 1898 年，氖、氪、氙相繼落網，週期表被塞進了整整一族（第 18 族）。

## 理論裁決

**裁決一：密度差是化學的，不是物理的。** 依氣體動理論，理想氣體的密度由分子數與分子質量決定：

$$pV = Nk_B T \quad \Longleftrightarrow \quad \rho = \frac{p\,M}{R\,T}$$

同溫同壓下密度只看莫耳質量 $M$。「空氣氮」的表觀莫耳質量是混合物的加權平均：

$$M_{\text{表觀}} = x_{\mathrm{N_2}}\,M_{\mathrm{N_2}} + x_{\mathrm{Ar}}\,M_{\mathrm{Ar}}$$

空氣體積含氬約 $x_{\mathrm{Ar}} \approx 0.0093$，代入 $M_{\mathrm{N_2}} = 28.0$、$M_{\mathrm{Ar}} = 39.9$：

$$M_{\text{表觀}} \approx 0.9907 \times 28.0 + 0.0093 \times 39.9 \approx 28.13$$

即比純氮重約 $0.5\%$——**與實測密度差定量吻合**。千分之五的謎團，由「空氣裡有百分之一的氬」一次算清。這份裁決的高明處在於：物理測量（密度）破案，化學推理（提純）定罪，理論計算（混合律）結案，三種證據鏈閉合。

**裁決二：氬是單原子的。** 絕熱過程滿足

$$pV^{\gamma} = \text{常數}, \qquad \gamma = \frac{C_p}{C_V}$$

能量均分定理給出：$f$ 個自由度的分子 $C_V = \frac{f}{2}R$，$C_p = C_V + R$。單原子 $f = 3$：

$$\gamma = \frac{5}{3} \approx 1.667$$

雙原子 $f = 5$（加轉動兩自由度）：$\gamma = 7/5 = 1.4$。實測氬 $\gamma = 1.66$ 直指 $f = 3$——氬分子就是一顆原子。這也立即解釋了它的化學惰性：滿殼層的電子組態（$3s^2 3p^6$）無可分享、無可奪取——這份電子層面的解釋要等波耳-包立時代補全，但 1895 年的物理學家已憑 $\gamma$ 值與惰性正確畫出嫌犯輪廓。

**裁決三：週期表要有新的一族。** 氬（$40$）、氦（$4$）與後來的氖（$20$）、氪（$84$）、氙（$131$）構成原子量間隔規整的一列，全族零價。門捷列夫週期表在 1894–1898 年間被迫增補第 18 族——一個由物理學家的天平逼出來的家族。

## 後果

| 年份 | 影響 |
|------|------|
| 1895–1898 | 氦、氖、氪、氙接連被拉姆齊等捕獲，惰性氣體族成形；拉姆齊獲 1904 年化學獎——同一年、同一案、兩座獎。 |
| 1898 | 拉姆齊與特拉弗斯用新發現的分餾法從液化空氣中取得氖氪氙；低溫物理（昂內斯，1913 年檔案）接棒。 |
| 1902 | 盧瑟福-索迪蛻變理論問世後，氦被確認是 $\alpha$ 蛻變的產物（$\alpha$ 粒子即 $^4\mathrm{He}$ 核）——氬與氦成為地球「氦庫」的來源解釋。 |
| 1904 | 瑞利獲物理學獎、拉姆齊獲化學獎：諾獎史上唯一一次同一發現雙科學類同屆授獎。 |
| 1905–1913 | 精密氣體密度與氣體常數 $R$ 的測定（包括後來杜瓦的液化氫氦），統計力學獲得最乾淨的宏觀檢驗場。 |
| 20 世紀 | 氬成為白熾燈填充氣與電弧焊保護氣；氖成就霓虹燈；氦成為低溫物理與磁共振成像的戰略資源。 |
| 現代 | 大氣氬的同位素比 $^{40}\mathrm{Ar}/^{36}\mathrm{Ar}$ 成為地質 K-Ar 定年法的核心：$^{40}\mathrm{K}$ 電子捕獲生成 $^{40}\mathrm{Ar}$。 |
