# 1915 · 布拉格父子：把晶體變成一把尺子

> 1915 諾貝爾物理學獎：威廉·亨利·布拉格（William Henry Bragg, 1862–1942，英國）與威廉·勞倫斯·布拉格（William Lawrence Bragg, 1890–1971，英國）——表彰「他們以X射線研究晶體結構所付出的努力」（For their services in the analysis of crystal structure by means of X-rays）。

## 懸案（案情提要）

1912 年 7 月，一則消息從德國慕尼黑傳到劍橋：馬克斯·馮·勞厄發現了晶體中 X 射線的繞射。消息被送到了威廉·亨利·布拉格手上——他是劍橋的一門非正課課程「X 射線的物理學」的授課者，當時正在撰寫《X 射線的 crystallography》相關教材。

布拉格的第一反應不是驚喜，而是懷疑。他的兒子威廉·勞倫斯·布拉格（當時 21 歲，本科剛畢業，後來在戰時是皇家海軍的無線電工程師）正在做博士論文，題目與 X 射線在晶體中的散射有關。父親給了他一個明確的指令：**去做「用 X 射線量測晶體結構」的實驗，去檢驗勞厄的結果**。

布拉格父子在兩週內得到了一個驚人的結果：他們發現，X 射線的波長（此前只能粗估）可以從晶體的反射角精確算出來。這意味著**晶體結構與 X 射線波長可以被「互鎖」地測量**——這就是 X 射線結構分析的原理。

接著是一個更深的謎。1912 年到 1913 年間，X 射線的物理本質仍未定論（德布羅意 1924 年才提出電子與光都具有波動性，而 X 射線是波這件事也尚未有絕對證明）。布拉格父子在 1912 年底的論文中提出一個大膽的解釋：**「X 射線可能不是粒子，而是波」**——他們使用「波」的語言寫下了著名的布拉格定律。

1913 年 1 月，布拉格父子發表論文，指出 X 射線的反射可以由一個簡單的整數關係描述：

$$n\lambda = 2d\sin\theta$$

1913 年 7 月，他們發表《晶體結構分析》的奠基論文，用這個定律測出鈉的雙波長 X 射線，並給出 NaCl 的立方結構——**電子的 X 射線繞射圖譜第一次被反演成原子的位置**。

這樁案子裡的「懸案」其實是兩個交錯的問題：

1. **X 射線是什麼？**（粒子？波？）——布拉格父子是第一批把「波」寫進 X 射線定律的人，而且用這個「波」成功預測了許多新現象。
2. **晶體裡的原子怎麼排？**——這個問題一旦能用 X 射線回答，整個結晶學、礦物學、材料科學、生物化學都會被改寫。

而「父親與兒子」這組搭檔，在諾貝爾獎史上留下了一個著名的註腳：**小布拉格是史上最年輕的諾貝爾科學獎得主（25 歲）**；而且他是繼托馬斯・楊（Thomas Young, 1801 年光學卷）與拉夫（Ralf）之後，自然科學獎中年齡最小的得主之一。他後來也獲得 1971 年諾貝爾化學獎（晶體學方法），是少數獲諾獎兩科的人。

## 調查

**第一件證物：為什麼「兩週內」的結果如此乾淨。** 布拉格父子用的是勞厄的路線的**反轉**：不是用已知波長的 X 射線去測晶體，而是**用晶體去測波長**。這是一個「循環」的量測，但循環能閉合，是因為兩者之間存在整數倍的布拉格條件。具體步驟：

1. 用岩鹽（NaCl）的已知結構（面心立方，$a \approx 0.564\,\mathrm{nm}$）作為標尺；
2. 對 $\mathrm{NaCl}$、$\mathrm{KCl}$、$\mathrm{MgO}$、$\mathrm{LiF}$ 等一系列樣品測反射角；
3. 發現所有數據點都落在一條線上——這條線就是「$n\lambda$ 對 $\sin\theta$」的線性關係。

布拉格定律的物理圖景非常直觀：晶體中有一族平行平面（面間距 $d$），X 射線以掠角 $\theta$ 入射。從相鄰兩平面反射的兩束波，光程差為 $2d\sin\theta$。要相長干涉，必須：

$$n\lambda = 2d\sin\theta, \qquad n = 1, 2, 3, \dots$$

這個式子把「布拉格角 $\theta_B$」與「反射級次 $n$」結合起來。實際測量中用的是「有限晶體的反射寬度」來區分級次：晶片越厚，$2\theta$ 展寬越窄，不同級次的峰就分得開。

**第二件證物：X 射線是波還是粒子。** 這是布拉格父子最重要的理論功勞。他們在 1912–1913 年的論文中明確主張 X 射線是波，並給出了三項「波的證據」：

- **布拉格定律本身**具有波的干涉結構特徵（整數級次）；
- **光的強度隨散射角衰減**符合電磁波的散射行為（Thomson 散射公式 $I \propto I_0\left(1 + \cos^2\theta\right)/2$）；
- **晶體的反射是「整個晶格」共同作用**的結果，單個原子的散射振幅太小，只有疊加才能產生可觀訊號——這正是德拜-謝爾散射。

然而布拉格父子的「波」論證有一個歷史性的尷尬：他們的公式與德布羅意 1924 年的電子波長公式 $\lambda = h/p$ 極為相似，但布拉格當時**並不知道**德布羅意的工作（德布羅意的論文 1924 年才發表），他們只是從實驗歸納出這個形式。1937 年戴維孫的電子繞射實驗最終證實了德布羅意的公式，而布拉格定律在電子繞射中原封不動地成立——這是物理學中「同構原理」的一個絕佳案例。

**第三件證物：NaCl 結構的解出——但差了一個係數。** 1913 年，布拉格父子用 X 射線分析 NaCl，得出的結果是「Na 與 Cl 交替排列於立方格子中，Cl–Cl 距離 $a = 0.564\,\mathrm{nm}$」。但他們的模型是**簡單立方**（Na 與 Cl 各佔一半位置，構成 NaCl 型），而現代認為 NaCl 結構是**面心立方**：$\mathrm{Cl}^-$ 組成面心立方格子，$\mathrm{Na}^+$ 佔所有八面體空隙。這個「差一個係數」的錯誤在物理上無關緊要（原子位置相同），但在**結構因子的取捨**上重要：面心立方結構因子為

$$F_{hkl} = f\left[1 + e^{i\pi(h+k)} + e^{i\pi(h+l)} + e^{i\pi(k+l)}\right]$$

只有當 $h,k,l$ 全為奇數或全為偶數時不消光；而 $h,k,l$ 奇偶混合時 $F = 0$。布拉格早期用的是「岩鹽 = 簡單立方 + 交替」，在實際解出的反射清單裡確實觀察到 $h+k$ 奇偶的消光規律，後來才被整理成面心立方的正確描述。

**第四件證物：原子序與 X 射線波長的關係。** 布拉格在 1913 年注意到：**由化學原子量計算的「原子序」與 X 射線反射強度有系統性關係**。這是莫塞萊定律的 precursor。1913 年底，亨利·莫塞萊（Henry Moseley）在拉姆齊的實驗室裡（正好在 1904 年諾獎得主的機構）系統測量各元素的 K 吸收邊頻率，得到：

$$\sqrt{\nu} = a(Z - b), \qquad a \approx 3.29\times 10^{15}\,\mathrm{s}^{-1/2}, \quad b \approx 1$$

（$a$ 為 Screening 常數約 1，$b$ 為屏蔽修正。）這個線性關係是**原子序 $Z$ 第一次被定義為一個物理量**，並允許預測尚未發現的元素——莫塞萊用此法在 1913–1914 年間確認了鎵、鉭、鈾等的存在。1914 年莫塞萊在加里波利戰役中陣亡（1918 年諾貝爾化學獎頒給他的同事，表彰「原子序的建立」）。

**第五件證物：W. L. 布拉格後來把 X 射線帶進生物學。** 1938 年起，小布拉格在 Cavendish 與 Perutz、Kendrew 合作研究血紅素與肌紅蛋白。他們用了兩種方法：**等強度傅立葉法**（isomorphous replacement 的前身）與 Patterson 函數法。到 1958 年 Kendrew 終於解出肌紅蛋白的原子結構（1962 年化學獎），開啟了結構生物學；而 1953 年 4 月，弗朗西絲·克里克在劍橋把富蘭克林（Rosalind Franklin）與古爾達（Raymond Gosling）的 DNA 衍射「照片 51」拿給沃森（James Watson）看，照片裡那個著名的「X 形」——正是布拉格定律在生物大分子上的頂級表現。

## 理論裁決

**裁決一：布拉格定律的數學形式——一維週期結構的傅立葉條件。** 對一維晶格（原子間距 $d$），散射振幅為

$$A(q) = f \sum_{n=0}^{N-1} e^{i q n d} = f \frac{1 - e^{i q N d}}{1 - e^{i q d}}$$

在 $qd = 2\pi m$（$m$ 為整數）時分母為零，振幅達極大 $Nf$——這就是布拉格條件的群論表述。對三維晶格，條件推廣為 $\mathbf{q} = \mathbf{G}$（倒格子矢量）。布拉格定律 $2d\sin\theta = n\lambda$ 是這個三維條件在**晶面法向與入射方向共平面**時的球面幾何表述。

**裁決二：原子因子 $f_j(q)$ 與 X 射線散射的物理。** 布拉格觀察到「反射強度隨原子序增加」，其背後是**Thomson 散射**：

$$f(\theta) = \int \rho(\mathbf{r})\, e^{i\mathbf{q}\cdot\mathbf{r}}\, d^3r$$

這是原子電子雲的傅立葉變換。在小角度（$q \to 0$）時 $f(0) = Z$（全部電子數）；隨 $q$ 增大，電子雲的雲霧效應（form factor 衰減）使有效散射電子數下降。**這解釋了一個重要事實：X 射線衍射「看不見」氫原子**（$Z=1$，散射弱），所以 1950–60 年代的蛋白質結構中，氫原子是「補」上去的——直到 1990 年代中子衍射（氫的散射長度大）與高解析 X 射線單晶才把氫定位。

**裁決三：X 射線的波長量測——「用晶體量晶體」的循環閉合。** 布拉格定律的實用性在於：只要知道一個晶體的 $d_{hkl}$，就能標定 X 射線波長；只要知道波長，就能測晶體的 $d_{hkl}$。這個循環閉合在實務上藉由「標準樣」（岩鹽、$\mathrm{Si}$、金剛石）打開。而且布拉格律也讓「X 射線管的工作電壓」可以被反推：Duane–Hunt 定律 $eV = h\nu$（1915）給出截止波長 $\lambda_{\min} = hc/eV$。

**裁決四：實驗誤差分析與「級次」的取捨。** 布拉格父子的方法有一個實際難題：$n$ 未知。解決方案有兩種：（a）用同一族不同級次的反射，檢查 $\sin\theta_n$ 是否等間隔；（b）用**粉末連續條紋法**（連續 X 射線的「Kratky」照相機）。第二種方法特別重要，因為它給出了「連續 X 射線譜的自動標定」，成為 1920–30 年代 X 射線晶體學量產化的關鍵。

**裁決五：結構因子與相位的問題——布拉格留下的一個未解難題。** 布拉格公式給出 $F_{hkl}$，但實驗只測 $|F_{hkl}|^2$。相位缺失問題的解決途徑：
- **直接法**：利用「強反射的相位關聯」與概率統計（Karle & Hauptman, 1985 年化學獎）；
- **同形置換法**（isomorphous replacement）：加入重原子（如 $\mathrm{Hg}$、$\mathrm{Au}$）製造母體與衍生物，用差分求相位；
- **多波長反常散射**（MAD/SAD）。
這些都是布拉格方程式的「後續補丁」，並在本書的 1953 年 DNA 卷與 1994 年中子散射卷中各自發揮作用。

**裁決六：諾獎史上的「分割裁決」。** 1914 年勞厄、1915 年布拉格父子，同一事實、同一年度、兩個諾獎。這是物理學獎史上著名的「分割」案例（類似 1974 年 J/$\psi$、1980 年 CP 破壞、2018 年雷射的分法）。委員會的處理反映了一個判斷：勞厄的**「發現現象」**（它發生了）與布拉格父子的**「定量律則與結構分析」**（它怎麼發生、如何用它量東西）是不同的貢獻類型。
