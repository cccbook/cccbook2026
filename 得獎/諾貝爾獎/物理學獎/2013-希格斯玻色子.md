# 2013 · 希格斯玻色子：標準模型的最後一名通緝犯

> 2013 諾貝爾物理學獎：恩格勒（François Englert）與希格斯（Peter Higgs），表彰 1964 年希格斯機制之理論預言（布勞特、恩格勒、海根斯同月另有論文；古拉尼克、哈根、基布爾（GHK）同場競技，唯二人在世者依諾委會規則得獎）

## 案情提要

1964 年，電弱理論（見 [1979-電弱統一理論](1979-電弱統一理論.md)）面臨兩難：

- 規範對稱性要求 W、Z 玻色子**無質量**——實驗明明很重。
- 直接修改理論加入質量項，會破壞規範對稱性，理論不可重整、機率不守恆——物理上不合法。

對稱性要求「零質量」，現實偏偏「很重」——必須找到一個**不破壞理論本身、卻打破其對稱表現**的機制。

## 推理：讓對稱性「藏起來」

三組人（英國的希格斯；比利時的布勞特-恩格勒-海根斯；GHK）在 1964 年幾乎同時想到：借鑑固態物理的超導（見 [1911-超導的發現](1911-超導的發現.md)）——

在超導體中，光子進入後獲得「等效質量」（邁斯納效應，磁場被排斥的穿透深度即其倒數），因為庫柏對凝聚提供了一個**有向的基態**：真空不再「空」，而是充滿一個場。

希格斯機制：

- 引入一個複數純量場 φ，其勢能 `V(φ) = μ²φ†φ + λ(φ†φ)²/2`
- 當 μ² < 0，勢能變成「墨西哥帽」：最低點不在原點，而在半徑 v 的圓環上——**真空自發選擇了一個方向**，SU(2)×U(1) 對稱被打破：

`⟨φ⟩ = v/√2, v ≈ 246 GeV`

- 規範玻色子「吃掉」Goldstone 模式獲得質量：`m_W = gv/2 ≈ 80.4 GeV`，`m_Z ≈ 91.2 GeV`；光子因對應未破壞的 U(1) 方向而保持無質量。
- 代價是理論必須殘留一個**實的純量粒子**——希格斯玻色子。費米子質量則由湯川耦合 `m_f = y_f v/√2` 得到。

希格斯本人 1964 年的論文初稿曾被 CERN 期刊退回（被評為與高能物理「無直接關係」），加註改寫後才刊出——歷史最著名的退稿之一。

## 跨世紀的通緝行動

| 年份 | 事件 |
|---|---|
| 1964 | 三組論文發表；翌年希格斯指出應有新粒子 |
| 1972 | 論文開始被大量引用（「Higgs 機制」命名確立） |
| 1984 | W/Z 被發現，質量與機制預言吻合——共犯結構成立，但主犯未到案 |
| 1989–2000 | LEP 在 Z 質量附近排除至 114.4 GeV |
| 2008-09 | LHC 啟用（26.7 km，能量 7→8→13 TeV） |
| 2012-07-04 | ATLAS 與 CMS 同日宣布：m_H ≈ 125 GeV，顯著性 5σ |
| 2013 | 兩實驗確認耦合性質近似純量；恩格勒與希格斯獲諾獎 |

5σ 的意義：`p < 3×10⁻⁷`，即純統計漲落造成假信號的機率約三百萬分之一——諾委會實務上承認「發現」的門檻。

## 理論裁決：為什麼 125 GeV 是謎中謎

- 預言中「質量未知」的部分被 2012 年補上，機制獲驗——標準模型自此**所有預言全部成立**。
- 但 125 GeV 引發新懸案：
  - **Hierarchy problem**：希格斯質量的量子修正 `δm_H² ∼ (Λ²/16π²)`，若新物理尺度 Λ 是普朗克尺度，修正比觀測值大 30 個數量級——需要荒謬的精細微調。
  - **真空穩定性**：以 m_H = 125 GeV 外推，宇宙正處於亞穩態邊緣（壽命遠長於宇宙年齡，暫無需擔心）。
- LHC 之後未發現超對稱等新物理，「自然性」論證受到根本挑戰——本案結案後反而留下更大的懸案。

## 人性註腳

- 命名之爭：1964 年的機制有 6 位作者、3 篇論文；2010 年 Sakurai 獎頒給全部六人，諾委會卻只能頒二（布勞特、海根斯、古拉尼克、哈根、基布爾已逝或依規則排除）。恩格勒公開表示「可惜布勞特不在」。這是諾獎「三人上限」規則最著名的不公案例。
- 希格斯拒用「上帝粒子」一詞——那是出版社為暢銷書起的行銷名（原稿「God-damned particle」被編輯改為 God Particle）。
