# 諾貝爾物理學獎 歷史年表（詳細版）

本書以「推理探案式 wiki」重寫諾貝爾物理學獎（1901–2024）的每一樁「懸案」：把當年物理界卡住的問題寫成懸案，把實驗寫成偵查，把理論寫成裁決。本 README 是全書的歷史年表與檔案索引。

查證基準：維基百科《諾貝爾獎得主列表》與《諾貝爾物理學獎得主列表》（zh-tw）。

## 序幕：獎項的誕生（1833–1900）

| 年份 | 事件 |
|------|------|
| 1833 | 阿爾弗雷德·諾貝爾（Alfred Nobel, 1833–1896）生於瑞典斯德哥爾摩。父親伊曼紐·諾貝爾是工程師，家中後來以火藥與機械製造為業。 |
| 1842 | 諾貝爾舉家遷往俄國聖彼得堡；他接受私人教育，能操多國語言，並愛上文學與化學。 |
| 1850s | 諾貝爾赴巴黎、美國遊學，師從化學家阿斯卡尼奧·索布雷羅，接觸硝化甘油——一種極不穩定的液態炸藥，日後所有故事的引信。 |
| 1864 | 海倫堡工廠爆炸，弟弟埃米爾罹難。瑞典政府一度禁止在城內試驗硝化甘油。 |
| 1867 | 諾貝爾發明「黃色炸藥」（dynamite）：用矽藻土穩定硝化甘油，取得專利。此後又有雷管（1865 年發明的引信改良）與爆膠（1875），事業遍及 20 多國、90 餘座工廠，一生擁有 355 項專利。 |
| 1876 | 貝爾塔·馮·蘇特納短暫擔任諾貝爾的秘書，日後成為著名和平運動者（1905 年和平獎得主），持續與諾貝爾通信，被認為影響了他對和平獎的構想。 |
| 1888 | 兄弟路德維希病逝，法國報紙誤登阿爾弗雷德的訃聞，稱他為「死亡商人」（le marchand de mort）。諾貝爾讀到自己如何被後世記憶，深受震動。 |
| 1895-11-27 | 諾貝爾在巴黎的瑞典-挪威俱樂部簽下著名的第四版遺囑：以遺產（約 3100 萬瑞典克朗）設立基金，利息分為五份，每年頒給「前一年為人類帶來最大福祉」的人：物理、化學、生理或醫學、文學、和平。物理學獎指定由瑞典皇家科學院頒發。 |
| 1896-12-10 | 諾貝爾病逝於義大利聖雷莫。12 月 10 日從此成為每年頒獎日。 |
| 1897–1900 | 遺囑引發家族爭產與瑞典輿論質疑（有人批評「把錢給外國人」）；經律師拉格納·索爾曼與工程師魯道夫·李列克維斯特奔走，瑞典國王最終同意。 |
| 1900-06-29 | 瑞典政府核准《諾貝爾基金會章程》，諾貝爾基金會（Nobel Foundation）正式成立；物理獎評選權交由瑞典皇家科學院組成的諾貝爾物理委員會。 |
| 1901-12-10 | 首屆頒獎在斯德哥爾摩舉行，適逢諾貝爾逝世五週年。物理學獎首位得主為德國的威廉·倫琴（X 射線），獨得獎金 150,782 瑞典克朗（約合今數千萬克朗），並婉拒了為他舉辦的公開演講——低調如他日後在信中自陳。 |

自此，物理學獎成為物理學史的「年度結案報告」：每一張獎狀背後，都是一樁被反覆查證、辯論、最終裁決的科學懸案。

## 1901–1920：經典物理的最後光輝與第一道裂縫

| 年份 | 得主 | 事件／貢獻 |
|------|------|------|
| 1901 | 威廉·倫琴（Wilhelm Conrad Röntgen，德意志帝國） | 發現 X 射線（1895，符茲堡）。首位物理學獎得主；放射學與醫學成像的起點。 |
| 1902 | 亨得里克·洛侖茲（Hendrik A. Lorentz）與彼得·塞曼（Pieter Zeeman）（荷蘭） | 磁場對輻射現象的影響：塞曼效應（1896）。洛侖茲電子論由譜線分裂反推出電子的荷質比 $e/m$，比 J. J. 湯姆森的陰極射線實驗更早觸及電子。 |
| 1903 | 亨利·貝克勒（Henri Becquerel）、皮耶·居禮（Pierre Curie）與瑪麗·居禮（Marie Curie）（法國） | 貝克勒發現鈾鹽的天然放射性（1896）；居禮夫婦提出放射性是原子本身的性質，發現釙（1898）與鐳（1898）。瑪麗·居禮為首位女性諾貝爾獎得主。 |
| 1904 | 約翰·斯特拉特（第三代瑞利男爵，John W. Strutt，英國） | 精密測定氫、氧、氮等氣體密度，發現大氣氮比化學氮重——追查「第三位小數的差」而發現氬（1894，與拉姆齊合作）。 |
| 1905 | 菲利普·萊納德（Philipp Lenard，德意志帝國） | 陰極射線研究：製出「勒納窗」（1892–1894），讓陰極射線穿出放電管，證明其能穿透物質、性質與螢光激發相關。 |
| 1906 | 約瑟夫·湯姆森（J. J. Thomson，英國） | 氣體導電的理論與實驗研究：以電磁偏轉測定陰極射線的荷質比（1897），宣告「電子」存在，原子不再是不可分的最小單位。 |
| 1907 | 阿爾伯特·邁克生（Albert A. Michelson，美國） | 精密光學儀器（邁克生干涉儀）與光譜學、計量學研究：以鎘紅光定義長度標準、精密測定光速 $c$；其 1887 年實驗早已動搖乙太假說。 |
| 1908 | 加布里埃爾·李普曼（Gabriel Lippmann，法國） | 基於駐波干涉的彩色照相術（1891）：感光層內形成 $\lambda/2$ 間距的銀鏡格子，再現自然色彩。 |
| 1909 | 古列爾莫·馬可尼（Guglielmo Marconi，義大利王國）與卡爾·費迪南德·布勞恩（Karl F. Braun，德意志帝國） | 無線電報的發展：馬可尼完成橫越大西洋電報（1901）；布勞恩改良火花電報機與調諧電路，並發明陰極射線管（布勞恩管）。 |
| 1910 | 約翰內斯·凡得瓦（Johannes D. van der Waals，荷蘭） | 氣體與液體的狀態方程（1873）：$(p + a/V^2)(V - b) = RT$，承認分子有體積、分子間有吸引力，打通氣液兩態的界線。 |
| 1911 | 威廉·維因（Wilhelm Wien，德意志帝國） | 熱輻射定律：維因位移定律 $\lambda_{\max} T = \text{常數}$（1893）與維因輻射公式（1896）——後者正是普朗克量子革命的直接前哨。 |
| 1912 | 古斯塔夫·達倫（Nils Gustaf Dalén，瑞典） | 燈塔與浮標用氣體蓄電器自動調節閥（太陽能閥）。工程學的一勝；本人因實驗事故失明，由兄弟代為領獎。 |
| 1913 | 海克·卡末林·昂內斯（Heike Kamerlingh Onnes，荷蘭） | 低溫物理：液化氦（1908，4.2 K），1911 年發現水銀在 4.2 K 附近電阻驟降為零——超導現象。 |
| 1914 | 馬克斯·馮·勞厄（Max von Laue，德意志帝國） | X 射線在晶體中的繞射（1912）：一箭雙鵰，證明 X 射線是波長極短的電磁波、晶體是原子規則排列的格子。 |
| 1915 | 威廉·亨利·布拉格與威廉·勞倫斯·布拉格（英國） | X 射線晶體結構分析：布拉格定律 $2d\sin\theta = n\lambda$（1913）。小布拉格時年 25 歲，至今仍是最年輕的科學類諾獎得主。 |
| 1916 | —（從缺） | 第一次世界大戰，未頒獎。 |
| 1917 | 查爾斯·巴克拉（Charles G. Barkla，英國） | 元素的特徵 X 射線（K、L 系輻射，1906–1911）：每一種元素都有自己的 X 射線「指紋」。（本獎延至 1918 年頒發。） |
| 1918 | 馬克斯·普朗克（Max Planck，德意志帝國） | 能量量子的發現（1900）：$E = h\nu$，為解黑體輻射難題拋出的「絕望之舉」，開啟量子物理。（本獎延至 1919 年頒發。） |
| 1919 | 約翰尼斯·斯塔克（Johannes Stark，德國） | 陽極射線（極隧射線）的都卜勒效應（1905）與電場中的譜線分裂——斯塔克效應（1913），波耳理論的又一次勝利。（本獎延至 1920 年頒發。） |
| 1920 | 夏爾·紀堯姆（Charles É. Guillaume，瑞士） | 鎳鋼合金反常膨脹研究，發明幾乎不隨溫度伸縮的「不變鋼」（Invar），奠定精密測量與大地測量的量具基礎。 |

## 1921–1940：量子革命與原子核的現身

| 年份 | 得主 | 事件／貢獻 |
|------|------|------|
| 1921 | 阿爾伯特·愛因斯坦（Albert Einstein，德國/瑞士） | 對理論物理的貢獻，特別是光電效應定律（1905 光量子假說 $E = h\nu$）。相對論未能單獨得獎，評審以「無爭議」的電子量子成就授獎。（本獎延至 1922 年頒發。） |
| 1922 | 尼爾斯·波耳（Niels Bohr，丹麥） | 原子結構與原子輻射的研究（1913 半量子化軌道模型，$E_n = -13.6\,\text{eV}/n^2$），譜線之謎的第一次系統性裁決。（本獎延至 1923 年頒發。） |
| 1923 | 羅伯特·密立根（Robert A. Millikan，美國） | 油滴實驗測定基本電荷 $e$（1909–1913）與光電效應的精密驗證（1916，測出普朗克常數 $h$）。 |
| 1924 | 曼內·西格巴恩（Manne Siegbahn，瑞典） | X 射線光譜學：精密測定各元素的 X 射線譜線，為原子結構理論提供最精確的「筆錄」。 |
| 1925 | 詹姆斯·法蘭克（James Franck）與古斯塔夫·赫茲（Gustav Hertz）（德國） | 法蘭克-赫茲實驗（1914）：電子撞擊水銀原子，能量以 4.9 eV 為單位被整份吸收——原子能階量子化的直接鐵證。 |
| 1926 | 讓·佩蘭（Jean Perrin，法國） | 布朗運動的定量研究（1908–1909）：以愛因斯坦 1905 年理論對照實驗，數出「原子」的個數，亞佛加厥常數浮出水面，原子論獲得終審。 |
| 1927 | 阿瑟·康普頓（Arthur H. Compton，美國）與查爾斯·威爾遜（Charles T. R. Wilson，英國） | 康普頓效應（1923）：X 射線光子與電子如撞球般碰撞，$\Delta\lambda = (h/mc)(1-\cos\theta)$，證實光量子有動量；威爾遜發明雲霧室（1911），讓帶電粒子自己留下「口供」。 |
| 1928 | 歐文·理查森（Owen W. Richardson，英國） | 熱電子發射定律（1901 起）：$J = A T^2 e^{-W/kT}$，燈絲放射電子背後的指數律。 |
| 1929 | 路易·德布羅意（Louis-Victor de Broglie，法國） | 電子的波動性（1924 物質波假說 $\lambda = h/p$）：把波粒二象性從光推廣到一切物質。 |
| 1930 | 錢德拉塞卡拉·拉曼（C. V. Raman，英屬印度） | 拉曼效應（1928）：光被分子散射後出現頻移，$\nu_{\text{散射}} = \nu_0 \pm \nu_{\text{振動}}$，分子的振動指紋學。 |
| 1931 | —（從缺） | 未頒獎（缺乏適當提名人選，獎金撥回基金）。 |
| 1932 | 維爾納·海森堡（Werner Heisenberg，德國） | 創立量子力學（1925 矩陣力學）與測不準原理（1927）：$\Delta x\,\Delta p \ge \hbar/2$。（本獎延至 1933 年頒發。） |
| 1933 | 埃爾文·薛丁格（Erwin Schrödinger，奧地利）與保羅·狄拉克（Paul A. M. Dirac，英國） | 原子理論的新形式：薛丁格波動方程（1926）與狄拉克相對論性電子方程（1928，預言正電子）。（本獎延至 1934 年頒發。） |
| 1934 | —（從缺） | 未頒獎。 |
| 1935 | 詹姆斯·查德威克（James Chadwick，英國） | 發現中子（1932）：解開原子核質量與電荷不符之謎，並為核分裂備好彈藥。 |
| 1936 | 維克托·赫斯（Victor Hess，奧地利）與卡爾·安德森（Carl D. Anderson，美國） | 赫斯乘氣球發現宇宙輻射（1912，輻射隨高度增強）；安德森在雲霧室中發現正電子（1932）——狄拉克方程的實體化。 |
| 1937 | 柯林頓·戴維孫（Clinton Davisson，美國）與喬治·湯姆森（George P. Thomson，英國） | 電子在鎳晶體（1927）與金屬薄膜上（1927）的繞射：電子繞射環證實 $\lambda = h/p$，父子兩代一個證明電子是粒子、一個證明電子是波。 |
| 1938 | 恩里科·費米（Enrico Fermi，義大利王國） | 中子轟擊產生新放射性元素（1934 起）與慢中子效應：石蠟使中子減速、反應率暴增，核能時代的鑰匙。 |
| 1939 | 歐尼斯特·勞倫斯（Ernest O. Lawrence，美國） | 迴旋加速器的發明與改進（1930–1932）：磁場回旋、電場反覆加速，$\omega = qB/m$，把粒子「拳擊」到百萬電子伏。 |
| 1940–1942 | —（從缺） | 第二次世界大戰，連續三年未頒獎。 |

## 1943–1970：從原子核到粒子動物園

| 年份 | 得主 | 事件／貢獻 |
|------|------|------|
| 1943 | 奧托·斯特恩（Otto Stern，美國） | 分子束方法的發展與質子磁矩的發現（1933，斯特恩-蓋拉赫實驗 1922 已為量子化空間取向留證）。（本獎延至 1944 年頒發。） |
| 1944 | 伊西多·拉比（Isidor I. Rabi，美國） | 原子核磁性的共振記錄法（核磁共振，1938）：$\omega = \gamma B_0$，原子核的「指紋比對」。 |
| 1945 | 沃夫岡·包立（Wolfgang Pauli，奧地利） | 不相容原理（1925）：同一量子態不容兩個電子，元素週期表的隱形法典。（本獎延至 1946 年頒發。） |
| 1946 | 珀西·布里奇曼（Percy W. Bridgman，美國） | 超高壓物理的儀器與方法：數十萬大氣壓下的物質新相。 |
| 1947 | 愛德華·阿普爾頓（Edward V. Appleton，英國） | 電離層的探測與「阿普爾頓層」（1924）：電波何以能環繞地球。 |
| 1948 | 派屈克·布萊克特（Patrick M. S. Blackett，英國） | 改良威爾遜雲霧室並以自動計數觸發，宇宙線與核物理的大量發現；也實測證實人工核嬗變。 |
| 1949 | 湯川秀樹（Hideki Yukawa，日本） | 核力的理論：預言質量約 200 倍電子質量的介子（1935），$V(r) \propto e^{-r/\lambda}/r$——日本首位諾貝爾獎得主。 |
| 1950 | 塞西爾·鮑威爾（Cecil F. Powell，英國） | 核乳膠照相法與 $\pi$ 介子的發現（1947，與巴西等高山觀測站合作）。 |
| 1951 | 約翰·考克饒夫（John Cockcroft，英國）與歐尼斯特·沃吞（Ernest Walton，愛爾蘭） | 高壓加速器人工嬗變原子核（1932）：鋰被質子擊碎，$^7\mathrm{Li} + p \to 2\,^4\mathrm{He}$，核能時代的第一次「破門」。 |
| 1952 | 費利克斯·布洛赫（Felix Bloch）與愛德華·珀塞爾（Edward M. Purcell）（美國） | 核磁共振精密測量（1946）：拉比方法的固體版，日後成為 MRI 的基石。 |
| 1953 | 弗里茨·塞爾尼克（Frits Zernike，荷蘭） | 相襯顯微鏡（1930s）：把看不見的相位差變成看得見的明暗，透明生物標本從此現形。 |
| 1954 | 馬克斯·玻恩（Max Born，英國/西德）與瓦爾特·博特（Walther Bothe，西德） | 玻恩：波函數的統計詮針 $|\psi|^2$ 為機率密度——量子力學的官方釋義；博特：符合法（coincidence method）與核物理發現。（本獎延至 1955 年頒發。） |
| 1955 | 威利斯·蘭姆（Willis Lamb）與波利卡普·庫施（Polykarp Kusch）（美國） | 蘭姆位移（1947）：氫 $2S_{1/2}$ 與 $2P_{1/2}$ 並非簡併——QED 的試金石；庫施：電子磁矩異常 $g \ne 2$。（本獎延至 1956 年頒發。） |
| 1956 | 威廉·肖克利、約翰·巴丁、沃爾特·布喇頓（美國） | 電晶體的發明（1947，貝爾實驗室）：半導體接面放大電流，資訊時代的第一塊基石。 |
| 1957 | 楊振寧與李政道（中華民國） | 宇稱不守恆（1956）：弱交互作用中左右不分並非天理，吳健雄的鈷-60 實驗（1957）執行終審。 |
