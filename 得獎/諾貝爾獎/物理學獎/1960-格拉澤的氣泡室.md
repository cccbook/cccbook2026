# 1960 · 格拉澤：一杯啤酒裡的粒子軌跡

> 1960 諾貝爾物理學獎：唐納德·阿瑟·格拉澤（Donald Arthur Glaser, 1926–2013，美國）——表彰「他發明了氣泡室」（for the invention of the bubble chamber）。

## 懸案（案情提要）

**1952 年，格拉澤（Donald Glaser）在密歇根大學。他的研究課題是：**

**「用高能粒子束研究核反應。」**

**而他的工具是一個令人沮喪的雲霧室（cloud chamber）。**

**讓我們把雲霧室的問題攤開來看——這是本案的全部起點：**

| 問題 | 後果 |
|---|---|
| **擴張機構是機械的** | 每次擴張需要 ~1 秒，**稀有事件的記錄效率極低** |
| **氣體密度太低** | 空氣密度 $\sim 1.2\,\mathrm{kg/m^3}$；高能粒子在 1 米氣體中只能留下 $\sim$ 幾厘米的軌跡 |
| **需要低溫** | 雲室要在 $-20^\circ\mathrm{C}$ 以下工作，且容易結冰 |
| **擴張與粒子通過不同步** | 大部分粒子在「按快門」的瞬間不在 chamber 裡 |

**所以 1952 年的高能物理實驗有個殘酷的限制：**

> **你只能「看見」粒子在低密度氣體中那短得可憐的一段弧線。**
> **而高能粒子的性質（電荷、質量、壽命、產生關聯）幾乎都要靠「長軌跡」才能判定。**

**1952 年 11 月的一個晚上，格拉澤在實驗室裡喝啤酒。**

**他後來的自述（大意）：**

> 「我正拿著一瓶啤酒，注意到瓶子裡的**氣泡**……我突然想到：**如果把一個粒子穿過液體所留下的擾動，能夠以氣泡的形式被看見呢？**」

**這個想法的物理內容是什麼？讓我們把它拆開：**

**（a）** 啤酒是**過飽和的含氣水**——液體處於亞穩態，隨時可能沸騰。
**（b）** 氣泡在液體中形成的條件是「有足夠大的成核核」——**如果沒有一個足夠大的核，液體可以保持過熱而不沸騰**。
**（c）** 一顆帶電粒子穿過液體時，會在軌跡上留下**電離**——**而電離正是完美的成核核！**

**因此：一個粒子穿過過熱液體時，會在軌跡上留下一串氣泡——而這些氣泡可以用光學方法照明、拍照。**

**這個想法的關鍵洞見是「**密度**」：**

| | 雲霧室（氣體） | 氣泡室（液體） |
|---|---|---|
| 介質密度 | 空氣 $1.2\,\mathrm{kg/m^3}$ | **液氫 $71\,\mathrm{kg/m^3}$** |
| 軌跡長度（相同裝置尺寸） | 幾厘米 | **幾米**（約 850 倍！） |
| 密度（粒子/$\mathrm{cm^3}$） | $10^{-6}$ | **$10^{-8}$**（更稀，背景更低） |
| 觸發方式 | 機械擴張（慢） | **壓力瞬時下降（快）** |
| 可用介質 | 空氣 | 液氫、液氦、氖、丙烷、Freon |

**格拉澤在 1952 年底用一個「啤酒瓶 + 闪光灯泡」做出了人類第一個氣泡室——**一個空的玻璃啤酒瓶，裝滿了過熱的**乙醚**，瓶口塞住，當時用一個閃光燈（flashbulb）快速照亮。**

**1952 年 12 月 18 日，他拍下了第一張氣泡室照片：一條由氣泡組成的直線。**

**而 1953–1954 年，在柏克萊建成了第一台「大型」氣泡室（10 升液氫）。**

**然後是爆炸性的收成：**

| 年份 | 發現 | 用的工具 |
|---|---|---|
| 1961 | **$\omega$ 介子**（1961） | 液氫氣泡室 |
| 1961 | **$\eta$ 介子** | 氣泡室 |
| 1964 | **$\rho$ 介子** | 氣泡室 |
| 1964 | **$\Xi^-$ 超子**（1964） | 液氫氣泡室 |
| 1967 | **$\Omega^-$ 介子**（1967） | 液氫氣泡室 |

**這些是「粒子 zoo」時代最重要的發現——而它們全部是在氣泡室裡被「看見」的。**

**本案的核心問題因此是：**

> **「用一杯啤酒，取代整個雲霧室的技術代際。」**
> **它背後的物理是「亞穩態 + 成核理論」——這是一個純粹的物理學問題，而格拉澤的貢獻是把它變成了一台機器。**

## 調查

**第一件證物：成核理論——「液體要多久才會沸騰」。**

**這是全案的物理核心，讓我們完整寫出。**

**第一步：過熱液體的亞穩態。**

**液體在壓力 $P_l$ 下（$P_l > P_v$），其沸點是 $T_b(P_l)$。若把液體冷卻到 $T < T_b(P_l)$，液體進入「過熱（superheated）」的亞穩態——**它的溫度低於該壓力下的沸點。**

**超熱量：**

$$\Delta T = T_b(P_l) - T$$

**第二步：氣泡成核的條件（Young–Laplace 方程）。**

**一個半徑為 $R$ 的氣泡，其內外壓差必須滿足：**

$$P_v - P_l = \frac{2\gamma}{R} \quad\Longrightarrow\quad R = \frac{2\gamma}{P_v - P_l}$$

**其中 $\gamma$ 是液-氣界面的表面張力。**

**這意味著：** 在固定的 $(P_v - P_l)$ 下，**存在一個臨界半徑**

$$\boxed{R_c = \frac{2\gamma}{P_v - P_l}}$$

- **$R > R_c$ 的氣泡會自發膨脹**（因為表面張力的壓力不足以平衡內外壓差）；
- **$R < R_c$ 的氣泡會收縮消失**。

**第三步：成核所需能量（古典成核理論，Farkas 1927）。**

**形成一個臨界氣泡所需的自由能：**

$$W_c = \frac{4\pi R_c^2\gamma}{3}\times 2\quad\text{（表面功 + 體積功）} = \frac{16\pi\gamma^3}{3(P_v-P_l)^2}$$

**成核速率：**

$$\boxed{J = J_0\exp\left(-\frac{W_c}{k_BT}\right)}$$

**讓我們做一個數字檢查（這是全案最重要的一個量）：**

**對液氫（$T = 20\,\mathrm{K}$，$\gamma = 0.0035\,\mathrm{N/m}$）：**

**若過熱量 $\Delta T = 1\,\mathrm{K}$：** 在 $20.4\,\mathrm{K}$ 時，液氫的飽和蒸氣壓 $P_v \approx 1.01\,\mathrm{atm}$；$20\,\mathrm{K}$ 時 $P_v \approx 0.90\,\mathrm{atm}$；施加外壓 $P_l = 1.05\,\mathrm{atm}$：

$$P_v - P_l = -0.15\,\mathrm{atm} \quad\text{（不對，應該取 } P_v(P_l) - P_l \text{）}$$

讓我們改用另一種（更實用的）表述：**在壓力 $P_l$ 下，把液體過熱到 $T$，則有效過壓為**

$$\Delta P = P_v(T) - P_l$$

**對 $\Delta T = 1\,\mathrm{K}$ 的液氫：** $\Delta P \approx 0.1\,\mathrm{atm} = 10^4\,\mathrm{Pa}$。

$$R_c = \frac{2\times0.0035}{10^4} = 7.0\times10^{-7}\,\mathrm{m} = 0.7\,\mu\mathrm{m}$$

$$W_c = \frac{16\pi(0.0035)^3}{3\times(10^4)^2} = \frac{16\pi\times4.29\times10^{-8}}{3\times10^8} = \frac{2.16\times10^{-6}}{3\times10^8} = 7.2\times10^{-15}\,\mathrm{J}$$

$$W_c/k_BT = \frac{7.2\times10^{-15}}{1.381\times10^{-23}\times20} = \frac{7.2\times10^{-15}}{2.762\times10^{-22}} = 2.6\times10^{7}$$

$$\boxed{J \sim J_0\,e^{-2.6\times10^7} \approx 0}$$

**這就是答案：在沒有成核核的情況下，液體可以保持過熱「essentially forever」。**

**第四件證物：離子如何「點燃」氣泡——「成核核的物理」。**

**粒子通過時留下的電離，提供了兩種成核機制：**

**(a) 離子核心（ion core）：** 溶液中留下的自由離子（$\mathrm{H}^+$, $\mathrm{OH}^-$ 等）作為「異質成核核」。它們使局部的表面張力降低，或提供一個半徑 $\sim 1\,\mathrm{nm}$ 的初始氣泡核。

**(b) 粒子本身的能量沉積：** 高能粒子在軌跡上直接沉積能量（$dE/dx$），局域地將液體加熱到沸點。**這是最重要的機制——因為它解釋了為什麼「氣泡密度」正比於 $dE/dx$。**

**第五件證物：氣泡密度的物理——「用氣泡的疏密判別粒子」。**

**這是氣泡室相對於雲霧室的一個關鍵優勢，也是阿爾瓦雷茨能「辨識」粒子的原因。**

**氣泡密度（每單位長度的氣泡數）$n_b$ 正比於比能損：**

$$\boxed{n_b \propto \left\langle\frac{dE}{dx}\right\rangle}$$

**由 Bethe 公式，$\langle dE/dx\rangle \propto z^2/\beta^2$。**

**讓我們做一個實際的比較（液氫中，$z=1$）：**

| 粒子 | $\beta$ | 相對比能損 | 氣泡外觀 |
|---|---|---|---|
| $e^-$（最小電離能） | 慢（$\beta \sim 0.05$） | **極大**（$\propto 1/\beta^2$） | **一條非常密的實線** |
| $\mu$（最小電離能） | 慢 | 極大 | 密的實線 |
| $\pi^\pm$（高能） | $\sim 1$ | 小 | **稀疏的點線** |
| $p$（高能） | $\sim 1$ | 小 | 稀疏 |
| $e^-$（高能） | $\sim 1$ | 小 | 稀疏 |

**因此：在液氫氣泡室中，**「慢而密的線」與「快而稀的點」一眼可辨**——這是阿爾瓦雷茨 1968 年諾獎工作的視覺基礎。**

**第六件證物：「氫氣泡室」——「讓短壽命粒子留下可見軌跡」。**

**問題：$K$ 介子、$\Lambda$ 超子、$\Sigma$ 超子的壽命是 $10^{-10}\,\mathrm{s}$，它們在產生後立刻衰變——但它們的衰變產物（$\pi$ 介子）可以走很長。**

**所以要看到它們，需要：**

1. **在原點看到一個「星」**（母粒子的衰變）；
2. **看到一條從星中伸出的長軌跡**（子粒子）；
3. **子粒子的軌跡必須能與母粒子連結**（即它們在空間上相連）。

**這需要極高的空間解析度（$\sim 0.1$–$1\,\mathrm{mm}$）與極短的曝光時間。**

**「液氫氣泡室」的幾個關鍵設計：**

| 設計 | 理由 |
|---|---|
| **液氫**（$71\,\mathrm{kg/m^3}$） | 高密度 → 軌跡長 → 子粒子能走遠 |
| **低溫**（$20\,\mathrm{K}$） | 液氫的低溫讓過熱狀態容易維持 |
| **瞬間減壓** | 只需把壓力降低 $\sim 0.1\%$ 即可產生過熱態；**減壓只需 $\sim$ 幾毫秒**，足夠「凍結」軌跡 |
| **超導磁體的均勻場** | 讓粒子軌跡成為圓弧（便於測量曲率 $\to$ 動量） |
| **底片/底片 + 掃描系統** | 底片的解析度只有 $\sim 0.1$ mm，而氣泡照片需要 $\sim 0.05$ mm |

**第七件證物：氣泡室的「操作藝術」——「為什麼它是 1960 年代最難用的偵測器」。**

**讓我們寫出操作序列，這是理解 1960 年代粒子物理「手工」氣味的地方：**

```
  1. 快門開啟前 1 秒：磁場建立，束流注入
  2. 快門開啟瞬間：壓力瞬時降低 0.1%（機械或壓電）
  3. ~10 毫秒：氣泡形成並生長到可見大小
  4. 曝光結束（~0.1 秒）：閃光燈或脈衝閃光照明，拍照
  5. 取出底片，沖洗
  6. 用「投影測量儀」逐條掃描底片上的軌跡
```

**第 6 步是真正的瓶頸：**

- 一卷底片有 $\sim 10^4$ 張照片；
- 每張要掃描 $\sim 20$–$100$ 條軌跡；
- **每條軌跡要人工測量 $\sim 50$ 個點**（弧長、曲率、徑跡）；
- 一卷底片 = **數千小時的人工**。

**這就是阿爾瓦雷茨 1968 年諾獎工作的意義所在——他把「掃描」與「分析」自動化了。**

**第八件證物：氣泡室的「衰亡」——「為什麼它在 1980 年代退場」。**

**氣泡室的致命弱點：**

1. **沒有電子學觸發**——你不能「選擇」有趣的事件，必須全部拍下再找；
2. **體積巨大**（一個大型氣泡室重達幾十噸，需要特殊的建築）；
3. **分析耗時**（即使有自動掃描）；
4. **不適合高亮度**（1970 年代的加速器亮度比 1950 年代高數千倍）。

**1970 年代的「線圈室」（drift chamber）與「多絲正比室」（MWPC，1982 諾獎）提供了電子學觸發與數位記錄——氣泡室因此在 1980 年代逐步退役。**

**但氣泡室的物理貢獻遠不亞於它的壽命：它帶來了「粒子 zoo」時代的整個成果。**

## 理論裁決

**裁決一：亞穩態與過熱——「相變的門檻與遲滯」。**

**氣泡室的物理是「相變的亞穩態與遲滯」的教科書案例，讓我們把它寫清楚。**

**相變的兩種典型行為：**

| | 一階相變 | 二階相變 |
|---|---|---|
| 序參量 | 有（潛熱） | 無 |
| 對稱性破缺 | 明確 | 連續 |
| 遲滯 | **有**（亞穩態） | **無**（臨界點唯一） |
| 對數項 | 有 $\ln|t|$ | 有 $\ln|t|$ |

**液體的過熱沸騰是一階相變（液-氣），因此有遲滯與亞穩態。**

**關鍵的物理量是「成核能壘」：**

$$W_c = \frac{16\pi\gamma^3}{3(\Delta P)^2}$$

**讓我們把這個公式的物理讀透——它解釋了氣泡室的每一個設計參數：**

| 設計選擇 | 對 $W_c$ 的影響 | 結果 |
|---|---|---|
| **增大過熱度 $\Delta T$** | $\Delta P$ 增大 | $W_c$ 急劇下降 → 更容易自發成核 → **背景太多** |
| **增大過熱度太 little** | $\Delta P$ 小 | $W_c$ 大 → 即使有離子也難成核 → **看不到軌跡** |
| **降低表面張力 $\gamma$** | $\gamma$ 進立方 | $W_c$ 急劇下降 → 容易成核 |
| **降低溫度 $T$** | $k_BT$ 小 | $J \sim e^{-W_c/k_BT}$ 急劇下降 → **抑制背景** |

**這就解釋了為什麼氣泡室要在低溫下工作：低溫讓「自發成核」被壓到零，但「離子成核」仍然有效。**

**這是一個極其漂亮的「精細平衡」設計。**

**裁決二：為什麼「液體」比「氣體」好——「密度」的物理收益。**

**讓我們把這個核心論證量化，這是氣泡室勝出的全部理由。**

**（一）軌跡長度：**

粒子在介質中的輻射長度（radiation length）$X_0$：

$$\frac{1}{X_0} = \frac{4\alpha r_e^2}{3}\frac{1}{\text{介質的 }Z/A}$$

**輻射長度（以 $\mathrm{g/cm^2}$ 計）與介質的 $Z/A$ 成反比：**

| 介質 | $Z/A$ | $X_0$ ($\mathrm{g/cm^2}$) | 密度 ($\mathrm{g/cm^3}$) | $X_0$ (cm) |
|---|---|---|---|---|
| 空氣 | 0.50 | 36.4 | 0.0012 | **30 000 cm = 300 m** |
| 液氫 | 0.50 | 36.4 | 0.071 | **51 cm** |
| 液氦 | 0.33 | 42.9 | 0.125 | **34 cm** |
| 丙烷 | 0.58 | 29.3 | 0.51 | **57 cm** |
| 銅 | 0.456 | 20.3 | 8.9 | **2.3 cm** |

**（注意：上表中「空氣」的 $X_0$ 以質量厚度計是 36.4 $\mathrm{g/cm^2}$，但因為密度低，實際長度達 300 m——**這是雲雾室軌跡長的真正原因，不是「密度低所以短」！** 讓我們修正這個論證。）

**這裡必須極其小心地修正一個常見的誤解：**

> **在「單位質量厚度」的意義上，氣體與液體的輻射長度相同；但在「單位幾何長度」的意義上，液體的軌跡短得多（51 cm vs 300 m）。**

**那麼為什麼液體仍然更好？因為真正的差別不在「軌跡長度」，而在以下三點：**

**(1) 軌跡「密度」（grain/bubble density）——分辨能力的來源。**

**在氣體中，粒子的電離太稀疏（每厘米只有幾個離子對），軌跡是「點狀的、斷續的」——難以測量曲率。**
**在液體中，電離密度高 1000 倍 → 軌跡是「連續的、稠密的」→ 可以精確測量曲率（也就是動量）。**

**這才是液體的真正優勢：不是「更長」，而是「更密、更連續」。**

**(2) 徑跡（range）——「停在哪裡」。**

**在氣體中，高能粒子常常直接穿出 chamber，無法測量其「射程」。**
**在液體中，由於密度高，粒子會在可測的距離內停下（對 $\mu$ 介子而言約 1 米），因此可以測量射程 $\to$ 能量。**

**這是阿爾瓦雷茨能判定粒子身分（$\pi/\mu/K/p$）的關鍵。**

**(3) 「無需擴張」——操作上的決定性優勢。**

**雲雾室需要「擴張」整個 chamber（機械動作，$\sim 1$ 秒）；氣泡室只需要「減壓」（毫秒級）。這意味著：**

- **記錄效率高得多**（擴張窗口 $\sim$ 幾毫秒 vs 雲雾室的 $\sim 10^{-3}$ 秒有效窗口）；
- **可以用電子學觸發**（1960 年代末的「氣泡室 + 觸發」系統）。

**裁決三：「液氫氣泡室」的物理設計——「三個物理量的最佳化」。**

**讓我們把液氫氣泡室的參數選擇寫成一個「最佳化問題」，這是本卷可以貢獻給全書的一個漂亮案例。**

**液氫的關鍵物性：**

| 參數 | 值 | 意義 |
|---|---|---|
| 沸點（1 atm） | $20.27\,\mathrm{K}$ | 決定工作溫度 |
| 密度 | $71.4\,\mathrm{kg/m^3}$ | 決定電離密度與徑跡 |
| 分子量 | 2 | 決定輻射長度（$Z/A = 0.5$，與空氣相同） |
| 氫的核子數 | 1 | **每個原子只有 1 個質子 → 「無背景」！** |
| 電離能 | 13.6 eV | 決定每個游離對的能量 → 決定最小電離粒子 |
| 電子的最小電離能 | 21.2 eV | **決定「慢電子」的軌跡長度** |

**「無背景」的關鍵優勢：**

**液氫只有一個核子（質子）。因此當一個 $\pi$ 介子或 $\mu$ 介子在液氫中停下時，它產生的「星」只會包含少數幾條分支（因為氫核少）。**

**對比液氫（1 個核子/原子）與液氬（20 個核子/原子）：**
- 在液氫中，一個 $\mu$ 介子停下時產生 $\sim 1$–$2$ 條質子分支 → **乾淨的「單星」**；
- 在液氬中，同樣的 $\mu$ 介子產生 $\sim 10$–$20$ 條分支 → **雜亂的「多星」**。

**因此：液氫氣泡室適合「測量母粒子的質量與壽命」，液氬（重液）氣泡室適合「看高能 $\gamma$ 與中微子散射」。**

**裁決四：本案在諾獎史中的座標——「把一個想法在 20 個月內變成一個領域的工具」。**

**讓我們把這個時間表列出來，這是格拉澤貢獻的最好刻畫：**

| 時間 | 事件 |
|---|---|
| 1952-11 | 「啤酒」的洞見 |
| 1952-12-18 | 第一張氣泡室照片 |
| 1953 | 轉到柏克萊；建成第一台大型液氫氣泡室（10 升） |
| 1954–1956 | 液氫氣泡室遍布 Berkeley、Brookhaven、CERN |
| 1960 | **諾獎頒發** |
| 1961 | $\omega$ 介子、$\eta$ 介子被發現 |
| 1961 | 液氦氣泡室（He II）問世（阿爾瓦雷茨） |
| 1964 | $\rho$ 介子、$\Xi^-$ 超子被發現 |
| 1967 | $\Omega^-$ 介子被發現（Alvarez 團隊，10 GeV 質子束打氫靶） |
| 1968 | **阿爾瓦雷茨獲諾獎**（氫氣泡室 + 自動掃描） |
| 1970s | 電子學偵測器（MWPC、漂移室）崛起，氣泡室退居幕後 |
| 1980s–2000s | 大型氣泡室相繼關閉；**最後一台大型氣泡室（Fermilab 15 ft）於 2008 年關閉** |

**這條時間線極其清楚地說明了一件事：**

> **1952 年的一個想法 → 1967 年的 $\Omega^-$ 介子 → 1968 年的諾獎 → 2008 年的最後一台機器關閉。**
> **一個偵測器技術的生命週期只有 50 多年——但它帶來了 20 個諾獎級的發現。**

## 後果

| 年份 | 影響 |
|---|---|
| 1952-11 | 「啤酒瓶」的洞見；**第一張氣泡室照片**。 |
| 1953–1954 | 第一台大型液氫氣泡室（10 升）。 |
| 1955 | **重液氣泡室**（丙烷、Freon）——中微子實驗的主力。 |
| 1956 | **液氦氣泡室**（He II 超流體）——觀察 $K$、$\Lambda$ 等奇短壽命粒子。 |
| 1958 | 柏克萊的「**10 GeV 加速器**」計畫（Bevatron 的一半）。 |
| **1960** | **諾獎頒發**。 |
| 1961 | **$\omega$ 介子**（Baton Rouge 氣泡室）、**$\eta$ 介子**被發現。 |
| 1964 | **$\rho$ 介子**、**$\Xi^-$ 超子**被發現。 |
| 1967 | **$\Omega^-$ 介子**被發現（Alvarez 團隊；這是「$S=-3$」夸克組合的證據，直接支持夸克模型）。 |
| **1968** | **阿爾瓦雷茨獲諾獎**（氫氣泡室 + 自動資料分析）。 |
| 1960s–70s | 氣泡室照片中的**「V0 粒子」**（$K^0$ 的長壽命態）系統研究 → 弱作用宇稱與 CP 破壞。 |
| 1970s | **「Strangeness」（$S$）** 量子數的引入（1961，蓋爾曼）；$K$ 介子研究。 |
| 1980s | 電子學偵測器取代氣泡室；氣泡室退居「重離子與特殊實驗」的角落。 |
| 2008 | **最後一台大型氣泡室（Fermilab 的 15 呎）關閉**。 |
| 2010s–2020s | 氣泡室的「影像分析」技術被移植到**微流道（microfluidic）氣泡室**——用微流道製造極小體積的過熱液體，做成「微氣泡室」晶片。 |
