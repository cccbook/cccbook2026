# 1923 · 密立根：把電子稱出重量

> 1923 諾貝爾物理學獎：羅伯特·安德魯斯·密立根（Robert Andrews Millikan, 1868–1953，美國）——表彰「他關於基本電荷以及光電效應的工作」（for his work on the elementary charge of electricity and on the photoelectric effect）。

## 懸案（案情提要）

1923 年的諾貝爾物理學獎，表彰的是兩件本來毫不相干的事，但它們背後是同一個信念：**物理學的終極目標是數字**。

**第一件：基本電荷。** 1911 年之前，「電荷」的量度有一個麻煩： elektrostatic 的方法只能量出**比值**（電荷對質量的比），不能量出**絕對值**。庫侖定律 $F = k \frac{q_1 q_2}{r^2}$ 中的比例常數 $k$ 是未知的，所以伏特、歐姆、法拉這些「實用單位」全都依賴於一個未確定的量。你可以把 $q$ 和 $k$ 同時乘以 2 而不改變任何物理。

要「定義絕對電荷」，必須有一個**可以獨立計數的粒子**。1906 年諾獎得主 J. J. 湯姆森的陰極射線實驗已經給出了 $e/m$，但那是比值。密立根的任務是：**把電子單獨抓住，數清它們的個數，並稱出它們的重量。**

密立根的解法是把「油滴」變成天平上的一粒沙子。

**第二件：光電效應。** 密立根用同一套精密電學方法驗證了愛因斯坦的光電方程（1911–1916），從中測出普朗克常數 $h$。這件事在 1921 年諾獎頒給愛因斯坦時就已經完成，但委員會認為它「尚待確認」，於是把光電效應部分的論證工作留給了密立根的 1923 年獲獎。

而密立根自己的態度，是科學史上的一個著名案例：**他用數據支持了一個他本人不喜歡的理論**。密立根至死對「光量子」與「電子自旋」都不滿意。他曾寫道（1930 年，《Physical Review》）：「我寧願相信電子有某種我尚未發現的性質，也不願相信它具有我在光電效應中發現的性質。」但他的數據——那些用多層油膜（多層重組、減少漏電）改進後的精密實驗——是量子論最硬的證據之一。他 1923 年的諾貝爾演講題為《電子電荷與光電效應》（"The Elementary Charge and the Photo-Electric Effect"），他在演講中花了整整一章解釋他如何**排除電子是連續分布的物質**（他稱之為「電子理論的荒謬推論」）。

值得記錄的是密立根的實驗精度：他把電荷測到約 0.5% 的精度，並且測出的值

$$e = 1.602\times10^{-19}\,\mathrm{C}$$

在他死後被 SI 定義為**基本電荷**（2019 年起），而成為整個電學與光學的基準。

## 調查

**第一件證物：油滴實驗的設計——一場三重夾擊。** 密立根要同時滿足三個條件：

1. **把電子隔離開來**（不能讓油滴帶上一堆電荷）；
2. **觀察並量測微觀的力**（重力 vs 電力 vs 粘滯阻力）；
3. **數出電子的個數**。

他的裝置是一個平板電容器：兩片平行金屬板之間有一層空氣，上方的小孔用油霧器噴出極小的油滴（半徑約 $10^{-6}$ 至 $10^{-5}\,\mathrm{m}$），油滴落下並在電場中懸浮。用顯微鏡觀測油滴。

**第二步：測量重力與電力。** 當電場關閉時，油滴以終端速度 $v_0$ 落下，由 Stokes 定律：

$$F_{\text{visc}} = 6\pi\eta r v_0 = mg \quad \Rightarrow \quad m = \frac{4}{3}\pi r^3 \rho$$

這給出油滴質量（但需要 $r$，不易量）。

**第三步：施加電場使油滴懸停。** 加上電壓 $V$ 使油滴靜止，則電力平衡重力：

$$qE = mg, \qquad E = \frac{V}{d} \quad (d = \text{板距})$$

若把電場關閉，油滴會反向加速到新的終端速度 $v_1$（因為電荷改變了），此時：

$$6\pi\eta r v_1 = mg - qE$$

兩個式子相減：

$$6\pi\eta r (v_1 - v_0) = qE \quad \Rightarrow \quad q = \frac{6\pi\eta r (v_1 - v_0) d}{V}$$

**第四步：關鍵的一步——「重組」（recharging）。** 這是密立根方法中最巧妙的部分，也是它能給出 0.5% 精度的原因。油滴帶電後，會從空氣中**捕獲離子**而改變電荷量 $q \to q + n e$（$n$ 為整數）。密立根的做法是：

1. 記錄某個油滴在幾次「通電—斷電—再通電」循環中的**平衡電壓 $V$**；
2. 每次循環後，油滴的電荷改變了一個**整數倍的基本電荷**（因為捕獲或釋放離子）；
3. 因此，把各次測得的 $q$ 畫成一個序列，相鄰兩項之差就是 $e$：

$$q_{i+1} - q_i = e \quad (\text{或 } -e, \; 2e, \dots)$$

**這個「整數跳躍」的觀測就是「電荷量子化」的直接證據**——密立根本人的說法是：電荷「不是連續的，而是以整數倍變化」。

密立根 1913 年報導的典型數據表（示意）：

| 油滴 | $q$（測得） | $q/e$（整數化後） |
|------|-------------|------------------|
| 1 | $4.42\times10^{-19}$ | 2.76 → 3 |
| 2 | $3.08\times10^{-19}$ | 1.92 → 2 |
| 3 | $6.68\times10^{-19}$ | 4.17 → 4 |
| 4 | $5.03\times10^{-19}$ | 3.14 → 3 |
| ... | ... | ... |

把**整數化的 $q$ 值**對實際測得的 $q$ 作圖，斜率就是 $e$——**這是一種「以整數為變元的最小平移法」**，類似於後來費曼圖中直線的「最長線段法」，也類似於赫兹登堡後來稱頌的「密立根的圖表法」（把散點排成整數序列）。密立根本人在《Physical Review》1913 年的文章中附有這樣的圖表，後人稱之為「Milankovitch plot」——正是密立根最有名的圖表。

**第五件證物：$e/m$ 的交叉驗證。** 密立根用油滴實驗得到的 $e$，與 1906 年諾獎得主湯姆森的陰極射線實驗得到的 $e/m$，結合起來給出**電子的質量**：

$$m_e = \frac{e}{(e/m)} = \frac{1.602\times10^{-19}}{1.758820\times10^{11}} = 9.109\times10^{-31}\,\mathrm{kg}$$

這是第一次**以電子為「秤砣」的直接質量量測**。注意：湯姆森的 $e/m$ 是在 1906 年諾獎裡，密立根的 $e$ 在 1923 年諾獎裡——**兩屆諾獎合起來才給出了電子的質量**。

**第六件證物：油滴實驗的三個副產品。** 密立根的裝置還順帶量到了：

- **水蒸氣在油滴上的凝結速率** → **大氣中的水蒸氣含量**；
- **油滴的布朗運動**（他實際上觀察了，1926 年佩蘭 1926 諾獎把布朗運動做成了定量的「沉降平衡」研究，密立根的數據被引用）；
- **太陽輻射強度的絕對量測**（用光電效應），這成為他日後宇宙線研究（1920s–1930s）的基礎。

**第七件證物：光電效應的精密測量與 $h$。** 密立根的光電實驗設計極為講究：

- **單色光**：用石英稜鏡 + 可調狹縫從弧光燈中挑出單一波長，並**直接用分光計測量所選波長**（這是他相較於前人的最大改進）；
- **遏止電位**：用反向電場阻止光電子，測出遏止電位 $V_s$，由

$$eV_s = h\nu - \phi$$

- **數據處理**：把 $V_s + \nu_0$ 對 $\nu$ 作圖（$\nu_0$ 為截止頻率），得到**直線斜率 $h/e$**。

密立根 1916 年的結果：斜率給出 $h/e = 4.82\times10^{-15}\,\mathrm{V\cdot s}$，乘上 $e$ 得 $h = 6.53\times10^{-27}\,\mathrm{erg\cdot s}$（後來 1919 年他報 $6.55$，現代值 $6.626\times10^{-34}\,\mathrm{J\cdot s}$）。

關鍵在於密立根的方法學：**他用「截止頻率 $\nu_0$」作為縱軸截距，把「$h$」與「逸出功 $\phi$」這兩個未知數分離開來**。這是雙參數擬合的經典處理，也是本卷最值得學習的實驗技巧。

**第八件證物：密立根與光量子的持久分歧。** 1930 年密立根公開挑戰光量子，他提出替代機制：

> 當光照射金屬時，電子先吸收光能並在金屬內部產生「高能狀態」，這個狀態可以通過碰撞傳遞給表面電子。

他主張這個機制也能解釋光電效應，而不需要「光子」。但 1930–1935 年的實驗（尤其 1932 年史密斯的 X 射線 Compton 效應實驗與 1937 年戴維孫的電子繞射）表明密立根的替代方案無法解釋數據。**密立根的立場最終是錯的，但他的數據是對的**——這是科學史上「正確的實驗、錯誤的解釋」的最著名案例之一，與愛因斯坦對光量子的執著形成完美對照。

## 理論裁決

**裁決一：Stokes 定律 + 靜電平衡——一個「以微觀為尺」的量測架構。** 讓我們把油滴實驗的物理鏈完整寫出，因為它是 20 世紀最漂亮的實驗之一。

**(a) 終端速度下的 Stokes 阻力**（雷諾數 $Re \ll 1$）：

$$F_{\text{drag}} = 6\pi\eta r v$$

其中 $\eta$ 是空氣黏度。重力：

$$F_g = \frac{4}{3}\pi r^3 \rho g \quad (\rho = \text{油密度})$$

平衡（無電場）：$6\pi\eta r v_0 = \frac{4}{3}\pi r^3\rho g$ →

$$r = \sqrt{\frac{9\eta v_0}{2\rho g}}$$

**注意這裡的一個精妙之處**：$r$ 可以從終端速度反推，不必直接量測微小油滴的半徑（這幾乎不可能）。

**(b) 加入電場**（油滴靜止）：$qE = mg$，其中 $E = V/d$：

$$q = \frac{mgd}{V} = \frac{\frac{4}{3}\pi r^3 \rho g\, d}{V}$$

**(c) 改變電荷量後再測終端速度**：$6\pi\eta r v_1 = mg - qE$。合併 (a) 與 (b)：

$$q = \frac{6\pi\eta r\,(v_1 - v_0)\, d}{V}, \qquad r = \sqrt{\frac{9\eta v_0}{2\rho g}}$$

代入得：

$$q = 6\pi\eta d \sqrt{\frac{9\eta v_0}{2\rho g}}\cdot\frac{v_1-v_0}{V}$$

這就是密立根的公式。**注意 $q$ 只依賴可觀測量 $v_0, v_1, V, d, \eta, \rho, g$**——完全沒有 $r$。

**(d) 電荷量子化**：捕捉離子使 $q \to q + ne$，故

$$q_i = q_0 + n_i e, \qquad n_i \in \mathbb{Z}$$

對多組獨立油滴，把 $q_i/n_i$ 作圖，或用「最長直線段法」求斜率，得到

$$e = 1.602\times10^{-19}\,\mathrm{C}$$

**裁決二：密立根的圖表法——一種「物理學家式的統計裁決」。** 密立根方法的美妙之處在於它把一個連續量（$q$）與一個離散量（$n$）分離開來，而誤差則落在離散量上。這個「以整數為樞紐」的思路在物理學中有深遠的同源：

- **塞曼效應**（1902）：譜線位移給出整數（$m$）；
- **Stark 效應**（1916）：電場位移給出整數（$k$）；
- **密立根**：電荷給出整數（$n$）；
- **1913 年巴耳末公式**：$1/n^2$。

1914 年密立根本人發表了改進論文《電子的電荷》（"On the charge of the electron"），在 1923 年諾貝爾演講中他把這套方法稱為「**charge of the electron determined by the method of the integer multiples**」，並在演講中展示了著名的圖表：橫軸是「整數化後的 $n$」，縱軸是「實測的 $q$」，散點排成整齊的直線，斜率即 $e$。

**裁決三：光電效應方程的雙參數分離。** 密立根的數學結構值得單獨記錄：

$$eV_s = h\nu - \phi$$

三個量（$V_s, \nu, \phi$）中，$h$ 是未知斜率、$\phi$ 是未知截距（縱軸上移）。密立根的方法是：

1. 用**多個 $\nu$**（不同波長）測多組 $(V_s, \nu)$；
2. 作 $V_s$ 對 $\nu$ 的圖，得**直線**——這本身即證明了「$V_s$ 與 $\nu$ 線性相關」這個愛因斯坦模型的預測；
3. 斜率 $= h/e$，截距 $= -\phi/e$。

這是一個教科書級的「**用多組數據分離多個未知參數**」的方法，與 1919 年莫塞萊定律的線性擬合、1913 年巴耳末公式的擬合同屬一類。

**裁決四：「基本電荷」的意義——物理學的計數原理。** 為什麼「電荷量子化」如此重要？

1. **它是「自然有最小單位」的證據**：電子電荷是所有帶電粒子的電荷的整數倍（質子 $+e$、中子 $0$、夸克 $\pm e/3$）——**夸克的發現（1969 諾獎）正是這一原理的延伸**。
2. **它是 SI 制的基石**：2019 年 5 月 20 日起，基本電荷 $e = 1.602176634\times10^{-19}\,\mathrm{C}$ 被定義為**精確值**（不再是量測值），整個電學、磁學、光學的計量鏈因此重構。
3. **它是統計力學的前提**：電荷量子化意味著「電荷守恆」可以從**守恆的量 $n$** 推出（電荷數守恆 $\Rightarrow$ 電荷守恆），這在粒子物理中至關重要。

**裁決五：2019 年的紀念——從「量出來的常數」到「定義出來的常數」。** 這條演化線值得完整追蹤：

| 年份 | $e$ 的地位 |
|------|-----------|
| 1911–1913 | 密立根量出 $e \approx 1.6\times10^{-19}\,\mathrm{C}$，誤差 3% → 0.5% |
| 1919 | 密立根（1913）與其他實驗室的值收斂到 0.1% 以內 |
| 1948 | 開始有系統的絕對電流量測（絕對安培） |
| 1960s | 以 $e$ 為基準定義「法拉第電荷」，$F = N_A e$ |
| 1982 | 推薦值 $e = 1.602176634\times10^{-19}\,\mathrm{C}$（CODATA） |
| 2010–2017 | 最終段實驗（2010 年《Physical Review Letters》的 two-way single-electron pump 實驗） |
| 2019-05-20 | **SI 重新定義**：$e$ 成為定義值；電子質量、玻爾半徑、阿佛加厥常數也隨之定義 |

這條線把 1923 年的諾獎直接連到 2019 年的 SI 改革，並連到 2024 年諾獎的量子資訊物理（單電子的量子控制）。

**裁決六：諾獎的「否定性貢獻」。** 密立根的貢獻有兩面：一面是「量出基本電荷」；另一面是「**排除**電子不是離散的、物質不是連續的這一可能性」。他在 1923 年演講中花了大量篇幅論證「電子理論的荒謬推論」——這些論證正是 20 世紀初「連續 vs 離散」大戰的一個戰場。而 1926 年佩蘭（1926 諾獎）用沉降平衡**獨立地**測出亞佛加厥常數 $N_A = 6.022\times10^{23}\,\mathrm{mol}^{-1}$，從而給出 $e = F/N_A$，兩條完全不同的路徑得到同一結果——**這是本卷中最有說服力的一次「雙重裁決」**。

## 後果

| 年份 | 影響 |
|------|------|
| 1911–1913 | 基本電荷被量出，精度 0.5%；電子質量隨之確定。 |
| 1913 | 密立根的「整數化圖表法」成為物理學示範實驗。 |
| 1916 | 愛因斯坦光電方程得到確認，$h$ 被獨立測量。 |
| 1923 | 諾獎頒發。 |
| 1926 | 佩蘭用沉降平衡獨立測出 $N_A$，兩條路徑交叉驗證 $e$。 |
| 1930 | 密立根挑戰光量子（歷史上的著名誤判）。 |
| 1930s | 密立根宇宙線研究：數千顆宇宙線粒子的量測，統計分析；Anderson 的正電子發現（1932 諾獎）即出自這個群體。 |
| 1938 | 密立根獲得宇宙線「分類」的早期系統；1939 年他試圖論證宇宙線是電子（錯了，是質子與原子核）。 |
| 1940s–1950s | 密立根基金會對美國科學教育的影響（Caltech 的支持、費米獎學金）。 |
| 1950s–60s | 以 $e$ 為基準的電流量測；Josephson 效應（1963）給出 $2e/h$ 的精密測量（1973 諾獎）。 |
| 1980s | 單電子泵實驗把 $e$ 的量測推到 $10^{-9}$ 相對精度，為 SI 改革鋪路。 |
| 2010–2017 | 最終確定 $e$ 的值，誤差 $<10^{-9}$。 |
| 2019-05-20 | SI 基本單位重新定義：$e$ 成為精確定義值。 |
| 2022–2024 | 量子計算與量子電學中，單電子的電荷量子化是最基本的操作前提；霍普菲爾德與辛頓的獲獎理由裡「以人工神經網路實現機器學習」也依賴「物理系統能以離散狀態編碼」的觀念。 |

## 關聯

- [1906-湯姆森與電子的身分證](1906-湯姆森與電子的身分證.md)：密立根的 $e$ 與湯姆森的 $e/m$ 合起來才是電子質量；兩屆諾獎構成同一件工作的兩半。
- [1921-愛因斯坦與光量子的賭注](1921-愛因斯坦與光量子的賭注.md)：密立根驗證愛因斯坦的光電方程，卻終身不認同光量子——本卷是那場「數據對、機制錯」的著名爭執。
- [1926-佩蘭與沉降平衡的原子計數](1926-佩蘭與沉降平衡的原子計數.md)：佩蘭獨立測出 $N_A$，從另一條路徑確認 $e = F/N_A$——「兩條路徑同一結論」的教科書案例。
- [1919-斯塔克與外場中的譜線分裂](1919-斯塔克與外場中的譜線分裂.md)：1919 年的多普勒位移法量測原子速度，與密立根的油滴法同屬「把不可見的量變成可見的量」的量測策略。
- [1944-拉比的核磁共振](1944-拉比的核磁共振.md)：1944 年的諾獎同樣是一場「頻率量測」的精密化運動；核磁共振後來成為 $e$、$h$ 的最精密量測工具之一。
- [1962-霍夫施塔特與穆斯堡爾的核探測](1962-霍夫施塔特與穆斯堡爾的核探測.md)：核物理中的「用譜線反推結構」方法，與密立根的「用整數跳躍反推電荷」同屬一個方法論家族。
- [2019-皮布林斯與馬約爾奎洛茲的宇宙學與系外行星](2019-皮布林斯與馬約爾奎洛茲的宇宙學與系外行星.md)：對照卷——1919 年的皮布林斯給出宇宙學的理論架構，與 1923 年的密立根給出基本電荷同屬「給物理學一個基準」的類型；且系外行星的視向速度法與密立根的「由微小位移反推物理量」同源。
