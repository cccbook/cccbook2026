# 1924 · 西格巴恩：X射線的指紋辨識術

> 1924 諾貝爾物理學獎：曼內·西格巴恩（Manne Siegbahn, 1886–1976，瑞典）——表彰「他在X射線光譜學領域的發現和研究」（for his discoveries and research in the field of X-ray spectroscopy）。

## 懸案（案情提要）

1913 年，物理學界已經知道：**每種元素有專屬的特徵 X 射線譜線**（巴克拉，1917 諾獎），而且譜線位置由莫塞萊定律給出：

$$\sqrt{\nu} = a(Z - b)$$

但這只解決了「譜線在哪裡」，沒有解決「**譜線是怎麼來的**」。1913–1924 年這十一年間，X 射線光譜學面臨的問題與整個物理學面臨的問題完全同構：**波耳的原子模型只適用於類氫原子，而真實原子都是多電子的。** 波耳自己知道這點，並在 1922 年諾貝爾演講中把它列為首要待解問題。

多電子原子的難題在於：
- 電子之間的相互作用沒有封閉形式的解；
- 「電子殼層」的存在已經從 X 射線的雙線系（巴克拉 1911）與**塞曼效應**得到暗示，但沒有系統模型；
- 需要一個能**解釋並預測所有元素的 X 射線譜線**的理論。

西格巴恩的貢獻，是把這門學科從「記錄現象」推到了「**診斷工具**」的地位。他做了三件事，每一件都對應一個技術突破：

**第一件：建立 X 射線光譜的精密測量學。** 1920 年代，西格巴恩在烏普薩拉（Uppsala）建造並改進了 **X 射線光譜儀**，其核心是一支他親手製造的高解析 X 射線管（稱為 **Siegbahn tube**，1924 年申請專利）與一套精密的真空泵與分光計。他的量測精度達到了**相對誤差 $10^{-6}$ 級別**——這在 1920 年代是驚人的。

**第二件：發現 L 系列的「三條線」結構並建立「選擇定則」的第一版。** 巴克拉只發現了 K 系列與 L 系列「兩套線」。西格巴恩在 1924 年前後發現：L 系列其實包含**三條線**（$L_\alpha, L_\beta, L_\gamma$），且它們與 K 系列（K$\alpha$, K$\beta$）之間存在系統性的頻率關係：

$$\nu(L_\alpha) = \nu(K_\beta) - \nu(K_\alpha) \quad (\text{組合差})$$

這意味著：**譜線的頻率不是獨立的，而可以由更小的基本頻率組合而成**。這是理解原子能階結構的關鍵一步，也是後來 1913–1930 年代「能階圖（term diagram）」的基礎。

**第三件：發展 X 射線的定量分析應用（化學分析）。** 西格巴恩把 X 射線光譜變成元素分析的標準方法。**這件事在化學史上極其重要**——它是「不用化學反應就能知道樣品裡有什麼元素」的技術的開端，直接支援了礦物學、冶金學與後來的核科學。**1930 年代之後，這套技術被用來發現新元素**（錳1937、鎵1937、鉭1937、鈾1938、鈽1938、鈾234等）——**而每一次「在自然界找不到」的發現都意味著「這個元素可以在核反應中造出來」**，這就是 1936–1939 年費米與勞倫斯的工作的化學基礎。

西格巴恩的命運也與 20 世紀的物理學政治交織：
- 他在 1939 年被選入**瑞典皇家科學院**（實際上是被提名為諾貝爾物理委員會的委員）——這在德國占領瑞典期間是一個需要勇氣的位置；
- 1942 年，他的兒子 Kai Siegbahn（後來 1981 年諾獎得主）被扣押在波蘭的 Lviv 集中營——**這是科學史上最黑暗的一段**；Kai Siegbahn 倖存，並在 1946 年回到烏普薩拉繼續研究，後來成為 X 射線光電子能譜（XPS，ESCA）的開創者；
- 1946 年，Manne Siegbahn 辭去所有職務，離開瑞典前往美國；委員會因此失去了一位資深成員。

本卷的核心線索：**X 射線光譜學從 1913 年的「發現元素特異線」走到 1924 年的「診斷原子內部結構」**，這條線在 1925 年法蘭克-赫茲（能階）、1932 年海森堡（量子力學）、1935 年查德威克（中子）、1955 年蘭姆-庫施（精細結構）、1981 年西格巴恩父子（ESCA）一路延伸。

## 調查

**第一件證物：Siegbahn 管——工程上的突破。** 1920 年代的 X 射線管有嚴重的技術瓶頸：管內殘餘氣體會產生自己的譜線（與靶材無關），干擾測量；陽極在電子轟擊下過熱；管壁散射造成背景。

西格巴恩的解決方案是：
- **高真空**：把殘餘氣體降到 $10^{-6}$ torr 量級，消除氣體本身的譜線；
- **旋轉陽極**：讓電子束在旋轉的靶面上掃過，把功率密度分散，同時獲得更高的有效靶溫；
- **獨立控溫與可換靶**：使譜線源可獨立優化。

這套設計成為 1930–1970 年代全世界 X 射線光譜儀的「工業標準」（Siegbahn tube 是當時最常見的商用 X 射線光源），也使西格巴恩的量測精度提升了一到兩個數量級。

**第二件證物：L 系列的三條線與「組合關係」。** 讓我們把這個發現的邏輯寫清楚。

1913–1924 年間，X 射線譜線的經驗結構是這樣的：
- **K 系列**：$K_\alpha, K_\beta, K_\gamma$（$K_\alpha$ 最強）；
- **L 系列**：巴克拉只知道有 L 線。

西格巴恩發現（1924）：**L 系列至少包含三條主要的線 $L_\alpha, L_\beta, L_\gamma$**，而且它們的頻率滿足：

$$\nu(L_\alpha) = \nu(K_\beta) - \nu(K_\alpha)$$
$$\nu(L_\beta) = \nu(K_\gamma) - \nu(K_\alpha)$$

這就是「**組合差（combination difference）**」。它的物理意義是：**譜線的頻率由「能階差」組成**，而這些能階本身形成一個有結構的集合。

現在我們可以把它寫成一個能階圖（term diagram）的雛形。若以「外層電子的能階」$L_1, L_2, L_3$ 與「K 殼層」$K$ 表示，躍遷為：

| 躍遷 | 描述 |
|------|------|
| $K_\alpha$ | $K \to L_3$ |
| $K_\beta$ | $K \to L_2$ |
| $K_\gamma$ | $K \to L_1$ |
| $L_\alpha$ | $L_3 \to M$ |
| $L_\beta$ | $L_2 \to M$ |
| $L_\gamma$ | $L_1 \to M$ |

這就是 1920 年代末（1926 年 Condon–Shortley 與 Russell）建立的**能階符號（term notation）**的基礎。用更現代的語言：$K$ 殼層只有一個 1s 態（$n=1$），而 $L$ 殼層有 2s 與 2p 態；$K_\alpha$ 對應 $2p_{3/2} \to 1s_{1/2}$（或 $2p_{1/2}$），$L_\alpha$ 對應 $3d_{5/2} \to 2p_{3/2}$。**譜線的「組合差」本質上就是「同一組量子態之間的共同能階差」**——這正是「能階圖」這個概念的物理內容。

**第三件證物：莫塞萊定律的精密化與「屏蔽效應」的量化。** 西格巴恩的高精度資料讓莫塞萊定律得以精確測試：

$$\sqrt{\nu} = a(Z - \sigma), \qquad a = R_\infty c \left(1-\frac{1}{n^2}\right)^{1/2}$$

對 K$\alpha$ 線（$n=1 \to 2$）：

$$\sqrt{\nu} = R_\infty^{1/2}c\sqrt{1 - 1/4}\,(Z - \sigma) \quad (\sigma \approx 1)$$

**西格巴恩的貢獻之一是確認這個線性關係在整個週期表上成立，誤差只有 $10^{-5}$ 量級**——這是原子序 $Z$ 作為「物理量」的決定性證明。這個精度後來被用作**發現元素的工具**：當某個樣品的譜線位置與已知元素的預測不符時，就發現了新元素。

**第四件證物：X 射線的化學分析——一門新學科的成立。** 西格巴恩在 1924 年前後建立的應用流程是：

1. 用固定電壓的 X 射線管照射樣品，激發元素的特徵譜線；
2. 用分光計（分析水晶或岩鹽）按**波長**分光；
3. 比對譜線位置 → 判定元素。

這套方法的灵敏度極高——**能檢測到百萬分之一量級的元素濃度**。1920 年代末到 1930 年代，這套技術被用在兩個方向：

- **地質學**： minerals 的組成分析（後來 X 射線螢光分析 XRF 的直系祖先）；
- **核科學**：1936–1939 年費米團隊在中子轟擊產物中**用 X 射線譜學搜尋新元素**，這是人工放射性元素的化學鑑定步驟。

西格巴恩與拉姆齊（1904 諾獎）在 **1912–1914 年就已經合作研究過 X 射線吸收與分子結構的關係**——這是「用 X 射線量分子」的先驅。

**第五件證物：X 射線的「化學位移」效應。** 這是一個美麗而實用的效應：**化學鍵的變化會極微小的改變內層電子的能階**，進而微移 K$\alpha$ 譜線（$\sim 10^{-4}$ 至 $10^{-2}$ eV）。1930 年代由 Oddi 與 others 觀察到，後來成為 **X 射線光電子能譜（XPS, ESCA）** 區分化學態的基礎——這是 1981 年諾獎（Kai Siegbahn）的技術基礎。

**第六件證物：從光譜到「原子結構的診斷」。** 讓我們把整條推理鏈寫清楚，這是本卷的核心：

$$\text{譜線位置} \to \text{能階圖} \to \text{電子殼層結構} \to \text{元素週期律}$$

1913 年莫塞萊的「譜線位置隨原子序線性變化」是第一段；1920–24 年西格巴恩的「L 系列的組合差與多條線」是第二段（能階圖）；1925 年泡利的「不相容原理 + 費米的填充」是第三段（殼層填充）；1932–1933 年量子力學是第四段（嚴格理論）。**西格巴恩的工作是這條鏈的第二段，也是最容易被忽略的一段**——沒有能階圖，泡利的原理無從談起。

## 理論裁決

**裁決一：組合差——「能階圖」這個概念的起源。** 讓我們用現代語言寫出西格巴恩發現的深層結構。

X 射線光譜線的頻率由原子的能階差給出（1913 年波耳的頻率條件）：

$$h\nu = E_i - E_f$$

由於 K 與 L 殼層都是「填滿的內殼層」，它們的能階基本上是原子的**有效核心電位**加上一個小的修正。因此對同一元素：

$$\nu(K_\alpha) = \frac{E_{K} - E_{L_3}}{h}, \qquad \nu(L_\alpha) = \frac{E_{L_3} - E_{M}}{h}$$

兩式相加立刻給出：

$$\nu(K_\alpha) + \nu(L_\alpha) = \frac{E_K - E_M}{h}$$

這就是「組合差」的來源：**所有譜線的頻率都落在同一個「能階間隔的格點」上**。用圖形語言：把每條譜線的頻率視為一條「線段」，則所有線段的端點都對應同一組能階。因此，只要量測到足夠多的譜線頻率，就能**重建整張能階圖**——這是一個「差分測量」的技巧。

西格巴恩 1924 年以後的所有工作，實質上都在**擴充這張能階圖**。它是 1920–30 年代物理學最被低估的「資料基礎設施」：海森堡、泡利、狄拉克在建立量子力學時所用的「真實原子光譜數據」，正是西格巴恩實驗室提供的。

**裁決二：屏蔽常數 $\sigma$ 的物理意義。** 莫塞萊定律中的 $b \approx 1$ 不是常數而是 $\sigma$，它代表內層電子的屏蔽。嚴格地（Dirac 1928 的相對論性修正後）：

$$\sqrt{\nu} = R_\infty c\sqrt{1 - \frac{1}{n^2}}\left(Z - \sigma\right) + \frac{(Z-\sigma)^4\alpha^2 R_\infty c}{8n^3}\cdots$$

這裡第二項就是**相對論性的精細結構修正**——它直接給出 1915 年莫塞萊定律的「偏差」：**$Z$ 越大，偏差越大**。這就是 1920–1930 年代光譜學家觀察到的「Moseley plot 曲線」，也是 1919 年莫塞萊之謎（為何高 $Z$ 元素偏離）的答案。**西格巴恩的高精度資料，正是揭示這個偏差所必需的。**

**裁決三：X 射線作為「核的探針」——電子屏蔽效應。** X 射線光譜測的是「內層電子」，而內層電子的能階幾乎只由**核電荷**決定（外層電子的屏蔽被內層遮蔽）。這就是 X 射線光譜能用來「稱量核電荷」的原因：

$$E_K \approx -\frac{1}{2}\mu c^2 (Z\alpha)^2 n^{-2}$$

這個「$Z$ 在高能譜線中被放大」的性質，是後來 **X 射線天文學**（2002 諾獎：賈科尼）的物理基礎——天體的 X 射線譜線可以直接「讀出」天體的溫度、密度、甚至電荷組成。

**裁決四：技術進步如何改變物理問題。** 讓我們把 1917 年（巴克拉）與 1924 年（西格巴恩）的實驗條件並列：

| 項目 | 巴克拉 (1911) | 西格巴恩 (1924) |
|------|---------------|----------------|
| 相對精度 | $\sim 10^{-2}$ | $\sim 10^{-6}$ |
| 譜線 | 只知 K、L 兩系列存在 | L 系的完整多線結構 |
| 光源 | 一般 X 射線管 | Siegbahn 管（高真空、旋轉陽極） |
| 分光 | 吸收邊法 | 布拉格式分光計 |
| 用途 | 定性存在性 | 定量分析、能階重建 |
| 理論需求 | 只需「元素特異」 | 需要多電子原子的能階理論 |

**量測精度的十倍提升，等於問題難度的數量級躍升。** 這是 20 世紀物理學最典型的發展模式：每一次實驗精度的大幅提升，都打開一扇新的理論之門。1924 年之後擺在物理學家面前的問題正是：「給我一個能算出所有元素 X 射線譜線的理論。」**而這個問題的答案要等到 1926 年（薛丁格的波動方程 + 泡利原理 + 費米統計）才開始出現，1930 年代的 Hartree-Fock 自洽場方法給出定量結果。**

**裁決五：戰時瑞典的科學界——一段必要的記錄。** 本卷有一個不能略過的歷史面向。

1940–1945 年，瑞典是二戰中的中立國，但地理位置使它成為德國佔領丹麥、挪威後的鄰國。1942 年 6 月，德國人將瑞典籍的物理學家 Kai Siegbahn（以及另外兩位猶太出身的物理學家）從烏普薩拉帶到波蘭 Lviv 的集中營，並強迫他們為德國的戰爭計畫工作。

KaI Siegbahn 在那裡待了約兩年，直到 1944 年透過瑞典外交部的干預才獲釋，返回瑞典繼續研究，並最終在 1981 年獲得諾貝爾物理學獎。

這個事件的歷史意義在於：**它是「科學不被政治豁免」這一提醒的直接來源之一**。戰後諾貝爾基金會、UNESCO 與瑞典科學界對科學自由的重視，都與這類經歷直接相關。1946 年 Manne Siegbahn 辭去瑞典的一切職務並離開，也反映出一代科學家對政治隱患的敏感。

**裁決六：諾獎的「工具性」傳統。** 西格巴恩案再一次確立了一個判準：**諾貝爾物理學獎可以表彰「測量技術」**。相關先例與後續：

- 1907 邁克生（精密光學儀器）；
- 1920 紀堯姆（材料）；
- 1946 布里奇曼（超高壓裝置）；
- 1953 塞爾尼克（相襯顯微鏡）；
- 1961 穆斯堡爾（共振吸收）；
- 1981 布洛伯根與肖洛（雷射光譜儀）；
- 1981 西格巴恩（電子光譜儀）；
- 1986 賓寧與羅雷爾（掃描隧道顯微鏡）。

**1924 年的諾獎是這條線上的一次特別好的示範**：它表彰的不是「發現了什麼新東西」，而是「**讓人類能看見原子內部結構的那台機器**」。

## 後果

| 年份 | 影響 |
|------|------|
| 1912–1914 | 與拉姆齊合作研究 X 射線吸收與分子結構。 |
| 1924 | Siegbahn 管問世；L 系列三線與組合差被確立。**諾獎頒發**（1925 年 12 月頒）。 |
| 1926–1928 | 能階符號系統建立；Moseley plot 的相對論性偏差被量化。 |
| 1928 | 狄拉克方程給出精細結構的相對論性理論，與西格巴恩的精密數據吻合。 |
| 1930s | X 射線光譜成為元素分析與新元素發現的標準工具（Mn, 1937; Ga, 1937; Ta, 1937; Hs, 1939…）。 |
| 1936–1939 | 費米與勞倫斯的人工放射性元素鑑定，X 射線譜學是化學確認的關鍵一步。 |
| 1939 | M. Siegbahn 進入瑞典皇家科學院與諾貝爾委員會。 |
| 1942–1944 | Kai Siegbahn 在 Lviv 集中營被扣押。 |
| 1946 | M. Siegbahn 辭職離開瑞典。 |
| 1950s–1970s | X 射線光譜儀成為工業與研究標準設備。 |
| 1970s–1980s | **ESCA / XPS**（Kai Siegbahn 的電子能譜學）：以 X 射線光子的能量直接量測電子動能 $\E_{kin} = h\nu - E_B - \phi$，可測出材料的化學組成與電子結構；成為表面科學的基礎技術。 |
| 1981 | **Kai Siegbahn 獲諾貝爾物理學獎**——父子兩代諾貝爾物理學獎得主，諾獎史上僅有的幾例之一。 |
| 1990s–2000s | 同步加速器光源讓 X 射線能譜達到 meV 解析度；X 射線吸收邊（XANES/EXAFS）成為催化與生物結構的探針。 |
| 2002 | 賈科尼獲諾貝爾物理學獎（X 射線天文學）——X 射線譜成為天文學的基礎工具。 |
| 2010s | X 射線自由電子雷射（XFEL）與 attosecond 固態物理（2023 諾獎）。 |
