# 1961 · 霍夫施塔特與穆斯堡爾：量出質子的大小，與「不反衝」的共振

> 1961 諾貝爾物理學獎：羅伯特·霍夫施塔特（Robert Hofstadter, 1915–1990，美國）與魯道夫·穆斯堡爾（Rudolf Mössbauer, 1929–2011，西德）——表彰「霍夫施塔特：他對原子核中電子散射的先驅性研究，以及由此對核子結構所作的發現；穆斯堡爾：他對 $\gamma$ 射線共振吸收的研究，以及由此發現的同名效應」（for his pioneering studies of electron scattering in atomic nuclei… / for his researches concerning the resonance absorption of gamma radiation…）。

## 懸案（案情提要）

**1961 年的兩位得主處理兩個表面無關的問題——但內核是同一個詞：「共振」。**

**第一宗（霍夫施塔特）：質子有多大？**

**1930 年代的物理學把原子核與粒子都當成「點」。** 那麼質子呢？

**1950 年，霍夫施塔特在史丹福用 100–600 MeV 的高能電子束轟擊核，量測散射的角分布。** 結果極其明確：

> **散射截面沒有像「點狀核」預期的那樣隨能量下降——它偏離了。**
> **這意味著質子有有限的大小。**

**推得的電荷半徑（rms）：**

$$\langle r^2\rangle_e^{1/2} \approx 0.84\,\mathrm{fm} = 0.84\times10^{-15}\,\mathrm{m}$$

**0.84 飛米——比原子核（$\sim 1.2$–$1.5\,\mathrm{fm}$）略小，比原子（$\sim 10^5\,\mathrm{fm}$）小十萬倍。**

**這是一個「把看不見的東西的尺寸量出來」的成果，而且用的是「電子散射」這把尺。**

**第二宗（穆斯堡爾）：為什麼核的 $\gamma$ 共振那麼模糊？**

**原子核有分立能階，可以用 $\gamma$ 射線去「敲」。但共振線有兩個模糊化機制：**

**(a) 壽命造成的自然寬度：**

$$\Gamma = \frac{\hbar}{\tau}$$

**57 鐵的 14.4 keV 躍遷：$\tau = 141\,\mathrm{ns}$ → $\Gamma = 4.7\times10^{-9}\,\mathrm{eV}$。**

**(b) 反衝（recoil）：** 發射 $\gamma$ 的原子核要反跳，動量守恆給出反衝能：

$$E_R = \frac{p^2}{2M} = \frac{E_\gamma^2}{2Mc^2}$$

**對 57 鐵（$Mc^2 = 51000\,\mathrm{MeV}$）、$E_\gamma = 14.4\,\mathrm{keV}$：**

$$E_R = \frac{(14.4\times10^3)^2}{2\times5.1\times10^{10}}\,\mathrm{eV} = 2.03\times10^{-3}\,\mathrm{eV}$$

**比較：$E_R/\Gamma = 2.03\times10^{-3}/4.7\times10^{-9} \approx 4.3\times10^5$。反衝能比自然寬度大 43 萬倍——共振完全被抹平了。**

**所以 1958 年之前，核 $\gamma$ 共振的能量解析度被反衝限制在 $\sim 10^{-4}$ 相對精度，而非理論上可能的 $10^{-9}$。**

**穆斯堡爾的洞見（1958 年）：**

> **「如果整個晶體（而不只是單一原子核）一起承擔這個反衝，那麼反衝能趨近於零——因為晶體的質量是原子的 $\sim 10^{23}$ 倍。」**

**這就是「穆斯堡爾效應」：無反衝的 $\gamma$ 共振吸收。**

| | 反衝限制 | 穆斯堡爾效應 |
|---|---|---|
| 57 鐵的能量解析度 | $\sim 2\,\mathrm{meV}$ | **$\sim 4.7\,\mathrm{neV}$** |
| 相對解析度 | $10^{-4}$ | **$3\times10^{-13}$** |
| 可觀測的物理 | 核能階 | **超精細結構、同位素位移、四極分裂** |

**$3\times10^{-13}$ 的相對解析度，比最好的光譜儀（$10^{-9}$）還好 4 個數量級。**

**所以本案的「懸案」一句話說清：**

> **兩位得主各用一種方法，把物理學的量測極限向外推了一格：一個量出了核子的大小，一個把核共振的解析度推到了 $10^{-13}$。**
> **而這兩者都是「用高能粒子或光子當尺子」的故事。**

## 調查

**第一件證物：霍夫施塔特的「追蹤曲線」——「一條直線的偏離」。**

**實驗：** 用能量為 $E$ 的高能電子束轟擊核，在散射角 $\theta$ 處量測微分截面。

**「點狀核」的預言（Rutherford）：**

$$\frac{d\sigma}{d\Omega}\bigg|_{\text{point}} = \left(\frac{Ze^2}{4E}\right)^2\frac{1}{\sin^4(\theta/2)}$$

**有限尺寸用形式因子 $F(q^2)$ 描述：**

$$\frac{d\sigma}{d\Omega} = \left(\frac{Ze^2}{4E}\right)^2\frac{1}{\sin^4(\theta/2)}\,|F(q^2)|^2, \qquad q = \frac{2E\sin(\theta/2)}{\hbar c}$$

**霍夫施塔特的技巧：定義「追蹤函數」 $G(E)$，把點狀預言的部分除掉——**

$$G(E) = \frac{E\,q^2}{3\hbar^2c^2}\left[Z(Z+1) - \text{尺寸修正項}\right]$$

**關鍵性質：**

- **對「點狀核」，$G(E)$ 是一條通過原點的直線；**
- **對有限尺寸核，$G(E)$ 是一條「縱軸截距不為零」的直線——截距直接給出 $\langle r^2\rangle$！**

**實測結果：質子的追蹤曲線在 $E \sim 100$–$600\,\mathrm{MeV}$ 區間明顯偏離直線（低能端「下沉」）。**

**推得：**

$$\langle r^2\rangle_e = 0.70\,\mathrm{fm^2}, \qquad \langle r^2\rangle_e^{1/2} = 0.84\,\mathrm{fm}$$

**這是「質子不是點」的第一個定量證據，並直接催生了 1960 年代的「核子結構物理」。**

**第二件證物：電子散射的「其他收穫」——「磁形式因子」。**

$$F_M(q^2), \qquad \mu_p = 2.79\,\mu_N,\qquad \langle r^2\rangle_M^{1/2}\approx 0.88\,\mathrm{fm}$$

**更重要的收穫：「核子的磁半徑與電荷半徑不重合」——這在 1960 年代成為「夸克模型」的重要線索（1969 諾獎）。**

**第三件證物：穆斯堡爾效應的物理——「把整個晶體當成一個巨大的原子」。**

**第一步：自然寬度。**

$$\Gamma = \frac{\hbar}{\tau} = \frac{1.0546\times10^{-34}}{141\times10^{-9}} = 7.48\times10^{-28}\,\mathrm{J} = 4.67\times10^{-9}\,\mathrm{eV}$$

**第二步：自由原子的反衝。**

$$E_R = \frac{E_\gamma^2}{2Mc^2} = 2.03\times10^{-3}\,\mathrm{eV}$$

**第三步：晶體中的兩種可能性。**

**(a) 產生一個聲子（phonon）：** 動能給了晶格的聲子模式 → 能量損失 $=E_R$（普通情形，共振被抹平）。

**(b) 無聲子（recoil-free）：** 整個晶體作為整體吸收動量 $p = E_\gamma/c$。對 1 克的晶體：

$$E_R^{\text{crystal}} = \frac{E_\gamma^2}{2M_{\text{crystal}}c^2} = \frac{(2.3\times10^{-15})^2}{2\times10^{-6}\times9\times10^{16}} = 2.9\times10^{-31}\,\mathrm{J} = 1.8\times10^{-12}\,\mathrm{eV}$$

**比單原子的反衝能小 $10^{9}$ 倍——完全可以忽略。**

**第四步：穆斯堡爾因子。**

$$f = \exp(-2W), \qquad 2W = \frac{E_\gamma^2\langle x^2\rangle}{\hbar^2c^2}$$

**其中 $\langle x^2\rangle$ 是共振原子相對於晶格質心的均方位移。**

**對 $^{57}\mathrm{Fe}$ 在室溫：$f \approx 0.7$（實測），對應 $\langle x^2\rangle \approx 6\times10^{-23}\,\mathrm{m^2}$。**

**第五件證物：穆斯堡爾光譜的三個參數——「把化學環境讀出來」。**

**(a) 同位素位移（isomer shift）：** 核的有限尺寸 → 核內電場與化學環境（氧化態、配位）有關。

**典型數值（$^{57}\mathrm{Fe}$）：**

| 化合物 | 同位素位移 (mm/s) |
|---|---|
| 金屬鐵 (Fe) | 0.00 |
| $\mathrm{Fe_2O_3}$（三價鐵） | +0.47 |
| $\mathrm{FeO}$（二價鐵） | +1.30 |
| $\mathrm{FeF_3}$ | +0.50 |

**(b) 四極分裂：** 若核有電四極矩 $Q$（$I\ge 1$），在電場梯度下分裂：

$$\Delta E_Q = \frac{eQV_{zz}}{4}\sqrt{1+\frac{\eta^2}{3}}$$

**這給出「分子結構」：四極分裂正比於電場梯度，符號給出「電子分佈的非軸對稱性」。**

**(c) 超精細分裂：** 核自旋與電子自旋的耦合 $\Delta E_{\text{hfs}} = \frac{A}{2}\langle\mathbf{I}\cdot\mathbf{S}\rangle$。對 $^{57}\mathrm{Fe}$，$A/B$ 的量測直接給出電子波函數在核處的值——**這是穆斯堡爾效應與核磁共振（1944 諾獎）之間的橋樑。**

**第六件證物：Pound–Rebka 實驗——「用重力檢驗等價原理」。**

**1959 年，Robert Pound 與 Joseph Rebka 用穆斯堡爾效應測量地球的重力紅移。**

**原理：** 樓上與樓下的 $^{57}\mathrm{Fe}$ 源與吸收體有 $\Delta h = 22.5\,\mathrm{m}$ 的高度差。它們都相對地心運動，感受到的引力不同。

**預測：**

$$\frac{\Delta\nu}{\nu} = \frac{g\,\Delta h}{c^2} = \frac{9.8\times22.5}{(3\times10^8)^2} = 2.45\times10^{-15}$$

**實測：$2.5\times10^{-15}$——吻合到 $\sim 1\%$。**

**這是「等價原理」的一次 $10^{-15}$ 量級檢驗——而它是用**核能階**而不是原子鐘做到的。** 它正是 2010 年代「原子干涉重力儀」的先聲。

**第七件證物：從「實驗室」到「銀河系」——天體穆斯堡爾光譜學。**

**1979 年起，人們發現可以用 $^{57}\mathrm{Fe}$ 的 14.4 keV $\gamma$ 線「照亮」天體。**

**原理：** 從天體發出的 $\gamma$ 射線穿過天體自身的物質，會被其中的 $^{57}\mathrm{Fe}$ 吸收，留下「吸收線」。**線的位移與寬度攜帶著 absorber 的物理狀態（溫度、密度、氧化態、磁場）。**

**IGR 探測器在 1979–1983 年量測了：**

- **銀河系中心的 $\gamma$ 射線譜**；
- **1943 年 5 月 15 日的「新星」（Nova CP 1943）**——「用 $\gamma$ 射線量測天文距離」的先驅；
- **Cyg X-1**（黑洞候選體）的吸收譜。

## 理論裁決

**裁決一：共振的線寬與「時間-能量極限」。**

**激发態的壽命 $\tau$ 決定能階的不確定性：**

$$\Gamma = \frac{\hbar}{\tau}$$

**共振吸收的截面形狀（Breit–Wigner）：**

$$\sigma(E) \propto \frac{\Gamma}{(\Gamma/2)^2 + (E-E_0)^2}$$

**對 57 鐵的三種寬度來源：**

| 限制因素 | 數值 |
|---|---|
| 自然寬度 $\Gamma = \hbar/\tau$ | $4.7\,\mathrm{neV}$ |
| 單原子反衝 $E_R$ | $2.0\,\mathrm{meV}$（**大 43 萬倍**） |
| 晶體整體反衝 | $1.8\,\mathrm{peV}$（**可忽略**） |

**結論：在晶體中，共振線寬完全由 $\tau$ 決定 → 解析度 $3\times10^{-13}$。**

$$\boxed{\text{穆斯堡爾效應把共振量測從「受反衝限制」變成「受壽命限制」}}$$

**這是 20 世紀物理學中「消除一個系統誤差」的典型案例：**

| 案例 | 系統誤差 | 消除方法 | 諾獎 |
|---|---|---|---|
| 1937 戴維孫–革拉赫 | 電子折射 | 重新分析幾何（1988） | 1937 |
| 1950 Hahn 自旋回波 | 磁場不均勻 | **180° 反轉脈衝** | 1952 |
| **1958 穆斯堡爾** | **反衝** | **整個晶體一起反衝** | **1961** |

**裁決二：散射實驗量尺寸的普遍原理——「傅立葉變換即尺寸」。**

**散射振幅是電荷密度差的傅立葉變換：**

$$f(\mathbf{q}) = \int \rho(\mathbf{r})\,e^{-i\mathbf{q}\cdot\mathbf{r}}\,d^3r$$

**這正是 1914/1915 年諾獎（X 射線繞射與布拉格定律）的「結構因子」。**

**因此有一條普遍規律：**

$$\Delta x \approx \frac{\hbar}{q} = \frac{\hbar c}{2E\sin(\theta/2)}$$

**對霍夫施塔特的電子散射（$E = 200\,\mathrm{MeV}$、$\theta = 90^\circ$）：**

$$\frac{\hbar c}{2E\sin45^\circ} = \frac{197\,\mathrm{MeV\cdot fm}}{2\times200\times0.707} = 0.70\,\mathrm{fm}$$

**正是原子核的尺度。**

**諾獎級實驗的「解析度公式」對照表：**

| 諾獎 | 方法 | 解析度公式 | 典型值 |
|---|---|---|---|
| 1914 勞厄 | X 射線繞射 | $\lambda/2\sin\theta$ | $\sim 0.1$ nm |
| 1937 戴維孫 | 電子繞射 | $h/(p\,2\sin\theta/2)$ | $\sim 0.1$ nm |
| **1961 霍夫施塔特** | **高能電子散射** | $\hbar c/(2E\sin\theta/2)$ | **$\sim 0.1$ fm** |
| 1961 穆斯堡爾 | $\gamma$ 共振 | $\hbar/\tau$ | **$10^{-13}$ 相對** |
| 1986 賓寧–羅雷爾 | STM | 原子間距 | $\sim 0.1$ nm |
| 1990 弗里德曼 | 深度非彈性散射 | $\sim 1$ fm | $\sim 0.1$ fm |

**裁決三：穆斯堡爾因子與「晶格動力學」——「$f$ 量測的是原子的振動」。**

**$f = e^{-2W}$ 中，$W$ 直接依賴原子的均方位移：**

$$2W = \frac{E_\gamma^2\langle x^2\rangle}{\hbar^2c^2}$$

**因此，測量 $f(T)$ 就能反推 $\langle x^2\rangle(T)$，進而得到聲子頻率、德拜溫度、以及原子的「德布羅意波長尺度」。**

**這讓穆斯堡爾效應成為「測量固體內部原子振動」的工具——並在後來發展出「穆斯堡爾效應式的三維光柵」：**

**1969 年，**H. Patty 與 **A. L. Schawlow** 等人利用穆斯堡爾效應產生的「**穆斯堡爾光柵**」（Mössbauer grating）——用 $^{57}\mathrm{Fe}$ 薄片在核 $\gamma$ 線上做「繞射光柵」，波長可到 $\sim 1$ nm（比可見光短 500 倍）。**

**這是「用核能階當尺子」的極端例子。**

**裁決四：從「質子的大小」到「夸克」——本案的深層後果。**

**霍夫施塔特的電子散射結果，在 1960 年代引發了一個巨大的問題：**

> **如果質子有結構（半徑 0.84 fm），那麼「質子的內部」是什麼？**
> **而且：為什麼它的電荷分布與磁分布不重合？**
> **而且：為什麼磁矩是 $2.79\,\mu_N$（而不是 $\mu_N$）？**

**這三個問題的答案，就是 1969 年諾獎的夸克模型。**

$$\mu_p = 2.79\,\mu_N \quad \text{（由夸克組成計算：} g_u \approx -3.03,\ g_d \approx 5.05\text{）}$$

**而 1960 年代的深度非彈性散射實驗（1990 諾獎）最終直接「看見」了點狀結構。**

**因此 1961 年這樁諾獎是 1969 年與 1990 年兩樁諾獎的直系祖先。**

**裁決五：本案在諾獎史中的座標——「用散射量尺寸」的完整家譜。**

| **1961 霍夫施塔特** | **高能電子** | **質子內部** | **$0.1$ fm** |
| 1961 穆斯堡爾 | $\gamma$ 射線（核能階） | 化學環境、晶格動力學 | $10^{-13}$ 相對 |
| 1986 賓寧–羅雷爾 | 電子（隧穿電流） | 表面原子排列 | $0.01$ nm |
| **1990 弗里德曼** | **高能電子** | **質子內部的夸克** | $0.1$ fm |
| 1999 胡夫特 | — | 量子場論的重整化 | — |

**這張表的主題是：「每一次把散射粒子的能量提高一個數量級，解析度就提高一個數量級。」** 而 1961 年的兩位得主，一位站在這條線的「尺寸」端，一位站在「精度」端。

## 後果

| 年份 | 影響 |
|---|---|
| 1937 | 戴維孫–革拉赫的電子繞射（霍夫施塔特的老師線索）。 |
| 1944 | 拉比的 NMR——穆斯堡爾超精細參數的對照。 |
| 1956 | 霍夫施塔特的**追蹤曲線 $G(E)$**。 |
| 1958 | **穆斯堡爾效應被發現**。 |
| 1959 | **Pound–Rebka 重力紅移實驗**（$10^{-15}$ 等效原理檢驗）。 |
| **1961** | **諾獎頒發**。 |
| 1960s | **核子結構物理**建立；質子與中子的電荷/磁形式因子被量測。 |
| 1969 | **穆斯堡爾光柵**（核能階作繞射光柵，波長 $\sim 1$ nm）。 |
| 1979 | **天體穆斯堡爾光譜學**（IGR）：銀河系 $\gamma$ 譜、新星距離、黑洞候選體。 |
| 1984 | **穆斯堡爾光譜學用於超導體**（Fe 基高 $T_c$ 超導體的 Fe 位點佔位分析）。 |
| 1990s–2000s | **穆斯堡爾光譜學用於鐵氧體、催化劑、生鐵蛋白（ferritin）、电池材料**。 |
| 2000s | **同步輻射的 Mössbauer 源**（${}^{57}\mathrm{Fe}$ 的同步輻射單光子脈衝，解析度 $\sim 10^{-14}$）。 |
| 2010s | **原子干涉重力儀**（$g$ 的量測精度 $10^{-9}$）——Pound–Rebka 的現代版。 |
| 2017 | **LIGO 的「速度耦合效應」測試**（用原子鐘與光學延遲線比較時間）——重力波相對論性檢驗。 |
| 2023 | **X 射線自由電子雷射（XFEL）**產生的 MHz 單光子脈衝，可用於穆斯堡爾光譜學。 |
