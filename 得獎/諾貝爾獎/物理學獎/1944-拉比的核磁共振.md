# 1944 · 拉比：讓原子自己「回答」一個頻率

> 1944 諾貝爾物理學獎：伊西多·艾薩克·拉比（Isidor Isaac Rabi, 1894–1988，美國）——表彰「他發明了記錄原子核磁性質的共振方法」（for his resonance method for recording the magnetic properties of atomic nuclei）。（本獎延至 1945 年頒發。）

## 懸案（案情提要）

1930 年代的原子物理學已經能非常精確地量測**電子**的磁矩了——斯特恩的分子束實驗可以量到百分之幾。然而，一旦問題換成**原子核**，一切就卡住了。

**卡在哪裡？**

1. **原子核太小。** 質子的磁矩只有 $1\,\mu_N$（核磁子）的量級，而 $\mu_N = 5.05\times10^{-27}\,\mathrm{J/T}$——比玻耳磁子小 $1836$ 倍。**用任何「讓核偏轉、量偏轉量」的辦法，訊號都會被雜訊淹沒。**

2. **核的磁矩不能直接讀。** 你不能把原子核拿出來放在天平上。**唯一的替代方案是「讓核去和別的東西作用，然後由那個東西的變化反推磁矩」。**

3. **核不是自由粒子。** 核被電子雲包著。你量到的可能是「原子」而非「核」的磁矩。

**1938 年，拉比想出了一個極其漂亮的繞路：**

> **不要去「量」磁矩，而要去「找」一個能讓核自發地吸收能量的頻率。**

**物理洞察：**

在靜磁場 $\mathbf{B}_0$ 中，一個具有磁矩 $\boldsymbol{\mu}$ 的核會以**拉莫爾頻率**繞 $\mathbf{B}_0$ 進動：

$$\omega_L = \gamma B_0, \qquad \gamma = \frac{g\mu_N}{\hbar}$$

而在**交變磁場** $\mathbf{B}_1(t) = B_1\cos(\omega t)\,\hat{x}$ 中，核的自旋會在兩個能階之間躍遷：

$$\Delta E = h\nu = g\mu_N B_0 \quad\Longleftrightarrow\quad \nu = \frac{\gamma B_0}{2\pi}$$

**「共振」的意義是什麼？** 當交變場的頻率**恰好**等於拉莫爾頻率時，核會**持續地、累積地**吸收能量（因為每個週期它都回到同一個相位，吸收是疊加的）；而當頻率偏離時，吸收會因相位漂移而互相抵銷。

**所以共振是一個「尖銳的濾波器」：它把雜訊濾掉，只留下 $\nu = \gamma B_0/2\pi$ 這個訊號。**

**這就是拉比的「共振法」的核心，也是NMR（核磁共振）時代的開端。**

**拉比的實驗設計（1938 年）——本案的關鍵工程：**

1. **第一段：不均勻磁場 A（速度選擇器）**——把原子束的速度與動量挑出來，同時讓不同磁矩的原子初步分離；
2. **第二段：均勻磁場 C（量子化場）**——提供靜磁場 $B_C$，使核的能階分裂 $\Delta E = g\mu_N B_C$；
3. **第三段：射頻場（振盪場）**——垂直於 $B_C$ 的射頻電場，頻率 $\nu$ 可掃描；
4. **第四段：不均勻磁場 B（分析場）**——把被「翻轉」的原子與沒被翻轉的原子分開；
5. **第五段：偵測器**——量測落在不同位置的原子束。

**結果：當掃描射頻 $\nu$ 時，偵測器收到一個「共振吸收的谷」——$\nu$ 掃過 $\gamma B_C/2\pi$ 時，原子束的偏轉突然改變。**

**這個「谷」的位置直接給出 $\gamma$；而 $\gamma = g\mu_N/\hbar$ 給出核的 $g$ 因子，也就是核的磁矩。**

**這是一個「用頻率量磁矩」的方案——把「量位移」變成「量頻率」。這是 20 世紀物理學最重大的量測範式轉換之一。**

**而且，這套裝置還帶來了兩個「意外的免費午餐」：**

- **拉比證明了「核自旋」的存在**：1939 年他與庫什（Polykarp Kusch，1955 諾獎）合作，發現**氘核**（$^2\mathrm{H}$）的自旋是 **1**（而不是像質子那樣是 $1/2$）。**這是核物理的一個基本事實，也是日後核磁共振波譜學的基礎。**
- **它開啟了整個「核磁共振」的分支**，直接通向 1952 年的固體 NMR（諾獎）、1960 年代的 MRI（醫學）、1991 年的 NMR 結構解析（化學獎）、2012 年的 NMR 量子計算（物理獎）。

**第四條暗線（科學史地位的暗線）：拉比是「科學的制度化」的重要推手。**

1945 年，**拉比主持了《拉比報告》（"The Rabi Report"）**，這份報告直接導致了**美國國家科學基金會（NSF, 1950）的成立**，也推動了**歐洲核子研究組織（CERN, 1954）的誕生**。**拉比是「科學政策」史上最有力的一次個人影響。**

## 調查

**第一件證物：1930 年代的核心困難——核磁矩的量測為何難。**

讓我們先量化「難」在哪裡，這是理解拉比方法的入口。

**斯特恩-革拉赫型的量測：原子束在磁場梯度中偏轉，偏轉量 $\propto \mu$。**

$$\Delta z = \frac{\mu_z}{B}\cdot\frac{\partial B}{\partial z}\cdot\frac{L^2}{2v^2}$$

**用這套方法量質子磁矩會怎樣？** 質子的磁矩是 $2.79\,\mu_N = 1.41\times10^{-26}\,\mathrm{J/T}$。而電子的磁矩是 $\mu_B = 9.27\times10^{-24}\,\mathrm{J/T}$——**大了 658 倍。**

**如果用同樣的幾何去量質子，偏轉量要小 658 倍。** 在 1930 年代的技術條件下，這等於訊號完全消失。

**拉比的破局之道：「不要量位移，要量頻率」。**

**理由非常精確：** 一個頻率是可以被**累積量測**的——你可以讓原子在共振場裡待上 1 秒，那麼原子吸收的能量（並在之後以光子形式釋放）就是 $\Delta E \times N$，而 $N$ 可以是天文數字。**頻率量測的靈敏度，遠高於位移量測。**

**第二件證物：拉比裝置的六個組件——「串接式」的設計哲學。**

讓我們把拉比的裝置完整寫出，這是全書最值得學習的實驗設計之一。

```
  爐 + 多狹縫准直
        │
        ▼
  ┌──────────────┐
  │  場 A        │  不均勻磁場：速度選擇 + 初步磁矩分離
  └──────────────┘
        │
        ▼
  ┌──────────────┐
  │  場 C        │  均勻磁場 B_C：建立能階分裂 ΔE = g μN B_C
  └──────────────┘
        │
        ▼
  ┌──────────────┐
  │  RF 場       │  交變場，頻率 ν 可掃描；共振時核自旋翻轉
  └──────────────┘
        │
        ▼
  ┌──────────────┐
  │  場 B        │  不均勻磁場：分析場，把翻轉與未翻轉的原子分開
  └──────────────┘
        │
        ▼
     偵測器（熱絲 / 電離計數器）
```

**注意這個結構的精妙之處：拉比把「量測」拆成了「選擇 → 量子化 → 激發 → 分析」四個功能段，每一段由一個磁場負責。** 這與後來所有 NMR 儀器的架構完全一致——**NMR 儀器的「五個磁場」DNA，就是拉比在 1938 年確立的。**

**第三件證物：共振條件的精確物理。**

在靜磁場 $\mathbf{B}_0 = B_0\hat{z}$ 中，核自旋 $\mathbf{I}$ 的哈密頓量：

$$H = -\boldsymbol{\mu}\cdot\mathbf{B}_0 - \boldsymbol{\mu}\cdot\mathbf{B}_1(t) = -g\mu_N\,\mathbf{I}\cdot\left(\frac{\mathbf{B}_0}{\hbar} + \frac{\mathbf{B}_1(t)}{\hbar}\right)$$

**靜場部分：** 能階

$$E_{m} = -g\mu_N m B_0, \qquad m = -I, -I+1, \ldots, +I$$

**相鄰能階間隔：**

$$\Delta E = g\mu_N B_0 = \hbar\gamma B_0$$

**射頻部分（射頻場垂直於靜場）：** 這是一個與時間有關的哈密頓量，其正確處理需要**交互作用表象（interaction picture）**。在射頻場的頻率接近拉莫爾頻率時，系統會「共振地」躍遷。

**共振頻率：**

$$\nu_{\text{res}} = \frac{\gamma B_0}{2\pi} = \frac{g\mu_N B_0}{h}$$

**選擇定則：** $\Delta m = \pm 1$（射頻場是橫向的，只能改變磁量子數）。

**第四件證物：拉比公式——共振的「概率曲線」。**

在射頻場作用下，核自旋在兩個能階間的躍遷概率由量子力學精確給出。對兩個能階組成的二能階系統（此處 $\gamma B_1$ 定義為射頻場的 Rabi 頻率 $\Omega = \gamma B_1$）：

**Rabi 公式：**

$$P_{m\to m\pm1}(t) = \frac{\Omega^2}{\Omega^2 + (\omega - \omega_L)^2}\sin^2\left(\frac{t}{2}\sqrt{\Omega^2 + (\omega-\omega_L)^2}\right)$$

其中 $\omega$ 是射頻場的角頻率，$\omega_L = \gamma B_0$ 是拉莫爾頻率。

**這個公式有三個極重要的特徵：**

**(a) 共振曲線是「洛倫茲線型」。** 在慢旋轉近似（$\Omega \ll |\omega - \omega_L|$）下，躍遷概率

$$P \approx \frac{\Omega^2/4}{(\omega-\omega_L)^2 + \Omega^2/4}$$

即**以 $\omega_L$ 為中心、線寬 $\Delta\omega = \Omega$ 的洛倫茲線型**。**這是 NMR 的「共振線」——所有化學位移與耦合常數的資訊都藏在它的位置與形狀裡。**

**(b) 「量子拍」現象（quantum beats）。** 在精確共振（$\omega = \omega_L$）時，

$$P(t) = \sin^2\left(\frac{\Omega t}{2}\right)$$

**概率以頻率 $\Omega/2\pi$ 振盪**——這就是「Rabi 振盪」。**它是「量子系統會周期性地把自己的資訊吐回環境」的第一次清晰展示，也是 2012 年諾貝爾獎（Wineland 與 Haroche 的量子操控）的直系祖先。**

**(c) 共振可以「累積」。** 因為每次躍遷都與射頻場同相，能量吸收是相干累加的：

$$\Delta E_{\text{absorbed}} = \hbar\Omega\,P(t) \quad\Rightarrow\quad \text{在 } t = \pi/\Omega \text{ 時達最大}$$

**這是「共振能把訊號放大」的物理根源，也是拉比方法比斯特恩方法靈敏千倍的真正原因。**

**第五件證物：熱平衡的起點——「熱中子的類比」不適用，但 Boltzmann 因子適用。**

在熱平衡下，兩個能階的粒子數比由玻耳茲曼分布給出：

$$\frac{N_+}{N_-} = e^{-\Delta E/k_BT} = e^{-h\nu/k_BT}$$

**在 $B_0 = 1\,\mathrm{T}$、質子（$\Delta E \approx 4.1\times10^{-26}\,\mathrm{J}$）、室溫（$k_BT = 4.14\times10^{-21}\,\mathrm{J}$）下：**

$$\frac{N_+}{N_-} = e^{-9.9\times10^{-6}} \approx 1 - 10^{-5}$$

**也就是說，在室溫下核自旋的「極化度」只有百萬分之一！**

**這解釋了為什麼拉比的分子束方法需要「用磁場把原子束『篩』成偏極化的』」——因為樣品的自旋偏極化太弱，必須靠斯特恩-革拉赫式的空間分離來產生一支偏極化束。**

**而在後來的固體 NMR 中，這個問題是用「**高場**」與「**氫化樣品（deuterated solvents）**」來解決的**（把 $^1\mathrm{H}$ 換成 $^1\mathrm{H}$，把溶劑的 $^1\mathrm{H}$ 密度降低以減少背景）。

**第六件證物：拉比與庫什的兩項發現——核自旋的兩個基本事實。**

1938–1939 年，拉比與庫什在哥倫比亞大學合作，得到兩個奠基性的結果：

**發現一：氘核的自旋是 1（而非 $1/2$）。**

${}^{2}\mathrm{H}$ 的核自旋 $I = 1$。這意味著氘核有三個能階（$m = -1, 0, +1$），在 NMR 譜中呈現**三重峰**而非二重峰。

**發現二：核磁矩可以「超過」玻耳磁子的一半。**

對 ${}^{23}\mathrm{Na}$，核磁矩 $\mu = 2.2175\,\mu_N$。**而 $I = 1/2$ 的核，若 $g=2$，磁矩應該不超過 $1\,\mu_N$（Schmidt 上界）。** 氘核的 $\mu = 0.8574\,\mu_N$ 尚在界內，但 **${}^{23}\mathrm{Na}$ 與 ${}^{11}\mathrm{B}$ 的磁矩「越界」**。

**這個「越界」現象在 1930 年代是一個大謎——它證明「核磁矩不是電子式的」，是後來 QCD 給出答案的（核子內夸克貢獻的結果）。** 這直接連回 1943 年斯特恩之謎那條線。

**第七件證物：拉比的「共振」如何成為一個可攜帶的量測工具。**

拉比方法的歷史意義不只在於它量了什麼，而在於**它把「核磁共振」變成一個可以帶到任何實驗室去的技術**：

| 時期 | 裝置 | 應用 |
|---|---|---|
| 1938 | 分子束磁共振（MBMR） | 核磁矩、自旋 |
| 1946 | **Purcell 與 Bloch 的固體 NMR**（1952 諾獎） | 化學位移、固體結構 |
| 1950s | 商業化 NMR 光譜儀（Varian） | 有機化學結構分析 |
| 1952 | **「化學位移」的發現**（化學家） | 官能基鑑定 |
| 1970s | **傅立葉轉換 NMR（FT-NMR）** | 靈敏度提高千倍 |
| 1980s | **核磁共振斷層掃描（MRI）** | 醫學影像 |
| 1990s | **核磁共振顯微術（NMRSM）** | 單細胞、單分子 |
| 2000s | **NMR 蛋白質結構解析**（化學獎 2002、2009） | 結構生物學 |
| 2010s | **NMR 量子計算**（物理獎 2012） | 量子邏輯閘 |

**第七條暗線：拉比的「分子束磁共振」其實是「斯特恩-革拉赫 + 射頻」的組合——這兩位 1943 與 1944 年的諾獎得主，是物理學史上最直接的一次「師承式」接力。**

## 理論裁決

**裁決一：拉莫爾進動的完整量子理論——自旋在磁場中的行為。**

**半古典描述：** 一個磁矩 $\boldsymbol{\mu} = \gamma\mathbf{S}$ 在磁場 $\mathbf{B}$ 中受到力矩

$$\boldsymbol{\tau} = \boldsymbol{\mu}\times\mathbf{B}$$

這導致 $\mathbf{S}$ 繞 $\mathbf{B}$ 進動。從 $\frac{d\boldsymbol{\mu}}{dt} = \boldsymbol{\tau}$：

$$\frac{d\boldsymbol{\mu}}{dt} = \gamma\,\boldsymbol{\mu}\times\mathbf{B}$$

**解出來：**

$$\boldsymbol{\mu}(t) = \mu_\parallel\hat{z} + \mu_\perp\left[\cos(\gamma B t)\hat{x} + \sin(\gamma B t)\hat{y}\right]$$

**拉莫爾頻率：**

$$\omega_L = \gamma B = \frac{g\mu_N B}{\hbar}$$

**注意這個頻率的驚人之處：它與自旋狀態無關。** 不論 $m = +I$ 還是 $m = -I$，進動頻率都相同（這就是拉莫爾定理）。**所以可以用一個射頻場同時「敲」所有原子——這是共振的效率來源。**

**量子描述：** 海森堡方程 $i\hbar\frac{\partial}{\partial t}|\psi\rangle = H|\psi\rangle$，其中

$$H = -\gamma\,\mathbf{S}\cdot\mathbf{B}$$

在 $\mathbf{B} = B\hat{z}$ 下，本徵態 $|I,m\rangle$ 與能量

$$E_m = -\gamma\hbar m B$$

**這是本案的「法律條文」：核的能階在磁場中均勻分裂，分裂間隔正比於 $B$，比例常數就是 $\gamma$——而 $\gamma$ 正是我們要量的東西。**

**裁決二：NMR 的 Bloch 方程——宏觀連續的量子系統描述。**

拉比的實驗處理的是**單原子**，但後來的 NMR 處理的是**巨觀樣品**（$10^{20}$ 個核）。這需要一套連續的描述——**Bloch 方程（1946 年，NMR 諾獎得主本人所立）**：

$$\frac{d\mathbf{M}}{dt} = \gamma\mathbf{M}\times\mathbf{B} - \frac{M_x\hat{x}+M_y\hat{y}}{T_2} - \frac{M_z-M_0}{T_1}\hat{z}$$

| 項 | 物理意義 |
|---|---|
| $\gamma\mathbf{M}\times\mathbf{B}$ | 進動（拉莫爾運動） |
| $-M_\perp/T_2$ | **橫向弛豫**（自旋-spin 相互作用造成的相位散失） |
| $-(M_z-M_0)/T_1$ | **縱向弛豫**（自旋-晶格相互作用造成的能量交換） |

**這三個方程是整個 NMR 與 MRI 理論的基礎。**

**在 $B_0 = B_0\hat{z}$、加上射頻脈衝 $B_1$ 的情況下求解，得到標準的 FID（自由感應衰減）訊號：**

$$S(t) = M_0 e^{-t/T_2}e^{-i\omega_L t}$$

**對 FID 做傅立葉轉換，就得到 NMR 頻譜——這就是 1960 年代 FT-NMR 的原理，也是 1991 年 Ernst 獲化學獎的工作（相位循環、2D NMR）。**

**裁決三：化學位移與高階 NMR——「共振頻率的位置就是物理量」。**

NMR 在化學中的力量來自一個現象：**同一個核在不同化學環境中，感受到的「有效磁場」略有不同。**

**有效場的來源：**

$$\mathbf{B}_{\text{eff}} = \mathbf{B}_0 + \mathbf{B}_{\text{電子雲屏蔽}} + \mathbf{B}_{\text{其他核偶極}}$$

**電子雲屏蔽：** 電子在外部磁場 $\mathbf{B}_0$ 中感應出反向的誘導磁矩，產生的屏蔽場

$$\mathbf{B}_{\text{shield}} = \sigma\,\mathbf{B}_0$$

因此核感受到的場是 $B_0(1-\sigma)$，共振頻率：

$$\nu = \frac{\gamma B_0(1-\sigma)}{2\pi}$$

**化學位移的定義（以 TMS 為基準）：**

$$\delta = \frac{\nu - \nu_{\text{TMS}}}{\nu_0}\times10^6 \quad (\text{單位 ppm})$$

**一個典型數據表（${}^{1}\mathrm{H}$ NMR，90 MHz 儀器）：**

| 官能基 | $\delta$ (ppm) | 裂解模式 |
|---|---|---|
| $\mathrm{CH_3}$（烷烴） | 0.9 | 三重峰 |
| $\mathrm{CH_2}$（烷烴） | 1.3 | 五重峰 |
| $\mathrm{CH}$（烷烴） | 1.5 | 六重峰 |
| $\mathrm{CH_3}$（連 $\mathrm{C=O}$） | 2.1 | 三重峰 |
| $\mathrm{Ar-H}$ | 7.2 | 多重峰 |
| $\mathrm{CHO}$（醛） | 9.8 | 單峰 |
| $\mathrm{OH}$ | 1–5（可變） | 單峰 |

**自旋-自旋耦合：** 相鄰核透過**化學鍵**（$J$ 耦合）或**空間**（偶極耦合）相互作用。**這給出「裂解模式」，也就是「有幾個鄰居」——這正是合成化學家讀出分子骨架的方式。**

耦合常數 $J$ 的量測精度可達 $0.1\,\mathrm{Hz}$，相對精度約 $10^{-9}$——**NMR 是人類能達到的最高精度的「化學量測」。**

**裁決四：拉比的量子力學觀——「共振」是物理學最通用的探針。**

讓我們在本卷中把拉比方法抽象化，因為這個抽象是 20 後半葉物理學的隱性主軸：

> **共振法的通用結構：**
>
> 1. 用一個「控制場」 $B_0$ 建立能階分裂 $\Delta E$；
> 2. 用一個「探測場」 $B_1(t)$ 以頻率 $\nu$ 掃描；
> 3. 在 $\nu = \Delta E/h$ 時，系統以最大概率發生躍遷；
> 4. 把 $\nu$ 與已知的 $B_0$ 對照，即得系統的「特徵頻率」 $\gamma$。

**用這個模板，可以把 20 世紀的幾乎所有精密量測排成一張表：**

| 系統 | 被量的特徵量 | $\Delta E$ | 共振頻率 | 諾獎 |
|---|---|---|---|---|
| 原子核 | $\gamma$ | $g\mu_N B_0$ | $\gamma B_0/2\pi$ | **1944 拉比** |
| 原子 | $\Delta E_{\text{gap}}$ | $h\nu_{\text{光}}$ | 光頻 | 1919 斯塔克、1964 雷射 |
| 分子振動 | 振動能階 | $h\nu_{\text{vib}}$ | 紅外/拉曼 | 1930 拉曼 |
| 電子自旋 | $g\mu_B B_0$ | $g\mu_B B_0$ | ESR 頻率 | 1945 包立 |
| 核 $\gamma$ 射線 | Mössbauer 能階 | $10^{-8}$ eV | $10^{-8}$ eV | 1961 穆斯堡爾 |
| 原子鐘 | 能階 | $h\nu$ | $10^{15}$ Hz | 1989 拉姆齊 |
| 電子自旋（巨觀） | EPR | $g\mu_B B_0$ | 雷達頻段 | 1945 包立 |

**這張表顯示：** **「共振」是 20 世紀物理學把「量子」轉化為「可量測的頻率」的標準手法。** 拉比的 1944 年諾獎，是這條路上最關鍵的一次奠基。

**裁決五：拉比的第二個貢獻——科學制度的建立。**

這部分在諾獎史上罕見地被提及，但它是拉比歷史地位的另一半。

**《拉比報告》（1945）的核心建議：**

1. **美國聯邦政府應資助「基礎科學」**——不是透過軍事或產業部門，而是透過一個**獨立的機構**；
2. **該機構應由科學家自己管理**，而非由行政官員管理；
3. **經費應支持「個人」與「小組」**，而非只支持大型設備。

**結果：**
- **1950 年，美國國家科學基金會（NSF）成立**，第一任主席是 Alan T. Waterman（拉比的學生）；
- **1954 年，CERN 成立**，拉比是主要的鼓吹者之一（他在 1949 年訪問歐洲，向各國科學界提出「各國共同出資、共享成果」的「大科學」構想）；
- **1960 年代，美國的「大科學」體制成形**。

**拉比在 1944 年獲諾獎、1945 年寫出這份報告、1946 年成為哥倫比亞大學物理系主任——他在一年內完成了「科學家」與「科學組織者」的双重轉身。**

**這是一個「諾獎得主的影響力不只在實驗室裡」的案例，也解釋了為什麼諾獎委員會會給他一個「方法論」性質的獎——拉比真正的方法論是「把問題轉成可量測的形式」。**

## 後果

| 年份 | 影響 |
|---|---|
| 1938 | **分子束磁共振方法**問世；拉比與 Kusch 發表《A New Method of Measuring Nuclear Magnetic Moment》。 |
| 1939 | 發現**氘核自旋為 1**；發現核磁矩「越界」現象。 |
| 1944 | **諾獎頒發**（1945 年 11 月）。 |
| 1945 | **《拉比報告》** → 1950 年 NSF 成立、1954 年 CERN 成立。 |
| 1946 | **Bloch 方程**建立；**Purcell 與 Bloch 的固體 NMR**（1952 諾獎）。 |
| 1950 | 商業 NMR 光譜儀問世（Varian）；**化學位移**成為化學家的基本工具。 |
| 1952 | 布洛赫與珀塞爾獲諾貝爾物理學獎；NMR 進入化學界。 |
| 1959 | **Ernst 的「時間域」 Fourier 轉換 NMR** 開啟 2D NMR。 |
| 1960s | **MRI（核磁共振斷層掃描）** 問世（Lauterbur 1973 醫學獎）。 |
| 1970s | **超導磁體**用於 NMR（900 MHz 的儀器問世）。 |
| 1980s | **NMR 顯微術**；**拉比振盪**成為量子控制的基本概念。 |
| 1989 | 拉姆齊的「分離振盪場」——拉比方法的高精度化（諾獎）。 |
| 1991 | **Ernst 獲諾貝爾化學獎**（高解析度 NMR）。 |
| 2002 | **Wüthrich 獲化學獎**（NMR 蛋白質結構解析）。 |
| 2012 | **Haroche 與 Wineland 獲物理學獎**（量子操控）——**Rabi 振盪的現代版。** |
| 2017 | **超導量子干涉儀（SQUID）** 用於 NMR 與量子計算。 |
| 2023 | MRI 與 PET 融合成像技術發展（生理醫學獎領域）。 |
