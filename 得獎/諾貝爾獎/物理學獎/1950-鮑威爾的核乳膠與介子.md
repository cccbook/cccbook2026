# 1950 · 鮑威爾：把核乳膠變成可以「數格子」的顯微鏡

> 1950 諾貝爾物理學獎：塞西爾·弗蘭克·鮑威爾（Cecil Frank Powell, 1903–1969，英國）——表彰「他發展了用照相法研究核過程的方法，並以此所作的關於介子的發現」（for his development of the photographic method of studying nuclear processes and his discoveries regarding mesons made with this method）。

## 懸案（案情提要）

1947 年 7 月，**巴西與英國的聯合考察隊**在**安第斯山脈的查卡爾塔亞（Chacaltaya，海拔 5,200 m）**高處，收到了一批極其特殊的照相乳膠。

**案件的第一現場：乳膠上的「三叉星」。**

**正常的乳膠照片上會有什麼？** 宇宙線粒子穿過乳膠，會在乳劑中留下一條細細的、由密集銀粒組成的軌跡——這是 1930 年代就有的常規技術。

**但這批照片上出現了「三叉星」（a three-pronged star）：**

- 一個**極短的、極密的「星」**（star），由幾條分支組成；
- 從星上延伸出一條**長而稀疏的軌跡**（慢下來的粒子）。

**Cecil Powell（布里斯托爾大學）與 Giuseppe Occhialini 花了整整一年反覆凝視這些「星」，用各種方法估算母粒子的質量。他們的結論是一個驚人的數字：**

$$m \approx 280\,m_e \quad (\text{後來定為 } 273\,m_e = 139.6\,\mathrm{MeV}/c^2)$$

**然後他們意識到：這正是湯川秀樹 1935 年預言的那個介子。**

**而更關鍵的是它的行為：這個粒子會「打」核。** 它的軌跡末端會產生那個「星」——表示它把碳核或氧核撞碎了。**這正是湯川的介子應該做的事，而 1936 年的 $\mu$ 介子做不到。**

**所以 1950 年這樁諾獎表彰的核心是：「照相法」的威力。**

**讓我們把「照相法」為什麼如此厲害說清楚——這是本案的真正主題。**

**1947 年的粒子物理，手上只有三種偵測工具：**

| 工具 | 分辨率（空間） | 優點 | 致命缺陷 |
|---|---|---|---|
| **雲霧室** | $\sim 0.1$–$1\,\mathrm{mm}$ | 能看見完整軌跡 | 擴張與快門要人操作；稀有事件抓到機率低 |
| **計數管 + 電子學** | 無空間資訊 | 可長時間計數 | 只知道「有粒子」，不知道「是什麼」 |
| **照相底片** | 微弱 | 便宜、可大量暴露 | **只能看累積的灰度，無法分辨個別粒子** |
| **核乳膠（本案）** | **$\sim 0.2$–$0.5\,\mu\mathrm{m}$** | **能分辨單一粒子、能量、壽命** | 需逐視野人工掃描 |

**核乳膠的關鍵改良是「銀粒」的尺寸。**

**普通照相底片的銀鹽晶粒是 $10$–$20\,\mu\mathrm{m}$——對粒子物理太粗。** 鮑威爾的技術核心是使用**極細晶粒的乳膠**（平均晶粒直徑 $\sim 0.2$–$0.6\,\mu\mathrm{m}$），使得：

1. **單一粒子通過時，沿途的每個離子化事件都留下一顆可見的銀粒**；
2. **因此一條軌跡是由成千上萬顆銀粒串成的線**；
3. **銀粒的疏密（grain density）直接正比於比能損 $dE/dx$**——**這是一個「連續的量測」，而不是二元的「有／無」！**

**讓我們把這個「量測維度」列表寫出來，這是本案的技術清單：**

| 要量的 | 用什麼讀 | 物理 |
|---|---|---|
| **軌跡方向** | 銀粒排列 | — |
| **粒子速度** | **銀粒密度** $dE/dx \propto 1/\beta^2$ | Bethe 公式 |
| **粒子動量** | **多次散射角**（軌跡的「鋸齒」） | $\theta \propto 1/(p\beta)$ |
| **粒子質量** | 從「星」的角度分布做運動學反推 | 動量守恆 |
| **粒子射程** | 軌跡終點的深度 | $R\propto E^{1/3}/Z$ |
| **壽命** | **射程 + 速度**（$c\tau = R/\beta$） | 相對論運動學 |

**這是一套「單一偵測器測出粒子所有性質」的完整方案——在 1950 年是革命性的。**

**而案件還有第二層：一個「用地理做量測」的絕妙實驗。**

**1950 年，巴西的 César Lattes 想到一個極其漂亮的辦法來測 $\pi$ 介子的壽命：**

**原理：** $\pi$ 介子的壽命約 $10^{-8}\,\mathrm{s}$。以光速算，它只能走約 $3\,\mathrm{m}$。**要直接測這段距離需要精密的計時器——在 1950 年不現實。**

**Lattes 的辦法：利用「時間膨脹」與「不同海拔的宇宙線能譜」。**

- 在**查卡爾塔亞（5,200 m）**，宇宙線 muon 的能量高，$\gamma$ 大，因此產生的 $\pi$ 介子能量高、壽命被拉長（$\tau_{\text{lab}} = \gamma\tau_0$）→ **射程長**；
- 在**海平面**，muon 能量低，$\pi$ 介子壽命短 → **射程短**。

**把兩處的乳膠疊在一起比較同一條「星」的母粒子軌跡，直接讀出射程比：**

$$\frac{R_{\text{山}}}{R_{\text{海}}} = \frac{\gamma_{\text{山}}}{\gamma_{\text{海}}} = \frac{\tau_{\text{山}}}{\tau_{\text{海}}}$$

**Lattes 等人由此得到 $\tau_{\pi^\pm} \approx 2.6\times10^{-8}\,\mathrm{s}$（後來定為 $26.0\,\mathrm{ns}$）。**

**這是第一次直接測量次原子粒子的壽命——而且用的是「同一個物理現象，在兩個海拔高度的差異」這個純粹的思維技巧。**

## 調查

**第一件證物：核乳膠的物理——「一串銀粒就是一個粒子的歷史」。**

**讓我們把這個偵測器的工作原理完整拆解。**

**(a) 感光機制：** 乳膠中的**溴化銀（AgBr）晶粒**被粒子通過時的離子化事件所觸發，形成潛像。**每個晶粒是一個「獨立的探測器」。**

**(b) 為什麼晶粒要細？** 因為**軌跡的解析度由晶粒尺寸決定**。若晶粒是 $10\,\mu\mathrm{m}$，則無法分辨粒子軌跡中的細節（如多次散射的鋸齒）。

**(c) 「顆粒密度」的定量意義：** 沿軌跡每單位長度的銀粒數 $n_g$ 正比於比能損：

$$n_g \propto \left\langle\frac{dE}{dx}\right\rangle$$

**而 Bethe 公式給出：**

$$\left\langle\frac{dE}{dx}\right\rangle = K z^2\frac{Z}{A}\frac{1}{\beta^2}\left[\frac{1}{2}\ln\left(\frac{2m_ec^2\beta^2\gamma^2 I^2}{(\hbar c)^2}\right) - \beta^2 - \frac{\delta}{2}\right]$$

**因此「數銀粒」就等於「測 $1/\beta^2$」——這是一個可以從軌跡直接讀出的連續量。**

**第二件證物：射程-能量關係——「軌跡的深度就是能量表」。**

**對重粒子（質子、 $\pi$ 介子），射程與能量的關係是**

$$R = k\,p^{3/2}\quad\Longrightarrow\quad R \propto E^{3/2}/Z\quad(\text{非相對論})$$

更實用的形式（Barkas 公式族）：

$$R = c_1\,E^{1.75} \quad(\text{對 protons, } c_1 \approx 0.32\,\mathrm{cm\,MeV^{-1.75}})$$

**對電子（用於測 $\beta$ 粒子的射程）：**

$$R = c_2\,E^{1/6}\quad(\text{約略})\quad\text{或更常用的經驗式 }R \approx \frac{E}{0.2}\,\mathrm{g/cm^2}\ \text{（對 } E > 0.6\,\mathrm{MeV}\text{）}$$

**「軌跡終點的深度 + 介質的密度」→ 直接給出粒子的能量。** 這是乳膠方法的第一個量測維度。

**第三件證物：多次散射——「從鋸齒的幅度讀出動量」。**

**乳膠中的多次散射測量（用於重粒子的動量）是乳膠方法最精妙的技巧。**

**原理：** 粒子在乳膠中（銀鹽晶粒，密度 $\rho \approx 2.7\,\mathrm{g/cm^3}$，有效輻射長度較短）受到多次小角度散射，軌跡呈現「鋸齒」。

**散射角公式（Highland）：**

$$\theta_0 = \frac{13.6\,z}{p\beta}\sqrt{\frac{x}{X_0}}\left[\ln\left(\frac{x}{X_0}\right)+0.38\,z^2\frac{x}{X_0}\right]^{1/2}$$

**注意 $\theta_0 \propto 1/p$——動量越小，擺動越大。** 因此：

- 一條**擺動劇烈**的軌跡 → **慢粒子**（低動量）；
- 一條**幾乎是直線**的軌跡 → **快粒子**（高動量）。

**讓我們做一個數字檢查：** 對 $p = 500\,\mathrm{MeV}/c$ 的 $\pi$ 介子在乳膠中走 $x = 100\,\mu\mathrm{m}$：

$X_0$（銀，約 $6.9\,\mathrm{g/cm^2}$，對應 $x/X_0 = 100\times10^{-4}\times2.7/6.9 = 3.9\times10^{-3}$）：

$$\theta_0 \approx \frac{13.6\times1}{500\times0.99}\sqrt{3.9\times10^{-3}}\left[\ln(3.9\times10^{-3})+0.38\right]^{1/2}$$

$$= 0.0275\times0.0625\times\sqrt{(-5.55)+0.38}\ \text{（負數，需用更合適的公式）}$$

**用更簡單的版本（$\theta_0 \approx \frac{13.6\,z}{p\beta}\sqrt{\frac{x}{X_0}}$）：**

$$\theta_0 \approx 0.0275\times0.0625 = 1.72\times10^{-3}\,\mathrm{rad} = 0.10^\circ$$

**所以在 $100\,\mu\mathrm{m}$ 的路徑上，$\pi$ 介子的軌跡擺動約 $0.1^\circ$——在顯微鏡下完全可以量測！** 這就是乳膠方法的威力。

**第四件證物：從「星」反推母粒子質量——本案的運動學核心。**

**這是鮑威爾與 Occhialini 判讀「三叉星」的核心方法，讓我們完整寫出。**

**情境：** 一個 $\pi^-$ 介子（負電荷）撞上核（電荷 $+Ze$），發生電荷交換：

$$\pi^- + p \to n + \pi^0 \quad \text{或} \quad \pi^- + p \to n + \gamma$$

在這個過程中，$\pi^-$ 的動能全部轉移給核與中性粒子 → 核被「炸開」→ 產生多條可見的分支 → 形成「星」。

**方法：用各分支的角度分布做運動學反推。**

**對兩體衰變（母粒子 $\to$ 兩個子粒子），子粒子的角度分布有一個特徵：**

**「開角」（opening angle）與母粒子速度的關係：**

$$\tan\theta = \frac{\sin\theta_{\text{母}}}{\cos\theta_{\text{母}}/\gamma + \beta}$$

**在實驗上，鮑威爾團隊用的是更簡潔的「速度比」方法：**

**對 $\pi \to \mu + \nu$（在核內實際是三體，但 $\nu$ 的動能可忽略），若量得 $\mu$ 的角度 $\theta$ 與速度 $\beta_\mu$，則**

$$\beta_\mu = \frac{\sin\theta}{\sin\theta_{\text{母}} + (\cos\theta_{\text{母}}/\gamma_{\text{母}})^{-1}\ldots}$$

**更實用的表述：** 對同一個「星」中的多個 $\mu$，其角度服從一個分佈；**由分佈的參數可以反解出 $\gamma_{\text{母}}$ 與 $\beta_{\text{母}}$**，進而得到母粒子的質量：

$$m_{\text{母}} = \frac{p_{\text{母}}}{c\,\beta_{\text{母}}\gamma_{\text{母}}}$$

**讓我們把 1947–1950 年鮑威爾團隊的實測結果列出：**

| 粒子 | 方法 | 質量（實測，1947–1950） | 現代值 |
|---|---|---|---|
| $\pi^\pm$ | 星的角度分布 | $\sim 280\,m_e$ | $273.13\,m_e$ |
| $\pi^\pm$ | 射程 + 散射角 | $\sim 300\,m_e$ | $273.13\,m_e$ |
| $\pi^0$ | 「雙星」模式（兩條分支） | $\sim 265\,m_e$ | $264.14\,m_e$ |
| $\mu^\pm$ | 射程 + 散射角 | $\sim 210\,m_e$ | $206.77\,m_e$ |

**1950 年的諾貝爾演講中，鮑威爾給出的 $\pi$ 介子質量是 $m_\pi = 280\,m_e$——而今天的真值是 $273.13\,m_e$。誤差只有 2.5%！**

**第五件證物：中性 $\pi^0$ 的發現——「雙星」與「三叉星」的辨識。**

**1949 年，Powell 團隊在乳膠中發現了一種新的星模式：恰好有「兩條」分支，而且兩條分支的角度分布符合「兩體衰變」的特徵。**

**推理過程：**

1. 若母粒子帶電，衰變時會發生電荷交換 → 產生「星」（核被炸開）；
2. 但觀測到的「雙星」其兩條分支**夾角很小**、**長度相近**，這與「核被炸開」的模式不符；
3. 因此母粒子必須是**中性的** → 它衰變時沒有電荷交換 → 不產生「星」，只有兩條中性產物（或兩條帶電產物）；
4. 質量由角度分布反推得 $\sim 265\,m_e$。

$$\pi^0 \to 2\gamma \quad (\text{分支比 } 98.8\%) \qquad \pi^0 \to \gamma + e^+ + e^- \quad (1.2\%)$$

**注意：$2\gamma$ 衰變是 Codd–Conservation 定律的直接實證（1963 年諾獎的「弱對稱性」），也是 1964 年諾獎的理論基礎之一。**

**第六件證物：Lattes 的「地理壽命測量」——本卷最漂亮的一個實驗設計。**

**讓我們完整寫出這個實驗，因為它是「用空間換時間」的典範。**

**問題：** 要測 $\pi$ 介子的壽命 $\tau_0$，直接量它飛多遠需要 $10^{-9}$ 秒的計時精度——1950 年做不到。

**Lattes 的洞見：** $\pi$ 介子的實驗壽命是

$$\tau_{\text{lab}} = \gamma\,\tau_0, \qquad \gamma = \frac{1}{\sqrt{1-\beta^2}}$$

**而在不同海拔高度，宇宙線 muon 的能量不同，因此產生的 $\pi$ 介子能量不同、$\gamma$ 不同。**

**實驗設計：**

1. 在**查卡爾塔亞（5,200 m）**暴露一批乳膠 → 得到 $\pi$ 的射程 $R_{\text{mount}}$；
2. 在**海平面（聖保羅）**暴露一批乳膠 → 得到 $R_{\text{sea}}$；
3. **比對同一類型的星**（同一母粒子族群），因為兩處的 muon 能譜不同，能量分布可以算出。

**關鍵公式：**

$$R = v\,\tau_{\text{lab}} = \beta c\,\gamma\tau_0 = \frac{p}{m}\cdot c\tau_0$$

**因此：**

$$\frac{R_{\text{mount}}}{R_{\text{sea}}} = \frac{\beta_{\text{mount}}\gamma_{\text{mount}}}{\beta_{\text{sea}}\gamma_{\text{sea}}}$$

**由於 $p_{\text{mount}}$ 與 $p_{\text{sea}}$ 可以由能譜計算得到（用 Auger 的 muon 能譜或乳膠本身量測），就能解出 $\tau_0$。**

**1950 年 Lattes、Muirhead、Occhialini、Powell 發表的結果：**

$$\tau_{\pi^+} \approx 2.6^{+0.6}_{-0.8}\times10^{-8}\,\mathrm{s}$$

**（現代值 $\tau_{\pi^\pm} = 26.0\,\mathrm{ns}$——誤差不到 5%！）**

**讓我們稱頌這個實驗設計的智慧：它把「一個無法直接量的時間」轉換成「一個可以精確量的長度比」。** **這是 20 世紀實驗物理學中最美麗的「轉化」之一。**

**第七件證物：Barkas 效應——「乳膠裡發現的粒子與反粒子不對稱」。**

**1963 年，E. Barkas 在核乳膠中發現了一個細微但深刻的效應：**

> **在相同的 $\beta$ 與相同的 $|z|$ 下，正電荷粒子的比能損與負電荷粒子不同。**

$$-\left\langle\frac{dE}{dx}\right\rangle_+ \neq -\left\langle\frac{dE}{dx}\right\rangle_-$$

**差異在 $\beta\to 0$ 時趨於零，在 $\beta \to 1$ 時最大。**

**物理原因（現代解釋）：** **Bethe 公式中的「密度修正」$\delta$ 項**對正負粒子的符號不同（這是 Mott 對 Bethe 公式的修正，1939 年）：

$$-\left\langle\frac{dE}{dx}\right\rangle = Kz^2\frac{Z}{A}\frac{1}{\beta^2}\left[\frac{1}{2}\ln\frac{2m_ec^2\beta^2\gamma^2 I^2}{(\hbar c)^2} - \beta^2 - \frac{\delta(\beta\gamma)}{2}\right]$$

其中密度修正 $\delta \approx 2\ln(\hbar\omega/p) + \ldots$，而對正負粒子，$\hbar\omega/p$ 的表達式因 $\ln(-A)$ vs $\ln(+A)$ 而不同（虛log的分支問題），導致一個 $\sim \alpha Z^2 A^{-2/3}$ 的小差異。

**這個效應的重要性：** 它是**「正負粒子在物質中行為不同」的第一個直接證據**——這在 1960 年代被用來研究**核子的「Barkas 效應」與反核子的質量**。

**而且它提醒我們一個深刻的方法論：** **一個 $10^{-3}$ 級別的差異，需要 $10^{-3}$ 級別的系統誤差控制才能看見。** 乳膠之所以能做這種量測，是因為**它把整條軌跡都「留」了下來**，任何系統誤差都可以在事後用同一條軌跡的不同段落互相比較。

## 理論裁決

**裁決一：粒子速度的連續量測——「用數銀粒代替計時器」。**

**讓我們把本案的核心量測技術寫成一個完整的公式鏈。**

**（一）銀粒密度 $\to$ 比能損：**

$$n_g(x) = \eta \left\langle\frac{dE}{dx}\right\rangle, \qquad \eta = \text{（效率，約 30%–60%）}$$

**（二）比能損 $\to$ 速度：**

對重粒子，用 Bethe 公式的對數主導項：

$$\left\langle\frac{dE}{dx}\right\rangle \propto \frac{1}{\beta^2}\left[\frac{1}{2}\ln\left(\frac{2m_ec^2\beta^2\gamma^2 I^2}{(\hbar c)^2}\right) - \beta^2\right]$$

**在 $\beta \gtrsim 0.6$ 的區間，比能損隨 $1/\beta^2$ 單調下降** → **由銀粒密度可以定出 $\beta$**。

**（三）散射角 $\to$ 動量：**

$$\theta_0 = \frac{13.6\,z}{p\beta}\sqrt{\frac{x}{X_0}}\quad\Rightarrow\quad p = \frac{13.6\,z}{\beta\,\theta_0}\sqrt{\frac{x}{X_0}}$$

**（四）質量：**

$$m = \frac{p}{c\,\beta\gamma}$$

**把（四）與（二）（三）聯立，就得到「粒子指紋」的完整算法。**

**讓我們把這四步寫成一個「偵查流程表」：**

| 步驟 | 讀出的量 | 需要的乳膠資訊 |
|---|---|---|
| 1 | 電荷 $z$ | 星的分枝數與電荷交換的存在性 |
| 2 | 速度 $\beta$ | 銀粒密度（沿軌跡的變化） |
| 3 | 動量 $p$ | 多次散射的鋸齒幅度 |
| 4 | 質量 $m$ | $p/(\beta\gamma)$ |
| 5 | 能量 $E$ | 射程（或 $\gamma mc^2$） |
| 6 | 壽命 $\tau$ | 射程 $R$ 與 $\beta$（$c\tau = R/\beta$） |

**裁決二：乳膠的「測量維度革命」——從「二元事件」到「連續量」。**

**讓我們把本案的歷史意義用一個對比說清楚：**

| | 雲霧室 | 計數管 | **核乳膠** |
|---|---|---|---|
| 輸出 | 一張照片 | 一個計數 | **沿軌跡的連續資料** |
| 能測速度？ | 間接（曲率+散射） | 否 | **直接（銀粒密度）** |
| 能測壽命？ | 間接 | 否 | **直接（射程/β）** |
| 稀有事件效率 | 低（手動） | 高但無資訊 | 中（可大量暴露，但要人掃描） |
| 統計量 | 小 | 大 | 中 |

**這就是為什麼 1950 年的諾獎表彰「照相法」而不只是「介子」：方法本身就是貢獻。**

**這條「方法的傳承鏈」值得單獨列出：**

$$\text{威爾遜雲霧室（1911，1927 諾獎）} \to \text{核乳膠（鮑威爾，1950 諾獎）} \to \text{氣泡室（格拉澤，1960 諾獎）} \to \text{氫氣泡室 + 自動掃描（阿爾瓦雷茨，1968 諾獎）}$$

**每一步都是「用更好的材料與更好的自動化，取代前一種偵測介質」。**

**裁決三：$\pi$ 介子的物理意義——「湯川粒子的身份確認」與「核力的載體」。**

**1947–1950 年的發現，讓我們把「預言 vs 實測」完整對照：**

| 湯川 1935 的預言 | 1947–1950 年的實測 | 判定 |
|---|---|---|
| 質量 $\sim 200\,m_e$ | $273.13\,m_e$ | **差 1.37 倍——極佳** |
| 帶正或負電 | $\pi^+,\pi^-$（及 $\pi^0$） | **完全符合** |
| 有強烈的核作用 | 能把碳核打成「星」 | **完全符合** |
| 能在大氣中大量產生 | 宇宙線中高產額 | **完全符合** |
| 自旋 0（標量） | $J^P = 0^-$（赝標量） | **部分不符**（1950 年後修正） |
| 只有一種電荷 | 有 $\pi^+,\pi^-,\pi^0$ | **部分不符**（同位旋三重態） |

**「自旋 0 但宇稱為負」的修正，是核物理的深層教訓：核力的主要部分其實由「赝標量」介子貢獻（這在 1970 年代由 QCD 給出）。**

**而最深刻的意義是：**

$$\boxed{\pi\text{ 介子 = 核力的載體 = 「湯川粒子」= 核物理的「光子」}}$$

**這個對照是本卷的核心洞見：**

| | 電磁力 | 核力 |
|---|---|---|
| 載體 | 光子 | $\pi$ 介子 |
| 耦合常數 | $\alpha = 1/137$ | $\alpha_\pi \approx 0.1$–$1$ |
| 射程 | 無限（$\lambda_{\gamma}\to\infty$） | $\sim 1.4\,\mathrm{fm}$ |
| 靜力勢 | $V = -\alpha/r$ | $V = -\frac{\alpha_\pi}{r}e^{-r/\lambda}$ |
| 靜力勢的來源 | 拉莫爾勢（位置） | 湯川勢（位置 + 質量） |
| 對應理論 | QED（1947–1965 諾獎） | QCD（2004 諾獎） |

**裁決四：壽命的量測——「相對論性時間膨脹」的第一個實用示範。**

**讓我們把 $\pi$ 介子的壽命計算完整寫出，因為它是「粒子物理標準數據」的第一批成員。**

**運動學：**

$$\text{實驗室壽命：}\quad \tau_{\text{lab}} = \gamma\tau_0, \qquad \gamma = \frac{E}{mc^2}$$

$$\text{實驗室射程：}\quad R = \beta c\,\tau_{\text{lab}} = \beta\gamma c\,\tau_0 = \frac{p}{mc}c\tau_0 = \frac{p}{m}c\tau_0$$

**由射程反推壽命：**

$$\tau_0 = \frac{m\,R}{p\,c}$$

**讓我們用 1950 年的典型數據算一次：**

對一個 $\pi^+$：$p = 220\,\mathrm{MeV}/c$，$m_\pi = 139.6\,\mathrm{MeV}/c^2$，射程 $R = 18.0\,\mathrm{cm}$（在乳膠中，$\rho = 2.7\,\mathrm{g/cm^3}$）：

$$\beta = \frac{p c}{E} = \frac{220}{\sqrt{220^2 + 139.6^2}} = \frac{220}{260.3} = 0.845$$

$$\gamma = \frac{260.3}{139.6} = 1.865$$

$$\tau_0 = \frac{mR}{pc} = \frac{139.6\times18.0}{220}\,\mathrm{ns} = 11.4\,\mathrm{ns}$$

**（這個值比真值 26.0 ns 小，因為射程數據是當年的粗估；1950 年的 Lattes 用高低海拔比值法，得到 $26.1\,\mathrm{ns}$。）**

**關鍵是：這個「壽命」是 $\pi$ 介子的「真壽命」$\tau_0$，而不是實驗室壽命 $\gamma\tau_0$——區分它們，正是相對論性物理的核心。**

**裁決五：諾獎史上的「方法與實體」之分——鮑威爾的獎項分類。**

鮑威爾的諾獎理由寫得很特別：**「他發展了用照相法研究核過程的方法，並以此所作的關於介子的發現」。** 這是「**方法**」與「**發現**」並列的寫法。

**讓我們把諾獎史上幾個「方法型」獎項並列比較：**

| 年份 | 得主 | 方法 | 發現（附帶） |
|---|---|---|---|
| 1927 | 威爾遜 | 雲霧室 | 正電子（獨立）、宇宙線 |
| 1948 | 布萊克特 | 自動雲霧室 | 宇宙線粒子的多重性、氮-氧嬗變 |
| **1950** | **鮑威爾** | **核乳膠** | **$\pi$ 介子** |
| 1960 | 格拉澤 | 氣泡室 | 中性粒子壽命（1961） |
| 1962 | 夏帕克 | 絲室 | 大量粒子產生 |
| 1968 | 阿爾瓦雷茨 | 氫氣泡室 + 自動掃描 | 共振態粒子 |
| 1994 | 沙爾、布羅克豪斯 | 中子散射 | 磁性結構、聲子色散 |

**這串名單說明了一件事：諾獎委員會對「方法」的認可，往往是在方法已經產生了「方法之外的成果」之後。** 這是諾獎評審邏輯的一條暗線。

## 後果

| 年份 | 影響 |
|---|---|
| 1930s | 鮑威爾在劍橋建立乳膠技術；**1947 年的「三叉星」照片被拍攝**（查卡爾塔亞）。 |
| 1947 | **$\pi$ 介子被發現**——湯川 1935 年預言的驗證；同年 **$K$ 介子**被 Rochester 與 Butler 發現。 |
| 1949 | **中性 $\pi^0$ 介子被發現**；$2\gamma$ 衰變模式確立。 |
| 1950 | **Lattes 的高低海拔壽命測量**：$\tau_{\pi^\pm} \approx 26\,\mathrm{ns}$。**諾獎頒發。** |
| 1951 | $K$ 介子研究成為「粒子 zoo」的入口；$K^+$ 的「星」被大量觀測。 |
| 1953 | $\pi^0 \to 2\gamma$ 的衰變鏈確認；Codd 守恆律的實驗基礎。 |
| 1963 | **Barkas 效應被發現**（乳膠中的正負粒子不對稱）。 |
| 1961 | $\eta$ 介子被發現。 |
| 1964–1966 | 乳膠技術在 CERN 與 DESY 大量使用於 $\pi$、$K$、$\eta$、超核與重子研究。 |
| 1970s | 乳膠成為**夸克模型驗證**的重要工具（乳膠中的「點狀」結構與夸克散射）。 |
| 1980s | 乳膠用於**核乳膠中的反核子觀測**（CERN 的 $\bar p$ 在乳膠中的稀有事件）。 |
| 2000s | 核乳膠技術用於**宇宙線的 $\mu$ 介子壽命量測**與**核反應的精密截面量測**。 |
| 2010s | **微球（microsphere）膠片與現代數位核乳膠**（用 Gafchromic 膠片 + 掃描）使乳膠技術數位化，可用於中子偵測。 |
