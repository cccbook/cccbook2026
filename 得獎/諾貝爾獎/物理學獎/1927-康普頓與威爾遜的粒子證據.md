# 1927 · 康普頓與威爾遜：光與粒子的最終對證

> 1927 諾貝爾物理學獎：阿瑟·霍利·康普頓（Arthur Holly Compton, 1892–1962，美國）與查爾斯·威爾遜（Charles Thomson Rees Wilson, 1869–1959，英國）——表彰「康普頓：以他命名的效應的發現；威爾遜：透過水蒸氣凝結使帶電粒子軌跡可見的方法」（for his discovery of the effect named after him / for his method of making the paths of electrically charged particles visible by condensation of vapour）。

## 懸案（案情提要）

1923 年是「光究竟是波還是粒子」這樁百年懸案的轉捩點。而轉捩點是一個非常簡單的實驗。

**康普頓的問題。** X 射線被電子散射後，波長會改變嗎？1921–1923 年間，康普頓在華盛頓大學用莫塞萊譜線（**Mo K$\alpha$**，波長 $\lambda_0 = 0.071\,\mathrm{nm}$，正是 1917 年巴克拉案建立的元素特異譜線）作為單色光源，讓它撞擊石墨中的自由電子，用水晶分光計量測散射後的波長。

結果：**散射後的 X 射線波長變長了**，而且波長增量只取決於**散射角**，與電子是什麼材料無關：

$$\Delta\lambda = \lambda' - \lambda_0 = \frac{h}{m_e c}(1 - \cos\theta)$$

這就是**康普頓位移公式**。注意三個驚人的特徵：

1. $\Delta\lambda$ 只與**散射角** $\theta$ 有關；
2. $\Delta\lambda$ 與散射物質的性質**無關**（這排除了「化學結合狀態影響」的解釋）；
3. $\Delta\lambda$ 是一個**普適常數**：$\frac{h}{m_e c} = 2.4263\times10^{-12}\,\mathrm{m}$ —— 這就是**康普頓波長** $\lambda_C$。

**為什麼這個結果如此致命？** 讓我們對比兩個預測：

- **波動論（Thomson 散射 / 干涉）**：X 射線是波，散射應該是**相干干涉**的結果，波長**不變**（就像光在粒子上的衍射不會改變光的波長）；
- **粒子論（光量子）**：X 射線是光子，它與電子做**動量守恆的碰撞**，所以光子的能量與動量都會改變，波長必然改變。

康普頓的實驗給出**波長改變**，且改變量恰好等於兩粒子碰撞的相對論性運動學所預測的值。

讓我們把這個推導完整寫出來，因為它是 20 世紀物理學中最漂亮的一個「假設—推導—驗證」鏈條。

**威爾遜的問題。** 與康普頓的「定量」互補，威爾遜解決的是「**看見**」的問題。1897 年 J. J. 湯姆森發現電子（1906 諾獎），但他只能量測電子的電荷質量比——**他看不到電子的軌跡**。物理學家想知道：電子在物質中究竟是怎樣運動的？它是一條直線穿過，還是散射成曲折的路徑？

威爾遜 1911 年的答案：擴散雲室（cloud chamber）。

原理簡單得令人驚訝：把容器中的空氣**用酒精**潤溼，再**急劇膨脹**容器（用活塞），空氣溫度驟降，酒精蒸氣**過飽和**，於是**離子（電子經過留下的離子化軌跡）成為凝結核**，水蒸氣在離子周圍凝結成細小水滴。於是**電子的路徑以一串可見的小水滴被「畫」出來**。

1912–1913 年，威爾遜用這個裝置觀察到：**電子在氣體中的路徑是曲折的**——在多次電離碰撞之間直線飛行，而在碰撞點改變方向。這直接測出了**電子的散射截面**，並首次顯示了**單次碰撞之間的平均自由程**。

威爾遜在 1927 年的諾貝爾演講中寫道，這個裝置「**讓我們能夠看見電子**」——這是本卷最動人的一句話。

**而兩位得主的貢獻在物理上是同一件事的兩面：康普頓證明光帶著動量（粒子性），威爾遜讓人看見帶電粒子的運動軌跡（粒子性）。兩者合起來，共同推翻了「光純粹是波」的完整版，並確立了「一切皆量子」的圖景。**

1927 年諾獎還有一層歷史意義：這是**第一次把諾貝爾物理學獎頒給兩個不同的實驗風格**——一個是「精密計數與譜學」（康普頓），一個是「直覺性的視覺發明」（威爾遜）。委員會的報告這樣描述威爾遜的貢獻：「他的方法使得帶電粒子的軌跡可以通過水蒸氣的凝結而顯現出來。」

## 調查

**第一件證物：康普頓散射的相對論性運動學推導。** 這是本卷的理論核心，讓我們完整寫出。

**設定**：入射光子能量 $E = h\nu$，動量 $p = E/c = h\nu/c$。靜止的電子質量 $m_e$。散射後光子能量 $E'$，動量 $p' = E'/c$，與原方向成角度 $\theta$；電子動量 $\mathbf{p}_e$。

**（1）能量守恆**：

$$E + m_e c^2 = E' + \sqrt{m_e^2c^4 + p_e^2 c^2}$$

**（2）動量守恆**（$\mathbf{p} = \mathbf{p}' + \mathbf{p}_e$）：

$$p_e^2 = p^2 + p'^2 - 2pp'\cos\theta$$

**（3）消去電子**：把 (1) 平方並整理：

$$2 m_e c^2 (E - E') = (E-E')^2 + p_e^2 c^2 - 2 m_e c^2 E$$

由 (2)，$p_e^2 c^2 = E^2 + E'^2 - 2EE'\cos\theta$。代入並化簡，得到著名的**康普頓方程**：

$$\frac{1}{E'} - \frac{1}{E} = \frac{1 - \cos\theta}{m_e c^2}$$

**（4）回到波長**：由 $E = hc/\lambda$：

$$\frac{\lambda' - \lambda}{\lambda\lambda'} = \frac{1-\cos\theta}{m_e c^2}$$

由於 $\lambda' > \lambda$ 且 $\lambda\lambda'$ 很小，近似得：

$$\Delta\lambda = \lambda' - \lambda = \frac{h}{m_e c}(1 - \cos\theta) = \lambda_C (1-\cos\theta)$$

**這個推導的每一個步驟都是純粹的守恆律 + 相對論性質能關係，沒有任何光學理論的輸入。** 這就是它的力量：**如果光是波，這個公式不可能成立**（波動論給出 $\Delta\lambda = 0$）。

**第二件證物：實驗的關鍵細節——「什麼沒變」。** 康普頓的實驗設計有三個精妙之處，每一個都在排除替代解釋：

1. **用單色 X 射線**（Mo K$\alpha$，$\lambda_0 = 0.071\,\mathrm{nm}$，來自 1917 年巴克拉案的元素特異譜線）。若用連續譜，「波長變長」會被「散射後的譜被模糊」所混淆。
2. **用石墨（石墨的碳是近乎自由電子）**：低 $Z$ 元素的電子束縛能小，Compton 效應相對顯著；對高 $Z$ 物質，束縛電子的反衝效應（Bondy–Kirkpatrick 效應）會「洗掉」Compton 峰。
3. **量測的是同一條譜線的位置隨散射角的變化**，而不是「有沒有峰」。

**第三件證物：康普頓與巴克拉的命題——「光子是粒子」的定量證據。** 1917 年康普頓發現 γ 射線散射後波長改變，但**無法解釋**。1921 年他作出了大膽的一步：承認光由光子組成，並寫下碰撞方程。1923 年 5 月的論文裡，他明確引用了 1905 年愛因斯坦的光量子假說，並指出這個假說能解釋**光電效應**（密立根已驗證）、**光化學效應**、**放射性物質的散射**。

**他的論證邏輯極為漂亮**，值得完整引用其結構：
- 光電效應顯示光能傳遞是「整份」的 → 光有離散的能元；
- 檢驗散射：若光有動量 $p = E/c$，則與電子的碰撞必使光波長改變 → 算得 $\Delta\lambda$；
- 實測值與預測值在 $1\%$ 內一致 → **光量子假說成立**。

**第四件證物：1924 年印度實驗的獨立確認。** 這是科學史上一次著名的「平行發現」。1924 年，孟买的 **C. V. Raman（1930 諾獎）** 與 **K. S. Krishnan** 觀察到**康普頓散射在散射角 $180^\circ$ 時的特徵**：散射光的波長位移與入射光無關（因為 $1-\cos 180^\circ = 2$），而是**由散射物質的原子量決定**——因為在 $180^\circ$ 散射時，電子的反衝運動學給出反衝原子/電子的最大能量 $\Delta E_{\max} = 2E^2/(m_e c^2 + 2E)$，這在原子光譜裡以「**反衝線（recoil line）**」的形式出現。這個 $180^\circ$ 的極值情形，成了康普頓位移的「指紋」，使這個效應在光譜上無可爭辯。

這條線在 1924–1930 年被 G. N. Lewis 與 Kramers 等人發展成「**康普頓–里維斯（Compton–Ravish）公式**」，精確給出任意散射角下的完整散射譜形狀。

**第五件證物：威爾遜的雲室——「把不可見的路徑畫出來」。** 讓我們把雲室的物理寫清楚。

**第一步：過飽和。** 容器內充滿空氣，其中溶有**酒精**（乙醇）蒸氣。酒精在水中/空氣中的溶解度隨溫度變化：在低溫時能溶更多。

**第二步：膨脹降溫。** 突然拉開活塞，氣體**絕熱膨脹**，溫度驟降。若降溫幅度足夠，酒精蒸氣從飽和變成**過飽和**。

**第三步：凝結核。** 過飽和的蒸氣需要凝結核才能成滴。而**離子**正是極好的凝結核（因為電荷會降低成核的表面能障礙）。因此，**凡有離子存在的路徑上，就會形成一條可見的水滴線**。

**第四步：光學。** 用**側向照明**（一束強光平行於觀測方向，在 $90^\circ$ 方向觀測散射光）——與佩蘭的超顯微鏡同一原理。水滴像一串珠子，串起電子的路徑。

**第五步：量測。** 由路徑的曲率半徑 $r$（在已知磁場 $B$ 中）可得電子的動量：

$$p = \frac{e B r}{v_\perp} \quad (\text{曲率半徑法}), \qquad p = \frac{2mv_\perp}{B T_{\text{turn}}}$$

第一式給「$p\sin\theta$」（垂直分量），第二式給「$p\cos\theta$」——**兩者結合給出完整的動量大小與方向**。這個「磁曲率法」是 20 世紀粒子物理的標準工具，一直用到今天（LHC 的徑跡偵測器用的就是它）。

**第六件證物：威爾遜量出的「電子散射截面」——第一個原子碰撞截面。** 1912–1913 年，威爾遜分析電子在氣體中的軌跡，得到：

- 電子在空氣中的**平均自由程** $\lambda \approx 10^{-5}$ 至 $10^{-4}\,\mathrm{cm}$（隨能量變化）；
- 由此推出電子的**散射截面** $\sigma$。

這是第一個被量測的**電子-原子散射截面**，也是後來 Mott 散射（1933 諾獎，電子核散射的相對論性修正）、Rutherford 散射公式在原子尺度上的實驗檢驗。**威爾遜的雲室把「原子」從一個數字變成了一個可以「看到軌跡穿過」的對象。**

**第七件證物：雲室的宇宙線應用與 1927 年的歷史意義。** 1914–1915 年，威爾遜用多層鉛板夾住雲室，量測不同深度處的粒子通量，證明宇宙線是**從上方來的高能粒子**（而非來自地面的γ射線）。這個「鉛板厚度 vs 計數率」的曲線，就是宇宙線的**吸收曲線（range curve）**，直接給出粒子的能量損失關係。

1927 年諾獎的演講中，威爾遜展示了著名的照片：從上方轟入的粒子，在雲室中產生一連串分岔的軌跡——那正是宇宙線的 **shower（簇射）**。

## 理論裁決

**裁決一：康普頓位移公式的雙重意義。** 這個式子可以從兩個完全不同的角度讀：

**(a) 作為「光的粒子性」的證據**：$\Delta\lambda$ 是普適的，與物質無關，這正是兩粒子碰撞的特徵。若光是波，$\Delta\lambda$ 應為零（這是 Thomson 散射的干涉理論所預測的）。

**(b) 作為「電子相對論性運動學的量測工具」**：反過來，把 $\Delta\lambda$ 當作**已知的電子性質**，可以用它量測散射電子的能量：

$$E_e = \frac{h\nu}{1 + \frac{h\nu}{m_e c^2}(1-\cos\theta)}$$

這是 1920–1930 年代**電子 Compton 譜儀**的原理，也是 1930–1935 年用電子散射「看到」原子內部結構的基礎。

**裁決二：波粒二象性不是「光同時是波又是粒」，而是「描述方式取決於實驗」。** 1927 年康普頓在諾貝爾演講中的核心論點，可以歸納為：

- 干涉與衍射現象 → 光表現為**波**（Thomson 散射、Kramers–Heisenberg 公式、Compton-Ravish 公式）；
- 光電效應、Compton 散射、散射粒子的統計 → 光表現為**粒子**。

波耳在 1927 年索爾未會議上提出的「**互補原理（complementarity）**」正是這個結論的哲學版本：兩者不是矛盾，而是**互補的兩種敘述**。而 1927 年 12 月的諾獎，恰好在索爾未會議（1927 年 9 月）之後三個月，把這個結論的兩塊實證基石分別頒了獎——**這是諾獎史與物理學史同步得最漂亮的一次**。

**裁決三：威爾遜的雲室——「讓物理學家看見」的傳統。** 讓我們把這個方法論單獨拉出來談。

物理學的歷史上，有一個反覆出現的母題：**「讓不可見的東西可見」**：

| 年份 | 技術 | 看見了什麼 |
|------|------|-----------|
| 1897 | 陰極射線偏轉 | 電子的存在 |
| 1911 | **擴散雲室** | 電子的路徑、散射、宇宙線簇射 |
| 1932 | 雲霧室（Wilson）→ 氣泡室（1952 諾獎） | 中微子、正電子、夸克 |
| 1937 | 電子繞射（1937 諾獎） | 電子是波 |
| 1952 | 核乳膠（1950 諾獎） | π介子、夸克 |
| 1981 | ESCA | 材料的化學狀態 |
| 1986 | STM / AFM | 單個原子 |
| 2012 | 腔 QED 實驗 | 單一光子 |

**威爾遜在 1911 年開啟了這個傳統。** 他的一句話值得記住：他在 1927 年演講中描述他看到的第一條電子軌跡時說，那條軌跡「**把一個人類永遠看不見的粒子的行為，暴露在人類眼前**」。

**裁決四：康普頓與威爾遜的物理學對話——同一個「散射」的兩種語言。** 讓我們把 1927 年的兩份諾獎並排看：

| | 康普頓 | 威爾遜 |
|---|--------|--------|
| 對象 | 光子 | 電子（與其他帶電粒子） |
| 方法 | **譜學**：量測波長的位置 | **成像**：把軌跡畫出來 |
| 工具 | 莫塞萊譜線 + 晶體分光計 | 膨脹雲室 + 側向照明 |
| 物理量 | $\Delta\lambda$ | 軌跡曲率 $\to$ 動量、散射角、自由程 |
| 揭示 | 光有動量 $p = E/c$ | 粒子在物質中的散射行為 |
| 關鍵常數 | $\lambda_C = h/m_e c = 2.426\,\mathrm{pm}$ | $\lambda_{\text{mfp}}$、散射截面 |

兩者合起來給出一個統一的圖景：**微觀世界由粒子組成，它們遵循相對論性的運動學；它們的碰撞可以用守恆律描述；而波動性則是量子場的行為。** 這個圖景在 1927 年之後被稱為「**量子力學的因果結構**」，並在 1948 年之後被 Schwinger、Feynman、Tomonaga 的重整化 QED 完全形式化（1965 年諾獎）。

**裁決五：康普頓效應與原子核物理的接線。** 康普頓效應在 1930 年代的用途之一是**產生**已知能量的 γ 射線（用不同元素散射的 Mo K$\alpha$ 射線），用於「**核的 γ 射線譜學**」——這是 1950 年代核物理的基礎技術之一，與穆斯堡爾效應（1961 諾獎）同一條線。

而康普頓效應最重要的「延伸」是：**1930–1935 年的康普頓散射實驗揭示了「反衝效應」與「散射截面隨 $Z$ 的變化」**，這直接導致 1933 年 Mott 散射公式：

$$\frac{d\sigma}{d\Omega} = \left(\frac{e^2}{4E v}\right)^2 \frac{1-\beta^2\sin^2\theta}{...}$$

以及最終的 Mott 散射實驗（1933 諾獎，與 1935 諾獎同年的克里斯托弗）——**「Mott 散射」是「康普頓散射在原子核尺度上的相對論性修正版」，1933 年的諾獎正是為此頒發。** 這是一條極漂亮的鏈條：1927 康普頓 → 1933 Mott。

**裁決六：諾獎演講作為「理論史」的經典。** 康普頓 1927 年的諾貝爾演講題為《光的量子理論》（"The Quantum Theory of Light"），是所有諾貝爾演講中最被物理學家反覆引用的一篇。他在其中提出了「光的三種表現形式」的系統表格，並留下了一段名言：

> 「問題不在於光是波還是粒子——問題在於**我們的心智如何與光互動**。」

（他原文的意思是：光的行為取決於我們如何探測它。）

## 後果

| 年份 | 影響 |
|------|------|
| 1923 | 康普頓效應確立；光的粒子性獲得定量證據。 |
| 1924 | Raman 與 Krishnan 在印度獨立驗證（180° 反衝線）。 |
| 1927 | **諾獎頒發**；索爾未會議（互補原理）。 |
| 1928 | 狄拉克方程預言正電子；1929 年海森堡用電子論解釋鐵磁性。 |
| 1930 | 拉曼效應（諾獎）。 |
| 1932 | Anderson 發現正電子（1936 諾獎）——正是狄拉克方程 + 康普頓式的電子-光子相互作用。 |
| 1933 | Mott 散射（諾獎）；1933–34 年 Mott 實驗驗證相對論性散射公式。 |
| 1935 | 查德威克中子（諾獎）。 |
| 1936 | 雲室被改進為**自動連續型**；Fermi 與 1930s 的物理學家群體用它大量生產中子、質子。 |
| 1936 | 赫斯宇宙線（諾獎）；1937 年安德森用雲室中的**磁分析器**量測宇宙線粒子的質量。 |
| 1950 | 鮑威爾的核乳膠（諾獎）——雲室的姊妹技術。 |
| 1952 | 格拉澤的氣泡室（諾獎）——液態版的雲室，密度高、徑跡長。 |
| 1955 | 蘭姆與庫施（諾獎）——精細結構與電子磁矩。 |
| 1960s | 1960 年代的「**大氣球實驗**」用 MILK（乳膠）與**氣泡室**尋找稀有粒子。 |
| 1964 | 威爾遜的學生（Donald Glaser 是他的研究生）發明**氣泡室**——這條師承線是物理學的一個美麗細節。 |
| 1990s–2000s | LHC 探测器（ATLAS/CMS）——原理正是「把帶電粒子的路徑可視化」：雲室 → 氣泡室 → 漂移室 → 硅微條 → 像素探測器。 |
| 2016 | 諾貝爾物理學獎（Kostelitz、Thouless、Haldane）——用拓撲相解釋二維材料的相變（與凝態物質中的集體模式）。 |
| 2017 | LIGO——把「看不見的時空漣漪」變成可偵測訊號的技術傳統（雲室的現代版）。 |
