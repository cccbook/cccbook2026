# 1951 · 考克饒夫與沃吞：第一次由人來點火

> 1951 諾貝爾物理學獎：約翰·道格拉斯·考克饒夫（Sir John Douglas Cockcroft, 1897–1967，英國）與歐尼斯特·辛頓·沃吞（Ernest Thomas Sinton Walton, 1903–1995，愛爾蘭）——表彰「他們以人工加速的原子粒子對原子核進行嬗變的先驅性工作」（for their pioneer work on the transmutation of atomic nuclei by artificially accelerated atomic particles）。

## 懸案（案情提要）

1930 年代的物理學家手上有兩種「高能粒子」：宇宙線（不可控）與**高壓加速器**（可控，但被電壓卡死）。而核物理最核心的問題之一是：

**「能不能用人工加速的粒子，把一個元素變成另一個元素？」**

**這是一個看起來很簡單、但技術上極難的問題。**

**難在哪裡？讓我們把 1930 年的條件攤開來看：**

1. **質子必須有足夠的能量才能「進入」原子核。** 質子帶正電，受到原子核的庫侖排斥。**要讓質子「碰到」核，必須先克服庫侖位壘（barrier）：**

$$V_C(r \approx R_{\text{nuc}}) = \frac{Z_1Z_2e^2}{4\pi\varepsilon_0 R_{\text{nuc}}} \approx \frac{1.44\,\mathrm{MeV\cdot fm}\times Z}{1.2\,A^{1/3}\,\mathrm{fm}}$$

**對 ${}^{7}\mathrm{Li}$（$Z=3$、$A=7$、$R \approx 1.2\times7^{1/3} = 2.24\,\mathrm{fm}$）：**

$$V_C \approx \frac{1.44\times3}{2.24} = 1.93\,\mathrm{MeV}$$

**所以至少需要 2 MeV 以上的質子能量。**

2. **但 1930 年的加速器最高只能做到 1 MeV 左右**（靠多級串聯電壓累積）。

**於是出現了「量子穿隧」這個希望：**

即使質子能量低於位壘，它仍有非零機率「穿過」位壘進入核內。**量子力學給了這個希望一個明確的計算。**

3. **還必須能「看見」反應產物。** 產物是放射性原子核，半衰期可能只有幾分鐘到幾天。

**考克饒夫與沃吞的完整實驗方案（1931–1932）：**

```
   氫離子源（放電管）
        ↓  加速到 0.8 MeV
   [四級串聯加速管]（Cockcroft–Walton 電壓倍壓器）
        ↓  質子束
   [銅靶 + 鋅靶]（產生核反應）
        ↓
   [閃爍計數器 + 吸收片]（量測產物的 β 粒子）
```

**1932 年 4 月，實驗成功了。**

**數據（歷史上第一筆人工核嬗變的數據）：**

| 靶 | 觀測 | 推論 |
|---|---|---|
| 鋰 (Li) | 質子束轟擊後產生大量**穿透力很強的 $\beta$ 粒子**（穿過 $0.3$–$0.5\,\mathrm{cm}$ 厚的黃銅板仍被計數） | **產物是高能 $\beta$ 放射源** |
| 銅 (Cu)、鉛 (Pb) | 也產生 $\beta$ 粒子，但射程小得多 | 產物不同（$Z$ 不同） |
| **碳 (C)、氧 (O)、鐵 (Fe)** | **沒有任何效應** | **這是關鍵的對照！** |

**「碳、氧、鐵沒反應，鋰卻有反應」——這排除了「任何物質都能被質子打成放射性」的trivial解釋，並證明反應是**元素特異的**（由核的結構決定）。**

**然後是決定性的第二步：用化學方法確認產物。**

考克饒夫與沃吞把靶片（鋰）**溶於酸中**，把溶液煮沸以**去掉易揮發的產物**，然後再測放射性的 $\beta$ 粒子。

**結果：放射性伴隨著「鋰」一起被沉澱/留在溶液中——產物是鋰的同位素！**

**結論：**

$$\boxed{{}^{7}\mathrm{Li} + {}^{1}\mathrm{H} \to {}^{4}\mathrm{He} + {}^{4}\mathrm{He} + Q}$$

**讓我們算一下反應能：**

$$Q = \left[m({}^{7}\mathrm{Li}) + m({}^{1}\mathrm{H}) - 2\,m({}^{4}\mathrm{He})\right]c^2$$

用原子質量：$m({}^{7}\mathrm{Li}) = 7.016004\,\mathrm{u}$，$m({}^{1}\mathrm{H}) = 1.007825\,\mathrm{u}$，$m({}^{4}\mathrm{He}) = 4.002603\,\mathrm{u}$：

$$\Delta m = 7.016004 + 1.007825 - 2\times4.002603 = 8.023829 - 8.005206 = 0.018623\,\mathrm{u}$$

$$Q = 0.018623\times931.5 = 17.35\,\mathrm{MeV}$$

**這與 1932 年考克饒夫與沃吞報導的「$17.3\,\mathrm{MeV}$」幾乎完全一致——他們當年是用阿姆特朗（Armstrong）的方法量測了 $\alpha$ 粒子的射程反推能量。**

**這樁案子的歷史意義，用一句話總結：**

> **1932 年 4 月 16 日，是人類第一次「由人來」控制核反應。在此之前，所有的核反應（放射性的發現、嬗變、宇宙線作用）都是「自然發生的」。**

**而它開啟的兩條大河是：**

1. **核能**（費米的鏈式反應、哈恩的裂變、曼哈頓計畫）；
2. **應用核物理**（放射性示蹤、癌症治療、醫療影像、碳-14 定年）。

## 調查

**第一件證物：Cockcroft–Walton 電壓倍壓器——「用電容串聯把低壓疊成高壓」。**

**讓我們把這個裝置的數學寫清楚，因為它是 1930 年代加速器技術的里程碑。**

**原理：一個「電壓倍壓器」（Greinacher circuit）的級聯。**

- 一個交流高壓變壓器（$V_0 \approx 10$–$20\,\mathrm{kV}$）提供驅動；
- 每級由**二極管 D**（只讓電流單向通過）與**電容 C**（儲能）組成；
- 經過 $N$ 級串聯，輸出電壓可達

$$V_{\text{out}} \approx 2N\,V_0$$

**1932 年的第一台機用了 4 級、$V_0 = 12\,\mathrm{kV}$，輸出約 $0.8$–$1.0\,\mathrm{MV}$。**

**這個設計的三個關鍵優點：**

1. **完全沒有真空**，因此絕緣子不會在高壓下放電——這是當時最難的技術障礙；
2. **可連續供電**（不像單次放電的高壓脈衝）；
3. **成本低廉**，用變壓器與整流器即可。

**缺點：** 電壓隨負載增加而下降（內阻大），因此必須用加速管（真空管）來聚焦電流。

**第二件證物：加速管（accelerating tube）——「把離子束引導並加速」。**

**這是考克饒夫在 1928–1930 年與 Oliphant 發展的關鍵零件。**

**結構：** 一串同軸的環形電極（disc electrodes），封在玻璃管或金屬管中，內部抽真空。離子源在頂端，離子被第一級電位加速，然後依次穿過各級的「縫隙」。

**為什麼用「縫隙」（而不是整個管道同電位）？** 因為**在整段管道同電位的情況下，離子束會被整個管壁的電場擾動而散焦**。用縫隙電位，離子只在通過縫隙的那一瞬間被加速，之後在無場區做直線運動——**束流因此能保持聚焦**。

**這是加速器設計的第一個「智慧」：把加速做成「脈衝式」而非「連續式」，以維持束流品質。**

**第三件證物：1932 年的實驗細節——「$0.8\,\mathrm{MeV}$ 的質子束」。**

讓我們把 1932 年那個春天的實驗完整重建。

**加速條件：**

$$E = qV = (1.602\times10^{-19})(8\times10^5) = 1.28\times10^{-13}\,\mathrm{J} = 0.80\,\mathrm{MeV}$$

**速度與德布羅意波長：**

$$v = \sqrt{\frac{2E}{m_p}} = \sqrt{\frac{2\times1.28\times10^{-13}}{1.673\times10^{-27}}} = 1.24\times10^{7}\,\mathrm{m/s}$$

$$\lambda = \frac{h}{mv} = \frac{6.626\times10^{-34}}{1.673\times10^{-27}\times1.24\times10^{7}} = 3.19\times10^{-14}\,\mathrm{m} = 0.032\,\mathrm{nm}$$

**反應截面（1932 年測得的 ${}^{7}\mathrm{Li}(p,\alpha)$ 截面）：**

$$\sigma(E) \propto e^{-\pi\eta}, \qquad \eta = \frac{Z_1Z_2\alpha c}{\hbar v}$$

**讓我們估算一下「穿隧因子」：**

$$\eta = \frac{Z_1 Z_2 \alpha}{\hbar v/c} = \frac{3\times1/137}{(1.0546\times10^{-34}\times1.24\times10^7)/(2.998\times10^8)}$$

$$= \frac{0.0219}{4.36\times10^{-29}} = 5.02\times10^{26}\ \mathrm{m}^{-1}$$

$$\pi\eta R = 3.1416\times5.02\times10^{26}\times2.24\times10^{-15} = 3.53$$

$$e^{-\pi\eta R} = e^{-3.53} = 0.029$$

**所以在 $0.8\,\mathrm{MeV}$（低於 $1.93\,\mathrm{MeV}$ 的位壘）時，穿隧因子約 $3\%$——反應率雖小，但完全可以測到！**

**這就是「量子穿隧讓不可能變成可能」的定量證明——也是 1973 年諾獎（江崎、賈埃弗、約瑟夫森）的思想先驅。**

**第四件證物：吸收曲線——「怎麼知道那些 $\beta$ 粒子是新的？」**

**1932 年實驗的第二個關鍵設計：吸收片（absorbers）。**

**方法：** 在計數器與靶之間插入不同厚度的黃銅板（每片 $0.3$–$0.5\,\mathrm{cm}$），測量計數率隨吸收片數目的下降。

**結果（典型的鋰實驗數據）：**

| 黃銅片數 | 計數率（相對） |
|---|---|
| 0 | 100 |
| 1 | 78 |
| 2 | 60 |
| 3 | 46 |
| 4 | 35 |
| 5 | 27 |
| 6 | 20 |

**這條曲線可以外推到「零吸收」處，給出「真正的 $\beta$ 粒子數」。** 而「高穿透力」這個特徵（穿過數 mm 黃銅仍被計數）立刻排除了兩種干擾：

- **排除散射反彈電子**（它們能量低、射程短）；
- **排除 $\gamma$ 射線的康普頓電子**（那會是連續譜）。

**留下的結論：是一個新的、能量很高的 $\beta$ 源。**

**第五件證物：化學試驗——「產物到底是什麼元素」。**

**這是全案的決定性一步。**

**方法與結果（鋰的實驗）：**

1. 把被轟擊的鋰片**溶於稀酸**，得到含鋰的溶液；
2. **煮沸**：去掉任何易揮發的產物（例如 ${}^4\mathrm{He}$、任何氣態產物）；
3. 加入**碳酸銨**：使鋰以**碳酸鋰（$\mathrm{Li_2CO_3}$）沉澱**；
4. 測量沉澱的放射性 → **放射性跟著鋰一起沉澱了！**

**結論：產物是鋰的同位素（${}^{8}\mathrm{Li}$ 或 ${}^9\mathrm{Li}$ 之類）。**

**而對「銅」的對照實驗：** 把銅靶溶於酸，加入氨水使銅以**氫氧化銅**沉澱 → **放射性沒有跟著銅沉澱** → 產物不是銅的同位素。

**讓我們把這張「排除表」寫出來，這是全書最值得學習的「元素特異性」實驗設計：**

| 靶元素 | 化學分離後放射性 | 推論 |
|---|---|---|
| Li | **隨鋰沉澱** | 產物是**鋰的同位素** |
| Cu | 不隨銅沉澱 | 產物**不是**銅的同位素 |
| Pb | 不隨鉛沉澱 | 產物不是鉛的同位素 |
| C, O, Fe | 完全無反應 | **元素特異**：只有某些核的組態允許低能反應 |

**第六件證物：1934 年考克饒夫與沃吞的「截面曲線」——「這把尺子畫出來了」。**

**這是他們第二篇（也是更重要的）論文的內容，也是本案最可貴的遺產。**

**他們系統測量了 ${}^{6}\mathrm{Li}(p,\alpha){}^{3}\mathrm{He}$ 與 ${}^{7}\mathrm{Li}(p,\alpha){}^{4}\mathrm{He}$ 的反應截面隨質子能量的變化，得到一條「上升曲線」。**

**這條曲線揭示了一個極其重要的核物理事實：**

> **在低能區，截面不是像指數函數那樣「永遠很小」，而是有一個「閾值結構」——超過某個能量後，截面急劇上升，然後趨於飽和。**

**讓我們用簡化的玻爾–惠特公式（Bohr–Wheeler）來看這個結構：**

$$\sigma(E) = \pi a^2\left(1 - \frac{V_C}{E}\right)\left(1 + \frac{V_C}{E}\right)\exp\left[-2\pi\eta\right]$$

其中 $\eta = \frac{Z_1Z_2\alpha c}{\hbar v}$。**注意：當 $E \to V_C$（位壘高度）時，第一個因子趨於零——反應在位壘高度處「打開」。**

**讓我們對 ${}^{7}\mathrm{Li}(p,\alpha)$ 估算：**

$$V_C = \frac{1.44\times3}{2.24} = 1.93\,\mathrm{MeV}$$

**而質子能量是 $0.8$–$2.5\,\mathrm{MeV}$——恰好跨越了位壘。** 這解釋了為什麼他們能看到「低能端的反應」：那是**純粹的量子穿隧效應**。

**第七件證物：「同位素質量的整數性」——一個被低估的發現。**

1934–1937 年，考克饒夫與沃吞發現了一條極其重要的經驗規則：

> **原子核的質量數 $A$ 幾乎精確地等於「原子質量單位」的整數倍，偏差只有 $0.001$–$0.01\,\mathrm{u}$（相對誤差 $\sim 10^{-3}$）。**

$$\frac{A - m_{\text{原子}}}{\text{相對誤差}}\quad\text{典型值：}\quad\frac{\Delta m}{m}\sim 10^{-3}$$

**這個「質量整數性」規則的意義：**

1. **它讓人相信「原子核由 $A$ 個核子組成」**——這是查德威克的中子發現（1935 諾獎）的核心背景；
2. **它的偏差量必須由束縛能解釋**：$B = \Delta m\,c^2$，每核子 $8$ MeV 對應質量虧損 $8/931.5 = 0.0086\,\mathrm{u}$——這正是質量的主要來源；
3. **它讓「原子質量的精密量測」成為核物理的核心工具**。

**第八件證物：一個歷史的註腳——「這次實驗在 1940 年被重做了一次」。**

**1932 年的「人工嬗變」實驗在物理學上只引發了有限的興奮（至少在英國），因為它「只」產生了幾百萬次反應。**

**1938–1939 年，德國的 Otto Hahn 與 Fritz Strassmann 在**柏林的化學研究所（**Kaiser Wilhelm 研究所**）用**化學方法**做了一件驚人的事：他們證明中子轟擊鈾會產生**鋇**——這意味著核裂變。而在此之前，費米的解讀是「超鈾元素」。**

**這個裂變發現，正是考克饒夫–沃吞方法的「化學分離 + 計數」邏輯的放大版**（只不過對象從幾百萬個反應變成了每小時 $10^{22}$ 個反應）。

## 理論裁決

**裁決一：穿隧因子——「為什麼 $0.8\,\mathrm{MeV}$ 的質子能擊碎鋰核」。**

**讓我們完整寫出 Gamow 因子，這是本案的物理核心。**

**第一步：庫侖位壘（對兩個帶電粒子的拋物線近似）：**

$$V(r) = \frac{Z_1Z_2e^2}{r} + \frac{\hbar^2}{2\mu}\frac{l(l+1)}{r^2}\Big|_{\text{離心}}\quad\text{（取 $l=0$ 的 $s$ 波最簡情形）}$$

$$V_C = \frac{Z_1Z_2e^2}{4\pi\varepsilon_0 R_{\text{nuc}}}$$

**第二步：WKB 穿隧係數。** 在位壘頂部附近，$V(r)$ 可近似為倒拋物線，WKB 給出：

$$\mathcal{T} \approx \exp\left[-2\int_{r_1}^{r_2}\sqrt{\frac{2\mu(V(r)-E)}{\hbar^2}}\,dr\right] = e^{-2\pi\eta}$$

**第三步：Gamow 因子。**

$$\eta = \frac{Z_1Z_2\alpha c}{\hbar v}$$

**讓我們代入數值做一次完整計算（${}^{7}\mathrm{Li}+p\to 2\alpha$ 在 $E = 0.8\,\mathrm{MeV}$）：**

$$v = \sqrt{\frac{2\times0.8\times1.602\times10^{-13}}{1.673\times10^{-27}}} = 1.24\times10^{7}\,\mathrm{m/s}$$

$$\frac{\hbar v}{c} = \frac{1.0546\times10^{-34}\times1.24\times10^{7}}{2.998\times10^8} = 4.36\times10^{-29}\,\mathrm{m}$$

$$\eta = \frac{3\times(1/137)}{4.36\times10^{-29}} = 5.02\times10^{26}\,\mathrm{m}^{-1}$$

$$\pi\eta R = 3.1416\times5.02\times10^{26}\times2.24\times10^{-15} = 3.53, \qquad \mathcal{T} = e^{-3.53} = 2.9\times10^{-2}$$

**第四步：總反應率。**

$$\text{反應率} = I_{\text{beam}} \cdot N_{\text{target}} \cdot \sigma(E)$$

**這裡有一個必須交代的「速率限制」：靶的自發衰變率。** 對 ${}^{7}\mathrm{Li}$，即使截面不算小，**$\beta$ 衰變的半衰期（$t_{1/2} = 0.467\,\mathrm{s}$）意味著產物只能存在不到一秒**——所以必須**快速**測量，這正是為什麼要用「吸收片 + 計數管」而不是化學沉澱。

**第五步（更重要的物理意義）：穿隧解釋了「核反應為何在低能下仍可能」。**

**這是一個哲學性的轉折：**

> **在古典物理中，低能粒子面對高位壘只能被「反射」——反應截面為零。**
> **在量子物理中，位壘只是「概率」而非「牆」。**

**這個「概率之牆」的觀念，是 20 世紀物理學最具革命性的概念之一：它不僅解釋了核反應，也解釋了：**

- **$\alpha$ 衰變**（Gamow 理論，1928）：$\alpha$ 粒子從核內「穿出」位壘，**這就是 1928 年 Geiger–Nuttall 定律的理論解釋**；
- **隧道二極體**（江崎，1973 諾獎）；
- **約瑟夫森效應**（1973 諾獎）；
- **掃描穿隧道顯微鏡**（1986 諾獎）；
- **放射性 $\alpha$ 衰變的半衰期與能量的指數關係**（Geiger–Nuttall 定律）。

**裁決二：核反應的「Q 值方程」與質量虧損——「把原子變成另一個原子時，能量到哪裡去了」。**

**第一定律：能量守恆。** 對反應 $a + A \to b + B$：

$$Q = \left[m(a) + m(A) - m(b) - m(B)\right]c^2$$

**第二定律：電荷守恆。**

$$Z(a) + Z(A) = Z(b) + Z(B)$$

**第三定律：核子數守恆。**

$$A(a) + A(A) = A(b) + A(B)$$

**第四定律：動量守恆（兩體終態）。**

$$p_a^2 + p_A^2 + 2p_ap_A\cos\theta = p_b^2 + p_B^2$$

**讓我們把 ${}^{7}\mathrm{Li}+p\to 2\alpha$ 的 Q 值算完整（已在懸案部分計算）：$Q = 17.35\,\mathrm{MeV}$。**

**第五步（關鍵的應用）：「粒子數守恆」如何決定 $Q$ 的符號。**

**注意一個漂亮的規則：** 對 $2\rightarrow2$ 反應，

$$Q = \frac{(m_a - m_A)c^2}{?} \ldots$$

**更實用的是：** 對同位素 $(p,n)$ 反應，

$${}^{A}_{Z}X + p \to {}^{A+1}_{Z+1}Y + n$$

$$Q = \left[m({}^{A}_{Z}X) + m_p - m({}^{A+1}_{Z+1}Y) - m_n\right]c^2$$

**這就是費米的「位移定律」的定量版本——核反應是把核子重新分配，而不是憑空創造。**

**裁決三：「人工加速器」到「核反應工程」的完整物理鏈。**

讓我們把本案的完整技術鏈寫出，因為它是 20 後半葉能源與醫學的共同源頭：

$$\text{電壓倍壓器} \xrightarrow{} \text{加速管} \xrightarrow{} \text{薄靶反應} \xrightarrow{} \text{產物收集} \xrightarrow{} \begin{cases} \text{人造同位素} \\ \text{加速器中子源} \\ \text{放射性示蹤} \\ \text{核裂變研究} \end{cases}$$

**每一步的關鍵物理：**

| 步驟 | 關鍵物理 | 諾獎 |
|---|---|---|
| 電壓倍壓 | $V_{\text{out}} = 2NV_0$ | — |
| 加速管 | 縫隙加速以維持束流聚焦 | — |
| 薄靶反應 | $\sigma(E)$、Gamow 因子 | 1951 |
| 產物分離 | 化學示蹤與比度 | 1951, 1944（化學獎） |
| 大量生產 | 迴旋加速器（高產率） | **1939 勞倫斯** |
| 鏈式反應 | $k_{\text{eff}} = \eta\epsilon pf$ | 1938 費米 |
| 裂變 | 液滴模型 | 1944（化學獎 哈恩） |

**裁決四：本案在諾獎史中的座標——「把核反應從天象搬進實驗室」。**

**讓我們把 1932 年前后的核物理「實驗對象」做一個對比：**

| 時期 | 核反應的驅動者 | 可控性 | 產率 |
|---|---|---|---|
| 1896–1919 | 天然放射性 | 不可控 | 極低 |
| 1919–1930 | $\alpha$ 粒子（天然放射性源） | 半可控 | 低 |
| **1932–** | **人工加速粒子（本案）** | **可控** | **高** |
| 1938– | 中子 | 可控 | 更高 |
| 1940s– | 反應爐中的中子 | 可控 | 極高（巨額） |

**這張表說明：1932 年是核物理的「可控性革命」。** 這正是諾獎委員會表彰它的理由——「pioneer work」。

**裁決五：沃吞的教學貢獻——「把一個領域建成一門課」。**

**這是本卷可以補上一段諾獎史上常被忽略的內容。**

**1934 年，沃吞回到都柏林三一學院，並在 1934–1935 年開設了**世界上第一門正式的核物理課程**。**

**沃吞還寫了一本教科書：《Principles of Nuclear Physics》（1936 年由 Oxford University Press 出版），這是**第一本系統講述核物理的教科書**——它把「人工加速器 + 核反應截面 + $\beta$ 衰變 + 核力」整合成一個領域。**

**一個領域的成熟有三個標誌：** ① 有自己的儀器；② 有自己的雜誌；③ **有自己的教科書**。沃吞在 1936 年補上了第三個。**這是諾獎背後「學科建設」的一個完整案例。**

## 後果

| 年份 | 影響 |
|---|---|
| 1928–1930 | 考克饒夫與 Oliphant 發展**加速管**技術。 |
| 1930–1931 | **Cockcroft–Walton 電壓倍壓器**建成，輸出 0.8–1 MV。 |
| 1932-04-16 | **第一次人工核嬗變**：${}^{7}\mathrm{Li}+p \to 2\,{}^{4}\mathrm{He}$，$Q = 17.35\,\mathrm{MeV}$。 |
| 1934 | 系統測量核反應截面；建立「同位素質量整數性」規則。 |
| 1934 | 沃吞在都柏林開設**世界上第一門核物理課程**；1936 年出版第一本核物理教科書。 |
| 1937 | 費米在羅馬用中子重現人工放射性；**中子比質子更有效**（$Z=0$，無庫侖排斥）。 |
| 1938–1939 | **哈恩與斯特拉斯曼發現核裂變**——化學分離方法的放大版。 |
| 1939–1945 | 考克饒夫參與 **Tizard Mission**（把英國磁控管帶到美國）、MAUD 委員會、**蒙特利爾實驗室**（ZEEP 與 NRX 反應爐）。 |
| 1947 | **GLEEP** 反應爐達臨界——西歐第一座運轉的反應爐（考克饒夫指導）。 |
| 1951 | **諾獎頒發**。 |
| 1952 | 沃吞的研究顯示**電子磁矩的精確值**——沃吞在 1950 年代測得的電子 $g$ 因子是當時最精確的。 |
| 1953–1957 | 加速器核物理的黃金期；**放射性示蹤**廣泛進入生物學與醫學。 |
| 1957–1960 | **加速器中子源**用於癌症治療與中子衍射。 |
| 1960s | 大量放射性同位素（${}^{60}\mathrm{Co}$、${}^{131}\mathrm{I}$、${}^{99m}\mathrm{Tc}$）成為醫療常規。 |
| 1973 | **江崎與賈埃弗的量子穿隧**（諾獎）——「穿隧」的技術化。 |
| 1986 | **掃描穿隧道顯微鏡**（諾獎）——穿隧的精密化。 |
| 2004–2010 | 加速器（**散裂中子源**、**同步輻射光源**）成為化學、生物、材料研究的標準平台。 |
