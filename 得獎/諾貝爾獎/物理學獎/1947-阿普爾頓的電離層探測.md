# 1947 · 阿普爾頓：用無線電「敲」出天空中的一層殼

> 1947 諾貝爾物理學獎：愛德華·維克多·阿普爾頓（Sir Edward Victor Appleton, 1892–1965，英國）——表彰「他對高空大氣物理的研究，特別是發現了所謂的阿普爾頓層」（for his investigations of the physics of the upper atmosphere especially for the discovery of the so-called Appleton layer）。

## 懸案（案情提要）

1920 年代，無線電廣播已經開始商業化。但工程師們立刻撞上一堵牆：

**牆的具體表現是：**
- **每天晚上特定的時間，接收距離突然縮短**，原能收到 1,000 km 外的電台，過了午夜就只剩 200 km；
- **不同頻率的電台，接收距離上限不同**，而且是隨季節變化的；
- **有些時候，完全聽不到某些頻段的電台**——它們「被反射到別處去了」；
- **而某些方向上，電訊號會「繞過地球」**——長距離短波通信。

**這些現象指向同一個推論：**

> **地球上方一定存在一層能「反射」無線電波的「鏡子」。**

**物理推論的推理鏈非常清楚：**

1. 無線電波是**電磁波**；
2. 電磁波在**均勻介質**中直線傳播，在**電離層**（含有自由電子的等離子體）中則會被折射；
3. 當**電離層中的電子密度足夠高**時，等離子體的**等離子體頻率**低於入射波的頻率，波就被**全反射**了（類似光從空氣射入金屬）；
4. 因此：**有一個「臨界頻率」** $f_c$——頻率高於它就穿透，頻率低於它就反射。**這就是「短波能傳很遠、但超短波不行」的完整解釋。**

**但 1920 年代末，天空中的「鏡子」還是一片模糊：**

- **它有多高？** 只能用三角測量（比較不同仰角的信號）估計，而且結果互相矛盾；
- **它是一層還是多層？** 有人主張是一層，有人主張是兩層、三層；
- **它的高度隨時間怎麼變？** 白天和夜晚顯然不同（夜間 D 層消失），但 F 層呢？

**1927 年，關鍵的技術突破來了：雷達 sounding（雷達探空）。**

阿普爾頓在英國**馬爾文（Malvern）的「無線電研究站」（Radio Research Station, RRS）**組織團隊，把**無線電探空雷達**架到山頂：發出脈衝，測量回波的往返時間。

**雷達 sounding 立刻給出了「反射高度」的精確數據：**

$$h = \frac{c\,t}{2}\sec i$$

其中 $t$ 是往返時間，$i$ 是入射角（仰角 complement），$\sec i = 1/\cos i$。

**阿普爾頓立刻用它做了一件極其精妙的事：把「反射高度對頻率的依賴」畫成圖。**

**這張圖就是全案的破案關鍵。** 因為等離子體的折射率是頻率的函數：

$$N^2 = 1 - \frac{\omega_p^2}{\omega^2} - \frac{\omega_p^2\omega_c^2}{\omega(\omega^2-\omega_c^2)}\sin^2 i$$

當頻率從高往低掃過時，反射高度會**先緩慢上升，然後在臨界頻率處急劇上升（躍升到無限大）**——**這條「曲線的拐點」就是等離子體頻率 $\omega_p$。**

**由此，阿普爾頓從「反射高度 vs 頻率」的曲線，直接反推出「電子密度 vs 高度」的剖面。** 這是地球大氣物理的第一把「量測尺」。

**1947 年的「懸案」則是更尖銳的一個：**

**1932 年，阿普爾頓發現了一件怪事：在同一個頻率上，從不同方向來的無線電波，測到的「反射高度」不同。**

**一個「只有電子密度」的模型解釋不了這件事。** 因為如果反射只由電子密度決定，那麼各方向的反射高度應該一樣。

**阿普爾頓的推理是：地球有磁場（這是 1900 年前就知道的事——地磁場強度約 $5\times10^{-5}\,\mathrm{T}$）。帶電的電子在磁場中做螺旋運動，這會讓等離子體對不同方向的波有不同的折射率。**

**於是出现了「雙重折射」：**

- 從**垂直於地磁場**的方向入射 → 看到**「O 線」（ordinary ray，普通光線）**，反射高度是 $h_o$；
- 從**平行於地磁場**的方向入射 → 看到**「X 線」（extraordinary ray，異常光線）**，反射高度是 $h_x$。

**兩條線的「臨界頻率」不同：**

$$f_o \neq f_x$$

**這個「O/X 分裂」是全套實驗的決定性證據**，因為它顯示了**地磁場對 radio 傳播的影響**——而這正是阿普爾頓要建立完整理論的核心對象。

**1947 年，阿普爾頓把這些成果整理成完整的「磁化等離子體（magneto-ionic theory）」，並且——這是本案的關鍵歷史事實——他用這些成果明確地把 F 層分成 **F1 與 F2 兩層**，確立了「大氣的分層結構」。**

## 調查

**第一件證物：雷達 sounding——「把時間變成高度」。**

**這是全案的技術底座，讓我們把它寫清楚。**

**原理：垂直入射的雷達脈衝**

$$h = \frac{ct}{2}$$

**傾斜入射（更一般）：**

$$h = \frac{ct}{2\cos\theta}$$

其中 $\theta$ 是**天底角（zenith angle）** $= 90^\circ - i$（$i$ 是仰角 elevation），故 $\cos\theta = \sin i$：

$$\boxed{h = \frac{ct}{2\sin i}}$$

**讓我們做一個數字檢查：** $f = 5\,\mathrm{MHz}$ 的垂直 sounding，回波時間 $t = 1.0\,\mathrm{ms}$：

$$h = \frac{3\times10^8\times1.0\times10^{-3}}{2} = 1.5\times10^5\,\mathrm{m} = 150\,\mathrm{km}$$

**這就是 1930 年代量到的 D 層與 E 層的高度。** 而對 $f = 1\,\mathrm{MHz}$ 的低頻，$t = 2.3\,\mathrm{ms}$：

$$h = \frac{3\times10^8\times2.3\times10^{-3}}{2} = 3.45\times10^5\,\mathrm{m} = 345\,\mathrm{km}$$

**這就是 F 層。**

**第二件證物：「反射高度 vs 頻率」的曲線——從曲線反推電子密度剖面。**

這是阿普爾頓方法的核心，讓我們完整寫出。

**步驟一：對每個頻率 $f$，量出回波時間 $t(f)$，換算成高度 $h(f)$。**

**步驟二：等離子體折射率。** 忽略地磁場（先做最簡單的情形），等離子體的折射率為

$$N^2 = 1 - \frac{\omega_p^2}{\omega^2}, \qquad \omega_p^2 = \frac{ne^2}{\varepsilon_0 m_e}$$

**步驟三：反射條件。** 波從真空（$N=1$）進入等離子體（$N<1$），在 $N = \sin\theta$ 處發生全反射（Snell 定律的臨界情形）。**代入 Snell 定律 $N\cos\theta$（折射角 $\theta$）並消去 $\theta$，得到「反射高度」的近似公式（Appleton–Hartree 的垂直入射特例）：**

$$h \approx h_0 + \frac{H}{2}\ln\left(\frac{f_c^2 - f^2}{f^2}\right), \qquad f_c = \frac{e}{2\pi}\sqrt{\frac{n_e}{\varepsilon_0 m_e}}$$

其中 $H = k_BT/(mg)$ 是**大氣标高**（等離子體層的「厚度尺度」），$h_0$ 是層底高度。

**這個公式的物理意義非常重要：**

- $f$ 越接近臨界頻率 $f_c$，$\ln$ 裡的分子趨近 0，$h$ 趨向**無限大**；
- $f \ll f_c$ 時，$h \approx h_0 + \frac{H}{2}\ln\left(\frac{f_c^2}{f^2}\right) = h_0 + H\ln\left(\frac{f_c}{f}\right)$。

**步驟四：反推。** 把實測的 $h(f)$ 曲線代入上述公式，即可逐點解出電子密度 $n_e(h)$。

**讓我們做一個典型的數字：** 白天正午的 $F_2$ 層峰值，$n_e^{\max} \approx 1.2\times10^{12}\,\mathrm{m^{-3}}$（即 $1.2\times10^6\,\mathrm{cm^{-3}}$）。

**驗算臨界頻率：**

$$f_c = \frac{e}{2\pi}\sqrt{\frac{n_e}{\varepsilon_0 m_e}} = \frac{1.602\times10^{-19}}{6.283}\sqrt{\frac{1.2\times10^{12}}{8.854\times10^{-12}\times9.109\times10^{-31}}}$$

$$= 2.55\times10^{-20}\sqrt{\frac{1.2\times10^{12}}{8.06\times10^{-42}}} = 2.55\times10^{-20}\sqrt{1.49\times10^{53}} = 2.55\times10^{-20}\times3.86\times10^{26}$$

$$= 9.85\times10^{6}\,\mathrm{Hz} \approx 10\,\mathrm{MHz}$$

**這與實際觀測完全一致：白天正午 $F_2$ 層的臨界頻率約 10–13 MHz。** 而日落時降到約 4–5 MHz（因為電子密度因 recombination 而減少）。**夜間 $F_1$ 層消失、$F_2$ 層降到最低點**，這正是阿普爾頓 1947 年的主要發現之一。

**第三件證物：O/X 分裂——「兩條曲線」比「一條曲線」多出的資訊。**

**這是本案的偵查核心，讓我們把它寫成一個完整的推理。**

**觀察：** 1947 年的 sounding 顯示，在同一頻率上，從不同方位角入射的波，測到的反射高度不同：

$$h_o(f) \neq h_x(f)$$

**排除清單：**

| 可能原因 | 檢驗方式 | 結果 |
|---|---|---|
| 儀器誤差 | 換方位角重測 | 曲線是**系統性**的，不是雜訊 |
| 電子密度有水平梯度 | 沿同一磁力線的不同方位角比較 | **排除**（梯度效應遠小於 O/X 分裂） |
| 地球曲率與折射 | 計算修正 | 修正量不足以解釋 |
| **地磁場的存在** | 檢查分裂量是否隨地磁傾角 $\theta$ 系統性變化 | **完全吻合** |

**結論：分裂由地磁場造成。**

**阿普爾頓方程（1924）——本案的「法律條文」。**

忽略地磁場的微小修正（$Y^2 \ll 1$），對斜向入射，兩個臨界頻率為：

$$\boxed{f_o^2 = f_c^2 + \frac{f_h^2}{2} - \sqrt{\left(f_c^2+\frac{f_h^2}{2}\right)^2 - f_c^2 f_h^2 \cos^2\theta}}$$

$$\boxed{f_x^2 = f_c^2 + \frac{f_h^2}{2} + \sqrt{\left(f_c^2+\frac{f_h^2}{2}\right)^2 - f_c^2 f_h^2 \cos^2\theta}}$$

其中：

- $f_c = \frac{e}{2\pi}\sqrt{\frac{n_e}{\varepsilon_0 m_e}}$：**等離子體頻率**（垂直入射的臨界頻率）；
- $f_h = \frac{eB}{4\pi m_e}$：**半旋轉頻率**（gyrofrequency 的一半）；
- $\theta$：**地磁傾角**（磁場與水平面的夾角）。

**讓我們用典型的地磁數值算一下分裂量：**

在英國，$B \approx 4.9\times10^{-5}\,\mathrm{T}$，地磁傾角 $\theta \approx 65^\circ$：

$$f_h = \frac{eB}{4\pi m_e} = \frac{1.602\times10^{-19}\times4.9\times10^{-5}}{4\times3.1416\times9.109\times10^{-31}} = \frac{7.85\times10^{-24}}{1.144\times10^{-29}} = 6.86\times10^{5}\,\mathrm{Hz} \approx 0.686\,\mathrm{MHz}$$

**而 $f_c \sim 10\,\mathrm{MHz}$，故 $f_h/f_c \approx 0.069$，$f_h^2/f_c^2 \approx 4.7\times10^{-3}$。**

**代入近似式（$f_h \ll f_c$）：**

$$f_o^2 \approx f_c^2 - f_h^2\sin^2\theta = f_c^2\left[1 - 4.7\times10^{-3}\times0.821\right] = f_c^2(1 - 3.9\times10^{-3})$$

$$f_x^2 \approx f_c^2 + f_h^2\cos^2\theta = f_c^2\left[1 + 4.7\times10^{-3}\times0.179\right] = f_c^2(1 + 8.4\times10^{-4})$$

$$\frac{\Delta f}{f_c} \approx \frac{1}{2}\left(3.9\times10^{-3} + 8.4\times10^{-4}\right) = 2.37\times10^{-3}$$

$$\Delta f = 10\,\mathrm{MHz}\times2.37\times10^{-3} = 24\,\mathrm{kHz}$$

**所以「O 線」與「X 線」的臨界頻率相差約 24 kHz——在 $10\,\mathrm{MHz}$ 的載波上，這是一個可以輕鬆量出的分裂！**

**第四件證物：阿普爾頓-哈特里方程（Appleton–Hartree equation）——完整的磁化等離子體色散關係。**

完整的（含地磁場效應）折射率公式：

$$N^2 = 1 - \frac{X}{1 - Y^2} \pm \sqrt{\frac{Y^4}{4(1-Y^2)^2} + \frac{Y^2}{1-Y^2}}$$

其中

$$X = \frac{\omega_p^2}{\omega^2} = \frac{f_c^2}{f^2}, \qquad Y = \frac{\omega_c}{\omega} = \frac{2f_h}{f}$$

**「$\pm$」號對應「O 線」與「X 線」。**

**這個方程的深意：** 它把三個物理效應（自由電子的極化、地磁場的迴旋運動、波的偏振態）編織成一個統一的色散關係。**它就是「等離子體中的電磁波」這個領域的奠基方程**，在 1990 年代之前一直是全球雷達與短波通信設計的標準工具。

**第五件證物：1947 年的具體成果——F 層被分成兩層。**

阿普爾頓在 1947 年藉由 sounding 資料提出：

**F 層的結構：**
- **F1 層**：出現在**白天**，高度 $\sim 200$–$230\,\mathrm{km}$，是一個「薄」的極大值（電子密度隨高度略減）；
- **F2 層**：出現在**全天**，高度 $\sim 250$–$350\,\mathrm{km}$，是真正的「主峰值」；
- **夜間**：F1 層**消失**（因為 recombination 消耗了電子），只留下 F2 層的殘餘。

**為什麼 F1 只在白天？** 因為它的電子來源是**太陽的極紫外輻照直接光電離**（低高度，光子能量足以電離但空氣密度大 → recombination 快）；而 F2 層在白天的電子來源是極紫外，在夜間則靠**流星的撞擊電離**維持（流星每天約 $10^{11}$ 次進入大氣層）。

**這個「夜間仍存在的 F2 層由流星維持」的結論，是 1947 年之後才被完全確立的。**

**第六件證物：短波通信的「跳躍距離」與 M 曲線——阿普爾頓的應用 crown jewel。**

**這是阿普爾頓工作在實務上最重要的貢獻，也是「從物理到工程」的一次經典示範。**

**問題：** 短波（3–30 MHz）能繞地球傳播，但**存在「跳躍距離」（skip distance）**：距發射台太近的地方（第一跳躍區之內）收不到信號，太遠的地方（第二跳躍區之外）也收不到。

**原因：** 一個波從地面以仰角 $i$ 發射，經電離層反射後落地。它能覆蓋的「跳躍距離」由「射線軌跡」決定——而射線軌跡由 **M 曲線（skip distance vs. frequency）** 給出：

- **頻率太低**（接近臨界頻率）→ 射線折射得太厲害 → 跳躍距離太大；
- **頻率太高** → 穿過電離層不反射 → 沒有跳躍；
- **中間有一個最佳頻率**，給出最小的跳躍距離。

**阿普爾頓正是用 O/X 分裂的資料，建立並修正了 M 曲線。** **這是諾獎級的物理工作直接改變了全球無線電網的設計。**

## 理論裁決

**裁決一：等離子體中的電磁波——「介質如何改變光的路徑」。**

**電子在電磁場中的運動方程（冷等離子體近似）：**

$$m_e\frac{d\mathbf{v}}{dt} = -e\left(\mathbf{E} + \mathbf{v}\times\mathbf{B}\right)$$

**加上電流的定義 $\mathbf{J} = -ne\mathbf{v}$ 與位移電流 $\partial\mathbf{D}/\partial t$，配合 Maxwell 方程，得到等離子體的波動方程。**

**讓我們完整推導「等離子體頻率」這個核心結果（這是本案最重要的公式）：**

**第一步：無碰撞、無磁場、沿 $z$ 傳播的波。**

$$\frac{\partial^2\mathbf{E}}{\partial z^2} = \mu_0\varepsilon_0\frac{\partial^2\mathbf{E}}{\partial t^2} + \mu_0\frac{\partial \mathbf{J}}{\partial t}$$

**第二步：由運動方程得電流對時間的導數：**

$$\frac{\partial \mathbf{J}}{\partial t} = -ne\frac{\partial\mathbf{v}}{\partial t} = \frac{ne^2}{m_e}\mathbf{E} = \varepsilon_0\omega_p^2\,\mathbf{E}$$

其中 $\omega_p^2 = ne^2/(\varepsilon_0 m_e)$。

**第三步：代回，得到波動方程：**

$$\frac{\partial^2\mathbf{E}}{\partial z^2} = \frac{1}{c^2}\frac{\partial^2\mathbf{E}}{\partial t^2} + \frac{\omega_p^2}{c^2}\mathbf{E}$$

**第四步：代入平面波 $E\propto e^{i(kz-\omega t)}$：**

$$-k^2 + \frac{\omega^2}{c^2} + \frac{\omega_p^2}{c^2} = 0 \quad\Longrightarrow\quad \boxed{k^2 = \frac{\omega^2 - \omega_p^2}{c^2}}$$

**第五步：折射率。**

$$N = \frac{ck}{\omega} = \sqrt{1 - \frac{\omega_p^2}{\omega^2}}$$

**這就是全案的基石。** 讓我們指出三個直接後果：

**(a) 等離子體頻率 $f_p = \omega_p/2\pi$ 是「截止頻率」。**
- $\omega > \omega_p$：$N$ 為實數，**波可以傳入等離子體**；
- $\omega < \omega_p$：$N$ 為虛數，**波被全反射**（$k$ 為虛數，衰減長度 $\sim c/\omega_p$）。

**這就是「高於臨界頻率就穿透、低於就反射」的完整數學。**

**(b) 等離子體頻率直接正比於 $\sqrt{n_e}$。** 所以量 $f_c$ 就量到了電子密度——**這就是阿普爾頓把「反射高度曲線」翻譯成「電子密度剖面」的依據。**

**(c) 等離子體頻率與粒子質量成反比平方根。** 因此**重離子的等離子體頻率遠低於電子**：

$$\frac{\omega_{p,\text{ion}}}{\omega_{p,e}} = \sqrt{\frac{m_e}{m_i}} \approx \sqrt{\frac{9.11\times10^{-31}}{1.67\times10^{-27}}} = 0.0234$$

**在 $n_e = 10^{12}\,\mathrm{m^{-3}}$ 時，$\omega_{p,e}/2\pi \approx 9\,\mathrm{MHz}$，而 $\omega_{p,\text{ion}}/2\pi \approx 0.21\,\mathrm{MHz}$——後者落在 AM 廣播頻段內！** 這解釋了為什麼**中波（AM）廣播會被電離層反射而繞地球傳播**，而**短波（SW）會穿透 F 層**（因為 $f > f_{p,e}$）。

**裁決二：地磁場的效應——「磁化等離子體」的雙重折射。**

**加入地磁場 $\mathbf{B}_0 = B\hat{z}$，並讓傳播方向與 $\mathbf{B}_0$ 成夾角 $\theta$。**

**電子在磁場中做螺旋運動，其迴轉（gyro）頻率為**

$$\omega_c = \frac{eB}{m_e} \quad(\text{帶電子的旋轉頻率})$$

**在 $\mathbf{E}$ 沿 $z$、$\mathbf{B}$ 沿 $y$ 的簡化幾何中，運動方程給出：**

$$\frac{dv_x}{dt} = -\frac{e}{m}E_0\cos\omega t + \omega_c v_z$$
$$\frac{dv_z}{dt} = -\frac{e}{m}E_0\sin\omega t - \omega_c v_x$$

**這是一個「受迫的進動」問題，其解可分為兩個圓偏振分量（左旋與右旋），分別對應「O 線」與「X 線」。**

**代入平面波解，得到折射率的兩個分支（即阿普爾頓-哈特里方程）：**

$$N^2 = 1 - \frac{X}{1-Y^2} \pm \sqrt{\frac{Y^4}{4(1-Y^2)^2} + \frac{Y^2}{1-Y^2}}$$

**這個方程的物理意義值得逐項拆解：**

| 項 | 意義 |
|---|---|
| $1$ | 真空折射率 |
| $-\dfrac{X}{1-Y^2}$ | 電子極化的貢獻（**等離子體頻率**，被磁場修正） |
| $\dfrac{Y^2}{1-Y^2}$ | 電子迴旋運動的貢獻（**迴轉頻率**） |
| $\pm$ | 兩種偏振態（O 線與 X 線） |

**最漂亮的一點是：** 當 $Y \to 0$（即頻率遠高於迴轉頻率，或 $B \to 0$），方程退化為 $N^2 = 1 - X$，**回到無磁場的等離子體公式**。**這是理論的自洽性檢驗，也是阿普爾頓方程在 1924 年能建立的原因（當時人們已知道高頻無線電在實踐中幾乎不受地磁場影響，因此 $Y\ll1$ 的近似是安全的）。**

**裁決三：「分層的大氣」——一個從 radio 曲線長出來的宇宙結構。**

阿普爾頓的實驗最終導出了地球大氣的標準分層模型：

| 層 | 高度 | 電子密度峰值 | 存在於 | 命名 |
|---|---|---|---|---|
| D 層 | 60–80 km | $10^3$–$10^4\,\mathrm{m^{-3}}$ | 僅白天 | — |
| E 層 | 90–120 km | $10^{5}$–$10^{6}\,\mathrm{m^{-3}}$ | 白天為主 | **Kennelly–Heaviside 層**（1925 命名） |
| F 層 | 150–450 km | $10^{12}\,\mathrm{m^{-3}}$ | 全天 | **阿普爾頓層（1932/1947）** |
| F1 | ~200–230 km | 次峰 | 僅白天 | 阿普爾頓 1947 |
| F2 | ~250–350 km | 主峰 | 全天 | 阿普爾頓 1947 |

**這張表是阿普爾頓諾獎工作的直接產物，也是 20 世紀「地球不是一個球面，而是一層套一層的洋」的圖像來源。**

**裁決四：阿普爾頓方程在 1990 年代之後的復興——「太空天氣」的科學。**

阿普爾頓-哈特里方程在雷達時代是「通信工程工具」。但 1990 年代之後，它成為**「太空天氣」（space weather）** 科學的核心：

- **CME（coronal mass ejection，日冕質量拋射）** 撞擊地球磁層 → 改變 $B$ → 改變 $f_o, f_x$ → **改變短波通信的可用頻段、GPS 的電離層延遲誤差、雷達的探測高度**；
- **太陽活動週期（11 年）** 驅動 $F$ 層電離層的長期變化 → 影響短波通信的「最佳頻率」；
- **2017 年 9 月的卡魯尼卡事件**：強 CME 使低緯度電離層幾乎消失，GPS 與無線電嚴重受干擾。

**因此阿普爾頓 1947 年建立的方程，是當今「空間氣象預報」的理論祖先。**

**裁決五：本案在諾獎史中的定位——「把無線電變成天文學與地球物理的探針」。**

阿普爾頓的貢獻可以分兩層，而第二層更重要：

**第一層（諾獎表彰的）：發現並刻畫了 F 層。**

**第二層（更重要的）：他示範了「用一個人造的電磁波作為尺子，量測看不見的結構」。**

**這是一種全新的實驗方法論，它在 20 世紀後半葉被複製了無數次：**

| 方法 | 被量的東西 | 諾獎 |
|---|---|---|
| **雷達 sounding**（阿普爾頓，1927） | 電離層 | **1947** |
| **射電天文**（Ryle, Hewish） | 宇宙射電源 | 1974 |
| **雷達測月與測行星** | 月球與行星的距離 | 1960 |
| **射電天文與 CMB**（Penzias, Wilson） | 宇宙微波背景 | 1978 |
| **雷達探測土衛六的液態甲烷** | 天體表面 | — |
| **VLBI**（Very Long Baseline Interferometry） | 黑洞的「影子」 | 2020 |
| **中性原子干涉重力儀** | 局部重力常數 | — |

**同一個物理（電磁波的傳播），在不同的天體上，被用來量度完全不同的東西。** 這是本卷可以貢獻給全書的一條「方法論主線」。

## 後果

| 年份 | 影響 |
|---|---|
| 1921–1922 | 無線電波沿地球表面繞射的理論；短波全球通信的物理基礎。 |
| 1924 | **阿普爾頓方程**建立。 |
| 1926 | 區分出 E 層與 F 層。 |
| 1927 | **雷達 sounding 首次探測到 F 層**。 |
| 1932 | 發現 **O/X 分裂**現象。 |
| 1934 | 把 O/X 分裂歸因於地磁場，建立磁化等離子體理論。 |
| 1938–1939 | 阿普爾頓主持倫敦大學學院，**戴維孫的電子繞射實驗在其領導下完成**（1937 諾獎）。 |
| 1940–1945 | 阿普爾頓主持英國雷達研究委員會，並任 **Tube Alloys 核武計畫**主管。 |
| 1947 | **諾獎頒發**；**F 層分為 F1、F2**；夜间的 F1 層被發現會消失。 |
| 1948 | 阿普爾頓當選皇家科學院院士。 |
| 1950s | **「太空天氣」的早期研究**：太陽活動與 F 層的關聯。 |
| 1957 | **人造衛星**升空（蘇聯 Sputnik）——此時人們已經能用 radio 從地面量到 $10^5$ km 外的電漿層。 |
| 1958 | NASA 成立；「空間環境」成為系統研究對象。 |
| 1960s | **Topside sounding**（從衛星向下探測電離層頂）、**探空火箭**測量電子-中性粒子碰撞（$\nu_e$、$\nu_i$ 的溫度）。 |
| 1969 | 阿普爾頓退休，長期從事愛丁堡大學的改革。 |
| 1980s | **超低頻（ULF）與極低頻（ELF）** 通信利用 D 層的反射；電漿層-雷達-通訊耦合。 |
| 1990s | **Appleton-Hartree 方程**成為「太空天氣」預報模型的基礎。 |
| 2003 | 雙層**電漿層-不規則層（irregularity）**模型確立。 |
| 2017 | 卡魯尼卡事件：電離層被 CME 剝蝕，GPS 與無線電嚴重受干擾。 |
| 2020 | **VLBI 對銀河系中心（Sgr A*）的成像**——把阿普爾頓的「用電磁波量不可見結構」推到黑洞視界。 |
