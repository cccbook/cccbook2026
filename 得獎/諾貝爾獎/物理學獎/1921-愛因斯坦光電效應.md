# 1921 · 愛因斯坦光電效應：光子的戶口名簿

> 1921 諾貝爾物理學獎（1922 年補頒）：阿爾伯特·愛因斯坦，表彰「理論物理學之貢獻，特別是光電效應定律之發現」——刻意不提相對論

## 案情提要

1905 年，專利局職員愛因斯坦讀到勒納 1902 年的實驗報告，發現一樁經典物理無法解釋的「懸案」：

- 光照射金屬打出電子，但**電子動能與光強無關**，只與**頻率**有關。
- 存在**截止頻率** `ν₀`：低於此頻率，光再強也打不出電子。
- 效應是**瞬時**的（< 10⁻⁹ s）——經典波動理論預言電子需要時間「積蓄」能量。

## 前因

- 1887 赫茲偶然發現紫外光可助長火花放電（發現者本人沒意識到它的意義）。
- 1902 勒納測量確立上述反直覺事實。
- 1900 普朗克已提出 `E = nhν`（見 [1918-普朗克量子假說](1918-普朗克量子假說.md)），但只當作數學技巧，且僅限物質振子——**光的本身仍是連續波**。

## 愛因斯坦的推理

普朗克說「能量以 hν 為單位交易」；愛因斯坦往前推一步：**光本身就是一顆顆能量子**。光束不是連續的浪，而是粒子雨。每個光子把全部 `hν` 交給一個電子：

**光電方程式**：

`½ m v²_max = hν − Φ`

其中 `Φ` 為金屬的功函數（把電子拔出表面所需的「保釋金」）。

三個懸案一次破解：

| 實驗事實 | 理論解釋 |
|---|---|
| 動能只看頻率 | 一個光子對一個電子，一對一交易 |
| 截止頻率 | `hν < Φ` 時連保釋金都付不起 |
| 瞬時發生 | 能量無需累積，單光子即付清 |

## 調查的雙重反轉

- **密立根反對辦案**：密立根本人不信光子，花了十年（1914–1916）做精密實驗想推翻此式——結果每一項數據都**完美吻合**，反而精確測出 `h`。他 1923 年的諾獎正是「敵方證人轉為關鍵證人」的經典。
- **康普頓最終定讞**：1923 年康普頓效應（見 [1927-康普頓效應](1927-康普頓效應.md)）顯示 X 光光子與電子像撞球般彈性碰撞，波動說無法解釋。光子自此在實驗上不可否認。

## 為什麼不頒給相對論？

諾貝爾委員會檔案顯示：相對論當時仍受哲學爭議與（帶有反猶色彩的）批評纏身，委員選擇實驗證據最堅實的光電效應「安全過關」。愛因斯坦本人視相對論為更重要工作，領獎時致詞卻只講相對論——一段著名的錯位。

## 後果

- 光電二極體、太陽能電池、CCD（2009 諾獎）、光電倍增管——今天所有「把光變電」的技術都源於這條方程式。
- 量子電動力學（見 [1965-量子電動力學](1965-量子電動力學.md)）最終統一了光的波粒二象性。
- 波粒二象性的數學：`E = hν = ħω`，`p = h/λ = ħk`
