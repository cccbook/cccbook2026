# 1952 · 布洛赫與珀塞爾：把共振從「一顆原子」搬進「一塊固體」

> 1952 諾貝爾物理學獎：費利克斯·布洛赫（Felix Bloch, 1905–1983，瑞士／美國）與愛德華·米爾斯·珀塞爾（Edward Mills Purcell, 1912–1997，美國）——表彰「他們發展了用於核磁精密量測的新方法，並以此所作的相關發現」（for their development of new methods for nuclear magnetic precision measurements and discoveries in connection therewith）。

## 懸案（案情提要）

1944 年，拉比用**分子束**完成了第一個核磁共振實驗。**但那是一個「一次只能量一顆原子」的方案。**

**1946 年 wanting 一整塊物質的核磁共振時，物理學家撞上了兩堵牆：**

**第一堵牆：「看不到」的問題。**

在拉比的分子束實驗中，原子束是一顆顆飛過磁場的，偵測靠「熱絲」或計數器——**每顆原子都是獨立的一次事件**。

**但在固體或液體樣品中，有 $10^{22}$ 個核同時存在。你不可能一個一個地「看」它們。**

**解法（這是 NMR 從「原子物理」變成「材料科學」的關鍵一步）：**

> **不要去「看」個別的核，而是去「聽」它們合體的共鳴。**

**具體做法：把樣品放在一個均勻磁場 $B_0$ 中，然後用一個「接收線圈」繞著樣品，測量線圈中感應到的電壓。**

**因為 $10^{22}$ 個核的總磁化向量 $M$ 在受到射頻脈衝後會整體「進動」，這個進動會在線圈中產生一個以 $\gamma B_0$ 為頻率的感應 EMF——所有核的訊號是「相干疊加」的！**

**第二堵牆（也是更深刻的一堵）：噪聲與線寬。**

珀塞爾與布洛赫各自獨立面對這個問題，得出了兩條不同的解法：

| 問題 | 布洛赫的解法 | 珀塞爾的解法 |
|---|---|---|
| **訊號太弱** | 承認它，用「連續波（CW）」慢慢掃頻 | **用更強的磁場** $B_0$（9000 高斯），因為熱極化 $\propto B_0/T$ |
| **線太寬** | 發展「**Bloch 方程**」描述弛豫，並預言「**自旋回波**」可消除不均勻 | **用「自旋回波」量測 $T_2$**（Hahn 1950） |
| **化學位移** | 預言「化學位移」的存在 | 發現「化學位移」 |

**1946 年 12 月，布洛赫與珀塞爾在《物理評論》的**同一期**上發表了他們的論文——**兩個人，兩個方法，同一個結果。** 這是科學史上最著名的「平行發現」之一。

**而他們的發現清單，才是這樁諾獎的真正內容：**

1. **液體與固體中的核磁共振被發現**（拉比的分子束方法無法處理）；
2. **弛豫時間 $T_1$ 與 $T_2$ 被定義並量測**（這兩個量是材料的「指紋」）；
3. **自旋回波被發明**（Hahn 1950）——**這是解決「線寬」問題的通用技術**；
4. **化學位移被發現**（1950 年代）——**這是 NMR 進入化學的門票**；
5. **超精細結構的核磁共振**——金屬中的 Knight shift（1949）與固體中的「化學位移分裂」。

**其中第 3 點（自旋回波）最值得單獨說明，因為它是「物理學的通用發明」。**

**1950 年，Erwin Hahn 的思路極其簡單卻深刻：**

**問題：** 樣品內的磁場不均勻（$B_0$ 有 $\delta B$ 的起伏），這讓不同的核有 slightly 不同的拉莫爾頻率，於是它們的進動逐漸「散相位」（dephase），訊號在 $\sim T_2$ 內衰減到零。

**Hahn 的洞見：** **不均勻性是「靜態」的——它不會隨時間改變。** 所以可以：

1. 用一個 **90° 脈衝**把所有核翻轉到橫平面；
2. 等一段時間 $t$（此時各核因靜態不均勻而散相位）；
3. 用一個 **180° 脈衝**把所有核**反轉**——**這讓「散開的相位」變成「反向的散開」，即重新聚集**；
4. 再等 $t$，所有核**重新同相** → 訊號重新出現（**「回波」**）。

$$\text{回波時刻} = 2t,\qquad S(2t) = S_0\,e^{-2t/T_2}$$

**這個「以反轉消除不均勻」的技巧，是 20 世紀物理學中「用控制論戰勝系統誤差」的最漂亮例子之一。** 它後來被用在 NMR、MRI、EPR（電子順磁共振）、以及 1980 年代的**量子計算糾錯**中。

## 調查

**第一件證物：NMR 的「偵測器革命」——從熱絲到線圈。**

**讓我們把這個核心裝置寫清楚。**

**（一）拉比的方案（1944）：**

```
[原子束] → [不均勻磁場] → [射頻場] → [分析磁場] → [熱絲偵測器]
```

**問題：** 一次只能量一顆原子；訊號是「計數」型的（有無），不是「連續」型的。

**（二）NMR（1946）的方案：**

```
                    ┌──────────────┐
        [射頻線圈]──│              │
                    │   樣品       │  在均勻磁場 B0 中
        [接收線圈]──│  （固體/液體）│
                    └──────────────┘
                              │
                    [均勻磁場 B0（大型磁鐵）]
```

**物理機制：**

**第一步：熱極化。** 在熱平衡下，核自旋沿 $-z$ 方向的比沿 $+z$ 方向多，其差值由玻耳茲曼分布給出：

$$\frac{N_{\uparrow}}{N_{\downarrow}} = e^{-2\Delta E/k_BT}, \qquad \Delta E = \hbar\gamma B_0$$

**淨磁化 $M_0$：**

$$M_0 = \frac{N}{V}\frac{\hbar\gamma B_0}{2k_BT}\ \text{（小極化近似）}$$

**讓我們算一下數字：** 對質子，$B_0 = 1\,\mathrm{T}$、$T = 300\,\mathrm{K}$：

$$\frac{\Delta E}{k_BT} = \frac{\hbar\gamma B_0}{k_BT} = \frac{1.0546\times10^{-34}\times(2.675\times10^8)\times1}{1.381\times10^{-23}\times300} = \frac{2.821\times10^{-26}}{4.143\times10^{-21}} = 6.81\times10^{-6}$$

**極化度只有百萬分之六。8！** 這正是珀塞爾要用**更強的磁場**的原因——**訊號正比於 $B_0$，所以把 $B_0$ 從 0.5 T 提到 2 T，訊號增加 4 倍。**

**第二步：射頻脈衝。** 用一個與 $B_1\perp B_0$ 的射頻場，頻率 $\omega_{\text{RF}} = \gamma B_0$（即「共振」），持續時間 $t_p$。**「翻轉角」為**

$$\theta_{\text{flip}} = \gamma B_1 t_p$$

**這是 NMR 的基本操作語言：**

| 脈衝 | 翻轉角 | 效果 |
|---|---|---|
| **90° 脈衝** | $\gamma B_1 t_p = \pi/2$ | 把 $M_z$ 倒到橫平面（$-y$ 方向） |
| **180° 脈衝** | $\gamma B_1 t_p = \pi$ | 把 $M$ 翻轉 $180^\circ$（**自旋回波用**） |
| **硬脈衝** | $\pi/2$ 加上相位 | 激發整個頻譜 |

**第三步：自由感應衰減（FID）。** 脈衝之後，磁化向量 $M$ 繞 $B_0$ 自由進動，同時因弛豫而衰減：

$$\mathbf{M}(t) = \left(M_x(0)e^{-t/T_2}\cos\omega_0 t + M_y(0)e^{-t/T_2}\sin\omega_0 t\right)\hat{\perp} + \left(M_0 + (M_z(0)-M_0)e^{-t/T_1}\right)\hat{z}$$

**第四步：接收線圈的感應電壓。**

$$V(t) = N A\,B_0\,\frac{dM_\perp}{dt} \propto \omega_0 M_\perp(0)\,e^{-t/T_2}\cos(\omega_0 t - \phi)$$

**第五步（關鍵）：把 FID 做傅立葉轉換 → NMR 頻譜。**

$$S(\nu) = \int_0^\infty V(t)e^{-i2\pi\nu t}dt \propto \frac{\omega_0 M_0 e^{-t/T_2}}{T_2 + i2\pi(\nu-\nu_0)}$$

**這就是「洛倫茲線型」的來源：**

$$\boxed{S(\nu) = \frac{S_0}{1 + \left(\frac{2(\nu-\nu_0)}{W}\right)^2}}$$

**這是一個重大變化：從「粒子計數」到「連續頻譜」。** NMR 給出的不是「有多少粒子」，而是「**有多少種類的核，各占多少，環境如何**」——**這是化學資訊的全新維度。**

**第二件證物：布洛赫方程——「自旋系統的動力學定律」。**

**這是布洛赫在 1935–1936 年（並於 1946 年發表）建立的方程組，是整個 NMR 理論的骨架。**

$$\frac{d\mathbf{M}}{dt} = \gamma\,\mathbf{M}\times\mathbf{B} - \frac{M_x\hat{x}+M_y\hat{y}}{T_2} - \frac{M_z-M_0}{T_1}\hat{z}$$

**三項的物理意義：**

| 項 | 物理 | 測得的量 |
|---|---|---|
| $\gamma\mathbf{M}\times\mathbf{B}$ | **進動**（繞 $B_0$ 的拉莫爾運動） | 化學位移 |
| $-\frac{M_\perp}{T_2}$ | **橫向弛豫**（自旋-自旋相互作用造成的相位散失） | **$T_2$**（測量局域場的均勻性） |
| $-\frac{M_z-M_0}{T_1}$ | **縱向弛豫**（自旋-晶格能量交換） | **$T_1$**（測量與晶格的耦合） |

**這三個參數 $(B_0, T_1, T_2)$ 加上化學位移 $\delta$，就是 NMR 能給你的全部「材料指紋」。**

**（a）縱向弛豫的物理（運動學模型）：** 核自旋與晶格（聲子、分子運動）交換能量。效率取決於**核的拉莫爾頻率 $\gamma B_0$ 是否與晶格的運動頻率「拍頻」**。

$$T_1^{-1} = \frac{1}{T_{1,\mathrm{intra}}} + \frac{1}{T_{1,\mathrm{inter}}} + \frac{1}{T_{1,\mathrm{dipole}}}$$

**（b）橫向弛豫：** $T_2 \le 2T_1$（一個普遍不等式），且

$$\frac{1}{T_2} = \frac{1}{2T_1} + \frac{1}{T_{2,\text{inhom}}}$$

**第二項就是「磁場不均勻」的貢獻——**這正是自旋回波要消除的項。**

**第三件證物：BPP 理論——「弛豫時間怎麼算出來」。**

**1948 年，Bloembergen、Purcell、Pound 建立的第一個弛豫理論，至今仍是液體 NMR 的標準。**

**核心：核自旋受到「由分子運動調變的局部磁場」的擾動。**

**（a）偶極-偶極弛豫（主要項）：** 兩個相鄰核的磁偶極相互作用

$$\mathbf{A}(t) = \frac{\mu_0}{4\pi}\frac{2\boldsymbol{\mu}_1\cdot\boldsymbol{\mu}_2 - 3(\boldsymbol{\mu}_1\cdot\hat{r})(\boldsymbol{\mu}_2\cdot\hat{r})}{r^3}$$

**其中 $\hat{r}$ 隨分子的棕色運動旋轉，因此 $\mathbf{A}(t)$ 是一個「隨機過程」，其自相關函數 $\langle A^2(t)A^2(0)\rangle$ 以相關時間 $\tau_c$ 衰減。**

**（b）BPP 的縱向弛豫率：**

$$\boxed{\frac{1}{T_1} = \frac{2}{3}\left(\frac{\mu_0}{4\pi}\right)^2\frac{\gamma^2\hbar^2\,n\,I(I+1)}{k_BT}\left[\frac{\tau_c}{1+\omega_0^2\tau_c^2} + \frac{3\tau_c}{1+4\omega_0^2\tau_c^2}\right]}$$

**（c）一個極重要的實驗結果（也就是「BPP 圖」）：**

$$\boxed{\text{以 } 1/T_1 \text{ 對 } \nu_0 \text{ 作圖，出現一個「山峰」，峰值在 } \nu_0 = 1/(2\pi\tau_c)}$$

**這就是「**BPP 圖**」——用 NMR 測量**化學交換速率**與**分子轉動相關時間**的標準方法。**

**讓我們算一個數字：** 對水中的質子，$T_1 \approx 2.9\,\mathrm{s}$（在 300 K、1.5 T）。這是生物 NMR 的基礎參數。

**（d）核 Overhauser 效應（NOE，1954 年 Overhauser 提出）：** 這是 NMR 中最重要的「結構參數」來源。

**物理：** 當射頻場恰好等於 $\omega_0$ 時，自旋能階人口差異被「抽空」（飽和），而人口差異的恢復透過 **cross-relaxation**（交叉弛豫）進行，效率取決於**核與核之間的偶極耦合**。

$$\text{NOE} \text{ 的強度} \propto r^{-6}$$

**這個 $r^{-6}$ 依賴是 NMR 結構解析的全部力量所在——它把「距離」直接變成「訊號強度」。**

**第四件證物：自旋回波——「用控制戰勝系統誤差」。**

**讓我們把 1950 年 Hahn 的實驗完整寫出。**

**脉冲序列：**

```
     90°            180°            檢測
      │   τ          │   τ            │
      ▼              ▼               ▼
   ───┐  ┌───────────────────────┐  ┌──
      │  │                        │  │
      └──┘                        └──┘
```

**物理推導：**

1. **$t=0$：** 90° 脈衝把 $\mathbf{M}_0 = M_0\hat{z}$ 翻到 $-y$ 方向。
2. **$0<t<\tau$：** 所有核以各自的 $\omega_i = \gamma(B_0 + \delta B_i)$ 進動，**相位差隨時間線性增長**：

$$\Delta\phi_i = \delta\omega_i\,t$$

3. **$t=\tau$：** 施加 180° 脈衝 → **每個核的自旋向量被反轉**，其進動相位差變成 $-\Delta\phi_i$（**注意：這裡的關鍵是「反轉」不僅翻轉了 $M_z$，也同時把 $M_x$ 與 $M_y$ 翻轉，因此相位差符號反轉**）。
4. **$\tau<t<2\tau$：** 相位差繼續以 $-\delta\omega_i(t-\tau)$ 演化。
5. **$t=2\tau$：** 相位差回到零：

$$-\delta\omega_i(2\tau-\tau) + \delta\omega_i\,\tau = 0$$

**所有核重新同相 → 訊號重新出現（回波）。**

**回波振幅：**

$$S(2\tau) = S_0\,e^{-2\tau/T_2}$$

**（因為縱向磁化在這段時間內按 $e^{-t/T_1}$ 衰減，實際上 $S(2\tau) \propto e^{-2\tau/T_1}e^{-2\tau/T_2}$。）**

**自旋回波的威力：**

| 問題 | 無回波 | 有回波 |
|---|---|---|
| 磁場不均勻造成的線寬 | 掩蓋了真實的 $T_2$ | **被完全消除**（因為 $\delta B$ 是靜態的） |
| 量到的 $T_2$ | 只是「視覺 $T_2^*$」 | **真實的 $T_2$** |
| 分辨率 | 受 $B_0$ 均勻度限制 | **由 $T_2$ 決定** |

**這就是 Hahn 定理的本質：靜態系統誤差可以被「翻轉」掉。** 這是一個可以推廣的物理思想。

**第五件證物：化學位移——「NMR 進入化學的門票」。**

**1950 年代初期（Rexxford、Dickinson、Williams、Roberts 與 Bloembergen 等人）發現：**

**同一種類型的核，在不同化學環境中，處於不同的有效磁場中，因此共振頻率略有不同。**

**來源：電子雲的「化學位移（chemical shielding）」。**

**電子在外部磁場 $B_0$ 中感應出誘導磁矩，產生的屏蔽場**

$$\mathbf{B}_{\text{shield}} = \sigma\,\mathbf{B}_0$$

**因此核感受到的有效場為**

$$B_{\text{eff}} = B_0(1-\sigma), \qquad \nu = \frac{\gamma B_0(1-\sigma)}{2\pi}$$

**化學位移的定義（以四甲基矽烷 TMS 為內部標準）：**

$$\boxed{\delta = \frac{\nu_{\text{sample}} - \nu_{\text{TMS}}}{\nu_0}\times10^6\ \ (\text{ppm})}$$

**為什麼化學位移如此重要？因為它是「電子環境的指紋」。**

**一個典型的 ${}^{1}\mathrm{H}$ NMR 數據表（60 MHz 儀器）：**

| 官能基 | $\delta$ (ppm) | 積分 | 裂解 |
|---|---|---|---|
| $\mathrm{CH_3}-\mathrm{R}$ | 0.9 | 3H | 三重峰 |
| $\mathrm{CH_2}-\mathrm{R}$ | 1.2–1.4 | 2H | 多重峰 |
| $\mathrm{CH}-\mathrm{R}$ | 1.5–1.7 | 1H | 多重峰 |
| $\mathrm{CH_3}-\mathrm{CO}-$ | 2.1 | 3H | 三重峰 |
| $\mathrm{Ar}-\mathrm{H}$ | 6.5–8.5 | 多重 | 多重峰 |
| $\mathrm{C}\equiv\mathrm{C}-\mathrm{H}$ | 2–3 | 1H | — |
| $\mathrm{CHO}$ | 9.5–10.5 | 1H | 單峰 |
| $\mathrm{OH}$ / $\mathrm{NH}$ | 1–6 | 1H | 單峰（可變） |
| $\mathrm{COOH}$ | 10–13 | 1H | 單峰 |

**加上「自旋-自旋耦合常數 $J$」（以 Hz 表示，與磁場無關）：**

$$J \sim 6\text{–}8\,\mathrm{Hz}\ (\text{同碳}), \quad 0\text{–}3\,\mathrm{Hz}\ (\text{跨碳}), \quad 6\text{–}12\,\mathrm{Hz}\ (\text{烯鍵})$$

**於是 NMR 提供三種資訊：**

1. **化學位移 $\delta$** → 有哪些官能基；
2. **耦合常數 $J$** → 骨架的連接方式；
3. **積分** → 各官能基的相對數目。

**這三樣加起來，就足以在紙上「重建」一個分子。** 這是 1950 年代化學革命的核心。

**第六件證物：金屬中的「Knight shift」——「費米海也會改變共振頻率」。**

**1949 年，W. D. Knight 在液態金屬中發現了一個微小的但系統性的共振頻率偏移。**

**物理：** 在金屬中，導電電子的**費米海**產生一個與核無關的**局域磁場**（由電子自旋的極化造成），使核感受到的場增加：

$$\Delta B = B_{\text{contact}} = \frac{8\pi}{3}\mu_0\,\mu_N n_\uparrow \mu_B \quad\text{（超精細耦合）}$$

**而 $n_\uparrow$ 的不對稱度取決於費米能處的態密度：**

$$\frac{n_\uparrow - n_\downarrow}{n} = \frac{P_F}{P_N}$$

**因此 Knight shift 直接量測了金屬的費米面態密度。**

**這是「不相容原理」（1945 諾獎）→ 費米-狄拉克分布（1938 諾獎）→ 費米面 → NMR 訊號」的完整因果鏈**——**費米 sea 的第一個「直接指紋」。**

## 理論裁決

**裁決一：拉莫爾頻率與化學位移——「共振頻率就是核的身分證」。**

**核在磁場中的進動：**

$$\omega_L = \gamma B_0, \qquad \gamma = \frac{g\mu_N}{\hbar}$$

**有效場與化學位移：**

$$\omega_{\text{eff}} = \gamma B_0(1-\sigma), \qquad \delta = \frac{\omega_{\text{eff}}-\omega_{\text{ref}}}{\omega_0}\times10^6$$

**對質子（$\gamma/2\pi = 42.577\,\mathrm{MHz/T}$）：**

| $B_0$ | $\nu_0$ | 解析度（$1\,\mathrm{Hz}$ 對應的 ppm） |
|---|---|---|
| 0.5 T | 21.3 MHz | $4.7\times10^{-8}$ = 0.047 ppm |
| 1.5 T | 63.9 MHz | $1.6\times10^{-8}$ = 0.016 ppm |
| 9.4 T | 400 MHz | $2.5\times10^{-9}$ = 0.0025 ppm |
| 21.1 T | 900 MHz | $1.1\times10^{-9}$ = 0.0011 ppm |

**讓我們注意到一個關鍵事實：NMR 的「解析度」（以 ppm 計）在提高磁場時**不會**改善**——因為 ppm 本身就是相對量。**

$$\text{絕對解析度（Hz）} = \delta \times \nu_0 \propto B_0$$

**所以提高磁場改善的是「絕對解析度」，而這正是超導磁體（1960 年代）成為 NMR 市場主力的原因。**

**裁決二：弛豫——「兩個時間常數，兩種資訊」。**

**讓我們把 $T_1$ 與 $T_2$ 的物理完整寫出。**

**（a）縱向弛豫 $T_1$（自旋-晶格）：** 核自旋把能量交給晶格（分子運動、聲子）。

**運動學模型：** 核自旋的拉莫爾頻率 $\omega_0$ 與晶格運動的頻譜有「重疊」才有效。

$$\frac{1}{T_1} \propto \left[\frac{\tau_c}{1+\omega_0^2\tau_c^2} + \frac{3\tau_c}{1+4\omega_0^2\tau_c^2}\right]$$

**這裡有一個beautiful的實驗事實：**

> **當 $\omega_0 \tau_c \approx 1$（即拉莫爾頻率等於相關時間倒數）時，$1/T_1$ 達到最大。** 這就是 BPP 圖的「山峰」。

**（b）橫向弛豫 $T_2$（自旋-自旋）：** 核自旋之間的偶極相互作用造成相位散失。

$$T_2 \le 2T_1$$

**（c）視覺 $T_2^*$：**

$$\frac{1}{T_2^*} = \frac{1}{T_2} + \gamma\,\Delta B$$

**（d）自旋回波消除 $\gamma\Delta B$ 項——這是 Hahn 的定理。**

**裁決三：核 Overhauser 效應與「結構生物學的引擎」。**

**讓我們把這個機制寫清楚，因為它是 2002 年化學獎（Wüthrich）的核心工具。**

**核 Overhauser 效應（NOE）：**

- **第一步：** 分子有兩個核 $A$ 與 $B$，它們之間有偶極耦合，耦合常數

$$r_{AB}^{-3}\ \text{正比於}\ J_{AB}\ (\text{標量耦合）\qquad\text{或}\qquad r_{AB}^{-6}\ \text{正比於}\ \text{交叉弛豫率}$$

- **第二步：** 對 $A$ 施加射頻脈衝（飽和或選擇性激發），$A$ 的人口差異被破壞；
- **第三步：** $A$ 透過**交叉弛豫**（$\sigma_{AB}$）把人口差異傳給 $B$；
- **第四步：** $B$ 的穩定磁化改變 → **$B$ 的訊號強度改變**。

$$\frac{I_B^{\text{sat}}}{I_B^0} - 1 = \frac{\sigma_{AB}}{\sigma_B}\ \text{（一般情形）}, \qquad \sigma_{AB} \propto r_{AB}^{-6}\ \text{（大分子極限）}$$

**關鍵：$r^{-6}$ 是極陡的依賴。**

**讓我們算一下：兩個核的距離從 $3.0\,\text{Å}$ 增加到 $3.5\,\text{Å}$（只增加 17%），NOE 強度改變為**

$$\left(\frac{3.0}{3.5}\right)^6 = 0.42$$

**——強度減半！** 這就是為什麼 NMR 能給出「距離約束」。

**裁決四：NMR 的「量測維度」——從物理到化學到生物學的擴張。**

| NMR 參數 | 給出的物理/化學資訊 | 對應的諾獎 |
|---|---|---|
| **化學位移 $\delta$** | 官能基、電子環境 | 1981（雷射光譜） |
| **耦合常數 $J$** | 鍵結路徑、幾何構型 | 1991（化學獎 Ernst） |
| **積分** | 原子數 | — |
| **$T_1$** | 分子運動、化學交換 | — |
| **$T_2$** | 局部磁場均勻性、交換 | — |
| **NOE** | **核間距離**（$r^{-6}$） | 2002（化學獎 Wüthrich） |
| **耦合常數（偶極）** | **鍵角** | 2002 |
| **残余偶極耦合（ RDC）** | **距離與方向**（$\sim r^{-3}$） | 2002 |
| **Knight shift** | 金屬費米面態密度 | 1938（費米） |
| **核自旋的量子相干** | 量子資訊 | 2012（物理獎 Haroche/Wineland） |

**裁決五：NMR 與 MRI 的分流——「同一個物理，兩個不同的目的」。**

**1950 年代的 NMR 是「化學的工具」；1970 年代的 MRI 是「醫學的工具」。** 但它們的物理基礎完全相同。

**MRI 的關鍵是**把「NMR 頻率」換成「**位置編碼**」：

- **線性梯度 $G_x$：** $\omega(x) = \gamma(B_0 + G_x x)$ → **頻率 encodes 位置**；
- **相位編碼 $G_y$：** 用脈衝序列累積相位；
- **切片選擇 $G_z$：** 用射頻脈衝的頻寬選定 $z$ 層。

$$S(\mathbf{r}, \tau) = \int d\mathbf{r}' \rho(\mathbf{r}')\,e^{-i2\pi\gamma\,\mathbf{G}(\tau)\cdot\mathbf{r}'}$$

**做二維傅立葉轉換 → 影像。**

**這就是「布洛赫方程 + 梯度編碼」的組合，1973 年由 Mansfield 與 Hahn 完成（1990 年諾貝爾醫學獎）。**

## 後果

| 年份 | 影響 |
|---|---|
| 1946 | **NMR 在液體與固體中被發現**（布洛赫與珀塞爾在同一期《物理評論》發表）。 |
| 1948 | **BPP 弛豫理論**（Bloembergen–Purcell–Pound）；「BPP 圖」成為測量分子運動的標準。 |
| 1949 | **Knight shift**：金屬費米 sea 的第一個直接指紋。 |
| 1950 | **Hahn 發明自旋回波**——「用反轉消除靜態系統誤差」。 |
| 1952 | **諾獎頒發**；**Bloch 明確論證「核感應」信號的存在**。 |
| 1953–1955 | **化學位移被建立**；商業 NMR 儀器問世（Varian 的 **A-60**，60 MHz）。 |
| 1954 | Bloembergen 建立**固體 NMR 理論**（各向異性、偶極耦合、自旋擴散）；**核 Overhauser 效應**被提出。 |
| 1960s | **超導磁體 NMR** 問世（400 MHz）；**FT-NMR**（Ernst 1966）大幅提升靈敏度。 |
| 1969 | 400 MHz 商用儀；**高分辨固體 NMR** 成立。 |
| 1971–1973 | **MRI（磁共振成像）** 由 Mansfield 與 Hahn 發明（1990 醫學獎）。 |
| 1977 | **2D NMR**（Ernst）開啟「化學位移 × 化學位移」的二维譜。 |
| 1980s | **多核 NMR**（${}^{13}\mathrm{C}$、${}^{15}\mathrm{N}$、${}^{31}\mathrm{P}$）；**固體 NMR** 用於聚合物的結構分析。 |
| 1984 | **FT-ICR** 與 **FT-NMR** 的極高解析度（$10^{-3}$ ppm）。 |
| 1991 | **Ernst 獲諾貝爾化學獎**（高解析度 NMR）。 |
| 1997 | **MRI 與 PET 的融合**（生理醫學獎 2003 給 MRI）。 |
| 2002 | **Wüthrich 獲化學獎**（NMR 蛋白質結構解析）——「$r^{-6}$ 距離約束」的勝利。 |
| 2012 | **Haroche 與 Wineland 獲物理學獎**（量子操控）——NMR 成為量子資訊的先驅。 |
| 2015 | NMR 與**化學動力學**、**代謝組學**（metabolomics）結合。 |
| 2017 | **超導 NMR 與「核磁共振量子電腦」**的實作。 |
| 2024 | **蛋白質設計**（化學獎）大量使用 NMR 結構約束。 |
