# 1917 · 巴克拉：每一種元素都有自己的X射線指紋

> 1917 諾貝爾物理學獎：查爾斯·戈爾頓·巴克拉（Charles G. Barkla, 1877–1942，英國）——表彰「他發現元素的特徵倫琴輻射」（For his discovery of the characteristic Röntgen radiation of the elements）。

## 懸案（案情提要）

1912 年底，X 射線的研究突然加速。與此同時，一個根本性的問題浮出水面：**X 射線管發出的輻射到底是什麼？**

當時的德國物理學家（當時的說法是「德國管的輻射」）有兩種成分：
1. **連續譜（bremsstrahlung）**：與靶材無關，隨電壓升高而加寬，截止波長由 Duane–Hunt 定律決定；
2. **特徵輻射（characteristic radiation）**：只依賴靶材，每種元素各有獨特的線狀譜線，且與管電壓無關（只要電壓超過某個「激發閾值」）。

第二種成分的存在是極其可疑的：它是什麼？如果 X 射線只是電子撞擊靶材產生的「輻射尾波」，那麼靶材的**化學成分**不該影響譜線。線狀譜意味著某種**離散、元素特異的過程**——也就是某種**原子內部的能階**。

但巴克拉面對的難題是：**他無法直接測量 X 射線波長**。1912–1913 年的 X 射線波長量測方法（布拉格式的角度測量）需要知道晶體結構或已知標尺，精度不夠且只覆蓋窄波段；1915 年的 Compton 效應尚未問世。所以巴克拉用了一個完全不同的辦法：**用吸收而非散射來「標記」X 射線**。

他的實驗設計精巧而樸素：

- 讓 X 射線穿過一片**厚薄可變**的吸收體（鋁片），記錄底片上的黑度隨厚度的變化，得到吸收曲線；
- 換一種吸收體（銀、銅、鋅等），曲線形狀完全不同；
- 關鍵觀察：**不同厚度的吸收體會給出不同數量的「折點」**，每一個折點代表一條**特徵吸收邊**（K 吸收邊），也就是某條特徵線的波長位置。

巴克拉的實驗把「特徵線的存在」從「線狀譜的目視觀察」變成了「可量測的吸收曲線折點」。他系統掃過了從鋁到鈦的一系列元素，證明：**每一種元素都有它自己的一組特徵 X 射線線**——這就是「元素的 X 射線指紋」。

這樁案子的深層重要性：**它第一次以實驗證明原子內部存在「與元素身分相關」的離散結構**。這是 1913 年莫塞萊定律（1915 年諾獎）、1913 年波耳原子模型（1922 年諾獎）、1925 年法蘭克-赫茲實驗（1925 年諾獎）的共同前提。而且巴克拉還發現了一個更精細的分類：**同一元素有兩套不同的線系**（K 系與 L 系），這意味著原子內部有**至少兩個不同的電子殼層**——這是 1913 年莫塞萊、1915 年巴克拉、1916 年 Kossel、1922 年波耳、1926 年薛丁格接力的證據鏈。

巴克拉還有一項後來才顯出價值的發現：**元素的高頻吸收係數 $\mu$ 與原子序之間有近似正比關係**，$\mu/\rho \propto Z$。這條規律後來成為 X 射線影像與放射防護的定量基礎。

（值得記錄的是：巴克拉因在第一次世界大戰中從事反潛水艇的聲學研究而積累大量技術難題，最終**沒有獲得 1915 年諾貝爾獎**——1915 年的物理學獎頒給了布拉格父子。委員會把票給了更「定量」的發現。巴克拉一直工作到 1942 年去世。）

## 調查

**第一件證物：吸收曲線上的「折點」。** 巴克拉的方法建立在比爾-朗伯定律（Beer–Lambert law）上：

$$I(x) = I_0\, e^{-\mu x}, \qquad \mu = \frac{\ln(I_0/I)}{x}$$

但 X 射線的 $\mu$ 不是常數——它隨波長變化，且在**特徵吸收邊**處躍升。當使用**連續譜 X 射線**時，長波（低能量）的部分被強烈吸收，短波部分穿透，因此底片黑度隨吸收體厚度變化會出現一段「指數尾巴」加上**對數斜率的變折點**。巴克拉量測的是這個折點位置。

在譜學上，這相當於把「吸收係數對光子能量的函數」畫出來，看見階躍：

$$\mu(E) = \sum_{i} \theta(E - E_i)\, \mu_i$$

其中 $E_i$ 是各電離能（K 邊、L$_1$ 邊、L$_2$ 邊…）。這正是後來 X 射線吸收邊精細結構（XANES）研究的源頭。

**第二件證物：K 系與 L 系的辨識。** 巴克拉發現對同一元素，隨吸收體種類不同會出現**一個或兩個**折點。當吸收體是該元素本身時，只有特定的折點位置會變化。這個觀察意味著：同一元素有**兩套不同的特徵線**，其能量分別對應不同的電子殼層（K 殼層 = 最內層，$n=1$；L 殼層 = $n=2$）。

巴克拉在 1911 年就已用「吸收體的化學組成與厚度的雙重變化」分離出 K 與 L 系。物理意義是：**原子內部有至少兩層結構不同的電子群**。這是「原子有殼層」的第一個實驗證據，與 1904 年 J.J. 湯姆森（J. J. Thomson）提出的「葡萄乾布丁模型」（正電荷連續分布 + 電子嵌其中）**直接衝突**——在湯姆森的模型裡，電子沒有可分辨的殼層。

**第三件證物：吸收係數與原子序的關係。** 巴克拉在 1909–1911 年累積的數據給出：

$$\frac{\mu}{\rho} \propto Z^{4\text{–}5}$$

這個近似正比關係（指數在 4 到 5 之間，視波長而定）是後來 1913 年莫塞萊定律的量化基礎，因為**吸收邊的位置**（$E_K = -R_H (Z-b)^2$）與**吸收強度**是同一份資料的兩個面向。

**第四件證物：X 射線散射與吸收的機制。** 巴克拉自己也提出了「X 射線散射主要來自原子內電子」的觀點。1906 年由 Compton（1927 年諾獎）提出的機制——**電子在 X 射線光子場中反衝**——正是電子尺度上 X 射線與物質作用的完整描述。而 Compton 效應本身正是用**波長可量測的 Mo K$\alpha$ 線**做的：$\lambda_{\text{Mo K}\alpha} = 0.071\,\mathrm{nm}$，正是巴克拉所建立元素特異譜線的重要實例。

**第五件證物：為什麼「特徵線」是全線譜中最有用的部分。** 巴克拉清楚指出：用於分析與量測的 X 射線必須是**單色**的，而連續譜做不到，唯有特徵線可以。因此他的發現直接催生了 1912–1913 年的「X 射線光譜儀」（Bragg 分光計）與 1913 年莫塞萊的系統工作。巴克拉自己的貢獻是把「有哪些特徵線、它們在哪裡」變成可系統查表的資料。

## 理論裁決

**裁決一：特徵 X 射線的能量公式（巴克拉的結果 → 波耳的解釋）。** 巴克拉在 1911 年已能提出一個大膽的猜測：特徵線的能量應與電子**在原子核場中的結合能**有關。1913 年波耳用他的原子模型給出了定量答案：

$$\frac{1}{\lambda} = R_{\infty}\,(Z - \sigma)^2 \left[\frac{1}{n_1^2} - \frac{1}{n_2^2}\right], \qquad R_{\infty} = \frac{m_e e^4}{8\varepsilon_0^2 h^3 c}$$

這就是**莫塞萊定律的完整波耳形式**。對 K 線（$n_1 = 1$）：

$$\sqrt{\nu} = R_{\infty}^{1/2}(Z-\sigma)\sqrt{1 - 1/n_2^2}$$

1922 年諾獎（波耳）與 1917 年諾獎（巴克拉）在這裡合成同一條線：**巴克拉給出「譜線存在且元素特異」的實證，波耳給出「譜線位置由什麼決定」的理論**。這是科學史上最典型的一次「實驗先行、理論後補」配對。

**裁決二：電子殼層的存在——對湯姆森模型的第一次致命反證。** 1904 年 J.J. 湯姆森的原子模型：正電荷均勻分布於半徑 $r_0$ 的球內，電子嵌入其中。若如此，則所有元素的 X 射線譜應**連續變化**、沒有特徵線；而且不該有「K 系、L 系」之分。巴克拉的兩套線系直接反駁了這一模型，迫使物理學家接受 **Rutherford (1911) + 玻耳 (1913)** 的「核 + 電子殼層」圖景。這裡可以看到諾獎史的一條暗線：**1906 年諾獎的湯姆森原子模型，在 11 年後被 1913 年與 1917 年兩屆諾獎的工作所取代**。

**裁決三：電離能階梯與原子內能階的實驗等價。** K 吸收邊的能量就是 K 殼層的電離能：

$$E_K = R_{\infty}(Z-\sigma)^2 \quad (\text{從 K 殼層到無限遠})$$

L$_1$ 邊對應 2s，2p 分別對應 L$_2$、L$_3$ 邊。而**吸收邊的精細結構**（1930–40 年代發展）最終測出了每個元素的每個能階值——這是後來核磁共振、$\gamma$ 射線天文學（2018 年諾獎）等領域的共同基礎。

**裁決四：截面與衰減係數的實用化。** 巴克拉的資料被立刻轉化為兩套工程語言：
- **衰減係數** $\mu(E) = \rho \left(\frac{\mu}{\rho}\right)$：用於 X 射線機的設計與屏蔽計算；
- **微分衰減與光电效應截面**：$\mu/\rho \propto Z^n/E^3$，直接導向「$\gamma$ 射線屏蔽厚度」與「X 射線防護」標準。

巴克拉自己在 1910–1915 年大量研究 X 射線在生物組織中的衰減與劑量，這條線在 1920 年代催生了**放射學**與放射治療，而他也因此獲得大量醫學上的認可。

**裁決五：諾獎委員會的取捨——「發現了什麼」比「量得多精」更難被替代。** 巴克拉的問題在於，他發現的東西**本身太簡單、太定性**。它是「現象存在」的宣告，而不是「量的關係」的確立。諾獎委員會給了布拉格父子 1915 年（量的律則）與勞厄 1914 年（現象的發現），巴克拉則被留下。委員會在 1939 年曾考慮補授，最終因巴克拉於 1942 年去世而作罷。

| 年份 | 影響 |
|------|------|
| 1906–1911 | 元素特異 X 射線被系統建立，成為 X 射線光譜分析的基礎。 |
| 1913 | 莫塞萊以巴克拉的吸收邊技術建立莫塞萊定律，原子序的物理意義確立。 |
| 1913–1915 | Bragg 光譜儀誕生，X 射線可用於元素分析（後來成為 X 射線螢光光譜儀 XRF 與 1948 年 nuclear gamma resonance 的源頭）。 |
| 1917 | 諾獎頒發（1918 年頒）。 |
| 1919 | 巴克拉在諾貝爾演講中總結「元素的特徵 Röntgen 輻射」，成為教科書標準章節。 |

| 2018 | 諾貝爾物理學獎（阿什金／穆魯／斯特里克蘭）推動超快 X 射線光譜，可「看見」吸收邊隨時間演化——從巴克拉的靜態譜線到時間分辨的吸收邊光譜。 |
