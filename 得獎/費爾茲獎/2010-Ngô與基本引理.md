# 2010 · Ngô 與基本引理：越南的一盞燈，照亮了朗蘭茲的入口

> 2010 費爾茲獎（海得拉巴 ICM）：**Ngô Bảo Châu（吳寶珠）**，表彰其在**自守形式**、特別是朗蘭茲綱領的**基本引理**上的貢獻；同屆 Elon Lindenstrauss（遍歷理論／量子唯一遍歷）、Stanislav Smirnov（共形不變性）、Cédric Villani（最優輸運）亦同獲此獎

## 案情提要

1967 年，朗蘭茲（Langlands）寫了一封長信給魏伊爾（Weil），提出一個大膽到幾乎離譜的對應：**把每個 Galois 表示，配上一個自守形式**。這封信開啟了半個世紀的數學工程。但工程立刻卡在第一塊磚上——**基本引理**（fundamental lemma）：一個關於「在群上做積分」與「在李代數上做積分」之間的等價性，這塊磚不鋪好，整座樓都起不了來。1990 年代末，人們知道有十幾種「局部版本」被分別證明，卻無人能處理一般的情形。2008 年，Ngô Bảo Châu——一位在越南河內工作的數學家——宣布了**一般情形的證明**。

## 前因

| 年份 | 事件 |
|---|---|
| 1967 | Langlands 致 Weil 的信：自守形式的「世界觀」 |
| 1970s | Weil 表述**基本引理**：對局部域上的 reductive group `G`，把 Weil 算子的「轉移」（transfer）在「群版本」與「李代數版本」之間對應起來 |
| 1980s | **Jacquet–Rallis** 的思路：把群上的函數轉成某個 variety 上的 trace；**Waldspurger**、**Chaudouard–Laumon**（Laumon 正是 Ngô 的博士導師）分別證明若干特殊情形 |
| 1995 | Laumon 用 **Kottwitz–Viehmann variety** 上的 trace 建立「轉移公式」——工具已備 |
| 1998 | **Ngô 在巴黎七大取得博士學位**（導師 Gérard Laumon），返越南河內工作 |
| 2000–2008 | Ngô 在河內的數學院（Institute of Mathematics, VAST）持續推進；同期他還解決了 Bessel–Gross–Prasad 理論中的若干問題 |
| 2008-04 | Ngô 宣布基本引理的一般證明（arXiv 預印本《Sur le lemme fondamental de la conjecture de Rapoport-Zink》） |
| 2010 | 海得拉巴 ICM：Ngô 獲費爾茲獎（**首位獲此獎的越南人**；ICM 首次在印度舉行） |

## 調查：兩種積分，為何應該相等

**基本引理要說的事**（以最簡形式）：對局部域 `F` 上的 reductive group `G`，取「測試函數」`φ`（群版本，用在 `G(F)` 上）與 `φ̃`（李代數版本），則 Weil 算子的 trace 滿足

`|Tr(φ, π)| ≤ |Tr(φ̃, π̃)|`

並且存在精確的等價關係——**群上的『整數點加權求和』等於李代數上的『流形上積分』**。

兩邊差異巨大：

| | 群版本 | 李代數版本 |
|---|---|---|
| 對象 | `G(F)` 上的函數（離散、算術） | `G` 的李代數上的函數（連續、解析） |
| 工具 | 群的表示論、`G(F)` 的點數 | `G` 的座標環上的分布 |
| 困難 | 算術性（`F` 的特徵相關） | 純分析（沒有 `F`） |

**Ngô 的破案手法**：

1. **引入「分次李代數」（graded Lie algebra）**——把問題搬到一個能同時看見兩邊的場景。分次結構讓「群」的資訊以「微分」的形式在李代數側顯影。
2. **證明轉移公式（transfer formula）**——用 Laumon 的 Kottwitz–Viehmann variety，把群側的 trace 改寫成 variety 上的幾何積分。
3. **處理一般 reductive group 的 reductive part 與非 reductive part 的分拆**——這是最艱難的部分，涉及「深層 (deep) 幺正表示」的精细分析。

**關鍵在於「降維」**：Ngô 不是分別攻克每個特殊情形，而是把一般情形**化約**成已知可行的情形——**從「無數個特例」到「一個一般定理」的範式轉換**。

## 理論裁決

| 層面 | 結論 |
|---|---|
| 綱領 | 基本引理是朗蘭茲綱領的**地基**；它鋪好之後，函數域與數域上的自守形式研究才得以系統推進（`GL(n)` 的 Langlands 參數、`GL(2)` 的反演等） |
| 與費馬案的對照 | Wiles 的做法是「**用 trace formula（全局）反推局部條件**」；基本引理則是「**把局部條件在群與李代數之間搬運**」——同屬「把不可算的東西算成可算的」這一大技法（見 [1998 案](1998-懷爾斯與費馬最後定理.md)） |
| 技術傳承 | Ngô 的證明被 **Wei Zhang（2016–2021）** 推廣到一般情形（與 Lan、Luo、Renaudineau 合作），**基本引理至此完全結案**——一樁懸案的生命週期跨越了三代人 |
| 學派 | 河內的 Institute of Mathematics 成為「**後殖民數學的樣板**」：Ngô、Ha Huy Tuan（院長）、Lê Minh Hưng 等人建立了一個能培養國際級數學家的體系——**與 Grothendieck 的 IHÉS 形成有趣的對照** |

## 後果

| 層面 | 影響 |
|---|---|
| 數論 | 朗蘭茲綱領在函數域上成為可計算的理論；`GL(n)` 的 `L`-函數、模形式的 p-進推廣得以建立 |
| 制度 | 2010 年 ICM 在印度海得拉巴舉行——費爾茲獎史上第一次在印度頒發；Ngô 的獲獎在越南引發國級別的慶祝（胡志明市統一慶祝日、機場命名） |
| 跨代 | Ngô 與同屆 Villani（最優輸運，Monge–Ampère 方程的弱解存在性，Lions–Villani 定理）構成有趣對照：**一個把算術帶進連續世界，一個把連續世界帶進隨機世界** |
| 里程碑 | **Ngô 是首位獲費爾茲獎的越南人**，且獲獎時仍任教於河內——**「在自己的國家做世界級數學」的樣板**；他的獲獎在越南引發國級別的慶祝（機場命名、國會表揚） |
