# 1978 · Deligne 與 Weil 猜想：有限域上的黎曼假設

> 1978 費爾茲獎（赫爾辛基 ICM）：Pierre Deligne，表彰其代數幾何工作，特別是**Weil 猜想的證明**；同屆 Charles Fefferman（實分析）、Grigory Margulis（超剛性）、Daniel Quillen（代數 K 理論）亦同獲此獎

## 案情提要

1955 年，安德烈·韋伊爾在給妹妹雅克琳的一封信中寫下了一串「猜想」：**對一條定義在有限域上的曲線，點數的誤差有嚴格上界**。他把它寫成更強的形式，涵蓋任意維度的代數簇——「點數的誤差由 Frobenius 作用在 l-進上同調上的特徵值控制，而特徵值恰落在某個圓盤上」。這封信後來成為著名的 **Weil 猜想**，等價於**有限域上的黎曼假說**。二十年間它是數學界最大的懸案之一，Deligne 1974 年將它拿下——**並因此獲得 1978 年費爾茲獎**。

## 前因

| 年份 | 事件 |
|---|---|
| 1901–06 | Hasse 證明橢圓曲線的點數公式 `|#E(F_q) − (q+1)| ≤ 2√q`——**一維案例先破** |
| 1922 | Weil 將 Hasse 的結果推廣到曲線，並首次提出「點數 = 特徵值之和」的猜測 |
| 1949 | Weil 在致妹妹的信中寫下完整的猜想清單（**Weil 猜想 I–IV**） |
| 1950s | Weil 定理：**zeta 函數是有理函數**，且可分解為多項式之商——「分子分母」的對稱性 |
| 1960s | Dwork、Serre 等建立 l-進方法；Grothendieck 的 **étale 上同調**問世（[1966-Grothendieck概形革命](1966-Grothendieck概形革命.md)） |
| 1971–73 | Deligne 證明 Weil II（對 K 理論的版本），並與 Grothendieck 合作發展「權（weights）」理論 |
| 1974 | **Deligne 證明 Weil 猜想**（IHÉS 出版物，`La conjecture de Weil I, II`） |

## 調查：三步推理鏈

### 第一步：找出正確的「點數替代品」—— zeta 函數

對有限域上的曲線 `C/F_q`，定義：

`Z(C, T) = exp( Σ_{n≥1} #C(F_{q^n}) · T^n / n )`

Weil 定理說它是**有理函數**，可寫成 `Z(C,T) = P(T) / ((1−T)(1−qT))`，其中 `P(T)` 是整係數多項式。懸案：`P(T)` 的根長什麼樣？

### 第二步：權重與「純粹性」——把特徵值放進圓盤

Deligne 與 Grothendieck 的關鍵發明是**權重（weight）**：

- 對特徵 p 的 variety `X/F_q`，定義 `H^i(X, Q_l)`（l ≠ p 的 l-進上同調），Frobenius 算子 `F` 作用其上，特徵值記為 `α`。
- **權重定理**：`H^i` 上的 Frobenius 特徵值的權重為 `w`，即

  `|α| = q^{w/2}`

- 特別地：曲線 `C` 上，`H¹` 的權重是 1，故所有特徵值落在半徑 `√q` 的圓盤上；且「純粹性」保證它們是**共軛對**（若 `α` 是特徵值則 `q/α` 也是）。
- 點數公式：`#C(F_q) = q + 1 − Σα_i`，於是立刻得到

  `|#C(F_q) − (q + 1)| ≤ 2√q`

  ——**Hasse–Weil 界在任意曲線上成立**。

### 第三步：黎曼假說的位置

Weil 猜想的最強版本說：`Z(C,T)` 的極點落在 `|T| = q^{-1/2}` 上，即**數學家可以「看見」 Riemann–Zeta 的行為**。Deligne 的證明把這部分也一併拿下（透過「硬 Lefschetz 定理 + 權重的對稱性」）。

**關鍵是工具的分工**：Deligne 並非憑空發明。他手上有 Grothendieck 的 étale 上同調（提供「點數的替代品」）、Weil 的權重猜測（提供「圓盤的半徑」）、以及 Lefschetz 定理在同調上的版本（提供「硬性」，排除多餘的特徵值）。**一個人的工作往往是整個學派十年累積的兇器。**

### 插曲：得獎者缺席，講稿由別人代讀

1978 年赫爾辛基：**Margulis 再次受阻**——蘇聯當局不放行，他無法出席；Deligne 在會場代讀了他的講稿。同一屆，**Deligne 自己的獲獎工作則是剛剛完成的最高難度案件**。

## 理論裁決

| 層面 | 結論 |
|---|---|
| 數論 | Weil 猜想成立＝**有限域上的黎曼假說成立**；Deligne 於 2008 年獲 Wolf 獎（與 Langlands 同屆） |
| 工具 | 「權重」成為上同調的通用語言；Deligne 的混合上同調論證（**Weil II**）開啟 K 理論與上同調的對偶 |
| 動機 | Deligne 的「motive」世界觀——所有上同調理論的母體——由本案催生，是 [2002-Voevodsky與動機同調](2002-Voevodsky與動機同調.md) 的直接源頭 |
| 物理 | 弦論中的「影子」計數（物理家算出的有理曲線數與代數幾何算的不一致）正是 Deligne 建立的 zeta/上同調框架所裁決的——見 [1990-Witten 案](1990-Witten與拓撲量子場論.md) |

## 後果

| 層面 | 影響 |
|---|---|
| 學科 | 「用上同調研究算術」成為標準動作；Deligne–Ihara（混合字、braid group 上同調）、Deligne–Lusztig 曲線（模形式與表示論的接點） |
| 橋樑 | 2000 年後 **Langlands 綱領**中的 Galois 表示，其「重量的正確性」正是靠 Weil 猜想這類工具支撐——Wiles 的方法最終要依賴 Frobenius 特徵值的位置（[1998 案](1998-懷爾斯與費馬最後定理.md)） |
| 生涯 | Deligne 於 1988 年獲 Crafoord 獎；2013 年獲 Shaw 獎。他的名言：「我在證明之前就已經知道答案是什麼了——我只是找不出怎麼證明它。」 |
| 遺憾 | Deligne 與 Bourbaki 的關係複雜；他在法國的「抵制」運動中保持距離——**學術與政治的案例** |
