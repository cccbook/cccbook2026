# 1936 · 首屆費爾茲獎：一個沒有贏家的時代裡的獎章

> 1936 首屆費爾茲獎：Lars Ahlfors（芬蘭）、Jesse Douglas（美國）——獎章的誕生本身就是一樁外交案件

## 案情提要

1920 年代的國際數學界滿目瘡痍：一戰使同盟國（德、奧、匈）數學家被排除在國際數學聯盟（IMU）與 ICM 之外——1920 年斯特拉斯堡大會德國人缺席，1924 年多倫多大會仍是「勝利者的聚會」。加拿大數學家 J.C. Fields 課題：**如何用一件金屬徽章，把撕裂的數學界重新縫起來？**——他給出的方案並非「獎金」，而是一枚刻著阿基米德頭像的獎章。

## 前因

| 年份 | 事件 |
|---|---|
| 1914–18 | 一戰；德國科學被「抵制」 |
| 1920 | 斯特拉斯堡 ICM（法屬領土象徵）；德國數學家抵制 |
| 1924 | Fields 力排眾議在多倫多辦 ICM，並**不邀請德國數學家**（他判斷時機未成熟，寧可先做「中立的」獎章） |
| 1932 | Fields 逝世；遺囑與構想於蘇黎世 ICM 通過。同年德國數學家重返 IMU（1928 年 Bologna 大會 Hilbert 帶隊強行入場是前奏） |

## 調查：Fields 的三條設計原則（都是政治學）

1. **不以個人命名**（官方名稱是「International Medal…」，民間以 Fields 為名）——避免成為任何一國的「民族獎」。
2. **獎章重於獎金**：刻阿基米德（歷史上最著名卻死於亂軍的數學家）與拉丁格言——榮譽無國界。
3. **成就 + 未來潛力 + 40 歲以下**：把獎設定為「種子投資」而非「蓋棺定論」——這使它在本質上**永遠不可能等同諾貝爾獎**（諾獎獎勵已完成、已驗證的工作；費爾茲獎獎勵正在發生的革命）。

## 兩位首屆得主的「案子」

### Ahlfors：黎曼面的面積法（芬蘭）

- 案件：Denjoy–Carlson–Ahlfors 定理——亞純函數在單位圓盤中的平均值特徵指數 ≤ 2：
  `limsup_{r→1} ∫₀^{2π} log|f(re^{iθ})| dθ / log r ≤ 2`
- 手法：把複分析的成長問題轉為**黎曼面上的曲率與面積估計**——「幾何化分析」的先聲。

### Douglas：Plateau 問題（美國）

- 案件：給定空間中任意閉曲線，證明存在**面積最小的曲面**（肥皂膜）——一個 1870 年代提出、無人能嚴格解決的變分問題。
- 手法：以 Fredholm 積分方程直接構造極小曲面的收斂序列。同年 Radó 也獨立解決，二人並列（未得獎的 Radó 是本案的「另一位偵探」）。

## 理論裁決

- 兩案共同點：都是把「分析問題幾何化」——這條主線貫穿了整個二十世紀數學（1954 Kodaira、1982 丘成桐、2018 Figalli 皆是此案後代）。
- 首屆評選的政治學驗證成功：芬蘭（夾在大國之間的中立小國）與美國（新興勢力）——刻意避開英法德舊秩序。

## 後果

- 1936 年至 1950 年因二戰中斷 14 年——獎章的「非戰爭屬性」由中斷親自證明。
- 1950 年劍橋（美）大會起，德國數學家全面回歸，Fields 的外交使命結案。
- 現代爭議：2022 年起「費爾茲獎是否過度偏愛特定領域與機構」（哈佛/普林斯頓/巴黎高師的高密度）——首屆案件的「平衡」設計至今仍在校準。
