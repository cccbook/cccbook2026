# 2021 Tony Hoare & Barbara Liskov —— 第二頂桂冠：抽象與驗證的兩位老兵

> 「1980 與 2008 兩位得主同台再獲圖靈獎——史上唯一。
> 2021 年的獎勵語不是新發明，而是兩條橫跨五十年的
> 主線：**抽象是可驗證的，驗證是可工業的**。」

## 案件檔案

| 項目 | 內容 |
|---|---|
| 得主 | C. A. R. Hoare（1980 案）、Barbara Liskov（2008 案） |
| 得獎理由 | 對程式設計語言基礎的根本性貢獻（第二度獲獎的延伸貢獻） |
| 關鍵詞 | Hoare 邏輯、CSP 的成熟、抽象資料型別的驗證 |

## 前因

2021 年，形式化方法終於走出論文：seL4 微核心全驗證、
CompCert 編譯器驗證、AWS 用 TLA+ 驗證雲服務、Rust 的
型別系統防止記憶體錯誤。ACM 選擇**再次**表彰兩位
奠基者：承認此案是「延遲兌現的長期投資」。

## 線索與推理

### 線索一：Hoare 的後續長跑

1980 年後的 Hoare：

1. **CSP 的數學精緻化（1985 專著）**：行程代數 +
   操作語義 + 雙模擬式等價（與 Milner 1991 案會師）；
   Failures/Divergences 模型使死結可判定。
2. **occam 語言與 Transputer**（1980s）：把 CSP 做成
   晶片與語言——「通訊順序行程」的第一次矽化。
3. **統一理論的追尋（Unified Theories of Programming,
   1998）**：主張操作語義、指稱語義、公理語義是同一
   理論的三種投影——與 Plotkin 的結構操作語義同向。
4. **演講文化**：《The Billion Dollar Mistake》自揭
   null 之過（1980 案）——偵探的最高品德：承認
   自己埋的雷。

### 線索二：Liskov 的後續長跑

1988–2000s 的 Liskov（2008 案續）：

1. **Viewstamped Replication 工程化**：容錯複製的
   實務譜系（Lamport 2013 案 Paxos 的姐妹路線）。
2. **Byzantine 容錯的抽象化**：在不可信節點上仍可
   複製狀態機——區塊鏈共識的理論前置。
3. **教育影響**：MIT 6.824（分散式系統課）與
   《Program Development in Java》——契約式思維的
   兩大培養皿。

### 線索三：兩人主線的會師

```
Hoare 邏輯：{P} C {Q}      —— 語句的契約
資料抽象（Liskov）：介面+不變式 —— 資料的契約
CSP：通訊的契約             —— 行程的契約

會師成果：契約式設計（Meyer 的 Eiffel）
  + 抽象解釋（Cousot）+ 模型檢查（2007 案）
  = 現代靜態分析工業（Facebook Infer、Polyspace）
```

## 理論評析

「抽象與驗證」的辯證法：

```
驗證的前提是抽象：狀態空間必須先被抽象到有限/可推理
抽象的價值靠驗證兌現：介面契約若不可檢查，只是口號
  Rust 的借用檢查器 = 型別層次的「驗證前置」
  seL4 = 11,000 行 C 對應 20 萬行 Isabelle 證明
  ——比例揭示了本質複雜性（1999 案 Brooks 定律的
    驗證版）
```

## 後果

- 2021 獎項被視為**形式化方法產業化的加冕**：
  軟體安全（記憶體安全、併發安全）由語言與工具承擔。
- 兩人皆 80+ 歲仍活躍——「長期主義研究」的榜樣。
