# 1990 Fernando Corbató —— 讓機器學會插隊的藝術

> 「一台百萬美元的電腦，95% 的時間在閒置——這是 1950 年代的
> 每日現實。誰破解了時間的密碼？」

## 案件檔案

| 項目 | 內容 |
|---|---|
| 得主 | Fernando J. Corbató (1926–2019) |
| 得獎理由 | 分時系統的先驅工作：CTSS 與 Multics |
| 關鍵詞 | CTSS、Multics、時間切片 |

## 前因

McCarthy（1971 案）1961 年在 MIT 提出分時構想。實作之謎：
**如何讓多個使用者共用一台機器，卻互不察覺彼此存在？**
本質是三個子案：排程、隔離、保護。

## 線索與推理

### 線索一：CTSS（1961，相容分時系統）

世界第一個公開展示的分時系統。核心機制：

```
時間片 quantum：每人跑一小段 → 中斷 → 換人
輪轉排程 Round-Robin：公平性 = n 人時回應延遲 ≈ n × quantum
互動性條件：回應時間 < 人類反應尺度（~0.5 秒）→ 排程是
  「人機工學約束下的優化」
```

名場面：1961 年 11 月 CTSS 演示，多位與會者同時從各自
終端敲入問題，機器即時回答——**計算第一次變成對話**
（Sutherland 1988 案的互動哲學在 OS 層的先聲）。

### 線索二：Multics（1964–69）

雄心：把計算做成**公用事業**（像水電）。貢獻遠超其商業
成敗：

1. **階層式檔案系統** + 動態連結（單一樹狀命名空間）
2. **環保護模型（rings）**：權限分環，核心在環 0——
   虛擬記憶體 + 硬體保護的完整理論
3. **虛擬記憶體的分段分頁**：位址空間與實體記憶解耦，
   程式可大於記憶體（需求分頁 demand paging）

### 線索三：失敗案件的遺產

Multics 因龐大而商業失利（Thompson 正因此出走寫 UNIX，
1983 案），但 Corbató 的名言成為工程箴言：

> 「用最聰明的方式做你力所能及的事，並知道你會在
> 某一天被更簡單的東西超越。」（啟發『爬第二個系統』效應）

## 理論評析

分時系統的抽象經濟學：

```
Amdahl 式利用率：批次模式 CPU 忙碌於算術的比率低
分時的價值 = CPU 服務 I/O 等待中的其他行程（多工）
量子選擇的兩難：太短 → 上下文切換開銷佔比高
                太長 → 互動性死亡
最優量子 ≈ 讓切換開銷 <5% 的最長值
```

## 後果

- 虛擬記憶體、檔案系統、保護環成為一切現代 OS 的骨架；
  雲端多租戶（multi-tenancy）是分時思想在虛擬機層的重演。
- 「公用計算」願景在六十年後以雲計算實現——願景延遲兌現。
