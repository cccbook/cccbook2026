# 2016 Tim Berners-Lee —— WWW：一篇提案改造文明

> 「1989 年，CERN 的物理學家在備忘錄裡提議：把實驗室
> 的論文和資料用『連結』串起來。上司的批註是：
> Vague, but exciting（含糊，但令人興奮）。」

## 案件檔案

| 項目 | 內容 |
|---|---|
| 得主 | Tim Berners-Lee (1955–) |
| 得獎理由 | 發明 WWW（URL、HTTP、HTML）與第一個瀏覽器 |
| 關鍵詞 | 超連結、開放標準、語義網 |

## 前因

1980s 末，CERN 上萬名研究員使用不同電腦、不同文件
格式，**資訊互通全靠口頭**。Engelbart（1997 案）的
hypertext 已存在（HyperCard、Guide），但每個系統都是
孤島。謎題：**連結如何跨越不同機器與格式？**

## 線索與推理

### 線索一：三大發明（1989–91）

```
URL：統一資源定位 → 位址獨立於實體位置
     scheme://host/path —— 把 DNS 變成全球地名系統
HTTP：極簡協定 —— GET /path、回傳文字（基於 TCP/IP，2004 案）
HTML：只取 SGML 的最小子集，標記可讀、可寫、可容錯
```

### 線索二：革命性的三個「不做」

| 決策 | 為何關鍵 |
|---|---|
| 不收費、不申請專利 | 1993 年 CERN 聲明免版稅 → 採用零摩擦 |
| 不做中心節點 | 無許可即可發布（permissionless publishing） |
| 不強制格式 | 瀏覽器對未知標籤容錯 → 演化式標準 |

**架構的謙遜**：Web 把「智慧」全放兩端（瀏覽器+伺服器），
網路保持笨——1992 案端到端原則在應用層的勝利。

### 線索三：開放標準的治理學

W3C（1994 創立）→ WHATWG 的 HTML5 分裂與再合流。
Berners-Lee 的持續主張：**語義網/Linked Data**——
讓連結承載語義（RDF、SPARQL），資料也能互連。
批評者：網路的商業演化走向資料孤島（平台 walled
garden）——語義網未竟，但知識圖譜（Google 2012）以
另一形態回歸（2011 案的表示譜系）。

### 線索四：Solid 與「還數據於民」

晚年的 Solid 專案：個人資料 pod + 全域存取控制——
對「平台壟斷個人資料」的架構級反抗。

## 理論評析

WWW 成功的偵探學：**成功 = 採用摩擦的倒數**。

```
採用阻力 = 學習成本 + 部署成本 + 治理成本
WWW：零（HTML 手寫即可）+ 零（免費）+ 零（無審批）
gopher 競品（1991）：需授權、無容錯 → 被淘汰
```

與 1997 Engelbart 案對照：後者的 NLS 太複雜；WWW 用
**減法**取勝——他自稱最大的發明是「不做決定的決定」。

## 後果

- 1991 第一個網站（info.cern.ch）至今可訪；全球經濟
  的應用層自此統一在 HTTP 上。
- 2016 圖靈獎確認：協議設計也是計算科學的最高成就。
