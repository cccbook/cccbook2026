# 2019 Edwin Catmull & Patrick Hanrahan —— 讓數學學會發光

> 「皮克斯的總裁與 OpenGL 的作者，共享一座圖靈獎。
> 你看過的每一部 3D 電影與每一個遊戲畫面，都是這兩條
> 線索的匯流。」

## 案件檔案

| 項目 | 內容 |
|---|---|
| 得主 | Edwin E. Catmull (1945–)、Patrick M. Hanrahan (1955–) |
| 得獎理由 | 3D 電腦圖形學的奠基影響 |
| 關鍵詞 | 紋理映射、RenderMan、GPU 著色語言 |

## 前因

1970s，電腦圖形是線框與平面色塊（Sutherland 1988 案
的遺產）。謎題：**如何讓合成影像擁有照片般的真實感？**
兩位後輩分頭攻堅：Catmull 走「動畫電影」的長征，
Hanrahan 走「即時繪製」的語言戰。

## 線索與推理

### 線索一：Catmull 的三項發明（1970s）

```
1. 紋理映射（1974）：把影像「貼」到多邊形上
   座標變換 (u,v) → 曲面參數域 → 像素插值
2. Z-buffer（1974）：以深度緩衝解決隱面消除
   O(n) 而非排序的 O(n log n)，硬體友善 → GPU 的標配
3. Catmull–Rom 樣條（1974）：過點的平滑曲線/曲面
   C¹ 連續、局部控制 —— 動畫曲線的標準
```

### 線索二：烏托邦的落點：Lucasfilm→Pixar

1979 年 Catmull 加入喬治·盧卡斯的特效部門（《星際
大戰》的電腦分部），1986 年隨 Apple 出售部門而成
**Pixar**。1995 年《玩具總動員》：全電腦長片，票房
3.6 億美元——**圖形學第一次兌換為大眾文化**。Catmull
的組織學遺產同樣重要：《創意電力公司》主張「創意
組織的問題不是想法不夠，而是坦誠不足」。

### 線索三：Hanrahan 的 RenderMan（1980s）

皮克斯的離線渲染器規格（1988 規範，Hanrahan 主筆）：
**著色語言（shading language）**的發明——

```
把「材質如何反射光」寫成可編程的小程式：
  surface shader: Ci = Os · Cs · (Ka·ambient + Σ Kd·diffuse...)
  幾何階段（固定管線）與著色階段（可編程）分離
《玩具總動員》《魔戒》《阿凡達》皆經 RenderMan
（以及 1977 案 TeX 式的長壽：至今仍在維護）
```

### 線索四：GPU 的編程模型（2000s）

Hanrahan 參與 **OpenGL 規格**；其學生（與業界）把
「可編程著色器」推到極致：Cg/HLSL/GLSL → CUDA 的
通用 GPU 計算路線——**深度學習（2018 案）的算力
引擎**由此點燃。著色語言的設計哲學（資料平行、
SIMD、明確的記憶體模型）正是今日 ML 編譯器的母體。

## 理論評析

3D 圖形的數學骨架（兩人工作的共同底座）：

```
渲染方程（Kajiya 1986）：
  L_o(x, ω) = L_e(x, ω) + ∫_Ω f_r(x, ω', ω) L_i(x, ω') (n·ω') dω'
  「出射光 = 自發光 + 入射光的雙向反射加權積分」
RenderMan = 此方程的工程取捨（區域光照近似）
即時管線 = 犧牲全局積分換取 16ms 週期
```

**物理正確性與即時性之間的取捨譜**——這是圖形學
六十年的一條主軸。

## 後果

- 遊戲產業、視效產業、GPU 產業（NVIDIA 2016 市值
  起飛）全部建立在此案基礎上。
- 2019 年頒獎時機：GPU 反哺 AI，圖形學與機器學習
  的債務關係公開結算。
