# 2022 Bob Metcalfe —— 乙太網：最簡單的仲裁，最長的壽命

> 「1973 年，一位 PARC 工程師要連接上百台 Alto 電腦。
> 中央交換機太貴、令牌環太脆弱。他的答案是：**一條
> 共享電纜，大家都聽，撞了就退。** 這個『粗暴』方案
> 贏了五十年。」

## 前因

1972–73 年，PARC 需要連接 Alto（2009 案）與雷射印表機。
候選方案偵查：

| 方案 | 缺陷 |
|---|---|
| 中央交換機 | 單點故障、成本隨 n² 增長 |
| 令牌環（token ring） | 令牌丟失即全網癱瘓 |
| ALOHA（夏威夷無線電） | 純隨機發射，利用率上限僅 18% |

## 線索與推理

### 線索一：CSMA/CD 的三段論

Metcalfe 在 Xerox PARC 與 Boggs 設計 Ethernet（1973
備忘錄），核心是對 ALOHA 的兩步改良：

```
1. Carrier Sense（先聽）：線上有人說話就閉嘴
   → 撞機率大幅下降
2. Collision Detect（邊說邊聽）：撞了立即停，別浪費整包
3. Binary exponential backoff：第 k 次碰撞後
   隨機等待 ∈ [0, 2^k) 個 slot —— 負載自適應
```

理論：CSMA 的利用率可達 ~50–80%（視傳播延遲比），
遠超 ALOHA——**統計仲裁的數學勝利**（1992 Lampson 案
的端到端哲學：網路笨、端點聰明）。

### 線索二：Metcalfe 定律

```
網路價值 ∝ n²   （n 個節點有 n(n−1)/2 條潛在連結）
```

這條「經驗法則」（並非嚴格定理）成為網路經濟學的
核心直覺：**成長會自我加速**——解釋了電話網、Web、
社交平台的一切壟斷動力學。批評（ODLYZKO）：價值更近
n log n；Metcalfe 自我修正為臨界質量模型——但 n²
版本已在創投文化中根深蒂固。

### 線索三：標準化與商業三幕劇

```
1980：與 Intel、DEC 聯盟推 DIX 標準（開放！）
1983：IEEE 802.3 標準化 → 供應商競爭、成本崩落
1990s–2000s：集線器→交換機（每埠獨立碰撞域）
  → CSMA/CD 退場，但「乙太網幀格式」存活
  同軸電纜→雙絞線→光纖：速率 10M→100M→1G→400G→800G
```

**協議不滅的秘訣：幀格式與最小變更**——衝突偵測
死了，乙太網活著。

### 線索四：連續創業與專欄生涯

3Com（1979 創立，賣網卡）→ 億萬身家；後為 InfoWorld
專欄作家（以預言失敗率自豪）、風投（Polaris）——
「技術→標準→企業→資本」的完整生命週期親歷者。

## 理論評析

乙太網的偵探學：**在「完美協調」與「純混亂」之間選
廉價中間態**。

```
中央控制：無衝突但昂貴、單點故障
CSMA/CD：以「偶爾碰撞 + 指數退避」換取零協調成本
  分佈式系統的普遍取捨（Paxos 2013 案的隨機化變體
  亦同源：用隨機性打破對稱）
```

## 後果

- 資料中心、辦公室、家用的一切有線網路；Wi-Fi 的
  CSMA/CA 是其無線近親。
- 802 標準家族（乙太網/Wi-Fi）成為 IEEE 最成功的
  商業基礎設施。
