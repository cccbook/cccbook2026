# 1937-東亞全面戰爭

## 案件摘要
1931/9/18 九一八事變（柳條湖）→ 1932 滿洲國 → 1937/7/7 蘆溝橋事變 → 1937/12 南京——中日全面戰爭；1938 國家總動員法（日本的戰時體制）、1940 大東亞共榮圈宣言（近衛）、汪精衛政權。這樁「全面戰爭」案件的偵辦重點：**帝國的「東亞新秩序」**——近衛 1938 聲明與 1940 大東亞共榮圈——「脫亞」（1868 案）的帝國版：日本中心的亞洲秩序構想；**總體戰的東亞化**（1914 案總體戰的日本版：國家總動員法、婦女的戰時勞動）；**殖民的戰時極端化**（1910 案朝鮮的皇民化、1937-45）。全面戰爭把東亞推向 1945 的終局。

## 前因 -- 為什麼會有這個案子
- **滿洲的帝國邏輯**：1905 案南滿鐵路 + 關東州 → 1931 九一八（關東軍的自導自演）——「軍部 = 帝國的動員機器」。
- **經濟危機與擴張**：1929 大蕭條（社會結構史 1929 案）——日本的「滿洲 = 資源與市場」的擴張邏輯（高橋是清的軍事財政）。
- **軍部的政治化**：1931-36 的軍部專政（二二六 1936）——「文官的退場」（政黨政治 1918-32 的終結）。
- **中日戰爭的擴大**：1937/7 蘆溝橋——「地方事變 → 全面戰爭」的擴大結構。

## 線索與推理 -- 數學式、理論、表格

### 線索一：帝國的「東亞新秩序」
近衛 1938 聲明與 1940 大東亞共榮圈：

| 層面 | 內容 |
|------|------|
| 口號 | 「東亞新秩序」（1938）→「大東亞共榮圈」（1940 松岡）|
| 結構 | 日本 = 核心（「皇道」）；亞洲 = 共榮的成員 |
| 實質 | 資源與勞動的帝國整合（「共榮」= 剝奪）|

**推理**：「大東亞共榮圈」= 「脫亞」（1868 案）的帝國版——「亞洲的解放者」的自我敘事 + 「資源的帝國整合」的實質——**帝國主義的亞洲化**（1905 案）的極致：亞洲帝國的亞洲統治——「解放的敘事、剝奪的實質」的結構。

### 線索二：總體戰的東亞化
國家總動員法（1938）與戰時體制：

| 領域 | 制度 | 效果 |
|------|------|------|
| 經濟 | 國家總動員法（1938）| 工廠、勞動、物資的國家統制 |
| 勞動 | 婦女的戰時勞動（女工與防空）| 勞動的全面動員 |
| 殖民 | 皇民化（1937-45）+ 徵用（1944）| 殖民地的勞動與兵員 |
| 消費 | 配給（1940 配給制）| 消費的統制 |

**推理**：總體戰的東亞化（1914 案的日本版）——「國家 = 總動員機器」——**戰時體制的社會結構**（經濟、勞動、消費的統制）——1945 案戰後的「國家遺產」（統制經濟的經驗 → 戰後的產業政策——1965 案發展型國家的戰時基因）。

### 線索三：殖民的戰時極端化
朝鮮與台灣的皇民化：

| 政策 | 內容 | 年代 |
|------|------|------|
| 國語常用 | 韓語的壓制（家庭內也禁止）| 1938- |
| 創氏改名 | 姓名的日本化 | 1940 |
| 神社參拜 | 信仰的統一 | 1935- |
| 志願兵 → 徵用 | 1942 志願兵、1944 徵兵 | 動員 |

**推理**：皇民化 = 「身份的抹殺」（1910 案殖民統治的戰時極端化）——「姓名、語言、信仰」的全面抹殺——**殖民的戰時結構**（動員與抹殺的同體）——1945 解放後的「身份回復」與分裂（1945 案）。

### 線索四：戰爭的擴大結構
從滿洲到珍珠港的擴大：

$$\text{九一八（1931）} \to \text{全面戰爭（1937）} \to \text{南進（1940-41）} \to \text{珍珠港（1941/12）}$$

**推理**：戰爭的「擴大結構」——「事變 → 戰爭 → 大戰」的升級鏈（「既成事實的累積」——軍部的自走）——**戰爭的自走結構**（佔領 → 需求 → 更大佔領）——1941 珍珠港 → 1945 案的終局。

## 結案 -- 後果與影響
- **東亞的全面戰爭社會**：經濟、勞動、消費的統制——「戰時體制」的社會結構——1945 案的終局。
- **殖民的戰時極端化**：皇民化（朝鮮台灣）——「身份的抹殺」——1945 後的身份回復與分裂。
- **帝國主義的亞洲極致**：大東亞共榮圈——「解放的敘事、剝奪的實質」——1945 的崩潰。
- **戰後的國家遺產**：統制經濟的經驗 → 戰後的產業政策（1965 案發展型國家的戰時基因）。
- **戰爭的自走結構**：事變 → 戰爭 → 大戰——「擴大的邏輯」——1945 案原爆與投降的終局。
