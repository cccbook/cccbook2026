# 1868 明治維新：制度「拼裝」的國家工程

## 案發現場

1868 年，明治政府取代德川幕府。面對的現場：黑船的技術代差（[1853-黑船事件.md](1853-黑船事件.md)）、不平等條約的主權讓渡（領事裁判權+協定關稅）、幕藩體制的財政（260 個藩、各自的稅與軍）。

明治的綱領：**富國強兵**（國家目標）+**殖產興業**（產業的國家推動）+**文明開化**（社會的西化）。配合的工程：廢藩置縣（1871）、徵兵令（1873）、地租改正（1873）、義務教育（1872）、鐵路（1872 首線）、岩倉使節團（1871–73——**兩年的西方實地偵查**）、聘雇外國顧問（oyatoi gaikokujin）、憲法（1889，普魯士模型）、民法（1898）。

> **「拼裝」制度的國家工程如何運作——各領域分別「抄誰」、依什麼選擇？國家先建廠再賣給財閥的「殖產興業」是什麼邏輯？維新的陰影（殖民地與軍國）從哪來？**

## 偵查過程

**線索一：岩倉使節團（制度的實地偵查）。** 1871–73 年，岩倉具視率領使節團（政府核心的半數）考察歐美十二國——**兩年的實地偵查**：參觀工廠、議會、學校、軍隊；結論（使節團報告）：「西方的強不在船炮，在**制度**（教育、法律、產業的組織）」。偵查的重點：**「制度的實地偵查」**——與 [1866-參謀本部與鐵路動員.md](1866-參謀本部與鐵路動員.md) 的沙盤（模擬器）同構：**把不可重複的觀察變成系統的偵查**——使節團=國家的「偵查團」（與 [1853-黑船事件.md](1853-黑船事件.md) 的蘭學情報網連線：**情報的存量=決策的空間**）；「制度的選擇」由實地觀察決定——**先偵查、再拼裝**。

**線索二：各領域的「抄誰」（拼裝的工程）。** 明治的拼裝清單——**各領域分別選擇最優模型**：

| 領域 | 先學 | 後改 | 選擇邏輯 |
|------|------|------|----------|
| 陸軍 | 法國 | **德國**（1870 普法戰的教訓） | **誰贏學誰** |
| 海軍 | 英國 | 英國（不變） | 海權的模板 |
| 憲法 | — | 普魯士（1889） | 君主權的保留（與 [../宗教史/0800-查理曼加冕.md](../宗教史/0800-查理曼加冕.md) 的雙劍同構） |
| 民法 | 法國 | 德國（1898） | 法律的移植 |
| 教育 | 美/法混合 | 體系化（1872） | 義務教育（[1763-普魯士義務教育.md](1763-普魯士義務教育.md) 的日本版） |
| 時間 | — | 格林威治（1886） | 標準時間（[1884-標準時間.md](1884-標準時間.md)） |

偵查的重點：**「拼裝」=各領域分別取最優**——不是整體抄一國，是**逐域選擇**（陸軍跟德國——因為 1870 誰贏；憲法跟普魯士——因為要保君主權；海軍跟英國——因為海權的模板）；**「誰贏學誰+目標定模型」的拼裝邏輯**——與 [1989-柏林牆倒塌.md](1989-柏林牆倒塌.md) 的「制度錨」對照：**明治的主動拼裝 vs 東歐的被動錨**——兩種制度移植的模式。

**線索三：殖產興業（國家建廠、私人接手）。** 殖產興業的邏輯：**政府建廠**（模範工廠：紡織、水泥、礦山——**示範的工程**）→**賣給財閥**（1880s 的低價讓渡：三井、三菱——「國家先建、私人接手」）；財閥的結構：**持股公司+分支企業**（與 [1855-有限責任.md](1855-有限責任.md) 的公司制度、[1494-複式簿記與理性化.md](1494-複式簿記與理性化.md) 的「帳面分家」同構：**財閥=法人+帳面分家的家族版**）。偵查的重點：**「政府示範→私人接手」**——國家先建（風險與示範由國家承擔）、賣出（經營與擴張由私人）——**「風險國家承擔、收益私人運作」的追趕工程**；財閥=「帳面分家」的家族版（與 [1494](1494-複式簿記與理性化.md) 連線）。

**線索四：文明開化與文化戰（西化的代價）。** 文明開化：西裝、洋曆（1873 改曆——**曆法的主權**）、牛食、義務教育；文化戰：**傳統與西化的張力**（「國體」與「西學」的平衡——佛教與神道的整理、武士道的重述——**傳統被重新發明**以平衡西化）。偵查的重點：**西化=文化工程**——不只要抄制度，要**重述傳統**（武士道從武家倫理變成國民倫理——「傳統的發明」invention of tradition，霍布斯邦的理論）；**「西化+傳統的重述」的雙軌**（與 [1994-開羅人口會議.md](1994-開羅人口會議.md) 的「制度與文化」對照：**制度的移植需要文化的配套**）。

**線索五：維新的利息與陰影（1895/1905 與 1945）。** 維新的利息：**1895 中日戰爭的勝利**（第一次非西方打贏西方化的國家）、1905 日俄戰爭（擊敗歐洲強國——**「追趕」的兌現**）；陰影：**殖民地**（台灣 1895、朝鮮 1910——**追趕的工程轉成殖民的工程**）+**軍國**（陸軍與海軍的專權、政黨的弱化——**「富國強兵」的極致=軍國主義**）→1945 的敗亡。偵查的重點：**維新的陰影在其成功裡**——「富國強兵」的成功（1905）與軍國的失控（1930s）是**同一條路**（與 [1945-核武與嚇阻.md](1945-核武與嚇阻.md) 的嚇阻陰影對照：**制度的成功與其陰影常同源**——追趕工程的軍事核心=軍國的種子）。

## 結案報告

1. **先偵查、再拼裝**：岩倉使節團（兩年的實地偵查）讓「制度的選擇」由觀察決定——**各領域分別取最優**（誰贏學誰+目標定模型）；與東歐的「制度錨」對照：**主動拼裝 vs 被動錨**。
2. **殖產興業=風險國家承擔**：政府建廠（示範）→賣給財閥（接手）——**國家承擔風險、私人運作收益**的追趕工程；財閥=法人+帳面分家的家族版。
3. **西化=文化工程**：制度的移植需要傳統的重述（武士道的「傳統的發明」）——**西化+傳統重述的雙軌**。
4. **偵探教訓**：維新的利息（1905 的兌現）與陰影（殖民+軍國→1945）同源——**「富國強兵」的極致=軍國的種子**；制度的成功與其陰影常在同一條路徑上。

## 證據與工具

**跨領域影響矩陣：**

| 領域 | 元件 | 機制 |
|------|------|------|
| 政治 | 廢藩置縣、憲法（1889） | 主權集中（普魯士模型） |
| 軍事 | 徵兵令、陸軍跟德國 | 誰贏學誰 |
| 產業 | 模範工廠→財閥 | 風險國家承擔 |
| 教育 | 義務教育（1872） | 國家的標準化 |
| 文化 | 洋曆、武士道重述 | 西化+傳統的發明 |

**維新工程的政策工具（拼裝的清單）：**

| 年份 | 工程 |
|------|------|
| 1871–73 | 岩倉使節團（實地偵查） |
| 1871 | 廢藩置縣 |
| 1872–73 | 義務教育、徵兵令、地租改正 |
| 1880s | 模範工廠→財閥讓渡 |
| 1886 | 格林威治標準時間 |
| 1889 | 憲法（普魯士模型） |
| 1898 | 民法（德國移植） |

**殖產興業的邏輯（示範→接手）：**

```
政府建廠（風險與示範由國家承擔）
   ↓ 模範效果
1880s 低價讓渡給財閥（三井/三菱）
   ↓
經營與擴張由私人（持股公司+分支企業）
   ↓
「風險國家承擔、收益私人運作」的追趕工程
```

**結論：** 1868 年的明治維新是「制度拼裝」的國家工程：岩倉使節團的實地偵查讓各領域分別取最優（誰贏學誰+目標定模型）、殖產興業讓國家承擔風險而私人運作收益、武士道的重述讓傳統平衡西化。維新的利息（1905）與陰影（軍國→1945）同源——**追趕工程的軍事核心就是軍國的種子**；與黑船（1853）合讀：**衝擊的轉化需要回應的制度**——同樣的羞辱可以是動力（明治）或感知的毒（1979 核能），差別在回應的制度。
