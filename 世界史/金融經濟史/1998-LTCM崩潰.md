# 1998 - LTCM 崩潰（諾貝爾獎團隊的槓桿災難：相關性趨近 1 的世界）

## 案件摘要
1998 年 9 月，**LTCM（長期資本管理公司）**——
由**Merton、Scholes（1997 諾貝爾獎得主）**與**Meriwether**（所羅門兄弟債券之神）
組成的對沖基金——**在俄羅斯違約後崩潰**：
$$\text{25:1 槓桿 + 收斂交易 + 流動性消失} \xrightarrow{\text{俄債違約（1998.8）}} \text{帳戶歸零}$$
**NY Fed 召集 14 家銀行私人紓困 $3.6 億**（「太大不能倒」的先例）——
**「危機時相關性趨近 1」**——**Markowitz 分散的極限**
（見 `1952-馬可維茲投資組合.md`）——**2008 年金融海嘯的預演**。

## 前因 -- 為什麼會有這個案子
- **LTCM 的明星陣容**：Meriwether（所羅門套利部門）+ Merton/Scholes（諾貝爾獎）
  + Mullins（Fed 副主席）——**理論的豪華陣容**；
- **收斂交易（convergence trade）**：買便宜券、賣昂貴券，**等價差收斂**——
  **利潤薄（bp 級）→ 必須用槓桿放大**——**25:1 → 100:1**；
- **1995–97 的成功**：年報酬 40%+——**信心膨脹 → 槓桿上升 → 部位擴大**；
- **偵推**：**「小利差 × 大槓桿」= 流動性依賴的機器**——
  **一旦流動性消失，機器反噬**。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：槓桿的死亡數學（保證金的螺旋）
槓桿 25:1（自有資金 1，借 24）：
$$\text{損失 } 4\% \Rightarrow \text{權益 } -100\% \quad (\text{槓桿} \times \text{小損失 = 滅頂})$$
$$\text{追加保證金螺旋：} \text{損失} \to \text{繳保證金} \to \text{賣部位} \to \text{價差擴大} \to \text{更大損失}$$
- **偵推**：**收斂交易的風險是「價差擴大」**——**市場越恐慌，價差越大**——
  **「價差收斂」的假設在恐慌中失效**。

### 第二條線索：相關性趨近 1（分散的崩潰）
Markowitz 的分散假設相關性 < 1（見 `1952-馬可維茲投資組合.md`）：
$$\rho_{\text{正常}} \approx 0.3\text{–}0.5 \xrightarrow{\text{危機}} \rho_{\text{危機}} \approx 0.9\text{–}1.0$$
- 1998.8–9：**所有市場同時逆轉**——俄債、美債、股票、期權——
  **LTCM 的「分散」部位全部同時虧**；
- **偵推**：**危機時「所有人賣同一批東西」**——
  **流動性風險 = 相關性的危機版**——**尾部相關（tail dependence）**。

### 第三條線索：Python——槓桿下的生存機率（LTCM 的算術）

```python
import random, math
random.seed(7)
capital, leverage = 1.0, 25.0
for year in range(1, 6):
    # 年波動 15%，槓桿 25 倍 → 權益年波動 375%
    ret = random.gauss(0.40, 1.50)         # 高報酬、巨大波動
    capital *= (1 + ret)
    if capital <= 0:
        print(f"第 {year} 年：權益歸零（破產）")
        break
    print(f"第 {year} 年：權益 = {capital:6.2f}")
```
輸出（範例）：
```
第 1 年：權益 =   1.87
第 2 年：權益 =   3.51
第 3 年：權益 =   0.42
```
（**25 倍槓桿下，一年 -80% 就足以瀕死**——
**高報酬的背後是「滅頂的機率分布」**。）

### 第四條線索：1998 的時間線（崩潰的六週）
| 日期 | 事件 |
|------|------|
| 1998.8.17 | 俄羅斯違約（GKO）|
| 1998.8–9 | 全球利差暴增；LTCM 權益 -50% |
| 1998.9.22 | 聯準會召集華爾街 14 家銀行 |
| 1998.9.23 | **私人紓困 $3.6 億**（90% 權益易主）|
- **偵推**：**「太大不能倒」（too big to fail）的先例**——
  **私人紓困（非公款）= Fed 的組織角色**——2008 年 TARP 的對照。

## 結案 -- 後果與影響
- **「相關性趨近 1」的教訓**：分散在尾部失效——
  **極值理論（EVT）、壓力測試**成為監管標配（Basel II 的動機）；
- **槓桿監管的缺口**：對沖基金**不在銀行監管內**——
  **影子金融的監管套利**（見 `1913-聯準會成立.md` 的信託、`2008` 的 CDO）——
  **同一漏洞第三次出現**；
- **2008 年的預演**：LTCM 的劇本（槓桿 + 流動性 + 相關性 = 崩潰 →
  官方組織紓困）**在 2008 年以百倍規模重演**（見 `2008-全球金融海嘯.md`）；
- **諾貝爾獎的諷刺**：Merton/Scholes（1997 得獎，1998 崩潰）——
  **理論的價值不因崩潰而消失，但「模型的前提」會崩潰**；
- **偵探教訓**：1998 年證明了——**「小利差 × 大槓桿」的機器
  依賴「流動性恆在」的假設**——**流動性是金融市場最脆弱的假設**——
  **VaR 之外，壓力測試才是生存的算術**。
