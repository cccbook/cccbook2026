# 世界史 -- AI 偵探風格

以「推理探案」的方式，追查人類文明的重大轉折：農業革命、帝國、宗教、印刷革命、工業革命、總體戰、全球化與 AI——
前因是什麼？線索在哪裡？推理如何展開？後果又如何改變了整個世界？

本卷的核心命題只有一句話：**歷史從來不是單一因素的故事。**
科技、政治、經濟、心理、武器、組織、宗教、地理、疾病、氣候與資訊——這些因素互相咬合，一個因素的變化會透過回饋迴路放大或抵銷其他因素。每個重大歷史事件都是一樁「多因懸案」：偵探的工作，就是把因素鏈一環一環還原出來。

（涵蓋：農業革命、文字、法典、帝國、宗教、印刷、貿易、科學革命、工業革命、革命、達爾文、全球化、大蕭條、冷戰、網路、疫情、AI）

## 十一種歷史因素：各自如何影響其他因素

| 因素 | 影響其他因素的機制 | 經典案例 |
|------|---------------------|----------|
| **科技** | 降低成本、開啟新維度，重寫既有制度的「不可能」 | 印刷術→宗教改革；蒸汽機→工業革命；網路→全球化 |
| **政治** | 制度決定誘因、動員能力與暴力使用規則 | 科舉→官僚帝國；民族主義→總體戰 |
| **經濟** | 剩餘與貿易決定誰有資源、誰承受衝擊 | 農業剩餘→國家；大西洋貿易→資本主義 |
| **心理** | 信念、恐懼、榮譽與預期驅動集體行為 | 十字軍的救贖經濟；金融恐慌；期望革命 |
| **武器** | 改變暴力成本曲線，從而改變權力結構 | 馬鐙→封建；火藥→中央集權；機槍→總體戰國家 |
| **組織** | 協調能力 > 個人能力；組織形式是隱形的武器 | 羅馬軍團；蒙古十進制；股份公司；列寧式政黨 |
| **宗教** | 提供合法性、動員、紀律與「無形報酬」 | 基督教→帝國國教；伊斯蘭的組織技術；清教倫理 |
| **地理** | 決定成本曲線、產業結構與機會窗口 | 地中海→城邦海權；大西洋→帝國時代 |
| **疾病與氣候** | 外生衝擊重置整個系統 | 黑死病→工資革命；小冰期→革命；新冠→遠距 |
| **資訊** | 傳播速度決定協調半徑與思想市場 | 文字→帝國；印刷→宗教改革；電報→帝國主義；網路→全球運動 |
| **人口** | 勞動力、需求與衝擊緩衝的乘數 | 定居→生育率；黑死病→工資；綠色革命→人口爆炸 |

## 因素的回饋迴路

```
                  ┌────────（疾病／氣候：外生衝擊）────────┐
                  ↓                                        ↓
   地理 ──→ 產業結構 ──→ 經濟 ──→ 政治 ──→ 組織 ──→ 武器
    │                     ↑        ↑                   │
    │                     │        │                   ↓
    └──→ 科技 ←── 資訊 ───┘        心理 ←──────── 心理迴路
              ↑                        ↑
              └── 宗教 ←──（合法性與動員）┘

   正向迴路（加速）：農業→人口→城市→文字→科技→更多農業
   正向迴路（加速）：煤→蒸汽→鐵路→市場→利潤→更多煤
   負向迴路（抑制）：帝國擴大→行政成本↑→過度擴張→崩潰
```

**偵探的訣竅**：找到「哪個因素先動、哪個因素放大、哪個因素抑制」，把迴路畫出來，案件的因果鏈就浮現了。

## 案件卷宗（歷史年表）

### 一、農業與文明誕生（前10000–前1200）

- 約前10000：新仙女木事件結束，氣候穩定溫暖——農業的「外生觸發器」。
- 約前9000：農業革命（新月沃地）：馴化小麥大麥與山羊綿羊，定居與剩餘出現——國家的物質前提。［[-9000-農業革命.md](-9000-農業革命.md)］
- 前7000–前5000：村落擴張，陶器、紡織；兩河灌溉使剩餘再放大。
- 約前5000–前4000：灌溉農業→蘇美城邦；神廟成為經濟與組織中心。
- 約前3200：文字（烏魯克泥板）——最早為了「會計」而寫字。［[-3200-文字與最早國家.md](-3200-文字與最早國家.md)］
- 約前3100：埃及統一（那爾邁），尼羅河的組織工程。
- 約前2560：大金字塔——史前最大規模的組織動員實驗。
- 約前2300：阿卡德的薩爾貢——第一個多民族帝國。
- 前1792–前1750：漢摩拉比法典——法、神與帝國行政的結合。［[-1754-漢摩拉比法典.md](-1754-漢摩拉比法典.md)］
- 約前1500：赫梯的鐵器萌芽；青銅時代貿易網的巔峰。
- 前1200–前1150：青銅時代大崩潰：乾旱＋貿易斷裂＋海上民族。［[-1200-青銅時代大崩潰.md](-1200-青銅時代大崩潰.md)］

### 二、軸心與古典時代（前1200–前221）

- 約前1000：鐵器普及；腓尼基字母——資訊成本的下降（22 個字母）。
- 前800–前200：軸心時代：佛陀、孔子、猶太先知、希臘哲學家——普遍倫理的誕生。［[-0800-軸心時代.md](-0800-軸心時代.md)］
- 前594：雅典梭倫改革（債務解放、階級分層）。
- 前508：克利斯提尼改革：雅典民主成形——海權、貿易與政治權的咬合。［[-0508-雅典民主與海權.md](-0508-雅典民主與海權.md)］
- 前551：孔子誕生；前500s 佛陀傳道、猶太先知運動。
- 前550：波斯帝國（居魯士）——帝國行政與宗教寬容。
- 前509：羅馬共和國建立。
- 前334–前323：亞歷山大東征——希臘化時代，文化與語言的融合。
- 前221：秦統一六國——官僚帝國與標準化的誕生。［[-0221-秦的統一與官僚帝國.md](-0221-秦的統一與官僚帝國.md)］
- 前206–前141：漢朝；張騫通西域（前138 起）——絲路開通。

### 三、帝國與宗教時代（前27–700）

- 前27：奧古斯都建立元首制——羅馬體系的組織工程：道路、法、軍團、公民權。［[-0027-羅馬帝國的組織工程.md](-0027-羅馬帝國的組織工程.md)］
- 約30s：耶穌受難與基督教誕生；保羅的普世化傳教。
- 105：蔡倫改進造紙——知識載體的成本革命（西傳要到八世紀）。
- 117：圖拉真治下羅馬帝國最大疆域。
- 165–180：安東尼瘟疫——疾病對帝國的第一次重擊。
- 313：米蘭敕令——君士坦丁合法化基督教，帝國收編宗教。［[0313-君士坦丁與基督教的勝利.md](0313-君士坦丁與基督教的勝利.md)］
- 380：狄奧多西立基督教為國教。
- 476：西羅馬帝國滅亡——多因系統的崩潰。［[0476-西羅馬的崩潰.md](0476-西羅馬的崩潰.md)］
- 541–549：查士丁尼瘟疫——地中海人口腰斬的疾病衝擊。
- 605：隋朝開科舉——中國官僚帝國的組織技術。［[0605-科舉與中國官僚帝國.md](0605-科舉與中國官僚帝國.md)］
- 622：穆罕默德遷往麥地那——伊斯蘭共同體（烏瑪）的誕生。［[0622-伊斯蘭的崛起.md](0622-伊斯蘭的崛起.md)］

### 四、中世紀的體系（600–1400）

- 751：怛羅斯之戰——造紙術西傳伊斯蘭世界（技術擴散的通道）。
- 868：《金剛經》雕版印刷——現存最早有日期的印刷書。［[0868-金剛經與印刷革命.md](0868-金剛經與印刷革命.md)］
- 962：神聖羅馬帝國建立；988 基輔羅斯受洗（東方正教圈的形成）。
- 1088：波隆那大學——歐洲大學的誕生（知識的制度化）。
- 1096–1291：十字軍東征：救贖經濟學的動員實驗。［[1096-十字軍東征.md](1096-十字軍東征.md)］
- 1206：成吉思汗統一草原——蒙古世界體系與絲路的重新接通。［[1206-蒙古世界體系.md](1206-蒙古世界體系.md)］
- 1279：元朝統一中國；紙幣與驛站的帝國網路。
- 1299：鄂圖曼侯國建立。
- 1347–1351：黑死病——疾病重置歐洲的經濟與社會。［[1347-黑死病.md](1347-黑死病.md)］
- 1405–1433：鄭和七下西洋與中國的海洋轉向。［[1405-鄭和下西洋與中國的轉向.md](1405-鄭和下西洋與中國的轉向.md)］

### 五、近代早期的三重革命（1450–1700）

- 1450：古騰堡活字印刷——知識複製成本斷崖式下降。［[1450-古騰堡印刷革命.md](1450-古騰堡印刷革命.md)］
- 1453：君士坦丁堡陷落（見 [武器與戰法/1453]）——火炮與帝國的重新洗牌。
- 1492：哥倫布抵達美洲——哥倫布大交換：疾病、作物、白銀。［[1492-哥倫布大交換.md](1492-哥倫布大交換.md)］
- 1517：路德《九十五條論綱》——印刷術加速的宗教改革。［[1517-宗教改革.md](1517-宗教改革.md)］
- 1543：哥白尼《天體運行論》——科學革命的起點。［[1543-哥白尼與科學革命.md](1543-哥白尼與科學革命.md)］
- 1588：無敵艦隊覆滅；1600 英國東印度公司。
- 1602：荷蘭東印度公司——股份公司與金融革命的誕生。［[1602-荷蘭東印度公司與金融革命.md](1602-荷蘭東印度公司與金融革命.md)］
- 1618–1648：三十年戰爭→1648 西發利亞和約——主權國家體系。
- 1637：鬱金香泡沫——第一批金融心理學教材。
- 1660：倫敦皇家學會；1665《哲學會刊》——科學共同體的制度化。
- 1687：牛頓《自然哲學的數學原理》——機械宇宙的誕生。［[1687-牛頓與科學革命頂點.md](1687-牛頓與科學革命頂點.md)］

### 六、革命與工業（1700–1900）

- 1707：英格蘭蘇格蘭合併；1721 華爾波爾首任英國首相（內閣制的成形）。
- 1769：瓦特分離冷凝器蒸汽機專利——工業革命的引擎。［[1769-瓦特蒸汽機與工業革命.md](1769-瓦特蒸汽機與工業革命.md)］
- 1776：美國《獨立宣言》＋亞當斯密《國富論》——政治與經濟的雙重革命。［[1776-國富論與美國建國.md](1776-國富論與美國建國.md)］
- 1789：法國大革命——財政、心理、資訊與思想的多因案件。［[1789-法國大革命.md](1789-法國大革命.md)］
- 1804：海地獨立——史上第一次成功的奴隸革命。
- 1830：利物浦-曼徹斯特鐵路；1837 電報——時空的壓縮。［[1830-鐵路與電報.md](1830-鐵路與電報.md)］
- 1848：歐洲革命之年——民族主義與自由主義的總預演。
- 1859：達爾文《物種起源》——科學、宗教與心理的碰撞。［[1859-達爾文物種起源.md](1859-達爾文物種起源.md)］
- 1861–1865：美國內戰——工業化總體戰的首次展示。
- 1869：蘇伊士運河開通（＋1866 大西洋電纜）——第一波全球化的基礎設施。［[1869-蘇伊士與全球化.md](1869-蘇伊士與全球化.md)］
- 1871：德意志帝國成立——民族主義時代與群眾政治。［[1871-德意志統一與民族主義時代.md](1871-德意志統一與民族主義時代.md)］
- 1884：柏林會議——列強瓜分非洲的規則；格林威治本初子午線（國際標準）。
- 1890s：電力、內燃機、化學工業——第二次工業革命。

### 七、總體戰與意識形態（1900–1950）

- 1903：萊特兄弟動力飛行（見 [武器與戰法/1903]）；1905 日俄戰爭——亞洲國家擊敗歐洲帝國。
- 1908：福特 T 型車——大眾消費與大眾社會的誕生。
- 1914–1918：第一次世界大戰——總體戰：武器、組織、心理、經濟的全因素咬合。［[1914-第一次世界大戰.md](1914-第一次世界大戰.md)］
- 1917：俄國革命——列寧式政黨與意識形態國家的誕生。［[1917-俄國革命.md](1917-俄國革命.md)］
- 1919：凡爾賽和約——民族自決與復仇並存。
- 1928：弗萊明發現青黴素（＋公共衛生革命）——人口轉型的加速器。［[1928-青黴素與人口革命.md](1928-青黴素與人口革命.md)］
- 1929：華爾街股災與經濟大蕭條——恐慌、信心與制度的案件。［[1929-經濟大蕭條.md](1929-經濟大蕭條.md)］
- 1933：希特勒上台——蕭條與民粹的路徑。
- 1939–1945：第二次世界大戰——科技的極致動員（雷達、密碼、原子彈；見 [武器與戰法] 各篇）。
- 1945：聯合國＋布列敦森林＋核時代——戰後秩序的三大支柱。［[1945-戰後秩序.md](1945-戰後秩序.md)］

### 八、冷戰與全球化（1945–2000）

- 1947：印度獨立——去殖民化與第三世界的誕生。［[1947-去殖民化與第三世界.md](1947-去殖民化與第三世界.md)］
- 1950s–60s：綠色革命（波洛格的高產小麥）——糧食與人口的賽跑。
- 1957：史普尼克（見 [武器與戰法/1957]）——太空競賽與「飛彈差距」恐慌。
- 1969：阿波羅十一號登月——大科學與冷戰象徵資本的頂點。［[1969-登月與冷戰科技競賽.md](1969-登月與冷戰科技競賽.md)］
- 1971：布列敦森林體系終結（浮動匯率）。
- 1978：中國改革開放——另一條現代化路徑的實驗。
- 1989：柏林圍牆倒下——計畫經濟的資訊問題與和平演變。［[1989-冷戰結束.md](1989-冷戰結束.md)］
- 1991：蘇聯解體；全球資訊網（WWW）公開——兩場革命同一年。［[1991-全球資訊網.md](1991-全球資訊網.md)］
- 1997：亞洲金融風暴；2001 中國加入世貿組織。

### 九、網路與 AI 時代（2000–今日）

- 2004：臉書創立；2007 iPhone——行動網路與平台經濟。
- 2008：金融海嘯——證券化、槓桿與「大而不能倒」。［[2008-金融海嘯.md](2008-金融海嘯.md)］
- 2010s：行動網路普及；阿拉伯之春（2011）——社會運動的網路化。
- 2016：AlphaGo；2017 Transformer 架構問世——深度學習的轉折。
- 2020：新冠疫情——疾病、科技、政治與經濟的全球測壓。［[2020-新冠疫情與全球測壓.md](2020-新冠疫情與全球測壓.md)］
- 2022：ChatGPT 問世；2023 生成式 AI 爆發——資訊社會的重構。［[2023-生成式AI與資訊社會.md](2023-生成式AI與資訊社會.md)］
- 2023–2025：晶片戰與地緣技術競爭；AI 對勞動市場與教育的衝擊（進行中）。

## 歷史的多因規律（七條）

1. **科技改變成本，成本改變制度**：印刷使知識複製成本趨零→教會的壟斷租金瓦解；蒸汽機使動力成本下降→工廠制度。看懂一項技術，先看它改寫了什麼成本。
2. **武器與組織互相定義**：馬鐙→騎士封建；火藥→中央集權的官僚軍；機槍→總體戰國家；核武→嚇阻機構。誰養得起決勝力量，誰就定義政治形態（與 [武器與戰法] 的規律相通）。
3. **資訊速度決定協調半徑**：文字→帝國行政；印刷→宗教與民族運動；電報→總參謀部與帝國主義；網路→全球運動。協調半徑的擴大是帝國、革命與全球化的共同引擎。
4. **外生衝擊重置系統**：黑死病把勞動力砍半→工資翻倍→封建義務瓦解；小冰期的歉收→革命的前奏；新冠→遠距與供應鏈重組。疾病與氣候是歷史的「隱形主角」。
5. **心理與信念是經濟的燃料**：救贖經濟學（十字軍）、鬱金香與華爾街的泡沫、恐慌與信心的銀行擠兌、「期望革命」（繁榮中的怨恨）。預期本身會自我實現——經濟史的一半是心理史。
6. **宗教提供合法性、動員與紀律**：君士坦丁的收編、伊斯蘭的組織技術、宗教改革的教派競爭、民族主義（世俗宗教）的動員。「無形報酬」（救贖、榮耀、認同）可以換取「有形服務」。
7. **回饋迴路決定歷史的加速度**：農業→人口→城市→文字→科技→更多農業；煤→蒸汽→鐵路→市場→利潤→更多煤。正向迴路造成起飛，負向迴路（帝國的行政成本、計畫經濟的資訊失真）造成崩潰——歷史的曲線是迴路的乘積。

## 閱讀方式

每篇 wiki 依「推理探案」格式撰寫，但分析焦點是**因素咬合**：

- **案件摘要**：這樁懸案的「兇手」（因素組合）做了什麼。
- **前因**：分因素列點（科技／經濟／政治／心理／……）的案發前局勢。
- **線索與推理**：因素如何互相咬合（回饋迴路、成本曲線、模型與表格），逐步還原因果鏈。
- **破案時刻**：案件的真相與高潮。
- **後果**：各因素被改寫之後，世界如何變化。
- **因素影響筆記**：本案件留下哪些「因素→因素」的因果鏈，連結到下一樁案件。

年表以時代分章；因素矩陣總覽各案件動用的因素；各篇 wiki 之間以「前案／後案」互相引用，串成本書的偵探主線。與 [武器與戰法] 卷（武器→戰法的主線）互相補充：這一卷看「因素網路」，武器卷看「武器→戰法」的單線深化。
