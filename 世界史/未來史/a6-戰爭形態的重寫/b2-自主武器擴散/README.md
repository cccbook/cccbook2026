# b2-自主武器擴散

> [a6-戰爭形態的重寫](../) 的下游節點——**如果自主武器擴散發生**，下游分岔：[c1-低烈度戰爭常態化](c1-低烈度戰爭常態化/)、[c2-道德鐘擺](c2-道德鐘擺/)。

## 這個節點（如果發生）是什麼

自主武器（AI 末端制導、蜂群、目標獲取）的擴散路徑：國家軍隊→盟友→市場→**非國家行為者**——「禁忌的失效條件」（[武器與戰法/1943] 先驗：非國家行為者使「報復可信」失效→禁忌的支撐腿被抽掉）。

## 傳導與理論

擴散的傳播律（與 [武器與戰法/-1650] 的技術擴散同構）：**沒有祕密材料的技術，擴散極快**——自主武器的核心是「演算法+量產」，兩者皆無法封鎖。

## 下游分岔（若…否則…）

| 環節 | 若 | 否則 |
|------|-----|------|
| 傷亡的不對稱 | 己方零傷亡的政治誘惑→常態化（c1） | 一次災難（平民大量死亡）→道德反彈、條約動員（c2） |
| 條約的時機 | 常態化之前的預防性條約（罕見）→門檻維持 | 常態化之後→條約追認現實（鎖定在低位） |

## 觀察指標

- 自主武器的條約談判進度（停滯=常態化的時間窗）。
- 非國家行為者的自主武器使用案例。
- 「無傷亡軍事行動」的公開報導與政治反應。

## 不確定性

- 「一次災難的道德反彈」可能翻轉（毒氣的先驗：1915–25 從使用到禁忌）——鐘擺方向由單一事件決定。
