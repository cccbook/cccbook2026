# 單人戶主流_照護真空_誰照顧誰的契約重寫

## 案件摘要

**如果單人戶主流化發生，就會造成「照護真空」，進而造成「誰照顧誰的社會契約重寫」**——一人戶占四成、獨居老人沒有家人照護者：家庭的照護模型崩潰，「照顧」必須重新找到供給者（市場、國家、社群、AI）。這條鏈的終點是：社會契約的深層重寫——**「誰提供照護，誰獲得忠誠」**（[0313-君士坦丁與基督教的勝利](../世界史/0313-君士坦丁與基督教的勝利.md) 的規律）的新競爭。

## 起火點 -- 如果單人戶主流化發生

- **現況證據**：一人戶占比——日韓台 35–40%、北歐逼近五成；都會區單人戶已成最大戶型；獨居老人的照護缺口統計持續擴大。
- **觸發條件**：少子化（[2027] 的引擎）＋solo economy 的舒適化（引擎三）＋婚育的延後與退出。

## 連鎖推演 -- A→B→C

### 第一步：單人戶主流化（人口⇒經濟）

$$\text{照護需求} \propto \text{（獨居老人數）} \quad \text{照護供給} = \text{家人} + \text{市場} + \text{國家} + \text{AI}$$

「家人」這一項歸零——其餘三項的總和就是社會契約的新邊界。

### 第二步：照護真空（經濟⇒社會）

- 家人的照護模型崩潰：一戶一人→「誰照顧我」沒有答案——**照護的勞動稀缺**（與老齡化搶人力，[2042]）。
- 孤獨的公共衛生：社會隔離的健康成本（死亡率↑）與吸菸同級——**孤獨是流行病**。

### 第三步：「誰照顧誰」的契約重寫（社會⇒政治⇒法律）

- 競爭的供給者：國家（長照保險）、市場（付費照護與 AI）、社群（互助與時間銀行）——**誰提供照護，誰獲得忠誠**（[0313] 的教會崛起邏輯：互助網路→組織的勝利）。
- 法律的承認：非親屬的醫療/遺囑/急診委託常態化——**「選擇家人」的法律地位**（與 [2046] 的契約重構咬合）。
- 與 [ai照護補位_獨居安全_親密的服務化](ai照護補位_獨居安全_親密的服務化.md)（AI 補位的鏈）互為分岔：AI 頂上 vs 人力與制度頂上。

## 分岔 -- 每一步的「若…否則…」

| 環節 | 若 | 否則 |
|------|-----|------|
| 照護的供給 | AI+市場補位（→[ai照護補位_獨居安全_親密的服務化](ai照護補位_獨居安全_親密的服務化.md)）→真空關閉 | 補位失敗→照護危機（健保與長照的爆發） |
| 國家 vs 市場 | 長照保險的國家化→「照護=公民權」 | 私人市場主導→照護的階級化 |
| 社群的回歸 | 互助與時間銀行（[0313] 的教會邏輯）→社群的忠誠競爭 | 私人社會的延續→孤獨常態化 |

## 整個世界的變化

| 領域 | 變化 |
|------|------|
| 社會 | 「照顧」的契約化；「選擇家人」的法律地位；社群與互助的回歸或缺席 |
| 政治 | 照護的供給者競爭「忠誠」（國家/平台/社群/教會）——政治的新戰場 |
| 經濟 | 照護產業的重構（人力→科技）；長照保險的財政 |
| 法律 | 非親屬委託與「選擇家人」的立法——與 [2046] 咬合 |
| 心理 | 孤獨的公共衛生；依附的服務化爭議 |

## 觀察指標

- 一人戶中「無近親」的比例（照護真空的深度）。
- 非親屬醫療/遺囑/急診委託的法律案件常態化。
- 長照保險的立法與給付範圍（國家化的訊號）。
- 時間銀行與社群互助的參與人數（社群回歸的訊號）。

## 不確定性

- 「誰獲得忠誠」的競爭結果（國家/市場/社群/AI）無法推演——歷史先驗（教會、福利國家）給了模式，但結果開放。
- 照護的「人力稀缺」可能被移民補位（與 [2042] 的 L3 交叉）——真空的填法是多解的。
