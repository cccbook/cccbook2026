# b1-保險退潮

> [a8-氣候衝擊與修復](../) 的下游節點——**如果保險退潮發生**，下游分岔：[c1-不可保地帶擴張](c1-不可保地帶擴張/)、[c2-氣候遷徙](c2-氣候遷徙/)。

## 這個節點（如果發生）是什麼

保險是氣候風險的「即時定價器」：極端天氣使賠付率失控→再保險定價傳導→保險公司撤出高風險區——「不可保化」的地產與財政連鎖開始。

## 傳導與理論

$$\text{極端事件頻率} \propto e^{\Delta T} \quad \text{（小升溫、大頻率——氣候科學的核心非線性）}$$

保險的定價器邏輯：保費↑/承保退出→地產估值↓（沒有保險=沒有房貸）→地方稅基↓→財政↓→適應能力更弱——**風險的死亡螺旋**。

## 下游分岔（若…否則…）

| 環節 | 若 | 否則 |
|------|-----|------|
| 國家的角色 | 「最後保險人」接管→財政風險社會化 | 自由市場撤資→地帶被棄（c1） |
| 適應的投資 | 堤防、建築規範、遷村→風險下降（保險回歸） | 不投資→螺旋持續 |
| 居民的反應 | 有序遷村（c2） | 災後逃離→政治地震 |

## 觀察指標

- 保險公司退出的公告與「最後保險人」的承保規模。
- 高風險區的地產交易與估值。
- 再保險費率的年度變化。

## 不確定性

- 適應投資可能使保險回歸——螺旋不是必然。
