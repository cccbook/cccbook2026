# b3-地球工程

> [a8-氣候衝擊與修復](../) 的下游節點——**如果地球工程（SRM）的誘惑與風險展開發生**，下游分岔：[c1-歸因衝突與氣候地緣戰](c1-歸因衝突與氣候地緣戰/)、[c2-協調治理與條約](c2-協調治理與條約/)。

## 這個節點（如果發生）是什麼

太陽輻射管理（SRM，平流層氣溶膠）技術簡單、成本以十億計：**一國或私營者即可啟動，全球承擔副作用**——「無法防禦的公共財」（[武器與戰法/1944-戰略轟炸與V武器](../../../武器與戰法/1944-戰略轟炸與V武器.md) 的 V-2 先驗：無法防禦≠有價值）。

## 傳導與理論

$$\text{SRM} = \text{（單方可動用）} + \text{（全球副作用）} + \text{（地區效應不均）}$$

「治理真空期的單方行動」（與 [a3/b2-治理真空](../../../a3-AI治理與法律/b2-治理真空擴大/) 同構）——本節點的分岔：單方動用（c1）vs 協調治理（c2）。

## 下游分岔（若…否則…）

| 環節 | 若 | 否則 |
|------|-----|------|
| 動用者 | 國家（可歸因）→外交對峙（c1） | 私營者（不可歸因）→陰謀論與混亂 |
| 副作用分布 | 相對均勻→容忍 | 明顯不均（雨帶移動）→受損方報復動機 |
| 治理的重建 | 條約與監測機構→收束（c2） | 無條約→持續歸因戰（c1） |

## 觀察指標

- SRM 研究與試驗的公開度與地點（秘密試驗=單方動用前置）。
- 「天氣歸因」科學（attribution science）的成熟度。
- 國際 SRM 談判的進度。

## 不確定性

- 「單方動用」是低機率高衝擊的尾端——政治選擇無法推演。
- 歸因科學可能成熟到「可裁決」——歸因衝突可能被科學部分化解。
