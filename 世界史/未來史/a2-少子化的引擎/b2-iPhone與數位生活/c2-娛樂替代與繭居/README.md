# c2-娛樂替代與繭居

> 樹葉節點：[a2/b2-iPhone與數位生活](../../) 的終點——**如果娛樂替代與繭居深化發生，整個世界的變化**。

## 這個終點的世界（變化總帳）

| 領域 | 變化 |
|------|------|
| 社會 | 「在家滿足」的常態化：串流、遊戲、短影音的替代——外出與聚會的萎縮；繭居（蟄居族）的擴大 |
| 經濟 | 「宅經濟」的全面化（外送、虛擬娛樂、在家服務）；實體商業（餐廳、聚會場所）的萎縮 |
| 心理 | 社交焦慮的螺旋（練習↓→能力↓→更繭居）；孤獨的「服務化」管理（→[a7/b2/c2-照護真空](../../../a7-壽命革命與老齡化/b2-老齡化加深/c2-單人戶與照護真空/)） |
| 人口 | 社交的萎縮=婚育前置行為的萎縮——與 [a2/b4/c1-親密退位](../../../a2-少子化的引擎/b4-AI陪伴的雙面/c1-真實親密退位與少子化加深/) 疊加 |
| 跨鏈 | 「數位排毒」與「面對面價值重估」的文化反彈——反向市場（實體體驗的溢價） |

## 上游（傳導回顧）

娛樂替代：在家的滿足↑→社交動機↓——「低摩擦的在家生活」與「高摩擦的外出社交」的相對價格逆轉。

## 觀察指標

- 青年世代的「出門時數」與繭居人口的統計。
- 實體聚會場所（餐廳、KTV、書店）的家數變化。
- 「數位排毒」與實體體驗產業的溢價（反彈的訊號）。

## 不確定性

- 文化反彈（實體體驗的價值重估）可能形成平衡——繭居不必然單向深化。
- 「繭居」的定義分歧（自願 vs 被迫）使統計不可靠。
