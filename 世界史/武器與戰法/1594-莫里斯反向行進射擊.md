# 1594-莫里斯反向行進射擊：把火槍手變成「機器」

## 案件摘要

西元 1590 年代，荷蘭執政拿騷的莫里斯親王面對西班牙大方陣，做出一項影響此後兩百年的改革：**以操典（drill）把火繩槍手變成射擊機器**。他把火槍裝填拆解為標準化的連續動作、以「反向行進射擊」（countermarch）讓橫隊輪流上前開火再退後裝填，使火槍隊能維持近乎不中斷的齊射；並以小型橫隊取代巨型方陣。1607 年《武器操演》（Wapenhandelinghe）出版，圖解全部動作。這樁案件確立了線列時代的基礎：**操練 = 射速 = 戰鬥力**，個體射速不足就靠「輪射組織」補足——軍隊從此變成「標準化作業的戰鬥機器」。

## 前因 -- 為什麼會有這個案子

- 荷蘭獨立戰爭（八十年戰爭）中，荷軍面對西班牙大方陣與職業軍團，兵力與資金都處於劣勢。
- 火繩槍射速慢（1–2 發/分）且需在陣前完成裝填——傳統深縱隊的解法是「前排開火、後排上前」，但混亂且射擊中斷。
- 莫里斯深入研究羅馬軍制（艾利安、李奧的著作），以「古典復興＋當代問題」的思路改革。

## 線索與推理 -- 組織工程

### 線索一：反向行進射擊的邏輯

橫隊十列，分為數個「射擊排」輪流上前射擊、退後裝填：

```
排1：上前 → 齊射 → 退後 → 裝填
排2：上前 → 齊射 → 退後 → 裝填   ← 同時進行
排3：上前 → 齊射 → 退後 → 裝填
```

設每排裝填時間為 $t$、排數為 $n$，則體系射速為

$$\text{體系射速} = \frac{n}{t} \text{ 發/分/正面單位}$$

**個體射速不變，體系射速隨排數線性增加**——這是把「人手限制」轉化為「排程問題」的組織工程。現代工業的流水線（福特 1913）、作業系統的時間片輪轉，都是同一數學。

### 線索二：裝填的動作分解

莫里斯把火槍裝填拆解為數十個標準動作（倒藥、裝彈、通條、吹管……），每個動作以操典規定、每日操練。**動作分解＋重複訓練 = 可靠性與速度**——這是泰勒科學管理（1911）的軍事前身，早了三百年。

### 線索三：橫隊取代縱深

大方陣（tercio）的縱深是為了「衝擊與反衝擊」，但**縱深越大，同時開火的火槍越少**。莫里斯以 10 列小型橫隊取代 30 列大方陣：

| | 大方陣 | 莫里斯橫隊 |
|---|--------|------------|
| 縱深 | 30+ 列 | 10 列 |
| 同時開火人數 | 少（前排） | 多（輪射全隊） |
| 機動性 | 慢 | 快 |
| 防騎 | 靠長矛 | 靠長矛＋地形 |

**火力與縱深的取捨**：防禦衝擊需要縱深，發揮火力需要橫隊——莫里斯以操練的紀律取代縱深的保險，這是「線性戰術」的誕生（布萊登菲爾德將驗證它，見 [1631-布萊登菲爾德會戰.md](1631-布萊登菲爾德會戰.md)）。

### 線索四：軍官職業化

莫里斯設立軍事學校、以考試晉升軍官、以操典統一全軍動作——**軍隊變成「有標準作業程序的組織」**。這條線索在普魯士總參謀部（1870）、現代軍事學說（Doctrine）體系反覆出現。

## 破案時刻

- 1597 圖倫豪特、1600 尼烏波特：荷軍以新操典擊敗西班牙王牌軍團——改革經過實戰驗證。
- 1607《武器操演》出版，全歐洲以圖解學習荷蘭操典——**操典成為國際軍事語言**。

## 後果 -- 改變了什麼

- 歐洲軍隊全面操典化：瑞典（古斯塔夫）、法國（路易十四）、普魯士（腓特烈）都以操典立軍。
- 「軍事革命」論題（Michael Roberts 1955；Geoffrey Parker 擴充）：操典、棱堡、常備軍、財政國家互相強化——**軍事變革推動國家形成**。
- 標準化思維從軍隊擴散到工業：操典是流水線與科學管理的祖先。

## 戰法演進筆記

莫里斯的戰法遺產：

1. **個體射速不足，以「排程」補足**——輪射是把人的限制轉化為組織設計問題。
2. **動作分解＋操練 = 可靠性**——標準化作業是戰鬥力的工程學。
3. **火力與縱深的取捨**——橫隊換火力，以紀律補保險。
4. **軍官職業化與操典**——軍隊從武士團變成組織，組織能力成為戰鬥力的核心。
