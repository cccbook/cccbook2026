# 6.2 快捷鍵指南

## 核心快捷鍵（每天用）

| 快捷鍵 | 功能 |
|---|---|
| `Enter` | 送出提示；工作中 = **Steer**（中途修正） |
| `Alt+Enter` | 工作中 = **Follow-up**（排隊追加） |
| `Alt+Up` | 把佇列訊息拿回編輯器 |
| `Escape` | 中止當前任務 |
| `Shift+Enter` / `Ctrl+J` | 插入換行 |
| `Ctrl+G` | 用外部編輯器寫長提示 |
| `Ctrl+L` | 開啟模型選擇器 |
| `Ctrl+P` | 循環切換模型 |
| `Shift+Tab` | 循環切換思考等級 |
| `Ctrl+O` | 展開/收合工具輸出 |
| `Ctrl+T` | 顯示/隱藏思考區塊 |
| `Ctrl+X` | 複製最後一條 assistant 回應 |
| `Tab` | 補全路徑 |
| `@` | 搜尋檔案插入提示 |

## Windows / WSL 替代鍵

Windows Terminal 保留部分 Alt 快捷鍵：

| 功能 | macOS/Linux | Windows/WSL |
|---|---|---|
| Follow-up | `Alt+Enter` | `Ctrl+Q` |
| 取回佇列 | `Alt+Up` | `Alt+Q` |
| 模型循環反向 | `Shift+Ctrl+P` | `Alt+P` |
| 貼上剪貼簿 | `Ctrl+V` | `Alt+V` |

> 隨時執行 `/hotkeys` 顯示你這個會話生效的快捷鍵。

## 編輯器操作（readline 風格）

| 快捷鍵 | 功能 |
|---|---|
| `Ctrl+A` / `Home` | 跳到行首 |
| `Ctrl+E` / `End` | 跳到行尾 |
| `Ctrl+W` / `Alt+Backspace` | 刪一個字（向左） |
| `Ctrl+U` | 刪到行首 |
| `Ctrl+K` | 刪到行尾 |
| `Ctrl+Y` | 貼上最近刪除的文字（yank） |
| `Ctrl+-` | 復原最後一次編輯 |
| `Alt+左/右` | 以字為單位移動 |
| `↑` / `↓` | 瀏覽提示歷史 |

## 全螢幕模式（預設）

| 快捷鍵 | 功能 |
|---|---|
| `PageUp` / `PageDown` | 捲動記錄 |
| `Ctrl+Shift+↑` / `Ctrl+↑` | 跳到上一個標記訊息 |
| `Ctrl+Shift+↓` / `Ctrl+↓` | 跳到下一個標記訊息 |
| `Ctrl+Shift+F` | 搜尋記錄 |
| `Ctrl+Home` / `Ctrl+End` | 跳到最開頭 / 最尾端 |
| `Ctrl+C`（第一次） | 清空編輯器；第二次離開 |
| `Ctrl+D` | 編輯器空時離開 |

## /tree 中的快捷鍵

| 快捷鍵 | 功能 |
|---|---|
| `Ctrl+左/右` | 摺疊/展開分支段 |
| `Shift+L` | 編輯節點書籤（label） |
| `Shift+T` | 切換書籤時間戳 |
| `Ctrl+U` | 只顯示使用者訊息 |
| `Ctrl+T` | 隱藏 tool results |
| `Ctrl+L` | 只顯示有書籤的條目 |
| `Ctrl+O` | 循環切換過濾模式 |

## 會話選擇器中

| 快捷鍵 | 功能 |
|---|---|
| `Ctrl+P` | 切換路徑顯示 |
| `Ctrl+S` | 切換排序模式 |
| `Ctrl+N` | 只顯示有名字的會話 |
| `Ctrl+R` | 重新命名 |
| `Ctrl+D` | 刪除會話 |

## 自訂快捷鍵

建立 `~/.pi/agent/keybindings.json`，改預設或綁未使用的動作：

```json
{
  "app.session.new": "ctrl+shift+n",
  "app.session.tree": ["ctrl+shift+t", "alt+shift+t"]
}
```

- key 語法：`modifier+key`，modifier 是 `ctrl` / `shift` / `alt` / `super`
- 空陣列 `[]` 可停用某動作的快捷鍵
- 改完執行 `/reload` 立即生效

常用的可綁動作：`app.session.new`、`app.session.tree`、`app.session.fork`、`app.session.resume`、`app.model.select`、`app.thinking.cycle`、`app.interrupt`、`app.editor.external`（完整清單見 `/hotkeys` 與官方 [Keybindings](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/keybindings.md)）。

> `super` 綁定需要終端機支援 Kitty keyboard protocol，一般終端機可能無效。
