# 1989-WWW：CERN 走廊裡誕生的全球超文本

## 案件摘要
1989 年 3 月，CERN 的英國物理學家 Tim Berners-Lee 在一份備忘錄中提出「資訊管理」構想——用超文本連結全球的科學文件。這份被上司批註「模糊但令人興奮」的提案，最終成為 WWW，徹底改寫人類取得知識的方式。

## 前因 -- 為什麼會有這個案子
- **CERN 的文件噩夢**：1980 年代末，上萬名研究員、數千種電腦平台、數十種文件格式在 CERN 來來去去。資訊散落各處，新人抱怨「誰知道這份報告在哪台機器上？」
- **超文本的百年伏筆**：1945 年 Vannevar Bush 的 Memex 構想、1960 年代 Ted Nelson 的 Project Xanadu（他造了 hypertext 一詞）早已描繪連結式文件的願景，卻始終沒有實作成功。
- **網路已就緒**：TCP/IP 於 1983 年切換，Internet 存在但只屬於學術精英——沒有統一的介面，普通人無法使用。
- ** Berners-Lee 的洞見**：超文本 + Internet = 把每台電腦上的文件用「連結」織成一張全球網。1989 年 3 月提出提案，1990 年 10 月開始實作，1991 年 8 月在 Usenet 公開。

## 線索與推理 -- 數學式、程式、理論

### 三大發明
Berners-Lee 在 1990 年的三個月內完成了三件套，至今仍是 Web 的核心：

1. **HTML（超文本標記語言）**——用 SGML 簡化而來的標記語言：

```html
<!DOCTYPE html>
<html>
  <head><title>CERN 首頁</title></head>
  <body>
    <h1>World Wide Web</h1>
    <p>這是 <a href="http://info.cern.ch/hypertext/WWW/TheProject.html">
    第一個網頁</a>的再現。</p>
  </body>
</html>
```

2. **URL（統一資源定位器）**——每份文件一個全球唯一位址。URL 結構解析：

```
https://info.cern.ch:80/hypertext/WWW/TheProject.html?id=1#top
└─┬──┘ └────┬─────┘└┬┘└──────────┬─────────────┘└┬─┘└┬─┘
scheme     host    port          path           query fragment
```

   對應的數學模型：URL 是一個映射

$$URL: \text{scheme} \times \text{host} \times \text{port} \times \text{path} \times \text{query} \to \text{Resource}$$

3. **HTTP（超文本傳輸協定）**——無狀態（stateless）的請求-回應協定：

```text
GET /hypertext/WWW/TheProject.html HTTP/1.1
Host: info.cern.ch
```

無狀態性質可用數學描述：每次請求 $r_i$ 的回應 $f(r_i)$ 只依賴 $r_i$ 本身：

$$f(r_i) \perp \{r_j : j \neq i\}$$

這個「健忘」設計換來的是無限的可擴展性（stateless 伺服器可任意加機器負載平衡）。

### 第一個瀏覽器與伺服器
- 1990 年 12 月：Berners-Lee 用 NeXT 電腦寫出第一個瀏覽器（同時是編輯器）與第一個 HTTP 伺服器（CERN httpd）。第一個網頁 `info.cern.ch` 至今仍在線上。
- 1991 年 8 月 6 日：他在 `alt.hypertext` 新聞群組張貼公告，WWW 正式對外開放。

### WWW vs 競爭者

| 系統 | 特點 | 為何輸給 WWW |
|------|------|--------------|
| Gopher（1991, 明尼蘇達大學） | 階層式選單文件 | 免費 vs 後來收授權費；WWW 更有彈性 |
| WAIS | 資料庫全文檢索 | 缺少超文本連結 |
| FTP | 檔案傳輸 | 無瀏覽體驗、無連結 |
| HyTelnet | 圖書館系統目錄 | 封閉、不開放 |

關鍵勝因：**1993 年 4 月 CERN 宣布 WWW 專利免費開放**，同時伊利諾大學的 **Mosaic** 瀏覽器（Marc Andreessen）加入圖形顯示，引爆大眾採用。1994 年 Andreessen 成立 Netscape，Netscape Navigator 一度佔有率超過 90%，開啟第一次瀏覽器大戰。

### Web 的演化
- **Web 1.0（1990s）**：靜態網頁，單向閱讀。$P(\text{read}) = 1, P(\text{write}) \approx 0$
- **Web 2.0（2000s）**：使用者產生內容（UGC），部落格、社群、維基。$P(\text{write})$ 大幅上升
- **Web 3.0（2020s）**：去中心化（區塊鏈）、語意網、AI 賦能。理想上是把「主權」還給使用者

## 結案 -- 後果與影響
- WWW 讓 Internet 從百萬學術用戶暴增到數十億人，成為人類史上最大的資訊基礎建設。
- Berners-Lee 放棄專利，成立 W3C（1994）持續制定開放標準；2016 年獲圖靈獎。
- 商業模式被徹底重寫：電子商務、搜尋引擎（Google）、社群媒體皆建構在 HTML/URL/HTTP 之上。
- 一個被上司批為「模糊」的提案，證明了**開放標準 + 免費授權**才是贏得世界的策略。
