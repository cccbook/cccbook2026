# 1450-古騰堡活字印刷機

## 案件摘要

約1450年前後，德國美因茲（Mainz）的金匠約翰內斯·古騰堡（Johannes Gutenberg，約1400–1468）完成了一項系統性發明：以鉛銻錫合金鑄造金屬活字、以手搖鑄字模具量產活字、改裝葡萄酒螺旋壓床為印刷機、調配油性印刷墨。約1455年印成的《古騰堡聖經》（四十二行聖經）是其代表作。單獨看每一項都不算全新，但把它們整合成可量產、可重製的印刷系統，是知識傳播史上的革命起點。

## 前因 -- 為什麼會有這個案子

- 中世紀書籍靠抄寫員手工謄寫，一本聖經需一名抄寫員費時約一年以上，書籍昂貴稀有。
- 中國活字印刷（北宋畢昇，約1045年泥活字）與韓國金屬活字（高麗《直指》，1377年）早已存在，但漢字數量龐大、雕版印刷已高度成熟，活字優勢不明顯。
- 歐洲使用拉丁字母，字母數量僅數十個——活字技術在歐洲的邊際效益遠高於東亞，這是本案的關鍵結構性線索。
- 古騰堡是美因茲金匠，熟悉金屬鑄造、合金與衝壓技術；十五世紀德國的造紙術（自義大利傳入）與葡萄酒壓床提供了硬體條件。
- 他與商人約翰·福斯特（Johann Fust）借貸約800古爾登開設工坊，這是一筆有商業回報期待的風險投資。

## 線索與推理 -- 數學式、程式、理論

### 理論一：鑄字合金的冶金學——鉛銻錫的黃金比例

古騰堡的活字合金約為鉛（Pb）60–80%、銻（Sb）15–25%、錫（Sn）5–15%。純鉛凝固時收縮率大（約3.5%），鑄出的字會缺角變形；銻凝固時反而微膨脹，抵銷收縮，使字面銳利清晰。冶金學上，合金凝固收縮量可近似為線性混合：

$$\epsilon_{alloy} \approx w_{Pb}\,\epsilon_{Pb} + w_{Sb}\,\epsilon_{Sb} + w_{Sn}\,\epsilon_{Sn}$$

其中 $w_i$ 為重量分數。取鉛70%、銻20%、錫10%（$\epsilon_{Pb}\approx-3.5\%$、$\epsilon_{Sb}\approx+0.3\%$、$\epsilon_{Sn}\approx-2.3\%$）：

$$\epsilon_{alloy} \approx 0.7(-3.5) + 0.2(0.3) + 0.1(-2.3) = -2.85\%$$

仍嫌偏大，故實際配方提高銻比例使收縮近於零，同時銻提升硬度（字要承受數千次壓印而不變形）。金匠的古騰堡解開了這個冶金謎題。

### 理論二：壓床的力學——螺旋壓印的均勻壓力

改裝自葡萄酒壓床的螺旋壓床，以螺桿把旋轉力轉為巨大垂直壓力。螺旋的機械利益：

$$F_{out} = F_{in} \cdot \frac{2\pi L}{p}$$

其中 $L$ 為搖桿長、$p$ 為螺距。取 $L=0.5$ m、$p=0.01$ m，機械利益約 $314$ 倍——一人以 300 N 施力即可產生近 10 萬 N 的壓力，足以將油墨從活字面均勻壓到紙上。印刷壓力需均勻分布於整版，故古騰堡採用平面式壓板與皮製墊版（tympan/frisket）定位紙張——每頁壓印一次，產能遠超抄寫員。

### 理論三：資訊經濟學——複製成本的数量級崩跌

抄寫成本隨字數線性增長：$C_{copy} = c \cdot N$（$N$ 為字數）。活字印刷的成本結構是「固定成本 + 低邊際成本」：

$$C_{print} = C_0 + c' \cdot N \cdot \frac{1}{n} \quad (n \text{ 為印數})$$

印數 $n$ 越大，單位成本趨近墨與紙的邊際成本。四十二行聖經一次印約180冊，每冊641頁、1282欄，字數約數十萬——若以抄寫生產同等書籍，成本高出數十倍。印刷使知識複製成本崩跌一個數量級以上，網路效應（識字率上升 → 需求上升 → 更多印刷 → 更便宜）就此啟動。

```python
# 驗證：抄寫 vs. 印刷的單位成本
c_copy = 1.0          # 抄寫單位字成本（相對值）
C0, c_print, N = 5000, 0.01, 2e5   # 印刷固定成本、邊際成本、字數
for n in [100, 500, 1000]:
    unit_print = (C0 + c_print*N) / n
    print(f"印數 {n}：印刷單位成本 {unit_print:.2f} vs 抄寫 {c_copy:.2f}")
```

## 破案時刻

約1455年，《古騰堡聖經》印成：每頁42行、兩欄排版，約180冊（部分印在羊皮紙上），字體模擬哥德手抄體，墨色至今烏黑鮮明。這本書證明金屬活字 + 油墨 + 壓床的完整系統可行——不是發明單一零件，而是整合成「可複製的製造流程」。破案後的插曲殘酷而真實：1455年前後古騰堡與金主福斯特訴訟失利，工坊被福斯特與彼得·舍弗爾（Peter Schöffer）接管並繼續營運獲利；古騰堡晚年靠選帝侯阿道夫的年金度日，1468年去世。技術留給世界，利潤歸了商人。

## 後果 -- 改變了什麼

- 五十年內，歐洲印刷廠超過千家、印書逾兩萬種數百萬冊，書價跌至原本的數分之一。
- 宗教改革（1517年路德《九十五條論綱》以印刷品瘋傳）、科學革命（1543年哥白尼《天體運行論》、標準化的數據與圖表）、文藝復興的人文傳播，全部建立在印刷機之上。
- 標準化、可重製、可校對的文本催生了現代校勘學、版權概念與出版產業；「作者—出版—讀者」的三角結構成形。
- 活字排版的「模組化組合」思想——少量基本元件、無限組合——被史學家（如 Eisenstein、Manovich）視為可複製工業製造與現代資訊技術的原型，直通三百年後的工業革命。
