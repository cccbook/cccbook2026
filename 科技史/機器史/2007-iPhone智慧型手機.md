# 2007-iPhone智慧型手機

## 案件摘要

2007年1月9日，史帝夫·賈伯斯（Steve Jobs）在舊金山 Macworld 展台上發表第一代 iPhone，6月29日上市。這台 3.5 吋螢幕的機器取消了實體鍵盤與觸控筆，用手指在投射式電容觸控螢幕上多點觸控操作，整合了行動電話、iPod、網際網路通訊三合一——而且內建近距感測器、加速度計、GPS 與行動網路。賈伯斯稱它「比所有手機領先五年」。這樁案子的本質：把整台電腦、整組感測器與整個網路，塞進口袋。

## 前因 -- 為什麼會有這個案子

- 2000年代手機市場由 Nokia、Motorola 統治，實體鍵盤 + 小螢幕 + 封閉的 WAP 網路；手機的功能是「打電話」，上網是副業。
- 蘋果的內部動機：iPod（2001）熱賣，但賈伯斯判斷手機會吃掉音樂播放器；摩托羅拉 ROKR（2005，蘋果與摩托合作）的失敗證明「寄人籬下」行不通，蘋果決定自己做手機。
- 技術前提成熟：投射式電容觸控（由 FingerWorks 的技術與專利而來，2005年蘋果收購該公司）、ARM 低功耗處理器、鋰離子電池、3G 前的 EDGE 網路。
- 1990年代 IBM Simon（1994）與 PDA（Palm）已試過觸控與手機結合，但多點觸控與完整網路體驗從未實現。

## 線索與推理 -- 數學式、程式、理論

### 理論一：投射式電容觸控——用電場測量手指

電容觸控屏由透明電極網格（ITO）構成，手指（導體）靠近時耦合走一部分電荷，使該節點電容下降。設未觸碰時節點電容 $C_0$、手指耦合電容 $C_f$，感測電路量到的等效電容變化為：

$$\Delta C = C_0 - \frac{C_0 C_f}{C_0 + C_f} \approx \frac{C_0^2}{C_0 + C_f} - C_0 < 0$$

控制器以高頻掃描整個電極網格，量出每個交叉點的電容變化，構成二維電容影像——「多點觸控」就是同時追蹤影像中多個指尖的座標 $(x_k, y_k), k = 1, 2, \ldots$。電阻式觸控屏只能單點，這正是 iPhone 選擇電容式的關鍵。

### 理論二：雙指縮放——指尖距離的微分幾何

多點觸控最經典的手勢 pinch-to-zoom：兩指座標 $P_1, P_2$，縮放比例由指尖距離的變化決定：

$$s = \frac{\|P_1(t) - P_2(t)\|}{\|P_1(t_0) - P_2(t_0)\|}$$

配合慣性捲動（inertial scrolling，以速度 $v$ 與摩擦衰減 $\tau$ 模擬物理動量 $v(t) = v_0 e^{-t/\tau}$），觸控介面第一次有了「物理感」——使用者摸到的不是選單，是可以推、捏、甩的物件。

### 理論三：感測器整合——加速度計與近距感測

iPhone 內建三軸微機電（MEMS）加速度計，量測比力（specific force）：

$$\mathbf{a}_{meas} = \mathbf{a} - \mathbf{g}$$

由此偵測螢幕旋轉方向與搖晃手勢；近距感測器（紅外線）在通話時貼臉自動關閉螢幕。加上 GPS（以偽距方程解 $x, y, z, \Delta t$）與 Wi-Fi/藍牙，iPhone 是史上第一台把「通訊 + 定位 + 運動感測」完整整合的消費機器——這個組合後來成為所有智慧型手機的標準解剖圖。

```python
import math
# 驗證：pinch-to-zoom 縮放比例與慣性捲動
P1a, P2a = (100, 300), (250, 450)   # 兩指初始位置
P1b, P2b = (80, 280), (320, 520)    # 張開後
s = math.dist(P1b, P2b) / math.dist(P1a, P2a)
print(f"縮放比例 s = {s:.2f}")

# 慣性捲動：速度指數衰減
v0, tau = 2000, 0.3   # px/s, 秒
for t in [0, 0.3, 0.6, 1.0]:
    print(f"t={t}s: 速度 {v0*math.exp(-t/tau):.0f} px/s")
```

## 破案時刻

2007年1月的發表會上，賈伯斯親自示範滑動解鎖、雙指縮放照片——觀眾第一次看到「手指直接操縱數位物件」。2008年7月蘋果推出 App Store，第三方開發者得以在這台機器上發布軟體，第一年即有逾 10 億次下載——「口袋超級機器」有了自己的生態系。破案的關鍵：硬體（多點觸控 + 感測器）與生態（App Store + 開發者）兩次破案，缺一不可。

## 後果 -- 改造了什麼

- 智慧型手機在 15 年內成為人類史上普及最快的機器：全球逾 60 億支，手機上網取代桌面電腦成為主要入口。
- App Store 生態催生整個 App 經濟：共乘（Uber）、導航、行動支付、短影音——數十個兆元級產業建立在這台機器之上。
- 觸控介面反過來定義了所有後續機器：平板、汽車中控、POS 機、智慧手錶，全部採用多點觸控範式。
- 感測器整合成為行動機器的標配：GPS、加速度計、陀螺儀、氣壓計、光感測——今天的手機本質上是「一組感測器 + 一台電腦 + 一個通訊模組」的封裝，這正是 2007 年 iPhone 定下的解剖圖。
