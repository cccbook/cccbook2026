# 1981-太空梭

## 案件摘要

1981年4月12日，哥倫比亞號（Columbia, STS-1）從甘迺迪太空中心升空，太空梭（Space Shuttle）正式首航。指揮官約翰·楊（John Young）與駕駛員羅伯特·克里平（Robert Crippen）駕駛這台史上第一艘可重複使用的載具，繞地36圈後像飛機一樣滑翔降落於愛德華茲空軍基地。這台機器承諾「像班機一樣定期往返太空」，最終卻沒有兌現成本承諾——這是一樁「工程成功、商業失算」的經典懸案。

## 前因 -- 為什麼會有這個案子

- 阿波羅計畫（1969年登月）後，農神五號火箭是一次性的：每飛一次丟掉整枚火箭，發射成本高達每公斤上萬美元。
- 1970年代 NASA 預算銳減（從阿波羅高峰的 4% 聯邦預算跌到不足 1%），必須說服國會：可重複使用能大幅降低單次發射成本。
- 軍方（空軍）要求能載大酬載（偵察衛星）、機動滑翔返航，設計因此妥協出巨大的三角形機翼與 60 呎長酬載艙。
- 1976年企業號（Enterprise）完成滑翔降落測試（ALT 計畫），1981年哥倫比亞號成為真正上天的第一架。

## 線索與推理 -- 數學式、程式、理論

### 理論一：升阻比滑翔重返——像飛機一樣回來

太空梭重返大氣層時無動力，靠機翼的升阻比（L/D）控制滑翔軌跡。設升力 $L$、阻力 $D$，升阻比為：

$$\frac{L}{D} = \frac{C_L}{C_D} \approx 1.1 \;(\text{高超音速}) \;\to\; 4.5 \;(\text{次音速})$$

高超音速階段 L/D 僅約 1（太空梭為了隔熱與酬載妥協的三角翼），軌跡近乎彈道式俯衝；進入次音速後 L/D 升到 4 以上，才能像飛機一樣精確滑向跑道。著陸下滑時無引擎重飛（go-around）能力，進場速度約 350 km/h——一次失誤就沒有第二次機會。

### 理論二：重返加熱——隔熱瓦的物理

重返時動能轉為熱能，機鼻與機翼前緣氣體溫度可達約 1650°C。以馬赫數 $M$ 估算駐點恢復溫度：

$$T_0 \approx T_\infty\left(1 + \frac{\gamma - 1}{2} M^2\right)$$

其中 $\gamma = 1.4$ 是空氣比熱比。鋁製機身只能承受約 175°C，解法是 3 萬多片二氧化矽基陶瓷隔熱瓦（LI-900，密度僅約 0.14 g/cm³、導熱率極低、耐溫 1260°C）：輕到能浮在水上，隔熱到瓦面通紅而瓦背徒手可觸。陶瓷脆性是弱點——每片瓦都是獨立黏貼、每次任務後逐一檢修，這正是後來哥倫比亞號（2003年）災難的伏筆。

### 理論三：重複使用的成本數學——為何沒有如預期

設開發成本 $C_{dev}$、每次發射邊際成本 $C_m$、飛行 $n$ 次，平均單次成本為：

$$\bar{C}(n) = \frac{C_{dev}}{n} + C_m$$

NASA 承諾 $C_m$ 低到每次發射約數百萬美元（目標單次總成本遠低於拋棄式火箭）；實際上每次飛行後要翻修三萬片瓦、三具主引擎與固體助推器，$C_m$ 高達數億美元（每次發射約 4.5 億美元攤提，邊際也有數千萬美元），單位酬載成本約每公斤 1.5–2 萬美元——比農神五號還貴。飛行次數 $n$（135次/30年）遠低於回本所需，公式裡的分母太小的下場。

```python
# 驗證：重返駐點溫度與平均發射成本
g, T = 1.4, 220.0   # 比熱比、高空大氣溫度 K
for M in [25, 1]:
    T0 = T * (1 + (g-1)/2 * M*M)
    print(f"Ma={M}: 駐點恢復溫度 {T0:.0f} K")

# 成本模型：開發攤提 + 邊際成本
C_dev, C_m = 20e9, 150e6   # 開發約200億(2010幣值)、每次翻修1.5億
n = 135
print(f"平均單次成本 {(C_dev/n + C_m)/1e6:.0f} 百萬美元")
print("承諾目標: 單次約數十百萬美元 —— 差了一個數量級")
```

## 破案時刻

1981年 STS-1 首航：起飛、入軌、繞地、全程滑翔降落成功——人類第一次證明「開上太空、開回來」可行，且首飛就是載人（大膽到極端）。隨後 1983年挑戰者號首航與 1984年麥考利夫「太空教師」計畫，太空梭成了太空時代的象徵。但破案的反轉在 1986年挑戰者號爆炸與 2003年哥倫比亞號解體：兩起災難合計14名太空人喪生，熱的問題（O型環與隔熱瓦）先後奪走兩架梭。

## 後果 -- 改造了什麼

- 太空梭 30 年執行 135 次任務：發射哈伯太空望遠鏡（1990）、五次哈伯維修任務、組裝國際太空站（1998–2011）——「帶機器上去修機器」只有太空梭做得到。
- 教訓直接塑造了後繼者：SpaceX 的獵鷹 9 號以「簡單構形 + 引擎回收」重新解成本方程，2020年代單位成本降到每公斤數千美元——把太空梭沒兌現的承諾兌現了。
- 隔熱材料進化：可重複使用的防熱系統（PICA、陶瓷基複材）成為太空船重返的標配技術。
- 美國載人太空飛行在 2011 年太空梭除役後出現九年空窗（依賴俄羅斯聯合號），直到 2020 年 SpaceX 載人龍飛船接手——可重複使用的火炬交給了民營機器。
