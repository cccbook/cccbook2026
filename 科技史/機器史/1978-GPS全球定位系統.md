# 1978-GPS全球定位系統

## 案件摘要

1978年2月22日，美國空軍在加州范登堡基地發射了第一顆 GPS 衛星 Block I（NAVSTAR 1），全球定位系統（Global Positioning System, GPS）從紙上計畫變成天上實物。這台「以太空為基準的測量機器」讓地球上任何一點，只要收到四顆衛星訊號，就能解出經緯度、高度與時間——一個接收器的定位誤差從戰場上的數百公尺，一路演進到今天手機的數公尺。這是一樁歷時二十多年、動員整個美國軍工體系的巨型懸案。

## 前因 -- 為什麼會有這個案子

- 1957年史潑尼克衛星發射後，約翰霍普金斯大學應用物理實驗室（APL）的 Guier 與 Weiffenbach 反向利用都卜勒頻移算出衛星軌道，誕生子午儀（TRANSIT）導航衛星系統——但它定位一次要十幾分鐘，無法供高速載具使用。
- 冷戰軍事需求：潛艦發射飛彈需要精確的自我定位；飛機、飛彈需要全天候、全球、連續的三維定位。
- 1973年，美國國防部整合空軍 NAVSTAR、海軍 Timation 等多項計畫，由布拉德福德·帕金森（Bradford Parkinson）主導確立 GPS 架構：中圓軌道（MEO）、約 20200 公里高度、六個軌道面、碼分多重存取（CDMA）。
- 相對論效應衛星鐘的速度與重力修正，早已由物理學算出——這是少數「理論先於硬體」的工程案例。

## 線索與推理 -- 數學式、程式、理論

### 理論一：偽距測量——四顆衛星解四個未知數

GPS 接收器測量訊號傳播時間，換算距離；但接收器時鐘不夠準，距離因此是「偽距」。設衛星位置為 $(x_i, y_i, z_i)$，未知量是接收器座標 $x, y, z$ 與接收器時鐘偏差 $\Delta t$：

$$\sqrt{(x - x_i)^2 + (y - y_i)^2 + (z - z_i)^2} = c\,\tau_i - c\,\Delta t, \quad i = 1,2,3,4$$

四個未知數、四條方程式，幾何上等價於「以四顆衛星為球心、以偽距為半徑的四球面交點」。三顆衛星只能定一個球面交環，第四顆正是用來消掉 $\Delta t$——這就是「至少要收到四顆衛星」的數學根源。

### 理論二：相對論修正——每天 38 微秒的軌道鐘

GPS 衛星時鐘同時受兩種相對論效應：狹義相對論的時間膨脹（衛星高速，時鐘變慢）與廣義相對論的重力紅移（衛星離地遠，時鐘變快）。設衛星軌道速度 $v \approx 3.87$ km/s、地球質量 $M$、軌道半徑 $r \approx 26560$ km，總頻率偏移率約為：

$$\frac{\Delta f}{f} \approx \frac{v^2}{2c^2} - \frac{GM}{r c^2} \approx -8.3\times10^{-11} + 5.3\times10^{-10} \approx +4.5\times10^{-10}$$

乘上一天的秒數 $86400$，即每天快約 38 微秒。光速下 38 微秒對應約 11 公里——若不修正，定位一天就漂移十公里以上，系統完全不可用。發射前工程師一度懷疑相對論「太抽象」，但物理學的答案被直接寫進衛星鐘的頻率偏置。

### 理論三：CDMA 與幾何精度稀釋因子（GDOP）

所有衛星共用同一頻率，靠 Gold 碼的自相關特性區分訊號。而定位誤差還取決於衛星的幾何分布，由精度稀釋因子（DOP）描述：

$$\sigma_{pos} = \text{GDOP} \times \sigma_{range}$$

衛星在天空分散得越開（GDOP 越小），同樣的測距誤差放大得越少。帕金森的團隊正是用這個準則最佳化了星座配置。

```python
# 驗證：相對論效應使 GPS 衛星鐘每天快約 38 微秒
import math
c, GM = 299792458.0, 3.986004418e14
r, R = 26560e3, 6371e3          # 軌道半徑、地球半徑
v = math.sqrt(GM / r)           # 圓軌道速度
doppler = -(v*v) / (2*c*c)      # 狹義相對論：變慢
gravity = GM / (r*c*c) * (r/(r)) - GM/(r*c*c)*0  # 直接重力紅移
grav = (GM/c**2)*(1/R - 1/r)    # 廣義相對論紅移（對地面比較）
print(f"狹義: {-doppler*86400*1e6:.1f} 微秒/天, 廣義: {grav*86400*1e6:.1f} 微秒/天")
print(f"合計: {(doppler+grav)*86400*1e6:.1f} 微秒/天")
```

## 破案時刻

1978年首批 Block I 衛星升空後，原型系統陸續驗證偽距解算與軌道預報；1983年大韓航空 007 號班機因導航誤差誤入蘇聯領空被擊落，雷根總統宣布 GPS 將開放民用——這起悲劇成為民用化的轉折點。1995年系統達到全面作戰能力（FOC），24 顆工作衛星覆蓋全球。2000年美國關閉選擇可用性（SA）人為誤差干擾，民用精度從約 100 公尺躍升到數公尺，「破案」成果真正落到每個人的口袋裡。

## 後果 -- 改變了什麼

- GPS 成為全球基礎設施：航空、航海、測量、農業、金融交易時間戳（網路 NTP 與電力網同步都依賴 GPS 時間）。
- 手機整合 GPS/GLONASS/Galileo 多星系接收，催生導航 App、共乘、無人機與精密農業整個產業。
- 與本案同源的其他衛星導航系統相繼出現：俄羅斯 GLONASS、歐盟 Galileo、中國北斗（2020年完成全球組網）。
- 反面教訓：系統早期軍民共用但民用訊號一度被降級（SA），說明「機器歸誰所有」與機器本身一樣重要——最後開放共享，才讓 GPS 的價值徹底釋放。
