# 1970s-GPS 相對論修正

## 案件摘要
GPS 衛星以 $\approx 3.87\,\text{km/s}$ 繞行於 20,200 km 高空，其時鐘因狹義相對論變慢、廣義相對論變快，淨效應每天快約 $+38.5\,\mu s$。若不修正，定位誤差每天累積約 10 km——這樁「時間的陰謀」在衛星發射前就被工程師識破並破解。

## 前因 -- 為什麼會有這個案子
- 1970 年代美國國防部開始部署 NAVSTAR GPS：至少 24 顆衛星、軌道半長軸 $a \approx 26{,}560\,\text{km}$，每顆衛星搭載銫/銣原子鐘（穩定度達 $10^{-13}$ 量級）。
- GPS 定位原理是「測距」：接收機比較衛星訊號的發射時刻與本地接收時刻，距離 $r = c\,\Delta t$。1 微秒的時鐘誤差就是 300 公尺的測距誤差。
- 1905 年愛因斯坦的狹義相對論與 1915 年的廣義相對論在當時仍是「純理論」，但 GPS 工程師（如 Daniel Kleppner、Neil Ashby）指出：衛星鐘與地面鐘處於不同速度與不同重力位，兩大理論的效應都遠超過導航容忍度。這是相對論第一次被迫從黑板上走進工程藍圖。

## 線索與推理 -- 數學式、程式、理論

### 線索一：狹義相對論——運動的鐘變慢
由狹義相對論的時間膨脹，在低速近似下，衛星鐘相對地面（地心慣性系）每秒損失

$$
\frac{\Delta t_{\text{SR}}}{t} \approx -\frac{v^2}{2c^2}
$$

GPS 衛星軌道速度（由 $v=\sqrt{GM/r}$，$r \approx 26{,}560\,\text{km}$）：

$$
v \approx \sqrt{\frac{3.986\times 10^{14}}{2.656\times 10^{7}}} \approx 3.87\,\text{km/s}
$$

代入得每天偏差：$-7.2\,\mu s/\text{天}$。

### 線索二：廣義相對論——高處的鐘變快
重力位中鐘速為 $d\tau = dt\sqrt{1+2\Phi/c^2}$，衛星（弱場）與地面的重力位差造成

$$
\frac{\Delta t_{\text{GR}}}{t} \approx \frac{\Delta\Phi}{c^2}
= \frac{GM}{c^2}\left(\frac{1}{R_\oplus}-\frac{1}{r}\right)
$$

代入 $R_\oplus = 6{,}378\,\text{km}$、$r = 26{,}560\,\text{km}$，得 $+45.7\,\mu s/\text{天}$——高處的重力位較高（$\Phi$ 較不负），鐘走得較快。

### 線索三：淨效應與「10 km/天」災難
$$
\Delta t_{\text{net}} = (-7.2 + 45.7)\,\mu s/\text{天} = +38.5\,\mu s/\text{天}
$$

換算為距離誤差：$c \times 38.5\,\mu s \approx 11.5\,\text{km}/\text{天}$，且隨時間線性累積，幾分鐘內就會讓系統失效。

### 破解手法：出廠前調整時鐘頻率
工程師在地面就把衛星鐘的標稱頻率 $10.23\,\text{MHz}$ 預先調低相對比例 $-4.4647\times 10^{-10}$：

$$
f_{\text{衛星}} = 10.23\,\text{MHz} \times \left(1 - 4.4647\times 10^{-10}\right) = 10.22999999543\,\text{MHz}
$$

進入軌道後，相對論效應恰好把頻率「拉回」$10.23\,\text{MHz}$，與地面系統同步。剩餘的小誤差由地面站每天上傳修正參數處理。

### 線索四：Sagnac 效應與 Shapiro 延遲
- **Sagnac 效應**：地球自轉使訊號傳播期間接收機移動，造成路徑積分項 $\Delta t_{\text{Sagnac}} = -\frac{\boldsymbol{\omega}_\oplus \cdot (\mathbf{r}_s \times \mathbf{R}_u)}{c^2}$，最大可達 $\pm 133\,\text{ns}$（相當於 $\pm 40\,\text{m}$），接收機必須修正。
- **Shapiro 延遲**：訊號經過太陽附近的重力位時路徑彎曲造成額外延遲 $\Delta t \approx \frac{2GM_\odot}{c^3}\ln\frac{r_1 r_2}{r_{12}^2}$，低仰角時可達數十奈秒，精密定位（公分級）需納入模型。

### Python numpy 數值驗證

```python
import numpy as np

# 物理常數 (SI)
GM   = 3.986004418e14   # 地心重力常數 GM (m^3/s^2)
c    = 299792458.0      # 光速 (m/s)
Re   = 6378137.0        # 地球赤道半徑 (m)
day  = 86400.0          # 一天 (s)

# GPS 衛星軌道參數
a    = 26560e3          # 半長軸 (m)
h    = a - Re           # 高度 ~ 20,200 km
v    = np.sqrt(GM / a)  # 圓軌道速度
print(f"衛星高度      = {h/1000:,.0f} km")
print(f"衛星軌道速度  = {v/1000:.4f} km/s")   # ~3.874 km/s

# 線索一：狹義相對論 (運動鐘變慢)
dSR = -v**2 / (2*c**2) * day
print(f"狹義相對論效應 = {dSR*1e6:+.2f} 微秒/天")  # ~ -7.2

# 線索二：廣義相對論 (重力位差, 鐘變快)
dPhi = GM * (1/Re - 1/a)
dGR  = dPhi / c**2 * day
print(f"廣義相對論效應 = {dGR*1e6:+.2f} 微秒/天")  # ~ +45.7

# 線索三：淨效應與定位誤差累積
dnet = dSR + dGR
print(f"淨效應         = {dnet*1e6:+.2f} 微秒/天")  # ~ +38.5
print(f"若不修正之距離誤差 = {c*dnet/1000:.1f} km/天")  # ~ 11.5 (約 10 km 量級)

# 破解：出廠前頻率偏移
f0   = 10.23e6
offset = -(dSR + dGR) / day          # 預先調降的相對頻移
f_sat = f0 * (1 + offset)
print(f"相對頻移 = {offset:.4e}")
print(f"衛星鐘出廠頻率 = {f_sat:.11f} MHz")  # 10.22999999543

# 線索四：Sagnac 效應量級估計
omega = 7.292115e-5                  # 地球自轉角速度 (rad/s)
r_s = np.array([a, 0, 0])            # 衛星位置 (示意)
R_u = np.array([Re, 0, Re])          # 接收機位置 (示意)
t_sag = -np.dot(omega*np.array([0,0,1.0]), np.cross(r_s, R_u)) / c**2
print(f"Sagnac 修正量級 = {t_sag*1e9:.1f} ns (最大 ±133 ns)")
```

執行結果驗證：速度 $\approx 3.874\,\text{km/s}$、$-7.2\,\mu s$、$+45.7\,\mu s$、淨 $+38.5\,\mu s$、距離誤差 $\approx 11.5\,\text{km}/\text{天}$、出廠頻率 $10.22999999543\,\text{MHz}$——與 1970 年代工程師的計算完全一致。

## 結案 -- 後果與影響
- **結案陳詞**：相對論不是哲學幻想，而是每天都需要「繳稅」的物理事實。GPS 是史上第一個把狹義與廣義相對論同時納入設計規格的大規模工程系統。
- 1978 年首顆 GPS 衛星發射起，所有衛星鐘都以 $10.22999999543\,\text{MHz}$ 出廠；實測確認廣義相對論預測在 $10^{-4}$ 精度內正確。
- 若省略修正，系統在數小時內即喪失公尺級精度——本案證明「忽視相對論」的代價是每天 10 km 的定位漂移。
- 深遠影響：催生了「相對論大地測量學」（Ashby 的標架理論）、GVG/GPS 時間傳遞成為國際時間標準比對手段，也讓相對論成為資訊工程與電機課程中的實用數學。

## 關鍵人物與文獻
- **Albert Einstein**（1905, 1915）：狹義與廣義相對論的理論源頭。
- **Daniel Kleppner**：1970 年代早期公開警告「原子鐘與相對論對 GPS 至關重要」的物理學家。
- **Neil Ashby**：《Relativity in the Global Positioning System》(Living Reviews in Relativity, 2003)，GPS 相對論修正的權威文獻。
- **Roger Easton / Ivan Getting / Bradford Parkinson**：GPS 系統的總體設計者，將相對論修正寫入系統規格。
- **Alfred Sagnac**（1913）與 **Irwin Shapiro**（1964）：兩個後續被發現必須納入的效應之命名來源。
