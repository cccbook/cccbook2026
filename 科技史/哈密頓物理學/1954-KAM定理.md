# 1954 - KAM 定理——近可積系統的救命繩

## 案件摘要
1954 年，Kolmogorov 在阿姆斯特丹國際數學家大會上宣布（未附完整證明）：
**近可積哈密頓系統中，多數不變環面不會被微擾摧毀。**
$$\text{可積} + \epsilon\,\text{微擾} \;\Longrightarrow\; \text{多數環面存活（僅共振環面破碎）}$$
Arnold（1963，解析情形）與 Moser（1962，有限光滑情形）各自完成證明，合稱 **KAM 定理**。
這是 Poincaré 不可積性發現（見 [1890-Poincare三體問題.md](1890-Poincare三體問題.md)）之後的轉折：
太陽系為何能穩定億萬年？答案不是「完全可積」，而是「**多數**可積」——混沌與秩序並存。

## 前因
- **Poincaré 的不可積性（1890）**：小分母問題 $A/(m\omega_1 + n\omega_2)$ 使攝動級數發散，可積世界破碎。
- **太陽系穩定性的百年懸案**：Laplace–Lagrange 時代的角度級數是否收斂？觀測說太陽系穩定，理論說級數發散——矛盾。
- **小分母的結構**：微擾展開的每項都有「頻率組合」做分母；共振（$m\omega_1 + n\omega_2 = 0$）時爆炸。
- **Kolmogorov 的直覺**：與其硬解，不如證明**多數**環面在微擾下形變但存活——用數論（丟番圖頻率）控制小分母。

## 線索與推理

### 第一步：丟番圖頻率條件
Kolmogorov 的關鍵觀察：共振環面（$m\omega_1 + n\omega_2 \approx 0$）是**測度為零**的集合；
若頻率向量滿足丟番圖條件
$$|k \cdot \omega| \ge \frac{\gamma}{|k|^{\tau}}, \qquad \forall k \in \mathbb{Z}^n \setminus \{0\}$$
（$\tau > n - 1$，$\gamma$ 充分大），則小分母雖小，但**不會小到破壞收斂**。
幾乎所有的頻率向量（Lebesgue 測度意義）都滿足此條件——「多數」的數學化。

### 第二步：牛頓法式的超收斂構造
KAM 證明的核心手法：把可積系統 $H_0(I) + \epsilon H_1(I, \theta)$ 逐步正則變換消去微擾。
每一步用**牛頓法**（二次收斂）：
$$\epsilon^{(n+1)} \sim C\left(\epsilon^{(n)}\right)^2$$
於是誤差序列 $C\epsilon,\ C(C\epsilon)^2,\dots$ 收斂——只要 $\epsilon < \epsilon_0(\gamma)$ 夠小。
**牛頓法 + 丟番圖條件 = 小分母問題的馴服。**

### 第三步：結構的圖像
微擾後的相空間（二自由度、Poincaré 截面）：
| 區域 | 結構 |
|---|---|
| 多數環面（丟番圖頻率）| 存活、形變，軌跡仍約束在環面上 |
| 共振環面附近 | 破碎，產生共振島鏈與混沌層 |
| 混沌層 | 同宿纏結（Poincaré 的指紋重現）|

**秩序（KAM 環面）與混沌（纏結層）並存**，且環面成為混沌的「籠子」——軌跡被 KAM 環面隔開，混沌被限制在層內。

### 驗證 1：太陽系的穩定性
行星頻率若滿足丟番圖條件，則太陽系在 $\epsilon$（行星質量比 $\sim 10^{-3}$）下多數軌道穩定——
懸了百年的理論矛盾被解開。數值驗證：長期模擬（見 [1988-幾何數值積分.md](1988-幾何數值積分.md)）顯示內行星軌道數億年穩定。

### 驗證 2：標準映射的數值檢驗
```python
import numpy as np

K = 0.8  # 微擾強度（K < K_c≈0.97 時多數 KAM 環面存活）
theta, I = 0.3, 0.7
traj = [(theta, I)]
for _ in range(2000):
    I_new = (I + K*np.sin(theta)) % (2*np.pi)
    theta = (theta + I_new) % (2*np.pi)
    I = I_new
    traj.append((theta, I))
# K 小時 I 幾乎不變（環面存活）；K 大時 I 隨機遊走（混沌）
print(np.std([t[1] for t in traj]))   # K=0.8: I 的變化仍受限
```

## 結案
- 「完全可積 vs 完全混沌」的二元對立被打破：**KAM 定理給出了混沌與秩序共存的精確數學**。
- 連鎖反應：FPUT 實驗（1955）的「能量不均分」很快被理解為 KAM 環面的效應（見 [1955-FPUT實驗.md](1955-FPUT實驗.md)）；
- 太陽系長期演化、托卡馬克磁約束、加速器設計——凡「近可積」的工程系統，都靠 KAM 定理背書。
- 遺留問題：混沌層隨 $\epsilon$ 增大而擴張，最終吞噬所有環面——臨界值 $K_c$ 的普遍性（Chirikov 擴散、Greene 殘留）成為後續研究主題。
