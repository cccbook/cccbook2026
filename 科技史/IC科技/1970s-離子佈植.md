# 1970s - 離子佈植：把摻雜從高溫爐搬進加速器

## 案件摘要
1970 年代初，熱擴散摻雜的三大罩門——高溫製程、橫向擴散失控、劑量無法精確控制——讓次微米時代止步。
1960 年代實驗室已驗證離子佈植：把雜質離子加速到 keV–MeV 打進晶圓，深度與劑量全由電壓與電流決定。
1973 年商業化離子佈植機問世，平面製程從此有了精準的摻雜筆——今日每顆晶片都必須過離子佈植機。

## 前因 -- 為什麼會有這個案子
- **熱擴散的罩門**：擴散需 $950\text{–}1200^\circ\mathrm{C}$ 高溔數小時，擴散係數 $D = D_0 e^{-E_a/kT}$ 對溫度呈指數敏感，爐溫差幾度，接面深度就差一大截。
- **橫向擴散失控**：雜質從窗口往下也往旁邊跑，橫向擴散約為縱向的 $0.7\text{–}0.8$ 倍，窗越縮、側向互吃越嚴重——次微米電晶體的 channel 被擴散吃掉。
- **劑量測不到**：擴散的劑量由氣體流量×時間間接決定，誤差動輒 $\pm 10\%$，$V_T$ 這種對劑量敏感的參數根本調不準。
- **關鍵推理**：若把摻雜從「熱運動的隨機漫遊」改成「加速器彈道」，則深度由能量 $E$ 決定、劑量由電流×時間決定、且全程低溫：

$$
\underbrace{D, t}_{\text{擴散：間接且高溫}} \quad\Longrightarrow\quad \underbrace{E \to R_p,\ \ I \to Q}_{\text{佈植：直接且精準}}
$$

1960 年代 Bell Labs 與英國 Harwell 的實驗機驗證概念；1973 年商業化離子佈植機上市，CMOS 摻雜自此改寫。

## 線索與推理 -- 數學式、程式、理論

### 線索一：機器解剖——離子源到晶圓的五站

$$\text{離子源} \xrightarrow{\text{游離}} \text{離子} \xrightarrow{\text{加速器 (keV–MeV)}} \text{質量分析磁鐵} \xrightarrow{\text{選質荷比}} \text{掃描} \xrightarrow{\text{靜電/機械}} \text{晶圓}$$

1. **離子源**：氣體（BF₃、PH₃、AsH₃）經游離產生雜質離子。
2. **加速器**：抽取電壓把離子加到設定能量 $E$（淺佈植 keV 級、well 佈植可達 MeV）。
3. **質量分析磁鐵**：磁場中離子走半徑 $r = \sqrt{2mE}/(qB)$ 的圓弧，只讓目標離子通過——防「分子離子」混入（如 BF₂⁺ 冒充 B⁺）。
4. **掃描**：靜電偏折或機械旋轉晶圓，讓束流均勻灑滿整片晶圓。
5. **法拉第杯**：晶圓本身接成法拉第杯，直接積分束流電流——劑量就是電流×時間。

### 線索二：Gaussian 摻雜分布與 junction depth

離子在固體中經多次核碰撞減速，停下的位置統計上近似高斯（投影射程 $R_p$、縱向偏差 $\Delta R_p$）：

$$
C(x) = \frac{Q}{\sqrt{2\pi}\,\Delta R_p}\, \exp\!\left[-\frac{(x - R_p)^2}{2\Delta R_p^2}\right]
$$

其中劑量 $Q = \int C\,dx$（ions/cm²）。pn 接面出現在濃度降到基板濃度之處：

$$
C(x_j) = C_{sub} \quad\Longrightarrow\quad x_j = R_p + \Delta R_p \sqrt{2 \ln\!\frac{Q}{\sqrt{2\pi}\,\Delta R_p\, C_{sub}}}
$$

$R_p$ 與 $\Delta R_p$ 都隨能量單調上升（可由 LSS 理論或 SRIM 模擬求得）——**能量就是深度旋鈕，劑量就是濃度旋鈕**，兩個旋鈕互相獨立，這是熱擴散做了一輩子也做不到的事。

### 線索三：劑量 = 電流 × 時間

法拉第杯直接積分束流：

$$
Q = \frac{It}{qA}
$$

其中 $I$ 為束流電流、$t$ 為時間、$q$ 為離子電荷、$A$ 為掃描面積。電流量測可達 $0.1\%$ 精度——劑量誤差從熱擴散的 $\pm 10\%$ 殺到 $\pm 1\%$ 以內，$V_T$ 調變才成為可能。

### 線索四：通道效應與退火

- **通道效應（channeling）**：離子若沿晶軸「走隧道」，深度可暴增數倍。對策：晶圓傾斜 $7^\circ$、表面預非晶化（Si 預佈植）。
- **晶格損傷**：離子打入會撞壞晶格，摻質被困住不導電。
- **退火（annealing）**：$900\text{–}1000^\circ\mathrm{C}$ 短暫回火，修復晶格並**活化**摻質。退火後活化率：

$$
\eta = \frac{N_{\text{active}}}{Q} \to 1 \quad (\text{足夠高溫退火後})
$$

RTA（快速退火）之後登場：毫秒級高溔、把擴散副作用壓到最低——佈植定深度、退火定活性。

### 線索五：$V_T$ 調變與 CMOS 三大佈植

閘氧化層下方薄佈植一層雜質，等效改變 $V_T$：

$$
\Delta V_T \approx \frac{q\, Q_{imp}}{C_{ox}}
$$

劑量 $Q_{imp}$ 由電流×時間精準控制，$V_T$ 可調到 mV 級。CMOS 標配三道佈植：**$V_T$ adjust 佈植**（門檻電壓）、**源/汲極佈植**（超淺、高劑量接面）、**well 佈植**（MeV 深佈植直接打進井區，省去長時間高溔驅入）。

### 線索六：SRIM 模擬——射程的計算器

LSS 理論把固體中的能量損失拆成兩項：

$$
\frac{dE}{dx} = \underbrace{\left(\frac{dE}{dx}\right)_{\text{核碰撞}}}_{\text{低能量主導，決定 }\Delta R_p} + \underbrace{\left(\frac{dE}{dx}\right)_{\text{電子阻擋}}}_{\text{高能量主導，決定 }R_p}
$$

- **核碰撞**：離子撞原子核、大角度散射，造成晶格損傷——低能量時主導。
- **電子阻擋**：離子把能量丟給電子雲、近乎直線前進——高能量時主導。
- **SRIM**（Ziegler–Biersack–Littmark, 1985）以 Monte Carlo 追蹤數萬顆離子的彈道，輸出 $R_p$、$\Delta R_p$ 與損傷分布——製程工程師在跑機台前，先在電腦上「試射」。

### Python 實作：Gaussian 摻雜分布與 junction depth

```python
import numpy as np

def implant_profile(E, Rp, dRp, Q, Csub, x):
    """離子佈植高斯分布；E 僅供標註，Rp/dRp 由 LSS/SRIM 給定"""
    C = Q / (np.sqrt(2*np.pi) * dRp) * np.exp(-(x - Rp)**2 / (2*dRp**2))
    return C

def junction_depth(Rp, dRp, Q, Csub):
    """C(xj) = Csub 之解：xj = Rp + dRp*sqrt(2*ln(C_peak/Csub))"""
    C_peak = Q / (np.sqrt(2*np.pi) * dRp)
    return Rp + dRp * np.sqrt(2 * np.log(C_peak / Csub))

# 案例：B+ 佈植，E = 60 keV，Rp = 0.2 um，dRp = 0.05 um（以 cm 為單位）
Q, Csub = 3e13, 1e16                 # dose [ions/cm2], 基板 Csub [/cm3]
Rp, dRp = 0.2e-4, 0.05e-4            # cm（1 um = 1e-4 cm）
x = np.linspace(0, 0.6e-4, 300)
C = implant_profile(60, Rp, dRp, Q, Csub, x)
print(f"C_peak = {C.max():.3e} /cm3")   # C_peak ≈ 2.393e18 /cm3
print(f"xj = {junction_depth(Rp, dRp, Q, Csub)/1e-4:.3f} um")          # xj ≈ 0.365 um
# 劑量加倍 → C_peak 加倍、xj 略增；能量加倍 → Rp/dRp 加倍、xj 大增
print(f"2x dose: xj = {junction_depth(Rp, dRp, 2*Q, Csub)/1e-4:.3f} um")              # ≈ 0.376 um
print(f"2x energy: xj = {junction_depth(2*Rp, 0.09e-4, Q, Csub)/1e-4:.3f} um")        # ≈ 0.681 um
```

模擬顯示：**劑量加倍，接面只淺淺外移；能量加倍，接面大幅下移**——深度與濃度是兩個獨立旋鈕，這正是離子佈植取代熱擴散的數學本質。

### 線索七：偵辦對照表——擴散 vs 佈植

| 項目 | 熱擴散 | 離子佈植 |
|------|--------|----------|
| 溫度 | $950\text{–}1200^\circ\mathrm{C}$ | 室溔（退火另計） |
| 深度控制 | $Dt$，間接、指數敏感 | $E \to R_p$，直接 |
| 劑量控制 | 氣體流量，$\pm 10\%$ | 電流×時間，$\pm 1\%$ |
| 橫向擴散 | $0.7\text{–}0.8 \times$ 縱向 | 幾乎無（彈道） |
| 單側掩護 | 需厚 SiO₂ | 薄光阻/SiO₂ 即可 |
| 均勻性 | 爐管內難控 | 掃描系統極佳 |

## 結案 -- 後果與影響
- **精密摻雜取代熱擴散**：劑量誤差從 $\pm 10\%$ 降到 $\pm 1\%$ 以內，深度由能量設定，全程低溔——熱擴散退居少數深接面場合。
- **CMOS 製程必備**：$V_T$ 調變、源/汲極超淺接面（S/D extension）、well 佈植——沒有離子佈植就沒有穩定的 CMOS。
- **LDD 與延伸佈植**：次微米時代為抑制 hot-carrier 與 short-channel 效應，LDD（lightly doped drain）延伸佈植登場，接面深度由 keV 淺佈植精準控制。
- **退火技術線**：爐退火 → RTA → 更先進的 spike/millisecond annealing，一路壓低熱預算。
- **至今每顆晶片都要過離子佈植機**：從 4004 到 3 nm 晶片，摻雜這一站 50 年未變，只有能量範圍與劑量精度持續進化。
