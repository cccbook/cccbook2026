# 1969 - CCD 影像感測器：電荷耦合，數位影像的誕生

## 案件摘要
1969 年，Bell Labs 的 Willard Boyle 與 George Smith 在白板前畫出一個想法：
用 MOS 電容儲存電荷，再以時脈把電荷沿陣列一格格「搬」出來——電荷耦合元件（CCD）就此誕生。
它讓半導體第一次能「看見」：光子轉電荷、電荷轉電壓、電壓轉數位影像。
四十年的數位影像革命——數位相機、手機相機、哈伯望遠鏡——全部從這塊白板出發，兩人於 2009 年獲諾貝爾物理獎。

## 前因 -- 為什麼會有這個案子
- **MOS 技術剛成熟**：1960 年代 MOSFET 與 MOS 電容量產，矽表面可以穩定儲存電荷；Bell Labs 手握 MOS 專利，卻還沒找到殺手級應用。
- **影像儲存的困境**：磁帶、磁泡記憶體都慢而笨重；電話公司需要「影像電話」的儲存與傳輸介質——Boyle 小組的任務正是找一種電子式移位暫存器。
- **真空管攝影管的枷鎖**：vidicon、vidissecter 體積大、易燒、需要掃描線圈；固態影像感測器若要取代它，必須解決「數十萬像素如何逐一讀出」的問題。
- **關鍵推理**：Smith 在白板上畫出一排 MOS 電容——若以三相時脈依序加深勢阱，電荷包會**像桶隊傳水一樣**沿陣列移動；把光電效應加進來，每個電容就是一個像素：
$$
\underbrace{h\nu \to e^-}_{\text{光電轉換}} \;\xrightarrow{\text{MOS 勢阱儲存}}\; \underbrace{\text{電荷包}}_{\propto \text{光強}} \;\xrightarrow{\text{三相時脈搬移}}\; \underbrace{\text{單點讀出}}_{\text{電壓→數位}}
$$

1969 年 10 月原型問世，8 價素的線陣列成功搬移電荷——「電子底片」立案成立。

## 線索與推理 -- 數學式、程式、理論

### 1. MOS 電容：光子的捕獲器

MOS 電容在閘極加正壓時，矽表面形成**勢阱（potential well）**；光子穿透進矽，被吸收後激發電子—電洞對，電子被勢阱捕獲累積：

$$
N_e = \frac{P \cdot t \cdot \eta}{E_{ph}} \;\;(\text{累積電子數}), \qquad
\eta = \text{量子效率 QE} = \frac{\text{產生電子數}}{\text{入射光子數}}
$$

- 每個電容是一個像素；累積電子數正比於曝光量——**這就是電子底片的感光原理**。
- 矽對可見光的 QE 可達 50–90%（背照式），遠優於底片；曝光上限由**滿阱容量（full well capacity）**決定，典型 $10^4\text{–}10^5\ e^-$。
- 暗電流（熱激發）是雜訊來源：降溫可壓制，天文 CCD 常冷卻至 $-100\,^\circ\mathrm{C}$。

### 2. 電荷耦合轉移：桶隊傳水

三相時脈 $\phi_1, \phi_2, \phi_3$ 依序升起、降下，勢阱邊界移動，電荷包被推向下一個電容：

$$
\phi_1 \uparrow \to \text{阱 1 深} \to \phi_2 \uparrow, \phi_1 \downarrow \to \text{電荷推向阱 2} \to \cdots
$$

- 電荷轉移**不是移動電子**，而是移動**勢阱本身**——電子只被馴服地跟著走。
- 每次轉移都有少量電荷殘留（陷阱、不完全轉移），定義**轉移效率 CTE**：

$$
\eta = \text{CTE}, \qquad
\text{n 次轉移後殘餘} = \eta^n, \qquad
\text{訊號損失} = 1 - \eta^n
$$

- 對 $1000 \times 1000$ 面陣列，像素要轉移約 2000 次才到讀出端；$\eta = 0.99999$ 時訊號只剩 $\eta^{2000} \approx 0.982$——**CCD 的成敗全繫於這幾個 9**。

### 3. 動態範圍：滿阱與雜訊的比值

CCD 的動態範圍由滿阱容量與讀出雜訊決定：

$$
\text{DR} = 20\log_{10}\frac{N_{\text{full well}}}{N_{\text{read noise}}}
\;\;\text{(dB)}, \qquad
\text{典型： } \frac{10^5\ e^-}{5\ e^-} \Rightarrow 86\,\text{dB}
$$

- 讀出雜訊（reset noise、kTC noise）以浮動放大器相關雙取樣（CDS）壓制。
- 高 DR 意味著**同時看到亮部與暗部**——天文觀測與專業攝影的生命線。

### 4. 線陣列到面陣列：三種讀出架構

- **線陣列（linear）**：一排電容，適合掃描器、傳真機；一維搬移、一維讀出。
- **幀轉移（frame transfer）**：上半場曝光、下半場遮蔽儲存，曝光完整場快速下移讀出。
- **行間轉移（interline transfer）**：每列感光區旁附一列遮蔽的轉移暫存器，曝光瞬間垂直轉移——**消費型攝影機的標配**，快門延遲極小。

面陣列的代價：像素要搬移數千次才到讀出放大器，CTE 的要求隨陣列變大而指數上升。

### 5. Kodak 1975：第一台 CCD 相機

1975 年，Kodak 工程師 Steven Sasson 用 Fairchild 0.01 MP（100×100 像素）CCD 組裝出世界第一台數位相機：

$$
\underbrace{0.01\,\text{MP CCD}}_{\text{Sasson 1975}} \to \underbrace{23\,\text{秒曝光}}_{\text{錄音帶儲存}} \to \underbrace{\text{電視顯示}}_{\text{0.01 百萬像素}}
$$

- 曝光 23 秒、存進卡帶、再放回電視看——Kodak 高層看著這台烤麵包機大小的原型說「這很可愛，但別告訴任何人」。
- 23 年後，Kodak 自己被這台「可愛的機器」淘汰——**顛覆者的原型常常先出現在受害者的實驗室**。

### 6. Python 實作：CTE 與訊號衰減

```python
import numpy as np

# ---- 轉移效率 CTE：n 次轉移後訊號殘餘 = eta^n ----
def signal_after_transfers(charge, eta, n):
    return charge * eta**n

N_transfers = 2000                          # 1000x1000 面陣列，最遠像素搬移次數
for eta in [0.999, 0.9999, 0.99999, 0.999999]:
    sig = signal_after_transfers(100_000, eta, N_transfers)   # 滿阱 1e5 電子
    loss = 100 - sig/1000
    print(f"CTE = {eta:.6f}: {N_transfers} 次轉移後訊號 = {sig:.0f} e-, 損失 = {loss:.1f}%")
# 預期輸出：
# CTE = 0.999000: 2000 次轉移後訊號 = 13520 e-, 損失 = 86.5%
# CTE = 0.999900: 2000 次轉移後訊號 = 81873 e-, 損失 = 18.1%
# CTE = 0.999990: 2000 次轉移後訊號 = 98020 e-, 損失 = 2.0%
# CTE = 0.999999: 2000 次轉移後訊號 = 99800 e-, 損失 = 0.2%

# ---- 簡化電荷轉移模擬：三相時脈沿陣列搬移電荷包 ----
L = 8                                        # 8 像素線陣列（Bell Labs 1969 原型）
wells = np.zeros(L, dtype=float)
wells[0] = 1000.0                            # 光子在像素 0 注入 1000 e-
eta = 0.9999                                 # 每次轉移效率

for clock in range(L - 1):                   # 依序把電荷推向下一格
    moved = wells[clock] * eta               # 轉移過去的電荷
    wells[clock + 1] += moved                # 下一格接收
    wells[clock] -= moved                    # 原格殘餘 1 - eta

print(f"讀出端電荷 = {wells[-1]:.1f} e-（注入 1000 e-, 7 次轉移）")
# 預期輸出：讀出端電荷 = 999.3 e-（注入 1000 e-, 7 次轉移）

# 核心結論：CTE 少一個 9，百萬像素陣列的影像就糊掉——CCD 的成敗全在製程純度
```

CTE $\eta^n$ 的指數律得到數值驗證：$\eta$ 從 0.999 進步到 0.999999，2000 次轉移的損失從 86.5% 壓到 0.2%——**CCD 的二十年是追九的二十年**。

## 結案 -- 後果與影響
- **數位影像革命**：從 0.01 MP 到數億像素，數位相機淘汰底片，Kodak 由霸主轉為破產——顛覆的完整劇本。
- **天文觀測改寫**：哈伯望遠鏡的 WFPC、各種巡天計畫全靠冷卻 CCD；量子效率與動態範圍遠勝底片，暗弱天體現形。
- **諾貝爾物理獎 2009**：Boyle 與 Smith 因「電荷耦合半導體電路」獲獎——白板上的草圖，四十年後拿到物理學最高榮譽。
- **CCD → CIS 演進**：1990 年代 Eric Fossum 在 JPL 發明 CMOS image sensor（主動像素 + 片上積體電路）；CIS 以低功耗、低成本、單晶片整合主導手機，CCD 退居科學與專業攝影。
- **半導體跨足光電的起點**：CCD 證明半導體不只做邏輯與記憶，還能**感測物理世界**——影像、距離、光譜，感測器自此成為 IC 的第三大支柱。
