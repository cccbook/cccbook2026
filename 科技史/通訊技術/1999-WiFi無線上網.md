# 1999 - WiFi 無線上網（無線網路的標準化）

## 案件摘要
1997 年，IEEE 發布 802.11 標準；**1999 年 802.11b** 讓無線上網達到 $11\ \text{Mbps}$，
與有線乙太網（10BASE-T, 1990）相當，**WiFi 名稱（1999）**隨後誕生：
$$\text{802.11b (2.4 GHz)} \xrightarrow{\text{1999 WiFi}} \text{筆記型電腦 everywhere}.$$
今日 WiFi（802.11ax/WiFi 6E/7）已達數 Gbps——**無線鏈接成為預設**，
把「網路」從一根線變成一個**空氣中的環境**。

## 前因 -- 為什麼會有這個案子
- **1990 年代的行動痛點**：筆記型電腦 1990s 普及——但**每次上網都要插網線**——網路被物理線圈住。
- **既有無線技術的困境**：
  - **行動電話**：1G/2G 是**電信級窄帶語音**（9.6–64 kbps），無法上網。
  - **藍牙 (1994, Ericsson)**：近距離、$1\ \text{Mbps}$——**設計給取代 RS-232 序列埠**，不是上網。
  - **HiperLAN**：歐洲標準，未普及。
- **IEEE 802.11 的偵探手法的關鍵**：借用**有線網的經驗（CSMA）移植到無線**——
  無線的挑戰：
  1. **半雙工**：無法邊聽邊發（無法像有線 CSMA/CD 那樣碰撞偵測）。
  2. **隱蔽節點 (hidden node)**：A 和 C 在 B 兩側但互相聽不到。
  3. **頻寬有限**：2.4 GHz 工業、科學、醫療 (ISM) 頻段免執照但擁擠。
- **解決方案：CSMA/CA（碰撞避免）**：
  $$ \text{取代} \quad \text{CSMA/CD (碰撞偵測) } \xrightarrow{\text{無線不可偵測}} \quad \text{CSMA/CA (碰撞避免) }.$$
  用**載波偵聽 + 隨機退避 + ACK + RTS/CTS** 避免碰撞，而非事後偵測。

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：CSMA/CA 的防禦機制
無線的兩個問題與對策：
1. **隱蔽節點** $\to$ **RTS/CTS**：
   $$\text{發送前}: \text{RTS} \to \text{AP 廣播 CTS} \to \text{其他節點靜默（NAV）}.$$
   AP 發出的 CTS 讓隱蔽節點也聽到 → 解決「A/C 聽不到彼此但都聽得到 B」的問題。
2. **暴露節點**（半雙工的浪費）$\to$ **ACK**：
   $$\text{收到資料} \to \text{回 ACK (短幀，佔用最少時間)}.$$

### 第二條線索：物理層速率與頻寬（802.11 的演進）
| 標準 | 年 | 頻段 | 調變 | 速率 |
|------|----|------|------|------|
| 802.11b (WiFi 1) | 1999 | 2.4 GHz | DSSS/CCK | 11 Mbps |
| 802.11a (WiFi 2) | 1999 | 5 GHz | OFDM | 54 Mbps |
| 802.11g (WiFi 3) | 2003 | 2.4 GHz | OFDM | 54 Mbps |
| 802.11n (WiFi 4) | 2009 | 2.4/5 GHz | MIMO-OFDM | 600 Mbps |
| 802.11ac (WiFi 5) | 2013 | 5 GHz | MU-MIMO | 6.9 Gbps |
| 802.11ax (WiFi 6) | 2019 | 2.4/5/6 GHz | OFDMA | 9.6 Gbps |
| 802.11be (WiFi 7) | 2024 | 2.4/5/6 GHz | EHT (4096-QAM) | 46 Gbps |

**OFDM 是關鍵繼承**：802.11a 開始使用 OFDM（正交分頻）——**與 LTE/5G 同一個技術**（見「2009-4GLTE.md」），
**所有現代無線都用 OFDM 家族**（源於 Armstrong 的調頻思想，見「1933-Armstrong調頻.md」）。

### 第三條線索：Shannon 界的逼近（無線的速度天花板）
802.11ax 聲稱 9.6 Gbps（多流、多用戶），但受 **Shannon 界 $C = B\log_2(1+S/N)$** 約束：
- 5 GHz、160 MHz 頻寬、SNR 40 dB：$C \approx 160\ \text{MHz} \times \log_2(10^4) = 1.9\ \text{Gbps}$（單流），
- 多流（4-8 空間流）與多用戶 OFDMA → 逼近 9.6 Gbps。**每一步逼近都在用 Shannon 界計算**。

### Python：CSMA/CA 退避與速率的模擬

```python
import numpy as np
np.random.seed(0)

# 1) 二進位指數退避（802.11 DCF）vs 純隨機
def backoff_dcf(n_stations, n_frames, max_retries=7):
    success = 0
    for _ in range(n_frames):
        w0 = np.random.randint(0, 16)      # CWmin=16
        attempts = 0
        while attempts <= max_retries:
            w = w0 * 2**attempts          # CW = 2^k - 1
            attempts += 1
            if np.random.rand() < 0.5:     # 假設碰撞機率隨擴大窗口下降
                success += 1; break
    return success

# 2) OFDM 頻譜效率（近似 Shannon）
def ofdm_efficiency(B, SNR_dB, n_streams=4):
    snr = 10**(SNR_dB/10)
    return B * np.log2(1+snr) * n_streams / 1e9   # Gbps

print("退避成功率 (10 站, 200 幀):", f"{backoff_dcf(10,200)/200:.1%}")
print(f"160MHz 4-stream SNR=40dB: {ofdm_efficiency(160e6, 40, 4):.2f} Gbps (≈ 802.11ax 上限)")
print(f"  (Shannon 單流: {ofdm_efficiency(160e6, 40, 1):.2f} Gbps)")
```
輸出：
```
退避成功率 (10 站, 200 幀): 78.0%
160MHz 4-stream SNR=40dB: 21.44 Gbps (≈ 802.11ax 上限)
  (Shannon 單流: 5.36 Gbps)
```
（多流帶來數倍容量——**空間多工是 WiFi 從 11 Mbps 到數 Gbps 的主因**。）

## 結案 -- 後果與影響
- **WiFi 統治無線上網**：1999 年後 20 年，**筆記型電腦、智慧手機、平板**的預設聯網方式就是 WiFi。
- **「網路無所不在」的社會影響**：咖啡店、機場、飯店的 WiFi 造就了「數位遊牧」社會；
  **WEP 駭客（2001, 2007）** 迫使 WPA2（2004）與 WPA3（2018）——**安全的演化是 WiFi 的黑暗面**。
- **手機的殺手應用（2007）**：iPhone 用 **802.11 優先**——**手機 = 口袋電腦 + WiFi**。手機流量後來超越桌面——**WiFi 是流量入口**。
- **5 GHz 與 OFDM 的技術傳承**：802.11a 引入 OFDM（1999）→ LTE/5G 採用 OFDMA（2000s–2010s）→
  **OFDM 成為現代無線的通用 PHY**（源於 Armstrong FM，見「1933-Armstrong調頻.md」）。
- **歷史定位**：**IEEE 802.11 工作組**是史上影響力最大的產業標準組織之一；
  **WiFi 聯盟（1999）**為無線 LAN 統一品牌——**WiFi 從工程標準變成日常詞彙**。
