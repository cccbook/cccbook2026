# 1987 - Gromov 雙曲群（把群論變成幾何）

## 案件摘要
1987 年，**Mikhail Gromov（1943–）** 發表《雙曲群中的雙曲流形》
（*Hyperbolic groups*），開創了**幾何群論（geometric group theory）**：
$$\boxed{\text{把「群」看成「空間」，用幾何工具研究代數}}$$
**雙曲群（hyperbolic group）**的定義：群在它的 Cayley 圖上表現得像**雙曲空間**——
三角形「細」：
$$\boxed{\delta\text{-細三角形：每個三角形的三邊都在彼此的 } \delta \text{ 鄰域內}}$$
$$\text{群論（代數）} \xrightarrow{\text{Gromov 1987}} \text{幾何（距離、曲率、面積）}.$$
**這是 Klein（1872）「幾何 = 群」的倒轉**——Gromov 說「**群 = 幾何**」。

## 前因 -- 為什麼會有這個案子
- **Klein 的 Erlangen 綱領（1872）**：
  Klein 用**變換群**分類幾何（見「1872-克萊因艾爾朗根計畫.md」）：
  $$\text{幾何} = \text{空間} + \text{群}.$$
  **Gromov 的倒轉（1987）**：
  $$\text{群} = \text{Cayley 圖（空間）} + \text{字度量規}.$$
- **Cayley 圖（1878）**：
  **Arthur Cayley** 發明：對群 $G$ 與生成元集合 $S$，畫一個圖——
  - 頂點 = 群的元素；
  - 邊 = 生成元的乘法（$g \to gs$）。
  $$\text{群的「形狀」= Cayley 圖}$$
  - $\mathbb{Z}$（整數）的 Cayley 圖 = 一條直線；
  - $\mathbb{Z}^2$ 的 Cayley 圖 = 方格網；
  - 自由群 $F_2$ 的 Cayley 圖 = **四叉樹**（樹是「極端雙曲」的）！
- **Mostow 剛性（1968）**：
  Mostow 證明雙曲流形的剛性（見「1982-瑟斯頓幾何化猜想.md」）——
  這啟發 Gromov 問：
  > 「『雙曲性』的抽象本質是什麼？能否不依賴流形，直接對群定義？」
- **Dehn 的字問題（1911）**：
  **Max Dehn** 提出群的**字問題（word problem）**：
  $$\text{給定群中的兩個字，判斷它們是否代表同一個元素}.$$
  - **1911 Dehn**：雙曲曲面群（表面群）的字問題可解（用「面積」）；
  - **1955 Novikov、1959 Boone**：存在字問題不可判定的群；
  - **Gromov（1987）**：**雙曲群的字問題是線性時間可解**（Dehn 演算法）！

## 線索與推理 -- 數學式、程式、理論

### 第一條線索：字度量規（word metric）
**字度量規**：群元素之間的「距離」= 最短的生成元表示的長度：
$$d_S(g, h) = \min\{n: g^{-1}h = s_1 s_2\cdots s_n,\ s_i \in S\}.$$
- **例子**（$\mathbb{Z}$，$S = \{1\}$）：
  $$d(0, 5) = 5 \quad\text{（需要 5 步）}.$$
- **例子**（自由群 $F_2 = \langle a, b\rangle$）：
  $$d(e, aba^{-1}b) = 4, \qquad d(e, aba^{-1}) = 1 \text{？不——} aba^{-1} \text{ 不能化簡，長度 3}.$$

### 第二條線索：δ-細三角形（雙曲性的抽象定義）
**定義（Gromov, 1987）**：群 $G$ 是 **δ-雙曲**的，若其 Cayley 圖中的每個**測地三角形**：
$$\text{任意一邊} \subset \delta\text{-鄰域（其餘兩邊的聯集）}.$$
$$\boxed{\text{三角形很「細」（thin）= 雙曲性}}$$
- **樹**（自由群的 Cayley 圖）：$\delta = 0$（**最細**——三角形根本不存在）；
- **雙曲平面**：$\delta$ 有限（三角形很細）；
- **歐氏平面**：$\delta = \infty$（三角形不細——等邊三角形可以任意大）。
$$\text{樹} \subset \text{雙曲} \subset \text{歐氏（越來越「胖」）}$$

### 第三條線索：雙曲群的性質（Gromov 的寶藏清單）
**雙曲群的性質**（Gromov 1987 證明）：
1. **字問題線性可解**（Dehn 演算法）：
   $$\text{時間} \le C \cdot |w| \quad\text{（字的長度的線性函數）}.$$
2. **只有有限多個共軛類的有限子群**；
3. **邊界（boundary）是「小」的**：
   $$\text{雙曲群的邊界} = \text{「無窮遠」的集合（分形）}.$$
4. **隨機群幾乎都是雙曲的**：
   $$\boxed{\text{Gromov 的密度模型：隨機群的雙曲概率} \to 1}$$
   $$\text{這與 Thurston 的「隨機流形 = 雙曲」呼應（見「1982-瑟斯頓幾何化猜想.md」）}.$$

### Python：Cayley 圖與雙曲性的數值驗證

```python
import numpy as np
from collections import deque

# 1) 自由群 F₂ 的 Cayley 圖 = 四叉樹（極端雙曲）
def free_group_ball(radius):
    """自由群 F₂ = <a,b> 的半徑 r 球（字及其逆）"""
    gens = ['a', 'b', 'A', 'B']   # A = a⁻¹, B = b⁻¹
    elements = ['']   # 單位元素
    frontier = ['']
    for _ in range(radius):
        new_frontier = []
        for w in frontier:
            for g in gens:
                # 自由群的化簡：不允許 g 後跟 g⁻¹
                if w and w[-1] == {'a':'A','A':'a','b':'B','B':'b'}[g]:
                    continue
                new_frontier.append(w + g)
        elements.extend(new_frontier)
        frontier = new_frontier
    return elements

print("自由群 F₂ 的成長（Cayley 圖 = 四叉樹）：")
for r in [1, 2, 3, 5]:
    n = len(free_group_ball(r))
    print(f"  半徑 {r}：元素個數 = {n}（理論 1 + 4(3^{r}-1)/2 = {1 + 4*(3**r-1)//2}）")
print("  → 指數成長（3^r）——雙曲群的特徵（歐氏 Z² 是多項式成長 r²）\n")

# 2) 對照：Z² 的成長（多項式）
def z2_ball(radius):
    return [(i, j) for i in range(-radius, radius+1)
                   for j in range(-radius, radius+1) if abs(i)+abs(j) <= radius]

print("Z² 的成長（方格網，多項式）：")
for r in [1, 2, 3, 5]:
    n = len(z2_ball(r))
    print(f"  半徑 {r}：元素個數 = {n}（理論 2r²+2r+1 = {2*r**2+2*r+1}）")
print("  → 多項式成長（r²）——非雙曲（虛擬平直）\n")

# 3) Dehn 演算法：雙曲群的字問題線性可解
def free_group_reduce(word):
    """自由群的化簡（Dehn 演算法的簡化版）"""
    inv = {'a':'A','A':'a','b':'B','B':'b'}
    stack = []
    steps = 0
    for g in word:
        steps += 1
        if stack and stack[-1] == inv[g]:
            stack.pop()
        else:
            stack.append(g)
    return ''.join(stack), steps

print("Dehn 演算法（字問題的線性解）：")
for w in ['abaA', 'abab', 'aabbBA', 'aabbBABA']:
    red, steps = free_group_reduce(w)
    print(f"  {w:10s} → 化簡 = '{red if red else 'e（單位元）'}'，步驟 = {steps}")
print("  → 步驟 = 字的長度（線性時間）✓\n")
```

### 理論與數學式：δ-細三角形與雙曲性的階層

**Gromov 的雙曲性定義（測地空間）**：存在 $\delta \ge 0$，使每個測地三角形的
每條邊都落在另外兩邊的 $\delta$-鄰域內（「δ-細三角形」）：

$$\text{群 } G \text{ 是雙曲群} \iff \text{Cayley 圖是 } \delta\text{-細（某有限 } \delta\text{）}.$$

| 空間 | $\delta$ | 三角形形狀 |
|------|----------|-----------|
| 樹（自由群 $F_2$ 的 Cayley 圖） | $0$ | 「三角形」兩邊完全重合 |
| 雙曲平面 $\mathbb{H}^2$ | 有限 | 極細（邊向中心坍縮） |
| 歐氏平面 $\mathbb{E}^2$ | $\infty$ | 等邊三角形可以任意「胖」 |

**樹 $\subset$ 雙曲 $\subset$ 歐氏**（越來越「胖」）。雙曲群的指數成長（$3^r$）、
線性時間的 Dehn 演算法、分形邊界——**全部是 δ-細性的推論**。

## 結案 -- 後果與影響
- **幾何群論的誕生（1987）**：
  $$\boxed{\text{群 = 幾何（Cayley 圖 + 字度量規）}}$$
  Gromov 的《雙曲群》開創了一個**全新的數學領域**——
  群論的問題（字問題、子群、成長）全部可以用**幾何工具**研究：
  $$\text{代數的問題} \xrightarrow{\text{Gromov 1987}} \text{幾何的解答}.$$
- **Gromov 的獎項（1993/1999/2009）**：
  Gromov 因雙曲群與幾何群論獲 1993 年沃爾夫獎候選、
  1999 年**阿貝爾獎的首屆呼聲**、
  2009 年**阿貝爾獎**（與 Varadhan）。
  $$\text{Gromov（1987）} \xrightarrow{\text{阿貝爾獎（2009）}} \text{幾何群論的黃金時代}.$$
- **Dehn 演算法與計算複雜度（1987–）**：
  - **雙曲群的字問題線性可解**——這是**群論中「最好」的演算法複雜度**；
  - **一般群的字問題不可判定**（Novikov–Boone, 1955）；
  - **中間地帶（1990s–）**：單播群、自動群（automatic groups）——
    **二次時間可解**。
  $$\text{不可判定（一般群）} \subsetneq \text{二次（自動群）} \subsetneq \text{線性（雙曲群）}.$$
- **隨機群定理（1990s–2000s）**：
  - **Gromov 的密度模型（1993）**：隨機群的雙曲概率 → 1；
  - **Ollivier（2005）**、**Żuk（1996）**：嚴格證明。
  $$\boxed{\text{「隨機」的群幾乎都是雙曲的}}$$
  **這與 Thurston 的「隨機流形 = 雙曲」呼應**——
  **雙曲性是「一般位置」的性質，平直是「特殊」的**。
- **3-流形幾何化的橋（1987–2003）**：
  $$\text{Thurston（1982）：隨機流形 = 雙曲} \xrightarrow{\text{Gromov（1987）：隨機群 = 雙曲}} \text{Perelman（2003）：幾何化證明}.$$
  Gromov 的**Gromov 範數**（見「1982-瑟斯頓幾何化猜想.md」）
  是「體積 = 拓樸」的橋樑。
- **現代應用（2000s–）**：
  - **網路科學**：複雜網路的**雙曲嵌入**（小世界 + 無尺度網路的隱空間是雙曲的）；
  - **密碼學**：**雙曲群上的密碼系統**（braid group cryptography 的對照）；
  - **機器學習**：**雙曲嵌入（hyperbolic embeddings）**——
    樹狀結構（知識圖譜、層次分類）在雙曲空間中更有效率（Nickel–Kiela, 2017）；
  - **計算機科學**：**自動機與群論**的結合（automatic structures）。
  $$\text{Gromov（1987）} \xrightarrow{} \text{網路科學 + AI（2010s）} \xrightarrow{} \text{雙曲嵌入的時代}.$$
- **未解問題**：
  - **Gromov 的「幾何化所有群」計畫**：所有群能否被幾何化？（部分解決）；
  - **Burnside 問題的幾何版本**（部分解決）。
- 歷史定位：**Gromov 是「幾何與代數的翻譯官」**——
  他把 Klein 的「幾何 = 群」倒轉為「**群 = 幾何**」，
  讓兩個原本獨立的領域**互通**。
  $$\text{Klein（1872）：幾何 = 群} \xrightarrow{\text{Gromov（1987）}} \text{群 = 幾何（雙向的橋）}.$$
