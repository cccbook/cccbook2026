# 1247 - 秦九韶《數書九章》

## 案件摘要
1247 年，南宋數學家秦九韶完成《數書九章》：包含兩大發明——**中國剩餘定理的一般解法**（「大衍求一術」：聯立同餘方程組）與**高次方程的數值解法**（「正負開方術」：等價於 19 世紀 Horner 方法，早 600 年）。**中國剩餘定理**來自《孫子算經》（約 4 世紀）的「物不知數」問題，秦九韶把它一般化到任意模數——這個定理今天是**密碼學（RSA 的 CRT 加速，見 `../密碼學/1977-RSA.md`）的核心工具**。**中國數學的算法化巔峰**。

## 前因 -- 為什麼會有這個案子
**《孫子算經》（約 4 世紀）**的「物不知數」問題：

> 今有物不知其數，三三數之剩二，五五數之剩三，七七數之剩二，問物幾何？

**數學**：$x \equiv 2 \pmod 3$、$x \equiv 3 \pmod 5$、$x \equiv 2 \pmod 7$——**聯立同餘方程組**。答案 23。

**口訣（明代程大位《算法統宗》）**：「三人同行七十稀，五樹梅花廿一支，七子團圓正半月，除百零五便得知」——70、21、15 的權重。

**秦九韶的問題**：孫子的解法只適用互質模數——**能否一般化到任意模數**（曆法計算的實際需求：上元積年，非互質模數）？

**秦九韶的背景**：南宋官員（曾守城抗蒙），兵荒馬亂中寫作——「心槁氣落，實賴數以安」——數學是他亂世的寄託。

## 線索與推理 -- 數學式、程式、理論

### 中國剩餘定理（CRT）
**定理**：模數兩兩互質時，聯立同餘方程組

$$x \equiv a_i \pmod{m_i} \quad (i = 1, \dots, k)$$

有唯一解 $x \bmod M$（$M = \prod m_i$）。

**構造**（孫子的權重法）：$M_i = M/m_i$，$y_i = M_i^{-1} \bmod m_i$（**逆元**），則：

$$x = \sum_{i=1}^k a_i M_i y_i \bmod M$$

**驗證**：模 $m_i$ 時其他項消失（$M_j \equiv 0$ for $j \ne i$），剩下 $a_i M_i y_i \equiv a_i \pmod{m_i}$。$\blacksquare$

**「大衍求一術」**：秦九韶的**逆元算法**——用輾轉相除（歐幾里得算法的中國版）求 $M_i^{-1} \bmod m_i$——**機械步驟**（「術」的傳統）。

### 正負開方術：高次方程
**秦九韶的數值解法**：高次方程 $x^n + a_{n-1}x^{n-1} + \dots = 0$ 的**數值根**——

**方法（與 Horner 1819 等價，早 600 年）**：

1. **估根**：試商（根的第一位）
2. **減根變換**：把根減去試商，方程降一階（係數重算）
3. **重複**：逐位求出（十進位的每一位）

**數學**（減根變換）：$x = b + y$ 代入 $f(x) = 0$，展開得 $y$ 的新方程（係數是泰勒係數）——**逐位逼近**。

**範例**：$x^3 - 1860867 = 0$（1247 年的實際問題）——秦九韶解得 $x = 123$——**機械步驟的高次方程**（歐洲 19 世紀 Horner 方法，見 `1665-Newton微積分.md` 的 Newton 迭代）。

### 程式碼：CRT 與正負開方

```python
def extended_gcd(a, b):
    if b == 0: return a, 1, 0
    g, x, y = extended_gcd(b, a % b)
    return g, y, x - (a // b) * y

def crt(remainders, moduli):
    """中國剩餘定理：聯立同餘方程組"""
    M = 1
    for m in moduli: M *= m
    x = 0
    for a, m in zip(remainders, moduli):
        Mi = M // m
        _, yi, _ = extended_gcd(Mi % m, m)      # 逆元（大衍求一術）
        x = (x + a * Mi * yi) % M
    return x

# 孫子的「物不知數」：x≡2(3), x≡3(5), x≡2(7)
x = crt([2, 3, 2], [3, 5, 7])
print(f"物不知數：x = {x}")                     # 23 ✓
print(f"驗證：{x%3==2}, {x%5==3}, {x%7==2}")     # True, True, True

# 口訣的權重：70, 21, 15
print(f"權重：70 = 35×2（5·7 的逆模 3），21 = 15×1，15 = 21×1")

# 正負開方術：高次方程的數值解（Horner 等價，早 600 年）
def qin_jiushao_horner(coeffs, x):
    """秦九韶的正負開方術 = Horner 方法：多項式求值"""
    result = 0
    for c in coeffs:                             # 高次到低次
        result = result * x + c
    return result

# x^3 - 1860867 = 0 → x = 123
print(f"f(123) = {qin_jiushao_horner([1, 0, 0, -1860867], 123)}")   # 0 ✓
print("秦九韶 1247：正負開方術 = Horner 方法（1819）早 600 年")
```

### CRT 與現代密碼學
**RSA 的 CRT 加速**：解密 $c^d \bmod n$（$n = pq$）用 CRT 拆成兩半：

$$m_p = c^{d \bmod (p-1)} \bmod p, \quad m_q = c^{d \bmod (q-1)} \bmod q$$

再用 CRT 合併——**速度提升 4 倍**（每次模運算的位數減半）。**OpenSSL 的 RSA 私鑰都存 $p, q, d_p, d_q, q^{-1}$**——秦九韶 1247 年的方法是 HTTPS 的基礎設施。

**偵探筆記**：秦九韶的推理是「**從特殊到一般**」——孫子的特殊解法（互質模數）一般化到任意模數（大衍求一術）。**「術」的算法化**（機械步驟）與花拉子米（820，見 `0820-Khwarizmi代數學.md`）同源：**照著做就對**。CRT 的權重構造（$M_i y_i$）是「每個方程獨立貢獻、互不干擾」的結構——與 Shamir 秘密分享（見 `1979-Shamir秘密分享.md`）的 Lagrange 插值同構！

## 結案 -- 後果與影響
- **中國剩餘定理**：從曆法（上元積年）到密碼學（RSA 的 CRT 加速）——**1247 年的方法是 HTTPS 的基礎設施**。
- **正負開方術**：Horner 方法（1819）的 600 年前身——高次方程的數值解。
- **大衍求一術**：逆元的機械算法——輾轉相除的傳統（歐幾里得算法的中國版）。
- **代數的獨立傳統**：中國的高次方程（秦九韶）、負數（九章算術）、極限（劉徽）——**獨立於西方的發展**。
- **抽象的譜系**：CRT 的權重構造 → Lagrange 插值 → Shamir 秘密分享——**同一個「獨立貢獻」結構**。
- **秦九韶的爭議**：官員生涯（守城時的殘酷手段）與數學成就的分裂——數學家的道德問題。
