# 1665 - 牛頓微積分

## 案件摘要
1665–1666 年，23 歲的 Isaac Newton 在瘟疫期間（劍橋停課，回鄉躲疫）發明**微積分**：流數術（fluxions）——處理「連續變化」的數學。1687 年出版《自然哲學的數學原理》（Principia）：微積分 + 萬有引力——**天空與大地服從同一條數學**。與此同時萊布尼茨（Leibniz）獨立發明微積分（1675，記號更優雅）——兩人的優先權之爭撕裂歐洲數學界數十年。**微積分是物理學、工程學、現代科學的引擎。**

## 前因 -- 為什麼會有這個案子
1660 年代的四個懸題（無法用舊數學解決）：

1. **瞬時速度**：物體在「一瞬間」的速度？——平均速度是 $\Delta x / \Delta t$，瞬時是 $0/0$（無意義！）
2. **切線**：曲線在一點的切線斜率？（費馬、笛卡爾的零散方法）
3. **面積**：曲線下的面積？（阿基米德窮竭法，見 `-0250-Archimedes圓周率.md`——笨拙）
4. **軌道**：行星為何走橢圓？（Kepler 的三定律是**經驗**觀察，無解釋）

**Newton 的洞察**：這四個問題是**同一個問題**——「連續變化」的數學。瞬時速度與切線是**同一件事**（變化率），面積是變化率的**反問題**（積分），軌道是變化率的**微分方程**。

## 線索與推理 -- 數學式、程式、理論

### 導數：瞬時的變化率
**核心技巧**：不取 $\Delta t = 0$（除零），而是取**極限**：

$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$

**範例**：$f(x) = x^2$：

$$\frac{(x+h)^2 - x^2}{h} = \frac{2xh + h^2}{h} = 2x + h \to 2x \quad (h \to 0)$$

——瞬時速度、切線斜率，一次解決。

**牛頓的原始記號**（流數術）：$x$ 的流數記為 $\dot{x}$（點號）——萊布尼茨的 $dx/dt$ 記號更優雅（今天通用）。

### 微積分基本定理（FTC）
**神來之筆**：微分與積分是**互逆運算**：

$$\int_a^b f'(x)\,dx = f(b) - f(a)$$

**為什麼**：面積的「微元」$f(x)dx$ 累加，與 $f$ 的變化量相等——**面積問題化為找原函數**（反導數）。阿基米德兩千年笨拙的窮竭法（見 `-0250-Archimedes圓周率.md`）變成「找 $f'$ 的逆」——**機械化**。

### 萬有引力：天空的數學
**Kepler 三定律**（1609–19）：橢圓軌道、等面積速度、$T^2 \propto a^3$——經驗觀察。

**Newton 的推理**：假設 $F = GMm/r^2$（平方反比），用微積分推導軌道：

$$m\ddot{r} = -\frac{GMm}{r^2}\hat{r}$$

**微分方程的解**：橢圓軌道 ✓、等面積速度 ✓、$T^2 \propto a^3$ ✓——**三條經驗定律全部從一條假設 + 微積分推導**。**蘋果與月亮服從同一條數學**（傳說中的蘋果——Newton 自己說是「月球的運動讓我想起引力」）。

**《原理》的結構**（歐幾里得的公理化範式，見 `-0300-Euclid幾何原本.md`）：定義 + 三條運動定律 → 幾何命題 → 行星軌道、潮汐、彗星——**自然的幾何建築**。

### 程式碼：微積分與軌道

```python
import math

# 導數（數值近似）
def derivative(f, x, h=1e-6):
    return (f(x + h) - f(x)) / h

f = lambda x: x**2
print(f"f'(3) = {derivative(f, 3)}")       # ≈ 6（解析值 2x = 6）

# 積分（微元累加）與 FTC
def integrate(f, a, b, n=100000):
    return sum(f(a + i*(b-a)/n) for i in range(n)) * (b-a)/n

print(f"∫x² from 0 to 3 = {integrate(f, 0, 3):.4f}")   # 9 = 3³/3 ✓
F = lambda x: x**3/3                                     # 原函數
print(f"FTC: F(3)-F(0) = {F(3)-F(0)}")                  # 9.0——微分與積分互逆

# 微分方程：軌道模擬（Euler 方法）
def orbit_simulate(vx0, vy0, r=10.0, steps=5000, dt=0.001, mu=1.0):
    """牛頓引力下的軌道（二維）"""
    x, y, vx, vy = r, 0.0, vx0, vy0
    path = [(x, y)]
    for _ in range(steps):
        d = math.sqrt(x*x + y*y)
        ax, ay = -mu*x/d**3, -mu*y/d**3       # 平方反比
        vx, vy = vx + ax*dt, vy + ay*dt
        x, y = x + vx*dt, y + vy*dt
        path.append((x, y))
    return path

# 圓軌道：v = sqrt(mu/r)
path = orbit_simulate(math.sqrt(1/10), 0)
print(f"軌道模擬：起點 ({path[0][0]:.2f}, {path[0][1]:.2f})，終點 ({path[-1][0]:.2f}, {path[-1][1]:.2f})")
# 圓軌道回到起點附近——橢圓/圓軌道從 F = GMm/r² 推導 ✓
```

### 牛頓-萊布尼茨優先權之爭
**萊布尼茨**（1675）獨立發明微積分（$dx, dy, \int$ 記號——今天通用）。**之爭**（1684–1716）：

- 牛頓宣稱萊布尼茨抄襲（牛頓 1665 早發明但未發表）
- 萊布尼茨的記號傳播更廣（歐陸學派）——英國數學界固守牛頓記號，落後歐陸百年
- **教訓**：先發明不如先發表——與 Cardano（1545）、Descartes（1637）的優先權案例並列

**牛頓自己說**：「如果我看得更遠，是因為站在巨人的肩膀上。」——阿基米德（窮竭法）、笛卡爾（座標）、費馬（切線）的肩膀。

## 結案 -- 後果與影響
- **物理學的誕生**：微積分 + 引力 = 現代力學——拉普拉斯的天體力學、麥克斯韋電磁學（見 `../電磁學/README.md`）。
- **微積分基本定理**：微分與積分的互逆——分析學的核心。
- **微分方程**：一切「連續變化」的數學——從軌道到熱傳導（見 `../微分方程/README.md`）到 Schrödinger 方程。
- **記號的帝國**：萊布尼茨的 $dx/dt$、$\int$——今天通用的語言。
- **基礎的危機**：牛頓的「無窮小」概念含糊（貝克萊主教的批評：ghosts of departed quantities）——極限的嚴格化（Cauchy、Weierstrass，19 世紀）。
