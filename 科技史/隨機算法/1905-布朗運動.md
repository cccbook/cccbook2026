# 1905 - 布朗運動

## 案件摘要
1905 年，Einstein 在他的「奇蹟年」發表《關於懸浮在靜止液體中微小粒子由分子動力學理論所要求的運動》，用**隨機漫步**的數學解釋布朗運動，並給出亞佛加厥常數的可測量預測。三年後 Perrin 的實驗證實了它——原子分子的存在首次被「看見」。隨機漫步從此從物理現象升級為數學對象，成為一切隨機算法的運動學基礎。

## 前因 -- 為什麼會有這個案子
1827 年，植物學家 Brown 顯微鏡下看到花粉顆粒在水中無規則亂動。幾十年無人能解：是生命？是熱流？1900 年 Bachelier 用隨機漫步模型研究股價（比 Einstein 早五年，但物理學界不知道）。Einstein 的動機不同：**如果原子真的存在，統計力學預言懸浮顆粒必然亂動**——算出這個亂動的定量特徵，就能用顯微鏡「稱出」原子。

## 線索與推理 -- 數學式、程式、理論

### 隨機漫步的擴散方程
設顆粒在一維上每 $\tau$ 秒隨機跳一步，跳距 $\pm\lambda$ 等機率。$n$ 步後位置的變異數：

$$\mathrm{Var}(X_n) = n \lambda^2$$

取極限 $\tau \to 0$、$\lambda \to 0$、$\lambda^2/\tau = 2D$ 固定，機率密度 $p(x,t)$ 滿足**擴散方程**：

$$\frac{\partial p}{\partial t} = D \frac{\partial^2 p}{\partial x^2}$$

解為高斯核：

$$p(x,t) = \frac{1}{\sqrt{4\pi D t}} \exp\left(-\frac{x^2}{4Dt}\right)$$

均方位移隨時間**線性**增長：

$$\langle x^2(t) \rangle = 2Dt$$

這是隨機漫步的指紋：**距離 $\propto \sqrt{t}$，不是 $\propto t$**——醉酒者回家的路是直線的 $\sqrt{}$ 倍長。

### Einstein 關係式
由統計力學，擴散係數與摩擦力（Stokes 定律，半徑 $a$ 的球在黏度 $\eta$ 的液體中）連結：

$$D = \frac{k_B T}{6\pi \eta a}$$

合併得**Einstein 關係式**：

$$\langle x^2(t) \rangle = \frac{k_B T}{3\pi \eta a} t$$

右邊所有量都可測（$T, \eta, a, t$），左邊 $\langle x^2\rangle$ 顯微鏡可量——**於是 $k_B$（連同亞佛加厥常數 $N_A = R/k_B$）可被實驗測定**。這就是「看得見原子」的推理。

### 程式碼：Python 模擬隨機漫步與擴散

```python
import random, math

def random_walk_1d(n, steps=1000):
    xs = [0.0]
    for _ in range(steps):
        xs.append(xs[-1] + random.choice([-1, 1]))
    return xs

random.seed(42)
# 驗證 <x^2> = 2Dt（此處 D = 1/2 每步）
for steps in [100, 400, 900]:
    msd = sum(random_walk_1d(0, steps)[-1]**2 for _ in range(2000)) / 2000
    print(f"t={steps:5d}  <x^2>={msd:10.1f}  預測 t={steps}")
# 輸出 <x^2> ≈ t：線性增長，根號擴散的指紋

# 布朗運動（連續極限）：維納過程
def wiener(dt=0.001, T=1.0):
    n = int(T/dt)
    x = 0.0
    path = [0.0]
    for _ in range(n):
        x += random.gauss(0, math.sqrt(2*dt))  # 每步方差 2*dt
        path.append(x)
    return path
```

### 隨機漫步與算法的連結
隨機漫步是後續所有隨機算法的運動骨架：

- **2-SAT 隨機算法**（1991）：沿隨機漫步修復變數，$O(n^2)$ 期望時間——擴散的收斂速度
- **Markov Chain Monte Carlo**（1953）：在狀態空間中隨機漫步，收斂到目標分佈
- **混合時間**（mixing time）：漫步多久才「忘記」起點——收縮性分析的核心量

**偵探筆記**：無人引導的隨機，長期卻呈現精確的統計規律（$2Dt$）——「個體混亂、集體有序」是蒙地卡羅方法能工作的根本原因。

## 結案 -- 後果與影響
- **原子論勝利**：Perrin (1908) 實驗測得 $N_A$，Einstein 獲 1921 諾貝爾獎（表彰布朗運動工作，而非相對論）。
- **維納過程**：Wiener (1923) 給布朗運動嚴格數學基礎，成為隨機分析（Itô 微積分，1944）的基石。
- **隨機漫步算法**：2-SAT、圖上漫步、PageRank（1998，隨機漫遊的平穩分佈）、MCMC——皆源於此。
- **混合時間理論**：隨機漫步收斂速度的分析成為隨機算法理論的中心問題。
