# 1820-Ampere 電動力學

## 案件摘要
1820 年 9 月起，安培（André-Marie Ampère）聽聞 Oersted 的發現後，在僅數週的時間內完成了一系列精確實驗與數學分析，建立「電動力學」（électrodynamique）：兩平行載流導線會互相吸引或排斥，其力律可寫成數學公式，並總結為安培迴路定律。他被譽為「電學中的牛頓」。

## 前因 -- 為什麼會有這個案子
- 1820 年 9 月 4 日，Arago 在法國科學院公開演示 Oersted 實驗，安培當時在場，立刻意識到其分量：電與磁若相關，電流與電流之間也應有作用力。
- **牛頓式抱負**：18 世紀物理的典範是牛頓萬有引力——任意兩體之間的力可用一條公式表達。Coulomb 已為靜電、靜磁寫出平方反比律；安培的目標是為「運動中的電」（電流）寫出對應的力律，建立電學的牛頓力學。
- 與 Oersted 不同，安培不信自然哲學，而是徹底的**數學化實驗主義者**：先猜測對稱的力律，再用精密儀器檢驗。

## 線索與推理 -- 數學式、程式、理論

### 線索一：兩平行載流導線實驗（1820 年 9 月）
- 安培用兩條平行長直導線：**同向電流互相吸引，反向電流互相排斥**。
- 這是第一個「電對電」的作用力實驗——磁只是電流之間作用的媒介表象。
- 對兩條相距 $d$ 的平行長直導線（電流 $I_1, I_2$），單位長度的作用力為：

$$
\frac{dF}{dl} = \frac{\mu_0 I_1 I_2}{2\pi d}
$$

同向（$I_1 I_2 > 0$）為吸力，反向為斥力。此式今日定義了 SI 的電流單位「安培」。

### 線索二：安培力定律（一般形式）
安培的最終成果是對任意兩個電流元 $I_1 d\mathbf{l}_1$、$I_2 d\mathbf{l}_2$ 的力律：

$$
d\mathbf{F} = \frac{\mu_0 I_1 I_2}{4\pi}\,
\frac{d\mathbf{l}_1 \times \left(d\mathbf{l}_2 \times \hat{\mathbf{r}}\right)}{r^2}
$$

其中 $\hat{\mathbf{r}}$ 從電流元 2 指向電流元 1。這條「電流元的牛頓引力公式」是其數學化物理的巔峰——雙重叉積保證了作用力的橫向性質，正確解釋平行導線與任意形狀迴路之間的力。

### 線索三：安培迴路定律
由圓形磁場 $\mathbf{B} = \frac{\mu_0 I}{2\pi r}\hat{\phi}$，沿半徑 $r$ 的圓積分：

$$
\oint \mathbf{B} \cdot d\mathbf{l} = \frac{\mu_0 I}{2\pi r}\,(2\pi r) = \mu_0 I
$$

一般化為：磁場沿任意閉合迴路的環流等於該迴路所包圍的總電流乘以 $\mu_0$：

$$
\oint \mathbf{B} \cdot d\mathbf{l} = \mu_0 I_{\mathrm{enc}} = \mu_0 \int \mathbf{J}\cdot d\mathbf{A}
$$

### 線索四：分子電流假說
- 當時磁鐵內部並無可見電流，安培提出：磁鐵的磁性來自每個分子內部環繞的微小電流（**分子電流**，courants moléculaires）——所有分子電流同向排列，內部抵消、表面形成環繞電流，外觀即為磁鐵。
- 這是「磁即電」的深刻洞見：磁性不是獨立實體，而是電流的集體現象，預言了原子內電子軌道與自旋磁矩，遠超當時實驗所能證實。
- 論證：若磁由分子電流構成，則磁鐵在載流導線旁受力與兩載流迴路受力應完全一致——安培的實驗（用螺線管模擬磁棒）證實了這一點。

### Python：驗證安培定律，計算螺線管磁場

```python
import numpy as np

mu0 = 4*np.pi*1e-7
n, I = 1000, 1.0      # 每米匝數、電流

# 理論：長螺線管內部 B = mu0 * n * I（由安培迴路定律導出）
B_theory = mu0 * n * I
print(f"安培定律理論值  B = {B_theory:.6e} T")

# 數值驗證：直接疊加 N 匝圓線圈在軸心產生的磁場
# 單匝半徑 a 圓線圈軸心 B = mu0 * I * a^2 / (2*(a^2+x^2)^(3/2))
N, a, L = 100, 0.1, 0.1        # 100 匝、半徑 0.1m、長 0.1m -> n = 1000 /m
xs = np.linspace(-L/2, L/2, N) # 各匝位置
B_numerical = sum(mu0 * I * a**2 / (2*(a**2 + x**2)**1.5) for x in xs)
print(f"數值疊加（100 匝）B = {B_numerical:.6e} T")
print(f"相對誤差 = {abs(B_numerical/B_theory - 1):.2%}")
```

執行結果：兩者相差約 3%（有限長度效應），螺線管越長誤差越小——驗證了安培迴路定律 $\oint\mathbf{B}\cdot d\mathbf{l}=\mu_0 I$ 對螺線管的推論 $B = \mu_0 n I$。

### 推理：為何「電學中的牛頓」？
牛頓以一條萬有引力公式統一天上地下；安培以一條電流元力律統一所有磁現象（導線磁效應、磁鐵作用、螺線管）為電流之間的數學關係。Maxwell 評價：「安培的整個理論與實驗，是科學史上最輝煌的成就之一。」

## 結案 -- 後果與影響
- **電磁鐵與電報**：Sturgeon（1825）與 Henry 製成實用電磁鐵；電流磁效應＋電磁鐵促成 Morse 電報（1837）。
- **單位命名**：SI 電流單位「安培（A）」即由兩平行導線力律 $dF/dl = \mu_0 I_1 I_2/(2\pi d)$ 定義。
- **通往 Maxwell**：安培迴路定律成為 Maxwell 方程組第四式；Maxwell 補上位移電流 $+\mu_0\varepsilon_0\, d\Phi_E/dt$ 後，電磁波得以誕生。
- **分子電流的勝利**：20 世紀原子物理證實磁性確源於原子內電子軌道與自旋——安培的假說是物理史上最成功的大膽推測之一。
