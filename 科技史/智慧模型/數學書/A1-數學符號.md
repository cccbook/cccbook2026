# A1 數學符號表

## 本書使用的符號

### 向量與矩陣（線性代數）

| 符號 | 意義 | 出現章節 |
|---|---|---|
| $\mathbf{x}, \mathbf{w}$ | 輸入向量、權重向量 | 01.1 起 |
| $\mathbf{x}^\top \mathbf{y}$ | 內積（點積） $= \sum_i x_i y_i$ | 02.1、05.2 |
| $\|\mathbf{x}\|$ | 歐氏範數 $\sqrt{\sum_i x_i^2}$ | 02.1 |
| $W, W^\top$ | 權重矩陣、轉置 | 03.2 |
| $\odot$ | Hadamard 積（逐元素乘） | 03.2 |
| $\mathbf{J}$ | 斜對稱結構矩陣 $\begin{pmatrix} 0 & I \\ -I & 0 \end{pmatrix}$ | 08.1 |
| $\mathrm{Cov}(\mathbf{e})$ | 協方差矩陣 | 08.2 |
| $Q, K, V$ | 注意力的查詢、鍵、值矩陣 | 05.2 |
| $R_{\Theta,m}$ | RoPE 的分塊旋轉矩陣 | 05.3 |

### 常用函數

| 符號 | 定義 |
|---|---|
| $\Theta(z)$ | 階梯函數 $\mathbb{1}[z \ge 0]$ |
| $\sigma(z)$ | $\dfrac{1}{1 + e^{-z}}$ |
| $\mathrm{ReLU}(z)$ | $\max(0, z)$ |
| $\tanh(z)$ | $\dfrac{e^z - e^{-z}}{e^z + e^{-z}}$ |
| $\mathrm{sgn}(z)$ | 符號函數 |
| $\mathbb{1}[\cdot]$ | 指示函數（條件真則 1） |
