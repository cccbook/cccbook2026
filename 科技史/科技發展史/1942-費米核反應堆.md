# 1942 費米 CP-1 核反應堆

## 案發現場

1942 年 12 月 2 日下午，芝加哥大學史塔格球場（Stagg Field）西看台下的壁網球場裡，一群物理學家聚集在一個「堆」旁邊：57 層石墨磚與鈾塊交疊，寬 9 米、高 6.5 米、重約 1400 噸的**芝加哥一號堆（CP-1）**。主持者恩里科·費米（Enrico Fermi, 1901–1954）手裡握著一支量測中子通量的儀器，現場只有兩件「控制工具」：一根可以抽出的鎘控制棒，以及一桶隨時準備潑上去的鎘鹽溶液——萬一失控，就是「液體控制棒」。

這是人類歷史上第一次**受控的核鏈式反應**。1938 年哈恩與邁特納發現裂變（[1938-核裂變.md](1938-核裂變.md)）時已指出：每次裂變會放出 2–3 個新中子，鏈式反應理論上可行。理論跑在前面，這一次實驗只用三年就追上——而追上的代價，是一個國家的總動員（曼哈頓計畫）。

## 偵查過程

費米的偵查手法，是把鏈式反應的理論拆解成一個**可計算、可控制的增殖係數**：

**線索一：增殖係數 k。** 每一代中子引發的下一代裂變數，記作 k。k < 1 反應熄滅；k = 1 恰好自持；k > 1 指數增長（原子彈）。費米的目標：讓堆精確停在 **k ≈ 1.0006**——超臨界一絲，可控。

**線索二：三個技術難題的解法。**
- **慢化中子**：快中子容易被鈾 238 吸收而不裂變。費米用**石墨**做慢化劑，把中子減速到熱速度，讓鈾 235 更容易捕獲並裂變——這是他在羅馬十年中子實驗的累積（他 1934 年起就系統轟擊各種元素，卻與裂變擦身而過——實驗數據在眼前而解讀權落到別人手中）。
- **純化材料**：鈾中的雜質（如硼）會吞噬中子。戰時曼哈頓計畫動員工業量產高純度石墨與金屬鈾。
- **控制反應**：鎘棒吸收中子，插入深度即控制 k。費米設計了一套「分級抽出」的程序，像外科手術一樣逼近臨界。

**線索三：12 月 2 日的現場推理。** 下午 3 時 25 分，費米下令分批抽出控制棒。每抽一段，他就用計算尺即時核算中子通量的增長率，對照理論預測。當最後一根棒抽到定位，反應自持——k 達到 1.0006，功率約 0.5 瓦（28 分鐘後升到 200 瓦）。費米對同事說：

> 「法國人皮雷（Fermi 對 Wigner 說的玩笑話）：如果反應失控，這座城就會消失。但我們算了又算，它是安全的。」

——他實際說的是舉起手，對觀察者說：「**反應自持了。曲線會上升，而人類將第一次釋放出核能。**」康普頓當場打長途電話給華盛頓的科南特（哈佛校長、曼哈頓計畫委員），留下那句著名的密語：「義大利航海家已經登上了新大陸。」「土著友善嗎？」「每個人都會落地、開火。」

## 結案報告

CP-1 屬於迴路的**實驗**環節——鏈式反應理論（[1938-核裂變.md](1938-核裂變.md)）的第一次受控實現，理論到實驗的等待時間只有三年。其深遠意義：

1. **核能時代的起點**——受控裂變成為核電廠的原理模板；今日全球約一成電力來自費米當年那個「堆」。
2. **迴路的國家級總動員**——CP-1 是曼哈頓計畫（[1945-原子彈.md](1945-原子彈.md)）的第一步；「理論—實驗—技術」的循環第一次由國家機器全權推動，個人實驗室（伽利略）、學會（皇家學會）、工業實驗室（愛迪生）之後，**國家計畫**成為迴路的新組織形式。
3. **理論領先、實驗追上的最短紀錄**——從哥白尼 60 年、麥克斯韋 23 年、愛因斯坦 4 年，到裂變 3 年：第七幕「等待時間縮短」的主題在此定格。
4. **戰後的兩面性**——同一套鏈式反應物理，既能發電也能滅城；科學第一次被迫面對「迴路的道德責任」。

## 證據與工具

```python
# 偵查證物：鏈式反應增殖係數 —— CP-1 的核心數學
import math

k = 1.0006        # CP-1 的增殖係數（超臨界一絲）
n0 = 1            # 初始中子數
generations = 200 # 世代數（每代約 0.1 毫秒）

n = n0 * k**generations
print(f"k = {k} 時，{generations} 代後中子數 = {n:.1f}")
print("反應自持但增長緩慢 → 可控（對比原子彈 k≈2，微秒內爆發）")

# 對比：原子彈的增殖係數
k_bomb = 2.0
n_bomb = n0 * k_bomb**80
print(f"原子彈 k = {k_bomb}，80 代後中子數 = {n_bomb:.2e} → 指數爆發")

# 功率帳本：CP-1 每次裂變 200 MeV，0.5 W 需要每秒多少次裂變？
MeV_J = 200*1.602e-13   # 每次裂變的能量（J）
fissions_per_sec = 0.5/MeV_J
print(f"\nCP-1 功率 0.5 W → 每秒 {fissions_per_sec:.2e} 次裂變（極其溫和）")
print("對比：1 GW 核電廠需每秒 3×10^19 次裂變 —— 同一原理，尺度差 38 個數量級")
```
