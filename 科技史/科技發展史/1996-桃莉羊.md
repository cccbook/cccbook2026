# 1996 桃莉羊

## 案發現場

1996 年 7 月 5 日，蘇格蘭愛丁堡近郊的羅斯林研究所（Roslin Institute），一頭芬蘭多塞特母羊誕生。她有一個響亮的名字：**桃莉（Dolly）**——取自鄉村歌手桃莉·巴頓，因為她由乳腺細胞培育而來。桃莉的誕生震驚世界，因為她推翻了生物學一條近百年未曾違反的「禁令」：**已分化的體細胞，其命運不可逆轉。**

自 1953 年 [1953-DNA雙螺旋.md](1953-DNA雙螺旋.md) 確立遺傳物質以來，科學家知道每個體細胞都攜帶全套基因；但主流觀點認為，細胞一旦分化成乳腺細胞，就回不去全能狀態——基因的「書」還在，卻被上了鎖。誰能開鎖？

## 偵查過程

偵探是發育生物學家伊恩·威爾穆特（Ian Wilmut）與基思·坎貝爾（Keith Campbell）。他們的偵查分四步：

**第一，選對細胞。**他們從一頭 6 歲母羊取出乳腺細胞，在低營養培養液中讓細胞**休眠**（G0 期）——關鍵推理：休眠狀態的細胞核，染色體處於最「可被重編程」的狀態。

**第二，核轉移。**從另一頭蘇格蘭黑面羊取出卵子，移除細胞核，再將乳腺細胞（或其細胞核）與去核卵子融合，用電脈衝啟動分裂。

**第三，代孕。**重編程的胚胎植入第三頭母羊子宮。277 次核轉移，只有 29 個胚胎發育成功植入，最終僅 1 頭存活——桃莉。她的基因與供體母羊完全相同：**她不是女兒，是分身。**

1997 年 2 月 22 日論文公表，世界嘩然。威爾穆特說：「桃莉證明了成體細胞的命運可以逆轉——生物學的教科書必須改寫。」

## 結案報告

桃莉羊屬於「**實驗+技術⚙**」環節：277 次受控實驗的堅持+顯微操作與電融合技術，把理論上「理論可行、實際無人做到」的複製變成現實，並反過來逼出新的理論——表觀遺傳學與細胞重編程。

1. **分化之鎖被打開**——體細胞可以重編程，直接通往山中伸介的 iPS 誘導多能幹細胞（2006）：不取卵子、不造胚胎，四個轉錄因子即可讓皮膚細胞回春。
2. **生命成為可編寫的對象**——從 [1828-Wohler尿素合成.md](1828-Wohler尿素合成.md) 打破有機/無機之牆，到桃莉打破體細胞命運之牆，「生命的化學」一步步成為工程。
3. **倫理的迴路同步啟動**——複製人的爭議、幹細胞研究的立法：技術突破第一時間引發社會治理的迴響。

桃莉死於 2003 年（肺部疾病，僅 6 歲半——正常綿羊可活 11 歲），引發對複製動物提前衰老的討論；2003 年後證據顯示她的端粒與一般羊相仿，衰老之謎仍在研究中。

## 證據與工具

```python
# DNA 的資訊帳本：桃莉案中的遺傳資訊複製
# (見 1953-DNA雙螺旋.md：A-T, G-C 配對)

codon_table = {}  # 64 個密碼子的簡表查找
bases = "TCAG"
aas = "FFLLSSSSYY**CC*WLLLLPPPPHHQQRRRRIIIMTTTTNNKKSSRRVVVVAAAADDEEGGGG"
i = 0
for b1 in bases:
    for b2 in bases:
        for b3 in bases:
            codon_table[b1+b2+b3] = aas[i]; i += 1

def translate(dna):
    """把 DNA 轉成胺基酸序列（每 3 個鹼基一個密碼子）"""
    # 以 DNA 密碼子查表（mRNA 中 U 將被替換為假尿苷 ψ，轉譯結果不變）
    return "".join(codon_table.get(dna[j:j+3], "?") for j in range(0, len(dna)-2, 3))

# 桃莉案：供體母羊與桃莉的基因完全相同 => 分身而非女兒
donor = "ATGGCCTATCTTTAA"
dolly = donor  # 核轉移：基因資訊 100% 複製
print("供體基因轉譯：", translate(donor))
print("桃莉基因轉譯：", translate(dolly))
print("兩者相同 => 桃莉是分身，不是女兒")

# 遺傳資訊量：綿羊基因組約 2.7 Gbp（十億鹼基對）
genome_bp = 2.7e9
print(f"\n綿羊基因組資訊量 ≈ {genome_bp*2/8/1e9:.2f} GB")
print("桃莉案 = 一次完整的 2.7 GB 遺傳資訊『複製貼上』")
print("277 次核轉移，1 次成功 => 成功率約 0.36%")
```
