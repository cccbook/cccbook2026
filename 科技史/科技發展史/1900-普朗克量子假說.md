# 1900 普朗克量子假說

## 案發現場

1900 年 12 月 14 日，柏林。普朗克（Max Planck）在德國物理學會報告一個他自己都不相信的公式——他為了解釋黑體輻射光譜，被迫假設：**能量不是連續的，而是一份一份的**，每一份為

$$E = h\nu$$

$h \approx 6.6\times10^{-34}\ \mathrm{J\cdot s}$。這一天後來被稱為「量子理論的生日」。但這場革命的点火者，與其說是哲學洞察，不如說是一場**工業測量需求**與一條**發散的公式**聯手逼出來的。

## 偵查過程

**第一條線：技術⇒實驗。** 1890 年代的德國正與英國爭奪電燈市場（見 [1879-愛迪生白熾燈.md](1879-愛迪生白熾燈.md)）。德國工業 lacking 白熾燈專利，只能靠「效率」取勝：燈絲該燒到多熱、發出多少光、多少是浪費的熱——這些問題需要**精確的黑體輻射標準**。帝國物理技術研究所（PTR，專為工業度量而設的國家實驗室）的陸末（Lummer）與普林斯海姆（Pringsheim）等人，於 1896–1900 年把黑體空腔加熱到各種溫度，測出了史上第一批高精度輻射光譜數據。**沒有燈絲標準化的產業需求，就沒有這批數據。**

**第二條線：實驗⇒理論（的破產）。** 手上有數據，理論家有兩件現成武器：

- **維恩公式（1896）**：短波（高頻）端吻合，但長波端偏離數據；
- **瑞利-金斯公式（1900）**：由經典統計力學（能量均分定理）推出，長波端吻合，短波端卻**發散到無窮**——波長越短、輻射越強，意味著任何溫熱的物體（包括你自己）都該瞬間射出無窮紫外線與 X 光。這就是物理學史上最著名的「**紫外災難（ultraviolet catastrophe）**」。這不是小誤差，而是經典物理的自殺判決：均分定理對輻射腔的應用，在數據面前徹底破產。

**第三條線：實驗⇒理論（的新生）。** 普朗克本來是維恩公式的支持者，但 1900 年 10 月的新數據顯示維恩公式在高溫長波失效。他決定：不管什麼理論尊嚴，**先內插出一条與數據完全吻合的公式再說**。數天內他得到了普朗克定律；接下來的兩個月，他反覆追問「這個公式背後的物理是什麼」，最後被迫接受唯一的推論：腔壁上的振子吸收與釋放能量時，只能取 $h\nu$ 的整數倍——能量量子化。他在信中自述這是「孤注一擲的行動」；事後多年他仍稱之為「一次絕望之舉」。

**第四條線：理論⇒理論。** 量子假說像一粒種子，落地即開花：1905 年愛因斯坦用它解讀光電效應，並進一步主張**光本身就是量子**（見 [1905-光電效應.md](1905-光電效應.md)）；1913 年玻爾用它構建原子模型（見 [1913-玻爾原子模型.md](1913-玻爾原子模型.md)）；1926 年薛丁格方程把量子假說升級為微觀世界的完整數學理論（見 [1926-薛丁格方程.md](1926-薛丁格方程.md)）。金觀濤所說「一個理論成為另一個理論的數學工具」，普朗克的 $h$ 是二十世紀最大的案例。

## 結案報告

普朗克量子假說的遺產：

1. **紫外災難解除**——普朗克定律在長短波兩端都與數據吻合，經典物理的死刑判決被撤回，代之以量子物理的新憲法。
2. **$h$ 成為自然常數**——微觀世界的貨幣單位，此後每一條量子理論都以它計價。
3. **技術需求倒逼理論的完整鏈**——燈絲標準化（技術）⇒ 黑體光譜測量（實驗）⇒ $E=h\nu$（理論）。README 九通道表中「黑體輻射測量的工業需求⇒普朗克量子假說」即此條。
4. **保守者的革命**——普朗克本人花了多年試圖把量子假說「馴化回經典框架」而失敗；科學的邏輯一旦啟動，連發明者也無法叫停。

## 促進鏈分析

本篇兼跨**實驗⇒理論**與**理論⇒理論**，並含完整**技術⇒實驗⇒理論**鏈，涉及九通道中的四條：

- **技術⇒實驗**：德國電燈工業的測量需求（技術）催生 PTR 的黑體光譜精密測量（實驗）。
- **實驗⇒理論**：光譜數據與瑞利-金斯公式的矛盾（紫外災難，實驗）逼出 $E=h\nu$（理論）。
- **理論⇒理論**：量子假說（1900）成為光量子（1905）、玻爾原子（1913）、薛丁格方程（1926）的數學種子。
- **實驗⇒實驗**：PTR 的黑體空腔測量方法成為此後一切輻射計量的樣板（含 1965 年宇宙微波背景的測量傳統，見 [1965-宇宙微波背景.md](1965-宇宙微波背景.md)）。

## 證據與工具

```python
# 用 Python 重演「紫外災難」：普朗克定律 vs 瑞利-金斯公式在短波的發散

import numpy as np

h = 6.62607015e-34   # 普朗克常數 J·s
c = 2.99792458e8     # 光速 m/s
kB = 1.380649e-23    # 玻耳茲曼常數 J/K
T = 5000.0           # 黑體溫度 K（接近燈絲工作溫度）

nu = np.logspace(12, 16, 400)   # 頻率軸：1 THz ~ 10^16 Hz

# 瑞利-金斯公式（經典）：B = 2 nu^2 kB T / c^2 —— 短波無界發散
B_RJ = 2 * nu**2 * kB * T / c**2

# 普朗克定律（量子）：B = 2 h nu^3 / c^2 / (exp(h nu / kB T) - 1)
B_P = 2 * h * nu**3 / c**2 / (np.expm1(h * nu / (kB * T)))

# 找出兩者開始背離的頻率（比值超過 2）
ratio = B_RJ / B_P
cross = nu[np.argmax(ratio > 2)]
print(f"T = {T:.0f} K")
print(f"瑞利-金斯與普朗克定律開始嚴重背離的頻率 ≈ {cross:.2e} Hz")
print(f"（背離點在長波段，隨頻率升高差距指數放大，進入紫外區後徹底發散）")
print(f"在 10^16 Hz 處：經典預言 {B_RJ[-1]:.2e}，量子預言 {B_P[-1]:.2e}")
print(f"經典公式多算了 {B_RJ[-1]/B_P[-1]:.1e} 倍 —— 這就是『紫外災難』")

# 維恩位移定律：峰值頻率隨溫度移動（燈絲標準化的核心公式）
lam_max = 2.897771955e-3 / T
print(f"\n維恩峰值波長 ≈ {lam_max*1e9:.0f} nm（可見光區，燈絲效率設計的依據）")
```
