# 1926 薛丁格方程與量子力學

## 案發現場

1925 年前後的物理學，是一樁證據堆積如山、卻沒有統一理論的懸案：

- 黑體輻射逼出普朗克的能量子假說（1900）；
- 光電效應逼出愛因斯坦的光量子（1905）；
- 氫原子光譜的規則線系逼出玻爾的量子化軌道（[1913-玻爾原子模型.md](1913-玻爾原子模型.md)）；
- 康普頓散射（1923）證明光量子有動量；
- 德布羅意（Louis de Broglie, 1892–1987）1924 年在博士論文中大膽反推：**既然光是波也是粒子，電子為何不能也是波？** λ = h/p。

每個實驗都在尖叫「微觀世界不遵守牛頓力學」，但沒有人能把所有證物放進同一套數學框架。誰來結案？

## 偵查過程

兩條完全不同的偵查路線，在同一年（1925–1926）抵達同一個兇手——這是科學史上罕見的「雙重偵破」。

**路線一：海森堡的矩陣力學（1925 年 7 月）。** 海森堡（Werner Heisenberg, 1901–1976）主張：電子軌道根本**不可觀測**，物理學只能處理可觀測量——光譜線的頻率與強度。他與波恩（Born）、約丹把可觀測量排成陣列，發現陣列相乘**不可交換**（pq ≠ qp）。波恩認出這是矩陣代數，矩陣力學誕生。

**路線二：薛丁格的波動力學（1926 年 1 月）。** 薛丁格（Erwin Schrödinger, 1887–1961）從德布羅意的物質波出發，追問：如果電子是波，那它滿足什麼**波動方程**？他度假到阿爾卑斯山，幾個月內連發四篇論文，寫下如今刻在一切量子物理入口的方程：

$$i\hbar\frac{\partial}{\partial t}\Psi = \hat{H}\Psi$$

對定態問題，這化為類似光學波動方程的「本徵值問題」。薛丁格把它代入氫原子：量子化**不再需要人為假設**（如玻爾的「角動量必須是 ħ 的整數倍」），而是從「波必須在軌道上駐波、自我干涉」自動湧出。能階 Eₙ = −13.6 eV/n² 與氫光譜完全吻合。

**偵查高潮：兩套理論是同一個。** 薛丁格 1926 年 3 月證明：矩陣力學與波動力學在數學上**等價**——兩條路線從相反的哲學（「只有粒子」vs「只有波」）出發，卻破獲同一案件。波恩再補上關鍵解讀：|Ψ|² 是**機率密度**——電子不在確定軌道上，只在機率雲中。

海森堡 1927 年接著推出「不確定原理」：Δx·Δp ≥ ħ/2。位置與動量不可同時精確測量——這不是儀器不夠好，而是自然界的內建極限。愛因斯坦終生不服，留下「**上帝不擲骰子**」的名言，與波恩的反擊「別告訴上帝該怎麼做」之間的辯論，至今未熄。

## 結案報告

量子力學屬於迴路的**理論**環節——它是微觀世界的完整數學理論，是繼 [1687-牛頓原理.md](1687-牛頓原理.md)、[1865-麥克斯韋方程組.md](1865-麥克斯韋方程組.md)、[1915-廣義相對論.md](1915-廣義相對論.md) 之後的第四大理論支柱。其遺產：

1. **微觀世界有了自己的牛頓**——從此化學鍵、光譜、半導體、核物理全部有理論可依。
2. **理論直接孵化技術**——量子力學寫完不到二十年，就釋放出 [1947-電晶體.md](1947-電晶體.md)（能帶理論）、[1960-雷射.md](1960-雷射.md)（受激輻射）——理論到應用的等待時間跌入歷史新低。
3. **機率進入物理學**——決定論的宇宙觀被改寫，「測量」本身成為理論的一部分。
4. **雙路線匯合的方法論教訓**——重大理論常被多條獨立路徑同時抵達，這是「理論—實驗—技術」迴路成熟的標誌：證據夠多時，破案只是時間問題。

## 證據與工具

$$\text{氫原子能階：}\ E_n = -\frac{13.6\ \text{eV}}{n^2},\qquad \frac{1}{\lambda} = R\left(\frac{1}{n_1^2}-\frac{1}{n_2^2}\right)$$

```python
# 偵查證物一：薛丁格方程對氫原子的裁決——巴耳末系譜線
import math
R = 1.0967758e7  # 里德堡常數 (1/m)，實驗值

print("--- 氫原子巴耳末系（n2=3,4,5,6 → n1=2，可見光）---")
for n2 in [3,4,5,6]:
    lam = 1/(R*(1/4 - 1/n2**2)) * 1e9   # 奈米
    print(f"Hα n={n2}: λ = {lam:.1f} nm")

# 656.3 / 486.1 / 434.0 / 410.2 nm —— 與實測光譜完全吻合
print("薛丁格方程自動湧出能階，無需玻爾的人為量子化假設")

# 偵查證物二：德布羅意物質波——電子的波長
h, m, c = 6.626e-34, 9.109e-31, 2.998e8
V = 100  # 加速電壓 100 V
p = math.sqrt(2*m*1.602e-19*V)     # 動量
lam_e = h/p * 1e9
print(f"\n100 V 電子的德布羅意波長：{lam_e:.3f} nm ≈ 原子間距 → 可以繞射！")
```
