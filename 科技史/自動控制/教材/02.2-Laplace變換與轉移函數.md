# 02.2 Laplace 變換與轉移函數

## 本章導讀

微分方程難解，但有一個轉換能把「微積分」變成「代數」——這就是 Laplace 變換。
它讓解微分方程像解 $3x + 5 = 0$ 一樣簡單，也催生了經典控制的核心語言：**轉移函數**。

## 淺顯說明

Laplace 變換像一台翻譯機：把「時間世界」的函數 $f(t)$ 翻譯成「$s$ 世界」的 $F(s)$。
翻譯的魔法在於：

- 時間世界的「微分」$\to$ $s$ 世界的「乘 $s$」
- 時間世界的「積分」$\to$ $s$ 世界的「除以 $s$」

於是微分方程變成代數方程，解完再翻譯回來即可。

## 正規理論

### 定義

函數 $f(t)$ 的 Laplace 變換：

$$
F(s) = \mathcal{L}\{f(t)\} = \int_0^\infty f(t)\, e^{-st}\, dt, \qquad s = \sigma + j\omega
$$

### 關鍵性質

| 性質 | 公式 |
|------|------|
| 微分 | $\mathcal{L}\{\dot f\} = sF(s) - f(0)$ |
| 二階微分 | $\mathcal{L}\{\ddot f\} = s^2F(s) - sf(0) - \dot f(0)$ |
| 積分 | $\mathcal{L}\left\{\int_0^t f\,d\tau\right\} = \dfrac{F(s)}{s}$ |
| 延遲 | $\mathcal{L}\{f(t-\tau)\} = e^{-s\tau}F(s)$ |
| 指數衰減 | $\mathcal{L}\{e^{-at}f(t)\} = F(s+a)$ |
| 線性 | $\mathcal{L}\{\alpha f + \beta g\} = \alpha F + \beta G$ |

### 轉移函數的誕生

對線性常係數微分方程（零初始條件）：

$$
a_n y^{(n)} + \cdots + a_1\dot y + a_0 y = b_m u^{(m)} + \cdots + b_0 u
$$

兩邊取 Laplace 變換，微分變乘 $s$：

$$
(a_ns^n + \cdots + a_1 s + a_0)\,Y(s) = (b_ms^m + \cdots + b_0)\,U(s)
$$

得**轉移函數**——輸出與輸入在 $s$ 世界的比值：

$$
G(s) = \frac{Y(s)}{U(s)} = \frac{b_ms^m + \cdots + b_0}{a_ns^n + \cdots + a_0}
$$

- 分母的根 = **極點**（系統的「共振頻率」，決定動態）；
- 分子的根 = **零點**（系統的「消音頻率」）。

### 反變換：部分分式

解出 $Y(s) = G(s)U(s)$ 後，用部分分式拆開，查表反變換：

$$
Y(s) = \sum_i \frac{c_i}{s - p_i} \;\Longleftrightarrow\; y(t) = \sum_i c_i e^{p_i t}
$$

**極點 $p_i$ 的實部決定命運**：$\Re(p_i) < 0$ 衰減，$\Re(p_i) > 0$ 爆炸。

## 簡易範例：一階系統的階梯響應

$\dot y + 2y = u$，$u(t) = 1$（階梯輸入），$y(0) = 0$。

1. 取 Laplace：$(s + 2)Y = \dfrac{1}{s}$。
2. 解代數：$Y = \dfrac{1}{s(s+2)} = \dfrac{1/2}{s} - \dfrac{1/2}{s+2}$（部分分式）。
3. 反變換：

$$
y(t) = \frac{1}{2}\left(1 - e^{-2t}\right)
$$

極點 $s = -2$：時間常數 $\tau = 1/2$，$t = \tau$ 時達到 $63\%$，$t = 4\tau$ 時達到 $98\%$。

三步驟「取 Laplace → 解代數 → 反變換」，就是經典控制的通用解法。
