# 1803 Dalton 原子說

## 案發現場

十九世紀初的曼徹斯特，定量革命已接近頂點：波以耳確立了元素判準（[1661-Boyle元素概念.md](1661-Boyle元素概念.md)），拉瓦節確立了質量守恆與元素表（[1789-Lavoisier質量守恆.md](1789-Lavoisier質量守恆.md)），普魯斯特確立了定比定律（[1799-Proust定比定律.md](1799-Proust定比定律.md)）。但一個終極問題仍然懸而未決：**物質到底由什麼構成？為什麼化學反應呈現出這些固定的計量關係？**

原子論古已有之——德謨克利特的古希臘原子說、伽桑狄與波以耳的微粒說——但都只是哲學思辨，沒有定量證據。哲學原子論回答不了關鍵問題：原子有多重？不同元素的原子有何不同？為什麼氫氧總是按固定的質量比化合成水？

誰接手這樁案件？**約翰·道耳頓（John Dalton, 1766–1844）**，英國坎伯蘭貧苦織工家庭出身、貴格會教徒、曼徹斯特的數學與自然哲學教師。他本人是色盲（他因此寫了第一篇關於色盲的科學論文，色盲因此一度被稱為「道耳頓症」），一生生活簡樸，卻擁有驚人的推理能力。這樁案件的重要性在於：道耳頓把原子論從哲學玄想變成**定量的科學理論**，開創了原子量表，是現代化學的真正奠基者。

## 偵查過程

道耳頓的偵查起點，出人意料地來自**氣象學**。

**第一步：從氣象觀測而來的靈感。** 道耳頓從 1787 年起堅持每日記錄氣象（一生記錄了約 20 萬筆觀測）。他研究大氣的性質時遇到一個謎：**空氣是氮、氧等多種氣體的混合物，為什麼它們不會按密度分層？** 按理說，重的二氧化碳應該沉在底部、輕的氫應該浮在頂部，但大氣卻是均勻混合的。道耳頓的解答是：**氣體由彼此獨立的微粒（原子）組成，不同氣體的微粒互不相斥，各自彌散**。這個解答把他引向微粒說，而氣象學的定量習慣則給了他測量原子相對重量的工具——「我從氣象學進入化學，」他後來說。

**第二步：提出原子說的基本假說（1803 年）。** 道耳頓在 1803 年向曼徹斯特文哲學會報告他的原子說，1808 年在《化學哲學的新體系》中完整闡述。基本假說有四：

1. **物質由原子構成**：一切物質由極小的、不可分割的微粒——原子——組成；
2. **同元素原子同質量**：同一元素的原子完全相同（質量與性質），不同元素的原子質量不同；
3. **化學反應 = 原子的重排**：化學變化只是原子的分離、結合與重排，原子本身不生不滅（呼應質量守恆）；
4. **化合以簡單整數比結合**：化合物由不同原子按簡單整數比結合，如 A+B、A+2B、A+3B。

第四條假說是關鍵：它把普魯斯特的定比定律從「經驗規則」提升為「原子結構的必然推論」。若水由 2 個氫原子配 1 個氧原子構成，則水中氫氧質量比恆為：

$$\frac{m_{\text{H}}}{m_{\text{O}}} = \frac{2 \times m_{\text{H原子}}}{1 \times m_{\text{O原子}}} = \text{常數}$$

**第三步：倍比定律——原子說的獨立檢驗。** 道耳頓的推理同時導出一條可獨立檢驗的定律：若兩元素能形成多種化合物，則**在一份固定質量的 A 中，與 A 化合的 B 的質量成簡單整數比**：

$$\frac{m_B^{(1)}}{m_B^{(2)}} = 1:2:3\cdots \text{（簡單整數比）}$$

因為如果 A+1B 與 A+2B 都存在，則第二種化合物中 B 的質量必然是第一種的兩倍——原子計數的必然結果。道耳頓以碳的氧化物（$\mathrm{CO}$ 與 $\mathrm{CO_2}$）驗證：對同質量的碳，氧的質量比為 $16:32 = 1:2$；以銅的氧化物（$\mathrm{Cu_2O}$ 與 $\mathrm{CuO}$，見 [1799-Proust定比定律.md](1799-Proust定比定律.md)）驗證：對同質量的銅，氧質量比為 $1:2$。整數比成立——原子說通過了獨立檢驗。

**第四步：第一張原子量表。** 道耳頓的天才還在於：既然無法稱量單一原子，他提出**相對原子量**的概念——以最輕的氫為標準（令 $\mathrm{H} = 1$），測定其他元素的相對質量。由化合物的質量比反推原子量：例如水中氫氧質量比為 $1:8$，若水為 H+O 結構（道耳頓假設水由 1 個氫配 1 個氧——這是他的誤判，正確是 $\mathrm{H_2O}$），則氧原子量為 8；正確結構下為 16。道耳頓 1803 年的第一張原子量表雖然數值多有錯誤（因為他缺乏「分子由幾個原子構成」的資訊——這要等亞佛加厥假說與給呂薩克定律解決，見 [1808-GayLussac氣體定律.md](1808-GayLussac氣體定律.md)），但**原子量表這個概念本身是革命性的**：化學第一次有了量度基本物質的統一尺子。此後貝采利烏斯以更精確的分析修正原子量（1810–1826），康尼查羅以亞佛加厥假說徹底理順原子量（1860），最終導向門得列夫的週期表。

**第五步：用符號表示原子。** 道耳頓為每種元素設計了圓圈符號（帶不同內部記號的圓），化合物寫成符號的組合。雖然他的符號系統很快被貝采利烏斯的字母記法（H、O、Cu……）取代，但「用符號表達原子的組合」是他首創。

## 結案報告

道耳頓原子說的遺產，是整個現代化學的根基。

**第一，原子論成為科學理論**：從哲學玄想到定量理論，原子說讓化學擁有了物質結構的統一圖像。今天的原子–分子學說、化學鍵理論、核化學、量子化學，都站在道耳頓的地基上。

**第二，倍比定律與定比定律**成為原子說的兩大實驗支柱，也是化學計量教學的經典內容。

**第三，原子量表**開啟了化學計量的傳統：貝采利烏斯的精確原子量、康尼查羅的理順、門得列夫的週期表（1869）、摩爾概念（19 世紀末），直到今天的 118 種元素週期表——一切的起點是道耳頓以氫為 1 的那張小表。

**第四，科學方法的教訓**：道耳頓的原子量表因「不知分子結構」而多有錯誤，這顯示原子說還缺一塊拼圖——**分子的原子數**。這個缺口由給呂薩克的氣體化合體積定律與亞佛加厥假說補上（見 [1808-GayLussac氣體定律.md](1808-GayLussac氣體定律.md)），但亞佛加厥假說被冷落了近半世紀，成為化學史上另一樁著名的懸案。

道耳頓本人終身簡樸，在曼徹斯特教書、做氣象記錄、研究化學。他被皇家學會授予勳章，晚年享有盛名。他留給化學的最深印記是：**世界的多樣性，來自原子的簡單計數。** 一位色盲的織工之子，用自己的眼睛看不出顏色，卻看出了萬物的原子。

## 證據與工具

**倍比定律的重現：** 對固定 1.000 g 碳，在 $\mathrm{CO}$ 與 $\mathrm{CO_2}$ 中結合的氧質量分別為

```python
# 道耳頓倍比定律重現：對同質量的元素 A，化合的 B 質量成簡單整數比

M = {"C": 12.011, "O": 15.999, "Cu": 63.546, "H": 1.008, "Fe": 55.845}

def oxygen_per_fixed_carbon(mass_C):
    """固定 1 g 碳，在 CO 與 CO2 中結合的氧質量"""
    # CO: 12.011 g C 配 15.999 g O；CO2: 12.011 g C 配 2*15.999 g O
    o_in_CO  = mass_C * (M["O"] / M["C"])
    o_in_CO2 = mass_C * (2*M["O"] / M["C"])
    return o_in_CO, o_in_CO2

co, co2 = oxygen_per_fixed_carbon(1.0)
print(f"固定 1.000 g 碳：")
print(f"  在 CO  中結合氧 {co:.3f} g")
print(f"  在 CO2 中結合氧 {co2:.3f} g")
print(f"  氧質量比 CO:CO2 = {co/co2:.3f} ≈ 1:2 —— 簡單整數比！（倍比定律）")

# 銅的兩種氧化物：Cu2O 與 CuO，固定 1 g 銅
o_in_Cu2O = 1.0 * (M["O"] / (2*M["Cu"]))
o_in_CuO  = 1.0 * (M["O"] / M["Cu"])
print(f"\n固定 1.000 g 銅：")
print(f"  在 Cu2O 中結合氧 {o_in_Cu2O:.3f} g")
print(f"  在 CuO  中結合氧 {o_in_CuO:.3f} g")
print(f"  氧質量比 = {o_in_CuO/o_in_Cu2O:.3f} ≈ 2:1 —— 又是整數比！")
```

**道耳頓第一張原子量表：以 H=1 為標準。** 由水的合成實驗（Cavendish：氫氧質量比約 1:8）反推氧的原子量，結果取決於對水結構的假設：

$$\text{若水為 } \mathrm{HO}: A_{\mathrm{O}} = \frac{8}{1} \times 1 = 8; \qquad \text{若水為 } \mathrm{H_2O}: A_{\mathrm{O}} = \frac{8}{1/2} \times 1 = 16$$

道耳頓因假設水為 $\mathrm{HO}$ 而取 8，正確值是 16——原子說缺的最後一塊拼圖，要等 Gay-Lussac 氣體化合體積定律與 Avogadro 假說補上。他 1803 年的部分原子量表（以 H=1）與現代值對照：

| 元素 | 道耳頓 1803 | 現代值 |
|---|---|---|
| 氫 | 1 | 1.008 |
| 氮 | 5 | 14.007 |
| 碳 | 5 | 12.011 |
| 氧 | 7 | 15.999 |
| 磷 | 9 | 30.974 |
| 硫 | 13 | 32.06 |

概念革命性十足，數值待修正——這正是科學理論演進的常態。
