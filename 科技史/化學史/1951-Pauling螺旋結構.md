# 1951 Pauling α-螺旋

## 案發現場

1940 年代，生物化學出現了一個巨大的謎團：**蛋白質到底是什麼形狀？** 化學家已知道蛋白質是由胺基酸以肽鍵 $\mathrm{-CO-NH-}$ 串成的長鏈（Fischer 的工作），也知道蛋白質有驚人的專一功能（酶、抗體），還發現蛋白質晶體能產生清晰的 X 射線繞射圖案（Astbury 的羊毛與角蛋白照片）。但從繞射圖案到三維結構之間有一道鴻溝：沒有人知道多肽鏈在空間中到底怎麼摺疊。

為什麼這是重大懸案？因為一個流行的觀點當時佔上風：「蛋白質是不規則的膠體」，結構毫無秩序可言。如果真是如此，酶的專一性、生物的精巧就無法用結構解釋。另外，Astbury 的繞射圖顯示角蛋白有週期性重複——這暗示結構是有規律的，但規律是什麼？

加州理工學院的鮑林（Linus Pauling, 1901–1994）——那位用雜化軌域與電負度統一了鍵結理論的量子化學大師（見 [1931-Pauling價鍵理論.md](1931-Pauling價鍵理論.md)）——在 1948 年之後把砲口轉向了生物巨分子。這場偵查也成為他與劍橋的 Watson-Crick 競賽的前哨（見 [1953-WatsonCrickDNA.md](1953-WatsonCrickDNA.md)）。

## 偵查過程

鮑林的偵查方法是典型的「理論偵探」：**不靠反覆試算，而是用結構化學的基本原理先推理出候選結構，再與實驗比對**。

**第一步：肽鍵的精確幾何。** 鮑林與 Corey 多年來用 X 射線繞射測量了胺基酸與小肽的精確結構，得到鐵一般的數據：肽鍵 $\mathrm{C-N}$ 鍵長為 1.32 Å（介於單鍵 1.47 Å 與雙鍵 1.27 Å 之間）——**肽鍵有部分雙鍵性**，因此肽基團 $\mathrm{-CO-NH-}$ 六個原子共平面、不能自由旋轉。可旋轉的只有 Cα 兩側的鍵。

**第二步：氫鍵作為摺疊的驅動力。** 鮑林深信鏈上的 $\mathrm{N-H}$ 與 $\mathrm{C=O}$ 之間能形成氫鍵（$\mathrm{N-H \cdots O}$，鍵能約 20 kJ/mol），這是長鏈摺疊成穩定規則結構的自然驅動力。問題變成：**怎麼捲，才能讓每個 $\mathrm{N-H}$ 與某個 $\mathrm{C=O}$ 剛好對上氫鍵，同時滿足肽鍵的平面性與鍵角？**

**第三步：紙上的靈感（破案關鍵）。** 1948 年，鮑林在牛津養病期間，用紙畫出肽基團的平面圖、剪下來、一個個摺疊拼接——這是「分子紙模型」的偵查手法。他發現：把多肽鏈捲成**右手螺旋**，每圈約 3.6 個胺基酸殘基、螺距 5.4 Å（每殘基沿軸上升 1.5 Å），氫鍵沿螺旋軸方向恰好一個接一個對上——每個殘基的 $\mathrm{N-H}$ 與其後第四個殘基的 $\mathrm{C=O}$ 形成氫鍵，氫鍵幾乎與螺旋軸平行。這就是 $\alpha$-螺旋（alpha helix）：

$$\text{每圈殘基數} = 3.6, \quad \text{螺距} = 5.4\ \text{Å}, \quad \text{R 基團指向螺旋外側}$$

關鍵的靈感還有一個：鮑林打破「整數殘基」的先入之見（Astbury 曾假設每圈 2 或 3 個殘基），接受非整數的 3.6——這是理論偵探勝過經驗主義的一步。1951 年，鮑林、Corey 與 Branson 發表 $\alpha$-螺旋與 $\beta$-摺板結構；同年 Perutz 的馬毛角蛋白 X 射線繞射圖上出現了 5.4 Å 的強反射——**理論預言的螺距在實驗中現形**，全案告破。

## 結案報告

$\alpha$-螺旋是分子生物學的第一塊基石：

1. **蛋白質結構的規則性確立**：「膠體說」破產，蛋白質有精確、可預測的三維結構——酶的事變成「結構決定功能」，結構生物學誕生。
2. **二級結構概念**：$\alpha$-螺旋與 $\beta$-摺板成為蛋白質二級結構的兩大基本元件，Kendrew 與 Perutz 於 1958–60 年解出肌紅蛋白與血紅蛋白的完整結構，處處可見 $\alpha$-螺旋。
3. **理論偵探的方法學**：先原理後實驗的推理模式，直接啟發了 Watson 與 Crick 對 DNA 的偵查——鮑林 1953 年甚至提出了一個（錯誤的）DNA 三螺旋模型，這個「前哨戰」刺激了劍橋團隊加速（見 [1953-WatsonCrickDNA.md](1953-WatsonCrickDNA.md)）。
4. **氫鍵的地位**：氫鍵從邊角概念變成生物結構的核心力量——DNA 的雙螺旋、蛋白質的摺疊、水的性質，氫鍵無所不在。

## 證據與工具

**α-螺旋的幾何推理：** 鮑林與科里把肽鍵視為剛性平面（酰胺共振），在精確鍵長鍵角的限制下拼合分子模型：主鏈繞軸捲成螺旋，每個殘基沿軸上升 1.5 Å、旋轉 100°，故每圈 3.6 個殘基：

$$\text{每殘基旋轉角} = \frac{360^\circ}{3.6} = 100^\circ, \qquad \text{螺距} = 3.6 \times 1.5\ \text{Å} = 5.4\ \text{Å}$$

**非整數的 3.6 是關鍵。** 若每圈是整數個殘基（如 Astbury 假設的 2 或 3 個），在平面肽鍵與鍵角的限制下，N–H 與 C=O 的指向無法一一對上；3.6 讓第 $i$ 殘基的 $\mathrm{N-H}$ 恰好指向第 $i+4$ 殘基的 $\mathrm{C=O}$，氫鍵幾乎與螺旋軸平行，整條主鏈由一串同向氫鍵鎖定：

$$\mathrm{C{=}O}_i \cdots \mathrm{H{-}N}_{i+4}$$

**理論與實驗撞出的數字：**

| 參數 | 模型值 | 來源／驗證 |
|---|---|---|
| 每殘基上升量 | 1.5 Å | Perutz 角蛋白繞射的 1.5 Å 子午線反射 |
| 螺距 | 5.4 Å | 1951 年 Perutz 的馬毛角蛋白繞射出現 5.4 Å 強反射 |
| 每圈殘基數 | $3.6 = 5.4/1.5$（非整數） | 兩個繞射值相除即得——模型自洽 |
| 每殘基旋轉角 | $360^\circ/3.6 = 100^\circ$ | 幾何推論 |
| 氫鍵模式 | $i \rightarrow i+4$ | N–H···O=C，與螺旋軸平行 |

螺距恰為 $3.6 \times 1.5$ ——模型的兩個自由參數不是拼湊，而是被肽鍵幾何與繞射數據同時鎖死。α-螺旋是史上第一個由化學原理精確預言、隨即被繞射證實的生物巨分子結構。
