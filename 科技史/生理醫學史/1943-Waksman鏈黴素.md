# 1943 - Waksman 鏈黴素（土壤裡的抗生素工廠）

## 案件摘要
1943 年，美國羅格斯大學的 Selman Waksman 團隊（研究生 Albert Schatz 主導實驗）
從**土壤放線菌**（Streptomyces griseus）中分離出**鏈黴素 (streptomycin)**——
第一個對抗**結核**有效的抗生素。
**青黴素（黴菌）只對革蘭氏陽性菌有效——結核（革蘭氏陰性、抗酸）無解**——
鏈黴素補上了這塊拼圖。
**土壤 = 抗生素的寶庫**：Waksman 系統性篩選上萬個土壤微生物，
之後的新黴素、四環素、鏈黴素家族——**土壤微生物學的工業化**。
（1952 年諾貝爾生理醫學獎——與 Schatz 的功勞之爭。）

## 前因 -- 為什麼會有這個案子
- **結核的無解**：Koch 1882 年偵破結核桿菌（見 `1882-Koch結核桿菌.md`），
  但**61 年後仍無藥**——結核桿菌的**蠟質細胞壁**（分枝菌酸）讓青黴素無法穿透、
  革蘭氏陽性的細胞壁靶點（肽聚糖）也不適用。**細胞壁是兇手的護甲。**
- **Waksman 的土壤先驗**：他是土壤微生物學家（放線菌的專家）——
  他早在 1940 年就主張：**土壤中的微生物互相對抗（拮抗作用）——
  土壤是天然的化學戰場**——**抗生素 = 微生物的化學武器**。
- **Schatz 的偵探直覺**：23 歲的研究生 Schatz 執行 Waksman 的篩選程序——
  **從土壤樣本逐一分離放線菌、測試抗菌譜**——
  數百個樣本中的**灰鏈黴菌**（雞的喉嚨分離株）勝出——**鏈黴素現形。**

## 線索與推理 -- 數學式、程式、理論

### 核心推理：拮抗作用 = 土壤的化學戰場
Waksman 的理論（抗生素的生態學）：
$$\text{土壤微生物} \xrightarrow{\text{互相對抗}} \text{抗生素（化學武器）}.$$
- 黴菌（青黴）分泌青黴素對抗細菌（Fleming 1928 的觀察）
- 放線菌（鏈黴菌）分泌**鏈黴素、四環素、新黴素**……——**放線菌是最大的武器庫**
  $$\text{抗生素的來源分佈}： \text{放線菌 } \sim 70\%， \quad \text{黴菌 } \sim 20\%， \quad \text{其他 } 10\%.$$
**系統篩選的工業化**：Waksman 的程序 = **土壤取樣 → 分離 → 抗菌譜測試 → 提純**——
**Ehrlich 的 606 篩選（1910）+ Domagk 的染料篩選（1932）的微生物版**——
之後的抗生素黃金時代（1943–1962，**20 餘種新抗生素**）全部用這個程序。

### 核心推理二：鏈黴素的機制
鏈黴素與青黴素的機制對比：
| 藥物 | 靶點 | 機制 |
|------|------|------|
| 青黴素 | 細胞壁（肽聚糖交聯） | 抑制合成 → 裂解 |
| **鏈黴素** | **核糖體 30S（蛋白質合成）** | **誤讀密碼 → 蛋白質錯誤 → 死亡** |
| 磺胺 | 葉酸代謝 | 競爭抑制 |
**鏈黴素 = 第一個攻擊「蛋白質合成」的抗生素**——
**核糖體成為抗生素的大靶點**（四環素、紅黴素、慶大霉素……全部攻擊核糖體）——
**細菌核糖體 70S vs 人類 80S**——**結構差異 = 選擇性毒殺**（Ehrlich 的公式）。

### 抗生素黃金時代（1943–1962）
| 年份 | 抗生素 | 來源 |
|------|--------|------|
| 1943 | 鏈黴素 | 灰鏈黴菌 |
| 1947 | 新黴素 | 鏈黴菌 |
| 1948 | 金黴素（四環素） | 金鏈黴菌 |
| 1952 | 紅黴素 | 紅鏈黴菌 |
| 1957 | 制黴菌素 | 鏈黴菌 |
| 1962 | 頭孢菌素 | 黴菌 |

## 結案 -- 後果與影響
- **結核的解藥**：1944 年首例（Patricia 病人）成功——
  結核從絕症變成可治——**Koch 1882 年偵破的兇手，62 年後被逮捕**。
  但**抗藥性**（MDR-TB）迅速出現——**單一用藥 = 天擇的加速器**
  （Fleming 1945 的警告）——**雞尾酒療法（多藥聯合）成為結核治療的標準**。
- **抗生素的黃金時代**：1943–1962 年 20 餘種新抗生素——
  **放線菌的土壤寶庫被開採殆盡**（之後的新抗生素斷層 40 年——
  2015 年 teixobactin 是下一個希望）。
- **土壤微生物學的工業化**：Waksman 的篩選程序 = 抗生素工業的標準流程——
  Merck、Pfizer、Lilly 全部參與（與學界合作）——**學產業的聯合開發**。
- **功勞之爭**：Schatz 發現鏈黴素（實驗主導）、Waksman 領諾獎與專利——
  Schatz 訴訟勝訴（1950，獲得專利分成與公開聲明）——
  **導師與學生的功勞之爭 = 科學史的反覆劇目**（Banting/Macleod 1923 的迴響）。
- **Waksman 的定名**：他定義「抗生素 (antibiotic)」一詞（1942）——
  **「微生物產生的、對抗微生物的物質」**——**化學武器的語言成為醫學的語言。**
