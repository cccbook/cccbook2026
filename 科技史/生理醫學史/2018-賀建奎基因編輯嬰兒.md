# 2018 - 賀建奎的基因編輯嬰兒（偵破的倫理紅線）

## 案件摘要
2018 年 11 月，中國科學家**賀建奎**在香港基因組學峰會宣布：
**一對基因編輯雙胞胎（露露與娜娜）已誕生**——他用 **CRISPR-Cas9**
修改胚胎的 **CCR5 基因**（HIV 入侵的共受體），宣稱讓嬰兒**天生抗 HIV**。
**全球科學界的地震**——這是人類史上第一次**生殖系基因編輯**的活體產出，
**技術是偷來的、倫理是違反的、科學是存疑的**——
**賀建奎被中國法院判刑 3 年（2022 年出獄）**。
**這是偵破史的黑暗面：當偵破工具落入越界的偵探手中——CRISPR（2012）的倫理考試。**

## 前因 -- 為什麼會有這個案子
- **CRISPR 的成熟（2012–2017）**：CRISPR-Cas9 已能精準編輯體細胞（2013, Zhang）、
  **人類胚胎**（2015，中國學者首次編輯胚胎——但**不植入**、僅研究）——
  **技術的門檻已過，倫理的紅線還沒被跨越**——**「不植入」是全球的默契。**
- **全球的默契**：生殖系編輯（germline editing）——**編輯會傳給後代、
  不可撤回、影響未來世代**——全球共識：**生殖系編輯 = 紅線**
  （美國禁止聯邦資金、歐洲禁止、中國「不許植入」的潛規則）。
- **賀建奎的越界**：他是物理學博士出身的生物創業者（深圳南方科技大學副教授）——
  他用**假的倫理批准書**（偽造簽名）、**瞞騙受試夫妻**（隱瞞編輯事實）、
  **偷用 CRISPR 編輯胚胎並植入**——**三重違規**。
- **CCR5 的選擇**：CCR5 是 HIV 入侵 T 細胞的**共受體**——
  CCR5-Δ32 突變（32 bp 缺失）**天然抗 HIV**（北歐 10% 人口帶有）——
  **賀建奎想「人工製造」這個突變**——**但技術粗糙、脫靶與嵌合體風險高。**

## 線索與推理 -- 數學式、程式、理論

### 核心推理：生殖系編輯的風險
賀建奎案的技術與倫理偵查：
$$\text{生殖系編輯} = \text{編輯胚胎} \to \text{植入} \to \text{誕生} \to \text{突變傳給所有後代}.$$
- **嵌合體風險**：CRISPR 在**單細胞胚胎**編輯，但**部分細胞沒被編到**——
  **嬰兒體內混合編輯與未編輯細胞**（嵌合體, mosaic）——**編輯不完整 = 無效或混合**
- **脫靶風險**：全基因組的其他位置被誤剪——**未知的突變**傳給後代
- **CCR5 的未知代價**：CCR5-Δ32 **增加西尼羅病毒重症風險、可能影響認知**——
  **敲除一個基因的代價未知**——**「收益」（抗 HIV）遠小於風險（有其他防護）**

$$\frac{\text{收益}}{\text{風險}} = \frac{\text{抗 HIV（有替代：血液篩檢、藥物）}}{\text{嵌合體 + 脫靶 + 未知代價}} \ll 1.$$
**醫學倫理的判準**：當**有安全的替代方案**時（HIV 已有血液篩檢 + 母嬰阻斷 = 風險極低），
**生殖系編輯的正當性歸零**——**這是本案被判「越界」的醫學理由**（不只是倫理）。

### 核心推理二：科學界的審判
賀建奎案的直接後果：
| 後果 | 內容 |
|------|------|
| 中國判刑 | 2022 年判刑 3 年（非法行醫罪）+ 罰款 300 萬元 |
| 全球暫停 | 全球科學界呼籲**暫停生殖系編輯**（2018/11 的公開信） |
| 準則的誕生 | WHO 的**人類基因組編輯治理框架**（2021）——全球準則 |
| 學術封殺 | 賀建奎的論文被拒、大學解聘 |

**WHO 框架的誕生（2021）**：**治理框架 + 登記制度 + 監督機制**——
**生殖系編輯的全球規則被本案催生**（賀建奎 2018 的「負面偵破」——
**錯誤的偵破催生正確的規則**）。

## 結案 -- 後果與影響
- **倫理紅線的確認**：生殖系編輯 = 紅線——**全球共識被本案強化**——
  **可遺傳的編輯影響未來世代、不可撤回**——**「編輯嬰兒」的禁令從潛規則變成成文法**。
- **技術的透明化**：賀建奎案的教訓——**假倫理批准、隱瞞受試者**——
  **生殖醫學的登記與監督制度誕生**（WHO 框架、中國的新規）。
- **體細胞 vs 生殖系的分界**：**體細胞編輯（治療病人、不傳後代）= 合法**
  （CRISPR 藥物 Casgevy 2023 獲批——鐮刀型貧血）；**生殖系編輯 = 禁止**——
  **同一把剪刀，兩種用途、兩種倫理**——**分界線被本案劃清**。
- **CRISPR 的公道**：Doudna 與 Charpentier（2012）的技術本身無罪——
  **工具的偵破與工具的濫用是兩個案件**——**Doudna 此後轉向倫理倡導**
  （《A Crack in Creation》2017——技術的倫理自覺）。
- **歷史的定位**：賀建奎案 = **偵破史的黑暗面**——
  **偵破工具（CRISPR）落入越界偵探（賀建奎）手中**——
  **科學的倫理考試，第一次以活體嬰兒為賭注**——
  **失敗的考試催生了全球的規則**（Asilomar 1975 的正面先例 vs 2018 的負面教材）。
