# 1671 -- Jan de Witt 的年金定價：機率論第一次應用於金融

## 案件描述

1671 年，荷蘭大議長（Grand Pensionary，實質上的首相）Jan de Witt 發表《人命年金價值論》（Waardije van Lyf-renten）。這份文件做了一件前無古人的事：

> **用機率與期望值，為「以人命為抵押的年金」定價——機率論第一次被應用於金融商品。**

De Witt 既是數學家又是政治家——他為荷蘭政府發售終身年金（戰爭融資）時，發現政府一直用「拍腦袋」的價格（按年齡的粗略倍數），於是動手算出了「正確」的價格。

## 前因：荷蘭的黃金年代與戰爭融資

- 17 世紀的荷蘭是歐洲金融中心：阿姆斯特丹銀行（1609）、世界上第一家證券交易所（1602）、繁榮的公債與年金市場。
- 荷蘭政府長期以**終身年金**（life annuity）融資：投資人付一筆錢，政府每年付利息直到受保人去世。
- 當時的定價慣例：按年齡給固定的倍數（如 4–6 年購買力）——**沒有考慮死亡機率隨年齡的變化**。
- **線索一**：1662 年 Graunt 出版《死亡表》，用倫敦的死亡統計建構了第一張生命表——死亡機率第一次有了資料。
- **線索二**：1657 年 Huygens 的機率論專著傳入荷蘭（Huygens 就是荷蘭人）；1654 年 Pascal–Fermat 的期望值框架（見 [1654-PascalFermat賭金分配.md](1654-PascalFermat賭金分配.md)）已經就位。
- De Witt 是 Huygens 的朋友，把兩者結合：**用機率論 + 死亡資料，計算年金的期望現值**。

## 推理過程

### 線索一：年金的期望現值

De Witt 的推理：年金的價值 = 「每年給付的期望值」的折現和：

$$V_{\text{annuity}}(x) = \sum_{t=1}^{\infty} v^t \, p_x(t) \cdot C$$

其中：
- $C$：每年給付額
- $p_x(t)$：年齡 $x$ 的人再活 $t$ 年的機率（**生存機率**——來自生命表）
- $v = 1/(1+r)$：折現因子

**歷史意義**：這個公式是現代所有保險精算與年金定價的祖先——「**期望現值**」= 機率（生存）× 現值（折現）。

### 線索二：死亡率的「偵探式」假設

De Witt 沒有足夠的荷蘭死亡率資料，他做了精妙的近似：假設死亡率隨年齡**分段線性上升**（4 段年齡區間，各段不同的年死亡率）——這是**分段 mortality 曲線**的第一次使用。

他還計算了「兩條命」年金的定價（joint-life annuity）——兩個受保人中最後一位去世才停止給付：

$$p_{xy}(t) = 1 - (1 - p_x(t))(1 - p_y(t))$$

（用生存機率的互補關係處理聯合生命——這是違約相關建模（見 [2000-Li高斯Copula.md](2000-Li高斯Copula.md)）的數學祖先。）

### 線索三：與市場價格的對比

De Witt 用他的模型計算出：政府長期以「4 年購買力」賣出的年金，**實際期望現值遠高於賣價**——也就是政府一直在**賤賣**年金。他建議對年輕人賣更高的倍數（年輕人活得久，年金更值錢）。

**偵探的結論**：這是歷史上第一次「**用模型發現市場的錯誤定價**」——正是後來所有量化投資與套利的原型。

## 現代程式重現：年金定價

```python
import numpy as np

def annuity_value(age, mortality_rate, C, r, max_t=100):
    """De Witt 的年金定價：期望現值 = Σ v^t * p_x(t) * C"""
    v = 1 / (1 + r)
    p_survive = 1.0
    value = 0.0
    for t in range(1, max_t + 1):
        p_survive *= (1 - mortality_rate(age + t - 1))  # 逐年生存機率
        value += v**t * p_survive * C
    return value

def mortality_rate(age):
    """De Witt 式分段死亡率：隨年齡上升"""
    if age < 30:  return 0.015
    if age < 55:  return 0.025
    if age < 75:  return 0.050
    return 0.150

for age in [20, 40, 60, 70]:
    print(f"年齡 {age} 年金價值:", annuity_value(age, mortality_rate, C=100, r=0.04))
# 年齡越大年金越不值錢 — 模型第一次告訴政府「如何分齡定價」
```

## 後果

- **精算科學的誕生**：De Witt 的工作經 Huygens 與 Edmund Halley（1693 年的 Breslau 生命表）傳承，發展成現代精算科學。
- **保險業的數學化**：18 世紀的蘇格蘭寡婦基金（1748，兩位蘇格蘭牧師用數學定價）與 Equitable Life（1762，第一家科學定價的保險公司）直接建立在這條傳承上。
- **「模型發現錯誤定價」的原型**：De Witt 發現政府賤賣年金的邏輯，正是現代套利與量化投資（見 [2000-AlmgrenChriss最佳執行.md](2000-AlmgrenChriss最佳執行.md)）的祖先。
- **政治的悲劇**：1672 年（「災難年」Rampjaar），荷蘭被法國入侵，de Witt 被暴民私刑處死——他的一年金定價文件被遺忘近一世紀，直到 18 世紀才被重新發現。
- 盲點：死亡率資料不足（他用近似假設）；沒有考慮利率的隨機性（要等 1977 年的利率模型，見 [1992-HJM利率模型.md](1992-HJM利率模型.md)）。

## 偵探筆記

- 動機：政府「拍腦袋」賤賣年金
- 工具：期望現值、生命表、分段死亡率、聯合生命機率
- 遺產：精算科學、保險定價、「模型發現錯誤定價」的原型
- 盲點：資料不足的近似、利率的隨機性
