# 1494 -- Pacioli 複式簿記：讓商業「可稽核」的計算系統

## 案件描述

1494 年，義大利修士兼數學家 Luca Pacioli 在威尼斯出版《算術、幾何、比與比例概要》（Summa de arithmetica）——其中一章首次系統性地描述了**複式簿記**（double-entry bookkeeping）。這一章讓 Pacioli 被後世稱為「**會計學之父**」。

> **每一筆交易都記錄兩次：借方（debit）與貸方（credit），兩邊必須相等。**

這是金融史上第一次，用一個「**守恆律**」把商業行為變成可稽核、可彙總、可計算的系統。

## 前因：威尼斯與熱那亞的商業實務

- 13–15 世紀，威尼斯與熱那亞的商人已經**在實務中**使用複式簿記（現存最早的帳本是 1340 年熱那亞的 Massari 帳簿）——但技術散落在各家商號的內部傳承中，沒有系統性的文獻。
- 單式簿記（只記一邊）無法回答「我到底賺了多少」「誰欠我多少」——商業規模擴大後，記帳混亂成為成長的瓶頸。
- **線索**：Pacioli 是達文西的朋友與數學教師，他撰寫 Summa 的目的是彙總當時全部的數學知識。複式簿記那一章來自威尼斯商人的實務（他自己住過威尼斯商人家中，當過簿記教師）。

## 推理過程

### 線索一：守恆律——借貸必相等

複式簿記的核心是一個會計恆等式：

$$\text{資產} = \text{負債} + \text{權益}$$

以及每一筆交易的「借貸相等」：

$$\sum \text{借方} = \sum \text{貸方}$$

**偵探的推理**：這是金融史上第一個「守恆律」——就像物理學的能量守恆，任何「不一致」都立刻暴露錯誤或欺詐。**錯誤可以被偵測**，是商業可信度的基石。

### 線索二：商業行為的「狀態空間」表示

複式簿記把企業的全部經濟活動編碼成**帳戶的集合**（總帳 ledger），每筆交易是一個「狀態轉移」。以現代計算的語言：

- 帳戶 = 狀態變數
- 交易 = 狀態轉移（借貸各一，向量加法）
- 結帳（closing）= 彙總運算

**這是一個「可計算的商業系統」**：資產負債表與損益表就是系統狀態的投影。Pacioli 甚至規定了日記帳（journal）→ 總帳（ledger）→ 試算表（trial balance）的三段式流程——這正是「輸入 → 處理 → 輸出」的程式結構。

### 線索三：與 Fibonacci 的傳承

Pacioli 的 Summa 建立在 Fibonacci（1202，見 [1202-Fibonacci計算之書.md](1202-Fibonacci計算之書.md)）引進的阿拉伯數字之上——**沒有位值制的算術，複式簿記的直式加總不可行**。計算技術（1202）→ 稽核技術（1494）→ 金融市場，是三步的接力。

## 現代程式重現：複式簿記的守恆律檢查

```python
from collections import defaultdict

ledger = defaultdict(float)   # 帳戶 -> 餘額
entries = []                  # (借方帳戶, 貸方帳戶, 金額)

def record(debit, credit, amount):
    """每一筆交易記錄兩次：借貸各一 — Pacioli 的規則"""
    assert amount > 0
    ledger[debit]  += amount
    ledger[credit] -= amount
    entries.append((debit, credit, amount))

def trial_balance():
    """試算表：借貸總和必須相等（守恆律）"""
    return abs(sum(ledger.values())) < 1e-9

record("現金", "資本", 10000)          # 開業
record("存貨", "現金",  6000)          # 進貨
record("現金", "銷貨",  8000)          # 銷貨
record("銷貨成本", "存貨", 6000)       # 結轉成本

print("試算平衡:", trial_balance())    # True
print("本期損益:", ledger["銷貨"] + ledger["銷貨成本"])  # 2000
# 借貸守恆 → 商業行為可稽核、可彙總 — 1494 的核心思想
```

## 後果

- **會計成為一門專業**：複式簿記隨印刷術傳遍歐洲，成為商業的通用語言。
- **資本主義的可稽核基礎**：Sombart 等學者主張——**沒有複式簿記就沒有現代資本主義**。股權、債權、投資決策都需要可信的帳目。
- **公司財務的基礎**：MM 定理（1958，見 [1958-ModiglianiMiller定理.md](1958-ModiglianiMiller定理.md)）討論的「資本結構」、Markowitz 討論的「報酬與風險」，全部依賴可稽核的財務報表。
- **審計與欺詐偵測**：守恆律至今仍是審計的基石——著名的麥道夫騙局（2008）最終由無法產生真實的借貸對應而暴露。
- 盲點：複式簿記保證「內部一致」，不保證「反映真實」——帳可以做平但價值可以造假（Enron、2008 年的 mark-to-market 爭議）。

## 偵探筆記

- 動機：商業規模擴大後的記帳混亂
- 工具：守恆律、帳戶狀態空間、三段式流程（輸入→處理→輸出）
- 遺產：現代會計、審計、資本主義的可稽核基礎
- 盲點：內部一致 ≠ 反映真實——價值造假的空間
