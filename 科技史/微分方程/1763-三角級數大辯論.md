# 1763 三角級數大辯論

## 案發現場

1753 年，丹尼爾·伯努利（Daniel Bernoulli）在柏林科學院宣讀論文，提出一個大膽的主張：弦振動是無窮多個簡正模式的疊加，

$$
u(x,t) = \sum_{n=1}^{\infty} b_n \sin\frac{n\pi x}{L} \cos\frac{n\pi c t}{L}
$$

而且——**這樣的三角級數可以代表任何初始形狀**，無論多麼怪異。

這句話引爆了十八世紀數學界最著名的方法論大辯論。辯論三方陣容豪華：

- **丹尼爾·伯努利**：物理學家立場。弦的振動模式在實驗中真實可測（泛音列），疊加原理又成立，所以「任意振動 = 模式之和」應是物理真理。
- **尤拉（Euler）**：接受疊加原理，但反對三角級數的普適性。正弦函數是**解析的、以 $2L$ 為週期的奇函數**，無窮多個之和仍是週期的、平滑的——怎可能等於一個非週期、有尖角的「任意」曲線？
- **達朗貝爾（d'Alembert）**：最嚴格的反對者。他認為三角級數逐項二階可微，其和必然無限平滑，連尤拉允許的「有尖角的力學曲線」都被排除在外；而且係數 $b_n$ 的確定方式根本不清楚。

表面上辯的是「弦怎麼振動」，實際上辯的是一個更深的問題：**函數到底是什麼？** 是解析式子（尤拉的舊觀念），還是任何可以畫出來的曲線（尤拉的新觀念），還是只有夠平滑的才算（達朗貝爾）？這是一場**概念的危機**，也是「分析」這門學科自我定義的陣痛。

## 偵查過程

**第一步：雙方的論證邏輯。**

尤拉的反駁：若 $\varphi(x)$ 有尖角（例如 $|\cdot|$ 形狀），則 $b_n$ 需要衰減得極慢，級數才可能收斂出尖角；但尤拉認為「解析式的無窮和仍是解析式」，不可能產生非解析的尖角。此外，三角級數是 $2L$ 週期的，而初始形狀可以完全非週期——兩者怎會相等？

達朗貝爾的反駁：若級數 $\sum b_n \sin(n\pi x/L)$ 在整個區間上二階可導，則 $\varphi''$ 存在且連續，這排除了尤拉的尖角曲線；尤拉所謂「任意函數」在達朗貝爾眼中根本不是函數。

**第二步：辯論的僵局。** 三人通信往返（現存於歐拉全集與科學院檔案），誰也說不服誰。僵局的根源在於：十八世紀的**收斂理論**尚未誕生。沒有極限的嚴格定義，「無窮級數的和」這個概念本身就是含糊的——大家都在用一個尚未被理解的工具爭論它的適用範圍。

**第三步：Fourier 的破案關鍵（1807–1822）。**
半世紀後，傅立葉（Joseph Fourier）在研究熱傳導時（見下），用**積分**而非猜測來確定係數。對週期 $2\pi$ 的函數：

$$
f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty} \left( a_n \cos nx + b_n \sin nx \right)
$$

傅立葉的關鍵一步：兩邊乘 $\sin mx$ 後在 $[-\pi, \pi]$ 上積分，利用**正交性**：

$$
\int_{-\pi}^{\pi} \sin mx \sin nx \, dx = \begin{cases} \pi, & m = n \\ 0, & m \neq n \end{cases}
$$

於是所有項都消去，只剩一項：

$$
\boxed{\,b_n = \frac{1}{\pi} \int_{-\pi}^{\pi} f(x) \sin nx\, dx\,}
$$

這個公式對**任何可積的** $f$ 都有意義——包括有尖角的、非週期的（在區間上）函數。傅立葉親自算出：方波

$$
f(x) = \begin{cases} 1, & 0 < x < \pi \\ -1, & -\pi < x < 0 \end{cases}
$$

的展開是

$$
f(x) = \frac{4}{\pi} \left( \sin x + \frac{\sin 3x}{3} + \frac{\sin 5x}{5} + \cdots \right)
$$

級數的部份和確實逐步逼近方波，尖角處也不例外。丹尼爾·伯努利的直覺**贏了**。

**第四步：Dirichlet 的嚴格化（1829）。**
狄利克雷（Peter Gustav Lejeune Dirichlet）首次給出收斂的嚴格證明：若 $f$ 分段單調且有界，則傅立葉級數收斂到 $\frac{f(x^+) + f(x^-)}{2}$——在連續點收斂到函數值，在**跳躍點收斂到左右極限的平均**。尖角與跳躍都被合法化了。辯論至此完全結案：三角級數確實能表示極廣泛的一類「任意函數」，而「函數」一詞也在此過程中被重新定義為**任意對應關係**（Dirichlet 函數概念的現代化），不再是解析式子。

**第五步：概念的連鎖反應。** 為了處理級數收斂，Dirichlet、Riemann、Weierstrass 逐步建立起極限、積分（Riemann 積分，1854）、一致收斂的嚴格理論——**現代分析的整座大廈，竟是這場辯論的餘波**。

## 結案報告

這場持續七十餘年的辯論（1753–1829），最終以「伯努利直覺 + 傅立葉計算 + Dirichlet 嚴格化」的組合結案。其遺產：

1. **Fourier 分析成為數學物理的通用語言**：熱傳導方程、波動方程（[1747-dAlembert波動方程.md](1747-dAlembert波動方程.md)）、Laplace 方程（[1782-Laplace位勢方程.md](1782-Laplace位勢方程.md)）的邊值問題，全靠三角級數求解；
2. **「函數」概念的革命**：從解析式到任意對應，為實分析、集合論（Cantor 正是從傅立葉級數的唯一性問題走向集合論）鋪路；
3. **嚴格分析的誕生**：極限、收斂、積分的現代定義皆源於此；
4. **正交函數系與希爾伯特空間**：正交性的思想在二十世紀擴張為 $L^2$ 空間理論，傅立葉級數成為量子力學的數學基礎。

值得注意的是：三方**各有對的地方**。伯努利的物理直覺對了，尤拉對「解析函數的直觀」的懷疑方向對了（確實需要新的收斂概念），達朗貝爾的平滑性擔憂也不算全錯（逐項微分的確需要一致收斂）。科學史少有如此戲劇性的案例：一場誰也沒「全贏」的辯論，卻讓整個學科脫胎換骨。

## 證據與工具

以下程式重現傅立葉的「驗屍證據」：方波的三角級數部份和如何逐步逼近有尖角的方波。

```python
import numpy as np
import matplotlib.pyplot as plt

# 傅立葉方波展開：f(x) = (4/π) [sin x + sin 3x/3 + sin 5x/5 + ...]
x = np.linspace(-np.pi, np.pi, 1000)

def fourier_square(x, n_terms):
    """取前 n_terms 個奇次諧波的部份和"""
    s = np.zeros_like(x)
    for k in range(n_terms):
        n = 2 * k + 1                      # 只取奇數項：n = 1, 3, 5, ...
        s += np.sin(n * x) / n             # 係數 b_n = 4/(nπ)，公因子提出
    return 4 / np.pi * s

# 真正的方波（有尖角與跳躍！）
square = np.sign(np.sin(x))

# 畫出諧波數遞增時，部份和如何逼近方波
fig, axes = plt.subplots(2, 2, figsize=(10, 7), sharex=True, sharey=True)
for ax, n in zip(axes.flat, [1, 3, 10, 50]):
    ax.plot(x, square, "k--", lw=1, label="square wave")
    ax.plot(x, fourier_square(x, n), lw=1.5, label=f"{n} terms")
    ax.set_title(f"Fourier partial sum, N = {n}")
    ax.legend(loc="upper right", fontsize=8)
    ax.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig("fourier_square.png", dpi=120)
plt.show()

# 驗證正交性：∫ sin(mx) sin(nx) dx = π (m=n) 或 0 (m≠n)
xs = np.linspace(-np.pi, np.pi, 200000)
for m, n in [(1, 1), (1, 2), (3, 3), (2, 5)]:
    val = np.trapz(np.sin(m * xs) * np.sin(n * xs), xs)
    print(f"∫ sin({m}x)·sin({n}x) dx ≈ {val:.4f}  (理論值: {np.pi if m==n else 0:.4f})")

# 驗證 Gibbs 現象：跳躍點附近的過衝約為 9% ，不隨 N 增大而消失
N = 200
s = fourier_square(x, N)
overshoot = (s.max() - 1.0) / 1.0 * 100
print(f"N = {N} 時跳躍點附近過衝約 {overshoot:.1f}%（Gibbs 現象，理論值 ≈ 8.95%）")
```

執行後可見：諧波數 $N$ 越大，部份和越貼近方波，連尖角都能逼近（證明伯努利與傅立葉是對的）；但跳躍點附近總有約 9% 的過衝（Gibbs 現象，1899）——提醒我們「收斂」的細節，正是當年達朗貝爾直覺擔憂的真實殘影。
