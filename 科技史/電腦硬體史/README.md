# 電腦硬體史 -- AI 偵探風格

以「推理探案」的方式，追查電腦硬體從加法機到先進製程的每一步：
前因是什麼？線索在哪裡？推理如何展開？後果又如何改變了整個文明？
核心謎題只有一個：**如何讓「計算」這件事，从鐵齒輪變成電子、开關，最後變成奈米尺度的開關？**
