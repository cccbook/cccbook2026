# 2004-有限單群分類補完（Quasithin Case）

## 案件摘要
1983 年 Gorenstein 宣告「有限單群分類完成」，但其中 quasithin 情形實際上未完成。
2004 年 Aschbacher 與 Smith 發表 1200 頁專著補完此漏洞，分類定理才真正蓋棺定論。

## 前因 -- 為什麼會有這個案子
- **分類目標**：證明每個有限單群都屬於已知清單——18 個無窮族（Lie 型群、交錯群、循環素數階群）
  加上 26 個散在群（sporadic groups，如 Monster、Baby Monster）。
- **1983 宣告**（見 [1983-有限單群分類](1983-有限單群分類.md)）：Gorenstein 於 1983 年宣告分類完成，
  但證明分散在約 500 位作者、上萬頁期刊論文中，無人能全盤查核。
- **漏洞浮現**：Mason 在審核 GLS 計畫時發現「quasithin 情形」——
  即 2-局部秩至多 2 的特徵 2 型群——的處理（Thompson 的工作）存在關鍵缺口，
  甚至可能有未知的散在群藏身其中。
- 這成為分類工程最大的「未結懸案」：若 quasithin 有例外，整個定理失效。

## 線索與推理 -- 數學式、程式、理論

### 分類定理的最終形式
每個有限單群恰為以下之一：
1. $\mathbb{Z}_p$（素數階循環群）；
2. 交錯群 $A_n$（$n \ge 5$）；
3. Lie 型有限群（如 $\mathrm{PSL}_2(q)$、$E_8(q)$ 等，共 16 族）；
4. 26 個散在群（$M_{11}, M_{12}, \ldots, M$, $B$, $Fi_{24}', \ldots, J_4$）。

Python 快速感受「清單」結構：

```python
from math import factorial
from sympy import isprime  # 若無 sympy，可自寫試除

def is_prime(n):
    if n < 2: return False
    i = 2
    while i * i <= n:
        if n % i == 0: return False
        i += 1
    return True

# 循環素數階單群：前 10 個
print([p for p in range(2, 40) if is_prime(p)])

# 交錯群 A_n 為單群 (n >= 5)：檢查階數 |A_n| = n!/2
for n in range(5, 9):
    print(f"|A_{n}| = {factorial(n)//2}")

# 散在群階數（例：最小的 M11 與最大的 Monster）
M11 = 7920
Monster = 2**46 * 3**20 * 5**9 * 7**6 * 11**2 * 13**3 * 17 * 19 * 23 * 29 * 31 * 41 * 47 * 59 * 71
print("Monster 的位數:", len(str(Monster)))
```

### Quasithin 情形是什麼
設 $G$ 為特徵 2 型單群（最大 2-子群非循環），其 **2-局部秩** $m_2(G)$ 定義為
$$m_2(G) = \max\{ r(S) : S \text{ 是某 2-局部子群的 Sylow 2-子群} \}$$
quasithin 案件即處理 $m_2(G) \le 2$ 的情形。此情形技術上極端繁瑣，
Thompson 1970 年代的原稿有洞，且不像其他情形有多人獨立驗證。

### Aschbacher–Smith 的推理
Aschbacher–Smith (2004) 以兩冊共 1200 頁證明：
> 若 $G$ 是特徵 2 型單群且 $m_2(G) \le 2$，則 $G$ 屬於已知清單（$\mathrm{PSL}_3(q)$、$\mathrm{PSU}_3(q)$、$L_2(q)$ 的推廣等）。

證明策略：對「弱嵌入子群」（weakly embedded subgroup）的存在做逐案分析，
排除所有可能的新散在群——結論是**沒有第 27 個散在群**藏身 quasithin 之中。

### 萬頁證明的管理問題
- 證明依賴約 **10,000+ 頁**期刊論文、**100+ 位**作者，邏輯依賴圖無人完整掌握。
- **Second generation proof（GLS 計畫）**：Gorenstein–Lyons–Solomon 自 1980 年代起
  重寫「簡化且自足」的證明，規劃 16 冊、目標僅 3000–5000 頁；至 2005 年出版至第 6 冊，
  quasithin 案件被排除在其重寫範圍外，由 Aschbacher–Smith 獨立成書補位。
- 這是數學史上最大規模的「軟體工程式」合作：版本管理、依賴追蹤、漏洞回報，
  都成為數學寫作必須面對的問題。

## 結案 -- 後果與影響
- 2004 年後，有限單群分類定理（CFSG）被學界普遍承認為**真正完成**。
- 促進對「巨型證明」的方法論反思：形式化驗證（如 Lean 的 Liquid Tensor 實驗、
  以及後續對 Monster 相關構造的形式化）開始被視為解方。
- CFSG 成為許多分支（如有限幾何、組合設計、Burnside 問題類結果）的標準引用依據。
- 26 個散在群、Monster 群的 moonshine 現象獲得更穩固的基礎。
