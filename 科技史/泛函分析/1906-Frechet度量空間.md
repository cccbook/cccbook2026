# 1906-Frechet度量空間

## 案件檔案表

| 項目 | 內容 |
|------|------|
| 發生時間 | 1906 年（Maurice Fréchet 博士論文，巴黎） |
| 發生地點 | 法國巴黎（École Normale Supérieure） |
| 報案人 | 泛函分析（距離的定義散落各處，缺乏統一公理） |
| 偵探 | Maurice Fréchet |
| 兇器 | 「極限」一詞的歧義：函數列、曲線列、集合列各說各話 |
| 結論 | 度量空間三公理誕生，完備性與緊性定義確立，泛函（fonctionnelle）一詞問世 |

## 案發現場

1906 年的巴黎，分析的版圖正在劇變。Hilbert 在哥廷根用 $\ell^2$ 幾何化了序列空間，但他的 $\ell^2$ 是**量身訂做**的：專為積分方程服務，換一個對象就要重新打造。

Fréchet 是 Hadamard 的學生。他注意到一個更深層的問題：

1. 數列有極限、函數列有極限、曲線列有極限——但每種「極限」的定義**各不相同**，沒有統一的語言。
2. Hilbert 用 $\ell^2$ 、Volterra 用一致收斂、Lebesgue 用測度收斂——大家都在講距離，卻沒有人問：**距離的本質是什麼？**
3. 「對函數的函數」（例如定積分 $\int f$ 、極值問題裡的泛函）到底該怎麼研究？

Hadamard 早已把「對函數的連續線性泛函」掛在嘴邊，並建議學生去研究「無窮維的微積分」。Fréchet 接下了這宗案子，他的武器只有一樣：**把距離抽象成公理**。

## 偵查過程

### 線索一：距離的本質——三公理

Fréchet 檢視了所有已知的「極限」定義，發現它們共有的骨架是：一個對每對點定義的正實值函數 $d(x, y)$ ，滿足三條公理：

$$
\begin{aligned}
&\textbf{(M1) 非負性與恆等：} && d(x, y) \ge 0, \quad d(x, y) = 0 \iff x = y , \\
&\textbf{(M2) 對稱性：} && d(x, y) = d(y, x) , \\
&\textbf{(M3) 三角不等式：} && d(x, z) \le d(x, y) + d(y, z) .
\end{aligned}
$$

滿足這三條的集合稱為**度量空間**（espace métrique）。這個詞就是 Fréchet 在 1906 年的博士論文裡發明的。

### 線索二：各種空間全部入籍

Fréchet 驗證了當時已知的各種對象都滿足三公理：

| 空間 | 點 | 距離 $d$ |
|------|-----|----------|
| $\mathbb{R}^n$ | 實向量 | $\sqrt{\sum (x_i - y_i)^2}$ |
| $\ell^2$ （Hilbert） | 平方可和序列 | $\left( \sum \lvert x_n - y_n\rvert^2 \right)^{1/2}$ |
| $C[a,b]$ | 連續函數 | $\max_{x \in [a,b]} \lvert f(x) - g(x)\rvert$ |
| 函數空間（逐點收斂） | 函數 | $d(f,g) = \min\{1, \sup \lvert f-g\rvert\}$ 類構造 |
| 集合的空間 | 閉集 | Hausdorff 式集距 |

同一套公理統治了所有極限理論——這是 Copernicus 式的轉向：**不再為每個對象量身打造收斂定義，而是讓對象入籍統一的王國**。

### 線索三：完備性——從 Cauchy 數列提煉出來

Fréchet 觀察到 Cauchy 數列的本質：**項與項愈來愈近，而不需要知道極限在哪**。他把這個性質公理化：

$$
\text{若 } d(x_m, x_n) \to 0 \ (m, n \to \infty) \text{，則存在 } x \text{ 使 } d(x_n, x) \to 0 .
$$

滿足此性質的度量空間稱為**完備**（complet）。這個詞也是 Fréchet 創造的。

在完備空間中，Cauchy 收斂準則、逐次逼近法、壓縮映射論證全部成立。Volterra 在 1887 年用的「疊核迭代 + 階乘壓制」，本質上就是在 $C[a,b]$ （完備度量空間）中做逐次逼近——Fréchet 把這個隱藏的骨架挖了出來。

### 線索四：緊性——Bolzano–Weierstrass 的抽象化

Fréchet 還定義了**緊性**（compactité）：序列緊（self-compact）——每個點列都有收斂子列，且極限落在集合內。這是 Bolzano–Weierstrass 定理（ $\mathbb{R}^n$ 中有界集有收斂子列）的公理化。

| 性質 | $\mathbb{R}^n$ | 一般度量空間 |
|------|-----------------|----------------|
| 有界 ⇒ 有收斂子列 | 成立（B–W 定理） | **不**成立 |
| 緊 ⇒ 有界 | 成立 | 成立 |
| 緊 ⇒ 完備 | 成立 | 成立 |
| 緊集上連續函數有最大值 | 成立（Weierstrass） | 成立 |

Fréchet 證明了抽象版本：**緊度量空間上的連續泛函必達到最大值與最小值**。這是變分法存在性問題的抽象基礎——Arzelà 與 Ascoli 的等度連續判據，正是在 $C[a,b]$ 中刻畫緊性的先聲。

### 線索五：泛函（fonctionnelle）一詞誕生

Fréchet 創造了新詞：**fonctionnelle**（泛函）——「以函數為自變數的函數」：

$$
F : X \to \mathbb{R}, \quad \text{其中 } X \text{ 是函數空間或集合空間} .
$$

例如 $F(f) = \int_a^b f(x)\,dx$ 、 $F(f) = f(c)$ 、 $F(f) = \max |f|$ 都是 $C[a,b]$ 上的泛函。有了度量空間，就可以談泛函的**連續性**：

$$
d(f, g) \to 0 \implies F(f) \to F(g) .
$$

「泛函分析」這門學科的名字，就從這裡長出來。

## 結案報告

1. **度量空間三公理**： $d(x,y) \ge 0$ （恆等）、對稱、三角不等式——統治一切極限理論的憲法誕生。
2. **完備性與緊性**：兩個核心概念的名稱與定義確立，完備空間中逐次逼近合法，緊集上連續泛函有極值。
3. **泛函一詞問世**：fonctionnelle 命名了「函數的函數」，泛函分析（analyse fonctionnelle）由此得名。
4. **遺產**：
   - Hausdorff（1914）把 Fréchet 的度量拓樸融入一般拓樸空間理論。
   - Banach（1920）在完備度量空間的基礎上加上範數公理，Banach 空間誕生。
   - Arzelà–Ascoli 定理成為 $C[a,b]$ 緊性的標準刻畫；Banach 不動點定理（1922）把逐次逼近法公理化。

## 證據與工具

| 證據/工具 | 陳述 | 用途 |
|-----------|------|------|
| 度量公理 | (M1) 非負恆等、(M2) 對稱、(M3) 三角不等式 | 王國的憲法 |
| 完備性 | Cauchy 序列收斂於空間內 | 逐次逼近的合法性 |
| 緊性 | 每個點列有收斂子列 | 極值存在性的保證 |
| 緊集極值定理 | 緊空間上連續泛函達最大最小值 | 變分法的抽象基礎 |
| 泛函定義 | $F : X \to \mathbb{R}$ ， $X$ 為無窮維空間 | 學科命名的源頭 |

**證明骨架**（緊集極值定理）：

```
F 連續於緊集 K → 取數列使 F(x_n) → sup F
  → K 緊 ⇒ x_n 有收斂子列 x_{n_k} → x* ∈ K
  → F 連續 ⇒ F(x*) = sup F，最大值達到
```

**一句話結案**：Fréchet 把距離抽象成三條公理，讓數列、函數列、曲線列全部入籍同一個王國——「泛函」一詞就此誕生，泛函分析有了自己的名字與地基。
