# 1936 — Mazur 分離定理：超平面切開凸世界

## 案件檔案表

| 欄位 | 內容 |

| 案件名稱 | 凸集分離之謎：兩個不交集能否被一張「超平面」隔開？ |
| 主嫌（主角） | Stanisław Mazur（波蘭利沃夫學派） |

| 案發地點 | 實 Banach 空間 $X$ 及其對偶 $X^*$ |

| 兇器 | Hahn–Banach 定理的幾何化身：支撐超平面與分離超平面 |
| 關鍵證物 | 不交集凸集 $C_1, C_2$ 與線性泛函 $f$ 及實數 $\alpha$ ，滿足 $f(x) \le \alpha < f(y)$ |
| 結案判決 | Mazur 分離定理：凡凸集與開集之不交者，必有超平面分離 |

## 案發現場

1930 年代中期，泛函分析的黃金年代剛落幕，Banach 的教科書（1932）把三大定理擺上架，但「幾何」這條線還埋在地底。有限維的圖像是清楚的：平面上兩個不交的凸多邊形，總能畫一條直線把它們分開；三維裡是一張平面。這條直線（或平面）的代數化身是什麼？答案是線性泛函的水平集 $\{x : f(x) = \alpha\}$ ——所謂**超平面**。

疑點有三層：

1. **無窮維還有「平面」嗎？** 在 Banach 空間裡，超平面應定義為非零連續線性泛函的核的平移： $H = \{x \in X : f(x) = \alpha\}$ 。但連續線性泛函是否夠多，足以擔任「切刀」？
2. **分離條件該多強？** 只有「兩集合不交」不夠——一個開圓盤與它邊界上的一點不交，卻切不出嚴格分離。正確的前提必須涉及**開性**或**內點**。
3. **它跟 Hahn–Banach 有何血緣？** 延拓定理（1927）看似純代數的次線性控制遊戲，是否其實暗藏幾何骨架？

Mazur 在利沃夫的蘇格蘭書店（Scottish Book）圈子裡活動——那本筆記簿上許多問題由他出題。1936 年，他把這件幾何案件正式偵結：**Hahn–Banach 的真正身分，就是凸集的分離器**。

## 偵查過程

### 第一步：把「分離」翻譯成代數

設 $X$ 為實賦範線性空間， $f \in X^*$ 非零， $\alpha \in \mathbb{R}$ 。超平面

$$H = \{x \in X : f(x) = \alpha\}$$

把空間切成兩個半空間 $\{f \le \alpha\}$ 與 $\{f \ge \alpha\}$ 。說 $H$ 分離集合 $C_1$ 與 $C_2$ ，即存在 $f, \alpha$ 使

$$f(x) \le \alpha \le f(y) \quad (x \in C_1,\ y \in C_2),$$

而**嚴格分離**是更強的 $f(x) \le \alpha < f(y)$ 。偵查目標：找出什麼條件下這樣的 $f$ 必然存在。

### 第二步：單點與凸集的分離（支撐）

先攻最簡單的局：設 $C \subset X$ 是非空開凸集， $x_0 \notin C$ 。宣稱存在 $f \in X^*$ ， $f \ne 0$ ，使 $f(x_0) \ge \sup_{x \in C} f(x)$ 。

關鍵構造：把原點平移到 $x_0$ ，考慮錐狀的凸集合並利用**規度函數（gauge / Minkowski 泛函）**

$$p_C(v) = \inf \{t > 0 : v \in t(C - x_0)\}.$$

開凸性保證 $p_C$ 是次線性泛函（次可加且正齊次），且 $p_C(v) \le 1$ 對 $v \in C - x_0$ 。在一年子空間 $\mathbb{R}x_1$ 上定義 $f_0(t x_1) = t\, p_C(x_1)$ （取 $x_1 \notin C$ ），再用 Hahn–Banach 延拓得 $f \le p_C$ 於全空間。這一步正是偵案的轉捩點：**延拓定理原來是幾何測距儀**。

### 第三步：兩凸集的分離

設 $C_1, C_2$ 為非空不交凸集， $C_2$ 開。令 $C = C_1 - C_2$ ：它是凸集，且由 $C_2$ 開可知 $C$ 也是開集，而 $0 \notin C$ 。套用第二步：存在 $f \ne 0$ 使

$$f(u - v) \le 0 \quad (u \in C_1,\ v \in C_2),$$

即 $f(u) \le f(v)$ 對所有 $u \in C_1$ 、 $v \in C_2$ 。於是有

$$\sup_{x \in C_1} f(x) \le \inf_{y \in C_2} f(y),$$

取 $\alpha$ 落在兩數之間即得分離。再因 $C_2$ 開且 $f \ne 0$ ， $f$ 在開凸集上不可能恆為常數，故實際上得**嚴格版**：

$$f(x) < f(y) \quad (x \in C_1,\ y \in C_2).$$

若還要求 $\|f\| = 1$ （正規化），只是尺度縮放，不失一般性。

### 第四步：證據整理表

| 條件 | 分離結論 | 反例警示 |
|------|----------|----------|
| $C_1$ 緊、 $C_2$ 閉凸、不交 | 可嚴格分離： $f(x) \le \alpha < f(y)$ | 需緊性，閉而不緊會失敗 |
| $C_2$ 開凸、 $C_1$ 凸、不交 | $f(x) < f(y)$ （弱嚴格） | 點在開集邊界時只能這樣 |
| 僅 $C_1 \cap C_2 = \varnothing$ ，皆凸 | 一般不可分離 | $\{(x,y): xy > 0\}$ 型習題 |
| $C$ 凸、 $x_0 \notin \operatorname{int} C$ | 支撐超平面： $f(x_0) \ge \sup_C f$ | 內點版本最乾淨 |

### 第五步：為何 Hahn–Banach 是「化身」

邏輯上兩者等價：由延拓定理推分離（如上），反向亦真——給定子空間上的受控泛函，分離 $\{(x, f_0(x))\}$ 的上方圖與控制泛函的上方圖，即得延拓。這是「分析命題 ↔ 幾何命題」的第一座雙語辭典，之後 Krein–Milman（1934）的端點理論、Fenchel 對偶全都建立在這座橋上。

## 結案報告

**判決**：Mazur 分離定理成立——Banach 空間中，不交的凸集與開凸集必可被超平面分離；Hahn–Banach 定理是它的代數偽裝，分離定理是它的幾何化身。

**遺產**：

1. **凸分析與對偶理論**：Fenchel 共軛 $f^*(y) = \sup_x (\langle y, x\rangle - f(x))$ 的整座理論，就是把「分離上方圖」反覆使用。支撐超平面給出次微分 $\partial f(x)$ 的存在性。
2. **最優控制**：Pontryagin 極大值原理（1956）證明的核心一步，正是用分離定理把「最優軌道的可達集」與「更好的端點」切開，切刀即協態變數 $p(t)$ ——凸對偶的伏筆在此埋下。
3. **優化與經濟學**：KKT 條件、Lagrange 乘子的存在性、Walras 均衡的 Arrow–Debreu 證明，本質都是 Mazur 分離。
4. **連續泛函夠多**：分離定理蘊含 $\bigcup_{f \in X^*} \ker f$ 補不出整個空間——對偶空間「看得到」每一點，這是弱拓樸（見 1950-Goldstine 一案）的地基。

## 證據與工具

| 工具 | 用途 |
|------|------|
| Hahn–Banach 延拓（1927） | 在規度函數控制下延拓子空間泛函 |
| Minkowski 規度函數 $p_C$ | 開凸集 → 次線性泛函，幾何變分析 |
| 超平面 $H = \{f = \alpha\}$ | 線性泛函的水平集，幾何切割器 |
| 差集 $C_1 - C_2$ 的開凸性 | 把兩集合問題化成單點問題 |

**範例**：在 $X = C[0,1]$ 中，取 $C = \{u : u(t) > 0\ \forall t\}$ （開凸）。任取 $v \notin \overline{C}$ ，即某點 $v(t_0) \le 0$ 。取 $f(u) = u(t_0)$ （賦值泛函），則 $f(u) > 0 \ge f(v)$ 對所有 $u \in C$ ——賦值泛函就是支撐 $C$ 的切刀。這個平凡的算例在無窮維並不顯然：若對偶空間不夠大（非局部凸的空間），分離會整個失效，可見「局部凸」正是本案的隱形前提。

**一句話結案**：超平面是泛函的影子，Mazur 讓影子開口說出凸集之間的秘密。
