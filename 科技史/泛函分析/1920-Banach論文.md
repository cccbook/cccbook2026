| 案件檔案 | 內容 |
|------|------|
| 案件編號 | CASE-1920-BANACH |
| 案發時間 | 1920 年（博士論文，1922 年刊於 Fundamenta Mathematicae） |
| 案發地點 | 波蘭 Lwów（利沃夫）工業大學 |
| 主嫌／主角 | Stefan Banach（1892–1945），自學出身的數學奇才 |
| 論文標題 | *Sur les opérations dans les ensembles abstraits*（論抽象集合中的運算） |
| 涉案罪名 | 擅自將無窮維空間公理化，搶走「賦範空間」的命名權 |
| 關鍵證物 | 範數公理、完備性、 $L^p$ 空間、Hölder 不等式 |

## 案發現場

1920 年的數學界，正面臨一場「空間身分」的混亂案件：

- Hilbert 在 1906 年把 $l^2$ 整修成幾何殿堂，但那裡只收容「平方可和」的序列，規矩太嚴。
- Fréchet 在 1906 年把距離抽象成度量公理，地基打好了，卻沒有「長度」的概念，無法談收斂速度與算子大小。
- Volterra、Fredholm 的積分方程到處需要一個能容納 $L^p$ 函數、又能計算範數的家。

**未解之謎**：能不能找到一組最精簡的公理，讓所有「可以談長度、談極限」的無窮維空間同時入籍？這樣一來，積分方程、級數、逼近問題就能共用同一套推理工具。

在 Lwów 的咖啡館（蘇格蘭咖啡館的前身）裡，Banach——一個沒有大學文憑、靠幫人補微積分被 Steinhaus「撿到」的年輕人——接下了這樁案子。

## 偵查過程

### 侦查線索一：範數的三條公理

Banach 的第一步，是從 Hilbert 空間的 $\|x\| = \sqrt{\langle x,x\rangle}$ 中「剝掉內積」，只保留長度最核心的三條性質。設 $X$ 為實（或複）向量空間，函數 $\|\cdot\| : X \to \mathbb{R}$ 滿足：

1. $\|x\| \ge 0$ ，且 $\|x\| = 0 \iff x = 0$ （正定性）
2. $\|\alpha x\| = |\alpha|\, \|x\|$ （齊次性）
3. $\|x + y\| \le \|x\| + \|y\|$ （三角不等式）

加上由範數導出的距離 $d(x,y) = \|x - y\|$ ，若 $(X, d)$ 完備，就稱為 **Banach 空間**。關鍵在完備性：Cauchy 列必收斂，這是讓積分方程的迭代法（逐次逼近）能收網的繩索。

### 侦查線索二： $L^p$ 全家入籍

Banach 接著驗證最重要的嫌疑人空間：對 $1 \le p < \infty$ ，定義

$$
\|f\|_p = \left( \int_a^b |f(t)|^p \, dt \right)^{1/p}
$$

在 Lebesgue 可測函數中把「幾乎處處相等」的函數視為同一人（商掉零範數類），得到 $L^p[a,b]$ 。這裡的偵查技巧是 Minkowski 不等式（三角不等式）：

$$
\|f + g\|_p \le \|f\|_p + \|g\|_p, \qquad 1 \le p < \infty
$$

而 $p = \infty$ 時定義本質上確界範數 $\|f\|_\infty = \operatorname{ess\,sup} |f|$ 。Banach 證明了 ** $L^p$ 空間對所有 $1 \le p \le \infty$ 皆完備**——這是比 Riesz–Fischer（只證 $p=2$ ）更大規模的集體入籍。

### 侦查線索三：Hölder 不等式——對偶的預告

證明完備性與驗證三角不等式的關鍵工具是 **Hölder 不等式**：若 $1 < p < \infty$ 且 $\frac{1}{p} + \frac{1}{q} = 1$ ，則

$$
\int_a^b |f(t) g(t)| \, dt \le \|f\|_p \, \|g\|_q
$$

偵查手法：先對 $t \in (0,1)$ 證明初等不等式 $t^{1/p} \le \frac{t}{p} + \frac{1}{q}$ ，兩邊取適當變數代換得 Young 不等式 $ab \le \frac{a^p}{p} + \frac{b^q}{q}$ ，再對 $f/ \|f\|_p$ 、 $g/\|g\|_q$ 正規化後積分即得。

這條不等式不只修好了 Minkowski（證明中要用它兩次），更埋下一個巨大伏筆： $(L^p)^* \cong L^q$ ——對偶空間的門已經被推開一條縫。

### 侦查線索四：把公理變成武器

Banach 論文的真正野心在後半：他直接在抽象空間裡證明定理，而不只是研究具體空間。論文中已含：

- 稠密線性子空間上的連續線性泛函可延拓（Hahn–Banach 定理的前身）
- 線性算子的連續性判據
- 逐次逼近法在抽象空間中的敘述

### 嫌疑人空間對照表

| 空間 | 範數 | 完備性 | 入籍年份 |
|------|------|------|------|
| $C[a,b]$ | $\|f\| = \max |f|$ | 是（已由 Weierstrass 傳統確立） | 前案已備 |
| $l^2$ | $\left(\sum |x_n|^2\right)^{1/2}$ | 是（Riesz–Fischer 1907） | 前案已備 |
| $l^p$ （ $1 \le p < \infty$ ） | $\left(\sum |x_n|^p\right)^{1/p}$ | 是 | 1920 |
| $L^p[a,b]$ （ $1 \le p < \infty$ ） | $\left(\int |f|^p\right)^{1/p}$ | 是 | 1920 |
| $L^\infty[a,b]$ | $\operatorname{ess\,sup} |f|$ | 是 | 1920 |

## 結案報告

**判決**：Banach 以這篇論文獲得 Lwów 工業大學博士學位（導師 Steinhaus，論文答辯後印成單行本），「Banach 空間」從此成為標準術語（命名歸功於 Fréchet 的提議）。

- **公理化成功**：抽象空間從此可以像歐氏空間一樣談長度、極限與算子，積分方程、級數論、逼近論共用一套語言。
- **波蘭學派開山**：Lwów 的蘇格蘭咖啡館成為「數學交易所」，Banach、Steinhaus、Mazur、Ulam 在咖啡帳本（Księga Szkocka）上記問題、懸賞獎品——這是數學史上最著名的「咖啡館研究所」。
- **伏筆繼承**：Hölder 不等式指出的對偶之門，由 1927 年的 Hahn–Banach 定理正式推開；而完備性公理，將在 1929 年成為 Baire 綱論發動攻擊的彈藥庫。

## 證據與工具

| 證物 | 陳述 | 用途 |
|------|------|------|
| 範數公理 | 正定、齊次、三角不等式 | 定義賦範空間 |
| 完備性 | Cauchy 列收斂 | 迭代法收網、Baire 綱論的彈藥 |
| Minkowski 不等式 | $\|f+g\|_p \le \|f\|_p + \|g\|_p$ | $L^p$ 的三角不等式 |
| Hölder 不等式 | $\int |fg| \le \|f\|_p \|g\|_q$ | 對偶理論第一道門 |
| 完備性定理 | $L^p$ 對 $1 \le p \le \infty$ 完備 | 全體 $L^p$ 入籍 |

**證明骨架**（ $L^p$ 完備性）：取 Cauchy 列 $(f_n)$ → 抽子列使 $\|f_{n_{k+1}} - f_{n_k}\|_p \le 2^{-k}$ → 令 $g = \sum_k |f_{n_{k+1}} - f_{n_k}|$ ，由 Hölder（離散版）證 $g \in L^p$ → 故級數幾乎處處收斂， $f_{n_k} \to f$ a.e. → 控制收斂定理得 $\|f_{n_k} - f\|_p \to 0$ → Cauchy 性質把整列拉回收斂網。
